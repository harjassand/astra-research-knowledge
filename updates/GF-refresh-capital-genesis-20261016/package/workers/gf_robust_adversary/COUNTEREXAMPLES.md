# Exact failure ledger

All examples are mathematical constructions. They do not report hardware observations. Source-relative examples are reconstructed here; additional examples sharpen the interface tests.

| Rejected shortcut | Witness | Failure |
|---|---|---|
| Prepared-bath reduced half-diamond errors multiply | A common bath bit is one with probability \(\epsilon\). Each parent's dephaser is followed by a syndrome \(X_i\) iff that bit is one. | Every reduced calibrated channel has half-diamond error \(\epsilon\); all selected flags are bad with probability \(\epsilon\), rather than \(\epsilon^n\). The actual full-joint slot distance is one, witnessed by bath input one. |
| One full-system error may be assigned independently to many parents | One channel applies \(X_1\cdots X_n\) with probability \(\epsilon\). | Its full half-diamond error is \(\epsilon\), and all-bad probability is \(\epsilon\). It is a joint/hyperedge fault, not \(n\) separate local faults. |
| A small diamond number is a coherent residual angle | \(N=(1-\epsilon)\operatorname{Id}+\epsilon\operatorname{Ad}_X\), ideal value zero. | Actual failure is \(\epsilon\). A proposed \(\sin^2\epsilon=O(\epsilon^2)\) bound is false. A coherent-unitary/action contract is stronger than a diamond bound. |
| Average angle may replace a uniform seed-controlled angle | A private seed applies a \(\pi/2\) rotation with probability \(w\), and identity otherwise. | Failure is \(w\); using the mean angle gives \(\sin^2(w\pi/2)=O(w^2)\). Use a uniform seed-controlled angle or a common-\(a\) weighted CP envelope. |
| Normalized Choi overlap supplies a uniform unitary angle | \(U=\operatorname{diag}(1,1,-1)\). | Normalized Choi overlap is \(1/3\), but \(U\) maps \((|0\rangle+|2\rangle)/\sqrt2\) to an orthogonal state. The numerical-range minimum is zero, so the correct uniform angle is \(\pi/2\). |
| Each elementary detectable footprint is sufficient for endpoint support | Code \(\langle XXXX,ZZZZ\rangle\), individual errors on qubits one and two. | Each one-qubit Pauli footprint has trivial centralizer, but their union supports logical \(X_1X_2\). The exact endpoint-good Kraus operator is \(\cos^2\theta\,I_{\rm logical}-\sin^2\theta\,X_1X_2\). |
| Exact endpoint instruments suffice while the comparator is mutable | True entry syndrome zero; a fault flips both syndrome and working record copy; exact final syndrome is one. | The reported comparison says \(1=1\), yet the true syndrome changed. Support needs the protected genuine entering record. The intended trusted-record source contract excludes this example. |
| Small logical diamond error has a large exact ideal CP component | \(U=cI-isX_L\) on a logical spectator; all syndrome flags remain good. | On the two Choi rays, \(\det[J(\operatorname{Ad}_U)-aJ(\operatorname{Id})]=-4as^2<0\) for every \(a>0\). There is no nonzero identity CP minorant. |
| Equal terminal channels imply equal live-port processes | Actual process swaps system and bath, later swaps back; reference uses two identities. | With no intervention both complete joint terminal channels are exactly identity. Intervening \(X\) on the system produces orthogonal final joint states in the two processes. |
| A compiled stabilizer endpoint makes baseline drift free | \(G=\langle ZZ,XX\rangle\), \(H_0=J(I-XX)/2\), \(H_c=\Omega(Z_1+Z_2)/2\), \(J=\sqrt5\Omega\), \(\tau=\pi/\Omega\). | Baseline preserves every stabilizer and has zero old odd action. The actual selected pulse fails with probability \(4/9\), and the hidden fair choice fails with \(2/9\). The whole path matters. |
| The new endpoint constant bounds the unchanged old history event | Two \(\pi/6\) rotations separated by \((\operatorname{Id}+D_Z)/2\). | Old any-block mismatch is \(19/32\); endpoint mismatch is \(18/32\). Leave-and-return histories explain the exact difference. |

The original local full-joint CP-majorant theorem survives these tests because it excludes the shortcuts above. The stronger coherent result retains the same causal/local reference contract and does not repair missing exact support, noisy endpoint records, or original-generator assumptions.

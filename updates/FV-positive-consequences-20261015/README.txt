preserve_selected.py copies only an explicitly root_frozen selection, checks all
inputs and destinations before copying, exclusively creates complete files and
refuses immutable collisions. It preserves a versioned SELECTED_FREEZE and
DERIVED_MANIFEST with exact selected paths/hashes. A later cumulative selection
must retain previously copied evidence; changed evidence needs a new destination
path and an explicit new version. Unselected files are never silently deleted.
Interrupted copying can be resumed with the same unchanged selection.

The copy filter excludes archive/PDF/binary network and coordinate extensions.
Each selected file also needs explicit root declarations that it contains no
publisher fulltext and no full LJ network or coordinate payload. These declared
content classes are root attestations, not an automatic semantic audit. Keep
external receipts, URLs, pinned versions, hashes and acquisition pointers. Keep
full molecular archives/coordinates in the research workspace, outside Git.

artifacts retain their frozen provenance roles. Applying requires the final input
hash, a separate explicit root-authorization flag, exact HEAD/base equality and
a fresh origin/main check. The generator does no scientific inference and does
not publish checkpoints, technology records, Git commits or generated views.

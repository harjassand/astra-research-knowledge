2. Exact scientific curation

Fill a new CURATION_INPUT.json using the input template. Preserve that template.
Its initial three card placeholders are a convenience, not a scientific grouping
decision. Root may replace the card array with the scientifically justified
number and grouping. Fill every REPLACE_ field and set curation_status=root_final
only after adjudication. The generator rejects unfilled required fields.

Set reserved_routes to exactly the numeric N routes selected by root. Card IDs
must match those routes and avoid existing numeric-route collisions. This packet
allocates no numeric scientific IDs. Refresh/reconcile the actual base before a
later application; the initial source acquisition pin is not a fresh remote check.

Set selected_freeze to the repository-relative path/full SHA of the preserved
root freeze. Preserve all three original source metadata entries. Add metadata
for selected evidence that will serve as an indexed proof source, retaining its
exact frozen path/hash and provenance role. New source IDs use src-FV-PC-.

Each evidence entry needs an exact repository path, full SHA, inclusive one-based
line range, range_scope and attributed status. Give source_id when metadata is
ambiguous. Historical source_revision is null unless its exact Git bytes have
been checked in separately authorized read-only Git work. Distinguish inventories
from decisive proof/counterexample ranges. A whole-text inventory is not a proof
completeness attestation.

Each card needs its exact scope, statement/quantifiers, assumptions, proof spine,
complete cost boundary or explicit UNKNOWN, supplied/acquired/legal-access
contract, obstruction/failure scope, matched comparator or explicit UNKNOWN,
remaining obligation, actual review depth, separately attributed source status,
proof availability and proof/inventory references. Internal completeness has its
own field; it does not change external UNKNOWN or source_derived_unreviewed.

3. Paired bridge contracts and open obligations

Use BRIDGE.template.json for each selected transfer. Preserve both the source
subclaim and destination obligation with exact separate evidence references.
Fill both object/domain, regime/quantifier, supplied/acquired input, legal-access,
guarantee, units/norm/precision and cost contracts. Record alignment, missing lemma,
losses, reciprocal scope and decisive falsifier. Use one of the five existing
COMPOSITION states. Positive states need transfer_proof_ref_ids; refutation needs
counterexample_ref_ids. A mismatch or planned falsifier is not an executed
refutation. New bridge IDs use FV_PC_; notices use SN-FV-PC-; gates use G-FV-PC-.

REVIEW and CAPABILITY gates are generated open for every card. Additional gates
remain open with empty completion evidence. Root must not use indexing or
integrity receipts to discharge a scientific or acquisition obligation.

# Root publication selection decisions

The Luna inventory is a candidate list, not a freeze or authority. Root admits
local workspace paths in authored proofs and integrity receipts: these are the
user-specified public research provenance already used in supplied inputs, not
credentials or a reason to discard load-bearing proofs. Final citations use
repository-relative paths and immutable GitHub URLs. No source bytes are edited.

Exclude complete external PDFs/texts/workbooks/data/clones, page renders, plots,
environments, caches, and acquired spreadsheet extracts. Exclude both conductance
and purity derived CSV tables: authored aggregate measurements and replay code,
with public raw-data URLs/hashes, suffice for the claims. Exclude redundant
source-cell inventories and exploratory source-data dumps. Publication does not
assert that every file listed in a producer's full local manifest was copied.
The root-selected manifest is the authority for preserved payload membership.

Preserve exact final algebra/proof artifacts and explicit corrections. Conditional
v1 records, the original failed ordered-pair checker, and earlier audit snapshots
remain labeled historical evidence. Final replay targets are identified separately;
a historical failure is not silently relabeled PASS. Original source prompts and
exact supplied bytes are kept separately from this authored selection.

Explicit safe exceptions to a blanket sources-directory exclusion are authored
acquisition manifests containing URLs, sizes and hashes only. They do not include
external article/SI text or workbook cells. The missing ZIP and physical packet
remain missing. No third-party license, publication or external correctness is
inferred from local possession or public retrieval.

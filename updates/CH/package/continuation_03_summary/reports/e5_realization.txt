1. THE FINITE CHANNEL IS PHYSICAL

Input: arbitrary normalized purification coefficients C[a,n], with finite Fock
support n<=N and any finite reference dimension r. Rows need not be orthogonal.
Channel parameters: 0<eta<1, nu>=0, G=1+(1-eta)nu, tau=eta/G.

Compose pure loss and a quantum-limited amplifier. The retained Kraus matrix
K_{ell,k}=P_M A_k L_ell has a single nonzero output entry per input n:

  output m=n-ell+k,
  |K_{ell,k}[m,n]|^2 = C(n,ell)(1-tau)^ell tau^(n-ell)
                       C(m,k)(G-1)^k/G^(m+1).

Only ell<=N and k<=M can contribute to retained levels 0,...,M. Thus every
retained entry is a finite sum. There is no cutoff on a thermal-environment
state and no hidden renormalization.

The missing probability is calculated positively, avoiding 1 minus a number
rounded to one. With q=(G-1)/G and p=1/G, the amplifier probability of an
output above M from a number state s is

  A_tail(s) = sum_{j=0}^s C(M+1,j) p^j q^(M+1-j),  s<=M,
              1,                                  s>M.

This follows by identifying the negative-binomial tail with the probability
that M+1 Bernoulli trials have at most s successes. For the loss-amplifier
composition, t_n=sum_ell Binomial(n,ell;1-tau) A_tail(n-ell).

The physical RB output is the direct sum of

  J_ret = sum_{ell,k} |vec(C K_{ell,k}^T)><vec(C K_{ell,k}^T)|,
  F_R   = C diag(t_n) C^dagger,

with F_R attached to the orthogonal erasure flag. Phase covariance makes the
erasure effect diagonal in the input Fock basis, so the latter formula keeps
the correct reference coherence. B is obtained by tracing R. All flags and
their entropies enter S(B)-S(RB).

The exact formulas define a CPTP map. Numerical evaluations use float64,
record trace/TP/positivity residuals, and do not repair traces by normalization.
Eigenvalues negative only at roundoff scale are clipped for entropy diagnostics;
the smallest eigenvalue is reported. This does not certify interval bounds.

Quantum data processing gives
  Ic(rho,Phi) >= Ic(rho,T_M o Phi).
Consequently a strictly positive certified finite result would suffice. A
negative finite result is only a negative LOWER bound; it is not a capacity
upper bound and cannot rule out positivity of the unprocessed channel.

3. EXACT OBSTRUCTION TO HERALDED SINGLE-PHOTON MULTI-RAIL CODES

Encode one logical m-level system into one photon spread across m modes. Keep
only total-output-photon-number-one and replace all other outputs by a flag.
At nu=1 the accepted map is exactly

  rho -> a rho + b Tr(rho) I_m,
  a=eta/(2-eta)^(m+2),
  b=2(1-eta)^2/(2-eta)^(m+2).

The acceptance probability is independent of rho:
  s_m=[eta+2m(1-eta)^2]/(2-eta)^(m+2).
The conditional channel is depolarizing with parameter a/s_m. This is an
unconditional flagged erasure-depolarizing channel, not a free heralded qudit.

For .75<=eta<=.8 and m>=2, s_m<=s_2(.8)=25/54<1/2. Proof: set x=1-eta.
The denominator minus numerator of s_{m+1}/s_m is proportional to
  x(1-3x+2m x^2)>0, x in [.2,.25].
Thus s_m decreases with m. Moreover
  d s_2/dx = (-5+11x-8x^2)/(1+x)^5 <0,
so its maximum in this interval is at eta=.8.

For every input rho,
  Ic(flagged channel) = s_m Ic(rho,depolarizing) -(1-s_m)S(rho)
                       <=(2s_m-1)S(rho)<=0.
The channel is a depolarizing channel followed by an erasure channel with
acceptance <=1/2, hence is antidegradable, including under arbitrary block
coding. The family therefore cannot close the unresolved region with this
decoder. Multiplying the conditional rate by acceptance and omitting the
failure-reference entropy would give a false positive.

Resource charge: m physical channel uses, one photon per block, logical
dimension m, acceptance as above, all failed uses included, and no feedback
or environment flag supplied. A total-photon-number-one decoder is assumed
ideal. This obstruction concerns that output processing; it is not a theorem
about all encodings supported on the one-photon input subspace with full output.

5. DISTINCT FAMILY: FIXED-TOTAL ENTANGLED BINOMIAL CODES

Define N=K S and two orthogonal pure two-mode states

  |psi_a> = 2^(-(K-1)/2) sum_{0<=j<=K, j mod 2=a}
             sqrt(C(K,j)) exp(i theta j^2) |j S,(K-j) S>, a=0,1.

Mix them with weights p and 1-p. Every input has exactly N photons, and the
logical reference has dimension 2. The support K+1, spacing S, energy N,
and nonlinear number phase theta can all scale. The phase is a local Kerr
phase on mode one, while the codewords already contain intermode entanglement.

This is not just a common passive rotation of a two-dimensional number-state
code. For K>=2,S>=2, every pure state in the code subspace has one-particle
density matrix (N/2)I_2: binomial parity matches first moments and spacing
removes first-order intermode matrix elements. Passive mixing preserves this
spectrum. In the fixed-total-N sector, a pure product state must be a product
of number states; only |N/2,N/2> can have this spectrum, when N is even. Thus
no common passive rotation can produce two orthogonal product basis states.

The first bounded scan used (K,S)=(2,2),(3,2),(4,2),(2,3), p=.2,.5,.8,
theta=0,pi/8,pi/4 when nonredundant, and six eta values. All 144 evaluated
trials were negative. A separate 40-trial scaling test used N=12,16,24,
spacing 2 or 4, p=.5, and theta=0 or pi/8. All were negative. The tested
nonlinear phases worsened the best unphased results; this is a bounded
observation, not a proof that phase optimization cannot help.

6. SPARSE PHYSICAL TWO-MODE ENGINE AND RESOURCES

two_mode_evaluate(channel,C,fixed_total=N) is a generic tensor contraction
that includes all local flags. two_mode_fixed_total_evaluate(channel,C,N) is
a more efficient exact-sector engine for fixed total photon number.

For |n,N-n><k,N-k| the first local output is a single band with shift k-n and
the second has opposite shift. Both outputs therefore have equal total
photon number. Retained RB blocks are indexed by output total 0,...,2M;
each block has dimension at most r(M+1). Each one-flag output is a separate
r-dimensional reference block, and the two-flag output is another such block.
The engine stores these blocks and the local bands, never the full RB matrix.
It verifies exact fixed-total support and does not drop tiny input amplitudes.

Storage: O(r^2 M^3 + d^2 M), d=N+1; diagonalizations are at most r(M+1).
This accounts for all output states, not an approximation to the eigenproblem.

7. PRECISION AND WHAT AN ASYMPTOTIC APPROACH WOULD STILL NEED

Float64 traces and TP residuals are diagnostics, not bounds on the entropy
error. Independent 80-digit computations confirm only the source baselines.
The smaller negative scaling values are numerical observations. No new trial
has been passed through a directed-rounding entropy certificate.

Preparation/noise accuracy cannot be treated as free for tiny rates. If the
half trace distance of the exact and implemented joint states is <=delta,
the reference-dimension-two conditional-entropy bound is

  |delta Ic| <= f(delta)
             =2 delta +(1+delta) h_2(delta/(1+delta)).

One derivation uses the positive and negative parts of the state difference
to write a common state as two mixtures with weight 1/(1+delta); conditional
entropy is concave with mixture deviation at most binary entropy and lies
between -log_2(r) and log_2(r). Channel contraction makes the same bound apply
to an input purification preparation error. This is a sufficient conservative
error budget, not a measured hardware capability.

For half the reported positive margin, f(delta)<=c/2 suffices. Taking c=4.7e-4
or c=1.4312e-7 gives delta about 1.1865e-5 or 2.2232e-9, respectively.
Every proposed very small positive witness needs a correspondingly explicit
numerical certificate and physical error budget. Increasing arithmetic
precision alone does not establish preparation accuracy.

The binomial support supplies a useful barrier to one obvious scaling story.
For any polynomial f(j) of degree<K,
  sum_j (-1)^j C(K,j) f(j)=0.
Consequently diagonal occupation moments of degree<K agree between codewords.
Spacing S>2t prevents a pair of ladder-error monomials with total loss-plus-gain
degree at most t from connecting distinct support points. On a fixed-total-N
input, loss/amplifier damping factors are scalar for each error pattern.
Thus K>t,S>2t are sufficient Knill-Laflamme conditions for that finite subset
of error Kraus operators. They imply N=KS >=(t+1)(2t+1)=Omega(t^2).

This protected subset does not capture typical thermal errors at growing N.
Total pure-loss count ell is Binomial(N,1-tau), independent of the encoded
state. Conditional added count has mean (G-1)(N-ell+2). Hence

  E[ell+k] = [1-eta^2/(2-eta)] N + 2(1-eta), nu=1.

At eta=.75 the coefficient is .55. With t=O(sqrt(N)), even an ideal observer
given the environment label would accept at most
  P(ell+k<=t)<=P(Binomial(N,1-tau)<=t),
which decays exponentially in N. Declaring those rare events successful and
omitting all other events cannot yield an unassisted rate. This does not rule
out a decoder that uses degeneracy or approximate correction beyond the
finite protected subset; it rules out claiming an asymptotic construction
merely from the low-degree binomial moment identities.

A meaningful next search should let the number of modes grow while keeping
energy/mode bounded, use genuinely correlated pure codewords, and test the
FULL reference-output entropy. A concrete support pattern to investigate is
fixed-total-number occupation configurations with a parity/syndrome constraint
and nonlinear quadratic occupation phases on a sparse graph. The phase graph
and support constraints must be varied independently of total energy. Such a
family could change complementary conditional-block mixing while allowing
extensive noise to be handled collectively; no positivity theorem is asserted.
For more than two modes the output dimension grows as (M+2)^m, and this code
does not yet provide a scalable certified entropy engine. That is a concrete
computational barrier, not a missing numerical decimal optimization.

Success gate for the original boundary claim remains: for every epsilon>0,
produce a finite block/code with a certified unconditional Ic>0 at
eta=.75+epsilon, finite energy and memory, all block uses and failures charged,
and numerical/preparation error smaller than the positive margin. This report
does not pass that gate.

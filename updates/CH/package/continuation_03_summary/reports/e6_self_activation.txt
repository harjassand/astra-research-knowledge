E6 scout: self-activation from private capacity using an internal shield link
Date: 2026-10-10
Scope: exact Smith–Yard erasure identity, then the dimension/noise cost of the
one-photon rail helper. No full proof review or source edits.

Finding
=======

The below-half erasure probability is not the algebraic obstruction. For an
ideal erasure helper with any fixed success probability p>0, the Smith–Yard
private-ensemble input gives positive coherent information once the private
code is long enough. The obstacle in turning that into a self-activation
argument for a thermal attenuator is that the helper must transmit a coherent
shield whose dimension grows with the private code, while the finite rail
implementation both consumes that many channel modes and becomes rarer and
more depolarizing as the shield dimension grows.

This blocks the generic inference P(Phi)>0 => Q(Phi)>0. It does not prove that
the thermal attenuator cannot self-activate: a high-energy code could in
principle make Bob's private decoding error exceptionally small, and I found
no valid energy-uniform lower bound that rules this out. No threshold below
the current 0.7841 positive-witness point is established here.

Exact ideal-erasure identity
============================

Let {p_x,rho_x^{A^m}} be a finite private ensemble for N^{otimes m}. Choose
purifications |rho_x>^{A^m C} whose C supports are mutually orthogonal and set
|psi>^{X A^m C}=sum_x sqrt(p_x)|x>|rho_x>. Smith–Yard's finite-dimensional
construction takes dim(C)=sum_x rank(rho_x). Write H_B=H(X|B) and
P_ens=I(X;B)-I(X;E), evaluated after N^{otimes m} on A^m. Send C through an
ideal flagged erasure channel which delivers C to Bob with probability p and
otherwise sends it to the environment. Purity of X B E C gives

  Ic(N^{otimes m} tensor Erasure_p, rho^{A^m C})
    = p [S(BC)-S(E)] + (1-p)[S(B)-S(EC)]
    = p H(X|E) - (1-p)H(X|B)
    = p P_ens - (1-2p) H(X|B).

Thus the exact below-half penalty is (1-2p)H(X|B), not a fixed negative
constant. At p=1/2 this is P_ens/2. At p=0.4096 it is
0.4096 P_ens - 0.1808 H(X|B), positive iff
H(X|B)<(256/113)P_ens. A private coding sequence with rate R>0 has
P_ens/m -> at least R and, by Bob reliability plus Fano,
H(X|B)=o(m). Consequently Ic/m -> pR>0 for every fixed ideal p>0.
This is a valid strengthening of the p=1/2 identity for an independently
available, noiseless-shield erasure channel.

The finite-helper theorem's input-size requirement is material: the shield
dimension is sum_x rank(rho_x), not merely the logarithm of the message count.
For a finite-rank positive-rate m-use private code with
M_m=2^{mR+o(m)} messages, dim(C)>=M_m. If any rho_x has infinite rank, a
finite-D rail helper does not carry this shield without a separate truncation
and continuity argument. The four-level private-Horodecki example in
Smith–Yard uses two rank-two states, so its shield has dimension 4. Its p=1/2
helper is a separate four-dimensional erasure channel. A two-rail helper
cannot carry this shield.

Exact one-photon rail cost and a noisy-shield bound
==================================================

For nu=1 and eta=3/4, the total-one-photon projection on D rails, retaining
all failures as a receiver erasure flag, induces

  Psi_D = Erasure_{p_D} o Depol_{alpha_D},
  p_D = [eta + 2D(1-eta)^2]/(2-eta)^{D+2},
  alpha_D = eta/[eta + 2D(1-eta)^2].

Here Depol_alpha(rho)=alpha rho +(1-alpha)I_D/D. These are deterministic
flagged channels; dropping failures would change the task. At eta=3/4,

  D=2: p_D=256/625=0.4096, alpha_D=3/4;
  D=4: p_D=1024/3125=0.32768, alpha_D=3/5.

For D>=2, p_D decreases at this eta. In particular, p=0.4096 is the
two-dimensional maximum, not a success probability available at arbitrary
shield dimension. The canonical Smith–Yard four-dimensional shield already
uses D=4 here. For large D, p_D is asymptotic to
2D(1-eta)^2/(2-eta)^{D+2}, alpha_D is asymptotic to
eta/[2D(1-eta)^2], and exactly

  p_D alpha_D = eta/(2-eta)^{D+2}.

There is a useful exact bound that isolates the accepted-branch penalty.
After N^{otimes m}, keep the private purification state on X B E C. If C is
sent through Erasure_p after Depol_alpha, with C' denoting the accepted
depolarized output, the full flagged-channel coherent information is

  Ic = -H(X|B) + p I(X;C'|B).

The failure branch contributes -H(X|B); the success branch contributes
-H(X|BC'). Depolarization is the mixture alpha*id +(1-alpha)*replacement,
where replacement discards C and prepares I_D/D. Giving Bob a flag for this
mixture can only increase conditional mutual information, so

  I(X;C'|B) <= alpha I(X;C|B) <= 2 alpha log_2 D.

The last inequality is the standard dimension bound on conditional mutual
information. Therefore this rail construction can be positive only if

  H(X|B) < 2 p_D alpha_D log_2 D
          = 2 eta log_2(D)/(2-eta)^{D+2}.

This is a necessary bound, not a converse for all thermal-channel codes. Since
D>=M_m is exponential in m at positive private rate, the right side is
super-exponentially small in m for this single-block rail simulation. The
usual private coding guarantee H(X|B)=o(m) does not establish this much
stronger inequality. High energy might reduce H(X|B), but that quantitative
tradeoff has to be proved; a degenerate code would likewise need a lower
bound on I(X;C'|B) after accepted-branch depolarization. Neither follows from
P(Phi)>0 alone.

Using many fixed-D rail blocks instead of one D-rail block is a different
construction: the shield sees a product of flagged noisy channels and all
partial-erasure patterns must be included in the entropy calculation. The
single-erasure identity above cannot be applied by substituting p=0.4096,
and an accepted conditional state is not an unflagged clean channel.

Decisive scope check from primary literature
============================================

Smith–Yard's own four-level private Horodecki channel N_H has P(N_H)>0 and
Q(N_H)=0, while N_H tensor a separate four-dimensional 50%-erasure channel
has positive quantum capacity. Thus positive private capacity alone cannot
imply that a channel self-activates: the independent shield link is a real
resource in their theorem. This is an exact finite-dimensional counterexample
to the generic P>0 => Q>0 transfer, not a counterexample for the thermal
attenuator.

The thermal-specific task remains open at this interface. To turn the rail
idea into a proof one needs a finite-energy private code and a bound on its
H(X|B) that beats the shield channel's dimension-dependent loss, or a
different same-channel shield map with a proven positive CMI contribution.
To rule the route out even at unbounded energy, one would need an energy-free
lower bound on Bob's residual conditional entropy (or an equivalent upper
bound on I(X;C'|B)); none is supplied by the current data. The current primary
thermal-attenuator bracket remains 0.75 <= eta_c(1) <= 0.7841.

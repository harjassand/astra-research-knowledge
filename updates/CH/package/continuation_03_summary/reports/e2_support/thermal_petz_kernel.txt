E2: EXACT THERMAL-PURIFICATION WEIGHT KERNEL
Status: internally derived local identities. They diagnose a failed direct-Petz
extrapolation. They are not a complete finite-energy GKP coding theorem.

Notation: r=1-eta, a=nu+1/2, b=sqrt(nu(nu+1)),
q=nu/(nu+1) in (0,1), tau=(1-q)q^n, D(z)=exp(z a^dag-z* a).
The environment is E'F, where F purifies the thermal input environment.
Its characteristic function is
chi_{N^c(rho)}(z,w)=chi_rho(-sqrt(r)z)
 exp[-a(eta|z|^2+|w|^2)+b sqrt(eta)(zw+z*w*)].
Signs in the cross term can change with the purification convention and do
not affect any norm below.

Applying this formula distributionally to an input displacement gives, up to
the common 1/r Fourier normalization and an E' displacement unitary,
N^c(D(alpha)) = const * exp[-eta|alpha|^2/(4ar)]
                      D_{E'}(-alpha/sqrt(r)) tensor T_s,
T_s=D_F(s) tau D_F(s), s= -b sqrt(eta/r) alpha*/(2a).
Indeed the F characteristic function before collecting the scalar is
exp[-a|w|^2+b sqrt(eta/r)(alpha w+alpha*w*)], while
chi_{D(s)tau D(s)}(w)=exp[-a|w+2s|^2].
At alpha=0 the reference background is const * I_{E'} tensor tau.
This is an operator-valued distribution, not a normalized physical input.

1. THE TEMPTING UNWEIGHTED COLLISION KERNEL.
||T_s||_2^2=Tr(tau^2)=1/(2nu+1), because D(s) is unitary.
Thus the normalized unweighted squared overlap has factor
exp[-eta|alpha|^2/(2ar)] = exp[-eta|alpha|^2/(r(2nu+1))].
Replacing the recovery metric by this overlap would yield exactly the
antidegradability boundary eta>(2nu+1)/(2nu+2). That replacement is invalid.

2. THE ACTUAL PERTURBATIVE PETZ DENOMINATOR.
The square-root perturbation metric uses
K_q(s)=sum_{m,n>=0} |(T_s)_{mn}|^2/(sqrt(t_m)+sqrt(t_n))^2,
t_n=(1-q)q^n.
For pure loss the finite F factor is vacuum and this issue is absent.
For nu>0 it cannot be dropped. Put t=sqrt(q) and
c(q)=2(1-t)(1+t^2)/(t(1+t)).
By AM-GM,
K_q(s) <= (1/4) W_q(s),
W_q(s)=Tr[tau^(-1/2) T_s tau^(-1/2) T_s^dag]
      =exp[c(q)|s|^2].
The trace identity is obtained by commuting q^n past displacement operators.
It is also verified by the numerical support script.

3. THE AM-GM UPPER BOUND HAS THE EXACT LARGE-DISPLACEMENT EXPONENT.
For real s (rotation invariance handles complex s),
(T_s)_{nn}=(1-q) q^n exp[-(1+q)s^2] L_n(x),
x=(1+q)^2 s^2/q.
The diagonal m=n terms alone give
K_q(s) >= (1/4) exp[-A(q)s^2] I_0(B(q)s^2),
A(q)=4(1+q)/(1-q),
B(q)=2(1+q)^2/[sqrt(q)(1-q)].
This follows from the Hille-Hardy Laguerre identity
sum_n q^n L_n(x)^2=(1-q)^(-1)
 exp[-2qx/(1-q)] I_0[2sqrt(q)x/(1-q)].
Since B-A=c, the standard I_0 asymptotic yields
K_q(s) >= [1+o(1)] exp[c(q)s^2]/[4 sqrt(2pi B(q)s^2)].
Consequently
lim_{|s|->infinity} log K_q(s)/|s|^2 = c(q).
This is an exact local exponent, not merely a possibly loose AM-GM estimate.

4. COLLECTED EXPONENT.
Multiplying by the squared scalar in N^c(D(alpha)), the exact thermal-weight
kernel exponent is
-eta|alpha|^2/r * [(1-q)/(1+q)-c(q)q/(1+q)^2]
= -eta|alpha|^2/r * (1-sqrt(q))/(1+sqrt(q))
= -eta|alpha|^2/[r (sqrt(nu+1)+sqrt(nu))^2].
For nu=1 the penalty is C=3+2sqrt(2)=5.828427...
instead of the unweighted collision penalty 3. An elementary theta-function
extrapolation would need eta>C/(1+C)=(2+sqrt(2))/4=0.853553...
This number is only the gate suggested by that local exponent; it is not
claimed as a new optimal GKP rate or a no-go theorem for GKP codes.

Multimode observation: tau^tensor n is invariant under passive U(n) rotations.
Such a rotation can concentrate a displacement vector into one F mode, while
the unaffected modes cancel in the weighted Frobenius metric. Thus simply
spreading the displacement among modes does not erase this thermal weight.
This does not exclude stabilizer degeneracy or correlated encodings that
change the entire reference background rather than retaining this Gaussian
zero-lattice reference.

EXACT UNSOLVED GATE.
To turn direct GKP/Petz into a near-AD construction one needs an encoding or
smoothing/degeneracy mechanism that changes the environmental reference and
controls all lattice contributions, with finite energy and blocklength.
One cannot import the pure-loss theorem using only thermal second moments
or the unweighted Hilbert-Schmidt collision factor.

This snapshot contains the continuation reports, scripts, retained outputs,
and an unchanged copy of the earlier amplifier proof candidate. It contains
no third-party source checkout and does not certify historical originality.

Run from any directory:
  python3 /absolute/path/to/continuation_03_summary/replay.py

Python requirements: numpy 2.5.3 and mpmath 1.3.0 were used at this checkpoint.
The scoped replay also needs a `lean` executable for the isolated formal
lemma (tested with Lean 4.34.1). If absent, that check is marked SKIPPED.
The complete amplifier proof is not formalized by that lemma.

The replay copies the reports into a temporary workspace with the original
relative layout. It runs channel consistency controls, two directed-interval
counterexamples, and a floating-point dark-vector coefficient diagnostic.
It also compiles the isolated Lean lemma when Lean is available. Original
report outputs are preserved. Results are written to replay_receipt.json.

Longer numerical experiments can be rerun from the temporary-layout root by
the commands documented in each report. The scoped replay intentionally does
not rerun all numerical searches or claim to verify all analytical proofs.

SHA256SUMS.json records the packaged files other than itself. Checksums are
integrity evidence, not evidence that mathematical claims are correct.

MISSION REPORT — h01_learning
Date: 2026-10-10
Primary objective status: OPEN / NOT ACHIEVED

Target

Find a representation that permits exact or robust learning of reusable, compositional programs from limited feedback without assuming an equivalence/counterexample teacher, hidden search, or uncharged precision. The target landmark would be a broadly applicable improvement over the strongest class-aware program learner, not merely a restricted theorem or benchmark gain.

Strongest candidate actually derived

I froze the first derivation in `work/high_conviction_04/reports/h01_learning/first_derivation.md` before literature comparison. Its interface is explicit membership access to an unknown map f:G→H between known finite groups, with known group operations and a listed generating set S. A query g returns f(g); there is no code access, equivalence query, counterexample teacher, or target-side hypothesis search. Query input length, output encoding, random group sampling, group operations, and local evaluation all count.

Under the promise that f is a homomorphism, store the tuple (f(s):s∈S), not a syntax tree or full table. d=|S| queries determine the entire function: for a word g=s1^e1…sm^em, evaluate f(g)=f(s1)^e1…f(sm)^em. In the sharp example G=(Z2)^d and H=Z2, f is an unknown parity mask. Querying the d basis vectors learns it exactly. The class has 2^d targets and each response is one bit, so any exact membership-query learner requires at least d calls; this learner is optimal. With generator images stored once, arbitrary long products are executable by reusing the same representation.

Dropping the promise does not permit exact certification with finite queries. A standard group-law property test chooses uniform x,y and checks f(xy)=f(x)f(y). The non-Abelian theorem of Ben-Or, Coppersmith, Luby, and Rubinfeld establishes O(1/ε) query testing for arbitrary finite groups: accept homomorphisms and reject maps ε-far from every homomorphism with constant probability. Each trial makes three target calls and costs 3 input encodings plus 3 output encodings. Repetition gives failure at most δ using O(ε^-1 log(1/δ)) trials. Their theorem states that if the test's group-law failure rate δ0 is below 2/9, f is within ρ=(3−sqrt(9−24δ0))/12 of a homomorphism; this relationship yields the soundness bound. It is an approximate promise check, not proof that every unqueried value is correct.

A further robust learner follows directly from the representation. If f is ε-close to a homomorphism h under uniform distance, then for any x, sample uniform r and query f(r), f(rx). The value f(r)^−1 f(rx) equals h(x) unless at least one sample is corrupted, so it is correct with probability ≥1−2ε. For ε<1/4, repeating this for each generator and taking the most frequent answer recovers all d generator images with probability ≥1−δ using O(d(1−4ε)^−2 log(d/δ)) pair samples. Then evaluate the recovered homomorphism compositionally. This is an explicit no-teacher, noise-tolerant interface, but local decoding/self-correction of homomorphism codes is prior art.

What the literature comparison says

The candidate's mechanism is established algebraic learning and coding theory, not a new representation or capability. Ben-Or et al. already give the non-Abelian O(1/ε) homomorphism test. Grigorescu, Kopparty, and Sudan give local list decoding for homomorphism codes from noisy oracle access, with running time polynomial in log|G| and 1/ε for fixed codomain; their paper explicitly describes homomorphisms as a code and gives a self-corrector. Thus generator-image reconstruction, local correction, and property testing together do not beat the strongest specialized baseline. On G=(Z2)^d→Z2, d basis queries match the information lower bound exactly, so there is no query-count improvement to claim.

The exact obstruction to a generic compositional claim is concrete. A one-node program can be an arbitrary lookup table h:X→{0,1}; writing h as id∘h changes no information. More specifically, among binary DFAs, consider the 2^L singleton languages {w}, one for each binary word w of length L, plus the empty language. Each singleton is recognized by a DFA with L+2 states. A membership query on a length-L word can distinguish at most that one singleton from the empty target; queries of other lengths distinguish none. If the target is empty, exact identification needs all 2^L such queries. Dana Angluin's 1981 query-complexity paper independently states that with only an n-state bound, regular-language query upper and lower bounds are exponential in n; a set of access strings reaching every live state changes the bound to polynomial. This shows the key resource is an identifying access structure, not program size or compositional syntax.

Positive interface boundary tested

I also formalized the strongest useful introspection interface I found: a deterministic finite-state program exposes reset() and cloneable step(snapshot, symbol)→(new_snapshot, output), where snapshots are exact canonical state values. If at most N states are reachable and the input alphabet is Σ, breadth-first exploration queries each reachable state/symbol pair once, in at most N|Σ| calls. By induction on input length, the resulting transition table exactly simulates the target on every future word. The representation stores each transition once, so it can be reused in arbitrarily many input compositions.

This is a valid positive result only for the declared interface. It exposes internal state identities, which can contain substantial information. With B-bit snapshots and c-bit outputs, the transcript carries up to N|Σ|(B+c) bits, plus query inputs and reset cost; state identity is not free. In `snapshot_bfs.py`, a four-state, binary-input Mealy machine is reconstructed in 8 calls. The returned snapshots are serialized as 8-bit bytes, so the actual snapshot/output payload is 72 bits (the ideal 2-bit state ID plus 1-bit output would be 24 bits). An internal exhaustive check compared 511 words of length at most 8 against the demo target; this validates the script only, not any external system. With this same interface, the strongest baseline is the same breadth-first transition extraction followed by ordinary DFA/Mealy minimization. There is no algorithmic advantage over that baseline, and without snapshots the singleton-DFA lower bound returns. This is not a landmark result.

Strongest falsifier and unresolved gap

The strongest falsifier of the initial algebraic path is the matched class-aware baseline: the candidate's best example already meets its information-theoretic lower bound, while its noisy extension is covered by local decoding and homomorphism testing. The strongest falsifier of the snapshot path is interface cost: state snapshots are the additional feedback that makes the exact learner possible. No endpoint-only method has been supplied that discovers an equally useful state/generator cover with polynomial cost on a broad class of compositional programs.

Actual result: two exact interface-boundary theorems, not the requested foundational capability. I found no new algorithm that autonomously discovers a compact, reusable semantic basis from endpoint feedback alone. The central open target is to identify a natural, non-oracular interface and a broad class where a learner can construct its own accessible contexts/state cover, achieve a provable gain over the best class-aware baseline, and account for every observation and validation cost. Until such a mechanism is produced, status remains OPEN.

Primary sources checked after freezing

- Dana Angluin, “A note on the number of queries needed to identify regular languages,” Information and Control 51(1), 76–87 (1981), DOI: https://doi.org/10.1016/S0019-9958(81)90090-5 . The abstract states exponential query bounds from a state-count bound alone and polynomial bounds given access strings reaching live states.
- Dana Angluin, “Learning regular sets from queries and counterexamples,” Information and Computation 75(2), 87–106 (1987), DOI: https://doi.org/10.1016/0890-5401(87)90052-6 . The L* result uses membership plus conjecture/equivalence queries with counterexamples, precisely the extra teacher feedback excluded here.
- Michael Ben-Or, Don Coppersmith, Mike Luby, and Ronitt Rubinfeld, “Non-Abelian homomorphism testing, and distributions close to their self-convolutions,” Random Structures & Algorithms 32(1), 49–70 (2008), DOI: https://doi.org/10.1002/rsa.20182 . The paper proves the random-pair group-law tester for general finite groups and O(1/ε) testing.
- Elena Grigorescu, Swastik Kopparty, and Madhu Sudan, “Local Decoding and Testing for Homomorphisms,” APPROX/RANDOM 2006, DOI: https://doi.org/10.1007/11830924_35 . The paper develops local list decoding and self-correction for homomorphism codes.
- Esty Kelman, Uri Meir, Debanuj Nayak, and Sofya Raskhodnikova, “Homomorphism Testing with Resilience to Online Manipulations,” APPROX/RANDOM 2026, DOI: https://doi.org/10.4230/LIPIcs.APPROX/RANDOM.2026.58 . This current result addresses online-corrupted query responses with O(1/ε+log t) queries; it reinforces that robust algebraic testing is an established active line, not a novel result here.

FIRST DERIVATION (frozen before literature search)
Date: 2026-10-10

Candidate target
Build the least-energy-state passive one-port satisfying a finite set of measured or specified input-output constraints, with a certificate that no lower-state passive device can satisfy the same tolerance box. The full transfer function is not input. Input consists only of sample locations, measured/specification intervals, and admissible device class (stable scalar positive-real rational one-ports).

Representation
For left nodes mu_j and right nodes lambda_k, form the Loewner divided-difference matrix

    L[j,k] = (y(mu_j) - y(lambda_k)) / (mu_j - lambda_k).

For any scalar realization G(s)=D+C(sI-A)^(-1)B with n internal dynamic states, the resolvent identity factors each entry as a row depending on mu_j times a column depending on lambda_k. Therefore rank(L) <= n. This is an architecture-independent lower bound: it applies to every n-state linear device matching those samples, hence also to every passive device.

With interval data y_i in [y_i^- , y_i^+], take centers y_i^0 and radii eps_i. Let L0 be the center Loewner matrix. Every compatible L obeys

    ||L-L0||_2 <= ||L-L0||_F <= delta,
    delta^2 = sum_{j,k} ((eps_mu_j+eps_lambda_k)/|mu_j-lambda_k|)^2.

Weyl's inequality then gives rank(L) >= d+1 whenever sigma_{d+1}(L0)>delta. If an explicit passive d-state realization lands inside all intervals, the minimum state count is exactly d. This is a tolerance-robust optimality certificate; it does not require assuming a complete target transfer operator.

Concrete one-state candidate
Take the desired impedance h(s)=1+1/(s+1) ohm, realized by a 1-ohm series resistor and a parallel 1-ohm resistor / 1-farad capacitor. It is positive real and has one dynamic state. Specify only four positive-real Laplace samples:

    s = 1, 2, 3, 4;    h(s) = 3/2, 4/3, 5/4, 6/5 ohm.

Split left nodes mu=(1,2) and right nodes lambda=(3,4). Then

    L0[j,k] = -1/((mu_j+1)(lambda_k+1)),

which has exact rank one. More importantly, the two endpoint centers differ by 3/10 ohm. If each of the four sample tolerances is eps<3/20 ohm, no constant impedance can lie in every interval, so zero-state devices are impossible. The explicit one-state R-RC realization matches every center, proving exact optimum one dynamic state inside the tolerance box. The sample tests are decaying exponential currents/voltages (s=1,2,3,4 in normalized inverse-time units), not sinusoidal frequency-response samples.

Why it may matter
The finite sample vector can certify both a state-count lower bound and a constructive upper bound while leaving the transfer function unspecified. In larger problems, a singular-value gap in L0 versus the uncertainty bound would certify a minimum state count d; a rank-d Loewner realization that passes an exact positive-real/KYP certificate would give the passive upper bound. Standard passive realization / network synthesis could then compile the model to an RLC one-port.

Known weak points before literature check
1. Loewner realization and passive network synthesis may already cover essentially all of this; if so the representation is not a foundational novelty.
2. Finite samples do not generally identify a unique device. Optimality is only for dynamic state count in the declared rational one-port class, not component count, topology, robustness outside the samples, or global material/device design.
3. Sampled exact rank is fragile. The interval perturbation bound fixes this only when the singular-value gap exceeds the propagated measurement error. The small example uses the simpler endpoint spread certificate.
4. The sample locations s>0 are Laplace points, not ordinary sinusoidal frequencies. Translating a frequency-band design specification into this interface without supplying a full transfer target remains open.
5. Ideal lumped RLC synthesis ignores parasitics, component quantization, size, power, and bandwidth. These must be charged or constrained for a manufacturable claim.

Status at freeze: a useful exact construction/certificate for one-port state order, not yet evidence of a new general inverse-design capability.

COORDINATOR: FINITE PHASE-CYCLING QUERY INTERFACE (PROPOSED BOUNDS)

Oscillator model q''+gamma q'+Kq+diag(alpha)q^3=e1 u, m I<=K<=M I,
0<alpha_i<=a, gamma<=sqrt(m). The stable linear Green operator has a crude
sup norm gain G<=4/(gamma sqrt(m)). For sufficiently small input amplitude,
a contraction on bounded quasiperiodic trajectories gives an expansion
q=A q1+A^3 q3+O(a^2 G^7 A^5), for a sum of three unit-amplitude cosines.
Constants and transient convergence require verification in the final proof.

Run 64 phase settings theta_j in {0,pi/2,pi,3pi/2}^3. Each input is
A[cos(omega1 t+theta1)+cos(omega2 t+theta2)+cos(omega3 t+theta3)].
At a common settled time T, multiply the scalar output by
exp[-i(theta1-theta2+theta3)] exp[-i(omega1-omega2+omega3)T] and average.
The character excludes every linear term. At degree3, the only surviving
phase multi-index is (1,-1,1): every tone must occur at least once. Its
coefficient is (3/4) A^3 H3(i omega1,-i omega2,i omega3).
Fifth and higher orders create bounded bias after division O(a^2 G^7 A^2).
This phase average does not require distinct temporal combination frequencies
or infinite-time Fourier isolation. Degenerate input tones do not invalidate
the phase algebra because the three source phase controls remain separate.

Independent scalar Gaussian readout noise of variance sigma^2 per phase
snapshot contributes variance of at most sigma^2/(36 A^6 N) to a cubic
coefficient after N independent repetitions of each phase setting (the exact
quadrature factor depends on complex-error convention). Reset, settling,
measurement bandwidth, repetitions and calibration must all be charged.
A finite experiment never provides an exact frequency-response oracle.

The first high-opposite-frequency approach is impractical in the measured
regime because recovering a hidden matrix multiplies errors by Omega^8.
The later dual-frequency/residue approach seeks the same identifiable matrix
as a linear functional of moderate resonant H3 samples. Root's executable
matrix test is supplied-spectrum/supplied-kernel only; physical acquisition
and matched algorithmic advantage are still open. Do not label it end-to-end.

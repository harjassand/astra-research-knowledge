POST-FREEZE EXACT SMOOTH ODE FALSIFIER

This is a later addition to the separately preserved first derivation.

Let r be a phase on R/Z and define the C-infinity periodic function

  chi(r) = exp(-0.01*((r-1/2)^(-2) + (1-r)^(-2)))  for 1/2 < r < 1,
           0                                           for 0 <= r <= 1/2,

extended periodically. Flatness of exp(-a/u^2) at u=0 makes both joins smooth.
On [5/8,7/8], the exponent is at most 32/45, so

  kappa := integral_0^1 chi(r) dr >= exp(-32/45)/4 > 0.122.

For a requested horizon T and any epsilon>0, consider two smooth systems
with state (r,theta,x), r and theta on R/Z:

  dr/dt = 1/T,
  dtheta/dt = 1/epsilon,
  dx/dt = sigma*chi(r)*(1 + (1/2)cos(2*pi*theta)),

where sigma is either 0 or 1 and the initial state is (0,0,0). Request the
observable O_T=x(T)/T. The two full-state trajectories are identical for
every t<=T/2, since chi(r(t))=0 there. But O_T=0 for sigma=0, whereas

  O_T = integral_0^1 chi(r)*(1+(1/2)cos(2*pi*T*r/epsilon)) dr
       >= kappa/2 >= exp(-32/45)/8 > 0.061

for sigma=1. Thus any trajectory-only predictor whose entire transcript
ends before T/2 has the same data on both systems. Its worst-case absolute
error is at least half the output gap, > exp(-32/45)/16 > 0.030. For fixed
step simulation that resolves theta and the oscillatory x velocity, target
work is O(T/epsilon); any prefix shorter than T/2 costs at least a fixed
fraction of that work. A sublinear-in-T prefix cannot certify the requested
output uniformly over this class.

The hidden variable r is a slow clock omitted from the requested observable;
the vector fields are smooth and contain a fast scale epsilon. This is a
black-box acquisition theorem, not a lower bound when the vector-field source
is supplied and can be inspected, nor for a family promised to have no slow
hidden modes. It makes the required limitation constructive rather than
statistical: without a closure/gap promise, a smooth nonlinear simulator can
hide a new observable response beyond every sampled prefix.

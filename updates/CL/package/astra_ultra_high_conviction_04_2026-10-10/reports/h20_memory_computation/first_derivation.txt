Candidate mechanism: goal-conditioned observable closure.

Interface. Let S be a finite hidden state space of size n. For each controllable action a and emitted observation o, the known nonnegative rational matrix T_(a,o) has entries P(s',o | s,a); rows are indexed by current state, columns by next state. Let r_1,...,r_k in Q^n be terminal payoff vectors (add stage-payoff vectors to the generator set for accumulated reward). A current unnormalized belief is a row vector x. A history h updates it to x T_h. The compiler is supplied these matrices and the goal vectors; this is a strong model-supply assumption, not a learned-model result.

Let V be the least linear subspace of Q^n containing 1,r_1,...,r_k and invariant under every T_(a,o). Compute it by repeatedly adding T_(a,o)v for each current basis vector v until the span stops growing. Let B (n by q) be a basis and find K_(a,o) (q by q) such that T_(a,o) B = B K_(a,o). Also write 1=B gamma and r_j=B beta_j. Store z=xB. On observing (a,o), update z <- z K_(a,o); if a normalized posterior is wanted, divide by z K_(a,o) gamma. The payoff prediction is z beta_j. Thus the hidden-state vector x is never retained.

Exact claim. Every continuation consisting of actions/observations and a terminal payoff has a state payoff vector in V. Every finite contingent policy tree has a payoff vector in V too, since a tree node with action a and observation-indexed subtrees has vector sum_o T_(a,o)v_o, and V is closed under every T_(a,o). Therefore z determines the exact expected payoff of every such policy from x, and a finite-horizon optimal policy can be evaluated using q coordinates. For infinite horizon, the same closure covers all finite continuations; convergence/optimality of an infinite-horizon Bellman solution is an additional assumption.

Minimality claim (restricted interface). Suppose a d-coordinate linear memory is z=xD and every continuation payoff x v is recovered by a fixed linear readout from z, for all x in an open subset of the belief simplex. Then each v lies in col(D), so d is at least dim span{v}; otherwise a nonzero direction in the kernel of D would change some required payoff while leaving z fixed. Hence q is minimal among linear exact predictive memories for this continuation family. This is not a lower bound against arbitrary nonlinear encodings or task-specific code that reads raw observations directly.

Resource interface. Matrix input/model acquisition is supplied and must be charged as O(|A||O| n^2) rational entries/bits. Closure preprocessing is exact rational linear algebra, with O(nq) basis storage and at most n dimension increases; a straightforward implementation scans all symbols and basis vectors at every increase. The compiled update tables cost O(|A||O| q^2) rationals; runtime stores q numbers and updates in O(q^2) arithmetic operations per symbol. With rational inputs, exact coordinate bit length can grow with history length. No horizon-independent finite-bit guarantee follows. A p-bit rounded implementation and accumulated decision loss are unresolved here; claiming a finite-memory hardware win without that analysis would be invalid.

Predicted discriminator. Add a product nuisance component w with a very large, independently evolving observation process, while the controlled reward/observation component z evolves independently and the initial belief factors as p_z tensor p_w. The task-optimal policy needs only p_z: nuisance observations are independent of z and can only act as private randomization, which cannot improve expected reward. A general exact predictor for the full nuisance stream may require a much larger state. If initial z,w are correlated, nuisance observations can reveal z and the reduction fails; the compiler must check/supply the factorization contract. This would separate task value memory from general prediction memory, but it may only formalize known state abstraction / observable-operator ideas.

Strongest anticipated falsifier. Find a policy tree whose payoff vector leaves V, or a pair of histories with equal z but different continuation values; either invalidates the closure/update claim. For the product discriminator, a correlated initial belief is an explicit failure mode. The unresolved high-value gap is efficient acquisition of the reward-closed subspace and a precision/error theorem under finite bits. OPEN: no novelty or practical advantage asserted yet.

MISSION: COMPUTATIONAL MEMORY / REPRESENTATION
Status: OPEN; no new foundational mechanism established. The frozen candidate is a direct rediscovery of value-directed compression of POMDP beliefs. Do not promote it as novel.

Exact foundational target
Find an acquired, finite-resource memory representation that preserves the action-relevant long-horizon behavior of a hidden process while costing less than a general predictive state. The relevant interface must say when the task is known, what the agent observes, whether the hidden model is supplied or learned, how the memory updates, what precision it uses, and which future decisions it must support.

Frozen first derivation
The initial candidate was the reward-closed observable subspace: for hidden-state update matrices T_(a,o) and reward vectors r_j, maintain z=xB where B spans the smallest subspace containing {1,r_j} and invariant under all T_(a,o). Then T_(a,o)B=BK_(a,o), so z updates linearly and determines every finite policy-tree payoff. Within linear exact representations this dimension is minimal for the continuation vectors included. The full frozen derivation, made before literature search, is in reports/h20_memory_computation/first_derivation.txt.

Prior art comparison and strongest baseline
The candidate's central theorem is already in Poupart and Boutilier, “Value-Directed Compression of POMDPs” (NeurIPS 2002). They characterize lossless linear compression by a reward-containing invariant subspace under every action-observation update and give Krylov iteration to obtain its smallest basis. This is a direct match, including the stated mechanism and proof idea; adding a constant vector for normalized posterior probabilities does not create a new contribution. Their later VDCBPI paper repeats the characterization and discusses compact structured representations. See:
- https://proceedings.neurips.cc/paper_files/paper/2002/file/14ea0d5b0cf49525d1866cb1e95ada5d-Paper.pdf
- https://proceedings.neurips.cc/paper/2004/hash/81c2f886f91e18fe16d6f4e865877cb-Abstract.html

The relevant lines in the 2004 paper say that exact compression requires the reward vector to lie in the range of F and T_(a,o)F to lie in that range; the smallest such range is the Krylov subspace generated from reward vectors (sections 4 and equations 3–4). It also warns that compressed vectors still have the original state-space size unless factored structure is exploited. This makes known-model acquisition and compact basis construction the remaining barriers, not the subspace identity.

Other strong baselines:
- Predictive state representations / observable operator models store predictions of future observable tests. Singh, James, and Rudary’s UAI 2004 paper introduces linear dimension through the system-dynamics matrix: https://web.eecs.umich.edu/~baveja/Papers/uai2004psr.pdf. This is a task-general prediction representation, with a different target than reward-only compression.
- A vanilla PSR need not preserve rewards. Baisero and Amato prove an exact condition for when PSR coordinates can represent POMDP rewards and define reward-predictive PSRs that model both observations and rewards for every finite POMDP: https://arxiv.org/abs/2106.03926. That is a stronger predictive baseline than a reward-only Krylov sketch when control decisions must account for hidden future observations.
- Successor features reuse a supplied linear reward-feature basis across tasks (Barreto et al., NeurIPS 2017): https://papers.nips.cc/paper/6994-successor-features-for-transfer-in-reinforcement-learning.pdf. Successor Feature Sets extend the representation to multiple latent states, policies, and rewards, with exact computation in small known environments (Brantley, Mehri, Gordon, AAAI 2021): https://ojs.aaai.org/index.php/AAAI/article/view/17399. Neither establishes discovery of the useful feature basis from raw observations at low cost.
- Spectral PSR/HMM methods factor a Hankel-like moment matrix; Hsu, Kakade, and Zhang give a provably correct SVD-based HMM learner under separation conditions: https://arxiv.org/abs/0811.4413. This is a credible model-acquisition route under rank and conditioning assumptions, but it targets predictive dynamics. Reward-aware prediction still needs the R-PSR or an equivalent objective-aware construction. Randomized low-rank/sketch approximations can reduce numerical work only when the relevant subspace is well conditioned; they do not bypass the exact delayed-query lower bound below.
- For a fixed stream objective, the strongest small-memory competitor is a minimal finite-state monitor (Myhill–Nerode residual automaton). This can be far smaller than a source predictor. Its guarantee is scoped to the supplied objective and input alphabet.

Actual mathematics and discriminating example
A binary de Bruijn cycle of order m has N=2^m phases and each phase has a unique next-m-bit output window. Therefore any exact predictor that must name the next m outputs from every phase needs N distinct memory states, i.e. m bits. If the fixed task is instead to return the parity of the observed stream at an end marker, a two-state monitor suffices: q <- q XOR b on each emitted bit, then output q. The two states are necessary because they disagree on the empty continuation. Thus task memory can be much smaller than prediction memory when the task is known before the stream and is computable incrementally.

The executable check in reports/h20_memory_computation/check_debruijn.py generates cycles for m=1,...,8 and verifies all N cyclic windows are distinct. All checks passed; output is in check_debruijn.out. This only checks the finite instances and illustrates a standard automata separation; it is not an empirical capability result or novelty evidence.

A sharper interface theorem for delayed goals: let an N-bit vector x stream past once. If a parity query q·x over F_2 is known before the stream, one accumulator bit is sufficient. If q is disclosed only after the stream and can be any vector in a family Q, two inputs x,x' may share memory only if q·x=q·x' for every q in Q. If r=dim(span Q), the memory must distinguish 2^r cosets, so at least r bits are necessary; r running parities of a basis of span Q suffice. For arbitrary delayed q, r=N and the lower bound is N bits. Proof is exact: any difference d=x XOR x' outside span(Q)^perp has a q in Q with q·d=1. This is the cleanest counterexample to claims that a tiny fixed-goal monitor can retain arbitrary future retargetability. It is standard linear-sketch / one-way communication structure, not a new theorem.

Resource interface and limits
For the POMDP closure candidate, model matrices and goal rewards were supplied. A dense rational interface costs Θ(|A||O| n^2) entries before compilation; Krylov closure performs up to n dimension increases and scans action-observation operators against the current basis. It stores an n-by-q basis and |A||O| q-by-q update tables. At runtime it stores q exact coordinates and performs q-dimensional updates. Exact rational bit length can grow with stream length. No finite-bit, horizon-independent error bound was derived. The model/acquisition cost and numeric precision are not discharged by lowering q.

For the fixed parity stream, the data arrive one bit per step, the objective machine is supplied, rolling memory is one bit, and update time is O(1) per bit. An arbitrary explicit q costs N bits to specify unless its bits are streamed in alignment with x or q has a compact program; that specification cost is separate and must be charged. If the goal arrives afterward, a query basis must be stored or the entire stream retained; the exact working space rises to rank(span Q), and the query-family description cost is additional. Hidden state is absent from the lower-bound example, so partial observability cannot make that bound easier. For the de Bruijn source predictor, the generator/phase acquisition cost must also be charged; the example only compares the required online state once the source contract is given.

Strongest falsifiers and why this does not clear the mission
1. Direct prior art destroys novelty of the invariant-subspace mechanism.
2. If the task is not fixed before observations, the delayed-parity theorem forces memory to grow with the rank of the future query family.
3. If action choices can depend on observations that correlate with nuisance variables, simply dropping a nuisance predictive state is invalid; exact task closure can expand back to the full state dimension.
4. When the source model is unknown, the mechanism assumes away representation acquisition. Spectral learners and automata-learning algorithms supply partial routes only under their own reset, rank, observability, or query assumptions. I did not establish an acquisition algorithm that discovers a small task residual directly from raw interaction while meeting the full cost interface.
5. Finite precision and value-loss bounds for long histories remain open here; rational coordinates can grow with horizon, and rare observations can make normalized belief updates ill-conditioned.

The mechanism therefore does not engage the decisive obstacle in this campaign: acquiring the right task representation and its update law at lower total cost than simply storing or learning the relevant hidden state. The credible next gate, if this area is continued, is an acquisition theorem for an unknown controlled process with a goal family declared on a specified schedule, plus a finite-bit value-error bound. Without that, this direction should be parked as a literature rediscovery and scoped interface lesson, not a foundational result.

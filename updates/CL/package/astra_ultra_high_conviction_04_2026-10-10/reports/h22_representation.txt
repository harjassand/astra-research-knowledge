H22 — representation mission
Date: 2026-10-10
Status: OPEN; exact derivation frozen before primary-source comparison below.

Mission target
Find a representation in which exact future behavior can be stored and composed without naming the system's raw hidden states, and determine whether that removes a genuine capability barrier or only a storage barrier.

FROZEN ORIGINAL DERIVATION (before literature search)

Let a deterministic, total, input/output machine be M=(Q,Σ,Y,δ,λ,q0), with finite Q, Σ, Y; δ:Q×Σ→Q and λ:Q×Σ→Y. For a history u∈Σ*, let q_u=δ*(q0,u). Define the continuation response R_u:Σ*→Y* by running the machine from q_u on a suffix w and returning the output word of length |w|. Define u≈v exactly when R_u=R_v.

The proposed state representation is the residual r_u=R_u itself. It is the exact task-relevant future, rather than a coordinate vector for the physical hidden state.

Lemma (minimal continuation representation). The set of reachable ≈-classes is a deterministic machine that reproduces every input/output trace. Every exact representation φ of histories with a decoder D satisfying D(φ(u),w)=R_u(w) for every u,w must assign different codes to histories in different ≈-classes. Hence the number of reachable residuals is the minimum cardinality of any exact future-response representation.

Proof. If [u]=[v], then R_u=R_v. For each symbol a, the first output on a agrees, and the residuals after reading a agree because R_{ua}(w) is the tail of R_u(aw); thus output and transition are well-defined on classes. Starting at [ε] therefore reproduces all traces. Conversely, if φ(u)=φ(v), decoder correctness gives R_u(w)=D(φ(u),w)=D(φ(v),w)=R_v(w) for every w, so u≈v. □

This is a representation theorem only. It does not say the residual can be inferred cheaply from observations. A raw state count can be a false storage barrier: a clean all-states-reachable construction is supplied in the post-freeze audit below.

Hard acquisition test. Let the unknown target be either f_0(x)=0 for every x∈{0,1}^m or f_z(x)=1[x=z] for an unknown z∈{0,1}^m. Under T iid uniform labeled examples, the transcript under f_0 is all-zero. Under a uniformly random z, the transcript differs from that only if a sampled x equals z, an event of probability 1−(1−2^(−m))^T≤T/2^m. Thus the total variation distance between these transcript laws is at most T/2^m, and any test distinguishing the two cases with equal prior has error at least (1−T/2^m)/2. Yet each f_z has a short description (store z and compare). Therefore a compact representation alone cannot unlock discovery under passive coverage-poor access; acquisition/interface is a separate barrier. Under adaptive exact membership queries with promised singleton-vs-zero targets, a worst-case lower bound is 2^m−1 queries before the final unqueried point can be inferred; random-z average identification needs 2^(m−1) queries.

Initial assessment before sources: likely standard residual/minimal-automaton mathematics. Possible leverage is a disciplined replacement of raw hidden-state counting by a continuation signature, coupled to a sharp acquisition lower bound. No novel primitive or 8+/10 capability is established yet. The concrete claim that survives this freeze is only the theorem above and the passive hard test. A fully reachable example and a different target with stronger leverage are outstanding.

POST-FREEZE CONSTRUCTION REPAIR AND FINITE CHECK

For n≥1, let Q={0,1}^n, q0=0^n, output λ(x,a)=|x| for every action a, and actions consist of inc, dec, and adjacent swaps s_i for 1≤i<n. inc changes the first zero bit to one and is identity at 1^n; dec changes the first one bit to zero and is identity at 0^n; s_i swaps coordinates i and i+1. From 0^n, inc^k reaches 1^k0^(n-k), and adjacent swaps can move the k ones to any k-subset, so every one of 2^n states is reachable. Every action either preserves weight or changes it by exactly +1 / −1 according only to current weight. Induction on suffix length shows equal-weight states have identical future output words. Different weights are distinguished by any one-symbol suffix because λ emits the current weight. Thus this single machine has exactly n+1 reachable residuals among 2^n reachable raw states.

The script check_residuals.py in the companion directory constructs this machine, exhaustively checks reachability, and computes the Mealy output-respecting partition by iterative refinement for n=1,...,8. It verifies exactly 2^n reachable configurations and n+1 behavior classes for every tested n. This check supports the construction; the proof above covers all n.

Scope correction for the acquisition test: the singleton family gives a lower bound for exact identification / exact all-input behavior under the stated interface. It does not give a constant-error PAC lower bound under the uniform input distribution, because the all-zero hypothesis has error only 2^(−m) on every singleton target. The precise passive testing statement is between the zero target and a uniformly random singleton target: transcript distributions have total variation 1−(1−2^(−m))^T, so equal-prior Bayes error is exactly (1−2^(−m))^T/2. For exact identification under a singleton-only promise, a deterministic membership-query learner needs N−1 queries in the worst case and Θ(N) queries on average for uniform z (the exact fixed-order count is (N−1)(N+2)/(2N) if it stops after N−1 negatives). If the target family also includes f_0 and exact identification of that possibility is required, the worst case is N queries. These are exact-target interface costs, not approximate prediction costs.

Resource interface for the finite-state example: the constructed machine has 2^n reachable configurations, n+1 residuals, and n+1 action symbols. Its explicit transition table costs Θ(n²2^n) bits up to encoding conventions; the quotient itself has n+1 states, and the generative construction can be specified using O(n log n) bits (n plus the named action rules). The quotient theorem does not provide an algorithm that compresses an arbitrary explicit table without inspecting it; standard partition refinement reads the supplied table. For the singleton family, the query input is m bits and the label is one bit; one passive sample costs m+1 bits, while exact membership querying a chosen point still costs m input bits. The lower bound counts queries, and omits local computation, which is immaterial to the exponential query separation here.

PRIMARY-SOURCE COMPARISON (performed only after frozen section)

The lemma is Moore's 1956 sequential-machine indistinguishability / reduced-form theorem, and equivalently the Myhill-Nerode residual construction extended from acceptance to complete output traces. Moore defines two states as indistinguishable when every input experiment yields the same outcome and proves that the reduced form is minimal; he also proves that a shortest state-distinguishing experiment has length at most n−1. Source: https://www.cs.cmu.edu/~cdm/resources/Moore1956-gedanken-experiments.pdf, pp. 136–143. Myhill's 1957 report is the foundational language result (J. Myhill, “Finite Automata and the Representation of Events,” WADD TR 57-624, pp. 112–137). The supplied theorem adds no new primitive.

The strongest constructive baseline for learning is Angluin's L* result: with membership queries plus equivalence queries that return a counterexample, it identifies the minimum DFA in time polynomial in the minimum state count and longest counterexample length. Her paper explicitly notes that equivalence queries require a precise target representation and a way to test equivalence; a stochastic variant permits sample-based approximate identification, not exact identification of all future behavior. Source: https://homepages.math.uic.edu/~lreyzin/papers/angluin87.pdf, especially abstract, pp. 87–90 and Theorem 6, pp. 96–97.

Later active-automata work continues to quantify the teacher-query burden: Kruger, Garhewal, and Vaandrager (ICGI 2023) establish worst-case equivalence/output-query lower bounds for L# and bounded-lookahead variants. Source: https://proceedings.mlr.press/v217/kruger23a.html. Thus the residual representation and the distinction between model size and oracle access are both established territory.

Strongest falsifier of mission-level leverage: no representation-only argument defeats the singleton test. A short representation may still need a high-cost informative query to identify its hidden parameter. Conversely, if the required goal is approximate prediction under a benign distribution, an exact residual quotient may be unnecessarily fine and this singleton family is easy. The candidate therefore fixes a storage/description barrier but does not unlock autonomous acquisition, goal achievement, or a broad new capability. Status: OPEN; mission threshold not met. A credible continuation would need a new cost-sensitive, task-indexed predictive representation with an acquisition theorem under a declared interface, and a matched lower bound showing genuine improvement over standard active automata learning / PAC state aggregation. No such theorem was obtained here.

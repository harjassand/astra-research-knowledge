# DB — Zero private activation beyond antidegradability

This intake preserves one five-page mathematical note as a coherent package; it is not split into frontier cards. The [package README](package/zero_private_activation/README.md) routes the original PDF and a marked, non-authoritative text extraction.

The note presents a two-qubit Pauli-channel family that is transpose-antidegradable for all mixture parameters, has a complete signed-lift comparison from its complement for `q >= 1/10`, and is antidegradable exactly at `q >= (3 - sqrt(5))/5`. In the interval between those thresholds, it claims a counterexample to an antidegradable-helper activation implication. These are source-reported claims, not independently verified by this intake.

No external correctness review or exhaustive historical-priority assessment is claimed. The note itself says the complete-order threshold below `1/10` is undetermined and that the signed-lift criterion is used only as a sufficient condition. See the package for further boundaries and provenance.

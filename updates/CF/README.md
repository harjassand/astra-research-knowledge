# CF — Deterministic propagation through coalescing multichannel crossings

Two result cards preserve their different evidence levels:

- [N578](../../frontier/dossiers/N578.txt): a source-reported deterministic bit-complexity theorem candidate for the full endpoint propagator of an explicitly supplied rational Hermitian matrix polynomial. The source reports one focused internal end-to-end check after specified repairs. External correctness and priority remain open; a uniformly terminating certified implementation and practical speedup are not established.
- [N579](../../frontier/dossiers/N579.txt): four source-reported exact residual certificates for bounded members of a three-channel coalescence family. The intake did not rerun them. The examples do not verify the general theorem or establish broad speed superiority: the source reports CF4 faster on modest cases, a censored B=8 baseline row, and no comparison against the unavailable phase-function solver.

The original v1 proof, exploratory proposals, benchmark specification, exact witnesses, controls, costs and censored/negative rows remain source data.

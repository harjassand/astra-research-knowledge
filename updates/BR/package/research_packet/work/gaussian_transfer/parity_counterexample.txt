PARITY-CORRECTED LOCAL NORMAL AUDIT
Scope: S=2X+Y, independent X~Pois(mu), Y~Pois(nu), 2mu+nu=n,
integer n>=1, 0<=nu<=n. No frozen product code was edited.

Let
 p_n = Pr(S=n),
 q_n = [1+(-1)^n exp(-2nu)] / sqrt(2pi(2n-nu)).
The formula q_n is an approximation, not an exact probability or enclosure.

1. EXACT COEFFICIENT AND ODD SMALL-DISPLACEMENT LIMIT

 p_n = exp[-(n+nu)/2] sum_{y=0..n; y=n mod 2}
       ((n-nu)/2)^((n-y)/2) nu^y / [((n-y)/2)! y!].

For odd n=2m+1, put z=n/2. As nu decreases to zero,
 p_n = nu exp(-z) z^m/m! [1+(-1+1/(2n))nu+O_n(nu^2)],
 q_n = nu/sqrt(pi n) [1+(-1+1/(4n))nu+O_n(nu^2)].
Thus
 p_n/q_n = R_n [1+nu/(4n)+O_n(nu^2)],
 R_n = sqrt(pi n) exp(-n/2)(n/2)^((n-1)/2)/Gamma((n+1)/2).
Stirling's shifted expansion gives
 log R_n = 1/(12n)-7/(360n^3)+O(n^-5),
 R_n = 1+1/(12n)+1/(288n^2)+O(n^-3).

This disproves any claim that q has arbitrarily small relative error merely
because nu is small with fixed n. It DOES NOT exhibit a divergent relative
error as nu->0: cancellation is correctly captured at first order.
Examples of R_n-1: n=1: .0750476034999202; n=3: .0275077350271946;
n=101: .0008254040966201. Here relative defect is measured against q.
At nu=0 exactly and odd n both probabilities are zero, so relative error
is undefined; the limiting ratio above is the relevant statement.

2. SIMPLE EXACT NUMERICAL COUNTEREXAMPLE TO HIGH ACCURACY

Take n=1, nu=1/2, mu=1/4. Only Y=1, X=0 can give S=1, so
 p_1 = exp(-3/4)/2 = .23618327637050734,
 q_1 = (1-exp(-1))/sqrt(3pi) = .20590379524607383.
Then
 p_1/q_1 = 1.147056449776687,
 (q_1-p_1)/p_1 = -.12820332408689786.
So q underestimates the true probability by 12.8203%.
This is an exact symbolic counterexample; decimal values are illustrative.

3. TWO-SADDLE FIRST CORRECTION (FIXED nu, n->infinity)

Fourier inversion is
 p_n=(2pi)^-1 int[-pi,pi] exp[(n-nu)/2(e^(2it)-1)
                                  +nu(e^(it)-1)-int] dt.
Near t=0 the mean is matched, variance V=2n-nu,
third cumulant 4n-3nu, fourth cumulant 8n-7nu. The ordinary first
Edgeworth correction is
 k4/(8V^2)-5 k3^2/(24V^3)=-1/(6n)+O_nu(n^-2).
Near t=pi write t=pi+s. The prefactor is (-1)^n exp(-2nu).
The remaining signed-Poisson exponent has mean n-2nu, variance 2n-3nu,
and third cumulant 4n-5nu, while the target remains n. To order 1/n,
relative to the common prefactor (2pi V)^-1/2:
 - variance-prefactor change: +nu/(2n),
 - Gaussian displacement by 2nu: -nu^2/n,
 - skewness times displacement: -nu/n,
 - zero-displacement Edgeworth correction: -1/(6n).
Their sum is -(1/6+nu/2+nu^2)/n. Therefore, for fixed nu>0,

 p_n = (2pi V)^-1/2 {
       1+epsilon exp(-2nu)
       -[1/6+epsilon exp(-2nu)(1/6+nu/2+nu^2)]/n
       +O_nu(n^-2)},       epsilon=(-1)^n.

 p_n/q_n = 1 + C_epsilon(nu)/n + O_nu(n^-2),
 C_epsilon(nu) = -1/6 - epsilon(nu/2+nu^2)/(exp(2nu)+epsilon).

For odd n:
 C_-(nu)=-1/6+(nu/2+nu^2)/(exp(2nu)-1)
       =1/12+nu/4-5nu^2/12+O(nu^3).
For even n:
 C_+(nu)=-1/6-(nu/2+nu^2)/(exp(2nu)+1).
This agrees with the separate exact nu->0 calculation.

The fixed-nu asymptotics have not been promoted to a UNIFORM remainder
bound in this note. In particular, bounding each saddle separately by an
absolute O(n^-2) remainder and subtracting them in the odd case only
proves a relative O(n^-2/nu) remainder; that is a proof defect, not a
counterexample, because the exact probability has a removable linear
zero. A uniform proof must preserve this common zero analytically.
The formula alone cannot support high-precision acceptance decisions.

4. NEGATIVE FINDING AND USEFUL DIRECTION

No divergent relative-error counterexample to the parity-corrected normal
approximation was found. The small-nu odd obstruction is to naive error
accounting, not evidently to a uniform relative O(1/n) theorem. An approach
that factors out nu for odd n (or factors the exact parity probability)
before interval/saddle approximation is a plausible way to avoid numerical
subtraction of nearly equal masses. Proving a uniform O(1/n) bound, including
nu comparable to n and the Poisson endpoint, remains a separate task.

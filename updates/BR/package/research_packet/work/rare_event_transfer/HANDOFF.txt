Decisive result
Exact all-box second-moment verification is coNP-complete even with P=q,
B_i=1 and all verified continuation intervals equal [t/(t+1),1] for any
fixed integer t>=2. Thus arbitrarily small fixed uncertainty does not make
exact verification polynomial unless P=NP. The proof is a PARTITION
reduction with a modular extra weight. It is weak hardness; no FPTAS or
approximation hardness is asserted. See positive_box_hardness.txt.

Practical counterweight
An exact rational secant/continuous-knapsack baseline takes O(d log d)
arithmetic and gives U<=kappa*L for strictly positive lower bounds, where
L is an actual corner witness and
kappa=max_i (L_i+U_i)^2/(4L_iU_i). For relative width delta this is
1+delta^2/[4(1+delta)]. All-zero lower bounds are even easier: the exact
answer is max active c_i, attained by a singleton corner. Mixed boxes get
a sound upper and sorted-prefix/one-flip lower witnesses. See
secant_baseline_proof.txt and ../variance_algorithm/secant_baseline.py.

The baseline is a conventional relaxation. It is a required comparator
for the sibling Pareto-DP implementation; it may remove the practical
case for the slower DP when continuation intervals are useful/tight.
The sibling agent owns the final held-out timing comparison and regenerates
it against the final source. No superiority over contemporary rare-event
simulation systems is claimed by this local verifier experiment.

Remaining capability barrier
None of these results acquires the continuation intervals. N492's original
state-time dynamic programming already bounds the event probability before
sampling. High-dimensional acquisition without comparable committor work,
rare-event data, or enumeration remains unresolved. The sibling simulation
agent investigates hidden-mode acquisition, so this branch did not duplicate
that lower bound. Transferable contribution is a sharp distinction between
exact local verification hardness, efficient approximate local verification,
and global scientific information acquisition.

Contemporary comparison scope
The earlier full source already discusses state-dependent importance
sampling, Lyapunov/subsolution methods and SAIS. Current primary search
also found high-dimensional committor-learning and DASTR methods. No
scientific simulator benchmark was run. The most relevant inspected
certification baseline is Deep-PrAE (Arief et al., arXiv:2111.02204): its
upper/lower relaxed efficiency certificates estimate bounding event sets;
the inspected theorem uses orthogonal monotonicity and assumptions enabling
dominating-point importance sampling. This differs from a guaranteed tight
relative interval for an arbitrary black-box event and does not supply our
missing continuation intervals. Primary text:
https://arxiv.org/html/2111.02204

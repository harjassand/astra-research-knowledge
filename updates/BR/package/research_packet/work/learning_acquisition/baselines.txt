LINEAR DYNAMICAL SYSTEM ACQUISITION: PRIMARY-SOURCE BASELINE GATES
Research date: 2026-10-10. Literature claims are source-reported unless explicitly derived below.

Decision: finite-horizon prediction, state-realization recovery, and infinite-horizon certification are different targets. Supplied order, stability margin, reset access, noise law, excitation energy, transient magnitude, and numerical precision must be charged. No general acquisition breakthrough was established.

1. Task-optimal exploration.
Wagenmaker, Simchowitz, Jamieson, Task-Optimal Exploration in Linear Dynamical Systems, ICML 2021.
https://proceedings.mlr.press/v139/wagenmaker21a/wagenmaker21a.pdf
https://arxiv.org/abs/2102.05214
TOPLE already directs exploration toward task-relevant parameter directions, with local instance/task-optimal guarantees. Main setting: fully observed x[t+1]=Ax[t]+Bu[t]+Gaussian process noise, unknown A,B, stable A, bounded input power, smooth task loss and regularity conditions. It sequentially solves experiment-design problems using estimated dynamics and then uses certainty equivalence. This is a mandatory comparator for any claim that learning only useful features of a system is new; it does not supply partial-state observability or an unknown stability certificate.

2. Active full-state identification.
Wagenmaker, Jamieson, Active Learning for Identification of Linear Dynamical Systems, COLT 2020.
https://proceedings.mlr.press/v125/wagenmaker20a.html
Finite-time adaptive periodic excitation and asymptotically optimal spectral-norm estimation under input-energy constraint. Stable A, observed states, Gaussian process noise; B is known in the exposition, with extensions discussed. Optimizes weakest information direction. Isotropic noise, even optimally covariance-tuned Gaussian noise, is not the strongest comparator in this setting.

3. Partially observed prediction.
Holden Lee, Improved rates for prediction and identification of partially observed linear dynamical systems, ALT 2022.
https://proceedings.mlr.press/v167/lee22a/lee22a.pdf
Stable partially observed LTI, zero initial state, a single trajectory, Gaussian inputs, Gaussian observation noise; strongest advertised rate is for no process noise. Multiscale Hankel low-rank approximation gives near-optimal H2 impulse-response error. Crucial gate: Theorem 2.2 requires T >= K L d_u log(L d_u/delta), and an explicit truncation remainder; logarithmic memory dependence in the error expression does not mean logarithmic total acquisition time. Realization recovery additionally pays Hankel conditioning. The paper explicitly notes unstable systems can have tiny finite response but infinite H2 response.

4. Unstable-only partial-state stabilization.
Zhang, Nakahira, Qu, Stabilizing Linear Systems under Partial Observability: Sample Complexity and Fundamental Limits, arXiv:2503.16756v1 (2025).
https://arxiv.org/html/2503.16756v1
LTS-P estimates unstable transfer-function components via shifted Hankel SVD and robust control. Main access: multiple zero-state rollouts, observation-only Gaussian noise, no marginal eigenvalues; controllability and observability. Assumption 5.2 supplies existence of a controller robust to the omitted stable component through an H-infinity small-gain condition. Complexity retains unstable-subsystem Gramian singular values and conditioning. Thus small unstable dimension is not a guarantee of cheap acquisition, and stable-tail certification remains a substantive supplied promise. Identifying some stable modes is explicitly suggested when the omitted remainder is too large.

5. Contemporary finite-hypothesis active comparator.
Chatzikiriakos, Jamieson, Iannelli, High Effort, Low Gain: Fundamental Limits of Active Learning for Linear Dynamical Systems, AISTATS 2026.
https://proceedings.mlr.press/v300/chatzikiriakos26a.html
https://arxiv.org/html/2509.11907v2
Single fully observed trajectory, a KNOWN FINITE model list containing the truth, Gaussian process noise, bounded expected input power. Identifiability needs excitation only along differences between hypotheses. Oracle benefit is controlled by eigenstructure of the discrimination matrices; active design need not help on every instance. The max-min input-design program is generally nonconvex; the paper defers scalable approximations. A finite model list is prior knowledge and cannot be counted as acquired representation.

6. Explicit information obstructions.
See weak_mode_no_go.txt for complete elementary proofs and primary sources.

These sources respectively expose ill-conditioned observability/controllability, underactuated stabilization cost, and weak Hankel-mode/order acquisition. Do not treat passing finite prediction tests as recovering a minimal realization or certifying all omitted modes.

Strongest elementary no-go reconstructed in this investigation:
Take known n, r>1, nilpotent shift J e_i=e_(i+1), J e_n=0, cyclic shift P e_i=e_(i+1), P e_n=e_1, B=e_1, C=e_n^T. A_s=rJ is stable and A_u=rP is unstable. Both are controllable and observable, with n-step Gramian least eigenvalue 1. Yet CA_s^k B=CA_u^k B for 0<=k<=2n-2; hence y_1,...,y_(2n-1) have identical laws for every adaptive input policy from x0=0 with common observation noise. No energy or computational method removes this observation-horizon gate. Unknown order permits matching an arbitrary finite unstable impulse-response prefix by a stable nilpotent realization.

Tractable target, correctly scoped:
Given an externally justified order bound d and pole radius rho<1, acquire noisy impulse coefficients through explicitly charged zero-state resets and use a finite-window analytic tail certificate. This can avoid estimating a poorly conditioned realization. It does not acquire d or rho. Strong classical rational-function inequalities already give a polynomial-length certificate; see tail_certificate_prior_art.txt. Therefore this is presently a useful implementation/validation target, not evidence of a new fundamental capability.

SAFE EXPLORATION: EXACT CALIBRATION BARRIER
Date: 2026-10-10. Status: internally derived elementary theorem and negative result;
not an invention beyond known Lipschitz set-membership methods, no priority claim.

TASK AND ACCESS
Autonomous experiments must acquire information while never evaluating an unsafe
parameter. Let x lie in [0,D], and safety mean f(x)>=0. The learner knows L>0
and f(0)=c>0 exactly; its model class is ALL real L-Lipschitz f on [0,D] satisfying
that seed. Each later query returns y_i=f(x_i)+e_i, |e_i|<=eta. Error may be
adversarial and correlated. Every proposed query and certificate must hold for
every function/error sequence consistent with the complete history. Randomness
does not relax this pathwise robust guarantee. Values, L and eta are supplied,
not learned. The theorem evaluates this learner on the favorable true f(x)=c.

EXACT THEOREM
Let a=max(c-2 eta,0). After n noisy queries, the greatest endpoint that any robust
learner can guarantee to certify on the constant instance, in the worst case over
its admissible measurement errors, is

             R_n = min(D, (c+n a)/L).

This counts CERTIFICATION: a subsequent physical query at D costs one additional
evaluation unless it has already been made. Initial exact seed acquisition is
excluded and must be charged separately. If D<=c/L, D is certified immediately.
Otherwise c<=2 eta makes certification impossible for every finite n, indeed for
every countable sequence of queries. If c>2 eta the exact number of noisy queries
needed to certify D is ceil((LD-c)/(c-2 eta)).

PROOF
For any feasible history, the pointwise minimum compatible function is

 g_n(x)=max(c-Lx, max_{1<=i<=n}(y_i-eta-L|x-x_i|)).

Every term is L-Lipschitz, so g_n is L-Lipschitz. Every compatible f dominates all
terms and hence g_n. The seed cone gives g_n(0)>=c, while dominance by any
compatible f gives g_n(0)<=c. At each observation g_n(x_i)>=y_i-eta and, again by
dominance, g_n(x_i)<=f(x_i)<=y_i+eta. Thus g_n itself is compatible. Consequently
the cone union {g_n>=0} is the EXACT robust-safe set, not merely sufficient.

For the lower bound the adversary always returns y_i=c-eta. This is legal on
the true constant instance. The envelope becomes

 max(c-Lx, max_i(c-2 eta-L|x-x_i|)).

Initially safe points form [0,min(D,c/L)]. If c-2 eta<=0, subsequent cones have
nonpositive peak and cannot add an unqueried safe point. If c-2 eta>0, each
new safe query x_i belongs to the existing interval [0,R_{i-1}], and its cone
extends the right endpoint by at most (c-2 eta)/L. Induction gives R_n above.
At every x beyond that bound the displayed compatible g_n is strictly negative,
so a more aggressive certificate would be false on a consistent alternative.

For achievability query the current certified right boundary. Under any error
on f=c, y_i-eta>=c-2 eta. Its new cone expands the certified interval by at least
(c-2 eta)/L when positive. Clip at D. Worst-case errors attain equality. QED.

This also proves the all-time stall: under y_i=c-eta and c<=2 eta, the single
alternative f_alt(x)=c-Lx is compatible with every measurement inside [0,c/L]
only when Lx<=2eta; that holds since c<=2eta. It is negative beyond c/L. Thus a
single fixed alternative, not an adaptively changing function, defeats escape.

EXAMPLES (D=L=1)
c=0.1, eta=0: 9 noisy queries certify the far endpoint (seed excluded).
c=0.1, eta=0.02: 15 queries.
c=0.1, eta=0.049: 450 queries.

SECOND ACQUISITION OBSTRUCTION
Replacing known L by the promise 'real analytic, range [-c,c], with some finite
but unknown Lipschitz constant' does not permit safe exploration. Given finitely
many distinct queried sites S with f(s)=c, put Q(x)=product_{s in S}(x-s)^(2m)
and f_epsilon(x)=c(2 exp(-Q(x)/epsilon)-1), epsilon>0. These functions are analytic,
bounded by [-c,c], individually Lipschitz on the compact interval, and agree with
the constant function at every s. Their derivatives of orders 1 through 2m-1
also agree with the constant function at those sites. For every z outside S,
f_epsilon(z) tends to -c. No off-sample safety or finite upper Lipschitz bound
can therefore be certified from these data, even with any preassigned finite
number of exact derivative observations at the sampled sites.

For a randomized proposed next-query law mu conditional on this history,
dominated convergence gives P_mu[f_epsilon(X)<0] -> mu([0,D] minus S). Thus a
uniform one-step failure probability <=delta requires the probability of a new
site to be <=delta. At the first new query, seed-only transcripts are identical
on all f_epsilon, so the same statement applies to the probability of EVER
leaving the seed set under a uniform all-time delta-safety requirement.

An RKHS version is equally explicit. For a strictly positive-definite kernel k,
sample Gram matrix K, sample values y and a new z, set
 p(x)=k(x,S)K^{-1}y,
 r_z(x)=k(x,z)-k(x,S)K^{-1}k(S,z).
Then r_z vanishes at S, r_z(z)=||r_z||_k^2>0, and p is orthogonal to r_z.
Every p+b r_z interpolates y, while its value at z ranges over all real numbers
and its squared norm equals y^T K^{-1}y+b^2||r_z||_k^2. RKHS membership alone
therefore does not acquire the required upper norm bound. See critic.txt.

OPERATIONAL CONSEQUENCE AND STRONGEST COMPARATOR
The optimal algorithm here is ordinary Lipschitz cone propagation. LoSBO already
uses this safety rule, independently of its GP optimization model; no more
sophisticated statistical model can enlarge the certified set with these same
assumptions. The exact flat-instance rate and analytic counterexample are useful
audit fixtures, not evidence of a new feasible capability. Treat known c,L,eta
and the error model as physical inputs. A zero-mean independent noise model,
known function structure, a calibrated reference or permitted safety risk changes
the information class and can change the result. For example one reference query
removes an exactly shared unknown additive bias, but not arbitrary bounded errors.
Charging that reference and proving bias stability is indispensable.

RESOURCES AND VALIDATION
For a one-dimensional connected cone union, greedy certification maintains one
endpoint: O(n) arithmetic operations and O(1) words beyond the observation log.
The full replay intentionally checks the O(n)-term envelope, all observation
constraints and a strictly unsafe consistent witness outside each computed
boundary, using exact rational arithmetic. It also checks arbitrary legal
non-greedy query paths. Numerical work is verification of examples; the proof
above, not finite tests, establishes the theorem. See replay_script.txt and
replay.txt for measured run details. No robot or physical sensor was tested.

EXACT ORACLE AND COVERAGE
check_exact.py constructs integer scaled Gaussian moments. For
Q=lcm(denominator(a),denominator(c)), A=aQ^2 and C=cQ are integers. Define
P_0=1, P_1=C and P_n=C P_(n-1)+(n-1) A P_(n-2). Then
H_n=P_n/(Q^n n!), exactly. This independently exercises the evaluator's
Taylor coefficients, factorial denominators, and prefactor.
Coverage includes n=0,1,2,3,4,15,50,101; a/c zero cases and rational scales
10^+/-30; force_integral with valid large saddles at n=1,2,3,15,100;
natural integral cases n=2304,2305,2500,2501, including odd c=10^-30;
and force-integral p=1,10,100,200. Results: check_exact.json.

CONCRETE REMAINING NARROW ISSUE
log_H(1,1,Fraction(1599,40),20,force_integral=True) raises ValueError although
its exact saddle m=40 equals the stated admissibility threshold 4(R+1).
The computed m.lower() is slightly below 40. Default dispatch uses finite_sum
and succeeds, so this is an optional diagnostic-branch false rejection, not
a counterexample to the default promised evaluator.
An exact rational test for m>=M, M=4(R+1), is
  n>=M^2 OR c^2 M^2 >= a(M^2-n)^2.
This avoids the equality ambiguity. Out-of-range force_integral inputs
should still be rejected.

FIXED-PROPOSAL BOX SECOND-MOMENT CERTIFICATION: EXACT-RATIONAL FPTAS COROLLARY
Status: internally reconstructed conventional approximation-scheme transfer.
Historic objective: NOT ACHIEVED. Originality: NOT CLAIMED; general fractional
FPTAS prior art is being checked by a separate investigator (Mittal--Schulz).

INPUT AND OUTPUT
For i=1,...,d the input consists of binary-encoded rationals P_i>=0, q_i>0,
sum q_i=1, B_i>=1, and 0<=l_i<=u_i<=1. Define a_i=P_i*l_i,
b_i=P_i*u_i, c_i=B_i/q_i. For x_i in [a_i,b_i], S=sum x_i>0,
V=sum c_i*x_i^2, R=V/S^2. If every b_i=0, the domain is empty and the
program returns NO_POSITIVE_EVENT_MASS, not a variance assertion.
For epsilon in (0,1], the program returns a corner xhat, L=R(xhat), and U
such that L <= max R <= U <= (1+epsilon)L. It does not optimize q.
The B_i and intervals are supplied certificates, not acquired by this algorithm.
When B_i merely bounds a local conditional second moment, max R bounds a
relative second moment; the relative variance of one unbiased sample is at
most U-1. Equality to the true worst-case variance requires additional model
realizability. This is an optimization/certification result, not a learning result.

LEMMA 1: A CORNER ATTAINS THE MAXIMUM
Fix other coordinates with s=sum_{j!=i}x_j and v=sum_{j!=i}c_j*x_j^2.
For s>0, f(x)=(c_i*x^2+v)/(x+s)^2 has derivative
f'(x)=2(c_i*s*x-v)/(x+s)^3. The derivative numerator is increasing,
so the only interior stationary point is a minimum. An interval endpoint
has value at least f(x). If s=0 then v=0, and f(x)=c_i for x>0;
choose b_i>0 whenever the current coordinate is positive. Thus coordinates
can be rounded successively to endpoints without decreasing R or making
the denominator zero. The maximum equals a finite maximum over positive
corners even if the box contains the excluded zero vector.

ALGORITHM
Set rho=1+epsilon/[2*d*(1+epsilon)]. Start with state (S,V,mask)=(0,0,0).
For each coordinate extend every retained state by each distinct endpoint
x in {a_i,b_i}, adding (x,c_i*x^2) and recording its choice in a bitmask.
Sort expanded states by increasing S. Keep one zero state (its V is zero).
For positive states start a bucket at the least remaining mass s0, include
all states with S<rho*s0, and retain the state of greatest V, breaking ties
by smaller S and then smaller mask. Repeat until all states are assigned.
After all layers choose the retained positive state with greatest V/S^2.
This is adaptive geometric bucketing. No irrational logarithms, floating
bucket indices, or exponentially large precomputed rational powers occur.

LEMMA 2: THE PRUNING INVARIANT
For every exact corner prefix (S,V) of length j with S>0, some retained
prefix (S',V') has S'<=rho^j*S and V'>=V. The all-zero prefix, when
feasible, is retained exactly. Proof is induction. Extend a representative
of an exact predecessor by the same endpoint x. Since rho>=1,
S'+x <= rho^(j-1)*S+x <= rho^(j-1)*(S+x), and V'+c*x^2>=V+c*x^2.
Trimming changes mass by a factor strictly less than rho and never lowers
V relative to the chosen incoming state: both old and representative S
belong to [s0,rho*s0). This completes the induction. An intermediate zero
predecessor is handled exactly; if extension is positive the same argument
applies.

THEOREM
For an optimal corner (S*,V*), Lemma 2 supplies a retained state with
R'>=V*/(rho^d*S*)^2=R*/rho^(2d). The selected L is at least R'. Since
its witness is a genuine corner, L<=R*. Hence U_DP=rho^(2d)*L is a
certified upper bound. Let t=epsilon/[2*d*(1+epsilon)] and m=2d.
The binomial coefficients satisfy binom(m,k)<=m^k, so
(1+t)^m <= sum_{k=0}^infinity (mt)^k
           =1/(1-epsilon/(1+epsilon))=1+epsilon.
Thus L<=R*<=U_DP<=(1+epsilon)L. All factors are computed as Fractions.
The program may tighten U by taking a minimum with independently valid
analytic upper bounds. The returned witness plus factor arithmetic can be
checked independently; checking only the witness does NOT verify the DP
implementation or supplied local assumptions.

BIT COMPLEXITY AND RESOURCES
Let h be the smallest strictly positive endpoint and H=sum b_i. For any
positive prefix h<=S<=H. Successive adaptive bucket starts are at least
rho times the previous start. At most
K=1+floor(log(H/h)/log(rho))
positive buckets plus a zero bucket survive any layer. Since
log(rho)>= (rho-1)/rho and epsilon<=1, K=O(d/epsilon * log(H/h)).
If N is the total binary length of rational inputs, log(H/h)=O(N+log d).
Each S,V is an exact sum of at most d original rational endpoint terms;
its reduced numerator/denominator have polynomial (indeed O(N+log d))
length. Comparisons and rho multiplication also have polynomial bit cost.
Every layer sorts at most 2(K+1) states: O(d*K*log K) arithmetic operations,
O(K) simultaneously retained states, and O(d) bits per witness mask.
The full certificate factor rho^(2d) has O(d*bitlength(rho)) bits. Hence
this is an FPTAS in input bit length and 1/epsilon, not a strongly polynomial
algorithm. Large input dynamic range, small epsilon and Fraction overhead
can make it substantially slower than analytic bounds. This cost does not
include learning or validating any supplied input. The code is serial Python
standard library, without specialized Pareto-state data structures.

ANALYTIC BASELINES (ALL USE THE SAME SUPPLIED INPUTS)
Let A=sum a_i and restrict to active b_i>0.
1. Ordinary interval: [sum c_i*b_i^2]/A^2 when A>0; otherwise infinity.
2. Max coefficient: max_i c_i, since sum x_i^2 <= (sum x_i)^2.
3. Coordinate fractions: sum_i c_i*[b_i/(b_i+A-a_i)]^2.
   Each individual x_i/sum x_j is maximized by x_i=b_i and others a_j.
4. For P=q, B_i=1 and common 0<l<=u, the Kantorovich bound
   (l+u)^2/(4*l*u). Indeed E[z^2]<=(l+u)E[z]-l*u,
   and maximization over E[z] in [l,u] gives this value. It is a valid
   continuous-distribution bound even if finite box corners cannot attain it.
The program uses the minimum available analytic bound. Benchmark results
must expose cases where this cheap bound is better than the FPTAS U_DP.

LIMITATIONS AND FAILURE MODES
No historical novelty claim; no robust optimization of q; no information
acquisition; no experimental event generator; no independent expert or
formal proof verification. The certificate only concerns the stated supplied
rational optimization problem. Binary floating JSON values are rejected.
The zero-mass domain is explicitly excluded. Exact exhaustive comparisons
on small cases establish finite implementation evidence, not universal
correctness. Reproducibility and hash freezing are provenance, not a proof.

ASTRA JOINT FINITE ACTION REFRESH BOUND
16 October 2026

Capability: Exact worst-case joint parity-error bounds for any finite selected set under synchronized ideal refresh operations, allowing an arbitrary finite shared bath. This closes a restricted version of the joint finite-action question left open by PR105.

Result: If all selected coordinates are completely pinched at the same fixed nodes, define Q_i = 1 - product_k cos^2(min(a_ik, pi/2)), where a_ik is the permitted interaction action on coordinate i in common gap k. The all-selected terminal-mismatch effect is bounded by product_i Q_i. The stronger event that every coordinate has a recorded mismatch obeys the same bound. Finite independent sink baths attain equality within the arbitrary-finite-bath adversarial class. A fixed small bath need not attain it.

Evidence: Analytic operator-valued entire-function argument, a past-record induction with nonnegative multilinear coefficients, and explicit attaining models. The coordinating assistant separately read the proof, checked the primary analytic theorem and replayed the own matrix checks. Internal reconstruction is not external validation.

Closest prior result: PR105 gives exact singleton minimax and only quadratic joint control. Classical Duffin-Schaeffer-Boas/Bernstein bounds, as presented by Redheffer (1953), supply the analytic ingredient. Historical originality of this particular transfer is unestablished.

Missing operation: Ideal complete pinches or the exact private-sign refresh interface must be physically implemented with actual timing, pulse-width, privacy, calibration and energy costs. No such hardware qualification is supplied here. Asynchronous schedules with multiple gaps on multiple coordinates remain open.

Plausible consequence: A sharper rigorous joint-error budget for synchronized designs, without pretending shared-bath errors are statistically independent. Proportional known envelopes permit common equal-action slots that simultaneously optimize the singleton factors within this synchronized class.

Decisive next mathematical test: Establish or refute the full product-Q bound for two genuinely asynchronous multi-gap schedules while preserving cross-parity commutation and private-sign independence. The packet supplies an improved sine-sum bound but does not close this case. Conditioning on a future error event is explicitly shown invalid as a shortcut.

Reproduce: python independent_checks.py (existing NumPy and SciPy). The four asynchronous examples are diagnostics only, not evidence of a universal theorem.

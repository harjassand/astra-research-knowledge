# Publication selection decision

The first hash-bound authored selection had 283 entries and 13995043 bytes.
Pre-copy review found that five current-PR file responses carried complete
patches totaling 11109396 bytes. Their content is already publicly addressable
at pinned GitHub heads, and the selected scientific reads have their own exact
range/hash receipts. Publishing all old-PR patches would obscure the scientific
claim and add unrelated archive material.

The final v0002 selection therefore excludes only PR84_FILES.json,
PR85_FILES.json, PR87_FILES.json, PR88_FILES.json and PR95_FILES.json. Live PR
metadata, head pins, changed-path/overlap analyses, scientific read receipts,
full audit and its source-snapshot hashes remain selected. The unselected full
responses and v0001 selection remain locally unchanged. This is a pre-copy
publication narrowing, not deletion of original research or concealment of a
failed check. Selective read is not full merger clearance.

Externally acquired paper fulltexts, workbooks, model datasets and clones remain
excluded. Exact witnesses, analytic proofs, meaningful executable checks and
failed-attempt records stay in the scientific preservation selection.

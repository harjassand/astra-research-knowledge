NONSTATIONARY ENTRANCE DELAY FOR PRODUCT-CHAIN HITTING TIMES
Version 1, 2026-10-10. Internally derived proof; priority UNKNOWN.
This is a limited extension, not a landmark discovery.

CONTRACT
n independent continuous-time two-state chains have target probabilities
0<p_i<1 and rates lambda_i>0. The transition 0->1 has rate p_i lambda_i,
and 1->0 has rate (1-p_i)lambda_i. The target is a=(1,...,1).
H_mu=inf{t>=0:X_t=a}; hence an initial target gives H_mu=0.
All parameters are supplied explicitly; neither model acquisition nor a
trajectory or conditional history is provided by this construction.

THEOREM 1 (product initialization below equilibrium)
If X_i(0) are independent Bernoulli(r_i), 0<=r_i<=p_i, let H_pi have the
stationary product hitting law. Independently sample D_i, equal to zero
with probability r_i/p_i and otherwise exponential with rate lambda_i.
Let D=max_i D_i, and take H_pi independent of all D_i. Then

                     H_mu = in distribution H_pi+D.

Proof. Put q=product p_i and R_mu(s)=integral_0^infinity
exp(-st) P_mu(X_t=a) dt. Strong Markov renewal at the first hit gives
R_mu(s)=E_mu[exp(-s H_mu)] R_a(s), including the zero atom. R_a(s)>0.
Independence gives
P_mu(X_t=a)=q product_i[1-(1-r_i/p_i) exp(-lambda_i t)]
           =q P(D<=t).
Tonelli yields R_mu(s)=q E[exp(-sD)]/s. Stationarity gives
R_pi(s)=q/s, so division by R_a(s) proves the transform factorization.
Uniqueness of Laplace transforms of finite nonnegative random variables
proves the claim. Finite irreducibility ensures hitting is almost surely
finite. For a zero delay the integral identity still holds.

THEOREM 2 (correlated erasures)
Choose any random subset S independently of a stationary product draw,
then force the coordinates in S to zero. The resulting initial law may
have correlations. Sample a fresh S with the same law and independent
E_i~Exp(lambda_i); let D=max_{i in S} E_i (empty maximum zero).
Then again H_mu =d H_pi+D with independent summands.
Proof. Conditional on S, coordinates outside S remain stationary, while
each coordinate in S has probability p_i(1-exp(-lambda_i t)) of being 1.
Thus P_mu(X_t=a)=q E_S product_{i in S}(1-exp(-lambda_i t))=q P(D<=t).
Apply the same renewal proof. The supplied interface must include an
efficient sampler for S; recovery of this mixing law is not free.

ERROR TRANSFER
Suppose the stationary algorithm supplies a coupling with
P(|Hhat_pi-H_pi|>epsilon H_pi)<=delta. With exact D independent, set
Hhat_mu=Hhat_pi+D. The same relative coupling holds since H_pi<=H_pi+D.
Furthermore convolution with a common independent D contracts uniform
CDF distance. Thus any stationary absolute CDF bound transfers unchanged.
If Dhat has its own relative coupling epsilon_D,delta_D, the sum has
relative error at most max(epsilon,epsilon_D) with failure <=delta+delta_D.
This last statement is a coupling guarantee, not by itself a CDF bound
for the sum. No continuous-law total variation guarantee is asserted.

COST AND BASELINE
The extra ideal-real work is n Bernoulli/exponential draws and a maximum;
memory is O(1) beyond the input if processed sequentially. For correlated
erasures add the actual subset-sampling cost. With binary rational input,
Bernoulli ratios are computable exactly and exponential draws can be
coupled at finite precision using truncated dyadic uniforms. Their bit
cost depends on input bit lengths and the requested error/failure budget,
not on the physical hitting duration. This file does NOT independently
reprove or implement the full N592 finite-bit stationary sampler.
Any total polynomial-runtime claim is conditional on that stationary
sampler's proof and implementation, which remain independently unaudited.

The exact renewal-transform identity, strong stationary duality and
stationary hitting decompositions are established techniques. This
corollary may already be implicit in them. The fully explicit 2^n-state
killed generator is a correctness comparator, not the strongest scalable
baseline. Brown's repair-system work and non-enumerative ODE methods
must be included before claiming an algorithmic advance.

OUTSIDE THE CONTRACT
The conclusion cannot cover arbitrary deterministic starts by this
nonnegative delay. For n=1 and r>p, P(H_r=0)=r>p=P(H_pi=0), whereas
P(H_pi+D=0)<=p for every independent nonnegative D. This rules out this
specific factorization, not efficient arbitrary-start sampling.
Neither rare-event tail relative error nor the event trajectory follows.

EVIDENCE AND NEXT GATE
verify.py compares rational Laplace transforms to direct killed-generator
linear solves, and tests the correlated-erasure extension. These finite
checks supplement the argument and do not certify the universal proof.

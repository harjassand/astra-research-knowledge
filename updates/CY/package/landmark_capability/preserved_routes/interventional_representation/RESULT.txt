Controlled commutator witness: measure and use a hidden interaction
Date: 2026-10-10
Status: concrete nonlinear black-box mechanism with a proved local law and an
exact toy construction. Mathematical core is related to classical Lie-bracket
control; the proposed contribution is an interaction-only measurement and
macro-action interface that needs no hidden-state reconstruction.

The mechanism
-------------
Suppose an unknown smooth system offers two reversible interventions. Applying
the first for signed strength a gives a black-box map F_a; the second at signed
strength b gives G_b. Assume F_-a = F_a^{-1} and G_-b = G_b^{-1}. A sensor
returns y=h(x), but the hidden state x and the maps are unavailable. The
experiment is the four-step loop

    G_b, F_a, G_-b, F_-a

in chronological order. The loop returns each action's first-order effect and
leaves the order-dependent interaction. It is a task-relevant query on the
unknown system: did these two interventions commute in the direction the
sensor can see, and by how much? It does not estimate the state or fit the
system.

Local theorem
------------
Let F_a and G_b be local flows of C^3 vector fields f and g. Define

    K_(a,b)(x) = F_-a(G_-b(F_a(G_b(x)))).

For sufficiently small a,b,

    K_(a,b)(x) = x + a b c(x) + O(|a|^2 |b| + |a| |b|^2),
    c(x) = Df(x) g(x) - Dg(x) f(x).

Consequently,

    h(K_(a,b)(x)) - h(x)
      = a b Dh_x[c(x)] + O(|a|^2 |b| + |a| |b|^2).

There are no pure-a or pure-b terms: if either action is absent, the loop is
exactly the identity. The mixed derivative is the projected Lie-bracket
coefficient, up to sign convention. Thus a single loop measures a hidden
interaction through the output projection Dh, even when neither action has an
observable first-order effect on its own.

For a less step-size-biased coefficient estimate, start four trials from the
same hidden state and measure the endpoints of K_(+a,+b), K_(+a,-b),
K_(-a,+b), and K_(-a,-b). Then

    kappa_hat = [h(K_(a,b)x) - h(K_(a,-b)x)
                 - h(K_(-a,b)x) + h(K_(-a,-b)x)] / (4ab)

equals Dh_x[c(x)] + O(a^2+b^2) for sufficiently smooth flows and readout.
This sign cycle cancels the leading finite-step terms that are even in either
control. With independent endpoint noise of variance sigma^2, its readout-noise
standard deviation is sigma/(2|ab|). Small pulses reduce truncation bias but
amplify sensor noise and inverse-control errors.

Exact example: two individually silent actions expose a coupling
--------------------------------------------------------------
Take hidden state (q,z), sensor h(q,z)=z, and reversible action maps

    F_a(q,z) = (q+a, z),
    G_b(q,z) = (q, z+bq).

At x=(0,0), either action alone gives readout zero. The four-step loop gives

    (0,0) --G_b--> (0,0) --F_a--> (a,0)
          --G_-b--> (a,-ab) --F_-a--> (0,-ab).

The loop returns q exactly and creates a pure z displacement. No internal
model, hidden-state estimate, or numerical derivative is needed. Repeating
the same loop N times yields (0,-Nab) exactly in this system. More generally,
with a=b=epsilon, N loops and N epsilon^2=T approximate time T of the vector
field c with global error O(T epsilon) on a compact region. This is a virtual
macro-action in a direction absent from the primitive actions; whether the
sensor can use it is exactly the projected-coupling question above.

Cost and feasibility
--------------------
A qualitative witness costs four signed action pulses and one endpoint
readout (plus a starting-state reference if the sensor has no fixed zero).
The four-sign coefficient estimate costs 16 pulses, four endpoint readouts,
and four replays from the same hidden starting state. A bracket macro-action
of N loops costs 4N pulses. If each primitive takes physical time |a| or |b|,
the N-loop approximation can be slow as epsilon shrinks; the mechanism is
useful when a small number of direct interventions is expensive or individually
uninformative, and when order-dependent movement is the quantity needed.

The interface requirements are sharp: signed controls must be calibrated,
inverse pairs must return the system sufficiently close to its start, and the
hidden starting state must be repeatable across the four sign-cycle trials.
If each output has standard deviation sigma, the four-run estimate has noise
scale sigma/(2|ab|). If the actual signed strengths have errors da,db, the
leading coefficient has relative scale error about da/a + db/b. An inverse
error that creates a residual larger than |ab kappa| is indistinguishable
from a true interaction. The one-axis echo checks F_a followed by F_-a and
G_b followed by G_-b should therefore be run first; a return residual above
the preregistered tolerance is an immediate fail, not evidence of coupling.

Early counterexamples
---------------------
1. Sensor blindness: keep the same F and G but add a hidden coordinate w and
   let h(q,z,w)=w. The loop still changes z by -ab, but every observation is
   unchanged. The operation measures Dh[c], not the full hidden bracket. No
   output-only method can recover an interaction lying in the sensor's null
   directions without another readout or a later action that maps it into a
   visible direction.
2. Non-inverse pulses: let F and G commute exactly, but suppose every physical
   pulse adds an unmodeled sensor drift eta. The four-call loop leaves 4 eta
   and reports a false interaction 4 eta/(ab). As a,b shrink, this artifact
   grows after normalization. Failed one-axis echo checks invalidate the
   result immediately.
3. A bracket can vanish at the current state even if the actions do not
   commute elsewhere. A zero witness is local and does not certify global
   independence.

Decisive narrow test
--------------------
Hide the rules of a two-actuator nonlinear toy plant and expose only its two
signed action controls, repeatable reset, and one scalar sensor. Pre-register
one starting state, a,b, pulse tolerances, sensor-noise scale, and the one-axis
echo acceptance threshold. First test both inverse pairs. Then run the
four-sign estimate without fitting a state model. A blinded evaluator chooses
the sign of a fresh commutator loop; the predicted sign of the sensor change
must agree, and its magnitude must match the frozen local coefficient within
the preregistered truncation-plus-noise bound. A direct-action-only baseline
must miss the example where F and G are individually silent at the start.
Finally, vary a,b and check the predicted ab signal and O(a^2+b^2) coefficient
bias. Failure of inverse checks, sign prediction, scaling, or the blind-sensor
negative control rejects the mechanism for that interface. This proposed test
separates a working interaction oracle from a pretty commutator trace.

Prior-art boundary and decision
-------------------------------
Commutator loops that produce Lie-bracket motion are standard in geometric
control; for example, the established small-loop formula is stated in
“Integral representation for bracket-generating multi-flows”:
https://arxiv.org/abs/1709.02677. This result does not claim a new Lie-bracket
theorem. The distinct research target is the task-specific black-box witness:
use output-only commutator measurements to reveal or exploit one hidden
coupling without identifying the dynamics. It is worth pursuing only where
reversible interventions and repeatable starts are cheap and the target
coupling has a visible downstream effect. Exact reversibility, sensor
visibility, and adequate signal-to-noise are the early gates.

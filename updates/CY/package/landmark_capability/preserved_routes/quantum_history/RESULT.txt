RANK-COLLAPSING KRAUS HISTORIES: LOCAL-SIMULATION EXTENSION AUDIT
10 October 2026

Verdict: NO_PASS for a broadly useful new quantum simulation algorithm.
The rank-one-history condition alone admits local circuits whose exact output
probability is #P-hard, and it admits arbitrary universal quantum computation
before the collapse. The N636 conic representation is useful as an exact
dense-dimension channel certificate, but no end-to-end advantage over matched
state, tensor/MPS/MPO, and trajectory methods was established. A different,
scoped constructive operation is developed in PIVOT_QUANTUM_RENEWAL.txt and
extended to monitored free fermions in PIVOT_FERMION.txt.
This is an obstruction to the original extension, not a proof that no
restricted useful extension can exist.

CONTRACT A BROAD EXTENSION WOULD NEED
Input: n-qubit local gate/instrument list of length G=poly(n), each gate of
arity at most 3 with O(1)-bit rational entries (or a stated precision budget);
initial product state; requested output a specified output-bit probability
or weak samples within stated error. Gate synthesis, discovering a favorable
Kraus representation, constructing the quotient/compressed objects, and
verifying error all count. In particular, a supplied 2^n-by-2^n Kraus matrix
is not a polynomial-size local input. Comparators get the identical circuit,
output contract, error and confidence target, and preprocessing budget.

OBSTRUCTION 1: EXACT STRONG SIMULATION
For any Boolean formula f on an even number n of variables, introduce clean
ancillas and do the following. An odd-variable formula can be padded with one
unused variable; the resulting count is twice the original count.

1. On each pair of input qubits apply G=H tensor H. This is a *two-qubit*
   rational gate: all its entries are +1/2 or -1/2. The data register is now
   2^(-n/2) sum_x |x>, with rational amplitude.
2. Compile f into a reversible circuit using X, CNOT and Toffoli, retaining x
   and placing f(x) on a designated output wire. This takes polynomially many
   local gates and clean ancillas. For example, fresh-target AND is Toffoli;
   fresh-target OR is two CNOTs followed by Toffoli. Garbage may remain.
3. Apply the local full computational-basis dephasing instrument to every
   qubit. For each complete outcome z, the full branch product is
   B_z = |z><z| U, where U is the preceding unitary. Hence rank(B_z)=1.

For input |0...0>, the output-bit-1 probability is exactly
  p_f = #{x : f(x)=1}/2^n.
Distinct x remain distinct basis states because x is retained. Thus the
final diagonal density has 2^n nonzero entries for this input, and positive
reweighting of its actual rank-one branches needs at least 2^n terms to
represent that density explicitly. An exact polynomial-time local-circuit
algorithm for p_f would compute #SAT by multiplying by 2^n; this is a #P-hard
strong-simulation task. The all-size conclusion is a reduction, conditional
only in its usual interpretation that FP is unlikely to equal #P. The finite
script checks 1/4, 9/16 and 7/16 examples with rational arithmetic.

For the entire terminal channel Phi_U = D o Ad_U, the Choi vectors vec(B_z)
are orthonormal: Tr(B_z* B_y)=delta_zy. Thus the Choi rank is d=2^N, with N
the total qubit count. Every explicit Kraus representation requires at least
d terms, irrespective of positive conic elimination. This is an unconditional
output-size barrier for the full explicit channel; it does not rule out a
succinct circuit representation or a special query algorithm. In the second
finite fixture N=8 and d=256, whereas N636's exterior dimension is 32,640
and its d^4 conic cap is 4,294,967,296. These are parameter counts, not
measured resource usage of an implementation.

OBSTRUCTION 2: APPROXIMATE WEAK SIMULATION
Let R = [[3/5,-4/5],[4/5,3/5]]. This is a fixed rational real one-qubit
rotation; R^2 changes the computational basis. Shi's primary theorem states
that CNOT plus such a real gate is universal for quantum computation, with
efficient approximation of desired gates. A compiled BQP circuit using this
local rational gate set can be followed by exactly the same local full
dephasing. All complete histories have rank one. If one could sample its
terminal output distribution in poly(n,G,1/epsilon) time within total
variation epsilon<=1/12, then reading the decision bit and repeating samples
would put BQP in BPP: the original 2/3-versus-1/3 gap remains separated.
The same applies to additive-1/12 estimation of that bit probability with
standard success confidence. This is a conditional complexity barrier, not
a proved separation of BQP from BPP. A rank-one condition confined to the
end of a computation has not controlled the difficult unitary prefix.

The exact #SAT fixture is *easy to sample weakly*: draw uniform x and evaluate
f(x). Its role is to rule out a generic exact probability/channel algorithm.
The BQP embedding addresses generic approximate sampling. Neither argument
claims that every rank-collapsing instance is difficult.

MATCHED BASELINE AND ACQUISITION ACCOUNTING
- For one supplied dense d-dimensional input state and one terminal query,
  direct density propagation rho <- sum_i K_i rho K_i* uses O(d^2) working
  storage and O(sum_t r_t d^3) ordinary dense arithmetic operations, without
  enumerating histories. A pure unitary prefix uses O(d) state storage and
  O(Gd) operations for local-gate statevector updates. Exact bit cost is
  polynomial in the supplied rational input size and length, as is N636.
- For all-input channel reuse, standard superoperator/Choi propagation
  already avoids histories and uses O(d^4) storage. Generic Kraus rank is at
  most d^2 if arbitrary combinations are allowed. N636 keeps actual products
  at the price of up to d^4 of them, so this is a structural certificate, not
  a faster generic channel simulator.
- With local n-qubit inputs, the N636 exterior space has dimension
  d(d-1)/2=Theta(4^n), and the conic coordinate space has dimension d^4=16^n.
  Expanding local gates into dense d-by-d matrices already costs Omega(4^n)
  entries per gate. These are acquisition and representation costs, not
  preprocessing that may be omitted from a claimed speedup.
- Optimized tensor contraction, MPS/MPDO evolution, and sampled MPS quantum
  trajectories exploit spatial structure or noise before the final readout.
  On the exact #SAT family a classical trajectory sampler is already linear
  in the compiled Boolean circuit per weak sample. On the BQP family the
  trajectories remain coherent until the last measurement. No measured or
  proved regime here lets positive conic compression beat the strongest of
  these baselines on the same local input/output/error contract.
- Reconstructing a rank-one Kraus representation from a channel description
  is a separate acquisition problem. N636 explicitly starts with a supplied
  representation; it does not solve generic entanglement-breaking recognition.
  That recognition problem is NP-hard in the dense general setting (Gharibian).

TERMINAL SEMANTICS ARE TOO NARROW FOR MULTITIME SIMULATION
Let D be full qubit dephasing. The two-stage sequences (D,I) and (I,D) both
have terminal forgotten-outcome channel D. Insert H between the stages and
start with |+><+|. For (D,I), the output is I/2; for (I,D), it is |0><0|.
Thus an N636 terminal-channel compression cannot answer arbitrary inserted
interventions or reconstruct the monitored history law. The example is exact
and requires no noise or approximation.

PIVOT AND GATE FOR A FUTURE POSITIVE RESULT
I considered three restrictions that could make collapse useful:
1. Early local measurement/reset creating bounded space-time clusters.
   Trajectory sampling and tensor contraction already exploit these cuts;
   collapse alone supplies no stronger cost bound.
2. Query-specific backward propagation inside a small reachable operator
   span. This can be useful, but acquiring a succinct basis and updating it
   is precisely the hard step, and the resulting method overlaps Heisenberg
   tensor/MPO contraction. A dimension count in dense d is insufficient.
3. Approximate branch merging. No certified trace/diamond error bound or
   polynomial acquisition procedure was derived; small branch rank by itself
   says nothing about the number or weights of relevant histories.

A quantum first-detection boundary recurrence for a sparse detector and
product unitary was subsequently constructed and exact-checked; see
PIVOT_QUANTUM_RENEWAL.txt and sparse_detector_renewal.py. The same operation
with determinant-valued free kernels handles sparse non-Gaussian detectors
amid local free-fermion dynamics; see PIVOT_FERMION.txt and
fermion_boundary_renewal.py. These avoid Hilbert-state materialization and
compute rare-event probabilities, but quantum renewal and free-fermion
determinants have prior art, and a representation-aware Gaussian mixture
baseline is also polynomial. They are scoped useful operations, not the
required broad comparative pass.

A credible next candidate must specify a locally checkable structural
parameter k, obtain a succinct basis/certificate in poly(n,G,k,1/epsilon)
time, prove the requested query or sampling error including all discarded
mass, and exhibit matched non-Clifford local instances where optimized tensor
contraction, MPS/MPDO and modern trajectory unraveling are all worse under
the same error target. No such candidate passed this gate here. Do not call
the query-span pivot a new algorithm until it clears that comparison.

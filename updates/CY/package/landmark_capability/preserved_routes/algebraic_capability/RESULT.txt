STATUS: exact scoped algorithmic capability; no historical breakthrough or priority claim.

Object. The active state is x in G = product_i Z/m_i. On an ordinary step,
x <- x + v. There are k prioritized rules. Rule j tests equalities x_i=c_ji
for a specified subset of coordinates. If it fires, x <- R_j (a fixed
active-state vector). An independent payload p in Z/Q is retained: ordinarily
p <- p+c, and when rule j fires p <- a_j*p+b_j. Rules inspect x, never p.
All parameters are explicit finite integers; there is no learned world model.

Result. Given (x_0,p_0) and binary T, compute the exact (x_T,p_T) in time
polynomial in the encoded rule size, log Q, and log(T+1), with no dependence
on |G| beyond its bit length. The implementation uses (k+1)k next-event
guard checks, each at most d generalized-CRT steps; then at most k event
edges, one division by the cycle duration, and O(log T) affine-map modular
multiplications. Event locations and durations can be huge; their bit
lengths are at most O(sum_i log m_i + log k). Output size is
O(sum_i log m_i + log Q). All operations are integer exact: no numerical
conditioning or probabilistic approximation occurs.

Proof. From any active x, guard j is next hit at the least t>=0 solving
v_i*t = c_ji-x_i (mod m_i) for all i fixed by the guard. Each congruence
reduces by gcd(v_i,m_i); inconsistent divisibility gives no hit. Generalized
CRT combines the reduced congruences, including noncoprime periods. Compare
the least nonnegative t for all guards; break equal-time ties by rule order.
This is exactly the first possible exceptional step because active evolution
before then is pure translation. After rule j fires, active state is R_j,
so the next guard and wait t_j depend only on j, irrespective of p. Thus
the post-rule active control follows a functional graph on at most k rule
indices. Its edge j -> l has duration t_j+1. During t_j ordinary steps
the payload gains t_j*c, then rule l applies its affine update; therefore
the edge payload map is p -> a_l*p + (a_l*t_j*c+b_l) modulo Q. If no next
guard is reachable from R_j, ordinary translation continues forever. Every
nonterminating path has a tail and a cycle of at most k nodes. Compose the
affine maps around the cycle once, raise that affine map to the number of
whole cycles by binary powering, and execute the remaining partial edge.
The initial segment before the first guard uses the same CRT computation.
Every time interval is accounted for exactly, so the returned state equals
the original rule-by-rule process at T.

Concrete separation from small linear realization. In the one-rule fixture,
32 pairwise-coprime active counters make |G| a 324-bit integer. A guard fixes
the first 16 coordinates; it describes a set of about 2^163 states. From
active zero the first hit t has 160 bits, and the rule resets active to zero.
The observed scalar h(x)=1[x=0] on this orbit is 1 exactly at multiples of
w=t+1. Its w-by-w Hankel matrix H_ab=h(F^(a+b)(0)), 0<=a,b<w, is a
permutation matrix, so has rank w>=2^159 over every field. Any ordinary
finite-dimensional linear realization of this scalar sequence needs at
least w dimensions. The CRT/event/affine representation uses one rule node,
32 modular registers, and one payload register. This is a succinct nonlinear
symbolic representation; it does not assert a new theorem about minimal
weighted automata or Koopman spaces.

Runnable evidence. `skew_guard_jump.py` passed 5,000 seeded random small
comparisons against literal step-by-step execution, including overlapping
guards, unreachable guards, noncoprime moduli, noninvertible affine factors,
empty guards, and short horizons as encountered by the random generator.
A separate 32-counter fixture used a 521-bit payload modulus and a
4,097-bit T. The exact result matched an independently derived geometric
series formula for the one-rule affine recurrence. The huge query took
about 0.011 s on this host; see `skew_guard_jump.log`. A two-rule skew-product
fixture with noncommuting affine payload rules additionally matched a
hand-derived period-17/geometric-series formula at a 4,097-bit horizon.
A two-rule constant-reset fixture matched a separate period-17 formula;
see `guard_reset_jump.log`. The point-defect variants in
`abelian_defect_jump.py` and `sparse_defect_jump.py` passed 3,030 and 12,288
small comparisons, respectively, plus independent huge-cycle checks.
These finite checks support the implementations, not novelty or an
unrestricted theorem.

Acquisition boundary. The small event quotient is compiled from the supplied
coordinate-congruence guards, fixed active resets, and affine payload maps.
It is not discovered from arbitrary black-box dynamics. If a guard can read
p, the event schedule can depend on all Q payload values and the k-node
graph no longer follows. If ordinary active motion is replaced by a merely
fast-forwardable map, locating the next exceptional point can be hard:
for x -> a*x mod a prime and a point guard, the first-hit query can encode
a discrete logarithm. If payload maps are arbitrary functions without a
compact composition law, the cycle map need not admit this small encoding.
The result computes one state at T, not a trajectory of length T. It does
not make a T-bit exact output cheap.

Prior-art/decision. The ingredients are generalized CRT, event-driven
simulation, functional-graph cycle detection, and affine-monoid powering.
Fast-forward permutations and exact finite-state Koopman reductions are
established nearby concepts. This work provides a clean, executable
combination and a useful separation from linear rank, but the current
evidence does not justify claiming a historical or landmark discovery.

Decision for parent: retain as a scoped positive exact capability and
counterexample to the idea that small linear rank is necessary for fast
forwarding. Do not promote it as novel beyond the above conventional tools.

Trace-invariant activation of a dark relaxation mode
Date: 2026-10-10
Status: exact narrow protocol and finite synthetic discrimination. Symmetry-
breaking activation and switched observability are established methods; this
is a bounded measurement recipe, not a new-theory or landmark claim.

Interface and exact mechanism
----------------------------
Consider a stable reciprocal two-mode plant with one input/readout port. The
input impulse initializes the bright coordinate and the scalar sensor reads
that coordinate:

    xdot = M_k x,     M_k = [[-a, k], [k, -rho]],
    x(0) = e1,         y(t) = e1^T x(t),      a > rho > 0.

At k=0, y(t)=exp(-a t), so the dark decay rate rho cancels from every
unperturbed port response. A switchable, symmetric off-diagonal coupling k
mixes the two modes. When it is on,

    H_k(s) = (s+rho) / ((s+a)(s+rho)-k^2).

For k != 0 both poles are visible, with their sum fixed by the trace:

    mu_+ + mu_- = -(a+rho),      rho = -a - mu_+ - mu_-.

Thus the hidden rate can be recovered from a single scalar transfer response
without calibrating the gate strength k. This requires a pure off-diagonal
gate: diagonal rate changes would alter the trace and bias the result. At
small k, the dark-pole residue is k^2/(a-rho)^2 + O(k^4), so the mode is
identifiable but weak.

A late-time alternative estimates the slow pole by

    mu_hat = (1/T) log(ybar(t+T)/ybar(t)),
    rho_hat = k^2/(a+mu_hat) - mu_hat.

The ratio cancels unknown multiplicative sensor gain. Its finite-time bias is
controlled by the fast-to-slow residue ratio q=(R_fast/R_slow)exp(-g t):

    bias = (1/T) log((1+q exp(-gT))/(1+q)),    g=mu_slow-mu_fast>0.

Because R_slow=O(k^2), a weak gate requires a longer wait before the dark tail
dominates. The pole-sum route avoids gate calibration; the tail route avoids
fitting a full two-pole model. Both pay for the weak residue in readout noise.

Protocol and resource boundary
------------------------------
1. Establish the bright decay a, impulse preparation, sensor zero, and a
   repeatable initial condition. Record the ungated response as a null check.
2. Turn on the symmetric mixing gate, apply the same impulse, and acquire the
   scalar impulse response long enough to resolve both poles (or the late
   slow-tail pair for the ratio estimator).
3. Fit the poles and use rho=-a-mu_+-mu_-. If gate polarity can be reversed,
   compare +k and -k; the modeled response is even in k, so an odd component
   reveals sign-odd feedthrough or actuator asymmetry.
4. Repeat until the pole uncertainty and any late-tail bias are below the
   predeclared bound.

Each repeat costs one preparation/reset, one calibrated impulse, one gate
window, and a scalar time trace. The trace-sampling rate, gate duration,
actuator energy, reset time, gate stability, and readout bandwidth belong in
the physical ledger. In a noiseless order-n discrete-time realization, 2n
Markov samples suffice to form a Hankel matrix and recover a minimal model;
standard realization cost is O(n^3) arithmetic and O(n^2) storage. This is
not a noisy-sample guarantee.

For R repeated measurements of a scalar endpoint with additive independent
Gaussian noise sd sigma, choosing the most separated time t* for two known
rate hypotheses gives a nearest-hypothesis error near Phi(-5) when

    R >= (10 sigma / |y_rho1(t*)-y_rho2(t*)|)^2.

For the tail ratio, if the measured means at t and t+T are y1,y2, the
delta-method bound is

    Var(mu_hat) ~= sigma^2/(R T^2) * (1/y1^2 + 1/y2^2),
    Var(rho_hat) ~= (1 + k^2/(a+mu)^2)^2 Var(mu_hat).

The means in these formulas are in sensor units, including any unknown gain.
Gain cancels in the ratio but still affects signal-to-noise against fixed
additive noise. Offset drift does not cancel. Reset mismatch, mode drift,
gate-dependent damping, and actuator energy are outside the synthetic count
and must be measured in a physical trial.

Finite computation
------------------
Run from the task root:

    python3 work/inverse_physics_frontier/dark_mode_gate.py

The script computes the exact 2x2 matrix exponential on 2401 times in [0,12]
for rho=0.10 and 0.35, with a=1. It assumes endpoint noise sd 0.005 for
repeat planning. Results:

    gate k    largest mean gap    time     repeats for 5-sigma choice
    0.00      0 exactly           --       --
    0.06      0.001516            7.58     1089
    0.12      0.006385            7.96       62
    0.24      0.032971           10.475       3

At k=0 the traces agree pointwise despite different rho. At nonzero k, the
pole-sum formula recovers both rates without knowing k; direct resolvent
evaluation agrees with the closed form within 2.24e-16, and +k/-k responses
agree exactly. The repeat counts follow the Gaussian formula above; no noisy
physical measurements were simulated. The finite computation confirms only
the model identity and its weak-gate noise cost.

Limits and prior-art boundary
----------------------------
The gate must couple the hidden mode to the port. If k=0, or if the available
gate preserves the bright/dark decomposition, rho remains unidentifiable.
With many hidden modes, a generic gate can reveal some or all of them; the
trace formula recovers their sum only if the perturbed scalar realization is
minimal and its order is known. A single port does not assign physical labels
to hidden coordinates.

Dynamic symmetry breaking that activates dark modes is established in
spectroscopy; for example, Shrewsbury, Audhkhasi, and Povinelli show a dark
supermode coupling to an external field after symmetry breaking:
https://doi.org/10.1364/OL.484163

Switch observability is also established for switched linear systems;
see Kusters and Trenn:
https://doi.org/10.1016/j.automatica.2017.09.024

The trace-invariant pole sum gives a useful calibration-free scalar target and
an explicit cost/noise contract. It does not establish superiority to those
methods or a new physical principle. Keep this branch only if an application
already has a trace-preserving mixing gate and lacks an interior sensor.

# Scientific handoff

## Capability

The restricted scheduled model combines finite-duration exact completed corrections with overlapping finite weak pulses on disjoint reserved memory patches sharing a noncommuting persistent bath. Under the explicit reset, ideal private-frame, full-support cleanliness, exogenous timing, common-dilation/deletion-stability and uniform integrated-action premises, it yields the same exponential-in-size recovered memory bound for each deterministic endpoint T. Initial logical–bath–reference entanglement is allowed in the stated finite-dimensional setting.

The proof uses global Fourier subset effects and a correlated-death contour argument. It does not claim a causal completion-time Fourier instrument. The exact crossing counterexample disproves the proposed small chronological conditional bound, while remaining consistent with the global subset theorem.

## Evidence

The packet includes the analytic subset-moment proof, memory-only support rearrangement, local-stochastic-to-contour proof, scheduled composition and separate quantum/classical/end-to-end audits. Four exact symbolic certificates check the crossing obstruction, its independent causal-measurement realization, all seven subsets in a three-pulse example, and 16 operator/64 syndrome reordering cases. A separately labeled floating-point stress test checks 84 subset effects. These are independent internal mathematical reviews and finite examples, not external scientific validation or machine verification of the complete theorem.

## Closest prior work

Standard continuous-Hamiltonian fault-path theorems already tolerate persistent baths under bounded local or summably nonlocal couplings. Randomized compiling, stabilizer randomization and syndrome projection are established. Toom-contour existence and counting supply substantive imported combinatorics here. The tailored contribution assessed in this packet is their explicit global-subset/support/contour connection for the specified scheduled memory model. The prior-art report explains why existing amplitude bounds or discrete compiling results do not directly supply the false chronological conditional interface. Historical priority remains unresolved.

## Missing physical operation

A real device must implement and qualify the exact clean corrections, fresh resets, private frame wrappers, fixed timing/reservations and uniform full-joint integrated-action bounds, with every data/check/ancilla/frame support accounted for. The proof assumes these properties. It does not provide noisy-control qualification, arbitrary continuous-noise robustness, a useful numerical threshold, a practical 3D embedding or an autonomous finite-controller/Lindbladian realization.

## Plausible consequence

If externally verified and matched to a realizable parameter regime, this would strengthen the theory of robust quantum memory beyond instantaneous post-error models. It is a mathematical route toward such a memory, not a demonstrated storage device or a measured resource advantage. Conservative sufficient constants can be very poor; failure to satisfy them is not a physical impossibility proof.

## Finding

At the selected fixed Toom β4 endpoint, D0 reports logical mask 7, while D1 and D2 report mask 0 on the same E,S. D1 retains the strict cutoff and changes only how already-valid local fills are retained before combined fallback. The selected sweep endpoint is unchanged. This is a recovery-policy diagnostic, not a ranking of memory dynamics.

## Evidence

All four phases retain raw data, manifests, source versions and independent audits. Both phase4 endpoints and six exact recovery chains are hashed. Independent saved-data replay verifies their boundaries, residual closure and all six homology coordinates at three cuts. Original small-sample confidence intervals and normalization caveats remain intact.

## Comparator and limits

The Toom implementation is a matched Poissonized adaptation written for this study. It does not reproduce the published parallel schedule. The experiment covers the base instantaneous one-sector Pauli model with ideal readout, not the newer shared-bath or noisy-core theorems.

## Missing evidence

Population-level comparison, robust recovery-policy assessment, useful thresholds, large-size/time scaling and a hardware-matched implementation are absent. The sample is tiny, and the final endpoint was chosen after failure. No irreversible-loss conclusion follows from one decoder's failure.

## Next decision

Any future predeclared common-readout comparison should fix resource normalization, readout policies and sufficient sampling before execution. This packet contains no new experiment and makes no recommendation to expand the grid automatically. First inspect the saved endpoint diagnosis and its relationship to the chosen decoder.

# Preregistered diagnostic test protocol
Written 2026-10-15 before this worker has loaded any measured detector rows or calculated any measured counts. Existing acquisition REPORT.md was read; it already exposes whole-dataset broad diagnostics. This is an exploratory diagnostic split, not a claim of pristine confirmatory preregistration.

Condition: Google Quantum AI Willow d5_at_q8_7 / X / r50, 50,000 shots. Use only the 25,000 original row indices in measured_syndrome_audit/diagnostic_indices.txt, SHA256 80d49493e16e51d3f2cfe8574ec3316ded74e0a51ae49865165e9def979ee2ae. No reserved row values will be read. Selection is sorted SHA256('astra-willow-split-v1:'+decimal zero-based row index), first 25,000. r13 is not analyzed.

Structural family: all pairs of detectors at the same spatial check (first two coordinates), with earlier and later time (third coordinate) both in 1..49, and integer lag 2..10. Here bulk means temporal bulk, including spatial boundary checks; exclude initial t=0 and final t=50 detector layers. Six-coordinate bulk annotations also specify previous measurement spacetime; use the first triplet for detector location. Require detector coordinate agreement between ideal circuit and both provided correlated-matching RL and SI1000 prior DEMs. Keep only pairs whose incident error-line mechanism sets have empty intersection in BOTH DEMs. Report every excluded pair and overlaps; no count-based filtering, screening, pooling, or threshold selection. Expected geometric family before exclusion: 24*sum(49-lag,lag=2..10)=9,288.

DEM semantics: an expanded error instruction is one independent Bernoulli mechanism. '^' separates suggested correlated components, NOT independent mechanisms. All D targets across the entire line are XORed, so repeated identical D targets cancel. Incident mechanism sets include all lines, even degenerate probability 0 or 1 (conservative); each error line has a distinct mechanism ID. Provided files were inspected and contain no repeat or shift_detectors instructions. Parser will fail on unsupported statements, including repeat/shift, rather than silently mishandle them. If these occur, stop before measured data and revise parser/protocol with explicit offset/repetition semantics. Circuit likewise is expanded, no REPEAT/SHIFT instructions.

Null: each shot is generated from one fixed supplied independent-Bernoulli DEM; disjoint incident mechanism sets imply the two detector parity bits are independent, regardless of the marginal probabilities. The same implication holds for arbitrary fixed probability refits on this support. Across shots, standard conditional test requires IID sampling with fixed joint law; unknown drift, sweep dependence, acquisition chronology and filtering may violate this assumption.

For each retained pair, count n11,n10,n01,n00 over diagnostic shots only. One-sided positive-association exact Fisher p is hypergeom.sf(n11-1, N, n11+n10, n11+n01), conditioning on margins. One prespecified Bonferroni family over all retained pairs; familywise alpha 0.01. Adjusted p=min(1,M*p). Report per-pair margins, all four counts, n11/(N), expected joint count from observed margins, excess joint probability, covariance, sample odds ratio, phi correlation, raw/adjusted p and support-overlap counts. Degenerate margins return p=1. No pooling of within-shot pairs as independent observations. Bonferroni does not require independence among pair tests. Rank results only for reporting; output full family.

Budget: CPU <=120 seconds, RSS <=1 GiB, only own parsing/statistics code and already-installed NumPy/SciPy. No software installations or author code execution. Freeze family and its hashes before opening measured rows. Read only selected 150-byte rows via seek/read; do not load whole detection-events file. Independently check strongest table with scipy.stats.fisher_exact.

Interpretation: rejection targets the provided fixed DEM structural independence implication under the IID-shot assumption. It is not proof of quantum/non-Markovian microscopic noise, burst cause, leakage, uniform fault norm, hardware theorem, or a better decoder. Drift, sweep dependence, leakage, selection and unobserved heterogeneity remain alternatives. Reserved half stays untouched for a separately authorized, fixed confirmatory protocol; no decoder or algorithm fitting.

# Frozen exploratory calibration protocol
Frozen before loading any measured shot arrays or counts for this test. Only r13 calibration, all 50,000 shots; no r50, reserved, or diagnostic data. No decoder fit or held-out confirmation.

For every one of 24 first-round ancilla measurements, use own independently produced noiseless stabilizer reference in r13_raw_reference_structure.json: determined first measurement -> ideal constant XOR its known sweep parity, never actual noisy M0; intrinsically random first measurement -> actual raw first bit, explicitly a noisy observed gauge proxy, predictive only.

Use actual circuit DETECTOR coordinate time t=2,...,12 (zero-based circuit coordinates), 11 times for each check, 264 tests total. Verify each detector uses two consecutive raw measurements of the same qubit, matching spatial coordinates, with raw indices 24*t+j and 24*(t-1)+j. Excludes t=1 to avoid direct shared first measurement. Reconstruct each tested detector from raw bits and independently simulated ideal reference, and require exact agreement with supplied detector stream before inference.

Two-sided scipy.stats.fisher_exact for each binary detector versus binary tag. Fixed Bonferroni family alpha=0.01, threshold 0.01/264. No selective filters or threshold changes. Record all four cells, tag and detector marginal counts, risks by tag, risk difference risk(tag1)-risk(tag0), sample odds ratio for detector=1 given tag1 versus tag0, unadjusted and Bonferroni p, tag type, qubit and detector mapping. Tests with absent tag support are recorded as non-informative, not removed from multiplicity.

Under the full fixed state-independent Pauli circuit, uniform gauge variables or randomized known preparation tags should carry no additional error information. A bare RL DEM does not specify a joint distribution with raw gauge and is not itself refuted by an association. Association could reflect state-dependent readout/gates, drift, sweep nonrandomization, or noisy-proxy effects. No quantum-mechanism claim. If no signal, record null and stop. CPU limit 120 seconds, RSS target <=1 GiB, no installations or execution of authors' code. Own parsing/analysis code with installed NumPy/SciPy only.

Scientific-law discovery under finite experiments: an exact lower bound and the oracle boundary

Finding

I tested whether active experiment selection can remove expression-search explosions while preserving exact behavioral equivalence. For a broad regular class, the answer depends on whether the learner receives an equivalence oracle or only performs experiments. With only resettable membership experiments, a sharp sparse-law family forces exponentially many experiments even when every target has a DFA with only O(n) states. The mechanism that avoids expression enumeration, Angluin's residual-state learner, is polynomial only when its exact equivalence-query interface is supplied. Classical conformance testing can implement that interface efficiently when the candidate and target state counts are close, but the exponential lower bound applies when their gap is unbounded. This identifies an information bottleneck, not a new learning algorithm.

Exact interface and theorem proved here

An experiment is a finite binary word x in {0,1}*, applied from a reset state; the device returns one exact bit f(x). The target is promised to be a regular Boolean law, represented by a complete DFA. I count both experiment calls and total input symbols. No source code, state labels, or access paths beyond reset are exposed.

For each n≥1 and each w in {0,1}^n, let L_w={w}; let L_0=∅. L_0 has a one-state DFA. L_w has an (n+2)-state DFA: n+1 prefix states q_0,...,q_n plus a rejecting sink, with only q_n accepting and every wrong next symbol entering the sink. Any deterministic adaptive learner that exactly identifies every language among DFAs of at most n+2 states must make at least 2^n membership experiments on target L_0.

Proof: follow the learner's transcript on L_0, where every answer is 0. If it has not queried some w∈{0,1}^n, then target L_w gives the same answer to every query in that transcript: its only positive input is w. Adaptivity therefore follows the identical path and produces the same output on L_0 and L_w, so it must be wrong on one. Hence every length-n word must be queried on the L_0 path. This is 2^n experiments and at least n·2^n input symbols, or 2^{N−2} calls for a state cap N=n+2. The result also applies to zero-error randomized learners: because there are finitely many targets in this subfamily, almost-sure correctness on each implies a probability-one set of random seeds correct on all of them, and each such seed must query all 2^n words along the L_0 transcript.

This is not a limitation caused only by automata. For any learner that halts after finitely many experiments on a computable target P over an infinite input domain, choose a fresh unqueried input x and define Q to agree with P everywhere except x. Q is computable, gives the same transcript, and differs behaviorally. So exact finite-data certification over all computable programs is impossible without a complexity or structural restriction. The singleton family gives the stronger quantitative bound within a compact, finite-state class.

Mechanisms that do work under stated assumptions

Angluin's L* learner learns the minimal DFA for any regular language in time polynomial in its number of states and the maximum counterexample length, using membership queries plus an equivalence query that either certifies equality or returns a counterexample. Its observation table groups prefixes by residual behavior, avoiding enumeration of source expressions. This is a genuine polynomial discovery mechanism over the full regular-language class at the oracle level. The equivalence query is a strong interface: Angluin explicitly notes that it appears to require a precise representation of the target and decidable equivalence; with an explicit target DFA, product-automaton reachability answers it in polynomial time.

For black-box experiments, conformance testing supplies a bounded alternative. For a minimal specification DFA with s states, a state cover P, characterization set W, and a target implementation promised to have at most s+k states, the W-method tests P·Σ^{≤k+1}·W. The suite is complete: agreement on all tests implies full equivalence. With shortest access and distinguishing words, |P|≤s and |W|≤1+binom(s,2); suite size is at most |P||W| sum_{i=0}^{k+1}|Σ|^i, and each test has length at most 2s+k−1. Thus total symbol cost is at most suite size times 2s+k−1. This is polynomial in s for fixed alphabet and k=O(1), but exponential in unbounded k. The singleton lower bound explains why this gap cannot generally be erased by a better test selection strategy: the one-state reject-all specification faces 2^n sparse alternatives under a target cap n+2. Sequential Mealy-machine versions cover output-producing experiments as well, with the same bounded fault-domain qualification.

For noisy or costly science, a principled relaxation is distributional rather than exact. Fix a candidate before drawing r fresh validation experiments from a declared distribution D. If its disagreement probability with the target exceeds ε, the chance of seeing no disagreement is at most (1−ε)^r≤exp(−εr). Thus r≥ln(1/δ)/ε gives a one-sided confidence certificate against disagreement mass greater than ε. This is a validation guarantee, not proof of global law equality; a rare singleton may have negligible D-mass. Angluin's paper also gives a stochastic L* variant with sampling in place of exact equivalence queries, proving polynomial approximate identification under its stated distributional assumptions.

Prior art and novelty status

The main ingredients are established results, and no novelty claim is made. Dana Angluin, “Learning Regular Sets from Queries and Counterexamples,” Information and Computation 75 (1987), https://homepages.math.uic.edu/~lreyzin/papers/angluin87.pdf, states the membership/equivalence-query model and the polynomial L* theorem; the paper itself discusses why equivalence queries are problematic in black-box settings. T. S. Chow, “Testing Software Design Modeled by Finite-State Machines,” IEEE Transactions on Software Engineering 4(3) (1978), DOI https://doi.org/10.1109/TSE.1978.231496, is foundational conformance-testing prior art. The current primary source Bálint Kocsis and Jurriaan Rot, “Complete Test Suites for Automata in Monoidal Closed Categories,” FoSSaCS 2025, https://link.springer.com/chapter/10.1007/978-3-031-90897-2_10, states the complete-test-suite definition, W-method construction, n+k completeness, and recovery for DFA, Moore, and Mealy machines. In particular, it notes that black-box testing cannot be exhaustive without a restricted fault domain. The lower bound above is an elementary reconstruction for the exact membership-only protocol; it is not a claimed new automata-learning theorem.

Significance and limits

The achieved result is a precise obstruction: state-bounded realizability alone does not permit polynomial-cost, exact experimental law identification when candidate/target state gap can grow. The useful alternative is to expose the missing resource—an equivalence oracle—or weaken the requirement to a declared distributional error bound. A possible landmark consequence would require proving that an important scientific domain has an experimentally justified bounded fault gap, or that its relevant laws admit a polynomial-size set of discriminating experiments independent of sparse exceptions. Nothing here establishes that for physical laws, continuous-valued measurements, stochastic dynamics, or noisy sensors. The discrete exact model is a diagnostic boundary case only.

Next proof gate

For a specified scientific measurement protocol, formalize the experiment alphabet, output precision/noise model, target state or program-size bound, reset assumptions, and what counts as a scientifically relevant disagreement. Then prove either (i) a lower bound matching the singleton construction under those constraints, or (ii) a polynomial complete suite with all experiment costs charged. Until that gate is met, exact broad autonomous discovery remains unproved.

09 — Adaptive predictive compression: representation exists, uniform acquisition does not

Verdict. Observable predictive state is a sound model-free representation: it stores probabilities of future experiments rather than a supplied latent state. Exact low-rank systems can therefore admit compact state updates and support simulation or planning. I tried to turn that representation into an operational learner that certifies its compression from reset-and-intervene samples, with no latent model, on every reachable history. The route fails without a coverage condition. A two-environment construction proves that even a generous simulator interface cannot distinguish a one-dimensional from a two-dimensional predictive continuation in fewer than order 1/p rare-context visits. Setting p inversely proportional to the planning horizon makes the missed distinction change a bounded-reward horizon-H value by one. This is an acquisition obstruction, not a representation impossibility.

Target and interface. The desired capability is a learner which, from action/observation/reward traces, returns a compressed predictive state, update/readout rules, and a certificate that every positive-probability history has future-test prediction error at most ε. The interface grants independent resets to a fixed initial distribution and lets the learner choose actions adaptively from observations; it returns only the resulting observations and rewards. The learner cannot set a latent state or ask for exact conditional probabilities. A useful certificate must cover all reachable histories and all forced future action sequences up to horizon H. The consequence sought is trustworthy long-horizon simulation and inference with state size tied to predictive complexity rather than hidden-state count.

Exact representation route. For a controlled process, let a history h be an observed action/observation trace, and let a test t be a forced future action sequence together with a specified future observation/reward event. The controlled Hankel matrix has entries K[h,t]=P(t|h), or equivalently joint entries P(ht) after scaling each row by P(h). Histories are behaviorally equivalent when all such continuation probabilities agree. A basis of continuation predictions is a predictive state; if the Hankel matrix has finite rank r, its row space gives an r-dimensional linear state and the usual observable-operator updates propagate predictions. This construction is independent of latent-state semantics. It is also operationally attractive: once a core set of histories/tests and update operators are known, repeated simulation can update an r-vector rather than filter a postulated latent-state distribution. With dense operators over event alphabet E, each update costs O(r²) arithmetic and stores O(|E|r²) coefficients, apart from the core basis.

The decisive step is whether a learner can discover and certify that basis from traces without a promise that informative histories are covered. Here is a finite, exact counterexample. Fix H≥2 and p=1/H, and even tell the learner H and p. Each reset episode starts with observation X∈{R,N}, with P(X=R)=p. It then has H action/reward rounds. At each round the learner chooses a∈{0,1} and observes reward Y. In environment E0, Y=0 always. In environment E1, Y=1 exactly when X=R and a=1; otherwise Y=0. This is a controlled stochastic process with an observable history, not a given latent model. Both candidates have the same initial observation law.

After the first observation, consider the two histories h_R=(R) and h_N=(N), and the continuation tests e=empty and t=(force action 1, then observe reward 1). The local conditional Hankel blocks, with rows h_R,h_N and columns e,t, are

E0: [[1,0],[1,0]], of rank 1;
E1: [[1,1],[1,0]], of rank 2.

Equivalently, the joint blocks are [[p,0],[1-p,0]] and [[p,p],[1-p,0]], respectively; the second determinant is -p(1-p)≠0. Thus in E1 the continuation state after R cannot be merged with the state after N: action 1 has different future reward predictions. In E0 those continuations can be merged. Rank here concerns this same-stage continuation problem; no claim about the rank of a time-homogeneous encoding of episode phase is needed.

Now run any learner for m reset episodes, allowing fully adaptive actions and arbitrary internal randomness. Couple the two environments using the same initial X and learner randomness. If X=N in every episode, all observed traces coincide in E0 and E1, for every action rule. This event has probability (1-p)^m. Hence the total variation distance between the two transcript laws is at most 1-(1-p)^m. By the two-point testing bound, any algorithm forced to label the continuation rank as 1 or 2 has average error at least (1-p)^m/2 under an equal prior. An algorithm allowed to return UNKNOWN must abstain on at least one candidate on the common transcripts. To reach error at most α<1/2, it needs

m ≥ log(1/(2α)) / [-log(1-p)] = Ω(p⁻¹ log(1/α)).

For p=1/H and m≤H/4, Bernoulli's inequality gives (1-p)^m≥3/4, so the average rank-classification error is at least 3/8. The bound counts m reset trials; fully running every trial costs at most Θ(mH) action/reward observations, while a learner can stop each trial after the first continuation. This is an exact lower bound for the stated interface, not a simulation or empirical estimate. It falsifies any universal sample bound independent of rare-history coverage for a uniform reachable-history certificate.

The value consequence is concrete. Under the fixed policy that always chooses a=1, E0 has expected H-step return 0, while E1 has expected return pH=1. If no sampled episode contains R, both data sets are identical, yet a simulator fitted by merging the two continuations predicts the wrong return by one in E1. The issue persists with bounded per-round rewards; a low-probability predictive distinction can accumulate across a long horizon. More generally, the conditional error after h_R is one even though its training frequency is only 1/H. A certificate for average error under a declared visitation distribution may tolerate this; a certificate for every reachable history cannot.

Prior art and boundary. The representation idea itself is established. Singh, James, and Rudary, “Predictive State Representations: A New Theory for Modeling Dynamical Systems” (UAI 2004), derive PSRs from the system-dynamics matrix: https://web.eecs.umich.edu/~baveja/Papers/uai2004psr.pdf. Thon and Jaeger, “Links Between Multiplicity Automata, Observable Operator Models and Predictive State Representations” (JMLR 2015), unify the algebraic model and learning viewpoints: https://jmlr.org/papers/v16/thon15a.html. Boots, Siddiqi, and Gordon, “Closing the Learning-Planning Loop with Predictive State Representations” (RSS 2010), report learning from action-observation traces and planning in the learned model: https://arxiv.org/abs/0912.2385. Balle and Maillard, “Spectral Learning from a Single Trajectory under Finite-State Policies” (ICML 2017), analyze spectral learning from dependent data for probabilistic automata and reactive PSRs: https://proceedings.mlr.press/v70/balle17a.html. These results show that an unknown latent model is not itself fatal. Their exactness or guarantees rely on basis, rank/separation, sampling, or policy regularity conditions; the construction above isolates the coverage condition needed for a uniform certificate. Jiang, Kulesza, and Singh, “Completing State Representations using Spectral Learning” (NeurIPS 2018), explicitly note low-data difficulties for standard spectral PSR discovery and use a supplied imperfect state representation to improve it: https://proceedings.neurips.cc/paper_files/paper/2018/file/8f14e45fceea167a5a36dedd4bea2543-Paper.pdf. This is consistent with, but does not prove, the lower bound here. I make no novelty claim for the model class or exact construction; it serves as a scoped falsifier for this access model.

Achieved versus potential significance. Proved here: a sample-only learner cannot uniformly certify adaptive predictive compression over all positive-probability histories without a lower bound on discovery/coverage, even with reset access; a missed 1/H event can induce unit horizon-H return error. Known: predictive states and spectral learning provide compact observable models when suitable core statistics are available and identifiable. Unproved: an adaptive acquisition algorithm with a useful uniform certificate under explicit coverage and conditioning assumptions, or a faster simulation result against a matched full-history baseline. The potential landmark is a model-free, finite-sample certificate that discovers the smallest task-relevant predictive state while preserving long-horizon values. The present result instead identifies a necessary price: either cover rare continuations, weaken the certificate to a stated distribution of histories, or propagate uncertainty for the unseen branch.

Next proof gate. Fix an explicit access model with reset episodes, finite alphabets, horizon H, minimum discovery probability μ for each required core history, and smallest nonzero singular value σ of a core Hankel block. Then prove or refute an adaptive acquisition bound polynomial in r, |A||O|, 1/μ, 1/σ, 1/ε, and log(1/α) that outputs a replayable predictive-state certificate and yields a horizon-H value-error bound against the retained full-history predictor. A construction must charge exploration and verify the certificate on all reachable one-step extensions; a failure must identify whether μ-coverage, σ-conditioning, or output-size is the remaining barrier.

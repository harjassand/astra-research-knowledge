Active interventions for a hidden sparse gate

Verdict

I derived a finite-sample intervention design that identifies a sparse hidden parent set despite arbitrary observational confounding in the candidate inputs. It measures only the target output and reduces the number of measured outcomes to O(k^2 log^2(n/delta)/gamma) for support size at most k and a response floor gamma. The result is a conditional construction, not a novelty-cleared mathematical advance: it is a direct noisy group-testing reduction, and active group interventions already have causal-debugging precedent. The decisive negative is that unrestricted hidden mechanisms defeat low-cost support discovery even with perfect access to every joint intervention.

Interface and assumptions

There are n binary, manipulable inputs X_1,...,X_n and one binary output Y. The unknown causal parent support S is a subset of [n] with |S| <= k. A pre-treatment latent state U may arbitrarily correlate the natural input values. Let Z=h(U) be a latent binary gate and let the target structural equation be

    Y = Z AND (AND_{i in S} X_i).

The law of U is invariant across experiments; U and Z are never intervened on. An experiment may surgically set every X_i to a chosen bit vector x, leaving the mechanism for Y and U unchanged. Experimental units are independent draws of U. Only Y is measured; the forced input vector is known from the intervention. A known lower bound P(Z=1) >= gamma > 0 is supplied. No observational support or faithfulness condition is assumed. There is no interference across units or post-intervention selection.

This permits substantial hidden confounding: U can determine all natural X_i and Z. The restriction is on the target mechanism and on surgical intervention stability, not on the observational distribution of X. The support here means the direct arguments of this gate; it does not identify internal hidden structure that generated Z.

Construction and proof

For any test set T subseteq [n], intervene with X_i=0 for i in T and X_i=1 otherwise. Then

    P(Y=1 | do(X_T=0, X_[n]\T=1)) = p if T intersect S is empty,
                                      0 otherwise,

where p=P(Z=1)>=gamma. Thus an intervention is an OR group test of S, with the positive response observed through a latent Bernoulli gate. If T hits S the output is always zero; if T misses S each independent replicate returns one with probability p. The observational distribution can hide S completely, but this intervention response cannot.

Here is a nonadaptive finite-sample decoder. Draw m rows independently, putting each input into each T_r with probability 1/(k+1). Repeat each row t times and label it “clear” if at least one output is 1; otherwise label it “hit.” Include input j in the recovered support exactly when every row containing j is labeled hit.

Assume 1 <= k < n. For any true support S of size at most k and any j not in S, one row contains j and avoids every member of S with probability

    (1/(k+1)) (k/(k+1))^|S| >= 1/(4k).

With m >= 4k[(k+1) ln n + ln(2(k+1)/delta)], a union bound over all pairs (j,S) makes the random matrix k-disjunct with probability at least 1-delta/2. On this event, every non-parent j has a row containing j but avoiding S. In that row, t replicates all miss a one with probability (1-p)^t <= exp(-gamma t). Taking t >= ln(2n/delta)/gamma and union-bounding over the n non-parents gives support recovery probability at least 1-delta. A true parent is never wrongly removed, since every row containing it intersects S and hence yields only zeros. The total number of measured output bits is

    m t = O((k^2 log n + k log(1/delta)) log(n/delta)/gamma).

For fixed k and gamma this is polylogarithmic in n, and the measurement interface reads one output bit per experimental unit. Generating and decoding a dense representation of the random matrix takes O(mn) bit operations and bits of storage. The experiment count is m distinct intervention settings, each repeated t times. Each setting forces all n inputs, so the design's intervention manipulation cost is n m t assignments if every unit is charged separately. This is a measurement saving under full vector-intervention access, not a claim that all experimental costs are sublinear.

The noiseless OR-query problem has M=sum_{s=0}^k binom(n,s) possible supports, so any binary-response procedure needs at least log_2 M queries in the worst case; for k<=n/2 this is Omega(k log(n/k)). Standard adaptive group testing meets this order in the noiseless setting. The finite-sample nonadaptive construction above has a factor-k-type gap and an extra repetition factor; I have not closed it. When k=0 the support is known without experiments.

Beyond observational identifiability

Let U be Bernoulli(1/2), set every natural input X_i=U, set Z=U, and use the gate above. For every S, including the empty set, the observational vector satisfies X_1=...=X_n=Y=U. Thus the entire observational law is identical for all supports. Under an intervention setting T to zero and all other inputs to one, however, P(Y=1) is 1/2 exactly when T avoids S and is zero otherwise. The active design identifies S despite this observational equivalence and despite the common latent cause U. This proves the construction's claimed scope, conditional on the supplied gate form and response floor.

Decisive falsifier and scope boundary

The sparse-gate assumption is indispensable. For arbitrary deterministic black-box mechanisms, compare f_empty(x)=0 with f_z(x)=1[x=z], for an unknown z in {0,1}^n. Every variable is an essential parent of f_z. Any intervention query x other than z returns zero under both models. A worst-case algorithm using fewer than 2^n distinct input assignments leaves some z unqueried and therefore cannot distinguish empty support from full support. This lower bound holds with causal sufficiency, noiseless measurement, and full intervention access. If the response floor is removed, the gate construction itself also fails at p=0: all interventions return zero for every S. Consequently, the result does not establish cheap discovery for general hidden mechanisms; it identifies the exact extra structure that makes sparse discovery possible.

Prior art and novelty audit

Anna Fariha, Suman Nath, and Alexandra Meliou, “Causality-Guided Adaptive Interventional Debugging,” SIGMOD 2020, https://doi.org/10.1145/3318464.3389694, explicitly applies adaptive group testing through simultaneous interventions and reports O(D log N) as a standard group-testing upper bound. Its setting is causal software debugging with candidate predicates and an approximate causal DAG, not this latent-gated structural equation. It nevertheless blocks any claim that group interventions plus sparse support search are new in themselves.

Bijan H. S. Mazaheri, Jiaqi Zhang, and Caroline Uhler, “Relaxing Faithfulness with Intervention-Only Causal Discovery,” UAI 2026, https://arxiv.org/abs/2607.11816, gives nonparametric DAG recovery from hard interventions under intervention-immediacy faithfulness, allowing path cancellations that defeat ordinary observational CI discovery. Their UIC result uses O(n^2) intervention distributions, with intervention sets as large as n-1; their stated model is causally sufficient. This is a much broader structural result than the gate construction, but it does not cover latent confounders. Their exact setting makes the unobserved-confounder assumption material, not optional.

Zihan Zhou, Muhammad Qasim Elahi, and Murat Kocaoglu, “Characterization and Learning of Causal Graphs from Hard Interventions,” NeurIPS 2025, https://proceedings.neurips.cc/paper_files/paper/2025/hash/6ff3e124a89678abb0dd5ffc322f0700-Abstract-Conference.html, characterizes intervention equivalence classes with latent variables and proposes a sound learning algorithm from hard-intervention invariances. This establishes that latent-confounded interventional discovery is active prior art, while also emphasizing equivalence-class output rather than universal point identification.

Status and next gate

Proved here: the gate response identity, the disjunct-matrix decoder, the stated finite-sample bound under independent units and p>=gamma, the observational-equivalence example, and the 2^n black-box obstruction. Known: group-intervention causal debugging and intervention-only DAG learning under cancellation-tolerant faithfulness. Conditional: sparse gate recovery with arbitrary natural-input confounding, given surgical full-vector interventions and a supplied gamma. Refuted: any blanket low-cost support-identification claim for unrestricted black-box mechanisms. Unproved: novelty, an optimal noisy/adaptive sample bound, and any extension to more general latent target mechanisms.

Next proof gate: either (a) derive and compare a minimax lower bound for the noisy latent-gated group-test interface, closing the O(k^2 log^2 n/gamma) versus Omega(k log(n/k)) gap, or (b) find a genuinely non-group-testing class of hidden mechanisms for which active interventions yield a strict information-cost advantage under explicit confounding assumptions. Until that gate, report this as a scoped reduction and obstruction, not a landmark breakthrough.

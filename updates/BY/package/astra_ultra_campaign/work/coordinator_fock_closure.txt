1. An exact weighted number identity
Let q<infinity modes have total number N and W=1+N. For integer k>=0 and a finite-particle vector psi,

 ||W^(k/2) psi||^2 = sum_{j=0}^k S(k+1,j+1) sum_{i_1,...,i_j=1}^q ||a_{i_1}...a_{i_j} psi||^2.   (1)

Here S denotes Stirling numbers of the second kind; the j=0 term is ||psi||^2. Indeed, on an occupation vector with total occupation M, the inner sum is M(M-1)...(M-j+1), by counting ordered particle removals. This is diagonal, so it holds on every vector in the form domain. The polynomial identity (M+1)^k=sum_j S(k+1,j+1) M_under_j follows by induction using M M_under_j=M_under_{j+1}+j M_under_j.

Every ordered mixed creation/annihilation word b_1...b_j maps an occupation vector to a scalar times one occupation vector or zero. Its squared coefficient is at most (M+j)^j. Its fixed occupation shift is injective on nonzero images, so there are no cross terms between distinct input occupation vectors. Consequently, for j>=1,

 ||b_1...b_j psi|| <= j^(j/2) ||W^(j/2) psi||.   (2)

2. Explicit Bogoliubov graph bound
Let U implement a homogeneous finite-mode Bogoliubov transformation U* a_i U=sum_l(alpha_il a_l+beta_il a_l*). Put L=max_i sum_l(|alpha_il|+|beta_il|). Then

 ||W^(k/2) U psi|| <= C(q,k,L) ||W^(k/2) psi||,
 C(q,k,L)^2=1+sum_{j=1}^k S(k+1,j+1) q^j L^(2j) j^j.  (3)

Proof: expand each transformed annihilator word, apply (2) and the triangle inequality; its coefficient absolute sum is at most L^j. There are q^j ordered annihilator words. Apply (1) and W^j<=W^k spectrally. The bound is intentionally loose and depends on q,k,U.

3. Weighted trace continuity
Write B_p={X: W^p X W^p is trace class}, norm ||X||_p=||W^p X W^p||_1. For a retained subsystem, (W_out^p tensor I) W_tot^(-p) is a commuting spectral contraction. Equation (3), with k=2p, implies K=(W_out^p tensor I) U W_tot^(-p) is bounded. Factor X=W_tot^(-p) T W_tot^(-p). The reduced weighted output is Tr_env(K T K*). Thus

 ||Tr_env(U X U*)||_p <= ||K||^2 ||X||_p.  (4)

The partial trace estimate holds for all trace-class T, by duality with the isometric amplification Y -> Y tensor I on bounded operators. Positive truncations and linearity identify the factorized operator with the actual reduced state. This avoids the invalid inference A<=B => A^p<=B^p for p>1.

5. Logarithmic slicing
If 0<=H_s<=C W_s^4 as forms, W_s^(-2) H_s W_s^(-2) is bounded. Pair it with W_s^2 delta_s W_s^2 in trace duality. 6. What this establishes and what it does not
Equations (1)-(4) are analytic statements with complete elementary proofs for the campaign's finite-mode Gaussian unitary. They supply the exact non-passive replacement for total-number preservation. They do not establish the entropy-Hessian interpolation or the signed defect inequality. The full EPnI additionally needs the exact Gibbs regularity argument, the four-weight theorem, dual norm summability, and the thermal limit. Constants can grow rapidly with gain and mode count; these estimates are domain-control tools, not an efficient experiment or numerical sampler. All review here is model-assisted; no external correctness or priority conclusion follows.

# Protected, unconsumed validation data

The numeric microscopy sequences 118um_ROS.tif, 118um_Nuclear dye.tif, 224um_ROS.tif, and 224um_Nuclear dye.tif, inside microscopy/Figure 2a/, are protected holdouts for the predeclared ferroptosis transport test. Only file headers (dimensions, frame count, image mode, descriptive tags) were inspected. No pixel data were used in this pass. Do not inspect or fit them opportunistically after seeing discovery outcomes. A future use requires a separately documented hypothesis, estimand, extraction rule, and explicit account of already-exposed qualitative published crossing categories.

The 35/156 micrometre discovery images were also not numerically inspected, because the source-history/measurement feasibility gate failed first. No inference is being withheld: this pass has no numeric ferroptosis model outcome.

Source16.xlsx and the original 7z archive contain the corresponding source data and must be treated consistently with these protections. Downloading or storing a file did not itself constitute numerical outcome inspection.

PAGE 1 — output-coordinate composition and intensity

PAGE 2 — simultaneous parity sparsification
C_nu(ell) = nu{v: ell(v)=1}.
e^(-rho) C_nu(ell) <= C_nutilde(ell) <= e^rho C_nu(ell), for every ell in V*.
C_ell = sum_(j:ell(v_j)=1) w_j >= k_i w_i, for any cut containing v_i.
p_i = min(1,alpha/k_i); retained weight w_i/p_i.
Pr[|Ctilde_ell-C_ell| > eta C_ell] <= 2 exp(-eta^2 alpha/3).
alpha >= 3[D log 2 + log(2/delta)]/eta^2.
E|S| <= D alpha(1+log N).
B = 64(D alpha+1)^2, enlarged to hold leaf summaries.

PAGE 3 — polynomial leaf and adaptive outside-subspace counts
M = O(2^d [D+log(1/delta)]/eta^2).
rho = 2 H eta, when eta<=1/2.
nu(V\W) = 2 E_(ell uniform on W-perp) C_nu(ell).
The same relative bound holds for nu{v:L v notin W}, including adaptive L,W.

PAGE 4 — true conditional descent and heatbath innovation
At concatenation A followed by B:
a_A = nu_A{v:L C_B v notin W}; a_B = nu_B{v:L v notin W}.
Left descent changes L to L C_B; right descent retains L.
Leaf proposal acceptance, when positive, is at least 2^(-d).
2 nu(v) [(f(x)+f(x+v))/2-f(x)] = nu(v)[f(x+v)-f(x)].
Conditional on proposed marks, endpoint is uniform on their span; <=D rank increases.

PAGE 5 — endpoint coupling and error allocation
a = 2 nu(V\W); exponential wait, true conditional outside mark, enlarge W, horizon 1.
d_TV <= O(D H rho) + delta_prep + delta_caps + delta_arith.
eta = c epsilon/(D H^2); rho <= 2 H eta, for sufficiently small absolute c.
An example eta=epsilon/(100 D H^2) may be reduced by an absolute factor.
Uniform span sample plus composed clean output is the full joint endpoint.

PAGE 6 — finite-bit clock precision
A = twice total positive root-summary weight.
Rounded cumulative-arrival boundary failure is O(D^2 A Delta).
Delta = O(epsilon/[D^2 max(1,A)]).
T = -log(U)/a; tiny-U tail O(epsilon/D), overflow beyond 2 treated as stop.
Precision depends polynomially on log A, log inverse smallest positive rate, log(1/epsilon).

Next decisive experiment for chemical quantitation
Status: prospective and unperformed. Main recommendation HOLD.

Output and fair comparison
Absolute desired-structure yield and minor-regioisomer amount in a specified Cernak crude matrix, with uncertainty and recovery. Candidate and strongest allowed incumbent receive the same measurements. Independent reference values remain blinded until predictions freeze. Reference preparation is charged as validation expenditure; any standards or extra measurements needed operationally are also charged to that method. Withholding standards from a candidate does not make the existing standards-free mass-balance or isotope methods new.

First resolve the existing-data interface
Acquire one complete actual sample run plus its raw pure calibrations, full caffeine spectrum, calibration recipes and exact processing arguments. Reconcile the amount denominator, normalization, sample mapping and unit contract. Shared dilution cancels in the source product/caffeine ratio; do not rescale yields from a code comment. The numerical point/error export mismatch is a code fact, while downstream handling is unknown.

Minimum physical discriminator
Use the same disputed actual crude sample for (a) the existing multiwavelength assay and (b) an orthogonal, quantitatively calibrated structural measurement with authentic co-spikes, uncertainty and recovery. If archived material does not exist or the reference is insensitive at the screening amount, reproduce the exact recipe at a reference-compatible scale and measure the transfer to the screening scale. Do not claim that larger-scale NMR automatically validates an individual nanomole well.

Pilot
Pure desired product, pure regioisomer, an independently prepared1:1 mixture and matrix blank, in clean and claimed crude matrices. Prepare calibration and validation stocks separately so common stock error cannot validate itself. This pilot can falsify gross cross-talk or normalization; it cannot exclude an arbitrary in-span interferent in every real sample. Quantitative19F NMR is a candidate for the fluorinated pair only after measured sensitivity, separation, relaxation and recovery permit it.

Expansion only after pilot survival
The saved detailed contract proposes60 held-out mixtures,20 calibration preparations and4 blanks across two independent batches. Set accuracy and interval-coverage targets from the intended synthesis decision before unblinding; these counts alone provide no power guarantee. Record minor-product false calls and unresolved samples as well as absolute errors. An apparently optimal existing label separated by0.00311percentage points does not warrant an operational ranking without corresponding calibration precision.

Strong incumbent and costs
Use source authentic-standard regression, GLS/NNLS with shared noise and calibration uncertainty, time-resolved MCR/PARAFAC2 where applicable, standard additions and orthogonal resolved LC/qNMR. Existing standard-free mass-balance methods must receive the same transfer controls as a new candidate. Count synthesis/purification, standard characterization, all injections, rejected samples, drift checks, instrument and operator time, chemicals/solvents, conversion, computation and recovery. Treat reference-only standards separately from recurring operational costs, and report both.

Decision after measurement
GO only if a distinct operation reaches the desired chemical output at the prespecified accuracy and complete matched cost, survives hidden-product/matrix controls and retains a credible novelty case.
HOLD if quantitative reference, raw mapping, scale transfer or physical selectivity remains unknown.
STOP if an equally informed existing method matches the output without greater complete cost, or if independent truth defeats the proposed accuracy.

Acquired alternatives
s02 supplies genuine retrospective assay interfaces with independent source references; their narrower ratio/generic-yield outputs and remaining raw-reference provenance gates are explicit. s04 supplies a source-reported same-parent-crystal X-ray absolute-configuration reference paired with fragment ED, original data and deterministic-fill provenance; its structural refinement was not independently rerun here. These are concrete validation access gains. Neither substitutes for the chosen Cernak structure-specific output, and neither establishes a new operation.

Manufacturing and scientific-control operation: single-drive mechanical state writing
2026-10-15
Decision: STOP the new-capability claim. HOLD a specific calibration experiment.
No qualifying new manufacturing/scientific-control operation was demonstrated.

This lane explicitly abandoned the attached-loop, septa, clearance-thermal,
and snapshot constructions. It tested an independent mechanism: use ordinary
springs, rigid rotors and stops to write a desired physical configuration with
one global displacement, despite unknown initial state, while avoiding a large
reset excursion. It did not optimize a synthetic material surrogate.

1. What was actually acquired

Public experimental source data and code from Joseph D. Paulsen's rotor
experiments, figshare 28856705 version 1, were downloaded without an account.
The workbook, exact kinematic notebook, and transition-graph notebook match
the source MD5 values. The workbook is 39,870 bytes and its SHA-256 is
c0777abf20bf77d7f24ba3b179c4435e28e498f9c9ecf0eb204c3b1472da1a13.
These are source experiments, not experiments executed by this worker.

The workbook contains 67 force/length points for three spring examples,
32 conditional threshold measurements at four coupling-arm settings,
eight measured conditional thresholds for one two-rotor latch, and 16 event
rows tracing a four-rotor cycle. The last eight rows repeat the first eight.
The source also includes model predictions, which were kept distinct.

The strongest fabrication/control incumbent already has a modular assembled
hardware platform with spring calibration, adjustable geometry, and physical
demonstrations of latching, counting, and period-two behavior [1,2]. Earlier
serial beam systems implement finite-state processing [3]. A 2025 robot uses
reprogrammable mechanical sequencing with one actuator [4]. Reset words and
constraint-aware synchronization are established automata concepts [5].
Simple sequential kirigami and a generic state-graph compiler are therefore
not defensible new operations.

2. A decisive obstruction on actual measured thresholds

At global displacement gamma=0, the measured two-rotor latch has the stable
states -- and +-. The eight recorded thresholds (cm) are:

                         other -       other +
 rotor 1 up                 6.7           17.7
 rotor 1 down              -1.5            9.7
 rotor 2 up                24.9           30.7
 rotor 2 down               2.1            7.3

The latched state +- has only two possible exits under a quasistatic drive:
rotor 1 switches down below -1.5 cm, or rotor 2 switches up above 30.7 cm.
Consequently EVERY waveform remaining in [0,30.7) leaves this state unchanged,
regardless of the number or order of subthreshold reversals. There is no
non-saturating positive-only reset hidden in a more clever pulse sequence.
This is an invariance proof for the measured-threshold model, not a finite
search over waveforms.

If each threshold stays within +/-0.1 cm, the interval [-1.4,30.6] is common
to every model in that uncertainty box. In particular, every waveform in
[0,30.6] remains unable to reset +-. The published set pulse (10 cm and back)
and reset pulse (32 cm and back) behave as expected in the measured model.

A direct bidirectional reset is the important matched comparator: -1.8 cm
and back resets either stable state at zero even if each threshold and each
commanded endpoint has +/-0.1 cm error. A 7.0 cm pulse sets +-. The former is
3.6 cm commanded round-trip travel, versus 64 cm for the published positive
reset. This is a displacement comparison only, not a demonstrated reduction
in work, energy, time, fatigue, or total cost. The source measured a negative
threshold, but this worker did not physically execute the proposed negative
reset. A real one-sided actuator or obstruction would need to be shown before
excluding that comparator.

audit.py exhaustively executed 8,192 corner trajectories over the threshold
and endpoint boxes. All four stated protocols produced the intended outcome.
Those checks corroborate the model calculations. They do not establish that
wear, rate effects, preload drift, backlash, or actuator error stay in the box.
No repeated threshold/fatigue dataset or independent hardware was acquired.

3. The physical model cannot silently replace measured thresholds

An independent translation of the source's full finite-rest-length spring
torques reproduces all eight published kinematic predictions to 2.75e-5 cm
(the publication's rounding). The maximum discrepancy between that reproduced
model and the actual measurements is 0.4499 cm. This exceeds the source's
stated +/-0.1 cm displacement measurement uncertainty. It is model discrepancy,
not evidence that the experiment is invalid.

There is a sharper test of the simplified shared-J hysteron representation.
For rotor 2, half the measured splitting between neighbour states is -2.9 cm
on the up branch and -2.6 cm on the down branch. Under +/-0.1 cm error per
threshold, the possible J intervals are [-3.0,-2.8] and [-2.7,-2.5]. They are
disjoint. At least +/-0.15 cm per threshold would be required just to make
the intervals touch. Thus one common J cannot be used as exact acquired
physical truth at the stated ruler uncertainty. Keep the eight conditional
measurements or validate a wider error model.

For the four-rotor example, the workbook supplies eight unique events along
the repeating cycle, not a measured table for every state and intervention.
A numerical graph reconstructed from the source's designed matrix is not a
complete experimental control graph. Its code explicitly modifies one model
threshold to match an observed avalanche ordering. Therefore all-initial-state
synchronization or new reachability claims need measurements of the relevant
unobserved transitions. Replaying the observed cycle does not provide them.

4. Joint physical realizability, with exact restricted mathematics

JOINT_REALIZABILITY.txt derives a necessary and sufficient threshold-realization
criterion for symmetric-stop, zero-rest-length spring networks. If h_i>0 is
the half-width and J the desired interaction matrix, one needs BOTH

  a positive diagonal D with DJ symmetric;
  a positive vector v satisfying (diag(h)+J)v=1.

The note gives a construction, a bound excluding stable interior equilibria,
and two exact failures. A directed three-cycle with clockwise couplings 2 and
counterclockwise couplings 1 fails the cycle-product condition (8 versus 1).
Even a sign-compatible two-node matrix can fail jointly with desired widths:
h=(1,1), J_12=3 and J_21=1/10 gives v=(-20/7,9/7).

This is conditional internally derived mathematics. It does not apply as an
exact theorem to the real finite-rest-length springs, certify a fabricated
network, or establish novelty. It specifically prevents composing independently
attractive threshold values and spring couplings into an unqualified device.

5. Narrow next discriminator: test the calibration interface itself

If a hardware owner wants to continue, first replicate a three-rotor fixture
and hold two neighbours in all four +/- configurations while measuring the
central rotor's up and down thresholds. For each branch form

  C = gamma(++) - gamma(+-) - gamma(-+) + gamma(--).

An additive pairwise threshold model predicts C=0. With finite-rest-length
driving springs, torque is additive but converting total torque to a drive
threshold is nonlinear. The full published kinematics predicts nonzero C.
This is a test of representation adequacy, not a new mechanical functionality.

triad_discriminator.py specifies a concrete source-scale fixture using the
0.46 N/cm spring example fitted from all 29 measured points. Its fit is
k=0.458533 N/cm and rest length 3.89403 cm. It uses stop half-angles 18.3 and
38.8 degrees, 15.24 cm neighbour spacing, 4.731 cm coupling arms, a 6.31 cm
drive arm, and 9.4 cm rod separation. The predicted contrasts are -1.2033 cm
(up) and +1.2033 cm (down). Setting only the drive spring rest length to zero
makes the contrasts vanish numerically, identifying the mechanism.

Predicted spring lengths at the eight threshold endpoints are 13.54–23.43 cm,
inside that source spring's measured 5.791–32.591 cm range. This fixes a material
range mismatch in the first 0.19 N/cm version, whose predicted extensions ran
beyond that spring example's supplied calibration range. It does NOT mean the
same calibrated specimen exists in every required position. Individual springs,
friction, mid-motion lengths, all swept volumes, and the assembled fixture
remain unverified. The strong spring's fit residual reaches 0.0578 N; that
finite sample residual is not a uniform force-law guarantee.

With a demonstrated +/-0.1 cm bound on each threshold, C has worst-case
measurement error +/-0.4 cm, smaller than the predicted contrast. Randomize
the four held-neighbour settings, repeat both loading directions at two ramp
rates, and bracket every run with the uncoupled calibration. A measured C
consistent with zero after this protocol rejects the proposed finite-rest
effect at this scale. A reproducible nonzero C rejects the additive threshold
surrogate; it does not prove a new capability, fundamental nonreciprocity, or
new material interaction. One rotor's nonlinear drive coordinate can absorb
such apparent higher-order terms. The known full kinematic model is the
proper incumbent and may fully explain the result.

The decisive GO to a new state-writing claim would additionally require a
specific useful target configuration unreachable by the equally informed
incumbent at the same allowed excursion, a fully measured robust transition
table along the required paths, independent blind initializations, and a
complete fabrication/reset comparison. None is currently present.

6. Acquisition-inclusive cost and evidence boundary

Source access: obtained anonymously; no purchase, account, paid job, or external
message. Local data and code replay: completed, with actual runtime in the JSON
receipts (approximately 0.06 s for the main audit on this run). These timings
exclude model inference, source retrieval, and human/hardware work.

Physical preparation: no apparatus acquired, assembled, or modified here.
The demonstrated incumbent uses optical posts, bearings, a long drive rod,
springs, fixed stops, a balance, and position measurement. A claim that cheaper
hinges or printed parts preserve its thresholds would itself need validation.
No priced bill of materials or possession of that apparatus was established.

Calibration and error: individual spring force curves; held-neighbour threshold
measurements; repeatability, rate, and fatigue tests; and complete graph
calibration must be charged. A pairwise model can reduce calibration count
only after its adequacy is validated. Worst-case unstructured N-rotor branch
calibration has 2 N 2^(N-1) conditional threshold entries. Model fitting does
not acquire those entries for free.

Energy/work: unknown. Rod travel is not a work measurement. Stiffness, preload,
friction, kinetic loss during snaps, reset, sensor/actuator electricity, and
labor are unmeasured for this candidate. Scaling: unknown; tolerances and
number of states can dominate. A local actuator or direct mechanical assembly
remains a legitimate stronger comparator when its full cost is competitive.

Inference tokens/cost/energy: UNKNOWN (no telemetry supplied).
New experimental repetitions: zero. Novelty: not established.
Mission status: NOT_ACHIEVED. Retained capital: a data-grounded impossibility
result, a restricted realizability theorem, exact source-model replay, and a
concrete calibration discriminator. None is a demonstrated new operation.

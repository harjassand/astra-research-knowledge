  python actual_data_diagnostic.py --seeds 12 --output replay_fresh

execution wall-clock values. Use a fresh output name each run.

receipt. It does not establish calibration, external transfer, novelty or advantage.

provided by load_workspace_dependencies, which contains numpy and openpyxl:

The analysis does not export or modify these workbooks.

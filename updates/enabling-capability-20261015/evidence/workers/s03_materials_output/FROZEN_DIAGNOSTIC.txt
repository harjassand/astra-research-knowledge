Actual-data diagnostic specification, frozen before model comparisons

This is retrospective reuse of actual measured labels. It is not a new experiment.
Primary output: source measured coercivity Coer [mT], maximized within this library.
Secondary output: source measured Kerr optical rotation [mrad], not saturation M.
No synthetic labels or simulated physical output will be generated.

Inputs: all 921 measured compositions. For structural-channel arms, all 921 XRD
spectra are supplied at the beginning. That deliberately generous information
assumption tests whether spectra could help; their complete acquisition cost is
charged separately. This is not a deployable sparse-XRD active learner.

Comparators: ordinary GP/EI on composition; equally informed GP/EI on composition
and continuous XRD features; phase-segmented GP/EI on composition and the same XRD.
Phase-segmented is a CAMEO-style mechanism test, not a faithful CAMEO reproduction.
No expert phase labels are acquired. XRD clusters are computational partitions,
not independently identified phases. No advantage against equally informed GP/EI
will be called a new enabling operation: these are established methods.

Primary model diagnostic: prediction on spatial composition holdouts and random
holdouts, with all output-dependent tuning confined to training/validation labels.
Spectral representations use only unsupervised spectra. Composition holdouts cannot
establish independent synthesis transfer; a different process/batch is still missing.

Finite search: paired random initial seeds; identical target observations per arm;
EI with GP hyperparameters fit from observed output only; no target leak from all
labels into spectral representation. Report each observation trajectory, mT/mrad
regret, and thresholds of 90% and 95% of source maximum. Source 99.9% optimum
tolerance will also be shown but cannot be physically certified without uncertainty.

Costs: characterize every needed channel, including library synthesis, composition,
XRD all 921 points, magnetic loops, calibration, model computation, reset, and any
validation refabrication. Unknown physical costs remain unknown. Show break-even
inequalities in units of one magnetic loop rather than inventing acquisition times.
Model runtime is measured wall-clock code execution, not inference telemetry.

Scientific target
Count active optical emitters and localize at a declared 100 nm separation,
with a finite observation window and lower detectable-brightness definition.
This is not total molecule stoichiometry, pixel MSE, or a count from a forced
clustering model. Independent count/distance truth was not acquired.

Important acquisition and parser corrections
1. Actual replay uses10 MHz, divider20, as specified in source
Run_TimeTraceCalc.m; the journal Methods gives20 MHz. At20 MHz the raw
sidepeaks alternate and disagree with the source MAT. At10 MHz all51
lagcounts in every one of188 source-valid windows match exactly. The
maximum absolute g2 discrepancy is8.15e-8 from source floating precision.
2. Manual pp56-57 says high-time applies to the previous event. That rule
produces72 backward jumps per typical file. Applying it to following
events, as the author software does, gives monotonic data. The first high
record is before the first photon, and wrap samples have high low24-bit
values BEFORE the update and low values after it. Therefore the parser
uses the source rule and records the competing manual interpretation.
3. The source software drops the last event of each file as suspicious.
Our replay does so too, with the final jump recorded per file. Source-invalid
-99 windows remain excluded: our present phase-zero diagnostic does not
reproduce the invalidity condition. We do not silently rehabilitate them.

Executed existing coincidence operation
Independent CPU NumPy code exhaustively counts all detector pairs at
excitation-pulse lags0..50. It excludes same detector pairs and the source
forbidden pairings(1,2),(3,4). On valid windows, the maximum prior-neighbor
offset needed is far below the author's20-event GPU cutoff. Source dark
vectors and old relative delays are used, not an invented calibration.
All188 valid lag vectors match; all22 available passing dominance tests
match. The complete MAT has101 passes, most outside available raw files.
Execution elapsed3.460705 s; this is code time, not inference time or
physical experiment cost. No GPU is needed for this finite replay.

Exact scope of source threshold
Supplementary Note3 derives g2=2r(1-r) for two independently emitting QDs
and explicitly interprets the .375 threshold as accepting events where
one QD contributes at least75% of photoluminescence. For arbitrary unequal
brightness this is a dominance test, not an exact count certificate.
Supplementary Note2 also filters image blocks to reject brief blinking of
a second emitter within an accepted window. Threshold alone is insufficient.
Source nominal emitter lifetime26 ns implies delayed detection across
pulse assignment boundaries; raw reconstructed counts are not emitted
photon-number truth. Multiple emission and background are further nuisances.

Full timestamps are richer than binary clicks or g2 alone
Across all acquired files,36,427 reconstructed100 ns pulse/detector bins
contain multiple detections in the same detector. The shortest same-channel
interarrival is43.45704 ns;20,156 intervals are below50 ns and50,273 below
100 ns. There are no intervals below10 ns. These are observed counts,
not a recovered serial-specific dead-time calibration. A current manufacturer
datasheet gives typical50 ns deadtime and0.5% afterpulsing, not the actual
2015 module calibration. Imposing50 ns as an exact threshold is unsupported.
The188 source-valid windows contain31 source-allowed distinct-detector
triple coincidences; none occur in the22 dominance-passing windows.
Consequently a theorem about one saturated binary click per pulse, or a
theorem about only first/second moments, must not be promoted to equality
of the complete timestamp observation law. Full timing, multiplicities and
higher correlations can discriminate some competing count models. Whether
these31 triples have source, latency, background or recovery explanations
is unresolved without a calibrated joint model and independent truth.

Executed spatial endpoint baseline
A direct Poisson maximum likelihood fit uses actual15-detector counts in
1500-photon blocks, source circular fiber geometry, supplied dark vector,
old detector-efficiency vector, elliptical Gaussian PSF and fitted uniform
extra background. This improves statistical modeling over unweighted image
least squares but is ordinary existing inference, not a new operation.
The188 valid windows provide1551 full blocks. The22 dominance-passing
windows provide95 blocks. Fitting TWO tracks with common linear drift to
these95 blocks gives94.480 nm separation and21.283 nm2D residual RMS.
The lowest-intensity10% of available valid blocks(155blocks, not the full
paper trace) gives71.526 nm and24.783 nm under the same two-track fit.
Both use1500 photons per localization; retained sample counts differ.
These are functional incumbent outputs, not measured errors to truth and
not a proof that exactlytwo emitters exist. Two tracks are imposed by the
fit. Model-based per-block Poisson SE excludes calibration and model error.
The code does not reproduce the full author's between-block rejection
protocol, so these values are not claimed as an exact figure reproduction.

Calibration sensitivity on identical95 blocks
A later dated source efficiency vector changes the fitted separation to
97.810 nm and produces median6.380 nm position shifts. Assuming equal
efficiencies gives103.389 nm and median9.898 nm shifts. These are alternative
calibration scenarios, not a confidence interval. Direct fits converge for
most blocks; LOCALIZATION_BASELINE.json preserves every block and status.

Strongest incumbent hierarchy
- Existing15-detector calibrated coincidences and source quantum-correlation
postselection already recover a conditional~100 nm spatial scale here.
- Full photon-number-resolving likelihood jointly estimates brightness/count.
Li et al. OptExpress2022 and AVSQuantumScience2023 use binomial/convolution
binomial MLE; the2023 model assumes known species count and omits background.
- Blinking inference is not new: Hillsley et al. NanoLetters2025 blinx infers
count from intensity time series. Its source model assumes independent,
identically distributed emitter kinetics/brightness and time-constant rates;
experimental validation uses1/4-DNA-PAINT-site origami with visually resolved
truth. Its code is pinned eaad8c2ad3fd9488a58952011eda3557dd21c6a9.
It is a necessary comparator where those assumptions apply. It was not
executed on this sparse QD raw trace; substituting its fitted count as truth
would not resolve calibration/heterogeneity requirements.
- Standard multi-emitter spatial likelihood, third/higher coincidences,
detector arrays, photon-number resolving detection and attenuation/decoy
measurements are established measurement operations. No novelty is claimed.

Why no blanket impossibility claim is licensed
For ideal unsaturated counts from a finite set of independent Bernoulli
emitters plus independent Poisson background, the count generating function
is F(z)=exp(lambda*(z-1))*product_i(1-q_i+q_i*z). For positive q_i the zeros
identify the Bernoulli factors and their number, while the exponential term
has no zeros. Therefore full photon-number laws can identify emitter count
under that restricted model; the unequal-brightness g2 ambiguity does not
extend automatically to the full law. Detector response, latency and blinking
change the actual observed law and must be included explicitly.
Arbitrarily dim/dark extra emitters still defeat uniform finite-sample exact
total-count certification without brightness and activity-duration bounds.

Minimal physically justified validation interface and decision
HOLD a claim of a new enabling count/localization operation. Acquire, on the
same instrument/regime, serial-specific dark exposures, smooth-illumination
efficiency exposures, timing IRF, recovery/afterpulse responses and loss
calibration; establish actual trigger/excitation settings per trace. Acquire
blind1/2/3-active-emitter specimens with independently known separation and
count at100 nm, brightness ratio limits and blinking controls. Compare full
joint marked-timestamp likelihood, source g2 criterion, applicable blinx,
PNR and attenuation/coincidence baselines at matched photons, illumination,
calibration and preparation cost. Existing benchmarks could implement this;
no new physically acquired control has been established here.
A useful certificate would return compatible counts at the declared minimum
brightness/activity duration and would say UNKNOWN when nuisances cannot
be bounded. That is a proposed validation contract, not a novel technology.

Exact algebraic certificate (standard, no novelty asserted)
Write the real symmetric matrix in selected/complement blocks H=[[A,B],[B^T,C]]. Choose positive weights w. Define
  d_i = C_ii - sum_{j != i} abs(C_ij) w_j/w_i.
For each off-diagonal pair, square completion gives
  2 C_ij z_i z_j >= -abs(C_ij)[(w_j/w_i) z_i^2 + (w_i/w_j) z_j^2].
Thus C >= D=diag(d_i), as a Loewner inequality. This does not require a guessed eigenvalue gap or a supplied complement spectrum.
For trial ell < min_i d_i, let S=diag(sqrt(d_i-ell)) and T=B S^{-1}. If
  Q=A-ell I-T T^T >= 0,
then the Schur-complement square completion proves H>=ell I. If numerical factors F,S,T satisfy the identity only to a residual R with ||R||_infinity <= delta, H >= (ell-delta) I. Pairwise square completion leaves the remaining C-D term positive semidefinite.
A Rayleigh quotient for any computed nonzero vector supplies an upper bound; an outward error allowance for its dot products makes it valid for the saved binary64 H entries. strong_audit.py documents each rounding allowance. Fraction arithmetic is used for outward endpoint conversion. No next-eigenvalue lower bound is assumed.
Arithmetic assumptions: IEEE binary64 round-to-nearest operations; standard gamma_n BLAS dot-product bounds; no overflow/underflow/nonfinite values. These are numerical proof assumptions, not a formalized hardware proof.

Failures and corrections preserved
1. Initial comparison-matrix construction incorrectly changed negative diagonal energies. BENCHMARK_INITIAL_UNCORRECTED.json and CORRECTION_001.txt preserve the error; no invalid comparison bounds are used. FCI and selected upper results were unaffected.
2. SciPy 1.18.1 arm64 cholesky(lower=True) locally retained nonzero unused upper-triangle values for 128+ matrices. Explicit np.tril produces the correct factor and tiny residual. The full residual verifier detected the misuse, yielding an enormous safe interval instead of a false tight certificate. STRONG_AUDIT_UNCLEAN_FACTOR.json and CORRECTION_002.txt preserve that diagnostic.
3. threads=1 was a requested setting, not measured effective threading. CORRECTION_003.txt corrects metadata.
4. Scalar complement floors plus a global coupling norm produce 1-4 Eh widths even when a 128-determinant upper error is already 0.000892 Eh. The optimal full absolute-value comparison relaxation loses 0.686245 Eh on this real matrix. Signed Schur structure repairs that weakness, but not the full-cost comparison.
5. STRONG_AUDIT.json root searches a much tighter microEh interval and is valid for arithmetic/accuracy, but its root-search timings are not the fair chemical-target performance comparison. MATCHED_TARGET.json supersedes that cost conclusion. No failure or discarded route is erased.

Reproducible compatibility fix

The official Kiwi recording client was pinned at
4eb733e6b6147f7fbeb97ced64cdac029b202d18. Its old /timestamp/SND path completed
a WebSocket handshake but yielded no samples. The receiver's own public
kiwisdr.min.js opens /ws/kiwi/timestamp/SND. kiwi_route_compat.py changes only
that path; normal authentication, channel admission, commands and parsing stay
in the vendor client. The new path returned server version 1.902 and actual IQ.
Public source bytes, old-route failures and the source export are preserved.
VENDOR_SNAPSHOT_MANIFEST.json verifies 58 source files; the verified source
archive preserves the pin without an embedded .git directory.

acquire.py prepares a bounded future run by default. --execute performs it.
It uses a new data directory, checks all vendor source hashes, supports only
ordinary receive-only options, disables AGC with an explicit fixed gain,
limits the requested clip to at most 90 s, and imposes an outer process timeout.
A 65 s plan was run locally without --execute; no further live clip was made.

Scientific target and primary incumbent

The selected prospective target is to exclude every calibrated single-path
explanation of a known WWV test burst, to support ionospheric multipath and
path-length studies. The initial measurable target is two arrivals separated
by at least 0.5 ms with a secondary component at least -12 dB, subject to stated
error rates and independent known-truth validation. These are design targets,
not obtained performance.

This science already has strong primary incumbents. NIST/HamSCI broadcasts
purpose-built characterization signals; the HamSCI 2026 workshop explicitly
reports multipath and Doppler analysis and labels that contribution non-refereed.
KCollins/wwv-h-wg provides waveform analysis. Current HamSCI/hf-timestd source
describes matched ticks, secondary peaks, propagation models and calibration;
its advertised accuracy was not independently validated here. Native Kiwi TDoA
is a further delay comparator. A candidate must receive exactly the same source
waveform, calibration family, timing bounds, and budgets as these comparators.

Decisive calibration gate

For known downstream digital controls q_u, the stationary model is
y_u = q_u * g * h * s + noise. If the admissible receiver family contains g*h,
the identical observations arise from receiver g'=g*h and propagation h'=delta.
This holds for every downstream filter/gain, even chosen adaptively. Independent
receiver-response bounds, an injected/reference channel, or justified stable
receiver restrictions across epochs can break that ambiguity. The actual
receiver need not admit arbitrary echoes: the no-go is explicitly conditional
on the stated receiver class. See IDENTIFIABILITY_v0001.txt for the proof.

PROSPECTIVE_EXPERIMENT_CONTRACT_v0001.json specifies one bounded next clip,
source/version and GPS checks, independent calibration/known-truth obligations,
an equally informed comparator and the UNKNOWN rule. It also records a bandwidth
gate: the live receiver supplied about 12 kcomplex samples/s; HamSCI currently
recommends above 20 kS/s for full-waveform work. A verified wider-band interface
or a correctly specified narrower target is needed. Interpolation does not
supply the missing physical bandwidth. No full-band scientific run was claimed.

S06 mathematical gate: molecular rate information is not geometric information

1. Exact clock nonidentifiability, any dimension.

Let X be an ergodic Markov process with invariant measure pi and disjoint target
sets A,B. For c>0 define X^c_t=X_{ct}. Its semigroup is P^c_t=P_{ct}; if X has a
generator L, the new generator is cL. Both processes have the same invariant pi.
Their hitting order, committor q(x)=Pr_x(tau_B<tau_A), and unparameterized paths
agree exactly. Their hitting times satisfy tau^c_B=tau_B/c, so any reciprocal-
MFPT rate changes by the factor c. Any estimator using only pi, q, state labels
and unparameterized paths therefore has unbounded multiplicative worst-case
rate error over this class. This is a standard time-change obstruction, not a
novel theorem and not a second physically validated dynamics for CLN025. The
acquired MD frame interval removes this scalar ambiguity within that MD model.
An experimental physical clock still requires validated dynamics or measurement.

2. Exact finite-record retention.

For a time-ordered label string s_i in {A,R,B} at times i*dt, retain the first
observed basin and then the first arrival in each opposite basin. Let these
indices be t_j and labels b_j. Discard the first residence interval, since its
initial age is unknown. The observed complete A-to-B samples are
  dt*(t_j-t_{j-1}) for j>=2 and b_j=B,
and similarly for B-to-A. Their reciprocal sample means, and every bootstrap
calculation based on those samples, depend only on this event skeleton and dt.
The code reconstructs an R-filled string from the skeleton and proves by exact
array equality that both observed sample arrays are unchanged. This is a finite
data identity. It does not certify unobserved long tails, independence, rate
stationarity, additional mechanisms, or physical accuracy of the force field.

The old source additionally pairs the numbers of opposite transition events
within each trajectory. On the acquired CLN025 record, that discards one terminal
A-to-B interval of 1.1735 us. The resulting stored rate 0.2766787483053426/us
agrees exactly with the source array. Keeping all complete intervals gives
0.2840567676524894/us. B-to-A is unchanged at 2.5249447124175046/us. These are
different explicit finite-record conventions, not a new physical discrepancy.

3. Why a scalar committor is not a free rate simulator.

Even for an exact diffusion committor, the projected q(X_t) need not be Markov:
the conditional quadratic variation grad(q)^T D grad(q) can vary along an
isocommittor surface and can depend on unresolved history. A learned committor
adds approximation error. A binned one-step transition matrix therefore needs
a validated lag/memory closure before its MFPT can be promoted to a molecular
rate. The supplied committor is learned; this benchmark does not isolate memory
from committor error, state aggregation, or basin initialization.

The actual CLN025 control gives a decisive warning for this particular closure:
with 10/30/100 bins at 0.1 ns lag, unfolding is 15.26-17.53 times the direct
reference, folding 15.72-18.02 times. A 10 ns lag gives ratios 1.40-1.42 and
1.34-1.36. Longer lag is not a monotone cure: 100 ns gives about 0.68 and 0.54.
This does not refute all MSMs, exact milestoning, or history-augmented methods.

4. Scientific operation verdict.

Clocked event compression preserves an already acquired rate statistic. It
cannot manufacture molecular trajectory exposure. TPS plus basin flux, exact
milestoning plus first-hitting clocks, WE plus weighted flux, and RFPS-AIMMD plus
free-state sampling already address this acquisition interface. A new operation
must change how correctly weighted physical trajectories or experimental clocks
are obtained, at matched total preparation and production cost. This worker has
not done that. The verified contribution is a bounded kinetic access/replay and
representation-failure package; proposed enabling-operation status remains HOLD.

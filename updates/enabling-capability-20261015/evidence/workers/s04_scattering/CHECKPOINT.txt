Scattering/crystallography checkpoint, 2026-10-15

Scientific target: identify the absolute atomic handedness of a real chiral
crystal, rather than improve image MSE. Exact ambiguity: for real nonresonant
kinematical form factors, r_j -> -r_j conjugates every structure factor and
preserves every intensity, even with complete noise-free reciprocal-space data.

Candidate operation investigated: retain multiple-scattering phase interference
and acquire only carefully chosen orientations, with an independently known
reference for detector/tilt handedness. This is NOT claimed new. Literature
already contains X-ray three-beam absolute-structure determination and dynamic
3D electron-diffraction handedness determination. Any surviving contribution
would have to beat an equally informed dynamical refinement with the same raw
data and nuisance parameters, not a kinematical baseline.

Primary novelty stop signals:
- Parsons, Flack and Wagner, Acta Cryst B 69, 249-259 (2013),
  DOI 10.1107/S2052519213010014. Quotient/difference refinement, independent
  R-mandelic-acid/L-alanine reference provenance, explicit reverse-beam same-pixel

- Li et al., Nature Chemistry (2025), DOI 10.1038/s41557-025-01950-5,
  high-throughput serial 3D ED enantiomorph quantification, with open software.

1. Exact acquisition contract and the decisive code gate

Input: n>=2, 0<=r<=n, h=n-r, 0<epsilon<1/16, 0<beta<=1/2, random bits,
and chosen directed comparisons C(x,y). Q:F2^n->F2^n is an unknown bijection,
all n output coordinates have degree<=2, and an unknown length-h translation
flag exists. There is an unknown fixed B, |B|/2^n<=epsilon, and C agrees with
strict lexicographic Q-order whenever both items avoid B. On incident pairs C
can be arbitrary, persistent, nontransitive, and inconsistent on reversal.
No coefficients, correct next-bit labels, ranks, B, clean flags, directions,
conditional sampler, or source truth are supplied to acquire(). The degree,
flag-existence and item-error-density promises ARE supplied, not recognized.

Primary interface uses the original directed C and an ordered-pair memo cache.
It never obtains C(y,x) by complementing C(x,y). The optional canonical mode
is only a preserved restricted experiment on C*(x,y): canonical forward C,
complemented reverse. It remains in the persistent-B class, but does not test
non-antisymmetric answers at the learner port. All old C* receipts retain that
scope and are not promoted to original-directed execution.

The implementation reuses exact GF2/Quadratic/Compiler algebra from
../p_s01_partial_flag/partial_flag.py read-only. Its new components are the
sampled shifted-ball decoder and the sequential matching validator. The
full learner is quadratic; the decoder itself accepts any fixed degree d.

2. Shared shifted-ball coefficient decoder

Let raw(x) be binary and let q be a fixed degree<=d multilinear polynomial.
For deterministic raw, assume Pr_uniform_x[raw(x)!=q(x)]<=rho<2^(-d-1).
The same result holds for fresh randomized raw calls if their global expected
error is<=rho and internal randomness is fresh across sampled rounds.

Let A={a:wt(a)<=d}, M=|A|. Draw R independent uniform centers x_t, and store
raw(x_t+a) for a in A, once per position. Descend through coefficient degrees.
For S of size k, its corrected finite-difference vote is
 V_S(t)= XOR_(a subset S) raw(x_t+a)
         XOR_(T strict-superset S, recovered coefficient a_T=1)
                 product_(i in T\S) (x_t)_i.

If higher coefficients are true, the noiseless vote equals a_S. Each of the
2^k queried positions is uniform; a union bound gives vote error<=2^k*rho.
Set g_k=1/2-2^k*rho>0 and
 R_k=least odd integer >= ln(M/eta)/(2*g_k^2), R=max_k R_k.
Hoeffding on the independent rounds makes the majority for S wrong with
probability<=eta/M.

Sharing rounds between coefficients needs care. Define every reference vote
using the fixed TRUE higher coefficients, before considering any recovery
success event. Union-bound all M reference-majority failure events. On their
complement, induction down the degrees shows every actual recovered higher
coefficient is true, hence each actual vote equals its reference vote. This
proves whole-body error<=eta without conditioning lower votes on correlated
higher-degree success.

Queries: R*M raw callback evaluations. Local decoder work is polynomial for
fixed d. There are <=2^d terms in each finite difference; total contributing
higher-term incidences is <=2^d*M. The current transparent implementation
also scans the recovered term list for each S, costing O(M^2) preprocessing
per body. Storage is O(R*(M+n)) logical bits plus polynomial instructions.
No input-domain enumeration or efficient-NIS backend is hidden in this step.

This is a sampled implementation of classical Reed majority logic, not a new
coding theorem. Gopalan/Klivans/Zuckerman explicitly identify Reed unique
majority decoding and local adaptation at radius 2^(-d-1), and discuss
bypassing noisy interpolating sets with local majority logic. Dvir/Shpilka
provide a stronger O(n^d) NIS construction with efficient interpolation; this
code does not instantiate its asymptotic constant-rate base-code family.
Our R*M has an explicit log(M/eta) factor and different finite constants.

3. Robust direction body acquisition

On a true acquired prefix, the exact algebraic common stabilizer is S_k.
A uniform v in S_k is a true next own-toggle with probability at least
p=2^(-r-1), by the remaining hidden flag dimension. Zero is skipped.
For a genuine v,
 raw_v(x)=1 XOR C(x,x+v)
agrees with the next q except when x or x+v is in B, so its error density is
at most rho=2epsilon<1/8. The sampled decoder with eta=1/4 recovers the entire
true quadratic with probability>=3/4. For a non-genuine v it can propose any
quadratic. Every proposal must satisfy the exact own-toggle identity
Delta_v f=1. Since sampled v belongs to S_k, a gate-passing f is balanced
in each acquired prefix fiber, and the exact projection sampler applies.

Deterministic raw-label caching and ordered persistent-comparison caching
only evaluate the same fixed functions at repeated points; they do not turn
repeated responses into independent fresh noise. Fresh sampled centers and
matching seeds, not oracle replay, provide the independence used in bounds.

4. Matching validator and valid sequential stopping

Use the robust matching lemma in ../p_s02b_matching_robustness/PROOF.txt §1.
Each batch samples a fresh uniform prefix and m independent positions from
each candidate half, then constructs a maximal matching of observed inversions.
Repeated item identities remain separate sampled vertices. Put Z=|matching|/m.
On a correct history, conditional on the fixed candidate:
  f=q: E Z <= a=2epsilon;
  f!=q, degree(f),degree(q)<=2: E Z >= b=1/4-2epsilon-c_m,
  c_m=binom(2m,m)/(2*4^m).
Choose m with a<b. The sampler and maximal-matching code are the same in
all conditions; no item is classified as clean to build these scores.

For a,b in (0,1), define
 ell(z)=z*ln(b/a)+(1-z)*ln((1-b)/(1-a)).
Because exp(ell(z)) is convex on [0,1], it lies below the chord joining its
endpoint values. Therefore for E Z<=a,
 E exp(ell(Z)) <= (1-EZ)*(1-b)/(1-a)+(EZ)*b/a <= 1.
For E Z>=b the reciprocal has the same property. Thus exp(sum ell) and its
reciprocal are respective supermartingales. Fresh independent batches make
the conditional mean premise valid after every fixed candidate/history.
Ville's inequality bounds either wrong boundary crossing at log(2/delta)
by delta/2. Positive crossing rejects; negative crossing accepts.

There is a deterministic finite cap. Let tau solve D(tau||a)=D(tau||b),
which is tau=-B/(A-B), A=ln(b/a), B=ln((1-b)/(1-a)). Set
 T=ceil(ln(2/delta)/min(D(tau||a),D(tau||b))).
If neither sequential boundary has been hit by T, accept iff mean Z<=tau.
The Bernoulli KL Chernoff bound for bounded iid scores charges at most
another delta/2 for either wrong final decision. Consequently true false
rejection<=delta and wrong-candidate false acceptance<=delta, including
all early stopping and the fallback. This is not uncorrected peeking at a
fixed-size confidence interval. The implementation uses Python floating
arithmetic for logarithms/thresholds, with the ordinary numerical-model scope;
this is not a formally verified exact-real implementation.

m is selected by minimizing the proved finite cap m^2*T over the bounded
integer search 1..ceil(2/(1/4-4epsilon)^2). This is a deterministic parameter
choice, not an optimization after observing data. Every candidate receives
fresh batches. False candidates may have arbitrary body errors; the separate
fresh matching test, not body correction, supplies their soundness.

5. Caps, suffix acquisition and whole-model confidence

Set Rcap=ceil((2/p)*ln(4h/beta)) for h>0 and
 delta=beta/(4h*Rcap^2).
On each correct-entry trial a genuine recovered true body is accepted with
probability >=p*(3/4)*(1-delta)>=p/2. The union over h stage exhaustions is
<=beta/4. Before the first false acceptance, all exact-prefix and matching
premises are true. Hence its probability is <=h*Rcap*delta=beta/(4Rcap).
This first-error argument does not assume the learner stays correct after
an erroneous acceptance. All later loops, fiber sizes and requests stay capped.

After h correct prefix coordinates, enumerate their acquired complement
seeds, at most 2^r per raw suffix label. Filter using already acquired suffix
coordinates; check the expected fiber cardinality and return UNKNOWN on
failure. For each x count original directed C(y,x) over y!=x in its current
fiber, then threshold at half the fiber size. The two-bad-item rank lemma
in ../p_s02b_matching_robustness/PROOF.txt §4 gives global error<=2epsilon,
even for nontransitive/asymmetric incident answers. Decode each suffix body
with failure beta/(2r). Their conditional union probability is<=beta/2.

Thus P(wrong returned model OR UNKNOWN)<=beta/4+beta/(4Rcap)+beta/2<=beta
without an optional artificial compute budget. A user-imposed request budget
may increase UNKNOWN frequency but cannot increase the probability of a wrong
model: stopping discards the partial model. A returned model has a Monte Carlo
confidence guarantee under the supplied promises, not a deterministic certificate.

6. Resource accounting and comparator boundary

Let M=1+n+binom(n,2), Rbody=R(n,2,2epsilon,1/4),
Rtail=R(n,2,2epsilon,beta/(2r)), and T,m be the matching cap parameters.
With S_r=sum_(j=1)^r(2^(r-j+1)-1)=2^(r+1)-r-2,
 Qmax <= h*Rcap*(M*Rbody+T*m^2) + M*Rtail*S_r.
Logical source requests can be smaller because deterministic raw labels are
cached per candidate. Physical source calls can be smaller again due to the
charged persistent ordered-pair cache. All counters distinguish these layers.
For fixed r, epsilon gap and beta, expected correct-entry proposal count is
<=2/p. A first-error bad-entry charge is bounded by beta/4 per stage with
these delta/Rcap choices, giving
 E Q <= h*(2/p+beta/4)*(M*Rbody+T*m^2)+M*Rtail*S_r.
This is O(n^3 log n) at fixed r, versus the known NIS construction's stronger
O(n^3) expected comparison statement. No asymptotic improvement over NIS is
claimed. The executed advance is concrete polynomial learner/runtime closure
with much smaller local constants than the old repeated-cube reference.

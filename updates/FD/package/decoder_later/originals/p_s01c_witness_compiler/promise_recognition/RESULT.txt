Exact known full-order validation is exponentially expensive and sharp.
For N=2^n items, a hidden adjacent transposition changes ONLY the comparison
between the two swapped adjacent items. Deterministic zero-error equality
validation therefore requires exactly N-1 comparisons; checking the entire
candidate chain achieves it. For error beta<1/2, the sharp worst-query cap is
 ceil((1-beta)(N-1)) with perfect null completeness,
 ceil((1-2beta)/(1-beta)*(N-1)) with two-sided error.
The matching tests sample a uniform adjacent-pair subset; the two-sided test
also blindly rejects with probability beta. Null expected lower bounds are
(1-beta)(N-1) and (1-2beta)(N-1), respectively, and randomized subset sizes
match them. These are source-query statements; candidate inverse and n-bit
argument generation/storage cost remain charged separately.

Class-recognition nuance matters. If only h=n-r prefix bits are degree-bound,
intra-2^r-block adjacent swaps preserve the entire prefix and hidden flag.
Exactly 2^h-1 adjacent swaps cross prefix boundaries and violate degree when
n-1>d. For ALL-output degree<=d, every N-1 adjacent swap is bad. The sharp
adjacent-family formulas use the ACTUAL number of bad needles.

Nevertheless general prefix-promise recognition remains Omega(N) even when
r grows: swap two uniformly selected items from different candidate prefix
blocks. A changed prefix bit gains a two-point indicator of degree n-1>d.
Comparator transcripts differ only if a query touches one of the endpoints.
T comparisons touch at most 2T items, so coupling gives T>=(1-2beta)N/4 for
two-sided bounded error; the same bound holds for null expected comparisons.
For deterministic zero error, at least(N-2^r)/2 comparisons are needed by the
untouched-endpoint argument. Constants of this general lower are not sharp.
For zero false acceptance, a stronger argument requires N-1 comparisons on
every accepting positive transcript. Otherwise an adjacent pair of prefix
blocks has incomparable endpoints in the queried poset. Reorder within the
blocks topologically (prefix unchanged), then swap adjacent maximal/minimal
endpoints across their boundary. The resulting source is off-class and keeps
every queried answer. Thus a sound certifier accepting positives with
probability at least 1-beta has null expected cost >=(1-beta)(N-1).

A known balanced prefix can be validated exactly in <=2N-2^h-1 comparisons:
find source minima/maxima in each candidate block and check adjacent block
extrema. This accepts arbitrary correct suffix order. Combining capped
recovery and this test gives Theta(N) source-query class recognition for
fixed d,r, with no false acceptance. For growing r, existing recovery caps
can be larger; universal sorting gives O(N logN) source-query recognition.
No general growing-r Theta(N) recognizer is claimed. Exact source/rank tables
and local ANF/flag checks carry exponential representation work.

A constructive alternative permits sound UNKNOWN-r model selection while
RETAINING the supplied global degree bound.

A candidate prefix has exact locally checked polynomial own-toggles, hence
exact uniform balanced model fibers even if it is false. A fresh test chooses
a random coordinate stage, a random earlier candidate prefix, and two points
from its candidate next-bit halves 0 and 1. One source comparison detects an
inversion. If the prefix is true it always passes, regardless of suffix.
If it is false and the TRUE coordinates also have degree<=d, the first
globally different bit has mismatch>=2^-d. Balance plus Jensen gives rejection
probability>=2^(-2d)/h. Thus O(h4^d log(1/eta)) comparisons validate exact
prefix equality UNDER DEGREE only; no true flag/r assumption is used.
Its 4^-d/h rejection bound is attained by swapping midpoint adjacent labels
of the high d+1 bits and preserving lower bits. This source still has every
coordinate degree<=d. It is sharp for this probe, not a universal testing lower.

For full degree-bound output, draw fresh uniform raw points after the prefix
test and compute each source suffix rank within its candidate 2^r fiber using
2^r-1 comparisons. Conditional on a correct prefix, any wrong degree-bound
tail is detected with probability>=2^-d. Another O(2^d log(1/eta)) points
suffice. Candidate global bijectivity need not be checked: equality to the
true source is the test target. Prefix/tail error allocations sum to eta.

Therefore run capped candidate generators at hypothesized r=0,1,... and
validate each returned candidate with fresh summable error budgets. Wrong
return probability is at most their sum even when earlier hypothesized flag
promises were false. A true r* candidate passes with certainty once recovered.
This removes supplied r for sound model selection, while retaining supplied
TRUE degree, exact static bijectivity/comparator and fresh entropy. Repeated
acquisition costs and capped failures are paid; no leading-optimality claim.
Unknown degree cannot be handled by silently applying the same small-d test.

A second alternative is established sortedness testing in deletion/LIS
distance: O(n/epsilon*log(1/beta)) comparisons distinguish exact match from
an epsilon deletion-far source order. Uniform pair disagreement has a
different distance/cost. Persistent bad-item models must specify one of these
operational witness distances; rank-value Hamming error alone is insufficient.
EKKRV Spot-Checkers already supplies the sortedness technique; no novelty is
claimed. A simple internal degree-gap lemma says distinct ALL-output degree-d
bijections have deletion distance>=2^(-d-1), allowing the established tester
to validate exact equality under degree if candidate bijectivity/inverse are
also available and their costs charged.
The degree/deletion gap and tail-detection gap are attained by flipping the
LSB conditional on a product of d higher bits.

HIGHER-DEGREE HIDDEN-FLAG LEARNING: PRIMARY PRIOR AND ACCESS GATE
13 October 2026. Targeted primary-source audit; not novelty clearance.

Decision

The strongest close results solve adjacent problems under strictly richer interfaces. Selezneva computes all periods of a low-degree Boolean polynomial from its supplied ANF in n^{O(d)} time. Augmenting f(x) by a new variable gives all constant-derivative directions (linear structures). If instead the learner has exact value-membership access to f and degree at most d, M_d(n)=sum_{j=0}^d binom(n,j) interpolation values recover the ANF, after which this coefficient-input algorithm applies. Reed–Muller local list decoding handles noisy received values when a distance promise is supplied. Kushilevitz–Mansour exactly learns bounded-depth trees whose tests are GF(2)-linear forms from membership queries, with time polynomial in n and 2^k; it is useful when the target depends on k hidden linear forms, but k may be n for fixed-degree examples. None of these methods gets the comparison-only hidden flag for free.

The closest same-response prior is active learning of lexicographic preferences over named binary attributes. Its query oracle accepts two outcomes and returns their order. For ordinary fixed-preference, unconditional-importance lexicographic orders, exact elicitation takes log_2(n!) comparisons; for conditional-importance/local-preference LP-tree classes, the exact complexity can grow as 2^n. This shows both that pairwise ordinal learning is established and that comparison cost depends on the structured class. However, the visible-coordinate LP-tree model does not learn the hidden affine map u=Lx+c or exploit a bounded-degree restriction on the conditional preference tables. Indeed, if u were supplied, the present degree-d triangular order is a fixed-order LP-tree with conditional local preferences: query pairs that agree on the earlier u-prefix and differ only in u_i, and each response gives the bit q_i for that prefix. Interpolating each degree-d table takes exactly sum_i M_d(i-1)=D(n,d)=sum_{j=0}^d binom(n,j+1) comparisons. This is a matched same-response control with the frame supplied. The hidden-coordinate acquisition is the extra operation addressed by the internal compiler.

No deployed/consequential interface satisfying the full promise was established in this screen. Pairwise human preference systems and ORE provide ordinal-comparison interfaces, but neither source supplies a certificate that raw binary alternatives are ordered by a low-degree map in an unknown affine frame with the stated partial-toggle structure. ORE compares ciphertexts of already encoded plaintexts; it does not provide x -> Enc(Q(x)) or the low-degree guarantee. This is an interface gap, not a novelty result.

Problem and exact access

The source port is a deterministic classical comparator

  C(x,y)=1[Q(x)<lex Q(y)]

on learner-chosen raw x,y in F_2^n. A call costs one comparison bit and supplies 2n chosen-input bits. The hidden object is a bijection Q=(q_1,...,q_n), with a supplied low-degree/flag promise. In the complete affine-triangular case, u=Lx+c is invertible and q_i=u_i+g_i(u_1,...,u_{i-1}), deg(g_i)<=d. In the bounded-defect partial case, only h=n-r leading coordinates are promised degree<=d and there are h independent translations with the required own-toggle/earlier-invariance identities; arbitrary suffix coordinates cannot be interpolated absent an additional promise. The learner is not supplied Q's labels, L,c, toggle directions, target ANFs, or fiber samplers.

The exact acquisition identity is promise-dependent. If v first toggles q_j while preserving q_1,...,q_{j-1}, then

  1 xor C(x,x+v)=q_j(x)

for every x. Thus a *certified genuine* direction converts one comparator into one exact value-membership label of a true polynomial. This is not available for arbitrary v in a partial flag. Acquiring and validating enough such directions, and building the prefix-fiber sampler from prior accepted structure, is the unresolved interface portion.

For the partial-flag class there is also a stronger-input same-comparator control. If the full flag directions and a complementary basis are supplied, then at stage k the true next q_{k+1} is a degree-d function on only k+r active quotient coordinates: the k already exposed coordinates and an r-dimensional complementary tail. Own-toggle comparisons provide exact values there, so interpolation costs M_d(k+r). Across h=n-r prefix stages the total is

  A_d(n,r)=sum_{k=0}^{h-1} M_d(k+r)=D_d(n)-D_d(r),
  D_d(t)=sum_{j=0}^d binom(t,j+1).

The resulting prefix is exact with zero semantic error; it uses the same one-bit pair-comparison port. It supplies the best natural known-flag control for the partial theorem. Unlike the complete triangular case, a partial-prefix q_i may depend on complementary lower-priority tail coordinates, so it is not generally a standard ancestor-only LP-tree. The hidden flag and a usable complement are precisely what this stronger-input control assumes.

Strongest close methods and precise access gaps

1. Coefficient-input periods and low-degree translation invariance.

Selezneva, “Finding periods of Zhegalkin polynomials,” defines a period v by f(x+v)=f(x), takes the Zhegalkin/ANF polynomial itself as input, and returns a basis for the full period space in n^{O(d)} time. This is an exact, degree-sensitive algorithm for the translation stabilizer after coefficients are known; it is not a black-box comparator learner and its theorem does not give a query bound.

A direct reduction also covers constant derivatives, not only zero derivatives. Define F(x,z)=f(x) xor z. Then

  F(x+v,z+b)=F(x,z) for every x,z  iff  f(x+v) xor f(x)=b for every x.

Therefore every (v,b) period of F encodes a direction with constant derivative b. The period subspace projects injectively to the linear-structure space in the x-coordinates, so a basis computation on F returns all linear-structure directions and their response bits. This is a useful post-acquisition reduction, not a method to discover the first genuine comparator toggle.

If exact f-value membership queries are supplied and deg(f)<=d, the M_d(n) standard low-weight interpolation points determine all ANF coefficients. Selezneva then computes the period/constant-derivative structure locally. M_d(n) is information-theoretically necessary in the worst case to identify the *entire polynomial* from binary value answers, since the class has 2^{M_d(n)} members; this is not asserted as a lower bound for outputting only a period basis. If a comparator has already yielded an actual q_i membership oracle via v, the acquisition charge is M_d(n) comparison calls for a full raw ANF, or M_d(k) if it is already restricted to a known k-dimensional quotient. This makes the post-toggle polynomial/stabilizer calculation standard once the hidden direction and usable quotient have been acquired.

2. RM interpolation, local decoding, and correction.

For RM(d,n), an exact polynomial value oracle yields exact interpolation with M_d(n) labels. The minimum relative distance is 2^{-d}. Gopalan–Klivans–Zuckerman give a local list decoder for a received-word function R:F_2^m->F_2: it returns all degree-d codewords within distance 2^{-d}-epsilon, in time polynomial in m^d and epsilon^{-d}. Their local-decoding model explicitly queries R(x) at selected points; it is not one-bit comparison access, and the decoder needs its received-word proximity promise. This provides the standard response to genuine noisy value labels, not a direct replacement for finding the flag. The internal comparator candidate test must separately account for selection, bad directions, the acquired fiber distribution, and the error parameter; generic RM decoding does not supply those guarantees.

3. Learning after an unknown linear feature transform.

Kushilevitz–Mansour learn Boolean decision trees whose tests are linear forms over GF(2), using membership queries. The publisher abstract states exact identification of depth-d trees in time polynomial in 2^d and n. A function g(a_1(x),...,a_k(x)) of k unknown GF(2)-linear forms is a depth-k such tree, so the result covers generalized k-juntas. It does not subsume arbitrary fixed-degree flags with polynomial time in n: k is not bounded by d. For example, the quadratic form sum_{i=1}^{n/2} x_{2i-1}x_{2i} has a full-rank polar matrix; any representation through k linear forms must have k>=n because its polar rank is at most k. Thus even degree two can force the exponential parameter regime of this control. Access is f(x) membership labels, not C(x,y).

4. Active lexicographic preference elicitation.

Booth et al. study exactly a pair-query teacher over multiattribute outcomes: submit (alpha,beta), receive which is preferred. Attributes are named and binary. LP-trees allow conditional local preferences and conditional importance. Their Proposition 2 gives exact communication complexities; for fixed local preference/unconditional importance the bound is log_2(n!), while the fully conditional-importance row has order 2^n (the exact formula is 2^n-1+g(n) for CP-CI in their notation; for CP-UI it is 2^n-1+log_2(n!)). These are real active ordinal-learning results, but they do not include an unknown affine mixing of raw feature bits. When u is supplied, our complete triangular rank is a special fixed-order conditional-preference tree over u, and the degree restriction gives the D(n,d) pair-query interpolation control above. The unknown-u comparator compiler spends its extra comparisons on exposing this hidden coordinate order/frame.

5. Hidden shifts, group actions, and linear-structure algorithms.

Classical/quantum hidden-shift results receive function oracles for f and g with g(x)=f(x+s); quantum algorithms use the corresponding coherent oracle. E.g. Gavinsky–Roetteler–Roland give an expected O(n/sqrt(gamma_f)) quantum-query algorithm, where gamma_f is the minimum nonzero-shift influence, and explicitly model O_f and O_g. Hidden-subgroup and Simon-style approaches likewise rely on group-action/function-value access and structural period promises. They do not operate on the single classical bit C(x,y), nor do they identify a significance-ordered family of low-degree features. No transformation from arbitrary chosen-pair comparison access to the required coherent f/g oracle is established here.

6. Full sorting and active ranking.

The exact comparison bit is identical to a sorting comparator. Without using the structural promise, sorting all N=2^n elements costs O(N log N)=O(n 2^n) comparisons, with decision-tree lower bound log_2(N!)=Theta(n2^n) for arbitrary total orders. It is the strongest promise-free exact control and is necessary if the downstream task requires the full explicit sorted list/rank table. Active noisy-ranking algorithms have different goals: e.g. Ailon’s pairwise preference algorithm adaptively asks O(epsilon^{-6} N log^5 N) labels on a finite set V of N items to obtain regret at most epsilon times optimum loss, allowing nontransitive/noisy preferences. It does not recover an exact hidden order map on all 2^n raw inputs.

Concrete interface test

- Human/ordinal preference interface: concretely supplies pair comparisons of outcomes, as in active preference elicitation, but not the degree/affine/flag promise. It may be a future adapter only if an audited teacher/model or data-generating contract proves the exact class. An observed human’s consistency with a few comparisons is not certification.
- Order-revealing encryption: concretely supplies comparison of ciphertexts and reveals their underlying plaintext order. To realize this target port, an additional service must take raw x and produce a token representing Q(x), and the token service must guarantee the hidden affine/partial polynomial flag. ORE alone compares ciphertexts for the plaintexts already encoded; its standard interface does not construct Q(x).
- Triangular cryptographic permutations and T-functions: these are meaningful construction classes, but published construction/cipher papers expose internal permutation/cipher outputs or use key/round APIs, not the specific raw-input, one-bit comparator with the fixed-degree hidden affine flag and partial-defect promise. A hypothetical ORE wrapper over such Q is a proposed composite, not evidence of an existing consequential system.

No concrete consequential system meeting both contract parts (raw chosen x,y -> exact order bit; certified bounded-defect fixed-degree hidden flag) was verified. The strongest real interface is pairwise preference learning, but the class is not supplied. Therefore no application claim or novelty conclusion is justified.

Higher-degree extension: standard and unresolved parts

Complete triangular flag. Replacing quadratic interpolation by degree-d interpolation is routine: on a known prefix complement of dimension k, the next q_i is recovered from M_d(k) labels; summing over k gives D(n,d)=sum_{j=0}^d binom(n,j+1). Translation exposure and the exact tournament do not depend on d. So the complete-flag comparator theorem’s higher-degree interpolation extension is a direct proof adaptation, not by itself a new technique. Coefficient-input period algorithms already handle the local stabilizer calculation once q_i is represented.

Bounded-defect partial flag. The genuine remaining step is: find a true next-bit toggle among S_k from comparator-only raw pairs despite up to r nonflag directions, then acquire enough safe constant-derivative directions to interpolate in dimension at most k+r while retaining a valid prefix sampler. A peer prototype under review uses (a) a three-comparison folded-pair test with conservative bad-candidate rejection probability >=2^{-2d}; (b) sampling directions in the common stabilizer; (c) fresh exact comparator labels testing constancy of derivatives; (d) degree-d interpolation in a quotient of dimension k+r; and (e) explicit cap/UNKNOWN accounting. Its reported degree-d worst-query expression is in `p_s01b_adaptive_compiler/degree_extension/fixed_degree.py`; the internal formula has terms A_d=sum_{k<h}M_d(k+r), bounded raw candidate tests, derivative tests, tournament cap, and a tail term M_d(n)(2^r-1) only if every suffix coordinate is also degree d. This is an internal construction, not established by the cited sources and not independently certified in this prior report. In particular, arbitrary suffixes permit prefix recovery but not full-map interpolation.

A prior false stronger test claim was explicitly retracted: general mismatch e=Pr[Delta_v q=0]/2>=2^{-d} yields only inversion/rejection >=E[e_a^2]>=2^{-2d}. For d=2, exhaustive 8-element total orders attain 1/16, so no universal 2^{-2d+2} bound is valid. Preserve 2^{-2d} and define per-fiber mismatch-half density rather than non-toggle orbit fraction.

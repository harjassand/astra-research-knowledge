Contains all the traces of rotation rate used in the main manuscript.

Description of subdirectories: 

* 01_Without external torque: Raw traces without external torque (figure 2).
* 02_Under constant external torque: Raw traces under constant external torque (figure 3).
* 03_Under pulse-wise external torque: Raw traces under pulse-wise external torque (figure 4).

## Traces

The text files in subdirectories contain the angle at each frame of the video recorded at 4000 fps. Each text file corresponds to a single trace. The experimental conditions for each trace are summarized in an Excel file named "Experimental conditions.xlsx". The Excel file contains the following information.

* Filename.
* Identification of bacterial cells (date-chamber-cell).
* Applied voltage (V_0^2).

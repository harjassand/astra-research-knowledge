Each of the ten undirected grid edges has both directed channels, of rate

2. A concrete full-horizon receiver using positive resolvents

Fix a positive rate r. Put U_0=f and

 (rI-Q) U_j = r U_(j-1), j=1,...,k.                 (1)

Since exp(tQ) is positive and stochastic,

 r(rI-Q)^(-1) = integral_0^infinity r exp(-rt) exp(tQ) dt.

The semigroup property and independent exponential clocks give

 U_k(x)=E_x[f(X_S)]=P_x(tau_A<=S), S~Gamma(k,r),     (2)

where the finite capped process has frozen target and overflow cost0.
This construction acquires a receiving function for a target directly;
it never requires an accurate forward distribution or a trajectory on
all intermediate slabs. It is an explicit resolvent operation, rather
than a conditional appeal to an already supplied exact adjoint.

The inverse is entrywise nonnegative and has infinity operator norm1/r,
because the full augmented Q satisfies Q1=0. For a subgenerator with fixed
absorbing boundary values, the corresponding norm is at most1/r. Let
stored approximations V_j have exact defects

 R_j=(rI-Q)V_j-rV_(j-1).

No sign or normalization assumption on V_j is needed. Subtracting(1),
applying the positive inverse, and iterating proves

 ||V_k-U_k||_infinity
 <=||V_0-f||_infinity+(1/r) sum_j ||R_j||_infinity
 <=||V_0-f||_infinity+(1/r) sum_j ||R_j||_F.         (3)

All generation, rank truncation and arithmetic errors in the final stored
V_j are charged by these defects if evaluated against exact Q and the
actual stored previous vector. No additional claim follows from a local
AMEn tolerance or a diagnostic contraction. Output-rounding errors require
their own charge. Tensor Frobenius residuals can serve in(3) without the
forward L1 conversion factor163^4=705,911,761. This does not prove that
such residuals can be made small cheaply: backward vectors, terminal
layers, cancellation, precision, ranks and all-state verification remain
substantive obligations.

3. Deterministic deadline conversion, with no free clock approximation

For any first-hit CDF F_x(t), it is nondecreasing and lies in[0,1]. Write
z_x=E[F_x(S)] and c=P(S>=T). The clock is independent and continuous. Then

 F_x(T)c <= z_x <= F_x(T)(1-c)+c.

Consequently

 max(0,(z_x-c)/(1-c)) <= F_x(T) <= min(1,z_x/c),   (4)

when0<c<1. To account for an approximation radius eta in(3), insert
max(0,V_k(x)-eta) on the lower side and min(1,V_k(x)+eta) on the upper
side. A rational enclosure c_lo<=c<=c_hi gives

 L=max(0,(V_k(x)-eta-c_hi)/(1-c_hi)),
 H=min(1,(V_k(x)+eta)/c_lo).                       (5)

Different independent clocks can be used for the two sides. A small
random-horizon defect is not a small deterministic-horizon error; the
width H-L must itself fit the target budget. The mean-one Gamma(64,64)
clock used below has c approximately0.4833760124961735 and is deliberately
only a bounded test. It is inadequate as a generally sharp rare-event
deadline approximation.

For integer r and T=1,

 c=exp(-r) sum_(j=0)^(k-1) r^j/j!.

The independent replay uses e_32=sum_(j=0)^32 1/j! and

 e_32 < e < e_32+34/(33*33!).

The tail estimate follows because, after term1/33!, each successive ratio
is at most1/34. Raising these positive rationals to integer r and inverting
gives exact rational endpoints for c. No floating exponential or CDF is
used in the certificate.

4. Why the three existing forward trial spaces cannot simply be reused

The immutable raw NPZs were read with allow_pickle=False. The script
inspect_saved_bases.py checks all spatial cores' literal supports and
performs exact dyadic rank-one products at

 x_A=(15,15,15,15,15,15,15,15),
 x_C=(16,15,15,15,15,15,15,15).

Every localized basis is exactly zero at both points. In the first saved
space the sole nonzero broad basis satisfies b(x_C)=b(x_A)>0. In the
weighted space it satisfies b(x_C)=2b(x_A)>0. The constrained space has no
broad basis. For any real coefficient alpha, if b_A,b_C>0,

 min_alpha max(|1-alpha b_A|,|alpha b_C|)=b_C/(b_A+b_C).

Proof: an error e requires alpha b_A>=1-e and alpha b_C<=e; hence
e>=b_C/(b_A+b_C), attained at alpha=1/(b_A+b_C). Allowing negative alpha
cannot improve it. The three unchanged spaces therefore have unavoidable
backward terminal sup defects at least1/2,2/3 and1, respectively. The
exact target indicator has Frobenius norm16^4=65536. This is a terminal
receiver obstruction for these particular spaces, not for enriched/new
backward TT spaces. It does not lower-bound their forward target error.

5. Uncapped spatial comparison before any finite calculation

Partition the sites into the four vertical pairs(0,4),(1,5),(2,6),(3,7).
Define four independent UNCAPPED pair processes Y. Retain each pair's
vertical diffusion in both directions. At each site retain birth b(n),
retain local death a(n), and retain every removed horizontal departure
as an additional death Dn. Discard every horizontal immigration. Thus
each corner-column site has one extra death channel, while each inner-
column site has two. The four pairs use independent driving clocks.

There is a coupling with the original unfrozen X in which Y_i<=X_i up to
each pair's first hit of A_pair={both counts<=15}. Birth b(n) and local
death a(n) are nondecreasing. Common events preserve order; unmatched
X-only deaths cannot cross an integer gap. For a retained diffusion edge,
the common source rate D Y_i is bounded by D X_i; additional X-only hops
preserve order. For a removed horizontal edge, common departures reduce
Y and X at the source, while X alone receives the immigrant. X-only
departures again cannot cross an integer gap. The usual independent
Poisson random measures realize these common and residual rates. Each
Y has the stated local marginal generator, with no cross-pair dependence.
The argument can first be stopped in a finite box; nonexplosion of X and
Y<=X before a pair is stopped justify the unbounded limit.

Let H_p(T) be the event that uncapped pair p has hit A_pair by T. At the
original global target time, any pair that has not previously hit must
have Y_pair<=X_pair<=15 and therefore hits then. Hence

 {tau_A(X)<=T} subset intersection_p H_p(T).

Independence and symmetry give the valid upper comparator

 P_original(tau_A<=T) <= C(T)=q_1(T)^2 q_2(T)^2,  (6)

where q_e is the UNCAPPED first-pair-hit probability with e=1 or2 removed
horizontal neighbors at each site. This comparison also discards the
requirement that the four local first hits occur simultaneously. Its
failure cannot be attributed exclusively to immigration deletion or
claimed for every possible cluster/spatial method.

6. The finite hit-or-overflow event and the required two-sided transfer

The finite calculation retains0..162 at each of the two sites. It freezes
A_pair and sends each genuine outward transition to a comparison-success

events stops the finite process. The finite value is b_e(T)=P(B_p(T)).

Coupling finite and uncapped Y until first exit gives q_e(T)<=b_e(T).
Thus a certified finite hit-or-overflow upper bound is a valid upper for
the uncapped pair event, without silently treating killed-overflow mass
as an upper bound. The actual upper acquired in this test is only1.

To turn a large finite value into a lower bound on the UNCAPPED comparator,
the overflow receipt IS required. Before a pair hits A_pair, Y_pair<=X_pair.
If Y reaches163 before its pair hit and by T=1, original X has reached at
least163 by that time. Original global target cannot already have occurred:
it would have forced this pair's hit by the same order comparison. The

overflow probability by epsilon. Consequently

 b_e(1)-epsilon <= q_e(1) <= b_e(1).               (7)

One epsilon is subtracted for each of the four independent pair marginal
lower bounds. No claim that their overflow events are independent in the
original coupling is used. The pair hit events in(6) themselves are
independent under the product Y law. This is the exact place where the
original cap theorem is consumed.

9. Same-information comparator and unresolved operation

Positive-clock/resolvent evaluation is an Erlangization specialization,
not a new general numerical principle. Standard FSP can solve these same
finite pairs, and tensor uniformization can use the same target backward
operator. The rates, target, graph, cap theorem and symmetry are shared
with those incumbents; no exact adjoint, committor, favorable boundary
law, or physical measurement has been supplied for free.

An actual useful full-eight-site result still needs a new/enriched
spatial receiver, exact or outward residual bounds for it, tight deadline
conversion, cap accounting, and complete cost comparison. The finite pair
demonstration proves that the operation and verification work in its
recorded scope. It proves no affordable full-eight-site ranks, TT
convergence, rare-event answer or runtime advantage. External correctness,
historical priority and physical validation remain UNKNOWN.

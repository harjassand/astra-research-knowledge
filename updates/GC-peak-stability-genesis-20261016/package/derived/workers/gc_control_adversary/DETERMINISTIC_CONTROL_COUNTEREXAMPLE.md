## Adversarial cancellation with a complete local detector group

Let g(t) be any prescribed finite deterministic stabilizer-frame path. Take a local memory Pauli P, and write Ad(g(t))(P)=sigma(t)P with sigma(t) in {+1,-1}. Let B be a fixed bath involution, or simply B=I. Choose the laboratory interaction

    V(t)=sigma(t) J P tensor B.

It is Hermitian, has norm J, has the same fixed weak memory support as P, and is independent of the unknown initial private frame bit. It is allowed to vary in time by the source norm-only model. In the actual deterministic toggling frame it becomes the constant interaction J P tensor B. An initial uniform detecting sign f therefore yields

    U_f=exp[-i(-1)^f a P tensor B],  a=JT,
    K_odd=(U_0-U_1)/2=-i sin(a) P tensor B,
    K_odd^dagger K_odd=sin^2(a) I.

This is independent of the number or spacing of deterministic toggles. Thus no estimate tending to zero with that count can hold uniformly for a fully fixed sign path under only the source's time-dependent norm bound. This is a minimax example: the adversarial interaction may depend on the public deterministic schedule, without observing any private initial seed or quantum input.

The example need not hide a local logical operator. Take the standard five-qubit stabilizer group generated by

    X Z Z X I,
    I X Z Z X,
    X I X Z Z,
    Z X I X Z.

For the weak patch A={qubit 1}, these generators restrict to both X and Z. Hence the only A-supported Pauli commuting with the full group is identity:

    Pauli(A) intersect Centralizer(G)={I}

Choose P=X_1. Every deterministic g(t) in this complete group has a known sigma(t), so the previous construction respects the exact no-local-logical/detection condition on the weak patch. The arbitrary shared bath can be absent; adding an inert shared bath does not change the example. Completeness and correctability do not create the missing private refresh information.

This counterexample concerns the nonzero-character/endpoint suppression factor. A single correctable local error is not itself a logical failure, so it does not disprove the source's complete correction/geometry/decoder memory theorem. Controller gates on a larger physical footprint also need their own qualification; the example does not pretend their noise is covered by the smaller weak patch.

## Leakage shows why fresh bits must remain private

If a coupling follows the realized random update signs xi_b(t), then A_b(t)=xi_b(t) J P makes the toggling interaction constant again and the same sin^2(a) effect persists for any random grid size. This violates the source's requirement that A_i and Hbase be independent of selected refresh histories. It is a concrete failure when the controller/bath interface leaks those histories, not a theorem counterexample under the stated independence premise.

If both the initial private frame and updates are followed, even the initial-character support decomposition can fail: a physical nontrivial error may become seed independent and appear in the zero Walsh character. Thus merely maintaining a software frame record does not establish the physical common-dilation/covariance interface.

# Real-data audit: a measured SMA damper needs loading history to identify force

**Status (15 October 2026): scoped empirical result reproduced; consequential new operation NOT_ACHIEVED.** A public, primary experimental release supports one quantitative information/control statement: in a large-scale shape-memory-alloy (SMA) damper under a specified cyclic displacement protocol, present displacement alone does not determine measured actuator force. A controller can infer a useful branch state from earlier readings of the *same* displacement sensor. The release does not test a new controller, establish improved structural safety, or show an advantage over a competent history-aware incumbent.

## Source and inspected evidence

I inspected the record description and its [one-page loading protocol](https://zenodo.org/records/17296336/files/Load_Protocol_v1.0.0.pdf?download=1), plus four actual CSVs inside [Data_v1.0.0.zip](https://zenodo.org/records/17296336/files/Data_v1.0.0.zip?download=1): `02_8wires_sin20mm_0p5Hz.csv`, `05_8wires_sin40mm_0p5Hz.csv`, `07_4wires_sin20mm_0p5Hz.csv`, and `09_4wires_sin20mm_0p5Hz_after_EQ.csv`. The related [2026 primary article](https://doi.org/10.1016/j.jobe.2026.116572) was identified from the dataset and RWTH publication record; its full text was **not** used as evidence here.

The record says the wires are 800 mm NiTi specimens from one batch, approximately 55.7% Ni, preconditioned for 20 strain-driven cycles to 5% at 0.5%/s. The 8-wire damper was driven sinusoidally to nominal ±20 mm at 0.5 Hz in source file 02. The file has 16,384 rows and three recorded columns: `Time` (s), `Actuator1_Disp` (mm), and `Actuator1_Force` (kN). Nominal sampling is 512 Hz; the CSV times are rounded decimals near 1/512 s. The imposed motion occupies about 0–20 s, followed by a rest segment to 32 s. The record describes MTS actuators with an integrated 500 kN load cell. The recorded displacement is the achieved actuator signal; the exact command trace, sensor calibration/uncertainty and controller latency are not supplied. The source explains that later real-time hybrid simulations include physical dampers coupled to a numerical structure; this audit uses the separate sinusoidal physical-damper tests, not a purported all-physical earthquake trial.

## Exact test and result

The narrow claim is that a single-valued force rule \(g(x_t)\) cannot accurately represent both branches of this *measured* 8-wire, ±20 mm, 0.5 Hz trace at \(x=+10\) mm. For each of eight complete interior periods, 2–18 s, [audit.py](audit.py) finds the one rising and one falling crossing of +10 mm. It linearly interpolates force between the two adjacent recorded samples on each branch. This is a numerical interpolation of measurements, not an invented physical calibration.

| Quantity, actuator 1 | Reproduced result |
|---|---:|
| Rising minus falling force at +10 mm, eight periods | 4.029–4.229 kN |
| Mean branch separation | 4.133 kN |
| Smallest paired, interpolated minimax error for any static \(g(10\text{ mm})\) | 2.015 kN |
| Approximate mean \(\int F\,dx\) over those periods | 136.38 kN·mm = 136.38 J |

The third line follows from the elementary inequality \(\max\{|g-y_\uparrow|,|g-y_\downarrow|\}\geq |y_\uparrow-y_\downarrow|/2\), applied to each interpolated pair. It is a bound on this *finite recorded trace* and interpolation procedure. No measurement uncertainty was provided, so it is not a calibrated physical lower confidence bound. The work integral is actuator force against measured motion; it is not electrical consumption, control cost, or necessarily heat dissipated, because a period's internal state need not close exactly.

I also executed a causal, within-trace prediction check. A static lookup uses 0.5 mm displacement bins; a history lookup uses the identical bins plus the sign of \(x_i-x_{i-16}\). The latter reads only prior samples (16 samples = 31.25 ms at the nominal rate), with no extra physical sensor or future force. Both tables use per-bin training medians from four interior periods, 2–10 s. On the next four periods, 10–18 s, every one of 4,096 rows is covered. The static table has 81 bins and gives 1.465 kN mean absolute error; the branch-aware table has 162 bins and gives 0.223 kN, a 6.58-fold reduction. The branch predictor is a familiar hysteresis-aware baseline, not a new algorithm. Bin widths 0.25–1.0 mm and causal lookbacks 8–32 samples still give branch-aware errors 0.181–0.350 kN, while the static errors remain 1.465–1.482 kN; the exact numbers and settings are in [RESULTS.json](RESULTS.json). The split consists of consecutive cycles in **one run**; it does not establish cross-device, cross-rate or prospective performance.

The [plot of a measured interior cycle](hysteresis_cycle.png) visibly shows the two force branches. Source file 05, the same 8-wire configuration at nominal ±40 mm and 0.5 Hz, provides a second measured check: its +10 mm gap is 5.119–6.689 kN across the same eight interior periods. The matched 4-wire, ±20 mm, 0.5 Hz files labeled before/after earthquake testing have mean branch gaps 1.955 and 1.844 kN, and approximate mean loop work 67.27 and 62.15 J. Those latter changes are observations under separate test runs; the files lack an environmental/fixture control sufficient to attribute them uniquely to earthquake exposure or material damage.

## Operational meaning, equal-information comparator and costs

The substrate stores loading-path state in its hysteresis. A feasible readout would combine measured actuator displacement with retained displacement history and use the inferred branch in force estimation or control. The decisive mathematical point is input nonidentifiability for a memoryless force law: no amount of static fitting to this trace can map the same +10 mm to both branch forces. The strongest equally informed comparator is an ordinary hysteresis-aware force estimator or controller (including any competent model using the same displacement history, force calibration runs, clock and actuator interface). It can use this branch information too. Thus the present audit gives **no competitive advantage, novelty claim or controller design win** for a special ASTRA operation.

The physical acquisition/preparation/control bill is material: construction and mounting of the NiTi wire damper; the authors' 20-cycle wire conditioning; a displacement-driven MTS rig and force load cell; at least 512 Hz acquisition for the reported trace; repeated force-labeled calibration cycles if using either empirical lookup; and a 16-sample history buffer for the tested branch bit. The branch table doubles the number of occupied bins from 81 to 162 in the chosen scheme. The 31.25 ms lookback is a data-history span, **not** a measured latency or a demonstrated real-time controller delay. Equipment electricity, conditioning energy, control computation energy, actuator command error, load-cell uncertainty, reliability under damage, and scaling to structures or many dampers were not measured in this audit. Nothing here allows these costs to be declared negligible.

A decisive next experiment would run the physical damper under preregistered, held-out earthquake-like trajectories and compare force tracking or protected-structure response using (a) the proposed branch-aware interface and (b) the best standard history-aware controller, with identical measured channels, sensor calibration, training exposure, update rate, actuator limits, latency and total energy. Randomized order and repeated specimens would separate controller benefit from drift or conditioning. The public CSV supports the input-state necessity test above; it cannot run or substitute for that intervention.

# Decisive physical test of the snapshot operation

Status: proposed experiment; no device access, new measurements, measured confidence set or measured advantage.

Use a stationary, zero-magnetic-field double quantum dot with charge states 0,L,R and a quantum-point-contact charge detector. Küng et al., J. Appl. Phys. 113,136507 (2013), https://doi.org/10.1063/1.4795540, demonstrate this three-state charge-monitoring platform, thermal transitions, tunable bias, and a current/voltage/temperature entropy ledger. Root inspected the primary author-hosted PDF's apparatus, three-state description and detector-bandwidth/back-action sections: https://people.phys.ethz.ch/~ihn/papers/Kung13.pdf. The source does not demonstrate our snapshot statistic, the homogeneous 20:1 target, an ideal memoryless detector, or superior inference costs.

The substrate is the actual charge device. Label 0 as A and both occupied states as B. Tune stationary gate and source-drain settings; the proposed assay does not run periodic feedback while claiming a time-homogeneous Q. First acquire full charge-state trajectories, independent bias/current/temperature measurements, detector impulse response and sensor-bias dependence. Quantify missed-state probability, temporal detector memory, back-action, additional charge states, cotunneling, reservoir channels and slow drift. An uncalibrated low-bandwidth filtered detector does not meet the independent memoryless-noise premise. Treat residual finite-Markov-model mismatch as an explicit observation-law error budget; finite held-out checks qualify an envelope and do not prove an exact microscopic model.

Freeze r and the clock law using a separate pilot. Use the same programmed distribution independently for both inter-snapshot gaps. Reveal only three binary snapshots and timing to the proposed method. Obtain stationary independent preparations if physically justified; otherwise estimate dependence using separately validated dynamics and use a dependence-valid confidence method. Do not count adjacent triplets as independent. If a verified independent-start interface cannot be obtained, the simple Hoeffding design is not executable as stated.

Competing predictions are precise:

1. Under an all-even equilibrium hidden CTMC and qualified noninvasive detector, the population score W has nonnegative mean. With predeclared confidence and model/detector errors included, a positive lower dissipation certificate is a controlled false rejection.
2. For the specified biased ring calibration, exact calculation predicts the negative score in SNAPSHOT_EXACT_RESULTS.json and a positive all-even floor. Real measured rates need not realize that fixture; use their independently acquired model only as a prediction, then test the withheld snapshot records. A null result can be ordinary lack of sensitivity.
3. Deliberately correlate the gap pairs or introduce detector memory. The saved two-state equilibrium counterexample predicts that these unqualified operations can yield negative scores; the assay must reject their interpretation, not report specimen dissipation.
4. After all interface gates pass, the certificate must stay below the independently acquired charge-transport entropy ledger, within its uncertainty and model discrepancy. An excess falsifies the observation/model/thermodynamic mapping. This ledger is not the total refrigerator, detector and electronics power.

Give a competing team the same snapshots, clocks, calibrations, independent preparations and analysis budget; allow optimized reflected-moment, likelihood and existing hidden-entropy certificates. In a second equal-total-cost comparison allow full continuous charge detection and waiting-time methods. Count wafer/device preparation, refrigeration, detector duty, calibration, rejected runs, time, readout damage/back-action, computation and uncertainty. Larger mathematical certificates do not establish a better experiment. A same-data method can compute our statistic too, so any claimed benefit must be measured finite-sample calibration or acquisition economy.

The physical-parity question is a separate discriminator. Binary trajectories alone cannot distinguish the original ring from the exact parity lift. A claimed equilibrium lift needs an actual signed odd coordinate and conjugate transition channels, not a renamed electronic bit. Measure that coordinate and its transition/velocity-reversal response, plus heat/work/chemical exchange, before treating the lift as a physical zero-dissipation device. The current electronic proposal qualifies an even-charge model; it does not manufacture an odd-parity implementation.

Stop if detector/model error consumes the negative margin, independent or dependence-qualified stationary trials are unavailable, the statistic is beaten at equal cost, or the physical reversal cannot be justified. Those outcomes preserve the theorem while denying physical operational closure. No further conditional simulation substitutes for this experiment.

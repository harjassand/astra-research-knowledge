With joint kernel zero, absence of a good two-plane implies `m <= 2w-1`. That dimension bound overlaps the earlier N55 scope; the new dossier emphasizes the explicit coupling and sampler and does not replace N55.

Sunflower-free binary supports in this model have at most `2^w` rows. A projective-plane example rules out one broad subfamily-acquisition route at fixed width two, not acquisition on sunflower-free families.

The exact sampler is exponential in the observed width and does not learn the representation.

A separate exact linear feasibility criterion handles three different marginals. Neither local result by itself supplies global gluing.

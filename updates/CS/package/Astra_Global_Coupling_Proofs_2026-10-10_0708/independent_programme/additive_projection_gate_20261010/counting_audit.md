# Independent audit: counting, entropy, and exact sampling

## Verdict

The proposed counting lower bound, latent relative-entropy bound, common-kernel reduction, and five-term fixed-parameter count/sampler are correct. Handle \(w=0\) separately, and use affine rather than homogeneous solution counting once a prefix is fixed.

All logarithms below are natural. The same formulas hold in another base if that base is used consistently.

## Definitions

Let \(V=\mathbb F_2^m\), with linear maps \(L_i:V\to V_i\), \(1\le i\le w\). Define
\[
C=\{(u,v)\in V^2:\operatorname{rank}(L_i|_{\langle u,v\rangle})\in\{0,2\}\text{ for all }i\}.
\]
Equivalently, for each block the two vectors \(L_i u,L_i v\) are either both zero or linearly independent. This definition includes the degenerate pair \((0,0)\).

A good plane is a two-dimensional linear subspace on which all maps have rank zero or two.

## 1. Joint kernel zero: exact count from good planes

Suppose \(\bigcap_i\ker L_i=0\). A dependent pair other than \((0,0)\) spans a line generated by a nonzero \(x\); some \(L_i x\ne0\), so this pair is inadmissible. Every admissible independent pair is an ordered basis of a unique good plane. Each binary plane has exactly
\((2^2-1)(2^2-2)=6\) ordered bases. Therefore, if \(G\) is the number of good planes,
\[
|C|=1+6G.\tag{1}
\]

Let \(w\ge1\), \(d=2w\), and \(m\ge d\). Every \(d\)-dimensional subspace contains a good plane, by the proved \(m\le2w-1\) obstruction bound applied to the restricted maps. Their joint kernel remains zero.

Double-count incident pairs consisting of a good plane and a containing \(d\)-subspace. There are \({m\brack d}_2\) such subspaces, and any fixed plane belongs to \({m-2\brack d-2}_2\) of them. Consequently,
\[
G\ge\frac{{m\brack d}_2}{{m-2\brack d-2}_2}
=\frac{(2^m-1)(2^m-2)}{(2^d-1)(2^d-2)}.\tag{2}
\]
Both denominators are positive because \(d\ge2\). For \(m\ge d\) and \(c\in\{1,2\}\),
\[
\frac{2^m-c}{2^d-c}\ge2^{m-d}.
\]
Thus (2) actually gives \(G\ge4^{m-d}\), and (1) gives the stronger bound
\[
|C|\ge1+6\cdot4^{m-2w}\quad(m\ge2w,\ w\ge1).\tag{3}
\]
In particular, the requested weaker bound holds:
\[
\boxed{|C|\ge4^{m-2w}.}\tag{4}
\]
When \(m<2w\), (4) follows simply from \((0,0)\in C\).

## 2. Common-kernel reduction

Let \(H=\bigcap_i\ker L_i\), with \(h=\dim H\) and \(n=m-h\). Every map factors through \(V/H\), and the quotient maps have joint kernel zero. Admissibility depends only on the quotient pair. If \(\overline C\) is its admissible set, then
\[
C=(\pi\times\pi)^{-1}(\overline C),\qquad
|C|=4^h|\overline C|.
\]
Applying (4) in quotient dimension \(n\) yields
\[
\boxed{|C|\ge4^{m-2w}}
\]
without any joint-kernel assumption. Also \(|C|\ge4^h\).

Uniform quotient sampling followed by independent uniform kernel lifts gives a uniform element of \(C\), although the direct exact sampler below needs no quotient reduction.

## 3. Uniform marginals and exact relative entropy

Choose \((u,v)\) uniformly from \(C\), and choose \(a\) independently and uniformly from \(V\). Define
\[
(X_1,X_2,X_3)=(a,a+u,a+v).
\]
Every \(X_j\) is uniform on \(V\), including when \(C\) is highly nonuniform in either difference coordinate. The map
\[
(a,u,v)\longmapsto(a,a+u,a+v)
\]
is a bijection on \(V^3\).

The latent law is uniform on \(V\times C\). Relative to the uniform law on \(V^3\), its exact divergence is
\[
D_{\mathrm{KL}}\bigl(U(V)\times U(C)\,\|\,U(V^3)\bigr)
=\log\frac{4^m}{|C|}
\le\boxed{2w\log4}.
\]
The same equality holds for the triple law relative to the product of its three uniform marginals, because the above map is bijective and preserves the uniform reference measure. One may also bound this divergence by \((m-h)\log4\) using \(|C|\ge4^h\).

If further deterministic maps are applied to the triple, data processing gives an upper bound by this latent divergence; equality after such further maps is not asserted.

## 4. Five-term expansion

Write \(\delta(z)=\mathbf1_{z=0}\). For a fixed block, set \(p=L_i u\) and \(q=L_i v\). The exact admissibility indicator is
\[
f_i(u,v)=1-\delta(p)-\delta(q)-\delta(p+q)+3\delta(p)\delta(q).\tag{5}
\]
Verification:

- Rank zero: all three delta values are one, so the expression is \(1-3+3=1\).
- Rank one: exactly one of \(p,q,p+q\) is zero, and \(p,q\) are not both zero, so the expression is zero.
- Rank two: none of \(p,q,p+q\) is zero, so the expression is one.

Therefore
\[
|C|=\sum_{u,v\in V}\prod_{i=1}^w f_i(u,v).
\]
Expanding the product gives \(5^w\) terms. Each term has integer coefficient \((-1)^s3^t\) and imposes some combination of the homogeneous linear constraints
\[
L_i u=0,\quad L_i v=0,\quad L_i(u+v)=0,
\]
where the fifth option imposes the first two simultaneously. If the resulting coefficient matrix has rank \(r\), the term's unweighted count is \(2^{2m-r}\). Summing all weighted counts gives the exact nonnegative integer \(|C|\), despite cancellations between terms.

Zero maps or duplicate equations cause no difficulty. All arithmetic should be exact integer arithmetic. Intermediate integers have polynomial bit length: a crude total-magnitude bound is \(4^m7^w\).

## 5. Prefix counting and an exact uniform sampler

Fix a coordinate basis for \(V\times V\), giving \(2m\) binary coordinates. For any prescribed prefix, append its equations to each expanded term's system. These augmented systems are generally affine, not homogeneous:

- An inconsistent system contributes zero.
- A consistent system with coefficient-matrix rank \(r\) contributes \(2^{2m-r}\), multiplied by its signed expansion coefficient.

This gives the exact number \(N(s)\) of admissible completions of every prefix \(s\).

An exact uniform unranking sampler is:

1. Compute \(N=|C|\), which is always positive.
2. Draw an integer \(R\) uniformly from \(\{0,\dots,N-1\}\).
3. At each coordinate, compute the number \(N_0\) of completions extending the current prefix by zero. If \(R<N_0\), append zero; otherwise append one and replace \(R\) by \(R-N_0\).
4. Continue through all \(2m\) coordinates.

This is a bijective unranking of the admissible pairs, so the output is exactly uniform. Drawing \(R\) from unbiased random bits can use standard rejection sampling, with fewer than two expected trials.

The running time is \(5^w\operatorname{poly}(\text{input size})\), including the polynomially many prefix-count calls. Thus this is fixed-parameter tractable in \(w\), not polynomial time when \(w\) is unrestricted.

## 6. Degeneracies

- \(w=0\): all pairs are admissible, \(|C|=4^m\), and the divergence is zero. Do not invoke the plane incidence formula with \(d=0\). If joint kernel zero is also assumed, then necessarily \(m=0\).
- \(m=0\): \(V=0\), \(|C|=1\), and divergence is zero for every \(w\).
- \(m=1\) and joint kernel zero: \(C=\{(0,0)\}\). There are no planes, so (1) remains correct with \(G=0\).
- All maps zero: \(H=V\), \(|C|=4^m\), and divergence is zero. Formula (5) is identically one block by block.
- \(m=2w\) with \(w\ge1\): the incidence formula is valid and gives \(G\ge1\), hence \(|C|\ge7\).

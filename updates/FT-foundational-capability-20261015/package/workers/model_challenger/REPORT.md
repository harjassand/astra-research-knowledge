# Model challenger report: dual-rail erasure information and the SWS gate path

**Date:** 15 October 2026
**Role:** independent physical-model challenger/inventor
**Search boundary:** began from primary experimental literature. I did not inspect other current-worker outputs or optional Astra-capital folders. This report records an established experimental alternative and a narrow proposed mutation; it makes no Astra novelty, advantage, or validation claim.

## Finding

A standard qubit-plus-Pauli interface throws away a useful physical output. In a dual-rail qubit, the logical basis is one excitation in either of two modes,

\[
|0_L\rangle=|1,0\rangle,\qquad |1_L\rangle=|0,1\rangle.
\]

Loss from either codeword leads to the same vacuum \(|0,0\rangle\). A hardware measurement can therefore return a third output symbol, “erasure,” that gives the decoder the location of the error. This is a real change in the channel the computer exposes, not just a relabeling of a Pauli error.

The strongest demonstrated cavity implementation I found is the Swap–Wait–Swap (SWS) controlled-Z (CZ) gate, published by Mehta et al. in Nature on 5 August 2026. The control excitation is temporarily swapped from one cavity into a transmon coupler, allowed to acquire a dispersive phase against a cavity in the target dual rail, and swapped back. The experiment used four microwave-cavity modes for two logical qubits, three SQUID transmon couplers, and a transmon/readout resonator on each cavity for state preparation and measurement. It reported a roughly 500 ns CZ, about 0.53% erasure probability per CZ, residual Pauli error below 0.1% after erasure detection, and bit flips around 10^-6 per gate. The control rail has the larger error rate because its excitation spends time in the less coherent coupler.

This is strong evidence for the user's co-design hypothesis as an engineering method: the mathematical operation (CZ), physical information (vacuum flags), control path (parametric swaps), temporary intermediate state (coupler excitation), and verification (flagged process tomography / randomized benchmarking) were designed together. It is prior art, so it is not a new Astra capability by itself.

## A concrete coupled obstruction

The temporary interaction creates a specific error channel. If the control photon is lost during the SWS wait, the gate stops at an unknown time and the target receives a partial CZ of unknown angle before the control erasure is flagged. The primary experiment verified that a control loss before the gate turns the gate off, while loss during the gate produces a conditional dephasing channel on the other qubit. Thus a final erasure flag does not, by itself, say which phase the surviving qubit accumulated. A Pauli-only model misses the correlated flag-plus-phase structure; an erasure-only model misses the residual conditional channel.

There is a simple timing bound for a proposed correction based on measuring the loss time. For the demonstrated \(|\chi_{bc}|/2\pi=1.51\) MHz interaction, the ideal entangling wait is \(T=\pi/|\chi_{bc}|\approx331\) ns (the full gate is about 500 ns). A timestamp error \(\delta t\) leaves phase error \(\delta\phi=|\chi_{bc}|\delta t\). For a small residual one-qubit phase rotation, average gate infidelity is approximately \(\delta\phi^2/6\). Keeping that contribution below 10^-3 therefore requires an event-time uncertainty below about 8 ns. This is a derived engineering target, not a demonstrated readout capability.

A 2026 experiment by Hung et al. supplies a useful comparator for the readout idea, but on a different platform: two transmons encode the dual rail and one symmetrically coupled resonator reads erasure without resolving the logical rail. Single-shot checks take 384 ns and produce a residual logical error of 6.0(2)×10^-4/check, including idling during the check; the check's estimated pure induced dephasing is 8(3)×10^-5. Continuous monitoring during 24 ns single-qubit gates reached median residual gate error 7.2×10^-5, versus 6.5×10^-5 with discrete checks, while the monitor added less than 10^-5. Erasure probability per gate increased from 1.8×10^-3 without continuous monitoring to 2.6×10^-3 with it. The experiment used 480 ns integration windows for continuous event classification, roughly 50 times longer than the ~8 ns timestamp target above; it does not report sub-window event-time precision, so that must be measured from the analog record before judging whether timing correction is feasible. It also measured a readout-associated reduction of erasure lifetime by about a factor of two. These data show that co-designed monitoring can overlap a control operation, while also exposing a measurement-time / loss / residual-error tradeoff.

The proposed mutation is therefore narrow: for an SWS cavity gate, add a QND continuous occupancy monitor that treats the two control cavities *and the temporary coupler* as the same one-excitation manifold, while distinguishing that manifold from vacuum; monitor the target dual rail similarly. Feed the analog record and erasure flags into a correlated decoder or a conditional phase correction. The target monitor must not distinguish its two logical rails. The control monitor must not distinguish the photon in either original cavity from the same photon in the coupler during the swap. Otherwise the monitor extracts logical which-path information and dephases the data it is meant to protect.

This coupling condition is demanding but concrete: the monitored resonator response must be equal for all states within each active logical manifold and different for its vacuum state. A two-rail SRO experiment established the static version for a transmon encoding. No experiment I found established it for the cavity SWS path, which temporarily populates a third mode and deliberately makes a cross-Kerr interaction with the target.

## Strong comparator and costs

The strongest direct comparator is a same-task surface-code simulation using the SWS error rates versus a conventional 0.1% two-qubit depolarizing channel. The SWS CZ had roughly five times the total error of that Pauli-gate comparator, yet the reported simulated logical-error reduction factor per increase of code distance by two was about 27 versus about 14 for the depolarizing model. This supports the value of structured, located errors. It is a model comparison, not an experimental logical-memory comparison.

The simulation deliberately used a restricted noise model: measured low-depth CZ error rates, perfect erasure checks delayed to the end of a syndrome round, and omission of subsequent CZ gates after leakage. It did not include one-qubit gate errors, measurement or erasure-check errors, or idling errors. The 5.6% erasure threshold likewise assumes erasure-only CZ noise and perfect delayed checks. The paper explicitly leaves simulations with imperfect checks and the full noise set to a future manuscript. No surface-code cycle or logical-qubit scaling result was demonstrated in this experiment.

The measured postselection cost is also material. Without active QEC or retries, independent 0.53% erasures per CZ leave an all-surviving fraction of roughly \((1-0.0053)^m\): about 59% after 100 CZs. The code can correct erasures, so this is not itself a logical failure rate; it is the raw shot-yield cost when using postselection. The apparatus cost is four cavity modes for two logical qubits plus the couplers, calibration, state-preparation/readout transmons and resonators. Published per-gate infidelity does not include the full cost of a repeated error-correction cycle.

There is also a strong same-family check comparison. A cavity dual-rail mid-circuit erasure-check experiment reported 2.92% total erasures/check, 0.31% Pauli error/check, 0.51% false positives/check, and 3.7% false negatives conditional on already being in vacuum; its 1.82 μs selective pulse was followed by transmon readout. A separate transmon-dual-rail SRO experiment reduced check duration and logical backaction, but still measured 2.54% erasures/check and readout-associated loss. These check results must not be silently combined with SWS rates: they come from separate experiments, and the SRO result also uses another encoding. They do establish that repeated checks can cost more than a 0.5% SWS gate unless the architecture exploits delayed checks or overlaps monitoring with gates.

In fact, the SWS paper already contains a relevant alternative to my proposed monitor: the gate is designed so a rail that was erased before CZ makes the gate act as identity, and leakage during a CZ can be represented as an unknown-angle CPHASE followed by loss. Its surface-code model delays checks until the end of each syndrome round and reports no bad hook errors in an exhaustive single-leakage-location check. This makes a new monitor less compelling unless a full realistic circuit model shows that the unknown-angle branch or imperfect delayed check materially limits scaling. The demonstrated mutation most directly addressing check overhead is thus native “leakage skips subsequent gates” plus delayed checking; that is already the 2026 paper's contribution, not my invention.

## Proposed experiment and decision rule

The proposed follow-on is a matched gate-path experiment, not a claim of benefit:

1. Use the SWS four-mode/two-qubit unit and add occupancy readout with equal dispersive response for the control photon in either cavity or the temporary coupler, and equal response for the target photon in either target cavity. Keep the zero-excitation response distinguishable.
2. Prepare both logical basis states and superpositions. Run the 500 ns SWS gate while recording the analog monitor output. Include calibrated loss injection over the wait interval so event time is known to the experimenter, then test the monitor's estimated time independently.
3. Compare three decoders on the same raw shots: (a) end-of-gate flag only; (b) end-of-round delayed erasure checks with the experimentally measured conditional phase channel; and (c) continuous monitor record plus time-conditioned phase correction. Record event-time uncertainty, erasure sensitivity, false flags, monitor-induced loss, logical dephasing, target conditional channel, circuit survival and surface-code logical error under matched noise.
4. Continue the monitor path only if it improves full-circuit logical error or resource-normalized yield relative to delayed checking after charging readout/coupler hardware, extra loss, reset, and decoder costs. Reject the phase-correction path if event-time uncertainty exceeds about 8 ns at the published χ for a 10^-3 added phase-error budget, or if matched response cannot keep monitor-induced logical error below the existing per-gate residual.

A faster SRO-style readout is not automatically the answer. The transmon-dual-rail demonstration used 384 ns single-shot checks and 480 ns classification windows, while the SWS gate takes ~500 ns and needs substantially finer phase timing for correction. Sub-window timing has not been reported. The SRO experiment also observed approximately doubled erasure rate while the readout drive was applied. A decoder that uses the known conditional dephasing distribution may outperform physical timestamp correction without that readout burden; this is a live alternative and should be tested first in simulation using measured channels.

## Conclusion for the capability search

This is a strong, experimentally grounded example that changing the state representation and output interface can expose a more correctable operation. The decisive qualification is that “flagged loss” is not a complete error description once an entangling interaction continues during an unknown-time loss. The exact physical structure helps: SWS can make later gates skip a leaked rail, and the published simplified code model indicates delayed checks can work. My independent invention candidate is a coupler-inclusive continuous erasure monitor with time-conditioned decoding, but current evidence does not show that it beats this delayed-check path. The immediate kill test is a full cost-matched noisy surface-code comparison with experimental false-positive, missed-erasure, dephasing, loss-during-readout, one-qubit, and idle channels. Until that test passes, the evidence supports an attractive hardware operation and a candidate experiment, not an end-to-end computational capability.

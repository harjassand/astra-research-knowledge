## Main source conclusion

2601.20818v3 gives a detailed discrete-time, two-dimensional, translation-invariant QCA construction for encoded fault-tolerant universal computation, with its threshold proof in the Supplementary Information. Its continuous-time, asynchronous, time-independent Lindbladian extension has detailed mechanism descriptions but is explicitly an outline: the authors say the proof is not given in full formal detail and leave it for future work. The finite clocks, Toom-style repair, damage-set transfer and waiting-time conversion below are therefore source claims and proof sketches, not a proved continuous-time gate theorem in this version.

2610.05589v1 proves an asynchronous quantum-to-classical reduction for a specified class of syndrome-based Lindbladians. Its concrete local-register construction implements synchronous SPCA memory using a globally periodic Reset/Read/Execute schedule. The paper explicitly leaves the time-independent realization of that synchronous SPCA memory open. This is a useful proof of a scheduled local-register memory implementation, not an asynchronous quantum gate controller.

Neither source states a general impossibility result. “Open” below means not established by that source.

## Focused reading for a new gate/clock design

For a candidate autonomous 2D gate controller, 2601 supplies the most directly relevant clock architecture: bounded modulo counters, local consistency on overlapping gate supports, finite-neighborhood repair, and a damage-region readout protocol that waits until every neighborhood has passed the last circuit layer before switching to memory behavior. Keep each item marked as part of the continuous-time outline unless a new proof fills the gap.

The clearest proof obligations exposed by that outline are: formalize the modulo-clock validity/repair invariant around all neighborhoods; prove the claimed \(O(M^+)\) consensus return for the stated update rule and residue conventions; show damaged-clock events obey the same recursive sparsity bound as data/control faults; formalize the uniform waiting-time estimate from the finite-state local process; and connect the Poisson trajectory law to the asynchronous fault model without broadening the noise model beyond local unitary jumps. The source itself says engineered-channel imperfections are outside its stated model.

The 2610 construction is a comparator for a different solution to an adjacent issue: it snapshots a synchronous predicate into local classical flags before any data corrections run, which prevents earlier corrections from changing a later site's decision. Its proof uses a globally repeated schedule and its goal is a memory bound. Do not transfer its cycle-boundary theorem to an unscheduled local gate history without a new argument.

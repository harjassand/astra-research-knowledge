# Receiving the crossed execution surface into a four-bank quantum ratchet

16 October 2026. Controlled recombination of this worker's occupied-port idea with s01's [crossed-plaquette execution surface](../s01_controller_repair/TRANSITION_TABLE.md), following the root's request. **Status: ideal four-bank reuse and isolated-tile release are established at the abstract atomic level; a two-bad-site trap refutes the listed receiver's general noisy progress. Recursive compilation and bounded damage remain open.** This is a modification of s01's candidate, not an interpretation of the original asynchronous scheme in arXiv:2601.20818v3.

## Why a naive two-bank merge fails

If the same physical \(A/B\) bank alternates both for protected idle EC and for gate execution, EC changes \(A\leftrightarrow B\) without incrementing s01's gate counter \(c_v\). Then bank parity no longer witnesses actual gate count. Conversely incrementing \(c_v\) for each idle EC changes the next noncommuting gate label. Thus the simple two-bank carousel cannot be plugged into s01 as a gate-history certificate.

Use **four** banks at each site, indexed \((g,e)\in\mathbb Z_2^2\). The outer bit \(g\) is the physical gate-execution frontier and obeys \(g=c_v\bmod2\) on legal states. The inner bit \(e\) alternates only for logical-identity EC. Exactly one of the four banks is occupied by a protected logical packet; all others are encoded vacuum. A separate logical erasure state \(E\) counts as occupied for control but carries no unknown qubit. Both \(|\perp\rangle\) and \(E\), along with \(|0\rangle,|1\rangle\), belong to an encoded **four-level** local alphabet. This extends the one-shot qutrit code of the independent candidate; it is not a qutrit. The code must be spatially spread over lower-level sites: putting all its physical constituents in one noisy site gives no protection against an arbitrary onsite fault. One physical fault cannot flip its *valid encoded* class only if code distance exceeds the actual fault support.

## Concrete abstract transition rows

Use s01's even \(q\ge8\), \(c_v\in\mathbb Z_q\), \(Valid_p\) and \(StarValid\) predicates. All listed proposal clocks are exogenous and local; their quantum maps are CPTP after dephasing the classical guard sectors. At the bottom fixed block size their supports are constants. The table is a proposed **abstract level** interface for recursive compilation.

| Jump | Guard | Atomic action |
| --- | --- | --- |
| \(B_v\) | at least one of the four physical bank blocks is outside its code sector | perform a total syndrome-recovery channel on all four bank blocks, returning them to their code sectors; on a specified correctable fault set it restores each prior logical sector exactly, and on other inputs its output is unrestricted within the code space |
| \(EC_v\) | exactly one valid occupied or erasure bank \((g,e)\); the other bank \((g,1-e)\) vacant | apply fixed-size recovery to the occupied data and move it to \((g,1-e)\); clear old bank; leave \(c_v,g\) unchanged |
| \(G(P,k)\) | s01's gate guard: all four \(c_v=k\), \(k\bmod2=p(P)\), every participant \(StarValid\); additionally each participant has one valid occupied bank with outer \(g=k\bmod2\), all destination outer banks vacant | apply the actual \(K_{P,k}\) on the four occupied quantum banks, move all four outputs to outer bank \(1-g\), inner bank \(e=0\), vacate source banks, and set all four \(c_v=k+1\) in the **same channel** |
| \(R_v\) | s01's unique six-neighbor counter candidate **and** its residue parity matches the sole decoded occupied outer bank at \(v\); no pending bank syndrome | restore only \(c_v\), leaving every quantum bank untouched |
| \(R_P\) | an invalid plaquette; **no enabled \(R_v\) on its four sites**; each participant has exactly one valid encoded occupied bank and no pending correctable occupancy syndrome; a **unique** vector of its four counter residues matches each site's encoded outer-bank parity and makes every tile incident to \(P\) valid | write that four-counter vector atomically, leaving quantum data untouched |
| \(A_P\) | invalid plaquette; no enabled unique \(R_v\) on its four sites and no unique \(R_P\); all four bank sectors decoded; at least one four-counter vector makes every incident tile valid **without** using bank parity | choose the lexicographically least such residue vector in the fixed color ordering of \(P\); write its counters, replace all four data packets by \(E\) in the corresponding outer banks and vacuum in every other bank |
| \(F_v\) | \(StarValid(v)\); every bank has a valid decoded sector and no pending correctable occupancy syndrome; the occupancy pattern is not exactly one packet in the outer bank \(c_v\bmod2\) | put \(E\) in that expected bank and encoded vacuum in all others. Leave \(c_v\) unchanged. |
| \(Reset_v\) | a bank is certified encoded vacuum after sector recovery | prepare encoded vacuum in that bank; identity on every occupied bank |

The \(G\) channel has one Kraus branch per vector of inner-bank choices, exactly as in the one-shot [candidate specification](CANDIDATE_SPEC.md). A proposal reads current \(e\) values rather than a saved EC phase. Repeating \(G(P,k)\) before another tile acts cannot replay \(K_{P,k}\): the four old source outer banks are vacant, \(c\) has advanced, and the gate guard is false. An \(EC_v\) proposal can occur immediately before or after \(G\), but if \(G\) is a single atomic map, the two possible orders have the same decoded action on correctable code states.

Define the gate action on \(E\) explicitly. \(H\) and \(T\) leave an \(E\) input at \(E\); a CNOT with \(E\) on either participating input outputs \(E\) on both participating wires; other tile wires pass through. On the all-qubit sector it applies the actual \(H,T,\mathrm{CNOT}\) channel. Dephasing these orthogonal erasure-pattern sectors gives a CPTP extension \(K^\sharp_{P,k}\). This conservative propagation preserves a visible data-fault lineage, but it can grow along arbitrarily many otherwise correct CNOTs. A recursive threshold proof therefore needs a fault-tolerant EC checkpoint before that shadow exceeds the outer code's capacity.

There is no routine reset of an occupied bank. On ambiguous states the \(A_P\) and \(F_v\) rows erase information by inserting \(E\); those are *bad data events* to be corrected by an outer code, never claims to reconstruct a missed \(H\), \(T\), or CNOT. A correctable physical occupancy syndrome is handled by \(B_v\) before \(F_v\) becomes enabled. The two channels can have independent clocks because their guards are disjoint. The totality of \(B_v\) prevents invalid physical bank syndromes from causing a permanent *single-site* stall, but this is still an abstract recovery row whose fault-tolerant lower-level implementation must be supplied.

### Exact bare finite-carousel lemma

For a fixed local physical alphabet with **ideal atomic** rows, start from a clean crossed surface and one occupied bank \((c_v\bmod2,e_v)\) at every site. Induct on the sequence of proposals. An EC row flips only \(e_v\) and vacates its old inner bank, preserving the outer parity and decoded logical state. A reset row changes only certified vacuum. A gate row applies its prescribed noncommuting \(K_{P,k}\), moves all four output packets to the opposite outer bank, vacates their source banks and increments their four counters in the same channel; hence the new outer parity is again \(c_v\bmod2\). s01's clean-surface invariant proves all later legal gate labels form the required per-wire order. Every bank has been freed after at most the next gate, so the **same four banks** serve arbitrarily many clean gate/EC rounds, including after a \(q\)-counter wrap. There is no stale acknowledgment or pending transfer object in this Markov generator; each proposal reads the current occupation and counters. The gate word at a reused site must itself be \(q\)-periodic or supplied by an additional protected program track; a finite carousel alone cannot store an arbitrary unbounded nonperiodic instruction list.

Once a clean tile \(P\) is ready, its four sites have the correct parity for \(P\). No other tile touching one of those sites can fire at that counter value, and exterior clean gates preserve \(StarValid\). EC only changes inner banks and reset only vacuum, so \(G(P,k)\)'s guard stays enabled until it fires. Its private rate-\(\lambda\) Poisson clock therefore gives an exterior-uniform \(\operatorname{Exp}(\lambda)\) ready-service delay **at this atomic level**. The claim stops before encoded compilation: there a gate is a multi-step lower-level gadget, and proving the same persistent guard is the missing work.

## Local release proof for the root's phantom attack

Start in a clean s01 configuration with \(c_v=k\) and the true packet in outer bank \(g=k\bmod2\). A noise fault creates a phantom in the *opposite* outer bank, the destination of the next gate, while the true packet remains. The modified \(G\) guard requires exactly one occupied bank with the correct outer \(g\) and vacant destination, so the phantom cannot advance through the next CNOT. The counterfeit also cannot make the counter advance. If the phantom is a small physical occupancy error, the encoded four-level bank code corrects it back to vacancy before any gate commit. If it is a valid but wrong-bank packet produced by a higher-order fault cluster, \(F_v\) sees a valid crossed counter surface and two occupied banks, replaces the local data by \(E\) in the expected bank and clears the wrong bank. This gives **one surviving lineage** after one local recovery proposal. The true quantum state may be lost in this higher-order branch; the outer code must correct that erasure before its causal cone widens.

The same finite-state canonicalization handles a missing expected packet: insert \(E\) in the expected bank, allowing gate progress with an explicit data fault. A sole packet in the wrong outer bank **must also become \(E\)**. Moving it intact without a gate is a silent skipped-gate path. If the counter is a cleanly repairable one-site fault instead, \(StarValid(v)\) is false by s01's isolated-fault lemma, so \(F_v\) is disabled and \(R_v\) repairs the counter before any data move. This guard ordering is essential: allowing \(F_v\) to act on an invalid counter would let one counter flip erase the real packet.

For a fixed valid counter star and a fully decoded bank pattern, this gives an exact **finite release word**: one \(F_v\) jump produces one encoded occupied sector (possibly \(E\)) in the expected outer bank and encoded vacuum in the other three. Its guard is then false, so repeated attempts are inert. If its private Poisson proposal clock has rate \(\kappa\), the additional waiting time is \(\operatorname{Exp}(\kappa)\), provided the neighboring star remains valid and no new fault arrives. The three freed banks can be reset by their guarded \(Reset_v\) jumps and reused on the next parity wrap. This is a local drain/reset result, not a uniform open-neighborhood service theorem: without repair of an invalid surrounding counter domain, \(F_v\) may never become enabled.

The erasure branch on a **detected inconsistency** is forced by quantum indistinguishability. Fix a nontrivial unitary \(U\), for example \(H\). One history counterfeits \(c=1,g=1\) and the new bank without applying \(H\), leaving current data \(\rho\). Another history actually applies \(H\) to initial data \(H^\dagger\rho H\), yielding exactly the same current control and data state \(\rho\). A local reset sees the same state, yet exact recovery to the prescribed outputs would require \(H\rho H^\dagger\) in the first history and \(\rho\) in the second. For a generic \(\rho\) these differ. No deterministic local channel can correctly restore both histories. In fact the *fully consistent* counterfeit \((c,g)=(1,1)\) is invisible to \(F_v\): it cannot be marked \(E\) selectively. It must instead be charged analytically as a bad gate packet, with a fault-weight lower bound from the protected counter/occupancy implementation. The local erasure marker is available only when the witness sectors disagree.

These are exact consequences of the table for the stated configurations. They resolve **stranded real-data lineage** for a one-port phantom; they do not claim that the phantom's downstream quantum error would by itself constitute many bad locations. Data errors can propagate through later *correct* CNOTs in an ordinary circuit. What must be bounded is the number of controller/gate locations misexecuted and the width of the data shadow before an EC checkpoint.

## Two-counter repair evidence and its limit

At the flat clean \(c=0,g=0\) surface, s01's two-fault counterexample changes two sites of one even plaquette from \(c=0\) to \(1\) without a gate. The tile is invalid, but all four outer banks still have \(g=0\). The \(R_P\) candidate \(c=0\) on the four sites is compatible with their banks and neighboring tiles; the competing \(c=1\) endpoint is excluded by the bank parity. After an actual even \(G\), the converse holds: \(c=1,g=1\), so two false rollbacks to \(c=0\) select \(c=1\). A four-site counter-only counterfeit \(0\to1\) may pass s01's counter validity, but \(g=0\) makes the gate guard false; once the counter star is valid, \(F_v\) erases the inconsistent packets. A simultaneous counterfeit of counters **and** the corresponding physical bank transfer has no local inconsistency and is the bad-operation case above.

There is a sharper two-site trap if the bank evidence itself is faulty. From the flat state, choose two sites of one even tile and change **both** their counters and their valid bank occupancy from outer \(0\) to outer \(1\), without applying the gate. Every \(R_v\) on the tile is disabled by the same two-counter deadlock as s01. The opposite odd tile of each site, with three exterior zeros, allows that site's corrected counter to be only 0 or 1; matching the observed bank parity forces 1 at the two mutated sites and 0 at the others. The focal even tile then has two zeros and two ones and remains invalid. Hence \(R_P\) has **no** candidate, \(F_v\) is disabled by the invalid star, and no gate touching the tile can fire. The first five rows alone have a permanent fault-free **gate/counter** deadlock after this two-bad-site state, although inner EC may still cycle. The \(A_P\) emergency row is necessary even for a two-site bad cluster: it may set the tile counters to all 0 or all 1, erase all four packets and free the wrong banks. Either selected endpoint is a bad plaquette operation, never an exact correction of the unknown inputs.

### A size-independent one-tile candidate lemma

Let \(h\) be any reachable clean integer-height surface, and let a corrupted counter field \(s\) agree with \(h\bmod q\) **outside one tile** \(P\). Consider any replacement \(z\) of the four counters on \(P\) making every incident tile valid. The opposite tile \(Q_v\) at each \(v\in P\) intersects \(P\) only at \(v\), so its other three counters are still clean. If \(P\) is the current tile for height \(h_v=k\), validity of \(Q_v\) restricts \(z_v\) to \(\{k,k+1\}\); if \(P\) is the previous tile, it restricts \(z_v\) to \(\{k-1,k\}\), all modulo \(q\). For a clean mixed \(P\), its values are \(\{a,a+1\}\) with \(a\bmod2\ne p(P)\). The lower sites can only stay or decrease and the upper sites can only stay or increase; any change makes the spread at least two, so \(z=h\) on \(P\). For a clean uniform \(P\) at \(k\), a mixed choice between \(k\) and \(k\pm1\) has lower residue of the tile's own parity and violates \(Valid_{p(P)}\). Thus \(z\) is either the original four-vector or the uniform \(k\pm1\) vector representing exactly **one** forward/backward \(P\)-event. This argument uses only the crossed geometry and works through modulo wrap for even \(q\ge8\).

Consequently, if the encoded outer-bank parity on all four sites is trustworthy, it excludes the \(\pm1\) alternative and \(R_P\) has the unique exact counter repair for *arbitrarily many counter faults confined to one tile*. The strengthened \(R_v\) guard cannot change a pristine-bank site to a wrong value either: the unaffected opposite tile admits only \(h_v\) or \(h_v\pm1\), and parity excludes the latter. If bank parity is not trustworthy, \(A_P\) may choose either endpoint and erase all four data packets; the resulting counter debt is at most one \(P\)-event under this isolated-tile premise. For the explicit two-site trap above, one \(A_P\) proposal produces a valid local star and four erasure packets, all other banks vacuum. Its guard then closes, the vacant banks can reset, and a private rate-\(\alpha\) clock gives \(\operatorname{Exp}(\alpha)\) release time while exterior repairs do not alter the crossed moat. This is an exact finite **controller** release/drain result, with four-site bad-data shadow. It is not yet a proof that all later quantum influence stays in four sites: an outer fault-tolerant EC checkpoint must absorb the erasures before downstream interactions.

The same geometry gives a static **two-counter-fault exact-repair lemma** with pristine bank sectors, even when the faulty sites do not share a tile. If the two sites share a tile, the preceding lemma applies. Otherwise each faulty site has both its incident tiles free of the other fault, so its strengthened \(R_v\) uniquely selects its clean value; the new \(R_P\) priority guard prevents a collective repair racing it. A clean site \(w\) cannot undergo a false parity-matched \(R_w\): each incident tile has at most one faulty neighbor, leaving two other clean sites. If those two values differ, tile validity confines the candidate for \(w\) to their adjacent pair, where the other value flips parity. If they agree at \(k\), validity allows \(w\) only \(k\) and at most one of \(k-1,k+1\), because the competing side has the tile's own forbidden lower parity. Thus no candidate distinct from \(h_w\) has the same parity. In a fixed exterior/no-new-fault repair interval, one or two \(R_v\) jumps restore the exact counter history without touching data. This is a static local lemma, not yet an exterior-uniform dynamic-service proof under all concurrent clocks.

I ran a finite search using s01's tile validity/successor definitions on the \(4\times4\) torus. In [the new checker](check_bank_parity_decoder.py), the decoder is **not told which two sites failed**: it enumerates all four counter values on the damaged tile compatible with the four pre-fault outer-bank parities and validity of every incident tile. Exhausting all **120 reachable modulo-8 clean states**, including wrap, and every replacement of any two counters on one tile by another modulo-8 value gives 282,240 cases. In all 276,480 cases with the focal tile invalid, exactly the original four-counter vector was the unique candidate. In the remaining cases, none was globally valid while retaining both sites' original bank parities. Thus this finite model has no undetected two-counter-only same-tile mutation compatible with unchanged bank sectors. These are computer-checked finite diagnostics, not a size-uniform theorem: a physical receiver sees decoded bank parity only after bank recovery, and arbitrary larger clusters, simultaneous bank/program faults and recursive compilation are untested.

## The strongest failed interface

The proposed \(R_P\) is defined only when there is a **unique** locally consistent four-counter candidate; \(A_P\) helps only when at least one incident-valid candidate exists. The one-tile lemma assumes that *all outside counters are clean*. Even faults physically confined to \(P\) may invalidate several tiles overlapping \(P\), so an independently ringing \(A_Q\) on a neighboring tile can erase clean exterior packets.

In fact **two bad sites already defeat the whole \(R_v,R_P,A_P,F_v\) receiver**. On the \(4\times4\) torus, start with every counter and outer bank at 0. At site indices 0 and 2, set \((c_0,g_0)=(1,1)\) and \((c_2,g_2)=(7,1)\) by two *abstract bad-site* events, without gates; all other sites remain \((0,0)\). At a protected physical level, producing each valid wrong-bank codeword should require multiple lower faults; that weight has not been proved here. The invalid tiles are even \(P=(0,1,4,5)\) and odd \(Q=(1,2,13,14)\). \(R_0\) and \(R_2\) each have sole counter candidate 0, but the required bank-parity guard rejects it. For any four-counter rewrite confined to \(P\), the opposite \(Q\) still contains both 7 (site 2) and 0 (sites 13,14), an invalid pair for an odd tile regardless of site 1; hence neither \(R_P\) nor \(A_P\) has an incident-valid candidate. Conversely, any rewrite confined to \(Q\) leaves 1 (site 0) and 0 (sites 4,5) on even \(P\), invalid regardless of site 1. \(F_v\) cannot act at either bad site because its counter star is invalid. No listed counter/gate repair can release this state, although setting both bad counters to 0 jointly would. [A checker](check_emergency_traps.py) independently found this class of trap from two-site injections. A seven-site joint abort on \(P\cup Q\) could handle this instance, but increasingly large connected invalid domains need a scalable local propagation/retirement rule.

Thus the present finite carousel has a **precise failure of noisy progress at two abstract bad sites**. Choosing a counter-valid endpoint without erasing its affected data can also skip a noncommuting gate. Holding an invalid domain forever violates progress; erasing only its boundary while leaving a wrong interior phase can let one fault seed an unbounded history discrepancy. A complete finite-state eroder would need to grow/shrink a damaged domain, quarantine quantum data, and prove the resulting erasure/operation shadow is proportional to the causally connected fault cluster. No such rule or proof is supplied.

There is a second independent obstruction. At a higher encoded level, the four-bank \(G(P,k)\) map spans several child blocks and cannot be a physical jump. Splitting it into "apply \(K\)" and "move banks/increment counters" permits repeats or skips under asynchronous interleaving or repair. The inner EC carousel cannot simply continue through those partial gate states; it could act on a half-moved encoded block. A valid recursive compiler must express each noncommuting substep as its own occupied-port move, fence partially moved child blocks from EC, and give a bounded clean release word after faults. The four-bank table states the desired input/output contract but does not implement that compiler.

Finally, the program/color symbols in s01 and the encoded occupancy syndromes here are noisy. A corrupted program bit could select the wrong \(K\) on multiple later counter wraps if it is not protected; a wrong source-reset decision can erase an unknown qubit. Protecting these symbols and proving their whole causal influence is bounded is part of the same missing theorem. The \(F_v\) row by itself does not solve static-program repair, random idle-round volume, final hold or readout.

## Resource and noise contract

At the ideal atomic level the data workspace is **four bank registers per logical site**, a \(q\)-ary counter, a finite color symbol and whatever finite periodic gate/program symbol selects \(K_{P,k}\). No bank or completion tag is consumed permanently; each successful gate frees its source outer bank and each EC shuttle frees its source inner bank. An \(A_P\) or \(F_v\) release also leaves exactly one occupied sector per affected site and vacates all others. For a physically protected bank, each four-level sector code must occupy multiple lower-level sites, so the hardware overhead is at least four code blocks per simulated site; the encoded \(G\), \(A_P\), and \(F_v\) rows then demand a compiler over a larger constant-size region at each chosen level. Merely declaring them atomic at every scale would assume the theorem being sought.

The intended base noise contract is independent local Poisson onsite faults acting arbitrarily on all registers at one *physical* site, including counter, bank and program; ideal proposal clocks are exogenous with fixed positive rates. The exact one-tile receiver lemma assumes fault-free decoded bank parity and a clean counter exterior, so it is a conditional local statement. A recursive bad-location definition must include every physical bank-syndrome extraction, EC shuttle while waiting, program repair, aborted tile, vacuum reset, gate transfer, final hold and readout. It must prove a reference-uniform CP/diamond bound after arbitrary fault clusters; the finite state checks above prove none of this.

# Independent architecture investigation: physical gate history as consumed matter

16 October 2026. Worker s02. Scope: autonomous asynchronous quantum control with noncommuting gates, repair and finite register reuse. Full formal candidate is [CANDIDATE_SPEC.md](CANDIDATE_SPEC.md). **Result: a clean local exact-once mechanism and a genuine reusable protected-idle interface; no recursive noisy autonomous threshold theorem.** The missing step is not a scalar waiting-time estimate. It is a physical compiler and causal-damage proof for encoded occupied-port moves, resets, token storage and collisions.

## Candidate in one paragraph

Use a directed acyclic *material* gate rail rather than a repaired modulo phase clock. Every logical data port has two finite EC banks. A live quantum packet occupies exactly one bank; repeated autonomous EC shuttles move it \(A\leftrightarrow B\) and apply logical identity recovery while it waits. A one-use gate token sits at a nearby vertex. Once all required packets have arrived, an exogenous Poisson proposal atomically applies \(H\), \(T\), or CNOT, transfers the quantum packets to vacant successor ports, and changes that gate token to SPENT. The same local proposal is exactly idempotent because its input occupancy and token have been consumed. Thus actual gate history is witnessed by the location of the quantum state and by the consumed instruction, even after a controller register is reset. For a finite circuit, lay its gate vertices out in two-dimensional space; the local rule and alphabet stay fixed, while area scales with the number of gates. The \(A/B\) EC banks and reset ancillas are reused, but noncommuting program vertices are one-use in this proved ideal version.

## What is genuinely established here

1. The bounded-support local channel in the candidate specification is CPTP, globally idempotent, and implements the chosen noncommuting gate on any joint state with an arbitrary reference. This is direct algebra, not a simulation.
2. Under legal initial occupancy, unique port ownership and a finite gate DAG, every fault-free asynchronous proposal interleaving that completes the DAG implements the specified circuit exactly once, regardless of EC interleaving. The proof is a topological-order argument and remains valid for \(H,T,\mathrm{CNOT}\), not only commuting Pauli corrections.
3. Once a gate's inputs are present, a private rate-\(\lambda\) proposal has an exterior-uniform \(\mathrm{Exp}(\lambda)\) completion time at the *abstract bounded vertex*, since EC only alternates the occupied bank. The clean makespan has an exponential path bound as in (2) of the specification.
4. Encoding vacant and occupied states in a single logical qutrit code permits a nondemolition occupancy test on the promised occupied subspace. A separate noisy classical flag is not promoted to evidence that unknown quantum data is safe to reset.

These statements stop at a fixed physical vertex and an ideal finite network. In particular, the existence of an abstract code and a large encoded isometry does **not** make that isometry a local physical proposal.

A small qutrit-port matrix check gave trace-preservation residual \(3.2\times10^{-16}\) for the \(H\) move, zero for \(T\), and zero sampled idempotence residual for both; \(\|TH-HT\|_F=0.7653668647\). This only sanity-checks the two-port finite algebra. The exact claims above rest on the displayed Kraus proof, not on those floating-point values.

## Exact obstruction: a repaired clock does not repair a skipped gate

Consider an unknown qubit, a required \(H\), and a classical controller phase that repair has set to "after \(H\)." There are two possible histories with that same controller state:

* History S: the physical \(H\) was skipped; choose initial state \(\rho\). Current data is \(\rho\).
* History A: the physical \(H\) was applied; choose initial state \(H^\dagger\rho H\). Current data is also \(\rho\).

If the controller holds no other witness of actual gate execution, a subsequent recovery channel \(R\) sees the same joint local state in S and A. To implement the prescribed computation for all inputs, S needs \(R(\rho)=H\rho H^\dagger\), whereas A needs \(R(\rho)=\rho\). Set \(\rho=|0\rangle\langle0|\); the targets differ. No CPTP channel \(R\) can satisfy both. For \(H\) followed by \(T\), the omitted/repeated \(H\) changes the noncommuting word, so later ordinary error correction cannot infer the missing operation. This is an indistinguishability proof for *clock-only* repair, not a no-go for controllers retaining a physical execution witness.

The occupied-port move supplies such a witness at a bare vertex. Marking a controller phase "done" without moving data cannot produce its legal output sector. Conversely, executing \(H\) moves the actual unknown state and consumes the token in the same channel. The argument depends on the gate channel being one atomic bounded-support map; a two-step emulation that applies \(H\) and then updates occupancy reopens the indistinguishability.

## Exact obstruction: finite-tag acknowledgments and unbounded stale lifetime

Suppose a reused gate cell accepts delayed completion/acknowledgment messages labeled from a finite set of \(m\) tags, and old messages can remain pending for unbounded physical time. After more than \(m\) uses, some new operation has the same tag as an old one. If an old acknowledgment can arrive when the cell is reloaded with that tag and is otherwise in the same local accept state as a fresh acknowledgment, the receiver has identical local input in the stale and fresh cases. Acceptance in the stale case can commit the new gate without its quantum operation; rejection in the fresh case can prevent progress. A finite-state local rule cannot do both correctly. This is the ABA obstruction under the **stated unbounded-pending-message premise**. A causally complete drain of old messages before reuse, or a physical one-use token consumed with the gate, evades it. Waiting a fixed time does not: a Poisson service time has a nonzero tail beyond every finite timeout.

This does not prove that every finite reusable controller is impossible. It identifies exactly what a successful one must certify before tag reuse. The proposed restricted architecture avoids the premise for noncommuting gates by using one-shot program vertices. It allows EC identities to cycle because a repeated logical identity needs no operation index.

## Countertests of the candidate itself

**Split transfer fails without a new witness.** Replace the one-step channel by (i) apply \(U\) in the source bank and (ii) move occupancy to the destination. In a fault-free asynchronous schedule, proposal (i) can ring twice before (ii), giving \(U^2\). Adding a repairable bit saying "i complete" creates the original skipped/repeated-gate problem when the bit is reset or overwritten. Every noncommuting lower-level microstep must therefore consume a distinct physical input port, or use another independently protected execution witness. This is the crucial recursive compilation constraint.

**Bare occupancy is vulnerable.** If a single local fault can turn a vacuum slot into an apparently occupied \(|0\rangle\), a CNOT proposal can pair the phantom with a real target and produce an unwanted operation. If the phantom continues through the graph, it can cause later trouble. Encoding occupancy as a logical qutrit makes one small physical fault detectable; however an uncorrectable fault cluster can still create a valid phantom. The needed upper-level theorem must show that this becomes one bounded causal fault packet, not a persistent counterfeit data stream.

**Late program corruption is not a ready-gate fault.** A gate token may wait through many predecessors. A fault that changes its program symbol hours before readiness can make the eventual gate wrong while no fault occurs during its short ready service. It is incorrect to begin the guard only at readiness. The token must run protected storage/repair while waiting, and every storage interval must be charged. Even a protected finite block has positive logical failure rate over unbounded physical time.

**Reset-on-flag can erase live data.** If the occupancy bit is stored separately from the quantum bank, a single flip to "empty" followed by an ideal reset can destroy arbitrary entangled input. The abstract proposal avoids this by testing an encoded occupancy sector and by defining reset to be the identity on occupied sectors. A physical syndrome-extraction implementation must prove the same property under faults.

**Reuse by a timeout reopens the gate.** If a one-shot token cell is reset to a new live token before all old delayed signals are drained, a stale signal can alias the new use. A noisy finite tag does not certify absence of stale signals. The space-unrolled variant never reloads a noncommuting vertex, paying linear circuit-space cost; a compact streaming variant needs a new drain theorem.

**Waiting EC cannot be ignored.** The \(A/B\) carousel keeps early packets undergoing recovery, but every round has some logical failure rate. If a ready block waits for a distant predecessor through \(W\) rounds, its failure probability can grow like \(1-(1-\eta_l)^W\). The final error bound must count the random expanded circuit of EC rounds and program maintenance, as the prior handoff requires.

## Precise noisy contract and attempted recursive composition

At one fixed encoded level, choose a code correcting \(t\) local faults and a fault-tolerant implementation of the qutrit occupancy test, EC shuttle and the universal gate set. An intended good vertex starts in the legal port sector with correct token and has a finite local DAG of lower-level proposals. It should satisfy:

* **Safety:** With at most \(t\) lower-level faults in its guarded extended rectangle, the decoded output is \(U_g\) on the reference-entangled input, both inputs are vacant, the correct outputs occupied, and the token SPENT. The same property for EC is decoded identity.
* **Quarantine:** Invalid or duplicate occupation, torn token consumption and partially reset ancillas are confined to a bounded enlarged region. Outside it, later clean vertices obey their own contracts on legal inputs. A bad event must not create an indefinitely reusable instruction.
* **Sealed service:** From every causally ready state that the induction admits, a bounded word of lower-level clean proposals completes the vertex or its repair, regardless of exterior clocks; alternatively every exterior action that can interfere is included in a bounded guard. Whole-certificate dependence and guard mass must be uniform across levels.
* **CP lift:** For every deterministic set \(J\) of bad upper-level labels, the inclusive subchannel has a uniform diamond-norm bound, including arbitrary input reference. A statewise probability or one-label estimate is insufficient.
* **Volume:** All EC shuttles while waiting, token storage, resets, terminal hold and readout are locations in the expanded circuit. Their random count and real duration enter the final error statement.

If these held with a level-uniform fault fanout \(R\), a conventional exRec count could yield a recursion of the schematic form \(\eta_{l+1}\le A\eta_l^{(t+1)/R}\). The expression is **conditional only**. There is no proof that the exponent exceeds one after resets, collisions, waiting loops and compiled CNOT rendezvous are included. There is no proof that a finite local alphabet self-simulates these conditions. The attractive bare idempotence does not substitute for those proofs.

The first attempt at composition fails exactly at the encoded move: an upper-level four-port \(U_g\) is spread across several lower-level subblocks and cannot be one local jump. A generic compiled gadget has intermediate states in which some subblocks have moved and others have not; a faulty reset, token update or EC action can then duplicate, skip or mix the actual logical operation. Compiling each elementary noncommuting substep into another one-way occupied-port move suggests an induction, but the partial-ownership states and their repair are not yet controlled. This is the strongest missing mathematical step.

## Physical-time and resource ledger

For the bare finite DAG, \(V\) gate vertices with longest path \(L\) have ideal completion time \(O((L+\log V+s)/\lambda)\) with exponential \(s\)-tail. A local nearest-neighbor circuit of \(N\) wires and depth \(D\) may take \(V=\Theta(ND)\) one-shot vertices plus routing; the two-dimensional strip area is at least that order. This is intentionally much larger than the polylogarithmic space overhead claimed for the *synchronous* self-simulating QCA of 2601.20818v3. Each site has fixed dimension, and EC banks are physically reused. The prepared program occupies \(O(V)\) classical cells and its maintenance has to be counted.

If a constant-size lower-level compiler with at most \(B\) constituent events and a uniform conditional service moment existed, an upper-level service scale of order \(B^l/\lambda\) would be plausible by conditional Hölder. If \(\eta_l\) fell superlinearly, a level \(l=O(\log\log(V/\epsilon))\) might offset polynomial expanded volume. Neither conditional premise has been established. The top-level EC-round completion intensity, program maintenance rate, number of physical occupied cells and final hold duration must all be included. A finite terminal block held forever under positive local noise eventually loses an unknown qubit; readout must have a stated physical deadline or a proved growing memory hierarchy.

## Closest-source boundary

I read the complete locally pinned versions of [Dünnweber–Styliaris–Trivedi, 2601.20818v3](https://arxiv.org/abs/2601.20818v3) and [Drechsler–Oreg–Aharonov, 2610.05589v1](https://arxiv.org/abs/2610.05589v1), and the campaign [continuation handoff](../../../2026-10-16-high-leverage-foundations-v1/CONTINUATION_HANDOFF.md). The former already proves a synchronous two-dimensional, fixed-rule autonomous QCA threshold, but explicitly leaves its continuous-time asynchronous threshold transfer at outline level. Its Supplement VII uses buffered classical controls, brickwork data gates and finite repaired clocks. This report does not claim to refute that architecture or inherit its recursion. The latter proves a Floquet Lindbladian lift for certain classical memories, not the time-independent universal gate processor sought here.

The idea of one-way quantum computation is also not new. [Silva–Danos–Kashefi–Ollivier](https://arxiv.org/abs/quant-ph/0611273) studies fault-tolerant computation through teleportation, and [Verstraete–Wolf–Cirac](https://arxiv.org/abs/0803.1447) studies computation from local time-independent dissipation. More directly, Supplement III of 2601.20818v3 already transports quantum data only into unoccupied sites, drawing on [Arrighi–Fargetton–Wang](https://dl.acm.org/doi/10.5555/1549637.1549652); it deliberately uses a separate classical occupancy flag to keep data faults from steering the program. My proposal's distinct, unverified direction is to encode occupancy as a protected qutrit sector and **atomically couple one-way data movement, a noncommuting gate, and one-use token consumption**, while only logical-identity EC recycles. That change trades the original flag's schedule independence for a still-open occupancy-damage theorem. No literature priority, threshold, quantum memory, practical device or technological superiority is established.

## Decision

Retain the occupied-port ratchet as a distinct research direction because it removes clock-repair-induced skipped/repeated gates at the bare local level by construction and gives a transparent conditional service clock. Do **not** promote it as a solution to the selected frontier B. The next decisive task is a fully explicit constant-alphabet physical implementation of one encoded CNOT or \(T\)-injection move with concurrent \(A/B\) EC, token consumption, reset and fault repair, followed by a causal packet/exRec proof. If that implementation requires a mutable phase bit whose repair can disagree with actual quantum action, or a stale token with unbounded fanout, reject this route or retain only the space-unrolled one-shot processor.

## Controlled recombination extension

At the root's request I also tested a **finite gate-bank carousel** that receives s01's crossed-plaquette counter surface; the full transition table, isolated-tile proof, emergency erasure row and exact traps are in [RECOMBINATION_TEST.md](RECOMBINATION_TEST.md), with [replay receipts](REPLAY_RECEIPTS.md) for the finite checkers. Four banks indexed by gate parity and idle-EC parity remove the one-shot *port* overhead at the ideal atomic level. The important new positive fact is size independent under an isolated-tile premise: any locally valid repair of a corrupted tile against clean exterior is either the true counter vector or one complete \(\pm1\) tile event, and trustworthy bank parity selects the true vector. When bank evidence is also corrupted, a two-site same-tile fault can deadlock ordinary repair; an emergency plaquette abort can release that isolated tile only by erasing all four data packets. A second explicit two-site fault on neighboring tiles defeats even that emergency row because neither tile has a candidate with its exterior held fixed. This is a precise failure of the proposed receiver's noisy progress, and it leaves overlapping damage clusters and fault-tolerant compilation of encoded gates unresolved. The report's original one-shot architecture and this conditional receiving construction remain separate candidates with different resource costs and assumptions.

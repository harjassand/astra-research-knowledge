# Finite bad-tile discharge with quantum output recovery

16 October 2026. Follow-up to [REPORT.md](REPORT.md). **Exact scope:** one finite, one-use encoded gate layer; arbitrary ideal Poisson interleavings; either zero faults, one onsite fault in the specified mutable interior counter/quarantine/early-ready/second-phase/terminal-flag/A- and B-data registers, or the specified two-site counter-fault fork on one tile. Onsite faults in the fork may also act on the **one pair of A/B data banks and local phase markers carried by that tile**. No further faults occur during the service word. One onsite B-bank fault after terminal transfer is correctable at a specified final decoding observation; no arbitrary indefinite hold is claimed. The first-accept channel is the output immediately after terminal `T`; the final-decoder claim concerns a separately named observation after any post-T fault. This is a complete transcript/channel proof for that restricted finite case, not a multi-level noisy controller or a threshold theorem. The rule is a modified combination of the s01 crossed counters and s02 one-way ownership, not the original `AsyncR` of arXiv:2601.20818v3.

## 1. Finite layout, code, and uniform local jump types

Use a 10×10 open square of sites with fixed zero-counter collar; active tiles are the five disjoint **even** 2×2 plaquettes with lower-left coordinates

```
(2,2), (2,6), (4,4), (6,2), (6,6).
```

All sites carry the s01 execution counter `c_v in Z_8`. A static program marks only these five even tiles as live in this one-shot layer. Odd-layer and block-crossing data gate proposals have no live program symbol until the terminal output moves to a fresh bank. At each active tile choose its lower-left site to carry one of five code data qubits; the other three sites carry no live code data. Each chosen site has source and output qutrit banks `A,B`, where `|perp>` means physically vacant. Initially the five A qubit sectors carry an arbitrary reference-entangled state of the `[[5,1,3]]` code and all B banks are vacuum. One physical onsite noise jump touches at most one of the five data qubits. Controller registers are classical sectors dephased by ideal jumps; a noise jump may entangle its local data and counter, and the subsequent dephasing yields CP branches. A quarantine bit `q_P` on each tile is written by emergency discharge but is **not an enabling guard** for any jump. The block's terminal authorization is three copies `f_1,f_2,f_3`, initialized LIVE at non-data sites `(2,3),(2,7),(4,5)`; its guard reads majority LIVE and its firing writes all three SPENT. A single onsite fault can corrupt one copy without changing the majority. This is the only block-wide terminal authorization in the finite stage.

For concreteness take stabilizer generators `XZZXI, IXZZX, XIXZZ, ZXIXZ` and logical `X_L=XXXXX`, `Z_L=ZZZZZ`. Their 15 weight-one nonidentity Pauli syndromes are all distinct and nonzero, so the code corrects **every** one-site operator, including arbitrary CP instruments and leakage into the local vacancy sector after the explicit recovery below. Both logical Pauli words commute with the stabilizers and anticommute with each other. Define the one-qubit cyclic Clifford `C=(I-i(X+Y+Z))/2`; direct multiplication gives `CXC†=Y`, `CYC†=Z`, `CZC†=X`. The transversal `C_L=C^{⊗5}` preserves the code: it sends the four displayed stabilizer generators respectively to `g_3g_4`, `g_1g_2g_3`, `g_2g_3g_4`, and `g_1g_2` (where `g_1,...,g_4` are listed in order). It sends logical `X_L` to logical `Y_L`, so `Ad_(C_L)` and `Ad_(X_L)` genuinely **do not commute as channels**. Tile `i` has two ordered local data operations: physical `X_i`, then physical `C_i`. Across the five tiles the intended two-layer word is `C_L X_L`. The five encoded data qubits and both banks fit in a fixed 6×6 bounding box. The terminal recovery/move below is one bounded-support CPTP jump on that box. Its support is large but constant in this **base case**; a recursive implementation of this jump is unproved.

The ideal jump table is:

| Jump | Pre-jump guard | Atomic action | Quantum effect |
| --- | --- | --- | --- |
| `G(P_i)` | Its four counters are 0; every participant has s01 `StarValid`; static program selects this stage | Apply `X_i ⊕ I_perp` on its A qutrit, set the four counters to 1 and early-ready bit `a_i=1` | First local gate, once in this stage |
| `H(P_i)` | `(all four counters are 1) OR (a_i=1)`; its one-bit second-phase marker `d_i=0`; static program selects this stage | Apply `C_i ⊕ I_perp` on its A qutrit, set `d_i=1` atomically | Second local gate; an early-ready fault can reorder it |
| `R(v)` | The s01 crossed-plaquette `Candidate(v,z)` set is the singleton `{z}`, `z != c_v` | Set `c_v=z` | Identity on data |
| `E(P)` | One active even tile has the `0/1` two-and-two invalid pattern; none of its four sites has a singleton repair candidate | Set all four `c_v=1`, set `q_P=1` | Identity on data; the missing/repeated gate is now charged to tile P |
| `T(B)` | All five active tiles have counters 1 and `d_i=1`; majority of `f_1,f_2,f_3` is LIVE | Discard/reset all unowned B banks, apply fixed `[[5,1,3]]` recovery on A, move the recovered code state isometrically to B, vacate A, set all `f_j` SPENT and clear all `q_P`, all in one bounded jump | Exact logical `C_L X_L` after the stated preterminal faults |

Every row is a bounded-support CPTP channel on all sectors: dephase its finite classical guard, apply the prescribed CPTP map in enabled sectors and identity (or an arbitrary fixed legal extension for the terminal map) in disabled sectors, then write finite classical states. Each `a_i,d_i` pair is stored at that tile's data site and starts at `0,0`; it may suffer the same onsite fault as its data and counter. A premature `d_i=1` skips `H_i`; a rollback to 0 after `H_i` repeats it. A premature `a_i=1` lets `H_i` run **before** `G_i`, so a single faulty shared flag genuinely reorders noncommuting channels. A rollback `a_i=0` after `G_i` cannot stall `H_i`, because the completed all-one counter field independently enables it. All these errors remain on physical qubit `i`, even though `C_i X_i` and `X_i C_i` differ as channels. `E` does **not** try to infer whether `G(P)` already fired; that is the point. The tile counter is one-use within this stage, so no tile token is needed: after `G` or `E`, its four counters are 1 and its `G` guard is false. The two ambiguous histories below always have the same counter field, and a three-pair subfamily has **identical complete classical controller states** after a faulty early-ready bit. `G` and `H` have no A-occupancy guard because one local data fault may leak its qutrit into `|perp>`; their unitary extensions still act locally and the code recovery corrects the leakage. `T` has no raw B-occupancy guard: B has no live incoming owner before this one-use transfer, so any phantom B state is discarded before the recovered A state is installed. The terminal gate does not use a mod-8 tag to authorize a new output. It transfers the data to a *different physical bank* and consumes the majority-protected one-use terminal flag. The old G, H, and E jumps cannot act on the fresh B output, even if attempted forever afterward. Reusing A or B for a later noncommuting gate would require a separate drain theorem and is excluded from this finite case.

The quarantine bit records that the block must pass through `T`, but a faulty `q_P` cannot block service because no guard reads it. Any successor data gate with a support intersecting this block must require **both** majority terminal flag SPENT and an occupied B input; a single preterminal B-vacancy fault cannot forge the spent majority, and `T` resets its phantom state before supplying the real output. The five current even-tile tracks are disjoint and may run while `q_P=1`; they act only on A and on distinct code qubits. No odd or cross-block gate has a live program symbol during this one-shot layer. This is the seam rule: a damaged block can delay its own successor, while disjoint blocks and the other four tracks proceed. It cannot repeatedly couple a later fresh output because that output resides in B and the terminal flag is spent before B becomes occupied. The finite stage never wraps its counter back to 0. The successor itself is outside the proved one-stage circuit; its combined guard is an interface condition, not a recursively compiled channel.

## 2. Exact controller transcripts

The `Valid_0/Valid_1` and `StarValid` predicates are exactly those in s01 `TRANSITION_TABLE.md`. In this restricted one-layer geometry, every clean active even tile has all counters 0 before firing and all 1 after. Every odd tile meets only residues 0 and 1; when mixed, its lower residue 0 has parity different from odd, so `Valid_1` holds. Consequently any unfired even tile remains enabled under **every interleaving** of the other four even-tile gates. No active counter changes except as a four-site `G`, one-site `R`, or four-site `E` write.

**Zero-fault word.** On each tile, `G(P_i)` changes its counter field 0→1 and sets `a_i=1`, enabling `H(P_i)`, which applies `C_i` and marks `d_i=1`. Different tile tracks commute because their data supports are disjoint, while `H_i G_i=C_iX_i` and `G_i H_i=X_iC_i` differ even as channels. Thus every allowed interleaving applies `∏_i C_iX_i=C_LX_L`, and `T` recovers the no-error code, moves it into B, vacates A, and spends the three terminal flag copies. Gate attempts before readiness or after their phase has completed are identity. This equality holds on any logical-reference state.

**One-onsite-fault word.** At any clean reachable interleaving, an arbitrary change of one mutable interior counter to any other residue may disable nearby gates. The s01 unique crossed repair `R(v)` is the only state-changing ideal repair, it restores exactly the original counter, and no `E` guard is enabled. Disjoint tile tracks may fire before `R`; after `R`, all incomplete `G` and `H` phases finish unless that same onsite fault changed `d_i`. A wrong `d_i=1` may skip `H_i`, while a wrong `d_i=0` after `H_i` may repeat it; neither blocks terminal readiness. A wrong `a_i=1` can cause the explicit **reordered transcript `H_i,G_i`** in place of `G_i,H_i`; `a_i=0` after G is harmless by the counter fallback. An arbitrary data action on the same site, including A-qutrit leakage or an A/B-entangling onsite map, stays on that tile's one data pair as the remaining `X_i` and `C_i` gates act there and all other tiles act disjointly. At `T`, tracing the unowned B input reduces any such local A/B action to a CP operation on A_i alone; the recovered first-accept output therefore equals `C_LX_L` on every input/reference. A B-only phantom state is discarded and cannot block service. A change to one of the three terminal flag copies leaves the majority correct, even if it co-occurs with a counter change at that flag's site; a change to `q_P` has no guard effect. A single onsite B fault **after** `T` is corrected by the specified final decoder below at a named observation. This statement does not cover an onsite change to static color, a program symbol, or a terminal recovery component.

**Two-fault ambiguous fork.** Fix the middle tile `P=(4,4)` and any subset `S` of the other four completed even tiles. Let two distinct sites of `P` have residue 1 and the other two 0. There are two admitted origins with identical counter observations:

* `A`: before `G(P)`, two onsite counter jumps changed 0 to 1. The tile's quantum `X_i` did not run.
* `B`: `G(P)` ran from the all-zero tile, applying `X_i` and setting `a_i=1`; two onsite counter jumps then changed the complementary two sites from 1 to 0.

For an **exactly indistinguishable controller fork**, choose the raised pair among the three non-data sites, so the complementary rollback pair in branch B contains the data site storing `a_i`. Let that onsite rollback also set `a_i=0`, while leaving `d_i=0` and the data untouched; then both branches have identical counters, `a_i,d_i`, quarantine and terminal flags, static program, and bank occupancy, but differ by the prior `X_i` quantum gate. This gives three raised-pair choices for each `S`. For the other three raised pairs `a_i` can disclose the branch, yet `E` deliberately ignores it and the same channel proof works. In both histories the even tile is invalid and `G(P)` is disabled. An `H(P)` enabled by a faulty `a_i=1` may run before `E`, but it changes neither counters nor the E guard and acts only on data qubit `i`. Every other *active even* tile is disjoint and remains eligible; its own `H` may also run after its `G`. The two-and-two pattern and `E(P)` guard persist regardless of those events. **No `R` anywhere on the open square is enabled** in these 96 counter states. The emergency clock thus fires and writes the same completed counter/quarantine state in both branches: `c_v=1` for every `v in P`, `q_P=1`. This counter field equals a legitimate clean field in which `G(P)` had completed, even though branch A's data did not undergo it. After `E`, every unfinished `G_j` and `H_j` phase completes; `H_i` also runs after `E` unless it already ran or a fault set `d_i=1`. Once all counters and `d_i` are 1, `T` fires.

At the input of `T`, branch B's ideal local word on tile `i` is `C_iX_i`, whereas branch A's is `C_i`; these are genuinely noncommuting-stage histories, and their relative operator `C_i(C_iX_i)†` is a one-site operator. Every other tile has its ideal `C_jX_j`. Any data part of the two onsite faults lies on the same code qubit `i` because P carries only that one data qubit. A fault may also flip `a_i` or `d_i`, making `H_i` early, skipped, or repeated, or flip the one terminal flag copy located at P; all the former changes remain one-site data errors and the latter leaves majority LIVE. All arbitrary CP Kraus operators, composed with any skip/repeat/reorder ambiguity on `i`, remain supported on `i`. The `[[5,1,3]]` recovery therefore maps every branch to a scalar multiple of `Ad_(C_LX_L)` with a scalar independent of the logical state and reference. Moving the recovered state to B does not change the logical channel. The controller never needed to decide whether branch A or B occurred. This is a complete finite example of *correctable history ambiguity for an ordered noncommuting word*, not an assertion that the counters recovered exact gate history.

The same argument covers all six choices of which two P sites are at residue 1 and all sixteen subsets `S`; independent `H` progress does not change any counter or E guard. [`finite_discharge_check.py`](finite_discharge_check.py) exhaustively checks the predicates and resulting counter cuts for these 96 states, including absence of **all** false singleton repairs. It also checks 32 clean counter cuts and 14,336 single-interior-counter perturbations (`32` cuts × `64` interior sites × `7` alternative residues): each single counter fault has only the true singleton repair and cannot enable E. The 32 counter cuts represent all `H` subsets because `H` leaves counters unchanged. It checks the majority flag against all six single-copy flip states and exhausts twelve local early-ready/second-phase alterations, finding service words including the skipped, duplicated, and reordered cases. The script checks **controller algebra**. [`quantum_recovery_check.py`](quantum_recovery_check.py) numerically checks the code's 31-map qutrit error Gram, its 26-dimensional syndrome space, preservation under `C_L`, and the noncommuting logical channels; the code-distance argument below is the exact quantum/reference proof. Neither check samples stochastic fault probabilities or proves higher-level behavior.

**Prescribed terminal recovery, including vacancy leakage.** Let `P_C` project onto the five-qubit code inside `(C^3)^{⊗5}`. Form the finite error list

```
E_0 = I,       E_(i,r,s) = |r><s| on A_i,
i=1,...,5,    r in {0,1,perp}, s in {0,1}.
```

It spans every linear map on one A qutrit restricted to a code input, including a qubit→vacancy transition. For any two members, `P_C E_a† E_b P_C = gamma_ab P_C`: after compression to the qubit sectors this is an operator of weight at most two, and the code has distance three. Diagonalize the fixed positive Gram matrix `gamma` as `V† gamma V=diag(lambda_m)`; for each `lambda_m>0` set `F_m=sum_a V_am E_a`, `W_m=lambda_m^(-1/2) F_m P_C`, and `Pi_m=W_m W_m†`. The `W_m` are isometries with mutually orthogonal images. Prescribe the A-bank recovery channel by measuring the orthogonal `Pi_m`, applying `W_m†` on outcome `m`, and mapping the complementary outcome to a fixed code state. This is CPTP on the entire qutrit input space, with a fixed legal extension on all noncode sectors. If an onsite Kraus `M_alpha` acts jointly on `A_i B_i` before T, then tracing the initially unowned B_i gives A-only Kraus operators `L_(alpha,b)=<b|_B M_alpha |perp>_B`, one for each B basis state `b`; these are in the displayed one-site span. On every admitted noisy branch its A input after discarding any preexisting B state is therefore in the span of these error images after the intended `C_L X_L`; the complementary recovery outcome has zero probability and the output equals a scalar times the intended logical/reference state. The rest of `T` is an isometric code-space transfer A→reset B followed by vacancy preparation on A. The **final decoder** at the declared observation time is the same Gram-syndrome CPTP recovery applied to B, followed by logical decode; it corrects any one onsite B error after transfer, if that is the sole fault. This construction is finite and explicit in the stabilizer/code projector and a 31×31 Gram eigendecomposition; it does not assume a perfect mystery decoder.

## 3. Exterior-uniform service and finite-time accounting in this case

Give `G,H,R,E,T` independent unit-rate proposal clocks. Once the ambiguous two-fault state occurs, `E(P)` stays enabled despite all disjoint tile activity. From its firing onward every not-yet-fired `G` remains enabled until it fires; each `H` becomes enabled after its tile reaches counter 1 and remains enabled until it fires or was already marked complete by a local fault. After the last `H`, `T` stays enabled until it fires. Conditional on no further faults, the completion time from the two-fault state is stochastically dominated by

```
Exp_E(1) + max(Exp_G,1(1),...,Exp_G,4(1))
         + max(Exp_H,1(1),...,Exp_H,5(1)) + Exp_T(1),
```

with fresh independent exponentials. A four-way split and union bound give `Pr(T_finish>t) <= 11 exp(-t/4)`; its mean is at most `2+H_4+H_5=191/30` time units. For a one-counter fault, first `R` takes one exponential service, then at most five `G` and five `H` clocks remain, followed by `T`; `Pr(T_finish>t) <= 12 exp(-t/4)` and `E T_finish <= 2+2H_5=197/30`. For a one-flag or one-`d_i` fault with no counter change, omit the `R` term. These bounds are independent of activity in *disjoint* blocks because no guard reads their state and the relevant private proposal clocks are independent. They do not imply a sealed joint exposure bound for many adaptively admitted labels under fault-rate tilt, and no assertion is made when further faults disrupt the service word.

The quantum data is not assumed perfectly stored during the random service time. In the restricted exact transcript there are no further noise jumps; in a stochastic extension, every additional jump during the wait is another seed and must be charged. The service tail makes a finite base gadget plausible, but a growing encoded block must run protected identity/EC rectangles while waiting or use a separately proved error-transparent gate. A serial unprotected higher-level move cannot be justified from this base case.

## 4. Why this does not give a reusable autonomous hierarchy

1. `T` is one atomic recovery-and-move channel over the fixed five-qubit code block. It is a bounded physical jump in this finite base abstraction, but treating the corresponding *higher-level* encoded block as one atomic jump would assume the missing compiler. A level-uniform decomposition into smaller local jumps, with intermediate protection, is not given.
2. The proof handles one onsite action on the listed counter, quarantine, phase flags, terminal flag, and A/B data registers, plus the specified two-site counter fork on one tile. The three terminal flag copies suppress one onsite flag change, and the unconditional B reset removes the B-vacancy oracle. It does not handle source noise on colors, static program, terminal recovery hardware, final decoding hardware, or correlated faults at distinct data tiles. The first-accept `T` claim and the optional final-decoder-at-observation claim are separate channel statements. The known two-fault lock-in and stale-carrier problem still need a general damage/discharge theorem.
3. The emergency guard is proved persistent for the two-and-two trap on a single tile in a one-layer stage. It does not discharge every two-fault counter cluster. The s06 exhaustive search found two-site configurations that no singleton or nearest-neighbor pair repair resolves, including a level-wide stall on a 6×6 torus. A general emergency decoder would need a bounded local basin or a protected erasure interface.
4. The seam is one-way and consumes spatial program/port resources. It avoids ABA in this finite stage by **not reusing** the old gate vertex or wrapping its counter. A fixed-area indefinite controller would need a causally drained recycler. The finite output bank and three-copy terminal flag do not by themselves supply one.
5. The code recovery corrects the one-qubit *output shadow* here even though each tile's intended `X_i,C_i` gates do not commute even as channels. The chosen subsequent `C_i` never leaves the same physical data site. In a general noncommuting gate gadget, later overlapping gates can enlarge that shadow; a fault-tolerant spread theorem and an EC boundary must be proved for every fault cluster before releasing its successor. A clean counter field by itself remains insufficient.
6. Even if every one-fault finite block behaved as here, quadratic renormalization needs canonical joint bad-event labels, sealed exterior-uniform service under the tilted law, bounded primitive owner and exRec overlap, damage erosion, and a physical final-hold/readout statement. The stopped-exposure theorem provides a conditional probability implication only after those concrete hypotheses are checked.

The finite result therefore advances one actual receiving interface: a bad counter cluster can be retired without guessing its quantum past when a **one-way ownership transfer and an immediate code-correctable output shadow** are both present. The repeated fixed-space version remains open; a controller that releases a dependent quantum wire before recovery must count that wire in the causal shadow, and may exceed the code budget.

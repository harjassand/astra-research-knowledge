## 1. Candidate operation: erase *correctable output shadows*, not event words

The tempting replacement for a durable exactly-once register is not a statement that every physical gate history is equivalent. It is a more limited semantic quotient at a named error-correction checkpoint: histories are equivalent when all of their difference from the nominal *unitary* gadget has propagated into a code-correctable set of output tiles. The internal history may contain arbitrarily many skipped, duplicated, or reordered noncommuting local gates. A single faulty controller seed counts once if its complete quantum and classical causal shadow remains small. The count of changed events is then irrelevant to exact **logical** correctness, though duration and fault likelihood still matter.

### Theorem H (unitary causal-shadow absorption)

Fix a finite unitary circuit `U=U_m ... U_1` between two specified encoded checkpoints. The output is a code subspace `C_out` of distance `d` in a fixed tile metric, with encoder `V_out`, and `U V_in = V_out U_L` for the intended logical unitary `U_L`. Let `t` satisfy `2t<d`. For every accepted physical history `h`, including every classical and environment branch that is inaccessible at the output, assume all of the following.

1. **A typed, causal alignment exists.** The nominal and physical event networks have a common typed, acyclic quotient after contracting disjoint causally convex discrepancy packets. Every outside event is the same unitary on the same data/control/ancilla ports and in a causally equivalent order. Every physical packet is a completely positive, trace-nonincreasing (CP-TNI) map on exactly its declared ports; summing exhaustive outcomes gives a trace-preserving map. A missing nominal packet is an identity channel on those ports. Any repeat across a later overlapping event puts that event in the packet. Hidden shared flags, live ancillas, baths, and routing dependencies are ports, not ignored state.
2. **The nominal quantum packet maps are unitary on their ports.** Equivalently, each physical packet can be written as a CP-TNI error map immediately after its nominal packet, by composing with the nominal unitary inverse. This condition applies to the data-bearing interval being analyzed; resets and irreversible EC must occur at named boundaries or be separately checked by a gadget-specific correctness identity.
3. **Bounded output shadow.** Start with every packet quantum output port, then follow all later nominal gates that overlap the current marked set, marking their entire outputs. Include any outside gate whose choice is affected by packet control output. At the checkpoint, the union `A_h` of all marked data tiles has size at most `t`, separately in each output code block. No unmarked output control or environment port can retain a history-dependent coupling to the logical state. The decoder/recovery at the checkpoint corrects *every* error on at most `t` output tiles, without relying on a trusted label `h`.

Then there is a CP-TNI map `E_h` supported on `A_h` such that, as a map on the encoded input **and any untouched reference**,

```
M_h o Enc_in = (E_h on A_h) o Ad_U o Enc_in.             (H1)
```

The same prescribed output-code recovery `Rec_out` gives

```
Dec_out o Rec_out o M_h o Enc_in
      = p_h Ad_(U_L),                                    (H2)
```

where `p_h>=0` is independent of the logical input and its reference. On a trace-preserving sum of accepted histories, `sum_h p_h=1`, so the accepted logical channel is **exactly** `Ad_(U_L)` in diamond norm. The number of events and elapsed time inside a packet need not be bounded for (H1)–(H2). This is an exact *finite-horizon channel identity*, not a physical-time reliability statement.

**Proof.** By the causal alignment, reorder only adjacent incomparable events. Their complete port supports are disjoint, so their superoperators commute; this is tensor-network equality, including an untouched reference. Replace every nominal unitary packet `Ad_(U_j)` by its physical CP-TNI comb `F_{h,j}`. Algebraically `F_{h,j}=(F_{h,j} o Ad_(U_j^dagger)) o Ad_(U_j)`; the parenthesized factor is a local CP-TNI error on the packet ports. Move each such error to the final cut by conjugating it through the *later nominal unitaries*. A conjugated Kraus operator remains supported inside the packet's forward causal shadow: a later unitary on disjoint tiles commutes past it, and an overlapping unitary only enlarges its support to that gate's output tiles. The chronological composition of these conjugated errors is CP-TNI and supported on their output-shadow union `A_h`, proving (H1). This argument neither inverts a noisy channel nor reconstructs a past physical state. It uses only inverses of the stipulated **nominal unitary maps** as an algebraic comparison.

For any two Kraus operators `E_a,E_b` drawn from any accepted histories, each has support on at most `t` output tiles, so `E_a^dagger E_b` has support on at most `2t<d` tiles. Code distance gives the Knill–Laflamme identity `P_out E_a^dagger E_b P_out = c_ab P_out`. Hence one recovery corrects the entire collection of errors, even when the output supports `A_h` vary with `h`, and even when different packet outcomes have coherent Kraus decompositions. Applied to each CP branch, recovery yields a scalar times the ideal logical unitary; the scalar equals its branch probability and is input independent. This proves (H2). No assumption of classical independence between histories is needed for the exact correction statement, but the stipulated CP-instrument and initially uncorrelated environmental ancillas are necessary for this representation.

**What is actually relaxed.** The earlier s06 conditional transfer requested at most `w` changed nominal gadget locations per seed. Theorem H permits unbounded internal edit count when the full *output shadow* has bounded width. It does not relax the need to bound the number of lower-level tiles hit per seed, the number of exRecs in which that seed participates, or the probability of such seeds. The proof is a fault-tolerance lemma, not an implementation of a self-healing asynchronous controller.

### Concrete protected-gate instance

Suppose `W=U_1 tensor ... tensor U_n` implements an encoded logical unitary and a code of distance `d>2t` corrects arbitrary errors on `t` tiles. On every tile outside some `A`, `|A|<=t`, the local gate occurs once. On the tiles in `A`, replace the intended local unitary by **any** local CPTP history, including skipped gates, repeated gates, noncommuting orders, faulty flags, local resets, and an arbitrary number of ideal attempts, provided no operation or control influence from `A` leaves it before the trailing EC cut. Since the tiles are disjoint, the physical channel equals `(F_A o Ad_(W_A^dagger) tensor id) o Ad_W`, and the code recovery restores the logical `U_L` exactly. For a transversal two-block gate, one matched pair can be one tile; a correlated arbitrary error on that pair is correctable when each block has budget for its one affected constituent. This is a *real semantic substitute for exact-once history for one local fault*, albeit only under the causal fence and physical-time conditions below.

The same theorem covers a genuinely noncommuting local packet: if nominal tile action is `S H` and the faulty local history executes `H S`, omits `H`, or repeats `S`, its relative action is an arbitrary single-tile error, regardless of the nonzero commutator. If that tile's forward cone touches more than `t` output tiles before EC, the argument no longer applies. Likewise a single wrong shared flag that causes *every* tile of a transversal logical gate to skip can implement the wrong logical unitary; its footprint is the entire block and is not correctable by this theorem.

## 2. Exact limit of a gauge/history quotient

The strongest general criterion for replacing an execution record is standard Knill–Laflamme correctability of the *whole family of accepted history Kraus operators*. Let `A_{h,a}:H_L -> H_phys` be Kraus maps of all accepted history branches, including the classical tag that the physical decoder may actually read. Assuming their sum is a channel, one decoder `R` can make the accepted channel exactly the same target unitary `U_L` on every logical input and reference **if and only if**

```
A_(h,a)^dagger A_(k,b) = c_(h,a;k,b) I_L             (G1)
```

for all pairs, after composing the target unitary inverse into the input or output convention. Here is the short QEC proof. For sufficiency, diagonalize the positive matrix `c` by a unitary change of Kraus basis. In the resulting basis `B_i^dagger B_j=lambda_i delta_ij I`, so the polar decompositions `B_i=sqrt(lambda_i) W_i` have mutually orthogonal isometric images. A recovery measures those image subspaces, applies `W_i^dagger`, then applies the target unitary. For necessity, let `{R_b}` be Kraus operators of an exact recovery. The corrected channel is a unitary channel and hence has Choi rank one, so every composite Kraus `R_b A_(h,a)` is a scalar multiple of `U_L`. Since `sum_b R_b^dagger R_b=I`, summing `(R_b A_(h,a))^dagger(R_b A_(k,c))` over `b` gives (G1). In particular, even if each individual accepted branch has the right logical output after a history-aware recovery, erasing the branch record requires the *cross-history* products in (G1). Correct decoded basis populations or a repaired classical clock do not establish it.

For a particularly clear obstruction, suppose two accepted histories have the **same accessible classical state and the same code subspace**, but act there as different logical unitaries `U_0` and `U_1`. Their Kraus maps contain `sqrt(p_0) V U_0` and `sqrt(p_1) V U_1` with positive probabilities. Their cross product is `sqrt(p_0 p_1) U_0^dagger U_1`. Equation (G1) holds only when `U_0^dagger U_1` is a scalar phase. Thus an unrecorded skipped, duplicated, or reordered *logical* gate cannot be declared gauge merely because a local clock/flag ends in the same value. A direct proof avoids the QEC theorem: if one decoder undoes each unitary on every state, its restriction to the common code subspace must equal both inverses; they agree only up to global phase.

If a physical gauge tag `|g_h>` is retained, with Kraus maps `sqrt(p_h) (V U_h) tensor |g_h>`, the cross equation becomes `sqrt(p_h p_k)<g_h|g_k> U_h^dagger U_k = c_hk I`. Distinct nonproportional logical unitary classes therefore require **orthogonal tag states**. A `D`-dimensional reusable tag can distinguish at most `D` such simultaneously live classes. This is a finite-capacity claim for exact recovery with accessible tags, not a theorem that all finite tags are unsafe: a verified drain, correctable local error, or checkpoint can erase the old class before reuse. It pinpoints the extra invariant needed to avoid ABA.

**Explicit one-qubit histories.** Let the target be the identity, but a faulty common flag allows either `I` or `Z` on the logical qubit with equal probability and leaves no readable trace. Their mixture is `(id+Ad_Z)/2`, complete dephasing. Applied to half a Bell pair it gives a separable state. Any subsequent decoder acts locally and cannot restore Bell entanglement, so its unhalved diamond distance from the identity is at least `1`. An analogous ambiguous order of `H` and `S` is nontrivial: `H S|0>=|+>` while `S H|0>=(|0>+i|1>)/sqrt(2)`, hence `H S` and `S H` are not projectively equal. Local occurrence inside a *correctable physical tile* is absorbed by Theorem H; occurrence as an unrecorded logical operation is not.

This also explains why a signed coefficient elsewhere is not the obstruction here. A negative coefficient in a particular kernel expansion defeats a **positive-kernel representation**, not quantum stability. Here the cross-Gram or Bell argument is an exact impossibility for a specified erased-history channel, while saying nothing about whether a different controller preserves a syndrome or confines the difference to correctable physical tiles.

## 3. How a finite verifier could test the contract—and what it cannot test

Root proposed, independently of this report, a useful finite-algebra verifier. For a **closed finite controller graph** whose edge labels are explicit quantum Kraus maps and whose state tracks a bounded fault budget, saturate the linear spans of `K_path V` at each controller/budget state. Each span lies in a matrix space of dimension at most `D_phys d_L`; finitely many states imply finite termination even when the graph has arbitrary loops. At accepting states, test the cross-Gram identities (G1) for a basis of the saturated span. This decides exact correctability of **all finite accepted histories** of that finite graph, including noncommuting repeats and recycled flag loops; one counterexample basis pair gives a finite witness. If a particular EC decoder is required for recursive composition, additionally test its prescribed decoded channel identity rather than merely the existence of some recovery. That algebraic test can sometimes establish a harmless gauge loop not covered by the simple width bound, or decisively reject a dangerous logical loop. The bounded-shadow theorem provides a structural certificate that makes the Gram test pass without enumerating the matrix span.

The finite graph is an adequate model only if every crossing quantum wire, controller read, reset/release carrier, shared flag, environment memory, and local noise effect is a port or state of the graph. A favorable test on an artificially closed neighborhood says nothing about a clock waiting on an exterior neighbor. Termination of the span algorithm is also not physical progress: loops that never accept, rare long gate episodes, and ongoing idle noise require separate service and protected-wait estimates. A graph for one level is not a proof that its support and alphabet remain fixed under self-simulation. The verifier does not itself bound how one fault can taint several code tiles or higher-level exRecs.

## 4. Recursive and stochastic interface, with exact remaining quantifiers

Suppose, **separately from Theorem H**, that a level-uniform machine provides canonical predictable labels for completed virtual macro-events. For any fixed set `J` of `n` such labels, suppose the hypotheses of `STOPPED_EXPOSURE_THEOREM.md` hold: one primitive fault owns at most `R_f` directly bad labels and the locally tilted stopped exposure has `E_Q exp(beta A_J)<=K^n`. Only then the direct-label event has

```
P(all J directly bad) <= K^n (p/beta)^ceil(n/R_f).
```

This is a classical Poisson witness bound. To turn it into a channel bound, the event-restricted branches must be CP instruments with state-independent clock weights or an equivalent reference-uniform effect domination. It says nothing by itself about a persistent wrong controller state after the witnessing jump; that propagation is what the output-shadow/damage theorem must bound.

At the next level, require a **subadditive multi-seed shadow certificate**: for *every* set `S` of lower-level bad seeds and every allowed interleaving, the union output shadow is at most `s|S|` constituent tiles **per affected code block**, and each seed participates in at most `R_x` higher-level exRecs. These bounds must be uniform in level, circuit, and elapsed time. Bounding each seed only on a fault-free background is insufficient: two bad controllers could interact and release a block-wide gate wave. Suppose the gate gadget is unitary between named leading/trailing EC cuts and, with up to `t` tainted tiles, meets Theorem H or its gadget-specific decoder identity. Then `q=floor(t/s)+1` distinct seeds are necessary to make that exRec bad **by this mechanism**. If each higher-level exRec has at most `m` fixed lower-level candidate seed labels and lower-level inclusive CP effects satisfy `||E_l(S)||_diamond<=eta_l^|S|` for every deterministic set `S`, the ordinary witness count gives

```
eta_(l+1) <= binom(m,q) eta_l^(q/R_x).                 (R1)
```

The proof selects one `q`-set of seeds for each prescribed bad exRec. Across `n` such exRecs, at least `ceil(qn/R_x)` distinct seeds occur; there are at most `binom(m,q)^n` selections, and the CP inclusion/union bound applies. Noise suppression needs `q>R_x`. Formula (R1) is **conditional**: `m`, `s`, `R_x`, and the CP effect inequality must be proved for the actual asynchronous controller. If random protected identity rectangles introduce unbounded candidate counts within a gate episode, one cannot silently use a fixed `m`; those rectangles need their own labels and a joint stopped-exposure/volume argument. Source values such as synchronous `R=4` and `t_bad=7` cannot simply be copied to an enlarged asynchronous controller.

Even with (R1), recursive correctness still needs (i) a level-uniform self-simulation map with fixed physical alphabet and support; (ii) a damage rule showing that every wrong flag/clock creates a bounded tainted footprint and that damage shrinks or stays marked until EC; (iii) exact joint packet composition at shared-wire and exRec boundaries; and (iv) a physical final-hold frontier and decoded readout. Virtual causal cuts do not imply an earlier state can be reconstructed from a later noisy state.

**Physical-time charge.** A code block waiting for another event must execute protected identity/EC rectangles. With conditional bad probability at most `epsilon_l` per entered identity rectangle and expected number `E W`, the error contribution is at most `epsilon_l E W`; the count is random but is *not free*. It also needs a completion-tail bound for the requested physical readout time. If the partial gate episode itself leaves growing encoded data unprotected for a duration tending to infinity, no history quotient saves it: under independent onsite dephasing at any fixed `p>0`, the averaged channel tends to an entanglement-breaking channel before trailing EC. The exact serialized-gate calculation in predecessor `SERIALIZATION_AND_REUSE.md` gives lower bound `||C_n-Ad_X||_diamond >= 1-n(1+2p)^(-n)` for its growing unprotected chain. Thus bounded shadow is a logical-algebra condition; protected exposure is a separate dynamical condition.

## 5. Tests against the actual controller features

| Feature | What the theorem absorbs | What remains unproved or fails |
| --- | --- | --- |
| Skipped/duplicated/noncommuting microgates | Arbitrary local history inside a causally fenced packet whose output cone has at most `t` tiles | A wrong *logical* gate or an unbounded cone violates the width/KL condition |
| Faulty shared flags | A flag whose entire influence remains within `s` correctable tiles is one seed regardless of repeat count | A common flag choosing a whole transversal layer has block-wide fanout; one fault can cause a logical skip |
| Clock repair | A repair-created gate debt is permissible if its **complete** data/control output shadow is corrected at a named EC cut | Clock validity alone does not give the shadow bound; the inherited affine-front witness propagates history discrepancy |
| Finite tags and recycling | Reuse is allowed after a provable drain/EC cut, or if every stale action remains correctable and cannot steer later gates | Same tag plus two nonproportional logical histories fails (G1); a one-phase recycler can loop arbitrarily long |
| Shared wires/exRec overlap | Typed joint causal quotient and an explicit `R_x` make packet and witness accounting meaningful | Separate convex packets can have a cyclic joint quotient; a reused shared control wire increases fanout |
| Protected idle | Identity exRecs can protect arbitrary waits with probability charged by their random count | A finite code cannot store perfectly for an indefinite unprotected wait |
| Self-simulation | A fixed-shadow local rule could be a component of an inductive goodness lemma | No level-uniform transition table, structural repair theorem, or actual overlap calculation is supplied here |

## 6. Status and next decisive experiment

Theorem H is mathematically exact under its explicit assumptions. It offers a consequential **conditional** design relaxation: for a unitary fault-tolerant gate stage, the controller need not prove a bound on the number of gate-history edits if it can prove a bounded output causal shadow and protected completion. The cross-Gram test gives an exact way to reject a proposed gauge/history quotient when a shared, erased record hides distinct logical actions.

The hard step is an actual finite asynchronous transition table that makes the shadow bound survive flag repair, tag reuse, domain handshakes, and arbitrary allowed one-seed interleavings, while still giving level-uniform service and protected time. A strong immediate falsification test is to feed a proposed table into the finite Kraus-span verifier and look for two accepted path operators with a nonscalar cross-Gram product, or for a one-seed path whose taint reaches more than `t` output tiles before EC. Even passing both at one level would not establish a threshold without the stopped joint exposure, damage erosion, exRec overlap, self-simulation, and physical readout proofs above. **No complete controller meeting those conditions has been found in this investigation.**

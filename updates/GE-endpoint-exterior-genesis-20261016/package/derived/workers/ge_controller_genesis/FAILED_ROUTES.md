# Independent inventions, failed routes and incumbent stop

## Frame-gauge phase erasure: rejected as a solution of logical execution

The initial independent idea used a finite one-site unitary frame group. Every atomic move would apply U_a to data and update frame g to ag; controlled ungauging makes each such move identity on decoded data. A total code recovery could reset every frame, with arbitrary same-site replay/omission histories corrected at a code cut. The binary tetrahedral group provides 24 exact frame labels for noncommuting physical X/C moves.

The issue is structural: all of those moves are gauge. No noncommuting logical operation survives. This changes the requested controller problem to standard fixed-code dissipative recovery, with an atomic whole-code recovery still assumed. The parent identified this receiving mismatch, and the route was not promoted. No executable implementation or claim of a new theorem was saved for it.

## Reusable total receiver: narrow lemma survives, general invention does not

`REUSABLE_RECEIVER.md` changes the logical target: terminal events implement real alternating logical X,C operations. Suffix completion and recovery make arbitrary partial fast-path history on one affected track correctable, and the same two banks and phase copies are reused indefinitely. Every malformed controller state has a terminal service proposal.

But set all optional fast-path rates mu_i to zero. The same T is then just a Poisson transversal gate, total whole-code QEC and bank swap. It has identical terminal rate, ideal logical outputs, and stopped-noise bound. It can remove the progress bits, halving the local register dimension. If fast-path gates have their own physical error contribution, suppressing them improves the error budget. This is an explicit same-interface incumbent, not an appeal to unexamined literature.

Therefore the receiving lemma is useful only as an interface for already partially executed transversal strands; it supplies no new capability over the atomic whole-code primitive. It does not remove the general controller/compiler obstruction. Continued optimization of its constants is not recommended.

## Naive terminal splitting: rejected by a fault-free replay

One proposed route to remove the atomic support was to separate recovery/movement from phase reset. With phase still r=0 after moving A to B, another data-move proposal can select A again, unconditionally clear B, recover an empty A and replace the unknown packet by the complement code state. Zero primitive faults are required. `split_terminal_trace.py` and `SPLIT_TERMINAL_TRACE.json` give this trace.

A lock set before the move can prevent that exact interleaving; it introduces lock recovery, partial-state ownership and noisy reset obligations. Treating that lock or its commit as an ideal encoded operation merely renames the missing interface. This is not a no-go for other asynchronous implementations.

## Broad phase damage and incoming ownership: genuine limits

From initial owned A and vacant B, change phases at three sites to `(1,1,1,0,0)`. T chooses phase one, treats B as source, discards live A, and returns its declared complement state |0_L>. Service succeeds and quantum history fails, outside the one-site family. The incorrect phase may then persist as a clock-payload offset. Every eta-rate faulty terminal is therefore globally bad in the finite-horizon theorem; it is never silently healed.

If an independent unknown live packet can enter the supposed unowned destination before T, the unconditional clear erases it. The closed-wire theorem cannot be connected to streaming sources or overlapping tiles without a proved ownership/drain interface.

The phase residue r mod4 records the next hardwired word and bank parity. It does not determine the full accumulated logical channel: Ad(CX) has order three, so alternating logical history has period six. For example terminal indices zero and four share r=0 but have different logical channels. D_hold returns the last-commit logical state of the matched random-terminal process; it is not deterministic-time identity memory or a free exact gate-count readout. A separately analyzed larger residue could store this finite Clifford frame, but would still have the same atomic-recovery incumbent and no universal controller result.

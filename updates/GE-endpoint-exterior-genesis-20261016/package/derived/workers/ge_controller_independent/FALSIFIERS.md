# Falsifiers and non-transfer boundaries

16 October 2026. These concern this modified finite-cell generator only.

1. **A noisy recovery circuit can defeat the theorem with one physical fault.** In a sequential parity-readout circuit, let a syndrome ancilla be the target of CNOT_(3->a) and CNOT_(4->a). An ancilla Z before those two gates propagates Z_3 Z_4 onto the data. A fault-tolerant recovery must prevent or separately correct this spread. The supplied generator instead declares its five-site recovery an ideal engineered jump, with onsite noise before or after. The diagnostic in RESULTS.json finds that R applied to Z_3 Z_4 on the code selects the Y_1 error image and leaves logical -Y, an actual logical error. Consequently an arbitrary one-fault implementation of T or R_* is not covered and could have an O(p) logical error rate. No noisy compiler has been invented here.

2. **Splitting a local gate from its phase/movement update fails even without noise.** Replace a phase-0 Phi by an independently ringing "apply X to A" action and a later "move A to B, set phase 1" action. Two apply-X actions can occur before movement. If that happens on all five tracks, the first output word is C_L X_L^2=C_L, instead of C_L X_L. Its logical channel is different. A finite-state microscopic implementation needs a consumed authorization for each noncommuting microstep; the abstract onsite CPTP map alone does not supply that implementation.

3. **Classical retirement without recovery is not the theorem.** Resetting all five phase markers to zero at the all-2 cut, while retaining data errors, permits a fault on track i in one epoch and track j in a later epoch to coexist. The code does not correct arbitrary two-track errors. The explicit R at each T cut is necessary for the stated per-epoch quadratic bound. Optional R_* also has an explicit quantum action; calling a phase reset an EC step would not be valid.

4. **Arbitrary domain retirement may lose the encoded qubit.** An arbitrary damaged cell can have every r_i=2 while its entire true code state is in B. T discards B and finds only vacancy in A. It returns a fixed code state through the complement term of (2), losing the original logical/reference state. Theorem B promises a canonical controller and a bounded cell-local quantum output error, not quantum correction of an arbitrary cluster. Theorem A's one-track restriction is load-bearing.

5. **A shared unprotected phase bit is unsafe.** If one physical control fault changes the phase of all five tracks, it can skip a full transversal X or C, which is a logical operation. The physical fault support in the theorem is one track's two banks and phase. Five separately located phases are necessary for the one-site history ambiguity to be code-correctable. A global program bit or shared control fanout cannot be inserted without a new proof.

6. **Bank occupancy alone cannot replace the phase history.** Both phase 0 and phase 2 have their true share in A. The complete code states before and after the logical U range over the same code subspace. For arbitrary unknown inputs, a bank-only receiver cannot infer whether U already ran. This construction retains the finite local phase history and tolerates one faulty track by correcting its data effect; it does not infer an unencoded quantum past from occupancy.

7. **General interaction and recursion remain unproved.** A nontransversal physical gate can spread one track error to a second track before the next recovery, invalidating Theorem A. Intercell CNOTs need an actual rendezvous/ownership rule. A growing encoded block cannot use the five-site T or R_* as one fixed-range physical jump. The fixed cell does not provide a coupled-lattice damaged-domain eroder, a universal programmable controller, or a level recursion.

8. **Output and hold cuts are separate.** The exact repeated output contract is immediately after the named nth T. A later onsite fault may corrupt that output before readout. A later ideal R_* can correct one-track damage, but an arbitrary indefinite hold under positive fault rate has no exact guarantee. The displayed finite-n diamond bound includes epochs through nth T, not future noise or faulty readout hardware.

9. **No acquired physical reset law is supplied.** The local maps contain discards and vacancy preparation. Their ideal CPTP definitions and local fault-rate model do not supply dissipator strengths, reservoir preparation, thermodynamic work, calibration, or an implementation's actual correlated fault support. Those quantities are UNKNOWN.

The finite diagnostics support only the specified algebra/service model. They establish no historical priority, external correctness, new physical capability, or mission achievement.

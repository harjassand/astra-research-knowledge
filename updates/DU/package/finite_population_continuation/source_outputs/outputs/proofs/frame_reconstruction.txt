# Near-cloning yields a nearly orthogonal Parseval frame

Date: 11 October 2026. Investigator: independent inventor.

**Status.** The rank-one compression, polar-rounding lemma, frame theorem, dimension/excess statements, simplex lower constructions, and information corollary below have complete internal proofs. The frame theorem is conditional on the upstream global Schur-class theorem in `work/astra_obstruction/global_surrogate_representation.md`. I did not independently reconstruct its Schur lemma; another investigator reconstructed that part. No external validation or historical-priority claim is made. Polar frame normalization and the rank-one POVM/Parseval-frame correspondence are established techniques; the contribution here is their pointwise, defect-weighted consequence for the supplied global cloning geometry, together with matching-order outcome lower bounds.

## 1. Input theorem and exact quantifiers

Let H have finite dimension d and let B:H -> H tensor H be CPTP. For a pure state P put

    e(P) = 1 - Tr[(P tensor P) B(P)],    tau = 1/2800,
    S = {P pure: e(P) <= tau},
    C = 224 + 128 sqrt(3) < 450.

The upstream theorem supplies, if S is nonempty:

- k compact classes S_c, with k <= floor(8d/7);
- a minimum-defect representative P_c = |psi_c><psi_c| in every class;
- one k-outcome POVM {M_c}, depending on B and not a prior;
- for every P in S_c,

      1 - Tr(M_c P) <= C e(P),
      1 - Tr(P P_c) <= 50 e(P),
      e(P_c) <= e(P).

The representation theorem proved below has quantifiers

    for every d and B, there exist N, an isometry U:H -> C^N,
    and N pure preparations Q_a, such that for every pure P,
    1 - Tr[P Lambda(P)] <= 2800 e(P),

where Lambda(P) = sum_a <a|U P U*|a> Q_a, all measurement effects have rank one, and

    d <= N <= floor(8d/7).

Thus a fixed isometric encoding sends every sufficiently well-cloned pure input close to one coordinate ray. This is stronger representation control than an arbitrary O(d)-outcome POVM, whose effects could each have rank d.

## 2. Rank-one compression of a high-success POVM

**Lemma 1.** Let {M_c}_{c=1}^k be a POVM and let psi_c be unit vectors with

    a_c = <psi_c,M_c psi_c> > 0,    r_c = 1-a_c.

Set

    m_c = M_c psi_c / sqrt(a_c),    A_c = |m_c><m_c|.

Then

    A_c <= M_c,    sum_c A_c <= I,
    |<m_c,psi_c>|^2 = a_c.

**Proof.** The vector z_c = M_c^(1/2) psi_c / sqrt(a_c) is unit. Consequently

    A_c = M_c^(1/2) |z_c><z_c| M_c^(1/2) <= M_c.

The sum inequality follows. Also <m_c,psi_c>=sqrt(a_c), up to the chosen harmless inner-product convention. Squaring gives the last identity. No rank hypothesis on M_c is used.

## 3. A pointwise polar-rounding lemma

**Lemma 2.** Under Lemma 1, put N=max(d,k). Form a row operator T:H -> C^N whose first k rows are m_c* and whose other rows are zero. There is an isometry U:H -> C^N such that, for every c,

    1 - |<c,U psi_c>|^2 <= 4 r_c.

**Proof.** Let S=T*T. Lemma 1 gives 0<=S<=I. Complete the partial isometry in the polar decomposition of T to a full isometry U, so

    T = U sqrt(S),    U*U=I.

This completion exists because N>=d: if rank(T)=r, its unused output dimension N-r is at least its unused input dimension d-r. It does not require an inverse lower bound on the nonzero eigenvalues of S.

For a representative psi_c,

    ||(U-T)psi_c||^2
      = <psi_c,(I-sqrt(S))^2 psi_c>
      <= <psi_c,(I-S)psi_c>
      = 1-||T psi_c||^2
      <= r_c.

The scalar inequality is (1-sqrt(s))^2<=1-s for 0<=s<=1. If Pi_c=I-|c><c|, then

    ||Pi_c T psi_c||^2 = ||T psi_c||^2-a_c <= r_c.

Therefore

    ||Pi_c U psi_c|| <= ||Pi_c T psi_c|| + ||(U-T)psi_c|| <= 2 sqrt(r_c).

Squaring proves the lemma. This is a pointwise statement, rather than an average-optimality statement.

**All effects have rank one.** Write u_a=U*|a>. The effects E_a=|u_a><u_a| sum to I. In the application, all first k rows are nonzero because their representative success is positive. If N=d, U is unitary and every row is nonzero. If N=k>d, the first k rows comprise all rows. Thus no claimed rank-one effect is a zero operator.

## 4. Extension from representatives to their whole classes

Define

    A = (2 sqrt(C) + sqrt(50))^2,
    K_in = A + 50.

Numerically, C=445.7025033688..., A=2429.9381426863..., K_in=2479.9381426863.... Exact estimates suffice:

    C<450,    A < (2 sqrt(450)+sqrt(50))^2 = 2450,
    K_in < 2500.

For P in S_c, Lemma 2 and e(P_c)<=e(P) give

    wrong_U(P_c) <= 4 C e(P).

Use the pure-state trace distance D(P,Q)=sqrt(1-Tr(PQ)). Isometries preserve it, and the coordinate ray |c><c| is pure. Hence

    sqrt(wrong_U(P))
      = D(U P U*, |c><c|)
      <= D(P,P_c) + D(U P_c U*, |c><c|)
      <= [sqrt(50)+2 sqrt(C)] sqrt(e(P)).

Thus every P in S_c satisfies

    wrong_U(P) <= A e(P).

On coordinate c<=k prepare P_c; on any added coordinate prepare an arbitrary existing P_c. The fidelity contribution of the correct coordinate alone implies

    1-Tr[P Lambda(P)]
      <= wrong_U(P) + 1-Tr(P P_c)
      <= K_in e(P) < 2500 e(P).

For P outside S, its reconstruction loss is at most 1<2800e(P). This proves the all-pure theorem. If S is empty, take any orthonormal measurement with d outcomes and prepare a fixed pure state on every outcome; the outside-S argument proves the bound.

The use of a genuine pure-state trace-distance triangle is deliberate. A raw vector triangle can introduce unnecessary phase or square-root losses.

## 5. Collective near-orthogonality and a small coherent dilation

The vectors {u_a}_{a=1}^N form a Parseval frame:

    sum_a |u_a><u_a| = I.

Their Gram matrix K=UU* is an orthogonal projection of rank d. For every representative c,

    K_cc = ||u_c||^2 >= |<u_c,psi_c>|^2 >= 1-4 C e(P_c).

The projection identity K^2=K yields the collective leakage estimate

    sum_(b != c) |<u_b,u_c>|^2
      = K_cc(1-K_cc)
      <= 4 C e(P_c).

This controls all other frame vectors at once, rather than only their pairwise overlaps. In addition, every good P in S_c obeys

    Tr[U P U* |c><c|] >= 1-A e(P).

So U is an explicit nearly one-hot coherent representation of the whole good set, after the upstream POVM and representatives have been acquired.

A rank-one N-outcome POVM has a coordinate-projective dilation on C^N. Here N<2d. Embed C^N into H tensor C^2 and extend the isometry from inputs H tensor |0> to a unitary on H tensor C^2. A single computational-basis measurement then implements the frame POVM; the extra 2d-N coordinates have zero input probability. Thus **one ancillary qubit suffices for a fixed Naimark implementation**. When N=d, U is unitary and the measurement is an ordinary orthonormal basis measurement on H.

This statement concerns coherent Hilbert-space size. It does not claim a short gate circuit or efficient acquisition of U. A lower bound below rules out one fixed basis measurement in some dimensions; it does not by itself rule out protocols with external classical randomization among many bases.

## 6. A defect-dependent excess-outcome budget

Fix 0<=epsilon<=tau and restrict to S_epsilon={P:e(P)<=epsilon}, or any family contained in it. Retain the upstream classes that meet this family. Their minimum-defect representatives have e(P_c)<=epsilon, and their effects are part of the same global POVM.

If there are k_epsilon such classes, then

    k_epsilon(1-C epsilon)
      <= sum_c Tr(M_c P_c)
      <= sum_c Tr(M_c)
      <= d.

The row compression and polar completion use only these selected effects; their sum is <=I, which is all Lemmas 1-2 require. Set N_epsilon=max(d,k_epsilon). One obtains a rank-one frame and preparations working simultaneously on the selected family, with loss <=K_in e(P), and

    N_epsilon <= min{floor(8d/7), floor[d/(1-C epsilon)]},
    N_epsilon-d <= C d epsilon/(1-C epsilon).

In particular, if

    C epsilon(d+1) < 1,

then N_epsilon=d and one fixed orthonormal basis measurement suffices for the whole family. The exact d+1 in this integer threshold should not be silently replaced by d.

This is a restriction-dependent representation. A frame constructed only for S_epsilon is not asserted to satisfy the all-pure guarantee outside that selected family.

## 7. Exact simplex cloning and the necessity of excess outcomes

This construction was independently reconstructed here and also by the parent researcher.

Let q>=2 and take q+1 real regular-simplex states psi_i in a q-dimensional Hilbert space, with

    <psi_i,psi_j> = -1/q  (i!=j),    sum_i psi_i=0.

One explicit realization is the zero-sum subspace of C^(q+1), with

    psi_i = sqrt((q+1)/q) [e_i - (1/(q+1)) sum_j e_j].

Put phi_i=psi_i tensor psi_i and t=(1/(q+1))sum_i phi_i. Directly from their Gram matrix,

    ||t||^2 = <t,phi_i> = 1/q.

The centered, normalized vectors

    v_i = (phi_i-t)/sqrt(1-1/q)

have exactly the same Gram matrix as the psi_i:

    <v_i,v_i>=1,    <v_i,v_j>=-1/q  (i!=j).

The assignment V psi_i=v_i therefore extends to an isometry on their q-dimensional span. The economical cloner B(P)=V P V* satisfies, on every simplex state,

    Tr[(P_i tensor P_i) B(P_i)] = |<phi_i,v_i>|^2 = 1-1/q,
    e_B(P_i)=1/q.

No hidden representation, oracle, or limiting argument is used.

Now take b orthogonal copies of this construction. The total input dimension and state count are

    d=bq,    k=b(q+1)=d(1+1/q),    epsilon=1/q.

Their direct-sum isometry maps each input block to the corresponding tensor-square block and again gives defect exactly epsilon on every input. Distinct input overlaps have modulus at most 1/q.

**Lower bound allowing mixed preparations.** Let an EB channel have m prepared states sigma_l. If every one of the k inputs has reconstruction fidelity strictly larger than

    (1+1/q)/2,

then m>=k. Indeed, each input needs some prepared state with at least its achieved fidelity. One sigma_l cannot serve two different inputs at that fidelity: for distinct i,j,

    Tr[sigma_l(P_i+P_j)] <= ||P_i+P_j||_infinity
                           = 1+|<psi_i,psi_j>| <= 1+1/q.

Pigeonhole proves the result. This does not depend on the ranks or algebraic forms of the POVM effects.

For any fixed linear constant K, choose an integer q>max{2800,2K+1}. Then a pointwise guarantee loss<=K e_B gives fidelity >=1-K/q>(1+1/q)/2, and consequently **every such surrogate needs at least**

    k = d + d epsilon

prepared states/outcomes. Thus an excess of order d epsilon is necessary. Section 6 shows that order d epsilon is sufficient, with a universal factor. The number of excess outcomes has the correct dependence on the defect budget; it is not just an artifact requiring one exceptional extra label.

For b=1, this also shows that no universal finite K can guarantee an all-pure surrogate with at most d prepared states in every dimension. In particular, a single fixed projective-basis measure/prepare channel can fail, even though the rank-one dilation needs at most one ancilla qubit.

The lower construction proves necessity on its explicitly exhibited input family. It need not classify every other well-cloned state of the same B.

## 8. One fixed measurement nearly captures the Holevo information

The same frame measurement, with its fixed preparations, works for every finite prior. Let {p_i,P_i} be any pure ensemble, Y its frame outcome, and

    E = sum_i p_i e_B(P_i),    delta = sum_i p_i [1-Tr(P_i Lambda(P_i))].

Then delta<=2800 E; if the ensemble is supported in the good set, delta<=K_in E<2500 E. Write rho=sum_i p_i P_i, q_y=Pr(Y=y), and

    rho_y = sum_i p(i|y) P_i.

If Q_y is the pure state prepared on outcome y, let delta_y=1-Tr(Q_y rho_y). Then sum_y q_y delta_y=delta and lambda_max(rho_y)>=1-delta_y.

For d>=2 define the concave nondecreasing capped entropy function

    g_d(t) = h_2(t)+t log_2(d-1),        0<=t<=1-1/d,
             log_2 d,                 t>=1-1/d.

The largest-eigenvalue entropy bound gives S(rho_y)<=g_d(delta_y), hence by Jensen

    sum_y q_y S(rho_y) <= g_d(delta).

Consider Y -> X -> A, where the classical preparation map sends label i to P_i. Data processing gives

    I(Y:A) = S(rho)-sum_y q_y S(rho_y) <= I(X:Y).

The input ensemble is pure, so its Holevo information is chi=S(rho). Consequently

    0 <= chi-I(X:Y) <= g_d(delta) <= g_d(2800 E).

On a uniformly epsilon-good family the same fixed frame measurement therefore has classical capacity at least its pure-state Holevo capacity minus g_d(K_in epsilon). The measurement is independent of the prior used to approach the capacity supremum. It has N<=floor(8d/7) outcomes, so its raw outcome entropy never exceeds log_2 N.

This is a one-use information-retention statement. It does not settle quantum-channel regularization questions or claim that a succinct circuit for the measurement can be found from black-box access to B.

## 9. Acquisition, arithmetic, and scope

Once explicit M_c and psi_c are supplied, the new conversion uses k matrix-vector products, one N-by-d polar/SVD computation, and a unitary extension. Its output has O(d^2) scalar entries because N=O(d), rather than O(d^3) entries for O(d) arbitrary full-rank POVM effects. Dense numerical linear algebra has cubic arithmetic scale here, but exact bit complexity and the precision needed for a desired operational tolerance must be charged separately.

The continuum-constrained upstream POVM and class-minimizing representatives have **UNKNOWN acquisition cost**. The finite representation theorem does not supply them for free, perform channel tomography, or establish efficient implementation in log(d) qubits.

The polar construction requires no quantitative spectral gap for its existence or its pointwise proof. Numerically approximating a particular polar factor can be sensitive near zero singular values. An approximate isometry U_delta satisfying ||U_delta sqrt(S)-T||_op<=delta gives, by the same proof,

    wrong_(U_delta)(P) <= [A^(1/2) sqrt(e(P))+delta]^2

on a good class. Using (x+y)^2<=1.1x^2+11y^2 and A<2450, the associated reconstruction loss is at most

    2800 e(P) + 11 delta^2

on all pure inputs covered by the full construction. This is the appropriate additive tolerance if a numerical frame is delivered; exact preservation of zero-defect states is not inferred from a floating-point SVD.

## 1. The general cutpoint-to-coupling transfer

Let `J` be a finite set of `d` states, `f_0,f_1:J->J` two deterministic maps, `s` a fixed initial state, and `F` a set of accepting states. Define

\[
P(j,k)=\tfrac12 1_{f_0(j)=k}+\tfrac12 1_{f_1(j)=k}.
\]

There is a finite two-generator semigroup `S`, distinct elements `a_0,a_1`, and elements `z!=0` such that `zs=sz=0` for every `s in S`, with the following exact transfer. Set `mu=(delta_{a_0}+delta_{a_1})/2`. At length

\[
N=2(d+1)r+10,
\]

there exists a joint law with every coordinate marginal `mu` and product equal to `z` almost surely if and only if

\[
(\delta_sP^r)(F)\ge\tfrac12.
\tag{transfer}
\]

No independence of the coordinate law is assumed. The semigroup is supplied by a finite DFA construction; this is an existence and explicit finite construction theorem, not a small multiplication-table bound.

### Fair-marginal forcing

A raw block has one branch bit `B` followed by `d` checker bits, with checker `j` required to equal

\[
C_j=B\mathbin\oplus1_{\{\text{current state}=j\}}.
\]

After these bits, update the state by `f_B`. Fairness of `B,C_j` implies

\[
\Pr(J=j,B=0)=\Pr(J=j,B=1)=\tfrac12\Pr(J=j).
\]

Thus the one-time state laws obey the exact recursion `law(J_{r+1})=law(J_r)P`. The conditional choice given the current state is fair; a full history-dependent Markov property need not hold and is not used.

After `r` complete blocks append one terminal bit `B_*`, accepted if `B_*=0` or the current state belongs to `F`. Fairness forces `P(J_r in F)>=1/2`. Conversely, use independent fair branch bits, which make every deterministic checker fair, and choose the terminal bit to be one with conditional probability `1/(2p)` on `F`, where `p=P(J_r in F)>=1/2`, and zero off `F`. This is fair and accepted. Hence raw-word feasibility at length `(d+1)r+1` is exactly the cutpoint condition.

### One accepted syntactic class, with all marginals retained

Manchester-encode each raw bit by `h(0)=01,h(1)=10`, and wrap the payload with any prefix in `{0001,1110}` and any suffix in `{1000,0111}`. The payload is THE SAME in every marker branch; it is not freely complemented.

In any wrapped word the only triple runs `000` or `111` are the initial three and final three positions. Manchester pairs and their boundaries cannot create a triple; the adjacent guard bit prevents a triple across each wrapper/data boundary. Therefore an accepted word cannot be a proper factor of another accepted word: its two marker triples would have to coincide with the containing word's two triples, fixing both endpoints.

All accepted words consequently have exactly the same accepting contexts, namely the two empty contexts. They form one syntactic class `z`; no rejected word has that class. The finite syntactic semigroup recognizes product `z` exactly on the wrapped language. Appending or prepending a nonempty word to an accepted word gives an empty-residual class `0`, so `zS=Sz={0}` and `z!=0`.

The two letter classes are distinct: replacing the first bit of an accepted word changes a valid prefix into an invalid one, which would be impossible if the letter classes were equal.

Reading the first bit in each Manchester pair decodes any fair-coordinate wrapped law to a fair-coordinate raw law. Conversely, independently fair marker choices preserve fairness of every wrapper coordinate, and a fair raw bit produces two fair Manchester coordinates. This proves (transfer).

Thus the displayed arithmetic progression does not merely witness a subsequence of a larger unknown horizon set.

## 3. Nonperiodicity, with all threshold equalities excluded

Write `lambda=|lambda| exp(i theta)`. Since

\[
\frac\lambda{\bar\lambda}+\frac{\bar\lambda}\lambda=-\frac{13}{7},
\]

`theta/pi` is irrational: otherwise the ratio would be a root of unity and its sum with its inverse would be a rational algebraic integer, which must be an integer. In particular `cos(t theta)` is nonzero for every positive integer `t`.

For any integer period `p>0`, rotation by `p theta` is nonzero modulo `2pi`. The positive semicircle and its translate by this angle have a nonempty open symmetric difference. Every tail of the irrational orbit `t theta mod 2pi` is dense, so infinitely many `t` and `t+p` have opposite signs. The sign sequence is not eventually periodic.

If the full horizon set had eventual period `P`, its restriction to `70+60t` would have eventual period `P/gcd(P,60)` in `t`, contradicting the sign result. Hence the exact product-feasibility set of this fixed finite semigroup, fixed rational two-point input law, and fixed point-mass target is not eventually periodic.

## 4. An explicit approximation boundary

Although exact feasibility is nonperiodic, the same construction has an exponentially vanishing approximation error. At `r=2+2t` use independent fair branch bits and valid checkers as before. Let

\[
p_t=\tfrac12+\tfrac12\operatorname{Re}(\lambda^t).
\]

If `p_t>=1/2`, choose the accepted terminal bit law and achieve the target exactly. If `p_t<1/2`, set the terminal bit to one on all accepting states and choose it to be one on an additional portion of the nonaccepting states of total probability `1/2-p_t`. This is a well-defined conditional randomization, since that amount does not exceed `1-p_t`. The terminal bit is fair, all checkers remain valid and fair, and rejection occurs only on the additional portion.

After independent balanced wrapping, the product law `eta_t` therefore obeys

\[
\boxed{\|\eta_t-\delta_z\|_{\mathrm{TV}}
\le\frac{(-\operatorname{Re}(\lambda^t))_+}{2}
\le\frac12\left(\frac{\sqrt7}{4}\right)^t.}
\]

Here TV is the supremum-over-events convention. This is an upper bound on approximation error, not a proof of optimal error. The nonperiodicity theorem is consequently an exact, nongap phenomenon; it does not furnish a fixed positive-error obstruction or an undecidability result.

# Mixed product-cloning extension: exact partial bridges and remaining gap

11 October 2026. **The missing mixed-state bridge has now closed analytically within the team.** Sections A–D preserve the exploratory derivation and failures; Sections E–G independently reconstruct the completed bridge and universal statement. This is an internally reconstructed candidate theorem, not an external validation or novelty claim.

## Target

For finite mixed ensemble `{(p_i,rho_i)}`, one full-domain channel `B:H->H tensor H` has errors

`e_i=1-F(B(rho_i),rho_i tensor rho_i)`,

where `F(sigma,tau)=||sqrt(sigma)sqrt(tau)||_1^2` is squared Uhlmann fidelity. Does there exist an EB channel `T` with

`sum_i p_i [1-F(T(rho_i),rho_i)] <= C sum_i p_i e_i`

for universal finite `C`? The premise concerns an approximately independent product output, not merely accurate marginals.

## A. The constrained majority bootstrap extends to mixed states

Suppose a fixed class assignment `c(i)` admits a full-domain class POVM with every error at most `a0=1/4`, on labels with `e_i<=tau=1/2800`. Then optimizing the prior-average class error over this compact constrained set and repeating the pure proof gives

`R <= (224+128sqrt(3)) E`,

where `R` is optimized wrong-class probability and `E` is the prior-average product-cloning infidelity.

Here is the mixed replacement for the pure Stinespring-vector step. Use Bures distance

`d_B(sigma,tau)=sqrt(2-2sqrt(F(sigma,tau)))`.

It contracts under channels, obeys the triangle inequality, and satisfies `d_B^2<=2(1-F)=2e`. Define the twice-used channel `B3=(id tensor B)B`. Then

`d_B(B3(rho_i),rho_i^tensor3)`

`<=d_B((id tensor B)B(rho_i),(id tensor B)(rho_i^tensor2))`

` +d_B(rho_i tensor B(rho_i),rho_i^tensor3)`

`<=2d_B(B(rho_i),rho_i^tensor2)<=2sqrt(2e_i)`.

The second term uses invariance of root fidelity under tensoring the same state. For any binary test effect `A`, Uhlmann plus the pure-vector square-root probability estimate gives

`|sqrt(tr A sigma)-sqrt(tr A tau)|<=d_B(sigma,tau)`.

Hence measuring the optimizing class POVM on three ideal copies and taking majority, then pulling the test back through `B3`, still gives

`r'_i<=(sqrt(3)r_i+sqrt(8e_i))^2`.

The constraint feasibility and all averaging algebra are exactly as in the independently reconstructed pure proof. Actual output independence is not assumed.

## B. Bures geometry gives a global class partition and a weighted within-class bound

Let `r_ij=sqrt(F(rho_i,rho_j))`, and retain good labels `e_i<=1/2800`. Define Bures angle `theta(sigma,tau)=arccos sqrt(F(sigma,tau))`. Monotonicity of fidelity and the triangle inequality give

`g(r):=arccos(r^2)-arccos(r) <= asin sqrt(e_i)+asin sqrt(e_j)`. (B1)

Indeed the ideal product targets have root fidelity `r^2`; their intervening actual outputs have angle at most the input angle `arccos(r)`.

For `0<=x<=sqrt(tau)`, the derivative bound gives

`asin(x)<=x/sqrt(1-tau)<(6/5)x`.

Since `g(r)=integral_(r^2)^r (1-t^2)^(-1/2)dt>=r(1-r)`, (B1) implies

`r(1-r)<(12/5)/sqrt(2800)<1/20`.

If `r` belonged to `[1/16,15/16]`, its product would be at least `15/256>1/20`. Thus every pair of good states satisfies the dichotomy

`r<1/16` or `r>15/16`.                            (B2)

The high-overlap relation is transitive. If `r_ij,r_jk>15/16`, Bures-angle triangle gives

`r_ik>cos(2 arccos(15/16))=97/128>1/16`,

so (B2) forces `r_ik>15/16`. Thus `r_ij>3/4` defines an equivalence relation on the good states, including all good density matrices of a fixed channel.

For any same-class pair put `s=sqrt(1-r^2)` and `D=e_i+e_j`. A sharper elementary lower estimate is

`g(r)>= r(1-r)/sqrt(1-r^4)`

` = [r/((1+r)sqrt(1+r^2))] s >=(12/35)s` for `r>=3/4`.

The coefficient is minimized at `r=3/4`: its logarithmic derivative has numerator `1-r^3>=0`. Combining with (B1) yields

`s <=(35/12)(6/5)(sqrt(e_i)+sqrt(e_j))`

` =(7/2)(sqrt(e_i)+sqrt(e_j))`,

`1-F(rho_i,rho_j)=s^2 <=(49/2)(e_i+e_j)<25(e_i+e_j)`. (B3)

Thus minimum-error class representatives give correct-class mixed fidelity loss at most `50e_i`, exactly as for pure states. Fidelity is concave in either state separately, so a measure-and-prepare mixture has loss at most the mixture of the individual prepared-state losses. This also follows from the variational formula for squared fidelity as an infimum of linear functionals in one argument. No affine pure-target identity is needed here.

For the entire good density-matrix set of one fixed finite-dimensional `B`, root fidelity is continuous and its good set is compact. The gap (B2) makes classes closed; the classes are finite in number because choosing one point from each class gives a uniformly Bures-separated set in a compact metric space. Their number is not bounded independently of dimension by this argument. Minimum-error representatives therefore exist globally.

**Bridge as originally isolated (closed in Section E):** establish one class POVM with error at most `1/4` on every good density matrix, uniformly over dimension and number of classes. If this follows from the product-cloning premise, Sections A–B and the fixed-threshold bad-label accounting prove the unrestricted mixed theorem with the same loose constant `2800`. Pairwise near orthogonality by itself is insufficient for such a multistate measurement, so (B2) alone does not close it.

## C. Failed lifts, with explicit failure mechanisms

1. **Coherent purification is unavailable.** A replacer `B(X)=tr(X) rho tensor rho` exactly product-clones the singleton `rho=I/d`. Yet `B tensor id` applied to a canonical purification destroys its reference correlations. Thus output-state product fidelity does not imply cloning a supplied purification.
2. **Pure convex-roof cloning loss is unavailable.** For the same replacer, every pure input `P` has global cloning infidelity `1-1/d^2`, while the mixed singleton's cloning error is zero. Decomposing `rho` into pure eigenstates therefore does not transfer the premise to a low-error pure ensemble.
3. **Canonical square-root vectors lose the physical restriction.** The vectors `|sqrt(rho_i)>>` in Hilbert–Schmidt space have a scalar affinity Gram matrix. Uhlmann alignment of the output purifications uses a different unitary on the reference/environment for each label. Their target overlap need not factor as the square of the input scalar Gram times a correlation matrix. A common physical Stinespring isometry acts only on the actual input system; treating those alignment unitaries as free would grant unavailable reference access.
4. **Generic iteration/de Finetti is dimension dependent.** Repeated approximate replication accumulates product approximation error. Classicalization of many output systems introduces the output-dimension factors in the primary Chiribella–D'Ariano bounds. This is not a replacement for the missing uniform weak class measurement.

## Primary context consulted

[Lemm–Wilde, *Information-theoretic limitations on approximate quantum cloning and broadcasting*, arXiv:1608.07569](https://arxiv.org/abs/1608.07569), gives entropic restrictions for pairs of mixed states and distinguishes cloning from mere broadcasting. Its definition requires exact product form for the approximate cloned outputs; this differs from the present product-fidelity promise. It does not supply the missing global weak class POVM.

[Piani, *Hierarchy of efficiently computable and faithful lower bounds to quantum discord*, arXiv:1501.06855](https://arxiv.org/abs/1501.06855), studies local-broadcasting and EB-recoverability fidelities via an SDP hierarchy. It concerns marginal broadcasting and convergence in the number of output systems, rather than the specific near-independent product premise here. No unrestricted linear mixed theorem was imported from it.


## E. The mixed weak-classifier bridge closes by a forbidden-risk interval and omission induction

The new operation was proposed by the independent inventor and reconstructed by root, obstruction and this agent. It does not use a scalar purification Gram matrix or Schur multiplier rounding.

### E1. Mixed PGM base case, with an elementary proof

For `m` states with prior `p`, set `A_i=p_i rho_i`, let `R=[sqrt(A_1) ... sqrt(A_m)]`, and put `S=R R*`, `G=R* R`. The PGM effects are

`M_i=S_support^(-1/2) A_i S_support^(-1/2)`.

They sum to the support projection of `S`; complete them arbitrarily on its orthogonal complement. The identity `sqrt(G)=R* S_support^(-1/2) R` gives

`PGM success=sum_i ||sqrt(G)_ii||_HS^2`,

`PGM error=sum_(i!=j) ||sqrt(G)_ij||_HS^2`.

Writing `G0=diag(A_i)`, Powers–Størmer and the off-diagonal block triangle inequality imply

`PGM error<=||sqrt(G)-sqrt(G0)||_HS^2<=||G-G0||_1`

`<=sum_(i!=j)||sqrt(A_i)sqrt(A_j)||_1`

`=sum_(i!=j)sqrt(p_i p_j) sqrt(F(rho_i,rho_j))`.

Singular states and zero priors are included by the support inverse. The elementary Powers–Størmer proof is in `linear_cloning_estimation_reconstruction.md`: for `X,Y>=0`, `D=X-Y`, duality with `sign(D)` gives `||X^2-Y^2||_1>=tr|D|(X+Y)>=trD^2`.

Choose one good representative from each distinct class. Cross-class root fidelities are less than `1/16`. Consequently for `m<=3` and every prior the PGM average error is at most

`[(sum_i sqrt(p_i))^2-1]/16 <=(m-1)/16<=1/8`.

Finite convex minimax therefore supplies one POVM whose individual representative errors are at most `1/8`.

### E2. A forbidden interval for optimal worst-case risk

Let `R_m` be the minimum, over `m`-outcome POVMs, of the largest error on a fixed set of `m` good representatives. The minimum exists. Applying the twice-used cloner and majority to an optimizing measurement gives

`R_m<=f(R_m)`, where `f(r)=(sqrt(3)r+sqrt(8tau))^2=(sqrt(3)r+1/sqrt(350))^2`.

The function `f(r)-r` is convex. Root supplied the exact rational endpoint witnesses: use `sqrt(3)<7/4` and `1/sqrt(350)<3/56`. Then

`f(1/200)<(349/5600)^2<(1/16)^2<1/200`,

`f(13/50)<(89/175)^2<13/50`.

Thus `f(r)<r` throughout the closed interval `[1/200,13/50]`. An optimal risk cannot lie in this interval. In particular any construction giving `R_m<=13/50` forces `R_m<1/200`.

The base case gives this for `m<=3`. For `m>=4`, assume every `m-1` representative subset has a POVM with errors below `1/200`. Randomly omit one of the `m` labels uniformly and apply its subset POVM, treating the omitted label as an error. Each state's error is then at most

`1/m+(1-1/m)/200 <=203/800<13/50`.

The forbidden interval forces `R_m<1/200`. This induction holds for every finite number of good classes, independently of dimension and cardinality.

### E3. Transfer from representatives to entire classes

Choose a minimum-error representative `sigma_c` in each class of a finite ensemble. The within-class bound from Section B gives

`1-F(rho_i,sigma_c)<=25(e_i+e_rep)<=50tau=1/56`.

For every effect, its outcome probability changes by at most half trace distance, and hence by at most `sqrt(1-F)<=1/sqrt(56)`. The representative classifier therefore has whole-class error at most

`1/200+1/sqrt(56)<1/4`.

This is precisely the missing coarse measurement premise. Sections A–B now prove, for every finite mixed ensemble and each supplied fixed full-domain cloner `B`, the existence of an EB channel `T` with

`sum_i p_i [1-F(T(rho_i),rho_i)] <=2800 sum_i p_i [1-F(B(rho_i),rho_i tensor rho_i)]`.

The theorem concerns product-target joint fidelity and makes no coherent-purification assumption.

## F. One surrogate for every mixed input, with finitely many prepared states

There are two ways to establish the universal quantifiers.

**Compact EB minimax.** For any finite states, each loss `l_i(T)=1-F(T(rho_i),rho_i)` is continuous and convex in `T`. Squared fidelity is separately concave: Alberti's variational formula expresses it, with one argument fixed, as the infimum over `H>0` of the linear functions `tr(rho H) tr(sigma H^-1)`. The EB channel set is compact and convex in finite dimensions. The average theorem for every prior, followed by Sion's minimax theorem, gives one `T` satisfying `l_i(T)<=2800e_i` for each state in the finite set. Compact finite-intersection then gives one EB `T_B` for every density matrix simultaneously.

**Global fixed-representative construction.** The good density-matrix set of fixed `B` is compact. The Bures gap defines compact equivalence classes. Every finite set of distinct class representatives admits error below `1/200`; since

`(199/200)m < sum_c tr(M_c sigma_c) <=sum_c tr(M_c)=d`,

there are fewer than `200d/199` classes globally. Hence the number is at most `floor(200d/199)` (the strict integer boundary can improve this loose bound). Minimum-error class representatives exist.

The representative classifier transfers to all good states with error less than `1/4`, so the compact set `K` of POVMs with all those global constraints is nonempty. For any finite prior on good states, optimize its average class error over `K`. Majority stays feasible on every good state. The same constrained-optimality calculation as in Section A gives `R<=(224+128sqrt(3))E`. Minimax and compact finite-intersection *within this fixed POVM set* give one globally feasible measurement with

`r(rho)<=(224+128sqrt(3)) e_B(rho)`

on every good state. Prepare its global class representative. The correct-class mixed fidelity loss is at most `50e_B(rho)`; the wrong-class contribution is at most `r(rho)`. Outside the good set the trivial loss bound one is at most `2800 e_B(rho)`.

This proves one EB surrogate for all density matrices, using at most `floor(200d/199)` mixed prepared states. An empty good set is trivial. This argument asserts existence, not efficient acquisition or implementation from an unknown black-box `B`.

## G. Independently checked measurement rounding with one ancilla qubit

Root proposed a further implementation consequence. After obtaining any globally weak good-state classifier, minimize its worst-case good-state risk over the compact POVM set. Majority and the same forbidden interval lower that worst risk to `a=1/200`. Optimizing average risk under the tighter global cap and repeating majority yields

`R<=C_dec E`, `C_dec=8/(1-sqrt(3/200))^2<11`.

Fix this class POVM `M_c`. Threshold each effect spectrally:

`P_c=1_[1/2,1](M_c)`.

Then `P_c<=2M_c`, `I-P_c<=2(I-M_c)`, and `sum_c P_c<=2I`. Therefore `N0=sum_c rank(P_c)<=2d`.

Stack the projections into `T:H -> directsum_c ran(P_c)`. Pad the output with zero rows to `N=max(d,N0)<=2d`. Its polar decomposition has an isometric completion `U:H->C^N` satisfying `T=U sqrt(S)`, `S=T*T=sum_c P_c`.

For a class-`c` state with original error `r=1-tr(M_c rho)`, let `A=sum_(j!=c)P_j` and `Q=I-P_c`. Then `tr(rho A)<=2r`, `tr(rho Q)<=2r`, `0<=A<=2I`, and

`(S-I)^2=(A-Q)^2<=2A^2+2Q<=4A+2Q`.

Hence `tr[rho(S-I)^2]<=12r`. Since `(I-sqrt(S))^2<=(I-S)^2` by scalar functional calculus,

`||(U-T)sqrt(rho)||_HS^2<=12r`.

The wrong-block component of `T sqrt(rho)` has squared norm at most `2r`. By the Hilbert–Schmidt triangle inequality the isometry's wrong-block probability is at most

`(sqrt(2)+sqrt(12))^2 r=(14+4sqrt(6))r<24r`.

Refining its output blocks to coordinates gives a rank-one POVM with at most `2d` outcomes. Embedding `U` in `H tensor C^2` realizes this measurement using one initially pure ancilla qubit and an orthogonal measurement on the enlarged system. Dummy coordinates may be assigned any prepared representative; this only reduces the bound that counted them wrong.

The rounded measurement has class error at most `24 C_dec e<264e`; together with correct-class preparation loss at most `50e`, it gives good-state EB loss below `314e`. Bad inputs still obey the universal `2800e` bound. The same compact/minimax construction can choose one such rounded measurement for all inputs using the global constrained POVM argument above.

**Scope:** the ancilla-qubit statement concerns implementing the input POVM. Preparing an arbitrary mixed class representative may use separate randomness or an environment. It is not a claim that the entire EB channel has a Stinespring dilation with one pure ancilla qubit. No computationally efficient extraction from an unknown channel is asserted.

## Outcome and status

The strongest internally derived result is an explicit normal form for exact arithmetic-circuit comparison inside an exceptionally regular optimization problem. An arbitrary integer straight-line circuit can be compiled in polynomial bit time to an **explicit sparse rational quartic polynomial** on a unit cube. Its Hessian lies between `(1/2)I` and `(3/2)I` everywhere on that cube, and its unique rational minimizer lies uniformly inside the smaller cube `[1/4,3/4]^N`. A designated optimizer coordinate exceeds `1/2` exactly when the circuit's integer output is positive.

Thus exact optimizer-coordinate comparison remains PosSLP-hard after eliminating nonconvexity, multiple minimizers, singular Jacobians, bad Hessian condition number, unbounded feasible regions, boundary optima, implicit polynomial coefficients, and representation acquisition. The obstruction is an exact semantic predicate, not optimization to a requested additive accuracy.

An explicit family in the same class has a reduced rational optimizer coordinate requiring exponentially many output bits. Circuit-form output remains short, but deciding its sign relative to the threshold still contains PosSLP.

This is a **candidate internally proved sharpening**, not an externally reviewed theorem or a demonstrated novel result. Existing work already reduces arithmetic-circuit comparison to exact SDP and to probabilistic polynomial systems. The specific sparse quartic, uniformly interior, constant-condition form was derived here, but historical priority is **UNKNOWN**. No PosSLP algorithm, complexity separation, deterministic general PIT algorithm, or foundational capability breakthrough was obtained. The original high-ambition objective is **NOT ACHIEVED** by this worker.

## Independent opening and three different routes

The opening question was formulated before reading Astra candidate conclusions: what operation can turn globally constrained structure into a usable representation without placing the hard search in an oracle or preprocessing stage? Three routes were pursued.

1. **Acquire a small representation from query information.** Try adaptive basis discovery or prefix refinement. An exact combination-lock family gives an unconditional exponential query lower bound despite an `O(n)`-state representation. A prefix-nonemptiness oracle repairs the algorithm but changes the information interface and hides the original search.
2. **Avoid branching and large numbers through a bounded algebraic lift.** Carry signed values as positive homogeneous triples. This succeeds as a fully explicit construction with constant-degree constraints and no hidden basis. It reveals that boundedness and numerical regularity do not imply cheap exact semantic extraction. This became the strongest theorem below.
3. **Retain a faithful algebraic encoding and a finite jet.** Inspired and challenged later by the OpenAI Math word-series mechanism, ask whether circuit sharing can be preserved while replacing formula-size jet bounds by circuit-size bounds. Repeated squaring defeats any polynomial truncation at the original regular base point. Sparse valuation jumps repair the simple example, but arbitrary cancellation reintroduces general identity/sign predicates. No general jump operation was found.

These routes concern information, exact numeric semantics, and algebraic representation respectively. They are not three names for the same iterative method.

## Route 1: exact query lower bound and the false repair

For each hidden word `h in {0,1}^n`, define a deterministic controlled system with states `0,1,...,n,dead`. From state `i<n`, input `b` leads to `i+1` if `b=h_{i+1}` and otherwise to `dead`; `dead` is absorbing. The observable returns one only after exactly the complete word `h`, and returns zero on all other complete-word experiments. A reset to state zero starts each experiment. This is a supplied interface of membership queries

`O_h(w) = 1{w=h}`.

The transition representation has `n+2` states and can be written in `O(n)` entries once `h` is known. Every unsuccessful length-`n` query excludes only one candidate hidden word. Consequently a deterministic algorithm can be forced to make `2^n-1` unsuccessful queries before identifying the secret. Under a uniform secret, any algorithm making at most `Q` queries and then possibly guessing has success probability at most `(Q+1)/2^n`; adaptivity does not improve this bound because all previous failures are identical. Hence success probability at least `2/3` for every secret requires `Q >= (2/3)2^n-1` in the worst-case query-budget model.

Mutation: add `V_h(u)=1{u is a prefix of h}`. Now one can recover each next bit by querying the current prefix followed by zero, using at most `n` queries. But computing `V_h(u)` from the original oracle requires an OR over the `2^(n-|u|)` completions, and its worst case needs all of them. The repaired operation is exactly the missing search; it cannot be treated as a free representation primitive.

This is an elementary and familiar query obstruction, not a novelty claim. Its function here is to prevent a small latent representation from being mistaken for an acquisition theorem. It is separate from the next construction, whose entire representation is explicit in polynomial time.

## Route 2: a bounded quadratic lift

Let `C` be a division-free straight-line circuit over integers, with inputs `0,1` and binary operations `+,-,times`. Number its `s>=1` gates topologically, and let `v_i` denote the integer computed at gate `i`. Set

`gamma = 1/(128s)`.

Associate three coordinates `(p_i,q_i,lambda_i)` with every gate, maintaining

`v_i = (p_i-q_i)/lambda_i`, with `lambda_i>0`.

The input triples are

`0 -> (1/8,1/8,1/8)`,

`1 -> (1/4,1/8,1/8)`.

For gate `i` with parents `a,b`, define the following right-hand sides.

Addition:

`p_i = gamma(p_a lambda_b + p_b lambda_a)`,

`q_i = gamma(q_a lambda_b + q_b lambda_a)`,

`lambda_i = gamma lambda_a lambda_b`.

Subtraction:

`p_i = gamma(p_a lambda_b + q_b lambda_a)`,

`q_i = gamma(q_a lambda_b + p_b lambda_a)`,

`lambda_i = gamma lambda_a lambda_b`.

Multiplication:

`p_i = gamma(p_a p_b + q_a q_b)`,

`q_i = gamma(p_a q_b + q_a p_b)`,

`lambda_i = gamma lambda_a lambda_b`.

Each identity follows by subtracting the first two equations and dividing by the third. The equations are triangular, so they define a unique rational vector. Every coordinate is strictly positive, and all triple coordinates are at most `1/4`: the input values have that property, and the gate right-hand sides preserve it. Thus this lift acquires its own bounded representation without querying a hidden model or searching for a basis.

Add one final coordinate

`z = 1/2 + gamma(p_out-q_out)`.

Let `N=3s+1`, and let `T:[0,1]^N -> [0,1]^N` consist of all the right-hand sides. The last row is affine and has one negative coefficient; every gate row has nonnegative coefficients. We have

`z*>1/2 iff C>0`, `z*=1/2 iff C=0`, and `z*<1/2 iff C<0`.

### Uniform contraction, with all derivative costs visible

Every quadratic row has at most two monomials of coefficient `gamma`. On the unit cube its gradient has l1 norm at most `4 gamma`; this also covers repeated operands. The final affine row has gradient l1 norm `2 gamma`. Therefore

`||DT||_infinity <= 4 gamma = 1/(32s)`.

Since `N<=4s`, the crude column bound is

`||DT||_1 <= N(4 gamma) <= 1/8`.

Consequently

`||DT||_2 <= sqrt(||DT||_1 ||DT||_infinity) <= 1/(16 sqrt(s)) <= 1/16`.

Thus `T` is a global Euclidean contraction with a fixed constant factor, as well as a global maximum-norm contraction. Banach's theorem supplies uniqueness independently of triangularity. Moreover the residual map `F(x)=x-T(x)` is globally bi-Lipschitz on the cube, and `I-DT` has inverse norm at most `16/15` in Euclidean norm. No singularity or poor local inverse condition explains the sign difficulty.

### Sparse quartic objective and Hessian bound

Define

`E(x) = (1/2) sum_{i=1}^N (x_i-T_i(x))^2`.

Each summand expands to a constant number of monomials of degree at most four. The entire **explicit coefficient list**, not just an evaluation circuit, has `O(s)` monomials. Coefficient numerators and denominators have `O(log s)` bits. The polynomial and its list are obtained in polynomial bit time directly from `C`.

Its Hessian is

`H_E = (I-DT)^T(I-DT) - sum_i F_i D^2 T_i`.

On the cube, `|F_i|<=1`. Each quadratic `T_i` has a symmetric Hessian whose maximum row sum is at most `4 gamma`; affine and constant rows contribute zero. Hence

`||sum_i F_i D^2 T_i||_2 <= ||sum_i F_i D^2 T_i||_infinity <= N(4 gamma) <= 1/8`.

Using `||DT||_2<=1/16` gives the uniform bounds

`(193/256)I <= H_E <= (321/256)I`.

In particular `(1/2)I <= H_E <= (3/2)I`. The fixed point has objective zero and is therefore the unique minimizer. Its rationality comes from the triangular equations, not from a generic convex-optimization claim.

### Uniform interior location without losing curvature regularity

The original coordinates can approach zero. To remove even that possible explanation, set

`y = c 1 + alpha x`, where `c=1/4`, `alpha=1/2`,

and define on the **full unit cube**

`S(y) = c 1 + alpha T((y-c 1)/alpha)`,

`G(y) = (1/2)||y-S(y)||_2^2`.

Here the argument of `T` lies in `[-1/2,3/2]^N`. A quadratic gate row of `S` has the form

`1/4 + 2 gamma[(y_a-1/4)(y_b-1/4) + (y_d-1/4)(y_e-1/4)]`,

with one term rather than two for a scale row. The input rows are constants between `5/16` and `3/8`. The last row simplifies to

`S_z(y)=1/2 + gamma(y_p-y_q)`.

These formulas show that `S` maps the unit cube into itself, in fact into `[1/8,7/8]^N`. Its fixed point is exactly `y*=c 1+alpha x*`; hence **every coordinate of the optimizer belongs to `(1/4,3/4)`**, with no hidden small boundary margin.

On the full unit cube,

`||DS||_infinity <= 6 gamma = 3/(64s)`,

`||DS||_1 <= 3/16`,

`||DS||_2 <= 3/(32 sqrt(s)) <= 3/32`.

The factor six in the first line comes from evaluating the old derivatives where each old coordinate has absolute value at most `3/2`. Each Hessian `D^2S_i` has maximum row sum at most `8 gamma`, and `|y_i-S_i(y)|<=1`, so the residual-weighted Hessian term has Euclidean norm at most `1/4`. Therefore

`(585/1024)I <= H_G(y) <= (1481/1024)I`

throughout the unit cube, which implies the stated `(1/2)I` and `(3/2)I` bounds. The coefficients remain explicitly sparse and have `O(log s)` bits after expansion. Finally,

`y_z*>1/2 iff C>0`.

**Theorem, internal status.** Exact designated-coordinate threshold comparison for explicit sparse rational quartic objectives on a unit cube is PosSLP-hard even under the promises that the Hessian is everywhere between `(1/2)I` and `(3/2)I`, the unique minimizer is rational, and it belongs to `[1/4,3/4]^N`. This is a polynomial many-one reduction into a promise problem. It does not assert membership of that entire optimization problem in PosSLP.

For the syntactically supplied triangular-map family, reverse reduction to PosSLP is immediate: evaluate the coordinates as rational arithmetic circuits using numerator-denominator pairs and compare their final numerator difference. Thus the construction with its triangular witness is an exact normal form for the arithmetic predicate.

### Arbitrarily small curvature perturbations do not repair exact semantics

For a rational `0<eta<=1`, use `gamma=eta/(128s)` instead. The central construction satisfies

`||H_G-I||_2 <= 7 eta/16 + 9 eta^2/1024 < eta/2`.

All previous sign identities remain exact. The compiler is polynomial in the circuit size and bit length of `eta`. Thus the exact predicate survives even for objectives arbitrarily close in Hessian norm to the identity quadratic. This is not a hardness statement for approximation; it locates the discontinuous semantic boundary.

## Exponential exact-output size, with a complete closed form

Take the circuit starting with integer one and squaring its previous value `n` times. Its value is still one, and it has `s=n+1` gates. At the base, `lambda_0=1/8`, and

`lambda_{j+1}=gamma lambda_j^2`.

Therefore

`gamma lambda_n = (gamma/8)^(2^n) = (1024s)^(-2^n)`.

Since `p_n-q_n=lambda_n`, the original threshold coordinate is

`z*=1/2+(1024s)^(-2^n)`.

For the uniformly interior construction,

`y_z*=1/2+(1/2)(1024s)^(-2^n)`.

Write `D=(1024s)^(2^n)`. Then `y_z*=(D+1)/(2D)` is reduced: `D` is even, so `D+1` is odd, and it is coprime to `D`. Its denominator requires `Theta(2^n log s)` bits. The explicit quartic input has polynomial length. Hence an algorithm required to print this exact rational coordinate in ordinary binary cannot have polynomial worst-case total running time, **unconditionally**, merely because it must print the answer.

This easy family does not make PosSLP hard on the family itself: its answer is plainly positive. It establishes output-size and numerical-margin claims, not a universal complexity lower bound for algorithms that inspect the circuit syntax.

The representation choices have exact consequences:

| Output contract | What is established |
|---|---|
| Expanded exact rational optimizer | Exponential output length can be unavoidable. |
| Compact rational arithmetic-circuit optimizer | Constructible with `O(s)` nodes here; exact comparison remains PosSLP-hard. |
| Additive `2^-b` optimizer approximation | Polynomial bit time in `s,b` is available; no sign claim without a margin or symbolic decision method. |
| Exact sign with arbitrary small/zero threshold gap | Contains PosSLP; no polynomial algorithm obtained. |

Triangularity means exact symbolic substitution, or unrounded iteration after sufficient topological depth, reaches the fixed point in `O(s)` stages. It would be incorrect to claim that this family forces exponentially many exact arithmetic iterations. The debt is expanded bit length and/or semantic comparison.

## Mutation tests against proposed escapes

### Normalize the common scale

Dividing `(p-q)` by `lambda` returns the original integer circuit. That avoids the artificial absolute scale but exactly reinstates PosSLP. It is a valid representation conversion, not a solution of the exact predicate.

Even direct positive quantities can have a doubly exponentially small relative gap. Let

`A_0=2`, `B_0=1`, `A_{j+1}=A_j^2`, `B_{j+1}=B_j(B_j+2)`.

Induction gives `A_j=2^(2^j)` and `B_j=A_j-1`. Both are computed by monotone `+,times` circuits of size `O(j)`, while `(A_j-B_j)/A_j=2^(-2^j)`. The example is algebraically easy once recognized; it proves that positivity and common-scale removal do not supply a polynomial relative-gap bound.

### Count subtraction gates or cancellation layers

This cannot be a reliable invariant. Every signed arithmetic circuit is representable as the difference of two positive circuits with only a final subtraction, using the standard positive-pair identities. Thus bounded explicit subtraction depth can conceal arbitrary arithmetic-circuit comparison. The positive homogeneous lift above retains that issue while bounding every coordinate.

### Use modular fingerprints as an ordering primitive

Residues can certify inequality of integers in appropriate randomized identity tests, but a residue does not determine real order. For any selected modulus product `M`, `1` and `1-M` have identical residues and opposite signs. Reconstructing a signed integer from enough residues requires an a priori magnitude bound and enough total modulus bits; the circuit magnitude bound can itself have exponential bit length. This rules out the proposed finite-residue-only escape, not every possible modular sign algorithm.

### Use convergence, residual size, or a bounded Hessian

These control distance to the optimizer and approximation cost. They do not bound `|y_z*-1/2|`. An error interval around `y_z*` must exclude `1/2` before that particular interval method certifies a sign. On the closed-form family this needs exponentially many precision bits. A syntax-sensitive method may perform better; finding such a general method is exactly the unresolved arithmetic-predicate problem.

## Route 3: finite jets and the shared-circuit obstruction

The source OpenAI Math characteristic-zero construction encodes a word `w=i_1...i_k` by iterated integrals, starting from `h_empty=1` and applying `h_{iw}'=h_w/(z+i)`. It realizes a formula as `uGv` in a linear differential system of dimension at most twice the formula-tree size. A Wronskian/minor argument bounds the order of a nonzero component by `(n-1) binom(m,2)+m-1`, permitting a polynomial jet truncation.

The decisive representation proof explicitly uses **disjoint child graphs** in multiplication and addition. The bound counts the formula tree; it is not a bound for shared circuits.

For the one-variable repeated-squaring circuit `f_j(x)=x^(2^j)`, circuit size is `O(j)`. Under the same faithful word encoding,

`h_{f_j}(z) = log(1+z)^(2^j)/(2^j)!`,

which has order exactly `2^j` at zero. Any polynomial-length initial Taylor truncation in circuit size loses it. This is no counterexample to the source formula theorem: the expanded formula tree has exponential size. It is a counterexample to the attempted circuit-size transfer of that particular truncation mechanism.

Mutation: keep a binary-encoded order and jump to it. For a single repeated word this works. For sums, leading terms can cancel; the required next exponent and nonzero coefficient are not provided by the tropical minimum rule. A universal exact operation returning a nonzero leading coefficient or ZERO for a general circuit would supply general identity testing, and on constant circuits its sign version includes PosSLP. No exact, resource-accounted general cancellation jump was constructed.

Therefore the source supplies a credible operation in its stated formula/path-program regime. It does not close the independent hard interface. No claim of an impossibility of all circuit hitting sets is made; only the attempted regular-base finite-jet extension is rejected.

## Resource accounting and remaining major operation

The reduction uses `N=3s+1` coordinates, `O(s)` gate equations, `O(s)` explicit sparse quartic monomials, and rational coefficients with `O(log s)` bits. It requires no samples, hidden structure, oracle evaluations, basis acquisition, calibration, or physical state preparation. Ordinary compilation and finite checks use local exact rational arithmetic only.

Approximating the optimizer to `b` bits can be done in polynomial bit time in `s,b`, either by rounded contraction iteration or by standard algorithms for the uniformly strongly convex objective. Exact rational output may require exponentially many bits. A compact arithmetic circuit for it has polynomial size. Exact decoding from that circuit is the remaining PosSLP predicate.

The missing operation is therefore precise: **a polynomial-bit-time exact sign extractor for succinct arithmetic circuits, or a genuinely smaller admitted class with a proved semantic margin/cancellation certificate and a major consequence that survives that restriction**. Simply assuming the extractor, a nonzero gap, a prefix-existence oracle, or an exact fixed-point query would hide the hard operation.

No candidate extractor satisfying that contract was obtained. The normal form gives a sharp target and a falsifier for proposed contraction/convexity solutions; it does not solve the target.

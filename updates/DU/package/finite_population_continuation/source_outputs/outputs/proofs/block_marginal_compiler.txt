# Exact overlapping-block repair and finite-population reachability

11 October 2026. Complete internal argument, pending independent reconstruction of this extension. The one-coordinate theorem is preserved in `../consequence_semigroup/FINITE_POPULATION_THEOREM.md`; its exact finite-seed/DAG compiler is in `../consequence_semigroup/FINITE_SEED_AND_COMPRESSED_SAMPLER.md`. This note extends the mathematical and executable interfaces to prescribed overlapping blocks of a fixed length. No historical originality claim is made.

## 1. The gluing operation

Let a finite family of variable sets admit a junction tree: for each variable, the sets containing it form a connected subtree. Let the prescribed clique probability tables `mu_C` agree on adjacent separators. Let an actual empirical joint law `P'` have clique tables `mu'_C`. Assume zero cells of `mu_C` also have zero empirical mass and, on positive cells,

    mu'_C(z) <= mu_C(z)+delta.

Put `alpha=min{mu_C(z):mu_C(z)>0}` and, for delta>0,

    beta=delta/(alpha+delta),
    q_C=[mu_C-(1-beta)mu'_C]/beta.

These tables are nonnegative and normalized, and their separator marginals agree. Root the junction tree, sample its root table, and attach each child using its conditional table given the separator. A zero-probability separator can be assigned any conditional law because it is never visited. This constructs one global law Q with all tables q_C. Thus `(1-beta)P'+beta Q` has all prescribed clique tables exactly, and changes the full word law by TV at most beta. For delta=0 use P' directly.

**Integer strengthening.** If every q_C has a common integer denominator F, one can take Q uniform on exactly F assignments, counted with multiplicity. List F root-clique assignments with their required counts. At each child, list F child assignments and match them bijectively to the already assigned slots within each separator value. Separator count equality makes every matching possible. Continue through the tree. Running intersection guarantees that new assignments never conflict with an earlier variable assignment. This needs no independent Markov coins or denominator multiplication with the number of cliques.

The mixture is one global repair, regardless of the number of constraints. An arbitrary additional global support/acceptance restriction need not survive it. Clique support zeros do survive it.

## 2. Exact fixed-block interface

Let A be a finite alphabet, Q a set of d DFA states, q0 its deterministic initial state, and `f:Q x A -> Q` a total transition table. Fix k>=2 and put ell=k-1. Supply a rational law kappa on A^k whose prefix and suffix marginals agree:

    pi(w)=sum_a kappa(w a)=sum_a kappa(a w),  w in A^ell.

Let H0=supp(pi), h=|H0|, M=d h, and alpha the smallest positive atom of kappa. Every positive pi atom is at least alpha. For n>=k, let R_n consist of terminal DFA laws over arbitrary joint laws of X1,...,Xn satisfying

    Law(X_t,...,X_(t+k-1))=kappa,  1<=t<=n-k+1.

This prescribes overlapping unconditional block laws. It does not prescribe a conditional Markov kernel, independence from the DFA state, or blind control. The first block fixes the initial ell-prefix law pi. Nonemptiness follows by the stationary order-ell Markov construction, but admissible laws may have arbitrary additional dependence.

The augmented DFA state after reading the initial prefix is `(q,w)` in `Q x H0`, with `q=f*(q0,w)`. Reading a new letter a sends it to

    (f(q,a), shift(w,a)).

A positive kappa(w a) ensures shift(w,a) belongs to H0.

## 3. Population graph, including its initial set

Fix an integer D>=1. Vertices are integer histograms x on Q x H0 of total D. There are at most

    N=binom(D+M-1,M-1)

vertices. Initial vertices have counts K_w satisfying

    sum_w K_w=D,  K_w=0 if pi(w)=0,
    |K_w-D pi(w)|<=1,
    x_(q,w)=K_w if q=f*(q0,w), and zero otherwise.

An edge x->y carries a nonnegative integer array k_(q,w,a) with rows x and augmented successors y, subject to

    k_(q,w,a)=0 if kappa(w a)=0,
    |sum_q k_(q,w,a)-D kappa(w a)|<=d   for every (w,a).

There are d terms for each block budget; the discrepancy is d, not M. Write `g(x)(q)=sum_w x_(q,w)/D`. For tail length m=n-ell>=1, G_(D,n) is the set of g(x) at vertices reachable in exactly m edges from this initial set.

All conditions are rationally decidable from the supplied tables. One may discard any vertex whose residual history counts in section 5 are negative: no valid edge or initial vertex used below has this defect.

## 4. Whole-path rounding, preserving the original terminal dimension

Given an admissible length-n law, let its real layered augmented-state/letter flow be D times its path probabilities. Add **separate source-to-initial-history edges** of value D pi(w), entering `(f*(q0,w),w)`. At the terminal layer, send every `(q,w)` node to an original-q collector, then send that collector to the sink with flow D p(q). All node balances are integer: source D, sink -D, otherwise zero.

Apply the floor/ceiling integral-flow rounding lemma proved in the source theorem. Every initial-history edge changes by less than one, so the initial histogram satisfies exactly the preceding initial conditions. Each block budget has d rounded edges, so its discrepancy is at most d; zero-flow edges stay zero. Decompose the resulting acyclic integer flow into D complete paths, including their initial prefixes.

The collector-to-sink edge for each original q changes by less than one. Consequently the original terminal law, rather than its larger augmented-state law, obeys

    sup_(p in R_n) dist_TV(p,G_(D,n)) <= r_D=d/(2D).       (B1)

No error factor depends on n. Omitting the source/history edges or rounding only a guessed initial histogram would leave a gap.

## 5. Rational residual counts and exact finite gluing

Choose one common denominator Qden with

    kappa(w a)=u_(wa)/Qden,  pi(w)=v_w/Qden,
    v_w=sum_a u_(wa)=sum_a u_(aw).

Let umin be the smallest positive u, and define

    H=D umin+d Qden,
    F=d Qden^2,
    beta=d Qden/H,
    1-beta=D umin/H.

For an edge e=(x,k,y), its empirical block counts and residual counts are

    K_e(w,a)=sum_q k_(q,w,a),
    C_e(w,a)=H u_(wa)-Qden umin K_e(w,a),
    R_x(w)=H v_w-Qden umin sum_q x_(q,w).

All C_e are nonnegative integers. If u_(wa)=0, K_e=0 and C_e=0. Otherwise the block budget gives

    C_e(w,a) >= d Qden (u_(wa)-umin) >=0.

They satisfy the exact integer conservation identities

    sum_a C_e(w,a)=R_x(w),
    sum_(w,a):shift(w,a)=z C_e(w,a)=R_y(z),
    sum_(w,a) C_e(w,a)=sum_w R_x(w)=F.                  (B2)

At an initial vertex, `sum_q x_(q,w)=K_w` and `K_w<=D v_w/Qden+1`, so

    R_x(w)>=Qden(d v_w-umin)>=0

on positive histories; zero histories have zero count. Thus initial residual prefixes are also legitimate integer counts. At any endpoint of an edge nonnegativity follows from (B2).

The table C_e/F is precisely

    [kappa-(1-beta) kappa'_e]/beta,

and R_x/F is its residual history marginal. Their shared denominator F is independent of the horizon.

**Canonical slot realization.** At each relevant vertex x, partition the ordered slots {1,...,F} into canonical consecutive history blocks B_x(w) of sizes R_x(w). For an edge e, partition B_x(w) further into letter classes of sizes C_e(w,a), in a fixed ordering. Assign letter a_e(i)=a to such a slot. Its destination history is shift(w,a). Match, in order, all source slots having each destination history z bijectively to the canonical target block B_y(z). This defines a permutation pi_e of the F slots, satisfying

    i in B_x(w) => pi_e(i) in B_y(shift(w,a_e(i))).        (B3)

For any graph path, start with a uniform slot i and the ell-letter prefix w identifying B_(x0)(w), then follow these permutations and emit their letters. The slot stays uniform at each time. Equation (B3) tracks its actual recent history, so each k-block law is exactly C_e/F. This constructs F deterministic filler words, counted with multiplicity. It is generally a dependent, non-Markov law; no independent block choices are made.

The normal D paths have empirical block counts K_e. Form a uniform population of

    R=Qden H

words: include each normal word with multiplicity Qden umin, and each of the F filler words once. Its count of block (w,a) at edge e is

    Qden umin K_e(w,a)+C_e(w,a)=H u_(wa).

Division by R gives exactly kappa(w a). The same identity with prefixes gives pi. All prescribed zero blocks are absent in every word. If g is the normal terminal law, the exact repaired terminal law p' satisfies

    TV(p',g)<=beta=d/(D alpha+d).                       (B4)

This proof establishes exact local finite-type support, not an arbitrary regular acceptance constraint on the entire word.

## 6. Uniform optimization and finite horizon cutoff

Equations (B1) and (B4) hold at the **same n**, for every n>=k. Since R_n is convex,

    d_H(R_n,conv G_(D,n))<=max{r_D,beta}.                 (B5)

Any endpoint positively reachable from the initial set has a positive path of length at most N: remove loops in a shortest positive path, retaining at most one simple cycle if its start equals its end. Therefore, for R=union_(n>=k) R_n,

    d_H(closure R, union_(k<=n<=ell+N) R_n)
       <=r_D+beta.                                      (B6)

The bounded union is compact because each R_n is a finite-dimensional marginal polytope image. Taking `D=ceil(2d/(alpha epsilon))` makes (B6) at most epsilon. Uniform terminal-distance/payoff approximation, promised terminal-gap decisions, and the uniform-gap eventual-periodicity argument therefore extend to this block interface, with initial subset I_D and tail length n-ell. This does not decide exact cutpoints or verify a supplied gap promise.

For a rational target nu and any fixed n, compute the minimum distance v_(D,n) to G_(D,n). Then

    max{0,v_(D,n)-r_D}<=dist_TV(nu,R_n)<=v_(D,n)+beta.

For the union over all horizons use ordinary positive reachability. For binary-encoded n use Boolean adjacency powering. Direct graph enumeration considers at most `(D+1)^(d h |A|)` edge arrays; all dimension, denominator, and positivity dependence is charged.

## 7. Exact compressed terminal evaluation and sampling

The integer gluing avoids a genuine limitation of choosing an independent-coin Markov filler: that alternative can have terminal rational bit length growing linearly in n. No claim for that particular Markov construction is needed.

Suppose a graph path is supplied as a concatenation DAG of W nodes, with leaf nodes holding concrete edge arrays. Store for each filler leaf the total deterministic map on `{1,...,F} x Q`

    T_e(i,s)=(pi_e(i), f(s,a_e(i))).

For a concatenation node, compose its two maps in temporal order. Every table has Fd entries. The complete path map is obtained by O(FdW) table operations, plus leaf construction. Initialize slot i with DFA state `f*(q0,w(i))`, where w(i) is its initial residual prefix. Apply the root map to all F starting slots and count terminal states. This evaluates the filler law exactly with denominator F. Combine it with normal endpoint g using beta; the entire repaired law has the horizon-independent uniform denominator Qden H. Multiplicities may merge, so this denominator need not be minimal.

A matching construction on the D normal slots uses canonical augmented-state blocks, partitions them according to k_(q,w,a), and matches destination slots. It supplies the normal word sampler. To sample the full repaired word, select one uniform slot among Qden H slots: normal slots occur Qden umin times each; filler slots occur once. Expected fair-bit acquisition is O(log(Qden H)) by ordinary rejection sampling. Retain this one slot for all subsequent queries.

For a query inside the initial prefix, read its history word. For later coordinates, descend the witness DAG and skip whole earlier subpaths using their stored slot maps. A query costs O(DAG depth) table lookups; multiple adaptive queries remain consistent with one exact sampled full word. Their answers are not independent. Full word output costs Omega(n).

For a binary tail length m, Boolean powers store witness productions

    P(j,x,y)=P(j-1,x,z) P(j-1,z,y)

for a selected midpoint z of each true length-2^j adjacency entry. There are at most O(N^2 log(m+1)) distinct productions; concatenating the selected binary-length pieces yields depth O(log(m+1)). A reachable endpoint and an initial vertex can be selected using the same powers. Thus an explicit graph plus binary n compiles an exact repaired terminal law and consistent random-access sampler using polynomial resources in N, D, F, table encodings and log(n+1). The factor F=d Qden^2 can be exponential in the bit length of Qden and is not hidden. This is an exact executable result, not a polynomial-in-input-bits claim.

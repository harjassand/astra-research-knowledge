CYCLIC WORD COUPLINGS WITH A BINARY HORIZON
Status: internally derived exact theorem and proof. Novelty UNKNOWN; no foundational breakthrough claimed. A generalization of the product-tree operation reported in Astra N674, not a new claim about that source.

Input: an explicitly listed finite directed multigraph with N vertices and E labeled edges, a finite alphabet A, a rational probability vector mu on A, and an integer n>=1 encoded in binary. A word is legal if it labels a closed directed walk of length n. The task is to decide whether a probability law on legal length-n words has marginal mu at every coordinate, and, if feasible, to construct a succinct exact sampler. Graph acquisition and its full explicit size are charged.

Theorem. Feasibility is equivalent to a rational LP with O(N^3 log(n+1)+E) nonnegative variables and O(N^2 log(n+1)+|A|) equations. Consequently it is decidable with rational linear programming in time polynomial in the explicit input bit length, including log(n+1). A rational feasible solution describes a consistent exact lazy sampler: after polynomial preprocessing, k requested coordinates can be generated in expected bit complexity polynomial in the input length and k, without materializing all n coordinates. Writing a complete word costs at least n symbol writes. Adaptive queries see one fixed sampled word, not fresh inconsistent samples.

1. Shared balanced-tree types
Recursively split each integer t>1 into a(t)=floor(t/2), b(t)=ceil(t/2). The set D of sizes that occur has at most two sizes at each depth and hence O(log(n+1)) members. Different occurrences of the same size share LP parameters, not one physical random subtree.

For each t in D and vertices i,j, let y[t,i,j]>=0 be the expected number of tree nodes of size t whose left endpoint is i and right endpoint is j. For each t>1 and i,h,j let x[t,i,h,j]>=0 be the expected number of such nodes whose midpoint is h. Require sum_h x[t,i,h,j]=y[t,i,j].

At the root impose sum_i y[n,i,i]=1 and y[n,i,j]=0 for i!=j. When n=1 these root constraints apply directly to the leaf variables.

For every non-root size s and endpoints i,j, require
 y[s,i,j] = sum_{t:a(t)=s} sum_h x[t,i,j,h]
            +sum_{t:b(t)=s} sum_h x[t,h,i,j].
Both contributions count when a(t)=b(t)=s. This is essential: the two children are distinct occurrences even if their type and endpoints agree.

For every graph edge e=(i,label(e),j), let z[e]>=0. Set
 sum_{e:i->j} z[e]=y[1,i,j],
 sum_{e:label(e)=a} z[e]=n mu[a] for all a in A.
If n=1 there are no split variables. Missing edges contribute zero. Multiple edges with the same label are allowed.

2. Necessity
For any feasible word law, choose a legal closed-walk witness for each word (a deterministic choice suffices because the finite sample space is finite). Parse it by the fixed balanced tree. Expected node, split, and leaf-edge counts satisfy every equation. Equal coordinate marginals imply expected label counts n mu.

3. Sufficiency and the shared-type issue
Sample root i with probability y[n,i,i]. At each occurrence of type (t,i,j), sample h with probability x[t,i,h,j]/y[t,i,j], then recursively generate its two children. If y[t,i,j]=0 that type is never reached and arbitrary choices there are harmless. At a leaf choose edge e with probability z[e]/y[1,i,j].

Induction down the acyclic size hierarchy proves that the expected occurrence count of each type is exactly y[t,i,j]. Therefore the generated object is a closed walk and its expected number of occurrences of label a is n mu[a]. No equality of the individual leaf marginals has been assumed at this stage.

Finally sample J uniformly from {0,...,n-1} and rotate the walk word by J. A rotation of a closed walk is again a closed walk. Every coordinate is now a uniformly chosen original leaf, so each has law mu. The sampler need not sample unqueried branches; a subtree's endpoint pair is determined by its sampled ancestors. Cache sampled internal splits and leaf edges. A queried coordinate traverses O(log(n+1)) nodes. Store one J for all queries and cache repeated nodes, which guarantees joint consistency.

4. Resources
All LP coefficients are 0,1,2 except the rational RHS n mu. Their bit lengths are polynomial in the input bit length. Rational basic feasible solutions have polynomial bit length by determinant bounds. A categorical rational draw can be sampled exactly in finite expected bit cost polynomial in its rational bit length (rejection from fair bits); there is no bounded worst-case random-bit count claim. The cache after k queries contains O(k log(n+1)) node instances, each with binary path/address and vertex data. Querying all coordinates costs Omega(n), as required.

5. Noncommutative product corollaries
For an explicitly tabulated finite group G, use its right Cayley graph, with edges g --a--> ga. A closed length-n walk labels precisely words with product identity. Thus identical-marginal product-identity coupling is polynomial in |G|, rational input size, and log n, even when G is noncommutative. Rotating an identity product preserves identity; arbitrary permutation generally does not. For a central target z, append a fixed z^{-1} boundary edge only if rotation timing and marginal contract are handled; the closed-word theorem above asserts the identity case directly and does not silently claim arbitrary product outcomes.

More generally, for an explicitly tabulated semigroup S and q:S->C with q(ab)=q(ba) for all a,b, the balanced product grammar with root q-distribution nu and leaf counts n mu admits the same cyclic symmetrization argument. This is a polynomial-size extension of N674 to cyclic observables; q need not be a semigroup homomorphism. Exact arbitrary noncentral product law is not preserved by rotations.

6. Periodic marginal corollary
For n divisible by p, replace vertices by (i,r), r in Z/p, and edges advance r by one. Require the root to begin/end at phase 0; assign separate leaf-label totals (n/p)mu_r[a] for each phase r. Rotate by a uniform multiple of p. Each phase-class coordinate then has its specified marginal. This is polynomial in p,N,E and log n. The p marginal vectors and phase-expanded graph are explicit inputs; no succinct exponentially large graph claim follows.

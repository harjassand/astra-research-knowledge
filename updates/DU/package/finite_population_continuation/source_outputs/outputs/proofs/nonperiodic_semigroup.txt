# A fixed-target finite-semigroup coupling with nonperiodic feasible horizons

Status: newly derived, complete proof below; sections 1–5 independently reconstructed by the cross-corpus worker with no gap found. Their bounded exact diagnostics pass and remain separate from the proof; section 7 is a subsequent generalization. No novelty claim is made. This result sharply separates general finite semigroups from the commutative and completely simple cases proved in the accompanying notes.

## 1. The statement

There exist a finite semigroup `S`, distinct generators `a_0,a_1`, and an element `z` such that, for

\[
\mu=\tfrac12(\delta_{a_0}+\delta_{a_1}),\qquad \nu=\delta_z,
\]

the set

\[
\mathcal N=\{N\ge1:\exists(X_1,\ldots,X_N),\quad
X_i\sim\mu\ (\forall i),\quad X_1\cdots X_N=z\ \text{a.s.}\}
\]

is **not eventually periodic**. More precisely, put

\[
\lambda=\frac{-1+3i\sqrt3}{8}.
\]

The full feasible-horizon set is

\[
\mathcal N=\{70+60t:\ t\in\mathbb Z_{\ge0},\quad
\operatorname{Re}(\lambda^t)\ge0\}. \tag{1}
\]

The construction even has a zero `0` and

\[
zs=sz=0\qquad(s\in S),\quad z\ne0. \tag{2}
\]

Thus a transient, nilpotent target can retain an ordered spectral obstruction for arbitrarily large horizons. No finite list of eventual length phases can classify exact attainability in all finite semigroups, even with two equally likely input atoms and one fixed output atom.

Adjoining an identity of input mass zero gives the same counterexample among finite monoids. In that monoid, (2) applies to every nonidentity element.

## 2. Fair coordinate constraints can enforce a Markov evolution

Let `J` be any finite set of `d` states, let `f_0,f_1:J->J` be deterministic maps, let `j_*` be a start state, and let `F` be a subset of `J`.

A complete block has length `L=d+1`. Its first input is a branch bit `B`. Its remaining inputs, in a fixed enumeration `j_1,...,j_d` of `J`, must be

\[
C_k=B\mathbin\oplus {\bf1}_{\{J=j_k\}},\qquad k=1,\ldots,d. \tag{3}
\]

After the block, the stored state changes to `f_B(J)`. A finite deterministic automaton checks (3), storing the pre-block state and branch bit. Incorrect checker bits enter an absorbing rejection state. Its start is `j_*`.

For a word of length `rL+1`, require `r` valid complete blocks and a final branch bit `B_final` satisfying

\[
B_{\rm final}=0\quad\text{or}\quad J_r\in F. \tag{4}
\]

This describes one fixed regular language `L_0`: its accepting states are the states immediately after a branch bit satisfying (4); checker phases and rejection state do not accept. Earlier branch bits satisfying (4) cause no special transition; acceptance is evaluated only at the end.

Suppose a joint distribution is supported on `L_0` and every input coordinate is a fair bit. In a complete block, for each `j=j_k`,

\[
\begin{aligned}
\tfrac12=\Pr(C_k=0)
&=\Pr(B=0)-\Pr(J=j,B=0)+\Pr(J=j,B=1)\\
&=\tfrac12-\Pr(J=j,B=0)+\Pr(J=j,B=1).
\end{aligned}
\]

Hence

\[
\Pr(J=j,B=0)=\Pr(J=j,B=1)=\tfrac12\Pr(J=j). \tag{5}
\]

Thus the branch bit is independent of the current state, although independence was not assumed. Every coupling supported on the language must have

\[
\mathcal L(J_r)=\delta_{j_*}P^r,\qquad
P(j,k)=\tfrac12{\bf1}_{f_0(j)=k}+\tfrac12{\bf1}_{f_1(j)=k}. \tag{6}
\]

By (4), fairness of the final bit implies `Pr(J_r in F)>=1/2`.

Conversely, generate the complete blocks with independent fair branch bits and deterministic checkers (3). All checker coordinates are fair by conditional independence. If `p=Pr(J_r in F)>=1/2`, choose the final bit to be `1` with conditional probability `1/(2p)` when `J_r in F`, and `0` otherwise. It is fair and satisfies (4). Therefore

\[
\begin{gathered}
\exists\ \text{fair-coordinate law supported on }L_0\cap\{0,1\}^{rL+1}\\
\Longleftrightarrow\quad (\delta_{j_*}P^r)(F)\ge\tfrac12. \tag{7}
\end{gathered}
\]

This argument uses only one-coordinate constraints. Long-range dependence of the input law does not provide an escape from (5).

## 3. An explicit 14-state dyadic chain

Take the following 14 states:

\[
J=\{s,x_0,x_1,z_0,z_1\}
\cup\{c_i:i\in\mathbb Z_3\}
\cup\{m_{i,b}:i\in\mathbb Z_3,\ b\in\{0,1\}\}.
\]

The maps `f_b` are completely specified by

\[
\begin{array}{c|cc}
j&f_0(j)&f_1(j)\\\hline
s&x_0&x_1\\
x_0&z_0&c_0\\
x_1&c_0&c_0\\
z_0&z_1&z_1\\
z_1&z_0&z_0\\
c_i&m_{i,0}&m_{i,1}\\
m_{i,0}&c_i&c_{i+1}\\
m_{i,1}&c_{i+1}&c_{i+1}
\end{array} \tag{8}
\]

Indices are modulo three. Set `j_*=s` and `F={z_0,c_0}`. Here `d=14`, so the checker block length is `L=15`.

After the first two Markov steps, the state is `z_0` with probability `1/4` and `c_0` with probability `3/4`. Every subsequent pair of steps preserves the fixed component `z_0`, and on the three cycle states it stays put only for the two branch bits `00`; otherwise it advances by one. Its macro transition matrix is

\[
Q=\tfrac14 I+\tfrac34 C,
\]

where `C` is the forward cyclic permutation on three states. If `omega=exp(2 pi i/3)`, its two nontrivial eigenvalues are

\[
\lambda=\tfrac14+\tfrac34\omega=\frac{-1+3i\sqrt3}{8},\qquad \bar\lambda.
\]

Consequently

\[
Q^t(0,0)=\tfrac13+\tfrac23\operatorname{Re}(\lambda^t),
\]

and the exact acceptance probability after `r=2+2t` microsteps is

\[
(\delta_sP^{2+2t})(F)
=\tfrac14+\tfrac34 Q^t(0,0)
=\tfrac12+\tfrac12\operatorname{Re}(\lambda^t). \tag{9}
\]

By (7), fair-coordinate feasibility for `L_0` at length

\[
n=15(2+2t)+1=31+30t
\]

is equivalent to `Re(lambda^t)>=0`.

For complete specificity, the checker DFA has 14 ready states, `14*2*14=392` states of the form `(j,b,k)` after the branch and before checker `k`, and one rejection state: 407 states altogether. From a ready state `j`, input `b` goes to `(j,b,1)`. From `(j,b,k)`, the unique correct bit in (3) advances `k`, or goes to ready `f_b(j)` if `k=14`; the other bit rejects. Accept precisely `(j,b,1)` with `b=0` or `j in F`.

## 4. Convert the accepted set into one semigroup target

The previous regular language may have many accepting syntactic classes. The following balanced encoding makes all accepted words a single class while preserving fair-coordinate feasibility.

Let `h(0)=01`, `h(1)=10` be the Manchester encoding, and define the regular language

\[
L=(0001+1110)\ h(L_0)\ (1000+0111). \tag{10}
\]

Here `+` means union. Every word in `L_0` is nonempty. In each word of `L`, the only occurrences of `000` or `111` are the initial three bits and the final three bits. Manchester data contains no triple run. At the left boundary the guard bit and the first encoded bit can form a run of at most two, because the next encoded bit is opposite. The corresponding statement holds at the right boundary. The guards also separate each marker triple from the adjacent data.

It follows that `L` is an **infix code**: no word of `L` is a proper contiguous factor of another word of `L`. Indeed, the first and last marker triples of a contained word must coincide with the unique first and last marker triples of the containing word. Their starting and ending positions then agree.

For any two words `u,v in L` and any contexts `x,y`,

\[
xuy\in L\quad\Longleftrightarrow\quad x=y=\varepsilon
\quad\Longleftrightarrow\quad xvy\in L. \tag{11}
\]

Thus all accepted words are one syntactic congruence class `z`. No rejected word belongs to this class, by the empty contexts. Let `S` be the syntactic **semigroup** of `L`, i.e. the image of all nonempty binary words under this congruence, with multiplication induced by concatenation. It is finite because `L` is regular. Put `a_b=[b]`. Then

\[
w\in L\quad\Longleftrightarrow\quad a_{w_1}\cdots a_{w_N}=z. \tag{12}
\]

The two generators are distinct. Otherwise every word of a given length would have the same class, whereas `L` is nonempty and contains only some words of any length at which it is nonempty.

There is also an empty-residual syntactic class `0`: any word containing an accepted word as a proper factor has no accepting context. For `w in L` and any nonempty word `v`, both `wv` and `vw` have this property. This proves (2), including `z!=0`.

The semigroup is a fully finite, explicit construction: start with the 407-state DFA above; take the finite automaton for the fixed expression (10); determinize and minimize it; enumerate its two-generator transformation monoid. Its quotient/image gives `S`. No decision oracle or asymptotic input is used. A large multiplication table is unnecessary for the mathematical counterexample, but it can be generated by this finite algorithm if a table is the required representation.

Now let `N=2n+8`. Any fair-coordinate law supported on `L` at length `N` decodes to a fair-coordinate law supported on `L_0` at length `n`, by reading the first bit of each Manchester pair. Conversely, encode any fair-coordinate law on `L_0` and choose the two prefix/suffix marker variants independently and fairly. Each encoded coordinate and each marker coordinate is fair. Therefore

\[
\begin{gathered}
\exists\ \text{fair-coordinate law on }L\cap\{0,1\}^{2n+8}\\
\Longleftrightarrow\quad
\exists\ \text{fair-coordinate law on }L_0\cap\{0,1\}^{n}. \tag{13}
\end{gathered}
\]

Combining (7), (9), (12), and (13) proves the claimed feasibility criterion at lengths `70+60t`. It also gives the full identity (1). Indeed, `L_0` accepts only lengths `15r+1`. At `r=0` the state is `s`, outside `F`; at `r=1` it is `x_0` or `x_1`, outside `F`; at every larger odd `r` it lies in `{z_1} union {m_{i,b}}`, also outside `F`. Thus only even `r=2+2t` can be feasible. The wrapper changes these lengths to `2(15r+1)+8=70+60t`.

## 5. The sign sequence is not eventually periodic

Write `lambda=r exp(i theta)`, with `r=sqrt(7)/4>0`. The angle `theta/pi` is irrational. To see this, calculate

\[
\frac\lambda{\bar\lambda}+\frac{\bar\lambda}\lambda=-\frac{13}{7}. \tag{14}
\]

If `theta/pi` were rational, `lambda/bar(lambda)=exp(2i theta)` would be a root of unity. The left side of (14) would then be an algebraic integer. A rational algebraic integer is an integer, contradicting `-13/7`.

In particular `cos(t theta)` is never zero for any positive integer `t`, and the irrational rotation sequence `t theta mod 2pi` is dense, including every tail. Suppose the signs were eventually periodic with a positive integer period `p`. The open positive semicircle would then have the same membership as its rotation through `p theta` on a dense tail. Since `p theta` is not `0 mod 2pi`, the two open semicircles have a nonempty open symmetric difference. Density supplies infinitely many `t` with different signs at `t` and `t+p`, a contradiction.

If `mathcal N` were eventually periodic with period `P`, its restriction to the progression `70+60t` would be eventually periodic in `t` (period `P`, or `P/gcd(P,60)`). Equation (1) contradicts this. This completes the proof.

In particular, `mathcal N` is not a semilinear subset of the natural numbers and is not definable in Presburger arithmetic: one-dimensional semilinear/Presburger sets are eventually periodic. Its unary language is not regular for the same reason.

### 5.1 The obstruction is exact, with no fixed approximation gap

Let `N=70+60t` and `p=(delta_s P^{2+2t})(F)`. If `p<1/2`, use independent fair branch bits in all complete blocks. Set the final bit to `1` on every outcome in `F`, and on a fraction `(1/2-p)/(1-p)` of the outcomes outside `F`; set it to `0` otherwise. All input coordinates remain fair. Only the final acceptance condition can fail, with probability `1/2-p`. Balanced wrapping preserves these marginals and the acceptance event. Hence the actual product law `eta_N` satisfies

\[
\|\eta_N-\delta_z\|_{\rm TV}
\le\frac{(-\operatorname{Re}\lambda^t)_+}{2}
\le\frac12\left(\frac{\sqrt7}{4}\right)^t. \tag{15}
\]

For `p>=1/2`, exact attainment gives distance zero. Thus this counterexample is an obstruction to **exact** phase classification. It does not give a fixed positive gap for approximate coupling.

## 6. Scope and source boundaries

The transition maps, checker, balanced infix encoding, and coupling reduction are newly derived here. The only background facts used are elementary finite automata/syntactic semigroup theory, the spectrum of a three-cycle, rational algebraic integers, and density of an irrational circle rotation. The theorem establishes a counterexample to general finite-semigroup eventual periodicity; it does not classify every semigroup with transient ideals, nor establish an undecidability claim.

Nonregular unary stochastic cutpoint languages and their irrational-rotation mechanism are already known. For example, [Shur and Yakaryılmaz, *Quantum, Stochastic, and Pseudo Stochastic Languages with Few States*](https://arxiv.org/abs/1405.0055), section 3, explicitly treats rotations and nonregular unary languages. The result here is the transfer into identical-marginal, fixed-product semigroup coupling via a fairness-forcing checker and a balanced infix code. No priority claim for that transfer is made.

The companion positive source/extension boundary is recorded in `NONCOMMUTATIVE_REPAIR.md` section 4: finite completely simple subsemigroups admit an exact endpoint-plus-cyclic-phase description after a finite cutoff. The nonzero annihilating target (2) cannot occur in a completely simple semigroup. The original commutative source is Astra revision `b2a7a8fa91a8fcf6da05f36100ae4ce64a72a729`, `updates/DE/package/finite_commutative_semigroup_classification/RESEARCH_REPORT.md`, especially lines 11–119 and 542–566; this note extends the failure boundary rather than re-proving that source theorem.

## 7. General bridge: rational Markov cutpoints embed in fixed-target coupling

The construction is not specific to the oscillating 14-state chain.

**Embedding theorem.** Let `P` be any rational stochastic matrix on `d` states, let `j_*` be a start state, let `F` be any state subset, and let `c` be rational with `0<c<1`. There are an explicitly constructible finite semigroup `S`, distinct elements `a_0,...,a_{q-1}`, and a nonzero element `z` satisfying `zs=sz=0` for every `s in S`, such that, for

\[
\mu=\frac1q\sum_{b=0}^{q-1}\delta_{a_b},\qquad\nu=\delta_z,
\]

the full set of feasible horizons is

\[
\mathcal N(P,F,c)=
\{2(d+1)t+10:t\ge0,\quad(\delta_{j_*}P^t)(F)\ge c\}. \tag{16}
\]

**Proof.** Choose `q>=2` so that `qP(j,k)` and `qc` are integers. In each row of `P`, list each successor `k` exactly `qP(j,k)` times. Reading column `b` of these lists defines a map `f_b` and gives

\[
P(j,k)=\frac1q\sum_{b\in\mathbb Z_q}{\bf1}_{f_b(j)=k}.
\]

Use alphabet `Z_q` with uniform coordinate marginals. A complete block has one branch symbol `B` and the `d` checkers

\[
C_j=B+{\bf1}_{\{J=j\}}\pmod q. \tag{17}
\]

For `p_{j,b}=Pr(J=j,B=b)`, uniformity of `B` and `C_j` gives, for every `b`,

\[
\frac1q=\Pr(C_j=b)=\frac1q-p_{j,b}+p_{j,b-1}.
\]

Thus all `p_{j,b}` are equal and `B` is conditionally uniform given `J`. The state law after `t` complete blocks is exactly `delta_{j_*}P^t` under every valid uniform-marginal coupling.

Let `R` be a subset of the alphabet with size `qc`, and accept a final branch symbol precisely when `B notin R` or `J in F`. Uniformity of `B` implies `Pr(J in F)>=c`. Conversely, if this probability is `p>=c`, give each restricted symbol conditional probability `1/(qp)` on `F` and zero outside. On `F`, give each unrestricted symbol probability `(1-c/p)/(q-qc)`; outside `F`, give each unrestricted symbol probability `1/(q-qc)`. These probabilities sum to one for every state, every branch symbol is unconditionally uniform, and acceptance holds. Earlier complete blocks may use independent uniform branches. This proves the analogue of (7).

Finally encode `b` by the two-symbol word

\[
h(b)=(b,b+1\bmod q),
\]

prepend one of the `q` markers `sss(s+1)` and append one of the `q` markers `(u-1)uuu`, with independent uniform choices of `s,u`. Uniform marginals are preserved in both directions. The only constant triples are the initial and final marker triples, so the language is an infix code. The syntactic-semigroup argument gives a single target `z` and (2). Its generator images are pairwise distinct: replacing only the first symbol `s` in any accepted word by `b!=s` breaks the necessary initial marker, and hence distinguishes `[b]` from `[s]` by a right context. The accepted raw lengths are exactly `(d+1)t+1`; the wrapper lengths are precisely those in (16). This proves the theorem.

For a supplied rational initial distribution, add one transient start state whose first transition samples that distribution. The same theorem then gives a fixed shift of the horizon progression. All construction steps are finite algorithms on the supplied rational matrix and threshold; no independence oracle is supplied to the coupling model.

## 8. Equality cutpoints and a computable Skolem barrier

There is also an exact-equality version of the general embedding. Keep the complete blocks from section 7, but append **two** terminal symbols. The first terminal test uses the subset `R` of size `qc` and requires

\[
B_1\notin R\quad\text{or}\quad J\in F.
\]

The second uses a subset `R'` of size `q(1-c)` and requires

\[
B_2\notin R'\quad\text{or}\quad J\notin F.
\]

Every uniform-marginal accepted law then has both `p=Pr(J in F)>=c` and `1-p>=1-c`, so `p=c`. Conversely, if `p=c`, apply the conditional terminal-symbol construction in section 7 independently to the two tests given `J`. Both terminal coordinates are uniform and both tests always pass. The raw language of valid blocks followed by these two tests is regular; at each fixed length its number of complete blocks is uniquely determined.

Balanced wrapping and the syntactic-semigroup argument therefore give one finite semigroup, uniform input law, and one fixed target with the full feasible-horizon set

\[
\mathcal N_{=}(P,F,c)
=\{2(d+1)t+12:t\ge0,\quad(\delta_{j_*}P^t)(F)=c\}. \tag{18}
\]

This reduction is newly derived here. The following arithmetic-hardness input is imported:

> Akshay, Antonopoulos, Ouaknine, and Worrell, *Reachability Problems for Markov Chains*, Information Processing Letters 115(2), 155–158 (2015), Theorem 3: the Skolem Problem reduces in polynomial time to the Markov Reachability Problem.

The [author-hosted primary PDF](https://people.mpi-sws.org/~joel/publications/markov_reach14.pdf), pages 1–5, defines the latter problem as: given a rational stochastic matrix `M` and rational `r`, determine whether `(M^n)_{1,2}=r` for some `n in N`, using the paper's convention. The off-diagonal Skolem question there must use positive indices, since `(M^0)_{1,2}=0` always. Proposition 2 produces `r=1/4`, so section 8 applies without needing endpoint thresholds `0` or `1`; admitting index zero in our coupling construction makes no difference, since `(M^0)_{1,2}=0 != 1/4`.

Composing their imported reduction with (18) proves the following **decidability implication**: an algorithm which, given an arbitrary finite semigroup multiplication table and rational marginal/target laws, decides whether any feasible horizon exists would decide the Skolem Problem. The implication already holds for a uniform input law and a point-mass target.

The automaton-to-syntactic-semigroup step can require a very large multiplication table, and the common-denominator alphabet can also be large. Thus this note claims a **computable many-one reduction** for ordinary table input, not a polynomial-time reduction or a quantitative complexity lower bound. It also makes no undecidability claim.

The proof boundary is important: the stochastic reachability hardness is imported from the cited theorem; the fairness-forcing checker, the two terminal tests, and the balanced single-target encoding provide the new transfer. The imported theorem is not being presented as a newly proved number-theoretic result.

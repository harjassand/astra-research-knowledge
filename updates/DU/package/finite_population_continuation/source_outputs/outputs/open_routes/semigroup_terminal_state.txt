## Completed mathematical results

1. **Arbitrary-support commutative transport limit.** `ARBITRARY_SUPPORT_SEMIGROUP.md` gives a periodic transport-polytope description with sharp `O(1/n)` Hausdorff error, exact input marginals, a constructive balancing argument, and a sharp three-element join counterexample to finite attainment of every limiting point.

2. **Exact eventual periodicity in finite commutative semigroups.** `EXACT_EVENTUAL_PERIODICITY.md` proves that every fixed pair of prescribed marginal/output laws has eventually periodic exact attainability horizons. A bounded-defect description of all count-fiber vertices reduces feasibility to finitely many rational functions of `1/n`; rational data have an explicit cutoff with binary length `O(log Q + m log m)`. No polynomial-time pattern enumeration claim is made.

3. **Exact ordered-product classification in every finite completely simple semigroup, with arbitrary support.** `NONCOMMUTATIVE_REPAIR.md` section 4 proves that the support-generated semigroup stays completely simple, has a cyclic length homomorphism, and has a bounded zero-phase repair block. For sufficiently large `n`, the possible output laws are precisely those with the required first-letter row projection, last-letter column projection, and length phase. A valid cutoff is `n>=2+ell ceil(1/alpha)`, with `ell<=2|T|^2`. Cross-corpus independently reconstructed section 4 and the fractional-repair interface with no gap found. Sections 1–3 and 5 also preserve the fractional repair theorem and explicit group/Rees samplers, including the optional coalition privacy corollary.

4. **General finite-semigroup phase classification fails.** `NONEVENTUAL_PERIODICITY.md` sections 1–5 gives one finite semigroup, two equally likely input generators, and one fixed nonzero target `z`, whose entire exact feasible-horizon set is

   `{70+60t : t>=0, Re(((-1+3i sqrt(3))/8)^t)>=0}`.

   It is not eventually periodic. The target annihilates every semigroup element to zero. The proof forces a Markov evolution through fair-coordinate checkers and converts acceptance into one syntactic class using a balanced infix code. The core/full-horizon theorem was independently reconstructed by cross-corpus with no gap found. The fixed-target obstruction approaches the target exponentially in total variation, so no fixed approximation gap is claimed.

5. **General Markov cutpoint and equality bridges.** `NONEVENTUAL_PERIODICITY.md` section 7 embeds any supplied rational stochastic matrix and rational threshold in a uniform-alphabet, fixed-target coupling problem. Section 8 uses two terminal symbols to embed exact equality. Combining this with the imported Akshay–Antonopoulos–Ouaknine–Worrell theorem gives a computable reduction from Skolem to existence of any feasible horizon. Parent independently checked the imported source and equality interface. The ordinary semigroup table may be very large: no polynomial-time table reduction and no undecidability claim are made.

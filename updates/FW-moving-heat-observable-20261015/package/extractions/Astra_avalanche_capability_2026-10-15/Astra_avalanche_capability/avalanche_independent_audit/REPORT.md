# Independent audit verdict

PASS for the stated fixed-strength model and four supplied finite input fixtures, conditional on ordinary compiler/hardware integer correctness. No formal compiler proof, novelty claim, or physical validation is supplied.

## Mathematical algorithm

The decomposition P(K=m)=P(N[j_m]=m) H(j_m,m) is correct with j_m=#{s_i>F/m}. If a feasible m had more than m survivors in its eligibility prefix, their greater count would itself be feasible; suffix inequalities rule out precisely the larger feasible counts. An absent position cannot introduce a genuinely new feasible count, since that count was already attained at a stronger present position. The suffix transfer must not check its current position; the implementation correctly checks the next position. Zero and repeated strengths and strict mechanical equality are handled correctly for nonnegative strengths/load and positive temperature.

One shared forward and backward pass costs O(n²) arithmetic operations per time. An O(n) workspace implementation is possible. The current C++ implementation stores an n×(n+1) boolean mechanics table, so its actual stored input/mechanics is O(n²), not O(n). This is not an unrestricted polynomial-bit-complexity claim.

## Integer enclosure

With M=2^60, argument reduction makes the Taylor argument at most 1/2. Positive term interval recurrences enclose each magnitude; signed summation with directed endpoints is valid despite dependency. The degree-24 remainder is less than (1/2)^25/25! <1/M; the extra unit on each side is safe. Monotone positive squaring propagates bounds. The x≥64 cutoff is valid since exp(-64)<2^-64<1/M.

The fixed-p DP deliberately floors both passes. Prefix and suffix errors are bounded by j/M and (n-j)/M. Their product loses at most (n+1)/M, and each weighted output loses another unit. Summing n outputs is covered by the implemented n(n+3)/M allowance. Evaluating at low/high survivor probabilities is justified by coupling the maximal feasible count, and increasing psi(k), rather than by monotonicity of individual PMF entries. Represented lower/upper psi values can be applied after that coupling argument.

All four fixtures have strictly positive lower rate bounds. I verified every tail exponent exceeds the 64 cutoff, so each tail p upper numerator is 1. Thus tail products fit unsigned 128-bit arithmetic. Rectangle accumulations require at most 97 bits (moderate) or 117 bits (author parameters); other products and Taylor intermediates fit comfortably. The denominator M*10^6 correctly converts probability numerators times integer micro-time ticks to physical time. The tail term ceil(p_upper*M*10^6/lambda_lower) has the same units. Omitting psi(n) from this union-bound tail only weakens the upper bound.

The first interval [0,10^-6] and final partial interval are covered by decreasing-function rectangles. The production grid uses ceil(1.005*ticks), not an exact geometric ratio; therefore the exact-ratio algebra in the derivation should not be quoted literally for this grid. Its directly summed lower and upper rectangles remain valid.

## Remaining gaps and limits

1. The executable is not a safe arbitrary-input certificate engine: it lacks input validation, and the generic tail product p.h*M*10^6 can overflow U128 when p.h is large (e.g. an insufficient tail horizon). Fixture-specific checks above make the current results safe; general reuse needs guards or wider arithmetic.
2. n100/n400 strengths are generated by RandomState(0). They are new finite-size fixtures under the specified parameter regimes. Calling them `author` means author-style parameters, not independently established exact author experimental realizations. I verified recorded exact inputs, not upstream provenance. Even n5 uses rational T=1/20, which differs from treating the author's binary64 0.05 as an exact real number.
3. The integer numerical enclosure rests on the common-clock identity connecting this static process to the target model. This audit verified the transfer/integral arithmetic, not the entire independent derivation of that identity from the physical model.
4. High-precision numerical comparisons are strong regression evidence, not formal transcendental proofs; the Taylor argument supplies the mathematical bound. Compilation/hardware correctness is assumed.
5. No independent high-precision n100/n400 mean computation was performed here. Exact endpoint reproduction verifies implementation reproducibility, not independent large-size mean accuracy by a different model solver.

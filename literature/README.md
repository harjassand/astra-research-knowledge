The denominator of eligible papers/supporting lemmas is **UNKNOWN**. No fraction of all corpus lemmas is claimed. Each record keeps exact quantifiers, assumptions, inputs, outputs, precision, resource charges, proof steps, dependencies, counterexamples and speculative transfer gates. `claim_ids` route to current-status result cards; `depends_on` identifies atlas prerequisites, not a scientific certification. Every potential use/generalisation is explicitly unproved. Newer status and proof availability must be checked in the frontier layer before using a source as a premise.

Sources carry their SHA256 version and a content-addressed `object_path`, plus one-based inclusive UTF8 source-line ranges. A logical source `path` can be inside an archive rather than an ordinary checkout file. Read it through `python3 tools/knowledge.py read <doc_id> --start A --end B`; exact original bytes are in `evidence/objects/<hash-prefix>/<hash-rest>`. `web_page` identifies the existing browsable source export. A byte-hash pass protects provenance; it does not verify mathematics. `VALIDATION.json` records hash, locator and identifier checks.

Coverage levels mean:

- `structural_scan`: document/section/mechanism inventory only; no detailed mathematical extraction implied.
- `detailed_extraction`: exact source assertions and their mechanisms/interfaces reviewed at stated ranges; proof correctness not independently reconstructed.
- `proof_reconstruction`: reserved for a new, scoped reconstruction receipt listing proof version, reconstructed modules and unresolved imports. Existing source-reported internal audits do not automatically populate this level.
- `not_assessed`: known missing or unread material. AC's thermal results currently have a summary; their linked full proof packet is missing. No atlas lemma from that packet is claimed.

Future additions should cite a fixed file hash and exact statement/proof ranges; preserve zero cases, tie cases, scaling windows, probability/error normalizations, supplied-versus-acquired resources and failure examples. Record unsupported transfers as hypotheses. A broad scan should count its own eligible-paper denominator and unreviewed items; never substitute indexed page count for audited lemma coverage. Keep source-reported internal checks, formal-kernel declaration scopes, finite diagnostics, external validation and historical priority separate.

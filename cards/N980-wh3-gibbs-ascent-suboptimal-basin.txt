N980-wh3-gibbs-ascent-suboptimal-basin | The Gibbs ascent has a strictly suboptimal attracting basin for 2 < a < 4
status=source_derived_unreviewed; internal acceptance is bound to an exact content version and review scope.

EXACT CLAIM
For the W3 Gibbs update at parameter 2 < a < 4, the product fixed-point manifold has an open locally attracting basin although its objective is strictly below the maximally entangled witness. At a = 3, the retained exact interval certificate gives a faithful witness gap greater than 1.03 nats. Therefore monotone ascent and smooth convergence are not global certificates. At a = 2, this comparison is not a disproof: the product and maximally entangled boundary values tie.

SOURCE-REPORTED INTERFACE
The exact local-basin theorem uses the W3 channel and source parameter range 1 < a < 4; strict suboptimality relative to the maximally entangled input holds for 2 < a < 4. The faithful interval witness is the stated a = 3, epsilon = 1/100 case.

BOUNDARIES
This does not disprove the a = 2 squashing target or prove a general Blahut-Arimoto failure theorem. The exact interval certificate supports the faithful a = 3 gap; the open basin is proved analytically in the source.

COST AND INFORMATION BOUNDARY
The interval output certifies a stated finite logarithmic gap; it is not a runtime or global-search certificate.

NEXT OBLIGATION
Any use of ascent for the a = 2 target needs a separate global bound or proof excluding other basins.

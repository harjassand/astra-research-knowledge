RESULT: INPUT-INDEPENDENT FLAG, DIFFERENT EARLY-INPUT COST
Let N:AB -> A'B' be a finite-dimensional bipartite channel. Let R discard its input and prepare a fixed product state. For 0<p<1 define

    H_{p,N}(X) = p |11><11|_{F_A F_B} tensor N(X)
                 + (1-p) |00><00|_{F_A F_B} tensor R(X).

For every input X, including one entangled with an external reference, the flag marginal is

    tr_{A'B'} H_{p,N}(X) = tr(X)[p|11><11|+(1-p)|00><00|].

The late-flag task supplies the input before the flag is produced. The early-flag task requires the shared flag to be announced first; the quantum input may be selected in response, and flag 1 requires N while flag 0 requires R. These are ordinary definite-time processes with different output deadlines.

The source reports that if N is separable but outside closure(LOCC), D=d_A d_B, and p=1/D, then H_{p,N} as a complete late-flag channel is LOCC, while the early-flag process is not arbitrarily approximable by causal LOCC. For a product-Kraus decomposition N(X)=sum_j (A_j tensor B_j)X(A_j tensor B_j)^dagger, set a_j=||A_j||_F, b_j=||B_j||_F, and lambda_j=a_j^2 b_j^2. Trace preservation gives sum_j lambda_j=D. Sample a shared index j with probability lambda_j/D and apply local success filters A_j/a_j and B_j/b_j, which are contractions. The exact success subchannel is

    sum_j (lambda_j/D)(A_j/a_j tensor B_j/b_j)X(A_j/a_j tensor B_j/b_j)^dagger = N(X)/D.

On any filter failure reset to R and announce flag 0. This realizes the complete flagged channel with input-independent success probability 1/D. For an early flag, however, the shared memory conditioned on flag 1 remains separable before the fresh input arrives, so its conditional future channel must be LOCC; this contradicts N outside closure(LOCC). Robustness is argued by taking any approximating sequence with success probabilities q_j -> p and conditional channels L_j in LOCC: q_j L_j -> pN and p>0 imply L_j -> N, contradicting N outside closure(LOCC).

FINITE-BLOCK ROUTING AND COST IDENTITY
Let e_N(k,m) denote the infimum adaptive distinguishing error for k sequential uses of N with m supplied ebits; define e_H(n,m) analogously for n early-flag uses. Error is the maximum adaptive external distinguishing advantage, normalized to [0,1]. For K distributed as Binomial(n,p), the report claims, for either unassisted definitions throughout or exact-catalyst-assisted definitions throughout,

    e_H(n,m) <= e_N(k,m) + Pr[K > k],
    e_N(k,m) <= e_H(n,m) + Pr[K < k].

The same entanglement budget is used in each direction. With catalysts, the same catalyst is retained. In the first routing direction, genuine inputs are sent only on successful flags; overflow is exceptional. In the reverse direction, zero flags receive dummy product inputs, and shortage is exceptional. Unused simulator calls are completed with dummy product inputs and discarded outputs, so the simulator reaches its end-of-horizon return condition.

Passing to rates with k near (p+delta)n and (p-delta)n gives the reported exact identities

    E_early(H_{p,N}) = p E_seq(N),
    E_early^cat(H_{p,N}) = p E_seq^cat(N).

These identities are presented for every N under the source's sequential simulation definitions. For catalysts, return is exact as a marginal at the end of the complete simulation for every allowed input interaction; correlations with retained outputs are allowed, catalyst dimension is any finite value with no prescribed bound, and the routing must complete the horizon. The report does not claim the identity under approximate return or a fixed nonadaptive test-only return condition.

NINE-DOMINO-STATE EXAMPLE
In C^3 tensor C^3, use the orthonormal product basis

    |1>|1>,
    |0>|0 plus-or-minus 1>,   |2>|1 plus-or-minus 2>,
    |0 plus-or-minus 1>|2>,   |1 plus-or-minus 2>|0>,

where |u plus-or-minus v>=(|u> plus-or-minus |v>)/sqrt(2). Let M(rho)=sum_{j=1}^9 <a_j b_j|rho|a_j b_j> |jj><jj|. Its Kraus operators |j><a_j| tensor |j><b_j| are product, so M is separable. The report cites a strictly positive LOCC discrimination gap for this basis, implying M is outside closure(LOCC), and sets p=1/9. Thus the late-flag block channel is LOCC while the early-flag cost is reported as E_early^cat(H_{1/9,M})=(1/9)E_seq^cat(M)>0, conditional on N683. All external outputs in this example are classical; the asserted resource is the temporal interface, not entanglement in the Choi operator.

NEGATIVE RESEARCH CAPITAL: CAUSALIZATION DOES NOT PRESERVE THE RESOURCE
The report refutes the proposed general principle that an LOCC complete block operation satisfying the no-backward-signalling equations must have an LOCC realization respecting the earlier-output causal order. It also refutes the inference that input-independent success probability makes the normalized successful branch a deterministic/free LOCC channel. Here the successful branch is pN with (pN)^dagger(I)=pI, but N can lie outside closure(LOCC).

This does not contradict semicausal-to-semilocalizable realization results that permit quantum communication; those results do not promise preservation of a zero-entanglement LOCC implementation. It also does not refute the original memoryless parallel question

    N outside closure(LOCC)  =>?  E_parallel^cat(N)>0.

The early-flag task adds an internal interaction stage and is not an ordinary memoryless channel. A general collective block-level test separating N^tensor n from arbitrary collective LOCC, with the required exponential gap, remains missing in the source. The unrestricted parallel entanglement-cost question remains unresolved.

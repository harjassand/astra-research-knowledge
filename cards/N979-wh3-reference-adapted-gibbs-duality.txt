N979-wh3-reference-adapted-gibbs-duality | Exact Gibbs duality transfers positive W3 entropy witnesses
status=source_derived_unreviewed; internal acceptance is bound to an exact content version and review scope.

EXACT CLAIM
For a finite-dimensional channel N, a fixed arbitrary finite reference R, and a >= 1, the reference-adapted Gibbs functional has the exact variational identity sup_X log Phi(X) = sup_rho F(rho). For each faithful X, the Gibbs state Y = exp(G_X)/Phi(X) is a positive input witness, and a violation transfers between the entropy and exponential formulations without a min-max swap. The alternating update X -> N(Y) is monotone under the stated premises.

SOURCE-REPORTED INTERFACE
Finite-dimensional channel; fixed finite reference R; a >= 1; normalized faithful X on the effective output support, with boundary states obtained by faithful approximation.

BOUNDARIES
This is an equivalent positive-state reformulation and witness transfer. It does not prove the W3 target, classify all stationary points, or make monotone ascent a global certificate. No complexity, speedup, novelty, or acquired experiment is established.

COST AND INFORMATION BOUNDARY
Matrix logarithms and exponentials, reference dimension, conditioning, and stopping tolerances are real resources. No universal complexity guarantee is given.

NEXT OBLIGATION
Use the identity for exact witness transfer or a bounded search; any global upper bound still requires an independent certificate.

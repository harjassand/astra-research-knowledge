EXACT CLAIM
Let a native experiment have an arbitrary possibly non-Markovian hidden path, finite terminal category B, and almost-surely finite stopping time. Before the first probe hit, a nonnegative dose vector c changes only independently driven competing capture clocks with predictable path susceptibilities b_j(t), under the stated dose-linearity and no-interference contract. If each integrated susceptibility A_j is finite almost surely (without a finite-mean or maximum-rate bound), then the no-hit outcome subprobabilities are K_b(c)=E[1{B=b} exp(-c·A)]. A weak mixed-dose challenge acquires the common continuity modulus L(h)=K_hit(h,...,h). A finite-net procedure can acquire uniform bounded-dose predictions and a set of compatible joint measures; it does not identify the hidden microscopic network or rates.

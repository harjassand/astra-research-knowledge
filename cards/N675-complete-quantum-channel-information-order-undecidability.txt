INTERFACE
Each test is finite-dimensional, with dimensions not bounded uniformly over instances. A POVM E=(E_i) on C^a has positive effects summing to I_a; “strictly positive” means every E_i>0. The classified inputs are pairs of rational-complex strictly positive POVMs on a common input, where real and imaginary matrix entries are rational and the input dimension and outcome counts are part of the finite description.

For channels P,Q with common input, the note defines complete SLD order by comparison of the SLD quadratic forms for every finite untouched reference R, faithful input state rho, and traceless Hermitian tangent H. It defines unrestricted complete Umegaki relative-entropy order by D(P_R(alpha)||P_R(beta)) >= D(Q_R(alpha)||Q_R(beta)) for every finite R and every input-state pair alpha,beta; there is no equal-reference-marginal condition.

EXACT CLAIM
1. For the rational strictly positive POVM-pair class above, complete SLD dominance is coRE-complete under computable many-one reductions; failure is RE-complete.
2. For every finite-dimensional channel pair, complete SLD order is equivalent to the stated unrestricted complete Umegaki relative-entropy order. Consequently the same coRE/RE classification applies to that POVM class and entropy order.
3. No total computable function of a valid rational POVM pair bounds a reference dimension sufficient to witness every failure of complete SLD order.
4. For strictly positive POVMs the source defines a finite bounded entropy defect V(E,F). The accepted result states no total algorithm approximates V at every requested rational additive tolerance, and that even additive error 1/4 is impossible uniformly over the same rational-complex strictly positive POVM class. The fixed-error claim uses a computable positive witness margin and finite tensor amplification; it is not presented as an efficiency result.

STATED PROOF SPINE AND INTERNAL DEPENDENCIES
The stated proof reduces a halting promise through a finite nonlocal game attributed to MIP*=RE. It uses a construction on the actual normalized two-factor Jordan domain, a quantitative Pauli anchor, local completely positive smoothing, a finite gap penalty, an ordered-word inverse-Jordan compiler, rational positive measurement effects, and dimension-independent global completion. It then enumerates rational faithful states, tangents, and reference dimensions to obtain the RE upper bound for failure. The bounded-defect strengthening uses a perfect-strategy Schmidt-sector argument, dimension-independent normalization, a Fisher-to-entropy margin, and tensor amplification. These details are available by exact page ranges in the package extraction; Harjas's explicit programme acceptance includes the stated internal dependencies; no new proof audit was performed.

It gives no efficient witness-finding procedure. Correctness at this stated scope is accepted for programme use.

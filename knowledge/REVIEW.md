## Evaluation design and retained failures

[comparison.json](evaluation/comparison.json) contains every question, expected
parent scope, returned IDs/ranks, expansions and followed source route. Cases
were written outside implementation fixtures at `../research-use/cases.json`;
their SHA256 is `5ea1108a5a776311c637cdce78b5e30699c31174878138b5ca1aeb08ab110d28`.
**This is not held-out, blind or independent evaluation.** The same owner read
the sources and curated the units. The original five audit diagnostics were
exposed, and earlier CLI/context probes are explicitly identified per case.
Later changes were informed by observed failures. This is not a measured
invention-gain experiment or a new scientific discovery.

All methods get five candidate slots and may follow the same packets/sources.
A hit means an expected parent appears, not that the returned claim is valid
for the question. The denominator is exactly 23 supported navigation cases;
two additional unsupported requests are evaluated separately.

| Method | Expected parent first | Expected parent in first five |
| --- | ---: | ---: |
| Full-card BM25, 1,012 complete cards | 14/23 | 15/23 |
| Plain BM25 over the same scientific cards, units and cited windows | 18/23 | 23/23 |
| Content/contract ranking, shown expansions and full-card safety lane | 18/23 | 23/23 |

The matched-content lexical baseline ties the final parent-hit counts. Thus
this evidence does **not** establish superior semantic ranking from field
weights, expansions, a graph or an embedding. The demonstrated change is richer
recoverable scientific content, explicit intermediate interfaces and bounded
source/status delivery. Field ranking sometimes returns the useful unit
directly rather than its enclosing result; it also worsens some orderings.

The initial 18-unit field-only run is retained in
[field-initial.json](evaluation/field-initial.json): 22/23 top-five parent hits,
with a regression on finite equilibrium cooperativity despite the full-card
baseline finding the right card first. That failure motivated the explicit
equilibrium obstruction unit, not an unsupported claim of a first-order
chemical device. The safety lane preserves an otherwise missed strongest
full-card candidate without pretending its score shares the field-score scale.
Trial reciprocal-rank fusion was rejected: on that initial exposed set,
constants 0 or 1 gave 21/23 top-five hits, 5/10/20 gave 20/23, and 60 gave 19/23.
The full-card safety lane and selective source extraction were retained instead.

## Realistic research-use checks

1. **An unnamed ordered-product reduction.** E03's plain full-card route misses
   N675 in five slots. Matched-content BM25 reaches it second; the final field
   route reaches `U675-ordered-word-compiler` third. Reading its actual source
   range (now 867-970) reveals suffix closure, the exact edge recurrence,
   finite penalty, same-reference negative-witness transfer and the essential
   strictly positive gap. A researcher can use the candidate compiler as a
   conditional reduction premise, or reject an attempted gap-free transfer.
   The entire hardness chain is not accepted by this extraction.

2. **Noisy cellular inheritance.** E10 misses N461 in five full-card slots;
   the enriched routes find its moment mechanism first. The source at lines
   16-115 derives the nonzero-lag pencil and dimensionless variance, but requires
   iid measurement errors independent of the latent lineage. The usable next
   step is a conditional population-moment estimator, not a universal biological
   law or a claim that correlated segmentation errors cancel. E11 deliberately
   tests that incompatible assumption. No biological dataset was acquired.

3. **A correlated rare-event update.** The full-card baseline already retrieves
   relevant N938/N950/N956 material, so no discovery gain is claimed for E07.
   The new positive-quadrature and relative-composition units expose a usable
   paired interface: preserve unnormalized mass, use an entrywise positive
   sandwich, multiply input/kernel spreads, and normalize only with positive
   finite mass. The inspected proof at N950 lines 211-260 establishes that
   positivity preserves the order. E08 rejects row-wise normalization with
   unchanged entrance weights. Reusing a stored kernel does not waive its
   per-application error or contraction/mixture-growth costs.

4. **A false reset transfer and a repaired material comparison.** The private
   rank-two reset has an accepted internal whole audit, but the identity/swap
   example refutes transfer to a continuation seeing the selected word.
   The explicit bridge retains that distinction. The coating query E23 reaches
   `U960-material-axis-correction` and its actual corrected source: the old
   frozen-axis ordinary instability is not a physical superiority witness, and
   both corrected designs are stable at the original 1MPa fixture. This is
   source-passage inspection, not just a link/hash check.

The return routes were followed and decisive passages inspected during
curation/review; every selected unit also has a checked literal passage anchor.
The N675 source regression initially assumed a PDF line-wrap-free phrase; that
test was repaired to match the actual preserved extraction, not by editing
scientific bytes. Equations in PDF-derived text remain non-authoritative.

## Remaining retrieval failures and next improvement

E03 still ranks unrelated candidates ahead of its compiler. E15's field route
ranks the relevant exposed-key counterexample family third while plain
matched-content lexical search ranks that family first. In the unsupported
superconductor/universal-algorithm cases, related vocabulary still returns
candidates. The reader does not fabricate the requested consequence, and its
bridge tool does not certify it, but reliable automatic unsupported-task
detection has **not** been demonstrated. Parent-hit success is not answerability.

Only 19 new units are deliberately curated; automatic windows do not give every
buried mechanism an audited structured interface. Existing topic tags are
uneven and are not a complete field taxonomy. Better rankings, broader
chemical/biological/material mechanisms and genuinely unfamiliar research-use
comparisons remain substantive work. The next useful improvement is to observe
new naturally occurring research tasks through the existing dispatcher,
extract the missed load-bearing premise/obstruction, and compare again with the
same-evidence lexical baseline without adding producer forms or an idle gate.

## Intake and implementation checks

`INTAKE.md` supplies one normal build/check path for every new source, changed
card, reusable subresult, correction and supersession. Tests exercise initial
intake, revised source plus immutable unit v2, retained v1 bytes, historical
review non-promotion, idempotent regeneration, missing/mismatched support,
wrong quote/branch, wrong range, new-shard membership, changed outputs,
correction propagation and distinct transfer states. Local readers refuse
stale views. Web catalog/posting/packet reads verify the search snapshot hashes
and report unavailable or mixed datasets as access failures.

Post-PR adversarial review found that a malformed numeric correction/dependency
target could be retained without being routed to any result. No such dangling
reference exists in the current corpus. A rejecting identity check and a
regression test now prevent that intake failure from being silently published.
The same review found that extracted units inherited direct parent notices but
omitted their parent's explicit prerequisite alerts. Those alerts now travel
with the unit as labeled parent-context notices, not automatic transitive
invalidation. N684's units preserve the scoped N675 prerequisite context.

The current publication gate preserves existing checkpoint tests and source
manifest verification, checks the actual PR base, protects old source/version
bytes and runs the new normalization tests. Original scientific scripts were
not replayed. Build/test success is implementation evidence; the scientific
reuse assessment is the source inspection above, and the accepted scientific
subclaims have separate scoped audit records.

The completed PR review, authorized merge, remote checks and ordinary Capital
contract demonstration are recorded in the task closeout after they actually
happen; none is inferred from this implementation review.

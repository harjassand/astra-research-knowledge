4 Comparator discretization
Choose rational 0<tau<=1/100. Let h_E=tau/lambda. Take L0=1+ceil(log_2(1/(tau rho))), computable from rational bit
lengths (or any explicitly polynomial-size upper bound of this order), and K=ceil(L0/tau); H=K h_E. Map E<H to
e_k=k h_E for k=0,...,K-1 and reject E>=H. Thus
  Pr(floor(E/h_E)h_E>=r, E<H)
    >= exp(-tau) exp(-lambda r)-exp(-lambda H)
for every r>=0, and is at most exp(-lambda r). Consequently the resulting remainder p_grid lies in
  exp(-tau) p_i-tau rho <= p_grid <= p_i.
K is polynomial in input bits and 1/tau. The E-cell masses are exp(-k tau)-exp(-(k+1)tau), plus a rejected tail symbol.

5 Geometric atomization and cumulative resource rounding

Let d_max=max_j(delta_j+1/T) and ell=tau rho/(m d_max). Then Pr_q[some X_j<ell]<=tau rho. Take rational
g=1+gamma with gamma = tau/[10m(m+1)] exactly. The explicit equality ensures that the number of geometric grid
points is polynomial; an unspecified arbitrarily smaller gamma would not suffice. Geometrically round every X_j
upward to an atom in {ell g^r:r>=0}, stopping at the first grid point >=T; values below ell are clamped to ell. Off the
bad event X_j<ell, each atom is <=g X_j.
Use the same geometric grid plus zero for both accumulated resources. On a skip transition add the current atom to
omitted cost; on a select transition add zero. On every transition add the atom to total cost. After each addition round
UP to the next resource grid point. Zero remains zero, and adding zero to an existing grid point leaves it unchanged.
Induction gives, for every selected path and every input outside the bad event,
  exact omitted <= rounded omitted <= g^(m+1) exact omitted,
    exact total   <= rounded total   <= g^(m+1) exact total.
Let D0=g^(m+1). The rounded automaton for comparator e_k accepts only D(e_k,T+e_k), and contains D(e_k/D0,
(T+e_k)/D0) outside the bad event. By the smoothing lemma its acceptance probability Q_round,k satisfies
  D0^(-m) Pr_q[D(e_k,T+e_k)]-tau rho
    <= Q_round,k <= Pr_q[D(e_k,T+e_k)].
Average over the comparator cells. Since m(m+1)log(g)<=tau/10, total relative geometric-rounding loss is O(tau).
Together with comparator discretization,
  (1-O(tau)) p_i <= p_round <= p_i.
Keep resource grid values through the first point at least 2mT (which exceeds g^(m+1)mT for the chosen gamma), plus
zero. There are only O(log(2mT/ell)/log(g)) positive resource grid values. Each has polynomial rational bit length. The
automaton state stores (original selected endpoint, rounded omitted resource, rounded total resource, comparator
index). The number of states and transitions is polynomial. Overflow is an absorbing reject state. A zero-cost forced
transition for the anchored activity can be removed by ordinary epsilon-elimination or a fixed bridge between prefix
and suffix; it carries no random coordinate.
This is an explicit approximate nondeterministic read-once branching program. It does not count witnesses; different
paths accepting the same input are accepted only once by #NFA.

Use a common denominator 2^b, with b polynomial. A uniform b-bit block is decoded to atom j according to a disjoint
integer interval of length equal to its numerator. Each interval has a polynomial-size binary comparator automaton.
Replace each atom-labelled transition by such a b-bit interval recognizer. The accepted bit strings encode the product
atom law exactly. Multiple nondeterministic witness paths do not multiply the count of a bit string.
The resulting ordinary NFA and unary input length are polynomial. Its accepted-word fraction equals the rounded
probability under the dyadic law. Total variation changes the event probability by at most tau rho/10, hence only O(tau)
relatively. Invoke the #NFA FPRAS at relative accuracy tau. Taking logs and restoring -lambda T+sum log C_j
approximates log Pr(A_i) to O(tau).
The external counting theorem [1] counts accepted words, not accepting runs, and also supplies polynomial-time
generation. An approximate conditional generator can alternatively be built from prefix-count self-reduction.

7 Conditional samples and the polynomial union correction
For a generated accepted atom word, jitter each X_j independently according to the original q_j law restricted to its
atom interval, and E according to its comparator cell. For the exact atom masses this produces q times the independent
E law conditioned on the rounded acceptance event. That acceptance event is a subset of {E>=R}; its mass differs by
O(tau) relatively, so conditioning changes the desired tilted joint law by O(tau) in total variation. Dyadic-law and NFA-
generator errors can also be budgeted as O(tau), because the normalizer is >=rho/2.
Project to the non-anchor X_j, then sample
  X_i=(T-L)_+ + Z, Z~Exp(lambda),
and sample every activity outside V_i independently from its original exponential law. This is within O(tau) total
variation of the original environment conditional on A_i. The true ideal conditional law follows directly from the
likelihood identity in Section 1. B_j conditionals are elementary memorylessness.
Now use the ordinary union-of-at-most-2n-events estimator: select a component with probability proportional to its
probability, sample its conditional environment, evaluate the number M(X) of true components containing X, and
average 1/M(X). The ideal mean is U/W and lies in [1/(2n),1]. Choosing all component count and conditional-sampling
errors tau=O(epsilon/n), with appropriate constants and polynomial sample count, gives relative O(epsilon) error in U
and hence additive O(epsilon) error in log U. Component weights are normalized in log scale without ever writing
exp(-lambda T) as a huge denominator. Optional omission of negligible components must use the retained-component
membership count throughout. Require total discarded component weight at most epsilon*W/(100K), which ensures
lost union mass at most epsilon*U/100 because W<=K*U. It suffices to drop only components whose true log gap from
the largest component is at least log(100K^2/epsilon); when gaps are computed approximately, add an explicit guard at
least twice the known log-estimation error. Alternatively keep every component and implement log-scale categorical
sampling to controlled total-variation accuracy.

Finite precision sampling
A discrete atom sample is not itself a continuous conditional sample. The jitter must use lazy continuous random bits or
an explicitly bounded finite-precision coupling. Membership checks for the true A_i/B_j can use interval arithmetic and
be refined until unambiguous, except on null boundaries. A worst-case polynomial-bit truncation uses the following
anti-concentration argument; the product tilted densities have polynomial-bit logarithmic sup bounds and conditioning
normalizer >=rho/2, and the shifted anchor adds an independent exponential. Section 9 below supplies a polynomial
precision bound from these density and conditioning estimates; continuous sampling and exact-real comparisons are
not assumed as oracles.

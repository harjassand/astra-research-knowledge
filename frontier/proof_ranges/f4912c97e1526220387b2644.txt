## 3. What a task can use without certifying a spectral class

Let a finite action family have losses

    ell_u(X)=c_u+Tr(Q_u X),

where Q_u is a supplied selfadjoint trace-class operator, c_u a supplied scalar,
and L=max_u ||Q_u||_1<infinity. All acquisition, representation and trace
evaluation costs are charged. Equations (2) and trace duality give

    |ell_u(Y)-ell_u(X_P)| <= ||Q_u||_1 R_a(eta).                (5)

Thus if the computed loss margin of a selected action over every competitor is
greater than 2 L R_a(eta), that action minimizes the true losses. The sharper
pointwise certificate, identified by the independent critic, subtracts first:

    |[ell_v(Y)-ell_u(Y)]-[ell_v(X_P)-ell_u(X_P)]|
       <= ||Q_v-Q_u||_1 R_a(eta).                              (6)

Only this smaller pairwise margin is needed. If D=max_(u,v)||Q_u-Q_v||_1,
minimizing approximate losses incurs true regret at most D R_a(eta)<=2L R_a(eta).
Proof: apply trace duality to Q_v-Q_u, and compare the selected action with
a true optimum. Common task components cancel exactly; they need not be
estimated to the absolute accuracy their separate norms would suggest.

For a family indexed by unknown theta, the same statement holds uniformly if
the approximation and trace-norm bounds hold for every theta. With exactly the
same acquisition output laws and policy class, changing only those loss tables
changes minimax risk by at most L R_a(eta), and a
policy optimal for the approximate table has excess minimax risk at most twice
that quantity. Pairwise pointwise cancellation alone does not replace this
minimax-risk bound: a theta-dependent common loss offset can change which theta
is worst. This does not optimize or acquire the experiment; it only bounds
loss-table perturbation for an unchanged acquisition class.

Consequently a strict scientific decision can remain certified when a nonzero
residual cannot establish compactness or a Schatten class. The conclusion needs
an identified fixed-point target and task margin. It does not require the full
singular-value list, but it does require the actual uniform residual guarantee.

For an exact source-word iterate X_k, the source supplies instead
||X_P-X_k||<=1/[a(k+1)]. Regret<=2L/[a(k+1)] follows. The dimension
D_k, Gram construction, source/operator acquisition, conditioning and arithmetic
precision remain paid. Free-word branching can make D_k exponential in k even
with rank-one P. A small list of formulas does not provide a cheap loss compiler.
If only an inexact solve and small gap Delta are available, (3) shows that the
universal norm-residual requirement scales as a Delta^2/(4L^2) near zero.

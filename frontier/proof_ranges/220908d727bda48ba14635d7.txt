## 3. The central theorem

### Theorem — Closed copy-stable classes admit simultaneous marginal completion

For each finite ground set \(E\), let \(\mathcal C_E\) be a class of polymatroids. Assume that the family \(\mathcal C\) is:

1. closed in the ordinary finite-dimensional topology;
2. preserved by restricting and relabelling coordinates;
3. closed under conditional copying, with the extension required to belong to the corresponding class \(\mathcal C_{E\cup A'}\).

Then, for every \(h\in\mathcal C_E\) and every protected family \(\mathcal F\), there is \(g\in\mathcal C_E\) such that

\[
g|_F=h|_F\qquad(F\in\mathcal F),
\]

\[
I_g(A;B\mid C)=0
\]

for **all** partitions separating \(\mathcal F\), and additionally

\[
g(E)\ge h(E).
\]

No representability, probability distribution, convexity, or differentiability assumption on \(\mathcal C\) is needed.

### Proof

First add all singletons to \(\mathcal F\). This does not change which partitions separate the family.

Consider the feasible set

\[
K=
\left\{
g\in\mathcal C_E:
g|_F=h|_F\text{ for every }F\in\mathcal F
\right\}.
\]

It is nonempty because it contains \(h\). It is closed by assumption.

Moreover, fixing the singleton ranks gives

\[
0\le g(S)\le\sum_{i\in S}h(\{i\})
\qquad(S\subseteq E).
\]

Thus \(K\) is bounded and consequently compact. Choose \(g\in K\) maximizing \(g(E)\).

Suppose that a separating partition \(E=A\dot\cup C\dot\cup B\) has

\[
d:=I_g(A;B\mid C)>0.
\]

Take a conditional-copy extension of \(A\) over \(C\), inside \(\mathcal C\). Restrict it to \(A'\cup B\cup C\), and relabel \(A'\) as \(A\). Call the resulting profile \(g'\).

The copy properties give

\[
g'|_{A\cup C}=g|_{A\cup C},
\qquad
g'|_{B\cup C}=g|_{B\cup C}.
\]

Every protected set lies in one of these two sides, so \(g'\in K\).

The copy independence also implies

\[
I_{g'}(A;B\mid C)=0.
\]

Therefore,

\[
\begin{aligned}
g'(E)
&=g(A\cup C)+g(B\cup C)-g(C)\\
&=g(E)+I_g(A;B\mid C)\\
&=g(E)+d.
\end{aligned}
\]

This contradicts maximality of \(g(E)\). Hence every required conditional mutual information is zero.

Finally, \(h\in K\), so the maximizing \(g\) satisfies \(g(E)\ge h(E)\). ∎

### What the mechanism actually is

The decisive identity is

\[
\boxed{
\text{increase in total rank}
=
\text{conditional-independence defect removed}.
}
\]

A single scalar objective therefore enforces all the separator conditions simultaneously.

The familiar maximum-entropy argument for distributions is not new. The contribution being investigated is that **the same argument works inside any closed class that can perform conditional copying internally**. It does not require actual distributions.

That observation becomes more consequential when applied to the maximal class compatible with finite copy proofs.

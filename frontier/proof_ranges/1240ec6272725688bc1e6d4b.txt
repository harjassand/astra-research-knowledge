## 4. A finite-horizon impossibility, not only an infinite-time one

Define
\[
\Lambda_T(z_0)
=
-\frac1T\log_2
\frac{f(G^Tz_0)}{f(z_0)}.
\]

For the same fixed objective, consider the decision problem
\[
\boxed{
f(G^TE(w))
\ge
2^{-(2k-1)T}f(E(w)),
}
\]
where \(w\) and the binary representation of \(T\) are the inputs.

The supplied reduction shows that this problem is **EXPTIME-complete**. Approximating \(\Lambda_T(E(w))\) within \(1/4\) is EXPTIME-hard.

The argument preserves a constant numerical gap.

At an aligned horizon \(T=2\ell n\), a computation that never accepts satisfies
\[
\Lambda_T=2k+O(1/T).
\]

If acceptance occurs at machine time \(h\), then
\[
\Lambda_T
=
2k-2(1-h/n)+O(1/T).
\]

Take any exponential-time decision procedure with an exponential running-time bound \(H\), and choose \(n\ge4(H+1)\). Its horizon still has only polynomially many binary digits.

After fixed additional padding, rejecting inputs give
\[
\Lambda_T\ge2k-\frac18,
\]
while accepting inputs give
\[
\Lambda_T\le2k-\frac{11}{8}.
\]

An approximation with error \(1/4\) distinguishes them.

Membership in EXPTIME follows by exact simulation: at step \(t\), each coordinate requires only \(O(|w|+t)\) bits for this fixed instance. Simulating through \(T\) therefore takes
\[
T\,\operatorname{poly}(|w|+T)
\]
bit operations, which is exponential in the actual input length \(|w|+\log T\).

The exclusion of a polynomial-time predictor is unconditional. It uses \(\mathrm P\ne\mathrm{EXPTIME}\), for which the note includes a short diagonal proof—not an assumption such as \(P\ne NP\).

Importantly, the decision formulation requires **only rational arithmetic**. No logarithm oracle is needed.

## 4. Exact 5^w counting and sampling algorithm

Represent each map by a list of binary row masks. For a block define δ_i(x)=1 if L_i x=0 and 0 otherwise. Its valid-pair indicator is exactly

f_i(u,v)=1−δ_i(u)−δ_i(v)−δ_i(u+v)+3δ_i(u)δ_i(v).

The three possible image ranks give values 1,0,1 respectively. Multiplying the w factors expands into at most 5^w terms. Each term is a signed integer coefficient times the indicator of a homogeneous binary linear system in 2m variables:

- no block constraint, coefficient 1
- L_i u=0, coefficient −1
- L_i v=0, coefficient −1
- L_i(u+v)=0, coefficient −1
- L_i u=L_i v=0, coefficient 3

Gaussian elimination counts each system exactly. With a fixed bit prefix, append the corresponding affine equations; an inconsistent system contributes zero, and a consistent rank-r system contributes 2^(2m−r). Summing gives the exact nonnegative number N(prefix) of valid completions. Signed intermediate sums are bounded in absolute value by 7^w·4^m, so O(m+w)-bit integer accumulators suffice, apart from input indexing.

Compute N(empty)=|C| and choose one uniform integer R in {0,…,|C|−1}. Traverse the 2m bits in fixed order. At a prefix let N0 be the number of valid completions with next bit 0. If R<N0, append 0; otherwise append 1 and replace R by R−N0. This is a bijective unranking of C. A uniform R therefore gives an exact uniform pair, not merely an approximately stationary sampler. An independent m-bit a completes the coupling.

Precomputing constraint bases and optionally merging identical systems takes 5^w poly(input) work and memory. Each of O(m) prefix counts uses at most 5^w Gaussian counts. A streaming variant trades recomputation for polynomial auxiliary memory. The algorithm is fixed-parameter tractable in w, not polynomial in w. Uniform-integer rejection uses finite expected random bits; the sampler has expected O(m) random-bit cost in addition to deterministic counting work.

The simpler baseline draws (u,v) uniformly from V² until valid. The count bound guarantees acceptance probability at least 16^(−w), hence expected at most 16^w proposals, each validated in polynomial explicit-input time. It does not provide a polynomial bound in w either.

None of these algorithms finds or learns an additive representation for an arbitrary set family. The maps and their binary coordinates are input, and reading them is included in the polynomial factor.

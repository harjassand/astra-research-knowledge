ACQUIRED PREDICTIVE OPERATIONS WITH RETAINED QUANTUM MEMORY
Owned construction and proof, 24 October 2026. Conditional mathematics; no
priority, physical-acquisition or incumbent-advantage claim. The spectral
realization and absorbing-controller resolvent are existing mechanisms.

1. Legal observations, and the supplied information that remains

A finite action alphabet a induces an unknown stationary CP instrument
T_(a,o) on an inaccessible D-dimensional quantum memory. Sum_o T_(a,o) is TP.
One concrete legal interface prepares a visible system, lets a fixed unknown
joint interaction occur, then measures/discards that visible system. Its next
preparation is a causal break on the visible system, not on the hidden memory.
Only classical actions/outcomes and repeatable full-process episode starts
are given. Episode starts, action calibration, stationarity and a dimension
upper bound are substantive supplied resources. No latent Kraus matrices,
memory basis, exact expectations, CP gauge or physical-state oracle is given.
The promised operations use this finite action library and classical feedback;
arbitrary new coherent quantum interventions/references are outside the claim.

Let rho0 be the reproducible memory state at episode start. All real Hermitian
memory states reachable by finite action/outcome words span R. Let

 N = {X in R : Tr[T_f(X)]=0 for EVERY legal future word f},
 V = R/N,                 r = dim V <= D^2.

Include the empty word, so N has trace zero. N is invariant under every T_z:
testing T_z N by f is testing N by the word z followed by f. True instruments
therefore descend to V. No finite noisy experiment alone proves that no unseen
mode exists; a known rank upper bound is required for the exhaustion below.

2. A physical norm whose usable conditioning comes from acquired probabilities

For v=[X] in V define

 ||v||Q = inf_(n in N) ||X+n||1.

Finite dimension makes this a genuine quotient norm. For a fixed action, the
CP direct-sum instrument is trace-norm contractive on Hermitian inputs:

 sum_o ||T_(a,o)Y||1 <= ||Y||1.

For any n in N, sum_o ||[T_(a,o)X]||Q is no larger than the left side with
Y=X+n. Infimizing proves sum_o ||T_(a,o)v||Q <= ||v||Q. This uses no mixing or
forgetting assumption. Positive reachable subnormalized states have norm equal
to their trace: the trace gives the lower bound and positivity the upper bound.

Choose r legal preparation procedures p_j producing positive memory states
rho_j of known mass m_j<=1. Our prototype uses deterministic action words with
outcomes DISCARDED, so all m_j=1; no postselection is hidden. Select r legal
future event tests f_i, with f_0 empty. Define

 H_ij = Tr[T_(f_i)(rho_j)],      x_i(v)=Tr[T_(f_i)(X)].

Assume H is nonsingular AND an independent architectural bound gives dim V<=r.
Its columns then span V and its tests give an isomorphism V -> real^r. In
particular x_0 is trace, not a fitted observable. A full-rank minor without the
rank upper bound would certify only a subspace and is insufficient here.

Each future event is a quantum effect between 0 and I. Consequently
||x||infinity <= ||v||Q. Conversely write v=sum_j c_j[rho_j], c=H^-1 x:

 ||v||Q <= sum_j m_j |(H^-1 x)_j|
         <= kappa ||x||infinity,
 kappa = ||diag(m)H^-1||_(infinity -> 1)
         <= (sum_j m_j)||H^-1||infinity
         <= r||H^-1||infinity.

Also kappa<=r/sigma_min(H) when all m_j<=1. The first bound can be tighter by
enumerating sign vectors for small r. Crucially the physical quotient norm
need never be reconstructed: measured H plus its confidence margin supplies
an upper bound on kappa. The norm is an analytical witness whose constants are
observationally certified; it is not an uncharged learned latent model.

3. Counts -> complete predictive realization, with data-dependent core selection

For z=(a,o), acquire H_z,ij=Tr[T_(f_i)T_z(rho_j)] and x(rho0) by raw joint-event
counts on repeated legal episodes. The exact coordinate map is B_z=H_z H^-1.
This follows by testing each basis state; spanning then extends it to all V.
Products predict all words. A CP gauge is neither identified nor needed for
these finite-library classical predictions.

All candidate action/outcome/wildcard events for basis selection and shifts
must be included in a finite confidence pool BEFORE selection. If N_s
independent full-process episodes estimate event s, Hoeffding gives simultaneous

 |p_hat_s-p_s| <= w_s=sqrt(log(2K/alpha)/(2N_s))

for K events, with probability >=1-alpha. Pooling settings sharing an action
prefix is legal by causality: later actions cannot change the prefix law.
Within a multinomial, individual event counts are binomial; independence
between distinct events is unnecessary for the union bound. All-outcome events
have known probability one and error zero from TP, rather than sampled error.
Prefix postselection, if used, must be represented by joint probabilities or
paid successful-prefix counts; normalization never comes for free.

Let dH bound ||Hhat-H||infinity by maximum row sum of entry widths and
Jhat=||Hhat^-1||infinity. If nu=Jhat dH<1, Neumann perturbation proves H true
nonsingular and

 Jtrue=||H^-1||infinity <= Jbar=Jhat/(1-nu),    kappa<=r Jbar.

Together with dim V<=r, this CERTIFIES exhaustion on the confidence event.
Define Bhat_z=Hhat_z Hhat^-1. If dz bounds ||Hhat_z-H_z||infinity, then

 ||Bhat_z-B_z||infinity <= ez=(dz+||Bhat_z||infinity dH) Jbar.

Proof: (Bhat_z-B_z)H = (Hhat_z-H_z)-Bhat_z(Hhat-H). Add any declared causal-row
repair's measured norm to ez. In our binary prototype branch 1 absorbs the
row discrepancy so sum_o Bhat_(a,o) has trace row exactly (1,0,...,0). This is
causal accounting, not positivity or an instrument-error certificate by itself.

By the acquired norm equivalence, on the SAME true quotient coordinate space,

 sum_o ||(Bhat_(a,o)-B_(a,o))x||Q
   <= kappa sum_o ez ||x||infinity <= e ||x||Q,
 e = kappa max_a sum_o ez.

This is a joint branch-instrument error, not max per-branch error and not error
only in the nonselective sum. r and conditioning matter explicitly. The bound
can be loose or vacuous at realistic shots; accurate held-out predictions do
not upgrade it. The first prototype's e=33.19 DOES NOT certify a useful uniform
controller error, despite certifying rank and giving accurate examples.

4. Compiling adaptive operations without native forgetting

Take ANY finite-state classical controller over the legal library, including
one selected after acquisition. Lift V into a direct sum over controller states,
with l1 sum of ||.||Q over classical labels. True selected instruments contract
this norm and the same primitive joint error e applies, independent of the
controller's number of states. Classical random choices are convex mixtures.
The compiler does not promise efficient SEARCH over controller graphs.

Before EACH attempted primitive, force an independent locally calibrated coin
to abort with probability delta in (0,1), gamma=1-delta. Abort is a terminal
LABEL retaining the current physical memory. It is not a bath reset. Native
success/other terminal labels also retain memory. All terminal branches remain
in the output; none is silently conditioned away. Let M continue, A terminate,
and C output forced abort, with M+A the native complete instrument. Then

 K=gamma M,       E=gamma A+delta C,
 O=E+O K=E(I-K)^-1.

The true completed terminal instrument O contracts the direct-sum quotient norm
and terminates almost surely by the paid clock. Its memory output permits
continuation and reuse. The learned linear predictor is
Ohat=Ehat(I-Khat)^-1. It may be signed and has no claimed CP realization.

If gamma e<delta, ||Khat||<=gamma(1+e)<1, and

 ||Ohat-O|| <= gamma e/(delta-gamma e).                         (1)

Proof: subtract completions using TRUE O after each discrepant branch:
DeltaO=(DeltaE+O DeltaK)+DeltaO Khat. Mutually exclusive terminal and continuing
primitive errors have JOINT sum at most e. The exact abort has zero error;
contractive O after continuation therefore gives
||DeltaE+O DeltaK||<=gamma e. Resolving on the right supplies only one inverse
gap delta-gamma e and proves (1). A naive independent resolvent subtraction
would lose an unnecessary second 1/delta. Two bounded Luna checks confirmed
this algebra and the joint-error/complete-quotient conditions; owned proof is
given here rather than inherited as a theorem.

The result is uniform over all such finite controllers using the same acquired
library. It does not extend to arbitrary new controls or an external coherent
reference. No complete/diamond norm is asserted: classical direct sums suffice.
If x0 has quotient error eta0, operation prediction error is at most
b+(1+b)eta0 for b in (1). For success mass p>0 and branch error epsilon<p,
normalized conditional continuation error is at most 2epsilon/(p-epsilon).
Rare events still pay their inverse probability and shot cost.

5. Costs and a nonvacuous route for selected operations

With C controller states, a dense compiler uses O((Cr)^3) arithmetic and
O((Cr)^2) storage; finite rational counts and rational clock/controller weights
allow rational elimination when invertible. Float64 prototype arithmetic is a
separate numerical approximation, checked by residuals/condition numbers.
Precision must resolve the measured H margin and the learned resolvent gap;
arithmetic complexity is not a bit-complexity theorem. All primitive outcomes
and clock randomness are paid. Expected native calls per physical invocation
are <=gamma/delta; controller success can reduce this. Tail after n calls is
<=gamma^n. An imperfect clock needs its own joint instrument error.

The generating operation F(z)=(delta C+gamma z A)(I-gamma z M)^-1 retains
terminal memory and counts interventions. F(1)=O. Its derivative at 1 gives
the first-moment cost; such costs have a separate O(e/delta^2) sensitivity and
are not covered for free by the terminal-law bound (1).

For a chosen operation C, direct macro tomography is an alternative: from each
core preparation actually execute C, then each core future test; estimate raw
joint terminal-label/test probabilities H_C,b. B_C,b=H_C,b H^-1 is reusable
on arbitrary reachable inputs, including states left by earlier macros. This
does not assume a known physical realization and pays a NEW set of experiments
per macro. It avoids assuming a useful all-controller primitive certificate.
The same error formula as section 3 applies with macro entry errors, plus
the observed H uncertainty. Directly acquiring an unconditioned contracting
control word can also certify a visible operational reset; it neither changes
the past acquisition's supplied full-reset cost nor manufactures bath access.

6. Relation to incumbents and unresolved scientific value

Controlled PSR/OOM/weighted-automaton spectral realization is precisely the
count-to-B component; an equally informed implementation can use this compiler
and the same proof. Process-tensor/MPO learning and quantum-process
identification already learn finite memory under their own legal interventions,
dimension/conditioning and repeatability assumptions. No separation from these
incumbents is proved. The contribution of this construction is a joined-up,
explicitly paid acquisition/quotient-norm/adaptive-operation contract, not a
new universal learner. No original-priority claim is established.

Its central boundaries are known finite architectural rank, stationarity,
repeatable acquisition starts or an ACQUIRED reset, and conditioning. Approximate
low rank with unknown hidden tails needs a separate all-future approximation
theorem; a small empirical singular value is insufficient. No resolution of
canonical arbitrary-source HMM learning, no general nonlinear physical process
compiler, and no practical or foundational advantage have been established.

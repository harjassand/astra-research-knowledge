6. The actual query algorithm and finite-bit costs
The online algorithm is short:
Read the selected edge columns of Y and the selected entries of z_hat.
Form M_hat = Y_Sᵀ Y_S + diag((1-d_e)/(d_e w_e)).
Solve M_hat x = z_hat_S using exact rational linear algebra.

If the system is inconsistent, return infinity.
Otherwise return c_hat + z_hat_Sᵀ x, rounded to the output precision.

When the system is consistent, any solution gives the same quadratic form; computing an explicit Moore–Penrose inverse is unnecessary.
Input acquisition and rounding
The graph, weights, terminal labels, and each damage scenario are explicit inputs. Reading them is charged.
For convenient finite arithmetic, initially replace each positive rational weight by a dyadic number satisfying
\[
(1-\tau)w_e\le\bar w_e\le(1+\tau)w_e,
\]
with \(\tau\) a small fraction of \(\varepsilon\).
This is safe uniformly over all damage queries, because multiplication by \(1-d_e\ge0\) preserves the same inequalities. Zero conductances after complete failure remain exactly zero, so connectivity is unchanged. The resistance error from this rounding is bounded by the corresponding multiplicative energy inequalities.
Use these dyadic weights consistently throughout preprocessing. Store the dyadic physical flows \(j\), rather than independently rounding their divided values \(j_e/\bar w_e\). The divisions needed by a query are performed as rational arithmetic.
Required solve precision
Let \(\rho=w_{\max}/w_{\min}\). The tree repair satisfies
\[
\|W^{-1/2}T\|\,\|BW^{1/2}\|
\le n\sqrt{2m\rho}.
\]
Thus, with
\[
C_T=1+n\sqrt{2m\rho},
\]
a baseline potential error bounded by
\[
\|v-u\|_L\le\frac{\eta}{C_T}\sqrt c
\]
is sufficient for (20).
For each sketch row, solve accurately enough that its normalized flow error is \(O(\theta/\sqrt q)\). Summing those errors in Frobenius norm gives the operator bound used in (16).
These tolerances require additional bits proportional to logarithms of \(n,m,\rho,q,\varepsilon^{-1}\), not to the reciprocal of a damaged-network eigenvalue.
The solve quality can be checked from a residual. For example, the grounded Laplacian satisfies
\[
\lambda_{\min}(L)\ge w_{\min}/n^2,
\]
so
\[
\|v-L^{-1}b\|_L^2
\le
\frac{n^2}{w_{\min}}\|Lv-b\|_2^2.
\tag{27}
\]
A suitably conservative residual threshold is explicitly computable. Solver calls can be repeated until this certificate passes; this is why the preprocessing bound is stated as expected work.
Bit, memory, and randomness bounds
Let \(b_{\rm in}\) bound the initial coefficient bit lengths. Working numbers need bit lengths polynomial in
\[
b_{\rm in}+\log\frac{mnq}{\varepsilon\delta}.
\]
The only large linear systems are the \(q+1\) preprocessing Laplacian solves. Their cost, the \(O(mq)\) sparse/tree operations, and coefficient arithmetic give
\[
\boxed{
P_{\rm bit}
=
\widetilde O(mq)\,
\operatorname{poly}(b_{\rm in}),

with the displayed logarithmic precision parameters included in the suppressed factors.

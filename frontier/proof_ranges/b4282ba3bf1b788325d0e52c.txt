## 7. Sharpness with an exactly unchanged quantum reference

This is the decisive converse construction. It replaces the longer varying-marginal construction retained in the earlier checkpoint.

Fix faithful \(C\) on \(R_0\otimes A\) with trace one, a nonzero block column \(B\) with \(\operatorname{Tr}_A B=0\), and a faithful state \(\tau\) on \(A\). Enlarge the reference to \(R=R_0\oplus\mathbb C r\). For \(0<p<1\), \(q=1-p\), define
\[
\omega_p=\begin{pmatrix}qC&0\\0&p\tau\end{pmatrix},
\qquad H_p=\begin{pmatrix}0&\sqrt{pq}B\\\sqrt{pq}B^*&0\end{pmatrix},
\qquad\rho_{p,t}=\omega_p+tH_p. \tag{7.1}
\]
These are states for sufficiently small \(|t|\). Indeed the Schur complement is
\[
p(\tau-t^2B^*C^{-1}B)\succeq0, \tag{7.2}
\]
which permits a nonzero interval of \(t\) **independently of \(p\)**. The trace is one, and
\[
\operatorname{Tr}_A H_p=0. \tag{7.3}
\]
Thus all states in (7.1) have exactly the same reference marginal. Moreover, the perturbation is off-diagonal in the reference decomposition, so \(\operatorname{Tr}_R H_p=0\) as well: their input marginals also agree exactly.

For each fixed \(p\), Taylor expansion at the faithful \(\omega_p\) gives
\[
D(\rho_{p,t}\|\omega_p)=\tfrac12t^2g_{\omega_p}(H_p)+O_p(t^3). \tag{7.4}
\]
Diagonalize \(C\) and \(\tau\), with eigenvalues \(\lambda_j>0\) and \(\nu_a>0\). Write \(B_{ja}\) in these eigenbases. The divided-difference formula gives the exact expression
\[
g_{\omega_p}(H_p)
=2pq\sum_{j,a}|B_{ja}|^2
\frac{\log(q\lambda_j)-\log(p\nu_a)}{q\lambda_j-p\nu_a}. \tag{7.5}
\]
The quotient is interpreted continuously if the eigenvalues coincide. Since there are only finitely many terms,
\[
\lim_{p\downarrow0}\frac{g_{\omega_p}(H_p)}{2p\log(1/p)}
=\sum_{j,a}\frac{|B_{ja}|^2}{\lambda_j}
=q_C(B). \tag{7.6}
\]
After \(\mathcal N\), the same calculation applies with
\(C'=\mathcal N_{R_0}(C)\), \(B'=\mathcal N(B)\), and \(\tau'=\mathcal N(\tau)\), all restricted to the fixed output support. It follows that
\[
\lim_{p\downarrow0}\lim_{t\to0}
\frac{D(\mathcal N_R\rho_{p,t}\|\mathcal N_R\omega_p)}{D(\rho_{p,t}\|\omega_p)}
=\frac{q_{C'}(B')}{q_C(B)}. \tag{7.7}
\]
No limits have been interchanged: take the local perturbation limit first for each \(p\), and only then send \(p\) to zero. The input quadratic form is strictly positive. Every pair used in (7.7) has exactly equal reference marginals. Therefore
\[
\eta_D^c\ge\eta_{\mathrm{rect}}=\eta_G=1-1/M. \tag{7.8}
\]
The upper bound proves equality.

For the additional CMI assertion, let uniform classical \(U\in\{-1,+1\}\) select \(\rho_{p,t}\) or \(\rho_{p,-t}\). Their average is exactly \(\omega_p\), and the two partial-trace identities give \(I(U;R)=I(U;A)=0\). Their input and output mutual informations are the averages of the two relative entropies against this common average, so (7.4)--(7.7) give the same limiting ratio. By Lemma 4.1 one needs \(\dim R_0\le m^2\), and the construction adds only one dimension.

Since equal-reference pairs are allowed in (2.2), all three coefficients have the claimed value. This completes the proposed proof. \(\square\)

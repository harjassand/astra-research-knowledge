## 8. Changed compatible counterexample search

The numerical representation was changed to complex carrier-envelope potentials

    phi(x,y)=sum_(n in N) z_n(x) exp(i n y),

where each z_n is a continuous periodic piecewise-linear complex envelope. This preserves genuine gradient compatibility. Uniform and strongly nonuniform x meshes allow localized gradients; multiple carriers produce interactions not covered by the one-carrier theorems. A constant invertible input transformation permits deformed periodic cells.

On each x interval the gradient is linear in the affine local coordinate. Three-point Gauss integration therefore integrates the quartic exactly at the representation level. The y grid has more than four times the largest carrier magnitude, avoiding Fourier aliasing for all moments used. Floating arithmetic and optimization errors remain.

The exactly certified G in (3.6) was used throughout. E|Dphi|^4 was normalized to one. All four affine directions were eliminated; regularization was used during the solve, while retained states with a positive Hessian were reevaluated using the unregularized quadratic form.

Six completed configurations, each with 2000 updates, produced these smallest directly reevaluated positive gaps:

| Carriers | Envelope nodes | Grading parameter | Gap |
|---|---:|---:|---:|
| 1,2 | 32 | 0 | 1.1738424947325867 |
| -1,1 | 32 | 0 | 0.8089814800668467 |
| 1,2 | 48 | 3 | 1.1404595701552174 |
| -2,-1,1,2 | 40 | 0 | 0.733720660453478 |
| 1,2,3 | 48 | 2 | 1.0891847605782925 |
| -3,-1,1,2 | 48 | 4 | 0.9924671033966204 |

The sixth configuration was completed separately after a tool timeout interrupted a batch. The final JSON contains exactly the six completed configurations. Initial 200-update runs are retained separately. Complete nodes, interval widths, input transformations, affine backgrounds and moment diagnostics are in the JSON. These are exploratory floating-point results, not exact witnesses or lower bounds. No negative gap was found. The best new value is not lower than the prior 512-triangle witness (~0.615); no empirical improvement over that witness is claimed.

The new analytic theorem explains why all single-carrier complex-envelope searches in the invariant quartic cone are futile as counterexample searches. The retained multiple-carrier runs lie outside that exclusion. More runs converging to positive values do not prove the unresolved multiple-carrier class positive.

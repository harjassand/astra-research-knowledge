## 7. Actual resource requirements

Dense elimination requires \(O(m^3)\) rational arithmetic operations. The provided implementation stores every routing table and therefore uses \(O(m^3)\) rational entries, not \(O(m^2)\) storage. Each sample uses \(O(m^3)\) count updates/scalar variates plus its matching work. These operation counts do not make arbitrary-size integers unit-cost; Section 6 accounts for their bit lengths.

The method needs the kernel coefficients. It does not supply efficient experimental tomography. A synthetic instance with \(1-\rho(XK)\) of order \(10^{-40}\) needs correspondingly accurate input coefficients. Such benchmarks test the encoded mathematical interface, not the feasibility of obtaining those coefficients or preparing that energy in a laboratory.

The exact DP includes all \(h\) herald photons in its complexity. Binary encoding of an exponentially large herald count does not magically make the present DP polynomial. The polynomial extension below is polynomial in the **numerical** herald count \(h\), not merely \(\log h\).

## 8. What the OpenAI perfect-matching result supplies

The pinned OpenAI manuscript [6] states an FPRAS for perfect matchings in simple unweighted general graphs. It does not directly promise a compressed weighted or loop-hafnian interface. Those interfaces require reductions.

The source mechanisms examined here include the tree-bag/vertex-scaling architecture and the original signed cell identity and demand-encoding proof. In the latter, a rare guide-event mass \(p_X\) is retained in a weighted demand bound and cancels the \(1/p_X\) introduced by conditional Jensen. The proof does not lower-bound the rare probability. Its two-coordinate energy inequality is separately lifted to a replicated product chain. This source result is not re-proved, implemented or kernel-built in the present package.

### 8.1 Compact rational-weight gadget

For rational pair weights \(w_e\), clear denominators to obtain positive integers \(W_e=Dw_e\). Every perfect matching uses the same number of edges, so this only multiplies its weight by a common power of \(D\).

Construct a simple DAG with exactly \(W_e\) source-to-target paths and \(O(\log W_e)\) vertices. Reading the binary expansion, replace a count \(q\) by \(2q\) using two distinct intermediate routes; add one direct source edge for a one bit.

For each DAG vertex \(i\), create internal vertices \(L_i,R_i\) and an identity edge \(L_iR_i\). For each directed DAG edge \(i\to j\), add \(L_iR_j\). Connect the original graph edge's ports \(u,v\) to \(R_s,L_t\), respectively.

When neither port is matched into the gadget, acyclicity forces the unique identity matching internally. When both are matched into it, the internal alternating path follows one source-to-target DAG path, giving exactly \(W_e\) completions. Exactly one used port is impossible by parity. The gadget is simple, unweighted and has size polynomial in the binary weight length. Thus it does not expand an integer weight into that many parallel edges.

`matching_gadgets.py` implements this construction. Tests exhaust weights 1 through 127 in three boundary states and test 20 complete rationally weighted four-vertex reductions.

### 8.2 Singleton reduction

For a fixed number \(k\) of singleton tokens, add \(k\) labeled dummy vertices. Connect token \(i\) to each dummy with weight \(t_i\), keep all original pair weights, and put no edges among dummies. A perfect matching gives a pair/singleton configuration, with exactly \(k!\) dummy labelings. Hence

\[
 L_r(S,t)=\sum_{\substack{0\leq k\leq 2h\\k\equiv2h\pmod2}}
 \frac{Z_{\rm PM}(G_k)}{k!}.
\tag{8.1}
\]

All summands are nonnegative. Relative approximations therefore sum safely. Deterministic matching-existence checks on the support graphs detect zero partition functions; an approximate counter returning zero on a bad random tape is not used as a proof of impossibility.

### 8.3 Sampling and composed guarantee

Self-reduction evaluates the positive branches of (5.2) with approximate partition functions and samples a branch proportional to those estimates. Allocate relative error \(O(\varepsilon/(h+1))\) per step and enough confidence to cover the polynomial number of graph-counter calls. A coupling bounds the accumulated matching error by its allocated portion of \(\varepsilon\).

**Composition theorem, using the counting guarantee stated in [6].** On the stated positive Gaussian input class, there is a randomized \(\varepsilon\)-TV sampler for arbitrary nonzero photon heralds in

\[
 \operatorname{poly}(L,m,h,\varepsilon^{-1})
\]

bit time, without a numerical-energy promise and without inverse herald probability. This is a consequence of the imported counting theorem plus the explicit reductions and reconstruction proved here. It is not a claim that a practical large-herald FPRAS was executed. The tested backend remains the exact DP of (5.2).

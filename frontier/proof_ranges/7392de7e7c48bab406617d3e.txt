## 5. New obstruction: the generic occupation-pair compiler already contains Exact Cover

Define a restricted computational problem. Input is a list of positive diagonal
one- and two-site density templates with binary rational coefficients, a specified
hopping pair p-q, and the admitted code family

    C_x = span{|p=1,q=0,x>, |p=0,q=1,x>}, x in {0,1}^n.

Question: is there an x for which every nuisance template restricts to a scalar
on C_x? Other hopping is off. This is existence of an invariant computational
occupation-pair sensor, not of every conceivable coherent/QEC/ancilla code.

**Proposition C.** This decision problem is NP-complete, already for templates
whose coefficients are 0 or 1 and whose individual terms have locality at most 2.

**Proof.** Let A be an Exact Cover incidence matrix with rows indexing universe
elements and columns indexing sets. Exact Cover asks for x in {0,1}^n satisfying
Ax=1. Introduce sites p,q and n spectator sites. For row l use

    Q_l = n_p sum_i A_li n_i + n_q.

On the first basis state its eigenvalue is (Ax)_l; on the second it is 1.
The unknown hopping maps these two states into each other and leaves x unchanged.
Thus the pair is nuisance-null for every coefficient exactly when Ax=1.
The reduction has polynomial size and only nonnegative 0/1 local terms. A bit
string x is a polynomial-size witness; evaluating all labels is polynomial in
the explicit incidence length, proving membership in NP. QED.

Each unknown coefficient multiplies its entire displayed Q_l: its grouped local
terms have a known shared coefficient. This proof does not assert hardness when
every individual monomial has an independently unknown coefficient instead.

There is a pure two-body variant with Q_l=n_p sum_i A_li n_i+n_q n_r, **only if
the admission class requires the reference spectator r to be occupied in both
basis states**. Then the same proof holds. If r may instead be empty, x=0 is a
trivial protected pair, so omitting the occupancy condition would make this
reduction false. Neither variant establishes hardness of the original pure
degree>=2 class allowing an empty background: Proposition A is a cheap sufficient
compiler for that class. Neither variant proves hardness for the most general
coherent sensor code, for approximate/noisy codes, for bounded-degree geometric
graphs, or for every algorithm allowed to abandon the stated code family.

The obstruction is useful because it identifies an explicit difference in the
input/control/admission contract that turns a four-pair enumeration into a hard
search. A scalar nullspace written after full Hilbert expansion does not evade
that compressed-input cost. It does not prove P differs from NP; the usual
conditional interpretation of NP-completeness applies.

2. Diffusion bound for every state
----------------------------------
Fix r>1 and set V(n)=sum_i r^(n_i). For an undirected edge with counts u,v,
the sum of the two directed generator contributions to V is exactly

    D[(r^-1-1)(u r^u+v r^v) + (r-1)(u r^v+v r^u)].

This remains valid when either count is zero because its outgoing rate then
vanishes. Since the exponential is increasing,

    u r^u+v r^v-u r^v-v r^u = (u-v)(r^u-r^v) >= 0.

Multiplying by r-1>0 proves the edge bound

    edge contribution <= D(r+r^-1-2)(u r^u+v r^v).

Summing each undirected edge once yields

    L_diff V(n) <= D(r+r^-1-2) sum_i deg(i)n_i r^(n_i)
                <= 3D(r+r^-1-2) sum_i n_i r^(n_i).

No population ordering, finite cap, stochastic simulation, or moment assumption
is used in this pointwise inequality. Symmetry of the two directed rates with
the same D is essential and holds in the supplied graph.

Birth and death at site i contribute exactly

    r^(n_i)[b(n_i)(r-1)+a(n_i)(r^-1-1)].

Consequently, at every n in N_0^8,

    LV(n) <= sum_i r^(n_i) q(n_i) <= 8K,

where

    q(m) = b(m)(r-1)+a(m)(r^-1-1)+3Dm(r+r^-1-2),
    K    = max_{m in N_0} r^m q(m).

The maximization domain is explicitly the nonnegative integers. The finite
enumeration below is not a maximization over real m.

4. Localization, stopping and nonexplosion
-----------------------------------------
It is not necessary to assume Dynkin's formula for the unbounded process.
For any integer N>max_i n_i(0), stop the minimal jump process at

    tau_N = inf{t>=0 : max_i n_i(t)>=N}.

Every transition changes any individual coordinate by at most one. Thus,
before tau_N every coordinate is at most N-1; at tau_N every coordinate is
at most N and at least one equals N. The stopped process can be constructed
directly as a finite CTMC on {0,...,N}^8 with all reached exit states absorbing.
All its rates are finite and bounded. This establishes its nonexplosion and
ordinary finite-state Dynkin identity without presupposing a nonexplosive
unbounded process.

For any finite T>=0, finite-state Dynkin gives

    E V(X_(T wedge tau_N))
       = V(n(0)) + E integral_0^(T wedge tau_N) LV(X_s) ds
       <= V(n(0)) + 8K T.

On {tau_N<=T}, the stopped V is at least r^N (indeed at least r^N+7).
Nonnegativity elsewhere therefore implies

    P(tau_N<=T) <= [V(n(0))+8KT]/r^N.                 (*).

Explosion cannot occur while the chain stays inside any finite box: the rates
there are bounded, so a Poisson process with a finite dominating rate bounds
the number of jumps there. Therefore explosion by T would require tau_N<=T
for every N. For fixed T, the right-hand side of (*) tends to zero as
N->infinity. The minimal unbounded CTMC is nonexplosive. Applying the same
argument from any finite initial vector establishes this for every state in
N_0^8, not just the initial vector used for the numeric bound.

At n(0)=(50,...,50), V(n(0))=8r^50. For N=163 and T=1, (*) becomes

    P(sup_(0<=t<=1) max_i n_i(t)>=163)
       <= epsilon := [8r^50+8K]/r^163 < 1/10^9.

The strict comparison is checked using exact integer fractions. Stopping the
original process on first target entry can only reduce its overflow probability.

6. Suppressed cap versus absorbing-overflow projection
------------------------------------------------------
For a suppressed cap, preserve all transitions staying in the box and suppress
every outward transition. This is exactly the source's cap=162 convention:
birth is zero when the site's count is already >=162, and diffusion into a
destination with count >=162 is zero. Starting inside the box, both processes
can use common reaction clocks until the first original overflow event. A
forbidden original jump is then a null event for the suppressed chain. Before
that first discrepancy their full paths and target-entry flags agree.

For any event determined by the path through time 1, this coupling gives

    |P_original(event)-P_suppressed(event)| <= P(tau_163<=1) <= epsilon.

In particular the exact suppressed-chain first-hit probability p_cap satisfies
|p-p_cap|<=epsilon. This is an absolute bias statement. Suppression alone gives
no one-sided lower bound: for example, suppressing diffusion into a full site
also keeps a particle at its donor, so a componentwise monotonic comparison is
not automatic. Sampling uncertainty and implementation/numerical error are
additional to this exact-law bias.

For an absorbing-overflow FSP, instead make target success B and overflow O
absorbing. At each transient state in box\A, retain every original transition
rate, send a target transition to B, send an outward transition to O, and keep
the full original negative diagonal (including those hazards). Then

    p_B = P(tau_A<=1, tau_A<tau_163),
    p_O = P(tau_163<=1, tau_163<tau_A).

The target and overflow cannot be reached simultaneously because their sets
are disjoint. Successful original paths omitted from p_B must overflow first,
so

    p_B <= p <= p_B+p_O <= p_B+epsilon.

These are statements about exact FSP probabilities. If a numerical solver
only certifies p_B in [L,U], the corresponding bound is [L,U+epsilon], clipped
to [0,1]. A raw floating-point p_B is not automatically a certified endpoint.
The exact target-absorbed FSP state count, including B and O, would be

    163^8-16^8+2 = 498311410023153827.

The supplied fsp_reference.py implements this absorbing target/overflow logic
only for TWO sites. Its local falling-factorial rates and one diffusion edge
in each direction are consistent with that two-site diagnostic. It does not
construct or solve the supplied full eight-site problem, and this audit does
not run it. Its expm_multiply calculation is explicitly floating point.

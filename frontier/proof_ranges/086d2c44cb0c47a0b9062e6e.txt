A classical damage-sensitivity oracle that remains accurate near disconnection
The strongest result from this investigation is a classical data structure for repeatedly evaluating sparse damage to a transport network.
After preprocessing a connected, weighted graph and a fixed pair of terminals, it answers:
What is the new terminal resistance when any \(k\) selected conductances are weakened by arbitrary amounts, including complete removal?

The construction gives relative accuracy even arbitrarily close to disconnection, correctly identifies infinite resistance, and supports arbitrarily many adaptively chosen hypothetical scenarios. Each query involves only the selected edges and a small linear system—not another solve on the entire graph.
Writing
\[
q=O\!\left(
\frac{k\log(em/k)+\log(1/\delta)}{\varepsilon^2}
\right),
\]
the principal costs are
\[
\boxed{
\begin{aligned}
\text{Expected preprocessing}&:\quad \widetilde O(mq),\\
\text{Stored numerical values}&:\quad O(mq),\\
\text{Worst-case query work}&:\quad O(qk^2+k^3),
\end{aligned}}
\tag{1}
\]
with the finite-bit factors specified below. Here \(m\) is the number of edges, \(\varepsilon\) is the requested relative error, and \(1-\delta\) is the probability that every admissible query is answered correctly.
The mechanism is to preserve conservation laws exactly while approximating circulating flows. This prevents numerical errors from creating fictitious conductance across a nearly broken cut.
The proof below supports this algorithmic construction. Historical originality and practical superiority remain unestablished. The attached code checks the identities and failure cases using dense reference calculations; it is not a production implementation of the near-linear preprocessing bound.
1. Target selection and prior-art boundary
I screened three non-quantum directions. In stochastic chemical simulation, eliminating repeated visits to trapping states is already an established kinetic-path-sampling operation. In parametric partial differential equations, random sketches of reduced solution and residual spaces are also established. Neither operation, by itself, was a credible new discovery. arXiv
Sparse network damage exposed a more specific opportunity: low-rank updating is inexpensive only after acquiring the necessary inverse information, and approximate inverse information can become unreliable near a cut.
The baseline is already strong. Spielman–Srivastava give near-linear preprocessing for static effective-resistance queries. Ronellenfitsch and collaborators give cycle-space formulas for multiple outages and arbitrary changes in line reactance. Thus neither static resistance sketching, cycle duality, nor the Woodbury identity is claimed as new here. arXiv
The potentially new content is their operational combination with exact conservation in both the sketch and the approximate reference current, yielding one compressed structure that remains valid for all sparse weakening scenarios, without a lower bound on the conductance remaining after damage.

2. Exact computational contract
The input is an explicit connected undirected graph \(G\), with \(n\) vertices, \(m\) edges, positive rational conductances \(w_e\), and distinct fixed terminals \(s,t\).
A query specifies a set \(S\) of at most \(k\) edges and rational damage fractions
\[
0<d_e\le1,\qquad e\in S.
\]
The modified conductances are
\[
w_e'=
\begin{cases}
(1-d_e)w_e,&e\in S,\\
w_e,&e\notin S.
\end{cases}
\tag{2}
\]
A zero damage fraction can simply be omitted.
Let \(c_d\) denote the terminal resistance. It is \(+\infty\) when \(s\) and \(t\) become disconnected; disconnected components containing neither terminal do not force an infinite answer.
Derived theorem
For \(0<\varepsilon<1/2\) and \(0<\delta<1\), the construction produces a randomized data structure with the costs in (1), such that, with probability at least \(1-\delta\), simultaneously for every query:
\[
\boxed{
c_d<\infty
\implies
(1-\varepsilon)c_d\le\widehat c_d\le(1+\varepsilon)c_d,
}
\tag{3}
\]
and
\[
\boxed{
\widehat c_d=\infty\quad\Longleftrightarrow\quad c_d=\infty.
}
\tag{4}
\]
The success event covers all supports of size at most \(k\) and all their rational damage fractions. Consequently, later queries may depend on earlier answers—or on the stored sketch itself—without accumulating an additional failure probability.
This is a sensitivity data structure: each query modifies the same reference graph hypothetically. It is not an assertion about unrestricted online updates to an evolving graph.

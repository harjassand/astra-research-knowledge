The suffix + denotes restriction to |0>^perp, not the positive part of an arbitrary matrix. Finite dimension and a unique zero-cost ray make H_+ invertible; E > 0 makes L bounded. Equivalently,

    alpha = max_{w: <w|H|w> > 0} <w|L|w>/<w|H|w>,
    L <= alpha H.

One can choose the maximizing unit vector w in the excited subspace. If L = 0, then E = I, alpha = beta = 0, and no probe can decrease the no-click probability below 1. The nontrivial statements below assume L != 0, hence alpha > 0.

For r parallel cells define

    H^(r) = sum_i H_i,    L^(r) = sum_i L_i,
    Q(rho) = Tr rho H^(r),
    p0(rho) = Tr rho E^(tensor r) = Tr rho exp(-L^(r)).

The charged quantity is expected input cost of the prepared probe. It is not a hard spectral-energy constraint and does not automatically include preparation work, driving references, resets, timing, or receiver work.

If the null experiment outputs the pure state |v>^(tensor r), p0 is precisely the minimum miss probability at zero false-alarm probability. A rejection effect T with zero null expectation must annihilate the null vector. The largest admissible rejection effect is I-|v>^(tensor r)<v|^(tensor r), so the corresponding miss effect is the null projector.

## 2. Universal entangled-probe bound: proved

For any r-cell density operator, including arbitrary entanglement,

    p0(rho) >= exp(-alpha Q(rho)).

Proof: apply scalar Jensen to the spectral distribution of L^(r) in rho:

    Tr rho exp(-L^(r))
      >= exp(-Tr rho L^(r))
      >= exp(-alpha Tr rho H^(r)).

The second step uses L^(r) <= alpha H^(r), obtained by summing local positive inequalities. No operator monotonicity of exp is used. Indeed, inferring exp(-L) >= exp(-alpha H) directly from L <= alpha H would be invalid for noncommuting matrices; that inference is unnecessary here.

The bound is statewise and therefore applies to a maximum per-codeword expected cost budget. It also gives an average no-click-mass bound under average expected cost, by another scalar Jensen.

## 3. Spectral-typical achievability: proved under expected cost

Choose a maximizing excited unit vector w, and write

    h = <w|H|w> > 0,    ell = <w|L|w> = alpha h.

Let delta_r -> 0 with r delta_r^2 -> infinity. For example delta_r proportional to r^(-1/4) works. Let P_r be the spectral projector of L^(r) onto

    [r(ell-delta_r), r(ell+delta_r)].

Put psi_r = w^(tensor r), eta_r = <psi_r|P_r|psi_r>, and

    chi_r = P_r psi_r / sqrt(eta_r).

The spectral distribution of L^(r) in psi_r is the sum of r iid bounded random variables, each having the spectral distribution of L in w. Thus eta_r -> 1. A concrete Hoeffding bound is

    1-eta_r <= 2 exp(-2 r delta_r^2/||L||^2).

The pure-state trace-norm distance is

    || |chi_r><chi_r| - |psi_r><psi_r| ||_1
      = 2 sqrt(1-eta_r).

Consequently

    |Q(chi_r)-rh| <= 2r ||H|| sqrt(1-eta_r) = o(r).

This cost estimate is valid even when H and L do not commute. On the range of P_r,

    exp(-L^(r)) <= exp(-r(ell-delta_r)) I,

so

    p0(chi_r) <= exp(-r(ell-delta_r)).

Together with the universal lower bound,

    (-log p0(chi_r))/Q(chi_r) -> ell/h = alpha.

Therefore the supremum of -log(p0)/Q over all finite parallel blocks is exactly alpha. This does not assert that a finite block attains the supremum. Repeating any fixed block whose ratio exceeds alpha-epsilon establishes the leading small-miss cost law

    inf{Q: p0 <= epsilon} / log(1/epsilon) -> 1/alpha

as epsilon -> 0. Similarly, if C(Q) is the infimum no-click probability over all block lengths with expected cost at most Q, then

    -log C(Q)/Q -> alpha    as Q -> infinity.

The construction is a valid normalized pure state. It is generally entangled when filtering a superposition of distinct local L eigenvalues. Entanglement is not required when a maximizing w is already an L eigenvector.

### What the construction does not prove

It does not establish the same coefficient with a hard support constraint rho supported on {H^(r) <= Q}. L-typical projection preserves expected H cost; it need not preserve a hard H spectral budget. Applying a subsequent H projection can change an exponentially small p0 by a much larger additive amount, so trace-distance closeness alone does not repair that gap.

Nor does the construction show exact saturation at each fixed finite Q. For example, for the commuting qubit pair

    H = diag(0,1),    E = diag(1,exp(-a)),    a > 0,

the exact optimum at expected cost Q = k+t, k a nonnegative integer and 0 <= t < 1, allowing arbitrary vacuum padding, is

    C(Q) = (1-t)exp(-ak) + t exp(-a(k+1)).

This follows from the lower convex envelope of exp(-a n) on integer excitation number n. In particular, for 0 < Q < 1,

    C(Q) = 1-Q+Q exp(-a) > exp(-aQ).

The exponent theorem is an asymptotic large-cost theorem. With the hard spectral budget Q < 1 in this example, only the vacuum is allowed and C(Q)=1.

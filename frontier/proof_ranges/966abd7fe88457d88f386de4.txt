## 3. Finite controls identify only a finite span

For a finite experiment, index each distinct waveform/readout-time pair by \(a=1,\ldots,J\), with actual program \(p_a\). Its response functions on an unordered history \(x\) are
\[
f_{a,k}(x)=[z^k]\prod_{i=1}^n\bigl(1-p_a(A_i)+zp_a(A_i)\bigr).
\tag{4}
\]
The observed histogram entries are the linear functionals \(y_{a,k}=\int f_{a,k}\,d\mu\). Since \(\sum_k f_{a,k}=1\), a complete histogram contributes at most \(n\) independent real numbers.

**Theorem 2 (finite-span criterion and null-pair witness).** Let
\[
\mathcal V=\operatorname{span}\bigl(\{1\}\cup\{f_{a,k}:1\leq a\leq J,\ 0\leq k\leq n\}\bigr).
\]
A bounded decision functional \(g(x)\) has the same expectation under every pair of ancestry laws with these observed histograms if and only if \(g\in\mathcal V\).

If \(g\notin\mathcal V\), there are two distinct finite-support probability laws \(\mu_+,\mu_-\) that give exactly the same observed count histogram for every measured setting but satisfy \(\mathbb E_{\mu_+}g\ne\mathbb E_{\mu_-}g\).

**Proof.** If \(g\in\mathcal V\), its expectation is the same known linear combination of the normalization and observed histogram entries for every compatible \(\mu\). Conversely, if \(g\notin\mathcal V\), the functions \(1,f_1,\ldots,f_d,g\), where \(f_1,\ldots,f_d\) form a basis for the measured span modulo constants, are linearly independent. There are \(d+2\) history points \(x_1,\ldots,x_{d+2}\) whose evaluation matrix for these functions has full rank. The \((d+2)\)-by-\((d+1)\) evaluation matrix for \(1,f_1,\ldots,f_d\) has a nonzero null vector \(\lambda\). Full rank of the augmented matrix forces \(\sum_i\lambda_i g(x_i)\ne0\), while \(\sum_i\lambda_i=0\) and \(\sum_i\lambda_i f_j(x_i)=0\) for every measured feature. The positive and negative parts of \(\sum_i\lambda_i\delta_{x_i}\) have equal nonzero mass. Normalizing those parts gives \(\mu_+\) and \(\mu_-\), the required exact null pair. \(\square\)

Consequences:

- A finite set of finite-time count observations cannot identify an arbitrary continuous ancestry law. It identifies precisely the measured response span.
- A particular decision statistic can still be obtained without reconstructing the law when its response function lies in that span. The telegraph parity statistic below is an example.
- For laws supported on \(q\) known entry-time bins, the number of unordered \(n\)-atom histories is \(M=\binom{q+n-1}{n}\), so the probability simplex has dimension \(M-1\). With \(J\) one-time whole-count histograms, injectivity requires
\[
Jn\geq M-1.
\tag{5}
\]
For \(n=4,q=5\), \(M=70\), and at least 18 such readouts are necessary. Conversely, on a known \(q\)-bin support,
\[
H_\mu(p_1,\ldots,p_q)=\sum_{\alpha_1+\cdots+\alpha_q=n}\mu_\alpha\prod_{j=1}^q p_j^{\alpha_j},
\]
where \(\mu_\alpha\) is the probability of occupancy vector \(\alpha\). These \(M\) monomials are linearly independent, so \(M\) points selected unisolvently in any open control box \((p_-,p_+)^q\) recover every coefficient from the top-count fraction alone in exact arithmetic. For the five-bin example, 70 such controls suffice; the lower bound of 18 uses all histogram bins and is only necessary, not sufficient. Both counts ignore finite precision, correlated products, calibration, and query conditioning. Neither is a lower bound for protocols returning infinitely many time-resolved observations.
- Whenever Theorem 2 supplies a null pair for a binary decision, a rule that must choose one of the two actions has worst-case error at least \(1/2\) under exact noiseless observations. More product counts cannot separate identical laws. Abstention can avoid the forced choice.

There is also a simple statistical cost floor for a fixed protocol. If the two hypotheses induce iid whole-product count laws \(q_0,q_1\), a test with both errors at most \(\alpha<1/2\) requires
\[
N D_{\rm KL}(q_0\Vert q_1)\geq 2(1-2\alpha)^2.
\tag{5a}
\]
by the testing total-variation requirement and Pinsker's inequality. If \(q_0=q_1\), the divergence is zero and no finite product count can distinguish them. This floor assumes independent product observations under a fixed protocol; it does not convert raw ion counts or correlated reaction events into independent samples.

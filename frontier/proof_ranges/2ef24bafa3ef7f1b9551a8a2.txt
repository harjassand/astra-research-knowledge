## 5. Resource accounting and the decisive boundaries

The result depends on the computational interface being stated accurately.

| Resource or operation | What the construction requires |
|---|---|
| Input acquisition | An ordinary finite program and input, encoded into \(O(n)\) rational bits |
| Objective preprocessing | One fixed finite compilation, independent of the subsequently supplied program |
| Update rule | Ordinary full-batch \(z-\nabla f(z)\), with no changing objective or gradient override |
| Bit memory at step \(t\) | \(O(n+t)\) per coordinate for the fixed instance |
| Exact simulation through \(T\) | \(T\,\operatorname{poly}(n+T)\) bit operations |
| Prediction output | A fixed-threshold decision or fixed additive accuracy for logarithmic loss decay |
| Verification supplied | General mathematical derivation plus executable exact checks of the compiler and a small example |

Several limitations are essential, not incidental.

### Absolute-error state prediction is easy

Global contraction gives
\[
\|G^Tz_0\|\le\varepsilon^T\|z_0\|.
\]

For any requested absolute tolerance \(\delta\), sufficiently late iterates can therefore be replaced by zero. Earlier iterates require only a number of simulation steps polynomial in the input size and \(\log(1/\delta)\).

Thus:

> **The theorem does not establish hardness of predicting the parameters or loss to fixed absolute error. It establishes hardness of predicting logarithmic decay.**

The distinction is part of the result. The same objective permits easy absolute-error prediction and hard rate prediction.

### Finding the minimizer is trivial

The exact answer is zero. The theorem supplies no new optimisation lower bound for obtaining a low-loss point.

What fails is inferring the **true input-specific convergence rate** from an objective whose minimizer, conditioning and global convergence bound are all already known.

### Fixed-dimensional state is not fixed memory

The number of coordinates is fixed, but their exact rational descriptions grow with computation time.

There is no claim that constant-precision floating-point hardware can simulate indefinitely, nor that an infinite computation is being performed with finite bit resources.

### The regularity and learning rate are specific

The objective is \(C^{1,1}\): continuously differentiable with globally Lipschitz gradient. It is not asserted to be \(C^2\), analytic or polynomial.

The unit learning rate is stable because
\[
1<\frac{2}{1+\varepsilon}.
\]
It need not satisfy the more conservative restriction \(1\le1/L\). The result does not automatically extend to every smaller learning rate, continuous gradient flow, or persistent numerical noise.

These restrictions prevent an unjustified escalation from the proved construction to all well-conditioned optimisation.

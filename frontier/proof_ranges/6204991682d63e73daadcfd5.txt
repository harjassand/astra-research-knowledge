# Consequence and interface comparison

Status: the finite-population proof in FINITE_POPULATION_THEOREM.md was independently reconstructed by the parent with no flaw found. This note derives further consequences and gives a bounded comparison to primary interfaces; it does not assert priority. Previous semigroup source/report files remain untouched.

## 1. What is computationally different

For a deterministic finite automaton with d states, fixed positive-support letter marginal mu, alpha=min mu, and arbitrary correlations between input letters, let R_n be its exact attainable terminal-state laws. A finite graph on D-particle histograms gives finite sets G_{D,n} such that, at **every supplied horizon n**, simultaneously,

    sup_{p in R_n} dist_TV(p,G_{D,n}) <= r_D=d/(2D),
    sup_{g in G_{D,n}} dist_TV(g,R_n) <= beta_D=d/(D alpha+d).

The proof does not use convergence of the state process, ergodicity, a fixed point, a stationary policy, or a mixing rate. All coordinate marginals remain exactly mu in the reconstructed coupling. The only approximation is terminal output TV.

Given any word-length n in binary, compute G_{D,n} by Boolean powering of the finite histogram graph. With N=binom(D+d-1,d-1) vertices, this costs O(N^3 log n) Boolean arithmetic after graph construction by a direct implementation. Therefore terminal output optimization is approximable at arbitrary supplied horizons with logarithmic dependence on n. If all finite horizons are allowed, finite graph reachability replaces matrix powering and gives a computable optimum over their union closure. Loop deletion supplies witnesses of length <=N.

These are computational theorems, not only compactness statements. Compactness of the finite-dimensional state simplex would supply a finite epsilon-net for an already known reachable closure, but would not identify which net points are reachable, compute a uniform horizon cutoff, or certify that approximate graph walks represent genuinely admissible correlated input laws.

## 2. Why the discretization is uniform in time

A per-step grid usually incurs n times the one-step error; nonexpansion does not remove the sum. For example, an identity transition on [0,1] is nonexpansive, but a grid abstraction allowing a displacement of delta at each step can creep from 0 to 1 after 1/delta steps, although the true reachable set is {0}. Refining the mesh alone never fixes unbounded-time reachability in that abstraction.

The population graph has a stronger property. Every entire graph walk corresponds to D actual input words. Its per-position discrepancy concerns only the *unconditional* letter marginal. One common mixture with a filler law of mass beta_D corrects all these marginal discrepancies at once, across an arbitrarily long walk. No resetting or repeated mixture is used. Conversely, whole-path network-flow rounding simultaneously controls all layers and has terminal error independent of the number of layers.

This two-direction argument is the substantive step. The rounding lemma itself is standard integral-flow rounding; the finite-state loop deletion is standard graph theory. A primary exposition of the floor/ceiling-capacity rounding construction appears, for example, in T. Asano's digital-halftoning survey, Section 6.3, pp.25-26:
https://www.kurims.kyoto-u.ac.jp/~kyodo/kokyuroku/contents/pdf/1185-3.pdf .

Their Section III gives exact one-step polytope projection and recursive finite-time reachability. Algorithm 1 / Theorem 3.1 samples and projects points to approximate a specified one-step set, with a probability bound as the sample count increases. Our theorem adds the special column constraints to deterministic transitions and obtains a global terminal-error guarantee through an unrestricted filler word law. It does **not** solve general stochastic-MDP distributional reachability. If a transition kernel T(y|s,a) must be obeyed conditionally, arbitrary rounding of path counts changes that kernel, and an arbitrary filler law cannot repair it while remaining a valid MDP law. The mixture repair is available precisely because the input specification consists of unconditional one-coordinate marginals.

## 4. A discriminating invariant-set example

The maximal invariant set obtained from the whole simplex does not characterize reachability from a fixed initial law. For the identity chain, every distribution is invariant, so the maximal invariant set is the whole simplex, while the reachable union from delta_0 is only {delta_0}. This is enough to separate invariant-set existence/convergence from the initialized reachable-closure computation required here.

One should also distinguish convergence toward an invariant set from finite-time entrance: the two-state chain with transitions 0->0, 1->0 or1 each with probability 1/2 has invariant limit {delta_0}, but starting at delta_1, the state law (1-2^-n,2^-n) never enters that limit set at finite n. Our theorem makes no finite-time entrance assumption.

## 5. State feedback and blind controls

The exact one-step coupling relation is

    K(s,a)>=0,  K 1=p,  K^T 1=mu,
    p'(u)=sum_{s,a:f(s,a)=u} K(s,a).

It is a rational convex polyhedral relation in (p,p'). Every correlated word law induces this relation, and every finite sequence of such flows is realizable by a state-feedback Markov policy. A PFA instead chooses one global control word independently of transition coins; that is an additional independence restriction.

A concrete gap: take two states i,j with initial law (1/2,1/2), two actions A,B with marginal (1/2,1/2), and absorbing outputs g,b. Set f(i,A)=f(j,B)=g and f(i,B)=f(j,A)=b. A blind global action, even randomly chosen independently of the state, reaches g with probability 1/2. The admissible coupling K(i,A)=K(j,B)=1/2 reaches g with probability 1, with exactly the same action marginal. Thus the blindness issue changes a constant output gap already in one step.

There is also a general obstruction to a proposed *finite, affine, uniform* blindness gadget. The graph of any fixed-length macro built from fixed unconditional marginals and finite deterministic transitions is convex polyhedral after auxiliary variables are projected out. The blind relation p' in conv{p, pSwap} for two-state identity/swap actions is not convex jointly in (p,p'): (delta_0,delta_0) and (delta_1,delta_0) belong to it, but their midpoint ((1/2,1/2),delta_0) does not. Consequently no such finite affine encoding realizes that blind relation for every supplied p. This does not rule out nonlinear encodings, unbounded gadgets, or reductions using a restricted set of initial distributions.

The QEST 2010 whole-matrix interface illustrates the distinction: Korthikanti et al. Theorem VII.2 takes a supplied finite set P of entire transition matrices and words over P, then sets P={delta_a} in its PFA reduction. It does not add independent row choices. Primary author-hosted PDF:
https://osl.cs.illinois.edu/media/papers/korthikanti-2010-qest-reasoning_about_mdps_as_transformers_of_probability_distributions.pdf (PDF p.8, Theorem VII.2).

## 6. A large horizon is sometimes necessary even at constant accuracy

This is a new derivation using classical coprime cycle periods, not a priority claim.

Take k=2^h distinct primes p_1<...<p_k. A binary DFA has an initial complete binary tree of depth h; each of its k leaves enters a cycle of length p_i. Thereafter both binary letters advance by one step on that cycle. Let mu be the fair binary marginal, so alpha=1/2. Let nu give mass 1/k to the predecessor of the entry state in each cycle.

At n<h, terminal support is disjoint from nu, so TV is one. At n>=h, any coupling selects some masses w_i on the cycles, and the cycle position in component i is completely determined by n. Its nu-target position can occur only when

    n-h+1 =0 mod p_i.

If t=n-h+1 is not divisible by p_i, the attainable law has zero mass at that component's nu-target state, whatever its selection weight w_i. Hence

    TV(p_n,nu) >= #{i:p_i does not divide t}/k.

To reach TV<=1/4 requires t to be divisible by at least 3k/4 distinct primes, and therefore

    n >= h-1 + product_{i=1}^{ceil(3k/4)} p_i.

Conversely, fair independent prefix bits select the cycles uniformly, and at a common multiple of every p_i they attain nu exactly. Thus no polynomial horizon cutoff in DFA state count can hold, even for fair binary input and constant terminal error. Using standard prime asymptotics, d=2^h-1+sum_i p_i=Theta(k^2 log k), while the necessary horizon is exp(Omega(k log k))=exp(Omega(sqrt(d log d))). The explicit product inequality is independent of those asymptotic estimates.

The phenomenon is deterministic phase alignment. It does not require Markov cutpoint oscillations, small marginal atoms, slow stochastic mixing, or an undecidability reduction. It explains why a finite graph / compressed binary-horizon computation is preferable to materializing a long coupling word.

## 7. Bounded comparison outcome

The ingredients overlap standard integral-flow rounding, automaton path polytopes, and occupation-measure control. The examined primary MDP result does not provide this exact unconditional-marginal, uniform-time interface or its shared filler repair. This bounded interface comparison is not an exhaustive literature search and establishes no novelty claim. The mathematical consequence survives even if an equivalent algorithm is later located: arbitrary-horizon exact cutpoints remain delicate, while terminal output optimization in this unrestricted-correlations model has an effective finite approximation.

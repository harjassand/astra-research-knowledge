## 2. A compatible-jet identity

Let a smooth map \(f\) have first and second derivatives at a point

\[
 x=f_{x_1},\quad y=f_{x_2},\qquad
 X=f_{x_1x_1},\quad Y=f_{x_1x_2},\quad Z=f_{x_2x_2}.
\]

All five letters are vectors in \(\mathbb R^2\). Put

\[
 A=(x\mid y),\qquad B_1=(X\mid Y),\qquad B_2=(Y\mid Z).
\]

The shared vector \(Y\) is the differential compatibility condition. Define

\[
 z_+=\begin{pmatrix}
 x\cdot X\\x\cdot Z\\y\cdot Y\\x\times Y\\y\times X\\y\times Z
 \end{pmatrix},\qquad
 z_-=\begin{pmatrix}
 -y\cdot Z\\-y\cdot X\\-x\cdot Y\\y\times Y\\x\times Z\\x\times X
 \end{pmatrix}.
\]

Here \(p\times q=p_1q_2-p_2q_1\). For six real parameters \(t_0,\ldots,t_5\), let

\[
 S(\ell,t)=
 \begin{pmatrix}
 12&10-t_0/2&25-t_0/2-t_4-3t_5&2\ell+t_3&-3\ell&-3\ell-t_2\\
 10-t_0/2&8&t_0/2+t_4+3t_5-9&2\ell+t_2&-\ell+t_1+t_2&-\ell\\
 25-t_0/2-t_4-3t_5&t_0/2+t_4+3t_5-9&t_0&t_1&t_2&t_3\\
 2\ell+t_3&2\ell+t_2&t_1&11-2t_5&1-t_4&t_4\\
 -3\ell&-\ell+t_1+t_2&t_2&1-t_4&7&t_5\\
 -3\ell-t_2&-\ell&t_3&t_4&t_5&4
 \end{pmatrix}.
\]

Define three linear one-forms on matrix space by

\[
 \theta=x\times dx+y\times dy,\qquad
 \zeta=x\cdot dy-y\cdot dx,\qquad
 \theta_a=x\times dx-y\times dy.
\]

Here \(dx,dy\) are coordinate differentials of the columns, not spatial derivatives. Set

\[
\begin{aligned}
 c_1&=-\frac{6\ell+t_1+3t_2-t_3}{4},&
 c_2&=-\frac{t_0+4t_5-20}{2},\\
 c_3&=\frac{20-t_0}{4},&
 c_4&=\ell-t_1-t_2,\\
 c_5&=\frac{4\ell+t_1+3t_2+t_3}{4}.
\end{aligned}
\]

The required cubic primitive is the compact, explicit one-form

\[
 \boxed{\alpha=c_1(u+v)\theta+c_2q\theta
                +c_3(u+v)\zeta+c_4q\zeta
                +c_5(u-v)\theta_a.}
\]

The last term is input-anisotropic. It is invariant under a quarter-turn, but not under arbitrary input rotations. The first four types occur in the prior isotropic framework [1]; the additional direction retains the anisotropy needed for the present construction. This is an extension of that framework, not a claim to have invented heat-flow correction by exact forms.

### Lemma B: exact differential correction

For every real \(\ell,t\), every matrix \(A\), and every compatible pair \(B_1,B_2\) as above,

\[
 \boxed{
 \sum_{i=1}^2 D^2F_\ell(A)[B_i,B_i]
 +(d\alpha)_A(B_1,B_2)
 =z_+^TS(\ell,t)z_++z_-^TS(\ell,t)z_-.
 }
\]

This is a polynomial identity, not an inequality or an SDP feasibility assertion. Direct expansion proves it. The standalone verifier differentiates both the quartic and the displayed one-form and verifies the identity symbolically with \(\ell,t_0,\ldots,t_5\) still independent. The parameter \(t_4\) changes the Gram representation without changing the polynomial one-form. The verifier also checks that this compact primitive has exactly the same exterior derivative as an independently acquired coordinate primitive.

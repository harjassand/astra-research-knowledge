## 10. Consequence for the proposed maximum-state lower bound

Assume the prior explicit-model candidate theorem for every fixed binary-vocabulary 2D FO+H interpretation program Q on its fixed binary hard inputs of size N:

    max target state size >= exp(c_Q N)

on at least one input in each sufficiently large opposite-answer hard pair, for a constant c_Q>0.

Let P instead use any fixed finite control, fixed relational intermediate vocabulary, and fixed finite dimensions, on these same binary inputs. The compiler produces Q with

    max target state size <= C_P (1+S_P)^(K r).

Consequently

    C_P (1+S_P)^(K r) >= exp(c_Q N),

and hence

    S_P >= exp(Ω_P(N)).

The constant can deteriorate with P, including its maximum dimension, maximum relation arity and compiled formula width. It remains a positive constant for each fixed P. The input size is unchanged, so no exponent in N is lost. No runtime bound is used.

This closes only the dimension/binary-vocabulary stage of a possible HF-program transfer. A history-independent compiler from live HF states and their operations to a fixed-dimensional relational interpretation program is a separate prerequisite. The present note neither assumes a polynomial total trace nor proves that missing HF-to-interpretation stage.

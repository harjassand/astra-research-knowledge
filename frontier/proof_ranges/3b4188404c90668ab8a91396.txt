## 3. Exact cost identity: proof by causal routing

The cost identity holds for every channel \(\mathcal N\), not only separable ones.

Let
\[
e_{\mathcal N}(k,m)
\]
be the infimum simulation error for \(k\) sequential uses of \(\mathcal N\), using \(m\) supplied ebits.

Let
\[
e_{\mathcal H}(n,m)
\]
be the corresponding infimum error for \(n\) sequential uses of the early-flag process.

Use either the unassisted definitions throughout or the definitions allowing universally returned exact catalysts throughout.

For
\[
K\sim\operatorname{Binomial}(n,p),
\]
the following finite-block inequalities hold:
\[
\boxed{
e_{\mathcal H}(n,m)
\le
e_{\mathcal N}(k,m)+\Pr[K>k],
}
\tag{10}
\]
and
\[
\boxed{
e_{\mathcal N}(k,m)
\le
e_{\mathcal H}(n,m)+\Pr[K<k].
}
\tag{11}
\]

These inequalities retain the same entanglement budget. In the catalyst-assisted case, the constructions retain the same catalyst.

### From ordinary channel simulation to the early-flag process

Take a simulator for \(k\) sequential uses of \(\mathcal N\).

For each of the \(n\) requested early-flag calls, sample the flag with probability \(p\) and issue it before accepting that call’s input.

On flag \(0\), apply \(\mathcal R\). On flag \(1\), route the input through the next available call of the \(\mathcal N\)-simulator.

This works unless more than \(k\) successes occur. On that exceptional event, use arbitrary local replacement outputs for the excess calls.

If fewer than \(k\) calls are used, complete the unused calls with dummy product inputs and discard their outputs. This completion matters for an exact catalyst: it ensures that the original simulator reaches its stipulated final return condition.

The sampled flags have exactly the ideal law, independently of the external inputs. Replacing the \(k\)-call simulator by its ideal version changes any external distinguishing probability by at most \(e_{\mathcal N}(k,m)\). With the ideal version, the only possible discrepancy is the overflow event.

This proves (10).

### From the early-flag process to ordinary channel simulation

Now take a simulator for \(n\) early-flag calls and use it to serve \(k\) requests for \(\mathcal N\).

Wait for a flag. If it is \(0\), supply a dummy product input and discard the replacement output. If it is \(1\), supply the next genuine input and return the resulting output as the next \(\mathcal N\)-output.

The genuine input is never submitted to an unsuccessful call.

After serving all \(k\) genuine inputs, complete all remaining early-flag calls with dummy inputs. If the available calls run out before \(k\) successes occur, complete the missing outputs locally.

With the ideal early-flag process, this fails only when \(K<k\). Against an approximate process, the routing procedure is an allowed causal external interaction, so its extra error is at most \(e_{\mathcal H}(n,m)\).

The complete simulated horizon is always finished; hence an exactly returned catalyst is still returned.

This proves (11).

### Passing to rates

For the upper bound, choose
\[
k=\lceil(p+\delta)n\rceil.
\]
The overflow probability in (10) vanishes exponentially. Any achievable channel-simulation rate \(r\) therefore gives an early-process rate at most \((p+\delta)r\).

For the reverse bound, choose
\[
k=\lfloor(p-\delta)n\rfloor.
\]
The shortage probability in (11) also vanishes exponentially. An achievable early-process rate \(R\) gives a channel-simulation rate at most \(R/(p-\delta)\).

Letting \(\delta\downarrow0\) proves (5) and (6).

The proof does not discard unsuccessful executions after they have received genuine inputs. It routes genuine inputs **only after a successful flag has already been issued**. That is why the reduction does not incur the error amplification associated with conditioning on a rare successful output.

### Consequence for exact catalysts

Combining (11) with the retained zero-rate strong converse gives
\[
\boxed{
m_n=o(n)
\quad\Longrightarrow\quad
e_{\mathcal H}^{\mathrm{cat}}(n,m_n)\longrightarrow1
}
\tag{12}
\]
whenever \(\mathcal N\notin\overline{\mathrm{LOCC}}\).

Thus the separation is not merely between zero error and small error. Sublinear supplied entanglement fails maximally in the asymptotic distinguishing metric, despite arbitrary exactly returned catalysts.

The return condition is essential here. The identity is not asserted for catalysts whose return is guaranteed only on one fixed, nonadaptive test ensemble: the routing constructions change the input interaction.

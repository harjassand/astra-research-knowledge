# Excluding absolutely-continuous invariant models

Status: detailed proof candidate for closed compact smooth manifolds. It modifies the source's finite-word construction and adapts its switching proof; it is not the identical symbolic system in the source paper. The boundary case is not included. I have not run an independent audit or formal verification.

## 1. Exact target

> **Theorem (AC obstruction).** There exists an ergodic invertible standard nonatomic probability-preserving system \((X,T,\mu_0)\) with zero Kolmogorov–Sinai entropy such that no closed compact smooth finite-dimensional manifold \(M\), smooth diffeomorphism \(S:M\to M\), and \(S\)-invariant ergodic probability \(\mu\ll\nu\) can realize it measurably, where \(\nu\) is any smooth positive volume on \(M\). A zero-dimensional compact manifold is finite and cannot support the nonatomic system, so the proof only needs to treat positive dimension.

The invariant density \(d\mu/d\nu\) may be merely measurable, unbounded, and may vanish on a set of positive \(\nu\)-measure. Thus the system can have no absolutely-continuous invariant model at all. Since a smooth diffeomorphism preserves the smooth-volume measure class, the Lebesgue decomposition of an invariant probability is invariant. An ergodic invariant probability is therefore either absolutely continuous or singular. Consequently every smooth model of this system, if one exists, must carry a purely singular invariant probability.

This does **not** exclude singular invariant Borel measures. It is a necessary-condition result for any remaining smooth model, not a solution of the arbitrary-measure smooth-realization problem.

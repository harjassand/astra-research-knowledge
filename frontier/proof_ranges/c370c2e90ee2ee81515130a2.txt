## A joint physical parameter is not a rank-one edge query

Take masses x=1/2,y=4. Measure a common parameter t in [0,1] setting

    a=1/8+128t, b=2+8t,

while c remains unresolved in [4,6]. The ratio F(a,b,4)/F(a,b,6) equals

    t=0:   2171/2170              = 1.0004608294...,
    t=1/4: 411538/347529          = 1.1841831904...,
    t=1:   1800674/1594629        = 1.1292118731....

The interior value exceeds both endpoints. The measured parameter makes a
positive rank-two update, despite having only one scalar outcome. Independent
coordinatewise batch reduction still holds; it does not reduce the diagonal
correlated parameter path to its two endpoints. Molecular perturbations
changing several rates require a separate theorem.

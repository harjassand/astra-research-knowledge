## 4. An exact tilted-label sampler pays the same acquisition scale

In the commuting family, the target rare probabilities, with scalar c cancelling,
are q0=1/(2-theta) and q1=2/(3-2theta). Their separation is

    q1-q0=1/[(3-2theta)(2-theta)]>=1/6.

Any algorithm producing ONE exact target label from reference p-coins must,
by(7), use expected reference draws at least1/(6theta) under case0. If each
output law is within TV epsilon of its target, the bound becomes

    E_0 N >= max(0,q1-q0-2epsilon)/theta.                      (9)

This links the new histogram interface to the collision packet's distinction
between an estimator and an actual sample. A Bernoulli factory or randomized
converter cannot freely amplify an unobserved rare weight into an O(1) output
difference. The collision theorem has its own supplied sampler/envelope and
integrated cost bound; neither theorem is contradicted.

The same certificate has a useful completion form.
Suppose \(B_1,\ldots,B_r\) already form a clique-minor model, and \(U\) is an even set of unused vertices. For each old branch set define
\[ S_i=\{u\in U:N_G(u)\cap B_i=\varnothing\}. \]
A new matching edge fails to touch \(B_i\) exactly when both endpoints lie in \(S_i\). Therefore form the forbidden-edge graph
\[ F=\overline{G[U]}\ \cup\ \bigcup_{i=1}^r K_{S_i}. \]
Use \(D=\Delta(F)\) in (1), while retaining the induced-four-cycle count of \(\overline{G[U]}\). When the certificate holds, the new matching extends the old model to
\[ K_{r+|U|/2}, \]
with all old branch sets unchanged and all new branch sets disjoint.
This is the substantive operation retained from the first approach. Its limitation is explicit: high chromatic number has not been shown to produce the required local budgets.
The matching-space argument also admits an exact elementary operation.
Suppose a perfect matching is uniformly distributed conditional on containing an edge \(ab\). Choose \(x\) uniformly among vertices other than \(a\). If \(x=b\), leave the matching unchanged. Otherwise, let \(xy\) be the matching edge at \(x\), and replace
\[ \{ab,xy\} \quad\longmapsto\quad \{ax,by\}. \tag{3} \]
The output is an unconditioned uniform perfect matching.
The reason is a bijection: from an output matching, recover the unique choice \(x\) as the partner of \(a\); the partner of \(b\) then determines the inverse switch.
For several prescribed edges, release them successively, temporarily excluding endpoints of edges still prescribed. This removes the conditioning exactly. Moreover, every newly created edge meets the support of the original prescribed edges. A canonical failure event supported entirely outside that support cannot be newly created.
This belongs to the established resampling-oracle framework; it is not a newly invented general local lemma. Nor does the bijection alone prove convergence of an arbitrary repeated-repair algorithm. [arXiv](https://arxiv.org/abs/1504.02044)
The supplied code checks the bijection and support property exhaustively through order ten. At order ten, each of the 945 perfect matchings has exactly one preimage in each tested release experiment.
The distinction between ordinary contact and domination matters.
In an ordinary model, some vertex of one branch set must meet some vertex of the other. In a dominating model, earlier branch sets must dominate every vertex of later branch sets. Illingworth and Steiner’s September 2026 construction disproves the corresponding exact dominating conjecture using complements of triangle-free subgraphs of Suzuki–Tits graphs. [arXiv](https://arxiv.org/html/2609.35361)

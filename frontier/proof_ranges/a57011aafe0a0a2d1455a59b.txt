6. A reconstruction attaining the same exponential order
The lower bound does not leave an unexplained gap: there is an explicit upper construction for every probability measure on \([0,1]\).
It reconstructs the desired response directly, without first recovering a spectral density. Direct functional recovery is a classical approach; the task here is to obtain the appropriate resource bound. arXiv
Fix amplitude accuracy \(\epsilon>0\), and set
\[
M=
\left\lceil
\max\!\left\{16T,\log_2\frac4\epsilon\right\}
\right\rceil,
\qquad
a=\min\!\left\{\frac BM,\frac1{16}\right\}.
\tag{17}
\]
Measure only at
\[
s_\ell=\ell a,\qquad \ell=0,\ldots,M.
\]
For \(0\le x\le1\), put
\[
z=1-e^{-ax}.
\]
Then
\[
e^{-itx}=(1-z)^{it/a}.
\]
Truncate the binomial expansion:
\[
P_t(x)
=
\sum_{j=0}^{M}
(-1)^j\binom{it/a}{j}
(1-e^{-ax})^j.
\tag{18}
\]
Uniform approximation error
For \(j>M\), uniformly over \(0\le t\le T\),
\[
\left|\binom{it/a}{j}\right|z^j
\le
\left(\frac{eT}{j}+ea\right)^j
\le
\left(\frac e8\right)^j
<2^{-j}.
\]
Thus
\[
\boxed{
\sup_{\substack{0\le t\le T\\0\le x\le1}}
|P_t(x)-e^{-itx}|
\le2^{-M}\le\frac\epsilon4.
}
\tag{19}
\]
Expanding the powers in (18) gives
\[
P_t(x)=\sum_{\ell=0}^{M}w_\ell(t)e^{-s_\ell x}.
\]
The resulting coefficient norm satisfies
\[
\boxed{
\sup_{0\le t\le T}\sum_{\ell=0}^{M}|w_\ell(t)|
\le
S:=
2\left[
2e\left(2+\frac TB\right)
\right]^M.
}
\tag{20}
\]
For completeness, this follows by bounding the coefficients with the rising factorial \((T/a)_j/j!\). The sequence \(2^j(T/a)_j/j!\) grows by at least a factor two, so its finite sum is at most twice its last term. Applying \(j!\ge(j/e)^j\) gives (20).
A usable error certificate
If every measured value obeys
\[
|\widehat G(s_\ell)-G(s_\ell)|\le\delta,
\]
then the entire reconstructed curve satisfies
\[
\boxed{
\sup_{0\le t\le T}
\left|
\sum_{\ell=0}^{M}w_\ell(t)\widehat G(s_\ell)-A_\mu(t)
\right|
\le
2^{-M}+S\delta.
}
\tag{21}
\]
Choose \(\delta=\epsilon/(4S)\). Repeating each Gaussian query sufficiently often yields the simultaneous bound with probability \(1-\zeta\), using
\[
\boxed{
N
=
O\!\left(
(M+1)S^2\epsilon^{-2}
\log\frac{M+1}{\zeta}
\right).
}
\tag{22}
\]
For logarithmic measurements, estimate \(\log G\), clip the estimate above at zero, and exponentiate. The map
\[
y\mapsto e^{\min(y,0)}
\]
is \(1\)-Lipschitz, so the same raw accuracy suffices.
The output amplitude is a polynomial in \(t\) of degree \(M\). Squaring its modulus and clipping to \([0,1]\) yields the return-probability predictor. Amplitude error \(e_A\) gives probability error at most \(2e_A+e_A^2\).
For fixed accuracy and confidence,
\[
M=O(T),
\qquad
\log S=O\!\left(T\log\!\left(2+\frac TB\right)\right),
\]
which proves the upper half of (1).
This is matching exponential order, not matching practical constants. The displayed construction is conservative.

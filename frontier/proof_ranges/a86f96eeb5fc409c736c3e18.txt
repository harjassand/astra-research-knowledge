## 2. The operation that removes the computational obstruction

The preceding manuscript explicitly left a global minimum over a generally nonconvex set as its computational limitation. A finite number of face descents did not make those descents efficiently computable. proof

There are actually two problems to remove.

First, negative curvature supplies a direction, but a feasible step may be arbitrarily short. Second, even polynomially many exact rational moves can produce an unacceptable recurrence in denominator size.

The new construction separates these problems:

**Short moves are charged to irreversible face loss. Numerical precision is reset inside the face already reached.**

### The precision-reset lemma

Suppose an exact local move reaches \(z^*\) in a matroid face \(F^*\). Suppose it also satisfies certain exact linear equations
\[
Hz=b,
\]
whose coefficients come from the original input.

For a prescribed rational tolerance \(\delta>0\), construct a small dyadic box containing \(z^*\):
\[
\mathcal B
=
\prod_{j=1}^{n}[a_j,a_j+2^{-p}],
\qquad
a_j=2^{-p}\lfloor 2^p z_j^*\rfloor,
\]
with \(2^{-p}\le\delta/(n+1)\).

Now find a vertex of the **linear** feasible set
\[
\boxed{
F^*\cap\{z:Hz=b\}\cap\mathcal B.
}
\]

This set is nonempty because it contains \(z^*\). Any returned point \(z^+\) satisfies
\[
\|z^+-z^*\|_2\le\delta,
\]
while retaining the face and equations exactly.

More importantly, its encoding length depends on the small-box precision and the encoding lengths of the linear constraints—not on the old denominator of \(z^*\). This follows from determinant bounds for rational vertices.

Exact rational linear optimization from a separation oracle is classical; the construction uses that machinery only for linear problems, including lower-dimensional ones. It does not assume that arbitrary nonlinear feasible sets can be optimized efficiently. [Springer](https://link.springer.com/book/10.1007/978-3-642-78240-4)

A critical distinction is that **the reset point need not be dyadic**. An exact slice might require \(z_1=1/3\), which no dyadic grid contains. The dyadic object is the enclosing box; the point returned inside it is rational.

### Why the exact equations do not themselves accumulate numerical complexity

The retained-row machinery supplies a useful fact.

A row is protected exactly while its retained squared norm satisfies
\[
q_i>K^2.
\]
A coefficient is deliberately discarded only when
\[
p_{ij}>q_i/K.
\]

But column normalization gives \(p_{ij}\le1\). For a large row,
\[
q_i/K>K\ge1,
\]
so deliberate deletion is impossible.

Therefore, **a currently large row has never undergone a deliberate deletion**. Its exact equation is simply
\[
\boxed{A_i(z-z_0)=0,}
\]
using the original input.

The reset consequently preserves only
\[
z\in F^*,\qquad
c^\top z=c^\top z_0,\qquad
A_i(z-z_0)=0\quad(i\text{ currently large}).
\]

It does **not** try to preserve the moving spectral constraints exactly. Those constraints receive a globally bounded numerical-error allowance. That separation is what makes the precision reset work.

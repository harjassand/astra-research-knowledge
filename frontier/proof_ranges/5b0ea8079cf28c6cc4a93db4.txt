5. What the executed experiments establish
Large-network coefficient acquisition
The main synthetic network contained 65,536 vertices and 130,560 edges. Its heterogeneous reference channels were chosen so that the reference solution was analytically available.
The stopping requirement was
\[
U/L\le1.05,
\]
using a nominal 99% confidence procedure.
The comparison used the same reference distribution, coefficient envelope, sampled indices, and confidence-budget schedule. The statistical comparator was a matched Hoeffding bound.
Target case	Intrinsic enclosure gap	Distinct reads: variance-adaptive	Distinct reads: Hoeffding	Variance-adaptive outcome
Common axial correction \(1.6\)	\(0\%\), up to rounding	2,014	24,506	3.60% interval width
Heterogeneous small axial mismatch	0.419%	2,014	24,506	4.95% interval width
Axial corrections randomly \(0.5\) or \(2\)	56.25%	51,380	51,380	Failed the requested width


The successful cases used 2,048 draws, compared with 32,768 for Hoeffding. With cached repeated queries, that is 12.2 times fewer distinct coefficient reads.
Relative to reading every coefficient, the successful procedure used approximately 64.8 times fewer reads. That is not a lower bound against all specialised methods: some full-input implementations could omit irrelevant terminal edges, and more sophisticated acquisition methods were not compared.
All successful intervals contained the float64 full-network solution. In 100 additional seeded runs of the heterogeneous case, every reported interval contained that comparator.
Several qualifications matter.
The common-scale case is a control, not evidence of difficult scientific discovery. The small-mismatch case’s actual conductance was already close to the reference answer; the achievement is acquiring a certificate, not uncovering a large unexpected physical effect.
Transverse coefficient corrections spanned approximately eight orders of magnitude, but those edges had zero reference work. This is not evidence of solving arbitrary high-contrast transport.
Finally, the 12.2-fold improvement comes from using a known variance-adaptive confidence rule rather than a range-only rule inside the candidate interface. It is not a new-method-versus-state-of-the-art result.
Local repair of strong mismatch
I also executed the paired-cell construction on a separate 64-by-64 strong-mismatch network.
As cell size increased, the enclosure gap fell:
\[
56.2\%
\;\longrightarrow\;
30.1\%
\;\longrightarrow\;
16.2\%
\;\longrightarrow\;
6.22\%
\;\longrightarrow\;
2.10\%.
\]
The first tested scale below 5% used four cells, each containing up to 2,016 edges.
That experiment acquired all 7,938 retained target coefficients. It demonstrates repair of the approximation, but not cheap acquisition of that repair. It does not prove that all coefficients are necessary; it shows that the executed method did not avoid them.
This was the most informative negative result: the local mechanism improved the prediction bounds, while the desired simultaneous resource saving remained unproved.
Exact arithmetic and finite-bit implementation
The packet also contains 3,223 passing exact-rational assertions covering local inequalities, global bounds, variance control, monotone coarsening, and whole-cell exactness on small graphs. These are finite checks, not formal verification of the general proofs.
Separately, I implemented a lazy rational-coefficient acquisition procedure on an implicit 256-by-256 grid. It uses integer/rational arithmetic for moment enclosures, logarithm upper bounds, square-root rounding, and stopping comparisons.
It stopped after 2,014 distinct target-coefficient acquisitions, returning
\[
C(c)\in
[2.1503171602351814,\;2.2339888389129205],
\]
with endpoint-ratio width \(3.891\%\).
Exact rational endpoints and the complete sampled-index stream are retained. No transverse coefficients were queried.
This removes floating-point enclosure ambiguity for that structured demonstration. It does not provide a verified arbitrary-graph solver or physical coefficient oracle. The probability theorem assumes independent random bits; the recorded reproducible run uses a seeded pseudorandom generator.

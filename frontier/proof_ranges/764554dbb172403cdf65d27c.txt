Activity-sensitive simulation of complete open-system dynamics
The stronger consequence is simulation of the full physical quantum channel—not just its no-jump propagator—with cost that adapts to the activity of the unknown input state.
The construction below gives, for time-dependent Lindblad dynamics,
\[
\boxed{
\mathbb E_\rho Q
=
\widetilde O\!\left(
1+g\sqrt{T(1+\nu_\rho)}+h_0T
\right),
}
\tag{1}
\]
while retaining
\[
\boxed{
Q_{\mathrm{worst}}
=
\widetilde O\!\left(1+(g^2+h_0)T\right).
}
\tag{2}
\]
Here \(g\) is the supplied normalization of the stacked jump-operator oracle, \(h_0\) is the Hamiltonian normalization, and \(\nu_\rho\) is the expected number of physical jumps from input \(\rho\) during \([0,T]\). The algorithm neither receives nor estimates \(\nu_\rho\). It operates on one unknown input, including an input entangled with an external reference.
The missing operation was to recover the lost amplitudes from the time-history construction. The resulting map is an isometry, so it can be implemented without a survival-probability penalty. An adaptive schedule then turns that first-event operation into the full-channel simulator.
This is a new derivation in this investigation. Independent verification and historical priority remain unestablished.
1. Exact target and comparison with current algorithms
Write
\[
\mathcal L_t(\rho)
=
-i[H(t),\rho]
+\sum_{\mu=1}^{r}L_\mu(t)\rho L_\mu(t)^\dagger
-\frac12\left\{
\sum_\mu L_\mu(t)^\dagger L_\mu(t),\rho
\right\},
\]
and define the rectangular stacked map
\[
\mathsf L(t)=\sum_{\mu=1}^{r}|\mu\rangle\otimes L_\mu(t).
\]
The input supplies coherent, controlled and inverse access to projected unitary encodings of
\[
\mathsf L(t)/g,\qquad H(t)/h_0
\]
at binary-encoded times. It also supplies valid bounds
\[
\begin{aligned}
\|\mathsf L(t)\|&\le g,&
\|H(t)\|&\le h_0,\\
\|\mathsf L(t)-\mathsf L(s)\|&\le \ell_L|t-s|,&
\|H(t)-H(s)\|&\le \ell_H|t-s|.
\end{aligned}
\]
Zero-normalization terms can be omitted. No commutation, spectral-gap or mixing-time assumption is imposed.
Let \(\Phi_{T,0}\) be the resulting channel and \(\rho(t)=\Phi_{t,0}(\rho)\). Define
\[
\nu_\rho
=
\int_0^T
\operatorname{Tr}\!\left[
\mathsf L(t)^\dagger\mathsf L(t)\rho(t)
\right]dt.
\tag{3}
\]
This is the expected jump count in the supplied jump representation, and
\[
0\le \nu_\rho\le g^2T.
\tag{4}
\]
The output is an adaptive quantum implementation \(\widetilde\Phi\) satisfying
\[
\|\widetilde\Phi-\Phi_{T,0}\|_\diamond\le\varepsilon.
\tag{5}
\]
The guarantee is uniform over inputs; the expected execution cost in (1) is input-dependent.
What is already available
The September 2026 algorithms of Chen–Gao–Wang–Zhou and Wang–Ye give general Lindblad-channel simulation in essentially this oracle model, including time dependence, with normalized time
\[
\tau=(g^2+h_0)T
\]
and query complexity
\[
O\!\left(
\tau+
\frac{\log(1/\varepsilon)}
{\log(e+\log(1/\varepsilon)/\tau)}
\right).
\]
They also account for efficient additional gates. Rational trace-preserving discretizations and compressed Kraus records already appear in this work; neither is counted as a discovery here. arXiv
Trajectory-based simulation is also established prior mathematics. For example, Borras–Marvian exploit a class with state-independent Poisson jump timing. The task here allows arbitrary \(\mathsf L(t)^\dagger\mathsf L(t)\), so jump timing depends on the evolving unknown state. arXiv
The scoped repository check used Astra revision 93996d8c872f and OpenAI revision fd4aeeb2ee4f. Related records inspected concern Choi-onset exponents and many-body loss identities, respectively—not a verified implementation of the target above. These checks do not establish absence of prior work.  
Thus the proposed advance is automatic activity-sensitive execution for the complete channel, not an improvement to the already optimal general worst-case time–precision bound.

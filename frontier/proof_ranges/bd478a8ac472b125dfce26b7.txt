Result: a matching information bound for recovering coherent dynamics
The strongest result is a quantitative obstruction to reconstructing real-time dynamics from imaginary-time measurements, together with a reconstruction algorithm attaining the same exponential order.
The obstruction survives several conditions that might otherwise be expected to make the problem tractable: a known complete spectrum, a fixed ground-state gap, substantial overlap with every eigenmode, nonnegative imaginary-time propagation, and a one-dimensional nearest-neighbour realization.
For an imaginary-time measurement window \(B\) and a requested real-time prediction horizon \(T\), the derived sample requirement is
\[
\boxed{
N_*(T,B)
=
\exp\!\left[\Theta\!\left(T\log\!\left(2+\frac{T}{B}\right)\right)\right].
}
\]
This is a worst-case, constant-accuracy result under the measurement models specified below. The constants in the exponent are not optimized.
This is not a new fast simulator. General ill-posedness of analytic continuation is established mathematics. The candidate contribution is the matching quantitative law and its realization under the strong physical restrictions above. Historical priority for that combination remains unresolved. DOI
1. The selected obstruction and exact access model
Let an unknown probability measure \(\mu\) be supported on \([0,1]\). Define
\[
G_\mu(s)=\int e^{-sx}\,d\mu(x),
\]
\[
A_\mu(t)=\int e^{-itx}\,d\mu(x),
\qquad
p_\mu(t)=|A_\mu(t)|^2.
\]
For a Hamiltonian \(H\) with spectrum in \([0,1]\) and a prepared state \(\psi\), these are
\[
G_\mu(s)=\langle\psi,e^{-sH}\psi\rangle,
\qquad
p_\mu(t)=|\langle\psi,e^{-itH}\psi\rangle|^2.
\]
Thus the target can be an ordinary return probability, not merely an inaccessible complex phase.
A measurement chooses \(s\in[0,B]\). I considered two separate noise models:
\[
\text{additive data:}\qquad G_\mu(s)+Z,
\]
\[
\text{relative-precision data:}\qquad \log G_\mu(s)+Z,
\]
where every call has independent standard Gaussian noise \(Z\). The second model is deliberately generous: it permits constant-precision measurements of the logarithm even when \(G_\mu(s)\) is small.
Query locations may be chosen adaptively. The algorithm may use unlimited processing. It is not given the Hamiltonian’s matrix entries or access to coherent real-time evolution.
Main theorem
Let \(N_*(T,B)\) be the minimum worst-case number of calls sufficient to produce a finite description of \(p_\mu(t)\) satisfying
\[
\Pr\!\left[
\sup_{0\le t\le T}
|\widehat p(t)-p_\mu(t)|
\le\frac1{16}
\right]\ge\frac23
\]
for every \(\mu\).
There are universal constants \(c,C,T_0>0\) such that, for \(T\ge T_0\) and every \(B>0\), in either observation model,
\[
\boxed{
cT\log\!\left(2+\frac TB\right)
\le
\log(1+N_*(T,B))
\le
CT\log\!\left(2+\frac TB\right).
}
\tag{1}
\]
The analogous statement holds for uniform approximation of \(A_\mu(t)\).
Two consequences follow immediately:
\[
\boxed{
B\text{ fixed}:
\quad
T_{\mathrm{recoverable}}
=
\Theta\!\left(\frac{\log N}{\log\log N}\right),
}
\]
whereas even an unlimited imaginary-time window gives only
\[
\boxed{
B=\infty:
\quad
T_{\mathrm{recoverable}}=\Theta(\log N).
}
\]
These are minimax orders—not assertions that every individual spectrum is difficult.
The representational issue is specific: compressing an imaginary-time function accurately does not establish that its real-time continuation is accurately determined. Recent work on compressed imaginary-time representations explicitly distinguishes these tasks; changing the representation of the forward data does not by itself remove inverse instability.

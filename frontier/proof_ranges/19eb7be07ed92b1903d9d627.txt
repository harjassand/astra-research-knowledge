## 5. Consequence for black-box certification against ALLSEP

There are \(m\) independent fresh target preparations. A protocol may access at most \(r\) distinct sites per prepared copy, select physical labels using classical earlier outcomes, retain arbitrary quantum memory, and make joint measurements on all accessed registers. As in audit_addendum.md, exchangeability reduces this to a channel of \(\rho_r^{\otimes m}\). The comparator \((\tau^{\otimes N})^{\otimes m}\) has identical site marginals and is globally fully separable. Hence output TV is at most
\[
 \min\{1,\sqrt{10^9m(r/N)^2}\}.
\]
Any test with a fixed gap between true acceptance and uniformly bounded acceptance on ALL fully separable alternatives needs
\[
 \boxed{m=\Omega(N^2/r^2),\qquad r_N=o(N).}
\]
This is a necessary bound for genuine entanglement certification, rather than target-versus-white discrimination. It allows arbitrary joint quantum processing. With \(r=1\), certification is impossible for any number of such preparations, because the accessed target and comparator states coincide exactly.

The physical cost at this lower scale is \(\Omega(N^3/r^2)\) prepared qubit instances and \(\Omega(N^2/r)\) local readouts. If all N readouts from a single prepared copy are pooled, the per-copy access budget is N and this lower theorem does not apply.

## 6. Trusted promise changes the task

If a null is trusted to obey \(\langle J^2\rangle=3N/4\), every fully separable null has \(|\langle J\rangle|\le\sqrt N/2\), equivalently \(|b|\le1/\sqrt N\). The polarized target has \(|b|\sim\sqrt{8/\pi}/\sqrt N\), violating this promise-aware mean bound. One-body estimation on \(O(N)\) fresh copies can then certify entanglement using the supplied global Casimir promise. The product-marginal comparator violates that promise and cannot support the quadratic certification lower bound in that interface.

Acquiring or validating the global Casimir experimentally is part of black-box certification and is not free. Exact initial state/coupling/model guarantees can supply it mathematically, but this is a separate, promise-aware inference. The unrestricted-ALLSEP theorem above must not be presented as a limitation on such trusted-model reasoning.

## 7. Upper bound status

A sound \(O(N^2)\)-preparation protocol using two random sites per copy is available from the tangent spin-variance witness; it is given separately. This matches the quadratic order when r is any fixed integer at least two. A matching uniform \(O(N^2/r^2)\) black-box certification protocol for growing r has not yet been proved in this file. Centered mean discrimination against only the product-marginal comparator would be insufficient to establish such an upper bound.

1. EXACT ACQUISITION–COMPUTATION SEPARATION

The input interface is essential. The procedure knows the following two formulas
and h, but not which source it receives. It may use arbitrary collective or
adaptive measurements of independent, unconditional copies. Its ancillas,
classical advice and random bits do not reveal the hidden label. Preparation
unitaries, their inverses, and conditional-state oracles are not supplied. It must
return an unconditional output, rather than discard failed attempts for free.

For integer m>=1, set
  h=4m^2, a=1/4, t=1/(4m),
  B0=[[a,0],[0,0]], B1=[[a,t],[t,0]].
The normalized pure Gaussian state is
  |B> = det(I-B^2)^(1/4) exp((a_dagger)^T B a_dagger/2)|vacuum>.
Both matrices have operator norm below one. Let P_i be the photon-count law of
the second mode conditional on first-mode count h in state B_i.

Define
  A_j = product_{r=0}^{j-1}(1-2r/h)^2,
  Z_h = sum_{j=0}^{h/2} A_j/(2j)!,
  F_h = sqrt(1-(8h-1)/(15h^2)).
The empty product is one. Direct expansion of the Gaussian generating function
gives
  P0 = delta_0,
  P1(K=2j)=A_j/((2j)! Z_h).
F_h is the squared overlap |<B0|B1>|^2, not the overlap amplitude.

THEOREM A — EXACT FIXED-COPY OPTIMUM.
The minimum fixed number of copies permitting these exact unconditional output
laws, for both possible sources, is
  N_star(h)=ceil(log Z_h / (-log F_h)).
Its limiting rate is
  N_star(h)/h -> (15/4) log(cosh 1) = 1.626678...
The exact criterion is F_h^N<=1/Z_h. An integer boundary can be decided using
the rational inequality
  [1-(8h-1)/(15h^2)]^N Z_h^2 <= 1.
This is copy optimality, not a claim of optimal classical runtime.

Proof of necessity. An always-output protocol defines a POVM. Write M0 for the
effect returning zero. Exactness under source 0 implies M0|B0>^N=|B0>^N.
Since 0<=M0<=I, Cauchy–Schwarz yields
  F_h^N <= <B1|^N M0 |B1>^N = P1(0)=1/Z_h.
This proof allows arbitrary collective measurements and classical processing.

Proof of sufficiency. Measure whether the second mode is vacuum on each copy.
Source 0 never clicks. The probability of no click on source 1 is F_h^N, because
its vacuum component in that mode is proportional to |B0>. Let s=1-F_h^N and
q=1-1/Z_h. If any click occurs, emit a positive draw from P1 conditioned on K>0
with probability q/s; otherwise return zero. The criterion makes q/s<=1. Under
source 1, the positive mass is exactly s(q/s)=q, with the correct positive law;
under source 0 the output is always zero.

No arbitrary-real coin or free conditional oracle is needed. Z_h is a finite
rational sum, and the positive law is sampled as described below. Put
v=F_h^(2N), a rational number. Comparing a rational u>q with q/(1-sqrt(v)) is
equivalent to comparing v with (1-q/u)^2. Lazy fair-bit comparisons therefore
implement the algebraic rebalancing coin exactly. Exact setup uses polynomial
work in h, with O(h log h)-bit operands; it is not poly(log h) setup.

THEOREM B — ROBUST LOWER BOUNDS.
If each output law need only be within total variation 1/12 of its target,
every always-output fixed-copy method still needs
  N >= 5h/96.
More precisely, N >= log(36/35)/(-log F_h).
For arbitrary almost-surely terminating procedures, including adaptive copy
counts, max_i E_i[number of copies] >= 5h/9216 is a valid weaker bound.

Proof. A_0=1 and A_1=1 imply Z_h>=3/2, so TV(P0,P1)>=1/3. Approximate output
laws must be separated by at least 1/6. The trace distance of the two N-copy
pure states is sqrt(1-F_h^N), so
  1/36 <= 1-F_h^N <= N(1-F_h) <= 8N/(15h).
The expected-copy version truncates at floor(24M), where M is the maximum
expected count, and charges the truncation probability. Full details and the
success-probability bound for heralded attempts are in the acquisition audit.

THEOREM C — SUPPLIED-MODEL SAMPLING IS EASY FOR THIS FAMILY.
When the label is supplied, source 0 returns zero. For source 1, propose J>=0
with probability 2^(-J-1). Reject when 2J>h; otherwise accept with rational
probability 2^J A_J/(2J)!, and return 2J. Proposal times acceptance is exactly
A_J/[2(2J)!]. Total acceptance is Z_h/2>=3/4, so the expected proposal count
is at most 4/3. Geometric moments and exact rational coin sampling give expected
bit work polynomial in log h. There is no bounded worst-case random-bit claim.

The input mean photon number is at most 1/4: ||B1||<=1/2 and
tr(B1^2)<=3/16 imply tr[B1^2(I-B1^2)^(-1)]<=1/4. The target mean output is at
most sinh(1)<1.2. The copy barrier is therefore not caused by a growing typical
output or growing input energy. Directly waiting for the herald is much worse:
its probability is of order 4^(-h)/sqrt(h). A one-copy attempt conditioned on
its own successful herald can be exact; its success probability cannot be
omitted from the cost ledger.

The two-state quantum discrimination mechanism is classical prior art, including
Chefles–Barnett (1998), https://arxiv.org/abs/quant-ph/9808018, and Fuchs–van de
Graaf, https://arxiv.org/abs/quant-ph/9712042. This note supplies an explicit
Gaussian conditioning witness and exact operational specialization. It does not
claim priority for quantum discrimination, fidelity contraction or postselection.

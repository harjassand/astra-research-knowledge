## New conditional operation and maximal boundary

Define the *rate-free scaling space*

`U(S)={gamma in R^m : S diag(gamma) K=0}`, where the columns of `K` form any basis of `ker S`.

This is a computable linear space independent of the unknown current. Every positive `gamma in U(S)` preserves stationarity for **every** current in `ker S`, hence for every baseline compatible with the complete model. Scalar multiples of `1` are always present; N771 uses only these. My extension allows distinct positive scales on separate support components. For fixed `h`, the total gate cost `sum_r w_r e_r rho_r(h) gamma_r` and each cap are linear in `gamma`. If `gamma` is parameterized by one positive scalar per circuit component, then `t_a=log gamma_a` gives the same convex upper-budget structure as N771 because each `log rho_r(h)` is convex in `h`. The resulting selected product ratio between two components is multiplied by `gamma_a/gamma_b`. Absolute productivity still requires a measured baseline flux.

**Maximality theorem, within this information contract.** Let a circuit of `S` mean a support-minimal nonzero vector in `ker S`, and join reaction indices when they lie in one circuit; take transitive closure. On all reaction indices that can carry a nonzero stationary current, `gamma in U(S)` iff `gamma` is constant on each such circuit component. A reaction outside every circuit carries zero in every vector of `ker S`, so its scale is irrelevant to the steady current. Proof: for a circuit vector `v`, both `v` and `diag(gamma)v` lie in `ker S`; the kernel supported on that minimal support is one-dimensional, forcing equal `gamma` on every nonzero coordinate. Transitive closure gives necessity. Conversely, every kernel vector is a linear combination of circuit vectors (remove a support-minimal dependence iteratively), and a componentwise-constant diagonal map sends each circuit vector to a scalar multiple of itself. Thus it preserves all of `ker S`. If physically possible currents occupy only a smaller subspace, this theorem is conservative; with a strictly positive point in the oriented flux cone, that cone spans `ker S`, so the boundary is exact for all such currents.

This theorem is a narrow algebraic observation, and the connection to known flux modes and network localization makes historical novelty **UNKNOWN**. It is not a universal biological controllability result. A coupled network whose column-dependence matroid is connected admits only N771's common scale when no current magnitudes are known. Thus topology itself says when the hoped-for rate-free change in selectivity is impossible under the universal guarantee.

There is a second, paid escape hatch. If `d=dim ker S`, choose `d` individual current measurements whose coordinate projection `P K` is nonsingular; such a choice exists because `K` has rank `d`. Then `j=K(PK)^{-1}Pj`, and any desired positive, same-orientation `j* in ker S` can be compiled at the target state by `e'_r=e_r rho_r(h) j*_r/j_r`. With fewer than `d` independent linear current readings, generic full-current reconstruction is impossible: two nearby currents in the positive relative interior of the flux cone can share those readings but require different gate ratios for a fixed `j*`. This is a lower bound for **full-current, fixed-target compilation** under that measurement interface; it is not a lower bound for a chosen ratio, for which far fewer measurements may suffice. Near-zero currents and a poorly conditioned `PK` can make the nominally low-dimensional readout very expensive. If `hat j=j+delta`, the actual stationarity residual under the compiled gates is `-S diag(j*/hat j) delta`, so a valid error bound requires acquired `|j_r|` margins and readout errors.

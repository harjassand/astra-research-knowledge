# Independent analytic audit of the structured signed-GKSL proposal theorem

16 October 2026, Brisbane. Audit worker `fz_signed_gram_audit`.

**Disposition: the exact signed theorem and its stated sufficient rate bounds
are valid under the explicit catalog obligation.** The normalized Choi block,
complex conjugations, trace condition, pseudoinverse/range condition, and
fixed-generator minimum all agree with an independent reconstruction. No
factor of the ambient Hilbert dimension is missing. The coefficient bounds
of order `nu/N` and coherent bounds of order `nu/sqrt(N)` have the stated
constants for `N>=1` and `nu>0`.

There is one useful presentation clarification: an open neighborhood means a
neighborhood **within the specified structured model enforcing the catalog
obligation**. If the catalog is not product closed, arbitrary Hermitian
perturbations of every entry of `C` on that catalog can violate the obligation.
The existing source explicitly requires the obligation, so this is a scope
clarification rather than a counterexample to its theorem. Arbitrarily small
violations can prevent finite-rate proposals altogether.

The root diagonal-Pauli theorem is the `C=0` specialization with additional
floor optimizations. It must remain distinct from the general signed theorem:
correlations in `C` change both the anticommutator and the inverse Gram cost.
The inherited memory support/recovery interface, physical realization, useful
device advantage, external peer verification, and historical originality are
not established by this audit.

## 2. Reconstruction from the normalized Choi matrix

Let the patch have `q` qubits and dimension `d=2^q`. Fix distinct Hermitian
nonidentity Paulis `P_1,...,P_N`, including fixed choices of their phases. The
operators `F_0=I, F_i=P_i` satisfy

```
tr(F_alpha^dagger F_beta)/d = delta_(alpha,beta).
```

Assume `h_i` are real, `C=C^dagger`, and `gamma_i>=0`. Define

```
H = sum_i h_i P_i,
D = diag(gamma)+C,
Gamma = sum_i gamma_i,
K = sum_ij C_ij P_j P_i.
```

Hermiticity of `C` makes `K` Hermitian even when off-diagonal entries of `C`
are complex. Orthogonality gives `tr(K)/d=tr(C)`. The product-coverage
hypothesis is the exact operator equality

```
K = tr(C) I + sum_i k_i P_i,       k_i real.
```

The generator can then be written

```
G(rho) = sum_ij D_ij P_i rho P_j
         - {Gamma I+K,rho}/2 - i[H,rho].
```

In particular, `G` is trace annihilating. This does not require `C>=0`.

Use `|Omega_d>=sum_u |u,u>/sqrt(d)` and
`|A>=(A tensor I)|Omega_d>`. Let `W` have columns
`|I>,|P_1>,...,|P_N>`. Then `W^dagger W=I_(N+1)`. For Hermitian `P_i`,

```
J(P_i (.) P_j) = |P_i><P_j|,
J(H (.))      = |H><I|,
J((.) H)      = |I><H|.
```

The same left/right formulas hold with `K`. Consequently, for any real `r`,

```
J(r Id+G) = W M(r) W^dagger,

M(r) = [ r-tr(D)    a^dagger ],
       [    a          D    ]

a = -k/2-i h,       tr(D)=Gamma+tr(C).
```

The Choi matrix is zero on the orthogonal complement of this catalog span.
This verifies the signs in the upper-right and lower-left blocks, including
complex `C`. On a full single-qubit catalog, if
`C_XY=x12+i*y12`, `C_XZ=x13+i*y13`, and `C_YZ=x23+i*y23`, then

```
k = (2*y23, -2*y13, 2*y12),
a = (-y23-i*h_X, y13-i*h_Y, -y12-i*h_Z).
```

The independent symbolic diagnostic verifies this identity with all nine
real parameters of a generic Hermitian `3x3` matrix `C` left symbolic. The
real parts of off-diagonal entries need not contribute to `K` for
anticommuting modes, but remain in `D`; they cannot be dropped.

### Trace annihilation independently fixes the real cross block

For any coefficient matrix `T` on this orthonormal basis,

```
Tr_output(W T W^dagger)
    = (sum_(alpha,beta) T_(alpha,beta) F_beta F_alpha)^T/d.
```

For the above block the associated rate operator is

```
(r-tr(D))I + Gamma I + K + sum_i 2 Re(a_i)P_i = r I.
```

Thus the normalized Choi partial trace is `r I/d`. The precise trace
constraint is `2 Re(a)=-k`, and the imaginary part is the Hamiltonian.
No unitality is assumed; positive nonunital channels are allowed.

### There is no missing dimension factor

The only dimension factor in the Choi definition is absorbed by the unit
norm vectors `|P_i>`. The block entries are exactly `D`, `a`, and
`r-tr(D)`, not those quantities multiplied or divided by `d`. Appending
spectator identity factors preserves `tr(P_i^dagger P_j)/d=delta_ij` and
the same block. The audit explicitly checks dimensions `2,4,8` for one
fixed supported generator and obtains `r_min=5/8` in all three cases.

This absence of an ambient `d` factor does not supply the catalog or acquire
its coefficients. A full unrestricted catalog still has `N=d^2-1`.

## 3. Exact positivity, range condition, and fixed-rate minimality

A completely positive map has a positive Choi matrix. Conversely, a
positive factorization of `M` gives Kraus operators in the basis
`I,P_1,...,P_N`, so positivity is sufficient here as well. The trace
calculation above supplies trace preservation after dividing by `r>0`.

Write `alpha=r-tr(D)`. The following equivalence is exact:

```
[ alpha  a^dagger ] >= 0
[   a        D    ]

iff D>=0, a in range(D), alpha>=a^dagger D^+ a.
```

Proof, including the singular case:

1. Compression to the lower block forces `D>=0`.
2. If `z in ker(D)`, the compression to vectors `(1,0)` and `(0,z)` has
   determinant `-|z^dagger a|^2`. Positivity forces
   `z^dagger a=0` for every kernel vector. For Hermitian `D`, this is
   exactly `a in range(D)`.
3. Under that condition, for every complex `t` and vector `z`,

   ```
   (t,z)^dagger M(t,z)
     = (z+D^+ a t)^dagger D(z+D^+ a t)
       + [r-tr(D)-a^dagger D^+a]|t|^2.
   ```

   The first summand is nonnegative. The second coefficient must be
   nonnegative, by choosing `t=1, z=-D^+a`. This proves necessity and
   sufficiency, with no invertibility assumption.

It follows that, whenever `D>=0` and `a in range(D)`,

```
r_min = tr(D)+a^dagger D^+a
      = Gamma+tr(C)+a^dagger D^+a.
```

Both summands in the first expression are nonnegative. If `r_min=0`, then
`D=0` and `a=0`, hence `G=0`; omit the stream or use an identity channel
at any positive rate. Otherwise the minimum is attained. At any rate
`r<r_min` the exact witness `(1,-D^+a)` has quadratic form `r-r_min<0`.
A negative eigenvalue of `D`, or failure of the range condition, cannot be
repaired by increasing `r`.

For this fixed generator `Psi=Id+G/r` is forced. Several independent
state-independent CPTP streams with total rate `r=sum_j r_j` average to
the same channel `Psi=sum_j (r_j/r)Psi_j`; they cannot lower the minimum.
An alternative Kraus representation cannot change Choi positivity. More
explicitly, any Kraus vector of a positive Choi matrix vanishing outside
the catalog span must itself lie in that span, since a sum of squared
projections outside it is zero. Additional unlisted Kraus directions give
no escape.

The optimization is over total state-independent CPTP proposal rate for
the **fixed** generator. It does not optimize physical energy, fabrication,
reset, every adaptive unraveling, or every possible deliberate-noise
intervention. A Lindbladian may fail the finite-rate/range criterion, as
a nonzero purely Hamiltonian generator does.

## 4. Explicit scalar-rate jump realization

Let `D=V V^dagger`, with `V` having `rank(D)` independent columns. When
`a in range(D)`, solve `V conjugate(c)=a` with minimum coefficient norm.
Then

```
sum_j |c_j|^2 = a^dagger D^+a,
B_j = c_j I + sum_i V_ij P_i.
```

Their coefficient Gram matrix is

```
M_0 = [ a^dagger D^+a   a^dagger ],
      [       a             D    ]
```

because its lower-left block is `V conjugate(c)=a`, rather than `V c`.
The conjugation in the source construction is correct. The total effect
operator is

```
sum_j B_j^dagger B_j
  = [a^dagger D^+a]I + Gamma I + K + sum_i 2 Re(a_i)P_i
  = r_min I.
```

The cross terms in the completely positive part are

```
sum_i [a_i P_i rho + conjugate(a_i) rho P_i]
     = -{K-tr(C)I,rho}/2 - i[H,rho].
```

Subtracting the scalar rate term gives `sum_j D[B_j]=G` exactly. For
`r>r_min`, append `sqrt(r-r_min)I`, whose dissipator is zero; dividing all
operators by `sqrt(r)` gives a CPTP Kraus representation. The rank bound
at the minimum is at most `rank(D)`, and at a larger rate at most
`rank(D)+1`, as claimed.

This calculation preserves signed changes of dissipators and complex
cross terms. It does not implement negative jump rates. The added physical
Pauli floor makes `D` positive; the `B_j` are an algebraic unraveling of
that specified generator.

### New singular, signed, complex diagnostic

Take the two-qubit unitary and catalog

```
U = diag(1,i,-1,1),       P=(ZI,IZ,ZZ),
c = (1+i)/4,
v = ((1+i)/4, -(1+i)/4, (3-i)/4)^T,
U = c I + sum_i v_i P_i.
```

Choose `gamma_i=1/16` and `C=v v^dagger-I/16`. Then `C` is genuinely
signed, with eigenvalues `-1/16,-1/16,13/16`, and has complex
off-diagonal entries. The lower block `D=v v^dagger` has rank one.
Direct coefficient extraction yields

```
k = (-1/4,1/4,-1/4),
h = (0,0,1/4),
a = (1/8,-1/8,1/8-i/4) = v conjugate(c),
tr(D)=7/8,       a^dagger D^+a=1/8,       r_min=1.
```

The generator is exactly `Ad_U-Id`, its Choi matrix at the minimum has
rank one, and the below-minimum witness has value `-1/100` at rate
`99/100`. This checks pseudoinverse minimality at a nontrivial complex
singular boundary, beyond the producer's positive-definite example.

Now perturb `h` by `eps*(1,1,0)`. The vector `z=(1,1,0)` lies in
`ker(D)`, but `z^dagger a_new=-2i eps`. The `(I,z)` compression has
determinant `-4 eps^2` for every `r`. Thus an arbitrarily small coherent
perturbation can destroy finite-rate uniformization at a singular floor.
This is exactly the range boundary, not a failure of the theorem.

## 5. Fixed signed coefficient budget and every numerical constant

Assume `N>=1`, `nu>0`, the product-coverage hypothesis, and real `k,h`.
Fix the real deliberate floor before realizing the error:

```
gamma_i=nu/(2N),       Gamma=nu/2.
```

Suppose the certified scalar `b` bounds all three of
`||C||_op`, `|tr(C)|`, and `||k||_2`, while `u>=||h||_2`. If

```
b<=nu/(8N),       u<=nu/(4 sqrt(N)),
```

then

```
D >= [nu/(2N)-b] I >= 3nu/(8N) I > 0.
```

The range condition is automatic. The reality of `k,h` gives the exact
identity

```
||a||_2^2 = ||k||_2^2/4 + ||h||_2^2.
```

In particular no mixed term was lost when `C` was complex. The rate is
bounded by

```
r_min <= nu/2+b+(b^2/4+u^2)/(nu/(2N)-b)
      <= nu * [2/3+13/(96N)].
```

For the last step, the contributions at the stated endpoints are
`nu/2`, `nu/(8N)`, `nu/6`, and `nu/(96N)`. Their sum is the displayed
constant. Its slack is

```
1-[2/3+13/(96N)] = (32N-13)/(96N) >= 19/96 > 0.
```

Thus the largest upper fraction occurs at `N=1` and is `77/96`, strictly
below one. All inequalities are valid at the allowed endpoints. These are
sufficient constants, not asserted optimal signed-neighborhood constants.

It is essential that `b` bound the trace and the full nonidentity
coefficient vector of `K`, as well as `||C||_op`. An operator-norm bound
on `C` alone has dimension-dependent conversion losses and is not the
stated hypothesis. If `N=0`, the only catalog-supported HP trace-annihilating
map is zero and the formulas involving `1/N` are replaced by omitting the
stream.

### Supported diamond-norm budget

Let `E` be any HP trace-annihilating map whose normalized Choi matrix is
supported on the above span. Because `W` is an isometry, write

```
J(E)=W [ beta  a^dagger ] W^dagger,
         [  a       C    ]
```

with `C` Hermitian and `beta` real. Trace annihilation forces
`beta=-tr(C)` and `2 Re(a)=-k`, where
`K=sum_ij C_ij P_j P_i`. It also forces all components of `K` outside
the catalog to vanish. Taking `h=-Im(a)` therefore recovers precisely
the signed representation under audit, with no extra assumption of
unitality or positivity of `E`.

For the normalized maximally entangled input,

```
||J(E)||_op <= ||J(E)||_1 <= ||E||_diamond = delta.
```

Compression and the first column then give
`||C||_op<=delta`, `|tr(C)|<=delta`, and `||a||_2<=delta`.
The fixed floor hence satisfies

```
r_min <= nu/2+delta+delta^2/(nu/(2N)-delta).
```

At `delta<=nu/(8N)` this is at most

```
nu/2+nu/(6N) <= 2nu/3 < nu.
```

This verifies both the constant and the normalized-Choi-to-diamond
conversion. Norm smallness by itself does not imply the Choi-support
promise; an arbitrarily small unsupported perturbation can have an
unfloored conditional block or cross direction.

## 6. Jump replacements, product coverage, and locality

For traceless jumps in the supplied span, let `l_j` and `delta_j` be
their complex Pauli coefficient columns. Replacement of `J_j` by
`J_j+Delta J_j` gives exactly

```
C = sum_j [(l_j+delta_j)(l_j+delta_j)^dagger-l_j l_j^dagger].
```

For each term, the rank-one expansion has matrix operator norm bounded
by `2||l_j||_2||delta_j||_2+||delta_j||_2^2`. Normalized
Hilbert-Schmidt orthogonality gives
`||l_j||_2=||J_j||_HS/sqrt(d)<=||J_j||_op`, and similarly for
`Delta J_j`. Therefore

```
B = sum_j [2||J_j||_op||Delta J_j||_op+||Delta J_j||_op^2]
```

bounds `||C||_op`. The exact rate-operator difference is

```
K = sum_j [(J_j+Delta J_j)^dagger(J_j+Delta J_j)-J_j^dagger J_j].
```

The same `B` bounds `||K||_op`. Hence it bounds both
`|tr(K)/d|=|tr(C)|` and `||k||_2`, since
`||k||_2<=||K||_HS/sqrt(d)<=||K||_op`. This establishes all three
entries in the source's `b` budget. It assumes the product-coverage
obligation holds for the actual replacement family.

If a jump has identity part `c I+A`, extracting it into a Hamiltonian
gauge induces

```
H_c = (i/2)(conjugate(c) A-c A^dagger),
D[cI+A] = D[A]-i[H_c,.].
```

The difference of those induced Hamiltonians must be included in the
certified `h`; it is not a free cancellation. For `t>=1`, `kappa>0`,
`||J_j||<=sqrt(kappa)` and
`||Delta J_j||<=eta sqrt(kappa)` give
`B<=t kappa(2eta+eta^2)`. The proposed condition

```
eta<=sqrt(1+nu/(8Nt kappa))-1
```

is exactly sufficient for `B<=nu/(8N)`. At equality substitution gives
that bound exactly. Zero affected jumps or zero amplitude scales are
handled separately as trivial cases. Every affected jump is charged in
`t`, and any induced Hamiltonian must independently fit its bound.

### Product coverage is an independent and decisive hypothesis

There are two different obligations:

- The actual `H` and `K` must have no components outside the stated
  catalog. Products of allowed jump modes determine what may be needed.
- After those modes are included, `a` must lie in the range of `D`.

Adding a missing product as a zero row/column of `C` is legitimate. Its
floor rate must also be installed or otherwise supplied when needed for
the range condition. Longer iterative product closure is unnecessary if
the added product-only modes remain unused rows/columns of `C`: their
diagonal Pauli floor terms have rate operator proportional to `I`.
Products appearing inside individual factorized `B_j` cancel in their
sum to the already specified `Gamma I+K`.

For a fixed model, if arbitrary new coherent entries of `C` are later
allowed on those product-only modes, their products must again be covered.
Calling a catalog a finite model does not by itself certify this closure.
The neighborhood in Section 5 contains an open neighborhood of zero in
the linear subspace of errors satisfying the supplied structure and
product obligation. It is generally not open in the full space of all
Hermitian `N x N` coefficient matrices for a non-product-closed catalog.

The exact new diagnostics illustrate both imaginary and real products:

1. For `P=(XI,ZI)` and
   `C=[[0,i eps],[-i eps,0]]`, the rate operator has the missing
   component `-2 eps YI`. With floors `g` only on the two listed modes,
   the `(I,YI)` Choi compression is

   ```
   [[r-2g, eps], [eps, 0]],       determinant=-eps^2.
   ```

   This fails for all rates and every nonzero `eps`, even when the
   error is arbitrarily small. Add `YI` with floor `g` and a zero
   added row/column of `C`; when `g>|eps|`, the exact rate is
   `3g+eps^2/g`.
2. For commuting modes `(XI,IX)`, the positive matrix
   `C=eps*ones(2,2)` is one physical positive dissipator, with
   `eps>0`. It creates the missing product `2 eps XX`. Without an
   `XX` floor the `(I,XX)` compression has determinant `-eps^2`
   for every rate. Positivity of the physical jump does not remove
   this finite-rate anticommutator obstruction.

For allowed Pauli jump weights at most `k_J` and Hamiltonian weights
at most `k_H`, every needed product has weight at most `2k_J`.
Canonical Hermitian Pauli representatives are included after stripping
the product phase `+/-1` or `+/-i`. Thus

```
N <= sum_(w=1)^max(k_H,2k_J) 3^w binomial(q,w)
```

is a valid sufficient count, with binomial coefficients zero for `w>q`.
For fixed weights it is polynomial in `q`. If each jump acts on a
single specified set of at most `k` qubits, its within-jump products
remain on that same set and a per-support catalog has at most `4^k-1`
modes. A low-weight sum spread across the patch does not have this
stronger support property.

The general factorized `B_j` can be spread across the whole union
patch. The receiving support certificate must charge that patch, its
incidence, and every proposal's rate. Only the separate Pauli
Hamiltonian construction below automatically keeps each proposal on
one `supp(P_i)`. Dense factorization costs `O(N^3)` arithmetic and
`O(N^2)` storage; it is an algebraic proof operation rather than a
new hardware primitive. These counts do not include calibration or
physical verification of the model.

## 7. Diagonal-Pauli specialization and the separate root theorem

Set `C=0`, so `k=0` and `a=-i h`. The general criterion reduces to

```
r_min=Gamma+sum_(gamma_i>0) h_i^2/gamma_i,
with h_i=0 whenever gamma_i=0.
```

For each positive `gamma_i`,

```
lambda_i=gamma_i+h_i^2/gamma_i,
U_i=(h_i I-i gamma_i P_i)/sqrt(h_i^2+gamma_i^2)
```

has `U_i^dagger U_i=I`, and expansion gives

```
lambda_i(Ad_(U_i)-Id)
  = -i h_i[P_i,.]+gamma_i(Ad_(P_i)-Id).
```

This does not require the `P_i` to commute. Additive generator identities
give the same chronological Poisson semigroup, with each stream supported
on `supp(P_i)`.

For the uniform fixed floor `Gamma=nu/2`,

```
r_min=nu/2+(2N/nu)||h||_2^2 <= nu
iff ||h||_2<=nu/(2 sqrt(N)).
```

This is the exact receiving coefficient ball for that floor, including its
boundary. The more conservative `nu/(4 sqrt(N))` bound in the signed
neighborhood spends additional rate on `C` and `K`. Since
`||h||_2=||H||_HS/sqrt(d)<=||H||_op` for the traceless catalog expansion,
the same operator-norm bound is sufficient under the fixed-span promise.
No dimension-free conversion to `sum_i |h_i|` is implicit.

The floor optimizations in the root note are consistent with this
specialization:

- Fixed `Gamma` and known `h`: Cauchy-Schwarz gives
  `sum_i h_i^2/gamma_i >= (sum_i |h_i|)^2/Gamma`, with equality for
  floors proportional to `|h_i|`. Optimizing `Gamma` gives
  `2 sum_i |h_i|`; zero-error coordinates can be omitted.
- Unknown box `|h_i|<=epsilon_i`: the worst rate is
  `sum_i (gamma_i+epsilon_i^2/gamma_i)`. Its exact minimum within
  this floor family is `2 sum_i epsilon_i`, attained at
  `gamma_i=epsilon_i`, with zero coordinates omitted.
- Unknown ellipsoid `sum_i(h_i/b_i)^2<=1`: the worst rate is
  `sum_i gamma_i+max_i b_i^2/gamma_i`. If
  `B=(sum_i b_i^2)^(1/2)` and `z=max_i b_i^2/gamma_i`, then
  `sum_i gamma_i>=B^2/z`, so the optimized value is `2B`, attained
  at `gamma_i=b_i^2/B`. An `N`-dimensional Euclidean radius-`rho`
  ball therefore costs `2rho sqrt(N)`. A coordinate box of half
  width `rho` instead costs `2N rho`.

These are optimizations inside the diagonal Pauli-floor family, rather
than over every physical intervention. They require the supplied box or
ellipsoid information and cannot infer one uncertainty set from the
other.

They also cannot replace the signed inverse formula. For example, with
one-qubit modes `(X,Y,Z)`, `gamma=(1,1,1)`, and

```
C = [[0,1/2,0],[1/2,0,0],[0,0,0]],
```

the exact signed rates for `h=(1,1,0)` and `h=(1,-1,0)` are
respectively `13/3` and `7`. Ignoring the off-diagonal `C` would
incorrectly give `5` in both cases. The diagnostic checks both directly
from the Choi block.

The source's arithmetic examples are consistent: `3*486=1458` one-body
modes give denominator `2 sqrt(1458)=54 sqrt(2)` (about `76.37`), and
the supplied six-face owner model has `18` one-body modes. On that
owner model equal native rates `gamma` give
`18gamma+sum h_i^2/gamma`, and choosing a real fixed positive baseline
`gamma=nu/36` yields radius `nu/(2 sqrt(18))`. The six-face geometric
ownership premise and inherited full-patch comparison constant were
not independently derived here. Existing bath rates may be reused only
when actually positive on all admitted coherent modes and their total
rate fits the budget; a theorem allowing zero bath rates does not supply
such a positive floor uniformly.

## 8. Unrestricted signed errors still incur basis-count cost

For one nonidentity Pauli direction, the signed perturbation
`E=-eps(Ad_P-Id)` changes its conditional diagonal entry from
`gamma_P` to `gamma_P-eps`. If this is negative, no rate is possible.
Requiring this same directional signed tolerance for every Pauli demands

```
Gamma >= (d^2-1)eps
```

for the stated Pauli-floor family. This agrees with the source's
obstruction. If a diamond-ball parameter is used instead, then
`||E||_diamond=2eps` for nonidentity Paulis, so that lower-bound
parameter conversion has a factor of two. The source states its
obstruction in the directional-rate parameter `eps`, not in a mislabeled
diamond radius.

The catalog theorem removes an ambient basis-count factor only after a
restricted catalog/model has been justified. If its patch or catalog

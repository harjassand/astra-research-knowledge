For maximum lag L=2T the sharp minimum variance is pi^2/L^2. Therefore
the cosine window's transverse completion satisfies

  0<=a_inf(r)-a_L(r)<=pi^3/(2 L^2 kappa^2 r^3),

uniformly in K. This is optimal for the leading angular deficit over
nonnegative squared-Fourier windows generated on [-L/2,L/2]. It is NOT
an optimality assertion over all collision closures or signed kernels.

Comparator: the rectangular amplitude gives Fejer phi=(1-cos x)/(pi x^2),
which has infinite variance and only T^-1 angular convergence. Exactly,

  R_Fejer(a)=(2/pi)[Si(a)+(cos a-2)/a+sin a/a^2],
  1-R_Fejer(a)=4/(pi a)+O(a^-3).

A triangular amplitude instead gives phi=3 sinc^4(x/2)/(4pi), mu2=3,
with the same support [-2,2] in time. Cosine's pi^2/4 is smaller.
For an equal maximum time lag L, compare cosine at T=L/2 with Fejer at T=L.
The order improvement survives this accounting; comparing equal T alone
would give cosine twice the temporal access.
Window optimization is the classical Poincare/Rayleigh operation. The
candidate composite is its use with exact collision transversality and a
cutoff-uniform weak error certificate. Historical novelty has not been cleared.

4. WEAK OPERATOR ERROR

Suppose f>0 has mass M, bounded density and bounded Hessian of log f,
||Hess log f||<=H_f, and psi has ||Hess psi||<=H_psi.
These assumptions include an anisotropic Gaussian. Then

 |<psi,Q_L^K(f)-Q_inf^K(f)>|
 <= pi^3 H_f H_psi/(4 L^2 kappa^2)
                         int ff*/|v-v*| dv dv*.

Proof: both gradient differences in the weak form are bounded by their
Hessian bounds times |u|; insert the tensor bound and integrate.
The remaining integral is finite. For example its crude upper bound is
M[2pi ||f||_infinity+M], by splitting |u| at 1.
This error estimate is uniform in K, retains nonlinear f in the weak form,
and needs neither an acquired spectral gap nor a supplied chaos bound.
It still does not control the microscopic-to-kinetic approximation.

The Hessian assumption on log f can in fact be removed in this screened
weak estimate. Suppose only f>0 has bounded density B, mass M, and finite
Fisher information I(f)=int f|grad log f|^2. For every R>0 put
  C2(f;R)=4pi B R+M/R^2.
Splitting the convolution at R gives
  sup_v int f(v*)/|v-v*|^2 dv* <= C2(f;R).
Using |grad log f-grad_*log f*|<=|grad log f|+|grad_*log f*|,
symmetry, and Cauchy-Schwarz gives instead

 |<psi,Q_L^K(f)-Q_inf^K(f)>|
 <= pi^3 H_psi/(2L^2 kappa^2) C2(f;R) sqrt(M I(f)).

Both versions are retained: the first has a sharper integrand for smooth
scores; the second uses a weaker and explicitly stated regularity interface.
Neither acquires a uniform Fisher bound from microscopic dynamics.

5. WHAT WOULD CLOSE THE ORIGINAL TARGET

The radial Yukawa potential is a diagnostic, not a substitute for point
Coulomb. A Balescu-Lenard completion must use a symmetric off-resonant
dielectric weight that agrees with |epsilon_f(k,k.v)|^-2 on k.u=0.
One candidate is 1/(|epsilon_f(k,k.v)| |epsilon_f(k,k.v*)|).
It preserves pair symmetry and positivity but agreement on resonance alone
does not give controlled off-resonant or microscopic error. It requires
uniform response estimates and a derivation of the dielectric from dynamics.

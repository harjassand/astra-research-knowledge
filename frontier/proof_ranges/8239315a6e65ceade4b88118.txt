## 3. Changing the iteration count does not rescue the same dimension argument

I then tested whether the obstruction was merely an unfortunate choice of \(\ell\).

For a polynomial map \(f:\mathbb C^n\to\mathbb C^m\) with coordinate degrees at most \(D\), define
\[
H_f(\ell)=
\dim_{\mathbb C}
\operatorname{span}
\left\{
f_1^{a_1}\cdots f_m^{a_m}:
\sum_i a_i\le\ell
\right\}.
\]
The constant function is included.

There are two immediate bounds:
\[
H_f(\ell)\le
\min\left\{
\binom{m+\ell}{\ell},
\binom{n+D\ell}{n}
\right\}.
\]

The first counts formal products of the outputs. The second counts the ambient input polynomials in which those products lie.

For a competing degree-\(r\) map
\[
\Gamma:\mathbb C^s\to\mathbb C^m,
\]
the corresponding universal bound is
\[
H_\Gamma(\ell)\le\binom{s+r\ell}{r\ell}.
\]

A sufficient strategy for proving that \(f\)’s image cannot lie in any such \(\Gamma\)’s image would be to make \(H_f(\ell)\) exceed this universal bound. The following result blocks that particular strategy across **all** choices of \(\ell\).

### All-degree comparison theorem

Suppose \(m\le M^r\), where \(M\ge1\), and
\[
s\ge6rM,
\]
\[
s-n\ge
2Mn\left(
1+\log\max\left\{1,\frac{Ds}{rn}\right\}
\right).
\]
Then, for every integer \(\ell\ge1\),
\[
\boxed{
\min\left\{
\binom{m+\ell}{\ell},
\binom{n+D\ell}{n}
\right\}
\le
\binom{s+r\ell}{r\ell}.
}
\]

The proof splits at
\[
L=\frac{s}{rM}.
\]

For \(\ell\le L\), compare
\[
\binom{m+\ell}{\ell}
\le\left(\frac{2eM^r}{\ell}\right)^\ell
\]
with
\[
\binom{s+r\ell}{r\ell}
\ge\left(\frac{s}{r\ell}\right)^{r\ell}.
\]
The hypothesis \(s\ge6rM\) makes the second expression large enough.

For \(\ell\ge L\), set \(t=r\ell/s\). Then
\[
\log\binom{n+D\ell}{n}
\le
n\left[
1+\log\max\left\{1,\frac{Ds}{rn}\right\}
+\log(1+t)
\right],
\]
whereas
\[
\log\binom{s+r\ell}{s}\ge s\log(1+t).
\]
Since \(t\ge1/M\), the second hypothesis completes the comparison.

For
\[
m=n\binom{n+r-1}{r},\qquad r\le n,
\]
one can choose \(M\) polynomial in \(n\). When \(\log D\) is polynomial in \(n\), sufficiently large polynomial \(s\) already satisfies these conditions.

**Scope:** this rules out comparing \(H_f\) against the universal ambient bound in this regime. It does not rule out using the actual structure of competing maps, their polynomial relations, or other invariants. In particular, it does not prove image containment.

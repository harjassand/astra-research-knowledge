## 4. A concrete example with only classical outputs

An explicit instance uses the nine domino product states in \(\mathbb C^3\otimes\mathbb C^3\):
\[
\begin{gathered}
|1\rangle|1\rangle,\\
|0\rangle|0\pm1\rangle,\qquad
|2\rangle|1\pm2\rangle,\\
|0\pm1\rangle|2\rangle,\qquad
|1\pm2\rangle|0\rangle,
\end{gathered}
\tag{13}
\]
where
\[
|u\pm v\rangle=\frac{|u\rangle\pm|v\rangle}{\sqrt2}.
\]

These states form an orthonormal product basis. Their local indistinguishability originates in the nonlocality-without-entanglement construction of Bennett and coauthors. [arXiv](https://arxiv.org/abs/quant-ph/9804053)

Write the basis as \(\{|a_jb_j\rangle\}_{j=1}^{9}\), and define
\[
\mathcal M(\rho)
=
\sum_{j=1}^{9}
\langle a_jb_j|\rho|a_jb_j\rangle
\,|jj\rangle\langle jj|.
\tag{14}
\]

Its Kraus operators are product operators:
\[
K_j=
|j\rangle\langle a_j|
\otimes
|j\rangle\langle b_j|.
\]
Hence \(\mathcal M\) is separable.

There is a strictly positive lower bound on the error of LOCC discrimination of this basis, so
\[
\mathcal M\notin\overline{\mathrm{LOCC}}.
\]
The robust gap, rather than merely failure of exact discrimination, is established by the state-discrimination analysis of Childs, Leung, Mančinska and Ozols. [arXiv](https://arxiv.org/abs/1206.5822)

Set \(p=1/9\).

The late-flag implementation is particularly simple. Select a uniformly random basis index \(j\); Alice tests \(|a_j\rangle\), and Bob tests \(|b_j\rangle\). If both tests pass, output flag \(1\) and label \(j\). Otherwise, output flag \(0\) and the fixed replacement label.

For every input \(\rho\),
\[
\Pr[F=1]
=
\frac19\sum_j\langle a_jb_j|\rho|a_jb_j\rangle
=
\frac19.
\tag{15}
\]

Therefore the late-flag channel is exactly LOCC, whereas
\[
\boxed{
E_{\mathrm{early}}^{\mathrm{cat}}
\bigl(\mathcal H_{1/9,\mathcal M}\bigr)
=
\frac19 E_{\mathrm{seq}}^{\mathrm{cat}}(\mathcal M)>0.
}
\tag{16}
\]

Every external output is classical. Each conditional future-input channel is separable. Starting from separable states, neither the early process nor any causal composition of it with LOCC can generate entanglement.

Nevertheless, implementing the early process requires positive entanglement expenditure.

The complete block channel is LOCC, so its Choi state is separable across the Alice–Bob cut. The early process has the same numerical Choi operator, now equipped with the requirement that the flag precede the quantum input. Its positive implementation cost cannot be inferred from spatial entanglement of that operator.

**The additional resource requirement lies in realizing the stipulated temporal interface.**

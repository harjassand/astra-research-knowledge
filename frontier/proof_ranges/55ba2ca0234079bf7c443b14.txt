## 3. Nonlinear localized-energy estimate

For \(\sigma=1\pm th_k\), \(t\le1/2\), set \(\kappa=1-t\). Write \(u_{\sigma,f}=u_{1,f}+w\), with \(w\in H_0^1(B_1)\). The exact weak equation gives
\[
 \int\sigma\nabla w\cdot\overline{\nabla v}
 =-\int(\sigma-1)\nabla u_{1,f}\cdot\overline{\nabla v}.
\]
Taking \(v=w\), using support in \(B_r\) and coercivity, yields
\[
 \|\nabla w\|_{L^2(B_1)}\le\frac{t}{\kappa}
     \|\nabla u_{1,f}\|_{L^2(B_r)},
 \quad
 \|\nabla u_{\sigma,f}\|_{L^2(B_r)}\le\kappa^{-1}
     \|\nabla u_{1,f}\|_{L^2(B_r)}.                \tag{2}
\]
There is no Born approximation in (2). Alessandrini's exact identity, obtainable by subtracting the two weak equations, now gives for \(D_k=\Lambda_{\sigma_k^+}-\Lambda_{\sigma_k^-}\)
\[
 |\langle D_kf,h\rangle|
 \le\frac{2t_k}{\kappa^2}
 \|\nabla u_{1,f}\|_{L^2(B_r)}
 \|\nabla u_{1,h}\|_{L^2(B_r)}.                 \tag{3}
\]

## 4. Exact angular selection and the full operator bound

Complexify the boundary Hilbert space and decompose it into rotation characters
\[
 E=\widehat\bigoplus_{p\in\mathbb Z}E_p,
 \qquad f_p(R_\alpha x)=e^{ip\alpha}f_p(x).
\]
A degree-\(\ell\) spherical harmonic has only weights \(|p|\le\ell\). For \(f_p\in E_p\), harmonic extension and radial integration give
\[
 \|\nabla u_{1,f_p}\|_{L^2(B_r)}^2
 =\sum_{\ell\ge\max(1,|p|)}\ell r^{2\ell+n-2}
       \|(f_p)_\ell\|_2^2
 \le r^{2|p|+n-2}\|f_p\|_E^2.                \tag{4}
\]
The harmless slack at \(p=0\) avoids a special case.

Rotation by \(\alpha=\pi/k\) exchanges \(\sigma_k^+\) and \(\sigma_k^-\). The covariance of the weak boundary form implies that conjugating \(D_k\) by this rotation changes its sign. Consequently,
\[
 \langle D_kf_p,h_q\rangle=0
 \quad\hbox{unless}\quad p-q\in k(2\mathbb Z+1). \tag{5}
\]
This is an exact selection rule for the nonlinear DN maps. Combining (3)–(5), the norm of a nonzero \((p,q)\) block is at most
\[
 b_{pq}=\frac{2t_k}{\kappa^2}r^{|p|+|q|+n-2}
            {\bf1}_{p-q\in k(2\mathbb Z+1)}.
\]
For every \(p\), the triangle inequality \(|p|+|q|\ge|p-q|\) gives
\[
 \sum_qb_{pq}
 \le\frac{2t_k}{\kappa^2}r^{n-2}
       \sum_{j\in\mathbb Z}r^{|(2j+1)k|}
 =\frac{4t_k}{\kappa^2}
       \frac{r^{k+n-2}}{1-r^{2k}}.
\]
The same bound holds for columns. The Hilbert-space block Schur test (apply the scalar Schur test to \(\|f_p\|_E\)) proves
\[
 \boxed{\|D_k\|_{E\to E^*}
 \le\frac{4t_k}{(1-t_k)^2}
       \frac{r^{k+n-2}}{1-r^{2k}}
 \le C_{n,r}a k^{-s}r^k,\quad
 C_{n,r}=\frac{16r^{n-2}}{1-r^2}.}             \tag{6}
\]
In particular, no polynomial factor in \(k\) from spherical-harmonic multiplicity is required: the Schur test is over angular character *blocks*, each of which can have infinite dimension.

There is a second, exact operational statement. If every permitted input has angular spectrum \(|p|\le L\), then for \(2L<k\),
\[
 B_{\sigma_k^+}(f,h)=B_{\sigma_k^-}(f,h)
 \quad\hbox{for all permitted }f,h.             \tag{7}
\]
Arbitrarily many adaptive queries, arbitrary amplitude and arbitrarily precise readouts cannot distinguish the pair under this exact bandwidth restriction. Spherical-harmonic degree \(\le L\) is a sufficient restriction. A nonzero compactly supported patch voltage generally has angular tails, so (7) must not be asserted for patch controls merely because their nominal pattern is coarse.

## 3. An exponential work certificate for nonlinear random trees

Finite expected work alone gives only a Markov tail, which can erase a claimed
polylogarithmic accuracy cost after imposing a hard cap. A stronger reusable
certificate is available for bounded-degree source trees.

**Theorem 2.** For a tree whose node has state x, suppose z>1 and t(x)>=1 satisfy

    z E_x[product_over_children t(child_state)]<=t(x).     (3)

Then total node count N is almost surely finite and

    E_x z^N<=t(x),  P_x(N>n)<=t(x) z^−n.                 (4)

The statement allows spatially dependent, multitype offspring. It does not
require a pointwise subcritical first-generation mean.

**Proof.** Explore the tree, retaining all unvisited nodes in a frontier.
`z^(visited nodes)*product_frontier t(state)` is a nonnegative supermartingale
by (3). Its expectation is bounded by t(root). Since t>=1, truncating at any
finite number of visited nodes or generations bounds the corresponding z-power
of the node count. Fatou gives (4); an infinite tree would make this power
infinite on a positive-probability event and is therefore excluded. This is a
standard branching/positive-supermartingale argument, used here as a checkable
resource certificate, not a new general probability principle.

For bounded degree b and uniform conditional child mean<=q<1, another sufficient
tail is obtained from the exploration queue and conditional Hoeffding:

    P(N>n)<=exp[−2(n(1−q)−1)_+^2/(n b^2)]
           <=exp[−n(1−q)^2/(2b^2)] if n>=2/(1−q).        (5)

Dummy offspring zero after extinction make the stopped queue argument valid.
For sharper constants, use a dominating offspring PGF f(s). Any s>1 with
f(s)<s yields (3) with constant t=s and z=s/f(s)>1. Individual upper offspring
probabilities produce a valid stochastic domination when their sum is<=1.
An arbitrary spectral-radius assertion is not itself an acquired PGF certificate.

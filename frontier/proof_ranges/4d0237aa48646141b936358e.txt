## Redundant constraint rows and the scope of the nullspace argument

The generic argument is now stated after row reduction. Given finitely many constraint functions φ\(_1\),…,φ\(_m\), first select a basis ψ\(_1\),…,ψ\(_r\) of their span as functions on the allowed frequency domain. If the target (g) is outside this span, then the (r+1) functions ψ\(_1\),…,ψ\(_r\), (g) are linearly independent. Their evaluation vectors therefore span ℝ\(^{r+1}\), so there are (r+1) frequencies whose augmented evaluation matrix has full rank. The (r\times(r+1)) constraint matrix has a nonzero null vector (v); full rank of the augmented matrix forces (g\cdot v\ne0). Around any strictly positive base weights on those support points, sufficiently small (\pm\delta v) perturbations preserve positivity, match every retained constraint, and separate the target. This explicitly handles redundant original rows.

For the present finite example, no abstract independence premise is needed: the interval-certified 8-by-8 determinant of the first eight columns is nonzero, and the ninth-column Cramer construction supplies the exact null direction.

The broader non-span statement is restricted to a finite list of Euclidean-time kernels, finitely many power/negative-power moment rows, and the static (2/\omega) row. At large ω, interior-time thermal kernels decay exponentially; the τ=0 row tends to a constant with exponential corrections; any finite collection of power and inverse-power rows spans only a finite Laurent polynomial. By contrast (g_\eta(\omega)=2\omega/(\omega^2+\eta^2)=2/\omega-2\eta^2/\omega^3+2\eta^4/\omega^5-\cdots) has an infinite nonzero Laurent tail for η>0. Thus it is not in that finite span. This does not cover an arbitrary calibrated intervention whose response function might include (g_\eta) itself or otherwise encode the target; such interventions must be analyzed from their actual measured row functions.

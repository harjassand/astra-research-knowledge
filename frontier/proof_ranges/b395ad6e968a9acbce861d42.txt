## 4. New theorem: arbitrary detuning pulses enter the exclusion loss quadratically

An objective-specific error can be much smaller than the full state error.
The following is independently derived; it does not import N771's chemical
equations into a quantum system.

During acquisition only, let the isolated-link Hamiltonian contain an unknown
differential detuning delta(t) Z/2 in addition to the fixed trine phase and known
unit hopping. Let delta be measurable with finite L1 area

    b = integral_0^T |delta(t)| dt.

Retain fixed nonnegative physical dephasing gamma, initial north-pole state and
the original phase-independent anti-trine readout. No detuning estimation or
control compensation is assumed.

**Proposition B.** For each true trine label, the bad-action probability satisfies

    |p_bad[delta]-p_bad[0]| <= b^2/6.

In particular a constant detuning |Delta|<=Delta_max costs at most
Delta_max^2*T^2/6. The result holds without a constant-sign pulse promise.

**Proof.** Rotate the true phase to zero. The Bloch generator is

    M_delta(t) = [[-gamma, -delta(t), 0],
                  [delta(t), -gamma, 2],
                  [0, -2, 0]],
    r(0)=(0,0,1),  p_bad=(1-r_y(T))/3.

The baseline dynamics preserve the yz plane and the x axis separately.
The perturbation K(A)=-i[Z/2,A] sends a baseline yz Bloch vector into x. Therefore
every first-order Dyson contribution has zero y readout. Let Phi_delta and
Phi_0 be the perturbed and baseline CPTP propagators. Subtract their Duhamel
identities once more to leave the exact ordered second-order remainder. Its
integrand contains Phi_delta(T,s) K Phi_0(s,t) K rho_0(t), multiplied by
delta(s)delta(t), for 0<t<s<T. All propagators contract trace norm on Hermitian
operators; K preserves Hermiticity/zero trace and has induced trace norm <=1,
since ||[Z/2,A]||_1<=||A||_1. The centered bad-action effect is -Y/3, with norm
1/3, so the absolute observed remainder is at most

    (1/3) integral_(0<t<s<T) |delta(s)delta(t)| dt ds = b^2/6.

The diagonal of the integration square has measure zero. QED.

For constant detuning an independent equivalent argument is that replacing
Delta by -Delta and r_x by -r_x preserves r_y,r_z, so p_bad is even in Delta;
the CPTP second-derivative norm bound gives the same result. This does not say
that the full state changes only quadratically: its x component is generally
linear in Delta.

At T=pi/4 and Delta_max=1/32 the extra bad-action allowance is

    pi^2/98304 < 0.000100398807792.

If separately acquired preparation/readout/timing law errors have TV bound eta_h,
the new valid decision bound is p_bad[0]+b^2/6+eta_h. Setting
eta_h<=1/2000-b^2/6 preserves the source's numeric decision risk while permitting
a much larger full-state perturbation in this particular direction. Hardware
errors are measured against the detuned experiment, not silently included twice.
The same phase-dependent action gap multiplies the probability term only when
the old stationary-output model remains valid.

If detuning persists during readout, bound it there separately (for constant
Delta, a safe additional TV cost is |Delta|*t_readout/2). If it persists during
device operation, the old physical loss certificate is inapplicable until
recertified. Unknown phase drift, hopping-amplitude error, population loss,
arbitrary leakage, correlated preparation error or a different measurement need
not enjoy this quadratic cancellation. This theorem buys one specified error
budget; it supplies neither a new general noise-correcting code nor a hardware
demonstration.

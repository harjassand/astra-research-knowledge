## 1. Exact finite-rate theorem

On one finite qubit patch let P_1,...,P_m be distinct nonidentity Hermitian
Paulis, with normalized Hilbert–Schmidt inner products delta_ij. Supports can
be smaller than the enclosing patch. Let h_i be real and gamma_i>0, and put

    G(rho)=-i[sum_i h_i P_i,rho]
                +sum_i gamma_i(P_i rho P_i-rho).

The least total rate r for which G=r(Psi-Id) with a CPTP channel Psi is exactly

    r_min=sum_i gamma_i+sum_i h_i²/gamma_i.                 (1)

A positive scalar identity part of H is irrelevant and is omitted. This is a
statement about state-independent Poisson proposals; it is not the least
physical energy cost, a claim about every unraveling, or robustness of the
unmodified sweep generator.

For a single Pauli, set lambda_i=gamma_i+h_i²/gamma_i and

    U_i=(h_i I-i gamma_i P_i)/sqrt(h_i²+gamma_i²).

U_i is unitary. Direct expansion gives

    lambda_i(Ad_U_i-Id)=-i h_i[P_i,.]+gamma_i(Ad_P_i-Id).   (2)

Summing proves existence at (1), with an explicit convex mixture of supported
unitary proposals. A term h_i=0 has U_i=-iP_i, lambda_i=gamma_i. All rates
must be charged; an identity amplitude in a Kraus operator is not a free
fault clock in the geometric support estimate.

For necessity, use the normalized maximally entangled vector and its orthonormal
Pauli translates |I>,|P_1>,...,|P_m>. Multiplying the Choi matrix of
Id+G/r by r restricts to

    [[r-Gamma, i h^T],[-i h, diag(gamma)]],
    Gamma=sum gamma_i,

and vanishes on the orthogonal complement. The Schur complement is nonnegative
iff r>=Gamma+h^T diag(gamma)^-1 h. Trace preservation is automatic from the
generator. Any finite collection of CPTP proposals with total rate r averages
to this same Psi; therefore none lowers the total state-independent rate.
Zero floors are allowed only for h_i=0 and are handled by support/range limits.

## 2. Fixed floors for an unknown coefficient box

Suppose only |h_i|<=epsilon_i is supplied, with all epsilon_i>0. For fixed
floors the worst possible rate is

    sum gamma_i+sum epsilon_i²/gamma_i.

Its exact minimum over gamma_i>0 is

    2 sum epsilon_i, attained by gamma_i=epsilon_i.        (3)

Each coordinate follows from (sqrt(gamma)-epsilon/sqrt(gamma))²>=0.
This is an exact minmax result within the stipulated Pauli dephasing floor
family. It does not optimize over every possible physical noise intervention.
If epsilon_i=0 that floor can be omitted. A universal memory proposal budget
nu therefore receives the sufficient per-cell coefficient-box condition
2 sum epsilon_i<=nu, with the chosen deliberate dephasing floors included.

## 3. Correlated ellipsoid information changes the best floor

For the supplied ellipsoid sum_i(h_i/b_i)²<=1, b_i>0, the worst rate is

    sum gamma_i+max_i b_i²/gamma_i.

Let B=(sum b_i²)^1/2. The exact optimized value is 2B, attained by

    gamma_i=b_i²/B.                                      (4)

Proof: writing z=max b_i²/gamma_i forces sum gamma_i>=B²/z,
so r>=z+B²/z>=2B; the displayed floors attain equality. Correlated information
cannot be invented from marginal coefficient bounds. For an ordinary m-dimensional
Euclidean ball of radius rho, b_i=rho and (4) gives 2rho sqrt(m), rather than
2m rho for the equally sized coefficient box. These are different input contracts.

## 4. Receiving autonomous-memory theorem

Receive the separately reconstructed conditional theorem for completed sweep
correction and arbitrary bounded-support CPTP faults at fresh state-independent
Poisson locations: if total proposal rate touching each local cell is below a
fixed geometric threshold, a location-only good-schedule event makes one fixed

2 Pr(bad schedule), uniformly in the logical input and external reference.

Add the specified Pauli dephasing floors to the completed baseline and allow
structured Hamiltonian drift on the same fixed catalog. Equations(1)–(4) give
an exact proposal representation and uniform rate budget, so the same receiving
memory bound applies. Every catalog term, support overlap, spatial incidence
and geometry factor is counted. The threshold constants still come from the
original LSS/HT/coarse-envelope proof; no useful numerical threshold is asserted.
The baseline has changed. Neither the original uncompleted generator nor an

The gain concerns an exact input distinction. A fixed k-body Pauli catalog in
a large geometric patch costs its catalog and local coefficient budget. It
need not pay the square of the Hilbert dimension of the whole enclosing patch.
An unrestricted dense patch Hamiltonian or arbitrary local dissipator is a
larger problem; basis count and coefficient conversion can again be exponential.
A local operator-norm bound cannot silently be substituted for sum |h_i|.
Unknown operators must have an acquired/justified expansion or an explicit
conversion loss. A shared-bath Hamiltonian P_i tensor B_i is not covered by the
scalar-coefficient formula; the separate persistent-bath Poisson theorem has

The Poisson representation is a proof device for the already specified generator.
It does not require experimentally implementing the unknown U_i. Actual deliberate

stability is not a fabricated memory or demonstrated technological advantage.

# Independent conceptual exploration: complete Gaussian likelihood probes

**Status:** Complete written proof for compactly supported probability measures. Finite formula/approximation tests are in verify.py. Historical novelty and a new efficient algorithm are not established. This is a useful reorganization of familiar convex duality, not a claimed new foundation.

## 1. Why a scalar monotone is not a complete structure

The main proof uses

\[
 E_r(\mu)=D(\mu*\gamma_r\|\gamma_r).
\]

It is strictly monotone along nontrivial convex-order comparisons. Nevertheless the complete list of these scalar numbers, for all r, does not characterize convex order or even distinguish reflected laws.

For example, set

\[
 \mu=\tfrac23\delta_{-1}+\tfrac13\delta_2,
 \qquad \nu=\tfrac23\delta_1+\tfrac13\delta_{-2}.
\]

Both means are zero and both second moments are two. Reflection preserves gamma_r and KL, so E_r(mu)=E_r(nu) for all r. Yet

\[
 \int(x-1)_+d\mu=1/3>0=\int(x-1)_+d\nu,
\]

while

\[
 \int(x+1)_+d\mu=1<4/3=\int(x+1)_+d\nu.
\]

They are incomparable in convex order. A universal scalar-energy interpretation would therefore discard indispensable directional/shape information.

## 2. Retain a reference family instead of one reference

Let mu be compactly supported in R^d. For every r>0 and finitely supported probability eta, put f_mu=mu*gamma_r and define

\[
 \Phi_{r,\eta}(\mu)
 =D(f_\mu\|\gamma_r)-D(f_\mu\|f_\eta)
 =\int f_\mu(z)\log\frac{f_\eta(z)}{\gamma_r(z)}\,dz.
 \tag{1}
\]

Unlike E_r, this expression is linear in mu for fixed r,eta. Its test function is a Gaussian-smoothed log-Laplace function. The collection is a family of likelihood probes; no new divergence is being invented.

**Theorem (completeness).** For compactly supported mu,nu,

\[
 \nu\le_{cx}\mu
 \quad\Longleftrightarrow\quad
 \Phi_{r,\eta}(\nu)\le\Phi_{r,\eta}(\mu)
 \quad\text{for every }r>0\text{ and every finite eta}.
 \tag{2}
\]

## 3. Complete proof

If nu<=cx mu, common Gaussian addition preserves that order. The function

\[
 z\longmapsto\log\frac{f_\eta(z)}{\gamma_r(z)}
 =\log\sum_jw_j\exp\left(\frac{z\cdot v_j}{r^2}-\frac{\|v_j\|^2}{2r^2}\right)
\]

is convex. Integrating proves the forward implication.

For the reverse implication, fix any finite maximum of affine functions

\[
 H(x)=\max_{1\le j\le N}(a_j\cdot x+b_j).
\]

For integer k>=1 choose r_k=1/k and a finite probe with centers and weights

\[
 v_{k,j}=a_j/k,\qquad
 w_{k,j}=\frac{\exp(kb_j+\|a_j\|^2/2)}{Z_k},\quad
 Z_k=\sum_j\exp(kb_j+\|a_j\|^2/2).
\]

Then direct cancellation gives the exact identity

\[
 \log\frac{f_{\eta_k}(z)}{\gamma_{1/k}(z)}
 =\log\sum_j\exp\bigl(k(a_j\cdot z+b_j)\bigr)-\log Z_k.
 \tag{3}
\]

Let H_k(z)=k^{-1}log sum_j exp(k(a_j dot z+b_j)). Elementary inequalities give

\[
 H(z)\le H_k(z)\le H(z)+\frac{\log N}{k}.
\]

The finite maximum H is globally Lipschitz with constant L=max_j||a_j||. Therefore

\[
 \left|\frac{\Phi_{1/k,\eta_k}(\mu)+\log Z_k}{k}-\int H\,d\mu\right|
 \le\frac{\log N+L\mathbb E\|Z\|}{k}.
 \tag{4}
\]

The same holds for nu. In comparisons between two probability measures, log Z_k cancels exactly. Taking k to infinity in the hypothesized probe inequalities yields integral H dnu<=integral H dmu for every finite maximum of affine functions.

It remains to recover all finite convex test functions. Let K be a compact set containing the two supports, inside the interior of a compact ball. Every finite convex function phi on R^d is continuous and has supporting affine functions at every point. For each x in K choose one support l_x with l_x(x)=phi(x). Continuity gives a neighborhood on which phi-l_x<epsilon. A finite subcover of K supplies finitely many supports whose maximum H satisfies H<=phi and phi-H<epsilon on K. Sending epsilon to zero establishes the convex-order inequality for phi. This proves (2). QED.

A single-atom eta supplies affine tests, including both signs of every direction. Thus equality of means is enforced by the profile; it is not an additional missing assumption.

## 4. What the theorem does and does not buy

The raw E_r profile can fail to distinguish two incomparable laws. The enriched profile restores order completeness by retaining Gaussian likelihood references. It also supplies concrete smooth tests approximating every polyhedral convex test, with the explicit error (4).

This is not evidence for a computational advance. The profile contains infinitely many probes, centers, slopes, scales, and weights. Weights in (3) may require precision growing with k, and the number of affine pieces needed to approximate a general convex function can be large. An arbitrary profile oracle would merely relocate the original problem.

For already supplied finite supports, convex-order comparison has the existing finite martingale-coupling linear feasibility formulation: find nonnegative r_ij with row sums p_i, column sums q_j, and sum_i r_ij x_i=q_j y_j. The probe theorem does not replace that by a smaller or faster method. A lower-cost use of a restricted probe family would need separate approximation and complexity guarantees.

The appropriate research conclusion is to retain the explicit completeness result and the scalar-profile counterexample, while withholding any claim that this construction is a fundamentally new mathematical primitive.

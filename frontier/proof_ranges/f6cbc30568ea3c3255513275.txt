The repaired estimate suppresses the graph error by requiring `D_m^(3/4) Omega_n(t)` to be small for every `n<=m` before starting stage `m`.

3. The double-slice Baire argument requires only point density within that slice. It does not require path avoidance while staying in the double slice. The later crossing-curve Baire argument takes place in the full parameter space with its value and first jet fixed.

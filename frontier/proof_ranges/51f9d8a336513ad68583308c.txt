## 6. Why “sample a global alternating cycle uniformly” hides a hard subroutine

A stronger proposal would avoid walk-generation bias by sampling uniformly from all alternating cycles relative to the current matching.

That cannot be assumed cheap.

### Proposition

A polynomial-time sampler within total variation distance \(1/8\) of the uniform distribution over alternating simple cycles, given a bipartite graph and a specified perfect matching and promised a nonempty cycle set, would imply

\[
\mathrm{NP}=\mathrm{RP}.
\]

The proof is a polynomial-size reduction from directed Hamiltonian cycle, an NP-complete problem. [Springer](https://link.springer.com/content/pdf/10.1007/978-1-4684-2001-2_9?utm_source=chatgpt.com)

### Proof

**First, directed cycles become alternating cycles.**

Given a loopless directed graph \(D\), create vertices \(v_L,v_R\) for each vertex \(v\), with specified perfect matching

\[
M_*=\{\{v_L,v_R\}:v\in V(D)\}.
\]

For every directed arc \(u\to v\), add the nonmatching edge

\[
\{u_R,v_L\}.
\]

Directed simple cycles of \(D\) correspond bijectively to \(M_*\)-alternating simple cycles: traverse a directed-arc edge from a right vertex to a left vertex, then the matching edge back to the corresponding right vertex.

**Second, favour longer cycles using only a polynomial-size unweighted construction.**

Let the original directed Hamiltonian-cycle instance have \(N\ge3\) vertices. Add a disjoint directed two-cycle so the cycle set is guaranteed nonempty.

Replace every directed arc by a sequence of \(L\) directed diamonds. Each diamond has two internally disjoint length-two routes between its endpoints. The replacement therefore has \(2^L\) possible directed paths.

An original simple cycle of length \(k\) has exactly

\[
2^{Lk}
\]

expanded versions. There are no cycles internal to an arc replacement because each replacement is directed acyclic.

The original graph has fewer than \(N^{N+1}\) simple cycles. Choose

\[
2^L\ge 16(N^{N+1}+1).
\]

Then \(L=O(N\log N)\), so the expanded graph has polynomial size.

If an original Hamiltonian cycle exists, its expanded versions contribute at least \(2^{LN}\) cycles. All non-Hamiltonian cycles together contribute at most

\[
(N^{N+1}+1)2^{L(N-1)}
\le \frac1{16}2^{LN}.
\]

Thus a uniform expanded cycle projects to an original Hamiltonian cycle with probability at least \(16/17\).

A sampler with total variation error \(1/8\) retains success probability greater than \(1/2\). Project its output and verify whether it is Hamiltonian. Verification prevents false positives when no Hamiltonian cycle exists.

This gives a one-sided-error polynomial-time algorithm for directed Hamiltonian cycle. ∎

### Scope of this obstruction

This does **not** establish hardness of approximately counting perfect matchings.

It establishes that one tempting global-update primitive is computationally too strong to use as an uncharged component. A successful matching sampler could use a very nonuniform distribution on alternating cycles.

The unresolved requirement is therefore not “make the moves global.” It is:

> Generate global moves with computable probabilities, correct balance, and sufficient transport between substantial parts of the matching space—without solving the uniform alternating-cycle sampling problem.

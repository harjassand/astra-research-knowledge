## 3. Static dielectric matching and dynamic contrast

A mass-only polar dielectric oscillator has

    epsilon(omega) = epsilon_infinity
      + (n Z*^2 / epsilon_0) / (K - M omega^2 - i M gamma omega).

At omega=0 its ionic contribution depends on K, not M. All isotope layers then have the same static permittivity; permuting their order changes no electrostatic reflection, even at finite lateral wavevector. At finite frequency their dielectric tensors differ.

The actual two species need not have identical static or high-frequency permittivity after quantum structural renormalisation. Therefore the code includes BOTH an exactly mass-scaled dielectric model and a reference using the published in-plane endpoints for h11BN. Static equality is an ideal-model theorem; actual equality is an experimental tolerance, not an assumption.

The retarded normal wavevector of a uniaxial layer is

    kz_j = sqrt(epsilon_t,j k0^2 - epsilon_t,j q^2/epsilon_z,j),

with nonnegative imaginary part. The p-polarized interface coefficient is

    r_ij = (epsilon_t,j kz_i - epsilon_t,i kz_j)
           / (epsilon_t,j kz_i + epsilon_t,i kz_j).

Layer coefficients are combined by the usual finite-thickness reflection recursion. The distinction arises from ordered, noncommuting layer propagation, not from inventing a new favourable material parameter.

In symmetric external media the unloaded structure and its geometric mirror share the overall mode spectrum. Their fields and coupling at a specified face need not be equal. When attached to an asymmetric target, the full loaded modes must be recomputed; unloaded isospectrality is not promised for the target system.

### Reference optical inputs

| Quantity | h10BN | h11BN in reference | Status |
|---|---:|---:|---|
| epsilon_infinity, in-plane | 5.1 | 5.1 | h10 model used in [4]; shared h11 value is an approximation |
| in-plane TO, cm^-1 | 1394.5 | 1359.8 | published endpoints [2,4] |
| in-plane LO, cm^-1 | 1650 | 1608.7 | published endpoints [2,4] |
| in-plane damping, cm^-1 | 1.8 | 1.8 | h10 literature reference; h11 equality not measured here |
| epsilon_infinity, normal | 2.5 | 2.5 | reference approximation |
| normal TO/LO, cm^-1 | 785 / 845 | both multiplied by 1359.8/1394.5 | h10 literature reference; h11 pure-mass approximation |
| normal damping, cm^-1 | 1.0 | 1.0 | reference approximation |

Loss sensitivity multiplies BOTH axes' damping by 1, 3 and 6. No low-temperature improvement in linewidth is assumed. In the ideal model, h11 LO is instead scaled by exactly the same factor as its TO, producing exact DC matching. This table is not a measured dielectric tensor of the proposed specimen. It must be replaced by a joint optical fit before manufacturing a performance claim.

## At most two genuine broader consequences

### 1. Counting does not rescue choiceless polynomial space

**Exact theorem target.** Define CPS(Card) by Ferrarotti–Schewe's deterministic finite-support, fixed-arity ASM syntax, adding ordinary von Neumann Card. Then PTIME is not contained in CPS(Card), witnessed by Q. In particular CPS(Card) does not capture PSPACE. On the expander family every fixed deciding ASM requires exp(Omega_M(N)) peak active-object count.

**Why it matters.** This excludes unlimited-time reuse of polynomial HF memory as a way around CPT's polynomial-time obstruction. It addresses an explicit 2024 question about a strictly more permissive resource setting, with counting and all HF ranks retained.

**Precise bridge.** The source does not formally define counting. We specify it and encode each finite-support dynamic function by its nonzero graph inside a tagged HF root. An r-ary graph has at most W^r entries when all nonzero-location arguments and values lie in the active family of size W. Assignment, branching and parallel rules yield fixed bounded-comprehension update terms; exact clash handling and zero-valued deletion restore one current graph root. The existing fixed-term footprint theorem bounds temporary work by W^{O_M(1)}, without a time factor.

No specialist priority validation has occurred. A literature sweep found only arXiv v1 for Ferrarotti–Schewe and no later primary paper resolving its counting question, but this is not exhaustive.

**Falsifier.** A permitted source primitive, state component or update behavior not faithfully expressible by a fixed term of polynomial footprint; e.g. uncharged nonzero location arguments, a succinct-number primitive, powerset, or history that cannot be removed. In the inspected syntax arguments/values are charged; none of the excluded primitives is present. Direct tests additionally target false truthiness, duplicated/conflicting updates, deletion and sibling-update visibility.

### 2. A single finite-field solvability operator cannot be eliminated with subexponential HF space

**Exact statement.** The query Q is definable by one F_3-solvability operator applied after polynomial-space choiceless preprocessing, as source243 §8 explicitly constructs; alternatively two rank tests suffice. Therefore no general translation eliminating that operator into the specified fixed Card-enabled HF terms can preserve subexponential peak hereditary memory on all inputs, even if arbitrary finite runtime is allowed. Quantitatively, a polynomial-memory source computation has exp(Omega(N)) target memory on the hard family.

Equivalently, FPS_3 and FPR_3 are not contained in the just-defined CPS(Card) once consequence 1's bridge is accepted. This is a model-relative noncontainment, not an assertion that all PTIME escapes all linear-algebraic logics.

**Why it matters.** It identifies a concrete primitive-level barrier: keeping all data invariant while allowing structured finite-field linear algebra is qualitatively stronger than merely iterating set construction and cardinality. Unlimited time is insufficient to compile away this algebraic primitive with polynomial memory.

**Precise bridge.** The input matrix has explicitly definable polynomially many tuple-indexed rows/columns. Its coefficients are bounded counts modulo three, representable by ordinary Card and bounded pure-ordinal arithmetic. The source243 all-ones/0–1 matrix normal form uses one solvability call. A fully syntactic extension of the fixed HF model by this operator would need its matrix encoding and the polynomial preprocessing bound written out; the source gives the logical formula but not this machine-level compiler.

**Falsifier.** A purported small-memory Card-only implementation of this precise matrix-solvability call, verified against the model and resource conventions, would contradict the lower bound. A rank/solvability primitive itself is instead a boundary control: it is equivariant and decides Q with polynomial explicit storage, so the phrase 'all symmetry-preserving computation requires exponential space' is false.

**Research value.** This sharpens an already source-reported FPS/FPR-vs-CPT separation to unlimited-time space. It is useful mathematical positioning, not by itself a route to a second historic breakthrough.

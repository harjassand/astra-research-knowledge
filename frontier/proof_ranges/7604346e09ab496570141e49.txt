## 4. Strongest consequences

### A. Dimension-independent classical approximation of channel powers

For KMS-symmetric \\(T\\), use the same comparator \\(\Psi\\) and define

\\[ \Lambda_n=\Psi T^n. \\]

Each \\(\Lambda_n\\) is entanglement breaking.

Since \\(0\preceq\Psi\preceq I\\),

\\[ (I-\Psi)^2\preceq I-\Psi. \\]

Using Theorem A,

\\[ \begin{aligned} \\|(T^n-\Lambda_n)A\\|\_\sigma^2 &\le2\langle T^nA,(I-T^2)T^nA\rangle\_\sigma\\\ &\le2\max\_{0\le x\le1}x^n(1-x)\\|A\\|\_\sigma^2. \end{aligned} \\]

Therefore,

\\[ \boxed{ \\|T^n-\Lambda_n\\|\_{2,\sigma\to2,\sigma} \le \sqrt{\frac{2n^n}{(n+1)^{n+1}}} \le\sqrt{\frac2{n+1}}. } \tag{11} \\]

This extends Astra's dimension-independent power approximation from the tracial setting to arbitrary faithful stationary states.

If \\(T\\) is KMS-normal, not necessarily self-adjoint, applying Theorem A to \\(T^\sharp T\\) similarly gives

\\[ \boxed{ \inf\_{\Lambda\ {\rm EB}} \\|T^n-\Lambda\\|\_{2,\sigma\to2,\sigma} \le 2\sqrt{\frac{n^n}{(n+1)^{n+1}}}. } \tag{12} \\]

These rates do not require spectral gaps.

### B. Classicalization of Cesàro powers without normality

The arbitrary nonnormal case admits another unconditional conclusion.

Let

\\[ F_N=\frac1N\sum\_{k=0}^{N-1}T^k. \\]

Using Theorem B, set \\(\Lambda_N=\Psi F_N\\), which is EB.

For any Hermitian \\(A\\),

\\[ \begin{aligned} \\|(F_N-\Lambda_N)A\\|\_\sigma^2 &\le8\langle F_NA,(I-H_T)F_NA\rangle\_\sigma\\\ &=8\langle F_NA,(I-T)F_NA\rangle\_\sigma. \end{aligned} \\]

The telescoping identity

\\[ (I-T)F_N=\frac{I-T^N}{N} \\]

and KMS contractivity give

\\[ \boxed{ \\|F_N-\Lambda_N\\|\_{2,\sigma\to2,\sigma} \le\frac4{\sqrt N}. } \tag{13} \\]

Thus even for an arbitrarily nonnormal, nonreversible self-compatible channel, its Cesàro iterates admit dimension-independent entanglement-breaking approximation.

This is not a pointwise estimate on \\(T^N\\) itself.

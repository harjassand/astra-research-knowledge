## 8. Exact output and its scope

At p=2/5, gamma=0.77213952 and b=0.22786048. The exact rational quantity 1-4b-b squared is positive. Since the five-clause gate is decreasing in particle occupations, b(p) is increasing, so the certificate condition holds for every 0<p<=2/5.

Equations (5), (7), (13), (14) and (18) therefore form a finite, completely evaluable lower-bound formula throughout that interval. No trajectory, system-size extrapolation, fitted decay length or numerical percolation threshold is part of its validity.

The elementary upper bound is

\[
D(p)\le(1-p^3)^2. \tag{27}
\]

To derive it, put f=0 in (1). The rate requires a vacancy in each of two disjoint triples of neighbors, independent of the exchanged occupations. Therefore E[c a^2]=2chi(1-p cubed) squared. Better specialized variational upper bounds already exist [4]; (27) is displayed only to show the present enclosure's width.

`certified_bounds.json` stores the exact rational lower and upper endpoints, gate probabilities, module costs, coarse-energy bounds and cutoffs. Displayed decimals are not used as evidence. The theoretical proof and the arithmetic certificate require independent mathematical review; a separate checker is not the same thing as independent peer review.

## 9. Resources, boundary handling and precision

A complete regeneration from the fixed five-clause gate, including graph construction, flow proposal, integer repair, independent verification, exact lower-bound evaluation, and adversarial/geometric tests, was run as

```
OPENBLAS_NUM_THREADS=1 /usr/bin/time -v python reproduce.py
```

The measured full-process wall time was **11.08 seconds** and peak resident memory was **247,264 KiB (241.47 MiB)**. The separate finite verification itself took approximately **1.03 seconds**, excluding process startup, in the final run. `reproduction_resources.txt` and the accompanying logs preserve the measurements. These timings measure regeneration and verification, not the research/literature investigation. They are not portable performance guarantees.

The finite certificate has 998,400 edge entries. Each current has denominator 2^40. Numerical convergence is not a correctness assumption; a poorer proposal simply gives a more expensive exact repaired flow. The verifier rejects a one-integer-unit corrupted current and checks a bound excluding int64 overflow before incidence accumulation. All moment sums are arbitrary-precision integers.

The tested environment was Python 3.13.5, NumPy 2.3.5 and SciPy 1.17.0. Only generation needs SciPy. Checking and evaluating the supplied witness need NumPy and the Python standard library.

### Honest scaling

For an L by L block, a complete two-block binary configuration graph has 2^(2L squared) states, with a polynomial-in-L factor in the number of edges. The current implementation pays this cost at L=3. It provides no polynomial algorithm in arbitrary block size.

For fixed L, evaluating a finite-radius current at one configuration requires only O(R squared) coarse gate queries, each of which reads at most L squared minus one reservoir bits. Matrix bounds (23) involve only two by two rational matrices. Fraction bit lengths and the stored current's denominator must still be paid for.

Exact expectation of a general truncated current may require enumeration of exponentially many radius-R gate configurations: 2^O(R squared), even though evaluating it at one configuration is inexpensive. No claim of polynomial accuracy complexity is made. At a fixed subcritical gate probability, R grows logarithmically in inverse desired L2 error up to logarithmic corrections, but exact moment enumeration can still be exp(O(log squared(1/epsilon))).

For the headline lower bounds, that expectation enumeration is unnecessary: the explicit majorant (14) already closes the proof. The full-current pointwise evaluator is almost surely finite under (12), with expected exploration size controlled by the proved radius moment. It can fail to terminate on exceptional infinite-obstacle configurations; finite-cutoff evaluation is uniformly finite.

Occupied exterior in the finite module is a conservative legality device, not a simulation boundary condition used to approximate the physical coefficient. The nine-phase average removes partition artifacts. Reservoir forcing prevents intermediate-state changes from invalidating current coefficients. The overlap weights account for simultaneous module use. These are all parts of the certificate, not post-processing assumptions.

## 10. What changed relative to the local no-go theorem

The earlier theorem rules out finite-range exactly conserved legal currents with positive transport in box-closed dynamics. This construction does not contradict it.

A finite module has an explicitly nonzero source–sink defect. A finite-radius spatial current can also have nonzero divergence; the tests exhibit a defect of magnitude one. The actual nonlocal current cancels those defects through spatial conservation after conditioning on the reservoirs. The convergence to it has the explicit energy tail (25).

Thus finite computation no longer tries to represent the final current inside an exact local kernel. It represents a finite source law, a nonlocal completion rule, and a quantitative tail certificate. The appropriate finite object is the **defect together with its completion interface**, not an already conserved local current.

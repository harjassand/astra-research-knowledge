## 4. Exact relational representation

At each semantic checkpoint the simulator has a finite domain `U` bijective with a transitive family of actual objects in `HF(A)`. The family contains all input atoms, the set `A`, `Empty`, `true`, the native current state and its recursive members, and a reserve of ordinals.

Stored relations include:

- a unary predicate for input atoms and the input relations, false on nonatoms;
- unary constant markers for `Atoms`, `Empty`, `true`;
- exact membership `E(x,y)` and its reflexive-transitive closure `C(x,y)`;
- singleton current-state marker `Cur`;
- unary `Ord`, marking precisely `[0],...,[R]`, and singleton `Top`, marking `[R]`;
- fixed-arity argument/value tables for the finitely many syntactic subterm occurrences;
- finite control predicates.

Each actual HF object has exactly one domain element. No order or choice on the atoms is introduced. `Set(x)` is the complement of the input-atom predicate because the only urelements are the original input atoms.

All semantic tests, including Härtig tests, are made only at checkpoints with unique object representatives. Representational duplicates inside a tuple construction are never counted as distinct HF objects.

### Initialization without choosing atoms

For `n>=2`, a fixed three-dimensional interpretation creates `n+3` objects. Tuples `(a,a,a)` represent the original atom `a`; the equality-pattern classes `x=y != z`, `x=z != y`, and `y=z != x` each represent one of `Empty`, `true`, and `Atoms`, respectively. Quotient each of these latter pattern classes to one object. All classes exist for `n>=2`. Define their membership directly: each atom belongs to `Atoms`, and `Empty` belongs to `true`. Initialize the exact closure and the reserve `[0],[1]`, with top `[1]`.

The initial native state is `Empty`, but this does not cause immediate halting: a finite first-step control flag suppresses the halt test until the first native step is evaluated. Halt/out are then read according to the native convention.

## 5. A uniform fresh-set constructor

Suppose `U` is a semantic checkpoint. Let `V(v)` be a fixed-arity relation of parameter tuples from `U`, and let `theta(v,u)` be a fixed FO+H formula over `U`. We can, with a fixed-dimensional interpretation, adjoin all actual sets

`b_v = {u in U : theta(v,u)}` for `v in V`,

merge every duplicate with other new or old sets, and preserve the exact representation invariant. The result has at most `|U|+|V|` elements.

Here is a full semantic specification of interpretation formulas. Use descriptors `old(u)` and `new(v)`. For a k-coordinate environment choose fixed length `L>=max(3,k+2)`. Equal final coordinates signal an old descriptor whose object is the first coordinate; unequal final coordinates signal a new descriptor whose environment is the first k coordinates. Other padding coordinates are ignored by equality. For zero-arity environments ignore the payload. At least two elements are available, so both tag patterns have representatives without choosing any atom.

Define descriptor equivalence by:

- `old(u) ~ old(w)` exactly when `u=w`;
- `new(v) ~ new(w)` exactly when `forall z (theta(v,z) iff theta(w,z))`;
- `new(v) ~ old(u)` exactly when `Set(u)` and `forall z (theta(v,z) iff E(z,u))`.

Because `U` is transitive, old-set membership rows are complete. The relation above is exactly equality of the denoted HF objects; in particular it is an actual equivalence relation. The `Set(u)` clause is essential.

Raw membership is inherited on old descriptors, and relates `old(z)` to `new(v)` precisely when `theta(v,z)`. Saturate this relation under descriptor equivalence on both coordinates. Likewise lift each retained old relation and each new table, saturating all coordinates under equivalence. These formulas are FO-definable because descriptor lengths are fixed. They give congruence-respecting quotient relations even when a new set coincides with an old one. No representative is chosen.

For closure, start with raw old closure, equality of descriptors, and the rule

`old(x) C new(v)` iff `exists z (C_old(x,z) and theta(v,z))`.

Again saturate under descriptor equivalence. This is the exact reflexive-transitive closure of the new membership. Every newly adjoined set has only old elements; any downward nontrivial path from it enters the old transitive family on its first edge. A new descriptor may coincide with an old object, but saturation accounts for that case. No general reachability computation is being smuggled into FO.

The source model used by the exponential-state theorem additionally permits generated equality and existential representative relation semantics. Our construction already uses a genuine equivalence and saturated relations, so it lies within that model as a special case.

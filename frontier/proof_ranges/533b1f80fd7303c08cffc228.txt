Let G be a finite connected undirected graph, c_e>0 its supplied conductances, and w_i>0 its supplied reversible CTMC masses. Fix distinct singleton source s and target t. Put q_ij=c_ij/w_i. Ground t, and let A be the grounded conductance Laplacian. Put a=e_s and b=(w_i)_{i!=t}. The requested directional MFPT is

    T = a^T A^{-1} b = E_s[tau_t].                         (1)

Indeed the first-step/backward equation is A u=b with u_t=0. The ground-state Green function v=A^{-1}a satisfies v_s=1/C, and h=Cv is the s-versus-t committor. Therefore (1) also equals sum_i w_i h_i/C. A singleton target's own mass is absent from b. No equilibrium partition sum needs to be computed.

**Single-ground restriction.** The cycle-block refinement below is proved for one grounded vertex. For multiple target vertices, first wire/identify all targets into one ground, retain resulting parallel edges, remove any resulting self-loops, and recompute the multigraph's edge blocks. Removing multiple target rows while reusing the original graph's bridge blocks is invalid: for the unit path target 0--source 1--target 2, grounding both endpoints gives A=[2] and MFPT 1/2, whereas treating the original two bridges as exact separate gradient blocks can incorrectly return 1. After wiring targets 0 and 2, the two edges form a parallel-edge cycle, restoring the correct cycle space. Multiple zero-valued vertices in a coarse trial target cluster are allowed only because the original verifier still grounds the actual singleton t and retains all other residuals. The current implementation accepts one target index and does not automate a target-set transformation. The independent audit countermodel is recorded in ../goal_certificate_audit_sol/PROOF_AUDIT.md.

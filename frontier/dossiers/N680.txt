INTERFACE
Work over C. For a three-tensor T = sum_i e_i tensor A_i, define T[d] = sum_i e_i tensor (A_i tensor I_d), equivalently placing the unnormalized bipartite maximally entangled vector Phi_d = sum_a f_a tensor f_a on the second and third parties. Write T >= S when three separate local complex-linear maps send T exactly to S, and T >=_cat S iff some finite d >= 1 has T[d] >= S[d]. The source describes this as a stochastic exact branch with nonzero success probability, potentially arbitrarily small; the bipartite catalyst is returned exactly and uncorrelated with the target. It is not deterministic conversion, approximate conversion, or a three-party catalyst.

THEOREM FAMILY CLAIM A — REPRESENTATION COMPILER
For a finite presentation A = Q<X_1,...,X_t>/(p_1,...,p_m), the report claims an effective compiler to integer three-tensors T_A,S_A such that, for every integer d >= 1,

    A has a unital (not necessarily faithful) representation in M_d(C)
        iff T_A[d] >= S_A[d].

The encoding size is polynomial when the relations are supplied as arithmetic circuits. The reported construction first reduces relations to quadratic/linear gate equations and encodes them as two-sided matrix equations. It adds marker blocks for forms x_*, x_*+x_i, 2x_*+x_i with block sizes h_j=(s+1)j. Rank monotonicity forces an arbitrary first slice map to permute the marker hyperplanes; the size gaps force the permutation to be the identity, and the forms' incidences force the map to be scalar. A distinguished full-rank marker slice then separates core from marker coordinates, yielding the represented algebra relations. This is the report's proposed cancellation-resistant proof spine, not an independently verified one.

THEOREM FAMILY CLAIM B — FIXED-AFFINE RE-COMPLETENESS
The report claims fixed integer three-tensors U,V,S, with U,V of one fixed format, tensor-rank(V)=1, and U,V,S entrywise strictly positive, such that

    { n in Z_{>=0} : U+nV >=_cat S }

is RE-complete under computable many-one reductions. The target and formats are fixed; n is binary encoded and the varying source coefficients have bit length O(log(n+1)). The reported hardness reduces integer polynomial solvability to finite-dimensional algebra representations and then applies Claim A; for each fixed d, conversion is a finite polynomial-system question, so enumeration over d gives RE membership. The unbounded catalyst dimension is the source of undecidability. No efficient catalyst-finding or conversion-execution algorithm is claimed.

The same source derives, as consequences of Claim B rather than separate cards: no computable uniform bound on sufficient catalyst dimension; no sound, complete, effectively enumerable finite certificate system for all impossible conversions; and a nonsemialgebraic real-parameter conversion set on the fixed affine line. Retain these only under the same assumptions and proof-status limitations.

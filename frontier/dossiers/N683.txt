THEOREM FAMILY: PROTOCOL-PRESERVING REPLACEMENT
All systems are finite-dimensional. Let C=C_A C_B be shared bipartite memory, tau any memory state, and Lambda:AB C_A C_B -> A'B' C_A' C_B' an LOCC channel with arbitrary finite protocols and classical randomization. For an initialization xi, define

    N_xi(X) = tr_C' Lambda(X tensor xi),
    E_R(xi) = min_{gamma in SEP} D(xi || gamma),

with natural-log relative entropy. Let eta_AB=(I_A/d_A) tensor (I_B/d_B) and tau'_eta=tr_A'B' Lambda(eta_AB tensor tau). The report claims that if E_R(tau'_eta)=E_R(tau), then for any closest separable state gamma_* to tau,

    N_tau = N_gamma_* in LOCC.

The condition is resource preservation only on the maximally mixed product input. It does not require the memory to be returned on every system input; tau may be mixed or rank-deficient and may become correlated with the output. When C'=C, the fixed-point condition tr_A'B' Lambda(eta_AB tensor tau)=tau is a sufficient special case.

PROOF INTERFACE AND COMPOSITION
The reported proof chooses a finite product-state input ensemble spanning Hermitian operators and averaging to eta_AB, plus a product informationally complete output POVM. Preparing, applying Lambda, measuring, and retaining the memory is a conditionally separability-preserving instrument. Relative-entropy data processing with the same closest-separable comparator gamma_* gives D(p||q) <= E_R(tau)-E_R(tau'_eta)=0. The full tomographic distributions agree, hence the original device has the same channel under tau and gamma_*. A finite product-state decomposition of gamma_* implements that initialization by shared randomness and local preparation. This is exact same-protocol simulation, not just an output-state separability statement.

For a stationary device Phi(xi)=tr_A'B' Lambda(eta_AB tensor xi) with Phi(tau)=tau, the report claims that one gamma_* reproduces the complete n-slot process P_n for every n, including under adaptive external interventions. A stationary separable substitute is also claimed via Cesaro averaging. The stated generalization requires compact convex free-state sets with a full-rank member, conditional free-instrument preservation, and freely available preparations and measurements sufficient for process tomography. A separate reported application covers randomized stabilizer operations with convex classical randomization: an exactly returned magic-state catalyst does not enlarge that channel class under the stated free-tomography contract.

SEQUENTIAL RESOURCE-EXPENDITURE THEOREM
Fix a bipartite channel N not in the closure of LOCC. The report constructs a free tomographic binary test with acceptance probabilities 0<b<a<1 for the best closed-LOCC implementation and N respectively; set kappa_N=d(a||b)>0, where d is binary relative entropy. In the reported model, a causal sequential LOCC simulator implements one call before receiving the next input. Its error epsilon_n is the maximum adaptive distinguishing advantage, normalized to [0,1], and all retained shared quantum registers are included in its finite-dimensional memory. If epsilon_n<a-b, the claimed bound is

    E_R(tau_n)-E_R(tau'_n) >= n d(a-epsilon_n || b).

If the simulator also uses m_n ebits and an arbitrary finite-dimensional catalyst chi_n returned exactly as a marginal (it may be correlated with other outputs; return on the averaged test input suffices), then

    m_n ln 2 >= n d(a-epsilon_n || b),
    liminf_{n->infinity} m_n/n >= kappa_N/ln 2 when epsilon_n -> 0.

The report therefore claims the zero-cost boundary

    E_seq^cat(N)=0 iff E_seq(N)=0 iff N is in closure(LOCC),

for its sequential universally usable simulation model. This does not identify the optimal positive cost or provide an algorithm to compute it.

TWO DISTINCT STRONG CONVERSES
1. If m_n ebits are the only initial nonfree resource, for every b<s<a the source reports

    epsilon_n >= 1-exp(-n d(s||a))-exp(m_n ln 2-n d(s||b)).

Below kappa_N/ln 2, a suitable s gives exponential convergence epsilon_n -> 1. This is the exponential strong converse when all supplied entanglement is counted.

2. With arbitrary, uncharged, exactly returned catalysts, the source separately reports

    epsilon_n >= 1-exp(-n d(s||a))-(m_n ln 2+ln 2)/(n d(s||b)),

and hence m_n=o(n) implies epsilon_n -> 1. This is a zero-rate strong converse; it is not the exponential statement above.

SEPARABLE CHANNEL CONSEQUENCE
For an orthonormal product basis {|a_k b_k>} with a positive LOCC discrimination error gap, the report applies the measurement channel

    M(rho)=sum_k <a_k b_k|rho|a_k b_k> |kk><kk|.

Its product Kraus operators make it separable and non-entangling on separable inputs with local references, while the discrimination gap places it outside closure(LOCC). Under the claimed sequential theorem it has positive entanglement simulation cost. The discrimination gap is attributed to prior work; the cost consequence is a source-derived claim, not independently verified here.

- Tomographic completeness: for real quantum operations, free real preparations/effects do not tomograph complex channels. The reported exactly returned |+i> catalyst implements a non-real phase gate, so the replacement principle is not claimed without the free-tomography hypothesis.
- Stochastic tensor conversion: related candidate N680 in open PR #42 concerns state-specific stochastic local filters/tensor restriction. Successful branches need not define one trace-preserving channel that returns the catalyst on a free tomographic input. N683 instead concerns the entire LOCC device/all outcome branches and exact same-protocol simulation from a separable initialization under its resource-neutrality hypothesis. These are different operational contracts; neither result contradicts or validates the other. N680 is a pending contextual reference, not a logical dependency.
- Parallel simulation: the sequential proof uses a fresh next input conditioned on past records. The report does not extend it to arbitrary parallel LOCC block maps, which can conditionally filter inputs not yet released.

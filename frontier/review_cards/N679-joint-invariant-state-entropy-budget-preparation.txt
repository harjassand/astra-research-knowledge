N679-joint-invariant-state-entropy-budget-preparation | An entropy budget prepares states jointly consistent with several stochastic or quantum rules
status=source_derived_unreviewed; the supplied Computational Discovery transcript reports a proof of the preparation inequality and scoped computational consequences. This intake preserved the exact transcript and retrieval routes only; it did not reconstruct the proof or replay code. External correctness and historical priority remain UNKNOWN. No transformative computational breakthrough is claimed.

INTERFACE AND PREPARATION THEOREM
Let K efficiently implemented affine rules Phi_1,...,Phi_K act on an m-bit classical state or m-qubit quantum state. The input must include an efficiently preparable initial state rho_0 and actual one-step sampler/physical-circuit implementations; an entry-evaluation circuit alone is insufficient. Assume, as a promise, that there exists a common invariant state sigma with Phi_i(sigma)=sigma for every i and finite natural-log relative entropy D(rho_0||sigma)<=B. Sigma is not supplied: the algorithm need not prepare it or compute its entries, logarithm, or eigenvectors. The numerical value B itself is charged.
Set
    R = (1/2) I + (1/(2K)) sum_i Phi_i,
    rho_t = R^t(rho_0),
    bar_rho_T = (1/T) sum_{t=0}^{T-1} rho_t.
The source reports, for every positive integer T,
    sum_i d(Phi_i(bar_rho_T), bar_rho_T)^2 <= 2 K B / T,
where d is total variation for classical states or half trace distance for quantum states. Hence T >= 2 K B / delta^2 implies max_i d(Phi_i(bar_rho_T),bar_rho_T) <= delta. Operationally, choose J uniformly from {0,...,T-1}, run J lazy rule updates, and discard the random-choice record; this directly prepares the mixed state bar_rho_T. It does not require mixing, a spectral gap, reversibility, normality, commutativity, an expanded transition matrix, or a density-matrix description.

COMPUTATIONAL CONSEQUENCE
Under a uniform construction with polynomially bounded K, B, delta^{-1}, initialization and rule costs, any decoder that is correct on every delta-jointly-consistent state is simulable in BPP for classical rules and BQP for quantum rules: prepare bar_rho_T and run the decoder. Ordinary BPP/BQP computation embeds in the contract through a one-bit replacement rule, so the theorem gives no extra complexity power under these promises. It does not make the promises efficiently recognizable, and robustness to physical faults is not the same as correctness on every small-residual state.
The source also derives an oracle-model search-compilation tradeoff. Let q_pre, q_init, q and q_dec be oracle queries for preprocessing, one initialization, one rule application and decoding, and let the decoder consume r independently prepared copies. It reports q_pre + r q_init + q_dec + C r q(1+KB/delta^2) >= Omega(N) classically or Omega(sqrt(N)) quantumly, for an absolute C. This uses established unstructured-search lower bounds and is restricted to the stated oracle compiler model.

COMMON-SUPPORT COUNTEREXAMPLE
For a satisfying set S, add symbols a,b and define deterministic idempotent rules F_a,F_b that fix x in S and send x outside S to a or b respectively. Each has an easy individual fixed state, while their average has the bad stationary law (delta_a+delta_b)/2. For every distribution mu,
    max{d(mu F_a,mu), d(mu F_b,mu)} <= delta
        implies mu(S) >= 1 - 2 delta.
Thus separate approximate consistency forces acquisition of satisfying support; averaging can hide it by cancellation. The source reports stability under perturbing each rule by at most eta in maximum-row total variation, with lower bound 1-2(delta+eta). Every common invariant law is supported on S, so a full-support initialization has no finite-relative-entropy common reference in this example. This refutes the proposed removal of the common-reference assumption, not arbitrary algorithms.

DIVERGENCE OBSTRUCTION
For any divergence monotone under all finite stochastic maps and q=delta_0, the source constructs maps fixing q and mapping any two distributions p,r supported outside 0 into one another. Data processing both ways forces the divergence to assign the same value to p and r relative to delta_0: it is flat on that support face (possibly infinite). Therefore it cannot be finite on that face and satisfy a uniform positive midpoint-curvature bound in total variation there. Under the report's additional normalization, first-argument convexity, data-processing and midpoint-curvature assumptions with constant c, it derives
    mathfrakD(delta_i||q) >= c floor(log_2(1/q_i)).
If q_i=0 the same argument forces an infinite divergence value, and the quantum obstruction already follows on diagonal states. This is a scoped obstruction to that repair strategy; it does not exclude adaptive support acquisition, non-data-processing potentials, or other algorithms.

OPERATIONAL AND PRECISION CONTRACT
The exact update count is O(1+KB/delta^2) rule opportunities per prepared output, multiplied by the actual costs of the supplied circuits. Memory is one state, rule/init workspace, supplied circuit storage and O(log T+log K) counter bits. With ideal fair bits, padding horizons/counts to powers of two gives bounded selection with constant-factor overhead. The common reference, entropy bound and universal decoder guarantee are promises, not verified by the algorithm. The output is approximately consistent, but need not be close to any particular invariant state. For implemented initialization error eta_0 and per-rule error eta (maximum-row TV or half-diamond norm), the transcript gives a sufficient regime T>=8KB/delta^2, eta_0<=delta/16, eta<=delta/(16T); these are accuracy bounds, not cheap-synthesis guarantees. Estimating an extra bounded observable to error epsilon with failure probability zeta takes O(epsilon^-2 log(1/zeta)) independent prepared outputs and multiplies the full preparation cost.

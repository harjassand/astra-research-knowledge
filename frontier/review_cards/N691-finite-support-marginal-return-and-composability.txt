INTERFACE
Let σ_AB be a finite-dimensional bipartite state. A preparation uses a finite-dimensional catalyst τ_{C_A C_B}, separable additional inputs, and a successful branch S of an LOCC instrument such that S(τ)=p Ω_{AB,C} for p>0, tr_C Ω=σ, and tr_AB Ω=τ. The catalyst is returned exactly in its success-conditioned marginal; Ω may correlate output and catalyst. Failure is unrestricted. This is state preparation, not a universally reusable channel implementation.

THEOREM FAMILY — FINITE SUPPORT CRITERION
The report claims these are equivalent:
1. σ admits the stated stochastic marginal-return preparation.
2. range(σ) contains a nonzero product vector.
3. σ=wω+(1−w)χ for a separable state ω and 0<w≤1.

When the criterion holds, the construction uses local catalyst dimensions at most d_A+1 and d_B+1. The necessity proof applies to every finite catalyst and every p>0, and remains valid for separable operations. A stronger reported version allows any fixed source state whose support is spanned by product vectors. All claims remain source-derived and unreviewed.

PROOF SPINE AND SUPPORTING RESULTS
For the positive direction, subtract a sufficiently small separable component from σ, flag the residual state in an active catalyst sector, and use shared randomness to either keep that residual in the catalyst or swap it into the output. The successful joint state has exactly the required two marginals. The construction does not clone the input resource.

For the converse, a product-free target support U admits a strictly positive product informationally complete measurement with a uniform one-copy relative-entropy separation κ_U>0. Data processing then gives E_R(ρ_n)≥nκ_U for every, possibly correlated, output supported on U^{⊗n}. Repeated success preserves this support while every successful branch has Schmidt number at most the finite initial catalyst's Schmidt number r, hence E_R(ρ_n)≤log r. These inequalities contradict each other for sufficiently large n, independent of how small p is. The report extends the iteration argument to product-spanned source supports.

NONCOMPOSABILITY AND ERROR BOUNDARY
The state-level marginal-return relation is not transitive: a flagged Bell/vacuum state is reachable from a free input with correlated marginal-return catalyst, and its active sector yields a Bell state, although the Bell state itself fails the support criterion. Physical postselection consumes the catalyst, despite the state-level marginals.

The report's finite capped reservoir keeps success probability q fixed and bounds output error and unconditioned output–catalyst trace distance by q^K. The stored resource and catalyst dimension grow with K; the catalyst already contains copies of the target. Thus this is not free generation and it does not give return guarantees after every later postselection. The source reports that requiring the catalyst marginal to remain τ after every nonzero product-effect outcome is equivalent to Ω=σ⊗τ; with finite catalysts this stronger product-return condition cannot generate an entangled state from a separable input.

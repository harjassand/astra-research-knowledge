# Status authorities and historical access editions

For a current result, use [current retrieval](../knowledge/README.md) and its packet. Packets combine current scoped reviews, corrections and authoring authorities.

`CURRENT_CLAIM_STATUS.jsonl` is a pinned baseline; `CURRENT_CLAIM_STATUS.d/` supplies later status shards. Neither a baseline count nor an old dossier is the full current inventory. The compiler applies explicit current replacements as described in [the intake contract](../knowledge/INTAKE.md).

Dossiers, proof-range indexes, v1-v5 readers/builders and dated reports are historical access editions. Reproduce them at their recorded revision. Do not run a dated builder to update current Capital.

Use [agent/COMPOSITION.txt](../agent/COMPOSITION.txt) for transfers and [state/CONTINUITY.md](../state/CONTINUITY.md) for published handoffs. `PRIORITIES.md` is a historical coordination aid, not evidence of current researcher activity.

ASTRA_KNOWLEDGE | entry point | local + web

Purpose: recoverable frontier knowledge outside model weights, with small task-specific context. This folder combines Literature Digestion's scientific checkpoint and full archived research assets with all nine A–I source documents, the latest compact handoff, and J/K result summaries. It enables in-context use and persistent retrieval; it does not train Astra's weights or prove Astra has mastered the corpus.

READING PATH
1. 01_CORE.txt: compact scientific map and the boundaries that prevent false transfers.
2. topics/<topic>.txt: choose acquisition, quantum, complexity, tensors, rounding, analysis, geometry, number_theory, probability or methods.
3. cards/<claim>.txt: statement, scope, mechanism, costs, obstruction and evidence IDs. L cards are curated current literature results; P cards preserve prior handoff records; W cards are selected current worker-report extracts; N cards cover subsequent J/K supplied summaries, with their full linked notes/packs unprovided.
4. Open the cited proof/gate/implementation when a result becomes load-bearing. Original byte snapshots remain available in evidence/objects, mapped by indexes/files.jsonl. Full source reading is separate from abstract/report intake.

LOCAL (Python3 standard library; no model calls/accounts/API keys)
 python3 tools/knowledge.py search "cyclic oracle acquisition"
 python3 tools/knowledge.py packet "conditional reference qubit archive" --topic quantum --budget 6000
 python3 tools/knowledge.py read L01-cyclic-grid
 python3 tools/knowledge.py read <source-id> --start 1 --end 100
 python3 tools/knowledge.py links L01-cyclic-grid
 python3 tools/knowledge.py next --topic quantum
 python3 tools/knowledge.py mark <ID> --level read --note "Exact assumptions and open prerequisite recorded."
 python3 tools/knowledge.py verify --full

Budget: installed tiktoken gives o200k_base estimates; otherwise packet uses conservative UTF-8 byte bounds. Neither is a claim about Astra's exact private tokenizer. Packets include source IDs and incomplete-extract labels; increase budget or follow IDs to complete proofs. --history includes earlier cycles. Search uses local contextualized FTS/BM25, not an embedding model or a promise of perfect recall.

WEB

 Agent endpoints: /api/search?q=... ; /api/packet?q=...&budget=6000 ; /api/read?id=... ; /api/stats
 Static agent map: web/llms.txt; web/pages/<source-id>.html; exports/ASTRA_BRIEF.txt.
 The full folder can be served on a chosen web host. The static export runs without Python and includes linked scientific text pages. Deployment status is recorded separately from this scientific snapshot. A cloud agent needs a reachable hosted URL, an uploaded export, or a local executor; another computer cannot reach this computer's loopback address.

RESEARCH USE
Turn a result into a typed representation: input/oracle contract → transformation → guarantees → charged acquisition/execution cost → dependencies → failure domain → discriminating use. Store this in state/representations.jsonl and retain cited source IDs. Preserve negative results and equally informed controls. For broad digestion, use state/reading_queue.json in batches; state/ACTIVE_CONTEXT.txt is the compact continuation record. All queue items begin UNREAD, not "learned".

IMMUTABLE INPUTS / LIMITS
Exact-byte duplicates share one archived object; versions with different bytes remain separate. Git database, Python bytecode/cache directories and Finder metadata are excluded explicitly; runtime dependencies are archived but excluded from default reading/search. Source HTML extraction is discovery text and may lose math; use the original snapshot or linked TeX/PDF. No scientific check/Lean build was rerun as part of packaging. Claim status and source-reported read depth are retained; links_to edges are navigation, not asserted proof prerequisites.

T10 INFORMATION NETWORK — FROZEN PHASE-I RECORD v1
Date: 2026-10-09
Status: candidate internally derived weighted-support theorem; no external proof validation or priority claim

1. Exact operational target
===========================

Let (X_i,Y_i), i=1,...,n, be iid with a fixed finite-alphabet law P_XY. Encoder X sees only X^n and sends one message M_X; encoder Y sees only Y^n and sends M_Y. There is no feedback, encoder cooperation, decoder side information, or run-time common randomness. A decoder must recover Z^n, where Z_i=f(X_i,Y_i), with block error probability tending to zero. Rates are log_2 |M_X|/n and log_2 |M_Y|/n. Fixed codebooks may be selected in the achievability proof; their selection is not a run-time shared-randomness cost.

Selected original problem: characterize the rate-region support value

    C_lambda(P_XY,f) = inf { R_X + lambda R_Y : (R_X,R_Y) is achievable }

for finite Latin-square functions f. Here “Latin square” means |X|=|Y|=|Z|=q and, for every fixed y, x -> f(x,y) is a permutation, and for every fixed x, y -> f(x,y) is a permutation. This is a sharply defined multi-terminal distributed-function problem. The result below only determines a range of support directions; it does not characterize the full rate region.

2. Literature check and scope choice
====================================

Primary sources consulted on 2026-10-09:

* J. Körner and K. Marton, “How to encode the modulo-two sum of binary sources,” IEEE Trans. Inf. Theory 25(2), 219–221 (1979), DOI 10.1109/TIT.1979.1056022. This establishes the structured-code rate region for the doubly symmetric binary source and XOR. It does not settle arbitrary binary source laws.
* C. Nair and Y. N. Wang, “On optimal weighted-sum rates for the modulo sum problem,” ISIT 2020, pp. 2416–2420, DOI 10.1109/ISIT44484.2020.9174208. Primary full text: https://chandra.ie.cuhk.edu.hk/pub/papers/Misc/mod-sum.pdf. Their Theorem 4 gives the weighted outer bound for finite-field modulo sums, λ≥1, by an auxiliary-variable entropy minimization; their proof uses the conditioned Csiszár/Körner–Marton sum identity. Their exactness conditions include convex/concave-envelope tests for Slepian–Wolf and Körner–Marton operating points.
* Y. Tsujino and S. Watanabe, “The Condition for Structured Coding to Improve Random Coding in the Binary Modulo-sum Problem,” arXiv:2606.25570v2, 12 Aug 2026, https://arxiv.org/abs/2606.25570. Theorem 4 proves when the adjacent-parity m-letter Ahlswede–Han (AH) scheme eventually improves on the Slepian–Wolf (SW) sum rate. It does not characterize the modulo-sum capacity region.
* M. Sefidgaran and A. Tchamkerten, “On Computing a Function of Correlated Sources,” arXiv:1107.5806v3, https://arxiv.org/abs/1107.5806. This treats decoder side information and graph-based bounds, with matching cases including partial invertibility relative to that side information. It does not directly give the weighted bound below for a decoder that sees only the two messages and must compute a Latin-square function.

The original XOR/general-binary-distribution route was not completed. The current research question is whether the Nair–Wang proof depends on group addition or only on the relevant invertibility identity. The derivation below shows that only Latin-square invertibility is needed for the one-sided weighted bound. A targeted search did not find this formulation in the primary sources above, but this is not an exhaustive novelty or priority audit. Treat it as a candidate extension of an existing method, not as an established discovery.

3. Candidate theorem: a weighted converse for Latin-square functions
====================================================================

Write W_Y(y|x)=P(Y=y|X=x) and W_Z(z|x)=sum_y W_Y(y|x) 1{f(x,y)=z}. For any λ≥1, any achievable rates obey

    R_X + λ R_Y >= H(X,Y) + min_{U-X-Y} [ λ H(Z|U) - H(Y|U) ].          (1)

The minimization is over finite auxiliaries. For fixed P_X and the channel W_Y, this is single-letter and computable: a choice of U is equivalent to a distribution over posterior input laws p_u=P_{X|U=u} whose mean is P_X. Thus the minimum is the lower convex envelope, at P_X, of

    g_lambda(p) = λ H(p W_Z) - H(p W_Y).

Equivalently, with phi_lambda(p)=H(p W_Y)-λH(p W_Z) and cav denoting the upper concave envelope,

    R_X + λ R_Y >= H(X,Y) - cav(phi_lambda)(P_X).                       (2)

For the symmetric direction, if f is also bijective in y for each fixed x, then for λ≥1,

    λ R_X + R_Y >= H(X,Y) + min_{V-Y-X} [ λ H(Z|V) - H(X|V) ].          (3)

This is the exact form needed below; the point is that addition in a group is not used in the derivation.

4. Full derivation of (1)
=========================

Fix a blocklength n code with messages M_X and M_Y and error probability P_e. Put U=M_X, V=M_Y, and Z^n=f^n(X^n,Y^n). Then U-X^n-Y^n-V is a Markov chain, and Fano gives H(Z^n|U,V) <= n eps_n with eps_n -> 0 along any reliable code.

Since U and V are deterministic encodings,

    I(U;X^n|V) + H(Z^n|U,V) <= H(U) + n eps_n <= n R_X + n eps_n,
    I(V;Y^n|U) + H(Z^n|U,V) <= H(V) + n eps_n <= n R_Y + n eps_n,
    I(U,V;X^n,Y^n) + 2H(Z^n|U,V) <= n(R_X+R_Y) + 2n eps_n.

For λ>=1, combine the sum inequality with λ-1 times the second inequality. Using U-X^n-Y^n-V,

    I(U,V;X^n,Y^n)=I(U;X^n)+I(V;Y^n|U),

so, after absorbing a vanishing term,

    n(R_X+λR_Y) >= I(U;X^n) + λ I(V;Y^n|U) + (1+λ)H(Z^n|U,V) - o(n).  (4)

Because V-Y^n and Z^n is a deterministic function of (X^n,Y^n),

    I(V;Y^n|U)=I(V;Z^n|U)+I(V;Y^n|U,Z^n),
    I(V;Z^n|U)+H(Z^n|U,V)=H(Z^n|U).

The first equality uses I(V;Z^n|U,Y^n)=0, which follows from the Markov chain. Therefore the right side of (4), before -o(n), equals

    I(U;X^n) + λ H(Z^n|U) + H(Z^n|U,V)
       + λ I(V;Y^n|U,Z^n).                                             (5)

The Latin condition in the X coordinate says that, given Y^n, Z^n and X^n determine one another. Also V is conditionally independent of X^n given (U,Y^n). Hence

    H(Z^n|U,V,Y^n)=H(X^n|U,V,Y^n)=H(X^n|U,Y^n).

Consequently

    I(U;X^n)+H(Z^n|U,V)
      = H(X^n)-H(X^n|U)+H(Z^n|U,V,Y^n)+I(Z^n;Y^n|U,V)
      = H(X^n)-I(X^n;Y^n|U)+I(Z^n;Y^n|U,V)
      = nH(X,Y)-H(Y^n|U)+I(Z^n;Y^n|U,V).                              (6)

The last equality uses U-X^n-Y^n, so H(Y^n|X^n,U)=H(Y^n|X^n)=nH(Y|X). Substituting (6) into (5) gives the exact decomposition

    I(U;X^n)+λI(V;Y^n|U)+(1+λ)H(Z^n|U,V)
      = nH(X,Y) + λH(Z^n|U)-H(Y^n|U)
        + λI(V;Y^n|U,Z^n)+I(Z^n;Y^n|U,V).                              (7)

Both final mutual-information terms are nonnegative.

It remains to tensorize the entropy difference. For iid (X_i,Y_i), let

    U_i = (U, Z^{i-1}, Y_{i+1}^n).

The conditioned Csiszár sum identity gives

    λH(Z^n|U)-H(Y^n|U)
      = sum_i [(λ-1)H(Z_i|U,Z^{i-1})
                 +H(Z_i|U_i)-H(Y_i|U_i)].                              (8)

Since λ-1>=0 and conditioning cannot increase entropy,

    RHS(8) >= sum_i [λH(Z_i|U_i)-H(Y_i|U_i)].

The iid source and U-X^n-Y^n imply U_i-X_i-Y_i. Each summand is therefore at least the single-letter minimum in (1). Thus

    λH(Z^n|U)-H(Y^n|U)
      >= n min_{U-X-Y}[λH(Z|U)-H(Y|U)].                                 (9)

Combining (4), (7), and (9), then taking n to infinity, proves (1). To obtain (3), repeat the derivation with X,Y interchanged and use bijectivity in the other Latin-square coordinate.

The only function-specific step is (6), which needs x<->f(x,y) to be a bijection for every y. No group law, linearity, associativity, or additive code appears in the converse.

5. Exact weighted Slepian–Wolf support under a convexity condition
==================================================================

Suppose f is Latin in both coordinates. Define

    phi_lambda(p) = H(p W_Y) - λ H(p W_Z),    p in the q-simplex.

If phi_lambda is convex on the simplex, then its upper concave envelope is the affine interpolation of its vertex values:

    cav(phi_lambda)(P_X)
      = sum_x P_X(x) phi_lambda(delta_x)
      = H(Y|X) - λH(Z|X).

The first equality follows because convexity gives phi(p) <= sum_x p(x)phi(delta_x), while every concave majorant lies above that vertex interpolation. The Latin property in the Y coordinate gives H(Z|X)=H(Y|X). Substituting into (2),

    R_X+λR_Y >= H(X,Y)-H(Y|X)+λH(Z|X)
              = H(X)+λH(Y|X).                                         (10)

The Slepian–Wolf code that sends X losslessly at rate H(X), and sends a bin of Y at rate H(Y|X), lets the decoder recover both sources and then compute f. Its weighted cost equals the right side of (10). Hence

    C_lambda(P_XY,f)=H(X)+λH(Y|X)                                      (11)

for every λ>=1 for which phi_lambda is convex. This is an exact support value of the operational rate region, not a bound on the whole region.

A finite threshold is guaranteed by a useful explicit condition. Assume every entry of W_Y is positive and W_Z has full rank. For tangent vectors d with sum_x d_x=0, the Hessian is

    D^2 phi_lambda(p)[d,d]
      = (1/ln 2) [ λ sum_z ((d W_Z)_z)^2/(p W_Z)_z
                         - sum_y ((d W_Y)_y)^2/(p W_Y)_y ].            (12)

All denominators stay positive on the simplex. Full rank of W_Z makes the first quadratic form positive for every nonzero tangent vector. Compactness therefore makes

    Lambda = max(1, sup_{p in simplex, d != 0, sum d=0}
       { sum_y ((dW_Y)_y)^2/(pW_Y)_y }
       /{ sum_z ((dW_Z)_z)^2/(pW_Z)_z })                              (13)

finite. For λ>=Lambda, (12) is nonnegative everywhere, so (11) applies. Equation (13) is a finite-dimensional, directly computable sufficient threshold. It need not be the smallest threshold.

This is the candidate novel mechanism: a pointwise Hessian comparison between the source channel X->Y and the induced function channel X->Z exposes an exact weighted-rate face, even when f has no group structure.

6. Explicit order-5 non-group example
=====================================

Use X=Y=Z={0,1,2,3,4} and the function table (rows are x, columns are y):

        y=0  1  2  3  4
    x=0   2  0  3  1  4
      1   3  1  4  0  2
      2   4  2  0  3  1
      3   1  3  2  4  0
      4   0  4  1  2  3

Every row and column is a permutation; the diagonal is (2,1,0,4,3), also a permutation. `latin_square_check.py` checks these facts and exhaustively checks all 120^3 triples of symbol/row/column permutations for an isotope representation

    alpha(f(x,y)) = beta(x)+gamma(y) mod 5.

No such triple exists. Since every group of order 5 is Z_5, this table is not isotopic to a group operation of order 5. This finite exhaustive result is scoped to the displayed table and uses an elementary permutation search.

Let X be uniform on {0,...,4}, and let

    P(Y=y|X=x) = 4/5 if y=x, and 1/20 otherwise.

This is a full-support, non-independent source. Given X=x, the output Z=f(x,Y) has probability 4/5 at g(x)=f(x,x) and 1/20 at each other output, because row x of the Latin square is a permutation. Since g is a permutation, W_Z is a 5-ary symmetric channel up to a relabeling of outputs; W_Y is the usual 5-ary symmetric channel.

Write a=4/5, b=1/20, delta=a-b=3/4. For input law p,

    (pW_Y)_y = b + delta p_y,
    (pW_Z)_z = b + delta p_{g^{-1}(z)}.

For every tangent d, the two Hessian quadratic forms in (12) obey

    sum_y ((dW_Y)_y)^2/(pW_Y)_y <= (delta^2/b) sum_x d_x^2,
    sum_z ((dW_Z)_z)^2/(pW_Z)_z >= (delta^2/a) sum_x d_x^2.

Thus their ratio is at most a/b=16. The curvature condition holds for every λ>=16, and the exact weighted support is

    C_lambda = log_2(5) + λ h_5(4/5,1/20,1/20,1/20,1/20),   λ>=16,

where h_5 is the entropy of the displayed five-point distribution. Numerically,

    H(X)       = 2.321928095 bits/symbol,
    H(Y|X)     = 1.121928095 bits/symbol,
    C_16       = 20.2727776 weighted bits/symbol.

The point is achieved by ordinary Slepian–Wolf binning with X decoded first and Y decoded using X. The exact weighted converse proves that no separate-encoder code, including structured or nonlinear codes, can lower R_X+λR_Y below this corner for λ>=16. This does not claim that the corner is optimal for other weight directions.

7. Binary modulo-sum diagnostic; gap remains open
==================================================

For XOR, the primary literature already contains a stronger specialized route. The current exploratory candidate (theta_00,theta_01,theta_10,theta_11)=(0.379,0.008,0.246,0.367) has full support. Direct enumeration of the known adjacent-parity AH construction gives:

    H(X,Y) = 1.6146847311,
    H(Z) = 0.8175566363,   2H(Z)=1.6351132726,
    R_AH^(3) = 1.5999981809 bits/source-symbol.

So this known scheme lies below both the SW sum H(X,Y) and the KM sum 2H(Z). `ah_parity.py` reproduces the calculation by enumerating all 4^m source word pairs and evaluating H(U,V) and H(U,V,Z_m); it is a finite inner-bound diagnostic, not a converse. The single-letter Nair–Wang bound at λ=1 is not tight at this example. No matching lower bound or capacity formula was found. The full arbitrary-source binary modulo-sum rate region remains unresolved in this work.

8. Counterexamples, degeneracies, and proof gates
=================================================

* If f is not injective in x for some fixed y, identity (6) fails; the bound (1) has not been proved for that function. If f is injective only in x, (1) remains valid but the symmetric bound (3) need not.
* λ<1 is not covered by this tensorization: the coefficient λ-1 in (8) has the wrong sign. No extension is claimed.
* If W_Z is rank-deficient, the Hessian denominator in (13) can vanish along a nonzero tangent direction; convexity may still hold, but the stated finite-threshold guarantee does not apply.
* At zero-error, positive-rate and blocklength assertions above do not transfer: all achievability statements use vanishing block error and asymptotic block coding.
* The order-5 weighted-support example is not a full rate-region result and is not evidence that a new general capacity theorem has been proved. It only establishes one exposed support direction under a sufficient curvature threshold.

Remaining novelty gates: check published versions and citations around Nair–Wang, Han–Kobayashi, and Sefidgaran–Tchamkerten for an equivalent general Latin-square weighted converse; independently rederive the block-code-to-AH outer representation and all Markov steps; test whether the curvature threshold is sharp for the q-ary example; characterize the reciprocal support direction and any interval where non-SW schemes become optimal; compare actual achievable points outside λ>=16.

# Code-image recognition for complement LCU: a binary-test spectral obstruction

Date: 2026-10-08  
Status: **INTERNALLY-PROVED-CANDIDATE** for the exact invariant and its application to the full fine-spectrum BMVZ list. It rules out replacing the complement-LCU image by an ordinary stabilizer/subsystem/qLDPC or flat orbit-code image while preserving its binary diagonal compression exactly. It does **not** rule out an arbitrary sparse positive enforcer for the original non-stabilizer LCU image, nor a comparison-only replacement with a different diagonal effect.

## Question and fixed interface

For the complement-LCU encoding of the full projection sum

    H = sum_j pi_j h_j,       0 <= h_j <= I,       sum_j pi_j=1,
    V|psi> = U(|0>_label |psi>),
    B = (I-|0><0|)_label tensor I_data,

we have the exact identities

    V*BV = F = I-(I-H)^2 = 2H-H^2,
    H <= F <= 2H,
    C_0 = UBU* = I-VV*,
    ker(C_0)=ran(V),       C_0 >= I-VV*.

Thus B is one computational-basis diagonal **projection**, not just a general effect, and the canonical C has exact gap one. The issue is its row support and whether its image can be recoded into a standard code image without losing the diagonal-test interface.

The report uses the full hard-plus-seed list with the route's disjoint dummy-projector fine-spectrum augmentation `H_fine` from `04_dilation_variants.md`. The hard block is retained in full; the proof uses any one hard-block eigenpair and never replaces the instance by the seed-only pair. The dummy terms are an explicit hardness-preserving augmentation of the generated positive projection list, not a claim about the unmodified fixed ABN-to-BMVZ output. A dummy term is needed for the invariant below; the scope if those dummy terms are removed is stated explicitly.

## The orbit-spectrum lemma

Let Q be a qubit stabilizer code subspace in the physical computational basis, and let B_diag be any computational-basis diagonal projection (entries only 0 or 1). For every isometry E onto Q, every eigenvalue of

    E* B_diag E

is a dyadic rational, i.e. belongs to Z[1/2].

Proof. Put the stabilizer tableau in CSS/orbit normal form. The computational-basis support splits into disjoint valid orbits O of the X-part of the stabilizer group, each of size 2^r for a common r. A stabilizer logical basis vector has the form

    |ell_O> = 2^(-r/2) sum_(z in O) omega_O(z)|z>,   |omega_O(z)|=1,

and distinct logical basis vectors have disjoint supports. Hence compression of B_diag is diagonal in this basis and its O eigenvalue is

    b_O = 2^(-r) sum_(z in O) 1[z in supp(B_diag)]
        = integer / 2^r.

For any other isometry E onto Q, E=E_0 W for a logical unitary W, so E*B_diag E=W*(E_0*B_diag E_0)W; its eigenvalues are unchanged. This proves the claim independently of the logical frame or code description size.

The same proof covers an ordinary subsystem stabilizer code when the encoded image is the full stabilizer subspace (logical and gauge qubits both included), or a stabilizer gauge-fixed subspace when the gauge is fixed by Pauli/stabilizer constraints. A fixed arbitrary non-stabilizer gauge state is outside that class: the selected image is then not the full stabilizer code space, and its extra gauge-state enforcer must be analyzed separately.

More generally, any flat monomial orbit code with disjoint uniform-amplitude orbit basis has rational compression eigenvalues under a binary diagonal projection: the value is a count divided by orbit size. Thus an irrational eigenvalue also rules out that standard orbit-code form, even when orbit sizes are not powers of two.

## Full-list irrational-spectrum witness

Use the actual seed-plus-hard augmented BMVZ input from the source audit and the fine-spectrum list in `04_dilation_variants.md`. After BMVZ repetition, the separate seed colors give

    h_(phi,R) = I-(I-P_phi)^(tensor R),
    h_(psi,R) = I-(I-P_psi)^(tensor R),
    c = |<phi|psi>| = 1/(2 sqrt(2)).

In `H_fine`, these two clauses have weights 1/8 each, the hard base list has total weight 1/4, and the disjoint dummy terms are `sum_k delta_k P_k` with rational delta_k>0; in particular delta_1>0. Add the zero-projector padding term if needed to keep a normalized convex list; it does not affect H.

Let S=span{phi,psi} and L=S^perp. On the reducing subspace

    R_seed = S tensor L^(tensor (R-1)),

one has h_(v,R)=(P_v tensor I) for v=phi,psi. Therefore

    (h_(phi,R)+h_(psi,R))/8

has the two eigenvalues

    s_+ = (1+c)/8,       s_- = (1-c)/8,
    s_+-s_- = c/4 = 1/(8 sqrt(2)).

Choose any eigenvalue lambda of the hard-base BMVZ block, with eigenvector |g>. Its contribution in `H_fine` is t=lambda/4, since the hard block's weight 1/2 in the seed-augmented BMVZ input is multiplied by the outer 1/2 used in `H_fine`. The dummy register sum has eigenstates of energy 0 and delta_1: choose |00000> on every dummy block for 0, and replace the first by |10000> for delta_1. The hard, seed, and dummy registers are disjoint. Thus the full list has eigenvectors with eigenvalues

    x_(+,d)=t+s_++d,       x_(-,d)=t+s_-+d,
    d in {0, delta_1}.

This argument uses the full hard block only through the existence of one eigenpair; it does not assume a known ground state, a known hard-instance energy, or frustration freeness.

Set f(x)=2x-x^2. These are eigenvalues of the actual LCU compression F=f(H_fine). For each d,

    D(d) = f(x_(+,d))-f(x_(-,d))
         = (s_+-s_-)(2-2t-2d-s_+-s_-).

Consequently

    D(delta_1)-D(0) = -2 delta_1 (s_+-s_-)
                    = -delta_1/(4 sqrt(2)),

which is irrational because delta_1 is a nonzero rational. If all four eigenvalues f(x_(+,0)), f(x_(-,0)), f(x_(+,delta_1)), f(x_(-,delta_1)) were dyadic, both D(delta_1) and D(0), and therefore their difference, would be dyadic rational. That contradicts the displayed irrational value. Hence:

> **Theorem (binary-diagonal code-image obstruction).** For the stated full fine-spectrum augmented BMVZ family, the complement-LCU compression F=2H_fine-H_fine^2 has at least one irrational eigenvalue. It cannot equal E*B_diag E for any qubit stabilizer-code image E (including any logical-frame change) and any computational-basis diagonal projection B_diag. In particular, no physical basis change that leaves the test a binary diagonal projection can turn this exact LCU image into a standard stabilizer/subsystem/qLDPC code image while preserving the compression F.

The nonzero dummy register energy is essential to this proof. If all dummy terms are removed, the irrational difference argument above no longer applies as written. It is not a claim that the unaugmented seed-plus-hard list has irrational compression spectrum; that case would need a separate spectral witness.

## What the obstruction does and does not exclude

1. **Excluded:** keeping the complement-LCU compression exactly while replacing its image by a standard stabilizer, stabilizer subsystem, qLDPC stabilizer, CSS, or flat uniform-orbit code image and retaining a binary diagonal test. The conclusion is spectral, so it allows any logical unitary within the candidate code image and any choice of binary diagonal projection.
2. **Not excluded:** a positive polynomial-row C for the original LCU image, which is generally non-stabilizer. The canonical C has gap one but the exact selected-row witness in `01_canonical_C.md` gives at least 5^R entries for its specified legal PREPARE completion. This is not a lower bound for every PREPARE completion or every positive enforcer of that image.
3. **Not excluded:** replacing B by a general diagonal effect with arbitrary real entries, or asking only for a constant-factor Loewner comparison rather than the exact F. On a standard CSS image, arbitrary orbit-constant values give an arbitrary diagonal logical contraction; a free logical eigenbasis can formally represent an aggregate H. Its eigenbasis, eigenvalue access, and circuit costs are not supplied. The binary-projection invariant does not apply to that changed interface.
4. **Basis change escape and its cost:** applying U* to the LCU physical image makes it the trivial stabilizer subspace |0>_label tensor data, with enforcer B of row degree one and gap one. It simultaneously replaces the physical test by B'=U*BU, which is generally not computational-basis diagonal. The theorem above rules out repairing this by some other binary diagonal projection on a stabilizer-code image while retaining exact compression F for `H_fine`.

The result therefore defeats the specific “recognize this LCU image as a stabilizer/orbit code and import its expander enforcer” route under the preserved binary test. It does not close the high-ceiling sparse-enforcer question for general non-stabilizer images.

## Concrete cubical qLTC checks: normalized gap and access costs

For a concrete candidate code, take the four-dimensional binary CSS family of Chen–Huang–Liu–Tang (CHLT), Theorem 1.2: explicit polynomial-time matrices `H_X,H_Z` with `H_X H_Z^T=0`, `K>=alpha N`, `D>=delta N`, check-row and column weight at most a constant `Delta`, `m_X,m_Z=Theta(N)`, and classical qLTC inequalities

    |H_X x|/m_X >= rho dist(x,ker H_X)/N,
    |H_Z z|/m_Z >= rho dist(z,ker H_Z)/N.

The theorem's constants are absolute but not numerically instantiated; it gives check-matrix construction, not a decoder. At its native lengths the physical/logical overhead is `N/K<=1/alpha`. Standard symplectic elimination constructs a tableau and Clifford encoder in polynomial time (a conservative `O(N^3)` binary-elimination bound); no decoding procedure is needed for the expander enforcer below. Its qLTC soundness is Hamming-distance rejection, not a normalized quantum energy gap. The same conclusions below hold for any commuting bounded-incidence CSS stabilizer family.

If one nevertheless tries to enforce a distance-at-least-two stabilizer/qLDPC code with a positive bounded-weight check average, normalization imposes a separate gap bound. Let m commuting nonidentity stabilizer checks S_j have supports at most w, Q_j=(I-S_j)/2, and

    C_av = (1/m) sum_(j=1)^m Q_j.

Its kernel is the code and every non-code joint-syndrome vector violates at least one check, so gamma(C_av)>=1/m. Since distance is at least two, choose a physical site and X or Z error with nonzero syndrome; it violates only checks incident to that site. If the maximum check incidence is Delta, then

    gamma(C_av) <= Delta/m.

Thus with m=Theta(N), bounded weight/incidence gives the exact scale `1/m <= gamma <= Delta/m = Theta(1/N)`. For CHLT, a weight-one Pauli error is at distance one from the relevant classical syndrome kernel for all sufficiently large N; qLTC soundness lower-bounds its rejection fraction by `rho/N`, while bounded column incidence upper-bounds that fraction by `Delta/m`. Both are order `1/N`, not a constant. Each CSS check projector has at most two nonzero entries per computational-basis row. The full average has at most `m_X+1` entries per row (off-diagonal X shifts plus one merged diagonal), `O(mw)` row-scan work, and coefficient bit length `O(log m)`. The unnormalized sum has gap at least one but norm at most m; dividing by m is what restores a contraction and produces the inverse-linear gap. More generally, for positive local projector weights summing to one, weighted incidence sums to at most w over N sites, so some one-site Pauli error has energy at most `w/N`. This is the local-check normalization barrier; it is not a claim about arbitrary nonlocal C.

For an ordinary stabilizer orbit image, the separate expander-orbit construction gives a positive contraction with kernel exactly that image, gap `delta_exp=(1-lambda_0)/2`, and row degree `D+1` for a constant-degree explicit expander. A row query solves the pure-Z affine constraints, obtains the orbit representative/coordinates by Gaussian elimination, then enumerates `D` rotation-map neighbors; this costs `poly(N)` time and space, with exact constant-bit rational weights for CSS phases (fourth-root phases for general stabilizer tableaux). No decoder is used. It is nonlocal: expander edges can connect strings at Hamming distance `Theta(N)`. The orbit enforcer is therefore an excellent C for an admissible stabilizer image, but the theorem above prevents pairing it with the retained binary LCU test/compression on `H_fine`.

The complement-LCU itself has polynomial circuit size in the term-table size and repetition R; B is a label-only binary projection with row degree one and O(log M) locality. A specified entry of C_0=I-VV* is computable from O(M^2 R) constant-size factor operations. For the completion in `01_canonical_C.md`, one full physical row contains at least 5^R nonzeros (exactly 5^R within its selected same-label block), so row listing is exponential even though entry evaluation is polynomial. For other completions, the full row bound remains open; a polynomial row-list for an arbitrary C on the original LCU image is likewise unknown.

## One aggregate test and the full-code algebra boundary

The seed-pair noncommutation argument for two separately requested tests does not settle an interface that asks for one test of the total Hamiltonian. For the legitimate seed-augmented hard input, a separate partial-trace/anticommuting-Pauli argument rules out exact `V_0^* B V_0=H` in every fixed Clifford frame, but it does not rule out a constant-factor Loewner sandwich in that fixed frame. See `../../cycle2/high_ceiling/route_qldpc_common_code.txt` for the exact construction and scope.

For a fixed stabilizer encoder `V_0`, the full compression algebra is exactly the diagonal algebra in its induced logical orbit basis: every physical diagonal effect compresses to orbit averages. If the logical frame is unrestricted, write `V=V_0 W` and diagonalize one aggregate positive contraction `H=W^* Lambda W`; assigning `Lambda_O` to each physical code orbit gives a formal single diagonal effect and the same orbit-expander enforcer. This proves an algebraic escape, not an efficient one: the logical diagonalizer and orbit-to-eigenvalue query may require exponential description or storage. In the current LCU interface B must remain a *binary projection* and the target is the exact compression `F`. For `H_fine` the irrational-spectrum theorem above rules out even this free-frame escape. Replacing B by an arbitrary real-valued diagonal effect, deleting the dummy augmentation, or weakening exact equality to a Loewner comparison leaves this argument inapplicable; those gates remain open.

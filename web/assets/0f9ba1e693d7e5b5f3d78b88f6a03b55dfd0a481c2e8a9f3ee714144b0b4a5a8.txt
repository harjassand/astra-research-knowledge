POLYNOMIAL MARGINALIZATION OF A RENEWAL TYPE CODE
Root derivation, 8 October 2026. INTERNALLY-PROVED CANDIDATE. Independent Sol
and two Luna derivations agree on the core theorem; the lead also audited it.
No external correctness or priority claim. Do not infer a breakthrough.

TARGET AND CONTROL
One stationary binary renewal path X_1,...,X_n, iid positive integer gaps
with arbitrary finite mean. Predict its actual next symbol X_(n+1), scored by
expected conditional KL, uniformly over this whole class. No mixing, finite
support, bounded mean, reset episodes or model oracle. Han-Jiang-Wu (2024),
arxiv:2404.15454v1 Theorem4, prove minimax order n^-1/2 and state that an
attaining polynomial-time algorithm is unclear. Their Proposition1 and
Section3.4 give the redundancy-to-terminal-risk conversion. We claim no new
statistical rate or conversion; the proposed addition is efficient exact
marginalization of an explicit block distribution with O(sqrt n) regret.

1. A PROPER FINITE-HORIZON BLOCK DISTRIBUTION
Fix N>=1. A nonzero binary string of length N has R+1 ones, first position a,
an ordered list of R positive gaps, gap counts C_j (1<=j<=N-1), and span
S=sum j C_j<=N-1. Put R=sum C_j. A type is the count vector C; the number
of strings of this type is exactly
             (N-S) R! / product_j C_j!.
Indeed there are R!/product C_j! ordered gap lists, and a has N-S choices.
Empty C corresponds to the N strings with a single one. Add the allzero
string as its own extra type. With p(s) the integer partition count, p(0)=1,
the total number of types is
             K_N=1+sum_(s=0)^(N-1) p(s).
Choose a type uniformly and a string uniformly within it. This defines Q_N,
positive on every binary string, with
 Q_N(x)= product C_j! / [K_N (N-S) R!]  if x has at least one one,
 Q_N(0^N)=1/K_N.
There is no exponential enumeration in this definition's implementation.

2. POINTWISE REGRET AGAINST EVERY STATIONARY RENEWAL LAW
Write gap law p_j and mean mu. For a nonzero string with trailing age
b=N-a-S, renewal regeneration gives exactly
 P(x)= [P(G>=a)/mu] product_j p_j^C_j P(G>b).
Both bracket/tail factors are <=1, so P(x)<=product p_j^C_j. The multinomial
probability of the count vector C in R iid draws is at most1, hence
             product p_j^C_j <= product C_j!/R!.
For R=0 both products are1. Thus P(x)/Q_N(x)<=K_N N for all nonzero x;
for allzero x it is <=K_N. Consequently
             D(P_N||Q_N)<=log K_N+log N.

For a self-contained partition bound, t>0 gives
 sum_(s=0)^(N-1)p(s)<=exp(tN) product_(j>=1)(1-exp(-tj))^-1,
 log product =sum_(k>=1)1/[k(exp(tk)-1)]
             <=(1/t)sum k^-2 <=2/t.
Choosing t=sqrt(2/N) gives
             log K_N <= log2+2sqrt(2N).
All logarithms are natural. This is O(sqrt N) pointwise regret, not just
average redundancy. Block coding itself is classical prior methodology;
complete priority of this particular elementary distribution is unresolved.

An additional boundary improvement, derived independently by the direct-hazard
Luna worker and checked by root, removes the extraneous logN. Write s_j=P(G>=j).
Since mu>=a s_a and mu>=(b+1)s_(b+1),
 s_a s_(b+1)/mu <=1/max(a,b+1)<=2/(a+b+1)=2/(N-S+1).
Consequently P(x)/Q_N(x)<=2K_N(N-S)/(N-S+1)<=2K_N for every nonzero word,
and the allzero bound is K_N. Thus D(P_N||Q_N)<=log(2K_N). The algorithm
is unchanged, and the risk numerator in (5.1) can be reduced to
2log2+2sqrt(2(n+1))+log(n+2). Both displayed risk bounds are valid.

3. EXACT PREFIX MARGINALS WITHOUT ENUMERATING TYPES OR SUFFIXES
Denote by q_N(x^t) the marginal of this SAME horizon-N distribution, not an
independently normalized horizon-t code. This distinction is essential.

If x^t has no ones, a type of span S has first position uniform1..N-S, so
 q_N(0^t)=(1/K_N)[1+sum_(S=0)^(N-1) p(S)(N-S-t)_+/(N-S)].       (3.1)
This includes t=0 and t=N and is computable by the usual partition DP.

Otherwise let first one be at a, let the r completed observed gaps have
counts c_j, and let b be the number of trailing zeros after the last one.
Let W(C)=product_j (C_j)_(c_j), where falling factorial is zero if C_j<c_j.
For a full type C of total gap number R>=r and span S<=N-a, the probability
of the specified ordered prefix gaps in a random permutation is W(C)/(R)_r.
The probability of no further one in the observed b slots is1 when R=r;
when R>r it is
             L_b(C)/(R-r),  L_b(C)=sum_(j>b)(C_j-c_j).
Indeed a next gap must exceed b, and its conditional law is proportional
to the remaining counts. Therefore define aggregate integer tables
 A(S,R)=sum_C W(C),
 B(S,R)=sum_C W(C)L_b(C),
where the sums fix span S and count R. Then EXACTLY
 q_N(x^t)=(1/K_N) sum_(S<=N-a,R>=r)
       [ A(S,r)/((N-S)(r)_r)                         if R=r,
         B(S,R)/((N-S)(R)_r(R-r))                    if R>r ]. (3.2)
The first summand notation means only the R=r row is included, with
(0)_0=1 and (r)_r=r!. No unobserved gap law is used.

To compute A,B, initialize A_0(0,0)=1, B_0=0. For each possible length
j=1,...,N-1, and multiplicity u=0,...,floor((N-1)/j), put
 w=(u)_(c_j), ell=(u-c_j) if j>b else0, omitting w=0.
For each preceding (S,R), update if S+ju<=N-1:
 A_new(S+ju,R+u)+=w A_old(S,R),
 B_new(S+ju,R+u)+=w[B_old(S,R)+ell A_old(S,R)].          (3.3)
This is an ordinary product-weight DP with one additive marked statistic.
All quantities are nonnegative integers. It covers R=r and empty observed
gap lists and permits all future type completions. The restriction S<=N-a
is applied only in (3.2). No exponential suffix search is hidden.

4. ARITHMETIC AND RUNTIME
There are O(N^2) states per layer, O(N) layers and at most N+1 choices u.
Thus the naive DP costs O(N^4) integer operations and O(N^2) table storage.
Since W(C)<=N^r, the number of types <=2^N, and L_b<=N,
all table integers have O(N log(N+1)) bits. In fact every denominator in
the grouped sum (3.2) divides N!: when R=r it is (N-S)r!, and when R>r
it is (N-S)(R)_(r+1), a divisor of (N-S)R!. Since R<=S, N-S<=N-R,
and R!(N-S) divides N! (the factor N-S divides the product of any N-R
consecutive integers), this claim follows. Equivalently, choose a multiple
of N-S among R+1,...,N, which exists since the interval has length N-R.
Thus H_N(x^t)=K_N N! q_N(x^t) is an integer with polynomial bit size.
Multiplication by K_N preserves polynomial bit size. This stronger arithmetic
observation was supplied by the independent Sol audit.
Thus exact rational marginals, ratios and comparisons take polynomial bit
time. A conservative schoolbook bound O(N^6 log^2(N+1)) per marginal is
sufficient; it is not optimized. Precomputing factorials and local weights
is polynomial. Positive support makes all conditional denominators nonzero.

5. TERMINAL PREDICTOR AND GUARANTEE
Take N=n+1. For each t=1,...,n let q_t(y|z^t)=q_N(z^t y)/q_N(z^t), using
the marginal of the FIXED Q_N. Output the average on actual suffixes
        qhat_n(y|x^n)=(1/n)sum_(t=1)^n q_t(y|x_(n-t+1):n).
At most O(n) independent DP calls give a conservative O(n^5) integer-operation
bound (and polynomial exact bit time). The output is a rational Bernoulli law;
the exact average of n rational conditionals can require O(N² log(N+1)) output
bits, which remains polynomial and is charged separately from a single marginal.

For clarity, the source's conversion is reconstructed. Convexity and
stationarity bound terminal expected KL by
 (1/n)D(P_N||Q_N)+(1/n)sum_(t=1)^n
              I(X_(n+1);X_1:(n-t)|X_(n-t+1):n).
The second sum is bounded by I(Z_1;X_1:N), where Z_1 is the stationary
countdown state. One proof uses the stationary entropy rate h_infty:
the sum of conditional entropy differences is at most
H(X_1:N)-N h_infty=I(infinite past;X_1:N)<=I(Z_1;X_1:N).
The last inequality follows from past -> Z_1 -> future. Countdown states
Z_1>N all produce the same allzero length-N observation, so the finite
cap min(Z_1,N+1) is sufficient for this block; its entropy is <=log(N+1).
No finite entropy of Z_1 itself is assumed. Thus
 sup_P E KL(P(X_(n+1)|X^n)||qhat_n(.|X^n))
       <=[log2+2sqrt(2(n+1))+log(n+1)+log(n+2)]/n.       (5.1)
This is O(n^-1/2), matching the established statistical lower order.
It is expected terminal risk, NOT a high-probability certificate, worst-
context guarantee, frozen reusable model, or next-H block guarantee.

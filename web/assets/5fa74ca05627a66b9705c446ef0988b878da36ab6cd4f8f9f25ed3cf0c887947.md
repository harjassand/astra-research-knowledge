# Binary-weight hafnians from unweighted perfect matching counts

**Status:** complete elementary reduction, conditional only on the algorithmic correctness of the released family 113 FPRAS. No implementation of that FPRAS was acquired or replayed. The graph gadgets and their exact signatures have been reconstructed independently.

## Theorem and input model

Assume an FPRAS for the perfect-matching count of every explicit finite simple unweighted graph, with exact zero detection and worst-case polynomial bit time. Then there is an FPRAS for

\[
Z(G,w)=\sum_{M\text{ perfect matching of }G}\prod_{e\in M}w_e
\]

on every explicit simple graph with nonnegative binary-encoded rational edge weights. Running time is polynomial in the **entire** input length, epsilon^{-1}, and log(delta^{-1}); zero weights and infeasible support are handled exactly. This is equivalently an FPRAS for every nonnegative symmetric binary-rational hafnian. No numerical density, weight-ratio, or conditioning promise is needed.

The [released theorem](https://raw.githubusercontent.com/openai/math/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/A-Fully-Polynomial-Randomized-Approximation-Scheme-for-Perfect-Matchings-in-General-Graphs-September-23-2026/main.pdf) states the assumption for simple unweighted graphs. Its prescribed-degree corollary already includes unweighted f-factors and prescribed-size matching sampling. Those unweighted consequences are not new here.

## 1. A logarithmic-size edge-weight gadget

For every integer K >= 1, construct a simple acyclic directed graph D with a distinguished source s and sink t and exactly K directed s–t paths. Allow the empty path if s=t. The graph has 1+3(b-1) vertices, where b is the binary length of K.

To construct it, start with one vertex s, whose source-path count is one. Read the remaining bits of K from left to right. If the current endpoint v has count a, introduce vertices u_0,u_1,v' and edges

\[
v\to u_0,\quad v\to u_1,\quad u_0\to v',\quad u_1\to v'.
\]

The count at v' is 2a. If the new bit is one, add the edge s -> v', raising its count to 2a+1. This edge is new, so no parallel edges appear. Set v=v' and continue. All edges point forward in insertion order.

For each vertex i of D, introduce an internal pair L_i,R_i and an undirected edge L_i R_i. For each arc i -> j, introduce L_i R_j. The two external terminals are the endpoints a,b of the logical edge being replaced. Add a R_s and L_t b. There are O(log K) new internal vertices and edges.

The gadget has the following exact signature:

| Terminal use | Number of internal matching completions |
| --- | ---: |
| Neither a nor b is matched into this gadget | 1 |
| Both a and b are matched into this gadget | K |
| Only a is matched into this gadget | 0 |
| Only b is matched into this gadget | 0 |

Proof: the inactive bipartite adjacency matrix is upper triangular with a diagonal, so it has a unique perfect matching, using every L_i R_i. In an active matching, a consumes R_s and b consumes L_t. The remaining non-diagonal matched edges form one directed s–t path in D, with every other vertex taking its diagonal edge. There are no additional directed cycles because D is acyclic. Conversely every s–t path gives a matching. A one-terminal state leaves an odd number of vertices to match, so it is impossible. If s=t, the active completion consists of the empty path and has count one.

Replace every positive-weight logical edge by its disjoint-internal-vertex gadget, removing the original edge. Every original vertex must be consumed by exactly one active gadget. Active gadgets therefore identify a perfect matching M of the original graph. The completion fibre over M has size exactly product_{e in M} K_e. Thus

\[
\#\operatorname{PM}(H)=\sum_M\prod_{e\in M}K_e.
\tag{1}
\]

The expanded graph H remains simple, even when the original graph is nonbipartite. Each gadget has its own internal vertices; global bipartiteness is unnecessary.

## 2. Rational weights and bit costs

Write each nonzero w_e=a_e/b_e with positive binary integers. Let B=product_e b_e and K_e=a_e B/b_e. The binary length of B is at most the sum of denominator lengths, hence polynomial in the input. Every perfect matching of an n-vertex input has n/2 edges, so

\[
\#\operatorname{PM}(H)=B^{n/2}Z(G,w).
\tag{2}
\]

Both B^{n/2} and every K_e have polynomial bit length. If the original encoded size is L and it has m edges, the gadget construction uses O(n+mL) vertices and O(mL) edges. The common denominator creates a polynomial increase, not an expansion proportional to the numerical magnitudes of the weights.

Run the assumed FPRAS once on H and divide its rational output by B^{n/2}. Relative error and failure probability are unchanged. Zero edges are omitted. An odd vertex count or infeasible positive support produces zero exactly. For n=0 the answer is one.

The distinction from replacing weight K by K parallel edges is material: that would be exponential in the binary input length for K=2^b. The path-count gadget uses O(b) vertices instead.

## 3. Sampling, f-factors, and local marginals

The release’s approximate uniform perfect-matching sampler on H, followed by deterministic decoding, produces a matching law proportional to product w_e. Equation (1) gives the exact target law for an ideal uniform sample, and deterministic decoding cannot increase total variation. Its accuracy parameter is charged as in the released sampler; an exact weighted sampler is not asserted.

Binary-rational weighted f-factor counts follow by first using the release’s usual prescribed-degree gadget. Put the activity w_e on the incidence edge selecting original edge e and activity one on all ancillary edges. All gadget fibres retain the same factorial multiplicity. Then apply the logarithmic weight gadget. This is a straightforward extension of the already stated unweighted f-factor result, not a new structural matching theorem.

For feasible weighted perfect matchings, an edge marginal is

\[
\Pr(e=uv\in M)=\frac{w_e Z(G-\{u,v\},w)}{Z(G,w)}.
\]

Two relative estimates give a relative marginal estimate whenever the numerator is nonzero. Its zero case is detected by ordinary perfect-matching feasibility on the residual positive support. All retained graph representations and calls are charged. This does not give an oracle for an implicitly represented exponentially large graph.

## 4. Quantum probability boundary

For a supplied symmetric real matrix B with nonnegative entries and spectral norm below one, a pure zero-mean Gaussian boson outcome s has the familiar form

\[
p_B(s)=\sqrt{\det(I-B^2)}\,
\frac{\operatorname{haf}(B_s)^2}{\prod_i s_i!},
\]

where B_s repeats rows and columns according to s. The expanded size is the total photon count N_s=sum_i s_i. The hafnian reduction therefore yields relative probability evaluation in time polynomial in the matrix input, N_s and the accuracy parameters, after determinant and factorial computation. If B=DAD for diagonal unitary D and nonnegative A, every perfect-matching term has the same phase and its modulus equals haf(A_s), so the same conclusion applies to that supplied gauge representation.

The marginal expression changes after partially observing modes, but it preserves nonnegativity for this special pure nonnegative input family. Write C=[[0,B],[B,0]] and Q=(I-C)^{-1}. For paired retained indices J and their complement T, the Schur complement gives I-Q_JJ^{-1}=C_JJ+C_JT(I-C_TT)^{-1}C_TJ>=0. Thus the marginal hafnian matrices remain nonnegative. With a polynomial numerical mean-photon bound, the FPRAS supplies a conditional sequential full sampler as well. The complete interface and TV budget are in `nonnegative_gbs_sampling.md`.

More strongly, that file derives an independent positive even-closed-walk construction for the same full collision-inclusive photon law. It needs no family 113 FPRAS: a determinant PGF yields independent Poisson walk counts, and matrix powers sample each bridge. Hence a claim that this Gaussian family newly becomes tractable *because* of family 113 would be misleading. The weighted-hafnian theorem remains the conditional general-graph counting consequence.

Photon counts written in binary can still represent an exponential expanded matrix for individual probability evaluation, and rare postselection has charged acceptance cost. General signed or complex hafnians have interference and are outside the nonnegative reduction.

A decisive four-vertex falsification is

\[
A_{12}A_{34}=1,\quad A_{13}A_{24}=-1,\quad A_{14}A_{23}=0.
\]

Then haf(A)=0, whereas haf(|A|)=2. Support perfect-matching feasibility does not detect that zero. Replacing phases by absolute activities therefore does not preserve either amplitudes or their probabilities.

The Gaussian formula is included as a narrowly typed implication; physical preparation is not supplied by this work. The graph-theoretic weighted-hafnian theorem does not depend on it. See the separate photon-sampling proof for the subsequently audited sampling interface.

## Evidence and novelty limits

`check_interfaces.py` exactly enumerated the four terminal signatures for K=1,...,64 and the complete expanded graph for one weighted K4, whose weighted hafnian and expanded perfect-matching count both equal 11. There were no violations. These tests verify finite implementation identities, not the release’s FPRAS.

The mechanism is a standard-style parsimonious weight reduction using path counts and matchings. Its global novelty has not been established, and it should not be described as a new resolution of approximate counting. The consequential algorithmic conclusion remains conditional on the newly released general-graph FPRAS. The source’s displayed replica/energy constants have very high fixed powers, so polynomial asymptotics supply no practical runtime estimate on the user’s hardware.

The load-bearing FPRAS gap is the released matching sampler’s spectral/energy analysis and complete finite-bit implementation, not this weight gadget. Astra had already reconstructed a general additive-to-full-product replica-gap lemma; that prior reconstruction does not certify the remaining long-cycle energy comparison, balance geometry, or whole FPRAS.

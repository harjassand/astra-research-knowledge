# Fermionic quartic loss and interacting-resource audit

## Verdict

The N100 quartic completion survives the current Y/Z checkpoint as a scoped candidate: for an explicitly described pure two-fermion block, independent vacuum loss with the environment discarded leaves a state within $O(\eta^4)$ of a convex mixture of pure fermionic Gaussian states. I derived a sharper shape-sensitive bound whose leading constant is the second elementary symmetric function of the canonical pair weights. I also derived a conditional interaction-versus-loss code-fidelity bound by composing the Y robustness certificate with Tang et al.'s full $(g,q)$-doped fidelity theorem.

Neither result upgrades Y's scientific status. The Y package labels its proofs and checks internally supplied and unreviewed; its sampling engine is a floating-point prototype, and novelty remains unresolved. The g-dependent extension imports Tang et al. Theorem 2 and applies only to deterministic unitary circuits in that theorem's bounded-weight interaction model. The sharpest interface correction is that arbitrary downstream channels preserve *closeness to the processed Gaussian mixture*, but interacting processing need not preserve Gaussianity or make that mixture efficiently sampleable.

## Reconstructed loss interface

Write a normalized two-form in canonical pair modes as

\[
|\psi\rangle=\sum_{j=1}^{r}s_j p_j^\dagger|0\rangle,
\qquad p_j^\dagger=a_{2j-1}^\dagger a_{2j}^\dagger,
\qquad w_j=|s_j|^2,\quad \sum_jw_j=1.
\]

For particle survival \(0\le\eta<1\), let \(a=(1-\eta)^2\), \(b=\eta^2\), and \(u=b/a\). After independent vacuum loss and tracing the environment,

\[
\rho_\eta=aP_0+\eta(1-\eta)\sum_jw_j(P_{2j-1}+P_{2j})+bP_\psi.
\]

This is a mixed output from a pure input. It is not a no-loss trajectory conditioned on a flag. Let \(P(x)=\prod_j(1+xw_j)\), and take the unique \(x\ge0\) satisfying \(P(x)=1+u\). The N100 phase average of \(r+1\) BCS pure Gaussian states, plus the unchanged one-particle Slater mixture, produces \(\sigma_\eta\in\mathcal C_G\) with

\[
\sigma_\eta=\rho_\eta-\delta P_\psi+R_{\ge4},\qquad
\delta=b-ax=a(u-x)=\operatorname{Tr}R_{\ge4}.
\]

The removed two-particle weight and added four-or-more-particle tail have orthogonal supports, so \(T(\rho_\eta,\sigma_\eta)=\delta\). The familiar uniform bound is \(\delta\le a[u-\log(1+u)]\le b^2/(2a)\). Tensoring sector-faithful completions gives the exact input distance

\[
\Delta:=T\left(\bigotimes_i\rho_i,\bigotimes_i\sigma_i\right)
=1-\prod_i(1-\delta_i)\le\sum_i\delta_i.
\]

For every fixed CPTP map \(\Phi\), including one containing interactions, trace-distance contractivity gives \(T(\Phi(\otimes_i\rho_i),\Phi(\otimes_i\sigma_i))\le\Delta\). This is a comparison theorem. It does not say \(\Phi(\sigma)\in\mathcal C_G\), nor that \(\Phi(\sigma)\) has an efficient classical sampler.

## New quantitative sharpening: pair-spectrum-dependent tail

Let \(e_k\) be the elementary symmetric polynomials of the nonnegative weights \(w_j\), so that \(P(x)=1+x+\sum_{k\ge2}e_kx^k\), and set

\[
e_2=\sum_{j<\ell}w_jw_\ell=\frac{1-\sum_jw_j^2}{2}.
\]

For every \(k\ge2\), counting each \(k\)-subset by its pairs gives

\[
\binom{k}{2}e_k
=\sum_{i<j}w_iw_j\,e_{k-2}(w_{\ne i,j})
\le e_2.
\]

The last inequality uses \(e_s(v)\le(\sum v)^s/s!\le1\) for normalized nonnegative weights. If \(\eta<1/2\), then \(u<1\), and \(x\le u<1\) because \(P(x)\ge1+x\). Therefore

\[
\begin{aligned}
\delta/a&=u-x=\sum_{k\ge2}e_kx^k\\
&\le e_2\sum_{k\ge2}\frac{x^k}{\binom{k}{2}}
=2e_2\bigl[x+(1-x)\log(1-x)\bigr]\\
&\le2e_2\bigl[u+(1-u)\log(1-u)\bigr].
\end{aligned}
\]

The series sum follows by \(1/[k(k-1)]=1/(k-1)-1/k\); its right-hand function is increasing on \([0,1)\). Equivalently,

\[
\boxed{\delta\le a\left(1-\sum_jw_j^2\right)
\left[u+(1-u)\log(1-u)\right],\quad 0\le\eta<1/2.}
\]

Since the bracket is \(u^2/2+u^3/6+O(u^4)\), the leading quartic coefficient is \(e_2\):

\[
\delta\le e_2\frac{b^2}{a}+O\!\left(\frac{b^3}{a^2}\right),
\qquad \delta=e_2\frac{b^2}{a}+O\!\left(\frac{b^3}{a^2}\right)
\]

where the second relation is the existing N100 expansion. Rank one has \(e_2=0\), and in fact \(\delta=0\) exactly. Rank \(r\) has \(e_2\le(1-1/r)/2\); the balanced rank-two case has leading coefficient \(1/4\), half the general upper-bound constant. This supplies a shape-sensitive multi-block sampling certificate by summing the displayed per-block bounds and then adding the separately charged sampler error. The bound is only claimed for \(\eta<1/2\); for larger survival use N100's original bound.

For an explicitly supplied mixed two-particle state diagonalized into pure two-forms \(\sum_\alpha\lambda_\alpha P_{\psi_\alpha}\), the same construction and convexity give the weighted average of these rank-sensitive per-eigenvector bounds. This requires acquiring the \(\binom m2\)-dimensional density matrix and its spectral decomposition; it is not a many-body oracle result.

## Conditional interaction-versus-loss code bound

Here is a precise extension of N105 to deterministic interaction circuits. Let \(\mathcal C\) be an \(m\)-mode fermionic code with \(k>0\), Majorana distance \(d_F\ge3\), and a specified target codeword \(|c\rangle\). Supply \(n\) balanced standard four-mode resources \(\rho_{\eta_i}\) with unobserved vacuum loss, and let the *entire output system* be acted on by a deterministic unitary circuit \(U\) with Gaussian unitaries and \(g\) Tang-model interaction gates \(e^{i\theta_jQ_j}\), each of even Majorana weight at most integer \(q\ge4\). No postselection, measurement discard, or untracked quantum ancilla is included in this statement.

Define Tang's quantities

\[
r=\left\lfloor\frac{d_F-3}{q-2}\right\rfloor,\qquad
s=q\max\{g-r,0\},\qquad
t=\left\lfloor\frac{d_F-(q-2)\min\{g,r\}-1}{2}\right\rfloor,
\]

and

\[
\Theta_{g,q}(\mathcal C)=
\left[1-H_2^{-1}\!\left(\frac{\max\{0,k-s\}}{\max\{m-s,m-k\}}\right)\right]^t.
\]

For each pure Gaussian component of the N100 completion, the same unitary circuit is a $(g,q)$-doped Gaussian circuit: absorb the initial Gaussian preparation into the first Gaussian layer. Tang's theorem therefore bounds its overlap with \(|c\rangle\) by \(\Theta_{g,q}\); averaging over the completion preserves that bound. For the balanced resource, N102 also supplies \(\rho_{\eta_i}\preceq(1+R_i)\sigma_i^+\), where

\[
R_i=\begin{cases}
\eta_i^4/[4(1-\eta_i)^2],&\eta_i^2\le2(1-\eta_i)^2,\\
\eta_i^2-(1-\eta_i)^2,&\eta_i^2\ge2(1-\eta_i)^2.
\end{cases}
\]

Let \(A=\prod_i(1+R_i)\) and let \(\Delta=1-\prod_i(1-\delta_i)\) use the sector-faithful completion. Positivity of unitary conjugation, the robustness domination, and the trace-distance comparison give two simultaneous bounds:

\[
\boxed{\langle c|U(\otimes_i\rho_{\eta_i})U^\dagger|c\rangle
\le \min\{A\Theta_{g,q}(\mathcal C),\;\Theta_{g,q}(\mathcal C)+\Delta\}.}
\]

Thus deterministic preparation with fidelity at least \(1-\epsilon\) requires

\[
\Theta_{g,q}(\mathcal C)\ge
\max\left\{\frac{1-\epsilon}{A},\;1-\epsilon-\Delta\right\}.
\]

At small, uniform survival, \(\log A=O(\sum_i\eta_i^4)\) and \(\Delta=O(\sum_i\eta_i^4)\), with the preceding pair-spectrum factor improving the latter. So when total quartic load vanishes, the lossy resource blocks cannot materially relax the interaction-gate fidelity constraint from Tang's theorem. At \(g=0\), the multiplicative side reduces to the deterministic specialization of N105; N105's successful Gaussian postselection statement is stronger and broader at \(g=0\), and is **not** extended here to interacting postselection.

The extension is conditional on both the N102 operator domination and the Tang Theorem 2 statement. A service-level cost ledger supplies \(m,k,d_F,q,g\); it charges gate count and precision, and it supplies the lossy two-form descriptions needed to compute each \(R_i\). This is a theorem-style resource constraint, not an algorithm for finding the code or carrying out its preparation.

## Counterexample and boundaries

Interacting processing does not preserve \(\mathcal C_G\). For four modes, the pure state

\[
|G\rangle=\tfrac12(|0000\rangle+|1100\rangle+|0011\rangle+|1111\rangle)
\]

is a product of two BCS Gaussian pairs. The density interaction \(V=e^{i\pi n_1n_3}\) flips only the fully occupied component, giving

\[
V|G\rangle=\tfrac12(|0000\rangle+|1100\rangle+|0011\rangle-|1111\rangle).
\]

An even pure four-mode Gaussian must satisfy the Plücker relation \(c_0c_{1234}=c_{12}c_{34}-c_{13}c_{24}+c_{14}c_{23}\). Here the left side is \(-1/4\) and the right side is \(+1/4\), so the output is not pure Gaussian. Because it is pure and not Gaussian, it cannot be a convex mixture of pure Gaussian states either. The gate is a quartic density interaction up to an overall phase and Gaussian quadratic factors. This exact example blocks any claim that N100 keeps the *post-interaction* state inside \(\mathcal C_G\). It does not prove hardness.

The distinctions that must survive synthesis are:

- **Discarded vacuum environment:** the N100 quartic completion applies; the error is for the unflagged output state.
- **Observed intact/loss flag:** N106's balanced distance is \(\eta^2/2\); quartic scaling is unavailable.
- **Gaussian downstream circuit:** the completed mixture yields N100's efficient Gaussian sampler, after input acquisition and finite-precision charges.
- **Arbitrary interacting channel:** trace distance to the *same channel applied to the completion* remains at most \(\Delta\); efficient simulation does not follow.
- **Counted Tang-model interactions:** the code overlap inequality above is available for deterministic unitary preparation; postselection/discarding and arbitrary interactions remain outside this derived theorem.
- **Three-particle inputs:** N106's \(\eta^3/2\) witness rules out a universal quartic law for arbitrary few-fermion inputs.

## Costs, blockers, and next gate

For each pure two-form, the supplied coefficient table has \(\binom m2\) entries; a Youla/canonical decomposition and all precision are charged. A mixed input requires its \(\binom m2\)-dimensional density matrix and diagonalization. A completion uses \(r+1\) Gaussian phase labels, a monotone scalar root, and bit costs depending on the vacuum weight (including \(\log(1/a)\)). The full N100 simulator uses dense covariance operations, reported as \(O(M^3)\) arithmetic and \(O(M^2)\) memory per final-occupation sample, after acquisition. Its conditional-probability precision workaround is a proposal; the delivered implementation is not interval-certified. The N104 \(\sum\eta_i^4=O(\log M)\) guarantee is for bounded-output *signed estimation*, not positive full-distribution sampling.

The interaction bound additionally charges \(g\), maximum even Majorana weight \(q\), angle precision, Gaussian layers, code parameters, and the absence of untracked ancillas. It does not certify a sampler or physical hardware cost. Loss flags, rare-event conditioning, active loss motion, and discarded quantum work registers each change the interface.

The decisive next gate is specialist review of the exact completion and the Tang interface composition, including the deterministic-unitary restriction, followed by a priority search against four-mode convex-Gaussian distance/robustness and low-loss resource bounds. If the algorithmic interaction extension is pursued, its next technical gate is a finite-bit sampler for a $2^g$-term coherent Gaussian sum with all Gaussian-overlap and rare-branch costs charged; no such interacting sampler is claimed here.

UNKNOWN GEOMETRY / SPECTRUM ACQUISITION
Date: 2026-10-08
Status: INTERNALLY-PROVED-CANDIDATE (two scoped impossibility results).
Novelty: UNKNOWN. The central lower-bound mechanism is the established quantum
random-access-code/Holevo argument of Nayak (1999); the sensor embedding and
the acquisition-oracle reduction below are written out here. No external
validation of the new scoped applications is claimed.

RESULT
There is no operational archive law determined only by a local signal/Fisher
spectrum across the sensor families below. Already in the aligned subcase, the same local Fisher eigenvalues r² (with
multiplicity d) permit two different precision laws: the finite-support
later-coordinate-query family has exact memory 2^d labels and, for every
fixed eps/r<1/2, requires only Θ(d) bits; the Gaussian later-coordinate-query
family has a source-derived candidate rate (d/2) log₂(r/eps)+O(d) bits as
eps/r tends to zero. The finite-support
lower bound allows arbitrary query-specific quantum POVMs, arbitrary
input-dependent classical/quantum hybrid encoders, and free independent
shared randomness. Every input-dependent orthogonal classical label is
included in the total Hilbert-space dimension D. For the finite-support lower bound, an arbitrary fixed orthogonal change of
coordinates is absorbed into the encoder; a protocol uniform over all hidden
bases must in particular work at the identity. This lower-bound observation
does not give an upper bound for an encoder that is not told the basis.

Separately, in a declared coordinate-threshold oracle, identifying the exact
number of modes above precision eps takes Ω(m) queries in the worst case,
even if each query returns a noiseless one-bit threshold answer. Thus an
effective-rank or multiplicity term cannot be treated as free when the
spectrum is unprovided. This oracle lower bound is deliberately conditional
on a coordinate-local acquisition interface; it is not a claim about every
possible collective quantum measurement.

THEOREM 1: SAME LOCAL SPECTRUM, DIFFERENT OPERATIONAL PRECISION LAW
Fix d≥1, 0<r≤1, and 0≤eps<r/2. Let X take values x in {−1,+1}^d. For
each later query i in {1,...,d} and hidden sign sigma in {−1,+1}, define

  P_(i,sigma)(x) = 2^(−d) (1 + sigma*r*x_i).

The encoder receives one draw X and does not receive i or sigma. It produces
a state rho_(x,s) in a Hilbert space H_s of dimension D for each value of an
independent public seed s. H_s may be any direct sum of matrix blocks,
H_s = direct_sum_j C^(d_j), with D=sum_j d_j. The decoder learns i only after
storage and applies any POVM {M_(i,s)(z): z in {−1,+1}} to H_s. No
input-dependent register, branch label, or side channel is free. There is no
free entangled receiver reference. Independent shared randomness is allowed.
The required output law R_(i,sigma) must satisfy

  TV(R_(i,sigma), Q_(i,sigma)) <= eps for every i,sigma,
  Q_(i,sigma)(z) = (1 + sigma*r*z)/2.

Then

  log₂ D >= d [1 - H₂(eps/r)],

where H₂ is binary entropy. Conversely, D=2^d suffices with zero error by
storing x as a classical label and returning x_i on query i. Hence for every
fixed eps/r ≤ c < 1/2, the optimum is 2^(Θ(d)) in total dimension, or
Θ(d) memory bits; at eps=0 the exact answer is D=2^d.

PROOF
Let U be uniform on the Boolean cube. For fixed seed s and coordinate i,
write

  m_(i,s)(x) = Tr rho_(x,s) [M_(i,s)(+1)-M_(i,s)(−1)],
  a_(i,s) = E_U m_(i,s)(X),
  b_(i,s) = E_U X_i m_(i,s)(X).

The source law has density 1+sigma*r*x_i relative to U. Therefore the mean
of the decoder's signed output under P_(i,sigma), averaged over S, is
E_S[a_(i,S)+sigma*r*b_(i,S)]. The target mean is sigma*r. Since a function
in [−1,+1] changes expectation by at most 2 TV,

  |E_S(a_(i,S)+r b_(i,S)-r)| <= 2 eps,
  |E_S(a_(i,S)-r b_(i,S)+r)| <= 2 eps.

Subtracting these two inequalities gives
E_S b_(i,S) >= 1 - 2 eps/r. (Adding also gives |E_S a_(i,S)|<=2eps,
which is not needed.) For uniform X, the actual POVM outcome Z_i in {−1,+1}
has average bit error

  q_i = Pr[Z_i != X_i] = (1 - E_S b_(i,S))/2 <= eps/r.

Now regard x as a uniformly random d-bit message and rho_(x,s) as a quantum
random-access encoding. For every i the later query measurement decodes bit
i with error q_i. For a fixed seed s, Holevo's bound gives
I(X:Q | S=s) <= log₂ D. Strong subadditivity and data processing give

  log₂ D >= I(X:Q | s)
             >= sum_i I(X_i:Q | s)
             >= sum_i I(X_i:Z_i | s)
             >= d - sum_i H₂(q_i(s)),

where the first lower inequality uses independence of the uniform input bits,
and the last is binary Fano. Average over S and use concavity of H₂ twice:

  log₂ D >= d - sum_i H₂(q_i)
             >= d [1 - H₂((1/d)sum_i q_i)]
             >= d [1 - H₂(eps/r)].

This proof puts no compatibility condition on the query POVMs: each i is a
separate measurement of the same pre-query memory, exactly as in a one-way
random access code. A direct-sum hybrid is an ordinary state on dimension
sum_j d_j, so its classical labels are already charged. Arbitrary
query-dependent classical post-processing can be absorbed into the POVM.

If an arbitrary entangled receiver reference were supplied for free, the
standard entanglement-assisted information bound changes the inequality to
2 log₂ D >= d[1-H₂(eps/r)]; the order-Θ(d) obstruction remains. The main
theorem uses the unassisted interface stated above.

SPECTRUM COMPARISON
For the Bernoulli one-coordinate model p_v(x)=(1+r v x)/2, the score at
v=0 is r x and its Fisher information is r². For the Gaussian model
X~N(r v,1), the score at v=0 is rX and its Fisher information is also r².
Taking d independent coordinates gives the same local Fisher matrix r² I_d
and the same multiplicity d. The queried subfamily v=sigma e_i produces the
P_(i,sigma) above in the Bernoulli model and N(sigma*r e_i,I_d) in the
Gaussian model. In the Gaussian model, the source-derived N36 lower bound
for the same delayed-coordinate query interface is

  ln D >= (d/2) ln(r/eps) - (5/4 + ln 2)d

in the stated weak-signal regime, with a matching classical candidate upper
(d/2)log₂(r/eps)+O(d) bits. Thus the dependence on precision is not determined by the
local spectrum/multiplicity alone. The difference is source support and
likelihood geometry. This is not a new proof of the Gaussian result; N36 is
source-derived and externally unreviewed in the prior.

THEOREM 2: ACQUIRING AN UNSUPPLIED ACTIVE-SPECTRUM COUNT
Declare m candidate mode labels 1,...,m and an oracle whose unknown vector
is b in {0,1}^m. A query j returns b_j exactly (one bit); b_j may represent
the threshold predicate 1[r_j>eps] or 1[n Delta_j²>1]. The task is to output
K(b)=sum_j b_j exactly. Any randomized adaptive protocol making at most q
distinct queries and having worst-case error at most delta<1/2 must obey

  q >= m(1-2 delta).

PROOF. Compare b=0 with b=e_J, where J is uniform on {1,...,m}. Under b=0,
the protocol follows its all-zero transcript path (conditional on its
internal coins). Under b=e_J, until it queries J, it sees precisely the
same answers and follows the same path. It hits J with probability at most
q/m. The transcript law under the active mixture differs from the null law only
on the hit event, so their total variation is at most q/m. Equal-prior
binary testing success is at most 1/2+q/(2m). Worst-case error delta requires
success at least 1-delta, proving the bound. If the oracle instead
returns an approximate amplitude with absolute error at most eps/4, the
same construction using amplitudes 0 and 2eps gives the identical result.
Even this optimistic labeled-coordinate oracle therefore charges linear
acquisition queries and precision sufficient to decide the threshold.
Hiding the basis or requiring physical copies is outside this oracle and
cannot be declared free by this proof.

FAMILY STATUS AND WHAT SURVIVES
The fixed-family laws survive with their exact supplied hypotheses:

* N07: the mean set Theta is fixed and public; the observation is one
  whitened Gaussian draw; all hybrid dimensions are charged. Its exponent is
  tied to the known affine dimension s. It does not price learning Theta.
* N08: the orthogonal block algebra/projectors and positive reference blocks
  are known. The critical law is conditional on the bridge remainder and
  eps*sqrt(n)->infinity; unrestricted partial collisions remain open.
* N21: the moving-support exponent assumes the endpoint power gamma is fixed
  and known.
* N22: n, q, reference basis, and the pure-state family are supplied. Its
  finite-copy branch law does not prove a generic mixed-state law.
* N23: n, the parameterization, basis, and range constants are known. Its
  finite-n total-D lower below the C/n bridge remains open.
* N30: Gaussian axes/radii and fixed dimension are known. Its matched
  box law is not an acquisition theorem.
* N31: the r_i and coordinate axes are known; for infinitely many modes an
  effective tail certificate is needed to locate the active prefix.
* N36: source and coordinate family are known, but the query index arrives
  after storage; its converse already permits arbitrary later
  query-specific POVMs.
* N37: Gaussian axes and ellipsoid weights are known; model calibration,
  axes, and tail certification are separately unpriced by the theorem.
* N38: the entrywise-nonnegative real Bargmann kernel is supplied. The claim
  does not acquire an unknown gauge or cover arbitrary phases.
* N39: the nontracial collision-floor entries are worker-written and still
  need a full independent audit; they are not promoted here.
* N66: the regular reference densities and score functions are supplied.
  Its own scope warns that spectra alone fail for discrete Rademacher data.

The supported conclusion is a negative one: no family-independent
operational precision law follows from an eigenvalue/Fisher spectrum without
also fixing or charging acquisition of support geometry, reference law,
axes, multiplicities, and effective tails/collision scales. A worst-case law
for a separately declared union of families could still exist; this note
does not rule out such a law. Nor does it prove that an unknown-basis
protocol must pay more than the lower bound inherited from its aligned
subfamily. A spectral-moment oracle or an efficient collective measurement
could improve the coordinate-query acquisition bound, but must be specified
and charged before any positive universal theorem can be stated.

BASELINE, COSTS, AND FALSIFIER
Strongest equally informed baseline for Theorem 1: store the full discrete
observation x as d classical bits (D=2^d), then answer the delayed query
exactly. The lower bound applies to every unassisted quantum/hybrid scheme
under that same delayed-query interface. For the Gaussian comparator, N36's
candidate hat/chi-square upper matches its lower to O(d) bits in the stated
regime; that package's finite-bit, table, random-bit, output, and external
validation limits still apply.

Costs in Theorem 1: one source draw X; no active acquisition query; public
query index i arrives after storage; one query-specific POVM; output TV
precision eps; total archive dimension D includes every input-dependent
classical and quantum branch. Encoder computation, state preparation,
classical arithmetic, and storage technology are not bounded here. Public
randomness is independent of X and uncharged. Entanglement assistance is
excluded (or incurs the factor-two lower bound described above).

Costs in Theorem 2: one exact threshold-bit query per selected mode; an
amplitude oracle needs absolute precision <=eps/4 to separate 0 from 2eps;
the output is exact active multiplicity/count; no noise or query batching.
The lower bound is query complexity only, not a sample-complexity or
physical-state-copy theorem.

Falsifier: a protocol in the stated Theorem 1 interface with
log₂ D < d[1-H₂(eps/r)] for some eps/r<1/2, including its entire
input-dependent hybrid register, would falsify the proof. For Theorem 2, a
worst-case-error-delta exact count protocol with q<m(1-2delta) coordinate
queries would falsify the indistinguishability argument. A universal
operational compression law may survive if its input includes enough
declared sensor regularity and the exact costs of discovering the missing
geometry; this note has not established such a law.

UNRESOLVED GATES

  multiplicity profile, or near-collision scales from physical copies while
  preserving all future POVM laws.
* No exact sample/query complexity is established for acquisition under
  collective measurements, adaptive entangled probes, or unknown measurement
  calibration.
* Unknown-basis upper bounds, finite-bit implementation, preparation cost,
  and sensor-family identification are not established.
* The N39 nontracial partial-collision floor is not independently proved in
  this work; it remains a worker-only candidate.
* This no-go settles insufficiency of spectral data alone, not the optimal
  universal minimax law over any more tightly declared union of source
  families.

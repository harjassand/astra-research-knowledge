1. PRECISE PHYSICAL INTERFACE

Let S+=(X+iY)/2 and S-=(X-iY)/2. A loopless graph has explicit oriented edge
data h_uv in Q(i), gamma_uv in Q, and site data q_v in Q(i), c_v in Q. Put
 H=sum_(u,v)[2 h_uv S+_u S-_v+2 conj(h_uv) S-_u S+_v+gamma_uv Z_u Z_v]
   +sum_v[q_v S+_v+conj(q_v) S-_v+c_v Z_v].
The physical Hamiltonian is -H. Thus q=b-i d gives bX+dY. A complex h
contains an XY interaction and its longitudinal Dzyaloshinskii--Moriya term.
The easy-plane condition is EXACTLY gamma_uv^2<=|h_uv|^2. All data are net
coefficients per unordered edge/site; combine duplicate terms first if desired.
An h=0 edge must consequently have gamma=0 and can be removed.

The targeted gauge is D=product_v diag(1,z_v), |z_v|=1. It transforms
 S+_v -> conj(z_v) S+_v,
 h_uv -> h_uv conj(z_u) z_v,
 q_v -> q_v conj(z_v).
Hence the desired real magnitudes are alpha_uv=|h_uv|, b_v=|q_v|. The gamma,c
terms stay unchanged. This is a product diagonal gauge; rejection does not
exclude all other basis changes or simulation reductions.

2. EXACT ACQUISITION WITHOUT ROOT/ARG EQUALITY ORACLES

For each connected component of nonzero hoppings choose a root and a spanning
tree. Set a Gaussian-rational t_root=1. For a tree edge traversed u to v in
its given orientation put t_v=t_u conj(h_uv); when traversed backwards use
t_u=t_v h_uv. Do not normalize t during this traversal.

Every tree constraint holds because h_uv conj(t_u)t_v is a positive real
number. For each remaining edge test
 h_uv conj(t_u)t_v has imaginary part zero and real part strictly positive.
This is an EXACT Gaussian-rational test. If it fails, the fundamental cycle
cannot have trivial phase. In particular a negative real product is rejected;
testing only a vanishing imaginary part would silently accept pi flux.

Necessity and sufficiency follow directly: any successful z satisfies

on an oriented nonzero edge. Along the tree z_v=z_root*t_v/|t_v|. The displayed
non-tree check is therefore exactly the remaining edge compatibility condition.

Now let p_v=q_v conj(t_v) at each nonzero transverse field. A successful
component root phase must equal p_v/|p_v|. Choose one anchor p0 and test that
every p_v conj(p0) is positive real. If any fails, those two fields are
incompatible with the acquired tree relation; even a tree can fail here.
When all pass, multiply every t_v in the component by p0. Then
 q_v conj(t_v)>0 and all edge tests are unchanged up to |p0|^2. With no field
anchor leave the root phase one. Finally define z_v=t_v/|t_v|.
Isolated vertices and disconnected components are handled by the same rule.

All t products use at most O(n) original factors, and the anchor multiplication
adds at most O(n) factors. If the explicit original input has L bits, every

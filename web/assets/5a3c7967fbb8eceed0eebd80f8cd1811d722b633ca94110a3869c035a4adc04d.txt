RESULT AND SCOPE

Let F be an explicit n by n matrix over Q(i), 0<=k<=floor(n/2), and
0<epsilon<=1 rational. An explicit charged base G and an acquired ordering
have support frontier v. An exact rational greedy algorithm obtains U,V
with r columns and H=G+UV^T from the residual F-G. It also obtains the
remaining error E=F-H. There is an exact all-sector and occupation-prefix
counter for H of cost polynomial(n,r,L) 16^(v+r+1). No truncation, projection
rejection, singular-value oracle, or unknown norm is used for that count.

The new approximation admission test uses an acquired exact Z_H=c_k(H):

  eta^2 = ||stripdiag(F-H)||_F^2,
  B >= max(||stripdiag F||_op, ||stripdiag H||_op),  B rational,
  d^2 = binomial(n,k) k^2 eta^2 B^(2k-2)       (k>=1),
  d^2 = 0                                     (k=0).

If Z_H>0 and d^2<=epsilon^2 Z_H/16, then

  |Z_H-c_k(F)| <= epsilon c_k(F),
  T( |hard-k F>, |hard-k H> ) <= epsilon/4,

where T is pure-state trace distance. The classical H law can be sampled
with a uniformly capped fair-bit routine; the implemented total-variation
error from the F law is <=3 epsilon/4, on every certified input. Unsupported
admissions return UNKNOWN_ADMISSION, never a general nonexistence or zero
claim. A zero H sector is insufficient to conclude that F has a zero sector.

For v+r=O(log n), with a supplied/checked ordering or a fixed separator
budget for ordering acquisition, all acquisition, certification, rational
bit arithmetic and sampling have polynomial cost. The automatic band version
takes G from the
specified band of F and acquires the rank approximation of the remaining
matrix. A finite explicit list of bases/orderings can also be tried, charging
the number, encodings and actual contractions. Finding an arbitrary unknown
sparse base, an optimal ordering, or the best approximate rank is NOT solved.

STRONGER ALL-ACCURACY ADMITTED MATRIX CLASS

The preceding guard is initially an accuracy-qualified admission test. It
does not alone give a scheme for every accuracy on the same fixed matrix.
A stronger, independently checked PRECISION-GAP admission does:

  Z_H>0,      d^2 <= Z_H 2^(-n)/16.                  (UNIFORM)

Acquire H,Z_H,d^2 once with the polynomial-width backend and test (UNIFORM)
exactly. For EVERY subsequent rational requested epsilon in (0,1], use H
when the earlier epsilon guard passes. Otherwise compute the ORIGINAL F
coefficient exactly with the phase-one full-frontier density algorithm.
Since an original n-site frontier is at most n-1, that fallback costs
poly(n,L)16^n. On the fallback branch the failed epsilon guard and (UNIFORM)
imply

  epsilon^2 < 16d^2/Z_H <= 2^(-n),
  16^n < epsilon^(-8).

Thus this deterministic relative norm scheme costs

  poly(n,r,L)16^(v+r+1) + poly(n,L,L_epsilon)epsilon^(-8)

on every admitted matrix, uniformly for all accuracies. The bounded fair-bit
sampler likewise uses H at coarse accuracy or exact F counts at fine
accuracy and has TV <=epsilon, with the same bound up to polynomial factors
and the fair-bit cap. This is a complete polynomial(n,L,epsilon^-1) class
when v+r=O(log n); the class is fixed before choosing requested epsilon.

The exact fallback can remain exponentially expensive in n. Its polynomial
charge is to a correspondingly huge 1/epsilon; no practical runtime is
inferred. This does not supply relative accuracy for every rare prefix at
coarse epsilon: the uniform root precision gap certifies the total norm and
whole law, not a prefix whose mass is vastly smaller than the root.

Implemented entry points: acquire_uniform_accuracy_certificate,
acquire_banded_uniform_certificate, norm_uniform_accuracy,
sample_uniform_accuracy. Failure to pass (UNIFORM) returns UNKNOWN_ADMISSION;
passing only the weaker one-accuracy guard still yields that valid scoped
result. The n=4 fine-accuracy branch is executed and matches independent
exact minors; larger fine-accuracy fallbacks are not benchmarked.

This adds a costed approximation-admission interface beyond exact low-width
classes. The physical normalized state certificate is mathematical; no
quantum circuit or hardware preparation is implemented. General arbitrary
F at k=Theta(n) remains unresolved. No novelty or field-breaking claim is
made; postselection conditioning and Gaussian MPS are established methods.

1. ACQUIRING A RATIONAL RANK APPROXIMATION

Set R=F-G. Start with no selected columns. At each of at most rank_budget
steps, project R onto the span of the selected ORIGINAL R columns and compute
all residual-column squared Euclidean norms exactly. If every norm is zero,
stop. Otherwise append a column of largest positive residual norm, breaking
ties by its original index. Its residual is nonzero, so it is independent of
the previously selected original columns. For the resulting n by r matrix U,

  A=(U^*U)^(-1) U^* R,
  V=A^T,                         (ordinary transpose)
  H=G+UA=G+UV^T,
  E=R-UA.

The Gram inverse exists by exact independence. All quantities lie in Q(i).
No numerical rank threshold or irrational SVD is used. If rank(R)<=budget,
the algorithm recovers R exactly after at most rank(R) steps. For a general
R it supplies an explicit approximation and a measured residual; it need
not find the optimum rank-r approximation. Admission, rather than an optimal
rank theorem, is the precise interface.

Naive recomputation has O(n^2 r^2+r^4) rational field operations. Gram
determinant/adjugate bounds make all factors polynomial-bit in n and the
original total encoding L. A tiny Gram determinant has charged encoded
rational size; no number of trials depends inversely on its value. G is
supplied explicitly or selected by a fixed, charged recipe. For the F-only
band recipe, G_ij=F_ij if |i-j|<=w and zero otherwise, so v<=w in input order.

A supplied permutation is scanned in O(n^2) support work to acquire its
actual frontier v. If no order is supplied, the owned phase-one fixed-budget
balanced-separator search is used: for fixed q, cost O(n^(q+3)) conservatively,
and every G whose support treewidth is <=q-1 is admitted with v<=q*bitlength(n).
Its failure is UNKNOWN_ADMISSION. A growing separator budget is charged by
that explicit exponent and must not be included in a uniform polynomial
claim. Exact optimal ordering and arbitrary sparse-base discovery remain
outside the compiler.

2. EXACT LOW-RANK UPDATE COUNT VIA FORCED DOUBLE AUXILIARIES

For r auxiliary sites A={n,...,n+r-1}, form

  M = [ G    U  ]
      [-V^T I_r ].

For every disjoint physical I,J with |I|=|J|=k, block elimination at the
identity pivot gives

  det M[I union A, J union A] = det(G[I,J]+U_I V_J^T)
                             = det H[I,J].

This identity includes singular physical minors. A hard local filter on
physical sites allows occupations {empty,up,down}; at every auxiliary site
force double occupation. Track only the completed PHYSICAL electron charge.
The surviving extended-state coefficient vector has exactly those selected
minors. Its extra up-then-down determinant sign relative to the physical
state is (-1)^(kr+r(r-1)/2), common within a fixed physical k sector. Thus
all weights and restricted norms agree exactly. Known mode permutation signs
do not affect counts; physical phases may be evaluated directly from H.

Order all physical sites by the acquired G ordering, then all r auxiliary
sites. The union support frontier of M contains at most v future physical
neighbors plus r auxiliary sites. Once physical sites are completed, only
auxiliaries remain. Width is therefore at most v+r; at most v+r+1 sites are
live during a gate update. This is directly scanned and verified by code.

The density counter is the phase-one exact creation-gate construction,
extended to retained auxiliary diagonals. For each directed nonzero edge,
apply I+a c_left^dagger c_right^dagger to the ket and its adjoint to the bra.
For each auxiliary i apply its diagonal I+u_i^dagger d_i^dagger exactly once.
Physical diagonals are omitted because the physical double filter kills
them. Omitting auxiliary diagonals would invalidate the identity pivot; the
implementation explicitly retains them. Partial trace at a completed site
keeps matching bra/ket occupations in its allowed set. An auxiliary double
adds zero to the recorded physical charge. Final physical charge 2k returns
c_k(H), and odd physical charges vanish. Prefixes only remove allowed local
occupations and preserve the same width. Exact zeros are obtained for H.

The invariant is the reduced density operator of all gates already applied,
traced through the completed local filters and split by physical charge.
Unprocessed sites are initially vacuum. Each live-site insertion has two
empty fermionic modes and changes no sign. Every future operator is even,
so the Jordan-Wigner string on already traced modes cancels. Gate updates
and matching-occupation trace preserve the invariant by linearity. The
Schur identity identifies the final scalar with the physical determinant
partition term by term. A count does not physically postselect auxiliary
sites and has no inverse auxiliary success-probability factor.

Let N=n+r and W=v+r+1. At most (n+1)16^W density coefficients are stored.
At most O(n(v+r)+r) pair gates occur, plus N site traces. Conservative time
is O(n N (v+r+1)16^W) exact rational operations, and memory O(n16^W), in
addition to input/recognition/acquisition. Clear all extended entry
denominators with a product D of polynomial bit length. Every ket uses at
most N pair creations; every bra likewise. A common coefficient denominator
D^(2N) and the at-most-factorial number of determinant terms bound bit
heights by O(N(L_ext+log N)). Intermediate partial density sums obey the
same bound up to constants. Thus rational bit cost is polynomial per state.

3. THE ACQUIRED ERROR CERTIFICATE

All hard disjoint minors ignore diagonal entries. Put F0=stripdiag F,
H0=stripdiag H, E0=F0-H0. Let a_F,a_H be their vectors of k by k disjoint
minors with the fixed canonical sign. Projection to any additional
occupation prefix is a coordinate projection on this vector.

The matrix of the exterior operator wedge^k F0 in orthonormal subset bases
has entries det F0[I,J] for ALL I,J of size k. Embed the exterior space
isometrically into the kth tensor power by normalized antisymmetrization.
The tensor-power telescoping identity gives

 ||wedge^k F0 - wedge^k H0||_op
 <= ||F0^(tensor k)-H0^(tensor k)||_op
 <= sum_{t=0}^{k-1} ||F0||_op^t ||E0||_op ||H0||_op^(k-1-t)
 <= k eta B^(k-1).

The exterior matrix dimension is binomial(n,k), so its Frobenius norm is
at most sqrt(binomial(n,k)) times this operator norm. Deleting overlapping
I,J entries and forbidden-prefix entries cannot increase squared norm.
Therefore for the entire hard canonical vector and for EVERY prefix p,

  ||a_F-a_H||^2 <= d^2,
  ||a_F,p-a_H,p||^2 <= d^2.                              (BOUND)

The code uses the exact rational eta^2=sum|E0_ij|^2 and
B=max over F0,H0 of sum_ij (|Re Aij|+|Im Aij|). This B is a rational upper
bound for Frobenius and operator norm. The squared bound uses integer
binomial coefficients and rational powers, so there is no approximate
spectral, square-root or cancellation evaluation. Its binary length is
polynomial in n,L_ext. The bound is deliberately conservative.

Let b=||a_H||=sqrt(Z_H), x=a_F, and t=d/b. The test ensures 0<=t<=epsilon/4
<=1/4. The reverse triangle inequality gives

  (1-t)b <= ||x|| <= (1+t)b,

so c_k(F)>0. Also

 |c_k(F)-Z_H|/c_k(F)
 <= (2t+t^2)/(1-t)^2 <= 4t <= epsilon.

For t<=1/4 the middle inequality follows from
2+t<=4(1-t)^2; the right-minus-left expression 2-9t+4t^2 is nonnegative
on that interval (zero at 1/4).

Pure-state trace distance obeys the tighter geometric bound t, rather than
an extra factor two: let P_x project onto span(x). Then

 T(x/||x||,a_H/b)^2 = ||(I-P_x)a_H||^2/b^2
                  <= ||a_H-x||^2/b^2 <= d^2/Z_H.

Measurement into any occupation basis contracts trace distance, hence the
two normalized Born laws differ by TV at most epsilon/4. The same norm
argument provides relative PREFIX accuracy only when its own positive
Z_H(p) passes the guard d^2<=epsilon^2 Z_H(p)/16. A root guard alone gives
absolute prefix vector error, not uniform relative conditional guarantees.

This proof explicitly uses the acquired projected norm Z_H. Omitting it
would be false even for small, well-conditioned rational input matrices;
see the attributed c03_s02 precision families. The code treats Z_H=0 as
failed admission, even if the remaining matrix error is extraordinarily
small. It does not silently normalize a zero state or use an unavailable
F norm.

4. UNIFORM FAIR-BIT SAMPLER AND COMPUTATIONAL SCOPE

For H, scan up occupation bits then down occupation bits. Compute the two
exact child masses by the forced-double backend; each preserves the same
frontier. Conditional probabilities are exact rationals. An integer fair-bit
rejection draw has success probability at least 1/2 at every attempt. Choose
r_coin so 2n*2^(-r_coin)<=epsilon/2, and cap every bit decision at that many
attempts. On a cap failure, finish with deterministic positive-child choices.
A coupling with unlimited rejection gives TV <=epsilon/2. At most 4n count
queries are made after admission and every produced H configuration has
positive H weight. Coin numerator/denominator bit lengths are polynomial.
The total law is <=epsilon/2+epsilon/4=3epsilon/4 TV from the F law.

Sampling time is the count bound times O(n), plus polynomial coin work and
r_coin=O(log(n/epsilon)); it contains no inverse Z_H or Z_F trial count.
Seeded pseudorandom executions only check code/support. The probabilistic
theorem requires the stated independent fair getrandbits contract.

Normalized H configurations may have zero F weight on some certified inputs;
the claim is total-variation approximation, not exact F-support sampling.
If an exact F-support output contract is needed, check its original minor
and use a separately charged repair/rejection protocol. This module claims
no such contract. Similarly, it delivers no target Hamiltonian ground-state
energy, no unimplemented quantum gate schedule, and no general sampler for
uncertified F.

5. WIDER CLASS AND SHARP CONDITIONING LIMITS

Every positive sector of an exact admitted H has an open rational
neighborhood accepted by the guard for fixed epsilon: its count is known
and positive, B changes continuously and the residual bound tends to zero.
Arbitrarily small generic dense rational perturbations can have large exact
support frontier and large exact cut ranks. Thus the admitted approximation
class strictly extends the exact representation class; its acceptance does
not infer low exact rank of F. For fixed frontier and r=O(log n), this remains
a polynomial-bit class. The permitted neighborhood can be extremely small
when Z_H is small, and this numerical width is charged in input bit length.

The diagnostic uses n=8,k=4 and the connected width-two complex triangle
chain from phase one. Add 2^(-80)*(1+((i+1)^(j+1) mod 101)) on every entry
with |i-j|>2. All offdiagonal entries become nonzero. The original support
frontier is seven and the middle directed cut-rank sum is eight. The F-only
bandwidth-two, rank-zero admission nonetheless passes, returning the exact
approximate norm 53014549/1679616. The true F norm and TV were independently
enumerated exactly only as a finite comparator; production does not query
them. This finite fixture demonstrates admission, not a large-scale speed
benchmark or unrestricted theorem.

An explicit ALL-SIZE family makes the strict extension quantitative. For
every even n=2q>=4, use input order, k=q, and a rational radius parameter
alpha in (0,1], independent of the later requested accuracy. Let G0 have
diagonal three and G0_ij=1 when 1<=j-i<=2, zero on all other offdiagonal
entries. Put

  D_ij=(i+1)^j/n^n for i!=j,  D_ii=0,
  B0=n^2+2n,
  delta=alpha/[4 n q B0^(q-1) 2^n],
  F=G0+delta D,                 H=bandwidth-two truncation of F.

All offdiagonal entries of F are strictly positive, so its input-order
support frontier is n-1. Its right-to-left block at the middle cut is
delta/n^n times the Vandermonde matrix with nodes q+1,...,n and exponents
0,...,q-1. Hence this block has EXACT rank q; maximum directed cut-rank
sum is at least q=Theta(n). Thus this family is outside the logarithmic
exact support/cut-rank admission classes in its charged input ordering for
large n; optimal reordering is not needed or claimed.

Nevertheless H has frontier two. The submatrix with even rows I={0,2,...}
and odd columns J={1,3,...} is lower bidiagonal: its diagonal entries are
1+delta D_(2a,2a+1)>=1, and the preceding odd-column entries are nonnegative
delta D_(2a,2a-1). Its determinant is the diagonal product, at least one.
Therefore the ACQUIRED hard norm Z_H>=1 at the full-occupancy sector. Every
entry of D is at most one, so eta^2<=n^2 delta^2 and the implemented rational
B is at most B0. Consequently

  d^2 <= binomial(n,q) q^2 n^2 delta^2 B0^(2q-2)
      = alpha^2 binomial(n,q)/(16*2^(2n))
      <= 2^(-n)/16 <= 2^(-n) Z_H/16.

The automatic F-only bandwidth-two/rank-zero compiler thus certifies EVERY
member under (UNIFORM), at k=n/2, independently of the later requested
epsilon. It has a deterministic polynomial-bit relative norm scheme and TV
sampler for ALL requested accuracies, with the charged fine-accuracy fallback
above. No hidden base or decomposition is supplied. The original matrix
is also uniformly well conditioned: ||G0-3I||_op<=2 since it is the sum of
the first and second upper shift matrices, and ||delta D||_op<=delta n<=1/16.
Thus sigma_min(F)>=15/16, sigma_max(F)<=81/16, and kappa_2(F)<=81/15<6.
The diagonal affects this conditioning claim but never a hard minor.

The matrix and delta have total bit encoding polynomial in n and alpha's
binary description; per entry it is O(n log n+L_alpha). This is a dense,
positive, uniformly conditioned, full-occupancy admitted approximation
family with linearly large exact cut rank. It is an easy neighborhood of a
bounded-width model, not an unrestricted approximation-hardness statement
or a claim that all dense well-conditioned F are easy. Exact full HARD
support of every complementary minor is not asserted. Executed admission
checks include n=4,6,8,20; small instances are also compared with exact
minor enumeration, while n=20 only checks admission and the direct positive
witness/cut-rank certificates.

A tiny perturbation of H=J4-I4 at k=2 is rejected because Z_H=0 although the
perturbed true norm is 2 delta^2. This is a correct failure, not an algorithm
defect. Prefix limitations are also exact: at n=4,k=1, set H01=1,H23=delta,
F01=1,F23=delta^2, all other entries zero. For delta=1/10000 the root guard
at epsilon=1/100 passes. But the prefix selecting up2,down3 has masses
delta^2 and delta^4, ratio 10^8. Small whole-law error cannot preserve
relative mass accuracy on rare prefixes. Here both prefix masses are
positive, so changed zero support is not the explanation.

The geometric constant T<=||x-y||/||y|| itself is sharp already for rational
k=1 BCS amplitudes. Let rational c,s>0 satisfy c^2+s^2=1, take H01=1,
F01=c^2,F23=sc and other entries zero. Then ||a_F-a_H||=s, ||a_H||=1,
the normalized vectors are (c,s) and (1,0), and trace distance is exactly s.
Scaling both matrices by any small rational delta leaves trace distance
unchanged while matrix and unnormalized vector differences tend to zero.
This shows why the projected norm divisor cannot be dropped. The stronger
full-support, spin-symmetric bounded-condition-number versions are the
attributed c03_s02 results, not a new claim by this worker.

ROUND 6 REVISION 2 — EXACT QUIBIT CAP FOR THE BROADER BRANCH-PETZ CLASS
c04_l09 | 2026-10-07 | internal derivation, cross-phase attributed; not externally reviewed

The earlier REV1 exactly characterized the canonical same-effect class
C=(L+Psi_M)/2, Phi=C^*C: for qubit depolarizing Delta_lambda it is representable iff 0<=lambda<=1/4. After the root's CROSS_PHASE release, I audited the broader c04_s03 interface in which the instrument effects M_y are retained but the EB branch may prepare arbitrary states with the correct reference mean. This genuinely enlarges the represented depolarizing range. I derive its exact endpoint:

  Delta_lambda is representable as Phi=C^*C, C=(L+Q)/2,
  with Q from a reference-preserving measure-and-prepare branch
  using the instrument's effects, iff

  0 <= lambda <= ((1+sqrt(5))/6)^2 = (3+sqrt(5))/18.

The upper bound applies to an arbitrary finite-outcome qubit instrument, including multiple Kraus operators per outcome. A four-outcome tetrahedral POVM with Lüders instrument and tetrahedral pure preparations attains equality. The universal qubit cloner marginal Delta_(2/3) remains outside this entire class. This is a structural representability obstruction only; it does not refute c=2 EB rounding or any vanishing EB modulus.

A. UPPER BOUND FOR AN ARBITRARY-PREPARATION BRANCH

Take A=M_2 with tau=Tr/2. A finite instrument has CP branches I_y with effects M_y=I_y^*(I), sum_y M_y=I, and total map L=sum_y I_y bistochastic. Set p_y=tau(M_y); discard zero effects. Write

  M_y=p_y(I+a_y dot sigma),   |a_y|<=1,   sum_y p_y=1,
  sum_y p_y a_y=0.

The branch Q measures these effects and prepares qubit states with Bloch vectors r_y, |r_y|<=1. Reference preservation at I/2 is exactly sum_y p_y r_y=0. On the traceless Pauli subspace its transfer matrix is

  S=sum_y p_y r_y a_y^T.

Let T be the Bloch matrix of L. The common midpoint C=(L+Q)/2 is a unital trace-preserving CP qubit channel. If Phi=C^*C is Delta_lambda and s=sqrt(lambda)>0, its transfer matrix is Q_C=sO with O orthogonal, so T+S=2sO.

If det O=-1, postcompose C with a unitary rotation to reduce its Pauli matrix to diag(s,s,-s). The corresponding Choi eigenvalue (1-3s)/4 forces s<=1/3. This is already below (1+sqrt(5))/6. Hence for the remaining case det O=+1, choose a qubit unitary U whose conjugation has Bloch matrix O.

For the post-unitary instrument U^* o L, Kraus operators are U^*K_{yk}, where k indexes all Kraus operators within outcome y. The superoperator trace identity gives

  Tr(O^T T)=4 F_e(U^* o L)-1,
  F_e(U^* o L)=1/4 sum_(y,k) |Tr(U^*K_(yk))|^2.

For each outcome, diagonalize its effect M_y. The exact multi-Kraus bound

  sum_k |Tr(U^*K_(yk))|^2 <= (Tr sqrt(M_y))^2

follows by writing A_k=U^*K_(yk) in the effect eigenbasis, applying the Euclidean triangle inequality to the vector (sum_i (A_k)_(ii))_k, and using

  sum_k |(A_k)_(ii)|^2 <= sum_k (A_k^*A_k)_(ii)=(M_y)_(ii).

The effect eigenvalues are p_y(1+|a_y|),p_y(1-|a_y|), so

  (Tr sqrt(M_y))^2=2p_y(1+sqrt(1-|a_y|^2)).

Consequently

  Tr(O^T T) <= 1+2 sum_y p_y sqrt(1-u_y),
  Tr(O^T S) = sum_y p_y r_y dot (O a_y) <= sum_y p_y sqrt(u_y),

where u_y=|a_y|^2. Taking trace of T+S=2sO gives

  6s <= 1+sum_y p_y[2sqrt(1-u_y)+sqrt(u_y)] <= 1+sqrt(5).

The last inequality is Cauchy-Schwarz on the unit vector (sqrt(1-u),sqrt(u)): 2sqrt(1-u)+sqrt(u)<=sqrt(5). This proves s<=(1+sqrt(5))/6. It uses the instrument's shared outcome effects, the arbitrary branch preparations, and reference preservation; it does not assume a single Kraus per outcome, a selfadjoint L, or a Lüders instrument.

B. FINITE ATTAINMENT BY A TETRAHEDRAL INSTRUMENT

Take unit tetrahedron vectors

  n_1=(1,1,1)/sqrt(3), n_2=(1,-1,-1)/sqrt(3),
  n_3=(-1,1,-1)/sqrt(3), n_4=(-1,-1,1)/sqrt(3).

They satisfy sum_y n_y=0 and (1/4)sum_y n_y n_y^T=I_3/3. For 0<=a<=1 define

  M_y=(I+a n_y dot sigma)/4,   K_y=sqrt(M_y),
  rho_y=(I+n_y dot sigma)/2.

The M_y form a POVM, the K_y give a bistochastic Lüders instrument, and the preparations have mean I/2. The outcome probability on Bloch input x is (1/4)(1+a n_y dot x), so Q has Bloch shrink a/3.

To compute L exactly, let q=sqrt(1-a^2) and write sqrt(I+a n dot sigma)=uI+v n dot sigma, with u^2=(1+q)/2, v^2=(1-q)/2, and 2uv=a. Then K_y=(uI+v n_y dot sigma)/2. Pauli multiplication gives, for X=x dot sigma,

  K_y X K_y = (1/4)[u^2 X + uv{n_y dot sigma,X}
                              +v^2(n_y dot sigma)X(n_y dot sigma)].

The scalar terms cancel by sum n_y=0 and the quadratic terms average by the tetrahedral second moment. The resulting Lüders map L is depolarizing with shrink

  t_L=u^2-v^2/3=(1+2sqrt(1-a^2))/3.

Therefore C=(L+Q)/2 is depolarizing with

  s(a)=[1+2sqrt(1-a^2)+a]/6.

This is maximized at a=1/sqrt(5), where sqrt(1-a^2)=2/sqrt(5) and s=(1+sqrt(5))/6. At that point Phi=C^*C=Delta_((3+sqrt(5))/18), attaining the universal upper bound. The c04_s03 instrument-append channel and Petz correction give an actual full-domain broadcaster for Phi; here C is itself selfadjoint depolarizing, so the corrected marginal is C^2.

For every smaller target lambda, the canonical same-effect construction in REV1 already represents Delta_lambda, since its range [0,1/4] is contained in the interval just attained. Thus the stated iff classification is complete.

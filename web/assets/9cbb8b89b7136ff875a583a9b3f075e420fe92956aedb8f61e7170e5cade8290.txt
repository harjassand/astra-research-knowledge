FERMIONIC ALGORITHMS — CYCLE 2 FINITE-BIT / AP AUDIT
8 October 2026

Question and status
-------------------
This note audits the full-sector reduction from general-graph perfect
matchings to the fixed Gutzwiller no-double-occupancy normalizer

  Z_k(A) = sum_{|I|=|J|=k, I intersect J = empty} |det A[I,J]|^2.

The reduction is restricted to the half-filled sector n=N, k=N/2 and to
explicitly encoded rational matrices A. In this regime the exact extraction
and the relative-approximation transfer both have polynomial-bit inputs. An
exact Fraction checkers pass on the unweighted and rational-weighted fixtures
in check_exact.json and check_weighted.json. The proofs below are general;
the checkers are finite evidence only.

Conclusion: one exact Z query recovers #PM by nearest-integer rounding. For
each requested relative error beta in (0,1], one FPRAS query to Z, after a
polynomial-bit dyadic perturbation and a polynomial-time perfect-matching
zero test, gives a beta-relative estimate of unweighted general-graph #PM.
More strongly, a separate rational-square-variant gadget gives an exact
one-query reduction and an AP transfer from arbitrary nonnegative rational
weighted perfect matchings. The fixed-filter weights remain nonnegative
rational squares. This is a reduction result, not an inapproximability
theorem or a claim that the source problem lacks an FPRAS.

Status correction: the 2017 paper cited in the earlier cycle-2 lead described
general-graph #PM FPRAS existence as open at that time. The pinned 23 September
2026 OpenAI/math release OA113 now claims an FPRAS for simple unweighted
general-graph #PM with exact zero detection. That release is primary
source-reported evidence, not independent proof validation performed in this
leaf. Thus the consequence established here is still a rigorous transfer, but
it must not be described as a consequence for a currently open problem
without accounting for OA113. The weighted extension below does not assert
weighted #PM inapproximability or validate a weighted FPRAS. No target FPRAS
or physical preparation procedure is inferred.

1. Source cleanup and pair gadget
---------------------------------
Let G be a finite simple graph on even m vertices, with E0 edges, and let
P(G) be its number of perfect matchings. If m=0, return P(G)=1 directly. If
E0=0 and m>0, return P(G)=0 directly. Otherwise, if E0<m, add new vertices
u,v, the edge uv, and all edges uw for old vertices w. Since v is a leaf,
uv is forced in every perfect matching; the added edges uw cannot be used,
and deleting uv recovers a perfect matching of G. This padding preserves P
and gives E>=m. If E0>=m, leave G unchanged. From now on m,E refer to this
possibly padded graph, so E>=m and E>=1.

Put D=E-m and N=E+D=2E-m=m+2D. Then N is even. Use the row-coordinate space
Q^N=Q^m direct-sum Q^(2D), with graph coordinates first. There are E+D=N
paired sites:

* for each graph edge e={u,v}, one pair of columns (b_e,c_e)=(e_u,e_v);
* for each dummy index r in {0,...,D-1}, one pair
  (b_r,c_r)=(e_(m+2r),e_(m+2r+1)).

Let B and C be the N-by-N matrices whose columns are these first and second
vectors, in the same site order. Every column of B is a coordinate vector.
For a site set S of size k=N/2, let P(S) select both columns for every site
in S, and define

  d_S(t) = det([B+t I_N,C]_{P(S)}),
  R(t) = sum_{|S|=N/2} d_S(t)^2.

At t=0, a nonzero determinant must include every dummy pair, since its two
private rows occur nowhere else. The remaining k-D=m/2 graph-edge pairs
must cover every graph row exactly once. This is exactly a perfect matching.
For such a matching the selected columns are a permutation of the coordinate
basis and the determinant is ±1. Therefore

  R(0) = P(G).

This also handles P(G)=0 without cancellation: every summand is a square.

2. Exact chart into the fixed-filter normalizer
------------------------------------------------
The matrix B is a functional-map matrix: for a function f on {1,...,N},
B e_j=e_(f(j)). Its functional digraph has directed cycles and trees feeding
into cycles. If cycle lengths are ell_1,...,ell_s, the eigenvalues consist of
zero with multiplicity N-sum ell_i and all ell_i-th roots of unity, one set
for each cycle. Consequently, for every rational 0<t<=1/2, -t is not an
eigenvalue and M_t=B+tI is invertible. Define the rational chart input

  A_t^T = M_t^(-1) C.

For every S, matrix factorization gives

  [M_t,C] = M_t [I_N,A_t^T],
  d_S(t)^2 = det(M_t)^2 det([I_N,A_t^T]_{P(S)})^2.

Because N=2k, the selected square matrix on the right contains the identity
columns e_i for i in S. Expanding on them leaves, up to sign, the minor
A_t[S,S^c]. Every disjoint pair of k-subsets of [N] is of the form (S,S^c).
Thus the selected determinants enumerate exactly the fixed no-double filter:

  R(t) = det(M_t)^2 Z_(N/2)(A_t).                 (1)

All entries and values here are rational. There is no algebraic or complex
field extension, and the sum-of-squares weights d_S(t)^2 are nonnegative.

3. Exact rational-weight extension by square variants
------------------------------------------------------
Give each edge e of an even-order simple graph G a nonnegative rational
weight w_e. The source value is

  P_w(G) = sum_{M perfect matching} product_{e in M} w_e.

Return 1 directly for the empty graph. Remove zero-weight edges, since no
positive-weight term uses them. If the positive-support graph has no perfect
matching, return 0 using polynomial-time matching decision. On a positive
instance, find one positive-support perfect matching M_0 and let
L=product_{e in M_0} w_e>0; then P_w(G)>=L.

If the positive support has fewer than m edges, pad it by new vertices u,v,
the unit-weight edge uv, and unit-weight edges uw to every old vertex w. The
leaf v forces uv and the spokes uw cannot be used, so this preserves P_w.
Call the padded vertex count m' and retain the positive rational weights.

For each positive edge weight w=p/q in reduced form, form the positive
integer pq. Write its binary expansion as a sum of powers of two. Replace
each even power 2^(2s) by the one square (2^s)^2; replace each odd power
2^(2s+1) by two copies of (2^s)^2. This gives integers a_r with

  pq = sum_r a_r^2,     w = sum_r (a_r/q)^2.

The construction is deterministic and uses at most 2 bitlength(pq) variants,
each with polynomially many bits. Denote the rational amplitudes a_r/q by
alpha_(e,r). Make one paired site for each edge variant, with first and
second columns

  b_(e,r)=e_u,     c_(e,r)=alpha_(e,r)e_v,

for a fixed orientation e={u,v}. Add D dummy pairs of private coordinate
vectors (e_(m'+2s),e_(m'+2s+1)) so that D=Evar-m'>=0, where Evar is the
number of variants. Put N=Evar+D=2Evar-m'=m'+2D and k=N/2. Every column of
the first-block matrix B remains a coordinate vector, so B is still a
functional-map matrix. Let C contain the second vectors, including their
rational amplitudes.

For t=0, a nonzero selected determinant must contain all dummy pairs and
exactly m'/2 edge-variant sites whose underlying edges form a perfect
matching. Two variants of the same edge cannot both occur in a nonzero
determinant because they repeat endpoint rows. For a fixed source matching,
summing squared determinants over variant choices gives

  product_{e in M} sum_r alpha_(e,r)^2 = product_{e in M} w_e.

Consequently the square-variant gadget obeys R(0)=P_w(G) exactly over Q,
with no square-root approximation or weight normalization. The chart identity
(1) applies unchanged with A_t^T=(B+tI)^(-1)C.

Here the determinant-polynomial coefficients are rational rather than
necessarily integral. Let alpha_s denote the amplitude on site s, with
alpha_s=1 on dummy sites, and set

  W = sum_{|S|=k} product_{s in S} alpha_s^2
    = [z^k] product_s (1+alpha_s^2 z).

For each S and j, every determinant term in [t^j]d_S contains the common
factor product_(s in S) alpha_s, and the remaining coordinate determinant
is 0 or ±1. Thus |[t^j]d_S|<=binom(k,j) product_(s in S)alpha_s, and

  |[t^ell]R(t)| <= W binom(N,ell),
  |R(t)-P_w(G)| <= W((1+t)^N-1) <= 2 N W t  if Nt<=1/2.       (5)

The value W is computable exactly by an O(Nk) elementary-symmetric
coefficient DP. Its rational bit length is polynomial: with
Lambda=product_s den(alpha_s), every term of W has denominator dividing
Lambda^2, and numerator length is bounded by the total amplitude bit length
plus O(N). The same denominator Lambda^2 clears every coefficient of R.

For exact rational extraction, let r=m/2 and
Delta=product_e den(w_e), over the original positive-weight edges. Then
Delta^r P_w(G) is an integer. Also W>=L, because the site sets for M_0 and
all its variants (together with every dummy pair) contribute total mass L
to W; hence W Delta^r>=1. With h=ceil(log_2 N), choose

  q_w,exact = N+h+4+ceil(log_2(W Delta^r)),   t=2^(-q_w,exact).

Combining (5) with this choice gives |R(t)-P_w(G)|<=1/(8 Delta^r).
Therefore rounding Delta^r R(t) to the nearest integer recovers
Delta^r P_w(G) exactly. This is an exact one-query rational metric reduction.

For relative error beta in (0,1], use the found matching lower bound L and
choose

  q_w,rel = N+h+4+ceil(log_2(W/(beta L))),   t=2^(-q_w,rel).

Because W>=L, the logarithm's argument is at least one. Equation (5) gives
|R(t)-P_w(G)|<=beta L/8, hence relative perturbation at most beta/8. A target
FPRAS queried at gamma=beta/4 then yields relative error at most
gamma(1+beta/8)+beta/8 <=13 beta/32 < beta, after multiplication by the
exact rational det(B+tI)^2. The support zero-test and one matching are
polynomial time. This proves an AP transfer from arbitrary nonnegative
rational weighted PM to the rational nonnegative fixed-filter family.

Encoding and conditioning for the weighted extension are polynomial too.
If the source input has bit length L_in, the number of variants is
O(L_in), N=O(L_in), and each amplitude has O(L_in) bits; thus W, Delta^r,
L, q_w,exact, and q_w,rel all have polynomial bit length (q also includes
O(log(1/beta))). Write Qeps=2^q and T=Qeps B+I. Then

  A_t^T = Qeps T^(-1) C.

Each column of C contains one rational amplitude. If
H_N=N(q+1+ceil(log_2 N))+2 is the Hadamard bit bound for det(T) and its
cofactors, and amax is the maximum numerator/denominator bit length among
site amplitudes, each chart entry has numerator at most q+H_N+amax bits and
denominator at most H_N+amax bits. The dense chart size is polynomial,
for example O(N^2(N(q+log N)+q+amax)). Computing the integer cofactors,
applying C, reducing fractions, computing W and the exact scale, and
postprocessing all take polynomial bit time. No algebraic extension is
used. B is unchanged, so the condition-number bounds below apply verbatim:
log_2 kappa_2(B+tI)=O(Nq+N log N), polynomial in the encoded source input
and log(1/beta).

Comparison with the existing square-root approximation chart: that reduction
uses one pair per positive edge, normalizes weights by their maximum, and
approximates sqrt(w_e/M) from below by dyadic rationals. Its precision and
perturbation are charged in
outputs/research/algebra_complexity/cycle2/determinant_beyond_degree/evidence/check_weighted_pm_reduction.py
and `../conditional_lb/CONDITIONAL_LB.md`. It is more compact in graph dimension
and already suffices for weighted AP transfer. The present construction is a
separate alternative: it removes square-root approximation bias and maximum
weight normalization and makes R(0)=P_w exactly, at the cost of O(log(pq))
sites per edge and a larger N. It is not a replacement that improves every
cost; it is useful when exact rational amplitudes and exact baseline
extraction are the priority. Therefore it adds a second exact encoding, not a
new approximation-hardness classification. The repository's separate PC-05
binary-weight gadget also claims a weighted-PM FPRAS conditional on OA113;
that route and the old square-root chart already cover the AP-transfer
interface. Neither source result is independently audited in this leaf.

4. Explicit coefficient and extraction bounds (unweighted special case)
-------------------------------------------------------------------------
Each d_S(t) has degree at most k. Its coefficient of t^j is a sum over at
most binom(k,j) choices of j perturbed first columns. Each resulting
determinant has coordinate-vector columns and is in {0,+1,-1}; hence

  |[t^j]d_S(t)| <= binom(k,j).

Writing R(t)=sum_(ell=0)^N c_ell t^ell and convolving d_S with itself gives

  |c_ell| <= binom(N,k) sum_j binom(k,j)binom(k,ell-j)
          = binom(N,k)binom(N,ell).                (2)

In particular every c_ell is an integer with O(N) bits. For 0<t and Nt<=1/2,

  |R(t)-P(G)|
    <= binom(N,k)((1+t)^N-1)
    <= 2^N (exp(Nt)-1)
    <= 2^(N+1) N t.                                (3)

For exact extraction choose

  h = ceil(log_2 N),  q_exact = N+h+4,  t=2^(-q_exact).

Then Nt<=1/2 and (3) is at most
2^(N+1)N/2^(N+h+4) = (N/2^h)/8 <= 1/8 (strictly below 1/8 in (3)). Since
P(G) is an integer, rounding R(t) to its nearest integer returns P(G),
including zero instances. Combining (1) with the known exact factor
det(M_t)^2 yields the claimed one-query exact metric reduction.

For a requested relative accuracy beta in (0,1], choose

  q_rel = N+h+ceil(log_2(16/beta)),  t=2^(-q_rel).

Equation (3) gives |R(t)-P(G)|<=beta/8. If P(G)>0, then P(G)>=1, so the
relative perturbation eta=|R(t)-P(G)|/P(G) is at most beta/8. Decide first
whether G has a perfect matching, using polynomial-time general-graph
matching decision; return zero if it does not. On a positive instance, query
an FPRAS for Z at relative error gamma=beta/4 and set
Rhat=det(M_t)^2 Zhat. With the oracle's success event,

  |Rhat-P|/P <= gamma(1+eta)+eta
              <= beta/4(1+beta/8)+beta/8
              <= 13 beta/32 < beta.

This is a one-call AP transfer when the oracle accepts the requested
confidence. An oracle specified only at constant success probability can be
boosted with the usual O(log(1/delta)) independent repetitions and median.
The zero test is necessary for a relative approximation, and is polynomial
time. No unknown value P is used to choose t.

5. Rational encoding, construction time, and conditioning (unweighted chart)
----------------------------------------------------------------------------
Let Q=2^q and T=QB+I. Since M_t=T/Q,

  A_t^T = Q T^(-1) C = Q adj(T) C / det(T).          (4)

This formula also proves nonsingularity exactly: det(T) is a nonzero integer.
Let h=ceil(log_2 N), so every entry of T has magnitude at most Q+1 and
log_2(Q+1)<=q+1. Hadamard's inequality bounds every r-by-r minor, for
r<=N, by (sqrt(N)(Q+1))^r. A convenient explicit bit bound for det(T) and
all cofactors is

  b = N(q+1+h)+2 bits.

Each entry of A_t can be encoded with a numerator of at most q+b bits and a
denominator of at most b bits. Thus a dense N-by-N chart has at most
N^2(2b+q+2) bits, up to the usual polynomial indexing/sign overhead, which
is O(N^3(q+log N)). With q_exact this is O(N^4). With q_rel it is
O(N^4+N^3 log(1/beta)). Reduced fractions only shorten this bound. The
normalizing factor is exactly

  det(M_t)^2 = det(T)^2 / Q^(2N),

with polynomially many bits. The requested dyadic t itself uses q+1 bits.

For a conservative construction-time bound, compute the N^2 cofactors by
fraction-free exact determinants. Each determinant uses O(N^3) integer
arithmetic operations on polynomial-bit minors, so this costs at most
O(N^5) polynomial-bit arithmetic operations. Integer gcd reduction and the
final dense matrix write are polynomial as well. Equivalently, any standard
exact rational linear solve with minor-bounded intermediates constructs the
same chart in polynomial bit time. The coefficient integers c_ell in (2)
have O(N) bits; evaluating R(t), computing the determinant scale, and
postprocessing an oracle estimate all use polynomial-bit rational arithmetic.
The FPRAS accuracy parameter is gamma=beta/4, so its requested precision
cost is polynomial in beta^(-1), while chart bit length depends on
log(1/beta).

Conditioning is charged separately from encoding. Each column of B has one
unit entry, so ||B||_2<=||B||_F=sqrt(N), and ||M_t||_2<=2sqrt(N). Every
zero eigenvalue of B contributes a factor t to |det(M_t)|. For a cycle
eigenvalue zeta, |zeta+t|>=1-t>=t when t<=1/2. There are N eigenvalues
counting multiplicity, hence |det(M_t)|>=t^N. It follows that

  sigma_min(M_t) >= t^N/(2sqrt(N))^(N-1),
  kappa_2(M_t) <= (2sqrt(N))^N t^(-N).

For q=O(N+log(1/beta)), log_2 kappa_2 is O(N^2+N log(1/beta)); the
condition number can be exponential, but its logarithm is polynomial. The
reduction constructs and inverts T exactly, so no floating-point inverse or
unaccounted numerical tolerance is used. A numerical implementation would
need guard precision reflecting this condition bound in addition to output
precision. This is a classical counting reduction, not a physical
postselection or gate-synthesis cost bound; in particular it does not bound
the Gutzwiller success probability Z/W.

6. Interpretation and boundaries
---------------------------------
* Exact complexity: Valiant's 0-1 permanent theorem makes counting bipartite
  perfect matchings #P-hard, and these graphs are a subclass of the source
  general graphs. The exact metric reduction above therefore proves exact
  #P-hardness for the rational half-sector fixed-filter normalizer.
* Approximation: we prove an AP reduction from both unweighted #PM and
  arbitrary nonnegative rational weighted #PM to the nonnegative rational
  family (1). Because the weights are explicit determinant squares, no
  signed cancellation or hidden exponentially long tag is used. This does
  not prove #BIS-hardness, #P-AP-hardness, or absence of an FPRAS for Z.
  The term “AP-hardness” is not used as a class-hardness conclusion here:
  no source with a separately established approximation-hardness result is
  reduced in this leaf.
* Current source context: the 2017 primary paper below says the general-graph
  perfect-matching FPRAS question remained open at that date. The pinned
  2026 OA113 primary release claims to resolve it for simple unweighted
  graphs. The present leaf neither validates nor rejects that separate
  theorem; its report is marked source-reported, not independently verified.
  The internal PC-05 binary-weight gadget conditionally extends that claim
  to nonnegative rational weighted PM, also without independent end-to-end
  validation here.
* Interface: the reduction is for the exact no-double filter and k=N/2.
  It does not transfer hardness for arbitrary externally supplied filters,
  arbitrary code constraints, or unfiltered Gaussian normalization.
* Physical resources: exact rational preprocessing and an FPRAS oracle are
  charged here. Device success rates, expected postselection trials, and
  coherent preparation are outside the theorem.

Reproduction
------------
Run:

  python3 outputs/research/algebra_complexity/cycle2/border_rank_bits/check_exact.py
  python3 outputs/research/algebra_complexity/cycle2/border_rank_bits/check_weighted.py

The scripts use only Fraction arithmetic and standard-library combinations.
The fixtures include C4, K4, P4 with forced-leaf padding, two disjoint
triangles (zero perfect matchings), C6, the no-edge branch, and the empty
graph branch. The weighted script checks rational square-variant identities,
exact denominator-grid extraction, weighted coefficient/error bounds, chart
bit bounds, and relative-error composition on weighted C4, a half-weight K2
with padding, and a zero-source graph. The receipts check the determinant/
target identity and are corroboration, not proof of the general claims.

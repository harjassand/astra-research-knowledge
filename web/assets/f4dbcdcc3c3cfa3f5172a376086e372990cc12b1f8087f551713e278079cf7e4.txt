REPRODUCING THE CENTRAL CHECKS

Extract frontier_research_evidence.zip into an empty directory and run commands
from its root. The archive contains new research reports, code, diagnostics and
source-provenance records. Downloaded paper snapshots and the full 276 MB prior
repository are intentionally omitted; their stable URLs/hashes remain in reports
and SOURCE_PROVENANCE.json. The original local workspace retains those snapshots.

Python 3 is required. The central spectrum and endpoint checks additionally use
NumPy. Other optional scripts may use SymPy, SciPy or CVXPY; inspect their imports.
No dependency installation was performed by the packaging step.

To restore the exact prior repository for checks that verify source hashes:

  git clone https://github.com/harjassand/astra-research-knowledge.git work/astra-research-knowledge
  git -C work/astra-research-knowledge checkout --detach 1c5743f427b2200d7a1ba188063e5c07053a5744

The six checks replayed by the root agent:

  python3 work/scouts/gibbs_criticality_checks.py
  python3 work/scouts/statistical_geometry_checks.py
  python3 work/deep/pure_quantum_lower_check.py
  python3 work/expansion/quantum_boundary_check.py
  python3 work/deep/energy_constructive.py --outdir work/verification/energy
  python3 work/deep/nonsofic_rank_checks.py

They write diagnostic JSON, some alongside their scripts. Expected receipt:
work/verification/root_replays.json. Other script/result pairs are located in
outputs/research_index.json and research_index.txt. Their reported executions
are not claimed as root replays.

Read the mathematical arguments separately. These scripts test finite instances,
identities and implementation details; they cannot certify infinite quantifiers
or historical priority. Compilation only checks the document source.

Open outputs/research_report.tex in the Codex native LaTeX editor for its PDF
preview. The main source is standalone and was compiled successfully there.

MANIFEST.sha256 records each packaged file's SHA-256 and archive-relative path.
PACKAGING_RECEIPT.json records archive CRC/hash checks, which concern integrity
only. SOURCE_PROVENANCE.json lists retained source handles and omitted snapshots.

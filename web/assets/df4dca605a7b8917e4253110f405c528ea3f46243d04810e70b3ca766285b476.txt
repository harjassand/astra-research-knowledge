STATUS AND STRONGEST CONCRETE RESULT
No field-breaking result is established. A concrete attempted transfer from general-graph perfect-matching approximation to arbitrary LDPC / quantum-code posterior inference fails at two precise interfaces. The positive result below is conditional on OA113; its code class has an unconditional distance ceiling. The main unconditional local result is internally proved and checked, but follows classical matching-circuit / delta-matroid mechanisms and is not claimed as novel.

Let G be a finite graph with d distinct port vertices. Nonnegative edge weights and arbitrary nonnegative monomer fugacities are fixed. Define f_G(S) as the partition function of all matchings after deleting port set S, with the product of unmatched-vertex fugacities included. Zero fugacities recover perfect matchings. For all S,T and i in S symmetric-difference T,

 f(S) f(T) <= f(S xor {i}) f(T xor {i})
              + sum_{j in (S xor T)\{i}} f(S xor {i,j}) f(T xor {i,j}).    (1)

The singleton term is omitted in the perfect-matching-only model. A weight-preserving injection switches the alternating path beginning at i between two matchings. This works with arbitrary internal vertices and arbitrary nonnegative weights; adding monomers does not remove the obstruction.

Two consequences, with full proofs in combinatorics_codes_proofs.txt:
* A nonempty affine Boolean relation x0+C is exactly realizable as the support of such a monomer matching gadget iff C is generated by vectors of Hamming weight one and two. In the perfect-matching model, generation by weight two alone is necessary and sufficient. Equivalently, these are disjoint parity blocks, fixed coordinates, and—in the monomer model—free coordinates. Thus a nontrivial local linear code of minimum distance >=3 cannot be a positive matching port gadget.
* For d>=3, R=sum_{S other than empty/all} f(S) satisfies R>=2 sqrt(f(empty)f(all)). Consequently any normalized square-root boundary state sum_S sqrt(f(S)) exp(i theta(S)) |S> has squared fidelity at most 1/2 with GHZ_d, even with arbitrary supplied phases. The induced classical distribution is at total variation distance at least sqrt(2)-1 from the fair copy relation {0^d,1^d}. These constants are sharp in the stated models (the TV infimum is attained with real weights, approached by rational ones).

This refutes even approximate three-way copy using this positive local port interface. It is NOT a no-go for all matching encodings or all quantum preparations. Selected original-edge bits are a different interface: a triangle with syndrome 110 has error configurations 100 and 011 and produces a GHZ-type error-record state after one bit flip. Extra quantum gates, nonlinear global encodings, postselection, and signed cancellations are not covered by (1).

CONCRETE POSITIVE TARGET AND EXACT INPUT INTERFACE
Target: posterior inference and near-maximum-likelihood logical-class decoding for a supplied graphical CSS code, including rare acquired syndromes, without an inverse-syndrome-probability factor.

Input consists of explicit binary CSS matrices H_X,H_Z with H_X H_Z^T=0; H_X has column weight <=2; independent X-error probabilities p_e supplied as rational bit strings; a measured/legal syndrome s; epsilon,delta>0. Deterministic p_e=0 or 1 are eliminated with the corresponding syndrome update. Columns of weight one connect to one added ground vertex; weight-two columns are graph edges; zero columns are independent free bits. This is a model supplied by the input, not a noise distribution learned for free.

For activities a_e=p_e/(1-p_e), the posterior has weights
 a^x / Z_s(a),   Z_s(a)=sum_{H_X x=s} a^x.
There is an exact positive weighted-perfect-matching representation of Z_s of size O(m+r). At each graph vertex, a tree of triangles realizes the prescribed parity with exactly one completion for each allowed external-edge pattern. Original-edge weights carry a_e. Graph degree is <=3 before the weight-elimination gadgets. Prefix restrictions are obtained by deleting fixed edges and updating the syndrome. Feasibility is acquired by a binary linear solve or component-parity check.

OA113's headline theorem is only for explicit SIMPLE UNWEIGHTED graphs. To close that interface, I constructed an O(log P)-vertex unweighted two-port gadget with signatures unused=1, used=P for each integer P>=1. A simple acyclic path-counting network with P source-target paths supplies it. For rational P/Q replace a logical edge by a length-three path of integer weights (P,Q,1), then replace each integer edge by the gadget. The exact identity is
 #PM(unweighted graph) = (product of the Q_e) Z_s(a).
The graph size and scale-factor bit length are polynomial in the total input bit length, not in numeric weight magnitudes. This construction is unconditional; no counting algorithm was executed.

Assuming the exact OA113 theorem, classical self-reduction therefore samples the posterior to total variation tau in polynomial time in m, the input bit length L, and tau^{-1}. Its cost contains no 1/Pr(s). Only visited prefixes are queried, with fresh randomness and exact feasibility checks. Fixed-bit rounding pays for sampling rational branch probabilities.

Let C_Z=im(H_Z^T), k=m-rank(H_X)-rank(H_Z). Label each sampled error by its coset modulo C_Z using Gaussian elimination. Take N=O((k+log(delta^{-1}))/epsilon^2) independent posterior samples of TV error <=epsilon/4, and return a representative of the most frequent observed logical class. Hoeffding over the 2^k possible classes costs only log(2^k)=k; the implementation stores only observed classes. With probability >=1-delta over decoder randomness, its posterior success mass is at least the optimal logical-class mass minus epsilon. No exponential class enumeration or class-conditioned partition oracle is assumed. Correlated X/Z depolarizing noise and coherent logical-phase sums are outside this interface.

A conditional coherent error-record compiler is also spelled out in the proof appendix: fixed capped random tapes shared across all prefixes at a depth; true-prefix-weighted bad mass; a hybrid norm bound. Its randomly compiled circuit has preparation error epsilon with probability 1-delta and polynomial size in m,L,epsilon^{-1},log(delta^{-1}). It requires a worst-case bit-time FPRAS and supplied efficient phases. Good seeds are not efficiently certified. This is not physical postselection of an existing unknown encoded quantum state.

TWO FATAL EXTENSIONS
1. Graphical CSS distance ceiling. If H_X has column weight <=2 and k>0, then for m>=2
 k d_X <= 6 m log(m) + 2k.
Choose pivot edges J for C_Z and delete them. The surviving graph cycle space maps isomorphically to ker(H_X)/C_Z, so every surviving cycle is a logical X operator. Its cycle rank is k. Prune to the 2-core and use the irregular Moore bound, or find a short unicyclic component. This proves d_X=O(log m) at constant rate, even without locality restrictions on H_Z. Thus the conditional decoder class cannot yield an asymptotically good quantum LDPC family.

2. Arbitrary column-weight-three posterior FPRAS. A uniform relative FPRAS polynomial in rational bit length for all Hx=s, already with columns of weight three, would imply RP=NP. Given an exact-cover-by-3-sets instance, use its incidence matrix H, s=all ones, and lambda=2^(-m-3). A solution of weight <=|U|/3 is exactly an exact cover. If one exists, all higher-weight legal configurations have total posterior probability <=2^m lambda<=1/8. The FPRAS self-reduction sampler then finds a verifiable cover with constant probability; no-instances are always rejected. This directly derived low-temperature reduction is a global obstruction, independent of the local copy-gadget failure. It does not exclude fixed-noise, typical-syndrome, or code-specific inference.

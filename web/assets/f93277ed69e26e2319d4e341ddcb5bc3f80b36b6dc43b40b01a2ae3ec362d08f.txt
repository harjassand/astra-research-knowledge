CYCLE 4 LEAF — SPARSE PAIRED-EDGE COMMUNICATING CLASSES
Date: 2026-10-08
Status: INTERNAL DERIVATION for class structure and Lyapunov properness. The
cycle-3 sparse Foster theorem remains an internally proved candidate pending
independent review; this report does not upgrade its status or claim novelty.

DECISIVE RESULT
---------------
For the finite sparse bipartite support graph E, with positive catalyst
immigration/death and positive paired substrate reactions on every declared
edge, the communicating classes are exactly the fibers obtained by fixing
the counts of substrates with no incident edge. Isolated catalysts are not
class labels: their counts can be raised/lowered through 0 <-> A_j. There are
no additional graph-component, parity, or nonlinear invariants. Every
reaction has its reverse, so each communicating class is closed.

The support-switch exponential Foster function is proper on each such class.
In fact, if it includes R_i^(b_i) for isolated substrates as written below,
it is proper on the full lattice too; those terms are frozen constants on a
class and contribute zero to its generator. The cycle-3 mixed-escape drift
argument therefore applies on each fixed-label fiber, including when some
catalysts are isolated. It yields no common full-state stationary tightness
over fibers when at least one substrate is isolated: the frozen labels alone
force classwise stationary laws to escape every finite set. This is a
cross-class obstruction, not a failure of recurrence inside a fixed class.

NETWORK AND NOTATION
-------------------
Let J and I be finite catalyst and substrate index sets, with state
(a,b) in N_0^J x N_0^I. For each j in J include 0 <-> A_j with rates
alpha_j, delta_j > 0. For each (j,i) in E include the four channels

  A_j <-> A_j+B_i,                 rates p_ji, q_ji > 0,
  A_j+B_i <-> (k_ji+1)A_j+B_i,    rates u_ji, v_ji > 0,

where k_ji is a fixed positive integer and propensities use stochastic
mass action (in particular, the reverse autocatalytic rate is
v_ji (a_j)_(k_ji+1) b_i). Define

  N(i) = {j : (j,i) in E},
  I_+ = {i : N(i) is nonempty},
  I_0 = {i : N(i) is empty}.

The label vector is ell=(b_i : i in I_0). The claims below are pointwise in
the fixed positive finite rates.

EXACT CLASSIFICATION AND CONSTRUCTIVE PATHS
-------------------------------------------
Necessity of the label: no reaction has an isolated B_i in its source or
changes its count. Thus b_i is constant along every path for i in I_0.

Sufficiency: fix any label ell and let C_ell be the set of all states with
those isolated-substrate counts. Define its canonical state z_ell by

  a_j=0 for every j;  b_i=0 for i in I_+;  b_i=ell_i for i in I_0.

For any x in C_ell, construct a finite positive-rate path x -> z_ell as
follows.

1. For each i in I_+, select one neighbor j(i) in N(i). If a_j(i)=0,
   fire 0 -> A_j(i) once. Then fire A_j(i)+B_i -> A_j(i) exactly b_i
   times. Each such firing is enabled while b_i>0, decreases b_i by one,
   and leaves the catalyst count unchanged. Processing another substrate
   cannot undo this clearing.
2. Fire A_j -> 0 exactly the current a_j times for each j. All catalysts
   are then zero and the active substrate counts remain zero.

For any target y in C_ell, construct z_ell -> y as follows.

1. For each i in I_+ with target count b_i(y)>0, choose j(i) in N(i).
   If its current catalyst count is zero, fire 0 -> A_j(i) once. Fire
   A_j(i) -> A_j(i)+B_i exactly b_i(y) times. These steps leave A_j(i)
   present and set the requested B_i count without changing other B counts.
2. Adjust every catalyst count to a_j(y), using 0 -> A_j for upward unit
   moves and A_j -> 0 for downward unit moves. These channels do not alter
   any substrate count.

Both paths use finitely many reactions (linear in the endpoint counts plus
the finite number of coordinates). Every prescribed jump has positive
rate at its source; because each visited state has finite total rate, the
finite path has positive probability. Thus every pair of states in C_ell
communicates. No state outside C_ell is reachable, so C_ell is closed.
Alternatively, closure follows immediately from preservation of ell, and
the paired channels also make each individual jump reversible.

This covers isolated catalysts: if N(j)=empty, its birth/death steps remain
available in both path constructions. Disconnected nontrivial graph
components likewise create no labels, since every catalyst has its own
0 <-> A_j moves and every nonisolated substrate can be built/cleared using
one neighbor. If E is empty, classes are exactly N_0^J x {ell} for each
substrate vector ell; if J is empty, the state space consists only of
singleton substrate-label classes.

There are no further invariants. The path proof shows every pathwise
invariant is constant on each C_ell, hence is a function only of ell. For
linear conservation laws, the reaction vectors include +e_Aj from
0 -> A_j and +e_Bi from A_j -> A_j+B_i for every i in I_+. Therefore

  S = span{e_Aj : j in J} + span{e_Bi : i in I_+},
  rank(S) = |J| + |I_+|.

The full space of linear conservation vectors is supported on I_0. In
particular, isolated catalysts and separate connected components supply no
additional linear or modular labels. The integer stoichiometric fiber
through x is exactly C_(b_i(x):i in I_0).

RATE/SUPPORT BOUNDARY
---------------------
The stated classification uses alpha_j,delta_j>0 for every catalyst and,
for each nonisolated substrate, positive B-production and B-removal paths.
In the assigned paired-edge family p_ji,q_ji>0 on every edge, which is a
simple sufficient condition. For communication alone, u_ji,v_ji are not
needed: the +/-1 catalyst moves and the p/q substrate pair already give all
the paths. Their positivity is part of the specified weakly reversible
family and v_ji>0 is used by the cycle-3 recurrence drift argument.

If a nominal edge has p_ji=q_ji=0, it does not connect its B_i coordinate;
recompute I_+ using positive substrate-changing channels. If no positive
production path or no positive removal path exists for a substrate, its
count cannot move both ways and the fiber classification above no longer
follows. If a catalyst immigration or death rate is zero, the corresponding
unit path can fail and additional one-way structure or labels can arise.
No classification or recurrence claim for those degenerate rate patterns
is made here.

SWITCH FOSTER FUNCTION: PROPERNESS ON EACH CLASS
------------------------------------------------
For i in I_+, set h_i(a)=1{sum_(j in N(i)) a_j=0}. Let lambda_j>0,
R_i>1, epsilon_i>0 and K>0. The cycle-3 candidate, extended explicitly
over isolated coordinates, is

  V(a,b) = sum_j lambda_j a_j
          + sum_(i in I_+) R_i^(b_i) (1+epsilon_i h_i(a))
          + sum_(i in I_0) R_i^(b_i)
          + K 1{a=0}.

On the class C_ell, write

  C(ell)=sum_(i in I_0) R_i^(ell_i),
  W(a,b_+) = sum_j lambda_j a_j
             + sum_(i in I_+) R_i^(b_i)(1+epsilon_i h_i(a))
             + K 1{a=0}.

Then V=C(ell)+W and L V=L W on C_ell, because every isolated-substrate
term is constant along every transition. Also V >= W and

  W >= sum_j lambda_j a_j + sum_(i in I_+) R_i^(b_i).

Since there are finitely many coordinates, lambda_j>0, and every R_i>1,
each sublevel set of W in the active coordinates is finite. Thus V is
proper on C_ell. Including the isolated R_i^(b_i) terms makes V proper on
the full lattice as well. If one omits those frozen terms from a chosen
representative of the Foster function, that representative remains proper
on each C_ell but is not globally proper across the union of classes.

For the actual drift candidate, choose R_i close enough to one that

  chi_j = lambda_j delta_j
          - sum_(i:(j,i) in E) p_ji (R_i-1) > 0

for each j, and choose K>(H+1)/alpha_sum, where
H=sum_j alpha_j lambda_j and alpha_sum=sum_j alpha_j. For an isolated
catalyst j, the sum in chi_j is empty and chi_j=lambda_j delta_j>0.
The cycle-3 support-switch generator has no dependence on ell: isolated
substrates create no reaction terms, and their added terms in V have zero
generator. Its escape-sequence proof is therefore fiberwise unchanged.
In particular, if a catalyst count diverges with all its neighboring
substrates zero, chi_j gives negative linear drift; with a positive
neighboring substrate, the reverse factorial term controls catalyst
growth. If an active substrate diverges while all its neighbors are absent,
immigration switches h_i down and contributes negative order R_i^(b_i);
if a neighbor is active, the paired q_ji a_j b_i removal dominates the
possible last-neighbor-death switch. Isolated catalysts have only their
negative linear death term in this escape analysis. This rules out an
active-coordinate escaping sequence with drift failing to tend to
-infinity, under the candidate's stated positive-rate hypotheses.

This drift parameter choice presumes J is nonempty, as in the cycle-3
Foster family. If J is empty, then I_+ is empty as well and every class is
a singleton fixed substrate vector; class structure and properness are
trivial, while the displayed K>(H+1)/alpha_sum criterion is simply not
needed.

Consequently the Foster exceptional set {x in C_ell : L V(x)>-1} is finite
for each ell. Its active-coordinate projection is the same finite set for
every ell because LV is independent of ell. This verifies classwise
properness and rules out a special bad class caused by graph isolation.
It is not a new independent proof of the stochastic nonexplosion/Foster
criterion steps in SPARSE_EXTENSION.txt; that broader candidate remains
pending independent proof review.

CROSS-CLASS ESCAPE AND UNIFORMITY
---------------------------------
If I_0 is empty, there is one communicating class and no cross-class
stationary-tightness question. If I_0 is nonempty, there are infinitely
many closed classes. Under the cycle-3 classwise positive-recurrence
candidate, all fibers have isomorphic active-coordinate generators: the
rates of every transition depend only on (a,b_+), never on ell. Hence their
unique stationary laws have the same active-coordinate marginal, say
bar_pi, and

  pi_ell = bar_pi tensor delta_ell.

Choose i0 in I_0 and classes with ell_i0=n, all other labels fixed. For
every finite set F of states, the i0-coordinate has a finite maximum on F;
when n exceeds it, pi_ell(F)=0. Thus {pi_ell} is not uniformly tight on the
full state lattice. Also E_pi_ell[V] >= R_i0^n, so there is no uniform
stationary V-moment bound. This is an exact frozen-coordinate obstruction,
not an N77-style nonlinear invariant inside a fixed stoichiometric slice.
It does not contradict classwise positive recurrence or tightness after
projecting away the fixed labels. A chosen probability mixture over the
classwise laws can itself be tight; what fails is a bound uniform over all
classes.

The global V displayed above is proper, but no global geometric drift
LV<=C-cV with c>0 can hold on the union when I_0 is nonempty: fix any
active state and let an isolated label n tend to infinity. LV stays fixed
while V grows like R_i0^n. Likewise, the global set {LV>-1} is the product
of a finite active set with infinitely many labels, hence is not finite.
The correct Foster application is on each closed fiber (or on the quotient
that forgets frozen coordinates). The additive-drift argument gives a
common active-coordinate drift region, but it supplies no uniform bound
for the frozen-coordinate values.

Oracle quotients, exact non-identifiability, and the smallest matrix extension
Date: 2026-10-08
Status: elementary propositions proved below; source claims retain their stated provenance.

Main result

An oracle reveals an equivalence class of representations, not necessarily the representation itself. The exact indistinguishability criterion is the kernel of the complete observation map. If the desired task distinguishes two representations inside one such fiber, no adaptive learner can solve it with any number of queries. This is a query-budget-independent obstruction. It applies to learning noncommutative word order from a commutative oracle. It does not, over an infinite field, make commutative PIT impossible: the commutative zero predicate is constant on the fibers. Over a finite field when queries are restricted to base-field scalars, there is a separate fiber obstruction to formal commutative PIT itself.

General quotient theorem

Let F be a field, R and S be unital F-algebras, and Q:R→S an F-algebra homomorphism. Let U be the set of legal queries. For every u∈U, let χ_u:S→Y_u be an additive map (in particular, an algebra evaluation homomorphism is allowed). The exact oracle on a hidden representation r∈R returns

  O_r(u) = χ_u(Q(r)).

Define K_U = ⋂_{u∈U} ker(χ_u). Then the complete observable profiles of r and r' agree exactly when

  Q(r)−Q(r') ∈ K_U.

If the query maps jointly separate S (K_U={0}), this is equivalent to Q(r)=Q(r'), or r−r'∈ker(Q). More generally the observable object is the further quotient S/K_U. This gives the exact query-fiber characterization, including restricted query domains.

Proposition (budget-independent impossibility). Let T:R→{0,1} be a task label. If there are r_0,r_1 with T(r_0)≠T(r_1) and Q(r_0)−Q(r_1)∈K_U, then no deterministic or randomized adaptive algorithm using this oracle can always distinguish r_0 from r_1, for any query budget. Proof: every legal query has equal answer on the two representations. Couple randomized algorithms with the same internal random bits. By induction on query number, the next query and its answer agree, so the full transcript and output distributions agree. Under a uniform prior on the pair, every decision rule has error at least 1/2. This remains true even if the algorithm is allowed every query in U; additional queries inside the same observation family cannot split the fiber.

Scalar/commutative specialization

Take R=F⟨x_1,...,x_n⟩, S=F[x_1,...,x_n], and Q=ab, the abelianization homomorphism. Its kernel is the two-sided ideal I_comm generated by all x_i x_j−x_j x_i. Scalar point queries are χ_a(f)=f(a), a∈F^n.

If F is infinite and U=F^n, then K_U={0}: a formal commutative polynomial that vanishes at every point of an infinite field is zero. Therefore two free polynomials have identical scalar-query profiles exactly when they have the same abelianization, equivalently their difference is in I_comm. For example, r_0=0 and r_1=xy−yx lie in one query fiber although they differ as free polynomials. They are task-distinct for free-polynomial identity testing, word-support recovery, or learning word order. No amount of exact scalar queries can recover that lost distinction.

Important scope limit: the commutative-PIT label T_comm(r)=1[ab(r)=0] is constant on these fibers. On an infinite field, all scalar values determine ab(r) in principle. The quotient theorem therefore does not give an information-theoretic impossibility for commutative PIT over Q or C. The known barrier there is computational/resource-bounded hitting-set construction for general circuit classes, as recorded separately in the preceding commutative-vs-NC note.

If F=F_q and the legal queries are only points in F_q^n, then K_U is the vanishing ideal

  J_q = (x_1^q−x_1, ..., x_n^q−x_n).

Thus the scalar oracle reveals only the polynomial function, i.e. the class modulo J_q. In one variable, 0 and x^q−x are different formal polynomials but agree on every legal query. Formal PIT for arbitrary-degree inputs is impossible with any number of base-field scalar queries. A degree bound below q or extension-field queries can remove this particular kernel; for a degree-D polynomial, an extension with more than D elements guarantees that nonzero polynomials cannot vanish everywhere by the root bound. If the base field is fixed as F_q, an extension of degree m≥ceil(log_q(D+1)) suffices, with each field element requiring m log q bits to represent. This is an interface limitation, not a claim about standard PIT models that already allow a sufficiently large extension field.

Smallest standard noncommuting extension for a commutator family

Consider r_c=c[x,y]=c(xy−yx), c∈Q, and task T(r_c)=1 iff c=0. Every scalar query returns zero for every c, so all c lie in one scalar-oracle fiber. Add the single capability of evaluating the hidden free representation at one tuple of square matrices. Set

  X=E_12=[[0,1],[0,0]],  Y=E_21=[[0,0],[1,0]].

Then [X,Y]=XY−YX=diag(1,−1)=D, and the one matrix response is cD. At dimension one all query matrices are scalars and every commutator vanishes; dimension two is therefore the smallest standard matrix-algebra extension that separates this family. One 2×2 tuple query suffices, with two input matrices (eight dense scalar slots, only two nonzero 0/1 entries) and one 2×2 output. For c∈{0,1}, the exact response uses constant bits and distinguishes zero from nonzero. This oracle augmentation is additional access to the free representation; it cannot be synthesized from the scalar transcript, which is identically zero for the whole family.

Noisy margin. In spectral operator norm, ||D||_2=1 and the two exact response centers for c=0 and c=1 are distance 1 apart. If the returned matrix has additive adversarial noise E with ||E||_2≤ε, thresholding ||cD+E||_2 at 1/2 distinguishes c=0 from c=1 whenever ε<1/2. More generally, if the alternatives are c=0 and |c|≥γ, their response centers are separated by at least γ; the radius-ε response sets are disjoint exactly when 2ε<γ, and threshold γ/2 succeeds.

For reduced rational c=a/b with nonzero numerator and denominator bit length at most H, |c|≥2^(−H). A worst-case robust test therefore needs error below 2^(−H−1), or roughly H+1 bits of precision; the exact response itself has O(H) bits. Without a coefficient-height or signal-margin bound, no fixed positive noise tolerance can decide zero versus nonzero: nonzero c can be arbitrarily close to zero. Thus the exact matrix separation is strong for this family, while its noisy extension needs a charged coefficient/precision promise.

This tailored 2×2 query is not a universal free-polynomial identity test. A fixed matrix algebra has polynomial identities at sufficiently high degree (the standard identity of M_d has degree 2d), so a universal family must scale its test structure or use multiple points. The ECCC sparse-polynomial result below supplies exactly such a class promise and a dimension that scales with sparsity.

Comparison with N68 and N51 full matrix calls

N68 primary-source boundary. Lakhani–Mukhopadhyay, ECCC TR26-120 rev. 2, Theorem 2.1, gives for every n,s≥1 a deterministic poly(n,s)-time construction of one tuple in M_s(Z)^n that detects every nonzero characteristic-zero free polynomial with at most s words. Each matrix entry has O(s log(n+1)) bits; the blackbox is assumed to accept matrix-algebra queries and return the full matrix f(A). The construction uses an injective base-(n+1) code for words and a Vandermonde independence argument. Their Theorem 2.7 shows dimension s is optimal for a single hitting tuple for the whole s-sparse class. At s=2 the interface is already a one-call 2×2 matrix oracle and covers the commutator example, but only because the hidden object is a free polynomial with a supplied sparsity ceiling. It does not create a free lift from a scalar commutative oracle.

The call-count is not the bit-cost. N68 writes n s^2 integer entries, each O(s log(n+1)) bits, so the tuple description is O(n s^3 log(n+1)) bits. For n=1,s=2 the construction has A_1=[[1,1],[0,2]]. On f=x^L it returns [[1,2^L−1],[0,2^L]], with Θ(L) response bits. The theorem is a one matrix-algebra query; exact bit-time to read a full response can depend on degree. The repository's stronger 2s-dimensional one-response term reconstruction is a separate source-derived candidate, with a decoder polynomial in the actual response bit length, not the ECCC theorem.

N51 source boundary. The repository's N51 card records a source-derived, unreviewed claim for size-s noncommutative rational formulas: a deterministic polynomial-total-bit list of integer/rational matrix tuples, indexed by unary n and B=2s+1, with a defined invertible hit for every nonzero admissible formula and all original inverse domains preserved. It is broader in formula semantics than N68's sparse-polynomial class, but has a list of full matrix calls rather than the tailored single query above. The card records that the full generator was not executed, its constants are impractical (already more than 4e62 tuples in a base case), and external correctness/priority remain unresolved. Formula evaluation at every tuple, complete matrix responses, and undefined-domain handling are separate costs. This is an exact algebraic hitting claim, not a noisy stability theorem.

Neither result separates representations in one commutative-oracle fiber unless the user supplies a new matrix-evaluation capability for a selected free lift. Their matrix response semantics are deliberately richer than scalar point values. Their exact nonzero guarantees also do not imply a uniform noise margin: for N68, scaling a nonzero sparse polynomial by c scales its response; for N51, the size-one constant formula c evaluates to cI. Arbitrarily small nonzero c makes the smallest singular value arbitrarily small. A coefficient-height promise can give a bit-precision bound, but the cited hitting statements alone do not provide robust margins.

Claim ledger

Q1 — Exact observation quotient theorem. For R,S,Q,U,χ_u as stated, equality of complete query profiles iff Q(r)−Q(r')∈⋂kerχ_u. Status: INTERNALLY-PROVED; proof is direct from the definition.

Q2 — Budget-independent impossibility. If T differs on a common observation fiber, no adaptive deterministic/randomized learner can distinguish the pair at any budget; uniform-prior error is at least 1/2. Status: INTERNALLY-PROVED; transcript coupling proof given above.

Q3 — Scalar free-algebra acquisition boundary. Over infinite F, scalar point queries identify exactly the abelianization; 0 and [x,y] are indistinguishable although free identity differs. Status: INTERNALLY-PROVED; uses the infinite-field polynomial identity principle and ker(ab)=I_comm.

Q4 — Finite-field scalar limitation. On F_q^n, the full scalar observation kernel is J_q; hence formal PIT on arbitrary-degree polynomials cannot be solved from base-field point queries alone. Status: INTERNALLY-PROVED; standard coordinate-ring/vanishing-ideal argument.

Q5 — Minimal targeted matrix extension. For c[x,y], all scalar responses are zero; one 2×2 query at (E12,E21) returns c diag(1,−1), and d=1 cannot separate. Exact gap 1 for c∈{0,1}; bounded spectral-noise threshold ε<1/2. Status: INTERNALLY-PROVED for the stated family/interface; not a universal PIT algorithm.

Q6 — N51/N68 scope. Their black-boxes return full matrix values on noncommuting tuples and rely on formula-size or free-word-sparsity promises, so neither supplies the missing lift or a commutative-quotient query.

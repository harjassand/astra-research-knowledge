2. CONCRETE NETWORK INTERFACE
Supplied: fixed A in C^{N x N}; certified compact convex K containing W(A); local state q, input p, output r; known time-dependent local matrices L_{t,0},L_{t,1},B_{t,0},B_{t,1},C_t. A polygon K admits the finite vertex certificate in Section 3; other K require a supplied valid scalar-domain gain certificate. Full network:
 x_{t+1}=(I_N tensor L_{t,0}+A tensor L_{t,1})x_t
         +(I_N tensor B_{t,0}+A tensor B_{t,1})u_t,
 y_t=(I_N tensor C_t)x_t, x_0=0.
Same spatial A at every time; local matrices may fail to commute arbitrarily. No feedthrough, so causal feedback is well posed by time recursion. Arbitrary rational/holomorphic spatial coefficients also work given the extended calculus, but polynomial interface avoids another import.
Scalar fibre at z in K replaces A by z:
 L_t(z)=L_{t,0}+z L_{t,1}, B_t(z)=B_{t,0}+z B_{t,1}.
Let T_H(z) map (u_0,...,u_{H-1}) to (y_0,...,y_{H-1}). Its strictly lower block-triangular entries are
 [T_H(z)]_{t,s}=C_t L_{t-1}(z)...L_{s+1}(z)B_s(z), s<t,
with empty product I. It is a rectangular matrix polynomial; tensor factor reordering gives full input-output map T_H[A]. This remains true despite local matrix noncommutation.

3. SUPPLIED LOCAL CERTIFICATE, VERIFY AT VERTICES ONLY
For polygon K, for each time t suppose supplied Hermitian P_t>=0, and gamma>0, such that for each vertex v of K,
 M_t(v) = [L_t(v) B_t(v)]* P_{t+1} [L_t(v) B_t(v)]
          + diag(C_t* C_t-P_t, -gamma^2 I_p) <= 0.
These are matrices of order q+p, independent of N and H except the number of times. Because [L_t(z),B_t(z)] is affine in real and imaginary z and P_{t+1}>=0, its squared P-norm is matrix convex. Explicitly for z=sum alpha_j v_j,
 W(z)*P W(z) <= sum alpha_j W(v_j)*P W(v_j),
the difference being sum alpha_j (W(v_j)-W(z))*P(W(v_j)-W(z))>=0. Thus vertex inequalities imply M_t(z)<=0 for every z in K. This argument fails for a higher-degree W(z) without an additional domain certificate.
For each fibre, multiply the inequality by (x_t,u_t), sum over t, and telescope:
 sum_{t<H} ||y_t||^2 + x_H*P_H x_H <= gamma^2 sum_{t<H} ||u_t||^2,
since x_0=0. Therefore sup_K ||T_H(z)||<=gamma.
OA325 gives ||T_H[A]||<=2 gamma, uniformly in N,H,p,r,q. Certificates for every horizon yield an infinite-horizon zero-state l2 induced-gain bound 2 gamma by monotone convergence.
This is a verification reduction from a full Nq-dimensional network to q-dimensional parameter storage plus a planar numerical-range enclosure. It is not an efficient universal synthesis algorithm: existence/acquisition of the local storage remains a separate optimization problem.

4. ROBUST FEEDBACK CONSEQUENCE
Let Delta be ANY single-valued causal uncertainty, possibly nonlinear, time varying, and mixing all network sites/channels, with Delta(0)=0 and prefix l2 gain <=delta. Close u=v+Delta(y). Strict causality of the plant gives a unique sequential solution without an algebraic loop. For every H,
 ||y||_H <= 2 gamma ||v+Delta(y)||_H
          <=2 gamma (||v||_H+delta ||y||_H).
If 2 gamma delta<1, then
 ||y||_H <= [2 gamma/(1-2 gamma delta)] ||v||_H,
uniformly in N,H. This is robust input-output finite-gain stability. Internal state stability is not asserted for hidden unobservable modes; it requires an internal stability premise or full-state monitored output. General uncertainty must satisfy the actual prefix gain bound; pointwise amplitude bounds alone are insufficient for dynamic uncertainty.

5. EXACT SHARPNESS AND STRONG FAILURE BOUNDARY
Let J=[[0,1],[0,0]], A=2J. Its numerical range is the closed unit disk. Plant y_{t+1}=gamma A u_t, y_0=0. Scalar fibre gain is gamma for all horizons H>=2, while full network gain is 2 gamma. For static real rank-one feedback Delta(y)_t=delta J* y_t,
 y_{t+1}=2 gamma delta J J* y_t+gamma A v_t.
At delta=1/(2 gamma), the homogeneous feedback matrix is diag(1,0). A single impulse v_0=e_2 creates a persistent nonzero y sequence, so the l2 gain is infinite. Above threshold it grows exponentially. Therefore the universal robustness threshold 1/(2 gamma) cannot be increased for this legal uncertainty interface. The downstream sharpness is unconditional algebra; only the universal upper bound imports OA325.
Same K does NOT substitute for same A. Let A_1=2J,A_2=2J*, both nilpotent with the same unit-disk numerical range, and choose scalar F(z)=z, |F(z)|<=1 on K. Then
 ||(F(A_2)F(A_1))^k||=4^k.
Thus one common metric / one-factor composition fails completely under arbitrary topology switching. Separate metrics can require exponentially growing changes between times. The applications-attack worker also supplies a continuous-time rational version with each individual generator Hurwitz and strictly dissipative scalar fibre.

6. COSTS AND COMPARATOR
Acquisition is explicit: A is supplied (reading arbitrary dense A costs N^2 entries; sparse input nnz(A)). K enclosure may be supplied. If K={Re(conj(nu_j)z)<=b_j}, rational/algebraic directions nu_j, its validity follows from m Hermitian inequalities Re(conj(nu_j)A)<=b_j I, checked by exact PSD certificates/LDL; roughly O(m N^3) arithmetic in a generic dense method, with bit cost and coefficient heights charged separately. Local storage certificate verification uses Hm matrices of order q+p, roughly O(Hm(q+p)^3) arithmetic plus coefficient reading; acquiring them is not covered by the theorem and may fail. Rational exact certification requires rational gamma^2/P_t or verified rounding margins. Continuous-time or frequency grids without certificates are not proofs.
Execution still evolves Nq states and applies A: per step roughly O(nnz(A)q+N q^2+Nqp), not size-independent simulation. No S construction is needed.
An equally informed comparator can calculate actual ||T_H[A]|| / actual full-network H-infinity norm or solve a full network storage problem, often producing tighter bounds at larger dimension/cost. The theorem does not defeat that comparator universally.
Old complete Crouzeix-Palencia theorem gives the identical proof with c_old=1+sqrt(2). Thus the release changes gamma -> 2gamma versus (1+sqrt(2))gamma, and universal admissible uncertainty radius from (sqrt(2)-1)/gamma to 1/(2gamma): a 20.7107% increase.

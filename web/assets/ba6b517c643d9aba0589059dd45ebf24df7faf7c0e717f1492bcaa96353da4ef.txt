INTERFACE AND RANK AFTER BRANCH COMPOSITION

The audited claim concerns one unknown pure projector P_x on H and
reconstruction of that same full density on H. The encoder is an instrument
with classical outcome y and conditional quantum branch K_y, dim K_y<=Q;
the decoder uses y and K_y, and may regenerate local ancillas. No reference,
entanglement assistance, or unknown quantum side input is present. Q is a
finite integer >=1. The worst-case error is epsilon=sup_x
||Phi(P_x)-P_x||_1/2. The classical alphabet and number of Kraus operators
are unrestricted for the converse.

For a discrete instrument, write encoder Kraus maps E_(y,i):H->K_y and
decoder Kraus maps D_(y,j):K_y->H. The composite channel Kraus maps are

  A_(y,i,j)=D_(y,j) E_(y,i),       rank(A_(y,i,j))<=dim K_y<=Q,
  sum_(y,i,j) A_(y,i,j)^dagger A_(y,i,j)=I.

The second identity follows by first summing the decoder Kraus effects to
I_(K_y), then using trace preservation of the full encoder instrument.
Postselection probabilities, conditional operations, variable branch
dimensions, decoder ancillas, and factor mixing are all absorbed in these
compositions; none can increase their rank above Q. Refining or coarsening
the classical label changes the indexing but not this factorization.

For a measurable outcome space the corresponding statement is an integral
of such rank-<=Q composites, with the TP equality holding after integration.
The proof needs one common Kraus family (or measurable Kraus field) for all
x, supplied by the fixed physical channel, not a separately chosen Kraus
decomposition for each input. The file expressly allows Kraus integrals for
measurable alphabets. If “arbitrary alphabet” were meant to include
nonmeasurable outcomes without an instrument measure, the channel interface
would need formalization; no such nonmeasurable physical instrument is
specified. This is a representation/measure-theory clarification, not a
counterexample under the stated measurable-instrument reading.

The rank claim is one-way and sufficient: a legal code gives a TP Kraus
family of rank<=Q. The converse does not need to assert that every such
Kraus family has a cheaper or uniquely identified implementation. No
classical-label count is charged in this lower bound, consistent with the
unrestricted alphabet in §1. In §4 the Kraus index is only an auxiliary
mixture index for a witness T; it need not be retained as a physical label.

TRACE ERROR AND THE INPUT OFF-DIAGONAL IDENTITY

Fix the common channel Kraus family. For each unit x decompose
  A_a x=lambda_(a,x) x+r_(a,x),   <x,r_(a,x)>=0,
and set f_x=sum_a||r_(a,x)||^2 and
u_x=sum_a conjugate(lambda_(a,x)) r_(a,x).
TP gives ||lambda_x||_2^2=1-f_x. Also the target-projector measurement
gives f_x=1-Tr(P_x Phi(P_x))<=epsilon. The off-diagonal output block is
exactly
  (I-P_x)Phi(P_x)x=u_x.
For u_x!=0 the Hermitian operator
  H_x=|u_x/||u_x||><x|+|x><u_x/||u_x||| 
has operator norm one and Tr(H_x(Phi(P_x)-P_x))=2||u_x||. Trace duality
therefore yields ||u_x||<=||Phi(P_x)-P_x||_1/2<=epsilon. This uses the
aggregate Kraus sum, so cancellations are preserved; replacing it by a
sum of individual absolute values would be invalid.

For an adjacent pair x,y, write s=<x,y>, b=|s|>0 and
d=||lambda_x-lambda_y||_2. The input-side TP identity is

  s=sum_a <A_a x,A_a y>.

Expanding both vectors, and adding/subtracting lambda_y in the first cross
term and lambda_x in the second, gives aligned terms <x,u_y> and
<u_x,y>, each <=epsilon; coefficient-difference terms bounded by
d sqrt(f_y) and d sqrt(f_x); and a residual term <=sqrt(f_x f_y).
Thus

  b |1-<lambda_x,lambda_y>|<=3 epsilon+2 sqrt(epsilon) d.

The normalization identity
  Re(1-<lambda_x,lambda_y>)=(f_x+f_y+d^2)/2>=d^2/2
then gives b(d/sqrt(epsilon))^2<=6+4(d/sqrt(epsilon)) for epsilon>0.
Its positive root is (2+sqrt(4+6b))/b<=6/b because 0<b<=1. At
epsilon=0 the undivided inequality implies d=0 directly. Hence
d<=6sqrt(epsilon)/b, with the source's constant valid.

Summing along a finite nonzero-overlap path and taking the infimum yields
||lambda_x-lambda_x0||_2<=6 kappa sqrt(epsilon). This does not select a
path for the code: the path is only a uniform analytical premise. It needs
the fixed global Kraus family and a finite uniform weighted path-length
bound as stated in (1.1); without overlap connectivity, §8's orthogonal
family is an actual obstruction.

CONVEX KRAUS-RANGE OPERATOR

Let P_a project onto Ran(A_a). Since rank(A_a)<=Q, Ran(A_a) is finite
dimensional and closed even when H is infinite dimensional. Set
W=sum_a|lambda_(a,x0)|^2=1-f_x0. If epsilon<=1/2 then W>=1/2. With
B_a=A_a-lambda_(a,x0)I, orthogonality of r_(a,x) to x gives the sharper
identity
  sum_a||B_a x||^2=f_x+||lambda_x-lambda_x0||_2^2,
which implies the source's looser bound
  sum_a||B_a x||^2<=2 f_x+2||lambda_x-lambda_x0||_2^2
                     <=74 kappa^2 epsilon.
Because (I-P_a)A_a=0,
  |lambda_(a,x0)|^2 ||(I-P_a)x||^2<=||B_a x||^2.
Therefore
  T=sum_a (|lambda_(a,x0)|^2/W) P_a
is a fixed positive contraction, with Tr(T)<=sum_a p_a Q=Q. It is fixed
from the anchor coefficients, not from the unknown x or that input's
outcome distribution. Summing the range inequality gives

  1-Tr(TP_x)<=74 kappa^2 epsilon/W<=148 kappa^2 epsilon.

Thus T is feasible in the convex width and omega_Q(X)<=148 kappa^2
epsilon. For a Kraus integral, the same expressions are integrals; the
positive weighted projections have total trace at most Q, so T is trace
class and the integral converges in trace norm. Measurability of the
finite-rank range projections is implicit in a measurable finite-rank
Kraus field; it can be obtained from the measurable support projection of
A_a A_a^dagger. This is the only minor technical regularity needed for the
integral version.

For epsilon>1/2, omega_Q<=1 and kappa>=1 imply
omega_Q/(148 kappa^2)<=1/148<1/2<epsilon. Taking the infimum over codes
therefore gives the lower bound for all errors, including nonattained
infima. The convex mixture does not assume a single deterministic
Q-subspace works for all x; it is exactly the feasible convex operator
allowed in (1.2). The argument's constants and resource use are consistent:
the branch dimension Q is the only bounded quantum resource here, while
the converse permits unlimited classical labels.

FINITE/INFINITE-DIMENSION STATUS AND LIMITS

No numerical solver is needed for §§2–4; the inequalities above are exact.
The trace-class conclusion uses Q<infinity and positive weights summing to
one. For separable H, each composite Kraus range has rank<=Q and is closed;
the trace bound controls the infinite sum/integral. The theorem separately
requires trace-norm compact X for its width-dual/upper arguments, but this
compactness is not used in the channel inequalities except when passing to
the full theorem's variational conclusions. I did not audit that dual,
upper finite-label construction, local chart, or any mixed-state transfer.

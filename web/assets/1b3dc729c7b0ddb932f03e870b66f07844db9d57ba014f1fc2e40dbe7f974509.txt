STRONGEST DEFENSIBLE RESEARCH LINE

The main advance is a common classical-reconstruction principle for
approximately broadcastable quantum states, now with an effective rational
core, a strictly broader information hypothesis and a stronger fixed-map
tracial bound. The proofs use ONE channel for the entire stated domain;
state-specific measurements are not substituted for that quantifier.
All logarithms below are natural; T is half trace distance.

A. General information-controlled classicality. For a normal state family
E on a separable Hilbert space define
 R=inf_(sigma in trace-closed convex hull E) sup_(rho in E)
       sup_(0<=F<=I) p ln(p/q), p=Tr(F rho), q=Tr(F sigma).
Let b be the infimum worst marginal error of one normal two-output
broadcaster. If R is finite, one normal EB map has worst error
 e <= min(1,400 sqrt((R+1)/ln(1/b)) for 0<b<1,
and exact zero error when b=0. The prior finite-Holevo-capacity C theorem
has the analogous400sqrt((C+1)/ln(1/b)) bound, also extended to separable
normal families. R<=C+ln2, but R<=C is false in general. Two exact examples
show bounded R with divergent maximum-prior C. Center-in-hull is essential.
Finite-output approximants give arbitrary slack; exact broad normal EB
attainment follows from a separate weak-star trace-loss optimizer theorem.

B. One fixed map, pointwise tracial rate. For any actual joint CPTP B on
M_d, set sigma=I/d, Phi=(B1+B2)/2 and
 b_rho=max(T(Phi rho,rho),T(Phi sigma,sigma)).
ONE EB Psi chosen from B and sigma BEFORE rho satisfies for EVERY rho
 T(Psi rho,rho)<=min(1,500[D(rho||sigma)+1]/ln(1/b_rho)).
At b_rho0 the same map fixes rho exactly; at b_rho=1 use 1. The reference
residual is explicitly charged. A family with tracial Holevo center thus
gets e<=min(1,500(C+1)/ln(1/b)). This is not an arbitrary nontracial rate.

C. Certified classical compilation. Supply an exact rational-complex Choi
matrix for a valid broadcaster with common bistochastic HS-selfadjoint
marginal Phi and rational delta>0. A classical Las Vegas algorithm returns
ONE rational pure canonical EB Psi with
 I-Psi <=4(I-Phi)+delta I
on the FULL Hermitian space, at most ceil(64d²/delta²)+d outcomes and expected
polynomial bit cost in d,1/delta and full input bitlength. Every return has
an exact PSD certificate; uniform fallback success is at least1/2 per batch.
The mechanism is a fixed rational informationally complete leaf measurement,
finite correlated-tree covariance, retained Kraus labels, exact conditional
classical sampling, and positive residual completion of empirical moments.
The input is dense d^6 data. The algorithm makes zero physical quantum calls.
It is polynomial in d, not log d. It has been proved and exercised on exact
small controls; a generic compiler or practical benchmark is NOT implemented.
Finite gate execution stays EB and approximates the ideal canonical map.
There is no acquired black-box broadcaster, exact delta0 compiler, or proved
end-to-end efficient compiler for arbitrary bounded-capacity experiments.

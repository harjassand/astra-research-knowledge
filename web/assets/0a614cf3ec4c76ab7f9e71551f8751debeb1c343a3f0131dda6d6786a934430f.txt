COMPLETE CONDITIONAL RESULT
Given ONE canonical pure-state EB comparator with
  I-Psi <= C(I-symPhi)
as an HS quadratic-form inequality, every density matrix satisfies
  ||rho-Psi(rho)||_1 <= 2D(rho||I/d)/log t
                           +sqrt(Ct ||rho-Phi(rho)||_1 /2), t>1.
The comparator is fixed before rho, t, or an ensemble is supplied.
Thus the supplied C4 self-adjoint and C8 arbitrary bistochastic
self-compatible comparator premises BOTH yield the entropy consequence.
The universal comparator theorem is supplied; it is not re-audited here.

2/3 for Phi*, 3/4 for symPhi. This is a failed proof step, not a
counterexample to the repaired result.

fg=tg and tau[f(I-Phi)g]=tau[(tI-f)Phi(g)]>=0, using positive TP.
Therefore E_symPhi(f)=E_Phi(f)<=tau[f(I-Phi)X]<=t epsilon/2.
3. Directly comparing f+g with Psi(f+g) costs 2q, not 4q.
4. The centered entropy integrand h(x)=x log x-x+1 bounds
log(t)(x-t)_+, giving q<=D/log t, with no 1/e term.

UNIFORM AND ENSEMBLE CONSEQUENCES
For 0<epsilon<1, t=epsilon^(-1/2) gives
  ||rho-Psi(rho)||_1 <= 4D/log(1/epsilon)
                           +sqrt(C/2) epsilon^(1/4).
This goes to zero uniformly over dimensions if D is bounded.
Zero error implies rho=Psi(rho) exactly. A tracial-barycenter ensemble
with average error barepsilon and Holevo information chi obeys the
same bounds with D=chi and epsilon=barepsilon, using Jensen and the
SAME Psi. With a nontracial barycenter the mean tracial relative entropy
is chi+D(bar rho||I/d), so chi alone does not give this consequence.
No general nontracial-reference theorem is claimed.

# From finite-range to arbitrary-range extensions into real L1

**Evidence status:** internally reconstructed conditional theorem. The proof below uses the cycle-1 finite-range claim MR-2 as a premise; that claim remains an internally reconstructed candidate based on the pinned release and Mendel–Naor. The Komlós subsequence theorem is source-reported from its primary paper. No independent proof audit was obtained.

## The finite-to-infinite bridge

Let (X) be a separable metric space, let (S\subseteq X) be nonempty, and let (Y=L_1(\Omega,\mu;\mathbb R)). Suppose (f:S\to Y) is (L)-Lipschitz. Assume the following finite-data property with a fixed constant (K<\infty): for every finite (A\subseteq S), there is a global map (F_A:X\to Y) such that

\[
F_A|_A=f|_A,\qquad \operatorname{Lip}(F_A)\leq KL,
\]

and, for some fixed sigma-finite measurable subset \(\Omega_0\subseteq\Omega\), every value of every selected \(F_A\) is supported in \(\Omega_0\). It is enough that this support condition hold for one chosen extension for each finite (A).

Then (f) has a global extension (F:X\to Y) with

\[
F|_S=f,\qquad \operatorname{Lip}(F)\leq KL.
\]

There is **no additional Lipschitz loss** in passing from finite to arbitrary range.

### Proof

Choose a countable dense set (S_0=\{s_1,s_2,\ldots\}\) in (S), and a countable dense set (D=\{x_1,x_2,\ldots\}\) in (X) with (S_0\subseteq D). (If either set is finite, use its finite enumeration.) For each (n\), apply the assumed finite-data property to (A_n=\{s_1,\ldots,s_n\}\), obtaining (F_n:X\to Y). Fix (s_1\in S_0). For each (x_j\in D\),

\[
\|F_n(x_j)\|_{L_1(\mu)}\leq \|f(s_1)\|_{L_1(\mu)}+KL\,d_X(x_j,s_1)=:B_j,
\]

uniformly in (n\), because all (F_n\) extend (f(s_1)\) and are (KL\)-Lipschitz.

The target measure need not be finite. On \(\Omega_0\), choose a finite measure \(\nu\) equivalent to \(\mu\): partition \(\Omega_0\) into measurable sets \(E_m\) of finite \(\mu\)-measure and set

\[
\frac{d\nu}{d\mu}\bigg|_{E_m}=\frac{2^{-m}}{1+\mu(E_m)}.
\]

Then \(\nu(\Omega_0)\leq1\), \(\nu\) and \(\mu\) have the same null sets on \(\Omega_0\), and \(d\nu/d\mu\leq1\).

Set \(\alpha_j=2^{-j}/(1+B_j)\). On the disjoint union \(\mathbb N\times\Omega_0\), put the finite measure

\[
\lambda(\{j\}\times E)=\alpha_j\nu(E),
\]

and define \(H_n(j,\omega)=F_n(x_j)(\omega)\). Since

\[
\|H_n\|_{L_1(\lambda)}=\sum_j\alpha_j\|F_n(x_j)\|_{L_1(\nu)}
\leq\sum_j\alpha_jB_j\leq\sum_j2^{-j},
\]

\((H_n)\) is a bounded sequence in \(L_1(\lambda)\). Komlós' theorem supplies a subsequence \((H_{n_k})\) whose Cesàro averages converge \(\lambda\)-almost everywhere to some \(H\in L_1(\lambda)\). Because every \(\alpha_j>0\) and \(\nu\sim\mu\) on \(\Omega_0\), the averages

\[
\overline F_N(x_j)=\frac1N\sum_{k=1}^N F_{n_k}(x_j)
\]

converge \(\mu\)-almost everywhere, for every \(j\), to a measurable function \(g_j\) on \(\Omega_0\). All values vanish outside \(\Omega_0\). Fatou's lemma applied with the original measure \(\mu\) shows \(g_j\in L_1(\mu)\).

For any \(j,\ell\), each average map \(\overline F_N\) is still \(KL\)-Lipschitz, by convexity of the norm. The two pointwise limits exist simultaneously outside a null set, so another application of Fatou gives

\[
\|g_j-g_\ell\|_{L_1(\mu)}
\leq\liminf_{N\to\infty}\|\overline F_N(x_j)-\overline F_N(x_\ell)\|_{L_1(\mu)}
\leq KL\,d_X(x_j,x_\ell).
\]

For fixed \(s_i\), every term \(F_{n_k}(s_i)\) with \(n_k\geq i\) equals \(f(s_i)\). Only finitely many terms in the Cesàro averages can differ, so \(\overline F_N(s_i)\to f(s_i)\) almost everywhere (and in L1). Thus \(g_i=f(s_i)\).

The assignment \(x_j\mapsto g_j\) is (KL)-Lipschitz on the dense set \(D\). Completeness of (L_1(\mu)\) gives a unique (KL)-Lipschitz extension (F\) to all of (X\). It agrees with (f\) on (S_0\). Since (S_0\) is dense in (S\) and both (f\) and (F|_S\) are continuous, it agrees with (f\) on every (s\in S\). \(\square\)

## Application to the finite-cut result

The cycle-1 claim MR-2 supplies the finite-data property with

\[
K=C_{MN}\,12\sqrt{21}\,M_2(X),
\]

where (C_{MN}\) is the unspecified universal factor in Mendel–Naor's dual-target extension corollary. For each prefix (A_n\), its range has (r_n\leq n\) distinct values. The cut code has dimension \(d_n\leq2^{r_n}-2\), and its affine recovery map has the form

\[
T_n(u)=v_n+\sum_{B}u_B b_{n,B}.
\]

Here (v_n\) and every (b_{n,B}\) are formed pointwise from the finitely many functions \(f(s_1),\ldots,f(s_n)\). If

\[
\Omega_0=\bigcup_{i\geq1}\{\omega:f(s_i)(\omega)\ne0\},
\]

then \(\Omega_0\) is sigma-finite: for each integrable (h\), \(\{h\ne0\}=\bigcup_{m\geq1}\{|h|\geq1/m\}\), and every set in this union has finite measure. The recovery functions vanish outside \(\Omega_0\). The selected finite-range extensions are (F_n=T_n\circ P_n\circ G_n), so their values also vanish outside \(\Omega_0\), regardless of the (possibly infinite-coordinate) ℓ1-valued extension (G_n\).

Consequently, conditional on MR-2, every Lipschitz map from an arbitrary subset of a **separable** Markov-type-2 source (X\) into any real (L_1(\Omega,\mu)\), including maps with genuinely infinite range, extends globally with

\[
\operatorname{Lip}(F)\leq C_{MN}\,12\sqrt{21}\,M_2(X)\,\operatorname{Lip}(f).
\]

In particular, this yields the same form of bound for a separable Hilbert source and a nonatomic (L_1) target, conditional on the finite-range claim.

## What this does not prove

The argument uses one sequence and one Komlós subsequence for a **countable dense subset** of the source. For a nonseparable source there need not be a countable dense set on which to diagonalize. Applying Komlós separately at uncountably many points does not produce a single subsequence compatible with all pairwise Lipschitz inequalities. The argument therefore does not establish the same statement for arbitrary nonseparable Markov-type-2 sources.

This is not a counterexample to the nonseparable extension claim; its truth remains `UNKNOWN` in this audit. It is the precise point at which the sequential compactness substitute stops applying.

## Why the standard compactness proof stops at L1

Mendel–Naor's finite extension theorem gives finite partial extensions. Their global reflexive-target corollary takes a net of such maps and uses weak compactness of each bounded target ball in the product topology. The dual-target corollary uses weak* compactness. The unit ball of (L_1[0,1]) is not weakly compact. A concrete witness to the failure of sequential weak compactness is

\[
h_n=n\,\mathbf 1_{[0,1/n]}.
\]

Each \(\|h_n\|_1=1\). For every continuous \(\varphi\), \(\int_0^1\varphi h_n\to\varphi(0)\), which is point evaluation (Dirac mass at zero), not integration against an (L_1) function. Hence no subsequence can converge weakly in (L_1[0,1]). This blocks the direct bounded-net compactness argument, but it does not block the separable-source Komlós/Cesàro construction above.

## Evidence boundary

- The pinned OpenAI release, family 332, and cycle-1 MR-2 are inputs to this derivation; neither is externally proof-validated here.
- Komlós' 1967 Theorem 1a states that from an (L_1)-bounded sequence one can select a subsequence such that averages of every further subsequence converge almost everywhere to an integrable function.
- Lee–Naor (2005, §1.4) recorded the Ball (L_2\to L_1) global extension question as open. Naor (2024, Question 25) later stated the analogous ℓ2-to-ℓ1 target question. The pinned 2026 paper explicitly resolves the **sequence-space ℓ1** target. These sources establish the historical context and a notation boundary; they do not preempt the present conditional separable-source theorem for ambient (L_1(\Omega,\mu)).
- The literature check was targeted, not exhaustive. Novelty and priority remain `UNKNOWN`.

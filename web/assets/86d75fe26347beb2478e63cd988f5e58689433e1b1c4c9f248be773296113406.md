# Source and prior-art ledger

## Primary signing source

Xiaoyu Li, *Fast Spectral Signing for Vector Balancing*, arXiv:2609.30044v1, 24 September 2026.

- Abstract and Theorem 1.1: deterministic signing for a matrix with Euclidean column norms at most one, infinity discrepancy `<99`.
- Theorem 1.1 also reports `O(t^2 log t)` updates and `O(d t+t^(omega+2) log^3 t)` arithmetic/comparisons for a `d x t` matrix, plus polynomial bit complexity for rational input.
- Section 11.3 explains the rational implementation and persistent polynomial bit lengths; it is the premise used for the composition's polynomial-bit claim.
- Primary URLs: [arXiv abstract](https://arxiv.org/abs/2609.30044), [versioned HTML](https://arxiv.org/html/2609.30044v1).
- Read status: source-reported. This task did not independently validate the manuscript proof or reproduce the signer.

## Distinction maintained

The new compiler uses simple cycles in the current positive/odd-numerator support graph as degree-preserving circulations. It never equates them with actual edges of the matching polytope or with `k(P)`. Its computed bound uses only the input feature matrix and the maximum possible simple-cycle length, not the maximum actual cycle norm. The P-round record uses actual polytope-edge support and a strong-optimization interface; the two geometric parameters are kept separate here.

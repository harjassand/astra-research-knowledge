ADDENDUM — SHARPER COORDINATE-BASE CONTAMINANT BOUND
7 October 2026

The global Hadamard/2^M estimate in the immutable INITIAL is valid but loose
for the actual parity representation V=[I,F^T]. A basis contains exactly
r/2 lines, and each original line is (e_i,f_i): one unit column and one row
vector f_i. Every coordinate line is also two unit columns.

Let M0=binom(r,2) be the number of complete-graph coordinate lines and let
the original line i have activity epsilon*lambda_i, with positive rational
lambda_i. Put h_i=||f_i||_2^2=sum_j |F_ij|^2 and a_i=lambda_i h_i. For a set of
s selected original lines I, Hadamard gives

  |det W_A|^2 <= product_(i in I) h_i,

because all remaining columns are unit coordinate vectors. There are at most
binom(M0,r/2-s) choices of coordinate lines. Summing over I gives the exact
computable rational upper bound

  C <= sum_(s=1)^(r/2) epsilon^s binom(M0,r/2-s) e_s(a_1,...,a_N),

where e_s is the elementary symmetric polynomial. Define

  S_F=sum_(s=1)^(r/2) binom(M0,r/2-s) e_s(a_1,...,a_N).

For epsilon<=1, epsilon^s<=epsilon, so C<=epsilon*S_F. The coordinate-only
partition is Z0=(r-1)!!, giving refresh TV at most C/Z0. Thus it suffices to
choose dyadic epsilon=2^-K with

  2^-K S_F <= eta (r-1)!!.

The S_F coefficients can be computed in O(Nr+r^2) rational arithmetic using
the recurrence for product_i(1+a_i x), followed by convolution with
(1+x)^M0. Their bit lengths are polynomial in the input length: each a_i is
an exact sum of squared rational components, products use at most N factors,
and summing O(Nr) terms adds only polynomially many bits. K can be found by
integer comparisons, with K=O(bitlen(S_F)+bitlen(1/eta)); no logarithm or
floating bound is required.

For M0=Theta(r^2) and N=O(r), a coarse estimate
S_F <= binom(M0+N,r/2) max(1,max_i a_i)^(r/2)
shows log2 S_F=O(r log r+r*ell), where ell bounds the matrix/activity input
bits. This improves the previous O(M+r*ell) exponent from the 2^M/global
Hadamard estimate to O(r log r+r*ell) in the intended representation.
The improvement is in the refresh precision parameter; both bounds were
already polynomial-bit.

Executable check: `refined_refresh_check.py` enumerates every 2-line set for
an exact r=4 rational-activity fixture, computes the determinants exactly,
and verifies C(epsilon=1)<=S_F and C(2^-13)<=eta*(r-1)!!. It reports actual
contaminant 573637/134217728, upper bound 621/8192, and coordinate partition
3 for eta=1/32. This is a finite check only; the displayed Hadamard argument
proves the general bound.

Boundary: this refinement uses the special (e_i,f_i) structure. For
arbitrary vector-pair lines with neither vector a unit coordinate vector,
replace h_i by ||v_i||^2||w_i||^2; the simpler global column-norm bound in
INITIAL remains valid for that generality.

# Geometry and optimization: an acquired centering and seed compiler

Status: two unconditional mathematical adapters reconstructed; one conditional, consequential sampling consequence. No complete family-139 sampler has been implemented or certified, and no new externally validated breakthrough is claimed.

The strongest opportunity is to turn release family 139's subpolynomial-query sampler into a sampler whose inter-query work and minimizer acquisition are explicitly charged. Its runtime uses scalar affine vector operations, gradients, and rank-one transformations of Gaussian seed slots. This differs from the prior Astra exact-mean rounding programme.

The candidate consequence is: for each fixed positive exponent epsilon, a well-conditioned C2 Gibbs law could be sampled at fixed accuracy with nearly linear arithmetic overhead, plus the cost of subpolynomially many acquired gradient evaluations, without a supplied exact minimizer. A finite-bit version must approximate the rounded Gibbs law; finite outputs have total-variation distance one from a continuous density.

## 2. Legal sampling interface and the acquisition problem

The release's main input is a first-order oracle for a potential V satisfying

    V in C2(R^d),  V(0)=0,  grad V(0)=0,
    I <= Hess V(x) <= 2I for every x.

The target is pi(dx)=Z^-1 exp(-V(x))dx. All-query execution budgets are fixed, random real variables are allowed, and computation between queries is unrestricted. For every fixed eta>0 the manuscript claims Q_eta(d)<=C_eta d^eta queries and TV error at most 1/10.

The supplied exact minimizer, exact gradient values, uniform Hessian promise, and unrestricted arithmetic are substantial parts of this interface. They are not measurements or representations acquired by the query theorem. The following adapters address the first and fourth items. Finite-bit gradient evaluation and source accuracy remain separate charges.

### 2.1 Unconditional centering by a small residual tilt

Suppose only that V is C2 and I<=Hess V<=2I, with an arbitrary starting point x0. Acquire m satisfying

    |grad V(m)| <= r.

Put h=grad V(m), and define

    W(z)=V(m+z)-V(m)-h dot z.

Then W has the same Hessian bounds, W(0)=0, and grad W(0)=0. Thus its exact minimizer is known by construction. A sample Z from exp(-W) translated to X=m+Z has law

    Q_h(dx) = exp(h dot x-K(h)) pi(dx),
    K(h)=log E_pi exp(h dot X).

The resulting tilt error satisfies

    KL(pi || Q_h) <= |h|^2/2,
    TV(pi,Q_h) <= |h|/2 <= r/2.

Proof: every tilted law Q_th has Hessian of its negative log density at least I. The Poincare inequality therefore gives Cov(Q_th)<=I. Since Hess K(th)=Cov(Q_th),

    K(h)-K(0)-grad K(0) dot h
      = integral_0^1 (1-t) h^T Cov(Q_th) h dt
      <= |h|^2/2.

The expression on the left is KL(pi||Q_h); Pinsker gives the TV assertion. Gaussian tails from strong convexity justify the cumulant differentiation.

No log-concave sampler or family-139 result is needed for this lemma.

### 2.2 Acquiring m, rather than assuming it is supplied

Use m_(k+1)=m_k-grad V(m_k)/2. If m_* is the unique minimizer, the integral Hessian between m_k and m_* has spectrum in [1,2]. Therefore

    |m_(k+1)-m_*| <= |m_k-m_*|/2,
    |m_0-m_*| <= |grad V(m_0)|,
    |grad V(m_k)| <= 2^(1-k)|grad V(m_0)|.

If B>=|grad V(x0)| is acquired, k=ceil(log2(max{1,4B/r})) suffices with slack. The cost is O(log(2+B/r)) gradient evaluations plus vector updates. This does not treat optimization as free.

This is compatible with approximate gradient access. If each gradient error has Euclidean norm at most r/16 and each update rounding error at most r/32, the distance recurrence is

    e_(k+1) <= e_k/2 + r/16.

After the displayed number of iterations, the residual gradient is at most 3r/4. Coordinatewise gradient precision r/(16 sqrt(d)) suffices. One can also certify the stopping condition by an interval bound on the final gradient norm.

The exact mathematical oracle for W is grad V(m+z)-grad V(m). A finite-precision implementation evaluates both gradients to its requested precision. It does not freeze a rounded value of grad V(m) and silently assert that the new minimizer is exact. The same source evaluation at m can be cached at successively refined precisions, with those bits retained and charged.

## 3. Unconditional Gaussian noise absorption with linear vector work

A seeded oracle routine Q(x;G_1,...,G_m) is required to satisfy a pathwise translation identity

    Q(x+Delta; G+v tensor Delta/r) = Q(x;G),

including equality of every physical gradient query point. This is much stronger than translation of an expectation. All seed slots are d-vectors; v is an acquired deterministic scalar vector with |v|<=D_s.

Set

    n=r/(2D_s),
    c=|v|^2/(4D_s^2) <= 1/4,
    s=sqrt(1-c),
    alpha=1/[4D_s^2(1+s)],
    P=I-alpha vv^T.

Then P is exactly the positive square root of I-vv^T/(4D_s^2). If Z and G are independent standard Gaussian arrays, the routine

    Q(x+nZ; (P tensor I_d)G)

has exactly the law of Q(x;G). To prove this, translate back to x. The resulting seed array is

    PG - (v tensor Z)/(2D_s).

Its covariance in slot space is P^2+vv^T/(4D_s^2)=I, so its slots are independent standard Gaussian vectors. Correlation of the rewritten slots with Z does not matter because the rewritten center is deterministic.

### 3.1 No matrix square-root computation is necessary

The implementation requires only

    shared = sum_j v_j G_j,
    (PG)_j = G_j-alpha v_j shared.

Computing shared and distributing its rank-one correction costs O(md) arithmetic and O(md) retained reals for the full array. It does not require storing an m-by-m matrix or any high-order d-dimensional derivative tensor.

The inverse needed by the recursive translation compiler is especially simple:

    P^-1 v = v/s.

Also s>=sqrt(3)/2, so this inversion has an absolute conditioning bound. The rationalized expression for alpha avoids subtracting two nearly equal numbers.

This adapter is actually implemented in adapter_checks.py. It accepts arbitrary certified scalar shift vectors and seed arrays. Its scope is one runtime primitive, not the complete sampling construction.

### 3.2 Sharp boundaries of the adapter

Fresh unmodified seeds at the noisy center add covariance rather than restoring it. At m=4, v=(-1,-1,-1,-1), D_s=13/5, the center variance is n^2=25/676. Omitting P adds exactly 25/676 to every slot covariance entry.

Variance matching is also insufficient when the center displacement is not Gaussian. A centered Rademacher displacement of the same variance leaves fourth cumulant -2n^4=-625/228488 in a physical query coordinate after covariance correction. Hence its law is not the original Gaussian query law. Arbitrary errors in an estimated center cannot be absorbed by this identity.

## 4. Independently reconstructed analytic gate: all-split cumulants

A nontrivial split views an order-n tensor as a matrix between two Euclidean tensor spaces. The coefficient vectors on each side may themselves be arbitrary tensors. Rank-one test directions would not be sufficient.

Assume S has an MGF near zero and satisfies

    Var(P(S)) <= beta E|grad P(S)|^2

for every ambient polynomial. Define Appell tensors through

    P_j(s) = derivative_theta^j [exp(theta dot s)/E exp(theta dot S)] at 0.

For Q_T(s)=T:P_j(s), every expected derivative below order j is zero and

    derivative^j Q_T = j! Sym(T).

Repeated Poincare applied componentwise therefore proves

    E|T:P_j(S)|^2 <= beta^j (j!)^2 |T|_F^2.

Cauchy-Schwarz gives a dimension-independent operator bound for each cross-moment tensor E[P_j(S) tensor P_k(S)] across the j|k split.

Now use the mixed generating function

    G(theta,omega)
      = M(theta+omega)/(M(theta)M(omega)).

Every nonzero coefficient of G-1 uses variables from both groups. Mixed derivatives of log G recover the desired cumulants. Expanding log(1+(G-1)), each contributing differentiated product is a tensor product of the cross-moment operators. Slot permutations within either side preserve operator norm. There are at most n^(n+1) assignments of n labeled derivative slots to ordered nonempty factors, and the product of their factorials is at most n!.

Consequently one explicit conservative bound is

    |kappa_n(S)|_split <= n^(3n) beta^(n/2),  n>=2.

This independently gates the release's dimension-free all-split cumulant lemma. It requires the full ambient Poincare interface, not merely covariance control or one-dimensional tail bounds.

For family 139's Gaussian conditional law,

    a=1-rho^2,
    density(Z|Y=y) proportional to
      exp(-|z-rho y|^2/(2a)-F(x+rz)),
    f(z)=grad F(x+rz),   Lip(f)<=L,
    l=lambda r^2<=1/2.

The conditional Poincare constant is at most a/(1-al)<=2a. The pushforward S=(Z,f(Z)/L) has derivative norm at most sqrt(2), so its ambient-polynomial Poincare constant is at most 4a. This step uses only first derivatives of f; repeated applications differentiate ambient polynomials, not higher derivatives of f.

Differentiation of a conditional mean along the linear tilt gives

    rho^-q derivative_y^q M_rho
      = a^-q cumulant(f(Z),Z,...,Z | Y=y).

Restricting the cumulant of S to one f/L slot yields the explicit bound

    |rho^-q derivative_y^q M_rho|_split
      <= 2^(q+1) (q+1)^(3(q+1)) L a^(-(q-1)/2).

The vector output slot is included in the split. This is a reusable, verified-within-interface smoothing lemma. It does not validate the subsequent Gaussian divergence estimates, stationary-centering flow, or nested approximation error propagation.

## 5. Structural total-cost theorem and the candidate sampling consequence

Consider a fixed-shape uncached routine tree with:

- Q Gaussian d-vector slots and terminal gradient queries;
- bounded routine height H, independent of d;
- scalar affine expressions between gradient queries;
- rank-one seed transformations of the preceding form;
- scalar parameters independent of oracle values and random events.

Once its scalar coefficient program has been acquired, its vector evaluation costs

    O(H dQ) + Q C_gradient(d)

real operations. Each slot belongs to at most H ancestor transformations. Every affine term occurrence owns a separate child/seed block, so term operations are charged to those slots rather than to an implicit tensor.

A conservative scalar-template construction and storage allowance is O(Q^2); collocation weights involve fixed-degree scalar polynomials, trigonometric functions, and scalar integrals. Thus the complete structural allowance is

    time <= T_template + O(H dQ + Q^2) + Q C_gradient(d),
    retained resources <= S_model + O(dQ+Q^2) + S_gradient.

This is a statement about a supplied/acquired finite program, not a claim that arbitrary measurable oracle algorithms can be compiled efficiently.

### 5.1 Applying this interface to source 139

The manuscript's runtime compiler claims:

- fixed Picard/dependency depth once the target exponent is fixed;
- an uncached expression/routine tree of uniformly bounded height;
- at most polylog(d) delta^-t seed slots and gradient leaves per primitive;
- delta=d^-e, t<1;
- O(delta^-1 log d) outer proximal calls, O(log d) descent calls;
- scalar parameters fixed before any oracle responses.

No runtime derivative tensor, exact conditional-mean oracle, or numerical PDE solve appears in the cited runtime sections. Those quantities are analytic comparison objects.

If the accuracy and counting claims hold, the total global count is

    Q= d^(e(1+t)+o(1)).

Choosing e sufficiently small for each fixed epsilon gives the conditional arithmetic bound

    T(d) <= T_input + T_mode
             + O_epsilon(d^(1+epsilon))
             + Q C_gradient(d).

The supplied-minimizer assumption is removed by Sections 2.1–2.2, with an additive r/2 TV cost. Retained model data remain S_model. This does not produce a small-memory representation of the potential.

Even a deliberately conservative polynomial-in-Q scalar construction allowance preserves an arbitrarily small extra dimension exponent after retuning e. Constants and approximation orders can be enormous as epsilon decreases. No useful hardware crossover is established.

### 5.2 Finite bits: a generic compiler gate, not a continuous-TV claim

A bounded-bit output distribution is discrete and cannot be TV-close to the continuous pi. The correct target is q_tau#pi, where q_tau rounds coordinates to a supplied dyadic grid of spacing tau.

A generic finite-program conversion is available under explicit acquired bounds:

    N = number of affine/gradient operations,
    D = dependence depth of the complete run,
    B = an upper bound on all absolute affine coefficient sums,
    s_out > 0 = standard deviation of an independent final Gaussian.

For a globally Lipschitz gradient oracle and truncated Gaussian inputs, elementary forward-error propagation bounds intermediate values and errors by powers of CB. Precision of the form

    b = O(D log(CB) + log N + log(1/s_out)
                  + log(1/error) + log input magnitude)

is sufficient to make the computed pre-Gaussian mean differ by at most error*s_out in Euclidean norm. The final Gaussian then converts mean error into TV error by the Gaussian shift inequality.

To output finite bits, approximate the last Gaussian and round it. Conditional on any mean, the probability of crossing a grid boundary under coordinate error zeta is at most

    C d zeta (1/tau+1/s_out)

plus the Gaussian truncation failure. This follows by summing Gaussian densities at equally spaced grid boundaries; the bound is uniform in the mean. Finite uniform bits and inverse-CDF approximation can achieve the required zeta with polynomial bit cost. Hence quantization does not assume a separation of output points from cell boundaries.

For source 139, the conservative complete-run depth is O_epsilon(d^e log d), its scalar coefficient sums are polynomial in d for fixed approximation orders, and s_out=sqrt(h) 2^(-J/2) is an inverse polynomial in d. With polynomial grid precision and moderate encoded input magnitudes, this yields

    b=O_epsilon(d^e polylog(d)).

Any fixed polynomial cost of b-bit scalar arithmetic can again be absorbed into an arbitrarily small dimension exponent by choosing e smaller.

This finite-bit compiler deduction is internally derived, conditional on explicit coefficient/depth bounds and an acquired requested-precision gradient oracle. A full instantiated implementation and an independent proof gate for all numerical scalar-generation bounds are still missing. It must not be reported as a certified nearly linear finite-bit sampler.

## 6. A real model class with charged acquisition

For nonzero rational/dyadic data rows a_i and labels y_i in {-1,1}, let

    S = sum_i |a_i|^2,
    V(x)=|x|^2/2 + (4/S) sum_i log(1+exp(-y_i a_i dot x)).

Its Hessian is

    I + (4/S) A^T D(x) A,  0<=D(x)<=I/4.

Since A^T A<=S I, the Hessian is between I and 2I. Acquiring S and this sufficient certificate costs a read of every nonzero input entry. The certificate does not require an uncharged spectral norm oracle.

Gradient evaluation costs O(nnz(A)+d) real arithmetic, plus scalar logistic evaluation and the requested bit precision. Every input entry and label is retained and charged. The regularization/data scale is explicit; this is a restricted, well-conditioned posterior class, not arbitrary Bayesian inference.

Starting from zero, the residual-centering optimization acquires m. The corrected W oracle uses the same data and current/refined evaluations of grad V(m). Conditional on the source sampler and the compiler gate, the running time is

    T_input + T_mode
      + d^(1+epsilon)
      + d^epsilon * C_gradient(A,d,b),

with fixed accuracy and a sufficiently small retuned epsilon in the last term. If nnz(A) is O(d polylog d), this is a candidate near-linear inference algorithm including gradient-vector work. If A is dense, its dense reading/evaluation cost remains. The single-sample and reusable-template costs should be reported separately.

The equal-information comparator receives the same data, strong-convexity promise, starting point, bit oracle, and preprocessing. Quadratic/product/separable targets already have direct samplers; the adapter tests below do not demonstrate an advantage on them.

## 8. Other opportunities and why they were not selected

### 8.1 Prefix balancing: a genuine hidden geometric interface, no acquired fast rounder

Family 097 gives one signing controlling every prescribed prefix by C sqrt(d), independent of sequence length. It explicitly allows dependence on the whole sequence and supplies no efficient or online rule.

I reconstructed the shifted-section operation. For ell=5/2, the next domain is

    T_e(K) = { y : length({s in (-ell,ell): y+s e in K}) > 2 }.

Equivalently, using open interiors,

    T_e(K) = interior[(K eroded by [-1,1]e)+[-3/2,3/2]e].

Indeed an open fiber has length above two exactly when it contains a closed length-two interval centered at a c with |c|<ell-1. Its two endpoints belong to K. Convexity then supplies every point between them. For any |q|<=1/4, one of q-1 or q+1 lies in that interval.

The source proves that this operation preserves every positive-diagonal Dirichlet-energy bound. Repeated backwards sections then select signs forwards. The first section transform has a convex projection description, but nesting creates a scenario tree of existential centers depending on preceding endpoint choices. A membership oracle for the initial K does not automatically give a polynomial-cost oracle for the final transformed body.

Fixed-dimensional grid/reachability algorithms or exhaustive search can acquire signs at much greater cost. That does not resolve growing-dimensional efficient prefix balancing. No new rounder or optimizer was claimed.

### 8.2 Linear-tilt subgaussian certificates: useful but lower-priority

For centered X with

    sup_|theta|=1 E exp((theta dot X)^2/a^2)<=2,

and tilt dP_h/dP proportional to exp(h dot X), Jensen gives its normalizer at least one. Cauchy-Schwarz and Young's inequality give

    E_h exp((theta dot X)^2/(2a^2))
       <= 2 exp(a^2 |h|^2/2).

Power interpolation yields an uncentered psi2 certificate

    b^2=2a^2+a^4 |h|^2/log 2.

Centering costs at most a factor four in the squared parameter, so one can certify every tilted centered marginal using

    b_centered^2 <= 8a^2+4a^4 |h|^2/log 2.

This is an unconditional elementary deduction. Conditional on family 093, it would produce an LSI certificate for bounded linear tilts. It does not give potential evaluation, discretization smoothness, preconditioning, or a sampling oracle.

The truncated exponential density proportional to exp(-R x) on [0,1] has centered psi2^2 of order 1/R, whereas the +R tilt is uniform with order-one scale. Thus reusing the original tail scale under arbitrary tilts is false; the polynomial tilt deterioration is necessary in order. Astra had already recorded this basic obstruction. The new certificate is not a practical sampling breakthrough, and 093's difficult analytic proof was not revalidated here.

## 9. Executed evidence, decisive falsification, and next gate

Executed adapter_checks.py, producing adapter_checks.json:

- 19 exact Fraction assertions validate one rational covariance-absorption instance and retain failures for uncorrected Gaussian seeds and a non-Gaussian center.
- The explicit multiquery translation routine preserves all query points to maximum floating error 2.22e-16; this is a finite pathwise diagnostic.
- Three legal one-dimensional nonquadratic targets V(x)=x^2/2+log cosh(x-3) check acquired centering and the proved residual-tilt TV/KL bounds. At requested residual 0.05 the actual residual was about 0.005441 and quadrature TV about 0.002040, below the analytic upper bound 0.002721. Gradient acquisition costs nine calls for that probe, counting the initial bound evaluation, seven updates, and final residual.
- Five resource probes vary slots/dimension. The rank-one adapter's operation count and additional memory scale with m*d. These measure one primitive only and exclude seed acquisition; no source sampler, inference dataset, or held-out runtime comparison was executed.

The decisive falsification for the near-linear consequence is an actual runtime operation requiring a dimension-dependent tensor, full seed-covariance factorization, hidden conditional-mean oracle, or an accuracy proof requiring growing recursion depth. The inspected runtime sections avoid those operations. This does not show their analytic accuracy estimates are correct.

The next load-bearing proof gate is family 139's Gaussian divergence/path-derivative estimates and the stationary-centering accuracy theorem, followed by the compiler's error recurrence under correlated seeds. The all-split cumulant lemma is already reconstructed, but is only one dependency.

The next computational gate is to emit the full scalar circuit/routine template with explicit constants for one fixed exponent and execute it on a nonseparable legal target against equally informed direct and established sampler controls. Until that succeeds, the result remains an acquired adapter plus a conditional asymptotic deduction, not a usable local near-linear sampler or a scientific breakthrough.

# PDE/transport safety: robust inventory filtering for plug flow

**Status:** internally reconstructed conditional theorem and algorithm. It applies to the scalar constant-speed advection model below. Novelty and external correctness are unverified; this is a candidate specialization of delay-safety methods, not a claim about general PDEs or physical plants.

## Result and interface

For a one-dimensional plug-flow channel with unknown but fixed speed in a certified interval, a sampled boundary controller can enforce a cap on total stored material at every time, including between samples. Characteristics make the next-interval inventory affine in the proposed boundary command. The exact robust command is the infimum of explicit scalar thresholds over speed and elapsed time. A finite grid with a derived Lipschitz margin gives a conservative certified implementation.

Let $q(x,t)$ be nonnegative concentration on $x\in[0,L]$:

\[
q_t+cq_x=0,\qquad q(0,t)=u(t),\qquad q(x,0)=q_0(x).
\]

The unknown speed is constant in time and belongs to the acquired interval $C=[c_-,c_+]$, where $0<c_-\le c_+$. The actuator holds $u(t)=a_k\in[0,U_{\max}]$ on each interval $[kh,(k+1)h)$. The safety output is total inventory

\[
M_c(t)=\int_0^Lq(x,t)\,dx\le M_{\max}.
\]

Startup data are the speed interval, initial cell integrals $m_i=\int_{I_i}q_0(x)dx$ on $N$ equal cells of width $d=L/N$, a known density cap $0\le q_0\le Q$, and the record of past held commands. The initial inventory is exactly $\sum_i m_i$ and must be at most $M_{\max}$.

The result excludes diffusion, reaction, recirculation, time-varying speed, and actuator or sensor faults. It is a model-level process-safety statement, not a real-plant guarantee.

## Robust one-step theorem

For residence time $\tau_c=L/c$, characteristics give

\[
M_c(t)=\begin{cases}
\displaystyle\int_0^{L-ct}q_0(x)\,dx+c\int_0^t u(r)\,dr,&t\le\tau_c,\\[4pt]
\displaystyle c\int_{t-\tau_c}^{t}u(r)\,dr,&t\ge\tau_c.
\end{cases}
\]

At sample $t_k=kh$, hold candidate command $a$ for $s\in[0,h]$. In the initial-profile branch, define

\[
A_k(c,s)=\int_0^{L-c(t_k+s)}q_0(x)dx+c\int_0^{t_k}u(r)dr,\qquad B(c,s)=cs.
\]

In the boundary-history branch, define

\[
A_k(c,s)=c\int_{t_k+s-\tau_c}^{t_k}u(r)dr
\quad\text{if }t_k+s-\tau_c<t_k,
\]

and set this history term to zero otherwise; let $B(c,s)=c\min(s,\tau_c)=\min(cs,L)$. In either branch,

\[
M_c(t_k+s;a)=A_k(c,s)+B(c,s)a.
\]

With an exact initial profile, use its exact prefix integral. With cell-integral data, replace that prefix by the upper envelope $I^+$ from the next section and write the result as $A_k^+(c,s)$. This is the exact robust upper envelope at each $(c,s)$ over every profile compatible with the acquired cell data.

If the current state is certified safe for every admitted speed and initial profile, the largest command certified throughout the next hold is

\[
a_k^*=\min\!\left\{U_{\max},\inf_{\substack{c\in C\\0<s\le h}}
\frac{M_{\max}-A_k^+(c,s)}{B(c,s)}\right\}.
\]

When this ceiling is nonnegative, filtering a nominal command $v_k$ by $a_k=\min(v_k,a_k^*)$ is its closest safe value in squared distance and maximizes the applied input among commands no larger than $v_k$. If no positive command is certified, set $a_k=0$. With zero inlet value, $M'_c(t)=-c q(L,t)\le0$, so zero is safe from any already-certified safe state. Repeating the rule proves all-time safety by induction. The full proof and finite-grid construction are in [PROOF_AND_ALGORITHM.md](PROOF_AND_ALGORITHM.md).

## Acquisition, discretization, runtime, and effort

For a partial cell of width $d$, measured mass $m$, density cap $Q$, and prefix length $r$, the exact possible mass range before the cut is

\[
\left[\max(0,m-Q(d-r)),\;\min(m,Qr)\right].
\]

The upper endpoint is attained by filling the prefix first; the lower endpoint is attained by filling the suffix first. The uncertainty width is at most $Q\min(r,d-r)\le Qd/2$, with equality possible at a half-cell cut. Sum exact full-cell masses and this upper endpoint to obtain $I^+(b)$. This requires $N$ cell-integral measurements and a valid cap $Q$; point samples alone do not determine inventory without added regularity. Measurement intervals are handled by using each cell’s upper mass endpoint.

For $q_0\le Q$ and $u\le U_{\max}$, inventory is Lipschitz in elapsed time and speed with

\[
K_s=c_+(Q+U_{\max}),\qquad
K_c=\max\{\tau_{\max}(Q+U_{\max}),\,2LU_{\max}/c_-\},\quad \tau_{\max}=L/c_-.
\]

On speed and time grids with maximum spacings $d_c,d_s$, use the mass margin

\[
\varepsilon_{grid}=\tfrac12(K_c d_c+K_s d_s)+\varepsilon_{num}+\varepsilon_{meas}.
\]

Here $\varepsilon_{num}$ bounds arithmetic error and $\varepsilon_{meas}$ bounds any mass-measurement uncertainty not already included in the acquired cell intervals. Accept a command only if every grid-point upper envelope plus this margin is at most $M_{\max}$. The Lipschitz proof makes that a continuous-time certificate. This is a conservative inner approximation; tight margins can make it return zero when some positive command would be safe.

At fixed grids, first check any $s=0$ points, where $B=0$. If those mass upper bounds plus margin fail, the grid cannot certify a positive action and the controller falls back to zero. Otherwise, every remaining candidate inventory is affine and nondecreasing in $a$, so the maximum certified command is computed in one pass by minimizing $(M_{\max}-\varepsilon-A_k^+)/B$ over grid points with $s>0$, then rounding downward to actuator resolution. With prefix-sum arrays for $N$ initial cells and $H=\lceil\tau_{\max}/h\rceil+1$ held commands, runtime is $O(n_cn_s\log(N+H))$ arithmetic per sample and memory is $O(N+H)$; $n_c,n_s$ are the two grid sizes. Finer grids reduce the explicit mass margin while increasing runtime as $n_cn_s$.

Boundary effort is $\sum_k h a_k^2$ in the normalized signal model. If actuator power is known to be $P(t)=\kappa u(t)^2$, physical energy is $E=\kappa\sum_k h a_k^2$; $\kappa$ must be calibrated. No electrical-energy number is inferred here. Injected material is $\sum_k ch a_k$ and depends on the unknown speed.

If the speed interval is not supplied, one ideal calibration is a step input from a cleared zero state and an outlet threshold sensor. Sampling the outlet every $\delta$ brackets first arrival $\tau=L/c$ between adjacent reads, hence brackets $c$. It costs at most $\lceil\tau_{\max}/\delta\rceil+1$ outlet readings and signal effort at most $A^2(\tau_{\max}+\delta)$ for step amplitude $A$, before multiplying by calibrated $\kappa$. Real noise and threshold uncertainty must widen the interval; they are not covered by this ideal acquisition calculation.

## Hand-computed check

Set $L=1$, $q_0(x)=0.4$, $C=[0.8,1.2]$, $h=0.8$, $M_{\max}=0.6$, and $U_{\max}=1$. All residence times exceed $h$, so

\[
M_c(s;a)=0.4+cs(a-0.4).
\]

For $a>0.4$, the maximum occurs at $c=1.2,s=0.8$, giving $0.016+0.96a\le0.6$. Hence $a\le0.60833\ldots$. A nominal $0.9$ is clipped to $0.60833\ldots$, which reaches the cap exactly at the end of the hold. This is an algebraic model check, not a physical-process result.

## Intersample obstruction for boundary-output safety

After the initial profile clears, pure transport gives $y(t)=u(t-\tau_c)$. A pulse of height $Y+\epsilon$ and width less than the sensor period can lie wholly between output samples: all sample values are safe while $y(t)>Y$ during the pulse. Thus sampled feasibility alone cannot certify continuous-time safety without a temporal regularity bound.

If $|\dot u|\le R$, the pure delay preserves that bound. Samples spaced by $\delta$ satisfying $y(t_j)\le Y-R\delta/2-e_y$, where $e_y$ bounds sample error, imply $y(t)\le Y$ continuously. A triangular tent between samples attains the $R\delta/2$ term, so the margin is sharp under only this regularity information.

## Comparator and novelty boundary

The closest structural comparator for plug flow is Kiss, Molnár, Ames, and Orosz (2023): the transport field can be represented by a delay state, and their differentiable barrier functional gives affine input constraints and an invariance theorem for a fixed-delay system. Their paper says disturbances are outside its scope. The present candidate specializes to an inventory output with uncertain-but-fixed speed, acquired initial cell masses, held input, and an explicit finite-grid mass margin. Whether this is new relative to all delay-barrier and sampled-data CBF work remains open.

The strongest continuum PDE safety-filter precedent found is Koga and Krstic (2023), who prove all-time safety for a Stefan heat equation with moving phase boundary and actuator dynamics while filtering an arbitrary operator input. Their CBFs include an energy-deficit functional and boundary heat flux; a backstepping auxiliary barrier handles the relative-degree-two interface constraint. The proof requires a compatible initial temperature/flux, feasible interface setpoint, gain conditions, and a classical solution. This is a parabolic free-boundary system with full-state quantities, not an uncertain-speed transport channel with partial cell-mass sensing.

Among current hyperbolic boundary models, Wang and Krstic (2026) prove continuous-time safety and tracking for a coupled 2x2 hyperbolic PDE–ODE with distributed disturbances and output feedback. Their backstepping/high-relative-degree-barrier controller predicts through the transport dead time, then protects the distal ODE output; their output-feedback theorem uses a known initial-observer-error bound to shrink the safe region by a decaying margin. It assumes known model parameters, an observable finite-dimensional exosystem, a smooth barrier with nonvanishing derivative, bounded initialization, and classical closed-loop solutions. This is a serious boundary-safety result, but its output and interface are different: scalar distal ODE tracking error versus total material inventory in a scalar plug-flow channel, and continuous-time state/observer feedback versus cell-mass acquisition plus ZOH action.

Other neighboring results are distinct again. Hu and Liu (2025) train a neural operator mapping boundary inputs to a boundary-output trajectory and filter with a learned time-dependent barrier; their theorem assumes an exact operator, while their discrete implementation includes a tunable mismatch threshold and leaves mismatch analysis for future work. Block and Stockar (2026) formulate spatial barriers for an upper density profile in the linearized LWR model with distributed in-domain variable-speed-limit actuation and report a circular-road simulation. Their displayed CBF admissible set in Eq. (23) uses $L_fh+L_ghu\ge-\alpha(h)$, but the QP in Eq. (26) prints the reverse sign; the mismatch appears in the official arXiv v2 PDF as well as HTML. Without an implementation/code audit or author clarification, I do not use Eq. (26) as a verified comparator guarantee, and whether this is typographical or affects the simulated implementation is UNKNOWN. Wang and Krstic’s 2026 parabolic PDE–ODE positivity theorem and their 2025 high-order Stefan stabilization theorem are adjacent results for different dynamics and outputs. PDE Control Gym’s transport benchmark adds a recirculation term $\beta(x)u(0,t)$ and targets stabilization; no transfer to that full benchmark dynamics is asserted.

No novelty/priority conclusion is claimed. See [SOURCE_LEDGER.md](SOURCE_LEDGER.md) for read depths, theorem boundaries, and exact primary sources.

## Falsifier and next gate

A falsifying trace would use a speed inside the certified interval, a nonnegative initial profile matching all cell integrals and the density cap, and a command accepted by the grid filter, yet produce inventory above $M_{\max}$ between samples. Coefficient drift, dispersion, recirculation, input delay, noisy flow meters, and actuator faults require separate models.

No simulator, formal proof checker, external proof review, or physical trial was run for this workstream. The next decisive gate is an exact-characteristic simulator with adversarial cell profiles attaining the partial-cell bounds, compared against (i) the same filter without the grid margin, (ii) sample-only inventory checks, and (iii) a delay-CBF baseline with the same speed interval and sensor budget. A physical plug-flow trial would first need measured speed bounds, dispersion, sensor error, and actuator-energy coefficient. Until those checks and the prior-art audit are done, this remains a conditional model theorem and research candidate.

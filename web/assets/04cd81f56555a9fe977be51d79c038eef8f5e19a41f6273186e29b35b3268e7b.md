# Resilient distributed control: event-sampled link failure

## Finding

The defensible result from this workstream is a counterexample to a tempting composition rule: applying the shared-channel PoC bound separately to each link does not guarantee that an event-triggered controller can obtain its required neighborhood data at event times. In an exact four-agent witness, each directed edge has \(\phi_e=11/30<1\), yet a fail-closed full-neighborhood controller misses at every retry and freezes at non-consensus. A same-event distributed baseline using the two messages that did arrive contracts disagreement by exactly \(1/27\) every three events.

This is a scoped implementation result, not a new general resilient-consensus theorem or a claim about physical devices. It attacks an edge-wise extension of the published PoC criterion, not the source theorem's shared-medium setting.

## Source theorem reconstructed

Senejohnny, Tesi, and De Persis (2015) study scalar integrators \(\dot{x}_i=u_i\) on a fixed connected undirected graph. At each local timer event, an agent polls all its neighbors for relative states, computes their sum \(\mathrm{ave}_i\), applies a ternary sign control when \(|\mathrm{ave}_i|\ge\varepsilon\), and chooses a next sampling interval proportional to \(|\mathrm{ave}_i|/(4d_i)\) (or \(\varepsilon/(4d_i)\) below threshold). Their DoS model is a shared communication medium: when an attack is active, no node can send or receive. They bound global attack start frequency and total blocked duration by \(\eta+(t-\tau)/\tau_f\) and \(\kappa+(t-\tau)/\tau_d\). The PoC condition is

\[
\frac1{\tau_d}+\frac{\Delta_*}{\tau_f}<1,
\qquad \Delta_* = \frac{\varepsilon}{4d_{\min}}.
\]

Under these assumptions, their Theorem 2 gives finite-time convergence to the practical-consensus set \(|\mathrm{ave}_i|<\varepsilon\) for all nodes. The theorem has no Byzantine-node model and no independent edge-availability process. The original source and relevant equations/proof spans are logged in [SOURCES.md](SOURCES.md).

Tseng and Vaidya's 2014 Springer chapter treats a different interface: synchronous rounds, fault-free nodes, and up to \(f\) transient Byzantine links per round. It states a necessary and sufficient directed-graph condition for its iterative approximate-consensus class. Its local repository mirror is marked withdrawn, while Springer identifies the chapter as published; I keep its result source-reported and do not promote it to independent proof validation. It does not close the continuous-time, event-sampled, mobile-node, independently jammed-link interface.

## Exact attack and comparator

There are four scalar agents on directed \(K_4\). After a non-consensus initial transient, set \(\delta=\Delta_*\). At each retry, every receiver loses one incoming link; cycle the missing sender through its three neighbors so each directed edge is unavailable only once every three events. Each outage lasts \(\rho=\delta/10\). Per edge, \(\tau_f=3\delta\), \(\tau_d=30\), and

\[
\phi_e = \frac{\rho}{3\delta}+\frac{\delta}{3\delta}=\frac{11}{30}<1.
\]

The fail-closed rule requires all three neighbor values and sets its control to zero after any incomplete sample. Since there is one missing value at every poll, it never resumes; its state stays at a diameter above \(\varepsilon\). This is not the original global-DoS protocol: it is an explicit per-link variant whose missing-packet behavior is stated so the counterexample has a complete interface.

The comparator uses the same event times and the same eight delivered directed values per event. Each agent averages its own state and its two available neighbors. The exact three-step transition product has minimum row overlap \(26/27\), hence Dobrushin coefficient \(1/27\). Its diameter obeys \(D_{3m}\le27^{-m}D_0\), reaching \(\varepsilon\) after at most \(3\lceil\log(D_0/\varepsilon)/\log27\rceil\) events. The standard-library rational calculation is in [counterexample.py](counterexample.py), with output in [counterexample_output.txt](counterexample_output.txt).

The bottleneck removed in this finite model is the requirement that every neighbor report arrive before any safe state update. The baseline keeps using available observations. It is a valid comparator here because the witness has no Byzantine nodes. For adversarial-node resilience the same averaging rule is not a safe substitute; the next gate is a W-MSR-type update on event-sampled link-reduced graphs.

## Resources and practical boundary

Over each three-event block, both rules attempt 36 directed messages; 24 arrive and 12 fail. They take 12 local samples. The fail-closed rule makes 36 link-status checks and no later state update. The averaging baseline performs 24 additions, 12 multiplications by \(1/3\), and 12 state updates. A parameterized message/sensing cost is \(36E_{tx}+24E_{rx}+12E_s\) per block, plus trigger, compute, and actuation terms. Failed transmissions are charged. No physical energy values, sensor model, or plant-actuation work model is available, so a joule comparison is UNKNOWN. The protocol operates on known directed links with synchronized event times in the witness; delayed, quantized, or mobile-topology behavior is outside the claim.

## Current prior-art boundary

The primary-source pass found nearby work in separate combinations: adversarial-agent MSR with self/event triggering (2021), mobile adversaries with mixed self/event-triggered ternary control (2024), and distributed link-specific DoS with event/self-triggered consensus (2026). The newer DoS paper explicitly treats directed graphs and independently disrupted communication channels; its abstract says self-triggering avoids continuous monitoring. I did not reconstruct these papers' full theorem conditions, so I do not claim their models are disjoint or claim novelty. The exact overlap audit remains UNKNOWN.

The Astra start/core/workflow were read first. The local methods/analysis/probability topic maps had no directly relevant control cards, so no unrelated Astra claim was used as a premise.

## Verdict and next gate

**Verdict:** retain the counterexample as a useful interface-level falsifier. Do not claim a new general theorem or priority. Its decisive content is exact: per-edge average budgets can pass while all event samples are incomplete, and partial-neighbor use of the same delivered information changes non-convergence to explicit geometric contraction.

**Next gate:** reconstruct the full conditions of the 2021, 2024, and 2026 primary papers; then formalize a joint condition on each event-sampled, link-reduced graph under \(F\)-local or \(F\)-total Byzantine agents. Compare W-MSR contraction, all attempted transmissions, event sensing, sorting/compute, and actuation against a retry/jitter policy with identical information. A result fails if its sampled reduced graphs lose the required robust connectivity, even when each edge separately has high time availability.

STRONGER EXACT GATE RESULT
The sharp easy-plane condition is not an Euler-step artifact. Among scalar-functional-calculus gates whose local six-vertex coefficients are nonnegative, it is exactly the boundary for the log-concavity test of every strictly increasing gate of a single XXZ edge, whenever the three eigenvalues lie in the interval of monotonicity.

Write h=alpha(XX+YY)+gamma ZZ, alpha>=0. On |00>,|11> its eigenvalue is gamma; on |psi+>=(|01>+|10>)/sqrt(2) it is 2alpha-gamma; on |psi->=(|01>-|10>)/sqrt(2) it is -2alpha-gamma. After an arbitrary scalar shift kappa, denote these three eigenvalues by
  x0=kappa+gamma, x+=kappa-gamma+2alpha, x-=kappa-gamma-2alpha.
For any real scalar function f defined on these values, f(kappa I+h) has outer diagonal a=f(x0), central diagonal b=(f(x+)+f(x-))/2, and central off-diagonal c=(f(x+)-f(x-))/2 in the computational basis. If f is increasing and alpha>=0 then c>=0, b+c=f(x+), b-c=f(x-). The six-vertex quadratic's Hessian has at most one positive eigenvalue exactly when its triangle inequalities hold. The inequalities a<=b+c and b-c<=a become
  f(x-) <= f(x0) <= f(x+).
The remaining inequality a+b>=c is equivalent to f(x0)+f(x-)>=0 and follows from nonnegativity of the gate table.
Strict monotonicity makes these equivalent to
  kappa-gamma-2alpha <= kappa+gamma <= kappa-gamma+2alpha,
that is, -alpha<=gamma<=alpha. The scalar shift cancels from both inequalities.

Consequences:
1. For any positive finite Euler gate F=I+s(kappa I+h), its r-fold same-edge block F^r (integer r>=1) has f(x)= (1+s x)^r. On a positive spectrum this is strictly increasing, so no number of repeated same-edge Trotter slices repairs a strict cone violation. At gamma>alpha, a=f(x0)>f(x+)=b+c, so a-b-c>0. At gamma<-alpha, a=f(x0)<f(x-)=b-c, so -a+b-c>0.
2. The exact local heat gate exp(t(kappa I+h)), t>0, also has a nonnegative six-vertex table but is non-LC on either strict outside side. Thus replacing the Trotter approximation by the exact two-site exponential cannot enlarge the local LC counting cone. This directly addresses c06_l09's frozen next-gate question at the local level; a rational implementation and product-formula cost argument remain separate.
3. Any Taylor truncation p_k(x)=sum_{j=0}^k x^j/j! is strictly increasing on x>=0. If a larger identity shift makes the edge generator positive semidefinite, the induced local gate p_k(hA) still has the same necessary ordering and cannot cure |gamma|>alpha. In particular the rational p_2 gate in c06_l03/c06_l08 remains correctly scoped to the existing cone; it does not produce an outside-cone extension.

FIRST-ORDER CONSISTENCY BARRIER
The obstruction does not require the approximating scalar gate to be globally monotone. Fix a strict outside-cone edge and a scalar-shifted spectrum x0,x+,x- as above. Suppose a family of local scalar gates has f_s(x)=c_s+s*x+o(s) at these three fixed arguments as s tends to zero, with c_s>0 and s>0. This is the usual first-order consistency condition for approximating a positive-time exponential, allowing a positive scalar normalization. Then
  f_s(x0)-f_s(x+) = 2s(gamma-alpha)+o(s) > 0
when gamma>alpha, while
  f_s(x-)-f_s(x0) = -2s(gamma+alpha)+o(s) > 0
when gamma<-alpha, for every sufficiently small s. In the first case the six-vertex table has a>b+c; in the second it has b-c>a. Hence it cannot be both a nonnegative signature and log-concave. This covers any first-order-consistent Euler, Taylor, rational, or other scalar functional-calculus local gate in the sufficiently fine-step regime, even if the approximant is not globally monotone. It still does not cover a genuinely coupled multi-edge block or a representation that is not a positive single-edge six-vertex signature.

The exact-block derivation is stronger than the INITIAL's block-diagonal Hessian of the product-of-distinct-gates polynomial: it also rules out compressing arbitrarily many identical edge gates into one local signature. It does not address a joint multi-edge block with noncommuting gates or global auxiliary contraction.

PRODUCT-UNITARY OBSTRUCTION
For an edge coupling matrix J=diag(alpha,alpha,gamma), local single-qubit unitaries induce J -> R_u J R_v^T with R_u,R_v in SO(3), so the singular values are invariant. Every accepted easy-plane coupling tensor, in any common choice of axes, has two equal largest singular values (alpha',alpha',|gamma'|) with alpha'>=|gamma'|. For strict |gamma|>alpha the input singular values are (|gamma|,alpha,alpha), with a unique largest singular value. Therefore no product of local unitaries can map that edge into an accepted easy-plane tensor. This covers arbitrary continuous local rotations, stronger than checking only Pauli-axis permutations. It is still only a local-unitary obstruction, not a lower bound against nonlocal encodings or different algorithms.

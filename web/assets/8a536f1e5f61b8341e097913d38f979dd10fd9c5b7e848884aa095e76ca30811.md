# Sparse relation graphs for complement-LCU: exact incidence and clock tradeoff

**Status: INTERNALLY-PROVED-CANDIDATE** for the direct-sum incidence identity, the biased-clock gap, the endpoint-mass bound, and the subdivision/amplification costs below. **UNKNOWN** whether the fixed complement-LCU image admits any other polynomial-row, constant-gap positive enforcer. This note rules out only the gate-granular path/subdivided-expander implementations specified here; it does not re-prove the Cycle-3 canonical-projector row lower bound.

## Result

There is an exact constant-gap, no-inverse incidence enforcer for any isometry `V`, but its row-list cost is the row/column support of `V`. Replacing its dense `V` relation by gate-by-gate history constraints makes each relation sparse, at the cost of a path bottleneck. A biased clock can make the *clock* gap and a root input anchor constant, but then the final LCU test has only inverse-polynomial (or exponentially small) clock mass. Conversely, a clock with constant mass on both the simple input anchor and the output test has gap `O(T^-2)` on a `T`-step gate path. Gap amplification does not restore the lost test-compression factor and its generic row-support cost is superpolynomial.

The post-computation “copy the failure flag, then uncompute” idea preserves the diagonal flag test at every suffix time, but its exact history-image anchor is the projector onto the copied-output image `F`; the root penalty is then `I-FF*`, not the simple input-label penalty. Moving the anchor back before the computation restores local input checks but loses the invariant-test property. This is the interface conflict, not a proof against arbitrary positive enforcers.

## Exact no-inverse incidence baseline

Use the full complement-LCU interface of
`../cycle3/complement_lcu/00_INTERFACE_AND_TENSOR_FORMULA.md`:

```text
H = sum_j pi_j h_j,       0 <= H <= I,
V|psi> = U(|0>_label |psi>),
B = (I-|0><0|)_label tensor I,
F := V* B V = 2H-H^2,     H <= F <= 2H.
```

Let `K` be the physical space of `V` and `L` its logical space. On the direct sum `K ⊕ L`, define

```text
T(x,y) = x - V y,                 T = [ I  -V ],
W|psi> = (V|psi> ⊕ |psi>)/sqrt(2),
C = T*T/2 = (1/2) [ I  -V ; -V*  I ],
B' = B ⊕ 0.
```

Then `W*W=I`, `ker T={(Vy,y):y in L}=ran(W)`, and

```text
TT* = I + VV*,       spec_nonzero(T*T) = {1,2},
0 <= C <= I,          C >= (1/2)(I-WW*),
W*B'W = F/2,          H/2 <= W*B'W <= H.
```

Thus the kernel, full-space gap, and comparison constants are exact, with no `K_a Y^{-1}`. `B'` is still diagonal and one-row-sparse. The direct-sum adds one logical-size sector; a sector bit plus padded registers is a concrete realization. But each off-diagonal row of `C` lists a row of `V`, and rows in the other sector list columns of `V`. This is a sparse enforcer **iff** both row and column lists of `V` are sparse and accessible. For the complement-LCU circuit with `M` clauses and `R` repeated local factors, a safe gate-independent bound for a reflection row is `2^(5R)`; summing `M+1` branch maps gives only the exponential upper bound `O(M 2^(5R))`. Circuit entry evaluation is not a polynomial row-list guarantee. No cancellation-free lower bound for every output block is claimed here.

This gives a useful exact baseline: the inverse in the earlier `K_aY^{-1}` incidence presentation is avoidable; the unresolved charge is sparsity of the *forward relation* `V`, not invertibility of `Y=I-H`.

## Gate-level history relation and its exact losses

Let the LCU unitary (including a reversible copy of the nonzero-label predicate into a flag) have a decomposition into `T` elementary gates. Set `J=|0>_label |0>_flag tensor I_data`, let `G_1,...,G_T` be the gates, and `U_t=G_t...G_1`, `U_0=I`. The final state map is

```text
F = U_T J,
F* (|1><1|_flag) F = 2H-H^2.
```

The flag is copied after the LCU output label is formed. A computation-history isometry with clock distribution `pi` is

```text
V_pi |psi> = sum_(t=0)^T sqrt(pi_t) |t> U_t J|psi>.
```
The usual clock-edge operator is the frame-gauged graph Laplacian. For the uniform path, use

```text
e_t = (1/4)[ |t><t| + |t+1><t+1|
             - |t+1><t| G_(t+1) - |t><t+1| G_(t+1)* ],
C_path = sum_(t=0)^(T-1) e_t.
```

It has `ker(C_path)=ran(V_uniform)` **only if the clock-history input space is the entire gate-system space**. Its exact spectrum is one quarter of the path-Laplacian spectrum, so

```text
gamma_path = (1-cos(pi/(T+1)))/2 = Theta(T^-2).
```
A two-qubit gate gives at most four data outputs in one edge block; a clock/data row has at most `1+2*2^2=9` entries. There are `T` edges. A `(T+1)`-level clock uses `ceil(log2(T+1))` qubits; edge terms have locality `O(log T)+2`, while row support stays constant. A unary clock can make edge locality constant but uses `Theta(T)` bits and needs a validity penalty; normalizing a sum of `T` invalid-pattern penalties can itself cost a factor `T`. The report uses the abstract valid clock register, avoiding a false constant-locality claim.

To select the intended image `ran(V_pi)` rather than all histories from arbitrary ancilla/workspace inputs, add a root input penalty

```text
A_root = |0><0|_clock tensor (I-JJ*).
```

The kernel of `C_path+A_root` is exactly `ran(V_uniform)`. Yet its gap is at most the path gap: choose a valid logical vector and a clock mode orthogonal to the uniform vector, for which `A_root` vanishes. The exact output-only test

```text
B_T = |T><T|_clock tensor |1><1|_flag
```
obeys

```text
V_uniform* B_T V_uniform = (2H-H^2)/(T+1).
```
If the original promise is `yes: lambda_min(H)<=a`, `no: lambda_min(H)>=b`, this gives `yes<=2a/(T+1)` and `no>=(2b-b^2)/(T+1)`. Scaling `B_T` by `T+1` would violate `B_T<=I`. Even if the clock gap were amplified, the comparison factor remains `1/(T+1)`.

## Biased-clock construction: constant gap, vanishing output mass

There is a precise way to repair the clock spectrum alone. On `{0,...,T}`, take the reflecting birth-death chain `P` with right-step probability `p=1/3` and left-step probability `q=2/3`; missing boundary moves are self-loops. Its stationary law is

```text
pi_t = (1/2)^t / Z_T,       Z_T=sum_(s=0)^T (1/2)^s,
pi_0 > 1/2,                 pi_T = 2^(-T)/Z_T < 2^(-T).
```
Let `S=diag(sqrt(pi)) P diag(1/sqrt(pi))` and `C_clk=(I-S)/2`. This is a positive contraction with kernel `sqrt(pi)` and tridiagonal support. For every set `A` with `pi(A)<=1/2`, vertex 0 is absent (as `pi_0>1/2`). Decompose `A` into intervals. For each interval `[a,b]`, `a>=1`, its left-boundary flow is `pi_a q`, while its mass is at most `pi_a/(1-p/q)=2 pi_a`; hence its conductance is at least `1/3`. Thus `Phi(P)>=1/3`, and the reversible Cheeger inequality gives `gap(P)>=Phi^2/2>=1/18`; consequently `gap(C_clk)>=1/36`.

Gauge by `W=sum_t |t><t| tensor U_t`. Add `A_root` above. Since `pi_0>1/2`, the root penalty has constant overlap with every clock-stationary invalid-input history. A direct decomposition proof gives a constant combined gap: write a unit vector as `|sqrt(pi)> tensor phi + r`, with `r` clock-orthogonal. If `E=<C_clk+A_root>`, then `||r||^2<=36E` and

```text
||P_(J^perp) phi||^2 <= (2/pi_0)( <A_root> + ||r||^2 ).
```
Therefore squared distance to the exact valid-history kernel is at most
`[(1+2/pi_0)36 + 2/pi_0] E <= 184 E`. Dividing `C_clk+A_root` by 2 makes it a contraction and leaves gap at least `1/368`. Each clock edge still carries one elementary gate, with constant row support; the root projector is diagonal on the input ancillas. The encoded isometry is exact.

But the output-only diagonal test has compression

```text
V_pi* B_T V_pi = pi_T (2H-H^2),
```
with `pi_T < 2^-T`. Thus this is a costed constant-gap sparse *history* enforcer, not a useful constant-factor encoding of the full list. Reversing the bias makes `pi_T` constant but `pi_0` exponentially small; for an invalid-input stationary history the root penalty energy is at most `pi_0`, so the exact-image gap becomes exponentially small (rescaling the penalty is erased by contraction normalization).

The tradeoff is not peculiar to this geometric law. For any reversible nearest-neighbor clock chain on `{0,...,T}` with edge conductances `c_t=pi_t P(t,t+1)`, set `f(t)=t/T`. Then

```text
Var_pi(f) >= pi_0 pi_T,
E_P(f,f) = sum_t c_t/T^2 <= 1/T^2,
1-lambda_2(P) <= 1/(T^2 pi_0 pi_T),
gap((I-S)/2) <= 1/(2 T^2 pi_0 pi_T).
```
So if the local input anchor has constant clock mass and the output test must have constant mass, every reversible path clock has gap `O(T^-2)`. A constant gap forces the terminal mass to be `O(T^-2)` when `pi_0=Omega(1)`. This rules out fixing both factors just by choosing a clever birth-death stationary distribution.

## Why the copied-flag suffix does not evade the anchor

One can start after the LCU computation, copy `1[label != 0]` to a flag, and then apply a suffix of `U*` gates on label/data while leaving the flag untouched. At every suffix time `t`, the diagonal test `B=|1><1|_flag` has exactly the same compression:

```text
(U_t F)* B (U_t F) = F* B F = 2H-H^2,
```
because every suffix gate acts away from the copied flag. This removes the terminal-mass loss. But the clock Laplacian's kernel is now histories from arbitrary states at the post-copy root. To make its kernel exactly the image of `F`, the root constraint is

```text
|0><0|_clock tensor (I-FF*),
```
not the local `I-JJ*` input-label projector. `F=copy(label!=0) U J` is the full output image of the LCU circuit; the root projector is a circuit-conjugated image test, and no polynomial row-list bound for it is established. A gate-by-gate implementation that moves the root back to `J` reintroduces pre-computation clock states where the same flag test does not compress to `2H-H^2`. Thus the copied-flag observation is an exact compression identity, not an enforcer construction.

## Expander clock with gate-granular edge subdivision

Suppose a constant-degree base expander has `K` vertices, and each edge connection between its unitary frames is implemented by a path of `ell` elementary gates. On the subdivided graph, every interior transition is one local gate, so row support remains `O(1)` and the exact kernel of the connection Laplacian is the gauged constant clock sector (plus the chosen anchor restriction). However the normalized spectral gap is `Theta(ell^-2)`, not the base expander's constant gap.

For the upper bound, choose a nonconstant base-graph eigenfunction `g` and linearly interpolate its endpoint values along every length-`ell` corridor. The unnormalized Dirichlet energy on a corridor is `(g(u)-g(v))^2/ell`, so total energy is the base energy divided by `ell`. The squared norm of the interpolation is `Omega(ell)` times the base squared norm: on each corridor the sum of squares of the linear interpolation is at least `ell(a^2+b^2)/6`, including when endpoints have opposite signs. Hence the Rayleigh quotient is `O(gamma_base/ell^2)=O(ell^-2)`, already enough to rule out constant gap. For the matching lower bound, decompose an arbitrary clock function into the linear interpolation of its base-vertex values plus zero-endpoint residuals. Path Cauchy/Poincare bounds the base interpolation energy and residual norm by `O(ell^2)` times the subdivided-graph Dirichlet energy; the base-expander Poincare inequality controls the interpolated component. Thus a fixed-degree base expander has subdivided gap `Theta(ell^-2)`.

If the simple input anchor is present at just one clock root, a stationary history with invalid ancilla state has anchor energy `1/K` before subdivision. If it is replicated on a constant fraction of base vertices to avoid that loss, while the useful output test also occupies a constant fraction, the linearly interpolated indicator between these sets gives the same `O(ell^-2)` gap upper bound. The physical graph has `K+Theta(K ell)` vertices, `O(log(K ell))` binary clock bits, `O(K ell)` local transition records, constant row degree, and a neighbor/gate sampler using `O(log(K ell))` bits plus the supplied gate-index lookup. A direct expander edge without subdivision retains constant clock gap, but its block applies the entire relative circuit; a product of `ell` local gates has only the generic row bound `s^ell` (for two-qubit gate row support `s<=4`). Neither branch yields both polynomial rows and a constant gap from this construction.

## Amplification cost and exact promise accounting

For a row-`s`-sparse contraction with gap `gamma=Theta(ell^-2)`, a Chebyshev filter that preserves the exact kernel and gives a fixed constant gap needs degree `d=Theta(gamma^-1/2)=Theta(ell)`. The direct row-support bound is

```text
1+s+...+s^d <= (s+1)^d = exp(O(ell log s)).
```
A detectability-style loss operator needs `q=Theta(gamma^-1)=Theta(ell^2)` sweeps, with generic row-support upper bound `s^(O(ell^2))`; gate-list size and circuit evaluation remain polynomial, but row listing need not. These are upper-cost warnings, not lower bounds for every signed filter or every alternative parent. In the BMVZ path construction of Cycle 3, the particular filter sweeps have exact seed-transition density lower bounds, but that proof concerns its named history image and is not transferred to this new LCU circuit history.

Crucially, any filter changes `C`, not the image isometry or the test `B`. Thus it cannot improve the `1/(T+1)` or `pi_T` factor in `V_clock* B_T V_clock`. In the copied-flag suffix, the compression is constant already; the remaining barrier is the nonlocal exact-image anchor. A rational/Schur lift of the subdivided graph likewise keeps a norm/gap tradeoff after normalization; it does not remove the path resistance.

For `H` with promise thresholds `(a,b)`, the LCU observable is `F=2H-H^2`. With output clock mass `mu`, the exact operator inequalities and threshold map are

```text
mu H <= mu F <= 2 mu H,
yes energy <= 2 mu a,
no energy >= mu(2b-b^2).
```
The transformed additive gap is `mu[(2b-b^2)-2a]`; for the BMVZ regime with negligible yes energy and constant `b`, a constant lower comparison still requires `mu=Omega(1)`. Clock-gap amplification does not change this requirement.

## Cost ledger and scope

* `M=poly(n)` term labels and `R=poly(n)` repeated local factors give a polynomial gate count `T=poly(M,R,n)` for PREPARE/SELECT/uncompute and flag copy, under the exact algebraic-gate representation used by the LCU interface. Finite-gate synthesis is approximate and needs a separate error budget against the yes floor.
* LCU workspace is `ceil(log2(M+1))` label qubits plus the `N=poly(n)` data qubits and one copied flag. The gate-history clock adds `ceil(log2(T+1))` qubits. Controlled-prefix/history preparation can be implemented with `O(T log T)` elementary gates and `O(log T)` temporary bits; the graph enforcer itself is specified by its `O(T)` local gate transitions.
* Path/clock row support is at most 9 for two-qubit gates; vertex/edge/gate lookup is polynomial. Binary-clock operator terms act on `O(log T)+2` qubits. A unary clock uses `Theta(T)` qubits and must charge an invalid-clock penalty; no constant-locality claim is made for the binary encoding.
* The direct-sum incidence construction adds one logical-size sector, has exact gap `1/2`, and does not use a clock, but row listing costs the row/column support of `V`.
* Uniform gate history has exact output scale `1/(T+1)` and gap `Theta(T^-2)`. The explicit geometric biased clock has constant clock gap, constant root-anchor overlap, but output scale below `2^-T`. General reversible path clocks obey the displayed endpoint mass/gap inequality.
* This is a Hamiltonian/image construction audit only. It does not alter a named MIP protocol, its question/answer alphabets, or a synchrony/conditional-linearity promise. No verifier resampling-gap theorem follows from these operator identities.

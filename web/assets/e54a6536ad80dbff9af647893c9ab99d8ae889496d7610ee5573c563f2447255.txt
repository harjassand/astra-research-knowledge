1. Exact question and interface

Let G be an unknown finite subgroup of Sym([n]), n>=1. A sampler returns iid uniform elements g_1,g_2,... of G, each exposed as its complete permutation on [n]. The learner may query the sampler and read all n images of each returned permutation. Let O_G be the partition of [n] into G-orbits, with r blocks. From m samples the learner must output O_G with error probability at most delta, for every finite G<=Sym([n]) and every 0<delta<1. The sampler is part of the interface; its internal cost is not free and must be charged separately if implemented rather than provided as an oracle.

The natural acquired representation is the orbit partition of H_m=<g_1,...,g_m>. It is reusable for every later task whose answer depends only on the fixed subspace of the permutation representation. For example, for x in Q^n or R^n, the Reynolds projection is

  (P_G x)_i = (1/|G|) sum_{g in G} (g.x)_i
             = (1/|O_G(i)|) sum_{j in O_G(i)} x_j.

The last identity follows because the map g -> g^{-1}(i) has fibers of size |G_i| over O_G(i). Thus the orbit partition is a sufficient reusable state for exact invariant linear projection. It does not determine G, its multiplication table, membership, arbitrary invariant polynomials, or tasks whose outputs depend on more than the fixed subspace.

2. Exact acquisition algorithm

Initialize a disjoint-set union (DSU) structure on [n]. For each sampled permutation g_t, union x with g_t(x) for every x in [n]. Return the DSU classes. Since each edge is undirected, inverse moves are included. The returned classes are exactly the orbits of H_m, so they refine O_G and can never merge two distinct true G-orbits.

All permutation images are scanned. With m samples the input consists of mn point images, each encodable in ceil(log_2 n) bits. Streaming DSU uses O(n) working words and O(m n alpha(n)) word operations; retaining all sampled permutations costs m n ceil(log_2 n) bits. The code is a fixed generic algorithm, not a task-specific synthesized program. A later vector projection costs O(n) additions/divisions and O(n) output entries; exact rational bit complexity depends on input bit lengths. Storing the partition costs O(n log n) bits (or O(n) machine words). Producing a dense n-by-n projector instead would itself cost Theta(n^2) output.

3. Universal orbit-acquisition theorem and proof

Theorem. Fix G<=Sym([n]) and let its true orbits be Omega_1,...,Omega_r. Let H_t=<g_1,...,g_t>, where the g_i are iid uniform in G, and let k_{j,t} be the number of H_t-orbits contained in Omega_j. Put

  X_t = sum_{j=1}^r (k_{j,t}-1).

Then, for every t>=0,

  E[X_t] <= (n-r) 2^{-t},
  Pr[ DSU output after t samples differs from O_G ] <= min{1,(n-r)2^{-t}}.

Consequently, if r is known, m=ceil(log_2((n-r)/delta)) samples suffice when n>r; if r=n, zero samples suffice. Without knowing r, m=ceil(log_2(n/delta)) is a uniform sufficient bound. The sample bound is independent of |G| and of any stabilizer profile.

Proof. Condition on all samples through time t and fix a true orbit Omega of size N, presently split into k H_t-orbits B_1,...,B_k. Add a fresh uniform g in G. Form the quotient multigraph Q on these k old components, adding an edge between the components containing x and g(x), for every x in Omega. Its connected components are exactly the H_{t+1}-orbits: old-component paths are H_t moves, and added edges are g moves; conversely every word in H_t and g^{+-1} gives a path in Q.

For each B_i let I_i be the indicator that B_i is incident to at least one cross-edge of Q, and let q=sum_i I_i. Pick any fixed x_i in B_i. Transitivity of G on Omega makes g(x_i) uniform on Omega. If g(x_i) is outside B_i, the edge {x_i,g(x_i)} is a cross-edge. Therefore

  E[I_i | current partition] >= Pr[g(x_i) notin B_i] = 1 - |B_i|/N.

Summing over every component, including a possible component larger than N/2, gives

  E[q | current partition] >= sum_i (1-|B_i|/N) = k-1.

In Q, the q nonisolated vertices lie in connected components of size at least two. If c is the number of those connected components, c<=q/2. The number of components merged is k-k' = q-c >= q/2, where k' is the number of H_{t+1}-orbits in Omega. Hence

  E[k'-1 | current partition]
    = k-1 - E[k-k' | current partition]
    <= k-1 - (1/2)E[q | current partition]
    <= (k-1)/2.

Sum over the true orbits. No independence between orbit-level changes is needed: linearity of conditional expectation gives E[X_{t+1}|history]<=X_t/2. Iterating and using X_0=sum_j(|Omega_j|-1)=n-r gives E[X_t]<=(n-r)2^{-t}. DSU is correct exactly when X_t=0. Since X_t is a nonnegative integer, Pr[X_t>0]<=E[X_t]. This proves the claim. QED.

The argument is uniform over all finite permutation groups, including intransitive actions. It uses only uniformity of g(x) within each true orbit; it does not assume the random samples are independent across different orbits (they are the same sampled group element).

4. Sharpness of the one-step potential and sample-order lower bound

For the regular action of G=(C_2)^d on itself, n=2^d. After t samples whose span has rank a, H_t-orbits are the 2^{d-a} cosets of that span. Write k=2^{d-a}. The next uniform sample is zero in the quotient with probability 1/k, leaving k components; otherwise it is nonzero and pairs all k cosets, leaving k/2 components. Thus

  E[k_{t+1}-1 | k_t=k]
    = (1/k)(k-1) + (1-1/k)(k/2-1)
    = (k-1)/2.

So the theorem's half-contraction is attained exactly at every state of this family. Moreover, m samples recover the single true orbit by generating all of C_2^d. For m<d this is impossible for the sampled-subgroup method. For m=d+s, s>=0, the exact full-rank probability is

  Pr[rank=d] = product_{j=s+1}^{s+d} (1-2^{-j}),

so the failure probability is at least 2^{-(s+1)} (the product is at most its first factor). A confidence requirement failure<=delta therefore forces m>=d and, when delta<1, m>=d+log_2(1/delta)-1 up to integer rounding. The uniform upper bound for this action is ceil(log_2((2^d-1)/delta)), which matches the lower bound to an additive constant. This lower bound is for recovery through the sampled generated subgroup; it is not asserted for a learner given extra prior metadata identifying the group family, nor is it a minimax lower bound over every possible estimator without a separately specified unknown-group prior/access model.

5. Matched baselines and end-to-end costs

The fair strongest baseline is ordinary orbit computation on the observed generators: it builds precisely the Schreier graph edges x--g_t(x) and takes connected components. DSU is that established algorithm. It has the same sample information, representation, preprocessing, memory, and O(m n alpha(n)) cost. A standard BFS traversal of all generator edges is also O(mn) and computes the same partition. Therefore the theorem establishes a uniform sample guarantee with an exact tail bound, but no computational or sample advantage over ordinary acquired-generator Schreier computation.

A raw-retention baseline can store all m permutations and recompute the orbit partition before each task, costing O(mn alpha(n)) per task; compiling and retaining DSU labels saves that avoidable repeated work. This is not a valid capability separation: a competent raw-data algorithm can cache the same partition after its first pass, with the same O(n) state and the same acquisition cost. Likewise an ordinary program synthesizer seeing the same samples can emit this fixed DSU program, so no synthesis advantage follows. For T vector-projection tasks the cached standard baseline and the compiled representation both cost O(mn alpha(n)+Tn) operations, plus sampler cost; the former can keep the same partition state. Merely comparing against a deliberately stateless baseline would misattribute the gain.

The sampler cannot be treated as free in an end-to-end theorem. Under the declared black-box interface the theorem charges m sampler calls and mn returned images, but not the internal mechanism for producing uniform G-elements. If uniform samples are obtained from a supplied generating set through permutation-group data structures, that generation cost must be added. No experiments were needed or run; this is an exact analytic result about a finite algorithm.

6. Prior-art comparison (primary sources, live-checked)

(a) Heidi E. Dixon, Matthew L. Ginsberg, Eugene M. Luks, and Andrew J. Parkes, “Generalizing Boolean Satisfiability II: Theory,” Journal of Artificial Intelligence Research 22 (2004), 481–534, DOI 10.1613/jair.1555, primary PDF https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume22/dixon04b.pdf. Proposition 4.8 and its appendix proof (PDF pp. 499 and 517; extracted source lines 837–846 and 1619–1649) take a transitive group action on d clause instances and iid uniform group elements, then prove an expected-orbit recurrence with factor 3/4, giving O(log d) random generators at fixed error. The authors cite O(v^2) cost per random element for their group data structure and note a Monte Carlo verification issue when the instance set may be exponential. This is direct prior art for random acquisition of a smaller subgroup preserving an orbit/instance class. The present elementary point-uniformity sum improves their displayed 3/4 potential factor to 1/2 and makes the delta dependence explicit for an explicitly represented action. The proof is a sharpening of their scaffold, not evidence of a new capability.

(b) Luca Sabatini, “Random Schreier graphs and expanders,” arXiv:2105.06378v3 (9 May 2022), later Journal of Algebraic Combinatorics 56 (2022), 889–901; primary source https://arxiv.org/html/2105.06378 and PDF https://arxiv.org/pdf/2105.06378. Proposition 1 gives, for a transitive action on Omega and epsilon,delta>0, a random multiset of size ceil((ln 4/epsilon^2) ln(2|Omega|/delta)) whose symmetrized Schreier graph has spectral parameter <epsilon with probability at least 1-delta (HTML lines 38–56). For any fixed epsilon<1 this implies connectivity, and so already gives the same O(log(|Omega|/delta)) orbit-acquisition order; its spectral-expansion conclusion is stronger than mere connectivity. For a general action, apply this result to each true orbit and union-bound, still obtaining O(log(n r/delta)) and hence O(log(n/delta)) samples. The exact half-contraction theorem has a smaller explicit connectivity constant, but it does not compete with the stronger expansion guarantee.

(c) Dona and Sabatini, “The diameter of random Schreier graphs,” European Journal of Combinatorics 127 (2025), article 104164, DOI 10.1016/j.ejc.2025.104164; primary open PDF https://wrap.warwick.ac.uk/id/eprint/191743/1/1-s2.0-S0195669825000472-main.pdf. Their introduction explicitly records that Sabatini's result [15] implies O(log n) random elements generate a transitive subgroup with probability 1-o(1) (PDF lines 113–122). This corroborates that the logarithmic acquisition order is established; their own main theorem concerns improved diameter for larger sample counts.

7. Claim ledger, failure boundaries, and conclusion of this finite investigation

- Internally derived: the exact recurrence E[X_{t+1}|history]<=X_t/2, the tail bound (n-r)2^{-m}, and the exact tightness example for the one-step potential. The derivation is complete under the finite uniform-sampler/full-permutation interface above.
- Prior-source-reported and live primary-source verified: O(log n) random group samples yield orbit transitivity for a fixed transitive action, and random Schreier expansion is available at O(log(n/delta)) sample size. The exact quantitative statements and hypotheses are identified above.
- Candidate sharpening, novelty unresolved: the factor 1/2 and explicit bound improve the 2004 ZAP proof's displayed factor 3/4 and the constants of the spectral route for connectivity. A targeted search found these close antecedents; it was not an exhaustive novelty search. No priority claim is made.
- Not established: advantage over a competent raw-data or ordinary program-synthesis baseline; a new end-to-end computational or sample capability; acquisition when only black-box point queries are allowed but full permutations are not exposed; robustness to biased/non-independent samplers; reconstruction of G beyond its orbit partition; practical cost of uniform group sampling; experimental or external verification.

Sharp failure cases: for n>=2 and m=0, no uniform guarantee is possible over all unknown G because the identity group and a cyclic transitive subgroup of Sym([n]) have different orbits. The stated bound uses n-r for fixed G and n for a uniform choice of m. If samples are not iid uniform, the central identity Pr[g(x) in B]=|B|/N can fail and the proof does not apply. If the task depends on more than the orbit partition, exact projection transfer is not justified. If the action is only implicitly evaluable over exponentially many points, the bound remains probabilistic but the DSU implementation may be computationally infeasible.

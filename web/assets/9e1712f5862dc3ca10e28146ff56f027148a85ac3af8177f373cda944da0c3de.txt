3. INDEPENDENT PROOF OF STRICT VALUE LOSS
First consider a synchronous strategy. Its tracial binary PVMs give reflections
X0,X1,Xz. A perfect equality on q0-z means (X0-Xz)|tau>=0; a perfect equality on
q1-z means (X1-Xz)|tau>=0; perfect inequality on q0-q1 means
(X0+X1)|tau>=0. Together these imply 2X0|tau>=0, contradicting ||X0|tau>||=1.
Quantitatively the three conditional errors e0,e1,e01 obey
  1 <= sqrt(e0)+sqrt(e1)+sqrt(e01),
so e0+e1+e01>=1/3. Since every corresponding pair has mass >=1/1024, the
synchronous value is at most1-1/3072. This proof was frozen independently.

For an arbitrary commuting strategy use the four ordered pairs
q0-z, z-z, z-q1, q0-q1. Let A0,Az,Bz,B1 be binary projective reflections and psi
the shared unit vector. Let e1,e2,e3,e4 be conditional errors. Then
  ||(A0-Bz)psi||=2sqrt(e1), ||(Bz-Az)psi||=2sqrt(e2),
  ||(Az-B1)psi||=2sqrt(e3), ||(B1+A0)psi||=2sqrt(e4).
Their vector sum is 2A0 psi. Triangle and Cauchy-Schwarz imply
  1 <= sum_i sqrt(e_i), hence sum_i e_i >=1/4.
Thus total loss >=1/4096. This is uniform over all Hilbert spaces.
Binary POVMs cause no restriction: for any self-adjoint contraction C, the
reflection C tensor Z + sqrt(I-C^2) tensor X dilates it on one ancilla. Use
independent Alice/Bob ancillas in |0>, preserving all cross-player commutators
and every pair correlation. This supplies the projective reduction explicitly.

After freezing, the originating worker's sharper bound was checked directly:
  S=<A0 Bz>+<Az Bz>+<Az B1>-<A0 B1> <=2sqrt(2).
Indeed write S=<A0 psi,(Bz-B1)psi>+<Az psi,(Bz+B1)psi>, apply Cauchy-Schwarz,
and use the parallelogram identity and norms of contractions <=1. Therefore the
four errors sum to at least2-sqrt(2), and
  omega^co(G_D) <= 1-(2-sqrt(2))/1024 <1.
The original value is one. This disproves Lemma5.11 perfect completeness and
also its printed near-perfect-value implication as epsilon tends to zero.

The failed proof gate is explicit: on a mixed parsed/unparsed pair only the
unparsed party returns the fixed answer. The other party keeps its original
measurement. An equality fallback imposes an additional correlation condition
which oracularizability does not supply.

4. CONDITIONAL GENERAL REPAIR WITH EXACT VALUE
Keep the sampler and answer set. Use the original predicate on nontrivial pairs;
on all other full question pairs, require equality only when x=y and accept
automatically when x!=y. Put the full diagonal first in a formal definition,
since the original synchronous predicate agrees with it on nontrivial diagonals.

The abstract repair theorem needs these precise premises:
(i) an injective canonical embedding phi of original questions into new wires;
(ii) on sampled wires, BOTH endpoints are canonical iff the shared seed event
E_nt occurs (single canonical endpoints on trivial seeds are permitted);
(iii) conditioned on E_nt, the canonical decoded pair has exactly the original
question-pair distribution; set rho=P(E_nt)>0.
Recognition can use the canonical prefix; testing membership in an exponentially
large body-map range is unnecessary on actual samples. Source padding and type
serialization must implement (i)-(iii); they were fully verified in the fixture.

For any original strategy, place its measurements on canonical wires and use
the same fixed existing answer on every inactive wire. Every trivial off-diagonal
pair is accepted. On a trivial diagonal both sides are inactive by (ii), so both
return the fixed answer. Thus the extension's score is 1-rho+rho times its old
score. Conversely every target strategy restricted to canonical wires is a legal
original strategy; the trivial branch contributes at most1-rho. Taking suprema:
  omega^t(G_R) = 1-rho+rho omega^t(G), for t=*,co.
This proof applies even when the original optimum is unattained or below one.
The same construction preserves global synchronous strategies. For any supplied
oracularizable strategy, positive canonical/canonical pairs are original pairs;
every other positive pair has a scalar endpoint. Hence within-algebra
oracularizability is preserved too, with the same state and original algebra.

The source conditioning proof instead supports the usual upper soundness bound
  omega^t(G_D) <=1-rho(1-omega^t(G))
even for its unrepaired predicate; the printed implication reverses its direction.
With rho>=1/(4t^2 16^t), the repaired game has soundness loss >=original_loss /
(4t^2 16^t). No general near-perfect lower implication with that denominator
follows from a LOWER bound on rho.

5. CROSS-AUDITED SAMPLER GAP AND LEVEL COUNT
See CROSS_AUDIT_ADDENDUM.txt for the full covariance proof. Under the intended
processed-prefix sampler, U_A=(s0,s1) and U_B=(s2,s3) are independent uniform
private selectors; R=(s4,s5,old_seed) is the remaining independent shared seed.
The entire Alice wire is a function of (U_A,R), Bob's of (U_B,R). If one's first
prefix is invalid, every later/shared/body output is zero and its entire wire is
a function only of its own private selector. First-prefix validity is locally
recognizable. Its common probability q is at most2^-t, since for any type word
exactly one of the2^t neighbor-mask words can be valid.

For centered local functions a(X),b(Y), branchwise mean cancellation yields
  E[a b]=q^2 Cov_ordinary(a,b),
and marginal variances dominate q times their ordinary conditional variances.
Consequently maximal correlation is <=q. For P=(P_X+P_Y)/2, where P_X,P_Y are
conditional expectation projections on the pair law, this implies
  gap(I-P) >=(1-q)/2 >=(1-2^-t)/2 >=1/4.
The fixture has q=1/4 and hence gap>=3/8. This certificate concerns the actual
wire law, not a supplied expansion hypothesis for the old body sampler. It is
independent of the predicate and independent of canonical/nontrivial recognition.

Therefore repaired detyping itself requires no NEW anchoring stage to meet L02's
gap premise. It already uses k+2 CL levels, and r independent copies stay at k+2
by parallel composition. All honest states/measurements may be tensor repeated.
Use of the L02 exponential bound remains conditional on L02's validity. No gap
certificate is asserted for later answer-reduction compositions which may carry
an additional old shared register outside this erasure mechanism.

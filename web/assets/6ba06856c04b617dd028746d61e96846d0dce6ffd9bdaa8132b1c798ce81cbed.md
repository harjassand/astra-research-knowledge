## Derivation notes

* For a coherent state with amplitudes \(\alpha_a,\alpha_b\) and phase \(U_\phi=e^{-i\phi J_z}\), coherent output amplitudes after equal pure loss are \(\beta_{a,b}=\sqrt\eta\alpha_{a,b}e^{\mp i\phi/2}\). Pure-state QFI is \(4\sum_j|\partial_\phi\beta_j|^2=\eta(|\alpha_a|^2+|\alpha_b|^2)\). This holds for arbitrary amplitudes and any common coherent superposition across the two arms.
* A positive-\(P\) state is a probability mixture of multimode coherent states. QFI convexity upper-bounds its QFI by the P-average of the coherent QFIs. For a correlated mixture across \(m\) copies, each global coherent component has QFI equal to \(\eta\) times its total signal photon number, so the same bound holds at fixed mean total energy.
* For \(|\mathrm{NOON}_2\rangle\), loss-free local QFI is \(4\operatorname{Var}(J_z)=4\). Equal pure loss leaves the phase-sensitive coherence only in the two-survivor sector, whose phase-independent weight is \(\eta^2\); one-survivor and zero-survivor sectors are phase independent. Therefore output QFI is \(4\eta^2\).
* A balanced analyzer maps the no-loss branch to count probabilities \(p_{20}=p_{02}=\cos^2\phi/2\), \(p_{11}=\sin^2\phi\). Their classical Fisher information equals 4. Equal detector loss commutes through this passive analyzer and is already included in \(\eta\); both output modes need number-resolving detection to label the two-photon sector.

The primary sources establish that this is an established optical-metrology regime; they do not validate any Astra claim or settle preparation-energy costs for a real NOON apparatus.

# Adversarial examples and failed interpretations

## A. Pooled D1/D2 cross-odds create a false ~10-fold H/C interaction

Use two physical tags in D1 with copy weights `c=(1,10)`. Let true per-copy CENP-A occupancy be `(1,epsilon)` and H3K9me3 occupancy `(epsilon,1)`, while a one-copy D2 tag has both marks equal to 1. With `epsilon=0.001`, raw pooled ChIP is:

- D1 H3K9me3: `1*0.001 + 10*1 = 10.001`;
- D1 CENP-A: `1*1 + 10*0.001 = 1.010`;
- D2 H3K9me3/CENP-A: `1/1`.

Therefore the pooled `D1:D2` H/C cross-odds is `10.001/1.010 = 9.90198`, even though the *equal-tag per-copy mean* is `(epsilon+1)/(1+epsilon)=1`. Shared DNA-copy factors do not cancel inside pooled sums. This is exactly the adversarial example embedded in `code/phase_allocation_metric.py`.

## B. Stable copy factors do cancel tagwise; changed copy mixture does not

For a single position code `i`, write `Y_{m,p,i}=s_{m,p} b_{m,i} c_{p,i} theta_{m,p,i}`. If `b_{m,i}` and `c_{p,i}` are invariant across phase for that code, the same-code fold cancels both. The D1-minus-D2 log mean cancels `s_{m,p}/s_{m,0}`. This remains true with arbitrarily different copy number between codes/domains.

If a tag has two unresolved physical copies `k=1,2`, the actual mean is `Y_{m,p,i}=s b_i sum_k c_{i,k,p} theta_{m,i,k,p}`. A fixed number of copies is not enough: if `theta` differs by copy and phase changes their relative contribution or clone abundance, the sum cannot be factored into one fixed `c_i` times a per-copy occupancy. One genomic-DNA sample or one partial assembly does not fix this. Condition-matched input DNA and complete structure plus copy-aware molecule-resolved mark reads are needed to bound it.

## C. Bulk phase snapshots can alias within-cell motion and changing mixture

Suppose two stable HAC-bearing subpopulations have different per-code states `(theta_A,b_A)` and `(theta_B,b_B)`. A bulk assay reports `Y_p = s_p[lambda_p theta_A + (1-lambda_p)theta_B]`. Changing `lambda_p` across separately synchronized culture aliquots can move the per-tag profile even if no cell changes chromatin state. Conversely, a homogeneous population with within-cell state changes can produce the same marginal profile. Without same-cell joint chromatin measurements and clone/structure tracking, those mechanisms are observationally indistinguishable from the PC tables.

This does not mean selection occurred; it means it is not excluded by the available assay. A common scalar change in HAC-positive fraction would cancel in the tagwise D1-minus-D2 contrast, but code-specific composition or structural states would not.

## D. Two distinct dynamic mechanisms interpolate the available endpoints

For each observed H3K9 profile `h(t)` over the barcode positions, consider `h_dot = D Lh + r(t)`, where `L` is any chosen spatial neighbor operator. Given any endpoint-interpolating path and any nonnegative diffusion/spreading parameter `D`, choosing the unmeasured recruitment/replication forcing `r(t)=h_dot−D Lh` yields exactly that path. Thus the same measured endpoints are compatible with `D=0` (no propagation) and `D>0` (spatial propagation). The phase-labelled samples are not a repeated trajectory of one clone, so no current endpoint puts a useful bound on the local forcing term. This explicit alias defeats a claim of inferred wave speed or replication-age lag.

## E. Independent failure axes are not interchangeable

1. Structural deletion/rearrangement can erase or alter the HAC while CENP-A intensity in surviving cells remains high.
2. One intact HAC can have two CENP-C/KNL1 foci and a dicentric-like segregation problem while retaining substantial CENP-A signal.
3. One CENP-C focus can still missegregate due to replication-fork defects, kinetochore assembly, cohesion, attachment, or checkpoint failure.
4. Selection can enrich faster-growing HAC-negative cells and mimic an increased chromosome-loss rate.

Therefore CENP-A/H3K9 ChIP, structural state, kinetochore multiplicity, and HAC segregation must be measured as separate outcomes. A generic per-division loss hazard fitted to a selected culture does not resolve these mechanisms.

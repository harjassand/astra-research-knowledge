1. Constant-kernel gauge proof compares exact PRINCIPAL coefficients. The
Fdelta perturbation changes two full complementary minors and one pair
partition, giving Zfull=2delta^2. The fixed-auxiliary Schur reduction requires
rank-one entry of each physical variable and a nonzero top coefficient. It
does not rule out arbitrary linear determinant circuits with cancellation.

2. Positive-mixture rank proof uses Hermitian kernels, nonnegative even
component coefficients, zero odd component coefficients and exact target
zeros. Removing any of these hypotheses would invalidate the zero/rank
inference. The block witness's scalar counting remains easy.

3. The coefficientwise-approximation obstruction explicitly preserves zero
coefficients. Its entropy lower bound is not extended to absolute error,
generic coherent Gaussian approximation or scalar-only counting.

4. Low-rank transfer uses F=UV^T, with no conjugation in this factorization.
Terminal indices are(A,B,A,B); using a different diagonal would compute a
different quantity. The cached suffix uses algebraic transpose, because
its dual contraction is bilinear. Exact factorization and optional dense
off-diagonal rank-one diagonal completion are acquired. General minimum-rank
diagonal completion is unresolved, and Fdelta's rank-two completion is a
supplied/verified fixture rather than a general discovery algorithm.

5. Low-rank storage O(16^r) is for counting. The delivered cached sample uses
O(n16^r) storage to attain O(n r^2 16^r) field work. The old recomputation
sampler keeps the smaller counting-storage bound but costs quadratic n.
Gaussian elimination/input costs and polynomial bit sizes are additional.
Rank r<=C log n is a fixed-constant admitted regime; k<=r is a real limitation.

6. Bandwidth transfer uses ACTUAL conjugate transpose for density gates.
The two creators' Jordan-Wigner strings cancel on previously traced sites.
All gates incident on a site occur before its trace; creation alone cannot
remove double occupancy. The induced norm equals determinant-square weights.
The h counter tracks traced row number and therefore correctly selects the
canonical sector. Bandwidth is acquired in the supplied order; ordering
optimization is not an oracle. The delivered sampler recomputes transfers,
and its operation bound is cubic n in the all-sector worst case.

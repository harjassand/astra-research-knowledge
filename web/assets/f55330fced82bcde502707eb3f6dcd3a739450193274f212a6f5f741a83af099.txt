INDEPENDENT POST-EXPOSURE LEMMA: POSITIVE TAYLOR GATES OF ANY DEGREE

This is a post-exposure derivation prompted by separating local gate error
from the Strang splitting error. It is not part of the frozen independent
INITIAL and is not evidence of pre-exposure priority.

Let p_r(x)=sum_{k=0}^r x^k/k!, with integer r>=1, and let s>=0 be rational.
For every admitted edge or field generator A_i, the finite matrix p_r(sA_i)
has rational, entrywise nonnegative coefficients and stays in the same local
homogeneous log-concavity cone.

For an edge, its three nonnegative eigenvalues are
  ell=alpha-gamma <= m=3alpha+gamma <= h=5alpha-gamma.
The table of p_r(sA_e) is six-vertex with
  a=p_r(sm), b=(p_r(sh)+p_r(sell))/2,
  c=(p_r(sh)-p_r(sell))/2.
Since p_r is nonnegative and increasing on [0,infinity),
  p_r(sell)<=a<=p_r(sh).
Thus c>=|a-b|. Also b-c=p_r(sell)>=0, hence c<=b<=a+b.
The six-vertex Hessian eigenvalues are a+b+c, a-b-c, -a+b-c,
-a-b+c, so exactly one can be positive. This proves the homogeneous
quadratic gate is log-concave, including gamma=+/-alpha and alpha=0.

For a field, A_v=[[r+c,b],[b,r-c]] is PSD and entrywise nonnegative, where
r=b+|c|. The matrix p_r(sA_v) is entrywise nonnegative by its positive
coefficient expansion. Its eigenvalues are p_r(s lambda_+),p_r(s lambda_-)
with lambda_+>=lambda_->=0, and are strictly positive because p_r(x)>=1
for x>=0. Hence, writing its entries as [[v,d],[d,u]], we have d>=0 and
uv-d^2=det p_r(sA_v)>0. Its rational two-dummy lift
  d z_1 z_2 + (u/2)x(z_1+z_2) + (v/2)y(z_1+z_2) + dxy
is log-concave: for d>0, the Hessian's (x,y) block has inertia (1,1), and
the Schur complement on (z_1,z_2) has eigenvalues -d and (d^2-uv)/d,
both nonpositive. If d=0 the polynomial factors as
(z_1+z_2)(ux+vy)/2. All stored coefficients remain rational; the square
root used to diagonalize the field matrix is proof-only.

Exact finite checks are in arbitrary_taylor_lc.py. Fraction arithmetic
confirmed the displayed matrix/table identities and cone inequalities on

zero gates and both anisotropy boundaries. This tests only those fixtures;

SEPARATING GATE ERROR FROM PRODUCT ERROR

For x>=0 the Taylor tail satisfies
  0 <= e^x-p_r(x) <= e^x x^(r+1)/(r+1)!.
Set h=beta/(2m), D=sum_i ||A_i||, tau=beta D, and assume m>=4tau, so
2hD=tau/m<=1/4. Let F_i=p_r(hA_i), E_i=e^(hA_i),
V_F=F_1...F_p, V_E=E_1...E_p, B_F=V_F V_F^*, and B_E=V_E V_E^*.
Both B_F,B_E are >=I. Telescoping the products and using
sum_i ||A_i||^(r+1)<=D^(r+1) gives
  ||V_F-V_E|| <= exp(hD) (hD)^(r+1)/(r+1)!.
Since ||V_F||,||V_E||<=exp(hD),
  ||B_F-B_E|| <= 2 exp(2hD) (hD)^(r+1)/(r+1)!.
For positive X,Y>=I the integral resolvent formula gives
||log X-log Y||<=||X-Y||. Thus replacing the exact exponential factors in
the palindromic layer by rational p_r gates adds at most
  2 exp(tau/m) m (tau/(2m))^(r+1)/(r+1)!
to the full log-generator error after m layers.

The exact exponential palindromic product already has the generic
second-order bound O(tau^3/m^2) from its degree-two cancellation. Taking
r>=3 makes the local Taylor contribution lower order in 1/m; for example,
r=4 makes it O(tau^5/m^4). This cleanly isolates the Strang error and uses
fixed-degree rational gate entries, so the variable count and gate-count
exponent are unchanged. It may reduce constants; it does not improve the
asymptotic m=Theta(tau^(3/2)/sqrt(epsilon)) barrier without a sharper
commutator/locality argument. That stronger step remains unproved here.

For bit accounting, if input and rational step numerators/denominators have
at most L bits, a degree-r local matrix entry can be computed with O(r)
constant-size rational matrix operations and has O(r(L+log m+log(r+1)))
bits, with a coarse bound allowing unreduced intermediate fractions. A
product coefficient oracle multiplies O(mp) selected local entries; its
output length is therefore O(mp*r*(L+log m+log(r+1))). The homogeneous
signature still has degree two in its four variables (the polynomial degree
r is only in the scalar gate parameter), so the lifted ground-set size is
still N=8mp. The imported counting core remains
O(N^10 B^2 eta^-2 log^2(2B/eta)), with B=N+log(R_P R_Q); local oracle
construction contributes O(mp*r) rational operations per call and all
integer arithmetic must be charged using the stated polynomial operand
length. For a fixed r such as 4, this adds only a constant-factor local
compiler change, while the full FPRAS is still not implemented.

# Family 139 → Bayesian enzyme-kinetic posterior: transfer audit

## Verdict

The pinned family-139 result gives a sharp *conditional* sampling service for a smooth, globally well-conditioned log-concave posterior. It does not make ordinary enzyme-kinetic posteriors satisfy those hypotheses. The usable bridge is exact: if, in chosen unconstrained coordinates, the posterior has a supplied mode z* and a supplied/proved SPD matrix G such that G ≼ ∇²U(z) ≼ 2G globally, then the affine map z = z* + G^(-1/2)x puts the normalized potential in the release class. The released sampler then uses at most Cε d^ε exact value-and-gradient queries, with TV error at most 0.1, for each fixed ε>0.

A two-parameter Michaelis–Menten posterior with a proper Gaussian prior on log parameters gives a concrete obstruction to this transfer: its potential has negative curvature at an explicit point. Translation to its mode and any invertible affine whitening preserve the negative inertia, so no affine preconditioner can put that posterior in the required class. This is an analytic counterexample for a biologically standard rate law, not a claim that every enzyme posterior is non-log-concave. A nonlinear coordinate map might change the conclusion, but would need its own global Hessian certificate and correct density Jacobian.

Evidence status: theorem interface source-reported from the pinned primary manuscript; the preconditioner map is a conditional derivation; the counterexample is an internally checked exact calculation; enzyme-model context and the comparator are source-reported from primary applied literature. No independent full proof audit, posterior experiment, or external validation is claimed.

There is also a positive capability path for a narrower biochemical observation model: a two-state equilibrium binding/occupancy assay with balanced paired outcomes and a Gaussian prior can meet the theorem’s hypotheses exactly after prior whitening and a spectral design bound. It is a real biochemical observation model, but it is not a general enzyme-turnover or cell-signaling posterior, and its balanced high-dimensional data can be rare.

## Pinned theorem and exact oracle contract

The source is OpenAI, “Subpolynomial query complexity for well-conditioned log-concave sampling,” in the OpenAI math snapshot adc7f1241b42e322a6451854ab7e4b4c146bf78a, manuscript PDF under preprints/Subpolynomial-query-complexity-for-well-conditioned-log-concave-sampling-September-26-2026/. Its model is:

- Dimension d≥2. The unknown V is C² on R^d and satisfies V(0)=0, ∇V(0)=0, and I_d ≼ ∇²V(x) ≼ 2I_d for every x.
- The target is π_V(dx) proportional to exp(−V(x))dx.
- One exact adaptive query at x returns the entire pair (V(x), ∇V(x)). The algorithm receives no other information about V. Random real variables and unrestricted computation between queries are allowed.
- Theorem 1.1 claims that for each fixed ε>0 there is a finite constant Cε such that a measurable randomized algorithm uses at most Cε d^ε queries on *every execution* and returns a draw whose law is within TV 1/10 of π_V, uniformly over the class. The same theorem gives Q(d)≥c log d for all sufficiently large d, even for centered Gaussian quadratics.
- This is an oracle-query theorem. The manuscript expressly gives no arithmetic, representation, bit, or practical runtime bound; it does not imply polylogarithmic query complexity. The constants and approximation orders may depend on ε.

The origin is a supplied minimizer in the mathematical interface. The posterior mode, coordinate map, preconditioner, and proof of global curvature are not acquired for free by applying the theorem to chemistry. Likewise, the theorem’s one exact real query is not a declared count of model integrations, assay cost, or bits.

## Conditional map from an enzyme posterior

Let θ denote positive kinetic parameters and D the fixed observed assay data. Write the posterior potential, up to an additive constant, as

U_θ(θ) = −log p(D|θ) − log p_0(θ).

Choose a smooth bijection θ=ψ(z) from R^d to the parameter domain and define the density with respect to dz correctly. If p_0 is a density in θ, the transformed potential is

U(z) = U_θ(ψ(z)) − log|det Dψ(z)|.

If the prior was specified directly as a density in z (for example, Gaussian priors on log-rates), use that z-density directly and do not add a second Jacobian. A mode in θ coordinates need not remain a mode under a nonlinear change of density coordinates.

Suppose an exact minimizer z* of this transformed U is supplied, and suppose an SPD matrix G is supplied together with a global certificate

G ≼ ∇²U(z) ≼ 2G for every z∈R^d.

Set P=G^(-1/2), x=P^(-1)(z−z*)=G^(1/2)(z−z*), and define

V(x)=U(z*+Px)−U(z*).

Then V(0)=0, ∇V(0)=0, and
∇²V(x)=Pᵀ∇²U(z*+Px)P,
so congruence of the global inequalities gives I≼∇²V(x)≼2I. The oracle is implemented by
V(x)=U(z*+Px)−U(z*) and ∇V(x)=Pᵀ∇U(z*+Px).
Run the family-139 algorithm on x and return z=z*+Px, then θ=ψ(z). Invertible changes of variables preserve total-variation distance, so the posterior error remains at most 0.1.

More generally, a certified global sandwich mG₀≼∇²U(z)≼MG₀ works if M/m≤2: use P=(mG₀)^(-1/2). In the isotropic case mI≼∇²U≼MI, this requires M/m≤2 and P=m^(-1/2)I. A local Hessian at the mode is not enough; if it is used as a metric, one still has to prove a uniform relative bound aH*≼∇²U(z)≼bH* with b/a≤2 everywhere.

For positive rates with θ_i=exp(z_i), a density originally expressed in θ has transformed Hessian
∇²_z U = D_θ ∇²_θ U D_θ + diag(θ_i ∂_{θ_i}U)
when the only Jacobian correction is −Σ_i z_i. This extra diagonal term means “take logs, then whiten the likelihood Hessian” is generally not a valid curvature proof. If likelihood gradients are obtained by stochastic simulation, minibatching, Monte Carlo, or approximate ODE/adjoint solves, the result is not the theorem’s exact deterministic oracle. Fixed measured data and a fixed noise model can still define a deterministic posterior; measurement noise in the statistical model is different from noise in the numerical oracle.

The cost ledger for a successful conditional application is therefore: exact posterior value/gradient calls at transformed points; the chosen data, noise model, and parameterization; the mode z*; a global curvature certificate and matrix G; and the numerical work needed to implement each oracle call. The release charges only its first-order query count. It does not charge or bound finding the mode, discovering G, proving the global inequality, evaluating an ODE likelihood, storing precision, or producing assay data.

## Worked enzyme-kinetic counterexample to the affine bridge

Use the standard Michaelis–Menten rate law, with substrate and total enzyme concentrations both fixed to 1. Let φ=log K_M and ψ=log k_cat be the two unknown log parameters. The predicted rate is

μ(φ,ψ)=exp(ψ)/(1+exp(φ)).

Observe one rate y=1/10 with Gaussian error σ=1/10, and place independent N(0,τ²) priors on (φ,ψ), with τ=10. This is a proper smooth posterior on R². Its negative log density, ignoring constants, is

U(φ,ψ)=(μ(φ,ψ)−y)²/(2σ²)+(φ²+ψ²)/(2τ²).

At (φ,ψ)=(-log 3,0), μ=3/4,
μ_φ=−μ(1−μ)=−3/16, and
μ_φφ=μ(1−μ)(1−2μ)=−3/32.
For a squared-error likelihood,
U_φφ = [μ_φ² +(μ−y)μ_φφ]/σ² + 1/τ².
Substituting y=1/10 and σ=1/10 gives
U_φφ = [(9/256)−(39/640)]/(1/100)+1/100
      = −165/64+1/100
      = −4109/1600 < 0.

The Gaussian prior makes U coercive, so a global mode exists and can be supplied. But at the point above the Hessian has a negative Rayleigh quotient, hence a negative eigenvalue. Translating coordinates to the supplied mode merely relocates this point. For every invertible affine preconditioner P, the transformed Hessian is PᵀHP; Sylvester’s law of inertia preserves the negative eigenvalue count. Thus no affine rescaling or whitening can make this posterior globally satisfy I≼∇²V. This is a direct falsifier for the proposed “log transform plus mode plus affine preconditioner” route on this valid assay instance.

This does not rule out a specially designed nonlinear bijection for this one posterior, nor the possibility that a different dataset/prior happens to satisfy the condition. Such a rescue would need to preserve the posterior density (including Jacobian), provide the transformed mode, and prove a global Hessian sandwich. A finite grid of Hessian evaluations would not certify that global premise.

## Positive capability path: an exactly checkable two-state binding assay

Consider d≥2 standardized free-energy or log-affinity parameters z with prior z∼N(0,I_d). In setting j, a two-state equilibrium assay has bound probability p_j(z)=σ(b_jᵀz), where σ(t)=1/(1+e^(−t)). This is exactly the one-site occupancy law c/(c+K_D)=σ(log c−log K_D) for a single log-affinity coordinate; more generally b_jᵀz is the calibrated free-energy gap of a two-state system whose energetic contributions add linearly. Calibrate each setting so its log-odds is zero at the prior center.

At each setting j, observe two independent aliquots with outcomes one bound and one unbound. Let B be the matrix with rows b_jᵀ and m rows total. The posterior potential in whitened coordinates, after subtracting its value at zero, is

V(z)=½||z||² + 2 Σ_(j=1)^m log cosh((b_jᵀz)/2).

Indeed, the paired Bernoulli negative log likelihood is softplus(t)+softplus(−t), equal to 2 log 2+2 log cosh(t/2). Consequently V(0)=0 and

∇V(z)=z+Bᵀ tanh(Bz/2),
∇²V(z)=I + ½ Bᵀ diag(sech²(Bz/2)) B.

The paired outcomes cancel the likelihood score at zero exactly. Since sech²≤1, the global Hessian satisfies I≼∇²V(z)≼I+½BᵀB. Thus the spectral design certificate BᵀB≼2I proves I≼∇²V≼2I everywhere. The Gaussian prior supplies the lower curvature; the design bound limits the likelihood curvature. The Hessian is positive definite everywhere, so z*=0 is the unique global mode and is explicitly supplied. No mode search or nonlinear transform is needed after whitening.

There is a sparse, coupled design meeting this bound for every d≥2. Take B_d to have rows e_kᵀ for k=1,…,d and (e_k+e_(k+1))ᵀ/2 for k=1,…,d−1. If C_d has rows (e_k+e_(k+1))ᵀ, then B_dᵀB_d=I+¼C_dᵀC_d≼2I because ||C_d z||²=Σ_k(z_k+z_(k+1))²≤4||z||². The adjacent-coordinate rows create likelihood coupling, so the posterior is not a product in the stated z coordinates. Here m=2d−1 assay settings and 2m=4d−2 binary outcomes. More generally, any known design B with BᵀB≼2I works. In original parameters θ with prior N(μ,Σ), set z=Σ^(−1/2)(θ−μ); the exact criterion is Σ^(1/2)AᵀAΣ^(1/2)≼2I for the unwhitened log-odds design A.

This gives an exact mathematical application of family 139: V itself is in the released class, and the theorem returns a posterior sample with TV error at most 0.1 using at most Cε d^ε exact value-gradient queries on every execution. The value-gradient oracle is explicit; for sparse B_d, one evaluation of V and ∇V costs O(d) real arithmetic operations, including O(d) softplus/tanh evaluations. Reading the design and checking the balanced-pair condition also costs O(d). The ideal theorem still places no bound on its computation between queries, finite-precision error, transcendental evaluation, storage, or a physical implementation of the observation model. For a real assay one must pay for the 4d−2 binary measurements and calibration of the free-energy design; those are not counted as oracle calls.

The data condition matters. At z=0 every outcome has probability 1/2, so one given pair is balanced with probability 1/2. If the m pairs are independently collected, the probability all are balanced is 2^(−m) (or 4^(−m) for one prescribed order within every pair). The theorem is uniform over the resulting posterior once such data are observed, but this construction does not promise that a typical high-dimensional experiment yields the exact balanced dataset. It is a verifiable eligibility family, not evidence of frequent experimental occurrence or practical superiority. A matched computational baseline gets the same prior, B, outcomes, and exact posterior oracle; standard HMC/MALA is an obvious control, while the family-139 query theorem offers no wall-clock comparison. The more complicated Michaelis–Menten counterexample above shows why this positive special case cannot be generalized to arbitrary kinetic likelihoods.

## Primary prior art and equally informed controls

The Michaelis–Menten model and its identifiability caveat are reported in Gupta et al., “Evaluation of Parallel Tempering to Accelerate Bayesian Parameter Estimation in Systems Biology.” They give the rate equation and explain that product trajectories constrain k_cat and K_M while the individual forward and reverse rates are unidentifiable. In their synthetic three-parameter example with 1% Gaussian error, four-chain parallel tempering averaged 369 lowest-temperature MCMC steps to their convergence threshold versus 4203 for Metropolis–Hastings; counting four model integrations per PT step, the reported comparison is roughly 1476 versus 4203 model integrations. These are finite empirical results on their specified synthetic setup, not worst-case sampling bounds. In a 12-parameter calcium-signaling model, only a fraction of chains reached the global minimum within 500,000 steps, and the paper shows trapping at a local minimum. This is relevant prior evidence that multimodality and mode acquisition are real application gates, not a universal claim about every assay.

For the abstract smooth strongly-convex oracle setting, Chen, Chewi, Lu, and Zhang’s primary “Smoothed Picard Hamiltonian Monte Carlo” paper is close prior art. Its low-accuracy result has a d^(1/6)-type gradient-query dependence at fixed conditioning/accuracy in Wasserstein distance; its high-accuracy result has a distinct TV guarantee and includes a d^(1/4) term. Family 139 reports a d^(1/6) expected-query predecessor at fixed parameters and upgrades its own theorem to every positive dimension exponent with an every-execution cap. These bounds are not a fair direct comparison on the counterexample above, which is outside the shared convexity premise. For the actual nonconvex enzyme example, parallel tempering is a better information-matched applied baseline: both methods receive the same fixed data and evaluate the same model likelihood, and its model-integration cost is observable.

## Decision gate

The scientifically meaningful transfer statement is conditional: on an enzyme posterior with exact gradients, supplied transformed mode z*, and certified global G≼∇²U≼2G, family 139 yields a TV-0.1 sampler with at most Cε d^ε exact first-order calls for each fixed ε. None of those posterior conditions is established by the release or by the cited applied study. The worked example refutes a general affine-preconditioning claim and makes the unconditional chemistry transfer false.

The next decisive gate for any narrower application is to freeze one model, prior, dataset, and coordinate measure; supply the global mode and a candidate G; then either prove the global Hessian sandwich analytically or refute it with an exact negative-curvature witness. Only after that should one compare the full cost of each exact value/gradient call—including forward and sensitivity/adjoint solves—with matched parallel-tempering or other posterior samplers. If gradients are approximate, a separate theorem must control an integrable surrogate oracle and its target-law error; arbitrary stochastic gradients do not inherit family 139’s guarantee.

## Appendix A — retained N68 negative result (short)

N68’s card-level interface is one exact full-matrix query f(A₁,…,A_n)∈M_(2s)(Q) for an s-sparse noncommutative polynomial with no degree bound; the decoder recovers the polynomial exactly, with the complete rational response bit length charged. It is an algebraic exact-response oracle, not a pulse/assay shot oracle. At n=s=1 its prescribed A₁ has eigenvalue 2. A unitary pulse channel has spectrum on the unit circle, and a finite-dimensional CPTP channel has spectral radius at most 1; similarity preserves spectrum. So direct identification of that matrix with an ordinary physical pulse/channel map is impossible. This rules out that direct realization only; no indirect encoding is resolved here. The card and input/output summary are saved in work/agents/sparse_response_metrology/N68-card.txt; the cited proof package was absent from the pinned tree in the earlier retrieval, so this remains card-derived, not an independent theorem audit.

The assignment phrase “Gaussian postselection / sequential adaptive filtering / one terminal hard projection” has multiple plausible meanings. I use the fermionic Gaussian interface most directly connected to the cluster’s parity target: a fixed transcript of fermionic Gaussian linear maps, including one-mode occupation measurements, versus an orthogonal projection onto one global number or parity sector. Under that interface the three operations are distinct. If “one terminal hard projection” instead means any projector on any ancilla subspace, one of the adaptive examples below collapses to such a projector; I retain that limitation explicitly.

1. Two sequential Gaussian hard filters need not be one hard projection.

Use two fermion modes and Fock basis (|00>, |10>, |01>, |11>). Let P project onto the first mode being empty, so P=diag(1,0,1,0). Let U be the number-conserving Gaussian mode rotation that fixes vacuum and the filled state and acts on the one-particle space by [[c,-s],[s,c]], with c=3/5 and s=4/5. Let Q=U P U*, the projector that the rotated first mode is empty. P and Q are both single-mode occupation projectors and hence fermionic Gaussian filters. The accepted two-step Kraus map is K=QP.

Direct multiplication gives
  K* K = diag(1, 0, c^2, 0) = diag(1, 0, 9/25, 0).
This is not a projection and is not a scalar multiple of a projection: its nonzero eigenvalues are 1 and 9/25. Any single orthogonal hard projection R preceded by a Gaussian unitary V has Kraus map RV and (RV)*(RV)=V*RV, a projection; allowing one overall success-amplitude scalar still gives equal nonzero eigenvalues. Thus this sequential filter cannot be replaced, as a map, by one terminal hard projection after a Gaussian unitary. On the maximally mixed two-mode Gaussian input I/4, the normalized sequential output has nonzero eigenweights 25/34 and 9/34, whereas a single rank-two hard projection gives equal weights 1/2,1/2.

This sequence remains a Gaussian map under composition. It separates “a general Gaussian postselection map” from “one orthogonal projection after a Gaussian unitary”; it does not separate the sequence from the broad Gaussian-map class. If the proposed terminal operation may include a nonunitary Gaussian filter before its hard projection, this particular nonfactorization target must be strengthened or narrowed.

2. Adaptive filtering can produce a mixed state in several number and parity sectors.

Take two ancilla modes a1,a2 and two data modes b1,b2 in the normalized Gaussian pair state
  |Psi> = (1/2)(1+a1* b1*)(1+a2* b2*)|0>,
where stars here denote fermionic creation operators. Measure occupation of a1. If a1=0, measure a2 and keep only a2=0. If a1=1, accept immediately and discard the unmeasured second pair. Each step is a one-mode fermionic Gaussian measurement. The accepted probability is 1/4 from the first branch plus 1/2 from the second, hence 3/4. After tracing the ancillas and forgetting the accepted transcript, the normalized data state is
  rho = (|00><00| + |10><10| + |11><11|)/3.
Each accepted transcript leaves a Fock state, hence a Gaussian pure branch. The coarse-grained output is not Gaussian: <n1>=2/3, <n2>=1/3, and <n1 n2>=1/3, while all cross normal and anomalous two-point functions vanish. Wick factorization for a Gaussian state would give <n1 n2>=<n1><n2>=2/9, a contradiction. The total-number probabilities are (1/3,1/3,1/3) for N=0,1,2, and even/odd parity probabilities are (2/3,1/3). So this output is not supported on one fixed number or parity sector and is not one Gaussian branch.

Caveat: this adaptive acceptance event is exactly equivalent to the single joint ancilla projector P(a1=1) tensor I + P(a1=0)P(a2=0), followed by tracing the ancillas. Therefore it does not distinguish sequential timing from an unrestricted terminal projector on an arbitrary ancilla subspace. Its precise separation is from one fixed-charge/parity projection on the retained data and from one fixed Gaussian transcript.

3. A single terminal hard number projection can leave the Gaussian class.

For four fermion modes c1,...,c4, the normalized BCS Gaussian state
  |Omega_lambda> = (1+lambda^2)^(-1) exp(lambda(c1* c2* + c3* c4*))|0>
expands as (1+lambda^2)^(-1)(|0> + lambda|12> + lambda|34> + lambda^2|1234>). Its probability of total number two is 2 lambda^2/(1+lambda^2)^2 (equal to 1/2 at lambda=1). A single terminal number-two projection produces (|12>+|34>)/sqrt(2). As a two-form omega=e1 wedge e2 + e3 wedge e4, it satisfies omega wedge omega=2 e1 wedge e2 wedge e3 wedge e4 !=0, so it is not decomposable and is not a two-particle Slater determinant. A pure fixed-number fermionic Gaussian state is a Slater determinant; this projected state is therefore non-Gaussian. This gives the reverse separation: global hard number projection can create a state unavailable from a single Gaussian-operation branch. It does not imply hardness of sampling or preparation.

Prior source and interface. Bravyi, “Lagrangian representation for fermionic linear optics,” arXiv:quant-ph/0404180, Theorem 1 and Sections V, VII–VIII, treats Gaussian maps, single-mode occupation projectors, and preservation of Gaussian states under FLO operations. This is established prior art, not a new claim. The exact gadgets above are derived directly. The prior campaign’s hard-BCS reports already separate number projection from the general determinant-weighted parity counting problem; see work/cycle4/hard_bcs_counting_attack.txt and work/cycle5/stable_parity_exchange.txt. Costs and boundaries. The first gadget has two modes, two one-mode filters, and exact rotation entries 3/5 and 4/5. The second has four modes, at most two occupation measurements, and acceptance 3/4. The third has four modes and terminal event probability 1/2 at lambda=1. All coefficients and checks are exact; there is no rare-event, precision, solver, or oracle cost. These examples do not establish approximation hardness, a limit for arbitrary non-Gaussian Kraus maps, or a result for arbitrary-subspace terminal projection. The term “arbitrary Gaussian postselection” must be defined: a fixed transcript of Gaussian maps is covered by Bravyi’s closure, while global fixed-N projection and coarse-graining of adaptive branches are different operations.

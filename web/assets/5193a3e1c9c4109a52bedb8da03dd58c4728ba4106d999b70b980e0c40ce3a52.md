## Gate before promoting any phase-control or stability claim

1. Resolve the actual HAC clone's complete/near-complete structure and map each PC multiplicity; obtain phase-matched genomic DNA from each ChIP aliquot.
2. Show the corrected `log2(Phi)` result replicates across independent cultures/clones with biological uncertainty measured, not just mapped-read uncertainty.
3. Map local replication-completion times in the same 2-kb codes and collect within-cycle time points, with single-cell or lineage evidence to distinguish within-cell state changes from clone/cell-mixture shifts.
4. Test D1-only, D2-only, and both-core HJURP/KAT7 recruitment against equal-dose early- and late-G1 controls. Keep outer H3K9me3 boundaries intact and measure both core marks and flanks.
5. Measure functional kinetochore multiplicity (CENP-C plus KNL1/NDC80 per HAC) independently of CENP-A intensity; measure HAC structural integrity and segregation as separate endpoints under selection-free passage.
6. Hold out a clone or a later time point. A model must predict spatial changes and the joint `structure intact / one functional kinetochore / segregation` outcome before it is promoted.

Stop or revise the model if core pulses alter only bulk intensity, if multi-domain foci appear, if structural breaks account for apparent loss, if a matched late pulse performs as well as the early pulse, or if the model fails held-out positions/timepoints. Do not fit a generic loss hazard and label it mechanism.

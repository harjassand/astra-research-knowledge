1. EXACT MIXED H BOUND
---------------------
Fix i, write c=c_i, M=M_i, and Q_i=Q(c-e_i). Terms whose other cofactor
coordinates are below their orders contribute zero to both Q and Q_i. For
every remaining active monomial with coordinate order nu<=M and c>=nu,

  phi_j(c-e_i)/phi_j(c)=(c-nu)/c,
  phi_j(c)-phi_j(c-e_i)=(nu/c)phi_j(c).

If c>M, each active term has c>nu and

  phi_j(c)-phi_j(c-e_i)
       = [nu/(c-nu)] phi_j(c-e_i)
       <= [M/(c-M)] phi_j(c-e_i).

After summing with the positive zeta_j coefficients,
Delta_i=Q-Q_i<=M Q_i/(c-M). Hence

  c Delta_i/[(1+Q_i)(1+Q)]
     <= [cM/(c-M)] [Q_i/((1+Q_i)(1+Q))]
     <= cM/(c-M)
     <= M(M+1),

where the last maximum over integer c>=M+1 occurs at c=M+1.

If 1<=c<=M, split the active monomials by nu<c and nu=c. For nu<c,

  phi_j(c)-phi_j(c-e_i)
       = [nu/(c-nu)]phi_j(c-e_i) <= M phi_j(c-e_i).

The sum of these differences is at most M Q_i. For nu=c, the post-death
term is zero, and the sum of differences is at most Q. Orders nu>c are
zero both before and after the death. Thus Delta_i<=M Q_i+Q, so

  c Delta_i/[(1+Q_i)(1+Q)]
      <= cM + c <= M^2+M.

If M_i=0, Q is independent of c_i and Delta_i=0. Multiplication by mu_i
and summation proves H(c)<=sum_i mu_i M_i(M_i+1)=H0 for every integer c,
including all mixed threshold faces. No separability assumption is used.

2. RE-DERIVED GENERATOR
-----------------------
Let x=1+Q and u=1/x. The reactions changing A contribute

  alpha*u - delta*a*u + Q*u - a*E*u.

C immigration contributes a sum_i gamma_i[u(Q(c+e_i))-u(Q)]<=0. C death
in coordinate i contributes

  a*mu_i*c_i [1/(1+Q_i)-1/(1+Q)]
    =a*mu_i*c_i*Delta_i/[(1+Q_i)(1+Q)].

Therefore the claimed exact expression for L(a*u) is correct. Because
E>=rho*Q, with rho=min_j eta_j/zeta_j,

  (delta+E)/(1+Q)>=min(delta,rho),
  (alpha+Q)/(1+Q)<=max(alpha,1).

Using H<=H0 gives L(a*u)<=max(alpha,1)-kappa*a.

Now g(a,Q)=x/(x+a). For an A-death or forward toggle (a decreases by 1),

  g(a-1,Q)-g(a,Q)=x/[(x+a-1)(x+a)]=D_a.

All A-immigration and reverse-toggle increments are nonpositive. C deaths
are nonpositive for g, and each C immigration increment is at most one,
contributing at most Gamma=sum gamma_i. For a>=1, x+a-1>=(x+a)/2 and
(x+a)^2>=4ax imply

  a*D_a<=1/2,
  delta*a*D_a<=delta/2,
  a*E*D_a<=2*Lambda*a,

since E<=Lambda*Q<=Lambda*x. This verifies the stated active bound
L(Wg)/W<=delta/2+2Lambda*a+Gamma. For a=0, g(0,Q)=1 is constant under
C jumps, while each A immigration/reverse toggle has total rate alpha+Q
and changes g by -1/(2+Q). Thus

  L(epsilon*W*g)(0,c,b)
    =-epsilon*W*(alpha+Q)/(2+Q)
    <=-epsilon*tau*W,
  tau=min(alpha/2,1)>0.

The B pair changes only b and contributes exactly

  a[1+epsilon*g(a,Q)]G_R(b),
  G_R(b)=[p(R-1)-q(1-R^{-1})b]R^b.

3. CHECK OF THE THREE-WAY b SPLIT
---------------------------------
Put C1=delta/2+2Lambda+Gamma and cB=epsilon*tau/2.

For a>=1 and b>=N, the first inequality in (6) gives

4. RATIONAL SEARCH AND EFFECTIVITY
----------------------------------
For rational input, choose integer k tending to infinity,

  epsilon=1/k,  R=1+1/k^2.

For fixed R, G_R(n)>0 only when n<pR/q, so g_+(R) is an exact finite
maximum of rational values. Since pR/q remains bounded as R down to one,
only a uniformly finite set of n can maximize the positive part; each
G_R(n)->0. Therefore g_+(R)->0.

The first constraint on N is equivalent to

  N >= 2pR/q,

which is uniformly O(1). The second requires

  N >= 2(epsilon*C1+cB)/[q(1-R^{-1})]=O(k).

Choosing the least integer N>=1 meeting both gives N=O(k), and hence
R^(N-1)=(1+1/k^2)^(O(k))->1. The left side of the third inequality is

  (1+1/k)g_+(R)+(2Lambda/k)R^(N-1)->0,

while kappa/2 is fixed and positive. Thus the sequential exact rational
search terminates. All comparisons are rational; the finite maximum for
g_+ uses the explicit cutoff n<pR/q. For real non-rational rates, the
analytic existence proof still applies, but this rational search is not an
exact-arithmetic compiler for those inputs.

5. PROPERNESS, NONEXPLOSION, RECURRENCE
--------------------------------------
V is norm-like. If b escapes, R^b escapes; if any catalyst count escapes,
the positive weighted linear term escapes. If b and c are bounded, then
Q(c) is bounded and u(Q)>0, so a*u(Q) escapes with a. Thus every finite
V-sublevel set is finite.

The drift inequality implies LV<=C. Localize on finite V-sublevel sets.
Before exit, rates are bounded because each set is finite; stopped Dynkin
gives a bound on the probability of reaching V-level n by any fixed time
that tends to zero as n increases. An explosion cannot remain in a finite
state set, where total rates are bounded, so the minimal process is
nonexplosive in physical time. The immigration/death pairs adjust A and
each C_i, and A<->A+B adjusts B while A>0; all states communicate. The
usual countable-state Foster criterion then gives positive recurrence on
this irreducible class.

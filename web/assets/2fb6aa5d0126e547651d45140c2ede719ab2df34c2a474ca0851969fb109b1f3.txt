## Independent mathematical result

The frozen result remains a local boundary-geometry bridge. In a finite weakly
reversible graph, from any integer state `x>=y`, a complex path
`y=c_0 -> ... -> c_l=z` lifts to the enabled stochastic path `x-y+c_k`; the
reverse path returns its endpoint. If `y` maximizes the available
falling-factorial source term, its endpoint satisfies `F(x-y+z)<=F(x)` for
the residual-factorial potential `F`. This is exact at zero-count boundaries
and preserves the actual communicating class, but it is not a negative drift
or recurrence argument.

The deterministic coordinate-face criterion also gives a one-step result:
a face is non-invariant exactly when a source supported in that face has an
edge producing a missing species. That edge is enabled on a count state only
when present counts clear the source thresholds. The reversible system
`A+B <-> 2A` shows the threshold cannot be omitted: the deterministic face
`B=0` is non-invariant, `(1,0)` is an absorbing state, and `(2,0)` can recover
to `(1,1)`.

For a length-`l` bimolecular source-swap path, the exact state formula
`x-y+c_k` bounds all intermediate populations by `N+M_*`, not by a cumulative
`N+lM_*`. Thus a prescribed path has an explicit lower success probability
`[k_min/(|R| k_max(1+N+M_*)^2)]^l` under fixed rates. The probability can
decrease polynomially with the starting population. This leaves the decisive
gap: a repeated thin-boundary return mechanism and a negative physical-time
Foster inequality for every state of an actual infinite component.

Exact finite checks in my `boundary_recovery.py` and
`certificate_checks.json` passed on the two counterexample fixtures; the
all-state statements rely on the written derivations. No general certificate,
finite stationary mass, or recurrence theorem was obtained.

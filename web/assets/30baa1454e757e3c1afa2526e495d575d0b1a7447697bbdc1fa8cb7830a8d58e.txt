INDEPENDENT AUDIT: EXACT HIDDEN-RENEWAL CODE COUNTING REDUCTION
Date: 2026-10-08
Audited artifact: outputs/research/sol_hidden_renewal/RESULT.txt

Verdict
-------
I reconstructed the load-bearing exact reduction. I found no algebraic or
combinatorial counterexample in the full-span extraction, fresh-label
Vandermonde identity, leading-coefficient interpolation, tensor transform,
medial orientation, or pinned-root recovery. The chain correctly yields
#P-hardness of exact evaluation of the specified projected-code full-block
marginals, under polynomial-time Turing reductions, for fixed q=2 and explicit
raw paths of polynomial length. The cited external counting theorem is the
right one: Govorov–Cai–Dyer Theorem 3.2 applies to the positive integer matrix
B below and gives hardness on simple graphs of some fixed bounded degree.

One scope correction is required for the broad membership claim: the assertion
that H_N(y)=q K_N N! Q_N^bin(y) is a #P function is justified when N is unary,
or otherwise polynomially bounded by the input length (in particular for the
full explicit-path inputs used in the reduction). It is not a #P-membership
claim over arbitrary binary-encoded N and short prefixes: H_N(empty) already
has Theta(N log N) output bits. This does not weaken the hardness reduction,
whose queries have |x|=N. This encoding caveat was sent promptly to the parent.

The result is only about exact compilation of this particular reference code's
marginals/conditionals. The reduction is exact and cancellation-heavy. It does
not imply hardness of an FPRAS, the suffix-averaged terminal predictor, or any
optimal predictor or predictor family. No such broader conclusion follows.

1. Exact full-span block identity
---------------------------------

Let q=2, and let w=(g_1,...,g_m) be a sequence of positive integer gaps.
The binary path x(w) has events at positions 1, 1+g_1, ..., 1+sum g_t,
so its explicit length is N=1+sum g_t. It begins and ends in event symbol 1;
there is no initial or terminal zero run. A hidden mark path is
u=(u_0,...,u_m) in {0,1}^{m+1}. Its count pool has coordinates
c_{i,d,g}(u), with total span sum g c = sum_t g_t=N-1.

Any pool that generates this marked path must contain each of these observed
transition counts coordinatewise. All gap costs are positive. Since the
observed counts already use span N-1 and a legal pool has span at most N-1,
the pool must equal c(u): there is no room for any additional item. The
anchor is forced to 1, because the path's first event is at 1. Conditional on
this pool and starting mark u_0, the row-urn probability of the ordered path
is

  product_{i,d,g} c_{i,d,g}(u)! / product_i r_i(u)!,
  r_i(u)=#{t: u_{t-1}=i}.

To see this, multiply the without-replacement probabilities along the fixed
transition order. In row i, every occurrence of a local type contributes
successive numerator factors c,c-1,...,1, while row-total denominators
multiply to r_i!. Interleaving visits to rows does not change the product.
Different hidden mark paths are disjoint marked output paths, though they may
share a pool; summing them is correct because their marks are erased by the
binary projection. Uniform pool/start weights contribute 1/(2K_N), hence

  Q_N^bin(x(w)) = Z(w)/(2K_N),
  Z(w)=sum_{u in {0,1}^{m+1}} a(u)/(r_0(u)!r_1(u)!),
  a(u)=product_{i,d,g}c_{i,d,g}(u)! .                    (A)

The separate allzero atom cannot generate x(w). This equality relies on full
span. For a non-full-span observed prefix, pools with unused resources do
contribute, and one cannot use (A) there. An exact rational code-marginal
oracle gives Z(w) by multiplication by the known 2K_N. K_N is a four-colour
partition sum, computable by a polynomial-in-N dynamic program for fixed q=2.

2. Fresh padding and exact denominator elimination
---------------------------------------------------

Let W(w)=sum_u a(u), an integer. Append ell distinct fresh gap labels to w,
each used exactly once and not present in w. They leave the numerator a(u)
unchanged for every hidden path. Write r for the number of original
transitions whose origin is 0, so m-r have origin 1, and let e=u_m.

For e=0, the first appended transition has origin 0. Among the remaining
ell-1 padding origins, choose s zeros in binom(ell-1,s) ways; the final
destination is free, with two choices. The row counts after padding are
r+1+s and m-r+ell-1-s. Thus the conditional denominator sum for fixed u is

  2 sum_{s=0}^{ell-1} binom(ell-1,s)
      /[(r+1+s)!(m-r+ell-1-s)!].

Multiplying by (m+ell)! turns each reciprocal-factorial term into
binom(m+ell,r+1+s). With s'=ell-1-s, Vandermonde's convolution gives

  sum_{s'} binom(ell-1,s') binom(m+ell,r+ell-s')
    = binom(m+2ell-1,r+ell).

Therefore the padding contribution is
2 binom(m+2ell-1,r+ell)/(m+ell)!. For e=1 the first padding origin is 1;
the symmetric calculation replaces r by m-r. Set r_e=r when e=0 and r_e=m-r
when e=1. If Z_ell is the exact evidence from (A) for the padded word, then

  F(ell) = Z_ell (m+ell)!/[2 binom(m+2ell-1,ell)]
         = sum_u a(u) R_{r_e}(ell),

  R_r(ell) = binom(m+2ell-1,r+ell)/binom(m+2ell-1,ell)
            = product_{h=0}^{r-1}(m+ell-1-h)/(ell+1+h).

The empty product for r=0 is 1. For 0<=r<=m, the denominator of R_r divides

  D(ell)=product_{h=1}^m(ell+h).

Also R_r(ell) tends to 1 as ell tends to infinity, because numerator and
denominator have the same degree and leading coefficient. Consequently
D(ell)R_r(ell) is a polynomial of degree at most m with leading coefficient
1. It follows that

  P(ell)=D(ell)F(ell)

is a degree-at-most-m polynomial whose leading coefficient is exactly
sum_u a(u)=W(w). This proves the coefficient claim; it is not an asymptotic
limit algorithm. Interpolation at ell=1,...,m+1 yields

  W(w)=sum_{ell=1}^{m+1} D(ell)F(ell)
        /[(-1)^(m+1-ell)(ell-1)!(m+1-ell)!].           (B)

These are polynomially many exact rational queries and polynomial-bit exact
arithmetic. For hard words below each original label occurs twice, and
a(u)<=2^h for h distinct labels; there are 2^(m+1) hidden paths. Hence
W(w)<=2^(m+h+1), with O(h) output bits. Padded row-factorial denominators
have O(h log h) bits. D(ell), factorial interpolation coefficients, K_N,
and the Q responses all have polynomial bit lengths for the stated horizon.
A common-denominator implementation of O(h) rational terms may use
O(h^2 log h) bits, still polynomial.

Approximation boundary. Formula (B) has alternating coefficients. At the last
node ell=m+1, its coefficient multiplying F(m+1) is

  D(m+1)/m! = (2m+1)!/((m+1)!m!) = binom(2m+1,m),

which is Theta(4^m/sqrt(m)). Thus even this one input's absolute error is
amplified exponentially in m; the all-zero-origin path with a final 0-to-1
transition gives an R_0=1 term, so F(m+1)>=1. This concretely illustrates
why this exact interpolation does not turn a polynomial-relative-accuracy
oracle into exact W recovery. It is not an approximation-preserving reduction
and proves no FPRAS hardness.

3. Repeated labels give a fixed four-ary tensor
----------------------------------------------

Suppose every original gap label occurs exactly twice, say at word positions
a and b. For each label the count-factor contribution is 2 exactly when the
ordered hidden transition pair at its two occurrences agrees; otherwise it
is 1. Therefore

  a(u)=product_labels f(A,B,C,D),
  f(A,B,C,D)=1+1[A=C]1[B=D],

where for the two occurrences A=u_{a-1}, B=u_a, C=u_{b-1}, D=u_b.

Use normalized Hadamard T=2^(-1/2)[[1,1],[1,-1]] on each of the four ports.
The constant tensor 1 transforms to 4 times the all-zero tensor. The two
equality factors transform as identities because T^T T=I. Hence

  fhat(A,B,C,D)=4*1[A=B=C=D=0] + 1[A=C]1[B=D].

After the equality wires identify A=C=s and B=D=t, the local interaction
weight is 1+4*1[s=t=0], namely

  M = [[5,1],[1,1]].

This is exact; there is no unaccounted 2-power because the transform is
orthonormal. Each free endpoint vector (1,1) transforms to (sqrt(2),0),
pinning that endpoint's spectral spin to 0 and contributing sqrt(2).

4. Medial construction from every connected loopless even multigraph
--------------------------------------------------------------------

Let H be connected, loopless, undirected, with at least one edge and all
degrees even. An Euler tour of H orients its edges with indegree=outdegree at
each vertex. At vertex v, write the incidences in a cyclic order alternating
outgoing and incoming; this is possible because the two counts agree.

Create a directed graph F with one vertex for each edge of H. At a vertex v,
let the cyclic order be O_1,I_1,...,O_k,I_k. For each incoming incidence I_j,
put directed arcs I_j->O_j and I_j->O_{j+1}, with cyclic indices (the
equivalent description is to join each adjacent out/in pair in the direction
from incoming to outgoing). Thus every F vertex has indegree two at its tail's
incidence loops and outdegree two at its head's loops: for an H edge u->z,
its two F-incoming ports lie at u, and its two F-outgoing ports lie at z.

At each H vertex the cyclic incidence construction connects every adjacent
in/out pair, so the underlying F is connected whenever H is connected. F is
balanced at every vertex, with indegree=outdegree=2. The directed Euler
criterion therefore supplies one directed Euler circuit. It has 2|E(H)| arcs.
Record the tail vertex of each arc in the circuit as a word label. Each F
vertex has outdegree two, so every label occurs exactly twice; the word length
is m=2|E(H)|.

To verify the tensor wiring, the two occurrences of one F vertex have two
incoming and two outgoing state ports. The Hadamard-transformed tensor pairs
its two incoming ports and separately pairs its two outgoing ports. Along the
cyclic incidence list at v, the F arcs connect each incoming-edge port to its
neighboring outgoing-edge port, while the local pairings join the two ports
of each incidence. Tracing the alternating list shows these wires form one
closed spin loop for v (degree two gives the two-arc loop; higher even degree
extends the same cycle). Each F vertex/e in H then contributes one interaction
M between the loops for the two endpoints of e. Thus the closed wire loops
are exactly the vertices of H and interactions are exactly its edges,
including parallel edges.

Choose any F arc belonging to the incidence loop of a designated root v and
cut the Euler circuit there. Record its tail labels in cyclic order after the
cut. Consecutive word positions are connected by every F arc except the cut;
therefore the missing state connection gives the two free path endpoints u_0
and u_m. They lie on the same root loop after the remaining cyclic wires are
traced. Each free endpoint vector gives sqrt(2) and pins its end to zero, so
the root loop is pinned to spin zero and the total factor is 2. Therefore

  W(w(H,v)) = 2 Z_M(H; v=0).                               (C)

Here Z_M(H;v=0) is the sum over spin assignments to V(H) with the root fixed
at zero, and edge weights M. The construction uses only Euler tours, cyclic
orders and a directed Euler tour; it needs no planarity. This is an all-graph
construction for the stated connected loopless even multigraph class, not
only the six finite test fixtures in the artifact.

5. Pin recovery and the source counting theorem
-----------------------------------------------

Take a connected nontrivial simple source graph G and duplicate every edge to
obtain H. H is connected, loopless, even-degree, and

  Z_M(H) = Z_{M^{odot 2}}(G) = Z_B(G),
  B=[[25,1],[1,1]], det(B)=24.

For a root v of H, write A=Z_M(H;v=0), C=Z_M(H;v=1). Add a new vertex z and
2t parallel edges between z and v, for t=1,2. The augmented graph H_t remains
connected and even-degree. Pin z=0. If v=0 the new-edge factor is
M_{00}^{2t}=5^{2t}=25^t; if v=1 it is M_{01}^{2t}=1. Thus

  B_1=Z_M(H_1;z=0)=25A+C,
  B_2=Z_M(H_2;z=0)=625A+C,
  Z_M(H)=A+C=(26B_1-B_2)/25.                               (D)

By (C), each B_t=W(w(H_t,z))/2. By (B), each W is computable from O(h)
exact code-marginal queries, where h=|E(H_t)|. This gives a polynomial-time
Turing reduction from Z_B(G) to the fixed q=2 projected code. It handles
simple G directly, including degree-bounded instances; the target-side
auxiliary graph may have parallel edges, as permitted by the construction.
If a hardness-source input G is disconnected, Z_B factors over components;
solve each nontrivial connected component separately, with isolated vertices
contributing the known factor 2. Thus restricting the reduction to connected
components does not weaken #P-hardness.

External premise actually checked. Govorov, Cai, Dyer, “A dichotomy for
bounded degree graph homomorphisms with nonnegative weights,” arXiv:2002.02021v1
(2020), Definition 2.1 defines Z_A(G) as the spin sum/product, Definition 2.3
defines block-rank-1, and Theorem 3.2 states: for symmetric nonnegative A and
nonnegative diagonal D, if the matrix A' after deleting zero-D rows/columns is
not block-rank-1, then EVAL_simp^(Delta)(A,D) is #P-hard for some Delta>0.
The theorem's degree bound is existential and depends on the fixed matrix;
the audit does not supply a numeric Delta. With D=I, A'=B. Since every B
entry is positive, its support is one full block (hence rectangular); that
block has rank two because det(B)=24, so it is not block-rank-1. The source
therefore supplies exactly the needed #P-hardness of Z_B on simple graphs of
some fixed bounded degree. The theorem uses polynomial-time Turing-hardness
conventions (defined in its Section 2); B has integer entries, so no algebraic
number representation issue arises. The finite-degree restriction is not
lost: the subsequent reduction works for those graphs.

6. Explicit raw horizon, query, and bit costs
---------------------------------------------

Let h=|E(H_t)|, so the medial word has m=2h transitions and its original
labels 1,...,h each appear twice. Their total gap duration is
2 sum_{j=1}^h j=h(h+1). For padding length 1<=ell<=m+1=2h+1, use new gaps
h+1,...,h+ell. The queried binary block length is

  N_ell=1+h(h+1)+ell*h+ell(ell+1)/2 = O(h^2).            (E)

Since h=2|E(G)|+O(1), every horizon is O(|E(G)|^2). Gap labels are represented
by literal zero runs in the binary query; (E) includes them. This is not a
succinct-horizon oracle. There are m+1=O(h) queries per W and two W instances
for (D), each answer has polynomial bit length, and exact interpolation uses
polynomial-bit rational operations. A coarse total query-symbol count is
O(h^3). If source graph input is measured by |V|+|E|, this is polynomial.
The four-colour K_N DP is polynomial in N; log K_N=O(sqrt N) for fixed q=2.

H_N membership encoding. For fixed q=2 and horizon N in unary (or N bounded
by a polynomial in the encoded input size), the marked prefix formula gives a
polynomial-size weighted nondeterministic count. A witness canonically
encodes the pool coordinates, hidden positive marks for observed events, and
the branch for the terminal tail. Multiplying by qK_NN! makes every
nonnegative contribution an integer: the common denominator lemma is the one
in the source artifact, and row-factorial products divide R!, with
(N-S)R! dividing N! because R<=S<N. Integer weight W can be realized by a
polynomial number of nondeterministic suffix bits accepting exactly W indices;
all such weights have O(N log N) bits. K_N is computable in poly(N) time for
fixed q. Hence H_N(y) is in #P under this explicit-horizon encoding. Combined
with the reduction it is #P-hard, thus #P-complete under polynomial-time
Turing reductions on the unary/explicit-horizon domain.

If instead input is (binary N, short prefix y), unrestricted, H_N(y) need not
have polynomial output length: H_N(empty)=qK_NN!, whose bit length is
Theta(N log N), while the encoding of N is only Theta(log N). Therefore the
artifact's all-prefix #P-membership sentence must be read with an explicit
unary/size-bounded N convention; it is not proved for unrestricted binary N.
The hardness part is unaffected because every reduction query is a full
explicit string with |x|=N and hence N<=input size. The exact conditional-
compiler consequence also uses only such polynomially sized queries.

7. What the exact hardness does and does not transfer to
--------------------------------------------------------

An oracle for exact Q_N^bin(full path) computes Z by (A), and by (B) computes
W; by (C) and (D) it computes the #P-hard source partition function. Thus
exact full-block probability evaluation for this particular fixed code is
#P-hard. If an exact interface instead returns every fixed-horizon next-symbol
conditional Q_N(x_t|x_{<t}), multiply the N conditionals along the explicit
full path. Full support makes each defined, and polynomial-bit exact
rationals multiply to a polynomial-bit result (at most a polynomial increase
in bit length). Therefore this general exact conditional compiler is also
#P-hard.

That argument does not recover an individual code prefix from the final
suffix-averaged predictor qhat_n(v|x^n): the latter is an average of conditionals
over suffixes, not a direct oracle for a selected complete path. No reduction
to computing that average is given. More broadly, a hard exact reference-code
compiler neither shows that all exact predictors are hard nor that every
minimax-optimal predictor is hard. It says nothing against relative
approximation in polynomial inverse tolerance, randomized approximate
prediction, or alternative codes. The separate relative-count-to-prediction
lemma is conditional on a prefix-uniform relative oracle and charges its
failure/bit costs; it does not supply that oracle for this code.

The reduction is exact rather than parsimonious: it uses interpolation and
the subtraction in (D). Consequently exact #P-hardness alone gives no
approximation-preserving hardness. The exponential interpolation coefficient
noted after (B) is a concrete margin warning, not a complete complexity
classification of approximate evaluation.

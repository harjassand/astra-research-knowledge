# Hidden transient-state discrimination: proof

## Model

Fix a known integer \(k\geq 1\). The latent state \(X_t\) is a continuous-time Markov chain on \(\{0,1,\ldots,k\}\). State \(0\) is absorbing. For each \(r\geq1\), state \(r\) jumps to \(0\) at rate \(\delta_r>0\), with no other jumps. Immediately after initialization,
\[
\Pr(X_0=r)=p_r>0,\qquad \Pr(X_0=0)=1-\sum_{r=1}^k p_r>0.
\]

At a chosen delay \(\tau\), a one-shot input \(u\in\{+,-\}\) produces a Bernoulli output \(Y\) whose conditional success probability is \(\theta_{u,r}\in(0,1)\) when \(X_\tau=r\). The readout does not change the state. Independent trials use independent copies of the same initialized chain. The observed discrimination summary is
\[
D(\tau)=\Pr(Y=1\mid u=+,\tau)-\Pr(Y=1\mid u=-,\tau).
\]
An uninitialized or reset control reveals \(D_0=\theta_{+,0}-\theta_{-,0}\). Write
\[
C_r=(\theta_{+,r}-\theta_{-,r})-D_0,\qquad A_r=p_r C_r.
\]
The observation interface contains terminal challenge probabilities and the reset baselines, but not \(X_\tau\). The sample-count theorem below uses the scalar difference \(D(\tau)\); retaining both class probabilities can add emission-amplitude information but does not remove occupancy-versus-emission confounding.

## Theorem

Suppose the rates \(\delta_1,\ldots,\delta_k\) are distinct and every \(A_r\neq0\).

1. The entire discrimination curve depends on \((p_r,C_r)\) only through \(A_r=p_rC_r\):
   \[
   D(\tau)-D_0=\sum_{r=1}^k A_r e^{-\delta_r\tau}.
   \]
   Thus no number of delay-only discrimination measurements identifies \(p_r\) and \(C_r\) separately. At every interior parameter point there is a continuum of distinct \((p_r,C_r)\) with exactly the same output law.

2. If \(k\) is known, \(2k\) noiseless scalar measurements at equally spaced delays identify the unordered pairs \(\{(A_r,\delta_r):1\leq r\leq k\}\). A labeled occupancy observation that identifies the \(p_r\)'s then identifies \(C_r=A_r/p_r\). Equivalently, supplied known \(p_r\)'s break the same ambiguity.

3. Fewer than \(2k\) scalar discrimination means cannot generically identify the \(2k\) continuous parameters \((A_1,\ldots,A_k,\delta_1,\ldots,\delta_k)\) from a fixed finite schedule.

## Proof

The pure-death transition law gives
\[
\Pr(X_\tau=r)=p_r e^{-\delta_r\tau},\qquad
\Pr(X_\tau=0)=1-\sum_r p_r e^{-\delta_r\tau}.
\]
For each input \(u\),
\[
\Pr(Y=1\mid u,\tau)=\theta_{u,0}
+\sum_{r=1}^k p_r e^{-\delta_r\tau}(\theta_{u,r}-\theta_{u,0}).
\]
Subtracting the two input probabilities gives the displayed exponential sum.

For the first assertion, take any constants \(s_r\) sufficiently close to \(1\), not all equal to \(1\), and set
\[
p'_r=s_rp_r,\qquad C'_r=C_r/s_r.
\]
For each input \(u\), set
\[
\theta'_{u,r}=\theta_{u,0}+(\theta_{u,r}-\theta_{u,0})/s_r.
\]
Interior assumptions allow the \(s_r\)'s to be chosen so that \(p'_r>0\), \(\sum_rp'_r<1\), and every \(\theta'_{u,r}\) remains in \((0,1)\). Then \(p'_r(\theta'_{u,r}-\theta_{u,0})=p_r(\theta_{u,r}-\theta_{u,0})\), so each input-specific terminal probability at every delay is unchanged. In particular \(C'_r=C_r/s_r\) and \(p'_rC'_r=A_r\). This is an exact observational equivalence, not a finite-sample approximation.

For the second assertion, sample at \(\tau_j=\tau_0+jh\), \(j=0,\ldots,2k-1\), where \(h>0\) is known. Put
\[
x_r=e^{-\delta_rh},\qquad b_r=A_re^{-\delta_r\tau_0},\qquad
y_j=D(\tau_j)-D_0=\sum_r b_rx_r^j.
\]
Let \(V_{jr}=x_r^j\) for \(j=0,\ldots,k-1\), and define the \(k\times k\) Hankel matrices
\[
(H_0)_{ij}=y_{i+j},\qquad (H_1)_{ij}=y_{i+j+1},
\quad i,j=0,\ldots,k-1.
\]
Then
\[
H_0=V\,\mathrm{diag}(b_r)\,V^\mathsf T,\qquad
H_1=V\,\mathrm{diag}(b_rx_r)\,V^\mathsf T.
\]
Distinct \(x_r\)'s make \(V\) invertible; nonzero \(b_r\)'s make \(H_0\) invertible. Therefore the generalized eigenvalues of \(H_1v=xH_0v\) are exactly \(x_1,\ldots,x_k\). Recover
\[
\delta_r=-h^{-1}\log x_r.
\]
Solving the \(k\times k\) Vandermonde system \(y_j=\sum_r b_rx_r^j\), \(j=0,\ldots,k-1\), recovers the \(b_r\)'s and hence \(A_r=b_re^{\delta_r\tau_0}\). This is unique up to permutation of mode labels. A labeled state readout at \(\tau=0\) gives the multinomial probabilities \(p_r\), after which \(C_r=A_r/p_r\).

For the third assertion, order rates as \(\delta_1<\cdots<\delta_k\) to remove label permutations and restrict to an open set with nonzero amplitudes. The parameter domain then has dimension \(2k\), while a schedule of \(m<2k\) scalar means maps it continuously into \(\mathbb R^m\). Such a map cannot be injective on an open subset: composing a hypothetical injection with the standard embedding \(\mathbb R^m\hookrightarrow\mathbb R^{2k}\) would contradict invariance of domain. Thus fewer than \(2k\) scalar means cannot generically identify all these parameters.

## Exact failure cases

- If \(A_r=0\), mode \(r\) is invisible to discrimination and its decay rate cannot be recovered from this output.
- If two rates coincide, only the sum of their amplitudes at that rate is visible; the model order collapses.
- If \(k\) is unknown, the theorem's \(2k\)-sample count does not identify order. More samples/model-order selection are required.
- The result is for terminal Bernoulli probabilities. Full event-time trajectories or richer state-dependent emissions may reveal additional parameters and are outside this observation map.
- Near-colliding \(x_r\)'s or small \(|A_r|\) make Hankel/Vandermonde recovery ill-conditioned; structural identifiability alone supplies no uniform finite-noise guarantee.

1. COMPLETE INTERFACE AND SHARP CP-FILTER PRINCIPLE

Finite-dimensional Hilbert spaces; A,B are nonzero PSD operators. T(ρ,σ) means
||ρ-σ||_1/2. A positive linear map Λ is enough; CP is the physical subclass. Λ need
not preserve trace. Assume Λ(A) != 0 and finite constants 0<a<=b satisfying
aA <= B <= bA. Then Λ(B) != 0 automatically. No lower bound on either output
trace, herald probability, rank, spectral gap, or conditioning is needed.

Define M(B/A)=inf{c:B<=cA}, m(B/A)=sup{c:cA<=B}. When supports are equal,

  C=A^{-1/2}BA^{-1/2} on their common support,
  M=λ_max(C), m=λ_min(C),
  h(A,B)=log(M/m)=D_max(B||A)+D_max(A||B),

where the logarithms are natural and inverses are support inverses. h is invariant
under independent positive scalar rescaling. Positivity immediately gives
h(ΛA,ΛB)<=h(A,B). For x=trΛA, y=trΛB, q=y/x in [a,b], the normalized outputs obey

  (a/q)ρ <= σ <= (b/q)ρ,
  D_max(σ||ρ)<=log(b/q), D_max(ρ||σ)<=log(q/a).

The sharper bound if q is known is

  T(ρ,σ) <= (b-q)(q-a)/[q(b-a)]                         (a<b),

and maximizing over q recovers tanh(log(b/a)/4).

Elementary direct proof of the latter: take any binary effect 0<=P<=I. Write
p=tr(Pρ), u=tr(PΛB)/tr(PΛA), v=tr((I-P)ΛB)/tr((I-P)ΛA), with endpoint cases by
continuity. Then u,v in [a,b] and tr(Pσ)=up/[up+v(1-p)]. If R=b/a, its difference
from p is at most Rp/[Rp+1-p]-p. The maximum over p in [0,1] is
(sqrt(R)-1)/(sqrt(R)+1), at p=1/(1+sqrt(R)). Maximizing over effects proves T.

Sharpness for EACH pair, not just some commuting pair: if A,B have common
support, choose eigenvectors u_min,u_max of C above and set

  w_min=sqrt(M)/(sqrt(m)+sqrt(M)),
  w_max=sqrt(m)/(sqrt(m)+sqrt(M)),
  K = diag(sqrt(w_min),sqrt(w_max))
      [u_min^* ; u_max^*] A^{-1/2}.

Then KAK* is diag(w_min,w_max), KBK* is diag(m w_min,M w_max). After normalization
the two probabilities swap, so T=tanh(h(A,B)/4). A common sufficiently small
positive scale makes K*K<=I without changing either normalized output. Therefore

  sup_{CP trace-nonincreasing Λ; trΛA,trΛB>0} T(normalized ΛA,normalized ΛB)
     = tanh(h(A,B)/4).

So h->0 is exactly the uniform-all-filters stability condition. This extremizing
filter may itself be expensive to acquire and may have tiny success probability;
the equality is an operational characterization, not a preparation algorithm.

If A and B are distinct pure states, their supports differ and h=∞. There is no
nontrivial Loewner sandwich. The principle does not justify rounding a pure
Slater orbital matrix before a rare projection. For a direct rational example,
A=(1,t,t)^T and A'=(1,t,0)^T define one-particle pure states tending together as
t->0. Projection onto the last two modes gives |+> versus |1>, with T=1/sqrt(2).
Both conditioned outputs exist for every rational t>0.

2. EXACT FERMIONIC EXTERIOR-POWER CONSTANTS

For positive-definite one-body Q on C^m, let

  Γ(Q)=direct_sum_{k=0}^m wedge^k Q,
  Γ_r(Q)=wedge^r Q,
  ρ_Q=Γ(Q)/det(I+Q).

If Q=e^{-βh}, then Γ(Q)=e^{-β dΓ(h)}; diagonalizing h proves this identity directly.
Γ_r is the unnormalized canonical r-particle block. Let C=Q^{-1/2}Q'Q^{-1/2}
have eigenvalues λ_1<=...<=λ_m, and write ℓ_i=log λ_i. Multiplicativity of exterior
powers and (wedge^r Q)^{1/2}=wedge^r(Q^{1/2}) show that the relative eigenvalues
of Γ_r(Q') versus Γ_r(Q) are exactly all products of r distinct λ_i. Consequently

  h(Γ_r(Q),Γ_r(Q'))
     = sum_{i=m-r+1}^m ℓ_i - sum_{i=1}^r ℓ_i.          EXACT

If aQ<=Q'<=bQ, overlapping terms cancel when r>m/2, giving

  h_r <= min(r,m-r) log(b/a).

Every positive filter on the r-particle space inherits the bound from Section 1.
In particular, a partition-occupation projector P with quotas summing to r, any
subsequent CP map, and ancilla tracing are allowed. Filtered states may be
non-Gaussian, coherences may be retained, and P need not commute with Q. Scalars
det(I+Q), canonical partition functions, and herald probabilities all cancel.
The r=0,m sectors are one-dimensional and have zero projective error.

For the full grand-canonical input the exact formula is instead

  h(Γ(Q),Γ(Q')) = sum_i |ℓ_i|.

Thus an ANCHORED symmetric one-body sandwich e^{-η}Q<=Q'<=e^{η}Q gives h_full<=mη,
and h_r<=2 min(r,m-r)η. An unanchored a,b ratio alone does not control the full
Fock state: Q'=cQ has h_r=0 but changes the grand-canonical particle law.

These facts apply to number-conserving mixed Gaussian states. The abstract CP
principle applies to paired/BCS mixed Gaussian states too, but this report does
not supply an efficient covariance-to-full-operator multiplicative compiler for
that class. Zero-temperature/pure limits require the support caveat above.

3. ACQUIRED RATIONAL HAMILTONIAN -> RATIONAL THERMAL FACTOR

Input: an explicit Hermitian h in Q(i)^{m x m}, rational β>=0, total binary input
length L, target dyadic scalar precision ε_s=2^{-p}<1, and an acquired rational
R>=||X|| for X=-βh/2. R can be computed by a rational row-sum bound; no eigenvectors
or hidden norm oracle are required. Treat this h as the exact mathematical input.
If h describes uncertain physical data, Section 4's acquisition precision debt
still applies.

Choose N=12 ceil(R)+p+2 and set

  q_{N-1}(x)=sum_{j=0}^{N-1} x^j/j!,   B=q_{N-1}(X).

Taylor's remainder obeys, for |x|<=R,

  |q(x)-e^x| <= e^R R^N/N! <= e^R (eR/N)^N <= e^R 4^{-N}
                    <= ε_s e^{-R} <= ε_s e^x.

The last inequalities follow from e<3, N>=12R and N log4>=2R+p log2.
Therefore q(x)>0 throughout the spectrum and exact rational polynomial evaluation
produces an explicit positive-definite rational-complex B commuting with exact h:

  (1-ε_s)e^X <= B <= (1+ε_s)e^X,
  (1-ε_s)^2 Q <= B^2 <= (1+ε_s)^2 Q,  Q=e^{-βh}.

This is a genuine Loewner sandwich because the matrices have the SAME eigenbasis.
It does not invoke exponential operator monotonicity. Set d=min(r,m-r); Sections
1--2 give the exact sufficient output error

  T(P Γ_r(Q) P /tr, P Γ_r(B^2) P /tr)
     <= tanh[d artanh(ε_s)].

Taking ε_s<=ε/(2m) for 0<ε<=1 safely gives <=ε, including full-Fock filtering via
its anchored bound. If r is fixed, m can be replaced by an appropriate d-based
budget for the canonical sector. A quantum compiler's trace error adds by the
triangle inequality. Positivity and exact support feasibility are preserved by
the sandwich; a zero-probability filter is zero for both inputs.

Degree O(R+p); exact polynomial arithmetic has bit complexity polynomial in
m,L,R,p. To see finite height directly, clear denominators X=M/D. A common
denominator N! D^{N-1} works; numerators have O(N(L+log m+log N)) bits. Horner
matrix evaluation is a polynomial number of arithmetic operations. The runtime
depends on numerical R, not merely log R. If β||h|| is exponentially large in its
compact binary description, this is NOT a polynomial-input-bit algorithm.
Precision p=O(log(m/ε)) after fixing R; no log(1/herald_probability) is present.

The parallel Slater agent's acquired matrix [B;I] has rational entries and can
purify Γ(B^2). Fixing physical r and ancillary m-r converts it into the N63 quota
interface. This report validates the thermal-factor stability part only. It does
not validate or implement the imported FPRAS, reversible prefix count program,
phase computation, or quantum compiler. Their own costs and failure probabilities
remain separately charged.

An optional coherent-purification strengthening: use the canonical r-block vector
|V>=vec(Γ_r(e^X)), followed by any left physical filter F. Because B commutes with
e^X, R_B=B e^{-X} is positive and Γ_r(B)=Γ_r(e^X)Γ_r(R_B). Hence the filtered
purifications differ by a positive operator on the ANCILLA, with spectral ratio
at most [(1+ε_s)/(1-ε_s)]^d. For any positive aI<=C<=bI and vector v,

  |<v,Cv>|/(||v|| ||Cv||) >= 2sqrt(ab)/(a+b),

by the elementary Kantorovich bound (C-aI)(bI-C)>=0, optimizing <C>.
Thus the pure-state trace error is <=(b-a)/(b+a)=tanh(log(b/a)/2), here again
<=tanh[d artanh(ε_s)]. The estimate is independent of ||F V||, so canonical
purification as well as its reduced density survives this particular commuting
polynomial approximation. It is not a guarantee for arbitrary near-pure inputs.

If one instead acquires a rational positive-definite Q directly, positivity and
aQ<=Q'<=bQ for rational a,b are polynomial-bit exact linear-algebra tests. A lower
eigenvalue bound is also derivable, not free: clear a common denominator D, let
U>=||Q||, then det Q>=D^{-m} and λ_min(Q)>=D^{-m}U^{-(m-1)}. Rational rounding at
this height can acquire a sandwich in polynomial bit precision, but replacing
an irrational thermal matrix by such a Q still needs a certified acquisition
procedure such as the exact polynomial construction above.

4. ADDITIVE NONCOMMUTING HAMILTONIAN ERRORS: SHARP LOCAL CONDITIONING

Let A,E be Hermitian, δ=||E||, Δ=λ_max(A)-λ_min(A), and G_t=e^{A+tE}. Duhamel gives

  S_{A_t}(E):=G_t^{-1/2}G'_t G_t^{-1/2}
     = integral_{-1/2}^{1/2} e^{u A_t} E e^{-u A_t} du
     = sum_{j>=0} ad_{A_t}^{2j}(E)/[2^{2j}(2j+1)!].

Centering A_t by a scalar yields ||ad_{A_t}||_{op->op}<=Δ_t. Therefore

  ||S_{A_t}(E)|| <= δ g(Δ_t),
  g(x)=sinh(x/2)/(x/2),  g(0)=1.

Weyl gives Δ_t<=Δ+2tδ. Differential Loewner inequalities and integration imply

  e^{-α}e^A <= e^{A+E} <= e^{α}e^A,
  α = δ integral_0^1 g(Δ+2tδ)dt <= δ g(Δ+2δ).

Consequently normalized arbitrary CP-filtered outputs have T<=tanh(α/2).
The dependence g(Δ)~e^{Δ/2}/Δ is unavoidable even infinitesimally. For
A=s σ_z, E=t σ_x, Δ=2s, the relative matrix
C=e^{-A/2}e^{A+E}e^{-A/2} has determinant 1 and eigenvalues exp(±u), where

  cosh u = cosh s cosh r - (s/r)sinh s sinh r,
  r=sqrt(s^2+t^2).

As t->0, u/|t| -> sinh s/s = g(Δ). Equivalently S_A(σ_x)=g(Δ)σ_x exactly.
For example Δ=20 gives g=1101.3232874703, so the claimed e^{±||E||} sandwich fails
by a factor of over 1100 at first order. This is exponential spectral sensitivity
in the Loewner-relative metric, despite perfectly conditioned eigenvectors of A.

In the commuting case [A,E]=0, S_A(E)=E and α=δ is valid. One must keep this
commutation hypothesis or charge g(Δ); replacing a scalar inequality by matrix
exponential monotonicity is invalid.

Ordinary normalized Gibbs states are nevertheless well behaved: with
ρ=e^A/tr e^A, σ=e^{A+E}/tr e^{A+E}, their Jeffreys divergence is
J=D(ρ||σ)+D(σ||ρ)=tr[(σ-ρ)E]<=2δ T(ρ,σ).
Measuring the binary Helstrom effect and using relative-entropy data processing
gives J>=4T artanh T: for binary probabilities p-q=T, the Jeffreys divergence is
T log[p(1-q)/(q(1-p))], minimized at p=(1+T)/2,q=(1-T)/2. Hence

  T(ρ,σ)<=tanh(δ/2),

which is sharp for commuting symmetric qubits. This trace bound alone cannot be
normalized through an arbitrarily rare filter. If needed, replace δ by
min_c ||E-cI||, since scalar perturbations cancel from Gibbs normalization.

5. FINITE-BIT THREE-MODE QUOTA COUNTEREXAMPLE

For integers n>=1 let L_n=4n, t_n=2^{-n}, and take exactly rational one-body data

  h_n=diag(0,L_n,L_n),
  h'_n=h_n+t_n(|0><1|+|1><0|), β=1.

Input description length is O(n+log n); ||h'_n-h_n||=2^{-n}->0. The physical
number-conserving Gaussian states are Γ(e^{-h_n})/det(I+e^{-h_n}) and the primed
version. On full Fock space the Hamiltonian difference dΓ(E_n) has norm t_n
(its one-body eigenvalues are -t_n,0,t_n), so Section 4 bounds their ordinary
trace distance by tanh(t_n/2)->0.

Filter quotas are one particle in {1,2} and zero in {0}. This is a diagonal
occupation projector, exactly within partition-quota postselection. On its
two-dimensional output the unperturbed state is I_2/2. Set s=L_n/2 and
r=sqrt(s^2+t_n^2). The rare diagonal of exp(-h'_n) is

  q_n = [t_n^2/(2r(r+s))] exp(r-s)
          + [(1+s/r)/2] exp(-r-s),

while the other retained diagonal is exp(-L_n); their off-diagonal is zero.
Since r-s=t_n^2/(r+s)->0 and r/s->1,

  q_n = (1+o(1)) t_n^2/L_n^2 + (1+o(1))exp(-L_n),
  q_n/exp(-L_n) -> infinity,
  conditioned T = [q_n-exp(-L_n)]/[2(q_n+exp(-L_n))] -> 1/2.

Indeed t_n^2 exp(L_n)/L_n^2=(e^4/4)^n/(16n^2)->∞. The unperturbed grand-canonical
success probability is exp(-L_n)/(1+exp(-L_n))^2. The primed success probability
also tends to zero, approximately t_n^2/(2L_n^2). This is a true rare-event
amplification of vanishing input error, with exact finite-bit input and a fixed
simple quota pattern, not an artificially acquired arbitrary CP extremizer.

# Distributed scientific control: finite q=4 sensor-tree capacity audit

## Verdict

The strongest defensible result here is a **computable finite capacity certificate and sensor-budget proxy** for q=4 Potts trees, with a conditional conversion to a small finite-depth Bayes-advantage floor. The max-ray weighted-flow problem has an exact scalar backward recursion; for finite sensor menus it can be optimized by a tree knapsack DP, and a fixed-scale implementation computes rigorous downward-rounded capacity bounds using integer square roots.

This is not a new BP algorithm or Bayes-optimal sensor-design result. The capacity recursion is a direct form of established nonlinear `L^3` tree-capacity machinery. The DP maximizes that proxy, and an exact counterexample shows it can choose a sensor package with *lower* Bayes MAP accuracy. The quantitative Bayes consequence also depends on an internally derived heterogeneous q=4 theorem whose load-bearing posterior-cone source proof has not received full independent replay/review. No physical device/data or closed-loop controller was tested.

The high-ceiling theorem candidate is the four-state posterior-cone mechanism: its expected cubic invariant survives Bayesian branch products and produces strict second-moment saving. When combined with the internal weighted-flow extension, it yields an all-tree heterogeneous-channel reconstruction criterion. The main missing lemma for treating that candidate as capital is external independent validation of the exact posterior-cone product inequalities and the complete weighted-flow proof. The published N49 paper is narrower: it assumes one homogeneous channel parameter and bounded outdegree.

## Exact finite capability derived

For a finite rooted tree, ordinary edge channels `P_lambda`, and sensor channels `P_rho` attached as noisy edges to observed terminals, define

`Phi_lambda(S)=lambda^2*S/sqrt(1+(1-lambda^4)*S^2)`,

`g(rho)=rho^2/sqrt(1-rho^4)`.

Backward from the sensor leaves,

`S_v = sum_child Phi_lambda(S_w) + sum_selected_local_sensor g(rho)`.

Then `S_root` equals the maximum root flow mass subject to max sensor-path energy at most one, with zero/one endpoint conventions detailed in [the proof](proof/FINITE_SENSOR_TREE_CAPACITY.md). This is exact over reals, linear in tree size for a fixed menu, and directly handles sensors at internal nodes. With integer cost budget `B`, a tree DP maximizes the capacity certificate in `O(B^2|E| + B*M)` transitions, where `M` is the number of sensor options. Rational fixed-scale downward rounding is implemented; the demo uses `Q=10^8` and remains below the floating recurrence as required.

Under the internal heterogeneous q=4 flow theorem and cone lemma, finite sensor reports can be copied along deterministic edges to a common level, so capacity mass `b` gives the following guarantee for the full finite report record (and for every deeper copied boundary):

`E TV(root posterior, uniform) >= b/(1600*sqrt(b^2+2))`,

`P(MAP correct)-1/4 >= b/(4800*sqrt(b^2+2))`.

The exact `C=460` proof yields the loss fraction `0.14+0.322=0.462<1/2` using `eta=.01/sqrt(b^2+2)`. These bounds apply in expectation and uniformly over finite depths, but they are weak: at the asymmetric test fixture's `b=0.49234806`, the floor is `2.0549e-4` expected TV and `6.8497e-5` MAP advantage. That is a theorem witness, not a practical accuracy target.

For a regular `d`-ary tree with perfect depth-`n` readings, the finite capacity is explicit. With `q=d^2 lambda^4` and `c=1-lambda^4`,

`1/S_root^2 = c * sum_(j=1)^n q^(-j)`.

It stays bounded away from zero above `d lambda^2=1`, is `1/sqrt(n c)` at the critical boundary, and vanishes below. The threshold is the known Kesten–Stigum boundary in this q=4 ferromagnetic case; the finite formula is a direct capacity calculation, not a new threshold claim.

## Attack and boundary

The strongest control is exact centralized sum-product (or its exact distributed upward BP realization) at the supplied model. It gives the actual Bayes posterior for each finite tree sample in `O(|E|)` four-vector updates. The capacity DP does not improve that inference algorithm. Best-single-sensor and census/majority are additional evaluation baselines; a sensor-design comparison must include centralized BP.

The certificate is not Bayes-optimal for design. On one root with total sensor cost two, one `P_0.7` sensor has capacity `0.5621055` and MAP success `31/40=0.775`; two independent `P_0.6` sensors have capacity `0.7717436` but MAP success `7/10=0.700`. This exact counterexample rejects any claim that maximizing capacity maximizes real Bayes reward. For finite menus, true Bayes-optimal design can be computed by exhaustive subset/outcome enumeration, generally exponential; no efficient exact optimizer, submodularity, or approximation guarantee was established.

The finite edge/sensor model assumes supplied q-symmetric channel parameters and a supplied tree. If reliabilities are unknown, each channel needs independently labeled calibration data; a one-sided Hoeffding lower bound is given in the proof. Under the proof's conservative sample rule, 1,000 edges with planning reliability `.8` and 95% simultaneous confidence require 221,000 labeled edge transitions before sensor calibration. Full row confusion data must validate the q-symmetric model. The cost ledger separately charges sensor acquisitions, calibration trials, per-edge messages, arithmetic/bit precision, and latency. If each edge sends three `b`-bit normalized log-ratios, the ideal payload is `3b|E|` bits per episode; exact rational messages have input-dependent bit lengths. Fixed-precision, asynchronous, packet-loss, and correlated-error robustness are unproved. Classification is not closed-loop safety or energy control.

Primary prior art was checked: Pemantle–Peres developed `L^3` nonlinear capacities on trees; Kschischang–Frey–Loeliger established sum-product on factor graphs; Tay–Tsitsiklis–Win studied Bayesian bounded-height tree detection under progressive message compression; Mossel–Sly–Sohn provide q=3/4 phase-transition results under Galton–Watson/SBM hypotheses. The finite scalar recursion is not presented as a novelty claim. Source handles and evidence limits are recorded in [SOURCES.md](source/SOURCES.md).

## Validation performed

`code/finite_tree_capacity.py` passed a self-check on an asymmetric finite tree with internal sensors, a deterministic edge, a zero edge, finite-flow energy, regular-tree values above and at the Kesten–Stigum boundary, exact root-only Bayes enumeration, and the capacity-versus-MAP ranking counterexample. A separate 100,001-point minimax split grid gives capacity `0.49234470` versus recurrence `0.49234808` (grid-resolution difference `3.4e-6`). A sub-capacity floating flow of mass `0.49234808089` has maximum path energy `0.9999999998`; the fixed-scale integer recurrence separately certifies at least `0.49234806`. Budget DP returns integer lower `0.77174362` for the two-moderate sensor set. `code/RESULTS.json` parses.

The hostile child audit reran the cone source's small exact rational scalar checker and all 24 symmetry actions. It did not rerun the two longer C++ product-certificate traversals; their counts and success are only source-reported. No external mathematical reviewer, priority search, physical data, or engineering trial was used.

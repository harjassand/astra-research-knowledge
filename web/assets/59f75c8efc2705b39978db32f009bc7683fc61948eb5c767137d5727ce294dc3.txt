REVISION — SAME OBSERVATION SPACE, SAME FISHER, DIFFERENT JOINT POSTERIOR

The initial checkpoint gave an exact two-mode shared-scalar sensor. Here the
comparison is sharpened by placing an independent-feature sensor on the same
observation space T^2. Both are one-draw analytic experiments with the same
two-dimensional parameter ball and exactly the same tangent Fisher matrix.

THE TWO FAMILIES

Let mu=dt_1 dt_2 be Haar probability on T^2, rho=1/4, and ||v||_2<=1.
Define

  S_v(t_1,t_2) = 1+rho[v_1 cos(2 pi t_1)+v_2 cos(4 pi t_1)],
  P_v(t_1,t_2) = 1+rho[v_1 cos(2 pi t_1)+v_2 cos(2 pi t_2)].

The second coordinate is ancillary for S. It is retained as an explicit
uniform draw after decoding, so both experiments have the same T^2 output
space and the same reference measure. Both densities integrate to one and are
strictly positive. Since each feature vector has Euclidean norm at most
sqrt(2), 5/8 < density < 11/8 follows from sqrt(2)<3/2.

At v=0, both score Gram matrices are exactly (rho^2/2)I_2=(1/32)I_2. The
shared features U=cos(2 pi t_1), V=cos(4 pi t_1) obey V=2U^2-1, while the
product features U_1=cos(2 pi t_1), U_2=cos(2 pi t_2) are independent under
mu. Thus the same orthogonal Fisher scores have different joint reference
laws: one singular on a curve, one absolutely continuous on a square.

The full Fisher metrics are uniformly comparable with the same constants for
both families. For any w in R^2 and any ||v||<=1,

  I_v(w,w) = rho^2 integral (w dot Phi)^2/(1+rho v dot Phi) dmu,

where Phi is the corresponding feature vector. The denominator is between
5/8 and 11/8 and integral (w dot Phi)^2=(1/2)||w||^2. Hence

  (1/44)||w||^2 <= I_v(w,w) <= (1/20)||w||^2.

This comparison uses exactly the same bounds for S and P. No local Fisher
approximation is being extrapolated outside its range.

ARCHIVE ORDERS BY CODEC AND LOWER BOUND

Shared family S: store the periodic triangular-hat label for t_1 and
regenerate t_2 uniformly. The initial certificate gives

  TV <= (3025/588)/J^2.

Thus D_S(epsilon)<=ceil(sqrt((3025/588)/epsilon)); the classical bit cost is
(1/2)log_2(1/epsilon)+O(1). The v=+/-e_1 posterior-regret lower in INITIAL.txt
gives B_q^S(epsilon)>=(1/2)log_2(1/epsilon)-O(1), including arbitrary
unassisted hybrid/quantum memory.

Independent family P: run the same periodic hat kernel on each coordinate.
The encoder stores (j_1,j_2), giving D_P=J^2 labels. Since K1=1 and the
likelihood is additive in the two coordinates,

  (K tensor K)P_v = 1+rho[v_1 KU(t_1)+v_2 KU(t_2)].

For U(t)=cos(2 pi t), ||U''||_infinity=4 pi^2. The interpolation bound
therefore gives

  TV <= (5 sqrt(2) pi^2/48)/J^2
     < (605/392)/J^2,

using sqrt(2)<3/2 and pi<22/7. Consequently
D_P(epsilon)=O(epsilon^-1), so B_cl^P(epsilon)<=log_2(1/epsilon)+O(1).

For the matching quantum lower, restrict the full-output promise separately to
v=+/-e_i, i=1,2. The mixture in each pair is the same reference mu, and each
posterior feature U_i has h(U_i)=ln(pi/2). The bounded proper-score transfer
forces E_mu[(U_i(X_i)-U_i(Y_i))^2]<=4epsilon/rho. Entropy-distortion and
data processing give

  I(U_i;Y_i,seed) >= (1/2)ln(1/epsilon)-O(1).

The U_i are independent under the common reference. For any fixed independent
seed, strong subadditivity and the Holevo dimension bound imply

  sum_(i=1)^2 I(U_i;Y_i|seed)
      <= I(U_1,U_2;Q|seed) <= ln D,

where Q is the single stored state and every input-dependent register is
included in its total dimension D. Averaging over the seed yields the same
bound. Hence B_q^P(epsilon)>=(1/ln 2)ln(1/epsilon)-O(1), matching the
classical order. This is a common-output archive lower, not a claim about
repeated or nondestructive queries.

Therefore, on the same T^2 sample space with the same parameter dimension,
same tangent Fisher matrix and uniformly comparable full Fisher metrics,

  B_q^S(epsilon) = (1/2)log_2(1/epsilon)+O(1),
  B_q^P(epsilon) = log_2(1/epsilon)+O(1).

The leading memory-bit coefficient differs by a factor of two. This is a
finite-dimensional exact pair, while the earlier cycle-1 family gives the
stronger log versus log-squared separation across infinitely many modes.

JOINT-POSTERIOR HEAT-FLOW CHECK

The posterior-feature geometry has a precise Gaussian smoothing signature.
Let g(u)=2u^2-1 on [-1,1], extended to R by g(u)=2 clip(u,-1,1)^2-1; this
extension is 4-Lipschitz. Let U have the arcsine law, let Z_1,Z_2 be
independent standard normals, and define

  W_S=(U,g(U)),
  Y_tau=W_S+sqrt(tau)(Z_1,Z_2).

Because W_S and U determine one another, I(W_S;Y_tau)=I(U;Y_tau). Write
Y_1=U+sqrt(tau)Z_1 and Y_2=g(U)+sqrt(tau)Z_2. Then

  I(U;Y_tau)=I(U;Y_1)+I(U;Y_2|Y_1).

For the first term,

  I(U;Y_1)=h(U+sqrt(tau)Z_1)-(1/2)ln(2 pi e tau)
           =(1/2)ln(1/tau)+O(1).

Indeed h(U) is finite, adding independent noise cannot lower differential
entropy, and the variance upper bound keeps h(U+noise)=O(1).

For the second term, the conditional Gaussian-channel maximum-entropy bound
and Jensen give

  I(U;Y_2|Y_1)
    <= (1/2)ln(1+ E Var(g(U)|Y_1)/tau)
    <= (1/2)ln(17).

For the final inequality, conditional variance is no larger than squared
distance to g(clip(Y_1,-1,1)); the extension is 4-Lipschitz and
E(U-Y_1)^2=tau, so E Var(g(U)|Y_1)<=16 tau. Therefore

  I(W_S;W_S+sqrt(tau)Z_2)=(1/2)ln(1/tau)+O(1).

For W_P=(U_1,U_2) with independent arcsine coordinates and independent
Gaussian noise, the information adds across coordinates:

  I(W_P;W_P+sqrt(tau)Z_2)=ln(1/tau)+O(1).

Both W_S and W_P have covariance (1/2)I_2. Thus Gaussian heat-flow
information has leading slope 1/2 versus 1 in ln(1/tau), exactly tracking
the joint feature-law dimensions 1 and 2 while Fisher covariance stays
identical. This is a derived diagnostic for these two laws, not a general
archive theorem and not evidence that heat-flow information alone controls
all posterior acquisitions.

INTERPRETATION AND NEXT GATE

This establishes a stronger finite counterexample pair against any claim that
the tangent Fisher spectrum, or even uniformly comparable full Fisher
metrics, determine the leading memory-bit coefficient. It supplies a concrete
candidate extra statistic: the joint reference law's small-noise information
dimension/heat-flow slope. The proof here only compares two explicit laws.
A broad positive theorem would still need a verifiable posterior condition
and a uniform positive reconstruction codec that remains valid under that
condition. Neither arbitrary correlations nor heat-flow slopes alone have
been shown sufficient. The full cycle-1 infinite-mode report remains the
stronger memory separation and carries its own proof and status.

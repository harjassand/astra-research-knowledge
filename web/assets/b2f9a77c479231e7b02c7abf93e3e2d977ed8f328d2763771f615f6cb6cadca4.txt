XXZ PHYSICAL-GATE EXPANSION: LOCAL ANCILLA OBSTRUCTION
Worker c06_l05 | independent checkpoint | 7 October 2026

CLAIM AND STATUS

The current easy-plane gate interface has a sharp local log-concavity boundary at |gamma| = alpha. For either strict outside side, the two-qubit polynomial has an exact positive-curvature witness at the all-ones point. Therefore no nonnegative log-concave local lift can represent that gate by specializing auxiliary variables to positive values; for multiaffine lifts, no fixed auxiliary coefficient can do so either. This rules out a broad class of direct local ancilla repairs.

A quarter-turn/permutation of the Pauli axes does not rescue the easy-axis branch: it creates positive pair-flip terms and a constant term, and the resulting nonhomogeneous local polynomial has a second exact positive-curvature witness near the origin. These are representation obstructions for local log-concave signatures. They do not prove that the physical partition-function problem is hard, and they do not rule out a global encoding whose auxiliary constraints correlate multiple gates and whose answer is obtained only after a coupled network contraction.

No expanded physical interface or new FPRAS is established at this checkpoint.

CURRENT CONDITIONAL INTERFACE

The existing transfer starts from
  H = sum_e [alpha_e (X_u X_v + Y_u Y_v) + gamma_e Z_u Z_v]
      + sum_v [b_v X_v + c_v Z_v],
with alpha_e >= |gamma_e|, b_v >= 0, c_v arbitrary, and rational input. For a rational local step s >= 0, use F_e = I + s A_e with
  A_e = 3 alpha_e I + alpha_e(XX+YY) + gamma_e ZZ.
Its computational-basis table is
  [ a  0  0  0 ]
  [ 0  b  c  0 ]
  [ 0  c  b  0 ]
  [ 0  0  0  a ],
where
  a = 1+s(3 alpha+gamma),
  b = 1+s(3 alpha-gamma),
  c = 2s alpha.
Keeping row bits and complementing column bits gives
  q(x) = a(x1 x2+x3 x4) + b(x1 x4+x2 x3) + c(x1 x3+x2 x4).

Its Hessian eigenvalues are
  a+b+c, a-b-c, -a+b-c, -a-b+c.
The last three are nonpositive exactly on the triangle region; here the first two triangle constraints reduce to |gamma| <= alpha. A homogeneous nonnegative quadratic is log-concave precisely when its Hessian has at most one positive eigenvalue.

EXACT OUTSIDE-CONE WITNESS

Take alpha=1, s=1/10, gamma=11/10. Then
  a=141/100, b=119/100, c=1/5,
  a-b-c=1/50 > 0.
At x=(1,1,1,1), q=2(a+b+c)=28/5 and grad q=(a+b+c)(1,1,1,1). For v=(1,1,-1,-1), which is orthogonal to grad q, the Hessian of q has eigenvalue a-b-c along v. Hence
  (v^T Hess(log q) v)/(v^T v)
     = (a-b-c)/(2(a+b+c)) = 1/280 > 0.
Thus log q is not concave. For gamma=-11/10, the analogous vector v=(1,-1,-1,1) gives the same exact Rayleigh quotient 1/280. The script computes both witnesses with rational arithmetic.

LOCAL ANCILLA NO-GO

Log-concavity is preserved by restriction to a positive coordinate slice: if p(x,z) is nonnegative and log-concave, then x -> p(x,z0) is log-concave for every z0>0. Therefore a local nonnegative log-concave lift cannot specialize to either witnessed gate polynomial.

For a multiaffine lift, extracting a fixed auxiliary monomial also preserves log-concavity. For one auxiliary coordinate,
  partial_z p(x,z) = lim_{t->infinity} p(x,z=t)/t;
each positive slice is log-concave in x, and the pointwise limit is log-concave. Setting remaining auxiliary coordinates to zero is a boundary limit. Iteration gives the same result for a fixed auxiliary coefficient. Since the Chen-Liu input signatures are multiaffine, adding a fixed number/load of local ancillas and then extracting that fixed load cannot cross this boundary.

Scope: this does not exclude a construction in which hidden degrees are coupled across several distinct gates and the required contraction sums several auxiliary sectors. It also does not rule out a physical algorithm based on a different non-local representation.

AXIS-PERMUTATION ATTACK

For alpha=1, gamma=2, s=1/10, globally rotate the Pauli axes so gamma becomes the XX coupling and alpha occupies YY and ZZ. With the same 3 alpha identity shift, the transformed local signature is
  q_rot = A(x1 x2+x3 x4) + B(x1 x4+x2 x3)
          + C(x1 x3+x2 x4) + D(1+x1 x2 x3 x4),
where
  A=1+4s alpha=7/5,
  B=1+2s alpha=6/5,
  C=s(gamma+alpha)=3/10,
  D=s(gamma-alpha)=1/10.
At x=t(1,1,1,1) as t tends to zero, the directional second derivative of log q_rot along (1,1,1,1) tends to 4(A+B+C)/D=116>0. At the explicit positive rational point t=1/100 the exact directional second derivative is
  384427996133320000 / 3372112200386667 > 0.
So this simple relabeling is not a log-concave nonhomogeneous signature. More generally, when the large coupling is moved into a transverse direction, the unequal transverse couplings create D=s(gamma-alpha)>0; the positive constant and degree-two part force positive curvature near the origin. Keeping gamma longitudinal returns the original failed triangle inequality. This covers simple uniform Pauli-axis permutations, not arbitrary continuous local rotations or global encodings.

COSTS, BOUNDARIES, AND NEXT GATE

The inherited easy-plane conditional trace algorithm has polynomial cost in input bits, numerical beta times the supplied norm bound, and inverse accuracy; its counting stage uses the imported log-concave coefficient algorithm and explicit coefficient-range bounds. It is not uniformly polynomial in binary log(beta). None of those global costs is improved by this local obstruction.

The next decisive gate is to test global charge/ancilla encodings that do not reduce to local specialization or fixed multiaffine coefficient extraction. Any successful route must give an explicit representation of the full trace, prove every supplied signature's log-concavity and positive support, charge its degree/ground-set size/coefficient ranges, and account for all precision and Trotter errors. In parallel, test whether bounded multi-gate blocks can have admissible joint signatures even when the individual gate fails; the simple one-edge signature itself cannot be repaired by local LC ancillas.

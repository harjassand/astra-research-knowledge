# Compression of common diagonal physical effects

Status: general POVM/frame formula proved; noncommuting compressions exhibited
exactly; quantitative impossibility proved for monomial computational-basis
encodings against the actual repeated five-qubit BMVZ seed-pair Hamiltonian.
This is a scoped obstruction, not a no-go for coherent encodings in general.

## Setup and the frame formula

Let `L` be a logical Hilbert space of dimension `d`, let `K` have a fixed
computational basis `{|x>}`, and let `V:L -> K` be an isometry. Define the
logical frame vectors and effects

    |v_x> = V^* |x>,       F_x = |v_x><v_x|.

Then

    sum_x F_x = V^*(sum_x |x><x|)V = I_L.

Thus `{F_x}` is a rank-one POVM (zero effects are permitted). For any common
physical diagonal effect

    B = sum_x b_x |x><x|,       0 <= b_x <= 1,

its logical compression is exactly

    A = V^* B V = sum_x b_x F_x.                         (1)

More generally, every diagonal physical effect `B_j` is a classical
postprocessing of this same frame, and all its logical compressions are
`A_j=sum_x b_{j,x}F_x`.

Physical commutativity does **not** generally survive compression. Let
`P=VV^*`. For two commuting physical effects `B_1,B_2`, direct insertion of
`P+(I-P)` gives

    [V^*B_1V,V^*B_2V]
      = V^*B_2(I-P)B_1V - V^*B_1(I-P)B_2V.             (2)

The two terms are leakage through the part of each physical effect that sends
the encoded subspace outside itself. If `B_j ran(V) subset ran(V)` for each
`j`, then this leakage vanishes and the compressions commute. Without that
invariance, they need not. For the full diagonal algebra, invariance under
every computational-basis projector is precisely the boundary that makes
the code subspace a coordinate subspace and all compressions diagonal in a
logical basis.

### Exact small counterexample to preservation of commutativity

Let the logical space be a qubit and the physical space a qutrit. Set

    |tau_0> = |0>,
    |tau_1> = -|0>/2 + sqrt(3)|1>/2,
    |tau_2> = -|0>/2 - sqrt(3)|1>/2,

and let `V` be the isometry whose three rows are
`sqrt(2/3)<tau_i|`. Since `sum_i |tau_i><tau_i|=(3/2)I`, `V^*V=I`.
The commuting diagonal projections

    B_0 = diag(1,0,0),       B_1 = diag(0,1,0)

compress to

    A_0 = (2/3)|tau_0><tau_0|,
    A_1 = (2/3)|tau_1><tau_1|.

In the logical computational basis,

    [A_0,A_1] = [[0, -sqrt(3)/9], [sqrt(3)/9, 0]] != 0.

This is the minimal warning against inferring logical commutativity from a
common diagonal physical `B` or from pairwise commutativity of several such
physical effects.

## Exact compression is easy in isolation; the enforcer is a separate cost

For any logical positive contraction `0<=H<=I`, the Naimark isometry

    V_H |psi> = sqrt(H)|psi>  direct-sum  sqrt(I-H)|psi>

obeys `V_H^*V_H=I`. The common diagonal effect
`B=I_L direct-sum 0_L` has `||B||=1`, is 1-sparse, and compresses exactly:

    V_H^* B V_H = H.

The exact all-state enforcer `C=I-V_HV_H^*` has kernel `ran(V_H)` and gap
one. In general it is dense, and efficient preparation or row access for
`sqrt(H)` is not automatic. Thus a common diagonal logical test by itself
does not obstruct exact compression, while the joint `{V,B,C}` resource
requirement remains substantive. The explicit negative result below concerns
a subclass where the enforcer is in fact optimally sparse.

## Quantitative obstruction for basis embeddings

### Target from the actual repeated BMVZ seed terms

Use the five-qubit rank-one Clifford seed states from the BJSW 5-LCH
propagation decomposition:

    |phi> = (|00010> - |10010>)/sqrt(2),
    |psi> = (|00010> - |01110> - |10110> - |11010>)/2.

The BMVZ path construction contains the repeated clauses

    h_phi,T = I - (I-|phi><phi|)^{tensor T},
    h_psi,T = I - (I-|psi><psi|)^{tensor T},
    H_seed,T = (h_phi,T + h_psi,T)/2.                    (3)

Their occurrence in a valid BMVZ output can be made exact as follows. Start
from the BMVZ equitable QMA-hard projective family
`H_n=(1/m)sum_i Pi_i` with `g=O(1)` nearly equal commuting layers. On a
disjoint five-qubit seed register, add `L=floor(m/g)` copies of `|phi><phi|`
as one new color and `L` copies of `|psi><psi|` as another. The resulting
starting Hamiltonian is

    H'_n = [m(H_n tensor I_seed)
            + L(I_base tensor |phi><phi| + I_base tensor |psi><psi|)]/(m+2L).

The layers remain balanced up to rounding and their minimum weight is
constant. The seed projectors have a common kernel of dimension at least 30,
so `lambda_min(H'_n)=[m/(m+2L)]lambda_min(H_n)` and the promise gap is only
rescaled by a constant. In either new color, every graph vertex carries the
same projector. Thus every path tuple yields exactly the corresponding term
in (3), regardless of self-loops; iterated amplification keeps this form
with the product repetition count `T`. This is an actual BMVZ-generated pair
in an augmented QMA-hard starting family, but (3) is only the two-clause
test. The obstruction below does not claim to encode the full seed-plus-hard
Hamiltonian.

### Encoding subclass and exact image penalty

Consider any monomial computational-basis isometry: for every logical basis
state `|u>`,

    V|u> = exp(i theta_u)|f(u)>,

where `f` is injective into the physical computational basis. The simple
representative is the clean-workspace encoding `V|psi>=|psi>|0^q>`. For
every common physical diagonal effect `B`, equation (1) shows that
`A=V^*BV` is diagonal and positive in the logical basis. Also

    P = VV^* = sum_u |f(u)><f(u)|,
    C = I-P

is itself diagonal and 1-sparse, with

    C>=I-P,       ker(C)=ran(V).

So this subclass already has polynomial (indeed unit) row support, exact
kernel equality, and a unit all-state gap. The only possible failure is the
logical comparison.

### Full-support kernel witness forces failure of every constant-factor comparison

Define the normalized five-qubit vector

    |chi> = [ 3|00010> + 3|10010>
              + sum_(x notin {00010,10010}) |x> ] / sqrt(48).

Every computational-basis coefficient of `chi` is nonzero, and direct inner
products give

    <phi|chi> = (3-3)/sqrt(96) = 0,
    <psi|chi> = (3-1-1-1)/(2 sqrt(48)) = 0.

Therefore `chi^{tensor T}` is annihilated by both repeated clauses in (3):
each factor `(I-|phi><phi|)` and `(I-|psi><psi|)` fixes `chi`. If the BMVZ
data space includes spectator registers, tensor `|+>` on every spectator;
the resulting vector `|Xi>` still has nonzero amplitude on every
computational-basis string and satisfies `H_seed,T|Xi>=0`. The target is
nonzero, since `h_phi,T |phi>^{tensor T}=|phi>^{tensor T}`.

Suppose, for some finite `beta` and any `alpha>0`, a monomial isometry and a
common positive diagonal contraction `B` satisfied

    alpha H_seed,T <= A=V^*BV <= beta H_seed,T.          (4)

The upper inequality evaluated on `Xi` gives `<Xi|A|Xi>=0`. Since `A` is
diagonal positive and every coordinate of `Xi` is nonzero, every diagonal
entry of `A` must vanish; hence `A=0`. The lower inequality in (4) then
forces `H_seed,T=0`, contradicting (3). Thus **no** such `B` exists for any
`alpha>0` and finite `beta`, even though `C` has exact image kernel and gap
one. This rules out exact compression (`alpha=beta=1`) and every constant-
factor two-sided Loewner comparison in this encoding subclass. It is a
kernel-based obstruction, not a Pauli-coefficient mismatch.

## Resource and scope ledger

For the clean-workspace representative, `V` adds only `q` clean qubits;
`C=I-VV^*` is a diagonal 1-sparse operator with entry and row access O(1),
and gap exactly one. Every candidate common diagonal `B` is also 1-sparse
(assuming its diagonal entry is efficiently computable). Nevertheless no
`B` satisfies the required logical comparison. The same proof applies to
any monomial basis injection, independently of its circuit cost.

The frame formula and trine example show why this obstruction cannot be
extended to arbitrary coherent `V`: a non-coordinate code can turn
commuting diagonal effects into noncommuting logical operators. The Naimark
construction even gives exact compression for any one effect, but it does
not supply a low-overhead all-state enforcer. Branch encodings, overcomplete
frames, and data-dependent workspace states remain outside the no-go. The
result also concerns the two actual seed clauses, not a compression theorem
for the complete QMA-hard BMVZ sum.

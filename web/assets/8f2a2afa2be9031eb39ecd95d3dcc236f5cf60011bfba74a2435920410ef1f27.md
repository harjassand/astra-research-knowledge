# Approximate broadcasting to an EB lift: qubit operator lemma and prior-art boundary

## Verdict

The unrestricted bounded-Holevo implication remains **OPEN / UNKNOWN**: for a sequence of finite-dimensional state families (E_n\subset\mathcal D(\mathbb C^{d_n})), bounded Holevo capacity and vanishing two-marginal broadcast error do not yet have a proved dimension-free implication to one common entanglement-breaking (EB) reconstruction. I found no external theorem with that exact interface.

There is, however, an exact dimension-two result for the stronger missing operator lemma. Every unital, trace-preserving, Hilbert–Schmidt-self-adjoint qubit channel that is self-compatible admits an EB channel \(\Psi\) with
\[
  I-\Psi\preceq 2(I-\Phi).
\]
The proof covers channels with negative Bloch eigenvalues as well as the Hilbert–Schmidt-positive subclass. Thus there is no qubit counterexample to a universal factor (c=2); this does not establish the operator lemma in dimensions (d\ge3), nor the bounded-Holevo family theorem.

## Exact interface and proof

Use normalized trace \(\tau=\operatorname{Tr}/2\) and the real Hilbert space of Hermitian (2\times2) matrices with inner product \(\langle A,B\rangle=\tau(AB)\). A channel \(\Phi\) is **self-compatible** when there is a CPTP map \(\mathcal B:M_2\to M_2\otimes M_2\) such that both partial-trace marginals of \(\mathcal B\) equal \(\Phi\). Swapping and averaging the two outputs lets us assume \(\mathcal B\) is swap invariant. The order \(S\preceq T\) is positive-semidefinite order on this Hilbert–Schmidt space.

For a unital qubit channel, the Bloch action is \(\Phi(I)=I\), \(\Phi(\sigma_j)=\sum_i M_{ij}\sigma_i\), with real \(3\times3\) matrix \(M\). Hilbert–Schmidt self-adjointness gives \(M=M^T\). A real symmetric matrix is diagonalized by an orthogonal basis change; choosing its orientation in \(SO(3)\), this change is implemented by unitary conjugation on the qubit. Conjugating the input and both broadcast outputs preserves self-compatibility and the comparator order. It therefore suffices to consider
\[
  \Phi(\sigma_i)=\lambda_i\sigma_i,\qquad \Phi(I)=I.
\]
The argument below only uses that \(\Phi\) is CPTP and self-compatible; it does not require \(\lambda_i\ge0\). If “positive” in the target lemma means positive as a Hilbert–Schmidt operator, that adds \(\lambda_i\ge0\), so it is a subcase.

Let \(|\Omega\rangle=(|00\rangle+|11\rangle)/\sqrt2\), \(J_\Phi=(\mathrm{id}\otimes\Phi)(|\Omega\rangle\langle\Omega|)\), and write the Bell eigenvalues of the Pauli-diagonal Choi state as \(p_0,p_1,p_2,p_3\). With a suitable Bell labeling,
\[
 p_0=\frac{1+\lambda_1+\lambda_2+\lambda_3}{4},\quad
 p_i=\frac{1+\lambda_i-\lambda_j-\lambda_k}{4}\quad(\{i,j,k\}=\{1,2,3\}).
\]
The Choi state of \(\mathcal B\) is a symmetric extension of \(J_\Phi\) to reference \(R\) and outputs \(B_1B_2\). For each Bell projector \(P_k\) on \(RB\), let \(P_{k,1}=P_k\otimes I_{B_2}\) and \(P_{k,2}=P_k\otimes I_{B_1}\). The two projection ranges have \(\|P_{k,1}P_{k,2}\|=1/2\): directly, \(P_{k,1}P_{k,2}P_{k,1}=P_{k,1}/4\). The two-projection norm identity gives \(\|P_{k,1}+P_{k,2}\|=1+1/2=3/2\). Equal marginals then imply
\[
  2p_k=\operatorname{Tr}\!\left[J_{RB_1B_2}(P_{k,1}+P_{k,2})\right]\le\frac32,
  \qquad p_k\le\frac34\quad(k=0,1,2,3).
\]
This is the only compatibility input.

Put \(\nu_i=(2\lambda_i-1)_+\). If all three \(\lambda_i>1/2\), then
\[
 \sum_i\nu_i=2\sum_i\lambda_i-3=8p_0-5\le1.
\]
If exactly two, say \(i,j\), exceed \(1/2\), and \(k\) is the remaining index, then
\[
 \nu_i+\nu_j=2(\lambda_i+\lambda_j)-2=4(p_0-p_k)-2\le4p_0-2\le1.
\]
With one active coordinate, \(\nu_i\le1\) because a channel has \(\lambda_i\le1\); with none the sum is zero. Hence always \(\nu_i\ge0\) and \(\sum_i\nu_i\le1\).

Let \(\Delta_i\) be dephasing in the \(\sigma_i\) eigenbasis and \(\Delta_0(X)=\operatorname{Tr}(X)I/2\). Each is EB, unital, trace preserving, and Hilbert–Schmidt self-adjoint. Define
\[
 \Psi=\left(1-\sum_i\nu_i\right)\Delta_0+\sum_i\nu_i\Delta_i.
\]
This is EB and has Bloch eigenvalues \(\nu_i\). (Equivalently, for Pauli-diagonal unital qubit maps, the EB octahedron is \(\sum_i|\nu_i|\le1\).) On the identity, both \(I-\Psi\) and \(I-\Phi\) vanish. On each \(\sigma_i\),
\[
 1-\nu_i\le2(1-\lambda_i):
\]
when \(\lambda_i>1/2\) this is equality; otherwise it follows from \(\nu_i=0\) and \(1\le2(1-\lambda_i)\). Thus \(I-\Psi\preceq2(I-\Phi)\). Conjugate \(\Psi\) back by the same unitary used to diagonalize \(\Phi\).

For a diagonal \(\Phi\), Pauli twirling any proposed EB comparator preserves EB and the order inequality, so the comparator search can also be restricted to Pauli-diagonal maps. The explicit mixture above is already such a comparator. The proof is algebraic and exact; it uses no numerical solver, asymptotics, or dimension-dependent constants.

## Prior-art audit and boundary

The exact broadcasting and discord results establish nearby but different interfaces:

- Barnum–Caves–Fuchs–Jozsa–Schumacher prove exact broadcasting of a set of mixed states is possible precisely for commuting sets. This is a zero-error characterization, not an approximate, bounded-capacity stability bound: [primary paper, arXiv:quant-ph/9511010](https://arxiv.org/abs/quant-ph/9511010).
- Piani–Horodecki–Horodecki’s no-local-broadcasting theorem concerns one bipartite correlation state; exact local broadcasting is possible precisely for classical-classical correlations. It does not give a single EB reconstruction for a varying ensemble from a two-copy marginal error: [primary paper, arXiv:0707.0848](https://arxiv.org/abs/0707.0848).
- Xie–Fang–Wang–Duan’s approximate-local-broadcasting paper gives SDPs for finite ensembles and correlations. Its Lemma 3 gives a useful channel-level finite-copy result: for any CPTP \(\Lambda:A\to A_1\cdots A_n\) and \(0<\delta<1\), there are a POVM on \(A\) and at least \(n(1-\delta)\) marginal indices \(j\) for which an EB channel \(\mathcal E_j\) satisfies
  \[
  \|\Lambda_j-\mathcal E_j\|_\diamond\le3\left(\frac{(\ln2)|A|^6\log_2|A|}{n\delta^3}\right)^{1/3}.
  \]
  For a symmetric (n)-broadcast channel the marginal is common, so fixed input dimension and (n\to\infty) give an EB lift with this dimension-dependent rate. The target here has only two marginal outputs, ranges over a family of input states, and asks for a dimension-free consequence from small error only on that family plus bounded Holevo capacity. Thus Lemma 3 does not close it: [primary paper, arXiv:1705.06071](https://arxiv.org/abs/1705.06071).
- Piani’s discord hierarchy recalls the finite de Finetti bound for a (k)-Bose-symmetric-extendible channel: an EB channel can be chosen with worst-case reference-assisted trace error at most \(|B|/k\). It also combines Fawzi–Renner recovery with measurement to produce an EB map for a **single supplied bipartite state**, with fidelity at least \(2^{-D(A:\underline B)/2}\). These are respectively (k\to\infty), dimension-dependent channel approximation, and state-dependent recoverability statements—not an operator-order comparator from only 2-compatibility or the bounded-Holevo family implication: [Piani, arXiv:1501.06855](https://arxiv.org/abs/1501.06855); [Fawzi–Renner, arXiv:1410.0664](https://arxiv.org/abs/1410.0664).

The N93 card in the pinned W evidence package explicitly leaves the general bounded-Holevo + vanishing-
\(b_2\) implication open and names the unrestricted positive tracial self-adjoint self-compatible \(\Phi\) to EB \(\Psi\) Dirichlet comparison as an unproved gate. It records the exact factor-2 construction only for the N92 supplied-instrument class. W’s newest relevant additions (cycle-4 detailed-balance attack, N92/N93 and W ledger) were reviewed; X/Y/Z source summaries concern different branches. The current pinned source is [`N93-bounded-holevo-gates.txt`](https://raw.githubusercontent.com/harjassand/astra-research-knowledge/8ede33c2f09a8abe07b430892b3ac4bb71c27c83/cards/N93-bounded-holevo-gates.txt). The nearby symmetric-extension characterization used as context is Chen–Ji–Kribs–Lütkenhaus–Zeng, [arXiv:1310.3530](https://arxiv.org/abs/1310.3530); the qubit Bell-overlap inequality above is derived directly here from the two-projector norm.

## Status, attack, and next gate

**Status:** exact internal proof, qubit-only. No numerical diagnostic was needed. No counterexample to (c=2) exists within the stated unital self-adjoint qubit self-compatible channel class, since the construction proves the bound for all of it. This neither validates the unrestricted (d\)-dimensional operator lemma nor proves the bounded-Holevo (E_n) implication. External novelty and independent proof review remain open.

The decisive next attack is (d\ge3): seek a self-compatible Choi extension for which no EB Choi state induces the required quadratic-form domination, or replace the qubit Bell-overlap/clipping argument with a dimension-free construction of one common EB map. In dimensions above two, PPT no longer characterizes separability, so the qubit EB-octahedron step has no direct replacement.

# Phase 3 addendum: two-species, source-order-three prior art

**Checked:** 2026-10-08 UTC. **Scope:** primary-source check only. I did not review the internal cubic non-explosion proof or the proposed order-5 example.

I found no primary source in this bounded search that states non-explosion for every fully endotactic two-species stochastic mass-action network of maximum source order at most 3, states a dimension-specific lower bound of 4 for explosive networks, or gives a fully endotactic two-species explosive example of source order 3, 4, or 5. This is a source-search result, not a novelty or priority conclusion.

The closest current source is Xu, *On the Regulary of Reaction Systems*, arXiv:2409.05340v2 (2026-05-09). The current arXiv record lists v1 (2024-09-09) and v2 only. Section 2 defines network order as the maximum source-complex ℓ1 size (HTML lines 80-82). Definition 4.4 requires u-endotacticity for **every** $u\in\mathbb{R}^d$ (HTML lines 265-269). Theorem 4.6 proves regularity for second-order endotactic mass-action systems, in every dimension, and its proof uses the special fact that each second-order reaction does not increase total molecule count (HTML lines 286-314; PDF p. 9). It does not state the cubic two-species result. Remark 4.8 says the cited explosive strongly endotactic example has order 10 and that the minimum order for an explosive endotactic stochastic mass-action system remains open (HTML lines 319-321; PDF p. 9). This global open-question statement is compatible with a dimension-specific cubic exclusion, but it does not supply that exclusion.

The two-species upper example Xu cites is Anderson, Cappelletti, Kim, and Nguyen, *Tier structure of strongly endotactic reaction networks*, arXiv:1808.05328v2 (2019-10-03), Example 3.2. It is `0 -> 2A -> 4A+B -> 6A+4B -> 3A`, reported strongly endotactic and explosive for every positive rate choice (HTML lines 199-209; PDF pp. 4-6). Counting reactant coefficients gives maximum source order 10, not a low-order example.

Two apparent matches do not settle this question. Xu Example 4.11 is a termolecular network, `0 <-> S1`, `2S1 -> 3S1`, `3S2 -> 2S2`, reported strongly $(1,1)$-endotactic and explosive on its stated closed classes (HTML lines 334-341; PDF pp. 9-10). It is not fully endotactic: Xu's full definition quantifies over all directions, while this example checks only $(1,1)$-endotacticity; the existing phase-2 audit records the violating $u=e_1$ direction. The source-order-4 one-species chain `A <-> 2A <-> 3A <-> 4A -> 5A` is an almost-sure explosion example in Anderson et al., arXiv:1708.09356v2, Example 3, pp. 8-9, but fails endotacticity at $u=1$ and is not two-species (details and source hash are in `phase2_source_manifest.json`). Xu Remark 4.9's two-species endotactic permanence result concerns deterministic ODEs, not the stochastic CTMC.

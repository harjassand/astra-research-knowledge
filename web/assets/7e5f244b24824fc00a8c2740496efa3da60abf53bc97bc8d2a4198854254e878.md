# Exact minimax probing for a quadratic sensor

## Interface

The state is scalar and follows the known integrator

\[
\dot x(t)=u(t),\qquad x(0)=x_0,\qquad y(t)=x(t)^2+v(t),
\]

on a probe interval \([0,T]\). The input \(u\) is a precommitted, measurable open-loop signal, the full applied input is known exactly, and the observation error is deterministic with \(\|v\|_{L^\infty}\leq\delta\). There is no process disturbance or model error in the exact theorem. The unknown initial state belongs to \([-R,R]\). A controller may record any finite number of samples, or the entire output trace. The probe cost is

\[
E_p=\int_0^T u(t)^2\,dt.
\]

This theorem concerns estimation of \(x_0\); since the input is known, its error equals the error in estimating \(x(T)\) after adding the known displacement.

## Theorem

Let the probe satisfy \(E_p\leq E\), where \(E,T,\delta>0\), and assume

\[
R\geq \frac{1}{2}\sqrt{ET}+\frac{\delta}{\sqrt{ET}}.
\]

Over all precommitted open-loop probes with energy at most \(E\), all finite sampling schedules in \([0,T]\), and all estimators, the worst-case absolute estimation error is at least

\[
\frac{\delta}{\sqrt{ET}}.
\]

The constant probe \(u(t)=D/T\), with \(D=\sqrt{ET}\), and endpoint measurements attain this bound. Thus the open-loop minimax error is exactly \(\delta/\sqrt{ET}\). Giving the estimator the full continuous output trace does not improve this worst-case bound.

## Proof

For a fixed probe define \(q(t)=\int_0^t u(s)\,ds\), and let \(Q=\max_{t\in[0,T]}q(t)-\min_{t\in[0,T]}q(t)\). This full displacement range contains zero because \(q(0)=0\). At any sampled time \(t_i\), the noiseless output as a function of the unknown state is

\[
F_i(x)=(x+q(t_i))^2.
\]

Every sampled displacement lies in this full range. Cauchy–Schwarz gives

\[
Q\leq \int_0^T |u(t)|\,dt\leq \sqrt{T E_p}\leq\sqrt{TE}.
\]

For the lower bound, let \(c=-(q_{\min}+q_{\max})/2\) and \(r=\delta/\sqrt{ET}\), and set \(x_\pm=c\pm r\). Since \(q(0)=0\), the displacement range contains zero, so \(|c|\leq Q/2\leq\sqrt{ET}/2\). The condition on \(R\) ensures \(x_\pm\in[-R,R]\). At every observed displacement \(q\in[q_{\min},q_{\max}]\),

\[
\begin{aligned}
|F_i(x_+)-F_i(x_-)|
&=2r\,|x_++x_-+2q|\\
&=2r\,|2q-(q_{\min}+q_{\max})|\\
&\leq 2rQ\leq 2\delta.
\end{aligned}
\]

The midpoint of the two noiseless output traces is therefore within \(\delta\) of both traces at every time. An adversary can give the estimator this same observed trace under either initial state. The initial states are separated by \(2r\), so every estimator has worst-case error at least \(r=\delta/\sqrt{ET}\). This argument already grants free access to every output time.

For achievability, take \(u=D/T\), so \(q(0)=0\), \(q(T)=D=\sqrt{ET}\), and measure

\[
y_0=x_0^2+v_0,\qquad y_T=(x_0+D)^2+v_T.
\]

Set

\[
\widehat{x}_0=\frac{y_T-y_0-D^2}{2D}.
\]

Then \(\widehat{x}_0-x_0=(v_T-v_0)/(2D)\), hence \(|\widehat{x}_0-x_0|\leq\delta/D=\delta/\sqrt{ET}\). The lower and upper bounds match.

## One-cycle output-feedback stabilizer and charged resources

After the probe, use a constant correction over duration \(T_c>0\):

\[
u_c(t)=-\frac{\widehat{x}_0+D}{T_c}.
\]

For the exact integrator, the final state is

\[
x(T+T_c)=x_0+D-(\widehat{x}_0+D)=x_0-\widehat{x}_0,
\]

so \(|x(T+T_c)|\leq\delta/D\). This is a finite-time output-feedback controller: it takes two scalar measurements, one open-loop excitation, one scalar division, and one constant corrective input.

The probe effort is exactly \(D^2/T\). The correction effort is exactly \((\widehat{x}_0+D)^2/T_c\), and uniformly over \(|x_0|\leq R\) it is at most \((R+D+\delta/D)^2/T_c\). The correction speed is at most \((R+D+\delta/D)/T_c\). If the state must remain in \([-S,S]\), sufficient safety conditions are \(R+D\leq S\) and \(\delta/D\leq S\); the correction path is a line segment from the post-probe state to the final residual, so it stays safe when both endpoints do.

For target radius \(\varepsilon>0\), the one-cycle design must choose

\[
\frac{\delta}{\varepsilon}\leq D\leq \min\{\sqrt{E_pT},\ U_{\max}T,\ S-R\},
\]

and also choose \(T_c\) large enough to meet the correction actuator limit. The condition \(\delta/\varepsilon\leq\min\{U_{\max}T,S-R\}\) is a necessary feasibility gate for this constant-probe controller. The total squared-input cost is bounded by

\[
E_p+\frac{(R+D+\delta/D)^2}{T_c}.
\]

The minimax claim concerns only the probe budget \(E_p\); the correction budget above is charged separately.

If each sensor read has physical error at most \(\delta_s\) and is quantized with step \(\Delta\), use \(\delta=\delta_s+\Delta/2\). With output range contained in \([-\delta_s,(R+D)^2+\delta_s]\), each read requires at most

\[
\left\lceil\log_2\left(1+\frac{(R+D)^2+2\delta_s}{\Delta}\right)\right\rceil
\]

bits up to endpoint coding convention; there are two reads. Computation is constant-size scalar arithmetic, including one division at the selected precision. Dynamics, sensor law, origin, probe displacement calibration, and exact input logging are supplied, not learned by this protocol.

## Bounded displacement error

Suppose the actual probe displacement is \(D+e\) with \(|e|\leq\zeta_p<D\), so that \(x(T)=x_0+D+e\). The same decoder, still using the commanded \(D\), obeys

\[
|\widehat{x}_0-x_0|
\leq \frac{(R+D)\zeta_p+\zeta_p^2/2+\delta}{D}.
\]

If the correction displacement also has an error at most \(\zeta_c\), then the final residual is bounded by

\[
|x(T+T_c)|\leq
\frac{(R+D)\zeta_p+\zeta_p^2/2+\delta}{D}+\zeta_p+\zeta_c.
\]

For bounded additive velocity disturbance \(|w(t)|\leq\bar w\), one may take \(\zeta_p=\bar wT\), \(\zeta_c=\bar wT_c\), provided these bounds also fit the state-safety margin. These terms expose rather than absorb process and actuation mismatch.

## Counterexample and falsifier

With no excitation, \(u\equiv0\), the states \(+a\) and \(-a\) have exactly the same noiseless output for every time. No estimator can guarantee error below \(a\) on an initial set containing both. Thus the rank/observability issue cannot be repaired by a more elaborate estimator while the input is fixed at zero.

For the positive theorem, a decisive falsifier is a calibrated integrator/square-law sensor run in which the two endpoint read errors are certified at most \(\delta\), the applied displacement is certified as \(D\), and yet the formula \((y_T-y_0-D^2)/(2D)\) differs from the true initial state by more than \(\delta/D\). With bounded probe/correction displacement errors, the displayed enlarged bound is the relevant threshold instead.

## Scope and novelty boundary

This is a complete theorem for a scalar, exact, disturbance-free model with a precommitted probe and worst-case bounded sensor noise. It is not a general nonlinear observability or observer theorem. It does not prove optimality over adaptive sensing laws. The output-set viewpoint, finite-horizon observability trajectory design, local Gramian planning, and robust MHE/output-feedback stability are established prior mechanisms. In particular, the set-valued trajectory-design literature is close enough that this exact formula must be treated as an internally reconstructed candidate with novelty and priority unresolved. The strongest demonstrated value is an exact, globally conditioned benchmark and a falsifier for broader claims; no advance beyond current general state-estimation/control baselines is established.

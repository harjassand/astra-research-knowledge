RESULT

There is an exact stationarity identity that retains the height and tilt in
the desired product. In the flat codimension-one model, let h be signed
height above a fixed affine plane and let each centered fit be its parallel
translate through x. Then

  z_x(y)=h(y)-h(x),       e_x(y)=|grad_{T_y V} h|^2,

and, for any compactly supported annular kernel K(x,y),

  2 int K |z_x| e_x dmu
       = - int z_x|z_x| <grad_T K, grad_T h> dmu.

Dyadic annular decomposition and Cauchy-Schwarz give the precise reduction

  P(l) <= C H(l),
  H(l)=int_C int_{B_{Cl}(x)} |z_x(y)|^3 |x-y|^{-m-2} dmu(y) dsigma(x).

Thus the weighted term is controlled if the cubic pair-height potential H
has the required a_i^2 (or o(a_i^2)/eta_i) bound. This is a stationarity
identity, not a generic Dini assertion. The remaining H bound is not a
consequence of the currently listed global mass/height/tilt budgets by any
argument established here.

The center-dependent fits have an exact additive transition in flat graph
coordinates. If S_x is obtained by translating a fixed graph S_0 through
the center x, and u is support height relative to S_0, then

  z_x(y)=u(y)-u(x),
  z_x(y)-z_{x'}(y)=u(x')-u(x).

For the fixed-domain near-flat Dirichlet recentering family
S_c=graph(f+c+v_c), v_0=0, ||D_c v_c||_{C^1}<=C eps_i, this becomes

  z_x(y)=u(y)-u(x)+v_{c_x}(b_x)-v_{c_x}(b_y),
  |v_{c_x}(b_x)-v_{c_x}(b_y)|<=C eps_i a_i |b_x-b_y|,

in the fixed graph coordinates, where u is the old-reference height,
b_x,b_y are horizontal projections, and |c_x|<=C a_i. The transition
remainders are an additive cocycle because they are differences of the same
graphs. This supplies coherence without identifying all S_x with one fit.
It does not provide a square-function bound for u(x')-u(x).

EARLY FALSIFIER: A FIRST-ORDER AFFINE TRANSITION IS REAL

In R^3 take the stationary integral varifold V=Q|P_beta|, where
P_beta={(s,t,z): z=beta s}, |beta| small. On a bounded patch choose the
center set C={(s,0,beta s): |s|<=1/2} with ds measure. Every point of C is a
density-Q point and sigma is 1-Frostman. Use the exact minimal centered fits
S_x={z=beta s_x}, parallel translates of the horizontal reference plane
Pi={z=0}. These fits are coherent and pass through every center. For
y=(t,v,beta t),

  z_x(y)=beta(t-s_x),
  e_x(y)=beta^2/(1+beta^2),
  |x-y|^2=(1+beta^2)(t-s_x)^2+v^2.

Direct integration on fixed comparable patches gives P(l) comparable to
beta^3 and H(l) comparable to beta^3, while the normalized squared
height/tilt excess relative to Pi is comparable to beta^2. In particular
P<=C a^2 in this model, and the stationarity reduction has the right
scaling. But

  c_x-c_{x'}=beta(s_x-s_{x'})

is first order in center separation. Therefore exact minimality plus coherent
translation does NOT imply a quadratic transition such as
|c_x-c_x'|<=C a_i^2 |x-x'| or an O(|x-x'|^2) residual. A global rotation
to P_beta removes this affine mode. Any usable square-function statement
must first quotient the affine/Jacobi modes or control them by the same
stationarity identity. This example falsifies the stronger quadratic
transition shortcut, not the desired weighted-potential bound and not the
source-selected fitting algorithm (which may select P_beta itself).

EXACT DERIVATION OF THE REDUCTION

Assume V is stationary in an open Euclidean set in R^{m+1}, nu is a fixed
unit normal to the reference plane, and h(X)=<X,nu>. For fixed x put
u_x(y)=h(y)-h(x). For any compactly supported C^1 scalar phi, first
variation with vector field phi nu gives

  0=int grad_T phi . P_T nu dmu.

Since grad_T u_x=P_T nu and e=|P_T nu|^2 in codimension one, choose
phi=chi |u_x|u_x. Approximation at u_x=0 gives

  2 int chi |u_x| e dmu
       = -int u_x|u_x| grad_T chi . P_T nu dmu.             (1)

For a smooth dyadic annular partition chi_j(r) comparable to r^{-m} on
r~2^{-j}l, with |D chi_j|<=C r^{-m-1}, (1) yields

  P_j <= C int |u_x|^2 sqrt(e) r^{-m-1} dmu dsigma(x).

Pointwise on each annulus,

  |u_x|^2 sqrt(e) r^{-m-1}
    = [e |u_x| r^{-m}]^{1/2}
      [|u_x|^3 r^{-m-2}]^{1/2}.

Cauchy-Schwarz over (x,y), followed by Cauchy-Schwarz over the dyadic
index (the annuli have bounded overlap), gives P<=C sqrt(P H), hence
P<=C H for truncated radii. Monotone convergence removes the inner cutoff
whenever H is finite. Outer cutoffs contribute only the outermost annulus
and obey the same bound. This argument requires no time/scale ergodicity,
no averaging-in-scale assumption, and no common centered disk.

For a fixed minimal graph reference rather than a plane, the normal-height
coordinate is not an affine harmonic function. Testing with its signed
normal field adds the term u|u| div_T N. Minimality cancels the horizontal
trace at the reference plane; the expected perturbative terms involve
reference curvature times tilt/height and must be bounded and absorbed.
That curved-coordinate extension is not included in the exact proof above.
The frozen conditional radial estimate does contain a small coefficient
times e|z| and related height errors, but it does not establish (1) for a
center-integrated pair kernel or bound H.

THE DECISIVE UNRESOLVED GATE

The exact new sufficient lemma is a cubic increment estimate for the
coherent center-height cocycle:

  H_i(l) <= C a_i^2,

uniformly for fixed l in the same local chart, or the weaker
eta_i H_i(l)=o(a_i^2) required after insertion into the radial inequality.
For Dirichlet-recentered graphs, the already-derived transition formula
reduces this to the corresponding cubic potential of u(y)-u(x), plus a
summable O(eps_i^3 a_i^3) graph-correction term. It is not valid to replace
this gate with a claim that every transition is quadratic: the tilted-plane
model disproves that. It is also not valid to infer the gate from
int e_i dmu_i + int |u|^2 dmu_i <= C a_i^2 and |u|<=C a_i alone; those are
bulk norms, whereas H has a critical pair kernel and includes center traces.

A plausible proof route is a quantitative trace/Hardy estimate for the
height increment on the density-Q center set, after removing the affine
Jacobi mode. The precise object to prove is H_i, not an unspecified Dini
condition. The current local-fit inputs provide small first-height moments
and overlap control for same-scale centered fits, but the supplied overlap
statement excludes translated center fits; no implication from those inputs
to H_i was reconstructed here. The plane model shows that the affine mode
must be retained in the test identity rather than discarded by a false
second-order transition bound.

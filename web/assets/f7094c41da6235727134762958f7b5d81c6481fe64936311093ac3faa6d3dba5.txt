EXACT CLAIMED INTERFACE TO AUDIT

Input: explicit full-column-rank A in Q(i)^(m x r), rational positive local amplitude filters depending only on occupation load in disjoint site blocks. Squared weights b_j(k) must have positive interval support and b_j(k)^2 >= b_j(k-1)b_j(k+1). Two-mode repulsive Gutzwiller filtering uses b_j=(1,1,g_j^2), 0<=g_j<=1. For g_j=0 this forbids double occupancy; r can be below the number of sites, so holes/doping are allowed. Arbitrary spin mixing/complex orbitals are permitted; no spin-sector separation is assumed. Input acquisition and variational optimization are outside the claim.

Target: Z^(-1/2) sum_|S|=r det(A_S) prod_j sqrt(b_j(|S intersect E_j|)) |S>, provided Z>0; explicit phases must be restored. Desired cost is polynomial in input encoding length, m, epsilon^(-1), log(delta^(-1)), with compiler success probability >=1-delta and output trace error <=epsilon, independent of Z/det(A* A) inversely. N63's imported counter must run in polynomial time on every tape; an expected-time black box is insufficient for circuit compilation. The conditional guarantee is not an implemented FPRAS/compiler, a practical gate-count claim, an interacting Gibbs-state preparation algorithm, or a ground-state/variational optimization theorem.

The finite-temperature extension is either exact supplied rational B (prepare D Gamma(BB*) D / Tr) or approximate B=e^(-beta h/2) for number-conserving rational-complex one-body h. The latter charges the numerical value beta||h|| as well as encoding length and accuracy; binary encoding alone does not make arbitrarily large beta polynomial cost. Gamma(L) denotes the direct sum of exterior powers of L. A fixed-particle canonical sector additionally requires a physical-count/ancilla-count quota.

INDEPENDENT DIRECT REDUCTION FOR TWO-FLAVOR REPULSIVE FILTERS

Let n sites have modes u_j,d_j, m=2n, and lambda_j=g_j^2 in [0,1]. Define

  F_A(x)=det(A* diag(x) A)=sum_|S|=r |det A_S|^2 x^S,
  G(x)=prod_j [lambda_j+x_(u_j)+x_(d_j)+x_(u_j)x_(d_j)].

The coefficient of x^([m]) in F_A G is exactly the filtered squared norm Z: complement coefficients are 1 for empty/single physical occupation and lambda_j for double occupation. Each local p=lambda+x+y+xy is log-concave on x,y>0, because

  Hess log p = p^(-2) [ -(1+y)^2, lambda-1 ; lambda-1, -(1+x)^2 ],

whose determinant is nonnegative for 0<=lambda<=1 and whose diagonal is negative. Products preserve log-concavity. F_A is log-concave by concavity of log det on positive definite Hermitian matrices. Its rational coefficients can be evaluated by exact determinants, even for complex A. Thus this is directly a complementary log-concave coefficient instance, without a new counting identity or any inverse Z.

For hard doping lambda=0, one may equivalently use the rank-r truncation of the partition matroid allowing at most one mode at each site. Exact support uses represented-linear/partition matroid intersection. For finite-temperature diagonals replace F_A by

  F_L(x)=det(I+L diag(x))=sum_S det L[S] x^S,
  L=e^(-beta h) or rational BB*.

The same coefficient gives Tr[D Gamma(L) D]. Thus the classical thermal Born law is already obtained from the general coefficient interface as well. These are derived reductions, not a claim that the physical words appear in Chen–Liu.

WHY FINITE-TEMPERATURE COHERENT PREPARATION IS AN EXTENSION, NOT A NEW STATE FORMULA

For supplied rational B, the m-particle graph Slater with orbital matrix A_tilde=[B;I_m] purifies Gamma(BB*). Expanding minors and tracing the bottom modes gives sum_J det B[S,J] overline(det B[S',J])=det((BB*)[S,S']) by Cauchy–Binet. Physical-site filtering acts only on top rows; apply the extended load-filter compiler and trace the bottom modes. Fixed physical number r is selected by bottom quota m-r.

Relative spectral approximation is the correct rare-filter stability contract. If B=q(h) approximates B_0=e^(-beta h/2) multiplicatively within 1±eta on every eigenvalue, then exterior powers obey

 (1-eta)^(2m) Gamma(B_0 B_0*) <= Gamma(BB*) <= (1+eta)^(2m) Gamma(B_0 B_0*).

Congruence by D preserves this order even when D has a kernel. Normalization then gives O(m eta) trace error without inverse filter success probability. Taking eta=O(epsilon/m) and constructing q with charged numerical beta||h|| gives the stated approximation regime. Additive operator error alone would not justify rarity-independent filtering. The graph purification identity and filtered thermal ansatz are elementary/old; a rigorous finite-bit preparation corollary is the residual contribution to assess.

EXPLICIT COUNTEREXAMPLE TO GENERIC LOCAL-VMC RAPID MIXING

For n>=2 use ordered rows u_1,d_1,...,u_n,d_n and n occupied orbitals

  phi_j = u_j + d_(j+1 mod n).

Equivalently A_(u_i,j)=delta_(i,j), A_(d_i,j)=delta_(i-1,j). It has A* A=2I, so the unfiltered squared norm is 2^n. If exactly one row is selected at each site, row i is the unit vector e_i (up) or e_(i-1) (down). A mixed up/down choice repeats a column at a circular boundary. Hence the only nonzero projected minors are all-up with determinant 1 and all-down with determinant (-1)^(n-1). Thus

  projected psi = (|up^n>+(-1)^(n-1)|down^n>)/sqrt(2),
  Z=2, W=2^(1-n).

Any transition changing fewer than n site spin choices cannot connect its two positive-support states. This is an exact failure of irreducibility, not merely an unknown mixing proof. Add permanently empty rows/sites to embed the obstruction in a doped hard-filter instance.

For the soft filter, every nonzero unfiltered configuration is uniquely an orbital choice t in {0,1}^n, choosing u_j or d_(j+1). Double occupancies occur when t_(i-1)=1,t_i=0; their count equals half the circular number of domain walls. Squared filter weight is therefore g^(#walls), and

  Z_g=(1+g)^n+(1-g)^n.

For the ordinary Metropolis chain choosing one of n occupied and one of n unoccupied modes uniformly, exactly n replacements from all-up are determinant-feasible, each creates one double occupancy, and each accepts with probability g^2. Therefore

  P(all-up, complement)=g^2/n,
  spectral gap <= (g^2/n)/(1-1/Z_g) <= 2g^2/n,

where the last inequality uses Z_g>=2. A lazy-chain version has a further factor 1/2. Choose g=2^(-n), which has O(n) rational bits: the inverse gap is exponential in input length. One can also obtain a direct slow-mixing lower bound by the probability of never leaving all-up. This does not refute global/prefix-count samplers, and the cat state itself is easy to prepare; it refutes a supposed uniform guarantee for the conventional local update mechanism.

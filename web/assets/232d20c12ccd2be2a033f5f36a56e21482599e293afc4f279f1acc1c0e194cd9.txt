THEOREM
Let B_sys be a finite-dimensional system, sigma>0 a density matrix there,
and Psi a pure sigma-Petz canonical EB map as in SCALAR_THEOREM_BLIND.txt.
Let R be any finite-dimensional quantum reference and rho_RB any state.
Write q=sqrt(rho_RB), T_sigma(X)=sigma^(-1/4)
Psi(sigma^(1/4)Xsigma^(1/4))sigma^(-1/4), and
  E_R=Tr q[q-(id_R tensor T_sigma)(q)],
  e_R=(1/2)||rho_RB-(id_R tensor Psi)(rho_RB)||_1.
Then
  e_R^2 <= (2+sqrt(2)) E_R <= 4 E_R.
The same result holds for normal states on a separable reference Hilbert
space, by the finite-rank approximation in section 4. No reference-size
factor occurs. id_R tensor Psi is not claimed to be globally EB/pure
canonical; a different block-column argument is used.

For a faithful reference state eta_R, this is exactly the KMS implementation
relative to omega=eta_R tensor sigma, because the eta_R^(+/-1/4) factors
cancel through id_R. For eta_R=rho_R the same statement is valid on its
support; the displayed E_R itself has no inverse of eta_R and is defined
for every rho_RB. Thus there is no hidden faithfulness assumption on rho_R.

1. A NEW BLOCK-COLUMN LEMMA
For an arbitrary square complex matrix Z and any positive matrix F,
  [ (1/2)||ZZ^*-Z^*Z||_1 ]^2
   <=2 Tr(Z^*Z) ||Z-F||_2^2.                         (L)

Proof. Write Z=H+iK with H,K Hermitian, and H=H_+-H_- its Jordan
decomposition. Set a=||H_+||_2, b=||H_-||_2, k=||K||_2. For every
positive matrix P and every Hermitian K,
  ||[P,K]||_1<=sqrt(2)||P||_2||K||_2.
Indeed, -i[P,K] is Hermitian, so trace-norm duality uses only Hermitian
contractions Y. Cyclicity and Hilbert-Schmidt Cauchy-Schwarz reduce the
dual expression to ||[Y,P]||_2||K||_2, while
  ||[Y,P]||_2^2
   =2Tr(P^2Y^2)-2Tr(PYPY)
   <=2Tr(P^2),
because Y^2<=I and Tr(PYPY)=Tr((P^(1/2)YP^(1/2))^2)>=0.
Consequently
  (1/2)||ZZ^*-Z^*Z||_1=||[H,K]||_1<=sqrt(2)(a+b)k.
Also Tr Z^*Z=a^2+b^2+k^2. Distance to the positive cone satisfies
  ||Z-F||_2^2=||H-F||_2^2+k^2>=b^2+k^2.
For completeness, ||H-F||_2^2=||H_+-F||_2^2+||H_-||_2^2
  +2Tr(H_-F)>=||H_-||_2^2.
Finally the exact scalar identity
  (a^2+b^2+k^2)(b^2+k^2)-(a+b)^2k^2
   =(ab-k^2)^2+b^2k^2+b^4>=0
proves (L). No operator Jensen is used.

2. BLOCK FRAME GEOMETRY
Use the finite pure frame V:C^d->C^N from the scalar proof; tensor it
with id_R and embed the physical state. Put
  A=(id_R tensor V) q (id_R tensor V^*),
  B=id_R tensor (V sqrt(sigma) V^*).
The letters A,B here are matrices, not channel labels. B need not have
Hilbert-Schmidt norm 1, and may be singular on the overcomplete support;
neither property is required. Tr A^2=1 and every block column B_i satisfies
  B_i^*B_i=p_i I_R,
where p_i is the same positive atom weight as in the scalar theorem.
Let the block diagonal matrix F have blocks
  f_i=(B^(1/2) A B^(1/2))_ii/p_i >=0.
The complete KMS implementation is
  A'=(id_R tensor mathcal T)(A)=B^(1/2) F B^(1/2).
Positive contraction 0<=id_R tensor mathcal T<=I is exact: on the
Hilbert-Schmidt space this is the tensor product of the identity with
the positive contraction already proved in the scalar proof.
Set S=<A,A'> and D=S-||A'||_2^2. Block trace expansion gives, without
assuming the blocks f_i commute,
  S=||BF||_2^2=sum_i p_i Tr(f_i^2),
  D=(1/2)sum_ij |B_base,ij|^2 Tr((f_i-f_j)^2)
   =(1/2)||[B,F]||_2^2,
  ||A-A'||_2^2=E_R-D, 0<=D<=E_R.
Here B_base=V sqrt(sigma) V^*. The expansion is legitimate because
Tr(f_if_j) is real and symmetric for Hermitian blocks. The coefficient
estimate from section 3 of the scalar proof holds for ANY Hermitian F,
not just a diagonal scalar F: diagonalizing positive B gives exactly
the same coefficient bound, including zero eigenvalues. Therefore
  d^2:=||A-BF||_2^2 <=(1+1/sqrt(2))E_R.                (G)

3. APPLY THE BLOCK-COLUMN LEMMA
Let A_i,B_i be the i-th block columns, Q_i=A_i^*A_i and V_i=B_i/sqrt(p_i).
V_i is an isometry from the reference space into the embedded space.
The two embedded physical states have decompositions
  A^2=sum_i A_i A_i^*,
  (id_R tensor Psi)(rho_RB)=sum_i V_i Q_i V_i^*.
For each i set
  Z_i=A_i V_i^*, F'_i=V_i (sqrt(p_i) f_i) V_i^*>=0.
Then
  Z_iZ_i^*=A_iA_i^*, Z_i^*Z_i=V_iQ_iV_i^*,
  Tr Z_i^*Z_i=Tr Q_i=:q_i,
  ||Z_i-F'_i||_2^2=||A_i-B_i f_i||_2^2=:d_i^2.
Lemma (L) gives the subnormalized disturbance e_i^2<=2q_i d_i^2.
Triangle inequality and Cauchy-Schwarz, using sum_i q_i=Tr A^2=1,
give
  e_R<=sum_i e_i<=sqrt(2)sum_i sqrt(q_i)d_i
     <=sqrt(2 sum_i d_i^2)=sqrt(2)d.
Combining with (G) yields
  e_R^2<=(2+sqrt(2))E_R.
This step replaces the scalar rank-one trace formula, so the complete
claim does not rest on falsely treating mixed reference blocks as pure.

4. SEPARABLE NORMAL REFERENCES
For a normal rho_RB with a separable, possibly infinite-dimensional R,
take increasing finite-rank projections P_n on R with P_n->I strongly.
Let t_n=Tr[(P_n tensor I)rho_RB] and, omitting any initial zero t_n,
  rho_n=(P_n tensor I)rho_RB(P_n tensor I)/t_n.
Then t_n->1 and rho_n->rho_RB in trace norm. The reference-preserving
channel id_R tensor Psi is trace-norm contractive, hence e(rho_n)->e(rho).
Also sqrt(rho_n)->sqrt(rho) in Hilbert-Schmidt norm. One elementary
justification uses trace-norm convergence to obtain operator-norm
convergence, continuous functional calculus for sqrt to obtain
operator-norm convergence of the roots, density of finite-rank tests
to obtain weak Hilbert-Schmidt convergence, and the equal root norms
||sqrt(rho_n)||_2=||sqrt(rho)||_2=1 to obtain strong Hilbert-Schmidt
convergence. The bounded contraction id_R tensor T_sigma therefore
gives E(rho_n)->E(rho). Applying the finite-reference inequality to
rho_n and taking the limit proves the claim. No infinite-dimensional
reference inverse, eigenvalue lower bound, or energy constraint is used.
Arbitrary larger reference Hilbert spaces reduce to a separable support
for a normal density operator (and the finite-dimensional B system).

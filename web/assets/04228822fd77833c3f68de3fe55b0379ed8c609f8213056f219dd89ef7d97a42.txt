CYCLE 4 LEAF — TWO ALL-RATE EXTENSIONS BY SUBSTRATE TRANSFERS
=============================================================
Date: 2026-10-08
Status: INTERNALLY-PROVED-CANDIDATE for the exact CTMC families and
potentials below. No novelty or priority claim.

Outcome
-------
Starting from the complete catalyst-substrate family in the cycle-3
exponential Foster report, I obtain two separate weakly reversible
extensions with exact all-state positive-recurrence proofs for every fixed
strictly positive finite rate vector:

1. Arbitrary reversible substrate conversions can be added. A potential
   exponential in total substrate count is exactly invariant under every
   conversion and gives the required drift for the original paired and
   autocatalytic reactions.
2. Arbitrary finite catalytic cross-feed pairs
   A_j+B_i <-> A_j+B_i+B_l (i != l) can instead be added. A sum of
   substrate-wise exponentials works: when the target count is bounded,
   base substrate removal controls an unbounded source; when the source is
   bounded, target removal controls an unbounded product; when both grow,
   the reverse feed reaction controls the forward feed term.

These are two proved branches, not a theorem for a network containing both
arbitrary conversions and arbitrary cross-feeds at once. A final section
records the first drift mismatch for the total-substrate potential on the
feed branch. That mismatch is a failure of that potential only, not a
nonrecurrence example.

1. Shared base network and CTMC convention
-----------------------------------------
There are finite nonempty sets of catalysts A_j (j=1,...,r) and substrates
B_i (i=1,...,s), with integer k_ji >= 1. For every j and i include

  0 <-> A_j,
  A_j <-> A_j+B_i,
  A_j+B_i <-> (k_ji+1)A_j+B_i.

Write the six positive finite fixed rates as alpha_j, delta_j, p_ji,
q_ji, u_ji, v_ji, in the order shown. Use standard stochastic mass-action
propensities, with falling factorial (n)_m:

  alpha_j, delta_j a_j, p_ji a_j, q_ji a_j b_i,
  u_ji a_j b_i, v_ji (a_j)_(k_ji+1) b_i.

All reaction rates in this report refer to physical-time CTMC propensities.
The base graph has one linkage class, is weakly reversible, and has
stoichiometric rank r+s. It is irreducible on the full nonnegative lattice:
immigrate a catalyst if needed, clear each B_i using A_j+B_i -> A_j, then
drain the catalysts. To build a target, immigrate its catalyst counts and
use A_j -> A_j+B_i to add the required substrate counts; if the target has
no catalyst, use and then drain a temporary catalyst. Every prescribed
finite path has positive probability. The added pairs preserve these paths.

Put A= sum_j a_j, B= sum_i b_i, alpha_sum=sum_j alpha_j, and
H=sum_j alpha_j lambda_j, where lambda_j>0. For both branches the only
boundary indicator is I_0=1{A=0}. Its exact generator is

  L I_0 = -alpha_sum I_0 + sum_j delta_j 1{a=e_j}.

Only immigration leaves A=0, and only death of the sole catalyst enters it.
The reverse autocatalytic reaction leaves one A_j, so it does not enter this
identity.

2. Branch X: arbitrary reversible substrate conversions
--------------------------------------------------------
For any finite set of pairs {i,l}, one may add, for any catalysts j,

  A_j+B_i <-> A_j+B_l,

with arbitrary strictly positive finite forward and reverse rates. Each
added reaction preserves A and B, so its jump in a function of (a,B) is
exactly zero. The complexes A_j+B_i and A_j+B_l already belong to the base
linkage class; the enlarged graph remains weakly reversible and has one
linkage class. The same proof also permits uncatalyzed reversible pairs
B_i <-> B_l at arbitrary positive rates; those pairs preserve the
potential too, though they form additional linkage classes.

Choose R>1 close enough to 1 that

  chi_j := lambda_j delta_j - (R-1) sum_i p_ji > 0
  for every j.

This is always possible for the fixed positive rates. Set

  V_X(a,b) = sum_j lambda_j a_j + R^B + K I_0,
  K > (H+1)/alpha_sum.

This is positive and norm-like. Let c=R-1 and d=1-R^(-1). Directly
summing each rate times its exact jump gives

  L V_X = H - K alpha_sum I_0 + K sum_j delta_j 1{a=e_j}
       + sum_j a_j G_j(b)
       - sum_(j,i) lambda_j k_ji v_ji (a_j)_(k_ji+1) b_i,

  G_j(b) = -lambda_j delta_j
       + c R^B sum_i p_ji
       - d R^B sum_i q_ji b_i
       + lambda_j sum_i k_ji u_ji b_i.

Every substrate-conversion term is absent from this identity because its
potential jump is zero. In particular, no restriction on any conversion
rate appears.

Let q_j^* = min_i q_ji > 0 and U_j=max_i(k_ji u_ji). Then

  G_j(b) <= -lambda_j delta_j + c R^B sum_i p_ji
             - d q_j^* B R^B + lambda_j U_j B.

At B=0, G_j=-chi_j<0. As B tends to infinity, G_j tends to minus
infinity: the negative B R^B term dominates R^B and B. This is uniform over
substrate compositions at a fixed B, since all q_ji are positive and s is
finite.

For A=0, all A-dependent terms vanish and

  L V_X(0,b)=H-K alpha_sum < -1

for every b. Consider an escaping state sequence. If B tends to infinity,
each G_j tends to minus infinity; when A>=1 their weighted sum does too.
The only positive boundary term is bounded by K max_j delta_j, and all
falling-factorial terms are nonpositive. Thus L V_X tends to minus
infinity on that subsequence.

If B is bounded, pass to a subsequence with b fixed. When b=0, each
G_j=-chi_j<0, so an unbounded catalyst coordinate makes the drift tend to
minus infinity. When b is fixed and nonzero, choose i_0 with b_i0>=1. For
each j with a_j tending to infinity, the reverse autocatalytic term

  -lambda_j k_ji0 v_ji0 b_i0 (a_j)_(k_ji0+1)

has degree k_ji0+1>=2, while the remaining terms involving a_j are at most
linear. It therefore drives that catalyst contribution to minus infinity.
Coordinates a_j that remain bounded contribute bounded terms. This covers
every escaping sequence, so {x: L V_X(x)>-1} is finite.

3. Branch F: arbitrary catalytic cross-feed pairs
-------------------------------------------------
Instead of adding conversion pairs, choose any finite set F of triples
(j,i,l) with i != l and add

  A_j+B_i <-> A_j+B_i+B_l

with arbitrary strictly positive finite rates sigma^+_jil and sigma^-_jil.
The reverse propensity is sigma^-_jil a_j b_i b_l. Every added pair is
reversible and attaches its new complex to the existing linkage class.

Choose R_i>1 close enough to 1 that

  chi_j := lambda_j delta_j - sum_i p_ji(R_i-1) > 0
  for every j.

Such choices always exist. Define c_i=R_i-1, d_i=1-R_i^(-1), and

  V_F(a,b) = sum_j lambda_j a_j + sum_i R_i^(b_i) + K I_0,
  K > (H+1)/alpha_sum.

This is positive and norm-like. The exact generator is

  L V_F = H - K alpha_sum I_0 + K sum_j delta_j 1{a=e_j}
       + sum_j a_j G_j(b)
       - sum_(j,i) lambda_j k_ji v_ji (a_j)_(k_ji+1) b_i,

  G_j(b) = -lambda_j delta_j
       + sum_i [p_ji c_i R_i^(b_i)
                - q_ji d_i b_i R_i^(b_i)
                + lambda_j k_ji u_ji b_i]
       + sum_((i,l):(j,i,l) in F)
             [sigma^+_jil c_l b_i R_l^(b_l)
              - sigma^-_jil d_l b_i b_l R_l^(b_l)].

The feed reaction changes only B_l. Its forward and reverse potential jumps
are respectively c_l R_l^(b_l) and -d_l R_l^(b_l), which gives the last
line exactly.

Here is the all-state substrate escape argument. Take any sequence with
|b| tending to infinity and pass to a subsequence on which every coordinate
is either a fixed integer or tends to infinity. Let D be the set of
diverging coordinates. For each j and i in D, the base contribution

  p_ji c_i R_i^(b_i) - q_ji d_i b_i R_i^(b_i)
      + lambda_j k_ji u_ji b_i

tends to minus infinity; the negative term is of order b_i R_i^(b_i),
while the positive terms are only order R_i^(b_i) and b_i.

For a feed edge (i,l), its positive forward term is handled by the
following exhaustive cases:

* If i diverges and l is fixed, it is O(b_i), so the q_ji removal term
  proportional to b_i R_i^(b_i) dominates it.
* If i is fixed and l diverges, it is O(R_l^(b_l)), so the q_jl removal
  term proportional to b_l R_l^(b_l) dominates it.
* If both i and l diverge, combine forward and reverse feed terms as
  b_i R_l^(b_l)[sigma^+_jil c_l - sigma^-_jil d_l b_l]. The bracket is
  eventually negative and tends to minus infinity because sigma^- and d_l
  are positive and b_l tends to infinity.
* If both are fixed, the contribution is bounded.

There are finitely many substrates and feed edges. In the first two cases,
the positive terms are little-o of the indicated base removal terms; in the
third case the paired net feed contribution is eventually nonpositive.
Thus G_j(b) tends to minus infinity for every j whenever |b| tends to
infinity.

On A=0, feed reactions are disabled and L V_F=H-K alpha_sum<-1. If A>=1
and |b| tends to infinity, every active catalyst has G_j(b) tending to
minus infinity, so the drift does too; the sole-catalyst boundary surcharge
is bounded and the reverse autocatalytic terms are nonpositive. If b is
bounded, pass to a fixed b. At b=0, G_j=-chi_j<0. At fixed b!=0, the same
degree-(k+1) reverse-autocatalytic argument from Branch X controls every
unbounded a_j. Hence {x: L V_F(x)>-1} is finite.

The feed rates are unrestricted: in the only case where the forward feed
term could share the same exponential scale as a diverging product count,
the reverse feed term has an additional factor b_l and eventually dominates.
When the product count stays bounded, the forward term is only linear in
the source count and the source's exponential substrate-removal term
dominates.

4. CTMC recurrence conclusion and scope
---------------------------------------
For either branch, V is proper, the set {L V>-1} is finite, and hence L V
is globally bounded above by some finite C. Every state has finite total
exit rate, and a V-sublevel set and its one-jump boundary are finite.
Localized stopped Dynkin therefore gives, for
tau_R=inf{t:V(X_t)>=R},

  P_x(tau_R<=t) <= (V(x)+Ct)/R.

Since infinitely many jumps cannot occur in a finite set with bounded exit
rates, letting R tend to infinity rules out explosion in physical time.
The base paths above retain irreducibility on the full lattice. The standard
continuous-time Foster criterion then gives positive recurrence and a
unique invariant probability for each fixed positive finite rate vector.
No embedded-chain clock substitution is used.

The two branches are distinct. The total-count exponential in Branch X
makes conversions exactly neutral. The coordinatewise exponential in
Branch F makes a catalytic feed edge manageable. This report does not prove
the union with arbitrary conversion and arbitrary feed edges simultaneously,
does not extend either result to sparse catalyst-substrate incidence, and
does not give uniform stationary moments or mixing bounds over rate boxes.
The choices of R and K may depend on the fixed rate vector. These are
family-specific internal proofs, not a general weakly reversible recurrence
theorem.

5. Exact failed interface for the wrong feed potential
------------------------------------------------------
The total-count potential from Branch X is not a valid all-rate treatment
of cross-feeding. For one feed edge

  A_j+B_i <-> A_j+B_i+B_l,  i != l,

consider V_X= sum lambda a + R^B + K I_0 and the states
a=e_j, b_i=n, b_l=0, with all other b coordinates zero. The forward feed
rate is sigma^+ n and its jump is (R-1)R^n. Its reverse rate is zero.
The base B_i-removal contribution is -q_ji n(1-R^(-1))R^n. Together these
terms equal

  n R^n (R-1) [sigma^+_jil - q_ji/R].

If sigma^+_jil >= q_ji, this coefficient is strictly positive for every
R>1, so L V_X tends to plus infinity along these states. The bounded
indicator correction and reverse autocatalytic term cannot repair it
(a_j=1 and k_ji>=1 makes the latter zero). This identifies the first
failure of the total-count drift interface at an empty product coordinate.
It does not contradict Branch F, whose coordinatewise exponential avoids
this interface, and it is not evidence that this feed network is transient.

Reproduction / proof status
---------------------------
The report gives symbolic generator identities and all-state escape
arguments; there is no finite-grid check because it would not strengthen
these proofs. A cold review should check both escaping-sequence case splits,
the stopped-Dynkin localization, and the linkage/irreducibility statements.
No deterministic permanence result is used to infer CTMC recurrence.

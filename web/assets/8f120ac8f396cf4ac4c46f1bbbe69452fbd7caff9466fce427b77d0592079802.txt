# c03_l03 final report

## Outcome

A single explicit integer matrix can encode the perfect-matching count in one hard-projected coefficient c_k(F), by balanced-digit extraction. The proof is complete, but the encoding uses entries with Theta(3^(m-1) log B) bits for an m-edge graph, so it is exponentially large. It is a costed exact representation, not a polynomial-time #P-hardness reduction or an approximation-preserving result.

The initial K4 counterexample remains intact: direct untagged adjacency weights do not count matchings because determinant cross terms interfere. The exact tagged construction separates those terms by base-3 exponent vectors, then pays exponential representation cost. The independent support boundary still applies: zero versus positive only decides whether a perfect matching exists.

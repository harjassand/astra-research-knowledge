TARGET AND CLAIM
The assigned interface asks whether the supplied balance of determinant-weighted linear-matroid-parity hole ratios can be acquired without count oracles, using determinant leverage scores or convex optimization. Write, for even n and even retained R,

  f(U) = sum_{I subset R, |I|=|R|/2} |det F[I,R\\I]|^2,
  R=[n]\\U,  g(ij)=f({i,j})/f(empty),  r_i=max_{j!=i} g(ij).

The balance interval used by the transferred capacity proof is 1/4 <= r_i <= 1 after calibration. The current cycle4 report proves capacity conditional on already-balanced ratios and explicitly leaves their acquisition to the absent sampler.

Exact obstruction to the proposed ordinary-leverage route. For n=4, let

  F = diag(J,R(c,s)),  J=[[0,-1],[1,0]],
  R(c,s)=[[c,-s],[s,c]],  c=(1-u^2)/(1+u^2), s=2u/(1+u^2),
  u=2^(-L), L>=1.

This is a rational orthogonal matrix, so its condition number is exactly one. Let V=[I,F^T], the 4-by-8 matrix whose size-four basis weights define the unfiltered determinant DPP. Since VV^T=2I, Cauchy–Binet gives total basis weight det(VV^T)=16, and every one of the eight columns has leverage v^T(VV^T)^(-1)v=1/2. These leverage scores, and indeed VV^T itself, are independent of u.

The hard paired partition is f(empty)=sum_{|I|=2}|det F[I,I^c]|^2. Block diagonality forces I to contain exactly one coordinate from each 2-by-2 block; the four surviving minors each have squared magnitude s^2. Hence f(empty)=4s^2. For holes U={0,1}, the retained block is R(c,s), so f(01)=|F_23|^2+|F_32|^2=2s^2. For U={2,3}, the retained block is J, so f(23)=|F_01|^2+|F_10|^2=2. A cross-block hole pair leaves one coordinate from each block and has f(ij)=0. Therefore

  g(01)=1/2,  g(23)=1/(2s^2)=(1+u^2)^2/(8u^2),
  g(ij)=0 for cross-block pairs,
  (r_0,r_1,r_2,r_3)=(1/2,1/2,1/(2s^2),1/(2s^2)).

For u=2^(-L), the last two row maxima are 2^(2L-3)(1+2^(-2L))^2, exponential in the O(L)-bit input length, although every ordinary column leverage remains exactly 1/2 and F remains perfectly conditioned. The hard-pair event has probability f(empty)/16=s^2/4=u^2/(1+u^2)^2 under the unfiltered DPP, so rejection from that DPP takes Theta(2^(2L)) expected samples. The exact formulas generalize to F=direct-sum_l R(c_l,s_l), n=2m: f(empty)=2^m product_l s_l^2 and g(B_l)=1/(2s_l^2) for the two-hole set B_l of block l, while all ordinary column leverages remain 1/2.

Convex-optimization interface. Let h(z)=sum_{U even} f(U) z^U be the signed-hole polynomial with signs removed. Then h(0)=f(empty), its first derivatives vanish at 0, and for i!=j, partial_i partial_j log h(0)=f(ij)/f(empty)=g(ij). Thus acquiring the needed row maxima by a coefficient/gradient method requires the hard partition and its second-order hole coefficients, or a multiplicative estimator for them. The stable representation and support/witness oracle do not supply these numerical values. Optimizing log det(VV^T) is a count-free convex surrogate for the unfiltered DPP, but here it is constant (log 16) as u varies while the target g(23) ranges exponentially. Convexity of log h(e^x) alone is not an evaluation or gradient oracle. The OA113 one-pass scale update is valid once upper estimates G_ij of g_ij are available; it does not produce those estimates.

COSTS, BOUNDARIES, STATUS
The example has dimension four and exact rational arithmetic with O(L)-bit entries and ratios; the diagnostic is polynomially small. Ordinary leverage computation is polynomial-time and gives no information beyond 1/2 in this family. Rejection costs Theta(2^(2L)) expected samples. This refutes leverage-only inference and naive conditioning/rejection, not every polynomial-time algorithm inspecting F. The matrix explicitly contains u, so this is not an information-theoretic impossibility. The exact block formula is a structured subclass, not a lower bound for general parity counting. No general balance acquisition, approximate count oracle, hardness theorem, or parity sampler has been established.

The next decisive gate is an explicit polynomial-bit method that returns multiplicative estimates of all needed g(ij), or otherwise certifies a balancing scale, without evaluating the hard paired partition. A candidate must survive the orthogonal weak-block family and its multi-block extension, and must charge error, bit precision, and sample cost. If its only input is ordinary leverage, the example rules it out; if it optimizes the hole polynomial, it must explain how its values/gradients are acquired.

# Repeating noncommuting quantum verifiers: exact scope and failure modes

## Verdict

There is a reusable, dimension-free bound for a fixed sequence of noncommuting *projective* pass tests applied sequentially to the same quantum system. If the pass tests are (P_1,\ldots,P_m), the input is a density operator \(\rho\), and

\[
  \varepsilon_i=\operatorname{Tr}[(I-P_i)\rho],
\]

then the probability that every sequential Lüders test passes obeys

\[
  p_{\rm all}=\operatorname{Tr}(P_m\cdots P_1\rho P_1\cdots P_m)
  \ge \max\{0,1-4\sum_{i=1}^m\varepsilon_i\}.
\]

The tests need not commute, act on separate subsystems, or see independent states. They may act on one globally entangled state, provided the list of projectors and the Lüders instruments are fixed. This is a noncommutative union bound, not a product rule. It is Gao's published sequential-projective-measurement theorem; his theorem also gives a postselected-state disturbance bound. [Gao, *Quantum union bounds for sequential projective measurements*](https://arxiv.org/html/1410.5688), Theorem 1.

The decisive boundary is the *instrument*. One-shot effects alone do not specify the postmeasurement state, so the bound cannot be transferred to arbitrary verifier channels, adaptive interactive strategies, or independently re-prepared/entangled rounds by replacing each test with its effect. A two-dimensional exact counterexample below has noncommuting effects whose one-shot pass probabilities both approach one, while the sequential pass probability approaches zero. For projective tests, a different exact counterexample shows that even the same test repeated on the same system does not amplify soundness multiplicatively.

## Exact fixed-sequence results

Let \(\rho\) be any state on the full joint Hilbert space, including any retained reference or prover workspace, and let \(P_i=P_i^*=P_i^2\) be the pass projector for round \(i\). Each measurement is the binary projective measurement \(\{P_i,I-P_i\}\), with Lüders update on the accepted branch. The unnormalized all-pass state after \(m\) tests is \(P_m\cdots P_1\rho P_1\cdots P_m\). Purifying \(\rho\) and applying Gao's pure-state inequality proves the mixed-state form without a dimension or separability premise.

When the projectors commute, \(I-\prod_iP_i\le\sum_i(I-P_i)\), so the sharper classical union bound \(p_{\rm all}\ge1-\sum_i\varepsilon_i\) holds. Without commutation this sharper operator inequality fails in general; the factor-4 Gao bound is a safe linear guarantee. The theorem uses each \(\varepsilon_i\) evaluated on the *same untouched input* \(\rho\), and requires \(\sum_i\varepsilon_i<1/4\) for a positive lower bound. It does not say \(p_{\rm all}=\prod_i(1-\varepsilon_i)\).

For one repeated Lüders POVM effect \(0\le E\le I\), the exact all-pass probability is instead

\[
  p_m=\operatorname{Tr}(E^m\rho).
\]

If \(\operatorname{Tr}(E\rho)=1-\varepsilon\), scalar Jensen gives \(p_m\ge(1-\varepsilon)^m\ge1-m\varepsilon\). For a projector \(E=P\), this improves to the exact identity \(p_m=\operatorname{Tr}(P\rho)\): after the first pass, repeating the same projective test does not amplify. Example: \(\rho=I/2\), \(P=|0\rangle\langle0|\). Every number \(m\) of same-system repetitions has all-pass probability \(1/2\), whereas the independent-product guess \((1/2)^m\) tends to zero. Gao notes the same-effect POVM Jensen bound and explicitly flags sequential POVMs/general measurements as a separate scope question in his discussion.

Order and noncommutation already invalidate a product-of-marginals calculation for two projectors. Take \(\rho=|0\rangle\langle0|\), \(P_1=|+\rangle\langle+|\), \(P_2=|0\rangle\langle0|\). Their untouched-input pass probabilities are \(1/2\) and \(1\), but sequential pass probability is

\[
  \operatorname{Tr}(P_2P_1\rho P_1P_2)=1/4.
\]

Reversing the order gives \(1/2\). The products of marginals would give \(1/2\) in either order. This is a direct finite-dimensional diagnostic of the difference between sequential measurements and independent trials.

## Shared registers, entanglement, and adaptivity

For disjoint local projectors \(P_A\) and \(P_B\) on an entangled state, the joint pass probability is \(\operatorname{Tr}[(P_A\otimes P_B)\rho_{AB}]\), not the product of local marginal probabilities unless the state factorizes (or a suitable independence condition is otherwise proved). On \(|\Phi^+\rangle=(|00\rangle+|11\rangle)/\sqrt2\) with \(P_A=P_B=|0\rangle\langle0|\), each marginal passes with probability \(1/2\), while both pass with probability \(1/2\), not \(1/4\). Entanglement itself does not invalidate Gao's bound: apply it to the global \(\rho_{AB}\) and the two global projectors \(P_A\otimes I\), \(I\otimes P_B\). It invalidates independent-round multiplication.

An arbitrary adaptive rule that chooses the next binary projective test based only on prior pass/fail bits has a special simplification: conditioned on the event that *all* tests pass, it follows one deterministic all-pass branch. Freeze that branch's projectors and apply Gao's theorem, if each selected projector has a supplied small rejection probability on the same initial global state. Random schedules also follow by conditioning on the schedule, if the bounds hold uniformly. This does not cover an interactive prover that applies a new operation between rounds, multiple accepted labels that branch into different future tests, or a verifier whose supplied guarantees only concern average/marginal tests. Those models require a comb/instrument-specific theorem or history-wise conditional error bounds.

The exact adaptive sufficient condition is elementary. At every reachable history \(h\), let \(q_i(h)\) be the conditional probability that round \(i\) rejects, given survival to that history and the actual postmeasurement state. If \(q_i(h)\le\delta_i\) for every such history, then

\[
  \Pr[\text{all pass}]\ge\prod_i(1-\delta_i)\ge1-\sum_i\delta_i.
\]

No independence or commutation is needed, but the conditional guarantees are stronger data than one-shot errors on the initial state. For a large adaptive tree, verifying those guarantees can require accounting for every reachable branch; no branch-acquisition or strategy-description cost is hidden in the inequality.

Here is an exact counterexample showing why effects alone cannot replace that condition. Let \(0<\epsilon<1\), start with \(\rho=|0\rangle\langle0|\), and give verifier 1 the two-outcome instrument whose accepted CP map has Kraus operators

\[
  K_0=\sqrt{1-\epsilon}|1\rangle\langle0|,\qquad K_1=|1\rangle\langle1|,
\]

and whose rejected Kraus operator is \(K_-=\sqrt\epsilon|0\rangle\langle0|\). The effects sum to identity. The first pass effect is \(E_1=(1-\epsilon)|0\rangle\langle0|+|1\rangle\langle1|\), so its one-shot pass probability is \(1-\epsilon\), but its accepted output is \(|1\rangle\langle1|\). Let verifier 2 be the projective pass test \(Q=|\phi\rangle\langle\phi|\), where \(|\phi\rangle=\sqrt{1-\epsilon}|0\rangle+\sqrt\epsilon|1\rangle\). Its one-shot pass probability on the original \(|0\rangle\) is also \(1-\epsilon\), and \([E_1,Q]\ne0\). Sequentially, the first pass occurs with probability \(1-\epsilon\), then the second passes with probability \(\epsilon\), hence

\[
  p_{\rm all}=(1-\epsilon)\epsilon\longrightarrow0.
\]

This does not contradict Gao: verifier 1 is not the Lüders instrument for its effect. It shows that a repeated-verifier theorem must specify its instruments and feedback interface, not merely its POVM effects.

## Decisive next gate

For a concrete proposed verifier, obtain its full round instrument (including accepted Kraus maps, rejected maps, retained environments, reset/re-preparation rules, prover messages, and verifier randomness), then decide which interface applies: (a) fixed projectors on one global state, (b) one repeated Lüders effect, (c) conditional-history error guarantees, or (d) a genuinely interactive strategy/parallel-repetition game. Only (a) admits Gao's stated bound directly. Keep verifier-description acquisition, strategy access, state preparation, and numerical precision separate from the theorem's dimension-free probability inequality.

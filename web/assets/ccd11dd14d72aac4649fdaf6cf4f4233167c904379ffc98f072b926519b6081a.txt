Cycle 4 leaf: quantitative physical clock for sparse support switching
Date: 2026-10-08
Status: independent internal derivation for the sparse paired-edge family;
exact compact-box constants and finite diagnostic supplied. Not externally
reviewed. The cited CTMC Foster theorem is an input only after the separate
nonexplosion proof below.

Finding
-------
For any fixed finite sparse bipartite support with every included reverse
pair present, positive immigration/death for every catalyst, and rates in a
compact box bounded away from zero and infinity, the support-corrected
Lyapunov function from the Cycle 3 sparse extension admits uniform constants
for (i) a stopped-Dynkin nonexplosion bound, (ii) a common finite return set
inside each closed class, and (iii) an exponential moment of physical time
to that set and of the first return to it after one jump. Thus the relevant
return-time exponential moment does follow here, by a stronger geometric
physical-time Foster inequality. It is not obtained from a reaction-event
count estimate. The embedded event chain still has no established
exponential step-return bound, and the CTMC result does not bound its jump
activity or its invariant event law.

1. Model, rate-box interface, and closed classes
------------------------------------------------
Let J and I be finite, E subset J x I be fixed, and k_ji>=1 be fixed finite
integers on edges. For every j include 0<->A_j with rates alpha_j,delta_j;
for every (j,i) in E include

  A_j <-> A_j+B_i                 rates p_ji, q_ji,
  A_j+B_i <-> (k_ji+1)A_j+B_i     rates u_ji, v_ji.

Propensities are stochastic mass action: 1, delta_j a_j, p_ji a_j,
q_ji a_j b_i, u_ji a_j b_i, and v_ji (a_j)_(k_ji+1)b_i, respectively;
(n)_m is the falling factorial and is zero for n<m. There are no B_i
reactions for i with N(i)=emptyset, where N(i)={j:(j,i) in E}.

Assume a product compact rate box, with every rate c in
[c^-,c^+] and 0<c^-<=c^+<infinity. The estimates below use only the indicated
endpoint, so they also hold for any correlated parameter family contained
in this box. Let I_*={i:N(i) is nonempty}. Each isolated B_i is a conserved
class label. For a fixed vector of isolated counts, the active coordinates
form one closed irreducible class: remove each active B_i by a neighboring
A_j+B_i->A_j reaction after immigrating a neighbor if needed, then drain all
A_j. Conversely immigrate the requested catalysts, create active B_i using
a neighbor catalyst, use temporary neighbor catalysts when the final target
has no active neighbor, then remove extras. All finite paths have positive
rates. All uniform claims below are within each such class, with constants
independent of the isolated labels. If I_* is empty the argument reduces to
immigration-death chains for A, and the formulas below use empty substrate
sums.

The total exit intensity is

  q_theta(a,b)=sum_j alpha_j+sum_j delta_j a_j
      +sum_(j,i) in E [p_ji a_j+(q_ji+u_ji)a_jb_i
                       +v_ji(a_j)_(k_ji+1)b_i].

It always obeys the uniform lower bound

  q_theta(a,b) >= alpha_*^- := sum_j alpha_j^- > 0,                       (1)

because every immigration is enabled. There is no global upper bound: for
any edge (j,i), q_theta(n e_j+e_i) contains
v_ji^- (n)_(k_ji+1), which diverges with n. On a finite active-coordinate
set, however, the upper rate-box endpoints give a common finite upper bound.

2. One common support-corrected function and exact generator
------------------------------------------------------------
Set lambda_j=epsilon_i=1. Write A=sum_j a_j, I_0=1_{A=0},
I_j=1_{a=e_j}, and

  h_i(a)=1_{sum_(j in N(i)) a_j=0}.

For a fixed isolated-count class use

  V(a,b)=A + sum_(i in I_*) R^(b_i)(1+h_i(a)) + K I_0.                  (2)

The isolated coordinates are omitted because they are constant on the
class. V>=1 and is norm-like in that class if K>=1. Let

  H=sum_j alpha_j,  H^+=sum_j alpha_j^+,
  delta^+=max_j delta_j^+,
  P_j=sum_(i in N(j)) p_ji^+,
  xi=min(1/2, min_j delta_j^-/[2(1+P_j)]),  R=1+xi,
  c_R=R-1,  d_R=1-R^(-1),
  K=max(1,(H^++2)/alpha_*^-).                                         (3)

Then xi>0 and

  chi_j:=delta_j^- - c_R P_j >= delta_j^-/2 >0.                         (4)

For an edge define the uniform upper envelope

  Gamma_ji(m)=p_ji^+ c_R R^m - q_ji^- d_R m R^m + k_ji u_ji^+ m.

Writing I_i(a)=1_{a restricted to N(i) is zero} and
I_ij(a)=1_{a restricted to N(i) is e_j}, direct rate-times-jump
calculation gives the exact identity (all rates in this expression are the
actual selected box values)

  LV = H - sum_j delta_j a_j
       + sum_(j,i) in E a_j g_ji(b_i)
       - sum_(j,i) in E k_ji v_ji (a_j)_(k_ji+1)b_i
       - K H I_0 + K sum_j delta_j I_j
       + sum_(i in I_*) R^(b_i)
           [-alpha(N(i)) I_i(a) + sum_(j in N(i)) delta_j I_ij(a)],     (5)

  g_ji(m)=p_ji c_R R^m - q_ji d_R m R^m + k_ji u_ji m,
  alpha(N(i))=sum_(j in N(i)) alpha_j.

Equation (5) is the crucial boundary audit. Immigration of a neighboring
catalyst switches h_i from 1 to 0 and contributes the negative
-alpha(N(i))R^(b_i) term. Death of the last neighbor switches it from 0 to
1 only when the restricted catalyst vector is e_j, giving the displayed
positive delta_j R^(b_i) term. The catalyst-zero corrector is separate:
L I_0=-H I_0+sum_j delta_j I_j. The q reaction does not switch either
support indicator. These are the only indicator-switch terms.

At A=0, (5) simplifies to

  LV(0,b)=H-KH-sum_(i in I_*) alpha(N(i)) R^(b_i) <= -2,               (6)

by (3), including on every unbounded frozen-substrate face.

3. Explicit uniform bounds on every state
------------------------------------------
The constants in this section are finite and depend only on E,k and the
rate-box endpoints.

First control large substrate coordinates. For each edge put

  Q_ji=q_ji^- d_R>0,  U_ji=k_ji u_ji^+,

and take M_ji to be the least integer m>=1 satisfying

  R^m >= 2 U_ji/Q_ji,
  Q_ji m/2 >= p_ji^+ c_R + delta_j^+ + 1.                               (7)

Both inequalities persist for every larger m. Dividing Gamma by R^m gives

  Gamma_ji(m)/R^m
    <= p_ji^+ c_R - Q_ji m + U_ji m/R^m
    <= p_ji^+ c_R - Q_ji m/2
    <= -(delta_j^+ + 1),   m>=M_ji.                                    (8)

Set M_i=max_(j in N(i)) M_ji. For b_i>=M_i, if h_i=1 all neighboring
catalysts are zero and the support switch contributes at most
-alpha_i^- R^(b_i), alpha_i^-:=sum_(j in N(i)) alpha_j^-. If h_i=0 then
sum_(j in N(i))a_j>=1. Equation (8) makes the incident g terms at most
-(delta^++1)R^(b_i); the only possible positive last-neighbor switch is at
most delta^+ R^(b_i), and is therefore absorbed. In both cases the combined
large-b_i edge and support-switch contribution is at most

  -zeta_i R^(b_i),   zeta_i:=min(1,alpha_i^-)>0.                       (9)

Next control catalysts without losing the large-substrate terms in (9).
For each j let

  G_j=sum_(i in N(j)) max(0, max_(0<=m<M_i) Gamma_ji(m)),
  c_j=chi_j/2>0.

Define N_j=1 if N(j) is empty. Otherwise take the least integer n satisfying
n>=max_(i in N(j))(k_ji+1) and

  k_ji v_ji^- (n-1)_(k_ji) >= G_j+c_j  for every i in N(j).            (10)

The left side is increasing in n once n>=k_ji+1, so (10) also holds for
all larger n. Separate the j-th catalyst drift into the -delta_j a_j term,
g terms for b_i<M_i, g terms for b_i>=M_i (reserved for (9)), and all
nonpositive reverse-factorial terms. If all neighboring b_i are zero, its
linear coefficient is at most -chi_j. If some neighboring b_i is positive,
then for a_j>=N_j the matching reverse factorial term and (10) dominate
every positive small-b linear term by c_j a_j. For a_j<N_j the positive
small-b terms are at most G_j a_j. Consequently the catalyst part not
reserved in (9) is uniformly bounded by

  C_j-c_j a_j,  C_j=(G_j+c_j)N_j.                                    (11)

For an empty N(j), this holds with C_j=0. The argument uses only
v_ji^->0, k_ji>=1, and the monotone growth of the falling factorial; it
retains the exact zero propensities at the reaction boundary.

For substrate coordinates with b_i<M_i, drop the nonpositive part of their
support switch. The positive part is at most
|N(i)| delta^+ R^(M_i-1). The catalyst-zero switch correction is at most
K delta^+ because at most one I_j is one; the -K H I_0 term is nonpositive.
Put

  C_0=H^+ + K delta^+ + sum_j C_j
                    + sum_(i in I_*) |N(i)|delta^+ R^(M_i-1).          (12)

Combining (6), (9), and (11), uniformly over every rate vector in the box
and every state in any fixed isolated-count class,

  LV <= C_0 - sum_j c_j a_j
              - sum_(i in I_*) zeta_i R^(b_i) 1_{b_i>=M_i}.             (13)

This gives the requested compact-box constant, not only the pointwise
escaping-sequence conclusion in the Cycle 3 sparse note.

Convert (13) to geometric drift. Let

  D_0=sum_(i in I_*) R^(M_i-1),
  c_A=min_j c_j,
  beta=min(c_A, (1/2)min_(i in I_*)zeta_i),

where beta=c_A if I_* is empty. Write
S=sum_i R^(b_i)1_{b_i>=M_i}. Since
V<=A+2D_0+2S+K, (13) implies

  LV <= C_geo-beta V,
  C_geo := C_0+beta(2D_0+K).                                          (14)

All of V,C_0,C_geo,beta are common to the whole rate box. A common finite
set is

  F={x in the fixed class: V(x)<=T_*},
  T_* = max(1, 2 C_geo/beta, (C_geo+1)/beta).                           (15)

Outside F, both LV<=-beta V/2 and LV<=-1. Each class restriction of F is
finite. A crude cardinality bound is

  |F| <= (floor(T_*)+1)^|J|
        (floor(log_R T_*)+1)^|I_*|,                                    (16)

and all isolated counts are fixed. The constants and active-coordinate
bound in (16) do not depend on the isolated labels.

4. Physical-time nonexplosion and quantitative return
-----------------------------------------------------
Let tau_L=inf{t>=0:V(X_t)>=L}, L>V(x). On {V<L} the active-coordinate
states are finite; their one-step target set is finite and all rates are
bounded there uniformly over the compact rate box. Localized stopped Dynkin
applied before tau_L and LV<=C_0 yields, for every T>=0,

  P_theta,x(tau_L<=T) <= [V(x)+C_0 T]/L.                               (17)

V is norm-like in each closed class. Infinitely many jumps while remaining
inside a finite sublevel set are impossible because the rates there have a
finite uniform upper bound. Explosion would therefore require crossing
every L in finite time. Let L tend to infinity in (17): the minimal CTMC
is conservative/nonexplosive, uniformly over the rate box, from every
initial state. This uses the physical-time generator, so short holding
times at high activity are included; it does not assume a globally bounded
total rate.

For tau_F=inf{t>=0:X_t in F}, stopped Dynkin and LV<=-1 outside F give the
explicit physical-time mean bound

  E_theta,x tau_F <= V(x).                                             (18)

In fact the stronger geometric inequality gives an exponential bound. Set
gamma_0=beta/2. Before tau_F, LV+gamma_0 V<=0. Localize on finite V-levels,
apply the time-dependent Dynkin/supermartingale calculation to
exp(gamma_0(t wedge tau_F))V(X_(t wedge tau_F)), use (17) to remove the
localization, then let t increase. Since V>=1 at every state,

  E_theta,x exp(gamma_0 tau_F) <= V(x),
  P_theta,x(tau_F>t) <= V(x) exp(-gamma_0 t).                            (19)

The bound is uniform in the selected rates; only the explicit starting
value V(x) varies. It is a return-to-a-common-finite-set bound, not a bound
to a specified state.

There is also a first-return-after-one-jump bound. Let F_1 be the set of
one-jump successors of F (including any targets still in F) in a fixed
isolated-count class, and V_1=max_(y in F_1) V(y)<infinity. For
0<gamma<min(gamma_0,alpha_*^-), let H_1 be the first holding time and
sigma_F^+=inf{t>=H_1:X_t in F}. Since H_1 is independent of the selected
reaction given the starting state, and q_theta(x)>=alpha_*^-,

  E_theta,x exp(gamma H_1)
    = q_theta(x)/(q_theta(x)-gamma)
    <= alpha_*^-/(alpha_*^- - gamma).

Using (19), monotonicity of exponential moments, and finiteness of F_1,

  sup_(theta,x in F) E_theta,x exp(gamma sigma_F^+)
    <= [alpha_*^-/(alpha_*^- - gamma)] V_1.                             (20)

This proves an exponential moment for a physical-time return to F after at
least one jump. It does not bound return to the origin in a uniform way
unless one also charges a uniform finite-path trial from F to the origin;
the class structure and compact box allow such a separate finite-set
calculation, but it is not needed for (18)-(20).

5. Exact source theorem interface
---------------------------------
Anderson and Kim, “Some network conditions for positive recurrence of
stochastically modeled reaction networks,” arXiv:1710.11263v3 (22 Aug 2018),
Theorem 3.1, states the following sufficient criterion: for a CTMC on a
countable state space S with generator A, if a finite K subset S and a
positive function W on S satisfy AW(x)<=-1 for every x outside K, then
each state in every closed irreducible component is positive recurrent;
moreover the expected time to enter the union of the closed irreducible
components is finite from every initial state. The theorem statement does
not give a numerical expected-return constant, a rate-box uniformity
statement, a geometric drift inequality, or an exponential hitting-time
moment. It is used here only after (17) has independently established
nonexplosion. Our explicit (18)-(20) come from the stronger derived bounds,
not from a quantitative interpretation of Theorem 3.1. The relevant
primary source is https://arxiv.org/html/1710.11263v3, Section 3, Theorem 3.1.

For each fixed rate choice, the isolated-label slice is a closed
irreducible component and (15) is finite, so (14)-(15) meet the theorem's
interface. The analytic proof actually supplies common objects for the
whole compact box. No inference from an event-index bound is used.

6. Event clock: what converts and what does not
-----------------------------------------------
At each jump epoch the holding time is Exp(q_theta(X_n)). The lower bound
(1) gives a uniform upper exponential moment for each holding time:

  E[exp(gamma H_n)|X_n] <= alpha_*^-/(alpha_*^- - gamma),
      0<gamma<alpha_*^-.

Consequently, if N is an embedded-chain stopping jump count and the
embedded chain separately has E[r_gamma^N]<infinity, where
r_gamma=alpha_*^-/(alpha_*^- - gamma), conditioning successively on the
embedded path gives

  E exp(gamma sum_(n=0)^(N-1) H_n) <= E r_gamma^N.                       (21)

Thus an exponential step-return bound would transfer to physical time for
this family. The old factorial-source estimate N76 does not provide such a
bound: it controls upward increments of a potential through a fixed number
of events, not a negative drift or a return-step tail. Dividing the
physical generator drift by q_theta(x) also loses a uniform margin because
q_theta is unbounded. Our physical-time proof avoids both gaps.

The reverse conversion is unavailable without additional activity control.
There is no uniform upper bound on q_theta(x); along a_j=n,b_i=1 for any
edge, the reverse propensity grows like n^(k_ji+1). Hence holding times have
no positive global lower bound, and a physical-time return estimate by
itself does not bound the number of reactions before return. Equivalently,
the expected jump count up to tau_F is E[int_0^tau_F q_theta(X_t)dt], which
is not controlled by (18) or (19). The generator inequality here does not
establish that stationary jump flux is finite; therefore it does not
establish positive recurrence of the embedded event chain or permit the
stationary conversion mu(x) proportional to pi(x)q(x). No claim that this
particular sparse chain has an infinite stationary jump flux is made.

7. Concrete compact-box constants and exact diagnostic
------------------------------------------------------
Take J={1,2}, I={1,2}, E={(1,1),(2,1),(2,2)}, k_ji=1 on every edge, with
independent rate intervals

  alpha_j,delta_j,p_ji,u_ji in [9/10,11/10],
  q_ji,v_ji in [19/10,21/10].

For this fixture choose the directly checked valid value R=6/5; it is a
larger choice than the conservative generic formula (3), but it still
satisfies every strict chi margin. Then chi=(17/25,23/50), c=(17/50,23/100),
alpha_*^-=9/5, H^+=11/5, delta^+=11/10, K=7/3, and d_R=1/6. For each
edge, Q_ji=19/60 and U_ji=11/10. The explicit threshold (7) gives M_ji=15,
so M_1=M_2=15. Exact maximization of Gamma on integers 0,...,14 gives
34838/15625. Therefore

  G_1=34838/15625, G_2=69676/15625,
  N_1=3, N_2=4,
  C_1=240903/31250, C_2=293079/15625,
  zeta_1=1, zeta_2=9/10, beta=23/100.

With D_0=2(6/5)^14, the remaining exact constants are

  C_0 = 6738457763377/91552734375,
  C_geo = 157380330573661/1831054687500,
  T_* = 314760661147322/421142578125 < 748,
  gamma_0=23/200.

Thus the common set is contained in a_j<=747 and b_i<=36, with isolated
labels fixed. The direct size upper bound is large and deliberately crude;
the point is that the return/horizon constants are finite, explicit, and
uniform over the nondegenerate rate box.

For example, taking gamma=1/10 in (20) gives the explicit holding-time
factor alpha_*^-/(alpha_*^- - gamma)=18/17 multiplying V_1. From (19),
Jensen also gives E tau_F <= (200/23) log V(x) in this box.

`check_rate_box.py` recomputes these rational constants, verifies threshold
inequalities, and checks the robust generator upper bound from (13) on
10,404 states with a_1,a_2<=5 and b_1,b_2<=16, using Fraction arithmetic
and choosing the worst endpoint of each rate term in each state. It prints
the values above. This is a finite consistency diagnostic only; the
all-state result is the threshold and case proof in Sections 3-4.

8. Claim boundary / next decisive experiment
---------------------------------------------
Proved internally for this family: uniform compact-box physical-time
nonexplosion estimate (17), a common finite set with mean return bound (18),
and return-time exponential moments (19)-(20). The use of “return” here is
to that finite set; all bounds are for the continuous clock. No claim is
made about expected total jump count, finite stationary jump flux, embedded
chain positive recurrence, uniform mixing, or return to one prescribed
state. Positive recurrence in each fixed isolated-label class follows from
Theorem 3.1 after the direct nonexplosion proof.

Next decisive extension: independently construct an event-count Lyapunov
function or compute the invariant flux for the non-complex-balanced
three-species sparse fixture over the same compact box. A finite bound on
E_pi q (or an event-step exponential drift) would close the reverse clock
bridge. Failing that, an exact example in this family with finite CTMC
return time but null-recurrent embedded chain would establish that the
remaining gap is real. Until one is proved, event-chain recurrence remains
UNKNOWN for this candidate outside the parameter subcases already covered
by a separate stationary-law argument.

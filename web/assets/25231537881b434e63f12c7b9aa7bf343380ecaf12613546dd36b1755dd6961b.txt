CYCLE 5 LEAF — LOCAL SUPPORT DENOMINATOR WITH SUBSTRATE-PRESERVING
CATALYST CHANNELS
==================================================================
Status: INTERNALLY-PROVED-CANDIDATE for the exact fixed-rate CTMC class
below. No claim for general weakly reversible networks.

Conclusion
----------
For the sparse paired family, the proposed local correction

  V(a,b) = A + sum_i R^(b_i) [1 + epsilon_i h_i(a)/(1+b_i)^D]
             + K 1{A=0}

does close after adding any finite set of the two specified reversible
substrate-preserving catalyst channel types, provided D is an integer at
least the maximum substrate-complex degree m of those channels. The proof
is pointwise for every fixed positive finite rate vector. The key facts are:

* A base B_i birth or death occurs only when h_i=0, where the local
  correction for B_i vanishes. It cannot change any other substrate's
  denominator.
* A conversion/deactivation channel can increase the correction for B_i
  only by removing the sole active neighbor of B_i. Its source count is
  then exactly one, so its rate has no unbounded catalyst multiplier.
* Remote substrate factors in a channel are absorbed by a max-substrate
  split. Near-max support switches are paid for by their own q-removal
  term; far switches are exponentially smaller than the maximal inactive
  or active substrate penalty. D>=m makes the near-max ratio O(1/b).
* The activation direction z_B -> A_j+z_B has positive catalyst increment
  at most one. At A=0 its full potential jump is nonpositive when K>=1;
  at A>0 its polynomial rate is absorbed by an unbounded substrate's
  exponential penalty.

The result includes mixed catalyst/substrate escape sequences. Isolated
substrate counts are class labels. The previous cycle-4 witness against a
total-substrate exponential on a catalytic feed network is preserved; this
leaf changes both the reaction interface and the potential.

1. Exact network and class assumptions
--------------------------------------
Let J and I be finite. The catalyst and substrate counts are
a in N_0^J and b in N_0^I. For E subset J x I, write
N(i)={j:(j,i) in E}. For each j include

  0 <-> A_j,

and, for each (j,i) in E, include both reversible pairs

  A_j <-> A_j+B_i,
  A_j+B_i <-> (k_ji+1)A_j+B_i,

where k_ji>=1 is an integer. The positive finite rates are
alpha_j,delta_j,p_ji,q_ji,u_ji,v_ji, with propensities

  alpha_j, delta_j a_j, p_ji a_j, q_ji a_j b_i,
  u_ji a_j b_i, v_ji (a_j)_(k_ji+1) b_i.

Add a finite set of reversible channels of the following two forms. For a
fixed multi-index z in N_0^I, let |z|=sum_i z_i and
M_z(b)=product_i (b_i)_(z_i).

(C) Catalyst conversion, for j!=l:

  A_j+z_B <-> A_l+z_B,

with directed propensities theta^+ a_j M_z(b) and
theta^- a_l M_z(b).

(D) Catalyst deactivation/activation:

  A_j+z_B <-> z_B,

with directed propensities eta^- a_j M_z(b) and eta^+ M_z(b), respectively.

All listed channel rates are positive and finite, and m=max |z| over the
added channels. If there are no added channels set m=0. Reactions use
standard mass action, including falling factorials for repeated substrate
species. The channels do not change b. The base network is weakly reversible
and retains the paths that clear and construct every nonisolated substrate
and every catalyst. Isolated substrates I_0={i:N(i)=empty} are unchanged by
all reactions; fix their counts as class labels. Each resulting class is
irreducible when J is nonempty, except for the trivial J-empty case covered
below.

Let I_+={i:N(i) is nonempty}, A=sum_j a_j,
alpha_sum=sum_j alpha_j, and alpha_i^*=sum_{j in N(i)}alpha_j>0 for i in
I_+. Define

  h_i(a)=1{sum_{j in N(i)} a_j=0},
  f_i(n)=R^n/(1+n)^D,
  g_i(n)=epsilon_i f_i(n),

for i in I_+. For isolated i, h_i=1 and its substrate term is constant in
each class, so it can be omitted from drift calculations. Choose any finite
epsilon_i>0. Choose a common R>1 sufficiently close to one that

  chi_j := delta_j - (R-1) sum_{i:(j,i) in E} p_ji > 0

for every j. This is always possible because J and E are finite. When
J is nonempty, K=1 already suffices for the recurrence proof (and any
K>=1 works). This is a useful boundary case: at A=0 the exact base drift
is -sum_i alpha_i^* g_i(b_i), not a uniform negative constant. If a
nonisolated substrate escapes, this tends to -infinity; if those substrate
counts stay bounded, the A=0 states form a finite set and can be included
in the drift set. At A=0 every activation jump is nonpositive for K>=1.
The displayed V is positive and norm-like on each fixed isolated-label
class.

2. Exact generator, including every switch
-------------------------------------------
Put c=R-1, d=1-R^(-1), I_A=1{A=0}, and

  L_ij(a)=1{a_j=1 and a_h=0 for every h in N(i)\{j}}.

Thus L_ij marks death of j as the last active neighbor of substrate i.
Also let e_j be the jth unit catalyst vector. For the base paired network,
direct calculation gives

  L_base V = alpha_sum - K alpha_sum I_A
       + K sum_j delta_j 1{a=e_j} - sum_j delta_j a_j
       + sum_(j,i in E) [ p_ji a_j c R^(b_i)
                          - q_ji a_j b_i d R^(b_i)
                          + k_ji u_ji a_j b_i
                          - k_ji v_ji (a_j)_(k_ji+1) b_i ]
       - sum_(i in I_+) alpha_i^* h_i(a) g_i(b_i)
       + sum_(i in I_+) sum_(j in N(i)) delta_j L_ij(a) g_i(b_i).

In particular, if 0 -> A_j fires, its exact jump is

  1 - K I_A - sum_(i in N(j)) h_i(a) g_i(b_i),

and if A_j -> 0 fires, its exact jump is

  -1 + K 1{a=e_j} + sum_(i in N(j)) L_ij(a)g_i(b_i).

There are no denominator-increment terms from the base substrate pairs.
For an edge (j,i), A_j -> A_j+B_i is enabled only when a_j>0, hence
h_i=0 before and after; the local B_i correction is zero. The reverse
substrate-removal reaction also leaves a unchanged and has h_i=0. A
substrate jump changes no other f_l because f_l depends only on b_l. The
autocatalytic forward reaction starts with a_j>0, and its reverse leaves
one A_j, so neither direction changes any h_i.

For a directed added channel from (a,b) to (a',b), its exact jump is

  Delta V_C = sum_(i in I_+) g_i(b_i)[h_i(a')-h_i(a)]

for a catalyst conversion, and

  Delta V_D^- = -1 + K 1{A=1}
                   + sum_(i in I_+) g_i(b_i)[h_i(a-e_j)-h_i(a)]

for deactivation A_j+z_B -> z_B, and

  Delta V_D^+ = 1 - K I_A
                   + sum_(i in I_+) g_i(b_i)[h_i(a+e_j)-h_i(a)]

for activation z_B -> A_j+z_B. The corresponding rates are
theta a_j M_z, eta^- a_j M_z, and eta^+ M_z. These formulas include all
K-boundary and support switches. Activation can only change h_i from 1 to
0, so its correction jump is nonpositive.

3. Channel switch bound and remote-co-reactant absorption
---------------------------------------------------------
For a conversion or deactivation whose correction jump is positive for
some i, one must have h_i(a)=0 and h_i(a')=1. The source catalyst j is
then the sole active neighbor of i and a_j=1: if a_j>=2, one copy remains
after the channel, and if another neighbor were active, support would
remain. Thus every positive support-switch term of these channels has
source catalyst factor exactly one. A positive K increment from a
deactivation also requires A=1. No positive channel term can grow linearly
in an unbounded catalyst count.

On a fixed isolated-label class, each M_z(b) is bounded above by
C_z(1+n)^m, where n=max_{i in I_+} b_i and C_z depends on the fixed
isolated labels. There are finitely many channels. For A>=1 their total
positive generator contribution therefore obeys

  (L_channels V)^+ <= C(1+n)^m
       [1 + K 1{A=1} + sum_{i in I_+: h_i(a)=0} g_i(b_i)],       (1)

with a finite class-dependent C. The 1 covers activation's +1. At A=0,
conversion/deactivation sources are disabled, and every activation jump is
at most 1-K<=0, so L_channels V<=0.

Choose N_0 large enough that, for every edge (j,i) and n>=N_0,

  p_ji cR^n + k_ji u_ji n <= (1/2)q_ji d nR^n.

This is possible because R>1 and all q_ji>0. Define the surviving
substrate penalty

  P(a,b) = sum_(i in I_+:h_i=1) alpha_i^* g_i(b_i)
          +sum_(i in I_+:h_i=0, b_i>=N_0)
                 (1/2)q_i^* d b_i R^(b_i),
  q_i^* = min_(j in N(i)) q_ji > 0.

Whenever n=max_{i in I_+} b_i tends to infinity, P tends to infinity and

  (1+n)^m (1 + sum_(i:h_i=0) g_i(b_i)) = o(P)                 (2)

for D>=m. To check (2), the direct polynomial term is exponentially
smaller than P. For an active i with b_i>=n/2, eventually b_i>=N_0 and P
contains its surviving q term, and

  (1+n)^m g_i(b_i)/(b_i R^(b_i))
       <= C (1+n)^m/b_i^(D+1) = O(n^(m-D-1)) -> 0.

For an active i with b_i<n/2, P is at least a constant times
R^n/(1+n)^D: this follows from the max coordinate's inactive correction
if h_max=1, and from its q term if h_max=0. Hence

  (1+n)^m g_i(b_i)/P <= C n^(m+D) R^(-n/2) -> 0.

There are only finitely many i and channels, so the same little-o bound
holds after summation. This explicitly covers a channel whose z_B uses
substrates remote from the support being switched. The local denominator
is essential to the first step of the argument: the base B_i jump has no
effect on g_l for l!=i, and when it changes b_i itself, h_i=0.

The positive last-neighbor terms in L_base V are also lower-order support
switch terms: L_ij=1 forces h_i=0 and a_j=1, so the corresponding q term
is present. For large b_i it dominates delta_j g_i(b_i); for bounded b_i
the term is bounded. Thus (1)-(2) absorb all positive support-switch
corrections from base deaths.

4. Escaping-sequence proof of a finite drift set
------------------------------------------------
For each j define the paired catalyst group

  D_j(a,b) = a_j[-delta_j + sum_(i in N(j)) G_ji(b_i)]
       -sum_(i in N(j)) k_ji v_ji (a_j)_(k_ji+1)b_i,

  G_ji(n)=p_ji cR^n-q_ji d nR^n+k_ji u_ji n.

Then G_ji(n)->-infinity as n->infinity, while
sum_(i in N(j))G_ji(0)=c sum_i p_ji <= delta_j-chi_j.
Along any sequence, after taking a subsequence, every catalyst count and
every nonisolated substrate count is fixed or tends to infinity.

If b is bounded, all added channel monomials are bounded on the fixed
isolated-label class. Their positive part is bounded independently of a:
conversion/deactivation support loss requires source a_j=1, deactivation's
K switch requires A=1, and activation rates depend only on b. If a_j tends
to infinity, either all neighboring b_i are zero and D_j<=-chi_j a_j,
or some neighboring b_i is fixed positive and its negative factorial term
has degree k_ji+1>=2, or a neighboring b_i tends to infinity and
G_ji(b_i)->-infinity. In every case D_j tends to minus infinity. Thus any
escaping catalyst sequence has LV->-infinity.

If some nonisolated substrate count is unbounded, write
n=max_{i in I_+}b_i and pass to a subsequence with n->infinity.

* If A=0 along a subsequence, all h_i=1 and

    LV <= alpha_sum(1-K) - sum_i alpha_i^*g_i(b_i).

  For K>=1 this tends to minus infinity whenever a nonisolated substrate
  diverges, since each g_i(n) tends to infinity. If those counts remain
  bounded, there are only finitely many such A=0 states. Added activation
  channels are nonpositive there. Thus the K=1 boundary only enlarges the
  finite drift set by at most finitely many A=0 states; it does not impair
  the escaping-sequence argument.

* Otherwise take A>=1. For each j, D_j is bounded or tends to minus
  infinity: if a_j grows, the preceding catalyst argument applies; if a_j
  is fixed positive and a neighboring b_i grows, its G_ji term tends to
  minus infinity; if a_j=0, D_j=0. No catalyst group diverges positively.

  The maximal substrate coordinate supplies an unbounded negative term in
  the base generator. If h_max=1, its neighbors are all absent, so its
  immigration-switch term is exactly -alpha_max^*g_max and no base
  substrate-production term on that coordinate is enabled. If h_max=0,
  some active neighbor supplies a q-removal term of order nR^n; the paired
  p-term is O(R^n), the forward-autocatalysis term is O(n), and every
  last-neighbor surcharge is O(R^n/(1+n)^D), so a fixed fraction of the
  q-removal remains negative. The other positive support-switch terms are
  absorbed by this max penalty or by their own active q terms using (2).
  Direct added-channel positives are polynomial and are also o of the max
  penalty. Hence LV tends to minus infinity on every such escaping
  subsequence, including simultaneous catalyst growth and remote
  co-reactant growth.

Therefore every escaping sequence in a fixed isolated-label class has
LV->-infinity, and F={x:LV(x)>-1} is finite. This is a finite-drift-set
argument rather than a claim of one global linear drift inequality; at
bounded nonzero substrate counts, the reverse factorial terms are needed
to control arbitrarily large catalyst coordinates.

5. Nonexplosion, recurrence, and degenerate cases
------------------------------------------------
On each class, V has finite sublevel sets and finite one-jump boundaries.
Since F is finite and all state rates are finite, LV is bounded above by
some finite C. Localized stopped Dynkin for tau_R=inf{t:V(X_t)>=R} yields

  P_x(tau_R<=t) <= (V(x)+Ct)/R.

Exit rates are bounded on finite sublevel sets, so infinitely many jumps
cannot occur while remaining in one. Letting R grow rules out explosion in
physical time. The base paths make each nontrivial isolated-label class
irreducible. The continuous-time Foster criterion gives positive
recurrence and a unique invariant probability on each such class. No
embedded-chain clock replacement is used.

If E is empty and J is nonempty, all substrate counts are fixed labels.
The candidate reduces on a class to A plus a constant and K1{A=0}; catalyst
conversions preserve A, deactivations decrease it away from A=1, and
activations have a finite class-dependent constant rate. The same
finite-drift and nonexplosion argument is immediate. If J is empty, E and
all catalyst channels are empty; each substrate state is a singleton
absorbing class with its point-mass invariant law. Isolated substrate
labels remain fixed even when they appear in z_B; they only change
class-dependent constants in channel rates.

Limitations and preserved obstruction
--------------------------------------
The theorem uses the complete directed pairs on each selected sparse edge,
positive alpha_j, delta_j, q_ji, and v_ji, finite channel sets, and bounded
substrate degree m. It is a family-specific fixed-rate result. It gives no
uniform recurrence constants over rate boxes and no claim for channels that
change substrate counts, higher catalyst stoichiometry, or unpaired
reactions. The local denominator removes the global-denominator mixed-face
failure, but only because base substrate jumps occur while h_i=0 and all
added channels preserve b.

The cycle-4 total-count-potential witness is unchanged: for the catalytic
feed A_j+B_i <-> A_j+B_i+B_l, its V_X=linear catalyst + R^(sum b_i)
potential has positive drift on a=e_j,b_i=n,b_l=0 when sigma^+>=q_ji.
That remains a template-specific failure and is not a nonrecurrence
counterexample. This cycle-5 result concerns substrate-preserving catalyst
channels and does not alter the cycle-4 artifact.

IMPLEMENTED RECOGNIZER AND SELECTIVE COMMANDS

work/cycle3/filter_rank_recognizer.py is an actual reusable exact-rational
admission routine. Inputs are explicitly supplied strictly positive rational
tables b_j(0),...,b_j(q_j), each q_j>=1, and an integer physical rank r in
[0,m], m=sum q_j. Use integers, fractions.Fraction or exact rational strings.
The fixed-rank coefficient recognition takes O(m^2) rational operations;
its table/bit interface and proof are in filter_threshold_audit.txt.

API entry points:
  recognize_complementary(tables, rank)
  recognize_direct(tables, rank)
  recognize_counting_pair(tables, rank)
The last entry admits either global orientation; a rejection returns both
orientation results, with residual-count Hessian witnesses where applicable.
Executing filter_rank_recognizer.py alone produces no result: it is a module.

Tiny usable API example, from the package root:
  python3 - <<'PY'
  import sys
  sys.path.insert(0, 'work/cycle3')
  from filter_rank_recognizer import recognize_counting_pair
  print(recognize_counting_pair([[1,1,2],[1,1,2]], 2))
  print(recognize_counting_pair([[1,1,3],[1,1,3]], 2))
  PY
Expected decisions: accepted in the complementary orientation, then rejected
in both orientations. This example has no file output.

There is also a reusable exact norm primitive inside
work/cycle4/hard_bcs_transfer_checks.py: monomial_dp(p,w,t,fixed). It assumes
a valid supplied permutation p, rational squared row weights w, nonnegative
rational onsite squared weights t, and a dictionary of fixed row-membership
bits. It returns exact charge-polynomial coefficients for this weighted
permutation subclass, including constrained prefixes. It is not a general
hard-BCS counter or an end-to-end sampler/coherent compiler. Keep
work/cycle3/paired_fermion_checks.py; it is imported by relative file path and
imports NumPy even when this DP uses only rational arithmetic.

Tiny DP example, from the package root:
  python3 - <<'PY'
  import sys
  sys.path.insert(0, 'work/cycle4')
  from hard_bcs_transfer_checks import monomial_dp
  print(monomial_dp([1,0], [1,1], [0,0], {}))
  PY
Expected exact coefficient list: [1,2,0], printed as Fraction objects. This
two-site hard permutation model has charge polynomial 1+2s. No file is written.

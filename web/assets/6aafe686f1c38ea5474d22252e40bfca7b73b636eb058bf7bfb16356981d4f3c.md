# Early target: acquired low-rank operator as a universal post-storage predictor

Proposed interface: unknown `A in R^{p x q}` has rank exactly `r` and bounded Frobenius norm; an acquisition algorithm adaptively chooses scalar linear measurements `Y_t=<G_t,A>` (first pass assumes exact real answers; finite-precision pass quantizes each answer to `b` bits). After acquisition it must encode a state `Z`; only then an adversary chooses a query `x` with `||x||_2<=1`, and the decoder must return `Ax` within `epsilon` in Euclidean norm for every admissible `A,x`.

Load-bearing obstruction: if the post-acquisition state must answer *all* future `x`, then its reconstruction induces operator-norm error at most `epsilon`. At a generic rank-r point, the rank-r matrix manifold has tangent dimension `r(p+q-r)`. For any fixed transcript of `m` adaptive exact linear measurements, the query matrices are fixed; their differentials impose at most `m` independent constraints on that tangent space. Thus if `m<r(p+q-r)`, a nonzero tangent direction remains and locally there are distinct rank-r matrices with exactly the same transcript. Some future `x` separates them, so universal exact task sufficiency is impossible. For approximation, a packing/bit-count version should charge at least the metric entropy of the rank-r class under operator norm (at least `Omega((p+q-1) log(1/epsilon))` already on rank-one subfamilies); every finite-bit transcript carries at most `mb` bits. Need finish constants/conditions and careful randomized guarantee.

Strong baseline: raw-transcript retention sees the same adaptive measurement answers. The lower bound applies to every learner, including the raw-data baseline; any claimed advantage must identify a constrained downstream task distribution, query family, measurement budget/precision, compute or storage budget. Rank alone permits a compact *description after acquisition*, but does not eliminate the information needed to discover unknown factors.

Prior-art boundary: primary low-rank recovery already treats `Y_t=<G_t,A>` and shows exact generic measurement thresholds (Xu, arXiv:1505.07204, abstract and setup lines 3, 13-22) and adaptive noisy matrix recovery round lower bounds (Kacham-Woodruff, NeurIPS 2023, abstract lines 46-58). The task-specific post-storage all-query formulation is the proposed bridge; do not claim generic low-rank sensing is new.

# BJSW seed-pair hypercube encoding: exact B lift and a row-gap tradeoff

Date: 2026-10-08
Status: internally proved for the two-clause repeated seed pair and the stated covariant-connector class. This is not an encoding of the complete augmented QMA-hard Hamiltonian.

## Setup and exact local data

Let `phi_5, psi_5` be the BJSW five-qubit stabilizer seeds

```text
phi_5 = |->|00>|10>
psi_5 = (|000>-|011>-|101>-|110>)/2 tensor |10>.
```

The exact overlap is `c=|<phi_5,psi_5>|=1/(2 sqrt(2))`. Choose Clifford decoders `U_0,U_1` with `U_0*|00000>=phi_5`, `U_1*|00000>=psi_5`. The relative Clifford `W=U_1 U_0*` has eight nonzero entries per row, all of magnitude `1/(2 sqrt(2))`; the attached exact test verifies this in `Q(sqrt(2))`.

For `T` repeated blocks, the logical pair Hamiltonian is

```text
H_pair = (h_0+h_1)/2,
h_b = I - tensor_(i=1)^T (I - |v_b><v_b|_i),   v_0=phi_5, v_1=psi_5.
```

## A workspace interpolation that keeps B sparse

Use a branch register of `T` bits. For `x in {0,1}^T`, put `U_x=tensor_i U_(x_i)` and define

```text
V|psi> = 2^(-T/2) sum_x |x> tensor U_x|psi>
       = G (|+>^T tensor I)|psi>,
G = tensor_i (|0><0| tensor U_0 + |1><1| tensor U_1).
```

This is an isometry with a polynomial-size circuit: `G` is a tensor product of `T` fixed-size controlled-Clifford gates and the uniform branch state uses `T` Hadamards.

Let `D=I-tensor_i(I-|00000><00000|_i)` and `B=I_branch tensor D`. Then `B` is a positive contraction, diagonal and exactly one-sparse per row, with an `O(T)` row/entry procedure. Its compression is

```text
V* B V = 2^(-T) sum_x [I-tensor_i(I-|v_(x_i)><v_(x_i)|)]
        = I-tensor_i(I-Q_i),
Q_i=(|phi_5><phi_5|+|psi_5><psi_5|)/2.
```

Put `q_-=(1-c)/2`. On each block, `Q_i` has kernel `span{phi_5,psi_5}^perp` and nonzero eigenvalues `(1-c)/2` and `(1+c)/2`. Thus `V*BV` has kernel

```text
K = tensor_i span{phi_5,psi_5}^perp
```

and satisfies `q_- P_(K^perp) <= V*BV <= P_(K^perp)`. The two endpoint OR projections have the same kernel. Their underlying product-kernel spaces have largest nontrivial principal cosine `c`: locally the two hyperplanes `phi_5^perp` and `psi_5^perp` intersect in `span{phi_5,psi_5}^perp` and have one remaining principal cosine `c`; tensor-product principal cosines multiply. Therefore `q_- P_(K^perp) <= H_pair <= P_(K^perp)`, and hence

```text
q_- H_pair <= V* B V <= q_-^(-1) H_pair,
q_- = (1-1/(2 sqrt(2)))/2 > 0.32.
```

So the branch hypercube repairs the pair's logical-test side with explicit constant comparison and row-1 access.

## Exact connector tradeoff

Define `G=direct-sum_x U_x`. For any reversible Markov kernel `K` on the uniform Boolean cube, set

```text
C_K = (1/2) G ((I-K) tensor I_data) G*.
```

If `K` is irreducible, then `ker C_K=ran V`; `0<=C_K<=I`; and its spectral gap is half the Markov Poincare gap. The row support is controlled by the transition Hamming distance. If `x,y` differ in `h` coordinates, then

```text
U_x U_y* = tensor_i (U_(x_i) U_(y_i)*),
```

has exactly `8^h` nonzeros per row. Distinct `y` labels occupy distinct branch-column blocks, so these entries cannot cancel across neighbors. If every transition changes at most `q` bits and the kernel has degree at most `s`, then `C_K` has at most `1+s 8^q` nonzeros per row; its row and entry oracle enumerates the `s` neighbor labels and the corresponding `5h`-qubit Clifford block.

Any reversible uniform-stationary kernel on `{0,1}^T` whose transitions change at most `q` coordinates obeys

```text
gap(K) <= 2q/T.
```

Proof: for any signs `epsilon_i in {+1,-1}`, let `F_epsilon(x)=sum_i epsilon_i(-1)^(x_i)`. It has mean zero and variance exactly `T` under the uniform cube law. Averaging its Dirichlet form over independent signs cancels cross terms; a transition changing `h<=q` bits contributes expected squared difference `4h`, hence the average Dirichlet form is at most `2q`. Some sign choice has Dirichlet form at most `2q`, giving the Rayleigh bound `2q/T`. ∎

Consequently `gamma(C_K)<=q/T`. A polynomial row bound in `T` forces `8^q<=poly(T)`, so `q=O(log T)` and this covariant connector has gap `O(log T/T)`. A constant gap requires `q=Omega(T)`, for which a single edge block has `8^{Omega(T)}` entries per row. The simple bit-flip walk attains the sparse side: degree `T`, row support at most `1+8T`, and gap `1/T` for `C_K`.

## What remains open

This is an exact tradeoff for a coherent interpolation of the two BJSW frame choices, with connector `C_K` obtained by conjugating a reversible branch Markov kernel. It rules out upgrading this hypercube interpolation to constant gap by choosing a different reversible branch graph while retaining polynomial rows. It does not rule out non-Markovian positive enforcers, an active workspace isometry that changes the data frame itself, or a construction for the entire augmented BMVZ hard family. In particular, it has not yet been composed with the base QMA-hard amplified term list.

The next concrete test is to seek an active encoding for the full augmented input that preserves the above constant-factor `B` comparison while making the consistency operator a polynomial-row constant-gap positive matrix. A successful construction must include the base BMVZ clauses, not only the isolated seed pair.

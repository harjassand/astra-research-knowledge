Cycle 3 high-ceiling result — sparse enforcer for a stabilizer image and the diagonal-test boundary
Date: 2026-10-08

STATUS

INTERNALLY-PROVED-CANDIDATE: every explicitly described qubit stabilizer-code image has an exact positive contraction C with constant all-state gap, constant row support, exact coefficients, and a polynomial-time row/entry oracle. The construction applies to Clifford encodings and exact stabilizer qLDPC codes; it is not a local-check Hamiltonian.

For a fixed Clifford isometry V onto that image, every physical computational-basis-diagonal positive contraction B compresses to a diagonal operator in one induced logical stabilizer basis. This gives a necessary-and-sufficient condition for a common diagonal B, and refutes exact compression of the hardness-preserving augmented BMVZ Hamiltonian used in cycle 2: its repeated five-qubit seed layers retain anticommuting Pauli terms after partial trace, so it is not diagonal in any stabilizer basis. If “same code image” leaves the logical frame of V free, an eigenbasis rotation gives a formal exact compression, but its circuit and eigenvalue-oracle costs are not known to be polynomial for the BMVZ family.

1. An explicit all-state enforcer for any stabilizer-code image

Input. Let S be an exact stabilizer group on N qubits with rank N-k, given by a polynomial-size Pauli tableau, a polynomial-size Clifford encoder, or polynomial-size stabilizer check matrices. Let Q be its common +1 eigenspace and P_Q its orthogonal projector. For qLDPC input the checks must specify an exact stabilizer subspace; approximate low-energy spaces and unfixed subsystem gauge spaces are outside this statement.

Let X_S <= F_2^N be the image of S under projection to its X-bits, and let r=dim X_S. The pure-Z elements of S give affine linear equations on computational strings. Let A be their solution set, namely the strings that satisfy every pure-Z stabilizer with eigenvalue +1. A is invariant under translations by X_S. Thus the valid computational strings split into disjoint cosets O=A/X_S, each of size 2^r. Gaussian elimination gives a basis L_1,...,L_r of X_S and, for each orbit O, a representative z_O. Write its strings as z_O+Lx, x in F_2^r.

The stabilizer group acts by signed computational-basis shifts inside each orbit. Invariance fixes every amplitude in the orbit from one anchor amplitude, so there is exactly one code vector per valid orbit. Stabilizer normal form gives it as

    |chi_O> = 2^(-r/2) sum_(x in F_2^r) omega_O(x) |z_O+Lx>,

where omega_O(x) is a fourth root of unity computable from the tableau. The vectors |chi_O> are orthonormal and span Q. There are 2^k valid orbits.

Fix the RVW zig-zag explicit expander family at vertex count 2^r. Its degree D and a uniform bound 0<=lambda_0<1 on the second-largest eigenvalue are constants; its rotation map Rot_r(x,j) is computable in poly(r) time from an r-bit vertex x and one of the D edge labels j. For the finite small-r exceptions use complete graphs (including the two-vertex edge), and enlarge lambda_0 to dominate their second eigenvalues. This keeps lambda_0<1. For r=0 use the one-vertex graph, whose orbit has no orthogonal complement. The adjacency matrix is never materialized. Set

    P_r = (I + A_r)/2,
    D_O = diag(omega_O(x))_(x in F_2^r),
    C_O = I - D_O P_r D_O*.

On invalid computational strings set C=I. On each valid orbit set C=C_O in the orbit coordinates. This defines C blockwise on the entire N-qubit computational basis.

Let delta=(1-lambda_0)/2. Since P_r is symmetric stochastic and lazy, its spectrum lies in [0,1], its top eigenvector is uniform, and every other eigenvalue is at most (1+lambda_0)/2. Consequently

    0 <= C <= I,
    ker C = Q,
    C >= delta (I-P_Q).

The unique zero vector on orbit O is D_O|uniform> = |chi_O>. On each orthogonal orbit complement the Laplacian eigenvalues are at least delta; invalid basis strings have eigenvalue one. This is an all-state statement, not a promise-sector or low-energy estimate.

Exact row/entry access. Preprocess the stabilizer tableau by binary Gaussian elimination to obtain (i) the pure-Z affine constraints for A, (ii) a basis L of X_S, (iii) an orbit-representative rule for A/X_S, and (iv) a polynomial-time phase function omega_O(x). Given a row label z in F_2^N:

1. Test the pure-Z equations. If z is invalid, return the single diagonal entry C_(z,z)=1.
2. If z is valid, find its orbit O and coordinate x with z=z_O+Lx.
3. Enumerate the constant number D of neighbors y of x using the expander rotation map. Return the entries

       C_(z,z') = 1[x=y] - omega_O(x) P_r(x,y) conjugate(omega_O(y))

   for z'=z_O+Ly, including the diagonal position.

All entries outside this orbit are zero. The row has at most D+1 nonzeros. Entries are exact rationals with constant denominator, multiplied by a fourth root of unity; coefficient precision is O(1) bits. Preprocessing and each row/entry query take poly(N) time and space; the graph-neighbor component takes poly(r) time. The exponentially large matrix is never materialized. From qLDPC check matrices, tableau reduction and a Clifford encoder can be computed in polynomial time by symplectic Gaussian elimination. No qLTC decoder or soundness theorem is needed.

This C may connect strings at Hamming distance Theta(N). It is sparse in rows, but it is generally not a sum of bounded-weight checks and gives no local-Hamiltonian gap claim.

Finite exact check. For the one-qubit code S=<X>, A={0,1}, X_S=F_2 and the sole code vector is |+>. Take the lazy two-vertex walk P=[[1/2,1/2],[1/2,1/2]]. The construction gives

    C = [[1/2,-1/2],[-1/2,1/2]],

with eigenvalues 0 and 1, kernel span{|+>}, and two nonzeros per row. This is the r=1 instance of the orbit formula.

2. Exact characterization of all diagonal B compressions on a fixed code image

Fix a polynomial Clifford isometry V:C^(2^k)->C^(2^N) with range Q. Define logical orbit states |ell_O>=V*|chi_O>. They form an orthonormal basis of the input. For any physical diagonal operator

    B = sum_(z in F_2^N) b_z |z><z|,       0<=b_z<=1,

disjoint computational supports of the code vectors give the exact identity

    V* B V = sum_(O in A/X_S) bbar_O |ell_O><ell_O|,
    bbar_O = 2^(-r) sum_(z in O) b_z.

Conversely, every choice of numbers bbar_O in [0,1] is attainable: set b_z=bbar_O for all z in orbit O and set b_z=0 on invalid strings. Thus the complete positive-contraction image of the physical diagonal algebra is exactly the diagonal cube in the induced logical stabilizer basis. Its row/entry oracle is 1-sparse and polynomial-time whenever O->bbar_O is polynomial-time computable to the required coefficient precision.

Therefore, for this fixed V:

- Exact compression V*BV=H is possible iff H is diagonal in {|ell_O>}, with eigenvalues in [0,1].
- A constant-comparison encoding alpha H <= V*BV <= beta H is possible iff there is a vector bbar in [0,1]^(2^k) such that alpha H <= sum_O bbar_O |ell_O><ell_O| <= beta H. In particular, if H has an exact kernel, that kernel must be spanned by a subset of the induced logical stabilizer basis. Noncommutativity alone does not refute a Loewner sandwich for a positive-definite, well-conditioned H.

For exact compression this is a basis-commutativity obstruction: V*BV commutes with every induced logical Z observable. The converse is constructive, not just a necessary algebra condition. The basis-dependent diagonal entries are the orbit averages above, and any desired diagonal contraction is lifted by an orbit-constant physical diagonal B.

Logical-frame caveat. The stabilizer subspace Q alone does not fix the isometry V. If V_0 is a Clifford encoder and V=V_0 W for an arbitrary logical unitary W, then Q and the enforcer C are unchanged, but V*BV=W*(V_0*BV_0)W. In particular, if W H W*=diag(lambda_x), the same code image admits the formal exact construction

    B_z = lambda_(orbit(z)) on valid strings,    B_z=0 on invalid strings,
    V*BV = H.

This only gives a polynomial construction when W, the orbit-to-eigenvalue map x->lambda_x, and the necessary coefficient precision are all efficiently available. No such diagonalizer/eigenvalue oracle is supplied for the QMA-hard BMVZ Hamiltonian. Hence the rigorous negative statement below concerns a fixed Clifford/stabilizer frame; it does not rule out an efficiently computable non-Clifford logical basis change on the same subspace.

3. Exact no-go for the fixed Clifford frame on the augmented BMVZ family

Any operator diagonal in a stabilizer basis has a Pauli expansion supported on one abelian Pauli subgroup: each basis projector is a product of commuting logical Pauli projectors. Since every diagonal compression from Section 2 is diagonal in a stabilizer basis, it cannot equal an operator whose Pauli expansion contains a nonzero anticommuting pair.

The cycle-2 hardness-preserving augmented input adds the BJSW five-qubit rank-one stabilizer projectors P_phi and P_psi on a fresh seed register as separate singleton colors, each of positive weight 1/4. Their seed vectors are

    phi_5 = |-> |0> |0> |1> |0>,
    psi_5 = (|000>-|011>-|101>-|110>)/2 tensor |10>.

On the first three seed qubits, Z_2 stabilizes phi_5 and -Z_1 X_2 X_3 stabilizes psi_5; both act as identity on the two clock qubits. These Hermitian Paulis anticommute. They are distinct nonzero terms in the Pauli expansions P_phi=2^(-5)sum_(s in S_phi)s and P_psi=2^(-5)sum_(s in S_psi)s. The nonzero overlap |<phi_5|psi_5>|=1/(2sqrt(2)) ensures there is no opposite common stabilizer element that could cancel either coefficient.

After T-fold BMVZ amplification, the singleton-color clauses are

    R_(phi,T)=I-(I-P_phi)^(tensor T),
    R_(psi,T)=I-(I-P_psi)^(tensor T).

Tracing out seed copies 2,...,T gives, for d=32,

    Tr_(2,...,T) R_(phi,T)
      = (d^(T-1)-(d-1)^(T-1)) I + (d-1)^(T-1) P_phi,

and the same identity for psi. Therefore the partial trace of their positive-weight sum is a scalar multiple of I plus a strictly positive multiple of P_phi+P_psi. Its Pauli expansion still contains the anticommuting terms Z_2 and -Z_1 X_2 X_3. Tracing out the disjoint base register in the full augmented BMVZ Hamiltonian adds only a scalar identity contribution from the base-Hamiltonian part; it does not cancel these seed coefficients.

If the full augmented H were diagonal in any stabilizer basis, its Pauli expansion would be supported on a commuting subgroup, and every partial trace would retain only a subset of those mutually commuting terms. The displayed partial trace contradicts this. Hence the full augmented BMVZ H is not diagonal in any stabilizer basis. No fixed polynomial Clifford/stabilizer isometry V and physical diagonal B can satisfy V*BV=H for this augmented family, even though its code image has the constant-gap sparse enforcer C above.

The obstruction is specifically to exact compression on a fixed Clifford frame. For the positive-order sandwich, the exact criterion is the diagonal feasibility condition in Section 2. The BMVZ promise is an energy-gap promise, not a promise of a unique spectrally isolated ground state, and the argument above does not by itself refute every possible constant-alpha,beta sandwich on a fixed frame.

Conditional sandwich test. If H has a unique ground vector |g> of energy epsilon and its second eigenvalue is at least epsilon+Delta, then any diagonal compression K with alpha H<=K<=beta H obeys (write lambda_1<=lambda_2 for the two smallest eigenvalues)

    lambda_2(K) >= alpha(epsilon+Delta),
    lambda_1(K) <= beta epsilon.

If beta epsilon < alpha(epsilon+Delta), the minimum eigenvector of K is unique. Since K is diagonal in the stabilizer basis, that eigenvector is a stabilizer state |s>, and

    |<s|g>|^2 >= 1 - beta epsilon/[alpha(epsilon+Delta)].

The first inequality follows by intersecting any two-dimensional trial subspace with |g>^perp and applying the min-max principle; the overlap bound follows by expanding |g> in K's stabilizer-diagonal eigenbasis. Thus a uniquely gapped low-energy state with small overlap with every stabilizer state rules out such a constant-factor diagonal sandwich. The present source package does not establish that spectral/overlap premise for the full BMVZ hard family; it is a falsifiable additional gate, not an asserted application.

4. What the per-branch construction supplies, and the exact missing consistency condition

For branch f let Q_f=U_f Q be the corresponding Clifford image. Apply the orbit-expander compiler separately to obtain C_f with ker C_f=Q_f and the same constant gap. Then

    C_0 = direct_sum_f |f><f| tensor C_f

is a positive constant-gap, polynomial-row operator with

    ker C_0 = direct_sum_f Q_f.

The branchwise diagonal test B=sum_f |f><f| tensor D_f can encode the full BMVZ average on the common-history isometry

    V_hist |psi> = sum_f sqrt(pi_f) |f> tensor U_f V_0 |psi>,

because each D_f is diagonal in that branch's decoded syndrome basis and V_0*U_f*D_f U_f V_0=h_f. This succeeds on B while C_0 alone fails on the required kernel: for M positive-weight branches and logical dimension d_L, ker C_0 has dimension M d_L, whereas ran V_hist has dimension d_L.

The missing condition is exact branch consistency. In decoder coordinates G=direct_sum_f U_f, a vector in the branch-code sum is a tuple (psi_f)_f with psi_f in the same logical space. The desired kernel is precisely

    { (sqrt(pi_f) psi)_f : psi in C^(d_L) }
      = ran( |sqrt(pi)><sqrt(pi)| tensor I_(d_L) )

inside the branch-code sum. Equivalently, every decoded sector must equal sqrt(pi_f) times one common logical vector. A separate code-membership enforcer only proves psi_f is legal in sector f; it does not impose these M-1 independent sector-consistency constraints. Any full C built from the per-branch route must add an operator whose kernel on the branch-code sum is exactly the displayed common-vector subspace. This note does not claim a sparse/gapped construction of that operator.

This separates the two gates: (i) code-image membership is solved by C_S above, and (ii) a fixed single stabilizer image cannot carry the noncommuting augmented BMVZ test through one diagonal B; branch-conditioned tests avoid (ii) but leave branch consistency for C.

5. Exact scope, costs, and next falsifiers

The enforcer assumes an exact stabilizer tableau or polynomial-size Clifford/qLDPC generators. It produces constant row support and exact access in polynomial time, but its graph edges may change Theta(N) physical bits, so it is not geometrically local and is not a positive average of bounded-weight qLDPC checks. It needs no decoder, qLTC soundness, or suppressor theorem. There is no exponential table construction: only an explicit expander rotation map on r-bit orbit labels is queried.

The diagonal-compression characterization is for B diagonal in the physical computational basis and V with exact stabilizer-code range. Exact BMVZ nonrepresentation applies to the constructed augmented family with the two singleton seed colors and to every fixed Clifford logical frame. It does not cover arbitrary non-Clifford logical frame changes; a polynomial W that diagonalizes H and provides its eigenvalue oracle would give an affirmative same-image construction. It also does not refute a fixed-frame Loewner sandwich without the exact-kernel or isolated-low-energy hypotheses stated above.

Falsifiers/next tests:

- An exact tableau/code instance and queried row for which C_S has a negative eigenvalue, a kernel vector outside Q, or a non-code vector with energy below delta falsifies the enforcer theorem; the one-qubit X-code matrix above is a finite sanity check.
- For a fixed Clifford V, any physical diagonal B whose compression has a nonzero off-diagonal element in the orbit basis falsifies the diagonal-compression identity.
- An exact Clifford basis diagonalizing the augmented seed Hamiltonian would falsify the anticommuting-Pauli obstruction; the partial-trace witness rules this out for the stated augmented family.
- For the remaining sandwich question, produce either a vector bbar satisfying alpha H<=diag(bbar)<=beta H in the orbit basis, or certify that the diagonal semidefinite feasibility problem has no solution. For a low-energy route, prove the stated unique-gap/stabilizer-overlap premise for a specific BMVZ family member.
- For the per-branch route, construct a positive polynomial-row operator with kernel exactly the amplitude-weighted common-vector subspace after decoding; a code-membership-only block sum cannot pass this dimension test.

# Multi-branch direct-frame enforcer lower bound

Date: 2026-10-08
Status: internally proved finite-dimensional lemma; applies to direct product-workspace branch isometries only.

## Theorem

Let the logical space have dimension `d`, the workspace have dimension `D_W`, and let there be `g` positively weighted branches. For each branch `c`, let `U_c` be a unitary on the logical space and `a_c` a normalized workspace vector. Define

```text
V|psi> = sum_c sqrt(w_c) |c> tensor U_c|psi> tensor |a_c>,
        w_c > 0, sum_c w_c = 1.
```

Partition the branches by the equivalence relation

```text
c ~ c'  iff  U_c U_(c')* is monomial in the chosen computational basis.
```

Suppose there are `r >= 2` equivalence classes and put

```text
mu = max_{c,c' from distinct classes} max_{y,z} |(U_c U_(c')*)_(y,z)|.
```

If `C` is any matrix with `ker C = ran V`, then some nonzero computational-basis row of `C` has at least `ceil(1+1/mu)` nonzero entries. This needs neither positivity nor a quantitative gap; the all-state gap condition in the N11 target supplies a special case because it implies `ker C = ran V` and `C != 0`.

For Clifford branch frames, distinct classes have nonmonomial Clifford relative matrices, so `mu <= 1/sqrt(2)`. If each branch frame is a `T`-fold tensor power `U_c = W_c^{tensor T}` of a one-copy Clifford, then

```text
mu <= 2^(-T/2),     row_support(C) >= ceil(1 + 2^(T/2)).
```

The seed pair `phi_5, psi_5` from the BJSW propagation decomposition has the stronger exact overlap maximum `1/(2 sqrt(2))`; if there are exactly two classes represented by these frames, the bound is `ceil(1+2^(3T/2))`.

## Proof

Let the output dimension be `D_out = g*d*D_W`. For each monomial class `j`, fix a representative unitary `R_j`. For every branch `c` in that class there is a monomial matrix `M_c` with `U_c=M_c R_j`. Thus each computational row `<y|U_c` is a unit-modulus multiple of one row `<z|R_j`, with `z` a permutation of `y`.

Define a linear collapse map from output row-coordinate vectors `r=(r_(c,y,a))` to `r`-class coefficients indexed by `(j,z)` by summing, within each class, all entries that map to `<z|R_j`, multiplied by the branch amplitude `sqrt(w_c)`, workspace coordinate `a_c(a)`, and the monomial phase. The coordinate blocks for distinct branches are disjoint. Every class contains a branch with `w_c>0` and normalized `a_c`, so this collapse map is surjective and has rank `r*d`; its kernel has dimension `D_out-r*d`.

Since `V` is an isometry, `ker C=ran V` implies `rank C=D_out-d`. Because `r>=2`, `D_out-d>D_out-r*d`. Therefore the row space of `C` is not contained in the collapse kernel, and some row of `C` has a nonzero collapsed coefficient vector. Multiplying that row by `V` gives a dependence among the representative basis rows `<z|R_j`.

If the nonzero collapsed coefficients used only one class, those rows would be an orthonormal basis subset and could not be dependent. Hence at least two distinct classes occur. Rows within one class are orthonormal; rows across classes have inner products at most `mu`. If the dependence has `s` distinct basis rows, the Gram matrix has diagonal 1 and off-diagonal magnitudes at most `mu`; Gershgorin makes it positive definite whenever `(s-1)mu<1`. Therefore `s>=ceil(1+1/mu)`. Each nonzero collapsed coefficient requires at least one nonzero entry in the original row, in disjoint coordinate groups, so the original row support is at least `s`.

For a Clifford matrix, all nonzero computational-basis entries have magnitude `2^{-h/2}` for an integer Hadamard rank `h`; nonmonomiality means `h>=1`. Tensoring `T` independent copies multiplies the maximum entry by at most `2^{-T/2}`. ∎

## Exact BMVZ application and boundary

For a layered starting family `H_base=sum_chi v_chi H_chi`, append the two
five-qubit BJSW seed projectors on a fresh ancilla block as separate singleton
colors of weight `1/4` each, scaling the original color weights by `1/2`.
The augmented Hamiltonian is

```text
H_aug = (1/2) H_base tensor I + (1/4) P_phi + (1/4) P_psi.
```

The two seed projectors have a common kernel of dimension at least 30, so
`lambda_min(H_aug)=lambda_min(H_base)/2`; the low/high promise and QMA
hardness are preserved. The color count stays constant and all color weights
remain bounded below. Each fresh seed qubit has incidence two. Under BMVZ's
small-layer rule a singleton seed color emits the exact repeated clause,
without a loop or adjacency-list assumption. Thus the augmented output
contains the two exact repeated seed frames.

Applying the theorem to the *two seed branches alone* gives the exact bound `ceil(1+2^(3T/2))`, even with arbitrary branch-dependent pure workspace states. The theorem also gives the stated multi-branch bound whenever its explicit global coherence parameter `mu` is small.

This does **not** by itself prove an exponential-row lower bound for an encoding of the entire BMVZ clause list. There, `mu` is the maximum cross-class entry over every pair of branch frames; arbitrary path pairs may differ in only one seed position, so the global maximum need not decay with `T`. Also, one branch per color does not automatically represent the within-color average over all path clauses. A full-list direct-branch no-go therefore requires an explicit encoding interface and a verified all-pairs coherence bound, neither of which is supplied here.

The two-branch result does not cover a branch-dependent isometry that entangles logical data with workspace, nor an encoding that does not use direct frames. A polynomial-row enforcer using such an active workspace would falsify this scoped obstruction. It is not a general impossibility theorem for common positive encodings.

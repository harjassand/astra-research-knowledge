COST AMORTIZATION FOR ACQUIRING A REUSABLE REPRESENTATION

Status: proved accounting theorem and exact retention counterexample. The theorem is conditional on a declared resource model and matched predictive quality. It does not establish that any particular representation exists, generalizes, or is worth acquiring. No novelty or external-validation claim is made.

1. Claim and comparison boundary

A learned predictive or algebraic representation can repay its acquisition cost over later tasks only when the cumulative reduction in later-task work and/or memory cost exceeds every net setup cost. The exact break-even point depends on the target precision, confidence, query protocol, memory trace, task count, and the selected prices for unlike resources. This is an accounting theorem, not a theorem that useful representations can be acquired economically.

Compare two policies under the same task stream, task prompts, oracle, and query rights. Both receive the same setup and validation transcript, and both are evaluated at the same predictive loss target epsilon and failure probability delta. The acquired policy may construct and retain a reusable representation R. The raw-retention baseline may retain the raw transcript, refit from all history, and cache any result it has derived. Do not define the baseline as forgetting its previous work. If policies make different on-demand task queries, report those counts and confirm that both had the same query interface and price; the theorem charges any difference explicitly.

There are three resource coordinates. For S, count the setup interval and each later task interval once; m_j,t denotes policy j's live bits during interval t, and S_j0 denotes its setup-interval bit-time. Thus S is a holding-cost measure, not just the final model size.

- Q: oracle/query calls, with declared price lambda_Q per call;
- W: bit operations at the declared numerical precision, with price lambda_W per operation;
- S: memory bit-tasks, where S = sum over time of live stored bits, with price lambda_S per bit-task.

Also report peak live memory M_max separately and impose a common capacity K. If no defensible prices convert these unlike resources into one objective, use the componentwise Pareto condition below instead of adding them. The precision parameter p is explicit: it determines approximation error, validation burden, bit-operation cost, and representation size. Both methods must meet the same (epsilon, delta) target at their selected p. In particular, require representation approximation error plus fitting error to fit within epsilon, and include the validation procedure needed for the stated confidence in its setup costs.

The setup transcript may include q_s acquisition queries and q_v validation queries. To enforce equal information, make their answers available to the raw baseline too and charge the physical q_s + q_v calls in both gross ledgers. They cancel in the differential ledger. If a comparison instead gives one policy additional query answers without giving the baseline access to those answers, it is information-asymmetric; report that extra count and do not call it equal-information. Validation computation that only the acquired policy needs remains a setup-work cost.

2. Exact amortization theorem

For a horizon of N later tasks, let the acquired policy have setup costs (Q_R0, W_R0(p_R), S_R0(p_R)); its setup work includes representation construction and validation. Let the raw-retention baseline have setup costs (Q_B0, W_B0(p_B), S_B0(p_B)). Let q_R,t and q_B,t be any method-specific task queries, w_R,t(p_R) and w_B,t(p_B) be task work, and m_R,t(p_R), m_B,t(p_B) be live memory after task t. Common task-access queries are omitted from both expressions because they cancel. Define Delta Q0 = Q_R0 - Q_B0, and similarly Delta W0 and Delta S0. Assume both methods satisfy the same (epsilon, delta) predictive target and their peak memory is at most K.

At fixed nonnegative prices lambda_Q, lambda_W, lambda_S, the acquired policy is strictly cheaper over the N tasks if and only if

  sum_{t=1}^N G_t  >  F,

where

  F = lambda_Q Delta Q0 + lambda_W Delta W0 + lambda_S Delta S0,

  G_t = lambda_Q(q_B,t - q_R,t)
      + lambda_W(w_B,t(p_B) - w_R,t(p_R))
      + lambda_S(m_B,t(p_B) - m_R,t(p_R)).

Equality is exact break-even. If strict componentwise resource dominance is required instead of a priced objective, the acquired policy dominates exactly when each component of its full (Q,W,S) ledger is no larger and at least one is smaller, with the same accuracy and peak-memory feasibility. Peak memory is a feasibility constraint; it is not silently converted into a bit-time saving.

Proof. Write each policy's total charge as its setup charge plus the sum of its task charges. Subtract the acquired-policy total from the baseline total. The shared task transcript and any shared query bill cancel. The remainder is sum_t G_t - F. The acquired policy is strictly cheaper exactly when that difference is positive. The result is sharp because it is an identity; no smaller fixed-cost term or larger task-saving term can be omitted without changing a ledger. The accuracy and capacity assumptions are required for the comparison to describe equivalent feasible policies.

Equal-information consequence. If both policies receive the same setup and validation answers and are charged the same physical query bill, then Delta Q0 = 0, although q_s + q_v remains present in each gross ledger. If the acquired method makes extra on-demand task queries, their answers must be made accessible to the baseline under the same rights and their calls charged, or the comparison must disclose that the methods saw different evidence. It is invalid to count setup answers as free evidence for the representation and at the same time deny the raw baseline access to them.

3. Constant-cost break-even count

Suppose each later task yields the same net saving G > 0 at the matched precision, and the net setup charge is F >= 0. Then strict savings begin at

  N_min = floor(F / G) + 1.

If G <= 0, a positive setup charge is never repaid. If F < 0, the acquired policy already begins with a net advantage at N=0. For the common special case where query costs are shared and per-task queries cancel, let w_R be acquired-policy work per task, w_B be raw-baseline work per task, and m_R,m_B be memory bit-tasks per task. Then

  G = lambda_W (w_B(p_B) - w_R(p_R))
    + lambda_S (m_B(p_B) - m_R(p_R)),

  F = lambda_W [w_acquire(p_R) + w_validate(p_R, epsilon, delta) - w_B0(p_B)]
    + lambda_S [S_R0(p_R) - S_B0(p_B)].

The precision dependence is material: raising p may reduce representation error while increasing w_acquire, w_validate, w_R, and m_R. Validation queries q_v belong in both gross query ledgers when their answers are shared; q_v(p, epsilon, delta) must still be disclosed. A reported threshold without the precision and confidence at which it was computed is incomplete.

For nonconstant tasks or memory traces, use the exact sum in Section 2; do not force it into a constant per-task threshold. For example, if a baseline truly retains h raw bits per task while the representation holds a fixed-size model, cumulative memory bit-task savings can grow quadratically with N. That is a real storage result only if the baseline cannot replace those raw records by a smaller sufficient summary. A competent retaining baseline should be allowed to compress or cache when its interface permits it.

4. Retention defeats an unqualified advantage claim

Let theta be any d-bit vector. A one-time setup transcript consists of the d answers to coordinate queries e_i -> theta_i, plus any validation answers. Both policies receive and pay for the identical transcript. Later task t supplies x_t in {0,1}^d and asks for y_t = inner_product(theta, x_t) modulo 2.

The acquired representation is theta itself. It occupies d bits, is exact at one-bit coefficient precision, and answers each task with a parity computation. The raw-retention baseline keeps the d coordinate-answer records, which contain exactly the same d bits, and answers the same parity query. Its error, confidence, setup-query count, validation-query count, memory, and per-task work match the representation policy. The raw baseline may also skip representation-specific validation computation because it directly retains the exact coefficient bits; if an evaluation forces both methods to run the same validator, that work is common. If a proposed baseline instead solves the same d-by-d identity system anew on every task, that extra refit is an avoidable policy choice: retaining the previous solution removes it. Thus a per-task advantage against a forgetful re-fit baseline disappears under ordinary retention, with no change in information or precision.

More generally, if R = phi(D) is a deterministic representation of retained transcript D, a baseline with D can compute phi(D), cache R, and follow every later action of the acquired policy. The baseline cannot have a statistical-decision advantage from R that was unavailable from D. It can have a computational or memory advantage only relative to a stated resource constraint and a baseline that cannot or does not perform the same preprocessing. If memory capacity forbids storing both D and R, the baseline may still choose which state to retain; that tradeoff must be represented in m_B(t) and K. If R uses fewer bits than D, that can establish compression, but it does not by itself establish cheaper acquisition, validation, or task execution.

This simulation argument is a negative theorem against any unconditional claim that acquiring R improves predictive quality or total cost over an unrestricted, equally informed baseline able to retain history and cache derived state. Strict cost improvement requires a restriction or price asymmetry, such as limited memory, bounded compute, costly replay, task-specific latency constraints, or a refitting baseline that is explicitly required to recompute. Name that condition and charge it.

5. Relation to primary literature

Blackwell's comparison of experiments formalizes the decision-risk side: an observation/statistic that is a function of a richer experiment cannot improve attainable statistical decisions solely by carrying more information. It does not compare the computation or memory needed to construct and use the statistic. This is the right boundary for the retention argument. Original paper and scan: David Blackwell, “Comparison of Experiments,” Proceedings of the Second Berkeley Symposium on Mathematical Statistics and Probability, 1951, pp. 93–102, https://digicoll.lib.berkeley.edu/record/112749.

Baxter's model of inductive-bias learning proves multi-task sample-complexity benefits under a related-task environment and conditions on the hypothesis-space family. It does not prove the economic theorem above: Baxter explicitly limits the treatment to sample-complexity properties and defers computability of the bias learner and representation/search cost. Source: Jonathan Baxter, “A Model of Inductive Bias Learning,” Journal of Artificial Intelligence Research 12 (2000), 149–198, https://doi.org/10.1613/jair.731; full text https://people.eecs.berkeley.edu/~russell/classes/cs294/f05/papers/baxter-2000.pdf.

Tarjan describes amortized analysis as averaging cost over an operation sequence. The theorem here applies that bookkeeping to a representation-acquisition phase followed by N task operations, with extra query and memory coordinates and a matched-quality constraint. Tarjan's paper is a survey of the method, not evidence that an acquired representation is useful: Robert E. Tarjan, “Amortized Computational Complexity,” SIAM Journal on Algebraic and Discrete Methods 6(2) (1985), 306–318, https://doi.org/10.1137/0606031.

6. Reusable decision rule

Before claiming acquisition benefit, publish one row per resource and one row per precision: same source/task transcript; same epsilon and delta; setup-query count; validation-query and validation-work count; setup bit-work at p; per-task work at p; retained bits after every task; peak memory; task horizon N; and the actual raw-retention baseline policy. Then apply the exact inequality in Section 2. If the baseline can cache the learned object, compare against that stateful baseline. If the acquired method wins only against repeated relearning, state that restricted comparison. If the evidence does not determine a shared-task model or validate its transfer, mark the corresponding accuracy/coverage term UNKNOWN rather than treating amortization as proof of generalization.

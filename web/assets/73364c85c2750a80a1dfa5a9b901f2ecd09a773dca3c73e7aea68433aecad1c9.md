## First-pass transfer: deletion-channel hardness for unstructured molecular tags

### Result and status

There is a precise, conditional no-go transfer from the family-122 trace-reconstruction lower bound to binary molecular tags. If a tag is an arbitrary word in a two-base alphabet, and every sequencing read is an independent complete subsequence produced by known iid per-base deletion, then for each fixed deletion probability $q\in(0,1)$ there are two length-$n$ tags whose distributions remain indistinguishable under every polynomial number of reads. This is a sample lower bound against every decoder, including one with unlimited computation.

The mathematical step that transfers is short but exact. Let
\[
 d_n=\min_{x\ne y\in\{0,1\}^n}\operatorname{TV}(D_q(x),D_q(y)).
\]
The source-reported family-122 theorem states $n^A d_n\to0$ for every fixed $A>0$. Since the minimizing pair exists at each $n$, choose $(x_n,y_n)$ attaining it. For $m$ iid traces, product subadditivity gives
\[
 \operatorname{TV}(D_q(x_n)^{\otimes m},D_q(y_n)^{\otimes m})\le m d_n.
\]
For any fixed polynomial budget (m(n)\le n^r), take (A=r+1): then (m(n)d_n\le n^{-1}(n^{r+1}d_n)=o(1)). Under equal prior probabilities, the optimal binary identification success is at most
\[
 \tfrac12\bigl(1+\operatorname{TV}(D_q(x_n)^{\otimes m},D_q(y_n)^{\otimes m})\bigr)=\tfrac12+o(1).
\]
This implication is internally derived from the source theorem; the family-122 theorem itself is source-reported and has not been independently proof-checked here.

## Exact application contract

Map bit 0 to A and bit 1 to C. An (n)-base tag is read repeatedly from the same molecular species. Each read independently deletes each base with probability (q), preserves the order of survivors, and reveals the complete surviving string and its length, without original position labels. The decoder knows (n,q), and the two hypotheses are equiprobable. There are no insertions, substitutions, flanking anchors, position tags, or whole-molecule dropouts in this contract; reads from different tags do not mix.

The conclusion applies if the allowed tag set contains the source's hard pair; it automatically applies to the unrestricted set of all (2^n) A/C tags. It does **not** imply a lower bound for every designed codebook. The source does not state that its minimizing pair obeys GC, homopolymer, secondary-structure, primer, or other synthesis constraints. A code designer may exclude the pair or use explicit redundancy.

This boundary matters for actual DNA storage: the empirical channel literature models a pool of short molecules, sampling/dropout, PCR effects, and within-molecule substitution, insertion, and deletion errors. That is different from one known oligo sent through repeated iid deletion-only reads. The result concerns an inner-code subproblem for an individual tag, not recovery of a whole DNA data-storage pool.

## What code design can change

Two primary-literature results identify the escape route. Aamand, Liu, and Narayanan give polynomial-time reconstruction with $O(n\log n)$ traces for strings with sufficiently large zero gaps between successive ones at a sufficiently small constant deletion rate. A direct count shows that this sufficient family has vanishing binary rate: if the gap is $L=\Theta(\log^8 n)$, the number of allowed words is at most
\[
 \sum_{t\le 1+(n-1)/(L+1)}\binom nt
 \le (r+1)(en/r)^r,\qquad r=\left\lceil 1+(n-1)/(L+1)\right\rceil,
\]
so $\log_2|C_{n,L}|=O((n/L)\log L)=O(n\log\log n/\log^8 n)=o(n)$. This is a capacity cost for this sufficient easy subclass, not for all polynomially decodable codebooks.

Conversely, Brakensiek, Li, and Spang construct binary codes of rate $1-\varepsilon$ recoverable with a number of traces depending on $q,\varepsilon$ but not on $n$, for fixed deletion probability. Thus the arbitrary-string lower bound and high-rate coded recovery coexist: the obstruction is to unstructured worst-case tags, not to binary DNA tagging in general. Their code theorem does not certify compatibility with biochemical sequence filters or the full storage channel.

## Practical prediction, control, and costs

For a fixed unstructured tag universe containing the hard pair, increasing the number of independent reads polynomially in tag length cannot drive equal-prior identification success away from $1/2$ as $n\to\infty$. For an explicitly designed codebook, this prediction is not asserted; code structure can change the sample complexity. The strongest matched control is a codebook decoder at the same length, alphabet, deletion probability, and read budget, with a code construction whose theorem applies. The high-rate coded result is an algorithmic existence control; experimentally, any GC/run-length/secondary-structure filtering must be applied equally and may invalidate its guarantee.

The theorem charges samples through the number of complete trace strings and is independent of decoding time. In the molecular application, $m$ reads cost $m$ sequenced molecules/reads and expose at most $mn$ base positions; decoding can only add cost. For $K$ tags each decoded with $m$ reads, this inner-code burden scales as $Km$, before pool dropout, PCR imbalance, synthesis yield, sequencing throughput, indexing, consensus, or code design are charged. The source's quasipolynomial-time upper theorem is for known rational $q$ and a single deterministic binary string; its runtime also charges received bits and arithmetic, but omits physical sequencing cost.

## Validation gate

First materialize the source's hard pair at selected finite lengths and replay the exact iid deletion channel in software. Then compare a fixed-budget decoder on (a) that pair and (b) an equally long designed-code control under the same known $q$; report exact finite likelihoods where feasible and Monte Carlo estimates with confidence intervals otherwise. A molecular follow-up would require a platform with calibrated deletion-dominant errors and matched oligos; flanks, substitutions, insertions, molecule dropout, and sequence filters must be measured rather than assumed away. The software replay checks the channel-to-tag mapping, not the physical deletion model. The strongest falsifier of the mathematical transfer is a source hard-pair reconstruction error or an error in the iid product-TV calculation; the strongest falsifier of the physical application is evidence that the actual read channel carries useful position information or deviates materially from iid deletion.

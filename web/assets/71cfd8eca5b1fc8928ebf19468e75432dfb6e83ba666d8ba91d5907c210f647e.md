# BMVZ term-generator audit: forced BJSW seed pair

**Status:** exact occurrence and an instance-specific computational-basis row obstruction are proved for a deliberately augmented, BMVZ-admissible QMA-hard input family. The published canonical BMVZ starting family does not identify this BJSW pair, so its occurrence in that particular unmodified family remains unshown. The obstruction does not extend to arbitrary changes of basis or arbitrary common encodings.

## Primary-source extraction

BMVZ's construction is an algorithmic definition in the paper, rather than a released code package. For a layered input

\[
H=\sum_{\chi=1}^g w_\chi H_\chi,\qquad
H_\chi=\mathbb E_{i\in[m_\chi]}\Pi_i^\chi,
\]

the projections within each layer commute (BMVZ, Definition 1.6, HTML lines 215–224). If a layer is larger than the fixed constant \(m_0\), BMVZ puts a deterministically constructible constant-degree expander on its clause labels (Lemma 2.9, lines 401–405); its generator enumerates the length-\(t\) paths \(f\) and emits

\[
\Pi_f^\chi=I-\bigotimes_{j=1}^{t}(I-\Pi_{f(j)}^\chi).
\]

For smaller layers, including a singleton, the paper says to handle them by “trivially repeating” their clauses. Thus a singleton layer's emitted factors are all copies of its sole projector (the label tuple is constant if no padding is used; padding only creates duplicate labels for that same projector). The output is the weighted expectation of these path clauses, with at most \(m d^t\) clauses in one round (Definitions 1.7 and 1.9, HTML lines 225–240).

This is a polynomial-size term generator under the theorem's parameter choice. In the iterated construction, each round uses \(2t\) copies, \(\ell=\lceil6\log p(n)/\log t\rceil\), and hence

\[
R=(2t)^\ell,\qquad
n_{\rm out}=n_{\rm in}R\le 2t n_{\rm in}p(n)^{12}.
\]

The clause multiplier is \(d^{2t\ell}\le d^{2t}p(n)^{12t/\log t}\), polynomial for fixed \(t\) (BMVZ, Theorem 7.3 proof, HTML lines 1041–1075). The seed terms below require no expander enumeration at any round: their singleton layers always repeat their sole clause. Recursively, if \(G_{v,r}=I-(I-|v\rangle\langle v|)^{\otimes r}\), then a \(2t\)-fold singleton step emits

\[
I-(I-G_{v,r})^{\otimes 2t}
=I-(I-|v\rangle\langle v|)^{\otimes (2tr)}.
\]

After \(\ell\) rounds the exact output term is therefore \(G_{v,R}\), where \(R=(2t)^\ell\).

The paper's QMA-hard starting family comes from a degree-reduced 5-local Hamiltonian: Claim 8.1 records unweighted projection terms and at most seven terms incident to each qubit; the conflict graph has degree at most 35; an equitable coloring gives a constant number of commuting layers (BMVZ, HTML lines 1101–1125). Theorem 7.4 then applies the iteration to that family (lines 1077–1083). Neither section lists the exact BJSW vectors among the unmodified ABN-derived input terms. I therefore do not mark their occurrence in that canonical input as established.

## Exact forced occurrence in a BMVZ-admissible hard family

The displayed weighting corresponds to singleton seed colors of weight
\(1/4\) each and original color weights scaled by \(1/2\). BMVZ
Definition 1.6 permits positive layer weights, and the seed block's per-qubit
incidence is two.

The augmentation uses the weighted layered interface exactly as defined in
BMVZ Definition 1.6: every color weight is positive, sums to one, and the
minimum color weight stays constant. It does not replace the hard input with
an unweighted global term average.

The pair is forced by a small augmentation that preserves the hypotheses and QMA hardness. Normalize the BMVZ starting sum as an expectation \(H_0=m^{-1}\sum_i P_i\), with its polynomially small completeness energy and inverse-polynomial soundness energy. Add a separate five-qubit ancilla block and define

\[
H_+=\tfrac12 H_0\otimes I
 +\tfrac14 |\phi_5\rangle\langle\phi_5|
 +\tfrac14 |\psi_5\rangle\langle\psi_5|.
\]

Put the two new rank-one projections in their own singleton layers. The two vectors are linearly independent, so their orthogonal complements have a common subspace (dimension 30 in the 32-dimensional block). In a yes instance, tensor a low-energy witness with any state in this common subspace; in a no instance, positivity gives \(\lambda_{\min}(H_+)\ge\lambda_{\min}(H_0)/2\). Thus the promise remains low-versus-inverse-polynomial-high and QMA-hard. The number of layers remains constant, their minimum layer weight stays bounded below by a constant, and each layer contains commuting projections. Hence this augmented input satisfies BMVZ's Assumption 7.1. Since the added layers are singletons, BMVZ's actual small-layer rule emits the exact all-equal repetition terms below at every iteration.

BJSW's 5-LCH proof supplies the local seeds. Its propagation term has the outer clock factor \(|10\rangle\langle10|\) (equation (4), HTML lines 182–189); for a \(\Lambda(P)\) gate, equation (6) includes \(\phi_3=|-\rangle|00\rangle\), and for an \(H\otimes H\) gate, equation (7) includes \(\psi_3=(|000\rangle-|011\rangle-|101\rangle-|110\rangle)/2\) (lines 191–201). Append the common clock suffix \(|10\rangle\), obtaining

\[
\phi_5=(|00010\rangle-|10010\rangle)/\sqrt2,\qquad
\psi_5=(|00010\rangle-|01110\rangle-|10110\rangle-|11010\rangle)/2.
\]

These are precisely the two local seed types from leaf 15. BJSW uses them in gate-specific decompositions, not as a claim that both occur on one clock step of its reduction; the augmentation above places both on the same five-qubit ancilla and in the same BMVZ input instance, in separate colors.

For \(v\in\{\phi_5,\psi_5\}\), the generated term on \(R\) repeated blocks is

\[
Q_{v,R}=I-(I-|v\rangle\langle v|)^{\otimes R},\qquad
(Q_{v,R})_{x,y}=\delta_{x,y}-\prod_{r=1}^R
\bigl(\delta_{x_r,y_r}-v_{x_r}\overline{v_{y_r}}\bigr),
\]

where each \(x_r,y_r\) is a five-bit string. The local computational-basis supports are

\[
S_\phi=\{00010,10010\},\quad |S_\phi|=2;
\qquad
S_\psi=\{00010,01110,10110,11010\},\quad |S_\psi|=4.
\]

For a row block string \(x=(x_1,\ldots,x_R)\), let \(a=|\{r:x_r\in S_v\}|\). Its exact row count is 0 if \(a=0\), and \(|S_v|^a\) otherwise: blocks outside the seed support force the matching column block, while each supported block allows exactly \(|S_v|\) nonzero choices. The all-supported rows attain the maxima \(2^R\) for \(Q_{\phi,R}\) and \(4^R\) for \(Q_{\psi,R}\).

This also proves a row lower bound for the *full augmented output Hamiltonian*, not just its displayed terms. Choose a basis row whose five-qubit ancilla block is \(00010\) in every copy, with any fixed basis string on the original BMVZ registers. The base-family terms act as identity on these ancillas, so contribute zero to columns that change the ancilla string. The two added terms have seed supports intersecting only at \(00010\). Their off-diagonal column supports from the chosen row are disjoint, and every listed entry is nonzero; their shared diagonal entry is positive. Consequently, this row of the full output has at least

\[
|S_\phi|^R+|S_\psi|^R-|S_\phi\cap S_\psi|^R
=2^R+4^R-1
\]

nonzero entries. There is no cancellation from the other QMA-hard terms on these columns. As BMVZ's high-gap iteration has \(R\) polynomial in the inverse-gap polynomial, this is superpolynomial (indeed exponential in a polynomial) row support in the output's computational basis. The sparse obstruction is specific to this constructed BMVZ output and basis; it does not rule out a change of basis or a different encoded representation.

## Charged access and the bare two-branch enforcer test

The seed projectors have rational matrix entries (denominators 2 for \(\phi_5\), 4 for \(\psi_5\)). A selected \(Q_{v,R}\) entry is computed by the displayed product in \(O(R)\) exact factor operations, with numerator and denominator bit lengths \(O(R)\); this is polynomial in the BMVZ output size. Listing an all-supported row is output-sensitive and costs at least \(2^R\) or \(4^R\) entries. This matches BMVZ's distinction between polynomially many terms that are easy to measure and a sparse matrix representation: their Theorem 1.4 describes \(O(n)\)-fold tensor-product terms and easy term measurement (HTML lines 173–180), while the sparse-quantum-PCP discussion explicitly leaves efficient sparse matrix conversion open (lines 194–209).

There is also a sharper exact obstruction for the bare two-branch isometry built from this pair. State-preparation Cliffords can be taken as \(C_\phi=ZH\) on the first qubit and

\[
C_\psi=CZ_{01}Z_0Z_1\,\mathrm{CNOT}_{1\to2}\,
\mathrm{CNOT}_{0\to2}H_0H_1.
\]

They prepare \(\phi_3\) and \(\psi_3\) from \(|000\rangle\). Appending the same \(X\) on the first clock-suffix qubit prepares the common \(|10\rangle\). Exact multiplication over \(\mathbb Q(\sqrt2)\) gives every entry of \(C_\psi^*C_\phi\) magnitude \(\mu=1/(2\sqrt2)\); appending the common clock operation tensors this relative matrix with \(I_4\) and does not change \(\mu\). The standalone script verifies the circuits and exact entries.

For

\[
V_R|\eta\rangle=\bigl(|0\rangle U_\phi^{\otimes R}|\eta\rangle+
|1\rangle U_\psi^{\otimes R}|\eta\rangle\bigr)/\sqrt2,
\]

any nonzero row of an exact enforcer \(C\) with \(CV_R=0\) is a dependence among computational-basis rows from the two Clifford bases. Within either branch those rows are orthogonal; across branches their normalized overlaps are at most \(\mu^R=2^{-3R/2}\). Gershgorin's bound makes any set of \(s\) such rows linearly independent when \((s-1)\mu^R<1\), so each nonzero enforcer row needs at least

\[
\left\lceil1+2^{3R/2}\right\rceil
\]

nonzeros. This rules out polynomial-row exact enforcers for this *bare pair-only two-branch isometry*. It does not establish a no-go for a multi-branch encoding of every term in the augmented QMA-hard family: additional branches can change the Gram dependencies. The full-output computational-basis row result above is separate and does not rely on an enforcer argument.

## Reproduction and source locations

Run `python3 outputs/research/games_hamiltonians/cycle2/bmvz_bjsw_seed_pair_test.py`. It uses only the Python standard library, exactly verifies both Clifford preparations and the \(1/8\) squared relative-entry magnitude in \(\mathbb Q(\sqrt2)\), exhaustively checks all 32 rows of each local \(R=1\) term against the support formula, and writes the table below. The larger-\(R\) rows use the proved closed-form support counts, so no exponential matrix is allocated.

The generated [seed-pair table](bmvz_bjsw_seed_pair_table.csv) records local qubits, exact term row maxima, the full-output row lower bound, and the bare-enforcer lower bound for representative \(R\). The values are illustrative; BMVZ's actual iteration uses \(R=(2t)^\ell\).

Rational complete-pair minorization fixture
============================================

Supplied fixture
----------------
One catalyst A and one substrate B; k=1; each of alpha, delta, p, q, u,
v independently ranges over [1,2]. These are chosen rational box data, not
acquired chemical measurements.

Take R=6/5, V(a,b)=a+(1+1_{a=0})R^b, c=1/10, and

  C = 369138966157/12207031250,

so the analytic proof in PROOF.txt establishes LV<=C-cV for every state and
every rate vector in the box. The common drift set is D={V<d}, where

  d = 2C/c+4 = 743160744814/1220703125,
  A_D=floor(d)=608,
  B_D=35 because (6/5)^35<d<=(6/5)^36.

For each state in D, clear with a currently present catalyst when a>0; at
a=0 immigrate A, clear B, and remove A. The common path-length and catalyst
count bounds are L_D=A_D+B_D=643 and A_*=A_D=608. The upper bound on total
exit rate throughout every such path is

  Lambda_D = 2 + 4A_* + 4A_*B_D + 2B_D A_*(A_*-1) = 25921474.

Choose the rational skeleton time

  T = 1/(2C+Lambda_D) = 6103515625/158212490720997407.

Then T<=1/(2C), Lambda_D T<1, and the common skeleton drift parameters are

  lambda = 316424981441994814/316424982662697939,
  b = 369138966157/316424981441994814,
  lambda_out=lambda+b/d
    = 74408797958195577532560357097331917799334297019
      /74408798102665589641732753898272767619890937644 < 1.

Here rho_*=1, so the exact rational clearing-path minorization is

  P_T^theta(x,{0}) >= eta,  x in D, theta in [1,2]^6,
  eta = T^643/(3*643!) > 0.

The script `rational_fixture.py` recomputes these constants with Python
Fraction arithmetic and asserts the drift maximum, path exit-rate ceiling,
skeleton inequalities, and positivity of the factored eta. Run:

  python3 -B outputs/research/reaction_dynamics/cycle4/leaves/uniform_mixing/rational_fixture.py

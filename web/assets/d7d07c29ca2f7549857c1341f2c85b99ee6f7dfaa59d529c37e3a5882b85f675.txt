FIXED-Q EXTENSION OF THE MULTIPLICITY-TWO FULL-SPAN BOND FPRAS
2026-10-08 | independent consequence of outputs/research/sol_bond_renewal/RESULT.txt

STATUS: INTERNALLY-PROVED-CANDIDATE, with the Jerrum--Sinclair zero-field
ferromagnetic Ising partition FPRAS as the imported algorithmic theorem.
Novelty, external proof validation and priority are UNKNOWN.

THEOREM / INTERFACE
-------------------
Fix any constant hidden-state alphabet size q>=2. Define the q-state uniform
bounded-span row-urn code as follows. The hidden state is in [q]; each pool
coordinate is a source/destination/gap triple (i,d,g), so there are q^2 gap
colors. It chooses uniformly from all q^2-colored count pools of total span
S<=N-1 together with a separate allzero mode; that separate mode outputs
0^N. For a selected count pool, it chooses an anchor uniformly in
{1,...,N-S} and the first hidden state uniformly in [q], independently.
It draws each outgoing row without replacement until the current row is
empty, and outputs event times only, erasing hidden states. Let K_{N,q} be the
number of pool modes including the separate allzero mode. It is computable
exactly by the fixed-q colored-partition DP; explicitly,

  K_{N,q}=1+sum_{s=0}^{N-1} p_{q^2}(s),

where p_{q^2}(s) counts q^2-colored integer partitions of s. In particular,
K_{1,q}=2 because the empty pool and separate allzero mode are distinct.

Input: one explicit N-bit binary block x(w), with ones at
1, 1+g_1, ..., 1+sum_t g_t=N, where all gaps g_t are positive integers and
every distinct gap value occurs at most twice. Thus m<=N-1 and N is the raw
input length. The block is full-span and begins and ends at an event. No
hidden states, pool, source parameter, code-probability oracle or succinct
horizon are supplied.

For a hidden path u=(u_0,...,u_m) in [q]^(m+1), set

  c_{i,d,g}(u)=#{t:(u_{t-1},u_t,g_t)=(i,d,g)},
  r_i(u)=#{t:u_{t-1}=i},
  a_q(u)=product_{i,d,g} c_{i,d,g}(u)!.

Then the full-span block evidence and code probability are

  Z_q(w)=sum_u a_q(u)/product_i r_i(u)!,
  Q_{N,q}^{bin}(x(w))=Z_q(w)/(q K_{N,q}).

For every rational 0<epsilon<1 and 0<delta<1/2, there is a randomized
algorithm returning a nonnegative rational estimate Zhat_q such that

  Pr[(1-epsilon)Z_q(w)<=Zhat_q<=(1+epsilon)Z_q(w)]>=1-delta.

Its worst-case bit running time is polynomial in N, epsilon^{-1},
log(delta^{-1}) and the bit lengths of the rational accuracy inputs; the
polynomial degree and constants may depend on fixed q. Hence dividing by the
exact qK_{N,q} gives the same relative FPRAS guarantee for Q_{N,q}^{bin},
even when the probability is exponentially small. For q=2 this includes the
exactly #P-hard full-span family in sol_hidden_renewal/RESULT.txt. The theorem
does not cover a gap value repeated three or more times, a censored prefix,
arbitrary q growing with N, a generic hidden-renewal predictor, or the
suffix-averaged optimal predictor.

PROOF
-----
1. Pair-bond expansion and exact correction identity

When a gap label occurs twice, at positions a<b, its factorial factor is

  1 + 1[u_{a-1}=u_{b-1}]1[u_a=u_b].

Thus give it one bond bit sigma_g. Selecting it adds equality edges
{a-1,b-1} and {a,b} on vertices {0,...,m}. Let kappa(sigma) count connected
components of the union graph, including isolates. Then

  U_q(sigma)=q^{kappa(sigma)},
  W_q=sum_sigma U_q(sigma)=sum_u a_q(u).

For component C let a_C be its number of origins among vertices 0,...,m-1;
then sum_C a_C=m, while the terminal vertex m has origin weight zero. If the
components are assigned independent uniform colors in [q], let R_i be the
number of origins colored i. Define

  M_{m,q}=max_{r_1+...+r_q=m} m!/(product_i r_i!),
  C_{m,q}=M_{m,q}/m!,
  g_q(sigma)=E_colors[(m!/(product_i R_i!))/M_{m,q}].

The row-weighted mass B_q(sigma), summing 1/product_i r_i! over all
component colorings, satisfies B_q=U_q C_{m,q} g_q. Consequently

  Z_q(w)=W_q C_{m,q} E_{sigma~mu_q}[g_q(sigma)],
  mu_q(sigma)=U_q(sigma)/W_q,
  0<g_q(sigma)<=1.

Given sigma, compute g_q exactly by the coefficient DP for

  product_C (1+y_1^(a_C)+...+y_{q-1}^(a_C)).

The q-th color is the implicit remainder. A zero-size endpoint-only
component multiplies every coefficient by q. The DP has
O_q((m+1)^(q-1)) states and polynomial-bit coefficients for fixed q.
M_{m,q} is the balanced multinomial coefficient, found by distributing m
as evenly as possible over q bins.

2. Uniform polynomial lower bound on the correction mean

For a fixed sigma, set p_i=R_i/m and D(p||u_q)=sum_i p_i log(q p_i).
The multinomial type bound is

  m!/(product_i R_i!) >= exp(m H(p))/(m+1)^(q-1),
  M_{m,q}<=q^m.

Indeed, R is a mode of Multinomial(m,p), whose support contains at most
(m+1)^(q-1) types. Also, log x<=x-1 gives

  D(p||u_q) <= q sum_i(p_i-1/q)^2.

Coloring components independently and uniformly gives
E R_i=m/q and
Var(R_i)=(q-1)/q^2 sum_C a_C^2. Therefore

  E_colors[m D(p||u_q)]
    <= (q-1)/m sum_C a_C^2
    <= (q-1) a_max,
  a_max=max_C a_C.

Jensen applied to exp(-mD) yields the pointwise correction bound

  g_q(sigma)>=(m+1)^(-(q-1)) exp(-(q-1)a_max).

It remains to bound a_max under mu_q. The potential simple equality graph
E_all has maximum degree two: a vertex can receive at most one start-equality
edge from the next gap position and at most one end-equality edge from the
previous gap position. If an edge is owned by two groups, one start and one
end, these use both possible incidences at both endpoints, so their shared
edge is an isolated two-vertex component. A simple path of length L>=2
therefore has unique group owners per edge and requires at least ceil(L/2)
selected bonds. Adding any bond only adds equalities, so the conditional
probability of selecting any bond, given any other bond bits, is <=1/2 under
mu_q (q^kappa is nonincreasing when edges are added). Thus

  Pr_muq[a fixed set of t distinct bond owners are all selected]<=2^-t,
  Pr_muq[max component size>=L+1]<=2(m+1)2^(-L/2).

With L0=ceil(log_2(64(m+1)^2)), the last probability is at most 1/4 and
2^(-L0)>=1/[128(m+1)^2]. On the complementary event a_max<=L0. Since
ln(2)>1/2,

  exp(-(q-1)L0)
    =(2^(-L0))^((q-1)/ln 2)
    >=(2^(-L0))^(2(q-1))
    >=[128(m+1)^2]^(-2(q-1)).

Hence for every m>=1,

  E_muq[g_q] >= p_q(m)
    := (3/4) 128^(-2(q-1)) (m+1)^(-5(q-1)).

This is inverse-polynomial for every fixed q. It is not uniform polynomial
in q. The degree-two graph and its isolated shared-edge exception are the
only graph structure used; no independence of bond bits is assumed.

3. Conditional q-state tensor and reduction to zero-field Ising

Choose a real orthogonal q-by-q matrix T whose first row is the uniform
vector (1,...,1)/sqrt(q), and apply T to every port index. Equality tensors
are invariant because TT^T=I. An all-ones vector maps to sqrt(q)e_0; an
all-ones tensor on k ports maps to q^(k/2) times a pin of every transformed
port to 0. Thus a singleton gap contributes q and pins both ports; the two
word endpoints together contribute q and pin to 0.

For a doubled label the free four-port tensor is
1+delta(A,C)delta(B,D). Its transformed constant term is
q^2 1[A=B=C=D=0], and its equality term is unchanged. Wire starts and ends
for every doubled label. A free bond then contributes the binary interaction

  M_q=[[q^2+1,1],[1,1]],

between the start-wire and end-wire components, where Fourier state 0 is the
first binary state. A forced identity pins both components to 0 and
contributes q^2; a forced swap only wires them. All pins agree. For any
partial bond assignment h,

  W_{q,h}=q^(1+s+2i) Z_{M_q}(G_h; pins=0),

where s is the number of singleton labels and i the number of forced
identity labels. The original equality graph in Step 2 and this Fourier wire
graph G_h are distinct.

Approximate alpha=q^2+1 by r^4, with rational dyadic r>1 chosen above
alpha^(1/4), close enough that

  |log(r^4/alpha)|<=rho/(8 max(1,L)),

for the desired W_{q,h} relative tolerance rho and L<=m/2 free
interactions. This makes every configuration and the partition change by a
factor in [exp(-rho/8),exp(rho/8)]. The choice r>alpha^(1/4) ensures
r^2>q>q-1.

For spins s_v=+1 at Fourier state 0 and s_v=-1 otherwise, an edge factor
of M_{q,r}=[[r^4,1],[1,1]] is

  (r^4)^(x_u x_v)=r^(1+s_u+s_v+s_u s_v), x_v=(1+s_v)/2.

Collapse the q-1 nonzero Fourier states at each unpinned component. Each
free binary state s_v=-1 then has multiplicity q-1. Remove unpinned
isolated vertices first; each contributes exactly q. For each remaining
free vertex define

  d_v = (# nonloop free-free interaction endpoints at v)
        + 2 (# free-pinned interactions at v)
        + 2 (# self-loops at v),
  B_v=d_v log r - (1/2)log(q-1)>0.

The inequality follows from d_v>=1 and r^2>q-1. Build a zero-field Ising
graph with one common ghost site *, one pair edge of coupling log r for
each nonloop interaction between two free vertices, and one ghost edge of
coupling B_v for every remaining free vertex. All pins are identified with
the ghost; original edges between free and pinned vertices and original loops
are converted to their correct scalar and field contributions. The formula,
with original interaction multiedges counted separately, is

  Z_{M_{q,r}}(G_h; pins=0)
    = C_q(r,G_h) Z_Ising(H; zero field)/2,

  C_q(r,G_h)=q^(I) (q-1)^(F/2)
       r^(E_FF + 2 E_FP + 4 E_PP + 2 L_F + 4 L_P),

where I is the number of unpinned isolated vertices, F the number of
remaining unpinned vertices, E_FF/E_FP/E_PP count nonloop edges between the
indicated classes (free-free, free-pinned, pinned-pinned), and L_F/L_P
count self-loops. For an FF edge the scalar r, pair coupling log r, and the
endpoint-field contributions are exactly its four factors above. An FP edge
has weight r^(2+2s_v), hence scalar r^2 and field 2 log r; a free loop is
the same. A PP edge or pinned loop contributes r^4. The single ghost spin
is summed; global spin flip gives equal ghost slices, so division by two
selects the required common pin value.

The Ising graph has O(m) vertices and edges, no external field, and all
couplings are strictly positive. For an FF edge of multiplicity t and a
field edge at v, the high-temperature activities are exact rationals:

  lambda_t=(r^(2t)-1)/(r^(2t)+1),
  mu_v=(r^(2d_v)-(q-1))/(r^(2d_v)+(q-1)) in (0,1).

Although (q-1)^(F/2) and cosh(B_v) need not be separately rational, their
product is exactly rational:

  sqrt(q-1) cosh(B_v)
     = [r^(d_v)+(q-1)r^(-d_v)]/2.

Thus the JS partition prefactor combined with C_q is rational and has
polynomial bit length. The FF cosh factors (r^t+r^(-t))/2 are rational.
All exponents are O(m), and r has O(log(m/rho)+log q) bits. No irrational
matrix entry from T is used by the algorithm: the proof reduces it to the
explicit integer q^2 constants and rational activities above.

The imported theorem is Jerrum--Sinclair, “Polynomial-Time Approximation
Algorithms for the Ising Model,” SIAM J. Comput. 22(5) (1993),
https://doi.org/10.1137/0222066; author PDF
https://people.eecs.berkeley.edu/~sinclair/ising.pdf. Its Theorem 5 gives a
ferromagnetic Ising partition FPRAS in an exact-real arithmetic model. The
finite-bit specialization uses the rational high-temperature activities,
Theorem 2's generator at annealing penalties mu>=1/v, and fixed-b-bit dyadic
simulation of each rational Metropolis transition. The generator's
O(E^2 mu^-8(log delta^-1+E)) step dependence is polynomial since the schedule
never samples below 1/v. A finite-kernel coupling with per-step TV error
O(tau/T_chain), plus the theorem's mixing allowance, gives a fixed worst-case
polynomial bit implementation; no unbounded rejection loop is used.

4. Relative FPRAS composition

If L=0 there are no bonds: W_q=q^(m+1), and the exact fixed-q component
count-vector DP computes Z_q directly. This includes m=0, where Z_q=q. For
N=1, K_{1,q}=2 (the empty count pool plus the separate allzero mode), so the
one-event code probability is Z_q/(qK_{1,q})=1/2. Hence assume L>=1 below.

The same component tail argument implies each selected bond conditional is
in [1/(q^2+1),1/2]: one selected gap adds at most two equality edges, so
U_1/U_0 is between q^-2 and 1 termwise. Thus approximate child partition
masses W_{h0},W_{h1} with relative tolerance

  rho=Theta(epsilon p_q/L), failure gamma=Theta(epsilon p_q/L),

and normalize to get each conditional. If both calls are accurate, scalar
branch error is O(rho); sequential coupling over the L stages, charging at
most gamma per partition-estimate failure and the allocated dyadic rounding
error per transition, makes the law nu of one complete self-reduction sample
within xi=epsilon p_q/32 TV of mu_q. No union bound over the T independent
samples is needed: they are iid from nu, and concentration is around E_nu g.
On a failed estimate, the algorithm cannot
recognize the failure; it always maps returned nonnegative masses to a
valid probability (using a fixed fallback if both are zero) and charges
conditional TV at most one on the FPRAS failure event.

Compute g_q exactly per sample by its fixed-q count-vector DP. Since
0<=g_q<=1, |E_nu g_q-E_muq g_q|<=xi and E_nu g_q>=p_q/2. The number of
independent samples

  T=O(epsilon^-2 p_q^-1 log(delta^-1))

then suffices for a relative epsilon/8 estimate of E_nu g_q by bounded
multiplicative concentration. Independently estimate W_q to relative epsilon/8
by its JS-based FPRAS and multiply by C_{m,q}. Exact division by qK_{N,q}
preserves relative error. The total arithmetic, sample, conditional-call,
Ising-graph, and accuracy costs are polynomial in N, epsilon^-1,
log(delta^-1) for each fixed q. A deliberately coarse number of conditional
W calls is O(L T)=O_q(m^(5(q-1)+1) epsilon^-2 log(delta^-1)); each call
uses JS accuracy inverse polynomial in m and epsilon. No inverse likelihood,
rare conditional branch, rejection event, or supplied dictionary occurs.

For an explicit coarse arithmetic bound, put p=p_q(m). There are
T=O(epsilon^-2 p^-1 log(delta^-1)) correction samples and at most L<=m/2
conditional partition calls per sample. Thus the number of W calls is
O_q(m^(5(q-1)+1) epsilon^-2 log(delta^-1)). With v,e=O(m), the source's
Theorem-5/annealing bound gives a per-call exact-real arithmetic cost
O(rho^-2 e^2 v^11 log(v+1)[e+log(v/rho)] log(gamma^-1)); substituting
rho=Theta(epsilon p/L) yields the conservative total
O_q(m^(15(q-1)+16) epsilon^-4 log(delta^-1) polylog(m/epsilon,delta^-1))
exact-real operations for the correction phase. This is deliberately a
coarse upper bound, not a practical runtime. The fixed-q correction DP takes
O_q(m^q) integer operations per sample and has O(m log q) coefficient bits;
the colored-partition DP for K_{N,q} takes O(q^2 N^2) additions with
polynomial-bit integers. Rational transition simulation, Ising activities,
prefactors and final products have polynomial bit length and the fixed-step
coupling repair is polynomial, so the bit-time bound remains polynomial.

5. Source/failure boundary

This extends the q=2 multiplicity-two full-span FPRAS to each fixed q using
q-ary row counts and an Ising graph with nonuniform local fields encoded as
positive ghost edges. It does not cover a repeated gap label of multiplicity
3+, because the pair-bond expansion is then replaced by a higher-arity
permutation tensor. Sol idempotent conflict owns that distinct
multiplicity-three Walsh-cycle route. It does not cover censored prefixes or
general predictive marginals; full span is what removes unused pool resources.
The empty-gap case m=0 is handled exactly: Z_q=q and, at N=1, the one-event
full-span code probability is 1/2 because K_{1,q}=2.

The exact q=2 #P-hardness reduction and its FPRAS do not imply an
approximation-preserving reduction or approximate-hardness barrier. The FPRAS
is a computational likelihood theorem for a restricted code family, not a
teacher-free hidden-state or source-reconstruction algorithm.

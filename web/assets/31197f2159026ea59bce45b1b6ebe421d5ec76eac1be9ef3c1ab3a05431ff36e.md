# Sparse positive rational-rate recognition is already coNP-hard

## Status and exact interface

This is an internal complexity reduction for the tropical/essential-source
recognition interface in
`outputs/research/cycle_checkpoint_03/evidence/systems_metabolism/reaction_graphs/RATIONAL_RATE_TROPICAL_LIFT.md`.
It is not a claim about a different definition of endotacticity, signed
coefficients, or black-box rates. Inputs are finitely many channels
\(e\), each with a fixed integer reaction vector \(\nu_e\) and a positive
rational rate \(P_e/Q_e\), where \(P_e,Q_e\) are sparse polynomials with
nonnegative integer exponents and positive rational coefficients. For a log
direction \(w\), set

\[
 \tau_e(w)=h_{P_e}(w)-h_{Q_e}(w),\qquad
 h_P(w)=\max_{\alpha\in\operatorname{supp}P}\alpha\cdot w.
\]

Use the exact neutral-edge convention from RG-05: first restrict to
\(E(w)=\{e:\nu_e\cdot w\ne0\}\); if this is empty the test is vacuous;
otherwise maximize \(\tau_e(w)\) over \(E(w)\), and require every exact
maximizer to have \(\nu_e\cdot w<0\). In particular, ties are exact, and a
neutral channel does not screen an active top channel.

## Reduction from 3SAT

Take a 3CNF formula on variables \(X_1,\ldots,X_n\), with three distinct
variables in every clause. The state variables are \(X_1,\ldots,X_n,Z\),
and a log direction is \(w=(u_1,\ldots,u_n,z)\). A literal has sign
\(\sigma\in\{+1,-1\}\). Build these channels; every displayed polynomial
has coefficient 1 on each term.

| Channel | Rate \(P/Q\) | Reaction vector |
|---|---|---|
| Target \(T\) | \(1\) | \(e_z\) |
| Variable \(V_i\) | \(X_i Z/(X_i^2+1)\) | \(-2e_z\) |
| Clause \(C=(\ell_1,\ell_2,\ell_3)\) | \(Z\prod_{i\in C}X_i\; /\; Q_C\) | \(\sum_{\ell=(i,\sigma)\in C}\sigma e_i-3e_z\) |
| Guard \(G_i^+\) | \(X_i/Z^2\) | \(-e_i\) |
| Guard \(G_i^-\) | \(1/(X_i Z^2)\) | \(+e_i\) |

The clause denominator is the ordinary polynomial

\[
 Q_C=\sum_{(i,+1)\in C}X_i^2\!\prod_{j\in C\setminus\{i\}}X_j
       +\sum_{(i,-1)\in C}\prod_{j\in C\setminus\{i\}}X_j.
\]

All denominators are strictly positive on the positive orthant. All supports
are explicit, sparse, and nonnegative-integral: the target has one term per
side; a variable denominator has two; a clause denominator has three; each
guard denominator has one. There is no denominator clearing or Cartesian
product in the construction. The total number of channels is \(3n+m+1\),
where \(m\) is the number of clauses.

In direction \(w=(u,z)\), the channel orders are exactly

\[
 \tau_T=0,\qquad \tau_{V_i}=z-|u_i|,\qquad
 \tau_C=z-\max_{(i,\sigma)\in C}\sigma u_i,
 \qquad \tau_{G_i^+}=u_i-2z,\quad
 \tau_{G_i^-}=-u_i-2z.
\]

These identities follow directly from the sparse supports. For example,
\(h_{X_i Z}=u_i+z\) and \(h_{X_i^2+1}=\max(2u_i,0)\), giving
\(\tau_{V_i}=z-|u_i|\). The clause denominator terms have heights
\(\sum_{j\in C}u_j+\sigma u_i\), while its numerator has height
\(z+\sum_{j\in C}u_j\), giving the stated clause order.

### Satisfiable formula gives a non-endotactic witness

Given a satisfying truth assignment, set \(z=1\) and \(u_i=+1\) for true
variables, \(-1\) for false ones. Then \(T\) is active, outward, and has
order 0. Every variable channel also has order 0 and points inward, since
\((-2e_z)\cdot w=-2\). Every satisfied clause has order 0; its reaction
dot product is \(\sum_C\sigma u_i-3=2r-6\le0\), where \(r\ge1\) is the
number of true literals. It can be neutral when all three literals are true;
neutral ties are excluded and do not affect the target. For each variable,
its paired guards have orders \(-1\) and \(-3\), in an order determined by
the assignment. Thus the target is an outward essential maximizer (tied at the exact
top order 0), so the system is not endotactic. This uses, rather than
perturbs away, the exact top tie.

### Unsatisfiable formula gives an endotactic witness

Check all directions, including the coordinate hyperplane \(z=0\).

* If \(z>0\), an outward variable channel does not exist. An outward clause
  has dot product \(S_C=\sum_C(\sigma u_i-z)>0\), so some literal satisfies
  \(\sigma u_i>z\), which implies \(\tau_C<0=\tau_T\). An outward guard
  also has order below 0: \(G_i^+\) is outward only if \(u_i<0\), and
  \(G_i^-\) only if \(u_i>0\); in either case its order is negative.
  Therefore no outward channel can be a top maximizer. If the target itself
  were top, then \(\tau_{V_i}\le0\) gives \(|u_i|\ge z\) for every
  variable, and \(\tau_C\le0\) gives a literal with \(\sigma u_i\ge z\)
  in every active clause. A neutral clause has
  \(\sum_C(\sigma u_i-z)=0\), so its largest literal is at least the
  average \(z\) and it also has a literal with \(\sigma u_i\ge z\).
  Thus the signs of the \(u_i\) would satisfy the formula,
  contradicting unsatisfiability. Hence the top active channels are inward.
  (More directly, all possible outward top channels have already been
  excluded; the active top set is nonempty because the target is active.)
* If \(z<0\), the target is inward at order 0 and every variable channel
  has order \(z-|u_i|<0\). An outward clause has \(S_C>0\), hence some
  \(\sigma u_i>z\), so its order is below 0. For an outward \(G_i^+\),
  \(u_i<0\), and its inward twin has order
  \(\tau_{G_i^-}-\tau_{G_i^+}=-2u_i>0\); the case of outward \(G_i^-\)
  is symmetric. Thus no outward channel is top.
* If \(z=0\), the target and variable channels are neutral. Put
  \(H=\max_i|u_i|\). If \(H=0\), every reaction is neutral and the test
  is vacuous. If \(H>0\), a guard at order \(H\) points inward for every
  coordinate attaining \(H\), and all guards have order at most \(H\).
  Each clause order is \(-\max_C\sigma u_i\le H\). If a clause channel
  points outward, \(\sum_C\sigma u_i>0\), so its largest literal is
  positive and its order is strictly below 0, hence below \(H\). Therefore
  every active top channel is inward. This guard pair is what closes the
  otherwise dangerous \(z=0\) slice.

This proof concerns ordinary essential-source endotacticity only. The
essential-top-face variant that ignores neutral global maximizers is a
different property from standard strong endotacticity. In fact, for the
unsatisfiable three-variable fixture containing all eight sign clauses,
\(w=(0,0,0,-1)\) makes all paired guards neutral global source maximizers at
score 2, with no inward reaction there. Thus this reduction does **not** prove
hardness for the standard Gopalkrishnan--Miller--Shiu strong property. A
separate strong-hardness result remains open.

This proves a polynomial many-one reduction

\[
 3\mathrm{SAT}\le_m \textsf{NON-ENDOTACTIC},
 \qquad
 \textsf{UNSAT}\le_m \textsf{ENDOTACTIC}.
\]

It uses positive polynomial denominators, coefficient 1, integer exponents,
integer reaction vectors, and constant-size supports. The hardness is in the
global direction quantifier and cross-channel ordering, not in evaluating a
support function. A support query on each constructed channel scans at most
three terms.

## Upper bound and exact bounded search interface

For this explicit sparse-input model, `NON-ENDOTACTIC` is in NP. A certificate
contains an outward channel, a rational direction, the neutral/positive/
negative status of each channel, and one maximizing numerator and denominator
exponent for every channel. The verifier checks all dot products, all support
maxima, and \(\tau_e\ge\tau_j\) for each active \(j\) with exact rational
arithmetic. To see that polynomial-bit rational witnesses suffice, fix the
sign pattern and the chosen support maximizers at any real violating
direction. These choices turn the certificate conditions into rational
linear equalities, weak inequalities, and finitely many strict sign
inequalities. Normalize \(\|w\|_\infty=1\) by selecting a coordinate and
sign attaining it, and introduce a margin \(\delta>0\) for all strict
inequalities. The resulting bounded rational LP has positive feasible margin;
an optimal rational basic solution has polynomial bit length. Thus
`NON-ENDOTACTIC` is NP-complete and `ENDOTACTIC` is coNP-complete for the
stated sparse encoding. Exact support-oracle evaluation is polynomial, so a
polynomial-time recognizer using polynomially many calls to that oracle would
imply \(\mathrm P=\mathrm{NP}\).

There remains an exact finite algorithm, but its natural interface must allow
`UNKNOWN` under a work budget. Enumerate (i) an outward candidate, (ii) the
three-way channel sign pattern, (iii) one numerator and denominator
maximizer per channel, and (iv) one coordinate/sign for the normalization.
Each branch is a rational LP: impose support-maximizer inequalities, exact
neutral equalities, strict active-sign margins, and all top-order comparisons.
Use a positive LP margin to decide strict feasibility. Return:

* `REFUTED` plus the exact rational direction if any branch has positive
  margin;
* `CERTIFIED` only if every branch is exhausted and infeasible;
* `UNKNOWN` with the remaining branch/budget record if the budget expires.

This procedure tests all exact ties because support and top-order comparisons
are weak inequalities and all tied active channels remain in the comparison.
Its branch count is exponential (at most a constant multiple of
\(m\,3^m\,2d\prod_e|A_e||B_e|\)), consistent with the hardness result and
with the prior finite LP-cell recognizer. It does not construct the expanded
common-denominator support.

## Replay artifact

`replay_reduction.py` constructs these sparse supports and exactly evaluates
the essential-source test at rational directions. Its SAT fixture confirms
the outward exact top tie; its UNSAT fixture checks a finite direction grid
only. The all-direction UNSAT result is the case proof above, not the grid
diagnostic.

# Exact versus noisy algebraic matrix oracles: N25 boundary audit

## Verdict

The exact and noisy claims have different information contracts. L01 is a source-card claim about exact, full-matrix evaluations of proper characteristic-zero recognizable series, with query count, query dimension, and bit/entry charges. N25 is an information-theoretic lower bound for adaptive full-matrix Gaussian observations of a special real, acyclic series family under a per-query aggregate excitation cap and an expected total query-dimension budget. N25 does not refute L01.

There is a direct strict separation inside the shared hidden-word subfamily. A one-word series of length `d` over `n` symbols has minimal Hankel rank `d+1`. A single exact query of dimension `d+1`, satisfying the same excitation cap `E=1`, identifies the hidden word with polynomial input/output bit cost. Under N25's Gaussian channel with `E=1` and fixed noise, any zero-versus-hidden-word test, and therefore any exact learner, needs expected total query dimension and returned scalar-entry count at least `2 σ² n^d kl(1−δ,δ)`. This is exponential in hidden dimension for fixed `n≥2`. This is a scoped counterexample to transferring exact-query complexity into the noisy interface; it is not a contradiction between the two source claims.

The lower bound below is independently reconstructed from the N25 card's compressed statement. The original cited scout package and the L01 proof note were not present at the pinned Astra commit when opened by their indexed paths. Thus the local proof is an internal reconstruction, and the source claims and priority remain unverified. The counterexample establishes the interface gap without validating L01's universal hitting theorem.

## Reconstructed interfaces

**L01 exact interface (source-card scope).** The target is a proper characteristic-zero noncommutative recognizable series over `n` symbols, with hidden state dimension at most `m`. A query supplies a finite matrix tuple and returns the exact full matrix `f(X_1,…,X_n)`. The card records an explicit Volterra tuple of dimension `2nm` plus `m` scalar rescalings that hits every nonzero series; its learner for minimal rank `r≤m` uses at most `m(1+nr)` exact queries of dimension at most `2nm(r+1)`, with feature length `4n²m³`. A separate batched width-`2n` variant uses maximum dimension at most `4nm` and at most `m+nm²r` calls. The card charges full output entries, coefficient heights, and elimination, and explicitly says field arithmetic is not bit-time and that useful oracle acquisition and numerical stability remain bottlenecks. Its own correction says release 116 plus truncation/unrolling already gave polynomial cyclic capability at `O(nm⁵)` dimension, so the claimed increment is a compactness/cost tradeoff, not first polynomial post-release learnability. Source status is `source_derived_unreviewed`.

**N25 noisy interface (source-card scope).** The target is either zero or the one-word series `f_w`, where `w∈[n]^d`; the nonzero series has a `0/1` acyclic realization and minimal rank `d+1`. At each adaptive call, a `D×D` real tuple obeys `Σ_i X_i*X_i ⪯ E I`; the oracle returns all `D²` entries of `f(X)` with independent Gaussian noise of variance `σ²`. The budget is `C=E_0[Σ_t D_t]`, expected total query dimension under the zero target. If the learner distinguishes zero from every `f_w` with both errors at most `δ<1/2`, N25 states `C ≥ 2σ²(n/E)^d kl(1−δ,δ)`. The stated energy lemma is `Σ_w ||X_{w_1}…X_{w_d}||_F² ≤ D E^d`. The excitation is summed over symbols within each query tuple; the summary does not specify a global cumulative actuation budget across rounds. Because a full response has `D_t²` entries and `D_t²≥D_t`, returned-entry cost is at least `C`. This model does not charge matrix-input description length, query-design runtime, or finite encoding of the Gaussian channel.

The boundary is substantive. L01's exact field oracle supports algebraic equality and rank decisions; N25's real Gaussian oracle only supplies statistical evidence, and a query's information is controlled by its signal energy. An exact series realization is not itself an acquired representation, and an exact oracle guarantee is not a finite-noise guarantee.

## Exact one-query encoding under `E=1`

Fix `n≥2`, `d≥1`, and the family

`f_w(u)=1` if `u=w`, and `0` otherwise, for `w∈[n]^d`.

Its Hankel matrix has rank `d+1`: the `d+1` rows indexed by the prefixes of `w` and columns indexed by the complementary suffixes give a permutation matrix, while the path realization with states `0,…,d` gives the matching upper bound. The realization is acyclic, has only `0/1` transition weights, and is minimal.

Let `D=d+1`. Choose `nd` distinct primes `p_{t,i}` indexed by position `t∈[d]` and symbol `i∈[n]`. For each symbol `i`, define the strictly upper-triangular rational matrix `X_i` by

`(X_i)_{t,t+1}=p_{t,i}/K` for `t=1,…,d`,

with all other entries zero, where

`K = ceil(sqrt(max_t Σ_i p_{t,i}²))`.

Then

`Σ_i X_iᵀ X_i = diag(0, S_1/K², …, S_d/K²) ⪯ I`,

where `S_t=Σ_i p_{t,i}²`. Thus this one query obeys N25's `E=1` cap. Joint strict triangularity also makes the evaluation legal for a formal series, since all products of length at least `D` vanish.

For the target `f_w`, the product has exactly one nonzero entry:

`f_w(X_1,…,X_n)_{1,D}=K^{-d} ∏_{t=1}^d p_{t,w_t}`.

Multiplying that rational by the known `K^d` recovers an integer whose prime factors identify each `(t,w_t)`; the position labels recover the order. The zero target returns the zero matrix. So one exact full-matrix query identifies the target and distinguishes zero.

With the first `nd` primes, each prime has `O(log(nd))` bits. The query dimension is `d+1`, with `n(d+1)²` dense input slots and `O(nd log(nd))` nonzero rational payload bits. The exact response has `(d+1)²` scalar entries and one nonzero rational with `O(d log(nd))` numerator/denominator bits. A sieve, exact multiplication, and division by the known prime table decode `w` in polynomial time. If the exact service counts dense scalar slots, the exact cost is `1` call, `d+1` query dimension, `Θ(nd²)` input slots, and `Θ(d²)` returned slots; the bit costs above are polynomial. No uncharged real-valued encoding is used.

## N25 lower bound reconstructed

Fix one admissible query tuple `X=(X_1,…,X_n)∈R^{D×D}` with `Σ_i X_iᵀX_i⪯E I`. For every vector `v`,

`Σ_{u∈[n]^k} ||X_{u_1}…X_{u_k}v||² ≤ E^k ||v||²`.

For `k=1`, this is exactly the excitation condition. For the induction step, sum first over the leftmost letter: for every fixed tail vector `z`, `Σ_i||X_i z||²≤E||z||²`, then apply the `k`-letter bound to the remaining tail. Summing over the `D` standard basis vectors gives

`Σ_{w∈[n]^d} ||X_{w_1}…X_{w_d}||_F² ≤ D E^d`.  (1)

Now consider any adaptive algorithm. Under zero, its query tuple and dimension at round `t` are functions of its past transcript and private randomness. Conditional on that history, the two response laws at a fixed `w` are Gaussians with common covariance `σ² I` and mean difference `X_{w_1}…X_{w_d}`. Their conditional KL divergence in the direction `P_0` to `P_w` is exactly `||X_{w_1}…X_{w_d}||_F²/(2σ²)`. The adaptive chain rule and (1) therefore imply

`(1/n^d) Σ_w KL(P_0 || P_w) ≤ E_0[Σ_t D_t] E^d/(2σ² n^d) = C E^d/(2σ² n^d)`.  (2)

Let `P̄=(1/n^d)Σ_w P_w`. Convexity of relative entropy in its second argument gives `KL(P_0||P̄)≤(1/n^d)Σ_w KL(P_0||P_w)`. If event `A` means “the test says nonzero,” the type-I and worst-case type-II guarantees imply `P_0(A)≤δ` and `P̄(A)≥1−δ`. Data processing to the binary event yields

`KL(P_0||P̄) ≥ kl(P_0(A),P̄(A)) ≥ kl(δ,1−δ)=kl(1−δ,δ)`.

Combining with (2) proves

`C ≥ 2σ² (n/E)^d kl(1−δ,δ)`.

The proof permits adaptive query choice and variable dimensions: adaptivity cancels from the conditional query kernel in the KL chain rule, and (1) holds for every realized tuple. If the algorithm can stop at a random time, apply the argument to a finite truncation and pass to the limit under finite expected cost. Since `D_t²≥D_t`, the same lower bound holds for expected returned scalar-entry count. If query dimensions are also capped by `D_max`, it implies an expected call lower bound `C/D_max`; without a dimension cap, the theorem is a total dimension/entry lower bound, not by itself a call-count lower bound.

For fixed `σ>0`, `E=1`, and fixed `δ<1/2`, this is `Ω(n^d)` total dimension/entries. The one-query exact construction above has only `Θ(d²)` returned entries at the same excitation cap. The information-bearing exact rational can be decoded because exact arithmetic resolves differences that Gaussian noise obscures. This comparison is consistent with (1): under a uniform hidden word, the average squared signal of any one admissible query is at most `D E^d/n^d`.

## Bridge gate and finite precision

A usable exact-to-noisy bridge needs a response-separation condition. One elementary sufficient statement is:

Let a deterministic exact learner make at most `Q` adaptive queries of matrix dimension at most `D` against a finite target class. After every exact transcript, let `M` be the set of oracle response matrices possible among targets still consistent with that transcript. Suppose distinct elements of every such `M` are separated in Frobenius norm by at least `Δ>0`. Repeating each query `s=O(σ²Δ^{-2}(D²+log(Q/δ)))` times and taking its matrix average allows nearest-response decoding. A Gaussian chi-square tail and union bound give exact transcript simulation with failure at most `δ`. This costs `O(QsD)` total query dimension, `O(QsD²)` returned scalar entries, and multiplies each query's excitation by `s`; finite-precision output additionally needs rounding error below `Δ/4` and enough bits for the dynamic range.

This is only a finite-class bridge. L01's source card supplies no uniform positive `Δ`, lower singular-value bound, or query-excitation bound for the full real/characteristic-zero target class. Even bounded rational coefficient height would need to be stated together with input-entry heights, degree/truncation, intermediate pivot margins, output range, and arithmetic runtime. In the prime encoding, exact responses can be separated by at least `K^{-d}` but this margin is exponentially small in `d log(nd)`; a generic repeated-query simulation can consequently cost exponentially many noisy observations. The bridge theorem does not erase N25.

## Prior-art attack

The broad phrase “exactly learning weighted automata” is old. Bergadano–Varricchio's field-valued learning work and the Balle–Mohri survey use membership queries on words together with equivalence queries that either certify the whole target or return counterexamples. The survey's reconstruction builds a basis of a finite Hankel block; it bounds iterations by rank and membership calls by alphabet size, rank squared, and longest counterexample length. These are strong exact-learning precedents, but their equivalence oracle is much stronger than L01's matrix evaluation oracle and they do not model Gaussian full-matrix responses with excitation charges.

Noisy or approximate weighted-automaton learning is also established. Balle–Mohri's constrained Hankel completion/spectral approach learns general real WFAs from iid string-value samples under distribution-dependent generalization and regularization assumptions. Hsu–Kakade–Zhang and subsequent spectral work use sampled Hankel blocks and rank/conditioning structure. Weiss–Goldberg–Yahav's 2019 probabilistic deterministic-automaton extraction uses local tolerance and conditional-probability membership queries, but still uses equivalence/counterexample feedback; it is not an iid Gaussian matrix oracle. Ferreira–Batz–Silva's 2026 SMT learner is active and semiring-parametric, but gives minimality on termination and sufficient termination conditions, not this real Gaussian/excitation guarantee. These precedents block any broad novelty claim for exact, noisy, or active weighted-automaton learning, while leaving the precise N25 oracle comparison distinct.

The closest information-theoretic methodological precedent found is Kacham–Woodruff (NeurIPS 2023) on adaptive Gaussian linear sensing for low-rank matrix recovery. It already uses adaptive-sensing lower bounds and Gaussian observations, so N25's use of a KL hard prior is not by itself a novelty basis. Its target, loss, and measurement model differ: arbitrary low-rank matrix recovery from linear functionals versus a hidden degree-`d` noncommutative monomial from constrained full-matrix evaluations. The N25 card's exact bound should be described as a structured interface obstruction until the original proof and a priority search specifically for this monomial/excitation theorem are checked.

The strongest source-side novelty correction is internal to L01: the card states that release 116 plus routine truncation/unrolling already yields polynomial cyclic capability at larger `O(nm⁵)` dimension. Any novelty argument should therefore compare the compact query/dimension tradeoff and its exact cost accounting against that baseline, not claim first polynomial cyclic learnability.

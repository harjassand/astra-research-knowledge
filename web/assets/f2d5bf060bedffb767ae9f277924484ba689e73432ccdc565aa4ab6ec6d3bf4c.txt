UNIVERSAL CONSTANT TWO AT THE QUBIT ENTROPY HESSIAN
Separate theorem; prior freezes unchanged.
Status: exact internally reconstructed local theorem. Not a global J>=2E proof.

1. Statement and physical interface

Let sigma>0 be any qubit density and Phi any full-domain CPTP map fixing sigma
whose Heisenberg adjoint is KMS self-adjoint. No positive weighted spectrum,
EB, compatibility, primitivity, or modular covariance is assumed. Put
 T=Gamma_sigma^(-1/2) Phi Gamma_sigma^(1/2), L=I−T,
 J(rho)=Tr[(rho−Phi(rho))(log(rho)−log(sigma))],
 E(rho)=Tr[sqrt(rho) L(sqrt(rho))].
For every Hermitian h perpendicular to sqrt(sigma), use the physical state
rho_e=sigma+e Gamma_sigma^(1/2)(h). Then
 lim_{e->0} [J(rho_e)−2E(rho_e)]/e^2 >=0.
Equivalently, with R and M defined in the baseline,
 (LM+ML)/2 >= 2RLR on the Hermitian trace-tangent subspace.
This also holds for every finite KMS qubit Markov generator, by applying the
channel statement to exp(tG) and dividing the quadratic forms by t as t->0.

2. All legal KMS qubit channels admit the following Kraus reduction

Diagonalize sigma=diag(1,q^2)/(1+q^2), relabel so q>=1. T is a CP map and
self-adjoint in ordinary Hilbert-Schmidt inner product. Any Kraus family A_j
for T can be replaced by Hermitian Kraus operators: average T and T*, then
write A_j=H_j+iK_j with H_j,K_j Hermitian. The average channel has Kraus H_j,K_j
because (A_j X A_j^*+A_j^* X A_j)/2=H_j X H_j+K_j X K_j. Hence write
 T(X)=sum_j H_j X H_j, H_j=[[a_j,z_j],[conj(z_j),b_j]], a_j,b_j real.

Ignore the harmless normalization of sqrt(sigma); stationarity is exactly
sum_j H_j diag(1,q) H_j=diag(1,q). Let
 x=sum_j |z_j|^2, A=sum a_j^2, B=sum b_j^2, f=sum a_j b_j,
 c=sum a_j z_j, k=sum z_j^2, Z=1+q^2, S=q+q^(-1).
The stationarity constraints are
 A=1−qx, B=1−x/q, sum_j(a_j+q b_j)z_j=0,
 0<=x<=1/q, |k|<=x, |f|<=sqrt(AB).
These are CP/stationarity constraints for actual quantum channels, not an
arbitrary ordered Markov-operator surrogate.

Use the orthonormal Hermitian trace-tangent basis consisting of
 d=diag(q,−1)/sqrt(Z),
 s1=[[0,1],[1,0]]/sqrt(2), s2=[[0,i],[−i,0]]/sqrt(2).
In this basis the genuine L takes block form
 L = [[delta,beta^T],[beta,N]],
 delta=x S,
 ||beta||^2=2Z |c|^2/q^2,
 eigenvalues(N)=1−f plus/minus |k|.
The sign convention for the second component of beta is immaterial.
In particular N >= (1−f−x)I. When q>1 and x>0,
1−f−x >= (S/2−1)x>0, so N is strictly positive.

3. The sharpened CP cross-coupling bound

For q>1,x>0 put W=||a+q b||^2=Z−2qx+2qf>0.
The complex vector z is perpendicular to the real vector a+q b. Orthogonal
projection and Cauchy-Schwarz give
 |c|^2 <= x [A−(A+qf)^2/W] = x q^2(AB−f^2)/W.
Consequently
 ||beta||^2 <= 2Zx(AB−f^2)/W.

Put r=sqrt(q)/(q+1). The following exact polynomial identity proves a bound
stronger than generic positivity of L:
 2W(1−f−x)−(q+1)^2(AB−f^2)
   = q(S−2)[(1−f)^2+(S+2)x−x^2] >=0.
All terms on the right are nonnegative: S>=2 and 0<=x<=1/q<=1. Therefore
 ||beta||^2 <= 4r^2 delta (1−f−x),
 beta^T N^(-1) beta <= 4r^2 delta.
This is the load-bearing CP lemma. Plain L>=0 would give only the larger
right side delta and would not suffice for the proof below.

If x=0 then z=0 and beta=0, so the cross bound is immediate without an inverse.
If q=1 the reference is tracial and R=I/2,M=I, so the desired C2 Hessian
defect is simply L/2>=0; the nontracial proof is unnecessary.

4. Universal scalar inequality and Schur complement

On the chosen basis R=diag(1/2,r,r), M=diag(1,b,b), where
 b=2q log(q)/(q^2−1), 4r^2<=b<=1, 0<r<=1/2.
The lower bound is the logarithmic-mean inequality from the classification
addendum; the upper bound follows from b=(log q)/sinh(log q)<=1.
Set a=(1+b)/2−r. Then the C2 Hessian defect is
 D2 = [[delta/2,a beta^T],[a beta,(b−2r^2)N]].
The scalar inequality
 b−2r^2 >= 8r^2 a^2
holds throughout the above interval. To see this put
 F(b)=b−2r^2−2r^2(1+b−2r)^2,
a concave function of b. At both endpoints it is nonnegative:
 F(4r^2)=2r^2[1−(1+4r^2−2r)^2]>=0,
 since 3/4<=1+4r^2−2r<=1;
 F(1)=(1−2r)[1+2r(1−r)(1−2r)]>=0.
Concavity now gives F(b)>=0 on [4r^2,1].

For q>1,x>0, the lower-right block of D2 is positive. Its Schur complement
is nonnegative because
 a^2 beta^T[(b−2r^2)N]^(-1)beta
   <= a^2 4r^2 delta/(b−2r^2) <= delta/2.
Thus D2>=0. The x=0 and q=1 cases were handled above. This proves the theorem.

5. What this does and does not establish

The strong constant4 qubit baseline is compatible with this theorem: its
Hessian ratio is slightly below4 and still above2. No finite numerical scan
or optimizer is used. The reduction spans ALL KMS qubit CPTP maps, including
negative weighted spectrum. It furnishes a precise next obligation: a
global nonlinear qubit proof would have to control the entropy/root
derivatives away from sigma, where the fixed R,M multipliers above no longer
describe the state. The theorem neither implies general-dimensional C2 nor
complete C2 with arbitrary ancillary reference, since those create several
distinct nonzero modular frequencies. The latter obstruction to this proof
is structural, not evidence that the global inequality fails.

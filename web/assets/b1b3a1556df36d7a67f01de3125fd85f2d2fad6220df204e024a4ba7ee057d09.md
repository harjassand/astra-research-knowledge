# Cycle 2: dyadic cycle signing for bipartite perfect-matching marginals

Artifacts: [claim ledger](CYCLE2_CLAIMS.json), [exact sampler wrapper](cycle2_bipartite_sampler.py), [finite smoke checks](cycle2_smoke.py), and [primary source ledger](CYCLE2_SOURCES.md).

## Result and interface

For a finite bipartite graph (G=(L\sqcup R,E)) with (|L|=|R|=n\ge1), take a rational feasible perfect-matching marginal (x\in\mathbb Q_{ge0}^{E}): every listed actual edge is labelled, (x_e\in[0,1]), and every vertex has incident marginal sum one. Let (A\in\mathbb Q^{d\times E}) be a supplied feature matrix whose actual-edge columns obey (\|A_e\|_2\le1). Fix an integer level (T\ge0).

The construction below is an exact rational sampler. Given a deterministic rational signing routine with the guarantee of Li, arXiv:2609.30044v1, it returns one actual perfect matching (M), with

\[
\mathbb E\,\mathbf1_M=x
\]

exactly. For the sampled path (P), let (U_t(P)) be the integer cycle scale defined below at dyadic level (t\). Every path satisfies

\[
\|A(\mathbf1_M-x)\|_\infty
\le |E|2^{-T}+99\sum_{t=1}^T2^{-t}U_t(P),
\]

so the unconditional all-atom guarantee is

\[
\boxed{\quad
\|A(\mathbf1_M-x)\|_\infty
\le |E|2^{-T}+99\max_{P}\sum_{t=1}^T2^{-t}U_t(P).
\quad}
\]

Because (\|A_e\|_2\le1), (U_t\le|E|), giving the simpler but graph-size-dependent bound ( |E|2^{-T}+99|E|\). There is no graph-independent constant from this argument unless cycle feature norms are uniformly bounded. If U_0 is an integer and every active cycle in every path has (\|A\delta_C\|_2\le U_0), then the bound improves to ( |E|2^{-T}+99U_0\), since (\sum_{t=1}^T2^{-t}<1\).

The implementation wrapper is [cycle2_bipartite_sampler.py](cycle2_bipartite_sampler.py). It implements exact input checks, the residual b-matching cycle rounder, Eulerian odd-edge cycle decomposition, dyadic coarsening, exact scale computation, output verification, and the rational sampler interface. Its `signer` callback must be Li's deterministic signing algorithm; that source theorem is a reported algorithmic primitive, not code embedded in this wrapper.

## Initial residual b-matching cycle rounder

Put (b=2^T) and (q_e=bx_e\). Let (\ell_e=\lfloor q_e\rfloor), (r_e=q_e-\ell_e\in[0,1)\). Since (x) has degree one at every vertex,

\[
\sum_{e\ni v}r_e=b-\sum_{e\ni v}\ell_e\in\mathbb Z
\quad(v\in L\sqcup R).
\]

Maintain (r\) and the floor vector (\ell\). At a state, let (F=\{e:0<r_e<1\}\). For any vertex, the sum of the fractional (r_e)'s incident to it is an integer after subtracting its incident (0/1) residual edges. Thus a vertex cannot have exactly one incident edge of (F\): its sole fractional value would have to be an integer. Every nonisolated vertex in the fractional-support graph has degree at least two, so if (F\ne\varnothing), that graph contains a cycle. Since it is bipartite, the cycle has even length.

Choose a deterministic simple even cycle (C=(e_1,\ldots,e_{2k})) in (F), and set (\delta_C(e_j)=(-1)^{j+1}\) on its edges, zero elsewhere. At each vertex on (C), one incident cycle edge has sign (+1) and the other has sign (-1), so (r+t\delta_C) preserves every residual degree. Let ([t_-,t_+]) be the exact interval that keeps each cycle coordinate in ([0,1]). Every selected edge is fractional, so (t_-<0<t_+\). Choose (t_-) with probability (t_+/(t_+-t_-)) and (t_+) with probability (-t_-/(t_+-t_-)). This makes (\mathbb E[t\mid r]=0\), keeps all coordinates feasible, and makes at least one fractional edge integral. Repeat until (r\in\{0,1\}^E\), then set

\[
y_T=\ell+r\in\mathbb Z_{ge0}^{E}.
\]

There are at most (|E|) cycle moves. The resulting integer b-matching has degree (b), satisfies (y_{T,e}\in\{\lfloor bx_e\rfloor,\lceil bx_e\rceil\}\), and has exact mean (\mathbb E y_T=bx\). Thus, for every initial-rounding outcome,

\[
\|A(y_T/2^T-x)\|_\infty
\le\sum_e|y_{T,e}/2^T-x_e|\,\|A_e\|_\infty
\le |E|2^{-T}.
\]

Every move is on actual fractional support edges. If (x_e=0\), that edge remains absent throughout. If (x_e=1\), then (y_{t,e}=2^t\) at every dyadic level and it is never altered by odd-edge coarsening.

## Odd-numerator cycle coarsening

Suppose (y_t\in\mathbb Z_{ge0}^{E}\) has degree (2^t\) at each vertex, for (t\ge1\). Its odd-edge graph is

\[
H_t=(L\sqcup R,\{e:y_{t,e}\text{ is odd}\}).
\]

At each vertex, the sum of the incident edge multiplicities is even. Modulo two, this says the number of incident odd edges is even; therefore (H_t\) is Eulerian. Decompose its edges deterministically into edge-disjoint simple cycles (C_1,\ldots,C_s\). Every such cycle is even because (H_t\) is bipartite. On each cycle choose an alternating vector (\delta_C\in\{-1,0,1\}^{E}\), with one (+1) and one (-1) at each cycle vertex, and form the rational feature vector

\[
w_C=A\delta_C.
\]

Let (U_t=\lceil\max_C\|w_C\|_2\rceil\). Compute this ceiling exactly: for rational (q=\max_C\sum_j(w_C)_j^2\), take the least integer (u\ge0\) with (u^2\ge q\), using integer square root and exact comparisons. If there are no cycles, set (U_t=0\) and halve (y_t\). If cycles exist and (U_t=0\), every (w_C=0\); use any fixed sign vector, e.g. all (+1\). Otherwise the columns (w_C/U_t\) have Euclidean norm at most one, so call Li's deterministic rational signing algorithm to obtain (s_C\in\{-1,+1\}) with

\[
\left\|\sum_C s_Cw_C\right\|_\infty<99U_t.
\]

Now draw one exact fair sign (\eta\in\{-1,+1\}) and define

\[
y_{t-1}=\frac{y_t+\eta\sum_Cs_C\delta_C}{2}.
\]

Both choices of (\eta\) are feasible. Every odd edge belongs to exactly one cycle and changes by (+1\) or (-1\), so its numerator becomes an even nonnegative integer: an odd nonnegative integer is at least one. Every even edge is unchanged before division. Each cycle direction has zero degree change at every vertex, hence the numerator still has degree (2^t\); after division, (y_{t-1}\) is an integer nonnegative b-matching of degree (2^{t-1}\). This proves feasibility at both signs without invoking an optimization oracle.

Conditioned on (y_t\), the signing (s\) is fixed and the fair antipodal sign has mean zero. Therefore

\[
\mathbb E[y_{t-1}\mid y_t]=y_t/2,
\qquad
\mathbb E[y_{t-1}/2^{t-1}\mid y_t]=y_t/2^t.
\]

The per-level normalized feature increment is

\[
A(y_{t-1}/2^{t-1}-y_t/2^t)
=2^{-t}\eta\sum_Cs_Cw_C,
\]

whose infinity norm is at most (99\,2^{-t}U_t\) on both branches. Starting from the initial residual sampler and iterating (t=T,T-1,\ldots,1\) gives a degree-one nonnegative integer vector, hence an actual perfect matching. Repeated conditional expectation gives (\mathbb E\mathbf1_M=x\); the triangle inequality gives the boxed pathwise bound.

## Sharp lower bound on graph-independent feature control

A graph-independent all-atom constant is impossible for arbitrary unit-norm actual-edge features. On the even cycle C_{2k}, there are exactly two perfect matchings M_+={e_1,e_3,...,e_{2k-1}} and M_-={e_2,e_4,...,e_{2k}}. Set x_e=1/2 on all 2k actual edges and scalar feature coefficient A_{e_j}=(-1)^{j+1}, so every column has norm one. Then Ax=0, while A 1_{M_+}=k and A 1_{M_-}=-k. Since these are the only perfect matchings and x gives each edge marginal 1/2, any exact-marginal law must assign probability 1/2 to each; both support atoms have discrepancy k. The sole active cycle has ||A delta_C||_2=2k. Thus cycle-norm dependence is necessary for this feature interface, not just an artifact of the proof.

## Bound, oracles, precision, and runtime

The bound depends on the *actual-edge feature sums around the active cycles*. In general,

\[
U_t\le\left\lceil\max_C\sum_{e\in C}\|A_e\|_2\right\rceil\le |E|.
\]

This only yields (O(|E|)\) all-atom discrepancy. The use of Komlós signing does not by itself give a constant bound: its columns here are cycle sums (A\delta_C\), whose norms may grow with the cycle length. A graph-independent constant follows from this proof only under an added uniform bound on these cycle sums (or a stronger theorem/argument controlling them).

No optimization or separation oracle is called. For a supplied bipartite graph, exact feasibility of (x\) is checked by nonnegativity and the vertex degree equations; those conditions characterize its perfect-matching polytope. The sampler finds cycles by deterministic graph search and does not solve a maximum-weight matching problem. All columns, cycle sums, norms, probabilities, endpoint comparisons, and output checks are rational/integer operations. (U_t) is computed without floating-point square roots.

Let (m=|E|\), (d=\dim(A)\), (L_x) be the total bit length of (x\), and (L_A) that of (A\). The initial cycle phase makes at most (m) cycle moves. A common denominator (Q\) for all (x_e\) has (O(L_x)\) bits; every residual coordinate remains a multiple of (1/Q\), so each endpoint probability has (O(L_x)\)-bit numerator and denominator. Cycle finding and exact updates therefore take polynomial bit time (a conservative implementation bound is (O(m(m+|V|)\,\mathrm{poly}(L_x+T))\)). Exact rejection from fair bits samples each rational endpoint coin with expected (O(L_x)\) bits, hence expected (O(mL_x)\) initial random bits.

At each of (T\) dyadic levels there are at most (m\) cycles. Their rational columns (w_C/U_t\) have bit length polynomial in (m,L_A\). Li's source theorem gives a deterministic signing algorithm with polynomial bit complexity for rational input; invoking it once per level therefore costs (T\cdot\mathrm{poly}(m,d,L_A)\) bit time. The only additional random choice at each coarsening level is one exact fair bit. Total expected random bits are (O(mL_x+T)\). To request initial residual at most (\rho>0\), choose (T\) with (2^T\ge m/\rho\); this can be selected by exact integer comparisons. The resulting cycle term is not improved merely by increasing (T\).

The routine outputs one matching with (n\) actual edge IDs and an exact rational feature-error certificate. It is a sampler whose transition probabilities are exact rationals. Its sample space can be exponential (at most (2^{m+T}\) paths from the stated binary decisions), so this does not enumerate the entire law.

## Explicit support versus sampler

Since the sampler is finite, its exact marginal (x\) is a convex combination of finitely many *safe* matching atoms, all obeying the same all-path bound. Carathéodory therefore implies that some law on at most (|E|+1\) of those safe matchings also has mean (x\). Because (x\) and matching incidence vectors are rational, the weights of such a basic feasible representation can be chosen rational; determinant bounds give polynomial bit length in (|E|\) and (L_x\). This is an existence statement only.

The implementation does not obtain this sparse law in polynomial time. Naively expanding all endpoint/sign branches may take (2^{|E|+T}\) paths before linear-dependence compression. Compression would preserve feature safety if it only retained or reweighted existing safe atoms, but finding the compressed atoms and weights from the implicit sampler is not implemented or costed polynomially. Accordingly, the delivered algorithm's output contract is the exact sampler, not an explicit support list.

## Primary prior-art and source boundary

- Li, *Fast Spectral Signing for Vector Balancing*, arXiv:2609.30044v1, Theorem 1.1: deterministic rational-input signing with infinity discrepancy (<99\), polynomial bit complexity. [Pinned primary version](https://arxiv.org/abs/2609.30044v1). Theorem 1.1 reports O(c^2 log c) updates, O(dc+c^(omega+2) log^3 c) arithmetic/comparison operations for fixed attainable omega>2, and polynomial bit complexity on rational input. This supplies the cycle-signing subroutine; it does not bound the norms of (A\delta_C\) or make them graph-independent.
- Gandhi, Khuller, Parthasarathy, Srinivasan, *Dependent Rounding and its Applications to Approximation Algorithms*, JACM 53(3), 2006: primary precedent for marginal-preserving dependent rounding on bipartite graph edge variables. [Author PDF](https://www.cs.umd.edu/~srin/PDF/2006/depround-jou.pdf), [DOI](https://doi.org/10.1145/1147954.1147956). The residual cycle argument here is proved for the exact floor/ceiling (b)-matching interface above; the citation is context, not a transfer of a theorem about hard features.
- OpenAI, *Entropy and Face Dimension of the Perfect-Matching Polytope*, pinned commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`, supplies the related perfect-matching face geometry but does not imply this sampler. [Pinned paper](https://github.com/openai/math/blob/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/Entropy-and-Face-Dimension-of-the-Perfect-Matching-Polytope-September-23-2026/main.pdf).

Li's constant, bit model, and exact implementation claim are source-reported and not independently reviewed here. The wrapper was exercised on C_4, C_6, and C_10, using the valid single-column signer +1 on the normalized cycle column. For both choices of the antipodal orientation coin it returned the two alternating perfect matchings with exact errors +k and -k, respectively, and a path certificate larger than those errors. This finite check validates only cycle bookkeeping and output/path certificates, not Li's algorithm or the general proof.

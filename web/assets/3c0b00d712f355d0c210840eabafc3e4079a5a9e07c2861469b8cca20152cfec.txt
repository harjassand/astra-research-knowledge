1. Uniform torsion barrier bound

Let phi(x)=sqrt((R^2-x^2)_+). The exact full operator satisfies Lambda phi=1 inside Omega. For x>=0 put
 D_x(r)=2phi(x)-phi(x+r)-phi(x-r),
 I_e(x)=(1/pi)int_0^e D_x(r)/r^2 dr,
 so Lambda_e phi=1-I_e.

If x<=sqrt(3)R/2, D_x(r)>=0 for every r: inside both edges this is concavity; when only one shifted point remains in Omega its value is <=R<=2phi(x); outside both it is immediate.

If x>sqrt(3)R/2, the only interval where D_x can be negative is (r1,r2), where
 r1=x-sqrt(4x^2-3R^2), r2=x+sqrt(4x^2-3R^2).
It is nonnegative before r1 and after r2. Thus a negative minimum of I_e, if any, could occur only at r2. But nonnegativity of phi gives
 Lambda_{r2}phi(x)<=2phi(x)/(pi r2)<=2/(pi sqrt(3))<1,
 since phi(x)<=R/2 and r2>=sqrt(3)R/2.
Therefore I_{r2}>0, and I_e>=0 for every e. Reflection gives the other half interval. In particular
 Lambda_e phi<=1 uniformly in e and x in Omega.

This supplies the same positive subsolution barrier a(t)phi for the bounded jump approximations if q initially dominates it and the scalar/reaction coefficients have uniform finite-time bounds. 2. Uniform mass-tangent coercivity

It converges locally uniformly to |xi| and satisfies

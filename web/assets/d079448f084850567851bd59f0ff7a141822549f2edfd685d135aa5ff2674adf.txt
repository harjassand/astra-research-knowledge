STRONGEST CLAIM AND EXACT ADMITTED INTERFACE

For every finite two-layer catalytic network of the following form, with every
displayed rate a fixed positive rational, a global rational norm-like Foster
function and explicit recovery core can be acquired by O(d+m) rational
arithmetic operations from the actual input rates. No supplied equilibrium,
Poisson stationary law, class membership oracle, deterministic absorber,
compact collar, real-field QE or unbounded coefficient enumeration is used.

There are nonempty root species R_i and disjoint child species Y_j. Each root
has reactions 0 -> R_i and R_i -> 0 with rates b_i and delta_i. Each child has
a nonempty set P_j of root parents; for each i in P_j there are reactions
  R_i -> R_i + Y_j,     R_i + Y_j -> R_i
with rates alpha_ij and beta_ij. There are no other reactions. Children never
act as catalysts. Root counts are denoted r_i and child counts y_j. This is
an actual binary stochastic mass-action model; its intensities are b_i,
delta_i r_i, alpha_ij r_i and beta_ij r_i y_j, respectively. Disabled
reactions have zero intensity at the integer boundary. No monomial/factorial
approximation is made. Every reaction has its reverse, hence the network is
weakly reversible and in particular endotactic.

The process is nonexplosive, irreducible on the entire lattice N^(r+s), and
positive recurrent. The certificate proves a physical-time drift at every
integer state, including all zero-catalyst faces. It gives an explicit
finite set K and E_x tau_K <= V(x) from every x outside K. It also gives
  E_x V(X_t) <= exp(-lambda t)V(x)
                 + (C/lambda)(1-exp(-lambda t)),
and its unique stationary law has E_pi V <= C/lambda. These bounds are for
this exactly recognized class. They do not settle arbitrary rational binary
weakly reversible recurrence or acquire a generic CRN Foster certificate.

CONSTRUCTED RATIONAL DATA

For each child j, set
  S_j = sum_{i in P_j} r_i,
  B_j = sum_{i in P_j} b_i,
  D_j = max_{i in P_j} delta_i,
  beta_j = min_{i in P_j} beta_ij,
  c_j = min(1, beta_j/D_j),
  gamma_j = min(c_j B_j/2, beta_j/2),
  g_j(S) = 1 + c_j/(S+1).
All c_j and gamma_j are positive. For each root choose
  w_i = [1 + sum_{j:i in P_j}(1+c_j)alpha_ij]/delta_i.
Define
  V(r,y) = sum_i w_i r_i + sum_j g_j(S_j)y_j,
  C = sum_i w_i b_i,
  lambda = min({1/w_i}_i union {gamma_j/(1+c_j)}_j),
  gamma_0 = min(1, min_j gamma_j).
If there are no children, omit the child sets and put gamma_0=1. Thus
  a_0 N <= V <= a_1 N,
where N=sum_i r_i+sum_j y_j, a_0=min({w_i}_i union {1})>0 and
a_1=max({w_i}_i union {1+c_j}_j). V is nonnegative, zero only at zero,
and norm-like. If a strictly positive Foster function is preferred use 1+V.

FULL DRIFT DERIVATION

Roots evolve autonomously: catalytic reactions leave each r_i unchanged.
Fix j and abbreviate S=S_j, c=c_j. A root immigration in P_j increases S
by one and changes g by
  -c/[(S+1)(S+2)].
For S>=1, each root death decreases S by one and changes g by
  c/[S(S+1)].
For S=0 there are no root deaths; the second term must be omitted. Therefore
  L_root g_j(S)
    = -c_j B_j/[(S+1)(S+2)]
        + 1_{S>=1} c_j [sum_{i in P_j}delta_i r_i]/[S(S+1)].
This identity is the decisive exact boundary correction. The expression
c_j D_j/(S+1) is an upper bound for the positive term only when S>=1;
it is not inserted at S=0.

Write the child's birth and per-particle death rates as
  h_j(r)=sum_i alpha_ij r_i,
  a_j(r)=sum_i beta_ij r_i.
Because changing a child does not change g_j, its contribution to LV is
  g_j h_j + y_j[L_root g_j - a_j g_j].
At S=0, h_j=a_j=0 and the bracket equals exactly -c_j B_j/2. At S>=1,
  L_root g_j - a_j g_j
    <= c_j D_j/(S+1) - beta_j S
    <= beta_j/(S+1) - beta_j S
    <= -beta_j/2.
The first inequality discards two nonpositive terms, the second uses
c_j D_j<=beta_j, and the last is valid for every integer S>=1.
Consequently, globally on the actual integer lattice,
  L_root g_j - a_j g_j <= -gamma_j.
Also g_j h_j <= (1+c_j)sum_i alpha_ij r_i. Summing all root and child
contributions gives
  LV <= sum_i w_i b_i
          + sum_i[-w_i delta_i
                   + sum_{j:i in P_j}(1+c_j)alpha_ij]r_i
          - sum_j gamma_j y_j
     = C - sum_i r_i - sum_j gamma_j y_j
     <= C - lambda V.                                      (F)
The final inequality uses lambda w_i<=1 and
lambda g_j<=lambda(1+c_j)<=gamma_j. There is no state sampling or asymptotic
drift remainder in this proof.

NONEXPLOSION AND IRREDUCIBILITY, WITHOUT A HIDDEN RECURRENCE PREMISE

The total molecule count N has positive changes only through root immigration
and catalytic births. Let b=sum_i b_i and A=max_i sum_j alpha_ij (A=0 if
there are no catalytic channels). Then
  LN <= b + A N.
All jumps change one count by one, and the total intensity is finite at
each state. Stopping at N>=M, Dynkin/Grönwall bounds the probability of
reaching M by a finite time by a quantity tending to zero as M->infinity.
For example use 1+N and LN<=max(b,A)(1+N), giving
  P_x(tau_M<=t) <= exp(max(b,A)t)(1+N(x))/(1+M).
Explosion within any finite set is impossible because its rates are bounded.
This proves nonexplosion in physical time independently of (F). It is a
special case of the familiar linear nonexplosion criterion, rather than a
new general regularity theorem.

For any two lattice states, first make every root positive using its direct
immigration. Adjust every child to its requested destination count using
one chosen parent, which stays positive. Then adjust each root to its
requested destination count. Every step has positive finite intensity, and
there is a finite positive-probability path following the selected reactions.
Hence the entire lattice is one irreducible communicating class. In
particular, no unidentified nonlinear component invariant is being erased.

EFFECTIVE RECOVERY AND STATIONARY CONSEQUENCES

Let R=max(1,ceil[(C+1)/gamma_0]) and K={x:N(x)<R}. From (F), outside K,
  LV <= C-gamma_0 N <= -1.
For tau_K stopped also on a finite box, Dynkin gives
  E_x(tau_K wedge t wedge tau_box) <= V(x).
Use nonexplosion, Fatou and then monotone convergence to obtain
E_x tau_K<=V(x). The standard Foster criterion for an irreducible countable
CTMC gives positive recurrence. Alternatively the following moment bound
provides tight Cesàro laws and thus an invariant probability, which with
irreducibility/nonexplosion implies positive recurrence.

Apply stopped Dynkin to exp(lambda t)V(X_t). Its drift is at most
C exp(lambda t) by (F). Fatou upon removing the finite-box stop gives the
displayed moment bound at every finite t. Cesàro laws are tight because
V>=a_0 N. On a countable state space, take a convergent subsequence; for
each fixed s, the Cesàro measure differs from its image under P_s by total
variation at most 2s/T. This proves invariance of the limit (bounded test
functions can be approximated uniformly on the common tight core). Fatou
then gives E_pi V<=C/lambda.

There is a computable exponential return-time variant. Put W=1+V and
choose a finite core K_e outside which
W>=2(C+lambda)/lambda. Then
  LW<=-(lambda/2)W outside K_e.
Stopped Dynkin for exp[(lambda/2)(t wedge tau_Ke)]W gives
  E_x exp[(lambda/2)tau_Ke] <= W(x) for x outside K_e.
One can take K_e to be a molecule-count threshold since W>=1+a_0 N.
This is an exponential moment of a physical-time return, not of the stationary
count vector and not an assertion that exp(theta V) is itself a Lyapunov
function. Minorization/mixing constants have not been acquired in this
INITIAL snapshot.

NON-COMPLEX-BALANCED EXAMPLE AND EXECUTED EVIDENCE

Take roots A,C with both direct immigration and death rates 1, and child B:
  A <-> A+B with forward/reverse rates 1,1;
  C <-> B+C with forward/reverse rates 2,1.
At the leaf complex A+B, complex balance would require c_B=1. At the leaf
B+C it would require c_B=2. Thus no positive complex-balanced equilibrium
exists. This is not merely the familiar Poisson product-form subclass.
The reaction graph has 5 complexes, one linkage, rank 3, deficiency 1.
The constructed certificate is c_B=1, gamma_B=1/2,
  w_A=3, w_C=5, C=8, lambda=1/5,
  V=3A+5C+[1+1/(A+C+1)]B.
At A=C=0, LV=8-B, so the boundary is recovered with actual negative drift.
The formula's conservative chosen return core is N<18.

RETAINED FAILED SHORTCUTS

1. Any positive linear function of molecule counts fails to be a strict
Foster function on the zero-root face with arbitrary children: child events
are disabled, while root immigration gives a strictly positive constant
drift. The reciprocal term is load-bearing, not cosmetic.

2. Exponentiating the constructed V is false in general. For the simple
network 0<->A, A<->A+B with every rate 1, the construction gives
V=3A+[1+1/(A+1)]B. At (A,B)=(1,n), the four jump increments are
-3+n/2, 3-n/6, 3/2, -3/2, with intensities 1,1,1,n.
For every theta>0 the first exponential grows in n faster than the negative
term n(exp(-3theta/2)-1), so L exp(theta V)/exp(theta V)>0 eventually.
At n=60 and theta=2 log 2, the ratio is the exact positive rational
295147905179352047617/16384. The script checks this witness exactly. An
exponential-return estimate from LW<=-eta W is valid; a naive stationary-
exponential-count estimate from exp(theta V) is not.

3. Children acting as catalysts fall outside this synthesis: root autonomy
used in L_root g_j fails. Arbitrary extra reactions can also destroy (F).
No extension to a catalytic feedback cycle is inferred from a finite test.

4. The N76 residual-factorial inequality is not assumed to imply negative
drift, and its reaction-event upward bound is not used as a physical-time
nonexplosion theorem. The reciprocal corrector closes that drift gap only
for the explicit class above. N77's classwise escaping laws remain intact;
our entire lattice is actually proved irreducible, so its tightness is a
component conclusion, not a transfer across unidentified components.

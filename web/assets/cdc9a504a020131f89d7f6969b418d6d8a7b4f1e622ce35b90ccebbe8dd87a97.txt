STRONGEST CONSERVATIVE PRECISE STATEMENT
Fix ε,β in (0,1/10). For all sufficiently large integers k (threshold depends only on ε,β), and uniformly for all integers 2≤Q≤k^β, there exists a prime-power cyclic group Z/NZ and a map C:Z/NZ→Z/QZ such that
  N ≥ k^(ε k/(320Q)),
  every nonzero-step cyclic k-AP contains at least
    t = ceil(k^(1−ε)/(4(Q−1)))
  positions of EACH one of the Q colours.
All k terms are distinct: N=q^D with q a power of a prime P>k.
The same statement holds on an ordinary interval of length N by restriction.

FRESH HIGHER CONSEQUENCE
For 0<s<1 take Q=floor((log k)^s), once Q≥2. Then
  log N ≥ (ε/320) k (log k)^(1−s),
so N^(1/k)→∞, while Z/NZ partitions into Q disjoint t-fold hitting sets for all k-APs. The smallest colour class S obeys
  |S|≤N/Q and |S∩A|≥t for every k-AP A.
Thus |S|/N→0; its complement has density ≥1−1/Q and misses ≥t points of every k-AP. Every deletion/recolouring set E satisfying |E∩A|≤t−1 for every A preserves the ENTIRE Q-colour palette on each A. Equivalently every near-full subset A\E, |E|≤t−1, remains Q-polychromatic.
This is substantially stronger than merely avoiding monochromatic APs or transferring the previous binary theorem via digit products.

FINITE GENERAL REPAIR THEOREM AND PROOF
See GENERAL_Q_REPAIR.txt. Let V finite, P a family of ordered k-tuples of distinct elements, outer c0:V→Z/Q, and key map κ:V→K, each key occurring at most twice per tuple. Suppose every tuple either is rich (at least γk positions of EACH outer colour) or has a literal (outer colour, ACTUAL key) signature among at most T words. For 0<p<1/4, a=p/(Q−1)≤γ and 1−p≥a, if
  Q|P|(2sqrt(p))^(γk/2) + QT exp(−ak/16) <1,
there is a final colouring having ≥ak/4 positions of each colour on every tuple.
Draw independent E_K: Pr(E_K=0)=1−p; each nonzero shift has probability p/(Q−1). Set C(v)=c0(v)+E_κ(v) mod Q.
Rich case: for target b select ONE initial-b representative per key. There are s≥γk/2; retained target indicators are independent Bernoulli(1−p). Fewer than ak/4 total b positions implies fewer than s/2 retained reps, forcing ≥s/2 nonzero key shifts. Subset union bound gives 2^s p^(s/2)≤(2sqrt(p))^(γk/2).
Structured case: select ONE position per key, s≥k/2. Independent final-target indicators each have probability ≥a, so their count dominates Bin(s,a). Chernoff lower-tail below ak/4≤as/2 is ≤exp(−as/8)≤exp(−ak/16). Literal signatures impose the SAME events on the SAME random variables. Union bounds suffice; no independence between APs is asserted.
The representative-only rich entropy is important: the older coarse 2^k bound would obstruct growing Q. This bound is supported by a direct proof, not an unjustified reduction of the event family.

Q-OUTER INPUT AND DERIVATION
Source parameter choice D=ceil(k^(.1)), M=ceil(k^(.5)), H=k^(−2), h0=D², primary-factor λ, adaptive cutoff α=q^(−D−1) persists, but choose c=ε/(320Q) in q≥k^(ck/D).
Colour each full label independently uniformly in Z/Q. Test every first-family light-label row and every eligible local pattern. For l distinct label variables, probability that any colour occurs <l/(2Q) is ≤Q exp(−l/(8Q)). Choose local-lemma weight z_E=exp(−l(E)/(32Q)).
Source global literal word entropy is log Tglob=O(D³ log k)=O(k^(.3)log k). First-family total incident weight is at most kTglob exp(−(δM−1)/(32Q))=o(1/Q), uniformly for Q≤k^β with β<.1 (β<.2 would suffice here).
For each fixed label, source anchored local count gives second-family incident weight bounded by sum_{h>D²}(CDh)^(6D) exp(−h/(64Q)). Since QlogD=o(D) for Q≤k^β,β<.1, this is o(1/Q). Incident weight ≤1/(500Q) eventually. Neighbour product lower bound is exp[−(1/32+2/500)l/Q], which dominates Qexp[−l/(8Q)] because l/Q≫logQ in both event families. The finite asymmetric local lemma therefore balances every test with ≥1/(2Q) of each colour.
Source geometric dichotomy is independent of palette values: ≥δk light positions give ≥δk/(2Q)=k/(20Q) of each colour. Otherwise a heavy label supplies a closest rational return. Short periods force a global affine lift; long periods have eligible heavy blocks covering ≥4k/5 and each contributing ≥h/(4Q) of each colour, hence ≥k/(5Q). Therefore every AP is either Q-rich with γ=1/(20Q), or globally affine.
The key remains the actual second-system box plus floor(||q y||²). Source Lemma6.1 puts same-box points on a real affine line and proves pairwise scaled separation≥1. The HALF-OPEN band [m,m+1) has intersection length≤1 on each half-line and an excluded outer endpoint, so it contains at most one 1-separated point per half-line; key multiplicity sharpens from source four to two. The closed-band variant fails at t=−1,0,1.
Source Lemma6.2 counts affine signatures retaining actual box and band identities. Changing binary c0 to the FIXED Q-valued label map adds no entropy: each literal label word determines all outer colours. Thus
  log Taff ≤ C k^(.3)log k +6logq+O(log k)
           ≤ C k^(.3)log k + O((ε/Q) k^(.9)log k)+O(log k),
with absolute constants uniform over Q in the stated range.

FAILURES AND LIMITS
- Ordinary Q-colour van der Waerden avoidance does NOT imply every AP sees every colour. Binary digit products preserve nonmonochromaticity but do not produce all colour tuples.
- Deterministic band residue floor(||qy||²) mod Q can be constant on a genuine AP: choose d≡λ^(−1)Q q^(D−1) mod q^D, q>2kQ. Its centered y_j=(0,...,0,jQ/q), so bands j²Q² are all0 mod Q. Sparse modular shifts are needed in this route.
- Arbitrary lists depend on vertices and can destroy literal signature entropy; no general list-choosability theorem obtained.
- N^(1/k)→∞ in this coefficient tradeoff requires Q=o(log k), despite validity of the colouring statement for Q up to k^β.
- No explicit useful threshold, efficient acquisition algorithm, or locally practical runtime. Finite exhaustive assignment exists but huge label/key spaces and LLL search must be charged. No Lean formalization of this Q-robust theorem.

FOLLOW-ON EXACT TRANSVERSAL LP CONSEQUENCE
Let H be the cyclic k-AP hypergraph on N vertices, t as above, τ_t(H) the smallest subset meeting every edge in≥t points, and τ_t^*(H) its fractional version with 0≤x_v≤1. Averaging all ordered cyclic APs proves τ_t^*=tN/k exactly: every vertex lies in k(N−1) ordered APs, so summing all constraints gives total weight≥tN/k; the uniform assignment x_v=t/k attains it.   τ_t/τ_t^* ≤ k/(Qt) ≤ 4((Q−1)/Q) k^ε.

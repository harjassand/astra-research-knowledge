# Acquired compression: rank alone does not make measurement discovery cheap

## Result

I found a clean obstruction to a universal claim that a low-dimensional task-sufficient representation can be acquired cheaply from measurements. Even granting the learner a known r-dimensional input subspace, an unknown output factor \(B\in\mathbb R^{p\times r}\) must be identified well enough to answer all post-storage bilinear tasks. A finite-bit adaptive sensing transcript needs
\[
mb\ge (1-\delta)r\max(p,q)\log_2\!\frac{1}{32\sqrt r\,\epsilon}-h_2(\delta)
\]
for a bounded rank-r family, when each of m answers has at most b bits and \(\epsilon\le1/(64\sqrt r)\). For exact-real deterministic measurements, fewer than pr scalar queries cannot provide uniform accuracy \(\epsilon<R/2\) on the p≥q chart. The proof and constants are in PROOF.md.

An engineering reading is a rank-r sensor or instrument transfer map: after calibration, users can choose an excitation direction x and a readout direction a. The reason is that task sufficiency depends on this future task class. When users may probe every bilinear form \(a^TAx\), the unknown factor is itself observable. The representation can be compact after acquisition, but rank does not erase the factor's metric entropy.

## Strongest equally informed baseline

For the hard family \(A_B=BV^T\), an informed raw-data baseline directly queries the pr entries \(B_{ij}\), rather than paying for all pq matrix entries. It stores their quantized table, which already answers every future task. At precision mesh \(\epsilon/\sqrt{pr}\), this takes \(pr\lceil\log_2(4\sqrt{pr}/\epsilon)\rceil\) response bits, pr scalar queries, \(O(pr)\) acquisition-side quantization work, and \(O(pr+qr)\) arithmetic per task. The lower bound applies to every sensing and encoding algorithm with the same oracle, so it also covers the strongest raw-data learner. When \(\epsilon\le1/(1024\sqrt{pr})\), this coordinate raw-data control matches the lower bound to constant factors in total response bits. The same Fano argument also lower-bounds any finite retained state by the same leading number of bits. The fair comparison therefore leaves no universal acquisition, storage-rate, or sample advantage for a learned factor representation; any benefit must come from a narrower task law or an explicit storage/compute constraint.

## Source and novelty boundary

The interface is a post-storage query problem with adaptive scalar linear measurements and finite-bit responses. It is distinct from full-matrix reconstruction, but adjacent low-rank recovery results already study linear matrix measurements. Xu defines \(b_j=\langle A_j,Q\rangle\) and proves generic exact recovery thresholds for complex matrices, with a separate qualified real result; see [arXiv:1505.07204, setup and Theorems 2.1/3.1](https://arxiv.org/abs/1505.07204). Kacham and Woodruff's [NeurIPS 2023 paper](https://proceedings.neurips.cc/paper_files/paper/e258bb98cc032ab6ae9053db453431f7-Paper-Conference.pdf) assumes independent Gaussian query noise and proves a round lower bound for adaptive relative-Frobenius recovery (Theorem 1.1). These are prior-art boundaries, not validations of the task-specific theorem here. The Astra pinned route also includes N25 on a noisy adaptive matrix-query excitation barrier and a spliced-teacher failure; that source package is source-derived/unreviewed and should not be treated as external proof.
Two nearby positive memory results in that same route, N36 and N66, store one observation under a known Gaussian or calibrated product sensor model and answer one coordinate-specific query selected after storage. Their cards give scoped memory upper/lower laws; they do not establish acquisition of an unknown matrix basis. All Astra card claims remain source-derived/unreviewed.

Sufficient-dimension-reduction methods such as inverse regression already estimate predictive subspaces under explicit conditions; the JMLR treatment of subspace estimation lists their linearity and coverage limitations and recommends collecting additional data when methods disagree ([Dalalyan, Juditsky & Spokoiny 2008, pp. 1–2](https://www.jmlr.org/papers/volume9/dalalyan08a/dalalyan08a.pdf)). The present obstruction does not supersede those methods or rule out positive results under their assumptions.

No novelty or external-review claim is made. The lower bound is a reconstructed packing argument; the exact-real count bound is a local nullspace argument. Prior art already covers adjacent adaptive matrix sensing, so the result should be used as a model-scope gate rather than advertised as a new general matrix-sensing theorem.

## Costs, limits, and next gate

The lower bound counts only measurement-response bits and calls. It grants arbitrary computation, omits query-description bits, and permits an ideal linear measurement oracle; these omissions favor the compressor. The known frame V is supplied for free to both algorithms; measuring, calibrating, or storing it would add costs. The raw baseline uses an agreed coordinate-query schedule, or pays \(O(pr\log(pr))\) address bits if the schedule is not pre-agreed. The matching upper bound has no measurement noise; noisy sensing needs repeated measurements and an explicit SNR/energy ledger. The finite-bit lower remains valid under independent noise because every response still has a finite alphabet.

The next useful search is a restricted-task positive theorem: specify a low-entropy distribution over post-storage tasks, a measurable feature/margin gap, and a raw-data learner that receives the same measurement transcript. Without one of those restrictions, this line is a principled rejection of a universal compression advantage.

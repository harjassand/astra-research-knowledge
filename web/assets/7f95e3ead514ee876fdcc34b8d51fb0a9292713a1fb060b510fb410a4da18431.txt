Exact scaling calculation (all powers are exact integers/rationals)
===================================================================

Equation and Leray projection
-----------------------------
∂t u − νΔu + P div(u⊗u) = P f,     div u=0.

Standard parabolic rescaling
---------------------------
Set uλ(x,t)=λu(λx,λ²t), pλ(x,t)=λ²p(λx,λ²t), fλ(x,t)=λ³f(λx,λ²t).

Term multipliers:
  ∂t uλ:       λ·λ² = λ³
  (uλ·∇)uλ:   λ·λ² = λ³
  νΔuλ:        ν·λ·λ² = λ³
  ∇pλ:         λ²·λ = λ³
  fλ:          λ³

For x'=λx and t'=λ²t, dx=λ⁻³dx' and dt=λ⁻²dt'. Therefore:
  ||uλ(t)||₂² = λ² λ⁻³ ||u(t')||₂² = λ⁻¹||u(t')||₂².

Since ∇uλ=λ²(∇u)(x',t'),
  ν∫||∇uλ||₂²dt = ν λ⁴ λ⁻³ λ⁻² ∫||∇u||₂²dt'
                    = λ⁻¹ ν∫||∇u||₂²dt'.

Since fλuλ has multiplier λ⁴,
  ∫∫ fλ·uλ dxdt = λ⁴ λ⁻³ λ⁻² ∫∫f·u dx'dt' = λ⁻¹∫∫f·u.

Thus the energy identity remains homogeneous: kinetic energy, dissipation, and force work all have exponent −1. The force term is not removed by this rescaling.

Mixed forcing norms
-------------------
For 1≤p,q≤∞,
  ||fλ||_(L_t^q L_x^p)
    = λ³ λ^(−3/p) λ^(−2/q) ||f||_(L_t^q L_x^p)
    = λ^(3−3/p−2/q)||f||_(L_t^q L_x^p).
The critical line is 3/p+2/q=3. Example p=q=2 gives exponent 3−3/2−1=1/2. Example q=1,p=2 gives exponent 3−3/2−2=−1/2. Which norm is useful depends on an estimate; smooth compact support alone supplies no uniform smallness in a critical norm.

Local blowup zoom
-----------------
At spatial scale r, set u^(r)=r u(x*+rx,t*+r²t). Chain rule gives forcing f^(r)=r³f(x*+rx,t*+r²t). If |f|≤M on the compact neighborhood, then |f^(r)|≤Mr³→0. This is only a local limit statement; it does not identify a global Cauchy datum.

Energy / Duhamel
----------------
For u(0)=0:
  (1/2)||u(t)||₂² + ν∫₀ᵗ||∇u||₂²ds = ∫₀ᵗ⟨Pf,u⟩ds.
If Pf=0 for all s, then u=0. Mild form:
  u(t)=−∫₀ᵗe^(ν(t−s)Δ)P div(u⊗u)(s)ds
       +∫₀ᵗe^(ν(t−s)Δ)Pf(s)ds.
The second integral is the only term that can initiate motion from rest; deleting it yields the zero solution in the smooth energy class.

Paper viscosity scaling (ν=1 to ν>0)
-------------------------------------
Let y=x/√ν and define uν=√νu(y,t), pν=νp(y,t), fν=√νf(y,t). Then
  ∂t uν, (uν·∇x)uν, νΔx uν, ∇x pν, fν
all equal √ν times the corresponding ν=1 terms.
Also dx=ν^(3/2)dy, so ||uν||₂²=ν·ν^(3/2)||u||₂²=ν^(5/2)||u||₂².
Further, ∇x uν=∇y u, so ν∫||∇x uν||₂²dt=ν·ν^(3/2)∫||∇y u||₂²dt=ν^(5/2)∫||∇y u||₂²dt.

C01_S03 -- DIRECTED-INTEGER SCALAR ACQUISITION FOR POSTERIOR CERTIFICATES
Separate performance repair after a declared30second conservative Fraction
Taylor check timed out. Earlier code/proofs and the failure are retained.
This routine acquires true exp(-x) intervals; no Gibbs optimizer is added.

Let x>=0 rational, desired B>=1. If x0, return[1,1]. If x>=B+2, e>2 gives
exp(-x)<2^(-B-2), so[0,2^(-B-2)] is a legal nonnegative interval of width
<=2^-B. Otherwise halve exactly to y=x/2^s<=1/16. Here s=O(log(B+2));
all rational arguments have polynomial binary input length. Set

 P=B+2s+2 bitlength(B+2s+16)+24, D=2^P, K=P+1.

Starting with term interval[D,D], use exact integer floor/ceiling at every
positive recurrence term_n=term_(n-1)*y/n, and add these enclosures through
degree K. Every true positive Taylor term and its partial sum is inside the
scaled integer interval by induction. Bound the first omitted term by an
outward upper recurrence. All later true-term ratios are<=y<=1/16, so add
ceil((16/15)*first_upper) to the scaled upper sum; the lower sum omits the
positive tail. This encloses exp(y) with no alternating-series ambiguity.

Both sums are>=D. Directed reciprocal bounds are
floor(D^2/upper_sum), ceil(D^2/lower_sum), enclosing exp(-y) at scale D.
The reciprocal upper endpoint may be capped at D, since exp(-y)<=1.
At each of s steps square the nonnegative interval with directed floor/
ceiling at scale D, again capping its upper endpoint at D. Monotonicity and
exact integer rounding enclose exp(-2^s y)=exp(-x) throughout.

For completeness, uniform polynomial precision follows as well as containment.
Let the scaled exact term be t_n. Each recurrence endpoint error satisfies
err_n<err_(n-1)/16+1, hence err_n<16/15. Each retained term interval width
is<32/15<3. The exact omitted term after K=P+1 has scaled size at most
D16^(-P-2)<1, so its outward first-upper term is<1+16/15 and is an integer
<=2; the added geometric-tail upper is<=3. Thus the exponential sum interval
width is<=3(P+1)+3. Reciprocation at a true value>=1 is1-Lipschitz on
real values, and its two directed endpoint roundings add<=2 scaled units.
The initial reciprocal width is therefore<=3P+8. During squaring the exact
upper/lower endpoint sum is<=2, so scaled width W obeys W_next<=2W+2.
Consequently its final width is<=2^s(3P+10)/D. The chosen P has
P-B-s=s+2bitlength(B+2s+16)+24, far exceeding log2(3P+10), so this is
<=2^-B. Explicitly u=B+2s+16>=17, bitlength(u)<=u/2, hence
P=u+2bitlength(u)+8<=3u and3P+10<=10u. On the other hand
2^(P-B-s)>=2^24 u^2>10u. The implementation verifies the width inequality before
returning. This verification does not substitute for the containment proof.

There are O(P+s)=O(B+logB) operations on integers of polynomial bit length
in B and input bits(x). No Taylor degree depends on a huge numerical x,
and no positive lower endpoint is required for tiny clipped exponentials.
This alternate kernel can therefore supply the same posterior scalar
interface as the conservative routine, with its actual costs separately
recorded. The old routine remains unchanged; generic compiler mathematics,
quantum output format, tested Gibbs domain and imported optimizer status are
unaffected. Independent target/candidate normalization and physical sector
TV algebra still require their previously proved positive-denominator guards.

THEOREM AND INPUT

Input is explicit F in Q(i)^(n x n), total binary length L, a physical pair
sector 0<=k<=floor(n/2), and arbitrary forced-in/forced-out occupation bits
of the n up and n down modes. Hard projection excludes double occupancy
but permits holes. F may be nonsymmetric, complex, singular, and arbitrarily
ill-conditioned. Its off-diagonal support graph has edge {i,j} iff F_ij or
F_ji is nonzero. Diagonal entries do not affect any hard-sector minor.

For a site ordering pi, let B_i be the unprocessed sites incident to at
least one of the first i processed sites. Put v=max_i |B_i|. Then an exact
algorithm computes ALL prefix-restricted c_k(F) using
 O(n^2(v+1)16^(v+1)) rational-complex operations,
 O(n16^(v+1)) stored rational-complex coefficients,
 and polynomial O(n(L+log n)) coefficient encoding length.
The explicit program is frontier_hard_bcs.py. Every execution is bounded.
Width is charged; v=O(log n) gives polynomial bit time. This is a narrower
exact compiler, not a general parity counting algorithm or a stability claim.

The ordering can also be acquired. For any FIXED integer q>=1, exhaustive
balanced-separator search of size <=q yields a checked ordering with
 v<=q*(floor(log_2 n)+1), when it succeeds. It succeeds on EVERY graph with
treewidth <=q-1, with no supplied tree decomposition. A conservative search
bound is O(n^(q+3)) support-graph operations. Taking an input ordering first
when its frontier already obeys the same cap avoids unnecessary searches.
The compiler may accept larger-treewidth graphs by an actual width certificate.
Failure is UNKNOWN_ADMISSION, not a hardness result or exact treewidth lower
bound. Exact minimum-width recognition is not claimed or used.

1. FINITE NONUNITARY FOCK PRODUCT

Use site-ordered fermion modes (u_0,d_0,u_1,d_1,...). The unnormalized paired
state is
 exp(sum_(i,j) F_ij u_i^dagger d_j^dagger)|vac>.
All pair-creation monomials commute: disjoint quadratic creation monomials
exchange four fermion operators, giving sign +1; monomials sharing a mode
have both products zero. Each square is zero. Thus the exponential is exactly
 product_(i,j) (I+F_ij u_i^dagger d_j^dagger)|vac>,       (1)
in any order, with no Trotter approximation. A diagonal pair creates double
occupancy which no other creation monomial removes, so every term using
F_ii is killed by the final hard projector. Deleting the diagonal is exact.

For each undirected support edge {i,j}, use its one or two directed pair
gates. Process all gates incident to site pi_i and an unprocessed neighbor
before finalizing pi_i. No remaining gate touches that site afterward.
Every gate is an EVEN operator. In a Jordan-Wigner split into completed
sites and remaining sites, each individual creation operator carries the
completed parity string, but the two strings in a pair gate cancel. Thus
the gate acts as identity on the completed tensor factor times the native
Fock gate on the remaining modes. Partial traces of completed sites commute
with every subsequent gate. No unknown outside parity register is discarded.

2. EXACT DENSITY RECURRENCE AND HOLE/CHARGE HANDLING

Maintain rho_q on the active unprocessed frontier, indexed by the total
number q of electrons already finalized. Initially rho_0=|vac><vac| and all
other coefficients vanish. Every new frontier site is appended in the vacuum;
inserting it at its ordered location embeds both Fock masks with two zero
bits, and causes no fermionic sign because those modes are empty.

Before site i is traced, the active sites are exactly {i} union B_i, so at
most v+1 sites. For each pair gate K=I+aC, the update is
 rho_q -> rho_q + a C rho_q + conjugate(a) rho_q C^*
                    + |a|^2 C rho_q C^*.             (2)
Here C=u_i^dagger d_j^dagger or u_j^dagger d_i^dagger. Its action on any
Fock mask has at most one target with sign determined by the occupied lower
bits. Equation (2) is implemented by four sparse coefficient updates, with
exact real/imaginary Fractions. It is a CP update; no eigenvalue truncation
or floating sign decision is made.

Let A_i subset {empty,up,down} be the local occupations compatible with the
requested physical prefix. Hard exclusion removes double. Finalization is
 rho'_q = sum_(s in A_i) <s|rho_(q-number(s))|s>.       (3)
In Fock masks, retain only entries whose ket/bra local two-bit occupations
coincide and belong to A_i, delete those two bits, and increase the charge
index by number(s). This is precisely the partial trace after the hard and
prefix projector. Empty s adds zero charge, so arbitrary holes are retained.
Every coefficient rho_q remains PSD. Although off-diagonal entries can be
signed or complex, their complete density coefficient is positive semidefinite.

Induction on sites proves that rho_q equals the partial trace of the EXACT
partially gated/projected pure state, with completed charge q. Previously
completed projectors commute with all remaining gates by their disjoint
support and even parity. Thus (2)-(3) preserve the invariant from vacuum
through all sites. At the end there is no active mode, and the scalar rho_2k
is exactly
 sum_(I intersect J empty, |I|=|J|=k, prefix compatible) |det F[I,J]|^2.
Odd final charges vanish because every creation term creates one up and one
down electron, and all prefix/hard projectors are diagonal. This proves every
canonical and prefix count, including exact zero, without a rare-event ratio.

3. COUNT AND BIT COSTS

With s<=v+1 active sites the Fock dimension is D_s=4^s; a density coefficient
has at most D_s^2=16^s entries. There are at most n+1 completed-charge values.
Each directed gate has a monomial matrix with at most one nonzero per column,
so (2) uses O(n16^(v+1)) field operations. An ordering of frontier v has at
most v unprocessed neighbors at each step and hence O(nv) directed pair
gates. Vacuum insertions and traces are bounded by the same coefficient count.
This gives O(n^2(v+1)16^(v+1)) time and O(n16^(v+1)) space in field operations.

For bits, let D clear all real/imaginary denominators, with log_2 D<=L,
and let M>=1 bound entry magnitudes with log M=O(L). At any partial stage,
the full pure amplitude is a restricted minor of the matrix of gates already
applied, with some completed diagonal projectors. Each amplitude has degree
<=n in F entries and denominator dividing D^n. A density coefficient is a sum
of at most 4^n products of two such amplitudes. Thus a common denominator
D^(2n) and numerator bound
 D^(2n) 4^n (n!)^2 M^(2n)
give O(n(L+log n)) bits. This also bounds prefix counts and their ratios.
Intermediates in the four additions/products have polynomially bounded
encodings. Rational arithmetic, gcd and rank/phase calculations therefore
have polynomial bit cost; an exponentially small nonzero determinant is not
an uncharged numerical precision assumption.

The use of dictionary sparsity in executed Python is an optimization. A dense
array indexed by q and both bounded Fock masks has fixed uniform loop caps
and the same conservative asymptotic bound; it supplies a reversible program
without an opaque classical oracle or an exponential prefix table.

4. ACQUIRED ORDERING / TREEWIDTH COVERAGE

At a recursion node with m vertices, enumerate every separator of size at
most q, compute the induced components after its deletion, and take the
first whose component sizes are <=m/2. Recurse on those components; put
the separator LAST. At a node with <=q vertices, order them directly.
Every accepted split comes with explicit vertex lists, components and sizes.
If a search fails, report the failed induced vertex set and stop admission.
One can verify the resulting permutation and its exact B_i lists in O(n^2)
graph operations. No balancing data for parity hole partitions is involved.

Accepted recursion depth is at most floor(log_2 n)+1 because nonleaf child
size at least halves. While processing a component, it has no edges to
other components at that level; all its external frontier lies in the ancestor
separators, each of size <=q. Its own live portion and later separator occupy
at most q more vertices. Hence v<=q*(floor(log_2 n)+1).

Why every treewidth <=q-1 graph is admitted: take any width-(q-1) tree
decomposition only for this existence proof. Assign each of the m vertices
to one containing bag and give bags the resulting integer weights. A weighted
tree has a centroid bag whose deletion leaves each tree branch weight <=m/2.
That bag has <=q vertices. A graph vertex outside it occupies bags in a
single branch by connectedness of its bag set. Adjacent vertices outside
the bag share a bag, so each graph component after deletion lies entirely
inside one branch and has size <=m/2. Thus an enumerated balanced separator
exists. Every induced subgraph inherits the width bound by intersecting bags,
so ANY successful first split retains the guarantee on recursive children.
The algorithm itself never acquires or queries the assumed decomposition.

At most O(n) recursive nodes and O(n^q) candidate subsets per node, each
with an O(n^2) graph scan, give the conservative O(n^(q+3)) search bound.
For FIXED q, v<=q log_2 n+q gives count time
 O(n^(4q+2) q log n) rational operations,
apart from constants depending on q and polynomial bit arithmetic. This is
deliberately loose; it is not a practical exponent or an FPT-optimal treewidth
algorithm. If q grows, n^q and the frontier factor are charged and the stated
fixed-q polynomial conclusion no longer follows.

5. TOTAL CLASSICAL BORN SAMPLER

At each of the 2n occupation bits compute the two exact child counts Z0,Z1.
If the parent count is positive, at least one child is positive. The ideal
Bernoulli probability Z1/(Z0+Z1) telescopes to the exact canonical Born law.
For a reduced rational p=a/d, use t=ceil(log_2 d) fair bits to draw an integer
uniform on [0,2^t). Reject draws >=d and return bit 1 iff an accepted draw
is <a. Each attempt accepts with probability >=1/2; conditional on acceptance
it is an EXACT Bernoulli(p). Endpoints 0 and 1 are deterministic.

Cap each such rejection routine after r attempts, choosing
 2n 2^(-r)<=eps.
On cap failure, complete the present prefix deterministically by always
choosing a positive child, which the SAME exact counts identify. This fallback
always outputs a supported configuration. Coupling to the uncapped ideal sampler
shows TV<=eps by the union bound; no accepted-only conditioning is used.
Every execution has <=4n+1 count queries and <=2n*r*poly(n,L) fair bits.
Runtime is O(n^3(v+1)16^(v+1)) rational operations plus bounded coin arithmetic.
This sampler is implemented. Its probability guarantee assumes independent
uniformly fair getrandbits; seeded Python PRNG runs are execution diagnostics.

6. COHERENT CONSEQUENCE AND ITS IMPLEMENTATION BOUNDARY

Exact count programs can be made reversible using padded fixed-size histories
and polynomial-bit arithmetic. At each depth they compute Z0,Z1 in superposition
on the current prefix, implement the conditional two-amplitude rotation, and
uncompute the workspace. A zero parent gets a fixed fallback angle; no ideal
amplitude reaches it. A uniform absolute angle error <=eps/(8n) at every node
gives total unitary hybrid error <=eps/4 over 2n depths. Ratio precision of
O(log(n/eps)) additional bits, with the square-root sensitivity accounted for
by using O((eps/n)^2) probability error, suffices for all extreme ratios.
Exact rationals already have polynomial encoding. Standard bounded-bit interval
square-root and angle evaluation have polynomial cost; no minimum probability
promise is used.

For the final supported physical string, restore
 (-1)^(k(k-1)/2) det F[I,J]/|det F[I,J]|
using exact Gaussian-rational determinant arithmetic and bounded-bit phase
evaluation; give zero/invalid strings phase 1. Original site ordering and
canonical fermionic mode order are explicit. A further eps/4 phase budget
keeps pure-state trace error below eps after a conservative hybrid budget.
The resulting uniform circuit existence cost is
 n * O(n^2(v+1)16^(v+1)) * poly(n,L,log(n/eps)),
plus phase/gate synthesis. No Chen--Liu FPRAS or random compiler tape is needed
for this width-bounded class. This is an exact-count-to-amplitude construction,
with the old Grover--Rudolph mechanism credited. The reversible bit engine,
rotation/phase synthesis and actual quantum circuit are NOT implemented here.

SPECTRAL GEOMETRY CYCLE 2 — CONSTRUCTIVE UNIFORM NEAR-FULL UPPER
Date: 2026-10-08
Scope: a finite, explicit diagonal construction for Sym^N(C^m).

Set p=m-1, n=binom(N+p,p), and

  Lambda_{N,p}(k)=inf{ E(X): ||X||_HS=1, rank X<=n-k },
  E(X)=sum_a ||[T_a,X]||_HS^2,

with Tr_fund(T_a T_b)=delta_ab/2. This note supplies a rank-exactly-counted
upper witness in a uniform near-full range; it makes no lower-bound claim.

THEOREM (uniform hole-cluster taper upper bound)

For each fixed p>=1, let k be an integer and assume

  N>=max(4p,16),   1<=k<=floor(32^{-p} n).

Then, with eta_p=1-(3/4)^p, the unrestricted rank-constrained infimum obeys

  p=1:  Lambda_{N,1}(k) <= 12/[log(e n/k)],

  p>=2: Lambda_{N,p}(k) <= U_p (k/n)^((p-1)/p),

where one valid explicit constant is

  C_p=p^p/(p-1)!,   B_p=1+(p!)^(1/p),
  U_p=2(p-1) C_p B_p^(p-1) (p!)^(1/p)/eta_p.

In particular, the construction has exactly n-V_R nonzero diagonal entries
for a specified integer R with V_R>=k, so the rank inequality includes the
integer rounding without an asymptotic substitution. The constants are
deliberately loose and depend only on fixed m.

PROOF

Occupation basis states are indexed by beta in Z_+^p with |beta|<=N,
the first occupation being N-|beta|. Layer s=|beta| has

  g_s=binom(s+p-1,p-1)

states, and V_s=sum_{j=0}^s g_j=binom(s+p,p). For a radial diagonal
operator A with entry a_s on layer s, the exact root-edge sum is

  E(A)=sum_{s=0}^{N-1} w_s |a_{s+1}-a_s|^2,
  w_s=(N-s)(s+p)g_s=p(N-s)binom(s+p,p).                 (1)

Let R be the least integer with V_R>=k, and set M=floor(N/2). The range
above implies R<M and R+1<=N/4, as checked below. Define

  R_{R,M}=sum_{j=R}^{M-1} 1/w_j,
  a_s=1                                  (s<=R),
  a_s=(sum_{j=s}^{M-1}1/w_j)/R_{R,M}  (R<s<M),
  a_s=0                                  (s>=M).

Thus a_R=1 and a_M=0; the displayed values are the unique resistance-linear
profile between the two layers. Put X=I-A. Then X is zero on every state
with s<=R and strictly positive on every state with s>R. Consequently

  rank X=n-V_R<=n-k.                                      (2)

Because [T_a,I]=0, E(X)=E(A). Substitution into (1), or Cauchy–Schwarz
with increments proportional to 1/w_j, gives the exact identity

  E(X)=1/R_{R,M}.                                         (3)

For s>=M, X=1, so
  ||X||_HS^2 >= n-V_{M-1}.
If N>=4p, then
  V_{M-1}/n=binom(M-1+p,p)/binom(N+p,p)<=(3/4)^p,
and hence
  ||X||_HS^2>=eta_p n.                                    (4)

For s<M, use s+p<=p(s+1) and N-s<=N in (1) to get

  w_s<=C_p N(s+1)^p,
  R_{R,M} >= (C_p N)^(-1) sum_{q=R+1}^{M}q^(-p).          (5)

If p=1, minimality gives V_R=R+1=k. Since M+1>=N/2 and k<=n/32,
N/k>=30 for N>=16. Therefore

  sum_{q=k}^{M}1/q >= log((M+1)/k)
                     >= log(N/(2k)) >= (1/2)log(N/k).

Using C_1=1, (3)–(5) imply

  E(X)/||X||_HS^2 <= 8N/[n log(N/k)]
                    <= 12/log(e n/k).

For the last inequality, N/n<=1 and
log(e n/k)=log(N/k)+1+log(1+1/N); the hypotheses make
log(N/k)>=log 30.

Now let p>=2. If k=1, then R=0 and (6) below is immediate. If k>=2,
minimality gives V_{R-1}<k, while
V_{R-1}=binom(R-1+p,p)>=R^p/p!. Hence R<(p!k)^(1/p), and in either
case

  R+1<=B_p k^(1/p).                                      (6)

Also n<= (N+p)^p/p!, k<=32^{-p}n, and N>=p imply
R+1<(N+p)/32+1<=N/16+1<=N/4 for k>=2; for k=1 this follows from
R=0 and N>=16.
The sum in (5) satisfies

  sum_{q=R+1}^{M}q^(-p)
    >= integral_{R+1}^{M+1}x^(-p)dx
    >= [2(p-1)(R+1)^(p-1)]^(-1),

since M+1>=N/2 and R+1<=N/4. Combining (3)–(6),

  E(X)/||X||_HS^2
    <= 2(p-1) C_p N(R+1)^(p-1)/(eta_p n)
    <= 2(p-1) C_p B_p^(p-1) N k^((p-1)/p)/(eta_p n).

Finally n>=N^p/p!, so N n^(-1/p)<=(p!)^(1/p), yielding the stated U_p.
Normalize X by its Hilbert–Schmidt norm. This proves the theorem.

INTERPRETATION / LIMIT

The witness is a coherent-corner hole cluster with a harmonic taper, not a
hard complement projection. For p=1 it improves the hard one-hole
construction from constant energy to inverse-logarithmic energy. For p>=2
and growing k it avoids the factor k^(1/p) paid by the hard cluster
boundary. Combined with the arbitrary-kernel lower bound in
alternative_high_ceiling.txt, this matches the near-full-rank order for
fixed m in the stated uniform range. The leading constant for p>=2 is not
identified, and no claim of optimal hole orientation is made.

1. EXACT CONTRACT AND CLAIM

For each n, the supplied radius r is known, 0<r<=1/2, and

    c0 <= r sqrt(n) <= c1,

where 0<c0<=c1<infinity are fixed. The unknown parameter is the full
orientation v in S^2. The input is rho_(r,v)^{tensor n}, with
rho_(r,v)=(I+r v.sigma)/2, and the output must reconstruct the whole n-qubit
density matrix. Error is the worst-case half trace distance. The classical
protocol may use an arbitrary/infinite outcome alphabet and arbitrary
sector-changing preparations; it has no retained quantum information or
entangled reference. Equivalently, the archive channel is any
entanglement-breaking CPTP map on the input family.

For all sufficiently large n in this critical window there are constants
c,C>0 depending only on c0,c1 such that

    c r <= inf_EB sup_v (1/2)||EB(rho_(r,v)^{tensor n})
                                  -rho_(r,v)^{tensor n}||_1 <= C r.

The upper is explicitly 2r/(1+r), hence the optimum EB error is
Theta_(c0,c1)(r)=Theta_(c0,c1)(n^(-1/2)). The lower holds for arbitrary
measure-and-prepare channels, with no sector-preservation premise. It is a
classical reconstruction floor; it is not a lower bound on all hybrid
memories with nontrivial quantum registers.

2. EXACT SCHUR REDUCTION

Under the Schur transform,

    rho_(r,v)^{tensor n} = direct_sum_L P_L tau_(L,v) tensor I_(m_L)/m_L,

where L=n mod 2,...,n, j=L/2, q=(1-r)/(1+r),

    tau_(L,v)=q^(j-J_v)/Z_L(q),   Z_L(q)=sum_(s=0)^L q^s,
    P_L=m_L ((1-r^2)/4)^((n-L)/2) ((1+r)/2)^L Z_L(q),
    m_L=binom(n,(n-L)/2)-binom(n,(n-L)/2-1).

The multiplicity state is independent of v. Discarding it and regenerating
I/m_L are exact channels on this family. Composing an arbitrary original EB
archive with these channels gives an EB archive of the reduced direct-sum
spin experiment, and trace distance contracts. Thus it suffices to prove the
lower on R_v=direct_sum_L P_L tau_(L,v); this reduction does not give away a
free sector label.

3. BOUNDED POSTERIOR-SCORE LOWER

Let mu be normalized Haar measure on S^2. For L>0 define

    R_L=Tr(tau_(L,z) J_z),   a_L=R_L/(j+1),   V_L=J/j,   b_L=R_L/j,

and set a_0=b_0=V_0=0. The orbit covariance identity is

    int v_i tau_(L,v) dmu(v)
      = R_L J_i / ((2j+1)j(j+1)),
    int tau_(L,v)dmu(v)=I/(2j+1).

Indeed the first integral transforms as a vector operator, hence is a scalar
multiple of J_i; pairing with J_i uses int v_i^2=1/3 and
Tr(J_i^2)=(2j+1)j(j+1)/3. For any positive POVM effect M in sector L,
conditioning the Haar prior on its outcome gives posterior mean

    m = R_L/[j(j+1)] * Tr(M J)/Tr(M).

The factor 2j+1 cancels between the first-harmonic integral and the Haar
outcome likelihood Tr(M)/(2j+1). For every unit u, -jI<=u.J<=jI, so
||Tr(M J)/Tr(M)||_2<=j and ||m||_2<=a_L. This normalization is essential.

For every output sector K>0 use the block score

    F_(K,v)=a_K (v.J_K/j_K) - (a_K^2/2) I,

and put F_(0,v)=0. Let A=max_K a_K<=1. The common spectrum interval is
[-A-A^2/2,A-A^2/2]. Therefore

    E_v=[F_v+(A+A^2/2)I]/(2A)

is a valid effect on the entire output direct sum. This score remains valid
for arbitrary output coherences because F_v is block diagonal.

Write an arbitrary EB channel as a POVM followed by prepared states. For an
input sector L/outcome y, the posterior direction has mean norm at most a_L.
For the prepared output block K, its normalized vector
w=Tr(sigma_(y,K) J_K)/(j_K Tr sigma_(y,K)) has norm at most 1. Hence the
conditional mean score of the input-L/output-K pair is bounded by

    a_K m.w-a_K^2/2 <= a_K a_L-a_K^2/2
                         =a_L^2/2-(a_K-a_L)^2/2 <= a_L^2/2.

No output-sector marginal is assumed; sum over all K and outcomes is with the
input marginal P_L. The target's score in its own sector is

    a_L b_L-a_L^2/2,
    b_L=a_L(1+1/j),

so the Haar-average target-minus-decoder score is at least
    sum_(L>0) P_L a_L^2/j = 2 sum_(L>0) P_L a_L^2/L.
An effect changes its expectation by at most half trace distance. Dividing
the score by 2A therefore gives the exact finite bound

    e_EB >= [sum_(L>0) P_L a_L^2/L]/A
         >= sum_(L>0) P_L a_L^2/L.                       (3.1)

Here the last inequality uses A<=1. Worst-case error dominates Haar-average
error. The completed square, rather than a coupling or an output-marginal
estimate, absorbs every L-to-K sector transition.

4. UNIFORM MASS ON A BOUNDED CRITICAL SPIN WINDOW

For q=(1-r)/(1+r), tau_(L,z) has a truncated-geometric occupation number
s=j-m with

    E s = q/(1-q) - (L+1)q^(L+1)/(1-q^(L+1))
        <= q/(1-q)=(1-r)/(2r).

If L>=2/r, j>=1/r and
R_L=j-E s >= j-(1-r)/(2r) >= (j+1)/2, hence a_L>=1/2. The weaker
a_L>=1/3 also follows and is enough below.

Let M=sum_i sigma_z^(i) in the measured input. The joint spectral inequality
L>=|M| is exact. Put c=r sqrt(n). The normalized binomial variable M/sqrt(n)
has mean c, variance 1-r^2, and a Berry--Esseen error O(n^(-1/2)) uniformly
for c in [c0,c1] (the summands are bounded and r tends to zero uniformly).
For the fixed threshold T=2/c0+1, the normal right-tail probability is
uniformly bounded below by

    alpha_raw = 1-Phi(T-c0)>0.

For sufficiently large n, P(M/sqrt(n)>=T)>=alpha0:=alpha_raw/2. Since
c>=c0, this event implies M>=2/r and therefore L>=ceil(2/r).

The exact Casimir identity is

    E[L(L+2)]=3n+n(n-1)r^2,
    E[L^2]=3n+n(n-1)r^2-2E[L] <= 3n+n(n-1)r^2.

Writing kappa=nr^2<=c1^2, Markov gives

    P(L>B/r) <= (3 kappa+kappa^2)/B^2
              <= (3c1^2+c1^4)/B^2.

Choose a fixed B>=4 so the last expression is at most alpha0/2. Then

    P(ceil(2/r)<=L<=B/r)>=alpha0/2.

On this interval a_L>=1/3 and 1/L>=r/B. Substitution in (3.1) yields

    e_EB >= alpha0 r/(18B).

Using the stronger a_L>=1/2 improves this displayed constant to alpha0/(8B),
but no optimization of constants is claimed. This proves the uniform critical
lower with no logarithm. The proof needs c0>0; it does not cover a sequence
r sqrt(n)->0 with no positive lower endpoint.

5. MATCHING CLASSICAL ACHIEVABILITY AND MEMORY ACCOUNTING

On each spin sector, the spin-coherent measure-and-prepare channel

    B_L(X)=(L+1) int <L,u|X|L,u> |L,u><L,u| dmu(u)

obeys B_L(tau_(L,v))>=q tau_(L,v) by covariance and its diagonal beta
integral. Consequently its half trace error is <=1-q=2r/(1+r), uniformly
in n,v. Regenerate maximally mixed multiplicities and invert Schur to obtain
a full-state EB reconstruction. Caratheodory in the real Hermitian Choi space
replaces each continuous coherent POVM by at most (L+1)^4+1 outcomes without
changing the channel. The total alphabet is O(n^5), i.e. O(log n) retained
bits; the construction/measurement synthesis cost and finite-bit description
of the convex decomposition are separate and not established here.

At accuracies epsilon<1/4, a distinct exact quantum Schur cutoff keeps each
V_L block for L<=J_epsilon and replaces only the tail by a symbol, where
J_epsilon=min(n,ceil(nr+2 sqrt(n log(A0/epsilon)))) for a sufficiently large
fixed A0(c0,c1). The discarded mass is <=epsilon; every direct-sum branch
label is charged, giving D=1+sum_(L<=J, parity)(L+1)=O(min{n^2,n[1+log(1/epsilon)]}). This provides a whole-density CPTP archive. At
epsilon=n^(-1), D=O(n log n), so the conditional epsilon^(-3/2) Gaussian law
cannot be extrapolated to all accuracies. Its inherited regime requires
epsilon sqrt(n)->infinity; no contradiction to that conditional statement is
claimed.

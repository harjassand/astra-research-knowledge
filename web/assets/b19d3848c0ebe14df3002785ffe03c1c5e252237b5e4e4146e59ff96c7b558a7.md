# Cycle 3: hidden-type controlled lineages, passive CLE aliases, and assay identifiability

Linked prior work: [cycle-one lineage counterexample](FINAL_REPORT.md), [cycle-two sharp offspring bounds](CYCLE2.md), and [cycle-two claim ledger](CYCLE2_CLAIMS.json). This cycle does not revise those files.

## Verdict

There are two different identifiability questions.

1. **Passive fields do not identify controlled laws.** I give two hidden-type branching models with exactly the same passive aggregate birth-death generator, hence the same passive CLE drift and covariance at every state, but opposite action rankings for clone-level safe regeneration.
2. **A finite lineage assay can rank actions only after the endpoint semantics are anchored.** With unrestricted, unknown terminal-label emissions, I construct two worlds with the same complete observed lineage-tree law under every adaptive action policy and opposite true safe-regeneration rankings. Their total-variation distance is exactly zero, so no increase in lineage count and no HMM fit can distinguish the true ranking. Randomized founder-level actions plus direct or externally calibrated terminal labels restore a finite-gap ranking guarantee.

These are model-level statements. The witness is an exact construction using standard branching and hidden-state label symmetry; it is not a new branching/HMM theorem, not evidence that a biological system has these parameters, and not a safety claim about any intervention.

## Exact passive-field match

Let each living cell have an unobserved inherited type $H\in\{1,2\}$. Under passive action $u=0$, cells of either type follow the same reactions

\[
C_h\xrightarrow{\beta}2C_h,\qquad C_h\xrightarrow{d}\varnothing,
\]

with daughters inheriting $h$. Write $X=C_1+C_2$. The aggregate CLE drift and quadratic-variation rate are

\[
A_0(X)=(\beta-d)X,\qquad \Sigma_0(X)=(\beta+d)X.
\]

They do not depend on the hidden composition. Even if the type counts were separately recorded, the two worlds have the same vector CLE drift $((\beta-d)x_1,(\beta-d)x_2)$ and diagonal covariance $\operatorname{diag}((\beta+d)x_1,(\beta+d)x_2)$. More strongly, the exact aggregate count generator is

\[
\mathcal Lf(X)=\beta X[f(X+1)-f(X)]+dX[f(X-1)-f(X)],
\]

so the passive aggregate count path law is the same for every hidden-type mixture, not merely its first two CLE coefficients. Both worlds below use this same passive process and the same passive observation channel. Consequently every passive CLE drift/covariance field available from this aggregate is identical.

## Controlled one-generation branching witness

A founder has $H=1$ with probability $4/5$ and $H=2$ with probability $1/5$. It divides into two sisters that inherit the same type. A clone-level action $u\in\{A,B\}$ is applied to both sisters. After division, each sister independently experiences competing terminal transitions to target R and unsafe state U, conditional on H, with the following rates in world $M_+$:

| Hidden type | Action A: \((\lambda_R,\lambda_U)\) | Action B: \((\lambda_R,\lambda_U)\) |
|---|---:|---:|
| $H=1$ | $(3,1)$ | $(1,3)$ |
| $H=2$ | $(1,3)$ | $(3,1)$ |

Every total event rate is 4. At infinite follow-up each sister reaches R with probability $3/4$ or $1/4$, respectively. Define clone success as “at least one target descendant and no unsafe descendant.” Because both sisters eventually terminate, this is exactly the event that both are R. Conditional on shared founder type, the sister outcomes are independent, so

\[
P_{M_+}(\mathrm{success}\mid A)=\tfrac45(\tfrac34)^2+\tfrac15(\tfrac14)^2=\tfrac{37}{80}=0.4625,
\]

\[
P_{M_+}(\mathrm{success}\mid B)=\tfrac45(\tfrac14)^2+\tfrac15(\tfrac34)^2=\tfrac{13}{80}=0.1625.
\]

Unsafe-clone probabilities are the complements, $43/80=0.5375$ for A and $67/80=0.8375$ for B. Thus A strictly dominates B on the declared reach and safety endpoints in $M_+$.

In world $M_-$, swap $\lambda_R$ and $\lambda_U$ for every hidden type and action, while keeping the passive process, founder-type prior, and sister branching law unchanged. Then

\[
P_{M_-}(\mathrm{success}\mid A)=13/80,\qquad
P_{M_-}(\mathrm{success}\mid B)=37/80,
\]

with harm probabilities $67/80$ and $43/80$, respectively. B strictly dominates A. The action ranking is therefore not a function of passive CLE drift/covariance, even though those fields match exactly.

For a finite endpoint $T$, put $c_T=1-e^{-4T}$, $p_R=\lambda_R/4$, and $p_U=\lambda_U/4$. Conditional on hidden type and action,

\[
P(\text{success by }T\mid H,u)=(e^{-4T}+c_Tp_R)^2-e^{-8T},
\]

\[
P(\text{any }U\text{ by }T\mid H,u)=1-(1-c_Tp_U)^2.
\]

At the concrete finite horizon T=1, the safe-reach probabilities are 0.469087 for M+ action A and 0.169188 for action B; harm probabilities are 0.530577 and 0.830476. M- reverses these values. Thus the strict reversal is present at a finite horizon. The exact T-to-infinity values above are also useful closed forms; each sister's event time has mean 1/4, and censoring must be counted if follow-up is cut off.

## Exact observation alias under unknown emissions

Suppose the terminal assay reports a binary label $V=1$ (“R reporter”). In $M_+$, its sensitivity and false-positive rate are $s_+=P(V=1\mid R)=0.9$ and $f_+=P(V=1\mid U)=0.1$. In $M_-$, take the equally admissible but uncalibrated channel $s_-=0.1$, $f_-=0.9$. For each hidden type and action, $M_-$ swaps the true R/U transition rates, so $p_R^-=1-p_R^+$; its reporter probability is

\[
f_-+(s_--f_-)p_R^-=0.9-0.8(1-p_R^+)=0.1+0.8p_R^+
=f_++(s_+-f_+)p_R^+.
\]

The total event rate remains 4, so event-time distributions and censoring/no-event probabilities also match. This equality holds conditional on each (H) and each action. Given (H), sisters are independent in both models; therefore the joint observed sister labels and times match as well. Any observed type-marker channel can be held fixed across the worlds; even perfect knowledge of (H) does not break this terminal-label alias.

For any adaptive policy that chooses later actions from earlier observed labels/times, the next-observation kernel is equal in $M_+$ and $M_-$ for every realized history, hidden type, and chosen action. Induction gives identical full transcript distributions under the policy. Thus the observational total-variation distance is zero for every sample size and every adaptive allocation. Since the unique best actions are opposite, any ranking rule has worst-case error at least $1/2$: if it chooses A with probability $r$ under the common transcript law, its errors in the two worlds are $1-r$ and $r$.

This no-go is about semantic safety/reach labels. If the goal is merely to maximize the reporter-positive fraction, the reporter-defined objective is observable; it need not equal the biologically specified safe-regeneration objective. A known orientation condition $s>f$, or a calibrated confusion matrix, rules out the particular label-swap alias. If emissions vary by hidden type or action, calibration must cover those strata or use an orthogonal endpoint assay.

## Minimal interface for finite action ranking

For **marginal, context-specific action ranking**, hidden type rates need not be estimated. The minimal useful observation contract is:

1. Randomize independent founder clones to a finite, predeclared action set, with delivered action/exposure recorded and no unmodeled cross-clone interference.
2. Freeze the target event, unsafe event, and finite horizon before assignment. Record a clone-level joint endpoint (target reached, any unsafe fate, and censoring) with direct semantic labels, or an externally calibrated emission channel with known orientation and bounded error.
3. Treat the founder clone as the sampling unit. Preserve parent/daughter identities and the full sister outcome vector if the mechanistic claim concerns dependence or lineage reachability; do not count descendants of one founder as independent trials.
4. Block/randomize across donors or organoids and retain donor/organoid as the independent biological cluster when clones share a context. Record all deaths, missing branches, and right-censoring.

Under that interface, randomized clone-level outcome distributions identify action-specific marginal reach/safety laws nonparametrically; hidden types and their rates are nuisance variables. Full lineage trees and a joint daughter law are required to transport a fitted branching mechanism or to optimize state-contingent actions, but not to estimate an average randomized arm difference.

For **hidden-type mechanism fitting or type-contingent control**, additionally acquire an anchored type/outcome assay, action positivity within each identified type, event times, at-risk cell-time, complete parent/daughter links, and censoring/death status. A proposed CTMC likelihood would use observed type/action exposure and marked event counts; passive CLE fields do not supply the action-specific rates. With hidden types and unrestricted unknown emissions, the model is identifiable at best up to observational equivalence classes; reporting one EM/HMM parameterization does not resolve the biological label.

## Finite sample and calibration cost

Let $Y_j\in\{0,1\}$ be the directly observed safe-reach endpoint for a randomized founder assigned action $j$, and let its mean be $\theta_j$. For two independently sampled arms of $n$ founders each and a true target gap $\Delta=\theta_A-\theta_B>0$, Hoeffding gives

\[
P(\widehat\theta_A\le\widehat\theta_B)\le e^{-n\Delta^2}.
\]

Thus $n\ge\lceil\log(1/\alpha)/\Delta^2\rceil$ per action suffices for one-sided ranking error at most $\alpha$. For the true witness gap $\Delta=0.30$ and $\alpha=0.05$, this is 34 independent founder clones per action. With the specified per-daughter reporter channel $s=0.9,f=0.1$, define the *observed* clone statistic as both sisters reporter-positive. Its probabilities in $M_+$ are 0.41 under A and 0.17 under B (gap 0.24); the same reporter statistic has the same law in $M_-$ because of the alias. Ranking this reporter-defined endpoint needs 53 founders per action at one-sided error 0.05. This does not identify the true biological endpoint in the absence of calibration. These are fixed two-arm ranking bounds, not a sample-size estimate for a real organoid study.

For a simultaneous safety/target selector over $M$ actions with direct binary endpoints, the Hoeffding radius

\[
h=\sqrt{\frac{\log(4M/\alpha)}{2n}}
\]

gives $1-\alpha$ coverage for all $2M$ endpoint means. Certify action $j$ safe only when $\widehat p_{U,j}+h\le\delta$, then choose the certified action with largest $\widehat p_{R,j}-h$. A true safe action with margin $p_{U,j}\le\delta-2h$ is certified, and the selected target mean is within $2h$ of the best such margin-feasible action. At $M=2,\alpha=0.05,h=0.05$, $n=1016$ per action. This larger number buys simultaneous target-and-harm coverage rather than only ranking one predeclared gap.

If the reporter confusion matrix is unknown, acquire blinded gold-standard reference cells of known R and U status under the same action, type, donor, and assay conditions. For a binary channel applied directly to the clone-level endpoint, $q=f+(s-f)p$, so $p=(q-f)/(s-f)$ only when the orientation/contrast is known and bounded away from zero. With $\kappa=s-f\ge\kappa_0>0$, if treatment reporter means and both calibration rates each have error at most $\gamma$ and $\gamma\le\kappa_0/4$, then the plug-in probability error is at most $4\gamma/\kappa_0$. If the reporter is emitted per daughter, use the calibrated joint emission likelihood for the full pedigree; the single-clone linear inversion need not hold for a composite clone endpoint. Hoeffding gives the calibration requirement

\[
n_{cal}\ge\left\lceil\frac{\log(4/\alpha_{cal})}{2\gamma^2}\right\rceil
\]

gold-standard R samples and the same number of gold-standard U samples for simultaneous two-rate error at most $\alpha_{cal}$. These reference-cell costs are in addition to treated founders. If no semantic ground truth or orientation constraint is available, the exact alias above makes the latent safety/reach ranking `UNIDENTIFIABLE`, not merely underpowered.

For a finite adaptive schedule capped at $N_{max}$ observations per action, union-bound the $2M$ direct binary endpoints over every possible action-specific sample count $n\le N_{max}$. At sample count $n$, radius $h_n=\sqrt{\log(4MN_{max}/\alpha)/(2n)}$ then covers every look, including data-dependent stopping, with probability at least $1-\alpha$. This assumes new independent founders are selected before outcomes are observed, randomized to an action, and drawn from the same fixed context; donor/organoid clustering needs a block-level analysis. For a known common reporter contrast $\kappa$ on the clone-level endpoint, divide the radius by $\kappa$. Stop only when the safety and ranking intervals separate the predeclared margins; otherwise return `UNKNOWN` at the cap. A useful finite $N_{max}$ for fitting type-specific continuous-time rates cannot be specified without minimum type frequency, event-rate bounds, and desired parameter precision; those rates are `UNKNOWN` from the current evidence and remain a charged acquisition cost.

## Baseline comparison and prior-art boundary

- **CLiNC / lineage reconstruction from clonal correlations.** Weinreb and Klein model branching/differentiation and use normalized covariance of barcode counts to infer lineage hierarchy under stated assumptions. Their paper notes exclusions including non-mean-field cell interactions, cell death, and some forms of self-renewal/asymmetric division, and characterizes retrospective barcode reconstruction as hypothesis-generating when definitive lineage structure matters. This is a strong baseline for branching/tree structure, but it is not a randomized action-effect estimator and cannot calibrate the semantic meaning of an unknown outcome reporter. Primary source: [PNAS 2020, PMC7382289](https://pmc.ncbi.nlm.nih.gov/articles/PMC7382289/), especially lines 99–108 and 235–242.
- **Tree-HMM.** Mohammadi et al. fit latent cellular states, transition probabilities, initial-state abundance, and state-specific phenotype emission distributions to measured lineage trees; they include censoring and benchmark state-count selection. Their application fits shared initial/transition probabilities across treatment concentrations while allowing phenotype emissions to vary. This is directly relevant prior art for hidden-state lineage modeling; it means no generic hidden-tree inference novelty is claimed. It does not eliminate an exact semantic emission alias: when two parameter sets give the same observed tree law and differ only by an unanchored R/U interpretation, no likelihood method can choose between them. Primary source: [Communications Biology 2022, PMC9671968](https://pmc.ncbi.nlm.nih.gov/articles/PMC9671968/), especially lines 167–173, 220–229, and 398–409.
- **Earlier lane work.** The Cycle 1–2 Galton–Watson counterexample, sharp offspring bounds, and minimal joint-offspring statistic are inherited and standard. The current addition is a controlled hidden-type/emission counterexample plus a finite-assay interface, not novelty over multitype branching, HMM label symmetry, or randomized-trial concentration.

The lineage models cited above use more information than passive CLE moments: observed lineage relations, barcode clone statistics, or phenotype emissions. The exact witness says even a complete lineage recording is insufficient if the endpoint label channel is allowed to float semantically. Conversely, direct randomization plus an anchored endpoint can rank average actions without solving the entire latent-rate identification problem.

## Proposed decisive experiment/control

Use one frozen regenerative-cell context and a finite panel of action schedules. Barcode independent founders, randomize at the founder/clone level, and image until the predeclared horizon. Track every division and branch, record action exposure and censoring, and measure target and unsafe endpoints on the same clone. Include positive gold-standard R and U reference populations passed through the same reporter pipeline in each action/context stratum, plus an orthogonal functional endpoint where feasible. Estimate the confusion matrix before ranking. Keep an untouched donor/organoid set for validation.

Compare three equally informed predictors on held-out founder clones: (i) a passive CLE/marginal-transition model, (ii) a calibrated tree-HMM or joint-offspring branching model with lineage and emissions, and (iii) the randomized empirical action means. Score safe-reach calibration, unsafe-risk calibration, and log loss at the clone level; charge founder clones, donor/organoid blocks, live imaging, barcodes, endpoint assays, gold-standard calibration cells, and follow-up/censoring. The decisive control implication is that reporter calibration must be intervention-matched and, if emissions vary across hidden phenotypes, type-stratified or orthogonal: using only the same unknown reporter labels cannot rule out the reversed-ranking world. If calibrated lineage structure adds no held-out predictive value beyond randomized arm means, do not claim a mechanistic controller advantage.

RESULT AND EXACT SCOPE

Let F be an explicit Q(i) pair matrix. Suppose its off-diagonal entries admit

 F_ij=a_i b_j x_min(i,j), i!=j,                              (G)

where min is the smaller INDEX, and x_i,a_i,b_i are complex rationals. No
monotonicity, positivity, real phase, full rank, or conditioning of x is needed.
All diagonal entries are irrelevant under hard onsite projection. For the dense
case F_ij!=0 whenever i!=j, a deterministic O(n^2)-arithmetic recognizer acquires
the parameters from F; its exact program is below. This is therefore an
explicitly recognized input subclass, not a supplied factorization oracle.
At zeros, supplied parameters can instead be verified by n(n-1) exact tests;
the present dense acquisition program does not recognize every zero-pattern
Green representation. The general width algorithm covers many additional zeros.

On this class the hard coefficients
 c_k=sum_{I,J disjoint,|I|=|J|=k}|det F[I,J]|^2
and every hard physical prefix count are acquired in O(n^2) rational operations,
with polynomial bit heights. A cached table gives exact canonical Born samples
in O(kn) additional arithmetic operations and expected polynomial random-bit
cost. Norm zero is decided exactly. There is no inverse norm, sector probability,
or projection probability. Arbitrary nonnegative rational local weights on
empty/up/down states are included, including hard zeros at any site.
Positive double-occupation filters are outside this fast DP; the generic exact
MPS/tree algorithm admits them. No coherent compiler or hardware was executed.

The symmetric positive example F_ij=min(i,j), i,j=1..n, is full rank (det=1),
dense, and has nonbipartite off-diagonal support for n>=3. It has every feasible
hard pair sector positive. Hence this is a genuine subclass beyond monomial
and cross-bipartite pair matrices, including actual symmetric spin-singlet
pairing matrices. It has ordered cut rank 2 and is contained in INITIAL's
broader admitted class; the new result substantially sharpens acquired costs.

DETERMINISTIC PARAMETER ACQUISITION

Use zero-based indices temporarily. Assume all off-diagonal F entries are
nonzero and n>=2. Let s_0=1 and s_i=F_i0/F_0i. Define H_ij=F_ij/s_i. Test every
off-diagonal H_ij=H_ji; failure supplies an explicit entry certificate.
This symmetrization is necessary for (G): if F_ij=a_i b_j x_min(i,j), then
s_i=(a_i/b_i)/(a_0/b_0), so H is symmetric.

Choose q_0=p_0=1, q_j=H_0j for j>=1, p_i=H_i,n-1/q_n-1 for 1<=i<=n-2, and
p_n-1=q_n-1 (the last p never appears off diagonal). Check H_ij=p_i q_j for
every i<j. If these identities hold, put
 x_i=p_i/q_i, a_i=s_i q_i, b_i=q_i.
Then F_ij=a_i b_j x_min(i,j) holds for i<j by construction, and for i>j by
the tested symmetry. All q_i are nonzero. Verify every off-diagonal identity
explicitly. Necessity follows because any symmetric H from (G) has strict
upper entries p_i q_j; the first row and last column determine a valid gauge.
Thus this program accepts exactly the dense diagonally gauged Green class in
the supplied order. For n=1 the hard target is vacuum, handled directly.

Every acquired parameter is a bounded-depth product/quotient of rational input
entries; small nonzero entries cause larger bit integers, not an inverse-value
iteration count. Parameter heights are polynomial in total input length.

SELF-CONTAINED MINOR FORMULA

First strip the row/column gauges. Set K_ij=x_min(i,j) on every entry, with
x_0=0 a virtual coordinate before site 1. Let delta_l=x_l-x_(l-1). Let L be the
lower triangular all-ones matrix. Then K=L diag(delta) L^T over Q(i), with no
positivity assumption.

For increasing I=(i_1,...,i_k) and J=(j_1,...,j_k), Cauchy–Binet gives
 det K[I,J]=sum_{R,|R|=k} det L[I,R] det L[J,R] product_{r in R}delta_r.
The step-matrix minor det L[I,R] is 1 exactly when
 i_(m-1)<r_m<=i_m for every m (i_0=0), and zero otherwise. To see this, replace
each selected row by its difference from the previous selected row. The rows
then indicate disjoint consecutive index intervals; a nonzero determinant
requires exactly one ordered R element in each interval, and its value is 1.

Both step minors are 1 exactly when
 max(i_(m-1),j_(m-1))<r_m<=min(i_m,j_m).
If any interval is empty, the minor is zero. Otherwise the intervals are
disjoint and ordered, so the sum factors and telescopes:

 det K[I,J]=product_m (x_min(i_m,j_m)-x_max(i_(m-1),j_(m-1))).       (M)

This proof also covers complex, nonmonotone coordinates and cancellations.
It is the classical Green-matrix minor formula in a convenient gauge.

Now assume I,J are disjoint. A nonzero minor requires each successive pair of
sites in the merged ordered occupied support to contain one I site and one J
site. Otherwise one of the displayed intervals is empty. For support
 p_1<q_1<p_2<q_2<...<p_k<q_k, write q_0=0. Each of the 2^k pair orientations
has the same ungauged determinant product
 product_m (x_p_m-x_q_(m-1)); orientations can differ in gauge magnitudes/phases.

With local weights e_i,u_i,d_i for empty/up/down, define
 A_i=|a_i|^2 u_i, B_i=|b_i|^2 d_i, E_i=e_i,
 H_pq=A_p B_q+B_p A_q.
Summing the two orientations of each occupied pair produces the positive
configuration weight

 product_m |x_p_m-x_q_(m-1)|^2 H_p_m,q_m
 times product_{unoccupied i} E_i.                         (W)

All amplitudes and their phases are still the original determinant amplitudes;
this is only the exact norm decomposition. Hard prefix constraints simply set
forbidden e/u/d weights to zero. A forced double occupation has zero norm.

EXACT O(kn) SUFFIX-MOMENT DP

Let D_m(r) be the weight of m further pairs on sites after r, where the previous
occupied right endpoint has coordinate x_r. Put
 D_0(r)=product_{s=r+1}^n E_s.
For m>=1 the direct recurrence from (W) is

 D_m(r)=sum_{r<p<q<=n} |x_p-x_r|^2 H_pq D_(m-1)(q)
             product_{s=r+1}^{p-1} E_s product_{s=p+1}^{q-1} E_s.    (D)

The initial coefficient is c_k=D_k(0). This recurrence itself already gives a
polynomial exact count. Its cubic per-layer sum compresses to linear cost:

 Q_A(r)=A_(r+1)D_(m-1)(r+1)+E_(r+1)Q_A(r+1), Q_A(n)=0,
 Q_B(r)=B_(r+1)D_(m-1)(r+1)+E_(r+1)Q_B(r+1), Q_B(n)=0.
Thus Q_A(p) and Q_B(p) are the two weighted right-endpoint suffix sums. Put
 R_m(p)=A_p Q_B(p)+B_p Q_A(p).

For h_0(x)=1, h_1(x)=x, h_2(x)=|x|^2, define
 S_h(r)=h(x_(r+1))R_m(r+1)+E_(r+1)S_h(r+1), S_h(n)=0.
Expansion of the squared complex distance yields

 D_m(r)=S_2(r)-2 Re(conj(x_r) S_1(r))+|x_r|^2 S_0(r).     (SM)

Every recurrence uses exact rational complex arithmetic. S_1 may be complex;
D_m is real nonnegative because (SM) equals the positive sum (D). Empty-weight
zeros are retained directly in the recurrences, with no division by E_i.
Each layer m costs O(n) arithmetic operations. Computing all k<=floor(n/2)
therefore costs O(n^2); prescribed k costs O(kn). Store D_m and R_m to sample.

EXACT ACQUIRED SAMPLING

At state (r,m), select p>r with mass
 product_{s=r+1}^{p-1}E_s |x_p-x_r|^2 R_m(p).
Its sum is D_m(r). Given p, select q>p with mass
 product_{s=p+1}^{q-1}E_s H_pq D_(m-1)(q).
Its sum is R_m(p). Given p,q, choose the orientation (p up,q down) or its
reverse with masses A_p B_q and B_p A_q. Update (r,m) to (q,m-1). All unused
sites are empty. Multiplication of these exact conditional probabilities
cancels the D and R factors, giving precisely (W)/D_k(0). A positive path
cannot skip a forced occupied site because its empty weight is zero. The final
D_0(r)>0 guarantees every remaining forced condition was met.

Each endpoint choice scans at most n rational masses; each orientation has two.
Use the existing exact denominator-clearing integer_choice routine. Under the
unbiased random-bit interface, every integer retry accepts with probability
>=1/2, proving exact expected polynomial sampling. A capped retry wrapper gives
arbitrary total variation error delta with O(log(n/delta)) retries per choice;
that wrapper is not implemented. The default code uses the OS random-bit API;
seeded MT draws are used only for reproducible diagnostics. No physical entropy
source or backend independence was certified.

BIT HEIGHTS AND COSTS

Let L include F, local tables, and any supplied parameters. Acquired parameters
have O(poly(L)) bits. After clearing all parameter/table denominators by one
integer of polynomial bit length, each configuration (W) has O(n) bounded-
degree factors and a common denominator with O(poly(n,L)) bits. At most 3^n
physical configurations are summed, adding O(n) numerator bits. The direct
definition (D) therefore gives polynomial numerator/denominator heights for
every D_m(r); Q, R and S sums/products obey the same bound. There is no numeric
dependence on 1/min gap, 1/c_k, or a singular value. Exact integer bit-operation
cost is the arithmetic count multiplied by polynomial(n,L) multiplication/
division costs. Acquisition and full all-sector counting cost O(n^2) arithmetic;
prefix restrictions cost another O(n^2) pass. A cached-table sample costs O(kn)
arithmetic plus polynomial(n,L) expected random bits. Table storage is O(kn)
rationals. General arbitrary-F input or unknown-order Green recognition is
not covered by the fast theorem.

UNIFORM MIN KERNEL: AN ALL-SIZE CLOSED FORM

Take a_i=b_i=1 and x_i=i. K=L L^T has det=1 and ordered cross-rank sum 2.
For a 2k-site support t_1<...<t_2k, all 2^k orientations have squared determinant
 product_m (t_(2m-1)-t_(2m-2))^2, t_0=0.
Let positive gaps d_l=t_l-t_(l-1) and final slack n-t_2k>=0. Summing the odd
gaps with weight d^2 and even gaps with weight 1 gives

 c_k=2^k [z^(n-2k)] (1+z)^k/(1-z)^(4k+1)
    =2^k sum_{j=0}^{min(k,n-2k)} binomial(k,j)binomial(n+2k-j,4k), k>=1,
 c_0=1.                                                      (CF)

The generating identities are sum_{d>=1}d^2 z^d=z(1+z)/(1-z)^3 and
sum_{d>=1}z^d=z/(1-z). The unconstrained final slack contributes 1/(1-z).
At n=2k the norm is exactly 2^k, and the hard state has the 2^k adjacent-pair
orientations. For all 2k<=n there is positive support; the alternating I=(1,3,...),
J=(2,4,...) minor has determinant 1 by (M). This supplies dense symmetric
full-rank hard examples at every size and charge without favorable probability.

# Cycle 2 report: an explicit kernel, with a narrower mask theorem

## Verdict

I could not materialize the pinned 9/4 paper’s kernel with explicit field-degree, coefficient-height, or setup-time bounds. The page-9 proof is existential at exactly that point: it chooses a base size and a rank decomposition from the asymptotic exponent definition, without giving either object or a bounded search procedure. Its Remark 5.2 also overstates Nullstellensatz: a complex solution need not have a rational point, although a `Qbar` point does give some finite number field.

The smallest nontrivial explicit base kernel used here is Strassen’s 2×2 seven-product kernel over `Q` (I make no new claim that its rank is minimal). I materialized and exhaustively checked its coefficient table, then compiled it recursively into a selective-output routine. This proves a uniform exact theorem for supplied rectangle-cover masks with `M<=N^(179/100)` and a smaller explicit residual. At `D=N^(1/4)`, its online bit bound is

`O(N^(2-min{3/400,sigma}) polylog N)`

for input entries with `O(log N)` bits and residual size `|F|<=N^(7/4-sigma)`. This is a narrow constructive replacement for the prior 9/4-based conditional tile route, not an arbitrary-mask result. It does not reach the prior `M=N^(15/8)` rectangle-volume endpoint.

## What is now explicit

The base kernel uses 36 nonzero coefficients in `{−1,0,1}`, with field `Q` of degree 1 and logarithmic height 0. The recursive `2^k` square program performs exactly `7^k` scalar multiplications and `6(7^k-4^k)` additions/subtractions. Padding each `D x D` tile to `m=2^ceil(log2 D)<2D` gives the fully uniform compiler. It uses `O(ND+M D^(log2(7)-2)+|F|D+M+|F|)` scalar operations. General bit accounting, mask-list input, value output, and circuit serialization are recorded in the theorem file.

The explicit nonempty mask sequence is `N=t^100`, `D=t^25`, with `t^21` diagonal interval blocks of side `t^79`; it has exact cover volume `N^(179/100)` and explicit index-list length `O(N log N)`. The direct independent-dot-product method costs `Theta(N^2.04)` scalar multiplications, while the Strassen-backed bound is strictly subquadratic.

## Falsification and limits

The coefficient identity passed an exhaustive 64-coordinate exact-integer check. The recursive implementation matched naive multiplication on 48 seeded integer fixtures of sizes 1, 2, 4, and 8; an overlapping-rectangle fixture with residual pairs also produced each distinct output exactly once. These are finite implementation checks, not external validation or a proof of the asymptotic result. The exact comparison `7^100<2^281` supports the exponent calculation.

At the earlier cover endpoint `M=N^(15/8)`, Strassen’s covered-work exponent is about `2.07684`, so this constructive kernel does not yield a subquadratic bound there. If the mask arrives only as a full bitmap, its `N^2`-bit read cost can erase the gain. No cover-generation theorem or arbitrary-mask lower bound is claimed.

1. Target and source boundary

For normalized BMVZ clause weights pi_f, the target is one isometry V and positive contractions C,B such that

    ker C = ran V,       C >= gamma (I - VV*),
    alpha H <= V* B V <= beta H,

with fixed alpha,beta,gamma>0 and polynomial row support plus polynomial-time row/entry access and bounded coefficient precision. Here

    H = sum_f pi_f h_f,
    h_f = I - product_{i=1}^t (I - Pi_{fi}).

The primary BMVZ source states that a clause is the OR projection I-product_i(I-Pi_i), with the Pi_i acting on disjoint tensor copies; its paths are length-t walks in a constant-degree expander. The iterated theorem gives polynomially many clauses that are O(n)-fold products of constant-locality projections. The construction below assumes the stipulated 5-local seed realization is rank-one stabilizer/Clifford, so each Pi_{fi} is the common +1 eigenspace of five commuting Hermitian Pauli checks. If only the more general projection statement is available for a particular instance, this measurement circuit is not yet justified for that instance.

2. Exact common branch isometry and positive sparse B

Take an explicit binary CSS qLTC code with N physical qubits and k>=n logical qubits, where N=O(n) by constant rate. Its polynomial-time check matrices give a stabilizer encoding. Gaussian elimination yields a Clifford encoder E_N on N qubits, with k logical input qubits and N-k zero ancillas; logical Pauli representatives are computable by symplectic linear algebra in poly(N) bit operations. Apply this encoding separately to each of the t BMVZ copies, using the first n logical qubits for the original Hamiltonian and fixing the remaining k-n logical qubits to |0>. The code's constant qLTC soundness is not used in the algebra below; the CSS check matrices and their efficient description are the resource.

For each clause f, each copy i, and each of the five stabilizer generators a=1,...,5 for Pi_{fi}, let R_{fia} be the corresponding physical logical Pauli representative after encoding. These 5t observables commute: within each rank-one seed they commute, and different copies have disjoint encoded registers. Use one ancilla bit per observable and the Clifford measurement circuit

    M_R = H_ancilla · controlled-R · H_ancilla.

On an R-eigenvector of eigenvalue (-1)^b with ancilla |0>, M_R records b in the ancilla without changing the data eigenvector. Let M_f be the product of these 5t commuting measurement dilations, in a fixed order, without the encoder. Let E_N be a full Clifford unitary extending the CSS isometry, and put U_f=M_f(E_N^{tensor t} tensor I_anc). Let D_f be the diagonal projection on the 5t outcome bits that is 1 iff some block i has all five outcome bits 0. Here J maps the nt input qubits to the encoded block with the unused k-n logical qubits, N-k encoding ancillas, and 5t measurement ancillas all fixed to zero; the total fixed workspace is t(N-n)+5t qubits. Then

    J* U_f* D_f U_f J = h_f.

The branch-label space has one basis state for every clause f. With pi_f>=0 and sum_f pi_f=1, set

    V|psi> = sum_f sqrt(pi_f) |f> tensor U_f J|psi>,
    B = sum_f |f><f| tensor D_f,

where D_f acts only on the outcome ancillas. Orthogonal branch labels make V an isometry. The compression is exact:

    V* B V = sum_f pi_f h_f = H.

B is a positive contraction, diagonal, and exactly 1-sparse per row. Its entry/row oracle reads the f label, computes the 5t syndrome bits, and tests the OR predicate; time is polynomial in t,N and the clause-index description. Its entries are exactly 0 or 1. V has a uniform controlled-Clifford circuit of polynomial size in the explicitly listed/generable clause family, plus amplitude preparation for sqrt(pi_f). For rational pi_f of b-bit height, amplitudes have algebraic degree at most two and O(b+log M) description bits; an epsilon-accurate state preparation has polynomial cost in M,b,log(1/epsilon). No claim is made that V itself is sparse as a matrix.

This is a genuine affirmative construction of the B side for the actual amplified OR clauses under the rank-one stabilizer seed condition. It pays no exponential Pauli expansion: the OR is evaluated on coherent syndrome ancillas.

3. A sparse constant-gap enforcer for each branch image

Each branch range

    Q_f = U_f (C^{nt} tensor |0^{t(N-n)+5t}>)

is a stabilizer code subspace: both the CSS encoder and W_f are Clifford. I give an exact sparse constant-gap enforcer for any stabilizer code, which can be applied to each Q_f. This is global and row-sparse; it does not equal the normalized qLTC check Hamiltonian.

Let S be an N0-qubit stabilizer group, with computational-basis X-projection X_S <= F_2^{N0} of dimension r. The subgroup of pure-Z stabilizers defines a valid affine set A of computational strings. Every orbit A/(X_S) is an affine coset of X_S. Standard stabilizer normal form gives one code basis vector per orbit, uniform on that orbit with a computable phase function omega_y(x) in {+1,-1,+i,-i}. Choose an explicit lazy constant-degree expander P_r on the 2^r labels x in F_2^r, with 1=lambda_1 and 1-lambda_2>=delta_0>0; for r=0 or bounded r use the finite complete graph. On each valid orbit define

    C_S|_orbit = I - D_omega P_r D_omega*,

and put C_S=I on invalid computational basis strings. The phase gauge makes the unique zero vector on each orbit exactly its stabilizer-code vector. Since P_r is lazy and symmetric, 0<=C_S<=I and

    ker C_S = code(S),       C_S >= delta_0 (I-P_code(S)).

Every row has at most d0+1 nonzeros, where d0 is the constant expander degree. The row oracle tests the pure-Z affine constraints, computes a canonical orbit representative and the X_S coordinates by Gaussian elimination, enumerates the d0 expander neighbors, and evaluates the phase ratio from the stabilizer tableau. This costs poly(N0) time and space; each entry is rational times a fourth root of unity with O(log d0) bits. The expander graph itself is succinct and is evaluated in poly(r) time. The operator may connect computational strings at Hamming distance Theta(N0); this is why the local-check gap bound does not apply.

For a concrete finite check, the Bell stabilizer code span{(|00>+|11>)/sqrt(2)} has exact enforcer, in basis 00,01,10,11,

    C_Bell = [[1/2,0,0,-1/2],
              [0,1,0,0],
              [0,0,1,0],
              [-1/2,0,0,1/2]].

Its spectrum is {0,1,1,1}, its kernel is the Bell code, and each row has at most two nonzeros. This finite example is not a BMVZ encoding; it checks the orbit-expander formula on one exact stabilizer subspace.

Apply this compiler to each Q_f, obtaining contractions C_f with common gap gamma_0=delta_0. The block-diagonal

    C_0 = sum_f |f><f| tensor C_f

has row degree at most d0+1, polytime entry access, kernel direct-sum_f Q_f, and gap gamma_0. This is a useful qLTC/HDX application: explicit CSS code matrices can be encoded and then enforced by a nonlocal sparse expander, even though the normalized positive average of bounded-weight checks has gap O(1/N). It does not yet force different branches to carry the same logical vector.

4. The missing common-branch connector and its exact architecture barrier

There is a simple constant-gap connector if row sparsity is ignored. Let Gamma be a reversible expander on the branch set with stationary law pi and lazy spectral gap delta>0. Let U_f be the full Clifford unitary used in branch f (including the common CSS encoder), and let G=direct-sum_f U_f. If L_Gamma is the symmetric normalized graph Laplacian on branch labels, define

    C_conn = G (L_Gamma tensor I) G*.

Its kernel is the common-frame space {sum_f sqrt(pi_f)|f>U_f xi : xi arbitrary}; its gap is delta. The intersection of ker C_0 with ker C_conn is exactly ran V. Moreover C=(C_0+C_conn)/2 is a positive contraction. In the gauge G*, if E_0=<C_0> and E_1=<C_conn>, branchwise gap gamma_0 and graph gap delta imply

    dist(psi,ran V)^2 <= 2 E_0/gamma_0 + 3 E_1/delta,

so C >= min(gamma_0/4,delta/6)(I-VV*). Thus the spectral/kernel part is solved abstractly.

Its row cost is the obstruction. An edge f~g contributes a block proportional to U_f U_g*. The common CSS encoder cancels, leaving the relative Clifford W_f W_g*. A Clifford matrix has exactly 2^r nonzeros per row, where r is its Hadamard rank (the rank of its computational-basis mixing part); the nonzero entries have magnitude 2^(-r/2) and fourth-root phases. The C_conn row support is at most 1+deg(Gamma) max_{f~g} 2^{r(f,g)}. Its entries and rows are computable in time polynomial in N0 times this support. Hence a constant-degree connector is polynomial-row exactly when r(f,g)=O(log n) on every edge.

For BMVZ's one-round path-indexed family, a path is X=(X_1,...,X_t), with X_1 uniform and X_{i+1} sampled by the regular expander walk. All length-t walks are represented, so this is the stationary Markov path law. Let the base walk be symmetric with absolute nontrivial eigenvalue at most lambda<1, and set K_F=1+2lambda^2/(1-lambda^2). For any reversible branch kernel P_path with this path law stationary and every transition changing at most q coordinates, the ordinary Poincare gap obeys

    gap(P_path) <= min(2, C_lambda q/t),   C_lambda=max(9,32 K_F).

Proof. Choose a subset A of base vertices of mass p in [1/3,2/3], and let g=1_A-p, with sigma^2=E[g^2]=p(1-p)>=2/9. For Sigma_ij=E[g(X_i)g(X_j)], stationarity and the absolute spectral bound give |Sigma_ij|<=sigma^2 lambda^|i-j|. Hence ||Sigma||_F^2<=K_F t sigma^4. For independent Rademacher signs epsilon_i, define F_epsilon(X)=sum_i epsilon_i g(X_i). Its path-law variance is epsilon^T Sigma epsilon, whose sign-average is t sigma^2 and sign-variance is at most 2||Sigma||_F^2. Chebyshev gives Pr_epsilon[Var(F_epsilon)<t sigma^2/2]<=8K_F/t. Meanwhile, for any edge X->Y changing at most q coordinates, E_epsilon[(F_epsilon(X)-F_epsilon(Y))^2]<=q, since |g(X_i)-g(Y_i)|<=1. Thus the sign-average Dirichlet form is at most q/2, and Markov's inequality gives Pr_epsilon[Dirichlet(F_epsilon)>q]<=1/2. When t>16K_F the two good events intersect, yielding a mean-zero test function with variance at least t sigma^2/2 and Dirichlet at most q. The Rayleigh quotient is at most 2q/(t sigma^2)<=9q/t. For smaller t use the general gap bound 2; q=0 gives gap 0. ∎

Thus q=O(log n) implies gap O(log n/t), and a constant connector gap requires q=Omega(t). In the covariant connector C_conn=G(L_path tensor I)G*, this is also the gap on the branch-valid subspace, because the relative frames identify each branch code with the same underlying logical space. If a transition's relative Clifford is a tensor product over changed coordinate blocks and at least rho q blocks contribute independent nonmonomial factors, its Hadamard rank is at least rho q and each row has at least 2^(rho q) nonzeros. A polynomial row bound therefore forces rho q=O(log n); with rho constant, q=O(log n) and the connection gap vanishes when t grows faster than log n. This converts to a gate-count bound only in an architecture where gates are charged per changed coordinate factor (or otherwise guarantee rank Omega(s)); a raw local gate count can include cancellations or monomial factors and does not alone bound Hadamard rank. The nonmonomial premise is checkable exactly from a seed Clifford table. BJSW supplies noncommuting five-qubit seed types, but the current note does not certify that every possible long-range path-expander edge has the required independent nonmonomial factors in the final iterated BMVZ clause list.

This proves a no-go for a precise architecture: (i) branch by the BMVZ one-round path/clause label, (ii) enforce each branch stabilizer image separately, and (iii) tie branches only with a reversible covariant connection Laplacian whose edges change q path coordinates. Such connectors cannot have constant gap when q=o(t); if q is linear in t and a constant fraction of those changes contribute independent nonmonomial factors, their transport is not polynomial-row. The proof applies to the one-round stationary Markov path law. It does not automatically apply to the final iterated BMVZ clause labels, whose joint label law must first be extracted and checked for the same covariance bound. It also does not rule out non-connection C terms, a different common isometry, a global sparse circuit-history enforcer, or a sparse frame encoding that avoids direct path branches.

5. What qLTC/HDX does and does not buy here

The 2609.20780v1 and 2609.28028v1 papers give explicit binary CSS qLTC parameters and polynomial-time check-matrix construction. These let us add a linear-rate inner encoding, derive logical Pauli representatives in polynomial time, and form the branch stabilizer tableaux required by C_f. Their constant Hamming-distance soundness does not supply the missing branch connector. The weighted local-check enforcer still obeys the exact one-site bound gap<=w/N for max check weight w and normalized nonnegative check weights: choose a site with weighted incidence <=w/N and a one-site Pauli outside the stabilizer. The expander-orbit C_f escapes that bound only by adding globally connecting matrix entries; it is not a bounded-weight positive check average.

The new resource thus helps construct B and individual code-space enforcers, while the common branch consistency remains the load-bearing gate. Decoder/suppressor assumptions are not needed for the constructions above and do not imply a connection gap. This does not use Bafna–Nguyen–Zhang combinatorial soundness as a spectral lower bound.

6. Falsifiable next test and status

Acquire the exact polynomial-size BMVZ clause generator for one five-qubit BJSW instance. For each clause f, compile its 5t physical logical Pauli measurement circuit W_f and stabilizer tableau. Then, for candidate branch transitions, compute the exact Hadamard rank r(f,g) from the Clifford tableau and count changed path coordinates. Test whether there exists a reversible constant-degree graph on the actual clause set with (a) stationary weights pi_f, (b) gap bounded below, and (c) r(f,g)=O(log n) on every edge. An exhibited graph proves this direct-branch connector gate and yields a full C by the formula above; a certificate that every such graph has a path-local bottleneck or an edge with r=Omega(t) resolves this architecture negatively. For the iterated O(n)-fold family, first derive its exact branch-label distribution and test the covariance and coordinate-change hypotheses of the theorem; the single-round path proof alone is not an iterated-family theorem.

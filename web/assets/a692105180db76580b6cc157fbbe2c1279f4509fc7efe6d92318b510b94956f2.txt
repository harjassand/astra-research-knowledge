Sparse support-switch geometric Foster certificate: effectivity
===============================================================

Status and answer
-----------------
For the paired sparse catalyst-substrate family below, a common geometric
Foster certificate is effectively synthesizable from a finite graph, fixed
integer autocatalytic orders, and a compact rectangular rational rate box
whose endpoints are strictly positive. The construction is direct, exact,
and does not enumerate states. It yields rational V,c,C with

    L_theta V(x) <= C - c V(x)

for every lattice state x and every rate vector theta in the box, after
omitting conserved isolated-substrate coordinates from V. On a fixed class
label for those isolated coordinates, V is norm-like. The certificate is
sufficient and one-sided: this is not a decision procedure for recurrence
of arbitrary weakly reversible networks, nor a necessary characterization
of recurrence.

This closes the sparse-rate-box geometric-drift candidate left as a gate in
the Cycle 3 sparse extension. It does not transfer the conclusion to missing
reverse reactions, zero lower rate bounds, arbitrary propensities, or general
higher-order weakly reversible networks.

Supplied interface
------------------
There are finite catalyst and substrate sets J and I, a supplied bipartite
edge set E subset J x I, and fixed integers k_ji >= 1. For every j in J the
reactions 0 <-> A_j have rates alpha_j,delta_j. For every (j,i) in E the
four directed reactions are

    A_j <-> A_j+B_i,                 rates p_ji,q_ji,
    A_j+B_i <-> (k_ji+1)A_j+B_i,     rates u_ji,v_ji.

Propensities are standard stochastic mass-action propensities: in particular
the reverse autocatalytic propensity is v_ji (a_j)_(k_ji+1) b_i and its
stoichiometric decrement is k_ji A_j. Each rate independently ranges over a
supplied rational interval, for example

    0 < alpha_j^- <= alpha_j <= alpha_j^+ < infinity,

and likewise for delta,p,q,u,v. Let N(i)={j:(j,i) in E}. No substrate
coordinate with N(i)=empty can change; those coordinates are fixed class
labels and are omitted from V. The construction is uniform over their
labels. All other coordinates are included. Catalysts of degree zero are
allowed.

Construction
------------
Write P_j=sum_(i~j) p_ji^+, alphaSigma^- = sum_j alpha_j^- and
H^+=sum_j alpha_j^+. Choose the integer

    M=max(10, max_j ceil(2 P_j/delta_j^-),
                max_(j,i in E) ceil(p_ji^+/q_ji^-)),
    R=1+1/M,    d=1-R^(-1)=1/(M+1).

An empty maximum over E is omitted. Then for each catalyst

    delta_j^- - sum_(i~j) p_ji^+(R-1) >= delta_j^-/2.

For each nonisolated substrate set

    alpha_i^- = sum_(j~i) alpha_j^-,
    alpha_i^+ = sum_(j~i) alpha_j^+,
    Q_i = min_(j~i) q_ji^-/(M+1),
    D_i = max(max_(j~i) delta_j^+, alpha_i^+),
    epsilon_i = min(1,Q_i/(16 D_i)),
    beta_i = epsilon_i alpha_i^-/2,   beta=min_i beta_i.

If there are no nonisolated substrates, omit beta and all substrate-indexed
quantities below. Otherwise beta>0. These choices give

    epsilon_i D_i <= Q_i/16,     beta <= Q_i/32.

For each edge define rational/integer quantities

    gamma_ji = p_ji^+/M,
    Q_ji = q_ji^-/(M+1),
    U_ji = k_ji u_ji^+,
    ell(x) = min{n integer >= 0 : 2^n >= x},
    t_ji = ell(max(1,4 U_ji/Q_ji)),

    B_i = max over j~i of
       { M t_ji,
         ceil( 8(gamma_ji/2 + epsilon_i delta_j^+ + beta)/(3 Q_ji) ),
         1 }.

These are finite integers. Put t_i=max(2,max_(j~i)t_ji). The choice of M
and epsilon implies B_i <= M t_i. Indeed, the second threshold is at most

    22 p_ji^+/(15 q_ji^-) + 1/4 <= 22 M/15 + 1/4 <= 2M,

using M>=10, M>=p_ji^+/q_ji^-, epsilon_i delta_j^+<=Q_ji/16 and
beta<=Q_ji/32. Also

    2 <= R^M < 3,

by Bernoulli's inequality and the binomial-series bound. Consequently
R^(B_i) < 3^(t_i), a compact rational upper bound used below.

We need a uniform upper bound on every positive catalyst-linear edge
coefficient, without searching through an unbounded substrate range. For
each edge let

    s_ji = ell(max(1,2 U_ji/Q_ji)),
    Gbar_ji = gamma_ji 3^(s_ji+3) + U_ji M(s_ji+3).

For all integers m>=0, all rates in the box satisfy

    p_ji(R-1)R^m - q_ji d m R^m + k_ji u_ji m <= Gbar_ji.      (1)

To see this, the left side is at most
gbar_ji(m)=gamma_ji R^m-Q_ji mR^m+U_ji m. For
m>=M(s_ji+3), we have m>=M s_ji and m>=2 gamma_ji/Q_ji. Since
R^M>=2, these imply U_ji R^(-m)<=Q_ji/2 and
gbar_ji(m)/R^m<=gamma_ji-Q_ji m/2<=0. For smaller m,
R^m<3^(s_ji+3) and m<M(s_ji+3); dropping the nonpositive term gives
(1). All quantities in (1) are exact rationals or binary integers.

Set delta_* = min_j delta_j^- and c_A=delta_*/4. For a catalyst j with
positive degree define

    G_j = sum_(i~j) Gbar_ji,
    v_j = min_(i~j) v_ji^-,
    k_j = max_(i~j) k_ji,
    A_j = max(k_j+1, ceil(1+(G_j+c_A)/v_j)),
    C_j = A_j(G_j+c_A).

For degree-zero j set C_j=0. Finally define

    C_i^low = (epsilon_i sum_(j~i) delta_j^+ + beta) 3^(t_i),
    C_1 = H^+ + sum_j delta_j^+ + sum_j C_j + sum_i C_i^low,
    c = min(c_A,beta/2,alphaSigma^-),
    C = max(H^+,C_1).

When there are no nonisolated substrates, use c=min(c_A,alphaSigma^-)
and omit beta and C_i^low. The claimed potential uses K=1 and unit catalyst
weights:

    A(a)=sum_j a_j,
    h_i(a)=1_{sum_(j~i) a_j=0},
    V(a,b)=A(a)+sum_(i:N(i) nonempty) R^(b_i)(1+epsilon_i h_i(a))
                    +1_{A(a)=0}.                              (2)

Every parameter in (2), and c,C, is rational. V is norm-like on each fixed
isolated-substrate class and on the whole lattice when there are no isolated
substrates.

Why the drift inequality holds
------------------------------
The exact generator identity, with alpha(N(i))=sum_(j~i)alpha_j, is

    LV = H - sum_j delta_j a_j
       + sum_(j,i in E) [
           a_j{p_ji(R-1)R^(b_i)-q_ji d b_i R^(b_i)+k_ji u_ji b_i}
           - k_ji v_ji (a_j)_(k_ji+1)b_i ]
       - alphaSigma 1_{A=0} + sum_j delta_j 1_{a=e_j}
       + sum_i epsilon_i R^(b_i)[
           -alpha(N(i))1_{h_i=1}
           +sum_(j~i)delta_j 1_{a restricted to N(i)=e_j} ].    (3)

For A=0, all h_i=1 and (3) reduces to

    LV = H-alphaSigma-sum_i epsilon_i alpha(N(i))R^(b_i).

Since c<=alphaSigma^- and c<=beta/2<=epsilon_i alpha_i^-/4,
while 1+epsilon_i<=2, this gives LV+cV<=H^+.

For A>=1 split each ordinary edge coefficient in (3) by substrate size:
when b_i<B_i put the full a_j{...} into catalyst group j; when b_i>=B_i
put half into group j and half into substrate group i. Put every negative
reverse-autocatalytic term into its catalyst group. Put the local support
switch terms into their substrate groups. The remaining K-switch term
sum_j delta_j 1_{a=e_j} is bounded above by sum_j delta_j^+.

For catalyst group j, if every neighboring b_i=0, its coefficient is at
most -[delta_j^- - sum_(i~j)p_ji^+/M]a_j <= -(delta_j^-/2)a_j.
Otherwise some neighboring b_i>=1. By (1), all positive linear-in-a_j
terms are bounded by a_j G_j, while that edge's reverse reaction contributes
at most -v_j(a_j)_(k_ji+1). If a_j>=A_j, then k_ji<=k_j and
(a_j)_(k_ji+1)>=a_j(a_j-1), so the group is at most -c_A a_j. If
a_j<A_j, dropping its nonpositive death and reverse terms bounds it by
a_jG_j<=C_j-c_A a_j. Thus every catalyst group is at most
C_j-c_Aa_j, uniformly in b and the rate box.

For a substrate group with b_i>=B_i, the threshold ensures

    (1/2)gbar_ji(b_i) + epsilon_i delta_j^+ R^(b_i)
        <= -beta R^(b_i)       for every j~i.                 (4)

Indeed U_ji R^(-b_i)<=Q_ji/4, hence after division by R^(b_i) the left
side of (4) is at most
gamma_ji/2 - 3Q_ji b_i/8 + epsilon_i delta_j^+;
the definition of B_i makes this at most -beta. If h_i=0, at least one
neighbor has a_j>0, and each positive last-neighbor death switch is bounded
by epsilon_i delta_j^+ a_j R^(b_i). Summing (4) over active neighbors
therefore makes the substrate group at most -beta R^(b_i). If h_i=1,
all its incident edge terms and positive death switches vanish, while
neighbor immigration contributes at most
-epsilon_i alpha_i^- R^(b_i)<=-beta R^(b_i).

When b_i<B_i the substrate group has only the support switches. Its positive
part is at most epsilon_i sum_(j~i)delta_j^+ R^(b_i), and
R^(b_i)<3^(t_i). Thus it is at most C_i^low-beta R^(b_i). Combining all
groups yields, for A>=1,

    LV <= C_1 - c_A A - beta sum_i R^(b_i)
       <= C_1 - c V,

because V<=A+2 sum_i R^(b_i), c<=c_A and 2c<=beta. Together with the
A=0 case, this proves (2)'s uniform geometric drift inequality.

Effectivity and bit cost
------------------------
This is a terminating direct synthesizer, not an unbounded candidate
enumeration. Its only integer thresholds are M, t_ji, B_i, s_ji, A_j and
the fixed integer k_j. The function ell is computed by exact rational
comparisons with powers of two. The proof uses only rational arithmetic,
ceilings, maxima, and integer powers 3^t.

For binary-encoded rational endpoints and binary-encoded k_ji, all output
numbers have polynomial bit length in the explicit input size (including
the graph). M and B_i can be numerically exponential in that size but are
binary-encoded. Each t_ji is O(input bit length); hence 3^(t_ji+3) has
polynomial bit length. The G_j,A_j,C_j and final C are formed by a
polynomial number of exact rational operations on polynomial-bit operands.
With standard polynomial-time integer arithmetic, this explicit certificate
construction is polynomial-time in the binary input length. It makes no
claim that the *smallest* certificate or the stationary mixing time has a
polynomial bound.

This cost statement is for the stated interface: a finite graph, fixed k,
and a supplied positive rational rectangular rate box. It does not charge
for discovering or verifying a model that was not supplied. If any required
lower endpoint is zero, the construction's divisions or positive drift
margins fail; that outcome means this certificate compiler is inapplicable,
not that recurrence is false.

Exact fixture
-------------
The included `synthesize_fixture.py` instantiates the sparse graph
E={(1,1),(2,1),(2,2)} with singleton rational rates
alpha=delta=p=u=1, q=v=2, k=1. It reports

    M=10, R=11/10,
    epsilon_1=1/176, epsilon_2=1/88,
    B_1=B_2=50,
    A_1=146, A_2=290,
    c=1/352, C=92275693/440.

It exactly checks the threshold arithmetic and the generator identity on
625 states. This finite check is only a formula diagnostic; the all-state
drift claim is supported by the case proof above, not by enumeration.
Run from the workspace root:

    python3 -B outputs/research/reaction_dynamics/cycle4/leaves/sparse_certificate_effectivity/synthesize_fixture.py

Recognition boundary
--------------------
The algorithm recognizes this sufficient sparse support-switch certificate
for every input satisfying its positive-box interface. Acceptance establishes
the stated pointwise, rate-uniform inequality. In the usual nonexplosive
irreducible communicating-class setting, that inequality is a Foster input
for positive recurrence and a finite V-moment. It is not a complete
recurrence recognizer: failure or inapplicability outside this family does
not classify the chain, and this template is not claimed necessary.

Evidence/status is internal mathematical derivation plus the finite exact
formula diagnostic above. Independent proof review, external validation,
novelty, and priority are unresolved. The starting sparse finite-set
candidate is `outputs/research/reaction_dynamics/cycle3/leaves/exponential_foster_outside_gain/SPARSE_EXTENSION.txt`;
the complete-pair compact-box proof in `outputs/research/reaction_dynamics/cycle3/leaves/geometric_rate_box.txt`
is a comparison, not a premise for the sparse argument.

# Restart gate

## Highest ceiling

The strongest mathematical ceiling in this branch is the four-state posterior-cone mechanism: an expected cubic statistic is preserved through Bayesian products and yields strict second-moment saving. Coupled to weighted edge increments, this gives an internal candidate iff between reconstruction and a max-ray conserved-flow criterion for arbitrary locally finite edge-heterogeneous q=4 Potts trees. The consequence with greatest concrete utility is a finite certificate pipeline: finite sensor menus -> exact max-ray capacity recursion -> budget-optimal certificate placement -> conditional uniform-in-depth Bayes-advantage floor. It avoids a qualitative compactness step because all finite-tree flow minimax values are computed directly by backward recursion.

The finite recursion and knapsack DP are not themselves the main theorem. The original source N49 paper has a narrower homogeneous/bounded-degree theorem. The applied/networked-control payoff is also limited: the bound is weak, channel calibration is costly, BP is standard, and the certificate design can choose a strictly worse Bayes design.

## Missing load-bearing work

1. **Independent review of the posterior-cone product inequalities.** The exact cone closure/moment saving is the release-specific source dependency. The sibling audit reran the small scalar rational checker and 24 symmetry actions, but not the two long C++ product subdivision traversals. The source receipt is not a replay. Independently rerun the exact verifier at the pinned commit, check coverage and arithmetic, then have a probabilist inspect the posterior product/interface and all ties/boundaries.
2. **Independent proof review of the weighted heterogenous flow extension.** The reconstruction-to-flow and flow-to-reconstruction algebra appears consistent on hostile audit, but it remains a source-derived candidate. Review `C=460` local moments, pairwise degree-free aggregation, occupation potential for `lambda=1` and `lambda→0`, and the terminal sensor augmentation against a fresh derivation.
3. **Exact certificate/witness API.** The script computes fixed-scale lower capacities exactly, but the explicit flow allocator currently uses floating values for the demo. Before an operational certificate is claimed, add rational branch splits (or certified square-root intervals) and a verifier that checks conservation and every path-energy constraint with integer arithmetic.
4. **Meaningful engineering margin.** The explicit lower bound yields only `6.85e-5` MAP advantage at the demo capacity. A high-powered emulation can test it, but that is not an attractive operational control margin. Either derive materially stronger constants, select a tree/sensor regime with larger certified mass without hiding sensor cost, or stop application work.
5. **Calibration/model validation.** A positive `lambda^-` needs independent labeled transitions on each edge (or a justified shared calibration model); q-symmetry needs all four rows/confusion probabilities. If arbitrary channel matrices are observed, this theorem is inapplicable. Quantization, asynchronous links, correlated failures, and actuation remain unmodeled.

## Continue only if

- Both exact product-certificate traversals rerun independently with matching counts/results, or an analytic replacement removes the computational dependency.
- A second mathematical reviewer accepts the flow iff under the exact edge-varying, sensor-augmentation interface, including endpoints and local finiteness.
- An application partner can supply a q=4 broadcast-like instrument/process with calibrated channels, per-edge trial rates, target report latency, and an actual decision cost; the matched comparator must include centralized exact BP and the best single/census policies.
- A preregistered minimum practical MAP advantage exceeds the conditional theorem floor by enough to make the experiment scientifically or operationally relevant. If not, close the lead as a conditional model result.

If any check fails, preserve the finite capacity/DP and exact Bayes counterexample as standalone mathematical diagnostics, but do not describe the route as a new distributed-control advance.

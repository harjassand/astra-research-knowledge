7 October 2026. Internal mathematical reconstruction, not external validation.

VERDICT
The original population code/projection identification argument is correct under its exact X-only intervention interface. The broader correlated-support nullspace extension developed by causal_discovery is also correct, but its identifiability mechanism is an immediate rowwise application of Causal Dantzig Theorem 2 combined with a classical completely separating experiment family. The broad claims "cycles + confounding from covariance changes" and "logarithmic binary intervention settings" are established prior-art territory. The explicit constant-distance decoder, deterministic perturbation bookkeeping, and sample allocation are useful implementation/design lemmas; I have not found evidence making them a field-breaking contribution.

Strongest audit additions: (i) an exact repeated-signature counterexample; (ii) a target-setting cost lower bound T >= Delta*r*(d-1)/2; (iii) a direct Gaussian aggregate-estimation proof avoiding an unnecessary logarithmic multiplier in total sample count; (iv) the one-environment logged-shift comparator; (v) a rank-deficient correlated-shift nonidentifiability construction.

1. EXACT INTERFACE AND POPULATION PROOF
Observe independent draws of X in each labelled environment, with every coordinate observed. The realised intervention vector Z is NOT supplied. Target memberships are supplied. Let A=I-B be invertible with diag(A)=1, M=A^{-1}, and
  X^e = M(epsilon^e+Z^e).
Cov(epsilon^e)=Omega is arbitrary PSD but identical across environments; Cov(epsilon^e,Z^e)=0. No diagonal-noise, Gaussian, DAG, faithfulness or cycle-product assumption is needed for the population result. This is identification of the specified equilibrium SEM; dynamical convergence still requires its own stability assumption if claimed operationally.

Original shift contract: Cov(Z^e)=diag(a_i b_ei), a_i>0 fixed but unknown, baseline b_0=0, all-on b_*=1, and r binary code masks. Code columns c_i are known and distinct, with min Hamming(c_i,c_j)/r = Delta>0. Means are zero or covariances are properly centred.
  C = Sigma_* - Sigma_0 = M D_a M^T > 0,
  W=C^{-1/2}, Q=W M D_a^{1/2}, Q Q^T=I,
  P_l = W(Sigma_l-Sigma_0)W = Q diag(b_l)Q^T.
Each P_l is a commuting orthogonal projection. The decoder
  H_i=(1/r) sum_l [(1-b_li)P_l+b_li(I-P_l)]
has H_i q_j = [Hamming(c_i,c_j)/r]q_j. Hence its unique ground line is q_i with gap >=Delta. Also
  q_i^T W = a_i^{-1/2} e_i^T A,
  A_i = (q_i^T W)/(q_i^T W e_i).
The denominator is exactly +/-1/sqrt(a_i), and unknown strength/sign disappears. Known code labels resolve permutation, so the cycle-product restriction used by unknown-target BACKSHIFT is unnecessary here. Allowing unknown self-loops destroys the row scaling convention and changes the identification target.

Fixed strengths and diagonal shift covariance are essential to the literal projection formula, but not to all identification. With a diagonal all-on calibration and arbitrary positive-definite covariance on the exact active support, replace each whitened covariance by its spectral support projector. This restores P_l at population level. It needs a positive lower active eigenvalue and a correctly separated zero spectrum for a robust version.

2. NEWER NULLSPACE VARIANT: VALID, BUT EXISTING CAUSAL DANTZIG MECHANISM
Let 2r environments be r binary code masks and their complements. In every environment let Cov(Z^e)=K_e be arbitrary PSD, zero off target support T_e, and K_e positive definite on T_e. Keep the same baseline Omega and cross-uncorrelatedness. No calibration environment, fixed strength or diagonal within-support covariance is needed. Define
  S_i=(1/r) sum_{e:i notin T_e} (Sigma_e-Sigma_0)
     = M [(1/r)sum_{e:i notin T_e} K_e] M^T.
Exactly r environments exclude each i. Completely separating targets ensure their union is every j != i. Therefore the middle PSD matrix has kernel span(e_i), giving
  ker(S_i)=span(A^T e_i).
Normalize a null vector at coordinate i to recover A_i. If K_e >= a_min I_{T_e} and base code distance is >=Delta*r, then
  lambda_min_positive(S_i) >= a_min*Delta*s_min(M)^2.
Proof: the middle matrix dominates a_min*diag(Hamming(c_i,c_j)/r), and congruence by invertible M preserves rank and lowers nonzero eigenvalues by at most s_min(M)^2. This proof was independently checked.

Causal Dantzig already states the load-bearing theorem with precisely the baseline/full-rank-support/coverage assumptions for a target that is never intervened upon. For every target i, restrict to the environments excluding it, apply that theorem, and use a completely separating family for simultaneous coverage. Thus this construction is a reconstructed corollary, not a new correlated-cycle identifiability theorem.

3. DETERMINISTIC PERTURBATION AND SAMPLE COST
It is cleaner to estimate aggregate contrasts than to demand an accurate estimate of every P_l. Put beta_i=(1/r)sum_l b_li and define
  L_i=C^{1/2}H_i C^{1/2}
     = beta_i Sigma_* -(1-beta_i)Sigma_0
       +(1/r)sum_l(1-2b_li)Sigma_l.
Compute the smallest generalized eigenvector v of (hat L_i,hat C) and normalize by v_i. This is exactly the same row decoder as whitening hat C and finding the ground vector. It never requires inversion of an estimated global Q.

Suppose the errors in the TRUE C metric obey
  ||C^{-1/2}(hat C-C)C^{-1/2}|| <= t < 1,
  ||C^{-1/2}(hat L_i-L_i)C^{-1/2}|| <= t.
Normalize u=C^{1/2}v to Euclidean norm 1. In this coordinate system
  (H_i+E_L)u=lambda(I+E_C)u.
Rayleigh bounds give |lambda|<=t/(1-t). The eigen equation gives
  ||(I-q_i q_i^T)u|| <= 2t/[(1-t)Delta].
After choosing the sign, ||u-q_i|| <= 2sqrt(2)t/[(1-t)Delta]. Multiplication by W converts this to row-direction error
  h <= 2sqrt(2)t/[(1-t)Delta*sqrt(lambda_min(C))].
If h<=1/(2sqrt(a_i)), normalization gives
  ||hat A_i-A_i|| <= 2sqrt(a_i)(1+||A_i||)h.
This explicitly retains signal conditioning and normalization leverage. Exact graph support additionally needs a minimum nonzero coefficient threshold; a nonzero numerical estimate is not edge identification. An Euclidean covariance bound eta implies t<=2eta/lambda_min(C) because the aggregate coefficients have absolute sum 2.

Gaussian aggregate-estimation lemma (proved here; routine concentration, novelty unclaimed): assume centered Gaussian X^e and
  gamma=max_e ||C^{-1/2}Sigma_e C^{-1/2}||.
Allocate m independent samples to baseline, m to all-on, and n_l=ceil(m/r) to each mask. The total sample count is <=3m+r. Estimate second moments and form the linear aggregates above. Set
  tau=d log(9)+log(2(d+1)/delta),
  t=4 gamma [sqrt(2tau/m)+tau/m].
Then with probability >=1-delta, all d+1 relative error bounds for C,L_1,...,L_d hold with this t.

Proof: for a fixed unit direction in the C metric, each covariance estimate is an average of squared Gaussians. For a signed aggregate with coefficients c_e, its centered quadratic form has tail <=2exp(-s) at threshold
  2gamma [sqrt(v*s)+w*s],
  v=sum_e c_e^2/n_e, w=max_e |c_e|/n_e.
This follows by multiplying the exact centered chi-square moment-generating functions; their log is bounded by gamma^2 z^2 v/(1-2gamma|z|w). For C, v=2/m,w=1/m. For L_i, beta_i^2+(1-beta_i)^2<=1 and r/(r^2 ceil(m/r))<=1/m, so v<=2/m,w<=1/m. A 1/4 net of at most 9^d directions multiplies the scalar threshold by 2; union-bound only over d+1 aggregates, not all r contexts. This proves the stated t.

Consequences: for a fixed t, m=O(gamma^2[d+log(d/delta)]/t^2) suffices. Logarithmic environments need NOT multiply total samples. In the original model gamma=1+||D_a^{-1/2}Omega D_a^{-1/2}||, independent of mixing M but unbounded under arbitrary noise. Output row error still depends on the displayed signal/normalization factors. Only finite second moments do not support any uniform finite-sample guarantee: rare intervention spikes of probability p and magnitude sqrt(a_i/p) hide the covariance signal until n is of order 1/p. Sub-Gaussian or quantitative moment assumptions must be added.

The nullspace variant likewise permits direct averaging, with r inactive masks per target and the shared baseline. Taking n0=m and n_e=ceil(m/r) in all 2r paired masks costs <=3m+2r samples. The same signed-quadratic-form proof in Euclidean metric bounds all S_i errors using V=max_e||Sigma_e|| and variance factor <=2/m. Its gap bound depends on a_min Delta s_min(M)^2. Thus no inherent log multiplier in total Gaussian samples there either.

4. RESOURCE ACCOUNTING AND COMPARATORS
Environment count, distinct target settings, individual sample count, per-sample actuator exposures, stochastic input rank, and arithmetic are different resources.
For an r-bit code let w_l=|T_l| and T=sum_l w_l. Pair-distance double counting gives
  sum_l w_l(d-w_l) = sum_{i<j}Hamming(c_i,c_j)
                         >= Delta*r*d(d-1)/2.
Since w_l(d-w_l)<=d w_l,
  T >= Delta*r*(d-1)/2.
Hence r=Theta(log d) with a fixed relative distance necessarily uses Omega(d log d) target-setting activations. An all-on anchor adds d. Paired masks have exactly rd activations. If every target set has size <=s, then Delta<=2s/(d-1); constant separation needs dense experiments. This is setting/setup cost. Under the uneven sample allocation above, total per-sample target exposures are O(dm), rather than O(dm log d).

The SPD calibration step requires hat Sigma_* itself to have full rank: if v is in its nullspace then v^T(hat Sigma_*-hat Sigma_0)v<=0. Thus n_*>=d for raw second moments (n_*>=d+1 when centred). Full dense matrix-output data and d(d-1) causal coefficients are being acquired; the logarithmic number counts SETTINGS, not observed scalars. Covariance formation costs O(N d^2) ordinary arithmetic. Straightforward d dense ground-eigenvector solves cost O(d^4), plus O(rd^3) whitening/aggregate work and O(rd^2) covariance storage. Iterative constant-gap filters can reduce the decoder cost, but no executed large-scale cost claim is made. Arbitrary fixed precision or bit complexity is not automatic from these floating-point formulas.

If the experimenter records the actual injected Z values, the correct comparator is much stronger:
  Cov(X,Z)=M Cov(Z), M=Cov(X,Z)Cov(Z)^{-1}.
A single all-on randomized environment identifies M, hence B, despite confounding and cycles. Coding is therefore only useful when effective shift realizations are not observed. This restriction is now explicit in causal_discovery's interface.

If arbitrary bounded continuous variance ratios can be assigned and their ratios to the anchor are known, a single additional contrast has distinct labelled generalized eigenvalues and gives population identification. A scalar profile in a bounded interval has minimum gap at most range/(d-1); coding's constant joint separation is a stability design benefit, not an environment-count win over continuous actuation. Compare finite-sample performance under equal total actuation/signal budgets before asserting superiority.

5. EXPLICIT FALSIFICATION CONSTRUCTIONS
Repeated signatures: for 0<t<1 take
  A_+=[[1,t],[-t,1]], A_-=[[1,-t],[t,1]],
  a_1=a_2=1+t^2, Omega=(1+t^2)I.
Both are distinct stable two-cycles, diag(A)=1. Each baseline covariance is I. If the two variables always have the same bit b_e, each environment covariance is (1+b_e)I in BOTH models. Even identical supplied intervention strengths do not resolve this ambiguity. This proves that distinct signatures are necessary for uniform binary-design identification over the stated class; r>=ceil(log2 d) follows. It does not prove a lower bound for arbitrary real-valued interventions.

Correlated rank deficiency: suppose each environment contrast Delta_e is PSD, rank k_e, with known target support but covariance otherwise unknown. For each target i, its row A_i is constrained only to annihilate range(Delta_e) for e excluding i, plus diag(A)=1. If
  dim span_{e:i notin T_e}range(Delta_e)<d-1,
there is a nonzero row perturbation satisfying all those constraints. Choose a small invertible A' with diag1 and those same annihilations. Define K'_e=A' Delta_e A'^T and Omega'=A' Sigma_0 A'^T. These are PSD, retain the target zeros, and any active marginal variances that were strictly positive stay positive for small perturbations. Independent Gaussian noises with these covariances generate exactly the same observed Gaussian environments and a different B'=I-A'. Stability can be preserved by a sufficiently small perturbation from a strictly stable model. Therefore r=O(log d) rank-one correlated perturbation contexts cannot generically recover unrestricted dense rows. Full-rank support, or the aggregate rank d-1 condition, is substantive stochastic actuation resource.

Invariance violations: if Omega drifts, cross Cov(epsilon,Z) is nonzero, shifts hit unknown off-target coordinates, or B changes, the covariance cancellation can fail. Arbitrary environment-specific Omega permits any candidate B by setting Omega_e=A Sigma_e A^T and supplies no identification. These are mathematical interface obstructions, not data-quality warnings.

9. LATE ADDENDUM: EXACT WHOLE-ENVIRONMENT CORRUPTION THEOREM
causal_discovery subsequently proposed a clean scoped extension. I independently checked both proof directions. In the correlated full-rank-support model of Section2, let E known masks have directed counts
  n_ij=|{e:j in T_e,i notin T_e}|, s=min_{i!=j}n_ij.
The baseline is trusted and up to k entire environment distributions/covariances are arbitrary corrupted replacements, with unknown locations. Uniform population identification of A holds iff s>2k.

Sufficiency: any two fitting models each declare at most k masks corrupt, so their common clean set omits at most 2k masks. Every directed pair retains an environment separating j from i. For each i, the sum of their common excluding-i covariance contrasts has rank d-1 and a unique normalized kernel row; this row equals both A_i. All rows therefore agree.

Necessity: if a pair (i,j) has n_ij<=2k, compare A0=I and A1=I-t e_i e_j^T, t!=0. Both have diag1, are invertible and are acyclic/stable. Put L=A1^{-1}=I+t e_i e_j^T, baseline Sigma0=I, and split the separator set into U,V of size<=k. Outside that separator set, L preserves the target coordinate subspace. Observed covariances I+I_T therefore fit both models there, with K0=I_T and K1=A1 I_T A1^T. On U use I+I_T; on V use I+L I_T L^T. Model0 then needs only V corrupt and model1 only U corrupt; take invariant Gaussian base covariances Omega0=I and Omega1=A1A1^T, with independent Gaussian shifts. Full rank on all clean supports is preserved. Hence the same Gaussian observations admit distinct A under the same corruption budget. This counterexample uses unknown base Omega and unknown correlated intervention covariance; its necessity conclusion is not automatically a fixed diagonal-strength result.

This is an internally proved exact population theorem; I did not find its precise causal formulation in the bounded search. However its distance and experiment construction are classical, and the sufficient mechanism is robust consensus around Causal Dantzig. Newness or significance is NOT established.

Design consequences (elementary double counting):
  s*d(d-1) <= sum_e |T_e|(d-|T_e|) <= E*d^2/4,
so s<=E*d/[4(d-1)] and s>2k forces k/E<d/[8(d-1)], tending to1/8 as d grows. Conversely any fixed rho<1/8 permits O_rho(log d) random masks tolerating k=floor(rho E). With independent Bernoulli(1/2) targets, each n_ij is Binomial(E,1/4); Hoeffding and a union over d(d-1) pairs gives the margin with E=O(log(d/delta)/(1/4-2rho)^2). Thus1/8 is the supremal asymptotic context corruption fraction in this broad uniform model, with no positive-rate design asserted at its boundary.

An exact decoder can enumerate sets of E-k claimed clean masks, reconstruct normalized kernel rows, and check full-rank/PSD/support compatibility for each. It costs binomial(E,k) times polynomial(d,E), not automatically efficient for arbitrary E,k. If E=O(log d) and k is a fixed fraction of E this enumeration is polynomial in d, though with potentially impractical exponents. This does not provide a stable finite-sample robust estimator. Adversarial corruption magnitudes are unbounded; naive averages fail.

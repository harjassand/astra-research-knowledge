## Exact lift

Let `E` be a finite set of reaction labels in dimension `d`. For each label `e`, let

\[
 P_e(x)=\sum_{\alpha\in A_e}p_{e\alpha}x^\alpha,
 \qquad Q_e(x)=\sum_{\beta\in B_e}q_{e\beta}x^\beta,
 \qquad \rho_e=P_e/Q_e,
\]

where `A_e,B_e` are finite nonempty subsets of `R^d` and every displayed coefficient is strictly positive. The source supports are canonicalized: repeated exponents within one polynomial have already had their positive coefficients added. Negative or nonintegral exponents cause no problem on `R^d_{>0}`. The positivity of `Q_e` follows termwise.

Set

\[
D=\prod_{f\in E}Q_f,
\qquad G_e=P_e\prod_{f\ne e}Q_f.
\]

If the original equation is `dx/dt = sum_e a_e(t) rho_e(x) nu_e`, the increasing time change `dt/ds=D(x)` gives `dx/ds=sum_e a_e(t(s))G_e(x)nu_e`. The support of `G_e` is the finite Minkowski sum

\[
\Gamma_e=A_e+\sum_{f\ne e}B_f
=\left\{\alpha+\sum_{f\ne e}\beta_f:\alpha\in A_e,\;\beta_f\in B_f\right\}.
\]

For every `gamma` in `Gamma_e`, its coefficient is a finite sum of products `p_{e alpha} product_{f != e} q_{f beta_f}` over all tuples giving that gamma. Every summand is positive, so this coefficient is positive and no candidate source disappears. Thus the lifted diagram is the finite labelled edge set `gamma -> gamma+nu_e`, for `e in E` and `gamma in Gamma_e`. Duplicate source exponents are retained as labels or merged by adding their positive coefficients; either representation has the same endotactic test. The lifted coefficients times `a_e(t(s))` lie in one finite positive interval: for fixed coefficients take `kappa' = kappa min_{e,gamma} c_{e,gamma}` and `K' = K max_{e,gamma} c_{e,gamma}`. Shared `a_e` values only constrain the lifted rate paths; N33's larger class of independently varying rates contains these paths.

## All-directions equivalence, including ties

Fix any `r in R^d`, not necessarily rational, and write

\[
m^P_e(r)=\min_{\alpha\in A_e}r\cdot\alpha,
\qquad m^Q_e(r)=\min_{\beta\in B_e}r\cdot\beta.
\]

Because each factor is chosen independently in the finite product, minima are attained and

\[
\min_{\gamma\in\Gamma_e}r\cdot\gamma
=m^P_e(r)+\sum_{f\ne e}m^Q_f(r)
=\tau_e(r)+C(r),
\]

where `tau_e=m^P_e-m^Q_e` and `C(r)=sum_f m^Q_f(r)` is independent of `e`. This holds for every direction, including directions where any number of supports tie. More precisely, the minimizing lifted sources are the Minkowski sums of the minimizing supports of each factor; collisions among those sums do not change the attained minimum or delete an arrow because the collected coefficient remains positive.

Let `E_r={e:r·nu_e != 0}`. Every lifted copy of an edge has the same `nu_e`, so a parent edge is relevant exactly when all its lifted copies are relevant. If `E_r` is empty, both tests are vacuous. Otherwise, the smallest `r`-source among all relevant lifted edges is

\[
 C(r)+\min_{e\in E_r}\tau_e(r).
\]

An essential lifted arrow at this global minimum must have `tau_e(r)=min_{f in E_r}tau_f(r)` and its source `gamma` must itself minimize `r·gamma` over `Gamma_e`: its own minimum is at most `r·gamma`, while the displayed global minimum is no greater than that own minimum, so equality forces both. Conversely, every lifted source minimizer for every `tau`-minimizing relevant edge is at the global minimum. Therefore the set of parent labels represented among the ordinary essential lifted arrows is exactly the set of tropical-minimal relevant labels. With N33's ordinary convention applied at `w=-r`, the sign condition is

\[
w\cdot\nu_e<0\quad\Longleftrightarrow\quad r\cdot\nu_e>0.
\]

So ordinary endotacticity of the lifted diagram for every `w` is equivalent to the session's tropical criterion for every `r`: each `tau`-minimizing relevant label has `r·nu_e>0`. This includes cross-edge ties and within-support ties. If multiple labels share one lifted source, N33 checks every essential arrow there. If identical source-and-vector arrows are merged, all merged labels have the same sign, so the condition is unchanged.

**Neutral-edge detail:** when `r·nu_e=0`, all its lifted arrows are neutral and excluded from `E_r`. N33 defines the maximal source only among the essential (nonneutral) edges; neutral arrows cannot move the source maximum. Including neutral sources in that maximum would be a different definition and this equivalence would not follow. In particular, one must not maximize over every source vertex and then test only nonneutral arrows.

**Sign detail:** tropical uses a *minimum* `r`-source and demands `r·nu>0`; N33 uses a *maximum* `w`-source and demands `w·nu<0`; the substitution is `w=-r`. Using `w=r` would reverse the criterion.

## Scope boundaries

Strict positivity is doing two jobs: it makes `D>0` for the time change, and it prevents cancellations when product terms with duplicate exponent sum are collected. With signed generalized-polynomial coefficients, even an everywhere-positive denominator need not have growth given by its raw support minimum. For example

\[
Q(x,y)=x+y-2\sqrt{xy}+1=(\sqrt{x}-\sqrt{y})^2+1>0
\]

on the positive quadrant, but along `x=y=h^{-1}`, its value is `1`, while the raw support minimum in direction `r=(-1,-1)` is `-1`; hence `Q(h^r)` is not comparable to `h^{\min_{supp Q}r\cdot\beta}=h^{-1}`. This is a concrete failure of the session's support-to-growth premise after positivity is relaxed. Signed expansions are not N33 positive-rate diagrams.

This audit establishes the equivalence itself. It does not externally validate N33/OAI149, certify novelty, or show that a measured biochemical system has the assumed rational form. If the positive polynomial coefficients vary with time, fixed supports preserve the source identity, but N33's bounded-positive-rate interface additionally needs uniform positive lower and finite upper bounds on all coefficient products. Unbounded coefficients or coefficients approaching zero fall outside that interface.

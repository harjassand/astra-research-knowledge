Scope: exact matrix compatibility across arbitrarily many shared-label binary and odd-prime square blocks

RESULT
======

INTERNALLY-PROVED-CANDIDATE. Two common-coordinate constructions give exact
full-rank scalar solutions on arbitrary overlapping block families. For
binary 2x2 blocks, every coefficient field with more than three elements
works in every matrix dimension D, with rectangle holonomies t^2 I_D or
t^-2 I_D. For p-by-p blocks with p odd prime, any coefficient field
containing a primitive p-th root works, with holonomy
zeta^(2(u'-u)(v'-v)) I_D. In both cases I-W is invertible, and the blocks
may share labels arbitrarily.

The two-block identity/transpose fixture is a special case. It is not an
assignment to the actual N65 incidence complex: N65 uses larger blocks and
its coordinate maps have not been shown to admit the required common
two-coloring. The next decisive gate is to test that exact coloring condition
on a source-legal subconfiguration, or prove that the full block system
precludes it. No group-level conclusion is changed.

1. THEOREM AND EXACT HYPOTHESES
==============================

Let F be a field with |F|>3 and let D>=1. Let I be a set of labels and B a
finite family of blocks. Each b in B has a four-element subset I_b of I and
a bijection

  phi_b : I_b -> F_2 x F_2,   i |-> (alpha_b(i), beta_b(i)).

Assume there is one global coloring epsilon:I->F_2 such that for every block
b there exist c_b in F_2 and an orientation o_b in {alpha,beta} satisfying

  epsilon(i) = o_b(i)+c_b   for every i in I_b.

The orientation and offset may depend on b. The subsets I_b can overlap in
any pattern. Choose t in F^* with t^2 != 1; such a t exists because the
polynomial X^2-1 has at most two roots while F^* has more than two elements.

For each label i and u,v in F_2, define shared matrices

  X_iuv = x_iuv I_D,
  x_iuv = t^-1 if epsilon(i)+u+v=0 in F_2, and 1 otherwise.

For an alpha-oriented block (epsilon=alpha_b+c_b), set

  L^b_{u,j}=t I_D if u+j+c_b=0, and I_D otherwise;
  R^b_{v,k}=I_D for all v,k.

For a beta-oriented block (epsilon=beta_b+c_b), set

  L^b_{u,j}=I_D for all u,j;
  R^b_{v,k}=t^-1 I_D if v+k+c_b=0, and I_D otherwise.

All subscripts j,k are in F_2. Then every triangle equation

  L^b_{u,alpha_b(i)+v} X_iuv (R^b_{v,beta_b(i)+u})^-1 = I_D

holds. Furthermore, for every label i and every ordered nondegenerate
rectangle of its 2x2 array, W_i is either t^2 I_D or t^-2 I_D. Hence

  rank_F(I_D-W_i)=D.

This is an exact finite-algebra statement. It makes no approximation, uses no
oracle, and has no dependence on a group presentation beyond the displayed
triangle wiring.

2. PROOF
========

First suppose b is alpha-oriented. Since
alpha_b(i)=epsilon(i)+c_b, the condition selecting L is

  u + (alpha_b(i)+v) + c_b = epsilon(i)+u+v = 0.

If this holds then L=tI_D and X=t^-1 I_D, while R=I_D. Otherwise L=X=R=I_D.
In either case L X R^-1=I_D.

If b is beta-oriented, beta_b(i)=epsilon(i)+c_b. The condition selecting R
is

  v + (beta_b(i)+u) + c_b = epsilon(i)+u+v = 0.

If it holds then X=R=t^-1 I_D, so X R^-1=I_D; otherwise X=R=I_D. Again
L X R^-1=I_D. Because X depends only on epsilon(i),u,v, this argument is
simultaneous for all blocks containing i and proves exact compatibility of
the shared variables.

For the canonical rectangle order (u,v)=(0,0),(1,0),(1,1),(0,1), if
epsilon(i)=0 then its scalar holonomy is

  t^-1 * 1^-1 * t^-1 * 1^-1 = t^-2.

If epsilon(i)=1 it is

  1 * (t^-1)^-1 * 1 * (t^-1)^-1 = t^2.

Reversing either side replaces W by W^-1; both possible scalars remain
different from 1 because t^2 != 1. Therefore I_D-W is a nonzero scalar
multiple of I_D, and has rank D. This completes the proof.

For the field-size claim, |F|>3 implies |F^*|>2. At most two nonzero
elements solve t^2=1, so one can choose a non-root. This applies to finite
fields of any characteristic and to infinite fields.

3. TWO-BLOCK TRANSPOSE INSTANCE
===============================

Let labels be i=(a,c) in F_2^2. Block 0 uses
phi_0(a,c)=(a,c); block 1 uses phi_1(a,c)=(c,a). The shared color
epsilon(a,c)=a is the first coordinate in block 0 and the second coordinate
in block 1. The theorem applies with c_0=c_1=0 and opposite orientations.
Explicitly, for any t^2!=1:

  L^0[u,j]=t when u=j, else 1;       R^0[v,k]=1;
  L^1[u,j]=1;                         R^1[v,k]=t^-1 when v=k, else 1.

The common table is independent of c and is

  X_(a,c,u,v)=t^-1 iff a+u+v=0, otherwise 1.

The four canonical rectangles are W=t^-2 for a=0 and W=t^2 for a=1.
Taking t=2 in F_5 gives a scalar witness over F_5; scalar multiples of I_D
give one in every dimension. The prior two-block leaf also has an explicit
noncommuting GL_2(F_3) witness and an exhaustive binary-linear proof that
scalar GL_1(F_3) assignments force W=I. That complementary result is in
`work/programmes/groups_operator/leaves/common_kernel_word_cost/CYCLE5_RESULT.txt`.

4. ODD-PRIME COLOR EXTENSION TO p-by-p BLOCKS
============================================

Let p be an odd prime, F a field containing an element zeta of exact
multiplicative order p, D>=1, and let an arbitrary finite overlapping
family of blocks have label sets I_b of size p^2 with bijections

  phi_b:I_b -> F_p x F_p,   i |-> (alpha_b(i), beta_b(i)).

Assume a global epsilon:I->F_p and, for each b, an offset c_b in F_p and
orientation o_b in {alpha,beta} such that epsilon(i)=o_b(i)+c_b on I_b.
Indices u,v,j,k lie in F_p. Put

  X_iuv = zeta^((epsilon(i)+u+v)^2) I_D.

For alpha-oriented b, set

  L^b_{u,j}=zeta^(-(j+c_b+u)^2) I_D,  R^b_{v,k}=I_D.

For beta-oriented b, set

  L^b_{u,j}=I_D,  R^b_{v,k}=zeta^((k+c_b+v)^2) I_D.

The alpha equation follows from j=alpha_b(i)+v and
epsilon=alpha_b(i)+c_b; the beta equation follows from
k=beta_b(i)+u and epsilon=beta_b(i)+c_b. In either orientation the
triangle identity L X R^-1=I_D holds exactly, including across arbitrary
overlaps because X is defined only from the global epsilon.

For u!=u' and v!=v', the ordered rectangle is

  W_i = X_iuv X_iu'v^-1 X_iu'v' X_iuv'^-1
      = zeta^(2(u'-u)(v'-v)) I_D.

The exponent is nonzero in F_p since p is odd and both differences are
nonzero. Thus zeta's exact order p implies W_i!=I_D and
rank_F(I_D-W_i)=D. This is an exact full-rank solution for every
nondegenerate rectangle in every block.

For example, p=3 and F=F_7 with zeta=2 gives a three-row/three-column
assignment; 2 has order three modulo seven. The verifier checks three
overlapping 3x3 blocks over F_7 (243 triangles, 648 ordered rectangles) and
three overlapping 5x5 blocks over F_11 (1875 triangles, 20,000 ordered
rectangles), in dimensions D=1,2. For arbitrary odd p the proof is
symbolic. Finite fields containing an element of order p exist: choose any
prime characteristic ell different from p and pass to the finite extension
degree ord_p(ell), so p divides ell^ord_p(ell)-1.

This does not yet cover the N65 full blocks. Their first coordinate sizes
are r and r+1, while the second coordinate sizes vary; they are not shown to
be p-by-p blocks for one common p, and no matching global epsilon has been
acquired. In particular, the theorem is a conditional adversarial
construction, not a counterexample to N65.

5. CONSEQUENCE AND PRECISE BOUNDARY
==================================

The local triangle equations, even with a second transpose-related block
sharing every X_iuv, do not force any rectangle matrix I-W to be singular.
The binary theorem handles arbitrary overlaps in aligned 2x2 blocks; the
odd-prime theorem handles arbitrary overlaps in aligned p-by-p blocks when
the field contains a primitive p-th root of unity. A proposed no-go argument
based only on the number of shared blocks is therefore false; it must use
failure of coordinate alignment, incompatibility of the needed field roots,
mixed/non-prime dimensions, interpolation identities, or another global
constraint.

There is also a useful adversarial diagnostic for a claimed full finite
presentation. If the actual coordinate maps on every relevant block admit
one epsilon with the stated orientation/offset property, this construction
assigns all edge matrices in GL_D(F), satisfies every triangle exactly, and
keeps every rectangle nonidentity. Since GL_D(F) is finite when F is finite,
this would induce a homomorphism to a finite (hence sofic) group separating
the entire listed rectangle family. That would contradict the N65
finite-permutation obstruction if all its premises and that exact rectangle
list are valid. Consequently, a correct N65 instance cannot satisfy the
alignment condition on every required block. This is a conditional diagnostic,
not an assertion that N65's maps do satisfy it.

The binary theorem applies to 2x2 coordinate blocks over F_2; the odd-prime
theorem applies to p-by-p blocks over F_p with a coefficient-field root of
unity of order p. N65's audited candidate uses dimensions at least r=19000,
with first coordinate moduli r or r+1 and second moduli at least r. Those
mixed dimensions are not covered, and the actual maps have not been shown
to align through a common nontrivial coordinate quotient. No large-block
solution, new nonsofic proof, or counterexample is established here.

One exact obstruction to a natural extension is worth recording. A common
quotient of the cyclic row-coordinate groups C_r and C_(r+1) has order
dividing gcd(r,r+1)=1, so it is trivial. Equivalently, a construction that
requires the same nontrivial one-step image for both row cycles cannot work.
This rules out that specific shared-character route across the adjacent
N65 row moduli. It does not rule out different images in a larger color
group, using the second coordinate, non-homomorphic colorings, noncommuting
matrices, or another representation.

5. COST, BASELINE, FALSIFIERS
============================

For the binary construction, the cost is O((|I|+|B|)D^2) entries if
materialized, or O(|I|+|B|) symbolic data plus labels; it uses one field
element t and its inverse. For the odd-prime construction, materializing
the matrices costs O((|I|+|B|)p^2D^2) entries, including p^2 shared X
matrices per label and p^2 L/R matrices per block. A symbolic encoding
stores epsilon per label and orientation/offset per block, in addition to
the supplied coordinate maps. Precomputing the p powers of zeta costs O(p)
field multiplications; afterward each variable takes O(1) lookups and field
operations. No large incidence acquisition or oracle is assumed.

Strongest equal-information baseline: the one-block exact construction and
the two-block transpose witnesses in the prior leaf. The present results
add arbitrary overlaps for binary and odd-prime coordinate systems under
an explicit common-coordinate condition. They do not attempt a full N65
coordinate assignment.

Falsifiers: (a) a triangle fails under the displayed formulas; (b) a
rectangle exponent is zero for distinct row and column indices; or (c) a
computed full-instance alignment certificate meets the hypotheses but its
finite GL assignment fails to preserve one required rectangle. The verifier
checks three overlapping binary blocks over F_5,F_7,F_11 and three
overlapping p=3 blocks over F_7, in dimensions D=1,2.

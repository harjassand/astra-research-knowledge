# Audit of the every-output-sector rank-Q score comparison

Scope: quantum_tail_precision.txt §§3–5, checked against the Schur reduction,
rank-Q projector lemma, and score identity in quantum_branch.txt §§2–5. The
spin-band estimate in tail §4 is used as stated and is not re-audited here.

## Verdict and hypotheses

The comparison in tail §3 is valid with the stated constant
\[
c_\Delta=1/786432,
\qquad
\Delta_{jk}\ge \frac{c_\Delta}{rQ^3}
\]
for every input spin \(j\in[16Q,32Q]\), every output spin \(k\), and every
nonzero rank-at-most-\(Q\) Kraus component. No gap was found in tail §5's
conversion to (5.1). The argument does permit arbitrary sector-changing
decoders and places no output-sector marginal constraint.

The shared critical-regime assumptions are important: \(n\) is sufficiently
large, \(c_0\le r\sqrt n\le c_1\), and hence \(r\le1/2\); \(Q\) is an integer
with \(1/r\le Q\le n/128\). The selected \(j\)'s are allowed Schur spins.
The upper Q restriction supplies \(32Q\le n/4\), so the input band exists
inside the Schur range. The lower restriction \(rQ\ge1\) is used in each
comparison with the claimed \(1/(rQ^3)\) scale.

## Pair deficit and its use

For a nonzero Kraus operator \(A:V_j\to V_k\), set
\[
 \psi_A=|A\rangle\rangle/\|A\|_{\rm HS},\quad
 h_A=\langle\psi_A|H|\psi_A\rangle,\quad
 H=-\sum_i J_i^{(j)}\otimes J_i^{(k)}.
\]
The vector \(\psi_A\) has Schmidt rank at most \(Q\). With
\(m=\min(j,k)\), the top eigenvalue of \(H\) is \(jk+m\); write
\(g=jk+m-h_A\ge0\). Branch (5.4), with the same input time-reversal
convention as branch §4, gives the output score of this Kraus component.
Subtracting it from the target score \(T_j=a_j^2/2+a_j^2/j\) gives
\[
 \Delta_{jk}(A)\ge
 \frac{(a_j-a_k)^2}{2}
 + \left(\frac{a_j^2}{j}-\frac{a_ja_k}{\max(j,k)}\right)
 + \frac{a_ja_k\,g}{jk}.                                      \tag{A}
\]
For \(k\le j\), the middle term is \(a_j(a_j-a_k)/j\ge0\), since \(a\)
increases. For \(k\ge j\), it is
\(a_j(a_j/j-a_k/k)\ge0\), since \(a(u)/u\) decreases. Thus every pair has
nonnegative deficit, and the middle term alone can be used in the far cases.
For \(k=0\), the output score is zero and
\(\Delta_{j0}=T_j\ge a_j^2/2\).

## Near output: \(|j-k|\le M/(16Q)\)

Let \(M=\max(j,k)\), \(m=\min(j,k)\). Here \(M\ge j\ge16Q\), so branch
(4.6) applies and gives \(g\ge M/(32Q)\). Also \(m\ge15M/16\), and in
particular \(k\ge15j/16\). Since \(rj\ge16\) and \(rk\ge15\), branch
(2.4) implies \(a_j,a_k\ge1/3\) (in fact it gives much larger values).
The last term in (A) therefore yields
\[
 \Delta_{jk}\ge \frac{1}{9}\frac{M}{32Qjk}
 =\frac{1}{288Qm}
 \ge\frac{1}{288Qj}
 \ge\frac{1}{9216Q^2}
 \ge\frac{1}{9216rQ^3}.
\]
The last step uses \(rQ\ge1\). This is stronger than the common
\(1/(786432rQ^3)\) bound.

## Far lower output: \(k<j(1-1/(16Q))\)

Put \(s=1/(16Q)\) and \(k_0=j(1-s)\). For \(k>0\), \(k<k_0\), and strict
monotonicity of \(a\), followed by branch (2.3), gives
\[
 a_j-a_k\ge a(j)-a(k_0)
 \ge \int_{k_0}^j\frac{du}{4r(u+1)^2}
 \ge \frac{j/(16Q)}{4r(j+1)^2}
 \ge \frac{1}{256rjQ}.
\]
Here \(k_0\ge15j/16\ge15Q\ge15/r\), so (2.3) is applicable throughout
the integration interval; the last inequality uses
\((j+1)^2\le4j^2\). As \(a_j\ge1/3\), the middle term in (A) obeys
\[
 \Delta_{jk}\ge\frac{a_j(a_j-a_k)}{j}
 \ge\frac{1}{768rj^2Q}
 \ge\frac{1}{786432rQ^3},
\]
where \(j\le32Q\) supplies the final factor \(32^2\).

For \(k=0\), \(T_j\ge1/18\) from \(a_j\ge1/3\). Meanwhile
\(rQ^3\ge r(1/r)^3=1/r^2\ge4\), so
\(1/(786432rQ^3)\le1/(4\cdot786432)<1/18\). The separate zero-output
case therefore meets the same bound.

## Far higher output: \(k>j/(1-1/(16Q))\)

Set \(k_0=j/(1-s)\). Since \(rj\ge16rQ\ge16\), branch (2.5) applies on
\([j,k_0]\). Monotonicity of the smooth extension \(a(u)/u\) and integration
give
\[
 \frac{a_j}{j}-\frac{a_k}{k}
 \ge \frac{a(j)}{j}-\frac{a(k_0)}{k_0}
 \ge\int_j^{k_0}\frac{du}{2u^2}
 =\frac{1}{32jQ}.
\]
Thus the middle term in (A) is at least
\[
 \Delta_{jk}\ge\frac{a_j}{32jQ}
 \ge\frac{1}{96jQ}
 \ge\frac{1}{3072Q^2}
 \ge\frac{1}{3072rQ^3}.
\]
The last two steps use \(j\le32Q\) and \(rQ\ge1\). This bound is again
stronger than \(1/(786432rQ^3)\). It covers arbitrarily distant high
outputs because only the comparison point \(k_0\) is used.

The three regions cover all \(k\): for \(k\le j\), the complement of the
near condition is exactly the far-lower condition; for \(k\ge j\), it is
exactly the far-higher condition. Equality at a boundary is included in the
near case.

## Kraus rank, weights, and sector transport

The normalized-vector estimate is applied to each nonzero Kraus component,
not to an unnormalized operator. For the postprocessed channel from the
Schur direct sum to itself, write its sector components as
\(A_{kjz}:V_j\to V_k\), with \(\operatorname{rank}A_{kjz}\le Q\). The
diagonal part of trace preservation gives, for each input \(j\),
\[
 \sum_{k,z}A_{kjz}^{\dagger}A_{kjz}=I_j,\qquad
 w_{jkz}=\|A_{kjz}\|_{\rm HS}^2/(2j+1),\qquad
 \sum_{k,z}w_{jkz}=1.
\]
The prior-averaged input in \(V_j\) is \(I_j/(2j+1)\), so these are the
actual conditional transition weights. Multiplying each normalized
component's score deficit by its own weight is essential; the proof does
not sum unweighted Kraus deficits.

For an encoder into a register of dimension at most \(Q\), followed by any
label-dependent decoder, each composite Kraus operator has rank at most
\(Q\). Pinching in output Schur sectors multiplies Kraus operators by row
projections and preserves this rank bound; restricting to input sector \(j\)
does likewise. Tracing/regenerating parameter-independent multiplicities
only introduces more Kraus labels, each still of rank at most \(Q\).
Classical labels, arbitrary decoder choices, and sector transport therefore
fit the above decomposition. No condition on \(\sum_j P_j w_{jkz}\), or on
the output-sector marginal, is used. Equivalently, the score observable is
already block diagonal, so off-diagonal output blocks cannot affect it.

Because (A) is nonnegative for every input/output pair, sectors outside the
selected input band cannot offset the selected band's positive deficit.
Within that band, the uniform \(c_\Delta/(rQ^3)\) bound and
\(\sum_{k,z}w_{jkz}=1\) imply the score-gap lower bound used in tail §5.

## Check of the §5 constant

Using the stated tail (4.3), the selected-band contribution is
\[
 2e\ge
 \frac{1}{786432rQ^3}\,
 4096e^{-2c_1^2/3}\frac{Q^3}{n^{3/2}}
 e^{-(8192/3)Q^2/n}
=\frac{e^{-2c_1^2/3}}{192rn^{3/2}}\,
 e^{-(8192/3)Q^2/n}.
\]
Dividing by 2 gives the \(1/384\) in tail (5.1). Since
\(r\sqrt n\le c_1\), \(1/(rn^{3/2})\ge1/(c_1 n)\), yielding exactly
\(c_T=e^{-2c_1^2/3}/(384c_1)\) and \(C_T=8192/3\).

The later use \(Q_0=\lceil1/r\rceil\le n/128\) is valid for sufficiently
large \(n\), since \(1/r\le\sqrt n/c_0\). Also \(r\le1/2\) gives
\(Q_0\le3/(2r)\), hence \(Q_0^2/n\le9/(4c_0^2)\), as stated in (5.2).
These are additional large-\(n\) conditions for the \(Q_0\) corollary, not
extra conditions in the sectorwise estimate itself.

## Audit boundary

This verifies the score comparison conditional on branch §§2–5, including
the rank-Q projector/energy lemma and the exact Schur score identity, and
uses tail §4.3 as an input. It is an internal derivation check, not external
validation or a priority assessment.

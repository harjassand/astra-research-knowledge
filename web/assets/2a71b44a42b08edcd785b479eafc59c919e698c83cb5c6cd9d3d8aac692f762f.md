# Cycle 2: robust multitype extinction certificate

## Result in one sentence

A common positive linear weight gives a global, schedule-uniform first-moment bound for a finite-type branching population under arbitrary switching among a prespecified set of pulse rate matrices; it yields an explicit finite-horizon upper bound on relapse after adding source/escape terms, but it is a standard sufficient Lyapunov certificate and can be too conservative or infeasible. It is a candidate decision rule only if all hazards and post-pulse establishment probabilities are bounded simultaneously from data and survive a held-out test.

This is a theorem conditional on the branching model and rate bounds, not evidence that a particular tumor has these dynamics or that any drug pulse works.

## Model and robust condition

Let X(t) in N^m be a column vector of counts for m tracked phenotypes/genotypes. In a fixed pulse environment, a type-i cell:

- makes one additional type-i daughter at rate b_i;
- dies at rate d_i;
- switches one-for-one from i to j at rate s_ji, for j != i.

Under a prespecified external schedule, the lineages branch independently. A more general schedule may choose dose predictably from population history; in that feedback case the shared control can couple lineages, but the generator inequality below still applies if the per-cell hazards retain this linear form. External immigration into tracked types has predictable intensity vector eta(t). The mean drift matrix is Metzler, with column i given by

A_ii = b_i - d_i - sum_{j != i} s_ji,
A_ji = s_ji for j != i,

so that under a deterministic rate matrix, d E[X]/dt = A E[X] + eta. Under a state-adapted treatment rule A(t) can be random and correlated with X(t), so the mean equation is instead d E[X]/dt = E[A(t)X(t)] + E[eta(t)]. The pulse-rate uncertainty set Acal contains every matrix induced by every allowed dose and every rate vector in the simultaneous confidence set. It must also contain interpolation points if a continuous range of dose intensities is allowed.

A robust certificate consists of one vector w >> 0 and delta > 0 such that

    w^T A <= -delta w^T       componentwise for every A in Acal.       (1)

Normalize sum_i w_i = 1. Given a candidate delta, (1) is linear in w; feasibility can be checked by linear programming with w_i >= rho > 0. Bisection in delta finds the largest certified margin. If A depends affinely on rates over a compact polytope, checking its vertices is sufficient. With independent rate intervals, the worst endpoint for each coefficient can be selected separately for fixed w; with correlated uncertainties, optimize over the joint confidence polytope. A positive delta establishes a common certificate across arbitrary switching; checking each matrix separately for stability is not enough to establish this.

For two reversible phenotypes, 0 <-> 1, with 0-to-1 rate alpha and 1-to-0 rate beta,

    A = [[b0 - d0 - alpha, beta],
         [alpha, b1 - d1 - beta]].

The two inequalities in (1) are

    w0 (b0-d0) + alpha (w1-w0) <= -delta w0,
    w1 (b1-d1) + beta  (w0-w1) <= -delta w1.

For independent rectangular rate intervals, the exact robust left side for the first row is
w0 (b0_upper - d0_lower) + max{alpha_lower (w1-w0), alpha_upper (w1-w0)};
the second is analogous with beta and the endpoint maximizing beta (w0-w1). This makes explicit why net growth b_i-d_i alone is not enough: the switch terms and turnover rates matter, and the signs depend on the common weights.

## Global bound, including source and escape

Set V(x)=w^T x, w_min=min_i w_i, and h(t)=w^T eta_upper(t), where eta(t) <= eta_upper(t) componentwise. The continuous-time branching generator satisfies

    L_t V(x) = w^T A(t) x + w^T eta(t)
             <= -delta V(x) + h(t).

Dynkin's formula and Gronwall therefore give, for any adapted schedule with A(t) in Acal,

    E[V(X(t))] <= B(t)
      := exp(-delta t) V(X(0))
         + integral_0^t exp(-delta (t-s)) h(s) ds.                 (2)

This is uniform over the schedule; it does not require independence between the chosen treatment mode and observed counts, provided every realized rate matrix remains in Acal. With eta=0, zero is absorbing, V(X) >= w_min whenever X != 0, and thus

    P(X(t) != 0) <= B(t)/w_min
                 = exp(-delta t) V(X(0))/w_min.                    (3)

Consequently, without immigration, the population becomes extinct almost surely from every finite initial state. This is a bound, generally loose; it is not an exact extinction probability.

Suppose maintenance starts at pulse end T. For each remaining type i, let pi_i^+ be a valid upper bound on its establishment probability under the post-pulse regimen. For eventual survival in a time-homogeneous multitype birth-death-switching process, compute extinction probabilities as the least fixed point q in [0,1]^m of the offspring generating-function equations. In this simple model,

    q_i = [b_i q_i^2 + d_i + sum_{j != i} s_ji q_j]
          / [b_i + d_i + sum_{j != i} s_ji],
    pi_i = 1 - q_i.

For a threshold-based relapse endpoint, use a valid bound on the corresponding hitting probability instead. Use the supremum of pi_i over the post-pulse confidence set for pi_i^+. Then, conditional on X(T),

    P(any residual lineage establishes | X(T))
       = 1 - product_i (1-pi_i)^{X_i(T)}
       <= sum_i pi_i^+ X_i(T)
       <= C_R V(X(T)),
    C_R := max_i pi_i^+ / w_i.

Thus the residual-lineage risk is at most C_R B(T).

Now allow pulse-time escape: a controlled type-i cell can generate one type-j founder outside the tracked controlled dynamics at rate at most kappa_upper,ji(s) per cell. Let rbar_j(s;T) upper-bound its probability of eventual establishment after experiencing the remaining pulse schedule and then maintenance. In general this probability depends on T-s; using the post-pulse establishment bound pi_j^+ alone is valid only if this founder is unaffected by the remaining pulse. For feedback schedules or uncertain continuations, take a valid supremum over the admissible remaining schedules and parameter confidence set. For a known time-inhomogeneous multitype pulse, let G_j(s;z) be the probability-generating function of type counts at T from one type-j founder at s. Then r_j(s;T)=1-G_j(s;q_post), where q_post is the post-pulse extinction vector. For the birth/death/switch model above, its exact backward equations are

    -dG_i(s;z)/ds = b_i(s)(G_i^2-G_i) + d_i(s)(1-G_i)
                     + sum_{k != i} s_ki(s)(G_k-G_i),
    G_i(T;z)=z_i.

With uncertain rates, take a valid upper bound over the confidence set. If it is not identified, setting rbar_j=1 is valid but may make the bound useless. The expected number of successful escape founders during the pulse, hence its chance of producing at least one relapse, is at most

    integral_0^T C_E(s;T) B(s) ds,
    C_E(s;T) := max_i [sum_j kappa_upper,ji(s) rbar_j(s;T)/w_i]. (4)

If the escaped founder is a mutation-born daughter at an otherwise ordinary division, A must describe the tracked controlled population after omitting that escaped daughter (for example, use only the non-escape division rate in b_i), and kappa must include the corresponding mutation-birth rate. This prevents counting that same offspring both in A and as an external escape source.

Any direct source creating founders during the pulse also requires the remaining-pulse success probability and has an additional union-bound term
J_pulse(T)=integral_0^T sum_j iota_upper,j^pulse(s) rbar_j(s;T) ds.
Direct post-pulse immigration over the follow-up window [T,T+H] contributes
J_post(T,H)=integral_T^{T+H} sum_j iota_upper,j^post(s) pi_j^+ ds.
Immigration into the tracked, pulse-controlled types is already represented by eta in (2). A genotype born by mutation that remains subject to the same pulse dynamics belongs in X and A; it belongs in kappa/iota only when it escapes the tracked controlled dynamics. For an independent Poisson source under a fixed schedule that does not depend on its arrivals, with exact time-to-go success probabilities p_j(s;T), the probability of at least one successful direct pulse immigrant is exactly 1-exp(-integral_0^T sum_j iota_j(s)p_j(s;T) ds). Replacing p_j by a valid upper bound gives a safe bound; the linear J terms above use the union bound. A direct post-pulse source has the analogous thinning expression under a fixed post-pulse regimen. Under feedback or source-dependent schedules, use a conditional success-probability upper bound and the union bound instead.

Combining the routes gives the finite-horizon certificate

    P(relapse by T+H)
       <= Rbar(T,H)
       := C_R B(T) + integral_0^T C_E(t;T) B(t) dt
          + J_pulse(T) + J_post(T,H).                             (5)

This counts some routes more than once, which is conservative. It upper-bounds clinical relapse if establishing a lineage is necessary for the defined relapse endpoint. If a positive post-pulse source persists forever and has positive establishment probability, eventual relapse probability can be one; a finite H bound must not be described as cure or permanent extinction. If confidence sets fail to bound a hidden escape type or source, report UNKNOWN.

### Constant-rate closed form and minimum duration

For a fixed pulse dose, suppose h(t)=h, C_E(s;T)=C_E is constant (for example, escape types with pulse dynamics identical to post-pulse dynamics and constant κ and π), direct pulse-source success intensity is j, and J=J_fixed + J_post is constant in T (for example, fixed follow-up length H and stationary post-pulse source). Let a=h/delta and V0=V(X(0)). Then

    B(t)=a+(V0-a) exp(-delta t),

and (5) becomes

    Rbar(T)=B0 + L T + K exp(-delta T),                            (6)
    B0 = J + C_R a + (C_E/delta)(V0-a),
    L  = C_E a + j,
    K  = (V0-a)(C_R-C_E/delta).

The duration certificate is

    T_epsilon = inf{T >= 0 : Rbar(T) <= epsilon}.                  (7)

It is infinite if the bound never reaches epsilon. This definition is safer than assuming longer pulses always reduce risk: escape and immigration can create a nonzero floor or make the bound rise. In the clean no-escape case C_E=j=0, V0>a, and
J+C_R a < epsilon < J+C_R V0, it reduces to

    T_epsilon = (1/delta) log( C_R (V0-a)/(epsilon-J-C_R a) ).     (8)

If h=0, this is delta^{-1} log(C_R V0/(epsilon-J)). No finite T reaches a target at or below the immigration floor J+C_R a. If V0 <= a, the bound does not decay toward the floor.

For completeness, when L>0, K>0, and delta K>L, Rbar first decreases and then increases, with minimum

    Rbar(T*) = B0 + (L/delta) [1 + log(delta K/L)],
    T* = (1/delta) log(delta K/L).

If epsilon is below its minimum, no duration is certified. If Rbar(0)>epsilon and epsilon is at least that minimum, the first downward crossing (when it exists) is

    T_epsilon = (epsilon-B0)/L
       + (1/delta) W_{-1}[-(delta K/L)
                           exp(-delta (epsilon-B0)/L)],            (9)

where W_{-1} is the lower real branch of the Lambert W function. Boundary cases use the infimum definition (7). If treatment intensity u changes both rates and cost, calculate T_epsilon(u) from (5) and minimize a declared cost such as D_epsilon(u)=c(u)T_epsilon(u) over feasible u. This is a dose-minimal rule only relative to that declared cost and feasible-set model; it is not a toxicity or clinical utility result.

## Statistical certificate: what measurements buy it

A common w is only useful if all rates entering A, escape/source bounds, initial V0, and maintenance pi_i^+ have simultaneous uncertainty coverage. Suppose M prespecified rate channels each have a Poisson count N_k with fixed, externally specified exposure E_k and marginal law N_k ~ Pois(lambda_k E_k). Bonferroni Garwood intervals have familywise coverage at least 1-alpha; channel independence is not required:

    L_k = chi2_quantile(alpha/(2M), 2N_k)/(2E_k),
    U_k = chi2_quantile(1-alpha/(2M), 2(N_k+1))/(2E_k),

with L_k=0 when N_k=0. For one-sided upper bounds use quantile 1-alpha/M; with zero observed events,

    U_k = log(M/alpha)/E_k.                                        (10)

For target upper rate lambda_star and observed count N_k=n, the exact exposure requirement is E_k >= chi2_quantile(1-alpha/M, 2(n+1))/(2 lambda_star); equation (10) is the n=0 case. These are Garwood exact Poisson intervals [Garwood (1936)](https://doi.org/10.1093/biomet/28.3-4.437).

As an explicit lower-bound design illustration, two states, four pulse conditions, and six hazards per condition (two births, two deaths, two switches) give M=24. At familywise 95%, log(24/0.05)=6.174. Zero events therefore require at least 6,174 cell-days of valid exposure per channel to upper-bound a hazard below 0.001/day, or 61,738 cell-days per channel for 0.0001/day. Across 24 channels that is about 148,176 channel-cell-days and 1,481,712 channel-cell-days, respectively. These are exposures, not counts of wells or mice. Estimating source, escape, maintenance, and additional clone rates increases M and the required exposure. If events are observed, use the stated Garwood upper formula rather than the zero-count shortcut.

The exact-Poisson calculation is valid only for the stated count/exposure design and a correctly specified constant hazard. In lineage assays, cell-time at risk is often random and affected by the same division/death events; plugging that random exposure into a Poisson interval is not automatically exact. Use externally fixed opportunities/exposures where feasible, or construct a simultaneous confidence set from the full continuous-time branching/counting-process likelihood with coverage validated under the actual observation and censoring process. Mutation probability per division is binomial, not a Poisson cell-time rate, and needs its own simultaneous exact interval. Overdispersion, barcode dropout, state misclassification, and clone dependence also widen uncertainty.

A simultaneous confidence region matters because w, delta, dose, and possibly the best certificate will be selected after observing the data. If the full prespecified parameter vector lies in a 1-alpha confidence region with probability at least 1-alpha, optimizing w or dose over that region preserves the stated coverage event. Constructing separate unadjusted intervals and then searching for a favorable w does not.

## Novelty and practical identifiability

The certificate's mathematical ingredients are established. Common linear/copositive Lyapunov functions are standard sufficient stability certificates for positive switched linear systems; the present inequality is their application to the first-moment system of a branching process. It is not a new theorem about extinction. The condition is sufficient rather than necessary: switched positive systems may be stable even when no single common w is found, so infeasibility means this certificate is unavailable, not that the biological pulse cannot work.

Cancer-specific prior art already includes time-varying treatment and multitype branching [Foo & Michor (2009)](https://pmc.ncbi.nlm.nih.gov/articles/PMC2766072/), multitype branching under targeted combination therapy [Bozic et al. (2013)](https://elifesciences.org/articles/00747), and stochastic phenotype-switching/extinction models [Gunnarsson et al. (2020)](https://pmc.ncbi.nlm.nih.gov/articles/PMC7785289/). Immigration has its own classical branching-process theory [Heathcote (1965)](https://doi.org/10.1111/j.2517-6161.1965.tb00596.x). Positive switched-system common copositive Lyapunov methods are explicit prior art [Xu et al. (2018)](https://doi.org/10.1016/j.automatica.2018.04.037). Barcode lineage distributions can add information beyond total population size for phenotype-transition inference, but recent work also reports model confounding and cases where richer escape models are not selected [Whiting et al. (2025)](https://doi.org/10.1038/s41467-025-59479-7).

Observed net growth alone cannot determine (1), (2), or (5): the matrix depends on birth and death separately and on switching, while pulse-created escape depends on mutation supply. Event-level births/deaths and state/genotype transitions, absolute tracked clone counts, source exposures, and post-pulse regrowth/establishment assays are needed. Even those data may not identify rare switching or maintenance pi_i at clinically relevant founder counts. The novelty that remains plausible is narrow and empirical: a prespecified, simultaneous-confidence-qualified dose rule that predicts mutation-resolved relapse risk on held-out experiments and changes a decision against equally informed, exposure-matched baselines. Priority and usefulness remain unestablished.

## Held-out falsifier and decision gate

Use a training set of independent barcoded cultures with isogenic founder types, fixed drug exposures, known seeded founder counts, live or otherwise validated birth/death/transition calls, absolute cell counts, and post-pulse limiting-dilution regrowth. Include direct mutation/escape measurements and a prespecified follow-up H. Fit no model after the holdout is unblinded. Build the simultaneous confidence region, solve the robust LP for w and delta, calculate pi_i^+, and freeze the dose and Rbar before evaluating holdout cultures.

The quantitative falsifier is: in independent, identically prepared held-out replicate cultures, the one-sided exact binomial lower confidence limit for relapse frequency exceeds the frozen Rbar(T,H). Split the preregistered total error budget between the training confidence region and this holdout test (or otherwise account for both in one familywise calculation). Also fail the mechanism if any held-out event rate falls outside the training simultaneous region, the common-w LP has no positive delta under the prespecified uncertainty set, or an untracked escape genotype contributes relapse. A useful-result gate additionally requires the frozen rule to beat the strongest equally informed controls: continued parent drug, the best mutation-directed agent, a fixed pulse, and variant-blind switching near the bulk nadir, with cumulative exposure, normal-cell toxicity proxy, assay latency, and follow-up matched or explicitly priced. Report failure if the bound is non-informative (Rbar >= 1 or above the best baseline), if no feasible duration meets epsilon, or if a control has lower relapse at no greater declared cost. A mouse or clinical effect is a later validation stage, not implied by this culture test.

No rate data, confidence intervals, optimized duration, or biological validation were generated for this note. The calculations are reusable conditional formulas and a prospective test specification, not a fit or efficacy claim.

1. EXACT STATE, SIGNS, AND RATIONAL INPUT

Canonical physical order is u_0,...,u_(n-1),d_0,...,d_(n-1). Let

  |BCS(F)>_unnormalized = exp(sum_(i,j) F_ij u_i^dagger d_j^dagger)|vac>.

For equal-size sets U,D of size k, its computational-basis amplitude is
  (-1)^(k(k-1)/2) det F_(U,D).
This follows by expanding the exponential: commuting each down creation past
subsequent up creations supplies the displayed sign; antisymmetrizing the row
and column assignments supplies the determinant. Every amplitude outside
N_up=N_down is zero. Arbitrary F describes opposite-spin pairing; F=F^T is
the true spin-singlet restriction. Do not label arbitrary F singlet.

Set hole occupation H=[n]\D. In the new ordered modes (up,hole), rank-n graph
Slater input is A0=[F;I_n]. Its ordered-row minor obeys

  det(A0_(U,H))=(-1)^(sum_(j in D)j-k(k-1)/2) det F_(U,D).       (1)

Proof: reorder the columns to (D,H). The identity rows become (0,I), and the
top-left block is F_(U,D). Moving the selected D columns to the front has
parity sum D-k(k-1)/2. Thus complementing all hole bits by X, then applying Z
to every odd zero-based physical down mode, sends the graph-Slater coefficient
to exactly the displayed BCS coefficient. This is O(n) gates and fixes every
fermionic sign. The canonical particle–hole unitary with new vacuum filled
with down electrons differs only by a known global phase.

Let positive onsite amplitude filter be
  G=product_i g_i^(n_(u_i)n_(d_i)), t_i=g_i^2>0.
In (up,hole) occupations (u,h), the squared filter table is
  t_i^(u(1-h)) = t_i^u (1/t_i)^(u h).
Its residual symmetric physical-load table is b_i=(1,1,1/t_i).

Even when t_i is rational, g_i=sqrt(t_i) and [diag(g)F;I] need not be rational.
Keep rational A0 and put the positive factors into

  f_(t,s)(x)=det(A0^* diag(s t_i x_(u_i), x_(h_i)) A0).         (2)

Every coefficient is the exact nonnegative rational
  s^(|U|) product_(i in U)t_i |det A0_(U,H)|^2.
No algebraic square-root arithmetic or irrational rank oracle is required.
Its coefficient phase is still det A0. A rational complex determinant has
polynomial-bit numerator/denominator; its phase can be approximated using
ratios to its larger nonzero real/imaginary component, independent of its
absolute magnitude. All zero/invalid strings receive a fixed default phase.
Explicit negative or complex g_i can also be allowed if t_i=|g_i|^2 satisfies
the bound and their local phase is supplied or polynomial-bit computable;
append the controlled double-occupancy phase. Hereafter g_i=sqrt(t_i)>0.

For the rank-n graph and positive filters, norm is always positive because
the vacuum coefficient is 1. Every prefix is feasible exactly when its forced
rows can be extended to a basis of the represented row matroid after deleting
excluded rows. Exact rational Gaussian elimination/greedy basis extension
finds a witness. There is no acquired exponential prefix table.

3. COMPLETE REAL-ROOTEDNESS PROOF FOR ALL REPULSIVE FILTERS

This theorem uses real sqrt(t_i), sqrt(1-t_i) as a proof construction only;
its algorithmic application still uses rational (2).

Introduce down clones v_j,w_j and rectangular paired matrix
  Ftilde=[F diag(sqrt(1-t)), F diag(sqrt(t))], n x 2n.
Impose hard exclusion of up_i AND v_i, with every w_i unrestricted.
For an up set U and down-clone set C of equal size k, a determinant containing
both v_j,w_j vanishes because those two columns are proportional. Every other
nonzero term picks exactly one clone of each j in an original down set D.
If j in U, hard exclusion permits only w_j, contributing squared t_j. If
j notin U, summing the two clone choices contributes (1-t_j)+t_j=1.
Therefore the total allowed squared-minor coefficient is precisely Z_k.

Now form the explicit 3n x 3n Hermitian chiral matrix H with up/down-clone
offblock
  B=[2 F diag(sqrt(1-t)), sqrt(2) F diag(sqrt(t))].             (3)
Its opposite offblock is B^*, and both diagonal blocks are zero. Equivalently
scale the U,V vertices of the Ftilde chiral matrix by sqrt(2) and W by 1.

For each A subset [n], retain the set
  R_A=U_A union V_([n]\A) union ALL W,
which has FIXED size 2n. Let H[R_A] denote the retained principal matrix.
Then

  2^-n sum_A det(x I_(2n)-H[R_A]) = x^(2n) Z(-1/x^2).        (4)

Coefficient proof: a balanced selected minor has up set U of size k and
clone set C of size k. If U and selected V conflict onsite it never appears.
Otherwise it is retained with probability 2^(-k-|C intersect V|). Its squared
vertex scaling from (3) is 2^(k+|C intersect V|), exactly cancelling that
probability. An unbalanced chiral principal minor has determinant zero;
a balanced one contributes (-1)^k times its paired squared determinant.
Thus the x^(2n-2k) coefficient is exactly (-1)^k Z_k.

Stability proof: P(z)=det(diag(z)-H) is real stable. If Im z_j>0, the imaginary
part of v^*(diag(z)-H)v is strictly positive for nonzero v, so it cannot vanish.
Its coefficients are real since H is Hermitian. Principal differentiation
deletes the differentiated rows/columns. Therefore the left side of (4) equals

  2^-n [ product_i (partial_(U_i)+partial_(V_i)) P(z) ]_(all z_j=x).  (5)

A nonnegative directional derivative preserves stability: replace z_U,z_V
by z_U+s,z_V+s; this is stable in s and all remaining variables, differentiate
s by Gauss–Lucas, and specialize s=0 by the boundary/Hurwitz limit. Repeating
over the sites and identifying all variables preserves stability. The result
is nonzero (leading coefficient1), has real coefficients, and is univariate,
so all roots of (4) are real. Since Z has positive constant1 and nonnegative
coefficients, every nonzero root of Z corresponds via s=-1/x^2 to a strictly
negative real root. This proves the theorem, including t_i=0 or1 and singular F.

The resulting scalar charge law is Poisson-binomial after factoring Z into
linear factors. This does not make the physical occupation law strongly
Rayleigh, nor the filtered state Gaussian. Already n=1 has physical polynomial
1+|F|^2 x_up x_down, which is unstable and positively associated. No full
multivariate occupation stability or free quasiparticle acquisition is claimed.
At every positive fugacity, Var(K)<=deg(Z)/4<=n/4 and the usual independent-
Bernoulli Chernoff bounds apply to charge. In particular the fixed-F ansatz's
normalized mean pair density has derivative <=1/4 with respect to log fugacity,
uniformly in n. This does not control a variational optimizer that changes F
with fugacity or the compressibility of an interacting Gibbs state.

The determinant/positive-derivative/principal-average steps are established
machinery, stated particularly directly in Leake–Ravichandran1609.04195v2,
Lemma2.1, Lemma2.7, Proposition2.8 and Theorem2.12. Their principal notation
means DELETION, whereas H[R_A] above means RETENTION. The cloned-column
identity (4) is the target-specific step; no novelty conclusion follows from
rediscovering the machinery.

4. FINITE-BIT CANONICAL CONSEQUENCE AND ACQUIRED TILT

Assume F in Q(i)^(n x n), rational 1/2<=t_i<=1, requested k in {0,...,n},
binary explicit input length L. Target electron number is N=2k. Let r=rank F.
Positive filters imply Z_k>0 iff 0<=k<=r: every k<=r has a nonzero k-minor,
and every larger minor vanishes. Exact rank decides feasibility without an
exponentially small mass estimate. Invalid k is reported as zero norm.

For a rational s>0, the legal grandcanonical tilted Born law has
  Pr_s(K=j)=Z_j s^j/Z(s), E_s K=m(s), d m/d log s=Var_s K.
Its coefficients are logconcave by the real-root theorem, hence the law is
unimodal. A self-contained conservative bound suffices:

  |E_s K-k|<=1/4 ==> Pr_s(K=k)>=a=3/[4(n+1)^2].              (6)

If a mode lies at or below k, every j>=k has p_j<=p_k. The mean lower bound
forces P(K>=k)>=(3/4)/(n-k+1); divide by the number of tail points. If a mode
lies above k, every j<=k has p_j<=p_k. The mean upper bound forces
P(K<=k)>=(3/4)/(k+1); divide by the number of prefix points. Both give (6),
including endpoints. No Darroch/mode-at-integer-mean import is required.

Acquire an integer b with max_positive Z_j/min_positive Z_j<=2^b. Rational
denominator clearing and upper bounds on sums of binom(n,j)^2 squared minors
acquire b=poly(n,L). Choose h=1/(16n^2) and the rational grid
  s_j=(1+h)^j, -J<=j<=J,
with J=poly(n,b) large enough that s_-J<1/(8n 2^b) and
s_J>8n 2^b. The two endpoint means are respectively <1/4 and >r-1/4.
Each s_j has polynomial bitlength, including reciprocal grids. Since
Var K<=n^2/4, adjacent means differ by at most1/64.

Bisection on the integer j range uses Born samples to estimate m(s_j) with
error <=1/64; stop when the estimate is within1/16 of k. Every non-stopping
comparison has the right sign on this good event. The adjacent grid gap
prevents bisection from skipping the target interval. Endpoints handle k=0,r.
O(log J) queries and O(n^2 log(log J/delta)) samples per query suffice by
Hoeffding, plus Born TV error O(1/n) and median/union success budgeting.
The sampler and all coefficients are evaluated with polynomial-bit s_j.
No exact roots, supplied saddle point, exact mean oracle, or numerical gap is
needed. This is a fully acquired tilt, conditional on the counting/Born gate.

Projecting the tilted state onto K=k leaves the desired normalized canonical
state unchanged because its only additional amplitude is the common s^(k/2).
Classical Born rejection therefore costs O(a^-1)=O(n^2) draws; cap repetitions
and retain an explicit failure outcome. Norm Z_k follows from Z(s)*p_k/s^k;
relative estimation of p_k uses only polynomial samples because p_k>=a.

Quantum preparation already follows from measured count projection with a cap
O(a^-1 log(1/epsilon)) on fresh prepared copies: on a good seed, every accepted
copy is the same projected quantum state, while all-failure probability is
small. Take grandcanonical trace error eta=O(epsilon a); normalized conditional
trace error is <=2 eta/a. Deferring the measurements and reversibly selecting
the first accepted register gives a polynomial unitary circuit with ancillas
and the same output-register trace guarantee. Thus amplification is optional.

For coherent preparation, compute electron count and reflect on N=2k. A
fixed-point amplitude amplification routine with lower bound a/2 uses
O(a^-1/2 log(1/epsilon))=O(n log(1/epsilon)) queries to the acquired prepared
circuit and its inverse. Compile the grandcanonical state to tighter error
O(epsilon sqrt(a)) (or the more conservative O(epsilon a)). Normalized
projection changes its error by only a polynomial factor; the actual prepared
circuit has sector probability >=a/2 on a good compiler seed. Allocate seed,
tilt and amplification errors explicitly. No unknown seed can be efficiently
certified as good; the conclusion keeps the randomized-compiler probability.

Finite-bit circuit synthesis and very high polynomial counting remain the
operational bottleneck. Local/row-sparse observables can use the existing N63
amplitude-ratio variance bound with this canonical Born sampler; no ground
state fidelity, Hamiltonian gap, optimization success, or local interacting
thermalization follows.

5. FAILED OBVIOUS REPRESENTATIONS AND ATTRACTION BARRIER

An extra number quota cannot simply be appended to the two-source count.
For n=2,k=1 the complementary source restricted to one up and one hole is
  q=a_2 u_1 h_1 +u_1 h_2+u_2 h_1+a_1 u_2 h_2,
  a_i=1/t_i.
Its quadratic Hessian has offdiagonal block [[a_2,1],[1,a_1]]. It has two
positive eigenvalues whenever a_1 a_2!=1, hence fails logconcavity. At the
allowed t_1=t_2=1/2 its eigenvalues are -3,-1,1,3. Moving the flavor quota
into the determinant source also fails: F=I and k=1 leaves the two disjoint
monomials u_1 h_2+u_2 h_1, again with two positive Hessian eigenvalues.
These are SOURCE/REPRESENTATION failures, not hardness or prep lower bounds.
The cloned-charge tilt proof above overcomes them in the repulsive window.

The same cure cannot be assumed for attraction. Let F=[[0,1],[1,0]] and
t_1=t_2=T>1. Then Z(s)=1+2s+T^2 s^2 has nonreal roots. Its k=1 mass is
maximized at s=1/T, with maximum1/(T+1). Taking T=2^L makes every fugacity
tilt exponentially ineffective in binary input length even at n=2. The
canonical k=1 state in this example is simple, so this proves no complexity
hardness. Another representation/algorithm could still cover attraction.

6. FINITE-TEMPERATURE NAMBU INTERFACE

Spin-conserving quadratic BCS Hamiltonians become number-conserving Nambu
quadratic Hamiltonians after down particle–hole transformation. A thermal
state generally has VARIABLE Nambu particle number, so it is not itself the
rank-n graph Slater used above. A supplied rational HPD Gaussian L-kernel
provides a clean purification interface instead:

  B in Q(i)^(m x m), m=2n, B>0,
  rho_B=Gamma(B)/det(I+B),
where Gamma(B) acts on the k-particle sector as wedge^k B. A rational covariance
0<C<I gives B=C(I-C)^-1 exactly. Acquire rational LDL* B=R D R* with D>0.
The Slater purification has matrix A=[R sqrt(D); I_m] on m system plus m
ancilla modes, rankm. Its system reduced state is rho_B. A selected system
set S and hole-complement ancilla J have squared coefficient
  product_(j in J)D_j |det R_(S,J)|^2,
and phase the rational determinant times the known complement sign.

Although A contains square roots, its determinant-source oracle is rational:
  det(A* diag(x_system,x_ancilla) A)
    =det(D) det(R* diag(x_system)R+diag(x_ancilla/D)).
Add t_i external fields to physical up system variables. Use the physical
site pairs with residual b=(1,1,1/t_i) and ancilla singleton b=(1,1).
The same complementary theorem applies for every t_i>=1/2. Preparing this
filtered purification and discarding ancillas produces
  G rho_B G / Tr(G^2 rho_B)
in polynomial bit time under the same counting/compiler import, without
inverse filter norm. Full rank/positive filters keep this target nonzero.

This is a FILTERED GAUSSIAN REFERENCE, not an interacting Hubbard Gibbs state.
If the input is instead only beta and a quadratic h, the acquisition and
precision cost of B=exp(-beta h), log coefficient ranges and numerical beta||h||
must be charged; it is not automatically polynomial in the binary encoding
of an arbitrarily huge beta. The canonical pure-state proof does not directly
cover this mixed thermal ensemble: physical spin difference varies, and
electron count after PH is n+N_up-N_hole. Generic spin-mixing/pure Pfaffian
states need not have fixed Nambu number and are outside the graph transfer.

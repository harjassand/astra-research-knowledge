For integer K>=2 use the active basis 0,...,K. Put
  Z_K=sum_(j=0)^K 2^(-j)=2-2^(-K),
  sigma_j=2^(-j)/Z_K.
Let the column-stochastic P send each j>=1 deterministically to j-1.
From input 0, reset with probabilities
  r_i=2^(-i-1), 0<=i<K; r_K=2^(-K).
These sum exactly to one. Stationarity is exact:
  (P sigma)_i=sigma_(i+1)+sigma_0 r_i=sigma_i for i<K,
  (P sigma)_K=sigma_0 r_K=sigma_K.

Its time reversal has, for every input i<K, probability 1/2 to output i+1
and 1/2 to output 0; input K returns to 0 with probability one. For the
uniform active state u_j=1/(K+1), direct multiplication gives
  b_active=T(u,Pu)=(1-2^(-K))/(K+1),
  (P^sharp Pu)_0=1/2+2^(-K)/[2(K+1)],
  (P^sharp Pu)_j=(1+r_(j-1))/[2(K+1)], j>=1,
  r_active=T(u,P^sharp Pu)=(K-1+2^(-K))/[2(K+1)].

discrepancy is negative. Forward near-invariance therefore does not imply
dimension-independent closeness of the Petz symmetrization without a budget.

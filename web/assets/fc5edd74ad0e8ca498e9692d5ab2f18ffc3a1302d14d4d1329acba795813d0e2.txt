The independent result is a precise local bridge, not a global recurrence
theorem. In a finite weakly reversible network, a complex path lifts from
state x>=y to the enabled stochastic path x-y+c_k; the reverse path returns
the endpoint, and an available maximizing source yields a non-increasing
residual-factorial potential at that endpoint. Deterministic non-invariance
of a coordinate face only gives a stochastic recovery jump after present
counts clear its reactant thresholds. For A+B<->2A, (1,0) is absorbing while
(2,0)->(1,1) is enabled. Path probabilities can decay with population, so
these lemmas do not imply a global physical-time Foster drift.

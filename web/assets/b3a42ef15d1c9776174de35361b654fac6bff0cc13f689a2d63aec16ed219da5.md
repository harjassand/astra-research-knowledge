# N-stage CTMC discrimination: exact amplification, information loss, and an optimal matched counter

## Finding

For a finite N-stage CTMC whose two simple hypotheses change the pass probability at each stage, an all-pass endpoint has a likelihood ratio that grows exponentially in N. Under a fixed N-jump and fixed-time budget, that endpoint does not create information: it compresses the event path and is Blackwell-dominated by observing the event marks. Its KL divergence is strictly below the full-path KL for N≥2 and distinct hypotheses.

For the same N Bernoulli event marks, the Neyman–Pearson optimal one-bit decision is a threshold on the number of passes. A finite stage-count CTMC implements that decision with the same N jumps, elapsed time, and one final readout. It uses a larger internal state graph than the all-pass chain. The defensible result is therefore a precise state/readout/information tradeoff inside a specified model, not a general gain from memory.

## Model and proved statements

Let `H=h` have pass probability `p_h` at each of N independent event slots, with `0<p_h<1` and `p_0 != p_1`. Each event occurs after an `Exp(lambda)` holding time, with the same `lambda>0` under both hypotheses. The N-slot schedule is fixed and the elapsed time is independent of H, with mean `N/lambda` and variance `N/lambda^2`.

The all-pass CTMC stores its stage and a sticky pass/fail flag. It has `2N+1` reachable states, exactly N jumps, and one terminal bit. Its positive probability is `p_h^N`. Reading its full state path (including the failure slot) has KL

`D_path = [sum_{i=0}^{N-1} p_0^i] * D(Ber(p_0)||Ber(p_1))`,

because the i-th informative transition is observed only if the first i marks passed. The terminal bit has KL `D(Ber(p_0^N)||Ber(p_1^N))`, strictly below that path KL for N≥2. A full mark-record control that reads every slot has KL exactly `N*D(Ber(p_0)||Ber(p_1))`; the inter-event times add zero KL because their law is shared by both hypotheses. The full-state-path row is the exact same-device comparator; the full mark record is the information ceiling for the N-slot input channel.

The optimal fixed-size test of H=0 versus H=1 at a prescribed false-positive level uses a threshold in the pass count `K`. For `p_1>p_0`, the likelihood ratio increases strictly with K. A time-homogeneous finite CTMC storing stage i and pass count k has `N(N+1)/2+2` reachable states, makes N jumps, runs for mean time `N/lambda`, and returns one terminal decision bit; it realizes the Neyman–Pearson threshold exactly, with a final common randomization for a boundary point when needed.

An endpoint-only all-pass observation identifies `p^N`, not N and p jointly. Separately, a three-state cyclic CTMC can have distinct generators with the same full fixed-time transition matrix; an explicit positive-rate pair is given in [proof.md](proof.md).

## Resource comparison

| Design | Reachable CTMC states | Jumps | Mean time | External observations | Final decision |
|---|---:|---:|---:|---:|---|
| All-pass endpoint | `2N+1` | N | `N/lambda` | 1 terminal bit | `P_h(accept)=p_h^N`; loses path information |
| All-pass full-state path | same device, `2N+1` | N | `N/lambda` | N transition observations | Reveals failure slot; KL `J_N(p_0)*d` |
| Stage-count threshold CTMC | `N(N+1)/2+2` | N | `N/lambda` | 1 terminal bit | Neyman–Pearson optimal for the Bernoulli-mark model |
| Full mark record | input channel plus observer | N | `N/lambda` | N marks, then 1 decision | KL `N*d`; threshold uses only K |

The count automaton trades a larger internal state graph for fewer external event readouts. Its state label needs only logarithmic bits, while an autonomous layered CTMC has quadratic many reachable stage-count pairs. This accounting does not model energy or implementation reliability.

## Prior art and novelty boundary

The proof uses established Blackwell comparison/data processing, the Neyman–Pearson lemma, and path-space relative entropy for CTMCs. Fixed-lag generator nonuniqueness is part of the classical Markov embedding and rate-identifiability problem. Primary mathematical sources and their precise role are listed in [sources.md](sources.md).

The exact N-stage KL formulas, terminal likelihood, count-threshold CTMC, cost table, and explicit alias witness are reconstructed here for this model. The underlying principles are established; no claim of a new general information-theory or Markov-process theorem is warranted. No independent review, external formal verification, or numerical test was performed.

## Limits and next gate

The model assumes known simple hypotheses, iid Bernoulli marks, common hypothesis-independent exponential event rates, a fixed N, and no state-dependent adaptive choice of event channel. Hypothesis-dependent holding rates would add information in event times; unknown parameters or correlated marks require new identifiability and optimality analyses. The cyclic generator alias refutes universal fixed-lag identifiability but does not settle identifiability for every staged architecture.

The next mathematical gate, if this direction is continued, is to characterize the state-cardinality versus observation-cost Pareto frontier for a specified class of finite-state transducers. The current report proves only the fixed-N Bernoulli case and an information upper bound; it does not solve that frontier.

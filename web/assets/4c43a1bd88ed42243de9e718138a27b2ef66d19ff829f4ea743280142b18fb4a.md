# Cycle 2: infinite-range L1 extension

## Finding

The finite-range result does extend to arbitrary-range maps when the Markov-type-2 source is **separable**. Conditional on cycle-1 claim MR-2, every Lipschitz map (f:S\to L_1(\Omega,\mu;\mathbb R)), for any (S\subseteq X) and separable (X) with finite (M_2(X)), has a global extension satisfying

\[
\operatorname{Lip}(F)\leq C_{MN}\,12\sqrt{21}\,M_2(X)\,\operatorname{Lip}(f).
\]

This handles genuinely infinite-range (f) and incurs **no extra constant** beyond MR-2. The proof takes global extensions of increasing finite restrictions, places their values on a countable dense source set in one weighted (L_1) space, applies Komlós' subsequence theorem to obtain a.e.-convergent Cesàro averages, and uses Fatou's lemma and completeness to recover a global extension. The cut-recovery maps keep each finite-stage output inside the sigma-finite support generated by the countable dense boundary data, which lets the argument cover arbitrary real (L_1(\Omega,\mu)), not only finite-measure (L_1).

## Boundary

The proof does **not** cover nonseparable sources. Its sequence/Komlós step needs a countable dense set covering every source point at which pairwise Lipschitz constraints must hold. No common subsequence is produced for uncountably many points. This is a limitation of this route, not a counterexample; the full nonseparable-source claim remains `UNKNOWN`.

The usual Mendel–Naor compactness argument also cannot be copied directly: the relevant bounded balls in (L_1[0,1]) are not weakly compact, and (L_1[0,1]) is not a reflexive target. The spike sequence (n\mathbf 1_{[0,1/n]}) is norm bounded but has no weakly convergent subsequence in (L_1[0,1]); testing against continuous functions yields the Dirac functional at zero, which is not represented by an (L_1) density. Komlós/Cesàro convergence is the replacement in the separable case.

## Status and prior art

The derivation is conditional on the cycle-1 finite-range candidate MR-2 (itself an internal reconstruction from the pinned family-332 release and Mendel–Naor). The finite-to-infinite bridge is proved here from that premise and Komlós' source theorem, but it has not been independently reviewed. Numerical (C_{MN}), construction time, finite-precision behavior, and an effective Komlós selector remain unknown. Historical novelty is `UNKNOWN` after a bounded primary-source search.

Lee–Naor (2005, §1.4) recorded the global (L_2\to L_1) question as open. A 2024 preprint by Chang, Naor, and Ren separately asked the ℓ2-to-ℓ1 question; the pinned 2026 release resolves the sequence-space ℓ1 target, which is distinct from arbitrary ambient (L_1(\Omega,\mu)). The present conditional result establishes the function-space target for separable sources by a finite-to-infinite argument, but no priority claim is made.

2. Separate simple-graph gadget for integer edge weights

Let W>=1 be an integer with binary length l. Write W=sum_{i:beta_i=1}2^i. Construct a DAG with vertices s,t,x_0,...,x_{l-1}: arcs x_i->t for all i; arcs x_i->x_j for j<i; and arcs s->x_i exactly when beta_i=1. If p_i counts paths x_i to t, then p_i=1+sum_{j<i}p_j=2^i by induction. Thus the number of s-to-t paths is W. The DAG is simple and acyclic, has O(l) vertices and O(l^2) arcs.

Make left/right copies L_v,R_v of every DAG vertex v and a diagonal edge L_vR_v. For every arc u->v add L_uR_v. Replace the logical host edge {a,b} by boundary edges aL_t and R_sb, with fresh internal vertices for each host edge. This is a simple unweighted graph gadget with O(l) internal vertices and O(l^2) internal edges. Its boundary signature, indexed by whether neither/both/only-a/only-b host endpoints are matched into the gadget, is exactly (1,W,0,0): with neither endpoint used, acyclicity forces all diagonal edges; with both used, the selected off-diagonal edges form one s-to-t path plus possible directed cycles, and acyclicity leaves exactly the W paths; a one-endpoint state has unequal left/right cardinalities and is impossible. The proof is in the separate N42 leaf `work/programmes/photonic_complexity/leaves/positive_kernel_counting.txt`, lines 60–68. Exhaustive enumeration for W=1,...,20 is recorded in `outputs/research/photonic_complexity/weight_gadget_check.json`; this finite test checks those signatures only.

3. Denominator clearing proves the rational-weight extension

Let G=(V,E) be a finite simple graph with even |V|=2r and nonnegative rational weights w_e encoded in binary. Define PM_w(G)=sum_{M perfect} product_{e in M}w_e. Delete zero-weight edges. If |V| is odd, or a deterministic maximum-matching test finds no perfect matching in the positive support, return zero. Handle V empty directly as PM_w=1. Otherwise, write each positive w_e=p_e/q_e with positive integers p_e,q_e, and set D=product_{e in E+}q_e. For every positive edge define W_e=D w_e, a positive integer. Replace each edge by the disjoint-interior gadget above.

Every perfect matching of the expanded simple graph selects both boundary edges in exactly those gadgets corresponding to a perfect matching M of the host. By the signature, the number of gadget completions is product_{e in M}W_e. Therefore

    #PM(G_expanded) = sum_M product_{e in M} W_e
                    = D^r PM_w(G).                         (1)

The scale is the same for every host matching because each has exactly r edges. Apply the OA113 unweighted FPRAS to G_expanded and divide its rational output by the exact integer D^r. Equation (1) preserves relative error and confidence without parameter loss. The deterministic feasibility branch ensures exact zero for zero weighted count; on a feasible positive-support graph, the expanded graph has at least one perfect matching. Thus, conditional on the OA113 theorem being correct, nonnegative rational weighted perfect matching has an FPRAS with exact-zero detection and worst-case polynomial bit time.

For input bit length L and e=|E+|, log D is at most the sum of denominator bit lengths, hence O(L); each W_e has O(L) bits. The gadget contributes O(L) vertices and O(L^2) edges per host edge, so the expanded graph has O(eL) vertices and O(eL^2) edges. D^r has O(rL) bits. Construction, exact scaling, and output postprocessing are polynomial in L. OA113 is invoked with the same epsilon,delta, so runtime is polynomial in L, epsilon^-1, log(delta^-1). This is an approximation-preserving reduction; it does not independently validate OA113 and does not claim an FPRAS for Z_k.

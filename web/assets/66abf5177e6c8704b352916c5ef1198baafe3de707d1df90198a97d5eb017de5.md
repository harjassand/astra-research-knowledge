# Selective matrix output: a structured-mask construction

**Verdict:** I derived a conditional subquadratic algorithm for masks with a
low-volume rectangle-cover representation, including masks with a sparse
arbitrary residual. At $D=N^{1/4}$, cover volume $M\le N^{15/8}$, and
residual size $|F|\le N^{7/4-\sigma}$, the total cost is
\(A_{1/8}+O(N^{2-\min(1/32,\sigma)}\operatorname{polylog}N)\) exact bit
operations. The arbitrary-mask target remains open. I found no counterexample
to the conditional construction, but its square-kernel setup is not
materialized or practically bounded.

The mask interface is explicit: $W=F\cup\bigcup_t R_t\times C_t$, each
rectangle has both sides at least $D$, and
\(M=\sum_t |R_t||C_t|\le N^{15/8}\). Tile each $X[R_t,:]Y[:,C_t]$ into
\(D\times D\) square products. The pinned release supplies a recursive exact
square algorithm costing $O_\xi(D^{9/4+\xi})$, so each rectangle cover
element costs $O_\xi(|R_t||C_t|D^{1/4+\xi})$. The residual entries are
computed as individual $D$-term dot products. For \(\xi=1/8\), the covered
part costs $O(N^{63/32})$, and the residual costs $O(N^{2-\sigma})$.

This uses the actual mechanism in the October 2 release: its tensor-character
argument derives the 9/4 bound, then its final recursion fixes one exact
finite rank decomposition and recursively multiplies square blocks. The
release proves existence but gives no practical rank decomposition, setup
time, field degree, or coefficient-height bound. I charge those as
\(A_\xi,S_\xi\). Exact arithmetic can use a fixed number field; it does not
need floating precision. For entries with (O(\log N)\) bits, recursive
coefficient heights are $O_\xi(\log N)$, yielding only a polylogarithmic
bit overhead after the fixed setup is acquired.

The strongest directly relevant primary prior I checked is Alman–Vassilevska
Williams, arXiv:2610.06783v1. Its arbitrary-mask result covers
\(D\le N^{1/18}\) and more generally exponents below 0.1204; the present
\(N^{1/4}\) interface is outside that regime. The release's rectangle-cover
construction therefore contributes only on structured masks. It does not
contradict the pinned Astra obstruction, which says some masks defeat
independently charged rectangle covers.

The exact application proof, prior-art boundary, source hashes, scope failures,
and finite check are in the sibling files. `finite_check.py` confirmed tile
indices and residual outputs on one exact small fixture using classical
integer multiplication; it did not test the release kernel or its exponent.
Novelty/priority of this structured corollary is unknown.

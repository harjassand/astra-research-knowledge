CORRIGENDUM: RESIDUAL RACAH SONIN-ENERGY ROUTE IS INVALID
8 October 2026.

The previous version of this packet incorrectly claimed that an energy
increment identity proved |eta_l(l)|=O(z^(-1/2)). That proof is withdrawn.
The exact Whipple transform and degree recurrence below remain valid, but
the residual decay estimate and q_(n,l)->1 conclusion are NOT ESTABLISHED
by this packet. Do not cite its previous claimed theorem.

Valid exact formulas retained
-----------------------------

Let D=n+1, N=n(n+2)=D^2-1, L=l(l+1). The exact diagonal scalar is
  eta_l(l)=_4F_3(-l,l+1,-l,l+1;1,-n,n+2;1).

For n>=2l, terminating balanced Whipple with order l and
a=-l,b=c=l+1,d=1,e=-n,f=n+2 gives
  eta_l(l)=P_(n,l) _4F_3(-l,-l,-l,-l;1,n-2l+1,-n-2l-1;1),
  P_(n,l)=(l-n)_l(n+l+2)_l/[(-n)_l(n+2)_l]
         =(n-l)!^2(n+2l+1)!(n+1)!/[(n-2l)!n!(n+l+1)!^2].
The transformed sum has terms (-1)^k u_k, where
  u_k=[l!/(l-k)!]^4/[(k!)^2(n-2l+1)_k(n+2l+2-k)_k],
  u_(k+1)/u_k=(l-k)^4/[(k+1)^2(n-2l+1+k)(n+2l+1-k)].
It does not have an alternating-series tail bound in the residual
regime: u_1/u_0~z^2->infinity.

The exact degree recurrence also remains valid. For
  P_r(x)=_4F_3(-r,r+1,-x,x+1;1,-n,n+2;1),
the specialization of the Racah recurrence is
  x(x+1)P_r=-A_rP_(r+1)+(A_r+C_r)P_r-C_rP_(r-1),
  A_r=(r+1)(D^2-(r+1)^2)/[2(2r+1)],
  C_r=r(D^2-r^2)/[2(2r+1)].
At x=l, R_r=P_r(l), L=l(l+1), and
  A_r(R_r-R_(r+1))+C_r(R_r-R_(r-1))=L R_r.
The recoupling eigenvalue interpretation gives |R_r|<=1.

Exact algebraic failure
-----------------------

Put u_r=sqrt(2r+1)R_r. The symmetrized recurrence is
  b_r u_(r+1)+b_(r-1)u_(r-1)=a_r u_r,
  b_r=(r+1)(D^2-(r+1)^2)/[2sqrt((2r+1)(2r+3))],
  a_r=A_r+C_r-L.
For the previously proposed energy
  E_r=b_r u_(r+1)^2+b_(r-1)u_r^2-a_r u_(r+1)u_r,
the claimed increment
  (b_r-b_(r-1))u_r^2+(a_r-a_(r+1))u_ru_(r+1)
was false: it drops the change of b in the recurrence. Direct substitution
of the recurrence gives instead
  E_(r+1)-E_r =
    (b_r^2/b_(r+1)-b_(r-1))u_r^2
       +(a_r-b_r*a_(r+1)/b_(r+1))u_ru_(r+1).          (1)
The omitted factors do not vanish.

A reproducible exact countercheck for the false identity uses n=12,l=3.
For r=2 the claimed left-minus-right difference is
  -66861*sqrt(35)/41503 + 157320*sqrt(7)/41503,
which is nonzero. The following standard-library/SymPy check reproduces
the discrepancy; it also verifies the recurrence and the exact
Whipple transformation over the finite grids used in the prior version.
Those checks do not establish residual asymptotics.

    from fractions import Fraction
    from math import prod
    from sympy import Rational, sqrt, simplify
    def poch(a,k): return prod(a+i for i in range(k))
    def P(n,r,x):
        return sum((Fraction(poch(-r,k)*poch(r+1,k)*poch(-x,k)*poch(x+1,k),
                              prod(range(1,k+1))**2*poch(-n,k)*poch(n+2,k))
                    for k in range(min(r,x)+1)), Fraction(0))
    n,l=12,3
    D=n+1; N=n*(n+2); L=l*(l+1)
    R=[P(n,r,l) for r in range(n+1)]
    u=[sqrt(2*r+1)*R[r] for r in range(n+1)]
    def b(r):
        return Rational((r+1)*(D*D-(r+1)**2),2)/sqrt((2*r+1)*(2*r+3))
    def a(r): return Rational(N-r*(r+1)-2*L,2)
    def E(r): return b(r)*u[r+1]**2+b(r-1)*u[r]**2-a(r)*u[r+1]*u[r]
    r=2
    claimed=(b(r)-b(r-1))*u[r]**2+(a(r)-a(r+1))*u[r]*u[r+1]
    print(simplify(E(r+1)-E(r)-claimed))

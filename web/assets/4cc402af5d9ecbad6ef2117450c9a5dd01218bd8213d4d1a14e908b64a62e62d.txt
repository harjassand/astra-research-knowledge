Strongest checkpoint claim

For the rational-rate mass-action family
  0 -> B          at rate alpha,
  B -> 2A         at rate beta,
  A+B -> B        at rate gamma,
with alpha,beta,gamma positive rationals, the network is endotactic, the CTMC is non-explosive, and its unique closed communicating class is positive recurrent. An explicit rational, norm-like potential gives a global geometric Foster drift. In particular this gives a worked boundary-recovery certificate on the unbounded A-axis B=0, where the process can sit at an arbitrarily large A-count until immigration creates B.

This is a fixed-rate, three-reaction family result. It does not prove recurrence for arbitrary rational bimolecular endotactic networks and makes no novelty claim.

Exact endotacticity check

Write w=(u,v) and let the source scores for 0, B, A+B be 0, v, u+v. The reaction vectors are (0,1), (2,-1), (-1,0). If 0 is w-maximal, then v<=0, so its essential edge has negative w-projection. If B is maximal, v>=0 and u<=0, so 2u-v<=0, strictly unless the projection is zero. If A+B is maximal, u>=0, so -u<=0, again strictly for every essential edge. These cases cover all ties, hence every edge at a maximal source with nonzero w-projection points strictly inward. Reactant molecularities are 0, 1 and 2; every complex in this displayed instance has molecularity at most 2.

The CTMC transitions from state (a,b) are
  (a,b)->(a,b+1)       at alpha,
  (a,b)->(a+2,b-1)     at beta*b, if b>=1,
  (a,b)->(a-1,b)       at gamma*a*b, if a,b>=1.

Boundary and communicating-class audit

Let C={ (a,b): b>=1 } union { (a,0): a>=2 }. No transition from C exits C: the only jump that can reach b=0 is B->2A from b=1, and it leaves a>=2. Every state in C can reach (0,1): when b>=1, apply A+B->B a times to clear a, then repeatedly apply B->2A followed by enough A+B->B jumps to reduce b to 1; when b=0,a>=2, first immigrate one B and then clear A. Conversely, from (0,1), immigration builds any desired positive b, repeated B->2A jumps create A in increments of two, A+B->B adjusts A downward one at a time, and a final B->2A jump reaches any (a,0) with a>=2. All these paths have positive probability, so C is closed and irreducible. States (0,0) and (1,0) enter C on the next immigration and cannot be reached from C.

Exact Foster certificate

For any positive rational rates alpha,beta,gamma, choose the integer
  q=max(1, ceil(2*beta/gamma)),
and set
  V(a,b)=a/(b+q)+b,
  delta=min(alpha/[q(q+1)], gamma/[2(q+1)]),
  eta=min(q*delta,beta).

V is nonnegative and norm-like: if b is unbounded then V>=b; if b stays bounded while a diverges, a/(b+q) diverges. Direct evaluation of the three reaction increments gives
  LV(a,b)=a*C_b+D_b,
where
  C_0=-alpha/[q(q+1)],  D_0=alpha,
and, for b>=1,
  C_b=-alpha/[(b+q)(b+q+1)]
      + b/(b+q) * (beta/(b+q-1)-gamma),
  D_b=alpha + m*beta*b/(b+q-1)-beta*b
with m=2 in the displayed network. Since b+q-1>=q>=2*beta/gamma,
  C_b<=-gamma*b/[2(b+q)]<=-gamma/[2(q+1)].
Thus C_b<=-delta for every b>=0. Also D_b<=alpha+2*beta-beta*b. Hence
  LV(a,b)<=-delta*a + alpha+2*beta-beta*b
          <=-eta*V(a,b)+alpha+2*beta.
The last inequality uses eta<=q*delta, eta<=beta, and q/(b+q)<=1. The standard countable-state Foster criterion applied to this norm-like drift on the non-explosive irreducible class C gives positive recurrence (indeed geometric ergodicity).

For the concrete all-unit fixture alpha=beta=gamma=1, q=2, delta=1/6 and eta=1/3, so
  V(a,b)=a/(b+2)+b,
  LV(a,b)<=3-V(a,b)/3
for every integer a,b>=0.

Non-explosion also follows directly: B is an autonomous immigration-death chain with immigration rate alpha and death rate beta*b. It has finitely many jumps on bounded time intervals. Each B->2A event is one of its deaths, so A can increase only finitely often on any bounded interval. Conditional on the resulting finite bounds for A and B, the A+B->B rate is bounded; hence there cannot be infinitely many jumps in finite time.

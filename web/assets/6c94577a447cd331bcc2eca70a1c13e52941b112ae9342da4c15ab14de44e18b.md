# Quantum sensing / thermodynamics / resource-theory audit

Date: 2026-10-07. Worker: quantum_metrology. Status: independent mathematical derivations with finite diagnostics; neither external correctness review nor historical priority is established. No scientific breakthrough is claimed.

## Outcome

The strongest closed new deduction in this pass is a constructive refinement of Astra N19. For its fixed noncommuting qutrit detector, a smoothly tapered superposition of Dicke counts reaches the regularized expected-input-cost detection exponent with deficit **O(n^(-2/3))**. The earlier high-probability binomial projection supplied only O(sqrt(log n/n)). Consequently a sufficient entangled block size becomes **O(epsilon^(-3/2))**, improving the inherited O(epsilon^(-2) log(1/epsilon)). An exact 64-use witness already beats every separable input, with a self-contained coarse separable converse. A deterministic sequential preparation has n rounds, n polylog(n) gate complexity with reversible arithmetic, O(polylog n) ancillary qubits, one trial, and O(log n) angle precision. No general rotation compiler was implemented here.

This is a real scoped mathematical improvement. It does not settle optimal block size: the inherited necessary-depth bound Omega(epsilon^(-1/2)) is far smaller. Nor does it show a total physical work advantage. A second elementary result below gives an exact overhead model and proves that per-cell costs suppress the claimed large condition-number gain. Autonomous time-covariant detectors eliminate the gain altogether. Full-rank thermal nulls eliminate exact-zero-false-alarm detection, independently of block size.

The useful OA276 load-bearing lemma is the rectangular zero-block estimate. For

    M = [[A,B],[C,0]], x=Tr AA*, y=Tr BB*, z=Tr CC*, x+y+z=1,

it claims

    S(MM*) >= x S(AA*/x)+y S(BB*/y)+z S(CC*/z)+g(yz),

with `g(u)=h((1+sqrt(1-4u))/2)`. I reconstructed the following decisive steps:

1. For equal-trace positive U,V, integrate the log determinant difference against dr/r² to obtain S(U)-S(V). Equal trace cancels the small-r singularity; the endpoint at infinity contributes -a log a eigenvalue by eigenvalue.
2. For fixed Z, `G_Z(D,E)=log det(D+ZE^-1 Z*)-log det D` is jointly convex. Put C=[[D,Z],[-Z*,E]], Dcal=diag(D,E), K=Dcal^-1/2(C-Dcal)Dcal^-1/2. K is skew-adjoint, so R=(I+K)^-1 is a contraction. The second directional derivative is `||L||_HS²-Tr((RL)²)>=0`, because the trace is real and its absolute value is at most ||RL||_HS².
3. A Schur complement turns the entropy-deficit integrand into `log det(I+rAA*)-G_(sqrt(r)A)(I+rBB*,I+rC*C)`. In an SVD basis for A, simultaneous averaging over coordinate signs lowers G to its diagonal arguments, in the correct direction because G is subtracted.
4. The resulting scalar deficit is homogeneous and concave. Concavity follows from the same scalar G convexity after setting x=1; homogeneity gives superadditivity and supplies the desired summed bound. Padding handles rectangular matrices.
5. The thermal extension expresses fixed row sums U0,U1 and cross coefficient K as a convex mixture of coefficient endpoints with either beta=0 or eta=0. Both endpoint corner products equal `u=U0 U1-K²`, so entropy concavity retains exactly the same g(u) term.

I found no flaw in those reconstructed finite-dimensional steps. This is a selected human-readable reconstruction, not an independent formal build or a comprehensive manuscript certification. OA276 would give the population-sensitive generalized-amplitude-damping entropy bound and capacity formula under its exact assumptions. It is **not needed** for the new detection construction below, which is proved from elementary finite matrices. In particular OA276 is a thermal communication result, not a way around a faithful-null zero-false-alarm obstruction.

## 2. Exact detection interface and audit of N18

Supplied and known: finite-dimensional CPTP channel Phi, H>=0 with unique zero ray |0>, pure null output Phi(|0><0|)=|v><v|, and `E=Phi*(|v><v|)>0`. Positivity implies E=1 direct-sum E_+, 0<E<=I. Set L=-log E, `H_n=sum H_i`, `L_n=sum L_i`.

Prepared input rho may be entangled across n parallel cells. Charge `Q=Tr rho H_n`. The smallest miss probability with exactly zero false-alarm probability is

    p0 = Tr rho E^tensor n = Tr rho exp(-L_n).

The exact regularized coefficient is

    alpha = lambda_max(H_+^-1/2 L_+ H_+^-1/2).

For every input, scalar Jensen in the L_n spectral distribution gives

    -log p0 <= Tr rho L_n <= alpha Q.

No operator monotonicity of exponentials is used. The maximizing local vector w obeys `<L>=alpha <H>`. A coherent L_n typical projection of w^tensor n gives the matching asymptotic coefficient. The bounded-H cost-continuity estimate is legitimate under expected cost.

For every separable block, including unequal local states and correlated classical mixtures,

    -log p0 <= beta Q,
    beta = max_(w in excited unit sphere) [-log <w|E|w>]/<w|H|w>.

Pure-state one-site bounds extend to mixed states and then to separable mixtures by scalar Jensen. Repeated beta-maximizing product pulses attain beta. A vacuum amplitude cannot improve this ratio because `-log(1-t+te)<=t[-log e]`.

I independently checked these inequalities, their use of expected cost, the equality criterion, and the source's two-use perturbative gain. The inherited exact criterion is also elementary: alpha=beta iff an excited E-eigenvector belongs to ker(alpha H-L). Equality in scalar Jensen is strict otherwise. A strict difference needs at least three input levels, since the excited subspace of a qubit is one-dimensional.

## 3. New smooth-Dicke construction and proof

Use exactly the N19 constructive local pair

    E = diag(1,e^-1,e^-4),
    H = 0 direct-sum [[1,1/2],[1/2,1]].

The positive H eigenvalues are 1/2 and 3/2. Put

    alpha = (10+2 sqrt(13))/3,
    p = (23+6 sqrt(13))/61,
    s = sqrt(p(1-p)) = (9+5 sqrt(13))/61,
    h = 1-s, ell = 1+3p = alpha h.

These follow by solving `det(L_+-lambda H_+)=4-5lambda+(3/4)lambda²=0`. The maximizing local vector is `sqrt(1-p)|1>-sqrt(p)|2>`.

A concrete physical CPTP interface is the driven binary detector

    Phi_E(rho)=Tr(E rho)|v><v|+Tr((I-E)rho)|click><click|,
    <v|click>=0.

It can be realized by a coherent qutrit-controlled flag rotation with flag-zero amplitudes 1, e^(-1/2), e^(-2), followed by flag measurement and preparation of its classical output. Vacuum is an exact no-click state. In the physical H eigenbasis the two excited energies are 1/2 and 3/2; the detector's |1>,|2> basis superposes those energies, so a driving/coherence reference is a load-bearing part of this implementation. The CPTP construction is operationally valid but does not specify its battery/reference work.

For n>=64, choose an integer m>=1 with `(m+1/2)/n<=1/8`. Let j0 be the nearest integer to np, `a=j0-m`, `b=j0+m`, and

    g_j = sin[pi(j-a+1)/(2m+2)] / sqrt(m+1), j=a,...,b.

The sine vector is normalized. Its nearest-neighbor overlap is

    sum_(j=a)^(b-1) g_j g_(j+1) = cos[pi/(2m+2)].        (1)

Define the normalized symmetric pure state

    |psi_(n,m)> = sum_(j=a)^b (-1)^j g_j |D_j^n>,

where |D_j^n> is the uniform superposition of all n excited-qubit strings with j copies of |2>. All registers here are counted: the pulse consists of n qutrits; the symmetric formula is a description of the state, not a smaller physical input archive.

The exact miss and energy are

    p0 = exp(-n) sum_(j=a)^b g_j² exp(-3j),
    Q = n - sum_(j=a)^(b-1) g_j g_(j+1) sqrt((n-j)(j+1)).  (2)

The second expression includes the adjacent-type coherences. Measuring the full j count would remove them, so it is not a substitute for this pure preparation.

The support is exact, giving immediately

    -log p0 >= n+3a >= n ell - 3(m+1/2).                 (3)

To bound Q sharply, write `f(x)=sqrt(x(1-x))`. On [1/8,7/8], `|f''(x)|=1/[4 f(x)^3]<7`. The nonnegative weights `g_j g_(j+1)` are symmetric about `j=j0-1/2`. Therefore their weighted first moment is x0=(j0-1/2)/n. Since x0 belongs to [p-1/n,p] and p>2/3, n>=64 gives 1/2<x0<=p, and consequently f(x0)>=f(p)=s. Taylor's lower bound and cancellation of the linear term give

    sum g_j g_(j+1) f(j/n)
      >= cos[pi/(2m+2)] [s - (7/2)m²/n²].

Also `sqrt((n-j)(j+1))/n>=f(j/n)`. Using (1) and `1-cos t<=t²/2`,

    Q/n <= h + s pi²/[8(m+1)²] + (7/2)m²/n².            (4)

Thus the proved finite-size rate bound is

    R_(n,m) = (-log p0)/Q
      >= [ell-3(m+1/2)/n]
          / [h+s pi²/(8(m+1)²)+(7/2)m²/n²].             (5)

The earlier cruder Lipschitz argument gave an additional O(m/n) energy term. Symmetry removes that term; only the detector exponent loses O(m/n).

Taking `m=floor(n^(1/3))` meets the admissibility condition for n>=64, and (5) gives

    0 <= alpha-R_(n,m) = O(n^-2/3).                     (6)

This is an upper bound on the deficit for this explicit family, not the optimal finite-block law. The balance is exactly between O(m^-2) coherence-gradient cost and O(m/n) detector-log support loss. It is a finite quantum version of replacing an abrupt boundary by the ground sine mode of a path.

### An exact 64-use separation

For the pair above, a pure excited state with |2>-population t has its smallest possible H-cost `h(t)=1-sqrt(t(1-t))`, achieved by opposite relative phase, and detector numerator

    n(t)=1-log(1-t+t e^-3).

Here is a self-contained coarse bound **beta<=5**, sufficient for a finite separation. Use e^-3>1/21. For t in the following four intervals, monotonicity gives respectively:

| t interval | h(t) lower bound | n(t) upper bound |
|---|---:|---:|
| [0,4/5] | 1/2 | 1+log(21/5)<5/2 |
| [4/5,9/10] | 3/5 | 1+log 7<3 |
| [9/10,24/25] | 7/10 | 1+log(35/3)<7/2 |
| [24/25,1] | 4/5 | 4 |

Every ratio is at most 5. These log inequalities have elementary finite-series proofs: e<11/4 implies e³<21; the positive Taylor partial sums of e^(3/2), e² and e^(5/2) exceed 21/5, 7 and 35/3 respectively. The one-site bound extends to all separable states by the Jensen argument of Section 2.

Set n=64, m=4. Then j0=47, a=43, b=51 and

    |psi> = sum_(r=1)^9 (-1)^(r+42) sin(r pi/10)/sqrt(5) |D_(r+42)^64>.

From exact support, p0<=e^-193. In the energy sum, the smallest neighbor coefficient occurs at j=50 and equals sqrt(714). Equation (1) gives

    Q <= 64-cos(pi/10) sqrt(714) < 193/5.

For the last strict inequality, `cos²(pi/10)=(10+2sqrt5)/16`; squaring reduces it to a rational inequality, already implied by sqrt5>223/100. Thus

    (-log p0)/Q > 5 >= beta.

This beats **every separable block of every length** under the same expected-input-cost resource definition. It is an exact inequality; floating-point values do not supply its proof. Diagnostics give Q≈36.64318, -log p0≈196.77720 and R≈5.37009. The numerical one-variable maximum beta≈4.2778057 is useful context but not a certified optimum here.

## 4. Deterministic preparation, finite precision and resource charges

There is a direct sequential preparation that avoids postselection. It is mathematically explicit, while the full reversible arithmetic and finite-gate compiler are not implemented in the diagnostic script.

1. Prepare a log(n+1)-qubit register K in `sum_j (-1)^j g_j |j>`. This is an O(m)-amplitude state with exact support [a,b]. Standard binary-tree conditional rotations require O(m) rotations and O(m polylog n) gates. Exact zero branches keep this support unchanged under finite accuracy in the interior rotations. An offset addition converts a support register on 0,...,2m into j=a,...,b.
2. Initialize n encoded excited data qubits in |1>, called computational bit 0.
3. With r=n,n-1,...,1 remaining sites and counter value k, rotate the next data bit with probabilities `(r-k)/r` and `k/r`. Uncompute the arithmetic scratch **before** updating k. Then decrement k conditionally on data bit 1.

For a fixed initial j, after i steps each prefix with r1 ones has squared amplitude

    (j)_r1 (n-j)_(i-r1) / (n)_i.

At i=n every weight-j string therefore has amplitude 1/sqrt(binomial(n,j)), and K=0. By linearity a superposition of j values becomes the desired Dicke superposition. K and all arithmetic scratch end in a supplied zero state, so no uncharged retained input-dependent counter is present at detector input.

The exact support property is stronger than a generic trace-distance guarantee. At k=0 implement bit 0 exactly; at k=r implement bit 1 exactly. At 0<k<r either output branch remains feasible, even when its angle is approximated. Every complete path therefore has exactly its initial j ones and counter zero. Approximate rotations cannot create counts outside [a,b]. Consequently (3) remains valid without exponentially accurate angles.

Compute `theta(k,r)=2 arcsin sqrt(k/r)` reversibly to O(log n) bits. Integer division, square root and arcsin away from exact endpoints have classical polynomial complexity in log n and precision; reversibilization gives polynomial logarithmic workspace and gates. Angle bits control a product of elementary rotations. Choosing per-component gate/angle error, for example, O(n^-3) after distributing it across the polynomial logarithmic subcircuit gives total state-vector error O(n^-2) in the n-stage preparation. With `||H_n||=3n/2`, the resulting per-cell cost error is O(n^-2); (6) is preserved. A finite universal gate set supplies the usual polynomial logarithmic synthesis overhead. An explicit compiler would be needed before claiming precise constants or a hardware run.

Resource account for one successful prepared pulse:

| Resource | Charge / limitation |
|---|---|
| Supplied input data | Known E,H and their common chosen basis; algebraic p; no unknown-channel acquisition solved |
| Physical signal cells | n excited qutrits, each with positive cost eigenvalues 1/2 and 3/2 |
| Stored mean signal energy | Q=nh+O(n/m²+m²/n+1), h≈0.556922 |
| Data hard energy support | Conservatively within [n/2,3n/2]; this is not a hard support budget Q≈nh |
| Preparation trials | Exactly one in the ideal deterministic circuit |
| Preparation gates | O(n polylog n+m polylog n), rather than an exponential state table |
| Preparation ancillary qubits | O(polylog n), all returned to zero before the detector |
| State description | O(m) algebraic/trigonometric amplitudes; no acquisition oracle |
| Angle precision | O(log n) bits; exact endpoint constraints are load-bearing |
| Peak control resources | Coherent reversible arithmetic, n stages, a reference allowing noncovariant E-basis operations; physical battery/reference model not supplied |
| Apparatus/detector uses | n per pulse; repeated pulses add their own n uses |
| Net preparation work | At least the stored energy increase Q for an initially zero-energy pure probe in a closed work-supplied model; inefficiency, resets, reference degradation and counter work require a specified apparatus. Do not double-count this same stored energy as both Q and a second Q of preparation consumption. |

The source's circuit acts inside the excited subspace after excitation. My stated circuit likewise starts there; populating it and any recovery of the difference between intermediate mean energy and final Q must be included by a physical work implementation. Gate counts are charged operational resources, but there is no universal theorem that each reversible gate dissipates a fixed positive energy. Hence the overhead theorem next is a **declared model**, not an invented universal energy lower bound.

## 5. Exact overhead extension and the physical no-gain boundaries

Suppose the detection contract explicitly charges c>=0 per physical channel cell:

    Q_c(rho)=Tr rho H_n+cn.

Define on the excited subspace

    alpha_c=lambda_max[(H_++cI)^-1/2 L_+ (H_++cI)^-1/2],
    beta_c=max_w [-log<w|E|w>]/(<w|H|w>+c).

The same Jensen and coherent-projection proof gives these exact regularized coefficients for arbitrary and separable probes. Vacuum dilution cannot improve beta_c: `-log(1-t+te)<=t[-log e]`, and `t/(th+c)` is increasing in t. The operator inequality is valid also on the vacuum, where L=0 and H+cI=c. An alternative declared charge `H+cP_exc` has the same best coefficients for the fully excited optimal probes.

The condition-number argument now proves

    1<=alpha_c/beta_c<=(h_max+c)/(h_min+c).              (7)

Proof: alpha_c<=||L||/(h_min+c); an L-maximizing eigenvector gives beta_c>=||L||/(h_max+c). Thus for h_max normalized to 1 and c bounded below by a fixed positive constant, the source's Theta(kappa(H_+)) gain is bounded even as h_min->0. For c>>h_max the upper bound tends to 1. This is an exact resource-accounting restriction, with no claim about the physical value of c.

For the local constructive pair, write d=1+c. Then

    alpha_c=[5d+sqrt(9d²+4)]/[2(d²-1/4)].

No common excited E/H eigenvector exists, so alpha_c>beta_c at every finite c. Nevertheless the separation shrinks. The script's numerical illustration gives gains about 1.341 at c=0, 1.136 at c=0.5, 1.073 at c=1 and 1.0023 at c=10; these beta optimizations are diagnostics, not certified global enclosures.

Other load-bearing boundaries:

- **Autonomous covariance.** If Phi is time-covariant for H and the null output projector is invariant under output time evolution, its pulled-back effect E commutes with H. A common eigenvector then reaches alpha as a product pulse, so alpha=beta. A real detector with this symmetry does not implement the proposed strict resource gain. A driving/coherence reference is necessary and is an additional physical resource.
- **Thermal null.** For a faithful null state sigma0, `Tr T sigma0=0` and T>=0 imply T=0. Tensor powers and arbitrary entangled inputs do not repair this. At any nonzero thermal occupation the exact-zero-false-alarm contract fails; a fixed positive tolerance is a different Stein/Hoeffding task.
- **Sequential stopping.** Stop-on-click gives bounded alternative-only expected cost but ever-smaller miss probability, as the source already notes. Parallel exponents do not cover that asymmetric stopping convention.
- **PPM bandwidth.** N message positions use Nn cells even though only one pulse carries Q. With a per-physical-cell charge c the total is Q+cNn, not Q+cn. Unrestricted bandwidth must not be hidden behind a signal-energy exponent.
- **Physical errors.** Polynomial synthesis accuracy is enough only because ideal computational support is exact. Generic faults leaking into lower-L sectors can contribute much more than e^-Theta(n) to the miss. No fault-tolerance threshold or dark-count robustness is established.
- **Calibration.** A detector effect with e^-M eigenvalue requires relative knowledge of that rare probability to certify its logarithmic coefficient. Estimating it from raw independent trials to fixed relative precision requires order e^M samples. A supplied analytic controllable model may avoid that estimation cost, but has its own time/parameter calibration charge. The large-kappa examples use M=Theta(kappa), so unknown-model acquisition can be exponentially expensive.

## 6. Primary prior art and priority assessment

The base regularization and zero-error distinguishability mechanisms already have close precedents. [Datta, min/max relative entropies](https://arxiv.org/html/0803.2770) supplies the support-overlap min-relative entropy and its one-sided zero-error interpretation. [Nuradha and Wilde, smooth fidelity-min relative entropy](https://arxiv.org/html/2305.05859) supplies the asymptotic relative-entropy smoothing framework. My sine construction is an explicit finite-block state family rather than a new entropy principle.

[Ding, Pavlichin and Wilde, capacities per unit cost](https://arxiv.org/abs/1705.08878) and [Jarzyna, classical capacity per unit cost](https://arxiv.org/abs/1704.06696) already develop cost observables, zero-cost symbols and pulse-position mechanisms. They do not make N18 a new capacity concept. [Berta, Hirche, Kaur and Wilde](https://arxiv.org/abs/1808.01498) treat energy-constrained channel discrimination; distinguishing channel order and allowed false alarms remains essential.

[Bärtschi and Eidenbenz, deterministic Dicke preparation](https://arxiv.org/abs/1904.07358) already give deterministic preparation and extend it to arbitrary symmetric states. [Their shorter-depth work](https://arxiv.org/abs/2207.09998) supplies broader connectivity constructions. The coherent remaining-count algorithm here is elementary and may itself be standard. [Dawson and Nielsen](https://arxiv.org/abs/quant-ph/0505030) supplies finite-gate approximation rather than an implementation in this report.

I did not locate the precise O(n^-2/3) finite-block energy-normalized detection refinement in the searched primary sources. This negative search is weak priority evidence. A systematic prior-art review of optimal number-squeezed probes, constrained Rényi divergences, spin-wave packets and discrete semiclassical variational problems is required before a novelty assertion. The exponent may be an instance of a standard boundary/kinetic scaling. It is deliberately reported as **new to this local derivation**, not proved historically new.

## 7. Decisive falsification and next observation

The mathematical construction can be falsified by finding a failure in the exact cost matrix element in (2), the path identity (1), the symmetry cancellation in (4), or the claimed count-preserving sequential circuit. A full-vector simulation on small n checks all of these algebraic dependencies except the asymptotic proof itself. The implementation contains 13 full-vector pulse fixtures and 65 sequential-count fixtures; all passed. It also evaluates ten finite block sizes using only O(m) coefficient arrays. `smooth_dicke_results.json` contains all values and clearly marks finite numerical scope.

The next observation that could change the physical assessment is a complete driven detector/reference model realizing this E,H pair with work, reference degradation, dark counts and channel time specified. Its competent separable comparator must receive the same drive, calibration and detector. If its c or higher preparation expense wipes out the gain, the input-only result remains mathematically true but physically unhelpful. A matching lower bound on finite entanglement depth would strengthen the mathematical contribution, but is open here.

A08 synchronization codes — bounded foundational investigation
Version: v2 (append-only; candidate mechanisms are not theorem claims)
Date: 2026-10-09

1. Exact target and model

Target selected after literature triage: close the explicit deterministic binary high-rate gap for adversarial insertion/deletion correction, ideally with an explicit, uniquely decodable, polynomial-time code whose redundancy is O(k log(n/k)) for every 1 <= k <= c n (for a fixed c<1), matching the information-theoretic order. In the constant-fraction regime k=delta n, this would improve the known explicit rate 1-O(delta log^2(1/delta)) to 1-O(delta log(1/delta)). At present this is a target, not a result.

Use edit distance ED with each insertion, deletion, or substitution costing one; to match the papers' adversarial model, a code must recover every transmitted codeword from every received string at ED at most k. For the pure deletion model, all adversarial deletion patterns are allowed and are chosen with full knowledge of the codeword. State whether the object is a code or a document-exchange sketch: a one-way randomized sketch for a fixed receiver string independent of the sketch randomness does not imply a deterministic code against an adaptive channel adversary.

The lower-order optimal redundancy scale is Theta(k log(n/k)) bits for k <= n/4 (with the usual +O(k) convention). A deterministic code meeting O(k log(n/k)) with near-linear or polynomial encoding/decoding would be a meaningful explicitness/rate advance. It is not legitimate to count a q-ary construction as binary without charging alphabet-reduction overhead; nor to assume random coins or feedback are free.

2. Primary-source baseline and status

(A) Cheng–Jin–Li–Wu, “Deterministic Document Exchange Protocols, and Almost Optimal Binary Codes for Edit Errors,” arXiv:1804.05776v4, https://arxiv.org/abs/1804.05776 . Primary HTML examined earlier in this session at https://arxiv.org/html/1804.05776 (arXiv source is dated 2018-04-16; relevant claims are Introduction/Theorems 1.2–1.4). The paper states:
  • information-theoretically optimal redundancy/sketch scale Theta(k log(n/k));
  • deterministic document exchange with O(k log^2(n/k)) sketch and polynomial-time recovery;
  • explicit binary insertion/deletion code with O(k log^2(n/k)) redundancy, giving rate 1-O(delta log^2(1/delta)) for k=delta n;
  • a second explicit binary code with O(k log n) redundancy, optimal for k <= n^(1-alpha) for fixed alpha>0;
  • for k=delta n, the information-theoretic rate loss is Theta(delta log(1/delta)), leaving a log(1/delta) factor between the displayed explicit and optimal asymptotic orders.
These are source-reported claims, not independently reconstructed proofs. The near-linear/poly(n) complexity statements are in the source theorems. The sharper second code does not close the constant-fraction regime, because O(k log n) is not O(k log(n/k)) when k=delta n and n grows.

(B) Haeupler, “Optimal Document Exchange and New Codes for Insertions and Deletions,” arXiv:1804.03604v3, https://arxiv.org/abs/1804.03604 ; primary HTML https://arxiv.org/html/1804.03604, especially lines 45–52, 82–99, 103–115, 123–149. Theorem II.1 (HTML lines 83–87) gives a randomized summary of Theta(k log(n/k)) bits, with deterministic recovery succeeding with probability 1-n^{-O(1)} for each receiver string F' that is independent of summary randomness. The paper explicitly includes a compact description of the randomness in the summary (lines 148–149); no shared random source is needed. This is an optimal randomized one-way document-exchange protocol under the independence condition, not a worst-case deterministic code. Theorem II.2 (lines 90–94) gives the deterministic O(k log^2(n/k)) result. The paper notes the randomized and deterministic document-exchange/code equivalence differs: the equivalence to systematic codes is stated for deterministic sketches (lines 75–77).

(C) Cheng–Li, “Efficient Document Exchange and Error Correcting Codes with Asymmetric Information,” arXiv:2007.00870, https://arxiv.org/abs/2007.00870 ; SODA 2021 primary abstract at https://epubs.siam.org/doi/10.1137/1.9781611976465.144 . The abstract reports an efficient randomized edit-distance document-exchange protocol with optimal communication and exponentially small error. This strengthens randomized error probability, not the deterministic/adaptive code guarantee targeted here.

(D) Kiah–Wei–Zeng, “Constant-List Insertion–Deletion Codes: New Bounds and an Improvement of Levenshtein’s Lower Bound,” arXiv:2609.21395v1 (2026-09-18), https://arxiv.org/abs/2609.21395 ; primary HTML https://arxiv.org/html/2609.21395, lines 75–86, 91–103, 131–153, and 159–175. This recent preprint strictly improves the binary unique-deletion existential rate lower bound over Levenshtein, e.g. at delta=0.1 from 0.1620088... to at least 0.180431; it develops fixed-list existential bounds and converses using run restrictions, local lemma, generating functions, and run counting. The authors explicitly say their achievability results do not claim efficient encoders/decoders (line 153). It changes the existential baseline, not the explicit efficient target selected here. Do not conflate the source's fixed-list versus unique-decoding models or its asymptotic existential rate bounds with an efficient construction.

(E) Maringer–Polyanskii–Vorobyev–Welter, “Feedback Insertion-Deletion Codes,” arXiv:2010.15928v3, https://arxiv.org/abs/2010.15928 ; primary HTML https://arxiv.org/html/2010.15928, lines 43–46, 63–85, 121–131. Their feedback model notifies the sender after each transmitted symbol of the entire per-symbol output string y_i, and permits adaptation (lines 65–75). They establish an exact asymptotic forward-use rate. Since the model supplies this feedback, it does not establish the same rate when feedback communication is charged. Even sparse event feedback needs an explicit coding/resource analysis before use as an answer to the current target.

3. Candidate mechanism: shared multiscale syndrome for alignment defects (internally derived structural count; construction unresolved)

Consider a dyadic hierarchy of block lengths B=1,2,4,...,2^J, where 2^J is comparable to n/k. Under a *known monotone edit alignment*, each insertion/deletion event intersects only O(1) source/received blocks at any fixed scale B. Thus the number of affected blocks at scale B is at most min(c k, c n/B) for an absolute constant c (the second bound is simply the number of blocks). Summing over dyadic B gives

  sum_{j=0}^{J'} min(k,n/2^j)
    <= k(1 + floor(log_2(n/k))) + sum_{j>log_2(n/k)} n/2^j
    <= k log_2(n/k) + O(k),

where J' is the last scale up to n. More explicitly, for 2^j <= n/k, each term is at most k and there are 1+floor(log_2(n/k)) such levels; for 2^j>n/k the remaining terms form a geometric tail less than 2k. Therefore the total number of edit-touched dyadic nodes can be O(k log(n/k)), the desired *bit* budget if each node could be conveyed with O(1) bits and decoded robustly.

The proposed leap would replace independent per-level ECC/hash payloads by one global syndrome for the union-of-paths support induced by k edit events. A root-to-leaf path description costs O(log(n/k)) per event, hence O(k log(n/k)) bits. The central missing theorem is a deterministic efficiently decodable map from all possible matched-block/alignment defects into a syndrome of this size, from which the receiver can recover a valid alignment or all source symbols. The count above is only for an alignment already known; it does not supply that map or decoder.

Extremal attack that invalidates the naive fixed-position version: let x=010101... of length n and delete x_1 to obtain y=101010... of length n-1. If every dyadic block is compared at its absolute, unshifted position, then essentially every suffix block differs at every scale, not only O(k) blocks. Thus the bound above applies only to blocks associated with the true monotone alignment, not to fixed-index partitions. Locating the aligned blocks is the synchronization problem itself. For x=0^n, the same deletion causes no content mismatch in internal blocks, showing that a value-difference count also depends on the source structure. Any proposed shared syndrome has to encode alignment shifts, not merely compare blocks at equal offsets.

Resource accounting required for a successful realization: bits to describe the syndrome, any seed/public randomness, the feedback (if any), length changes under insertions, decoder list size or collision probability, and time to generate/compute the syndrome and reconstruct x. A random hash of constant size per tree node suggests the information budget but fails worst-case guarantees if an adversary chooses the input/alignment after the hash map is fixed. The randomized document-exchange result above handles a receiver fixed independently of the summary randomness, but cannot be promoted to deterministic adversarial code without a separate argument.

4. Alternative markerless invariant: substring-spectrum sparse differences (candidate; tested counterexample refutes sufficiency)

For a fixed window length ell, deleting one bit removes at most ell source windows of length ell that cross or contain the deleted position, and creates at most ell new windows across the newly adjacent boundary. Therefore the l1 difference between the length-ell substring-count vectors of x and y is at most 2 ell per deletion (and at most 2 ell k for k deletions), before cancellation of repeated patterns. This is a local, alignment-independent sparse-change property and could support sparse-recovery sketches of spectra.

However, the spectrum alone does not identify the sequence even with zero errors. At ell=2, the shortest collision found is x=0010 and x'=0100. Both have bigrams {00,01,10}, identical endpoints 0, but x != x'. This is the Euler-trail ambiguity in the order-1 de Bruijn multigraph. A runnable exhaustive search for the shortest such pair is saved beside this record. Increasing ell just shifts ambiguity; it gives no proof for all strings. Any hierarchy of spectra needs a bound and encoding for the branch/ordering information at repeated contexts. No such bound has been established here.

5. Other attempted routes and exact failure points

(a) Basic marker-block concatenation. If a marker of length M is placed every B data bits, marker overhead is about M/B. With a total of delta n adversarial deletions, at most delta n/M markers can be destroyed, a fraction about delta B/M among n/B blocks. Balancing the two losses M/B and delta B/M gives order sqrt(delta); basic markers therefore do not reach delta log(1/delta). This is a cost calculation, not a universal lower bound against more structured marker schemes.

(b) Run-length transform. Write x=b 0^{r_1}1^{r_2}0^{r_3}... . Deleting a bit from a run of length at least two decrements one r_i. Deleting a singleton interior run changes (...,a,1,c,...) into (...,a+c,...), merging its two neighboring same-symbol runs. Thus one source deletion is not just one substitution/deletion in the run-length vector; it can merge symbols and increase the output alphabet up to n. A q-ary edit code on run lengths must account for this merge and for its parity/total-length constraints. A naive fixed q mapping either loses rate (restricting maximum run length) or pays too many bits for parity symbols; no near-optimal binary code follows from this transform as currently stated.

(c) Derivative transform. Define d_i=x_i xor x_{i+1}. Deleting an interior bit replaces adjacent derivative labels (a,b) by a xor b; for several deletions, each received derivative is the XOR of a contiguous group of original derivatives between retained vertices. The total XOR is only the endpoint parity x_1 xor x_n, so the immediate invariant has constant information and cannot identify the deletion pattern. This reframes alignment as a group-contraction channel but provides no decoder or code construction.

6. New theorem candidate, sharp obstruction, and unresolved inference

Candidate (not proved): there exists an efficiently computable shared multiscale syndrome of O(k log(n/k)) bits for binary strings such that, given the syndrome of x and any y with ED(x,y)<=k, a deterministic decoder recovers x in poly(n) time. For all k in a fixed small-fraction range, this would yield an explicit systematic binary edit code with matching-order redundancy. It would imply the explicit high-rate loss O(delta log(1/delta)).

The extremal alternating-string example refutes the simplest proof strategy that uses equal-index dyadic block mismatches as a k-sparse object. The spectrum example refutes the simplest markerless histogram invariant. The missing inference is not “only” an encoding of an edit script: the encoder has x but does not know the receiver y or the alignment, and the receiver must identify the right alignment from the compact syndrome plus y.

No new theorem is claimed in v1. Status: literature baseline = source-reported; dyadic count = internally derived conditional on known monotone alignment; fixed-position dyadic strategy = refuted by explicit example; spectrum sufficiency = refuted by explicit example; shared syndrome and near-optimal explicit code = unresolved.

Finite search note: exhaustive enumeration over all binary strings of lengths 2 through 12 finds a zero-error spectrum collision at n=4: 0010 and 0100 both start/end in 0 and have bigram multiset {00,01,10}. The runnable exact search is `work/applied/a08_synchronization_codes/spectrum_collision_search.py`; it reports this first collision. In the order-1 de Bruijn graph, both strings are Euler tours using edges 00,01,10, with different edge order. This confirms that preserving endpoints does not repair the spectrum invariant.

Exact alignment counterexample: let n=2^J and x=0101... of length n; delete its first bit to get y=1010... of length n-1. For each dyadic B=2^j, x's B-blocks are alternating-pattern blocks; every full B-block of y at the same absolute block index is its bitwise complement, because y[t]=1-x[t] for all 1<=t<n. There are n/B-1 full blocks of y when B divides n and B>=1. Hence the equal-index mismatch count is n/B-1 at every scale, while the edit count is k=1. This exact formula makes the fixed-position failure independent of an asymptotic heuristic.

8. Algebraic group-product syndrome: exact identity, necessary tests, and current failure

Let G be a finite group and assign fixed generators g_0,g_1 in G to the two input symbols. Define the product hash Φ(w)=g_{w_1}g_{w_2}...g_{w_|w|}, in left-to-right string order. Suppose x is obtained from y by inserting k symbols a_1,...,a_k, and split y into (possibly empty) chunks y=p_0p_1...p_k so that

  x = p_0 a_1 p_1 a_2 ... a_k p_k.

For r=1,...,k define P_r=Φ(p_0...p_{r-1}). Then direct cancellation gives the exact identity

  Φ(x) Φ(y)^{-1} = ∏_{r=1}^k (P_r g_{a_r} P_r^{-1}),

with the factors ordered by r. For k=2, writing P=Φ(p_0), Q=Φ(p_1), R=Φ(p_2), the quotient is P g_{a_1} Q g_{a_2} Q^{-1} P^{-1}, while the right side expands to (P g_{a_1}P^{-1})(P Q g_{a_2}Q^{-1}P^{-1}), which is the same product. This explicit expansion fixes the order and conjugators. Each prefix product P_r is computable from the known receiver y and a candidate alignment, but depends on its bit values as well as its length.

Necessary condition from one insertion. Fix b∈{0,1}; let q be a nonempty intervening word and compare x_1=p b q s with x_2=p q b s. Both yield the same receiver y=p q s by one deletion. Their hashes agree exactly when Φ(q)g_b=g_bΦ(q). They are distinct codewords whenever q contains at least one symbol other than b. Thus a universal one-deletion group-product hash must have no word q of length at most n−1 that contains the opposite symbol and whose product lies in the centralizer C_G(g_b). In particular, for receiver y=0^{n−1}, the n distinct candidates obtained by inserting one 1 have hashes distinguished only if the n conjugates g_0^i g_1 g_0^{-i} (i=0,...,n−1) are distinct. Likewise y=1^{n−1} forces n distinct conjugates of g_0 under powers of g_1. These are exact necessary conditions, not sufficient conditions.

Necessary group size for k deletions. For y=0^{n-k}, every length-n word containing exactly k ones has y as a subsequence. There are binom(n,k) such words, so any hash whose value alone distinguishes all candidates for this fixed y must have |G|≥binom(n,k), or at least log_2 binom(n,k)=k log_2(n/k)+O(k) bits when k≤n/2 up to the standard entropy expression. This meets the information-theoretic scale but does not yield a group of that size with the required universal collision-free products or an efficient decoder.

Failed affine/wreath instantiation. In the semidirect product F_q^m ⋊ <t>, take a shift t acting by multiplication by α and encode a bit b by (b,1). Then Φ(w) stores length plus a polynomial-like weighted bit sum. For a single insertion x=p b s, y=p s, the quotient's module component is (1−α)P(p)+α^{|p|}b, where P(p) is the weighted value of the entire prefix. The second term is position-sensitive, but the first depends on arbitrary prefix content. Consequently this is not a sparse position error to which a BCH/sparse-vector decoder can be applied directly. I found no quotient of the module that kills this prefix term while preserving both bit information and position information. The exact group identity remains a candidate representation; universal k-product separation and efficient decoding are unresolved.

9. Power-moment syndrome probe (finite-tested only; no uniqueness theorem)

For a binary word x=x_1...x_n define M_r(x)=Σ_{i:x_i=1} i^r using 1-based positions. For two words with a shared length-(n−k) subsequence, equality of only M_0,...,M_k is insufficient already at k=2. Exact certificate:

  x  = 0110001,   x' = 1000110,   y = 10001;
  x and x' each contain y as a subsequence after deleting 2 bits;
  (M_0,M_1,M_2)(x)=(M_0,M_1,M_2)(x')=(3,12,62).

The next moment separates this pair: M_3(x)=378 while M_3(x')=342. The executable exhaustive checker is `work/applied/a08_synchronization_codes/moment_collision_search.py`.

Exhaustive checks found no collision using M_0,...,M_{2k} through the following finite limits: k=1 through n=14; k=2 through n=17; k=3 through n=12. The same search finds the displayed collision at n=7 for k=2 with moments only through degree 2. These observations are finite-tested and do not establish that 2k moments always suffice. A plausible but unproved conjecture suggested by the small cases is that any distinct equal-length binary x,x' sharing a length-(n−k) subsequence differ in at least one of the first 2k+1 exact moments. No proof was obtained; do not use this as a theorem.

Even if the conjecture held, the direct exact-integer checksum is not near the target for growing k: 0≤M_r(x)≤Σ_{i=1}^n i^r≤n^{r+1}, so transmitting all moments r=0,...,2k costs O(k^2 log n) bits. Enumerating all insertions into y costs n^{O(k)} in the direct decoder. Replacing integers by residues needs an additional collision proof and does not automatically improve the sum of syndrome lengths. Thus this candidate does not close the constant-fraction logarithmic gap.

10. Updated literature pin on the explicit-binary gap

The primary ICALP 2025 paper by Guo et al., “Random Reed–Solomon Codes Achieve the Half-Singleton Bound for Insertions and Deletions over Linear-Sized Alphabets,” states in its binary-code discussion that explicit binary codes correcting εn insdels for small constant ε with optimal rate remain open: https://drops.dagstuhl.de/storage/00lipics/lipics-vol334-icalp2025/html/LIPIcs.ICALP.2025.60/LIPIcs.ICALP.2025.60.html (lines 75–80). This is consistent with the narrower source-reported O(k log^2(n/k)) explicit construction and Θ(k log(n/k)) optimal order in Cheng–Jin–Li–Wu, https://arxiv.org/html/1804.05776 (abstract and Theorems 1.2–1.4; lines 3–6, 68–79). The 2025 paper supplies a current primary-source statement that the small-constant-fraction explicit binary frontier remains open; it does not itself prove the exact logarithmic-factor gap for every k.

12. Stronger moment counterexample and expanded finite diagnostic

Four moments (degrees 0 through 3) do not suffice for two deletions. The first collision in exhaustive search is at n=12:

  x  = 011000101110; delete positions {1,3} to obtain y=1000101110;
  x' = 100010111001; delete positions {11,12} to obtain the same y;
  (M_0,M_1,M_2,M_3)(x)=(M_0,M_1,M_2,M_3)(x')=(6,42,364,3438).

The fifth moment separates them: M_4(x)=33700 and M_4(x')=34420. This directly refutes the tempting “one moment per deletion pair” rule (2k checks) for k=2. It supports only a still-unproved pattern that 2k+1 moments might suffice. The earlier 7-bit example remains a smaller collision for just M_0,M_1,M_2.

An independent exact C++ search, `work/applied/a08_synchronization_codes/moment_supersequence_search.cpp`, enumerates each receiver y and every length-n supersequence formed by inserting two bits at any pair of cuts. It calculates moments from interval power sums, deduplicates multiple insertion scripts yielding the same word, and compares distinct candidate words. It found no collision for moments M_0,...,M_4 for n=18,19,20. This is a separate implementation/finite check from the Python search and covers all two-deletion receivers at those n. It is still not a proof for arbitrary n.

Expanded finite status for the 2k+1-moment conjecture: no collisions through n=14 for k=1, n=20 for k=2, and n=15 for k=3. The k=2 upper bound uses the independent C++ search for n=18,19,20 plus the prior Python checks for n≤17; k=1 and k=3 use exhaustive Python enumeration. For moments only through degree 2k−1, k=2 has the exact n=12 counterexample above. All these checks use integer moments, exact equality, and arbitrary binary words; they do not establish a general syndrome theorem or an efficient near-linear decoder.

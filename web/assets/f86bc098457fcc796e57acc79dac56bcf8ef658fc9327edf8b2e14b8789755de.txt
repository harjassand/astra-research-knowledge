LEAF: EXACT COMMUNICATING CLASSES AND BOUNDARY BEHAVIOR

Question

For the weakly reversible network

    0 -> A,   A -> B,   B -> mB,   mB -> A,   A -> 0,

with fixed positive rates and integer m>=3, determine the lattice communicating classes, settle the boundary reachability, and test whether a Foster argument gives recurrence on each class.

Conclusion

The CTMC is irreducible on all N_0^2 for every fixed m>=3 and every fixed positive rate vector. Thus there are no hidden boundary closed classes. The reaction graph is strongly connected, and explicit enabled paths show that every state reaches the origin and the origin reaches every state; this proves that the single communicating class is all of N_0^2 and is closed.

The total count N(a,b)=a+b is a norm-like Foster function. Its exact generator drift is

    LN(a,b) = alpha - eta*a
              + (m-1) [gamma*b - delta*(b)_m],

where alpha, beta, gamma, delta, eta are the rates in the displayed reaction order and (b)_m=b(b-1)...(b-m+1). The negative degree-m term controls large b, and -eta*a controls large a when b is bounded. Therefore LN<=-1 outside an explicitly definable finite rectangle. Also LN<=c(1+N), which proves non-explosion by stopping and Gronwall. The countable-state Foster criterion then gives positive recurrence of the unique class. No counterexample to the classwise recurrence step exists for this candidate network: there is only one class, and it satisfies the drift criterion.

Network and exact CTMC

Coordinates are (a,b) in N_0^2. The positive constants are:

    alpha: 0 -> A
    beta:  A -> B
    gamma: B -> mB
    delta: mB -> A
    eta:   A -> 0.

With stochastic mass-action propensities using falling factorials, the state changes and rates are

    (a,b) -> (a+1,b)     at alpha,
    (a,b) -> (a-1,b+1)   at beta*a, if a>=1,
    (a,b) -> (a,b+m-1)   at gamma*b, if b>=1,
    (a,b) -> (a+1,b-m)   at delta*(b)_m, if b>=m,
    (a,b) -> (a-1,b)     at eta*a, if a>=1.

These are all enabled transitions; all rates are finite at every fixed state. The reaction graph on complexes 0,A,B,mB has the directed cycles 0<->A and A->B->mB->A. It is strongly connected, hence weakly reversible, and has one linkage class. Its stoichiometric vectors include (1,0) and (-1,1), so the stoichiometric rank is 2. There is no nonzero linear conservation law, and the integer stoichiometric class is the whole N_0^2.

Boundary reachability and class closure

The boundary does not create a closed sub-class.

1. From any (a,b) with b>=1, fire B->mB once. The B count becomes b+m-1>=m, so mB->A is now enabled. Firing it yields (a+1,b-1). Thus the two-step path

       (a,b) -> (a,b+m-1) -> (a+1,b-1)

reduces B by exactly one and increases A by one. Repeating it b times reaches (a+b,0), including when the initial A count is zero.
2. From (a+b,0), firing A->0 exactly a+b times reaches (0,0). If b=0 this is just the direct A drain.
3. From (0,0), fire 0->A exactly a+b times and then A->B exactly b times. This reaches the arbitrary target (a,b).

Every reaction in these finite paths has positive rate at the state where it is used. Hence every state reaches (0,0), and (0,0) reaches every state. All states communicate. Every reaction preserves nonnegative integer counts when enabled, so the entire class N_0^2 is closed.

This conclusion is proved for this network by the paths above. Weak reversibility alone should not be substituted for the enabling argument: reaction-graph paths can fail to be executable at a lattice boundary in other networks. Here the empty-source immigration plus the B->mB->A route explicitly resolves each boundary obstruction.

Non-explosion

Let W(a,b)=1+a+b. Its generator is

    LW = alpha - eta*a + (m-1)*gamma*b - (m-1)*delta*(b)_m.

In particular,

    LW <= alpha + (m-1)*gamma*b
       <= c*W

for any c>=alpha+(m-1)gamma. All upward jumps of V have size at most m-1, and all rates are bounded on each finite state set. Let tau_M be the first time V>=M. Applying stopped Dynkin and Gronwall gives

    P_x(tau_M<=T) <= exp(cT) W(x)/M.

The bound tends to zero as M tends to infinity. Thus the process cannot escape to infinity in finite time. Within a finite state set the total jump rate is bounded, so infinitely many jumps cannot occur there in finite time. The minimal CTMC is non-explosive.

Foster recurrence on the class

Set

    g(b)=alpha+(m-1)[gamma*b-delta*(b)_m].

Since (b)_m is a degree-m polynomial with positive leading coefficient and m>=3, g(b)->-infinity as b->infinity. Choose an integer b_*>=1 such that g(b)<=-1 for all b>=b_*. Let

    G=max{g(b): 0<=b<b_*},
    a_*=ceil((G+1)/eta),
    K={ (a,b): 0<=a<a_*, 0<=b<b_* }.

Here G>=g(0)=alpha>0, so a_* is a positive finite integer. If b>=b_*, then

    LW(a,b)=-eta*a+g(b)<=-1.

If b<b_* and a>=a_*, then

    LW(a,b)<=G-eta*a_*<=-1.

Therefore LW<=-1 outside the finite set K. Together with non-explosion, irreducibility, and finite rates on finite sets, the standard CTMC Foster-Lyapunov criterion gives positive recurrence of N_0^2. The same stopped-Dynkin argument gives a finite expected hitting-time bound E_x[tau_K]<=W(x) for x outside K. There is only one communicating class, so this is also the complete classwise recurrence result.

The argument is valid for every fixed positive rate vector, but its threshold depends on the rates. In particular, no uniform bound over rate vectors is claimed. The exact acquisition of b_* and a_* from arbitrary real rates is also not claimed; with rational rate inputs the inequalities can be searched using exact arithmetic.

Counterexample search / interpretation

No boundary counterexample arises in this network. Even from A=0,B>0, the sequence B->mB->A reduces B one at a time and eventually permits the A drain. From B=0,A>0, the direct A->0 edge drains to the origin. From the origin, immigration followed by A->B constructs every target. This rules out multiple closed communicating classes and makes the attempted classwise obstruction inapplicable here.

The one potential failure to keep separate is a uniform-in-parameters claim: the Foster rectangle can become very large as eta or delta becomes small, or as other rates grow. That is not a failure of positive recurrence for any fixed positive rates and is not a counterexample to the requested fixed-network classwise step.

Claims and falsifiers

- INTERNALLY-PROVED-CANDIDATE: The entire lattice N_0^2 is one closed irreducible communicating class. Falsifier: exhibit a state with no positive-rate path to or from (0,0); the explicit paths cover every (a,b).
- INTERNALLY-PROVED-CANDIDATE: The CTMC is non-explosive and positive recurrent for every fixed positive alpha,beta,gamma,delta,eta and integer m>=3. Falsifier: a violation of LW<=cW, failure of the degree-m limit g(b)->-infinity, or an enabled path contradicting the class partition; none occurs under the stated assumptions.
- NOT FOUND: A counterexample to recurrence of a stochastic component for this network. There is only one component, and it has the Foster drift above.
- NOT CLAIMED: Uniform recurrence constants over rate vectors, a polynomially sized Foster set, an optimal stationary tail, or an extension to arbitrary weakly reversible networks.

The leading-order constant beta does not enter LN because A->B conserves total molecule count. It affects individual transition intensities and the state-to-state communication paths, but not the chosen drift inequality.

Costs and source boundary

Proof cost is symbolic: evaluate five reaction increments, use the falling-factorial propensity for mB->A, and choose finite thresholds from the polynomial g. No simulation or finite state enumeration is used. The state-space cost of explicitly enumerating K is O(a_* b_*), which can be large and is not needed for the Foster theorem.

This is an internally derived candidate proof, not an external novelty claim. Weak reversibility and the general Foster-Lyapunov criterion are established background. No specific historical-priority claim is made. For a comparison boundary, the prior reaction-dynamics capital records N76 as an event-indexed upper-growth inequality, not a physical-time recurrence theorem; here recurrence follows from a direct physical-time drift for this specific network.

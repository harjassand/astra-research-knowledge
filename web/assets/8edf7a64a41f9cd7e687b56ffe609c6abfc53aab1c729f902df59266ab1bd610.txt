Representation transfer is discontinuous under total-variation perturbations
Date: 2026-10-08
Status: exact counterexample for minimal predictive-state structure; no novelty claim.

1. Claim and interface

The observable process law is the supplied object. A source-only acquisition
map receives the exact source law Q and returns its exact minimal predictive
machine. It does not receive target observations or the target law. Reuse
means running that acquired predictive machine unchanged on a later held-out
process P. A prediction query reads the machine state and returns the law of
the next L observations. For conditioning, the held-out process supplies its
actual finite past H_t = (Y_{t-m+1},...,Y_t), and the target conditional law
is P(F_t | H_t), with F_t = (Y_{t+1},...,Y_{t+L}).

For laws on {0,1}^Z, use whole-process total variation

    d_TV(P,Q) = sup_A |P(A)-Q(A)|,

where A ranges over measurable events of the entire bi-infinite process.
This is stronger than asking only for closeness on a single fixed horizon.

2. Counterexample family

Let Q be the stationary one-state HMM that emits 0 forever. For each integer
m >= 2, let R_m be the stationary periodic process obtained by choosing a
uniform random phase in the period word w_m = 1 0^(m-1), then repeating that
word forever in both time directions. For rational 0 < epsilon < 1, define

    P_(epsilon,m) = (1-epsilon) Q + epsilon R_m.

This is a stationary finite-state HMM: one absorbing state emits 0; the other
m hidden states form a deterministic cycle emitting the symbols of w_m;
the stationary hidden-state mass is 1-epsilon on the absorbing state and
epsilon/m on each cycle state. The two observable components have disjoint
supports, so

    d_TV(P_(epsilon,m), Q) = epsilon.

The same equality holds for every length-n block with n >= m: the Q block is
0^n, while every R_m block contains a 1. Thus the perturbation remains
epsilon even when the held-out observation window is long enough to reveal
the rare component.

Define exact causal states by equality of conditional distributions of the
entire future given the semi-infinite past. This is the standard predictive
equivalence definition (Shalizi and Crutchfield, 2001, Definition 5 and
Eqs. (16)-(17)). Directly, any exact history-to-predictive-state machine
must assign different states to histories with different future laws; their
Theorem 2 gives the related minimality result in statistical complexity.
Under Q there is one positive-probability causal state.
Under P_(epsilon,m), the all-zero past from Q has future 0^infinity; each of
the m phases of R_m has a distinct periodic past and a distinct deterministic
future. All m+1 classes have positive probability. Therefore

    number of exact causal states under Q = 1,
    number of exact causal states under P_(epsilon,m) = m+1.

This is an unbounded state-count jump inside every total-variation
neighborhood of Q: for every delta > 0 and every integer M, choose rational
epsilon < delta and m >= M. The source's exact minimal predictive structure
then fails to preserve the target's exact minimal structure. State count is
the complexity measure here; this is not a claim that statistical complexity
or expected memory must jump. For fixed m, the target causal-state entropy is
h_2(epsilon) + epsilon log_2(m), which tends to zero as epsilon tends to
zero.

3. Actual-path held-out prediction error of literal reuse

Let M_Q be the one-state machine acquired from Q. It stores no phase and, on
every query, returns the all-zero future. This specifies its executable
extension on histories that had probability zero under Q; Q itself cannot
determine that extension. Use L=m and the actual m-symbol past H_t above.
On the Q component, H_t=0^m and P(F_t | H_t)=delta_(0^m). On the R_m
component, H_t identifies the cycle phase, and the next m-symbol block has
exactly one 1, so P(F_t | H_t)=delta_(v_t) for some v_t != 0^m. With total
variation loss between conditional distributions,

    e_t = TV(P_(epsilon,m)(F_t | H_t), M_Q(H_t))

is 0 on the Q component and 1 on the R_m component. Consequently, for every
T >= 1,

    P_(epsilon,m){ max_(1<=t<=T) e_t = 1 } = epsilon,
    E_(P_(epsilon,m))[ max_(1<=t<=T) e_t^2 ] = epsilon,
    ess-sup_(target-supported H_t) e_t = 1.

All statements condition on target-supported finite histories. The error is
exact: epsilon can be rational, and all conditional predictions are point
masses, so no numerical precision approximation causes the failure. This
separates rare-path worst-case error from expected actual-path error. The
example does not show a large average error when epsilon is small; it shows
that no uniform conditional guarantee or exact state-partition stability
follows from total-variation closeness alone.

4. Executable cost and scope

Given the exact one-state specification of Q, acquisition writes M_Q's one
state and self-transition: O(1) specification reads, construction work, and
retained state records in this explicit symbolic-record model. M_Q's reuse
update uses O(1) state work per symbol and writes O(L) output bits for an
L-symbol prediction. An exact target machine needs m+1 predictive states. An
explicit transition-table encoding has Theta(m) state/transition records; a
compact uniform program can instead store a phase index in ceil(log_2(m))
bits and advance it modulo m. Either target representation must retain phase
information absent from M_Q. These costs describe executable representations,
not a measured wall-clock advantage. No matched relearning baseline,
acquisition-versus-reuse break-even, or net transfer win is claimed here.

The loss mechanism is not description length or faster execution. It is that
the target assigns epsilon mass to histories impossible under the supplied
source law, and those histories induce different future conditionals. The
source minimal-state machine has no evidence fixing its behavior there. A
theorem claiming uniform conditional transfer must control predictions on
source-null histories, for example through a support/conditioning assumption
or an explicit extension/adaptation rule whose costs are charged. Bounding
the total target mass of those histories can help expected-risk bounds, but
does not by itself control their conditional error. Total variation alone
cannot force literal reuse to recover the new predictive partition.

This is distinct from the amortized-transfer identity in
equal_information_transfer.txt: that criterion compares acquisition plus
reuse costs against a named retaining/relearning baseline on a specified
workload; it does not imply that a representation learned for Q remains
predictive when the law changes to P. This counterexample makes no
amortization claim.

It is also distinct from the canonical arbitrary-HMM compiler target. The
construction is a small exact HMM family and only proves instability of exact
causal-state structure under a weak law metric. It neither proves nor
disproves a general approximate finite-precision compiler with executable
state trajectories and simultaneous readouts. The prior canonical target
remains scoped as unresolved (MEMORY.md:707-713, 808).

5. Primary source and limitations

Cosma Rohilla Shalizi and James P. Crutchfield, “Computational Mechanics:
Pattern and Prediction, Structure and Simplicity,” Journal of Statistical
Physics 104, 817-879 (2001), Definition 5, Eqs. (16)-(17), Theorems 1-3.
The paper defines causal states by identical conditional future laws and
proves their minimal predictive role; the mixture construction and its
total-variation calculations above are proved directly here. Original
primary-source PDF: https://csc.ucdavis.edu/~cmg/papers/cmppss.pdf
DOI: https://doi.org/10.1023/A:1010388907793

The example is non-ergodic because its hidden chain has separate recurrent
components. It does not rule out stability under stronger assumptions such
as irreducibility, uniform mixing, support overlap, or a fixed lower bound on
history probabilities. No priority claim is made for this elementary
construction, and no external empirical validation is involved.

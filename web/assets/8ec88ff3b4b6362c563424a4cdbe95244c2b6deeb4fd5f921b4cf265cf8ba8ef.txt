T06 LEARNING/COMPRESSION — REFINED RECORD v2
Date: 2026-10-09
Status: no universal O(d) construction found; exact cone-cover formulation retained; two finite diagnostics now isolate failures of simple invariant routes.

CORRECTED TARGET

The required information budget is the standard total-size bound: a labeled subsample of at most C d points and a side index from a fixed set of size at most 2^{C d}. Equivalently k+log_2 r=O(d), with k=O(d) and r=2^{O(d)}. An arbitrary finite side budget b(d) is not enough for the requested result. This corrects the looser target language in v1.

COHERENT LIST/CONE COVER CRITERION

For each realizable labeled root a=(T,z), |T|<=k, choose a fixed list H_a of at most r binary hypotheses, each agreeing with z on T. Let V(F) denote the hypotheses in this list which agree with every label of a realizable face F=(A,y). A scheme exists exactly when the lists can be chosen so that

  for every F=(A,y) in P(C), there is a root a=(T,z) with T subseteq A,
  z=y|T, and H_a intersect {h : h|A=y} nonempty.

This criterion states the coherence requirement directly. A separately chosen consistent hypothesis for each full target is not enough; the list H_a must be fixed from the root alone and must cover every partial sample extending that root.

For finite X, the exact integer program has one binary variable x_{a,h} for each legal root and each hypothesis agreeing on that root:

  minimize max_a sum_h x_{a,h}
  subject to sum_{a=(T,z), T subseteq A, z=y|T} sum_{h: h|A=y} x_{a,h} >= 1 for every F=(A,y) in P(C),
             sum_h x_{a,h} <= r for every root a,
             x_{a,h} in {0,1}, |T|<=k.

The corresponding relaxation uses x>=0. Integral feasibility is exactly a cone-cover compression scheme, by ordering the selected cones and returning the first one containing the input face. The LP exposes a possible fractional route but does not supply a rounding theorem. Any rounding must cover every realizable face exactly and preserve the per-root cap; a generic union bound over faces introduces the domain/sample-size dependence the target forbids.

The fractional LP has an exact minimax dual. Let Δ(P(C)) be distributions on realizable faces and define

  Φ_k(ν) = sum_{a=(T,z), |T|<=k} max_{h: h|T=z} ν(K(a,h)).

If t_frac(k,C) is the smallest fractional per-root capacity, finite LP duality gives

  t_frac(k,C) = sup_{ν in Δ(P(C))} 1/Φ_k(ν)
               = 1 / inf_{ν in Δ(P(C))} Φ_k(ν).

Indeed, the dual packs nonnegative face weights y_F and root prices z_a, maximizes Σ_F y_F subject to Σ_{F∈K(a,h)}y_F<=z_a for every root/top pair and Σ_a z_a<=1. For y=Mν, the least permissible z_a is M max_h ν(K(a,h)); normalizing gives the displayed identity. This is an exact finite minimax elimination invariant: a proof that Φ_k(ν)>=2^{-O(d)} for every ν and k=O(d) would yield a fractional list cover with the target per-root scale. It still would not prove an integral scheme without a separate coherent rounding argument.

EXACT OBSTRUCTION TO A NAIVE VERSION-SPACE VC ROUNDING

Let X=[n] and C={c_i : i in [n]}, where c_i(j)=1 iff j!=i (the co-singletons). For n>=3, VC(C)=1: every coordinate takes both labels, while a pair never receives (0,0). For any Q subseteq [n-1] and any R subseteq Q, take the realizable sample with label 1 on Q\R. Its version space is {c_i : i notin Q\R}, whose trace on {c_i:i in Q} is exactly {c_i:i in R}; c_{n} remains a consistent witness. Thus the family of version spaces induced by realizable partial samples shatters n-1 concepts, despite VC(C)=1. `version_space_vc_check.py` exhaustively verifies the n=7 instance (VC dimension 1 for C and 6 for the version-space range family).

This rules out a direct epsilon-net/VC-rounding argument that assumes realizable version spaces have VC complexity O(d). It does not rule out all fractional cone-cover roundings: no integrality-gap lower bound for the cone LP has been proved here.

There is an even more direct exact obstruction to generic VC-net rounding of the cone LP. Fix the empty root and range over all 2^n binary decoder tops h. The n positive singleton faces F_j=({j},1) are realizable, and K((empty),h) contains F_j exactly when h(j)=1. These cones shatter all n singleton faces; since there are only 2^n such cones, their VC dimension is exactly n although VC(C)=1. The n=7 checker verifies the 2^7 traces. Thus no epsilon-net argument can use a cone-range VC bound depending only on d, even before roots are allowed to vary.

Indeed this high version-space VC example is still compressed by a tiny improper scheme: the empty root decodes to the all-ones hypothesis, and a one-point root (j,0) decodes to c_j. Every realizable face is either all-positive (covered by the empty root) or has its unique negative at j (covered by (j,0)). The n=7 checker verifies this for all 575 realizable faces. So the lesson is specifically that version-space VC dimension is the wrong parameter for a direct rounding argument, not that high version-space complexity obstructs compression.

IMPROPER TOPS: A FINITE CONTROL

On Warmuth's C_W from v1, the improper fixed decoder table has 38 roots at support <=2, while `proper_finite_check.py` gives a proper fixed decoder table with 39 roots at the same support. Both tables cover all 176 realizable partial samples; both have one hypothesis per root (zero side bits). Thus improper outputs improve this particular table's count by one but are unnecessary for compression of this class at k=2. This is not a properization theorem and does not establish that improper tops are dispensable in a universal O(d) construction.

ONE-INCLUSION / CUBICAL ROUTE STATUS

Sauer/one-inclusion sparsity gives local low-degree vertices and supports prediction bounds. A decoder needs a globally fixed list per retained labeled root that covers every face above it. The low-degree fact only supplies a vertex relative to each induced sample class; it neither defines such a list nor proves face coverage. Extremal/ample cubical structure does yield size-d compression for those subclasses, but embedding arbitrary VC classes into comparable-dimension extremal classes cannot be the universal bridge: Chase–Chornomaz–Hanneke–Moran–Yehudayoff prove classes of VC dimension d that require any containing extremal class to have dimension at least 2^d-1 (arXiv:2405.17120, Theorem A). This blocks that embedding strategy, not all cubical approaches.

FROZEN STATUS

The exact mathematical deliverables so far are: (i) the cone-cover equivalence and decoder table for C_W in v1; (ii) a proper version of that finite table; and (iii) the co-singleton counterexample showing that version-space range complexity can be arbitrarily large at VC dimension one. No fractional rounding lemma, coherent-cover invariant with O(d) total information, universal reconstruction proof, or independently verified breakthrough has been obtained. The main unresolved step is still to choose fixed H_a lists of size 2^{O(d)} for roots of size O(d) that cover every realizable partial face.

# Non-Clifford code images, diagonal tests, and inverse-resolvent costs

Date: 2026-10-08  
Status: **INTERNALLY-PROVED-CANDIDATE** for the image-penalty construction, its row/gap accounting, the full-support-kernel obstruction in a fixed logical frame, and the positive syndrome-local gap theorem stated below. This gives an exact constant-gap sparse enforcer for a genuinely non-stabilizer code image, but it does not give a common diagonal test for the full BMVZ Hamiltonian. A fixed-frame counterexample rules out that test on one legal full noncommuting BMVZ instance. The QMA-hard fixed-reduction image and arbitrary non-Clifford encoders remain open.

## Interface and conclusion

For a positive contraction \(H\) on a logical space, the target is one isometry \(V:\mathcal L\to\mathcal K\), one computational-basis diagonal contraction \(0\le B\le I\), and one positive contraction \(0\le C\le I\) satisfying

\[
\ker C=\operatorname{ran}V,\qquad
C\ge \gamma(I-VV^*),\qquad
\alpha H\le V^*BV\le\beta H,
\]

with input-independent positive \(\alpha,\beta,\gamma\), plus polynomial row support and a polynomial row-list algorithm. A non-Clifford code can have an exact sparse constant-gap image penalty while its diagonal compression algebra remains too small for the desired \(H\). A local qLTC check average gives a separate inverse-linear gap; an inverse-resolvent makes its spectral gap constant but loses a row-list guarantee.

## A sparse constant-gap enforcer for a non-stabilizer code image

Start with an explicit binary CSS code \(Q\subseteq(\mathbb C^2)^{\otimes N}\) with stabilizer tableau, such as a member of the four-dimensional cubical qLTC family of Chen–Huang–Liu–Tang (CHLT). Let \(P_Q\) project onto \(Q\). This construction needs an exact tableau and not a decoder.

Let \(X_S\le\mathbb F_2^N\) be the group of computational-basis shifts induced by stabilizers, with rank \(r\). Pure-Z stabilizers define an affine valid set \(A\subseteq\mathbb F_2^N\); valid strings split into disjoint orbits of \(X_S\), each of size \(2^r\). For CSS codes, a logical computational-basis vector is uniform on one orbit. For a general stabilizer tableau, its orbit basis has a computable fourth-root phase function \(\omega_O\).

Choose an explicit lazy symmetric constant-degree expander walk \(P_r\) on the \(2^r\) orbit coordinates, with second eigenvalue at most \(\lambda_0<1\). On each valid orbit \(O\), define \(C_Q=I-D_{\omega_O}P_rD_{\omega_O}^*\); on invalid computational strings set \(C_Q=I\). Then

\[
0\le C_Q\le I,\qquad \ker C_Q=Q,\qquad
C_Q\ge\delta_{\rm exp}(I-P_Q),\quad
\delta_{\rm exp}=1-\lambda_2(P_r)>0.
\]

If the expander rotation map has degree \(d_0=O(1)\), each row has at most \(s=d_0+1\) entries. Given a row string, tableau reduction checks pure-Z validity and computes its orbit representative and coordinates; one rotation-map query lists the \(d_0\) neighbors. Preprocessing and each row/entry query take polynomial time and space in \(N\), with constant-bit rational walk weights (and fourth-root phases for a general stabilizer tableau). No decoder is used. This enforcer is **nonlocal**: expander edges can connect strings at Hamming distance \(\Theta(N)\). It is not the bounded-weight qLTC check Hamiltonian.

Append one fixed magic-state qubit

\[
|T\rangle=(|0\rangle+e^{i\pi/4}|1\rangle)/\sqrt2,\qquad
|T^\perp\rangle=(|0\rangle-e^{i\pi/4}|1\rangle)/\sqrt2,
\]

and define \(V_T=V_Q\otimes|T\rangle\), so its image is \(Q\otimes|T\rangle\). This image is not a stabilizer subspace: the last qubit is fixed to a pure non-Pauli-eigenstate. An exact enforcer is

\[
C_T=C_Q\otimes|T\rangle\langle T|
       +I_N\otimes|T^\perp\rangle\langle T^\perp|.
\]

In the orthogonal ancilla decomposition, \(C_T\) is \(C_Q\) on the \(T\) block and identity on the other block. Thus

\[
0\le C_T\le I,\qquad \ker C_T=Q\otimes|T\rangle,
\qquad \gamma(C_T)\ge\delta_{\rm exp}.
\]

If \(C_Q\) has row degree at most \(s\), a physical row of \(C_T\) has at most \(2s+2\) entries: at most \(2s\) from the first tensor term and at most two from the second. A row algorithm makes one \(C_Q\) row query and enumerates the two ancilla values. The workspace overhead is one qubit, the coefficient field adds only the fixed algebraic numbers \(e^{\pm i\pi/4}\), and row/entry time remains polynomial in \(N\). This is an exact non-Clifford code image with a constant-row, constant-gap penalty.

For a target with \(K\) logical qubits, this construction requires a code member with exactly \(K\) logical qubits. CHLT guarantees \(K\ge\alpha_0N\) along its family, but not every requested value of \(K\); fixing spare logical qubits adds a separate constraint whose locality and gap must be charged.

## Why this code's common diagonal test does not encode the BMVZ sum

For any physical diagonal effect \(B=\sum_{x,a}b_{x,a}|x,a\rangle\langle x,a|\),

\[
V_T^*BV_T
=V_Q^*\Big(\sum_x\frac{b_{x,0}+b_{x,1}}2|x\rangle\langle x|\Big)V_Q.
\]

The magic-state phase cancels. Every compression is still diagonal in the CSS orbit-logical basis; allowing \(B\) to be a general diagonal effect rather than a projection does not change this fact.

There is an all-constant-factor obstruction for a concrete **legal full noncommuting BMVZ instance** in this fixed logical frame. On \(n\) data qubits start from the one-color commuting Hamiltonian

\[
H_0=\frac1n\sum_{i=1}^n|-\rangle\langle-|_i,
\]

and append the two BJSW five-qubit seed projectors on a disjoint block as separate singleton layers, giving

\[
H_+=\tfrac12H_0\otimes I
 +\tfrac14 I\otimes|\phi_5\rangle\langle\phi_5|
 +\tfrac14 I\otimes|\psi_5\rangle\langle\psi_5|.
\]

The three commuting layers have positive constant weights, and the seed projectors do not commute with one another. The five-qubit vector

\[
|\chi\rangle=
\frac{3|00010\rangle+3|10010\rangle+
\sum_{z\notin\{00010,10010\}}|z\rangle}{\sqrt{48}}
\]

has full computational support and is orthogonal to both seeds. Hence \(|+\rangle^{\otimes n}\otimes|\chi\rangle\) is a full-support zero-energy state of the complete sum, which is nonzero. Under the BMVZ path/OR construction, \(|+\rangle^{\otimes nR}\otimes|\chi\rangle^{\otimes R}\) remains a full-support kernel vector: every local violation projector annihilates its copy, so every generated OR clause annihilates the product state. This is a legal generated instance, though it is not claimed to be an output of the fixed QMA-hard reduction.

Take a code member whose logical dimension matches this BMVZ data space and fix its CSS logical frame so its orbit basis is the input computational basis. Dimension matching is always possible within this fixed-frame counterexample class: the clean-workspace CSS code \(V_0|\psi\rangle=|\psi\rangle|0\rangle\) has exactly the target logical dimension and an exact one-sparse gap-one enforcer. It is not a qLTC distance example; a CHLT instantiation requires a matching native code dimension. If \(A=V_T^*BV_T\), then \(A\) is positive diagonal in that basis. If

\[
\alpha H_R\le A\le\beta H_R,
\qquad\alpha>0,\quad\beta<\infty,
\]

the full-support ground state \(g\) gives \(0\le\langle g|A|g\rangle\le\beta\langle g|H_R|g\rangle=0\). Positivity and full support force every diagonal entry of \(A\) to be zero, so \(A=0\); the lower inequality then contradicts \(H_R\ne0\). Therefore **no common diagonal effect satisfies any positive two-sided comparison for this full BMVZ instance in this fixed-frame code class**, even though \(C_T\) has exact unit-scale kernel and constant gap.

The limitations matter. This does not refute the fixed-reduction hard family, whose yes energy may be positive rather than zero. It also does not handle an arbitrary logical basis change \(V_QW\): such a \(W\) can map this particular ground vector to a coordinate vector. For an arbitrary hard instance, a free \(W\) chosen from an eigenbasis gives a formal diagonal effect, but no efficient \(W\) or eigenvalue lookup is known. So the result is a precise counterexample to the fixed-frame magic-state/qLTC route, not a general no-go for non-Clifford encodings.

## Local qLTC checks and the inverse-resolvent tradeoff

For the CHLT four-dimensional binary CSS family, Theorem 1.2 gives explicit polynomial-time matrices \(H_X,H_Z\), with \(H_XH_Z^{\mathsf T}=0\), \(K\ge\alpha_0N\), distance \(D\ge\delta_0N\), row and column weights at most a constant \(\Delta\), \(m_X,m_Z=\Theta(N)\), and Hamming soundness \(\rho>0\). The theorem does not numerically instantiate these constants and does not supply a decoder. Standard symplectic elimination computes a tableau and Clifford encoder in polynomial time; the native physical/logical overhead is \(N/K\le1/\alpha_0\).

Let \(S_j\) be the \(m=m_X+m_Z\) nonidentity CSS checks, \(Q_j=(I-S_j)/2\), and

\[
C_{\rm av}=\frac1m\sum_{j=1}^m Q_j.
\]

Its kernel is exactly the code. Commutativity gives \(\gamma(C_{\rm av})\ge1/m\). Since the distance exceeds one for large \(N\), at any physical site one of \(X_i,Z_i\) has nonzero syndrome; that one-site Pauli violates at most \(\Delta\) checks, giving \(\gamma(C_{\rm av})\le\Delta/m\). Hence

\[
1/m\le\gamma(C_{\rm av})\le\Delta/m=\Theta(1/N).
\]

The qLTC inequality detects a weight-one error with rejection fraction at least \(\rho/N\); bounded column incidence gives the matching \(O(1/N)\) upper bound. This is Hamming-distance soundness, not constant normalized energy gap. In the computational basis each CSS check projector has at most two entries per row. The average has at most \(m_X+1=O(N)\) entries per row, can be listed in \(O(m\Delta)\) time by scanning sparse checks, and has rational coefficients with \(O(\log m)\) bits. The unnormalized sum has gap at least one but norm at most \(m\); normalization to a contraction produces the inverse-linear gap.

For any such \(C_{\rm av}\) with exact gap \(\gamma\), the inverse-resolvent

\[
R_\tau=C_{\rm av}(C_{\rm av}+\tau I)^{-1}
\]

is a positive contraction with the same exact kernel and gap at least \(\gamma/(\gamma+\tau)\). At \(\tau=\gamma\), the gap is at least \(1/2\). But this formula gives no polynomial row-list algorithm: the inverse can fill in rows, and the qLTC matrix/decoder guarantees do not control its support. No density lower bound for the CHLT resolvent is claimed.

The standard sparse Schur parent makes the normalization cost explicit. With one extra flag qubit, put

\[
P_\tau(C)=\frac1\tau
\begin{pmatrix}C&C\\ C&C+\tau I\end{pmatrix}.
\]

It is positive, its Schur complement is \(C(C+\tau I)^{-1}\), and if \(C\) has row degree \(s\) then the parent has row degree at most \(2s+1\). At \(\tau=\gamma\), its first positive eigenvalue is at least \((3-\sqrt5)/2\), while its norm is \(\Theta(1/\gamma)=\Theta(N)\). Scaling it to a contraction restores only gap \(\Theta(\gamma)=\Theta(1/N)\). Thus this one-qubit linearization preserves polynomial row access and exact kernel, but does not provide a constant **normalized** gap.

## A broader positive local syndrome theorem

The inverse-resolvent calculation is not the only limit on locally testable code routes. Consider \(t\) independent binary syndrome bits \(x\in\{0,1\}^t\), an arbitrary common auxiliary Hilbert space, and a positive budget-one syndrome-local operator whose block at syndrome \(x\) is

\[
K_x=\sum_a w_a E_{a,x|S_a},\qquad
w_a\ge0,\quad\sum_aw_a=1,\quad0\le E_{a,\cdot}\le I,
\quad |S_a|\le r.
\]

The effects may be nonlinear and noncommuting on the auxiliary system; only the syndrome coordinates read by term \(a\) are restricted. If \(\inf\operatorname{spec}K_0\le\eta\) and \(K_x\ge cI\) for every nonzero syndrome, then

\[
c\le\eta+\frac rt(1-\eta).
\]

Proof: take a unit vector whose zero-syndrome energy approaches \(\eta\). For any term reading \(S_a\), all singletons \(e_i\) with \(i\notin S_a\) use the same effect as at zero; for the at most \(r\) remaining singletons use \(E\le I\). Thus

\[
\frac1t\sum_{i=1}^tK_{e_i}
\le(1-r/t)K_0+(r/t)I.
\]

Every \(K_{e_i}\ge cI\), so expectation in the near-ground vector and a limit give the claim. Exact completeness \(\eta=0\) therefore forces \(c\le r/t\): constant gap requires checks that read \(\Omega(t)\) syndrome bits, even with unrestricted noncommuting workspace.

For the robust version, suppose blocks \(\widetilde K_x\) are within operator norm \(\epsilon\) of such a budget-one \(r\)-local family \(K_x\), the approximate zero block obeys \(\inf\operatorname{spec}\widetilde K_0\le\eta\), and every approximate nonzero block obeys \(\widetilde K_x\ge cI\). If \(\eta+\epsilon\le1\), then

\[
c\le\eta+\frac rt(1-\eta)+(2-r/t)\epsilon.
\]

Indeed, the exact family has zero-block minimum at most \(\eta+\epsilon\), and its nonzero singleton blocks are bounded below by \(c-\epsilon\); apply the exact inequality and rearrange. Thus small operator-norm approximation does not rescue bounded-syndrome checks.

This theorem excludes the stated positive-term syndrome-local enforcer class, not every sparse matrix with a code kernel. Sector-coupling encodings, \(x\)-dependent auxiliary identifications, or globally positive constructions without a normalized positive local-term budget are outside its premise. The orbit-expander \(C_Q\) above escapes by using nonlocal transitions across each full orbit.

## Exact scope

This route produces an exact constant-row, constant-gap enforcer for a non-stabilizer code image, but the diagonal compression remains in a commuting orbit algebra and fails on the explicit full-support-kernel BMVZ instance. The CHLT qLTC check average has polynomial rows but gap \(\Theta(1/N)\); its inverse-resolvent has constant gap but no row-list guarantee; the standard sparse Schur parent has polynomial rows and constant unnormalized gap but only inverse-linear normalized gap. The N26 theorem blocks positive bounded-syndrome local checks even with arbitrary quantum auxiliary space.

Still **UNKNOWN**: an efficient non-Clifford logical frame or locally testable encoding for the fixed QMA-hard BMVZ family that supplies one common diagonal \(B\) with \(\alpha H\le V^*BV\le\beta H\), alongside an exact or certified operator-norm-approximate sparse \(C\) with polynomial row access and constant normalized gap. A general Naimark construction has \(B\) and a unit-gap \(C\) for every \(H\),
\[
V_H|\psi\rangle=\sqrt H|\psi\rangle|1\rangle+\sqrt{I-H}|\psi\rangle|0\rangle,
\]
but row access to \(I-V_HV_H^*\) requires the matrix roots and is not supplied by a term list. This is the remaining joint gate.

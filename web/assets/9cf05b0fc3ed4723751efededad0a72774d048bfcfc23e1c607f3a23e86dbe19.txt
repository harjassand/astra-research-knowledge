Proof and exact interfaces
Leaf 05 — noncommutative-to-commutative PIT

A. Fixed-order bridge

Theorem. Let F be any field. Let A be a layered commutative ABP with layers V_0,...,V_n, one transition from layer i-1 to i for each i=1,...,n, and each edge e in that transition labeled a_e+b_e x_i. Let p_A in F[x_1,...,x_n] be its source-to-sink path polynomial. Homogenize each edge to a_e x_0+b_e x_i and interpret the same graph over F⟨x_0,x_1,...,x_n⟩; call its output R_A. Then p_A=0 if and only if R_A=0. Consequently, deterministic noncommutative ABP PIT decides this commutative PIT instance in polynomial time.

Proof. Add a fresh variable x_0 and replace each edge label by the homogeneous linear form a_e x_0+b_e x_i. Let P_A be the resulting commutative path polynomial and let R_A be the same graph interpreted in the free algebra F⟨x_0,x_1,...,x_n⟩. Every path uses exactly one edge from each layer. Upon expansion, each term selects a subset S of layers at which the x_i term was chosen. Its commutative monomial is

    x_0^(n-|S|) product_{i in S} x_i,

and its free word is the length-n word whose i-th letter is x_i if i is in S and x_0 otherwise. Distinct subsets S yield distinct commutative monomials and distinct free words. The coefficient attached to S is the same sum of path-coefficient products in P_A and R_A. Hence coefficient cancellation occurs in one representation exactly when it occurs in the other:

    P_A=0  iff  R_A=0.

Also P_A(1,x_1,...,x_n)=p_A. Because the monomials of P_A are exactly the displayed indexed family and remain distinct after setting x_0=1, P_A=0 iff p_A=0. Combining gives the theorem.

The lift is still an ABP with the original vertices and edges, now over one extra variable. The Raz–Shpilka algorithm is deterministic polynomial-time white-box PIT for noncommutative ABPs. Over F_2, each field operation is constant-cost, so the reduction has polynomial bit complexity in the explicit graph size. For arbitrary coefficient encodings over Q, this note claims only the arithmetic-operation bound unless an implementation-specific bit-growth audit is added.

The one-variable-per-layer hypothesis matters: it guarantees that each path word is already in the same canonical variable order. This proof does not apply to an arbitrary ABP where different paths can permute variables.

B. Failure of the same-path lift for general commutative ABPs

Let A have two source-to-sink paths. The first path has edge labels x then y; the second has labels -y then x. Its commutative polynomial is

    p_A=xy-yx=0 in F[x,y].

The same graph interpreted in the free algebra computes

    Q_A=xy-yx != 0 in F⟨x,y⟩,

because xy and yx are distinct basis words. Equivalently, abelianization ab:F⟨x,y⟩→F[x,y] has a nonzero kernel containing xy-yx. Thus q=0 implies ab(q)=0, but the converse needed for this lift fails. This refutes only the direct same-graph lift as a general identity-preserving reduction.

C. Exact blow-up-rank obstruction for an ABP determinant encoding

Let F be any field. Let A be an arbitrary commutative ABP for p, and q its path lift, so ab(q)=p. Construct a finite DAG H with a distinguished source s and sink t whose path polynomial in the free algebra is

    g=qz+ab-ba,

where a,b,z are fresh variables. A common source and sink can be joined to the three branches with constant-labeled edges; this changes the number of vertices and edges by only O(1) beyond the copy of A. Put the vertices in topological order. Let U be the strictly upper-triangular weighted adjacency matrix: U_ij is the sum of labels on edges i→j. For m=|V(H)|, U^m=0, so (I_m-U)^(-1)=I_m+U+...+U^(m-1).

Define the affine linear pencil L of size m+1 by

    L = [ I_m-U    e_t ]
        [ e_s^T     0  ].

The block determinant / Schur-complement identity is valid because I_m-U has determinant 1 and a polynomial inverse. Hence

    det_comm(L)
      = det(I_m-U) * (-e_s^T (I_m-U)^(-1) e_t)
      = - ab(g)
      = -zp.

The commutative rank is the rank over F(x_1,...,x_n,z,a,b). If p is nonzero, -zp is a nonzero polynomial, so L has rank m+1. If p=0, its determinant vanishes, so its rank is at most m. The upper-left m×m submatrix I_m-U has determinant 1, so rank is at least m. Thus

    crank(L)=m+1 iff p!=0;   crank(L)=m iff p=0.

For a blow-up of dimension d, evaluate every variable at a matrix in M_d(F) and every scalar coefficient c at cI_d; the resulting matrix has order d(m+1). Now take d=2 and substitute x_i=0, z=0, a=A=E_12, b=B=E_21. The qz branch vanishes. The other two source-to-sink branches give

    e_s^T (I_m-U(A,B))^(-1) e_t = AB-BA = E_11-E_22.

This is invertible over every field: its determinant is -1, which is nonzero; in characteristic 2 it equals I_2. The block matrix U(A,B) is still strictly upper triangular, hence I_m-U(A,B) is invertible. Its Schur complement in L(A,B) is -(AB-BA), also invertible. Therefore

    rank_F L(A,B)=2(m+1).

This reaches full possible rank for every p, including p=0. Under the standard blow-up definition of noncommutative rank as the maximum normalized rank over matrix substitutions, this makes the pencil full noncommutative rank in both cases. The conclusion also stands on the literal d=2 blow-up alone and does not require identifying other notions of rank.

The matrix dimensions are exact: pencil order m+1; blow-up parameter d=2; evaluated order 2(m+1). The witness does not inspect coefficients of p beyond retaining its ABP in the dormant qz branch. Building the block-sparse witness costs O(m+|E(H)|) operations on constant-size blocks. If materialized densely, the evaluated matrix has O(m^2) entries.

D. What the proof does not show

Neither the kernel example nor the blow-up gadget rules out another polynomial-time map from general commutative circuits to a model covered by NC PIT. They show why the two obvious transfers fail: preserve the input ABP syntax and identities can split under abelianization; preserve commutative rank with this determinant gadget and noncommutative blow-up rank is already saturated by a 2×2 commutator. No PIT hardness lower bound is proved.

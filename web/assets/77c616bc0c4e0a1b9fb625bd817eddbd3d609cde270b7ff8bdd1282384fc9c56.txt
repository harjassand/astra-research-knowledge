INDEPENDENT AUDIT: MARKED-RENEWAL ROW-URN CODE
2026-10-08

Verdict
=======

The row-urn construction in outputs/research/sol_marked_renewal/RESULT.txt
passes this independent algebraic audit under its stated interface: a known,
fixed q-symbol event-mark alphabet; visible event times and marks in one raw
path; one Markov-renewal kernel p_i(g,d); and a stationary version with finite
mean under a stationary distribution of the embedded mark chain. I found no
counterexample to properness, pointwise domination, the exact prefix formula,
the row-statistic DP, the integer-denominator claim, or the fixed-q polynomial
cost. The result remains an internally proved candidate: this audit is not
proof-assistant verification, external expert validation, or a novelty/priority
survey.

The decisive design choice is correct: stop as soon as the current row is
empty, and leave all other-row counts unused. Requiring every pool item to be
used would reject valid generated paths and destroy the stated normalization
and prefix formula. A concrete branch is q=2, N=2, with one pool item from
mark 1 to mark 2 at gap 1, but start mark 2 at position 1. The row for mark 2
is empty immediately, so the code emits (mark 2, 0) with the mark-1 item
unused. Its conditional probability under that pool is 1/[q(N-S)]=1/2.

Scope and stationary likelihood
===============================

Let marks be [q], and let p_i(g,d) be the probability that after an event of
mark i the next event is g positions later and has mark d. Write
P(i,d)=sum_g p_i(g,d), let pi be a stationary law for P, and let
M=sum_i pi_i sum_{g,d} g p_i(g,d)<infinity. For a stationary time origin,
the countdown/next-mark state has law

  nu(r,d) = M^{-1} sum_i pi_i sum_{g>=r} p_i(g,d).

This normalizes because summing over r,d gives M^{-1}sum_i pi_i sum_{g,d}
g p_i(g,d)=1. It also gives nu(1,d)=pi_d/M. This formula allows dependence
between gap and destination, reducible embedded chains, and a stationary
mixture over recurrent classes of this one kernel. It does not cover hidden
marks, invisible same-mark events, or mixtures over different kernels unless
those are separately added to the model.

For a nonzero length-N block, let a be its first event time and u its first
mark; let c_{i,d,g} be the completed transition counts between visible events;
let ell be the final visible mark and b the trailing zero age. Its target mass
is exactly

  P_N(x)=nu(a,u) prod_{i,d,g} p_i(g,d)^{c_{i,d,g}}
           sum_{d,g>b} p_ell(g,d).

The initial equilibrium-residual and terminal survival factors are both at
most one. The all-zero block has target mass

  M^{-1} sum_i pi_i sum_{g,d} (g-N)_+ p_i(g,d) <= 1.

No uniform mean, support, mixing, or minimum-transition-mass promise is used.

Code properness and pointwise domination
========================================

For horizon N, a pool is C=(C_{i,d,g}) with g=1,...,N-1 and span
S(C)=sum g C_{i,d,g}<=N-1. The pool count is
P_{q^2}(N)=sum_{s=0}^{N-1} p_{q^2}(s), where p_{q^2}(s) counts
q^2-coloured partitions of s. Put K_N=1+P_{q^2}(N), with the extra one
reserved for a single all-zero option.

Choose uniformly from the all-zero option and every pool. For a chosen pool,
choose anchor a uniformly in {1,...,N-S}, then start mark i uniformly in
[q]. Emit i at a. At current row i, if its remaining outgoing count is zero,
stop and pad with zeros. Otherwise sample one remaining (d,g) label with
probability its multiplicity divided by the current row total, consume it,
emit d after g positions, and repeat. Every draw removes one of at most
R=sum C items, so termination takes at most R transitions. The total used
gap span is no greater than S; hence the last event time is at most
a+S<=N. Every random choice is normalized. Therefore Q_N is a proper
distribution on length-N strings.

For any nonzero x, take its exact transition-count pool c(x). Its span is
last_time-a<=N-a, so the anchor is allowed. The observed ordered row draws
have probability

  prod_i prod_{d,g} c_{i,d,g}! / prod_i r_i!,
  r_i=sum_{d,g} c_{i,d,g}.

The target code contribution from this one pool/anchor/start is therefore

  Q_N(x) >= [q K_N (N-S)]^{-1}
             prod_i prod_{d,g} c_{i,d,g}! / prod_i r_i!.

For each row i, (r_i!/prod c_{i,d,g}!) prod p_i(g,d)^{c_{i,d,g}}
is a multinomial probability and is at most one. Combining with the target
likelihood gives P_N(x)/Q_N(x)<=q K_N(N-S)<=q K_N N. The global all-zero
option gives P_N(0^N)/Q_N(0^N)<=K_N. Thus

  D(P_N||Q_N) <= log(q K_N N).

This proof does not condition on, or normalize by, a rare Euler trail. In
particular, unused counts in non-current rows neither invalidate a path nor
enter a stopping event.

Exact prefixes, including all unused pools
==========================================

Fix a prefix y of length t with at least one event. Let a be its first event
time, ell its last event mark, b=t-last_event_time, c_{i,d,g} its completed
transition counts, r_i=sum_{d,g}c_{i,d,g}. For a candidate pool C define

  R_i=sum_{d,g} C_{i,d,g},
  W(C)=prod_{i,d,g} (C_{i,d,g})_{c_{i,d,g}},
  D(C)=prod_i (R_i)_{r_i},
  T=R_ell-r_ell,
  L(C)=sum_{d,g>b}(C_{ell,d,g}-c_{ell,d,g}),

where (u)_v=u!/(u-v)!, and a pool contributes only when C>=c
coordinatewise and S(C)<=N-a. Its exact prefix contribution is

  [q K_N (N-S)]^{-1} [W(C)/D(C)] times
       1                         if T=0,
       L(C)/T                    if T>0.

Reason: the observed completed ordered transitions have the without-
replacement probability W/D. If T=0 the current row is empty and the code
stops, regardless of unused counts in other rows. If T>0, the next sampled
edge must have gap strictly greater than b; exactly L of T remaining edges
qualify. After that edge, all unobserved continuation paths sum to one.
At t=N the T>0 term is necessarily zero: remaining total span is at most
N-a minus the already used first-to-last span, which is at most b, so no
remaining gap can be >b.

For the all-zero prefix, the separate all-zero atom contributes 1/K_N. A
pool contributes if its anchor lies after t, giving

  Q_N(0^t) = [1 + sum_{S<N} p_{q^2}(S) (N-S-t)_+/(N-S)]/K_N.

The formula gives Q_N(empty)=1 and Q_N(0^N)=1/K_N. No-event prefixes are
not obtained by forcing all pools to be empty.

DP and exact bit accounting
===========================

The prefix sum can be compiled without enumerating paths or Euler trails.
Track total span S and row totals R_1,...,R_q. For each local coordinate
(i,d,g), with observed lower count c=c_{i,d,g}, choose u>=c and set
w=(u)_c. Also set lambda=u-c when i=ell and g>b, and lambda=0 otherwise.
Maintain integer tables A and B, initialized by A(0,0_vec)=1 and B=0, with
updates

  A_new(S+gu,R+u e_i) += w A_old(S,R),
  B_new(S+gu,R+u e_i) += w [B_old(S,R)+lambda A_old(S,R)].

Cap span at N-a. A sums W(C), and B sums W(C)L(C). At the end divide by
(N-S)prod_i(R_i)_{r_i}; for T>0 divide B by the additional T, while for
T=0 use A. Then divide the sum by qK_N. The additive marked statistic L is
all the terminal-age test requires.

The integer common-denominator assertion in Sol's packet checks out. For
T=0, every (R_i)_{r_i} divides R_i!, their product divides R!, and
N-S divides (N-R)! because 1<=N-S<=N-R. Hence
(N-S)prod_i(R_i)_{r_i} divides N!. For T>0 combine
(R_ell)_{r_ell}(R_ell-r_ell)=(R_ell)_{r_ell+1}, which divides R_ell!;
the same argument applies. Each no-event denominator N-S also divides N!.
Consequently H_N(y)=qK_N N! Q_N(y) is integer for every prefix, and
H_N(y)=sum_{v=0}^q H_N(yv). This uses R=sum_i R_i<=S; it is valid also
for the empty pool and N=1.

There are O(N^{q+1}) (S,R-vector) table cells, O(q^2 N) coordinates, and
at most N multiplicities per cell, so the conservative count is
O(q^2 N^{q+3}) integer updates per event-prefix marginal. Pool counts come
from the colored-partition recurrence in O(q^2N^2) updates. Table entries
are bounded in bit length by O(N log(N+1)+q sqrt(N)+log(q+1)); H_N and
qK_NN! use O(N log(N+1)+q sqrt(N)+log(q+1)) bits as well. A conservative
schoolbook bit bound per marginal is O_q(N^{q+5}log^2(N+1)); memory is
O_q(N^{q+2}log(N+1)) bits. The predictor needs O(qn) child-prefix calls,
and exact averaging can use O_q(n^2 log n) output bits. Thus the stated
whole-predictor bound O_q(n^{q+6}log^2(n+2)) is conservative and polynomial
for each fixed supplied q, not jointly polynomial in unbounded q.

The code's maximum number of anchor/start pairs for a pool is q(N-S)<=qN.
The separate zero option is outside this count. The qN+1 quantity in the
risk proof is instead the number of clipped countdown/next-mark states:
(r,d) for r<=N, plus one sentinel for r>N. These are distinct caps.

Partition bound and prediction reduction
========================================

For d=q^2 colours,

  prod_{g>=1}(1-exp(-beta g))^{-d}

generates p_d(s). Since log of the product is
d sum_{k>=1}1/[k(exp(beta k)-1)]<=2d/beta,

  sum_{s<N}p_d(s)<=exp(beta N+2d/beta).

Taking beta=sqrt(2d/N) and adding the all-zero option gives

  log K_N <= log 2 + 2 q sqrt(2N).

Use the fixed length N=n+1 distribution Q_N and its prefix conditionals.
The suffix-average predictor from Han--Jiang--Wu's stationary
compression-to-prediction proposition has expected terminal KL at most

  [D(P_N||Q_N)+ sum_{t=1}^n
       I(X_{n+1};X^{n-t}|X_{n-t+1}^n)]/n.

The stated
stationary countdown state Z_1=(r,d) yields, by conditional data processing
and stationarity, a bound on that sum by I(Z_1;X^N). Replace Z_1 by its exact
(r,d) for r<=N and one sentinel for r>N. In the sentinel case the length-N
block is all zero; otherwise the capped state retains the full initial
countdown and mark, so X^N is conditionally independent of Z_1 given the cap.
There are qN+1 capped values, hence I(Z_1;X^N)<=log(qN+1). No finite entropy
assumption on the uncapped countdown is needed.

Combining terms gives

  E KL(P(X_{n+1}|X^n)||qhat_n(.|X^n))
  <= [log 2 + 2q sqrt(2(n+1)) + log q + log(n+1)
      + log(q(n+1)+1)]/n.

For fixed q this is O(n^{-1/2}) uniformly over the stated arbitrary-finite-
mean class. The class contains the binary renewal subclass, and categorical
KL is at least the binary KL after normalizing predicted mass on {0,1}; thus
the HJW binary lower bound transfers and gives a fixed-q minimax
Theta_q(n^{-1/2}) order. This does not assert a sharp q-dependent constant.

Adversarial guards and exact diagnostics
========================================

Three concrete mutations fail:

1. If anchor positions are not restricted to 1,...,N-S, then q=1,N=3 with
   two gap-1 pool items and anchor 2 generates events at 2,3,4, outside the
   length-3 block. Sol's restriction prevents this.
2. If the tail condition uses g>=b instead of g>b, a prefix ending one zero
   after its last event (b=1) incorrectly allows another event at gap 1,
   which contradicts the observed zero. Sol's strict inequality is correct.
3. If one forces every row pool to be used, the q=2,N=2 branch described
   above is lost. This breaks properness unless a new rejection/renormalization
   mechanism is defined, and changes the prefix law. Sol's stop-on-current-
   row-empty rule is essential.

# Parameterized-counting prior-art audit for the low-sector Pfaffian route

Worker c03_l04, phase-2 assigned audit. This is an attributed literature/interface comparison, not a proof review of every internal theorem and not a novelty claim. `INITIAL.txt` remains immutable.

## 1. Compared interfaces and costs

### General low-sector counter and physical prefixes

The assigned target is an explicitly encoded (F\in\mathbb Q(i)^{n\times n}), total binary length (L), and integer (0\le k\le\lfloor n/2\rfloor), with

\[
c_k(F)=\sum_{\substack{|I|=|J|=k\\I\cap J=\varnothing}} |\det F[I,J]|^2.
\]

The counter is claimed to return exact zero on every zero instance and, when (c_k(F)>0), a relative-η estimate with probability at least (1-δ). The central parameter factor is (C_k=\binom{2k}{k}\sim 4^k/\sqrt{\pi k}). For the assigned implementation, one prefix estimator uses

\[
M=\left\lceil 3 C_{a,b}\,\lceil\log_2(2/\delta)\rceil/\eta^2\right\rceil,
\qquad C_{a,b}=\binom{2k-a-b}{k-a},
\]

sign samples (or exact enumeration when the free sign cube is no larger than this cap). Here (a=|U|,b=|D|), for pairwise disjoint prescribed-up, prescribed-down, and prescribed-empty site sets (U,D,H). Each sign sample forms (2^b(2a+1)) trace/Newton coefficient calls. A coefficient call costs (O(kn^3+k^2)) exact rational/Gaussian-rational arithmetic operations by the supplied implementation. The identity (2^b C_{a,b}\le C_k) therefore gives at most

\[
O\!\left(C_k(2a+1)\eta^{-2}\log(1/\delta)\right)
\]

coefficient calls for a prefix estimate. Denominator clearing and trace/Newton intermediates are claimed to have polynomial bit length in (n,L,k,\log(M)); so the headline is (C_k\,\mathrm{poly}(n,L,\eta^{-1},\log(1/\delta))) bit work. With (U=D=H=\varnothing), this is the unconditioned counter. For fixed (A), (k\le A\log_2(n+1)) makes (C_k\le n^{2A}); when (k=\Theta(n)), the dependence is exponential.

For the code's sequential Born sampler, (c_k(F)>0) is promised. It uses η=ε/(8n), δ_call=ε/(12n), at most (3n) child-prefix estimates, and (s=\lceil\log_2(8n/\epsilon)\rceil) bits for each ternary decision. The cap gives (O(C_k k n^7\epsilon^{-2}\log(n/\epsilon))) scalar arithmetic operations using the preceding per-coefficient (O(kn^3+k^2)) bound; rational bit costs add only polynomial factors. The claimed total-variation guarantee is on configurations plus a failure symbol. This output interface is narrower than an all-runs legal-configuration sampler.

The physical-prefix mass is the original weighted sum restricted by (U\subseteq I), (D\subseteq J), and ((I\cup J)\cap H=\varnothing); there is no promise that a positive prefix has mass bounded below by the root mass. This is a material difference from literature algorithms that only estimate one global combinatorial count.

### Phase-matched extension

The assigned `phased_pfaffian.py` accepts only even (n), legal (k), and a fixed adjacent-pair anchor ((0,1),(2,3),\ldots). It retains each diagonal entry and each anchor pair's real entries in (G), sets \(\beta_j=F_{2j,2j+1,\mathbb R}^2+F_{2j+1,2j,\mathbb R}^2\), and certifies only if (\beta_{\min}>0) and

\[
\Delta^2=\|F-G\|_F^2\le \beta_{\min}/(256k^2).
\]

On acceptance it samples a site-sign Pfaffian coefficient with batch size \(\lceil16/\epsilon^2\rceil\) and (8\lceil\log_2(1/\delta)\rceil+1) median-of-means rounds. The total is (O(\epsilon^{-2}\log(1/\delta))) coefficient evaluations, each (O(kn^3+k^2)) exact arithmetic operations, plus polynomial bit costs and (n) random bits per sample. (k=0) returns 1 without sampling. Failure of the certificate returns `NOT_CERTIFIED`; it does not return an estimate for a general input. The code has no arbitrary-prefix counter or Born sampler.

For any fixed phases γ_i of unit modulus, the random signs (s_i\gamma_i) preserve the unbiasedness identity: in the Pfaffian expansion the monomial indexed by a site set (S) has character \(\prod_{i\in S}s_i\) times a fixed unit-modulus factor; independent sign orthogonality kills cross terms for (S\ne T), and the diagonal terms are unchanged. Thus the phase choice is not itself an interface problem. The decisive extra claim is the uniform pointwise comparison between every sampled coefficient and the acquired baseline under the residual threshold. The implementation tests that assertion with `assert`; `acquire()` computes the threshold but contains no derivation of the implication. The accompanying checker provides finite checks only (96 sign words, 352 coefficient comparisons, 10 sector-mean checks, one count smoke); it does not prove that implication for all accepted rational matrices.

## 2. Closest parameterized-counting prior art

1. **Arvind and Raman, “Approximation Algorithms for some Parameterized Counting Problems,” ECCC TR02-031 (2002).** For an (n)-vertex graph and the number of unweighted matchings of size (k) (equivalently copies of the (k)-edge matching pattern, of treewidth 1), the report gives (k^{O(k)}n^{O(1)}) time, approximation ratio (1/k^{O(k)}), and error probability (2^{-n^{O(1)}}). This is a genuine FPT-style approximation antecedent for matching counts. Its stated weak approximation ratio is not the assigned relative-η FPTRAS guarantee; its input is a graph and its object weight is 1. [Primary source](https://eccc.weizmann.ac.il/eccc-reports/2002/TR02-031/index.html).

2. **Friedland and Levy, “A polynomial-time approximation algorithm for the number of (k)-matchings in bipartite graphs” (2006 preprint).** The interface is a nonnegative (m\times n) matrix (B\in\mathbb R_+^{m\times n}), with \(\mathrm{perm}_k(B)=\sum_{|I|=|J|=k}\mathrm{perm}(B[I,J])\), the total product-weight of size-(k) matchings in the induced bipartite graph. They construct a padded square matrix (B_k\) of order (m+n-k) and prove \(\mathrm{perm}_k(B)=\mathrm{perm}(B_k)/((m-k)!(n-k)!)\); a nonnegative-permanent FPRAS gives polynomial time in the padded input size and accuracy parameter. The source states an FPRAS but does not give a modern bit-model exponent in the abstract. This is close in “sum over order-(k) objects” and, for bipartite graph input, improves any (4^k\) parameter factor. It does not cover complex signed minors squared: permanent terms are locally product-weighted and do not have the alternating cancellation inside \(|\det|^2\). It also lacks the same-site disjoint restriction (I\cap J=\varnothing). [Primary preprint](https://arxiv.org/abs/cs/0607135).

3. **Liu, Chen, and Wang, “On Counting 3-D Matchings of Size (k),” Algorithmica 54 (2009).** Input is a set (S) of (N) triples and (k); the count is the number of (k)-subsets of pairwise coordinate-disjoint triples. Their FPTRAS runs in \(O(5.48^{3k}N^2\ln(2/\delta)/\epsilon^2)\), with relative error ε and success probability (1-δ). This confirms that strong relative approximation for parameterized packing counts is established prior art. The dependence (5.48^{3k}\approx164.7^k) is larger than (C_k\approx4^k/\sqrt{\pi k}), but the objects, weights, and input size differ, so this is not an apples-to-apples algorithmic dominance claim. [Primary article](https://link.springer.com/article/10.1007/s00453-008-9207-x).

4. **Liu, Wang, and Wang, “Parameterized counting matching and packing: A family of hard problems that admit FPTRAS,” TCS 734 (2018).** The abstract explicitly includes set packing, graph matching, and vertex-/edge-disjoint subgraph packing, states #W[1]-hardness for a series of them, and gives an FPTRAS for each considered problem by extending the 3-D matching approach. The accessible abstract does not expose the individual (f(k)) factors, so I use it as existence-level taxonomy, not a numerical runtime comparator. It also illustrates that exact #W[1]-hardness and parameterized randomized approximation can coexist; exact-count hardness alone would not refute this route. [Publisher record and abstract](https://www.sciencedirect.com/science/article/pii/S0304397517306849).

5. **Jain, Perkins, Sah, and Sawhney, “Approximate Counting and Sampling via Local Central Limit Theorems” (2021 preprint).** Theorem 1.1 gives a *deterministic FPTAS* for the unweighted count (m_k(G)), on maximum-degree-Δ graphs, when (1\le k\le(1-\delta)m^*(G)), with running time \((n/\epsilon)^{O_{\delta,\Delta}(1)}\) and multiplicative (e^{\pm\epsilon}) error. Thus a low-(k), bounded-degree graph-counting subclass can have polynomial dependence on (n,1/\epsilon), without any (4^k) term. It is not an algorithm for arbitrary (\mathbb Q(i)) matrices or determinant-square weights. The same paper gives a randomized near-linear TV sampler for size-(k) matchings under its bounded-degree/margin hypotheses, again for the uniform graph-matching law. [Primary paper](https://arxiv.org/abs/2108.01161).

## 3. Exact match/mismatch and novelty boundary

* The label “matching/packing” is not enough to transfer an FPTRAS. In a graph-matching input, each legal object is a set of (k) edges with endpoint-disjointness and (in weighted versions) a product of edge weights. Here an object is a pair of (k)-sets (I,J), constrained to be disjoint as site labels, and its weight is a squared determinant. The latter is a coherent sum over (k!\) permutations before squaring; it need not factor over selected local edges.
* A concrete obstruction to replacing the minor weight by a permanent/product weight is the all-ones (2\times2) block: its determinant is 0 by cancellation, while its permanent is 2. It can be embedded as (F[\{1,2\},\{3,4\}]), so the selected row and column site sets satisfy the target disjointness. This witnesses term-level polynomial mismatch; it does not rule out a more elaborate reduction for the total sum.
* The older matching/packing FPTRASs establish prior art for parameterized approximate counting over nonnegative discrete objects, but none of the checked sources states an algorithm for arbitrary explicit complex (F), disjoint row/column minor pairs, exact-zero output, or all physical prefixes. No direct approximation-preserving reduction from (c_k(F)) to one of those sources was identified in this bounded screen. This is a scoped search result, not a claim that no such reduction exists.
* Relative to the unconditioned estimator, physical-prefix estimates are a substantive stronger interface: their exact physical restrictions and (2^b(2a+1)) coefficient extraction remain within the same (C_k\mathrm{poly}\) bound because (2^b C_{a,b}\le C_k). The old graph-matching sources do not provide prefix marginals for the determinant-square law.
* The phased route replaces (C_k\) samples by (O(\epsilon^{-2}\log(1/\delta))) samples only on its certificate-accepted subclass. It is not a blanket improvement to the general FPTRAS, and its universal residual-to-pointwise-coefficient lemma remains the proof gate.

## 5. Status and decisive gates

The assigned general counter, prefix method, and low-(k) consequence remain internal claims whose proof must be judged on their own algebra and finite-bit implementation; this literature screen cannot certify them.

# Cycle 2: failures, falsifiers, and scope limits

## 9/4 kernel materialization failed at the source boundary

The pinned page-9 proof shows existence of a base size and exact rank decomposition only after an existential asymptotic exponent argument. It gives no actual `u`, `r`, coefficient table, number-field degree, coefficient height, or stopping bound for search. Enumerating algebraic candidate decompositions and checking tensor identities is at best a semidecision from this source: it may terminate for a chosen rational `δ`, but the release gives no bound on when. Its claim “complex solution implies a solution over Q” is false in general; the valid weaker fact is existence of a point over `Qbar`, which gives some finite field for each witness but no explicit bound.

Thus the attempt to materialize the released 9/4 kernel is **blocked by non-effectivity**, not by a counterexample to its exponent theorem.

## Falsification and audit of the explicit fallback

The Strassen kernel survives an exhaustive exact check of its 64 tensor coordinates. The recursive code matches classical exact multiplication on 48 seeded integer fixtures with sizes 1, 2, 4, and 8. A selective-output fixture with overlapping rectangles plus residual pairs returns exactly the requested distinct pairs and values. This supports the listed base identity and implementation at those cases; it does not prove a general complexity claim by experiment (the recurrence and tile counting supply that proof).

The exponent arithmetic survives an exact integer check: `7^100 < 2^281`, hence `log_2(7)<2.81`. This leads to the explicit covered-work exponent `179/100 + 81/400 = 797/400`, below 2.

## Defeated generalizations

* Raising the cover-volume promise to the earlier endpoint `M<=N^(15/8)` does not yield a subquadratic guarantee under Strassen recursion: its covered-work exponent is `15/8+(log_2(7)-2)/4`, approximately `2.07684`.
* If a mask is supplied only as an `N x N` bitmap, reading it can cost `N^2` bits. The theorem only receives a rectangle-list-plus-residual representation; it does not include the cost of finding this representation from a bitmap.
* No arbitrary-mask guarantee follows. The theorem does not bound the cover volume or residual size for a general mask and proves no lower bound against other output-local circuits.
* The bit claim assumes exact integer input entries and `b=O(log N)` for its displayed subquadratic specialization. Large input bit heights must be charged through the explicit `b` factor in the general bit-cost bound.
* Finite code checks do not validate the pinned 9/4 proof, a practical implementation at large dimensions, or novelty/priority.

## Falsifier for the theorem as written

An error in the seven-product tensor identity, the recurrence counts, the rectangle tile count, or the `m<2D` padding/bit-growth bounds would invalidate this result. The executable exhaustive tensor check is a full finite verification of the base coefficient identity; the random fixtures are only finite implementation diagnostics. The analytic recurrence and cost proof are separately recorded in `STRASSEN_STRUCTURED_MASK_THEOREM.md`.

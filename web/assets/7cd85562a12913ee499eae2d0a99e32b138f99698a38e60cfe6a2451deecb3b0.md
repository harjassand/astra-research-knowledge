# Reduction, linear leading edge, and parameter inversion

## Source model

The Supplementary Information (SI Eqs. 18–21) gives, in one spatial dimension,

\[
\partial_t\rho+\partial_x(\rho v)
  =[k_A(1-\phi)+k_B\phi]\rho,
\]
\[
\partial_t\phi+v\partial_x\phi
  =D\rho^{-1}\partial_x(\rho\partial_x\phi)
   +(k_B-k_A)\phi(1-\phi)+k_D(1-\phi),
\]
\[
\eta\partial_{xx}v-\gamma v=\partial_xP,
\quad P=E\log(\rho/\rho_h),
\quad E=E_A+\Delta E\,\phi,
\quad k_D=\alpha(E-E_A)=\alpha\Delta E\,\phi.
\]
The source closes the rates as \(k_i(\rho)=(\rho_i^c-\rho)/(\tau\rho_i^c)\), and assumes the Fickian relative fraction flux \(J=-D\partial_x\phi\).

## Exact scalar reduction and the SI equations

If \(\rho\) is constant and \(v=0\), the fraction equation becomes

\[
\phi_t=D\phi_{xx}+f(\phi),\qquad
f(\phi)=(k_B-k_A)\phi(1-\phi)+k_D(1-\phi).
\]
With the source's linear stiffness and differentiation closure, \(k_D=\alpha\Delta E\phi\), hence

\[
f(\phi)=r\phi(1-\phi),\qquad r=(k_B-k_A)+\alpha\Delta E.
\]
This *reduced* reaction is logistic and satisfies the scalar KPP inequality. For it, the critical/steep-tail speed is \(c_*=2\sqrt{Dr}\), while exponential leading-edge modes \(e^{-\lambda(x-ct)}\) satisfy

\[
c(\lambda)=D\lambda+r/\lambda,\qquad \min_{\lambda>0}c(\lambda)=2\sqrt{Dr}.
\]

The SI page headed “Wave velocities” first states \(v_{FKPP}=2\sqrt{D f'[0]}\), but Eqs. 29 and 30 print the square root without the factor 2. This is a confirmed internal inconsistency. Eq. 30 as printed and Eq. 31 imply

\[
\alpha_{\text{from printed (30)}}=
  \frac{(v_F-v_A)^2/D-(k_B-k_A)}{\Delta E}.
\]
The standard steep-tail KPP formula instead gives

\[
\alpha_{\text{steep KPP}}=
  \frac{(v_F-v_A)^2/(4D)-(k_B-k_A)}{\Delta E}.
\]
SI Eq. 32 prints \(\{(v_F-v_A)^2-D(k_A-k_B)\}/\Delta E\). It neither follows from the printed Eq. 30 (a factor \(1/D\) is missing in the speed-squared term and the growth-difference sign is reversed), nor from the standard formula. Since \([D]=L^2/T\), \([v^2]=L^2/T^2\), and \([\Delta E]=\mathrm{stress}\), Eq. 32 has units \(L^2/(T^2\,\mathrm{stress})\), whereas Eq. 27 requires \([\alpha]=1/(T\,\mathrm{stress})\). With the correct factor 2, the inversion is \(((v_F-v_A)^2-4D(k_B-k_A))/(4D\Delta E)\).

This establishes an SI derivation defect, not that the coupled simulation is numerically invalid. The executable notebook inserts \(\alpha=3.5\times10^{-6}\) directly; a parameter-estimation defect affects the scientific interpretation of that fitted value, while changing the parameter or refitting would be needed to change the forward simulation.

## Full-system linearization at the leading edge

Let \(\rho=\rho_A^c+u\), \(\phi=\psi\), about the homogeneous mesenchymal state \((\rho_A^c,0,0)\). Set

\[
g=(k_B-k_A)|_{\rho=\rho_A^c}
  =\frac{\rho_B^c-\rho_A^c}{\tau\rho_B^c}.
\]
To first order, the full PDE linearizes to

\[
\psi_t=D\psi_{xx}+(g+\alpha\Delta E)\psi,
\]
\[
u_t+\rho_A^c v_x=-u/\tau+g\rho_A^c\psi,
\]
\[
\eta v_{xx}-\gamma v=
\partial_x\left[\frac{E_A}{\rho_A^c}u+
\Delta E\log(\rho_A^c/\rho_h)\psi\right].
\]
The reason the first equation decouples is that \(v\psi_x\) and \((u_x/\rho_A^c)\psi_x\) are products of first-order perturbations. Thus the source's \(2\sqrt{Dr}\) is indeed the full PDE's linear spreading speed under this homogeneous-edge linearization, with \(r=g+\alpha\Delta E\). That does **not** prove the nonlinear coupled system has a pulled front: the nonlinear mechanical transport can alter wave selection and could in principle support a pushed front. Nor does the linear speed equal a measured finite-time speed when a shallow tail is already seeded or tissue flow is nonzero around the level set.

For the released far-field state, \(\rho=\rho_A^c=.0067\), \(\rho_B^c=.0077\), and \(\tau=10\,h\), giving \(g=.0129870\,h^{-1}\). The source seed \(\phi_0(x)=(1-\tanh(4x/1500))/2\) has tail \(\exp(-q_0x)\) with \(q_0=8/1500=.0053333\,\mu m^{-1}\). Under the notebook's numerical stress convention, \(\alpha\Delta E=.0439992\,h^{-1}\), so \(r=.0569862\,h^{-1}\), \(q_* =\sqrt{r/D}=.061637\,\mu m^{-1}\), \(c_*=1.8491\,\mu m/h\), and \(c(q_0)=Dq_0+r/q_0=10.7649\,\mu m/h\). Thus \(q_0/q_*=.0865\): the reduced model does not start in the steep-tail regime for which the minimum is selected.

An independent explicit NumPy solution of the scalar logistic reduction on the source domain, seeded with the same tanh profile, gives a \(\phi=.5\) OLS speed of 10.694 \(\mu m/h\) over 0–8 h, close to its shallow-tail dispersion prediction and far above its steep-tail minimum. This is a finite-domain/finite-time diagnostic; the asymptotic speed theorem applies to the scalar KPP Cauchy problem, not to the full bounded, moving-density PDE. The exact source-code solver replay is in `../code/replay_model.py` and reproduces the released arrays to maximum absolute errors below \(4\times10^{-13}\), but that only validates transcription and numerical reproduction.

## Flow, density, and pulled/pushed terminology

The exact fraction PDE contains

\[
D\rho^{-1}\partial_x(\rho\phi_x)-v\phi_x
=D\phi_{xx}+(D\partial_x\log\rho-v)\phi_x.
\]
Consequently, the scalar FKPP reduction assumes away both a density-gradient drift and the tissue velocity. Eq. 31's additive \(v_A\) is exact only for a translation-invariant, constant advection (or as a local approximation if coefficients vary slowly across the wave); the full force-balance velocity \(v(x,t)\) is spatially varying and evolves with \(\rho,\phi\). The full simulation's 0–6 h \(\phi=.5\) level speed is 21.917 \(\mu m/h\); it cannot be equated to \(c_*\) or to the scalar tail formula alone.

For the scalar logistic reduction, the nonlinearity is KPP, so the *steep-tail selected* wave is linearly pulled. A shallow pre-existing exponential tail selects the faster linear-dispersion branch \(c(q_0)>c_*\); calling that branch “pushed” would be incorrect. The full mechanically coupled PDE is not shown to satisfy a scalar KPP comparison inequality, and source observations of isolated ahead cells or interface roughness do not by themselves classify the in-vivo wave as pulled or pushed.

## Physical-unit ambiguity

From Eq. 27, \(k_D=\alpha(E-E_A)\) and \(k_D\) has units \(h^{-1}\), so when \(E\) is expressed in Pa, \(\alpha\) must have units \(\mathrm{Pa}^{-1}h^{-1}\). Table S1 reports \(E_A=30\,Pa\), \(E_B=1000\,Pa\), and \(\alpha=3.5\times10^{-6}\) but gives no units for \(\alpha\). The notebook converts Pa to its internal \(kg/(\mu m\,h^2)\) stress unit by multiplying by 12.96, while leaving the numeric alpha unchanged. If the table's alpha means \(\mathrm{Pa}^{-1}h^{-1}\), the code should instead divide alpha by 12.96 after converting E. That conditional branch lowers the model replay's front-level speed from 21.917 to 14.281 \(\mu m/h\). If alpha was numerically fit in the notebook's internal stress unit, the code may be internally consistent but the SI table has omitted its units. Available source text does not disambiguate; mark as unresolved, not a confirmed implementation defect.

The SI Table S1 lists \(\eta=10^4\,Pa\,s\), while the released executable notebook uses \(10^3\,Pa\,s\). The exact NumPy replay using the table value but otherwise the same convention changes the front-level speed only from 21.9169 to 21.9159 \(\mu m/h\). This is a genuine published-source parameter mismatch with negligible effect in this one baseline replay, not a decisive explanation for the wave.

## Conditional speed-only nonidentifiability

In the scalar shallow-tail regime, an observed tissue-frame relative speed \(c\) satisfies

\[
c=Dq+\frac{g+\alpha\Delta E}{q},\qquad
\alpha(q)=\frac{q(c-Dq)-g}{\Delta E}.
\]
For \(c=10.808225\,\mu m/h\) (the released full-model \(\phi=.5\) OLS speed minus output-sampled tissue drift \(v-D\partial_x\log\rho\) at the front), the distinct tail exponents \(q=.005333,.010,.020\,\mu m^{-1}\) give respectively \(\alpha=3.5184\times10^{-6},7.4452\times10^{-6},1.5685\times10^{-5}\) in notebook stress units and exactly the same displayed \(c\). Each is on its shallow-tail branch. Therefore one speed does not identify \(\alpha\) if the initial tail is not independently measured, even in this favorable scalar reduction. The code fixes \(q_0\) synthetically; the primary source does not report a live in-vivo measurement of that exponent. This conditional no-go does not refute the full PDE or establish a biological tail law.

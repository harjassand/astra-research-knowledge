# A rectangle-cover route for structured selective outputs

## Claim and interface

Let $N=D^4$, $D\in\mathbb N$, and let

\[
 X\in\mathbb Z^{N\times D},\qquad Y\in\mathbb Z^{D\times N},
 \qquad |X_{ik}|,|Y_{kj}|<2^b.
\]

The requested mask is represented by an explicit list of $q$ rectangles
$(R_t,C_t)$, where $R_t,C_t\subseteq[N]$,
$|R_t|,|C_t|\ge D$. The represented mask is

\[
 W=F\;\cup\;\bigcup_{t=1}^q(R_t\times C_t),
 \qquad M:=\sum_{t=1}^q|R_t||C_t|\le N^{15/8},
 \qquad |F|\le N^{7/4-\sigma},\qquad M+|F|\le N^{15/8}
\]

for some fixed $\sigma>0$; $F$ is an explicit list of exceptional pairs
outside the rectangles. Rectangle overlaps are allowed and are counted with
multiplicity in $M$. If the mask has no residual pairs, take $F=\varnothing$.
The algorithm returns each distinct requested pair once, with its exact value.

**Conditional theorem.** Assuming the pinned release's exact square-matrix
algorithm bound, for every fixed $0<\xi<1/4$ this task has a uniform
arithmetic algorithm over one fixed number field $K_\xi$, with online cost

\[
 O_\xi\!\left(ND+M D^{1/4+\xi}+|F|D+M+|F|\right)
\]

field operations and $O_\xi(\text{online cost}\cdot\operatorname{polylog}N)$
bit operations when $b=O(\log N)$. The setup description and its acquisition
cost are additional terms $S_\xi,A_\xi$, respectively, independent of
$N,D,X,Y,W$; the release proves existence of such a setup but does not give
useful numerical bounds for $S_\xi,A_\xi$. Thus the statement is an
asymptotic structured-mask theorem with an explicitly isolated nonuniform
constant, not a competitive implemented kernel.

At the target scale, setting $\xi=1/8$, $D=N^{1/4}$, gives

\[
 M D^{3/8}\le N^{15/8+3/32}=N^{63/32},\qquad
 |F|D\le N^{2-\sigma}.
\]

Hence the online bit cost is

\[
A_{1/8}+O\!\left(N^{2-\min(1/32,\sigma)}\operatorname{polylog}N\right),
\]

with a saving of at least $1/32$ in the exponent for the
rectangle-covered mask class when $F=\varnothing$. The target mask size
bound is 
$|W|\le M+|F|$; it is not necessary for the theorem that the rectangles
be disjoint.

## Construction and proof

The primary release theorem gives, for every $\xi>0$, an exact recursive
algorithm for multiplying two $D\times D$ matrices in
$O_\xi(D^{9/4+\xi})$ arithmetic operations. Its proof chooses a fixed
integer base size $u$ and a fixed exact rank decomposition of the $u\times u$
matrix-multiplication tensor, then recurses. All coefficients are fixed once
$\xi$ is fixed and lie in one finite number field when represented
algebraically.

Uniform setup is possible by enumeration, although it is not practical from
the evidence available here. Enumerate candidate base sizes, ranks, number
fields, and algebraic coefficient tuples; verify every rank-decomposition
identity exactly. The exponent theorem guarantees a successful size/rank
pair. Its polynomial equations have rational coefficients, and a complex
solution implies a point over $\overline{\mathbb Q}$ (not necessarily over
$\mathbb Q$), so the finite search eventually reaches one algebraic witness.
Call this setup time $A_\xi$ and stored description length $S_\xi$. No useful
upper bound for either is available from the release proof.

For each rectangle $R_t\times C_t$, partition $R_t$ and $C_t$ into
chunks of at most $D$ indices. Pad a short final chunk by zero rows or
columns. Every pair of chunks requires one $D\times D$ product:

\[
 X[R_{t,r},:]\;Y[:,C_{t,c}].
\]

Since the middle dimension is exactly $D$, this product returns precisely
the corresponding requested tile. The number of products is

\[
 \left\lceil\frac{|R_t|}{D}\right\rceil
 \left\lceil\frac{|C_t|}{D}\right\rceil
 \le 4\frac{|R_t||C_t|}{D^2},
\]

using $|R_t|,|C_t|\ge D$. Thus a rectangle costs
$O_\xi(|R_t||C_t|D^{1/4+\xi})$, and all rectangles cost
$O_\xi(MD^{1/4+\xi})$. Overlaps only repeat correct outputs; collect the
pair/value records and deduplicate by pair, charging $O(M\operatorname{polylog}N)$ bits.

For each pair in $F$, compute its $D$-term dot product directly, costing
$O(|F|D)$. Reading $X,Y$ costs $O(ND)$ field elements. Copying inputs
into square tiles and collecting tile outputs costs $O(M)$ field elements.
The complete cost bound follows.

For the bit interface, each requested integer has at most
$2b+\lceil\log_2D\rceil+O(1)$ bits. Store the fixed base coefficients in
an exact representation of $K_\xi$ (minimal polynomial, basis, and
coefficient coordinates). The extension degree and base data depend only on
$\xi$, not on $N$. In a depth-$O(\log D)$ recursion, every intermediate
is a linear or bilinear combination using a fixed finite set of constants;
coefficient heights and operand bit lengths therefore grow by
$O_\xi(b+\log N)$, not by finite-precision rounding. Exact number-field
operations on these $O_\xi(\log N)$-bit coordinates cost
$\operatorname{polylog}N$ bit operations. The final coordinates lie in
$\mathbb Z\subset K_\xi$ and can be decoded exactly.

## Mask acquisition and representation charges

If the input supplies rectangle index lists, their encoded length is

\[
 L_{\rm rect}=O\!\left(\sum_t(|R_t|+|C_t|)\log N+q\log N\right).
\]

Because each side is at least $D$,
$\sum_t(|R_t|+|C_t|)\le 2M/D$, so
$L_{\rm rect}=O((M/D+q)\log N)$. The residual list uses
$O(|F|\log N)$ bits. Expanding the mask or emitting all values costs
$O((M+|F|)\log N)$ bits, already below the stated exponent. If the mask
arrives as an explicit list rather than this representation, reading and
sorting the list costs $O(|W|\operatorname{polylog}N)$ bits; the theorem
requires either a supplied rectangle cover plus residual list or a separate
algorithm that acquires that cover. It makes no claim that such a cover can be
found for arbitrary $W$.

The matrix entries, all requested output values, mask indices, rectangle lists,
tile copies, exact coefficient representation, and base-kernel search/storage
are charged above. No numerical precision or stability assumption is used.

## Boundary and falsification

The promise is essential. If $W$ is an arbitrary set of
$N^{15/8}$ isolated positions, the natural singleton cover has side lengths
below $D$; padding every singleton to a $D\times D$ rectangle has cover
volume $N^{15/8}D^2=N^{19/8}$, outside the theorem. Direct computation then
costs $N^{17/8}$, so this construction supplies no arbitrary-mask saving.

For rectangle masks with complete bipartite connected components, the
decomposition can instead be recovered from an explicit edge list: form the
bipartite graph, find its components, and check that each component with
vertex classes $R,C$ has exactly $|R||C|$ edges. This takes
$O(|W|\operatorname{polylog}N)$ bit operations and yields the rectangle
representation without a separate cover search. The theorem does not extend
to general connected masks: a three-edge path has one component with
$|R||C|=4$ but only three edges, so the promised rectangle identity fails.

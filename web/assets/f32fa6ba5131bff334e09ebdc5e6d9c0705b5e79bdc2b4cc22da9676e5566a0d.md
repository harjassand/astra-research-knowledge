# Incidence enforcer: exact inverse-block row lower bound

**Status.** An exact, internally proved row-support lower bound is obtained for
one explicit QMA-hard family of fully legal BMVZ inputs and one fixed
complement-LCU PREPARE completion. For every member of this family, a specified
cross-label block row of the exact incidence enforcer has exactly `2^R`
nonzeros, so the full physical row has at least `2^R` nonzeros. Here `R` is the
BMVZ singleton-repetition parameter and grows as a positive power of the source
input size. Thus this exact `C_inc` has no polynomial-time explicit row-list
oracle on this legal family, even though its selected-row entries have a
polynomial-time exact formula.

This is **not** a lower bound for the unmodified ABN-derived input in BMVZ
Theorem 7.4, nor for every PREPARE completion or every BMVZ-admissible input.
The all-input/unmodified-family question remains open. The construction below
does not use the earlier `C_0` row lower bound.

## Legal hard input and its BMVZ output

Start with any BMVZ-admissible QMA-hard family

```text
H0 = sum_chi w_chi E_i P_i^chi
```

whose terms are 5-local projections, whose `g=O(1)` layers commute, and whose
minimum layer weight is bounded below by a constant. Let its promise be
`lambda_min(H0) <= eps(n)` or `lambda_min(H0) >= gamma(n)`, where `eps` is
negligible and `gamma` is inverse polynomial. Add a fresh two-qubit flag `F`
and a fresh five-qubit seed register `S`. Write

```text
F0 = |00><00|,  Fphi = |01><01|,  Fpsi = |10><10|,
Fbad = I - F0,
phi = (|00010> - |10010>)/sqrt(2),
psi = (|00010> - |01110> - |10110> - |11010>)/2.
```

Use tensor order `old register tensor S tensor F`. Control every old
projection by `F0`, and add three singleton layers:

```text
P_i^chi tensor I_S tensor F0,             layer weights w_chi/2,
I_old tensor |phi><phi|_S tensor Fphi,    layer weight 1/8,
I_old tensor |psi><psi|_S tensor Fpsi,    layer weight 1/8,
I_old tensor I_S tensor Fbad,             layer weight 1/4.
```

The old layers remain commuting because all their terms receive the same
flag projector; the three added layers are singleton layers. The weights are
positive, sum to one, and have a constant minimum. Each term is at most
7-local. Thus the input satisfies BMVZ Assumption 7.1: polynomially many
constant-local projections, `O(1)` commuting layers, and constant
`omega_min`. This construction does not assert bounded incidence on the two
new flag qubits; bounded incidence is not part of Assumption 7.1.

The input Hamiltonian is block diagonal in `F`. In the `F=00` block it is
`H0/2`; in each `F=01` or `F=10` block it is at least `1/4`; in `F=11` it is
`1/4`. Therefore its ground energy is

```text
min(lambda_min(H0)/2, 1/4),
```

which preserves the negligible-versus-inverse-polynomial QMA promise. This is
a QMA-hard enlargement, not a claim about the exact fixed ABN term table.

Apply the BMVZ iteration to this layered input. For a singleton layer with
projector `P`, the actual small-layer rule repeats its clause; after `ell`
rounds the emitted clause is

```text
h_(P,R) = I - (I-P)^(tensor R),   R=(2t)^ell.
```

In particular, the output contains the repeated `phi`, `psi`, and `Fbad`
clauses. The aggregate layer weights stay `1/8`, `1/8`, and `1/4`. For the
LCU, scale the complete BMVZ output by `3/4` and append a zero projector of
weight `1/4`. Thus the LCU projection weights sum to one and
`0 <= H <= 3I/4`; the zero projector is a silent branch. In this scaled list,
the aggregate `phi`, `psi`, and `Fbad` weights are respectively

```text
beta = 3/32,     3/32,     rho = 3/16.
```

The constant `t` and iteration count
`ell=ceil(6 log p(n)/log t)` give polynomial output size and
`R=(2t)^ell = n^Omega(1)` for the inverse-polynomial starting gap. Hence
`2^R` is superpolynomial in both the source size and the polynomial-size BMVZ
output.

## Fix the complement-LCU and incidence enforcer

Index the zero projection in the LCU term list along with all nonzero BMVZ
terms, and add the separate identity-reflection label `id`. For term weights
`pi_j` set

```text
chi_id = 1/sqrt(2),  chi_j = sqrt(pi_j/2),
R_j = I - 2 h_j,
U = (A^* tensor I) SELECT (A tensor I),  A|0> = chi.
```

Then the physical branch maps and the distinguished block obey

```text
K_a = <a|U|0> = sum_j conjugate(A_(j,a)) chi_j R_j,
K_0 = sum_j chi_j^2 R_j = I-H = Y >= I/4.
```

The following enforcer is exact on the full physical space. For
`z=(z_0,z_1,...,z_(m-1))`, define

```text
Tz = (z_a - K_a Y^(-1) z_0)_(a>0),
C_inc = T^* T / 16.
```

With `M` the vertical stack of the `K_a Y^(-1)` blocks,

```text
T = [-M | I],
M^*M = Y^(-2)-I <= 15 I,
TT^* = I+MM^* >= I.
```

Consequently `||T||^2 <= 16`, `0 <= C_inc <= I`, and every nonzero singular
value of `T` is at least one. Also `ker(T)=ran(V)`: `Tz=0` implies
`z_a=K_a Y^(-1)z_0`, so with `u=Y^(-1)z_0` one has `z=Vu`. Therefore

```text
ker(C_inc)=ran(V),
C_inc >= (1/16)(I - VV^*).
```

In label-block form, with the `0` block first,

```text
C_inc = (1/16) [ Y^(-2)-I       -Y^(-1)K_1^* ... -Y^(-1)K_(m-1)^* ;
                  -K_1Y^(-1)       I             ... 0                 ;
                  ...              ...           ... ...               ].
```

In particular, the block from physical output label `b>0` to label `0` is
exactly `-K_b Y^(-1)/16`. No other term can cancel an entry in this block.

## PREPARE completion isolating one legal seed clause

Choose any one positive-weight output label `j_phi` for the repeated
`phi` singleton clause, with LCU probability `pi>0`. If the singleton rule
retains duplicate labels, choose one of them; all have the same clause. Choose
the physical output label `b=1` and set its PREPARE column to have only these
two nonzero entries:

```text
A_(id,b)   = chi_phi / sqrt(chi_id^2 + chi_phi^2),
A_(j_phi,b)= -chi_id / sqrt(chi_id^2 + chi_phi^2).
```

This column is unit length and orthogonal to the required first column `chi`.
Complete it and `chi` to a real orthogonal `A` by exact algebraic Givens
rotations. This is a polynomial-size PREPARE circuit. The selected branch is
exactly

```text
kappa = chi_id chi_phi / sqrt(chi_id^2+chi_phi^2)
      = sqrt(pi/(2(1+pi))) > 0,
K_b = kappa (I-R_(j_phi)) = 2 kappa h_(phi,R).
```

All other BMVZ terms, including every hard-base clause, remain in the full
Hamiltonian and in `K_0=Y`; their coefficients in this one `K_b` block are
zero by construction.

## Exact resolvent and row support on a reducing flag sector

Let `S` be the subspace in which the flag is `01` in every one of the `R`
repetition copies. All terms are diagonal in each copy's flag, so `S` reduces
both `H` and `Y`, and `Y^(-1)` preserves it. On `S`:

* every amplified hard-base clause is zero, since each of its controlled
  factors is controlled on flag `00`;
* the amplified `psi` clause is zero, since it is controlled on `10`;
* the amplified `Fbad` singleton clause is `I`;
* the amplified `phi` clause is `I-Q_phi^(tensor R)`, where
  `Q_phi=I-|phi><phi|` acts on the five-qubit seed block in one copy.

Thus on `S` the **complete** scaled output Hamiltonian and its inverse are

```text
H|S = rho I + beta (I-Q_phi^(tensor R)),
Y|S = alpha I + beta Q_phi^(tensor R),
alpha = 1-rho-beta = 23/32,
alpha+beta = 26/32 = 13/16,
Y^(-1)|S = alpha^(-1)(I-Q_phi^(tensor R))
           + (alpha+beta)^(-1) Q_phi^(tensor R).
```

The selected branch acts on this sector as

```text
K_b|S = 2 kappa (I-Q_phi^(tensor R)),
K_b Y^(-1)|S = (2 kappa/alpha)(I-Q_phi^(tensor R)).
```

The second equality is exact: the two spectral projections
`Q_phi^(tensor R)` and `I-Q_phi^(tensor R)` annihilate one another. It is the
inverse resolvent, not a `C_0` argument, that has now been evaluated on the
full legal output sector.

Let `c=00010`, `f=10010`, and fix any computational-basis string `r` for the
old base register. Choose the physical row data string

```text
x = [(base=r, flag=01, seed=c)]^(tensor R).
```

For one seed block, `Q_phi` has row `c` supported exactly on `{c,f}`, with
`Q_phi[c,c]=Q_phi[c,f]=1/2`. Therefore `Q_phi^(tensor R)` has row `x`
supported exactly on the `2^R` strings with the same base and flags and seed
coordinates in `{c,f}^R`; each product entry is `2^(-R)`. Since
`I-Q_phi^(tensor R)` has diagonal entry `1-2^(-R)` and every off-diagonal
entry on this set equal to `-2^(-R)`, the selected incidence block row is

```text
C_inc[(b,x),(0,y)] = -kappa/(8 alpha) *
                     (I-Q_phi^(tensor R))[x,y].
```

Its exact values are

```text
y=x:       -kappa (1-2^(-R))/(8 alpha),
y!=x:      +kappa 2^(-R)/(8 alpha),  y in the same {c,f}^R support,
otherwise: 0.
```

Because `kappa>0` and `alpha=23/32`, all `2^R` listed entries are nonzero.
The support in this cross-label block is **exactly** `2^R`; hence the complete
physical row of `C_inc` has at least `2^R` nonzeros. This is a direct
support count, not a generic claim that matrix inverses are dense.

## Access and cost ledger

* **Term generation:** BMVZ has polynomially many terms; each repeated clause
  has polynomial circuit size in `R` and its source term description. The
  singleton rule guarantees the exact `phi`, `psi`, and flag-penalty clauses.
  All base clauses are retained in `Y`; their vanishing on `S` is exact.
* **Encoding:** the LCU alphabet is polynomial, the label register has
  `O(log M)` qubits, and `A` has a polynomial-size exact algebraic circuit.
  Each selected `K_b` entry is a two-term expression. The full `C_inc`
  includes `Y^(-1)`; a polynomial circuit approximation to `Y^(-1)` follows
  from `Y>=I/4`, but a finite-precision approximation is not the exact
  enforcer and does not inherit its exact kernel automatically.
* **Selected exact entries:** on the displayed cross block, a queried `y` is
  checked in `O(R)` bit operations against the fixed base/flag pattern and
  the local alphabet `{c,f}`. The value is one of the formulas above.
  `kappa` is a square root of a rational of polynomial bit length, and the
  factor `2^(-R)` needs `O(R)` bits. Thus selected-entry evaluation is
  polynomial in the BMVZ output size and requested precision.
* **Row listing:** the displayed cross block has `2^R` entries. Any explicit
  row-list routine for the full physical row must output at least these
  coordinates, requiring `Omega(2^R)` output operations (and
  `Omega(R 2^R)` bits for explicit column indices). The support is succinctly
  describable, but succinct support description is not an explicit row list.
* **Arbitrary entries:** no general polynomial classical exact-entry
  algorithm for `Y^(-1)` or all of `C_inc` is claimed. Fast entry evaluation
  on this selected row and a polynomial quantum circuit approximation are
  distinct from both arbitrary exact-entry access and row enumeration.

## Scope boundary and falsifiers

The proof establishes a worst-case obstruction for this fixed incidence
formula over the class of all BMVZ-Assumption-7.1 inputs, including the
explicit QMA-hard controlled family above. A purported explicit row list for
the displayed row with fewer than `2^R` entries must omit a string
`y in {c,f}^R`; that omitted entry has the exact nonzero value
`kappa/(8 alpha 2^R)` when `y!=x`, or the displayed nonzero diagonal value
when `y=x`. This is the direct falsifier for any claimed polynomial row
routine on this family.

The result does not decide the output of the one fixed ABN-derived reduction
used in BMVZ Theorem 7.4, because the two flag qubits here control every old
term. To extend the lower bound to that narrower family, the missing lemma is
an exact reducing-sector or cancellation-resistant support theorem for
`K_a(I-H)^(-1)` with the unmodified term table. Conversely, a polynomial
row-list algorithm for that unmodified family would not contradict the
controlled-family lower bound; it would only show the scope distinction
matters. No path/layer-based polynomial row enumerator is established.

## Operator-norm approximation test for the selected block

The exact row lower bound is not by itself robust to operator-norm
approximation. On the `N=2^R`-dimensional seed support
`X={c,f}^R` with fixed old-register string and all flags `01`, write

```text
|u> = N^(-1/2) sum_(y in X) |y>,
Q_phi^(tensor R)|_X = |u><u| = J_N/N,
a = kappa/(8 alpha),
D := C_inc[(b, X),(0, X)] = -a(I-J_N/N).
```

Thus for any column `j in X`, the selected cross-block column has one
diagonal entry `-a(1-1/N)` and `N-1` off-diagonal entries `a/N`. Its exact
norm and its off-diagonal tail are

```text
||D e_j||_2^2 = a^2(1-1/N),
||offdiag(D e_j)||_2^2 = a^2(N-1)/N^2.
```

Let `C_hat` be any matrix with at most `s` nonzeros per column (in
particular, a Hermitian row/column-`s`-sparse approximant) and suppose
`||C_hat-C_inc|| <= epsilon`. Projecting to output label `b` and input label `0`
cannot increase the norm, so the selected block column must also have error
at most `epsilon`. The best `s`-entry approximation keeps the large diagonal
and then `s-1` off-diagonal entries. For `1<=s<=N`, its squared residual is
at least `a^2(N-s)/N^2`. Hence the column test gives

```text
s >= N - (epsilon/a)^2 N^2.
```

This is informative only when `epsilon < a/sqrt(N)`; for example,
`epsilon=a/(2 sqrt(N))` forces `s>=3N/4`. For any fixed `epsilon>0` and
constant `a`, or even inverse-polynomial `epsilon(n)`, this bound is vacuous
once `N=2^R` is large. The exponential exact support lies in entries whose
combined column `ell_2` tail is only `Theta(a 2^(-R/2))`.

There is also a direct block-level reason not to infer a constant-error
operator-norm obstruction from these entries. Let `P_0` be the lazy normalized
adjacency matrix of an explicit constant-degree expander family on `X`, with
uniform eigenvector and second singular value at most a constant
`lambda_0<1`. Taking its `k`-step walk matrix `P=P_0^k` gives at most
`d_0^k` nonzeros per row and column and second singular value at most
`lambda_0^k`, where `d_0` is the base degree. Then

```text
D_sparse = -a I + a P,
||D-D_sparse|| = a ||J_N/N-P|| <= a lambda_0^k,
row/column sparsity(D_sparse) <= d_0^k+1.
```

The `k`-step neighbor list is generated by enumerating `d_0^k` base walks
from an `R`-bit vertex, so this block-approximation row oracle costs
`poly(R,d_0^k)`, not `Theta(N)`. For target error `epsilon<a`, choose
`k=ceil(log(a/epsilon)/log(1/lambda_0))`; then `a lambda_0^k<=epsilon`, and
the selected block has a `d_0^k+1`-sparse approximation. This degree is
constant for fixed `epsilon/a` and polynomial in `1/epsilon` when `a` is
constant. In the one-label singleton representation `pi=3/32`, so
`kappa=sqrt(3/70)` and `a=4 sqrt(3/70)/23` are constants. This is only a
sparsification of the selected cross block (and its adjoint block), not of
the full `C_inc`; other blocks may still obstruct a sparse approximation of
the complete enforcer. The precise conclusion is that the `2^R` exact
support lower bound does **not** yield a superpolynomial lower bound on `s`
for constant or inverse-polynomial operator-norm error by the column-norm
test.

1. EXACT THEOREM

There are N fixed sites, d species, and fixed volumes v_s>0. At each site the
concentration c_s follows the same finite actual endotactic arrow diagram
y_e -> y'_e, nu_e=y'_e-y_e, with bounded positive measurable rates. Let n_s=v_s c_s
be species amounts. Species i is transported by unary arrows
X_(s,i) -> X_(t,i), each with a bounded positive measurable coefficient a_(s,t,i).
Every species transport graph is strongly connected. Graphs and coefficients
may differ by species and need not be reversible. Transport conserves each
species' sum_s n_(s,i). All volumes are fixed; concentration transport is therefore
allowed provided it conserves these SAME volume-weighted amounts for every species.

Conditional on N33: for each positive total stoichiometric class there is ONE
nonempty compact convex positive set Q in R^(Nd), fixed before initial state and
rates, invariant and absorbing for every allowed path. Each initial state has
a finite entry bound uniform over rate paths. Thus every species at every site
has eventual positive lower and finite upper bounds. The set is a joint profile
polytope, not generally a Cartesian power of a local concentration range.

Moreover, the same statement holds under arbitrary measurable switching or
convex mixing among FINITELY MANY such transport topologies, provided each
species graph is strongly connected in each mode. No dwell time is required.
One can also switch local diagrams having the same local span S.
For fixed N there are only finitely many directed species graph supports.
Consequently one may take the mode family to be ALL strongly connected supports
on those sites with the supplied active-edge rate box. The common absorber can
therefore be chosen before the actual topology path too. It may depend on N,
volumes and allowed active-edge rate box; no graph-size-uniform bound follows.

2. PROOF — NO PDE ESTIMATE OR NUMERICAL EVIDENCE IS NEEDED

Embedding lemma. Embed a local arrow into its site's coordinate block. For
W=(W_1,...,W_N), projected source and arrow products are W_s.y and W_s.nu. Its
essential-source endotactic test is exactly the local test for W_s. Hence
coordinate embedding preserves endotacticity.

Union lemma. Suppose finite arrow sets R_j are endotactic. Fix W and an essential
edge e in their union at a globally maximal essential-source height W.y_e.
Choose a module R_j containing e. Every essential source of R_j is also an
essential source in the union, so e is maximal essential within R_j. Its own
endotacticity gives W.nu_e<0. This proves finite-union endotacticity, retaining
all ties and exempting tangent edges. No same-span assumption is used here.

Transport lemma. The unary graph for each species is weakly reversible since
it is strongly connected. Every weakly reversible diagram is endotactic. One
can also prove this directly: if a maximal essential source had an arrow to a
higher W-height, follow a directed path back to its source; the first downward
edge on the higher part of that path has an essential source of higher height,
a contradiction. All essential arrows from a maximal essential source thus
point strictly down.

Amount conversion. The local term in amounts is exactly
  dot n_s = sum_e [k_(s,e)(t) v_s^(1-|y_e|_1)] n_s^y_e nu_e.
For nonnegative chemical integer complexes |y_e|_1=sum_i y_(e,i).
For general real power laws replace that notation by sum_i y_(e,i), which may
have either sign. All transformed coefficients still have one finite strictly
positive rate box because sites, arrows and fixed positive volumes are finite.
The arrows are still the original actual y_e -> y'_e: the scalar v_s is absorbed
into the coefficient, not into the stoichiometric vector. Unary transport arrows
and all embedded local diagrams form a finite actual endotactic enlarged diagram.
Apply N33 in dimension Nd.

Exact span and conservation. Write S=span{nu_e}. With every species graph
strongly connected, the hopping arrows generate
  H={z in R^(Nd): sum_s z_s=0}.
Their incidence vectors generate each species' entire zero-sum site subspace;
directed strong connectivity suffices. Local arrows have total projection in S.
Conversely any z with sum_s z_s in S can first realize that total at one site
using local arrow vectors, then realize the remaining zero-total displacement
using H. Therefore
  S_aug={z: sum_s z_s in S},
  dim S_aug=d(N-1)+dim S,
  S_aug^perp={(ell,...,ell): ell in S^perp}.
This proves that the class is specified only by original total amount
conservation laws ell.sum_s(v_s c_s). It also proves that all allowed connected
transport modes have the SAME span. N33's common-span switching theorem applies
to the enlarged modes. Edges inactive in one mode need not have positive rates
there: apply the mode theorem, not a fictitious positive box on their union.

3. THIS IS STRICTLY OUTSIDE THE OLD STRONGLY-ENDOTACTIC SUBCLASS

Two-site example: at each site use 2A -> A+B <- 2B, and add
A_1 <-> A_2 and B_1 <-> B_2 with independent diffusion coefficients.
Each local diagram is endotactic (indeed strongly endotactic within its local
one-dimensional span), and each hopping diagram is reversible. The enlarged
diagram is endotactic by the proved union lemma and has span of dimension 3,
with only A_1+B_1+A_2+B_2 conserved. It is not weakly reversible: A_s+B_s has no
outgoing arrow. It is not strongly endotactic: for W=(1,1,0,0), maximal sources
2A_1 and 2B_1 have height 2 and all their arrows are W-tangent. Yet W is not
orthogonal to hopping vectors. Strong endotacticity's required inward arrow at
the full-source maximum fails. Thus the 2014 strongly-endotactic permanence
theorem does not directly prove this enlarged example. This does not establish
that this example lacks other special-case permanence proofs.

5. LIMITS / FAILED TRANSFERS

No mesh-independent result. The state dimension, diffusion coefficients
(usually O(h^-2)), volume-adjusted reaction rates, affine family and cutoffs all
change with mesh. A family of positive bounds epsilon_h can tend to zero. Hence
this graph theorem does not settle arbitrary unequal-diffusion PDE permanence.
N54's continuum missing bridge remains uniform spatial/relative-production
control, not finite-dimensional chemical interpretation.

Amount conservation matters. A species-dependent row-Laplacian preserving
constants may have different invariant site measures for different species.
Such an operator need not be representable by conservative unary hops with one
common volume weighting. A species-wise coordinate scaling changes reaction
vectors without the matching kinetic exponents and does not automatically
preserve the actual-diagram endotactic property. That larger class is excluded.

Changing spans matters. Disconnected instantaneous transport modes can preserve
extra site totals. A positive global total can be concentrated arbitrarily
unevenly, so a single classwise site lower bound can fail if a disconnected mode
is held forever. Joint connectivity alone has not been proved sufficient here.
Modes with no transport are nevertheless allowed if their enlarged spans happen
to equal the required common span; this is an exact linear-algebra condition.

Deterministic graph permanence does not imply stochastic recurrence, invariant
stationarity or infinite-time safe survival. N35 retains only finite horizons;
the separate stochastic report gives a stronger matching obstruction.

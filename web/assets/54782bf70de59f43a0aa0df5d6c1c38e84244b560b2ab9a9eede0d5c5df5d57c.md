# Independent reconstruction: robust permanence for all endotactic networks

**Status, 7 October 2026.** I independently read all of release149's affine, trapping, and permanence TeX, checked the exact Gopalkrishnan–Miller–Shiu endotactic definition, and reconstructed the weighted-flux replacement. I found no mathematical gap in the extension described below. The proof candidate is stronger than the fixed-rate weakly reversible theorem stated in release149: it gives a common compact convex absorbing set for all measurable rates in a fixed positive interval, on each positive stoichiometric class of every finite endotactic network. This is an internal reconstruction, not an external correctness or priority determination. No numerical experiment or formal proof replay is being offered as certification.

The load-bearing input is release149's finite affine approximation lemma with a discontinuous positive tolerance. Its full induction is audited in the final section. No weak reversibility, kinetic rate, or stoichiometric restriction is used in that lemma.

## Exact interface and definition

Let a finite directed edge set consist of reactions (e:y_e\to y'_e), with (y_e,y'_e\in\mathbb R^d), and write (\nu_e=y'_e-y_e). Ordinary chemical mass action is the subcase (y_e,y'_e\in\mathbb Z_{\ge0}^d). Let

\[
S=\operatorname{span}\{\nu_e:e\in R\},\qquad
P=(c+S)\cap\mathbb R_{>0}^d,\quad c\in\mathbb R_{>0}^d.
\]

For a vector (w\), set (R_w=\{e:w\cdot\nu_e\ne0\}\). The (w\)-support is the set of sources maximizing (w\cdot y_e) among (e\in R_w\). The network is endotactic if, for every (w\), every **essential** reaction (e\in R_w\) from that support has (w\cdot\nu_e<0\). Empty essential sets impose no condition. Tangent edges and self-loops at support sources are permitted. This is exactly Definitions 3.9 and 3.14 in [Gopalkrishnan–Miller–Shiu, arXiv:1305.5303v2](https://arxiv.org/html/1305.5303v2#S3.Thmtheorem14), not the stronger condition involving extrema among *all* sources.

Fix supplied bounds (0<\kappa\le K<\infty\), and let each (k_e:[0,\infty)\to[\kappa,K]\) be an arbitrary measurable function. The dynamics are

\[
\dot x(t)=f(t,x(t)):=\sum_{e\in R}k_e(t)x(t)^{y_e}\nu_e,
\qquad x^y=\prod_i x_i^{y_i}.
\]

Solutions mean absolutely continuous Carathéodory solutions satisfying this equation almost everywhere. On every compact subset of the positive orthant, this vector field is uniformly bounded and uniformly locally Lipschitz in (x), and measurable in (t\). Thus each positive initial state has a unique maximal positive solution. Allowing real exponent vectors causes no local difficulty on this domain.

**Candidate theorem.** For every such finite endotactic edge diagram, interval ([\kappa,K]\), and positive class (P\), there is a nonempty compact convex (K_P\subset P\), determined by the diagram, the interval, and (P\), with the following property. Every measurable choice of rates in that interval and every (x^0\in P\) give a unique global positive solution. That solution enters (K_P\) in finite time and thereafter stays in (K_P\). The set is common to *all* those choices of rates. The entry time can be bounded in terms of (x^0\), the diagram, the interval, and (P\), independently of the measurable rate path.

Consequently there is a common (\epsilon_P>0\) such that eventually
\[
\epsilon_P\le x_i(t)\le\epsilon_P^{-1}\qquad(1\le i\le d).
\]
The class may be unbounded. The result applies in every finite dimension. In the ordinary chemical case this is the extended permanence conclusion.

## The actual new weighted-flux lemma

The affine lemma furnishes a finite family of slopes (r_\lambda\in[-1,1]^d\), independent of a small scale (h\), and offsets (b_\lambda(h)\). Define
\[
F_h(x)=\min_\lambda\{r_\lambda\cdot x+b_\lambda(h)\},\qquad
B_h=[h,h^{-1}]^d.
\]
Write (A_h(x)\) for every active label, including every minimizer at a tie. Each (x\in B_h\) is uniquely (x=X_h(p)=(h^{p_i})_i\) with (p\in[-1,1]^d\).

Use the finite comparison set
\[
D=\{e_i:1\le i\le d\}\cup\{z-y:y,z\in C,\ z\ne y\}
\]
and the strictly positive, generally discontinuous tolerance
\[
E(r)=\min\left(\{1/2\}\cup
\left\{\frac{|r\cdot v|}{2\|v\|_1}:v\in D,\ r\cdot v\ne0\right\}\right).
\]
The affine activity bound says, for every sufficiently small (h\), every active label at (X_h(p)\) satisfies
\[
\|p-r_\lambda\|_\infty<E(r_\lambda).
\]
Fix the family before setting
\[
H=\min\left(\{1\}\cup
\{|r_\lambda\cdot v|/2:\lambda\in\Lambda,\ v\in D,\ r_\lambda\cdot v\ne0\}\right)>0.
\]
It follows, for every active slope (r\), that
\[
r\cdot v\ne0\implies
\operatorname{sgn}(p\cdot v)=\operatorname{sgn}(r\cdot v),\qquad
|p\cdot v|\ge H.
\tag{1}
\]
In particular, whenever sources (u,w\) satisfy (r\cdot u>r\cdot w\),
\[
\frac{x^u}{x^w}=h^{p\cdot(u-w)}\le h^H.
\tag{2}
\]
All pairs of complexes are safe here. A smaller valid comparison set would contain coordinate vectors, all nonzero reaction vectors, and all nonzero source differences. Using *only* source differences would not justify the reaction coefficient lower bound below when a product is not itself a source.

Set
\[
L=\sum_{e\in R}\|\nu_e\|_1,\qquad
M=\max_{e\in R}\|y_e\|_1
\]
(take (M=0\) if (R\) is empty). Choose scales with
\[
K L h^H\le\kappa H.
\tag{3}
\]
If (r\in S^\perp\), then (r\cdot f(t,x)=0\) exactly. Otherwise there is a nonempty essential set (R_{-r}\). Choose an essential reaction (e_*:w\to w'\) whose source minimizes (r\cdot y_e\) over this set.

Endotacticity for the vector (-r\) says **every** essential reaction at this minimum tier has
\[
(-r)\cdot\nu_e<0,
\quad\text{or equivalently}\quad r\cdot\nu_e>0.
\]
Therefore (r\cdot\nu_{e_*}>0\). By the definition of (H\),
\[
r\cdot\nu_{e_*}\ge2H.
\tag{4}
\]
Every reaction with (r\cdot\nu_e<0\) is essential and has source (u=y_e\) strictly above this tier: equality is excluded by endotacticity. Hence (2) applies to *every* negative reaction, using the same source (w\). Dropping the other positive terms gives the exact estimate
\[
\begin{aligned}
r\cdot f(t,x)
&\ge\kappa x^w(r\cdot\nu_{e_*})
   -K\sum_{r\cdot\nu_e<0}x^{y_e}|r\cdot\nu_e|\\
&\ge x^w\bigl(2\kappa H-K L h^H\bigr)\\
&\ge\kappa H x^w.
\end{aligned}
\tag{5}
\]
The second line uses (\|r\|_\infty\le1\), so (|r\cdot\nu_e|\le\|\nu_e\|_1\). This coefficient accounting is essential: merely comparing *unweighted* reaction fluxes does not prove the derivative sign for a non-weakly-reversible network.

For (x\in B_h\), even for real possibly negative source exponents,
\[
x^w=h^{p\cdot w}\ge h^{\|w\|_1}\ge h^M,
\]
because (p\in[-1,1]^d\) and (0<h<1\). Thus
\[
r\cdot f(t,x)\ge\delta_h:=\kappa H h^M>0
\quad\text{for every active }r\notin S^\perp.
\tag{6}
\]
This bound is pointwise in admissible rate values. It does not use continuity in time, weak reversibility, connectedness, strong endotacticity, or boundedness of the class.

## Plateau, switching, and finite-time absorption

Choose (c\in P\) once. Choose (h_P\in(0,1)\) so small that activity holds for every (0<h\le h_P\), (3) holds there, and
\[
\|\log c/\log h\|_\infty<H\qquad(0<h\le h_P).
\tag{7}
\]
The labels and (H\) are already fixed. Condition (3) tends to zero with (h\), and (7) follows as (|\log h|\to\infty\). There is no circular choice of a family after a supposedly uniform scale.

Let (M_h=F_h(c)\). An active label at (c\) has zero slope: if any (r_i\ne0\), (1) for (e_i\) contradicts (7). Thus an active label is the constant (M_h\), and (F_h\le M_h\) throughout (\mathbb R^d\). The plateau
\[
K_h=\{x:F_h(x)=M_h\}
   =\bigcap_\lambda\{x:r_\lambda\cdot x+b_\lambda(h)\ge M_h\}
\]
is nonempty, closed, and convex. A constant label at the least constant value (M_h\) is active at every point of (K_h\cap B_h\). Its activity estimate gives
\[
\|p\|_\infty<E(0)=1/2,
\qquad K_h\cap B_h\subset\operatorname{int}B_{\sqrt h}.
\tag{8}
\]
Hence (K_h\) misses the boundary of (B_h\). If it contained any point outside (B_h\), the segment from (c\in\operatorname{int}B_h\) to that point would, by convexity, place a plateau point on this boundary. Therefore
\[
K_h\subset\operatorname{int}B_{\sqrt h},
\tag{9}
\]
and (K_h\) is compact and wholly positive. This also excludes the faces where any concentration vanishes; no separate face induction or a boundary extension of real powers is needed.

For (x\in P\setminus K_h\), a slope (r\in S^\perp\) cannot be active. Indeed (r\cdot(x-c)=0\), so its affine value equals its value at (c\), which is at least (M_h\), while (F_h(x)<M_h\). Consequently (6) applies to every active label on (B_h\cap(P\setminus K_h)\).

The fixed-rate source's all-times right-derivative formula must be adapted, rather than asserted unchanged. Along a Carathéodory solution, all affine compositions and their finite minimum are absolutely continuous on compact time intervals. At almost every time when (x\) and (F_h\circ x\) are differentiable,
\[
\frac{d}{dt}F_h(x(t))
 =\min_{\lambda\in A_h(x(t))}r_\lambda\cdot\dot x(t).
\tag{10}
\]
To see the formula, expand the finitely many active affine functions at a differentiability point of (x\); inactive labels have positive gaps and cannot become minimizing for sufficiently small positive increments. The right expansion is the minimum of the active slopes applied to (\dot x(t)\). At the almost-everywhere points where the composition is differentiable, this is its derivative. This handles ties. Integrating (10), (5), and (6) gives, on every trajectory segment in (B_h\), monotonicity of (F_h\); and, on a segment in (B_h\cap(P\setminus K_h)\),
\[
F_h(x(t))-F_h(x(s))\ge\delta_h(t-s).
\tag{11}
\]

A solution starting in (K_h\) initially stays in (B_h\). Monotonicity together with (F_h\le M_h\) forces it to remain at (F_h=M_h\). It cannot exit (B_h\), since the closed plateau misses its boundary. It stays in a compact subset of the positive domain. Uniform local boundedness gives a limit at any finite maximal endpoint, and Carathéodory local existence from that positive limit continues the solution. Thus it is global and stays in (K_h\), for every rate path. Since (f(t,x)\in S\) almost everywhere, it also remains in its class.

A global class trajectory remaining in (B_h\) from time (t_0\) must enter (K_h\): otherwise (11) increases the globally upper-bounded (F_h\) by at least (delta_h(t-t_0)\) indefinitely. The waiting time is at most
\[
W_h=\frac{M_h-\min_{x\in B_h}F_h(x)}{\delta_h}<\infty.
\tag{12}
\]
This bound depends on the scale and supplied data, not the measurable rate path.

Finally let (x^0\in P\), and choose (0<h_0\le h_P\) such that
\(|\log x^0/\log h_0\|_\infty<H\).
The same coordinate comparison shows every label active at (x^0\) has zero slope, and its constant value is the least constant value (M_{h_0}\). Hence (x^0\in K_{h_0}\), which proves global positivity and boundedness for this solution immediately.

Iterate
\[
h_{j+1}=\min\{\sqrt{h_j},h_P\}.
\]
If the trajectory stays in (K_{h_j}\), (9) implies that it stays in (B_{h_{j+1}}\), because (h_{j+1}\le\sqrt{h_j}\). Apply (12) to enter (K_{h_{j+1}}\) in finite time, after which it stays there. Repeated square roots reach the cap (h_P\) in finitely many steps. This argument needs no nesting or continuity in (h\) of the plateaux. One may sum the finite bounds (W_{h_j}\) for a path-independent entry bound. The number of transitions is at most
\[
\left\lceil\log_2\frac{|\log h_0|}{|\log h_P|}\right\rceil
\]
when (h_0<h_P\), and is zero when they coincide.

Set (K_P=K_{h_P}\cap(c+S)\). This is a nonempty compact convex subset of (P\), forward invariant for every admissible rate path and absorbing for every positive class solution. This completes the proposed theorem's proof, assuming the affine lemma reconstructed below.

## Scope tests, consequences, and charged resources

**Non-weakly-reversible, non-strongly-endotactic example.** In two species use
\[
(1,3)\to(2,3),\quad(3,3)\to(2,3),\quad
(0,0)\rightleftarrows(0,1).
\]
The horizontal subnetwork is endotactic in every direction: its two essential extreme sources point inward. The vertical reversible subnetwork is endotactic. A union of endotactic networks is endotactic, since a global extreme essential source is an extreme essential source of its own subnetwork. The full network is not weakly reversible, since the two horizontal arrows have no return paths. It is not strongly endotactic for (w=e_2\): every overall maximal source has second coordinate 3 and a horizontal, (w\)-neutral arrow, while the essential vertical sources have second coordinates 0 and 1. Its stoichiometric subspace is (\mathbb R^2\). In the constant-rate case its equations are
\[
\dot x=y^3(k_1x-k_2x^3),\qquad \dot y=k_3-k_4y.
\]
This is a concrete example the extension covers and the fixed-rate weakly-reversible hypothesis of release149 does not. For (r=-e_2\), the correct minimum tier is the source ((0,1)\) among *essential* reactions; taking minima among all source complexes would incorrectly choose neutral horizontal sources at height 3.

**Scope falsifications.** The need for rate bounds is real. The reversible, hence endotactic, network (0\rightleftarrows A\) with inflow (k_{\rm in}(t)=1/(1+t)\) and outflow 1 has (x'=1/(1+t)-x\) and (x(t)\to0\): dropping the positive lower rate bound breaks permanence. With inflow (e^t\) and outflow 1, its concentrations become unbounded: dropping the upper bound also breaks the conclusion. The one-way network (A\to2A\) fails endotacticity and has unbounded positive solutions. These are exact interface checks, not numerical diagnostics.

**Further mathematical consequences.** For fixed rates the theorem implies a positive equilibrium in each class. Apply Brouwer to the flow selfmaps of (K_P\) at times (1/n\), take a convergent sequence of fixed points, and use the uniform small-time expansion of the autonomous flow to obtain (f(x_*)=0\). For measurable (T\)-periodic rates, the time-(T\) map is a continuous selfmap of (K_P\), so Brouwer gives a positive (T\)-periodic solution. These are corollaries, not assertions of new priority. The weighted estimate also applies to every absolutely continuous solution of the rate-box differential inclusion; existence and uniqueness of arbitrary discontinuous state-feedback laws should not be conflated with the time-measurable ODE statement.

Real exponent vectors are covered because the comparison construction only uses finitely many real differences, and (x^y\) remains smooth on the positive domain. For a generalized kinetic system with kinetic complexes different from the stoichiometric sources, endotacticity must be checked on the **exponent-arrow diagram** (y_e\to y_e+\nu_e\); endotacticity of an unrelated stoichiometric graph is not enough.

**Supplied versus acquired inputs and costs.** The supplied finite diagram, its endotacticity assumption, and the global rate interval are the input. The argument acquires no rate history, samples, or equilibrium oracle. It retains a finite affine family, the network comparisons, a representative (c\) of the class, and a chosen scale. For a supplied family the active-label calculation costs (O(|\Lambda|d)\) scalar operations; the flux estimate uses (O(|R|d)\) network data. The affine existence proof supplies no useful bound on (|\Lambda|\), bit precision, (h_P\), or the waiting times. Its compactness-selected cover is not an implemented or polynomial-time synthesis algorithm. No practical runtime claim follows merely from having a finite trapping description. All scales, constants, and labels must be counted if a constructive compiler is later claimed.

## Independent audit of the affine lemma

The exact statement permits any pointwise positive (E:[a,b]^m\to(0,\infty)\). It produces finitely many labels with slopes in ([a,b]^m\), offsets (o(h^a)\), and this sequential property: if (h_n\to0\), (p^n\to p\in[a,b]^m\), and a fixed label is active at (X_{h_n}(p^n)\), then (|p-r\|_\infty<E(r)\). The approximating (p^n\) are allowed outside the cube. Finite labels and compactness then give the uniform activity bound used above. These are precisely the quantifiers needed here.

I reconstructed the induction as follows.

1. **Fix the smallest limiting exponent (t\).** Let (\mu(p)=\min_i p_i\). Include the slope (t\mathbf1\). In dimension 1 or at (t=b\), the fixed-minimum statement is immediate. In higher dimension, construct labels by the number (k\) of entries strictly raised above (t\), for (1\le k\le m-1\). Choose strictly decreasing (eta_k>t\) with (eta_k-t<E(r)\) for every already constructed type-(k-1\) slope. This is possible because the relevant slopes are finite and every corresponding (E(r)\) is positive.

2. **Induct on the raised coordinates.** For every (k\)-element set (U\), use the lower-dimensional lemma on ([eta_k,b]^U\), with tolerance (s\mapsto E(r(s))\), where (r(s)=s\) on (U\) and (t\) off (U\). Lift every label with offset (-h^{\beta_k}+d(h)\), where (d=o(h^{\beta_k})\). Every lifted slope has minimum (t\), and all local offsets are (o(h^t)\).

3. **Audit activity.** Comparing an active type-(k\) label with (t\mathbf1\) yields
   (sum_{i\in U}(r_i-t)h^{p_i^n}\le(1+o(1))h^{\beta_k}\).
   Since every coefficient is at least (eta_k-t>0\), no limiting (p_i\) on (U\) is below (eta_k\). Within the labels on the same (U\), all contributions off (U\) and the common negative offset cancel exactly. Lower-dimensional activity therefore gives the strict tolerance bound on (U\). Allowing (p_U^n\) to approach the cube from outside is genuinely needed at its faces.

4. **Audit unraised coordinates.** If (k<m-1\) and an unraised limiting coordinate exceeded (eta_{k+1}\), compare with any type-(k+1\) label raised on (U\) plus that coordinate. Every exponent there is strictly above (eta_{k+1}\), so its excess over (t\mathbf1\) is (-h^{\beta_{k+1}}+o(h^{\beta_{k+1}})\). The active type-(k\) excess is at least (-h^{\beta_k}+o(h^{\beta_k})\) (zero when (k=0\)). Because (eta_k>\beta_{k+1}\), the competitor is strictly smaller. Thus every unraised coordinate is at most (eta_{k+1}\), and its error is at most (eta_{k+1}-t<E(r)\). When (k=m-1\), the sole unraised coordinate equals (t\), since the raised coordinates have limits strictly above (t\). No asymptotic argument is applied at an equal limiting exponent.

5. **Extend from (mu(p)=t\) to a neighborhood.** For each local label, the set of limits of actual active sequences is closed by diagonal selection. The finite union of limits violating (|p-r\|_\infty<E(r)\) is compact, even though (E\) is discontinuous, because its arguments here are fixed slopes. This compact bad set contains no limit with minimum exponent (t\), and so stays a positive distance in the (mu\) coordinate from (t\). This provides a symmetric interval (I_t\) of valid minimum exponents. Shrink its radius so all local offsets are (o(h^{t+\rho_t})\), by keeping (t+\rho_t<\min_k\beta_k\). These are compatible positive-radius requirements.

6. **Combine a finite cover without a uniform lower bound on (E\).** Take a finite subcover of ([a,b]\) by the (I_t\), remove contained intervals, and order by centers (t_1<\cdots<t_N\). Noncontainment forces both endpoint lists to be strictly increasing. Consecutive intervals overlap; otherwise a point between their centers would be uncovered. Choose cuts
   (max(t_j,L_{j+1})<q_j<\min(t_{j+1},R_j)\).
   The interval is nonempty because of overlap and because each interval contains its center. Then ([q_{j-1},q_j]\subset I_{t_j}\), including endpoints.

7. **Check the shifted affine values exactly.** Shift every family (j\) by (-sum_{\ell<j}h^{q_\ell}\). If its active limiting minimum is above (q_j\), comparison with the shifted (t_{j+1}\mathbf1\) gives excess (h^{q_j}+o(h^{q_j})>0\). If it is below (q_{j-1}\), comparison with shifted (t_{j-1}\mathbf1\) gives
   ((r-t_{j-1}\mathbf1)\cdot X_h(p^n)+c(h)-h^{q_{j-1}}\),
   whose quotient by (h^{q_{j-1}}\) goes to (+\infty\), since every coefficient is positive and one limiting exponent is strictly smaller. Thus every active family is valid on its assigned interval. The shifts and local offsets are all (o(h^a)\). The strict local guarantees complete the induction.

8. **Get the uniform corollary in the correct order.** If activity failed uniformly for arbitrarily small (h\), finite labels give one fixed label along a subsequence, and the compact cube gives a limiting (p\). The violation passes to the limit because the tolerance is evaluated at that fixed slope, contradicting the sequential lemma. No continuity of (E\), offsets in (h\), or moving reaction rates is assumed.

In particular, I checked the base case, negative (a\), the terminal slice (t=b\), ties, equal cuts, lower-dimensional faces approached from outside, deletion of contained intervals, strictness of the error bound, and the exact cancellation of shifts. I found no invalid limit exchange or quantifier mismatch. The affine statement is genuinely more flexible than a finite ordinary grid: zero products are deliberately permitted, while every nonzero product gets a slope-specific neighborhood that preserves its sign.

## Evidence and prior-art boundaries

- Exact release149 source: [Uniform Permanence in Weakly Reversible Mass-Action Systems, fixed release commit](https://github.com/openai/math/tree/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/Uniform-Permanence-in-Weakly-Reversible-Mass-Action-Systems-October-5-2026). The source itself states fixed rates and weak reversibility. I copied all six supplied TeX/bibliographic sources and checked every supplied SHA-256 against its manifest. See `sources/manifest.json` in this directory. Integrity is not correctness.
- The essential-source convention and distinction from strong endotacticity are verified in [Gopalkrishnan–Miller–Shiu 2014](https://arxiv.org/html/1305.5303v2). Its stated main permanence result is for strongly endotactic networks; Conjecture 4.5 records the all-endotactic target.
- [Craciun–Nazarov–Pantea 2013](https://arxiv.org/abs/1010.3050) formulated the variable-rate extended permanence conjecture and proved the two-species case. Their power-law discussion does not require integer or nonnegative exponents.
- [Endotactic Networks and Toric Differential Inclusions](https://arxiv.org/abs/1906.08384) concerns the embedding mechanism; embedding by itself is not a permanence proof. [First-order endotactic reaction networks](https://arxiv.org/abs/2409.01598) is a first-order subclass result, not an arbitrary higher-order result.

A targeted live search on 7 October 2026 and a search of the supplied OpenAI contents did not identify another all-dimensional all-endotactic variable-rate permanence theorem. That search is useful prior-art evidence, not a novelty certificate. The genuinely new deduction here is the weighted essential-tier flux replacement of release149's weakly-reversible cut argument, together with rate-independent positive drift and the almost-everywhere chain rule. The expensive mathematical capital remains the affine construction supplied by release149.

## Standalone manuscript and subsequent checks

At root's request, the full proof has now been written in `endotactic_permanence.tex` in this directory, with no external includes or bibliography files. The desktop built-in compiler returned success twice, including after the final definition correction and three-species witness addition. Compilation establishes source validity, not theorem correctness.

The manuscript includes the correct finite-family switching extension: every component diagram must have the same exact stoichiometric span (S\) for common classwise absorption under arbitrary measurable switching or convex weights. The budgets can be (L=\max_j\sum_{e\in R_j}\|\nu_{j,e}\|_1\) and (M=\max_{j,e}\|y_{j,e}\|_1\). Each component has the same lower drift (delta_h=\kappa Hh^M\) for active (r\notin S^\perp\), so every convex mixture does too. If spans differ, switching permanently between (0\rightleftarrows A\) and (0\rightleftarrows B\) preserves an arbitrary concentration in the inactive coordinate and prevents a compact absorber on the class for the union span.

It also proves topology-independent **invariance** of the common plateau for any finite number of compartments under common scalar mixing coefficients across species. The joint minimum (G=\min_{z,\lambda}L_{\lambda,h}(x_z)\) is nondecreasing in the product box. At an active pair ((z,\lambda)\), every mixing contribution is nonnegative because (L_{\lambda,h}(x_w)\ge F_h(x_w)\ge G=L_{\lambda,h}(x_z)\). This needs no common mode span, since only nonnegative reaction drift is required. It is a safety result for a supplied compact positive initial range, not a common absorption or convergence-rate claim.

The coupled higher-order three-species witness (2A\to2B\to2C\to2A\), (4A\rightleftarrows6B\), (A+B\to2B\) has determinant-8 reaction-vector basis and hence span (mathbb R^3\). For (w=(a,b,c)\), the added edge is outward only if (b>a\), when its source level (a+b\) is below an essential cycle source at level (2b\). It therefore preserves endotacticity of the weakly reversible base. The source (A+B\) has no return path, and (w=-(1,1,1)\) makes all maximal source levels neutral, so the full diagram is neither weakly reversible nor strongly endotactic. This is a concrete witness outside the first-order, two-dimensional, and strongly endotactic hypotheses directly discussed in the cited prior work.

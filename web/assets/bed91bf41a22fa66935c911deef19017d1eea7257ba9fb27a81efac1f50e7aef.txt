LEAF: EXACT REACHABILITY AND COMMUNICATING CLASSES

Assigned network

Let r,s>=1 be integers, with catalyst species A_1,...,A_r and substrate species B_1,...,B_s. For each j,i let k_ji>=1 be an integer. Include, for every j,i, the reversible reaction pairs

    0 <-> A_j,
    A_j <-> A_j+B_i,
    A_j+B_i <-> (k_ji+1)A_j+B_i,

and assume every direction has a fixed positive rate constant. The state is x=(a_1,...,a_r,b_1,...,b_s) in N_0^(r+s). This note treats exact reachability, classes, stoichiometric rank and deficiency. It does not infer recurrence from weak reversibility or irreducibility.

Main conclusion

The reaction graph has one linkage class and is weakly reversible. Its stoichiometric rank is r+s, so there is no nonzero linear conservation law. Its number of distinct complexes is 1+r+2rs, and its deficiency is

    delta = (1+r+2rs) - 1 - (r+s) = s(2r-1).

For every fixed positive rate vector, the stochastic mass-action CTMC is irreducible on the entire lattice N_0^(r+s); this entire lattice is its one closed communicating class. In particular every catalyst-free substrate vector (a=0,b arbitrary), including arbitrarily high substrate tiers, is reachable from every other state. Constructive paths are given below.

Complexes, linkage, rank, deficiency

All listed complexes are distinct under k_ji>=1: the zero complex; r single-catalyst complexes A_j; rs complexes A_j+B_i; and rs complexes (k_ji+1)A_j+B_i. The last kind has at least two A_j molecules, and the B_i coordinate and catalyst index identify the pair (j,i), so it collides with none of the other listed complexes. Thus n_c=1+r+2rs.

The reaction graph is connected: every A_j is adjacent to 0, every A_j+B_i is adjacent to A_j, and every amplified complex is adjacent to A_j+B_i. Every edge has its reverse, so there is one linkage class, l=1, and the network is weakly reversible.

Using standard unit vectors in species coordinates, reaction vectors include

    0 -> A_j:                    +e_(A_j),
    A_j -> A_j+B_i:              +e_(B_i),
    A_j+B_i -> (k_ji+1)A_j+B_i:  +k_ji e_(A_j).

Since all k_ji>=1 and both catalyst and substrate indices exist, the first two families already span every coordinate direction. Hence rank(S)=r+s. The deficiency is therefore n_c-l-rank(S)=s(2r-1). The high-order reactions add no stoichiometric directions beyond the catalyst directions supplied by 0<->A_j.

Exact stochastic transitions

Write the positive direction-specific rate constants as alpha_j for 0->A_j and alpha_bar_j for A_j->0; beta_ji for A_j->A_j+B_i and beta_bar_ji for its reverse; gamma_ji for A_j+B_i->(k_ji+1)A_j+B_i and gamma_bar_ji for its reverse. Under stochastic mass action with falling factorials, the rates and state changes are:

    0 -> A_j:                    a_j increases by 1, rate alpha_j,
    A_j -> 0:                    a_j decreases by 1, rate alpha_bar_j*a_j,
    A_j -> A_j+B_i:              b_i increases by 1, rate beta_ji*a_j,
    A_j+B_i -> A_j:              b_i decreases by 1, rate beta_bar_ji*a_j*b_i,
    A_j+B_i -> (k_ji+1)A_j+B_i:  a_j increases by k_ji,
                                    rate gamma_ji*a_j*b_i,
    (k_ji+1)A_j+B_i -> A_j+B_i: a_j decreases by k_ji,
                                    rate gamma_bar_ji*(a_j)_(k_ji+1)*b_i.

Every listed transition is enabled exactly when its reactant counts are present. In particular, all B_i-changing reactions require a catalyst, but catalyst immigration is enabled even when every count is zero.

Constructive communication paths

First show that every x reaches the origin. Fix any catalyst index j0 (available because r>=1).

1. If a_j0=0, fire 0->A_j0 once. Otherwise keep the existing A_j0. Now a_j0>=1.
2. For each i=1,...,s, fire the reverse substrate reaction A_j0+B_i->A_j0 exactly b_i times. Each firing has rate beta_bar_(j0 i)*a_j0*b_i_current>0, leaves a_j0 unchanged, and reduces b_i by one. After these firings all substrates are zero.
3. Fire A_j->0 exactly a_j times for each j. This reaches the origin.

Now show that the origin reaches an arbitrary target (a*,b*).

1. If some target a*_j*>0, use 0->A_j exactly a*_j times for every j, producing the desired catalyst vector. Keep one positive target catalyst j* available.
2. For every substrate i, fire A_j*->A_j*+B_i exactly b*_i times. These reactions preserve all catalyst counts.
3. If all target catalyst counts are zero, instead create one temporary A_1, create the required substrates using A_1->A_1+B_i, and then remove the temporary A_1 by A_1->0.

Every prescribed finite path has positive probability because all used rate constants are positive and each selected reaction is enabled when fired. Thus every state reaches zero and zero reaches every state. All states communicate, and the one class is closed because it is the whole state space; no enabled reaction exits N_0^(r+s).

Catalyst-free high-substrate tiers

For every substrate vector b in N_0^s, the catalyst-free state (0,b) is in the same irreducible class. In particular the adjacent tier steps are explicitly reachable in both directions:

    (0,b) -> (e_(A_1),b) -> (e_(A_1),b+e_(B_i)) -> (0,b+e_(B_i)),

using immigration, substrate birth, and catalyst death; and, whenever b_i>0,

    (0,b) -> (e_(A_1),b) -> (e_(A_1),b-e_(B_i)) -> (0,b-e_(B_i)),

using immigration, substrate death, and catalyst death. All rates on these paths are positive. Repetition reaches any substrate tier, including vectors with arbitrarily large coordinates, while keeping all catalysts zero at the endpoints.

Essential assumptions and edge-removal checks

- Positive 0->A_j for every j is necessary for full-lattice irreducibility. If it is absent, the face a_j=0 is invariant: all other reactions that can increase a_j require A_j already present.
- Positive A_j->0 for every j is necessary for full-lattice irreducibility. Without it, a_j cannot fall below 1 once positive: the only other reaction that lowers a_j is the reverse amplification, which leaves one A_j in its product.
- For each substrate B_i, at least one positive substrate-birth edge A_j->A_j+B_i is necessary to increase b_i, and at least one positive substrate-death edge A_l+B_i->A_l is necessary to decrease b_i. The indices j and l need not match, provided their catalysts can be created. If all such edges are removed for a given i, b_i is conserved. If all forward (respectively reverse) substrate edges for i are removed, b_i is nonincreasing (respectively nondecreasing), obstructing full-lattice communication.
- It is sufficient for reachability that each catalyst has positive immigration and death, and that each substrate has at least one catalyst channel in each of the two substrate directions. Having both substrate directions for every catalyst-substrate pair, as in the assigned network, is stronger than necessary.
- The high-order amplification pairs are not needed for communication at all. They may be removed, or their rates set to zero, and the paths above still prove irreducibility as long as the immigration/death and substrate-direction conditions remain. Their positivity and k_ji values affect the reaction graph/deficiency and can affect recurrence, but not the communicating class.
- The values k_ji>=1 are not used in the path proof except that they define valid nonzero amplification jumps and distinct extra complexes for the stated deficiency count. Changing their positive integer values does not change reachability.
- Rate magnitudes do not affect the communication result; positivity of the required directed edges does. If any required rate is zero, use the edge tests above to determine whether an obstruction appears.

Boundary and scope limits

There are no catalyst-free closed boundary classes because 0->A_j is enabled at every state, including the origin and every substrate-only state. Once a catalyst is present, each substrate count can be changed in either direction, and the catalyst can later be removed. This is the exact boundary reason the full lattice is one class.

Weak reversibility alone is not the boundary proof: graph paths need not be executable from every lattice point. Here the empty-source catalyst births and the explicit helper-catalyst paths prove executability. Also, communication and class closure say nothing by themselves about non-explosion, positive recurrence, stationary distributions, or Foster inequalities. The high-order amplifier rates may be important for those separate questions; this leaf does not resolve them.

Claim status and falsifiers

- INTERNALLY-PROVED-CANDIDATE: One closed irreducible class N_0^(r+s) under the stated r,s>=1 and positive-rate assumptions.
- INTERNALLY-PROVED-CANDIDATE: rank r+s, one linkage class, n_c=1+r+2rs, deficiency s(2r-1).
- INTERNALLY-PROVED-CANDIDATE: every catalyst-free substrate state (0,b) and every high-substrate tier is reachable both from the origin and from every other state.
- Falsifiers: a duplicate complex invalidating n_c; a missing coordinate vector in the stoichiometric span; a boundary state with no positive-rate path to/from zero; or an enabled transition violating the prescribed count changes. Under k_ji>=1, r,s>=1, and positive rates, none is present.
- UNKNOWN / OUT OF SCOPE: recurrence, non-explosion, rate-uniform bounds, and stationary tails. No such conclusion is inferred from weak reversibility or from the single communicating class.

Computational costs

The proof uses O(r+s) symbolic reachability operations for a given state (one helper catalyst, then one pass over catalyst and substrate coordinates); path length is at most O(sum_j a_j + sum_i b_i + 1) in each direction, with the one-time helper allowance. It does not enumerate the infinite state space. The graph count is O(r+s+rs) complexes and the rank computation is explicit. No rate magnitude, numerical precision, or oracle query is used beyond checking that the required edge rates are positive.

Cycle 4 leaf: uniform V-geometric mixing on a complete-pair rate box
====================================================================

Status and scope
----------------
INTERNALLY-PROVED-CANDIDATE, conditional on the stated complete-pair family
and compact positive rate box. The result is a uniform-in-parameter mixing
upgrade of the common geometric Foster inequality in
outputs/research/reaction_dynamics/cycle3/leaves/geometric_rate_box.txt.
The all-state geometric drift is separately checked for the rational
one-catalyst/one-substrate fixture below. A finite script check is evidence
for those exact constants, not a substitute for the analytic tail proof.
External correctness review and novelty/priority are unresolved.

Data boundary: the reaction topology, dimensions, integer k_ji, and rate-box
endpoints are supplied assumptions. The [1,2] one-catalyst fixture is a
chosen rational example, not acquired molecular geometry or measured rate
data. No N35 finite-horizon safety certificate, stochastic-control result,
or N34 global-recognition result is used as a premise. This theorem concerns
an autonomous homogeneous CTMC in the specified complete-pair family; it
does not cover arbitrary predictable switching or general weakly reversible
networks.

1. Family and common geometric drift premise
--------------------------------------------
Fix finite r,s>=1 and integers k_ji>=1. For j=1,...,r and i=1,...,s the
reactions and propensities are

  0 -> A_j                              alpha_j
  A_j -> 0                              delta_j a_j
  A_j -> A_j+B_i                        p_ji a_j
  A_j+B_i -> A_j                        q_ji a_j b_i
  A_j+B_i -> (k_ji+1)A_j+B_i            u_ji a_j b_i
  (k_ji+1)A_j+B_i -> A_j+B_i            v_ji (a_j)_(k_ji+1) b_i.

All rate coordinates range in compact intervals with strictly positive lower
and finite upper endpoints. One parameter vector theta is held fixed for
each chain. Falling factorials are exact stochastic mass-action factors and
are zero below their thresholds.

Use the common function from the Cycle 3 rate-box proof,

  A = sum_j a_j,   Psi(b) = sum_i R^(b_i),
  V(a,b) = A + (1 + 1_{A=0}) Psi(b),

for a common rational R>1. The Cycle 3 proof supplies constants C,c>0,
independent of theta, such that

  L_theta V <= C - c V                                                    (1)

on every state. V is norm-like, V>=1, and all its sublevel sets are finite.
For the generic theorem below, (1) is the only drift input. A complete
all-state verification of (1) for one explicit rational box is in Section 5.

2. One common time skeleton and finite-set drift
------------------------------------------------
Let P_t^theta be the CTMC semigroup. The nonexplosion proof accompanying
(1) uses stopped Dynkin localization. Applying it to the local Lyapunov
supermartingale exp(ct)V(X_t)-integral_0^t C exp(cs) ds, followed by Fatou,
gives the common semigroup estimate

  P_T^theta V <= exp(-cT)V + (C/c)(1-exp(-cT)).                            (2)

This holds for every theta and T>=0. It is physical-time semigroup drift;
it does not assume globally bounded reaction rates. Choose a rational T>0
with T<=1/(2C) and Lambda_D T<1, where Lambda_D is the local path-state
exit-rate bound constructed in Section 3. Define rational/real constants

  lambda = 1/(1+cT),       b = C T.

Since exp(-x)<=1/(1+x) and 1-exp(-x)<=x, (2) implies

  P_T^theta V <= lambda V + b.                                            (3)

The time T will be the same in both the drift and minorization. Put

  d = 2C/c + 2s + 2,       D = {x: V(x)<d},
  lambda_out = lambda + b/d,       K_D = lambda d+b.

Here d>V(0)=2s, so 0 is in D. D is finite. Also

  2b/(1-lambda) = 2C(1+cT)/c <= 2C/c+1 < d,

where T<=1/(2C) was used. Thus lambda_out<1. From (3),

  P_T^theta V(x) <= lambda_out V(x),   x outside D,
  P_T^theta V(x) <= K_D,              x in D.                             (4)

These are the common skeleton drift constants in the form used by the
quantitative V-geometric ergodicity theorem.

3. Uniform clearing-path minorization
-------------------------------------
Write alpha_j^-, delta_j^-, q_ji^- for the supplied lower endpoints and set

  rho_* = min(alpha_1^-, min_(j,i) q_ji^-, min_j delta_j^-) > 0.

For x=(a,b) in D define conservative coordinate bounds

  A_D = floor(d),
  B_D = min{n in N_0: R^(n+1)>=d},
  L_D = A_D + s B_D.

Indeed A<d gives A<=A_D, and V>=Psi>=R^(b_i) gives b_i<=B_D. Also d>2s+2>=4, hence A_D>=2.

Choose a finite clearing path from x to zero as follows. If A>0, choose any
j with a_j>0, use A_j+B_i -> A_j exactly b_i times for each i, then use
A_j -> 0 exactly a_j times for each j. If A=0, first immigrate one A_1,
clear all b_i using A_1+B_i -> A_1, and kill the temporary A_1. Every
selected step is enabled. The number of steps is at most L_D: for A>0 it is
A+sum_i b_i; for A=0 it is 2+sum_i b_i<=A_D+sB_D. The catalyst total
along the path is at most A_D (the temporary value 1 is also <=A_D), and
each substrate coordinate is at most B_D.

For every state z on every such path, the total exit rate is bounded by the
same finite constant

  Lambda_D = sum_j alpha_j^+
       + A_D sum_j delta_j^+ + A_D sum_(j,i) p_ji^+
       + A_D B_D sum_(j,i)(q_ji^+ + u_ji^+)
       + B_D sum_(j,i) v_ji^+ (A_D)_(k_ji+1).                            (5)

This uses (a_j)_(k+1)<=(A_D)_(k+1). At each selected step the propensity is
at least rho_*: immigration is >=alpha_1^-, a selected substrate-removal
step has q_ji a_j b_i>=q_ji^-, and a selected catalyst death has
delta_j a_j>=delta_j^-.

Fix theta and one such path z_0=x,...,z_ell=0. The probability density for
exactly these ell jumps at ordered times 0<t_1<...<t_ell<T, with no other
jumps before T, equals the product of the selected channel propensities
times the exponential holding factor over the ell+1 path states. All those
exit rates are <=Lambda_D, so integrating this density over the time simplex
gives

  P_T^theta(x,{0}) >= exp(-Lambda_D T) (rho_* T)^ell / ell!.              (6)

This is a finite-path density bound, not global uniformization: exit rates
outside the path-state box need not be bounded. If Lambda_D T<1, then
exp(-Lambda_D T)>exp(-1)>1/3. Also rho_*<=alpha_1^-<=sum_j alpha_j^+
<=Lambda_D, so rho_*T<1. Hence the right side of (6) is at least the rational constant

  eta = (1/3) min_(0<=ell<=L_D) (rho_*T)^ell/ell!
      = (rho_*T)^(L_D) / (3 L_D!) > 0.                                  (7)

For rational endpoints and rational T this is an exact positive rational;
it is intentionally left factored when its numerator and denominator would
be enormous. We have the common minorization

  P_T^theta(x,.) >= eta delta_0(.),       x in D, theta in Theta.          (8)

4. Irreducibility, aperiodicity, and uniform V-norm rate
--------------------------------------------------------
The complete-pair support gives an explicit path from any state to zero by
the clearing procedure above, regardless of whether the starting state is
in D. From zero, immigrate each desired catalyst count, add each desired
substrate count using any catalyst that is present, and, when the target
has no catalysts, remove the temporary catalyst after adding substrates.
Every prescribed finite path has positive probability in every time T>0:
its selected propensities are positive and its finite path-state exit rates
are finite. Therefore every P_T^theta is irreducible. Moreover

  P_T^theta(x,{x}) >= exp(-q_theta(x)T)>0

by the no-jump event, so the irreducible skeleton is aperiodic. The common
minorization also gives strong aperiodicity in the small-set formulation,
because delta_0(D)=1.

Apply Baxendale's quantitative V-geometric ergodicity theorem for discrete
time Markov chains (Theorem 1.1 and the non-atomic formulas in Section 2.1
of the cited paper). Its common inputs here are

  minorization tilde-beta = eta,   minorizing law nu = delta_0,
  strong-aperiodicity beta = eta,   lambda_B = lambda_out,
  K_B = K_D,                        nu(D)=1.

Let rho_B<1 and M_B(gamma)<infinity be exactly the explicit functions of
these inputs defined in that theorem. In particular its formula gives
rho_B from the root R_1 and maximization R_e in Section 2.1, and M_B from
equation (6) there; since nu(D)=1, the theorem's simplification alpha_2=1
applies. More explicitly, use the paper's
alpha_1=1+log((K_B-eta)/(1-eta))/log(lambda_out^(-1)),
R_0=min(lambda_out^(-1),(1-eta)^(-1/alpha_1)), and
L(R)=eta R/[1-(1-eta)R^alpha_1]; then R_e maximizes
R_1(eta,R,L(R)) on 1<R<=R_0 and
rho_B=1/R_1(eta,R_e,L(R_e)). R_1 and M_B are the exact functions in
equations (4) and (6) of Section 2.1 of the cited source. No theta-specific
input occurs. For every gamma with
rho_B<gamma<1, all theta, all states x, and all n>=0,

  ||P_(nT)^theta(x,.) - pi_theta||_V <= M_B(gamma) V(x) gamma^n,         (9)

where ||mu||_V = sup_{|f|<=V} |integral f dmu|. Each pi_theta is unique
and has finite V moment. Integrating (3) against pi_theta gives the common
moment bound pi_theta(V)<=b/(1-lambda)=C(1+cT)/c.

Equation (9) is the requested exact uniform-in-the-box convergence norm
and rate: rho_B and M_B are the computable Baxendale functions evaluated at
the displayed common rational/real inputs. One can fix a single rate, for
example gamma=(1+rho_B)/2, and its corresponding common M_B. The numerical
rate is not sharp; the path minorization can be very small.

The skeleton theorem gives one invariant pi_theta with finite V moment. For
any s>=0, pi_theta P_s^theta is also P_T^theta-invariant because the CTMC
semigroup commutes. Uniqueness for the irreducible skeleton therefore gives
pi_theta P_s^theta=pi_theta, so this is also the CTMC invariant law used in
(9)-(10).

It also gives a continuous-time bound. For 0<=s<T, (2) and V>=1 imply
P_s^theta V <= (1+C/c)V. If t=nT+s and r_gamma=-log(gamma)/T, then

  ||P_t^theta(x,.)-pi_theta||_V
       <= (1+C/c) M_B(gamma) gamma^(-1) exp(-r_gamma t) V(x).            (10)

Thus the physical-time exponential rate and prefactor are also common to
the entire compact box.

5. Exact rational one-catalyst/one-substrate fixture
----------------------------------------------------
Choose r=s=1, k=1 and independently let each of alpha,delta,p,q,u,v range
over the supplied interval [1,2]. Set R=6/5 and

  V(a,b)=a+(1+1_{a=0})R^b,       c=1/10.

The exact generator is

  LV(0,b)=alpha(1-R^b),
  LV(a,b)=alpha-delta a
      +a[p(1/5)R^b-q(1/6)bR^b+u b]
      -v a(a-1)b + delta 1_{a=1}R^b,       a>=1.                        (11)

The last term is the exact support-switch correction when the sole catalyst
dies. Define g_b=(2/5)R^b-(b/6)R^b+2b, the uniform upper envelope of the
bracket in (11). For 0<=b<=24, maximize LV+cV over the box endpoints; this
is exact because the generator expression is affine in each rate coordinate.
At a=0 it is <=1/5. At a=1 the exact upper envelope is

  W_1(b)=2+2(R^b-1)+g_b+c(1+R^b).

For a>=2 it is

  W_a(b)=2-a+a g_b-a(a-1)b+c(a+R^b).

For each b>=1, W_a is the concave quadratic
2+cR^b + a(-1+g_b+b+c)-b a^2; its integer maximum over a>=2 is found by
checking the integers bracketing its rational vertex and a=2. At b=0 it
decreases over a>=2. Exact Fraction arithmetic gives the maximum over all
low states at (a,b)=(1,14):

  C = max_{0<=b<=24,a>=0,theta}(L_theta V+cV)
    = 369138966157/12207031250 > 2.                                    (12)

For the remaining tail, let

  f(b)=g_b/R^b = 2/5-b/6+2b/R^b.

For b>=5, (b+1)/R^(b+1)<=(b)/R^b, so f decreases. Direct exact arithmetic
gives

  f(25) = -230465642630552213999/71075720074824253440 <= -3.

Thus g_b<=-3R^b for every b>=25. If a>=2, (11) gives
LV<=2-3aR^b<=2-aR^b. If a=1, use
delta(R^b-1)<=2(R^b-1) to obtain LV<=2-R^b. In both cases,

  LV <= 2-aR^b <= 2-(a+R^b)/2 = 2-V/2 <= C-(1/10)V.

At a=0, LV+(1/10)V=alpha(1-R^b)+(1/5)R^b<=1/5<C. Together with (12),
this proves the all-state strict geometric drift LV<=C-cV for the entire
[1,2]^6 box.

The shared skeleton and minorization constants are the following exact
rationals:

  d = 2C/c+4 = 743160744814/1220703125,
  A_D=floor(d)=608,   B_D=35 since (6/5)^35<d<=(6/5)^36,
  L_D=A_D+B_D=643,    A_path=608,
  Lambda_D = 2 + 4 A_path + 4 A_path B_D
                 + 2 B_D A_path(A_path-1) = 25921474,
  T = 1/(2C+Lambda_D) = 6103515625/158212490720997407,
  lambda = 1/(1+cT) = 316424981441994814/316424982662697939,
  b = CT = 369138966157/316424981441994814,
  lambda_out = lambda+b/d
      = 74408797958195577532560357097331917799334297019
        /74408798102665589641732753898272767619890937644.

This exact lambda_out is below one; Lambda_D T<1 and T<=1/(2C). Here
rho_*=1, hence

  eta = T^643/(3*643!) > 0.                                               (13)

This is an exact rational small-set minorization for every state in D and
every rate vector in the [1,2]^6 box. It is deliberately conservative and
tiny, so (9) certifies uniform geometric convergence but is not a practical
mixing-time estimate.

Reproduction and limits
-----------------------
Run from the workspace root:

  python3 -B outputs/research/reaction_dynamics/cycle4/leaves/uniform_mixing/rational_fixture.py

It checks the exact tail inequality, quadratic low-state maximization,
drift constants, path-state rate bound, skeleton parameters, and rational
minorization expression. The proof of the tail monotonicity and the
parametric clearing-path argument are analytic. The uniform theorem does
not hold here for arbitrary time-varying controls by this proof: such
controls do not define the homogeneous kernel to which the V-geometric
ergodicity theorem is applied, and a stationary law pi_theta is not
available for a general controlled evolution.

Primary theorem reference: P. H. Baxendale, "Renewal theory and computable
convergence rates for geometrically ergodic Markov chains," Annals of
Applied Probability 15 (2005), 700-738, Theorem 1.1 and Section 2.1,
https://arxiv.org/abs/math/0503515 . The cited source supplies the explicit
rate functions only; it is not evidence for the reaction-family drift or
clearing-path calculations above.

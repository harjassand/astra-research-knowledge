Q06 | Critical qubits: conditional classical compression and Schur baseline
Date: 2026-10-08

**Verdict.** For ρ_(n,U)=U diag(1/2+r_n,1/2-r_n)U*, with
r_n=Θ(n^-1/2), the inherited Gaussian-memory theorem gives a fully
classical total dimension D=Θ(ε_n^-3/2), but only conditionally on the
N08 two-way quantum-to-Gaussian bridge. If each bridge direction has error
b_n, channel contraction gives |e_D^iid-e_D^G|≤2b_n. The precise asymptotic
transfer gate is 2b_n=o(ε_n); N08 supplies b_n=O(r_n+n^-1/2), so the law is
certified only when ε_n→0 and ε_n√n→∞. This is not a newly proved,
uniform full-orbit QLAN theorem.

The exponent is 3/2 because the critical qubit orbit's Gaussian mean sphere
has affine span R^3, not because it has three intrinsic parameters: the
noiseless orbit itself is two-dimensional. N07's positive-hat Gaussian code
uses J^3 classical labels at mesh J^-1 and TV error O(J^-2); the matching
lower allows arbitrary quantum/hybrid storage. All branch labels count.

**Fair Schur comparison.** Independently, an exact finite-n cutoff retains
each spin-L block with L≤L_* and sends one tail symbol. For the Schur law,

    p_L=m_L(p_+p_-)^((n-L)/2)(p_+^(L+1)-p_-^(L+1))/(2r_n),
    m_L=C(n,(n-L)/2)-C(n,(n-L)/2-1).

The critical tail is sub-Gaussian uniformly for r_n≤c/sqrt(n); hence
L_*=O(sqrt(n log(1/ε))) gives discarded mass at most ε. Keeping the
sector label and its (L+1)-dimensional spin state while regenerating the
maximally mixed multiplicity costs

    D_Schur=1+sum_(L≤L_*)(L+1)≤C n(1+log(1/ε)).

For ε->0 with ε sqrt(n)->infinity, the explicit choice
L_*=Theta(sqrt(n log(1/ε))) is o(n), so this selected cutoff has
D_Schur=Theta(n log(1/ε)); this is not an optimality claim over all
quantum codecs.

The encoder and decoder need only a public critical-radius envelope; neither
the unknown eigenbasis nor the realized radius is estimated. Bacon--Chuang--
Harrow supply poly(n,log(1/ν)) Schur-transform circuits; output preparation
and fresh multiplicity randomness are separate from retained D. In the
bridge-valid window, ε^-3/2=o(n), so the conditional classical dimension is
asymptotically smaller than this simple Schur cutoff. This cutoff is not an
optimality claim.

At ε=O(n^-1/2), the bridge remainder is comparable to the target: the upper
has no assured positive error budget after composition, and the lower only
controls D via ε+O(n^-1/2). The classical precision law below the bridge scale
is unknown; this does not refute it. The N07/N08 code remains an
information-theoretic continuous-channel statement: finite-bit realization
of the normal CDF/inverse-CDF kernels and reverse quantum channel is not
specified. Any implementation remainder ν_n must be charged and satisfy
2b_n+ν_n=o(ε_n) for the same asymptotic law.

If exact spectrum calibration is imposed, the source model treats it as
supplied data. The bridge and a conservative Schur cutoff actually need only
a public bound r_n≤c/sqrt(n), so no calibration sample is required under the
stated contract. If a separate known-axis radius calibration is desired, a
sufficient Hoeffding budget for accuracy O(ε/sqrt(n)) is
O(nε^-2 log(1/α)) samples; it is optional, not part of either theorem.

Primary-source scope: [Kahn--Guță Q-LAN](https://arxiv.org/abs/0804.3876)
and [Bacon--Chuang--Harrow Schur circuits](https://arxiv.org/abs/quant-ph/0407082)
are established antecedents. The known-spectrum [Yang--Chiribella--Hayashi
compression](https://arxiv.org/abs/1606.02893) does not transfer its stated
precision estimate to a gap of order n^-1/2. The 2026 [quantum minimum
description theorem](https://arxiv.org/abs/2610.06742) fixes distinct positive
eigenvalues and explicitly lacks uniformity as gaps close. No novelty claim is
made for this conditional synthesis.

THE ACQUIRED INTERFACE

Input: a disjoint union of J loopless components, component j having b_j
qubits, rational nonnegative beta, and rational Hamiltonian
 H_j = sum_edges alpha(XX+YY)+gamma ZZ + sum_vertices b X+c Z,
 alpha>=|gamma|, b>=0. No term connects two components. The physical Gibbs
state for energy -H is rho=exp(beta H)/Tr exp(beta H), H=sum_j H_j.
The observable is a rational sum of r I/X/Z Pauli strings on ALL n=sum b_j
qubits, with sum_k |c_k|<=1. It has norm <=1 and row sparsity at most r;
it need not be local. The restriction to real Pauli strings is an explicit
implemented subset of INITIAL's general sparse Hermitian interface.

Errors epsilon and epsilon_s lie in (0,1]. The probabilistic theorem assumes
independent unbiased random bits. The default execution uses SystemRandom;
a seeded pseudorandom replay is labeled diagnostic and is not proof of this
randomness assumption. No stochastic stopping time or rejection is used.

The shipped machine caps are at most 32 components of width 4, 512 layers
per component, 32 observable terms, 100,000 samples, 256-bit input rationals,
32,768-bit matrix operands and 262,144-bit global ratio operands. The code
rejects input/admission/cost violations; rejected cases are not completed
samplers. Its conservative preflight rejects a power before its operand
height could exceed the cap. This is a finite-cost executable subclass.
The mathematical algorithm extends to any explicitly charged finite b_j.
It is exponential in component width. It is not a general many-body FPRAS.

The component decomposition is supplied in the concrete input. Verifying
an edge list has no cross-component edge and finding connected components
are ordinary graph operations if instead supplied as one global graph.
Acquisition of a physical Hamiltonian from experiment is outside this input.

1. EXACT ACQUISITION OF A SINGLE POSITIVE RATIONAL STATE

Let C_j=3 sum alpha+sum(b+|c|), D_j=2C_j, tau_j=beta D_j, and use the same
positive shifts as the shared baseline:
 A_e=3alpha I+alpha(XX+YY)+gamma ZZ,
 A_v=(b+|c|)I+bX+cZ.
Each A_i is PSD with nonnegative computational-basis entries, and
sum_i||A_i||<=D_j. Put
 kappa=min(epsilon_s/2,epsilon/100), delta=min(epsilon_s/2,epsilon^2/1000),
 kappa_j=kappa/J, delta_j=delta/J,
 m_j=max{1,ceil(2tau_j),ceil sqrt(43 tau_j^3/(60 kappa_j))},
 h_j=beta/(2m_j), F_i=I+h_j A_i+(h_j A_i)^2/2,
 W_j=product_i F_i in the declared order, B_j=W_j W_j^T, K_j=B_j^(m_j).

All choices, including ceil sqrt, use rational/integer comparisons. For
x=a/d>=0, floor sqrt(x)=isqrt(a//d); adding one exactly when k^2 d<a gives
the ceiling. No float selects m, accuracy, a probability, or a gate entry.

The P2 local admission and uniform second-order generator bound come from
c06_l08's independently frozen construction (overlapping c06_l03 as reported
in the reviewed attribution). They were re-derived in CROSS_REVIEW.txt:
 ||m_j log B_j-beta(H_j+C_j I)|| <= k_j,
 k_j=43 tau_j^3/(60 m_j^2)<=kappa_j.
The proof uses monotone local eigenvalues, an explicit second-degree
palindrome cancellation, positive Taylor tails, and resolvent-log Lipschitz
continuity. This bound does not import Chen--Liu or rely on finite numerics.
The local log-concavity admission would enable that separate counting route,
but the executable instead acquires counts by bounded dense matrices.

Exact integer compilation: choose a common denominator d_i for each F_i and
store M_i=d_i F_i, an integer matrix. If M_W=product M_i and d_W=product d_i,
then M_B=M_W M_W^T and
 K_j=M_K/d_W^(2m_j), M_K=M_B^(m_j).
Matrix powers use binary exponentiation. Common denominators cancel from
all diagonal probabilities and all entry ratios. The acquired integer
matrix is symmetric, entrywise nonnegative and positive definite. In fact
each F_i>=I; its smallest singular value is >=1, and products inherit that
lower singular bound. Consequently B_j>=I and K_j>=I. Every diagonal count
is positive even when off-diagonal support vanishes. beta=0 and C_j=0 are
handled by identity matrices. Both fields and nonbipartite triangle edges
are present in the executed instance.

Define sigma_j=K_j/Tr K_j and sigma=tensor_j sigma_j. The same K_j supplies
every sampler count, global observable ratio and exact reference moment.
There is no estimator using a matrix different from the sampling matrix.

2. A SAFE GIBBS PERTURBATION BOUND, INCLUDING NONCOMMUTING GENERATORS

For Hermitian A,E in finite dimension and rho_t=exp(A+tE)/Tr exp(A+tE),
Duhamel differentiation gives
 rho_t'=integral_0^1 rho_t^(1-s) E rho_t^s ds-rho_t Tr(rho_t E).
Schatten Holder with exponents 1/(1-s), infinity, 1/s bounds the first
integrand in trace norm by ||E||op; endpoints follow by continuity.
The second term has trace norm at most ||E||op. Therefore
 ||rho_1-rho_0||_1<=2||E||op.
Scalar identity shifts cancel under normalization. Applied to each component
and tensorized by a telescoping sum,
 ||rho-sigma||_1<=2 sum k_j<=2kappa.
Thus computational-basis measurement TV is <=sum k_j, and the bias for any
norm-one observable is <=2sum k_j. No asserted sharper tanh bound is needed.
This proof charges a factor of two that cannot be silently omitted when
converting a measurement-TV budget into an arbitrary observable budget.

3. FIXED-BIT SAMPLER WITH AN EXACT KNOWN DISTRIBUTION

For one component let d=2^b and pi_i=(M_K)ii/Tr M_K. Choose
 q=ceil log2((d-1)/delta_j), truncated below at zero, M=2^q.
Let C_i=sum_{a<=i} pi_a and thresholds t_i=ceil(M C_i), with t_last=M.
Draw a q-bit uniform integer U in {0,...,M-1} and return the first i with
U<t_i. Equal thresholds simply skip zero-probability bins. The code uses
bisect_right. There is no rejection, Bernoulli loop or rare-prefix division.
Its EXACT implemented law is mu_i=(t_i-t_{i-1})/M.

Write e_i=t_i/M-C_i, e_last=0, e_before_first=0. Then
 mu_i-pi_i=e_i-e_{i-1}, 0<=e_i<1/M for internal boundaries. Hence
 TV(mu,pi)=sum_i|e_i-e_{i-1}|/2 <=sum_internal e_i <=(d-1)/M<=delta_j.
Equivalently, couple a continuous uniform number with its left grid point;
they differ only in cells containing a CDF boundary. The program computes
the actual TV exactly as a rational and checks it against this uniform bound.
Sampling components independently gives product mu with
 TV(mu,diag sigma)<=sum delta_j<=delta.
Therefore each returned n-bit string has
 TV(mu,diag rho)<=sum k_j+sum (2^b_j-1)/2^q_j <=epsilon_s.

Each complete n-bit sample uses EXACTLY sum_j q_j fair bits. Generating
M_obs samples consumes M_obs sum q_j bits on every execution. Counts are
acquired once, not estimated afresh on an exponentially rare prefix.

4. GLOBAL SPARSE OBSERVABLE RATIO AND VARIANCE

For any PSD trace-one sigma and Hermitian ||O||<=1, put p_b=sigma_bb and
 g_b=(O sigma)bb/p_b, defining arbitrary g_b=0 when p_b=0. PSD
Cauchy--Schwarz gives
 |(O sigma)bb|^2 <=p_b (O sigma O*)bb.
Consequently E_p g=Tr(O sigma) and E_p |g|^2<=Tr(O sigma O*)<=1.
Here every p_b>0. For the implemented real Pauli sum, g_b is real.

If P_k is a Pauli string, its computational-basis row has one nonzero sign.
On component j, let its X mask be x_kj and Z mask z_kj. For local b_j,
 r_kj(b_j)=(-1)^popcount(b_j & z_kj)
                  (M_Kj)[b_j xor x_kj,b_j]/(M_Kj)[b_j,b_j].
Then g_b=sum_k c_k product_j r_kj(b_j), computed from acquired component
matrices without constructing a 2^n global matrix. Pauli operators on
disjoint components have product matrix entries, so this identity is exact.
The variance bound is independent of small p_b or the magnitude of g_b.
Exact first/second moments in the run are also obtained from component sums,
using respectively r and r^2 cross terms, in O(r^2 sum 2^b_j) local queries.
They are diagnostics/references for this actual matrix, not a substitute for
the uniform PSD proof. The global observable contains X on all 48 qubits
and Z on all 48 qubits in the run.

5. CERTIFIED FINITE-PRECISION LOCAL RATIO TABLES

Repeated exact global rational ratios were a measured bottleneck. The
optimized implementation acquires a fixed dyadic local table once.
For each term k put M_kj=max{1,max_b |r_kj(b)|}, U_k=product_j M_kj,
and U_weighted=sum_k |c_k| U_k. All maxima are exact rational computations
over already acquired bounded component matrices. This does not assume
that any diagonal mass is lower bounded by an inverse polynomial.

Let zeta=epsilon/4000 and choose Q so
 2^Q >= max{J,3J U_weighted/zeta}.
Replace each local r by floor(2^Q r)/2^Q, with error at most a=2^-Q.
For a product of J local values, telescoping gives absolute error at most
 J a U_k (1+a)^(J-1) <=3J a U_k,
because J a<=1 and (1+a)^J<=e<3. After weighting and summing terms,
  sup_b |g_hat_b-g_b| <=3J a U_weighted<=zeta.
The program records this exact rational bound and fixed operand schedule.
Large ratios raise Q through log U; that precision and operand size are
charged. It never mistakes a small exact denominator for a numerical zero.
Products of stored dyadic numerators have common denominator 2^(QJ), so
per-sample global queries avoid the acquired matrices' much longer exact
denominators. Masks with no flips have exact +/-1 local values.

6. CLIPPING, OUTPUT ROUNDING AND COMPLETE ADDITIVE GUARANTEE

Set T=10/epsilon. Clip g_hat to [-T,T], then round to the nearest dyadic
with 2^q_out>=4000/epsilon. This output rounding has error at most
epsilon/8000. Clipping is 1-Lipschitz, so the total uniform numerical error
relative to clip(g) is at most zeta+epsilon/8000<epsilon/1000.

The clipping bias under p is at most E_p g^2/T<=epsilon/10. Changing p to
mu changes the mean of a [-T,T] variable by at most 2Tdelta<=epsilon/50.
The Gibbs generator bias is <=2kappa<=epsilon/50. Numerical error adds
at most epsilon/1000. Combined expectation bias is <=.141epsilon<epsilon/5.

Under mu, E clip(g)^2<=1+T^2delta<=11/10; squared clipping lies in [0,T^2],
so the TV conversion uses T^2delta rather than 2T^2delta. If the numerical
error is at most z<=epsilon/1000<=.001, the rounded variable Y has
 E_mu Y^2 <=11/10+2z sqrt(11/10)+z^2<6/5.
Draw M_obs=ceil(256/epsilon^2) independent complete samples, sum the dyadic
integers, and divide once. Chebyshev gives
 Pr[|sample_mean-E_mu Y|>=epsilon/2]
       <=(6/5)/(M_obs epsilon^2/4)<=3/160.
On the complement, absolute error from Tr(O rho) is less than .7epsilon,
and hence <=epsilon. Projecting the final estimate to [-1,1] cannot increase
its error, since Tr(O rho) belongs to that interval. This is a completed
98.125%-success additive estimator; it does not claim a relative estimate
when the expectation is tiny. Independent repeated runs and a median give
the usual confidence amplification, but arbitrary-confidence scheduling is
not supplied as a separate CLI feature in this version.

The long-integer sum is avoided: each sample is quantized before summation,
so its accumulator has O(log M_obs+q_out+log T) bits. The source-code fixed
random tape, acquired integer matrices, local dyadic precision, state queries,
clipping and output rounding are all part of the algorithm and cost record.

7. CHARGED COST AND THE IMPLEMENTED BOUNDARY

Write d_j=2^b_j, p_j for the local term count, ell_j for the rational local
gate bit height including beta, m_j, and input bits, and
 A_j=O(m_j p_j(ell_j+log d_j)) for the acquired integer height.
Embedding local two/four-dimensional gates costs O(p_j d_j) nonzero local
entries plus O(p_j d_j^2) initialization of the allocated zero matrices.
Exact integer dense acquisition costs
 O(sum_j d_j^3(p_j+log m_j)) integer products/additions,
on operands of height O(A_j), plus polynomial common-denominator work.
Bit cost must multiply those counts by the chosen big-integer arithmetic
cost at A_j; measured Python wall times and maximum heights are reported.
Storage is O(sum_j d_j^2 A_j) bits for the component matrices, plus their
scalar denominators. No global 4^n matrix is built or silently supplied.

The local ratio table preprocessing uses O(r sum_j d_j) exact divisions
with acquired operand heights; its uniform maximum budget uses products
with O(sum A_j) bits. Q=O(log(J/epsilon)+log U_weighted) and thus Q is
polynomial in acquired bit length even if a mass is exponentially small.
The dyadic product operands have O(JQ+sum_j log M_kj) bits. The executed
cap checks these heights. Each sample uses O(sum_j log d_j) CDF comparisons
on fixed q_j-bit thresholds and O(rJ) dyadic integer products plus rational
coefficient/rounding work. Exact reference moments cost O(r^2 sum_j d_j)
local rational operations. Their intermediate heights can be
O(sum_j d_j A_j), because weighted local sums have different exact diagonal
denominators; they are not restricted by the per-sample ratio cap. They are
auxiliary diagnostics rather than required sampler queries. Their full wall
time and final maximum rational height are reported separately and included
in preprocessing, rather than hidden inside the dense matrix timing. The
operative algorithm needs only matrix acquisition, CDFs and the certified
finite-ratio table compiler.

For fixed bounded b_j and polynomial numerical beta C_j and epsilon^-1,
this is polynomial in J and the explicit input sizes. It is NOT uniformly
polynomial in binary log(beta C_j); the layer count depends on the numerical
temperature-energy product. Caps enforce the actual admitted machine regime.
The algorithm's disconnected bounded-component factorization is standard
and readily solvable by conventional dense methods. It does not claim a
new interacting-hard regime, priority, general quantum advantage loss,
global density-matrix output or a physical Gibbs preparation circuit.

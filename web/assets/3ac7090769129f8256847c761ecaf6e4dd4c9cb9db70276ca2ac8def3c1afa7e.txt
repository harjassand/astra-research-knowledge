ROBUST MONOGAMY FOR NONCOMMUTING REFERENCES AND WEIGHTED PAIR COVERS
c04_s02, independent post-INITIAL derivation. General target still unresolved.

Let sigma be ANY faithful finite-dimensional density, and G_i Hermitian
involutions with Tr(sigma G_i)=0. For fixed 0<a<=1/2 define
 rho_(i,+/-)=sqrt(sigma)(I+/-aG_i)sqrt(sigma).
These are actual normalized fixed-sandwich states. The reference need not
commute with G_i. Let p_i>=0 sum p_i=1, and let alpha_ij>=0 on unordered pairs
have incident sums sum_(j!=i)alpha_ij=p_i. Thus sum alpha=1/2.
Put
 q_i=Tr[sqrt(sigma)G_i sqrt(sigma)G_i]
    =1-(1/2)||[sqrt(sigma),G_i]||_HS^2,
 Q=sum_i p_i q_i,
 epsilon_ij=sqrt(Tr[sigma {G_i,G_j}^2]),
 E=2sum_(i<j)alpha_ij epsilon_ij.
Then every actual full-domain broadcaster has worst marginal half-trace error

 b >= (a/4) max{0, 2Q-sqrt(2+E)}.                         (R1)

No receiver-flag restriction, unitality, output symmetry, independent-copy
assumption or fixed number of labels is used. All reference/observable/input
dimensions can grow. A normalized-trace L2 anticommutator defect suffices;
operator-norm approximate anticommutation is not required.

PROOF OF THE ROBUST TWO-SETTING SOS

For input involutions G_1,G_2 and receiver involutions B_1,B_2,C_1,C_2, where
every B commutes with every C, put
 P=(G_1G_2+G_2G_1)/2, F=i(G_1G_2-G_2G_1)/2,
 R=B_1-C_1, S=B_2-C_2,
 K=G_1(B_1+C_1)+G_2(B_2+C_2), M=R+iF S.
P,F are Hermitian, commute, and F^2=I-P^2. Direct expansion gives

 K^2+M* M =8I-P^2 S^2+P Z,
 Z={B_1,B_2}+{C_1,C_2}+2B_1 C_2+2B_2 C_1.                 (R2)

Input factors commute with all receiver factors. The negative term is PSD
with a minus sign, and ||Z||<=8. For any tripartite density omega whose input
marginal is sigma (transpose can be incorporated), Cauchy--Schwarz gives

 <K>_omega^2 <=<K^2>_omega
 <=8+8sqrt(Tr sigma P^2)=8+4epsilon_12.

Hence <K>_omega <=2sqrt(2+epsilon_12). This is an expectation bound with the
specified input marginal, not an operator-norm bound from an L2 defect.
It reduces to the baseline exact Clifford SOS when epsilon=0.

WEIGHTED CHOI TRANSFER

For arbitrary B, let J_B be its unnormalized Choi operator and let
 omega=(sqrt(sigma)^T tensor I) J_B (sqrt(sigma)^T tensor I).
It is a density operator with input marginal sigma^T. For either receiver t,

 Tr[omega G_i^T G_i^(t)]
   =Tr[G_i B_t(sqrt(sigma)G_i sqrt(sigma))].

Testing the trace errors on plus/minus states by norm-one G_i, then subtracting,
bounds this score below by q_i-2b/a. Therefore the weighted two-receiver
witness W=sum p_i G_i^T(G_i^B+G_i^C) has expectation >=2Q-4b/a.
Since W=sum alpha_ij K_ij, the robust pair bound and Jensen, with weights
2alpha_ij summing to one, give

 <W> <=sum alpha_ij 2sqrt(2+epsilon_ij) <=sqrt(2+E).

Rearranging proves (R1). All Choi normalizations and sigma transposes are
retained. The target score q_i accounts explicitly for noncommutation of the
reference; it cannot be set to one without justification.

CONSEQUENCE / FAILED NEGATIVE ROUTE

If a growing near-Clifford family has E_n->0 and Q_n->1, its actual b2 has
liminf >=a(2-sqrt2)/4=a(1-1/sqrt2)/2. Small pair-affinity or pair-commutator
criteria alone are still insufficient. This result blocks approximate
anticommuting frames with small reference commutators, including weighted
fractional pair covers not organized into exact equal cliques.
It does NOT exclude families with substantial noncommuting-reference defect,
without a positive weighted pair cover, or with no anticommutator control.
In particular it is not a universal collective joint-variance theorem.

PRIORITY / COSTS

The exact two-setting monogamy mechanism is established Toner--Verstraete
prior art, https://arxiv.org/abs/quant-ph/0611001, and was already rederived
in the baseline work/cycle3/large_clique_broadcast.txt. The displayed robust
weighted reference extension is an internal application/derivation, not a new
fundamental monogamy principle or externally validated novelty claim.
Proof uses finite matrices and weighted Choi identities, without constructing
the full growing Choi matrix. Checking q_i and epsilon_ij from explicit input
matrices requires charged matrix products/trace evaluations; acquiring sigma,
G_i and the fractional graph is not assumed costless.

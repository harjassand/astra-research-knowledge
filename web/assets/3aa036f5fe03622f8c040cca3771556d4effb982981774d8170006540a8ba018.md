# Ordered binary matrix removal: tree propagation, sampling, and repair gap

## Verdict

I reconstructed OpenAI release family 190 from its PDF at the pinned commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`. It gives a concrete obstruction in ordered combinatorics outside the matching, CSS, sparse noncommutative acquisition, selective-output, metric-representation, stable-determinant, and nonsofic branches: one fixed binary `66 x 66` pattern has no polynomial removal rate.

The main useful consequence is a precise testing boundary. A canonical tester that samples a uniformly random set of `q` rows and, independently, `q` columns, then rejects only on an induced ordered copy, needs `q = exp(Ω(ε^{-1/2}))` along an explicit sequence of inputs. This does **not** lower-bound arbitrary adaptive or noncanonical property testers. A second derived consequence is a large gap between covering all copies already present and repairing the matrix: a set of `2^h` edits can destroy every old copy, while every fully `H`-free repair needs at least `4^h` edits; the small edit set creates new copies.

The release theorem is source-reported and remains externally unvalidated here. I independently reconstructed its parameters and proof mechanism, checked the cited prior-art boundary, and ran a finite construction check for `h=1,2`. That check validates two concrete copies and the copy-creation example only; it does not prove the all-`h` theorem or the universal location of every copy.

## Exact interface and statement

Fix a binary `k x k` matrix `H`. An ordered copy in a binary `n x n` host `A` is specified by strictly increasing rows `r_1<...<r_k` and columns `c_1<...<c_k`, with `A(r_i,c_j)=H(i,j)` for every pair. Zeros and ones must both match. The distance is the minimum number of cell changes, in either direction, needed to make `A` `H`-free, divided by `n^2`.

For every integer `h >= 1`, the release sets

`m = 2^h`, `d_h = 386h + 2`, `n_h = d_h m`, and `ε_h = d_h^{-2}`.

It constructs one fixed binary `66 x 66` pattern `H` and a binary host `A_h` of order `n_h` such that

`dist_H(A_h) >= ε_h`

and

`N_H(A_h) / n_h^132 <= ε_h 2^{-h}`.

Here `N_H(A_h)` counts ordered copies. If a polynomial removal theorem held with constants `c,C>0`, the ratio of this copy density to `ε_h^C` would be at most `(386h+2)^(2C-2) 2^{-h}`, which tends to zero. Thus no fixed positive `c,C` work for this `H`.

## Reconstructed mechanism

The pattern consists of a `64 x 64` anchor `S` and a final `2 x 2` body

`P = [[1,0],[1,1]]`.

The anchor’s last five columns, restricted to 32 selected rows, list all 32 binary words of length five. The host places copies of this anchor in groups indexed by six ordered modes at each of `h` levels. Its remaining row and column positions form signed blocks on a binary tree, plus dummy blocks. At each leaf, the plus and minus block names refer to the same physical position. The host’s entries are fixed by the anchor groups, the mode-specific role vectors, and four threshold rules comparing tree indices and parent indices.

For the distance bound, choose one root-to-leaf path and one position from every relevant size-`m` class on each axis, together with anchor and dummy representatives. Every protected cell needed for the argument is selected with probability exactly `m^{-2}`. If fewer than `m^2` cells were changed, a union bound leaves positive probability that none of the selected protected cells changed. For such a selection, the root has a plus entry equal to 1 and a minus entry equal to 0. Avoiding `P` in the designated `V` modes forces these values to propagate through the row levels; avoiding `P` in the `W` modes propagates them through the column levels. The two signs meet at the shared leaf cell, which cannot simultaneously be 1 and 0. Therefore every `H`-free repair changes at least `m^2` cells.

For the copy bound, the anchor rigidity argument first forces every copy of `S` into the 64 row and column anchor groups of one mode. Its two remaining rows and columns must be that mode’s body roles. The four mode types are then checked against the inequalities encoded by the tree order. Three types cannot realize `P`; the fourth can do so only at the terminal level and only when the two leaf indices agree. Hence every copy maps the body entry `(65,65)` into

`L_h = union_{p=0}^{m-1} R_h^+(p) x C_h^+(p)`,

which contains exactly `m` diagonal leaf cells. Fixing that body row and column leaves at most `n_h^65` choices for each of the other 65 rows and columns, so

`N_H(A_h) <= m n_h^130`.

After division by `n_h^132`, this is `m/n_h^2 = ε_h 2^{-h}`.

## Consequences and scope

For the canonical row/column sampler, each cell in `L_h` enters the independently sampled `q`-row by `q`-column submatrix with probability `(q/n_h)^2`. A rejection requires the sample to meet `L_h`, so

`Pr[reject on A_h] <= m(q/n_h)^2 = ε_h 2^{-h} q^2`.

For fixed rejection probability `ρ>0`, this forces

`q >= sqrt(ρ) ε_h^{-1/2} 2^{h/2}`

per axis. Since `h = (ε_h^{-1/2}-2)/386`, the required sample size is `exp(Ω(ε_h^{-1/2}))`. The source’s sampling corollary assumes the tester rejects only after its sampled induced submatrix contains `H`; it makes no claim about arbitrary adaptive cell-query algorithms. If the whole sampled submatrix is read, it contains `q^2` cells and the total cell count is also exponential in `ε_h^{-1/2}`.

The set `L_h` hits every copy already present, and changing its `m=2^h` entries from 1 to 0 destroys all those copies. It does not repair the matrix: a `W+` leaf configuration uses the changed diagonal entry as the required zero and becomes a new copy. At the same time, the distance argument says every `H`-free repair needs at least `m^2=4^h` changes. Thus the ratio between this explicit old-copy hitting set and the minimum full repair size is at least `m=2^h = 2^{(ε_h^{-1/2}-2)/386}`. This is a concrete obstruction to treating a set that hits the current induced copies as a repair certificate when both 0-to-1 and 1-to-0 edits are allowed.

The witness itself is explicit but large. It has `n_h=(386h+2)2^h` rows and columns, so a dense one-bit-per-cell representation occupies `n_h^2` bits; direct materialization costs `Θ(n_h^2)` cell writes. As `ε_h` decreases, the witnesses grow exponentially in `ε_h^{-1/2}`. The theorem concerns the dependence of copy density on distance, not an efficient construction algorithm or a lower bound for every testing model.

## Prior art and novelty boundary

Alon, Ben-Eliezer, and Fischer already established qualitative removal and strong testability for hereditary ordered matrix properties: for each fixed positive distance there is a positive copy-density bound, but it need not be polynomially related to the distance. Alon and Ben-Eliezer established polynomial bounds for important restricted settings, including families closed under row permutations or column permutations, and polynomial weak-removal/hitting-set results for many pairwise entry-disjoint copies. The fixed, order-sensitive singleton pattern here does not lie in those symmetry-closed settings. The release explicitly highlights the distinction between hitting the old copies and editing to a copy-free host.

Fischer and Rozenberg had earlier shown nonpolynomial testing lower bounds for related induced-substructure problems with ternary host alphabets. The reconstructed result’s boundary is the binary host alphabet with both row and column orders retained. The release identifies the conjecture as the singleton ordered-binary-matrix conjecture in Gishboliner–Shapira’s 2025 survey and as a negative answer to the finite-family question of Alon–Ben-Eliezer.

The ordered-removal theorem, canonical-sampler corollary, and copy-hitting/repair contrast are already stated in the pinned release. This report does not claim priority or a new theorem beyond that source. Its contribution is a compact reconstruction of the tree-propagation mechanism, explicit parameter algebra, a precise limitation on the sampling consequence, and a finite check of the repair counterexample.

## Bounded check and remaining gate

`check_leaf_repair.py` builds the literal binary pattern and host for `h=1,2`, then verifies an original `W-` copy, confirms zeroing every leaf-diagonal cell breaks that chosen copy, and confirms the same edit creates a `W+` copy. It reports `n=776,m=2,ε=1/150544` for `h=1` and `n=3096,m=4,ε=1/599076` for `h=2`. Results are in `CHECK_RESULTS.json`. This finite check catches indexing or sign errors in the explicit adversarial edit; it does not enumerate all copies or all edits.

The next decisive review is an independent proof audit of anchor rigidity (the source’s Lemmas 4.1–4.4), the four mode exclusions in Proposition 4.6, and the protected-cell sampling argument in Proposition 3.1. A counterexample would be either an `H`-free repair changing fewer than `m^2` cells or an ordered copy whose `(65,65)` image lies outside `L_h`. No such counterexample was found in the source reconstruction or finite checks. External specialist review and priority remain unresolved.

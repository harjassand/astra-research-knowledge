POLYNOMIAL HIDDEN-STATE LEAF: UNKNOWN DETERMINISTIC EMBEDDED TRANSITIONS
2026-10-08 | internal corollary; external validity/priority UNKNOWN

Fix a supplied hidden state bound q. The raw input is one binary event-time
path. Hidden state i chooses an arbitrary positive integer gap from mu_i,
and its next hidden state is T(i), for one UNKNOWN deterministic map on at
most q states. Use any stationary version with finite embedded-pi weighted
gap mean; there is no uniform mean, mixing, support or positivity bound.
The event marks/states and T are not supplied. Self-transitions are allowed,
and events are recorded even when the hidden state does not change.

This is the full deterministic-transition subclass of the hidden model, not
the arbitrary joint p_i(g,d) class. Destination randomness beyond a fixed T
is outside this corollary. It gives a different proper code whose exact
compiler is efficient; it does not contradict the #P hardness of projecting
the unrestricted all-pool q=2 code.

1. Canonical cycle codes
------------------------
For each ell=1,...,q, let states be residues modulo ell and use only the
directed cycle i->i+1. Counts C_{i,g} for positive lengths g have total span
S=sum g C_{i,g}<=N-1, and row totals R_i=sum_g C_{i,g}. There are
K_{ell,N}=1+sum_{s<N}p_ell(s) options: every ell-colored pool plus a separate
allzero option. Choose an option uniformly; for a pool choose anchor uniform
in [N-S] and start phase uniform in [ell]. Draw gap lengths from the current
row without replacement, advancing phase by one each time; stop on empty
current row even if other rows retain resources. Emit the observed binary 1
at every event. This Q_{N,ell} is a proper full-support binary law by the
same span/termination proof as the general row-urn code.

For a binary prefix with r complete observed gaps and an event, a starting
phase determines the entire hidden phase sequence. There are only ell
possibilities. For each phase calculate its c_{i,g}, outgoing row uses and
last phase, then apply the exact marked product-weight DP, now with only
ell(N-1) local coordinates and ell row-total statistics. Sum the ell
marked-prefix masses. No unknown-state branching is enumerated. Before any
event use the ordinary no-event anchor formula with p_ell(s), which is
already independent of the start phase.

Consequently exact prefix evaluation is polynomial in N for every fixed ell,
with conservative O_ell(N^{ell+5}log²(N+1)) bit time and polynomial memory.
This bound includes all unseen pool gap lengths and has no true-law support
promise. The source need not be identified or its hidden phases inferred.

2. Unknown period and arbitrary stationary cycles
------------------------------------------------
Take the proper horizon-fixed mixture

  R_N=(1/q)sum_{ell=1}^q Q_{N,ell}.

Every stationary distribution of a finite deterministic map is supported on
its recurrent cycles; transient states have zero embedded mass. Its stationary
time law is a mixture of cycle laws, with calendar-time cycle weights. Each
component of cycle length ell<=q is a canonical ell-cycle law after relabeling
the hidden phases; their state-dependent gap laws remain arbitrary. For each
component the exact count pool and row multinomial bound give

  P_component(x)<=ell K_{ell,N} N Q_{N,ell}(x).

Since K_{ell,N}<=K_{q,N}, group mixture weights by cycle length as alpha_ell,
with sum alpha_ell=1. Even when several cycles have the same length and
different gap laws, their entire mixture is bounded by the SAME universal
Q_{N,ell}. Thus

  P_N(x)<=q K_{q,N} N sum_ell alpha_ell Q_{N,ell}(x)
         <=q² K_{q,N} N R_N(x).

No stationary mixture over a continuum of DIFFERENT transition/gap kernels
is inserted into the memory claim. The source here is one finite deterministic
kernel whose recurrent cycles are its actual finite hidden states. The optional
allzero absorbing atom can be handled as before.

The colored-partition bound gives logK_{q,N}<=log2+2sqrt(2qN). Thus

  D(P_N||R_N)<=log2+2sqrt(2qN)+2log q+log N.

The true countdown/next-state still has its exact qN+1 initial cap, so the
memory sum is at most log(qN+1), independently of every gap mean and tail.
Use ONE horizon N=n+1, form each conditional of R_N on the observed suffix,
and average as in the banked theorem. Uniform expected terminal KL risk is
at most

  [log2+2sqrt(2q(n+1))+2log q+log(n+1)+log(q(n+1)+1)]/n.

For fixed q this is O(n^{-1/2}), with exact polynomial bit time. The class
contains binary renewal as ell=1, so HJW's lower bound gives the matching
order for every fixed q. There is no sharp uniform-q lower constant claim.

3. Integer scale and end-to-end charged cost
------------------------------------------
Each cyclic marked prefix has scale ell K_{ell,N} N! and an integer numerator;
summing its ell phases preserves that scale. Set

  D_N=q N! product_{ell=1}^q(ell K_{ell,N}).

Then D_N R_N(prefix) is integer: sum the ell-th code numerator multiplied
by product_{j!=ell}(j K_{j,N}). For fixed q the scale has O_q(N log N) bits;
no products of exponentially long paths or unbounded denominators are hidden.
All suffix conditionals are ratios of these integer weights. Exact averaging
can have O_q(n² log n) output bits and remains polynomial. At most O_q(n)
prefix evaluations are needed, so a conservative total bit time is
O_q(n^{q+6}log²(n+2)); no claim of practical optimization is made.

4. Why the deterministic restriction is load-bearing
----------------------------------------------------
Given initial phase, all later hidden states are fixed. This bounds the hidden
assignment sum by sum_{ell<=q}ell, rather than q^{number_of_events}. Allowing
arbitrary destination randomness destroys this bounded enumeration. A common
template that treats all hidden models as ordinary renewal is also invalid:
deterministically alternating gap laws concentrated at 1 and 2 produce a
constant-probability alternating gap word, while an iid gap type code pays
linear multinomial-order regret. The present cycle code retains that order.

Known q and deterministic embedded transitions are real supplied CLASS
promises; no destination map, starting phase or gap probability oracle is
supplied. The result applies to calendar-time terminal continuation, not a
fresh independent gap sample, a reset experiment, a high-probability model
certificate or a frozen phase estimator. Novelty remains UNKNOWN.

This corollary is an explicit alternative efficient code and a positive leaf.
It leaves the arbitrary branching hidden-prefix FPRAS and generic optimal
polynomial-time hidden-state prediction problem unresolved.

5. Independent finite diagnostic
--------------------------------
periodic_check.py is self-contained and uses exact integers/Fraction. It
enumerates all cyclic pools, anchors, phases and row draws into full binary
laws, independently compiles every prefix by the phase/product-weight DP,
then forms the unknown-period mixture. For N=1..6 and q=1..3 it passed
738 prefix equalities, 360 normalizations and 1,008 pointwise stationary
regret checks. Fixtures include alternating gaps, varying cycle gap laws,
two distinct recurrent cycles of one three-state map, gaps of length200 and
transient unused states. PERIODIC_CHECKS.json records the finite scope.
This is internal exact evidence, not external validation or a priority claim.

# Replay theorem for deterministic known-state plants

## Contract

Plant: `xdot = A x + B u`, `x(0)=x0`; `A`, `B`, and `x0` are known to the controller. There is no process noise, unmeasured disturbance, parameter drift, or unknown initial condition. A passive sensor, when on, reports `y=Cx`. The actuator can be commanded independently of the sensor. A causal policy may use its observation history to choose sensor state `z(t) in {0,1}` and actuator input `u(t)`. Cost is

`J = integral_0^infinity [x'Qx + u'Ru + s z] dt`, with `Q >= 0`, `R > 0`, `s > 0`.

## Claim

For every admissible finite-cost policy `pi=(z,u)`, a sensor-off policy `pi0` exists with exactly the same `x(t)` and `u(t)` and

`J(pi0) = J(pi) - s integral_0^infinity z(t) dt`.

If the sensing duration is positive, the inequality is strict. The infimum over the broad class with independently available actuation equals the infimum over the zero-sensor subclass.

## Proof

Run a software replica of the original controller and plant in the controller. Initialize `xhat(0)=x0`. At each instant, integrate `xdot_hat=A xhat+B u`, and pass `C xhat` as a virtual observation whenever the original policy requests a measurement. Assume first the original controller is deterministic. By uniqueness of the linear ODE, if `xhat(t)=x(t)` and both use the same past controls, then they remain equal until the next control update. The virtual output therefore equals the physical sensor output. The original controller's next sensor and actuator decisions are reproduced exactly. Induction over update times gives equal action and state trajectories. The software replica uses no physical sensing, so only the `s z` integral is removed.

For a randomized controller, couple the sensor-off replica to the same private random seed; the pathwise argument is unchanged. A sensor schedule that depends on the state is reproducible because the controller computes the exact state trajectory under the known model and its chosen inputs.

## Boundary

If hardware enforces `z=0 => u=0`, the same physical actuation path cannot be replayed while the sensor is off. This is a coupled sensor/actuator gate and a different interface. The theorem also fails to establish dominance when the state has process noise, unknown initial state, unknown parameters, unmodeled inputs, measurement-dependent physical effects, or nonzero prediction/computation cost.

## Numeric reproduction of the 2026 fixed-gain example

For the paper's scalar family use `a=-1`, `b=1`, `k=0.5`, `q1=1`, `r=1`, `q2=r k^2=0.25`, `s=0.1`, `x0=1`. The hypotheses `a<0`, `a-bk<0`, and `q1*b*k+q2*a>0` hold. The switching ratio is

`rho = -a*s / ((q1*b*k+q2*a)*x0^2) = 0.1/0.25 = 0.4`.

Thus `tsw = ln(rho)/(2(a-bk)) = ln(0.4)/(-3) = 0.30543024396`. The on-interval state is `x=e^(-1.5t)` and `e^(-3 tsw)=0.4`. The state and actuator cost during sensing is `(1+0.25)(1-0.4)/3=0.25`. After sensing shuts off, the open-loop state cost is `x(tsw)^2/2=0.4/2=0.2`. Sensing cost is `s tsw=0.0305430244`. Total: `0.4805430244`.

An independently addressable sensor-off controller can replay the same input path at total cost `0.45`; the actuator-energy component remains `0.25`. The full-information LQR controller for `xdot=-x+u`, `q=r=1`, `x0=1` solves `-2P-P^2+1=0`, giving `P=sqrt(2)-1`, `u=-P x`, `x=e^(-sqrt(2)t)`, and total cost `sqrt(2)-1=0.4142135624`. Its sensing cost is zero, actuator cost is `(3 sqrt(2)/4)-1=0.0606601718`, and state cost is `sqrt(2)/4=0.3535533906`.

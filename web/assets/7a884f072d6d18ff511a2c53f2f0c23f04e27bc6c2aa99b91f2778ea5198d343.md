# Exact acquisition and the retention boundary for finite-state prediction

Date: 2026-10-08  
Status: internally proved for the deterministic finite-state panel theorem; no universal strict advantage over a competent retainer. See STATUS.txt.

## Result

There is a fully explicit, legal raw-trajectory procedure that learns an unknown deterministic Mealy predictor with at most n states, compresses its observed behavior into an exact finite transition/output table, and predicts every future word correctly when the dynamics are stationary. It uses a finite but very large reset panel and a finite exhaustive search. The setup query, validation, transcript, search, precision, peak-memory, model-storage, and later prediction costs are listed below.

The positive amortization statement is conditional on a restricted comparator that independently reacquires or refits on every task. If one fit costs F and K stationary tasks each have the same acquisition interface, reuse saves exactly (K−1)F in setup resources. With drift loss charged at rate α_L, the sharp scalar frontier is (K−1)F > α_L L, with the memory and inference terms shown explicitly in the ledger.

There is no strict separation from the strongest same-information stateful retainer. A retainer with the same memory/computation cap and raw observations can run the identical reconstruction, keep the resulting model, and produce exactly the same task outputs. That is a direct simulation theorem, including when task dynamics drift. Consequently, this note does not claim that a learned representation beats an unrestricted retaining learner. It gives the acquisition construction, its restricted break-even frontier, and the exact boundary of the comparison.

## 1. Source, interface, and tasks

Let A=Y={0,1}. The unknown source during acquisition is a complete deterministic Mealy machine
M=(Q,q0,δ,λ), where 1≤|Q|≤n, δ:Q×A→Q, and λ:Q×A→Y. A reset returns the source to q0. The learner knows n and the alphabets, but not Q, q0, δ, λ, state names, or any transition/output entries.

The only acquisition access is a reset-word query. On input w=a1…aj, the source returns the full raw trajectory y1…yj, with yi=λ(qi−1,ai) and qi=δ(qi−1,ai). The query costs one reset, j input symbols, and j output bits. The learner sees no internal state, source code, model oracle, parity cache, teacher-supplied access sequence, or equivalence-query answer. The finite test panel below is generated by the learner from n and the public alphabet.

After setup, task t supplies an exogenous word ut∈A^{≤H}, starting from reset, and asks for its predicted output word. The sequence is exogenous (fixed independently of the predictor’s outputs); this is enough for the exact guarantee and for the drift bound. All policies being compared receive the same task words and any later raw observations. A task is scored by normalized Hamming loss
L_t = (1/|ut|) Σ_i 1{ŷ_{t,i}≠y_{t,i}},
with the empty word assigned zero loss. The deterministic stationary theorem has loss exactly zero for every word, not just words sampled from a task distribution.

For the independent-refitting cost comparison only, each task opens an additional reset-query window against that task’s source before its prediction word is scored; the same query interface and cost schedule are available to every policy. The reuse policy may leave the window unused. In the raw-transcript replay comparison, the baseline instead reuses the first panel and needs no later query window.

A fixed algorithm description and public parameters are not source information. For a literal bit-memory accounting, the algorithm description length is denoted L_alg and is added to the stated working-memory bound. The source-dependent transcript and model are fully charged.

## 2. Acquisition and validation panel

Put d=n². Query every binary word of length strictly less than d during acquisition, then query every word of length exactly d as a separate validation panel. Within each length, enumerate words lexicographically.

Let T=⋃_{j=0}^{d−1} A^j and V=A^d. The counts are:

- acquisition/reset queries: Q_T=2^d−1;
- validation/reset queries: Q_V=2^d;
- total reset queries: Q=2^{d+1}−1;
- acquisition input and output symbols: X_T=Σ_{j=0}^{d−1} j2^j=(d−2)2^d+2;
- validation input and output symbols: X_V=d2^d;
- total input symbols and output bits: X=X_T+X_V=(2d−2)2^d+2.

Thus the validation cost is visible rather than folded into an informal “test”: it is 2^d independent reset episodes and d2^d input/output symbols. Since outputs are binary and deterministic, every observed output symbol is recorded at exactly one bit. No statistical confidence parameter or floating-point precision is used.

The complete response transcript can be stored as X bits. Query words need not be stored: the fixed enumeration and each word’s length determine the transcript boundaries and let the learner regenerate the inputs.

## 3. Finite-state acquisition theorem

**Theorem 1 (exhaustive raw-trajectory acquisition).** For every deterministic Mealy source M with at most n states and reset access as above, the following algorithm uses only the T and V raw trajectories and returns a finite Mealy table Mhat whose output on every finite input word equals M’s output. It uses Q reset queries, X input symbols, X output bits, and a peak workspace bound B_peak below. A simple exhaustive implementation has at most N_n·X transition-and-output comparisons, plus candidate-generation and index work, where
N_n = Σ_{m=1}^n m^{2m+1}4^m.

**Algorithm.** Store the raw output words in the public panel order. Enumerate every labeled complete Mealy table on m states for m=1,2,…,n. For each candidate, compare its responses against the stored training panel T. Reject it on the first training disagreement. For each candidate passing T, compare it against every stored response in V; accept the first candidate passing both panels. If desired for a canonical compact table, restrict to reachable candidates or enumerate m in increasing order and retain the first fully passing candidate.

The candidate set is finite, and it contains a renaming of M. Therefore at least one candidate passes both panels. The algorithm terminates.

**Proof of correctness.** Consider two deterministic Mealy machines M1,M2 having at most n states each. Their product has at most n² state pairs. If their output traces differ on any word, choose a shortest distinguishing word w of length ℓ. Every proper prefix of w has matching output traces. The product-state pairs reached after prefixes of lengths 0,…,ℓ−1 must all be distinct: if the same pair occurred after prefixes i<j, deleting the intervening input segment would preserve the product state before the remaining suffix and would produce a shorter distinguishing word. Hence ℓ≤n²=d.

The selected candidate agrees with M on every word of length less than d by the training check, and on every word of length d by the validation check. If it disagreed on any longer or shorter word, the preceding product argument would give a distinguishing word of length at most d, contradicting those checks. It is therefore behaviorally equivalent on all finite words. This proof uses only the known state cap and exhaustive legal trajectories; it uses no equivalence oracle. ∎

If the accepted candidate is selected with minimum state count, its reachable states are the residual predictive states of M and are unique up to isomorphism. This is useful only for stating a state-aligned drift condition; exact prediction requires behavior equivalence and does not require canonical labels.

## 4. Representation, precision, memory, and computation

For a candidate with m≤n states, let s=⌈log2(n+1)⌉. A simple exact table encoding uses:

- s bits for m;
- s bits for the initial-state ID;
- for each of m states and each of two actions, s bits for the successor ID and one bit for the emitted symbol.

Thus the persistent representation uses at most
B_M = 2s + 2n(s+1)
bits. The encoding is exact: state IDs and output bits are finite symbols, not estimates. A minimum-state table may use fewer bits. At prediction time the machine retains a current state ID (s bits) and performs one table lookup per input symbol. Each task costs one reset plus |ut| table transitions and |ut| predicted output bits. For K tasks of maximum horizon H, the prediction work is at most KH table transitions, and the persistent table occupies B_M bits across the task sequence.

During fitting, retain the X-bit transcript and one current candidate table. A concrete sufficient peak-data-memory bound is
B_peak = X + B_M + B_ctrl + L_alg,
where
B_ctrl = ⌈log2(N_n+1)⌉ + 4⌈log2(X+1)⌉ + 2d + s + 16.
The terms cover the candidate enumeration index, transcript and symbol cursors, word-length/position and table-loop counters, two d-bit word-generation/simulation buffers, the active state ID, and 16 fixed loop/control bits. Since X≥d, the X-cursors also hold counters up to d and n. This deliberately conservative bound permits keeping the complete raw transcript while the candidate table is built. After acceptance, the transcript and counters may be erased, leaving B_M persistent bits. L_alg charges the fixed program if code memory is included.

For computation, one transition/output comparison is a word-RAM operation whose word width is
w=⌈log2(N_n+X+n+2)⌉.
Testing every candidate against the full panel gives at most N_n X such comparisons. Candidate enumeration, address arithmetic, and transcript traversal add at most O(N_n(X+n)w) bit operations under a direct table implementation. This is a finite budget, not a polynomial-time claim. In particular Q=2^{n²+1}−1, and N_n is itself superpolynomial in n. The construction demonstrates legal acquisition and exact reuse under a declared budget; it is not an efficient general-purpose learner.

## 5. Stationary reuse and the restricted break-even frontier

Assume the same M generates all K future tasks. The acquired model has zero prediction loss on every task. Let the one-fit charge, excluding future prediction and common memory residence, be
F = α_R Q + (α_I+α_O)X + α_C C_fit,
where Q includes both acquisition and validation reset episodes, X includes both panels’ input symbols and output bits, and C_fit is the explicit finite computation bound above. All α coefficients are nonnegative resource prices. Precision cost is exact one-bit output symbols and the finite B_M table; there is no uncharged estimation precision.

Use a hard memory cap B≥B_peak. If memory residence is priced, charge α_M B_M bits per task-horizon unit. This model-residence charge is the same for a reusable model and for a baseline that fits one table for each task and holds it while predicting that task. Common future resets, task input/output traffic, and KH table transitions also cancel in the comparison.

Under that accounting:
- reuse fits once and pays setup F;
- independent relearning fits once per task and pays KF;
- both pay the same task prediction, exact-precision, B-bit feasibility, and model-residence costs.

Therefore the exact stationary frontier against the restricted “discard the fitted table and relearn independently on every task” baseline is:
reuse is strictly cheaper iff K>1 and F>0.
In the expanded per-resource vector, the saving is (K−1)Q reset episodes, (K−1)X input symbols, (K−1)X output bits, and (K−1)C_fit local fitting work. Validation is charged each time in that baseline and once under reuse.

For a general drifted task sequence, let L=Σ_t E[L_t] be the total normalized-Hamming loss of reusing Mhat, let Δ denote any noncommon extra storage/inference charge for reuse, and let α_L price unit loss. If a per-task refit can attain zero task loss at setup charges F_t—as in a deterministic finite-state task with the same reset-panel interface—then the exact scalar break-even condition is
Σ_{t=1}^K F_t > F_acq + Δ + α_L L,
where F_acq is the one-time acquisition charge. For equal F_t=F_acq=F this is (K−1)F>Δ+α_L L. This is an accounting identity once the task-specific F_t and loss are specified, not a statistical sample-complexity theorem for noisy drifting sources. The stationary theorem supplies F exactly. For noisy future sources, F_t at a requested accuracy/confidence remains UNKNOWN here.

## 6. Explicit drift guarantee

A drift bound must be stated against the acquired source; without one, future prediction quality is not guaranteed. Here is one precise conditional extension. Assume first that the acquired source is minimal and reachable. More generally, replace it by its minimal reachable behaviorally equivalent quotient and assume later sources use that same state space. Let those state labels be aligned with each later task source. During task t, the later source may use a stochastic joint transition/output kernel P_t(y,q′|q,a), with the same reset state. Suppose every state/action row satisfies
TV(P_t(·|q,a), P_0(·|q,a)) ≤ ε_t,
where P_0 is the point-mass transition/output kernel of the minimal acquired machine. For a fixed exogenous word of length H_t≤H, couple the task trajectory to the P_0 trajectory. If H_t=0 both losses are zero; otherwise, while the paths remain coupled, each next state/output pair disagrees with conditional probability at most ε_t. Hence
Pr[any output disagreement on task t] ≤ min{1,H_t ε_t},
and the expected normalized Hamming loss obeys
E[L_t] ≤ min{1, ε_t(H_t+1)/2}.
For the second inequality, at position j the paths can have diverged by at most j opportunities, so the probability of a symbol mismatch is at most min{1,jε_t}; summing and dividing by H_t gives the stated bound (the displayed simpler bound is conservative when ε_t is large). The first bound is the union bound over the first divergence.

This is a performance guarantee conditional on a row-wise drift promise and state alignment; the learner does not receive ε_t or P_t as an oracle. No query in the acquisition panel estimates the future drift. If future dynamics have no such bound, their reuse loss is UNKNOWN. If the later source is instead a different deterministic Mealy machine with at most n states and the same reset convention, replace the kernel condition by the directly specified task-distribution drift
D_t = E_{u∼μ_t}[ |u|^{-1} d_H(λ^*_{M_t}(q0,u), λ^*_{M}(q0,u)) ].
Then E[L_t]=D_t exactly. No structural bound on D_t follows from the acquisition panel alone.

## 7. Strongest retainer: exact no-advantage simulation

**Theorem 2 (retention simulation).** Fix any legal acquisition-and-prediction policy A that receives raw reset trajectories and future task inputs through the interface above, uses at most B bits of mutable memory, and uses at most C local computation. An equally informed stateful retaining baseline R with the same B-bit and C-operation budgets can match A’s task predictions and losses exactly, on every source and task sequence, while seeing the same observations.

**Proof.** R runs A’s update rule on the identical raw-trajectory stream, stores A’s resulting B-bit state, and executes A’s prediction rule on the identical future task inputs. If A uses internal randomness, R couples the same random tape. Thus the state before every prediction, each emitted prediction, and every resulting loss coincide. For the panel used here, R may preserve the raw transcript as well during setup: B_peak accommodates transcript plus active model. It can also discard raw records after forming A’s state if the baseline permits summaries. No information, model, parity table, or teacher response is supplied to R; the representation is computed from the same legal observations. ∎

Consequently the optimal unrestricted B-bit retaining/refitting baseline has cost no greater than the acquisition policy. If the acquisition policy itself is optimal in that class, the baseline can tie it exactly; otherwise the baseline may improve on it. A universal strict cost advantage over this comparator is impossible. The same simulation remains true under drift because both policies see the same drifted observations and tasks.

This also explains why a lower bound against literal raw replay alone is not a lower bound against competent retention. A policy that is forced to discard every fitted table and refit from raw samples on every task pays repeated fitting work. Once the policy may retain any B-bit derived state, it can retain precisely the learned table above. Any claimed strict advantage must state an additional restriction—such as “no derived model may be retained,” a lower baseline memory/computation budget, or different task information—and charge that restriction explicitly.

## 8. Literature and scope

Mealy’s original sequential-machine paper supplies the classical deterministic input/output state-machine setting used here. Angluin’s 1987 primary paper studies regular-set learning with membership queries plus equivalence queries/counterexamples, and explicitly notes the stronger equivalence-testing ability of that teacher. The present construction does not assume such an oracle: it replaces it with a known state cap and an exhaustive finite panel, at exponential query cost. The product-state distinguishing argument and the retention simulation are proved directly above; neither is being attributed as a novel result from those sources.

## 9. Falsifiers and open gates

The positive exact acquisition theorem would fail if the source were not deterministic during the panel, reset did not return to a fixed initial state, the true state count exceeded n, or query responses were corrupted. The all-future exactness claim would fail if the learned candidate were only approximately checked; the proof depends on every word through length n², including the full validation layer.

The drift inequality requires common/aligned states, a common reset, a per-row total-variation bound, and exogenous task words. Removing any one of those assumptions requires a new bound.

The negative boundary theorem would not apply to a comparator forbidden to retain derived state, a baseline with a stricter memory/computation budget, or a learner/comparator with different legal observations. Those are potentially interesting restricted comparisons, but no universal result is asserted for them.

Whether a substantially smaller panel or polynomial-cost learner exists under only the stated access, whether a useful noisy-source precision frontier can be proved, and whether a nontrivial advantage survives a genuinely strongest equal-information retainer are left UNKNOWN. The last question has a negative answer for strict total-cost advantage when the baseline class contains the acquisition policy itself, by Theorem 2.

DETAILED PROOFS — CYCLE 1 COMBINATORICS / CODES
All statements below are internally derived. Matching, delta-matroid, and irregular-Moore mechanisms are classical; priority is not asserted. Algorithmic corollaries explicitly assume the unvalidated OA113 theorem recorded in combinatorics_codes.txt. The exact finite evaluator implements none of those algorithms.

1. WEIGHTED EXCHANGE, INCLUDING MONOMERS

Fix a finite graph G with distinct ports P={1,...,d}, weights w_e>=0, and monomer fugacities lambda_v>=0. For S subset P, let M_S be all matchings on the induced graph G-S and
 f(S)=sum_{M in M_S} product_{e in M} w_e product_{v unmatched in G-S} lambda_v.
All data are fixed before S is chosen. The perfect-matching model is lambda_v=0 for all v.

Fix S,T and i in S symmetric-difference T. Overlay a matching M on G-S, in red, with N on G-T, in blue. Each vertex has at most one edge of each color. A port present in exactly one graph has at most one incident edge. Begin at i. If i is unmatched, the path has length zero. Otherwise follow its unique incident edge, alternating colors, until another changed port j or a vertex unmatched in one of the two matchings. A cycle cannot be entered from a degree-one endpoint. Shared matching edges give doubled cycles and do not affect this path.

Switch colors on the path. At a second changed port j this gives matchings on G-(S xor {i,j}) and G-(T xor {i,j}). At an ordinary unmatched endpoint, including a port present in both graphs, it gives matchings on G-(S xor {i}) and G-(T xor {i}). A zero-length path has the same singleton effect. The monomer at each ordinary endpoint transfers colors; its product contribution is unchanged. Edge products are also unchanged. No deletion outside i or i,j changes.

The output pair, together with the singleton/pair bucket, recovers the input by following and switching the same alternating component starting at i. Thus this is a weight-preserving injection into the disjoint union of the output-pair sets. Summing gives
 f(S)f(T) <= f(S xor {i})f(T xor {i})
              + sum_{j in (S xor T)\{i}} f(S xor {i,j})f(T xor {i,j}).
When all monomer fugacities vanish, a positive-weight input has no ordinary unmatched endpoint, so the singleton bucket is absent. If f(S)f(T)=0 the inequality is immediate.

2. EXACT AFFINE-SUPPORT CLASSIFICATION

Let R=x0+C be a nonempty affine subspace of F2^d. Say it is realizable if {S:f(S)>0}=R for some fixed finite gadget of Section 1.

Necessity in the monomer model. Take z in C and i in supp(z). Set S=x0 and T=x0+z; their weights are positive. Exchange produces either e_i in C or e_i+e_j in C with j in supp(z)\{i}. Subtract this vector from z. The support falls by one or two, and the result stays in C. Inductively every z is a sum of weight-one/two vectors in C.

Necessity for perfect matchings. In addition to the exchange argument without singleton, every feasible deletion set has parity |V(G)| mod 2. Thus every vector of C is even, and the same induction expresses it using weight-two vectors alone.

Structure. Put i~j when e_i+e_j is in C, with reflexivity added. This is an equivalence relation: summing pairs gives transitivity. Within a class, those pair vectors span the even-parity subspace. If one coordinate in the class has its unit vector in C, then all do, and that whole class is free. Classes without units are even-parity blocks. Coordinates in no nontrivial pair class are either free (unit present) or fixed (unit absent). Since C is generated by these vectors, there is no remaining interaction between classes. Translation by x0 changes each constrained block to a prescribed parity and fixes the fixed coordinates to their prescribed values.

Sufficiency follows from the flat parity gadgets in Section 4 below. Take their disjoint union, one prescribed-parity gadget per constrained block. A fixed-0 port is joined to a private dummy with fugacities zero; a fixed-1 port is isolated with fugacity zero. In the monomer model a free port is isolated with fugacity one. Every allowed profile has weight exactly one. Perfect-matchings require no free coordinates, so all constrained/fixed blocks are handled without monomers.

An equivalent matrix test: let C=ker H, with H over F2. Unit vectors correspond to zero columns of H and weight-two vectors to equal columns. In the monomer model, realizability is equivalent to linear independence of the distinct nonzero column types. The perfect-matching model also forbids zero columns. This is a polynomial-time acquisition/test of the port interface once H is supplied.

In particular, equality_d={0^d,1^d} has kernel generator of weight d, so is impossible for every d>=3 even with monomers. This statement is about deletion of port vertices; it does not classify arbitrary maps from entire matchings to Boolean outputs.

3. QUANTITATIVE COPY / GHZ OBSTRUCTION

Take S=empty, T=P, and i fixed. For d>=3 every set appearing on the right side of the monomer exchange inequality is neither empty nor P. Write A for the list {i} and {i,j}, and B for their complements. The A sets are distinct and contain i; the B sets are distinct and do not contain i. Thus A and B are disjoint lists. With a_q=f(A_q), b_q=f(B_q), and R=sum_{S not empty/P} f(S),
 f(empty)f(P) <= sum_q a_q b_q
                 <= (sum_q a_q)(sum_q b_q)
                 <= R^2/4.
The perfect-matching version omits the singleton list entry and gives the same conclusion. For odd d its endpoint product is already zero by parity.

Let Z=sum_S f(S)>0 and
 |phi> = (1/sqrt Z) sum_S sqrt(f(S)) exp(i theta(S)) |S>.
For GHZ_d=(|empty>+|P>)/sqrt2, arbitrary phases satisfy
 |<GHZ_d|phi>|^2 <= (sqrt(f(empty))+sqrt(f(P)))^2/(2Z) <=1/2,
because Z>=f(empty)+f(P)+2sqrt(f(empty)f(P)). The squared-fidelity bound is attained by any single-endpoint state, and nontrivially at balanced endpoint weights for two independent equality pairs on four ports (or one free bit and one equality pair in the monomer three-port model).

For the classical distribution p(S)=f(S)/Z, put a=p(empty), b=p(P). The same bound gives sqrt(a)+sqrt(b)<=1. Its TV distance from the fair endpoint law is
 1-min(a,1/2)-min(b,1/2).
To maximize overlap under sqrt(a)+sqrt(b)<=1, if both a,b<=1/2, use convexity of t^2+(1-t)^2 in t=sqrt(a), with the endpoint caps. The maximum is at a=1/2, b=(1-1/sqrt2)^2, or vice versa. If a>1/2 the overlap is at most 1/2+(1-sqrt(a))^2 and cannot improve that maximum. Hence TV>=sqrt2-1.

Sharpness: take two independent bits, each one with probability q=1-1/sqrt2, and repeat each on its own equality pair. On four ports, the endpoint masses are (1-q)^2=1/2 and q^2=(1-1/sqrt2)^2, with leakage 2q(1-q)=sqrt2-1. A two-port edge implements an equality pair using a suitable positive weight. In the monomer three-port model repeat one of these bits twice and leave the other free. Rational weights approximate the real sharp parameter arbitrarily closely. The TV constant need not be sharp for every individual d; it is sharp for these stated cases and therefore sharp uniformly.

Countercontrol to an overbroad quantum interpretation: in a triangle with edge bits (12,13,23), syndrome (1,1,0) admits exactly x=100 and 011. Unit activities produce (|100>+|011>)/sqrt2, which one X gate converts to GHZ_3. This is a selected-edge error-record state, not a deleted-port boundary signature, and violates none of the above statements.

4. EXACT FLAT PARITY REDUCTION

Let G0 be a finite loopless multigraph, with m original edge bits, nonnegative rational activities a_e, and boundary syndrome s in F2^{V(G0)}. Define
 Z_s(a)=sum_{x subset E(G0): partial x=s} product_{e in x} a_e.
Distinct parallel edges remain distinct variables. Zero activities may be removed. The following graph is simple because every original incidence has its own port.

For one parity equation of arity d, construct a gadget with external selected/deleted-port parity p. Arity zero uses the empty graph if p=0 and an isolated internal vertex if p=1. Arity one uses an isolated port for p=1 or a port joined to a private dummy for p=0. Arity two, p=0, uses a single edge joining the ports.

Otherwise choose D=d or d+1 so D mod2=p. A cubic tree with D leaves has N=D-2 internal nodes. Replace each internal node by a unit-weight triangle and each tree edge by an edge between the corresponding triangle vertices. The leaves designate D triangle-vertex ports. If D=d+1, the extra port has no external edge attached and is inactive (bit zero), not deleted. A chain of triangles suffices; the checker constructs that chain.

At a triangle, if one or three external incident edges are selected, there is exactly one internal matching completion; if zero or two are selected there is none. Thus each triangle imposes odd parity on its three incident tree/leaf bits. For fixed leaf bits, the internal tree-edge bits solve a system uniquely, by peeling leaves of the tree. The only compatibility condition is that the XOR of all external leaf bits equals N mod2=D mod2=p. Hence every compatible external profile has exactly one completion.

At vertex v of G0, use the gadget of arity deg(v) and parity s_v. Connect the two incidence ports of each original edge e by a single edge of activity a_e. A matching selects this connecting edge iff x_e=1. The parity constraints impose partial x=s and their completions have multiplicity one. Therefore the weighted perfect-matching partition function is exactly Z_s(a). Vertex/edge count is O(m+|V(G0)|); degree is at most three before unweighting. Fixing a prefix edge to 0 deletes it. Fixing it to 1 removes it, XORs its incidence vector into s, and factors out a_e. Thus each self-reduction prefix preserves the same interface.

This is a classical parity-to-matching construction; its role here is to remove an assumed gadget/multiplicity oracle. It is not offered as a novel graph construction.

5. COMPACT INTEGER AND RATIONAL WEIGHT ELIMINATION

For any binary integer P>=1, build a simple DAG with P source-target paths in O(log P) vertices. Start with source 0 -> x0, so x0 has path count 1. Process the remaining bits of P from left to right. To double the current count, create x_new and helper y, and add old->x_new, old->y, y->x_new. If the bit is one, add source->x_new. All vertices increase in topological order; source is distinct from the first current vertex, so there are no duplicate arcs. The path-count recurrence is r_new=2r_old+b.

From a DAG D with source s and target t, make a bipartite graph with left copies of all vertices except t and right copies of all vertices except s. Add left(u)-right(v) for every arc u->v, and the diagonal left(v)-right(v) for every internal vertex. Every perfect matching consists of one selected source-target path plus all unused diagonals. To see this, the source left copy must choose an arc. At any internal right copy reached by a selected arc, the diagonal is unavailable, so its left copy must continue along an arc. Acyclicity forbids cycles and branching; target has no left copy. Every other vertex must use its diagonal because an arc-only component would be a directed cycle. Thus the full count is P.

Delete the source-left and target-right copies. The remaining graph has exactly one perfect matching, all diagonals; a nontrivial arc selection would require a directed cycle. Add new ports a,b joined respectively to those two original terminal copies. Now the two-port signature is: neither new port deleted ->1; both deleted ->P; one deleted ->0 by parity. Attach a,b by connectors to the endpoints u,v of a logical edge. Both connectors are either selected or unselected. The unused state contributes 1; the used state contributes P. This replaces an integer-weight edge by an explicit simple unweighted graph of O(log P) size.

For a rational edge activity P/Q>0, replace u-v by the path u-c-d-v with integer edge weights P,Q,1. If the logical edge is unused, c-d must be selected, giving Q. If used, both outer edges are selected, giving P. Its signature is Q times the original rational signature. Replace those integer edges with the preceding gadgets. Across the graph,
 #PM(H)=(product_e Q_e) Z_weighted(G).
Both graph size and output-scale bit length are polynomial in the original graph size plus sum_e(bitlen P_e+bitlen Q_e). A zero edge is simply omitted. Constructing the rational scaling factor does not require counting.

Reverse approximation-preserving reduction: given any unweighted simple graph with even n vertices, first decide existence of a perfect matching exactly (polynomial matching algorithm). If none exists, output zero. Otherwise use its original graph as a syndrome model, with every vertex odd and uniform activity lambda=eta*2^(-m-4). Any such edge subset has at least n/2 edges, and exactly n/2 iff it is a perfect matching. Therefore
 Z_allodd(lambda)/lambda^{n/2}=#PM(G)+R,   0<=R<=2^m lambda<=eta/16.
Since #PM(G)>=1 in this branch, a sufficiently accurate relative estimate of Z is a relative estimate of #PM, in polynomial bit complexity. This proves that arbitrary rare-source, bit-encoded weighted syndrome counting is AP-equivalent to general #PM. It should not be conflated with previously tractable unweighted parity functions or fixed-source ferromagnetic correlations.

6. CONDITIONAL CLASSICAL POSTERIOR SAMPLER AND LOGICAL DECODER

Assumption A (not established here): a uniform randomized algorithm on simple unweighted graphs returns a nonnegative rational relative eta estimate of #PM, zero with certainty on zero inputs, in worst-case bit time polynomial in graph encoding length, eta^{-1}, log(beta^{-1}), with failure probability <=beta. This is exactly OA113 thm:main, not a weighted/compressed/oracle upgrade of it.

Sections 4-5 give the same oracle for Z_s(a), with polynomial rational scaling. For input probabilities p_e in (0,1), activities a_e=p_e/(1-p_e) have polynomial bit length. p_e=0,1 are treated deterministically first. H_X columns of weight one use a ground vertex; append the XOR of all original rows as its row. Column-weight-two variables are edges, and zero columns are independent free Bernoulli factors. The ground-row addition preserves the kernel. Support feasibility is exactly H_X x=s, solvable over F2; no inverse-probability oracle is assumed.

For m remaining bits and target TV tau<=1, process only the prefix actually visited. At a prefix a estimate its two continuation partition functions Z_{a0},Z_{a1}. Any nonzero fixed-prefix factors are included. Check support feasibility of both branches exactly, so every output is legal even on a bad counting tape. If only one is feasible take it. If both estimated values vanish, choose any supported branch distribution; this case is included in the counting-failure mass.

For eta<=1/2, if both estimates have relative error <=eta, then qhat=Zhat_1/(Zhat_0+Zhat_1) differs from q=Z_1/(Z_0+Z_1) by at most eta. Indeed the numerator difference is q(1-q)(e1-e0), divided by 1+(1-q)e0+qe1, giving bound 2eta/(4(1-eta))<=eta. Generate a B-bit uniform number and use the rounded binary threshold for qhat; the extra branch TV error is <=2^{-B}. Use fresh independent counting tapes with failure bound beta per estimate. Uniform conditional failure guarantees remain valid at adaptive visited prefixes. Sequential coupling gives total TV <=m eta+2m beta+m2^{-B}.

Take eta=tau/(4m), beta=tau/(8m), and B>=log2(4m/tau). This is <=3tau/4, hence <=tau. It uses at most 2m FPRAS calls and has polynomial worst-case bit time in m,L,tau^{-1}. Tiny Z_s causes no extra factor; small activities are charged through L. Independent repetitions use fresh randomness, including the counting tapes.

For CSS H_X,H_Z with H_X H_Z^T=0, legal X errors of a common syndrome differ by C=ker H_X. Successful corrections are equivalent modulo C_Z=im H_Z^T subset C. Compute a binary echelon basis of C_Z; reduction modulo that basis gives a canonical coset label in polynomial time. Only 2^k labels occur in this syndrome, where k=dim C-dim C_Z. This label computation is supplied by linear algebra, not a class-count oracle.

Let p_l be the true posterior class probabilities and q_l those induced by one approximate sampler with TV<=tau. Then |q_l-p_l|<=tau for every l. With N independent samples, let h_l be empirical frequencies. Hoeffding and a union bound give
 Pr(max_l |h_l-q_l|>u)<=2*2^k exp(-2Nu^2).
So N>=log(2^{k+1}/delta)/(2u^2) suffices. Store only labels observed in the samples, choose one maximizing h_l, and retain an actual error representative. For an optimal true class l*,
 p_lhat >= h_lhat-u-tau >= h_l*-u-tau >=p_l*-2u-2tau.
Take u=tau=epsilon/4. With probability >=1-delta the resulting correction's conditional success mass is at least max_l p_l-epsilon. The sample count is O((k+log(delta^{-1}))/epsilon^2); no 2^k iteration occurs. An unobserved optimal label has frequency zero and does not invalidate the inequality. Expected conditional success over decoder randomness is >=opt-epsilon-delta.

These are conditional existence/complexity results. The Python checker enumerates partition functions exactly at tiny sizes and does not implement the FPRAS or run this decoder. Product X noise is essential to the stated partition factorization; arbitrary depolarizing correlations or coherent sums of logical amplitudes are not supplied.

7. OPTIONAL CONDITIONAL COHERENT ERROR-RECORD COMPILER

For the same product law and syndrome, the target record state is
 |psi>=sum_{x:H_Xx=s} sqrt(a^x/Z_s) exp(i theta(x)) |x>,
with a supplied polynomial-time phase computation. The state records hypothetical errors, not an unknown physical encoded state's postselected syndrome.

Use coherent binary self-reduction. At depth i, choose one independent random tape r_i long enough for a worst-case-bounded pair of FPRAS executions and reuse it coherently at every prefix at that depth. The worst-case bit bound in Assumption A is essential: a reversible bounded circuit can implement the program on all prefixes, including bad random tapes. Compile the prefix graph/gadgets and scale factors reversibly, compute two estimates, rotate the next bit, and uncompute work. Exact binary feasibility limits rotations to supported branches. Arithmetic and rotation precision are charged separately.

For a fixed depth i, let b_i(r_i) be the true ideal prefix probability mass on prefixes where either partition estimate is bad. The true prefix weights are independent of r_i. Consequently E b_i<=2beta by summing the individual failure probabilities with those weights, without a union bound over exponentially many prefixes. Markov implies
 Pr(sum_i b_i>2m beta/delta)<=delta.
For a good prefix the pair of square-root branch amplitudes changes by norm <=3eta when both relative estimates are eta-accurate. The elementary estimate follows from their multiplicative ratios between sqrt((1-eta)/(1+eta)) and its inverse; eta<=1/2 suffices. A bad prefix has norm error at most 2. Therefore the error caused by one coherent step on its ideal prefix state is <=3eta+2sqrt(b_i). A unitary telescoping/hybrid argument evaluated on ideal prefix states gives
 ||phi_seed-psi|| <=3m eta+2sum_i sqrt(b_i)
                  <=3m eta+2m sqrt(2beta/delta)
with probability >=1-delta. Choose eta=epsilon/(12m), beta=delta epsilon^2/(128m^2); this contributes <=epsilon/2. Spend the other epsilon/2 on finite-precision reversible arithmetic, rotations, and the phase circuit. Compiled size and classical compilation time are polynomial in m,L,epsilon^{-1},log(delta^{-1}).

This is a randomly compiled circuit guarantee. The construction does not recognize good seeds efficiently, and this does not give a deterministic certificate that a particular compiled seed is accurate. No quantum circuit was executed. The fixed-depth shared-tape mechanism parallels Astra N63's compiler; it is not offered as a newly invented counting-to-state method.

8. GRAPHICAL CSS DISTANCE CEILING

After adding the ground row, regard H_X as graph incidence, with zero columns as loops/free cycle coordinates. Set C=ker H_X and C_Z=im H_Z^T. Let h=dim C_Z and k=dim C-h>0. Choose h coordinate positions J such that restriction C_Z -> F2^J is an isomorphism; echelon pivot columns do this. Since C_Z subset C, restriction from C is also surjective. Hence
 C'=C intersect {x_J=0}
has dimension k and intersects C_Z only in zero. It is precisely the cycle space of the graph G' obtained by deleting edges J. Inclusion C' -> C/C_Z is an isomorphism. Every nonzero surviving cycle is therefore a logical X operator, so d_X<=girth(G'). A surviving loop or parallel pair gives d_X<=1 or 2 immediately.

Otherwise G' is simple. Prune vertices of degree <=1 repeatedly and ignore isolated empty components. This preserves all cycles and the cycle-space dimension k. The resulting core has n vertices, e<=m edges, c components, minimum degree >=2, and k=e-n+c. Thus n<=e<=m and each component has cycle rank at least one.

If c>3k/4, let t be the number of components of cycle rank one. Since every other component has rank >=2, k>=t+2(c-t)=2c-t, so t>=2c-k>k/2. A connected minimum-degree-two rank-one graph is a simple cycle. The sum of the lengths of these t disjoint cycles is <=m, so girth<=m/t<2m/k.

If c<=3k/4, average degree dbar=2e/n=2+2(k-c)/n>=2+k/(2n). The Alon-Hoory-Linial irregular Moore bound gives
 girth <=2 log(n)/log(dbar-1)+2.
Write x=k/(2n). Since log(1+x)>=x/(1+x),
 girth <=(4n/k+2) log(n)+2 <=(6m/k)log(m)+2,
using n<=m and k<=m. The unicyclic case also satisfies this last bound for m>=2. Therefore
 k d_X <=6m log(m)+2k.
There is no assumption on row weights of H_Z. At constant encoded rate k/m, d_X=O(log m); minimum quantum distance is <=d_X. Thus column-weight-two H_X cannot define an asymptotically good CSS family. This classical graph corollary bounds the consequence of Section 6 instead of promoting its tractability to a good-qLDPC claim.

9. COLUMN-WEIGHT-THREE GLOBAL HARDNESS TRANSFER

Take an exact-cover-by-3-sets instance with universe U of size 3q and m available triples. H is its U-by-m binary incidence matrix, so each column has weight three. Let s be the all-ones vector. If Hx=s, each element of U is covered an odd positive number of times. Thus 3|x|>=|U|. If |x|<=q, equality forces every element to be covered exactly once, so x is an exact cover. Conversely every exact cover has Hx=s and |x|=q.

Set activity lambda=2^(-m-3), which has only O(m) input bits, and p=lambda/(1+lambda). If an exact cover exists, its weight contributes lambda^q to Z_s. Every legal non-cover has at least q+1 selected triples. There are at most 2^m such subsets. Thus
 Pr_posterior(non-cover)<=2^m lambda^(q+1)/lambda^q<=1/8.
If Hx=s is infeasible, this can be determined exactly by linear algebra and the instance rejected. Otherwise a hypothetical uniform relative FPRAS for these syndrome partition functions, polynomial in the arbitrary rational input bit length, yields the self-reduction sampler of Section 6 to TV<=1/8. When a cover exists it returns one with probability >=3/4; when none exists a returned object cannot pass exact-cover verification. This is a randomized polynomial algorithm with one-sided error for X3C and therefore implies RP=NP using the classical NP-completeness of X3C. The direct reduction is also the standard source of general-code syndrome decoding hardness.

This argument uses arbitrary low-temperature rational noise and worst-case acquired syndromes. It does not settle complexity for one fixed noise probability, typical syndromes, a specific good-code construction, or approximate decoding under a promise. It supplies the exact boundary a proposed matching-to-LDPC transfer must evade.

10. VERIFICATION / PRIORITY LIMITS

The companion script uses Fraction arithmetic, exhaustive all-subset matching counting on tiny graphs, all binary subspaces through dimension six, and a deterministic seeded sample of larger weighted graphs. It verifies the gadget identities, exchange polynomials, affine exchange classification, pivot-subgraph quotient correspondence, and the X3C incidence identity/concentration bound. It has no heuristic floating-point acceptance step. It is exponential and verifies finite instances, not the unbounded theorems, OA113, or the claimed algorithmic running time.

Decisive source handles and reading status are in combinatorics_codes.txt. The matching support/exchange mechanism and parity gadgets are prior-art territory. The particular proof package joins them to a conditional rare-syndrome decoder and explicit distance/copy/hardness ceilings; that package is a research audit result, not an established novel publication or field-breaking achievement.

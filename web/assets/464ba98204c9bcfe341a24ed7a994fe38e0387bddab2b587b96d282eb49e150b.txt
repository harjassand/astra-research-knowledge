1. Exact interface and the projected code
----------------------------------------
Fix q. The source has the event-mark Markov renewal law in
outputs/research/sol_marked_renewal/RESULT.txt, Section 1, with unknown joint
gap/destination kernels p_i(g,d) and any stationary embedded pi whose weighted
mean M is finite. Event times are observed, but all positive marks 1..q are
replaced by binary 1. The learner receives q and one binary raw trajectory.
There is no mark oracle or transition kernel oracle. Reducibility, arbitrary
duration/destination dependence and arbitrary finite mean are allowed; no
uniform mean, support or mixing promise is imposed.

Let Q_N^mark be the proper row-urn code already banked. It chooses uniformly
among bounded-span q^2-colored pools plus a separate allzero option, a uniform
anchor/start mark, and draws outgoing items without replacement, stopping on
an empty current row while allowing unused other rows. Define

  Q_N^bin(x)=sum_{marked y mapping to x} Q_N^mark(y).

This is a proper full-support binary law. Pointwise marked domination sums to
P_N^bin(x)<=q K_N N Q_N^bin(x), hence its redundancy is O(q sqrt(N)+log(qN)).
The true hidden countdown/next-mark state still has a block-sufficient cap
with qN+1 values. Thus the same fixed-horizon suffix conversion gives an exact
REFERENCE predictor with O_q(n^{-1/2}) expected terminal KL risk. This statement
is statistical: an efficient evaluation algorithm is not assumed.

The common integer scale is unchanged:

  H_N^bin(x)=q K_N N! Q_N^bin(x),

which is the sum of the corresponding marked integer prefix masses. Its bit
length is O_q(N log N). The observed-mark prefix DP cannot simply be reused:
the transition counts c_{i,d,g}, outgoing row uses and final mark must now be
summed over the hidden ordered state path.

2. Full-span blocks isolate a precise factorial-weight word problem
------------------------------------------------------------------
Set q=2, with hidden states 0,1. Take a word w=(g_1,...,g_m) of positive
integer gap labels. Set N=1+sum_t g_t and form the binary length-N string
with events at positions 1, 1+g_1, ..., 1+sum_t g_t=N. It starts and ends
with an event. For a hidden path u=(u_0,...,u_m), let

  c_{i,d,g}(u)=#{t: (u_{t-1},u_t,g_t)=(i,d,g)},
  r_i(u)=#{t=1,...,m: u_{t-1}=i},
  a(u)=product_{i,d,g}c_{i,d,g}(u)!.

Every code pool generating this marked block must contain these observed
counts. Their span already equals N-1, so the span cap forces EXACT equality
of the pool with c(u); extra unused resources cannot fit. The anchor is 1.
Therefore, now as an equality rather than a domination lower bound,

  Q_N^bin(x(w))=Z(w)/(2 K_N),
  Z(w)=sum_{u in{0,1}^{m+1}} a(u)/[r_0(u)! r_1(u)!].

The factorial numerator couples occurrences of the same observed gap label;
the row-factorial denominator couples global hidden state visit counts. An
exact Q_N^bin oracle computes Z(w) by multiplying by 2K_N, which itself is
computed by the polynomial colored-partition DP. Numeric gap labels are
represented by actual zeros in the input, not by a succinct horizon oracle.

3. Fresh padding removes the row-factorial denominators by exact interpolation
----------------------------------------------------------------------------
Define W(w)=sum_u a(u), an integer. Append ell FRESH distinct positive gap
labels to w, none equal to any original label. Their transition counts are
each 1, so they do not change the factorial numerator. For a fixed original
hidden path, let r=r_0(u), m-r=r_1(u), and let e=u_m be its endpoint. With
ell>=1, the first appended transition has origin e, the remaining ell-1
origins are freely chosen binary states, and its final destination is free.
If e=0, the padding contribution is

  2 sum_{s=0}^{ell-1} binom(ell-1,s)
    /[(r+1+s)! (m-r+ell-1-s)!]
   = [2/(m+ell)!] binom(m+2ell-1,r+ell).

The equality is the ordinary Vandermonde convolution. If e=1, replace r by
m-r in the final expression. Write r_e=r when e=0 and r_e=m-r when e=1.
If Z_ell denotes evidence of the padded word, set

  F(ell)= Z_ell (m+ell)! /[2 binom(m+2ell-1,ell)].

Then

  F(ell)=sum_u a(u) R_{r_e}(ell),
  R_r(ell)=binom(m+2ell-1,r+ell)/binom(m+2ell-1,ell)
          = product_{h=0}^{r-1}(m+ell-1-h)/(ell+1+h).

The product is empty when r=0. Each R_r has numerator and denominator degree
r<=m, denominator dividing D(ell)=product_{h=1}^m(ell+h), and tends to 1 as
ell tends to infinity. Hence D(ell)F(ell) is a polynomial of degree at most m
whose coefficient of ell^m is EXACTLY W(w). Values ell=1,...,m+1 recover that
leading coefficient by rational interpolation. Explicitly it is

  sum_{ell=1}^{m+1} D(ell)F(ell)
    /[(-1)^{m+1-ell}(ell-1)!(m+1-ell)!].

Thus W(w) polynomial-time Turing reduces to exact Z of fresh-padded words.
For original labels in {1,...,h}, use fresh labels h+1,...,h+ell. In the hard
family below m=2h and ell<=m+1, so every binary oracle input has N=O(h^2).
There are O(h) queries, and all factorials, partition counts, exact rational
values and interpolation coefficients have polynomial bit length. The above
limit is recovered by FINITE interpolation; an infinite-precision or infinite
padding operation is not used.

This extraction has cancellation and potentially large condition numbers.
It is an EXACT reduction, not an approximation-preserving one. An FPRAS whose
cost is polynomial in inverse relative tolerance cannot be used here at the
exponentially fine tolerance exact coefficient recovery might require.

4. Two occurrences per gap label give a fixed Holant tensor
---------------------------------------------------------
Restrict the original word so every label occurs exactly twice, at positions
a,b. Its local factorial contribution is 2 iff the two ordered hidden
transition pairs agree, and is 1 otherwise. Thus

  a(u)=product_labels f(u_{a-1},u_a,u_{b-1},u_b),
  f(A,B,C,D)=1+1[A=C]1[B=D].

Internal hidden states along the word connect adjacent tensor ports; the two
end states are summed freely. Apply the orthonormal real Hadamard matrix
T=2^{-1/2}[[1,1],[1,-1]] to every port. Inner identity edges are unchanged
because T^T T=I. The transformed tensor is exactly

  fhat(A,B,C,D)=4*1[A=B=C=D=0]+1[A=C]1[B=D].

This follows by transforming the all-ones tensor and the two equality tensors
separately. The only permitted configurations wire A to C and B to D. Their
weight is 5 when BOTH wire bits are 0 and is 1 otherwise. A wire component
therefore carries one binary spin, and a tensor joining two components has
the two-spin interaction matrix

  M=[[5,1],[1,1]].

Each free end vector (1,1) transforms to sqrt(2)*(1,0). The two word ends thus
give a factor 2 and pin the wire component broken at that word cut to spin 0.
No unaccounted power of 2 or sign remains in this tensor identity.

5. An Eulerian medial construction realizes arbitrary even-degree graphs
-----------------------------------------------------------------------
Let H be a connected loopless undirected multigraph with all degrees even and
at least one edge, and choose a root vertex v. Orient H along an Euler circuit;
every vertex has equal incoming and outgoing incidence count. At each vertex
choose a cyclic ordering of its incidences alternating outgoing and incoming.

Create a directed 4-regular medial graph F with one vertex for each edge e of
H. If e is oriented u->z, its two incoming ports belong to the loop of u and
its two outgoing ports belong to the loop of z. At each H vertex, connect the
two ports of each incident medial vertex cyclically to those of its neighbors
in the chosen incidence ordering. Alternation ensures every such medial edge
joins an outgoing to an incoming port. Each medial vertex has indegree and
outdegree 2; F is connected, and consequently has a directed Euler circuit.

Record the medial vertex encountered at each departure on that circuit. This
gives a word of length 2|E(H)| in which every medial vertex/label occurs exactly
twice. Cut the circuit on a medial edge belonging to the incidence loop of v,
and rotate the word accordingly. The incoming ports at a label's two visits
are precisely the pair A,C of its f tensor, and the outgoing pair is B,D.
After the Hadamard transform, the equality wires form exactly the incidence
loops of H's vertices; the tensors give exactly its M interactions. The cut
pins root v to 0. Therefore the constructed word satisfies

  W(w(H,v)) = 2 Z_M(H; v=0).

This proof is constructive and uses only an Euler orientation, alternating
rotation choices and a directed Euler circuit, all polynomial-time graph
operations. It does not require a planar embedding. Parallel edges are legal.
Assign distinct integer gap labels 1,...,|E(H)|, giving actual total duration
2 sum_{j=1}^{|E(H)|}j=O(|E(H)|^2). Every queried binary trajectory is polynomial
in the input graph size even in the explicit raw-path representation.

6. Remove the pinned root and obtain a fixed #P-hard source matrix
----------------------------------------------------------------
Start with a connected nontrivial simple graph G. Duplicate every edge to form
H; it is connected and all degrees are even. Evaluating M on H equals evaluating
the ENTRYWISE-square matrix B on G, where

  B=M^{odot2}=[[25,1],[1,1]].

Pick a vertex v in H. Let A=Z_M(H;v=0) and C=Z_M(H;v=1). Add a new auxiliary
vertex z attached to v by 2t parallel edges, for t=1 or t=2. Degrees remain
even. Pin z to 0. The two partition values are

  B_1=25A+C, B_2=625A+C,
  Z_M(H)=A+C=(26 B_1-B_2)/25.

Each B_t is W(w(H_t,z))/2 by Section 5, and every W is recovered from exact
projected-code Q queries by Sections 2-3. Disconnected graphs are handled
componentwise; an isolated vertex contributes a known factor 2. Thus an exact
projected-code prefix oracle computes Z_B(G) in polynomial time.

The one external hardness premise is the nonnegative matrix partition-function
dichotomy. In Govorov--Cai--Dyer, arXiv:2002.02021v1, Theorem 3.2, a positive
nonnegative symmetric matrix with identity vertex weights is #P-hard on bounded
degree simple graphs unless it is block-rank-1. B is positive and det(B)=24,
so it has one full support block of rank 2. It therefore satisfies the hard
case. The reduction above imports this theorem; it does not reprove the whole
published dichotomy. Its own tensor, padding and graph constructions are the
new internally reconstructed steps.

Conclusion: exact evaluation of Q_N^bin(prefix), already with q=2 and the
fixed uniform pool prior, is #P-hard under polynomial-time Turing reductions.
Hard queries need only original gaps that occur twice and fresh gaps that
occur once. No weights, graph filters or source kernels are inputs to Q.

7. Membership, sequential conditionals and the precise consequence
----------------------------------------------------------------
For q=2 the integer H_N^bin(prefix)=2 K_N N! Q_N^bin(prefix) is in #P. A
nondeterministic machine chooses the hidden marks of its observed events and
one canonical binary encoding of every count-pool coordinate C_{i,d,g}; it
rejects if the span cap or prefix feasibility fails. For each accepted choice,
the marked prefix formula has a polynomial-time computable nonnegative integer
weight after multiplying by N!, by the previously proved denominator lemma.
For the tail branch include its integer linear statistic. An additional
polynomial number of nondeterministic bits, accepting precisely that many
indexes, implements the integer weight. No-event prefixes use the analogous
pool/anchor integer weight and a separate allzero branch. Each weight has
O(N log N) bits. Counts have O(N log N) total encoding length for fixed q.
This is a polynomial-size weighted-count implementation with unique encodings,
not a promise of efficient enumeration. Together with hardness, the scaled
integer prefix function is #P-complete under polynomial-time Turing reductions.

An exact compiler of all fixed-Q_N next-symbol conditionals would also evaluate
full Q_N blocks: multiply its N sequential conditionals from the empty prefix.
Each rational has polynomial bits, and the unreduced product has polynomial
bits. Therefore that general exact conditional compiler is #P-hard too.

This does NOT show that the final suffix-averaged terminal predictor itself is
#P-hard to evaluate, since the oracle used here gives individual prefixes or
conditionals and one cannot simply extract them from an average. It also does
not show that every optimal predictor must implement this code. FP=#P is the
conditional exact-computation barrier, not NP=RP or a sampling impossibility.

8. A complete subexponential exact compiler and polynomial leaves
---------------------------------------------------------------
For a binary prefix with observed complete gaps g_1,...,g_r, enumerate hidden
PATH STATISTICS by a forward dictionary keyed by (current mark, count vector
c_{i,d,g}), storing the number of hidden paths with those statistics. Initially
give every start state weight 1. At step t extend each current state i to each
destination d, increment c_{i,d,g_t}, and accumulate into the new key. After
all observed gaps, each key's code prefix weight depends only on c and its
last mark, as proved in the observed-mark formula; multiply by the stored path
count and use the exact marked-prefix DP. First observed event time and final
zero age come from the binary path; the uniform starting-mark factor does not
depend on the hidden first mark. Sum all keys.

Every count vector reached has weighted span <=N-1, so there are at most
sum_{s<N}p_{q^2}(s) such vectors. The dictionary has at most q times this many
keys, and its path counts have O(N log q) bits. This gives a deterministic
exact bit algorithm with exp(O(q sqrt(N))) times a fixed-q polynomial cost,
using no probability approximation. It is an explicit fallback, not polynomial
time in general. The exponential factor arises from exactly the latent count
statistics that the observed-mark compiler was handed by its input.

If the number L of DISTINCT OBSERVED complete gap lengths is bounded, only
q^2 L count coordinates can be nonzero. This same forward compiler has at
most q(N+1)^{q^2 L} keys, hence is polynomial in N for fixed q,L. Unseen pool
gap labels remain included exactly by the marked partition DP; no true support
bound is assumed. Prefixes with no events, or with one event, have no unknown
transition path and are already polynomial-time leaves.

A raw count-vector representation really can have exp(O(sqrt N)) many keys:
take distinct gaps 1,...,L, total duration Theta(L^2). Each hidden binary path
has a distinct transition-label count vector, giving 2^{L+1} keys. But this
fact alone is not a hardness proof: at full span all those gaps are unique,
and factorial numerator is 1, so their evidence can be summed using only row
visit totals. The repeated-label reduction in Sections 3-6, rather than a
dimension count or generic HMM folklore, establishes the exact obstruction.

9. Approximation boundary and the relative-count prediction contract
-------------------------------------------------------------------
M=[[5,1],[1,1]] has positive determinant and is ferromagnetic in the two-spin
sense. Exact #P-hardness of its partition function can coexist with efficient
relative approximation. The reduction from Z to W uses cancellation-heavy
interpolation, so it is not an AP reduction. An FPRAS for W therefore neither
settles nor refutes an FPRAS for the full hidden-code prefix weights. Those
weights retain row-factorial denominators, pool span, anchor factors, unused
rows and last-row survival; none may be silently dropped.

The conditional approximation-to-prediction theorem is banked separately at
outputs/research/root_relative_prediction_compiler/PROOF.txt. This worker read
and audited it: for each suffix, estimate CHILD prefix masses relatively and
normalize them, then average the categorical vectors and smooth by gamma.
If all calls have relative error delta, the extra KL is bounded by
log((1+delta)/(1-delta))-log(1-gamma). If each of An calls fails with probability
at most eta, uniformly in the supplied input, smoothing bounds the added failure
contribution by An eta log(A/gamma). No independence or rare-prefix lower
bound is required. Relative-oracle bit time must be polynomial in N, inverse
delta and log inverse eta; inverse actual prefix probability is not free.

For fixed A one fully rational choice is k=ceil(sqrt n),
delta=gamma=1/(4k), eta=1/(A n^2); the added risk is O(n^{-1/2}). The root's
alternative confidence parameters have the same order when rounded with their
error charged. This is a conditional lemma; it does not provide the missing
hidden-prefix FPRAS. Additive accuracy, unbounded relative-variance unbiased
estimators and sampling the prior until a rare prefix occurs do not meet it.

COORDINATE-QUERY QUANTUM MEMORY AUDIT
Date: 2026-10-07
Status: proved proposition under the explicit interface below; novelty not established.

MAIN FINDING

Separate, possibly incompatible POVM decoders still imply the full s/2 precision exponent. A simultaneous reconstruction is unnecessary. The relevant tool is strong subadditivity of quantum conditional entropy, applied to finite quantizations of the target coordinates.

The target must be the posterior vector being estimated, rather than the raw observation: its selected queried coordinates must have a jointly absolutely continuous s-dimensional law on a fixed positive-mass patch. Independence of those coordinates, a Gaussian law, and pointwise unbiasedness are unnecessary.

EXACT INTERFACE AND THEOREM

Let T be the target posterior vector, and let B be an event determined by the source with P(B)=p>0. Choose s queried coordinates, relabelled T_1,...,T_s. Let Z=(T_1,...,T_s) conditional on B have a compactly supported absolutely continuous distribution with finite differential entropy h_B in natural-log units.

Let R be arbitrary public randomness independent of the source. It may have any alphabet. The encoder may depend on R and produces a hybrid memory M with total Hilbert dimension N. In particular, C distinguishable classical memory values and a D-dimensional quantum register give N=C D. With varying quantum dimensions D_c, use N=sum_c D_c.

For each selected coordinate j, a distinct decoder may use (M,R), apply any POVM, and output a real random estimate A_j. There is no requirement that these POVMs commute, that they can all be performed on one copy, or that A_j is unbiased. Each guarantee concerns the actual estimate in that query experiment:

    E |T_j-A_j|^alpha <= eps_j,    alpha>0.

All source-dependent information available to the decoder is included in M. Independent ancillary systems and computation are allowed. Uncharged entangled decoder side information correlated with the encoder is outside this interface.

Define

    C_alpha = 2 Gamma(1+1/alpha) (alpha e)^(1/alpha).

Then

    N >= exp(h_B) C_alpha^(-s) p^(s/alpha)
         product_{j=1}^s eps_j^(-1/alpha).                 (1)

For alpha=2, C_2=sqrt(2 pi e), so

    N >= exp(h_B) [p/(2 pi e)]^(s/2)
         product_j eps_j^(-1/2).                         (2)

If each selected coordinate has MSE <= eps, this gives

    N >= exp(h_B) [p/(2 pi e eps)]^(s/2).                (3)

If instead the sum of selected coordinate MSEs is <= eps, the arithmetic-geometric mean inequality gives the stronger constant

    N >= exp(h_B) [s p/(2 pi e eps)]^(s/2).              (4)

Each error in the sum is understood in its own query experiment; a common joint output is not assumed. Zero eps_j is impossible for finite N under these source assumptions, as follows by taking the bound with arbitrarily small positive eps_j.

FINITE-QUANTIZATION PROOF

First condition all source and experiment distributions on B. Public R remains independent of the source. By nonnegativity of the loss, the conditioned alpha-moment error is at most eta_j=eps_j/p.

Fix delta>0, and write K_j=floor(Z_j/delta), K=(K_1,...,K_s). Because Z is compactly supported, every K_j has finite alphabet. Conditional on K and R, M is an ordinary finite-dimensional classical-quantum state; the state can be defined by averaging the original encoder states in each source cell. Therefore only finite-register quantum entropy is used below.

The quantum information capacity bound is

    I(K:M | R) <= log N.

Since K and R are independent,

    H(K)-log N <= H(K | M,R).

Quantum strong subadditivity, applied successively to the finite classical coordinate registers and conditioned on the public classical R, gives

    H(K | M,R) <= sum_j H(K_j | M,R).

For each j separately, the measurement-and-output map M -> A_j is a quantum channel once R is fixed. Quantum data processing gives

    H(K_j | M,R) <= H(K_j | A_j,R).

Consequently,

    H(K)-log N <= sum_j H(K_j | A_j,R).                 (5)

This is the decisive random-access step. It does not assert that the A_j jointly exist as outcomes of measurements on a single copy. The terms are evaluated in their respective experiments, all of which start with the same source-memory ensemble.

Bound each conditional classical entropy by introducing an auxiliary independent U_j~Unif[0,1). Disjoint unit intervals give the exact identity

    H(K_j | A_j,R)=h(K_j+U_j | A_j,R).

Let

    V_j = delta(K_j+U_j)-A_j.

Translation and scaling of conditional differential entropy imply

    H(K_j | A_j,R) = h(V_j | A_j,R)-log delta
                           <= h(V_j)-log delta.        (6)

If f_j=Z_j/delta-floor(Z_j/delta) is its fractional part, then

    V_j=(Z_j-A_j)+delta(U_j-f_j),
    |delta(U_j-f_j)| <= delta.

For alpha>=1, Minkowski gives

    E|V_j|^alpha <= (eta_j^(1/alpha)+delta)^alpha.

For 0<alpha<=1, subadditivity of |.|^alpha gives

    E|V_j|^alpha <= eta_j+delta^alpha.

In either case write the displayed upper bound as m_j(delta), which tends to eta_j as delta decreases to zero.

For any real random variable V with a density and E|V|^alpha<=m, the maximum-entropy moment bound is

    h(V) <= log C_alpha + (1/alpha) log m.              (7)

An elementary verification uses nonnegativity of relative entropy against

    g(v) = [2 Gamma(1+1/alpha)(alpha m)^(1/alpha)]^(-1)
           exp(-|v|^alpha/(alpha m)).

Its alpha moment is m, and its entropy is log C_alpha+(1/alpha)log m. Applying (7) to (6) yields

    H(K_j | A_j,R)
    <= log C_alpha+(1/alpha)log m_j(delta)-log delta.   (8)

The source differential entropy obeys an exact cell-volume inequality. Every quantization cell has volume delta^s, so its conditional differential entropy is at most log(delta^s). Thus

    h_B <= H(K)+s log delta.                           (9)

There is no need to import a quantization-entropy convergence theorem. Combining (5), (8), and (9) cancels all log delta terms:

    log N >= h_B-s log C_alpha
                     -(1/alpha)sum_j log m_j(delta).

Let delta decrease to zero and substitute eta_j=eps_j/p. This proves (1).

For alpha=2, the same proof gives the useful finite-delta inequality

    log N >= h_B-s log sqrt(2 pi e)
                   -sum_j log(sqrt(eps_j/p)+delta).

CORRELATED COORDINATES AND THE GEOMETRIC ASSUMPTION

No coordinate independence is used. The proof keeps the joint entropy h_B instead of replacing it with the sum of marginal entropies. Strong subadditivity supplies the necessary combination even for correlated coordinates.

Suppose the posterior vector T lies on a smooth embedded s-dimensional manifold, its source law has a nonzero smooth density relative to s-dimensional volume on some patch, and all ambient posterior coordinate queries are allowed. At an interior regular point, an s by s minor of the embedding derivative is nonsingular. Choose those s ambient coordinates and shrink to a patch where this coordinate projection is a diffeomorphism. Conditioning further on a relatively compact positive-mass subpatch yields the theorem's selected-vector distribution and finite h_B. The constant depends on that fixed patch and prior, but the exponent is s/alpha.

If the queried target map has rank below s, or the selected coordinates do not parameterize any positive-mass s-dimensional patch, the raw observation dimension is not a valid exponent. Likewise, a smooth support set alone does not guarantee a source density or finite entropy. A deterministic posterior gives a decisive counterexample to an assumption-free statement: D=1 and zero error.

For worst-case coordinate-error guarantees, one may choose any smooth full-dimensional prior in a regular compact patch. The same proof then applies without dependence on an originally supplied prior.

BAYES REGRET INTERPRETATION

For Bernoulli prediction with posterior T_j, the squared-loss conditional Bayes regret of an actual scalar decision a is exactly (a-T_j)^2. After averaging over source, public randomness, and decoder measurement outcomes, expected Bayes regret is the MSE in the theorem. No pointwise unbiasedness is needed.

More generally, if a query's conditional regret dominates kappa_j |a-T_j|^alpha, expected regret delta_j implies eps_j<=delta_j/kappa_j. Substitute this value in (1). If queries are sampled with fixed positive probabilities q_j and total expected regret is <=eps, each relevant coordinate has moment at most eps/(q_j kappa_j). This keeps the s/alpha exponent, with an explicit product of query-weight constants.

The guarantee must concern the realized output. Access to exact Born expectations is a different interface. For example, the qubit state rho_{x,y}=(I+x sigma_x+y sigma_z)/2 encodes a two-dimensional disk continuously, and the two observable means equal x and y exactly. Their one-shot outcomes have nonzero variance, so this does not violate the MSE theorem. An oracle that supplies exact observable means would defeat the dimension bound.

HYBRID MEMORY AND EXTERNAL SIDE INFORMATION

For C classical states and a D-dimensional quantum register, the bound is on C D. Equivalently, b classical bits and q qubits obey b+q>=log_2 of the right-hand side. A bound stated only on D is invalid if arbitrary source-dependent classical memory is free.

Arbitrary public randomness independent of the source is handled explicitly by conditioning on R and does not add information capacity. Independent decoder ancillary states are absorbed into its POVM. Source-dependent external side information must be counted or incorporated as a conditional source-entropy assumption.

Uncharged pre-shared entanglement is a materially different communication interface. Counting only a transmitted D-dimensional system can allow a 2 log D classical information cap (dense coding), rather than log D. Counting the full received/source-dependent memory avoids this mismatch. No entanglement-assisted bound is claimed here.

CONDITIONAL CLAIM

Let d>=2, 1<=r<=floor(d/2), m>=1, and let lambda be a nonempty partition in
the r-by-2m rectangle. Assume the candidate formulas

  mu_s(lambda) = product_(j=0)^(r-1) product_(t=0)^(lambda_(j+1)-1)
                   (s+j-t)/(s+d-j+t)

give the coherent-EB eigenvalue mu_(2m), and the compatible-channel
eigenvalue mu_m/mu_(2m), with mu_m=0 on components absent from the
m-rectangle. Then

  (1-mu_(2m)) / (1-mu_m/mu_(2m)) <= c0,
  c0 = 2(m+d)/(2m+d) < 2.

For lambda=(1), equality holds. Thus the candidate's coupled-partition
scalar comparison is valid for every d,k,m and admitted lambda, with a
stronger first-harmonic constant. This is conditional scalar algebra only;
it does not supply the missing general spectrum theorem or an EB rounding
theorem.

PROOF

Write a box's content as x=j-t. For lambda_1<=m, all contents satisfy
-(m-1)<=x<d/2. Define the factors

  u_x = (2m+x)/(2m+d-x),
  v_x = [(m+x)/(m+d-x)] / u_x
      = (m+x)(2m+d-x)/[(m+d-x)(2m+x)].

Then B=mu_(2m)=product u_x and V=mu_m/mu_(2m)=product v_x. Put

  kappa = (2m+d)/(2(m+d)), alpha=1-kappa=d/(2(m+d)),

so 1/c0=kappa. We prove V<=alpha+kappa B.

First consider a column prefix with contents x<=0. Direct common-denominator
algebra gives

  alpha+kappa*u_x-v_x
    = (-x)(d-2x)(d^2+3dm-(d+2m)x)
      / [2(d+m)(2m+x)(d+2m-x)(d+m-x)] >= 0.

All denominator factors are positive in the allowed range, and for x<=0
the numerator is nonnegative. Thus v_x<=1-kappa(1-u_x). For any finite list
u_i in [0,1], the function

  g(s)=1-product_i(1-s(1-u_i)),  0<=s<=1,

is concave: its second derivative is the negative of a sum of nonnegative
terms. Since g(0)=0, g(kappa)>=kappa*g(1). Consequently

  product_i [1-kappa(1-u_i)] <= 1-kappa(1-product_i u_i)
                               = alpha+kappa*product_i u_i.

This proves V<=alpha+kappa B for the nonpositive-content prefix of each
column. If the column has no positive contents, it is complete.

For a positive content 0<x<d/2, exact algebra gives

  v_x-u_x
    = (d-2x)(dm+dx-x^2)
      / [(2m+x)(d+2m-x)(d+m-x)] > 0,

and

  (d+2m*u_x)/(d+2m)-v_x
    = m(d-x)(d-2x)^2
      / [(d+2m)(2m+x)(d+2m-x)(d+m-x)] >= 0.

During the positive-content part of a column, let U and V be the products
before the next box. The prefix includes content 0, and all u_x<=1, so
U<=u_0=2m/(2m+d). If V<=alpha+kappa*U, then after appending content x,

  alpha+kappa*U*u_x - V*v_x
    = v_x*(alpha+kappa*U-V) + alpha*(1-v_x) + kappa*U*(u_x-v_x).

Here u_x-v_x<0. Replacing U by its upper bound u_0 can only decrease the
last term. The second positive-content identity and
kappa*u_0=m/(m+d) show

  alpha*(1-v_x)+kappa*u_0*(u_x-v_x) >= 0.

Thus the affine bound is preserved when each positive-content box is added.
Every column therefore satisfies V_t<=alpha+kappa*U_t.

Apply the same concavity inequality to the column products U_t. Since
B=product_t U_t and V=product_t V_t,

  V <= product_t(alpha+kappa*U_t)
    <= alpha+kappa*product_t U_t
    = alpha+kappa*B.

Rearranging gives 1-V>=kappa(1-B), hence

  (1-B)/(1-V) <= 1/kappa = 2(m+d)/(2m+d).

If lambda_1>m, the candidate mu_m vanishes on that absent component, so
V=0 and the ratio is 1-B<=1<c0. For lambda=(1), B=u_0 and V=kappa, giving
equality c=c0. The empty partition is the scalar fixed mode; both deficits
vanish there, so the quotient is not defined and no comparison is needed.

OPEN LOAD-BEARING GATE

The proof closes only the scalar partition step under the imported candidate
eigenvalue formulas. To obtain an actual theorem, one still needs a complete
derivation with exact hypotheses of the multiplicity-free Grassmann
decomposition, the coherent-EB Berezin eigenvalues, and the actual compatible
Petz channel eigenvalues mu_m/mu_(2m). The d=4,5 exact audit above is finite
supporting evidence, not a general proof. No unrestricted broadcasting
rounding result, novelty, or priority is claimed.

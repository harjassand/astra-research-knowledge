# C13 sources and read depth

## Primary studies

1. O'Farrell A, Raj A. “Human macrophages encode stimulus-specific information of prior exposures through trained immunity.” *Cell Systems* 17 (2026), 101647. DOI [10.1016/j.cels.2026.101647](https://doi.org/10.1016/j.cels.2026.101647). [Publisher full-text landing/index](https://www.sciencedirect.com/science/article/pii/S2405471226001298). Abstract and publisher-index text inspected; full publisher page fetch returned 403. Source claims include primary human monocyte-derived macrophages, beta-glucan vs muramyl-dipeptide training, stimulus-specific recall at day 6, and durability differences through day 11.
2. O'Farrell A, Raj A. “Quantitative cytokine profiling of primary human macrophages reveals distinct single-cell modes of trained immunity.” *Cell Systems* 17 (2026), 101648. DOI [10.1016/j.cels.2026.101648](https://doi.org/10.1016/j.cels.2026.101648). [Publisher full-text landing/index](https://www.sciencedirect.com/science/article/pii/S2405471226001304). Abstract and extensive publisher-index text inspected; full publisher page fetch returned 403. Source reports >90,000 single-cell RNA-FISH measurements from 26 donors, cross-sectional temporal comparisons, gene-specific changes in response mode, and trained/untrained catch-up at later time.
3. Raj A, O'Farrell A. “Data and code from ... [the two papers above].” Dryad dataset, DOI [10.5061/dryad.stqjq2cjc](https://doi.org/10.5061/dryad.stqjq2cjc), [dataset landing page](https://datadryad.org/dataset/doi:10.5061/dryad.stqjq2cjc), [anonymous API metadata](https://datadryad.org/api/v2/datasets/doi%3A10.5061%2Fdryad.stqjq2cjc), version 448862, published 2026-06-22. Landing-page README says processed FISH measurements and figure scripts are provided; FISH metadata includes donor, condition, time, stimulus, imaging field, morphology, and spot counts. API manifest and hashes were read. Download endpoints returned 401/403, so the underlying numeric files were not acquired.

## Prior art relevant to novelty boundary

- Sheu KM, Guru AA, Hoffmann A. “Quantifying Stimulus-Response Specificity to probe the functional state of macrophages.” *Cell Systems* 14 (2023), 180–195.e5. DOI [10.1016/j.cels.2022.12.012](https://doi.org/10.1016/j.cels.2022.12.012), [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC10023480/). Prior art for single-cell immune-response specificity, information-theoretic metrics, and condition classifiers; rules out presenting those metrics alone as a C13 advance.
- Wang et al. “Macrophage memory emerges from coordinated transcription factor and chromatin dynamics.” *Cell Systems* 16 (2025), 101171. DOI [10.1016/j.cels.2025.101171](https://doi.org/10.1016/j.cels.2025.101171), [primary PDF](https://taylab.uchicago.edu/uploads/9/1/8/0/91804060/PIIS2405471225000043.pdf). Full PDF inspected. Prior art for sequential microfluidic NF-kB stimulation, signaling memory, chromatin measurements, and an integrated prediction model; no C13 novelty should be claimed for generic signaling-memory or chromatin/dynamics coupling.

1. MANDATORY RESET BOUNDARY, INCLUDING ADVERSARIAL OLD SCRATCH

Every recovery invocation is a STATELESS fixed combinational decoder circuit.
At entry to every storage round or disjoint pair/identity tile, all decoder
working registers, local message buffers and temporary control bits are fresh
or reset to their specified computational-basis initial values. Static code
tables, local incidence maps, iteration count, graph colors and the prescribed
gate schedule are hardwired circuit data. A noisy persistent instruction or
working-memory bit is not an uncharged controller resource.

The nominal reset acts correctly on EVERY old scratch state, not merely on a
scratch input already known to be zero. Its purified form may be written

 |u>_old -> |0>_working tensor |u>_retired,

with the retired register retained in the environment/garbage. This is an
isometric representation of erasure, not a declaration that the bath has been
refreshed. Readout records needed only inside the current tile are also retired
or reset before they can become working inputs of another tile. Data-qubit
errors and explicitly protected encoded resource errors remain in the data
residual invariant; they are not erased by resetting classical scratch.

Every reset, fresh-register preparation, readout, message transfer, idle, gate
and physical correction is an elementary location assigned to that tile.
Reset/preparation faults are charged to the tile containing the operation.
A fault inside a fixed-size reset gadget can change only its bounded system
support; its later influence on that tile's corrections lies in a bounded
fanout cone. It is included in the constants a,b,c and the tile fault count.
At the next tile a nominal reset removes a corrupt old working bit. A later
reset fault, if any, is separately marked there. Thus an old controller bit
cannot cause an uncharged error in a later otherwise-good tile.

The bath may retain every old record, phase, scratch value and correlation and
may participate in future MARKED faults. Those coefficients remain joint and
chronological. No bath independence, reinitialization, factorization or
finite-dimensional bath-memory assumption is used. Ideal operations on fresh
working registers do not permit unmarked system-bath fault effects.

This boundary is necessary. If a controller bit persists and is not reset or
charged again, one marked fault can flip it once and affect arbitrarily many
later corrections while the later tiles contain no marked faults. The
per-tile recurrence with a,b,c fixed would then be unjustified. T22's audit of
the local-chart decoder identified this implementation quantifier explicitly;
the present record excludes that countermodel for BOTH QTC and chart branches.

2. CONSOLIDATED DECODER AND TILE HYPOTHESES

Use a supplied positive-rate, linear-distance CSS LDPC family with bounded
check/qubit degree and constant check weight. Let the whole PHYSICAL reduced
Pauli decoder interface be

 |e+f(syn(e)+m)|_stab-red <=alpha |e|_stab-red+beta |m|,

under positive linear data/syndrome promises, implemented by a fixed-depth
bounded-fanout O(n)-gate Boolean circuit on supplied graph links.

For the independent QTC branch the source theorem is Gu et al.
arXiv:2306.12470v2 and the local compilation is A04 v2. Its component constant
alpha0 must be converted to alpha=2alpha0 for TOTAL physical Pauli support.
Choose alpha0<1/2 for memory and alpha0<1/4 for spread-two primitives.

For the optional local-chart application, Sol6 v2 Eq(5.4) already states the
whole physical alpha AFTER both CSS sectors and the binary block-to-physical

GGJ source family, actual stalk maps, fixed parameters and Sol6's decoder proof

composition. The QTC branch remains independent of accepting that application.

Let s=1 for storage and s=2 for the v3 matching-block CNOT/encoded-transfer
primitives. Use disjoint tiles: an identity tile contains one block's whole
round; a matched-pair tile contains the transversal gate ONCE, both recoveries
and all associated readout, control, reset, prep and idle operations. If the
source is consumed in transfer, its primitive locations still belong to that
pair tile. Every physical spacetime location belongs to exactly one tile.
Joint faults touching several tiles mark every touched location.

The bounded causal-cone constants a,b,c include all physical decoder/controller
and primitive operations, including the entry reset. They do not grow with n,
time or the number of blocks. A good tile has at most tau n marked locations.
Per surviving output block, input errors bounded by rho n satisfy

 r_out<=alpha(s rho+a tau)n+beta b tau n+c tau n,
 K=alpha a+beta b+c, rho=K tau/(1-s alpha).

Choose alpha<1/s and a positive tau small enough that the source decoder
promises hold at data radius (s rho+a tau)n and syndrome radius b tau n, and
2rho<d0. The QTC promise is exactly v3 Eq(3),
A(s rho+a tau)+B b tau<h. The local-chart promise is v4 Eq(1),
s rho+a tau<eta_data and b tau<eta_syndrome. All these strict inequalities
have a positive solution because their coefficients are fixed and their
right sides are positive. Then every good tile restores r_out<=rho n.

The cumulative data error is measured relative to the initially encoded
logical state and the intended logical circuit. The induction includes each
incoming residual; it is not an inference from a small syndrome alone.

3. COMPLETE COHERENT THEOREM AND EXACT GOOD-PATH QUANTIFIER

Assume a support-respecting purified circuit fault expansion

 V=sum_F W_F, E(S)=sum_(F contains S) W_F,
 ||E(S)||<=eta^|S|

in operator norm uniformly on the bath input space, for every specified set
of locations over the ENTIRE circuit. Each marked operator has system support
only on its declared bounded-arity location wires; joint correlated terms
mark their union. Outside the specified set S all other faults are summed.
No bound on each exact path W_F is substituted, and no tensor channel or
independent-round assumption is used.

Expand data operators in Paulis and nonlinear reversible controller blocks
in computational matrix units, keeping all bath factors in their original
chronological order. The reset boundary makes each invocation a fixed input
combinational circuit; a marked location has a bounded output cone. Every
fully expanded good global history is a final cumulative reduced Pauli of
weight <=rho n on each output block times the intended encoded logical
circuit C, with a logical-independent record/garbage/bath coefficient.

At a transfer tile, v3's exact covariance is

 source X(a)Z(b), target X(c)Z(d), record flip D
     -> target X(a+c)Z(b+D) |psi>,

up to a branch phase. A23 v2 independently computed that phase as
(-1)^[x dot c+D dot(a+c)] in the XZ convention; it is independent of |psi>.
The target Z(d) error cancels, and each record flip is a local target Z.
The output support is bounded by the UNION of source, target and record-flip
supports, so there is no extra factor2 beyond s=2 and the CSS alpha conversion.

For each reachable syndrome choose a physical-weight <=rho n representative
R_s. Because 2rho n<d, equal-syndrome representatives in that radius differ
only by a stabilizer. One common ideal final syndrome/encoding decoder maps
the entire good coherent sum to

 G=C tensor g.

This statement is on encoded input H_L tensor H_B, including arbitrary joint
logical/bath/reference inputs. It is NOT an unqualified round identity on
all incoming syndrome sectors. A23's exact [[5,1,3]] example remains a
counterexample to that stronger assertion: R_s=IZIII, P=IIXII, R_t=IIIZI
gives R_t^dagger P R_s=IZXZI, a logical-X class. The cumulative reduced-weight
promise, rather than only chosen syndrome representatives, prevents this
holonomy in the theorem.

4. GLOBAL MASK AND NORMALIZATION, WITH THE SAME RETAINED BATH

Suppose each disjoint tile has at most N_tile n locations and there are M
tiles. Put k=floor(tau n)+1. Exact Boolean threshold Mobius inversion yields

 b_n=binom(N_tile n,k)eta^k(1+eta)^(N_tile n-k),
 delta=(1+b_n)^M-1,
 ||V-G||<=delta.

This follows by expanding the product of all disjoint good-tile indicators
in GLOBAL aggregate cylinders. It is not a norm union bound on separately
factorized recovery channels. A22 independently reconstructed this exact mask
and its one-tile combinatorial coefficients.

If delta<1 and the decoded actual V is an isometry, the singular spectrum of
g lies in [1-delta,1+delta]. Its polar isometry h obeys
||g-h||<=delta, hence

 ||V-C tensor h||<=2delta.

After discarding syndrome/records/bath, the logical channel differs from the
ideal Ad_C by diamond norm <=4delta for every fixed initial bath state and
logical reference. The same uniform joint-isometry estimate bounds output
trace distances for initially correlated logical/bath/reference inputs.
No normalization of a selected good history, postselection or acquired bath
description is used.

For eta<=tau/(e^3 N_tile),

 b_n<=exp(-c n),
 c=tau log[tau/(e N_tile eta)]-N_tile eta
   >=(2-e^(-3))tau>0.

Thus any prescribed supported native circuit of
M<=exp(c n) log(1+epsilon/4) tiles has logical diamond error <=epsilon.
The operations available are passive memory, all corresponding logical CNOTs
between aligned identical CSS blocks, and local encoded transfer with the
specified target resource. They are a concrete native circuit class, not an
arbitrary universal logical gate set or independent addressing theorem.

5. RESOURCE AND PHYSICAL-NOISE INTERFACE

Each tile uses O(n) active data/check/controller registers, O(n) counted
elementary operations and constant GRAPH depth. q live blocks use O(qn) active
space and O(qn) operations per matching round. Total work is O(nM), with all
resets/preparations/readouts included. Graph links and constant communication
latency are supplied. Additional permitted interblock matching links must be
counted; arbitrary Euclidean/long-range routing is not proven free.

The O(n) space statement concerns active hardware registers. A repeated
protocol also requires O(n) fresh/reinitialized register uses and entropy
export per round, hence O(nM) total initialization/reset/retirement uses.
The purified mathematical environment can retain O(nM) records; its dimension
is not bounded by the active-space claim. No closed finite autonomous machine
with an unlimited clean entropy sink is asserted. Supply and disposal are
explicit resources, and their hardware operations and couplings must obey the
declared all-location fault model.

Encoded transfer consumes a supplied/preexisting protected |0_L> target of the
same code. Its previous storage errors are included in the invariant. Count
the target stocks and all their storage tiles. Initial encoding and acquisition
of that entangled code state are inputs, not free constant-depth preparation
or just-in-time resource manufacture.

For the AKP pair-Hamiltonian specialization use the CORRECTED v2 constant

 C_A=exp(1+1/(2e)), eta=C_A sqrt(2mu),
 mu=t0 max_(i,t) sum_(j!=i)||H_ij(t)||,
 mu<=eta0^2/[2 exp(2+1/e)].

This condition must cover the entire augmented quantum dilation of data,
readout/controller, message, preparation/reset and correction hardware.
AKP does not establish that an ordinary electronic controller obeys that
bound. Nominal pure-register supply, reset/entropy disposal and its physical
coupling model are explicitly imposed resources. The supplied threshold is
not a calibration/certification theorem for conventional equipment.

6. FINAL ENCODED-OUTPUT BOUNDARY

The physical memory, CNOT and transfer circuits use noisy extraction/controller
operations throughout. Their common ideal final decoder is only a logical
metric on encoded output; it is not executed inside a transfer tile. Efficient
ideal diagnostic decoding exists by repeated contraction followed by stabilizer
linear algebra, but its ideal gates are not counted as physical retrieval.

An arbitrary-accuracy bare quantum output cannot be deduced in the fixed-eta
all-location model. An allowed last output rotation exp(i theta X) with
2 sin(theta/2)<=eta obeys the singleton cylinder bound but changes the output
channel by diamond norm 2 sin(theta), independent of n. Hence a bare output
requires a separately specified protected observer/interface or exemption of
the last location. The theorem supplies actual ENCODED transfer; it does not
supply noiseless bare readout, a universal gate set, magic-state resources or
protected state acquisition.

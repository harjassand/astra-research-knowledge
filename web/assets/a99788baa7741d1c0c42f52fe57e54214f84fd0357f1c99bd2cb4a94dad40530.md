# Proof sheet: rational matrix-oracle compilation

## Model and notation

Let `f` have a minimal rational linear representation

`f(w)=λᵀ A_{w₁}⋯A_{w_k} γ`,

with hidden dimension `r≤m`, alphabet size `n`, and `f(ε)=λᵀγ=0`. Assume every reduced parameter fraction `a/b` has `|a|,b≤2^H`, `b≥1`. A query is a tuple of rational, jointly strictly upper-triangular matrices `X_i∈Q^{D×D}` with reduced entries `|p|,q≤2^B`. The full response is `F=f(X)=Σ_w f(w)X_w`. Since the `X_i` are strictly upper triangular, `X_w=0` for `|w|≥D`.

Let `q_λ,q_γ,q_A,q_X` be products of the denominators of, respectively, the entries of `λ`, `γ`, all `n r²` transition entries, and all `nD²` query entries. Write `h_j=ceil(log₂ q_j)`. Then

`h_λ≤rH`, `h_γ≤rH`, `h_A≤nr²H`, `h_X≤nD²B`.

Products may be replaced by least common multiples when denominators share factors; the product bounds are simple and always valid.

## Exact response denominator

Form `S=Σ_i A_i⊗X_i ∈ Q^{rD×rD}`. With the query index as the outer Kronecker block,

`F=(λᵀ⊗I_D)(I+S+⋯+S^(D−1))(γ⊗I_D)`.

Every entry of `S` has denominator dividing `q_Aq_X`, so entries of `S^k` have denominator dividing `(q_Aq_X)^k`. The boundaries contribute `q_λq_γ`. Thus each reduced entry of `F` has denominator at most

`Q_* = q_λ q_γ (q_A q_X)^(D−1)`,

and

`h_* = ceil(log₂ Q_*) ≤ 2rH + (D−1)(nr²H+nD²B)`.  (1)

This common denominator covers additions across all words: every summand's denominator divides the same integer `Q_*`.

## Magnitude and numerator bound

Each transition/query entry has magnitude at most `2^H`/`2^B`. For a row `(p,a)` of `S`,

`Σ_(q=1)^r Σ_(b=1)^D |S_(p,a),(q,b)| ≤ Σ_(q,b,i)|A_i[p,q]||X_i[a,b]| ≤ rDn 2^(H+B)`.

Set `L=rDn 2^(H+B)≥1`. Then `||S||_∞≤L`, `||S^k||_∞≤L^k`; the left boundary for one output entry has `ℓ₁` norm at most `r2^H`, and the right boundary has `ℓ∞` norm at most `2^H`. Therefore

`|F_(a,b)| ≤ r D 2^(2H) L^(D−1)`.  (2)

Define

`h_mag = ceil(2H+log₂(rD)+(D−1)(H+B+log₂(rDn)))`.

Then `|F_(a,b)|≤2^h_mag`. The reduced numerator has at most `h_mag+h_*+1` magnitude bits. A dense response has `D²` entries, so its worst-case exact payload is `O(D²(h_mag+h_*+1))` bits. Fixed-point output also needs `h_mag+O(1)` integer-range bits per entry.

## Rational reconstruction threshold

Let a reduced output be `x=p/q`, `q≤Q_*`. Distinct rationals with denominators at most `Q_*` differ by at least `1/Q_*²`, because `|p/q−p'/q'|=|pq'−p'q|/(qq')≥1/(qq')≥1/Q_*²` when they are unequal. If the oracle rounds to the nearest multiple of `2^(−b)` (fixed-point with `b` fractional bits), `|x̃−x|≤2^(−b−1)`. The sufficient precision `b≥2h_*+2` gives `|x̃−x|<1/(2Q_*²)≤1/(2q²)`. Legendre's continued-fraction criterion then makes `p/q` a convergent of `x̃`. Enumerate convergents with denominator at most `Q_*` and check the error bound; the unique candidate is the exact rational. This works entrywise without a union bound because the rounding bound is deterministic.

If the interface instead returns `b_sig` significant binary bits with absolute error at most `2^(h_mag−b_sig)`, the sufficient threshold is `b_sig≥h_mag+2h_*+3`. This also needs enough integer/exponent range. Under fixed-point rounding, one matrix response costs `D²(b+h_mag+O(1))` output bits.

## Per-query exact/rounded compiler costs

Let `L_X` be the bit length of the full rational query tuple; dense encoding gives `L_X=O(nD²(B+1))`. One query costs dimension `D`, one call, and `D²` returned entries. When `b≥2h_*+2`, reconstruction costs `O(D²(b+h_mag+h_*)²)` bit operations using schoolbook continued fractions, and `O(D²(h_mag+h_*))` working bits. Faster multiplication improves the arithmetic bound.

For a local exact evaluator holding `(λ,A_i,γ)`, form `S` in `O(nr²D²)` rational operations and sum its powers by `D−1` dense `(rD)×(rD)` multiplications, costing `O(r³D⁴)` rational operations; boundary contraction is lower order. With common-denominator arithmetic, intermediate bit lengths are `O(D(h_A+h_X+H+B+log(nrD))+h_λ+h_γ)`. This is a polynomial bit-operation evaluator bound, not an acquisition guarantee for an inaccessible oracle.

## Gaussian implementation of the same compiler

Suppose each scalar output entry is observed with independent noise `N(0,σ²)`, and the same query can be repeated. To simulate an exact adaptive learner using at most `T` calls of dimension at most `D`, repeat each query `s` times and average entrywise. Set `ε=1/(4Q_*²)`. Gaussian tails and a union bound over `TD²` entries show simultaneous statistical error at most `ε` with probability `1−δ/2` if

`s ≥ 32 σ² Q_*^4 ln(4TD²/δ)`.  (3)

Continued fractions then recover each exact rational, and the exact transcript is simulated with probability at least `1−δ/2`.

The ideal Gaussian model returns real values and has no finite bit cost. For a digital channel, quantize each sample to grid spacing `η=1/(4Q_*²)` and clip it to `[-R,R]`. With `s` as in (3), put `N=T s D²`, `M=2^h_mag`, and `R=M+σ sqrt(2 ln(4N/δ))`. The chance any of the `N` samples clips is at most `δ/2`; quantization changes each sample by at most `η/2=1/(8Q_*²)`. The average is within `3/(8Q_*²)<1/(2Q_*²)` of the exact rational except with probability `δ`. Each scalar sample costs `b_G=ceil(log₂(2+2R/η))` bits.

Per exact learner query, this sufficient compiler costs:

- `s` matrix calls, dimension `D` each, and cumulative per-call excitation `sE` if every repeat obeys `Σ_i X_iᵀX_i⪯E I`;
- `sD²` scalar samples and `sD²b_G` returned bits;
- `sL_X` query-description bits if inputs are retransmitted, or one `L_X` description plus protocol overhead if inputs can be cached;
- `O(sD²b_G)` bit operations to accumulate outputs, plus `O(D²(b_G+h_*+h_mag)²)` for rational reconstruction;
- total query dimension `sD` and returned-entry count `sD²`.

For `T` calls multiply by `T`, using the largest `D` and `L_X`. In an adaptive learner, issue the next exact query only after reconstructing the previous response. If a physical service charges cumulative excitation, all repeats are charged; a per-query cap does not erase that cost. Since `Q_*=2^h_*`, (3) is an explicit sufficient uniform simulation cost of order `σ²2^(4h_*)` samples per entry up to logarithms. This is generally exponential in denominator bit height; denominator separation alone does not make this cost necessary.

## Same-class lower bounds

For `w∈[n]^d`, let `f_w(u)=1[u=w]`, and compare it with zero. This class has a `0/1` acyclic realization and minimal Hankel rank `d+1`, so it belongs to the bounded-height class with `H=0`.

### Gaussian channel

Under each query cap `Σ_i X_iᵀX_i⪯E I`,

`Σ_w ||X_(w₁)⋯X_(w_d)||_F²≤D E^d`.

The adaptive Gaussian KL chain rule, convexity for the uniform mixture of hidden words, and binary data processing imply any zero-versus-word test with both errors at most `δ<1/2` has expected total query dimension

`C≥2σ²(n/E)^d kl(1−δ,δ)`.

Each full response has `D²≥D` entries, so returned-entry count has the same lower bound. At `E=1`, fixed noise and fixed `n≥2`, this is exponential in `d=r−1` even though coefficients are only `0/1`. Thus there is no uniform polynomial-cost Gaussian compiler over the bounded-height class under this excitation contract.

### A `Q_*^4` Gaussian lower bound from a same-class amplitude pair

The sufficient `Q_*^4` averaging cost above is not a lower bound merely because two bounded-denominator rationals can be close. A separate testing construction does give that order. Fix a word `w` of length `d`, let `q≥2`, and compare the two rank-`d+1` rational series

`g_0=(1/q) f_w`, `g_1=(1/(q+1)) f_w`.

Their realization entries have height at most `H=ceil(log₂(q+1))`. A designated integer, strictly upper-triangular query with a unit edge at each position of `w` obeys the `E=1` cap and returns the coefficient in one matrix entry; the two exact responses there have denominators at most `Q=q+1`. The output-mean difference for any query is `Δ X_w`, where `Δ=1/[q(q+1)]`. For any query of dimension `D`, the energy lemma gives `||X_w||_F²≤D E^d`. The adaptive Gaussian KL chain rule, with expectation under `g_0`, therefore yields

`KL(P_{g0}||P_{g1}) ≤ Δ² E^d E_{g0}[Σ_t D_t]/(2σ²)`.

If both testing errors are at most `δ<1/2`, binary data processing lower-bounds the left side by `kl(1−δ,δ)`. Hence

`E_{g0}[Σ_t D_t] ≥ 2σ² q²(q+1)² E^(−d) kl(1−δ,δ)`.

At `E=1`, this is `Θ(σ² Q^4)` for fixed `δ`, and the full returned-entry count is at least as large. This is a lower bound for the specified two-target Gaussian testing task, derived from signal amplitude and excitation; it is logically separate from the generic rational-reconstruction upper bound. If query dimension is capped by `D_max`, it also implies at least this bound divided by `D_max` calls.

### Fixed-grid information-loss lower bound

For `f_w` versus zero, suppose every exact response is rounded to the nearest multiple of `q_grid=2^(−b)`. Couple both algorithms on the same private randomness and follow the null transcript. Define `Z_w=Σ_t ||X_{w_1}⋯X_{w_d}||_F²` along it. If `Z_w<q_grid²/4`, every entry of every hidden-word response is strictly below `q_grid/2`; all answers round to zero, so the transcripts never diverge. The two error bounds imply divergence probability at least `1−2δ` for each word. Markov's inequality and the word-energy lemma then give

`E_0[Σ_t D_t] ≥ (1−2δ) 2^(−2b−2) (n/E)^d`.

This is a fixed absolute-grid obstruction (and hence also a returned-entry lower bound); it does not apply to floating-point output with unbounded exponent.

### Absolute fixed-point rounding

Suppose instead exact responses are rounded entrywise to nearest multiples of `q=2^(−b)`. Couple runs on zero and `f_w` with the same random bits until the first different rounded response. Along the null transcript set `Z_w=Σ_t ||X_(w₁)⋯X_(w_d)||_F²`. If `Z_w<q²/4=2^(−2b−2)`, every hidden-word output entry is below `q/2`; each response rounds to zero and the transcripts never diverge.

Testing errors at most `δ` force divergence probability at least `1−2δ` for every `w`: under the coupling, the nonzero-output probability is at most the null false-positive probability plus the divergence probability. Markov's inequality and the word-energy bound give

`C≥(1−2δ) 2^(−2b−2) (n/E)^d`.

This fixed-point lower bound concerns absolute resolution near zero; it does not apply to floating point with unbounded exponent and relative precision. It shows that constant absolute precision requires exponential total dimension/entry cost on this family. The continued-fraction threshold guarantees reconstruction for all bounded-height rational outputs; this lower bound separately exhibits information loss for a specific family below adequate absolute resolution.

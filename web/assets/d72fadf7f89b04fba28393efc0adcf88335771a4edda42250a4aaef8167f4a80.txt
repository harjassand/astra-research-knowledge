LINEAR VERSUS SQUARED COHERENT EB DOMINATION
8 October 2026. Independent sharpness audit for the exact SU(2)-covariant,
bistochastic, genuinely 1-to-2-compatible interface.

VERDICT

The audited all-spin squared lift is compatible with a dimension-free
linear lift, but its proof does not imply one. I have not derived either
(a) a legal sequence for which the coherent linear ratio diverges or
(b) a dimension-free linear domination theorem. The all-mode linear
question therefore remains UNKNOWN.

There is an exact finite falsifier to the tempting factor-two strengthening
for the fixed coherent comparator. At spin j=2, an actual symmetric,
SU(2)-covariant two-output extension has a rank-three multiplier
lambda_3=(17+3 sqrt(41))/56, while the coherent EB multiplier is mu_3=1/14.
Thus any linear constant for this particular channel/comparator must be at
least

  (1-mu_3)/(1-lambda_3)
     =13(13+sqrt(41))/96
     =2.62750640715237... .

This refutes C=2 for Psi_coh, not every finite C. In particular, it is not
a sequence proving structural necessity of the square. The full exact
calculation is replayable with
work/programmes/classicality/leaves/linear_vs_squared_sharpness_check.py.

1. SCALAR FORM OF THE QUESTION

Let n=2j, d=n+1, and let Phi be an SU(2)-covariant, bistochastic UCP
channel with an actual joint UCP map J:M_d -> M_d tensor M_d whose two
marginals are Phi. Multiplicity-free covariance gives real multipliers
lambda_l on l=0,...,n. The coherent measure/prepare channel has

  mu_l = product_{r=0}^{l-1} (n-r)/(n+r+2).

Consequently, for this fixed comparator,

  I-Psi_coh <= C(I-Phi)

is exactly the scalar family

  1-mu_l <= C(1-lambda_l),  l=1,...,n.                 (1)

Define R_{n,l}(Phi)=(1-mu_l)/(1-lambda_l). A dimension-free linear lift
exists precisely when sup_{n,l,Phi} R_{n,l}(Phi) is finite over the stated
actual-compatible class. The already-audited squared result says instead

  (1-mu_l)^2 <= C_sq(1-lambda_l)                     (2)

for one finite, non-effective C_sq. This only gives
R_{n,l} <= C_sq/(1-mu_l). Hence an unbounded linear ratio, if it exists,
must occur along a sequence with mu_l -> 1. From the exact product,
1-mu_l -> 0 is equivalent to l(l+1)/n -> 0. Modes with coherent loss
bounded below cannot obstruct linear domination: if 1-mu_l >= eps, then
(2) gives R_{n,l} <= C_sq/eps. The unresolved regime is therefore the
low-multipole scale l=o(sqrt(n)), not the Racah high-mode regime that
closed the squared theorem.

2. EXACT COMPATIBLE SPIN-2 COUNTEREXAMPLE TO C=2

Use the normalized Choi convention in which Omega_RAB has trace one and
the reference carries the conjugate spin-2 representation. For the
rank-three tensors T_{3q}, normalized by Tr(T_{3q}^* T_{3q})=5, the Choi
multiplier functional is

  W_3 = (1/7) sum_{q=-3}^3 conjugate(T_{3q})_R tensor T_{3q,A}
                       tensor I_B,
  lambda_3 = Tr(Omega W_3).

Couple outputs A,B first to J=0,2,4, and then couple the conjugate
reference spin 2 with J to total F=2. Write |J;F,M> for these normalized
intertwiners. The J=0,2,4 sectors are symmetric under swapping A,B. On the
F=2 multiplicity space, the exact matrix of W_3 is

  K = [ 0,                 0,              0             ]
      [ 0,                16/49,           15 sqrt(5)/98 ]
      [ 0,          15 sqrt(5)/98,          55/196       ].

Its top eigenvalue and a corresponding multiplicity vector are

  lambda_3 = (17+3 sqrt(41))/56,
  (c_0,c_2,c_4) proportional to
       (0, 1, (7 sqrt(41)-3)/(20 sqrt(5))).

Normalize this vector and define

  |chi_M> = c_2 |J=2;F=2,M> + c_4 |J=4;F=2,M>,
  Omega = (1/5) sum_{M=-2}^2 |chi_M><chi_M|.

This is a positive trace-one invariant Choi state. Since the A,B sectors
J=2,4 are symmetric, Omega is invariant under the output swap, so its two
output marginals are equal. Invariance and irreducibility make each
one-body marginal I/5; hence Omega is the normalized Choi state of a
genuine bistochastic SU(2)-covariant common marginal with an actual
two-output extension. These are not just necessary compatibility
inequalities or a one-output CP example.

At n=4,l=3, the coherent eigenvalue is

  mu_3 = 4! 5!/(1! 8!) = 1/14.

Substitution in (1) yields the exact lower bound on C shown in the
verdict. For C=2 the modewise PSD inequality fails. The script checks the
exact K matrix, the top eigenpair, all three Choi marginals, and output
swap symmetry with SymPy algebraic arithmetic.

The example says the fixed coherent orbit is too restrictive to claim the
sharp factor 2. This is consistent with the separate spin-2 theorem
SPIN2_PROOF.txt: that theorem can choose a channel-dependent EB
comparator. It does not show that Psi_coh requires an unbounded constant
as j grows, and does not refute existence of a different universal EB
selector.

3. LEGAL-SEQUENCE CHECK AND REMAINING GATE

The standard symmetric spin-j 1-to-2 cloner is an actual compatible
sequence. Its rank-one multiplier is lambda_1=(n+1)/(n+2), whereas
mu_1=n/(n+2); hence R_{n,1}=2 for every n. This supplies the familiar
factor-two lower bound but no divergence.

For the broader exact invariant extension class, the Choi variables can
be organized by total spin F and the multiplicity labels J of symmetric
AB sectors (J=n mod 2, n mod 2+2, ..., n). For each F, a positive
multiplicity matrix C_F gives an invariant Choi block. Its l-multiplier is
the linear functional Tr(C_F K^{(l,F)}), where K^{(l,F)} is obtained by
compressing W_l to the coupled |(AB)J, Rbar;F,M> intertwiners. Thus the
largest possible lambda_l at fixed n,l is the largest eigenvalue among
these finite matrices. This includes coherent off-diagonal terms between
different J with the same F; using only diagonal projectors would miss
the spin-2 falsifier above.

The needed all-d statement is now precise: prove a uniform gap below one,

  1 - max_F lambda_max(K^{(l,F)}) >= c (1-mu_l)

for some c>0 independent of n,l, or find n_k,l_k,F_k and legal
multiplicity states for which the ratio tends to infinity. The available
Stinespring/Racah argument proves only a quadratic lower bound in
1-mu_l. It leaves exactly the l=o(sqrt(n)) regime above. No such legal
sequence or analytic linear bound was found in this audit.

4. NOT THE TRACE-POWER CLAIM OR THE UNRESTRICTED PROBLEM

The squared comparison is the right input for the audited positive-spectrum
power estimate. Since Phi and Psi_coh are simultaneously diagonal in
multipoles,

  |(1-mu_l) lambda_l^m|^2
      <= C_sq (1-lambda_l) lambda_l^{2m},

and max_{0<=t<=1}(1-t)t^{2m} <= 1/(2m+1), giving the established
O(m^{-1/2}) infinity-to-trace bound. This trace functional does not imply
(1), and the spin-2 failure of C=2 does not affect it. If a linear lift
were proved, it would be stronger: on nonnegative spectrum it would yield
the modewise bound C^2(1-lambda_l)^2 lambda_l^{2m}, whose maximum is
O(C^2/m^2), hence an O(C/m) norm estimate. Neither power statement is an
argument that linear domination holds.

All conclusions here retain the supplied exact covariance, bistochasticity,
and actual common two-output extension. They do not promote the result to
arbitrary channels, and they neither establish nor refute an implication
from bounded Holevo information or an N93 reconstruction claim. Those need
separate covariance/compatibility reductions with their errors charged.

STATUS: UNKNOWN for existence of any dimension-free linear constant for

spin-2 witness above. The squared all-spin lift remains a separate,
stronger-in-scope but weaker-in-order result.

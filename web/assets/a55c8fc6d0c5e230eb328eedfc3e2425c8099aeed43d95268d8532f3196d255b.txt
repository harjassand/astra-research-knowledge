ANYTIME TERMINAL PREDICTION FOR STATIONARY FINITE-MEAN RENEWALS
2026-10-08

Outcome
=======

YES for the stated anytime interface: one causal algorithm can output a
prediction after every nonempty observed prefix without being told a final
sample size. At prefix length t it runs the verified fixed-length
suffix-average predictor using the current-length block assignment Q_{t+1}.
It never treats Q_{t+1} as a marginal of another Q_N. The outputs define a
new projective sequential law by multiplication of their conditional
probabilities. This does not make the fixed-block family (Q_N) projective.

For every t>=1 and every stationary binary renewal process with iid positive
integer gaps of arbitrary finite mean, the same-path terminal expected-KL
risk satisfies

  E_mu KL(P_mu(X_{t+1}|X_1^t) || qhat_t(.|X_1^t))
    <= [pi sqrt(2t/3)+2 log(t+1)+log 2+log(t+2)]/t
    <= 8/sqrt(t).

Logs are natural; 8 is a convenient bound, not an optimized constant. No
uniform mean, tail, support, mixing, reset, or fresh-history assumption is
used. The finite-mean assumption only defines the stationary renewal law and
its equilibrium residual wait. HJW's fixed-horizon minimax lower bound gives
the matching Theta(t^{-1/2}) order at each t.

This is an anytime wrapper around the type-first code and exact suffix DP in
`outputs/research/acquisition_learning/cycle4/renewal_integer_code/RESULT.txt`.
It is not a new block-code derivation or a novelty claim. Priority remains
UNKNOWN.

Interface and rule
==================

The input is one raw binary path. After observing x_1,...,x_t the learner
predicts X_{t+1}. It knows current length t, but no terminal horizon T is
announced. Its state stores the raw prefix and t. When a bit arrives, append
it and compute the output for the new prefix. The input does not include
event queries, hidden ages, resets, or independent trajectories.

Let Q_L be the full-support type-first probability assignment on length-L
binary blocks. At time t, set L=t+1 and output

  qhat_t(.|x_1^t) = (1/t) sum_{s=1}^t
       Q_{t+1}(X_{s+1}=.|X_1^s=x_{t-s+1}^t).

Every summand is a conditional from the SAME block law Q_{t+1}, and the
suffix comes from the observed history. No conditional is borrowed from a
different block length. Thus the average is a proper categorical
distribution. Full support of Q_{t+1} makes both probabilities positive.

Projective law generated by the online outputs
===============================================

Define the sequential assignment, for T>=1, by

  Rhat_T(x_1^T)=(1/2) product_{t=1}^{T-1} qhat_t(x_{t+1}|x_1^t).

Since each qhat_t sums to one, summing Rhat_{T+1} over its last symbol
returns Rhat_T. Hence (Rhat_T) is one projective family and its conditionals
are exactly the online outputs. It is generally different from Q_T.

The distinction is necessary. Under the type-first code,
Q_2(X_1=1)=1/2 but Q_3(X_1=1)=17/30. At length 2 the masses are
Q_2(00)=1/3, Q_2(10)=Q_2(01)=1/6, Q_2(11)=1/3. At length 3 the type
classes give Q_3(000)=1/5, Q_3(100)=Q_3(010)=Q_3(001)=1/15,
Q_3(110)=Q_3(011)=1/10, and Q_3(101)=Q_3(111)=1/5. Thus Q_2 is not
the length-2 marginal of Q_3. The proof below never uses such an identity.

Risk proof at every prefix
==========================

Fix any t>=1 and stationary renewal law mu. Han--Jiang--Wu (HJW)
Proposition 1 applies to the length-(t+1) stationary block and any joint
assignment on that block, including Q_{t+1}. It constructs exactly the
suffix-average predictor above and gives

  Risk_t <= Red(Q_{t+1};P_mu^{t+1})/t
       + (1/t) sum_{s=1}^t I(X_{t+1};X^{t-s}|X_{t-s+1}^t).

The type-first code proves

  Red(Q_{t+1};P_mu^{t+1})
       <= pi sqrt(2t/3)+2 log(t+1)+log 2.

Its likelihood proof uses only that the equilibrium left-residual mass and
right-censor survival mass are at most one; it imposes no tail bound. For
the memory term, represent the source by its stationary countdown state
Z_1, the positive time to the next renewal. HJW's hidden-state information
inequality bounds the sum by I(Z_1;X^{t+1}). Clip Z_1 to its exact value up
to t+1 and a sentinel for larger values. In the sentinel case the whole
length-(t+1) block is zero; otherwise the capped state retains the exact
initial countdown. The capped state has t+2 values, so

  I(Z_1;X^{t+1}) <= log(t+2).

No finite entropy assumption on the untruncated countdown is needed. These
steps prove the displayed risk bound for every t, on the same single
stationary trajectory. They do not use projectivity of Q_L.

For the explicit constant, log(t+1)<=log(2t) and log(t+2)<=log(3t).
After multiplying the numerator's log terms by 1/sqrt(t), their total is at
most 3 log 2+log 3+3 log(t)/sqrt(t). Since
sup_{t>=1}log(t)/sqrt(t)=2/e, this is less than 5.39. The partition term
contributes pi sqrt(2/3)<2.57, so 8 suffices.

The projective assignment also obeys an expected cumulative-KL bound. By the
chain rule, for every T,

  KL(P_mu^{1:T}||Rhat_T)
   = KL(P_mu(X_1)||Ber(1/2))
     + sum_{t=1}^{T-1} E_mu KL(P_mu(X_{t+1}|X_1^t)
                               ||qhat_t(.|X_1^t))
   <= log 2 + 8 sum_{t=1}^{T-1}t^{-1/2}
   <= log 2+16 sqrt(T).

This is expected KL, not a pointwise likelihood-ratio guarantee for Rhat_T.

Per-prefix output and update costs
==================================

The scratch wrapper is
`work/programmes/acquisition_learning/cycle4/renewal_anytime/anytime_predictor.py`.
Appending an observation to its state costs O(1) input bits/time. To emit
the new prediction it reruns the exact current-length predictor on the
retained history. The shared suffix DP in
`work/programmes/acquisition_learning/cycle4/renewal_integer_code/predictor.py`
uses O(t^3) coefficient/summand updates for all suffixes together, with
O(t^2) table cells and O(t)-bit table coefficients. Common denominator
products for a suffix conditional use O(t^2 log(t+2)) bits; the average of
t rational conditionals has O(t^3 log(t+2)) bits under a denominator-product
bound. Therefore each output has polynomial exact bit cost. A conservative
schoolbook upper bound, allowing quadratic multiplication/gcd on
O(t^3 log(t+2))-bit intermediates for O(t^3) updates, is
O(t^9 log^2(t+2)) bit operations per prefix. Working and output storage is
O(t^3 log(t+2)) bits. These are charged symbolic upper bounds, not measured
runtime claims.

Recomputing at each length through T costs O(T^4) coefficient/summand
updates and at most O(T^10 log^2(T+2)) bit operations. No sublinear-memory
or sub-polynomial incremental update is claimed. If the exact cumulative
mass Rhat_T(x_1^T) is also maintained, its denominator length grows by at
most the sum of conditional output lengths, O(T^4 log(T+2)), still
polynomial.

At a declared terminal n, this returns exactly the fixed-horizon predictor.
In anytime use it recomputes that predictor at each new prefix; through T
the update count is O(T^4), versus one O(T^3) terminal computation. Both
interfaces use the same raw path and information. The projective law comes
from the online conditionals, not by forcing Q_N to be consistent.

Primary source and limits
=========================

Y. Han, T. Jiang, Y. Wu, “Prediction from compression for models with
infinite memory, with applications to hidden Markov and renewal processes,”
arXiv:2404.15454v1 (2024-04-23), Proposition 1/equation (8) for stationary
suffix averaging, Theorem 4 for the binary stationary finite-mean renewal
minimax rate, and Section 3.4 for the countdown memory argument. The paper
states that its optimal-rate renewal predictor is not computationally
efficient and polynomial-time attainment is unclear. The published
COLT/PMLR version numbers the renewal theorem differently.

  https://arxiv.org/html/2404.15454v1
  https://proceedings.mlr.press/v247/han24a.html

The source proves a fixed-sample theorem, not this anytime wrapper or a
projective block code. The construction here applies its argument separately
at each current prefix length and then forms a new sequential law. No broad
anytime-prior-art search or external proof review was performed; priority
and novelty remain UNKNOWN.

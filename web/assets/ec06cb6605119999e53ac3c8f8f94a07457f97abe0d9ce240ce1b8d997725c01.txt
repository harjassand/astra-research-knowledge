PREDICTIVE AUTOMATON QUERY FRONTIER: A RESTRICTED PATH FAMILY
Research leaf | 2026-10-08

Result and scope
----------------
This gives a clean membership-only separation for acquiring an unknown
minimal predictive automaton in a deliberately narrow class. For horizon cap
H, exact fixed nonadaptive membership queries require and suffice with
M-1 = 2^(H+1)-2 calls; adaptive membership queries need between H+1 and 2H
calls. Thus the adaptive order is sharply Theta(H), versus Theta(2^H) for a
fixed query list. A passive IID prefix-query stream with exact labels has
minimax sample complexity Theta(M log(1/delta)) for 0<delta<1/4, with no
extra log M factor. With BSC response noise, a KL lower bound is
Omega(M kl(1-delta||delta)/d_epsilon), and an explicit traversal learner
uses O(M log(H/delta)/(1/2-epsilon)^2) samples. The remaining log H factor
in the noisy passive bound is unresolved here.

This is not a general algorithm or lower bound for arbitrary hidden HMMs,
weighted automata, or Hankel-basis discovery. The transition-graph template is
known; the path word and hence the minimal rank are hidden. It is a scoped
oracle-cost theorem and a counterexample to treating strong equivalence
oracles as free scalar membership access.

Interface and target class
--------------------------
Fix H>=1 and alphabet Sigma={0,1,#}. The supplied information is H, Sigma,
and the promise below. The hidden object is a word w in {0,1}^{<=H}; there
are M=1+2+...+2^H=2^(H+1)-1 candidates. Put t_w=w# and let

    L_w = Pref(t_w) = {epsilon, t_w[:1], ..., t_w}.
    f_w(x) = 1{x in L_w}, x in Sigma*.

The learner receives no w, transition table, state labels, rank, Hankel
basis, or target matrix. Its objective is to output the exact predictive
function f_w, equivalently its minimum DFA modulo state renaming. A membership
query names any x in Sigma* and returns the single bit f_w(x). In the noisy
version it returns f_w(x) XOR Z, with independent Z~Bernoulli(epsilon),
known 0<=epsilon<1/2. The cap H is known, while the realized terminal depth
|w|+1 and rank are unknown. Accuracy is
max_w P_w[wrong semantic function]<=delta.
Query addresses are not free; their length is charged below.

The unknown minimal DFA has |w|+3 states: one state for each of the |w|+2
accepted prefixes of w#, plus a dead state. The real Hankel matrix
H_f(u,v)=f(uv) has rank |w|+2. Every accepted prefix has a distinct nonzero
residual, and any non-prefix has zero residual, so rank is at most |w|+2.
For the lower bound, index rows by prefixes t[:i] and columns by tails
t[j:] (0<=i,j<=|t|). The resulting square minor has ones on the diagonal,
ones in its last column, and zeros elsewhere; its determinant is 1. Thus the
rank is exactly |w|+2, unknown in {2,...,H+2}. These are semantic claims:
renaming DFA states changes no target, and any weighted realization is
identified only up to transformations preserving f. For row-vector
convention, the usual similarity gauge alpha'=alpha*S,
A'_a=S^(-1)*A_a*S, beta'=S^(-1)*beta preserves every scalar
alpha*A_x*beta. Raw matrix syntax is not the target.

Exact fixed versus adaptive membership queries
-----------------------------------------------
For any membership address x, its positive-target set is one of:

  * if x=p is binary, S_p={w: p is a prefix of w};
  * if x=p# with p binary, the singleton {p}, when |p|<=H;
  * a constant set, for all other x (including epsilon, which is always
    accepted).

The nonconstant sets are laminar: two prefix subtrees are nested or disjoint,
and each terminal singleton is nested in its ancestor subtrees or disjoint
from them. Adding one laminar set to a query family can split at most one
existing response atom, so q fixed addresses induce at most q+1 distinct
response patterns. Exact identification of M candidates therefore needs
q>=M-1. Querying p# for every p except one candidate uses M-1 calls and gives
distinct patterns, proving the exact nonadaptive optimum. The same M-1 floor
holds for a fixed schedule under BSC noise: a collision of exact response
patterns gives identical noisy transcript laws. For 0<epsilon<1/2, the
parent-child edge argument below also gives the precision lower bound
q>=N*kl(1-delta||delta)/(3*d_epsilon) for a fixed schedule, since each
address can separate at most three such edges.

A simple noisy fixed-design upper asks every p# singleton r times and returns
the maximum-likelihood target. For each rival, the likelihood test differs
on the two terminal coordinates for the target and rival, so a Chernoff
bound is exp(-2r*J_epsilon), where
J_epsilon=-ln(2*sqrt(epsilon*(1-epsilon))). Taking
r>=ln((M-1)/delta)/(2*J_epsilon) gives q=M*r. This upper is included for
accounting; its log M factor is not claimed optimal.

For adaptive exact queries, a binary decision tree needs at least
ceil(log2 M)=H+1 responses. The following prefix walk uses at most 2H:
maintain a known target prefix p, initially epsilon. If |p|=H, stop. Ask
whether p0 is accepted. If yes, set p<-p0. If no, ask whether p# is accepted;
if yes, output p, otherwise set p<-p1. At each step these answers determine
whether w ends at p or which bit follows p. Consequently

    H+1 <= Q_adaptive(H) <= 2H,   Q_adaptive(H)=Theta(H),
    Q_nonadaptive(H) = M-1 = 2^(H+1)-2.

The factor-two interval for the optimal adaptive constant is deliberately
left open; the theorem establishes the sharp linear-versus-exponential
frontier, not an exact adaptive count. Every response is one bit. The adaptive
walk uses O(H) responses, stores O(H) bits for w, and sends O(H^2) address
symbols in the literal per-query-string interface. The exact fixed design
uses M-1 response bits and Θ(H 2^H) address symbols if all words p# are sent
literally. A packed address alphabet uses at most two bits per symbol.

Passive IID trajectory baseline
-------------------------------
Define a passive learner precisely as follows. Before seeing any labels, it
chooses a distribution mu over membership addresses x in Sigma* (mu may
depend on H, epsilon, delta), and receives n independent pairs
(X_i, f_w(X_i)) with X_i~mu; the input schedule is independent of w and no
query is selected from earlier responses. In the noisy case the label is
passed through the BSC above. The minimax is over w. This is the best
designer-chosen IID scalar-trajectory interface, not a fixed deterministic
list and not Angluin's equivalence oracle.

Exact labels: let N=M-1=2^(H+1)-2 and sample uniformly from
U={p in {0,1}*: 1<=|p|<=H}. The exact decoder returns the unique v consistent
with all observed labels, if there is one. For true w with 0<|w|<H, the
certificate C(w)={w,w0,w1} has labels (1,0,0) and uniquely distinguishes w
from every v!=w. For w=epsilon use C(w)={0,1}, both negative; for |w|=H,
C(w)={w}, positive, already unique under the cap. If all addresses in C(w)
appear, the consistent hypothesis is exactly w. A union bound gives

    n >= N ln(3/delta)

as a sufficient sample count up to rounding (replace 3 by 2 for the
short/maximum-length cases).

The passive input itself is observed and charged: uniform U has mean address
length Theta(H), so n examples carry Theta(nH) input symbols, plus n one-bit
labels (or n noisy one-bit labels).

For a lower bound that allows arbitrary designer-chosen mu over all query
strings, consider each parent-child edge e=(u,c=u0 or u1). The two semantic
functions differ only on D_e={c,c#,u#}. A binary query address c belongs to
one such D_e; a terminal address v# belongs to at most the three edges
incident to v. Hence sum_e mu(D_e)<=3 and some edge has mu(D_e)<=3/N. If no
sample address falls in D_e, the two targets generate identical transcripts.
For any estimator, its maximum error on that pair is at least half this
miss-event probability. Thus, for 0<delta<1/4,

    n >= ln(1/(2 delta)) / [-ln(1-3/N)] = Omega(N ln(1/delta)), for N>=4.

Together with the uniform certificate construction, this proves the exact
label passive minimax order Theta(M ln(1/delta)); no simultaneous log M
factor is needed. This conclusion uses the target-specific certificate and
the fact that exact labels at unrelated sampled addresses cannot contradict
the truth.

Noisy labels: for 0<epsilon<1/2, write g=1/2-epsilon,
d_epsilon=(1-2epsilon) ln((1-epsilon)/epsilon), and
kl(a||b)=a ln(a/b)+(1-a)ln((1-a)/(1-b)). For the edge e above, one sample
has KL divergence mu(D_e)*d_epsilon between the two transcript laws. Data
processing from an estimator with max error delta gives

    n >= N*kl(1-delta||delta)/(3*d_epsilon).

This lower bound charges a one-bit noisy answer and holds for every
designer-chosen IID mu. It has the right M dependence for fixed epsilon and
fixed confidence.

An explicit noisy passive upper bound samples uniformly from U and stores,
for every queried p, its empirical majority. Traverse from epsilon. At each
prefix p of length <H, use the majority labels of p0 and p1: (1,0) moves to
p0, (0,1) moves to p1, and (0,0) stops at p. If (1,1) occurs, return an
arbitrary candidate. On the true target path, at most 2H addresses are
consulted and their true labels uniquely trace w. Set

    r = ceil(ln(4H/delta)/(2g^2)),
    n = N*ceil(max(2r, 8 ln(4H/delta))).

For each of the at most 2H path addresses, a Chernoff bound gives probability
at most exp(-n/(8N)) that fewer than r samples arrive. Conditional on at
least r arrivals, Hoeffding bounds its wrong majority by exp(-2rg^2).
Union over those path addresses gives error at most delta (with slack in the
constants above). Thus n=O(M g^-2 ln(H/delta)). This incurs log H from the
pathwise union bound, not log M from testing all M hypotheses. Whether that
log H factor can be removed, or is necessary for BSC labels under this
passive interface, remains unresolved. The exact-label passive theorem above
does remove log M entirely.

Adaptive noisy membership queries: each BSC answer carries at most
C_epsilon=1-h2(epsilon) bits, so Fano's inequality under the uniform target
prior gives

    q >= [log2 M-h2(delta)-delta*log2(M-1)]/C_epsilon.

Repeating every query in the exact prefix walk r times and taking majority,
where r=ceil(ln(4H/delta)/(2g^2)), gives q<=2H*r with error at most delta.
This is a Theta(H) versus Theta(M) query/sample frontier in the noiseless
case, and an Omega(H/C_epsilon) active lower bound against the passive
Omega(M/d_epsilon) noisy lower bound. The elementary noisy upper bounds leave
log H and constant/channel-factor gaps; no sharper noisy-search theorem is
claimed.

How an equivalence oracle hides acquisition cost
-------------------------------------------------
Now change the contract: an equivalence query submits a proposed language K;
the oracle returns YES if K=L_w and otherwise any string in K symmetric-
difference L_w. This is the minimally-adequate-teacher interface of
Angluin, not a scalar membership response. Submit K={epsilon}. For every w,
the string w# lies in L_w and not K, so an oracle that chooses this informative
counterexample returns the complete hidden word in one call. The returned
payload costs |w|+1 symbols (Theta(H) in the worst case), and the teacher's
search and access to the target are required to find it. Counting this as one
free oracle call hides both the model-side search and the O(H)-symbol
counterexample. An arbitrary valid-counterexample policy need not return the
informative witness; Angluin's theorem counts membership/equivalence queries
and bounds dependence on counterexample length, while this leaf charges the
payload and identifies the extra teacher capability explicitly. Membership-
only lower bounds do not apply after adding this stronger oracle.

Finite exact verifier
---------------------
`work/programmes/acquisition_learning/leaves/predictive_automaton_query_frontier/verify.py`
enumerates all targets through H=3, verifies the adaptive walk's output,
counts its responses, checks the terminal Hankel minor, and exhaustively
enumerates all query subsets for H=1,2 to check the laminar response-pattern
bound. It explicitly checks the marker-sensitive example t=000#: the entry
i=1,j=2 is f(0·0#)=0, while i=1,j=|t| is f(0·epsilon)=1. Replay:

    python3 work/programmes/acquisition_learning/leaves/predictive_automaton_query_frontier/verify.py

    all prefix languages, DFA-state counts, and Hankel minors H<=3: PASS

The exhaustive fixture is finite evidence for the implementation and small
instances only; the proofs above establish the stated general bounds.

Primary sources and status
--------------------------
- Dana Angluin, “Learning Regular Sets from Queries and Counterexamples,”
  Information and Computation 75(2), 87–106 (1987), DOI
  https://doi.org/10.1016/0890-5401(87)90052-6. This defines membership and
  equivalence queries; a negative equivalence answer is a counterexample in
  the symmetric difference. The current result is a finite-class
  membership-only specialization, not a claim against L*.
- J. W. Carlyle and A. Paz, “Realizations by Stochastic Finite Automata,”
  Journal of Computer and System Sciences 5(1), 26–40 (1971), DOI
  https://doi.org/10.1016/S0022-0000(71)80005-3. It relates finite Hankel
  rank to finite sequential realizations. Our rank calculation is direct for
  this finite prefix function and does not acquire a general basis.
- Laure Daviaud and Marianne Johnson, “Feasibility of Learning Weighted
  Automata on a Semiring,” Logical Methods in Computer Science 21(3), 15
  (2025), DOI https://doi.org/10.46298/lmcs-21(3:15)2025. It formalizes
  membership as f(w) and equivalence as testing a proposed weighted automaton
  plus a counterexample; it studies limitations of Angluin-style systems of
  linear equations over semirings. It reinforces that access and algebraic
  assumptions matter, but is not used as a lower-bound dependency here.

Status: INTERNALLY-PROVED-CANDIDATE for the exact membership bounds, exact
passive IID order, DFA size, and Hankel rank; CONDITIONAL for stated noisy
upper/lower bounds under independent known BSC noise; FINITE-EVIDENCE for the
small verifier. No novelty or priority claim. Representation-acquisition
connection is limited: the hidden rank/path is recovered only in a supplied
one-path template. The unresolved general problem remains acquisition of
unknown predictive directions/observable Hankel bases for arbitrary finite
rank systems, with model-selection and witness-oracle costs charged.

L02: LOCALIZATION, FANO, AND FINITE WINDOWS

extends to normalized volume on a positive-volume full-flow invariant set A.
Its work localization is a useful conditional corollary: integral_A |S|^2 >=
2 mu(A) h_muA(phi_1)^2. It is absent as an explicit result in the three frozen
Sol INITIALs, but introduces no different exponent/strain mechanism.

INITIAL uses two actual finite-valued observables c and c-hat on A, with
h(c-hat)>=R. Then the factor inequality ALREADY implies h_muA(phi_1)>=R.
The displayed [R-F_K(delta)]_+ lower bound is valid but strictly weaker than
the bound with R, independent of mismatch. Its interpretation as a necessary
noise/acquisition interface is redundant in that initial interface.

The cross-exposure revision repairs this by using an EXTERNAL stationary
reference Q and a stationary joining to the physical readout factor. The block
Fano argument gives h(physical)>=h(Q)-F_K(delta). The local code set C need
only be invariant under phi_tau and lie where X!=0 a.e. Oseledec's theorem
applies to bounded derivative cocycles on the ambient compact manifold; the
flow direction exponent is zero by boundedness plus recurrence to a set where
|X| is bounded below. This avoids an unsupported integrability assumption on
log|X| near zeros. Normal quotient exponents consequently have zero sum.
For x in C, the top exponent per unit time is bounded by the phi_tau ergodic
average of (1/tau)integral_0^tau s(phi_t x)dt. Ruelle and Jensen therefore give
 beta(h_eta(phi_tau)/tau)^2 <=

Since |S|^2>=2s^2 on U, the claimed work bound follows. Its localization and
Fano components are explicitly joint post-exposure contributions from L06/L10
as well as L02, not a solo independent L02 result.

The de Bruijn counterexample is valid for every integer N: a directed de Bruijn
graph Euler cycle yields q=2^N bits whose cyclic n-word counts are 2^(N-n),

form' needs a volume-compatible embedding lemma. One explicit repair uses a
smooth area-preserving isotopy from id to f supported in the disk (standard
disk Hamiltonian isotopy premise), converts the mapping torus to a product
Hamiltonian suspension, and embeds its product-volume solid torus through

Its Euclidean volume is exactly ds dtheta dz. Scaling theta=2pi t only changes

gadget vanishes in a collar, so extension by zero is smooth and divergence-free.
Alternatively a correctly stated relative-volume Moser embedding closes this
routine geometry step. This review records the imported isotopy/embedding
premise; it does not claim a constructive gadget compiler.

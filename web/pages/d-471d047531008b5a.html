EXACT ANCILLARY / COHERENT BRANCH FAILURES AND REMAINING SCOPE
9 October 2026. quadratic_dilation_sol, Cycle05.
These are scoped exact failures, not impossibility proofs for all quantum
architectures. No source or earlier frozen file is modified.

1. A FIXED LABEL-INDEPENDENT ANCILLARY CATALYST IS EXACTLY NEUTRAL

Let E be a state family on H and let kappa be ANY fixed density on K.
Define E_ext={rho tensor kappa:rho in E}. Under the same full-domain
common-channel/HALF-error definitions,

 b2(E_ext)=b2(E), e(E_ext)=e(E), R(E_ext)=R(E).        (1)

For any full-domain extended broadcaster, prepare kappa on input and
trace K from both outputs. This is a full-domain CPTP broadcaster on H;
trace contractivity gives b2(E)<=b2(E_ext). Conversely trace the input
ancilla, apply any broadcaster on H, and prepare kappa at each output.
This is full-domain CPTP and gives exactly the original promised marginal
distances because ||X tensor kappa||_1=||X||_1. Hence equality for b2.

The same two constructions preserve EB channels: composition with
input preparation and output partial trace is EB, and preparing fixed
kappa on output keeps a measure-prepare map EB. Thus e is equal too.

Every convex center of E_ext has the form sigma tensor kappa with
sigma in closed conv(E). An arbitrary binary effect F on H tensor K
has effective effect
 F_eff=Tr_K[(I tensor sqrt(kappa))F(I tensor sqrt(kappa))],
with0<=F_eff<=I_H. Its rho and sigma probabilities are exactly those
from F_eff. Conversely F_H tensor I_K realizes every effect on H.
Therefore D_obs(rho tensor kappa||sigma tensor kappa)=D_obs(rho||sigma),
and convex-center infima give the radius equality in (1).

Thus a supplied label-independent ancillary state cannot create a new
mathematical counterexample to this interface. Its preparation/runtime
cost may change an acquisition problem, but full-domain channel existence
already permits fixed ancillary preparations. Label-dependent catalysts,
correlations with an externally preserved reference, or purification
requirements define different promises and are NOT ruled out by (1).
Those resources must be explicitly included and charged if used.

2. PURE COHERENT FLAG SUPERPOSITION FAILS UNDER THE EXISTING SPLITTER

Consider the pure coherent state
 |Psi_psi>=sum_j sqrt(p_j)|j> tensor |psi>^(tensor N_j),
where the flag sectors are orthogonal. Apply the existing deterministic
splitter which sends each nonbottom j to the SAME lower flag on both
outputs, so its image there is
sum_j sqrt(p_j)|j-1,j-1> psi^(N_j/2) tensor psi^(N_j/2).
Tracing one output kills every cross term between distinct j because
the other output flags are orthogonal. The bottom replacement with its
environment is also decohering. Thus each marginal is block diagonal
in the output flag decomposition.

For ANY block-diagonal normalized density nu on the same flag space,
not merely this particular splitter's output,

 <Psi_psi|nu|Psi_psi>
     =sum_j p_j <psi^N_j|nu_j|psi^N_j>
     <=sum_j p_j Tr(nu_j)<=max_j p_j.

The pure-state binary test therefore gives
 T(nu,|Psi_psi><Psi_psi|)>=1-max_j p_j.               (2)

Broad weights needed for a slowly shifting ladder make this error near1.
Hence simply replacing the mixed flag ladder by a coherent superposition
and keeping the same orthogonal-output splitter is a fatal route, not a
new low-error broadcaster. A different channel preserving flag coherence
or a genuinely new correlated resource is not excluded by (2).

3. THE EXACT NONUNIFORM BRANCH OBSTACLE

The naive adjacent-splitting error depends on total variation of the
weight sequence and can be needlessly large. The separate file
NONUNIFORM_DIVISION_RADIUS_OBSTACLE.txt derives the exact optimal
flag-lowering error delta=w max p_j
by a rational quantile coupling. It gives an explicit radius-controlled
logarithmic upper bound and every power alpha in(0,2) in THAT delta.
Thus more scans of nonuniform adjacent profiles cannot refute arbitrarily
small alpha through that route.

The global infimum b2 can be smaller than an exhibited error. The branch
theorem proves only b2<=b_div, not the converse. Same/higher-flag quantum
cloning and nontrivial output preparations from vacuum are outside its
class. Claiming all globally legal quantum broadcasters obey the branch
rate would be an unsupported inference.

4. WHAT THE NEW LOWER FAMILY SETTLES AND WHAT IT LEAVES OPEN

VACUUM_FLAG_POWER_OBSTRUCTION.txt proves, with finite faithful states,
actual b2=Theta(w/K), exact radius R=w R_K and an arbitrary-EB lower
bound e=Theta[w log K/K]. The w=1/K regime has bounded nonzero R and
e=Theta[b2 ln(1/b2)]. The w=2^(-K) regime has R,Cchi->0, polynomial
dimensions/label counts in inverse error, and e=Theta[b2 ln ln(1/b2)].
Both refute all universal exponents alpha>=2, including the endpoint.
They do NOT refute any fixed alpha<2.

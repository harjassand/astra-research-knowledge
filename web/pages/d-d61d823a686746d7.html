For an m-point new block, the2m+1 rational axis candidates at stereographic parameters j/(2m+1),0<=j<=2m, cannot all be parallel to its points: each point excludes at most two axes. About a chosen remaining axis, every new point has a nonconstant rotation orbit. On the rational Rodrigues parameter interval[0,1), the angle is injective, so each old/new pair forbids at most one parameter. For n retained old points, mn+1 equally spaced rational candidate parameters therefore contain a disjoint rotation. Exact unit length, all within-block dot products and internal distinctness are preserved. The old points never move.

Each candidate axis and rotation has O(log(m+n+1)) coordinate height. Constant-size rational matrix products add this height to the fresh block's height; repeated refinements do not repeatedly rotate old nodes. At mostO((mn+1)^2) naive rational pair comparisons suffice. Thus deterministic exact search is polynomial in output size and bit height; no generic-position oracle or random Haar sampler is supplied for free.

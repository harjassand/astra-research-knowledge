Theorem 3.1 audit
-----------------
1. Constants: D0 is 10^8(n+1)^4, not 108(n+1)^4; OCR loses
   superscripts. Relocation constant is 10^5 n. The official Lean file
   Algorithm/AffineWeights.lean:256-257 confirms the exact D0 value.

2. Lemma 3.2's four-hole comparison is a valid-looking weighted injection:
   overlay a matching missing four vertices with a perfect matching; the
   alternating path from one hole ends at one of the other three. Switching
   that path leaves the respective two-hole sets, preserves product weight,
   and is reversed by following the output path from the same endpoint.
   No negative-association assertion is silently used. OA113.txt:309-324.

3. Lemma 3.3's relocation cases are exhaustive, including when the row
   maximizer p is already a fixed hole. That p is isolated in the input
   overlay; it is correctly omitted as a possible path endpoint. The
   inserted edge az was absent from both layers, so removing it before the
   inverse path switch distinguishes its insertion. The endpoint and case
   determine the inverse. OA113.txt:339-382.

4. The recurrence normalizes by the row maximum of the current hole. Its
   leading terms are g(S)/r_a and g(S-a+z)/r_z, so the path bound adds
   errors rather than multiplying successive row ratios. Choosing a simple
   path and stopping at the first fixed hole gives at most n-2 relocation
   steps followed by the direct-edge bound. The row bounds provide the
   advertised 6144/B and final 10^5 n/B constants. OA113.txt:383-396.

5. The interpolation differentiates finite polynomials and uses the same
   original bottleneck B throughout. The derivatives require only two- and
   four-hole bounds during the provisional row interval. The strict
   integrated bounds lie inside [1/8,4], permitting a first-exit continuity
   bootstrap. The final selected pairing inserts distinguished added edges,
   so the high-hole bound follows by a direct weighted injection. There is
   no need to compute the pairing capacity algorithmically.
   OA113.txt:397-453.

6. Inspected formal counterpart:
   Graphs/PathStrength.lean:69 normalized_relocation;
   Graphs/PathStrength.lean:349 hole_relocation;
   Algorithm/AffineWeights.lean:358 logical_inflation;
   Graphs/FillHoles.lean:223 logical_hole_bound.
   These interfaces contain the relevant row assumptions, positive partition
   assumption and exact constants. The formal inflation proof uses a finite
   family barrier with normalized partition plus two-hole ratios, rather
   than literally reproducing the manuscript's exponential first-exit
   phrasing; this is compatible in the inspected interface.

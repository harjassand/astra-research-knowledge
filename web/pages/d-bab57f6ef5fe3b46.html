# Adaptive feature acquisition versus a fixed-dictionary margin barrier

**Verdict.** Adaptivity has three different answers depending on what the learner receives. A fixed polynomial bank of bounded trajectory moments has exponentially bad worst-case conditioning on the parity-clock family. A stateful exact expectation oracle can recover the hidden parity in \(L+1\) adaptively chosen scalar queries, with \(O(L^2)\) query-description and answer bits; its first signal is \(2^{-L}\), so a sample-based implementation costs exponentially many samples. If the learner keeps each noiseless raw path, Gaussian elimination recovers the same feature from \(L+O(\log(1/\delta))\) independent resets, using \(O(L^2+L\log(1/\delta))\) observed bits. That last gain comes from the richer raw-example interface and the promised parity-clock model. It is a classical parity-learning construction, not a general solution to adaptive predictive-feature discovery for HMMs.

## Model and supplied structure

Fix \(L\ge 2\), alphabet \(\{0,1\}\), and characters
\[
  \chi_s(x)=(-1)^{s\cdot x},\qquad s,x\in\mathbb F_2^L.
\]
The source is promised to be either \(Q_L\), which emits a uniform \(X\in\mathbb F_2^L\), or \(P_s\) for an unknown nonzero \(s\in\mathbb F_2^L\), which emits \(X\) uniformly from the hyperplane \(H_s=\{x:s\cdot x=0\}\). After the first \(L\) symbols, both sources emit an independent fair iid tail. Thus
\[
  \frac{dP_s}{dQ_L}(x)=1+\chi_s(x),\qquad
  \operatorname{TV}(P_s[1{:}L],Q_L[1{:}L])=\tfrac12.
\]

The learner is given \(L\), the alphabet, the promise \(Q_L\) versus \(\{P_s:s\ne0\}\), and independent reset access when the sample theorem below is used. It is not given \(s\), a parity feature, or a transition table. The class restriction itself is substantial: it tells the learner that the distinguishing structure is one homogeneous parity over the first \(L\) outputs. The unknown parameter and eventual feature are an \(L\)-bit vector. Each \(P_s\) has a positive finite-state symbol-transition generator with a clock and running parity, using at most \(2L+1\) states; that clock is part of the model. Concretely, if \(j\) is the last nonzero coordinate of \(s\), states \((t,p)\), \(0\le t<j\), \(p\in\{0,1\}\), emit fair bits while updating the parity accumulator \(p\) at selected coordinates; at coordinate \(j\), the emitted bit is \(p\), after which a single fair-tail state emits iid bits. This counts the clock and parity states and yields the uniform law on \(H_s\). No stationary or homogeneous-emission assumption is made.

For any fixed trajectory test \(\phi\in[0,1]\), average its tail randomness conditional on the first \(L\) bits to obtain \(g(x)\in[0,1]\). Then
\[
  \mathbb E_{P_s}\phi-\mathbb E_{Q_L}\phi
    =\mathbb E_{Q_L}[g(X)\chi_s(X)].
\]
Parseval gives
\[
 \sum_{s\ne0}\bigl(\mathbb E_{P_s}\phi-\mathbb E_{Q_L}\phi\bigr)^2
 \le \operatorname{Var}(g)\le \tfrac14.
\]
For any fixed bank of \(M\) such tests, summing over its coordinates shows that some nonzero \(s\) has moment-vector separation
\[
  \left\|\left(\mathbb E_{P_s}\phi_a-\mathbb E_{Q_L}\phi_a\right)_{a=1}^M\right\|_2
  \le \sqrt{\frac{M}{4(2^L-1)}}.
\]
Since the laws differ by TV \(1/2\), any uniform inverse-Lipschitz recovery modulus for this fixed moment map is at least \(\sqrt{(2^L-1)/M}\). This is the inherited fixed-dictionary barrier: polynomial \(M\) cannot give a uniform polynomial conditioning bound.

## Adaptive exact-expectation queries

There is a direct query-count escape if the oracle returns the population expectation of any submitted bounded path test to exact, or sufficiently many, bits. It illustrates why a fixed-dictionary theorem does not itself rule out adaptive queries.

For a prefix \(y=(y_1,\ldots,y_{k-1})\in\mathbb F_2^{k-1}\), define
\[
 \phi_{k,y}(x)=\frac{1+\mathbf 1\{x_{k+1}=\cdots=x_L=0\}
       (-1)^{\sum_{j<k}y_jx_j}}{2},\qquad 1\le k\le L.
\]
It is a bounded test on one length-\(L\) path. Put
\[
 \gamma_k=2^{-(L-k+1)},\qquad
 b_{k,y}=\mathbb E_{Q_L}\phi_{k,y}
       =\tfrac12+\gamma_k\mathbf 1\{y=0\}.
\]
The Fourier support of its nonconstant part is exactly the affine set
\[
 S_{k,y}=\{s:s_1\cdots s_{k-1}=y_1\cdots y_{k-1},\ s_k=0\},
\]
and every coefficient on that set equals \(\gamma_k\). Hence, for nonzero \(s\),
\[
 \mathbb E_{P_s}\phi_{k,y}=b_{k,y}
    +\gamma_k\mathbf 1\{s_{1:k-1}=y,\ s_k=0\}.
\]

Start with the empty prefix. Query \(\phi_{k,y}\) at each step, choosing the next bit \(s_k=0\) if the response exceeds the known \(Q_L\) baseline by \(\gamma_k/2\), and choosing \(s_k=1\) otherwise. Under \(P_s\), each answer selects the correct half of the current candidate set, so after \(L\) calls the learner has \(s\). Under \(Q_L\), every answer takes the second branch and the candidate becomes \(1^L\), which is nonzero. A final query
\[
  \psi_y(x)=\frac{1+\chi_y(x)}2
\]
has mean \(1/2\) under \(Q_L\), mean \(1\) under \(P_y\), and mean \(1/2\) under \(P_s\) for \(s\ne y\). It confirms the candidate and distinguishes \(Q_L\) from \(P_s\). The protocol uses \(L+1\) adaptive expectation queries.

For finite numerical answers, it suffices that query \(k\) has absolute error at most \(\gamma_k/4\). This needs \(p_k=L-k+3\) fractional bits if answers are rounded to binary precision \(2^{-p_k}\). The final query needs three fractional bits. Thus the total returned precision is
\[
 \sum_{k=1}^L(L-k+3)+3=\tfrac12L^2+\tfrac52L+3=O(L^2)\text{ bits}.
\]
The \(k\)-th query is specified by \(k\) and its already acquired prefix \(y\), so a self-contained encoding costs \(O(L)\) bits per query and \(O(L^2)\) overall. Evaluating one submitted feature on one path takes \(O(L)\) bit operations; the learner stores the prefix and counter in \(O(L)\) bits and does \(O(L^2)\) local bit operations across the protocol. These are caller-side costs. The exact expectation oracle's internal computation is not specified by this interface. If it enumerates all \(2^L\) paths, that oracle computation is exponential and must be charged separately.

The small signal has not disappeared. The first query separates two possible expectation values by \(\gamma_1=2^{-L}\). An exact-oracle answer can encode this difference in \(L+O(1)\) fractional bits. In a standard sample-mean implementation, fresh length-\(L\) paths and Hoeffding's inequality give the sufficient allocation
\[
 m_k\ge 8\gamma_k^{-2}\log\frac{2(L+1)}{\delta}
\]
for each split to be correct with total failure at most \(\delta\); the final query needs the same order with constant gap. Since \(\sum_k\gamma_k^{-2}=\sum_{j=1}^L4^j=\Theta(4^L)\), this generic mean-estimation implementation uses \(O(4^L\log(L/\delta))\) resets and \(L\) times as many observed symbols. If the oracle exposes each individual test value rather than only an expectation, the first cut also remains expensive: comparing \(P_{e_2}\) with \(P_{e_1}\), the induced feature-value distributions have KL divergence at most \(4\gamma_1\), so \(m\) such values have TV at most \(\sqrt{2m\gamma_1}\) by Pinsker. Constant-confidence membership therefore needs \(\Omega(1/\gamma_1)=\Omega(2^L)\) samples. Either sample implementation is exponential in the first cut. The exact expectation oracle is a stronger access primitive than passive sampling, even though its answers have only polynomial bit length.

This proves a narrow claim: adaptive directions can reduce the *number of exact population queries* while preserving polynomial answer-description bits, but query count alone hides either exponentially fine statistical tolerance or an unspecified exact-oracle computation. It does not supply a margin-free passive learner.

## Adaptive acquisition from raw reset paths

With noiseless binary paths retained individually, the unknown parity is a system of homogeneous equations rather than a small expectation difference.

Take \(N=L+q\) independent resets and put their first-\(L\) outputs in an \(N\times L\) matrix \(X\) over \(\mathbb F_2\). Every \(P_s\) row satisfies \(Xs=0\). Gaussian elimination over \(\mathbb F_2\) returns the nullspace.

**Theorem (parity feature acquisition).** For \(q\ge0\):

* Under \(P_s\), \(\Pr[\operatorname{rank}(X)=L-1]>1-2^{L-1-N}=1-2^{-q-1}\). On that event the unique nonzero vector in \(\ker X\) is exactly \(s\).
* Under \(Q_L\), \(\Pr[\operatorname{rank}(X)=L]>1-2^{L-N}=1-2^{-q}\).

For the first bound, identify the hyperplane \(H_s\) with \(\mathbb F_2^{L-1}\). Rank failure means some nonzero vector in this \((L-1)\)-dimensional coordinate space is orthogonal to all \(N\) rows. A union bound gives probability at most \((2^{L-1}-1)2^{-N}<2^{L-1-N}\). For the second, rank failure means some nonzero \(v\in\mathbb F_2^L\) satisfies \(Xv=0\); each fixed \(v\) survives all \(N\) uniform rows with probability \(2^{-N}\), so the union bound is \((2^L-1)2^{-N}<2^{L-N}\).

With \(q=\lceil\log_2(1/\delta)\rceil\), the acquired direction is correct under every \(P_s\) except with probability below \(\delta/2\), and the nullspace is trivial under \(Q_L\) except with probability below \(\delta\). A rank-only classifier returns \(P\) exactly when rank is \(L-1\), and otherwise returns \(Q\); its two error probabilities are respectively below \(\delta/2\) and \(\delta\). To demonstrate the acquired observable on data independent of the acquisition, reserve \(t=\lceil\log_2(1/\delta)\rceil\) further resets. Freeze \(\widehat s\) after training and apply \(\phi_{\widehat s}(x)=\mathbf 1\{\widehat s\cdot x=0\}\) only to those holdouts. Under \(P_s\), the feature is exactly correct with probability above \(1-\delta/2\); under \(Q_L\), all holdouts pass with probability \(2^{-t}\le\delta\), conditional on any training output.

### Full acquisition ledger

For the held-out feature check, \(N+t=L+q+t\) independent reset calls each reveal \(L\) exact bits, for \(L(L+q+t)\) observed bits total. The learned direction is stored in \(L\) bits. Incremental row-echelon elimination can stream training paths using at most \(L\times L\) pivot bits plus one \(L\)-bit row, so working memory is \(O(L^2)\) bits; storing every path for audit instead costs \(L(L+q+t)\) bits. Gaussian elimination costs \(O(NL^2)\) bit operations, and evaluating the frozen parity on \(t\) holdouts costs \(O(tL)\) XOR/bit operations. Thus total local time is \(O((L+q)L^2+tL)\) bit operations, or \(O(L^3+L^2\log(1/\delta))\) with the stated choices. The tests use exact symbols and exact arithmetic over \(\mathbb F_2\); no floating-point tolerance or hidden coefficient precision is used. The feature description, every reset, and all observed symbols are charged. No sample labels, process parameters, hidden-state access, or oracle responses are free.

### Same-data controls and lower bounds

Use the identical training block of \(N\) paths and validation block of \(t\) paths for both arms.

* **Adaptive arm:** infer \(\widehat s\) from training. Only score that direction on the untouched validation block. Its false-rejection probability under \(P_s\) is below \(2^{-q-1}\); its false-acceptance probability under \(Q_L\) is at most \(2^{-t}\). Training passes cannot validate \(\widehat s\), because the nullspace choice makes those passes true by construction.
* **Known-direction control:** supply \(s\) as an \(L\)-bit parameter before seeing the same data. Check \(s\cdot X_j=0\) on *all* \(N+t\) paths. Under \(P_s\) it never rejects; under \(Q_L\) it falsely accepts with probability exactly \(2^{-(N+t)}\). It spends no acquisition computation or validation data to avoid selection bias. This is a stronger, equally informed control only after explicitly supplying the direction; the \(L\)-bit feature is precisely the information the adaptive arm has to acquire.
* **Rank/nullspace control:** the rank-only classifier above uses the training block alone and has errors \(0\) under \(P_s\) and below \(2^{-q}\) under \(Q_L\). It is the natural structure-aware adaptive baseline; it does not pretend that a bounded-moment SVD alone found the parity.

There is a matching linear information lower bound for recovering the direction. Put a uniform prior on the \(2^L-1\) nonzero masks. Given \(X\), all masks in \(\ker X\setminus\{0\}\) have the same likelihood under the prior, so the posterior is uniform on that set. With \(N\le L-2\), its size is at least three for every \(X\), and any estimator recovers \(s\) with average success at most \(1/3\). Thus \(L-1\) examples are necessary for success above \(1/3\), and \(L+O(\log(1/\delta))\) suffices with the explicit rank bound.

Classification without outputting \(s\) also needs a linear number of paths in this family. Let \(P_{\mathrm{mix}}^N\) average \(P_s^N\) over nonzero \(s\). For an observed matrix of rank \(r\), its likelihood ratio against \(Q_L^N\) is
\[
 \Lambda(X)=\frac{2^N(2^{L-r}-1)}{2^L-1}.
\]
On full-row-rank matrices (\(N\le L-1\)), this ratio is constant and differs from one by less than \(2^{N-L}\). Under \(Q_L\), the rank-deficient mass is below \(2^{N-L}\); under each \(P_s\), it is below \(2^{N-L+1}\), again by a union bound on nonzero row combinations. Splitting on these two events yields \(\operatorname{TV}(P_{\mathrm{mix}}^N,Q_L^N)<2^{N-L+1}\). With equal priors, any classifier's success is below \(1/2+2^{N-L}\); in particular \(N\le L-3\) cannot reach \(2/3\) success. The adaptive raw-data learner is therefore within a constant additive number of this class-specific information limit.

## Noise sensitivity and reset boundary

The positive theorem is exact-symbol only. If each bit is independently flipped with probability \(\varepsilon\), the observed law becomes
\[
  P_s^{(\varepsilon)}(z)=2^{-L}\bigl(1+\rho_s\chi_s(z)\bigr),
  \qquad \rho_s=(1-2\varepsilon)^{\operatorname{wt}(s)}.
\]
Its TV gap from \(Q_L\) is \(|\rho_s|/2\). A known-\(s\) parity test has mean gap \(|\rho_s|/2\), so a threshold test needs \(O(\rho_s^{-2}\log(1/\delta))\) paths by Hoeffding. For dense \(s\) and fixed positive \(\varepsilon\), this is exponential in \(L\); exact nullspace recovery no longer applies. The noisy unknown-direction problem is not resolved here and must not inherit the noiseless polynomial bound.

Independent resets are essential to the \(N\)-row theorem. A single run of this clocked, nonstationary generator contains only one constrained length-\(L\) vector; after its last selected position, the tail is iid and contributes no new parity equations. Overlapping windows or a long tail cannot be counted as \(N\) independent rows. If the interface supplies only one uninterrupted stream, the positive sample theorem does not apply.

## Prior art and Astra interface boundary

The raw-sample algorithm is the ordinary noiseless parity-learning problem in linear-algebra form: each example \(x\) carries the homogeneous equation \(s\cdot x=0\), and Gaussian elimination is the standard learner. The construction packages that problem as two \(O(L)\)-state stochastic processes and isolates the exact acquired trajectory observable. No priority or algorithmic novelty claim is made. Klivans and Servedio explicitly describe the standard Gaussian-elimination parity learner in [Toward Attribute Efficient Learning of Decision Lists and Parities](https://jmlr.org/papers/volume7/klivans06a/klivans06a.pdf); parity's degradation in noisy learning and statistical-query settings is treated by Blum, Kalai and Wasserman in [Noise-Tolerant Learning, the Parity Problem, and the Statistical Query Model](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/11/2003-Noise-Tolerant_Learning.pdf). Standard spectral HMM learning also states its separation/conditioning conditions explicitly; see Hsu, Kakade and Zhang, [A Spectral Algorithm for Learning Hidden Markov Models](https://arxiv.org/abs/0811.4413). Those works are comparators, not proofs of a general adaptive HMM theorem.

The local Astra card L01-cyclic-grid describes a different interface: proper characteristic-zero recognizable series with state bound \(m\), an exact **full matrix-output oracle**, and charged matrix dimensions/query counts. Its source-derived, unreviewed card reports a compact Volterra detector and notes that the older release-plus-truncation route already gives polynomial proper-cyclic capability; the incremental claim is a compactness/query tradeoff. The paired blocker B-EXACT-ORACLE-INTERFACE says L01 and N25 cannot be transferred across exact versus noisy matrix outputs, excitation constraints, or acquisition models without a bridge theorem. The parity example here uses reset samples or an explicitly specified scalar expectation oracle. It neither validates nor refutes L01, and no L01 matrix-output query is silently treated as a path sample.

The adaptive exact-expectation protocol above is a counterexample to a blanket inference from a fixed-bank conditioning barrier to an adaptive-query lower bound. The raw-sample construction is a counterexample to a blanket impossibility claim for all feature acquisition. Neither settles the target open problem: adaptively acquiring predictive features for arbitrary finite-state sources with no parity-class promise, under a finite-sample interface, and proving a useful certified singular-value margin against a same-data retaining baseline.

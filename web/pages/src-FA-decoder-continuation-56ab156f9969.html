2026-10-13 — independent higher-degree audit of the translation tournament

Decision
  No counterexample was found. The winner-only fresh-match tournament and
  one-row suffix update extend from quadratic coordinates to every degree
  d>=1, provided the map is a hidden-affine triangular bijection
  q_i(x)=u_i(x)+g_i(u_1,...,u_(i-1)), u(x)=Ax+b with A invertible. The
  extension does not use quadratic polar forms. A self-contained learner
  passed 33 exact degree-three/four finite cases through n=9, including every
  input rank and inverse target in each case. These checks are finite
  implementation evidence; the general statement below is an internally
  reconstructed proof under the stated promise.

Contract
  The learner knows n and an upper degree bound d. It receives only an exact
  strict comparator C(x,y), which returns one iff the hidden rank Q(x)
  precedes Q(y) in most-significant-bit-first lexicographic order. It receives
  no values q_i, affine coordinates, coefficients, or triangular directions.
  The hidden map is a bijection with q_i(x)=u_i(x)+g_i(u_1(x),...,u_(i-1)(x)),
  u(x)=Ax+b over F_2 and A invertible; every q_i has total degree at most d.
  The guarantee is conditional on this complete triangular promise. A partial
  flag with an arbitrary suffix is outside the result.

Proof of the degree-d tournament
  Write Δ_v f(x)=f(x+v)+f(x). Define

      H_k={v in F_2^n : Δ_v u_i=0 for every i<=k}.

  These are linear subspaces of dimensions n-k. For v in H_k, let j(v) be
  the least index greater than k for which Δ_v u_j=1. For each i<j(v),
  either i<=k or Δ_v u_i=0; all hidden inputs used by g_i are therefore
  unchanged, and q_i(x+v)=q_i(x). At j=j(v), the inputs to g_j are also
  unchanged while u_j flips, so q_j(x+v)=q_j(x)+1. Thus the first output
  bit changed by translation v is q_j, for every x. With the stated order
  convention,

      f_v(x):=1 xor C(x,x+v)=q_j(x).

  Here C(x,x+v) is one bit. This identity is independent of d.

  A basis of H_k contains a vector with Δ_v u_(k+1)=1: the next row of the
  invertible affine coordinate map is linearly independent of the first k
  rows, so its restriction to their common kernel is nonzero. Hence the
  smallest j(v) among basis vectors is exactly k+1.

  Select that smallest j without first interpolating every candidate. For a
  pair v,w in the current basis, sample a fresh uniform global x and query
  f_v(x), f_w(x), using two strict comparisons. If the labels disagree,
  discard x and sample again. If they agree at c, query C(x+v,x+w). If
  j(v)<j(w), then at their first differing output bit the two translated
  values are 1-c and c, so the comparator answer is c. If j(w)<j(v), the
  values are c and 1-c, so the answer is 1-c. Thus the answer equals c
  exactly when v has the earlier coordinate. If j(v)=j(w), either witness
  is valid. Keep v when the answer equals c and otherwise keep w. Repeated
  pairwise selection therefore leaves a basis vector
  with minimum j. This argument uses the comparator orientation stated in
  the contract and strict inputs: v,w are distinct basis vectors, so the
  third comparison never compares an input with itself.

  If j(v) and j(w) differ, q_j(v)(x) and q_j(w)(x) are two distinct output
  coordinates of a bijection. Under uniform x their pair is uniform on
  F_2^2, so the two labels match with probability exactly 1/2. If the
  indices agree, they match with probability 1. Each attempt uses two
  comparisons; a match uses one more priority comparison. Fresh independent
  global x values are required at every attempt, including after earlier
  comparisons or stages.

  Having selected v with j(v)=k+1, recover q_(k+1) by querying
  f_v(z)=1 xor C(z,z+v) at the M_d=Σ_(h=0)^d binom(n,h) low-weight points
  z=1_S, |S|<=d (terms with h>n are omitted). These points determine every
  degree-at-most-d ANF: in increasing |T| order, its coefficient is

      a_T=q(1_T) xor xor_(S proper-subset T) a_S.

  The interpolation uses exactly M_d comparisons. It recovers the complete
  polynomial in original x-coordinates, not just its restriction to H_k.

  Update a basis b_1,...,b_(n-k) of H_k using one response row

      r_i=q_(k+1)(b_i)+q_(k+1)(0).

  Since b_i is in H_k, every lower hidden coordinate is unchanged under
  translation by b_i, so r_i=Δ_(b_i)u_(k+1), a linear functional on H_k.
  Its restriction is nonzero, hence has rank one. A kernel basis is obtained
  by choosing any pivot p with r_p=1 and replacing each other b_i by
  b_i+r_i b_p. This yields H_(k+1), with dimension reduced by exactly one.
  No polar form, shared future radical, or additional oracle query is used.
  Repeating all n stages recovers every q_i and a toggle v_i in H_(i-1)
  with Δ_(v_i)q_i=1.

  The toggles give exact sequential prefix projection. For a requested prefix,
  process i in order and add v_i when the current q_i value is wrong. Each
  toggle preserves every earlier q_j and flips q_i. At stage i, translation
  by v_i is a fixed-point-free pairing inside every already-fixed prefix
  fiber, so a uniform point remains uniform after conditioning on the new
  bit. Composition maps a uniform full-domain point to an exact uniform
  point in the requested fiber. Correcting all n bits from zero gives the
  unique inverse input for any rank. The executable checks these properties
  exhaustively for each finite teacher.

Complete-flag interpretation
  More generally, suppose a complete translation flag has independent
  directions v_i with Δ_(v_j)q_i identically zero for i<j and identically
  one for i=j. In coordinates t dual to the basis v_i, q_i is invariant
  under every later coordinate toggle t_j, j>i, and has difference one in
  t_i. Therefore q_i=t_i+g_i(t_1,...,t_(i-1)). If q_i has degree at most d,
  affine change of variables preserves this upper bound on degree. Conversely
  every such triangular map has this complete translation flag. This is a
  finite-difference argument and applies to all Boolean degrees. A partial
  flag does not establish the missing suffix invariances; the explicit
  partial-flag counterexample in the main RESULT.txt remains applicable to
  any attempt to widen this theorem without an added suffix promise.

Comparison, randomness, and information costs
  Let P=binom(n,2), the total number of tournament contests over basis sizes
  n,n-1,...,1. Without a cutoff, each different-coordinate contest has
  expected two matching attempts, two comparisons per attempt, and one
  priority comparison; same-coordinate contests cost three comparisons.
  Thus the Las Vegas expected comparison count is at most

      n M_d + 5 P.

  The uncapped Las Vegas version terminates almost surely with finite
  expectation and is exact whenever it returns. The learner uses at most 2nQ
  input bits and receives Q comparison bits for Q comparisons. Matching
  randomness uses at most nPT fresh bits under a cap T, and at most 2nP in
  expectation without a cap. The returned polynomials contain nM_d ANF
  coefficient bits; the n toggle vectors contain n^2 bits.

  For a bounded-run version with 0<beta<1, choose
  T=ceil(log_2(P/beta)) when P>0 and return UNKNOWN if any contest fails to
  match in T attempts. Take T=1 when P=0.
  Conditional on the history before any contest, an attempt matches with
  probability at least 1/2; fresh points make the cutoff probability at
  most 2^-T for that contest. An adaptive union bound over at most P contests
  gives Pr[UNKNOWN] <= P 2^-T <= beta. Every completed run is exact. Its
  worst-case comparisons are at most

      n M_d + (2T+1) P.

  The capped expected comparison count is also at most nM_d+5P, since
  truncation only shortens contests. For fixed d>=2 and fixed beta, the
  capped worst-case leading ratio below is d+1; for d=1 its O(n^2 log n)
  worst-case cap has an extra logarithm, even though the expected upper has
  leading ratio 7.

  A known-input-basis subclass already has 2^L distinct orders, where

      L=Σ_(h=0)^d binom(n,h+1),

  omitting terms with h+1>n. Fix u=x and vary each coefficient of each
  g_i over all monomials on the i-1 earlier variables. The count is
  Σ_i Σ_(h=0)^d binom(i-1,h)=L. Different coefficient tables give different
  maps and therefore distinct total orders. A deterministic exact binary
  comparison tree needs at least L worst-case comparisons. For a randomized
  algorithm with worst-case cap Q that may return UNKNOWN and succeeds on
  each order with probability at least 1-beta, uniform choice from these
  orders gives at most 2^Q correctly decoded leaves for every fixed random
  seed. Hence Q >= L+log_2(1-beta). This is the appropriate capped
  information bound; UNKNOWN does not count as a decoded order.

  For an expected-query randomized algorithm with average error <= beta on
  this uniform subclass (0<=beta<=1/2), Fano's inequality and the
  prefix-free binary comparison transcripts give

      E[Q] >= (1-beta)L - h_2(beta).

  The worst-case expected cost is at least this average bound. This lower
  bound is on comparisons only and assumes one bit per exact comparator call.

  For fixed d>=2, M_d~binom(n,d)~n^d/d! and L~binom(n,d+1)~n^(d+1)/(d+1)!;
  hence nM_d/L tends to d+1 and 5P is lower order. At d=1, nM_1~n^2,
  5P~2.5n^2, and L~0.5n^2, so the expected upper has leading ratio 7.
  These are comparison-model ratios, not evidence of a practical speedup.

  A dense synthetic source representation stores L triangular polynomial
  coefficients and an affine matrix/offset of O(n^2) bits; generating and
  storing that synthetic source model is separate setup, with O(L+n^2)
  parameter bits. A scalar-gate
  evaluator can compute one rank in O(n^2+dL) elementary Boolean operations:
  O(n^2) for u and O(dL) to test the monomials. The finite Python teacher
  uses dense n-bit integer masks, so the conservative elementary-bit charge
  for its actual implementation is O(n^2+nL) per fresh rank: each n-bit mask
  membership test may scan n bits. Its O(n^2+L) count of big-integer mask
  operations is a different, word-operation model and is not reported as
  elementary bitwork. With Q comparisons and U distinct queried endpoints,
  U<=min(2Q,2^n). A memoized teacher costs O(U(n^2+nL)+Qn) elementary bitwork
  and O(nU) logical bits to cache the paired n-bit inputs/ranks; without
  caching, charge O(Q(n^2+nL)). This is source-side model/query accounting,
  separate from learner comparisons and interpolation. The learner also spends
  O(nM_d) space for the returned ANFs and O(nM_d) coefficient-point input
  bits, with O(2^d M_d) elementary subset work for direct low-weight
  Möbius interpolation (a coarse bound). The finite harness reports actual
  comparisons, random bits, query-argument bits, response bits, distinct
  source endpoints, and exhaustive postchecks.

Finite evidence and limitations
  degree3_4_audit.py is self-contained and uses no Sol03 or root code. It
  constructs random hidden affine triangular teachers with independently
  sampled ANF coefficients, runs the comparator-only acquisition, and then
  uses truth solely for verification. It covers 18 degree-3 cases (n=4..9,
  three seeds each) and 15 degree-4 cases (n=5..9, three seeds each). All 33
  runs recovered every coordinate body exactly, checked all 2^n inputs for
  rank and inverse, and had zero errors. At n<=8 it additionally exhausts
  every prefix target and every input to verify exact projection fiber sizes.
  Across degree 3, observed acquisition cost was 80..1,324 comparisons;
  across degree 4 it was 187..2,496. These are seeded finite runs, not
  randomized failure guarantees. The explicit capped no-match test forces
  five misses, uses ten comparisons, and returns UNKNOWN with no guess.

  The code's source-endpoint counts exclude its post-acquisition truth checks.
  The cutoff-test fixture uses hidden ranks to choose a deliberate mismatch
  point; that test-only construction is not part of acquisition. The formal
  cap probability comes from fresh independent uniform points, not this
  deterministic fixture.

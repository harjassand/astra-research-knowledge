## 1. Exact input and output contract

The input is a list of \(m\) binary affine equations

\[
a_e\cdot x=b_e,\qquad a_e\in\mathbb F_2^d,\quad b_e\in\mathbb F_2,
\]

and explicitly supplied rational retention probabilities \(p_e\in[0,1]\). Retention bits are promised independent. Let \(S\subseteq[m]\) be the retained index set and

\[
U=\Pr[A_Sx=b_S\text{ is inconsistent}].
\]

Write \(B\) for the sum of binary numerator/denominator encoding lengths, and take the instance length \(L\) to include the matrix, right sides, probabilities, and dimensions. For rational \(\epsilon,\delta\in(0,1)\), write \(E_\epsilon,E_\delta\) for their binary numerator/denominator encoding lengths; the full input length is \(L+E_\epsilon+E_\delta\). The requested output is a rational \(\widehat U\) satisfying

\[
\Pr[(1-\epsilon)U\le\widehat U\le(1+\epsilon)U]\ge1-\delta.
\]

The output is zero exactly in the preprocessed zero case. All Gaussian elimination, representation construction, probability arithmetic, random-bit generation and output writing are charged. No rare-event conditional-sampling oracle is supplied. Physical acquisition/calibration of failure probabilities and evidence for the independence promise are outside this purely computational input contract.

Remove probability-zero rows. Solve the probability-one subsystem by Gaussian elimination. If it is inconsistent, return one. Otherwise find a particular solution \(x_0\) and a matrix \(N\) whose columns form a basis of its homogeneous nullspace. Substitute \(x=x_0+Nz\) into every remaining row:

\[
a'_e=a_eN,\qquad b'_e=b_e+a_ex_0.
\]

This preserves consistency for each retained subset and preserves the original independent retention law. Drop tautological rows \(0=0\). A row \(0=1\) remains a valid random contradiction. Thus the algorithmic proofs may assume \(0<p_e<1\), with all endpoint costs already charged. Testing the full remaining system detects \(U=0\): inconsistency is increasing, and every subset of the positive-probability rows has positive product mass.

## 2. Reconstructing the cographic reduction

Let \(H=(V,E)\) be a finite undirected multigraph, with distinct terminals \(s,t\). A physical edge opens independently with probability \(q_e\). Let \(S\) denote **closed/failed** edges, so their retention probabilities in the reduction are

\[
p_e=1-q_e.
\]

If \(H\) has no full-graph terminal path, unreliability is one and can be returned without an oracle. Otherwise add a new distinguished edge \(e_0=st\). Choose a basis of the binary cycle space of \(H+e_0\), and use its vectors as the rows of a matrix \(R\). Write \(v_e=R[:,e]\) and \(t_0=v_{e_0}\). The added edge belongs to a cycle, hence \(t_0\ne0\).

### Lemma 2.1

For every failed set \(S\subseteq E\),

\[
t_0\in\operatorname{span}\{v_e:e\in S\}
\quad\Longleftrightarrow\quad
H\setminus S\text{ disconnects }s,t.
\]

**Proof.** If \(t_0\) is not in that span, binary linear separation gives a row vector \(z\) with \(zt_0=1\) and \(zv_e=0\) for all \(e\in S\). The edge vector \(w=zR\) lies in the cycle space, avoids \(S\), and contains \(e_0\). An even subgraph decomposes into edge-disjoint cycles; the cycle containing \(e_0\), with that edge removed, contains a surviving \(s\)-\(t\) path in \(H\setminus S\). This includes parallel edges and loops with their usual binary incidence conventions.

Conversely, a surviving terminal path together with \(e_0\) gives a cycle-space vector \(w=zR\) containing \(e_0\) and avoiding \(S\). Thus \(zt_0=1\) and \(zv_e=0\) on \(S\), which forbids \(t_0\) from being in the selected-column span. Taking contrapositives proves the result. ∎

This matrix is the standard binary cographic representation. The proof above does not need to import the circuit/bond characterization of that matroid. Equivalently, the kernel of \(R\) is the cut space; a dependency containing \(e_0\) is a separating cut contained in \(S\cup\{e_0\}\).

Choose an invertible binary row transformation \(T\) with \(Tt_0=(0,\ldots,0,1)\). One may swap a nonzero coordinate of \(t_0\) to the last position and clear its other coordinates using that last row. Write

\[
Tv_e=(a_e,b_e).
\]

### Lemma 2.2

The distinguished column is in the selected span if and only if the selected affine equations \(a_e\cdot x=b_e\) are inconsistent.

**Proof.** Span membership is equivalent to a selected coefficient vector \(c\) with

\[
\sum_ec_ea_e=0,\qquad\sum_ec_eb_e=1.
\]

Such a combination proves inconsistency. In the other direction, a binary system is consistent exactly when its right side annihilates the left kernel of its coefficient matrix. This follows directly by row reduction: a failure of consistency produces a row \(0=1\), hence precisely such a combination. ∎

A spanning forest and its fundamental cycles construct \(R\) in polynomial time. Its dimensions are at most \((m+1)\times(m+1)\); all entries are single bits. The coordinate transformation and explicit affine output therefore have polynomial bit cost. Disconnected remote components are allowed. A one-edge terminal path gives the extreme zero-dimensional affine equation \(0=1\), correctly retained with the edge's failure probability.

## 3. Ternary compilation and removal of deterministic endpoints

For an original row \(x_{i_1}+\cdots+x_{i_\ell}=b\), introduce private variables \(y_0,\ldots,y_\ell\), impose deterministic helpers

\[
y_0=0,\qquad y_j+y_{j-1}+x_{i_j}=0\quad(1\le j\le\ell),
\]

and retain the final row \(y_\ell=b\) with the original row's probability. The helpers uniquely determine the prefix parities for every original assignment. If the final row is absent they impose no restriction on that assignment; if present they impose exactly the original equation. Different original rows have disjoint private variables. This proves per-subset consistency equivalence, including \(\ell=0\). Let \(D\) be the number of helper rows; \(D\le m(d+1)\).

### Lemma 3.1: independent near-certain helpers have multiplicative error without a rarity floor

Replace each of the \(D\) deterministic helpers by an independently retained copy of probability \(1-\eta\), while keeping original final-row bits unchanged. Let \(U'\) be the resulting inconsistency probability. Then

\[
(1-D\eta)U\le(1-\eta)^DU\le U'\le U.
\]

**Proof.** Removing helpers only relaxes a system, so the new inconsistency event is contained in the original event for each final-row realization. If all helpers survive, the two events agree. This survival event has probability \((1-\eta)^D\), independent of all final-row bits. Bernoulli's inequality supplies the first bound. ∎

Thus \(\eta=\epsilon/(8D)\) suffices with only \(O(\log(D/\epsilon))\) additional bits. The initial suggestion that one needed an explicit exponentially small lower bound on \(U\) was unnecessarily weak. No inverse-rarity dependence occurs in this replacement.

### Lemma 3.2: distinct fair rows implement each helper

For a helper \(\sum_{i\in C}x_i=b\) of arity between one and three, partition \(C=A\mathbin{\dot\cup}B\), with \(|A|\le2\), \(|B|\le1\). For a fresh private variable \(z\), use two independent fair-retained rows

\[
z+\sum_{i\in A}x_i=0,\qquad z+\sum_{i\in B}x_i=b.
\]

Both rows have arity at most three. When both survive, eliminating \(z\) imposes the helper. When either is absent, every assignment of the old variables extends to a satisfying assignment of the retained gadget rows. Repeat this construction \(r\) times, with different private \(z\)'s. The projected helper is active exactly when at least one pair survives completely, with probability

\[
q=1-(3/4)^r.
\]

All activations for different helpers are independent, and are independent of final-row bits. All gadget rows are distinct because each contains its own private \(z\). The two rows in a pair are distinct because the helper has nonempty support. Final rows contain no gadget-private variable and are therefore distinct from all gadget rows; they are mutually distinct by their private prefix variables.

Choose \(r\) as the least integer satisfying \(D(3/4)^r\le\epsilon/8\). Then \(r=O(\log(D/\epsilon))\), and

\[
(1-\epsilon/8)U\le U'\le U.
\]

An oracle estimate of \(U'\) with relative error \(\epsilon/4\) is a relative \(\epsilon\) estimate of \(U\), since \((1-\epsilon/4)(1-\epsilon/8)\ge1-\epsilon\). The construction has polynomial output size, all probabilities exactly \(1/2\), and no repeated equations.

### Imported consequence, with its exact scope

[Feng, Fu and Guo, *Approximating two-terminal network reliability*, arXiv:2608.02523v1, Theorem 3](https://arxiv.org/html/2608.02523v1) state that, for each fixed open probability \(q\in(0,1)\), an FPRAS for undirected two-terminal unreliability at that probability implies an FPRAS for #BIS. Apply it at \(q=1/2\), then Lemmas 2.1–3.2. We obtain the fair distinct ternary consequence stated at the beginning. The theorem is an approximation-hardness implication; it neither proves that #BIS lacks an FPRAS nor establishes NP-hardness of relative approximation.

Root/S5 independently reported a second route after the foregoing reconstruction: deterministic vertex-flow parity equations with divergence one at \(s,t\), and random equations \(f_e=0\) on failed edges. Flow existence is equivalent to surviving connectivity. This gives the same hard event without a cographic matrix. The independent derivations should be preserved; this report's proof and finite checks use the cycle-space route.

## 4. Contradiction witnesses and an exact overlap formula

Return to the general preprocessed system, with \(U>0\), and define the affine code

\[
\mathcal C=\{c\in\mathbb F_2^m:A^Tc=0,\ b^Tc=1\}.
\]

If \(r_A=\operatorname{rank}A\) and \(k=m-r_A\), then \(|\mathcal C|=K=2^{k-1}\). The functional \(b^T\) is nonzero on \(\ker A^T\), because the full system is inconsistent. For a retained set \(S\), let

\[
N(S)=|\{c\in\mathcal C:\operatorname{supp}c\subseteq S\}|.
\]

For inconsistent \(S\), the same argument restricted to \(S\) gives the exact identity

\[
N(S)=2^{|S|-\operatorname{rank}A_S-1};
\tag{4.1}
\]

for consistent \(S\), it is zero. Thus one Gaussian rank computation counts every overlapping contradiction witness without enumerating them.

Assign witness weights

\[
w(c)=\prod_{e:c_e=1}p_e,\qquad Q=\sum_{c\in\mathcal C}w(c)=\mathbb E_\mu N(S).
\]

Sample \(c\) with probability \(w(c)/Q\), then independently retain every edge outside its support with its original probability. The marginal retained-set law is

\[
\pi(S)=\frac{\mu(S)N(S)}Q.
\]

Every sample is inconsistent. For \(Y=1/N(S)\),

\[
\mathbb E_\pi Y=U/Q,\qquad
\frac{\operatorname{Var}_\pi Y}{(\mathbb E_\pi Y)^2}
\le Q/U-1\le K-1.
\tag{4.2}
\]

The first inequality uses \(0<Y\le1\), so \(\mathbb E Y^2\le\mathbb E Y\). This is the classical union-mixture/Karp–Luby construction; the rank formula is its useful algebraic realization here.

## 5. A retention-mass bound on certificate overlap

### Theorem 5.1

For every binary affine input with independent retention,

\[
\boxed{\quad Q\le UP,\qquad P:=\prod_{e=1}^m(1+p_e)\le\exp\!\left(\sum_ep_e\right).\quad}
\tag{5.1}
\]

When \(U>0\), this is equivalently \(Q/U\le P\). When \(U=0\), one has \(Q=0\), and no quotient is asserted. The bound has no dependence on \(U^{-1}\), coefficient rank, equation arity, or the number of witnesses.

**Proof.** The case \(U=0\) is immediate from \(Q=\mathbb E_\mu N(S)=0\), so assume \(U>0\). Let \(\mathcal M\) be the family of inclusion-minimal contradictory supports, ordered in any fixed way. For each inconsistent \(S\), let \(C\) be the first member of \(\mathcal M\) contained in \(S\). This partitions the inconsistent event. A contradiction witness on a minimal support must use every coordinate of that support, so over \(\mathbb F_2\) it is the indicator \(1_C\).

First, there is no nonzero vector \(d\) supported inside \(C\) with \(A^Td=0\) and \(b^Td=0\). Otherwise, the all-one indicator \(1_C\) is a contradiction witness, and \(1_C+d\) is a contradiction witness with strictly smaller support, contradicting minimality. Consequently, the map

\[
\{c\in\mathcal C:\operatorname{supp}c\subseteq S\}\longrightarrow
\mathbb F_2^{S\setminus C},\qquad c\longmapsto c|_{S\setminus C}
\]

is injective: two witnesses agreeing off \(C\) differ by a forbidden zero-right-side dependency on \(C\). Therefore

\[
N(S)\le2^{|S\setminus C|}.
\tag{5.2}
\]

Condition on \(C\subseteq S\). Outside \(C\), retention is still a product measure. The further condition that no earlier minimal contradictory support is contained in \(S\) is a **decreasing** event in those outside retention bits. Harris correlation implies that conditioning a product measure on a decreasing event cannot increase the mean of the increasing random variable \(2^{|S\setminus C|}\). Thus

\[
\mathbb E[N(S)\mid C\text{ is first}]\le
\prod_{e\notin C}(1+p_e)\le P.
\]

All conditioning events of positive mass are legitimate. The outside-empty configuration avoids every earlier minimal support, since one minimal support cannot properly contain another. Averaging over the partition yields

\[
Q/U=\mathbb E[N(S)\mid S\text{ inconsistent}]\le P.
\]

Finally \(1+p_e\le e^{p_e}\). ∎

For completeness, the Harris inequality needed here is elementary: for increasing functions \(f,g\) of independent binary coordinates, \(\operatorname{Cov}(f,g)\ge0\). Induct on the number of coordinates. Conditional covariance on the last coordinate is nonnegative by induction, and covariance of the two conditional means is nonnegative because both means increase with that last bit. Apply this to \(f=2^{|S\setminus C|}\) and \(g=-1_D\), where \(D\) is the decreasing avoidance event.

The proof uses the special affine-code injectivity in (5.2). For arbitrary monotone DNF witnesses this injectivity need not hold: \(C=\{1,2\}\), \(D_1=\{1,3\}\), \(D_2=\{2,3\}\) give the same restriction outside \(C\). The inequality is therefore not being asserted for arbitrary certificate families.

This exponential retention-mass dependence cannot simply be removed from this particular estimator. Take \(m_0\) copies of the left coefficient \(a=1\) with right side zero, and \(m_1\) copies with right side one, all retained with fixed probability \(p\). This is one connected coefficient-matroid block. Then

\[
U=[1-(1-p)^{m_0}][1-(1-p)^{m_1}],
\]

\[
Q=\tfrac14[(1+p)^{m_0}-(1-p)^{m_0}]
               [(1+p)^{m_1}-(1-p)^{m_1}].
\]

For large balanced \(m_0,m_1\), \(Q/U\) is asymptotic to \((1+p)^m/4\), where \(m=m_0+m_1\). A large upper bound alone does not prove large actual variance. To compute that variance, define

\[
B_i=(1-p/2)^{m_i}-(1-p)^{m_i},\qquad i=0,1.
\]

When both row types are present, \(N(S)=2^{|S|-2}\). Independence of their retained counts therefore gives

\[
\mathbb E_\pi[Y^2]
=\frac1Q\mathbb E_\mu[1/N(S);\ S\text{ inconsistent}]
=\frac{4B_0B_1}{Q},
\]

\[
\frac{\operatorname{Var}_\pi(Y)}{(\mathbb E_\pi Y)^2}
=\frac{4QB_0B_1}{U^2}-1.
\]

For \(m_0=m_1\to\infty\), the relative variance plus one is asymptotic to

\[
[(1+p)(1-p/2)]^m,
\]

whose base is \(1+p(1-p)/2>1\). Thus this estimator's actual relative variance is exponential. The event itself has the easy closed-form probability above; this is an estimator limitation, not an instance-hardness argument.

## 6. Compiling the witness distribution by a syndrome trellis

Put \(u_e=(a_e,b_e)\in\mathbb F_2^{d+1}\), and \(t=(0,\ldots,0,1)\). Fix the supplied row order. For a cut after row \(j\), write

\[
P_j=\operatorname{span}\{u_1,\ldots,u_j\},\quad
F_j=\operatorname{span}\{u_{j+1},\ldots,u_m\},
\]

\[
w_j=\dim P_j+\dim F_j-\dim\operatorname{span}\{u_1,\ldots,u_m\},
\qquad w=\max_jw_j.
\]

The feasible prefix syndromes of witnesses in \(\mathcal C\) are exactly

\[
T_j=P_j\cap(t+F_j).
\]

Since \(t\) is in the full span, this affine intersection is nonempty. Its direction space is \(P_j\cap F_j\), of dimension \(w_j\), so \(|T_j|=2^{w_j}\). Gaussian elimination constructs one offset and a basis of every \(T_j\). Enumerating those states costs \(O(m2^w)\) vector operations after polynomial linear algebra; no full \(2^{d+1}\)-state enumeration is hidden. We do not assume an optimal row ordering can be found cheaply. The width of the supplied order is computed and charged.

Let \(p_e=a_e^{\rm prob}/d_e^{\rm prob}\); the superscripts distinguish probability integers from equation coefficients. Use common prefix denominators \(D_j=\prod_{e\le j}d_e^{\rm prob}\). Let \(Z_j(s)\) be the total witness-prefix weight ending at feasible syndrome \(s\), and store integers \(G_j(s)=D_jZ_j(s)\). With absent states interpreted as zero,

\[
G_0(0)=1,\qquad
G_j(s)=d_j^{\rm prob}G_{j-1}(s)
       +a_j^{\rm prob}G_{j-1}(s+u_j).
\tag{6.1}
\]

The desired total is \(Q=G_m(t)/D_m\). Starting at \(s=t\), choose backward inclusion of coordinate \(j\) with exact rational probability

\[
\frac{a_j^{\rm prob}G_{j-1}(s+u_j)}{G_j(s)},
\]

and update \(s\leftarrow s+u_j\) if included. Induction on the recurrence proves that this samples witnesses with weight \(w(c)/Q\). Its support is then forced retained and every other row uses its original rational coin. Equation (4.1) supplies \(Y\) in one rank computation.

The trellis is standard linear-code machinery; it is reconstructed here to make the acquired representation and all costs explicit. One also has \(w\le\min\{r_A+1,k-1\}\): the first inequality follows from ambient augmented rank, and the second because the intersection at a cut is a linear image of \(\ker[u_1\ \cdots\ u_m]\), whose dimension is \(k-1\). Thus a low-nullity implementation can always use this trellis, while explicit witness enumeration gives the usual Karp–Luby baseline.

### Theorem 6.1: complete direct approximation algorithm

Let \(R=\min\{K,P\}\), computed from the rank and the supplied rational probabilities. Set

\[
n_{\rm samp}=\left\lceil3R\epsilon^{-2}\left\lceil\log_2(4/\delta)\right\rceil\right\rceil.
\]

Take this many independent witness-mixture samples and output

\[
\widehat U=Q\,\frac1{n_{\rm samp}}\sum_iY_i,
\]

clipped to \([0,1]\). In ideal exact-rational sampling, \(Y_i\in[0,1]\) has mean \(U/Q\ge1/R\). The multiplicative Chernoff bound for independent bounded variables gives relative error \(\epsilon\) with failure at most \(\delta/2\); the base-two logarithm used above is a conservative upper bound for the required natural logarithm.

There are at most \(H=2mn_{\rm samp}\) rational coin calls. To generate a rational coin with probability \(a/d\), sample a uniform integer in \([0,d-1]\) by rejection from \(\lceil\log_2d\rceil\) fair bits and test whether it is less than \(a\). Each rejection probability is at most one half. Cap every call at

\[
T=\max\{1,\lceil\log_2(2H/\delta)\rceil\}
\]

attempts; abort only if all \(T\) proposals are rejected, and return the positive fallback value one. A successful \(T\)-th proposal is accepted. A union bound makes this additional failure probability at most \(\delta/2\). Couple the capped procedure to the ideal unbounded exact sampler: they agree unless a cap abort occurs. No independence claim is made about samples conditional on avoiding every abort. Together with the ideal concentration bound, this gives a worst-case finite running-time bound and total failure probability at most \(\delta\). Since every nonaborted estimate for \(U>0\) is positive, the positive fallback also preserves the literal promise that the output is zero exactly in the preprocessed zero case.

All integer table entries have \(O(B+m)\) bits, since

\[
0\le G_j(s)\le\prod_{e\le j}(d_e^{\rm prob}+a_e^{\rm prob})\le2^jD_j.
\]

The coin probabilities also have \(O(B+m)\)-bit numerators and denominators. The values \(Y_i\) are reciprocal powers of two with exponent at most \(k-1\), so one may sum them with common denominator \(2^{k-1}\). The exact rational output has \(O(B+m+\log n_{\rm samp})\) bits. A conservative schoolbook bit-work bound is

\[
O\!\left(
(B+m+d+E_\epsilon+E_\delta)^2
+m(m+d)^3
+m2^w[(B+m)^2+d^2]
+n_{\rm samp}[md^2+mT(B+m)^2]
\right),
\tag{6.2}
\]

up to ordinary indexing overhead. The additive quadratic term charges reading the accuracy/confidence encodings and exact parameter setup for \(R,n_{\rm samp},T\); the displayed main terms also cover the probability-product work. This includes the case of a rational \(\epsilon\) with a long encoding but constant numerical value and constant sample count. The bound charges representation construction, arithmetic, rank computations, all random bits, caps and output. In particular it is polynomial in the full input length and \(\epsilon^{-1}\), with logarithmic confidence dependence apart from processing its supplied encoding, on each promised family with \(w\le c\log L\) and \(\log P\le c'\log L\), for fixed constants \(c,c'\). The simpler sufficient promise \(\sum p_e\le c'\log L\) implies the latter.

## 7. Dependency blocks and composition without an error multiplier

Choose a basis of the left coefficient vectors \(a_e\). For each nonbasis vector, compute its fundamental dependency on that basis and connect it to every basis index occurring in that dependency. A zero vector is its own singleton block. The connected components of this graph partition the row indices into dependency blocks \(B_i\).

The fundamental dependency vectors form a basis of \(\ker A^T\), each supported in one block. Hence the kernel is a direct sum of the local dependency spaces. A retained system is inconsistent exactly when at least one block's retained subsystem is inconsistent: a global contradiction decomposes into local dependencies, at least one of which has right-side parity one. Blocks with fully consistent systems never contribute and can be discarded. For all other blocks, their events are independent and

\[
U=1-\prod_i(1-U_i).
\tag{7.1}
\]

The partition is computed by Gaussian elimination and graph search; no matroid-component oracle is supplied. Apply the direct estimator to each contributing block with relative error \(\epsilon\) and failure probability \(\delta/h\), where \(h\) is their number. Clip each estimate to \([0,1]\) and combine by (7.1).

There is **no factor \(h\) in the required accuracy**. Let \(f(u)=1-\prod_i(1-u_i)\). For \(\lambda\in[0,1]\), independently thin Bernoulli events of probabilities \(u_i\) with probability \(\lambda\); conditional on at least one original event, its first occurring member survives with probability \(\lambda\). Therefore

\[
f(\lambda u)\ge\lambda f(u).
\]

Monotonicity gives the lower bound for all coordinatewise relative lower estimates. For the upper bound, let \(v_i=\min\{1,(1+\epsilon)u_i\}\). Then \(u_i\ge v_i/(1+\epsilon)\), so

\[
f(u)\ge f(v/(1+\epsilon))\ge f(v)/(1+\epsilon).
\]

This proves the same relative error for the union. A union bound suffices for failure probability. Exact rational product arithmetic avoids numerical cancellation; all denominators and output bits are charged.

One tractable family has each contributing block's nullity \(k_i=O(\log L)\), with arbitrary total rank/nullity and arbitrary equation arity. For a concrete high-global-nullity example, take \(h\) disjoint blocks, each consisting of a basis \(v_1,\ldots,v_\ell\) and their sum, with right sides zero on the basis rows and one on the last row. Each block has exactly one contradictory support, namely all \(\ell+1\) rows, so

\[
U_i=\prod_{e\in B_i}p_e.
\]

Its total nullity is \(h\), and the full event is given exactly by (7.1). For even \(\ell\), choose \(v_j=\mathbf1+e_j\); these vectors form a basis because \((I+J)^2=I\) over \(\mathbb F_2\), while their sum is \(\mathbf1\). Thus the equation arities grow with \(\ell\). This is a representation-aware extension, not a generic claim of advantage over graph treewidth methods.

## 8. The stronger established NFA baseline

The witness trellis also supports a different route. On input retention bits \(S_1,\ldots,S_m\), nondeterministically choose \(c_e\le S_e\) at row \(e\) and follow the syndrome transitions. Accept at syndrome \(t\). The input word is accepted exactly when it contains at least one contradictory witness, regardless of how many accepting runs exist. The trellis therefore becomes an NFA recognizing inconsistent retention sets, with \(O(m2^w)\) states/transitions.

For fair probabilities this is immediately a #NFA counting instance. For general rational probabilities, first round downward to dyadic probabilities \(q_e\) satisfying

\[
(1-\alpha)p_e\le q_e\le p_e,\qquad \alpha=\epsilon/(8m).
\]

Using \(O(B_e+\log(m/\epsilon))\) binary digits for probability \(e\) suffices. The monotone thinning coupling, retaining any fixed contradiction witness of a realized inconsistent set, gives

\[
(1-\alpha)^mU(p)\le U(q)\le U(p).
\]

Each \(q_e=z_e/2^{\ell_e}\) is realized by a block of \(\ell_e\) uniform input bits with binary value less than \(z_e\). A three-comparison-state threshold automaton processes each block, carries the trellis syndrome, and on the final bit allows the appropriate \(c_e\in\{0,1\}\) choice. No epsilon transition is needed: the nondeterministic syndrome update is folded into the final input-bit transition. The total input length is \(O(B+m\log(m/\epsilon))\), and the explicit NFA size is polynomial in that length and \(2^w\). An accepted-word count divided by \(2^{\sum\ell_e}\) is exactly \(U(q)\).

[Arenas, Croquevielle, Jayaram and Riveros, *#NFA Admits an FPRAS*, JACM 68(6), article 48 (2021)](https://doi.org/10.1145/3477045) prove an FPRAS for the number of accepted words of a supplied unary length. Their theorem, applied to this constructed NFA with a constant-fraction error allocation, gives an FPRAS whenever \(2^w\) is polynomial in the full input length, with **no restriction on \(P\)**. Standard median amplification handles \(\delta\).

This imported result subsumes the *existence* of an FPRAS in the direct estimator's low-width/low-mass regime. The direct estimator provides a different, elementary algorithm with explicit \(O(P\epsilon^{-2}\log(1/\delta))\) sample complexity and exact rank-based reciprocal-multiplicity correction. No measured runtime comparison with a complete modern #NFA implementation has been made. It would be misleading to promote the small-mass promise as a newly discovered complexity boundary.

## 9. Reproducible finite evidence

`S2_verify.py` is an independent standard-library implementation; it does not use N715's proposed Markov chain. Run it with Python 3. Its adjacent `S2_evidence.json` records:

- 4,880 affine instances checking the witness-rank multiplicity identity, exact mixture moments, and \(Q\le UP\); 200 use nonuniform rational probabilities.
- 100 exact dependency-block factorization instances and 1,000 coordinatewise relative-error union-composition checks.
- 50 cographic input graphs and 694 failed-edge selections checking both span and affine inconsistency equivalence, including parallel edges, loops and a remote component.
- 112 local gadget assignment/projection checks, plus an exact compiled fair system with 10 distinct rows of arity at most three. Its original probability is \(1/4\), compiled probability \(1/1024\), matching the all-four-helpers-active lower bound for one copy per helper.
- A supplied low-rank rare instance with 32 rows, rank five and nullity 27. The 67,108,864 contradiction witnesses are represented by 64 full-syndrome states per layer. All probabilities are \(2^{-80}\). Independent exact subspace DP gives \(U\approx6.842277657836021\times10^{-49}\). Four hundred witness-mixture samples with the recorded seed returned an estimate whose ratio to the exact value rounds to one, while ordinary product sampling requires about \(1.46\times10^{48}\) draws per observed failure in expectation. The example is a diagnostic, not a practical universal speed benchmark.

The rare example uses all nonzero five-bit left coefficients and one duplicate, with a single right-side-one row. Its coefficient matroid is connected, so the large nullity is not an artifact of many independent blocks. Exact fractions, seed and test counts are retained in the evidence file. The implemented rare diagnostic uses a capped rational-coin primitive; the report gives the complete general cap/error accounting. The implementation currently uses the full-syndrome DP for that low-rank instance; the smaller feasible-trellis construction is proved above rather than claimed as executed software.

## 10. Prior art, rejected overclaims, and remaining gates

The basic interfaces have substantial predecessors:

- [Colbourn and Pulleyblank, *Matroid Steiner problems, the Tutte polynomial and network reliability*, JCTB 47 (1989), 20–31](https://doi.org/10.1016/0095-8956(89)90062-2) develop matroid abstractions of Steiner reliability and generalized Tutte evaluation.
- [Chari, *Steiner Complexes, Matroid Ports, and Shellability*, JCTB 59 (1993), 41–68](https://doi.org/10.1006/jctb.1993.1053) explicitly relates matroid ports and minimal supports of affine systems. Thus neither calling target-span a matroid port nor the affine-support interface should be presented as new.
- [Karp, Luby and Madras, *Monte-Carlo Approximation Algorithms for Enumeration Problems*, J. Algorithms 10 (1989), 429–448](https://www.math.cmu.edu/~af1p/Teaching/MCC17/Papers/KLM.pdf) is the classical union-counting baseline. Our sampling law and reciprocal-multiplicity correction instantiate that method.
- [Hou, Liu and Ma, *Some Results on Incorrigible Sets of Binary Linear Codes* (2021)](https://doi.org/10.1587/transfun.2020EAL2021) relates erasure failure sets and matroid/Tutte enumerators. This makes the erasure/code connection established territory.
- [Kashyap, *Matroid Pathwidth and Code Trellis Complexity*](https://arxiv.org/abs/0705.1384) connects the supplied-order width with code trellis complexity and documents the difficulty of finding favorable orders. The representation cost cannot be assumed away.
- The #NFA result above is the stronger generic approximation baseline for a polynomial-size witness trellis. [Meel, Chakraborty and Mathur, *A faster FPRAS for #NFA*](https://arxiv.org/abs/2312.13320) supplies a further algorithmic comparison route; no numerical performance claim against it is made here.

The limited primary-source search did not locate the exact inequality \(Q/U\le\prod(1+p_e)\) or this precise direct witness-estimator statement. Absence from that search is not evidence of priority. The direct elementary proof and fair distinct ternary compilation are new to this wave; literature novelty remains unresolved.

Rejected or limited claims are preserved explicitly:

1. A universal no-FPRAS theorem does not follow from #BIS-hardness.
2. Width-two/N715 rapid mixing is unreviewed and was never used as an assumption or algorithm here.
3. Deterministic-helper replacement does not require an inverse-rarity precision floor; monotonicity plus an independent all-helpers-active event gives the sharper multiplicative bound.
4. Polynomial variance of the all-witness estimator for arbitrary inputs is false; the connected rank-one example has exponential relative variance by the exact second-moment calculation in Section 5.
5. A new low-width tractability boundary is not established; #NFA already supplies the stronger existence result.
6. Exact probability evaluation is not obtained from the witness partition function \(Q\): it counts witnesses with multiplicity. The rank-based correction is essential.
7. Bounded arity by itself does not supply a compact witness representation: the hard ternary construction can have large trellis width.
8. Correlated physical failures, acquisition/calibration errors, and unknown probabilities are outside the independent supplied-rational contract. No technological readiness claim follows from the mathematical algorithm or finite diagnostics.

The next worthwhile gates are a focused literature review of affine-coset union estimators and their overlap bounds, implementation of the feasible-trellis compiler, and a matched comparison with a modern #NFA FPRAS on rare, nontrivial code/erasure instances with the same explicit matrix and probabilities. These are separate from the fully written mathematical proofs above.

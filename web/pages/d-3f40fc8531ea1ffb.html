# A rational safe-event branch for constrained spectral rounding

7 October 2026, `rounding_spectral`. This is a certified acceleration of
the local D construction, rather than a claimed execution of its high
spectral-potential branch. The checker `handoff_sol_max_check` independently
derived the acceptance argument before any trajectory result was used.

Given a cleaned state, a rational direction satisfying the current original
face/cost/large/protected equations, and an exact candidate endpoint of
length `s>0`, retain coefficients and scales throughout the segment.
The following certificate uses rational arithmetic only.

For every medium row/sign, the segment barrier is a concave quadratic

`u_sigma(t)=u_sigma(0)+a_sigma t-b t^2`,

where `a_sigma=g_sigma^T h`, `b=R sum p_jh_j^2/(2r^2)>=0`.
Its exact maximum on `[0,s]` occurs at zero, `s`, or `a_sigma/(2b)`
when that stationary point is inside the interval. Compute this maximum
`U_sigma` exactly, and require `U_sigma<=0`.

Set `j_sigma=floor(-beta U_sigma)>=0` and
`E_sigma=2^(-min(j_sigma,J_cap))`, with any selected nonnegative
integer cap. Since `e>2`, `exp(beta u_sigma(t))<=E_sigma` throughout.
The cap makes the bound looser but retains validity and avoids an
exponentially long denominator if the barrier is hugely negative.

The PSD identity `p p^T <= q diag(p)` gives the diagonal upper vector

`C_j=sum_medium,sigma [32K q/r^4] E_sigma p_j +sum_large p_j`.

Hence, on the whole segment,

`lambda_max(M(t)) <= max_j C_j + eta N`.

If this last rational bound is at most eight, the cubic term is exactly
zero throughout: `Phi(x+th)=-eta||x+th||^2`. If additionally `x^T h=0`,
the entire accepted event step decreases potential exactly by
`eta s^2||h||^2`, irrespective of the original `tau`. All barriers have
already been certified, and large row movement is annihilated by its exact
direction constraint. The endpoint is in a proper original subface,
verified using the exact endpoint and face oracle. Same-new-face/cost
reset preserves that progress. Thus at most `n` accepted event steps
occur, even when some are arbitrarily short.

The expanded algorithm is explicit:

1. Construct a nonzero rational candidate in the exact kernel of the current
   original face, cost, large rows, protected gradients, and `x^T h=0`.
   The existing reserve counts guarantee this kernel is nontrivial in the
   active regime; it uses fewer equations than the full existence proof.
   Normalize to `1/2<=||h||<=1`. This attempt does not require deciding an
   exact transcendental eigenvalue comparison with eight.
2. Try an exact face endpoint; apply the rational segment certificate.
3. If certified, take the event step, recover the new original face, clean,
   reset exactly in its cost slice, and clean again.
4. If the certificate fails, regenerate the original rational spectral
   direction with approximate-gradient orthogonality and use the original
   proved `tau` step and its exact endpoint/progress/reset rules. The failed
   candidate is not a fallback direction: its `x^T h=0` equation alone
   need not control the full gradient when `L>8`. No guarantee of practical
   fallback runtime is added here. A general high-`L` execution is not
   implemented by the fixture below.

If accepted event steps are added to the original algorithm, they can
have reset loss bounded by `3eta sqrt(n)delta`, just like original short
steps. There are at most `n` face drops in total across both branches, so
the original global loss budget and tiny-step fallback remain valid.
For an all-event run one may instead choose `delta` from the known `n`
event cap to bound `e` and tracking; termination then comes entirely from
face drops and needs no tiny-step potential budget.

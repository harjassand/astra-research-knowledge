# Exact asymptotic event execution: verified restricted construction, no qualifying invention

Date: 2026-10-10 UTC.

## Result first

No original transformative computational operation was established in this pass.
The strongest developed mechanism is an exact one-sided execution operation for
an explicitly restricted class of finite, native quadratic-guard networks. It
returns the perturbed event order, finite jumps, fractional response powers,
and a certified parameter interval. It handles competing branches and complete
coefficient cancellation, not only a single pre-solved cascade.

The prototype passed:

- 100 native competing-branch DAGs, each checked at three exact rational parameter
  values: 3,600 native guard substitutions and 17,055 sign-certificate checks.
- 99 of those 100 networks have a different event order from their exact-zero
  nominal tie order.
- A three-guard cancellation example in which the correct final value is 2 while
  binary64 loses an epsilon-cubed time separation and produces 1.
- Growing cascades through 256 events. The final response is exactly
  epsilon^(1/2^256), represented without expanding an algebraic polynomial of
  degree 2^256.
- Event disappearance, downstream blocking, finite-radius order reversal, and
  rejection of out-of-class guards.

These facts validate the restricted implementation. They do **not** establish
novelty, an advantage over existing exact symbolic arithmetic, or a new physical
measurement/control capability. No realistic large application was validated.

## Why it does not meet the requested invention bar

The efficient class has been chosen to preserve finite sparse Puiseux
polynomials. Its algorithm is the direct closure calculation in that existing
representation. Producing epsilon^(1/2^K) with K bits of denominator is ordinary
rational-exponent arithmetic, not a newly discovered compression operation.
The competing-branch tests are stronger than a single cascade, but their cheap
comparisons still follow from the same native monomial restriction.

The wider proposal—running an event queue over ordered algebraic germs—uses
established symbolic perturbation, nonstandard hybrid semantics, and algebraic
series methods. This pass did not find a new acquisition theorem for an
important native model class outside the closed representation. A general
polynomial bound cannot be advertised: even finite quadratic event queues can
encode square-root-sum comparison. See `GENERALITY_BARRIER.md`.

The original useful work here is a concrete construction, proof, implementation,
and adversarial test suite assembled for this investigation. No priority claim
is made for the construction or its restricted complexity bound.

## Native input and semantics

A model is a finite DAG of K one-shot events. Node i has:

1. A local clock s_i, activated after all explicitly listed parents have fired.
   The activation time is A_i = max_{p in parents(i)} t_p, or zero at a source.
2. Native rational coefficients of a monic quadratic guard

   s_i^2 - 2 c_i s_i + c_i^2 - sigma_i epsilon^{b_i}
       product_p r_p^{w_ip} = 0.

   Here c_i > 0 is rational, sigma_i is +1 or -1, b_i and w_ip are
   nonnegative integers given in binary, and r_p is the deficit saved by parent
   p. Source gaps must tend to zero. Sources have b_i > 0. All source parents
   must also be activation parents.
3. The guard fires at its first real root in 0 <= s_i <= c_i. At epsilon=0,
   a tangential touch is explicitly accepted. This is a stated semantic choice,
   not a claim about all contact simulators.
4. At firing, save r_i = c_i - s_i. An optional rational affine reset updates an
   output register y <- u_i y + v_i. This register does not feed the guards.
5. A supplied distinct integer priority resolves exactly equal event times.

A negative source has no real guard root at positive epsilon. Descendants
requiring that event are blocked. The number of firings is at most K by
construction; cycles, repeated events and Zeno accumulation are excluded.

The compiler receives guard coefficients, source monomials, parent lists and
reset maps. It is not given the event times or precomputed response exponents.
It checks the square-completion identity, positive c_i, topological order,
source domain and vanishing exponent. The native schema itself restricts the
source to a monomial. Discovering an equivalent monomial from an arbitrary
program is not included or claimed.

## Algorithm

For each node in topological order, after blocking absent-parent nodes:

- Form the exact source exponent

  q_i = b_i + sum_p w_ip alpha_p.

- Reject q_i <= 0. For sigma_i = -1, record absence.
- Otherwise alpha_i = q_i/2, r_i = epsilon^{alpha_i}, and the local duration is
  c_i - epsilon^{alpha_i}.
- Compare parent event times as finite generalized polynomials, choose their
  exact one-sided maximum, and form

  t_i = A_i + c_i - epsilon^{alpha_i}.

- Sort all firing events by these full polynomials, using explicit priority
  only for identical polynomials. Fold the affine resets in this order.

Every comparison subtracts the *complete finite expressions*, combines exactly
matching rational exponents, deletes zero coefficients, and takes the sign of
the first remaining coefficient in increasing exponent order. There is no
finite truncation or uncharged radical-sign oracle.

For every nonzero difference D(epsilon) = sum_j a_j epsilon^{q_j}, let q_0 be
the smallest exponent and a_0 its coefficient. With at least two terms, put

- delta = q_1 - q_0 > 0,
- C = sum_{j>0} |a_j|,
- m = max(0, smallest integer with 2^m >= 2C/|a_0|),
- L_D = ceiling(m/delta).

For 0 < epsilon <= 2^(-L_D), the tail magnitude is at most half the leading
term. A monomial or identically zero comparison needs L_D=0. The shared
certificate exponent is the maximum over queue comparisons, activation maxima
and strict positive-duration checks. It proves the entire returned execution
for every parameter in that interval, rather than merely asserting that some
unspecified interval exists.

## Correctness

Induct over the DAG. At source nodes, the positive source is a positive monomial
and the first admitted root is c_i - epsilon^{b_i/2}; the other root is outside
the admitted interval. A negative source has no real root. For an inductive
node, all saved parent deficits are positive monomials on the common certified
interval. Their supplied product is therefore epsilon^{q_i}; square completion
again gives exactly the stated root and deficit.

Finite generalized polynomials have the sign of their first nonzero term on
the explicitly certified interval by the displayed tail estimate. Consequently
every activation maximum and every pairwise comparison used by sorting is
correct there. The positive-duration checks imply t_i is later than all its
activation parents, so the final sorted order is a legal execution order.
Identical expressions are identical for every positive parameter, so explicit
priority correctly handles genuine ties. The affine fold then gives the exact
final output, and all recorded continuous quantities are exact formulas on that
same interval. An absent parent cannot activate its dependent nodes, exactly as
recorded by the compiler.

The argument is for the supplied finite DAG and touch semantics. It neither
establishes a general solution concept for hybrid systems nor continues a
trajectory through Zeno behavior.

## Bit and representation costs

Let E be the number of dependency edges, K the number of nodes, and B bound the
bit lengths of rational input coefficients and integer source powers. The
source-exponent denominator divides 2^K. Its numerator has
O(K(B+log K)) bits, since each node uses additions, integer multiplications and
one division by two. Event times copy a selected parent's timestamp and add one
constant and one monomial; each has at most K+1 nonzero terms. Timestamp
coefficients have O(KB+log K) bits. Exact cancellations reduce support.

Thus acquisition and arithmetic stay polynomial in the native description size
for this class. With complete sparse dictionaries, the unoptimized program
stores O(K^2) timestamp terms. It uses O(E+K log K) order comparisons. Each
comparison or timestamp construction sorts/combines O(K) terms, giving a
conservative O((E+K log K) K log K) rational-arithmetic operation bound, plus
input validation, exponent propagation and output folding. Standard integer
multiplication/gcd costs must be applied at the preceding bit lengths; no
unit-cost unbounded-real model is assumed. Recorded comparison certificates
also use polynomial space.

The *value* of L can be exponential in K, but its binary encoding is
polynomial. This does not make numerical access to epsilon <= 2^(-L) cheap.
For the simple K-stage cascade the conservative common radius is
2^(-2^K). To make its final gap less than a fixed tolerance eta<1 requires
epsilon < eta^(2^K). This precision/conditioning cost is not removed by a
succinct symbolic exponent and is a major reason not to infer a useful physical
capability from the cascade.

No bound is claimed for arbitrary source polynomials, arbitrary algebraic root
coefficients, rational/algebraic flows, feedback cycles or general resets.

## Decisive native example

There are three guards, all with rational coefficients:

- Event A starts at zero, has c=1 and source epsilon, and resets y <- 2y.
- Event P starts at zero, has c=1/2 and source epsilon^6, and does not change y.
- Event B starts after P, has c=1/2 and source epsilon, and resets y <- y+1.

At positive epsilon:

  t_A = 1 - sqrt(epsilon),
  t_P = 1/2 - epsilon^3,
  t_B = 1 - sqrt(epsilon) - epsilon^3.

Hence P, B, A is the true order and y ends at 2. At epsilon=0, if A has priority
before B, y ends at 1. The compiler certifies the positive-parameter order on
0 < epsilon <= 2^-6.

At epsilon=10^-6, the ordinary binary64 computation stores both t_A and t_B as
0.999. Priority then chooses A before B and returns the wrong value 1. The exact
germ subtraction is simply epsilon^3. This is a reproducible demonstration of
why a floating nominal run plus a derivative is inadequate. It is not proof
that existing exact symbolic methods cannot do the same computation.

## Status and reopening criterion

Closed as a proposed foundational invention. Retain as a verified restricted
prototype and a warning against charging algebraic comparisons as free.

A meaningful reopening would require a genuinely important native family with
nontrivial guard interaction for which a new theorem controls acquisition,
cancellation, algebraic coefficient comparison and conditioning at growing
size, together with a capability or resource advantage over existing exact
algebraic/validated hybrid methods. Changing the operator's name, adding more
synthetic cascades, or testing larger exponents would not supply that evidence.

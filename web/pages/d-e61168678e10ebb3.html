CYCLE 3 — ADAPTIVE RAW-TRAJECTORY OBSERVABLE-FEATURE ACQUISITION
Status: theorem reconstructed/proved internally; no external proof review. Novelty/priority: UNKNOWN. A positive rank-free learning theorem for the unrestricted class below is REFUTED by the construction. Scope is the stated worst-case stationary-context conditional-KL target, not occupancy-weighted risk.

Question and interface
----------------------
Can a learner, from one passive noisy raw trajectory, adaptively discover a useful observable feature bank and certify its future predictive value without receiving a dictionary, exact Hankel/membership queries, hidden labels, resets, or a uniform gap? The answer is negative for uniform conditional prediction, even for a two-state, positive, identifiable, uniformly mixing HMM. The obstruction is a rare observable context whose next-symbol law differs by a constant while its probability is O(1/n). A full-trajectory learner receives exactly the same data and cannot evade the lower bound. Any feature search based on that trajectory is only post-processing.

The experiment gives one stationary path Y_1,...,Y_n in {0,1}; there are no controlled actions. A learner may retain and use the entire path, randomize, and choose any observable features or predictive representation after seeing it. It receives no hidden states, no separate validation sequence, no resets, and no conditional-query service. For the lower bound we strengthen the learner by supplying the hidden-state cap D=2, the horizon n, the common model-class description, the noise rate, and the target context c=1. The feature 1{Y_t=1} is therefore effectively supplied. This strengthening means failure cannot be blamed on a bad search over candidate features. The cap costs ceil(log2(D+1))=2 bits; alpha below is encoded in O(log n) bits and eta is derived from it. Describing the common candidate pair costs O(1) bits; identifying which member generated the data is the unknown binary hypothesis, not supplied side information. The selected output model costs one bit. All common side information is identical under both hypotheses.

Target and quantifiers
----------------------
KL uses natural logarithms. For a stationary process P, a finite observable context c with positive stationary mass, and future horizon h>=1, write
  P^h_c = Law_P(Y_{t+1:t+h} | context c ends at t),
  L_h(P,Q;c) = KL(P^h_c || Q^h_c).
The stationary-context worst-case conditional risk of a learned predictor Q is
  R_h(P,Q) = sup_{c: nu_P(c)>0} L_h(P,Q;c),
where nu_P(c) is the stationary context mass. A predictor is a table indexed by the designated finite context; at evaluation it receives only c, not a longer history or hidden state. Risk is evaluated on a fresh stationary continuation from the same process after training; it is not an in-sample loss. The theorem below uses a one-symbol context c=1 and h=1, and therefore also lower-bounds every h>=1 predictor whose first-symbol marginal is its one-step forecast. This criterion asks for a guarantee at every supported context. It is not the occupancy-weighted objective sum_c nu_P(c)L_h(P,Q;c); the latter can discount a context of mass O(1/n), so this construction alone does not refute uniform estimation under that different objective.

Theorem (single-path conditional prediction lower bound)
--------------------------------------------------------
Let the fixed process family contain the models below for every alpha in (0,1/16] and j in {0,1}. For every sample length n>=1, choose the hard pair with alpha=1/(16n), eta=alpha/16, and r_0=1/4, r_1=3/4. Define two stationary binary-emission HMMs P_0 and P_1 with hidden state S_t in {0,1} and stationary law pi(1)=alpha. Under model j, transitions are
  P_j(S_{t+1}=0 | S_t=1)=r_j,
  P_j(S_{t+1}=1 | S_t=1)=1-r_j,
  P_j(S_{t+1}=1 | S_t=0)=p_j=alpha*r_j/(1-alpha),
  P_j(S_{t+1}=0 | S_t=0)=1-p_j.
Emissions, common to both models, are
  P(Y_t=1 | S_t=1)=1-eta,  P(Y_t=1 | S_t=0)=eta.
The path starts from pi and then runs continuously for n observations.

Every transition and emission probability is strictly between zero and one. pi is stationary since (1-alpha)p_j=alpha r_j. The nontrivial hidden-chain eigenvalue is lambda_j=1-r_j/(1-alpha); for alpha<=1/16, 0<lambda_j<3/4, so the absolute spectral gap is greater than 1/4 (uniformly bounded below by 1/4). The transition determinant is lambda_j != 0, and the emission matrix has absolute determinant 1-2eta>0. Thus each HMM is full rank and, under the usual known-state-count interpretation, meets the transition-full-rank / linearly-independent-emissions population-identifiability conditions. Nevertheless, for every randomized learner A that observes only Y_1:n and outputs a one-step conditional forecast qhat in [0,1] for context Y_t=1. Let theta_j=P_j(Y_{t+1}=1 | Y_t=1), the observable conditional law. Then:

(a) max_{j in {0,1}} P_j{ KL(Ber(theta_j) || Ber(qhat)) > 1/50 } >= 15/32;

(b) max_j E_j[ KL(Ber(theta_j) || Ber(qhat)) ] >= 3/80. These bounds allow unlimited computation and exact arithmetic. The bound holds even when the model pair, alpha, eta, c=1 and D=2 are disclosed. It consequently rules out a uniform finite-sample, high-confidence certificate for R_1 over this class, and hence for any rank-free adaptive feature procedure whose certificate implies this conditional-KL guarantee.

Proof
-----
First compute the observable context mass and posterior hidden-state probability:
  q_alpha=P_j(Y_t=1)=alpha(1-eta)+(1-alpha)eta
          =alpha(17/16-alpha/8),
  w=P_j(S_t=1 | Y_t=1)=alpha(1-eta)/q_alpha=(16-alpha)/(17-2alpha).
Thus alpha <= q_alpha <= 17alpha/16 for alpha<=1/16; along the hard length-n path the expected number of occurrences of context 1 is n*q_alpha<=17/256. Given S_t, the next hidden-state-1 probability is 1-r_j in state 1 and p_j in state 0. Hence
  u_r=P(S_{t+1}=1 | Y_t=1)
      =w(1-r)+(1-w)alpha*r/(1-alpha),
  theta_r=P(Y_{t+1}=1 | Y_t=1)=eta+(1-2eta)u_r.
Subtracting the two forecasts gives
  Delta=|theta_(3/4)-theta_(1/4)|
       =(1-2eta)/2 * [w-(1-w)alpha/(1-alpha)].
For alpha<=1/16, w>=15/16, (1-w)alpha/(1-alpha)=alpha/(17-2alpha)<=1/240, and 1-2eta>=127/128. The bracket is therefore at least 14/15, so Delta >= (127/128)(14/15)/2 > 2/5. The two models make a constant-separated observable forecast at the target context, although that context has stationary mass q_alpha=Theta(alpha).

Next bound the information in the complete raw path. Couple the two hidden chains from the same initial S_1~pi. While they agree in state 0, the maximal-coupling transition mismatch probability is |p_1-p_0|=alpha/[2(1-alpha)]; in state 1 it is |r_1-r_0|=1/2. At transition t, the unconditional probability of a first mismatch is at most
  P_0(S_t=0)|p_1-p_0| + P_0(S_t=1)|r_1-r_0|
    =(1-alpha)*alpha/[2(1-alpha)] + alpha/2 = alpha,
because the event that the chains still agree can only reduce each state-specific term. (The first chain remains stationary under the coupling.) A union bound over n-1 transitions gives P{hidden paths ever disagree} <= (n-1)alpha. Couple emissions identically whenever the hidden states agree; since the emission kernel is common, this yields
  TV(P_0^{Y_1:n},P_1^{Y_1:n}) <= (n-1)alpha.
At alpha=1/(16n), this is <1/16.

For any test of j based on the entire raw path (randomization allowed), the equal-prior average classification error is at least (1-TV)/2 > 15/32. Turn any forecast qhat into the test that selects the nearer of theta_(1/4), theta_(3/4). If KL(Ber(theta_j)||Ber(qhat))<=1/50, Pinsker gives |qhat-theta_j|<=sqrt((1/50)/2)=1/10. Since Delta>2/5, those success intervals are disjoint, so success implies correct classification. Therefore the average failure probability is at least 15/32, proving (a). If the test is wrong, |qhat-theta_j|>=Delta/2, and Pinsker in the lower-bound direction gives KL(Ber(theta_j)||Ber(qhat))>=2(Delta/2)^2=Delta^2/2. Thus average expected KL is at least (15/32)(Delta^2/2)>=3/80, proving (b). The maximum over the two models is at least their average.

Future-horizon extension: for h>1, apply data processing to the projection of Y_{t+1:t+h} onto its first symbol. The KL between any proposed h-step conditional law and the true h-step law is at least the KL between the corresponding first-symbol marginals, so the same lower applies.

Fixed-alpha confidence/sample lower bound
-----------------------------------------
The preceding n-dependent choice proves non-uniformity. A related bound states the amount of raw path needed when alpha is fixed. For any alpha<=1/16, the KL between the hidden path laws is
  KL(P_0^{S_1:n}||P_1^{S_1:n})
    =(n-1)[(1-alpha) KL(Ber(p_0)||Ber(p_1))
           + alpha KL(Ber(1/4)||Ber(3/4))]
    < (n-1)alpha.
Indeed KL(Ber(p_0)||Ber(p_1)) is at most its chi-square divergence
  (p_1-p_0)^2/[p_1(1-p_1)] <= (5120/12825)alpha < 0.4alpha,
and KL(Ber(1/4)||Ber(3/4))=(ln 3)/2<0.55; the weighted row sum is <alpha. The common emission channel adds zero conditional KL to the joint hidden/observed path, and data processing gives KL(P_0^{Y_1:n}||P_1^{Y_1:n})<(n-1)alpha.

Any predictor with probability at least 1-delta under each model of conditional KL <=1/50 induces a test with both errors <=delta. For delta<1/2, binary data processing for the test event implies KL(P_0^{Y_1:n}||P_1^{Y_1:n}) >= kl(1-delta||delta), where kl is Bernoulli KL. Consequently
  n-1 > kl(1-delta||delta)/alpha.
For small delta this is Omega(alpha^{-1} log(1/delta)) raw observations. This is a path-information lower bound, not merely a coupon-counting heuristic; the hidden state is never revealed.

Observable rank / gap diagnostic
--------------------------------
The 2-by-2 Hankel block indexed by empty context and symbol 1 is
  H = [[1, q_alpha], [q_alpha, P(Y_t=1,Y_{t+1}=1)]].
Its determinant is Cov(1{Y_t=1},1{Y_{t+1}=1})
  =(1-2eta)^2 alpha(1-alpha)lambda_j > 0.
So the predictive rank is exactly 2 for each member, while this determinant tends to zero as alpha->0. Since the largest singular value is at least 1, the smallest singular value of this block is at most its determinant and therefore has no uniform positive lower bound. The example does not violate separation-conditioned spectral learning guarantees: it removes the uniform observable gap. It does show that a rank cap alone is not a finite-sample conditional-risk certificate.

Adaptive versus fixed versus full-data policies
------------------------------------------------
For any adaptive feature search that sees only X=Y_1:n, its selected bank, internal state, and final forecast are a randomized channel K(output|X). By data processing, TV(KP_0,KP_1)<=TV(P_0^X,P_1^X), and KL contracts as well. Thus no choice of features from the same path can improve the binary distinguishability above the complete-path benchmark. This includes any precommitted bank, any bank selected after inspecting histories, and any online feature-selection policy with independent random bits. The lower applies even if the target feature/context is supplied, so dictionary acquisition is not the decisive bottleneck here.

For the known two-candidate comparison, the strongest equally informed full-data policy is the likelihood-ratio test formed from the complete raw path; for equal priors it achieves Bayes error exactly (1-TV(P_0^X,P_1^X))/2, which is optimal among all randomized decisions. Its likelihood can be evaluated by the ordinary two-state forward recursion, summing over hidden paths rather than estimating a hidden path. The feature learner cannot improve on this using the same symbols. The exact-pair LR is a comparator, not a universal model-selection method; it is deliberately given the same class information that made the lower harder.

The precise interface changes that can escape the theorem are visible in its proof: impose a known lower bound on target-context mass (and suitable predictive separation), provide independently sampled context-conditioned futures/resets, or allow actions that increase visitation and charge those interventions. A pre-supplied observable dictionary alone does not fix the rare-context lower bound. These alternatives are outside the passive one-path interface and would need their own costs and transfer proof.

Cost ledger
-----------
- Data: exactly one stationary passive path of n binary observations; n bits of raw input, n-1 transitions. The process has a constant hidden spectral gap, so the bound is not caused by slow hidden mixing. No fresh sample is used for evaluation; the target is a population conditional distribution.
- Noise: positive emissions with eta=alpha/16 and 1-eta, explicitly included in the model and learner side information. eta is Theta(n^-1) in the triangular lower-bound sequence. All probabilities are rational; no noiseless channel or hidden label is used.
- Hidden information: no hidden states, basis, state labels, conditional future oracle, Hankel entry, membership query, or reset is provided. D=2 may be supplied at a charge of 2 bits; the result remains true. Giving alpha, eta, the model pair and context costs O(log n) common description bits and only strengthens the learner; the one-bit model identity remains unknown and is the prediction target.
- Feature/query budget: zero oracle queries and zero actions. The input itself can be kept as n bits. A selected feature program/bank must be encoded if retained; any such code and all feature-search computation are extra nonnegative costs, but the lower holds even with unlimited computation. No validation symbols are free: any split/held-out check must use part of the same n-symbol path and cannot invalidate the path-TV lower bound.
- Precision: the statistical lower grants an exact real-valued forecast for free, so finite output precision cannot explain the failure. Encoding a general b-bit forecast costs b bits; the known-pair LR output is one of two rationals and costs O(log n) bits (or one bit to select the candidate).
- Full-data comparator: for the disclosed pair, two forward recursions cost O(n) rational arithmetic updates and O(n) storage bits for the input if retained. Exact rational filtering can be streamed with two numerators whose bit lengths grow O(n log n); a straightforward integer implementation uses O(n log n) working bits and polynomial bit operations (conservative grade-school bound O(n^2 log^2 n) for multiplying O(n log n)-bit numerators by O(log n)-bit step coefficients and adding them). No floating-point precision assumption is needed. The final selected one-step prediction is one of two rationals with O(log n)-bit descriptions. This is only a cost bound for the known pair, not for arbitrary HMM search.
- Statistical confidence: at alpha=1/(16n), every test has average error >15/32; at fixed alpha, a uniform failure probability delta<1/2 requires n-1 > kl(1-delta||delta)/alpha. Infinite precision, unlimited compute, and raw-path retention do not change either lower bound.

Falsifiable check / evidence
----------------------------
Scratch exact-rational enumerator: work/programmes/acquisition_learning/cycle3/adaptive_raw_features/check.py. It enumerates both hidden and observed paths for T=1,...,7, checks stationarity, positivity, the conditional forecast gap, hidden-chain gap, nonzero rank witness, and the observed-path TV inequality using Fraction arithmetic. This is a finite implementation check of the formulas on those seven sizes only; it is not the proof. Command and output are in CHECK.txt beside the script.

Counterexample boundary: the construction's context mass tends to zero. If a theorem is stated only for contexts with nu(c)>=mu>0, this particular sequence is excluded and does not rule out a positive theorem with dependence on mu, a transition/emission margin, or a uniform predictive gap. Likewise, average-in-context loss can downweight the rare context. The result is a scoped refutation of rank-free, worst-case conditional prediction without these premises, not an impossibility for all observable representation learning.

Identifiability at each fixed alpha does not yield uniform finite-sample conditional prediction as alpha approaches zero.

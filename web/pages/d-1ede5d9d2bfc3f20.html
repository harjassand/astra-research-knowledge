REGULAR-CONE UPPER PROFILE FOR FIXED ROOT SYSTEMS
Date: 2026-10-08
Status: independent analytic reconstruction; nonsimply-laced normalization
is explicit below. Awaiting an independent leaf audit before synthesis as a
completed theorem. No operational transfer is asserted.

1. TARGET

Let Phi be a fixed irreducible reduced root system, with rank r, positive
root set Phi+, p=|Phi+|, and h=max_{alpha>0} ht(alpha). Normalize the
invariant form so long roots have squared length 2 and use the half-Casimir
scale c2(lambda)=1/2(lambda,lambda+2rho). Let V_lambda be regular with
Dynkin labels

  n <= a_i <= K n,   n=min_i a_i,   K fixed.

Then d=dim V_lambda satisfies

  (n+1)^p <= d <= C_(Phi,K)(n+1)^p.                            (1)

For n sufficiently large depending only on Phi,K, the explicit filters
below give

  Lambda_lambda(Q) <= C_(Phi,K)(d/Q)^(1/p), 1<=Q<=d/2,          (2)

and

  Lambda_lambda(d-k) <= C_(Phi,K)(k/d)^((p-1)/p),
        1<=k<=d/2, p>=2,                                     (3)

  Lambda_lambda(d-k) <= C_(Phi,K)/log(e d/k),
        1<=k<=d/2, p=1.                                      (4)

For the A1 case p=1 exactly, the root-string conductance is the usual
one-dimensional SU(2) conductance up to the chosen fixed Casimir scale.

2. PRINCIPAL HEIGHT AND EXACT STABLE CAP

Use H0=rho^vee, so alpha(H0)=ht(alpha) for every positive root. For a
weight mu in V_lambda define depth

  q(mu)=<lambda-mu,rho^vee>.

It is a nonnegative integer. A PBW monomial indexed by occupations
(n_alpha)_{alpha>0} has depth sum_alpha n_alpha ht(alpha). Define

  F_Phi(z)=product_(alpha>0)(1-z^ht(alpha))^(-1),
  g_q=[z^q]F_Phi(z),  V_R=sum_(q=0)^R g_q.                  (5)

Thus V_R counts nonnegative root occupations of total height <=R. Since
all heights lie in [1,h],

  (R/(p h))^p <= V_R <= binom(R+p,p),  R>=0,                 (6)

with the lower bound interpreted trivially at R=0. Hence
V_R ~=_Phi (R+1)^p.

For beta in the positive root lattice, Kostant's formula gives

  mult_(V_lambda)(lambda-beta)
   =sum_(w in W)(-1)^ell(w)P(beta-delta_w),
  delta_w=lambda+rho-w(lambda+rho).

For w!=1, the inversion-set expression is

  delta_w=sum_(alpha in Inv(w)) <lambda+rho,alpha^vee> alpha.

Because all Dynkin labels are at least n and each positive coroot has
nonnegative integral simple-coroot coordinates with positive total,
<lambda+rho,alpha^vee> >= n+1. Every alpha in Inv(w) has height at least
one, so depth(delta_w)>=n+1. Consequently, for every depth q<=n the
nonidentity Weyl terms vanish: the carrier shells are exactly the PBW
shells g_q in (5). This uses the general Kostant formula and does not
assume a type-A occupation identity.

3. ROOT-STRING NORMALIZATION FOR NONSIMPLY-LACED TYPES

For each alpha>0 choose an sl2 root triple (E_alpha,E_-alpha,H_alpha)
with

  [E_alpha,E_-alpha]=H_alpha,  [H_alpha,E_alpha]=2E_alpha,
  E_-alpha=E_alpha^*,

so H_alpha acts on weight mu by <mu,alpha^vee>. With the invariant form
normalized by long-root length squared 2, root vectors can be chosen so
that (E_alpha,E_-alpha)=2/(alpha,alpha). The half-Casimir root-pair term
is then

  (alpha,alpha)/2 * (T_alpha,x^2+T_alpha,y^2),
  T_alpha,x=(E_alpha+E_-alpha)/2,
  T_alpha,y=(E_alpha-E_-alpha)/(2i).

For Hermitian radial filters f(H0),

  ||[T_alpha,x,f]||_HS^2+||[T_alpha,y,f]||_HS^2
       = ||[E_alpha,f]||_HS^2.

Thus the exact root weight in the energy is

  eta_alpha=(alpha,alpha)/2.                                  (7)

It equals one for long roots and is the fixed positive short-root ratio
for short roots (for example 1/2 in B/C/F4 and 1/3 in G2, with long
roots squared 2). Cartan terms vanish on f(H0). These eta_alpha factors
must be carried through the conductance and resistance estimates; they
are bounded above and below by positive constants depending only on Phi.

For each root define the shell trace and conductance

  S_alpha(q)=Tr_(W_q) H_alpha,
  c_alpha(q)=Tr_(W_q)(E_-alpha E_alpha),
  h_alpha=ht(alpha).

The exact trace recurrence is

  c_alpha(q+h_alpha)-c_alpha(q)=S_alpha(q),
  c_alpha(q)=sum_(t>=1, q-t h_alpha>=0) S_alpha(q-t h_alpha). (8)

The sign follows from [E_alpha,E_-alpha]=H_alpha and cyclicity of trace
between W_q and W_(q+h_alpha). In particular c_alpha(q)=0 for
q<h_alpha. For a real shell function f(q),

  E(f(H0))=sum_(alpha>0) eta_alpha sum_q
             c_alpha(q)|f(q)-f(q-h_alpha)|^2.                (9)

Equations (8)-(9) hold for short and long roots alike. Length appears only
in eta_alpha and the coroot in S_alpha; height h_alpha controls the shell
step.

4. STABLE-SHELL CONDUCTANCE BOUNDS

Write a positive root coroot as
alpha^vee=sum_i b_i(alpha) alpha_i^vee, b_i(alpha)>=0, and set

  B_Phi=max_{alpha,gamma>0}|<gamma,alpha^vee>|,
  Hvee_Phi=max_{alpha>0}sum_i b_i(alpha).

The constants are finite and B_Phi>0. Any beta=sum_gamma n_gamma gamma
at depth q obeys sum_gamma n_gamma<=q, hence

  |<beta,alpha^vee>|<=B_Phi q.

For q<=epsilon n, with epsilon<=1/(2B_Phi), every weight
mu=lambda-beta in W_q satisfies

  n/2 <= <mu,alpha^vee>
      <= (K Hvee_Phi+B_Phi epsilon)n.

Therefore

  (n/2)g_q <= S_alpha(q)
      <= C_(Phi,K)n g_q,       q<=epsilon n.                 (10)

The lower bound uses <lambda,alpha^vee>=sum_i a_i b_i(alpha)>=n;
the upper uses the bounded coroot coefficient sum. Choose n large enough
that M+h<=n for M=floor(epsilon n/2), so every source shell in (8) for
q<=M+h-1 lies in the stable range.

For simple roots h_alpha=1. Define the energy-weighted simple-shell
conductance

  c_1(j)=sum_(i=1)^r eta_(alpha_i)c_(alpha_i)(j).

Equations (8),(10) give

  c_(Phi)n V_(j-1) <= c_1(j) <= C_(Phi,K)n V_(j-1),
                           1<=j<=M.                         (11)

For any positive alpha and q in the stable crossing range,

  c_alpha(q)<=C_(Phi,K)n V_(q-h_alpha).

The ratio V_q/V_(j-1) is bounded by C_Phi uniformly when
q-h_alpha+1<=j<=q: for q>=2h use (6) and j-1>=q/2; for q<2h there
are only finitely many shells. Therefore

  eta_alpha c_alpha(q)<=C_(Phi,K) c_1(j),
       q-h_alpha+1<=j<=q.                                  (12)

This estimate includes the distinct long/short energy weights eta_alpha.

5. LOW-RANK RAMP

For integer 1<=R<=M, set

  F_R|_(W_q)=(1-q/R)_+.

It is positive semidefinite and rank V_(R-1). From (6),
||F_R||_HS^2>=c_Phi R^p (the q=0 shell handles bounded R). For a root
of height h_alpha, the active source depths are exactly
q=h_alpha,...,R+h_alpha-1, a total of R shells; each has
q-h_alpha<=R-1 and difference at most h_alpha/R. Thus
c_alpha(q)<=C n V_(R-1), and (9) gives

  E(F_R)<=C_(Phi,K)n V_(R-1)/R
         <=C_(Phi,K)n R^(p-1),
  E(F_R)/||F_R||_HS^2<=C_(Phi,K)n/R.                         (13)

Because V_R is increasing and V_R~=R^p, integer rank rounding chooses
R>=c_Phi Q^(1/p) with rank(F_R)<=Q until the stable cap is reached.
For budgets larger than V_(M-1), use the fixed filter F_M; its quotient
is O_(Phi,K)(1), and (d/Q)^(1/p)>=1 for Q<=d/2. Weyl's formula and
regularity give d~=_(Phi,K)n^p, so (13) proves (2).

6. HARMONIC CAP FOR NEAR-FULL RANK, p>=2

Reduce epsilon if necessary so that V_(M-1)<=d/2. Let
r_*=floor(M/2), k0=V_(r_*-1). From (6) and the upper Weyl dimension
bound, k0/d>=epsilon_(Phi,K)>0 for all sufficiently large n.

For 1<=k<=k0, take the least R with V_R>=k, put B=R+1, and define

  rho=sum_(j=B)^M 1/c_1(j),
  A_q=1                                                (q<=R),
  A_q=rho^(-1)sum_(j=q+1)^M 1/c_1(j)                 (R<q<M),
  A_q=0                                                (q>=M),
  X=I-A.

Then nullity(X)=V_R>=k, so rank(X)<=d-k, and

  ||X||_HS^2>=d-V_(M-1)>=d/2.

The simple-root energy is exactly

  E_1(X)=sum_(j=B)^M c_1(j)(A_(j-1)-A_j)^2=1/rho.

For a root of height h_alpha, the difference A_(q-h_alpha)-A_q is a
sum of h_alpha consecutive increments. Cauchy-Schwarz and (12) bound
its energy by C_Phi h_alpha^2 E_1(X); summing the fixed root set gives

  E(X)<=C_Phi/rho.                                           (14)

By (11), c_1(j)<=C_(Phi,K)n V_(j-1)<=C_(Phi,K)n j^p. Since
B<=M/2 and p>=2,

  rho >= c_(Phi,K)/(n B^(p-1)).                              (15)

If k=1, then R=0 and B=1, so B<=C_Phi k^(1/p) directly. If R>=1,
k>V_(R-1)>=( (R-1)/(p h) )^p, which gives
B<=C_Phi k^(1/p). Combining (14)-(15), ||X||²>=d/2, and
d~=n^p yields

  E(X)/||X||^2 <= C_(Phi,K)(k/d)^((p-1)/p).                  (16)

For k>k0 up to d/2 use the positive-part Cartan filter

  X_H=(-T_(H0)/L)_+,  L=lambda(H0).

Since w0(H0)=-H0, the spectrum is symmetric and rank(X_H)<=d/2<=d-k.
Regularity gives L~=_(Phi,K)n and c2(lambda)~=_(Phi,K)n^2. If B is the
invariant form whose dual weight metric has long roots of squared length
2, then trace isotropy and the standard Casimir eigenvalue 2c2 give

  Tr_(V_lambda)(T_H0^2)
       = 2 d c2(lambda) B(H0,H0)/dim(g).

Hence ||X_H||²=Tr(T_H0²)/(2L²)>=c_(Phi,K)d. The 1/L-Lipschitz
positive-part function changes by h_alpha/L along a root edge; the root
Casimir trace is at most d c2(lambda). Thus E(X_H)<=C_(Phi,K)d and the
quotient is bounded. Since k/d>=epsilon_(Phi,K), this patches (16) to all
1<=k<=d/2.

7. LOGARITHMIC A1 CASE

For Phi=A1, p=1 and all stable shells are one-dimensional. If the Dynkin
label is n, d=n+1 and c_1(j) is a fixed-normalization multiple of
j(n-j+1). For k up to a fixed fraction of d, the same harmonic profile
has

  rho=sum_(j=k)^M 1/c_1(j)
       ~= n^(-1)log(e d/k).

The filter has nullity k, norm squared at least d/2, and energy 1/rho,
so E/||X||²<=C/log(e d/k). The Cartan patch handles k/d bounded below,
where the right side is bounded below by a positive constant. This proves
(4). The logarithm is the one-dimensional resistance sum.

8. SCOPE AND OPEN AUDIT

This derivation is root-system-uniform for fixed Phi, including B/C/F4/G2,
provided the exact root-energy coefficient in (7) is used. The exponent is
p=|Phi+|, not r. All constants may depend on Phi and on the regular-cone
ratio K, and no claim is made uniform as rank grows. Small n leaves only
finitely many weights for fixed Phi,K and can be absorbed after checking
that every nonzero rank-constrained matrix has positive energy; the
asymptotic proof above is stated for n large enough to fit the stable cap.

The root-height shell recurrence is the mathematical mechanism. No
E/F/G operational score frame, tensor-power transfer, or acquisition
claim is inferred. Independent normalization/source review remains
required before closing this as a theorem package.

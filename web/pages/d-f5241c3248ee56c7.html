# Deterministic propagation through coalescing multichannel crossings

Research package, 2026-10-09 UTC. Version 2, with the original version preserved.

## Result in one paragraph

A constructive theorem draft gives a deterministic algorithm for the full endpoint propagator of an explicitly supplied rational Hermitian matrix polynomial. The proposed bit-work bound is polynomial in the matrix dimension, polynomial degree, coefficient encoding length, frequency encoding length, and requested number of accuracy bits. It covers coalescing multichannel scales without free eigenbasis, phase, gap, or connection-matrix oracles. One focused internal end-to-end check found no blocking mathematical gap after the implementation addendum and small mesh/input repairs now incorporated in version 2.

The operational promise is coherent transition matrices at useful precision without paying directly for every carrier oscillation or the inverse width of a narrow crossing. This is a supplied-model computational result. It does not acquire an accurate physical model or remove exponential many-body matrix dimension.

## What changed the resource conclusion

The earlier randomized construction required work proportional to inverse squared error. The present deterministic mechanism is different:

1. Algebraic discriminant roots acquire a geometric mesh using the bit length of narrow scales.
2. Finite-valency complex analysis bounds spectral rotation and relative gap variation on those panels, with only a polynomial radius shrink.
3. Precision-dependent clustering leaves bounded-action blocks; separated blocks admit finite-order superadiabatic decoupling.
4. Original algebraic scalar phases are integrated separately. Polynomial-size Taylor-jet circuits acquire the nonpolynomial transformed generators and all endpoint conversions.

This changes the accuracy dependence to a polynomial in the requested number of bits. The conservative constants do not establish a useful runtime.

## Reproducible exact evidence

Run the small supplied Python scripts with SymPy (and mpmath where used):

    python verify_three_channel_scaling.py
    python verify_review_projector_jets.py
    python make_benchmark_manifest.py

The saved JSON records show:

- exact rescaling of the genuinely irreducible three-channel quadratic family;
- exact su(3) Lie rank eight;
- a degree-twelve discriminant with exactly zero real roots;
- five exact nonzero projector-jet orders and the transport sign identity.

Numerical complex-root locations in the scaling record are labeled approximate. These checks validate identities and an adversarial input family, not the full propagation algorithm or its complexity experimentally.

REVISION R3 — EXACT POLYNOMIAL KERNEL FOR LOG-SIZE BLOCK-DIAGONAL INPUTS
Worker c01_l07. 7 October 2026. Exact restricted-class construction.

CONSTRUCTION

Suppose the supplied rational matrix F is block diagonal with r even-sized
blocks B_1,...,B_r, of dimensions d_1,...,d_r. In the full-basis law

  w(I)=|det F[I,I^c]|^2,  |I|=n/2,

write I_b for the labels in block b. A nonzero determinant requires the
diagonal submatrix for each block to be square, hence |I_b|=d_b/2. Conversely,
if every block is half selected, the determinant factors (up to a row/column
permutation sign) into the product of the local complementary minors. Thus

  w(I)=product_b w_b(I_b),   pi=product_b pi_b.

Each local law pi_b can be computed exactly by enumerating
binom(d_b,d_b/2) states. The one-replica kernel Q chooses a block uniformly
and replaces its state by an exact independent sample from pi_b. It is
reversible with respect to pi.

EXACT GAP AND TWO-REPLICA ENERGY

Let H_b denote conditional resampling of block b. Then
Q=(1/r)sum_b H_b. Under the product law, the tensor-product decomposition
diagonalizes these projections: a mode nonconstant on exactly s blocks has
eigenvalue 1-s/r. Therefore the one-replica spectral gap is exactly 1/r
(when at least one block has a nonconstant state space). Equivalently,

  E_Q(f)=(1/r)sum_b E[Var(f | all blocks except b)]
         >= Var_pi(f)/r,

with equality for a nonconstant function of one block.

For two independent replicas define P to choose A or B with probability 1/2
and apply Q to that replica. For every real f1,f2, independence and the fact
that an update changes only one summand give

  E_P(f1(A)+f2(B))=(E_Q(f1)+E_Q(f2))/2
                    >= Var_pi(f1)/(2r).

The exact pair-energy constant is L=2r; a function depending on one block
with f2 constant attains equality.

The sampler and bound avoid full enumeration of the product state space. If
the block decomposition is supplied or recovered from the exact zero pattern
of F and max_b d_b=O(log n), then each local state table has at most
2^(O(log n)) entries. Across all blocks, exact determinant preprocessing and
integer categorical sampling therefore have polynomial bit cost. For fixed
block size six, exactly 20 local minors are evaluated per block. If a block
is large, this construction pays its exponential local enumeration cost and
does not claim a general polynomial sampler.

EXACT CHECK

The executable work/cycle6/c01_l07/revisions/r3_bounded_block_heatbath.py
uses two copies of the delta=1/8 six-coordinate block. It constructs exact
Fractions, explicit one-replica kernels for r=1,2, and checks row sums,
detailed balance, the product stationary law, a unit-variance witness, and
its exact energies. Results are in
work/cycle6/c01_l07/revisions/r3_bounded_block_heatbath_result.json. The
observed cases have global support sizes 14 and 196, pair support sizes 196
and 38,416, and exact energy constants 2 and 4. The r=2 matrix has 924 global
fixed-cardinality candidates, while local preprocessing needs only 40
three-by-three determinants (20 per block). The pair kernel is implicit; no
38,416-by-38,416 transition matrix is materialized.

STATUS AND BOUNDARY

This is a genuine exact construction for a decomposable, supplied-input
subclass. It explains why the two-block example from R2 is easy if one can
selectively refresh a block: exact block heat-bath removes its product-sign
mode with L=2r. It supplies no method to find a useful decomposition for a
general dense F, and no transition normalizer for a connected determinant
kernel. The general microscopic energy lemma and hard-BCS FPRAS remain open.

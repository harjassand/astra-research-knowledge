QUANTUM OUTPUT CONTRACT
Trace distance is half trace norm. Each label gives exact rational PSD trace-one
local2x2 density matrices. Their tensor-product mixture has the stored total
target trace-distance upper bound. This implies at most that TV error for any
fixed common measurement. Displayed angles are floating diagnostics only.
The default label sampler uses a fixed finite fair-bit budget, including
quantified near-uniform phase/subset choices. Seeded examples use Python PRNG;
the exact sampling law assumes independent uniform bits. No physical apparatus
or amplitude-to-device conversion is included.

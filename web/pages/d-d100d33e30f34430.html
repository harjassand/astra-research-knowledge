CYCLE09 PRETTY-GOOD / TRANSPOSE RECOVERY SCOPE CHECK
Status: exact purified-state subcase closes; arbitrary mixed-extension interface remains UNKNOWN from this bounded source pass.

Question
--------
For CPTP Phi with faithful Phi-fixed state sigma, let

  Phi^sharp(X)=sigma^(1/2) Phi^*(sigma^(-1/2)X sigma^(-1/2)) sigma^(1/2).

Given rho_RB with rho_B=sigma and b=(1/2)||rho_RB-(id_R tensor Phi)(rho_RB)||_1, does pretty-good/transpose recovery give a bound on

  r=(1/2)||rho_RB-(id_R tensor Phi^sharp Phi)(rho_RB)||_1

for arbitrary mixed rho_RB, using the same local Phi^sharp? The answer depends on whether rho_RB is a purification of sigma or a general mixed extension.

Exact positive match: a purification of sigma
---------------------------------------------
Barnum and Knill, “Reversing quantum dynamics with near-optimal quantum and classical fidelity,” arXiv:quant-ph/0004088v2 (18 Jan 2026; journal version, J. Math. Phys. 43 (2002), 2097-2106, DOI 10.1063/1.1459754), https://arxiv.org/abs/quant-ph/0004088 and version-pinned HTML https://arxiv.org/html/quant-ph/0004088v2.

Their reversal map (Eq. (12), Sec. IV) for a channel A with Kraus operators A_i and reference input state omega is

  R_{A,omega} ~ { omega^(1/2) A_i^dagger A(omega)^(-1/2) }_i.

If A=Phi, omega=sigma, and Phi(sigma)=sigma, this is exactly the unrotated Petz adjoint Phi^sharp. Theorem 3, Eq. (13), says for a finite ensemble E={p_i,rho_i} of commuting density matrices with average omega, and every CPTP recovery R,

  Fbar_e(E,R_{A,omega} A) >= Fbar_e(E,R A)^2.

Take the singleton ensemble E={sigma}; its commuting assumption is vacuous, and Fbar_e=F_e. Take the competing recovery R=id. Then

  F_e(sigma, Phi^sharp Phi) >= F_e(sigma,Phi)^2.

Here F_e(sigma,T)=<psi_sigma|(id tensor T)(|psi_sigma><psi_sigma|)|psi_sigma> for a purification psi_sigma of sigma. Thus if the observed state rho_RB is itself a purification psi_sigma and b_pur=T(psi_sigma,(id tensor Phi)(psi_sigma)), measurement with the projector psi_sigma gives F_e(sigma,Phi)>=1-b_pur. Therefore

  F_e(sigma,Phi^sharp Phi) >= (1-b_pur)^2,
  r_pur <= sqrt(1-(1-b_pur)^2) <= sqrt(2 b_pur).

This is dimension-free, uses the exact fixed unrotated Phi^sharp, and needs no mutual-information budget. It closes the pure purification subcase. It does not establish the same estimate from the b of an arbitrary mixed extension.

Why the general mixed extension is outside this theorem
-------------------------------------------------------
Entanglement fidelity F_e(sigma,Phi) tests Phi on a purification of sigma. An arbitrary mixed extension rho_RB with rho_B=sigma is generally a channel output of such a purification, not a purification itself. If Gamma maps the purifying reference to R, then rho_RB=(Gamma tensor id)(psi_sigma), and trace-distance contractivity gives

  T(rho_RB,(id tensor Phi)(rho_RB)) <= T(psi_sigma,(id tensor Phi)(psi_sigma)).

The inequality points the wrong way for using a small mixed-extension b to bound the purification error. The BK theorem applied instead to the composite channel id_R tensor Phi with input reference rho_RB produces a transpose map based on the full input rho_RB; in general that map is not id_R tensor Phi^sharp. The paper's Theorem 3 also explicitly assumes a commuting ensemble; immediately after Corollary 4 it says the authors do not know whether their Petz reversal remains near-optimal for noncommuting ensemble members (Sec. IV, paragraph following Eq. (10)).

An elementary scope check makes the distinction concrete. Let sigma=I_2/2, Phi(X)=Xconj by Pauli X, and rho_B=sigma with a trivial reference. Then b=0, Phi^sharp=Phi^{-1}, and Phi^sharp Phi(rho)=rho exactly, while F_e(sigma,Phi)=|Tr X|^2/4=0. So entanglement fidelity of the purification is not inferred from the observed mixed-state residual. This is not a counterexample to the target mixed-state conclusion; the Petz round trip on this rho is exact.

Later code-space near-optimal theorem
------------------------------------
Zheng, He, Lee, and Jiang, “Near-Optimal Performance of Quantum Error Correction Codes,” arXiv:2401.02022v2 (17 Jun 2024), Phys. Rev. Lett. 132, 250602 (2024), DOI 10.1103/PhysRevLett.132.250602. Primary sources: https://arxiv.org/abs/2401.02022, v2 HTML https://arxiv.org/html/2401.02022v2, APS DOI page https://doi.org/10.1103/PhysRevLett.132.250602.

Section I, Eqs. (2)-(3), defines channel fidelity using the purification of the maximally mixed logical code state. Theorem 1, Eqs. (4)-(5), gives a computable near-optimal fidelity Ftilde_opt and

  (1/2)(1-Ftilde_opt) <= 1-F_opt <= 1-Ftilde_opt.

Section II and Supplemental Lemma 1, Eqs. (S7)-(S8), identify the transpose channel as achieving this near-optimal fidelity. This is a strong full-reference theorem for a code channel: it tests the maximally mixed logical input together with its purification and compares the transpose decoder with the optimal decoder. In the full-code special case with sigma=I/d, it is closely aligned with the pure maximally entangled extension. It still does not turn the residual of an arbitrary mixed extension into that channel fidelity, and its transpose decoder is code/noise specific. It does not supply a bound for arbitrary faithful sigma and arbitrary mixed rho_RB as posed here.

Conclusion of this source pass
------------------------------
Pretty-good recovery does yield the desired sqrt(b) scaling for a purified sigma input, by a short exact application of Barnum-Knill with the identity as competing recovery. The cited later code theorem reinforces this for maximally mixed code-space channel fidelity. Neither theorem directly controls a general mixed extension rho_RB from its own forward trace residual b using the same local Phi^sharp. The gap is the passage from one possibly degraded extension to the full purification/entanglement-fidelity criterion, while retaining the prescribed product-local Petz map. No counterexample to the coordinator's arbitrary-mixed candidate is supplied here; literature/priority status for that interface remains UNKNOWN.

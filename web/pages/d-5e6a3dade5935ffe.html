# Per-link PoC does not imply event-time neighborhood availability

## Claim and scope

This is an internally reconstructed, exact counterexample to a *naive edge-by-edge extension* of the Persistency-of-Communication (PoC) condition in Senejohnny, Tesi, and De Persis (2015). It does not refute that paper: its model has a shared medium, so every DoS interval disables the whole network together. The counterexample shows that applying its scalar frequency/duration test separately to each directed edge is insufficient for a self-triggered rule that requires a complete neighbor vector at each event.

The interface is explicit. There are four scalar-state agents on the complete directed graph (K_4), without self-links. They sample at common event times. A conservative full-vector controller updates only when all three incoming values arrive; on any missing value it sets its control to zero and retries after δ. A same-event baseline instead averages its own state with the two neighbor values that did arrive. The event schedule is self-triggered after a failure; no continuous sensor monitoring is used.

## Attack schedule and per-edge budget

Let the retry interval be

\[
\delta=\Delta_* = \frac{\varepsilon}{4d_{\min}}=\frac{\varepsilon}{12}.
\]

At event phase (r\in\{1,2,3\}), every receiver (i\in\{0,1,2,3\}) loses the incoming link from sender (i+r\pmod 4). Thus each receiver loses exactly one of its three incoming links at every poll, while each directed edge is attacked only once every three polls. Give each attack window duration \(\rho=\delta/10\), centered on its event time. For every directed edge, the duration/frequency envelopes hold with

\[
\eta=1,\quad \tau_f=3\delta,\quad \kappa=\rho,\quad
\tau_d=\frac{3\delta}{\rho}=30,
\]

and the per-edge PoC expression is

\[
\phi_e=\frac{1}{\tau_d}+\frac{\Delta_*}{\tau_f}
      =\frac{1}{30}+\frac{1}{3}=\frac{11}{30}<1.
\]

So every edge separately satisfies the same numerical threshold as the global-DoS result. The union of outages at each receiver nevertheless contains one missing input at every sample. The receiver-level union has an event rate (1/\delta), which is not bounded by any one edge's rate (1/(3\delta)).

One explicit initial transient follows the ternary sign law in the 2015 source: use \(\varepsilon=0.01\), start at \((0,0,1,1)\), and let the first sample at time zero succeed. Each low-state node has \(\mathrm{ave}=2\), each high-state node has \(\mathrm{ave}=-2\), so all four timer intervals are (2/(4\cdot3)=1/6\). The controls move the state to \((1/6,1/6,5/6,5/6)\), still at diameter (2/3>\varepsilon\). The first incomplete sample is at (1/6); it zeros all controls and sets the common retry interval to \(\delta=\varepsilon/12\). Rotate the missing links on each retry as specified above.

## Consequence for the full-vector controller

At each event, every receiver sees an incomplete input vector. Under the stated fail-closed rule, all controls are zeroed and the next attempt occurs after \(\delta\). The adversary rotates the missing link so the next event is incomplete again. After any initial successful transient that leaves diameter (D_0>\varepsilon), the state is constant and the controller never reaches the consensus target.

This attack uses no Byzantine node and no message tampering. It isolates the sampling/link-timing interface: very high individual edge availability does not imply availability of a complete neighborhood *at the event instants*.

## Same-information baseline and exact quantitative result

The baseline uses exactly the same event times and the same successful messages. At each event, node (i) averages its own state with the two successfully received neighbor values. For phase (r\in\{1,2,3\}), the row-stochastic update matrix is

\[
P_r(i,j)=\begin{cases}
1/3,&j=i\text{ or }j\notin\{i,i+r\pmod4\},\\
0,&\text{otherwise.}
\end{cases}
\]

The exact three-event product is

\[
P_3P_2P_1=\frac1{27}
\begin{pmatrix}
7&7&6&7\\
7&7&7&6\\
6&7&7&7\\
7&6&7&7
\end{pmatrix}.
\]

The minimum overlap between any two rows is (26/27), so its Dobrushin coefficient is exactly (1/27). Therefore

\[
\operatorname{diam}(x[3m])\le 27^{-m}\operatorname{diam}(x[0]),
\]

and the baseline reaches diameter at most \(\varepsilon\) within

\[
3\left\lceil\frac{\log(D_0/\varepsilon)}{\log 27}\right\rceil
\]

events when (D_0>\varepsilon). The calculation is exact rational arithmetic and is reproducible with [`counterexample.py`](counterexample.py).

## Cost ledger

Per event, both rules attempt 12 directed messages, deliver 8 neighbor values, lose 4 messages, and take 4 local state samples. Over a three-event block this is 36 attempts, 24 delivered values, 12 drops, and 12 local samples. The fail-closed rule checks completeness (12 link-status checks per event) and makes no state update after the first incomplete sample. The baseline computes four three-term means per event (eight additions and four multiplications by (1/3)); it uses the same received information and achieves the contraction above.

For hardware accounting, leave unit costs explicit: a three-event block costs (36E_{tx}+24E_{rx}+12E_s) in message attempts, successful receptions, and local sensing, plus trigger/completeness computation and actuation. Both schemes share the communication and sample terms under the point-to-point attempt model. The baseline adds arithmetic and state-update costs. No joule values or plant-actuation model were supplied, so a total-energy winner is UNKNOWN; a message-only count would omit failed transmissions and sensing.

## Limits, falsifier, and next gate

- The exact result covers this specified complete-neighborhood/fail-closed rule and the four-node scalar baseline. It is not a counterexample to Senejohnny et al.'s shared-medium theorem or to every event-triggered controller.
- The witness has no Byzantine nodes. With Byzantine agents, using partial neighbors requires a resilient update (for example, W-MSR) and the event-sampled graph must retain a suitable robust-connectivity property. Per-edge uptime alone does not establish that property. Whether the same rotating schedule defeats a carefully designed Byzantine-resilient partial-neighbor controller is an unresolved next gate.
- A failure-aware random/jittered retry, predicted neighbor state, or link-subset controller can change the result. Test these only against the exact event-sampled graph and equal information/cost ledger above.
- A direct falsifier for the stated claim would show that the stipulated fail-closed protocol can produce a complete neighbor vector at one of the scheduled events despite the rotating drops, or that the listed (P_3P_2P_1) matrix/product or overlap is wrong. Neither occurs in the specified interface.
- Novelty/priority is UNKNOWN. Current literature separately covers Byzantine agents with self/event-triggering and independent channel DoS with event/self-triggering; the full papers and theorem interfaces still need a focused overlap search before any novelty claim.

# Exact source-count resource ladder for independent attenuated channels

2026-10-06. Lead mathematical deduction extending check_vector's sharp one-source versus n-source theorem. This is an exact resource criterion for the supplied weighted-block family, not a conductivity PDE realization. Generic rank-constrained covariance design is established prior art; priority of this particular interpolation is unverified.

## Model and resource interface

Use H=Y=ℓ²(N;R^n), unknown A in a supplied Frobenius ball in Sym(n) with τ||A||_op<1, and F_A=⊕_l w_l(I+τA), where 1=w₁≥w₂≥…>0 tends to zero. Parameter dimension is D=n(n+1)/2. There are k simultaneous or separately executed source currents f_j=(f_{jl}), 1≤k≤n, with total hard squared input norm Σ_{j,l}||f_{jl}||²≤E.

The noise interface is independent Gaussian noise of variance σ² in orthonormal coordinate voltage tests. The sum of full-coordinate Fisher contributions is an upper bound on any retained subset of these readings. If an infinite observation experiment is invoked, white noise means a Gaussian product sequence; it is not an ℓ²-valued noise vector. Below the optimum is attained with only n² acquired coordinate scalars, for every k. Arbitrary repeated or nonorthogonal unit detector banks can redistribute information and are outside this exact equality; the separate randomized minimax obstruction allows those banks. Source settings k are charged independently of input power and scalar count. All weights and the operator model are known.

Subtract the known baseline. The Fisher quadratic for a perturbation V∈Sym(n) is

    I_f[V,V]=(τ²/σ²)Σ_{j,l}w_l²||V f_{jl}||²
             =(τ²/σ²)tr(V² C),
    C=Σ_{j,l}w_l² f_{jl} f_{jl}ᵀ.

For ||V||_F=1 its minimum is (τ²/σ²)λ_min C: the lower bound follows from C≽λ_min(C)I, and V=uuᵀ for a minimum eigenvector attains it.

## Exact theorem

Define

    S_k=Σ_{i=1}^n w_{ceil(i/k)}⁻².

Then the optimal minimum Fisher eigenvalue over at most k sources and energy E is

    max_f min_{||V||_F=1} I_f[V,V]
       = τ²E/(σ²S_k).                              (1)

The maximum can be attained with exactly n nonzero source-block vectors and n coordinate readings from each, hence n² scalar acquisitions. For k=1 this recovers S₁=Σ_{l=1}^n w_l⁻². For k=n it gives S_n=n and the strongest first physical block is reused n times.

### Upper bound proof

If α=λ_min C is zero there is nothing to prove. Otherwise set

    x_{jl}=w_l C⁻¹/² f_{jl}.

The n-by-countable-column matrix X with these columns satisfies XXᵀ=I_n. Therefore XᵀX is an orthogonal projection of rank n. Each column's squared norm is a diagonal projection entry in [0,1]. The group leverage

    q_l=Σ_{j=1}^k||x_{jl}||²

obeys 0≤q_l≤k and Σ_l q_l=n. Nonnegative sums are legitimate even for infinitely many blocks. Since C≽αI,

    E≥Σ_{j,l}||f_{jl}||²
      =Σ_{j,l}w_l⁻²||C¹/²x_{jl}||²
      ≥αΣ_l w_l⁻² q_l.

Among group masses in [0,k] with total n, increasing block costs w_l⁻² are minimized by filling the cheapest groups to capacity k and then any remaining mass in the next group. Equivalently repeat each cost k times and choose the first n unit slots. Thus Σ_l w_l⁻²q_l≥S_k and α≤E/S_k. If costs tie, the same value holds with nonunique minimizing allocation. This proves the upper bound in (1), including full-output information.

### Attainment and charged measurements

Enumerate the first n slots (j,l), with j=1,…,k filled before moving to the next block l. Assign a different orthonormal coordinate e_i to each slot and set

    α=E/S_k,   f_{jl}=√α·w_l⁻¹e_i

on those slots and zero elsewhere. Then C=αI and total input norm is αS_k=E. Each of the k currents may occupy multiple blocks. Retain the n coordinate voltages only from its nonzero blocks. There are exactly n such source-block vectors and exactly n² scalars. The signal columns, after subtracting the known baseline, are all τ√α A e_i, independently of the occupied block's weight. Thus no uncharged extra coordinate readings are needed to attain (1).

The symmetrized column estimator has exact mean-square Frobenius error

    E||A_hat−A||_F² = Dσ²/(τ²α)
                    = Dσ² S_k/(τ²E).               (2)

Projection onto any admitted Frobenius ball improves this error. The estimator needs O(n²) arithmetic before projection. Equation (2) is the risk of this explicit attaining design; it is not claimed to be the bounded-parameter minimax optimum at every noise level.

## Operational use and limitations

For a required minimum Fisher level λ, this interface needs energy at least λσ² S_k/τ². A known setup cost per source can be compared with the explicit decreasing sequence S_k, while the n² scalar count stays fixed. The criterion distinguishes the number of available nonzero channels from their attenuation and from the number of independent vectors each channel can receive across source settings. One source has capacity one per physical block; k sources have capacity k.

This is a finite calculation from supplied weights. Acquiring certified weights or analogous normalized-secant channel strengths for a nonradial boundary PDE is a separate unresolved step. The family is compact positive symmetric but not globally coercive; every nonzero parameter contrast has infinite rank. Infinite rank alone leaves all S_k constants uncontrolled.

The upper bound is against full orthonormal coordinate output with white Gaussian noise. Analog repeated detector gains, correlated noise, restricted electrodes, Joule dissipation, unknown model structure and adaptive source settings need separate contracts. The theorem supplies no special efficiency advantage for random currents and no continuum EIT claim.

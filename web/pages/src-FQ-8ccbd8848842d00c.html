## 1. Results worth retaining

The useful scientific abstraction is a **rewiring of independent joint preparations**, with a specified logical reference assignment. Its tagged output is conditionally product, but its complete output is generally an edge-correlated quantum state. This distinction permits stronger deductions than the tagged trace-distance bound alone.

1. **An exact universal two-for-one preparation lower bound extends beyond routing.** To output `m` globally independent, exactly marginal-preserving decorrelated pairs from `N` unknown iid joint preparations, any universal fixed-budget quantum operation needs `N >= 2m`. A polynomial-degree proof works even if the operation can control the environment, and even with heralded success. It therefore cannot be bypassed merely by replacing swaps with a more elaborate quantum circuit. The target and universality restrictions are essential.
2. **All-output entropy accounting is exact.** For a condition class with `k` members, the mutual information between all logical data-reference registers and all environments is unchanged. A derangement converts `k I(RS:E)` bits of that information into total correlations between the logical output blocks. There is no global erasure of these correlations.
3. **The checkpoint's swap compilation can be improved.** A class of size `k >= 2` requires only `ceil(k/2)` block swaps using pairs and, for odd `k`, one triple. The checkpoint's single cycle uses `k-1`. Tagged output states are the same under the ideal contract.
4. **All endpoints can support a rigorous mean estimator.** Conditional output components have sizes at most three under pair/triple routing. After accounting separately for random labels, four-arm estimation admits the sufficient per-arm radius `sqrt(6 log(8/delta)/(BN))` for `B` independent batches of size `N`. This is not a claim that endpoints are iid. The original batch-only bound remains valid with weaker independence assumptions.
5. **A zero tagged contrast cannot certify a Markov process.** The candidate addresses present `(R,S)` versus `E` associations conditional on the actual classical record. Environmental records of earlier histories can remain even when the present tagged state is exactly product.
6. **Reference assignment can supply the entire observed contrast.** There are allowed states for which swapping the data registers changes no physical density operator, yet the donor-tracked score changes by `3/4`. This is a valid change to the logical routing-and-reference task, but it does not by itself demonstrate changed local processor dynamics.

These results improve the mathematical resource and interpretation contract. They do not close the source's decisive open gate: a jointly certified intervention that changes the intended associations without uncontrolled environmental action, followed by a cost-matched held-out decision advantage.

## 2. Exact operation and conventions

Write `A = RS` for a logical data-reference block. For one actual classical record `c`, let the normalized joint state be `rho^c_AE`. Independent preparations give

\[
 \rho_{C^N A^N E^N}
 =\sum_{\mathbf c}\Big(\prod_j p_{c_j}\Big)
 |\mathbf c\rangle\langle\mathbf c|\otimes
 \bigotimes_{j=1}^N\rho^{c_j}_{A_jE_j}.
\]

Condition on the **whole observed label vector** throughout the output-graph calculation. Choose a permutation `pi` such that `c_pi(i)=c_i`, using the labels and parameter-independent randomness only, not unrecorded microscopic states or measurement outcomes on `A/E`. Recipient site `i` receives donor data `S_pi(i)`; the logical reference scored with it is `R_pi(i)`. In the output factorization, define

\[
 B_i=(A_{\pi(i)},E_i)=(R_{\pi(i)},S_{\pi(i)}\text{ delivered to }i,E_i).
\]

This notation does not assert that `R` physically moves. It defines the logical output partition. The physical operation is on `S`; the logical partition follows the donor reference. With a fixed assignment it is equivalent, for reduced-state calculations, to relocating the whole `A` block and retaining the corresponding labeling.

The full state is still a tensor product of the original factors on their original correlated subsystem pairs:

\[
 \Omega_{\mathbf c,\pi}
 =\bigotimes_j \rho^{c_j}_{A_jE_j},
 \qquad\text{viewed in the output partition }\{B_i\}_i.
\]

Each original factor joins the `A` subsystem in output `pi^{-1}(j)` to the `E` subsystem in output `j`. Thus the original correlations become edges of the permutation graph. An input's quantum correlations remain quantum correlations on these edges; this is not a hidden-variable reduction.

For a moved site, the tagged state is exactly

\[
 \Omega_{B_i}=\rho^{c_i}_A\otimes\rho^{c_i}_E.
\]

A fixed point retains `rho^c_AE`. This proof requires independent **joint** preparations conditional on the full label vector. Equal one-replica marginals are insufficient. A shared latent variable, shared quantum reservoir, or entangled preparation stream can invalidate the factorization.

The supplied finite-batch rule moves every nonsingleton class and leaves singleton classes untouched. Its tagged output is therefore the stated mixture with singleton probability `(1-p_c)^(N-1)`. No claim in this report removes that sparsity cost.

## 3. Global information is relocated, with an exact retained-subset criterion

Assume finite-dimensional registers, or finite entropies wherever the following entropy expressions are used. Let `I_c = I(A:E)_{rho^c}` and let `M` be the set of moved sites. Independence and the invariance of entropy under subsystem permutations imply

\[
 I(A^N:E^N)_{\Omega\mid\mathbf c}
 =\sum_j I_{c_j}.
\]

The total correlation, also called multipartite mutual information, of the output partition is

\[
 \begin{aligned}
 T(B_1:\cdots:B_N)_{\Omega\mid\mathbf c}
 &:=\sum_i H(B_i)-H(B_1\cdots B_N)\\
 &=\sum_{i\in M}I_{c_i}.
 \end{aligned}
\]

For an iid class of size `k` with no fixed point this is exactly `k I_c`. The local entropy increase is balanced by correlations between outputs; global entropy has not increased.

For a retained site set `T` chosen from the labels and routing record without quantum-outcome postselection, the retained `A` donor indices are `pi(T)` and the retained environment indices are `T`. Every original factor indexed by `j` contributes one of four possibilities:

| Membership of `j` | Factor remaining in the retained marginal |
|---|---|
| `j in pi(T) intersect T` | Full `rho^{c_j}_{A_jE_j}` |
| `j in pi(T)` but not `T` | `rho^{c_j}_{A_j}` |
| `j in T` but not `pi(T)` | `rho^{c_j}_{E_j}` |
| Neither | Scalar trace one |

These factors are mutually independent. In particular,

\[
 I(A_{\pi(T)}:E_T)_{\Omega\mid\mathbf c}
 =\sum_{j\in\pi(T)\cap T}I_{c_j}.
\]

The exact universal condition for retaining jointly independent product-marginal outputs is

\[
 \pi(T)\cap T=\varnothing.
\]

Sufficiency follows directly from the table. Necessity is universal rather than state-by-state: if an edge remains, choose a correlated input state on that edge. For example, if each original pair consists of identical independent fair classical bits, the covariance between the sum of retained `A` bits and the sum of retained `E` bits is `|pi(T) intersect T|/4`, whereas the fully decorrelated target has covariance zero. A product input is a state-specific exception.

The disjoint-set condition forces `N >= 2|T|`. Pair swaps followed by retaining one recipient from each pair attain equality. Conditioning can reduce attainable throughput further because partner labels must match. A whole correlated workload can be treated as one larger `A/E` module if there are independent preparations of that **whole** module; treating its internally correlated pieces as independent copies is invalid.

Randomizing the permutation does not supply a universal escape: for the classical fair-bit witness, each permutation contributes nonnegative covariance. If every output is retained, the global sums of `A` and `E` bits remain identical in every realization, so forgetting the routing record cannot turn them into independent collections.

### A concrete higher-order correlation warning

For the checkpoint's Bell-phase model, an echo endpoint on a cycle scores

\[
 X_i=\mathbf 1\{e_{\pi(i)}=e_i\},\qquad e_j\sim\mathrm{Bernoulli}(u)\text{ independently}.
\]

For a two-cycle, the two scores are identical. For any cycle,

\[
 \sum_i(1-X_i)\equiv0\pmod 2.
\]

At `u=1/2`, cycles of length at least three have pairwise-independent fair endpoint scores, but the parity constraint remains. Pairwise covariance checks alone cannot certify full independence. For `q=(1-u)^2+u^2`, `v=u(1-u)`, the exact sum variance is

\[
 \operatorname{Var}\!\Big(\sum_iX_i\Big)=
 \begin{cases}
  2kq(1-q),&k=2,\\
  4kv(1-3v),&k\ge3.
 \end{cases}
\]

The finite checks enumerate these distributions through cycle length seven. The graph description explains both the local product state and the surviving higher-order dependence.

## 4. A universal exact preparation lower bound, beyond swaps

**Theorem.** Let `dim A >= 2` and `dim E >= 2`, so the classical two-bit family below embeds in the input spaces. Fix a finite copy budget `N`. Let a physical quantum operation, with arbitrary parameter-independent ancillas and adaptive internal measurements, take `N` independent preparations of an unknown joint state `rho_AE` and output `m` pairs with exact state

\[
 (\rho_A\otimes\rho_E)^{\otimes m}
\]

for every allowed input state. Then `N >= 2m`, provided the allowed family includes the following classical one-parameter states. The result holds even if the operation can control `A` and `E` jointly, and therefore also holds for an environment-inaccessible or reference-preserving subclass.

**Proof.** Take constant `C`, trivial `R`, and

\[
 \rho_t=t|00\rangle\langle00|+(1-t)|11\rangle\langle11|,
 \qquad 0<t<1.
\]

The input `rho_t^{tensor N}` is an operator-valued polynomial in `t` of degree at most `N`. A fixed quantum channel is linear in that operator. Therefore the probability of every fixed output effect is a scalar polynomial of degree at most `N`. The target assigns probability `t^{2m}` to the effect that all `m` output `A` bits and all `m` output `E` bits are zero. Equality for every `t` in an interval forces a polynomial of degree `2m` to have degree at most `N`. Hence `N >= 2m`. QED.

For heralded operation, collect the designated successful branches into a trace-nonincreasing completely positive map. Its success probability `q(t)` is a polynomial of degree at most `N`. If the successful normalized output equals the target wherever `q(t)>0`, the unnormalized all-zero probability is

\[
 q(t)t^{2m}.
\]

A nonzero polynomial `q` gives degree `deg(q)+2m`; this is at most `N` only if `N >= 2m`. It is enough to require exactness on an open interval of nonzero success; the polynomial identity extends from that interval. This does not grant a zero-success protocol any capability.

Adaptive protocols that use at most `N` preparations fit the same proof: pad unused preparations and combine measurement branches into one CP instrument. Parameter-independent randomness can be averaged into that instrument. A protocol with an unbounded stopping time or only an expected-copy bound is outside this argument; no exact expected-copy lower bound is claimed here.

The result is not a ban on two locally decorrelated outputs from two inputs: their joint output generally has edge correlations. Nor does it cover a supplied exact description of `rho_t`, parameter-dependent ancillary preparations, an oracle for marginal preparation, a fixed known state, approximate output, or restricted scalar scores. These change the information or target contract.

An elementary finite-error obstruction is also available, without claiming a useful asymptotic approximate-copy theorem. If every input in `t in [0,1]` has trace error at most `epsilon`, the all-zero effect differs by at most `epsilon`. For `N=2m-1`, take the `2m`-th finite difference on the grid `j/(2m)`. Its value on every degree-`N` polynomial is zero and its value on `t^{2m}` is `(2m)!/(2m)^{2m}`. The sum of absolute binomial coefficients is `2^{2m}`, so

\[
 \epsilon\ge\frac{(2m)!}{2^{2m}(2m)^{2m}}.
\]

For `m=1`, this gives `epsilon >= 1/8` with one input copy. The bound decays rapidly with `m` and should not be advertised as a sharp scalable approximate-copy lower bound. Exact rational finite differences through `m=6` are checked.

This is an independently derived obstruction within this report. General decorrelation impossibility and the need to add noise for various signal families are established prior art; see [D'Ariano et al., *Erasable and Unerasable Correlations*](https://arxiv.org/abs/quant-ph/0703171) and their longer [*Quantum state decorrelation*](https://arxiv.org/abs/0712.0896). The priority of this particular elementary copy-ratio formulation has not been searched exhaustively and remains UNKNOWN.

## 5. Cheaper compilation and an estimator that uses every endpoint

### 5.1 Minimum swap count among derangements

A permutation on `k` elements with `r` cycles requires `k-r` transpositions. In a derangement, every cycle has length at least two, so `r <= floor(k/2)`. The minimum count is consequently `ceil(k/2)`. It is attained by pairs for even `k`, and one triple plus pairs for odd `k >= 3`.

Every site still receives an independent same-condition donor, so the tagged state and singleton formula are unchanged. Under arbitrary connectivity this reduces the count from `k-1` to `ceil(k/2)`. On a restricted routing graph, nearest-neighbor transport, scheduling, congestion, block size and bath action can change the physical cost; transposition count is only an abstract circuit cost. References must still be tracked, stored and measured correctly.

### 5.2 Conditional measurement concentration

Assume, in addition to the checkpoint's input contract:

- the permutation is a deterministic function of labels, or its randomized choices are conditioned on and independent of the quantum inputs;
- continuation channels act independently on the logical output blocks `B_i`;
- score readout is a tensor product of block-local instruments, with an actual score `X_i in [0,1]`;
- no common uncontrolled drive, shared readout noise or cross-site continuation coupling invalidates this product-channel description.

Under pair/triple routing, the permutation components use disjoint original preparations and hence are independent **conditional on the labels**. Let their sizes be `ell_r in {1,2,3}` and their summed scores be `Y_r in [0,ell_r]`. Hoeffding's lemma gives

\[
 \mathbb E[e^{\lambda(\sum_iX_i-\mathbb E[\sum_iX_i\mid\mathbf C])}\mid\mathbf C]
 \le \exp\!\left(\frac{\lambda^2}{8}\sum_r\ell_r^2\right).
\]

The exact denominator is

\[
 \sum_r\ell_r^2=n_{\rm singleton}+4n_{\rm pair}+9n_{\rm triple}\le3N.
\]

Here `n_pair` and `n_triple` count components, rather than endpoint registers. When nearly all moved components are pairs the denominator is near `2N`. A single large cycle also has a degree-two dependency graph; a proper coloring with at most three colors yields the same conservative `3N` conditional mgf bound by Hölder's inequality. The pair/triple version is easier to compile and audit.

### 5.3 Random labels cannot be silently conditioned away

Let `o_c` be the natural tagged score and `d_c` the product-marginal tagged score in condition `c`, each in `[0,1]`. They are assumed to be the same for every calibrated replica in that condition. With count `k_c`, the unnormalized conditional expected batch sum is

\[
 \mu(\mathbf C)=\sum_c g_c(k_c),\qquad
 g_c(0)=0,\quad g_c(1)=o_c,\quad g_c(k)=kd_c\ (k\ge2).
\]

Changing one label decrements one count and increments another. The possible increment of one count is `o_c`, `2d_c-o_c`, or `d_c`; decrement gives the negative of one of those. At most one affected count is decremented and one incremented, giving

\[
 |\mu(\mathbf C)-\mu(\mathbf C')|\le3.
\]

The constant is attained in the abstract class of arbitrary bounded score pairs; physical score relations could tighten it. Exhaustive vertex checks are supplied. McDiarmid's bounded-difference mgf bound for iid labels gives

\[
 \mathbb E e^{\lambda(\mu-\mathbb E\mu)}\le e^{9N\lambda^2/8}.
\]

Combining this with the conditional measurement mgf yields, for the sum `Z` of scores in a batch,

\[
 \mathbb E e^{\lambda(Z-\mathbb EZ)}\le e^{12N\lambda^2/8}.
\]

For `B` independent batches, with mean over all `BN` endpoint scores `hat F_N`,

\[
 \Pr\{|\hat F_N-F_N|\ge t\}
 \le2\exp(-BNt^2/6).
\]

For four predeclared arms and a union bound at failure probability `delta`, a sufficient per-arm statistical radius is

\[
 r_{\rm endpoint}=\sqrt{\frac{6\log(8/\delta)}{BN}}.
\]

Each two-arm contrast has radius `2r_endpoint`. Bounds for acquisition errors, detector bias, site mismatch, gate bath action and continuation errors must still be added. To infer the fully matched ideal target from the finite-batch policy, retain the singleton correction with an upper confidence bound on `s_N`. This estimator targets the actual finite-batch policy without changing label weights or discarding rare conditions.

For the checkpoint's illustrative `B=4000`, `N=32`, `delta=.05`, the old per-arm radius is `0.0251872`; this sufficient endpoint-aware radius is `0.0154240`, with two-arm radius `0.0308479`. Both use `4BN=512000` complete preparations for four arms. The improvement here is modest because the new bound pays a conservative label-variation constant. It becomes favorable to the batch-only radius only for `N>12`. Neither number includes systematic errors or wall time. Exact finite-model mgf checks support the implementation; the inequalities above supply the general proof under their assumptions.

If the score is a quasiprobability or readout-corrected estimator of width `w`, the bounded-range argument pays `w^2`. For example, replacing a physical Bell projection with randomized local Pauli reconstruction changes the estimator range. The `[0,1]` assumption must refer to an actual recorded score, not to the desired expectation alone.

## 6. Quantum Markov and recoverability interpretation

For classical `C`, define

\[
 \gamma_{CAE}=\sum_c p_c|c\rangle\langle c|\otimes\rho_A^c\otimes\rho_E^c.
\]

It is the unique maximum-entropy classical-block extension with the same `CA` and `CE` marginals. Per block, subadditivity gives `H(AE)<=H(A)+H(E)`, with equality only for the product state. Consequently,

\[
 D_{\rm rel}(\rho_{CAE}\Vert\gamma_{CAE})
 =H(\gamma)-H(\rho)=I(A:E\mid C)_\rho,
\]

where logarithms are base two. Also, `I(A:E|C)=0` if and only if `rho=gamma`. Recovery from the classical record can be written explicitly: read `c` and append `rho_E^c` to the `CA` marginal. This is a state-dependent mathematical recovery channel; acquiring and physically preparing an inaccessible `rho_E^c` is a separate resource. The swap construction realizes a tagged product state using independent preparations instead of a marginal-state description.

The general quantum conditional-information setting is broader. Approximate recovery is related to small conditional mutual information by [Fawzi and Renner, *Quantum conditional mutual information and approximate Markov chains*](https://arxiv.org/abs/1410.0664). For quantum conditioning registers, exact Markov states have a direct-sum tensor-factor structure on the conditioning register, as characterized by [Hayden, Jozsa, Petz and Winter](https://arxiv.org/abs/quant-ph/0304007). A generic quantum register cannot be read and used to sort copies like a classical label without disturbance. No coherent-`C` extension, universal recovery implementation, or quantum-condition tomography advantage is proved by the checkpoint.

### State Markovity at a cut is weaker than process Markovity

Consider a past controlled classical history bit `h` stored in `E`. At the cut, `S` has been reset to `|0>` and `R` is constant. The present state is

\[
 |0\rangle\langle0|_{RS}\otimes\sum_h p_h|h\rangle\langle h|_E.
\]

Thus `I(RS:E)=0` and exchange produces no tagged-state change. A future CNOT from `E` to `S` nevertheless reveals `h`. The future remains dependent on the past after the system reset. This is precisely the type of dependence tested by the operational process criterion of [Pollock et al., *Operational Markov condition for quantum processes*](https://arxiv.org/abs/1801.09811).

Expanding `R` to contain the history can make the association visible, but changes the acquired input/reference contract. Conditioning on a larger actual `C` changes the estimand and the matching cost. Neither operation happens automatically. A null result for a finite family of continuations certifies only that those probes did not distinguish the corresponding interventions.

### Comparison with conditional erasure

[Berta, Brandao, Majenz and Wilde, *Conditional Decoupling of Quantum Information*](https://arxiv.org/html/1808.00135), defines deconstruction and conditional erasure using randomizing channels with ancillary resources, negligible disturbance of a specified other marginal, and recoverability or decoupling conditions. Its asymptotic noise rate is conditional mutual information. Conditional erasure permits a maximally mixed output on an appropriate subspace rather than preserving an arbitrary unknown `RS` marginal. In their notation the accessible conditioning subsystem is also part of the allowed control.

Exchange preserves the donor `RS` marginal and substitutes independently acquired partners, while retaining correlations in the total output. These are different resource and output contracts. Deterministic exchange with zero randomization bits does not violate an erasure-cost theorem: the complete exchange output has not been decoupled. Discarding complementary modules removes their correlations from the retained description and pays a preparation/disposal cost. No heat or work claim follows from the local entropy increase alone.

## 7. A reference-pairing-only contrast

Take two independent copies of

\[
 \rho_{RSE}=|0\rangle\langle0|_S\otimes|\Phi^+\rangle\langle\Phi^+|_{RE}.
\]

Both data registers are blank `|0>`. Exchanging them leaves the **entire physical density operator unchanged**. The allowed future operation swaps each resident `E_i` into `S_i`. It retrieves a Bell pair between resident `R_i` and `S_i`.

- Scoring `S_i` against resident `R_i` gives Bell success one, before or after data exchange.
- Scoring after the derangement against donor `R_j`, `j != i`, gives a maximally mixed two-qubit state and Bell success `1/4`.

The candidate's donor-tracked contrast is consequently `3/4`, exactly as predicted by its tagged product-marginal identity. The physical routing state change is zero. NumPy checks verify both facts without fitting a model.

This is not a counterexample to the algebra. The logical task changed which external reference is associated with the data delivered to a site. If the intended task explicitly follows original job identities, the loss of association with resident environmental storage can be operationally meaningful. It is, however, a counterexample to the claim that every tracked contrast establishes changed local processor behavior caused by the physical swap. The assay must name the joint routing-and-reference-assignment intervention, and its decision must depend on that logical task.

A useful controlled test records both resident-reference and donor-reference scores when those measurements are separately implementable. It can separate local physical response from changes in task association. Reference readout requires its own gate/distance/storage accounting; bookkeeping does not create a remote Bell measurement for free.

The strongest system-only representation also clarifies the information limit. If a complete operational process tensor is supplied, independent replicas have tensor-product process operators. ## 9. Acquisition lower bounds and remaining physical gates

### Records and score acquisition still cost preparations

No finite `N` makes singleton mass uniformly small over all record distributions: take a uniform distribution over `K` records with `K >> N`. In that case

\[
 s_N=(1-1/K)^{N-1}.
\]

To make this particular distribution's `s_N <= epsilon` requires

\[
 N\ge1+\frac{\log\epsilon}{\log(1-1/K)}\approx1+K\log(1/\epsilon).
\]

This is an example, not a worst-case claim over all distributions on `K` symbols. For a rare condition of probability `p`, one needs order `1/p` complete preparations just to obtain a matching partner with constant probability. The expected number of moved records of that type in a batch is exactly `Np[1-(1-p)^(N-1)]`; when `Np` is small it is about `N(N-1)p^2`. These costs cannot be eliminated by not estimating `p` explicitly.

There is also a basic score-estimation lower bound already in classical diagonal inputs. Suppose a single informative prepared experiment returns a Bernoulli bit with parameter `p_+=(1+gamma)/2` or `p_-=(1-gamma)/2`, with `0<gamma<=1/2`. Deciding which sign holds with error at most `delta<1/2` requires, by data processing of relative entropy,

\[
 n\,d(p_+\Vert p_-)
 \ge (1-2\delta)\log\frac{1-\delta}{\delta}.
\]

Since `d(p_+||p_-)=gamma log((1+gamma)/(1-gamma)) <= 4gamma^2`,

\[
 n\ge\frac{(1-2\delta)\log((1-\delta)/\delta)}{4\gamma^2}.
\]

The relative-entropy calculation uses natural logarithms. The decision margin from `1/2` is `gamma/2`. Collective quantum processing cannot circumvent this classical iid subfamily: the states commute and the input already exposes its full classical information. This is a worst-case lower bound, not a measured sample requirement for the checkpoint witness. A rare-condition decision adds the record-acquisition burden. Nothing here establishes an advantage over direct policy trials.

### Gates that remain open

1. **Independent joint source.** Preparation reset, common reservoirs, correlated drive noise and cross-site coupling need physical evidence. Independently sampled endpoint distributions alone do not certify this premise.
2. **Bath-safe joint action.** The source's invisible-environment-unitary counterexample remains decisive. Perfect reduced-register tomography and a perfect double-swap echo can coexist with a wrong environmental action. None of this report's graph or sampling algebra closes that gate.
3. **Site interchangeability and matched time.** The same-condition continuation response must be calibrated at the different recipient sites, with routing duration, idles and controller latency included.
4. **Reference meaning and access.** The score must belong to the task the user actually intends to preserve. A changed reference assignment cannot silently become evidence of changed local dynamics. Reference storage and readout cost are physical resources.

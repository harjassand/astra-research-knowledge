# Payoff-certified quantum exclusion for an interacting control decision

Read `research_note.md` for the exact mathematical/experimental contract and limitations. This is a finite four-site device, not the earlier infinite-chain coefficient. It does not implement a universal many-body solver or a physical experiment. Known state-exclusion and discrimination principles are credited.

## Reproduce

Python 3.13, NumPy and SciPy were used. The recorded exact arithmetic uses Python integers and Fraction. No SDP package is needed: the particular minimax measurement has an explicit dual certificate.

From this directory:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python benchmark.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python checks.py --verify-witnesses
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python calibration.py
```

`benchmark.py` computes six robust response families from scratch, constructs the nuisance-null probe, and checks the payoff/measurement/risk/information inequalities. It overwrites `results/` with new output and timing records. It does not execute any laboratory shots.

`checks.py --verify-witnesses` rebuilds the exact certificates from saved rational trial and inverse arrays, without invoking a numerical optimizer, and runs independently written full-Kronecker and two-level diagnostics. It rejects a deliberately corrupted proposed inverse. Timings depend on hardware.

`calibration.py` constructs an optional two-stage physical characterization budget and implements rational quadrature-to-interval conversion. Its sample inputs are clearly labelled synthetic and are not observed counts. Acceptance can be inconclusive. Characterization, known controls, readout error and actuator accuracy are not free.

## Main output files

- `results/decision_certificate.json`: exact risk and all-adaptive phase-identification bounds, robust action ordering, and fixed-probe POVM optimality margins.
- `results/*_witness.npz`: rational numerator arrays for the six many-body response calculations. Denominators are fixed and reconstructed in `finite_certificates.py`.
- `results/good_4.json`: full coefficient polynomial and exact verified error for the selected throughput type.
- `results/experiment_construction.json`: enumeration of the nuisance-null preparation, explicit readout form, sufficient finite bandwidth/timing budget.
- `results/calibration_certificate.json`: optional characterization shot/time costs and acceptance-valid confidence bound.
- `results/resource_ledger.json`, `results/checks.json`: execution and evidence boundary.

## Scientific boundary

The protocol is guaranteed for four interaction uncertainties, three fresh persistent phase-fault hypotheses and nine nominal actions, with the specified physical dephasing and error budgets. It outputs an action, not a phase estimate. The phase-learning lower bound allows arbitrary adaptive acquisition under a hard total unknown-link exposure cap, not only the chosen probe/readout. A decision-aware learner may match the protocol; no universal advantage over all direct-decision methods is claimed.

The actual laboratory readout is untested and requires rapid calibrated known controls. A stationary-throughput prediction does not provide a transient recovery deadline. The current example is a strict scoped decision-versus-identification separation, not a civilisation-level advance or a scalable large-matter prediction engine.

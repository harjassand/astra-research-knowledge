## Interface and theorem

There are three hidden states, fixed throughout one run. Source action a in {0,1,2} returns Bernoulli(1/10) in state a and Bernoulli(9/10) otherwise, with one unit charged per physical source observation. The source catalogue is supplied exactly. Write d=(4/5)log9. A finite controlled target catalogue has known rational full-support channels G_i^b, with positive rational action costs beta_b. The catalogue and its rational encoding are supplied; no calibration is implicit.

A target program is state-independent code that selects target actions, stops, and reports using its observations and private randomness. It makes at most m>=1 target calls. A supplied bit-execution bound P limits its instruction count, memory, integer bit lengths, and number of private rational choices; all rational choices have bit lengths at most B. The code can be executed under any supplied candidate state k by sampling its target channels with auxiliary randomness. The controller/report code receives no candidate-state label: it accesses the candidate only through an opaque observation oracle. It cannot inspect the callback closure, channel-sampler implementation, retry counts, timing, or candidate-dependent backend state; controller decisions use logical observations and original coins only. Its terminal report can be an arbitrary bounded circuit or program, with a potentially exponentially large finite report space. Exact rational choices use fair-bit rejection, whose expected work is charged; a hard cap on raw random bits is not assumed.

Independently reconstructed conditional theorem: an executable source program reproduces the joint augmented target execution record exactly, and therefore its terminal report exactly, in every state. Its expected physical-source cost obeys

E_i N <= gamma_i E_i C_G + C sqrt(m),

gamma_i=max_b max_{j!=i} D(G_i^b || G_j^b)/(d beta_b).

C depends on the fixed catalogue and source, not the target code, output cardinality, or m. Compiler preprocessing and expected auxiliary bit/CPU work are polynomial in m, B, catalogue encoding size and P. This is a polynomial in the actual hard horizon and the supplied bit-execution bound, not in log(m), and not a claim that arbitrary succinct programs have small P. The source observation count has no hard cap. The first-order coefficient is sharp for the full-record interface, by repeating any target action and the stopped likelihood/KL lower bound.

The bounded-program contract is narrower than Li–Liu's arbitrary integrable mathematical target-policy theorem. In particular the asserted remainder here is sqrt(m), not sqrt(E_i T). An effective compiler for arbitrary unbounded target programs remains open.

## Removing terminal-law extraction

Let h retain the target action/observation sequence, the ORIGINAL controller/report private-choice outcomes, and the terminal report. Discard all artificial channel-sampling fair bits. Retaining those bits is invalid: the deterministic seed-to-observation map can depend on the candidate state and destroy common support. Record a rational controller coin outcome as its finite discrete outcome, not the fair-bit rejection trace used to generate it. Under state i its mass factors as

H_i(h)=s(h) product_t G_i^{b_t}(x_t),

where s(h) is the common state-independent execution/randomness factor. Original controller/report private correlations can be retained explicitly; artificial channel-sampling randomness is marginalized out. Impossible executions are never proposed, and full support makes every legal execution common to every candidate state. Consequently

H_i(h)/H_k(h)=product_t G_i^{b_t}(x_t)/G_k^{b_t}(x_t).

A candidate-k proposal is generated by running the original code with candidate-k auxiliary channel draws. The converter never evaluates s(h), H_i(h), the probability of a terminal circuit event, or the size of the report support. Only likelihood ratios along the proposed execution are evaluated. This avoids the specific #P-hard terminal-H extraction identified by r05; it does not refute that extraction lower bound.

Let R0>=1 be the largest single-target-observation likelihood ratio, in either direction, across states and actions. Then H_i/H_j<=R=R0^m on every augmented record. Computing these rational ratios uses O(m B) bits, up to a catalogue encoding constant. R can be represented or bounded by a rational power; no logarithm need be compared for exact threshold selection.

## Classifier and scalar verifier

Use a balanced source classifier with r readings per action, selecting the smallest success count and breaking ties uniformly. Its exactly computable confusion matrix is

A(r)=(1-3b(r))I+b(r)J,

with b(r)<=(9/25)^r. An O(r) binomial integer recurrence gives b exactly; denominators have O(r) bits. Choose eta=1/(30m), and r0 so 2b(r0)<=eta. A0=A(r0) costs 3r0 observations.

After classifier label k, propose h~H_k. Let L be the smallest positive integer with 9^L>=1/eta; let U_k(h) be the smallest integer with

9^U >= eta^-1 max(1,max_{j!=k} H_k(h)/H_j(h)).

Query source action k until a walk, incrementing +1 for observation zero and -1 for one, hits +U or -L. Under state k its positive-step probability is .9; in either wrong state it is .1. Its exact acceptance probabilities are

p_wrong=(9^L-1)/(9^(U+L)-1),
p_own=9^U p_wrong.

Thus own rejection<=eta and cross acceptance<=eta H_i(h)/H_k(h). The expected verifier observations are <=U/(4/5) under the candidate state and <=L/(4/5) under a wrong state. Threshold comparisons and these probabilities are rational/integer operations, avoiding undecidable equality comparisons between computable real logarithms.

Thin a successful verifier independently by a=(1-eta)/(1+2eta). The accepted submass is

Q_i(h)=a sum_k A0(i,k) H_k(h) p_i(k,h).

Put T_i=H_i-Q_i. The same pointwise argument as the finite-transcript fixture gives

eta H_i(h)<=T_i(h)<=6 eta H_i(h).

The missing masses delta_i=sum_h T_i(h) need not coincide and need not be computed.

## Fresh-classifier joint residual repair

Choose rR so b=b(rR)<=1/(36R), let A=A(rR), lambda=1-3b, and

W_k(h)=[T_k(h)-b sum_i T_i(h)]/lambda.

Since sum_i T_i<=18 eta R H_k, the numerator is >=eta H_k/2. Also lambda>=11/12, so 0<=W_k<=7 eta H_k. Both W_k/H_k and Q_i/H_k are evaluated from the likelihood ratios and scalar verifier probabilities; no normalizer or support enumeration appears.

On initial failure, repeat the following JOINT trial: take a fresh physical classifier with matrix A; call its label k; run the target code under candidate k to propose h; accept with probability W_k(h)/(7 eta H_k(h)). If rejected, reclassify afresh before the next proposal. One trial has state-i accepted submass

sum_k A(i,k) W_k(h)/(7 eta)=T_i(h)/(7 eta).

Its acceptance probability is delta_i/(7 eta)>=1/7, so the eventual law is T_i/delta_i. The original failure branch has probability delta_i, hence the complete output law is Q_i+T_i=H_i exactly. Discard the internal record to obtain the requested terminal report.

Classifying only once and then retrying proposals from that row is generally incorrect when the delta_i differ. The physical repair cost, unconditionally, is exactly

delta_i * [7 eta/delta_i] * 3rR =21 eta rR.

This joint normalization identity removes any need to calculate delta_i and preserves the small expected repair contribution. It is an application of classical unnormalized/signed-mixture rejection plus Li–Liu classifier-inverse repair; those individual primitives are not new.

## Physical cost and computational work

Under H_i, define lambda_ij(h)=log(H_i/H_j). Its predictable drift is the sum of the target directed KL values along the target action sequence. Each drift is <=d gamma_i C_G. Bounded per-step log likelihood increments give E max_j [lambda_ij]_+ <=d gamma_i E C_G + C1 sqrt(m), by the two martingale second-moment bounds and Jensen. Integer rounding adds at most one, and the common L term is O(log m). Correct-candidate verifier cost therefore has the desired leading coefficient. Wrong classification has probability<=eta and costs at most L/(4/5). Initial classification costs O(log m); repair costs 21 eta rR=O(1+log R0). Since log m<=C2 sqrt(m), the displayed source-cost bound follows.

Threshold U is at most O(m log R0+log m). Its gambler probabilities and every ratio in the repair coin have polynomial bit length in m and catalogue encoding. The rR classifier recurrence has rR=O(m log R0+log m) terms. A conditional repair run takes <=7 joint trials in expectation. For a uniform per-run target execution bound P, each proposal is bounded by P plus exact rational channel/coin sampling work. Fair-bit rejection from a rational denominator of l bits takes O(l) expected fair bits. Integer arithmetic, trace storage, classifier compilation, verifier updates and exact coin work therefore have polynomial expected cost. This proof does not assign zero cost to auxiliary target draws, private bits, compilation, memory or source waiting/preparation; they must be separately measured in any application.

## Existing finite implementation and strict comparator

For G_i=(.8 at i,.1 elsewhere), n=1024, a tighter count-variance bound produces the exact rational physical-source upper bound 113216857/122880=921.361140950... in every state. The full ordered target transcript is reproduced. A universal stopped-KL converse gives every frozen iid source mixture worst-state expected cost at least (3*.7log8)/(2*.8log9)*1024=1271.954... . Thus the comparator also has exact full-output freedom and arbitrary stopping/garbling; it is restricted only to a fixed iid action mixture. Arbitrarily randomized schedules are not covered by that comparator claim.

The asymmetric iid target (.8,.1,.1),(.2,.7,.1),(.1,.2,.7) uses unequal residual masses and the fresh-classifier loop. ## Boundary to research information acquisition

The supplied source and target channels, state catalogue, full support, fresh conditional sampling, target code and bounded execution promise do the essential scientific modelling work. Unknown target q independent of the source cannot be acquired for free: producing one exact n-fold Bernoulli(q) target report requires at least n paid target/calibration observations by stopped KL. Conditional guarantees supporting reports chosen after a retained dataset require still more calibration at prescribed precision. A cached bank can be a competent unconditional one-report baseline but is not an unlimited fresh conditional law.

The concrete prototype now accepts a genuinely branching controlled target through an observation oracle, with216 exact small records and648 independently checked state/record identities; see notes/d_example/cycle3/PROGRAM.md. It proves the source upper941.752547 at m1024, while own rational-log fixed-design certificate proves every frozen iid mixture needs>=1042.5135 in some state for the full record. Its Boolean projection is not separately lower-bounded. Compilation, auxiliary/environment bits, memory, edge-case fixes and all replays are charged. The next falsifiable expansion is a target report circuit family with provably hard marginal extraction, verifying that no such extraction is hidden in preprocessing. The theorem already handles that family under its supplied bit-execution promise, but this prototype does not run a large #P-hard family benchmark. A general efficient source-menu verifier evaluator and a general unbounded effective continuation compiler remain unresolved. No general-intelligence or model-acquisition claim follows from this result.

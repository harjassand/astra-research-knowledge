STRONGEST CLAIM
The audited easy-plane XXZ Hamiltonian class has an exact hard-core-boson form that gives a useful physical and complexity-theoretic interface. For every rational loopless multigraph instance

 H = sum_{e=ij}[alpha_e(X_i X_j+Y_i Y_j)+gamma_e Z_i Z_j]
       + sum_i[b_i X_i+c_i Z_i],
 alpha_e >= |gamma_e|, b_i >= 0,

with rational c_i, the physical Hamiltonian K=-H is exactly

 K = kappa I - sum_{e=ij} t_e(a_i^* a_j+a_j^* a_i)
       + sum_{e=ij} V_e n_i n_j + sum_i nu_i n_i
       + sum_i Omega_i(a_i+a_i^*),

where a_i is a hard-core boson annihilation operator, n_i=a_i^*a_i,

 t_e=2 alpha_e >= 0,   V_e=-4 gamma_e,   |V_e| <= 2 t_e,
 Omega_i=-b_i <= 0,   nu_i=2c_i+2 sum_{e incident to i} gamma_e,
 kappa=-sum_e gamma_e-sum_i c_i.

No graph bipartition or geometry restriction is needed. The real source term Omega_i preserves the computational-basis sign structure but breaks particle-number conservation unless it vanishes. Arbitrary rational on-site potentials nu_i are allowed.

DERIVATION
Set n_i=(I-Z_i)/2 and a_i=(X_i+iY_i)/2, so X_i=a_i+a_i^*, Z_i=I-2n_i, and

 X_iX_j+Y_iY_j=2(a_i^*a_j+a_j^*a_i),
 Z_iZ_j=I-2n_i-2n_j+4n_i n_j.

Substituting into K=-H gives the displayed coefficients term by term. The attraction/repulsion range is |V_e|<=2t_e because |gamma_e|<=alpha_e. Also every off-diagonal entry of K in the occupation basis is nonpositive: pair hopping has amplitude -t_e, and a source has amplitude Omega_i<=0. Thus the model is stoquastic in this supplied basis.

# FI barrier-gating audit package

This directory contains the read-only-source audit and new scalar finite-time
and finite-noise qualifications. Original inputs are byte-copied under
`inputs/barrier/`; the original source tree was not edited.

`DELTA_MIXED_GATE_AUDIT.md` and its independent checker separately audit the
mixed local/mean gate claim in `work/FI-root/`; they preserve its conditional
model scope and do not establish a material implementation.

To replay the supplied verifier and the independent symbolic checker, create a
disposable environment from the workspace root, install the pinned dependencies,
then run:

```sh
uv venv work/FI-barrier/.venv
work/FI-barrier/.venv/bin/python -m pip install \
  -r work/FI-barrier/requirements.txt
work/FI-barrier/.venv/bin/python work/FI-barrier/replay/verify_barrier_gating.py \
  --output work/FI-barrier/replay/replayed_source_results.json
work/FI-barrier/.venv/bin/python work/FI-barrier/deepening_checker.py
```

The generated outputs are in `replay/` and `deepening_results.json`. The
source replay's finite root scans are diagnostics, not interval proof. The
finite-noise results are a one-coordinate Gibbs/Laplace model, not a material
prediction. See `REPORT.md`, `DERIVATIONS.md`, and
`READ_PRIMARY_LEDGER.md`. `MANIFEST.json` freezes the source and package
SHA-256/byte inventory; `MANIFEST.sha256` hashes the manifest.

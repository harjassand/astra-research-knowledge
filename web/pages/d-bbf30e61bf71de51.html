# The original commuting frame is already saturated

Status: complete own deduction, adoption PENDING independent reconstruction. The saturation and vertical-centralizer statements use the explicitly proved polynomial presentation and localization, not noncoordinateness. The final all-LND-centralizer corollary additionally uses the independently audited noncoordinate conclusion. No historical novelty claim.

## Interface and prior

Keep A and D_X,D_Y,D_Z from STABILIZATION_AND_DEGENERATING_FRAME.md:

  A=C[p,s,u,F,J]/(H)≅C^[4],
  A[p^-1]=C[p±1,X,Y,Z], D_i=p²∂i.

Define the rational invariant-span saturation

  M=(C(p)D_X+C(p)D_Y+C(p)D_Z) ∩ Der_C(A).                   (S1)

The coefficient field here is C(p); coefficients depending on X,Y,Z are not silently included. The goal is to determine whether clearing denominators by p² created a removable rank drop.

Nearest checked primary: Derksen–van den Essen–Maubach, A commuting derivations theorem on UFD's, arXiv0806.2038v1, Theorem2.1 and Lemma3.7, both fully read. Lemma3.7 replaces an invariant-span module by a saturated basis which can improve the set of fibres on which its derivations are independent. The text asks about the relation between maximal such independence and polynomial fibres. Our argument determines the whole saturated module in this concrete case. The paper's displayed question contains a “not a polynomial ring” wording inconsistent with its preceding theorem and set-inclusion claim; we do not assert that our result resolves that literal question.

## 1. Rational invariant coefficients must first be polynomial

There is a C[p]-retraction A→C[p] given by setting s=u=F=J=0. It is valid because H vanishes under that substitution. Thus

  A∩C(p)=C[p].                                             (S2)

Indeed, if a(p)/b(p) lies in A, apply the retraction to b(p)g=a(p). The resulting polynomial g0(p) satisfies b g0=a, so the rational function was polynomial.

Take E∈M and write its localization uniquely as

  E=r_X(p)∂X+r_Y(p)∂Y+r_Z(p)∂Z.

Since E(X),E(Y),E(Z) lie in A, (S2) makes all r_i polynomials. On H=0 the identity p u=XY−Z(Z+1) implies

  E(u)=[r_XY+r_YX−r_Z(2Z+1)]/p.                            (S3)

Regularity forces its numerator to vanish modulo p. On A/(p)=C[s,u,N],

  X=s²−u², Y=s+Xs², Z=sX.

If (α,β,γ)=(r_X(0),r_Y(0),r_Z(0)), the numerator becomes

  αs+X(αs²+β−2γs)−γ.                                      (S4)

Its u² coefficient is −αs²−β+2γs, hence α=β=γ=0. Thus r_i=p a_i with a_i∈C[p].

## 2. Global F,J force a second factor p

Put

  A0=a_XY+a_YX−a_Z(2Z+1),
  C0=a_Y−(2X+u²)a_X, k=1+2sX.

Using the literal original-generator formulas for D_i gives

  E(u)=A0, E(s)=pC0−2XuA0,
  E(F)=a_X−2sC0+2ukA0/p,
  E(J)=a_Z−XC0−sa_X+2X²uA0/p.                              (S5)

The first terms in the last two lines are polynomial. Thus regularity makes ukA0/p and X²uA0/p elements of A. Since

  (1−2sX)k+4s²X²=1,

their polynomial linear combination makes uA0/p an element of A. Modulo p this gives u(A0 mod p)=0. A/(p) is a domain and u is nonzero there, so A0 mod p=0. Apply the same coefficient comparison (S4), now to a_i(0), to get a_i(0)=0. Thus r_i=p²b_i with b_i∈C[p].

Conversely each b_iD_i is a polynomial derivation. Therefore

  M=C[p]D_X ⊕ C[p]D_Y ⊕ C[p]D_Z.                          (S6)

The displayed action is already saturated. Every element of M is locally nilpotent: after p-localization it is a constant-in-X,Y,Z translation derivative; it preserves A, so local nilpotence restricts. All elements commute because their coefficients are common invariants. No inverse-fibre denominators or more favorable invariant-span basis remove the rank drop on p=0.

## 3. The whole vertical centralizer

Suppose E is any polynomial derivation of A with E(p)=0 and [E,D_i]=0 for all three i. In A[p^-1] write E=Σr_i(p,X,Y,Z)∂i. The commutators give p²∂j r_i=0, so r_i∈C[p±1]. Hence E∈M. Conversely every element of M commutes. Thus

  {E∈Der_C(A):E(p)=0,[E,D_i]=0 for all i}=M.                (S7)

On p=0, every vector field in this centralizer is a C-linear combination of the original three restrictions, because b_i(p) specialize to b_i(0). Its rank is at most one, and every one of its fields fixes the plane p=u=0. In particular no compatible additional global vertical flow supplies a missing independent direction there.

After noncoordinateness is independently adopted, every LND in the full centralizer is vertical as well. If E is an LND commuting with all D_i, E(p) is in their common kernel C[p]. A locally nilpotent derivation on C[p] has E(p)=c constant: a nonconstant coefficient times ∂p never has terminating iterates on p. If c≠0, p/c is a slice. The slice decomposition gives A=ker(E)[p], and its kernel is isomorphic to A/(p)=C^[3]. This would make p a coordinate, a contradiction. Thus c=0 and E belongs to M. This last corollary is conditional on the separate noncoordinate gate; the derivation and saturation in Sections1–3 are not.

## Scientific consequence and scope

The example has every fibre A^3, a polynomial section, and a complete explicit stable chart, yet the standard rational invariant-span improvement has already exhausted its capacity. This identifies an actual acquisition bottleneck: escaping the original action's centralizer, rather than choosing a better basis inside it.

This does not classify all triples of commuting LNDs with common kernel C[p], because a different triple need not commute with the original one. Nor does it compute all automorphisms or all derivations of A. The saturated module and vertical centralizer are exact all-degree statements for the supplied frame.

The next falsifiable gate is the two divisibility steps (S3)–(S5); a polynomial combination circumventing the boundary coefficient comparison would refute (S6). Finite sample ranks cannot establish saturation.

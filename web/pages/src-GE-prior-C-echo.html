# Finite time loss echo and its precision boundary

16 October 2026. Root follow-up to the independently constructed s04 loss echo and s07 finite-time audit. This closes an exact sampling-alias assumption, not the physical acquisition or practical conditioning problem. System realization and nonuniform sampling have substantial predecessors; no historical novelty is asserted.

## Exact two grid identification

Let A be an unknown conservative n-state column Markov generator, c=1^T, b a normalized preparation, and D a fixed unknown diagonal loss matrix with distinct entries. The illuminated generator is M=A-D. Fix positive times h1,h2,tau1,tau2 with h1/h2 and tau1/tau2 irrational. Define P1=exp(M h1), P2=exp(M h2), Q1=exp(A tau1), Q2=exp(A tau2).

Assume the sampled on-mode triple (P1,b,c) is minimal. Set C=[b,P1b,...,P1^(n-1)b] and O with rows cP1^i. The following finite scalar probabilities are available from single on intervals and two on intervals separated by darkness:

    H_ij = c P1^(i+j) b,
    J1_ij = c P1^(i+j+1) b,
    J2_ij = c P1^i P2 P1^j b,
    Kℓ_ij = c P1^i Qℓ P1^j b,    ℓ=1,2; 0≤i,j<n.

The J2 measurement is a single pulse of total duration (i+j)h1+h2. All matrices use the same H=OC. Therefore

    H^-1 Jℓ = C^-1 Pℓ C,
    H^-1 Kℓ = C^-1 Qℓ C.

The pair of exponentials at two incommensurate times uniquely determines each generator in this common basis, without a supplied rate cap. Proof: if exp(h1 X)=exp(h1 Y) and exp(h2 X)=exp(h2 Y), invertibility and commutation of these equal exponential matrices give exp((m h1+n h2)X)=exp((m h1+n h2)Y) for every integer m,n. The additive subgroup is dense in R. Continuity gives equality at all real times, and differentiation at zero gives X=Y. Apply this separately to M and A. Then C^-1 D C is known. Its simple spectrum gives physical state axes; normalize each eigenvector v by (cC)v=1, and only state permutation remains. Preparation b is recovered in the same basis.

Thus finite exact probabilities at finite positive durations can replace arbitrarily high derivatives and the single-grid logarithm branch assumption. A mere assertion that the on-mode is minimal is still a substantive restriction: simple D does not imply it. S07 has an exact singular-H counterexample. General switched-word identification may work there, but the compact H inverse operation does not.

## What has not been removed

Exact probabilities and exact time ratios are ideal mathematical inputs. The dense-subgroup argument can use arbitrarily large signed powers; it is a uniqueness proof, not a stable finite-precision algorithm or an attainable timing prescription. There is no uniform error bound without quantitative conditions on H, generator scales, loss contrast and spectral separation.

Even ordinary conservative Markov generators expose the lack of uniform stability. For a three-cycle permutation C0, A_r=r(C0-I) is a valid column generator. At any fixed positive tau, exp(A_r tau) approaches the uniform stationary projector as r→infinity, while ||A_(2r)-A_r|| grows with r. Hence a finite set of positive dark-time matrices can become arbitrarily indistinguishable for increasingly different fast generators. Illuminated survival data must supply sufficiently informative, sufficiently early temporal contrast; the identifiability theorem does not supply an instrument with that resolution. Near-uniform D separately makes all output pulse sequences independent of A in the limit D=dI.

The existing finite-duration protocol with a verified rate bound is more operational: a log branch can be fixed by a sufficiently short sample interval, and numerical sensitivity can be checked on the acquired matrices. It still needs actual count statistics, timing calibration, a diagonal-loss law, constant dark kinetics, preparation/reset and a same-data likelihood comparator.

## Source and contribution boundary

S04 supplied the conservative diagonal-loss two-pulse H/K operation and exact single-pulse collision. S07 independently supplied the finite-duration H/K version and checked this two-grid proof. Root supplied the dense-subgroup extension to remove the exact rate-bound premise and the explicit distinction from stability. These are structured recombinations of established realization and sampling theory.

Primary predecessors include Sontag–Wang–Megretski, https://arxiv.org/abs/math/0610633; Petreczky, https://doi.org/10.1016/j.sysconle.2007.04.006; and matrix-exponential aliasing work by Yue–Thunberg–Goncalves, https://arxiv.org/abs/1605.06973. The search also found pre-existing nonuniform sampled-system reconstruction, https://doi.org/10.1016/j.automatica.2008.08.007. The exact specialized theorem has not received an exhaustive priority review or external mathematical validation.

Decision: retain as an exact interface theorem; do not allocate a main research tranche merely to refining its matrix inversion. The decisive next evidence is either a new stable target operation with materially better acquisition cost, or a physical platform actually providing the assumed contrast/control at useful timescales.

1. Exact interface and claim.

Write T(A,B)=||A-B||_1/2. For every integer K>=2 there are a full-domain
CPTP self-compatible qubit channel Phi_K, a FIXED faithful sigma, and a
faithful state rho_K on a FIXED two-dimensional CLASSICAL reference times
a qubit such that

  Phi_K(sigma)=sigma,     (rho_K)_B=sigma,
  I(R:B)_{rho_K}=D(rho_K||(rho_K)_R tensor sigma)<=S(sigma)<ln 2,
  b_K=T(rho_K,(id_R tensor Phi_K)(rho_K))=1/(6K^2),
  r_K=T(rho_K,(id_R tensor Phi_K^sharp Phi_K)(rho_K))>=1/(7K).

Here Gamma_sigma(X)=sqrt(sigma) X sqrt(sigma), and the Petz/KMS adjoint is
Phi_K^sharp=Gamma_sigma Phi_K^* Gamma_sigma^{-1}. The map depends only on
Phi_K,sigma and is applied simultaneously to both conditional states.
Consequently no dimension-free estimate r<=P(D+1)b^gamma, with a fixed
locally bounded polynomial P and gamma>1/2, can hold even on this stationary
margin, fixed-dimension, uniformly faithful-reference subclass.

This disproves ONLY that stronger residual transfer for the specific Petz
symmetrization. It does not disprove an exponent <=1/2, and does not disprove
raw broadcast-to-EB classicality: Phi_K itself is EB and has error b_K.

2. Legal channel and actual broadcaster.

Set v=K^{-2}, c=sqrt(v(1-v)), and

  sigma = diag(3/4,1/4),
  tau_0 = [[1-v/3,-c/3],[-c/3,v/3]],
  tau_1 = [[v,c],[c,1-v]].

Both tau_j have trace one. tau_1 is a rank-one positive state because its
determinant is v(1-v)-c^2=0. tau_0 is positive definite because its diagonal
entries are positive and det(tau_0)=2v/9>0. Define on ALL of M_2

  Phi_K(X)=<0|X|0> tau_0 + <1|X|1> tau_1.

This is a measurement-preparation CPTP map. Its genuine CPTP broadcaster is

  B_K(X)=<0|X|0> tau_0 tensor tau_0
         + <1|X|1> tau_1 tensor tau_1.

Both output marginals equal Phi_K for every matrix input, not only the
tested states. Directly, (3/4)tau_0+(1/4)tau_1=sigma.

Phi_K is not KMS-symmetric. It sends E_01 to zero, whereas

  Phi_K^sharp(E_01)=diag(-c/sqrt(3),c/sqrt(3)) != 0.

The stationary Petz map is CPTP, fixes sigma, and always outputs a diagonal
matrix. More explicitly,

  Phi_K^sharp(X)
    = sum_{j=0,1} sigma_jj Tr[tau_j sigma^{-1/2}X sigma^{-1/2}] E_jj.

Thus S_K=Phi_K^sharp Phi_K is a legal sigma-stationary KMS-positive
self-compatible map. A broadcaster for S_K is
(Phi_K^sharp tensor Phi_K^sharp) composed with B_K.

3. Faithful tested states with exact stationary local margin.

Let q_+=3/8, q_-=1/8, and define

  rho_+ = [[5/8,c/6],[c/6,3/8]],
  rho_- = [[7/8,-c/6],[-c/6,1/8]],
  rho_K = (1/2)|+><+| tensor rho_+
          +(1/2)|-><-| tensor rho_-.

positive; the smaller is at least 7/64-(3/16)/36=5/48. Hence each rho_j

  D(rho_K||(I_R/2) tensor sigma)

No eigenvalue floor is tending to zero: sigma is fixed, and the above

4. Exact forward residual and Petz lower bound.

For arbitrary q define

  h(q)=(4/3)c(q-1/4),
  rho(q)=[[1-q,h(q)],[h(q),q]],
  m=1-4v/3.

Phi_K preserves the off-diagonal coefficient h(q) exactly and changes the
tail probability to

  q'=1/4+m(q-1/4).

For q=q_+,q_-, the change of the tail probability is respectively -v/6,
+v/6. The input-minus-output matrix is diagonal with trace zero, so each
conditional half-trace error is v/6. Classical block additivity yields
b_K=v/6 exactly.

S_K always outputs a diagonal matrix, so the input-minus-S_K output has
off-diagonal coefficient +c/6 or -c/6. A traceless Hermitian qubit matrix
[[x,h],[conj(h),-x]] has half-trace norm sqrt(x^2+|h|^2)>=|h|. Thus

  r_K>=c/6=sqrt(1-K^{-2})/(6K)>=sqrt(3)/(12K)>=1/(7K).

The last bound follows from 147>=144. An optional exact formula also
confirms the asymptotic rate. Put

  ell=m^2+(8/(3sqrt(3)))c^2.

Applying the displayed Petz formula to Phi_K(rho(q)) gives a diagonal
state with tail probability 1/4+ell(q-1/4). Consequently

  r_K=sqrt((1-ell)^2/64+c^2/36),   lim_{K->infinity} K r_K=1/6.

Therefore r_K is Theta(K^{-1}), while b_K=1/(6K^2). In particular, for any
gamma>1/2 and any bounded prefactor on 0<=D<=ln 2,

  r_K/[P(D+1)b_K^gamma] grows at least as a positive multiple of K^{2gamma-1}.

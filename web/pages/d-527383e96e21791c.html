## Explicit input and scientific promise

Observe iid exact rational vectors X1,...,XN in R^n, n>=2. A **supplied, scientifically justified** bound ||X||<=R holds almost surely; an empirical maximum is not such a bound. Fix a failure budget alpha. The mean mu is unknown and estimated. No population covariance, quartic, error radius, latent frame or branch is supplied.

The scientific model is X=mu+A Z, unknown invertibleA, Cov(Z)=I, and the actual fourth cumulant ofZ has quartic h_Q(z)=(z²)^T Q(z²), QPD or more generally nonnegative pair gaps in this standardized latent gauge. Then the observed cumulant is f(x)=h_Q(A^T x), and its aligned metric is **G=Cov(X)=AA^T=(A^T)^T A^T**. This proves the covariance orientation/link rather than assuming it from a fitted metric. Reflectional/common-variance restrictions and actual positive gaps remain promises about the true physical sources. The cycle12 published LiMIAM example shows a positive fitted representation alone cannot validate them.

Write Mr=E X^tensor r, Mhat_r=N^-1 sum Xi^tensor r, for r1,...,4, with full symmetric tensor-Frobenius norms. The observed empirical central covariance and fourth cumulant are

    mhat=Mhat1,
    Chat=Mhat2-mhat^tensor2,
    Hhat4=Mhat4-4 sym(mhat tensor Mhat3)
                    +6 sym(mhat^tensor2 tensor Mhat2)-3 mhat^tensor4,
    That4=Hhat4-3 sym(Chat tensor Chat).

The convention sym is the orthogonal symmetric projection; its polynomial evaluates the usual covariance pairing term3(x^T Cx)^2. Population versions usemu, C=Cov(X), andT4. Cumulants are translation invariant. No population mean is assumed known.

## First load-bearing lemma: Hilbert Bernstein, reconstructed

For independent centered vectors Zi in a finite-dimensional real Hilbert space, with ||Zi||<=B and sum E||Zi||²<=sigma²,

    P(||sum Zi|| >= s) <= 2 exp[-s²/(2(sigma²+B s/3))].

Here is a complete proof, so no unverified theorem constant is imported. Let phi(x)=cosh(lambda||x||), lambda>0. At x!=0 its radial Hessian eigenvalue is lambda² cosh(lambda||x||); tangential eigenvalues are lambda sinh(lambda||x||)/||x|| and are no larger, since tanh(u)<=u. At0 the Hessian is lambda²I. Hence

    D²phi(x)[v,v] <= lambda² phi(x)||v||².

Triangle inequality and cosh(a+b)<=cosh(a)e^b for a,b>=0 give phi(x+tZ)<=phi(x)e^(lambda tB). Taylor's integral remainder therefore gives

    phi(x+Z) <= phi(x)+Dphi(x)[Z]
       +phi(x)||Z||² (e^(lambda B)-1-lambda B)/B².

Take conditional expectation; centering cancels the derivative. Iterate independence and1+u<=e^u:

    E phi(sum Zi) <= exp[(e^(lambda B)-1-lambda B)sigma²/B²].

Since cosh(lambda s)>=e^(lambda s)/2, Markov gives a tail with exponent equal to this log-mgf bound minuslambda s. For0<=lambda B<3,

    e^(lambda B)-1-lambda B
       <= (lambda B)²/[2(1-lambda B/3)].

This follows termwise from j!>=2*3^(j-2), j>=2. Set lambda=s/(sigma²+B s/3). The claimed exponent follows. If sigma²=0 the variables vanish almost surely; treat that case directly. Thus for one sample average with variance proxyv,

    radius(v,B,t,N)=sqrt(2v t/N)+2B t/(3N)

has failure probability at most2e^-t. Substitution into the quadratic tail verifies the radius; it is deliberately slightly conservative.

## Variance proxies acquired from the same observations

For r1,...,4, set ur=N^-1 sum ||Xi||^(2r). These are four scalar moments up to order8; **no order8 tensor** is required. A one-sided scalar Hoeffding event gives

    E||X||^(2r) <= ur+R^(2r)sqrt(t/(2N))

with failure at moste^-t. One may reconstruct Hoeffding by the Doob/independent-sum exponential argument and the scalar bounded-range log-mgf lemma. Define

    vhat_r=min{R^(2r), ur+R^(2r)sqrt(t/(2N))},
    epsilon_r=sqrt(2 vhat_r t/N)+4 R^r t/(3N).

Raw tensor Xi^tensor r has norm||Xi||^r. Its centered version has norm at most2R^r, and variance

    E||X^tensor r-Mr||² <= E||X||^(2r).

The scalar upper event and Hilbert Bernstein therefore imply ||Mhat_r-Mr||<=epsilon_r. The **same samples may estimate vhat_r**: if vhat_r bounds the unknown deterministic true variance, a deviation beyond radius(vhat_r) implies a deviation beyond radius(true_variance). No conditional iid assertion after estimating vhat is made. Union four scalar upper events and four vector tail events:

    P(all four raw moment bounds) >= 1-12e^-t.

Choose t>=log(12/alpha), or a rational/integer upper bound verified by an exponential series. The executed confidence choice t6, alpha1/20 uses12e^-6<1/20, proved by a finite rational lower sum for e^6. Every square root is evaluated with an outward rational bound. For N=3m², the scalar root is1/m and epsilon_r=2sqrt(vhat_r)/m+8R^r/(3m²).

This is a dimension-free **Hilbert norm** event, not a dimension-free sample cost. R, the acquired variance proxies, covariance conditioning, coefficient volume and gap all depend on dimension/model.

## Unknown-mean centering and cumulant transport

On that one simultaneous event put a=epsilon1, b=||mhat||, dr=||Mhat_r|| for r2,3. Tensor multiplication is norm multiplicative and sym is a contraction. Therefore

    epsilon_C=epsilon2+(2b+a)a,

and

    epsilon_H=epsilon4
       +4[a(d3+epsilon3)+b epsilon3]
       +6[(2ba+a²)(d2+epsilon2)+b² epsilon2]
       +3[(b+a)^4-b^4].

The three lines bound respectively mu tensorM3, mu² tensorM2 andmu^4 differences. For the covariance pairing term,

    epsilon_T=epsilon_H+3 epsilon_C(2||Chat||F+epsilon_C).

Thus ||C-Chat||F<=epsilon_C and ||T4-That4||F<=epsilon_T with probability at least1-alpha. Observed b,d3,d2 and||Chat|| retain much tighter centering terms near a truly centered/symmetric source than replacing every factor byR. A Bessel correction is not required; Chat uses the explicitly stated denominatorN.

## An observed rational frame supplies an exact candidate metric

Any data-dependent proposer returns invertible rationalV. Define

    Gc=V^-T V^-1, so V^T Gc V=I exactly.

This does not establish true alignment by itself. It permits exact metric/frame postchecking without an uncharged algebraic square root. Obtain rational bounds

    nu >= ||Gc^-1||op = ||V V^T||op,
    Delta >= ||Chat-Gc||op.

For example use the maximum absolute row sum for the symmetric inverse metric, and the Frobenius norm forDelta. Then the acquired statistical covariance event proves

    zeta=nu(epsilon_C+Delta),
    (1-zeta)Gc <= C <= (1+zeta)Gc.

If zeta>=1, retain **UNKNOWN_METRIC_CONDITIONING**. Otherwise this is the exact relative Loewner premise of the adopted cycle12 theorem. The candidate-metric cumulant error is at most

    delta=nu² epsilon_T,

because a four-slot V action has operator norm||V||op^4. With an observed rational upper normM>=||That4||B,Gc+delta, use

    delta_eff=delta+[(1-zeta)^(-2)-1]M.

The standardized covariance link also fixes the gauge of the true pair-gap promise. In candidate coordinates putL=A^T V andB=(L^T L)^(-1/2). ThenLB is orthogonal, so ideal orthogonalization gives h_Q(LBx) with the **same actualQ**. No latent row rescaling is needed here. In a different interface supplying only an arbitrary aligned metric, nonuniform row rescaling can change pair gaps; the broader pair-gap-only promise would then require a separate check. QPD survives such rescaling.

Transform the observed quartic byV, project onto its even monomials, and computeQc, rho andqc=half its minimum pair gap. Ifqc<=0, retain **UNKNOWN_PAIR_GAP**; if an actual QPD fit is required, checkQc SPD too. Forqc>0 every compatible true frame, after ideal orthogonalization, lies in the cap

    d<=2(delta_eff+rho)²/qc².

A narrow cap gives matching; actual axes add the metric distortion bound zeta(1+zeta)/(1-zeta), then the explicit condition factor forV for ordinary Euclidean angles. Large caps return **VALID_BUT_UNINFORMATIVE_AMBIGUITY**, not recovery. If the combined axis radius exceeds1, clip only the reported sine bound, not a claimed matching theorem.

All these postconditions hold **simultaneously for every proposed V on the same raw-data confidence event**.

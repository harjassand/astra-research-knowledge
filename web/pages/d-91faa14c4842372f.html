Let the set of vectors be $V=\{v_1,\dots,v_n\}$.  For a matroid \(\M=([n],\I)\), we denote
\(\I_s(\M)=\set{S\in\I:|S|=s}\), the set of all independent sets of
size \(s\). We denote by \(\P(\M)\) the matroid base polytope of
\(\M\). For any vector \(z\in\R^{[n]}\) of real numbers indexed by \([n]\)
and a subset \(S\subseteq [n]\), we denote \(z(S)=\sum_{i\in S} z_i\). Let $\Z = \{ z \in \rR^{[n]} : \forall S \in \I_d(M), z(S) \geq 0\}$. We now introduce an optimization problem
\begin{equation} \label{eq:D-relax}
\max_{\bx\in\P(\M)}  \inf_{z\in\Z} g(x,z):= \log\det\pr{\sum_{i \in [n]} x_ie^{z_i} v_i v_i^\top}
\end{equation}
\vivek{It should be sup instead of max, correct? Not obvious as to why sup is equal to max.}

We call the optimization problem \eqref{eq:D-relax} \CPD{($\M,V$)}. We denote
its optimum value by \CP{($\M,V$)} and optimal solution (when one exists) by
\((x^\star,z^\star)\).

\begin{theorem}\label{thm:relax}
\eqref{eq:D-relax} is a relaxation for \Ddesign (\vivek{not correct}). That is,
\[\DOPT{(\M,V)} \leq \exp(\CP{(\M,V)})\]
for any set of vectors $V = \{v_1,\dots,v_n\}$ and matroid $\M=([n],\I)\}$.
\end{theorem}

The next theorem shows that \CPD{} can be solved approximately to any
degree of accuracy.

\begin{theorem} \label{thm:solvability}
There is an algorithm that given an instance of the \DOPT{} problem and $\epsilon>0$ either shows that the optimal value is $0$ or returns a solution to $(\tilde{x},\tilde{z})$ such that
\begin{enumerate}
\item $f(\tilde{x})\geq f(x^\star) -\epsilon$.
\item $g(\tilde{x}, \tilde{z})\leq \inf_{{z\in\Z}} g(\tilde{x}, z)+\epsilon.$
\item \ms{We need some for approximate KKT.} \sasho{For now we are not

\end{enumerate}
The algorithm runs in polynomial time in the size of the input and \(\log\pr{\frac 1\eps}\).
\end{theorem}

For $\bx \in \P(\M)$, let $$f(\bx):=
\inf_{\bz\in\Z} g(\bx,\bz).$$
Let $\bx^* \in \P(\M)$ be the optimum solution to \CPD. As discussed above, our rounding algorithm yields a positively correlated distribution if $\bx^*$ is sparse which may not always be the case. In order to convert the $\bx^*$ into a sparse optimum solution $\bx'$, we need the existence of finite $\bz^*$ optimizing $f(\bx^*)$; $g(\bx^*,\bz^*) = f(\bx^*)$. However, for some of the \Ddesign instances and optimum $\bx^*$, there may not exists any finite optimum $\bz^*$.  This issue can be resolved using the following lemma:

\begin{lemma} \label{lem:finite_z}
  Let \(\hat \bx\in\P(\M)\) be such that $\max_{i \in [n]}, \hat x_i < 1$,
  \(f(\hat \bx)=\inf_{\bz\in\Z} g(\hat \bx,\bz)\) is finite, and suppose that
  the vectors $\{v_i: i\in [n]\}$ are in general position. Then,
  \(g(\hat \bx,\bz)\) attains its infimum over \(\bz\in\Z\) at some
  \(z^*\in\Z\). Here, vectors $\{v_i: i \in [n]\}$ in general position means that all subset of vectors of size $d$ are linearly independent.
\end{lemma}

Next, given a \Ddesign instance with vectors $V=\{v_1,\dots,v_n\}$ and matroid $\M = ([n],\I)$, we can create a \Ddesign instance with vectors $V' = \{v_1',\dots,v_m'\}$ and matroid $\M' = ([m],\I')$ such that both the optimum and the relaxation optimum are roughly same for both instances. Additionally, vectors $V'$ are in general position and there exists an optimum solution $\bx^*\in \P(\M')$ to the relaxation with $V', \M'$ satisfying $\max_{i \in [m]} x_i < 1$.

\begin{lemma}\label{lem:new_instance}
For any $\epsilon > 0$, given a matroid $\M  = ([n],\I)$ an vector set $V= \{v_1,\dots,v_n\}$, we can construct $\M' = ([m], \I')$ and $V' = \{v_1',\dots,v_m'\}$ in time $poly\pr{n,d,\frac{1}{\epsilon}}$ such that
\begin{itemize}
\item $|\CP(\M,V) - \CP(\M',V')| < \epsilon$ and $\frac{\DOPT{(\M,V)}}{\DOPT(\M',V')} \in [1-\epsilon, 1+\epsilon]$.
\item Vectors $\{ v_1',\dots,v_m'\}$ are in general position.
\item There exists $\hat \bx$ with $\max_{i\in [m]} \hat x_i < 1$ which is approximately optimal for \CPD with matroid $\M'$ and vector set $V'$. That is,  $\inf_{z\in\Z'} g(\hat x,z) \geq \sup_{x \in \P(\M')} \inf_{z \in \Z'} g(\bx,\bz)$ where $\Z' = \{ \bz \in \rR^{[m]} : \forall S \in \I_d(\M'), z(S) \geq 0\}$.
\end{itemize}
\end{lemma}

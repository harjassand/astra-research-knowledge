Abstract
This paper studies the class of stochastic maps, or channels,
for which (I⊗Φ)​(Γ)(I\otimes\Phi)(\Gamma) is always separable
(even for entangled Γ\Gamma). Such maps are called entanglement
breaking, and can always be written in the form
Φ⁡(ρ)=∑kRk​Tr​Fk​ρ\Phi(\rho)=\sum_{k}R_{k}~{\rm Tr}\,F_{k}\rho
where each RkR_{k} is a density matrix and Fk>0F_{k}>0.
If, in addition, Φ\Phi is trace-preserving,
the {Fk}\{F_{k}\} must form
a positive operator valued measure (POVM).
Some special classes of these maps are considered
and other characterizations given.
Since the set of entanglement-breaking trace-preserving
maps is convex, it can be characterized by its extreme points.
The only extreme points of the set of completely
positive trace preserving maps which are also entanglement breaking
are those known as classical quantum or CQ. However, for d≥3d\geq 3,
the set of entanglement breaking maps has additional extreme points
which are not extreme CQ maps.
1 Introduction
A quantum channel is represented by a stochastic map,
i.e., a map which is both completely positive and trace-preserving.
We will refer to these as CPT maps.
In this paper we consider the special class of
quantum channels which can be simulated by a classical
channel in the following sense: The sender makes a
measurement on the input state ρ\rho, and send the
outcome kk via a classical channel to the receiver who
then prepares an agreed upon state RkR_{k}.
Such channels can be written in the form
Φ⁡(ρ)=∑kRk​Tr​Fk​ρ\displaystyle\Phi(\rho)=\sum_{k}R_{k}\,{\rm Tr}F_{k}\rho
(1)
where each RkR_{k} is a density matrix and the {Fk}\{F_{k}\} form
a positive operator valued measure POVM. We call this
the “Holevo form” because it
was introduced by Holevo in [6].
It is also natural consider the class of channels which
break entanglement.
Definition 1
A stochastic map Φ\Phi is called entanglement breaking
if (I⊗Φ)​(Γ)(I\otimes\Phi)(\Gamma) is always separable, i.e.,
any entangled density matrix Γ\Gamma is mapped to a separable one.
It is not hard to see that, as shown in the next section,
a map is entanglement-breaking if and only if it can be
written in the form
Φ⁡(ρ)=∑k|ψk⟩​⟨ψk|​⟨ϕk,ρ​ϕk⟩\displaystyle\Phi(\rho)=\sum_{k}|\psi_{k}\rangle\langle\psi_{k}|\langle\phi_{k},\rho\,\phi_{k}\rangle
(2)
in which case it is necessarily completely positive.
Furthermore, Φ\Phi is trace-preserving if and only if
∑k|ϕk⟩​⟨ϕk|=I\sum_{k}|\phi_{k}\rangle\langle\phi_{k}|=I, in which case,
(2) is a special case of (1).
One can show that the converse also holds, so that we
have the following result.
Theorem 2
A channel can be written in the form (1)
using positive semi-definite operators FkF_{k}
if and only if it is entanglement breaking. Such a map
is also trace-preserving if and only if the {Fk}\{F_{k}\} form
a POVM or, equivalently, ∑k|ϕk⟩​⟨ϕk|=I\sum_{k}|\phi_{k}\rangle\langle\phi_{k}|=I.
The rather straightforward proof will be given in the next
section together with some additional equivalences.
We will refer to stochastic maps which are both entanglement-breaking
and trace-preserving as EBT.
Of course there are stochastic maps which are not of the
form (1). In particular, conjugation with a unitary
matrix is not EBT.
Channels which break entanglement are particularly noisy
in some sense, e.g., a qubit map is EBT
if the image of the Bloch
sphere collapses to a plane or a line. In the opposite
direction, we will show
that a channel in dd dimensions is not EBT
if it can be written using fewer than dd Kraus operators.
Theorem 3
The set of EBT maps is convex.
Although this follows easily from the definition of entanglement breaking,
it may be instructive to also show directly that the set of maps of the
form (1) is convex. Let Φ\Phi and
Φ~\widetilde{\Phi} denote such maps with density matrices
{Rj}j=1​…​m\{R_{j}\}_{j=1\ldots m} and
{R~k}k=1​…​n\{\widetilde{R}_{k}\}_{k=1\ldots n} and POVM’s
{Ej}j=1​…​m\{E_{j}\}_{j=1\ldots m} and
{E~k}k=1​…​n\{\widetilde{E}_{k}\}_{k=1\ldots n} respectively.
For any α∈[0,1]\alpha\in[0,1] the map
[α​Φ+(1−α)​Φ~]​(ρ)=∑jRj​Tr​(α​Ej​ρ)+∑kR~k​Tr​[(1−α)​E~j​ρ]\displaystyle\big[\alpha\Phi+(1-\alpha)\widetilde{\Phi}\big](\rho)=\sum_{j}R_{j}\,{\rm Tr}(\alpha E_{j}\rho)+\sum_{k}\widetilde{R}_{k}\,{\rm Tr}[(1-\alpha)\tilde{E}_{j}\rho]
has the form (1) since
{α​E1,α​E2,…​α​Em,(1−α)​E~1,…​(1−α)​E~n}\{\alpha E_{1},\alpha E_{2},\ldots\alpha E_{m},(1-\alpha)\widetilde{E}_{1},\ldots(1-\alpha)\widetilde{E}_{n}\} is
also a POVM.
Note that we have used implicitly the idea of generating
a new POVM as the convex combination of two POVM’s, In this
sense, the set of POVM’s is also convex, and one might expect
that the extreme points of the set of entanglement-breaking
maps are precisely
those with an extreme POVM and pure RkR_{k}. However, this is false; at
end of Section 3 of [18], the trine POVM is
used to give an example of a qubit channel
which is not extreme, despite the fact that the POVM is.
Certain subclasses of EBT maps
are particularly important. Holevo called a channel
•
classical-quantum (CQ) if each
Fk=|k⟩​⟨k|F_{k}=|k\rangle\langle k| in the POVM is a one-dimensional projection.
In this case, (1) reduces to
Φ⁡(ρ)=∑kRk​⟨k,ρ​k⟩\Phi(\rho)=\sum_{k}R_{k}~\langle k,\rho k\,\rangle.
•
quantum-classical (QC) if each
density matrix Rk=|k⟩​⟨k|R_{k}=|k\rangle\langle k| is a one-dimensional projection and
∑kRk=I\sum_{k}R_{k}=I.
If a CQ map has the property that each density matrix
Rk=|ψk⟩​⟨ψk|R_{k}=|\psi_{k}\rangle\langle\psi_{k}| is a pure state,
we will call it an extreme CQ map.
Note that the
pure states |ψk⟩|\psi_{k}\rangle need not be orthonormal, or even
linearly independent. We will see in Section 3 that
extreme CQ maps are always extreme points of the set of EBT maps,
but they are only extreme points for the set of CPT maps if
all pairs ⟨ψj,ψk⟩\langle\psi_{j},\psi_{k}\rangle are non-zero.
When all Rk=RR_{k}=R are
identical, then Φ\Phi is the maximally noisy map
Φ⁡(ρ)=R\Phi(\rho)=R for all ρ\rho.
Because it maps all density matrices to the same
RR, its image is a single “point” in the set of density matrices
and its capacity is zero. A point channel is extreme if and
only if its image RR is a pure state. A point
channel is a special case of a CQ map; however, because all Rk=RR_{k}=R the
sum in (1) can be reduced to a single term with E1=IE_{1}=I.
For d>2d>2, one can also consider those CQ maps for which some RkR_{k}
are identical; then
the POVM can be written as a projective measurement, and the
image is a polyhedron.
It is useful to have Kraus operator representations of EBT maps.
For Φ\Phi of the form (1), let
Ak​m​n=Rk​|m⟩​⟨n|​FkA_{kmn}=\sqrt{R_{k}}\,|m\rangle\langle n|\,\sqrt{F_{k}}
where {|m⟩}\{|m\rangle\} and {|n⟩}\{|n\rangle\} are orthonormal bases.
Then one easily verifies that
∑k​m​nAk​m​n​ρ​Ak​m​n†=∑kRk​Tr​Fk​ρ\displaystyle\sum_{kmn}A_{kmn}\,\rho\,A_{kmn}^{\dagger}=\sum_{k}R_{k}{\rm Tr}F_{k}\rho
(3)
For CQ and QC maps these operators reduce to
Ak​m=Rk​|m⟩​⟨k|A_{km}=\sqrt{R_{k}}\,|m\rangle\langle k| and
Ak​n=|k⟩​⟨n|​FkA_{kn}=|k\rangle\langle n|\,\sqrt{F_{k}} respectively.
Moreover, if all density matrices are pure states
Rk=|ψk⟩​⟨ψk|R_{k}=|\psi_{k}\rangle\langle\psi_{k}|, then one can achieve a further
reduction to Ak=|ψk⟩​⟨k|A_{k}=|\psi_{k}\rangle\langle k| in the case of CQ maps.
Holevo [6] showed that for EBT maps
the Holevo capacity (i.e., the capacity of a quantum channel
used for classical communication with product
inputs) is additive. This result
was extended by King [13] to additivity of
the capacity of channels of the form Φ⊗Ω\Phi\otimes\Omega where
Φ\Phi is CQ or QC and Ω\Omega is completely arbitrary.
Shor [20] then proved the additivity of
minimal entropy and Holevo capacity when Φ\Phi is EBT
and Ω\Omega arbitrary. Quite recently, King [14]
showed that the maximal p-norms of EBT channels are multiplicative,
and used this to give another proof of Shor’s additivity results for
minimal entropy and Holevo capacity. In a related
development, Vidal, Dür and Cirac [22] used
Shor’s techniques to prove additivity of the entanglement
of formation for a class of mixed states associated with
EBT maps.
Because
it is important to understand the differences between those
channels which break entanglement and those which preserve it,
we seek other characterizations of these channels, describe
their extreme points, and examine their properties.
Results for qubits are
given in a related paper [18] which follows.
Some analysis of entanglement breaking channels was
also independently presented by
Verstraete and Verschelde  [21].
2 Equivalent conditions
In this section, we establish a number of equivalent
characterizations of EBT maps, some of which were already
discussed in the previous section.
Theorem 4
The following are equivalent
A)
Φ\Phi has the Holevo form (1) with
FkF_{k} positive semi-definite.
B)
Φ\Phi is entanglement breaking.
C)

all positivity preserving maps Υ\Upsilon.

3 Extreme points
We now give some results about the extreme points of the convex
set of EBT maps.
In this section we will use some additional results from Choi [2]
who observed that Φ\Phi is completely positive if and only if
(I⊗Φ)​(|β⟩​⟨β|)(I\otimes\Phi)(|\beta\rangle\langle\beta|) is positive semi-definite.
When Φ\Phi is written in the operator sum form
Φ⁡(ρ)=∑kAk​ρ​Ak†\displaystyle\Phi(\rho)=\sum_{k}A_{k}\rho A_{k}^{\dagger}
(7)
the Kraus operators AkA_{k} can be chosen as the eigenvectors
of (I⊗Φ)​(|β⟩​⟨β|)(I\otimes\Phi)(|\beta\rangle\langle\beta|) with strictly
positive (i.e., non-zero)
eigenvalue. (See Leung [16] for an nice exposition.)
Choi [2] also showed that Φ\Phi is extreme in the set of CPT
maps if and only if the set {Aj†​Ak}\{A_{j}^{\dagger}A_{k}\} is linearly independent.
Since both (7) and this linear independence are preserved when
Ai↦∑jui​j​AjA_{i}\mapsto\sum_{j}u_{ij}A_{j}, a sufficient condition
for Φ\Phi to be an extreme EBT map is that {Aj†​Ak}\{A_{j}^{\dagger}A_{k}\}
is linearly independent for some set of operators {Ak}\{A_{k}\}
satisfying (7).
Note that the condition that Φ\Phi is also trace-preserving
becomes ∑kAk†​Ak=I\sum_{k}A_{k}^{\dagger}A_{k}=I.
Recall that an
extreme CQ map is one which can be written in the form
Φ⁡(ρ)=∑k|ψk⟩​⟨ψk|​⟨ek,ρ​ek⟩\displaystyle\Phi(\rho)=\sum_{k}|\psi_{k}\rangle\langle\psi_{k}|\,\langle e_{k},\rho\,e_{k}\,\rangle

with the vectors {ek}\{e_{k}\} orthonormal.

# Exact partial-flag oracle for the Hirai packing algorithm

## Question and source interface

Can the actual update in Hirai, *Horospherically convex optimization for fractional subspace packing and its applications*, arXiv:2608.13972v1, be executed and independently audited using only exact linear algebra over Q or Fp, without a generic submodular minimization oracle or enumeration of subspaces? The primary v1 was retrieved directly on 7 October 2026; the abstract page verifies Hiroshi Hirai, submitted 14 August 2026 at 05:32:26 UTC. The source's rational-weight bit bound in Theorem 3.5 applies to p and u, not the rational field entries in its flag basis.

Our contribution here is a direct lattice formula for the same update and an executable canonical partial-flag/certificate interface. The formula may be established filtration/building arithmetic in other terminology; priority is UNKNOWN. ## 1. The exact object: a weighted partial flag

Represent a source point by a basis v_1,...,v_n and nonincreasing rational weights p_j in [0,C], where C=cmax. Define

    F(h) = span{v_j : p_j >= h}        for h>0;
    F(h) = K^n                       for h<=0.

Only positive distinct weight levels and their subspaces matter. If p_i=p_(i+1), the intermediate complete-flag subspace is invisible to the building point and is omitted. Each retained subspace is stored as its unique row RREF in the fixed ambient coordinates. This object is canonical for the weighted point over the supplied field, regardless of column scalings, upper triangular changes preserving its full flag, or completions hidden inside tied blocks. It requires at most n spaces and O(n^3) field scalars in the deliberately simple implementation.

No total order on Fp is needed. All field decisions are equality/pivot decisions; comparisons and sorting act on the separate rational weights. An Fp modulus must actually be prime. The oracle does not test or sample that prime; this is an explicit caller obligation.

## 2. Universal exact update formula

Suppose a subspace S-step is active in source Step 2-2 and let alpha=t*u_k>=0. Lemma 2.3 gives an apartment basis U with the same complete flag as V and S=span{U_j:j in J}. Before clipping, its weights change by

    q_j = p_j + alpha*1_(j in J).

For 0<h<=C, clipping q_j to C does not change whether q_j>=h. In this apartment, selected basis elements in S have threshold p_j>=h-alpha, while unselected elements have threshold p_j>=h. Therefore

    F_new(h) = F(h) + (S intersect F(h-alpha)).       (P1)

This is literal equality of subspaces: the first summand includes all basis elements with p_j>=h; the second includes exactly selected elements with p_j>=h-alpha. Conversely those are precisely the basis elements meeting the new threshold. It follows independently of apartment choice, refinement inside a tied block, or field characteristic. For h>C set F_new(h)=0; for h<=0 use the ambient space. Zero S and alpha=0 give the original point.

All possible new positive weight levels are in

    {min(C,w), min(C,w+alpha): w is an old positive level}
       union {min(C,alpha)}.

Evaluate (P1) at these finitely many levels, order them descending, and retain the first occurrence whenever its subspace grows. This gives precisely the canonical weighted partial flag. It is an algorithm, not a search over possible subspaces.

The source's k=0 step is equally intrinsic:

    F_new(h) = F(h+t),  0<h<=C.                       (P2)

This subtracts t from positive weights and drops levels that become nonpositive. It needs no apartment construction.

The active-step test uses the exact support below; a zero penalty has the source's zero ray. Replacing the source's arbitrary complete-flag representation with (P1)--(P2) thus preserves every represented weighted point in the iteration. It does not change the convergence theorem or remove its numerical cmax and epsilon^-1 dependence.

## 3. Objective and distance oracles

Let positive levels w_1>...>w_l>0 have nested spaces A_i=F(w_i); put w_(l+1)=0 and lambda_i=w_i-w_(i+1). The support of S is

    a_S = sum_i lambda_i dim(S intersect A_i).          (P3)

In a common apartment this equals sum_(j in J) p_j, so the source's Busemann value is -a_S and the active penalty is max(0,c_k-a_S). Its exact capped dual objective is

    f = sum_i lambda_i dim(A_i)
          + sum_k u_k max(0,c_k-a_(S_k)).               (P4)

This is a dual upper value for the optimization over the current field. It is not a primal packing vector or an original-rational-field certificate merely because a modular flag was supplied.

For two partial flags with levels w_i,z_j and spaces A_i,B_j, write delta_i=w_i-w_(i+1), eta_j=z_j-z_(j+1). A common apartment exists by the source's Lemma 2.2. Expand each diagonal coordinate vector into indicators of its partial-flag spaces there. The inner product is

    <p,q> = sum_(i,j) delta_i eta_j dim(A_i intersect B_j).

Consequently their exact building distance is

    d^2 = sum_i w_i^2[dim(A_i)-dim(A_(i-1))]
          + sum_j z_j^2[dim(B_j)-dim(B_(j-1))]
          - 2 sum_(i,j) delta_i eta_j dim(A_i intersect B_j).  (P5)

This uses only lattice intersection dimensions and rational arithmetic. Without clipping, an S-step has d^2=alpha^2 dim(S); clipping gives d^2<=alpha^2 dim(S) by the source's projection/nonexpansivity property (also visible coordinatewise in its apartment). The independent checker tests these equations as well as point equality, and does not import the optimization iteration.

## 4. Compact apartment certificate

For independent comparison we implemented the source's reverse-row column elimination. Compute V^-1 S, row-reduce its column vectors in reversed ambient-coordinate order, and reverse them back. Each has a distinct lowest nonzero coordinate j. Replace e_j by that column and leave other e_j unchanged, obtaining an upper triangular T with nonzero diagonal. Put U=V T.

The certificate consists of T, U, and selected J. Check (i) U=VT, (ii) T is upper triangular with nonzero diagonal, and (iii) selected U columns span S. Then every old prefix span is preserved and S is represented by exactly J. Thus its intersection jumps are 1_(j in J). Direct prefix-span checks in the finite controls independently verify this implication. There is no hidden formal inverse, extension-field search, submodular minimizer, or min-cut assumption.

The two implementations use genuinely different constructions: the comparator changes apartments; the acquired oracle computes sums/intersections of canonical partial spaces.

## 5. Charged cost and exact prime boundary

The intentionally simple sum/intersection oracle uses at most 2n+1 thresholds. Each intersection is the kernel of [A^T,-B^T], followed by an image and RREF, taking O(n^3) field operations; each sum is another RREF. Thus the acquired positive-step implementation costs O(n^4) field operations and O(n^3) stored field scalars. Evaluation is O(m n^4); pairwise distance is O(n^5). The source's O(n^3) alignment is asymptotically faster for a single update. This implementation is a reusable canonical trace auditor and a directly executable oracle, not a claimed practical speedup.

Over Fp with L=bit_length(p), scalar storage is O(L), and every modular arithmetic/inversion operation has polynomial cost in L. There is no factor p in enumerating field elements or subspaces. Separate rational weights have the source's polynomial bit bound in iteration count, cmax, epsilon^-1, and bit length of u. The counters report declared field arithmetic AND conversion calls, including modular conversion inverse/multiply/reduction when needed. They exclude those weight operations, library internals, serialization, source I/O and model/proof work; measured process time includes the executed Python body. They are not a complete bit-operation count. These exclusions are explicit in the resource ledger.

The cycle16 random-prime reduction is an inherited independently gated proof, not an experiment in this cycle. For fixed integerized dense packing data r,m,H, its displayed B bound and L=4[bit_length(B)+bit_length(ceil(1/delta))+20] produce an exact uniformly sampled L-bit prime with exceptional probability at most delta. The whole packing polytope is preserved simultaneously, so adaptive weights on the SAME input require no fresh union bound. Exact AKS/uniform rejection, or another certified prime sampler with separately charged error, is a caller dependency; the present oracle performs neither. The computational reduction provides original-field value/gap outputs on its good event, without a rational flag lift or a deterministic certificate that this particular prime is good.

For a general quiver, cycle16 similarly preserves the convex dimension polytope, after charging active expanded vertex dimension A and removing binary-large isolated vertices. It does not acquire an arbitrary quiver support optimizer. Hirai's actual source is a packing/star interface, and cannot simply be called a general quiver optimizer. The oracle here likewise does not assert such a reduction.

## 6. What canonicalization removes, and an exact obstruction to a general bit remedy

Column scalings and invisible refinements can inflate a representing basis without changing its point. The exact control uses

    V = [[N,N^2],[0,N]],  p=(1,0),  N=2^1024.

Its raw matrix needs 2049 scalar bits; the retained weighted subspace is just span(e_1), whose canonical coordinates need one bit. The same point is obtained from the identity basis. This demonstrates a real gauge saving, not a polynomial bit bound for all changing subspaces.

There is a stronger intrinsic obstruction for arbitrary lattice programs. In Q^3 use affine projective coordinates (x,y,1), fixed horizontal/vertical directions H=(1,0,0), V=(0,1,0), the x/y axes, diagonal y=x, infinity line z=0, and unit point U=(1,0,1). Start at the small point A=(a,0,1), a=2. Perform six joins followed by meets:

    B = (A+V) intersect diagonal       = (a,a,1);
    C = (B+H) intersect y-axis         = (0,a,1);
    I = (U+C) intersect infinity       = (1,-a,0);
    D = (A+I) intersect y-axis         = (0,a^2,1);
    E = (D+H) intersect diagonal       = (a^2,a^2,1);
    A_new = (E+V) intersect x-axis     = (a^2,0,1).

Here points mean one-dimensional subspaces; + is span, and the intermediate two-dimensional objects are projective lines. All formulas follow by solving the indicated linear equations. Repeating the fixed pattern k times uses O(k) lattice operations and constant initial input, but produces a=2^(2^k). The unique row-RREF point contains the reciprocal 1/a, whose denominator has 2^k+1 bits. Thus the blowup is intrinsic to the subspace, not removable by scaling or normalization. The code verifies the first eight rounds and the universal recurrence proves the exponential bit statement.

IMPORTANT scope: this is an arbitrary meet/join straight-line program, NOT a displayed trajectory of Hirai's specific alternating, fixed-input optimization method. It rules out a general claim that canonical lattice storage alone makes such operations polynomial-bit. It does not prove that our fixed instance or every source trajectory attains this growth. Source §4.2 supplies the broader warning; an algorithm-specific better rational height theorem remains a separate missing hypothesis.

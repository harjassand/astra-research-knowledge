# Effective bounded rational-program bridge: independent adversarial audit

Worker check_selection; 2026-10-06. Scope: the supplied three-state source menu only, not arbitrary source catalogues or unbounded target policies. Mathematical audit passed with the support and bit-complexity conditions below. Implementation of the generic program wrapper is not claimed by this note. Prior-art novelty and independent external validation remain unresolved.

## Interface that makes the claim true

The source has actions a=0,1,2 with Bernoulli success probability1/10 in statea and9/10 in other states, each observation costing1. Statei is fixed and hidden. The target is a supplied state-independent controller/report program querying a supplied finite memoryless catalogue of rational full-support channels G_i^b. Conditional on hidden state and chosen action, each channel observation is fresh with the specified law. At mostm target observations occur on every execution. All channel rational numerators/denominators and alphabet encodings have explicitly bounded input lengthB.

The target program has a supplied boundP on logical execution steps, private rational-coin calls, output length and all rational/integer operand sizes. A standard bit-operation bound is sufficient; a unit-cost arithmetic bound permitting exponentially large intermediate integers is insufficient. Controller coin probabilities may depend on its recorded history, but never on the hidden state or simulation candidate. The candidate is exposed only to the fake observation callback used by the converter. The controller receives observations and its own state-independent randomness.

Original controller/report randomness can be represented by finitely many bounded rational coin OUTCOMES. Exact unbiased-bit implementation of each rational coin may consume an unbounded number of retry bits, with polynomial expectation. Those retry bits need not be retained in the logical report; retaining them would yield countable support and needs a corresponding measurability argument. Recording abstract controller coin outcomes gives finite, potentially enormous support and avoids this issue.

## Load-bearing support boundary

Retain the target's logical augmented record

    h=(selected actions, observations, original controller coin outcomes,
       terminal output and enough logical trace to replay their order).

Artificial randomness used to simulate a physical channel under candidatek must be DISCARDED. It is not original controller randomness. If a simulator uses a common uniform seedU to produce observationX via a state-dependent threshold, then recording(U,X) can produce disjoint supports across states: the sameU can force differentX. Its likelihood ratio is not the physical channel ratio. Recording the physical channel's fake sampler seed therefore invalidates the proposed argument.

Likewise exclude channel-sampler runtime, retry counts and other state-dependent implementation artifacts fromh. Program execution promises refer to logical controller execution, not a timeout that truncates channel-sampler rejection loops depending on the candidate. Source/target runtime is measured separately.

For the valid logical record, a common factorκ(h) contains every controller action, stopping, coin and report probability. Every feasible positive record under one state is feasible under all states because channel observations have full support. Thus

    H_i(h)=κ(h)∏_{t≤T(h)}G_i^{b_t}(x_t),
    H_i(h)/H_k(h)=∏_{t≤T(h)}G_i^{b_t}(x_t)/G_k^{b_t}(x_t).

The converter evaluates only the latter exact rational products. It does not computeκ, H_i, terminal marginals, state posterior distributions, full-support tables or the number of possible records. Terminal probability counting is bypassed by retaining and later discarding the complete logical record.

## Initial proposal, scalar verification and pointwise residual

Setη=1/(30m), classify a candidate using a symmetric balanced source classifier with total error≤η, and simulate the supplied target program under that candidate using independent controller randomness and a fake channel callback. Let A_0 be the exactly computable confusion matrix. Given proposalh under candidatek, its likelihood ratios determine the source scalar verifier barriers

    L=ceil(log_9(1/η)),
    U_k(h)=ceil(log_9(max_{j≠k}max(1,H_k(h)/H_j(h))/η)).

Both barriers are calculated by exact integer comparisons. Under actionk, all candidate-versus-alternative scores move together by±log9. Exact correct/wrong acceptance probabilities and expected source costs have the cycle3 gambler-ruin formulas; no infinite acceptance-probability sum is required. The correct candidate's reverse error is≤9^{-L}≤η. In this special source every reverse process is identical; a two-alternative union bound would unnecessarily give2η.

Thin accepted outputs by a=(1-η)/(1+2η). Define Q_i(h)=aΣ_k A_0(i,k)H_k(h)p_i(k,h) and T_i=H_i-Q_i. Cross acceptance givesηH_i≤T_i. Keeping the own-state accepted term gives

    T_i(h)≤[1-(1-η)^3/(1+2η)]H_i(h)≤5ηH_i(h).

The last inequality follows from the numerator5η-3η²+η³; it is valid for the chosen smallη. These pointwise ratios are evaluable without H itself:

    Q_i(h)/H_k(h)=aΣ_j A_0(i,j)[H_j(h)/H_k(h)]p_i(j,h),
    T_i(h)/H_k(h)=[H_i(h)/H_k(h)]-Q_i(h)/H_k(h).

Thus arbitrary bounded controlled programs retain an explicit pointwise residual because the source's verifier is scalar and its probabilities are exactly rational.

## δ-free joint repair

Choose R_0≥max_{i,j,b,x}G_i^b(x)/G_j^b(x)≥1 and R=R_0^m. All logical record ratios are bounded byR, regardless of controller path probabilities. A balanced repair classifier with r_R samples per source action has common off-diagonal parameterb≤(9/25)^{r_R}; chooseb≤1/(18R). Its matrix is A_R=(1-3b)I+bJ and λ=1-3b≥5/6.

Set W=A_R^{-1}T, so W_k=(T_k-bΣ_iT_i)/λ. Positivity and envelope follow from

    bΣ_iT_i≤15bηR H_k≤(5/6)ηH_k≤T_k,
    W_k≤5ηH_k/λ≤6ηH_k.

On EACH repair attempt take a fresh paid source classifierk, run the target program underk to obtainh, and accept with exact probabilityW_k(h)/(6ηH_k(h)). In statei, the one-attempt output submass is

    Σ_k A_R(i,k)H_k(h)W_k(h)/(6ηH_k(h))
      =T_i(h)/(6η).

Its total acceptance probability isδ_i/(6η), whereδ_i=Σ_hT_i(h) lies in[η,5η]. Repeated fresh joint attempts therefore terminate almost surely with mean at most6, and final conditional repair lawT_i/δ_i. Noδ_i or W-row normalization is calculated. Initial accepted submass plus original failure probabilityδ_i times this repair law equalsH_i exactly. Discarding the controller trace, private coins and other record components yields the original terminal output law.

Each joint attempt's classifier takes3r_R physical source readings. The unconditional expected physical repair cost is exactly

    δ_i * (6η/δ_i) * 3r_R =18ηr_R.

Classifying only once and repeatedly proposing within its chosen row is invalid in general; the asymmetric cycle3 exact audit demonstrates its law defect. Fresh classifier/target simulation/coins on EVERY attempt are required.

## Sharp source-observation coefficient and bounded overhead

Let D=.8log9 and g_ij^b=KL(G_i^b||G_j^b). For unit-cost target observations define

    γ_i=max_b max_{j≠i} g_ij^b/D.

Under truei, the full logical record's log likelihood vector is the stopped target observation score S_ij(T)=Σ_{t≤T}g_ij^{b_t}+M_ij(T). Its drift is coordinatewise at mostDγ_iT. Bounded channel log ratios and orthogonal martingale increments give E_i|M_ij(T)|≤C√(E_iT). Therefore

    E_i max_j[S_ij(T)]_+≤Dγ_iE_iT+C√(E_iT).

The correct-candidate scalar verifier costs≤(5/4)U_i, whose leading ratio converts Dγ_iE_iT/log9 toγ_iE_iT. Its additive overhead is O(√(E_iT)+logm+1). Wrong candidates cost≤(5/4)L and occur with probability≤η. Initial classification costs O(logm). Repair lengthr_R=O(1+m logR_0), so18ηr_R=O(1+logR_0). Consequently

    E_i source_observations≤γ_i E_i target_observations+C√m,

uniformly over the supplied bounded programs, with channel-dependent constants. This is a hard-horizon remainder, not a claimed C√(E_iT) effective theorem for arbitrary stopping policies. A zero-time target decision can still incur preliminary classification in this implementation, so omitting the horizon dependence would be unjustified.

For necessity, repeat any target actionb m times and report its observations. Every source action supplies at mostD KL in directioni/j. Exact reproduction forces DE_iN≥m g_ij^b. Maximizing overj andb provesγ_i is the sharp universal statewise first-order coefficient. A different witnessb may be needed for each state. No claim about decision-order equivalence follows automatically.

## Expected polynomial CPU/bit argument

With explicit rational channel operands of input lengthB, each record likelihood product has O(mB) numerator/denominator bits. Success barriers are O(mB+logm); powers9^U and the exact scalar acceptance formulas have the same order of bit length. The repair classifier lengthr_R is O(mB+1), and its exact finite binomial/tie sum, confusion parameter and inverse entries have polynomial arithmetic cost and O(mB) bits. Each pointwise T/W evaluation combines a fixed number of these rational operands and remains polynomial; it does not enumerate target paths.

The target simulation has supplied bounded logical execution and operand sizesP, plus expected polynomial unbiased-bit work for its rational primitives. Channel simulation from an explicitly tabulated rational row can use a common-denominator integer categorical draw; its denominator has polynomial input length. Source verification has expected O(mB+logm) reads in every state, and its integer score needs logarithmic space in the barriers. Each rational accept coin uses expected at most twice its denominator bit length under ordinary rejection from unbiased bits.

A repair attempt has uniform polynomial EXPECTED cost over its candidatek. Acceptance may correlate with a record's expensive execution, but this does not break the expected bound: for iid joint attempts, renewal gives E(total work)=E(one-attempt work)/P(accept)≤6 E(one-attempt work). This follows by charging every attempt, not by assuming accepted paths have typical runtime. All classifier, rejected proposal, target simulation and coin costs must be included in that one-attempt work. Expected loop cost is polynomial in m, input bit length and the supplied execution/operand bound. Worst-case runtime is not bounded because unbiased-bit rejection and source gambler walks have unbounded tails.

The promiseP must be supplied or independently established; this construction cannot decide arbitrary program termination or prove a polynomial execution bound automatically. Counting unit-cost arbitrary-size arithmetic, ignoring observation-sampler bits, or treating finite pseudorandom seeds as ideal independent randomness would overstate the computational result.

## Verdict and next falsifiable step

The bridge is more consequential than a terminal-table compiler: it exactly samples the output of a bounded known rational controlled program without computing terminal marginal probabilities. It retains a genuine sharp source-observation coefficient for this special source catalogue and an effective expected polynomial implementation route. It is still supplied-model simulation: no target structure acquisition, unknown-law calibration, arbitrary-source scalar verifier or effective unbounded continuation is obtained.

Next decisive implementation should expose a callback-only target controller with branching rational private coins and observations, compare its small-horizon full output law by independent enumeration, deliberately show that recording fake channel-sampler bits violates common support, and record CPU/peak-memory/auxiliary bits separately from paid source observations. This would make the theoretical bridge concrete beyond the existing iid histogram family.

## 1. Proof reuse does not contract an antecedent

Section2.1 explicitly defines both Frege and sequent proofs as finite
sequences citing earlier rows, and defines sequent lines as total formula
occurrences rather than rows. An earlier endpoint P_F:T_F,S_F=>bottom is
a complete sequent derivation. Citing it twice in different later
inferences changes no multiset inside either conclusion. The linear
resource restriction concerns those antecedent multisets, not the number
of citations of an already derived rule premise. A tree-only proof
convention would change this argument; the primary uses DAG proofs.

I reconstructed the per-constructor obligations. For AND, apply left-AND
to the appropriate positive child in each cached child pairing, then
left-OR on the negative side. OR is dual. For fusion, take the first
negative implication T_B->S_C, use identity T_B=>T_B and the cached
pairing for C, then left-AND and left-fusion. For implication, use
identity S_C=>S_C and cached P_B with S_C->S_B, then left-AND and
left-fusion. Bang pairs !T_B with !T_B->bottom directly by identity and
left-implication. Atoms/constants have bounded proofs when D=N=bottom.
Every context has bounded arity. The recursive reference graph is the
original formula DAG, so these endpoints cost O(V) occurrences together.

The four negation-direction proofs use only P_F, identities, unit rules,
right-implication and right-AND. Any needed negation wrappers create only
a bounded number of nodes per axiom application. Thus the closure is
O(V+L), including duality work; there is no hidden tree-size recursion.

## 3. Skeleton compression is a finite-term argument

Fix the exact rule labels and predecessor references of the supplied
proof. One fresh set of metavariables per finite schema and one root per
line produce O(L+|A|) constructors/equations. The actual finite tree
proof is a ground solution. Therefore forced congruence cannot identify
different rigid constructors or rigid target atoms, and cannot produce
a directed constructor cycle. Quotient equal constructors, propagate
equal-child obligations, retain rigid target labels, and complete each
otherwise free class by an ordinary atom. This gives a finite acyclic
DAG solution of the same equations with the exact final target.

Object-level uniform substitution inference is not used. Compression
constructs a different proof of the same target with the same legal rule
skeleton. No canonical rule requires distinct schematic atoms, freshness
of such atoms, or an eigenvariable condition. Closed promotion/necessitation
is preserved because every cited line stays a theorem. The occurs check
and fixed target are indispensable. Arbitrary cyclic rational terms,
atom-only restrictions, uniform substitution as an inference, or
additional semantic side conditions require new arguments.

With V=O(L+|A|), the shared translation adds O(L+|A|) occurrences. Cached
conservative repair uses the primary grammar: its implication case needs
only two cached equivalence directions for the antecedent/consequent
and the cached negative codomain endpoint. Additives/fusion/bang lift
their child directions in bounded context. This supplies the final A
without expanding its intermediate translations into short trees.

## 4. Fresh EF must be eliminated before translating

Use e_i<->F_i=(e_i->F_i)AND(F_i->e_i), with e_i absent from earlier
lines, F_i and the final target. Later definitions may use earlier names;
the resulting dependency graph is acyclic. Define the global expansion
in dependency order. Every ordinary rule remains an instance under this
expansion, and every definition becomes (G->G)AND(G->G), with a fixed
ordinary Frege proof. The fully expanded final target stays A. Thus an
E-step EF proof gives O(E) ordinary Frege steps, even when an intermediate
tree is enormous. Apply the skeleton argument to this ordinary proof.

An alternate size argument is that redirecting definition atoms in the
supplied explicit certificate yields O(S) shared nodes. Neither argument
directly translates a definition axiom with an unmatched s(e)=bottom.
That shortcut is invalid. The global expansion proof needs the exact
two-direction, acyclic, extension-free convention. It does not establish
an unrestricted substitution-Frege bound or any nonuniform extension
rule not specified here.

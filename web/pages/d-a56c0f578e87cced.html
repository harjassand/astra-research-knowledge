original joint check syndrome by a fixed binary vector f_W. Each color has

arbitrary W signs/orientation and for a Gibbs state with check coherence:
conjugated syndrome projectors are exactly shifted syndrome projectors.

after translation. In the unshifted pattern it has a fixed set of k holes,

no illegal single-bit interpolation or conditional other-sector law is used.

h_min t/2-(h_min+h_max)k. The injective translation therefore bounds this
part by exp[beta(h_min+h_max)k] exp(-beta h_min t/2).

    Pr(unshifted fixed pattern on tau)

    Pr(unshifted fixed pattern on tau)

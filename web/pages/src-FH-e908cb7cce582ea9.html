# Shared balanced-tree acquisition audit

## Exact class and learner

For a promised homogeneous degree-two cycle, with `W(S)=r^{|S|}t^{n-b(S)}`, the energy contrast for a target `i∉S` is

`R_i(S)=W(S+i)W(empty)/(W(S)W(i))=(t²)^{|N(i)∩S|}`.

The root calibration `S=V\\{0}` contains both neighbors of site zero, so its ratio is `t^4`; a positive rational square root gives `q=t²`. Seed and cache all `W(empty)`, `W(V)`, the `n` singleton weights, and `W(V\\{0})`.

For each target vertex, begin with known count two on `V`. At each positive nonleaf tree node, query one child excluding `i` (use its sibling if `i` is in one child; otherwise choose left). The exact contrast gives that child's count in `{0,1,2}`; subtract from the parent's known count to get the other child count. Recurse into positive children and identify neighbors at positive singleton leaves. Cache actual subset masks globally across every target.

## Independent count and correctness receipts

- `query_tree_audit.py` independently counts masks for 5,000 seeded random n=24 cycle relabelings and checks the learned edge set against the planted cycle. With all singleton bootstrap masks included and the target-excluding child selected, counts are min 183, p10 200, median 208, mean 207.585, p90 214, max 223. Every sample is below the 301 unique masks of the pairwise probe baseline.
- `query_tree_exact_replay.py` evaluates exact rational weights for `t=3/2,r=5/3` on 101 deterministic cycle orderings, executes the contrast decoder from actual rational ratios, and recovers all 24 edges in every case. It reports 173 unique masks for natural order, and min/median/max 173/209/220 over those 101 cases.
- The same exact decoder also recovers all edges on 25 source-like n=24 fixtures with `t=1000,r=1`; unique-mask min/median/max are 189/208/218.
- At n=6, the same exact transcript uses 28 unique masks versus 22 for all singleton/pair probes, so the tree is not better at every finite size.
- These samples are not an enumeration of all `24!` orders. Separately, for the recursive midpoint tree `h=ceil(log2 24)=5`, the number of masks is deterministically at most `(2n−1)+2nh+2=47+240+2=289`. The `2n−1` term covers all tree node masks, including all singleton seeds and `V`; each vertex has at most two positive root-to-leaf paths, hence at most `2h` contrast nodes; the two masks outside the tree are `empty` and `V\\{0}`. Each contrast adds at most one new `A+i` mask because `A` is a tree node. This bound gives a guaranteed mask-count improvement over 301 for this exact n=24 cycle protocol, without needing the random-placement assumption.

## Deterministic energy-error condition

If every dimensionless energy reading has absolute error at most `delta`, every four-term contrast has error at most `4 delta`; the root estimate of `log q` has error at most `2 delta`. For `k∈{0,1,2}` true neighbor count, nearest-integer decoding error is at most

`8 delta / (2 log(t)-2 delta)`.

The decoder is unambiguous if this is below `1/2`; `delta<log(t_min)/9` is sufficient, so the proposed `delta<log(t_min)/10`, `t_min>1`, is sufficient with a strict `4/9` upper bound. The condition requires deterministic per-reading error bounds in dimensionless energy units. It does not infer class membership or describe an experimental energy-query implementation.

## Prior-art and scope boundary

The contrast is a cross-additive query between singleton `{i}` and subset `A`; in this class it returns the number of incident edges into `A`, times a common known scale. Also, one energy query on `S` reveals the additive induced-edge count once `t` and uniform `r` are calibrated: `s(S)=(log W(S)-|S|log r)/log t=n-cut(S)`, and regular degree two gives `e(S)=|S|-(n-s(S))/2`. Hamiltonian-cycle query reconstruction and additive/cross-additive hidden-graph reconstruction are established literature (see [PRIMARY_READ_LEDGER.md](PRIMARY_READ_LEDGER.md)). A bounded-degree additive-query result gives an asymptotically linear query baseline. The current learner's contribution is, at most, a simple energy-mask implementation with a rigorous n=24 cache count. It is not a new graph-query primitive, and no head-to-head query-constant comparison to the separating-matrix algorithms was performed.

An acquisition-only extension to pairwise graphs with strictly positive nonuniform couplings is proved in [PROOF_AND_COUNTERMODELS.md](PROOF_AND_COUNTERMODELS.md). That extension does not supply the homogeneous-ring spectral minorant, so it does not extend the certified FH lifetime result.

The exact n=6 class countermodel in `replay/independent_checks.json` was also checked against the actual adaptive tree transcript: the learner queries 28 unique masks, never queries the higher-order trap at mask 14, and receives the same full transcript after that hidden weight is multiplied by 1000. This shows that the lower query count does not solve the global class-identification problem.

## Audit development note

The first audit draft omitted singleton bootstrap masks and selected the child containing the target. The exact-rational replay exposed the invalid child choice because the ratio identity requires `i∉S`; both issues were fixed before producing the final receipts. All counts above are from the corrected cache and branch rules only.

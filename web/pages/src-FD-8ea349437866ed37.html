# CRAY equilibrium-free comparison validation

Read `RESEARCH_NOTE.md` first. This is a scoped mathematical and numerical research
record, not a completed materials experiment. No supplied repository was modified.

## Reproduce

Python 3 with the versions in `requirements.txt` was used. From this directory:

```bash
OPENBLAS_NUM_THREADS=1 python run_tests.py
OPENBLAS_NUM_THREADS=1 python echo_tests.py
OPENBLAS_NUM_THREADS=1 python retained_memory_test.py
OPENBLAS_NUM_THREADS=1 python exact_certificate.py
```

`run_tests.py` generates the local search matrices used by `echo_tests.py`.
`exact_certificate.py` reads the recorded synthetic echo counts. It proves exact
rational inequalities conditional on the declared physical assumptions; it does
not prove that those assumptions have been verified in hardware.

## Outputs and provenance

- `results.json`: polar-map checks, a constructed comparison, all 40 scope
  controls, a hidden-sector obstruction and a rejected derivative acquisition.
- `echo_results.json`: finite-time, phase-frame and arbitrary-memory diagnostics;
  simulated acquisition; full resource table.
- `retained_memory_results.json`: a separate sequential quantum-instrument test
  propagating the same unreset outside spin; its 100-million-trial result is
  inconclusive even at ideal calibration.
- `exact_certificate.json`: exact local algebra, a conditional 99% data-to-sign
  certificate, and exact signs for the hidden-sector counterexample.
- `local_search_matrices.npz`: small numerical matrices, not a many-body bath state.

The favorable 100-million-trial count generator uses binomial blocks and
history-dependent conditional probabilities. It is not an autonomous quantum
trajectory. The separate retained-memory test propagates the quantum instrument
and samples long no-click runs with superoperator powers. Neither implementation
performs 100 million dense matrix exponentials. Its physical trial count is an acquisition cost, not the runtime of
the simulator. All laboratory feasibility statements remain qualified in the note.

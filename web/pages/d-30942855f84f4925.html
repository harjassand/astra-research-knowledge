# Cycle4 decision: checkpoint the DP branch

The complete constructive composition is in `notes/team_b_quantum/cycle4/one_dimensional_dp_closure.md`.

For a supplied finite-range bounded-degree 1D Pauli Gibbs family and fixed beta, the integrated proper loss admits:

- a uniform local candidate-only observable oracle;
- a single nonadaptive global product-Pauli dataset serving every candidate;
- coefficient discretization plus exact chain dynamic programming;
- coefficient RMS error<=epsilon with probability>=1-delta;
- copies polynomial in1/epsilon times log(n/delta), and classical work n exp[O_beta(log²(1/epsilon))], including matrix precision and exact table comparisons.

This does not assume Hamiltonian convexity. It uses the full uniform weight mixture, not the randomized clipped-weight objective. Identity coefficients are excluded; normalization by m handles sparse term lists. Copy preparation, n local measurements per copy, classical moment processing, local matrix construction and table storage are charged. No end-to-end experiment or implemented learner is claimed.

Comparative outcome: Chen-Anshu-Nguyen2504.02706v1 already gives all-temperature non-SOS lattice learning with near-linear n and polynomial accuracy, with stronger per-coefficient error. A competent fixed-local-dataset reduction also serves its later adaptive bounded-region candidate observables; b_math independently audited this reduction and passed it. Full comparison: notes/b_prior/cycle4/NEAR_LINEAR_PRIOR_AND_PAULI_REDUCTION.md. Consequently the DP cannot establish a novel experimental interface, superior accuracy, first near-linear learning or competitive temperature constants. Its explicit Araki constants are particularly poor.

Retain the transparent proper-loss/coercivity/locality bridge as an alternate proof and a control for future optimizers. Recommend reducing allocation and doing no substantial DP implementation now. Reopen only for a verified quantitative advantage or an interface/model outside the existing learner's guarantees.

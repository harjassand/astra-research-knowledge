# Resampling gap through independently selected observation branches

Scientific status: new internal derivation of a finite classical probability lemma and its explicitly conditional application. This is not an externally validated compression theorem. The probability lemma is an elementary conditional-expectation comparison; its historical novelty is UNKNOWN and no novelty claim is made for the operator facts.

## 1. Exact interface

Let (X,Y) have a finite law mu with connected support. Suppose for all centered local real functions a(X), b(Y),

    |E[a(X)b(Y)]| <= rho ||a||_2 ||b||_2,   0 <= rho < 1.       (1)

Let U and V be finite auxiliary variables independent of one another and of (X,Y). Let S include (X,Y,U,V), together with arbitrarily many other registers. These other registers may be correlated with all four; only the specified marginal factorization is required.

Generate Q_0 and Q_1 by two channels that are conditionally independent given S. Each channel uses an independent selector, independent of S. On each side two specified branches each have probability at least eta, 0 < eta <= 1/2. On branch A the output is a function only of (X,U) and local independent randomness; on branch B it is a function only of (Y,V) and local independent randomness. All other branches may reveal all of S and may differ between the two sides. Local selector bits can also be sent. The essential restriction is that the A/B outputs do not contain any other shared register.

**Claim.** The maximal correlation of Q_0 and Q_1 is at most

    rho_out <= 1 - eta(1-rho).                               (2)

Consequently their pair-resampling chain (P_{Q_0}+P_{Q_1})/2 has connected support and gap

    sigma_out >= eta(1-rho)/2.                              (3)

For a nondegenerate connected original pair law, sigma_in=(1-rho)/2, so sigma_out >= eta sigma_in. If the original law is a single atom with the conventional sigma_in=1, use min(sigma_in,1/2). This prevents a false factor-two claim in the degenerate case.

A selector probability exceeding eta only improves the comparison: split its branch into an eta subbranch with independent local coin, and treat the remainder as arbitrary.

## 2. Adding independent point blocks preserves the correlation bound

Take centered a(X,U), b(Y,V). Put a_bar(X)=E[a|X] and b_bar(Y)=E[b|Y]. Independence of U,V gives

    E[a b] = E[a_bar b_bar].

Both conditional means are centered and contractions in L2. Therefore (1) implies

    |E[a b]| <= rho ||a||_2 ||b||_2.                         (4)

Let P_A and P_B be the conditional-expectation projections on L2(S) onto functions of (X,U) and (Y,V). For any centered f(S), put a=P_A f, b=P_B f, and D=||a||^2+||b||^2. By (4),

    ||a+b||^2 <= (1+rho)D,
    D = <f,a+b> <= ||f|| sqrt((1+rho)D).

If D=0 there is nothing to divide; otherwise division yields D <= (1+rho)||f||^2. Hence, on the centered space,

    (P_A+P_B)/2 <= (1+rho)I/2,
    (I-P_A)+(I-P_B) >= (1-rho)I.                            (5)

No enumeration of S or its hidden registers occurs.

## 3. Every remaining observation can be maximally informative

For side i define C_i:L2(Q_i)->L2(S) by C_i g=E[g(Q_i)|S]; its adjoint is C_i^* f=E[f(S)|Q_i]. Append the local selector and local channel coins to Q_i if necessary, producing a more informative observation. This can only increase maximal correlation, so it suffices to prove the bound for that enriched observation.

Conditional on a fixed selector branch, the corresponding observation operator K_{i,l}=C_{i,l}C_{i,l}^* is a positive contraction. On A it is <=P_A, because the observation is a local channel from (X,U); on B it is <=P_B. Independent selectors give an orthogonal direct sum of the observation spaces and

    K_i=C_i C_i^* = sum_l p_{i,l} K_{i,l}
        <= eta P_A + eta P_B + (1-2eta) I
        = I - eta[(I-P_A)+(I-P_B)]
        <= [1-eta(1-rho)] I                                (6)

on centered L2(S). This remains valid if all other branches reveal the complete S.

Conditional independence of Q_0,Q_1 given S gives their cross conditional-expectation operator exactly as C_0^* C_1. Its centered norm is bounded by

    ||C_0^* C_1|| <= ||C_0|| ||C_1||
                   <= 1-eta(1-rho).                        (7)

The operator norm equals maximal correlation by directly optimizing E[g(Q_0)h(Q_1)] over unit centered local functions. This proves (2).

To derive (3), for a centered pair function f(Q_0,Q_1), put a=P_{Q_0}f, b=P_{Q_1}f and repeat the calculation leading to (5), with rho_out in place of rho. This proves

    <f, (P_{Q_0}+P_{Q_1})f/2> <= (1+rho_out)||f||^2/2.

The absence of any nonconstant eigenvector with eigenvalue one implies connectedness of the finite positive-mass pair support. Thus sigma_out >= (1-rho_out)/2 >= eta(1-rho)/2.

## 4. Sharpness: full seed disclosure cannot improve the universal constant

Let X,Y be uniform signs with E[XY]=rho >=0 and full support; let U,V and an extra bit R be independent uniform bits. Both players independently select A=(X,U) with probability eta, B=(Y,V) with probability eta, and F=S with probability 1-2eta. Retain the branch label.

On centered f=X+Y, P_A f=(1+rho)X and P_B f=(1+rho)Y. Therefore

    K f = [eta(P_A+P_B)+(1-2eta)I] f
        = [1-eta(1-rho)] f.

For this symmetric channel, the cross observation operator has the same nonzero eigenvalues as K=C C^*. The upper bound is attained: rho_out=1-eta(1-rho) and sigma_out=eta(1-rho)/2. This is an exact analytic fixture, not an inference from floating-point eigenvalues.

## Family107: actual arithmetic statement

The challenge independently defines finite programs. A new gate can read
only `Fin r` registers already produced, so cycles or unrestricted calls
are not hidden in the program type. Constant/input gates cost0;
addition, subtraction and multiplication each cost1. A matrix algorithm
has finitely many registers and specified output register indices.
`Correct` means evaluation equals the matrix product for every pair of
input matrices. Division is not a gate. This is the usual exact arithmetic
model; constants are not charged by bit length.

The admissibility predicate has the correct quantifier order:

    for every epsilon>0, there exists C>0, such that
    for every n>=1, there exists a correct finite program P,
    cost(P)<=C n^(tau+epsilon).

Thus C is uniform in n; the algorithm and C may depend on slack. The
definition is existential/nonuniform and gives no efficient search for P.
`omega` is the infimum of admissible exponents. The actual exponent file
uses nonemptiness from the naive algorithm and a lower bound2, then derives
admissibility of omega with an epsilon-half argument. I did not read every
lower-bound/naive-algorithm dependency, but the selected proof visibly does
not rely on an empty-set infimum default.

The independent challenge and actual `Model.lean` use matching Gate,
Program, evaluation, cost, correctness and admissibility definitions in
the inspected text. The selected main theorem is exactly
`Arithmetic.omega ℂ <= 9/4`. Its auxiliary main additionally gives the
direct admissible/correct-program cost statement. It is not merely an
opaque real inequality disconnected from a program model.

The rectangular definitions use inner size `ceil(n^k)`, positive slack
and the analogous uniform bound. The dual exponent takes the supremum of
k∈[0,1] with rectangular exponent exactly2. These definitions are sensible
and the top-level aliases match α>0.465 and the aspect0.709 exponent<2.092.
Their complete older CW/duality proofs were not read, so the deep mathematical
gate in this packet concerns square9/4 only.

## Family197: the selected statement includes torsion

The selected challenge states the existence of a finite characteristic-two
field K, a finitely presented group G, an odd prime ell and an element of
G of order ell, together with scalar a,b∈K[G] satisfying ab=1 and ba≠1.
The actual `FinitelyPresented.lean` theorem has the same text and extracts
the existential from `thm_main`. The latter also gives prescribed search
and output-group properties; its proof composes the imported construction,
odd-torsion and termination lemmas. No theorem-specific hypothesis silently
replaces the desired existence claim at the selected endpoint.

This is the September23 characteristic-two paper's statement. It does not
assert K=F2, a torsion-free group, or nonsoficity. The family197 overview's
later torsion-free headline and the docs' broad title must not be attributed
to this certificate. The docs' scope body does correctly describe odd-prime
torsion and excludes nonsoficity from these statements. Other determinant
and odd-characteristic comparators exist but were not independently audited
here.

Selected source sections give a conditional incidence criterion followed
by gluing, scalar packing and explicit parameter selection. I reconstructed
the local-subgroup injectivity and the scalar-defect mechanism. The missing
independent full source gate is the hypergraph/LLL existence and its complete
specification. A separately saved note gives the conditional construction
without pretending that this remaining dependency is settled.

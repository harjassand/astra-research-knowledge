## Delta-owned artifacts

`DELTA_AUDIT.md` contains the queue-tail derivation, frontier-product proof,
exact two-type FJ example, factory cap/coupling argument, expected-cost proof,
uniform-subcritical control case, prior comparison, and scope limitations.
`verify_delta.py` uses only the Python standard library and exact
`fractions.Fraction` arithmetic. Its rational logarithm intervals use the
positive atanh series and a rational geometric remainder; its nonlinear tree
cap is verified by exact rational powers. It is an arithmetic and finite-case
checker, not a verifier of the general N722 clipping proof, a continuous
diffusion sampler, bit-level arithmetic, or novelty.

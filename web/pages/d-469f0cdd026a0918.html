POLYNOMIAL-DIMENSION RANGE ACQUISITION WITHOUT INNER EIGENVECTOR GAPS
2026-10-08. Internal candidate. Replaces the deliberately exhaustive
column search in acquisition.txt Section 5; that fallback remains valid.
The volume-exchange/rank-revealing idea is established numerical linear
algebra (Gu--Eisenstat1996); the proof below is self-contained for this
near-projector interface. No new generic matrix algorithm is claimed.

1. INTERFACE AND EXPLICIT PRECISION

Let P be an unknown rank-d orthogonal projector on C^a, 0<d<a, and let
Q be the EXPLICIT rational symmetric sign polynomial from acquisition.txt,
with ||Q-P||<=zeta. Rank d is acquired by exact rational inertia. Let
0<nu<=1 and put

 theta=d!/(2a)^d, H=1+3d(a-d),
 zeta<=min{1/4, theta/(100d2^d), 1/(12H), nu/(128H^2)}. (1.1)

All quantities are public. Crucially log(1/zeta)=O(dlog a+log(1/nu));
theta is not an inverse-square-root degree or exponential time penalty.
The sign-polynomial degree still only depends LOGARITHMICALLY on 1/zeta
and quadratically on its previously acquired outer gap.

2. GREEDY INITIAL COLUMN SELECTION: A FINITE RATIONAL ALGORITHM

Choose d columns of Q successively. For a current k-column matrix C,
select a new column whose squared distance from ran C is largest.
Compute each distance exactly as the Gram-determinant ratio
det(C_new^*C_new)/det(C^*C), with the empty Gram determinant equal to one.
No orthonormal unknown basis is used. All matrices in these tests are
rational, and the selected Grams are invertible by the bound below.

If Pi_k projects onto the selected span, the matrix (I-Pi_k)Q has at
least d-k singular values >=1-zeta. Indeed range P has an intersection
of dimension >=d-k with (range Pi_k)^perp. On that intersection,
(I-Pi_k)P is the identity and the error in Q has norm <=zeta.
Min-max proves the assertion, hence

 sum_(j=1)^a ||(I-Pi_k)Q e_j||^2 >=(d-k)(1-zeta)^2.

The maximal column residual squared is >=(d-k)/(2a). Previously selected
columns have zero residual, so the selected new column is distinct.
Multiplying the d Gram-determinant increments gives

                  det G_selected >=d!/(2a)^d=theta.    (2.1)

3. LOCAL VOLUME EXCHANGES AND THEIR PROVED ITERATION BOUND

Now examine every replacement of one selected column by an unselected
column. If a replacement increases det G by MORE THAN factor 2, perform
it. Repeat until no such replacement exists. Every accepted step doubles
the positive determinant. Since ||Q||<=1+zeta and

 det(Q[:,I]^*Q[:,I])<=(1+zeta)^(2d)<=exp(2d zeta)<2,

there are fewer than 1+log2(2/theta)=O(dlog a) accepted steps. The
algorithm terminates with all replacement ratios <=2, and its current
determinant is still >=theta. Exact rational comparisons include ties.

Let C0=P[:,I], G0=C0^*C0, and C=Q[:,I], G=C^*C. For this set AND every
one-column replacement, ||G-G0||<=3zeta and each Gram norm is <=2.
Determinant telescoping gives

 |det G-det G0|<=e:=3d2^(d-1)zeta<=.015 theta.

Consequently the true selected det G0>=.985theta, and EVERY true
replacement determinant divided by that true determinant is at most

                  (2det G+e)/(det G-e) <=3.             (3.1)

4. POLYNOMIAL CONDITIONING FROM THE TRUE LOCAL VOLUME BOUND

Take any isometry U with range P; it is used only analytically. For the
selected rows I, let U_I be the square dxd row matrix. It is invertible
because det G0>0. For an unselected row j, write

                     U_j=z_j U_I.

Cramer's rule identifies |(z_j)_i|^2 with the true Gram determinant
ratio from replacing selected row i by row j. By (3.1) all these squared
coefficients are <=3. Put Z=U_(I^c) U_I^-1. Orthonormality gives

 I=U_I^*(I+Z^*Z)U_I,
 G0=U_I U_I^*=(I+Z^*Z)^-1.

Hence

                 lambda_min(G0)>=1/[1+3d(a-d)]=1/H,
                 lambda_min(G)>=1/(2H).               (4.1)

No internal eigenspace or singular-value gap is being acquired. A local
volume condition on the near-projector columns supplies the polynomial
conditioning bound. It is stronger than bounding the smallest eigenvalue
by an exponentially small determinant alone.

Define exact polar isometries U0=C0 G0^-1/2, W=C G^-1/2. The same positive
inverse-square-root integral calculation as acquisition.txt gives

                   ||W-U0||<=8H^(3/2)zeta<=nu/16.      (4.2)

The acquired Gram spectrum lies in [1/(2H),2]. A binomial inverse-square-
root polynomial therefore needs only O(H log(H/nu)) terms. Compute it
and compile the resulting isometry with the finite-bit budgets already
specified in acquisition.txt Section 6. All true spectral projector/basis
objects occur only inside this proof; Q, column tests, Grams and rotations
are actually acquired from public rational matrices.

5. PREPROCESSING AND BIT COSTS

Precompute Q^*Q in O(a^3) rational operations. Greedy selection tests at
most ad small Gram determinants. Each local search tests at most d(a-d)
determinants of size d. With O(dlog a) exchanges, the deliberately simple
implementation costs at most O(a^3+a d^5 log a) rational operations plus
the sign-polynomial setup O(q a^3) and Gram series O(H log(H/nu)) terms.
There is NO binom(a,d)-sized exhaustive list or exponentially large Gram
series. Intermediate numerator/denominator sizes for these exact rational
operations are bounded polynomially in a,d,q, coefficient bit lengths and
the precision log(1/nu), by determinant height bounds and polynomial
evaluation. Those integer bit sizes are charged, not suppressed behind
an arithmetic-operation count. Dense finite rotation compilation remains
polynomial in a and its requested bit precision.

This proves polynomial dependence on the PHYSICAL MATRIX DIMENSION a,
not on N or n. Here a<=binom(L-1,r) and can be L^r, with r=O(sqrt(log n)).
Thus it can still be superpolynomial in n and impractical. Offline inverse
conditioning setup and small-L prefix constants remain as before.
The basis acquisition is a stronger finite resource interface, not an
efficient many-body eigenbasis theorem. Existing RRQR literature supplies
much sharper implementations; none is silently assumed for this proof.

Strongest claim

For every d>=2, the known symmetric universal 1-to-2 qudit cloner has
depolarizing marginal

  Phi_d(X) = p_d X + (1-p_d) Tr(X) I/d,
  p_d = (d+2)/(2(d+1)).

Its exact best EB Dirichlet comparison constant is 2:

  inf { c : there is an EB UCP Psi with I-Psi <= c(I-Phi_d) } = 2.

The upper certificate is the depolarizing EB channel

  Psi_d(X) = q_d X + (1-q_d) Tr(X) I/d,
  q_d = 1/(d+1),

and equality holds on the traceless operator space. The lower certificate
applies to every EB Psi: twirling any proposed comparison over U(d) preserves
the comparison and EB property; the twirled map is depolarizing with
parameter q<=1/(d+1), since the overlap of a separable state with a normalized
maximally entangled vector is at most 1/d. Hence

  1-q >= d/(d+1),  1-p_d = d/[2(d+1)],  and c>=2.

This gives a dimension-growing sharpness calibration for the c=2 candidate
in the broadcasting project. It does not refute the bounded-Holevo
broadcasting-to-EB conjecture.

Derivation of the cloner marginal

Let F be the swap on C^d tensor C^d and P+=(I+F)/2. The universal cloner is

  B_d(X) = [2/(d+1)] P+ (X tensor I) P+.

It has Kraus operators K_j=sqrt(2/(d+1)) P+(I tensor |j>), j=0,...,d-1.
Their normalization follows from

  sum_j (I tensor <j|)P+(I tensor |j>) = (d+1)I/2,

so B_d is trace preserving. Expanding P+ and tracing either output gives

  Tr_2[P+(X tensor I)P+] = ((d+2)X + Tr(X)I)/4.

The same expression holds for Tr_1 by swap symmetry. Multiplication by
2/(d+1) gives Phi_d above. On the normalized Hilbert-Schmidt space, Phi_d
has eigenvalue 1 on I and p_d on every traceless operator; it is therefore
UCP, selfadjoint and positive as a Hilbert-space operator. The explicit
two-output map B_d proves selfcompatibility on the full input algebra.

EB certificate and exact channel-distance witness

The normalized Choi state of a depolarizing map with parameter t is

  J_t = t |Omega><Omega| + (1-t) I/d^2,

where |Omega>=d^(-1/2) sum_i |ii>. A pure product vector has squared overlap
at most 1/d with |Omega>; convexity gives the same bound for every separable
state. Thus EB implies t<=1/(d+1) after U(d) twirling.

At q=1/(d+1), the Choi state has the separable Haar decomposition

  J_q = integral |psi><psi| tensor |bar(psi)><bar(psi)| dpsi
      = [I + d |Omega><Omega|]/[d(d+1)].

Equivalently, the EB map is the Haar measure-and-prepare channel

  Psi_d(X) = d integral <psi|X|psi> |psi><psi| dpsi
           = [X + Tr(X)I]/(d+1).

For prime-power d, a complete set of d+1 mutually unbiased bases gives a
finite d(d+1)-outcome projective 2-design implementation; its effects are
P_x/(d+1), and it prepares P_x. The all-d proof uses the Haar integral and
does not claim a finite efficient measurement compiler in arbitrary d.

For Phi_d, the normalized Choi overlap is

  <Omega|J_{p_d}|Omega> = p_d + (1-p_d)/d^2 = (d+1)/(2d).

For every EB channel Lambda, the overlap is <=1/d, so the Choi trace
distance obeys

  T(J_{p_d}, J_Lambda) >= (d-1)/(2d).

Psi_d attains this bound exactly, since J_{p_d}-J_{q_d} is a scalar multiple
of |Omega><Omega|-I/d^2. Thus the minimum EB Choi trace distance of the
full channel is exactly (d-1)/(2d), tending to 1/2. This is a Choi-input
certificate only; it is not a lower bound on reconstruction error for a
fixed-sandwich state family.

Instrument-structure check

For each d>=2, let S be the cyclic shift and use the bistochastic Kraus family

  K_0=sqrt(1/3) I,  K_1=sqrt(2/3) S.

Then L(X)=K_0 X K_0*+K_1 X K_1* is bistochastic, and for d>=3 is not
selfadjoint. Its effects are M_0=I/3 and M_1=2I/3. The canonical measurement
map is D(X)=Tr(X)I/d. The symmetrized instrument-append broadcaster has
common marginal C=(L+D)/2. Applying the bistochastic adjoint C* to both
outputs gives a full-domain broadcaster with positive selfadjoint marginal
Phi=C*C. The exact SOS identity is

  2(I-Phi)-(I-D)
     = (I-L*L) + (D-D^2) + (L-D)*(L-D)/2 >= 0.

Here I-L*L=(2/9)(I-Ad_S)*(I-Ad_S) for the selected probabilities,
D=D^2, and the final term is a Gram operator. On traceless operators,
Phi=L*L/4<=I/4, so the explicit EB map D satisfies

  I-D <= (4/3)(I-Phi).

This 4/3 is sharp for this fixed D: H=S+S* is traceless, Hermitian and fixed
by Ad_S, giving Phi(H)=H/4 and D(H)=0. This is a nonselfadjoint-instrument
fixture for the Petz-corrected construction, not a representation theorem
for arbitrary compatible channels or an optimality claim over all EB maps.

Costs, boundaries, and next gate

The cloner has d Kraus operators from a d-dimensional input to d^2 output
dimension; its formula and exact coefficient description have polynomial
size in d. The EB upper map can use d(d+1) outcomes in prime-power dimensions
with a complete MUB, while the general all-d Haar form has continuous
outcomes; finite POVM compilation and precision costs are not claimed free.
The entangled-Choi lower bound charges a maximally entangled reference and
does not transfer to the bounded-steering fixed-sandwich experiment.

The exact factor 2 is a necessary lower benchmark for any universal
Dirichlet-rounding theorem. The assigned open gate remains: prove a uniform
EB Dirichlet comparison (or weaker collective-variance modulus) for every
positive tracial-selfadjoint selfcompatible channel, or build a growing
fixed-sandwich family with vanishing broadcast error and EB error bounded
away from zero. Neither is resolved here.

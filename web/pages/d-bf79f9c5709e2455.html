1. THERMAL COST INTERFACE
For each edge and site define
  A_uv = 3 alpha I + alpha(XX+YY)+gamma ZZ,
  A_v  = (b+|c|) I + b X+c Z.
Their eigenvalues show A_uv >= 0 and ||A_uv|| <= 6 alpha. Also A_v >= 0 and ||A_v|| <= 2(b+|c|), because (b+|c|)^2 >= b^2+c^2. Thus sum A_i=H+C I and sum ||A_i|| <= D=2C. C=0 is the trivial H=0 case.

For rational s>=0 the edge gate F_i=I+s A_i has a six-vertex table with coefficients
  a=1+s(3alpha+gamma), b'=1+s(3alpha-gamma), c'=2s alpha.
The triangle inequalities are equivalent to the three nonpositive Hessian eigenvalues 2s(gamma-alpha), -2s(gamma+alpha), -2-4s alpha. A field gate has table [[v,d],[d,u]], d=sb, u=1+s(r-c), v=1+s(r+c), r=b+|c|; uv-d^2 >= 1. Splitting its two off-diagonal variable roles over two dummy variables gives the rational homogeneous lift
  d z1 z2 +(u/2)x(z1+z2)+(v/2)y(z1+z2)+dxy.
It is log-concave: a positive rescaling used only in the proof balances u,v, after which the quadratic has at most one positive Hessian eigenvalue precisely because d^2<=uv. The oracle still uses rational u/2,v/2; no irrational square root is computed.

Let p be the number of retained local terms and tau=beta*D. With m=ceil(max{1,4 tau,20 tau^2/eta}), s=beta/(2m), and W=product_i(I+sA_i), set B=W W*. The symmetric product gives ||m log B-beta(H+C I)|| <= 5 tau^2/m <= eta/4. Min–max then bounds every eigenvalue of the two Hermitian generators by eta/4, and summing the exponentials gives
  exp(-eta/4) Tr exp(beta(H+C I)) <= Tr(B^m)
      <= exp(eta/4) Tr exp(beta(H+C I)).
This uses eigenvalue comparison; it does not use operator monotonicity of the exponential or an additive error divided by the partition function.

The B^m circuit has 2mp gates and N=8mp variables after the field lift. Its two homogeneous measures are P (product of the local lifted gates) and Q (wire-pair factors times a uniform-matroid elementary-symmetric polynomial). Their degrees both equal N/2. A positive coefficient of P is a product of O(mp) local rational coefficients, so the explicit value oracle has polynomial output length and log coefficient range O(mp(L+log m)), where L covers rational input bit lengths; Q has coefficient range 1. Chen–Liu Theorem 5.1 costs
  O(N^10 (N+log(R_P R_Q))^2 zeta^-2
       log^2(2(N+log(R_P R_Q))/zeta))
value-oracle calls/arithmetic operations for relative counting error zeta. Remark A.4 supplies a bit implementation for rational inputs with polynomial-time rational value oracles. Here those oracles are products of local rational coefficients; their support witnesses are selected locally. The crude bit cost is therefore polynomial in N, L, log m and zeta^-1 on every execution.

For partition approximation, eta and zeta are Theta(epsilon), so m=O(1+tau+tau^2/epsilon). This is polynomial in numerical beta*C, not in binary log(beta*C) in general. Recovering Tr exp(beta H) from the shifted trace multiplies by exp(-beta C); a relative rational approximation to this scalar can require O(beta*C+log(1/epsilon)) bits. Thus the binary-input FPRAS claim is not made for arbitrary low temperatures. Diagonal sequential sampling also has polynomial numerical-temperature cost: each conditional uses relative child-mass estimates, so no inverse probability of the sampled prefix enters; Chen–Liu's convolution algorithm returns exact zero when the target coefficient is zero.

2. RELATIVE LARGEST-EIGENVALUE EXTRACTION
Put A0=sum alpha, B0=sum b, T0=sum |c|. The |+>^n state has expectation A0+B0. A computational basis state with Z signs matching c has expectation at least T0-A0, since every edge contributes gamma z_u z_v >= -|gamma| >= -alpha. Therefore
  lambda_max(H) >= max(A0+B0,T0-A0)
      >= (4(A0+B0)+(T0-A0))/5
      = (3A0+4B0+T0)/5 >= C/5.
Also ||H||<=C, so lambda_max(H)<=C. These bounds hold for signed gamma,c and all allowed graphs.

For C>0 choose rational beta=20(n+1)/(epsilon C), so beta*C=20(n+1)/epsilon and tau=beta D=40(n+1)/epsilon. For Z+=Tr exp(beta(H+C I)),
  lambda_max(H) <= log(Z+)/beta-C
      <= lambda_max(H)+n log(2)/beta.
A constant-relative estimate of Z+ contributes only O(1/beta) after the logarithm. With the displayed beta, both that error and n log(2)/beta are < epsilon*C/5 <= epsilon*lambda_max(H) with room to spare; logarithm evaluation to constant additive accuracy suffices. Choose constant eta,zeta in the Euler/counting reduction, so m=O(tau^2), N=O(p(n/epsilon)^2), and the imported arithmetic bound is roughly O(N^12 poly(L,log N)) (hence, very large but polynomial, with epsilon exponent about 24 under this loose bound). beta has polynomial encoding length even when C is tiny. This is a standard bit-FPRAS for the positive lambda_max; C=0 returns zero. No exp(-beta C) scaling is needed because the estimator uses Z+ and subtracts exact rational C.

3. OFF-DIAGONAL REDUCED-STATE INTERFACE
Write e for two-qubit gates and f for one-qubit field gates in the Euler circuit. There are W=2e+f physical wires and N=4(e+f)=2(W+f) ground variables. Open k wires for a reduced-state entry N_(a,b)=Tr_rest <a|B^m|b>, pin the row bits to a and the original column bits to b. Under the complement-column convention, a pinned column bit contributes 1-b. On each opened wire, replace its partner factor by the fixed complement monomial for the two pinned P endpoint bits, then factor out all 2k pinned coordinates. With Delta=|a|-|b|, P's pins force k+Delta selected physical variables; the remaining W-k wire factors contribute one selection each. Hence P's residual degree is
  N/2-(k+Delta) = N/2-k-Delta.
The partner Q must use the uniform-matroid factor e_(f+Delta) on the 2f dummy variables, so its degree is
  (W-k)+(f+Delta) = N/2-k+Delta.
The degrees sum to N-2k, the remaining ground-set size. The adjusted rank is essential: using e_f on every entry would kill all charge-changing entries. If f+Delta is outside [0,2f], the entry is zero; this matches the fact that the XX+YY/ZZ gates preserve excitation number and only the f X-field gates can change it. Differentiation for pins equal to 1 and zero-variable specialization for pins equal to 0 preserve log-concavity. The resulting oracles remain rational and nonnegative. In particular, these are nonnegative counts despite off-diagonal entries: every local gate is entrywise nonnegative in the stated basis.

For d=2^k, each normalized entry of the positive state B^m/Tr(B^m) lies in [0,1]. Relative estimates of numerator and denominator with zeta=epsilon/(100 d^2) give entry error at most 3 zeta. The entrywise absolute-error sum bounds trace norm by the triangle inequality on matrix units, so the raw trace-norm error is at most 3 epsilon/100. Symmetrize; clipping negative eigenvalues and renormalizing costs at most four times the raw error. The symmetric-Euler state itself is within trace norm at most epsilon/4 of the Gibbs state when its generator error is set to epsilon/4: the Jeffreys-divergence/Helstrom argument gives half trace distance t<=tanh(eta/8)<=eta/8. Partial trace contracts trace norm. The total is below epsilon, with extra allowance for numerical spectral arithmetic. Estimating d^2 entries at accuracy epsilon/d^2 costs at most a d^6 factor in the naive call count (d^4 per entry for zeta^-2 times d^2 entries), still polynomial for k=O(log n). No relative guarantee is claimed for signed local observables; only their additive error follows from the trace-norm estimate.

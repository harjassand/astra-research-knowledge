## Original versus auxiliary inputs

Assume original checks of bounded weight w_c and site incidence w_q on physical qubits of bounded density, fixed physical range, code distance d and nonzero code space2^k. Assume an ambient filling radiusCr, for whole original checks, up to r_fill. Let a finite rectangular integer box contain all original sites and a fixed margin, with polynomially many integer grid vertices. This volume is a separate premise. If the original actual qubit graph is connected and its edges have physical length<=2, its physical diameter is<=2(n-1), giving a box of volumeO(n^3) in three dimensions; actual connectedness is independently checked by the geometry workers.

Attach each original site q to its nearest grid site a(q), with at most b attachments per grid site. Add fixed |+> ancillas and actual checks X_v. Apply the commuting CZ gates on grid nearest-neighbor edges and all attachment edges. Let Delta=2D+b, s=Delta+1. Gates can be partitioned into a bounded number of matching layers. Their Pauli conjugation adds only one-neighborhood Z factors, because CZ leaves Z unchanged. Thus both U and U* have actual Pauli spread<=s and fixed physical range.

The dressed ancillary check is

    K_v=X_v product_{w grid-neighbor v} Z_w
               product_{q:a(q)=v} Z_q.

These are actual nonidentity supports. Neighbouring K_v,K_w intersect, and their qubit supports contain each grid and attachment edge. Every dressed original check C'_alpha retains every original nonidentity data site, even if all added grid Z factors cancel. It therefore intersects K_{a(q)} for any q in its original support. This closes the possible all-Z or even-parity attachment concern without declared supports.

Explicit conservative incidence constants are

    Wc'=max(2w_c, 2D+b+1),
    Wq'=max(w_q+1, 2D+1+b w_q).

The second bound charges transformed original checks meeting each attached data site. It is not the original Tanner degree. The untransformed augmented code has distance d and dimension2^k; any commuting ancilla I/X factor is a stabilizer. Conjugation gives d'>=d/s, not exact preservation.

## Actual-graph local generation

For an actual stabilizer p supported on the union of a connected set S of k checks, fixed dressed range puts its support in an ambient ball of radiusO(k). Undressing adds only a fixed range and produces g_data times a product of X_v ancillas. The data factor is an original stabilizer in that ambient ball. Apply the whole-check filling premise, then dress the chosen generators again.

Every required ancillary generator is adjacent to S directly: CZ preserves Pauli X-bits, so its index v was an X/Y site of p inside that union. If the data factor is nontrivial, pick q0 in its actual support. Either q0 was already in p or its new Z arose from an X/Y at a(q0); in either case K_{a(q0)} is adjacent to S. Every selected dressed original generator intersects K_{a(q)} at an original data site q of its whole-check filling. Manhattan grid paths join the selected anchors in O(Ck) steps. Both endpoints lie in the rectangular grid; a coordinate-monotone path remains inside it. Pure ancillary stabilizers require no data filling.

Consequently actual TQO-II holds up to cutoff r_fill/A for a fixed geometric A, with an actual check-graph radius ell k. The word cutoff is at most

    d_eff=min(d/(s Wc'), r_fill/A),

and must dominate log n', where n' includes all grid ancillas. Polynomial ancillary volume only preserves an already adequate distance/filling scale; it cannot increase the filling window.

If r_fill is comparable with d, or is infinite, the source's formal requirement that its local-generation cutoff be Theta(actual distance) is satisfied. For a smaller r_fill, replacing the distance parameter by the explicit smaller cutoff uses the audited proof's TQO-I/word-truncation variant and is not literally the published distance definition. The intended all-radii premise avoids this qualification.

## Physical norm and removal of ancillas

For an original physical finite-range perturbation V=sum_X V_X, bounded density bounds |X|<=q0 and define J=sup_q sum_{X:q in X}||V_X||. Its Pauli l1 cost is<=2^{q0}. The dressed original-only term adds only attached grid sites. Its supports have an explicit connected cover of fixed size m0: use those attachments and coordinate-monotone grid paths inside the bounded box spanned by them. At an original site the originating term sum is<=J, and at an ancilla it is<=bJ. Therefore

    |||U(V tensor I)U*|||_mu
       <=max(1,b)2^{q0}exp(mu m0)J.

This verifies the actual-graph Pauli norm with its body, incidence and cover costs charged. No numerical usefulness of the resulting J threshold is asserted. The construction is a mathematical proof device, not an implemented physical circuit or a finite-bit embedding acquisition.

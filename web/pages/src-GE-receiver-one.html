# Total reusable noncommuting receiver on one closed code wire

16 October 2026. Modified generator. This is a **fixed five-site base operation**, with an actual reusable two-bank contract. It is not a recursive compiler, universal computation construction, general interacting-lattice eroder, or threshold theorem. The terminal map is fully specified below, but is one atomic five-site engineered CPTP jump. Enlarging its support with encoding level is not permitted by this result.

The construction retains actual noncommuting logical operations. At terminal number n its quantum output is the alternating word `X_L, C_L, X_L, C_L, ...` through n, not an identity obtained by undoing every gate. Independent onsite fast-path proposals may apply portions of the next transversal operation. A total terminal receiver finishes the missing suffix, recovers the code, transfers ownership and resets all control copies. It can accept from every physical state. This removes one-use authorization and raw occupancy guards in this finite closed receiver.

## Hardware and code

Five distinct noisy physical sites lie in one fixed bounded-diameter motif, e.g. five cells of a 2 by 3 rectangle. Each carries two qutrit data banks `A_i,B_i` with levels `0,1,perp`, one phase copy `r_i in Z_4`, and one progress bit `l_i in {0,1}`. The local Hilbert dimension is `3*3*4*2=72`. No program word, coordinate color, input token or occupancy flag is stored. The motif and the two gate matrices are hardwired couplings. Identically translated motifs can be independent cells; this does not establish a one-site translation-invariant interacting hierarchy.

`V:C^2 -> (C^2)^5 subset (C^3)^5` is the standard five-qubit perfect code with stabilizers `XZZXI, IXZZX, XIXZZ, ZXIXZ`; `X_L=XXXXX`, `Z_L=ZZZZZ`. Define

```
X = [[0,1],[1,0]],
C = (I - i(X+Y+Z))/2.
U_r = X if r is even, C if r is odd.
```

Both transversal `U_r` preserve this code. Their induced logical channels are `Ad_X` and `Ad_C`, which do not commute. Every physical gate uses the qutrit extension `U_r tilde = U_r direct-sum 1_perp`. The exact code/isometry check is in `check_receiver.py`; the proof uses the stabilizer action, not floating-point tolerance.

For a five-copy phase word `s`, let `d(s)` be a residue with maximal multiplicity, with ties resolved by the least residue. It is a total finite function. If at most one site differs from a uniform phase r, `d(s)=r`. Hardwiring this function does not require a noiseless physical register: it is part of the ideal five-site map. Failure of that map is an admitted block fault below.

Initially all `r_i=0,l_i=0`, A contains `V rho V^dagger`, and B is vacuum. On canonical phase r the owned bank is `S=A` if r is even and `S=B` otherwise; the other bank D is unowned and has no live incoming port. The sole logical packet never branches to other cells in this model.

Assuming this atomicity at growing levels would assume the missing compiler. If the five-site proposal fails physically, its error is counted as a block fault; it is not declared a harmless clock repair.

`T` deliberately has no source-occupancy, destination-vacancy, ready-majority, completion or program-unanimity guard. The suffix is physically applied, not silently inferred. At a clean strand `l=0` means no fast-path gate occurred, so T applies it; `l=1` means precisely one occurred, so T does not apply it again. ## Explicit total qutrit recovery

Let the 26 error maps be

```
E = {I} union {X_i,Y_i,Z_i: i=1,...,5}
        union {|perp><0|_i, |perp><1|_i: i=1,...,5}.
```

On the code, `V^dagger E_a^dagger E_b V = delta_ab kappa_a I_2`, with `kappa=1` for I/Pauli maps and `kappa=1/2` for the leakage maps. Thus `W_a=E_a V/sqrt(kappa_a)` are orthogonal isometries. Put `Q=sum_a W_a W_a^dagger`, and choose `tau=V|0><0|V^dagger`. Define the **specified**, total recovery

```
R(sigma) = sum_a V W_a^dagger sigma W_a V^dagger
           + Tr[(I-Q)sigma] tau.
```

This is CPTP on the whole 243-dimensional qutrit space. The first 26 Kraus operators are `V W_a^dagger`; the remaining Kraus operators can be `|0_L><w_j|` for any fixed orthonormal basis of the 191-dimensional complement of Q. Its range is always the code, including on states with several vacancies. It corrects every one-site qutrit error on an arbitrary reference. No noisy syndrome register or postselection is hidden in this definition.

## Exact fault and observation contracts

An onsite fault may be any CPTP action on **all** of `A_i,B_i,r_i,l_i` at one site, with an arbitrary untouched reference. It may occur at any partial fast-path cut, alter source/destination sectors coherently, or repeat arbitrarily often at that site. The theorem permits at most one DISTINCT affected site between consecutive ideal terminal events, and at most one in the last interval before `D_hold`. This is stronger than a one-counter theorem, but not a two-site code theorem.

The separate engineered-operation model admits arbitrary faulty M proposals as onsite faults. An arbitrary faulty T proposal acts on all five sites and is a declared bad block event at rate eta. Under a model with bad fraction epsilon per nominal terminal proposal, use good-terminal rate `lambda=(1-epsilon)lambda_0` and bad-terminal rate `eta=epsilon lambda_0`. If a finite-duration implementation is used, its gates, ancillas, idle volume and errors require a new proof; the atomic model has no such interval.

At the n-th ideal T, on a good history the owned output code equals

```
V G_n rho G_n^dagger V^dagger,
G_n=U_(n-1) ... U_1 U_0,  U_even=X_L, U_odd=C_L,
```

all controls are canonically `r=n mod4,l=0`, and the previous source is vacuum. This holds for every n and every joint input/reference state. `D_hold` returns the state after the last T by undoing the incomplete fast-path prefix. It does not accidentally advance the logical circuit. A deterministic-time experiment therefore compares to the ideal random-terminal autonomous process; it does not supply an external exact gate count for free.

All malformed control words, including `(1,2,3,0,0)` and split copies, have the same state-independent rate-lambda terminal service. From EVERY joint physical input, an ideal T returns one bank to the code, the other to vacuum, and unanimous phase/progress controls. From an uncorrectable input it may destroy the logical state or select the wrong phase. Total service is not exact-history recovery outside the stated fault family.

There is no incoming live port to the unowned bank before T. Adding one invalidates the unconditional discard. There is no entangling gate with a fresh external block, output stream, or independently reloaded source. A phase corruption outside the correctable family can become a clock-payload error on this one closed wire; this does not prove bounded fanout for a streaming/interacting controller.

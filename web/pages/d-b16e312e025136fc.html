STRONGEST INITIAL CLAIM

The Gaussian and regular product-sensor archive bounds have a clean, dimension-free tail charge when their independent-reference and ellipsoid hypotheses hold, but the summaries do not define an end-to-end finite-bit, uniformly effective compiler. Two exact gates are visible: (i) a bare pointwise condition r_i -> 0 does not let a general coordinate-oracle algorithm certify an active-mode cutoff, and (ii) a decoder using only finite digital randomness has countable support and therefore TV distance exactly one from a continuous target. An effective spectral-tail certificate and an explicit continuous-output/randomness interface are necessary. The known memory laws also have distinct dimension regimes: geometric spectra give quadratic-in-log precision bits, polynomial spectra give only a Theta(active-modes) candidate law whose per-mode overhead is leading-order. These claims do not validate the unavailable N30/N31/N66 proof packets or solve the joint-posterior target.

1. EXACT TAIL BOUNDS (VERIFIED INTERNAL DERIVATIONS)

Gaussian sequence. Let P_v = product_i N(r_i v_i,1), with sum_i v_i^2 <= 1. If a certified cutoff n satisfies sup_{i>n} r_i <= tau, regenerating the omitted coordinates as independent N(0,1) gives a tail mean m_i=r_i v_i with ||m||_2 <= tau. On every finite tail block,

  D(N(m,I) || N(0,I)) = ||m||_2^2/2 <= tau^2/2,
  TV(N(m,I),N(0,I)) <= sqrt(D/2) <= tau/2.

Passing to the countable product by the finite-block likelihood limit preserves this bound. Thus tau=epsilon spends at most epsilon/2 in TV, without a log-tail or dimension factor. This conclusion needs the ellipsoid bound and a certified tail envelope; it is false for an unrestricted parameter box with one nonzero coordinate per omitted mode.

Regular nonGaussian product sensor. Under N66's supplied assumptions, write dP_i/dmu_i=1+t_i with t_i=r_i v_i h_i, E_mu_i h_i=0, |h_i|<=1/2. If all omitted r_i<=tau, then t_i>-1 and log(1+t_i)<=t_i, so

  D(P_v,tail || product_i mu_i)
    = sum_i E[(1+t_i)log(1+t_i)]
    <= sum_i E[t_i+t_i^2]
    = sum_i r_i^2 v_i^2 E h_i^2
    <= tau^2/4.

Pinsker gives tail TV <= tau/sqrt(8), hence tau=epsilon spends less than epsilon/2. This extends from finite tails by the L2/KL product limit when the displayed sum is finite. The independence, centering and uniform amplitude bound are load-bearing; a Fisher diagonal alone does not supply this tail estimate.

2. GROWING-DIMENSION AND BIT CHARGE

For a weak sequence 0<=r_i<=1, define N_r(epsilon)=#{i:r_i>epsilon} and S_r(epsilon)=sum_i [log_2(r_i/epsilon)]_+. The N31 summary claims

  (1/2) S_r(100 epsilon) <= B_q(epsilon) <= B_cl(epsilon)
      <= (1/2) S_r(epsilon) + 14 N_r(epsilon).

This is only a candidate claim here: its linked full proof/compiler package is absent, and the constants/checks are source-reported. Conditional on that theorem, the label count is not just an active-coordinate count: each retained coordinate costs about one half log_2(r_i/epsilon) bits plus a per-mode label/rounding overhead. The file memory_cost_audit.py computes the exact sums and one illustrative mixed-radix serialization for r_i=2^-i, epsilon=2^-q; its output is saved alongside it. The computation checks the arithmetic only, not the codec theorem.

For r_i=e^(-b i^p), L=ln(1/epsilon), the integral/sum comparison gives

  N_r(epsilon) ~= (L/b)^(1/p),
  (1/2) S_r(epsilon) ~ [p/(2(p+1)b^(1/p) ln 2)] L^(1+1/p).

For p=1 this is L^2/(4 b ln 2)+O_b(L), matching the earlier candidate. For r_i=i^(-a), N_r(epsilon) ~= epsilon^(-1/a) and

  (1/2) S_r(epsilon) ~ [a/(2 ln 2)] epsilon^(-1/a).

The N31 +14N overhead is the same order as the polynomial-spectrum leading term, so that summary gives a sharp exponent but not a sharp leading coefficient there. For finite dimension d, replace N by min(d,N_r); with d weak axes r_i=1, the main term is (d/2)log_2(1/epsilon), and the reported overhead is 14d.

N30 is a different interface: known Gaussian mean boxes, arbitrary radii, but constants c_s,C_s,epsilon_s depend on fixed affine dimension s. Its formula cannot be promoted to growing s without a new uniform-constant proof. N31 is a weak ellipsoid sequence candidate with dimension-independent constants, not a consequence of N30. N66 is an independent nonGaussian product-sensor candidate whose constants depend on fixed regularity data (density bounds, Lipschitz/derivative bounds and monotonicity); if those bounds vary with dimension, its claim does not remain uniform. None of these labels includes model acquisition, exact eigenvector/sensor access, encoder input precision, decoder runtime, physical random-bit generation, or continuous output generation.

3. EXACT EFFECTIVE-TAIL OBSTRUCTION FOR GENERAL ORACLE SEQUENCES

A computable sequence r_n in [0,1] can tend to zero with no algorithm that, from coordinate access to r_n, returns N(epsilon) satisfying r_n<=epsilon for every n>N(epsilon). Here is a halting reduction. Enumerate machines M_e. At stage n, simulate each e<=n for n steps. Set r_n to the maximum 2^-e over those machines whose first observed halting time t_e satisfies max(e,t_e)=n; set r_n=0 if there are none. Each r_n is an exactly computable dyadic rational. It tends to zero, since for any fixed threshold only finitely many indices e have 2^-e above it, and each such machine can create at most one spike.

Suppose a total cutoff algorithm existed. On input epsilon=2^(-(e+1)) and this sequence oracle, let it return N. Simulate M_e for max(N,e) steps. If it halts, answer yes. If it has not halted, it cannot halt later: a later halt would create a spike r_n>=2^-e>epsilon at n=max(e,t_e)>N, contradicting the certified tail. This decides the halting problem. Therefore pointwise r_i->0 is not an effective tail certificate. A sorted monotone computable spectrum avoids this particular obstruction because scanning until r_i<=epsilon certifies its suffix, but costs a scan; a nonmonotone coordinate oracle needs a modulus/envelope or an equivalent promise. This lower bound applies directly to the broad N31/N66 countable-sequence wording unless effective decay is supplied.

For an arbitrary unsorted coordinate oracle, finding all active indices additionally takes at least one query per inspected coordinate in the black-box model. If a model provides a sorted spectrum, a closed-form decay law, or a tail oracle, that charge can be lower; none is free by the memory-bit theorem. In an explicit geometric model, n=Theta(log(1/epsilon)) values are active. For a polynomial model, n=Theta(epsilon^(-1/a)); acquiring n spectral values/eigenvectors can already dominate the archive. If n entries must each be delivered to P bits, that metadata is nP bits. With P=Theta(log(1/epsilon)), this is a factor log(1/epsilon) beyond the Theta(n) polynomial-spectrum archive. This is a conditional cost statement, not a universal lower bound when the spectrum has a short formula.

4. FINITE-DIGITAL OUTPUT OBSTRUCTION

If an encoder/decoder uses only a finite random tape (even a random-length tape that terminates almost surely), its possible output set is countable. Any target with a density assigns that set probability zero, while the digital output assigns it probability one; hence TV=1. A fixed B-bit tape gives finite support and the same conclusion. This applies already to a one-dimensional Gaussian reconstruction, regardless of how fine its grid is. The N30/N31/N66 codecs define stochastic Markov kernels with continuous decoder densities; that is an information-theoretic interface, not a finite-bit sampler. A practical implementation must explicitly allow an analog/continuous random primitive, change the output/task to a quantized law or weaker metric, or abandon TV-to-the-continuous-target. Merely charging a finite precision parameter cannot repair TV for an atomic output.

A further finite-time issue appears for the countably infinite output experiment: a machine cannot emit an entire infinite sample in finite time. A realizable theorem needs a cylinder-query/lazy-stream contract or a finite truncation with a proved global tail bound, in addition to the active input-mode cutoff.

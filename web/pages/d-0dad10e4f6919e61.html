SU(3) WALL WEIGHTED COUNT: INTERPOLATING FIBER-SPECTRUM GATE
Date: 2026-10-08
Status: the reduction below is proved conditional on the all-output sorted
eigenvalue lower bound (2.1), which remains open globally. A separate exact
near-wall argument now proves the required low-window count H; see
NARROW_WALL_WEIGHTED_COUNT.txt. Thus (2.1) is no longer required for H.
A bounded numerical check found no violation; this is finite evidence only.

1. SETUP AND EXACT BLOCK DATA

Let a>=b>=1, N=a+b, B=b+1, and lambda=(a,b). Use the exact normalization
in outputs/research/sol_semiclassical_memory/wall_su3/
MISSING_LABEL_MAPPING.txt: on End(V_lambda),

  L_w=L_T/N^2 + L_S/(N sqrt(C_S)),
  End(V_lambda)=direct_sum_(p,q) V_(p,q) tensor M_(p,q),
  L_w|_(p,q)=c2(p,q)/N^2 I + K_(p,q)/(N sqrt(C_S)),

where K_(p,q) is the positive Hermitian multiplicity-space matrix induced
by L_S. Write D_w(t)=Tr 1_[0,t](L_w) for the full count; the target below
is the positive-spectrum count D_w(t)-1, with the one scalar eigenvalue
removed. The exact identity

  C_S/[b(b+2)] = a(a+2)(N+1)(N+3)/(12 C2 N^2)

gives sqrt(C_S) comparable to B with absolute constants for a>=b>=1.

For a low output block with p+q<=a, the exact GT/LR interval in
wall_lower/branching/weighted_branching_audit.txt is

  delta=|p-q|/3,
  j=delta,delta+1,...,min(j_max,b),
  j_max=(2 min(p,q)+max(p,q))/3,
  dim M_(p,q)=min(j_max,b)-delta+1,

when p congruent q (mod 3), and zero otherwise. Since c2(p,q)<=T
implies p+q<=2 sqrt(T), the range p+q<=a contains every nontrivial
output block in the requested window T<=c0 N once N is larger than an
absolute threshold (the remaining bounded N cases can be absorbed into
the final constant). The branch interval identifies the integer labels,
but does not identify eigenvectors of K_(p,q).

2. A SHARPER SUFFICIENT SPECTRAL LOWER BOUND

Write the eigenvalues of K_(p,q) in increasing order as

  0<=kappa_1<=...<=kappa_m,
  eta=(a-b)/N,
  j_l=delta+l-1, l=1,...,m.

The following carrier-uniform bound would suffice:

  kappa_l >= c_* [j_l + eta j_l^2]                            (2.1)

for every low block p+q<=a and every l, with a universal c_*>0.
The j=0 slot has right side zero; it may be the one soft mode in a
diagonal p=q block. Thus (2.1) does not rule out the exact adjoint
soft-mode behavior. It is weaker than a uniform quadratic lower bound in
the regular interior and has the correct two regimes: linear when a=b,
quadratic near the wall a-b comparable to N.

No simultaneous eigenbasis assumption is made in (2.1): the labels j_l
are attached to the ordered eigenvalues only as a proposed spectral
comparison. This is precisely why (2.1) is the load-bearing unresolved
claim rather than a consequence of the GT dimension formula. The narrow
window count does not need this global interpolation.

3. PROOF THAT (2.1) IMPLIES THE TARGET COUNT

Let T=N^2 t and beta=B/N. A counted eigenvalue in a block must satisfy

  c2(p,q)<=T,
  kappa_l <= N sqrt(C_S) (t-c2(p,q)/N^2)
            <= C beta T.                                   (3.1)

The j=0 slot is not controlled by (2.1) and must be counted separately.
It occurs only when delta=0 and l=1, hence only once in each diagonal
output block p=q. The Casimir cutoff leaves O(sqrt(T)) such outputs, each
of dimension O(T^(3/2)), so all j=0 slots contribute O(T^2).

For every counted slot with j_l>=1, (2.1) implies

  j_l+eta j_l^2<=R,  R=C beta T.

Also j_l<=j_max<=C sqrt(T). For fixed delta, the relation q-p=3 delta
leaves O(1+sqrt(T)) possible labels (p,q); each representation has
dimension O((1+sqrt(T))^3). Thus each admissible pair (delta,l)
contributes at most C T^2 to D_w(T/N^2), for T>=3.

Let J be the largest positive integer with J+eta J^2<=R, or J=0 if
there is none. The map (delta,l)->j=delta+l-1 has j+1 preimages at
fixed j, so the number of admissible positive-j pairs is at most

  C sum_(j=1)^J (j+1) <= C J^2.

If beta>=1/4, use J^2<=CT<=4C beta T. If beta<1/4, then
b/N=beta-1/N and

  eta=1-2b/N=1-2beta+2/N>1/2,

so J^2<=R/eta<=2R<=C beta T. Therefore positive-j slots contribute
O(beta T^3), and adding the separately counted j=0 slots gives

  D_w(T/N^2)-1 <= C[T^2+beta T^3],  3<=T<=c0 N.          (3.2)

For T<3 there is no nontrivial SU(3) Casimir block. Finally d=dim
V_(a,b) is comparable to N^2 B uniformly for a>=b, so (3.2) is
equivalent, up to absolute constants, to

  D_w(t)-1<=C d[(N^2/B)t^2+N^3 t^3], 0<t<=c0/N.

This conditional proof includes the truncated branching range p+q>b;
it does not infer a matrix comparison from cardinalities.

4. FINITE CPV MATRIX CHECK

The exact quartic map in MISSING_LABEL_MAPPING.txt §4 gives

  K_(p,q)=(-Y_(p,q)-2 alpha X_(p,q)+sigma_(p,q) I)/N^2,

where X,Y are the simultaneous tridiagonal missing-label matrices of
Crampé, Poulain d'Andecy, and Vinet, arXiv:2110.03521, §1.3, Eq. (18).
Their Appendix A gives the physical multiplicity-space basis. In the
stable region p<=q, p+q<=b, the CPV basis has index set m=b-(p+delta),...,
b-delta, which relabels as delta,...,p+delta. This is an exact match of
index sets to the GT spin labels, not by itself a unitary identification.
The block is generally not diagonal in the CPV basis: its upper
off-diagonal is nonzero.

interpolating_fiber_check.py instantiates the source X,Y formulas and the
exact quartic map, symmetrizes each irreducible Jacobi matrix by diagonal
similarity, and tests (2.1) for all triality-zero p<=q, p+q<=a, on
1<=b<=20, b<=a<=60. It checked 112,251 carrier/output blocks and
652,918 nonzero-j eigenvalue comparisons. The minimum numerical ratio

  kappa_l/[j_l+eta j_l^2] = 0.777557969307...

occurred at (a,b,p,q,j)=(25,20,1,1,1), with kappa=0.86395329923...
The j=0 slot is omitted from the ratio. The CPV/GT multiplicity lengths
agreed throughout the checked range. This is a reproducible finite
diagnostic, not a proof of (2.1); the source matrices were evaluated in
floating point for the eigensolve.

The exact adjoint two-by-two block in
wall_lower/subelliptic/adjoint_block_and_count_obstruction.txt confirms
why the j=0 slot must be left unconstrained: near the wall one eigenvalue
of K_adj is O((b/N)^2), while the other remains order one. The count
condition (2.1) permits that first mode and charges the j=1 mode.

5. STATUS, FALSIFIERS, AND PRIOR ART

Proved: the branching interval and the conditional implication
(2.1)->(3.2); separately, NARROW_WALL_WEIGHTED_COUNT.txt proves the needed
low-window weighted count H by a restricted birth-death comparison.
Finite evidence: the stated CPV matrix test. Unknown: the uniform
all-output eigenvalue inequality (2.1), which is stronger than H. No
weighted-count counterexample is found. The exact ordinary
Casimir shortcut remains refuted by the stable-range counterexample in
WORKING.txt §4; that does not refute the weighted estimate.

Primary prior art: Crampé, Poulain d'Andecy, and Vinet give explicit
tridiagonal X,Y missing-label operators on SU(3) tensor-product
multiplicity spaces, and discuss their Hahn/Heun-Hahn structure and the
absence of general closed eigenvalue formulas; see their 2021 preprint,
https://arxiv.org/abs/2110.03521 and
https://arxiv.org/html/2110.03521. Their result does not state (2.1),
an eigenvalue count for K_(p,q), or the present weighted Dirichlet
profile. No novelty or priority claim is made for the conditional
comparison.

Next decisive gate: derive (2.1) from a uniform tridiagonal/Jacobi
quadratic-form comparison that preserves the physical multiplicity
metric, or find a growing (a,b,p,q,l) sequence for which its ratio tends
to zero. A proof only on stable blocks is insufficient when b<<sqrt(N),
because nonstable labels then occur in the requested Casimir window.

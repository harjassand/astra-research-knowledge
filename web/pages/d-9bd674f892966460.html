ACTUAL THERMAL / GLOBAL-OBSERVABLE IMPLEMENTATION

Input is a disjoint union of components of at most the admitted width cap,
rational easy-plane XXZ couplings, arbitrary rational Z fields, nonnegative
X fields and rational beta. The energy is -H, so rho=exp(beta H)/Tr exp(beta H).
The implemented global observable is a rational sum of I/X/Z Pauli strings
with sum absolute coefficients <=1. A full exact Hamiltonian-to-count
compiler is supplied for this subclass; K is acquired, not given as an oracle.

For component j the rational P2 factors are converted to common-denominator
integer matrices. K_j=(W_j W_j^T)^m_j is acquired by dense integer binary
power; its scalar denominator cancels in every mass and ratio. The exact
state sigma=tensor K_j/Tr K_j supplies every sampling and observable query.
No global 2^n matrix is built. The component width is where exponential cost
is paid. Numerical beta*C, bit height, matrix/storage cost, sample count,
random bits, query precision and output rounding are all charged.

An exact fixed-bit inverse CDF draws q_j fair bits and uses ceil(2^q CDF)
thresholds. Its actual law is known exactly, with
TV(mu_j,diag sigma_j)<=(2^b_j-1)/2^q_j. There are no rare-prefix divisions,
unbounded rejection loops, or soft-chain/mixing assumptions.

For the sparse estimator g_b=(O sigma)bb/sigma_bb, PSD Cauchy--Schwarz gives
E g^2<=1 with no minimum diagonal mass. A new certified local table compiler
approximates product ratios uniformly: set M_kj=max(1,max_b|r_kj(b)|),
U_k=product_j M_kj, choose 2^Q>=max(J,3J sum_k|c_k|U_k/zeta), and floor
each local ratio to Q bits. Product telescoping bounds global error by zeta.
This charges log U when individual ratios are large and avoids repeated long
denominators. Clipping, final dyadic rounding and variance give an additive
epsilon estimate with failure <=3/160 using ceil(256/epsilon^2) samples.
The mathematical contract assumes independent unbiased bits; the actual
default run uses SystemRandom. This is a classical measurement-law sampler,
not a quantum-state preparation or relative rare-event estimator.

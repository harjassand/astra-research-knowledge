EXACT CONVENTIONS

Sigma is a faithful density in M_d, sigma=sum_i p_i pi_i a finite pure
decomposition, p_i>0, pi_i=v_i v_i^*, ||v_i||=1. Let S=sqrt(sigma),

  M_i=p_i S^(-1)pi_i S^(-1),
  Psi(X)=sum_i Tr(M_i X)pi_i             [SCHRODINGER CPTP],
  Gamma(X)=S X S,
  T=Gamma^(-1/2) Psi Gamma^(1/2),
  E(rho)=Tr[sqrt(rho)(I-T)sqrt(rho)],
  e(rho)=||rho-Psi(rho)||_1/2.

Gamma^(1/2)(X)=sigma^(1/4) X sigma^(1/4). Do not confuse the present
Schrodinger notation Psi with the Heisenberg notation in the earlier
Cycle05 KMS proof. Define the Parseval frame

  a_i=sqrt(p_i) S^(-1)v_i, sum_i a_i a_i^*=I.

The Kraus operators K_i=v_i a_i^* are rank one and implement Psi. Its
balanced Kraus operators are

  L_i=sqrt(p_i) sigma^(-1/4)pi_i sigma^(-1/4),
  T(X)=sum_i L_i X L_i.

They are positive rank one. Thus T is CP and HS self-adjoint/positive.
Sigma stationarity gives T(S)=S. Sandwiched Renyi-2 contraction, already
reconstructed and primary-pinned in own Cycle05 work, gives ||T||<=1 on
Hermitian HS space. Hence 0<=T<=I and E>=0. The positivity and the following
explicit score formulas also follow directly from the rank-one Kraus form.
No Jensen inequality for T is asserted.

PROVED PURE-BRANCH TRACE REDUCTION

Put A=sqrt(rho), so ||A||_2=1. Define

  alpha_i=A a_i, q_i=||alpha_i||^2,
  f=sum_i p_i [v_i^* sigma^(-1/4) A sigma^(-1/4)v_i]^2,
  g=sum_i p_i |v_i^* A S^(-1)v_i|^2.

The score in E is exactly f, so E=1-f. The two state decompositions are

  rho=sum_i alpha_i alpha_i^*,
  Psi(rho)=sum_i q_i pi_i,
  sum_i q_i=1.

For q_i>0, both summands in each branch are pure and have the same trace
q_i. The exact pure-state trace formula gives

  (1/2)||alpha_i alpha_i^*-q_i pi_i||_1
      =q_i sqrt(1-|v_i^*alpha_i|^2/q_i).

Zero-q_i branches are zero and are omitted. Triangle inequality, followed
by Cauchy-Schwarz with weights q_i, gives

  e(rho)^2 <=[sum_i q_i sqrt(1-|v_i^*alpha_i|^2/q_i)]^2
             <=sum_i q_i-|v_i^*alpha_i|^2
             =1-g.                                      (B1)

The pointwise bound |v_i^*alpha_i|^2<=q_i also proves 0<=g<=1. This proof
uses actual trace error and pure branches, with no unknown fidelity claim
or prior-averaged reconstruction substitution.

SUFFICIENT ALGEBRAIC OBLIGATIONS, NOT PROVED HERE

The following would suffice, but are not established by this baseline:

  1-g<=2(1-f), equivalently g>=2f-1;                    (B2)
  1-g<=(1+1/sqrt2)(1-f).                               (B3)

These are sufficient conditions for the actual scalar bounds, not logically
necessary conditions. Failure of (B2) or (B3) would therefore not by itself
refute the requested actual-error bound.

The tempting stronger comparison g>=f IS FALSE. In particular a proof
claiming this from scalar Cauchy-Schwarz or from an unproved fidelity
comparison has a genuine gap. The exact counterexample follows.

EXACT LEGAL COUNTEREXAMPLE TO g>=f

Take d=2 and

  H=[[2,1],[1,1]], H^2=[[5,3],[3,2]],
  sigma=H^4/47=[[34,21],[21,13]]/47,
  p_0=34/47, p_1=13/47,
  v_0=(5,3)^T/sqrt34, v_1=(3,2)^T/sqrt13.

H is positive definite. Its fourth power has trace 47, and the displayed
ensemble sums to sigma. The actual canonical effects are the computational
projections M_0=|0><0| and M_1=|1><1|. Thus

  Psi(X)=X_00 pi_0+X_11 pi_1

is an explicit full-domain pure canonical EB channel. It has the full-domain
broadcaster sum_i X_ii pi_i tensor pi_i if compatibility is additionally
wanted; compatibility is not a premise of the scalar challenge.

Set A0=diag(101/100,99/100) and

  Z=Tr(A0^2)=10001/5000,
  rho=A0^2/Z=diag(10201/20002,9801/20002), A=A0/sqrt Z.

This rho is faithful. Since sigma^(1/4)=H/47^(1/4), all scores simplify to
rationals:

  f=[sum_i (H A0 H)_ii^2/(H^4)_ii]/Z=4649117/8840884,
  g=[sum_i |(H^2 A0)_ii|^2/(H^4)_ii]/Z=4648261/8840884,
  g-f=-214/2210221<0.                                   (B4)

These expressions are exact, not a numerical search. The actual qubit
trace error is separately computable from its traceless 2x2 difference:

  E=4191767/8840884,
  e^2=43368944841/176835361768,
  e^2/E=43368944841/83843723534<1.                       (B5)

Thus this example explicitly DOES NOT refute even e^2<=E. It only falsifies
the stronger branch-overlap shortcut g>=f.

A useful exact diagnostic behind (B4) is that for a general Hermitian
A0=z0 I+z1 X+z2 Y+z3 Z in this same legal example,

  g(A0)-f(A0)
    =[6z0 z1-12z0 z3+79z1^2-330z1 z3
       +423z2^2+344z3^2]/442.

The form is indefinite, and A0=I+Z/100 is already strictly positive.
This makes the false shortcut's failure transparent without any solver.

INDEPENDENT AMPLIFIED BASELINE

Let R be any finite reference, tau_R faithful, and use product weight
omega=tau_R tensor sigma. The amplified similarity is exactly

  T_R=Gamma_omega^(-1/2)(id_R tensor Psi)Gamma_omega^(1/2)
     =id_(operators on R) tensor T.

All tau_R factors cancel because the reference channel is the identity.
Therefore the stipulated E is independent of which faithful tau_R is
used, including a maximally mixed one. This algebraic fact is exact.
The amplified channel is EB on B only; it is NOT globally pure EB.

For A=sqrt(rho_RB), define embeddings
J_i=I_R tensor a_i, J'_i=I_R tensor v_i, and rectangular matrices

  alpha_i=A J_i, C_i=alpha_i^*alpha_i=J_i^*rho_RB J_i.

Then exactly

  rho_RB=sum_i alpha_i alpha_i^*,
  (id_R tensor Psi)(rho_RB)=sum_i J'_i C_i J_i'^*.

Both terms in branch i have trace Tr C_i, but can have rank dim R. The
scalar pure-state formula used in (B1) no longer applies. In particular,
if alpha_i=J'_i D_i, its input branch is J'_i D_iD_i^* J_i'^*, whereas
its output branch is J'_i D_i^*D_i J_i'^*. Internal nonnormality prevents
inferring equality merely because alpha_i lies in the prepared B subspace.
This is an obstruction to REPEATING THE SCALAR BRANCH ARGUMENT, not an
actual amplified counterexample: the matrices alpha_i are constrained by
a common positive A, and those constraints must be used in a correct proof.

The amplified (2+sqrt2)E bound remains unresolved in this independent
baseline. No globally pure-EB property or automatic tensorization of the
scalar trace proof is asserted.

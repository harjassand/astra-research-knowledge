SU(3) REGULAR-IRREP NEAR-FULL-RANK POSITIVE FILTER
Date: 2026-10-08

RESULT AND CONVENTIONS

This note constructs a positive-semidefinite, near-full-rank test operator for
the regular SU(3) irrep V_(a,b). It derives the relevant layer edge weights
from U(3) down to U(2) Gelfand–Tsetlin branching and Casimir identities; no
Sym^N(C^m) radial formula is used.

Use the Hermitian-generator normalization Tr_fund(T_A T_B)=delta_AB/2 and
define

  E(X)=sum_A ||[T_A,X]||_HS^2.

Write

  D=dim V_(a,b)=(a+1)(b+1)(a+b+2)/2.

Here Q denotes a prescribed nullity/rank deficit, in the near-full-rank
constraint rank(X)<=D-Q. The exact rank of the witness below is D-V_R, which
may be smaller than D-Q because entire weight layers are removed.

THEOREM (uniform finite range)

Let N>=16 be an integer and suppose the supplied highest-weight parameters
satisfy

  N<=a,b<=2N.

For any integer

  1<=Q<=floor(D/512),

put M=floor(N/2). For 0<=t<=min(a,b), define the E_11 layer size and
crossing conductance by

  g_t=(a+1)(t+1),
  w_t=(a+1)(t+1)(t+2)(a+2b-2t)/2.             (1)

Let V_r=(a+1)(r+1)(r+2)/2, and let R be the least nonnegative integer with
V_R>=Q. Then R<M. Define the exact resistance

  rho_(R,M)=sum_{t=R}^{M-1} 1/w_t
           =sum_{t=R}^{M-1} 2/[(a+1)(t+1)(t+2)(a+2b-2t)].             (2)

Define a layer profile alpha_t by

  alpha_t=1,                                             0<=t<=R,
  alpha_t=rho_(R,M)^(-1) sum_{j=t}^{M-1}1/w_j,          R<t<M,
  alpha_t=0,                                             t>=M.

The operator A acts by alpha_t on the entire E_11-eigenspace with eigenvalue
t. Set X=I-A. Then X is positive semidefinite and

  nullity(X)=V_R=(a+1)(R+1)(R+2)/2,
  rank(X)=D-V_R<=D-Q,
  E(X)=1/rho_(R,M).                                      (3)

After Hilbert–Schmidt normalization, this gives

  E(X)/||X||_HS^2
    <= 24 N^2/D * (1+sqrt(2Q/N))
    <= 24/N + 24 sqrt(2) sqrt(Q/D).                      (4)

Thus the near-full-rank constrained infimum over positive semidefinite X is
at most the right side of (4), uniformly over the stated finite range. The
construction is exact for each integer a,b,N,Q in that range; (4) is a
coarse but explicit simplification.

The exact formulas (1)-(3) themselves only require an integer 1<=M<=min(a,b)
and Q<=V_(M-1); the comparability assumptions N<=a,b<=2N are used for the
uniform estimates and the explicit Q<=floor(D/512) range.

PROOF

1. GT coordinates and layer counts

Use the polynomial U(3) highest weight

  lambda=(a+b,b,0).

The U(3) to U(2) branching is multiplicity free. A middle row (u,v) obeys

  b<=u<=a+b,   0<=v<=b,

and its U(2) module has dimension u-v+1; the bottom GT entry runs from v to
u. The U(3) center acts by T=a+2b, while E_11 has eigenvalue

  t=T-u-v.

Equivalently set x=a+b-u and y=b-v. Then 0<=x<=a, 0<=y<=b, t=x+y, and the
branch dimension is a-x+y+1. For t<=min(a,b), x runs from 0 to t, y=t-x,
so

  g_t=sum_(x=0)^t (a+t-2x+1)=(a+1)(t+1).

The cumulative multiplicity through layer r in this range is therefore

  V_r=sum_(t=0)^r g_t=(a+1)(r+1)(r+2)/2.                (5)

2. Exact root-edge conductance from Casimirs

Let E_ij be the standard complex matrix units in the representation. The
roots 1-2 and 1-3 change E_11 by one; the root 2-3 preserves E_11. For a
diagonal operator constant on E_11 layers, only the first two root pairs
contribute to E.

For a layer H_t, the total squared matrix-element weight of edges from H_t
to H_(t+1) is

  w_t=sum_(j=2)^3 Tr_(H_t)(E_j1 E_1j).                  (6)

Indeed E_1j raises the E_11 eigenvalue, so the trace is the sum of
||E_1j v||^2 over an orthonormal basis v of H_t. Under the stated Hermitian
normalization, the two Hermitian generators

  (E_1j+E_j1)/2,   (E_1j-E_j1)/(2i)

contribute a total |<w,E_1j v>|^2 |alpha_t-alpha_(t+1)|^2 per undirected
edge. Thus (6) is exactly the conductance for the commutator energy, with no
extra factor of two.

Use the U(n) quadratic Casimir C_n=sum_(i,j=1)^n E_ij E_ji. On the U(3)
irrep lambda its scalar is

  c_3=(a+b)(a+b+2)+b^2.

On a U(2) branch (u,v), the Casimir for indices 2,3 has scalar

  c_2(u,v)=u(u+1)+v(v-1).

On that branch E_11=t. Splitting C_3 into E_11^2, C_2, and cross terms gives
the scalar sum

  K_down+K_up = c_3-t^2-c_2(u,v),

where K_up=sum_(j=2)^3 E_j1 E_1j and K_down=sum_(j=2)^3 E_1j E_j1.
The commutator identity

  K_down-K_up=sum_(j=2)^3 [E_1j,E_j1]
              =2E_11-E_22-E_33=3t-(a+2b)

then gives the branch's upward conductance per basis vector as

  gamma_(u,v)=1/2 [c_3-t^2-c_2(u,v)-3t+(a+2b)].        (7)

The sum of (7) times branch dimensions over x=0,...,t, y=t-x simplifies
exactly to (1). For clarity, the summand is

  (a+t-2x+1) * [a+2b+(b-2)t-t^2+(a+t+1)x-x^2],

and summing this quadratic-times-linear expression gives, with
A=a+t+1 and K=a+2b+(b-2)t-t^2,

  sum_(x=0)^t (A-2x)(K+Ax-x^2)
    =(t+1)[K(a+1)+A*t*(a-t)/2+t^2*(t+1)/2]
    =(a+1)(t+1)(t+2)(a+2b-2t)/2=w_t.

All conductances used by the filter have t<M<=min(a,b), so this formula
applies throughout the taper.

3. Taper, rank, and exact energy

For Q>=1, define R by the integer threshold V_R>=Q in (5). Because alpha_t
strictly decreases from 1 to 0 on R<=t<=M, X=I-A has value zero exactly on
layers t<=R and is strictly positive on every layer t>R. Hence its nullity
and rank are exactly those in (3), including all integer overshoot in V_R.
This also proves X>=0.

Write rho for (2). The profile satisfies

  alpha_t-alpha_(t+1)=1/(w_t rho),  R<=t<M.

All other layer differences vanish. Using the exact conductance (6),

  E(X)=E(A)=sum_(t=R)^(M-1) w_t/(w_t rho)^2=1/rho.

This is the unique energy-minimizing profile on the weighted path of layers
with alpha_R=1 and alpha_M=0, by Cauchy-Schwarz. No values of w_t beyond
t=M-1 are needed because X is constant on all later layers.

4. Uniform bounds and endpoint checks

For N<=a,b<=2N, dimension satisfies D>=N^3. For N>=16,

  V_(M-1)/D = M(M+1)/[(b+1)(a+b+2)] <= 1/4,

using M<=N/2, M+1<=N, b+1>=N, and a+b+2>=2N. Since X=1 on t>=M,

  ||X||_HS^2 >= D-V_(M-1) >= 3D/4.                    (8)

The stated Q range ensures the taper endpoints are separated. If R>=1,
minimality and (5) give

  R(R+1) < 2Q/(a+1)
           <= (b+1)(a+b+2)/512
           <= 18N^2/512=9N^2/256.

Hence R<3N/16 and R+1<3N/16+1<=N/4 for N>=16. For R=0 the same final
bound is immediate. Also M+1>=N/2, so M+1>=2(R+1) and R<M. This verifies
the resistance sum is nonempty and every w_t in it is positive.

For 0<=t<M, the bounds N<=a,b<=2N imply

  N^2(t+1)(t+2) <= w_t <= 9N^2(t+1)(t+2).

The upper bound yields

  rho >= (1/(9N^2)) sum_(t=R)^(M-1) 1/[(t+1)(t+2)]
       = (1/(9N^2))[1/(R+1)-1/(M+1)]
       >= 1/[18N^2(R+1)],

where M+1>=2(R+1) was just proved. Thus E(X)<=18N^2(R+1).

For R>=1, V_(R-1)<Q gives

  R(R+1)<2Q/(a+1),

and the estimate R+1<=1+sqrt(2Q/N) also holds for R=0. Combining this with
(8),

  E(X)/||X||_HS^2 <= 24N^2/D * (1+sqrt(2Q/N)).

Finally D>=N^3 gives (4). This proves a uniform finite-N upper over all
integers Q in the stated interval. For N>=16 this interval is nonempty
because D>512.

EXACT-CHECKER SCOPE

filter_construction_check.py uses integer and Fraction arithmetic to check
the GT branch dimension sum, the Casimir-derived crossing weights against
(1), and the taper's exact energy/rank/norm identities in several admissible
finite examples. It is a finite algebra checker, not a substitute for the
uniform derivation above.

C03_L05 INITIAL CHECKPOINT — COSTED LOW-RANK / BOUNDED-TREEWIDTH PARITY
7 October 2026

Status: internal theorem candidate, not externally reviewed. The algebraic
reduction below is proved on paper. A standard connectivity dynamic program
then gives the stated fixed-parameter exact algorithm, but that general DP
has not yet been implemented. Finite exact checks corroborate the Schur and
alternating-cycle identities. This is a tractable structural subclass, not a
general determinant-weighted parity algorithm or a field-breaking claim.

Strongest claim
--------------

Given explicit Gaussian-rational matrices S in Q(i)^(n x n) and
U,V in Q(i)^(n x r) with F=S+UV^T, let H(S) have 2n vertices
L_1,...,L_n,R_1,...,R_n, support edges L_i R_j for S_ij != 0, and the
site-conflict matching edges L_i R_i for every i. If a width-t tree
decomposition of H(S) is supplied, then every coefficient

  c_k(F) = sum_{I,J subseteq [n], |I|=|J|=k, I intersect J = empty}
          |det F[I,J]|^2

can be computed exactly in

  2^{O((t+2r) log(t+2r))} poly(n,r,L,L_T)

bit operations, where L is the total bit length of F,S,U,V and L_T is the
decomposition encoding length. Here the polynomial's degree is independent
of t,r. If t,r are fixed constants, this is polynomial time. A supplied
decomposition is an exact certificate: support, F=S+UV^T, and the
decomposition axioms are checked by exact rational-complex arithmetic. For
fixed t, treewidth itself can instead be recognized exactly by Bodlaender's
algorithm. No claim is made that S,U,V can be discovered efficiently from F
alone.

The update UV^T may be dense and complex. Its rank, rather than its number of
nonzeros, is charged through 2r apex vertices. The width parameter must be
that of the sparse support graph PLUS the row/column site-conflict matching;
bounding only the support graph's width is insufficient for this argument.

Derivation
----------

1. For every pair I,J of physical site sets with |I|=|J|=k, form the square
   augmented submatrix on row set I plus r auxiliary rows and column set J
   plus r auxiliary columns:

       M = [ S   U ]
           [-V^T I_r].

   With the selected physical indices ordered first, Schur complementation
   gives

       det M[I union A, J union A]
          = det(S[I,J] + U_I V_J^T)
          = det F[I,J].

   This identity holds even when S[I,J] is singular, because the pivoted
   block is I_r. Consequently c_k(F) is a sum of squared determinants of
   these augmented minors, over I,J disjoint.

2. Expand each determinant as a signed sum over perfect matchings from its
   selected row vertices to its selected column vertices. In the square,
   pair a red matching M with a blue matching M'. They cover exactly the same
   selected vertices. A red edge has weight M_ab; a blue edge has weight
   conjugate(M_ab). If the selected minor has q=k+r rows, the union of the
   two colored matchings is a disjoint union of alternating cycles. If it has
   c cycles, then

       sign(M) sign(M') = (-1)^(q-c).

   This follows by identifying both matchings with permutations: their
   quotient permutation has c cycles and sign (-1)^(q-c). Thus an exact
   partition dynamic program only needs to multiply by -1 whenever a cycle
   closes, then multiply the final coefficient for k by (-1)^(k+r).

3. The graph for this loop partition has sparse edges L_i R_j for S_ij,
   conflict edges L_i R_i forbidding both twins from being selected, and
   2r auxiliary vertices. Each auxiliary column has edges from rows i with
   weight U_i,l; each auxiliary row has edges to columns j with weight
   -V_j,l; the auxiliary block has its r identity edges. Put all 2r
   auxiliary vertices into every bag of a tree decomposition of H(S).
   Every new edge is then covered and the width rises by at most 2r, to
   w=t+2r.

4. A standard nice-tree-decomposition DP tracks, for each bag vertex, its
   selected/inactive status and its red/blue degree (each at most one), plus
   the connectivity partition of the partial red/blue union. At an ordinary
   support edge, it either skips the edge or chooses it in one color when
   both endpoints are active and have unused degree in that color. At each
   conflict edge, it rejects the state in which both endpoints are active.
   Auxiliary vertices are forced active. When a physical vertex is
   forgotten, an active one must have red and blue degree exactly one, and an
   inactive one degree zero. When a component closes, its cycle factor -1 is
   applied. The DP records the number k of selected physical left vertices.
   At the root all selected vertices are saturated, so the colored edge sets
   are exactly pairs of perfect matchings of one common selected set.

   The degree data has a constant number of possibilities per bag vertex;
   connectivity partitions contribute at most Bell(w+1)=2^{O(w log w)}
   states. Tracking k adds a factor at most n+1. Each transition uses exact
   rational-complex additions and multiplications.

5. Bit cost is finite and polynomial per state. Each partial term uses at
   most 2(n+r) matrix entries, each with input bit length at most L. The
   number of matching pairs on at most n+r vertices has logarithm
   O((n+r) log(n+r)); hence exact partial sums can be stored with
   O((n+r)(L+log(n+r))) bits after a common-denominator representation.
   The Schur identity uses no division by a possibly small determinant or
   coefficient. Exact zeros and cancellation are resolved exactly. Matrix
   equality F=S+UV^T is verified in O(n^2 r) field operations, with
   polynomial bit growth. A tree-decomposition certificate is checked in
   time polynomial in its encoding size.

Recognition boundary
--------------------

This is an exact certificate-recognizable class. The input includes S,U,V
and a width-t decomposition; the verifier checks them and the arithmetic
identity exactly. If only a sparse support pattern E is supplied, setting
S=F on E and demanding rank(F-S)<=r is a different, narrower class that can
be recognized by exact Gaussian elimination after E is fixed. Discovering an
arbitrary sparse-plus-low-rank decomposition from F is NOT part of the
result. For fixed t, exact treewidth recognition of H(S) is available by
Bodlaender's constant-k algorithm; the original theorem states that it
decides tw(H)<=t and finds a decomposition when the answer is yes.

Consequences:

* If S=0, H(S) is just a matching, so tw(H)=1. Every rank-r F has all c_k
  exactly computable in 2^{O(r log r)} poly(n,L) time through the same
  representation, even when F is dense. (Also c_k=0 for k>r.)
* If S is sparse and H(S) has bounded treewidth, any supplied rank-r dense
  correction costs only an additive 2r in width. This gives an exact
  fixed-parameter algorithm in t+r for a structurally different class that
  includes nonbipartite sparse bases and dense low-rank corrections.
* If H(S) is planar and r is fixed, its O(sqrt(n)) treewidth gives a generic
  exact 2^{O(sqrt(n) log n)} poly(L) upper bound. This is subexponential,
  not polynomial.

Planar/Pfaffian route and exact local obstruction
-------------------------------------------------

The ordinary planar perfect-matching Pfaffian method does not directly apply
to the signed double-matching expansion, because the two copies must select
the same row and column vertices while a physical site forbids selecting
both its row and column twins. The local four-port signature for (red-row,
blue-row, red-column, blue-column) is

  g_0000 = 1,   g_1100 = 1,   g_0011 = 1,
  all other g_x = 0.

It says: neither twin selected, or the row twin selected in both copies, or
the column twin selected in both copies. The signature has even parity, but
fails the four-port matchgate/Grassmann-Plucker identity. For one port
ordering that identity reads

  g_0000 g_1111
    = g_1100 g_0011 - g_1010 g_0101 + g_1001 g_0110.

Its left side is 0 and its right side is 1. Reordering ports can change signs
but cannot make the sole nonzero pair product vanish. Thus no planar
matchgate gadget can realize this exact local constraint. This refutes the
straightforward route that turns the whole overlay into a planar weighted
perfect-matching instance. It does NOT exclude a different nonlocal
Pfaffian transform, a different polynomial algorithm for planar inputs, or
randomized approximation.

Primary source for the matchgate identities: Cai and Gorenstein, “Matchgates
Revisited,” Theory of Computing 10(7), 2014, DOI 10.4086/toc.2014.v010a007,
https://www.theoryofcomputing.org/articles/v010a007/ . Primary source for
exact fixed-width recognition: Bodlaender, “A Linear-Time Algorithm for
Finding Tree-Decompositions of Small Treewidth,” SIAM J. Comput. 25(6),
1996, DOI 10.1137/S0097539793251219,
https://epubs.siam.org/doi/10.1137/S0097539793251219 .

Relevant prior-art and unresolved gates
---------------------------------------

The baseline's general hard norm is the positive weighted linear-matroid-
parity partition function. Deterministic polynomial-bit support/zero
recognition exists, but is not a counting oracle. The central unresolved
general gate remains a microscopic two-replica energy/sampling theorem.
Prior exact classes include bipartite pair-matrix support and monomial
permutation matrices. This checkpoint adds an exact bounded-(sparse-treewidth
+ low-rank)-rank class; it does not close the unrestricted norm FPRAS, produce
an acquired sampler, or improve the general support oracle.

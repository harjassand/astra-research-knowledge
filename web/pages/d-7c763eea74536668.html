# Exact implicit conversion of bounded target programs

Independent reconstruction, 2026-10-06. This extends the finite histogram audit in cycle3. It is our deduction, not a claim attributed to Li–Liu. The classical controlled-testing information rates are prior art; novelty of this implicit exact all-output implementation is not established.

## Interface and theorem

There are three possible fixed states. Source action k produces Bernoulli(0.1) in state k and Bernoulli(0.9) in either other state; source observations have unit cost. Let D = 0.8 log 9. A finite known target menu has rational, strictly positive laws G_i^b on finite alphabets and deterministic costs beta_b > 0. Every target observation is a fresh draw conditional on the chosen action and state.

A supplied controller makes at most m >= 1 target observations. Its actions, original private-coin laws, stopping, and report depend causally on its earlier observations and private outcomes. Its code does not inspect the hidden state, the proposal-state parameter, the internals of the observation callback, or the callback's artificial sampling coins. Bound its bit computation, number of atomic rational-coin calls, rational operand bit lengths, and output length. Exact rational sampling may use an unbounded number of fair bits with polynomial expected cost. There is no assumed hard bound on this raw fair-bit count.

Define g_ij^b = KL(G_i^b || G_j^b) and

    gamma_i = max_b max_{j != i} g_ij^b / (D beta_b).

There is an exact source-only simulator of the controller's terminal report, simultaneously in every state, with

    E_i N <= gamma_i E_i C_G + K sqrt(m).

K depends on the fixed known target catalogue, including beta and probability values, and not on the controller or m. The simulator has polynomial expected bit computation in m, target-model bit size, and the supplied controller bounds. This is a hard-horizon overhead, not a proved O(sqrt(E_i T)) efficient-program theorem. The coefficient is sharp over bounded programs: repeating any one action b gives the usual KL lower bound for each rival j.

## Augmentation removes terminal probability evaluation

Retain a transcript h containing all target actions and observations, original controller private-coin outcomes, stopping, and terminal report. Record the outcomes of atomic original rational coins, rather than every fair bit used by their sampling backend. Bounded atomic calls and finite alphabets give a finite augmented support. Crucially, discard the artificial coins used by a proposal backend to sample channel observations. Keeping those coins can destroy common support: the same backend bits and observation can be compatible with one candidate state and incompatible with another.

For a given valid h the controller's private/action/report factors are common across states. Thus

    H_i(h) = C(h) product_t G_i^{b_t}(x_t),
    H_i(h)/H_k(h) = product_t G_i^{b_t}(x_t)/G_k^{b_t}(x_t).

C(h) need not be evaluated. To sample H_k, execute the controller with a fake-observe callback sampling G_k^b at each requested action b. The secret parameter k belongs only to that backend. All targets have common augmented support by strict positivity. Projection of an exact augmented transcript gives the exact terminal report, even when computing its marginal probability would require counting exponentially many paths. A polynomial-time Boolean reporting function, including a smoothed counting fixture, introduces no terminal-marginal oracle.

Let R0 = max(1, max_{b,x,i,j} G_i^b(x)/G_j^b(x)) and R = R0^m. All augmented density ratios are at most R. Products of m rational ratios have O(mB) bit lengths when channel probability bit lengths are at most B.

## Primary proposal and verification

Set eta = 1/(30m). Sample each source action r0 times, and choose the action with the fewest ones, uniformly over ties. Its confusion matrix is A0 = (1-3b0)I+b0 J. Choose r0 so that total error 2b0 <= eta. The exact finite classifier probability is computable by the integer binomial sum in the cycle3 proof; b(r) <= (9/25)^r ensures r0 = O(log m).

Given candidate k, generate h from H_k. Put L = min{l:9^l >= 1/eta} and

    B(k,h) = min{b >= 0:9^b >= max(1,max_{j != k} H_k(h)/H_j(h))/eta}.

Use source action k repeatedly. Increase a scalar walk by one for observation zero and decrease it by one for observation one; accept at +B and reject at -L. Under state k the upward probability is 0.9; in each other state it is 0.1. Therefore both reverse likelihood scores coincide, so there is no union factor in the own rejection probability. The exact acceptance probabilities are

    s(B) = (9^(B+L)-9^B)/(9^(B+L)-1),
    t(B) = (9^L-1)/(9^(B+L)-1) = 9^(-B) s(B).

Hence s >= 1-eta, and for i != k, t <= eta H_i/H_k. The expected source walk length is at most B/0.8 in the correct state and L/0.8 in a wrong state (bounded walk, optional stopping, and the signed drift).

Thin accepted proposals by a = (1-eta)/(1+2eta). Write

    Q_i(h) = a sum_k A0(i,k) H_k(h) p_i(k,h),
    T_i(h) = H_i(h)-Q_i(h),

where p_i is s for i=k and t otherwise. Cross-acceptance and correct acceptance give

    eta H_i <= T_i <= 5 eta H_i.

Indeed Q_i <= (1-eta)H_i, while Q_i >= (1-eta)^3 H_i/(1+2eta); the latter residual ratio is (5eta-3eta^2+eta^3)/(1+2eta) <= 5eta. All quantities divided by H_k are evaluable through channel density ratios and the scalar gambler probabilities.

The residual masses delta_i = sum_h T_i(h) need not coincide. No symmetry, residual-mass evaluation, or individually normalized inverse row is used below.

## Joint repair without delta evaluation

Choose a balanced classifier of size rR with off-diagonal probability bR <= 1/(18R), using the explicit sufficient inequality 18R(9/25)^rR <= 1. Its confusion matrix is AR = lambda I+bR J, lambda=1-3bR >= 5/6. Its inverse is (I-bR J)/lambda. Define

    W_i(h) = [T_i(h)-bR sum_j T_j(h)]/lambda.

Since sum_j T_j <= 15eta R H_i, we have W_i >= 0; also W_i <= 6eta H_i. These statements hold pointwise; the row masses of W generally differ.

When primary output is not accepted, repeat the following complete trial:

1. Obtain a fresh source classifier K with matrix AR.
2. Run the controller proposal to sample h from H_K.
3. Accept h with probability W_K(h)/(6eta H_K(h)); otherwise restart the entire trial, including its classifier.

In true state i, the accepted submeasure in one trial is

    sum_k AR(i,k) H_k(h) W_k(h)/(6eta H_k(h))
      = T_i(h)/(6eta).

The success probability is delta_i/(6eta) >= 1/6. The eventual conditional law is T_i/delta_i, so the full output measure is exactly Q_i+T_i=H_i. Conditional expected trials are at most six. Unconditional expected physical repair observations are

    delta_i * [6eta/delta_i] * 3rR = 18eta rR.

Fresh classification on EVERY retry is load-bearing. Holding one classifier fixed and separately normalizing W_K would fail when its row masses differ. Expected computation until success is the expected cost of one trial divided by its success probability, even if trial cost and acceptance correlate; only independence of fresh trials is needed.

## Physical cost and weighted target costs

The initial classifier costs 3r0. Wrong-candidate verifier cost is at most eta L/0.8. Correct-candidate verifier cost is bounded by E_{H_i}B(i,h)/0.8 (its classifier probability is at most one). For full augmented records, log(H_i/H_j) is exactly the target log likelihood sum, not a marginal conditional expectation. Under true state i,

    S_ij(T) = sum_{t<=T} g_ij^{b_t} + M_ij(T),
    sum_{t<=T} g_ij^{b_t} <= gamma_i D sum_{t<=T} beta_{b_t}.

For the fixed finite catalogue the stopped martingale has E|M_ij(T)| <= K0 sqrt(m), because T <= m and the log ratios are bounded. Thus

    E max_j [S_ij(T)]_+ <= gamma_i D E C_G + 2K0 sqrt(m).

Since B <= L+1+max_j[S_ij]_+/log 9, dividing by 0.8 yields the claimed coefficient gamma_i. The remaining terms are O(log m)+18eta rR; rR=O(m log R0+log 18), so for a fixed catalogue they are absorbed in K sqrt(m). This also covers m=1 by increasing K. For m=0 no state information is used and the supplied controller is simulated directly without source observations.

For sharpness, every source action gives at most D KL per observation for any pair, while action i attains D simultaneously against both rivals. An exact converter of n repeats of target action b must satisfy D E_i N >= n g_ij^b by stopped-record KL and data processing. Dividing by target cost n beta_b gives gamma_i after maximizing b,j.

## Bit computation and limits

Thresholds can be found by exact integer comparisons and binary search; no exact transcendental logarithm computation is needed. Powers in s,t have O(mB+log m) bits. The classifier's exact binomial sum uses polynomially many integer operations on O(rR) bit integers; rR=O(mB). Matrix inversion is explicit in dimension three. Q/H, T/H, and W/H use a constant number of such fractions and ratios, so have polynomial bit size. Known finite categorical channels and original rational coins can be sampled exactly in polynomial expected bit cost. Each proposal executes the bounded controller; the source walk has polynomial expected length; the joint repair uses at most six expected trials. These establish expected bit complexity, not a worst-case fair-bit bound.

The result requires supplied laws and a legally instrumentable controller. It does not acquire unknown channel laws, compile inaccessible code, or cover actions that modify a persistent physical hidden state. Abstract polynomial step counts without bounded rational/integer operand lengths are insufficient. A controller allowed to inspect the fake backend's state parameter or sampling seed would violate the common-kernel hypothesis.

Exact irreducible SU(2) obstruction

Let V_{j,K,L}: H_j -> H_K tensor H_L be the unique Clebsch–Gordan isometry
when K=j+L, so the input spin j is the minimum-spin summand of K tensor L.
Write Phi_{j,K} for its output channel to H_K and Phi-hat_{j,L} for its
complement to H_L. The complement is exactly the spin-coherent
measure/prepare channel

  Phi-hat_{j,L}(rho)
    = (2j+1) integral_{S^2} <n;j|rho|n;j>
                        |-n;L><-n;L| dmu(n),

where dmu is normalized sphere measure. For input |j,j>, the probability of
environment magnetic number m is, from the Clebsch–Gordan coefficient,

  p_m = (2j+1)(2L)!(2j+L-m)!
        / ((L-m)!(2j+2L+1)!),   -L <= m <= L.

The coherent measure/prepare expression gives the same probabilities by the
beta integral

  (2j+1) binom(2L,L+m) integral_0^1
       x^(2j+L-m) (1-x)^(L+m) dx.

Both maps are SU(2)-covariant and agree on the orbit of |j,j><j,j|. That
orbit spans B(H_j) (spin coherent projectors are informationally complete),
so the two maps are equal on every input. Thus the complement is
entanglement-breaking. Shor's 2002 theorem and equality of channel/complement
output spectra on pure inputs imply

  S_min(Phi_{j,K} tensor Psi)
    = S_min(Phi_{j,K}) + S_min(Psi)

for every finite-dimensional channel Psi; induction gives the same for all
tensor powers. This is a strong-additivity obstruction on one boundary
family of irreducible SU(2)-covariant channels, not a counterexample.

When j=1/2, every pure input is a coherent state, so the global single-channel
minimum is explicitly certified by the same formula. Writing L=K-1/2,

  p_m = (L-m+1)/((L+1)(2L+1)),
  S_min(Phi_{1/2,K}) = -sum_m p_m log p_m.

The proof is analytic; `evidence/spin_complement_exact.py` checks the CG
factorial identity and normalization for a finite grid only. EPOSIC papers
already compute complementary channels and classify some entanglement-
breaking cases, so priority/novelty of this boundary result is UNKNOWN.

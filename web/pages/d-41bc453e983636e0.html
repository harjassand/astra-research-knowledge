# Guarded whole-proof compiler: frozen interface

7 October 2026; root-verified GPT-6.1 Sol / max handle; no nested workers.
This extends the sealed whole affine installer with the independently proved
four-state profile. It is acquired tool support, not a new lower-bound or
historical-priority claim. September author slides are retained as matching
prior for the affine line-sensitive core.

The source format is `canonical-LLW-guarded-Frege-v1`, with the exact old 23
canonical axiom schemata, MP, adjunction with unit and closed necessitation.
One additional schema `guard_contract` has operands A,B and endpoint
`(A->(A->B))->(A->B)`. Its substitution domain must be exactly A,B. There is no
uniform substitution rule on already proved theorems. Syntax is a canonical
acyclic constructor DAG, with ordinary tree terms as its interpretation.

Fresh acyclic definitions use the old standard interface: globally distinct
names, no earlier occurrence in an actual line/operand or in their own body,
only earlier definition dependencies, the exact defining equivalence as
endpoint, and no extension name in the rigid final formula. Every definition
is globally unfolded before guard admission, and replaced by its explicit
seven-line ordinary affine derivation. Structural parsing alone is an internal
pre-admission pass. Every public compile/validate entry checks the expanded
guards; no accepted target can be emitted from raw displayed-name flags.

The deterministic flags tt,tf,st,sf are the complete fixed syntax table in
`guarded_profile.py`, corresponding to actual endpoints `=>T`, `T=>bottom`,
`=>S`, `S=>bottom`. Their absence does not assert semantic nonprovability.
Admit a contraction exactly when tt(A) or sf(B) after expansion. Choose tt
first if both hold. Acquire all state proofs topologically, with no named
initial sequents. Cache their exact endpoints once per ordinary source node;
each acquired state step must agree with the deterministic table.

The target format is `ordinary-LJ-bang-guarded-Chu-certificate-v1`. It is
ordinary LJ_! with cut, intuitionistic weakening and explicitly enabled ordinary
left contraction `C`. Each C row deletes exactly one of at least two principal
occurrences and retains one. State and Pair prefixes contain no C. The tt
contraction macro uses zero C; the sf macro uses exactly one. Native bang
contraction remains a separate rule. No target witnesses are assumed freely.

Output preserves original and actual expanded source, all definition maps,
post-unfold guard decisions, raw displayed flags for comparison, each cached
Pair/state endpoint and proof range, all installed old/guard rule endpoints,
every primitive target row, the true final Chu goal, and exact occurrence/DAG/
unfolded-tree-byte charges. Schema slots and aliases never become equations
between otherwise independent target atoms.

The fixed new fixture has two operational contractions feeding MP chains and
a fixed small final formula. A positive compound alias has a raw false guard
but an expanded tt guard; a separate compound codomain passes sf and forces
one target C. A fresh alias of linear0 must be rejected despite its raw atom
sf flag. The control is the exact same ordinary expanded proof skeleton,
operands, final formula and supplied information. No proof-search or speed
benefit is inferred from this comparison.

The supplied local theorem/template prerequisites are those of cycle15
`logic_prior14` and `logic_gate14`. Uniform 2-potency proposed in cycle16 is
outside this format until separately proved, gated and assigned. General
conservative target repair, a sequent compiler, hard-family source proof search
and full classical Frege/EF remain outside this tool's implementation.

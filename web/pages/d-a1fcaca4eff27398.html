# Stochastic safety versus deterministic permanence: final report

## Verdict

A decisive obstruction is independently reconstructed: a deterministic global attractor on a positive stoichiometric class does not imply stationary tightness uniformly across all stochastic communicating classes inside that class. This is a scope correction, not a new permanence theorem or a claim of historical novelty.

For the network
\[
2C\to A+B+C\to3A+2B\to2C,\qquad 2C\rightleftarrows2C+D,
\]
the deterministic mass-action system is complex balanced at \((1,1,1,1)\) in the positive class \(B+C=2\). By the established global-attractor theorem, all positive ODE trajectories in that class converge to this equilibrium. For each \(n\ge0\), the falling-factorial CTMC has a distinct closed irreducible class
\[
\Gamma_n=\{(n,0,2,d),(n+1,1,1,d),(n+3,2,0,d):d\ge0\}.
\]
Direct transition enumeration and exact stationary flux balance give positive recurrence and a stationary law supported on \(A\ge n\). Thus, for every compact K, all sufficiently large n have \(\pi_n(K)=0\). The same obstruction holds for the standard density-dependent process at each fixed volume V, with count class \(B+C=2\), concentration class \(b+c=2/V\), deterministic equilibrium \((1,1/V,1/V,1)\), and stationary support \(A/V\ge n/V\).

The result is consistent with the Astra P finite-horizon exit theorem. That theorem assumes an already acquired compact inward-collar certificate and only controls exit by finite T. It supplies neither stochastic permanence nor uniform stationary control over every stochastic subclass.

Anderson–Craciun–Kurtz, arXiv:0803.3042, Theorems 4.1/4.3, gives the product-Poisson stationary antecedent and density-dependent scaling. Our local balance computation is direct.

## Experimental discriminator

For each n, prepare the positive count seed \((n+1,1,1,1)\), enforce and measure \(B+C=2\), calibrate all five propensities, and sample \(A,B,C,D\) at single-molecule resolution over replicated long trajectories. The model predicts A is never below n in its stationary class, the phase weights are explicit, and D is Poisson(1) at V=1 (Poisson(V) under standard volume scaling). A reproducible stationary sample with A<n, or phase fluxes incompatible with the calibrated generator, falsifies the physical realization. The deterministic ODE with the same diagram, rate constants, and positive initial conditions is the comparator; it converges to the common class equilibrium.

The experiment has substantial feasibility costs: the return phase rate scales as \(2n^3+O(n^2)\), and stationary burn-in and exact high-order chemistry were not measured. The proposed falsifier tests the idealized CTMC model, not the external global-attractor theorem.

## Next gate

The unresolved mathematical bridge is an additional stochastic condition—such as a uniform Foster–Lyapunov drift or a restriction on the closed communicating-class decomposition—that rules out escaping stationary laws while retaining deterministic classwise attraction. The current obstruction shows the need for that condition; it does not identify a sufficient one.

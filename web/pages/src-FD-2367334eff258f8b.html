# Independent review of replacing the collar reset by local Pauli twirling

14 October 2026. This uses the standard Pauli unitary-one-design identity;
no novelty is claimed for twirling itself. Exact finite identities are checked
in `independent_echo_audit.py` and recorded in `INDEPENDENT_ECHO_AUDIT.json`.

## Correct theorem and filtration

Let S contain ell qubits, d=2^ell. Before trial j, condition on the complete
past record F_(j-1), including earlier Pauli choices and label outcomes. Allow
the current joint state rho_SE to be arbitrary and entangled. Draw P uniformly
and independently from the d^2 tensor products of I,X,Y,Z, apply P to S, and
run the fixed comparison/readout sequence. The known twirling identity is

    (1/d^2) sum_P (P tensor I) rho_SE (P^dagger tensor I)
       = I_S/d tensor Tr_S(rho_SE).                     (1)

One proof expands the S part in the orthogonal Pauli basis. Conjugation by a
uniform independent Pauli fixes its identity coefficient and cancels every
nonidentity coefficient. The surviving coefficient is exactly Tr_S(rho_SE).
This works for arbitrary joint states and arbitrary outside dimension.

The quantum outcome probability is linear in the input state. Averaging the
current Pauli choice before conditioning on the current outcome therefore
reduces it to the product-reset probability. The extremal-eigenvector theorem
in the companion note supplies

    Pr(Y_j=1 | F_(j-1)) >= c(t)||R||^2

in the ideal protocol. A justified state-uniform conditional error gamma
subtracts at most gamma. Thus the same fixed-n binomial domination and norm
certificate apply to the pooled failure count. The post-trial state and next
trial state can depend arbitrarily on all earlier Pauli choices and outcomes.

The label still needs the prescribed preparation. The comparison Hamiltonians,
comparison unitary, scalar reference and time must be fixed for this validation
record, independently of the current Pauli draw. The statement does not cover
a within-trial outside controller that sees the current Pauli and changes the
comparison/evolution in response. Earlier history dependence is permitted.

## What must not be conditioned on

Each individual Pauli is unitary and does not destroy entanglement. The state
conditioned on the current P need not factor and need not obey the product-reset
failure floor. It is valid to record P and use it in the later history. The
current outcome must enter the pooled count before any selection by current P.
The proof uses F_j generated by the complete current pair (P_j,Y_j), with
the conditional lower bound for Y_j evaluated against F_(j-1).

An exact counterexample to current-P-conditioned inference is a single collar
qubit initially in |1>, H=0 and a rank-one residual on |0>. Choose an echo
diag(3/5-4i/5,1). For current P in the order I,X,Z,Y, the failure probabilities
are respectively

    0, 1/5, 0, 1/5.

The pooled probability is 1/10, exactly the maximally mixed reset result.
Selecting only I and Z produces zero failures for a nonzero residual, so the
pooled uniform lower bound cannot be applied to those selected counts. The
example is realized by a positive rank-one residual with a phase in (0,pi/2),
which lies within the companion theorem's positive time range.

## Exact correlated example

For the two-qubit pure entangled state

    |psi> = (3|00>+4|11>)/5,

the outside marginal is diag(9/25,16/25). Twirling only the first qubit gives
exactly the diagonal joint state

    diag(9/50,8/25,9/50,8/25)
      = I/2 tensor diag(9/25,16/25).

The script verifies this as a Fraction identity, and verifies that every
current-P-conditioned state remains pure and differs from the product average.
Because local unitary operations preserve the nonzero Schmidt coefficients
3/5 and 4/5, each such conditional state remains entangled. This finite example
illustrates (1); the Pauli expansion proves it universally.

## Physical and resource scope

The twirl consumes 2ell fresh classical bits per trial plus the chosen local
Pauli gates. It replaces the ideal collar replacement channel in the pooled
mathematical probability calculation. It does not eliminate label preparation,
controlled comparison gates, finite timing, readout, calibration or model costs.
Finite-duration Pauli gates may interact with the outside; their deviation from
the ideal random-gate channel must be included in the state-uniform gamma.
Average gate fidelity alone is insufficient. Nonuniform or reused randomness,
postselection by current P, and uncharged P-dependent evolution are not covered.
Allowed Pauli gates must preserve the intended physical sector; a genuine
spin-register tensor factor may permit this, whereas an arbitrary constrained
fermionic sector need not.

The physical relaxation is useful but conditional: no device-level bound on
gamma, gate duration or error has been provided by this review. Combining it
with the improved bound does not establish a hardware capability, novelty, or
a matched practical advantage.

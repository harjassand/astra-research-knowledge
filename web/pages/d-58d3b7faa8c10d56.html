1. EXACT PAULI COVARIANCE OF THE ENCODED TRANSFER

Use P(x,z)=X(x)Z(z), with binary strings and all additions below over F_2.
For CSS codewords |[u]>=|A|^{-1/2} sum_{a in A}|u+a>, the ideal encoded
transfer branch obeys

 <y_X| U_CNOT |psi>_A |[0]>_B = kappa 1[y in A^perp] Z(y)|psi>_B,
 kappa=2^{-n/2}|A|^{1/2}.

This follows on each |[u]> from <y_X|[u]>=kappa(-1)^{y.u}1[y in A^perp]
and Z(y)|[u]>=(-1)^{y.u}|[u]>. It is a single scalar kappa, independent of
u, hence independent of an arbitrary superposition or reference-entangled
logical input. The retained outcome register is a uniform logical-independent
superposition after the bitwise correction; it does not retain logical
information.

Before the transversal CNOT put P(a,b) on the source and P(c,d) on the target.
Direct Clifford propagation, with no data-dependent phase introduced by this
ordering, gives

 source: P(a,b+d),       target: P(a+c,d).

Write q=b+d. For an observed X outcome x,

 <x_X|X(a)Z(q)=(-1)^(a.x)<(x+q)_X|.

Thus x0=x+q is the underlying ideal outcome. If the classical record has an
additional bit-flip vector D, feedforward uses Z(x+D). The target branch is

 Z(x+D) X(a+c) Z(d) Z(x0)|psi>
   = phase(a,c,x,D) X(a+c) Z(b+D)|psi>,

where the phase includes (-1)^(a.x) from the measured source and the scalar
from commuting Z(x+D) past X(a+c). With this P=XZ convention, their product is
(-1)^(a.x+(x+D).(a+c))=(-1)^(x.c+D.(a+c)). It depends only on Pauli/error
and record branch labels, never on |psi>. The Z(d) target-resource error cancels exactly;
the source's b remains as the output byproduct, and each readout flip D_i adds
only target Z_i. The relation holds for arbitrary binary a,b,c,d,D, including
branches whose ideal outcome is forbidden: those branches vanish for every
logical input. It therefore holds by linearity for coherent fault expansions.

This proves the v3 Eq. (1) covariance without assuming stochastic paths,
independent baths, or a correctable Pauli. For arbitrary local faults, a
bounded-size system-support operator expands in data Paulis and controller
matrix units. On a definite retained record, each matrix unit either kills the
term or changes a definite set of bits; ideal Boolean control blocks carry
these basis transitions through bounded fanout cones. Coefficients on the
common bath stay in chronological order and are never factored or norm-summed.
Hence every fully expanded term has a definite output data Pauli, output record
and ordered bath coefficient; the displayed covariance gives the same identity
logical map on each surviving term, with branch phases absorbed into its
coefficient. This needs local bounded-fanout readout-to-target control and
explicitly charged measurement, record, feedforward, reset, idle, and decoder
locations, as stated in v3.

2. SUPPORT BOUND AND CSS COMPONENT CONVENTION

Choose minimum-total-support physical representatives of the source and target
input Pauli classes, with supports S_A and S_B and sizes r_A,r_B. For the
transversal CNOT, each output block has Pauli support no larger than
r_A+r_B. For transfer, the final target Pauli P(a+c,b+D) has support contained
in

 S_A union S_B union supp(D),

so its physical weight, and therefore its stabilizer-reduced weight, is at most
r_A+r_B+|D|. A finite-support fault pattern changes only a bounded number of
record/control/data bits per marked location in the stipulated constant-depth,
bounded-arity/fanout circuit. Thus |D| and all other new target support are
bounded by a fixed a_transfer f_transfer. This support argument uses total
Pauli support (the union of X and Z supports); it does not incorrectly add two
separately minimized component weights while calling their sum the same
radius.

For CSS recovery, Sol v2 correctly retains r as TOTAL stabilizer-reduced Pauli
weight and pays alpha=2 alpha0 for the two component decoders. Consequently the
pair-block contraction condition must use alpha<1/2, equivalently select
alpha0<1/4. In one pair tile, CNOT spread is s=2, so with per-block input radius
rho n, fault-spread a tau n, syndrome corruption b tau n, and decoder term
c tau n,

 r_out <= alpha(2 rho+a tau)n + beta b tau n+c tau n
        = (2 alpha rho+K tau)n,
 K=alpha a+beta b+c.

The stable choice rho=K tau/(1-2 alpha) is valid when alpha<1/2. The v3 choice
alpha0<1/4 gives exactly this condition. A transfer consumes one source-target
pair tile; local D-induced Z support is part of its charged a tau term. A pair
gate is counted once in the pair tile, and every physical location belongs to
one disjoint tile per round. Under these conventions the pair-tile invariant
and the global disjoint-tile bad-mask expansion are consistent. Intertile bath
operators may remain jointly correlated; if a physical fault touches multiple
tiles, every touched location must be marked in the cylinder model.

3. LOGICAL PHASE / RECORD / RESOURCE AUDIT

No hidden logical phase survives the CNOT or transfer: Pauli propagation and
measurement/feedforward introduce only scalar commutation phases independent
of the logical vector. The phase can depend on the full branch and is correctly
retained in the ordered bath/record coefficient. This is sufficient for
good-history factorization; a common phase across different histories is not
required. The ideal final decoder acts only as the encoded logical metric.
Actual syndrome extraction, noisy local readout/feedforward and one noisy
single-shot recovery are charged; the theorem does not provide a noisy final
bare readout or bare unencoded output.

The transfer premise is a supplied/preexisting clean codeword |[0]> on the
target, or a resource whose prior encoded errors are already represented in
the same fault-path residual invariant. It is not a free encoded-state
preparation theorem. Its source is consumed and its target becomes the encoded
output. Arbitrary logical addressing inside a block, universal gate synthesis,
and protected acquisition of |[0]> remain outside the theorem. Repeated tiles
also need a counted supply of fresh/reinitialized ancillas and entropy disposal;
their preparation, reset and bath coupling must be included in the full
location model rather than treated as free resources.

4. SURVIVING A23 QUANTIFIER COUNTEREXAMPLE

The v3 operational theorem is an encoded-input / cumulative-error statement;
it must not be strengthened to a whole syndrome-subsystem identity based only
on an encoded-input recurrence. A23 v1's counterexample remains exact. In the
[[5,1,3]] code, choose one weight-1 representative R_s=IZIII for syndrome
0101; apply P=IIXII, obtaining syndrome 1001 with chosen representative
R_t=IIIZI. Then

 R_t^dagger P R_s = IZXZI,

a weight-3 logical-X class. The fault is corrected on the encoded code sector,
but on J_s|psi>=R_s Enc|psi>, its residual after syndrome t correction is
logical X. Thus the pair-CNOT/transfer audit establishes no missing phase or
support term for good histories that start encoded and keep the full cumulative
Pauli within <d/2; it does not prove I_L tensor g uniformly on arbitrary
correctable syndrome inputs. To claim that stronger interface, the recurrence
must include every incoming R_s and prove the final cumulative R_t^dagger E R_s
has zero syndrome and reduced weight <d.

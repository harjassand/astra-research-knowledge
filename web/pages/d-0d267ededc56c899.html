 A solution to a strengthened conjecture of Bukh, van Hintum and Keevash on additive bases 
 
 
 Zixiang Xu
 † † thanks:  Email: zxxu8023@qq.com. 

 Abstract 
 
    
 Motivated by the change-of-domain problem for additive bases, Bukh, van Hintum and Keevash conjectured that if  A , B ⊆ ℚ n A,B\subseteq\mathbb{Q}^{n}  and
 { 𝒆 i + 𝒆 j : 1 ≤ i ≤ j ≤ n } ⊆ A + B , \{\bm{e}_{i}+\bm{e}_{j}:1\leq i\leq j\leq n\}\subseteq A+B, 
then  | A | + | B | ≥ 2 ​ n |A|+|B|\geq 2n . They further proposed the strengthened conjecture: if
 | A | = n − t |A|=n-t , then  | B | ≥ n + ( t + 1 2 ) . |B|\geq n+\binom{t+1}{2}. 
Bukh also explicitly asked whether the same bounds hold for  A , B ⊆ ℝ n A,B\subseteq\mathbb{R}^{n}  and an arbitrary basis  S S  of  ℝ n \mathbb{R}^{n} , under the assumption  S + S ⊆ A + B S+S\subseteq A+B . 
 
    
 We prove the full strengthened statement over  ℝ n \mathbb{R}^{n} : if  S + S ⊆ A + B S+S\subseteq A+B  and  | A | ≤ n − t |A|\leq n-t  with  0 ≤ t ≤ n − 1 0\leq t\leq n-1 , then
 | B | ≥ n + ( t + 1 2 ) , |B|\geq n+\binom{t+1}{2}, 
which is sharp for every basis  S S  and every  0 ≤ t ≤ n − 1 . 0\leq t\leq n-1. 
The proof is short, using edge contractions in a graph-theoretical framework and a new coloring lemma over  𝔽 2 n \mathbb{F}_{2}^{n} . 
 
  
 
 
 1  Introduction 
 

 
 A basic topic in additive number theory and additive combinatorics is to understand how efficiently a set can be generated by sums. Classical instances include Waring’s problem  [ 4 ,  8 ]  and Goldbach-type problems  [ 5 ,  7 ,  12 ] . In finite settings, initiated by Erdős and Newman  [ 6 ] , one asks how small a set  B B  can be while still satisfying  A ⊆ B + B A\subseteq B+B , or more generally  A ⊆ k ​ B A\subseteq kB . This viewpoint has led to connections with extremal and geometric problems in additive combinatorics, including discrete Kakeya-type phenomena  [ 1 ] ; see also  [ 9 ,  11 ] . 
 
 
 
 Recently, Bukh, van Hintum and Keevash  [ 3 ] , motivated by questions of Ruzsa  [ 10 ] , studied a natural change-of-domain problem: how does the minimum size of an additive basis change when the basis is required to lie in a more restrictive domain? In the rational-versus-integer setting, they proved that every rational basis of size  n n  can be replaced by an integer basis of size at most  2 ​ n 2n , and constructed examples showing that this factor  2 2  is tight up to a lower-order error. 
 
 
 
 A key ingredient in their argument is a linear-algebraic vector model. Let  𝒆 1 , … , 𝒆 n \bm{e}_{1},\ldots,\bm{e}_{n}  be the standard basis of  ℝ n . \mathbb{R}^{n}.  In the case of  2 2 -bases, this model asks for the minimum possible value of  | A | + | B | |A|+|B| , where  A , B ⊆ ℚ n A,B\subseteq\mathbb{Q}^{n}  and 
 
 

 
 
 { 𝒆 i + 𝒆 j : 1 ≤ i ≤ j ≤ n } ⊆ A + B . \{\bm{e}_{i}+\bm{e}_{j}:1\leq i\leq j\leq n\}\subseteq A+B. 
 
 
 Bukh, van Hintum and Keevash  [ 3 ]  proved the lower bound  2 ​ n − O ⁡ ( n ) 2n-O(\sqrt{n})  for  | A | + | B | |A|+|B|  and conjectured that the sharp answer is exactly  2 ​ n 2n   [ 3 , Conjecture 13] . They further proposed the refined extension that if  | A | = n − t |A|=n-t , then one should have
 | B | ≥ n + ( t + 1 2 ) . |B|\geq n+\binom{t+1}{2}. 
On his open problem list, Bukh  [ 2 , Problem 12]  asked explicitly whether this entire conjectural picture persists over  ℝ n \mathbb{R}^{n} : if  S S  is a basis of  ℝ n \mathbb{R}^{n}  and  A , B ⊆ ℝ n A,B\subseteq\mathbb{R}^{n}  satisfy  S + S ⊆ A + B S+S\subseteq A+B , do the same bounds still hold? 
 
 
 
 Our main result answers this question affirmatively, including the refined extension. 
 
 
 
 Theorem 1.1 . 
 
 
 Let  S S  be a basis of  ℝ n \mathbb{R}^{n} , and let  A , B ⊆ ℝ n A,B\subseteq\mathbb{R}^{n} . Suppose that
 S + S ⊆ A + B . S+S\subseteq A+B. 
Let  t t  be an integer with  0 ≤ t ≤ n − 1 0\leq t\leq n-1 . If
 | A | ≤ n − t , |A|\leq n-t, 
then
 | B | ≥ n + ( t + 1 2 ) . |B|\geq n+\binom{t+1}{2}. 
 
 
 
 
 The bound is sharp for every basis  S = { 𝒔 1 , … , 𝒔 n } S=\{\bm{s}_{1},\dots,\bm{s}_{n}\}  and  0 ≤ t ≤ n − 1 0\leq t\leq n-1 . Indeed, take
 A = { 𝒔 1 , … , 𝒔 n − t } A=\{\bm{s}_{1},\dots,\bm{s}_{n-t}\} 
and 
 
 

 
 
 B = { 𝒔 1 , … , 𝒔 n } ∪ { 𝒔 i + 𝒔 j − 𝒔 1 : n − t < i ≤ j ≤ n } . B=\{\bm{s}_{1},\dots,\bm{s}_{n}\}\cup\{\bm{s}_{i}+\bm{s}_{j}-\bm{s}_{1}:n-t<i\leq j\leq n\}. 
 
 
 Then  | A | = n − t |A|=n-t  and  | B | = n + ( t + 1 2 ) |B|=n+\binom{t+1}{2} , with the displayed elements of  B B  being distinct by the linear independence of  S S . Moreover,  S + S ⊆ A + B S+S\subseteq A+B : sums involving one of  𝒔 1 , … , 𝒔 n − t \bm{s}_{1},\dots,\bm{s}_{n-t}  are immediate, while the remaining sums are represented as
 𝒔 i + 𝒔 j = 𝒔 1 + ( 𝒔 i + 𝒔 j − 𝒔 1 ) \bm{s}_{i}+\bm{s}_{j}=\bm{s}_{1}+(\bm{s}_{i}+\bm{s}_{j}-\bm{s}_{1})  for
 n − t < i ≤ j ≤ n n-t<i\leq j\leq n . 
 
 
 
 Since the standard basis of  ℚ n \mathbb{Q}^{n}  is also a basis of  ℝ n \mathbb{R}^{n} , Theorem  1.1  immediately yields the vector-model conjecture of Bukh, van Hintum and Keevash  [ 3 , Conjecture 13]  and its extension. 
 
 
 
 Corollary 1.2 . 
 
 
 Let  A , B ⊆ ℚ n A,B\subseteq\mathbb{Q}^{n} , and suppose that
 { 𝐞 i + 𝐞 j : 1 ≤ i ≤ j ≤ n } ⊆ A + B . \{\bm{e}_{i}+\bm{e}_{j}:1\leq i\leq j\leq n\}\subseteq A+B. 
If  0 ≤ t ≤ n − 1 0\leq t\leq n-1  and  | A | ≤ n − t |A|\leq n-t , then
 | B | ≥ n + ( t + 1 2 ) . |B|\geq n+\binom{t+1}{2}. 
 
 
 
 
 Combined with their reduction from the change-of-domain problem to the vector model, Corollary  1.2  shows the factor  2 2  in  [ 3 , Theorem 1]  is best possible already for  2 2 -bases: for every  n n , there exists a set of integers with a rational  2 2 -basis of size at most  n n  whose smallest integer  2 2 -basis has size exactly  2 ​ n 2n .

 If  B B  is infinite, then the conclusion is immediate. Thus we may assume that  B B  is finite.  If  n = 1 n=1 , then  t = 0 t=0 , and the inclusion  S + S ⊆ A + B S+S\subseteq A+B  implies that  B B  is nonempty. Hence  | B | ≥ 1 = n + ( t + 1 2 ) |B|\geq 1=n+\binom{t+1}{2} . We may therefore assume that  n ≥ 2 n\geq 2 .

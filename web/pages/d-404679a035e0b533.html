# Transport claims and counterexample

## Interface

Let `D` identify source or target context, `A∈{0,1}` be a well-defined perturbation assignment, `Z` be a vector of pre-assignment context descriptors, and `Y∈[0,1]` be a prespecified scalar outcome. The experimental unit is the independently randomized culture/well (or donor-level block), not an individual sequenced cell. Potential outcomes are `Y^d(a)`. The target is the mean effect

`τ_T = E_T[Y^T(1) − Y^T(0)]`.

The treatment must have the same operational meaning in both domains. For CRISPR, “assigned the guide” and “achieved the same target knockdown” are different interventions; for a compound, nominal concentration and intracellular exposure are different interventions. The estimand should name which one is randomized and measured.

## Sufficient standardization result (classical transport formula)

Suppose:

1. consistency and no interference across experimental units hold for the named treatment versions;
2. in the source, treatment is randomized conditional on `Z`, with both arms represented for every `z` having positive target probability;
3. conditional mean causal responses are invariant: `m_T(a,z)=m_S(a,z)` for `a∈{0,1}` and `P_T`-almost every `z`, where `m_d(a,z)=E_d[Y^d(a)|Z=z]`;
4. the target baseline distribution `P_T(Z)` is known or estimated.

Then

`τ_T = ∫ { E_S[Y|A=1,Z=z] − E_S[Y|A=0,Z=z] } dP_T(z)`.

Proof: by iterated expectation, `τ_T=∫{m_T(1,z)-m_T(0,z)}dP_T(z)`. Conditional response invariance substitutes the source functions. Source randomization and consistency identify each source potential-outcome mean by the corresponding observed arm mean. Positivity makes those functions observed wherever the target integral needs them. This allows measured baseline composition/state distributions to shift; it does not allow unmeasured effect modifiers, changed target response functions, treatment-version changes, or unsupported target states.

This is a sufficient, familiar transport formula in the Pearl–Bareinboim framework, not a new general identification theorem. More general transportability can hold under other selection diagrams and do-calculus derivations; the formula above is intentionally restricted to the directly testable experimental design.

## Quantitative approximate-invariance bound

Define `d_d(z)=m_d(1,z)-m_d(0,z)`. Assume `sup_z |m_T(a,z)-m_S(a,z)|≤ε` for each arm on target support, a clipped source contrast estimate satisfies `sup_z |d̂_S(z)-d_S(z)|≤ρ`, and a target state-distribution estimate `Q_T` satisfies `TV(P_T,Q_T)≤δ`, using `TV(P,Q)=sup_B|P(B)-Q(B)|`. Since `Y∈[0,1]`, `d̂_S∈[-1,1]` after clipping. Then

`|τ_T − ∫ d̂_S(z)dQ_T(z)| ≤ 2ε + ρ + 2δ`.

Proof: split the difference into (i) `∫(d_T-d_S)dP_T`, bounded by `2ε`; (ii) `∫(d_S-d̂_S)dP_T`, bounded by `ρ`; and (iii) `∫d̂_S d(P_T-Q_T)`, bounded by `2δ` for an integrand in `[-1,1]`. This bookkeeping bound is an elementary TV-duality consequence. It is not a novelty claim. Its practical value is that it prevents “good source fit” from silently replacing the missing target-mechanism error `ε`. Without target perturbation data, a mechanistic restriction, or a validated envelope on `ε`, the bound is vacuous.

## Non-identifiability theorem for unrestricted domain shift

With source randomized data and a target observational distribution, the target ATE is not identifiable over unrestricted nonparametric structural causal models, even when source and target observational distributions match exactly.

Witness. In both worlds, the source has `V~Bernoulli(1/2)`, observational `A=V`, and `Y=A`; source interventions set `A=a` and give `Y=a`, so the observed source RCT has ATE 1.

In target world I, `V~Bernoulli(1/2)`, observational `A=V`, `Y=A`; hence `P_T(A=Y=0)=P_T(A=Y=1)=1/2`, and target ATE is 1.

In target world II, `U~Bernoulli(1/2)`, observational `A=U`, `Y=U`; hence the same target observational law, but intervention `do(A=a)` leaves `Y=U`, and target ATE is 0. All source data and both target observational laws agree between worlds, while target effects differ. Therefore `τ_T` is not identified from these data.

For this diagonal target law, consistency alone yields the sharp target ATE identified set `[0,1]`: among treated units half of the population has observed `Y^1=1` while `Y^0` is missing; among untreated units half has observed `Y^0=0` while `Y^1` is missing. The two missing potential-outcome means can independently range over `[0,1]`, giving `τ_T=1/2+q_1/2-q_0/2∈[0,1]`. Thus any point estimate has worst-case absolute error at least `1/2` over this observationally indistinguishable pair. This exact witness is a small instance of standard transportability non-identification, not a novelty claim.

Important scope: if the target perturbation itself is randomized, the target intention-to-treat effect is directly identified by that experiment. The witness concerns transfer without target intervention outcomes. If guide uptake or drug exposure differs, target randomization still identifies the effect of assignment; a separate exposure/target-engagement analysis is required before reinterpreting it as the effect of a common molecular intervention.

## Failure gates

- If `Z` is post-treatment (for example, a cell state induced by the perturbation), conditioning or standardizing on it does not in general identify the total treatment effect. Use pretreatment state information or define a different estimand explicitly.
- If cells communicate inside a well, the cell is not an independent unit. Define the intervention and outcome at the culture/well/tissue unit or model interference.
- If target state lies outside source support, the integral is not identified there. Report that mass and collect data or leave transport `UNKNOWN`; do not extrapolate by silent smoothing.
- A common guide label or compound dose is not necessarily a common intervention. Verify target engagement/exposure and reagent controls, but do not condition naively on a post-treatment engagement variable if it is affected by latent cell viability or assignment.
- Even exact agreement on a finite validation panel does not prove invariance in an unseen tissue, species, in vivo environment, or future culture batch.

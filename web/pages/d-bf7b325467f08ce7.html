  tau=(log(1/p)+|C|log d)/m,
  q=(1/m)sum_{i notin C} Pr(win_i | E).

  q <= omega_co(G) + 4112 tau^(1/4).                         (T)

2. ABSTRACT WEIGHTED MASS LEMMA

Fix m modes, a finite joint question law mu, finite label sets R_i and
nonnegative label weights w_i(r), independent of the live questions.
Suppose vectors v_{i,r,x,y}, u_{i,r,x}, z_{i,r,y} in ONE Hilbert space
satisfy, for every positive marginal and every i,r,

  ||u_{i,r,x}||^2=sum_y mu(y|x)||v_{i,r,x,y}||^2,
  ||z_{i,r,y}||^2=sum_x mu(x|y)||v_{i,r,x,y}||^2.           (M1)

Suppose each mode has total mass

  sum_{r,x,y} w_i(r)mu(x,y)||v_{i,r,x,y}||^2=p>0.          (M2)

All zero marginal questions are assigned arbitrary defaults. Let

  Q(i,r,x,y)=w_i(r)mu(x,y)||v_{i,r,x,y}||^2/(mp),
  e_u=E_i sum_{r,x,y} w_i(r)mu(x,y)||v-u||^2,
  e_z=E_i sum_{r,x,y} w_i(r)mu(x,y)||v-z||^2,
  Delta_X=E_i dTV(Q_{X|i},mu_X),
  Delta_Y=E_i dTV(Q_{Y|i},mu_Y).

There are locally specified probability laws P_A(r|i,x), P_B(r|i,y)
and unit local descriptions a_{i,r,x},b_{i,r,y} such that the fresh
referee-law tuples

  J_A(i,r,x,y)=mu(x,y)P_A(r|i,x)/m,
  J_B(i,r,x,y)=mu(x,y)P_B(r|i,y)/m                        (M3)

obey

  dTV(Q,J_A)<=sqrt(e_u/p)+Delta_X,
  dTV(Q,J_B)<=sqrt(e_z/p)+Delta_Y.                        (M4)

For the ideal unit vector f=v/||v|| on Q-positive tuples,

  E_Q ||a-f||^2 <=4e_u/p,
  E_Q ||b-f||^2 <=4e_z/p,
  D:=E_Q ||a-b||^2 <=8(e_u+e_z)/p.                       (M5)

There is finite shared classical randomness which samples a common
uniform i and histories r_A,r_B with laws J_A,J_B and

  Pr(r_A!=r_B)<=2[dTV(Q,J_A)+dTV(Q,J_B)].                 (M6)

The local laws are input-dependent; (M4) is NOT a product-history bound.

3. PROOF OF THE MASS LEMMA, INCLUDING ZERO MASS

Put n_i(x)=sum_r w_i(r)||u_{i,r,x}||^2. If n_i(x)>0 set

  P_A(r|i,x)=w_i(r)||u_{i,r,x}||^2/n_i(x).

If n_i(x)=0 choose any fixed history (or adjoin one default label of
weight zero). Define P_B using z in the same way. Unit descriptions
are normalized u,z where nonzero, and one common fixed unit otherwise.
This completes the families on ALL finite inputs before fresh questions.

Define the auxiliary probability law

  J_tilde_A(i,r,x,y)=w_i(r)mu(x,y)||u_{i,r,x}||^2/(mp).

It is normalized by (M1),(M2). On the weighted grid (i,r,x,y),
with measure w_i(r)mu(x,y)/m, both ||v||^2 and ||u||^2 integrate to p.
Thus Cauchy--Schwarz and | ||v||-||u|| |<=||v-u|| yield

  dTV(Q,J_tilde_A)
  <=(1/(2p))sqrt(e_u)
      sqrt(E_i sum w_i mu (||v||+||u||)^2)
  <=sqrt(e_u/p),                                           (M7)

since the last squared integral is at most 4p. By (M1),
Q_{X|i}(x)=mu_X(x)n_i(x)/p. Consequently J_tilde_A uses the same
P_A(r|i,x) and mu(y|x) as J_A, but live X marginal Q_{X|i} instead
of mu_X. This remains true on n_i(x)=0: J_tilde_A is zero there;
the arbitrary default in J_A has exactly the missing marginal mass.
Therefore dTV(J_tilde_A,J_A)=Delta_X. Triangle inequality gives
the first (M4); the second interchanges the two sides.

For v!=0, normalization and the reverse triangle inequality give

  ||v/||v|| - u/||u|||| <=2||v-u||/||v||.

When u=0 the same bound holds for any default unit because the left
side is at most 2. On Q-positive tuples (M1) actually forces both u,z
nonzero, without a lower bound on their masses. Multiply the squared
bound by Q: the factor ||v||^2 cancels. This proves the first two
(M5); ||a-b||^2<=2||a-f||^2+2||b-f||^2 proves the last.

For (M6), use the following exact finite-family correlated sampling.
For every history label r draw one independent Exp(1) variable E_r.
For a distribution P select argmin_r E_r/P(r), interpreting P(r)=0
as infinity. This has marginal P (exponential race). For two laws P,Q
write t=dTV(P,Q). Conditional on E_r=s, simultaneous selection of r
requires E_j>=s max(P(j)/P(r),Q(j)/Q(r)). Integration gives matching
probability for r at least min(P(r),Q(r))/(1+t). Summing gives
Pr(match)>=(1-t)/(1+t), hence Pr(mismatch)<=2t.
The argument omits zero entries and ties have probability zero.

There are finitely many input-dependent laws in this application.
Push the exponential randomness forward to the finite tuple of its
selected outcomes for ALL these laws. That finite tuple is an EXACT
finite shared random variable; its real-valued probabilities need not
be rational. Thus no infinite shared resource is required. Applied
for common i, its average mismatch is at most

  2 E_{i,(x,y)~mu} dTV(P_A(.|i,x),P_B(.|i,y))
  =2 dTV(J_A,J_B) <=2[dTV(J_A,Q)+dTV(Q,J_B)].

FULL DERIVATION OF THE CORRECTED TRACE OBSTRUCTION
Use an orthonormal basis of L2(M_d,tau). Every bistochastic UCP L contracts
this Hilbert space: Kadison Schwarz followed by trace preservation gives
||L(A)||_2^2 <= tau(L(A*A))=tau(A*A). Hence ||L||<=1 and
Tr_S L*L <= d^2.

Psi is the sum of positive rank-one Hilbert-space operators
 |M_y><M_y|_tau / tau(M_y). Therefore it is positive selfadjoint. Scalar
Cauchy-Schwarz gives Psi<=I. Its superoperator trace is exactly

 Tr_S Psi=sum_y tau(M_y^2)/tau(M_y)
          =sum_y Tr(M_y^2)/Tr(M_y)
          <=sum_y Tr(M_y)=d.                              (5)

The inequality uses sum_i mu_i^2 <= (sum_i mu_i)^2 separately for each
effect, not a rank or number-of-outcomes assumption.
Since 0<=Psi<=I, Tr_S Psi^2<=Tr_S Psi. Also Re L<=I because ||L||<=1,
so Re Tr_S(L*Psi)<=Tr_S Psi. Expanding C* C gives

 Tr_S C*C
   =(Tr_S L*L+Tr_S Psi^2+2 Re Tr_S L*Psi)/4
   <=(d^2+3d)/4.

This proves (1). No commutation of L and Psi is used. Nothing assumes
Psi<=Q. In particular this is consistent with the baseline exact SOS.

For tensors of dimensions a,b, trace multiplies and

 [a(a+3)/4][b(b+3)/4] <= ab(ab+3)/4,

because the difference after removing ab/16 is
4(ab+3)-(a+3)(b+3)=3(a-1)(b-1)>=0.
Induction treats every finite tensor product. Mixtures preserve the trace
bound by linearity, and unitary conjugation preserves supertrace. Pinched
block sums satisfy sum_j d_j(d_j+3)/4 <= d(d+3)/4 for d=sum_j d_j.
Thus these operations do not rescue exact corrected representation.

FULL DERIVATION OF THE RAW CANONICAL-INSTRUMENT OBSTRUCTION
For the same Kraus family, Tr_S L=sum_y |Tr K_y|^2. Polar decomposition gives
|Tr K_y|<=Tr sqrt(M_y). Set s=Tr M_y and p_i=mu_i/s for nonzero M_y.
For d>=2,

 (sum_i sqrt(p_i))^2+sum_i p_i^2 <= d+1/d.                (7)

Here is a proof rather than an import. Define
D=d-(sum_i sqrt(p_i))^2=sum_{i<j}(sqrt(p_i)-sqrt(p_j))^2.
Also sum_i p_i^2-1/d=(1/d)sum_{i<j}(p_i-p_j)^2.
Since (sqrt(p_i)+sqrt(p_j))^2<=2(p_i+p_j)<=2,

 sum_i p_i^2-1/d <= 2D/d.

Consequently the left side of (7) is at most
 d+1/d-(1-2/d)D<=d+1/d. Multiply by s, sum outcomes using sum_y s=d,
and combine with (5) to obtain Tr_S L+Tr_S Psi <= d^2+1. This proves (4).
The universal cloner has a strict gap (d-1)/2 above this raw trace cap.
This concerns the CANONICAL prepared state M_y/Tr M_y, not every arbitrary
outcome-dependent preparation or every possible instrument.

SECOND ATTACK: THE CLONER DOES NOT REFUTE EB POWER-RANGE LIFTING
For this actual counterexample to representation, powers are depolarizing:
Phi_d^m has parameter lambda_d^m. In fact their exact distance to all
trace-preserving EB maps in the normalized infinity-to-one norm is

 dist(Phi_d^m,EB_tau)=kappa_d max(0,lambda_d^m-1/(d+1)),
 kappa_d=4 floor(d^2/4)/d^2.                              (8)

To derive it, average any EB comparator over simultaneous unitary input
and output conjugation. Averaging preserves EB, TP, and cannot increase
this norm. A covariant TP map has depolarizing parameter eta. Its normalized
Choi state is eta |Omega><Omega|+(1-eta)I/d^2. A separable Choi state has
overlap with |Omega> at most 1/d, by the product-state Cauchy-Schwarz bound,
so eta<=1/(d+1). The endpoint is EB explicitly via the Haar measure-prepare
map d integral <psi|A|psi> |psi><psi| dpsi=(A+Tr(A)I)/(d+1). Convex mixing
with the depolarizer treats all 0<=eta<=1/(d+1). Its finite-dimensional
integral can be replaced by a finite convex decomposition; no efficient
outcome compiler is claimed.

The remaining norm is ||Id-Delta||_(infinity->1,tau)=kappa_d. The norm is
convex in the input contraction, so its maximum occurs at Hermitian
unitaries with k eigenvalues +1 and d-k eigenvalues -1. Direct calculation
gives 4k(d-k)/d^2, maximizing at floor(d/2) or ceil(d/2). This proves (8).
Since lambda_d<=2/3 for every d>=2,

 sup_d dist(Phi_d^m,EB_tau) <= (2/3)^m ->0.               (9)

Growing d beyond 2^m keeps these channels non-EB at every finite m, but
non-EB membership is NOT constant distance. The actual error in (8) still
vanishes. Thus neither cloner non-EB powers nor the structural obstruction
constitutes the assigned decisive beta_m counterexample.

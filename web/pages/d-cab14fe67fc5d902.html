# Exact conversion: representation barriers and an effective explicit-matrix class

2026-10-06. Independent cycle-2 reconstruction by r05. Status: elementary reductions and construction, with exact fixture evidence; no novelty claim or unrestricted acquisition result.

## Question and legal interface

Can the exact finite-experiment converter used in `notes/team_d_experiments/RESULT.md` be implemented efficiently when its target report law is specified by a short stopping program rather than an explicit probability matrix? We distinguish (a) physical source observations, (b) computing probabilities and compiler kernels, (c) executing an implicit sampling program, and (d) acquiring unknown laws. The target/source laws below are supplied and known; none of these constructions learns them.

Team D's provisional theorem charges expected source action cost. It does not assert polynomial running time, computability for arbitrary real kernels, or a succinct effective compiler. Li–Liu v2, Appendix B.4, Lemma 8, equations (31)–(36), proves reproduction of an explicit finite common-support experiment by a classifier confusion matrix A and K=A^{-1}H. It bounds the number of physical observations using likelihood-ratio diameter. The paper does not supply a polynomial complexity guarantee for computing an arbitrary stopping policy's H. Our deductions below concern that missing effective interface, and do not refute the existence theorem.

We also read `results/root_rank/conditioning_moments.md`: its finite truncation assertion is an existence statement with dependence on singular values and metric entropy. We did not reconstruct its entire proof in this cycle and do not certify an effective truncation bound from that reading.

## 1. A binary, full-support report law already hides #P counting

Fix two hidden states and target observation laws G_0=Bernoulli(1/2), G_1=Bernoulli(3/4). These are fixed, rational, full support, and identified. Given a Boolean circuit φ on m input bits, take exactly m target observations X_1,...,X_m. Independently draw two fair bits R. Report 1 when R=00, report 0 when R=01, and report φ(X) when R is 10 or 11. This is a polynomial-size bounded-horizon target policy with only two possible reports. Its report probabilities satisfy

    h_i(1)=1/4+(1/2) P_i[φ(X)=1],    1/4 ≤ h_i(z) ≤ 3/4.

Under state 0, every input has probability 2^{-m}. Consequently

    #SAT(φ)=2^{m+1}(h_0(1)−1/4).

An algorithm extracting the exact rational h_0(1) from this succinct policy therefore solves #SAT with one call and polynomial additional work. An approximation with absolute error at most 2^{-(m+3)} also suffices: after scaling, the error is at most 1/4, so nearest-integer rounding recovers the count. The precision request has O(m) bits. This is a #P-hard exact-law extraction problem, even though the output matrix has only four entries, each bounded away from zero, and the observation model is fixed. It is not an output-size argument, an ill-conditioned matrix argument, or a rare-report example. Valiant's 1979 Section 3, Facts 1 and 2, provides the standard parsimonious counting foundation; alternatively, the verifier-circuit definition of #P gives the reduction directly.

### Important counterexample to an overstrong compiler impossibility

Fix source laws F_0=Bernoulli(1/10), F_1=Bernoulli(9/10). A one-observation state-independent garbling gives G:

    K(1|source=0)=15/32,    K(1|source=1)=25/32.

Indeed 9·15/320+25/320=1/2 and 15/320+9·25/320=3/4. Simulate each target observation by this kernel, run the original circuit, then perform the two-bit smoothing. This exact sampler uses m source observations and O(m+|φ|) elementary operations, without computing h_i. The dyadic garbling requires only five fair bits per observation.

Thus #P-hard terminal-law extraction does **not** prove that every exact sampling compiler is #P-hard. It challenges converters whose explicit construction requires H or exact residual matrices. Implicit simulators can bypass probability extraction. Whether the sharp source-cost rate of Team D can also be achieved by a uniform effective implicit compiler remains open here.

## 2. Arbitrary mathematical kernels exceed computable samplers

Assume finite rational source menus, an ordinary computable policy, independent fair private bits, and almost-sure termination with a finite output alphabet. For each fixed state i, simulate the supplied rational source distributions using fair bits. Enumerate finite halting computation cylinders, disjointly, and sum the cylinder masses for each output. This produces increasing rational lower bounds L_z on each output probability. Almost-sure termination implies Σ_z L_z tends to one. To approximate P_i[Z=z] within ε, enumerate until Σ_z L_z>1−ε; then

    L_z ≤ P_i[Z=z] ≤ 1−Σ_{w≠z}L_w

has width below ε. The search terminates under the promise, even without a supplied stopping-time modulus. Therefore every such report probability is a computable real. This is a reconstruction of the standard correspondence between almost-surely halting probabilistic Turing machines and computable discrete laws, explained by Freer–Roy–Tenenbaum, Section 3.2, pp. 14–16 of the saved author manuscript.

Choose a noncomputable real r in (1/4,3/4), and allow a mathematical target reporting kernel Bernoulli(r), independent of the hidden state, after one observation. It has full support and finite stopping cost. There is no almost-surely halting effective source policy with rational source laws and fair private bits that reproduces it. The abstract existence theorem may nevertheless select the very same mathematical Bernoulli(r) randomization. The discrepancy is the allowed kernel representation.

This does not exclude computable irrational report probabilities: exact sampling by successive precision refinement is possible with almost-sure termination. It also does not establish any impossibility of unknown-law Bernoulli factories. The obstruction is specifically arbitrary noncomputable kernels versus an effective discrete sampler.

## 3. Constructive class: explicit rational H without transcript enumeration

Let r≥2 hidden states have a finite known rational source menu, with conditionally independent observations given the state and selected actions. Suppose every pair is identified by some action/outcome. Let H be an explicitly supplied r×s rational stochastic matrix with all entries positive. Put h_min=min H_i(z). For each ordered pair (k,j), choose action a_{kj} and event x_{kj} with

    p_k=F_k^{a_{kj}}(x_{kj}) ≠ p_j=F_j^{a_{kj}}(x_{kj}).

Let γ be the minimum of these positive absolute gaps. Set e=h_min/8, M=ceil(log_2[r(r−1)/e]), and

    L=ceil(2 M/γ²).

M can be found by exact rational comparisons with powers of two; no transcendental decision is required. In each ordered-pair block take L observations of its action. Favor k when the indicator average is strictly above (p_k+p_j)/2 if p_k>p_j, and strictly below if p_k<p_j. A tie rejects k. All blocks are fresh and independent.

Hoeffding (1963), Theorem 1, equation (2.3), journal p.15, gives the bounded-variable inequality used below. Applying it to the indicators or their complements gives, both for rejecting true k and accepting k under true j,

    q_pair ≤ exp(−Lγ²/2) ≤ e/[r(r−1)].

Candidate k passes if every (k,j) block favors k. Choose the first passing candidate in a fixed order, defaulting to 0 if none passes. Under true i, error requires either some own block rejects i or an earlier wrong candidate k passes. Each such k's pass includes its block against i. A union bound gives

    P_i[classifier ≠ i] ≤ 2(r−1) q_pair ≤ 2e/r ≤ e.

Let t_{i,k,j} be the exact binomial-tail acceptance probability of block (k,j) under state i, and b_{i,k}=Π_{j≠k} t_{i,k,j}. Independence makes the confusion matrix computable directly:

    A_i(k)=b_{i,k} Π_{ℓ<k}(1−b_{i,ℓ})          for k>0,
    A_i(0)=b_{i,0}+Π_{ℓ=0}^{r−1}(1−b_{i,ℓ}).

There is no enumeration of the 2^{r(r−1)} pass patterns or all source transcripts. Row stochasticity and the error bound give ||I−A||_∞≤2e<1. Hence A is invertible. For K=A^{-1}H, the Neumann-series bound yields

    |K_i(z)−H_i(z)| ≤ 2e/(1−2e) < h_min.

The last inequality follows from e=h_min/8 and 0<h_min≤1. Thus K is positive. Also A1=H1=1 implies K1=1. Taking the classifier's candidate and then sampling its row of K reproduces H exactly, since AK=H.

### Computation and cost accounting

Each binomial tail for p=P/Q is an integer sum divided by Q^L:

    Σ_{t in acceptance} binom(L,t) P^t(Q−P)^{L−t} / Q^L.

Its integer operands have O(L B_F) bits when source rationals have at most B_F bits. A simple binomial recurrence uses polynomially many big-integer operations in L and B_F. There are r³−r² state/block combinations. Products, the r×r inverse, and the explicit r×s K matrix have rational bit complexity polynomial in r,s,L,B_F,B_H; fraction-free elimination or determinant bounds control intermediate size. Exact rational row sampling uses standard fair-bit rejection and expected O(log denominator) bit work.

Physical observations are N=r(r−1)L; action cost is L Σ_{k≠j}c_{a_{kj}}. This is polynomial in the actual chosen horizon and inverse separation, **not** necessarily polynomial in the binary input size. It is a deliberately crude explicit-H effective baseline and does not attain the sharp α_i rate. For r=1, just sample H_0 with private randomness and use zero source observations.

Li–Liu Lemma 8 supplies the near-identity inversion mechanism. Pairwise marker blocks supply an elementary factorization of a computable confusion matrix, replacing generic maximum-likelihood transcript/count enumeration. r11 independently implements the marker formula and validates it against direct Bernoulli count recurrences. No claim that this classifier design is new.

### Stronger diameter-dependent horizon

The h_min choice above is conservative. It unnecessarily penalizes reports that are uniformly rare in all states. r11's implementation uses the following stronger, independently checked choice. Put R=max_{i,j,z} H_j(z)/H_i(z)≥1, set M=ceil(log_2[4(r−1)(R+1)]), and L=ceil(2M/γ²). Then q_pair≤1/[4(r−1)(R+1)], classifier error≤2(r−1)q_pair, and δ=||I−A||∞≤1/(R+1)≤1/2. For every entry,

    K_i(z) ≥ H_i(z)[1−R δ/(1−δ)] ≥ 0.

Together with K1=1 this proves exact reproduction. This is the column-relative version of the same Neumann argument, matching Li–Liu's existing likelihood-ratio-diameter mechanism. Since log R is that diameter, N=O(r²γ^{-2}[1+log r+log R]). The finite explicit-matrix class therefore retains the diameter-dependent observation scaling, with polynomial arithmetic in the actual horizon and input bits. The number of states and source gap are charged constants, and succinct H extraction remains #P-hard. Equality in the bound permits zero K entries; strict positivity is not required for a Markov kernel.

## 4. Tiny rational gaps inherently force exponential source cost

For B≥2 put ε=2^{-B}, F_0=Bernoulli(1/2−ε), F_1=Bernoulli(1/2+ε), and prescribe constant-size explicit reports H_0=Bernoulli(1/4), H_1=Bernoulli(3/4). Any exact converter with E_0N finite satisfies stopped-transcript data processing:

    E_0N · D(F_0||F_1) ≥ D(H_0||H_1)= (log 3)/2.

For completeness, full support makes the stopped transcript likelihood ratio the product of the per-observation likelihood ratios, with private randomization cancelling. Its log has bounded increments. Wald's identity follows by expanding the stopped sum and using that {N≥t} is determined before observation t, with absolute integrability from E_0N<∞. Thus the stopped transcript KL equals E_0N times the one-step KL; applying the output kernel decreases it.

Here

    D(F_0||F_1)=2ε log[(1+2ε)/(1−2ε)] ≤ 16ε²,

because log[(1+x)/(1−x)]≤2x/(1−x) for 0≤x≤1/2. Therefore

    E_0N ≥ (log 3)/(32ε²) = (log 3)·4^B/32.

The source description has O(B) bits. A converter polynomial in that bit length, while charging physical draws, cannot exist uniformly over these inputs. This is a statistical information lower bound, so optimizing the marker compiler does not remove it. Prior art is the standard sequential KL/Wald lower bound already used by Team D and Li–Liu; only its binary-encoding implication is highlighted here.

All reductions and the constructive class are elementary programme support. We have not found a new general theorem or performed exhaustive novelty search for the marker architecture.

Concrete downstream use: future effective compiler statements must supply an explicit H/residual law, a tractable structured representation, or an implicit algorithm that demonstrably avoids exact extraction. Charge compiler bit work, classifier probability evaluation, representation size, and γ-dependent observation cost. Generic small output alphabet and bounded likelihood-ratio diameter do not make succinct H extractable efficiently.

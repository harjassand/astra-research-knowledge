# A conditional binary-capacity table interface, with charged sampling

Status: complete elementary deduction conditional on family114's stated FPRAS. The source counting theorem is not independently established by this worker. This note does not re-prove family115's exact-uniform expected-time theorem. It isolates a concrete use of the common-polymatroid interface without expanding a binary capacity into individual labelled units.

## Input, rank oracles, and exact bijection

There are p rows and q columns, nonnegative integer target margins r_i,s_j, and integer cell bounds 0<=l_ij<=u_ij, all in binary. A legal output is an integer table X with those margins and bounds, counted once per table. An absent upper bound can be replaced by min(r_i,s_j). Inconsistent bounds or unequal total margins are rejected exactly.

Write Y_ij=X_ij-l_ij, c_ij=u_ij-l_ij,

    r'_i=r_i-sum_j l_ij,   s'_j=s_j-sum_i l_ij.

Reject a negative residual margin. Both residual totals equal the same integer R. Let E be the explicitly enumerated cells. For a subset A of cells define

    rho_row(A)=sum_i min(r'_i, sum_{j:(i,j) in A} c_ij),
    rho_col(A)=sum_j min(s'_j, sum_{i:(i,j) in A} c_ij).

Each function is normalized, nondecreasing, integer-valued and submodular. To see submodularity, within one row the marginal increment from adding a cell of capacity c is min(c,max(0,r'-current_capacity)), which decreases as the previous subset increases; sum these disjoint row functions. The column proof is identical. Evaluation needs O(pq) binary additions and minima; all intermediate numbers have bit length bounded by the encoded capacities plus log(pq). The oracle itself is therefore charged, rather than provided as a free computational primitive.

Test feasibility by a capacitated bipartite max-flow network: source-to-row capacities r'_i, row-to-column capacities c_ij, and column-to-sink capacities s'_j. Integral flow of value R is equivalent to a residual table. Edmonds–Karp uses a polynomial number of augmentations independent of numerical capacity; binary arithmetic and network encoding are charged. On a feasible instance every row and column has sufficient total capacity, hence both rank functions have total rank R.

Common integer bases of these two polymatroids are exactly the feasible residual tables. In one direction, a common base Y has total R; the full-row constraints give row sums <=r'_i, so their sum forces equality for every row, and likewise for columns. Singleton constraints give Y_ij<=min(c_ij,r'_i,s'_j)<=c_ij. In the other direction, a feasible residual table obeys, for every A and every row i,

    sum_{j:(i,j) in A} Y_ij <= min(r'_i,sum_{j:(i,j) in A} c_ij),

and summing yields rho_row(A); the column constraints follow similarly. Adding the fixed lower table is a bijection. Every integer vector/table has multiplicity one. A labelled clone construction has different multiplicities and can have size proportional to the numerical capacity; it is not used here.

Consequently, **if** the uniform binary-capacity FPRAS of family114 is correct with its stated oracle/bit interface, it supplies an FPRAS for this table problem. The oracle evaluations above make its full cost polynomial in the explicit table dimensions, binary data length, inverse relative error and logarithmic inverse failure probability. This is a conditional consequence, not an executed large counting algorithm or a novelty claim about table counting.

## Binary subdivision gives a bounded-time approximate sampler

Assume the conditional FPRAS above, including its polynomial time/output bound on every random tape. For rational 0<tau<1, an always-feasible sampler within total variation tau of uniform can be acquired without looping over all numerical values in a cell.

Maintain a feasible cell box [L_e,U_e] and margins. Initially these are the original bounds. An exact max-flow test decides feasibility of each box by subtracting its current lower bounds as above. If a cell interval has more than one integer value, split it into two contiguous intervals as equally sized as possible. At least one child box is feasible. Use a forced branch when only one is feasible. When both are feasible, estimate each positive child count with two fresh calls at relative error eta and failure probability gamma. Use their rational ratio A/(A+B) to choose a child; if both estimates vanish, choose a fixed feasible child. Every branch stays feasible even after a failed estimate.

Let

    T=sum_e ceil(log2(u_e-l_e+1)),   T_*=max(1,T),
    eta=gamma=tau/(8T_*),
    k=min{j: 2^j>=8T_*/tau}.

There are at most T subdivision decisions: along any chosen branch each interval size is at most the ceiling of half its previous size. Drawing k fair bits J chooses the first child when J<floor(2^k A/(A+B)). This approximates its estimated probability within 2^-k<=eta, with fixed bounded fair-bit cost.

The ideal sampler using exact child count ratios is uniform, since those conditional probabilities telescope. At any adaptive history with two feasible children, true counts z_+,z_- are positive. If both estimates succeed, write A=z_+(1+a), B=z_-(1+b), |a|,|b|<=eta. Then

    |A/(A+B)-z_+/(z_++z_-)|
      <= eta/[2(1-eta)].

Fresh calls make the conditional probability of either failure <=2gamma. On failure the branch discrepancy is at most one. Thus the conditional TV error is at most

    eta/[2(1-eta)]+2gamma+2^-k <=4eta.

Sequential coupling until the prefixes differ gives total output error <=4Teta<=tau/2<tau. At most 2T counting calls and 2T+1 exact flow tests are required. Child instances have polynomial encoding length. Their requested inverse error is 8T_*/tau and confidence cost log(8T_*/tau). Even failed rational estimates have polynomial bit length by the counter's every-tape bound. No stationary warm start, supplied feasible sampler, exponential coordinate enumeration or exact count is hidden in this deduction.

This argument supplies worst-case polynomial cost in tau^-1, not log(tau^-1). It does **not** give exact uniform sampling, either bounded-time or expected-time. Exact unbiased sampling is a stronger claim requiring another argument; the separate family115 manuscript and formalization claim such an algorithm, but were not technically audited here.

## Downstream limitation and prior

Uniform feasible sampling cannot by itself guarantee useful experimental discrepancy. The independently reconstructed cycle example in `notes/frontier_design_bridge/cycle19/DESIGN_BRIDGE.md`, sections 1–2, has only two feasible alternating perfect matchings, known count two, exact uniform sampling by one fair bit, and all marginals one half; nevertheless its unit scalar feature has discrepancy r on every feasible output. It also supplies positive rank-one information contributions H_even=diag(1,0), H_odd=diag(0,1). The fractional target is (r/2)I and sum H_e²=rI, but both feasible outputs are singular with operator error r/2. Thus ideal access cannot provide a dimension-independent constant times sqrt(||sum H_e²||) bound under these two exact partition budgets. The claimed implication fails already in matrix order two; it is not a counterexample to a source FPRAS. A design application needs a separate geometric/output-admission theorem or permission to relax hard budgets.

The rank reduction uses partition-capacity polymatroids and integral bipartite flow. Approximate-count-to-approximate-sample self-reduction follows the Jerrum–Valiant–Vazirani framework and the explicit binary/finite-bit deletion argument in family 113 section 10.2, Lemma `deletion-sampler` (source lines 3203–3286). The binary interval specialization and explicit oracle accounting above are our deduction; no priority claim is made. The decisive remaining gate is the complete family 114 counting theorem, especially its binary continuous-to-discrete regularization and numerical evaluator. The next falsifiable implementation step would be an admitted, resource-capped implementation of those upstream modules, not a toy enumeration being presented as an FPRAS.

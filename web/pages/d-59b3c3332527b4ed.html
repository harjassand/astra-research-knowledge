SU(3) WALL WEIGHTED SPECTRUM: TWO EXACT MULTIPLICITY-ONE FAMILIES
Date: 2026-10-08
Status: internally proved conditional only on the exact CPV source-to-L_S
map already recorded in MISSING_LABEL_MAPPING.txt. This is a partial
spectral result; the all-block weighted count remains open.

1. COMMON SETUP

Let a>=b>=1, N=a+b, eta=(a-b)/N, and C2=(a^2+ab+b^2+3N)/3,
C3=(a-b)(2a+b+3)(a+2b+3)/18, alpha=C3/C2. For an output
V_(p,q) with p<=q and p+q<=a, write delta=(q-p)/3. The exact
Littlewood--Richardson/GT multiplicity interval is

  j=delta,...,min(p+delta,b),

so a one-dimensional block occurs on the boundary p=0 or delta=b.
The operator K_(p,q) is L_S restricted to this multiplicity space,
with the normalization in
outputs/research/sol_semiclassical_memory/wall_su3/
MISSING_LABEL_MAPPING.txt. The proposed global sufficient bound is

  kappa_l(K_(p,q)) >= c [j_l+eta j_l^2],
  j_l=delta+l-1,                                          (1)

where kappa_l are sorted increasingly. No GT/CPV eigenvector
identification is used here: for a singleton, there is only one
eigenvalue and one branch label.

2. LEFT BOUNDARY p=0

Take output (p,q)=(0,3r), with integer 0<=r<=min(b,floor(a/3)).
It has delta=r and multiplicity one. Substitution in the source Eq.18
and the exact quartic map gives the scalar identity

  kappa = r(r+1)/N^2 [2 C2+5/4+3 alpha^2-r(r+1)].        (2)

For transparent source algebra, the source labels are

  xi=(N+1-2r,b+1,b+1-r,b-2r,b-r,0),
  Lambda=N+2r+3,
  X_miss=-2C3/3,
  Y_miss=r(r+1)[-C2+r(r+1)/4-1/2].

In the map
  K=[-Y_miss-2alpha X_miss
     -c^2/12+(C2/3+1/4+alpha^2)c-4alpha C3/3]/N^2,
with c=3r(r+1), the X/C3 terms cancel, yielding (2).

Uniform lower bound: C2>=N^2/4. Also r<=N/4: if a<=3b then
r<=a/3 and a/[3(a+b)]<=1/4; if a>=3b then r<=b and
b/(a+b)<=1/4. Therefore, for N>=2,

  r(r+1)/N^2 <= 1/16+1/(4N) <=3/16,
  [2C2+5/4+3alpha^2-r(r+1)]/N^2 >=5/16.

For r>=1, r(r+1)>=r^2 and r+eta r^2<=2r^2, so

  kappa >= (5/32)(r+eta r^2).                            (3)

For r=0 this is the scalar block and both sides of (1) are zero.

3. RIGHT MULTIPLICITY-CAP BOUNDARY delta=b

Take q=p+3b, p>=0, and impose p+q<=a, equivalently
a=3b+2p+t with an integer t>=0. Here delta=b and the exact
multiplicity interval is the singleton {b}. Put N=4b+2p+t and

  R=a^2+ab+b^2+3N=3C2.

The CPV Eq.18 scalar specialization and exact quartic map give

  kappa = b(a+2)(N+1) P(b,p,t)/(4 N^2 R^2),             (4)

where

  P = 568b^5 + b^4(1300p+665t+1519)
    + b^3(1112p^2+1143pt+2981p+291t^2+1496t+1365)
    + b^2(422p^3+653p^2t+2105p^2+333pt^2+2125pt+2190p
          +56t^3+537t^2+1065t+414)
    + b(60p^4+124p^3t+626p^3+95p^2t^2+949p^2t+1134p^2
        +32pt^3+478pt^2+1122pt+504p+4t^4+80t^3+282t^2+234t)
    +64p^4+128p^3t+192p^3+96p^2t^2+288p^2t+144p^2
      +32pt^3+144pt^2+144pt+4t^4+24t^3+36t^2.

Every coefficient is nonnegative, and coefficientwise comparison gives

  P >= 4b(b+p+t)^4 >= b N^4/64,

because N=4b+2p+t<=4(b+p+t). Since a>=3b, a>=3N/4; since
N>=4, R<=3N^2+3N<=15N^2/4. Hence (4) implies

  kappa >= b^2/4800.

Here eta<=1, so b+eta b^2<=2b^2 and therefore

  kappa >= (b+eta b^2)/9600.                             (5)

Equations (3) and (5) prove (1), with c=1/9600, on both
multiplicity-one boundary families and their conjugates.

4. VERIFICATION / LIMITS

The source used is Crampé--Poulain d'Andecy--Vinet, arXiv:2110.03521,
Eq.18, together with the exact source normalization map and quartic
identity in MISSING_LABEL_MAPPING.txt §§1--4. The algebraic simplification
was independently re-evaluated in SymPy and compared with the numerical
CPV matrix implementation on the fixtures (10,5,1), (8,8,2), (30,2,2),
(20,8,6) for p=0 and (8,2,1), (9,2,0), (12,3,1), (30,5,6),
(40,10,0) for delta=b. Agreement is to floating precision only; a
separate symbolic certificate is supplied in
boundary_singleton_certificate.py.

This proves no estimate for blocks with multiplicity >=2, does not imply
the target global weighted count, and does not repair the cubic proxy
K>=M^2/c: that proxy vanishes on the stable (a,a), output (0,3) block
while (2) is positive. The load-bearing unresolved problem remains a
uniform lower spectral profile for the true quartic K on the interior
multiplicity blocks (or a different proof of the all-matrix count).

INDEPENDENT AUDIT: A POSITIVE-RC PAIR HARD FOR SHORT BOUNDED-CURRENT EXPERIMENTS

Status: analytic theorem candidate passed internal reconstruction. Exact
positive-model feasibility and rational interval computations passed. Neither
physical validation nor historical novelty nor technological advantage follows.

1. Model and exact difference

Let A>0 have resistance units and let delta>0 have inverse-time units. Let Z0
be any common causal linear impedance with the same zero incremental initial
state in the two experiments. Define, in the Laplace variable p,

  Z_minus(p) = Z0(p) + A*(2 delta)/(p+2 delta),
  Z_plus(p)  = Z0(p) + 2A*delta/(p+delta).

Both added terms are positive RC modes. Their resistance and decay-rate pairs
are (A,2 delta) and (2A,delta), respectively. Direct subtraction gives

  Z_plus(p)-Z_minus(p)
    = 2A delta^2 / ((p+delta)(p+2 delta)).

Consequently the impulse-response difference is

  g(t) = 2A delta [exp(-delta t)-exp(-2 delta t)] >= 0  (t>=0),

and its integral, the unit-step-response difference, is

  d(t) = integral_0^t g(u) du = A [1-exp(-delta t)]^2.

In particular d is increasing and tends to A. The shared model Z0, including
any common feedthrough or common series inductance, cancels for the SAME
current history. This cancellation does not assert that Z0 is itself known
from the EIS data.

2. Sharp bound for every signed bounded current

For any measurable scalar current I with |I(u)|<=Imax on [0,H], zero increment
initialization implies

  Delta v(t) = integral_0^t g(t-u) I(u) du.

Since g>=0,

  |Delta v(t)| <= Imax integral_0^t g(u)du
                = Imax d(t) <= Imax d(H),  0<=t<=H.

For I(u)=Imax, equality holds at t=H. Thus

  sup_{|I|<=Imax} ||Delta v||_{infinity,[0,H]} = Imax d(H).

Allowing arbitrary signed currents does not improve this fixed-pair optimum.
This is an exact induced-norm calculation for this pair, not an assertion
that the pair is extremal among all EIS-compatible positive-RC models.

If an ideal input step is used with a positive series inductance, the
individual voltages include a common switching distribution. The ordinary
voltage statement excludes the switching instant or concerns a compensated
regular voltage. The difference has no such distribution. A finite slew
contract, treated below, gives ordinary outputs without this idealization.

3. Adaptive same-transcript lower bound

Assume a deterministic additive voltage-error interface

  y(t_j) = v_theta[I](t_j) + e_theta,j,   |e_theta,j|<=epsilon_V,

with no distributional or independence assumption. The EIS observation box
is a separate supplied interface; both models can yield its same data vector.
Set B(H)=Imax d(H). Suppose B(H)<=2 epsilon_V.

First consider a finite sequential policy. From its prior observations it
chooses the next input segment, next measurement time, and whether to stop,
with every measurement time at most H and every applied current admissible.
Run this policy against the midpoint system

  Z_mid = (Z_minus+Z_plus)/2.

At every query provide its noiseless midpoint voltage. Given the already
constructed common current history, linearity gives

  v_mid[I] = (v_minus[I]+v_plus[I])/2.

The same observation is admissible in world theta with error

  e_minus = (v_plus[I]-v_minus[I])/2,
  e_plus  = (v_minus[I]-v_plus[I])/2.

The absolute value of either error is at most B(H)/2<=epsilon_V. By induction
the policy sees the same past observations in both worlds, hence chooses the
same future segments, times, stopping decision, and final answer. The
midpoint is itself a positive-RC model whenever both endpoints are, but the
finite-query argument only needs the algebraic midpoint response. An
adaptive stopping time bounded by H is covered by the same induction.

For a continuous-time feedback policy, the same proof holds if its closed
loop with the midpoint system is well posed and its input is admissible.
Let (I_star,y_star) be that midpoint closed-loop solution. Set

  e_theta(t) = y_star(t)-v_theta[I_star](t).

These are bounded by B(H)/2 and reproduce the same feedback solution in both
worlds. The proof does not quantify over undefined or nonunique algebraic
feedback loops. Well-posedness for the whole two-model segment is a convenient
sufficient contract. No Gaussian-noise or independent-repetition statistical
lower bound is being asserted.

Since the policy is deterministic, the constructed error histories are fixed
histories once the policy has been specified; they are allowed by the
deterministic worst-case interface. For randomized policies one must specify
the noise adversary more carefully. A causal adversary allowed to observe
applied currents can implement the midpoint response and couple both worlds
with the same private random seed; an oblivious stochastic-noise claim does
not follow automatically.

4. Estimation and decision consequence

Let q_minus and q_plus be two scalar targets on the endpoint models. An
estimator receiving the common transcript returns the same number c, so

  max(|c-q_minus|,|c-q_plus|) >= |q_plus-q_minus|/2.

If a decision threshold lies strictly between q_minus and q_plus, no policy
can certainly classify both worlds under this error interface. This remains
true even if the policy is supplied the common baseline and the entire
two-model segment. It is a lower bound for any larger model class containing
the pair.

Conversely, when Imax d(H)>2 epsilon_V, the constant-current experiment has
disjoint endpoint error intervals at H and can distinguish this KNOWN pair.
This converse is about the pair; it does not identify every model in the
larger EIS-feasible class. At equality the intervals meet at the midpoint,
so certain pair discrimination still fails.

5. Sharp finite-slew version

Suppose I(0)=0, I is absolutely continuous, |I'|<=Imax/rho almost everywhere,
and |I|<=Imax, with rho>0. Pointwise,

  |I(u)| <= Imax min(u/rho,1).

Because g>=0, the positive maximal ramp I(u)=Imax min(u/rho,1) attains the
largest difference at every t. Integration by parts gives

  D_rho(H) = (1/rho) integral_{max(0,H-rho)}^H d(t)dt,
  sup_admissible ||Delta v||_{infinity,[0,H]} = Imax D_rho(H).

D_rho is increasing because d is increasing. A convenient primitive is

  J(t)=A[t-2(1-exp(-delta t))/delta
          +(1-exp(-2 delta t))/(2 delta)],

so D_rho(H)=[J(H)-J(max(0,H-rho))]/rho. The midpoint proof holds with d(H)
replaced by D_rho(H). A ramp constraint without I(0)=0 would not give this
particular improvement: a pre-existing Imax is admissible under a mere slew
bound. The initialization is therefore essential.

For peak-only current and 0<2 eta<A, where eta=epsilon_V/Imax in resistance
units, the exact pair-discrimination boundary is

  H_crit = -log(1-sqrt(2 eta/A))/delta.

Certain discrimination of this known pair requires H>H_crit. If 2 eta>=A,
no finite H suffices; if eta=0, every H>0 separates the pair ideally.

9. Informed-segment minimax extension

The final author proof adds the convex family Z_theta=Z_minus+theta*Delta Z,
0<=theta<=1, with the entire baseline, initial state and family supplied.
Every family member is positive RC and is in the EIS box by convexity.
Write K=d(H) under peak-only control and K=D_rho(H) under finite slew.
For deterministic sequential policies the exact minimax absolute target error
is

  R_star = d(T) min(1/2, eta/K),

with value d(T)/2 when K=0.

For the lower bound choose theta_+-theta_-=2r, centered at 1/2, where
r=min(1/2,eta/K). The impulse difference between these two members is 2r*g,
so every admissible current has full-path separation at most 2r Imax K,
which is at most 2 epsilon_V. The midpoint argument yields a common transcript.
Their target separation is 2r d(T), hence every estimator has worst-case
absolute error at least r d(T).

For the upper bound use the optimal ramp/plateau (or peak-only constant input)
and read at H. Subtract the known Z_minus response. The residual observation
is y=theta Imax K+e, |e|<=epsilon_V. Its exact feasible theta interval is

  [0,1] intersect [(y-epsilon_V)/(Imax K),
                  (y+epsilon_V)/(Imax K)].

Return its midpoint, then map to Q_theta(T)=Q_minus(T)+theta d(T).
The feasible theta interval has radius at most min(1/2,eta/K), proving the
matching upper bound. This upper bound requires the supplied known family;
it is not an estimator for the whole EIS-compatible model class.

10. General binomial extension

For n>=1 and positive A,delta, put resistance A*binomial(n,k) at rate k*delta
in the plus system for odd k and in the minus system for even k, k=1,...,n.
All resistances are positive. For x=exp(-delta t), the exact identity

  sum_{k=1}^n (-1)^(k+1) binomial(n,k)(1-x^k)=(1-x)^n

gives d_n(t)=A(1-exp(-delta t))^n. Differentiation gives

  g_n(t)=A n delta exp(-delta t)(1-exp(-delta t))^(n-1)>=0.

For Re(p)>0 the beta integral gives

  integral_0^infinity exp(-p t) g_n(t)dt
  = A n integral_0^1 u^(p/delta)(1-u)^(n-1)du
  = A n! delta^n / product_{k=1}^n(p+k delta).

Thus the author's transfer, positivity, sharp control and segment-minimax
extensions follow. For rational delta/a=d, x_mode=a*tau=1/(k*d) is rational,
so the compact node 1/(1+k*d) and normalized mass are rational as claimed.
Independent diagnostics checked 216 exact step, derivative, and rational
transfer identities for n=1,...,12. Those diagnostics supplement the analytic
binomial/beta proof; finite evaluations alone do not prove it.

11. Scope and known-method boundary

The proof requires a stationary causal linear-response model or valid
subtraction of the unforced trajectory from the same initial state, with
zero incremental RC states at the start. Preparation, drift, state of charge,
temperature changes, nonlinear response, unknown relaxation initialization,
and additional independent measurement interfaces are outside this theorem.
The deterministic EIS error assumption and the voltage error assumption
require separate physical acquisition. This audit establishes neither.

Brown and Grabovsky already study worst-case discrepancy and optimal
extrapolation of completely monotone positive-measure transforms, including
local optimality conditions and a single-exponential solution. Their Theorem
2.1 has a relative L2 observation contract, distinct from the present
bounded-current and deterministic L-infinity voltage contract. This specific
causal-pair calculation must not be promoted into a generic discovery of
extrapolation ill-posedness or historical priority.

Primary source inspected: Henry J. Brown and Yury Grabovsky, On feasibility
of extrapolation of completely monotone functions, arXiv 2401.15178v2,
https://arxiv.org/html/2401.15178v2 (introductory formulation, Theorem 2.1,
and description of the local problem, inspected 15 October 2026).

The retained positive result is a small explicit EIS-feasible hard pair and

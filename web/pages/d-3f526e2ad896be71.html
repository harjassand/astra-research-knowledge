## Dyadic completion: direct proof

`06-exactness.tex:9–27`, Lemma `lem:completion`, equation `eq:completion`.

Write `A=(1-delta)s`, `delta=2^-t`, `E=W+t+2`,
`C=2^-E floor(2^E z/A)`, and `R=z-CA`. Then, for **every** allowed parameter
tuple, including `W=0` and `z=A`,

    0 <= C <= 1,
    0 <= R < A*2^-E <= 2^-E,
    0 <= q_guess := R*2^(W+t) < 1/4,
    Pr(pass) = (1-delta)*s*C + delta*2^-W*q_guess
             = AC+R = z.

The scaled floor uses exact integer division; the ratio `z/A` itself is never
sampled. `C`, `R`, and `q_guess` are dyadic. If `A` has denominator exponent
`alpha`, then a common representation of `R` has exponent at most
`max(denom_exp(z), E+alpha)`. Multiplication by `2^(W+t)` therefore leaves a
polynomial denominator exponent; when `denom_exp(z)<=E+alpha`, the exponent
of `q_guess` is at most `alpha+2`. There is no hidden non-dyadic coin.

## Deferred filters: independent kernel proof

`06-exactness.tex:50–73`, Proposition `prop:known-probability`; in particular
lines 58–66.

Fix the unique true data `D` only in the mathematical analysis. For each
recorded prefix `h`, let `T_h` be its next ordinary transition distribution
and let its hypothetical immediate retention predicate use `D`. Attach
fresh independent filter coins to this distribution. By the completion lemma,
the probability of a passing next slot is exactly `z`, for every passing
prefix `h`.

Why the next slot exists: every passing output is good. A passing prefix can
be continued with canonical good outputs; the all-good completion premise
therefore rules out an abort or exhausted cap before its next slot. This
reasoning does not inspect future sampled outputs or condition on eventual
completion. Early completion simply changes all later kernels to the dummy
kernel, which has the same retained mass `z`.

Thus, if `F_i` denotes passage of the first `i` hypothetical tests,

    Pr(F_i | each particular passing prefix at i-1) = z,
    Pr(F_i) = z Pr(F_(i-1)) = z^i.

At `i=L`, all outputs were good, hence the actual run generated true complete
data and its deferred tests are exactly those hypothetical tests. Conversely,
an implemented success has verified data; uniqueness makes those data equal
to `D`, so its deferred tests equal the hypothetical tests on the same history
and same coins. This proves pathwise event equality, not merely equality of
averaged distributions. It also handles bad runs that happen to complete
correctly: their bad slots are rejected by the actual deferred tests.

The quantum issue is separately resolved by immutable orthogonal history
copies (`02-model.tex:28–37`, `lem:records`; `05-factor-process.tex:73–78`).
Conditioning on prior outputs and prior filter coins leaves fresh trial
registers in zero state. Unobserved old work can be arbitrary and entangled;
the next trial acts identically on it. Copying only final control outcomes
does not destroy the intended within-trial interference.

## Quarter correction and final reflection

`06-exactness.tex:94–117`, Lemma `lem:quarter`, is another application of
the same rounding-and-unique-guess principle. For any dyadic `1/2<p<=1`
and nonnegative guess width `J`,

    c = 2^-(J+2) floor(2^(J+2)/(2p)),
    e = 1/4 - pc/2,
    0 <= e < p*2^-(J+3),
    0 <= 2^(J+1)e < 1/4,
    pc/2 + (1/2)*2^-J*2^(J+1)e = 1/4.

The valid root factor list is unique because of ordering, primality,
multiplication, and zero padding. Exact reflection at mass 1/4 is elementary:
for `g=Pi psi`, `||g||^2=1/4`,

    (2|psi><psi|-I)(psi-2g) = 2g.

Keeping all workspace is sufficient: `V(2|0><0|-I)V^-1` reflects about
the full prepared state including histories. There is no requirement that
successful garbage be equal across branches.

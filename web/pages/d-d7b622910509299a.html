\[

## 4. Typed completion preserves guard witnesses under compression

The deterministic table reaches just
`{}`, `{sf}`, `{tf}`, `{tt,sf}`, `{tf,st}`. Every output bit is a monotone
DNF in the child bits; `typed_guard_completion.py` writes those DNFs
independently and checks all105 constructor/state cases against the separate
transition implementation.

Start with the acyclic forced-constructor quotient of a finite source proof
skeleton and its actual ground solution. Each quotient class has the actual
original classifier state; equal terms have equal states. Demand one
originally true bit for each accepted guard (tt is chosen if available), and
propagate demands downward: choose a DNF clause true in the original child
states and demand those clause bits. Merge demands on shared classes. Every
demand stays a subset of that class's original state, so incompatible bit
requirements are never introduced. There are at most four unique demands per
class, and each DNF clause has bounded size.

Ground a free class to1 when tt is demanded, to0 when tf or st is demanded,
and to a fresh atom otherwise. Each jointly compatible leaf demand is
satisfied: the three fillers have states `{tt,sf}`, `{tf,st}`, `{sf}`. Rigid
atoms/constants and forced constructors remain fixed. Induct upward using
monotonicity to preserve every selected root witness. Thus the completed
common term graph remains linear in skeleton size plus rigid goal size, and
the added annotation work is at most four demands per class.

The executable checks all13 compatible original-state/demand-subset pairs,
a shared seven-class example requiring all three fillers, rejection of a
joint incompatible demand, and the failure of uniform all-free-to-atom
grounding. The latter loses a tt root and a derived sf product witness.
This is a universal completion lemma **given the original legal solution's
states and an acyclic constructor quotient**. It is not an independent solver
for arbitrary type constraints, and it does not establish semantic information
from absent classifier bits. Whole installer fixtures use actual source DAGs;
they do not themselves execute the older skeleton compiler.

cannot be treated as conservative standard EF admission.

## 6. New uniform fixed-power construction, no state guard

For each fixed integer k>=2, define left-associated source powers
`A^1=A`, `A^(n+1)=A^n*A`. The schema `A^k -> A^(k+1)` has an ordinary Chu
proof in LJ_! with no Pair input and no classifier witness. This is a
substitution-closed source extension. Its exact formula is stated because
the S literature calls `A²=A³` **three-potency**, while the general k-potent
literature uses the exponent k in this displayed equality.

Write `a=T_A,u=S_A`, `P_1=a,P_(n+1)=P_n*a`, and `S_n=S_(A^n)`. Then
`S_2=(a->u)&(a->u)` and
`S_(n+1)=(P_n->u)&(a->S_n)`. Primitive recurrences:

* `D_n: a=>P_n`: tensor the prior D with `a=>a`, then explicitly contract
  the two a resources. Each n adds2 rows/5 occurrences.
* `E_n: P_n=>a`: weaken E_(n-1) by one a, then L*; each n adds2 rows/
  5 occurrences. E_1 is identity.
* `F_n: (a->u)=>S_n` for n>=2: F_2 is R& of the implication identity twice.
  For n>2 the first conjunct uses E_(n-1) followed by L-> and R->; the second
  weakens F_(n-1) by a and discharges it; then R&.
* `S_(k+1)=>a->u` applies the first conjunct `P_k->u` using D_k and discharges
  a. Cut with F_k gives `S_(k+1)=>S_k`.
* Cut E_k with D_(k+1) gives `P_k=>P_(k+1)`. Discharge both legs and R&.

`potency_independently.py` serializes this recurrence: exactly `9k` rows and
`22k-6` occurrences, k ordinary C rows, maximum antecedent2. For k=2 a
shorter independent direct proof uses14 rows/34 occurrences, two C rows,
maximum antecedent3. It proves the positive leg from `a,a,a=>a²*a` with one
C and the negative leg from `S_3,a,a=>u` with one C, then repeats that
negative proof through R& to obtain S_2. Reusing a proof endpoint through
additive R& is legal; it is not an extra linear contraction.

The mathematical recurrence is uniform in each fixed k. Checks k=2,3,5,12
are implementation witnesses. Cost is O(k) when k is charged; it is not a
polynomial bound in a binary encoding of an arbitrarily large exponent or a
scheme allowing variable-length schema patterns for free. k=1 fails already
in the Boolean target: `(p->p*p)^t` is false when p is false.

In the involutive commutative source, `c(A,negA)` is equivalent to this
k=2 schema: currying gives `neg(A³)->neg(A²)`, and DN/contraposition gives
`A²->A³`. This is a manual source equivalence argument, **not** a serialized
source equivalence certificate in this worker's output.

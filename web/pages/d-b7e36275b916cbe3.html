BASELINE VERDICT
There is a viable constructive theorem for the stated additive C4 target
with explicit rational-complex joint Choi access. Its two mechanisms are:
 (A) keep only Phi eigenmodes lambda>=3/4, giving a CONSTANT tree covariance
     contraction 1/(2lambda^2)<=8/9; depth logarithmic in d/delta is enough.
 (B) retain every Kraus-environment outcome and rank-one leaf measurement.
     Each complete record has a rank-one input effect whose ket is computed
     by a bottom-up d-dimensional tree contraction. Prepare its normalized
     ket. No global POVM enumeration or generic spectral refinement is used.
For implementation to diamond tolerance epsilon, extremely small ket norms
can be discarded with a rigorous whole-channel error bound, because the
logarithm of the total record count is polynomial. This removes any minimum
outcome-probability premise without postselection or repeated trials.

The mathematical finite-tree theorem and rank-one instrument construction
are fully derived below. The bit-complexity claim includes an explicit
spectral-data/standard universal-gate compilation lemma. Its technical
implementation references still require a primary-source check; the lemma's
degree/height and stability argument is spelled out rather than treated as
a free exact eigenbasis oracle. No runnable general circuit compiler has
yet been built, and that is not claimed by this baseline.

EXACT TARGET AND IMPLEMENTATION CONVENTION
Input: explicit Gaussian-rational entries of the unnormalized Choi matrix
of a valid CPTP B:M_d -> M_d tensor M_d, promised to have two identical
marginals Phi which are TP, unital and HS-self-adjoint. Let ell denote total
input bitlength. Input delta and implementation tolerance tau are positive
rationals. One may restrict 0<delta,tau<1; larger tolerances are trivial.
Output: a succinct specification of ONE ideal pure canonical EB Psi_delta
with
 I-Psi_delta <= 4(I-Phi)+delta I
on the entire real Hermitian normalized-HS space. The specification contains
no observable query and works simultaneously for all inputs.
The same specification can be implemented to diamond error epsilon using
per-shot classical/quantum resources polynomial in d,1/delta,ell,
log(1/epsilon). A finite-gate implementation is EB but need not be exactly
canonical, HS-self-adjoint or unital. The ideal map is exactly canonical.
If the requested actual quadratic-form error must still have additive
delta, allocate half of delta to the ideal tree and take
epsilon<=min(tau,delta/(4d)); the diamond perturbation contributes at most
sqrt(d)epsilon in normalized-HS quadratic-form norm, leaving enough slack.
No claim of exact irrational gate implementation in a finite gate alphabet
is made. The target must distinguish this standard approximation convention
from a demand for exact finite-gate canonicality.

1. CONSTANT-THRESHOLD FINITE TREE
Let tau_d=Tr/d. Diagonalize the supplied Hermitian HS operator on H_0:
 Phi(E_a)=lambda_a E_a, tau_d(E_a E_b)=delta_ab,
 lambda_a in [-1,1], E_a Hermitian and traceless.
Select J={a:lambda_a>=3/4}, q=|J|<=d^2-1. Negative eigenvalues are omitted.
For every omitted mode, 4lambda_a-3<=0, so positivity of a canonical EB
quadratic form is already sufficient for the additive C4 comparison.
If q=0, any pure rank-one dephasing is sufficient, with no tree.

Choose Q=2^ceil(log2 q). Give q-1 modes probability 1/Q and the last
mode probability (Q-q+1)/Q. These probabilities are exactly dyadic,
sum to one, and satisfy 1/p_a<=Q<2q. Each leaf coin needs ceil(log2 q)
fair bits with no rejection loop. Measure a rank-one eigenbasis of E_a,
including a basis within each degenerate eigenspace, with estimator
coordinate e_aj/p_a. This is one randomized POVM; its estimator covariance
is diag(1/p_a), and its first moments are exactly E_a.

For the depth m binary broadcast tree, use the Cycle03 unbiased estimator
Lambda^-m 2^-m sum_leaves x_0. Its exact reference covariance N_m is
bounded by diagonal D_m with
 D_m,aa=r_a/p_a+(1-r_a)/(2lambda_a^2-1),
 r_a=(2lambda_a^2)^-m <=(8/9)^m.
This follows from the actual sibling covariance C<=I, not independent
clones. For an unsymmetrized B, replace C by (C+C^T)/2 in the covariance
recursion; the same square-positivity inequality gives the bound. One may
instead symmetrize the rational Choi matrix first.

Put a_a=2lambda_a^2-1 in [1/8,1]. Then
 D_m,aa<=1/a_a+2q r_a,
 D_m,aa^-1>=a_a/(1+2q a_a r_a)>=a_a-2q r_a.
The full-space Schur-complement proof gives the canonical quadratic form
 S_m >= embedding diag(D_m,aa^-1) embedding^T.
It includes every selected/unselected cross term, not just diagonal scores.
Any rank-one refinement only increases S_m.

Take delta_0=delta/2, k=ceil(log2(2q/delta_0)), m=6k.
Since (8/9)^6<1/2, 2q(8/9)^m<=delta_0. The number N=2^m of leaves obeys
 N<=64(2q/delta_0)^6=64(4q/delta)^6,
and the tree uses N-1 supplied joint-channel operations. For selected modes,
 a_a-(4lambda_a-3)=2(1-lambda_a)^2>=0.
For omitted modes the target lower bound is nonpositive. Identity is fixed
exactly, with zero identity/traceless cross terms. Hence the single refined
finite-tree canonical map obeys
 Psi_m >=4Phi-3I-delta_0 I,
 I-Psi_m<=4(I-Phi)+delta_0 I.                         (F1)
No eigenvalue gap at 1/sqrt(2), 3/4, or 1 is assumed. This construction
does NOT claim to approximate the stronger positive-part theorem uniformly
with polynomial resources near its 1/sqrt(2) threshold.

2. CHOI DESCRIPTION PROVIDES A MEASURABLE KRAUS INSTRUMENT
Factor the PSD Gaussian-rational joint Choi matrix by exact rational
LDL^*: C=L D L^*. Zero pivots have zero residual rows/columns and are
discarded. The r<=d^3 nonzero columns sqrt(D_e)L_e reshape into Kraus
matrices K_e:C^d -> C^(d^2), with sum_e K_e^*K_e=I_d.
Each K_e has operator norm <=1. The LDL entries/pivots have polynomial
bitlength by determinant/minor height bounds for an explicit rational
matrix of dimension d^3. Square roots are approximated to the needed bits.
The Stinespring isometry V=sum_e K_e tensor |e> has output dimension
d^2 r<=d^5. It can be completed and compiled as a dense polynomial-
dimensional unitary. Measure the environment label e immediately, retain
it, and send the two child systems onward. This implements the specified
B when the environment outcome is ignored and supplies its Kraus
instrument when the label is retained.

Black-box CPTP access alone DOES NOT supply these environment outcomes,
the Kraus matrices, or the backward ket contractions below. Choi description
permits constructing one's own Stinespring implementation. A promised
self-compatible Phi without a supplied B description is also a different
acquisition problem. No joint-channel synthesis/learning oracle is assumed.

3. EVERY COMPLETE RECORD HAS A RANK-ONE EFFECT
A record omega contains N leaf coin choices a, N rank-one leaf eigenvector
labels j, and N-1 environment labels e. Let u_aj be the measured leaf ket.
Ignore the positive scalar leaf-coin probabilities while computing kets:
 eta_leaf=u_aj,
 eta_node=K_e^*(eta_left tensor eta_right).
At the root let eta_omega be the resulting d-vector, and let
 c_omega=product_leaves p_a.
The pulled-back input POVM effect for this full record is EXACTLY
 M_omega=c_omega |eta_omega><eta_omega|.                (F2)
This is a rank-one refinement of the tree POVM used in (F1). It follows
directly by multiplying Kraus maps and final rank-one bras, or by induction
over the tree. No spectral decomposition of a posterior effect is needed.
Every environment and leaf rank-one label is retained; an unobserved
environment could leave a mixed effect and would invalidate this shortcut.

For eta_omega!=0 prepare
 pi_omega=|eta_omega><eta_omega|/||eta_omega||^2.
Zero effects can prepare anything. The channel
 Psi_m(X)=sum_omega Tr(M_omega X) pi_omega
is CPTP and pure canonical, because sum_omega M_omega=I and the ensemble
weights Tr(M_omega)/d have barycenter I/d. It is unital, HS-self-adjoint
and HS-positive. One run produces one record and one posterior state.
The estimator is proof-only and need not be evaluated per shot.

The record alphabet satisfies
 R<=(qd)^N r^(N-1), log2 R=O(N log d).
Store a safe power-of-two bound R<=2^h, where h is computed from this
formula using integer dimension bounds. Both h and the record bitlength
are polynomial. No alphabet/POVM/ensemble enumeration occurs.
The root ket uses N-1 local d by d^2 contractions, O(N d^3) scalar
operations, rather than a d^N state-vector calculation. All exact local
kets have norm <=1, because each K_e is a contraction.

4. SMALL-OUTCOME NORMALIZATION WITHOUT A PROBABILITY PROMISE
Let epsilon be the desired diamond implementation error. Put
 zeta=epsilon/(100*2^h), and compute every realized root ket to Euclidean
absolute error eta_err<=epsilon sqrt(zeta)/100. If its approximate squared
norm is below 4zeta, prepare a fixed pure default state. Otherwise normalize
the approximate vector and prepare it to a further uniform small error.

On a default branch, the true ket norm is <=3sqrt(zeta), so
Tr(M_omega)=c_omega ||eta_omega||^2<=9zeta, since c_omega<=1.
For ANY input density, including an entangled ancilla,
probability of this outcome is <=||M_omega||_infinity=Tr(M_omega).
Hence the total probability mass of all discarded branches is at most
9Rzeta<=9epsilon/100. Their preparation discrepancy has diamond norm
at most twice that mass. On a nondefault branch the true norm is at least
sqrt(zeta), so standard normalized-vector stability gives uniformly
O(epsilon) pure-state trace error. Fixing numerical constants makes the
total preparation error <=epsilon/2. No exact sign decision or inverse
normalization is required on extremely tiny effects.

The precision cost is
 log(1/eta_err)=O(h+log(1/epsilon)), not O(1/min_probability).
The bottom-up contraction is stable in ABSOLUTE norm: exact local norms
are <=1; local coefficient/rounding errors of size eta_err/poly(N,d)
give root error <=eta_err by a telescoping/product norm bound. Intermediate
approximants may be clipped to the unit ball. Thus arithmetic precision
and per-record work remain polynomial even if a true record effect is
zero or has doubly tiny norm due to algebraic cancellation.

Separately compile the forward Stinespring/leaf-PVM circuit so the entire
classical-record measurement channel is within epsilon/4 in diamond norm;
allocate inverse-polynomial epsilon across its polynomial number of gates.
Postprocessing this record by any preparations is CPTP and contracts that
error, independently of record probabilities. State-preparation gates
contribute another uniform epsilon/4. Combining with the preceding
discarded-branch bound gives a diamond-epsilon implementation of the SAME
ideal Psi_m. Approximate implementations remain EB because they measure
to a classical record and then prepare; exact canonicality is a property
of the ideal mathematical map only.

5. BIT-COMPLEXITY AND GATE-MODEL OBLIGATIONS
The remaining preprocessing data are exact Phi eigenspaces/eigenmodes and
rank-one spectral bases of their d by d Hermitian matrices. This baseline
uses the standard polynomial-bit algebraic spectral-data lemma, with the
following justification and obligations:
 - Phi has a d^2 by d^2 Gaussian-rational Hermitian matrix in the complex
   matrix-unit HS basis. Its real eigenvalues are roots of a rational
   characteristic polynomial of degree <=d^2 and coefficient height of
   polynomial bitlength. Repeated roots are isolated through the square-
   free characteristic polynomial; nonzero gaps have logarithmic inverse
   bounded polynomially by root separation from the explicit encoding.
 - A projector for a distinct root lambda is q_lambda(Phi)/p_sf'(lambda),
   q_lambda(x)=p_sf(x)/(x-lambda). It lies in Q(lambda,i). Hermitian columns
   span its real Hermitian eigenspace. A field-valued Gram LDL decomposition
   gives an orthonormal basis with ONE extra square root per resulting
   column, instead of an uncontrolled nested-radical extension. Traceless
   lambda=1 modes use the projector with |I><I| removed.
 - Thus an individual E_a has algebraic degree O(d^2), with coefficient
   heights bounded polynomially by rational-matrix minors and normalization
   pivots. Its eigenvalues/eigenvectors have algebraic degree O(d^3) after
   the d-dimensional spectral problem and another normalization square root.
   Exact multiple eigenvalues are handled as subspaces. Nonzero leaf gaps
   can be exponentially small, but their logarithmic inverses still have
   polynomial bounds in the encoding. These derived bounds are not an
   additional spectral-gap premise.
 - Rational/algebraic root isolation, linear algebra and evaluations to
   P bits must be implemented by their polynomial-bit algorithms. An exact
   eigenbasis oracle or numerical routine requiring a user-supplied gap
   would not justify the target. A primary-source algorithm audit remains
   to verify this technical lemma/height accounting fully.
 - Dense Stinespring unitary completion can use stable Householder steps;
   the input columns are an isometry, and one can avoid tiny denominators
   by phase choices. Dense leaf PVM unitaries and normalized known vectors
   are classically specified, rather than unknown states given by an oracle.
 - Under a standard fixed universal gate set with efficient rotation/
   unitary compilation, polynomially many one/two-qubit rotations can be
   synthesized to error epsilon/G with poly(log(G/epsilon)) overhead. This
   compilation assumption and a primary source must be named; neither an
   exact arbitrary-rotation gate nor a free amplitude-loading oracle is
   implicit. Power-of-two register padding can be charged and erroneous
   padding outcomes assigned default preparations within the same global
   measurement-channel error budget.

6. RESOURCES AND CLAIM BOUNDARY
N=O((d^2/delta)^6); forward node count N-1. A dense local Stinespring
unitary has dimension at most d^5, so generic local gate count is a fixed
polynomial in d. Peak quantum storage is O(N log d) qubits plus local
ancillas. Classical record storage is O(N log d) bits. Posterior
processing uses O(N d^3) arithmetic operations at P=poly(d,ell)+
O(N log d+log(1/epsilon)) bits, and standard known-vector state preparation.
Preprocessing and all per-shot resources are polynomial in the advertised
parameters, contingent on the named standard compilation/spectral-data
algorithm lemma. The polynomial degree is large; no practical benchmark
or local laptop implementation is asserted.

The outcome alphabet is generally exponential in N, but its logarithm,
the sampled record and the work on that record are polynomial. There is
no rejection sampling, outcome-list enumeration, postselection repetition,
minimum outcome probability, acquired broadcaster, or hidden eigen-gap.
The posterior calculation relies essentially on EXPLICIT INSTRUMENT DATA
constructed from the supplied Choi matrix. Black-box B access is weaker.
This baseline has no counterexample to the explicit-Choi additive-C4
target. It does identify a real exact-versus-approximate distinction:
polynomial approximate implementation does not imply exact finite-gate
implementation of the ideal irrational pure canonical map.

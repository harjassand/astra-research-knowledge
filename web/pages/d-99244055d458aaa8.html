Claim: For every integer d≥2, the source constructs two matrices A_1,A_2 over F_2 with 2d+1 input coordinates and d columns such that rank(A_1)=rank(A_2)=rank(A_1+A_2)=d. At x_0=e_0 the 2×d matrix F(x_0) has rank 1; changing any one binary coordinate yields rank at most 1 (the e_0 flip yields zero), while the two-coordinate move x=e_0+e_1+e_2 yields rank 2. Thus a single-coordinate rank-ascent rule can stall despite minimum nonzero-combination rank d. The source reports exact script checks for d=2,3,5,8.
Interface: Finite field F_2; a two-output linear matrix map F:F_2^(2d+1)→F_2^(2×d), for each d≥2. The obstruction is only to procedures whose next move changes one input coordinate at a time while seeking a larger rank.
Proof spine: Use the explicit coordinate generators F(e_0)=E, F(e_j)=E+e_2e_jᵀ, and F(eʹ_j)=E+(e_1+e_2)e_jᵀ, with E=e_1e_1ᵀ, j=1,…,d. Direct row inspection gives rank d for each nonzero A-combination; evaluating at e_0 and each Hamming-neighbor gives rank at most one, whereas the displayed two-coordinate move has rank two.
Costs: The witness dimension is 2d+1 by d with two constraint matrices; the source includes exact finite checks for d=2,3,5,8. No algorithm benchmark or asymptotic runtime comparison is supplied.
Failure: This falsifies only single-coordinate rank-ascent for the stated family. A two-coordinate escape is explicit. It is not a lower bound against multi-coordinate or global algorithms, a hardness result, or a failure of dual-kernel sampling.
Closest comparator: The source screens a separate pivot-chart construction against the established LLD triangular argument and does not claim it as novel. This counterexample addresses a local coordinate-update heuristic, not that established chart theorem or all rank-acquisition methods.
Open verification: Check the symbolic ranks for all d≥2 and the listed finite witnesses; make sure downstream use concludes only that single-coordinate ascent may stall, without inferring general rank-certification hardness.

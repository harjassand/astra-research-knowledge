C03_L02 REVISION R03 — exact terminalization criterion and remaining universal gate
7 October 2026 UTC. Earlier checkpoints remain immutable.

NEW EXACT LEMMA: WHEN AN INTERLEAVED FILTER CAN BE DEFERRED
Let P_j be even projectors supported on disjoint two-mode registers S_j. Suppose a postselected circuit branch is a product of Gaussian one-particle gates G_t and these P_j, and every Gaussian gate occurring after P_j has support disjoint from S_j (the register measured by P_j is retired and never reused). Then each P_j commutes with all later gates and with all other P_i, so the branch operator can be written

  (product_j P_j) G_total,

with G_total the product of all Gaussian gates in their original order. This identity is exact; it introduces no success-probability approximation. If branch-dependent classical corrections are selected by fixing a successful measurement transcript, substitute those fixed Gaussian corrections before combining the Gaussian gates. For fermions, even P_j commute with disjoint-mode even Gaussian operators, so there is no hidden Jordan–Wigner sign.

This is a useful sufficient condition for converting an interleaved charge-measurement protocol into one terminal product of hard projectors. The four-mode witness from r01 shows why the retired-register hypothesis matters: a later mode swap touching the measured site invalidates the commutation step.

APPLICATION AND THE OPEN GATE
The hard site projector P_hard=P_0+P_1 is exactly the grouped “not doubly occupied” charge outcome discussed by DiVincenzo–Terhal. Their primary-source discussion says grouped P_{0,1}/P_2 measurements can participate in a nondeterministic universal scheme, whereas exact zero-failure universal implementation is ruled out for that measurement class. So a conceivable route is to recast a postselected universal FLO+charge circuit using only fresh/retired detector registers, then apply all its P_{0,1} branch filters in one terminal layer. This is stronger than the simple source substitution and remains consistent with Knill's FLO simulation boundary because P_hard is non-Gaussian.

This route is not yet a reduction. The cited universal schemes do not, by themselves, establish that (i) every required successful gate transcript can be selected using only the P_{0,1} terminal outcome at each target site, (ii) all detector registers can be consumed without later reuse while preserving the data branch, (iii) corrections can be fixed or classically decoded from the final occupation sample, (iv) the Gaussian resource is in the target's opposite-spin pair form with exactly the desired canonical sector, or (v) the selected branch has an explicit rational lower bound suitable for the rare-herald filter. A static compiler must prove these statements simultaneously. The exact terminalization lemma only says what such a compiler must arrange.

A schematic candidate architecture would use a gate-teleportation/cluster resource so all non-Gaussian charge filters act on retired ancillary pairs, with the data encoded so P_hard is the identity on its protected code. The full Gaussian preparation, teleportation resource and fixed-success Gaussian branch would have to collapse to one explicitly rational pair matrix F_x. No gadget diagram, branch matrix or cost ledger for that architecture is claimed here.

Consequently the strongest supported conclusion is:
1. The literal bosonic R-buncher has no fermionic counterpart (exact zero).
2. Directly treating all passive signal mixing as a disjoint bipartite easy case is too broad; overlapping site labels make the final P active.
3. Interleaved charge measurement plus FLO has known nondeterministic computational power, so the active P could carry the missing nonlinearity.
4. Static transfer is precisely an unresolved terminalization/compiler and positive-herald-bound problem. The commuting witness rules out naive reordering only.

No source supports a universal impossibility theorem for static projected BCS sampling, and no PP=BPP transfer is established. The filter, O(R)-rail readout, and exact Pauli obstruction remain as recorded in INITIAL. This revision identifies a constructive route worth testing but does not claim that it works.

# Bounded-vector mean to Gaussian: complete reconstruction and novelty stop

Status: internally reconstructed real-arithmetic theorem; direct FORS specialization;
no fresh scientific capability established. This file records the useful operation
without claiming that it is a new result. Literature was checked on 2026-10-12.

## Exact interface and output claim

An acquisition oracle returns independent samples of a vector X in R^d with
||X||_2 <= R almost surely, for a known certified R. Write mu = E X. Neither mu
nor a representation of the oracle law is supplied. A single acquisition costs
C_X, including the generation and reading of all d coordinates. Sampling Gaussian
and uniform real variables and exact arithmetic are explicit computational
primitives for the theorem.

For every 0 < epsilon < 1, an algorithm returns Y whose **entire law** satisfies

    TV(Law(Y), N(mu, I_d)) <= epsilon.

Expected oracle acquisitions are at most 2 e^2 m, expected arithmetic is O(dm),
and working memory is O(d), where one explicit valid choice is

    s = 1 + R^2,
    L = log(64s/epsilon),
    m = ceil(64sL).

Consequently acquisition-inclusive expected time is
O((C_X + d)(1+R^2) log((1+R^2)/epsilon)). The oracle-count bound has no d factor;
vector reading, Gaussian generation, inner products, and output writing do.
When R=0, output N(0,I_d) directly with no oracle acquisitions.

## Algorithm

Independently generate m accepted factors. For each factor, repeatedly:

1. Propose y ~ q_m = N(0, I_d/m).
2. Draw J ~ Poisson(2).
3. Acquire J fresh independent oracle samples X_1,...,X_J.
4. Set h_j = clip_[−1,1](<y,X_j>) and accept y with probability

       A = product_{j=1}^J (1+h_j)/2.

   The empty product is 1.

Return the sum of the m accepted y's. The sampler never evaluates mu.

## Acceptance identity: positivity and termination are proved

Define

    w(y) = <y,mu>,
    w_hat(y) = E_X clip_[−1,1](<y,X>).

Every acceptance factor lies in [0,1]. Conditional on a proposed y,
independence gives

    E[A | y,J] = ((1+w_hat(y))/2)^J.

The Poisson probability generating function therefore gives

    P(accept | y) = exp(w_hat(y) − 1).

Thus the accepted density is exactly

    p_hat_m(y) = q_m(y) exp(w_hat(y)) / Z_hat,
    Z_hat = E_q exp(w_hat(y)).

Since |w_hat| <= 1, Z_hat >= e^(−1), so every trial succeeds with probability
a = e^(−1) Z_hat >= e^(−2). Each trial acquires E[J]=2 samples. If Q is the
expected remaining acquisitions, the independent-trial recurrence is

    Q = 2 + (1−a)Q,

so Q=2/a <=2e^2. This does not assume that J and the trial's success are
independent. The recurrence only uses independence of the next fresh trial.

Termination is almost sure. A capped implementation can allocate a separate
failure probability, but the stated expected-cost theorem does not need a cap.

## Full-law approximation, including explicit constants

The unclipped tilted density is

    p_m(y) = q_m(y) exp(w(y)) / Z,
    Z = exp(||mu||^2/(2m)) >= 1.

Completing the square shows p_m=N(mu/m,I_d/m). We now compare p_hat_m to p_m
without replacing <y,X> by the much weaker deterministic bound R||y||.

Let tau(t)=(|t|−1)_+ and delta(y)=w(y)−w_hat(y). Jensen gives

    delta(y)^2 <= E_X tau(<y,X>)^2.

If m>=R^2, then E_q exp(2w)=exp(2||mu||^2/m)<=e^2, and
exp(2w_hat)<=e^2. The elementary inequality

    |exp(a)−exp(b)| <= |a−b|(exp(a)+exp(b))

and Cauchy–Schwarz imply

    A_1 := E_q |exp(w)−exp(w_hat)|
         <= 2e (E_{q,X} tau(<y,X>)^2)^(1/2).

Conditional on X=x, with y independent of X,

    G=<y,x> ~ N(0,sigma_x^2), sigma_x^2=||x||^2/m<=R^2/m.

For sigma>0, exponential Markov and the Gaussian moment generating function give

    E[G^2 1{|G|>1}]
      <= exp(−1/(4sigma^2)) E[G^2 exp(G^2/(4sigma^2))]
      = 2 sqrt(2) sigma^2 exp(−1/(4sigma^2)).

The zero-variance case contributes zero. Because tau(G)^2<=G^2 1{|G|>1},

    E_{q,X} tau(<y,X>)^2
      <= 2 sqrt(2) (R^2/m) exp(−m/(4R^2)).

Consequently

    A_1 <= 2^(7/4) e sqrt(R^2/m) exp(−m/(8R^2))
         <= 10 exp(−m/(8R^2)).

Normalization costs no additional exponential factor: |Z−Z_hat|<=A_1 and

    TV(p_m,p_hat_m)
      <= (1/2)(A_1/Z + |Z−Z_hat|/Z)
      <= A_1/Z <= A_1.

For independent factors, product-TV subadditivity followed by contraction under
the sum map yields

    TV(Law(sum_{i=1}^m Y_i), N(mu,I_d))
      <= sum_i TV(p_hat_m,p_m)
      <= 10m exp(−m/(8R^2)).

This is a full-distribution argument, not a moment or observable calculation.
No selected-range truncation, signed acceptance, unknown density evaluation,
conditional sampler, or unproved Bernoulli factory is used.

For the explicit m above, m>=R^2 and m<=65sL. Also m/(8R^2)>=8L. Therefore

    10m exp(−m/(8R^2)) / epsilon
      <= (650/64) L exp(−7L)
      <= (650/64) exp(−6L) < 1,

where L>=log64 and L<=exp(L). The proposed m is sufficient. The code instead
finds a smaller integer satisfying the same proved inequality on its decreasing
branch m>=8R^2; it does not infer m from empirical diagnostics.

## Closest comparator: novelty is not established

The positive Poisson product rule is FORS Algorithm 1/Theorem 3.1 in
[Chen, Chewi, Daskalakis and Rakhlin, arXiv:2602.01338v2](https://arxiv.org/html/2602.01338v2).
More decisively, their later paper
[High-accuracy log-concave sampling with stochastic queries, arXiv:2602.14342v2](https://arxiv.org/html/2602.14342v2)
already proves high-accuracy stochastic-gradient sampling. Its Theorem 3.2
allows Gaussian tilts of a linear potential, so set f(y)=−<mu,y>, gradient
oracle −X, x_0=x_hat=0, and approximate-proximal tolerance R. The gradient's
Holder constant is zero, removing the dimension term. Bounded noise satisfies
the required light-tail condition. Small-factor convolution is elementary.
Their Proposition 4.1 also treats the unknown Gaussian-mean lower-bound case
and shows the bounded-variance accuracy obstruction.

The correct strongest matched baseline is that stochastic FORS theorem
specialized to the same acquired oracle, not ordinary sample-mean plug-in or
uncorrected stochastic-gradient Langevin dynamics. This reconstruction does
not establish an asymptotic improvement over that baseline.

| Method | Acquired inputs | Oracle samples for one output | Precision/error mechanism | Extra arithmetic/memory |
|---|---|---:|---|---|
| Sample mean plus independent N(0,I) | Same iid bounded vector oracle | O(R^2/epsilon) sufficient by second-order smoothing cancellation | Gaussian convolution error O(R^2/n) | O(dn) / O(d) |
| General stochastic FORS, linear-tilt specialization | Same oracle, known R | Poly(R,log(1/epsilon)), dimension-free in this specialization | Positive exponential factory plus clipped small Gaussian factors | O(dm) / O(d) |
| This explicit reconstruction | Same oracle, known R | <=2e^2 m in expectation | Entire-law bound 10m exp(−m/(8R^2)) | O(dm) / O(d) |

The first row is a useful intuitive contrast, but it is not the strongest
literature comparator. No universal lower bound against all sample-mean
postprocessing schemes is claimed here.

For completeness, the first row follows by Taylor expansion of the standard
Gaussian density around the true mean. For D=sample_mean−mu, E D=0 and
E||D||^2<=R^2/n. In every unit direction v, the L1 norm of the second
directional derivative of the Gaussian density is E|Z^2−1|<=2, where Z is
standard normal. The linear Taylor term cancels after expectation, the
integral remainder has weight integral_0^1(1−t)dt=1/2, and TV adds a factor
1/2. Hence TV(Law(sample_mean+G),N(mu,I))<=R^2/(2n).

## Acquisition and precision ledger

- Known R is a substantive input promise. Finite observed samples cannot certify
  an almost-sure bound for an arbitrary unknown distribution. A scientific source
  must derive it from the measurement/model interface, or pay for its verification.
- iid acquisition includes simulator/measurement setup, burn-in where applicable,
  and generation/read cost C_X. A correlated trajectory is not the promised oracle.
- No law learning, mean learning, hidden representation, or decoder is supplied.
  Preprocessing chooses m using only R and epsilon, in O(log m) scalar steps.
- Each proposal generates d Gaussian coordinates. Each oracle sample requires a
  d-coordinate inner product and norm check in the diagnostic implementation.
- Expected acquisitions are <=2e^2m. Expected Gaussian vectors/proposals are
  <=e^2m. Working memory is O(d) when factors are accumulated online. Output is d
  real coordinates, so writing it costs at least Omega(d).
- The theorem is in an ideal random-real/arithmetic model. A float vector has
  finite support and TV distance 1 from a continuous Gaussian. A deployment must
  specify rounded-target output or an exact-real random-bit representation and
  prove its arithmetic acceptance error. That bit-level gate is not closed by
  this Python implementation.
- If the acquired X is independently rounded with ||X_tilde−X||<=eta almost
  surely, then the procedure targets mu_tilde=E X_tilde. Pinsker bounds
  TV(N(mu_tilde,I),N(mu,I))<=eta/2. This controls oracle rounding bias only;
  it is not a complete numerical-analysis proof for Gaussian/probability generation.

## Evidence and missing gate

`gaussian_factory.py` is runnable. Its 1D diagnostics use exact finite-support
oracle laws whose means are hidden from the sampler. They include symmetric and
skewed boundary distributions, a rare positive spike, and a deterministic
boundary. Independent quadrature evaluates the ideal one-factor density;
empirical mean, variance, KS, and acquisition counts are auxiliary diagnostics.
Neither finite tests nor quadrature certify all-law TV; the derivation does.

The recorded run `python3 gaussian_factory.py --diagnostics --samples 1000
--epsilon 0.01` used seed 20261012 and m=92 in each R=1 case. The analytic
total-TV upper bound was 0.0093196862. Acquisitions per factor were 5.400,
5.417, 5.469, and 5.413, respectively, below the proved upper bound 2e^2.
Empirical KS distances were 0.0159, 0.0246, 0.0239, and 0.0323; these
include sampling noise and are not error certificates. Independent factor
quadrature makes the clipping effect visible before the bound becomes small:
for the deterministic boundary law its one-factor TV is about 0.1763 at
m=1, 0.01164 at m=4, and 4.97e-6 at m=16. Numerical values near 1e-16
are at the floating-point floor and should not be interpreted as validated
accuracy at that scale. The symmetric boundary law has w_hat=w=0 exactly
by oddness, so its factor is an exact centered Gaussian in the ideal model.

The mathematical operation is useful: it generates a Gaussian-smoothed unknown
mean without estimating the mean to epsilon accuracy. But the mechanism and
its general stochastic-oracle setting are already in primary 2026 literature.
The decisive missing gate for a **fresh major opening** is an advantage beyond
that comparator on an acquisition-realistic scientific task. This branch has
not produced one. Arbitrary covariance whitening, adaptive conditional kernels,
and the bounded-variance lower-bound boundary are not safe novelty claims by
themselves; the same paper must be tested first.

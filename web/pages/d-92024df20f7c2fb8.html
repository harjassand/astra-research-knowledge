TARGET AND SUPPLIED DATA

full-domain EB channel Lambda with uniform half reconstruction error bounded
by a function f_C(b)->0, independently of dimension, reference spectrum,
number of labels, Kraus count and output correlation.
No input label is supplied to Lambda. Acquisition and computation are not
bounded. The sequence version permits arbitrary finite dimensions H_n.

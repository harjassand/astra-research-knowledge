# Capacity decomposition without coefficient dynamic-range dependence

Release family 077, exact commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`.
Source read in full: OpenAI, *Diagonal Fourier extension for positively
curved surfaces in three dimensions*, September 24, 2026, all seven source
sections, main file and bibliography. Exact source root:
https://github.com/openai/math/tree/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/Diagonal-Fourier-extension-for-positively-curved-surfaces-in-three-dimensions-September-24-2026/build

This note isolates Lemma 3.2 (capacity decomposition) and extends its
positive-energy exponent. The proof below has no dependence on the
claimed sharp packet or Kakeya theorems. The global restriction theorem
remains conditional in this investigation on independently validating
those inputs. This is a derived reusable lemma, not a priority claim.

## Exact abstract question and interface

Let T₁,…,Tₙ be measurable sets, each of measure v>0, and let weights
wᵢ>0. Write

```
H_w = Σ_i w_i 1_{T_i},      m(w)=v Σ_i w_i.
```

There is a fixed family of tests τ. Each test selects a subset S_τ of
the n indices and has a weight W_τ≥v. Assume:

1. The union of Tᵢ for i∈S_τ has measure at most C_geo W_τ.
2. For each i there is a test selecting i with W_τ=v. It may select
   other indices too; this still gives the required singleton lower bound.

For coordinate subarrays u of w define

```
K(u) = sup_τ m(u restricted to S_τ)/W_τ.
```

Thus K is monotone under coordinate restriction and, for D=max_i wᵢ,
`D ≤ K(w) ≤ nD`. Suprema need not be attained. All counts and norms
are finite; if ∫H_w^r is infinite the following energy bound is automatic.

**Derived theorem.** For any fixed r>1, w decomposes into disjoint
coordinate subarrays u¹,…,uᴶ such that

```
J ≤ min(n, 2+floor((1+1/(r-1))log₂ n)),
Σ_j m(u^j) K(u^j)^{r-1}
    ≤ [4^{r-1} C_geo^{r-1}+1] ∫ H_w^r.
```

The constant depends on r and geometry but not on the ratio of the
largest to smallest nonzero weight. At n=1, a single piece suffices.
This abstract statement contains the release's tube/ellipse lemma up
to its fixed π normalization, with r=3/2.

## Complete derivation

For a bundle q selected by a test τ from a remainder, positivity and
Hölder imply

```
∫ H_q^r ≥ [∫H_q]^r / |supp H_q|^{r-1}
         ≥ C_geo^{1-r} m(q) [m(q)/W_τ]^{r-1}.      (1)
```

Set A=D/n^{1/(r-1)}. Start with the full remainder. While K(remainder)>A,
select a test with density ρ=m(q)/W_τ≥K(remainder)/2 and remove all
selected nonzero entries. Such a test exists by the definition of the
supremum, and at least one entry is removed. Therefore no more than n
nonempty bundles are extracted. Stop with remainder u* satisfying
K(u*)≤A, allowing u*=0.

Group extracted bundles by the dyadic interval `[λ,2λ)` containing
the capacity of the remainder before extraction, with λ=2^k A.
Let u_k be the union of bundles assigned to a level. It is a coordinate
restriction of the first remainder at that level, so K(u_k)<2λ.
Every bundle q there has ρ≥λ/2. Additivity of m gives

```
m(u_k)K(u_k)^{r-1}
 ≤ (2λ)^{r-1} Σ_{q at k}m(q)
 ≤ 4^{r-1} Σ_{q at k}m(q)ρ(q)^{r-1}
 ≤ 4^{r-1} C_geo^{r-1} Σ_{q at k} ∫H_q^r.
```

The extracted bundles have disjoint coordinate supports, so their
positive functions sum pointwise to at most H_w. Since r>1,
`Σ_q H_q^r ≤ (Σ_q H_q)^r ≤ H_w^r`. Summing the last display bounds
the total extracted-level cost by
`4^{r-1} C_geo^{r-1}∫H_w^r`.

The remainder cost obeys

```
m(u*)K(u*)^{r-1} ≤ vnD A^{r-1} = vD^r ≤ ∫H_w^r,
```

because the largest original entry contributes D1_{T_i} to H_w, with
|Tᵢ|=v. No lower bound on the remaining coefficients is needed.

All extracted remainder capacities are in `(A,nD]`. The ratio of these
endpoints is `n^{1+1/(r-1)}`, giving at most
`1+floor((1+1/(r-1))log₂ n)` occupied levels. Add the nonzero remainder
to get the stated J bound. The number of nonempty output pieces also
cannot exceed n. This proves both assertions.

The stopping threshold's n exponent is chosen to charge the entire
small-capacity remainder to one largest original coefficient. It is
not obtained by bounding log(D/min wᵢ), and does not change when an
additional coefficient is extremely small.

## Linear oscillatory transfer, with homogeneity retained

Suppose coefficients aᵢ are complex, wᵢ=|aᵢ|², and a linear map T
satisfies an arbitrary-subarray estimate into a normed output space B:

```
||T a||_B^{2r} ≤ C_osc m(|a|²) K(|a|²)^{r-1}.       (2)
```

Apply the decomposition to |a|² and restrict a to the resulting
disjoint supports. The triangle inequality and finite Hölder yield

```
||T a||_B^{2r}
 ≤ J^{2r-1} Σ_j ||T a^j||_B^{2r}
 ≤ C_osc J^{2r-1}
   [4^{r-1} C_geo^{r-1}+1] ∫ H_{|a|²}^r.           (3)
```

The powers matter: for r=3/2 the linear norm exponent is 3 and the
grouping loss is J², exactly the log² cost in the release's
Proposition 3.3. Writing J^{r-1} here would violate the actual
coefficient homogeneity and underestimate the triangle-inequality cost.
Equation (2) must hold for arbitrary complex arrays on the full legal
support, including every coordinate subarray; an estimate only for
coefficient arrays acquired from a particular analysis map does not
automatically suffice.

For the release, T is synthesis followed by terminal packet sampling,
C_osc=N^{10κ+η}P(κ,η), B is a weighted ℓ³ output, and r=3/2. Its
positive tube estimate then uses the independently claimed Kakeya
maximal result. The abstract decomposition does not itself prove
that Kakeya estimate or the oscillatory array bound (2).

## Source-specific dependencies and costs

The diagonal manuscript's Theorem 1.1 claims Lᵖ(Σ)→Lᵖ(R³) for every
p>3 on a fixed compact smooth positively curved surface, including
smooth boundary. Its proof actually obtains L³ input→Lᵖ output on
each fixed graph chart. The two decisive supplied inputs are:

* The sphere companion's Theorem 6.4, finite packet propagation:
  `A_m(T_m d)^3 ≤ C m^{10κ+ε}G(d)^3`, for arbitrary finite complex
  arrays, coordinate masks, fixed phase/windows/frequency region and
  polynomial complexity `m≤N≤m^B`, positions ≤m^B for a fixed B.
* Family 074, 3D Kakeya maximal Theorem 1.1:
  `||K_ρg||_{L³(S²)} ≤ M(s)ρ^{-s}||g||₃`, for every s>0.

The source packet interface in Section 6.1 explicitly permits labels
in the continuation's transition annulus. Thus the diagonal paper's
Lemma 2.1 can insert an arbitrary elliptic graph germ there by matching
its two-jet, cutting off a cubic remainder, and altering the nonradial
spherical continuation cutoff. A simple domain mismatch is not a
valid objection to this transfer at this pinned version. The actual
remaining obligation is the packet theorem's proof, including its
near-extremal path/time law and geometric capacity estimate.

I read the sphere source Section 6.1 through Theorem 6.4 in full, and
targeted Section 7 portions (time pruning, leaf selection, conditional
time law, terminal capacity/mass and contradiction). I did not read or
independently reconstruct its complete geometric Sections 2–5 or all
quartic packet estimates. The sphere theorem therefore remains an
unchecked dependency here. Kakeya's full proof was not read.

The diagonal paper's elementary sparse-ball argument was read in full:
it discards resonant frequency area O(μ²⁴), costs O(μ¹⁶) in output
L∞, and uses a smooth unrestricted TT* operator to avoid differentiating
the rough excision boundary. Sparse families contain at most μ⁻⁸ balls,
radius R≥μ⁻¹⁰⁰, mutual distance at least μ⁻⁴⁰R. The cover requires no
diameter bound. These details prevent a superficial objection based on
large spatial translations or rough L³ data.

For τ=p−3 and θ=10⁻⁶τ², its stated global constant is bounded by
`C(Σ) τ^{-7/p} P_Σ(θ,θ)^{1/p} M(θ)^{3/(2p)}`. Only finiteness of P
and M at each positive loss is supplied. Therefore a polynomial rate
in 1/(p−3), a strict p=3 endpoint, or efficient computability of these
constants is not established by the stated estimate. Its elementary
lower bound `c(Σ)(p−3)^{-1/p}` excludes a uniform strong endpoint.

The greedy decomposition is constructive with a capacity oracle. A
finite test family can be exhaustively queried; that implementation
cost is separate from J. Continuous ellipse-capacity acquisition is not
made computationally cheap by the logarithmic piece count.

## Obstruction, prior art, use, and falsifiable continuation

The geometric support-volume upper bound is load-bearing. A one-atom
counterexample with |T₁|=1, w₁=1 and a test weight W=ε instead of 1
has K=1/ε and cost ε^{-(r−1)}, while ∫H^r=1. Thus an arbitrary
unrelated "capacity" cannot replace the legal geometric tests.

The closest cited primary restriction result is Wang–Wu,
arXiv:2411.08871v3, Theorem 0.2, with p>22/7. Its v3 submission date is
December 19, 2024, verified from the arXiv submission history. This is
the closest cited comparator, not a claim that no later primary result
exists. The full novelty search for the abstract r>1 lemma is unfinished;
greedy density grouping and sparse epsilon removal have substantial
older precedents. Treat this as an extracted and extended proof tool.

Concrete downstream use: whenever an oscillatory estimate (2) is proved
with a maximal concentration cost, (3) converts it into a positive-energy
bound without paying for coefficient dynamic range. This is a portable
route from uniform finite-array estimates to estimates for rough data,
provided the test geometry really controls the support volume.

Best next scientific allocation: reconstruct the sphere companion's
quartic estimate and root-conditioned time-law-to-geometric-capacity
step, rather than rechecking the now elementary density conversion.
Those are the remaining places that could invalidate the sharp
restriction consequence. A separate useful test is to identify a
different packet geometry satisfying the abstract assumptions and prove
its version of (2); the decomposition then transfers automatically.

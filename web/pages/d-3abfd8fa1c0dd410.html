Cycle 4 renewal terminal prediction: hazard boundary, explicit code, and age-only UNKNOWN

Status
======

For the stationary finite-mean renewal class, the terminal one-step expected-KL minimax rate is source-reported as Theta(n^{-1/2}) by Han, Jiang and Wu, arXiv:2404.15454v1, Theorem 4. This package gives an explicit normalized finite-block type code with pointwise redundancy O(sqrt(n)), proves its stationary left-residual/right-censor domination, and derives a polynomial-time (high-degree) prefix-marginal DP needed to implement the source's reverse-suffix predictor. This provides an internally derived candidate predictor attaining the source upper rate from one raw path. The HJW minimax lower bound remains cited/source-reported, not independently reconstructed here. The simple empirical age-only hazard plug-in is not proved: a fixed Beta smoother is refuted exactly below. Novelty, independent proof review, and implementation performance are UNKNOWN.

Interface and exact target
=========================

Let W_i iid~mu on {1,2,...}, with unknown finite mean m. Define s_r=P(W>=r), so m=sum_{r>=1}s_r. The stationary renewal path has renewals at T_0,T_0+W_1,... with P(T_0=r)=s_r/m. We observe one stationary binary path X_1,...,X_n, with X_t=1 exactly at renewals. There is no reset, support/tail/mean bound, or observation-bit noise. The endpoint loss is

  R_n(q,mu) = E_mu[ KL( Ber(p_mu(X^n)) || Ber(q(X^n)) ) ],
  p_mu(x^n)=P_mu(X_{n+1}=1 | X^n=x^n),

with natural logarithms. This is expected terminal conditional KL, not pathwise realized code regret and not average-over-time prediction loss.

If event locations are 1<=r_1<...<r_J<=n, complete gaps are g_j=r_{j+1}-r_j and terminal age/censor is c=n-r_J. Then

  P_mu(X^n=x^n) = (s_{r_1}/m) (product_{j<J} mu(g_j)) s_{c+1}.             (1)

The first factor is the left-censored stationary residual; it is not mu(r_1). The last factor is the right-censored terminal gap. When J>=1, the true terminal event probability is the ordinary renewal hazard

  h_mu(c)=mu(c+1)/s_{c+1}.                                               (2)

On the all-zero path, the initial residual is censored instead, and

  p_mu(0^n)=P(T_0=n+1 | T_0>n)=s_{n+1}/sum_{r>=n+1}s_r.                  (3)

In general (3) differs from h_mu(n); for mu=(delta_{n+1}+delta_{n+2})/2, the two values are 2/3 and 1/2. This is the stationary boundary correction. Equation (1) follows by multiplying the initial residual mass, the iid complete gaps, and the survival of the terminal interval. Appending 1 replaces s_{c+1} by mu(c+1); appending 0 replaces it by s_{c+2}. If no event is seen, P(0^n)=sum_{r>=n+1}s_r/m and the append-1 mass is s_{n+1}/m.

Observed age-risk counts and the direct plug-in failure
======================================================

Each complete gap g supplies one observed hazard trial at every age a=0,...,g-1: a zero for a<g-1 and a one at a=g-1. The terminal censored age c contributes observed zeros only at a=0,...,c-1; it supplies no trial at the requested age a=c because X_{n+1} is unseen. Thus for event-containing paths,

  S_a = sum_{j<J} 1{g_j=a+1},
  N_a = sum_{j<J} 1{g_j>=a+1} + 1{c>=a+1}.                             (4)

The initial residual contributes likelihood s_{r_1}/m (or sum_{r>n}s_r/m for 0^n); it is not an iid mu-gap observation. A natural KT hazard table q_a=(S_a+1/2)/(N_a+1), with fallback 1/2 when N_a=0, has an exact constant-risk counterexample. Take mu_n=delta_{n+1}. Then T_0 is uniform on {1,...,n+1}; the length-n sample has one event at r<=n or is all zeros, with each of the n+1 phase words having probability 1/(n+1). Every sample contains no complete post-event gap, and at the requested terminal age the right-censored interval supplies no trial. On event paths h_mu(a)=0; on 0^n, (3) is 1. The KT rule predicts 1/2 in both cases, so

  R_n(q^KT,mu_n) = (n/(n+1)) log 2 + (1/(n+1)) log 2 = log 2.       (5)

Any fixed Beta(alpha,beta) fallback q=alpha/(alpha+beta) has limiting risk -log(1-q)>0 on this family. This refutes fixed smoothing plus complete-gap counts; it does not refute n-dependent smoothing, use of the residual likelihood, or all hazard estimators.

Explicit finite-block code and proof
====================================

For a horizon N let p(s) be the integer-partition count and T_N=sum_{s=0}^{N-1}p(s). Give the all-zero word mass Q_N(0^N)=1/2. For every nonzero word let C=(c_j) count its complete gaps of length j, S=sum_j j c_j, R=sum_j c_j, and set

  Q_N(x^N) = [1/(2 T_N)] [ product_j c_j! / ((N-S) R!) ].              (6)

Here S<=N-1. For a given type C there are exactly (N-S)R!/product c_j! words: permute the R gaps and choose the first event location from 1 to N-S. Hence each type has mass 1/(2T_N); (6) plus the zero atom is normalized.

For a nonzero word, let r=r_1 and c=N-r_J, so r+c=N-S. Monotonicity of survival and m=sum s_j imply m>=r s_r and m>=(c+1)s_{c+1}; hence

  s_r s_{c+1}/m <= min{s_{c+1}/r,s_r/(c+1)}
                  <= 1/max{r,c+1} <= 2/(N-S+1).

For R>0, the multinomial probability at the empirical type is at most one:

  (R!/product c_j!) product_j(c_j/R)^{c_j} <= 1.

Therefore product_j mu(j)^{c_j} <= product_j(c_j/R)^{c_j} <= product_j c_j!/R!. For R=0 use product 1. Applying (1),

  P_mu(x^N) <= 2 product_j c_j! / ((N-S+1)R!)
            <= 4 T_N Q_N(x^N).

The all-zero likelihood is at most one and Q_N(0^N)=1/2. Thus every stationary finite-mean renewal law obeys the pointwise redundancy bound

  max_{x^N} log(P_mu(x^N)/Q_N(x^N)) <= log(4T_N).                      (7)

Since T_N=sum_{s<N}p(s), the partition generating function (or Hardy-Ramanujan) gives log T_N=O(sqrt(N)). No mean/tail bound is used.

Terminal predictor and its cost
===============================

Set N=n+1 and use the single joint law Q_N in the reverse-suffix rule

  qhat_n(1|x^n) = (1/n) sum_{t=1}^n q_N(1|x_{n-t+1}^n),
  q_N(b|v)=Q_N(vb)/Q_N(v),

where Q_N(v) is the prefix marginal of this same fixed-horizon joint law. The HJW stationary suffix-averaging inequality gives

  R_n(qhat_n,mu) <= Red(Q_N;P_mu)/n + mem_n(mu).

By (7), Red<=log(4T_N). For clarity, the terminal conversion is not a time-average claim. Put Y=X_{n+1}, V_t=X_{n-t+1}^n, and U_t=X_1^{n-t}. Convexity of KL gives

  E KL(P(Y|X^n) || (1/n)sum_t q_N(.|V_t))
    <= (1/n)sum_t E log[P(Y|X^n)/q_N(Y|V_t)].

Each expectation splits into I(Y;U_t|V_t) and the stationary length-(t+1) conditional KL E_{X^t}KL(P(X_{t+1}|X^t)||q_N(.|X^t)). By the chain rule for this one Q_N joint law, the sum of those n conditional KL terms is KL(P_{X^N}||Q_N) minus the nonnegative first-symbol KL. The renewal countdown representation has stationary hidden state Z_1 with law s_r/m; the HJW hidden-state argument bounds sum_t I(Y;U_t|V_t) by I(Z_1;Y). Truncating Z_1 at n+2 preserves all information about Y (if Z_1>=n+2 then Y=0), so I(Z_1;X_{n+1})<=H(min{Z_1,n+2})<=log(n+2). Consequently

  sup_{mu: E W<infty} R_n(qhat_n,mu)
      <= [log(4T_{n+1})+log(n+2)]/n = O(n^{-1/2}).                       (8)

This meets the source's Theorem 4 upper order, but the output is a predictor from the full raw terminal path, not a plug-in table depending only on the terminal age. No resets, queries, or side information are used.

Computing the required conditionals
===================================

The horizon-specific family Q_N is not projectively consistent: Q_1(X_1=1)=1/2 but Q_2(X_1=1)=3/8. Therefore separately normalizing Q_t for each t is not valid in the suffix formula. The prefix marginals of the one fixed Q_N can nevertheless be computed by a polynomial DP.

For prefix 0^t, direct summation over types and first-event placements gives

  Q_N(0^t)=1/2 + [1/(2T_N)] sum_{S=0}^{N-t-1} p(S)(N-S-t)/(N-S).       (9)

For an event-containing prefix v with event positions r_1<...<r_J, write C_0 for its complete-gap counts, S_0=r_J-r_1, R_0=J-1 and b=t-r_J. The full extensions with no new event contribute

  [1/(2T_N)] product_j c_j! / ((N-S_0)R_0!).                           (10)

For extensions with a new event, choose its gap w=b+1,...,N-r_J and let d_j=c_j+1{j=w}, R_d=sum d_j. If the subsequent complete-gap type is f=(f_j), define L=sum f_j and S=sum j f_j. There are L!/product f_j! orderings of that type. Their total mass, summed over a fixed (L,S), is

  [product_j d_j!/(2T_N)] [L!/(R_d+L)!]
       G_d(L,S)/(N-S_0-w-S),

  G_d(L,S)=[z^L y^S] product_{j=1}^N (1-z y^j)^(-(d_j+1)).            (11)

Sum (11) over S<=N-r_J-w and L, and then over w, and add (10). This is exact: (d_j+f_j)!/f_j!=d_j! binom(d_j+f_j,d_j), whose generating function is the factor in (11).

Compute G_d by a bivariate coefficient DP, convolving for each j with coefficients binom(d_j+f,d_j) at shift (f,jf), and truncating degrees L,S at N. This costs O(N^4) integer arithmetic operations for one w, O(N^5) per event-containing prefix, and O(n^6) for the at most three prefix queries per suffix needed to form all n conditionals. Partition counts use O(N^2) operations. The DP coefficients have O(N) bits; factorial factors and a common denominator for each prefix marginal have O(N log N) bits. Exact ratios q_N(1|v) therefore have O(N log N) bits, while averaging n such ratios may produce O(n^2 log n) bits. Thus a conservative bit-cost with naive integer arithmetic remains polynomial (O(n^10 polylog n)); no empirical speed claim is made. The path scan costs n observed symbols. The checker under `work/programmes/acquisition_learning/cycle4/renewal_direct_hazard/check_renewal.py` verifies the prefix DP against literal extension sums for N<=7.

Matched lower bound and source comparison
=========================================

Han, Jiang and Wu, “Prediction from compression for models with infinite memory, with applications to hidden Markov and renewal processes,” arXiv:2404.15454v1, Theorem 4, state absolute constants c,C>0 with

  c n^{-1/2} <= inf_q sup_{mu: E W<infty} R_n(q,mu) <= C n^{-1/2}.

Their upper argument uses pointwise Shtarkov/NML redundancy Theta(sqrt n), the stationary reverse-suffix conversion (Proposition 1 / Proposition 2.1), and the renewal countdown-HMM memory bound. They explicitly note the NML estimator is computationally inefficient and polynomial-time computation is unclear. Equations (6)–(11) provide an alternative internally derived code and an explicit polynomial prefix-marginal DP, which would make that suffix construction polynomial-time at high degree. This apparent algorithmic strengthening needs independent proof review and priority checking; it is not externally validated here. The source's lower bound is reported, not reproved.

UNKNOWN and failure boundary
============================

The source theorem and (8) settle the minimax terminal expected-KL rate for a raw-path predictor. They do not prove that the age-only empirical hazard (4) with a particular n-dependent smoothing attains the rate. The missing route is a bound on endpoint-selected age risk with the random stopped complete-gap sample, the size-biased initial residual, and right censoring all handled together. A time-averaged risk does not imply this terminal bound absent a separate conversion; (8) uses the source's valid reverse-suffix mixture. Fixed smoothing is ruled out by (5), but this is not an impossibility result for all direct hazard estimators. Independent external verification/novelty review, optimization of the DP, noisy-event observations, and unknown stationarity are outside this package.

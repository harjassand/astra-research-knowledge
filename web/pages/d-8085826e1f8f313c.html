SPECTRAL GEOMETRY — CYCLE 2 LEAF: SO(3) SPHERICAL HARMONICS
Date: 2026-10-08
Status: explicit representation calculation; rank-profile bounds proved below.

SCOPE

This is the rank-one SO(3)=SO(2+1) case, with carrier the degree-N spherical
harmonics on S^2. It is an independent compact-group realization of the
conjugation-Casimir calculation. All spectral multiplicities are one, so
there is no isotypic-multiplicity obstruction in this example. The exact
integrated profile below is a universal lower bound from the projector
partial traces; exact attainment for every Q is not asserted. A matching
order rank-Q energy law is established in the stated small-rank range.

1. CARRIER AND GENERATORS

Let N be a nonnegative integer and let H_N be the restrictions to S^2 of
homogeneous harmonic polynomials of degree N on R^3. Under rotations,

  H_N = V_N,       d_N=dim(H_N)=2N+1.

Use an orthonormal angular-momentum basis |N,m>, -N≤m≤N, and Hermitian
generators J_1,J_2,J_3 with [J_i,J_j]=i ε_ijk J_k. With J_±=J_1±iJ_2,

  J_3|N,m> = m|N,m>,
  J_+|N,m> = sqrt((N-m)(N+m+1)) |N,m+1>,
  J_-|N,m> = sqrt((N+m)(N-m+1)) |N,m-1>,
  sum_i J_i^2 = N(N+1) I.

These conventions agree with the spherical-harmonic angular-momentum
eigenvalue and magnetic-index formulas in NIST DLMF §14.30, especially
Eqs. 14.30.11 and 14.30.11_5. The ladder coefficients are the standard
spin-N representation coefficients.

Define the positive conjugation Casimir on End(H_N) by

  L(X)=sum_{i=1}^3 [J_i,[J_i,X]],
  E(X)=<X,LX>_HS=sum_i ||[J_i,X]||_HS^2.

2. CONJUGATION-CASIMIR DECOMPOSITION AND MULTIPLICITIES

As an SO(3) representation, End(H_N) is V_N⊗V_N^*. Every integer-spin
SO(3) representation is self-dual, and the Clebsch–Gordan rule is

  V_a⊗V_b = direct-sum_{ell=|a-b|}^{a+b} V_ell,

with each summand appearing once. Therefore

  End(H_N) = direct-sum_{ell=0}^{2N} V_ell,   multiplicity m_ell=1,
  dim(V_ell)=2ell+1,
  L|_{V_ell}=lambda_ell I,   lambda_ell=ell(ell+1).

The dimension check is exact:

  sum_{ell=0}^{2N}(2ell+1)=(2N+1)^2=dim End(H_N).

In particular, the multiplicities do not distort the cumulative spectral
dimension. If P_ell denotes the orthogonal projector onto V_ell under
vectorization, then for 0≤K≤2N,

  P_{≤K}=sum_{ell=0}^K P_ell,
  D_K=Tr(P_{≤K})=sum_{ell=0}^K(2ell+1)=(K+1)^2.

3. PROJECTOR PARTIAL TRACES

The projector P_{≤K} commutes with U_N⊗overline{U_N}. Its partial trace
over the second factor commutes with the irreducible representation U_N.
Schur's lemma and the trace identity Tr(Tr_2 P_{≤K})=Tr(P_{≤K}) give

  Tr_2(P_{≤K}) = (D_K/d_N) I_{H_N}
                 = ((K+1)^2/(2N+1)) I_{H_N}.                 (3.1)

Term by term this is also

  Tr_2(P_ell)=((2ell+1)/(2N+1))I_{H_N},

so the scalar partial trace contains the full cumulative multiplicity
profile, with no hidden isotypic blocks.

For ||X||_HS=1, vectorization identifies X with a unit vector of Schmidt
rank rank(X). If rank(X)≤Q, the range projection argument applied to
(3.1) yields

  ||P_{≤K} vec(X)||^2 ≤ min{1, Q(K+1)^2/(2N+1)}.             (3.2)

Because the next Casimir eigenvalue is (K+1)(K+2), (3.2) gives, for
0≤K<2N,

  E(X) ≥ (K+1)(K+2)
          [1-Q(K+1)^2/(2N+1)]_+.                             (3.3)

Integrating the spectral tail, and using lambda_{K+1}-lambda_K=2(K+1),
gives the explicit integrated lower profile

  E(X) ≥ Phi_N(Q)
       := sum_{r=1}^{2N} 2r [1-Q r^2/(2N+1)]_+.              (3.4)

The bracket is zero once Qr^2≥2N+1. Formula (3.4) is the profile supplied
by the general rank/projector argument, not a claim of exact optimizer for
all Q.

4. RANK-Q CONSEQUENCE AND EXPLICIT UPPER WITNESS

For N≥4 and 1≤Q≤floor((2N+1)/8), set

  r=floor sqrt((2N+1)/(2Q)),   K=r-1.

Then r≥2, K<2N, r≥(1/2)sqrt((2N+1)/(2Q)), and
Qr^2/(2N+1)≤1/2. Applying (3.3) gives

  E(X) ≥ r(r+1)/2 ≥ (2N+1)/(16Q) ≥ N/(8Q).                (4.1)

For a matching upper bound, write s=N-m in the magnetic basis and, for
1≤Q≤floor((2N+1)/8), define the diagonal operator

  X_Q |N,N-s> = c(Q-s)|N,N-s>,    0≤s≤Q-1,
                   0,              Q≤s≤2N,

where

  c^{-2}=sum_{s=0}^{Q-1}(Q-s)^2=Q(Q+1)(2Q+1)/6.

Thus rank(X_Q)=Q and ||X_Q||_HS=1. Its J_3 commutator vanishes. Across the
edge joining s and s+1, the squared ladder coefficient is

  (s+1)(2N-s).

For a diagonal operator, the J_1 and J_2 commutators together contribute
this coefficient times |x_s-x_{s+1}|^2 on each edge. Here each nonzero
edge difference is c, so

  E(X_Q)=c^2 sum_{s=0}^{Q-1}(s+1)(2N-s)
        = [6N-2Q+2]/(2Q+1)
        ≤ 3N/Q.                                               (4.2)

Consequently, throughout this explicit range,

  N/(8Q) ≤ inf_{rank(X)≤Q, ||X||_HS=1} E(X) ≤ 3N/Q.

This is a rank-Q energy scale Θ(N/Q) for the SO(3) spherical-harmonic
carrier. It is an energy statement; no heat-plateau, observation-channel,
or information-transfer conclusion is inferred here.

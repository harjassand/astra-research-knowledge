1. ABSTRACT ONE-SIDED GIBBS RECOVERY LEMMA

Let H be finite dimensional, K=K^*, and Phi a unital completely positive
trace-preserving map on B(H). Suppose it is covariant under the K flow:

 Phi(e^(itK) A e^(-itK))=e^(itK) Phi(A)e^(-itK), all t,A.

Suppose the WHOLE output generator drift obeys

                     K-Phi(K)<=delta I, delta>=0.        (1.1)

An operator-norm bound ||K-Phi(K)||<=delta suffices. Define
rho=e^K/Tr e^K, sigma=Phi(rho). Then exactly

 sigma>=e^(-delta)rho,
 (1/2)||sigma-rho||_1<=1-e^(-delta)<=min(1,delta),
 D(rho||sigma)<=delta.                                  (1.2)

No bound on ||K||, dimension, gap, spectral multiplicity or partition
function is assumed. The channel need not be entanglement breaking.
For the storage application below it is an actual fixed coherent EB.

PROOF. Since rho>=lambda_min(rho)I and Phi is unital, sigma>0.
Operator log Jensen gives log Phi(A)>=Phi(log A) for A>0. Here is its
finite resolvent justification: [[A+tI,I],[I,(A+tI)^(-1)]] is positive;
apply the unital CP map to the two-by-two blocks and use the Schur
complement to obtain

 Phi((A+tI)^(-1))>=(Phi(A)+tI)^(-1).

Integrating the standard resolvent formula for log proves Jensen.
Finite dimension and A>0 justify the convergent integral. Therefore

 log sigma>=Phi(log rho)
          =Phi(K)-log(Tr e^K)I
          >=log rho-delta I.                            (1.3)

Covariance is the crucial additional input: rho is invariant under
e^(itK), so sigma is too, and hence [sigma,K]=0. Consequently
[sigma,rho]=0 EVEN WHEN K HAS DEGENERATE EIGENVALUES: rho is scalar on
every K eigenspace. Thus log sigma and log rho commute. Simultaneous
diagonalization makes exponentiating the LAST inequality in(1.3)
valid and gives sigma>=e^(-delta)rho. No general operator-monotonicity
claim for exp is made; it would be false without this commutation.

For delta>0, tau=(sigma-e^(-delta)rho)/(1-e^(-delta)) is a state,
so sigma=e^(-delta)rho+(1-e^(-delta))tau and its half-trace error is
at most1-e^(-delta). If delta=0 the positive difference has zero trace,
so sigma=rho. Finally log is operator-monotone, so the state order
gives log sigma>=log rho-delta I and D(rho||sigma)<=delta.

This improves the trace consequence of the same Jensen entropy bound
from O(sqrt(delta)) to O(delta), by using the exact input-output
commutation rather than Pinsker. The first-order shift bound remains
the load-bearing carrier-uniform input.

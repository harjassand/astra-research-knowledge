# Computational scope and explicit encoding

## Mathematical versus computational claims

The geometric proof is over an algebraically closed field and does not use characteristic zero. Degree bounds have no coefficient-height dependence. The stated effective corollary restricts to rational coefficients and a rational specified initial point, represented exactly. An embedding into an algebraic closure preserves which rational outputs are zero.

The input explicitly lists the n coordinate polynomials of F and the output h in either dense or sparse representation; coefficients and initial coordinates are binary integers or binary numerator–denominator pairs. A sparse representation includes binary exponent vectors. All encoding choices count toward the input length. The degree d is max(1, degree F); a constant or zero output is handled directly.

## A finite exact procedure

1. Handle h = 0, nonzero constant h, or constant F directly.
2. Compute the integer cutoff T_n using the displayed recurrence. Computing Delta_n is unnecessary if only the cutoff is wanted.
3. Evaluate x_0 = a and x_(t+1) = F(x_t) with exact rational arithmetic.
4. Check h(x_t) at every t from 0 through T_n-1. Stop with a nonzero witness if one occurs. If all checked outputs are zero, the candidate theorem certifies all-time zeroness.

This procedure does not need to compute irreducible components or extract the proof's geometric certificate. It is a conceptual finite algorithm and may be astronomically impractical.

## Why bit cost remains primitive recursive

Clear all update coefficient denominators once, using one positive common denominator Q. Write F_j = P_j/Q with P_j having integer coefficients and degree at most d. At time t use a common denominator D_t and integer numerators A_(j,t) for all state coordinates. Homogenizing the P_j to degree d permits D_(t+1) = Q D_t^d without cancellation.

Let H_t be the maximum of 1 and the binary lengths of D_t and all A_(j,t). Let M bound the number of monomials in any P_j and let C bound the binary lengths of Q and all its integer coefficients. The unreduced representation satisfies a conservative estimate

H_(t+1) <= d H_t + C + ceil(log2(M+1)) + 3.

Each monomial can be evaluated by a finite number of integer products and powers; even schoolbook arithmetic, with naive powering if desired, is primitive recursive in H_t, the exponent encodings, and the explicit polynomial size. Output evaluation has the same type of estimate using degree e and the output's coefficient data. Recursing for T_n steps therefore has primitive-recursive bit cost in the encoded input. No height-independent bit-complexity claim is made.

## Growth of the bound

With A = max(16,n+2,d,e), the proof supplies a rough base-A power-tower upper bound of height 2n+1. This is elementary for each fixed n, but the displayed family is not a fixed-height elementary bound as n varies. For rational coefficients and rational initial points, a better undiscovered bound could still be elementary; the upper candidate does not decide that question. The separate cyclotomic lower construction rules out a coefficient-uniform elementary horizon across arbitrary algebraic coefficients, which is a different arithmetic contract.

## Limits of the saved computations

The script evaluates only small examples and ideal-membership identities. Its bound routine is deliberately straightforward and is not intended for large parameters: arbitrary-precision integers still consume finite time and memory. Passing these cases is a consistency check, not a substitute for the symbolic proof or for external validation.

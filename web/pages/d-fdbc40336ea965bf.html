LSI UNDER CONVEX CONDITIONING — INDEPENDENT DERIVATION / PRIOR-ART AUDIT
2026-10-07. Status: complete proof of elementary psi2 conversion and sharpness
example; conditional application of release 093 only. No release proof validated.

DECISION
The proposed log(1/p) conditional LSI conclusion is already exactly Milman's
Corollary 3.9, once the original LSI is available. It is a useful consequence
of a claimed psi2-to-LSI theorem, but not a new conditioning theorem. The loss
is necessary across psi2 logconcave base measures. A ball/cylinder example
below proves necessity by elementary volume and variance calculations.

INTERFACE / DEFINITIONS
Let mu be a probability measure on R^n with mean m0 and
  sup_{|theta|=1} E_mu exp(<theta,X-m0>^2/a^2) <= 2.
Let K be measurable, p=mu(K)>0, nu=mu(. | K), and mK=E_nu X.
Define C_LS(rho) as the best coefficient in
  Ent_rho(f^2) <= C_LS(rho) E_rho |grad f|^2.
Assume release 093's claimed implication, exactly at this interface:
  every centered psi2 logconcave measure with parameter b has
  C_LS <= C_093 b^2, with a universal C_093.
No assertion here verifies that release implication.

1. CONDITIONING AND RECENTERING: ALL DETAILS
Fix a unit theta, Y=<theta,X-m0>, and set
  q = log(2)/log(2/p), b^2=a^2/q.
Then 0<q<=1. Restriction followed by concave Jensen gives
  E_nu exp(Y^2/b^2)
   =E_nu (exp(Y^2/a^2))^q
   <=(E_nu exp(Y^2/a^2))^q <=(2/p)^q=2.
Write h=E_nu Y. Convex Jensen and the preceding estimate imply
  h^2 <= E_nu Y^2 <= b^2 log 2.
Using (Y-h)^2<=2Y^2+2h^2 and concave Jensen again,
  E_nu exp((Y-h)^2/(4b^2))
   <=exp(h^2/(2b^2)) E_nu exp(Y^2/(2b^2))
   <=sqrt(2)*sqrt(2)=2.
Hence the centered conditional psi2 parameter is at most
  2a sqrt(log(2/p)/log 2) = O(a sqrt(log(e/p))).
This conversion needs no logconcavity and holds for every positive-mass
measurable event. The same calculation yields the mean displacement bound
  |mK-m0| <= a sqrt(log(2/p)).
For convex K and logconcave mu, nu is logconcave. Translation preserves its
LSI constant. The assumed release then gives
  C_LS(nu) <= (4 C_093/log 2) a^2 log(2/p).
This is a valid assumption-conditioned corollary; no extra dimension factor
or p^{-1} factor is hidden.

2. PRIMARY PRIOR ART: EXACT MATCH
Emanuel Milman, Properties of Isoperimetric, Functional and Transport-Entropy
Inequalities Via Concentration, arXiv:0909.0207v3; published PTRF 152,
475–507 (2012). Corollary 3.9, PDF page 16 (zero-based 15), states:
if mu1=e^{-V} dx satisfies rho Ent_mu1(f^2)<=E_mu1|grad f|^2,
A is convex, mu1(A)=p>0, and V is convex on A, then mu2=mu1|A/p
satisfies (c rho/(1+log(1/p))) Ent_mu2(f^2)<=E_mu2|grad f|^2.
In this report's coefficient convention,
  C_LS(mu2) <= C_univ C_LS(mu1)(1+log(1/p)).
It applies directly to the desired target, with the base LSI supplied by the
release. Milman's Theorem 3.8 is broader: a logconcave target measure nu
with density dnu/dmu<=D inherits C_LS(nu)<=C C_LS(mu)(1+log D).
Thus convex conditioning is only the D=1/p instance. Convex hard support is
included through the paper's total-variation approximation convention.

3. SHARPNESS: UNIFORMLY PSI2 BALL, CONVEX CYLINDER
For n>=2 put R=sqrt(n+2). Let mu_n be uniform on B_n(R), so it is centered,
isotropic and logconcave. Rotational invariance plus beta integration gives
  E X_1^{2k} = R^{2k}(1/2)_k / ((n+2)/2)_k <= (2k-1)!!.
Thus for every unit theta,
  E exp(<theta,X>^2/4) <= sum_k (2k-1)!!/(4^k k!)=sqrt 2 <=2.
All bases have psi2 parameter a=2, independent of n.

Take the convex, symmetric infinite cylinder
  K_n={x: |(x_2,...,x_n)|<=R/2}.
Let v_j denote unit j-ball volume and L=sqrt(3)R/2. The intersection
B_n(R) cap K_n contains [-L,L] x B_{n-1}(R/2) and is contained in
[-R,R] x B_{n-1}(R/2). Therefore its probability p_n obeys
  sqrt(3) (v_{n-1}/v_n) 2^{-(n-1)}
    <=p_n<=2 (v_{n-1}/v_n) 2^{-(n-1)}.
Since v_{n-1}/v_n=Gamma(n/2+1)/(sqrt pi Gamma((n+1)/2)),
  log(1/p_n)=(n-1)log 2 - (1/2)log n + O(1)=Theta(n).

The unnormalized X_1 density in the intersection is
  w(t)=v_{n-1} min(R/2,sqrt(R^2-t^2))^{n-1}, |t|<=R.
It equals w0=v_{n-1}(R/2)^{n-1} on [-L,L] and is at most w0 everywhere.
Symmetry gives mean zero, while its normalizer Z<=2Rw0. Hence
  Var_nu_n(X_1) >= (w0/Z) int_{-L}^{L}t^2dt
                   >=L^3/(3R)=sqrt(3) R^2/8.
The coordinate f(x)=x_1 has gradient norm 1, so C_P(nu_n)>=this variance.
Linearizing LSI at f=1+epsilon*x_1 gives C_LS(nu_n)>=2 C_P(nu_n).
Consequently
  C_LS(nu_n)>=sqrt(3)(n+2)/4=Omega(log(1/p_n)).
The conditional centered psi2 parameter is also Omega(sqrt n), since
E exp(Z^2/b^2)<=2 implies Var(Z)<=b^2 log 2.
Thus both the sqrt(log(1/p)) psi2 loss and log(1/p) LSI loss are sharp
in order, across dimensions and such base measures.

4. LIMITS / FAILED NOVELTY ROUTE / NEXT ACTION
The failed route is a novelty claim for logarithmic convex-conditioning
stability: the exact conclusion predates the release. The psi2 proof is a
routine restriction-plus-Jensen calculation; the cylinder example is an
independent derivation, with no priority claim for this particular example.
For strongly logconcave bases, convex restrictions preserve the curvature
bound and need not pay log(1/p); the lower example uses general logconcavity.
The dimension-free psi2-to-LSI release remains the only new load-bearing
input. A consequential new target would need a statement exceeding these
known transfer results, or use them as background without claiming novelty.

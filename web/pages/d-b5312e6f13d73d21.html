Leaf 05 — noncommutative-to-commutative PIT
Date: 2026-10-08

Outcome

There is a direct, exact reduction from deterministic noncommutative ABP PIT to commutative PIT for fixed-order read-once oblivious ABPs. The reduction keeps the ABP size and uses the same explicit graph. Its proof is an injective monomial-code argument.

The same-graph lift of a general commutative ABP does not preserve identity: abelianization has a nonzero commutator kernel. More sharply, a determinant gadget whose commutative rank is full exactly when its ABP polynomial is nonzero can have full 2-blow-up rank in both cases. This blocks that specific rank-transfer route. It is not an impossibility theorem for other reductions and does not resolve commutative PIT.

Exact interfaces

1. Positive bridge. Let F be a field. The input is a layered commutative ABP with layers 0,...,n, one edge step per variable x_i, and edge labels a_e + b_e x_i with a_e,b_e in F. The output p belongs to F[x_1,...,x_n]. Its size S counts the explicit vertices and edges. Homogenize each edge to a_e x_0 + b_e x_i and reinterpret the same graph as an ABP over F⟨x_0,x_1,...,x_n⟩. This homogeneous free-algebra lift is zero exactly when p is zero. The input is a white-box graph, not a scalar black-box.

   The lift has the same graph size and polynomially many field operations. Raz–Shpilka deterministic noncommutative ABP PIT then decides p=0 in poly(S,n) field operations. Taking F=F_2 gives poly(S,n) bit operations with no coefficient-height or precision cost. The procedure uses no matrix substitution and has no blow-up dimension parameter.

2. Scoped rank obstruction. Let an arbitrary commutative ABP A compute p, and let q be its same-path free-algebra lift. Thus ab(q)=p. Build a DAG H whose path polynomial is g=qz+ab-ba, where a,b,z are fresh variables. If H has m vertices, topologically order it and let U be its strictly upper-triangular weighted adjacency matrix. Set

       L = [[I_m - U, e_t],
            [e_s^T,     0]].

   L is an affine linear matrix pencil of size m+1 over F. Its commutative determinant is -zp. Therefore its commutative rank is m+1 exactly when p is nonzero, and is exactly m when p=0.

   For every field F, evaluate at blow-up size d=2 with x_i=z=0, a=E_12, b=E_21. Then the path matrix e_s^T(I-U)^(-1)e_t is E_11-E_22, which is invertible (it is I_2 in characteristic 2). Since U is strictly upper triangular, I-U is invertible. The Schur complement shows L(A) is invertible, so its rank is 2(m+1), independent of p. Thus this particular commutative-rank encoding is erased by a size-2 blow-up witness.

3. Minimal natural-lift failure. In F[x,y], p=xy-yx is identically zero. A two-path commutative ABP for p lifts on the same graph to q=xy-yx, which is nonzero in F⟨x,y⟩. At d=1 every scalar evaluation is zero; at d=2, x=E_12 and y=E_21 give q=E_11-E_22, invertible over every field. The failure is exactly ker(ab), not a numerical artifact.

N68 route and boundary

The inherited N68 card is an exact one-query acquisition statement for an s-sparse free polynomial over Q: one full response at matrix dimension 2s, with O(s log(n+1)) bits per query entry and an output-sensitive decoder. The primary ECCC source for sparse NC PIT gives a zero-test tuple at dimension s. Both assume matrix-algebra evaluation; neither is an interface to a commutative scalar-evaluation oracle. A size-O(n) ABP for product_i(1+x_i) already has 2^n path words in its free lift, so N68's dimension can be exponential even on an easy ordered ABP. Its full returned matrix and coefficient/response bits remain charged. The sparse promise therefore does not yield a general circuit-size reduction.

For a commutative sparse polynomial given as an explicit exponent/coefficient list, sorted-word encoding is injective and the sparse NC hitting point gives an abstract legal one-query identity test when the oracle accepts matrix inputs. This is only a representation translation: the explicit sparse list already permits direct coefficient aggregation. Its matrix response must be charged, and the theorem does not extend to an ABP or circuit whose monomials are implicit.

Costs and limits

The positive ROABP reduction preserves S and has deterministic polynomial arithmetic cost; over F_2 the cost is polynomial bit time. The determinant obstruction uses an (m+1)×(m+1) pencil and one 2(m+1)×2(m+1) evaluated blow-up. Its witness is constructed from constant 2×2 matrix units and the ABP graph, with O(m+|E(H)|) block operations; dense materialization would take O(m^2) entries. No numerical conditioning or precision is involved.

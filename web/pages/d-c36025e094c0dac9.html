# Candidate obstruction: low rank does not remove acquisition information

## Interface

Fix integers \(p,q\ge r\ge1\). An unknown \(A\in\mathbb R^{p\times q}\) has rank exactly \(r\). Grant the learner, for free, a known \(r\)-dimensional input frame \(V\in\mathbb R^{q\times r}\), \(V^TV=I_r\), and restrict the hard family to
\[
A_B = B V^T,\qquad B\in\mathbb R^{p\times r},
\]
where \(B\) lies in a small full-rank operator-norm ball. The learner may make \(m\) adaptive scalar linear measurements. Query \(G_t\in\mathbb R^{p\times q}\) may depend on the preceding responses and an independent random seed; response \(Y_t\) is one symbol from an alphabet of size at most \(2^b\). The finite-bit response channel may quantize or add independent noise, but conditional on past transcript and independent randomness it depends on A only through \(\langle G_t,A\rangle\); the exact-real clause returns that scalar without noise. After acquisition, the learner retains a state \(Z\) that is a function only of its transcript and independent randomness. The decoder has no further access to \(A\). It must answer every bilinear task
\[
f_A(a,x)=a^TAx,\qquad \|a\|_2,\|x\|_2\le1,
\]
with simultaneous error at most \(\epsilon\) and failure probability at most \(\delta<1/2\), uniformly over the hard family. The simultaneous post-storage guarantee means tasks can be selected after storage and one state must support the whole stated task class.

## Finite-bit lower bound

Assume \(p\ge q\) and \(\epsilon\le 1/(64\sqrt r)\). Let
\[
B_0=\frac1{2\sqrt r}\begin{bmatrix}I_r\\0\end{bmatrix},\qquad
\mathcal B=\{B_0+H:\|H\|_{\mathrm{op}}\le R\},\qquad R=\frac1{8\sqrt r}.
\]
Every \(B\in\mathcal B\) has rank \(r\), since its least singular value is at least \(1/(2\sqrt r)-R=3/(8\sqrt r)\). Also \(\|B\|_F\le5/8\), so this is a bounded signal family. For \(p<q\), transpose the construction and vary the unknown right factor instead.

The \(pr\)-dimensional normed space \(\mathbb R^{p\times r}\), equipped with operator norm, has a \(4\epsilon\)-packing of \(\mathcal B\) of size
\[
M\ge\left(\frac{R}{4\epsilon}\right)^{pr}
=\left(\frac1{32\sqrt r\,\epsilon}\right)^{pr}.
\]
This follows by the volume bound for a maximal separated set in the operator-norm ball. For any distinct \(B,B'\) in this packing,
\[
\sup_{\|a\|=\|z\|=1}|a^T(B-B')z|=\|B-B'\|_{\mathrm{op}}\ge4\epsilon.
\]
The future task set contains \(x=Vz\), so \(f_{A_B}(a,Vz)=a^TBz\). If two packed inputs led to the same retained state, the decoder would return the same function of \((a,z)\), which cannot be within \(\epsilon\) of both target functions. Thus the retained state identifies the packing point whenever the simultaneous-success event occurs.

Choose the packing index \(J\) uniformly and denote all independent algorithm randomness by \(S\). Since success probability is at least \(1-\delta\), Fano's inequality gives
\[
I(J;Z,S)\ge (1-\delta)\log_2 M-h_2(\delta)
\ge (1-\delta)pr\log_2\!\frac1{32\sqrt r\,\epsilon}-h_2(\delta).
\]
Conditional on \(S\), an \(m\)-round adaptive transcript has at most \(2^{mb}\) paths, so \(I(J;Z,S)\le mb\). Thus both the acquired response budget \(mb\) and any finite retained-state budget \(B_Z\) must be at least the displayed Fano term: if \(Z\) has at most \(2^{B_Z}\) states conditional on \(S\), then \(I(J;Z,S)\le B_Z\). Adaptivity and unbounded computation do not change either bound. For \(p<q\), replace \(pr\) by \(qr\). Hence the lower bound is \(\Omega(r\max\{p,q\}\log(1/(\sqrt r\,\epsilon)))\) in this precision range. Since \(r(p+q-r)\le2r\max\{p,q\}\), this is at least the usual rank-\(r\) parameter-dimension scale up to constants when \(\epsilon\) is sufficiently small relative to \(r\).

The bit bound does not assert that \(m\) alone must be large for a finite-bit oracle: one very high-precision scalar can carry many bits. If each query \(t\) has a different response budget \(b_t\), replace \(mb\) by \(\sum_t b_t\). The exact-real deterministic obstruction below supplies a separate query-count lower bound.

## Exact-real deterministic obstruction

If the learner is deterministic and each oracle response is an exact real scalar, then \(m<pr\) cannot support uniform error \(\epsilon<R/2\). Along the transcript produced at an interior \(B\), the adaptive query matrices are fixed. Their restrictions to variations \(H\mapsto\langle G_t,H V^T\rangle\) impose at most \(m\) linear constraints on the \(pr\)-dimensional factor space, leaving a nonzero \(H\) in their common nullspace. Scale \(H\) to have operator norm in \((2\epsilon,R)\). Both \(B\) and \(B+H\) remain in the full-rank ball and return identical exact answers along the same adaptive path, but some unit \(a,z\) has
\[
|a^THz|=\|H\|_{\mathrm{op}}>2\epsilon.
\]
No single post-storage answer can be accurate for both. This argument grants exact real measurements and unbounded computation; it is only stated for deterministic uniform correctness. A randomized positive-error query-count version needs a separate minimax argument.

## Raw-data control and cost match

For \(p\ge q\), the strongest simple control does not measure all \(pq\) entries of \(A\). It directly asks the task-relevant entries of \(B\): use \(pr\) coordinate probes
\[
G_{ij}=e_i(Ve_j)^T,\qquad \langle G_{ij},A_B\rangle=B_{ij}.
\]
The resulting \(p\times r\) raw response table already answers every task because \(A_Bx=B(V^Tx)\). Quantize each response in \([-1,1]\) with mesh \(h=\epsilon/\sqrt{pr}\); then \(\|\widetilde B-B\|_F\le\epsilon/2\), so every bilinear task has error at most \(\epsilon/2\). This uses:

- \(pr\) scalar measurement calls;
- \(b_{\mathrm{raw}}=\lceil\log_2(4\sqrt{pr}/\epsilon)\rceil\) bits per returned response, hence \(pr\,b_{\mathrm{raw}}\) acquired and retained response bits;
- \(O(pr)\) scalar quantizations and \(O(pr+qr)\) arithmetic per decoded task;
- only the \(p\times r\) table as data-dependent storage; \(V\) is the explicitly supplied public frame. Its acquisition, calibration, and digital description are outside this theorem and would need charging if not already shared.

For \(\epsilon\le1/(1024\sqrt{pr})\), this raw baseline's response-bit count is within a constant factor of the lower bound; both scale as \(pr\log(1/\epsilon)\) when \(p\ge q\ge r\). Query addresses can be pre-agreed or charged separately at \(O(pr\log(pr))\) bits. The lower bound omits query-address, calibration, physical noise/SNR, and runtime costs, so these cannot help a purported compressor. In the exact-real oracle, direct probes have zero measurement error; under noisy sensing, repetitions/SNR add costs and require a noise model.

This is a sharp obstruction to a universal acquisition advantage: unknown task-relevant factors must be learned at their metric-entropy rate even when rank is one or the right subspace is supplied. It is not a statement that compression never helps. If one compares with storing all \(pq\) entries, the rank prior can save storage; the fair raw-data control already stores only measurements needed for the post-storage task family. A positive result must exploit a restricted task law, a structural margin/identifiability condition, or an explicit compute/storage tradeoff beyond this worst-case class.

## Scope and status

This is a self-contained internally reconstructed candidate obstruction, not an externally reviewed theorem or novelty claim. The rank-\(r\) theorem assumes the output task family can probe all unit bilinear forms after storage and grants one factor \(V\) for free. It does not cover a single random future task, a low-entropy task distribution, nonuniform average-case prediction, nonlinear measurements, or task-specific noise models. The finite-bit lower is rigorous for fixed finite response alphabets; the exact-real query-count argument is deterministic. Measurement/calibration precision and query-description costs beyond response symbols remain outside the lower bound and are explicit in the control ledger.

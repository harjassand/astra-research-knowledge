# Classical affine sequent occurrence-line extension

7 October 2026. Independent argument by `logic_prior14` (verified Sol/max).
This note fills the additional sequent-to-Frege accounting requested by root.
It does not infer line preservation from a bare symbol-size equivalence.

## Exact statement

Let pi be an ordinary DAG-like proof of `=>A` in the classical affine linear
sequent calculus of Tabatabai–Jalali arXiv:2601.22393v2, Tables 3–5, with the
corresponding finite Frege system in Tables 6–8: exchange is implicit, weakening is unrestricted,
cut is allowed, only `!`-formulas admit contraction, and promotion has exactly
the side condition `!Gamma=>B / !Gamma=>!B`. Let

    ell = sum over written sequents S of (|antecedent(S)|+|succedent(S)|)

count formula **occurrences**, without counting internal symbols. Then there
is a same-target proof of A in the source's canonical finite affine Frege
system with

    number of Frege rows <= C(ell^4+1),
    common formula-DAG nodes <= C(ell^4+|A|+1),

where C depends only on the two fixed presentations. No formula tree-size bound
is asserted. A very loose fourth power is intentional; optimizing it is not
needed for an exponential lower bound.

Combined with the audited O(V+L)-occurrence memoized Chu compiler and the
source's O(|A|^2)-occurrence conservative repair, this gives, for conservative A,

    an ordinary intuitionistic affine proof of =>A
    with at most C'(ell^4+|A|^2+1) formula occurrences.

In particular the same Theta*_n family requires exponentially many total
formula occurrences in classical affine sequent proofs. This is our deduction,
not the v2 paper's stated symbol-size theorem.

## 1. Occurrence-skeleton compression before context packing

Freeze, from the given pi, every rule, principal occurrence, cut occurrence,
and occurrence matching of its multiset contexts. These matchings are merely
annotations of an already valid proof, not a new exchange or contraction rule.

Create one first-order term variable for each written formula occurrence.
For an identity equate its two roots; for logical principal formulas impose
their fixed constructor equations; for cut identify the two cut-formula roots;
and for preserved context occurrences impose equality according to the frozen
wiring. For promotion require that every antecedent occurrence be of the form
`!X`; add a constructor/child variable for each such occurrence if not present
already. Likewise enforce the top-level bangs required by W!/C!. Constants
are rigid. Equate the final occurrence with the actual rigid formula A.

For every rule in the finite sequent presentation, the sum of premise context
slots is at most twice the number of conclusion slots plus a fixed constant.
Hence a rule contributes O(number of conclusion occurrences+1) equations and
nodes, including promotion's per-occurrence bang tests. Summed over the proof,
this is O(ell+number_of_rows+|A|), even when one earlier sequent is used many
times: the equations for a use are charged to that use's conclusion slots.

Every written row has at least one occurrence. The empty sequent is not
derivable: the Boolean interpretation (fusion=and, par=or, `!`=identity) is
sound for all the present rules, while the empty sequent is false. Thus
number_of_rows<=ell. The original proof gives a finite ground solution of the
equations. Apply the constructor quotient and decreasing-ground-height
argument of `INDEPENDENT_GATE.md`, Section 3. The result is a replacement
sequent proof with exactly the same row/context-occurrence skeleton, the same
target A, and O(ell+|A|) common formula-DAG nodes.

This compression preserves the **syntactic** promotion condition because
every relevant root is explicitly constrained to a bang constructor. It does
not infer promotion from semantic equivalence to a bang formula.

## 2. Canonical interpretations and normalization costs

For each replacement sequent S=(Gamma=>Delta), store

    I(S) = (product Gamma) -> (par Delta),
    product empty = 1, par empty = 0,
    X+Y = neg(neg X * neg Y), neg X = X->0.

Choose a fixed binary bracketing and an arbitrary but recorded occurrence
order for each written multiset. Constructing all these roots costs O(ell)
extra shared syntax nodes. Internal source formulas remain opaque roots.

At a use of a sequent rule, normalize each already proved premise
interpretation so its antecedent and succedent products are grouped into the
rule's context blocks and active formulas. A rule has only a fixed number of
context blocks; the contents of a block can be arbitrarily long.

The normalization uses the fixed provable associativity, commutativity and
unit equivalences for fusion/par. Lift a local equivalence through the enclosing
product or par constructors using fixed monotonicity/congruence derivations,
and through the outer implication using its fixed contravariant/positive
composition laws. Both directions of an equivalence are retained. This uses
ordinary finite Frege derivations instantiated at the current opaque roots;
there is no object-level uniform-substitution rule.

A context of m occurrences can be rebracketed, permuted and regrouped using
O(m^2) local moves (even bubble sorting suffices). A move lifts through depth
at most O(m), using O(m) fixed-template Frege rows and O(m) fresh formula-DAG
constructor nodes. Thus normalization costs O(m^3). There are at most two
premises, and m<=ell. A step therefore costs O(ell^3), and all at most ell
steps cost O(ell^4). The bound allows deliberate overcounting of reused lines
and does not depend on the tree size of any context member.

Empty context blocks are handled as separate fixed template variants, or by
the fixed unit equivalences. There are finitely many empty/nonempty patterns
because the number of context blocks in a rule is fixed.

## 3. Why the normalized nonpromotion templates are finite and valid

Replace every nonempty context block Gamma by one formula variable G whose
instance is its fusion product; replace every nonempty succedent block Delta
by one formula variable D whose instance is its par product. Keep each active
formula/operand as a separate variable. The interpretations of every ordinary
logical/structural rule other than promotion now have bounded-size formulas
with a fixed number of variables. C! uses a principal variable syntactically
of the form !X. There is one finite family of such representatives, including
the finite empty-context variants.

Each representative is a sound inference for the global theorem consequence
relation used by the standard Frege system. Here is a uniform concrete
sequent derivation establishing that claim:

1. Start with the representative's premises as the initial **closed** sequents
   `=>I(P_i)`.
2. From each such closed sequent derive the corresponding flat abstract
   premise P_i. Fuse its boundedly many antecedent block variables/active
   formulas by identities and right fusion; combine this with I(P_i) through
   left implication and cut; ungroup the boundedly many succedent par blocks.
3. Apply that one original sequent rule to these flat premises.
4. Fold the conclusion's boundedly many antecedent slots by left fusion and
   its succedent slots by derived right par; apply right implication to obtain
   `=>I(conclusion)`.

The derived par operations used here have **constant** derivations. For
example, to turn `Gamma=>X,Y,Delta` into `Gamma=>X+Y,Delta`, use derived left
negation twice, left fusion on negX/negY, and right negation. Derived left
negation uses left implication with the axiom `0=>`; derived right negation
uses right 0-unit weakening and right implication. To derive
`X+Y=>X,Y`, first derive `=>negX,X` and `=>negY,Y` from identity and right
negation, apply right fusion, and then left negation. All abstract contexts in
these fixed representative derivations have boundedly many formula occurrences.

Therefore each representative has a fixed finite Frege derivation from its
fixed formula premises by the standard system's strong completeness. This
last step only concerns a **finite collection of fixed, constant-size schema
objects**; one can select their derivations once, or enumerate finite Frege
derivations until they are found. Their number of rows and constructor nodes
is a presentation-dependent constant. Instantiating those fixed derivations
inserts references to whole DAG roots, so contributes O(1) rows/nodes per
normalized inference. This use of completeness does not apply a size simulation
to arbitrary long formulas or long contexts.

As an illustrative binary rule, normalized left implication maps

    G -> (X+D),     (H*Y) -> E
    ----------------------------------------------
    (G*H*(X->Y)) -> (D+E).

Unpack the two interpretations to `G=>X,D` and `H,Y=>E`, use the exact source
left-implication rule, and repack. The argument supplies the fixed standard
Frege derivation without requiring unrestricted contraction.

## 4. Promotion: an explicit linear fold, not an arbitrary context variable

The context of promotion cannot simply be replaced by one unconstrained G.
Let its antecedent be `!A_1,...,!A_m`, and let

    Q = !A_1 * ... * !A_m

with the chosen bracketing. Its premise interpretation is the already proved
theorem `Q->B`. Its conclusion interpretation must be `Q->!B`.

First build a proof `J(Q): Q->!Q` using O(m+1) Frege rows and O(m+1) new
formula-DAG nodes:

* For m=1, J(!A_1) is the exact axiom `!A_1->!!A_1`.
* If Q=Q_1*Q_2 and J(Q_1),J(Q_2) are proved, fixed fusion monotonicity gives
  `Q_1*Q_2 -> !Q_1*!Q_2`; compose with the fixed theorem
  `!X*!Y -> !(X*Y)` at X=Q_1,Y=Q_2.
* For m=0, Q=1; use the fixed theorem `1->!1`.

The fixed theorem `!X*!Y -> !(X*Y)` has this exact legal sequent derivation:

    X=>X                    Y=>Y                 [identities]
    !X=>X                   !Y=>Y                [L!]
    !X,!Y=>X*Y                                   [R*]
    !X,!Y=>!(X*Y)                                [R!, both antecedents bang]
    !X*!Y=>!(X*Y)                                [L*]
    =>(!X*!Y)->!(X*Y)                            [R->]

Its standard Frege proof is a fixed constant-size object, independently of
the instances of X and Y. Likewise `1->!1` has the three-rule construction
`=>1`, promotion to `=>!1`, left unit weakening to `1=>!1`, and right implication.

Now theorem necessitation on the **closed, already proved** Frege theorem
`Q->B` gives `!(Q->B)`. Axiom !K and modus ponens yield `!Q->!B`. Compose with
J(Q) to obtain `Q->!B`. This costs O(1) additional rows beyond the O(m) fold.
No arbitrary antecedent is promoted, no ordinary hypothesis is copied, and
no contextual application of necessitation is assumed.

If the recorded context order differs between premise and conclusion, the
normalization budget in Section 2 accounts for it. All bangs A_i and Q's
subproducts are exact DAG roots, so no unfolded tree is traversed here.

## 5. Costs, target extraction and lower-bound transfer

Process the source sequent proof in its original DAG order, appending the
normalization and fixed-rule simulations above. Formula roots generated by
these finite instantiated templates use O(1) new constructor nodes per Frege
row, since large operands are references. Occurrence-skeleton compression
costs O(ell+|A|) nodes, initial context packing O(ell), all normalizations
O(ell^4), all fixed nonmodal templates O(ell), and all modal folds O(ell^2)
under a deliberately loose bound. Hence the claimed polynomial bounds hold.

The final interpretation is `1->A`. The unit axiom and modus ponens give A
in constant extra rows. Apply memoized Chu compilation on the resulting
common Frege/formula graph, then the source's conservative repair. The
intuitionistic formula-occurrence lower bound now forces

    C'(ell^4+|Theta*_n|^2+1) >= 2^{n^{Omega(1)}}.

Since the target has polynomial tree size, ell is itself 2^{n^{Omega(1)}}.
This conclusion measures total formulas in sequent rows; it does **not** claim
a lower bound on the number of sequent rows if arbitrarily many context
occurrences are permitted at zero cost.

## Prior source and verification boundary

The actual arXiv:2006.09705v2 text labels the sequent-to-Frege result
**Theorem 6.2**, pages 35–36; the recent paper cites the published theorem as
6.3. I read that proof. It concerns the unmodal FL_S calculi and constructs
interpreted inference rules; it does not perform the above bang-context fold.
Its asserted equality counts sequents as lines, whereas the recent v2 paper
counts all formula occurrences. Those conventions must not be conflated.
The recent paper's Lemma 1 asserts symbol-size equivalence; that alone was
not used to infer the theorem here.

The present argument is a universal mathematical construction with a complete
cost ledger and an explicit promotion derivation. The finite Frege derivations
of every packed/normalization representative have been justified by fixed
constant-size sequent proofs plus standard strong completeness; this worker
has not serialized a runnable end-to-end sequent-to-Frege compiler or every
fixed Frege axiom derivation. The recent Chu schema certificates held by the
other workers are complementary local verification, not external validation.

A precise falsifier would be a source rule that cannot be normalized into a
fixed number of opaque context blocks, a supposedly fixed representative that
is not standard-sound, or a promotion rule with an extra side condition absent
from the stated source. The tables contain none of these obstructions. The
route does not extend automatically to arbitrary nonstandard/admissible
Frege rules, non-acyclic definitions, or zero-cost unbounded sequent contexts.

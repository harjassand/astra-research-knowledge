# Exact CTMC likelihood and rate-discrimination bound

## Model and statement

Let (X_t) be a finite-state, non-explosive CTMC on a common state space, observed continuously on ([0,T]), with a common initial law ν independent of the hypothesis. A subset (E_s) of directed transitions has rates

\[
q_\theta(x,y)=\theta a(x,y),\qquad (x,y)\in E_s,
\]

where (a(x,y)>0) is known and all other rates are independent of θ. Define

\[
K_T=\#\{t\le T:(X_{t-},X_t)\in E_s\},\qquad
A_T=\int_0^T a(X_t)\,dt,\quad a(x)=\sum_{y:(x,y)\in E_s}a(x,y).
\]

For (0<\theta_0,\theta_1<\infty), the path log-likelihood ratio is

\[
\log\frac{dP_{\theta_1}}{dP_{\theta_0}}(X_{[0,T]})
=K_T\log(\theta_1/\theta_0)-(\theta_1-\theta_0)A_T.
\]

Thus ((K_T,A_T)) is sufficient for this binary test. Its path relative entropy is

\[
D(P_{\theta_1}^{[0,T]}\Vert P_{\theta_0}^{[0,T]})
=d_{\rm Pois}(\theta_1\Vert\theta_0)\,\mathbb E_{\theta_1}A_T,
\quad d_{\rm Pois}(u\Vert v)=u\log(u/v)-u+v.
\]

If (a(x)\le a_{\max}), this is at most (a_{\max}T d_{\rm Pois}(\theta_1\Vert\theta_0)). Any terminal or downstream decision with true-positive probability (s) under θ₁ and false-positive probability α under θ₀ obeys

\[
d_{\rm Ber}(s\Vert\alpha)\le a_{\max}T d_{\rm Pois}(\theta_1\Vert\theta_0).
\]

Consequently, if (s\ge\eta>\epsilon\ge\alpha), then

\[
T\ge \frac{d_{\rm Ber}(\eta\Vert\epsilon)}{a_{\max}d_{\rm Pois}(\theta_1\Vert\theta_0)}.
\]

The bound applies to every downstream finite-state memory or randomized readout because such processing cannot increase KL divergence.

## Proof

For a realized path, each transition in (E_s) contributes a factor θ to its density, and the integrated exit hazard from the set contributes \(\exp(-\theta A_T)\). Factors for all other transitions and the initial state cancel between hypotheses. This gives the displayed likelihood ratio. Taking expectation under θ₁ gives

\[
\mathbb E_{\theta_1}\log\frac{dP_{\theta_1}}{dP_{\theta_0}}
=\mathbb E_{\theta_1}K_T\log(\theta_1/\theta_0)
-(\theta_1-\theta_0)\mathbb E_{\theta_1}A_T.
\]

The counting-process compensator gives \(\mathbb E_{\theta_1}K_T=\theta_1\mathbb E_{\theta_1}A_T\), yielding the Poisson divergence formula. The activity cap gives \(A_T\le a_{\max}T\). Finally, the terminal binary decision is a channel from the full path, so data processing bounds its Bernoulli KL by the path KL. Monotonicity of \(d_{\rm Ber}(s\Vert\alpha)\) for (s>\alpha) yields the stated target bound.

## Identifiability consequence

If θ is a product θ=γu of unknown gain and unknown input strength, then any positive pair (γ,u) and any rescaled pair (cγ,u/c) induce the same generator and exactly the same path law. No observation duration, state resolution, or downstream classifier can identify the two factors separately. One factor must be known or an additional transition class with a different parameter dependence must be supplied.

## Scope and costs

The model assumes known, time-homogeneous rate structure; positive common transition support; a common initial law; complete path observability for the sufficient-statistic claim; and a charged integrated activity \(A_T\). When only an endpoint is seen, the KL inequality remains valid but generally becomes strict. If the initial law carries hypothesis information, its KL must be added. If θ₀=0 while θ₁>0, absolute continuity fails and this finite-KL bound is not the right regime.

The sufficient statistic requires tracking the current state plus an integer jump count and a real-valued integrated activity. Exact unbounded counters are not a free implementation. With a finite horizon, a bounded-rate CTMC has a Poisson-dominated jump count; quantization of (A_T) to error δ in the LLR requires activity resolution at most (2\delta/|\theta_1-\theta_0|). Rate acquisition/calibration, event sensing, and storage precision are outside the theorem and must be charged in any physical use.

This is an exact model theorem, not evidence about any biological system.

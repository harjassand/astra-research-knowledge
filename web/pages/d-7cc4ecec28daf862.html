2. Exact finite-copy module
--------------------------
Use five formal species X+, X-, M, Y+, Y- and two irreversible reactions

    r1: X+ -> M + Y+,
    r2: M + X- -> Y-.

The initial integer state is (X+,X-,M,Y+,Y-)=(p,n,0,0,0), for p,n in
{0,1,2,...}. No other initial species or fuel is present in this formal model.
The decoded output is y=Y+ - Y-. This is the standard dual-rail, two-reaction
ReLU module in the Vasic et al. compiler; it is recorded here as a baseline,
not a new construction.

Let a and b be the numbers of r1 and r2 firings. Every reachable state has

    (X+,X-,M,Y+,Y-)=(p-a, n-b, a-b, a, b),
    0 <= b <= a <= p,  b <= n.

If a<p, r1 is enabled. If a=p but b<min(p,n), then both a-b>0 and n-b>0,
so r2 is enabled. Therefore every static state has a=p and b=min(p,n), and
this state is reachable by firing r1 p times and then r2 min(p,n) times. It is
the unique terminal state. Hence, for every legal event order,

    Y+ = p,  Y- = min(p,n),
    y = p - min(p,n) = max(p-n,0).

This is an exact statement for integer counts, not an ODE approximation. The
number of reaction events on every maximal path is p+min(p,n). The total number
of formal molecules in state (a,b) is p+n+a-b, so it is at most 2p+n; the
maximum is attained after firing r1 p times before firing r2. The final
intermediates are M=max(p-n,0) and X-=max(n-p,0). The first reaction creates
one net formal molecule on each firing; the second consumes one net molecule
on each firing. Formal CRN accounting therefore hides matter/fuel for up to p
extra species units. Atom, fuel-complex and free-energy budgets require a
physical implementation and are not supplied by this stoichiometric proof.

For stochastic mass-action in a fixed volume V_L, use Ω=N_A V_L molecules per
molar concentration, first-order rate k1>0, and second-order rate k2>0. At
state (a,b), the propensities are

    λ1(a,b)=k1(p-a),
    λ2(a,b)=(k2/Ω)(a-b)(n-b).

At every nonterminal state one enabled reaction has propensity at least
κ=min(k1,k2/Ω)>0. There are exactly p+min(p,n) firings before absorption, so
the chain terminates almost surely and

    E[T] <= (p+min(p,n))/κ.

If rate intervals k1>=k1_min>0 and k2>=k2_min>0 are supplied, the same bound
holds with κ=min(k1_min,k2_min/Ω). Thus the terminal output is independent of
the positive rate constants, but this bound depends on positive rate floors.
If rates are only known to be positive, with no common lower bound, no uniform
finite deadline follows. For any network whose rates are all rescaled by s>0,
the embedded jump sequence is unchanged and physical time is multiplied by
1/s; as s tends to zero, completion by any fixed deadline has probability
tending to zero. This is a time-rescaling obstruction, not a new theorem.

3. Leakage attack and resource counterexample
---------------------------------------------
Append one fuel species F and allow a single unproductive activation leak

    rL: F -> Y+.

Starting from the zero input p=n=0, one rL firing changes the correct output 0
to 1. This is an exact, one-token counterexample to the assertion that
rate-independent ideal stoichiometry implies leakage robustness. If one F is
present and rL is a unimolecular leak of rate λ, then after a fixed observation
time t the false-positive probability is exactly 1-exp(-λt), assuming no
other reactions after the correct computation. To keep this contribution at
most δ at deadline t>0 requires λ<=-log(1-δ)/t. If the system is allowed to
wait indefinitely and the irreversible leak rate is positive, the false
positive probability tends to 1. This bounds this particular output encoding;
it is not a lower bound for every possible fault-tolerant compiler.

For the output-only leak, E leak events change the decoded output by at most E,
and the bound is tight if all leaks produce the same rail. A binary decision
with a one-token signal has no margin against even one such event. A wrapper
that corrects this would need to specify its own state transitions, leak
model, threshold/margin, finite-count probability, rates, reporter and fuel.
No such wrapper is proved here. The strongest directly relevant leak baseline
found is a special detector whose target species is catalytic and cannot itself
be leaked into; that restriction prevents this counterexample from being
silently transferred into the detector theorem.

The BReLU compiler's unary molecule output can also be exponentially large in
network depth even when the network description is linear-size. For L hidden
layers of width two, let both first-layer nodes compute x and each later node
compute the sum of the two preceding nodes. All weights are +1 and ReLU is
inactive on these nonnegative values. Then

    h_1^(l)=h_2^(l)=2^(l-1)x,  and y=h_1^(L)+h_2^(L)=2^L x.

With one final ReLU readout on the sum, the network has 2L+1 nodes and O(L)
edges, but for integer input x=1 a unary output requires 2^L output molecules.
This is an architecture-specific resource counterexample, not a universal
lower bound: a different encoding could store the value in binary, but no
chemically realizable, leak-robust, cost-bounded binary counter compiler is
supplied here. In fixed volume, keeping output concentration below a constant
C requires volume at least 2^L/(C N_A) when x=1 molecule is the input. Any
physical strand-displacement implementation must account for the auxiliary
matter and energy that formal nonconserving reactions omit.

4. Primary-source comparison under matched boundaries
-----------------------------------------------------
The relevant comparison is which guarantees hold in a common ideal irreversible
finite-copy model and which survive an explicit leak/physical implementation.
No reviewed compiler provides all four requested guarantees at once.

* Vasic, Chalk, Luchsinger, Khurshid and Soloveichik, “Programming and Training
  Rate-Independent Chemical Reaction Networks,” arXiv:2109.11422v1,
  https://arxiv.org/html/2109.11422. In §2.1, lines 137-154, noncompetitive
  means every species decreased in a reaction is a reactant in only that
  reaction; a reachable static state is the unique mass-action limit for any
  fair rate law under the theorem's hypotheses. In §7.6, lines 570-593, they
  prove the discrete stochastic analogue: counts are integers, reactions are
  single events, and positive transition probabilities are assumed whenever
  all reactants are present; a reachable static state reached in path length
  ell is the unique terminal reached by every path of length ell, with no
  longer path. §§3-4, lines 184-230, give the rational and binary-weight ReLU
  compilers; optimized BReLU uses one bimolecular reaction per ReLU node plus
  two unimolecular input reactions per input. Their line 231 explicitly warns
  that adversarial optimized networks can create exponentially many product
  species per reaction. This is the closest ideal compiler and preempts the
  finite-copy/order-independence candidate. The theorem assumes the formal
  reaction graph and no added leak or reverse reaction; it supplies no
  quantitative physical-time bound, strand sequence, crosstalk bound, or fuel
  budget. The paper's CRN examples are numerical kinetic simulations, not wet
  lab validation of this formal compiler.

* Soloveichik, Seelig and Winfree, “DNA as a universal substrate for chemical
  kinetics,” PNAS 107 (2010), https://www.pnas.org/doi/10.1073/pnas.0909380107.
  Abstract/intro and §§“Molecular Primitive” and “Implementing Networks,”
  lines 139-170 and 172-198, describe a systematic strand-displacement
  realization that approximates arbitrary CRN mass-action dynamics in a
  scaled concentration/time regime. It uses reaction-specific auxiliary gate
  and translator complexes; signal concentrations must be much lower than
  auxiliary concentrations, and the paper proves convergence to target
  kinetics in the high-auxiliary-concentration limit. Toeholds tune rate
  constants over reported orders of magnitude, so this is not an uncertainty-
  independent timing guarantee. It is a broad CRN-to-DNA construction, but the
  limit and fuel requirements are explicit and generic leak/error-rate and
  finite-copy guarantees are absent from the claimed theorem.

* Alistarh et al., “Robust Detection in Leak-Prone Population Protocols,”
  arXiv:1706.09937v2, https://arxiv.org/html/1706.09937v2. §§1-2, lines 64-84,
  model spurious conversions among noncatalytic states in a fixed-size
  population with uniform random pair interactions; the detected species D is
  required to be catalytic in every reaction involving it. Lines 108-122 give
  Robust-Detect: with leak rate at most β/n, a randomly selected molecule
  after O(log n) parallel time has false-negative probability at most
  1/e+o(1) and false-positive probability at most β; the stated task is
  single-molecule detection. This is a real bounded-count leak theorem, but it
  is a specialized detector, not a compiler for arbitrary input/output
  functions, and its target cannot itself be created by the modeled leak.

* Wang et al., “Effective design principles for leakless strand displacement
  systems,” PNAS 115 (2018), https://pmc.ncbi.nlm.nih.gov/articles/PMC6310779/,
  and Kennedy, Pearce and Thachuk, “Fast and Robust Strand Displacement
  Cascades via Systematic Design Strategies,” DNA28 (2022),
  https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.DNA.28.1.
  The 2018 primary abstract reports redundancy-based leak reduction, including
  tests on a translator and a nine-step cascade. The 2022 primary abstract,
  lines 145-148, reports domain-level redundancy for leak suppression and a
  sequence strategy improving speed without practical robustness loss. These
  are physical cascade design techniques, but not a compiler with the full
  finite-count, arbitrary-network guarantee and complete molecule/energy
  accounting requested here.

* Stérin et al., “A thermodynamically favoured molecular computer,” Nature 657
  (2026), https://www.nature.com/articles/s41586-026-10996-5. Lines 77-95 and
  101-120 describe SDC tiles and a compilation for any finite-state machine,
  with experimental outputs on ten programs. Lines 151-180 report the scale-up
  and limitations: 25-position bit-copy reached 59% yield after 14 h, the
  experiment did not enforce a specific kinetic model, and off-pathway
  interactions were not characterized/optimized. Methods lines 201-215 give
  concrete supplies: 1,539 synthesized non-scaffold strands, 10x compute-strand
  concentration (5.7x for renewal), 10 nM scaffold for the biological M13
  systems, 35 μL reaction volume and 12.5 mM Mg++ buffer. This is the strongest
  physical finite-state compiler found, and it has actual experiments; it does
  not give a worst-case finite-molecule stochastic error bound against explicit
  adversarial leaks or all rate perturbations. The stated experimental yields
  are source-reported evidence, not measurements reproduced here.

* Petrack et al., “Scaling up Thermodynamically Favoured Scaffolded DNA
  Computing by Sculpting the Energy Landscape,” DNA32 (2026),
  https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.DNA.32.7, abstract
  lines 149-154. Their idealized SDC models relate target probability to
  temperature/domain length, report logarithmic domain length suffices for
  target dominance, and give expected O(N^2) or O(N^3) kinetics under their
  model variants, with narrow O(N) cases. These model results preempt generic
  claims that SDC energy/kinetic scale-up alone is open; they are not a
  finite-copy adversarial-leak theorem or an experimental realization of those
  asymptotics.

* Bohm Agostini et al., “ChemComp: A Compilation Framework for Computing with
  Chemical Reaction Networks,” ASPDAC 2025,
  https://www.pnnl.gov/publications/chemcomp-compilation-framework-computing-
  chemical-reaction-networks. The primary abstract describes a multilevel
  intermediate representation and emulation of a simplified chemical
  reservoir. This is a useful high-level programming/emulation framework, not
  evidence of a DNA-level robust compiler.

5. Alternatives and limits
--------------------------
Candidate A: claim that noncompetitive CRNs extend the continuous rate-
independent theorem to finite integer molecule counts. Rejected as a discovery:
the exact stochastic theorem is already published by Vasic et al. §7.6. The
local ReLU proof and enumeration below only check that known baseline.

Candidate B: wrap an ideal ReLU output in a leak detector. A detector can be
strong only under a specified input species/leak model. Robust-Detect requires
an unleakable catalytic target; an output that the computation must newly
produce is a noncatalytic species in the modeled sense. The direct module's
F->Y+ event makes the zero-input case a false positive, so a black-box wrapper
cannot inherit the detector theorem without a new output-generation and
leak-separation proof.

Candidate C: use domain redundancy to suppress leakage and then compile large
programs. Leakless DSD and SDC already establish important pieces separately.
The missing joint theorem would need actual sequence-level crosstalk limits,
finite-volume molecule counts, calibrated rate intervals, leak transition
rates, copy-number/fuel bounds, and an output-error metric, compared against
both compilers under the same input encoding. No such construction was derived.

Candidate D: allow arbitrary positive but unknown rates and promise a deadline.
This fails even before chemistry-specific leakage: common rate rescaling leaves
eventual order behavior unchanged and makes every finite deadline unattainable
uniformly without a rate floor. Any fast computation guarantee must include a
positive lower rate or a dimensionless time scale.

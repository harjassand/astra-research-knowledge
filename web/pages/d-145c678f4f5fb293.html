# Counterpart splitting forces full-Gibbs leakage in the old decoder frame

## 1. The actual interface and the result

Use a finite member of the admitted one-logical-qubit CSS replacement family.
Keep its original physical checks C_a and original decoder Pauli algebra.
Let

    H0=sum_a h_a(I-C_a)/2,       1<=h_a<=2,
    H=H0+V,                     V=-sum_i epsilon_i X_i,
    rho=exp(-beta H)/Tr exp(-beta H),   beta>0,
    v=||V||<=sum_i epsilon_i.                                    (1)

All fields can be strictly positive. The independent h_a are explicitly a
weighted-check extension of the unit-penalty source, already covered by the
weighted equilibrium witness. They are not asserted to equal the source's
illustrative unit weights. All locality, check relations, and replacement
geometry remain the actual code's.

Choose a bare pure-X logical L. H commutes L and all original X checks.
Each valid joint check syndrome s has two old states phi_(s,+/-), one for
each L eigenvalue. Since the code encodes one qubit, each such joint space
is one-dimensional after L is fixed. Write their common H0 energy E_s.
Assume the valid E_s are pairwise distinct, with minimum spacing Delta>0.
Let O be the ORIGINAL full-space Hermitian decoder Z or Y observable. Then

    O^2=I, [O,C_a]=0 for every a, {O,L}=0,
    O phi_(s,eta)=u_(s,eta) phi_(s,-eta), |u_(s,eta)|=1.           (2)

Equation (2) follows from the primary decoder definition and one-dimensional
joint spaces. It makes no claim that O maps current eigenvectors exactly.

Fix an unchanged physical bath observable A=X_q. It translates the old
syndrome by a nonzero vector v_q: t=s+v_q, and its old counterpart matrix
element has modulus one. Assume

    v<=min(Delta/64,1/2),
    (lambda_(s,+)-lambda_(t,+))
       !=(lambda_(s,-)-lambda_(t,-))   for EVERY valid s.         (3)

Here lambda_(s,eta) is the unique current eigenvalue continuing E_s in the
eta sector. All distinct old syndromes remain distinct in each current
sector. Section 3 proves the necessary eigenvector estimate directly.

Decompose the SAME A into FULL-H components using lowering convention

    [H,A_omega]=-omega A_omega,
    gamma(-omega)=exp(-beta omega)gamma(omega),
    0<=gamma(omega)<=Gamma.

Suppose gamma>=gamma_min>0 on |omega|<=7 h_max+1. Define the old-frame
frequency-resolved Gibbs leakage

    k_O=sum_omega gamma(omega)
                   Tr rho [O,A_omega]^*[O,A_omega].              (4)

Then

    k_O >= gamma_min (1-6r)^2 >= gamma_min/4,
    r=2v/(Delta-v)<=2/63<1/16.                                  (5)

The entire current Gibbs mass appears in (5); no ground-state fraction,
sector Gibbs comparison, minimal Gibbs eigenvalue, or frequency count is
inserted. OTHER counterpart pairs may have exactly coincident frequencies.
Only the same source/target pair's two logical-sector gaps must differ.

For the fixed smooth original rate gamma(omega)=2/(1+exp(-beta omega)),
one can take Gamma=2 and

    gamma_min=2/(1+exp(beta(7h_max+1))).                          (6)

This lower bound is independent of N at fixed beta and h_max. Its numerical
size at the witness temperature can be extremely poor and is retained.
Changing physical bath couplings or rebuilding a convenient sampler is not
part of the result; only the required spectral decomposition is rebuilt
for the actual current H.

## 3. Individual eigenvector control, without dimension loss

In each eta sector H0 has one old basis state per valid syndrome. Weyl's
bound gives |lambda_(s,eta)-E_s|<=v. The intervals [E_s-v,E_s+v] are
disjoint. Let P_s=|phi_(s,eta)><phi_(s,eta)|. Projecting the eigenvalue
equation for the normalized psi_(s,eta) gives

    (H0-lambda)(I-P_s)psi=-(I-P_s)V psi,
    ||(I-P_s)psi|| <= v/(Delta-v).                               (7)

Choose the phase so <phi,psi> is real nonnegative. Then

    ||psi-phi||^2=2(1-sqrt(1-||(I-P_s)psi||^2))
                  <=2||(I-P_s)psi||^2,
    ||psi_(s,eta)-phi_(s,eta)|| <= r=2v/(Delta-v).                (8)

This is an INDIVIDUAL vector/row estimate. No operator bound on a whole
eigenbasis change is inferred, and no sqrt(2^N) factor is hidden. From (2),

    ||O psi_(s,eta)-u_(s,eta) psi_(s,-eta)||<=2r,
    |<psi_(t,eta), A psi_(s,eta)>|>=1-2r.                        (9)

## 4. Other exact resonances cannot cancel the selected coefficient

Fix s,eta and t=s+v_q. Put omega=lambda_(s,eta)-lambda_(t,eta).
Because the current spectrum in the eta sector is simple and A preserves
eta, A_omega psi_(s,eta) has ONLY the output psi_(t,eta):

    A_omega psi_(s,eta)=a_ts psi_(t,eta), |a_ts|>=1-2r.

By (9), its image under O has selected opposite-sector component with
modulus at least (1-2r)^2. In the reverse order write

    O psi_(s,eta)=u_s psi_(s,-eta)+e_s, ||e_s||<=2r.

Condition (3) says the selected element
<psi_(t,-eta),A_omega psi_(s,-eta)> is EXACTLY zero. Every other
resonance enters only through e_s. Since ||A_omega||<=||A||=1, it costs
at most 2r. The triangle inequality consequently gives

    |<psi_(t,-eta),[O,A_omega]psi_(s,eta)>|
      >=(1-2r)^2-2r >=1-6r.                                   (10)

This proof explicitly pays the failure of exact current label transport by
O. It does not claim that shared frequency supports must be empty. The same
argument works for eta=- and every s.

The selected current omega is within 7h_max+2v: the old X_q flips at most
seven incident Z checks, and the two eigenvalue shifts cost at most 2v.
Expand the trace in (4) in the CURRENT Gibbs eigenbasis. For every input
state psi_(s,eta), positivity retains the single squared selected component
(10) and its rate. Every Gibbs eigenstate is one of these inputs. Summing
their Gibbs weights, which add to one, proves (5). Many inputs may select
the same atom; each is a different orthogonal input contribution, so this
retention neither double-counts nor requires an atom inventory.

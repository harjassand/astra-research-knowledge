Outcome
-------
The actual fixed no-double-occupancy normalizer

  Z_k(A) = sum_{I,J subset [n], |I|=|J|=k, I intersect J=empty}
               |det A[I,J]|^2

contains general-graph perfect-matching counting in its full sector n=2k.
This is an explicit polynomial-bit rational reduction to A itself; it does not
change the filter to an arbitrary Boolean predicate.

1. Exact evaluation is #P-hard, including for real rational contractions A.
   For integer A it belongs to #P and is #P-complete under polynomial-time
   one-query metric reductions (known scaling followed by rounding). An
   interpolation proof independently gives a polynomial-time Turing reduction.
2. An FPRAS for Z on all such rational inputs would give an FPRAS for general-
   graph perfect matchings. A total-variation sampler polynomial in explicit
   input bit length and inverse requested error would give an approximate uniform
   generator and hence an FPRAS for general-graph perfect matchings.
   This is a one-way transfer to general-graph PM approximation. The pinned
   OA113 source claims an FPRAS for that source problem; accepting that claim
   removes a clean open-problem obstruction from this transfer. It does not
   give a reverse reduction or a Z algorithm, imply NP=RP, or rule out an FPRAS.
3. There is a positive full-sector Pfaffian expectation identity, but its direct
   Monte Carlo estimator has relative variance 2^d-1 on d disjoint 4-cycle blocks.
   That family has an easy block sampler and exponentially rare physical success.

Legal interface and supplied/acquired inputs
-------------------------------------------
Input A is an explicitly listed n by n matrix in Q(i); all constructions here
use Q. Input bit length L includes n, k, and every numerator/denominator. There
is no determinant oracle in the input, hidden circuit, or supplied promise of
polynomial success probability. The target retained outcome (I,J) has probability
|det A[I,J]|^2/Z_k(A), for Z_k(A)>0. For n=2k, J=[n]\I uniquely, so its law is the
law of I alone. Our reduction selects this legal sector rather than modifying
the local projection. Acquisition of the explicit matrix is polynomial-time
exact rational arithmetic; a hypothetical counting/sampling algorithm is the
only queried oracle in the consequences.

The physical pairing state, if used, is the Gaussian BCS state with unnormalized
amplitudes det A[I,J] in balanced sectors. Its normalization is det(I+AA*).
Projecting to the k-pair sector and applying the fixed no-double filter has
success probability Z_k(A)/det(I+AA*). If the k-pair state is already supplied
normalized, its norm before the no-double filter is

  W_k(A)=[u^k] det(I+u AA*) = sum_{|I|=|J|=k}|det A[I,J]|^2,

and success is p=Z_k(A)/W_k(A). Neither circuit synthesis nor physical preparation
cost is silently supplied. Rare success costs an expected 1/p attempts and,
for per-attempt energy E_try, expected E_try/p energy. These costs remain in the
resource ledger. A particle-hole reformulation as a Slater state changes the
local projection to even parity; it is only an algebraic representation here.

Exact paired-column identity used by the reduction
--------------------------------------------------
Let V=[I,A^T], an n by 2n matrix, and let P(S) be both columns i and n+i for
every i in S. If |S|=k, Cauchy-Binet gives

  det((V*V)[P(S)]) = sum_{J subset [n]\S, |J|=k}|det A[S,J]|^2.

At n=2k this reduces to

  |det V[:,P(S)]|^2 = |det A[S,[n]\S]|^2.

To check the second identity directly, expand the determinant along its identity
columns. The remaining determinant is A^T[[n]\S,S]=A[S,[n]\S]^T, with a sign
from the column order. Absolute squares remove that sign. Consequently

  Z_{n/2}(A)=sum_{|S|=n/2}|det V[:,P(S)]|^2.                 (1)

This is the cycle2 paired-Gram identity in its full sector. For a general row
change V -> T V, every determinant in (1) changes by det T, so the same common
factor is removed by normalization. This full-sector condition is essential;
we do not claim that arbitrary row changes preserve lower-dimensional volumes.

Graph padding with unchanged perfect-matching count
-------------------------------------------------
Let H be a simple graph on an even number m of vertices with E edges. Denote its
number of perfect matchings by P(H). Empty-vertex, odd-vertex, and nonempty edgeless
instances are handled directly (counts 1,0,0). Assume E>=1. If E>=m no padding is
needed. Otherwise add two fresh vertices u,v, the edge uv, and edges uw for every
old vertex w. Vertex v is a leaf, so every perfect matching must contain uv;
none of the edges uw can be used. Restriction to H is therefore a bijection of
perfect matchings. The padded graph has

  M=m+2, E'=E+m+1>=m+2=M,

and P is unchanged. We henceforth write M,E for the padded or original values,
so M is even and E>=M. Padding is linear in the source graph size and does not
multiply its count. It need not preserve bipartiteness; the target allows all
graphs. Exact #P-hardness can start from bipartite perfect matchings.

Unit-column parity encoding with the target dimension ratio
-----------------------------------------------------------
Set d=E-M>=0 and N=E+d=2E-M. Then N=M+2d is even. Use N coordinate rows: the M
graph vertices and 2d private dummy rows. There are N column pairs:

* For each edge e={u_e,v_e}, choose an orientation and the pair
  b_e=e_{u_e}, c_e=e_{v_e} of coordinate unit vectors.
* For each dummy a, use b_a=e_{M+2a-1}, c_a=e_{M+2a} on its private rows.

Let B=[b_1 ... b_N], C=[c_1 ... c_N], V_0=[B,C], and K=N/2. For |S|=K define
d_S(0)=det V_0[:,P(S)]. Each selected column is a unit vector, so this determinant
is 0 or +-1. A nonzero determinant must select every dummy pair because each of
its rows occurs nowhere else. The remaining K-d=M/2 selected edge pairs cover
each graph vertex exactly once, which is exactly a perfect matching. Conversely
each perfect matching plus all dummies gives a nonzero determinant. Thus

  R(0):=sum_{|S|=K} d_S(0)^2 = P(H).                       (2)

The forcing of dummies matches the dimensions N rows and N pairs needed by the
actual chart [I,A^T]. It is not a constraint added to the target filter; zero
determinants enforce it through the explicitly supplied matrix.

Nonsingular rational common chart for every 0<t<1
-----------------------------------------------
Define B_t=B+tI, V_t=[B_t,C], and

  A_t^T=B_t^{-1}C.                                        (3)

B_t is nonsingular for every real 0<t<1. Here is the proof, including repeated
columns and zero rows. Each column of B is exactly one unit vector, so B e_j=
e_{f(j)} for a map f:[N]->[N]. Every orbit has transient length at most N and
eventual period at most N. If r=lcm(1,...,N), then f^{N+r}=f^N, hence
B^{N+r}=B^N. Every nonzero complex eigenvalue lambda of B satisfies lambda^r=1.
It has modulus 1. Zero eigenvalues are possible, but none equals -t for 0<t<1.
Thus det(B+tI)!=0. Repeated endpoint columns and zero dummy-second rows do not
invalidate the proof; they are allowed in a functional-map matrix.

Equation (3) gives [I,A_t^T]=B_t^{-1}V_t. Using (1) and the common row factor,

  det(B_t)^2 Z_K(A_t)=sum_{|S|=K}d_S(t)^2=:R(t).           (4)

All entries are real rational for rational t. Each d_S(t) has degree at most K,
because only K first-member columns are perturbed. Therefore R(t) is an integer-
coefficient polynomial of degree at most 2K=N. Equations (2)--(4) are the exact
bridge from graph perfect matchings to the fixed filter.

Finite-bit error bound for tiny perturbations
-------------------------------------------
Each term in a multilinear expansion of d_S(t) is the determinant of N unit
vectors, hence 0 or +-1. For 0<t and Kt<=1/2,

  |d_S(t)-d_S(0)| <= (1+t)^K-1 <= 2Kt.

Since |d_S(0)|<=1 and 2Kt<=1,

  |d_S(t)^2-d_S(0)^2|
       <=2Kt(2+2Kt)<=6Kt<=8Kt.

With at most 2^N subsets, this yields the total unnormalized weight bound

  Delta(t):=sum_{|S|=K}|d_S(t)^2-d_S(0)^2|
       <=8 K 2^N t.                                      (5)

Thus |R(t)-P(H)|<=Delta(t). For a desired 0<eta<=1/2 choose a dyadic t=2^{-q}
with t<=eta/(128 K 2^N). Then Delta<=eta/16 and

  q=O(N+log K+log(1/eta)).

The seemingly tiny real perturbation requires only polynomially many binary
bits. That fact permits a classical bit-complexity reduction; it does not
promise experimentally inexpensive precision.

Exact complexity consequence
----------------------------
Fix eta=1/2 in (5), so Delta<1/4. One exact query for Z_K(A_t), multiplied by
the exactly computable rational det(B_t)^2, returns R(t). Rounding R(t) to its
nearest integer returns P(H), including when P(H)=0. Hence exact evaluation is
#P-hard under a polynomial-time one-query metric reduction. As an independent
proof, interpolate degree-at-most-N R from N+1 values t_j=1/(j+2), j=0,...,N.
All are nonsingular by the functional-map argument; each value is recovered
from one Z query via (4). Lagrange interpolation at zero gives (2).

To restrict queries to integer A, clear a common denominator h: A'=h A_t.
Every K by K minor scales by h^K, so Z_K(A')=h^{2K}Z_K(A_t)=h^N Z_K(A_t).
For integer A, Z is in #P. A nondeterministic machine chooses the two subsets
by their bit strings, checks disjointness and cardinality, computes their integer
determinant in polynomial time, and chooses one fixed-length binary integer r.
It accepts iff r<|det A[I,J]|^2. A uniform polynomial bound on determinant bit
length permits a common number of r bits. The accepted path count is exactly Z.
This proves #P-completeness under the stated metric reductions. It does not
prove a parsimonious reduction or an NP-hard zero-support decision problem.

Approximation-preserving consequence
-----------------------------------
First decide whether H has a perfect matching by an ordinary polynomial-time
graph matching algorithm. Return zero if it has none. Otherwise P(H)>=1. Choose
t as in (5) with Delta<=eta/16 and call a hypothetical Z FPRAS with relative
accuracy eta/4. Multiply its output by det(B_t)^2. On the successful FPRAS event,

  |estimated_R/P(H)-1|
     <=(eta/4)(1+eta/16)+eta/16 < eta.

The failure probability is the oracle's requested failure probability. Matrix
size and precision are polynomial in the source graph and log(1/eta); the number
of oracle calls is one. This is an approximation-preserving reduction from
general-graph perfect matchings. It is not an approximation-hardness theorem.
Bipartite permanent already has an established FPRAS, and OA113 source-reports
an FPRAS for the general simple-unweighted source used here. Accepting OA113
therefore removes an open-problem consequence from this one-way transfer; it
does not provide the reverse Z-to-PM reduction needed for a Z algorithm.

Sampling-law consequence and counting by self-reduction
-------------------------------------------------------
For P=P(H)>0, let p_0(S)=d_S(0)^2/P, which is uniform on perfect matchings plus
forced dummies, and p_t(S)=d_S(t)^2/R(t). Normalization plus (5) gives

  TV(p_t,p_0) <=Delta/R(t)<=Delta/(P-Delta)<=Delta/(1-Delta). (6)

By (4), p_t is exactly the retained law of the fixed-filter target A_t. There is
no unresolved change of measure. A target sampler within TV zeta of p_t is within
zeta+Delta/(1-Delta) of p_0. The matching represented by a sample is decoded by
discarding dummies and, if used, the forced padding edge. Validate the result
with an ordinary graph check. Invalid outputs have probability at most this TV
error. Repeating until valid costs a bounded expected number of calls when this
error is below 1/4. For a worst-case bounded runtime, stop after O(log(1/gamma))
calls and use a polynomial-time found matching on the rare all-invalid event.
Conditioning on valid outputs adds at most twice the original TV error, and
the stopping event is charged. Taking zeta and Delta small constant multiples
of gamma therefore yields a gamma-accurate approximate uniform generator for
perfect matchings in polynomial time.

For completeness, the route from this generator to an FPRAS does not require a
black-box counting theorem. In a residual graph G with a perfect matching, pick
one vertex v. Under the uniform matching law, the probabilities alpha_e that
v is matched along its incident edges sum to 1. One is at least 1/m, where m
is the original vertex bound. Estimate all alpha_e simultaneously to additive
error a=eta/(64 m s), s=m/2, using polynomially many independently generated
samples. Use a generator whose TV bias is at most a/2, and Hoeffding bounds for
the remaining a/2 sampling error, with failure budgets union-bounded over at
most m^2 events. Choose the edge with maximum estimated probability. Its true
probability is at least 1/m-2a>=1/(2m), so its relative estimation error is at
most 2ma=eta/(32s). Delete its endpoints and repeat. Positive probability ensures
that the residual graph still has a perfect matching. The exact probabilities
telescope as

  product_{steps} alpha_e = P(empty_graph)/P(H)=1/P(H).

The reciprocal of their estimated product has relative error below eta on the
simultaneous good event. Each sample count is O(a^{-2} log(m^2/failure)), and
there are s stages. Every residual graph is encoded afresh by the same legal
fixed-filter construction; all sizes and bit lengths remain polynomial. This
establishes the sampler-to-FPRAS implication with all small probabilities and
precision charged. No NP=RP consequence follows from this implication.

Bit sizes, conditioning, and physical cost
-----------------------------------------
For t=2^{-q}, T=2^q B+I is an N by N integer matrix. Then

  B_t^{-1}=2^q adj(T)/det(T),

so det(T) is a common denominator for (3), and numerators/denominators have
O(N(q+log N)) bits by determinant/cofactor bounds. Exact inversion, determinant
evaluation, scaling, and optional interpolation run in polynomial bit time.
There are O(N^2) explicitly stored entries. N=O(E+m); the padding introduces
at most m+1 edges. The total acquired input length is polynomial in the graph
length and log(1/eta).

Large chart entries or condition numbers are permitted and accounted for; this
is not a bounded-condition-number reduction. Uniformly scale A_t by a rational
lambda with polynomial-bit encoding to make every entry at most 1/N in absolute
value. For example, let M_0 be 1 plus the largest numerator magnitude, and use
lambda=1/(N M_0). Then ||lambda A_t||_F<=1, hence ||lambda A_t||_2<=1. All fixed-
sector weights scale by lambda^{2K}, a known common factor, so counting hardness,
FPRAS transfer, and retained sampling law survive. Thus even rational contraction
inputs do not evade these conclusions. This rescaling can make physical success
very small, and does not fix condition numbers or physical gate precision.

W_K and det(I+AA*) are polynomial-time computable exact rational determinants
and coefficients, so the physical success probability is available as a charged
quantity. The reduction does not claim that it is inverse-polynomial, or that
filter-based physical rejection prepares successful samples in polynomial time.
No hardware temperature, fabrication, or physical gate-precision assumptions
are inserted. An efficient Gaussian description is a supplied mathematical
input model, not proof of inexpensive realization.

Positive Pfaffian expectation and an exact variance obstruction
--------------------------------------------------------------
Let n=2k, A be complex, and sigma_1,...,sigma_n independent uniform signs.
Write D_sigma=diag(sigma). Pfaffian minor summation for V=[I,A^T] gives, up to
a single global sign from column ordering,

  Pf(D_sigma A-A^T D_sigma)
       =sum_{|S|=k} det V[:,P(S)] product_{i in S}sigma_i.

Distinct square-free sign characters are orthogonal. Therefore

  Z_k(A)=E_sigma |Pf(D_sigma A-A^T D_sigma)|^2.             (7)

For real A, the squared Pfaffian is the determinant of the real skew matrix,
which is nonnegative; thus (7) is a legal positive unbiased determinant
estimator. It still has 2^n possible signs and does not by itself bound relative
variance, capacity, or mixing.

Take A to be a block diagonal matrix of d directed 4-cycle permutation blocks,
with n=4d and k=2d. On each block the Pfaffian is a signed sum/difference of two
independent degree-two sign characters. Its square is 0 or 4 with equal
probability. Block signs are independent. If Y is the random determinant in
(7), then

  E Y=2^d=Z_{2d}(A), E Y^2=8^d,
  Var(Y)/(E Y)^2=2^d-1.                                  (8)

For the direct sample mean, no nonzero sample is seen with probability
(1-2^{-d})^T after T attempts. Thus constant relative accuracy with probability
at least 3/4 needs T=Omega(2^d), and observing any nonzero sample takes 2^d
expected attempts. This is an estimator-specific obstruction, not hardness
of the family: its retained law samples independently between the two matchings
of each block. On the same easy family AA*=I, so

  W_{2d}(A)=binom(4d,2d),
  p_canonical=2^d/binom(4d,2d),
  p_grand_BCS=Z/det(I+AA*)=2^{-3d}.

This cleanly exposes rare success even when the classical target sampler is
easy. Equation (7) supplies an alternate positive representation but not a
polynomial relative-error estimator.

Equally informed baselines and falsifiers
----------------------------------------
* Exact enumeration uses binom(N,K) full-sector minors; general input enumeration
  uses binom(n,k) binom(n-k,k). It needs no extra matrix-acquisition oracle.
* The paired-Gram formulation makes support a linear matroid parity problem;
  support testing is tractable. Exact normalizer hardness is compatible with
  that support algorithm. Hardness cannot be inferred from zero-output detection.
* Pfaffian graph orientations count special graph parity families efficiently.
  Equation (7) is an unbiased baseline for all real A, with the explicit failure
  family (8). A better estimator or global sampler is not ruled out.
* The cycle2 bounded-rank exterior DP and bounded-block scalar DP are stronger
  baselines in those promised classes. The reduction does not prove hardness at
  fixed rank or bounded block size.
* The load-bearing proof can be falsified by a graph whose dummy-pair determinant
  support fails (2), a B_t singular at 0<t<1 despite every B column being a unit
  vector, an incorrect transpose/common determinant factor in (4), a unit-column
  expansion exceeding (5), or a retained-law mismatch in (6). All are explicit
  algebraic assertions, not appeals to postselection folklore.

2026-10-13 — independent audit of the comparison-only quadratic-flag decoder

Decision
  I found no mathematical counterexample to Sol03's partial-flag median/RM
  decoder under its exact supplied promise, with fresh independent fair bits
  and a strict total-order comparator. Its tail count and asymptotic query
  bound are correct. Its finite runs are exact implementation evidence, not
  evidence of novelty or practical advantage: through n=12 the measured
  full-domain mergesort control uses fewer comparisons and less time.

  On the stronger complete-flag promise, the root's random-match tournament
  is also sound. It selects among suffix-stabilizer directions before any
  polynomial interpolation, then interpolates only the winner. My independent
  implementation passed 33 exact triangular cases through n=12 and a cutoff
  test that returns UNKNOWN rather than a guessed bit. The current root file
  triangular_translation.py is the earlier all-candidates-interpolation
  implementation; this audit does not claim that the optimized tournament
  has already been integrated there.

  The complete-flag shortcut does not follow from Sol03's partial-flag
  promise. The four-bit example below is a bijective quadratic map with two
  valid initial flag gates, but a direction in the unacquired suffix space
  need not toggle one fixed output coordinate. Thus the two constructions
  have distinct scopes. Novelty, a practical win outside the synthetic
  complete-flag cases, and the wider mission remain UNKNOWN / NOT ACHIEVED.

Contract and notation
  Let Q=(q_1,...,q_n): F_2^n -> F_2^n be a supplied-to-the-theorem but
  hidden bijection, each q_i of algebraic degree at most two. The oracle takes
  two chosen raw inputs and returns C(x,y)=1 iff Q(x) precedes Q(y) in
  lexicographic (most-significant-bit-first) order. No ranks or coordinate
  values are exposed. Write

      B_i(x,y)=q_i(x+y)+q_i(x)+q_i(y)+q_i(0)

  for the polar form. The sequential flag promise through k coordinates is

      B_i(v_j,.)=0 for i<=j, and q_i(v_j)+q_i(0)=1[i=j].

  The flag vectors and quadratic-bijection promise are supplied assumptions;
  the learner must acquire the coordinate polynomials and witnesses using
  comparisons. Sol03 permits k=n-c and leaves c suffix bits to exact search.

Sol03's partial-flag projection and fiber sampler
  For a quadratic q, q(x+v)+q(x)=B_q(v,x)+q(v)+q(0). Consequently a flag
  direction v_j leaves every earlier bit q_i unchanged for all x and flips
  q_j for all x. The matrix of responses of q_1,...,q_k to
  v_1,...,v_k is triangular with diagonal one, so these vectors are
  independent.

  To project x onto a requested prefix b, process j=1,...,k and add v_j
  exactly when q_j(x) differs from b_j. Later toggles preserve all earlier
  bits, so the final point lies in the requested fiber. Let H be the span of
  the acquired toggles. The response map H -> F_2^k is an isomorphism. Every
  H-coset therefore has exactly one point in a given prefix fiber, and the
  projection is constant on each H-coset. If W is any linear complement to
  H, projection restricted to W is a bijection W -> fiber. Uniform seed bits
  in W followed by projection give an exact uniform fiber point. This uses
  only the acquired flag and does not require any common radical of future
  coordinates. The projection and uniformity proof does not need the future
  suffix coordinates to be linear.

Average median-label error
  At a randomized stage with k acquired bits, every prefix fiber has size
  N=2^(n-k). For a point of local rank r, the m odd fresh uniform samples
  from its own fiber vote according to whether each sampled rank is greater
  than r. The majority label is exactly the threshold test r >= R_med,
  where R_med is the sampled median rank. The true next bit is 1[r>=N/2].
  Averaged over a uniform point of any one fiber, the error is exactly
  E|R_med-N/2|/N.

  Couple each discrete sample rank to floor(N U_s), where U_s is uniform on
  [0,1). The sample median is floor(N U_(m+1)/2), and

      E|R_med/N-1/2| <= a_m + 1/N,
      a_m = E|Beta((m+1)/2,(m+1)/2)-1/2|
          = binom(m+1,(m+1)/2) / 2^(m+2).

  This is an average-over-the-global-cube bound because every prefix fiber
  has the same size N. For m=127, a_m=0.03519304608500757. If N>=256,
  eta=a_m+1/N<=0.03909929608500757.

Degree-two correction and failure budget
  For each interpolation point z, one trial chooses fresh uniform a,b,c and
  XORs the seven noisy labels at z+s for
  s in {a,b,a+b,c,a+c,b+c,a+b+c}. The sum over all eight vertices of a
  three-dimensional cube vanishes for every polynomial of degree <=2, so
  the seven-label parity equals the true value at z. Each shifted point is
  uniform globally. A union bound gives per-trial error <=7 eta; no
  independence among the seven cube vertices is needed. Different trials
  use fresh independent cube directions and fresh independent conditional
  samples. For N>=256, the majority gap is at least
  1/2-7 eta=0.22630492740494704.

  Let M=1+n+binom(n,2), the number of unisolvent coefficient points, and
  let t_k be the least odd integer at least

      ln(n M / beta) / (2 (1/2-7(a_m+2^-(n-k)))^2).

  Hoeffding and a union bound over M coefficient points and at most n
  randomized stages give total error <= beta, conditional on every earlier
  stage having succeeded. The first-failing-stage argument then gives the
  same unconditional bound. Each stage has 7 m t_k M oracle comparisons.
  The theorem assumes ideal fresh fair bits; seeded Python evidence is
  reproducible finite evidence and is not an entropy/independence guarantee.

Exact suffix acquisition
  Stop random stages once r=n-k<=c (Sol03 uses c=7). For each of the M
  coefficient points x, enumerate all 2^r complement seeds and project each
  to x's already acquired prefix fiber. The complement/projection proof above
  gives every fiber point exactly once. Query each y != x against x; the
  number of points y preceding x is exactly x's residual lexicographic rank
  in that fiber, an integer in [0,2^r-1]. Its r binary digits give the
  remaining coordinate values at x. Interpolating those M labels recovers
  each remaining quadratic exactly. This is M(2^r-1) comparisons, including
  r=0 as zero. No future radical, anchor table, or rejection sampler is
  hidden in this enumeration.

Sol03 query and source accounting
  With fixed m=127, c=7, and fixed beta, the comparison count is

      Q = sum_{k=0}^{n-c-1} 7 m M t_k + M(2^c-1)
        = O(n^3 log(n/beta));

  query input is 2nQ bits and the comparator returns Q bits. This is a real
  polynomial bound, but a large one: the exact n=8 bound is 3,326,892; n=12
  is 34,633,916. Analytic n>=16 entries in analytic_check.json are formulas,
  not executed runs. The executed source is a memoized synthetic rank oracle.
  If U distinct inputs are ranked, dense source rank generation costs
  O(U n^3) bit operations, where U is the number of distinct ranked inputs
  and U<=min(2Q,2^n). Add Q cache lookups/comparisons (O(Q n) bit work under
  linear-bit key hashing/comparison); the logical cache payload is 2nU bits.
  Without source memoization, charge O(Q n^3), not merely the
  learner's number of comparator calls. Source generation/setup and
  post-acquisition checks are separate from comparator-query acquisition.

  Learner-side projection also costs. Each stage draws 7 m t_k M uniform
  complement seeds (n-k bits each), plus 3n t_k M cube-direction bits.
  Each projected sample performs k prefix-toggle checks unless served by
  the sampler cache. In addition, noisy_bit recomputes compiler.prefix(point)
  once per median label; this is 7 t_k M k quadratic evaluations per stage
  and is not included in the recorded fiber_projection_q_evaluations field.
  Dense evaluation of one quadratic is O(n^2) bit operations in the
  straightforward implementation. The sampler cache can have up to the
  number of draws in entries; its logical key/value payload is about 2n bits
  per entry, before Python object overhead. These costs are distinct from
  oracle calls and must be included in a wall-time/memory comparison.

  The executed n=8,10,12 Sol03 runs used respectively 3,326,892; 14,593,824;
  and 34,633,916 comparisons, with acquisition times 0.86; 4.75; and 14.73
  seconds on this local synthetic teacher. Exact full-domain merge-sort
  controls used 1,735; 8,443; and 44,546 comparisons in 0.0015; 0.0092; and
  0.0544 seconds. These controls do not refute polynomial-time asymptotics,
  but they show no practical advantage at the measured sizes. An equally
  informed implementation of the same conditional-median/RM composition
  ties its query count; the method components alone are not a novelty claim.

Complete-flag equivalence and improved translation tournament
  A complete flag v_1,...,v_n is a basis. To see independence, if a nonempty
  linear combination vanished, take its least active index j. In the
  directional response of q_j, all active later v_i contribute zero and
  v_j contributes one, since v_i lies in rad B_j for i>=j. This contradicts
  the zero vector. Let u_j be affine linear coordinates dual to this basis.
  Since v_j lies in rad B_i for j>=i, every quadratic monomial of q_i in
  the u-coordinates involves only u_1,...,u_(i-1). The directional response
  constraints give coefficient one on u_i and zero on u_j for j>i.
  Therefore

      q_i = constant_i + u_i + g_i(u_1,...,u_(i-1)), deg(g_i)<=2.

  Conversely, any hidden-affine triangular quadratic map of this form has a
  complete flag given by the coordinate directions dual to u. Thus a
  complete quadratic polar-toggle flag and an affine hidden-variable
  triangular quadratic permutation are equivalent promises (up to bit
  offsets/order conventions).

  For H_k={v: q_i(x+v)=q_i(x) for every x and i<=k}, the complete triangular
  form gives H_k=span(v_(k+1),...,v_n), dim n-k. Any nonzero v in H_k has a
  least hidden-coordinate index j>k with u_j(v)=1. All earlier q_i remain
  fixed and q_j flips constantly, so

      f_v(x)=1 xor C(x,x+v)=q_j(x).

  A basis of H_k contains a direction with u_(k+1)(v)=1, so its candidate
  coordinates include the true next bit. The learner can select the earliest
  candidate without interpolation: for each pair v,w in the tournament,
  repeatedly draw fresh uniform global x and query f_v(x),f_w(x) via two
  comparisons until the labels agree. If the underlying coordinates q_a,
  q_b are distinct, bijectivity makes (q_a(x),q_b(x)) uniform on F_2^2, so
  agreement occurs with probability 1/2 per independent draw. If they are
  the same coordinate, agreement is certain. At a match with common value c,
  C(x+v,x+w)=c iff v toggles the earlier coordinate; it is 1-c iff w does.
  If both toggle the same coordinate, either witness is acceptable. A
  tournament over the dim(H_k) directions therefore returns a witness for
  the earliest candidate. Only that witness is interpolated, with M
  comparisons, then H_{k+1} is recomputed from the acquired quadratics.

  There are P=binom(n,2) pair contests in total. Unbounded Las Vegas expected
  comparison cost is at most nM+5P: for distinct candidates the geometric
  match count has mean two, at two queries per attempt plus one priority
  query; equal candidates cost three. For cutoff T=ceil(log_2(P/beta)),
  return UNKNOWN on a pair with no match in T attempts. With fresh independent
  global bits, its total false-UNKNOWN probability is at most P 2^-T<=beta.
  A completed run is exact. Worst-case comparisons are

      nM + (2T+1)P,

  with 2n input bits per comparison and at most nTP random bits for matching.
  Thus for constant beta this route uses O(n^3) comparisons and O(n^4) query
  argument bits. The executable optimized_tournament_audit.py independently
  implements the route; its 33 seeded cases n=2,...,12 recover every
  coordinate body exactly, have zero rank/inverse errors, and exhaustively
  verify prefix projection uniformity for n<=8. Its forced no-match case
  returns UNKNOWN after the cap. Actual comparison counts are 398--418 at
  n=8 and 1,208--1,224 at n=12 (for three seeds each). These are finite implementation checks;
  the randomized cutoff bound is established by the proof above, not the
  finite seeds.

Partial-flag boundary counterexample
  Consider

      q_1=x_0+x_2 x_3,  q_2=x_1+x_2 x_3,  q_3=x_2,  q_4=x_3.

  This is a bijection: x_2,x_3 are the last outputs and recover the mixing
  terms in x_0,x_1. All coordinates are quadratic. The first two flag gates
  hold with v_1=e_0 and v_2=e_1; the first three output coordinates do not
  extend to a sequential flag (the exact compiler check returns
  [True,True,False] on the first three gates). At stage zero, for v=e_2,
  the translation label is

      1 xor C(x,x+e_2) = x_2 + x_0 x_3,

  which is not any q_i. Hence “every suffix-space direction is one rank bit”
  cannot be inferred from a partial flag, and the random-match tournament
  has no proof on Sol03's broader partial-flag interface. This example does
  not refute Sol03's conditional-median/RM algorithm.

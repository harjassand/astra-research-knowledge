## What was actually acquired

Hirai2608.13972v1 Section3.2 was implemented with the source step sizes,
source order, exact weights, exact Q/residue arithmetic, and best completed
sweep selection. The required Lemma2.3 apartment oracle was explicitly acquired
by reverse-row Gaussian elimination; no generic subspace separation, LP or
exhaustive subspace enumeration was substituted. The kernel returns a feasible
geometric-field dual scalar and a flag. It does not return a primal packing
vector or a rational lift of a finite-field flag.

The cycle16 whole-polytope theorem supplies a single good-prime event protecting
all nonnegative objectives/caps on each fixed input. It does not imply equal
individual incidence profiles or iterates. Under that event, source convergence
turns the finite-field scalar into an original-Q additive approximation. This
cycle replaces the theoretical exact-primality sampler with the explicitly
charged bounded-error sampler below and executes the SAME optimizer in each
field. The mathematical expected polynomial bit-time consequence is retained;
the short measured runs are a separate finite experiment.

## Bit and resource charges

For N source sweeps, let K=ceil(sqrt(N)), Du=lcm of cap denominators, and
D=(m+1)Du lcm(1,...,K). Every stored weight is an integer multiple of1/D,
and its numerator is at most cmax*D. This follows inductively from the source
increments and integer clipping endpoints. A uniform bound is

log2D<=log2(m+1)+sum_j log2den(uj)+Klog2K.

A full objective has denominator dividing D*Du, because multiplication by a
cap may contribute its denominator AGAIN. Its value is at most(n+m)cmax.
This completes the scalar bit accounting; it does not bound rational flag
heights. Actual coordinate denominator sizes were37/39bits. The rational
field operand maxima11/24bits show no height obstruction on these runs.

The finite-field kernel uses O(Nmn^3) field operations, apart from the same
order of scratch objective alignments and scalar/trace bookkeeping. With
N=O((m+1)^2 cmax^2 n^2 epsilon^-2), the resulting generic guarantee is
polynomial in numeric cmax, n,m, input/cap height, epsilon^-1 and log(delta^-1),
not in log(cmax) for arbitrary large binary costs. Rational input subspace
bases may be cleared columnwise before the integer-input theorem; quiver
arrows instead require whole-arrow clearing, a different interface.

The instrumented implementation stores every trace, with O(Nmn^2) geometric
coordinates plus rational weights; it is not the source's smallest-space
implementation. On a true prime those coordinates have at most log2p bits,
giving a polynomial but potentially large trace cost. A generic theoretical
horizon is not an affordable-execution claim on this machine.

## Decisive discrimination, prior and next gate

The direct family controller acquired exact optima8/3 and4 from the same
matrices and caps, in one0.0011845s core execution. The universal proofs are in
DIRECT_FAMILY_CERTIFICATES.md. Consequently the family is rejected as a useful
stress test for generic rational-height growth or as evidence of a practical
algorithmic advantage. The Q and modular runs are descriptive correctness
evidence, not a timing study. Finite-field entries were larger than rational
entries here. This null result is retained.

Nearest method prior is the source algorithm itself and its Goodwin et al.
Hadamard-space prerequisite. General modular inconsistency/random-prime ideas
are older HMPS/KPS results. GGOW1607.06711v4 provides exact BL membership in
polynomial inputbits/numeric common denominator, and BFGOWW1804.04739v2 weak
moment-polytope approximation is a stronger broad comparison than a toy LP.
No first-approximation, first-modular-method or broad speed advantage is claimed.
Priority remains UNKNOWN for the exact full-polytope application.

The strongest next falsifiable technical step is to find an admissible source
order/cost/cap/hinge pattern that forces intrinsic weighted-subspace height
growth in an ACTUAL Hirai trajectory, and prove/measure it against a basis-free
partial-flag representation. A generic lattice-squaring example or removable
complete-flag gauge is not enough. A separate route is acquiring a generic
primal lower certificate to replace fixture truth; no such solver is silently
provided here. The source-level scalar interface and saved complete traces are
usable for either investigation without another bibliography-only cycle.

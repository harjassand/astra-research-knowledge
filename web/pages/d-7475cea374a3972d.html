## Research result: finite-power Bernoulli extraction

The strongest mechanism I can establish is an **exact Bernoulli splitting of a finite power of the defect system \(K\)**\.

Assume \(G\) is countably infinite and torsion-free, as in the intended Family 197 application, and retain

\[
ab=1,\qquad ac=0,\qquad c\neq0,\qquad
X=\mathbb F_2^G,\qquad K=\ker T_a.
\]

There is a finite integer \(m\) and a p.m.p. \(G\)\-system \(R\) such that

\[
\boxed{K^m\cong_G X\times R.}
\]

This gives two further exact consequences\:

\[
\boxed{X\cong_G X^2\times R}
\qquad\text{and}\qquad
\boxed{K^{\mathbb N}\cong_G K^{\mathbb N}\times B_h}
\]

for every finite-entropy Bernoulli shift \(B_h\)\.

The construction uses a measurable equivariant coloring of the finite-range dependencies in \(K\), followed by an explicit linear right inverse. It does not require the previously invoked relative Bernoulli-isomorphism theorem.

**This does not establish \(2^G\cong_G4^G\)\.** The residual \(R\) remains, and none of the displayed identities permits its cancellation. The following analysis identifies the exact construction, a different possible route through Bernoullicity of \(R\), and the obstruction that remains.

### A rigorous obstruction to the original tail-cancellation route

There is a stronger failure than merely knowing that \(D=\bigcap_n B^nX\) is nontrivial.

Set

\[
E_n=B^nA^n,\qquad Q_n=E_n-E_{n+1}=B^nPA^n.
\]

For Haar-random \(x\in X\) and any fixed \(g\in G\), the sequence

\[
\boxed{\bigl((E_nx)(g)\bigr)_{n\ge0}
\text{ consists of independent fair bits}.}
\]

Indeed, for each \(N\), the commuting orthogonal projections

\[
Q_0,\ldots,Q_{N-1},E_N
\]

decompose \(X\) into independent Haar components. Each component is a nonzero \(G\)\-invariant binary group shift, so evaluation at \(g\) is fair. Since

\[
E_n=E_N+\sum_{j=n}^{N-1}Q_j,
\]

the vector of evaluations \((E_0x(g),\ldots,E_Nx(g))\) is an invertible linear transformation of \(N+1\) independent fair bits.

Consequently,

\[
\Pr\bigl((E_nx)(g)\neq(E_mx)(g)\bigr)=\tfrac12
\qquad(n\neq m).
\]

Thus **no deterministic subsequence of the canonical tail projections converges in probability**, even at one coordinate. A proof relying on a limiting \(B^nA^n x\) cannot work. This does not rule out an entirely different measurable conjugacy.

## 1\. Explicit construction and inverse

Work with the left Bernoulli action on \(X=\mathbb F_2^G\), and write

\[
p=1-ba,\qquad P=T_p.
\]

Since \(ab=1\),

\[
p^2=p,\qquad AP=0,\qquad P(X)=\ker A=K.
\]

The relation \(ac=0\), \(c\ne0\), ensures \(p\ne0\)\.

Let \(S=\operatorname{supp}(p)\)\. With the convolution convention

\[
(Pu)(g)=\sum_{s\in S}u(gs),
\]

\(S\) is a finite, nonempty set. Set

\[
d=|SS^{-1}|,\qquad m=d+1.
\]

### A measurable equivariant coloring

Because \(K=P(X)\) is a factor of the Bernoulli shift, its Haar action is mixing. Moreover, \(K\) contains a nonzero finitely supported configuration: \(P\delta_t\) for a suitable \(t\)\.

When \(G\) is torsion-free, this implies that the action on \(K\) is essentially free. Indeed, a nonidentity \(g\) has infinite order, cannot fix every finitely supported element of \(K\), and acts ergodically on \(K\) by mixing. Hence its fixed-point set has Haar measure zero.

Write \(K_0\subseteq K\) for the invariant conull free part.

Consider the Borel graph on \(K_0\) whose edges join \(\eta\) to \(t\eta\), for

\[
t\in SS^{-1}\setminus\{e\}.
\]

Its maximum degree is at most \(d-1\)\. The Kechris–Solecki–Todorcevic finite-degree coloring theorem supplies a Borel proper coloring

\[
f:K_0\longrightarrow\{1,\ldots,d\}.
\] :chatgpt-content-reference{index="0"}


For a seed \(\eta\in K_0\), define a coloring of \(G\) by

\[
\chi_\eta(g)=f(g^{-1}\eta).
\]

It satisfies two crucial properties\:

\[
gS\cap hS\ne\varnothing,\quad g\ne h
\quad\Longrightarrow\quad
\chi_\eta(g)\ne\chi_\eta(h),
\]

and

\[
\chi_{t\eta}(tg)=\chi_\eta(g).
\]

The first separates dependencies. The second guarantees equivariance.

### Extracting independent fair bits

Take independent Haar-random elements

\[
\eta,\kappa_1,\ldots,\kappa_d\in K,
\]

and define

\[
\boxed{Y(g)=\kappa_{\chi_\eta(g)}(g).}
\]

Conditional on \(\eta\), the random field \(Y\) is exactly a fair binary Bernoulli process.

To see this, express each reservoir as \(\kappa_j=PU_j\), where the \(U_j\) are independent Haar-random elements of \(X\)\.

Each \(\kappa_j(g)\) is the parity of the input bits in \(gS\)\. Sites assigned the same color have disjoint input windows. Sites assigned different colors use independent reservoirs.

Consequently, for every finite \(F\subset G\),

\[
\Pr\bigl(Y|_F=y\mid\eta\bigr)=2^{-|F|}
\]

for every \(y\in\mathbb F_2^F\)\.

Thus \(Y\) has Haar law on \(X\) and is independent of \(\eta\)\.

### Constructing a right inverse

Fix \(s_0\in S\)\. For every \(g\in G\), define

\[
w_g=P\delta_{gs_0}\in K.
\]

These finitely supported toggles satisfy

\[
w_g(g)=1,
\]

and, crucially,

\[
h\ne g,\quad\chi_\eta(h)=\chi_\eta(g)
\quad\Longrightarrow\quad w_g(h)=0.
\]

For \(y\in X\), define

\[
\bigl[S_\eta(y)\bigr]_j
=
\sum_{\substack{g\in G\\\chi_\eta(g)=j}}
y(g)w_g,\qquad j=1,\ldots,d.
\]

Although the displayed sum is infinite, it is well-defined coordinatewise: each toggle has support in a fixed finite translate of \(SS^{-1}\), so only finitely many terms contribute to each output coordinate.

Let

\[
T_\eta:K^d\to X,\qquad
T_\eta(\kappa_1,\ldots,\kappa_d)(g)
=\kappa_{\chi_\eta(g)}(g).
\]

By the toggle identities,

\[
\boxed{T_\eta S_\eta=I_X.}
\]

This is an exact linear right inverse for every fixed admissible seed \(\eta\)\.

### The residual and the exact conjugacy

Define

\[
r=\kappa-S_\eta(T_\eta\kappa).
\]

Then \(r\in\ker T_\eta\)\.

Introduce the residual system

\[
R=
\left\{(\eta,r)\in K_0\times K^d:
T_\eta r=0\right\},
\]

equipped with Haar measure on the fiber \(\ker T_\eta\), integrated against Haar measure on \(\eta\)\.

The forward map is

\[
\Phi(\eta,\kappa)
=
\left(
T_\eta\kappa,\,
\bigl(\eta,\kappa-S_\eta(T_\eta\kappa)\bigr)
\right).
\]

Its inverse is explicitly

\[
\boxed{\Phi^{-1}(y,(\eta,r))
=(\eta,r+S_\eta y).}
\]

For fixed \(\eta\), this is a compact-group isomorphism

\[
K^d\cong X\times\ker T_\eta.
\]

It sends Haar measure to product Haar measure. Since the \(X\)\-marginal is identical for every \(\eta\), \(Y\) is independent of the entire residual \((\eta,r)\)\.

Finally, the identities

\[
T_{t\eta}(t\kappa)=tT_\eta(\kappa),
\qquad
S_{t\eta}(ty)=tS_\eta(y)
\]

verify \(G\)\-equivariance of both maps.

This proves the finite-power splitting stated above\:

\[
\boxed{K^{\,|SS^{-1}|+1}\cong_G2^G\times R.}
\]

The argument uses only the algebraic premises, torsion-freeness, elementary Haar probability, and the Borel coloring theorem.

## 2\. Consequences for Bernoulli entropy

The inherited algebraic identity has the explicit Haar-preserving isomorphism

\[
X\longrightarrow X\times K,\qquad
x\longmapsto(Ax,Px),
\]

with inverse \((u,k)\mapsto Bu+k\)\.

Iterating gives \(X\cong_GX\times K^m\)\. Combining it with the theorem yields

\[
X\cong_G X^2\times R.
\]

Repeating that identity produces, for every integer \(n\ge1\),

\[
\boxed{X\cong_G X^n\times R^{n-1}.}
\]

There is now a direct way to establish the inherited infinite weak Pinsker entropy claim without relying on Bowen–Hoff–Ioana.

Given \(h>0\), choose \(n\) such that \(n\log2>h\)\. Seward's isomorphism theorem says that Bernoulli shifts over any countably infinite group with equal base Shannon entropy are measurably isomorphic. Consequently,

\[
X^n\cong_G B_h\times B_{n\log2-h}.
\] :chatgpt-content-reference{index="1"}


Therefore

\[
X\cong_G
B_h\times
\bigl(B_{n\log2-h}\times R^{n-1}\bigr).
\]

**Conditional on the torsion-free group-ring witness, this establishes**

\[
\boxed{h_{\mathrm{WP}}(2^G)=\infty.}
\]

Separately, taking countably many copies of the finite-power splitting gives

\[
K^{\mathbb N}\cong_G X^{\mathbb N}\times R^{\mathbb N}.
\]

The first factor is a Bernoulli shift with nonatomic standard base \(\mathbb F_2^{\mathbb N}\)\. Such a base absorbs every other standard probability base under measure-space isomorphism. Hence the earlier stabilized absorption statement actually extends to **every standard-base Bernoulli shift**, including those of infinite base entropy.

None of this cancels the residual in \(X\cong X^2\times R\)\.

## 3\. The strongest remaining route: Bernoullicity of a finite defect power

The construction suggests a route different from self-absorption or measurable cancellation.

The exact unresolved lemma is

\[
\boxed{
K^{\,|SS^{-1}|+1}
\text{ is measurably isomorphic to a nontrivial Bernoulli shift.}
}
\]

Equivalently, for the explicit residual constructed above\:

\[
\boxed{X\times R\text{ is Bernoulli}.}
\]

If this lemma holds, with

\[
K^m\cong_G (L,\lambda)^G,\qquad H(\lambda)>0,
\]

then

\[
\begin{aligned}
2^G
&\cong_G2^G\times K^m\\
&\cong_G(\mathbb F_2\times L)^G.
\end{aligned}
\]

The new Bernoulli base has entropy

\[
\log2+H(\lambda)>\log2.
\]

That would **settle Bowen's unequal-entropy question affirmatively for \(G\)**, without first proving \(K^2\cong K^2\times B_\varepsilon\)\.

A stronger sufficient statement would be \(R\) itself Bernoulli, but the product \(X\times R\) being Bernoulli is all that this approach needs.

The difficulty is genuine. \(K^m\) is a finite-range-dependent algebraic process and has an exact independent Bernoulli factor, but the coordinates retained in \(R\) need not admit an independent generating partition. General nonamenable-group theory does not allow us to infer Bernoullicity simply because a system is a factor of a Bernoulli shift; Popa-type examples demonstrate that this implication fails. Those examples do not directly refute the more specific complemented, projective case here. [pldml.icm.edu.pl](https://pldml.icm.edu.pl/pldml/element/bwmeta1.element.doi-10_1515_agms-2016-0006?q=422f04d4-11df-4d58-82dd-c928b38a63ae%246\&qt=IN_PAGE)

A productive next mathematical target would therefore be an **iid generating theorem for finite powers of split linear cellular-automaton images**, exploiting the projective identity \(P^2=P\)\. That is substantially more precise than asking for abstract cancellation.

## 4\. Two additional safeguards against false proofs

**The stabilized defect cannot simply be transferred back to \(X\)\.**

The canonical map

\[
\pi:X\longrightarrow K^{\mathbb N},\qquad
\pi(x)=(PA^n x)_{n\ge0}
\]

has kernel \(D=\bigcap_nB^nX\)\.

Because \(\varepsilon(b)=1\), the nonzero constant configuration \(\mathbf1\) satisfies \(B\mathbf1=\mathbf1\)\. Hence

\[
\pi(x+\mathbf1)=\pi(x)
\]

for every \(x\)\.

In fact, \(\pi\) cannot become injective by discarding null sets. For any conull \(E\subset X\), translation invariance of Haar measure makes \(E\cap(E+\mathbf1)\) conull. Thus almost every retained configuration has a distinct retained partner with exactly the same image.

So the *specific* infinite-defect factor map cannot provide the missing measurable inverse.

**Topological conjugacy cannot supply the desired absorption.**

Since \(ab=1\), the augmentation satisfies \(\varepsilon(a)=1\)\. Thus \(K\) contains no nonzero constant configuration and

\[
|\operatorname{Fix}_G(K^m)|=1.
\]

But

\[
|\operatorname{Fix}_G(K^m\times X)|=2.
\]

Consequently, a full topological \(G\)\-conjugacy \(K^m\cong K^m\times X\) is impossible. A successful absorption theorem would have to be genuinely measurable and operate modulo null sets.

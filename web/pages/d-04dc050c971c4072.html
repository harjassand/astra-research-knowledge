# Correctable balls and a distance consequence of the actual anchor

7 October 2026. pde_transport9, verified Sol/max; no nested workers.

actual uniform closed-error anchor.** Root proposed this consequence;

an independent substitute for that load-bearing anchor's final gate.

The source-family/diagonal/geometric-admission interface is exactly the
anchor gate. Let i>=1 be the number of replacements, lambda the fixed
physical dilation, a the one-step projection slack, r*=a lambda/(lambda-1)
and r0=r*+1. The seed has logical errors, so stop at level1 rather than0.

If a closed error e at level i is supported in B(x,r) with

    r <= lambda^(i-1),

apply the degree-one chain projection i-1 times. Both CSS sector maps
preserve closedness. Its support radius at level1 is at most

    r_(i-1)=r/lambda^(i-1)+r*(1-lambda^(-(i-1)))
            <=1+r*=r0.                             (1)

The actual fine-level anchor fills ALL closed errors of that radius
using original level1 checks. Each HPL identity e+I P e=D K e lifts
a projected boundary to a fine boundary. Recursively lifting proves
that the original e is a global boundary. No assertion about seed
logical errors, original unknown generator coefficients, or the radius
of an arbitrary global solve is used.

Thus every physical ball of radius lambda^(i-1) is correctable for
both Pauli sectors. Equivalently, no nontrivial logical Pauli can be
supported there. A general Pauli in the CSS centralizer decomposes
into closed X and Z components, each with support contained in the
original support; if both are boundaries it is a stabilizer modulo
an irrelevant phase.

Let a nontrivial logical Pauli have weight w. At least one of its
closed CSS components is nontrivial in its corresponding homology.
Split that component by the graph joining supported qubits whenever
they share a syndrome check. Each component is closed, because any
syndrome check touching two of them would join them. If every
component were a boundary their sum would be a boundary, so at least
one component is nontrivial. Let its weight be w'<=w.

For any adjacent qubits of that graph, the physical distance is<=2
via their common check, since actual Tanner edges have length<=1.
A spanning tree on w' vertices therefore puts the entire component
in the ball centered at any one of its qubits with radius<=2(w'-1).
If2(w-1)<=lambda^(i-1), this nontrivial component fits in the
correctable ball just proved, a contradiction. Consequently

    d_i >= floor(lambda^(i-1)/2)+2.                 (2)

This deliberately conservative root-centered estimate does not use
a Euclidean minimum-enclosing-ball improvement. Folded overlaps do
not hurt it: graph paths still have the length bound and unrelated
physical crossings do not join components.

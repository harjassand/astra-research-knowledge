Fix the first-order parameters J,tau,kappa and any nonzero smooth
coexistence minimizer theta as in proof.txt; mu=int rho>0,v=int rho(1-rho)>0.
For a constant a>=0 put

 lambda_L=lambda_*(kappa)-a log(L)/L,

For every a>0, this field is STRICTLY below lambda_* at every L>1.
Nevertheless if r=1/2-tau a mu>0, the same macro window eps>0 obeys

 liminf_L Tr_{N>eps L}exp(-tau B_L^a)/L^r
                                        >=2sqrt(2v/pi)>0,

Hence every fixed particle cutoff loses all mass and the number-preserving
ideal Bose distance tends1, even though the field approaches the critical
point from its strict vacuum side. The ideal Bose comparison state has
the limiting parameter lambda_*<lambda_c. This result is NOT uniform
failure on every moving approach; it is a precisely specified family.

Proof. Parameter linearity gives for the SAME product trial
<B_L^a>=<B_L>+(a log L/L)sum_i rho_i
       =a mu log L+o(1).
The O(1/L) endpoint/contact quadrature in proof(3.3) and

 Z_hi^a>=(q/p_max)exp[-tau(a mu log L+o(1))]
        >=[2sqrt(2v/pi)+o(1)]L^(1/2-tau a mu).

# Rational chart refinement of the fixed-local X/Z counterexample

This independently checks b_compute's proposed replacement of the real exponential chart in `real_ift_counterexample_audit.md`. It preserves the exact Jacobian and every stated contraction bound. The refinement makes the existence theorem algebraic for any specified rational parameter inside the certified interval.

For real skew \(\Omega(x)=\sum_k x_k E_k\), put
\[
 R(x)=(I-\Omega(x)/2)^{-1},\qquad
 Q(x)=(I+\Omega(x)/2)(I-\Omega(x)/2)^{-1}=2R(x)-I,
 \qquad U(x)=U_0Q(x).
\]
The real matrix \(I-\Omega/2\) is always invertible: its smallest singular value is at least one because
\((I-\Omega/2)^T(I-\Omega/2)=I-\Omega^2/4\ge I\).
Thus \(\|R\|_{\rm op}\le1\), and \(Q\) is orthogonal. Differentiating gives
\[
 \partial_iQ=RE_iR,
\]
\[
 \partial_j\partial_iQ
 =\tfrac12(RE_jRE_iR+RE_iRE_jR).
\]
Since \(\|E_i\|_{\rm op}=1\), these derivatives have operator norm at most one. At zero, \(\partial_iQ=E_i\), exactly as for the exponential chart. Therefore the selected 756-by-756 Jacobian is the same rational matrix with verified determinant 47716 modulo 65521; the conjugated observables retain entry derivative bounds 2 and 4. The infinity-norm contraction estimates, radius \(r\), and interval \(\epsilon\) in the preceding audit hold unchanged.

The \(1/\sqrt8\) Bell normalization cancels in the conjugation \(U_0^TAU_0\), so it introduces no irrational coefficient into \(F\). Fix, for example, the explicit rational \(s_* =\epsilon/2>0\). Consequently \(x_*\) is an isolated solution of a rational polynomial system, hence each coordinate is real algebraic.

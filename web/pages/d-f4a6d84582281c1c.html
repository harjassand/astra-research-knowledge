# Reference flux certificate for global continuum inverse stability

2026-10-06. Exact question: can the frozen finite boundary-measurement certificate be transferred to the continuum conductivity PDE without treating mesh agreement as proof? Answer for the two-current plan: yes, using feasible flux witnesses, a quadratic reference derivative bound and a continuum resolvent remainder. This does not transfer the finite noisy reconstruction experiment or prove current-design optimality. Publication novelty is unverified.

## Continuum and supplied physical interface

Let Ω=(0,1)². Put φ₁=1 on its upper-left quadrant and φ₂=1 on the lower-right strip x>1/2,y<1/4, zero elsewhere. The known conductivity is σ_θ=1+θ₁φ₁+θ₂φ₂, with θ∈[-1/20,1/20]². Work on V=H¹(Ω)/R with reference energy a₀(u,z)=∫∇u·∇z. The actual boundary currents g_j and voltage test functions h_jl are the unchanged, exactly centered P1 traces from the frozen Cycle2 design. Their mean is zero. Currents have total squared L² boundary norm one and each detector has L² norm one. There are two exposures and two independently noisy scalar tests per exposure. Analog access to those known traces and the stated noise law are supplied assumptions, not learned hardware capability.

For any admitted trace r, let u_r(θ) solve

    a_θ(u_r,z)=∫∂Ω r z,  a_θ(u,z)=∫Ω σ_θ∇u·∇z.

Coercivity σ_θ≥.95 and the trace theorem ensure existence on V. The output is y_jl(θ)=∫∂Ω h_jl u_gj(θ). Constants in representatives do not matter. The discrete P1 space V_h⊂V is the fixed four-by-four-cell triangulation; u_r,h is its exact Galerkin solution. No H² regularity is assumed.

## Exact energy error majorants

At θ=0, a field q_r∈H(div,Ω) with div q_r=0 and q_r·n=r gives

    ||u_r−u_r,h||₀ ≤ η_r:=||q_r−∇u_r,h||₂.

Indeed for any z∈V, integration by parts gives a₀(u_r−u_r,h,z)=∫(q_r−∇u_r,h)·∇z; insert z=u_r−u_r,h and use Cauchy–Schwarz. Boundary traces hold weakly, so no classical normal differentiability of the true state is required.

For each parameter direction i and discrete state u_r,h, define the auxiliary continuum state w_r,i by

    a₀(w_r,i,z)=∫φ_i∇u_r,h·∇z.

Its exact Galerkin projection w_r,i,h satisfies the same equation for z∈V_h. A divergence-free q_r,i∈H(div) with zero boundary normal gives

    ||w_r,i−w_r,i,h||₀
      ≤ η_r,i:=||q_r,i−(∇w_r,i,h−φ_i∇u_r,h)||₂.

This follows by the same residual argument. The target includes the discrete volume-source vector φ_i∇u_r,h; equilibrating only ∇w_r,i,h would certify the wrong problem.

## Quadratic reference derivative transfer

Let e_r=u_r−u_r,h at θ=0. Galerkin orthogonality a₀(e_r,V_h)=0 gives

    ∫φ_i∇e_g·∇u_h,h
      =a₀(e_g,w_h,i−w_h,i,h).

The exact response derivative is −∫φ_i∇u_g·∇u_h. Expand both states into their discrete and error parts. The two cross terms are controlled by the auxiliary error identity, and the error-error term by ||φ_i||∞=1. Consequently, for each physical scalar row,

    |∂_i y(0)−∂_i y_h(0)|
      ≤ η_g η_h,i + η_h η_g,i + η_g η_h =: d_row,i.

Thus the reference Jacobian difference has operator norm at most

    D₀=[Σ_{rows,i} d_row,i²]^(1/2).

This is a certified reference bound. Applying it without auxiliary states would instead give large linear energy-error terms and can erase the margin.

## Uniform continuum remainder from the reference

Define C_i on V by a₀(C_i u,z)=∫φ_i∇u·∇z. Because the two regions are disjoint, C_i≽0 and C₁+C₂≼I. For H_θ=θ₁C₁+θ₂C₂, therefore ||H_θ||≤ρ=1/20, and ||C_v||≤||v||₂. The continuum state is u_r(θ)=R_θu_r(0), R_θ=(I+H_θ)⁻¹. The resolvent identity gives

    ||R_θ C_v R_θ−C_v|| ≤ f(ρ)||v||₂,
    f(ρ)=ρ(2−ρ)/(1−ρ)².

Let U_j² be the discrete reference energy of current g_j. Let V_j² be a certified operator-norm upper bound for the discrete reference map from the k_j detector coefficients to their states. Orthogonality yields exact Pythagoras, hence

    ||u_gj(0)||₀² ≤ U_j²+η_gj²,
    ||[u_hjl(0)]_l||_op² ≤ V_j²+Σ_l η_hjl².

The second inequality uses the orthogonality of the discrete state map and its error map; the Frobenius bound Ση² controls the error map operator norm. Hence the complete continuum Jacobian varies from its continuum reference by at most

    β_cont=f(ρ)[Σ_j (U_j²+η_gj²)(V_j²+Σ_lη_hjl²)]^(1/2).

If α_h is a certified lower singular value of the discrete reference Jacobian, then every θ has a Jacobian differing from that one fixed discrete reference by at most D₀+β_cont. Integrating along any segment in the convex parameter box gives the GLOBAL statement

    ||y(θ)−y(η)||₂ ≥ (α_h−D₀−β_cont)||θ−η||₂.

This proof controls global cancellation; a lower singular value at every point alone would not. It uses only reference flux computations, not a parameter grid or assumed derivative convergence.

## Constructive continuum-feasible flux witnesses

rank_pde represents q=(ψ_y,−ψ_x), where ψ is continuous piecewise P2. Its curl is affine on each triangle, divergence-free exactly and has continuous normal trace because the tangential derivative of the shared edge trace agrees. On the square boundary, take ψ to be the exact primitive of the frozen P1 normal load along the counterclockwise perimeter. The load's exact zero integral closes the primitive. For auxiliary states use zero boundary ψ. The resulting finite fields belong to H(div) and have precisely the required boundary normals.

A weighted P2 Dirichlet solve finds a low-residual ψ. At the reference, its stiffness is the ordinary P2 gradient form. A minimizer is convenient but unnecessary for validity: every feasible field with its exactly integrated residual certifies the stated bound. The finite witness construction uses 49 free P2 DOFs on 32 triangles. All coefficients, loads and integrals are rational before the original physical square-root normalizations. Residual squares after those normalizations are rational.

The lead independently verifies the supplied polynomial witnesses by Cartesian interpolation, independently assembled P1 state/sensitivity weak equations, exact divergence and edge-normal checks, and a separate exact degree-two triangle integration rule. All 27 fields for nine distinct raw traces reproduce the published residual squares exactly. This is stronger than merely rerunning the owner's barycentric assembly. Code and audit are under work/results/team_a_inverse/cycle3/audit_flux_witness.py and flux_witness_audit.json.

## Limits and next falsifiable step

This closes the continuum stability-transfer gap for the supplied fixed two-parameter model, box and frozen two-current boundary plan. It does not claim efficient noisy reconstruction, comparison with all possible single inputs, optimized setup cost, finite electrode implementation or a general nonradial theorem. The Cycle2 coarse forward predictions have appreciable continuum bias, so their RMSE table does not transfer.

For continuum observations, an estimator with certified residual slack η has parameter error at most (2||noise||+η)/κ_cont. Producing that slack requires certified forward enclosures or an exact continuum solver, and a charged search. A credible next step is to construct a uniformly certified forward approximation on the declared parameter box and retain an equally informed comparator. Enlarging the contrast box may make this reference proof UNKNOWN; the present argument does not hide that limitation.

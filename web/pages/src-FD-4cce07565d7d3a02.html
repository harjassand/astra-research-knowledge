EXACT RECOGNITION, DEGREE-PROMISED VALIDATION, AND UNKNOWN-DEFECT SELECTION
13 October 2026. Internal derivation; no novelty or external-review claim.
Only an exact static chosen-pair comparator of a bijection is assumed below.
All random guarantees require fresh conditional ideal randomness; fixture
PRNGs are reproducibility devices, not acquired physical entropy.

1. Problems that must be kept separate

Let N=2^n, X=F_2^n, and Q:X->F_2^n a bijection. The oracle is
 C_Q(x,y)=1[Q(x)<lex Q(y)]. A candidate F is known locally.

Whole equality validation asks whether Q=F, where F is a KNOWN bijection.
Exact prefix validation asks whether the first h bits of Q equal a known
balanced candidate prefix p, allowing arbitrary suffix order in each block.
Promise recognition asks whether Q belongs to the entire degree/hidden-flag
class, accepting all members, not just a single known candidate. Recovery
under that class promise does not recognize the promise.

The class has degree<=d first-h bits and an independent h-vector triangular
constant-translation flag. Full-output recovery additionally promises every
output bit degree<=d. Write r=n-h. Unless stated otherwise, n-1>d and h>0;
small n or degree >=n-1 do not satisfy the degree-based counterexample below.

2. A two-point perturbation has exact degree n-1

For distinct raw a,b, let E_(a,b)=1[x=a]+1[x=b] over F_2. Write
 1[x=a]=product_j (x_j+1+a_j).
The degree-n coefficients cancel. The coefficient of the degree-(n-1)
monomial missing coordinate j is (1+a_j)+(1+b_j)=a_j+b_j. At least one is
nonzero. Therefore deg E_(a,b)=n-1. This uses actual raw input points and
requires no affine-coordinate promise.

Swap the Q values at a,b. Every output coordinate on which Q(a),Q(b) differ
is changed from q_i to q_i+E_(a,b). If deg q_i<=d<n-1, the new coordinate
has degree exactly n-1. The swap preserves bijectivity but leaves the
relevant low-degree class whenever it changes a promised coordinate.

3. Adjacent-pair needles and SHARP whole-equality complexity

Enumerate candidate order x_j=F^(-1)(j), j=0,...,N-1. Let Q_j swap only
F(x_j),F(x_(j+1)). Then C_Qj differs from C_F only on the unordered pair
{x_j,x_(j+1)} (either orientation). All other pair comparisons agree.
Adaptivity does not help: for a fixed random tape, null-run and Q_j-run
transcripts coincide until that exact pair is queried.

More generally consider M distinct query needles (one exceptional unordered
pair per alternative), with the null source accepted with probability A and
every alternative accepted with probability <=beta<1/2. Let H_j be the event
that the null transcript queries needle j. Coupling gives
 Pr_null[ACCEPT and H_j]>=A-beta.
Summing j gives
 E_null[distinct needle queries * 1_ACCEPT]>=M(A-beta).
Thus E_null[Qcalls]>=M(A-beta)>=M(1-2beta). If every run has at most T calls,
 T A>=M(A-beta), so
 T>=ceil(M(1-2beta)/(1-beta)).                         (TWO-SIDED SHARP)
If the null is ALWAYS accepted, A=1 and
 E_null Qcalls>=(1-beta)M, T>=ceil((1-beta)M).          (PERFECT COMPLETE)
At zero error, every accepting null transcript queries all M needles.

Matching whole-equality tests use the candidate's M=N-1 adjacent pairs.
Any nonmatching source permutation has at least one adjacent candidate-order
descent. Perfect-completeness test: sample T=ceil((1-beta)M) distinct adjacent
pairs uniformly, reject an inversion, otherwise accept. Its false-accept
probability is <=1-T/M<=beta. Two-sided test: blindly reject with probability
beta; otherwise sample ceil(M(1-2beta)/(1-beta)) adjacent pairs uniformly.
Its null rejection is beta and worst false acceptance is
 (1-beta)(1-T/M)<=beta.
These match the WORST-CAP lower bounds exactly. To match the null expected
bounds exactly, randomize subset size between the floor and ceiling of its
required mean. The two-sided null expectation is then M(1-2beta), while the
perfect-completeness expectation is (1-beta)M. These expected statements
concern the null source, not the maximum expected cost over all inputs.

The deterministic exact chain check queries all N-1 adjacent candidate pairs.
If all agree, strict total-order transitivity forces the entire candidate
order. Since both Q and F biject onto the same ordered N labels, their ranks
are equal everywhere. Hence deterministic zero-error whole equality costs
EXACTLY N-1 chosen-pair comparisons. Each communicates two n-bit arguments.
Candidate inverse generation, storage and all local work are additional costs.

4. Which adjacent swaps REALLY violate the partial-prefix class?

There are B=2^h prefix blocks of L=2^r candidate ranks each. An adjacent swap
inside one L-item block leaves ALL first-h coordinate functions unchanged,
and therefore preserves their original degree and flag. Such a swap is NOT
a partial-prefix promise violation. A swap crosses blocks precisely at
 j=L-1,2L-1,...,(B-1)L-1.
Each changes a promised prefix bit by E_(a,b), so is off-class under n-1>d.
Consequently the adjacent off-class family has
 M_prefix=B-1=2^h-1,
whereas under the ALL-output degree promise all N-1 adjacent swaps are bad.
The sharp formulas of section 3 apply with the appropriate actual M.

For the RESTRICTED input family consisting only of F and one adjacent swap,
checking the B-1 block boundaries exactly decides partial-prefix membership;
intra-block swaps are accepted. This is not a recognizer against arbitrary
source permutations. For fixed r, B-1=Theta(N); for growing r it can be much
smaller. No false claim that all N-1 adjacent swaps violate a prefix promise
is made. The n-1>d regime is essential; degree alone does not settle smaller
examples (all two-bit permutations are affine, for example).

5. Arbitrary cross-prefix swaps restore an Omega(N) recognition lower bound

Take a uniform ordered pair (a,b) from different F-prefix blocks and swap
their candidate output values. Each alternative changes some promised bit
by E_(a,b), hence violates the degree promise. Each endpoint marginal is
uniform over X, since every a has exactly N-L partners outside its block.
Comparator answers can change only on queries touching a or b.

Fix a null random tape, and let U be all raw items touched by its queries.
Before a first changed answer the alternative transcript follows the same
null query path. Therefore transcripts can differ only if a or b lies in U,
which has probability at most 2|U|/N<=4T/N for T null-path comparisons.
Averaging over tapes preserves this bound. Two-sided error <=beta requires
null acceptance>=1-beta and mixture alternative acceptance<=beta. Coupling
therefore yields
 T>=(1-2beta)N/4,
 E_null Qcalls>=(1-2beta)N/4.                         (GENERAL PREFIX LOWER)
With perfect null completeness, replace 1-2beta by 1-beta. Constants here
are not claimed sharp. This proves exponential-in-n recognition even when
h is small and r grows, as long as h>0 and n-1>d.

For deterministic zero error, if two untouched items lie in different blocks,
swapping them produces an off-class source with identical transcript. Thus
untouched items must lie in one block: |U|>=N-L and Qcalls>=ceil((N-L)/2).
This endpoint argument is distinct from the sharper one-comparison needles.

For ZERO false acceptance there is a stronger N-1 lower, even for partial
prefix-class recognition. On a positive transcript, orient queried edges by
the known candidate order and take their transitive closure. If this poset
does not force all candidate prefix blocks in order, some adjacent blocks
B_j,B_(j+1) contain incomparable u,v. Extend u to a maximal element u' of
the within-B_j poset and v backward to a minimal element v' of B_(j+1).
They remain incomparable: a relation u'<=v' would imply u<=v. Concatenate
within-block topological orders, putting u' last in B_j and v' first in
B_(j+1). This is a positive source: the prefix FUNCTIONS and their flag are
unchanged, while every queried comparison is preserved. Now u',v' are
adjacent, their pair is unqueried, and swapping them produces an off-class
degree-(n-1) prefix with the same entire transcript. Hence no such transcript
can be accepted by an exact recognizer.

An accepting transcript must therefore force all prefix blocks in order.
Its comparison graph must be connected, so it has at least N-1 edges/calls.
For a randomized certifier with ZERO false acceptance and positive-source
acceptance at least1-beta, accepted null paths cost>=N-1 and
 E_null Qcalls>=(1-beta)(N-1), worst cap>=N-1.
The finite source universe permits the probability-one zero-false-acceptance
events to be intersected across all negative permutations. This is the
opposite one-sided orientation from the perfect-completeness tester above;
it must not be confused with allowing beta false acceptance. General
two-sided error still uses the quantitative endpoint mixture lower bound.

For exact KNOWN-prefix equality, a stronger deterministic lower N-1 follows
from connectivity: if the comparison graph is disconnected, concatenate its
components in an order that reverses some pair of items in different prefix
blocks. All queried comparisons survive, but the candidate prefix is wrong.
This connectivity construction need not preserve or violate the degree class,
so it is used only for known-prefix equality, not as a class-recognition proof.

6. Exact upper bounds and their cost boundaries

Whole equality: the exact N-1 chain test above is sharp.
Known balanced-prefix equality: enumerate each candidate block, find its
ACTUAL source minimum and maximum by comparisons, and compare the maximum
of block j with the minimum of block j+1. This is necessary and sufficient
for correct prefix blocks. A simple two-pass extrema implementation uses
 2B(L-1)+(B-1)=2N-B-1
calls for h>0; h=0 is vacuous and uses none. It accepts any correct within-
block suffix order. Generating N items from the acquired sampler, n-bit
traffic and local model evaluation are charged, not treated as free.

Entire class recognition can first run the capped promise-based learner,
then verify locally that its candidate has the required degree/flag, then
perform the exact source validation. A full candidate must also be certified
bijective before using its inverse chain; brute-force local checking costs
exponential local work if no efficient bijective certificate is available.
The prefix extrema validator only needs the checked candidate's balanced
flag certificate. If validation passes, actual Q has exactly the certified
candidate coordinates, so off-class sources are NEVER accepted. In-class
sources are accepted with the learner's recovery probability. For fixed d,r,
the previous learner costs polynomial(n), so source-query recognition is
Theta(N), including lower bounds above. This does not make local cost free.
For growing r the present recovery caps can exceed N; no Theta(N) complete
class-recognition upper is claimed there. Universal comparison sorting gives
O(N log N) source queries, after which ranks/ANFs/flag identities can be
checked locally with all exponential representation costs charged.
After sorting, flag existence is decided exactly by successive constant-
direction spaces C_i inside the known stabilizers S_i. Require a nonzero
response on C_i, choose an own-toggle, and update S_(i+1) to its response
kernel. The S_i depend only on the known coordinate polynomials, not on the
chosen earlier toggles, so this succeeds iff a triangular h-vector flag exists.

7. Approximate alternatives: choose the distance before claiming a shortcut

Pair disagreement (normalized Kendall distance) delta is the fraction of all
unordered pairs on which source/candidate comparators differ. Uniform pair
checks detect delta>=epsilon using O(epsilon^-1 log(1/beta)) comparisons.
One adjacent swap has delta=1/binom(N,2), so uniform-pair probing is much
worse than the targeted chain for that needle.

Order deletion distance is (N-LIS)/N for the actual source-rank sequence in
candidate order. The established EKKRV sortedness spot-checker uses
O(log N/epsilon) comparisons for constant confidence. A self-contained
binary-search-tree version: choose an item i uniformly and compare it with
all ancestors in the balanced binary search tree on candidate indices; reject
any comparison inconsistent with candidate index order. Any two passing
items are correctly ordered, by their least common ancestor. Thus passing
items form an increasing subsequence, and epsilon deletion-distance forces
at least epsilon N individually failing items. After
 ceil(log(1/beta)/[-log(1-epsilon)])
independent sampled items, rejection probability is >=1-beta. Each item uses
at most log2(N)=n comparisons. validation.ancestor_validate implements this
established test through actual raw comparisons and a locally known inverse.
It distinguishes exact match from epsilon-far; it does not certify exact
identity, identify bad items, or acquire source degree.

A persistent-bad-item assumption must have an operational distance meaning.
If an epsilon mass of items each has a rho mass of comparison witnesses,
fresh uniform pairs detect at probability >=epsilon*rho. Alternatively,
epsilon deletion-distance supports the ancestor tester. Rank-value Hamming
error is insufficient as a surrogate: a cyclic shift changes EVERY rank but
deleting one item restores order. Conversely disjoint adjacent swaps have
large deletion distance but tiny normalized Kendall distance. The metric and
fresh witness/randomness assumptions are part of the interface, not evidence
acquired merely because a test passed.

8. Cheap exact MODEL validation under a remaining degree promise

This validation section only needs d>=1; it does not require n-1>d.
Now retain the supplied promise that TRUE first-h output coordinates have
degree<=d, but DO NOT assume that a candidate r or true hidden flag is valid.
A candidate prefix p consists of degree<=d polynomials with exact locally
checked own-toggles w_i and earlier invariance. This gives exact balanced
uniform candidate-prefix fibers without knowing whether p is true.

One probe chooses i uniformly in {0,...,h-1}, a uniform i-bit candidate
prefix a, and two independent uniform points x0,x1 from candidate next-bit
halves 0 and 1 of that fiber. Reject if C_Q(x0,x1)=0. If the whole candidate
prefix is correct, every probe passes regardless of suffix order.

If p is wrong, take the FIRST GLOBALLY differing coordinate i. Earlier
coordinate functions agree everywhere, so the chosen earlier-prefix fibers
are also true fibers. Within such a fiber, true and candidate next bits are
both balanced. Write e_a for their conditional mismatch fraction. The two
opposite mismatch halves have equal sizes; the probability that x0 is true
bit1 and x1 true bit0 is e_a^2, which guarantees an order inversion. Averaging
over a gives rejection >=E e_a^2 >=(E e_a)^2. Since q_i+p_i is a nonzero
degree<=d polynomial, RM distance gives E e_a>=2^-d. Hence a full random-stage
probe rejects any wrong prefix with probability at least
 2^(-2d)/h.
Thus O(h 4^d log(1/eta)) chosen-pair comparisons validate the EXACT prefix
with error <=eta UNDER THE TRUE DEGREE PROMISE. No true flag/r assumption
is used in this validation proof. All sampling uses the certified candidate
model; one comparator per probe. Candidate preparation/sampling work and
random bits are separately charged. h=0 is the empty correct prefix.

This bound is sharp FOR THIS uniform-stage paired-half probe. Apply the
midpoint adjacent swap to the high d+1 bits and leave every lower bit intact.
All output coordinates have degree<=d, because the high-bit perturbation is
a two-point indicator on d+1 bits. Only the two adjacent high-bit blocks have
their mutual order reversed. A stage0 probe hits both with probability4^-d;
every later-stage probe fixes the candidate leading bit and cannot hit both.
The complete per-probe rejection probability is exactly4^-d/h.

Full model: additionally retain TRUE degree<=d for every output coordinate.
After the prefix test, draw fresh uniform raw x. Enumerate its 2^r-point
candidate-prefix fiber and compute its actual source-local rank using
2^r-1 comparisons. Compare that integer with the candidate's last-r-bit
value. Conditional on a correct prefix, the local rank IS the actual suffix
rank, regardless of flags or candidate suffix bijectivity. If a candidate
tail differs, some degree<=d true/candidate bit difference is nonzero, so a
uniform x detects it with probability >=2^-d. O(2^d log(1/eta)) raw samples
suffice. A wrong prefix passes with probability <=eta_p; a correct prefix
with wrong tail passes with probability <=eta_t. Total wrong acceptance is
<=eta_p+eta_t. A correct full candidate ALWAYS passes. No global candidate
bijectivity check is required: equality to the true bijection is the target.

The explicit validator cap is
 ceil(log(1/eta_p)/[-log(1-2^(-2d)/h)])
 +(2^r-1)ceil(log(1/eta_t)/[-log(1-2^-d)]),
with the empty-prefix/tail terms omitted. For fixed d,r it is polynomial in
n and log(1/eta). validation.degree_promised_validate implements these ports.
This is validation under degree, NOT degree/flag promise recognition.

An alternative full-candidate gap: if BOTH Q and F are certified bijections
of degree<=d, Q!=F forces order deletion-distance >=2^(-d-1). The first
globally differing coordinate has mismatch>=2^-d; in each common earlier-
prefix fiber, the equally sized opposite mismatch sets form complete crossing
inversions, forcing deletion of at least half of the mismatches. Consequently
the established ancestor tester validates whole equality in
O(2^d n log(1/eta)) comparisons under this degree promise. This route needs
candidate bijectivity and inverse ports; their costs must not be hidden.
The prefix/tail validator above avoids the global candidate-bijectivity gate.
Both the tail mismatch bound and deletion gap are sharp: identity versus an
LSB flip controlled by a product of d higher bits moves exactly2^-d of all
items and swaps N/2^(d+1) disjoint adjacent pairs. Its exact deletion-distance
is2^(-d-1). All output coordinates remain degree<=d.

9. Sound unknown-r selection WITHOUT recognizing the degree promise

Fix a TRUE global degree bound d and exact source bijectivity. For r=0,1,...
up to a resource cap, run any capped candidate generator, including the prior
compiler under its hypothesized r. Exact local degree and candidate-toggle
checks are mandatory, but generator assumptions may be false. A returned
candidate is then tested with FRESH randomness at error eta_r, where
sum_r eta_r<=eta (for example eta_r=eta/2^(r+1)). Accept the first passing
candidate; otherwise continue or return UNKNOWN at the cap.

For every fixed adaptive candidate conditioned on its earlier transcript,
section 8 bounds wrong acceptance by eta_r under the remaining TRUE degree
promise. Union bound gives total wrong return<=eta, even though earlier
hypothesized flag/defect values may have been invalid. If the source admits
some r* within the cap, the promised-class compiler produces the exact model
at r* with its stated probability, and the true model passes validation with
certainty. Overall correct-return probability is at least
1-acquisition_error_at_r*-eta. The all-history query cap is the sum of each
candidate-generator cap and validation cap through the search resource cap.
A high-probability cost through r* requires conditioning on successful recovery
there; it is not an unconditional stopping bound. Repeated leading acquisition
work can multiply costs, so no unknown-r leading-optimality claim is made.

This genuinely removes the need to SUPPLY r for sound model selection, but
retains the supplied degree and exact-comparator promises. Removing those
promises reintroduces sections 3-5. In particular, off-degree adjacent needles
can be accepted by section 8 with high probability; the saved fixture makes
this failure explicit. Unknown-d adaptation cannot silently reuse a small-d
rejection bound against arbitrary higher-degree sources.

10. Finite evidence, prior and limitations

recognition_fixture.py checks adjacent needle transcripts and two-point ANF
degrees through n8; exact budget formulas; all 40320 three-bit permutations
against the prefix inversion and full degree/deletion-gap bounds; and the
ancestor good-set proof on that whole finite domain. New validator execution
rejects explicit underestimated-r candidates for a quadratic source, accepts
its exact r2 candidate, rejects a nonbijective wrong tail without a global
bijection test, and separates prefix equality from whole equality when only
the within-block suffix is permuted. These are validation fixtures, not new
compiler acquisition/performance runs. It retains an off-degree adjacent-
swap false acceptance showing why the degree promise remains an access gate.
sharp_degree_gap.py additionally checks25 degree/deletion constructions and
50 sharp prefix-probe cases through n9. certificate_lower_fixture.py builds
972 positive/off-class transcript completions below N-1 comparisons for
n3/n4 prefix promises, exercising the stronger exact-certification argument.

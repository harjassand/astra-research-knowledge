## Reconstructed load-bearing lemma

Write
\[
 X(a)(r,s)=(r+as,s),\qquad Y(a)(r,s)=(r,s+ar).
\]
The chronological stages
\[
Y(-\lambda),\quad X(\lambda^{-1}-1),\quad Y(1),\quad X(\lambda-1)
\]
compose to `diag(λ, λ⁻¹)`. Starting from `(r,s)`, their endpoints are
\[
\begin{aligned}
 (r,s)&\mapsto(r,s-\lambda r)\\
 &\mapsto(\lambda r+(\lambda^{-1}-1)s,s-\lambda r)\\
 &\mapsto(\lambda r+(\lambda^{-1}-1)s,s/\lambda)\\
 &\mapsto(\lambda r,s/\lambda).
\end{aligned}
\]
If the two source offsets and two final offsets have magnitude at most `h`, then
\[
 |s-\lambda r|\le |s|+|\lambda r|\le2h,
\]
and
\[
 |\lambda r+(\lambda^{-1}-1)s|
 \le |\lambda r|+\bigl||s|/\lambda-|s|\bigr|
 \le 2h,
\]
because `||s|/λ−|s|| ≤ max{|s|/λ,|s|} ≤ h`. The remaining endpoints are bounded by the assumed endpoint offsets. During each partial shear the moving point traces the segment between consecutive endpoints, so convexity of `[-2h,2h]^2` gives the same bound at every intermediate time. The cancellation is the useful feature: bounding each shear matrix separately would introduce factors proportional to `λ` and `1/λ`.

The fluid embedding uses these estimates to verify, rather than assume, that each localized shear stays on its cutoff plateau. Private heights isolate the finite branches while the four shears act; a later translation moves between branch centers; a final height stage returns the point to the coding plane. Each time pulse has one active velocity component transverse to its spatial variation, so the self-advection term vanishes. The constructed field therefore solves forced Navier–Stokes exactly with `p=0` and `f=V_t−νΔV`. The recorder and radix coding supply finite, separated source and target rectangles; the shear lemma controls their entire filled rectangles and all within-period excursions.

## Transfer tested: finite-horizon precision, then failure at unbounded horizon

The useful stronger capability to test is: **does the exact simulator also preserve a computation under one fixed positive error in the initial encoded particle, for an unbounded run?** The answer is no for this coding. The exact shear theorem proves positive neighborhoods for each finite branch; it does not give one neighborhood that preserves an infinite computation.

There is a precise finite-horizon transfer. Let `m` be the complete recorder-alphabet size, `B=2m+1`, and `κ=1/(32N)` as in the source. Each digit is odd in `{1,3,…,B−2}`. Thus every valid tail code satisfies
\[
 1/(B-1)\le C(\text{tail})\le1-1/(B-1).
\]
A length-`r` prefix cylinder has width `B⁻ʳ`; the code point sits at least `B⁻ʳ/(B−1)` from either endpoint. After the scale `κ`, the margin is `κB⁻ʳ/(B−1)`. The state-square margin is larger. Equivalently, each normalized instruction map has infinity-norm at most `B`, so an initial coordinate error can grow by a factor `B` per local transition. A planar perturbation at the coding height smaller than
\[
 \varepsilon_T=\frac{\kappa}{(B-1)B^{T+1}}
\]
preserves the first `T+1` complete symbols on both tape tails and the control. The recorder’s first `T` local transitions are then unchanged: in `T` one-head steps it cannot inspect a cell farther than `T` from its initial position, and the source’s branch rectangles implement the exact transition on every point in each such rectangle. This is an initial-state guarantee for a finite horizon, with the exact compiled force; the loader is locally a translation, so the same radius applies to nearby particle labels. It does not cover perturbations to the force or claim robustness after `T` transitions.

The unbounded-horizon extension fails by an exact counterexample. Let `M` move right whenever it reads blank and halt when it reads a marker `#`. On the empty input, `M` never halts. Let `z_∞` be the source’s loaded recorder code for that input. The right stack coordinate is `y=y₀+κC(s₀s₁…)`. For each `n`, the valid finite input consisting of `n` blanks followed by `#` changes only the digit at stack position `n`, so its loaded coordinate differs by
\[
 |y_n-y_\infty|=\kappa|d_{(\#,E,0)}-d_{(\square,E,0)}|B^{-(n+1)}\longrightarrow0.
\]
The force’s periodic mechanism is `V_M`, independent of the input; the input affects only the loader. Keeping the empty-input force fixed and shifting the initial particle’s `y` coordinate by `y_n-y_∞` therefore produces the marker-input recorder state after the same loader. The loader translates nearby labels by the same amount on its plateau, and the perturbed trajectory reaches the halting detector. The unperturbed trajectory never does. Hence every neighborhood of this single nonhalting initial label contains a trajectory with the opposite reachability answer. No positive local tolerance can certify the negative answer under arbitrary initial-label error.

This distinction matters for physical interpretation. The exact nonhalting orbit is kept at least `7/32` to the left of the detector during every nonterminal period, by the paper’s `x≤9/32` estimate. That large output gap does not stabilize the computation: arbitrarily small input-coordinate changes can encode a marker farther down the tape and change an infinite-time reachability answer. A finite yes-run is locally stable because it reaches an open detector in finite time; the no-run above is not. Reachability remains semidecidable, not robustly decidable.

## Closest primary prior art

Moore’s [1991 generalized-shift paper](https://sites.santafe.edu/~moore/nonlinearity-gs.pdf) constructs a generalized shift conjugate to any Turing machine, explains that reversible machines give one-to-one shifts, and embeds these systems in smooth low-dimensional dynamics. The source paper’s radix stacks follow that positional-coding line; its reversible recorder supplies the finite local table needed by its fluid construction.

Cardona, Miranda, Peralta-Salas, and Presas construct a Turing-complete stationary Euler flow on a chosen Riemannian `S³` via an area-preserving disk map and the contact/Reeb correspondence ([primary preprint](https://arxiv.org/abs/2012.12828)). Cardona, Miranda, and Peralta-Salas construct universal stationary Beltrami flows on noncompact `R³`; their paper says this construction has infinite energy and uses noncompactness, while their separate flat-`T³` theorem robustly simulates tape-bounded machines ([primary preprint](https://arxiv.org/abs/2111.03559), especially Theorem 27 and its robustness discussion). Dyhr et al. construct stationary unforced Navier–Stokes examples on certain Riemannian three-manifolds through cosymplectic geometry ([primary preprint](https://arxiv.org/abs/2507.07696)). These establish that fluid computation itself is prior art; they do not assert this manuscript’s fixed-flat-torus, zero-initial-data, input-dependent-forcing construction.

Bournez, Graça, and Hainry prove, for their stated perturbation/reachability model, that robust recognition is equivalent to decidability; they also note that bounded-domain robustness may depend on the particular encoded input ([primary paper](https://sapientia.ualg.pt/server/api/core/bitstreams/a1a08464-1e63-404d-9ad6-997a3fa27620/content), pp. 715–716, 722–723). That result is consistent with the explicit shrinking-cylinder obstruction above. It should not be silently substituted for the direct counterexample, because its perturbation model is defined on reachability relations and need not match every physical error model.

The narrow reusable conclusion is the exact endpoint-conditioned excursion estimate and its finite-horizon radix precision budget. The robust unbounded-time capability is refuted for arbitrary initial-coordinate perturbations. Any different noise model—such as only bounded perturbations to the force, or errors constrained to preserve the encoded input—needs its own interface and proof.

## T2. Retain the shared spectral budget instead of bounding it twice

PSD B gives M0=lambda0+||B||. Test B on the normalized trace-free projector p_i=P0(u_i u_iᵀ)/sqrt(1−1/n). Its i-th contribution is beta_i(1−1/n), with all other contributions nonnegative. Therefore

    beta_max<=n||B||/(n−1)=n(M0−lambda0)/(n−1),
    lambda0+beta_max<=n M0/(n−1)−lambda0/(n−1).   (T2)

This is stronger than two separately available inequalities; it charges the same eigenvalue budget only once. Substituting into(T1) yields

    rho<=[n a_zeta/(n−1)]M0+d_zeta lambda0,
    d_zeta=(n/2)zeta²−a_zeta/(n−1).              (T3)

For every n>=2, discarding the negative subtraction in(T2) and using lambda0<=M0 on the remaining trace leakage gives the unconditional sufficient coefficient

    k_star=[n/(n−1)](2zeta+zeta²)+(n/2)zeta²,
    rho<=k_star M0.                             (T4)

It improves the original coefficient by precisely a_zeta. If k_star<1, triangle inequality and M0<=Mhat+epsilon4+rho give

    M0<=(Mhat+epsilon4)/(1−k_star),
    e_star=(epsilon4+k_star Mhat)/(1−k_star).    (T5)

The same confidence event supports this total bound. It uses only acquired quantities; the same all-adaptive-frame event and original graph/axis proof then apply.

## T3. Low metric-error regime and dimension3

When d_zeta<=0, the lower lambda0>=2 gives the still sharper observable relation

    rho<=k0 M0−t,
    k0=n a_zeta/(n−1), t=−2d_zeta>=0.            (T6)

The sign condition holds for zeta=0, or positive zeta<=4/[n(n−1)−2] if n>=3; for n=2 it holds for every zeta. For n=3 exactly d_zeta=zeta²−zeta<0 whenever0<zeta<1, so

    k0=(3/2)(2zeta+zeta²), t=2zeta(1−zeta).      (T7)

If k0<1, observable rearrangement yields

## Exact two-parameter obstacle

For a family of kinetic data indexed by a Knudsen parameter kappa, let T_kappa be the horizon in release coordinates, B_kappa its summable Gaussian input bounds, and L_kappa the layer count. A simultaneous microscopic/hydrodynamic limit must control all of the following; existence for each fixed kappa does not supply them:

1. Base r_kappa=C(B_kappa,beta,T_kappa) T_kappa/sqrt(L_kappa)<1 uniformly.
2. Layer occupancy counting. The source calls the number of vectors (n_i) polynomial only because L is fixed. Exactly,

   sum_{n>=0} binom(n+L-1,L-1) r^n=(1-r)^{-L}.

   Hence even at r=1/2 the numerical majorant sums to 2^L before the complexity polynomial. For a fixed nonnegative integer d and eta=log(3/2),

   sum_n binom(n+L-1,L-1) (1+n)^d (1/2)^n
   <= (3/2) d! eta^{-d} 4^L,

   using (1+n)^d <= d! eta^{-d} exp(eta(1+n)). This is a derived bound, not a lower bound on the actual correlations. C_K,d_K can themselves grow with L.
3. The explicit cutoff hierarchy is A_L=ell=|log epsilon|, Lambda_i=A_i^{30}, A_{i-1}=A_i^{900}. Therefore A_i=ell^{900^{L-i}}, Lambda_i=ell^{30*900^{L-i}}. For any positive fixed gamma,p,

   epsilon^gamma Lambda_i^p
   = exp[-gamma ell + 30p*900^{L-i} log ell].

   To absorb these cutoff-polynomial losses by epsilon powers one needs 900^{L-i} log ell=o(ell) (sufficient with fixed coefficients), hence L-i substantially below [log ell - log log ell]/log 900. This is a limitation of directly uniformizing this proof, not a physical upper bound on the true microscopic dynamics. If one unrealistically held all kinetic-envelope constants uniform and L=O(T^2), it already suggests T=o(sqrt(log log(1/epsilon))) for this particular hierarchy; actual second-parameter dependence is untracked.
4. Coarse complexity removal needs |log epsilon|^{C_*(L) rho} epsilon^{c_*(L) rho} small; c_*(L)>0,C_*(L) are only given at fixed L.
5. Higher cumulants need C_h(T_kappa,L_kappa,data_kappa) epsilon^{h-2}->0 for every fixed h>=3.
6. Covariance/tree convergence has only the qualitative finite-graph extra-contact result. To establish a prescribed coupling epsilon=epsilon(kappa), a recollision modulus uniform in retained graph sizes/horizons/data and a cutoff/mean error modulus are still needed.
7. Diffusive hydrodynamics also requires process tightness and tests involving unbounded polynomial velocities. The release proves only FDD for fixed compact smooth phase-space tests. Its weighted bounds are for retained diagrams and limiting trees, and it explicitly does not claim velocity-weighted microscopic expansion-remainder estimates.
8. Periodic equilibrium is outside the summable whole-space probability-density interface. Simply substituting a uniform torus Maxwellian is not a valid application.

For orientation on normalization: a physical whole-space equation (partial_t+v.grad_x) f_kappa = kappa^{-1} Q(f_kappa,f_kappa), with physical particle activity a^{-2} kappa^{-1}, can be put into the release's unit-collision convention by y=sqrt(kappa) x, s=sqrt(kappa) t, epsilon=a sqrt(kappa), and g_kappa(s,y,v)=kappa^{-3/2} f_kappa(s/sqrt(kappa),y/sqrt(kappa),v). Then activity=epsilon^{-2} exactly and g solves unit-coefficient Boltzmann. A physical diffusive horizon t=T/kappa becomes a release horizon s=T/sqrt(kappa), while the density/gradient norms grow at least as the concentration scaling dictates. Counting collisions in standard kinetic units still gives O(kappa^{-2}) collisions. This exhibits both time and data deterioration rather than silently treating only the time parameter.

A trivial nonconstructive diagonal schedule can be selected after convergence for each fixed second parameter, but it gives neither a prescribed quantitative coupling nor a new uniform estimate. It is not a historical-calibre advance.

It concludes uniform-in-deterministic-time fixed-order factorial L1 chaos. It permits attractive wells and keeps many-body clusters in the exact microscopic flow. It has NO fluctuation theorem.

It explicitly forbids concluding independence after normalizing a rare conditional sector. `exp:defects` gives P^{C_L p} epsilon^{c_L p}, after compact cutoff losses <=exp(-A p). `exp:finite` separately treats finitely many top roots, and explicitly asserts no algebraic rate in the small-speed/output-increment exclusion parameter eta.

`sections/06-closure.tex`, `close:summability`: for any desired a>0, choose L with C T/sqrt L < exp(-4a-20), then rarity cutoffs. Completed absolute p-label terms are <=exp(-ap) when p>=p_L and h_0<=eta_L p. It again uses binom(n+L-1,L-1)=exp(o(p)) at FIXED L.

Merely combining the two released conclusions does not yield radial fluctuations, and the potential is fixed independently of epsilon, so it also does not prove a simultaneous weak-potential/grazing Newton-to-Landau limit.

## At most one serious target

Target: a quantified NONEQUILIBRIUM joint hydrodynamic fluctuation limit around a prescribed smooth regular kinetic/hydrodynamic family, initially at FDD level. The new ingredient is the regular-lifespan nonequilibrium connected-cumulant expansion. The smaller load-bearing missing theorem is a horizon/data/graph-size-uniform recollision and centering modulus that pays the explicit layer hierarchy above. This audit has not supplied that theorem. Even a polynomial finite-graph sublevel estimate alone would not control the recursively growing layers, complexity constants, or the hydrodynamic covariance limit.

Strongest next attack: replace the qualitative polynomial-nonidentity argument in `lem:sharp-no-extra` with explicit small-sublevel bounds on bounded velocity/time/direction charts; track their dependence on graph size, and couple that to the exact negative-binomial occupancy count. A claimed quantitative horizon must state epsilon(kappa), B_kappa, L_kappa, every complexity cutoff, and the epsilon threshold. Do not claim global regularity or skip the nonequilibrium kinetic-to-fluid covariance analysis.

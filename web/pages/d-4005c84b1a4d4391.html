# c03_l04 deeper attack R2 — a two-mode adaptive effect is not one Gaussian postselection

Date: 2026-10-07. This extends R1 without editing frozen `INITIAL.txt` (its SHA-256 remains `0784ed06e10d9827e31a4a81e892c3418b50d3b81464ebcadeaf3e87f30d7f8e`). It gives a smaller and more operational counterexample for the sequential-adaptive versus one-terminal-filter boundary.

## New exact claim

Use the two-mode `P,Q` and rotation from R1. Perform this adaptive instrument:

1. Measure whether the first mode is empty, with projectors `P` and `I-P`.
2. On branch `I-P`, accept immediately. On branch `P`, measure whether the rotated first mode is empty, with projector `Q`, and accept only outcome `Q`.
3. Erase the accepted branch label.

The two accepted Kraus operators are `K0=QP` and `K1=I-P`. Therefore the acceptance effect (the adjoint acceptance map applied to identity) is

`E = K0* K0 + K1* K1 = P Q P + I - P = diag(1,1,9/25,1)`

in basis `(|00>,|10>,|01>,|11>)`. Exact multiplication is included in `check_gadgets.py`. The sequential protocol consists entirely of single-mode Gaussian occupation measurements and an outcome-dependent continuation. Yet its coarse-grained accept effect is not a projector: it has eigenvalues `1` and `9/25`. Consequently it cannot be reproduced, as an acceptance-probability effect on the same two-mode input, by a single terminal orthogonal hard projection after any unitary. Allowing an overall scalar does not help, since the two nonzero eigenvalues are unequal. This extends the R1 branch-map witness: it is a direct test of the erased-record adaptive **event**, rather than only a Kraus map for one fixed accepted transcript.

It also cannot be one positive fermionic Gaussian Kraus postselection on these same modes. If a positive effect `E` were of the form `G*G` for one Gaussian operator/map branch, its normalized version would be a Gaussian density operator. But `rho_E=E/tr(E)` is diagonal with trace denominator `84/25`; its exact moments are

`<n1>=25/42`, `<n2>=17/42`, `<n1 n2>=25/84`,

and all cross normal and anomalous two-point contractions vanish. Wick's rule for a Gaussian state would then require `<n1 n2>=<n1><n2> = 425/1764`; the actual value is `525/1764`, a nonzero gap `25/441`. This proves `rho_E`, and hence `E`, is not Gaussian. The point is the coarse-grained sum over outcome-dependent branches: each accepted branch is a Gaussian map, but the accepted event is not one Gaussian Kraus branch.

The accepted effect is a valid positive contraction (`0<=E<=I`). The reject Kraus operator is `(I-Q)P`, so the reject effect is `P(I-Q)P`; hence `E+P(I-Q)P=I`. This is a complete exact instrument, not just a formal sum. No ancilla or hidden coherent control is used.

## Relation to R1 and peer overlap

R1's first witness still separates a two-projector product as a map from one same-register projective map. R2 sharpens the adaptive part with a two-mode construction. The four-mode data-state/Wick gadget in INITIAL remains a useful state-level consequence but is not needed for this event-effect result. The R2 proof is independent of the peer reports' finite examples.

Prior-art attribution remains: c03_l01 and c03_s01 already state that coarse-grained adaptive/FLO measurement can leave the fixed Gaussian transcript class, and c03_l01 cites the Cao–Tang–Eisert monitored-FLO architecture. Therefore R2's broad qualitative boundary is overlapping prior work. Its incremental contribution is this exact rational two-mode adaptive accept effect, its non-projective spectrum, and its direct Wick certificate that no one Gaussian Kraus effect realizes it. This is a finite, elementary counterexample and is not claimed novel or complexity-theoretic.

## Scope and costs

Two modes, two projective occupation measurements on at most one branch, the rational rotation `(3/5,4/5)`, and exact arithmetic suffice. The accept event has state-dependent probability `tr(E rho)`; for the maximally mixed input it is `21/25`? Correction: `tr(E)/4=(84/25)/4=21/25`, so it is not rare. The matrix/spectrum/Wick calculations were checked exactly with `Fraction`. There is no sampling, solver, oracle, precision, or resource cost.

This is same-register equivalence. Adding arbitrary ancillas and tracing them can realize effects outside projectors on the retained system; the test does not exclude such dilations. Nor does it show a runtime gap: the adaptive sequence is still FLO/Gaussian-branch simulation with classical feedforward, in Bravyi's established interface. It does not transfer to bosonic Gaussian postselection or prove hardness for weighted parity / hard-BCS norms. The decisive semantic question remains whether “arbitrary Gaussian postselection” refers to one Kraus branch, a fixed resolved transcript, or a sum over adaptively accepted transcripts.

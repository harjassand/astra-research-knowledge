CYCLE 4 — TYPE-FIRST INTEGER CODE FOR STATIONARY RENEWAL BLOCKS
Date: 2026-10-08
Status: INTERNAL THEOREM + POLYNOMIAL-TIME EXACT PREFIX ALGORITHM; EXTERNAL REVIEW AND NOVELTY UNKNOWN

1. RESULT

For every block length L, there is an explicit, full-support probability
assignment Q_L on binary strings with the following properties.

* For every stationary binary renewal process with iid positive-integer gaps
  of arbitrary finite mean, the pointwise log redundancy is at most
  log((A_L+1)L), where A_L=sum_{s=0}^{L-1}p(s) and p(s) is the integer
  partition number. Thus the KL redundancy is at most
  pi sqrt(2(L-1)/3)+2 log L+log 2 = O(sqrt L).
* Q_L is exactly computable and the marginals Q_L(prefix) can be computed in
  polynomial time by an explicit bivariate coefficient DP. Consequently the
  stationary-renewal terminal predictor obtained through Han–Jiang–Wu's
  Proposition 1 is polynomial-time and has worst-case expected next-symbol
  KL risk at most

      [pi sqrt(2n/3) + 2 log(n+1) + log 2 + log(n+2)] / n,

  for history length n>=1. In particular this is O(n^{-1/2}), matching the
  minimax order in their Theorem 4.
* The data interface is one ordinary stationary observed binary path. The
  predictor uses the n observed symbols and predicts the next; it has no
  hidden labels, event-query oracle, source mean, support cutoff, or reset.
  The stationary first-wait law and terminal right-censoring enter the proof
  explicitly.

This is a concrete internally proved candidate that appears to address the
computational gate stated in HJW v1. It is not externally checked, and no
novelty or priority claim is made. The type-class route itself is classical:
Csiszár's 1998 method-of-types survey says renewal type classes yield
O(sqrt(n)) universal coding, and Csiszár–Shields 1996 is the underlying
minimax source. A bounded source audit cannot establish whether this exact
type-first assignment or its prefix DP was previously known.

2. SOURCE CLASS AND INTERFACE

Let T_1,T_2,... be iid with pmf mu on {1,2,...} and finite mean
m_mu=sum_j j mu(j). The binary renewal process has ones at renewal epochs and
is observed in its stationary version. If W is the forward wait from time 1
to the first one, then

    P_mu(W=w) = nu_mu(w) = (1/m_mu) sum_{j>=w} mu(j),  w>=1.

This is the equilibrium residual/age initialization. Conditional on the first
one, all subsequent complete gaps are iid mu. The learning input is the raw
history x_1^n from this one stationary path; the target is X_{n+1}. The
training procedure observes no hidden residual age, no gaps beyond what is
visible in x_1^n, and no model-dependent query. There is no reset or repeated
sample assumption. The code/predictor is horizon-indexed by n, which is
available from the observed history length. The source mean may be unknown
and arbitrarily large but finite; mu can have unbounded support.

3. CODE DEFINITION AND NORMALIZATION

Set L=n+1 and define

    A_L = sum_{S=0}^{L-1} p(S),  with p(0)=1.

The code classes are: one special class containing only 0^L, plus one class
for every integer partition C of S for S=0,...,L-1. Write c_j for the number
of completed gaps of length j in C, R=sum_j c_j, and

    S=sum_j j c_j,      M(C)=R!/prod_j c_j!.

The class for C consists of all words formed by choosing a first one at
w in {1,...,L-S}, then choosing one of the M(C) distinct orderings of the
completed gaps, and putting zeros after the last resulting one through time
L. Assign each of the A_L+1 classes mass 1/(A_L+1), uniformly within each
class. Therefore

    Q_L(0^L) = 1/(A_L+1),
    Q_L(x) = 1/[(A_L+1)(L-S)M(C)]   if x contains at least one one.

Every nonzero word maps uniquely to its first-one position and ordered gap
sequence, and hence to one class. A class has exactly (L-S)M(C) words. This
proves normalization and full support. The finite limit S<=L-1 is imposed by
the block horizon, not by a source support truncation. Interarrivals after the
last observed one are not coded as completed gaps.

4. EXACT STATIONARY LIKELIHOOD AND REDUNDANCY PROOF

Let x contain at least one one. Let w be its first-one position, g_1,...,g_R
its completed gaps, C their multiset, and c=L-(w+sum_i g_i) the trailing
right-censored length. The exact stationary likelihood is

    P_mu(x) = nu_mu(w) [prod_{i=1}^R mu(g_i)] P_mu(T_1>c).

The strict tail is correct: after the last one, no renewal occurs in the next
c positions exactly when the next positive gap exceeds c. For 0^L,

    P_mu(0^L)=P_mu(W>L)
      =(1/m_mu) sum_{j>L}(j-L)mu(j).

For the completed gap sample,

    M(C) prod_j mu(j)^{c_j}

is exactly the iid probability that R gaps have multiset C, so it is at most
one. The equilibrium residual probability nu_mu(w) and censoring probability
P(T_1>c) are each at most one. Consequently,

    P_mu(x)/Q_L(x)
      =(A_L+1)(L-S)M(C)nu_mu(w)prod_j mu(j)^{c_j}P(T_1>c)
      <= (A_L+1)L.

For the all-zero word P_mu(0^L)<=1, giving ratio at most A_L+1. Taking
logarithms and expectation proves, uniformly over all such stationary mu,

    D(P_{mu,1:L} || Q_L) <= log((A_L+1)L).

No approximation of the equilibrium initial wait or censoring distribution is
used.

For s>=1, the integer partition generating function and any t>0 give

    p(s) <= exp(ts) prod_{j>=1}(1-exp(-tj))^{-1}.

Expanding the log and using 1/(exp(tr)-1)<=1/(tr),

    log prod_j (1-e^{-tj})^{-1}
      = sum_{r>=1} 1/[r(e^{tr}-1)] <= pi^2/(6t).

Optimizing at t=pi/sqrt(6s) yields p(s)<=exp(pi sqrt(2s/3)). Thus

    A_L <= L exp(pi sqrt(2(L-1)/3)),
    log((A_L+1)L) <= pi sqrt(2(L-1)/3)+2 log L+log 2.

All logs in risk formulas are natural logs. The same inequalities in bits are
obtained by dividing by log 2.

5. EXACT PREFIX MARGINALS AND POLYNOMIAL ALGORITHM

The probability assignment is not yet a usable terminal predictor until
Q_L(y) can be computed for each prefix y. The following formula sums over
completion types without enumerating the exponentially many partitions.

Let y have length t. If y=0^t, then the all-zero class contributes 1/(A_L+1).
For a type with completed-gap total S, its first one is uniform on
{1,...,L-S}, and the prefix is zero iff this start exceeds t. Therefore

    Q_L(0^t) = 1/(A_L+1) *
       [1 + sum_{S=0}^{L-1} p(S) (L-S-t)_+/(L-S)].                 (1)

Now suppose y has ones at positions w=i_1<...<i_{R+1}=u. Let k_j count
the observed complete gaps of length j among i_{a+1}-i_a, set

    r=sum_j k_j=R,  S_0=u-w,  c=t-u,  B=L-u=L-w-S_0,
    kappa=prod_j k_j!.

In a completion, let d_j>=0 count additional completed gaps of length j,
q=sum_j d_j, and s'=sum_j j d_j. Feasibility of the fixed first-one location
requires s'<=B. If q>0, the first new gap must be >c to preserve the observed
trailing zeros. Define

    b_{s',q} = sum_{d: sum d_j=q, sum j d_j=s'}
                 (sum_{j>c} d_j) prod_j binom(k_j+d_j,k_j).

Then

    Q_L(y) = kappa/(A_L+1) *
       [ 1/(r!(L-S_0))
         + sum_{q=1}^{B} (q-1)!/(r+q)!
             sum_{s'=0}^{B} b_{s',q}/(L-S_0-s') ].             (2)

The q=0 term is the completion with no further renewal before block end. For
q>=1, among all permutations of full type k+d, there are
(r+q)!/prod_j(k_j+d_j)! total orderings. The number whose first new gap
exceeds c is
    (q-1)! (sum_{j>c}d_j)/prod_j d_j!.
The ratio of these counts equals
    kappa (q-1)!/(r+q)! (sum_{j>c}d_j) prod_j binom(k_j+d_j,k_j),
which gives (2) after multiplying by the type's start-position mass
1/(L-S_0-s'). In particular, that denominator depends on the added gaps and
cannot be dropped.

To compute all b_{s',q}, use

    F(x,z)=prod_{j=1}^{B}(1-zx^j)^(-(k_j+1)),
    G_c(x,z)=F(x,z) sum_{j=c+1}^{B}(k_j+1)zx^j/(1-zx^j).

Then b_{s',q}=[x^{s'}z^q]G_c. Truncate both degrees at B. For each j,
the factor coefficient at multiplicity d is binom(k_j+d,k_j). A direct DP
updates an F array by

    Fnew[s+jd,q+d] += Fold[s,q] binom(k_j+d,k_j).

Update the G array by multiplying Gold by the same unmarked factor and, when
j>c, adding Fold times a marked factor whose d-th coefficient is
d binom(k_j+d,k_j). This recurrence exactly tracks the factor
sum_{j>c} d_j.

There are O(B^2) coefficient cells and O(B^3) updates by an in-place
unbounded-part recurrence: for each j, update each (s,q) cell once from
(s-j,q-1), rather than explicitly convolving over all multiplicities.
Thus one arbitrary prefix marginal costs O(L^3) integer additions and
O(L^2) live cells. Partition counts p(0),...,p(L-1) are precomputed by the
standard coin-change recurrence in O(L^2) integer updates and O(L) cells.
Each coefficient has O(L) bits: products of binomial terms are at most
2^(r+q), and there are at most p(B) contributing vectors. Factorials are at
most L!, with O(L log L) bits. A common denominator over the O(L^2) terms
has polynomial bit length (the crude product bound is O(L^3 log L) bits).

There is also an explicit fixed-horizon prefix code, so code/decode does not
depend on recomputing prefix marginals. Encode a class index in fixed width
ceil(log2(A_L+1)) bits: index 0 is all-zero, and indices 1,...,A_L enumerate
integer partitions C by increasing S and a fixed lexicographic order. For a
nonzero class, append a fixed-width index in
{0,...,(L-S)M(C)-1}; split it as (w-1)M(C)+permutation_rank, with w the first
one position and permutation_rank the lexicographic rank of the distinct
gap order. A partition DP P(s,m)=P(s,m-1)+P(s-m,m) gives class unranking in
O(L^2) integer operations; multinomial completion counts rank/unrank the
multiset permutation in O(L^2) operations. The decoder reads the fixed-width
class header, then knows the exact payload width from C. Thus the code is
prefix-free for fixed L. Its length is less than -log2 Q_L(x)+2 bits. The
worst-case length is O(L log L), since M(C)<=R!<=L! and L-S<=L. No source
parameter is sent. The runnable encoder/decoder and round-trip check are in
`block_code.py` and `check_block_code.py`.

For the HJW prediction rule, computing each prefix/child-prefix marginal
independently would cost O(n^4) coefficient updates. The suffixes used by HJW
all end at x_n, so they admit a shared O(n^3) DP. For every suffix containing
a one, its trailing-zero age b=n-last1 is the same, and the next possible
gap for a one at the prediction time is j0=b+1. Let c_j be the observed
completed-gap counts, r=sum c_j and s0 the observed gap span. Define arrays

    A_{beta,q}=sum_d prod_j binom(c_j+d_j,c_j),
    B_{beta,q}=sum_d (sum_{j>b}d_j) prod_j binom(c_j+d_j,c_j),
    C_{beta,q}=sum_d d_{j0} prod_j binom(c_j+d_j,c_j),

where sums have sum d_j=q and sum j*d_j=beta. They are coefficients of
`G_c`, `G_c` marked by residual-gap count above b, and `G_c` marked at j0.
Initialize them at c=0 from the base geometric factors
prod_{j=1}^{L-1}(1-z y^j)^(-1). As a suffix grows leftward over a zero, only
the first-one cutoff changes. When it includes an earlier one, a new observed
gap of length j is added, multiplying all three generating functions by
(1-z y^j)^(-1). The same in-place recurrence updates an existing cell from
(beta-j,q-1):

    A[beta,q] += A[beta-j,q-1]
    B[beta,q] += B[beta-j,q-1] + 1_{j>b} A[beta-j,q-1]
    C[beta,q] += C[beta-j,q-1] + 1_{j=j0} A[beta-j,q-1].

Process beta in increasing order; the referenced lower-span cells have
already incorporated all copies of this j. Equivalently, an explicit
multiplicity-d convolution must multiply the added B/C mark by d. Omitting
that d would be an error.

For a suffix of length t, let a be its first-one position and cap=L-a-s0,
which is also L minus its last-one position. The unnormalized denominator and
next-one numerator, after cancelling the common factor kappa/(A_L+1), are

    D_t = 1/[r!(L-s0)]
          + sum_{beta<=cap,q>=1} B_{beta,q}/[(L-s0-beta)(r+q)_r q],
    N_t = sum_{beta<=cap,q>=1}
          C_{beta,q}/[(L-s0-beta)(r+q)_r q],

where (r+q)_r=(r+q)!/q!. The q=0 term appears only in D_t. Then
Q_L(y1)/Q_L(y)=N_t/D_t. The first-position cutoff cap is essential. For an
all-zero suffix 0^t, use (1) and

    Q_L(0^t1)=1/(A_L+1) sum_{S=0}^{L-t-1} p(S)/(L-S).

Prefix sums of p(S) and p(S)/(L-S) give these all-zero conditionals in O(1)
time each after O(L^2) partition-number preprocessing.

Base marked-table construction costs O(L^3) coefficient updates; each
observed gap added while scanning suffixes costs O(L^2), for at most O(L)
gaps. Evaluating each of O(n) suffix ratios costs O(L^2), for a further
O(L^3) coefficient-weighted summand operations. Therefore a terminal HJW
prediction costs O(n^3) integer coefficient/summand updates, not O(n^4),
plus polynomial-bit exact arithmetic. The tables have O(n^2) cells with
O(n)-bit coefficients (O(n^3) bits). For an explicit rational calculation,
the q denominators F_q=(r+q)!/(q-1)! and slack denominators
V_beta=L-s0-beta separate: use the common products U=prod_{q=1}^{max(1,cap)}
F_q and V=prod_{beta=0}^{cap} V_beta. This scales D_t and N_t to integers of
O(n^2 log n) bits. The final average of n conditional probabilities has
O(n^3 log n) bits under a denominator-product bound. Thus this is polynomial
in bit complexity as well as coefficient-update count. A reference exact
implementation and exhaustive checks are in `predictor.py`,
`check_suffix_incremental_dp.py`, and `check_predictor.py`.

6. TERMINAL PREDICTOR AND RISK

For a given observed history x_1^n, define

    q_t(1 | y) = Q_L(y1)/Q_L(y),  |y|=t,   L=n+1,

and output the binary distribution

    qhat_n(. | x_1^n)
      = (1/n) sum_{t=1}^n Q_L(X_{t+1}=. | X_1^t=x_{n-t+1}^n).       (3)

This is the suffix-averaged predictor in Han–Jiang–Wu Proposition 1. Their
proposition states for stationary data that its worst-case expected KL loss
is at most `Red(Q_L)/n + mem`. For a renewal process, represent the hidden
state as the stationary countdown to the next renewal. Truncating this
countdown at n+2 gives an alphabet of n+2 values sufficient to determine the
observed block; hence the memory term is at most log(n+2)/n. Substituting the
redundancy bound with L=n+1 yields

    sup_mu E_mu KL(P_mu(X_{n+1}|X_1^n) || qhat_n(.|X_1^n))
      <= [pi sqrt(2n/3)+2 log(n+1)+log 2+log(n+2)]/n.

This is order n^-1/2. HJW Theorem 4 establishes the matching minimax order
Theta(n^-1/2) for this stationary renewal class; the result here matches the
order, not the sharp constant or exact minimax code. Because (3) averages
suffix predictors, it is a legitimate probability distribution even though
Q_L is only a block assignment and is not asserted to arise from a single
infinite stationary model.

7. RESOURCE ACCOUNTING AND STRONG BASELINES

Raw information cost. One history of n observed bits is read once; for the
prediction task, X_{n+1} is not acquired. The theorem itself is under the
stationary law and charges no independent episodes, renewal-event oracle,
reset, hidden labels, known initial age, mean, or support cutoff. For full
block coding, L bits are encoded. There is no external calibration sample.

Computation and storage. The fixed-horizon prefix code uses a partition DP
with O(L^2) integer cells and O(L^2) rank/unrank operations; multiset-gap
ranking takes O(L^2) operations. All integers have at most O(L log L) bits,
and the output has O(L log L) bits in the worst case. The separate HJW
terminal predictor uses O(n^3) coefficient and summand updates across all
suffixes, with O(n^2) coefficient cells / O(n^3) coefficient bits and
O(n^3 log n) bits for an exact final mixture. The exact rational predictor
has no numerical precision error. These are conservative symbolic bounds,
not measured runtime; runnable code and exhaustive checks are included.

Same-data statistical baseline. HJW's normalized maximum-likelihood (NML)
block distribution is the strongest redundancy benchmark: Shtarkov's theorem
makes it minimax for worst-case pointwise redundancy, and for the renewal
class the minimax redundancy is Theta(sqrt n). HJW use its conditional
marginals in Proposition 1 to attain the optimal terminal risk order, but
explicitly state that this predictor is not computationally efficient and
that a polynomial implementation is unclear. It uses the same stationary
history interface. The code above gives an alternative with the same
O(sqrt n) redundancy order and a polynomial exact marginal algorithm, while
not claiming NML's sharp constant or minimax optimality.

Same-class computational coding baseline. Garivier's 2006 thesis studies a
stationary renewal likelihood with a special first-passage term and a
right-censored terminal term. The visually inspected page 90 (printed p.85),
Theorem 22, gives CTW pointwise redundancy
Theta(sqrt(n) log_2 n) on renewal sources. This is efficient but has a log n
factor over the minimax redundancy order. Applying the HJW
redundancy-to-risk conversion gives O(log n/sqrt(n)) terminal risk, plus the
smaller log n/n memory term. Its analysis is directly relevant to the same
stationary class. The type-first assignment has a better proved rate bound
if its derivation and DP survive independent review; this comparison does not
imply a practical runtime advantage or a novelty result.

Acquisition versus computation. Both HJW NML and this algorithm receive the
same one raw path. There is no sample/information saving. The distinction is
the cost of evaluating a probability assignment and its conditionals: the
NML minimax assignment is hard to compute in the cited work; the proposed
type assignment has a polynomial exact class code and a cubic coefficient /
summand update count for its HJW predictor. Its conservative big-integer
cost is unbenchmarked and may be less practical than optimized CTW at
moderate n, so only polynomial computability is claimed.

8. PRIOR ART, LIMITS, AND STATUS

Primary-source audit performed for this note:

1. Han, Jiang, and Wu, arXiv:2404.15454v1 (2024), Proposition 1,
   Theorem 4, and Section 3.4. They define exactly the finite-mean stationary
   renewal law with equilibrium initial wait; state minimax risk Theta(n^-1/2),
   use a Theta(sqrt n) NML redundancy plus O(log n) countdown-memory term,
   and call a computationally efficient optimal renewal predictor an open
   question in that version.
2. Csiszár and Shields, “Redundancy rates for renewal and other processes,”
   IEEE TIT 42(6), 2065–2072 (1996), DOI 10.1109/18.556596. HJW cite it for
   Theta(sqrt n) renewal minimax redundancy. The original paper's full text
   was not directly accessible in this audit.
3. Csiszár, “The Method of Types,” IEEE TIT 44(6), 2505–2523 (1998),
   Section VII. It describes renewal types as counts of zero-run lengths,
   states same-type words are equiprobable under its renewal convention, and
   reports that Csiszár–Shields proved exp(O(sqrt n)) many such types. This
   establishes the general type-class principle as prior art, but that
   source's initial-wait convention has not been reconciled line-by-line with
   the stationary likelihood used here.
4. Garivier, “Modèles contextuels et alphabets infinis en théorie de
   l'information,” PhD thesis (2006), Chapter 3. Equation (3.12) has the
   renewal likelihood with its first-passage and censored factors; Theorem 22
   gives CTW's Theta(sqrt(n) log n) pointwise redundancy. The page was also
   visually checked at printed p.85 (PDF p.90), resolving an OCR ambiguity.
5. Flajolet and Szpankowski, “Analytic Variations on Redundancy Rates of
   Renewal Processes,” IEEE TIT 48(11), 2911–2921 (2002), DOI
   10.1109/TIT.2002.804115. Its precise asymptotics concern nonstationary
   renewal sources; it is not substituted for the stationary model here.

Novelty is UNKNOWN. The type-code upper bound is a standard method-of-types
idea and may simply be an explicit form of known renewal-type coding. The
bounded audit supports only this statement: the above exact start-position
weighting, stationary likelihood ratio, and bivariate prefix-marginal DP are
proved internally here and pass small exact diagnostics; whether these
specific algorithmic details appeared previously is unverified. The primary
CS96 text and broader post-2024 literature need a targeted review before any
novelty claim. No external proof review has occurred.

The all-n theorem is analytic and does not depend on the finite checker. The
checker verifies L=1,...,8 only. The DP bit-time bounds are conservative
worst-case upper bounds, not measured runtime. The HJW reduction is invoked
with the exact stationary class and exact block assignment; if any hidden
technical condition in a later HJW version differs from v1, recheck it before
reuse. Finally, the code is indexed by known block length and is not claimed
to be a single horizon-free online code with one persistent state.

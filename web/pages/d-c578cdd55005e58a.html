# Family 120 as molecular interaction-graph design

## Verdict

The constrained application that matches release family 120 is exact **graph topology / coordination feasibility**. Given an explicit simple candidate-contact graph `G=(V,E)` and a target contact count $f(v)$ for each site, an $f$-factor is an edge set $F\subseteq E$ satisfying
\[
\deg_F(v)=f(v)\qquad(v\in V).
\]
The pinned release states a uniform randomized word-RAM algorithm with $(n+m)^{1+o(1)}$ worst-case instruction complexity that outputs a valid factor with probability at least $2/3$ when one exists, and always outputs `NO` if none exists. This is useful as a near-linear, witness-producing combinatorial filter **after** a candidate interaction graph and target degrees have been supplied. It does not predict binding, optimize a weighted interaction network, construct a molecular geometry, or certify chemical yield.

The algorithmic theorem and its asymptotic bound remain **source-reported** here. I pinned the source and reconstructed the input/output interface and reduction described in its prescribed-degree section; I did not independently audit the matching proof, implement the algorithm, or validate it against an external artifact.

## Exact source and claimed algorithm

The release source is family 120 in the OpenAI `math` snapshot `adc7f1241b42e322a6451854ab7e4b4c146bf78a`: [pinned manuscript PDF](https://github.com/openai/math/blob/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/Almost-Linear-Time-Maximum-Cardinality-Matching-in-Sparse-General-Graphs-September-24-2026/main.pdf). The relevant extracted source ranges are theorem/interface at `family120.txt` lines 90–115 and Corollary 10.1 plus Lemma 10.2 at lines 3920–3998 (printed manuscript pages 4 and 81–82). Those ranges define a simple undirected graph in adjacency-list form, $n\ge1$, $m=|E|$, $p=n+m$, and one-word integer records $f(v)$ with $0\le f(v)\le\deg_G(v)$.  A factor is an explicit edge subset with those exact degrees.

The source reduces this problem to one general-graph maximum-matching call. Its stated witness-preserving construction has $O(m\log(n+2))$ total vertices and edges and takes $O(n+m\log(n+2))$ word instructions. At each original vertex it makes one port for each incident edge and uses a split/permutation network to route exactly the required number of unused incidences; original graph edges become cross-edges, and the auxiliary perfect matching decodes to the chosen factor. The source says all reduction, checking, decoding, random-bit, and output costs are charged in its word-RAM model. It explicitly cautions that the interface neither encodes binary edge multiplicities nor optimizes edge weights.

The corollary's error behavior is asymmetric:

- If a valid $f$-factor is output, its edge list is explicitly checked and certifies graph feasibility.
- If no $f$-factor exists, the algorithm always returns `NO`.
- If a factor does exist, the algorithm returns one with probability at least $2/3$; it can return `NO` on that feasible instance. Therefore a single `NO` is not a proof of infeasibility.

Re-running with independent randomness `r` times and accepting the first verified factor lowers the feasible-instance false-negative probability to at most $3^{-r}$, at a factor-`r` time cost. This is a deduction from the stated per-run guarantee, not a separate source theorem.

## Molecular interface and scope

One precise interface is:

- `V` is a finite set of atom, ligand, or binding-patch sites whose **new single contacts** are being designed.
- An edge $\{u,v\}\in E$ means that one candidate contact between those two sites is permitted. The graph is supplied explicitly, simple, undirected, and has at most one contact type per unordered pair.
- $f(v)$ is the exact number of new contacts to select at site $v$. If a scaffold has fixed existing contacts and target total coordination $d^*(v)$, set $f(v)=d^*(v)-d_{\rm fixed}(v)$, provided this is a nonnegative integer no larger than the candidate degree.
- The returned design is $F\subseteq E$, with exactly $f(v)$ selected contacts incident to every site.

This checks only whether the supplied pairwise candidate graph admits the requested degree sequence. The input graph and target degrees must be acquired from an upstream model or experiment; family 120 does not identify sites, generate edges, estimate parameters, or decide whether the edge set is physically complete. Even simultaneous edgewise geometric plausibility need not imply joint geometric realizability. Extra constraints such as bond order, atom labels, mutually exclusive states, charge, aromaticity, connectedness, chirality, and multiple edge types are outside the theorem unless separately encoded by a proved reduction. Ordinary simple $f$-factors do not themselves encode these constraints.

In particular, the theorem certifies no energy ordering, free energy, affinity, on/off rate, reaction barrier, solvent effect, kinetic accessibility, or product yield. A factor is a feasibility certificate in the chosen abstract graph, not a physical-realizability or performance certificate.

## Explicit energetic counterexample

Consider two rigid bivalent scaffolds. Let the four contact sites be $V=\{1,2,3,4\}$, with sites `1,3` on scaffold A and `2,4` on scaffold B. Permit all four cross-scaffold pairs, so $G=K_{2,2}=C_4$, and require $f(v)=2$ at every site. The only $f$-factor is the complete four-edge square. Place the sites at the corners of a rigid square with side length $r_0=2^{1/6}\sigma$; then each allowed contact has length $r_0$, and the angle between the two contacts at every site is $\pi/2$. The graph constraint is satisfied exactly and is geometrically realized.

Use the following deliberately stylized, fully specified interaction energy. Each cross-scaffold contact has a Lennard–Jones potential
\[
U_{\rm LJ}(r)=4\epsilon\left[(\sigma/r)^{12}-(\sigma/r)^6\right],
\]
whose minimum at $r_0$ is $-\epsilon$. Each site that forms two contacts pays the harmonic angle-strain cost
\[
U_\theta(\theta)=\tfrac12 k_\theta(\theta-\pi)^2,
\qquad k_\theta=16\epsilon/\pi^2.
\]
At $\theta=\pi/2$, this is $2\epsilon$ per site. Relative to separated scaffolds, the four favorable contacts contribute $-4\epsilon$, while the four angle terms contribute $+8\epsilon$, giving
\[
\Delta U=8\epsilon-4\epsilon=4\epsilon>0.
\]
Take $\epsilon=1$ kcal/mol, $T=298$ K, and, for this toy example only, set the standard association free energy equal to this energy change (zero additional entropy/solvent/reference contribution). With standard concentration $c^\circ=1$ M,
\[
K_a c^\circ=\exp[-\Delta G^\circ/(RT)]\simeq \exp[-4/0.5925]\simeq1.17\times10^{-3}.
\]
For equal $1\,\mu\mathrm M$ scaffold concentrations, the dilute equilibrium bound fraction is approximately $K_a C\simeq1.2\times10^{-9}$. Thus this topology is an exact feasible factor and has an explicit square embedding, yet it is strongly disfavored in this specified energy model. This is a toy force-field counterexample, not a measured molecule or a claim about real-world yields. It suffices to show that the combinatorial guarantee alone supplies no binding or yield guarantee; the angle term is invisible to the graph algorithm. The use of pair and angle terms is consistent with the kinds of terms used in primary molecular-mechanics force-field work, but the numeric parameters above were chosen for the counterexample, not imported from those force fields ([Weiner et al. 1984](https://doi.org/10.1021/ja00315a051); [Weiner et al. 1986](https://doi.org/10.1002/jcc.540070216)).

## Prior art and comparison

The underlying $f$-factor existence problem and its witness construction are classical. Anstee's algorithmic proof of Tutte's $f$-factor theorem gives an algorithm to find a factor or establish nonexistence in $O(n^3)$ operations, including for multigraphs with loops ([Anstee 1985](https://doi.org/10.1016/0196-6774(85)90022-7)). The family-120 contribution, if its source theorem holds as stated, is a much faster almost-linear input-size randomized graph algorithm through a compact reduction to general matching—not a new chemical feasibility predicate. General-graph maximum matching already had the $O(\sqrt{|V|}|E|)$ algorithm of Micali and Vazirani ([1980](https://doi.org/10.1109/SFCS.1980.12)); the new claimed exponent is asymptotically closer to input-linear, especially on sparse graphs. These comparisons are about mathematical problem and asymptotic operation counts; word-RAM conventions and randomized versus deterministic guarantees differ, so they are not direct implementation benchmarks.

Chemical graph generation also predates this release and can carry richer structure. Kvasnička and Pospíchal describe exhaustive nonredundant constructive enumeration of molecular graphs with prescribed valence states and empirical formula ([1991](https://doi.org/10.1016/0169-7439(91)80061-T)); their later search-tree pruning treatment handles colored multigraphs and valence by edge multiplicity ([1996](https://doi.org/10.1016/0166-218X(95)00019-N)). Those methods address generation/enumeration with chemical labels and multiplicities, while family 120's corollary takes a single unweighted simple graph and emits one degree-constrained edge subset. The latter may be an efficient subroutine after a chemical state space has been reduced to exactly this graph interface; it does not subsume those chemical constraints or the potentially large cost of generating candidates.

## Charged costs and practical boundary

For the formal input, $p=n+m$, the source-claimed worst-case runtime is $C_f p^{1+\eta_f(p)}$, where $\eta_f(p)\to0$, on every random computation path. The `f`-array uses one word per site, and the source includes the $O(n+m\log n)$ factor reduction, matching computation, validity checks, witness decoding, and output in the claimed instruction bound. The model charges random bits and uses $\Theta(\log n)$-bit words. The reduction expands to $O(m\log n)$ size; it is part of the runtime, not a free oracle.

For a molecular use, separately charge: acquiring the site list and target degrees; computing or learning the allowed-edge set; checking that each edge is a valid candidate under the chosen geometric/chemical filters; and any later geometry, energy, solvent, or kinetics calculations. A naive all-pairs candidate construction can cost $\Theta(n^2)$, which can dominate an almost-linear solver; spatial indexing or sparse chemistry-specific candidate generation requires its own assumptions and costs. No force-field energy, precision/conditioning, binding assay, model mismatch, or measurement uncertainty is included in family 120's graph runtime.

## Falsifier and next decisive gate

The application mapping would fail for any instance where a legal design cannot be represented by one explicit simple graph plus exact integer degrees without losing a constraint that affects legality. The energetic counterexample is falsified only if its stated toy energy arithmetic or equilibrium assumptions are wrong; it does not challenge the source matching theorem. A useful next gate is to specify a real target system and test whether its legal interaction choices truly reduce to this interface, then compare the solver only against equally informed construction methods while charging candidate-edge acquisition. Separately, the release's almost-linear randomized theorem needs independent mathematical/implementation validation before treating its claimed runtime as established.

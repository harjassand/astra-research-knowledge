Final scoped result: for exact rational-complex F of rank r, the determinant-
weighted disjoint-minor coefficients
  c_k(F)=sum_{I,J disjoint, |I|=|J|=k}|det F[I,J]|^2
are exactly computable by a four-exterior-factor transfer. Rank factorization
F=AB is acquired by exact pivot selection and inversion. The transfer has at
most binom(2r,r)^2 reachable states across all k. For one requested k, pruning
all degrees above k leaves at most
  (sum_{p=0}^{min(k,r)} binom(r,p)^2)^2
states. Direct updates cost O(r^2) per state/site. These give arithmetic
bounds O(n r^2 binom(2r,r)^2) for all sectors and
O(n r^2 (sum_{p<=k}binom(r,p)^2)^2) for one sector. Bit lengths, including
factorization pivot minors, remain polynomial in n, r, and total rational
input length L; the output has O(n+kL+k log n) bits. Exact suffix covectors
provide exact conditional sampling in any positive sector with the same
coefficient-specific state bound and O(n) stored suffix tables.

This is a costed exact subclass result, not a solution to the unrestricted
parity sampler/energy problem, not a generic weighted FPRAS, and not an
approximate-rank guarantee. Exact rank can be unstable under rounded input;
sector-relative conditioning must be certified before replacing exact
arithmetic by approximation. The worst-case state base is high; the
coefficient-specific bound is useful for low k, while the global-rank bound
is useful when r is small. No production-scale benchmark was run.

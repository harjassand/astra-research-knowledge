# Odd X-check rows persist in the actual replacements

7October2026. Verified reused Sol/max, no nested workers. An actual-template
fact useful for the parity-sector dynamics audit; no spectral theorem follows.

Primary: BDL2605.10943v1, owned recoverable paper.tex. Current read ranges
1435--1667 (RX square/cochain replacement),1938--2008 (RZ dual replacement),
and the previously reconstructed actual seed at2200--2220.

The seed has two X checks, each weight3. A parent X-check of degree r has
at least one descendant X check of exactly the same degree in each operation:

* RX: C_x is the cellular cochain complex of two copies of the subdivided
  parent closed star X_x, joined by the cylinder on its boundary. The parent
  x apex is excluded from that boundary. In each sheet its C_x^0 vertex has
  precisely r first radial edges, one for each original x-q neighbor. The
  embedding of Y_q into Y_x is in the star boundary, so the restriction
  g_xq^0 contributes zero at that apex. The outgoing coboundary row therefore
  has exactly r distinct fine qubits. The two abstract apices remain distinct
  even if their physical realizations collapse to the same position.

* RZ: C_x^0 is two point copies with no internal outgoing differential. For
  each original x-q adjacency, the dual gluing map inserts that x-cap into
  the corresponding endpoint vertex of C_q^1=(C^0(Y_q))^*. There is one such
  endpoint qubit per adjacent q in the same layer, and none for nonadjacent q.
  The parent incidence row therefore has exactly r distinct entries.

Thus an odd weight3 X row persists through every finite RX/RZ sequence.
The hypothesis that ALL final X checks have even weight is false for this
actual family. This does not decide existence of a different particle-hole
symmetry, exact Bohr-frequency matching or memory failure. Those remain
separate dynamics questions.

The argument uses abstract cell incidences; geometric folding does not cancel
distinct basis cells. It would fail if one silently merged physically
coincident qubits or replaced the cylinder gluing by a different quotient.
No acquisition or simulation of the astronomical full code is claimed.

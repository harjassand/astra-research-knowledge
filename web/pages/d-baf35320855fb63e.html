N27 — finite-memory cue-triggered reset in a correlated error model
Version: v1 (append-only frozen record)
Date: 2026-10-09
Claim status: exact finite-model result; operational thermodynamic and biological realization unresolved.

1. Exact target and boundary

Test whether a finite-memory controller that sees only noisy mismatch cues can
use temporal correlation in a latent copying mode to improve the error/cost
tradeoff over named sitewise and burst-trigger controls. The controller is
forbidden from seeing the mismatch bit E or latent conformation X. All
calculations below are for a source-unfitted, stipulated finite-state model.
The result is not a measured property of DNA polymerases, not an optimum over
all controllers, and not a completed physical implementation.

The original oracle-threshold idea (repair a suffix after observing m true
errors) is excluded. It is not executable by a molecular controller and can
make m=1 dominate if detection/reset is treated as free. N27 instead supplies
the controller with cues Z generated by a noisy channel from the error bit.

2. Finite-state model

At site i the latent mode X_i is G (good) or B (bad), with natural transition
matrix, in G,B order,

                  T = [[1-a, a], [b, 1-b]],
                  a = 0.005, b = 0.02.

Before any action on that site, E_i is Bernoulli(e_X), with
e_G=0.0001 and e_B=0.1. The sensor reports Z_i=+ with

  P(Z=+ | E=1)=s=0.8,       P(Z=+ | E=0)=f=0.2.

Thus the controller never observes either X_i or E_i. Its state M_i is the
last three cues, in oldest-to-newest order. A policy is a Boolean map
A(M_i,Z_i) in {0,1}; no policy uses an oracle label.

For each policy, every positive cue also triggers one patch/resynthesis
attempt. It succeeds with probability eta=0.98. On success the new base is
wrong with probability e_X' in the mode after the reset action; on failure
the original E_i remains. A negative cue causes no patch. Thus a false
positive patch is charged and can create an error, while a missed error is
retained. Each successful replacement consumes one extra dNTP; failed
attempts consume none. Initial copy consumes one dNTP/site.

If A=1, apply the effective reset channel, rows/columns G,B,

                  R = [[0.8, 0.2], [0.6, 0.4]].

That is, a reset attempt sends G->B with probability delta=0.2 and B->G
with probability rho=0.6. Failures leave the mode unchanged. Then apply the
natural mode transition T, shift the cue into M, and continue. All model
choices are explicit in `finite_frontier.py` and `exact_check.py`.

The physical timing and fuel ledger used for the finite comparison is
stipulated, not inferred from chemistry:

  copy time/site       = 1 + 0.4 P(Z=+) + 1.0 P(A=1),
  dNTP/site            = 1 + eta P(Z=+),
  event-ATP-equivalent  = P(Z=+) + P(A=1).

The event ledger charges one ATP-equivalent for every patch attempt and every
reset attempt, including false alarms, incomplete resets, and correct-base
replacement attempts. It is an accounting rule for comparison only; it is not
the net ATP flux of the LDB reset channel. The copy/patch/reset time units are
synthetic; sensor acquisition, controller logic, cue-register update, and
clock costs are absent.

3. Finite cue-memory policy

Under the uncontrolled HMM, cue emissions by mode are

  P(+|G) = f + (s-f)e_G = 0.20006,
  P(+|B) = f + (s-f)e_B = 0.26.

The prior mode probability is a/(a+b)=0.2. For each finite cue window, run
the ordinary two-state HMM filter with these emissions and T. The controller
uses the finite table that triggers when the filtered posterior
P(B | last four cues) crosses 0.30 from below relative to the last-three-cue
posterior. In truth-table order index=2*memory+current cue, the on-indices
are 7, 11, 13, i.e.

  previous/current cues:  -+++ ; +-++ ; ++-+ .

Equivalently, among four cues the controller reacts to the 3-of-4 patterns
with one miss only when the three-cue posterior was below threshold. It does
not repeatedly reset on ++++ because that window is already above threshold.
The filter is a design-time map under the no-reset baseline; after feedback,
it is not asserted to be the true posterior of the controlled process, and it
is not claimed to be the optimal POMDP policy. The full online action still
depends only on M_i and Z_i.

4. Derivation of stationary rewards

The Markov state is S_i=(X_i,M_i), with 2*2^3=16 states. For each state, sum
over e,z with mass

  P(e|x) P(z|e),

then over reset outcome x' (depending on A), then over the natural transition
x'->x_next. The next memory is ((M<<1)|z) mod 8. These branches define a
16-by-16 row-stochastic transition matrix P_pi. The unique stationary vector
pi satisfies pi P_pi=pi and sum(pi)=1. `exact_check.py` obtains pi by exact
Fraction Gauss-Jordan elimination and computes stationary rewards. For a
positive cue, expected final error conditional on e,x' is

  eta e_{x'} + (1-eta)e;

for a negative cue it is e. Consequently

  expected errors/site = pi-average of that final-error reward,
  expected dNTP/site   = 1 + eta P_pi(Z=+),
  expected time/site   = 1 + 0.4 P_pi(Z=+) + P_pi(A=1),
  event-ATP equivalent = P_pi(Z=+) + P_pi(A=1).

All + cues are patched under all policies. This charges true and false cue
patches equally, including re-copy errors on originally correct bases. The
transition branch includes both reset directions and non-reset failures.
No Monte Carlo estimate is used for the tables below.

policy kernels, not an implemented control circuit. Strict 3+ controls have
maximum reset rates below the candidate and are shown unscaled; they under-use
the candidate's event budget and remain lower-cost frontier points.

The finite computation also reports H(U|M'), where U is the oldest cue
popped from the three-bit shift register and M' is the updated register. For
the candidate this is 0.7424039029 bits/site. The thermodynamic erasure lower
bound is kBT ln(2) times this number only in the stated abstraction where M'
is the available side information and U is erased. It is not achieved work.
The output H(Z|E)=0.7219280949 bits/site is retained only as a cue-channel
entropy diagnostic; it is not added as a second erasure charge. If Z is copied
reversibly into M' and the sensor is unbound using that retained copy, adding
H(Z|E) independently would double-count information that was not discarded.
The actual receptor, copy, reset, and register network is not specified, so
the total controller work remains unknown.

6. Finite-time reset embedding and local detailed balance

The effective 2-state reset map is exactly embeddable in a finite-time CTMC.
Let K=k_GB+k_BG and run the generator with positive off-diagonal rates
k_GB (G->B) and k_BG (B->G) for tau_R=1. Its transition probabilities are

  P(G->B;tau_R) = (k_GB/K)(1-exp(-K tau_R)),
  P(B->G;tau_R) = (k_BG/K)(1-exp(-K tau_R)).

Choosing K=-ln(1-rho-delta)=ln(5),
k_GB=delta K/(rho+delta)=ln(5)/4, and
k_BG=rho K/(rho+delta)=3 ln(5)/4 gives exactly delta=0.2 and rho=0.6.
Both directions have strictly positive finite rates, so the effective map is
not relying on a one-way reset. `thermo_check.py` verifies these identities.

One local LDB assignment compatible with the given background rates is to
couple ATP hydrolysis to G->B:

  G + ATP <-> B + ADP + Pi,
  ln(k_GB/k_BG) = beta(Delta_mu_ATP - (E_B-E_G)).

If the background G->B and B->G rates a=0.005,b=0.02 are an equilibrium
channel, they imply (E_B-E_G)/kBT=ln(b/a)=ln(4). The reset rates have
k_GB/k_BG=delta/rho=1/3. Therefore local detailed balance holds with

  Delta_mu_ATP/kBT = ln(k_GB/k_BG) + (E_B-E_G)/kBT
                    = ln(1/3)+ln(4) = ln(4/3) > 0.

For the opposite convention, hydrolysis on B->G would require affinity
ln(3/4)<0 under the same state gap. This sign and orientation are important.

The reset channel's actual net hydrolysis under the cue-triggered stationary
controller is not one ATP per alarm. With G->B hydrolytic and B->G
synthetic, net ATP per site is

  delta * P(alarm starts in G) - rho * P(alarm starts in B)
  = P(G->B reset) - P(B->G reset)
  = 0.00322178994379 - 0.00388807242967
  = -0.000666282485879/site.

The negative value means the conditioned reset channel would synthesize ATP
on net if interpreted alone. It cannot be claimed as free fuel: the controller
uses the correlated sensor history to gate the channel, and the energetic
cost/work extraction of that measurement, gate, cue reuse, and memory update
has not been included. The positive-affinity local reset edge is LDB
compatible; the full feedback machine is not thermodynamically closed. The
stipulated 0.2330795 event-ATP-equivalent/site table must not be relabeled as
net ATP use, ATP molecules hydrolyzed, chemical work, or thermodynamic
efficiency.

The cue odds themselves can be represented by conditional equilibrium
binding free-energy differences for a binary receptor R:

  Delta F_bind(E=1) = -kBT ln[s/(1-s)] = -kBT ln(4),
  Delta F_bind(E=0) = -kBT ln[f/(1-f)] = +kBT ln(4).

This states a possible equilibrium free-energy assignment, not a receptor
kinetic model. The model samples Z immediately from its target distribution;
it does not give finite-time association/dissociation rates, receptor reset,
ligand turnover, or the work/time needed to couple mismatch structure to the
binding energy. Similarly, the shift register has a Landauer lower bound but
no finite-speed implementation, clock, or realized dissipation. Those gaps
prevent an operational accuracy-speed-fuel claim.

7. Counterchecks and alternative attempts

* Oracle suffix clipping was rejected because the controller would need true
  mismatch labels and a free detector/reset assumption. N27 uses only noisy Z.
* The deterministic 3+ burst rows are explicit counterexamples to any claim
  that the threshold-crossing policy dominates all accuracy-speed-fuel points.
* Randomized rate matching beats only the named, thinned sitewise and burst
  kernels; the randomizer's cost is omitted and no all-policy optimization
  was done.
* The reset event ledger and the LDB reset-channel flux disagree by design:
  the former is a charged per-attempt budget, while the latter is signed net
  stoichiometric flux. The latter is negative in the candidate stationary
  controller. Treating the former as realized fuel would be unsupported.
* A biological fit is absent: e_G,e_B,a,b,s,f,eta, dwell times, and mode-reset
  transition rates were chosen for a finite example, not measured or inferred
  from a specific polymerase. No evidence is supplied that a polymerase has
  this two-state persistent high-error mode or this mismatch cue channel.

  in Biosynthetic Processes Requiring High Specificity,” PNAS 71(10),
  4135–4139 (1974), DOI 10.1073/pnas.71.10.4135,
  https://doi.org/10.1073/pnas.71.10.4135 . The paper's driven proofreading
  cycle is established prior art for fuel-consuming accuracy enhancement.
* M. J. Donlin, S. S. Patel, and K. A. Johnson, “Kinetic partitioning between
  the exonuclease and polymerase sites in DNA error correction,” Biochemistry
  30(2), 538–546 (1991), DOI 10.1021/bi00216a031,
  https://pubmed.ncbi.nlm.nih.gov/1988042/ . The PubMed abstract reports
  measured T7 polymerase kinetic partitioning: transfer to exonuclease is
  2.3 s^-1 for mismatched DNA versus 0.2 s^-1 for matched DNA, while
  polymerization over a mismatch is slow. This is established conformational/
  site-partitioning fidelity work; it does not validate N27's latent
  persistent good/bad mode or finite cue trigger.
* A. R. Fersht, J. W. Knill-Jones, and W. C. Tsui, “Kinetic basis of
  spontaneous mutation: Misinsertion frequencies, proofreading specificities
  and cost of proofreading by DNA polymerases of Escherichia coli,” J. Mol.
  Biol. 156(1), 37–51 (1982), DOI 10.1016/0022-2836(82)90457-0,
  https://pubmed.ncbi.nlm.nih.gov/6212689/ . The publisher abstract reports
  10–13% of dATP/dTTP and 6% of dGTP/dCTP turned over to monophosphate under
  the studied conditions, showing why replacement and proofreading fuel
  cannot be ignored. N27's one-dNTP replacement charge is only its toy ledger.
* R. Landauer, “Irreversibility and Heat Generation in the Computing Process,”
  IBM J. Res. Dev. 5(3), 183–191 (1961), DOI 10.1147/rd.53.0183,
  https://doi.org/10.1147/rd.53.0183 ; T. Sagawa and M. Ueda, “Minimal Energy
  Cost for Thermodynamic Information Processing: Measurement and Information
  Erasure,” Phys. Rev. Lett. 102, 250602 (2009), DOI 10.1103/PhysRevLett.102.250602,
  https://pubmed.ncbi.nlm.nih.gov/19659065/ . These motivate treating overwrite
  and feedback work as real resource terms. N27 records only a conditional
  erasure lower-bound diagnostic and no finite-time achieved work.

No novelty or priority claim is made. This is a small finite-policy/model
construction in a domain with extensive kinetic proofreading and polymerase
partitioning literature. The computation does not establish an experimentally
realized advantage or that the temporal-cue controller is new.

9. Executable evidence and exact remaining inference

Run from the campaign root:

  python3 work/natural/n27_correlated_repair/exact_check.py
  python3 work/natural/n27_correlated_repair/finite_frontier.py
  python3 work/natural/n27_correlated_repair/thermo_check.py

The exact script uses only Python's standard library and rational arithmetic;
it verifies row stochasticity, nonnegative stationary masses, exact stationary
equations, and strict inequalities against the first four deterministic
controls. The floating frontier script uses NumPy for the 16-state stationary
solves and analytical Bernoulli thinning. The thermodynamic check verifies the
finite-time reset embedding, positive rates, LDB affinity and exact signed net
reset stoichiometry for the candidate. The scripts do not measure enzymes or
close controller thermodynamics.

Remaining inference for a physical claim: specify and solve a complete
finite-state chemical network for mismatch-coupled cue formation, reversible
cue copy/erasure, trigger gating, timed CTMC reset, patch success/failure and
dNTP/ATP stoichiometry, with local detailed balance on every edge and all
reverse paths. Charge sensor kinetics, cue reuse, register update, clock and
all nucleotide turnover. Then fit every kinetic parameter to one named
polymerase and compare against equally informed controls with the same
implemented sensor, register, and work/time budgets. None of those steps is
established by this record.

10. Accounting clarification (append-only)

The 0.2330795/site value is only the stipulated one-event-per-trigger
accounting convention. It is not a conservative upper bound on physical work
or fuel use: omitted sensor, trigger-gating, register, clock, and finite-time
reset implementation costs could make the realized total larger. The signed
net ATP flux derived for the isolated reset reaction is a separate quantity
and is not the value in that event ledger.

CYCLE 4 LEAF — QUANTIFIERS AND CLASSWISE CONSEQUENCES OF THE SPARSE-SWITCH CANDIDATE
Date: 2026-10-08
Status: INTERNAL AUDIT. The sparse-switch positive-recurrence argument remains an
internally proved candidate pending independent review. The factorization,
class-label, tightness, and minorization comparisons below are exact conditional
consequences of that candidate and the specified CTMC interface.

DECISIVE STATEMENT
------------------
Fix one positive finite rate vector for the sparse paired-edge network. Split
substrates into I_+={i: N(i) is nonempty} and I_0={i: N(i) is empty}. The full
state space factors as Y x L, where

  Y = N_0^J x N_0^(I_+),       L = N_0^(I_0).

Every transition preserves ell in L and has a rate depending only on y in Y.
Thus each class C_ell=Y x {ell} is an exact copy of one active-coordinate
chain. Isolated catalysts are not labels because 0 <-> A_j changes them.
Disconnected active graph components are not labels either: the catalyst
immigration/death channels and paired B-changing reactions give paths across
every active-coordinate fiber.

Conditional on the sparse-switch Foster candidate establishing positive
recurrence of the active chain, the unique class invariant laws are exactly

  pi_ell = pi_Y tensor delta_ell,       for every ell in L.

Consequences, with quantifiers made explicit:

1. For a fixed rate vector, active-coordinate stationary tightness is uniform
   over all labels: for every epsilon>0 there is a finite K subset Y such that
   pi_ell(K x {ell})=pi_Y(K)>=1-epsilon for every ell. This is equality of
   distributions, not an estimate uniform over rate vectors.
2. The full-state family {pi_ell: ell in Lambda} is uniformly tight if and only
   if Lambda is finite. In particular, if I_0 is nonempty and all label values
   are allowed, it is not uniformly tight. Every individual pi_ell is still a
   tight probability. A chosen probability mixture over labels is also tight;
   the failing quantifier is the supremum over all class labels.
3. Any nonnegative measurable dynamic-coordinate statistic f has exactly the
   same stationary integral in every class, as an extended integral:
   integral f(y) pi_ell(dy,dell)=integral f(y) pi_Y(dy). If finite, that
   moment is automatically label-uniform. The additive sparse-switch drift
   alone does not assert finiteness of a specified moment or supply a numerical
   tail bound.
4. The drift exceptional set is finite in active coordinates but has an
   infinite full-state lift when I_0 is nonempty. A physical-time minorization
   has the same time and positive constant on each class, but its atom/measure
   must retain the class label. There is no single nonzero full-state
   minorizing measure valid across two or more disjoint classes.

The fixed-label theorem is therefore neither a global irreducibility claim nor
a global uniform-tightness claim. It does give exact label-uniform control after
projection onto the active coordinates.

1. EXACT QUOTIENT AND CLASS QUANTIFIERS
--------------------------------------
For every (j,i) in E the paired channels are

  A_j <-> A_j+B_i,          A_j+B_i <-> (k_ji+1)A_j+B_i,

with all four rates positive and finite, k_ji>=1, and standard stochastic
mass-action propensities. For each j, 0 <-> A_j has positive finite rates.
Let ell=(b_i:i in I_0). No reaction changes any coordinate in ell. Conversely,
within a fixed ell, the active coordinates communicate: use a neighbor
catalyst birth if necessary and A_j+B_i -> A_j to clear each active substrate,
then drain catalysts; to build a target, birth a neighbor catalyst and use
A_j -> A_j+B_i, then adjust catalyst counts by 0 <-> A_j. Each required finite
path has positive probability. Thus

  C_ell = {(a,b): b|_(I_0)=ell}

is exactly one closed communicating class for every ell. This statement is
structural and does not depend on the recurrence candidate.

Write y=(a,b|_(I_+)). If q_theta(y,y') denotes the active quotient rates, then
for all ell,

  Q_theta((y,ell),(y',ell)) = q_theta(y,y'),
  Q_theta((y,ell),(y',ell')) = 0       when ell' != ell.

The active generator, its paths, and every active-only Lyapunov generator are
therefore identical in every class. If I_0 is empty, L consists of the single
empty label and there is one class; all cross-class claims below become
vacuous.

2. WHAT THE SPARSE DRIFT PROVES ABOUT FINITENESS
-----------------------------------------------
For active substrates use h_i(a)=1{sum_(j in N(i)) a_j=0}; the sparse-switch
candidate on a fixed class can be written

  W_theta(y) = sum_j lambda_j a_j
       + sum_(i in I_+) R_i^(b_i)(1+epsilon_i h_i(a))
       + K 1{a=0},

with lambda_j>0, R_i>1, epsilon_i>0, and K chosen as in
SPARSE_EXTENSION.txt. One may include frozen terms C(ell)=sum_(i in I_0)
R_i^(ell_i), setting V_theta(y,ell)=W_theta(y)+C(ell). Since C(ell) is
constant along every transition,

  L_theta V_theta(y,ell) = q_theta W_theta(y),

independently of ell. The sparse escape-sequence argument gives, for each fixed
positive finite rate vector theta, a finite active set

  F_theta = {y in Y: q_theta W_theta(y)>-1},

and q_theta W_theta is bounded above. This is the exact quantifier supplied by
the pointwise Foster proof: for each theta, F_theta is finite, then the same
F_theta works for every label ell. The argument does not state one F common to
an arbitrary family of rate vectors.

On each fixed class, V_theta is norm-like because C(ell) is a finite constant
and W_theta controls every active coordinate. On the full lattice, V_theta is
also proper if the frozen exponential terms are included. Properness is not
the same as a finite drift set: the global exceptional set is

  { (y,ell): L_theta V_theta(y,ell)>-1 } = F_theta x L.

If I_0 is nonempty and F_theta is nonempty, this is infinite. Under the
candidate recurrence conclusion F_theta cannot be empty: an everywhere
strict drift LV<=-1 for a nonnegative norm-like W on a nonexplosive chain
would force negative expected W after sufficiently long stopped-Dynkin
localization. Equivalently, the Foster exceptional set is a genuine nonempty
part of the irreducible infinite active class. Hence no single finite full-state
exceptional set is obtained when all labels are allowed. The Foster criterion
is applied class by class, or on the quotient Y, not as an irreducible-chain
criterion on the reducible union.

This also rules out a global geometric inequality with a positive coefficient
on the full V. Fix any y and let one isolated label ell_i tend to infinity.
Then V_theta(y,ell) tends to infinity while L_theta V_theta(y,ell) stays
constant. Thus no constants C<infinity and c>0 can satisfy
LV_theta<=C-cV_theta over the full lattice. This obstruction disappears if
there are no isolated substrates or if labels are restricted to a finite set.

3. STATIONARY TIGHTNESS: SHARP COMPARISON
----------------------------------------
Assume the sparse-switch candidate is valid, so the active quotient chain is
nonexplosive, irreducible, and positive recurrent. Let pi_Y be its unique
invariant probability. Since every class generator is the same copy of the
quotient generator, uniqueness gives

  pi_theta,ell(A)=pi_Y({y: (y,ell) in A})

for measurable A in the full state space; equivalently the active marginal of
every pi_theta,ell is exactly pi_Y and its label is delta_ell.

For active tightness, fix theta and epsilon>0. Countable-state probability
tightness gives a finite K subset Y with pi_Y(K)>=1-epsilon. Then

  sup_(ell in Lambda) pi_theta,ell(Y notin K)=pi_Y(Y notin K)<=epsilon

for every label family Lambda, including all of L. No moment hypothesis is
needed for this probability-tail assertion. For a statistic f>=0,

  sup_(ell in Lambda) E_pi_theta,ell[f(Y)] = E_pi_Y[f(Y)] in [0,infinity].

So any finite active moment is uniform in ell; its finiteness is a separate
question. In particular, the additive Foster conclusion LV<=-1 off a finite
set should not be silently upgraded to E_pi[W]<infinity, an exponential
moment, or a quantitative tail estimate. Those stronger conclusions require a
stronger drift/moment theorem, such as a justified LV<=C-cW inequality, or
another explicit integrability argument.

For full-state tightness, let Lambda be the set of labels being compared. If
Lambda is finite, take K as above and use the finite set K x Lambda; then
{pi_theta,ell: ell in Lambda} is uniformly tight. If Lambda is infinite, it
contains a label outside the label projection of every finite full-state set
(the lattice N_0^(I_0) is discrete and its compact subsets are finite). For
that label ell, pi_theta,ell assigns mass zero to the proposed finite set.
Thus the family is not uniformly tight. In particular, for any i0 in I_0,
choose ell^(n) with ell_i0^(n)=n and all other labels fixed. For any finite F,
max_(a,b) in F b_i0 is finite, so pi_theta,ell^(n)(F)=0 once n exceeds that
maximum. The same argument applies to all stationary laws of the reducible
chain: a selected mixture over labels is a tight probability, but the family
of class-extremal invariant laws is not uniformly tight.

This distinction is not repaired merely by finite-dimensionality or
polyhedrality. Here the active stoichiometric subspace is the full active
coordinate space and each fixed-label nonnegative fiber is an unbounded
polyhedral orthant. Uniformity over all labels ranges over infinitely many
translates. A common bounded polyhedral envelope, a fixed finite label set, or
a restriction to one fixed linear compatibility class would remove this
particular frozen-label obstruction. But a fixed linear class is a different
quantifier: it fixes every isolated-substrate value and therefore contains
only one of these classes. Polyhedral structure by itself does not imply a
uniform compact set for a family of unbounded classes.

4. RATE UNIFORMITY IS A DIFFERENT QUANTIFIER
------------------------------------------
The exact factorization above is uniform in ell at each fixed theta. It does
not prove

  sup_(theta in Theta, ell in L) pi_theta,ell(Y notin K) -> 0

for a rate family Theta: pi_Y itself changes with theta. A common Foster
function/drift and common finite active set are needed for that additional
supremum. The compact positive rate-box geometric drift theorem in
cycle3/leaves/geometric_rate_box.txt is stated for complete support, so it
cannot simply be cited for an arbitrary sparse E. The separate
structural_small_gain.txt argument does give a common linear drift and
uniform active first-moment bounds on rate boxes for which its strict support-
dependent LP is feasible and every active substrate has a neighbor. That is a
separate certificate with separate assumptions, not a consequence of
classwise equality alone. No uniformity is implied when rates approach zero,
become unbounded, or the LP/candidate hypotheses fail.

5. FINITE-PATH PHYSICAL-TIME MINORIZATION
-----------------------------------------
Fix theta and use the active finite drift set F_theta. Irreducibility provides
for each y in F_theta a finite positive-rate path gamma_y from y to the
active origin o. Since F_theta is finite, the union of these paths is finite.
If all paths have length zero, the result below is the direct no-jump bound
P_1(o,{o})>=exp(-q_theta(o)). Otherwise set L to the maximum path length,
Q to the maximum total exit rate over every path state and o, and r_* to the
minimum selected reaction-channel rate over all path steps. These are finite
and Q,r_*>0. Set delta=1/(2L). At each path state require the selected channel
to fire before time delta, with no earlier jump; the probability is at least
r_* delta exp(-Q delta). After reaching o (by time at most 1/2), require no
jump through time 1, with conditional probability at least exp(-Q). Therefore
for eta=exp(-Q)(r_* delta exp(-Q delta))^L>0,

  P_1^theta((y,ell), {(o,ell)}) >= eta,
       y in F_theta, ell in L.

The constants 1 and eta are common across all labels because every active
path and total rate is label-independent. On the quotient this is the common
minorization P_1^theta(y,.) >= eta delta_o(.). On the full state space the
minorizing probability is delta_(o,ell), which depends on ell.

No nonzero full-state measure nu can minorize all these classwise kernels
when Lambda contains at least two labels: each P_1((y,ell),.) is supported on
C_ell, so nu would have to be supported in every disjoint C_ell. The only
measure with that support property is zero. This is a support obstruction,
not a failure of a uniform lower probability: the constants can be uniform
while the minorizing measures differ. Conversely, classwise minorization does
not by itself give a common mixing-time or convergence-rate statement. The
additive Foster drift in the sparse candidate is not a geometric drift. For a
rate box, a common physical-time minorization can be made parameter-uniform
only after a common finite active set/paths and uniform positive lower bounds
on selected rates and finite upper bounds on total exits are supplied; labels
remain irrelevant to those constants.

6. CONCLUSION AND FALSIFIERS
----------------------------
Established exactly from the network structure: inert substrate labels,
active-generator factorization, absence of additional class labels, and the
support obstruction to one common minorizing measure across distinct fibers.
Conditional on the sparse-switch classwise Foster theorem: unique stationary
factorization; uniform stationary tightness of active projections for each
fixed rate vector; and failure of full-state uniform tightness over every
infinite label family. The candidate supplies a finite exceptional set in
active quotient coordinates (hence finite in each class), not a finite
exceptional set for the union of all labeled classes.

A direct falsifier for the classwise recurrence candidate would be an exact
positive-rate instance and active escape sequence for which the displayed
support-switch generator fails to tend to -infinity, or an explosion/recurrence
counterexample within one fixed fiber. This audit found no such obstruction;
it does not independently re-prove the mixed active-coordinate escape case.
A direct falsifier for the uniform active-stationary statement at fixed theta
would require two labels to induce different active generators, which is
impossible in the specified inert-label model; changing the interface so
isolated counts enter active propensities would invalidate the factorization.
A direct falsifier for global uniform tightness is not needed: the explicit
sequence ell_i0=n proves its failure whenever the label family is infinite.

For an independent audit of the finite-path construction, check that all
selected path channels remain positive and that Q includes the total exit rate
at the target o. For a rate-uniform upgrade, first provide one common active
drift set; then the finite union of paths gives the exact remaining lower-rate
and upper-exit-rate obligations. Do not infer geometric ergodicity from this
minorization alone.

# Consequence checked independently: physical correctability and distance

7 October 2026. rounding_spectral, verified Sol/max, no nested workers.
This independently checks the consequence proposed by root and
pde_transport9 from the actual all-closed fine anchor. It applies to the
fixed X--Z replacement family with density-admitted parameters and unit
fine Tanner edges. It does not use the source's asserted code distance.

At fine level i>=1, let e be a zero-syndrome X error supported in the
physical ball B(x,lambda^(i-1)); the Z case uses the independently gated
dual maps. No global-boundary membership is assumed. A chain map sends
a closed vector to a closed vector. After i-1 projections, its radius
is at most

    lambda^(i-1)/lambda^(i-1)
      +r*(1-lambda^(-(i-1)))<=1+r*=r0,

where r*=a lambda/(lambda-1). The resulting vector is at level1, which
is a fine replacement level, so the strong anchor proves it is a
boundary. The identity e+I P e=D K e lifts a boundary to a boundary at
each intervening level. Therefore e is a boundary in the original
level-i code. This avoids applying the stronger anchor to the seed,
which has nontrivial closed logical vectors.

For a mixed Pauli supported in the ball, its X and Z components have
support contained in that same ball. If it commutes with every check,
the preceding result makes each component a stabilizer. If it does
not commute, P O P=0. The Pauli basis thus gives the usual local
indistinguishability condition on that physical ball. It is a
zero-temperature code-space statement, not a thermal encoding theorem.

For the separate Hamming-distance bound, decompose a closed error into
its syndrome-interaction components: supported qubits are connected when
they share a syndrome check. Every component is closed because a check
touching two components would connect them. If every component were a
boundary their sum would be a boundary, so a nontrivial logical has at
least one nontrivial component. A component with w qubits has a spanning
tree with w-1 edges. Each such edge has physical length<=2 via its
common unit-range check. The component lies in the ball centered at
any one of its qubits with radius<=2(w-1). Correctability therefore
rules out

    2(w-1)<=lambda^(i-1),

and gives the conservative integer bound

    d_i>=floor(lambda^(i-1)/2)+2.                    (1)

For CSS mixed logicals at least one pure component is nontrivial and
has weight no greater than the mixed support, so(1) also bounds the
full Pauli distance. This argument remains valid for coincident physical
qubits; a zero-length tree edge only improves the radius bound.

The result is conditional on the actual proved fine anchor and geometric
admission. It does not supply BHM's fixed collar, convert arbitrary
physical interactions into Tanner-local ones, or preserve the source's
thermal lifetime under a perturbation. Those require independent
interfaces. No priority claim has been established for this consequence.

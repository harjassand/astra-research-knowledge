RELATIVE PREFIX COUNTS SUFFICE FOR EXPECTED-KL PREDICTION
8 October 2026. Root internal lemma; general approximation conversion, not a novelty claim.

Contract. Let Q_N be a full-support probability law on strings of length N=n+1
on a fixed alphabet of size A. For any input history x^n let z_t be its suffix
of length t. The exact reference predictor is q*(v|x^n)=n^{-1} sum_t
Q_N(z_t v)/Q_N(z_t). All terms refer to the same horizon N.
Suppose an algorithm approximates each positive child prefix weight Q_N(z_t v)
(or one common positive multiple H_N(z_t v)) to relative error delta, with
failure probability at most eta per call, uniformly for every supplied prefix.
It must have polynomial BIT cost in N, delta^{-1}, log(eta^{-1}); there is no
permission to charge inverse true prefix probability as a constant. This is
an assumption about a relative counting algorithm, not one established here
for hidden renewal codes. Its A n calls need not be independent.

Construction. Clip an invalid negative/nonfinite returned weight to zero. For
each t normalize the A returned child weights to a categorical distribution;
if all are zero, use the uniform distribution. Average the n distributions
to get q_tilde, and output q_gamma=(1-gamma)q_tilde+gamma/A, 0<gamma<1.
Use rational approximations with their bit/rounding error charged to delta;
randomness and failure are included in the risk expectation.

Proof. On the event that every call is relatively accurate, normalization gives
q_tilde(v)/q*(v) between (1-delta)/(1+delta) and its reciprocal, for every v,
because these bounds hold for each suffix conditional and are preserved under
averaging. Thus, for ANY true next-symbol law p on this history,
 D(p||q_gamma) <= D(p||q*) + log((1+delta)/(1-delta)) - log(1-gamma).
On the complement, smoothing gives D(p||q_gamma)<=log(A/gamma). The union bound
is conditional on the observed history and gives failure at most A n eta.
Because D(p||q*)>=0, averaging over both the stationary data (if relevant)
and algorithmic randomness yields
 E D(p||q_gamma) <= E D(p||q*)
   + log((1+delta)/(1-delta)) - log(1-gamma)
   + A n eta log(A/gamma).
No independence, lower bound on observed-history probability, or stationarity
is needed for this approximation step. Stationarity is used only in the
separate theorem that controls the exact predictor risk.

For exact rational implementation, take k=ceil(sqrt(n)),
 delta=gamma=1/(4k), eta=1/(A n^2).
Then the added expected KL is O_A(n^{-1/2}): the good-event terms are O(1/k),
and the failure contribution is log(4Ak)/n. The call count, inverse relative
accuracy and logarithmic confidence parameter are polynomial. Integer square
root and rational parameters require no real-number oracle. If an exact H_N
has O(N log N) bits, estimates may have polynomial bits; averaging n rational
probabilities also has polynomial bits. A practical implementation may instead
budget rounding before smoothing. Independent narrow Sol audit found no defect.

Application boundary. Marginalizing observed event marks of the proper row-urn
code preserves pointwise domination and its O_q(sqrt N) redundancy. The hidden
countdown/next-mark still has an exact finite block sufficient cap. Therefore
an FPRAS for the resulting hidden prefix weights, with the above cost contract,
would yield a randomized polynomial-time optimal-order O_q(n^{-1/2}) terminal
predictor. Exact #P hardness of a particular projected code would not rule this
out, and neither would it prove hardness for every possible predictor.
Conversely additive approximation, unbiased estimation with unbounded relative
variance, or sampling the prior until a rare prefix occurs does not satisfy
the required oracle contract. The conditional theorem supplies no such oracle.

Load-bearing failure tests: failure probability not uniform in supplied prefix;
relative error replaced by additive error; inverse rare-event probability hidden
in runtime; smoothing omitted on oracle failure; different horizons used across
suffixes; random-confidence risk confused with a high-probability risk theorem.
External priority and a useful hidden-code FPRAS remain UNKNOWN.

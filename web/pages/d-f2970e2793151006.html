MEMORY INFORMATION | operational archive laws and collision boundaries
Date: 2026-10-08

MAIN FINDING

There is no universal one-shot compression law determined by local Fisher
information, singular values, manifold dimension, or a collision product alone.
The robust reusable result is a pair of converse profiles: posterior-regret
small-ball volume for a fixed query, and a sum of scalar rate-distortion costs
for independent features that may be queried separately after storage. A
matching archive law still requires an explicit positive decoder/code for the
full experiment.

For a blind encoder X -> rho_X in a total D-dimensional quantum or hybrid
memory, a fixed query with bounded regret 0 <= R(X,Y) <= L obeys the
posterior trace-cap bound

    E R(X,Y) >= integral_0^L [m - D V(u)]_+ du,

where C is any source chart of probability m and

    V(u) = sup_y P{X in C : R(X,y) <= u}.

The proof is short and general. For each y, rho_X <= I_D implies
integral_{C_y} rho_x dP(x) <= P(C_y) I_D <= V(u) I_D. Integrating against
the decoder POVM yields P{X in C, R(X,Y)<=u} <= D V(u), and integrating the
resulting tail bound gives the display. For a direct-sum memory, D=sum_j d_j;
every branch label and input-dependent register is included. Independent
public seeds are allowed only when the same D bound holds at each seed.

For independent classical features X_1,...,X_d stored in the same D-dimensional
memory, with one possibly incompatible POVM for each later query i, the
second converse is

    ln D >= sum_i R_i(delta_i),

if query i guarantees expected distortion at most delta_i and R_i is the
ordinary scalar Shannon rate-distortion function for that feature/distortion.
Measurement data processing gives I(X_i;Y_i)<=I(X_i;M). Independence and
strong subadditivity give sum_i I(X_i;M)<=I(X_1...X_d;M)<=ln D. No joint
measurement of incompatible queries is assumed. This mechanism underlies the
later-query quantum converses in N36/N66. It does not apply when features are
dependent or the encoder learns the query before storage.

COUNTEREXAMPLES TO SIMPLE UNIVERSAL LAWS

1. Fisher information does not determine memory, even when the full scalar
Fisher function agrees on the same parameter interval. On theta in
[pi/3,2pi/3], the families X~N(theta,1) and X~Bernoulli(sin^2(theta/2)) both
have Fisher information exactly 1 at every theta. The Bernoulli observation
is archived exactly by storing its one bit, so D=2; a D=1 archive fails below
the TV radius 1/4 between the endpoint distributions. The Gaussian family has
affine dimension one and the supplied N07 candidate gives e_D=Theta(D^-2),
so D_min(epsilon)=Theta(epsilon^-1/2). The Bernoulli half is proved directly;
the Gaussian rate remains source-derived/internal pending independent review.
See `work/programmes/memory_information/leaves/entropy_profile_law.txt`.

2. Identical inverse singular spectra do not determine archive cost when the
singular direction is hidden until a later query. For A_i=r e_i e_1^T,
i=1,...,d, every operator has singular values (r,0,...,0). A blind encoder
receives X~N(+/- r e_i,I_d), then learns query i only after storage and must
output the corresponding scalar Gaussian. Under the N36 later-query lower,

    ln D >= (d/2) ln(r/epsilon) - (5/4+ln 2)d,

for 128 epsilon<=r<=1, even with arbitrary query-specific quantum POVMs.
If i is supplied before encoding, the equally informed scalar classical code
costs only (1/2)log2(r/epsilon)+O(1) bits. This is conditional on the
source-derived N36 inequality; the exact reduction and arithmetic fixture are
in `work/programmes/memory_information/leaves/inverse_problem.txt` and
`outputs/research/memory_information/evidence/inverse_problem/`.

3. Intrinsic curve dimension can be the wrong exponent. For a one-observation
Gaussian location experiment on the cusp theta(t)=(t^2,t^3), |t|<=1, the mean
set has affine dimension two although the parameter set is a one-dimensional
curve. The internally reconstructed N07 mechanism gives e_D=Theta(D^-1),
not the D^-2 law obtained by substituting intrinsic dimension one. The
positive-hat upper and finite-prior posterior-chart lower are recorded in
`work/programmes/memory_information/leaves/nonregular_curved_spaces.txt`.

4. The finite-n qudit collision product gives a useful but scoped theorem.
Fix d and a known sorted spectrum p_n in [1/(2d),3/(2d)]^d with p_n -> I/d,
and let

    B_n = product_{i<j}(1+n(p_{n,i}-p_{n,j})^2),  H_n=log2 B_n,
    delta_n = 1 - product_{i<j}(p_{n,j}/p_{n,i}).

For total hybrid dimension D=sum_j d_j, the collision leaf reports a
source-derived candidate lower D>=c_d B_n for every whole-state archive of
half-trace error <=1/8, and a classical upper D<=C_d eta^(-2(d^2-1)) B_n
with error <=delta_n+eta. Thus if H_n->infinity, vanishing-error leading
memory is H_n+o(H_n). For a prescribed epsilon_n this upper rate is certified
when epsilon_n>delta_n eventually and
log2(1/(epsilon_n-delta_n))=o(H_n); this condition is sufficient, not known
necessary. The upper reuses earlier internal weighted-flag/Schur likelihood
machinery and is not externally certified. The exact pair product handles
unequal gap scales; a minimum-gap summary does not.

For a power profile Delta_ij,n=n^(-alpha_ij+o(1)), this gives

    H_n = [sum_{i<j}(1-2 alpha_ij)_+] log2(n) + o(log n).

This records every pair that remains visible above the n^(-1/2) scale. At the
boundary alpha_ij=1/2, subpolynomial factors can still make H_n diverge, so the
exact product must be retained instead of this leading-log expression.

That product is not a complete all-accuracy law. For qubits n=k^2 and spectrum
(1/2+3/(2k),1/2-3/(2k)), B_n=10 exactly, but the collision leaf proves that
any bounded total hybrid dimension along a subsequence has error bounded away
from zero. A separate growing-d counterexample refutes constants uniform in
d: for full-rank p=(1-eta,eta/(d-1),...), eta=epsilon/(16n), projection onto
Sym^n(C^d) reconstructs the whole n-copy state within epsilon/8 using
D=binom(n+d-1,n), independently of the unknown eigenbasis. At d=n,
log2 D<=2n-1 while log2 B_n=(n-1)log2 n+O(1). Pure symmetric-subspace
compression is established prior art; the mixed inequality is a direct
trace-distance bound. See `growing_dimension.txt`.

5. At the rank-changing qubit boundary, the pure lambda=0 face of N23 admits a
finite-n Dicke cutoff archive with D<=O_R(1+min(n,h_epsilon)), where
h_epsilon=ln(1/epsilon)/ln ln(1/epsilon). This refutes a quadratic total-D
lower bound claimed uniformly through lambda=0. The matching two-sided pure
face rate is only source-reported because the N22 lower proof is absent from
the static prior. For fixed positive rare-rank range, N23 gives a quadratic
counted-D upper but leaves its matching lower below the C/n comparison error
open. The detailed proof and 35 exact cutoff fixtures are in
`finite_rank_boundary.txt` and `evidence/finite_rank_boundary/`.

There is also a finite-n extension to a shrinking unknown intensity range. If
lambda in [0,Lambda_n] with Lambda_n<=epsilon_n/2, the exact n-copy
half-trace distance to the pure lambda=0 family at the same z is
1-(1-lambda/n)^n<=Lambda_n. The pure-face cutoff at tolerance epsilon_n/2
therefore gives a counted-D upper O_R(1+min(n,h_{epsilon_n/2})); the included
lambda=0 subfamily gives the matching order lower via N22, still
source-reported. So a uniform square-law lower also fails for these shrinking
unknown intervals, including epsilon_n<<1/n. No such transfer is justified
for fixed positive Lambda. If a singleton intensity lambda_n is supplied and
lambda_n<=epsilon_n/2, the same comparison gives the pure archive upper; the
lambda=0 lower does not apply to that known-intensity subfamily.

MOVING SPECTRA AND QLAN

The fixed-reference literature boundary is now sharper than the old N39
blocker. Yamaguchi--Tajima, arXiv:2609.11926v2 (19 Sep 2026), proves strong
two-way trace-norm QLAN for unitary-orbit models at any fixed finite-d
reference, including repeated positive levels and rank deficiency. Its
typical Schur-sector construction factors truncated Fock modes from a ground
component and resets that component in the reverse channel. It does not cover
triangular spectra whose distinct gaps close with n, nor simultaneous unknown
splitting within repeated blocks. Kahn--Guța's full-d result assumes a fixed
simple faithful spectrum and has gap-dependent remainders.

A separate exact stability lemma for common-eigenbasis iid models is promising.
For parameter-indexed spectra p_{n,theta}, q_{n,theta} with supp(p) subset
supp(q), define Xi_n=sup_theta sum_i (p_i-q_i)^2/q_i. Then

    sup_theta T(rho_{n,theta}^tensor n,sigma_{n,theta}^tensor n)
      <= r_n := min{1, sqrt(n Xi_n/2)}.

For any fixed archive dimension D and later-query family,
|e_D(E_n^p)-e_D(E_n^q)|<=2r_n. The two factors of two-sided comparison matter:
the archived output and the target output each move. Thus the N08 bridge
transfers only with combined remainder eta_n+2r_n=o(epsilon_n). This follows
from quantum relative-entropy additivity, D(p||q)<=chi^2(p||q), and Pinsker;
it is a stability bound, not a QLAN theorem or a matching collision law. The
four-level counterexample and proof are complete in
`work/programmes/memory_information/leaves/moving_spectrum_partial_collisions.txt`.

The fixed-d collision converse has now also been reconstructed independently:
`work/programmes/memory_information/leaves/collision_lower_independent.txt`
uses only the published one-sided closed-chamber orbit-ball bound, a maximal
net, fixed informationally complete tomography with O_d(1/n) risk, and the
full direct-sum trace cap. It proves D>=c_{d,e}B_n for every fixed error e<1.
This validates the lower route internally; the weighted-flag classical upper
still depends on the earlier internal candidate package.

A complementary critical-qubit precision audit is in
`outputs/research/sol_collision_precision/RESULT.txt`. For the known full
orbit rho_(r,v)=(I+r v.sigma)/2 with c0<=r*sqrt(n)<=c1 and whole-state
half-trace reconstruction, its corrected bounded proper-score proof gives
every EB channel e>=c r; a coherent finite-alphabet EB channel has e<=2r.
Thus the optimum EB error is Theta(r)=Theta(n^(-1/2)) uniformly on each fixed
positive critical interval, including arbitrary EB outcomes and
sector-changing decoders. The earlier logarithmic lower bound is superseded.
A direct exact Schur cutoff also gives a charged hybrid quantum archive
D<=C n(1+log(1/epsilon)) at every accuracy, capped by O(n^2). Thus below the
N08 bridge, such as epsilon=n^(-1), classical archives are ruled out while
quantum compression still exists; the conditional N08 exponent 3/2 cannot
extend to all accuracies. The proper-score mechanism has known ancestry in
posterior-direction moments and a related Astra ordered-spin VMF archive
theorem; the targeted audit is
`outputs/research/memory_information/prior_art_critical_eb.md`. The exact
finite-n theorem remains an internal candidate pending independent proof and
priority review. It does not identify the optimal total hybrid dimension or
rule out another uniform quantum comparison channel. The exact sectorwise
thermal-to-Fock replacement error remains positive at critical signal, so
that particular Gaussian construction needs a precision gate.

The next quantum-capacity gate is now closed at the branch-order level for
the same critical qubit family. Let Q be the maximum quantum dimension of a
retained branch; unlimited classical outcomes are allowed in the converse,
and branch labels are charged in the construction. A rank-Q Choi/Schmidt
score argument gives e>=c(c0,c1) r/Q whenever Q<=1/(32r), even for arbitrary
output-sector changes. A covariant instrument with a positive tapered
rank-Q spin filter gives e<=C(c1) r/Q. Therefore the optimal worst-case
whole-state error is Theta(r/Q) for 1<=Q<=1/(32r); fixed Q cannot attain
o(r). On the unknown-radius ball ||b||<=c1/sqrt(n), the corresponding
worst-case order is Theta(1/(sqrt(n)Q)) up to Q of order sqrt(n). The lower
and full-trace upper proofs, exact finite Euler/Gauss quadrature, and
independent audit are in
`outputs/research/sol_collision_precision/quantum_branch.txt` and
`outputs/research/memory_information/quantum_branch_upper_audit.txt`.

The finite code has O(n^3) classical outcomes and total direct-sum dimension
D<=O(Q n^3); it is not a total-D optimum. The separate Schur cutoff has a
smaller total-D upper but does not settle the minimum Q for each error. The
branch converse saturates at Q=Omega(1/r) below error scale r^2, so the
all-accuracy branch law and optimal joint (D,Q) frontier remain open. Exact
algebraic quadrature, gates, runtime and physical output preparation are
not costed. This internally audited candidate is not externally proof- or
priority-validated.

COSTS AND LIMITATIONS

All bit claims use archive bits log2 D, not D itself. Known spectra, inverse
operators, axes, calibration and query conventions are supplied only where
stated. Unknown spectra/geometry require an acquisition interface and cannot
be hidden inside a model description. An effective tail certificate is
needed for a terminating infinite-spectrum codec. Encoder/decoder runtime,
public tables, arithmetic precision, random bits, calibration reads, model
description and fresh physical outputs are separate costs unless a particular
claim explicitly includes them.

Ideal continuous-output TV is not a finite-float guarantee: any deterministic
finite-output decoder has countable support and TV distance one from a
non-atomic Gaussian target. A finite-bit implementation must change the
target metric, give a charged lazy-real sampler, or prove a precision/coupling
bound. The finite binned inverse codec is a concrete comparator, not evidence
of practical superiority; its graded tables were larger than the uniform-hat
baseline at the same archive size.

No claim here is externally validated as a new theorem or priority result.
Primary-source audits, exact interfaces, proof limits and restart gates are
linked in `CLAIMS.json` and `RESTART.txt`.

# Exact sequential conversion: source audit and a sharp executable special case

Status: reconstructed, proved special case; no novelty claim. 2026-10-06.

## Exact interface and author claims

States are finite, signals finite, every state law has full support, and every pair of state laws is distinct. The laws F_i,G_i are known. Signals are conditionally iid. State-independent auxiliary randomization is free. Policies stop almost surely, have finite expected sample count in every state, and emit a finite-valued terminal output. Budgets constrain expected count in every state, not maximum count, delay quantiles, arithmetic work, model learning or policy synthesis.

Theorem 2 gives exact reproduction of every stopping G-policy (T,Z) from F with

E_i N <= rho_i E_i T + C_FG sqrt(E_i T),

rho_i = max_(j != i) KL(G_i || G_j)/KL(F_i || F_j).

The same reproducing policy works in all states; C_FG is uniform over policies and finite output spaces. Theorem 1 equates small-cost decision dominance with large-budget stopping dominance when no directed KL entries of F and G tie. In that generic setting both require strict improvement in every directed KL entry. Neither genericity nor strictness may be silently dropped.

Appendix C.1 first proposes a target output H_k after approximately classifying the state, verifies output-specific likelihood thresholds, and repairs its residual mass exactly. Lemma 8 repairs via a classifier confusion matrix A_n and the stochastic kernel A_n^-1 R. This is mathematically constructive but does not establish efficient computation of H_i(y), verifier success probabilities, residual R, A_n or conditional behavioral kernels q_h. Enumerating histories or target outputs can be exponential. Sampling access to unknown channels does not provide these quantities for free.

## Our explicit question

Can adaptive stopping reduce exact experiment-simulation cost against an equally informed comparator allowed any random sample length chosen before seeing data and any output garbling?

Both arms know the same source and target, retain the same specification and may use arbitrary independent randomization. Source F has theta in {0,1}, X in {0,1}, with P_1(X=1)=4/5 and P_0(X=1)=1/5. A source observation costs one. The desired target G has output {+,0,-}. For 0<epsilon<=13/25,

G_1 = (64 epsilon/65, 1-epsilon, epsilon/65),
G_0 = (epsilon/65, 1-epsilon, 64 epsilon/65).

One target draw, rather than an unknown representation or a discovered experiment, is the task. The full source/target matrices are supplied.

### Theorem A: optimal sequential cost is 63 epsilon/13 in each state

First draw an independent release coin with probability epsilon. On no release emit 0 using zero source samples. On release, initialize S=0, increment S by +1 on X=1 and -1 on X=0, and stop at S=+3 or -3. Emit the sign.

The likelihood ratio under state 1 versus 0 after any path is 4^S. The walk reaches a boundary almost surely with finite mean: in every six-step block, an all-up or all-down path forces absorption with a positive uniform probability, giving a geometric tail. At absorption its likelihood ratio is precisely 64 or 1/64. If a is the probability of + under state 1, then likelihood change of measure and reflection give a/(1-a)=64, so a=64/65. The state-0 probability is 1/65. Multiplying by the independent release coin gives exactly G.

Wald's identity for bounded increments at an integrable stopping time yields

(3/5) E_1 tau = E_1 S_tau = 3 (64-1)/65,

so E_1 tau=63/13. Reflection gives the same state-0 cost. Therefore E_i N=63 epsilon/13.

For any exact sequential simulator, stopped-history KL is E_1 N KL(F_1||F_0). Data processing to the output gives

E_1 N >= KL(G_1||G_0)/KL(F_1||F_0)
 = [epsilon (63/65) log64]/[(3/5) log4]
 = 63 epsilon/13.

The opposite direction gives the same bound in state 0. Thus the construction simultaneously attains both information lower bounds. It uses O(N) integer arithmetic and one signed integer in {-3,...,3}, plus the supplied probabilities. No residual inversion or target-space enumeration is needed.

Cost ledger: specifying F,G and the release probability is supplied information; one release draw and constant setup are performed per target sample; the sequential arm then makes N source requests and O(N) arithmetic steps; the nonadaptive construction makes one pre-sampling draw, either zero or three requests, and constant postprocessing. The theorem compares observation counts with randomization free, matching the paper's interface. It does not assert a wall-clock improvement when source sampling is cheap or batch execution makes the nonadaptive arm faster. No dataset/model acquisition cost has been hidden inside the count because acquisition is not part of this supplied-channel task.

### Theorem B: optimal nonadaptive randomized cost is 75 epsilon/13

Allow a nonadaptive policy to draw any nonnegative integer N independently of state and all source observations, then take N iid source observations and output through any randomized kernel. Infinite-support distributions for N are allowed, provided E N is finite. Arbitrary retention and computation are allowed.

For fixed n let P_i^n be the entire n-sample law and define the hockey-stick divergence

H_n = sum_x [P_1^n(x) - 16 P_0^n(x)]_+.

For any output kernel, its + event has G_1(+)-16G_0(+) <= H_n. With random N this gives

48 epsilon/65 <= sum_n P(N=n) H_n.

The source count t of ones is sufficient and

H_n = sum_(t=0)^n binom(n,t) [4^t - 16*4^(n-t)]_+ / 5^n.

Exact rational evaluation for n=1,...,7 yields H_n/n:

0, 0, 16/125, 12/125, 1968/15625, 328/3125, 12144/109375.

Each is at most 16/125. For **every n>=8**, H_n<=1 gives H_n/n<=1/8<16/125. This analytical tail bound, together with finite exact evaluation, proves the global inequality H_n <= (16/125)n for all n. It is not a finite test asserted to be universal.

Consequently E N >= (48 epsilon/65)/(16/125)=75 epsilon/13.

Attain the bound by selecting N=3 with probability 25 epsilon/13 and N=0 otherwise. At N=3 emit + only for 111, - only for 000, and 0 otherwise. State 1 output probabilities are

(25 epsilon/13)*(64/125)=64 epsilon/65,
(25 epsilon/13)*(1/125)=epsilon/65.

The remaining probability is 1-epsilon. State 0 is reflected. The pre-sampling probability is at most one exactly when epsilon<=13/25. Thus the strong nonadaptive comparator is optimal, and the adaptive policy saves 4/25=16% of its cost. Its comparator/sequential ratio is 25/21, not an arbitrarily large advantage.

### Why a weaker comparator is misleading

A deterministic sample length n must satisfy n>=3 by data processing for maximum likelihood ratio: source 4^n must cover target64. At epsilon=.1 the sequential cost is 63/130=.484615 while every deterministic policy pays at least3. The resulting ratio over6 is mostly avoided by the competent baseline's pre-sampling randomization; the genuine stopping advantage is only25/21. A baseline allowed sequential stopping can run the same optimal procedure, so there is no special-architecture advantage.

## Audit and execution

`work/r08_information/exact_conversion.py` uses rational Gaussian elimination on the five transient walk states to recover absorption probabilities and expected durations independently of the closed-form derivation. It checks every rational term in the dual certificate and the baseline's channel law. It also simulates 200,000 runs for each state/method; these are finite diagnostics only. `results/r08_information/exact_conversion.json` records all outputs. ## Prior art, consequence, and next step

The sequential component is classical SPRT/gambler's ruin plus stopped KL accounting; Wald/Wolfowitz optimality and Li/Liu's conversion theorem cover broader related mechanisms. The sharp nonadaptive comparator is an independently reconstructed hockey-stick dual certificate for this witness; novelty has not been established. Do not label the special case a foundational discovery.

Concrete use: an exact unit benchmark for experiment compilers, cost accounting, and adaptive-vs-nonadaptive acquisition claims. It prevents overclaiming gains obtained solely by allowing one arm to skip sampling before data.

The load-bearing unresolved step is source acquisition and calibration under a bounded real interface. If the real source is Bernoulli(p)/Bernoulli(1-p), the same walk gives release error (1-p)^3/(p^3+(1-p)^3), not1/65 unless p=4/5. Thus robust validity requires either known p or an explicit tolerance/calibration certificate. A falsifiable continuation is to build a learner with exact cost ledger, confidence interval for p, worst-case output-law error, and a matched retaining sequential baseline. Success would require a useful finite budget after charging calibration; no such result is claimed here.

ADDENDUM — FIXED-TIME RATIONAL COINS WITH FAILURE BUDGET
7 October 2026

The k-bit downward-rounded coin in INITIAL is a one-step approximation with
no explicit abort. Another fixed worst-case implementation preserves the
exact rational coin on every non-abort execution.

Let alpha=a/b in lowest terms, 0<a<b, and let B=ceil(log2 b). Draw B fair
bits, obtaining X in {0,...,2^B-1}. If X<b, return the exact answer
1[X<a]. If X>=b, repeat, at most m trials. If all m candidates are >=b,
return an explicit ABORT flag rather than a Metropolis decision.

On each trial the probability of a valid candidate is b/2^B>1/2. Conditional
on the first valid trial, X is uniform on {0,...,b-1}, so the decision has
exact Bernoulli(alpha) law. The abort probability is

  rho=(1-b/2^B)^m < 2^(-m).

Thus this is an exact rational acceptance coin except on an explicitly
reported event of probability <2^(-m), with worst-case cost mB fair bits and
m comparisons of B-bit integers. Across T adaptively chosen acceptance
ratios, the conditional abort probability at each step remains <2^(-m), so
the probability of any abort is <T*2^(-m). Taking
m=ceil(log2(T/eta)) makes the entire run abort with probability <eta.
Couple to the ideal variable-time MH run using the same candidates: whenever
the bounded run does not abort, every accepted/rejected decision and the
entire output path coincide with the ideal run. An abort is charged as a
failure event. This avoids pretending the finite-budget process is exactly
stationary.

For alpha=0 or 1, decide deterministically with no random bits. For any
non-dyadic alpha, an exact fair-bit coin with a finite worst-case bound is
impossible: the accept event is a union of depth-at-most-B leaves and hence
has dyadic probability with denominator dividing 2^B. The explicit abort
budget is the needed escape hatch under a strict every-execution runtime
claim. It costs O(B log(T/eta)) random bits per decision, polynomial when the
rational acceptance has polynomial bit length and T,1/eta are polynomially
bounded.

The INITIAL dyadic truncation remains cheaper when a per-step TV perturbation
is acceptable. This abort construction is preferable when the algorithm's
failure contract already includes delta: allocate eta<delta to aborted
transition simulation, couple the bounded run to the ideal exact-kernel run,
and charge any abort/mismatch to that failure budget. Do not claim that the
rounded or abort-conditioned transition kernel itself has exact stationarity.

The same primitive samples a uniform coordinate matching with an explicit
worst-case bound. At each recursive matching step the number q of candidate
partners is the deterministic sequence r-1,r-3,...,1. Use truncated
randbelow(q), with B_q=ceil(log2 q) bits per trial and m trials. Each step
aborts with probability below 2^(-m), while conditional on success its
partner is exactly uniform. Since the q sequence is independent of the
chosen partners, the no-abort probability is constant over final matchings;
conditional on no abort the full matching is exactly uniform. Taking
m=ceil(log2(r/(2 eta))) makes total abort probability at most eta. The
worst-case random-bit count is

  m * sum_(q=r-1,r-3,...,1) ceil(log2 q)
    = O(r log r log(r/eta)),

with polynomial integer-comparison cost. Thus the initial coordinate base can
be freshly sampled exactly on success; its only approximation is the
contaminant TV bound, and refresh abort is separately charged to the
algorithm's failure budget. This is an alternative to the cheaper modulo
sampler in INITIAL, which always returns but has a small explicit sampling
bias.

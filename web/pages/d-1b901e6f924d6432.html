## G1: source validation and fresh definitions

The source reader checks every actual line, schema operand, source reference,
constructor DAG and conclusion, including nonancestors of the last line.
The extra schema's endpoint and substitution domain must be exactly c(A,B)
and A,B. A Boolean index, future reference, unexpected rule or annotation is
not a valid source encoding. Canonical syntax has only topological children.
Public acceptance is disabled under Python optimization, preserving asserts
used in primitive verification.

Definitions have globally distinct names, fresh in every earlier actual
formula and schema operand and in their own body. Bodies use only earlier
definitions; the stated equivalence must match exactly. No defined atom may
occur in the rigid final formula. Expansion resolves every alias to its body
before classifying any guarded operand. Raw syntax validation and unchecked

Every expanded definition is `(F->F) AND(F->F)`. The actual replacement uses
seven old canonical steps: id(F); adj_u; fusion intro; two MP steps; the
fusion-to-additive schema; MP. Original references map to these real endpoints.

    L_e = L+6d,       m_e <= V+5d+1.

The node bound counts one image per supplied original node, five extra
constructors per replacement and one global unit, exactly as in cycle15.
Expansion of guard axioms uses the expanded operands and is admitted only
when their resulting actual syntax passes the same fixed table. Thus fresh

## G2: actual state acquisition

The four flags have exact endpoint meanings:

    tt: =>T,   tf: T=>bottom,   st: =>S,   sf: S=>bottom.

Atoms have sf; source 1/top have tt,sf; source 0/bottom have tf,st. These are
ordinary unit/top/bottom proof rows. For compound nodes, the exact table is
implemented in `flag_step`, and `StateCompiler` builds its required endpoints
from actual cached child rows using primitive sequent rules. It never adds a
named hypothesis or enriches the classifier with later semantic source proofs.

For illustration, x=>bottom proves =>x->y by cut against bottom elimination
and right implication. A closed =>x and y=>bottom prove (x->y)=>bottom by left
implication. Falsehood of one product factor uses weakening and left fusion.
Conjunction/disjunction use their precise left/right rules. Closed bang truths
are promoted with empty context; bang falsehood uses dereliction. These
constructions preserve every antecedent occurrence and promotion side condition.

Topologically process ordinary source nodes and acquire each of its at most
four state endpoints once. At a node the computed endpoints must match the
independently defined flag table and actual Chu components. This construction
is a structural induction: legal children imply legal parent proofs, so no
guard is an unproved assertion. The supplied finite local proof accounts for
at most 16 added occurrences/9 rows per constructor; one common bottom-false
row adds 2 occurrences. Therefore the entire cache costs at most `16m_e+2`.
No general C occurs in it. The new code's 105 fixed operator/state branch
checks all pass with the same maxima; that is implementation verification of
the supplied local lemma, not new research or another complete-proof fixture.

## G3: install the actual guarded macro

Put x=T_A,u=S_A,y=T_B,v=S_B, and define

    d=(x->y) AND(v->u),  k=x*v,
    e=(x->d) AND(k->u).

Literal Chu expansion of c(A,B) is

    T_c=(e->d) AND(k->(x*k)).

If tt(A) holds, the supplied actual cached row is =>x. Select x->d in e,
apply this closed theorem and discharge e. Independently right fusion of
=>x and k=>k proves k=>x*k. Discharge k and combine the two closed conjuncts.
This is at most 14 occurrences and uses no C. Reusing a closed theorem in a
proof DAG is legal proof sharing, not structural duplication of an assumption.

Otherwise sf(B) must hold and its supplied actual row is v=>bottom. Selecting
x->d and x->y gives e,x,x=>y. Exactly one general C produces e,x=>y; discharge
x. The null-v row yields v=>u by bottom elimination; weaken by e, discharge
v and combine to get e=>d. The same null row with x weakened and left fusion
gives k=>bottom, hence k=>x*k. Discharge k and combine the closed conjuncts.
This is at most 50 occurrences. No Pair obligation or free closed x theorem
is used in this branch. Its C deletes exactly one principal copy and retains
another, as required by the explicit target rule.

The program deterministically chooses tt first if both hold. It checks that
the witness endpoint precedes the installed macro, has exactly the required
sequent, and that the result equals the actual recursive T_c. Each actual
wire, row range, branch and ordinary-C count is serialized. Every old source
step likewise consumes only earlier real Pair or closed source endpoints.
The complete target checker permits no named initial sequents.

### Sound old-affine countermodel, including bang

Use [0,1] with product x*y=max(0,x+y-1), residual x->y=min(1,1-x+y), conjunction
min, disjunction max, truth/unit=1 and source falsehood/bottom=0. Interpret
!x as 1 when x=1 and 0 otherwise. This is an old-source sound model, not a
model of the target's general C. The basic adjunction

    x*y <= z iff x <= (y->z)

is immediate from the displayed formulas. Commutativity/associativity, unit
and integrality give the canonical identity, PF/permutation, fusion intro/
elimination and weakening inequalities. For example,
c*(c->a)*(a->b)<=b gives PF. Residual into a min is the min of the residuals;
residual from a max is likewise the min, giving the AND/OR implication schemata.
Product is below both factors, giving fusion-to-AND. The remaining projections,
injections and truth/bottom schemata are direct order facts. Negation is 1-x,
so DN is exact. Thus all bang-free old schemata have value 1 for arbitrary
assignments, not merely the retained four rational test values.

The bang truth projection is below its input and idempotent. If a<=b then
!a<=!b, hence !(a->b)<=(!a->!b): when its left side is 1, a<=b; when it is 0
the inequality is automatic. This proves !K; !T and !4 follow immediately.
Bang contraction has domain !a in {0,1}, whose duplication is idempotent;
bang weakening follows from general weakening. MP preserves truth 1,
adjunction with 1 preserves it and necessitation preserves it since !1=1.
Consequently the whole old canonical affine Frege system is sound, even if
its proof uses intermediate bangs. Fresh definitions are satisfied by assigning
each alias its body's value in chronological order, so they do not invalidate
this old-source control.

At p=q=1/4, r=1/2, s=0, the first par domain is 1/2. Each small contraction
conjunct has value 1/2, hence H=1/2 rather than 1. This exact rational evaluation
and the universal model argument prove that H is not an old affine theorem
(nor an old fresh-definitional affine-EF theorem). The new complete proof
therefore exercises a genuine proper strengthening. This does not classify
the guarded profile as an ordinary substitution-closed logic.

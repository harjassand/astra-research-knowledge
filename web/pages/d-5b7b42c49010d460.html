Abstract

As a foundation for optimization, convexity is useful beyond the classical settings of Euclidean and Hilbert space. The broader arena of nonpositively curved metric spaces, which includes manifolds like hyperbolic space, as well as metric trees and more general CAT(0) cubical complexes, supports primal tools like proximal operations for geodesically convex functions. However, the lack of linear structure in such spaces complicates dual constructions like subgradients. To address this hurdle, we introduce a new type of subgradient for functions on Hadamard spaces, based on Busemann functions. Our notion supports generalizations of classical stochastic and incremental subgradient methods, with guaranteed complexity bounds. We illustrate with subgradient algorithms for p-mean problems in general Hadamard spaces, in particular computing medians in BHV tree space.

A Proof of Proposition 2.2

Suppose first that \(\xi _n\rightarrow \xi \) in \(X^\infty \), which is to say \(b_{\xi _n}\rightarrow b_{\xi }\) uniformly on bounded subsets of X. Fix \(\delta > 0\) and let \(\varepsilon > 0\) be arbitrary. By assumption, there exists \(N \in \mathbb {N}\) such that

$$\begin{aligned} |b_{\xi _m}(r_n(\delta )) +\delta | = |b_{\xi _m}(r_n(\delta )) - b_{\xi _n}(r_n(\delta ))| < \frac{\varepsilon ^2}{2\delta } \text { for all } n,m \ge N. \end{aligned}$$

                    (27)

The inequality in [14, Lemma II.8.21(2)] asserts

$$\frac{d(r_n(\delta ),r_m(\delta ))^2}{2\delta } \le d(r_m(\delta +t),r_n(\delta )) - d(r_m(\delta +t),r_m(\delta )) \text { for all } t\ge 0.$$

Making the substitution \(s = \delta + t\), this simplifies to

$$\begin{aligned} \frac{d(r_n(\delta ),r_m(\delta ))^2}{2\delta } \le d(r_m(s),r_n(\delta )) - s + \delta \text { for all } s \ge \delta . \end{aligned}$$

Letting \(s\rightarrow \infty \) we conclude

$$\begin{aligned} \frac{d(r_n(\delta ),r_m(\delta ))^2}{2\delta } \le b_{\xi _m}(r_n(\delta )) + \delta . \end{aligned}$$

Now use (27) to bound the righthand side by \(\varepsilon ^2/(2\delta )\), which leads to

$$\begin{aligned} d(r_n(\delta ),r_m(\delta )) \le \varepsilon \text { for all } n,m \ge N. \end{aligned}$$

Since \(\varepsilon > 0\) was arbitrary, the sequence \(\left\{ r_n(\delta )\right\} _{n=1}^\infty \) is Cauchy and thus converges since X is complete. It remains to prove that its limit is \(r(\delta )\).

By [14, Proposition II.8.22], we know that \(r(\delta )\) is the unique minimizer of \(b_\xi \) on the sphere of radius \(\delta \) around \(\bar{x}\), denoted by \(S_\delta (\bar{x})\). Thus, \(\min _{z\in S_\delta (\bar{x})}b_\xi (z) = b_\xi (r(\delta )) = -\delta \). Likewise, it is easy to see from (27) that \(\lim _{n\rightarrow \infty }b_\xi (r_n(\delta )) = -\delta \). As the limit \(\bar{z} = \lim _{n\rightarrow \infty } r_n(\delta )\) is in \(S_\delta (\bar{x})\), we conclude that

$$\begin{aligned} -\delta = \min _{z\in S_\delta (\bar{x})}b_\xi (z) \le b_\xi (\bar{z}) = \lim _{n\rightarrow \infty }b_\xi (r_n(\delta )) = -\delta . \end{aligned}$$

Thus equality holds throughout, and \(b_\xi (\bar{z}) = -\delta \). The uniqueness of \(b_\xi \)’s minimizer on \(S_\delta (\bar{x})\) forces \(\bar{z} = \lim _{n\rightarrow \infty }r_n(\delta ) = r(\delta )\) as desired.

Conversely, let us suppose that \(r_n(\delta )\rightarrow r(\delta )\) for all \(\delta > 0\) and prove \(b_{\xi _n}\rightarrow b_\xi \) uniformly on bounded subsets. It suffices to prove \(b_{\xi _n}\rightarrow b_\xi \) uniformly on each ball \(B_\delta (\bar{x})\) for all \(\delta > 0\). Fix \(\delta > 0\) and let \(\varepsilon > 0\) be arbitrary. The inequality in [14, Lemma II.8.21(1)] asserts the existence of \(R > 0\) such that

$$\begin{aligned} 0\le d(z,r_n(R)) + t - d(r_n(R+t),z) \le \varepsilon \text { for all } z \in B_\delta (\bar{x}), t \ge 0, n\in \mathbb {N}. \end{aligned}$$

                    (28)

Let \(z\in B_\delta (\bar{x}), n,m \in \mathbb {N}\) and \(t\ge 0\). Applying first the triangle inequality and then (28), we deduce

$$\begin{aligned} d(z,r_n(R+t)) - d(z,r_m(R+t))&\le d(z,r_n(R)) + t - d(z,r_m(R+t))\\&= d(z,r_m(R)) + t - d(z,r_m(R+t))\\&~ ~ ~ + d(z,r_n(R)) - d(z,r_m(R))\\&\le \varepsilon + |d(z,r_n(R)) - d(z,r_m(R))|. \end{aligned}$$

After switching the roles of m and n above we finally get

$$\begin{aligned} |d(z,r_n(R+t)) - d(z,r_m(R+t))| \le \varepsilon + |d(z,r_n(R)) - d(z,r_m(R))|. \end{aligned}$$

                    (29)

Letting \(t\rightarrow \infty \) in (29), we deduce the following inequality for all \(z\in B_\delta (\bar{x})\):

$$\begin{aligned} |b_{\xi _n}(z) - b_{\xi _m}(z)| \le \varepsilon + |d(z,r_n(R)) - d(z,r_m(R))| \le \varepsilon + d(r_n(R),r_m(R)). \end{aligned}$$

Taking the supremum over \(z\in B_\delta (\bar{x})\), it follows that

$$\begin{aligned} \limsup _{n,m\rightarrow \infty }\sup _{z\in B_\delta (\bar{x})}|b_{\xi _n}(z)-b_{\xi _m}(z)|\le \varepsilon \text { for all } \varepsilon > 0. \end{aligned}$$

As a consequence, \(\lim _{n,m\rightarrow \infty } \sup _{z\in B_\delta (\bar{x})}|b_{\xi _n}(z)-b_{\xi _m}(z)| = 0\). That is to say \(\left\{ b_{\xi _n}\right\} _{n=1}^\infty \) satisfies the Cauchy criterion for uniform convergence on \(B_\delta (\bar{x})\) as desired.

B Proof of Lemma 2.4

Suppose first that \([\xi _n,s_n] \rightarrow [0]\). Then \([\xi _n,s_n]\) is eventually contained in any open neighborhood of [0]. Let \(q:X^\infty \times \mathbb {R}_+\rightarrow CX^\infty \) be the quotient map. For any \(\varepsilon > 0\) define the set \(W_\varepsilon = q(X^\infty \times [0,\varepsilon ))\). It is readily verified that \(q^{-1}(W_\varepsilon ) = X^\infty \times [0,\varepsilon )\), which is open in \(X^\infty \times \mathbb {R}_+\). Thus by the definition of the quotient topology on \(CX^\infty \), the set \(W_\varepsilon \) is open in \(CX^\infty \) and contains [0]. It follows that \([\xi _n,s_n]\) is eventually contained in \(W_\varepsilon \), which then implies \(s_n < \varepsilon \) eventually. Since \(\varepsilon > 0\) was arbitrary, \(s_n \rightarrow 0\).

For the converse implication when \(s = 0\) we assume X is proper, hence \(X^\infty \) is compact. Suppose \(s_n \rightarrow 0\) and fix any neighborhood U of [0]. Then for each \(\zeta \in X^\infty \) there exists an open set \(W_\zeta \subseteq X^\infty \) and \(\varepsilon _\zeta > 0\) such that \((\zeta ,0)\in W_\zeta \times [0,\varepsilon _\zeta ) \subseteq q^{-1}(U)\) because \(q^{-1}(U)\) is open in \(X^\infty \times \mathbb {R}_+\). The sets \(\left\{ W_\zeta \times [0,\varepsilon _\zeta )\right\} _{\zeta \in X^\infty }\) form an open cover of the compact set \(X^\infty \times \left\{ 0\right\} \), from which we select a finite subcover \(\left\{ W_{\zeta _i}\times [0,\varepsilon _{\zeta _i})\right\} _{i=1}^N\). Let \(V:= \bigcup _{i=1}^N W_{\zeta _i}\times [0,\varepsilon _{\zeta _i})\). To summarize, \(X^\infty \times \left\{ 0\right\} \subseteq V \subseteq q^{-1}(U)\). Since \(s_n\) is eventually smaller than \(\min _{i=1,\dots ,N}\varepsilon _{\zeta _i}\), we have \((\xi _n,s_n) \in V\) for all n sufficiently large. Then \([\xi _n,s_n]\in q(V) \subseteq q(q^{-1}(U)) = U\) for all n sufficiently large, which says \([\xi _n,s_n]\) converges to [0] since the open set U around [0] was arbitrary.

Now suppose \([\xi _n,s_n]\rightarrow [\xi ,s]\) with \(s > 0\). As before, \([\xi _n,s_n]\) is eventually contained in any open neighborhood of \([\xi ,s]\). For any \(\varepsilon > 0\) with \(s - \varepsilon > 0\), and any open set \(U \subseteq X^\infty \) containing \(\xi \), consider the set \(W_{U,\varepsilon } = q(U \times (s-\varepsilon , s+ \varepsilon ))\). As before it is easy to check that \(q^{-1}(W_{U,\varepsilon }) = U \times (s-\varepsilon , s+\varepsilon )\) which is open in \(X^\infty \times \mathbb {R}_+\), hence \(W_{U,\varepsilon }\) is open in \(CX^\infty \). It follows that \([\xi _n,s_n]\) is eventually contained in \(W_{U,\varepsilon }\), which implies \(\xi _n \in U\) eventually and \(s_n \in (s-\varepsilon ,s+\varepsilon )\) eventually. Since \(U,\varepsilon \) were arbitrary, we conclude \(\xi _n\rightarrow \xi \) and \(s_n \rightarrow s\). Conversely, suppose \(\xi _n \rightarrow \xi \) and \(s_n\rightarrow s > 0\). If U is an open neighborhood of \([\xi ,s]\) then \((\xi ,s) \in q^{-1}(U)\) so there exists an open set \(W \subseteq X^\infty \) and \(\varepsilon > 0\) such that \((\xi ,s) \in W \times (s-\varepsilon ,s+\varepsilon ) \subseteq q^{-1}(U)\). Then \(\xi _n \in W\) eventually, and \(s_n \in (s-\varepsilon ,s+\varepsilon )\) eventually, implying \([\xi _n,s_n] \in q(W\times (s-\varepsilon ,s+\varepsilon ))\subseteq q(q^{-1}(U)) = U\) for all n large.

Remark B.1

The converse implication in Lemma 2.4 can fail if X is not proper due to the lack of compactness for \(X^\infty \). Indeed, if X is an infinite-dimensional Hilbert space then \(X^\infty \) is homeomorphic to the unit sphere \(S\subseteq X\) with the norm topology. But passing to the quotient topology introduces undesirable open sets. Choose any continuous function \(f:S \rightarrow (0,+\infty )\) with infimal value 0 (the existence of such a function hinges on the noncompactness of S), and let \(\left\{ \xi _n\right\} _{n=1}^\infty \) be an infimizing sequence. The set \(V = \left\{ (\xi ,s) \in X^\infty \times \mathbb {R}_+ \mid s < f(\xi )\right\} \) is open in \(X^\infty \times \mathbb {R}_+\) because f is continuous. Moreover, \(X^\infty \times \left\{ 0\right\} \subseteq V\) and \(q^{-1}(q(V)) = V\). Thus q(V) is an open neighborhood of [0] in \(CX^\infty \), we have \(f(\xi _n) \rightarrow 0\), but \([\xi _n,f(\xi _n)] \notin q(V)\) for any \(n\in \mathbb {N}\) and so does not converge to [0].

C Proof of Example 3.2

We will show that if \(C\subseteq \mathbb {R}^n\) is convex and \(f:C \rightarrow \mathbb {R}\) is convex and locally Lipschitz on C then f has a (Euclidean) subgradient at each point in C. For any \(x\in C\), if f is locally Lipschitz one can find \(L, \delta > 0\) such that \(|f(y) - f(z)| \le L \Vert y-z\Vert \) for all \(y\in C \cap B_{\delta }(x) =: C'\). Define \(g:\mathbb {R}^n \rightarrow (-\infty ,+\infty ]\) as follows:

$$ g(y) = {\left\{ \begin{array}{ll} f(y), &  y\in C' \\ +\infty , &  \text {else}. \end{array}\right. }$$

Then set \(h(y) = \inf _{z\in \mathbb {R}^n} \left\{ g(z) + L\Vert y-z\Vert \right\} \). We claim that h is finite-valued, convex, and agrees with f on \(C'\). Clearly \(h(y) < +\infty \) for any y because \(C'\) is nonempty, while \(h(y) > -\infty \) because \(C'\) is bounded and

$$\begin{aligned} h(y) = \inf _{z\in C'} \left\{ f(z) + L\Vert y-z\Vert \right\} \ge f(x) + L\inf _{z\in C'}\left\{ \Vert y-z\Vert -\Vert z-x\Vert \right\} > -\infty . \end{aligned}$$

Thus h is finite-valued, and convexity of h follows by recognizing h as the infimal convolution of the convex function g with the finite-valued convex function \(L\Vert \cdot \Vert \). Given \(y\in C'\) we observe \(h(y) \le f(y)\) because y is feasible for the infimum defining h, while on the other hand the L-Lipschitz property for f on \(C'\) implies

$$\begin{aligned} f(z) + L\Vert y-z\Vert \ge f(y) \text { for all } z\in C'. \end{aligned}$$

Taking the infimum over \(z\in C'\) implies \(h(y) \ge f(y)\), hence \(h \equiv f\) on \(C'\).

Now, h is a real-valued convex function on \(\mathbb {R}^n\) and thus admits a subgradient v at x. We claim that v is a subgradient of f. The subgradient inequality for h reads

$$\begin{aligned} h(y)\ge h(x) + v^T(y-x) \text { for all } y\in \mathbb {R}^n. \end{aligned}$$

Restricting to points in \(C'\) where \(h \equiv f\) this shows \(\tilde{f}:= f-v^T(\cdot - x)\) is minimized over \(C'\) at x. By definition of \(C'\) it follows that x is a local minimizer of \(\tilde{f}\) on C, from which convexity of \(\tilde{f}\) implies x minimizes \(\tilde{f}\) on C. This says that v is a subgradient of f at x.

D Proof of Example 3.5

If \(f :\mathbb {R}^n \rightarrow \mathbb {R}\) is convex, then Fenchel biconjugation allows us to write it in the form \(f(x) = \sup \left\{ y^Tx - f^*(y) :y\in \mathbb {R}^n\right\} \) where \(f^* :\mathbb {R}^n \rightarrow \overline{\mathbb {R}}\) is the convex conjugate of f. The supremum is always attained by choosing any subgradient \(y \in \partial f(x)\), which is always nonempty since f is continuous. Furthermore, our earlier remarks show that we can identify \(C(\mathbb {R}^n)^\infty \) with \(\mathbb {R}^n\) itself via the bijection \(\varphi :C(\mathbb {R}^n)^\infty \rightarrow \mathbb {R}^n\), \(\varphi ([\xi ,s]) = -s\xi \) (viewing \(\xi \) as an element of \(\mathbb {S}^{n-1}\)). If we adopt the reference point \(\bar{x} = 0\) then our Busemann functions take the form \(b_\xi (z) = -\xi ^Tz\). Then we derive:

$$\begin{aligned} f(x)&= \max \left\{ y^Tx - f^*(y) :y\in \mathbb {R}^n\right\} \\&= \max \left\{ \varphi ([\xi ,s])^Tx - (f^*\circ \varphi )([\xi ,s]) :[\xi ,s] \in C(\mathbb {R}^n)^\infty \right\} \\&= \max \left\{ -s\xi ^Tx - (f^*\circ \varphi )([\xi ,s]) :[\xi ,s] \in C(\mathbb {R}^n)^\infty \right\} \\&= \max \left\{ \left\langle x,[\xi ,s]\right\rangle - (f^*\circ \varphi )([\xi ,s]) :[\xi ,s] \in C(\mathbb {R}^n)^\infty \right\} . \end{aligned}$$

Defining \(g:= f^* \circ \varphi \), we see that \(f = g^\circ \) and since the supremum is always attained f is a Busemann envelope. Thus we recover the class of real-valued convex functions on \(\mathbb {R}^n\). More generally, this argument works for continuous convex functions on a Hilbert space.

E Proof of Example 3.8

Let \(\tilde{r}(t) = r_{x,a}(d(x,a) + t)\) be a ray issuing from a in direction \(\xi _x\), so \(b_{a,\xi _x} = b_{\tilde{r}}\). Then

$$\begin{aligned} b_{a,\xi _x}(x) = b_{\tilde{r}}(x) = \lim _{t\rightarrow \infty }(d(x,r_{x,a}(d(x,a)+t)) - t) = d(x,a). \end{aligned}$$

                    (30)

Now write:

$$\begin{aligned} \sup \left\{ \left\langle x,[\xi ,s]\right\rangle - g([\xi ,s]) :[\xi ,s] \in CX^\infty \right\}&= \sup \left\{ \left\langle x,[\xi ,s]\right\rangle - g([\xi ,s]) :[\xi ,s] \in K\right\} \nonumber \\&= \sup \left\{ \left\langle x,[\xi _z,1]\right\rangle - b_{\xi _z}(a) :z\in X\setminus \left\{ a\right\} \right\} \nonumber \\&= \sup \left\{ b_{\xi _z}(x) - b_{\xi _z}(a) :z\in X\setminus \left\{ a\right\} \right\} . \end{aligned}$$

                    (31)

If \(x = a\) then this last expression is identically zero, so choose any \(z\in X\setminus \left\{ a\right\} \) and observe \([\xi _z,1]\in CX^\infty \) attains the supremum in (31). We have the upper bound \(b_{\xi _z}(x) - b_{\xi _z}(a) \le d(x,a)\) for all \(z\in X\setminus \left\{ a\right\} \) because Busemann functions are 1-Lipschitz. On the other hand, if \(x\ne a\) then choosing \(z = x\) we use Proposition 2.1 and (30) to conclude

$$\begin{aligned} b_{\xi _x}(x) - b_{\xi _x}(a) = b_{a,\xi _x}(x) = d(x,a). \end{aligned}$$

Thus the supremum in (31) is attained by \([\xi _x,1] \in CX^\infty \). It follows that for all \(x\in X\) the supremum in the first line above is always attained, allowing us to say

$$\begin{aligned} d(x,a) = \max \left\{ \left\langle x,[\xi ,s]\right\rangle - g([\xi ,s]) :[\xi ,s] \in CX^\infty \right\} \end{aligned}$$

is Busemann subdifferentiable by Proposition 3.4.

F Proof of Example 3.10

If \(x\in H_r\) then \({{\,\textrm{dist}\,}}(x,H_r) = 0 = \max \left\{ 0,b_r(x)\right\} \) so it remains to consider \(x\notin H_r\). We use the Lipschitz property of \(b_r\) and the definition of \(H_r\) to deduce

$$\begin{aligned} b_r(x) \le b_r(y) + d(x,y) \le d(x,y) \text { for all } y\in H_r. \end{aligned}$$

Taking the infimum over \(y\in H_r\) implies \(b_r(x) \le {{\,\textrm{dist}\,}}(x,H_r)\). On the other hand, for any \(t\ge 0\) one has \(B_t(r(t)) \subseteq H_r\) because \(s\mapsto d(x,r(s)) - s\) is nonincreasing. As a consequence, \({{\,\textrm{dist}\,}}(x,H_r) \le {{\,\textrm{dist}\,}}(x,B_t(r(t)))\). But since \(x\notin H_r\) we must have \(x\notin B_t(r(t))\) for any \(t\ge 0\), so \({{\,\textrm{dist}\,}}(x,B_t(r(t)) = d(x,r(t))- t\). To summarize,

$$\begin{aligned} {{\,\textrm{dist}\,}}(x,H_r)\le d(x,r(t)) - t \text { for all } t\ge 0. \end{aligned}$$

As \(t\rightarrow \infty \) we get \({{\,\textrm{dist}\,}}(x,H_r) \le b_r(x)\), proving \({{\,\textrm{dist}\,}}(x,H_r) = b_r(x)\) for \(x\notin H_r\).

G Proof of Proposition 3.5

The definition of the biconjugate implies \(f^{\bullet \circ } \le f\). Assuming f is Busemann subdifferentiable, choosing a Busemann subgradient \([\xi ,s]\) at a point \(x\in X\) implies via (14) that

$$\begin{aligned} f(x) = \left\langle x,[\xi ,s]\right\rangle - f^\bullet ([\xi ,s]) \le f^{\bullet \circ }(x). \end{aligned}$$

Thus \(f = f^{\bullet \circ }\). Suppose conversely that \(f = f^{\bullet \circ }\), f is continuous, and X is proper, so \(X^\infty \) is compact. Then one has

$$\begin{aligned} f(x) = \sup _{[\xi ,s]\in CX^\infty }{\left\langle x,[\xi ,s]\right\rangle - f^\bullet ([\xi ,s])}. \end{aligned}$$

The conjugate \(f^\bullet \) is lower semicontinuous as a supremum of continuous functions, so the function \(\phi _x([\xi ,s]) = \left\langle x,[\xi ,s]\right\rangle - f^\bullet ([\xi ,s])\) is upper semicontinuous. Choose a maximizing sequence \(\left\{ [\xi _n,s_n]\right\} _{n=1}^\infty \), meaning \(f(x) = \lim _{n\rightarrow \infty } \left\langle x,[\xi _n,s_n]\right\rangle - f^\bullet ([\xi _n,s_n])\). The sequence \(\left\{ \xi _n\right\} _{n=1}^\infty \) has a convergent subsequence because \(X^\infty \) is compact, so without loss of generality say \(\xi _n\rightarrow \xi \). If \(\left\{ s_n\right\} _{n=1}^\infty \) is unbounded then after extracting a subsequence we may assume \(s_n\rightarrow \infty \). Then for each \(R > 0\), letting \(\bar{x}\) be the underlying basepoint for all Busemann functions,

$$\begin{aligned} \frac{f^\bullet ([\xi _n,s_n])}{s_n}&\ge \sup _{y\in B_R(\bar{x})}\left\{ \left\langle y,[\xi _n,1]\right\rangle - \frac{f(y)}{s_n}\right\} \\&\ge \sup _{y\in B_R(\bar{x})} b_\xi (y) - \sup _{y\in B_R(\bar{x})}\frac{f(y)}{s_n}\\&= R - \frac{\sup _{y\in B_R(\bar{x})} f(y)}{s_n}. \end{aligned}$$

The supremum of f on \(B_R(\bar{x})\) is finite because f is continuous. Letting \(n\rightarrow \infty \) reveals

$$\begin{aligned} \liminf _{n\rightarrow \infty } \frac{f^\bullet ([\xi _n,s_n])}{s_n} \ge R. \end{aligned}$$

Since \(R > 0\) was arbitrary, \(\lim _{n\rightarrow \infty } \frac{f^\bullet ([\xi _n,s_n])}{s_n}\) \( = +\infty \). Then

$$f(x) = \lim _{n\rightarrow \infty } s_n\left( b_{\xi _n}(x) - \frac{f^\bullet ([\xi _n,s_n])}{s_n}\right) $$

$$ \le \lim _{n\rightarrow \infty } s_n \left( d(x,\bar{x}) - \frac{f^\bullet ([\xi _n,s_n])}{s_n}\right) = -\infty . $$

This contradicts the finite-valuedness of f, so \(\left\{ s_n\right\} _{n=1}^\infty \) is bounded. Extracting a further subsequence, we may assume \(s_n \rightarrow s\ge 0, \xi _n \rightarrow \xi \). Upper semicontinuity of \(\phi _x\) ensures

$$\begin{aligned} \left\langle x,[\xi ,s]\right\rangle - f^\bullet ([\xi ,s]) = \phi _x([\xi ,s]) \ge \limsup _{n\rightarrow \infty } \phi _x([\xi _n,s_n]) = f(x). \end{aligned}$$

Thus equality holds in the Fenchel-Young inequality (15), meaning \([\xi ,s]\) is a Busemann subgradient for f at x. Since x was arbitrary, we are done.

H Proof of Proposition 4.2

To prove the implication (ii) \(\Rightarrow \) (i), we suppose that f has a horospherically convex epigraph. Let \(x \in X\) and consider the point (x, f(x)) in the boundary of \({{\,\textrm{epi}\,}}f\). Since \({{\,\textrm{epi}\,}}f\) is horospherically convex, there exists a ray \(r:\mathbb {R}_+ \rightarrow X\times \mathbb {R}\) issuing from (x, f(x)) such that \({{\,\textrm{epi}\,}}f \subseteq b_r^{-1}((-\infty ,0])\). The point at infinity \(r(\infty )\) lies in \((X\times \mathbb {R})^\infty \), which is homeomorphic to the spherical join of \(X^\infty \) and \(\mathbb {R}^\infty \) (see [14, Example II.8.11(6)]), so we may assume \(b_r(z,t) = \alpha b_{r_1}(z) + \beta b_{r_2}(t)\) for rays \(r_1:\mathbb {R}_+\rightarrow X,r_2:\mathbb {R}_+ \rightarrow \mathbb {R}\) and scalars \(\alpha ,\beta \ge 0\) satisfying \(\alpha ^2+\beta ^2 =1\). Realizing that \(r_2\) must be of the form \(r_2(t) = f(x) \pm t\), we derive the following inequality for all \((y,s) \in {{\,\textrm{epi}\,}}f\):

$$\begin{aligned} 0 \ge b_r(y,s) = \alpha b_{r_1}(y) \pm \beta (f(x) - s). \end{aligned}$$

                    (32)

If \(\beta = 0\), then \(b_{r_1}(y) \le 0\) for all \(y\in X\). Since X has the geodesic extension property, we can extend \(r_1\) into a geodesic line \(r_1'\), and obtain a contradiction:

$$\begin{aligned} 0\ge b_{r_1}(r_1'(-1)) = 1. \end{aligned}$$

If the coefficient of \(\beta > 0\) is \(-1\), then taking \(y = x, s = f(x) + \lambda \) for \(\lambda > 0\) one eventually obtains a contradiction for \(\lambda \) sufficiently large. Thus the coefficient of \(\beta \) must be \(+1\). Finally, taking \(s = f(y)\) for each \(y\in X\) we observe directly from (32) that f has Busemann subgradient \([r_1(\infty ),\alpha /\beta ]\) at x. We have proved property (i).

Next, to prove the implication (iii) \(\Rightarrow \) (ii), suppose f is Busemann subdifferentiable and continuous. Let (x, t) lie in the boundary of \({{\,\textrm{epi}\,}}f\). By continuity of f, \(t = f(x)\). Busemann subdifferentiability of f at x yields a Busemann subgradient \([\xi ,s]\) such that

$$\begin{aligned} f(y) \ge f(x) + sb_{x,\xi }(y) \end{aligned}$$

for all \(y\in X\). Equivalently,

$$\begin{aligned} 0\ge f(x) - t + sb_{x,\xi }(y) \text { for all } (y,t) \in {{\,\textrm{epi}\,}}f . \end{aligned}$$

Normalizing by a factor of \((1+s^2)^{-1/2}\), this becomes

$$\begin{aligned} 0 \ge \frac{1}{\sqrt{1+s^2}}(f(x) - t) + \frac{s}{\sqrt{1+s^2}}b_{x,\xi }(y) \text { for all } (y,t) \in {{\,\textrm{epi}\,}}f . \end{aligned}$$

This is exactly the Busemann function for the ray

$$\begin{aligned} r(t) = \left( r_{x,\xi }\left( \frac{s}{\sqrt{1+s^2}}t\right) ,f(x) + \frac{1}{\sqrt{1+s^2}}t\right) , \end{aligned}$$

which supports \({{\,\textrm{epi}\,}}f\) at (x, f(x)) by the inequality above. This completes our proof of property (ii).

Now suppose that the space X is proper. We first show the implication (i) \(\Rightarrow \) (ii). By Proposition 3.5,

$$\begin{aligned} f(x) = f^{\bullet \circ }(x) = \sup _{[\xi ,s]\in CX^\infty }\left\{ \left\langle x,[\xi ,s]\right\rangle - f^\bullet ([\xi ,s])\right\} . \end{aligned}$$

Thus f is a supremum of nonnegatively scaled Busemann functions, whose epigraphs are easily seen to be horoballs in \(X\times \mathbb {R}\). The epigraph of f is therefore an intersection of horoballs, and such intersections are horospherically convex when X is proper: see [17, Theorem 10] for a proof in the manifold case which generalizes, nearly verbatim, to proper Hadamard spaces. This proves (ii).

Finally, assuming that the space X is proper, we prove the implication (i) \(\Rightarrow \) (iii). Any Busemann subdifferentiable function is automatically lower semicontinuous, so it suffices to prove that for each \(\bar{\alpha } \in \mathbb {R}\) the strict level set \(L = \left\{ x\in X\mid f(x) < \bar{\alpha }\right\} \) is open. Consider any point \(\bar{x}\in L\). Then \((\bar{x},\bar{\alpha }) \in {{\,\textrm{epi}\,}}f\), and if \((\bar{x},\bar{\alpha })\) lies in \({{\,\textrm{int}\,}}({{\,\textrm{epi}\,}}f)\) then there exists \(\varepsilon > 0\) such that \(f(x)\le \alpha \) whenever \(d(x,\bar{x})^2 + (\alpha - \bar{\alpha })^2 < \varepsilon ^2\). This ensures that if \(d(x,\bar{x}) < \varepsilon \) then \(f(x) < \bar{\alpha }\), so \(\bar{x}\) lies in the interior of L. On the other hand, if \((\bar{x},\bar{\alpha })\) is not in the interior of \({{\,\textrm{epi}\,}}f\) then it must lie on the boundary. Property (ii) implies the existence of a supporting horoball to \({{\,\textrm{epi}\,}}f\) at \((\bar{x},\bar{\alpha })\). As in the proof of (ii) \(\Rightarrow \) (i), we deduce the existence of a ray \(r:\mathbb {R}_+\rightarrow X\) issuing from \(\bar{x}\) and scalars \(\rho \ge 0, \sigma > 0\) such that \(\rho ^2 + \sigma ^2 = 1\) and

$$\begin{aligned} \rho b_r(y) + \sigma (\bar{\alpha } - s) \le 0 ~ \text { for all } (y,s) \in {{\,\textrm{epi}\,}}f. \end{aligned}$$

Noting \((\bar{x}, f(\bar{x}))\in {{\,\textrm{epi}\,}}f\) yields the contradiction \(\bar{\alpha } \le f(\bar{x})\), completing the proof.

I Proof of Example 4.2

Let \(\bar{x} = (0,0,0)\) be the reference point with respect to which we define our Busemann functions. Suppose for a contradiction that f has a Busemann subgradient \([\xi ,s]\) at \(x_0 = (1,1,0)\). As \(x_0\) is not a minimizer of f, we have \(s > 0\). Moreover,

$$\begin{aligned} f(y) - sb_\xi (y) \ge \frac{\sqrt{2}}{2} - sb_\xi (x_0) \text { for all } y\in X. \end{aligned}$$

                    (33)

Case 1: Suppose \(\xi \) is the direction of the ray \(\gamma \) issuing from \(\bar{x}\) and passing through \(x_0\). Taking \(y = (1/2,1/2,0)\) we have \(f(y) = 0, b_\xi (y) = -\sqrt{2}/2\), and \(b_\xi (x_0) = -\sqrt{2}\), in contradiction to (33).

Case 2: Suppose \(\xi \) is the direction of a ray r in the plane \(\left\{ z = 0\right\} \) issuing from \(\bar{x}\) and obtained by moving \(\gamma \) an angle \(\alpha \in (0,3\pi /4]\) in the trigonometric sense. Taking \(y = (3/2,1/2,0)\), we have \(f(y) = \sqrt{2}/2\) and \(d(\bar{x},y) = \sqrt{5}/\sqrt{2}\). Moreover, for all \(t > 0\),

$$ d(x_0,r(t))^2 = 2 + t^2 -2\sqrt{2}t\cos \alpha $$

and

$$\begin{aligned} d(y,r(t))^2 = \frac{5}{2} + t^2 -2t(\sqrt{2}\cos \alpha - (1/\sqrt{2})\sin \alpha ). \end{aligned}$$

Hence, \(b_\xi (x_0) = -\sqrt{2}\cos \alpha \) and \(b_\xi (y) = -\sqrt{2}\cos \alpha + (1/\sqrt{2})\sin \alpha \), in contradiction to (33).

Case 3: Suppose that \(\xi \) is the direction of a ray r in the quadrant \(\left\{ x\le 0, y = 0, z\ge 0\right\} \). Taking \(y=(3/2,1/2,0)\), we have \(f(y) = \sqrt{2}/2\) and \(b_\xi (x_0) \le \sqrt{2}\).

Fix \(t > 0\) and let \(v = (-s,0,0)\), where \(s\ge 0\), such that \(d(y,r(t)) = d(y,v) + d(v,r(t))\). Then \(s\le t\) and

$$\begin{aligned} d(y,r(t)) = d(v,r(t)) + \sqrt{\frac{5}{2}+s^2+3s} \ge t-s + \sqrt{\frac{5}{2}+s^2+3s} \ge \sqrt{\frac{5}{2}+t^2+3t}. \end{aligned}$$

Therefore \(b_\xi (y) \ge 3/2 > b_\xi (x_0)\), a contradiction. The remaining cases follow by symmetry.

J Proof of Example 4.3

Defining \(\tilde{x}= (2/5,0,0), \bar{x} = (1/4,1/4,0)\), we do some preliminary calculations:

$$\begin{aligned} f(\tilde{x}) = 37/25, ~ ~ ~ f(\bar{x}) = 13/8. \end{aligned}$$

                    (34)

Any ray issuing from \(\bar{x}\) is determined by a choice of unit vector \(v = (v_1,v_2,0)\), or equivalently an angle \(\theta \in [0,2\pi ]\) such that \(v = (\cos \theta ,\sin \theta ,0)\). By symmetry it suffices to consider \(\pi /4 \le \theta \le 5\pi /4\). We denote a ray r originating from \(\bar{x}\) in direction v by \(r_v\).

Case 1: Corresponding to the case \(\theta = 5\pi /4\), consider the direction \(v= (-1/\sqrt{2},-1/\sqrt{2},0)\), pointing from \(\bar{x}\) to the origin \(\textbf{0}:= (0,0,0)\). Since the ray ultimately extends up the spine \(\left\{ 0\right\} \times \left\{ 0\right\} \times \mathbb {R}_+\), for \(t > 0\) sufficiently large the geodesic between \(r_v(t)\) and any \(x\in \mathbb {R}_+\times \mathbb {R}_+ \times \left\{ 0\right\} \) consists of the two segments \([x,\textbf{0}] \cup [\textbf{0},r_v(t)]\). Hence

$$\begin{aligned} d(x,r_v(t)) = \Vert x\Vert + \Vert (t-\Vert \bar{x}\Vert )(0,0,1)\Vert = \Vert x\Vert + t- \Vert \bar{x}\Vert \text { for all } t \ge \Vert \bar{x}\Vert . \end{aligned}$$

The corresponding Busemann function at such an x is thus

$$\begin{aligned} b_{r_v}(x) = \Vert x\Vert - \Vert \bar{x}\Vert . \end{aligned}$$

Plugging in \(\tilde{x}\) we find \(b_{r_v}(\tilde{x}) = 2/5 - \sqrt{2}/4 = (8-5\sqrt{2})/20 > 0\). On the other hand, the preliminary calculations (34) show \(f(\tilde{x}) < f(\bar{x})\), so \(\tilde{x}\in f_{\bar{x}}\setminus \left\{ b_{r_v}\le 0\right\} \) i.e. this horoball does not contain the given level set.

Case 2: Now consider any direction v corresponding to \(\pi< \theta < 5\pi /4\). After sufficient time, the point \(r_v(t)\) will inhabit the upright quadrant \(\mathbb {R}_-\times \left\{ 0\right\} \times \mathbb {R}_+\). By imagining the quadrant \(\mathbb {R}_-\times \left\{ 0\right\} \times \mathbb {R}_+\) being folded down into \(\mathbb {R}_- \times \mathbb {R}_-\times \left\{ 0\right\} \), we see that for \(t > 0\) large enough the distance \(d(\textbf{0},r_v(t))\) is equal to the Euclidean distance \(\Vert \bar{x} + tv\Vert \) when we identify \(\bar{x},v\) with vectors in \(\mathbb {R}^3\). Since the geodesic from \(\tilde{x}\) to such an \(r_v(t)\) consists again of the two segments \([\tilde{x},\textbf{0}]\cup [\textbf{0},r_v(t)]\), it follows that

$$\begin{aligned} d(\tilde{x},r_v(t)) = \Vert \tilde{x}\Vert + \Vert \bar{x} + tv\Vert . \end{aligned}$$

The corresponding Busemann function evaluated at \(\tilde{x}\) is thus

$$\begin{aligned} b_{r_v}(\tilde{x}) = \Vert \tilde{x}\Vert + v^T\bar{x} \ge \Vert \tilde{x}\Vert - \Vert \bar{x}\Vert > 0. \end{aligned}$$

As in the previous case we conclude \(\tilde{x}\in f_{\bar{x}}\setminus \left\{ b_{r_v}\le 0\right\} \).

Case 3: Finally, consider directions v corresponding to \(\pi /4 \le \theta \le \pi \). Then we have \(d(\tilde{x}, r_v(t)) = \Vert \tilde{x} - \bar{x} - tv\Vert \), hence \(b_{r_v}(\tilde{x}) = v^T(\bar{x} - \tilde{x})\). Using \(v = (\cos \theta ,\sin \theta ,0)\) we find:

$$\begin{aligned} b_{r_v}(\tilde{x}) = -\frac{3}{20} \cos \theta + \frac{1}{4}\sin \theta . \end{aligned}$$

Using calculus, one can show that the righthand side is a concave function of \(\theta \) on \([\pi /4,\pi ]\) and so attains its minimum at an endpoint. It is easy to check that the values at these endpoints are both positive, so \(b_{r_v}(\tilde{x}) > 0\) for all such \(\theta \). As before, \(\tilde{x}\in f_{\bar{x}} \setminus \left\{ b_{r_v}\le 0\right\} \). We conclude that no ray issuing from \(\bar{x}\), which lies in the boundary of \(f_{\bar{x}}\), supports \(f_{\bar{x}}\), so \(f_{\bar{x}}\) is not horospherically convex.

Define the geodesic \(\eta :[0,1]\rightarrow X, \eta (t) = \bar{x} + (t/\sqrt{2})(1,1,0)\). We will show that \(([\eta ],3/\sqrt{2}) \in T_{\bar{x}} X\) is a subgradient for f at \(\bar{x}\). According to (17) and the value computed for \(f(\bar{x})\) in (34), it suffices to prove

$$\begin{aligned} \frac{3}{\sqrt{2}}d(\bar{x},y)\cos \angle (\eta ,\gamma _y) + \frac{13}{8} \le f(y) \text { for all } y\in X. \end{aligned}$$

                    (35)

Despite the initial requirement that this inequality holds for all \(y\in X\), it is shown in [30, Remark 3.3(iv)] that the subdifferential of a geodesically convex function depends only on the function locally. Thus it suffices to verify (35) on a small ball around \(\bar{x}\) contained in the quadrant \(Q = \mathbb {R}_+\times \mathbb {R}_+\times \left\{ 0\right\} \), say \(B_{1/5}(\bar{x})\). For \(y = (y_1,y_2,0) \in Q\) we have

$$\begin{aligned} f(y) = \frac{1}{2}\left( (y_1+1)^2+y_2^2 + y_1^2 + (y_2+1)^2 \right) . \end{aligned}$$

                    (36)

Furthermore, for \(y \in B_{1/5}(\bar{x})\) the geodesic segment \([\bar{x},y]\) is the Euclidean line segment joining these points in Q. It follows that \(d(\bar{x},y) = \Vert y-\bar{x}\Vert \) and

$$\begin{aligned} \cos \angle (\eta ,\gamma _y) = \frac{(1,1,0)^T(y-\bar{x})}{\sqrt{2}\Vert y-\bar{x}\Vert } = \frac{y_1+y_2 -1/2}{\sqrt{2}\Vert y-\bar{x}\Vert }. \end{aligned}$$

                    (37)

Thus after restricting to \(y\in B_{1/5}(\bar{x})\) and substituting (36) and (37) into (35), our desired inequality becomes

$$\begin{aligned} \frac{3}{2}y_1 + \frac{3}{2}y_2 + \frac{7}{8} \le \frac{1}{2}\left( (y_1+1)^2+y_2^2 + y_1^2 + (y_2+1)^2 \right) \end{aligned}$$

$$\begin{aligned} \text { for all } y = (y_1,y_2,0) \in B_{1/5}(\bar{x}). \end{aligned}$$

This now holds by the Euclidean subgradient inequality for the differentiable convex function \(h(a,b) = \frac{1}{2}\left( (a+1)^2+b^2 + a^2 + (b+1)^2 \right) \) at the point (1/4, 1/4).

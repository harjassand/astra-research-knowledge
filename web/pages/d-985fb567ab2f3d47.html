This is a lecture-note exposition, not an additional research result. It was directly inspected in web lines 4168–4196.

## Komlós subsequence input

3. János Komlós, “A generalization of a problem of Steinhaus,” *Acta Mathematica Academiae Scientiarum Hungaricae* 18(1–2), 217–229 (1967), [version-of-record DOI](https://doi.org/10.1007/BF02020976), [open Rutgers repository record/PDF](https://scholarship.libraries.rutgers.edu/esploro/outputs/journalArticle/A-generalization-of-a-problem-of/991031549979804646). Theorem 1a, pp. 217–218 in the paper (local extracted file begins with repository cover pages): from a sequence of random variables with uniformly bounded first absolute moments, a subsequence exists whose averages, and averages of any further subsequence, converge almost surely to an integrable random variable. Local version-of-record PDF SHA-256: `5b4af7cbc9b8c57e5f6b22dc8049267645b1701b2867069ad429dd769e47c2e4`.

The proof uses Komlós only on a **finite measure** disjoint union. For arbitrary ambient σ-finite support, the finite equivalent measure ν is constructed in DERIVATION_CYCLE2.md. No unverified generalization of Komlós beyond finite measure is needed.

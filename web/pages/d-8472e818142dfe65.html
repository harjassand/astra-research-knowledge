## B. A proof-level obstruction: N129's torsion-free hyperbolic target is impossible

Let `G` be torsion-free, `F` any field. If `a,b` in `F[G]` have `ab=1` and `ba != 1`, then `e=1-ba` is an idempotent strictly between `0` and `1`: `e^2=1-2ba+b(ab)a=1-ba`. If `e=1` then `ba=0`, hence `a=aba=0`, absurd. If `e=0` then `ba=1`, excluded.

For a torsion-free word-hyperbolic `G`, Formanek's theorem as explicitly recorded on page 9 of Bartels–Lück–Reich forbids every such proper idempotent over fields of *all* characteristics. Therefore no torsion-free word-hyperbolic group admits an F2-group-ring counterexample to direct finiteness. **The hyperbolic conclusion of N129 must be withdrawn, not just flagged as an unresolved proof gap.** This does not decide groups with torsion or possible errors in the separate torsion-free (not hyperbolic) OpenAI manuscript.

**Required characteristic-p geometry (a corollary of Formanek, not claimed original):** If `G` is torsion-free and `F_p[G]` has a proper idempotent/non-directfinite, then there exist `1!=g in G`, `t in G`, `k>=1` with `tgt^-1=g^(p^k)` (up to conjugator orientation). Thus `G` contains a subgroup isomorphic to `BS(1,p^k)`. To show injectivity of the homomorphism `BS(1,m)=Z[1/m] ⋊ Z -> G`, note the additive base is the increasing union of conjugates `t^-r <g> t^r`; every nonzero base element maps to a nontrivial conjugate of `g^n`, since `g` has infinite order. If a kernel element has nonzero `Z`-exponent `n`, normality/commutator with the base and the relation imply `g^(m^n-1)=1` (after clearing denominators), impossible for infinite-order `g`. Hence the whole map is injective. In particular, conditional on family197's torsion-free main theorem, its group contains `BS(1,2^k)` for some `k>=1`; identifying explicit words or `k` remains open. The group cannot be torsion-free hyperbolic, and no routine small-cancellation hyperbolic upgrade is possible.

## C. Exact finite counterexample to all-time singleton PPT

```
  d rho/ds = (nu+1) D[J_-](rho) + nu D[J_+](rho),
  rho(0)=I/8,   D[L](rho)=L rho L^dagger - {L^dagger L,rho}/2.
```

```
 rho(s)|_k = [p_3(k;s)/2] P^+_k
             + [p_1(k-1;s)/4] P^-_k  (second term only for k=1,2).
```

Take computational basis indices `0,...,7`, first qubit as highest bit. The integer vector `v=(0,1,1,0,0,0,0,14)` satisfies exactly

```
    = 4 p_3(1;s) + 56 p_3(2;s) + 588 p_3(3;s)
```

## D. Sharp rare-sector relaxation theorem (self-contained mathematical derivation)

**Theorem D1.** Fix any finite `nu>0` and `s>0`. For ideal `N`-qubit dynamics above with maximally mixed initial state and its selected sector-preserving stationary state `rho_N(∞)`, define `D_N(s)=(1/2)||rho_N(s)-rho_N(∞)||_1`. Write `r=N mod 2`. Then, as `N->infinity` through parity `r`,

```
 lim N^(3/2) D_N(s)
    = 2 sqrt(2/pi) * sum_(M>=1, M==r mod2) (M+1)^2 d_M(s)
    =: C_(r,nu,s) in (0,infinity),
```

where `d_M(s)= (1/2)||exp(s Q_M)u_M - pi_M||_1`, `u_M` uniform, `pi_M(k)=q^k/(sum_(i=0)^M q^i)`, `q=nu/(nu+1)`, and `Q_M` is tridiagonal birth-death generator with `k->k+1` rate `lambda_k=nu(M-k)(k+1)` and `k->k-1` rate `mu_k=(nu+1)k(M-k+1)`. Consequently `D_N(s)=Theta_(nu,s,r)(N^(-3/2))` for both parity subsequences.

**Proof.** The Schur-Weyl decomposition has spin `j=M/2`, multiplicity `m_(N,M)=binom(N,(N-M)/2)-binom(N,(N-M)/2-1)` and total sector weight

```
 w_(N,M) = ((M+1)^2/(N/2+M/2+1)) * binom(N,(N-M)/2)/2^N.
```

Under the initial maximally mixed state, each spin sector starts with `u_M`, multiplicities remain maximally mixed, and the blocks have orthogonal supports; hence **exactly** `D_N(s)=sum_M w_(N,M)d_M(s)`.

To bound `d_M(s)` for large `M`, let `tau_0` be the first hitting time of level `0`. Standard skip-free birth-death recurrences yield for starting level `x`:

```
 E_x tau_0 = sum_(k=1)^x [sum_(i=k)^M pi_i]/[mu_k pi_k]
           = sum_(k=1)^x (1-q^(M-k+1))/[k(M-k+1)]
           <= 2 H_M/(M+1) =: A_M.
```

In particular the expectation is bounded uniformly in starting `x`. By Markov at `2A_M` and successive strong-Markov restarts, for all `s>0`,

```
  sup_x Pr_x(tau_0>s/2)
    <= 2 exp[-(ln2)*s*(M+1)/(8H_M)].
```

For mixing after the first visit to `0`, compare the sector Dirichlet form to a reversible reflecting birth-death chain with constant up-rate `nu*M` and down-rate `(nu+1)*M`, preserving the same geometric stationary distribution. Every actual edge rate is at least the comparison edge rate since `(k+1)(M-k)>=M`. The comparison chain's spectral gap is at least `c_nu*M`, `c_nu=(sqrt(nu+1)-sqrt(nu))²>0`. The initial chi-square divergence of `delta_0` from `pi_M` is at most `nu` because `1/pi_M(0)-1<=nu`. Therefore after `s/2` from state `0`, the TV distance is at most `(sqrt(nu)/2) exp(-c_nu*M*s/2)`. Using the Markov property at `tau_0` and contraction thereafter gives

```
 d_M(s) <= 2 exp[-(ln2)*s*(M+1)/(8H_M)]
            + (sqrt(nu)/2) exp[-c_nu*M*s/2].          (BOUND)
```

This is summable with any fixed polynomial weight in `M` at every fixed `s>0`, because `H_M~ln M`. Stirling/local central binomial give for each fixed admissible `M`,

```
  N^(3/2) w_(N,M) -> 2 sqrt(2/pi)*(M+1)^2.
```

Uniformly in admissible `M<=N`, the elementary `central_binomial <= C 2^N/sqrt(N)` gives `N^(3/2)w_(N,M)<=C'(M+1)^2`. The BOUND and dominated convergence establish the formula. The constant is positive: for every `M>=1`, `u_M!=pi_M` when `nu` is finite and the invertible finite-dimensional matrix `exp(sQ_M)` cannot map the initial nonstationary vector exactly to `pi_M` at finite `s`. Both parity families contain such a block. QED.

**Corollary D2 (optimal order of trace-distance thermalization).** For every fixed `nu>0`, `eps in (0,1)`, the mixing time of this *particular maximally mixed input*, not a worst-case quantum-state mixing time,

```
 T_(N,eps)=inf{s : D_N(s)<=eps}
             = Theta_(nu,eps)(log N/sqrt N).
```

*Upper bound:* the total Schur weight of `M<a sqrt N` is `O(a^3)` by the explicit weight formula. On `M>=a sqrt N`, insert `s=C log N/sqrt N` into BOUND; the first term is <=`2 exp(-Omega(a C))`, the second tends to zero. Choose `a` small enough for residual <eps/2, then `C` large enough for remainder <eps/2.

*Lower bound:* under Schur weights, `M/sqrt N` converges to Maxwell density `f(x)=sqrt(2/pi)*x² exp(-x²/2)` on `(0,infty)`. Choose a compact band `[a,b]` of mass as near 1 as desired. Conditioned on any `M` in this band, all except an arbitrarily small fraction of the uniform initial levels have `k(0)>=delta M`. Couple the original level process from below by a *pure-death* process whose per-particle death rate is `(nu+1)M`: original downward rate is <=`(nu+1)Mk` and upward transitions only increase the level. This pure death has `Binomial(k(0),exp(-(nu+1)Ms))` survivors. At time `s=c log N/sqrt N` with fixed `c<1/[2(nu+1)b]`, its expected survivors from those initial levels diverges as a positive power of `N`; with high probability the actual level exceeds any fixed `K`. In contrast the geometric stationary law places mass `1-q^(K+1)+o(1)` on levels `0,...,K`. Taking a small initial-level excluded fraction, large fixed `K`, and a band of weight near 1, one obtains `D_N(s)>eps` for every fixed eps<1 and suitably small c. The stronger consequences are `D_N(s_N)->1` if `s_N=o(log N/sqrt N)`, and `D_N(s_N)->0` if `s_N >> log N/sqrt N`. The constants for ε-thresholds are not shown to coincide; **no classical cutoff in the technical mixing-time sense is asserted**. QED.

*Physical rate scaling:* if the Lindblad operators are conventionally divided by `sqrt N` while Γ remains fixed, all dimensionless times gain a factor `N`; the input-specific physical mixing scale becomes `Theta(sqrt N log N)/Gamma`, not `Theta(log N/sqrt N)/Gamma`. Also no exact finite-time PPT follows from a polynomial trace-distance error because minimum PT eigenvalues can shrink exponentially with N.

## E. Explicit Maxwell crossover at zero bath temperature

**Theorem E1.** Extend only the **relaxation** calculation to zero temperature `nu=0` (not the N130 stationary singleton-PPT claims). For every fixed `c>0`, set `s_N=c logN/sqrt N`. Then

```
 lim_(N->infinity) D_N(s_N)
   = F_Maxwell(1/(2c))
   = erf(1/(2 sqrt(2)c)) - sqrt(2/pi)*(1/(2c))*exp(-1/(8c²)).
```

This limit holds along both parity sequences. It is a **nontrivial, continuous mixing profile**, not a Heaviside cutoff. Proof: at `nu=0`, each sector is a pure-death chain with rates `r_k=k(M-k+1)` and absorbing state 0, so `d_M(s)=Pr_(uniform initial level)(tau_0>s)` exactly. For initial level `x`, `tau_0` is the sum of independent exponential holding times `E_k~Exp(r_k)` for `1<=k<=x`. Thus

```
 E_x tau_0 = (H_x+H_M-H_(M-x))/(M+1),
 Var_x(tau_0) = sum_(k=1)^x 1/[k²(M-k+1)²].
```

Uniformly for `x/M` in any compact subinterval of `(0,1)`, the mean is `(log M+O(1))/M` and variance `O(M^-2)`. Chebyshev shows `M tau_0/log M->1` in probability for a uniform initial level (boundary fractions made arbitrarily small). Therefore `d_M(alpha logM/M)->1` if `alpha<1` and `->0` if `alpha>1`. If `M/sqrt N->x>0`, `M*s_N/log M->2cx`, so the sector TV tends to `1_(x<1/(2c))`. Schur weights converge weakly to Maxwell density `sqrt(2/pi) x² exp(-x²/2)`. Dominated convergence for triangular arrays and continuity of Maxwell measure yield the stated CDF. QED.

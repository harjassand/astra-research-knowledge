# CTMC path information and identifiability: derivations

Date: 2026-10-08

## Interface and resource ledger

There are two simple hypotheses, $h\in\{0,1\}$. Under hypothesis $h$, a non-explosive, time-homogeneous CTMC $X_t$ has finite hidden state space $S=\{1,\dots,N\}$, generator $Q_h=(q^h_{ij})$, exit rates $\lambda^h_i=\sum_{j\ne i}q^h_{ij}$, and initial law $\mu_h$. The observed record is either the full state path $X_{[0,T]}$, a deterministic readout $Y_{[0,T]}=F(X_{[0,T]})$, or a common hypothesis-independent stochastic readout channel applied to that path. A test may use the record and its own randomness, but receives no extra data.

The experiment is charged by horizon $T$, hidden state count $N$, output alphabet size $m$, and record resolution. A discrete sample of $n$ visible states costs at most $n\lceil\log_2 m\rceil$ label bits; an exact continuous path has $J_T$ jumps and $J_T$ real-valued times, so timestamp precision must be specified before claiming a finite bit cost. A full generator has at most $N(N-1)$ free off-diagonal rates. The inequalities below use ideal path access, which upper-bounds the information in finite-resolution, sampled, compressed, or hidden-state records. State count and time are reported as a resource pair $(N,T)$; adding them into one scalar requires an explicit hardware price per state and time unit.

## Theorem 1: finite-time discrimination ceiling

Assume the two path laws have common support (on each directed edge either both hypotheses give positive rate or both give zero rate) and $\mu_0\ll\mu_1$. Write $\mu_0(t,i)=\Pr_0(X_t=i)$. Then

\[
D_T^{\rm full}:=D(P_0^{X_{[0,T]}}\Vert P_1^{X_{[0,T]}})
=D(\mu_0\Vert\mu_1)+\int_0^T\sum_i\mu_0(t,i)
\sum_{j\ne i}\left[q^0_{ij}\log\frac{q^0_{ij}}{q^1_{ij}}-q^0_{ij}+q^1_{ij}\right]dt.
\]

For any common readout channel $K(dy\mid x_{[0,T]})$, data processing gives
\[
D(P_0^Y\Vert P_1^Y)\le D_T^{\rm full}.
\]
Every equal-prior binary decision rule based on $Y$ therefore has average error
\[
P_e(Y)\ge \frac14\exp(-D_T^{\rm full}).
\]

If each model starts in its stationary law and the generators have common support, put
\[
d_0=\sum_i\pi_0(i)\sum_{j\ne i}\left[q^0_{ij}\log(q^0_{ij}/q^1_{ij})-q^0_{ij}+q^1_{ij}\right].
\]
Then $D_T^{\rm full}=D(\pi_0\Vert\pi_1)+Td_0$. To achieve equal-prior error at most $\varepsilon<1/4$, it is necessary that
\[
T\ge \frac{\log(1/(4\varepsilon))-D(\pi_0\Vert\pi_1)}{d_0}
\]
when the numerator is positive and $d_0>0$. If $d_0=0$, time adds no full-path KL in this stationary setup; if initial divergence is insufficient, the target error is impossible for every $T$. Hiding states can make the actual requirement strictly larger.

### Proof

For a path starting at $x_0$, with jumps $x_{r-1}\to x_r$ at times $t_r$, the density relative to the common jump-time/state reference measure is
\[
\mu_h(x_0)\prod_{r=1}^{J_T}q^h_{x_{r-1}x_r}
\exp\left(-\int_0^T\lambda^h_{X_t}\,dt\right).
\]
Its log likelihood ratio is
\[
\log\frac{\mu_0(X_0)}{\mu_1(X_0)}+
\sum_{r=1}^{J_T}\log\frac{q^0_{X_{t_r-},X_{t_r}}}{q^1_{X_{t_r-},X_{t_r}}}
-\int_0^T(\lambda^0_{X_t}-\lambda^1_{X_t})dt.
\]
Under hypothesis 0, the expected number of $i\to j$ jumps in $dt$ is $\mu_0(t,i)q^0_{ij}dt$. Taking expectation yields the displayed KL identity. Deterministic readout is a measurable map, so KL data processing gives the readout inequality; a common stochastic channel obeys the same inequality by the KL chain rule.

For the decision bound, let $A=\int\sqrt{p_0p_1}$ be Hellinger affinity for the two record laws. Jensen gives
\[
A=E_0\exp[-\tfrac12\log(p_0/p_1)]\ge e^{-D(P_0\Vert P_1)/2}.
\]
The total-variation bound $\mathrm{TV}^2\le 1-A^2$ implies
\[
P_e^*=\tfrac12(1-\mathrm{TV})\ge\tfrac12(1-\sqrt{1-e^{-D}})\ge\tfrac14e^{-D}.
\]
Every particular equal-prior test has risk at least the optimal Bayes risk $P_e^*$. Apply this to $Y$, then use $D(P_0^Y\Vert P_1^Y)\le D_T^{\rm full}$. The stationary formula follows because $\mu_0(t,\cdot)=\pi_0$.

## Rate cap and explicit state-count accounting

Suppose every exit rate under either hypothesis is at most $\Lambda$, and every shared positive edge obeys $|\log(q^0_{ij}/q^1_{ij})|\le L$. Each row divergence satisfies
\[
\sum_{j\ne i}\left[q^0_{ij}\log(q^0_{ij}/q^1_{ij})-q^0_{ij}+q^1_{ij}\right]
\le \lambda^0_iL+\lambda^1_i\le\Lambda(1+L).
\]
Consequently,
\[
D_T^{\rm full}\le D(\mu_0\Vert\mu_1)+T\Lambda(1+L),
\]
uniformly in $N$. Under a per-edge bound $q^h_{ij}\le r$, the corresponding ceiling is $T(N-1)r(1+L)$. These are information-capacity bounds, not guarantees that the visible output attains the rate. A bound on $N$ alone is insufficient: rate ratios can diverge, and support differences can make KL infinite. Finite precision on rate specification and path timestamps is a further acquisition/recording cost.

## Chernoff path coefficient

Under common positive edge support, define a Metzler matrix $K_s$ for $s\in[0,1]$ by
\[
(K_s)_{ij}=(q^0_{ij})^s(q^1_{ij})^{1-s}\quad(i\ne j),\qquad
(K_s)_{ii}=-s\lambda^0_i-(1-s)\lambda^1_i,
\]
with off-diagonal entry zero when both rates are zero. Let $a_s(i)=\mu_0(i)^s\mu_1(i)^{1-s}$. Direct summation of powered path densities gives the exact full-path Hellinger/Chernoff coefficient
\[
H_s(T)=\int (dP_0^X)^s(dP_1^X)^{1-s}=a_s e^{TK_s}{\bf1}.
\]
Since $\min(p_0,p_1)\le p_0^sp_1^{1-s}$, the likelihood-ratio test has
\[
P_e^*\le \tfrac12\inf_{0\le s\le1}H_s(T).
\]
If the common transition support is irreducible and initial masses are positive, Perron–Frobenius gives the affinity's exponential rate from the spectral bound $\gamma(s)$ of $K_s$: $H_s(T)=\exp(T\gamma(s)+o(T))$. Set $C_{\rm aff}=-\min_s\gamma(s)$. This is an exact affinity exponent and gives a Chernoff upper bound on error. Equality with the optimal error exponent is a separate asymptotic testing theorem; this note does not use it as a premise. Rényi-divergence data processing implies that a hidden readout has no larger Chernoff information than the full path.

## Theorem 2: local parameter information contracts under hidden readout

Let $Q_\theta$ be a differentiable, common-support finite-state generator family; assume a parameter-independent initial law and regularity to differentiate the path likelihood. The full-path score is
\[
S_a=\sum_{r=1}^{J_T}\partial_a\log q_{X_{t_r-},X_{t_r}}(\theta)
-\int_0^T\partial_a\lambda_{X_t}(\theta)dt.
\]
Its Fisher information is
\[
I^{\rm full}_{ab}(T)=\int_0^T\sum_i\mu_\theta(t,i)\sum_{j\ne i}
\frac{\partial_aq_{ij}(\theta)\partial_bq_{ij}(\theta)}{q_{ij}(\theta)}dt.
\]
Under stationarity, the per-time information is
\[
\mathcal I_{ab}(\theta)=\sum_i\pi_\theta(i)\sum_{j\ne i}
\frac{\partial_aq_{ij}(\theta)\partial_bq_{ij}(\theta)}{q_{ij}(\theta)}.
\]
For observation $Y=F(X)$, the observed score is $E[S\mid Y]$, so
\[
I^Y(T)=\operatorname{Cov}(E[S\mid Y])\preceq\operatorname{Cov}(S)=I^{\rm full}(T).
\]
Thus no estimator from the hidden record can exceed full-path Fisher information. For a regular unbiased estimator and nonsingular information, $\operatorname{Cov}(\hat\theta)\succeq I(T)^{-1}$; singular directions of $I^Y$ preclude regular first-order estimation. The Fisher bound is local and does not by itself establish global identifiability.

The formula follows by differentiating the path log-likelihood. The score is a compensated jump martingale; its predictable quadratic covariation is the integrated jump intensity times score increments squared. The conditional expectation of the full score is the score of the marginal observation law, and the covariance contraction is the law of total covariance.

## Counterexample A: hidden within-block rates are exactly unidentified

Take states $1,2\mapsto A$ and $3,4\mapsto B$, and set rates
\[
1\to2:u,\quad1\to3:\alpha;\qquad 2\to1:u,\quad2\to4:\alpha;
\]
\[
3\to4:v,\quad3\to1:\beta;\qquad 4\to3:v,\quad4\to2:\beta,
\]
with diagonal entries the negative row sums. The visible output changes $A\to B$ at rate $\alpha$ from either hidden $A$ state, and $B\to A$ at rate $\beta$ from either hidden $B$ state. Hence $Y_t=g(X_t)$ is exactly a two-state CTMC with rates $\alpha,\beta$, for every $u,v>0$ and every initial distribution with the same visible initial law. Its entire path law is independent of $u,v$, for all horizons. Changing $u,v$ changes the full hidden path law but gives visible KL exactly zero. No estimator or classifier on the visible path can recover these rates, even with infinite observation time. This is strong lumpability and shows why positive hidden-path KL is only an optimistic ceiling, not an achievability result for the output.

## Counterexample B: fixed-interval sampling aliases distinct generators

On a three-state directed ring, let
\[
Q(a,b)=\begin{pmatrix}-(a+b)&a&b\\b&-(a+b)&a\\a&b&-(a+b)\end{pmatrix}.
\]
With $S=a+b$ and $\delta=a-b$, its eigenvalues are $0$ and $-3S/2\pm i\sqrt3\delta/2$. At sample interval $\Delta=1$, choose $(S,\delta)=(10,1)$ and $(S',\delta')=(10,1+4\pi/\sqrt3)$. Both rate pairs are positive:
\[
(a,b)=(11/2,9/2),\qquad
(a',b')=\left(\frac{11+4\pi/\sqrt3}{2},\frac{9-4\pi/\sqrt3}{2}\right).
\]
The nonzero eigenvalues differ by $\pm2\pi i$, with the same Fourier eigenvectors, so
\[
e^{Q(a,b)}=e^{Q(a',b')}
\]
exactly. Even the fully visible sampled chain $(X_0,X_1,X_2,\ldots)$ has identical law under these distinct generators, from the same initial distribution. The continuous jump path distinguishes them. A second incommensurate lag, or observation of jump times, breaks this particular alias. This is non-uniqueness of the generator logarithm, not finite-sample estimation error.

## Discrete sampling formula and same-record baselines

If only $X_{k\Delta}$ is recorded, set $P_h(\Delta)=e^{\Delta Q_h}$. The exact sampled-path divergence is
\[
D(P_0^{X_0,\ldots,X_n}\Vert P_1^{X_0,\ldots,X_n})
=D(\mu_0\Vert\mu_1)+\sum_{k=0}^{n-1}\sum_i\mu_0(k\Delta,i)
D\!\left(P_0(\Delta)_{i\cdot}\Vert P_1(\Delta)_{i\cdot}\right).
\]
Under stationarity this grows at rate $\Delta^{-1}\sum_i\pi_0(i)D(P_0(\Delta)_{i\cdot}\Vert P_1(\Delta)_{i\cdot})$, at most the continuous-path rate by data processing.

Given exactly the same record, the raw likelihood-ratio test is the optimal equal-prior simple-hypothesis test (Neyman–Pearson). Any statistic, embedding, classifier, hidden-state posterior, or learned summary is a postprocessing of that record and cannot improve its information-theoretic risk. A summary can match the full-record optimum only if it is sufficient for the likelihood ratio. Runtime can differ, but additional training records, calibrated parameters, or model-selection data are additional information and must be separately charged.

## Decisive controlled discriminator

Use Counterexample A with fixed visible $(\alpha,\beta)$ and several $(u,v)$. Start all trials with the same visible initial law, randomize hidden starts within a block, and record only $A/B$. The prediction is identical visible path distributions and chance-level expected discrimination for every $T$; full-state logging should distinguish the generators. Then vary $\alpha$ across hypotheses and compare raw visible-path likelihood ratio against compressed or filtered methods at identical $N=4,m=2,T$, timestamp resolution, and number of independent trajectories. On the three-state ring, compare sampling every $\Delta=1$ against adding $\Delta=\sqrt2$ or recording jumps. This separates generator aliasing from finite-data weakness.

A preregistered falsifier is a validated visible-path classifier with population error below $1/2$ on the same-law $(u,v)$ fixture, or a test whose error falls below $\frac14e^{-D_T^{\rm full}}$ when the model, priors, and path accounting are correct. Such an outcome would identify hidden leakage, a misspecified readout, an incorrect likelihood calculation, or an error in the derivation. A finite run that fails to reject equality is not proof of equivalence; equivalence in Counterexample A is analytic.

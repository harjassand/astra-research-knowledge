REFERENCE CANCELLATION: CORRECTION OF THE COORDINATOR'S SCOPE WARNING
Cycle06. Separate addendum; every earlier frozen proof remains unchanged.

The earlier classification statements quantify all faithful qubit product
references tau. They are correct, but the coordinator additionally warned
that varying tau was essential and that a fixed maximally mixed reference
was not covered. That warning was too restrictive and is superseded here.
The cancellation was noticed while reading Section2 of complexity_proof_recon's
independent global-qubit baseline, then checked directly by root and separately
by tensor_frame_sol and variance_monogamy_sol. It does not require the global
qubit entropy theorem or any unproved higher-dimensional weak inequality.

Let L be a Heisenberg generator on B, L(I)=0, and fix sigma_B. On untouched R,
the weighted generator relative to omega=tau_R tensor sigma_B is exactly
 id_R tensor H_sigma,
because Gamma_tau^(+/-1/2) cancels through the identity. Hence
 E_omega(rho_RB)=Tr[sqrt(rho_RB)(id_R tensor H_sigma)(sqrt(rho_RB))]
is independent of tau_R. Also
 Tr[(id_R tensor L_*)(rho_RB)(log tau_R tensor I_B)]
   =Tr[rho_RB(log tau_R tensor L(I_B))]=0.
Thus J_omega is independent of tau_R as well. For channels the same argument
uses Delta=rho-(id_R tensor Phi)rho, with Tr_B Delta=0.

Consequently, if the test domain consists of ALL faithful joint states rho_RB,
the following are equivalent:
 - J>=4E for every faithful qubit product reference tau_R tensor sigma_B;
 - J>=4E for any ONE chosen faithful qubit reference, including tau_R=I_R/2.
The already proved classification therefore characterizes modular covariance/
GNS symmetry using the fixed maximally mixed qubit reference as well.
The necessity proof still expands at specially tuned stationary product STATES
tau'_R tensor sigma_B. Those states are legal because all joint states are
being tested. The entropy and energy functions coincide with those for the
original fixed reference; changing the expansion center introduces no new
assumption.

Different constraint, not silently covered: if one ALSO requires the physical
marginal rho_R to equal the one fixed reference tau_R, the admissible joint
state set is smaller. Our calibrated-center proof does not establish the same
classification on that restricted set. If instead tau_R=rho_R is chosen anew
for each arbitrary joint state, all joint states remain admissible and the
cancellation still applies.

This correction strengthens the minimal reference assumption. It changes no
counterexample, no channel/GNS equivalence proof, and no scalar-energy theorem.
Earlier frozen phrases requiring 'all faithful tau' are sufficient formulations;
earlier warnings that a fixed tracial reference was insufficient are withdrawn.
No claim about every literature convention of the word 'complete' is made
without checking its actual state domain.

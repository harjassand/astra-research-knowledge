# Receiver proof, stopped exposure and exact boundary

## 1. Totality and canonical retirement

The control sector projectors indexed by all `(r_i,l_i)` are orthogonal and sum to identity. On each sector, d selects one residue. The suffix is a product of qutrit unitaries; tracing/preparing the unowned bank is CPTP; R is CPTP; moving a code from one bank to a vacated bank and preparing the old source is CPTP; the final control reset is CPTP. Summing sector channels proves T is CPTP, including on coherent control inputs and arbitrary references.

The range of R is the five-qubit code for every input. Therefore T always produces exactly one code-bank owner, vacuum in the other bank, and uniform `(r+1,0)` controls. This property is unconditional. It gives a real reusable reset channel rather than a promise that an invalid local counter star eventually becomes valid. The terminal clock never inspects an exterior. From any physical state, the time to the next ideal T is Exp(lambda); noisy microsteps or onsite faults do not disable it. Every old progress marker, phase copy and unused-bank phantom is consumed in that event. There is no acknowledgment/message object which can survive a wrap.

## 2. Qutrit correctability

The five-qubit code has distance three. Its 16 Pauli syndromes for `I,X_i,Y_i,Z_i` are distinct. Hence their code images are orthogonal with scalar Gram identity. A leakage map `L_(i,b)=|perp><b|_i` has

```
V^dagger L_(i,b)^dagger L_(i,c) V
 = V^dagger |b><c|_i V = delta_bc I/2.
```

This uses that every nonidentity one-site Pauli has zero code expectation. Leakage at different sites has orthogonal vacancy patterns, and leakage images are orthogonal to the no-vacancy Pauli images. Thus the 26-map diagonal Gram identity in the specification is exact. An arbitrary map from a qubit input to a qutrit at one site is a linear combination of its qubit Pauli block and its two leakage matrix units. R consequently corrects its entire span. Orthogonal syndrome isometries plus an explicitly assigned complement establish trace preservation and a fixed decoder, rather than KL existence alone.

For any one-site Kraus family E_j, `R(E_j V rho V^dagger E_j^dagger)=c_j V rho V^dagger`, with `c_j>=0` independent of rho. For a trace-preserving fault family, `sum_j c_j=1`. This identity tensored with identity on any reference proves reference-uniform channel correctness. Conditioning on a finite controller branch can change c_j but cannot reveal logical information.

## 3. Single-interval quantum receiver

Suppose the preceding terminal left canonical phase r, code state `V sigma V^dagger` in source S and vacuum in D. Fix an ideal/fault event history up to the next T. Assume all faults in that interval act on one site i, possibly many times and on its entire A/B/control register. Every other site j has unchanged phase r and starts with progress zero. Its M_j either has not fired, or has applied exactly one `U_r` to S_j and set progress one. At T, the suffix therefore makes the total action on every such j exactly `U_r`.

The four clean phase copies force d=r. Every action involving the affected site's data, progress, phase, wrong-bank choice or vacancy sector remains supported at that one site; none of the M rows interacts between sites. Dephasing its controls at T produces a local Kraus family. Since D was vacuum at interval entry, tracing D_i gives source-only Kraus matrices of the form

```
K_(alpha,b) = <b|_(D_i) M_alpha |perp>_(D_i),
b in {0,1,perp},
```

where M_alpha includes all local faults, local microsteps and the local terminal suffix branch. Thus before R the source has `U_r` on the four clean sites and an arbitrary qutrit map at i. Moving `U_r` through that one-site map rewrites this as an arbitrary one-site error AFTER the intended transversal `U_r^tensor5`. Since that transversal preserves the code, R returns precisely `V U_(r,L) sigma U_(r,L)^dagger V^dagger`. The data move and reset then give the next canonical state. A fault which acts jointly on the two banks and controls is therefore included; a raw occupied/vacant assumption at the faulty site is unnecessary.

The source/destination trace is sound because D has NO incoming live owner. It would erase legitimate unknown data if another controller could write D. The proof is about one closed code wire.

## 4. Indefinite reuse and real logical history

Induct on terminal events using section 3. After any finite n good intervals, the output is `G_n` on the logical input and controls are canonical `n mod4`. No terminal authorization is one-use: the same A/B banks and phase residues wrap arbitrarily often. The data owner swaps on each event and the old source is vacated on that same event. There is no pending transfer to replay after wrap.

The actual logical gates survive this receiving map. `X_L C_L != exp(i phi) C_L X_L`; for example, C conjugates X to Y, and the induced Bloch rotations differ. Thus the second terminal's `C_L X_L` is not a gauge-erased identity. This is a restricted repeating Clifford wire, not a universal logical gate controller.

At a final observation instant the four clean sites' `D_hold` branches undo exactly their partial fast-path gate. The affected site's entire remainder remains a one-site map, so R returns the logical state after the last terminal. The observation is ideal and fixed-support; noisy readout implementation is additional work.

## 5. Continuous noise and waiting are charged

Let each physical site's entire register be hit by independent exogenous rate-p onsite fault proposals. The fault maps may be arbitrary CPTP. Let all ideal terminal proposals have rate lambda, and arbitrary block-wide faulty terminal proposals have independent rate eta. Microstep errors are included in p. No assumption that a service interval is noise-free is made.

A good history has no faulty terminal event and never has faults at two distinct sites between consecutive ideal terminals, including the last unfinished interval. Write a_0(t) for the probability of no distinct fault site since the last ideal terminal and no earlier bad event, and a_1(t) for exactly one distinct site. The exact homogeneous killed process is

```
a_0' = -(5p+eta) a_0 + lambda a_1,
a_1' = 5p a_0 - (lambda+4p+eta) a_1,
(a_0(0),a_1(0))=(1,0).
```

Repeated faults on the same site are loops and remain correctable. A second distinct site has rate 4p, and is conservatively declared bad even if its actual map is harmless. Set `a=(lambda+9p)/2`, `b=sqrt((lambda+9p)^2-80p^2)/2`. The survival probability is exactly

```
s(t)=exp(-eta*t-a*t) * [cosh(b*t)+(a/b)*sinh(b*t)]
```

with the continuous limiting value when b=0. Thus, after the specified D_hold, the diamond distance to the matched ideal random-terminal process, including its reported phase, is at most `2(1-s(t))`. The proof couples the state-independent clocks; the good CP subchannel equals the ideal instrument times its clock-history weight. Bad subchannels have total weight `1-s(t)` independently of logical input/reference.

A useful simpler bound for possibly unequal p_i is

```
||decoded_noisy(t)-matched_ideal(t)||_diamond
 <= 2 min(1, eta*t + t sum_i p_i*(nu-p_i)/(lambda+nu-p_i)),
nu=sum_i p_i.
```

To prove it, charge a fault at i whenever another site's fault has occurred since the last ideal terminal. The probability of that antecedent is at most `(nu-p_i)/(lambda+nu-p_i)` by the race between an ideal terminal and other-site fault clocks, starting from the reset initial state. The expectation of charged arrivals bounds their union probability. In the homogeneous case the displayed rate is `eta+20p^2/(lambda+4p)`. This is finite-code quadratic suppression, not size-dependent asymptotic memory.

The first ideal terminal has mean wait `1/lambda` and tail `exp(-lambda*t)`, and exposes all five data/control sites during that entire wait. An ideal terminal can occur early: its suffix physically completes any missing microsteps, so mu_i does not enter the correctness or service bound. Physical finite gate durations, energy/reset-bath costs, and a microscopic realization of R are not supplied.

## 6. Bad controller bursts and lineage boundary

For `(r_i)=(1,2,3,0,0)`, d=0, T is immediately enabled, and the three corrupted progress/data strands are not claimed correctable. An arbitrary split word also has a defined d; hardwired U_r has no replicated program copies to deadlock. The three-counter trap and two-program split therefore cannot be absorbing states of this table.

An uncorrectable phase burst can make d wrong, select the wrong source and erase the logical input. T then still returns a canonical phase and code-bank pair. It does NOT recover the true ghost phase. The subsequent clock offset is a corrupted clock payload carried on the same closed wire. Declaring later gates automatically good in an interacting hierarchy would require an outer encoding/lineage argument for that payload. This construction supplies no such argument and no source-fanout bound for fresh output ports.

## 7. Why this does not close the frontier

The unconditional suffix plus total recovery removes a finite receiver's liveness, partial-history and A/B reuse obstruction. It does so with one physical five-site map containing all of the code recovery. This is legal only as a fixed bounded-support base generator. At a concatenated level the corresponding map acts on a growing region. A lower-level asynchronous implementation must protect partial syndrome extraction, ancillas, reset, code transfer and phase selection; no such implementation is proved here. A malformed multi-block neighborhood with incoming owners is also outside the table. Existing dissipative QEC and encoded gate recovery are the strong incumbent; no historical novelty or practical advantage is established.

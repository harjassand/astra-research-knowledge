# Leaf 09 — mask entropy and row-incidence partition

Date: 2026-10-08. Status: internally proved combinatorial statements; conditional arithmetic upper bound for a structured mask; no general selective-product algorithm or general circuit lower bound.

## Interface

Let `N=2^(8k)`, `D=N^(1/4)=2^(2k)`, and `m=floor(N^(15/8))`. The input is dense integer `X in Z^(N x D)`, `Y in Z^(D x N)`, and an explicit list `W` of `m` distinct output pairs. Return exactly `(XY)_{ij}` for `(i,j) in W`. Assume input entries have `O(log N)` bits. All input and output bits, mask processing, circuit descriptions, coefficient heights, arithmetic, and decoding are charged. The mask is supplied; this note does not charge the cost of generating it.

The input matrices contain `O(ND log N)=O(N^(5/4) log N)` bits. The mask list and exact answer list each contain `O(m log N)=O(N^(15/8) log N)` bits. Both are below `N^2` by a fixed power, up to logarithms. The largest dot-product output has `O(log N)` bits because `D=N^(1/4)` and the two input entries have `O(log N)` bits.

## A mask-specific disjoint rectangle partition

For each row `i`, write `Gamma(i)={j:(i,j) in W}`. For every distinct nonempty row neighborhood `S`, set

    R_S={i:Gamma(i)=S},  r_S=|R_S|,  t_S=|S|.

Then

    W = disjoint_union_S (R_S x S),       sum_S r_S t_S = m.       (1)

This is an exact biclique partition, not a cover with overlap. For each part, compute the complete rectangular product `X[R_S,:] Y[:,S]`. Its entries are exactly the requested outputs in that part; no unrequested output is produced. The row-signature dictionary is directly derived from the supplied mask.

### Arithmetic bound, conditional on an explicit square multiplier

Suppose a single uniform, exact `D x D` matrix-multiplication circuit is supplied, with total charged gate count `M(D)<=D^(omega+o(1))`. The gate count must include linear forms, coefficient multiplications, and output decoding. Tiling `R_S` and `S` into pieces of size at most `D` gives:

- If `r_S,t_S>=D`, at most `ceil(r_S/D)ceil(t_S/D)` square products, hence `O(r_S t_S D^(omega-2+o(1)))` arithmetic operations.
- If `min(r_S,t_S)<D`, compute each requested dot product directly, for `O(r_S t_S D)` arithmetic operations.

The first estimate follows by multiplying the number of tiles by `M(D)`. The ceiling terms are absorbed because `r_S,t_S>=D` and `omega>=2`. The second estimate directly counts `D` multiply-add terms for each output. Therefore the exact pattern strategy costs

    T_arith(W) = O( sum_{good S} r_S t_S D^(omega-2+o(1))
                    + sum_{thin S} r_S t_S D ),                 (2)

where `good` means `r_S,t_S>=D` and `thin` means otherwise. This also charges repeated reads of rectangle inputs: good tiles read `O(r_S t_S)` input scalars total, and thin rectangles read `O(r_S t_S D)` scalars, both within their displayed operation bounds. The initial dense input read is `O(ND)` scalars.

The mask can be grouped exactly without expanding an `N x N` bitmap: comparison-sort its `m` coordinate pairs by `(i,j)` in `O(m log m)` comparisons, costing `O(m log^2 N)` bit operations, then insert the resulting `N` sorted sparse neighborhood strings into a binary trie. The trie processes `O(m log N+N)` bits (encode each column index in `ceil(log_2 N)` bits and terminate every row string), and equal strings reach the same terminal node. Thus row classes are found in `O(m log^2 N)` bit operations and `O(m log N)` storage. The explicit mask and output each cost `O(m log N)` bits. Add the one-time cost `A_D` to acquire/generate the square circuit and its description. If its rational coefficients have at most `h_D` bits and intermediate heights obey the corresponding standard bilinear-circuit bound, bit work is (2) times a polynomial in `h_D+log N`, plus `A_D` and the mask/input/output bit work. Without a uniform circuit-generation bound and a coefficient-height/denominator ledger, (2) is only an arithmetic-operation statement; it is not an end-to-end integer-bit algorithm.

For the released `9/4` arithmetic exponent noted in L04 and contextualized by N12, (2) becomes

    T_arith(W) = O(m_good D^(1/4+o(1)) + m_thin D),              (3)

with `m_good=sum_good r_S t_S` and `m_thin=sum_thin r_S t_S`. A sufficient combinatorial condition for a fixed subquadratic saving is `m_thin<=N^(7/4-delta)` for some fixed `delta>0`: then the good part is at most `N^(15/8+1/16+o(1))=N^(31/16+o(1))`, and the thin part is at most `N^(2-delta)`. Since `31/16<2`, the arithmetic saving is any fixed exponent below `min(delta,1/16)` after absorbing the `o(1)` term. Mask processing and exact output bits are also subquadratic.

This is a partition/cover condition that can enable shared output-local arithmetic: the repeated neighborhood class causes one rectangular multiplication to serve all rows in that class. It is conditional on the supplied uniform square multiplier. N12's `9/4` exponent by itself does not supply the required uniform integer-bit circuit or its coefficient ledger, so no such algorithm is claimed here.

### Exact favorable mask

For `N=2^(8k)`, choose any `S subset [N]` with `|S|=N^(7/8)=2^(7k)` and set `W=[N] x S`. Then `m=N^(15/8)` exactly, there is one row signature, and `r=N,t=N^(7/8)`, both at least `D`. Formula (3) gives

    T_arith = O(N^(15/8) N^(1/16+o(1))) = O(N^(31/16+o(1))).

The mask can be listed in `O(m log N)` bits or represented by the one set `S` in `O(N^(7/8) log N)` bits plus the rule that every row is used. Even when the user supplies the full edge list, its read/sort and output costs remain `O(N^(15/8) polylog N)`. This is an exact structured-mask arithmetic gain, conditional on the square circuit and bit ledger above. It is not a result for arbitrary `W`.

## High-entropy masks defeat exact-neighborhood reuse

Let `U=N^2`, `m=floor(N^(15/8))`, and choose `W` uniformly from the `m`-subsets of `[N] x [N]`. Then

    log binom(U,m) = m log(U/m)+O(m)
                    = (1/8+o(1)) m log N.                       (4)

Thus the mask family has `N^(m/8+o(m))` possibilities. An explicit edge list takes `2m ceil(log_2 N)+O(log m)` bits, still `O(N^(15/8) log N)=o(N^2)` bits. So its combinatorial entropy is high enough to defeat a small row-pattern dictionary while its supplied representation is affordable within the target time.

There exist such exact-size masks with all row and column degrees in `[m/(2N),2m/N]` and with all row neighborhoods pairwise distinct; the same holds for columns. Proof: first sample each edge independently with `p=m/N^2`, and put `mu=Np=m/N=N^(7/8)(1+o(1))`. Each row degree is `Bin(N,p)`, so Chernoff gives failure probability at most `2 exp(-mu/12)` for a fixed row to lie outside `[mu/2,2mu]`. For two fixed rows, their independent Bernoulli neighborhood strings are equal with probability

    (p^2+(1-p)^2)^N <= exp(-2Np(1-p)) <= exp(-mu)

for all sufficiently large `N`. Union bounds over `N` rows and `binom(N,2)` row pairs make the total failure probability `exp(-Omega(mu))`. The identical argument applies to columns. The total edge count `M` is `Bin(N^2,p)` with mean `m`; the local central limit estimate gives `Pr[M=m]=Theta(m^(-1/2))`. Conditioning on `M=m` therefore increases the exponentially small failure probability by only a polynomial factor. Under this conditioning `W` is uniform among exact `m`-edge masks, proving the existence claim.

For any mask in this family, every nonempty row-signature class is a singleton (`r_S=1<D`), and by symmetry every column-signature class is a singleton. The exact row partition has `m_thin=m`, so its fully charged direct arithmetic cost is

    mD = N^(15/8+1/4+o(1)) = N^(17/8+o(1)) > N^2.

The same holds for the column-signature partition. This is a counterexample to the specific strategy “share a full rectangular product only among rows (or columns) with identical neighborhoods.” It does not refute a biclique partition with overlapping or mixed input forms, shared arithmetic across distinct neighborhoods, or a general value-independent arithmetic circuit. The L04 independently charged block-cover obstruction remains the relevant stronger prior for one broader restricted model; neither result rules out shared output-local arithmetic in general.

## Claims and unresolved gate

1. **INTERNALLY-PROVED-CANDIDATE:** the row-signature partition (1), arithmetic accounting (2), and the high-probability existence of exact masks with unique row and column signatures. These are elementary combinatorial/cost derivations; no external formal verification or novelty claim.
2. **CONDITIONAL:** subquadratic arithmetic for masks with `m_thin<=N^(7/4-delta)`, and the exact complete-rectangle example, provided a uniform `9/4+o(1)` square circuit is actually supplied. End-to-end bit complexity additionally requires `A_D` and coefficient/denominator heights small enough. N12 explicitly leaves this gate open.
3. **REFUTED, scoped:** exact identical-neighborhood reuse as a universal arbitrary-mask strategy. It costs `N^(17/8+o(1))` on the mask family above. This is not a general selective multiplication lower bound.

Strongest equally informed baseline: compute each requested dot product independently in `mD` scalar operations; it exactly matches the row-signature strategy on the random-mask family. On a complete rectangle, tiled square multiplication improves that baseline by the factor `D^(3-omega+o(1))` when `omega<3` and both sides are large. The full thin product `XY` followed by output selection is the other baseline at `N^(2+o(1))` arithmetic operations, but does unnecessary outputs for the favorable rectangle.

Next decisive attack: extend (2) to a mask-dependent partition with shared transforms across *different* row signatures, and prove a bound on its total acquisition and arithmetic cost; or prove that the random exact-size masks above force large cost for a precise mixed-linear-form model. This leaf has not closed that gate.

N51 CONSEQUENCE: DETERMINISTIC ACQUISITION OF AN NC RATIONAL DESCRIPTOR
2026-10-07. Derived theorem candidate; exact oracle interface and inherited gates retained.

MAIN RESULT

Accepting N51's universal strong affine-pencil list, an unknown admissible
noncommutative rational FORMULA Phi over ANY field F, with n variables and
tree size <=s, can be reconstructed deterministically from exact matrix
evaluation access. The output is an affine matrix-inverse descriptor

                 alpha (C - sum_i D_i x_i)^(-1) beta,

of polynomial order, equivalent to Phi over the free skew field. Moreover,
the displayed MATRIX pencil is invertible at every matrix tuple where the
ORIGINAL formula tree is defined, and its selected value is Phi there.
This domain conclusion concerns the descriptor, not a scalar inverse-gate
formula obtained by Gaussian elimination. Polynomial-size scalar FORMULA
reconstruction is not established; matrix inverse entries can require
exponential formula size (HW2015).

The number of oracle queries, their dimensions, all explicitly written
query entries, and the learner's field operations are polynomial in n,s.
Complete integer list generation is polynomial BIT time, not an unbounded
search. Actual oracle evaluation, reply encoding and field arithmetic costs
remain charged. For an unspecified abstract coefficient field there is no
coefficient-height-independent total bit algorithm. Over Q with hidden
constant height <=h and ordinary exact matrix evaluation, total bit costs
are polynomial in n,s,h; no bound independent of h is claimed.

The mathematical reduction below is unconditional given a strong hitting
generator. Instantiating it with N51 inherits N51's unreviewed all-field
q-Newton/symbol/descent derivation. The actual OpenAI Sept-24 source is
Q-only; it is not an external proof of the all-field extension. No whole
promised-size N51 generator or whole reconstruction run has been executed.

INTERFACE

Inputs: n,s in unary; exact field operations/equality over F; a black-box
service returning the FULL ordinary matrix Phi(X), or an explicit UNDEFINED
symbol, for requested n-tuples of matrices over F. All specified polynomial
dimensions must be supported. No coefficient, formula tree, supplied regular
centre, equivalence oracle, counterexample word, or intermediate-gate output
is assumed. The oracle is promised to be an admissible size-s formula.
After centre acquisition every subsequent query is proved defined.
Only particular principal/cross blocks of replies are used, but complete
reply encoding and cost are charged under the full-output interface.

1. ACQUIRE A REGULAR MATRIX CENTRE, INCLUDING ZERO FUNCTIONS

Generate N51's list H(n,2s+1), reduce its integers through F's prime-subfield
map, and query until Phi(A) is defined. At least one succeeds: retain only
the original formula's inverse-node domain pencils, omitting the root
nonzero/invertibility augmentation. There are <=s pencils, order <=s+1,
each feasible because the formula is admissible. The strong common-hit
property therefore applies even when Phi is zero. Let d be the selected
centre dimension. N51 gives d=poly(n,s), without knowing F's characteristic
or Phi's coefficient constants. An explicit UNDEFINED reply is needed for
this search.

2. TURN THE FUNCTION INTO ONE ORDINARY PROPER SERIES

Use k=n d^2 free letters y_(i,a,b). Define

 G(Y)=Phi(A_i + sum_(a,b) E_ab y_(i,a,b)),       g(Y)=G(Y)_(1,1).

The generic-entry perturbation is essential. A shift using only n scalar
letters would not supply the cancellation/recovery step below.

Release Lemma4.1 constructs a constant row u, column v, and affine pencil
L(x)=L0+sum_i L_i x_i of order r=|Phi|+1<=s+1, satisfying

 Phi(X)=u L(X)^(-1) v,

with L(X) invertible at EVERY ORIGINAL-DOMAIN point. Its block recursion
uses only 0,1,-1 and ordered inverses, so the lemma is characteristic-free.
It is used for existence/proof; the learner does not construct unknown L.

Set m=rd, L_A=L(A), and

 T_(i,a,b)=-L_A^(-1)(L_i tensor E_ab).

Taking the first row/column selectors gives scalar row c and column b with

             g(Y)=c (I_m-sum_j T_j y_j)^(-1) b.

Thus g is a proper recognizable nc series of dimension <=R=(s+1)d.
Its coefficient at word w is c T_w b. Its left-residual space has dimension
<=R. Every linear combination of its residuals has the SAME transitions
T_j, with a different initial row, and consequently also dimension <=R.

3. A POLYNOMIAL, INJECTIVE RESIDUAL FEATURE MAP

Any nonzero recognizable scalar series of dimension <=R has a nonzero
word of length <R. Proof: row spans generated by prefixes stabilize after
at most R steps; if all words shorter than R have zero output, invariance
forces every output zero. This is ordinary linear algebra over any field.

For any residual combination f, its truncation

                     P_f=sum_(|w|<R) f(w) w

therefore detects whether f is zero. P_f has an affine inverse realization
of order <=R^2: unroll its width-R transition system through R layers.
The layer pencil is unit triangular, hence always invertible. Augment it
by its scalar input/output selectors. For nonzero P_f this augmentation is
an order <=R^2+1 feasible pencil (HW2015 Proposition7.3 / the standard
free-field linearization bridge).

Generate H=H(k,R^2+1) from N51. For each H tuple Z of dimension e, set

                      N_j=Z_j tensor J_R,

where J_R is the nilpotent upper shift. Define the finite feature vector
D(f) by flattening all f(N) matrices over all list tuples. These queries
are legal for every proper series. If P_f(Z) is invertible at an N51 hit,
some homogeneous component P_(f,l)(Z) is nonzero. The corresponding
l-th upper block diagonal of f(N) is P_(f,l)(Z). Hence D(f)!=0. Therefore
D is linear and injective on the entire unknown residual space.

This is a deterministic finite feature map; no randomized specialization,
ordinary scalar Wronskian, Frobenius-fixed coefficient assumption, or
equivalence oracle occurs in the learning phase. All H tuples and all
entries are explicitly generated and their costs are counted.

4. OBTAIN EACH FEATURE BY DEFINED ORIGINAL-ORACLE QUERIES

For prefix p=p1...pell and a graded tail tuple N of dimension t=eR, form
k block matrices P_j of order (ell+1)t. Their first ell diagonal blocks
are zero; their final diagonal block is N_j; block (a-1,a) is I_t exactly
when p_a=j. Other blocks are zero. In g(P), cross block (0,ell) is

                       (partial_p g)(N).

Indeed a word reaching that block must consume the forced prefix and
then continue along the tail. Query the original oracle at

                X_i=A_i tensor I +sum_(a,b) E_ab tensor P_(i,a,b).

After one fixed permutation, all P_j are simultaneously strictly upper
triangular. X is block upper triangular with A on every diagonal block.
At every original inverse gate its operand is block upper triangular with
the corresponding operand value at A on the diagonal. Those diagonal
blocks are invertible by centre regularity. Thus EVERY such query is in
the original formula's domain, without any unknown determinant tests.
Selecting output indices corresponding to outer entry (1,1) and prefix
cross block gives precisely the feature matrix required above.

The coefficient g(p) is obtained by the same chain with one-dimensional
zero tail; it requires a query of dimension d(ell+1).

5. ACQUIRE A RESIDUAL BASIS BY FINITE BFS

Start with epsilon. Cache D(partial_p g). Maintain prefix words whose
feature vectors are linearly independent. For every basis prefix p and
every letter j, query D(partial_(pj) g). Add pj to the basis if independent;
otherwise solve its exact coordinates in the existing basis. Because D is
injective, every computed feature dependency is the actual identity of
residual SERIES. At most R basis words are added. Final closure under all
k letters proves by induction that the basis spans every residual.

For basis p_a let B_j[a,b] be the coordinates of residual p_a j, and let
beta[a]=g(p_a). Alpha is the coordinate row of residual epsilon. Then

                 g(Y)=alpha (I_q-sum_j B_j y_j)^(-1) beta,

where q<=R. The equality follows from the recovered residual transitions
and constant outputs, coefficient by coefficient. If initial D(g)=0,
return the zero descriptor. Basis prefixes have length <R; tested transition
prefixes have length <=R.

6. RECOVER Phi AND PROVE DOMAIN CONTAINMENT

Substitute y_(i,a,b)=delta_ab x_i-(A_i)_(a,b). This gives

 C=I_q+sum_(i,a,b) (A_i)_(a,b) B_(i,a,b),
 D_i=sum_a B_(i,a,a).

Return alpha (C-sum_i D_i x_i)^(-1) beta.
The ORIGINAL generic matrix substitution becomes I_d tensor x_i;
therefore entry (1,1) of G becomes Phi(x). C itself may be singular
(e.g. acquiring x^(-1) about A=1 gives C=0), and this is allowed.

Rational-function equality alone would NOT prove the promised domain.
The following invariant-quotient argument proves it directly.
Let W=span{c T_p} be the reachable row-state space of the hidden proper
realization, and K={a in W: a T_w b=0 for every w} its unobservable space.
Both W and K are invariant under right multiplication by every T_j. The
recovered residual space is exactly W/K; its transition matrices B_j are
the induced right-multiplication maps in the acquired residual basis.
Choose an F-basis of ambient F^(1xm) respecting K subset W subset ambient.
Each T_j, and hence every evaluated pencil I-sum_j T_j Y_j, is block
triangular in that fixed basis, with the learned quotient pencil as one
diagonal block.

At ANY original-domain tuple X of order e, substitute the Y above. The
ambient pencil is L_A^(-1), tensored with I_e, times

            L(I_d tensor X_i),

up to fixed tensor permutations. The latter is permutation-similar to
L(X) tensor I_d and is invertible by the original affine realization
invariant. The ambient pencil is therefore invertible. An invertible
ordinary block triangular matrix has every diagonal block invertible.
Consequently the learned quotient pencil is invertible at X. The block
identity and coefficient-series equivalence give the same output Phi(X).
This works over every F and every finite matrix dimension, not merely at
generic/free-field points. No minimal-realization domain theorem is needed.

7. COMPLETE COST ACCOUNTING

Let L0 be the centre-list length, L1 the graded detector-list length, and
e_max its largest dimension. N51 makes each polynomial in its stated
unary parameters. Here d=poly(n,s), k=n d^2, R=(s+1)d, B1=R^2+1.
Thus L0,L1,e_max and entry bits are polynomial in n,s.

There are <=1+kR queried residual words. Each needs L1 feature queries;
at most R additional zero-tail coefficient queries suffice. Hence

                     Q<=L0+(1+kR)L1+R.

Largest original query dimension is at most d R(R+1)e_max, since tested
prefix length<=R and tail order R e. Complete replies of that dimension contain
at most its square number of field elements per query. Extracted feature
vectors have <=sum_H (R e_H)^2 field entries. Gaussian elimination,
query construction and printed output are polynomial in all these bounds.
Reduction of integer coordinates over F must itself be represented or
charged; field elements are not free anonymous bit strings.

N51 generator is polynomial TOTAL BIT construction: integer triangular
Newton operations, a polynomial parameter grid, polynomial-size ordinary
regular representations/adjugates, all primes p<=K for polynomial K,
and small-field irreducible search through Q<=H^4 candidates. It is not a
claim of efficient computation of an unknown formula's outputs.
Astronomical constants remain: n=B=1 already about 4.91e62 tuples and
2.06e69 integer entries in the source's parameter calculation. Nothing
here makes this practical. Implementing the true promised-size detector
is infeasible in the current run.

For Q, hidden formula constants of <=h-bit height and polynomial-size
integer/rational query entries give polynomial reply heights: use each
subtree's affine realization of order <=(s+1)D, with entries built from
the original constants and query entries. Inverse entries are ratios of
minors of these represented matrices, giving height polynomial in
s,D,h,query bits. Exact feature elimination likewise gives ratios of
polynomial-size minors. Thus including oracle execution/reply lengths
gives a polynomial bit bound in n,s,h under that promised implementation.
The matrix oracle itself is still a supplied computational capability.

8. UNCONDITIONAL LIST/COMPRESSION OBSTRUCTION

Independent child audit: work/agents/algebra_complexity/pit_bridge/
all_field_audit/REPORT.txt. Over an algebraic closure, for each proposed
ordinary tuple X^(j), choose an eigenvalue a_j of its first matrix. The
order-one pencil x1-a_j is feasible but singular at tuple j. Thus a list
of h<=B tuples cannot have the common-hit property for B feasible pencils:
the list must contain at least B+1 tuples. This is an exact all-extension
coefficient obstruction, not an N51 flaw.

For P(x1)=product_(j=1)^h(x1-a_j), the scalar formula size is 4h-1 and it
is singular at EVERY tuple. The nonzero admissible formula

                   Phi=1+0*P(x1)^(-1)

has size 4h+4 and is UNDEFINED at every tuple. Cancellation does not remove
the original inverse gate. Therefore strong invertible-value hitting for
size s requires >=floor((s+1)/4)+1 tuples (P alone), and a list supplying
defined nonzero values requires >=floor(s/4) tuples (the domain formula).
Taking a block direct sum of the tuples preserves every bad singular block
and cannot compress these domain requirements to one universal query.

9. PRIOR ART / NOVELTY LIMIT / FAILURE LEDGER

The learned residual realization and reachable/observable quotient are
standard weighted-automata / recognizable-series mechanisms. This report
is an explicit deterministic polynomial consequence at the newly available
strong hitting interface; no historical priority claim is made.
Older polynomial ABP reconstruction (Arvind-Mukhopadhyay-Srinivasan 2008)
requires intermediate-gate output access. Forbes-Shpilka 2013 combine
quasipolynomial hitting with reconstruction for nc ABPs. Volcic2018 and
Porat-Vinnikov2021 supply existing arbitrary-matrix-centre realization
theory; minimal realizations themselves are not new. Arvind-Chatterjee-
Mukhopadhyay's general rational black-box PIT is quasipolynomial in the
acquired July2025 version, not a direct disproof of this new polynomial
consequence. A complete latest-version reconstruction comparison remains
unperformed; call this a derived candidate, not the first theorem.

matrix-centre cancellation. Replaced by nd^2 generic entry directions.
Failed shortcut: free-field equality alone proves descriptor domain.
Replaced by invariant ambient-state quotient and block triangularity.
Failed shortcut: use N51 at arbitrary tails and assume original oracle
defined. Replaced by nilpotent graded tails and forced prefix chains.
Failed shortcut: claim a small scalar formula follows from a small matrix

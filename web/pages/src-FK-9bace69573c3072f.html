- `exact_checks.py` uses Python `fractions.Fraction` only. It verifies the explicit vector addition, the determinant and visibility/phase-class statements for the chosen finite reflection set. This is exact arithmetic for the scoped crystallographic table, not an imaging simulator or detection-completeness test.
- `exact_checks.py` was run once using the repository's existing `work/FE-hidden-gate/venv/bin/python`. Output is `exact_checks.json`. One intermediate assertion initially assumed fault-phase uniqueness; exact arithmetic exposed the correct alias modulo a perfect-lattice translation. The check/report were corrected to preserve that alias.
- No atomistic/material simulation, experimental acquisition, device test, or source-code replay was run. Assay time, dose, preparation, and wall-power costs remain parameters to measure on a selected specimen. No experimental repair, novelty, performance, or global absence claim is established.

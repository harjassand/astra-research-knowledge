## Required limitations

The bound must depend on the norm of **all** supplied roles. An output
error bound depending only on the logical source `x` is false for
unbounded dirty catalysts: coefficient mismatch leaks catalyst amplitude.
For the single-array transform, zero padded roles give total input norm
equal to the requested input norm. The full dyadic tensor network does
not use the arbitrary-length Fourier Newton/Toeplitz compiler; that
compiler can introduce large conditioning and is outside this claim.

Address work remains logarithmic-word RAM work. Numeric payload bit work
may be accounted separately, but a sub-n-log-n multitape bit bound does
not follow by charging address operations as single bits. No practical
crossover claim is possible with these enormous fixed constants.

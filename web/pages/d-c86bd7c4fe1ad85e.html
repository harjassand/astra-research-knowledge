# Frozen nonradial finite conductivity discriminator

The experiment produces an effective, exact all-secants stability certificate for a nonradial two-parameter **finite Galerkin** inverse problem with boundary-only inputs and voltage tests. At equal total current energy and four scalar readings, the selected optimized two-current control has **provably greater true global secant separation** than the selected optimized single current; both outperform normalized random single currents in the heldout noisy experiment. This is an executable scoped construction, not a claim of a general random-current advantage or a foundational novelty.

## Exact question and interface

Can the qualitative continuum one-current theorem be accompanied by finite input energy, finitely many noisy detectors, a computable **global normalized-secant** lower bound, and a competent multi-current comparison on a nonradial fixed partition?

Here the forward object is exactly the conforming P1 Galerkin map on the unit square: 4×4 square cells, lower-left/upper-right diagonal, 32 triangles,25 nodes,24 grounded DOFs. Conductivity is1+θ1 in the upper-left quadrant,1+θ2 in the lower-right strip x>1/2,y<1/4, and1 elsewhere. The two regions have areas1/4,1/8; background area5/8. The parameter box is[-1/20,1/20]^2. The partition is known. Only boundary nodes are used for flux and voltage testing; interior voltages are not observed. This is neither an all-node-accessible resistor-network toy nor a continuum theorem.

Let Kθ=K0+θ1K1+θ2K2 be the grounded stiffness matrix. Each regional matrix and the background complement are sums of positive-semidefinite element gradient forms. Thus K0 is SPD and0≤K1+K2≤K0. The 16 boundary nodes carry the consistent P1 boundary mass M. Fifteen orthonormal mean-zero L2 boundary modes span all admissible traces. The finite response in those modes is Fθ=BᵀKθ⁻¹B, with B formed from consistent flux loads.

Each finalized physical trace is first rounded to2^-32 and then exactly mean-centered. All currents are jointly normalized by the square root of their **exact rational summed L2 energy E**; each detector by the square root of its **exact rational L2 norm Nℓ**. The immutable raw arrays and E,Nℓ define the map for both exact verification and noisy data. The data code evaluates this definition using ordinary floating square roots and solves. It does not use a different unrounded design or claim an interval certificate for floating observations.

The one-current arm uses one unit-duration exposure and four unit-L2 voltage tests. The two-current arm uses two unit-duration exposures and two tests per exposure. Both have summed current energy1 and exactly four independent Gaussian scalar detector errors of the same SD. Repeated identical tests are allowed and charged individually. Input/test mode dimension15 is charged. Arbitrary linear voltage tests in that space and the declared independent-noise readout law are supplied interface assumptions; electrode hardware construction is not acquired here. Multi-current uses an additional exposure, so elapsed physical experiment time is not equal.

## Complete global certificate

Whiten the stiffness by K0: Cj=K0^-1/2 Kj K0^-1/2, Hθ=θ1C1+θ2C2, Rθ=(I+Hθ)^-1. Regional PSD order gives ||Hθ||≤ρ=1/20 on the box, and ||Cv||≤||v||2 for Cv=v1C1+v2C2. Consequently

\[
\|R_\theta C_vR_\theta-C_v\|
\le f(\rho)\|v\|_2,
\qquad f(\rho)=\frac{\rho(2-\rho)}{(1-\rho)^2}.
\]

This follows by writing the difference as(Rθ−I)CvRθ+Cv(Rθ−I), using ||Rθ||≤1/(1−ρ) and ||Rθ−I||≤ρ/(1−ρ).

For current j, let b_j be its normalized physical flux load and let Q_j have its normalized test loads as rows. The scalar-response derivative is

\[
D y_j(\theta)[v]=-Q_jK_0^{-1/2}R_\theta C_vR_\theta K_0^{-1/2}b_j.
\]

Stack all four measurements as y(θ), and let J0=Dy(0). Set

\[
\beta=f(\rho)\left[\sum_j
\|Q_jK_0^{-1/2}\|^2\|K_0^{-1/2}b_j\|^2\right]^{1/2},
\qquad \alpha=\sigma_{\min}(J_0).
\]

Then ||Dy(θ)−J0||≤β uniformly. Integrating along the straight segment between any θ,η in the convex box and applying the reverse triangle inequality gives the **all-secants** statement

\[
\|y(\theta)-y(\eta)\|_2\ge(\alpha-\beta)\|\theta-\eta\|_2.
\]

The argument controls global cancellation; a uniform lower singular value of the Jacobian alone would not do so. A negative bound is UNKNOWN, not nonidentifiability.

The implementation independently assembles the stiffness using rational triangle areas/gradients, verifies SPD by exact LDL, and computes K0⁻¹ with Fractions. Every reference row is rational before normalization. The normalized Gram is exactly Σℓ zℓzℓᵀ/(E Nℓ). A rational α lower guess is accepted only when this2×2 Gram−α²I is PSD exactly. For each current the raw output energy Gram G_q has a rational norm upper λ certified by λdiag(Nℓ)−G_q being SPD under exact LDL. The input energy is rational b_rawᵀK0⁻¹b_raw/E. A rational β upper is accepted only when β² exceeds the resulting exact squared remainder. Floating eigenvalues merely propose bounds; exact tests accept them.

## Competent design controls and frozen protocol

The preregistration precedes heldout data. Training knows only the model, box, reference and noise law. The single search uses15 basis directions,512 Gaussian directions and6 extremal eigenvectors of D1,D2,D1+D2, deduplicated to533. For each fixed current, four output tests are analytically E-optimal at the reference: if J=Udiag(s1,s2)Vᵀ, assign frame weights w1=4s2²/(s1²+s2²),w2=4s1²/(s1²+s2²) to the two left singular directions. Four unit tests q±=sqrt(w1/4)u1±sqrt(w2/4)u2, each sign twice, realize this optimum. Its minimum information is4s1²s2²/(s1²+s2²). Simply duplicating two singular vectors equally would handicap the single-current control.

The multi search pool contains the top12 single-certificate directions, all basis directions, and the extremal directions, deduplicated to32. All496 unordered pairs and seven energy splits are evaluated, totaling3472 candidates. Each fixes its two currents and jointly optimizes their two-output frames in a convex reference-information problem. PSD2×2 frames of trace2 are parametrized by disks, solved with primal-dual extragradient.100 iterations per outer candidate, then up to10000 for each of ten finalists:447200 solver iterations. Joint optimization allows complementary responses; independently balancing each current could handicap the multi control. The chosen fixed-current information is bracketed by .076919885636 and .076923296110, relative gap4.43×10^-5. This gap certifies the fixed-current reference frame problem only. The outer current search is finite and has no global optimality certificate. Designs are ranked by their global reference-minus-remainder margin, not by heldout truth.

The solver's preceding bracket is evaluated in floating arithmetic. A separate **exact rational optimality certificate for the finalized physical currents** removes that numerical qualification: if A_j is the full mean-zero L2-output reference Jacobian, S_j=A_jᵀA_j is rational for the normalized raw traces. Any W≥0,trW=1 gives the E-optimal output-design upper bound Σ_j k_jλmax(S_jW), because λmin(information)≤tr(W information) and each unit test contributes at most that spectral maximum. Rational PSD W and rational characteristic-root upper bounds certify this sum exactly. The selected tests give primal lower α_lower². The single fixed-current gap is at most9.56×10^-11 using the exact analytic upper4det(S)/tr(S). All128 random unit-sphere currents receive the same reference-optimal four-detector treatment; no redraw or favorable selection is allowed. Each local halfwidth is the previous grid spacing and then spacing divides by3, with boundary clipping. No truth is used in reconstruction. There are1681 full-grid points and250 additional forward requests per fit. The implementation shares offline forward matrices among equally informed methods, and reports both its actual cache cost and the1931 naive per-fit forward query budget.

If L uniformly bounds the exact map's parameter Lipschitz norm, the full-grid covering radius h√2/2 gives residual slack η=Lh√2/2. For exact arithmetic, any incumbent retained from that grid satisfies

\[
\|\widehat\theta-\theta_*\|_2\le
\frac{2\|\varepsilon\|_2+\eta}{\kappa},\qquad\kappa>0.
\]

The reported numerical ratios evaluate this theorem in ordinary floating arithmetic. They are diagnostics, not verified rounding enclosures. The local refinement does not justify shrinking a global optimization slack to its local spacing.

## Effective information and decisive discretization obstacle

Across5000 frozen normalized secant pairs, sampled measurement separation minima are .196135 for the selected single design and .259454 for the selected multi design, above their analytic certificates. These **finite minima are upper bounds** on the unknown continuous global minimum. They are not the certificate.

Here an upper witness gives a stronger exact discriminator. The single sample at pair4307 is below the multi rigorous lower bound. Re-evaluating this pair's **exact dyadic coordinates** with Fraction stiffness inverses and the SAME frozen physical currents/tests gives an exact rational squared normalized secant. Its inequality with .19614² is verified exactly. Thus, writing κ_design for the actual infimum over all distinct states,

\[
\kappa_{\rm single}\le .19614 < .202099906433
\le\kappa_{\rm multi}.
\]

The strict gap is at least .005959906433. This proves a genuine ordering of the two frozen designs' global worst-case secant constants, not merely an ordering of two lower certificates. It does not prove that every single design is inferior to a multi design or that either outer search is globally optimal. Witness selection after evaluation is legitimate verification of an upper bound; it changes no design or data procedure. Its two exact24×24 parameterized inverses take .141s, and the resulting rational numerator/denominator reach2396bits. See secant_witness.py and exact_secant_order_witness.json.

For the full15-mode normalized operator secants, sample minima of singular values1,2,4,8,15 are approximately .190291,.0946269,.0234094,3.89442×10^-6,1.85×10^-20. The high tail exposes why qualitative rank alone cannot certify inexpensive finite experiments. Exact rational elimination gives regional stiffness ranks8 and5, so **every finite operator secant has rank≤13** by the resolvent identity; the15th singular value is mathematically zero. No matching lower rank is claimed. Continuum infinite-rank arguments do not convert finite grids into infinite-rank matrices. See rank_obstruction.py and finite_rank_obstruction.json.

Refining to8×8 cells, with the **same physical boundary traces prolonged**, gives reference full-mode discrepancy norm .0488221. The first16 heldout truths give four-output discrepancies as large as .0264813 for single and .0474672 for multi. For the four-dimensional noise vector, RMS is2σ, hence at the largest scalar SD .003 these discrepancies are about4.4× and7.9× the noise RMS .006. Sample normalized-secant discrepancies reach .0334085,.0404899. Nested Galerkin monotonicity is consistent with the positive reference difference eigenvalues, but neither refinement agreement nor discrepancy is a continuum error enclosure. Even a uniform forward error δ would give only2δ numerator discrepancy and would not transfer normalized-secant bounds as θ→η. A uniform derivative/normalized-secant approximation is missing. Thus the experiment currently resolves the finite Galerkin cost gap only.

## Prior art, novelty and downstream step

The previous continuum argument uses Harrach's localized potentials and monotonicity, and classical generic experiment-identifiability ideas. This finite certificate uses a standard resolvent perturbation estimate plus reference information; its frame design is a standard E-optimal information objective. Boyd and Vandenberghe, *Convex Optimization*, first published2004 (official PDF copyright page4), Section7.5/book page387/SDP7.27, formulate E-optimal design by maximizing minimum information via a semidefinite constraint; primary official source and retrieved metadata are preserved in sources/rank_pde/cycle2. Our specific unit-test frame construction and nonradial global-margin assembly are deductions, not claims taken from that source. No historical novelty is established. The new artifact is a reproducible frozen discriminator with actual all-secants bounds, physically normalized finite traces, exact rational validation and competent controls, preserving the negative random-comparison result.

Downstream use: test proposed general experiment-design statements against effective finite secant margins, energy, detector noise and discretization, rather than operator rank or a local Jacobian. The next falsifiable step is to bound the **uniform normalized-secant Galerkin-to-continuum error** for this fixed partition and boundary space. If that bound is smaller than the finite margin, the same chosen design could transfer to the continuum. Another legitimate step is a larger predeclared parameter box: the present reference-minus-remainder proof will eventually become UNKNOWN; one would need an actual secant cover or other global certificate, not a finite Jacobian plot.

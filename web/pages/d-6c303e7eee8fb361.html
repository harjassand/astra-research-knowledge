DIMENSION-UNIFORM BOUNDED EXPONENTIAL-EXPERIMENT SPECTRAL COMPRESSION
Status: current internal candidate derivation; independent correctness and
historical priority unresolved. This is NOT a new general compression principle.

Model. For each coordinate i, a known probability density rho_i on [-1,1]
satisfies common bounds 0<m<=rho_i<=M, Lip(rho_i)<=L. Let
psi_i(theta)=log integral exp(theta*x)rho_i(x)dx, and define
P_theta=product_i exp(theta_i*x_i-psi_i(theta_i))rho_i(x_i)dx_i,
theta_i=r_i v_i, 0<=r_i<=1, sum_i v_i^2<=1.
For infinitely many coordinates assume r_i->0 with an effective tail certificate
required only for implementation, not mathematical existence. The encoder sees
one X and is blind to v. ALL input-dependent classical/quantum storage is counted
by D=sum_j d_j. No free entangled receiver reference. Output-law TV is <=epsilon
uniformly in v. Independent public randomness allowed.

Theorem candidate. There are constants A,C depending only on m,M,L such that
  (1/2) S_r(A epsilon) <= log_2 D_quantum(epsilon)
                           <= log_2 D_classical(epsilon)
                           <= (1/2) S_r(epsilon)+C N_r(epsilon),
where N_r(t)=#{i:r_i>t}, S_r(t)=sum_i[log_2(r_i/t)]_+.
The lower needs only later coordinate-specific reconstruction under axial
alternatives +/- r_i e_i, with the same stored state supporting all future
coordinate choices. It does not assume a joint output or compatible measurements.
Scalar lower proof is in quantum_lower/REPORT.txt; actual scalar positive compiler
is in universal_upper/REPORT.txt. This file proves the dimension-free tensor step.

Scalar compiler summary. Use J+1 rational graded knots
 x_j=-1+6(j/J)^2-4(j/J)^3, j=0,...,J.
Let phi_j be their nonnegative linear nodal hats, sum_j phi_j=1. Encode x into j
with probability phi_j(x); decode y with density rho_i(y)phi_j(y)/m_j,
m_j=integral rho_i phi_j. The induced density-ratio operator is
 K_i f(x)=sum_j phi_j(x)[integral rho_i(y)phi_j(y)f(y)dy]/m_j.
K_i is positive semidefinite, self-adjoint, Markov, an L2 contraction, and fixes
the known reference exactly. This is a weighted spline/Durrmeyer operator, not
a new operator family.

Audited scalar estimates for |theta|<=1, f_theta=exp(theta*x-psi(theta)):
 ||(I-K_i)f_theta||_2 <= C0 |theta| J^-2 ||f_theta||_2;
 <f_theta,(I-K_i)f_theta> <= C1 theta^2 J^-2 ||f_theta||_2^2.
Explicit conservative choices are C0=e^2(B+45/8), C1=9e^4,
B=4M/m+3L/(2m), from the independent scalar derivation.
The boundary grading is load-bearing: ordinary uniform endpoint hats have
||(I-K)x||_2 of order J^-3/2 under uniform reference and do not meet this lemma.

Tensor proof. Put E_i=I-K_i on the tensor product Hilbert space. Since the K_i
commute and each has spectrum in [0,1],
 (I-product_i K_i)^2 <= (sum_i E_i)^2
in operator order, by scalar joint spectral calculus. For F=product_i f_i and
w_i=||f_i||_2^2, define
 a_i=||E_i f_i||_2^2/w_i,
 b_i=<f_i,E_i f_i>/w_i.
Exact product factorization gives
 ||sum_i E_i F||_2^2 / ||F||_2^2
   = sum_i a_i + sum_{i!=j} b_i b_j
   <= C0^2 sum_i theta_i^2/J_i^4
       + C1^2 (sum_i theta_i^2/J_i^2)^2.
Let t=max_i r_i/J_i^2. Since theta_i=r_i v_i and r_i<=1,
 sum theta_i^2/J_i^4 <= t^2 sum v_i^2 <=t^2,
 sum theta_i^2/J_i^2 = sum (r_i/J_i^2)r_i v_i^2 <=t.
Thus retained-coordinate error is <= sqrt(C0^2+C1^2)t ||F||_2.

The elementary exponential-family identity psi''(u)=Var_u X<=1, X in [-1,1],
implies psi(2theta)-2psi(theta)+psi(0)<=theta^2. Hence
 ||F||_2^2=exp(sum_i[psi_i(2theta_i)-2psi_i(theta_i)])<=e,
so TV <= Cstar t with Cstar=(sqrt(e)/2)sqrt(C0^2+C1^2).
This is a MAXIMUM coordinate scale, not a sum epsilon/d allocation.

Inactive tail. Drop coordinates with r_i<=epsilon and regenerate them from
their known reference law. Since
 KL(P_theta_i||mu_i)=theta_i psi_i'(theta_i)-psi_i(theta_i)<=theta_i^2/2,
tensor tail KL<=epsilon^2/2. Pinsker gives tail TV<=epsilon/2. This keeps the
active threshold exactly epsilon and avoids dimension-dependent overhead.

Choose active J_i=ceil(sqrt(2 Cstar r_i/epsilon)), ensuring retained TV<=epsilon/2.
Each label count J_i+1 <=3 sqrt(2 Cstar r_i/epsilon) (Cstar>=1), so
 log_2 D <=(1/2)S_r(epsilon)
             +[log_2 3+(1/2)log_2(2 Cstar)]N_r(epsilon).
Product encoder is sampled coordinatewise and labels are packed into one mixed
radix integer. Decoder samples each reference-weighted hat law independently.
No exponential lookup table is needed; numerical integration/sampling and model
acquisition remain costs. All rational knots are explicit with O(log J) bits.
Finite digital output must be compared to a quantized target or use lazy reals:
an atomic floating point output has literal TV one from a continuous target.

Infinite product. theta lies in l2. The variance bound makes the finite product
likelihood martingale bounded in L2(mu), so it converges to a normalized likelihood
ratio F in L2. Equivalently, use the bounded sum of coordinate KL divergences.
Only finitely many active modes remain because r_i->0. The same finite retained
code, regenerated inactive product reference, and tail KL bound give the theorem.

Consequences. Exponential r_i=exp(-bi) yields sharp leading archive bits
[ln(1/epsilon)]^2/(4b ln2)+O(ln(1/epsilon)); polynomial r_i=i^-a yields
Theta(epsilon^-1/a), with constants dependent on m,M,L,a. The Gaussian N31
spectral law therefore has a dimension-uniform nonGaussian transfer under real,
checkable reference conditions. It does not apply to arbitrary noise/scores,
unknown calibration, arbitrary dependent observations, or changing supports.

Failure of spectral-only universality. Replace the continuous coordinates by
Rademacher observations with canonical binary exponential tilts. Any finite
d-dimensional experiment has exact classical archive D<=2^d for ALL epsilon,
whereas its bounded nonzero radii are the same as a continuous model whose
memory diverges with epsilon^-d/2. Singular radii alone cannot classify archive
cost across arbitrary experiments. Posterior support/regularity remains necessary.

quantum random-access entropy converse (Nayak99), posterior/leakage risk bounds
(Esposito et al. JMLR 25/23-0361), and positive weighted Durrmeyer approximation.

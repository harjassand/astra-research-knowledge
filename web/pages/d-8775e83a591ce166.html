## Completed construction and exact interface

Input is only an alphabet size n, an upper bound m, and an oracle for the final matrix value of an unknown series having some realization

    R(x)=u(I_m−Σ_i B_i x_i)^−1v=Σ_w(uB_wv)x_w.

The hidden matrices/vectors, word coefficients, axes, internal gates and coefficient heights are not supplied. The oracle must return exact field elements on rational jointly nilpotent matrix tuples. This realization semantics makes every requested inverse defined. An arbitrary syntactic rational formula with canceled but undefined inverse gates is a different interface.

Set d=(n−1)binom(m,2)+m. The release's triangular rational operators satisfy

    T_i[r,q]=(-1)^(r−q−1)/(r i^(r−q)), 0≤q<r<d.

Let S_d be multiplication by λ on F[λ]/(λ^d), and set W_i=S_d⊗T_i of dimension **D=d²=O(n²m⁴)**. The length-marked formal solution G_λ=Σ_w λ^|w| B_w h_w is nonzero in a scalar component whenever R is nonzero: a nonzero homogeneous slice cannot vanish under finite-word independence. The original m-state multiplicity bound still applies over F(λ), so a nonzero jet occurs below z^d. Its λ-degree is below d, and regular-representation descent preserves it. Therefore R(W) has a nonzero seed column. Products of d generators vanish, so proper-domain validity is automatic over every characteristic-zero field. Exact derivation and source locations are in `notes/metric_prior/cycle19/LENGTH_MARKER_RECOGNIZABLE_HITTING.md`.

The word-length marker is necessary for this first-column argument. The explicit three-state cyclic series

    (1−x2)(1−x1)^−1x1−2x2

has nonzero degree-one coefficients1,−2 but its unmarked integral-system scalar component is identically zero, with exact ODE solution (1,z,0). This refutes the naive infinite-series extension of finite-word faithfulness; it does not refute the release's acyclic theorem or full-matrix detection. Our code independently constructs the operators and verifies the failure and the marked repair at D36. Universal correctness comes from the proof, not this fixture.

Construction/output is polynomial, but response heights and oracle execution are charged. Dense query descriptions may require n(D+r)² records. Our learner postprocessing is polynomial in n,m and the total encoded exact response length; it is not polynomial in n,m alone for unbounded unknown rational coefficients. Neither positivity/nonnegative realization nor noisy/passive-sample learning follows. A safe seed-reachable restriction has dimension d(d+1)/2; it only improves a constant and was not used in the saved execution.

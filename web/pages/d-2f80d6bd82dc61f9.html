Computational certificates for Vector balancing in convex order

The directories below contain the certificate programs and recorded numerical outputs supporting the manuscript's Gaussian reference comparisons and numerical constants. Files were retained from the complete research archive without changing their mathematical content. No manuscript TeX is needed by the certificate entry point.

Main entry point (from the certificates directory):
    python3 reproduce.py

The Python certificate calculations called by this entry point use the standard library. Recomputing the continuum profile also requires a C++17 compiler, MPFR 4.x and GMP. The entry point detects common Linux and macOS compiler/library locations.

To recompute the Python scalar checks and validate the stored profile enclosures without recomputing the MPFR profile:
    python3 reproduce.py --skip-profile-recompute

The auxiliary reference/capacity certificate tools are in code/response-certificate/. The fourth-order rational calculation is in asymptotic/code/.

The manuscript's results/comparison_bounds.json is provided as a byte-identical alias of the saved results/second-pass/comparison.json (7,939 accepted rectangles and 2,305 subdivisions).

The recorded outputs are from the original certificate computations. Ancillary packaging checked file identity, Python syntax and exact coverage/positivity of the stored profile, but did not rerun the complete MPFR computation. The stored reproduction-summary.json describes its own original run.

# The finite decoder and the actual local bath interface

Worker rounding_spectral, 7 October 2026. Source2605.10943v1 is the actual BDL construction, with the X–Z realization and parameters admitted in cycle13. This note supplies two exact interface repairs and an actual local distinction between check commutation and energy commutation. It does not infer thermal robustness from a stable ground band.

## A correction depending only on the syndrome

In the source's decoder-modification and necessary-condition subsections (TeX3430–3491), the level2 code has fixed, finite size depending on ell. Its coarse-graining is replaced by a complete syndrome decoder. The text asks for correction of every error whose syndrome lies in a small ball. Read literally this is impossible: a logical error has zero syndrome, as does the identity.

The proof actually needs this property:

    if s=δh and |h|≤w_*, then h+f2(s) is a stabilizer.

Define f2(s) to be a global minimum-Hamming-weight 1-cochain satisfying δf2=s, with a fixed lexicographic tie-break. Define f2(0)=0. The decoder is a function of the syndrome only; it does not receive the error, its support, or the star in which a local representative exists.

If s=δh and |h|≤w_*, then |f2(s)|≤|h|. The closed error h+f2(s) has weight≤2w_*. If d2>2w_*, it is a stabilizer. This is ordinary minimum-distance decoding, not a claim that f2 lies in the same star as h.

For the actual source star X_(2),x, every qubit in the closed union of incident Tanner squares is adjacent to x. Each Tanner square has one X vertex, one Z vertex and two Q vertices, both joined to X. Hence w_*≤deg(x)≤7. The cycle13 distance bound is enormously larger than14 at level2, so d2>14 holds in the admitted family. A conservatively enlarged radius-two graph ball would have at most50 vertices and also fits the distance bound, but that extra enlargement is unnecessary.

The ordinary BDL propagation proof produces h2=e2+tilde e2 inside X_(2),x after comparing an error with the same error plus one fine qubit flip. The two alternating steps can be checked directly from the actual maps:

* R_Z: the coarse error on each Q block is its literal C_Q¹ parity. Corrections have only C_Z¹ support. A fine X-check cap projects to an old X stabilizer; a check in a Y_q edge projects into that one q; a Y_z face check has zero coarse projection. A difference confined to a fine X star therefore projects into the appropriate old X star.
* R_X: after the decoder's local X-syndrome correction, choose the auxiliary error-cleaning gauges by the same deterministic local linear contraction outside the affected parent x block. All unaffected block inputs are identical, so those gauges agree. Only neighboring Q blocks q~x can differ after restriction/gluing, and each becomes one coarse qubit. Thus the difference stays in the old X star. The syndrome correction itself depends on the observed syndrome; these auxiliary gauges are proof devices, not unseen data furnished to the decoder.

These checks agree with pde_spectrum9's independently reconstructed FINITE_LOOKUP_AND_WITNESS_GATE.md, which spells out all three R_Z fine-X types and the paired R_X gauges. The ordinary BDL syndrome-weight-contraction lemma remains a named primary prerequisite; this worker has read its full actual construction/proof, not executed an ell-sized patch.

Iterate this star propagation until level2. If the original coarse syndrome is zero at that level, the second coarse syndrome is δh2, with |h2|≤7. The new minimum-weight f2 removes it without a logical change. Lifting through the code maps preserves the logical class. Thus the source's sufficient stable-syndrome implication survives with a legal, specified base lookup.

This lookup is not spatially locally computable. Nodes on G2 arising from f2 cannot be charged to a nearby syndrome node. The thermal note therefore excludes G0,G1,G2 from the same-level domination proof and pays C_low=Σ_(i≤2)|V(G_i)|. The lookup can be implemented by exhaustive enumeration, but the constant-size C2 has O(ell^4) qubits. The word “constant” does not make that construction practical.

## Raw versus frequency-resolved errors

For a syndrome-diagonal H, let Π_ε be its energy projectors and P the stable-syndrome projector. The dressed logical observables commute with both. If [O,F]P=0, then

    [O,Π_(ε′)FΠ_ε]P
       =Π_(ε′)[O,F]PΠ_ε=0.

Summing over a fixed energy difference proves protection from every resolved Davies component of the raw coupling F. Its support may be larger than the raw support, and the number of components may change discontinuously with check penalties. Neither fact invalidates this argument.

For a single site, the CSS dressed logical X commutes globally with its X-type raw flip and is protected from its Z-type flip on the Z-sector good set; the dual statement holds for dressed Z. A Y flip changes each CSS syndrome exactly as the corresponding X/Z flip, so the joint good projector protects from all three Paulis. Alternatively the decoder-defined tensor factorization establishes this directly in each joint syndrome sector. By linearity arbitrary one-site operators are protected.

Chesi0907.2807v2 already proves

    Σ_ω F_ω†F_ω=lim_T (2T)^(-1)∫_(-T)^T F(t)†F(t)dt
                 =pinch_H(F†F).

For ||F||≤1 this is≤I. Weighted nonnegative rates bounded by γ give a positive jump map of Hermitian trace-norm≤γ and an anticommutator of the same bound. Hence one raw channel contributes≤2γ to ||L||_1, independently of frequency count. This is prior, with an independently checked algebraic identity.

## A literal interior-edge sector

The R_X local complex C_x is the cellular cochain complex of a doubled subdivision Y_x. Each old square is subdivided into N×N squares, N=(ell-1)/2, on each layer, with a belt on the old outer boundary. The source defines g_xq by restriction to the embedded radial Y_q graph (TeX1560–1643).

Choose a layer0 grid edge between(1,1) and(2,1) strictly inside a single old square, with N≥3. It is adjacent to exactly two cellular faces, the plaquettes immediately above and below it. It is neither a parent radial side nor part of the outer belt. Therefore its qubit Q=X_e anticommutes with exactly those two C_x² Z checks S1,S2. Its g_XQ¹ restriction vanishes. There is no direct C_x¹→C_z² map. Every other check commutes with Q. This is an actual code-template incidence, not an artificial matrix.

For the last, even R_Z step, interchange colors and transpose: choose the corresponding interior edge and Q=Z_e, with two X plaquettes. Both sectors give the same two-check algebra.

A realizable syndrome with s1≠s2 is obtained by applying a different interior edge adjacent to S1 and a third plaquette to a ground state. It excites S1 and the third check while leaving S2 unexcited. Applying Q then interchanges the S1/S2 excitations and changes nothing else. This proves that the opposite-sign two-state sector exists in the actual Hilbert space; it is not a freely supplied synthetic syndrome.

## Commuting with H0 is a strictly weaker condition

Let H0=Σ_a D_a and P_odd=(I-S1S2)/2. The local Hermitian term

    V_ε=ε Q P_odd

has norm|ε|. It is supported on the union of the two adjacent plaquettes (at most7 interior edge qubits), within a physical radius2 ball centered at e. Because Q anticommutes with S1,S2 but commutes with their product, V_ε is Hermitian. On P_odd, D1+D2=I. Outside P_odd the perturbation vanishes. Thus

    [V_ε,H0]=0,   but [V_ε,S1]≠0 and [V_ε,S2]≠0.

The ground code is unchanged, yet V_ε mixes two equal-energy syndrome sectors. Accordingly it cannot be treated as a scalar syndrome function by the stabilizer twirl/local-filling proof. This is an exact obstruction to weakening the theorem's check-wise commutation premise. It is not a counterexample to thermal memory for this Hamiltonian.

## Secular discontinuity is separate from memory failure

On the realizable opposite-sign sector above, H0 is a scalar and Q acts as a logical two-state σ_x for these **syndrome** states. Adding δS1 splits that sector. At δ=0 the resolved bath has one componentQ=σ_x, whereas at δ≠0 it has separate raising/lowering components. With rates continuous at zero and positive there, the corresponding secular generators have an O(1) difference as δ→0. For example on σ_y, D[σ_x](σ_y)=-2σ_y, while (D[σ_+]+D[σ_-])(σ_y)=-σ_y.

This is a genuine local-energy degeneracy in the actual template. pde_transport9 independently derives and checks the full discontinuity and a locally rotated noncommuting orbit. It blocks an automatic norm-continuity argument for Davies generators. It does not block THERMAL_ERASURE_EXTENSION.md, which proves protection and the Gibbs estimate directly for the new Hamiltonian and its own resolved jumps.

The unresolved broad problem is a generic noncommuting perturbation. It loses the classical syndrome energy law even when its ground band is stable.

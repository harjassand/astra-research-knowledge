JOINT d / SCORE-SLACK PARAMETER SEARCH
2026-10-08

Purpose and status

This is a small scalar optimization of the cycle4 finite Haar gate, not a new
mechanism. It varies the generator count d and score slack s jointly, keeping
the exact free-radius input C_r^2=16r^2-7r, the product-conjugate Bell
quotient, the stronger product-leg moment gate, and the same expectation and
concentration proofs. The selected point is checked with Decimal arithmetic
and source-parameter inequalities in joint_parameter_search.py and
rough_gate.py. The finite existence claim remains conditional on the
internally reconstructed free-radius and score-transfer arguments.

Exact objective for the two-factor witness

For r=2, K=4d, C=sqrt(50), and the exact free Bell fibre entropy is

  H(q) = 2 ln K - (ln K)/K - (ln 2)/2.

With score radius at most C+s, the purity identity gives

  S_min(Phi) >= -ln((K+(C+s)^2)/K^2).

Thus the certified pairwise entropy gap is bounded below by

  g(d,s) = (ln 2)/2 + (ln K)/K
           - 2 ln(1+(sqrt(50)+s)^2/K).

For each d, the search maximizes s subject to g(d,s)>=0.001 nats, then
minimizes the input register exponent after solving the expectation gate.
The r=2 screen covered every integer d from 62 through 150. A double-
precision scalar sweep identifies d=65 as the lowest-cost point; nearby
integer candidates were then replayed in Decimal arithmetic. This is a
bounded numerical optimization, not a symbolic proof of a global optimum.

Selected point and exact finite gate

Use d=65, r=2, K=260, and the rational slack s=0.165. The product-conjugate
Bell fibre sizes are K once, 2 repeated 16,900 times, and 1 repeated 33,540
times, for 50,441 distinct quotient labels. Direct entropy arithmetic gives

  H(q) = 10.7534024347087153899246186246185... nats,
  S_min(Phi), S_min(bar(Phi)) >= 5.37720472465807834499720242361237... nats,
  pairwise gap >= 0.00100701460744130006978622260621687... nats.

The scalar search's target-gap boundary at d=65 is s=0.1650756999509366...
and its estimated per-use register cost is 56,879.75 qubit-equivalent
dimensions. The selected rational s=0.165 stays below that boundary and
retains more than 7.0e-6 nats above the 0.001 target.

Here |B_1|=261, coefficient dimension n=522, eta=s/(2K)=
0.00031730769230769..., and e=s/(6(262)sqrt(50))=
1.48438446432290...e-5. The log net-cardinality bound is 591,419.8951.
The product-Haar concentration threshold for score failure at most 1/3 has
log2 N=66.86071..., well below the selected N.

Theorem 5.1 moment gate gives

  P = 12d+56 = 836,
  N_0 = 16(2d)^14 = 6299802217118862400000000000000,
  N = N_0 p^836.

The least even p passing the Decimal expectation check is

  p = 15,999,300,534,
  log2 N = 28,440.447407844605917...,
  input register per channel use = 2 log2 N
      = 56,880.894815689211834... qubit-equivalent dimensions,
  two-use product-conjugate witness = 113,761.789631378423668....

The flagged same-channel tensor-square lift adds one input qubit-equivalent
dimension per use. These are mathematical register dimensions; there is no
materialized matrix sample or efficient preparation.

These checks address the numerical hypotheses at d=65. They do not resolve
the conceptual open gate: Theorem 5.1 must apply unchanged to each hybrid

symmetry conventions preserved. This is internally reconstructed, not
externally validated.

For an exact safe comparator, d=64 and s=0.112 gives gap
0.00101184966559829... and 56,954.52659... qubits/use. Thus the selected
rational d=65 point saves about 73.63 register qubits per use, around 0.13%.
This is a modest parameter retuning, not a scientific significance claim.

tested range. The r=2 exact point is the one retained in the main result.

Reproduction and costs

Run:

  python3 evidence/joint_parameter_search.py
  python3 evidence/rough_gate.py

The first script performs the bounded float screen and exact selected-point
Decimal replay. The second independently checks the selected r=2 fibre,
entropy, score-net, concentration, expectation, hidden-constant, optional
trace diagnostic, and source gates. The optional Bell trace computation is
not used in the entropy or probability conclusion.

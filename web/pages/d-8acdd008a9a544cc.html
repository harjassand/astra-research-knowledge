# Exact variable-dual-frame interface and one retained-collision control

Cycle17, 7 October2026; hessian_bridge12. This note records the investigated constructive interface outside the constant dual frame used in cycle16. It does not classify all variable frames or assert a successful reduced HC4 potential.

Let E(x,y) be any polynomialGL3 matrix with constant nonzero determinant. The actual five-dimensional source map is `T(b,Z)=(b,E(b)^T Z)`. Its polynomial inverse uses E^-T. Write `gbar=E g`, `hbar=E h`, `Fbar=hbar+t gbar`; the transformed actual potential is

`fbar=(gbar·Z)²+13 gbar·Z+2 hbar·Z`.

The complete Hessian is a2+3 block with dual block `2gbar gbar^T`. The all-free rank-one block identity gives

`det Hfbar=32[Jac Fbar(b,t)]² |_(t=gbar·Z+13/2)`.          (V1)

All nonlinear frame corrections in the base block are present; the mixed block contains the derivatives of E as well. The vector gbar is unimodular. Thus substitution `t=gbar·Z+13/2` is injective on C[b,t] (a polynomial Bezout row gives a section), and a square equal to a nonzero constant makes its polynomial factor a constant. Therefore

`det Hfbar is a nonzero constant iff Fbar is Keller for ALLt`. (V2)

This is the load-bearing variable-frame test. Its coefficient equations are exact:

`det(gbar,gbar_x,gbar_y)=0`,
`det(gbar,gbar_x,hbar_y)+det(gbar,hbar_x,gbar_y)=0`,
`det(gbar,hbar_x,hbar_y)=c!=0`.

They impose projective rank at most1 on gbar, the mixed compatibility coefficient, and the constant final Jacobian. Polynomial frame invertibility alone supplies none of these equations. If a frame exposes a constant unit gbar component, (V2) still has to hold; this is the point at which a nominal polynomial pivot can fail the full-source requirement.

The actual zero-dual witness pair is retained exactly when `E(bplus) w=E(bminus) w`, with old common dual gradient `w=(-1/2,0,0)`. Original base gradient is zero at both points. General dual translations add their separately charged base-gradient condition; no collision invariance is assumed for arbitrary frames.

## Executed outside-orbit chart: legal inverse and collision, wrong full determinant

Take

`E=I+e3 e1^T P(b)`, `P=(x²−1)²`.

The actual source chart sends `(z1,z2,z3)` to `(z1+P z3,z2,z3)`, with subtractive global inverse and Jacobian1. P vanishes at both old witness bases, so the exact common gradient remains `(0,0,−1/2,0,0)`.

But `Fbar=F+e3 P F1`, and the complete target-Jacobian defect is

`JacFbar=−2[1+F1 δ3P]`, `δ3=(JF)^−1 e3`.

The own literal checker reconstructs this identity. Via (V1), its full5D Hessian determinant has exact values128 at `(b,Z)=(0,0,0)` and4615683200 at `(b,Z)=(2,0,0)`. Thus it fails source constancy before any selected-level elimination or collision transfer can be advertised. This is an exact refutation, not pointwise evidence for a universal positive claim.

One independently computed invariant is useful for selecting more substantial frames. For a nonzero constant target vectorq, write the first two components of `(JF)^−1q` as `a0+t a1,b0+t b1`. Literal algebra gives

`a0 b1−a1 b0=−3(1+xy)[−2q1 x³+q2 x²(1+xy)+q3(1+xy)³]²/4`. (V3)

The three bracket polynomials are linearly independent, so this is nonzero for every nonzero constantq. Consequently its lifted derivation has no nonconstant polynomial BASE invariant: a base invariant would have gradient annihilated by two independent coefficient vectors. In particular a single variable transvection `E=I+q e_j^T P(b)` with q_j=0 cannot preserve a constant target Jacobian unless P is constant. This is an exact substantial class condition but not a theorem about coordinated transvection words with nonconstant intermediate Jacobians.

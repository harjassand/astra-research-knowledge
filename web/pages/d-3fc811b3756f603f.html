# Falsification attempts, failures, and scope limits

## Generalizing the rectangle theorem to arbitrary masks fails

The proof needs rectangles with both side lengths at least \(D\). A mask of
\(N^{15/8}\) isolated entries has no such efficient cover from this argument.
Padding each singleton to a \(D\times D\) tile yields total cover volume

\[
N^{15/8}D^2=N^{19/8},
\]

outside the theorem. Directly evaluating those entries costs
\(N^{15/8}D=N^{17/8}\), also not subquadratic. Thus this result does not solve
the arbitrary-mask target.

## Block-component recognition has a strict promise test

For a mask supplied only as an edge list, the special case in which every
nonisolated connected component is a complete bipartite graph can be
recognized in \(O(|W|\operatorname{polylog}N)\) bit operations. A component
with row class \(R\) and column class \(C\) is complete exactly when its edge
count is \(|R||C|\). A three-edge path on two row and two column vertices
fails this test (three edges versus four), so it cannot be treated as one
rectangle. This is a deliberate rejection, not a theorem counterexample.

## Exact coefficients: do not overclaim rational descent

The release's Remark 5.2 is phrased as though the Nullstellensatz turns a
complex solution of the rank-decomposition equations into a rational solution.
That implication is false for general rational polynomial systems; for
example, \(x^2+1=0\) has a complex solution and no rational solution. This
does not refute the release's complex exponent theorem or prove that this
particular tensor variety lacks a rational point. The
structured algorithm needs only coefficients in a finite extension of
\(\mathbb Q\): because the rank equations define a nonempty variety over
\(\mathbb C\), they define a proper ideal over \(\overline{\mathbb Q}\) and
have an algebraic point there. Any finite tuple of algebraic coefficients lies
in one number field. The proof and cost ledger use this weaker, valid claim.

## Base-kernel acquisition remains unmaterialized

The pinned theorem proves an asymptotic exact arithmetic algorithm but does
not publish the fixed rank decomposition used by its final recursion in the
PDF. For fixed \(\xi\), one can enumerate candidate algebraic decompositions
and verify their tensor identities; the exponent theorem guarantees that a
candidate with the needed exponent eventually appears. This setup search halts
but no useful time, certificate-size, field-degree, or coefficient-height
bound is supplied. The theorem therefore exposes an additive setup charge
\(A_\xi,S_\xi\), not a practical executable kernel. No claim is made that
these constants are small.

## Finite check scope

`finite_check.py` used exact Python integer products to check tiling, residual
dot products, duplicate-output removal, and a rectangle-promise rejection on
one seeded finite fixture. It used classical multiplication, not the release
kernel. It does not verify the 9/4 theorem, the recursion's number-field bit
growth, an acquisition bound, asymptotic complexity, or external priority.

No counterexample to the stated conditional rectangle-cover theorem was found.

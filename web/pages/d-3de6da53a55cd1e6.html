## Precise improvement

Use the canonical affine linear Frege system in the primary tables labelled `Fig: FL_e`, `Fig: linear`, `Fig: contraction-free logics` (Tables6–8 in v2 HTML), with ordinary tree formulas, DAG-like proof sequences, and no unrestricted substitution inference. Let L count source proof steps. The certified canonical bound is13V+93L; cached conservative repair adds at most30V_A+1. Suppose all formulas used by the proof share a syntax DAG with V nodes. There exists an ordinary intuitionistic affine linear sequent proof of the Chu translation of the conclusion whose **total formula occurrences over all sequents** are O(V+L). Formulas in that output may be exponentially long when expanded as trees. The theorem bounds lines, not explicit output bytes or the time needed to print them.

For a conservative conclusion A, simultaneous cached conservativity repair gives O(V_A) additional formula occurrences, where V_A is its syntax-DAG size; the older O(|A|^2) bound would already suffice for the intended hard family. Combining this with finite-proof-skeleton compression yields the bound O(L+|A|) on intuitionistic proof lines. Thus the primary hard formulas Theta*_n require exponentially many affine Frege lines, even when source proof formulas are arbitrarily large.

## Lemma1: the syntax graph carries all recursive work

Take D=N=bottom. Compute two nodes t(F),s(F) per source node F by the primary's bounded constructor templates. The resulting shared graph has O(V) nodes. In particular implication creates (t(B)->t(C)) AND (s(C)->s(B)), and its dual is t(B)*s(C); no tree expansion is necessary to name them.

Cache one sequent P_F: t(F),s(F)=>bottom per source node. Each atom/constant has a bounded proof. For AND, two cached child proofs are followed by left-AND and left-OR. For OR, use the corresponding dual additive rules. For fusion, the first implication conjunct in its dual and the appropriate child pairing suffice. For implication B->C, use identity s(C)=>s(C), cached t(B),s(B)=>bottom, left-implication, left-AND, then left-fusion. For !B, use identity and left-implication on !t(B) and !t(B)->bottom. Every step adds boundedly many sequents with boundedly many context formulas.

The proof is a sequence, so an earlier P_F may be cited by several later inferences. This is explicitly allowed by the source's DAG-proof definition. It duplicates neither a hypothesis inside a sequent nor a linear resource. No unrestricted contraction rule is inserted.

Cache the four negation-duality directions per needed F as well. They use P_F and unit rules with bounded overhead. If an axiom template calls for neg F not already present in the input graph, add this bounded number of wrapper nodes per axiom instance. Total recursive closure remains O(V+L), not the tree size of an intermediate formula.

## Lemma3: finite proof skeletons admit small formula DAGs

This is older proof-complexity machinery; no novelty claim is made. Here is the exact reconstruction needed for this application. Fix the rule/axiom used at each source line and its earlier premise references. Give each rule occurrence fresh schematic metavariables. Create one root variable per proof line, equate each schema conclusion with its line root, and equate each schema premise with the root it cites. Equate the final root with the literal target A. Since the rule inventory is finite and every schema has fixed size, there are O(L+|A|) constructor nodes and equations.

The supplied original proof is a solution by finite formula trees. Therefore congruence closure cannot identify distinct constructors/atoms or create a directed constructor cycle. Quotient the existing constructor nodes by forced equalities, propagating equal-constructor child equations. Replace any unconstrained remaining metavariable by one ordinary atom. The acyclic quotient is a formula DAG with O(L+|A|) nodes and a ground solution of every schema equation. Reading its line roots yields another legal proof with the same step skeleton and exactly the target A.

This uses no object-level substitution inference and no object-level contraction. The canonical schemas have no eigenvariable or atom-only side conditions. Closed necessitation is the unary schema F/!F on earlier theorems, which the equations preserve. An occurs check is essential; cyclic rational terms are not formulas. Original arbitrary atoms not occurring in the target may merge, since the schemas impose no distinctness requirement.

Combining Lemmas1–3 and conservativity sends a short affine Frege proof of Theta*_n to an intuitionistic proof with O(L+|Theta*_n|) formula occurrences. The latter family has a named prior 2^(n^Omega(1)) intuitionistic lower bound, while |Theta*_n|=poly(n). Therefore L is at least 2^(n^Omega(1)). The complete finite-template gates pass. ## Fresh definitional EF: unfold first

Specify extensions e_i <-> F_i as the conjunction of both implications, with e_i fresh in earlier lines and F_i, definitions acyclic and the final target extension-free. Expand definitions by redirecting atom nodes to their earlier defining roots in a shared graph. The common DAG and ordinary Frege step count stay O(S), where S is the explicit EF certificate size. Each extension axiom becomes (F->F) AND(F->F), with a fixed Frege theorem proof. Other rule instances stay instances. Apply the transfer above.

Directly translating e<->F is not valid reasoning: s(e)=bottom while s(F) need not equal bottom. The independently retained e<->p*p counterexample forbids this shortcut. Unfolding first avoids it. This proves the explicitly specified fresh acyclic definitional extension convention used in Jalali2006.09705v2 Definition3.9. Other substitution proof systems require their own interface. In fact global expansion replaces each definition by a constant number of Frege lines even when its tree is huge, so an E-line EF proof gives O(E) ordinary Frege lines. Thus both EF symbol-size and EF line lower bounds follow under this convention.

The advance is a proof-compilation method: charge the number of distinct recursive obligations rather than their repeated textual occurrences. It gives an internally checked resolution of the precisely stated recent affine line/EF direction by combining a recent translation with old lower bounds. ## Sequent occurrence-line extension, separately reconstructed

[Independent construction](../logic_prior14/cycle14/SEQUENT_LINE_EXTENSION.md) gives a Frege simulation with O(ell^4) rows and O(ell^4+|A|) formula-DAG nodes for an affine sequent proof of A with ell total formula occurrences. Root read and independently reconstructed its load-bearing steps:

1. Freeze principal occurrences and multiset wiring. The same constructor quotient works with one variable per occurrence. A rule's premise-slot count is at most twice its conclusion-slot count plus a constant. No empty sequent is derivable under the sound Boolean interpretation; hence rows<=ell. Promotion requires explicit bang constructors on each relevant antecedent root. The graph is O(ell+|A|), with the same target and contexts.
2. Pack contexts as fusion and par, keeping empty units. O(m^2) rebracketing/permutation moves on m occurrences, each lifted through O(m) constructors, cost O(m^3) Frege rows and new DAG nodes. At most ell rules give the safe ell^4 bound. Internal formulas are opaque roots throughout.
3. Every nonpromotion rule has finitely many packed context/empty-context variants. They are standard-sound fixed inference schemata: unpack the interpreted closed premises, apply the original rule, repack. Explicit derived par unpacking is valid: from identities derive =>neg X,X and =>neg Y,Y, right-fuse the negated formulas, then left-negate to obtain X+Y=>X,Y. Repacking reverses the corresponding moves using left negation twice, left fusion and right negation. Fixed strong-completeness derivations cost a presentation-dependent constant. This is not an uncharged arbitrary-size equivalence theorem.
4. Promotion is not packed into an arbitrary context atom. For Q=product_i !A_i, build Q->!Q in O(m) steps via !4 and the fixed theorem !X*!Y->!(X*Y). The latter follows by two identities, L! on each, right fusion, promotion under the two bang assumptions, left fusion, right implication. Necessitate the already closed theorem Q->B, use !K to get !Q->!B, then compose with Q->!Q. Empty context uses 1->!1. This pays the actual side condition.

Composing with the adopted Chu transfer and conservative repair gives O(ell^4+|A|^2) intuitionistic occurrence-lines. Therefore Theta*_n requires 2^(n^Omega(1)) **total formula occurrences** in affine sequent proofs as well. It does not bound the number of rows when unbounded contexts are free.

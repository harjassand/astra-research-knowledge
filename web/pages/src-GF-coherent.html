## 3. Reconstructing the half-diamond constant

Write \(N\le_{\mathrm{CP}}T\) when (T-N) is completely positive. Use unnormalized output-first Choi matrices. For CPTP \(N,T\), let

\[
\epsilon=\tfrac12\|N-T\|_\diamond.
\]

The channel-discrimination SDP in Watrous (2009), Section 4, printed pp. 14–15, gives

\[
\epsilon=\min\{\|\operatorname{Tr}_{out}Z\|_\infty:
Z\ge0,\ Z\ge J(N-T)\}.
\]

Choose optimal \(Z\). Let the CP maps with Chois \(Z\) and (Z-J(N-T)) be \(\Phi_+,\Phi_-\). Since (N-T) is trace-annihilating, their input effects agree, say \(A\le\epsilon I\). Add to both the same CP filler

\[
L(X)=\operatorname{Tr}[(\epsilon I-A)X]\sigma
\]

for a fixed output density matrix \(\sigma\). Then

\[
N-T=\epsilon(E_+-E_-),\qquad
N\le_{\mathrm{CP}}T+\epsilon E_+,
\]

with both \(E_+,E_-\) CPTP on the same complete local boundary. The filler construction is local because the SDP was posed on \(D_iB\), before tensoring identities on other private reservations.

Conversely, \(N\le_{\mathrm{CP}}T+bE\), with \(E\) a channel, implies

\[
E_-=(T+bE-N)/b
\]

is a channel and \(\|N-T\|_\diamond\le2b\). Thus with reference coefficient fixed to one, the least additive majorant cost is exactly \(\epsilon\). There is no generic improvement of the additive constant by renaming it a channel-order cost.

This is an upper domination, not a convex decomposition of the actual channel. In particular it supplies no actual fault flag and no ideal CP subchannel.

## 5. Stronger operation: the optimized weighted CP envelope

The source already permits general \(a,b\). The substantive additional calculation is to optimize that freedom against the actual ideal tester value and evaluate it exactly for coherent operations.

For \(a\ge0\), define

\[
b_a(N\mid T)=\inf\{b\ge0:\ N\le_{\mathrm{CP}}aT+bE,\ E\ \mathrm{CPTP}\}.
\]

The same filler argument gives the exact SDP

\[
b_a=\min\{b:\ Z\ge0,\ Z\ge J(N)-aJ(T),\ \operatorname{Tr}_{out}Z\le bI\}.
\]

Its dual is

\[
\max_{\rho\ge0,\operatorname{Tr}\rho=1,\ 0\le W\le I_{out}\otimes\rho}
\operatorname{Tr}[(J(N)-aJ(T))W].
\]

Strictly feasible finite-dimensional primal/dual points give strong duality. For fixed \(\rho\), conjugating by \(I\otimes\sqrt\rho\) makes the inner maximum the positive-part trace of the corresponding output difference on a purified input. That output has trace (1-a). The Hermiticity-preserving diamond norm can be maximized on a pure state, so

\[
\boxed{b_a(N\mid T)=\tfrac12\big(\|N-aT\|_\diamond+1-a\big).}\tag{W}
\]

The **tester-sensitive majorant cost** is

\[
\beta_f(N\mid T)=\inf_{a\ge0}\{af+b_a(N\mid T)\}.
\]

It never exceeds \(\min\{1,f+\epsilon\}\): choose \(a=0,b=1\), or \(a=1,b=\epsilon\). It equals \(f\) for \(N=T\). For a genuine mixture (N=(1-r)T+rE), choosing (a=1-r,b=r) recovers \((1-r)f+r\). At fixed \(a=1\), equation \(W\) reduces exactly to the source half-diamond cost.

For arbitrary multiple slots, choose their \(a,b_a\) in the first-erasure formula. The scalar optimization can be done backwards in the parent's own chronological order:

\[
x_m=f_i,\qquad x_{k-1}=\inf_{a\ge0}\{a x_k+b_a(N_{ik}\mid T_{ik})\}.

Endpoint infima are handled by finite approximants and continuity. This dynamic scalar optimization is valid despite global interleaving, because the first-erasure polynomial factors parent by parent. ## 6. Closed-form coherent angle law

First take \(N=\operatorname{Ad}_U,T=\operatorname{Id}\) on the complete local boundary. Let

\[
\nu=\min_{\rho\ge0,\operatorname{Tr}\rho=1}|\operatorname{Tr}(\rho U)|,
\quad \theta=\arccos\nu\in[0,\pi/2].
\]

This is the distance of zero from the convex hull of the eigenvalues of \(U\), expressed as an angle. It is invariant under a global phase. On a purified input, the two weighted output states are pure with overlap \(\operatorname{Tr}(\rho U)\). Their difference has trace norm

\[
\sqrt{(1-a)^2+4a(1-|\operatorname{Tr}(\rho U)|^2)}.
\]

The overlap must be minimized over all input densities. Replacing it by normalized Choi overlap \(|\operatorname{Tr}U|/d\) is false in general: \(U=\operatorname{diag}(1,1,-1)\) has normalized Choi overlap \(1/3\), but numerical-range distance zero and an orthogonal input/output witness, hence \(\theta=\pi/2\).

Maximizing over \(\rho\) and substituting in \(W\),

\[
b_a(\theta)=\tfrac12\left(1-a+\sqrt{(1-a)^2+4a\sin^2\theta}\right).
\]

An explicit one-variable minimization gives

\[
\boxed{\beta_f(\theta)=H_\theta(f)
=\sin^2\!\left(\min\{\pi/2,\arcsin\sqrt f+\theta\}\right).}\tag{A}
\]

For \(0<f<\cos^2\theta\), set \(c=\cos\theta,s=\sin\theta\). The minimizer is

\[
a_*=c^2-s^2+\frac{cs(1-2f)}{\sqrt{f(1-f)}}\ge0,
\]

and the value is \((c\sqrt f+s\sqrt{1-f})^2\). If \(f\ge c^2\), \(a=0\) yields value one and is optimal. For \(f=0\), the infimum is (s^2), approached as \(a\to\infty\). For \(\theta=0\), the value is \(f\).

This envelope is exact: a two-dimensional reference state \(\sqrt{1-f}|0\rangle+\sqrt f|1\rangle\), accept projector \(|1\rangle\langle1|\), and the real rotation with matrix \(\begin{pmatrix}c&-s\\s&c\end{pmatrix}\) attain the nonsaturated expression. If \(f\ge c^2\), choose reference acceptance \(c^2\le f\) and rotate to acceptance with probability one. Tensor independent instances gives product equality over the broad local-tester class. Exact equality for every particular Schur reference is not asserted.

If an actual slot has the form \(N=\operatorname{Ad}_U\circ T\), or \(N=T\circ\operatorname{Ad}_U\), compose the local CP majorant with \(T\). The same \(b_a(\theta)\) is a valid upper envelope. A specified local common dilation followed by a uniformly bounded residual unitary also works after composing preparation/isometry and discarding its environment, provided every returning environment is retained in the boundary.

For multiple local coherent slots, \(A\) composes exactly as

\[
H_{\theta_1}(H_{\theta_2}(f))
=H_{\min\{\pi/2,\theta_1+\theta_2\}}(f).
\]

Consequently the source first-erasure argument proves the stronger local product

\[
\boxed{F_R\le
\prod_{i\in R}
\sin^2\!\left(\min\{\pi/2,\arcsin\sqrt{f_i}+\sum_k\theta_{ik}\}\right) I.}\tag{C}
\]

This is a genuine strengthening for qualified coherent defects. For \(f_i=0\), it gives \(\sin^2(\sum_k\theta_{ik})\), instead of a generic linear half-diamond floor. For small angles it is \(f_i+2\sqrt{f_i}\delta_i+\delta_i^2\) to leading orders, with \(\delta_i=\sum_k\theta_{ik}\). The law is an upper comparison; it still provides no stochastic physical fault flag or exact ideal CP minorant.

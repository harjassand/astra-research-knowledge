# Decision algorithm for barrier-aware pulse design

This procedure consumes an acquired stochastic reduced model and returns a
candidate in-vitro pulse design. It does not infer a gene-regulatory network
from a small marker panel. Model acquisition and biological validation are
explicit resource costs and decision gates.

## Inputs and gates

1. Define the source, target, and avoid fates operationally. Record the live
   reporter panel and endpoint assay confusion matrix: sensitivity \(s\),
   specificity \(c\), with \(s+c>1\).
2. Acquire a stochastic model \((b(x),A(x))\), a source-to-target
   minimum-action path, and feasible actuator vector fields \(G_j(x)\) from
   pilot lineages or a validated external model. Record cells, markers, time
   points, imaging or sequencing expense, and failed tracks.
3. Calibrate the commanded-to-delivered pulse, amplitude and time-dependent
   control error, trigger-clock jitter, toxicity, and safe range. Preserve
   calibration uncertainty instead of treating it as zero.
4. Set a horizon \(T\), a required transition probability \(p_*\), a delivered
   dose budget, observation budget, and resource weights. Include the cost of
   model acquisition and assay calibration.
5. Stop the scalar-barrier procedure if the source is not metastable over
   \(T\), transition times are not approximately exponential after
   intrabasin relaxation, several paths are comparably likely, or the state
   omits memory relevant to the pulse. Fit a multi-path or non-Markov model
   instead.

## Kernel-based pulse construction

For each credible path \(x_*(t)\), calculate

\[
\kappa_j(t)=\frac12G_j(x_*(t))^\top A(x_*(t))^{-1}
(\dot x_*(t)-b(x_*(t))).
\]

With \(L\) time bins, \(m\) independent lineage measurements per bin,
sub-Gaussian observation scale \(\sigma_o\), and familywise error \(\alpha_o\),
use the simultaneous band

\[
\delta_o=\sigma_o\sqrt{\frac{2\log(2L/\alpha_o)}{m}},
\qquad
\underline{\kappa}_{j,r}=\widehat{\kappa}_{j,r}-\delta_o.
\]

Keep uncertainty in the path and fitted parameters separate from this
readout-noise band. Do not truncate negative values until the actuator's sign
constraint has been applied.

For an \(L^2\) energy budget \(E\) and nonnegative dose, use the positive part
of the lower-confidence kernel and set

\[
u_r=\sqrt{E}\,
\frac{\max\{\underline{\kappa}_{j,r},0\}}
{\|\max\{\underline{\kappa}_j,0\}\|_2}.
\]

Apply an amplitude cap by clipping this waveform and solving for its
multiplier by bisection. For an \(L^1\) dose cap, allocate to bins in descending
order of positive lower-confidence susceptibility. If multiple paths remain
credible, optimize the worst-case action reduction across that path set; a
single-path pulse can fail when the dominant path switches.

For multiplicative actuator gain error \(\eta\), debit a one-sided lower
confidence factor for \(1+\eta\). For independent timing jitter \(\delta\),
evaluate the kernel autocorrelation
\[
R(\delta)=\langle\underline{\kappa}(\cdot),
\underline{\kappa}(\cdot-\delta)\rangle
\]
using the measured timing distribution. The small-jitter expansion
\[
\mathbb E R(\delta)\approx\|\underline{\kappa}\|_2^2
-\frac{\mathbb E[\delta^2]}2\|\dot{\underline{\kappa}}\|_2^2
\]
is an expected-gain approximation, not a confidence guarantee. A robust
promise needs a one-sided quantile or worst-case support bound. For additive
process error with covariance \(C\), debit the one-sided term
\(z_{1-\alpha_a}\sqrt{\kappa^\top C\kappa}\). Reject a schedule when the
remaining lower-confidence action decrease is nonpositive.

## From action to finite-horizon decision

For sustained quasi-static dosing, estimate the escape rate from censored
first-passage data and use
\[
p(q,T)=1-\exp[-T k(q)].
\]
Integrate over the calibrated dose-error distribution. For a time-localized
pulse, use a validated finite-horizon action and prefactor, or calculate the
finite-state reduced-model transition probability by uniformization or a
matrix exponential. A stationary Kramers rate must not be applied to a pulse
shorter than intrabasin relaxation without testing that approximation.

The large-deviation statement is only
\[
\varepsilon\log p \longrightarrow -S
\]
under the model's small-noise asymptotic conditions. It is not an exact
finite-noise probability. Choose the lowest-cost feasible plan by minimizing
\[
J=c_u\int u_c(t)^2\,dt+c_TT+c_omL+c_yn+c_{\rm cal}N_{\rm cal}
\]
subject to \(p_{\rm model,L}\ge p_*\), viability constraints, and specified
observation and control error budgets. The kernel calculation is linear in
the number of time bins per actuator; this does not make high-dimensional
drift or path inference inexpensive.

## Assay and timing observability

For a binary endpoint assay, let \(Y=1\) denote a positive call and \(p\) the
true target fraction. If sensitivity and specificity are known,
\[
p=\frac{\mathbb E[Y]+c-1}{s+c-1}.
\]
With \(n\) independent cells, the Hoeffding half-width after assay correction
is at most
\[
\frac{1}{s+c-1}\sqrt{\frac{\log(2/\alpha_y)}{2n}},
\]
so precision \(\delta\) requires
\[
n\ge
\frac{\log(2/\alpha_y)}
{2(s+c-1)^2\delta^2}.
\]
This excludes the cells used to calibrate \(s,c\), well-level dependence,
cell loss, and lineage-track failures. If \(s,c\) are estimated, propagate
their joint confidence region through the inversion.

For path-alignment feedback, a reporter with local slope
\(v_y=|d h(x_*(t_*))/dt|\) and averaged measurement standard deviation
\(\sigma_y/\sqrt{m}\) gives approximate trigger-time standard deviation
\(\sigma_t=\sigma_y/(\sqrt{m}v_y)\). Feed that jitter distribution into the
timing debit. A shallow reporter slope requires more observations or another
marker; endpoint sensitivity alone does not give timing observability.

## Falsification protocol

Randomize lineage founders to the path-matched schedule, a uniform schedule,
and a fitted constant-dose schedule at equal integrated dose and equal
cell/time resource. Record delivered waveform per well, blind endpoint
scoring, and report all missing tracks. Reject the single-path model if the
assay correction erases its predicted gain, if pulse latency exceeds the
susceptibility window, if matched pulses do not outperform equal-resource
controls, if measured actuator error exceeds the debit, if lineages use
several comparable paths, or if the fate does not persist after withdrawal.
Any of these outcomes can falsify the proposed biological use while leaving
the conditional action-sensitivity calculation intact.

# Follow-up: one random boundary current and inverse moments

Read notes/rank_pde/proof.md and results/root_rank/conditioning_moments.md on2026-10-06. Those are independently derived programme claims, not claims from the papers below. This is a targeted primary-source novelty audit, not an exhaustive bibliometric proof of novelty.

## Exact candidate interface
Known finite-dimensional affine span of scalar piecewise-analytic conductivities on bounded connected n≥2 domain; partial open boundary access Σ; one Gaussian mean-free current g with injective trace-class covariance; entire voltage trace Λ(σ)g. Same draw should identify EVERY σ in the admissible positive parameter domain, be an immersion everywhere, and have compact inverse Lipschitz constant with ALL finite inverse moments. Finite input/detector subspaces may be chosen for any prescribed finite moment order, with no effective dimension or singular-value lower bound.

## Gaussian-design and one-shot antecedents
Alberti, *Non-zero constraints in elliptic PDE with random boundary values and applications to hybrid inverse problems*, arXiv2205.00994v2,13Oct2022. PDF recovered. Theorem1 gives high-probability uniform-in-space nonzero constraints from N independent groups of boundary functions; output is internal hybrid data. Bound1−C1N^d exp(−C2N^(1/n)) with fixed positive nonvanishing threshold. Constants depend on prior geometry, ellipticity/regularity, constraint and sampling law. This is relevant precedent for covariance dependence, quantitative Runge, random rich boundary fields and discriminating tests, but not a one-current boundary-only inverse Lipschitz/all-moments result.

Boullé–Halikias–Otto–Townsend, *A zero-one law for one-shot system identification*, arXiv2607.15832. Primary downloaded PDF manuscript compiled20Jul2026; arXivv1 HTML header17Jul2026 (HTML body oddly says compiled24Aug2026, so cite savedPDF for theorem details). MainTheorem1 and Lemma1 verified. Unknown governing coefficients multiply prescribed analytic dictionary terms; observed response must permit evaluation of dictionary D_i(u,f). For a fixed true coefficient vector c*, if one input yields independent evaluated terms, almost every nondegenerate Gaussian input does. The theorem’s fixed-c* null set does not automatically yield one event uniform over uncountably many parameter vectors. Its discussion explicitly leaves quantitative noisy stability and partial observations open. Thus important nearest recent motivation, not direct coverage of boundary-only uniform theorem.

## Known ingredients vs potentially new composition
Known: finite-codimension localized potentials, monotonicity, visible-sign argument, infinite positive/negative eigenvalue results in Helmholtz, Sontag's parameter/incidence dimension counting, analytic Gaussian null sets, compact injective-immersion Lipschitz stability, fixed-operator Gaussian small-ball bounds and deterministic-net union bounds.

Our current reconstruction: use finite-codimension localization to establish infinite rank for every normalized secant and tangent in a fixed conductivity span; use compact singular-value lower bounds for each fixed r and polynomial entropy exponent2d to obtain random inverse moments of all orders; then preserve any prescribed r by uniform input/output truncation. The elementary Gaussian-net bound can plausibly be existing general folklore or theorem; absent search hits is not evidence otherwise. The PDE composition appears more specific than verified sources, but historical novelty remains unestablished.

Scientific novelty boundary should be phrased as a candidate *uniform one-excitation boundary-recovery theorem with integrable random conditioning*, proved from explicit established prerequisites. Do not claim first one-measurement conductivity recovery, first Gaussian elliptic experiment design, or dimension-efficient/noise-robust practical gain. A theorem composition can be useful even if each ingredient is established; independent source coverage remains required before calling it new.

## Independent construction/check of moment mechanism
For any compact normalized-secant family T_K and injective trace-class C, if every T has infinite rank, each σ_r(TC^(1/2))>0 and compactness makes its infimum positive. The same covariance coupling is not an independence obstacle: cover operators deterministically and on ||g||≤R approximate Tg using operator norm. Fixed-r Gaussian density and ball-volume bounds give t^r, net entropy costs t^(−2d), norm cutoff costs logarithmic factors. Tail integration gives p<r−2d. Choosing larger r for each p proves all finite moments without claiming uniform bounds as p↑∞. This derivation checks the central inference; it is not independent external novelty validation.

A rank-one family Tδ=δI in one output coordinate gives inverse Gaussian absolute-value conditioning with divergent p≥1 moments. Hence pairwise nonzero response operators alone cannot give the claimed all-moments theorem: unbounded available response rank is load-bearing. Conversely, all-moments can coexist with disastrous constants when singular values collapse; no exponential moment or economic complexity follows.

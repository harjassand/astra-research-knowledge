## Robustness and cost findings retained

Normalized commutator powers p_k=2^(-k)[x1,x2]^k have coefficient l1 norm one and formula size 10k+1. Their first-column leading coefficient is (-1)^k/[8^k(3k)!]. More strongly, every output entry at any dimension d obeys the analytical bound

    max |entry| < e * (ln(2d))^(2k) / (2^k (2k)!).

At polynomial dimensions, this forces increasing precision under an adversarial entrywise absolute-error oracle. This does not prove floating-point failure, relative-error instability, or failure of exact identity testing. A bounded-norm periodic control obtains output magnitude one on these commutators but has its own exact polynomial alias and is not universally faithful.

The matrices can be integerized by D_rr=r!*lcm(1,...,n)^r. This exact similarity preserves detection and removes the observed attenuation in that coordinate basis, but charges large entries; it is not a numerical stability theorem. A recurrence applies each structured generator in linear arithmetic time in d. Using it on a supplied formula tree changes the oracle interface to white box, where polynomial methods already exist.

The dense payload calculation explicitly avoids creating huge tuples.

The atom theorem uses the five-row K/S identity proof of T, one disjunction-introduction axiom, and MP. Negation uses disjunction case analysis. Conjunction case-splits a/u then b/v: a,b yield a&b; u or v yields u∨v. Disjunction is dual: a or b yields a∨b; u,v yield u&v. Implication needs **coverage of the consequent only**: b gives a→b by weakening, and v gives a→v. Those local arguments have been turned into literal closed K/S/and/or Frege rows using the elementary deduction theorem. Every final row is checked, and every stored row is a final ancestor. The constants are unsimplified, explicitly charged construction costs; no optimality is claimed.

## Strong aliases: decisive bad shortcut and exact repair

Do **not** set every displayed extension alias's negative coordinate to T. If e:=~p, the actual expanded signed negative body is p. A two-way strong definition would then require p↔T, which is not a valid IPC theorem. This is a concrete representation obstruction, not merely a syntactic admission rejection.

Unfold-first avoids it completely. A direct EF alternative assigns a strong alias the two fresh target definitions `e+ ↔ F+` and `e− ↔ F−`. Acquire `Cov(F)` first, and transport it using the actual backward directional target definition clauses. The fixed closed target lemma is

`(x->a) -> (u->b) -> (x or u) -> (a or b)`.

Its exact certificate costs1079 closed theorem rows and three MP rows, **1082 installed**, where a/b are e+/e− and x/u are the actual F+/F−. This uses no assumption that either alias coordinate is T. Each source definition body uses only earlier aliases, so body coverage is available before this acquisition. Weak definitions can leave the negative alias at T because their literal image constrains only e+; strong definitions constrain both.

Use the preserving, full-input atom allocator from the C note for every fresh negative **alias**, and pick r outside its reserved names. Ordinary negative coordinates are deliberately the compound theorem T, so their identification is intentional; target extension freshness is required only for the actual fresh alias variables. The fresh bodies and prior rows omit both current alias coordinates. An original source atom can be named `p-` or any allocator-looking string; this does not permit a target collision.

All local cached proof rows have fixed-template node cost O(S), with generated names charged O(log(S+2)). A conservative direct symbol-size bound is therefore **O(S² log(S+2))**.

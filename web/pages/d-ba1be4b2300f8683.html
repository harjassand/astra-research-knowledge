Square Γ event-level dependency-cluster swap gate
Date: 2026-10-09

STATUS

The finite cut-and-paste map transfers the *actual* negative-corner square
ordered-port-pair transcript, including every turn-determined negative T query,
provided all dependency components meeting its query support are swapped and
there are nested primal nearest-neighbor circuits of opposite strict signs for
h1-h2 in the free annulus. The event-level map has no factor depending on the
number of T queries and does not use a primal-bond property of the Γ cut.

This does not prove a uniform square comparison constant. The remaining
probability input is an R-uniform positive probability for the required
opposite-order primal circuits under the exact square transcript-conditioned
field law. The pinned source proves its high-crossing/shift input on the
triangular lattice; it does not establish that square estimate. No full square
G7 or Γ obstruction to the full swap is claimed.

WHAT THE PRIMARY EXCHANGE USES

For two feasible fields h1,h2 on a graph with edge constraints
|h_i(u)-h_i(v)|<=1, put d=h1-h2. Declare uv a dependency edge if swapping the
two replicas at only one endpoint makes at least one replica violate an edge
constraint. Write Δ_i=h_i(u)-h_i(v). If d(u)>=0>=d(v), then both mixed
differences lie between Δ_1 and Δ_2:

    h2(u)-h1(v) = Δ_1-d(u) = Δ_2-d(v),
    h1(u)-h2(v) = Δ_1+d(v) = Δ_2+d(u).

Each is therefore in [-1,1]. The same holds with u,v reversed. Thus a
dependency edge cannot join vertices whose d-values have opposite strict
signs, or a zero d-value to a nonzero one. A nontrivial dependency component
has one strict sign throughout; zero-difference vertices have no incident
dependency edges.

Suppose C+ and C- are nested Jordan cycles in the *primal constraint graph*,
both surrounding the full inner query set, with d>0 on C+ and d<0 on C-.
Any graph path from the inner set to beyond the outer cycle must meet both
cycles. A dependency path cannot do so because it cannot change the strict
sign of d. Hence every dependency component meeting the inner query set stays
inside the outer cycle.

Swap h1 and h2 at every vertex of every dependency component meeting the
inner disk. The operation is valid for all internal edges. An edge leaving a
selected component is not a dependency edge, so the one-endpoint partial swap
on that edge is feasible. If all base pins and sign walls are outside the
outer cycle, they are untouched. The dependency graph and selected components
depend only on the unordered height pair at each vertex, so the map is an
involution. On each component-selection region it is a coordinate
permutation and preserves Lebesgue measure.

If E is any event determined by a set K of inner height coordinates and every
component meeting K is selected, then E transfers exactly from h1 to h2.
In particular, this argument never asks whether the cut edges of Γ form a
primal bond, whether deleting them leaves two components, or whether Γ is a
triangular two-crossing strand. The path/cut topology may be useful elsewhere
for the conditional kernel on one side; it is not a premise of this swap.

ACTUAL SQUARE Γ TRANSCRIPT AND QUERY SUPPORT

Use a visited square face with cyclic corners p,q,r,s, incoming cut edge pq,
p>0>q, and r opposite p. The actual negative-corner rule is:

    r>0:          leave across qr; query r only;
    r<0<s:        leave across rs; query r,s;
    r<0 and s<0:  leave across sp; query r,s and record T=r<0.

The first branch does not query s, including when p,r are positive and q,s
are negative (the checkerboard completion). Thus no checkerboard/tie flag is
part of Γ. The T query is determined by the C-turn, is negative, and is
adjacent to q<0 by the uncut NN edge qr. All other queried positive sites are
endpoints of selected NN cut edges. Rotations give the other incoming sides.

For a fixed ordered-port-pair transcript γ, the event {Γ=γ} is the
intersection of exactly its local queried sign inequalities, up to zero
measure tie sets. In particular it includes every T_j<0 prescribed by the
turns, and imposes no sign on unqueried corners. It is a one-strand local
sign-wall conditioning; the query set K_γ lies in a fixed-width neighborhood
of the resolved path and is contained in B_{2R+c} when the recorded path is
stopped in B_{2R}. A visited checkerboard face may carry both disjoint negative-
corner arcs; this does not change the locality statement. Every T site is NN-adjacent to the incoming negative cut endpoint q; the other
queried sites lie on selected cut edges. Consecutive visited faces share the
selected NN edge, so the transcript wall set is a connected bounded-width
thickening of this one strand, even when a face is visited on both disjoint
resolved arcs. The record is not replaced by a sign-reversed geometric lift.
Comparisons are for the same fixed geometric incident edge σ, and the walk
landing side remains averaged.

A local exact rational falsifier shows why K_γ must include T. With cyclic
corners p,q,r,s, take

    h1=(1/5,-1/5,-1/10,-1/5),
    h2=(1/5,-1/5, 1/10,-1/5).

Both are feasible on all four unit square edges. The first transcript is the
C-turn sp with T=r<0; the second is the A-turn qr. They agree at all selected
cut endpoints p,q,s. A proposed swap that touches only cut-edge endpoints
leaves r positive in the second replica and does not transfer Γ. In the full
dependency graph r is isolated from the zero-difference cut endpoints, so
selecting all components meeting the *inner event support* swaps r as required.
The exact enumeration is in `gamma_t_omission_counter.py` and its JSON output.
This refutes the cut-only shortcut, not the full inner-support swap.

THE EXACT SQUARE CIRCUIT HYPOTHESIS

Let P_{φ} and P_{φ'} be square hard-1-Lipschitz field laws for two external
records. Let μ_{φ,γ} be the conditional law given one exact ordered-port-pair
transcript γ, with all cut signs and all T_j<0 constraints retained. The
needed square input is the following uniform statement, and also its
role-reversed version:

(QHC) There are p0>0 and R0, independent of R, φ, φ', γ and the number of
T-queries, such that for every R>=R0 and every admissible positive-probability
γ contained in B_{2R+c}, an independent pair
h1~μ_{φ,γ}, h2~P_{φ'} has probability at least p0 of two nested simple
*primal square-NN cycles* C+,C- in a fixed middle annulus, with h1-h2>0 on
one and h1-h2<0 on the other. Both cycles separate B_{2R+c} from the
exterior. The two base graphs coincide throughout the disk enclosed by the
outer cycle and in the annulus, so every swapped coordinate and edge has the
same graph in both laws. All *base* fixed data/sign walls lie outside the
outer cycle; the transcript walls lie inside B_{2R+c}. The annulus has a
fixed proportional free buffer, and each law has a macroscopic
observed/Dirichlet anchor at comparable distance.

For the G7 radii, the candidate middle annulus is between 9R/4 and 5R/2.
The exact Γ/T support is at most 2R+O(1), external strand observations start at
3R-O(1), and the original boundary/clearance is outside 6R. Hence for large
R the transcript does not touch the annulus or its proportional buffer. The
two external arms in each outer record remain macroscopic anchors for both
replicas. The same specified σ is fixed throughout; no landing-side
conditioning is introduced. The inner Γ itself need not serve as an anchor
for this G7 geometry, though a macroscopic strand could serve as an anchor in
other setups.

Assuming (QHC), write V_i for the base polytope volume and V_i(γ) for
the exact transcript cell. The favorable subset of the product cell has
volume at least p0 V_1(γ)V_2. Its swap image lies in the full first polytope
times the second transcript cell, with the same volume. Hence

    p0 V_1(γ)V_2 <= V_1 V_2(γ),

so p0 P_φ(Γ=γ) <= P_{φ'}(Γ=γ). Reversal gives the two-sided ratio
p0 <= P_φ(Γ=γ)/P_{φ'}(Γ=γ) <= p0^-1.
Summing the disjoint exact transcripts proves the same comparison for every
Γ-event. The number q_T(γ) of extra negative queries is at most a crude
O(R^2) bound from the number of visited face transitions. It costs no factor
in this argument; it only enlarges K_γ inside the inner disk. Any proof of
(QHC) whose constant decays with q_T does not give G7. The reversed random-walk
piece and hookup conditioning are separate G7 factors, not proved here.

WHAT IS AND IS NOT CLOSED

The exact square transcript satisfies the *geometric conditioning* side of
(QHC): all queried walls, including T, are local to Γ and separated from the
comparison annulus; external arms furnish the specified anchors. There is no
actual Γ obstruction to the finite exchange once QHC holds. The actual local
counterexample above rules out omitting T from the swapped support.

The missing theorem is QHC for the square real-valued uniform hard-Lipschitz
field, uniformly over the exact sign-wall transcript class and the exterior
anchors. The pinned triangular g:high-crossing proof uses its own local
reflected-comparison, averaged-field and sparse-box/feasible-shift inputs. No
square version of those inputs with the required uniformity has been imported
or proved in this packet. In particular, the triangle theorem cannot be
silently reused after changing the constraint graph. A square proof would
need (i) a high-crossing bound for h1-h2 in the free buffered corridors under
the transcript-conditioned laws, (ii) a feasible-shift/positive-volume
argument uniform in those same wall transcripts, and (iii) primal square-NN
rectangle crossings glued with literal vertex intersections to make the two
separating cycles. The crossing paths must be primal constraint-graph paths;
a dual-only circuit would not fence dependency components.

Finite checks
-------------
`dependency_edge_check.py` enumerates 1,521 valid two-replica edge assignments
on the exact half-integer grid [-2,2]. All 449 assignments with an order
change or tie admit both one-endpoint swaps; there is no strict-order-reversal
counterexample. The report proof covers arbitrary real feasible values. This
is a local finite check only, not evidence for QHC.
`gamma_face_check.py` checks all four r,s branches for p>0>q, including the
unqueried checkerboard completion and the T branch. `gamma_t_omission_counter.py`
checks the exact feasible rational cut-only counterexample above.

1. EXACT FULL PHYSICAL TRACE-DISTANCE METRIC
Let b=0,...,floor(N/2),j_b=N/2-b,d_b=C(N,b)-C(N,b-1),D_b=(2j_b+1)d_b,
and G(x)=sum_b x_b P_b/D_b for a probability vector x. Put
 f_m=exp[-delta m^2/N+h m], z_b=sum_(m=-j_b)^j_b f_m,
 c_b=z_b/(2j_b+1), beta_x=sum_b x_b c_b,
 Q_b(x)=x_b c_b/beta_x.

The eigenvalue of Phi_F(G(x)) at (b,m,multiplicity-label) is EXACTLY

 x_b f_m/[d_b(2j_b+1)beta_x]=Q_b(x) f_m/(d_b z_b).              (D1)

There are d_b multiplicity labels for each m. The state conditional on b has
eigenvalue f_m/(d_b z_b), independently of x. These conditional states have
orthogonal sector supports and trace one. Therefore

 T(Phi_F(G(x)),Phi_F(G(y)))=(1/2)sum_b |Q_b(x)-Q_b(y)|.          (D2)

This includes every physical multiplicity; it is not a compressed-state norm
or an exp(C) upper bound. A first message had a transcription error in(D1)'s
conditional numerator; root caught it. The corrected formula above is used
throughout, and the correction is retained in REPAIRS.json.

With the main proof's exact rational A_bk=Tr(P_b K_k), define
 Z_k=sum_b A_bk c_b,
 C_bk=A_bk c_b/Z_k=Tr(P_b Phi_F(K_k)).                          (D3)
All columns C are nonnegative/stochastic. The heat/Bernstein proof gives
G(q) in conv{K_k}, hence Q(q) in conv{C_.k}; the normalized filter maps
old simplex weights w to v_k=w_k Z_k/sum_l w_l Z_l. Conversely exact
v gives w_k=(v_k/Z_k)/sum_l(v_l/Z_l). For an APPROXIMATE Zhat conversion,
posterior(D2) must use the actual delivered rational w and TRUE c intervals.
An LP's fitted approximate C v alone does not certify that converted output.
The direct compiler below samples v and normalized filtered K columns, so no
conversion is needed and no condition factor is reintroduced.

2. COUPLING-INDEPENDENT POSITIVE NORMALIZER FLOOR
Use the GLOBAL shift H=|h|N/2 and the magnetization-grid values

 v_t=exp[-delta(t-N/2)^2/N+h(t-N/2)-H], t=0,...,N.              (D4)

 Z_k >=v_ext/[(k+1)2^(N-k)] >=2^-2N,                          (D5)

since k+1<=2^k, including k0. This floor is UNIFORM in alpha,h magnitudes.
Also every Z_k<=1, because v_t<=1 and K_k has trace one.

Put x_b=alpha b(N+1-b)/N. The target filtered sector vector is

 Q_b=D_b exp(-x_b)c_b / sum_a D_a exp(-x_a)c_a.                (D6)

The b0 term has D0=N+1, x0=0, and (N+1)c0=sum_t v_t. Thus its denominator
is at least v_ext>=2^-N, independent of alpha,h. All needed exponent

Large numerical magnitudes are clipped by the main proof's exp-negative
routine, not evaluated using a degree proportional to those magnitudes.

3. ACQUIRE POSITIVE NORMALIZED COLUMNS; FEASIBILITY PERTURBATION
Set lambda=eps/256 and choose a dyadic tau<=lambda 2^(-2N-5). Acquire
0<=vhat_t<=1 and0<=rhat_b<=1 approximating v_t and exp(-x_b) with absolute
error<=tau, keeping rhat0=1. Only O(N) scalar values are required. Their
precision is O(N+log1/eps). The extremal vhat remains positive. Define

 chat_b=(sum_{t=b}^{N-b}vhat_t)/(N-2b+1),

 Chat_bk=A_bk chat_b/Zhat_k,
 Qhat_b=D_b rhat_b chat_b/sum_a D_a rhat_a chat_a.              (D7)

All acquired columns and Qhat are exactly nonnegative rational stochastic
vectors. Zhat_k>0, since A_0k>0 and chat0 contains the positive endpoint.
Some smaller chat_b may be zero after clipping; that is allowed.

For each C column, the sum of absolute raw errors is at most tau because
sum_b A_bk=1 and |chat_b-c_b|<=tau. Standard positive normalization and(D5)
give TV(Chat_.k,C_.k)<=2^(2N)tau<=lambda/32.
For Q, the product error |rhat chat-r c|<=2tau, since both factors are in[0,1].
Using sum_b D_b=2^N and the(D6) denominator floor gives
TV(Qhat,Q)<=2^(2N+1)tau<=lambda/16. These bounds are <lambda each.

Fit v by the finite rational LP
 min (1/2)sum_b t_b,

 t_b>=|(Chat v)_b-Qhat_b|,0<=t_b<=4.                           (D8)
The same explicit center v_k=1/(N+1),t_b=2 and relative radii of the main
proof apply, because the acquired columns and target are stochastic. The
true target lies in the true filtered hull, so opt(D8)<=2lambda by mapping
its existence weights into Chat. Request additive lambda from the charged

              T(rho,sum_k v_k Phi_F(K_k))<=5lambda.           (D9)

This follows from(D2): target approximation lambda + LP residual<=3lambda
+ column approximation lambda. Rounding v dyadically with denominator

4. DIRECT NORMALIZED FILTERED-K BRANCH SAMPLING
For k fixed, n=N-k and u=0,...,n, let
 Z_ku=sum_{t=u}^{u+k}v_t,
 R_ku=C(n,u)Z_ku/[(k+1)2^n].
The exact conditional type law is

                  P(u|k)=R_ku/Z_k.                           (D10)

also an independent equality check between the sector and computational
formulas. Use the SAME vhat_t to acquire Rhat and Zhat. For each k,
sum_u |Rhat_ku-R_ku|<=tau, since the averaged k+1 summands have total
coefficient mass1. Therefore

                 TV(Phat(.|k),P(.|k))<=2^(2N)tau<lambda.      (D11)

The joint rational outer probabilities are v_k Phat(u|k) and sum exactly1.
Round this O(N^2)-entry distribution dyadically with denominator>=256M/eps,
adding <=eps/256. Choose a subset and complementary u-one string with the

Some global Zhat_ku can be zero for a huge field. Its approximate branch

`Wstar=2^71`, `Delta=6871402692000000`,
`S=Wstar*m-Delta`, and `theta=log_m(S/Wstar)<1`.

The candidate is a finite-precision application of the unitary
`C^tensor(k)` with relative Euclidean error `epsilon=2^-b`, using

`p=b+C_precision+9 ceil(log2(k+1))`

mantissa bits and `O(log(b+k+2))` exponent bits. Its numerical input is
an explicitly encoded finite floating-point vector. Reading and rounding
that input are charged. The norm in the simultaneous Wstar-array contract
includes **every input role**, including dirty auxiliaries. For a requested

The proposed numerical operation count retains
`O(n(k+1)^theta)` under the source's logarithmic-word RAM address model,
for `b=O(log n)`. This does not assert a multitape bit bound or an ordinary
fixed-binary64 implementation. The constants and crossover are enormous.

Only the fixed C tensor network is involved. The arbitrary-length DFT's
Newton/Toeplitz compiler is outside the stability claim.

## 1. Reconstructed scalar operation

For `h=100`, let T be the three-element subsets of `[h]`,
`v=|T|=161700`, and `d=147731` the number of triples with even
intersection with a fixed triple. Side wires use ordered neighboring
pairs `(S,T)`; central wires have indices `1,...,h,*`.

The source defines

```
(Vx)_(S,T) = x_T
(Gx)_j = sum_(T contains j) x_T;  (Gx)_* = sum_T x_T
(JA)_S = -sum_(T neighbor S) ((|S intersect T|-1)/2) A_(S,T)
(Rc)_S = (sum_(j in S) c_j-c_*)/2.
```

Thus `(RG)_(S,T)=(|S intersect T|-1)/2`. It is one on the diagonal,
zero for intersection size one, and canceled by JV for intersection
sizes zero or two. Therefore `RG+JV=I` exactly.

The eight scalar rows are

```
y -= JA; y -= Rc; A += Vx; c += Gx;
y += Rc; y += JA; c -= Gx; A -= Vx.
```

They implement `(x,y,A,c)->(x,y+x,A,c)` for arbitrary initial A,c.
Three stages, forward X to Y, inverse Y to X, then forward X to Y,
give `(X,Y)->(-Y,X)` and restore all auxiliaries.

## 2. Prefix conditioning: explicit bound

All norms here are Euclidean operator norms. J has disjoint row supports;
V has disjoint column supports. Consequently

`||V||=sqrt(d)`, `||J||=sqrt(d)/2`.

Each G column has four unit entries; each R row has four half-unit
entries. Thus

`||G||<=||G||_F=2sqrt(v)`, `||R||<=||R||_F=sqrt(v)`.

These upper bounds also hold after retaining any subset of the scalar
additions within a row, and for the complementary subset. A forward
invocation prefix, including a partially evaluated row, has the form

```
x=x0; A=A0+V' x0; c=c0+G' x0;
y=y0+J' A0+R' c0+P x0.
```

The primed maps have the corresponding bounds above. Before row 4,
P is zero. During row 4, `P=R_partial G`; during row 5,
`P=RG+J_partial V`; afterward P is I. Hence `||P||<=5v/2`.
Summing the norms of the off-diagonal blocks gives

`||F_prefix||<=1+(9/2)sqrt(v)+(5/2)v<6v`.

To invert the prefix, recover x0, then A0,c0, then y0. The inverse's
source coefficient is bounded by

`||P||+||J'||||V'||+||R'||||G'||<=5v`.

Thus `||F_prefix^-1||<=1+(9/2)sqrt(v)+5v<6v`.
The complete invocation and its inverse have norm below two because
their only nonidentity action is `y+=x`. A prefix of the inverse
invocation is a forward prefix times the inverse complete invocation,
so its norm and inverse norm are below 12v.

Within one stage the invocations act on disjoint bank entries and private
auxiliaries. Completed first-stage and first-two-stage bank maps are
`[[1,0],[1,1]]` and `[[0,-1],[1,1]]`; their norms and inverse norms
are below two. Therefore the complete scalar parent skeleton, at every
cut and including reversed invocations, has prefix and inverse-prefix
norms bounded by

`K0=32v=5174400`.

## 3. Unitary frames and recursive prefixes

The source frame is `Phi_U=J_m diag(i^q_U) J_m`, with normalized Walsh
matrix J_m and a quadratic weight q_U modulo four. Both factors are
unitary, so Phi_U is unitary. These matrices are proof devices; the
algorithm does not execute Walsh transforms to change frames.

At a cut of the unexpanded parent network, assign each physical wire
its current frame. A scalar gate's touched wires have a common frame;
the scalar gate commutes with it. An edge advances a wire's frame by
`Phi_V Phi_U^-1`. Induction over events gives

`B_prefix=D_current (S_prefix tensor I) D_source^-1`,

with block-unitary D matrices. During a scalar row, partial additions
still act on wires with their common gate frame. During an edge's
directional decomposition, completed C_z kernels are unitary; absorb
them into the current frame. Hence the bound K0 holds at every cut
of the nonrecursive framed execution, not only at scalar endpoints.

Now substitute the exact recursive algorithm for a directional block.
Its endpoint is unitary on **every** role. Independent recursive batches
are disjoint; a partially completed collection of earlier batches is a
unitary block summand. While one child is active, the global prefix is a
parent prefix followed by the child's prefix, extended by identities and
unitary completed blocks. The same multiplication rule holds for inverses:

`K(k)<=K0 K(floor(k/m))`.

Base calls apply unitary two-coordinate C gates at their logical
interfaces. There are at most `ceil(log_m(k+1))` nonbase levels. A loose
integral bound, using K0<m^2, is

`K(k)<=K0^2(k+1)^2=:Kbar(k)`.

Copy buffers for exact permutations do not impose an inverse requirement
on discarded physical memory. The logical state is the current role
array; float encodings are copied exactly, and completed permutations
are unitary on that state.

This is the central proposed extension requiring independent review. It
would fail if the source endpoint identity held only on zero auxiliaries.

## 4. Arithmetic layers and depth

Use conceptual layers of disjoint numerical updates. Every fixed
pointwise scalar operation can be grouped over all array addresses.
Independent recursive batches can be layered together: they have identical
topology and disjoint operands. Reordering them leaves rounded results
unchanged because the precision and exponent range below are fixed before
execution. Actual hardware may execute serially; all arithmetic and address
operations retain their charged cost.

To avoid an optimized scheduling assumption, use the companion's fixed
elementary scalar-operation overestimate

`W=1873807244643542670000`, `E=64(W+m+1)^3`,
`Q=E+m+100`, `Kbase=72m`.

The parent has S ordered directional child steps and fewer than m leftover
bit layers. Therefore

`L(k)<=S L(floor(k/m))+Q`, with `L(k)<=k` in the base range.

Unrolling and using S<m^5 gives the effective bound

`L(k)<=D(k+1)^5`, `D=(Kbase+Q+1)S`.

This is dependency depth; serial work has not been made free.

## 5. General rounding lemma, with proof

Let `B_j=A_j...A_1`, B_0=I, be an exact invertible layered computation,
with unitary B_L and every prefix and inverse prefix bounded by K.
Suppose implemented updates satisfy

`vhat_j=A_j vhat_(j-1)+e_j`,
`||e_j||<=c u ||A_j vhat_(j-1)||+eta`.

Put `z_j=B_j^-1 vhat_j`. Then

`||z_j-z_(j-1)||<=c u K^2 ||z_(j-1)||+K eta`.

Iterating this elementary recurrence, with `t=c u K^2 L`, gives

`||vhat_L-B_L x|| <= (exp(t)-1)||x|| + K eta L exp(t)`.

An initial input error delta contributes at most `exp(t)||delta||`.
The proof allows nonlinear, correlated, adversarial rounding errors.
It needs neither unbiased rounding nor random input.

For scalar shears with coefficients `0,+/-1,+/-1/2`, correctly rounded
binary addition and exact halving above the underflow floor satisfy this
model. For C, use

`s=x+y; d=x-y; t=i d; o1=(s+t)/2; o2=(s-t)/2`.

The first sum/difference map has norm sqrt(2); the final half-sum map
has norm 1/sqrt(2). Propagating the real-component rounding errors
gives a safe common `c=8`. With N complex live coordinates and a real
underflow allowance tau per arithmetic result, use the safe common
`eta=8sqrt(2N) tau`.

Now `c L(k) Kbar(k)^2<=8D K0^4(k+1)^9`. Set

`C_precision=ceil(log2(1024D K0^4))`.

The advertised p makes `t<=2^-b/128`, leaving ample room for input
rounding, underflow, and projection to the requested output role.

## 6. Finite exponent range and acquisition cost

Read the encoded input; find its largest real-component exponent and
normalize by one common exact power of two. Every component then has
modulus at most one and one has modulus at least one half; the normalized
vector norm is at least one half. No norm oracle or exact-real equality
test is needed. Arbitrary input mantissa/exponent lengths are charged.

For the simultaneous call N=Wstar*2^k. A safe underflow floor is

`tau=2^-q`,
`q=b+ceil((k+72)/2)+ceil(log2(4096D K0^2))+7ceil(log2(k+1))`.

Then `Kbar eta L<2^-b/128` in normalized units. Values below the floor
may be flushed to zero, with that explicit Euclidean error. Input
flushing and mantissa rounding are controlled by the same calculation.

A safe upper exponent is

`U=ceil((k+72)/2)+ceil(log2(16K0^2))+2ceil(log2(k+1))`.

The prefix bound and small-error recurrence keep every intermediate
norm below `2Kbar sqrt(2N)`, so this avoids overflow. Exponents in
`[-q,U]` require `O(log(b+k+2))` bits. Return the common dyadic scale
once; charging separate original-scale exponents at every output is an
additional requested-format cost.

Correctly rounded binary addition uses capped shifts. If exponents differ
by more than p+O(1), retain only the small operand's sticky/rounding
information; otherwise align at most p+O(1) bits, add and normalize.
Halving updates the exponent; i swaps signed real components. Each
operation has payload bit cost `O(p+log(b+k+2))`. No general multiply
occurs in C or the scalar replay.

With address word size `w=Theta(log n)`, numerical values use
`O(1+ceil(b/w))` words. The candidate arithmetic/array work is

`O(n(k+1)^theta (1+ceil(b/w)))`

word operations, plus input acquisition and output-format cost.
Payload bit work is `O(n(k+1)^theta(b+log(k+2)))`; addressing still
uses the source's charged logarithmic-word operations. A full multitape
bit bound needs a separate address-movement argument and is not claimed.

## 7. A scoped consequential operation

For normalized `H=[[1,1],[1,-1]]/sqrt(2)` and `P=diag(1,i)`,

`H^tensor(k)=exp(-i*k*pi/4) P^tensor(k) C^tensor(k) P^tensor(k)`.

The diagonal phases are exact fourth roots. For odd k the global phase
requires a sqrt(2) constant acquired and multiplied to the required
precision; charge its preparation and n scalar products. Thus the
candidate gives a normwise dense Walsh-Hadamard operation.

For an explicitly supplied diagonal Dspec with norm at most one, two
such transforms implement the contraction filter

`x -> H^tensor(k) Dspec H^tensor(k) x`.

If each transform has error `eta||input||` and the implemented diagonal
has operator error eta, the triangle inequality gives total error at most
`4eta||x||` for eta<=1/10. Charge acquisition of all n diagonal values,
n pointwise products, and the constant-phase products. This assumes a
supplied full vector/model; it does not reduce sensor count or acquire
an unknown physical system.

## 8. Decisive dirty-catalyst counterexample

For one DAG gate M=1, take binary64 `x=1,y=0,z=2^60`. The source
replay performs z+=x, adds its readout into y, undoes the sweep, then
subtracts the source-suppressed readout z. Since 2^60+1 rounds to
2^60, it returns y=0 instead of one, while z is restored. A bound
depending only on the logical source norm conceals the catalyst scale.
The whole-role norm in the proposed interface is essential.

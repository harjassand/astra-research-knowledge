C02_L07 REVISION 01 — CROSS-COORDINATE AUXILIARIES CAN REMOVE THE LOCAL OBSTRUCTION
7 October 2026. Exact finite construction; internal status, no external review.

RESULT
The INITIAL four-site conservation law is exact for auxiliaries whose endpoints lie in the same four coordinates as the F4 witness. It cannot be generalized to coupled six-site matrices with cross-coordinate auxiliaries. An explicit six-site rational matrix F, whose upper-left 4x4 block is the F4 witness but whose added rows and columns are coupled to it, together with seven unit-activity coordinate-pair auxiliaries on a K_{4,2} cross graph changes the four-site pinned slice's necessary windability defect from

  Delta_before = -245931/32768

to

  Delta_after = 28101/32768 > 0.

Moreover, this particular pinned four-site signature is even-windable: an exact nonnegative pair-flip witness is given below and checked for every ordered assignment pair. Thus cross-coordinate auxiliaries can remove the specific four-hole positive-matching obstruction in this coupled completion. The F4 upper-left block is retained, but its standalone four-site hole signature is not preserved by the nonzero cross blocks; this is not a conservative gadget extension of the original F4 signature. It is only a pinned marginal of a six-site completion; it does not prove the full six-site signature is even-windable, provide a matching-circuit realization, or yield an acquired microscopic sampler.

SIX-SITE INSTANCE
All indices are zero-based. Set

  F = [[ 0,       0,       1,  1, -1/4, 0 ],
       [ 0,       0,       1, -1, -1/4, 0 ],
       [ 0,       0,       0,  0,  1/4, 0 ],
       [ 0,       0,       0,  0,  1/4, 0 ],
       [ 1/4,  1/4,       0, -1/4,    0, 1 ],
       [-1/4, -1/4, -1/4, -1/4,    1, 0 ]].

For every even hole set U subset [6], let

  f(U) = sum_{I subset [6]\U, |I|=(6-|U|)/2} |det F[I,([6]\U)\I]|^2,

and let f(U)=0 for odd U. The hole variables 4 and 5 are then pinned to zero, so the four-site slice is g(S)=f(S) for S subset {0,1,2,3}.

Add coordinate-pair auxiliaries of activity one on the following seven edges:

  04, 05, 14, 15, 24, 25, 34.

The missing eighth K_{4,2} edge is 35. For a family E of coordinate-pair auxiliaries, the unsigned-hole coefficient action is

  f_E(U) = sum_{M matching subset E, V(M) intersect U=empty} f(U union V(M)),

because one auxiliary edge {i,j} acts by I+partial_i partial_j, and overlapping edge derivatives vanish on multiaffine polynomials. Thus the table below is an exact finite matching expansion, not a floating calculation.

EXACT EVEN-WINDABILITY WITNESS
For each pairing M_i, let h_i be its complementary two-hole product, and let A=g_E(empty)g_E(all)=1897/64. Define

  B = (h_1+h_2+h_3-A)/2 = 28101/65536,
  a = (h_1, h_2-B, h_3-B)
    = (98515/32768, 907149/65536, 838349/65536),
  b = (B,0,0).

For an ordered assignment pair (x,y):
- if their difference has size zero or two, put all mass g_E(x)g_E(y) on its unique matching;
- if the difference has size four, for each M_i put mass a_i when x is a union of edges of M_i, and b_i otherwise;
- if the difference has odd size, its product weight is zero and assign no mass.

The identities sum_i a_i=A and h_i=a_i+sum_{j!=i} b_j verify total mass at empty/all and at each complementary pair of two-hole states. The definition is constant on each orbit under flipping an edge of its matching, so it verifies pair-flip invariance. The exact diagnostic checks the sum condition for all 256 ordered (x,y) pairs and all 192 applicable flip equalities. This is a complete witness for the four-site even-windability interface, not only the necessary Delta test.

MINIMALITY SCOPE
A deterministic exhaustive check of the 247 cross-edge subsets of size 0 through 6 found none with nonnegative defect. All 8 size-7 subsets were checked; the displayed seven-edge set succeeds. All activities are fixed to one. This establishes minimal edge count only for this F, this K_{4,2} candidate graph, and unit activities; it does not optimize over rational activities, other matrices, or other auxiliary architectures.

STABILITY / REPRESENTATION STATUS
The six-site signed ambient-hole polynomial is stable by the prior chiral-determinant construction. Each positive coordinate-pair auxiliary is the known stability-preserving operator I-w partial_i partial_j on the signed polynomial (the unsigned-hole transform above has the corresponding plus sign). Its algebraic symbol is [(z_i+y_i)(z_j+y_j)-w] times the other coordinate factors; for w>=0 it is nonzero when all z_i,y_i are in the open upper half-plane. Borcea–Brändén's stability-preserver criterion supplies the operator implication. Specializing x_4=x_5=0 yields a stable-or-zero polynomial; it is nonzero because g_E(1111)=2. This certifies that the pinned four-site slice remains in the stable class.

The exact script is `work/cycle6/c02_l07/cross_aux_counterexample.py`; its result JSON is `work/cycle6/c02_l07/cross_aux_counterexample_result.json`. It computes every determinant over Q, expands matchings, exhausts the restricted auxiliary-subset search, and constructs/checks the witness. No solver, floating point, parallel processes, or downloads were used. Runtime is bounded by 64 hole sets, minors of size at most 3, at most 256 auxiliary graphs, and 256 assignment pairs.

BOUNDARIES AND NEXT GATE
The example shows that the local four-site invariant is not a barrier to cross-coordinate auxiliary transformations of coupled completions. However the six-site F is one explicit fixture; no polynomial-time rule extends a general input F while preserving its original signature. The pinned slice omits states with auxiliary holes, and a witness for that slice gives no sampler or energy comparison for the unpinned six-site distribution. Full coefficient acquisition, conditional sampling, two-replica energy/congestion, bit/precision costs for a general extension, and priority remain open. Next, identify whether these cross-edge repairs can be generated uniformly from arbitrary F while preserving the needed marginal data and extend to a full six-site witness; otherwise isolate the exact extra states or balancing data that block the lift.

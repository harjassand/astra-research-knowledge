# Cycle 2: estimated experiments, uniform report error, and real deployment cost

Status: complete elementary propositions plus executed finite rational fixture; Bernoulli-factory exception is a verified prior theorem application, not an implemented factory. 2026-10-06.

## Exact acquisition interface

There are s finite states. Source rows F_i and target rows G_i are unknown finite-alphabet distributions. During calibration, the learner may request independently labelled iid samples **from each row**. This is controlled known-state calibration, a strictly stronger interface than passively observing a single hidden state. It must be supplied by an experiment, intervention or dataset; it is not inferred from a black-box trajectory. Deployment has only F samples from an unknown fixed state i. A target policy is state independent and may use observations/randomness to choose when to stop and what finite report to emit.

Both the compiler and a competent retaining comparator receive the same calibration rows, target-policy code, probabilities already given by the task, and randomization access. Computation, stored models, all calibration requests and subsequent source requests count. No special architecture or discovery advantage is claimed.

Notation: fitted matrices are Fhat,Ghat. On the confidence event, TV(F_i,Fhat_i)<=d_F and TV(G_i,Ghat_i)<=d_G for every i. The chosen target policy has a hard horizon T<=L. TV is one half of the L1 distance. A compiler reproduces the Ghat terminal law exactly under Fhat, has finite output, and has a **proved** fitted expected count E_i N<=K for all i. A simulation estimate of K is insufficient.

## Proposition 1: uniform output and cost repair for any fitted compiler

Cap the compiled source policy at integer B>=1. If it requests observation B+1, stop at B and emit a fixed fallback report. Let N_B=min(N,B). For every true state i,

TV(Law_i^F(report capped compiler), Law_i^G(target report))
 <= min(1, d_F K + K/B + d_G L),

E_i^F N_B <= min(B, (1+B d_F)K).

These inequalities apply to the **entire output law** and hence to every measurable downstream decision/event simultaneously. They also hold when the compiler and target policy are chosen after seeing the calibration data, provided the per-row confidence event is simultaneous.

Proof. Couple true and fitted source observations maximally, sharing auxiliary randomness. Until the first mismatch, both policies request the same samples and make the same decisions. The probability of a mismatch before the fitted capped stop is at most

d_F sum_(t=1)^B P_hat(N_B>=t)=d_F E_hat N_B<=d_F K.

On no mismatch, reports and costs agree. Therefore source report TV is at most d_F K. Fitted truncation changes the report only if N>B, which has probability at most K/B by Markov. The analogous target coupling gives at most d_G E_hat T<=d_G L. Triangle inequality proves report error. Because both costs lie in [0,B], the same coupling bounds the difference in their expected costs by B times the mismatch probability. Thus E_true N_B<=E_hat N_B+B d_F E_hat N_B<=(1+B d_F)K; also N_B<=B pointwise. QED.

For an originally integrable target with certified E_i^G T<=tau, one may first cap the target at L and add tau/L to output error. This does not preserve an exact terminal law and must be charged separately.

An explicit tolerance allocation is B=ceil(K/a), d_F<=min(b/K, h/B), d_G<=c/L. It gives report TV<=a+b+c and true mean cost<=(1+h)K, up to the chosen integer B. The cost of learning source laws therefore scales at least quadratically in K/(h a) under this elementary method. Calibration is not a free preface to the Li–Liu rate.

## Proposition 2: labelled calibration costs and uniformity

Let M be the number of calibrated state rows, k the largest alphabet size, beta the permitted calibration failure probability. For each row use n iid samples and its empirical distribution. The event

max_rows TV(empirical,true)<=d

has probability at least 1-beta when

n >= [k log2 + log(M/beta)]/(2d^2).

Proof. TV(empirical,true)=max_(A subset alphabet) [empirical(A)-true(A)]. Each subset is a Bernoulli mean, so a one-sided Hoeffding bound is exp(-2nd^2). Union over at most 2^k subsets and M rows. Total calibration count is **M n**, not n. For binary rows the sharper familiar two-sided bound gives n>=log(2M/beta)/(2d^2).

The full-matrix event is uniform over subsequent target-policy/report selection. It does not give unlimited reuse of a desired fixed error tolerance: an adaptive transcript with R total target requests may accumulate R d_G error (and analogous source error). It also does not certify that an iid calibration oracle or state labels exist.

## Proposition 3: explicit effective two-state compiler after calibration

Suppose Fhat_i=Bern(phat_i), Ghat_i=Bern(qhat_i), phat_0!=phat_1. Solve

t=(qhat_1-qhat_0)/(phat_1-phat_0),
a=qhat_0-t phat_0, b=a+t.

If a,b are in [0,1], take one source sample X, then emit a target bit with probability a if X=0 and b if X=1. It reproduces Ghat_i exactly because (1-phat_i)a+phat_i b=qhat_i. If feasibility fails, return UNKNOWN rather than silently project to a different channel.

For the real channels the per-generated-bit mismatch is at most |b-a|d_F+d_G. Applying the online generator to **any** target stopping/report policy with T<=L gives all-output TV at most L(|b-a|d_F+d_G), true maximum source requests L, and O(L) generation arithmetic. The kernel uses constant retained matrix state. It bypasses extracting the target report probability law, even when the report code is succinct and its exact law would be computationally hard to evaluate.

This is a fully effective positive scope, not merely an existence statement. It applies only when a one-step garbling is feasible; it does not realize the general adaptive KL dominance theorem. A competent retaining baseline can learn and use the identical kernel.

Conditional on count, both history laws are uniform, so the count-based calculation equals full-history TV; it is not merely a one-task diagnostic.

## Proposition 4: fitted finite expected cost is not stable under TV error

Draw an auxiliary K with P(K=k)=2^-k for k>=1. Request K Bernoulli(q) samples. If all are one, request an additional floor(4^K/K^2) samples; then emit a constant report. The source stopping time is almost surely finite for every q because K is finite and each branch length is finite.

Its mean is

E_q N = 2 + sum_(k>=1) 2^-k q^k floor(4^k/k^2).

At fitted q=1/2, this is at most2+sum1/k^2<infinity. At any real q=1/2+u, u>0, each summand is at least(2q)^k/(2k^2), and the series diverges. Thus an arbitrarily small one-step TV error can change a fitted finite expected cost to **infinite** real expected cost. Embed this in a full-support identified two-state experiment with fitted rows Bern(.25),Bern(.5) and real rows Bern(.25),Bern(.5+u).

The constant report shows this is a resource obstruction, not failure of output-law approximation. It does not prove the specific Li–Liu construction fails under every perturbation; it disproves the generic inference that fitted integrability plus small TV guarantees real expected cost. A tail certificate, hard cap or stronger likelihood-ratio robustness condition is needed.

## Proposition 5: hard-cap exact unknown-law reproduction is impossible

Consider p in (.7,.8), source F_1=Bern(p),F_0=Bern(1-p), and a fixed target with distinct state laws H_0!=H_1. Permit labelled calibration samples from either source row, then deployment samples from the unknown state, arbitrary state-independent randomness, and adaptive branching. Suppose the **total** source sample count is at most a fixed finite B for every run, and the algorithm must always reproduce H exactly for every p in the interval.

For any output event A, its probability in state theta is a polynomial P_theta(p) of degree at most B. Integrating arbitrary auxiliary randomness changes coefficients, not the degree: pad the finite decision tree to depthB and sum products of p and1-p. Exact reproduction requires P_theta(p)=H_theta(A) on an open interval, so the polynomial identity theorem makes it constant for all p. At p=1/2 the two deployment laws are identical, and the calibration law is the same in either deployment state. Hence P_0(1/2)=P_1(1/2), contradicting an event with H_0(A)!=H_1(A). QED.

The theorem concerns a deterministic total cap, including calibration. It is not an impossibility theorem for unbounded integrable stopping, nor for approximate reproduction, abstention, restricted finite parameter classes, or identifying a nontrivial invariant quotient.

## Why Bernoulli factories defeat a broader negative conclusion

Verified prerequisite: Holtz–Nazarov–Peres, *New coins from old, smoothly*, arXiv0808.1936v3 (2010-01-25), Theorem8 and Result3. It states that a known positive C^alpha function on [0,1] has a Bernoulli factory with uniform tail O(Delta_n(p)^alpha), for noninteger alpha>0. We inspected the theorem and its polynomial-envelope interface, not reconstructed its long approximation-theory proof.

Let z=(q-.3)/.4 and s(z)=6z^5-15z^4+10z^3 on[0,1], extended by0 to the left and1 to the right. Set f(q)=1/4+s(z)/2. This function stays in[1/4,3/4], is C^2 with a Lipschitz second derivative, hence C^{2.5}[0,1]. It equals1/4 for q<=.3 and3/4 for q>=.7.

The cited theorem supplies an exact factory for f(q) with uniform tail O(n^-5/4). Summing the tail gives a uniform finite expected sample count. Thus for p in(.7,.8), unknown F_0=Bern(1-p) and F_1=Bern(p) can reproduce the **fixed**, nontrivial target Bern(1/4)/Bern(3/4) exactly with finite expected sampling, without learning p. No hard cap is possible by Proposition5. This is an existence/application result from prior art; an executable factory with explicit usable constants has not been produced here. The target function and the band promise are supplied.

Nacu–Peres, *Fast simulation of new coins from old*, arXiv math/0309222v4 (2004-01-02), supplies the complementary analytic/exponential-tail relation. A connected-domain plateau transition cannot have exponential tails everywhere because it is not analytic across its transition; this does not preclude faster factories designed only for separated parameter bands.

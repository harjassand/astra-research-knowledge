GAMES / HAMILTONIANS — HIGH-CEILING ROUTE SYNTHESIS
Date: 2026-10-08
Scope: Cycle-2/3 continuation; internal proof candidates and source audits.

DECISION

No construction yet satisfies the complete common positive sparse encoding
interface on the full augmented BMVZ hard family. The decisive separation is
now sharp: polynomial-circuit isometries and common diagonal tests can encode
the entire noncommuting list exactly (or within fixed two-sided constants),
but the known image enforcers either have exponentially large rows or have
only inverse-polynomial normalized gap. Some fixed-image classes admit a
stronger arbitrary-enforcer obstruction. The surviving gate is a redesigned
global coherent isometry whose image has a polynomial-row, constant all-state
positive enforcer while one diagonal test still compresses the full hard
Hamiltonian.

The audited target interface is a polynomially described finite instance H,
an isometry V from the full logical space into the physical space, a common
computational-basis diagonal positive contraction B, and a positive
contraction C with

    ker(C)=ran(V),   C >= gamma (I - VV*),
    alpha H <= V* B V <= beta H,

for size-independent alpha,beta,gamma>0. A row-sparse claim includes the
maximum number of nonzeros per row and an algorithm to enumerate them, not
just polynomial-time evaluation of one specified entry. Gap is normalized
by ||C||<=1. Locality, circuit cost, exact/algebraic coefficient access and
precision are separate resources. The seed witness is appended to a
constant-color BMVZ hard input as two fresh five-qubit singleton layers,
weights 1/4 each, with the old hard weights scaled by 1/2. The singleton
rule forces the repeated BJSW seed clauses at every BMVZ round. This is a
legal hardness-preserving augmented family, not a claim about membership in
an unnamed canonical reduction image.

PROVED / RECONSTRUCTED ROUTES (at least twelve independent mechanisms)

1. Commuting-operator threshold repetition (operator proof, separate from
Hamiltonian encodings). For any finite two-player game with commuting value
v<1, product answer size d, component resampling gap sigma, and
0<delta<1-v, the L02 candidate proves

    Pr[W_k >= ceil((v+delta)k)]
      <= exp(-sigma delta^3 k / (2048(1+ln d))).

For connected support the denominator constant improves to 1024. The proof
handles arbitrary Hilbert spaces and commuting von Neumann algebras, not an
identification with finite tensor strategies. The independent operator
audit `../operator_exposure_referee.txt` reconstructs the zero-spectrum
operator Jensen inequality through an epsilon resolvent shift, the bounded
transport at zero spectrum, the normalized mixed-exposure law, the component
barycenter, disconnected-component likelihood drift, selection, and ceiling
rounding. This is source-derived/internal, not formally or externally
validated. It gives no Hamiltonian V,B,C.

2. Named verifier plus one-sided erasure. Lin's MIPco=coRE verifier is a
two-prover, one-round commuting verifier with polynomial question/answer
bit lengths and value 1 versus at most 1/2 (source-reported). Erasing
Alice's question with probability 1/4 and accepting the erased branch gives
omega_new=1/4+3 omega/4, hence value 1 versus at most 5/8, and contracts
maximal correlation to sqrt(3/4) times its previous value. The resulting
question-pair resampling gap is at least (2-sqrt(3))/4>1/15. The wrapper
adds two random bits per copy, one question and answer symbol to Alice's
alphabet, and has a charged polynomial repetition cost conditional on L02.
The question support need not be bounded degree. The verifier acceptance
element is positive in the universal commuting-measurement algebra, but it
does not produce finite row access, fixed qubit count, or a common finite
matrix representation. See `route_game_energy.txt` for the exact interface
and model boundary.

3. BMVZ gap amplification and the PCP gap distinction. BMVZ produces a
QMA-hard constant-promise-gap list of tensor-OR clauses by derandomized
expander walks; after iteration there are polynomially many terms and
polynomial repetition length R, but term locality is O(R), not constant.
The expander samples/combines clauses; it is not an expander consistency
operator on an encoding image. A constant promise gap is not the normalized
all-state image gap gamma. Their sparse-QPCP discussion explicitly leaves
conversion from the tensor representation to efficient sparse matrix access
open. Source and clause calculations: `route_primary_gap_mechanisms.txt`.

4. Direct full-list term-frame/Naimark construction. Write each generated
term h_j=U_j*D_jU_j with D_j diagonal and weights w_j. Then

    V|psi> = sum_j sqrt(w_j)|j> U_j|psi>,
    B = sum_j |j><j| tensor D_j,
    V*BV = H=sum_j w_j h_j.

This is an exact all-state equality, B is a diagonal contraction with one
entry per row, and V has a polynomial circuit from the term generator. The
diagonal predicate can inspect all R repeated registers; row sparsity does
not imply constant locality. The direct-refresh connection
C=(1/2)G((I-S) tensor I)G* has exact kernel and gap 1/2, but every cross
branch block is a relative decoder U_jU_k*. Entry evaluation can be
polynomial while listing that row is exponential. Exact construction/costs
are in `route_game_energy.txt` and `route_diagonal_dilation.txt`.

5. Direct reversible expander clock on term branches. For a regular
constant-gap graph on replicated clause labels, the same frame gives

    C=(1/2)G((I-P_Gamma) tensor I)G*,
    gamma(C)=gap(P_Gamma)/2,
    C_ab=-U_aU_b*/(2 Delta).

This is an exact constant-gap construction algebraically; row support is
1+Delta times the relative edge-row support. In a connected reversible
color-frame graph, the fixed factorwise BJSW seed frames force an edge with
at least 8^(R/(g-1)) entries by telescoping the relative-unitary support
along a path through g colors. If the graph is disconnected by color,
extra logical kernels remain and the image gap is zero. The coordinate
hypercube interpolation has gap at most q/R when an edge changes q bits,
and row degree at most 1+d*8^q; polynomial row degree gives O(log n/R)
gap. These are scoped connector bounds, not arbitrary-C theorems.
See `route_game_energy.txt`, `route_primary_gap_mechanisms.txt`, and
`route_expander_clock.txt`.

6. Coherent active-flag full-list encoder plus arbitrary-enforcer theorem.
For each clause let F_j be its diagonal OR predicate and
J_F|z>=|z>|F(z)>. Set W_j=J_Fj U_j and

    V|psi> = sum_j sqrt(w_j)|j> W_j|psi>,
    B = I_branch tensor I_data tensor |1><1|_flag.

Then V is an explicit polynomial-circuit isometry, B is diagonal and
one-row-sparse, and V*BV=H exactly. For the forced singleton phi/psi
branches, the image projector P=VV* has a selected row with mass m=1/16
over valid psi-branch columns, each selected entry square at most
a=(1/16)8^(-R). The branch block is
sqrt(w_phi w_psi) J_phi U_phi U_psi* J_psi*; valid psi flags are first
removed by J_psi* and the phi flag then written by J_phi, so no equality
constraint on the two branch flag bits is imposed. The general
Chebyshev/row-mass lemma proves that ANY positive contraction C with this
exact kernel and max row degree s obeys

    gamma(C) <= [ln(128) ln(s+1) /
       (4(R ln 8 - ln 2 - ln(s+1)))]^2,

when the denominator is positive. Thus polynomial s and polynomially
growing R force vanishing normalized gap. This rules out all positive
enforcers for this exact active-flag image, not just graph Laplacians or
budgeted positive sums. It does not instantiate N26's fixed auxiliary-sector
positive-budget hypothesis: the flag is branch/data correlated, not a
fixed auxiliary state with an all-workspace floor. The result also does not
rule out a different global V. The proof, including the dimension-free
lemma and exact flag block, is in
`route_syndrome_extension.txt`; the exact BJSW fixture passed.

7. Complement-LCU square-root dilation (new full-list candidate). Add a
silent zero projector so H=sum_j pi_j h_j is a normalized sum of
projections. With R_j=I-2h_j,

    I-H = (1/2)I + (1/2)sum_j pi_j R_j.

A standard LCU unitary U block-encodes I-H. Let
V|psi>=U(|0>_label|psi>) and
B=(I-|0><0|)_label tensor I. Then B is a diagonal row-1 projector,
V is polynomial-circuit, and

    V*BV = I-(I-H)^2 = 2H-H^2,
    H <= V*BV <= 2H.

The label-only B has O(log M) locality. C=U B U* is an exact projection
with gap one and the right kernel. The row ledger is only
1 <= max-row-support(C) <= min{(M+1)2^N, O(M^3 2^(10R))}; no polynomial
row bound or matching lower bound is established. Specified entries are
polynomial-time computable from local factors, but this does not enumerate
a row. This bypasses the scalar-polynomial QSVT no-go below; it is a
particularly concrete surviving candidate where the only unproved
requirement is polynomial row access for C. See the LCU section of
`route_diagonal_dilation.txt`.

8. Rational filtering and detectability amplification on the fixed history
image. The Cycle-2 history isometry has exact compression V*BV=(Q/K)H,
row(C)<=9, and path gap Theta(K^-2). The rational filter
C(C+K^-2 I)^(-1) has gap at least 1/2 but an actual seed-tail row has
8^R entries. A two-layer detectability sweep needs Theta(K^2) rounds and
also has an 8^R row. A positive sparse Schur parent has degree at most 10,
but its normalized gap remains Theta(K^-2); scaling to constant absolute
gap costs norm Theta(K^2). Chebyshev's generic support upper bound is
exponential and is not mistaken for an exact support lower bound. See
`route_gap_amplification.txt`.

9. Fixed-history arbitrary-positive-enforcer obstruction. On the same
history image, a selected phi-tail row has projector mass m=q/K^2 on psi
tail columns and individual entry square a=1/(K^2 8^R). For every positive
contraction C with this exact kernel and row degree s,

    gamma <= [ln(8K^2/q) ln(s+1) /
      (4(ln(q*8^R/2)-ln(s+1)))]^2.

The displayed bound vanishes when R >> ln K ln(s+1); in particular polynomial R versus
polynomial K,s suffices. The result is not limited to reversible,
covariant, or path C, but fixes V to the history image. The factorwise
arbitrary-decoder extension replaces 8^R by (8/7)^R. This proof is
independently audited and saved at
`outputs/research/sol_history_gap/RESULT.txt` and
`outputs/research/games_hamiltonians/cycle2/sol_history_gap_independent_audit.txt`.

10. Non-Clifford common frame for the repeated two-seed pair. For
Q=(P_phi+P_psi)/2, L=I-Q, q=(1-|<phi,psi>|)/2, and
E_R=I-L^tensor R, the pair average H_R and E_R have the same kernel and
satisfy q P_(K-perp)<=E_R,H_R<=P_(K-perp). Diagonalize Q with a fixed
non-Clifford five-qubit unitary S0. Then V=S0^tensor R tensor |0>,
B=diag(I-D0^tensor R), C=I_data tensor |1><1| give gap 1, row degree 1,
and qH_R<=V*BV<=q^-1H_R. B is global 5R-local; exact algebraic Q(sqrt2)
access is O(R). This defeats pair-only exact-row, no-cloning and Clifford
intuition, but has no common factorized envelope for the full overlapping
multi-clause BMVZ sum. Full proof/costs: `route_pauli_obstruction.txt`.

11. Compatibility/no-cloning obstruction and its escape. For common
compressions A,B of two rank-one tests P,Q with overlap c and separate
operator sandwiches alpha P<=A<=beta P, alpha Q<=B<=beta Q, compatibility
forces alpha<=1/(1+c), sharply. For the BJSW pair, alpha<=0.738796...
and alpha=1 is impossible. An additive perturbation bound is also proved.
But a common-label Naimark dilation compresses any weighted aggregate
H=sum w_j H_j exactly into one diagonal projection; therefore this does
not obstruct aggregate B and cannot be promoted from individual clauses
to one aggregate test. See `route_no_cloning_perturbation.txt`.

12. Compression-frame identity and monomial basis obstruction. For any
isometry V and computational basis x, F_x=V*|x><x|V form a POVM and
every diagonal B compresses to sum_x b_x F_x. Thus compression can turn
commuting physical effects into noncommuting logical effects; an exact
qutrit/qubit frame witnesses this. For monomial basis isometries, however,
the compression is logical diagonal. A full-support zero-energy vector
for the repeated seed-pair target forces any positive diagonal compression
to vanish, contradicting alpha H<=A for alpha>0, even though C=I-VV*
is 1-row and gap one. This is only a seed-pair monomial-frame obstruction.
See `route_compression_cone.txt`.

13. Clifford image: positive control for C, negative for common diagonal B.
For any n+a-qubit Clifford image V=U(I tensor |0^a>), a finite-field
small-bias Pauli average yields exact C with
ker C=ran V, C<=I/2, gap >=1/4 and at most q^2+1=O(a^2) entries per
row; q is the least power of two at least 2a, and the root-count bias is
at most (a-1)/q. This rules out a universal impossibility based only on
active workspace, circuit size, and sparse constant-gap C. However every
diagonal B compresses into one commuting logical Pauli algebra. Sol's
full-kernel rigidity proof gives a legal augmented three-color
frustration-free YES instance with nonzero data kernel R and full kernel
projector R tensor S_seed^tensor R. Its X_1 and Z_1Z_2Z_3 coefficients
are both nonzero and anticommute. Loewner comparison forces equal kernels,
contradicting that abelian algebra. This rules out all Clifford-image /
diagonal-B constant-factor compilers on the broad legal generator class
or an explicitly tagged enlargement; it does not establish membership in
a particular canonical hard-reduction image and does not apply if H has
zero kernel. Exact fixture passed. See
`outputs/research/sol_history_gap/RESULT.txt` sections D-E and
`outputs/research/sol_history_gap/KERNEL_RIGIDITY.txt`.

14. Stabilizer qLTC / expander code. For the checked cubical CSS qLTC,
the normalized local-check average has exact 1/m <= gap <= Delta/m with
m=Theta(N), bounded incidence Delta; a one-site Pauli excitation gives
the O(1/N) upper bound despite constant code soundness. An orbit-expander
Laplacian on the same stabilizer image does achieve constant gap and
constant row degree D+1, but it is nonlocal and does not provide the
required diagonal B for the BMVZ sum. In a fixed CSS frame, diagonal
compressions lie in an abelian logical orbit algebra; exact full-family
equality is obstructed, while a free logical eigenbasis leaves an
unpriced efficiency gap. See `route_qldpc_common_code.txt`.

15. Universal sparse enforcer impossibility by coordinate support. For an
explicit polynomial-circuit isometry V with image S=H_(n+1)L_{>n/2},
the dual S-perp has minimum coordinate support at least 2^(n/2+1), by the
Reed-Muller low-degree polynomial support bound. Every exact-kernel matrix
C has some nonzero row in S-perp, hence row degree at least that value,
even with arbitrary coefficients or fixed product workspace. Dense
C=I-VV* still has gap one and an exact polynomial-time rational entry
formula. This proves that circuit access, entry access, and row enumeration
are different resources; it does not rule out choosing another image.
See `route_explicit_access.txt`.

16. Polynomial spectral/QSVT channel obstruction (scoped). A polynomial
dummy-register augmentation gives two eigenvalues lambda_0 and
lambda_1=lambda_0+Delta with lambda_0/Delta->0 and Delta=Theta(2^-n),
while preserving QMA-hardness. For
V|z>=sum_a |a>q_a(H)|z>, sum_a|q_a(x)|^2=1 on [0,1], and an ancilla-only
diagonal effect B, the compression is F(H)=sum_a b_a|q_a(H)|^2. If
alpha H<=F(H)<=beta H, Markov's polynomial derivative inequality forces
degree D>=alpha^(1/4)/(2 Delta^(1/4))=Omega(2^(n/4)). This blocks
polynomial-query scalar-QSVT channels before C. It does not cover
term-dependent LCU or arbitrary data-dependent B. Details, dummy-weight
bit costs and exact eigenvalues are in `route_diagonal_dilation.txt`.

17. Game/Hamiltonian and HDX energy boundary. In a commuting universal
measurement algebra, a repeated verifier's loss is a positive operator
with a uniform no-case floor, but the strategy Hilbert space is
representation-dependent and no finite row oracle follows. For the
specified coRE-complete game family any total computable compiler to a
finite effectively separated spectral problem would decide coRE; this is
not a no-go for the decidable QMA BMVZ family. Separately, HDX/qLTC
combinatorial support soundness is not ordinary expected violation
energy: an explicit one-qubit pair keeps combinatorial violation 1/2
while its minimum expectation energy tends to zero. Do not use either
mechanism as an implicit conversion to a finite constant-gap C. Full
scopes and model costs: `route_game_energy.txt` and
`route_expander_clock.txt`.

WHAT COULD TRANSFORM THE FULL-LIST RESULT

The exact LCU construction is the best current high-ceiling positive
candidate: it already has a polynomial active circuit V, an O(log M)-local
diagonal row-one B, and constants alpha=1,beta=2 for the complete
noncommuting H. Its canonical C is an exact gap-one projection with
polynomial-time specified-entry access, but the known row upper bound is
exponential and no lower bound is known. A direct theorem for this C, or a
new sparse C on exactly its image, would resolve the remaining gate. The
active-flag architecture is more strongly ruled out by row-mass filtering,
so any positive result should explain how it changes the image-projector
row witness.

Other concrete transformation targets are:

* Build one efficiently represented positive envelope E for the ENTIRE
  weighted BMVZ sum with ker(E)=ker(H) and a constant spectral floor on
  ker(H)^perp, whose diagonalizing/common isometry is polynomial and whose
  image has a sparse expander-type enforcer. The two-seed E_R construction
  solves this only for the two-projector tensor-factorized subfamily.
* Use a global, copy-mixing coherent decoder to evade factorwise
  expander-clock and active-flag row-mass barriers, and prove row support,
  exact kernel, and the full Loewner sandwich together. Pairwise CS
  decomposition provides sparse frames for two projections, but compatible
  efficient frames for all BMVZ clauses are unknown.
* Provide a constant-gap sparse image enforcer for the term-dependent LCU
  image without an efficient spectral decomposition. A polynomial circuit
  or block-encoding for C is insufficient; the proof must give a polynomial
  row-list algorithm and normalized spectrum bound.

Each candidate must retain the full generated term list and exact
hardness-preserving membership, and charge branch preparation, row versus
entry access, locality, coefficient precision, and the normalized gap.
Nothing here proves quantum PCP from commuting repetition, from an
efficient sampler, or from a qLTC/HDX soundness statement.

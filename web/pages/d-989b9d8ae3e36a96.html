## Storage conclusion and next allocation

The independently gated CG implementation has conservative O(n^72*(B+logn)) peak storage; the modular-annihilator replacement is now independently gated at O(n^48*(B+logn)) before bounded small quotient/output routines, with the same expected O(rmax*m) source passes and explicit large-prime bit costs. The exact scope, prime-sampler correction and independent four-projection replay are in `notes/metric_use10/cycle17/MODULAR_ANNIHILATOR_INDEPENDENT_GATE.md`. Dense Gaussian peak was O(n^78B), while dense INITIAL storage was only O(n^54B). These are implementation upper bounds, not optimal lower bounds. The coefficient branch still uses huge ambient/source vectors through moderate n; the evaluation branch switches only later. No n>=3 complete degree30 acquisition was executed. No degree58 or universal FLOW speed comparison was run.

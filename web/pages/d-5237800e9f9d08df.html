c03_l09 REVISION — ARBITRARY ONSITE FILTERS ON TREEWIDTH SUPPORT
2026-10-07. Initial checkpoint remains immutable.

ATTRIBUTED CROSS-PHASE STATUS

The original functional-digraph DP in INITIAL.txt remains a valid independent
derivation, but its tractability class is not new after exposure. c03_s03's
exact MPS theorem covers it: the simple undirected support of a row-functional
matrix is a pseudoforest. A tree on N vertices has pathwidth at most
ceil(log2 N), by recursively taking a centroid and adjoining that centroid to
all bags in each smaller component's path decomposition. A unicyclic
component becomes a tree after deleting one cycle edge; adding that edge to a
path decomposition costs at most one extra bag vertex. Thus each support
component has pathwidth O(log n).

From a width-w path decomposition (bag size at most w+1), ordering vertices
by first bag occurrence gives vertex separation at most w+1. At any cut L|R
in that order, let B_L be the earlier vertices with a later neighbor.
F[L,R] has nonzero rows only in B_L, and F[R,L] has nonzero columns only in
B_L, so each rank is at most |B_L|<=w+1. Hence c03_s03's rank sum is at most
2(w+1)=O(log n). Its arbitrary-t exact MPS
therefore covers the functional-digraph class, including column collisions.
My O(n^2) tree/cycle recurrence remains a sharper scoped cost, not a new
tractability boundary.

The stronger result below extends the hard-only bounded-support Grassmann
contraction independently reported by c03_l08 and c03_s01. Their frozen
reports use a local functional supported on empty, row-only, and column-only
states, so they count the t=0 hard-disjoint norm. c03_s03 handles arbitrary
t in a broader low-cut-rank class. My increment is a complete local sign
derivation and exact treewidth-FPT counter for all rational t_i>=0, including
overlap/double occupancy, arbitrary site restrictions, exact prefixes, and
an exact self-reduction sampler. This is a costed refinement/extension of
known tensor contraction mechanisms; novelty and priority are UNKNOWN.

THEOREM AND EXACT INTERFACE

Let F be an explicit n-by-n matrix over Q(i), let each t_i be a nonnegative
rational, and let A_i be any subset of {0,u,d,ud}. For I,J subset [n] with
|I|=|J|=k, assign site i state 0 if i is in neither set, u if i is in I\J,
d if i is in J\I, and ud if i is in I intersect J. Define

 C_k(F,t,A) = sum_{|I|=|J|=k; all local states in A_i}
              |det F[I,J]|^2 product_{i in I intersect J} t_i,

with increasing row and column order in each minor. If the simple support graph
G has an explicitly supplied elimination order of induced width w, all n+1
coefficients and every local-prefix completion norm are computable exactly
in FPT time in w and polynomial bit complexity. The algorithm accepts all
diagonal entries, complex phases, cancellations, zero sectors, t=0 hard
projection, and arbitrary attraction t>2. It needs neither log-concavity nor
an approximation theorem.

LOCAL GRASSMANN IDENTITY

For each site use anticommuting generators x_i,y_i,u_i,v_i in the displayed
site order. Form

 P_F = product_{i,j}(1+F_ij x_i y_j)
       product_{i,j}(1+conjugate(F_ij) u_i v_j).

Every bilinear is even, so these factors commute. In species-block order
(all x, then all y, all u, all v), the coefficient for fixed I,J is
(-1)^(k(k-1)/2) det F[I,J] times
(-1)^(k(k-1)/2) conjugate(det F[I,J]), hence |det F[I,J]|^2.
Reordering x_I y_J u_I v_J from species-block order to site-block order
contributes sign (-1)^(k^2-h), where h=|I intersect J|. To see the parity,
row-row and column-column site pairs each contribute binom(k,2) inversions,
which cancel modulo two. For every row-site/column-site pair with unequal
indices there is one inversion; equal indices contribute none. There are
k^2-h such unequal pairs. Since k^2-h is congruent to k-h modulo two, the
shuffle sign is (-1)^(k-h).

Apply the following even local linear functional at each site, and set it to
zero on every other local exterior monomial:

 ell_i(1)=1,
 ell_i(x_i u_i)=-z,
 ell_i(y_i v_i)=1,
 ell_i(x_i y_i u_i v_i)=z t_i.

The last plus sign is in the canonical local order x,y,u,v. It is the
row-only factor (-z) times the column factor 1 and t_i, with one additional
minus sign because (x_i u_i)(y_i v_i)=-x_i y_i u_i v_i.
For h overlap sites, row-only sites contribute (-z)^(k-h), overlap sites
contribute (z t_i)^h, and column-only sites contribute 1. This local sign
(-1)^(k-h) cancels the species-to-site shuffle sign. Therefore the fully
contracted polynomial is exactly

  (ell_0 tensor ... tensor ell_(n-1))(P_F)
      = sum_{k=0}^n C_k(F,t,A) z^k,

after replacing any disallowed local state's functional value by zero.
The identity includes diagonal F_ii: its edge factor has one-site scope and
contributes to the all-four local monomial when t_i>0. Omitting diagonal
edges, as is valid under hard projection, would be incorrect here.

The paired local mask requires x_i and u_i together, and y_i and v_i
together. Thus the first determinant replica and its conjugate have equal row
sets and equal column sets. Edge expansion itself equates the number of
selected rows and columns. The local table then imposes exactly the desired
onsite state and weight. This proves the count identity term by term; no
positivity-of-coefficients assumption is used during contraction.

TREEWIDTH CONTRACTION AND COST

Create one factor per nonzero F_ij with scope {i,j}; diagonal factors have
scope {i}. Each edge factor has at most four exterior terms and is
constructed exactly. Process sites in the supplied elimination order: multiply
all factors containing the site, apply ell_i, erase its four generators, and
emit the resulting message on the remaining scope. By the induced-width
definition, every message scope is contained in at most w later neighbors.
Every intermediate message therefore has at most 2^(4(w+1)) exterior masks.
The extra z polynomial has degree at most n.

For a simple graph of treewidth w, |E(G)|<=wn. There are at most two directed
matrix entries per off-diagonal support edge and n diagonal entries, so the
number of edge factors and elimination merges is O(n(w+1)). With dense
polynomial convolution and mask-pair multiplication, one factor merge costs
at most O(n^2 2^(8(w+1))) rational operations. A conservative total bound is

  O(n^3 (w+1) 2^(8(w+1))) rational operations,
  O(n^2 (w+1) 2^(4(w+1))) rational storage.

These are intentionally simple, conservative bounds; sparsity and shared
messages can improve them. Every exact intermediate is a sum of products of
input entries, conjugates, and at most one t_i per site. Clearing the input
denominators gives polynomial bit heights (coarsely O(nL+n log n) for an
explicit input of total encoding length L); the number of arithmetic
operations and representation sizes are FPT in w. There is no conditioning
or smallest-singular-value assumption. The code reports/accepts an explicit
order. Its min-degree order is only a heuristic; no treewidth order is
smuggled in for free. If a decomposition is supplied, an induced-width order
can be read from it; if a decomposition must be acquired, charge its actual
algorithm and cost separately.

For w=O(1) the method is polynomial, and for w=O(log n) it remains polynomial.
Unlike a generic path-order MPS consequence, the displayed bound is FPT in w.
The exact count also supplies all prefix completion masses: fixing a prefix
merely deletes local states from the corresponding ell_i table.

EXACT SAMPLER

Fix sector k and a valid prefix. For the next site, run the counter four times
with that site forced to 0,u,d,ud (or only the states still permitted). The
four nonnegative rational values sum exactly to the current completion mass.
Choose a state with probability equal to its value divided by this sum and
continue. The chain rule gives exactly the normalized squared-minor law over
occupation configurations. Exact rational weights can be scaled to integers;
uniform `randbelow` by rejection from fair bits has acceptance probability at
least one half. The sampler's expected random-bit/arithmetic work is
polynomial in the counter's output bit length. There is no conditioning on a
rare event and no inverse sector probability. It samples occupation labels;
it does not prepare a coherent state, synthesize phases, or claim a physical
gate/energy bound.

  arXiv:quant-ph/0511069, https://arxiv.org/abs/quant-ph/0511069, gives the
  generic deterministic treewidth contraction principle. These establish
  substantial representational/contraction prior art. The selective reads do

  not evidence of novelty. The single-occupancy numerical MPS scope in the

- Standard Grassmann/tensor contraction is established methodology. Exact
  rational gauge or arbitrary-attraction FPT implementation priority is

- No generic parity FPRAS, unrestricted BCS sampler, hardness reduction,

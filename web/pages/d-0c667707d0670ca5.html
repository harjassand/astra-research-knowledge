# Weighted orthogonal quartic: a necessary stationary singular locus

2026-10-07. Universal proof below; independent exact matrix checks are supplementary. This is a search-method obstruction, not a proof of the full weighted landscape conjecture.

For \(G=G^T\), define \(F_G(W)=\sum_k m_k^TGm_k\), \(m_k=W_{:k}^{\circ2}\), \(W\in O(n)\). Let \(P=I-\mathbf1\mathbf1^T/n\). Adding \(\mathbf1v^T+v\mathbf1^T\) to \(G\) changes \(F\) by the constant \(2\mathbf1^Tv\): every \(m_k\) sums to one, and \(\sum_km_k=\mathbf1\). Every symmetric \(G\) is gauge-equivalent to \(G_0=PGP\). Thus the relevant metric space is
\[
\mathcal V=\{G_0=G_0^T:G_0\mathbf1=0\},\qquad
\dim\mathcal V=d=n(n-1)/2.
\]
If the original \(G\succ0\), then \(G_0\) is positive definite on \(\mathbf1^\perp\), so it is nonzero for \(n\ge2\).

The exact first-order map at fixed \(W\) is
\[
\Phi_W(G_0)_{ij}=S_{ij}-S_{ji},\quad i<j,\qquad
S=W^T[W\circ(G_0M)],\quad M=W^{\circ2}.
\]
It maps \(\mathcal V\) linearly into the \(d\)-dimensional skew coordinate space. Orthogonal stationarity is precisely \(\Phi_W(G_0)=0\); the irrelevant factor four in the Euclidean gradient does not affect this equation.

**Theorem.** For every \(n\ge2\), \(\det\Phi_W\) is not identically zero on either determinant component of \(O(n)\). Therefore the set where some \(G\succ0\) can make \(W\) stationary is contained in a proper algebraic singular locus. A generic continuously sampled orthogonal \(W\) has no such metric.

Proof. Take a skew \(A\) with every \(A_{ij}\ne0\), and a feasible curve
\(W(t)=I+tA+O(t^2)\), for example a Cayley curve. Then
\(M(t)=I+O(t^2)\), and for \(i\ne j\),
\[
S_{ij}=tA_{ij}(G_{0,ij}-G_{0,jj})+O(t^2),\qquad
\Phi_{W(t)}(G_0)_{ij}
=-tA_{ij}(G_{0,ii}+G_{0,jj}-2G_{0,ij})+O(t^2).
\]
The map from a centered Gram matrix to its \(\binom n2\) pairwise squared-distance contrasts is an isomorphism. Explicitly, set \(D_{ii}=0\),
\(D_{ij}=G_{0,ii}+G_{0,jj}-2G_{0,ij}\); then
\(G_0=-\frac12PDP\). This identity follows by centering the two rank-one terms containing \(\operatorname{diag}(G_0)\). Domain and codomain have equal dimension, so the inverse identity proves the isomorphism.

Hence the leading coefficient of \(\det\Phi_{W(t)}\) is a nonzero constant times \(t^d\prod_{i<j}A_{ij}\). For sufficiently small nonzero \(t\), the map is invertible, and its determinant polynomial is not identically zero on \(SO(n)\). A signed column reflection moves between components while preserving the existence of a stationary metric: \(F_G(WD)=F_G(W)\), and the tangent/gradient maps are invertibly transformed. Thus the same conclusion holds on the other component. A nonzero real polynomial on a smooth algebraic chart has a measure-zero zero set, giving the generic statement. Discrete rational sampling need not assign zero probability to that locus; the claim is generic geometry, not a probability bound for a finite grid.

Consequences: generic exact Cayley \(W\) followed by a stationary-\(G\) SDP will generally return only the constant-objective gauge kernel and cannot examine the intended nonglobal stationary landscape. Such infeasibility is uninformative about absence of traps. A useful inverse search must parametrize the singular locus, exploit exact structured stationary families, or optimize \(W,G\) jointly and then certify the stationary point. Near-permutation fixed-W samples are particularly unsuitable: the first-order distance map is explicitly invertible there.

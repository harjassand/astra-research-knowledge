# Independent audit target: several almost commuting contractions

Let a known density Ω commute with k Hermitian contractions A_i. Let

    η = max_ij ||[A_i,A_j]||_(2,Ω),  ||X||_(2,Ω)^2=Tr Ω X*X.

Candidate elementary deduction: commuting Hermitian contractions B_i exist with

    max_i ||A_i-B_i||_(2,Ω) <= C_k η^(1/(2^k-1)),

and each B_i has at most ceil(2/h)+2 spectral values, h=η^(1/(2^k-1)). No dimension or minimum-eigenvalue dependence.

The random-grid inequality is the load-bearing observation. Diagonalize a current Hermitian contraction X jointly with Ω. Shift width-h grid boundaries uniformly in [0,h). Let P be pinching to the resulting bins. For a current contraction Y commuting with Ω,

    E ||Y-P(Y)||_(2,Ω)^2
       = sum_rs p_s |Y_rs|^2 min(1, |x_r-x_s|/h)
       <= (1/h) sum_rs p_s |Y_rs|^2 |x_r-x_s|
       <= ||[X,Y]||_(2,Ω) ||Y||_(2,Ω) / h
       <= ||[X,Y]||_(2,Ω) / h.

Round X to bin centers, clipped into [-1,1], with operator-norm error <=h. Pinch all other remaining Y to the same grid. Select one offset bounding the SUM of their squared errors by the expectation. Work inside the existing nested spectral blocks so every previously rounded B remains fixed and commuting.

If all remaining current matrices differ from their original A by <=d_j in weighted norm, their pairwise commutators are <=η+4d_j. This uses ||XY||_(2,Ω)<=||X||op||Y||_(2,Ω), and the analogous right-multiplication bound when the right factor commutes with Ω. Hence

    d_0=0;
    d_(j+1) <= d_j + sqrt(k (η+4d_j)/h),  0<=j<k-1.

With η=h^(2^k-1), induction gives

    d_j <= C_(k,j) h^(2^(k-j)-1).

In fact a_(j+1)=(a_j-1)/2 for a_j=2^(k-j)-1. At j=k-1 the exponent is one. Round the last score without another pinch. Each final B_i differs by <=d_(i-1)+h<=C_k h. All rounded matrices share one global width-h grid for their own step; there are O(1/h) values per score even when the nested partition has many supplied reference blocks.

Prior art: Bansil–Kachkovskiy, arXiv:2608.31000, Theorem 1.1 proves pair exponent 1/3; Corollary 1.4 states multi-matrix exponent 1/3^(k-1). The latter is 1/9 for k=3; this common-width recursion is 1/7. This is a written deduction, not a validated novelty claim. It is not an operator-norm approximation theorem. The construction never assumes right multiplication is contractive for a factor not commuting with Ω.

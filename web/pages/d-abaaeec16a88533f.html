This is the one main result with an external mathematical premise: Tang et al., arXiv:2609.15059v1, Theorem 2 at zero non-Gaussian gates (only stated specialization imported;full proof not independently certified). For m-mode code with k>0 logical qubits, Majorana distance d_F>=3, F_G(C)<=[1-H2^-1(k/m)]^floor((d_F-1)/2),H2^-1 on [0,1/2], bounding overlap with any Gaussian mixture. If only non-Gaussian inputs are lossy standard blocks rho_i and Gaussian processing succeeds p with fidelity>=1-epsilon to specified pure codeword, positivity and tensor robustness domination imply p(1-epsilon)<=[prod_i(1+R_i)]F_G(C). Thus sum_i log(1+R_i)>=floor((d_F-1)/2)*[-log(1-H2^-1(k/m))]+log[p(1-epsilon)];at constant rate/success/fidelity,uniform small eta, n=Omega(d_F/eta^4).
Scope is that input-loss/Gaussian-processing architecture. No code-preparation achievability, arbitrary extra non-Gaussian gates/noisy hardware, or loss record. Theorems A-D do not depend on Tang or Chen-Liu; source says no new OpenAI math-release manuscript is a premise.

STRONGEST CLAIM

The external-field balance step for determinant-weighted paired bases can be
compiled with rational ambient row scales and fixed-bit precision. In
particular, the square roots implicit in converting edge-scale updates to
ambient row scaling are avoidable: a geometric rational grid with ratio 5/4
keeps every two-hole row maximum in [0.4075...,1], stronger than the required
[1/4,1]. There is also a deterministic coordinate-dominated starting law for
any explicit rational-complex F: after assigning activity epsilon=2^-Q to
each original pair and unit activity to all coordinate pairs, the law is
within 1/128 total variation of a uniform complete-graph matching. Q is
polynomial in n and the input bit length. Its two-hole ratios can be placed
inside the balance window by one rational row scaling, without evaluating any
determinant sum.

These results remove algebraic-number and initial-conditioning concerns from
the balance/subdivision interface. They do not acquire the later empirical
hole ratios, produce a microscopic sampler, or prove mixing. A sharp generic
barrier is also recorded: additive estimates of raw hole ratios cannot
deterministically choose balancing fields when a row maximum may be
exponentially small; a relative lower bound or a known balanced base is
necessary for that oracle interface.

1. EXACT RATIONAL AMBIENT-FIELD IDENTITY

Let V be an n-row rational-complex vector-pair representation with n even.
Each allowed basis selects both columns of n/2 pairs; pair activities are
positive rationals. For even R subset [n], let Z_R be the sum of activity
times squared determinant over bases on rows R, and let
g_ij=Z_[n]\{i,j}/Z_[n]. If D=diag(tau_1,...,tau_n), tau_i>0 rational, then

  Z_R(DV) = (product_{i in R} tau_i^2) Z_R(V),
  g_ij(DV) = g_ij(V)/(tau_i^2 tau_j^2).

The full-basis law is unchanged, because every full determinant is multiplied
by the same det(D)^2. The partition itself changes by the known rational
factor product_i tau_i^2, so it can be corrected exactly. This applies to
V=[I,F^T] and to its private-coordinate subdivisions; it uses only rational
row scaling and exact determinants.

2. ROBUST GRID BALANCING THEOREM

Suppose symmetric rational estimates G_ij satisfy

  alpha <= G_ij <= 3,   g_ij <= G_ij <= g_ij+2 alpha,
  max_{j!=i} g_ij >= 1/8 for every i,

with alpha=10^-5. Run the standard one-pass recurrence v_i=2 initially and,
in a fixed vertex order, replace

  v_i <- max_{j!=i} G_ij/v_j.

The constraints v_i v_j>=G_ij are preserved, each row has a tight neighbor,
and alpha/2<=v_i<=2. The assumed true row maximum also gives v_i>=1/16:
when row i is updated, a neighbor with g_ij>=1/8 has v_j<=2. On a final tight
edge, G_ij=v_i v_j>=1/256, so g_ij/(v_i v_j)>=1-512 alpha.

Now round each v_i upward to the smallest q_i=(25/16)^{m_i} not below v_i,
where m_i is an integer. Set tau_i=(5/4)^{m_i}, so q_i=tau_i^2 and tau_i
is rational. The exact grid comparison gives 1<=q_i/v_i<25/16. Every scaled
hole ratio is at most one. On a tight edge it is greater than

  (256/625)(1-512 alpha) = 795904/1953125 > 1/4.

Thus r_i(DV)=max_j g_ij(DV) lies in [1/4,1] for every i. The grid has
constant bit size when alpha is fixed. If G has polynomial bit length, the
one-pass rational operations have polynomial bit length; over K stages the
cumulative row multipliers have O(K) bits per row. The known partition
correction has O(nK) bits. No irrational square root or floating comparison
is needed. This is deterministic given the one-sided interval estimates G;
it does not explain how to acquire those estimates from F without samples or
another partition oracle.

3. DETERMINISTIC COORDINATE-DOMINATED START

Assume the explicit matrix F has n rows and total rational-complex encoding
length L. Use the original pairs (e_i,f_i), f_i=row_i(F)^T, and every
coordinate pair (e_i,e_j), i<j. Let M=n+binom(n,2). Every column norm is at
most R0=2^s for s=L+ceil(log2 n)+1. For any even retained row set R, each
mixed basis (one containing at least one original pair) has squared
determinant at most R0^(2n) by Hadamard, and activity at most epsilon when
each original pair has activity epsilon<=1. There are at most 2^M pair
subsets. The coordinate-only partition is exactly (|R|-1)!!, at least one.

Choose Q=M+2ns+7 and epsilon=2^-Q. Then the total mixed contribution on
every even R is at most

  epsilon * 2^M * R0^(2n) = 1/128.

Consequently Z_R^coord <= Z_R^mix <= (1+eta)Z_R^coord for eta=1/128,
uniformly over all retained row sets, including the full set and every
two-hole set. In particular, for n>=2,

  1/((1+eta)(n-1)) <= g_ij^mix <= (1+eta)/(n-1).

The coordinate-only full law is uniform over complete-graph perfect
matchings. The mixed law has the same conditional distribution on its
coordinate-only component, so the uniform matching law is within eta total
variation of it. This gives a deterministic approximate base sample without
an inverse rare-event rejection. The epsilon denominator has Q+1 bits,
Q=O(n^2+nL), so the numerical smallness is polynomially representable.

Set q=(25/16)^m with m the least integer for which
q^2 >= (1+eta)/(n-1), and set tau=(5/4)^m uniformly on all rows. This is
found by exact rational comparisons. Since q^2 is within a factor
(25/16)^2=625/256 of its threshold, the scaled two-hole ratios lie in

  [256/(625(1+eta)^2), 1] subset [1/4,1].

This initial balance does not compute any positive determinant sum. The
uniform matching sampler is an eta-approximation to the mixed base law, not
a sampler for later determinant-weighted stages.

4. FINITE SCHEDULE AND SUBDIVISION COST

To raise original-pair activity from epsilon to 1, use lambda_j=epsilon
(1+1/n)^j. The number of stages is at most 1+2n Q, because
log(1+1/n)>=1/(2n). Each basis uses at most n/2 original pairs, so one
stage changes any basis weight by a factor in [1, (1+1/n)^(n/2)] subset
[1,2). Coordinate-pair activities can then be reduced from 1 to
D0^-1, D0=10^8(n+1)^4, in O(n log n) stages with the same factor-two
bound. All activities are rational; their binary lengths remain polynomial
in n and L. Rebalance each stage from rational interval estimates using the
grid theorem above. The final coordinate activity is D0^-1; the previously
proved aggregate capacity transfer applies when the resulting row maxima are
balanced. It bounds the inflation from its added calibration probes by a
factor two relative to the chosen positive-coordinate base. It does not
identify that base with the F-only target, nor remove that base's
coordinate-line mass.

For the graph-style subdivision, the coordinate graph has all activities in
[D0^-1,1], so the floored bottleneck is B_ij=1 and H_i=1. The existing
profile therefore has K_sub=0, p=2, and 4p+1=9 edges per coordinate path.
This is constant-size in the original F norm. More generally, the private
two-coordinate vector-pair gadget preserves an arbitrary rational pair
activity lambda by using three pair activities lambda_L,lambda_M,lambda_R
with effective activity lambda_L*lambda_R/lambda_M; repeating it with
matched adjacent factors yields the exact odd path profile and a known
partition multiplier. Rational input activities of B-bit length remain
polynomially encoded. The profile proves an exact counting identity, not a
mixing or determinant-ratio bound. Large or small determinants of F still
control microscopic transition energies and are not removed by subdivision.
More generally, if rational line activities have maximum at most 2^P, the
same profile uses O(P) subdivision depth and rational activities with
polynomial bit length in P and the input activity length. Hadamard also gives
O(nL+n log n) bits for an individual input determinant; summing at most 2^M
such terms adds only O(M) output bits. This is an arithmetic-size bound,
not a polynomial-time way to evaluate the sums: the enumeration may still
have exponentially many terms.

5. SHARP RAW-ADDITIVE-ORACLE BARRIER

For n=2 take F_t=[[0,t],[1,0]]. The full hard-pair partition is t^2+1, the
empty-row partition is 1, and the only two-hole ratio is g_12=1/(t^2+1).
For even L, t=2^(L/2) and t=2^L both have g_12<2^-L. An additive oracle
with error 2^-L may return the same value 0 on both. Any balancing scale
product q_1 q_2 must satisfy g_12 <= q_1 q_2 <= 4g_12 to put the scaled
ratio in [1/4,1]. For L>=4 these admissible intervals are disjoint for the
two inputs. Hence raw additive estimates alone cannot deterministically
acquire a balancing field without a lower bound, relative precision, or a
known balanced initialization. This is only an oracle-interface barrier:
the small example is easy from F itself, and it is not a lower bound against
arbitrary deterministic algorithms.

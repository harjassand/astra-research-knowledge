## G1. The literal indexing defect is not a satisfied assumption

Primary TeX lines1796–1818 define strong faithfulness using I(T_t;E_(t-ell)|X_<t). E_(t-ell) is a deterministic function of that same conditioning history. Hence H(E_(t-ell)|X_<t)=0 and the CMI is0 for every distribution. An active edge cannot meet a strictly positive margin under this literal definition. Treating a counterexample as meeting it would be wrong. The peer correctly marks the assumption malformed and evaluates the more charitable pre-candidate history query separately.

Under that charitable main query, A→M→Y with A fair and both independent flip noises Ber(1/4) is a valid obstruction to incremental-prediction→direct-parent. The joint probabilities in(A,M,Y) lexicographic order are(9,3,1,3,3,1,3,9)/32. They are all positive. Conditioning on M makes A and Y independent. Marginally P(Y=1|A=0)=3/8 and P(Y=1|A=1)=5/8, so I(Y;A)=log2-h_b(3/8)>0. A and M remain dependent given Y, and M and Y remain dependent given A; this positive binary chain is faithful. It has a unique direct target parent M and a leaf target. An independent irrelevant terminal event can pad the indexing into the source two-chain factorization without changing these conclusions.

The main outcome query omits the later mediator M, giving a false A→Y edge even with exact prediction. Leafhood removes children/spouses, not ancestors. This rejects the stated nonparent implication under that query; it does not prove that code using a different full-context query fails.

## G4. The replacement kernel score and sharp transfer pass

Let Z be all pre-target variables except candidate A, including any later mediators. In a fully observed ordered SCM with independent structural noises, target kernel k(a,z) is its conditional probability given the full earlier assignment. Assume positivity, a minimal kernel-parent DAG and a query law rho(a,z)=lambda(z)pi(a|z) with support witnessing every dependence under consideration. For independent A,A' conditional on the same Z,

    D(k)=E[k(A,Z)-k(A',Z)]^2=2 E_Z Var_pi k(A,Z).

D=0 exactly when the queried kernel is constant in A almost everywhere. With the support/minimality assumptions this is equivalent to nonparenthood in the kernel DAG. It is not an individual's actual-cause certificate, nor a hidden-DAG identifiability claim. Positivity plus the witness law are needed for the parent direction.

Write e=hat k-k. Independent pairing gives

    E[e(A,Z)-e(A',Z)]^2=2 E_Z Var_pi e<=2 E_rho e^2.

Binary Pinsker bounds e^2<=KL(k||hat k)/2 pointwise. L2 reverse triangle and d rho/d nu<=kappa therefore yield

    |sqrt D(k)-sqrt D(hat k)|
       <=sqrt(E_rho KL)<=sqrt(kappa epsilon_obs).

No target entropy term is missing. The constant1 is sharp: on a rare query context set k(1|a)=1/2+(2a-1)h, model1/2 and uniform A. Then D(k)=2h^2 and kappa epsilon_obs=KL(Ber(1/2+h)||Ber(1/2))=2h^2+O(h^4). This is a known Hilbert variance/sensitivity transfer specialized to the acquired causal kernel interface, not generic novelty.

## G6. Full support is not efficient witness acquisition

For unknown w among2^m contexts, an exact probability oracle can equal baseline1/2 everywhere except w, where it is1/2+(2a-1)h. A baseline transcript and an alternative transcript coincide until w is queried. For any adaptive randomized algorithm using at most K distinct contexts, coupling to uniform w bounds that hit probability by K/2^m. Baseline false-positive probability<=alpha then bounds average alternative acceptance by alpha+K/2^m. Uniform sensitivity>=1-alpha requires K>=(1-2alpha)2^m. The source kernel is positive/minimal but no ordinary faithfulness is promised. This is an oracle/query-law obstruction, not a lower bound on inspecting neural-network weights.

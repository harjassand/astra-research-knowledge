Let \(F:\mathbb R^{m\times2}\to\mathbb R\) be \(C^1\) and rank-one convex. Work on a periodic rectangle with \(x\)-period \(L\). For a potential \(\varphi(x,y)\), write
\[ P=(\varphi_x\mid0),\qquad Q=(0\mid\varphi_y). \]
Both increments are rank one, although \(P+Q=D\varphi\) generally is not.
For a rank-one increment \(Z\), define
\[ \mathcal R_F(C,Z)=F(C+Z)-F(C)-DF(C)[Z]\ge0. \]
Direct subtraction gives
\[ \begin{aligned} F(B+P+Q)-F(B) ={}&\mathcal R_F(B+Q,P)+\mathcal R_F(B,Q)\\ &+DF(B+Q)[P]+DF(B)[Q]. \end{aligned} \tag{1} \]
The last term has zero average.
Define a one-form on profile space:
\[ \boxed{ \alpha_{F,B}(u)[v] = \mathbb E_y\,DF\!\left(B+(0\mid u_y)\right)[(v\mid0)]. } \tag{2} \]
Then the complete Jensen gap is
\[ \boxed{ \begin{aligned} J_F(B,D\varphi) ={}&\mathbb E\!\left[ \mathcal R_F(B+Q,P)+\mathcal R_F(B,Q) \right]\\ &+\frac1L\oint_u\alpha_{F,B}. \end{aligned} } \tag{3} \]
The first line is nonnegative. The second is a single signed circulation of the joint profile.
Equation (3) is available for every smooth periodic potential. It does not impose affine phase, nonvanishing amplitude, a polar representation, or resonance separation.

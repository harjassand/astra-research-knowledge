# A weaker prior stability interface worth testing

Root, 7 October 2026. **Research target, not an adopted stability theorem.** Actual local filling for the May2026 memory remains open. This note prevents the separate downstream stability question from being forgotten or silently assumed.

De Roeck, Khemani, Li, O'Dea and Rakovszky, arXiv2411.02384v3, Section2.2, permits a check-graph generation radius proportional to the cardinality of a connected check set. Section2.3 restricts perturbations to that Hamiltonian's graph. This is a weaker collar requirement than the old BHM statement, but graph locality is not ambient Euclidean locality in a folded embedding. The v3 revision is dated12August2026 and describes a funding update; the journal article is from2025. These are prior results.

The precise candidate bridge is as follows. A uniform filling radius Cr for every sufficiently small ambient ball would put all stabilizers supported on a connected physical-proximity check set S inside an ambient ball of radius O(|S|). To use the prior theorem one still needs a compatible bounded-degree qubit/check graph in which all filler checks have distance O(|S|) from S. Accidental spatial proximity does not create an original Tanner edge.

One possible proof extension is to allow declared local supports containing identity sites. Bounded declared incidence gives finite check/qubit degree. It must preserve both support-connectivity implications used in Sections3.3–3.4: a connected qubit set has connected check extension, and a connected check set has a connected union of declared qubit supports of size at most declared check weight times its cardinality. Extra commuting checks in the word-sandwich expansion are algebraically harmless. Nonzero commutators still require actual overlaps, which are contained in declared overlaps. However, every later proof use of graph distance, connectivity, TQO-II and locality norms must be audited before adopting this extension; the published statement itself fixes actual supports.

A grid of decoupled single-qubit Z ancillas could provide paths across empty geometric gaps. A successful proof would need to charge its volume, preserve distance and ground-sector structure, transfer the filling premise, and show that physical finite-range perturbations have bounded intensive Pauli norm. Polynomial volume overhead would preserve a positive-power distance lower bound relative to the logarithmic stability requirement. None of those geometric/proof obligations is replaced by calling the larger graph a supergraph.

Root separately proved a limited conditional relative-bound lemma in `LINEAR_BUFFER_RELATIVE_BOUND.md`; it covers already ground-annihilating perturbations, not the full block-diagonalization. Transport is independently checking it. This new prior may remove the need to rebuild the old BHM flow if its graph interface can be legally extended, but that remains a question.

Finally, zero-temperature spectral-gap and ground-band stability are distinct from exponential thermal memory lifetime under perturbed open-system dynamics. Even a complete ground-sector stability composition would not by itself establish the latter.

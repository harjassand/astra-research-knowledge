# A distance bound from the stronger local anchor

Root, 7 October 2026. **Conditional on the actual fine-level anchor and controlled maps; independently reconstructed by pde_transport9.** This consequence does not rely on the source's asserted power-law code distance.

At each fine recursion level i>=1, assume every closed error of either CSS sector supported in a ball of radius r0=r_*+1 is a boundary, where r_*=a lambda/(lambda-1). At the seed this stronger assertion is false and is not assumed. The degree-one projection is a chain map, has support-radius rule r -> r/lambda+a, and every closed fine error satisfies e+IPe=DK, with the dual-sector identity as well.

If a closed level-i error lies in B(x,r), r<=lambda^(i-1), project i-1 times and stop at level1. Its projected radius is

    r_(i-1)=r/lambda^(i-1)+r_*(1-lambda^(-(i-1))) <= 1+r_*.

It is closed, hence is a boundary by the fine-level anchor. Recursively lifting through e+IPe=DK makes the original error a boundary too. This uses the identity for all closed errors; the unknown original error need not already be a global boundary. Therefore every ball of radius lambda^(i-1) is correctable in both CSS sectors, in the Pauli centralizer sense. Mixed logical Paulis have a nontrivial X or Z component, whose support is contained in their total support.

Take a nontrivial closed sector error of weight w. Split its supported qubits into components connected when they share an opposite-type syndrome check. Every component is closed: a check contributing to two components would connect them. At least one component is not a boundary, or their sum would be a boundary. If its weight is w'<=w, a spanning tree roots all its qubits within physical distance 2(w'-1), because each two-edge Tanner path has length at most2. Thus it would be a boundary whenever 2(w'-1)<=lambda^(i-1). Consequently

    d_i >= floor(lambda^(i-1)/2)+2.                 (1)

This is a conservative cardinality bound. It is not a claim that the whole support is connected, that the seed is correctable, or that all unbounded-radius closed errors are boundaries.

The local replacement uses at most8(ell+1)^2 fine vertices per old face. The source bounds qubit degree by7 and edge-face degree by4, giving the safe parent face count<=7N_i. Thus N_(i+1)<=56(ell+1)^2 N_i; take B=64(ell+1)^2 and N_i<=5B^i. These template/incidence bounds were independently reconstructed by pde_spectrum9. Equation(1) gives d_i>=c N_i^epsilon, epsilon=log(lambda)/log(B)>0. Even the weaker facts log N_i=O(i) and d_i grows exponentially already suffice for the graph-local stability distance condition after polynomial padding.

There is also a simple padding bound independent of coordinate magnitudes. The seed Tanner graph is connected. Nonisolation and overlap0/2 put every parent edge in a square. Each replacement template has connected Tanner one-skeleton and nonempty corner/boundary interfaces, so the quotient gluing stays connected; this was independently reconstructed by pde_spectrum9. The original qubit interaction graph is consequently connected, and every two qubits can be joined using at most N_i-1 graph edges. Each such edge has physical length at most2. The physical diameter is at most2(N_i-1), so the containing rectangular integer grid box has O(N_i^3) sites in three dimensions. This avoids deriving polynomial padding from a possibly very loose recursive coordinate recurrence.

Combined with the Clifford-grid bridge, full-radius global stabilizer filling and these two actual-family facts would provide the distance and volume premises for original-system spectral stability. It still proves nothing about thermal lifetime under perturbed dynamics, achievable temperatures, practical scale or optimal geometric parameters.

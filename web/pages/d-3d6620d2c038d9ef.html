# Leaf 06: the smooth-form ceiling for determinant lower bounds

Date: 2026-10-08

## Scoped question

Can degree, projective smoothness, and essential variable count alone yield a super-cubic lower bound for the determinantal complexity of an affine restriction of the (m\times m) permanent?

## Exact obstruction

Work over \(\mathbb C\), with \(r,d\ge 2\), and set

\[
F_{r,d}(x_1,\ldots,x_d)=\sum_{i=1}^d x_i^r.
\]

Its degree is exactly \(r\), and all \(d\) variables are essential. Its projective hypersurface is smooth: the partial derivatives are \(r x_i^{r-1}\); their common zero is only the zero vector, which is not a projective point.

There is an affine-linear determinant representation of order

\[
N=1+d(r-1).
\]

Index rows and columns by a hub \(0\) and vertices \((i,j)\), where \(1\le i\le d\) and \(1\le j\le r-1\). Define the matrix \(M\) by

\[
M_{00}=0,\qquad M_{(i,j),(i,j)}=1,
\]

and, for each \(i\), put \(x_i\) in positions

\[
(0,(i,1)),\quad ((i,j),(i,j+1))\ (1\le j<r-1),\quad ((i,r-1),0),
\]

with the last entry replaced by \((-1)^{r-1}x_i\). Set all remaining entries to zero.

To expand \(\det M\), each branch vertex either uses its diagonal 1 or lies on the unique directed cycle through the hub and that branch. The hub has no diagonal term, so every nonzero determinant term must use exactly one such cycle: two cycles cannot both use the hub. Choosing branch \(i\) contributes the permutation sign \((-1)^{r-1}\) times the edge product \((-1)^{r-1}x_i^r\), hence contributes \(x_i^r\). All unused branch vertices contribute their diagonal 1. Therefore

\[
\det M=\sum_{i=1}^d x_i^r.
\]

This is an exact representation, so it also bounds border determinantal complexity:

\[
\operatorname{bdc}(F_{r,d})\le \operatorname{dc}(F_{r,d})\le 1+d(r-1).
\]

The witness has \(dr\) variable coefficients and \(d(r-1)\) constant diagonal coefficients, up to one optional hub constant. Thus its sparse coefficient description has \(O(rd)\) entries of height 1, or \(O(rd\log(rd))\) bits when row, column, and variable indices are explicitly encoded. A dense coefficient-array serialization would separately write zero entries (up to \(O(dN^2)\) scalar slots) and is not claimed to have linear output length. Determinantal complexity counts matrix order; it does not charge determinant-evaluation time.

## Consequence for geometry-only criteria

Any lower-bound rule that is valid for every smooth degree-\(r\) hypersurface in \(d\) essential variables must respect

\[
L(r,d)\le 1+d(r-1).
\]

In particular, no such rule can give \(\omega(rd)\) uniformly. The scale \(\Omega(rd)\) is possible and is asymptotically matched by this example, so this is not a refutation of a degree-times-dimension lower bound.

An affine restriction of \(\operatorname{Perm}_m\) has degree at most \(m\). It depends on at most \(m^2\) essential affine coordinates because the source permanent has only \(m^2\) input coordinates. Therefore a universal smooth-form bound based only on these parameters can contribute at most

\[
1+m^2(m-1)=O(m^3).
\]

This precisely blocks super-cubic or super-polynomial escalation by repeated use of the same degree/smoothness/essential-dimension information. It does not block a cubic lower bound. The September 2026 Family 108 manuscript's claimed smooth-form estimate \((r-1)(d-1)/(4e)\) is consistent with the Fermat upper bound and would yield a cubic permanent bound if its separate permanent-projection and smooth-section arguments are valid.

This ceiling concerns criteria uniform over all smooth forms and depending only on degree and essential dimension. It does not rule out invariants of the particular permanent restriction, such as additional dual or conormal data, if those invariants are proved to force higher determinantal complexity.

For an affine-only variant, \(1+F_{r,d}\) also has a smooth affine zero hypersurface and is represented by the same matrix after changing \(M_{00}\) from 0 to 1; its determinant is \(1+F_{r,d}\). The homogeneous Fermat form above is the relevant example for a smooth-projective-initial-form criterion.

## What this does and does not falsify

The explicit determinant is a falsifier for any proposed *universal smooth-form criterion stronger than order \(rd\)*. It is not a counterexample to a cubic permanent lower bound: for \(r\asymp m\), \(d\asymp m^2\), both the candidate \(\Omega(rd)\) lower bound and this upper bound have cubic scale.

The Family 108 webpage says its cubic theorem has a Lean formalization, but at the pinned release commit both posted theorem declarations end in `by sorry`. This directly falsifies the narrower claim that these posted Lean files mechanically certify the results. It does not falsify the mathematical theorem or replace a proof audit.

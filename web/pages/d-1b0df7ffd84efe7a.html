REVISION — DIRICHLET DOMINATION GIVES A SINGLE EB LIFT OF ALL POWERS

Theorem

Let (A,tau) be a finite-dimensional tracial algebra. Assume Phi:A->A is
UCP, tau-preserving, positive as an L2(tau) operator, selfadjoint, with
spectrum in [0,1]. Suppose Psi:A->A is a tau-preserving EB UCP map that is
a positive selfadjoint L2 contraction and, for some c>=1,

  I-Psi <= c(I-Phi)

in L2 Loewner order. Then for every integer m>=0, the composed channel

  E_m = Psi o Phi^m

is EB, tau-preserving, and satisfies

  sup_{H=H*, ||H||_infinity<=1}
      ||E_m(H)-Phi^m(H)||_(1,tau)
  <= sqrt(c g_m),
  g_m = (2m)^(2m)/(2m+1)^(2m+1),                      (1)

with g_0=1. For m>=1, g_m is the exact maximum of
(1-lambda)lambda^(2m) over 0<=lambda<=1. In particular,

  sqrt(c g_m) ~ sqrt(c/(2e m)) -> 0.                  (2)

There is no dimension, label-count, reference-spectrum, or spectral-gap
factor. The slow eigenspace lambda=1 has zero error in the energy bound and
is retained by Psi: the comparison itself forces Psi to fix every
Phi-fixed vector.

Proof

Post-composition of a channel with an EB channel is EB, so E_m has the
claimed channel type. For any Hermitian contraction H put X=Phi^m(H).
Since 0<=Psi<=I as an L2 operator, functional calculus gives
(I-Psi)^2<=I-Psi. Therefore

  ||(I-Psi)X||_2^2
    = <X,(I-Psi)^2 X>
    <= <X,(I-Psi)X>
    <= c <X,(I-Phi)X>
    = c <H,Phi^(2m)(I-Phi)H>.

The last equality uses selfadjointness of Phi. Its spectrum lies in [0,1],
and ||H||_2<=||H||_infinity<=1, whence

  <H,Phi^(2m)(I-Phi)H>
    <= max_{0<=lambda<=1} (1-lambda)lambda^(2m) ||H||_2^2
    <= g_m.

For m>=1, differentiating f(lambda)=(1-lambda)lambda^(2m) gives the
maximizer lambda=2m/(2m+1) and value in (1). For m=0, the maximum is 1.
Finally ||Y||_(1,tau)<=||Y||_(2,tau), so the displayed map bound follows.

The composition order matters: E_m applies Phi^m first, then Psi. The
opposite order need not be EB-approximating by this argument.

Consequences for the campaign

The exact bistochastic-instrument SOS in
work/cycle4/detailed_balance_broadcast_attack.txt supplies Psi with c=2.
Thus the entire corrected-instrument class has the dimension-free power
lift

  beta_m^(instrument) <= sqrt(2) *
      (2m)^m/(2m+1)^(m+1/2)
      ~ 1/sqrt(e m).

The same conclusion applies to any other proven c-Dirichlet subclass,
including positive selfadjoint selfcompatible qubit factors and their
listed product/mixture closures, provided the EB comparator from that
subclass remains part of the supplied interface. It does not apply to an
arbitrary compatible channel unless a universal c and a corresponding EB
map are proved or acquired. In that unrestricted case the main CP-range
gate remains open.

For a bounded likelihood experiment rho_H=sigma(I+H) with ||H||<=theta,
and r=sup_H ||Phi(H)-H||_(1,tau), telescoping gives
||Phi^m(H)-H||_1<=m r. The EB channel E_m then reconstructs every member
with half-trace error

  sup_H T(E_m(rho_H),rho_H)
     <= (1/2)[theta sqrt(c g_m) + m r].                (3)

This pays the actual likelihood amplitude theta because all channels fix
the reference/scalar. Equation (3) is a consequence for any admitted
c-Dirichlet class, not a replacement for the fixed-sandwich-to-tracial
reduction and its imported dependencies.

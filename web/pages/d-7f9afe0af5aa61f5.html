## A. A finite union needs a witness or a selection term

Kocabay–Akkuş–Yalçın, arXiv2606.29331v1, was submitted28June2026. Read: main statistical §§1–4, AppendixA.1/A.2 and B.1–B.6, with reported experiments read but not rerun. Lemma4.6 uses the pointwise inequality max_k V_k<=sum_k V_k, where V_k is the signed supremum in component k. That inequality requires V_k>=0, which does not hold for arbitrary bounded components.

An exact counterexample has n=1, C_0={constant0}, C_1={constant1}. Each singleton has empirical Rademacher complexity0, whereas their union has E max(0,epsilon)=1/2. For any n the union complexity is E(S_n)_+/n>0. Translating each component separately to zero changes this union. Translation invariance for ONE shared fixed output shift is valid; it cannot identify unions with different component shifts.

A sufficient repair is to put the same zero-output function in every component. Then every V_k is pointwise nonnegative. For recursive compositions, zero belongs to the leaves and actual operators Phi(0)=0 ensure every operator component contains zero, so the sum bound is valid at each level. Theorem4.7 states this centered condition; its recursion can therefore be reconstructed for that exact centered class. This does not certify the original uncentered mixed vocabulary automatically. For example, exp/cos have value1 at zero while +, multiplication and sin have value0. Subtracting their different offsets is a change of the composite library unless an exact representation equivalence is supplied.

The competent iid control is Nomura–Hamano–Ono2604.17402v2, revised12June2026, Lemma1: a bounded finite union can instead be controlled by the largest component complexity plus an envelope times sqrt(log(number of components)/n). Its fixed-tree Lipschitz parameter argument in §4.2 is a further supplied-structure control. Only those passages and the counting discussion were checked here; the complete paper is not adopted as a theorem oracle. Fitted empirical slopes are also not an acquired uniform Lipschitz envelope, and a continuously parameterized operator family is not one free fixed finite-vocabulary member.

The tree paper's displayed explicit multiplier is (K b sqrt(2) L)^(d-1). An O(L^d) shorthand with K,b fixed still hides depth-dependent factors in its constant; it is not uniform if d varies. None of these observations resolves efficient acquisition of the correct symbolic law library.

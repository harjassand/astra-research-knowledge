# Elementary independent PDE witness and measurement-cost obstruction

Take the unit disk, known interface radius 0<R<1, conductivity c₁>0 inside radiusR, c₂>0 outside. For mode cos(nθ), n≥1, set core u=C r^n cos(nθ) and shell u=(A r^n+B r^(−n))cos(nθ). Interface potential and flux continuity give

C=A+B R^(−2n), c₁C=c₂(A−B R^(−2n)),

so B/A=−tR^(2n), t=(c₁−c₂)/(c₁+c₂)∈(−1,1). Boundary flux is n c₂(A−B)cos(nθ); hence the ND eigenvalue is

μ_n(c₁,c₂)= [1−tR^(2n)]/[n c₂(1+tR^(2n))].

This derivation is independent of localized-potential theory. Sine has the same eigenvalue.

## Secant infinite rank for ALL distinct positive parameter pairs

If c₂≠c₂′, then n(μ_n(c₁,c₂)−μ_n(c₁′,c₂′))→1/c₂−1/c₂′≠0, so the differences are nonzero for all sufficiently large n. If c₂=c₂′ and c₁≠c₁′, t≠t′ and the scalar rational function t↦(1−tz)/(1+tz) is strictly decreasing for z=R^(2n)>0. Every n gives a nonzero difference. Thus the ND difference has infinite rank, including pairs whose conductivity contrast changes sign between the two layers.

## Tangent infinite rank in EVERY nonzero direction

The inner derivative is

∂μ_n/∂c₁=−4R^(2n)/[n(c₁+c₂)²(1+tR^(2n))²]≠0.

For a direction v=(v₁,v₂), nDμ_n[v]→−v₂/c₂². Thus v₂≠0 gives nonzero high mode derivatives. If v₂=0, v₁≠0 and the inner derivative gives a nonzero derivative in every mode. The directional derivative has infinite rank.

## Explicit one-input reconstruction

Take any g∈L²_mean0(circle) with nonzero cosine Fourier coefficient α_n for every n (or at least an unbounded sequence plus one mode). Output cosine coefficient β_n=μ_nα_n. With exact complete response, recover μ_n=β_n/α_n. Then

c₂=[lim_(n→∞)nμ_n]^(−1),

t=[1−n c₂μ_n]/[R^(2n)(1+n c₂μ_n)] (any n),

c₁=c₂(1+t)/(1−t).

A trace-class Gaussian with all mode variances positive has these nonzero coefficients almost surely. This radial reconstruction does not establish novelty: simultaneous Fourier diagonalization makes the single input idea elementary in this symmetry class. It is an independent exact witness of the general theorem's mechanism.

## Exact obstruction: rank alone does not grant economical noisy recovery

At fixed outer c₂ the inner derivative scales like R^(2n)/n. For R=1/2, the exact rational two-state interior-only secant is about9.04e−22 at mode32 and2.45e−41 at mode64. Gaussian coefficient decay multiplies these already tiny amplitudes. A proof of nonzero high modes does not give a finite-precision measurement budget.

Moreover a single pure-frequency current g=cos(nθ) gives only one scalarμ_n although its response is a full function; distinct two-parameter coefficients share that scalar. An explicit level curve: given μ_n=m, choose c₂ with 0<nc₂m and t=(1−nc₂m)/(R^(2n)(1+nc₂m))∈(−1,1), then c₁=c₂(1+t)/(1−t)>0. Choices in a nonempty interval around any positive state give the same full response. Thus sufficiently rich excitation is essential; 'any nonzero input' is false for this class.

## Finite refinement (2026-10-06)

The infinite-mode reconstruction above is superseded for this explicit radial model by notes/rank_pde/finite_construction.md: any two distinct harmonics with nonzero input amplitudes already give exact global identification, an explicit inverse Lipschitz bound on compact parameter rectangles, and a finite noisy reconstruction certificate. In particular, full Gaussian support is unnecessary in this solvable model, although it remains a sufficient general continuum hypothesis. B disjoint harmonic pairs give explicit inverse moments of order p<B, with exactly2B input modes and2B voltage scalars.

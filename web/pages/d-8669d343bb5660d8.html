N06 — Evolutionary acquisition of predictive heredity
Frozen record v2; 2026-10-09. It preserves v1 and corrects its cost optimum, soft-selection growth accounting, finite-branching costs, and prior-art scope.

Status: internally derived candidate mechanism and exact special-model theorem. No claim of novelty, priority, empirical validation, or a general biological law. The binary switching result overlaps classical bet-hedging theory. The finite-state conditional-score extension is mathematically exact in the stated life cycle, but evolutionary convergence under realistic mutation/recombination and finite carrying capacity remains open.

1. Target and boundary

Target: determine when an evolvable inherited state-transition rule can acquire predictive structure from an exogenous fluctuating environment without supplying the environment's transition matrix to the organism, and quantify the growth premium after hereditary transmission losses.

The mechanism below supplies a finite state alphabet and a fitness interface that rewards phenotype e in environment e. It does not supply the transition matrix P or the predictive table K=P. A population-level distribution of phenotypes is endogenous; it is not treated as a lineage memory variable. The model uses explicit parent-to-offspring state transitions. The environment is generated exogenously and is not estimated from population frequencies.

The exact central model is asexual and has hard viability selection. Two extensions are stated separately: a finite-mismatch-strength approximation for infinite populations, and a finite-founder branching model for demographic drift. Generic sexual recombination is not represented by a fixed one-parent kernel. A sexual model requires the parental-pair law and a two-parent transmission kernel; the scalar recombination loss below applies only when recombination destroys an intact predictor haplotype with a specified probability.

2. Joint genotype, epigenetic-state, and environment process

Let S be a finite phenotype/epigenetic-state alphabet. Let (E_t) be an irreducible stationary Markov chain on S with stationary distribution μ and transition matrix P(e'|e)>0. Positivity is assumed here so all logarithms and KL divergences are finite. For a predictor genotype θ, let K_θ(e'|e) be the probability that an offspring of state e has inherited epigenetic/phenotypic state e'. Thus θ encodes a transition table, but not the environment's P.

Hard-selection life cycle, generation t to t+1:

1. The focal population has N_t adults, all in state E_t. This is true after the first generation because only adults whose state matches the current environment survive.
2. Each adult produces B potential offspring. Each offspring carries the focal predictor table intact with probability s_θ. For an intact copy, its state is drawn from K_θ(·|E_t).
3. In environment E_{t+1}, only offspring with state E_{t+1} survive.

In the deterministic infinite-population model, the focal table's abundance therefore obeys

    N_{t+1} = N_t B s_θ K_θ(E_{t+1}|E_t).

This scalar update is lifecycle-consistent because selection first collapses the state distribution to the current environmental state. There is no mixture of parental memory states outside the logarithm. If one adds independent noisy memory states across cells before selection, the update becomes a population average and this scalar formula no longer holds; see §7.

Let the intact-table probability be s_θ=(1-u_θ)(1-r_θ), where u_θ is the probability that a strategy-changing mutation removes a copy from the focal predictor class and r_θ is the probability that recombination with the resident breaks the intact, multi-locus predictor haplotype. Let c_θ≥0 be a per-generation maintenance cost in log-growth units, so the effective multiplier is multiplied by exp(−c_θ). These are separate from K_θ: K_θ is the epigenetic state transition expressed by an intact predictor, while u_θ and r_θ are losses of the predictor genotype/table. If mutations or recombinants create useful neighboring predictor tables, they must be tracked as additional strategy types rather than charged as losses.

3. Exact long-run growth and information-regret identity

Theorem 1 (hard-selection growth identity). For any fixed θ with K_θ(e'|e)>0 on every transition used by P, almost surely

    λ_θ := lim_{T→∞} (1/T) log(N_T/N_0)
         = log B + log s_θ − c_θ
           + Σ_e μ(e) Σ_{e'} P(e'|e) log K_θ(e'|e).

Equivalently,

    λ_θ = log B + log s_θ − c_θ
           − H(E_{t+1}|E_t)
           − Σ_e μ(e) D_KL(P(·|e) || K_θ(·|e)).                 (1)

Proof. Taking logs of the exact update and summing gives

    (1/T)log(N_T/N_0)
      = log B + log s_θ − c_θ
        + (1/T)Σ_{t<T} log K_θ(E_{t+1}|E_t).

The finite-state irreducible Markov chain is stationary ergodic, so the last time average converges almost surely to Σ_{e,e'} μ(e)P(e'|e)log K_θ(e'|e). For each row e,

    Σ_{e'}P(e'|e)log K_θ(e'|e)
      = −H(P(·|e)) − D_KL(P(·|e)||K_θ(·|e)).

Average over μ. This proves (1), with every limit taken along the exogenous environment law.

If the intact-copy probability s and maintenance cost c are held fixed while K varies, the unrestricted optimum over row-stochastic K is uniquely K*=P, with

    λ* = log B + log s_θ − c_θ − H(E_{t+1}|E_t).

If architecture costs depend on K, the total optimum is instead

    argmax_K { Σ_{e,e'} μ(e)P(e'|e)log K(e'|e) + log s(K) − c(K) }.

The maximizer need not equal P. For example, a sufficiently large cost for any state-dependent row makes the memoryless table preferable even when P has positive predictive information. In the rest of §3, statements about K*=P hold at fixed s,c. This is an evolutionary prediction rule in the precise sense that the inherited phenotype state of a surviving parent is E_t and offspring state probabilities K(·|E_t) forecast E_{t+1}. Selection favors the table that assigns higher probability to realized next states. The organism is not handed P; selection compares heritable table variants through their realized descendant counts. Acquisition still presupposes that the phenotype alphabet and an evolvable table architecture exist and that mutation can reach suitable rows.

Let the memoryless baseline K_0(e'|e)=μ(e'), with transmission factors s_0 and cost c_0. Then

    λ_θ − λ_0
      = I(E_t;E_{t+1})
        − Σ_e μ(e)D_KL(P(·|e)||K_θ(·|e))
        + log(s_θ/s_0) − (c_θ−c_0).                              (2)

The equality follows from H(E_{t+1})=H(μ) and
Σ μ(e)P(e'|e)log μ(e')=−H(E_{t+1}). The first two terms are the predictive information available from the inherited state less the predictor's log-score regret. Equation (2) is a sharp threshold in this life cycle: a predictor beats the memoryless baseline exactly when its information gain less its regret exceeds the intact-transmission and maintenance costs.

If K_θ=P, the score regret is zero. With s_0=1 and c_0=0, the threshold is

    I(E_t;E_{t+1}) > −log[(1-u_θ)(1-r_θ)] + c_θ.                 (3)

For small u,r the transmission cost is u+r+O(u²+r²), but (3) uses exact log costs. The relevant environmental quantity is predictive mutual information, not marginal entropy alone. A process can have the same marginal distribution and different predictive value.

4. Acquired-table dynamics and exact binary consequence

Suppose a finite set Θ of predictor genotypes is already present, each at positive abundance, and no strategy-changing mutation occurs after initialization. Their abundance trajectories are independent under the common exogenous environment, and each has exponent λ_θ from (1). For any θ,φ,

    lim_{T→∞}(1/T)log[N_T(θ)/N_T(φ)] = λ_θ−λ_φ almost surely.

Therefore a unique maximum of (1) dominates all other represented tables in the infinite-population deterministic model. This proves selection of a predictor conditional on the table being represented; it does not prove that mutation will find it, that a finite population will fix it, or that an organism can invent a state alphabet absent from the model.

Binary example. Let S={0,1}; E_t is stationary fair and P(E_{t+1}=E_t)=q, with 0<q<1. Restrict K to a symmetric switching rule K(1−e|e)=ν and K(e|e)=1−ν, holding s and c fixed across ν. Then

    λ(ν)=log B + log s − c + q log(1−ν)+(1−q)log ν.

For 0<ν<1, differentiation gives the unique maximum ν*=1−q. The learned epigenetic switch probability equals the environmental flip probability. Against the memoryless rule ν=1/2,

    λ(ν*)−λ(1/2) = log 2 − h(q) + log(s/s_0) − (c−c_0)
                  = I(E_t;E_{t+1}) + log(s/s_0) − (c−c_0),

where h(q)=−qlog q−(1−q)log(1−q). This is a derived consequence of the exact model, but the binary switching result is already within classical stochastic bet-hedging theory and is not claimed as new.

Example values: q=0.8 gives I=log 2−h(0.8)=0.1927 nats/generation. If u=0.01, r=0.02, and c−c_0=0.05, then log(s/s_0)=log(0.99·0.98)=−0.03025 and the net relative exponent is 0.1124 nats/generation. The implied asymptotic abundance ratio per generation is exp(0.1124)≈1.119 in the hard-selection model. These numbers are algebraic evaluations of (2), not biological measurements.

5. Positive but finite mismatch fitness

Hard selection is an idealization. A related deterministic asexual model gives a controlled approximation when mismatches still reproduce. Let state and environment alphabets both be S, fitness be R>δ>0 on a match and δ otherwise, and K(e'|e)≥κ>0 for every pair. Normalize the within-strategy adult state frequencies p_t to sum to one. The lifecycle is

    w(a,e)=R 1{a=e}+δ 1{a≠e},
    W_t=Σ_a p_t(a)w(a,E_t),
    q_t(a)=p_t(a)w(a,E_t)/W_t,
    p_{t+1}(b)=Σ_a q_t(a)K(b|a),
    log(N_{t+1}/N_t)=log s−c+log W_t.

After one transmission, p_t(b)≥κ. Also

    1−q_t(E_t)
       = (1−p_t(E_t))δ/[p_t(E_t)R+(1−p_t(E_t))δ]
       ≤ δ/(κR).

Since K entries lie in [0,1],

    |p_{t+1}(E_{t+1})−K(E_{t+1}|E_t)| ≤ δ/(κR).

Both W_{t+1} and δ+(R−δ)K(E_{t+1}|E_t) are at least
b_κ=δ+(R−δ)κ≥κR. Using |log x−log y|≤|x−y|/min(x,y),

    |log W_{t+1}−log[δ+(R−δ)K(E_{t+1}|E_t)]|
       ≤ ω_K := δ/(κ²R).                                       (4)

The state-frequency recurrence describes the composition conditional on an intact predictor table. The absolute abundance update also includes its retention/cost multiplier:

    N_{t+1}/N_t = s exp(−c) W_t.

Consequently, (λ_K=log s−c+lim_{T→∞}T^{-1}Σ_{t<T}log W_t).

Thus, if λ_K is the absolute long-run growth exponent of this positive asexual process, then

    J_{R,δ}(K)=Σ_{e,e'} μ(e)P(e'|e)log[δ+(R−δ)K(e'|e)].

Then |λ_K−[log s−c+J_{R,δ}(K)]|≤ω_K. The positive matrix product has an almost-sure top Lyapunov exponent under the stationary ergodic environment; alternatively (4) directly bounds limsup and liminf of the residual log-fitness average around the ergodic limit J.

For k≥κ,

    log[δ+(R−δ)k] = log R + log k + a_{R,δ}(k),
    0≤a_{R,δ}(k)≤β_K := log(1+δ/(Rκ)).

Combining this with (2), for candidate K and baseline K_0 having entry floors κ and κ_0, respectively, a sufficient condition for the candidate's deterministic long-run exponent to exceed the baseline is

    I(E_t;E_{t+1}) − E_E D_KL(P(·|E_t)||K(·|E_t))
      + log(s/s_0) − (c−c_0)
      > ω_K+ω_0+β_K+β_0.                                     (5)

This is a finite-selection-strength consequence, not a Kelly limit. It is conservative; (4) and the exact objective J can be used directly. The requirement K≥κ is substantive: if the predictor assigns zero probability to a realized transition, the hard-selection score can be −∞, and the uniform approximation fails. Epigenetic reset/mutation can enforce a positive floor, but that alters K and creates a measurable score regret.

6. Finite demographic drift and its boundary

For the finite-founder version, realize the per-generation log maintenance cost c≥0 as an independent per-offspring retention probability exp(−c); this makes the finite stochastic process exactly implement the deterministic cost. Give each focal adult B potential offspring and let each offspring independently retain the predictor table with probability s, pass the maintenance gate with probability exp(−c), and draw its state from K. Conditional on an environmental transition e→e', the number of intact, matching offspring from one adult is Binomial(B, s exp(−c)K(e'|e)). Thus a finite focal clone has integer random abundance

    N_{t+1} | N_t,e,e'  ~  Binomial(BN_t, s exp(−c)K(e'|e)),

with conditional mean multiplier m(e,e')=Bs exp(−c)K(e'|e). This is a one-type branching process in a finite-state Markov environment whose state can be the transition edge z_t=(E_{t−1},E_t); the edge chain has transition (e,e')→(e',e'') with probability P(e''|e'). Its environmental log-mean is exactly

    E log m(E_t,E_{t+1}) = λ_K.

For B≥2, s exp(−c)>0 and K>0, the per-edge offspring laws are Binomial(B,ξ_z), ξ_z=s exp(−c)K(e'|e)>0. They have finite moments, finite E|log m_z| and E|log(1−p_{0,z})| (the edge set is finite and every ξ_z>0), and p_{0,z}+p_{1,z}<1. The finite-state edge chain is irreducible when P is strictly positive. Athreya and Karlin's branching-process-in-Markov-random-environment extinction theorem then gives positive survival probability from one or more finite founders iff E log m_z=λ_K>0; for λ_K≤0 extinction is almost sure under these nondegeneracy conditions. This claim is source-applied, not reproved here. The exact extinction probabilities can be represented as the minimal solution of the edge-indexed generating-function recursion

    q_z = Σ_{z'} R(z,z') (1−ξ_z+ξ_z q_{z'})^B,

where R is the edge-chain transition matrix; extinction from n founders in edge z has probability q_z^n. This handles demographic sampling noise and finite founding numbers in the branching phase. It is not a carrying-capacity model and does not prove fixation in a finite Wright–Fisher or Moran population.

A closed-form sufficient lower bound is available when every environmental transition is individually supercritical. If

    ξ_min := s exp(−c) min_{e,e'}K(e'|e) > 1/B,

then every generation's offspring law stochastically dominates Binomial(B,ξ_min). Coupling each offspring trial to a shared uniform random variable shows that the focal clone dominates a Galton–Watson process with this constant offspring law. Let q_min be the smallest root in [0,1] of

    q_min=(1−ξ_min+ξ_min q_min)^B.

Since Bξ_min>1, q_min<1, and from n founders survival probability is at least 1−q_min^n, uniformly over the environmental path and initial edge. This bound is conservative: λ_K>0 may hold even when some edge means are ≤1, in which case use the Markov-environment extinction recursion instead. For the grid architecture in §11, K≥ε makes the sufficient condition (B s e^{-c}ε>1) directly checkable.

For a large fixed-size population near a resident equilibrium, the early count of a rare predictor allele is approximated by a branching process whose per-generation mean is its relative reproductive output. In the hard-selection, memoryless-resident example K_0(e'|e)=μ(e'), the relative mean is

    m_rel(e,e')=[s_θ/s_0] exp[−(c_θ−c_0)] K_θ(e'|e)/μ(e'),

and its Markov-environment exponent is exactly the right-hand side of (2). A positive exponent predicts positive establishment in the branching approximation for a rare allele, subject to the usual large-N/low-frequency approximation. At fixed finite N, the approximation ceases to be exact once mutant frequency is no longer small; fixation, coexistence, and mutation-selection balance require the full count-state Markov chain. A positive asymptotic exponent alone is not a fixation theorem.

7. Recombination and the model-class limit

The kernel K_θ is a one-parent transmission channel for asexual reproduction. For sexual reproduction with parental states a,b and offspring state y, the correct transition is a pair kernel K_r(y|a,b) and the population update has the form

    p_{t+1}(y)=Σ_{a,b} Q_t(a,b)K_r(y|a,b),

where Q_t is the selected mating-pair distribution. Under random mating Q_t may be q_t⊗q_t; under assortative mating it is different. It is generally frequency-dependent and nonlinear in p_t. It cannot be replaced by a fixed row-stochastic one-parent K without specifying the mate law. In rare-modifier analysis, linearizing around a resident population gives a time-dependent one-mutant kernel obtained by averaging K_r over resident mates. Its growth is a random matrix/cocycle exponent.

The scalar r in s=(1-u)(1-r) is therefore only the probability that a particular multi-locus predictor block is broken and leaves the focal predictor class. It is not a general quantitative law for recombination's effect on prediction. If recombinant tables remain functional, replace sK by the full offspring-table transition matrix; if recombination changes the memory/phenotype association, use K_r and the resident mate distribution.

8. Causal identifiability obstruction and decisive test

Observed phenotype frequencies and environment histories do not identify inheritance. In a general asexual model, selection followed by transmission is

    q_e(a)=p(a)w(a,e)/Σ_x p(x)w(x,e),
    p'(b)=Σ_a q_e(a)K(b|a).

For one observed full-support transition p→p', the same p' is generated by (i) pure selection with K=I and w(a,e) proportional to p'(a)/p(a), or (ii) equal fitness and a parent-independent reset K(b|a)=p'(b). Thus frequency-environment association alone cannot establish inherited prediction. Asexual lineage tracking identifies the parent-offspring channel K; sexual studies must additionally observe or control parental pairs.

For this candidate mechanism, a discriminating experiment would use isogenic, barcoded predictor-table variants in replicated populations and randomize environmental transition matrices while holding environmental marginals fixed. Measure each parent-state/offspring-state transition, absolute descendants per barcode, and table retention. Randomly erase or scramble the inherited state in one arm after E_t is realized, then randomize E_{t+1} according to the assigned transition matrix. Under the model, the intact-minus-reset log-growth contrast tends to

    I(E_t;E_{t+1}) − predictor regret − transmission loss − maintenance cost,

with the finite-strength correction bounded by (5). A same-marginal, different-transition-order protocol distinguishes predictive inheritance from adaptation to environment frequencies alone. The randomized reset identifies a causal effect of the inherited state; natural frequencies alone do not.

9. Counterexamples, alternatives, and remaining work

• Predictive information is not sufficient for positive net growth when the table is inaccurate or transmission is costly. Equation (2) gives the exact failure condition.
• Entropy rate alone is not a sufficient statistic. The gain over the best history-free phenotype distribution is I(E_t;E_{t+1}) in this first-order model. Two processes with the same marginal state frequencies can have different I and therefore different predictor advantages.
• In the no-memory case I=0, a table that varies by parent state has no score advantage when P(·|e)=μ for every e; any positive intact-table cost makes it worse.
• If a strategy table assigns zero mass to a transition that occurs with positive probability, its long-run hard-selection growth is −∞. Positive mutation floors avoid this but impose regret.
• The full-state optimal table K=P presupposes that surviving phenotype states identify current E_t. If selection is weak, observations are noisy, or environments are hidden, the inherited state is only a lossy statistic and the target is P(E_{t+1}|M_t); the soft-selection approximation in §5 quantifies one perturbative regime.
• Alternative route: a transgenerational feedback can estimate marginal environment frequencies without a conditional predictor table. That mechanism is already in Xue–Leibler (2016); it is not evidence for the transition-table mechanism here.
• Alternative route: directly optimize a stochastic response policy using the full matrix cocycle for soft selection and a frequency-dependent sexual inheritance map. This is the correct extension, but no closed general information threshold has been derived in this record.

Unresolved exact gates: (i) derive convergence or a mutation-selection concentration result outside the rare-mutation successive-substitution idealization, especially under mutation-selection balance and finite carrying capacity; (ii) derive the finite-N fixation probability or a sharp establishment bound under a carrying capacity; (iii) replace the scalar recombination integrity loss with an explicit two-parent model and quantify when recombinant predictor rows improve versus destroy prediction; (iv) verify whether the conditional-table result is genuinely new beyond existing stochastic switching, information-value and transgenerational-learning models; (v) identify an empirical organism/circuit where the state alphabet, response table mutability, and parent-offspring memory channel are all measurable. No biological law or novelty claim follows before these gates close.

11. A mutation-accessible finite-table acquisition mechanism

This section supplies a concrete acquisition path that was missing from v1. It remains a mathematical mechanism, not a claim that a named organism implements it. It removes the requirement that the best predictor table be present at initialization, but it still supplies a generic table architecture and a mutation graph. It does not supply P, the table K=P, or the direction of a beneficial mutation.

Let |S|=d, assume P(e'|e)>0, and consider a finite genotype set Θ_L. Each θ∈Θ_L stores a d×d table whose rows are probability vectors on the finite rational grid

    G_{L,a}={ (k_1/L,...,k_d/L): k_i∈Z, k_i≥a, Σ_i k_i=L },

for integers L>d a≥1. The genotype's table is K_θ. A point mutation transfers one count unit within one row: k_i→k_i−1, k_j→k_j+1. This is a finite connected mutation graph for each row and hence for the table. The admissible code alphabet, floor a/L and local mutation operation are generic architecture supplied to the system; P is not.

In a rare-mutation substitution idealization, hold strategy-altering mutations rare enough that only one table mutant segregates at a time; every table has the same intact-line transmission s and maintenance c. Conditional on a given table being represented, its hard-selection growth exponent is

    λ(θ)=log B+log s−c+Σ_e μ(e)Σ_i P(i|e)log K_θ(i|e).

For a one-unit mutation in row e from donor i to recipient j, the relative invasion exponent is exactly

    Δλ_{i→j}(e)=μ(e)[P(i|e)log((k_i−1)/k_i)+P(j|e)log((k_j+1)/k_j)].       (6)

This is selection's long-run score difference; no organism or mutation rule computes P. If architecture costs depend on the table, add Δlog s−Δc and the following ascent result only applies to mutations whose total cost-adjusted Δλ is positive.

Theorem 2 (local mutation ascent reaches a globally best grid table). For fixed costs independent of θ and positive μ(e), every table in Θ_L that is not a rowwise maximizer of

    F(K)=Σ_e μ(e)Σ_i P(i|e)log K(i|e)

has a single-row one-unit transfer mutation with Δλ>0. Therefore every sequence of strictly growth-increasing point mutations terminates after finitely many substitutions at a global maximizer of F over Θ_L; there are no strictly suboptimal local maxima on this grid.

Proof. Fix a row e. For coordinate i define the discrete marginal gain

    g_i(n)=P(i|e)log((n+1)/n),  n≥a.

It is nonincreasing in n, and strictly decreasing if P(i|e)>0. Increasing coordinate i from n to n+1 gains g_i(n); decreasing coordinate i from n to n−1 loses g_i(n−1). Suppose an allocation k is not globally optimal. Take any better allocation k'. The total number of units gained by coordinates with k'_j>k_j equals the number lost by coordinates with k'_i<k_i. Concavity makes every gain marginal no larger than that recipient's first gain g_j(k_j), and every loss marginal no smaller than that donor's last removable marginal g_i(k_i−1). If every legal one-unit transfer had gain at most loss, then every recipient's first gain would be ≤ every donor's last removable marginal; pairing equal numbers of gained and lost units would imply F(k')≤F(k), contradiction. Thus some legal transfer has strictly positive ΔF. Applying this independently to every row proves the first claim. Since Θ_L is finite and each accepted step strictly increases F, no cycle is possible and the walk stops. At its stopping table, no row has an improving unit transfer, so the same exchange argument makes every row globally optimal. ∎

For a grid with entry floor ε=a/L and a rowwise covering radius h of the true row P(·|e), the best grid table has score regret

    Σ_e μ(e)D_KL(P(·|e)||K(·|e)) ≤ d h²/ε.                       (7)

Indeed, for probability vectors p,k with k_i≥ε, log x≤x−1 gives D(p||k)≤Σ_i(p_i−k_i)²/k_i≤d h²/ε. Consequently, against the history-free baseline K_0(i|e)=μ(i), this table has relative exponent at least

    I(E_t;E_{t+1})−d h²/ε+log(s/s_0)−(c−c_0).                   (8)

Equations (6)–(8) give a finite architecture prediction: finer table resolution reduces information-score regret quadratically in covering radius, while any measured table maintenance or transmission penalty enters additively in log growth. If the right side of (8) is positive, the table has a long-run advantage over the memoryless comparator in the infinite-population exogenous-environment model. If also λ(θ)>0 after all absolute costs, the finite-founder branching result of §6 gives a strictly positive establishment probability. Neither statement implies fixation in a finite carrying-capacity population.

The finite-population status is precise. For each fixed table mutant with λ>0, a finite founder population has a nonzero chance of persistence despite demographic sampling. The point-mutation ascent theorem is about expected log lineage ratios under the stationary environmental law and an idealized successive-substitution path. It does not show that a finite Wright–Fisher/Moran population follows that path, because a locally beneficial mutant can be lost by drift, the table can be costly in absolute terms, mutations can interfere, and a beneficial path may pass through subcritical intermediate genotypes. A finite population can also fix a deleterious mutant by drift. The finite-N fixation problem remains the count-state Markov chain noted in §6.

12. Joint genotype/environment representation and shared versus independent memory noise

There is a second exact way to represent the deterministic mutation-selection dynamics. Let Θ be a finite table set, let Q(θ'|θ) be the asexual mutation kernel applied before offspring phenotype expression, conditional on remaining in the tracked table family, and define ℓ_t(θ')=exp(−c_{θ'})s_{θ'}K_{θ'}(E_{t+1}|E_t), where s_{θ'} is an independent intact-family probability and c_{θ'}≥0. In the hard-selection life cycle, absolute genotype counts obey

    N_{t+1}(θ')=B ℓ_t(θ') Σ_θ N_t(θ)Q(θ'|θ).

Normalize (x_t(θ)=N_t(θ)/Σ_ϕN_t(ϕ)). Then

    x_{t+1}(θ') = ℓ_t(θ')Σ_θ x_t(θ)Q(θ'|θ)
                  / Σ_ζ ℓ_t(ζ)Σ_θx_t(θ)Q(ζ|θ).                 (9)

Equation (9) is exactly the hidden-Markov filtering recursion for latent genotype θ_t with transition Q and observation likelihood ℓ_t(θ') proportional to the probability that an offspring of that table is retained and survives phenotype selection under the observed transition E_t→E_{t+1}. The mutation kernel supplies the prior transition; environmental history supplies the likelihood evidence; the population frequency vector is an endogenous filter state. This is not an equivalence between an individual organism's beliefs and genotype frequencies, and it is not a new general replicator/Bayesian identity. It specializes known replicator-mutator filtering interpretations to hereditary predictors and gives an explicit lifecycle decomposition. For the finite per-parent branching process in §6, the conditional expected genotype counts follow the unnormalized matrix update, but realized frequencies are not the filter because the total count is random and parents contribute a fixed number of trials. In a separate finite Wright–Fisher implementation that samples each offspring parent independently from x_t and uses the normalized right side of (9) as offspring-type probabilities, the next count vector is Multinomial(N,F_t(x_t)); that stochastic frequency is an unbiased sample of the ideal filter conditional on the environment, not an exact posterior path.

If each offspring independently draws a private noisy memory M∼L(·|e) and then its phenotype from π(·|M), an infinite population's matching fraction is

    K(e'|e)=Σ_m L(m|e)π(e'|m),

and the hard-selection growth term is log K(E_{t+1}|E_t). It is not E_{M,E'}logπ(E'|M). Conversely, if a single M is sampled once and shared by the whole population in each generation, the per-generation factor is π(E_{t+1}|M_t) and the growth statistic averages logπ over the shared signal process. These are distinct biological noise scopes. The information identity in §3 is about the first specified table channel, with the mixture already inside K; the shared-noise variant has its own joint law and costs. Generic sex still requires the two-parent nonlinear kernel of §7.

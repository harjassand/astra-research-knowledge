## C1. Interface and theorem

Let v>=1, alpha_i>=1, D=max_i alpha_i, and sigma in Z^v. There is an integer vector w with

    ||w||_infinity <= v! D^(v-1)

such that sign(w.z)=sign(sigma.z) for EVERY integer vector z satisfying |z_i|<=alpha_i. Hence for every subset of the profile box 0<=d_i<=alpha_i, w and sigma induce the same entire preorder, including ties. In particular they have precisely the same maximizing dimension profiles and the same maximizing subrepresentations for every representation of those dimensions over every field. The conclusion requires no good-prime event and makes no assertion about equality of profile polytopes between fields.

## C2. A pointed rational polyhedron

For every integer z in the box form these constraints on x in R^v:

    (sign(sigma.z) z).x >= 1, if sigma.z != 0;
    z.x = 0,                  if sigma.z = 0.

The finite system is nonempty: x=sigma satisfies it, since a nonzero integer dot product has absolute value at least1. The unit-coordinate z=e_i belongs to the box. It forces x_i>=1 when sigma_i>0, x_i<=-1 when sigma_i<0, and x_i=0 when sigma_i=0. Thus the feasible set contains no line. For c_i=sign(sigma_i), minimizing c.x gives a nonempty bounded optimal face: each nonzero-signed coordinate has a fixed sign and the sum of its absolute values is bounded on a sublevel set. The optimal face therefore has a vertex x*. The sigma=0 case simply gives x*=0. At a vertex one can select v independent active constraint normals, counting independent equality rows as needed.

Write the selected equations as R x*=b. R is an invertible integer v by v matrix with entries bounded in absolute value by D; b has entries0 or1. (An inequality's sign was absorbed into its normal before this selection.) Let delta=det R and put w=|delta| x*. Cramer's rule makes w integer. All equalities remain zero and every signed nonzero inequality has value at least |delta|>=1, so w has the required signs. Replacing one column of R by b gives, by the determinant expansion,

    |w_i| = |det R_i| <= v! D^(v-1).

This proves C1 without a solver or a genericity premise. Differences of two profile vectors lie in the constraint box, which proves the preorder conclusion rather than only a particular optimizer statement.

## C3. Charged acquisition of a compressed weight

There are at most product_i(2 alpha_i+1) constraint normals. Their coefficients have O(log(D+1)) bits. Computing their signs costs original sigma arithmetic with its actual bit length. A rational linear-programming implementation, with that explicit system and its own bit-cost contract, can return a vertex; Cramer's integerization then gives w. For fixed v and expanded active dimensions this is polynomial input work. No such LP backend has been implemented or invoked in this cycle, so this is a theorem-level acquisition composition, not an executable service.

The bound is exponential in v through v! and D^(v-1). Enumerating the constraint box is also exponential in v. It does not compress arbitrary variable-vertex input into polynomial numerical weights. Isolated dimensions encoded in binary must be handled by full/zero descriptors separately: polynomial in the numerical D is not polynomial in its binary length. For active vertices supplied as dense arrow matrices, each positive dimension is bounded by an incident dense entry count, and total active dimension is at most twice the total dense entry count.

## C4. Acyclic identity-penalty reduction, including cycles

For completeness, the already audited cycle17 reduction has a particularly simple form after C1. Let A=sum alpha_i, C=||w||_infinity, and choose M=AC+1. For every original vertex make source S_i and target T_i, each of dimension alpha_i. Put an identity S_i->T_i and replace each original arrow i->j by the same matrix S_i->T_j. Source weights are M+w_i>0 and target weights are -M. This is an acyclic depth-one quiver, even when the original has loops or cycles.

With source subspaces U_i fixed, target weight negativity forces T_i to be the span of U_i and all incoming arrow images. Write gap_i=dim T_i-dim U_i>=0. The resulting score is

    sum_i w_i dim U_i - M sum_i gap_i.

If any gap is positive, this score is at most AC-M<0. The zero subrepresentation scores0. Therefore every optimizer has all gaps zero, exactly the original arrow-closure equations, and T_i=U_i. The complete optimizer lattice, hence its unique largest member, is preserved. The new numerical weights are at most AC+C+1, and the dimensions double; no large matrix coefficient is introduced.

Combining C1-C4 removes dependence on the original numerical |sigma| from this reduction for FIXED v. Its cost still depends polynomially on original sigma BIT length, active dimensions and arrow entry bit height, and exponentially on a growing v. This is an analytic improvement of the admitted interface; an executable generic backend remains a separate prerequisite.

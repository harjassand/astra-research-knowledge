# Independent centered secant certificate and competent output design

2026-10-06. Interface proposed by rank_pde: conforming P1 stiffness on a grounded square mesh, affine positive scalar conductivities on two disjoint fixed regions, center conductivity one, finite orthonormal L² boundary modes, total current energy one, and four independent equal-variance scalar acquisitions. This is an exact finite Galerkin model; continuum PDE approximation remains uncertified. The following derivations are ours, independently reconstructed before heldout data.

## Uniform global certificate in a small convex parameter box

Let A0 be the positive-definite baseline stiffness, and A1,A2 the regional stiffness matrices, with A_i≥0 and A1+A2≤A0. Set `H_i=A0^(-1/2) A_i A0^(-1/2)` and `B0=A0^(-1/2)B`. Thus H_i≥0 and H1+H2≤I. For `c_i=1+δ_i`, `|δ_i|≤ε<1`,

`H_δ=δ1 H1+δ2 H2`, `R_δ=(I+H_δ)^(-1)`, `F(δ)=B0ᵀ R_δ B0`.

The order inequalities `-||δ||∞ I≤H_δ≤||δ||∞ I` imply `||H_δ||≤ε`, `||R_δ||≤1/(1-ε)`, and `||R_δ-I||≤ε/(1-ε)`. Likewise `||H_v||≤||v||∞≤||v||2` for any parameter direction v. Hence

`D F(δ)[v]=-B0ᵀ R_δ H_v R_δ B0`,

`||R_δ H_v R_δ-H_v||≤||(R_δ-I)H_vR_δ||+||H_v(R_δ-I)||`

`≤ ε(2-ε)/(1-ε)² · ||v||2`.

For fixed currents g_j and fixed test matrices Q_j, stack `Y_j(δ)=Q_j F(δ)g_j`. With `C_B=||B0||²`, the reference Jacobian J0 obeys the uniform bound

`||DY(δ)-J0||≤L(ε)`

`L(ε)=C_B ε(2-ε)/(1-ε)² · sqrt(Σ_j ||Q_j||² ||g_j||²)`.

Integrating along the line segment joining any two parameters in the convex box, triangle inequality gives

`||Y(δ)-Y(δ')||≥[σ_min(J0)-L(ε)] ||δ-δ'||`.

Thus `κ_lower=max(0,σ_min(J0)-L(ε))` is a global secant lower bound, not merely a reference/local diagnostic. Positivity is an explicit falsifiable requirement; if it fails, the method certifies nothing. The disjoint-region order bound removes an unnecessary √2 factor in the parameter remainder. Each Q_j has rows of unit norm, so `||Q_j||≤sqrt(number of its detectors)`, but computing its actual operator norm sharpens the estimate. Total current energy is Σ||g_j||²=1.

This is an analytic finite-matrix certificate. Numerical evaluations of C_B, σ_min and matrix order require outward rounding or explicit numerical error bounds if machine-verifiable certification is claimed. A positive floating margin is evidence of a mathematical certificate's applicability, rather than a verified interval certificate.

## Exact reference-optimal four-test frame for a given single current

Let the M×2 reference response Jacobian for a fixed single current be `J=U diag(s1,s2)Vᵀ`, `s1≥s2>0`, with unit left singular vectors u1,u2. Four tests q_l each have Euclidean/L² norm one. Their matrix P=Σq_l q_lᵀ has trace four. Projecting P to span(u1,u2) cannot reduce relevant information. For any information lower bound `JᵀPJ≥τI`, testing the two right singular directions gives `P_11≥τ/s1²` and `P_22≥τ/s2²`. Therefore

`τ≤4/(s1^(-2)+s2^(-2))=4s1²s2²/(s1²+s2²)`.

Equality is attained with

`w1=4s2²/(s1²+s2²)`, `w2=4s1²/(s1²+s2²)`,

and four tests, two each of

`q_+=sqrt(w1/4)u1+sqrt(w2/4)u2`,

`q_-=sqrt(w1/4)u1-sqrt(w2/4)u2`.

Every test has norm one, P has eigenvalues w1,w2 on the two relevant output directions, and the reference information is exactly τI. The signs produce orthogonal cancellation in P; repeated directions are separate independent acquisitions and must be explicitly admitted by the experiment.

Duplicating u1,u2 twice instead gives information eigenvalues 2s1²,2s2² and minimum 2s2². The optimal frame is strictly better when s1>s2, with ratio `2s1²/(s1²+s2²)` in the minimum information. Consequently an equally duplicated SVD frame is not a competent optimized single-current baseline under this test budget. Optimize the current using the analytical τ formula, then reconstruct its output frame, using training/model knowledge only.

## Multi-current output tests must be optimized jointly

The same freedoms must apply to two currents with two tests each. For each fixed current g_j its reference Jacobian J_j has at most two-dimensional range. Any positive semidefinite output matrix P_j supported in that range with trace two can be realized by two unit-norm tests: in an eigenbasis with eigenvalues λ1+λ2=2, take `q_±=sqrt(λ1/2)u1±sqrt(λ2/2)u2`. Hence, for fixed currents, their competent joint output optimization is

maximize τ subject to `Σ_j J_jᵀP_jJ_j≥τI`, `P_j≥0`, `tr(P_j)=2`.

This is a small semidefinite problem in the two-dimensional relevant output ranges. It remains valid when one J_j has rank one; assign unused trace within that direction if helpful. Joint optimization matters: separately making each current's information isotropic can be poor, because two rank-one currents may carry complementary parameter directions. Optimizing currents/energy allocation adds a nonconvex outer design search; declare and charge that budget, and never call a finite search globally optimal without proof.

## Scope, obstruction, consequence, next test

These finite-dimensional derivative and frame calculations claim no new EIT theorem.

 Abstract 
 
    
 We consider two questions of Ruzsa on how the minimum size
of an additive basis  B B  of a given set  A A  depends on the domain of  B B .
To state these questions, for an abelian group  G G  and  A ⊆ D ⊆ G A\subseteq D\subseteq G 
we write  ℓ D ( A ) = def min { | B | : B ⊆ D , A ⊆ B + B } \ell_{D}(A)\stackrel{{\scriptstyle\mbox{\tiny def}}}{{=}}\min\{|B|:B\subseteq D,\ A\subseteq B+B\} .
Ruzsa asked how much larger can  ℓ ℤ ​ ( A ) \ell_{\mathbb{Z}}(A)  be than  ℓ ℚ ​ ( A ) \ell_{\mathbb{Q}}(A)  for  A ⊂ ℤ A\subset\mathbb{Z} ,
and how much larger can  ℓ ℕ ​ ( A ) \ell_{\mathbb{N}}(A)  be than  ℓ ℤ ​ ( A ) \ell_{\mathbb{Z}}(A)  for  A ⊂ ℕ A\subset\mathbb{N} .
For the first question we show that if  ℓ ℚ ​ ( A ) = n \ell_{\mathbb{Q}}(A)=n  then  ℓ ℤ ​ ( A ) ≤ 2 ​ n \ell_{\mathbb{Z}}(A)\leq 2n ,
and that this is tight up to an additive error of at most  O ⁡ ( n ) O(\sqrt{n}) .
For the second question, we show that if  ℓ ℤ ​ ( A ) = n \ell_{\mathbb{Z}}(A)=n  then  ℓ ℕ ​ ( A ) ≤ O ⁡ ( n ​ log ⁡ n ) \ell_{\mathbb{N}}(A)\leq O(n\log n) ,
and this is tight up to the constant factor. We also consider these questions for higher order bases.
Our proofs use some ideas that are unexpected
in this context, including linear algebra and Diophantine approximation. 
 
  
 
 
 1  Introduction 
 

 
 Many classical questions of Combinatorial Number Theory concern additive bases,
which are sets  B B  such that any natural number  n n  can be expressed as a sum
of  k k  elements of  B B , for some fixed  k k  called the order of the basis.
There is a highly developed theory for the classical bases (see Nathanson  [ 1 ] ),
where  B B  is the set of  r r th powers for some fixed  r r  (Waring’s problem, resolved by Hilbert)
or the set of primes (the Schnirel’man-Goldbach Theorem). More generally, a set  B B 
is a  k k -basis  for  A A  if every element of  A A 
can be written as a sum of  k k  elements of  B B .
For example, the Goldbach Conjecture states that the set of primes
is a  2 2 -basis for the set of even numbers  n > 2 n>2 ,
and the Ternary Goldbach Conjecture, proved by Helfgott  [ 2 ] ,
states that the set of primes is a  3 3 -basis for the set of odd numbers  n > 5 n>5 .
Besides having clear intrinsic interest, such questions have also spurred
many developments in Analytic Number Theory and Harmonic Analysis. 
 
 
 
 Additive bases of finite sets. 
 

 
 A related natural research direction, initiated by Erdős and Newman  [ 3 ] ,
considers some fixed finite set  A A  and asks for the smallest set  B B  such that  A ⊆ B + B A\subseteq B+B .
They considered a random set  A A  of size  n n  inside  { 1 , … , N } \{1,\dots,N\} ,
where for  N > n 2 + c N>n^{2+c}  they showed that typically one needs  | B | > n ​ c / ( 1 + c ) |B|>nc/(1+c) .
For  N = n 2 N=n^{2}  they posed the question of whether for all  A A  of size  n n 
one can take  | B | = o ⁡ ( n ) |B|=o(n) ; this was proved by Alon, Bukh and Sudakov  [ 4 ] ,
who showed that one can take  | B | = O ⁡ ( n ​ log ⁡ log ⁡ n / log ⁡ n ) |B|=O(n\log\log n/\log n) .
On the other hand, it remains open (see  [ 5 , Problem 2.8]  posed by Wooley)
to give good lower bounds on  | B | |B|  for specific natural sets  A A , such as  A = { i d : 1 ≤ i ≤ n } A=\{i^{d}:1\leq i\leq n\} . Furthermore, even for  A A  with strong multiplicative structure,
for which it should be particularly hard to find an additive basis, there is
a massive literature on the ‘sum-product phenomenon’, which still falls far short
of the classical conjecture by Erdős  [ 6 ] ,
and has broad connections to a range of topics including
growth and expansion in groups, exponential sums
and the Kakeya Problem (see the survey by Bourgain  [ 7 ] ). 
 
 
 
 In this paper, we consider two questions of Ruzsa  [ 8 ] 
on how the minimum size of an additive basis  B B  of a given set  A A  depends on the domain of  B B .
To state these questions, for an abelian group  G G  and  A ⊆ D ⊆ G A\subseteq D\subseteq G  we write 
 
 

 
 
 ℓ D ( A ) = def min { | B | : B ⊆ D , A ⊆ B + B } . \ell_{D}(A)\stackrel{{\scriptstyle\mbox{\tiny def}}}{{=}}\min\{|B|:B\subseteq D,\ A\subseteq B+B\}. 
 
 
 Ruzsa asked how much larger can  ℓ ℤ ​ ( A ) \ell_{\mathbb{Z}}(A)  be than  ℓ ℚ ​ ( A ) \ell_{\mathbb{Q}}(A)  for  A ⊂ ℤ A\subset\mathbb{Z} ,
and how much larger can  ℓ ℕ ​ ( A ) \ell_{\mathbb{N}}(A)  be than  ℓ ℤ ​ ( A ) \ell_{\mathbb{Z}}(A)  for  A ⊂ ℕ A\subset\mathbb{N} .
Here we write  ℚ \mathbb{Q}  for the rationals,  ℤ \mathbb{Z}  for the integers,
and  ℕ = def { 0 , 1 , 2 , … } \mathbb{N}\stackrel{{\scriptstyle\mbox{\tiny def}}}{{=}}\{0,1,2,\dotsc\}  for the natural numbers.
Our main results give fairly tight answers to both of these questions. 
 
 
 
 
 
 Additive bases in  ℚ \mathbb{Q}  versus  ℤ \mathbb{Z} . 
 

 
 Our results here apply more generally to additive bases of any order.
We write  k B = { b 1 + ⋯ + b k : b 1 , … , b k ∈ B } kB=\{b_{1}+\dots+b_{k}:b_{1},\dots,b_{k}\in B\}  for the  k k -fold sumset of  B B .
For an abelian group  G G  and  A ⊆ D ⊆ G A\subseteq D\subseteq G  we write 
 
 

 
 
 ℓ D ( k ) ( A ) = def min { | B | : B ⊆ D , A ⊆ k B } . \ell^{(k)}_{D}(A)\stackrel{{\scriptstyle\mbox{\tiny def}}}{{=}}\min\{|B|:B\subseteq D,\ A\subseteq kB\}. 
 
 
 In the following theorems we consider sets  A A  of integers that have
 k k -bases of size  n n  over the rationals. We show that such sets  A A 
have  k k -bases of size  2 ​ n 2n  over the integers, and that this bound
is tight up to a lower order term. Here the upper bound ( Theorem   1 )
is fairly straightforward, so the main interest is in the lower bound ( Theorem   2 ). 
 
 
 
 Theorem 1 . 
 
 
 Every set  A A  satisfying  ℓ ℚ ( k ) ​ ( A ) ≤ n \ell_{\mathbb{Q}}^{(k)}(A)\leq n  also satisfies  ℓ ℤ ( k ) ​ ( A ) ≤ 2 ​ n \ell_{\mathbb{Z}}^{(k)}(A)\leq 2n . 
 
 
 
 
 Theorem 2 . 
 
 
 For all  k , n ≥ 2 k,n\geq 2  there is an  A ⊂ ℤ A\subset\mathbb{Z}  satisfying  ℓ ℚ ( k ) ​ ( A ) ≤ n \ell_{\mathbb{Q}}^{(k)}(A)\leq n 
and  ℓ ℤ ( k ) ​ ( A ) ≥ 2 ​ n − k 4 ​ n 1 − 1 / k \ell_{\mathbb{Z}}^{(k)}(A)\geq 2n-k^{4}n^{1-1/k} . 
 
 
 
 
 
 
 Additive bases in  ℤ \mathbb{Z}  versus  ℕ \mathbb{N} . 
 

 
 Next we consider sets  A A  of natural numbers
that have  k k -bases of size  n n  over the integers;
our task here is to find small  k k -bases for  A A  over the natural numbers.
For  k = 2 k=2  we find that it is no longer possible to find such sets of linear size;
in fact, the minimum size is  Θ ⁡ ( n ​ log ⁡ n ) \Theta(n\log n) . The following theorems
give upper and lower bounds that match up to a constant factor, which we did not optimise. 
 
 
 
 Theorem 3 . 
 
 
 If  A ⊂ ℕ A\subset\mathbb{N}  with  ℓ ℤ ​ ( A ) ≤ n \ell_{\mathbb{Z}}(A)\leq n  then  ℓ ℕ ​ ( A ) ≤ 3 ​ n + 2 ​ n ​ log 2 ​ n \ell_{\mathbb{N}}(A)\leq 3n+2n\log_{2}n . 
 
 
 
 
 Theorem 4 . 
 
 
 For all  n ≥ 1 n\geq 1  there is  A ⊂ ℕ A\subset\mathbb{N}  with  ℓ ℤ ​ ( A ) ≤ 2 ​ n \ell_{\mathbb{Z}}(A)\leq 2n 
and  ℓ ℕ ​ ( A ) ≥ 1 25 ​ n ​ log 2 ​ n − 1 5 ​ n \ell_{\mathbb{N}}(A)\geq\tfrac{1}{25}n\log_{2}n-\tfrac{1}{5}n . 
 
 
 
 
 For larger  k k  our results are not as precise.
From  Theorem   3  it follows that
if  ℓ ℤ ( k ) ​ ( A ) ≤ n \ell^{(k)}_{\mathbb{Z}}(A)\leq n  then  ℓ ℕ ( k ) ​ ( A ) ≤ O ⁡ ( n ⌈ k 2 ⌉ ​ log ⁡ n ) \ell^{(k)}_{\mathbb{N}}(A)\leq O(n^{\lceil\frac{k}{2}\rceil}\log n) ; indeed, if  B ⊂ ℤ B\subset\mathbb{Z}  is a  k k -basis, then  ⌈ k 2 ⌉ ​ B \lceil\frac{k}{2}\rceil B  is a  2 2 -basis.
In the following theorem we give a cubic construction,
thus showing that the power of  n n  does not need to increase with  k k . 
 
 
 
 Theorem 5 . 
 
 
 If  A ⊂ ℕ A\subset\mathbb{N}  with  ℓ ℤ ​ ( A ) ≤ n \ell_{\mathbb{Z}}(A)\leq n 
then  ℓ ℕ ( k ) ​ ( A ) ≤ 16 ​ k ​ log ⁡ ( k ) ​ n 3 \ell^{(k)}_{\mathbb{N}}(A)\leq 16k\log(k)n^{3} . 
 
 
 
 
 
 
 Ideas and techniques. 
 

 
 Somewhat surprisingly, our lower bound in  Theorem   2  comes from linear algebra.
The key idea is to reduce the problem to a related question in a  vector model .
For example, when  k = 2 k=2  the problem in the vector model is to find  B 0 , B 1 ⊂ ℚ n B_{0},B_{1}\subset\mathbb{Q}^{n} 
minimising  | B 0 | + | B 1 | |B_{0}|+|B_{1}|  subject to  B 0 + B 1 B_{0}+B_{1}  containing all vectors  e i + e j e_{i}+e_{j}  with  1 ≤ i ≤ j ≤ n 1\leq i\leq j\leq n ,
where  { e 1 , … , e n } \{e_{1},\dots,e_{n}\}  is the standard basis of  ℚ n \mathbb{Q}^{n} .
If some  B i B_{i} , say  B 0 B_{0} , spans a subspace  V V  of codimension  d d 
then we can find a subspace  W W  spanned by  d d  standard basis vectors  { e i : i ∈ I } \{e_{i}:i\in I\} 
such that any translate of  V V  contains at most one point of  W W .
In particular, we need at least  ( d + 1 2 ) \tbinom{d+1}{2}  elements in  B 1 B_{1} 
to cover all  e i + e j e_{i}+e_{j}  with  i , j i,j  in  I I . Thus we can assume  d = O ⁡ ( n ) d=O(\sqrt{n}) ,
from which we deduce  | B 0 | + | B 1 | ≥ 2 ​ n − O ⁡ ( n ) |B_{0}|+|B_{1}|\geq 2n-O(\sqrt{n}) . 
 
 
 
 For bases in  ℤ \mathbb{Z}  versus  ℕ \mathbb{N}  our constructions use dyadic partitioning.
For example, when  k = 2 k=2  the problem reduces to finding a basis  B B  for sets
of the form  { x r − x t : 1 ≤ t < r ≤ n } \{x_{r}-x_{t}:1\leq t<r\leq n\}  for some  x 1 < ⋯ < x n x_{1}<\dots<x_{n} .
Our construction is to take all  x r − x s x_{r}-x_{s}  where for some  j ≤ log 2 ⁡ n j\leq\log_{2}n 
we have  s = 2 j ​ ⌊ 2 − j ​ r ⌋ s=2^{j}\lfloor 2^{-j}r\rfloor  or  r = 2 j ​ ⌈ 2 − j ​ r ⌉ r=2^{j}\lceil 2^{-j}r\rceil : it is not hard to see that any  x r − x t x_{r}-x_{t}  can be expressed
using this set in the form  ( x r − x s ) + ( x s − x t ) (x_{r}-x_{s})+(x_{s}-x_{t}) .
Thus we include in  B B  order  n n  elements at each of the  log 2 ⁡ n \log_{2}n  dyadic scales.
The intuition for the lower bound is that each scale requires order  n n  elements,
although this is not true literally, only in a rather subtle averaged sense
that requires some careful counting. 
 
 
 
 For higher order bases in  ℤ \mathbb{Z}  versus  ℕ \mathbb{N} , the key idea is to establish
a ‘separation of scales’ via a Diophantine approximation argument
that finds an arithmetic progression  P P  approximating
some fixed  k k -basis  B B  over the integers.
For elements of the iterated sumset  k ​ B kB  at the scale of  P P 
we can apply a variant of the dyadic partitioning construction
to find a moderately efficient  k k -basis over the natural numbers,
losing a factor of  n n  due to the exponential loss in Diophantine approximation.
We then reduce modulo the common difference of  P P ,
which is chosen to reduce the number of elements from  n n  to  n − 1 n-1 ,
so that we can conclude by induction, losing another factor of  n n .

 2  ℤ \mathbb{Z}  versus  ℚ \mathbb{Q} 
 

 
 Here we consider sets  A A  of integers that have  k k -bases of size  n n  over the rationals;
our task is to find small  k k -bases for  A A  over the integers. We start with the upper bound,
which is a straightforward rounding argument. 
 
 
 
 Proof of  Theorem   1 . 
 
 
 Suppose  A ⊂ k ​ B A\subset kB  for some set  B ⊂ ℚ B\subset\mathbb{Q}  with  | B | = n |B|=n . Let 
 
 

 
 
 C = def { ⌊ b ⌋ : b ∈ B } ∪ { ⌈ b ⌉ : b ∈ B } . C\stackrel{{\scriptstyle\mbox{\tiny def}}}{{=}}\{\lfloor b\rfloor:b\in B\}\cup\{\lceil b\rceil:b\in B\}. 
 
 
 We claim that  A ⊂ k ​ C A\subset kC ; this will imply that  ℓ ℤ ( k ) ​ ( A ) ≤ 2 ​ n \ell_{\mathbb{Z}}^{(k)}(A)\leq 2n . 
 
 
 
 Indeed, let  a ∈ A a\in A  be arbitrary. Write it as  a = b 1 + ⋯ + b k a=b_{1}+\dotsb+b_{k}  for some  b 1 , ⋯ , b k ∈ B b_{1},\dotsb,b_{k}\in B .

Since  ⌊ b 1 ⌋ + ⋯ + ⌊ b k ⌋ ≤ a \lfloor b_{1}\rfloor+\dotsb+\lfloor b_{k}\rfloor\leq a ,

 The change of domain question can be formulated in any abelian group.

and compare bases over  A ⊂ D A\subset D  over  D D  and over  G G .

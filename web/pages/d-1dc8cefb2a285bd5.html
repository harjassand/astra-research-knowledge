ACQUIRED FOUR-EXTERIOR-REGISTER REPRESENTATION FOR EXACT HARD-BCS COUNTING AND SAMPLING
c02_s01, independent deeper attack after INITIAL. 7 October 2026.

EXACT RESULT AND SCOPE
Given explicit rational-complex F in C^(n x n) with exact rank r, nonnegative rational row/column occupation activities, and arbitrary sitewise allowed subsets of {empty,row,column}, all determinant-squared disjoint-minor coefficients and exact conditional samples are acquired with
 O(n r^2 16^r) rational-complex arithmetic operations for counting after factorization,
 O(n^2 r^2 16^r) operations for one simple self-reduction sample,
 O(16^r) rational-complex storage,
plus polynomial-bit Gaussian elimination to acquire F=UV^T and polynomial-bit arithmetic per operation. There is no inverse norm, inverse sector probability, coefficient oracle, determinant-phase oracle, Chen-Liu dependency, floating approximation, or Markov mixing assumption.
Thus r<=C log n, with fixed public C, gives a deterministic polynomial-bit exact counting algorithm and expected-polynomial random-bit exact canonical/grandcanonical/conditional sampling algorithm. It permits dense, non-bipartite, phase-interfering pair support. It is an admitted exact-low-rank class, not a solution of arbitrary-rank parity. In particular every nonzero coefficient has k<=r, so this class bounds active pair number.

A dense off-diagonal rank-one diagonal completion is also acquired and verified by the implementation. General minimum-rank diagonal completion is not claimed. Supplying an arbitrary low-rank diagonal completion is a distinct additional interface.

REPRESENTATION AND PROOF
Acquire exact factorization F=UV^T by rational-complex Gaussian elimination. U,V have n rows and r columns. One explicit construction: select independent columns C, set U=F[:,C], select r independent rows R of U, set B=U[R,:] invertible, and V^T=B^-1 F[R,:]. Verify all n^2 entries; no numerical rank threshold is used.
For subsets I,J of equal size k, Cauchy-Binet gives
 det F[I,J]=sum_{S subset[r], |S|=k}det U[I,S]det V[J,S].             (3)
Let E=Lambda C^r, with basis e_A for A subset[r]. In four independent exterior registers keep a tensor
 D_t=sum_{I,J disjoint subsets[t]} weight(I,J)
 (wedge_{i in I}u_i) tensor overline(wedge_{i in I}u_i)
 tensor (wedge_{j in J}v_j) tensor overline(wedge_{j in J}v_j),       (4)
where wedge order is increasing site order and weight is the product of supplied rational occupation activities. Terms not admitted by site tables are omitted. Different registers use ordinary tensor product, so no cross-register fermionic signs are introduced. D0 has only the all-empty basis coefficient1.
At site i, exactly three choices are possible. Empty leaves the tensor unchanged; row applies the right-wedge map R_(u_i) in registers1 and2 (conjugated in register2) and multiplies by its row activity; column similarly acts on registers3 and4 with v_i and its conjugate. Sum only the allowed branches. Because no branch chooses both row and column, (4) is preserved by induction and disjointness is exact.
Each register has dimension2^r, so at most16^r tensor entries. To right-wedge e_A by a vector u, insert a new coordinate j notin A with multiplier
 u_j (-1)^(number of elements of A greater than j).
A row/column branch uses at most r^2 additions/multiplications per tensor entry. Thus the stated O(n r^2 16^r) operation count and O(16^r) memory bound follow. Sparsity may reduce actual storage but is not needed for the proof.

The coefficient of e_A tensor e_B tensor e_C tensor e_D in the final tensor is exactly
 sum_{I,J disjoint}weight(I,J) det U[I,A] overline(det U[I,B])
                               det V[J,C] overline(det V[J,D]),
with the natural zero convention for unequal dimensions. By (3), summing the final entries with A=C, B=D and |A|=|B|=k yields precisely
 c_k=sum_{I,J disjoint, |I|=|J|=k}weight(I,J)|det F[I,J]|^2.          (5)
No termwise positivity is assumed in the tensor; exact rational-complex cancellation is retained. (5) proves final coefficients are nonnegative real rationals, which the implementation checks. This is an acquired representation whose primitive is a finite polynomial-size linear update for the admitted rank regime, rather than an unknown hole-coefficient oracle.
A retained ambient set R is obtained by site tables {row,column} inside R and {empty} outside. Its partition Z_R is coefficient |R|/2. A canonical pair number selects the corresponding coefficient in (5). Arbitrary fixed prefixes restrict site tables to singleton choices. Row versus column activities can encode asymmetric physical fields; the original unweighted target sets all activities1.

EXACT SAMPLING / COSTS
For a nonzero admitted sector, at each next site compute the mass of each legal singleton choice by (5) with that prefix fixed and all remaining site tables unchanged. The three nonnegative rational branch masses sum exactly to the current prefix mass. Choose the branch with its rational probability, then continue. Telescoping gives probability weight(I,J)|det F[I,J]|^2/c_k for every output. There is no rare-sector rejection; exact zero is detected from exact coefficient arithmetic.
A direct implementation recomputes at most3 counting DPs per site: O(n^2 r^2 16^r) operations after one acquired factorization. Share denominators of at most3 rational branch masses and draw a uniform integer below the sum of integer numerators. A b-bit rejection draw accepts with probability at least1/2, so expected fewer than2 draws and O(b) random bits per site (or zero bits for one deterministic branch). This exact sampler has expected runtime; a fixed time budget can truncate with explicit failure probability, but no such approximate budget is claimed in the delivered code.
The desired sector may have exponentially small probability under the unconditioned law. It does not affect exact branch-count evaluation or number of prefix steps.

BIT COMPLEXITY
Let L be the input rational entry/activity bit length, or use total encoding size B. Exact rank factorization entries are ratios of Gaussian-rational minors and have polynomial(n,B) bit size (denominator clearing and determinant bounds suffice). Let L' be an explicit maximum factor/activity bit size after acquisition. At each site take a common denominator for its at most O(r^2) row/column tensor multipliers. The product of these site denominators has polynomial(n,r,L') bit length. Every DP term shares a divisor of that denominator. Absolute numerator sizes are bounded by summing at most3^n choices and at most r^(4r) exterior terms, with at mostO(r) wedge degrees per register and O(n) activity factors. Their logarithms are polynomial(n,r,L'). Thus rational exact arithmetic, including cancellation, has polynomial bit cost per arithmetic operation. No exponentially small numerical tolerance is hidden.
The literal Python implementation uses Fraction gcd reduction, not a numerical interval engine. Its field-operation and bit-size proof applies to the mathematical algorithm; high-rank practical performance is not claimed.

ACQUIRED DIAGONAL-COMPLETION SUBCLASS
Hard disjoint minors never use an entry Fii, so a verified diagonal change preserves every target coefficient. For n>=3 with all off-diagonal entries nonzero, a rank-one completion is acquired as follows: set u0=1 and vj=F0j for j!=0; for each i!=0 choose j!=0,i and set ui=Fij/vj; set v0=F10/u1; verify ui vj=Fij for every i!=j. If verification succeeds, G=uv^T is a rank-one matrix differing from F only on the diagonal, so use its factorization. This gives correct counts for F0=J4-I4 while avoiding its misleading full matrix rank4. Zeros, n<3 and failed checks fall back to factorizing F; the code does not assert no low-rank completion exists in those cases.
For F_delta, an explicitly verified completion F_delta+I=J+delta E12 has rank2. The delivered fixture has canonical c2=2delta^2 and samples its tiny sector directly. This completion is supplied in the fixture and verified by ordinary elimination; the code does NOT generally discover a rank-two diagonal completion.
Approximate rank truncation is not licensed: replacing J+delta E12 by J makes c2 exactly zero instead of2delta^2, for arbitrarily small rational delta.

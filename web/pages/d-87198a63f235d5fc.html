# A16 Phase II, v4: use the actual integration slot in all energy terms

Date: 2026-10-09. Append-only clarification to v1-v3.

When a measured settling floor exceeds the Gaussian noise time, the protocol operates for `t_op=max(t_delta,t_front)`. Every operation-energy term must use that actual slot:

    E_branch = lambda V^2 t_op sum_i |w_i| x_i^2
    Q_max = lambda V W_aug t_op
    E_capacitor = Q_max^2/(2C), subject to Q_max/C <= V_FS.

The post-integration error is evaluated at `t_op` and is no larger than its value at `t_delta`. The 18.025 fJ illustrative subtotal in v3 uses the 1 ns operation slot, not the 56.22 ps noise-only lower time. The script uses the exact integer ceiling for the digital ADC bit count.

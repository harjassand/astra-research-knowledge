PREDICTIVE ALIASING AT A FINITE OBSERVATION HORIZON
Research leaf | 2026-10-08

Finding
-------
For every finite passive observation horizon T, two deterministic finite-state
processes can have exactly the same law on every observation the learner is
allowed to obtain, while their next-symbol predictions after the observed
history disagree maximally. Even unlimited samples and exact probabilities
for every prefix of length at most T leave the learner's minimax total
variation prediction risk at 1/2. One extra observed symbol, or one chosen-
prefix query for the next symbol, removes this particular alias. Extra
precision on the same length-T observations cannot.

This is an exact finite-horizon identifiability boundary, not a computational
hardness result and not a lower bound for a teacher that can be queried on all
prefixes. Its task is to extrapolate one step past the acquisition horizon.

1. Interface and minimal pair
-----------------------------
Fix any integer T >= 1 and alphabet {0,1}. A target is an infinite output
process generated by a time-homogeneous deterministic finite-state machine
with a fixed initial state. The learner knows T and even knows that the target
is one of the following two processes:

  P0: X_t = 0 for every t >= 1.
  PT: X_t = 0 for 1 <= t <= T, and X_t = 1 for every t >= T+1.

The acquisition interface may return any finite number N of independent
length-T trajectories and may answer any finite, adaptive set of exact
prefix-law queries P(X_1:k = w), for 0 <= k <= T and w in {0,1}^k. More
generally, it may return any statistic of these length-T trajectories. There
is no observation or conditional-law query that reaches time T+1. Every
answer is identical under P0 and PT: every sample is 0^T, and each queried
prefix has probability 1 exactly when w = 0^k. Thus the complete adaptive
transcript laws coincide for every N and every query budget within this
interface.

The pair is minimal in hypothesis count (two targets suffice); T=1 is the
smallest nontrivial delayed disagreement. It also uses a particularly simple
process class: both laws are deterministic and have small, explicit machines.
PT is nonstationary from its fixed initial state, although its hidden-state
transition rule is time-homogeneous. No stationary or ergodic-process claim
is made.

2. Different predictive structures
----------------------------------
P0 has one predictive state: every supported history 0^t has future law
0^infinity. PT has the following time-homogeneous countdown machine with
T+1 states k in {0,...,T}:

  initial state k=T;
  in state k>0, emit 0 and move to k-1;
  in state k=0, emit 1 and stay at 0.

After history 0^t, for 0 <= t <= T, PT is in state k=T-t and its entire
future is 0^(T-t) 1^infinity. These T+1 future laws are distinct. For each
r in {0,...,T}, the future test “the next r symbols are 0 and the following
symbol is 1” has probability 1 in countdown state r and probability 0 in
every other countdown state. Therefore any exact predictive-state
representation that supports all finite future tests must distinguish all
T+1 histories 0^t, 0 <= t <= T. The displayed machine attains this bound, so
PT has exactly T+1 reachable predictive equivalence classes; P0 has one.

This count concerns distinct predictive equivalence classes, not the number
of real coordinates in an arbitrary encoding. A symbolic counter can encode
the countdown value in ceil(log2(T+1)) state bits. A state map that merges
two of these histories nevertheless cannot predict every future test
exactly.

3. Exact minimax lower bound
----------------------------
The later task is to estimate the next-symbol law after h_T = 0^T. This
history has probability one under both processes, and

  P0(X_(T+1)=1 | h_T) = 0,
  PT(X_(T+1)=1 | h_T) = 1.

Let an arbitrary learner output p_hat in [0,1], its predicted probability
of symbol 1 after h_T. Since the transcript laws agree, p_hat has the same
distribution mu under P0 and PT, including any learner randomization. Under
total variation loss for the predicted Bernoulli law,

  L0(p_hat) = p_hat,
  LT(p_hat) = 1 - p_hat.

Consequently, for every learner A,

  ( E_P0 L0 + E_PT LT ) / 2 = 1/2,
  inf_A max_{P in {P0,PT}} E_P L_P = 1/2.

The equality follows because the common law mu makes the two losses sum to
one pointwise; the constant forecast p_hat=1/2 attains worst-case risk 1/2.
For squared error in the next-symbol probability, the corresponding exact
minimax risk is 1/4, since

  [p_hat^2 + (1-p_hat)^2]/2 >= 1/4.

There is also a sharp confidence form. For any epsilon < 1/2, the outputs
with loss <= epsilon under P0 and PT lie in the disjoint intervals
[0,epsilon] and [1-epsilon,1]. Since the learner has the same output law
under both targets, at least one target has probability at least 1/2 of
loss > epsilon. Thus no guarantee with error epsilon < 1/2 and failure
probability delta < 1/2 is possible, for any number of length-T samples or
within-horizon exact queries.

The bound is independent of N: adding more data at the same truncation does
not alter the transcript law. It is an information-interface statement, not
a sample-complexity rate for noisy or full-support processes.

4. Smallest interface change
----------------------------
For this pair, the first differing coordinate is exactly T+1. One additional
passive symbol is both necessary and sufficient: a single length-(T+1)
trajectory is 0^T0 under P0 and 0^T1 under PT. Equivalently, one chosen-prefix
query at the supported history h_T asking for
P(X_(T+1)=1 | h_T) returns 0 or 1 and identifies the target. This adds one
bit of target-dependent information. A conditional query at any supported
history of length < T still returns the same answer under both laws.

Increasing numeric precision for the existing length-T observations does
nothing: the relevant distributions are exactly equal, not merely close.
The remedy must extend the observable support to time T+1 (by passive horizon
or an active query); more digits on the old support cannot separate an exact
alias.

5. Representation-oracle comparison and cost
---------------------------------------------
An oracle that supplies the correct predictive machine solves the task with
zero prediction error. For P0 it supplies the one-state all-zero machine.
For PT it supplies the countdown machine above, including initial state T,
transition rule, and output rule. An explicit table has T+1 states and
O(T log(T+1)) bits; a symbolic decrement-counter implementation has
O(log(T+1)) description bits and ceil(log2(T+1)) persistent state bits, with
the machine identity included. The predictive-state quotient still has T+1
classes even when represented by a compact counter.

This oracle changes the information interface by supplying the target's
predictive distinctions. It should be charged for its representation output
and any runtime state. In this two-target family the missing identity is only
one bit, and the one-symbol query acquires it; the example does not show that
representation acquisition is computationally expensive. It shows that no
learner can infer a distinction absent from every legal observation.

6. Relation to prior work and limits
------------------------------------
The standard predictive-state viewpoint defines a state through predictions
of future tests. Littman, Sutton and Singh define a predictive state
representation as test predictions sufficient to predict every test
(NIPS 2001, section 1). Shalizi and Crutchfield define histories with the
same conditional future law as causal-state equivalents and prove minimality
under their process assumptions. The T+1 count above is proved directly for
this deterministic transient example; it does not import a stationarity
theorem. Rivest and Schapire's active finite-automata inference explicitly
uses experimentation and test-equivalence information, illustrating that
query access is a different learning interface; their deterministic
automata results are not a theorem about this stochastic-process class.

Status and limits
-----------------
The pair, predictive-state count, and two-point minimax bounds are exact
derivations. There is no novelty or priority claim. The counterexample only
blocks extrapolation one step beyond a finite acquisition horizon when the
class permits a delay as long as that horizon. It does not block learning
when the training interface exposes the target horizon, permits the
separating conditional query, supplies a representation, or imposes a
known shorter delay bound. If the application predicts only events contained
within the observed length-T block, this pair creates no prediction failure.

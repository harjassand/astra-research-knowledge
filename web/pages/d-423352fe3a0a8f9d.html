# Independent gate of the conditional linear-buffer relative bound

7 October 2026, pde_transport9, verified Sol/max; no nested workers.
**PASS for the explicitly conditional, already-ground-annihilating
perturbation statement.** This does not gate generic spectral stability.

Target: root_cycle13/LINEAR_BUFFER_RELATIVE_BOUND.md, read in full;
primary prior BHM1001.0344v1 §§2.2–3.2. Assume commuting local defect
projectors h_j of bounded range and density, nonzero defect energy>=1,
and a stated-scale local annihilation property: O_A P=0 implies
O_A P_B(A)=0, where side(B(A))<=C(q+2). Each Hermitian W_A is q-local,
annihilates P and has norm<=J. All enlarged B(A) must be contained in
Omega for a local-Hamiltonian version; original support alone is
insufficient.

Choose syndrome-anchor boxes of side R=ceil C(q+2), and project onto
the set Y of occupied boxes. With k=|Y|, H0 has energy>=k there.
Hermiticity and annihilation imply
W_A=(1-P_B(A))W_A(1-P_B(A)). Thus a nonzero block from Y to Z requires
an occupied box near A in both labels. Only checks intersecting A can
change, so at most d_D boxes change; d_D is independent of C and q
because q<=R and the check range is fixed. A fixed Y permits at most
O(kR^D) translated cubes A and at most2^d_D output occupancy labels.

For M_YZ=norm(R_Y W R_Z), the matrix is symmetric and
sum_Z M_YZ<=a_D J kR^D. For a nonzero block |Z|<=k+d_D. Expanding
norm(W psi)^2, applying2xy<=x²+y², and using symmetry yields the
coefficient bound

    sum_Z M_YZ sum_V M_ZV
      <=a_D² J² R^(2D) k(k+d_D).

The k=0 row vanishes. For k>=1 the last factor is at most
(1+d_D)k², while sum_Y k²R_Y<=H0². Therefore

    norm(W psi)<=c_D J [C(q+2)]^D norm(H0 psi).

All overlap and density factors are charged in c_D; the polynomial C
cost is not hidden. An exponential q-tail sums this bound over q on
the scales for which annihilation is available; beyond-scale terms
remain a separate finite-size tail. This is useful after a valid
ground-annihilating decomposition has been constructed. It does not
construct that decomposition or justify repeated support dilation in
BHM's flow. The stabilizer premise needed for this conditional lemma
is distinct from its elementary syndrome-box proof.

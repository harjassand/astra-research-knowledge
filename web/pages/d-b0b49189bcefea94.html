# Complement-LCU connection enforcers: exact blocks and an image-specific support obstruction

Date: 2026-10-08  
Status: **INTERNALLY-PROVED-CANDIDATE** for the identities, graph-incidence gap, seed-transition support bound, and expander-clock subclass obstruction below. **UNKNOWN** for an arbitrary polynomial-row positive enforcer of the complement-LCU image. The global-copy-mixing escape is not closed outside the stated connection-graph subclass.

## Result

The complement-LCU isometry has branch operators that can be written exactly. In the PREPARE basis they are linear combinations of the selected reflections; after undoing PREPARE they are the individual clause reflections. This exposes an LCU-specific obstruction missed by the decoder-frame argument: the transition between the two amplified BJSW seed *reflections* has a row with at least

```text
N_R = 5^R - 2^R - 4^R + 1
```

nonzeros. Consequently:

1. The canonical image projector `I - V V*` has row support at least `N_R / m^2` in the original PREPARE output basis, for every PREPARE completion, where `m` is the polynomial LCU label dimension.
2. A constant-gap bounded-degree expander/connection enforcer whose vertices carry the actual LCU reflection frames (or any unitary frames with the same two endpoint relative frame) cannot have polynomial physical row support. This remains true with arbitrary, global, copy-mixing intermediate vertex frames: a short expander path telescopes to the dense endpoint transition.
3. This is a lower bound for the canonical projector and for the term-anchored unitary connection-graph subclass only. It is **not** a no-go for every positive `C` with `ker C=ran(V)`. A separate exact graph-incidence enforcer below has constant gap but an inverse-dependent, unbounded row ledger. No polynomial-row arbitrary enforcer or unrestricted obstruction was found.

## Exact complement-LCU branch blocks

Let the normalized positive projection list, including its silent zero branch, be

```text
H_f = sum_{j=1}^L pi_j h_j,     0 <= H_f <= 3I/4,
R_j = I - 2 h_j,                R_j = R_j* = R_j^{-1}.
```

The `3/4` upper bound follows from assigning weight `1/4` to the silent zero projector and scaling the hard augmented sum by `3/4`. Include an identity-reflection label `id` with LCU probability `1/2`; the other labels have probabilities `pi_j/2`. Set `chi_id=1/sqrt(2)` and `chi_j=sqrt(pi_j/2)`. Choose a real orthogonal PREPARE matrix `A` with `A|0>=chi` (a real Givens-rotation synthesis suffices), and

```text
S = |id><id| tensor I + sum_j |j><j| tensor R_j,
U = (A^T tensor I) S (A tensor I),
V|psi> = U(|0> tensor |psi>).
```

In the physical PREPARE output basis the branch maps are

```text
K_a = <a|U|0> = sum_{j in {id,1,...,L}} A_{j,a} chi_j R_j,
V|psi> = sum_a |a> K_a|psi>.
```

The distinguished block is exact:

```text
K_0 = sum_j chi_j^2 R_j
    = (1/2)I + (1/2)sum_j pi_j R_j
    = I - H_f =: Y >= I/4.
```

Undoing the output PREPARE rotation gives the direct reflection frame

```text
V_tilde = (A tensor I)V = S(A|0> tensor I)
         = sum_j chi_j |j> R_j,
C_tilde = I - V_tilde V_tilde*,
(C_tilde)_{jk} = delta_{jk} I - chi_j chi_k R_j R_k.
```

This is a genuine physical label-basis rotation for analyzing `C`; it is not by itself a replacement common encoding, because the diagonal observable `B=I-|0><0|` rotates to `I-|chi><chi|`. Since `A` acts on only `m=L+1=poly(n)` labels, for every matrix `X`,

```text
rowdeg((A tensor I) X (A^T tensor I)) <= m^2 rowdeg(X).
```

Thus a polynomial-row enforcer in the original basis would remain polynomial-row after this rotation. The row-degree loss is explicit and polynomial.

In the unrotated basis the exact projector blocks are

```text
C_{ab} = delta_{ab} I - K_a K_b*,
K_a K_b* = sum_{j,k} A_{j,a} chi_j A_{k,b} chi_k R_j R_k.
```

This is the actual LCU transition expansion. A specified `K_aK_b*` entry is a sum of `O(L^2)` products of reflection-pair entries. For a pair of BMVZ clauses, each `R_jR_k` entry is obtained from

```text
R_j R_k = 4 Q_j Q_k - 2 Q_j - 2 Q_k + I,
Q_j = tensor_{r=1}^R (I-P_{j,r}),
```

using `O(R)` constant-size local operations per pair (hence `O(L^2 R)` arithmetic operations per requested entry, plus PREPARE/weight arithmetic). This is polynomial-time **entry** access to specified precision, not a row-list algorithm.

## Exact seed transition support

For the two appended BJSW five-qubit seed kets use the audited computational-basis supports

```text
u = 00010,
v = 10010,
S_phi = {u,v},
S_psi = {u,01110,10110,11010}.
```

The intersection is `{u}` and all entries below are real. Let `P_v=|v><v|`, `A_v=I-P_v` for `v in {phi,psi}`. The singleton BMVZ amplification term is `h_{v,R}=I-A_v^{tensor R}`, so its LCU reflection is

```text
R_{v,R} = I - 2 h_{v,R} = 2 A_v^{tensor R} - I.
```

In the one-copy common row `u`, direct multiplication gives

```text
<u| A_phi A_psi = (3/8)<u| + (1/2)<v|
                    + (1/8)(<01110|+<10110|+<11010|).
```

All five displayed coefficients are nonzero. Put `U0=S_phi union S_psi`, so `|U0|=5`. For `x=u^{tensor R}` and any `y in U0^{tensor R}` outside `S_phi^{tensor R} union S_psi^{tensor R}`,

```text
<x| R_phi,R R_psi,R |y>
 = 4 <x| (A_phi A_psi)^{tensor R}|y>.
```

Indeed, expanding the product gives `4(A_phi A_psi)^tensor R - 2A_phi^tensor R - 2A_psi^tensor R + I`; the second term vanishes unless every coordinate of `y` is in `S_phi`, the third vanishes unless every coordinate is in `S_psi`, and the identity term vanishes since `y != x`. The remaining tensor-product coefficient is nonzero on every `y in U0^tensor R`. Therefore this row has at least

```text
|U0^tensor R \ (S_phi^tensor R union S_psi^tensor R)|
    = 5^R - 2^R - 4^R + 1 = N_R
```

nonzero entries. For `R>=2`, `N_R=5^R(1-o(1))`; BMVZ uses polynomially growing `R` on the hard family.

The seed branches have positive LCU amplitudes `chi_phi,chi_psi`. In the term-frame projector the off-diagonal block is exactly

```text
(C_tilde)_{phi,psi} = -chi_phi chi_psi R_phi,R R_psi,R.
```

Thus `rowdeg(C_tilde)>=N_R`. PREPARE rotation then yields the PREPARE-independent canonical-projector bound

```text
rowdeg(C_LCU) >= N_R / m^2.
```

For the audited weights (seed layers `1/4` each before adding a silent zero branch of weight `1/4`), `pi_phi=pi_psi=3/16` after the `3/4` rescaling and `chi_phi=chi_psi=sqrt(3/32)`. The scalar on the block is therefore nonzero and does not affect support. Exact arithmetic fixture: `outputs/research/games_hamiltonians/cycle2/bmvz_bjsw_seed_pair_test.py`; it verifies the seed states/supports and the singleton amplified clause formula. The support lower bound above is an analytic tensor-product count, not an inference from the finite fixture.

## Expander/connection-graph obstruction, including global intermediate frames

For the BMVZ term weights, make the connection clock uniform by taking a
common polynomial-size denominator `K` and duplicating label `j` exactly
`K chi_j^2` times; this leaves the frame isometry unchanged up to a relabeling.
The iterated BMVZ path probabilities have polynomial common denominator here:
the number of iterations is logarithmic, while the starting degree and path
length are constant. The label generator and the copy number are therefore
polynomial-time describable. An explicit constant-degree regular expander on
these `K` vertices has an `O(log K)`-bit vertex name and a polynomial-time
(typically polylogarithmic-time) neighbor map (uniform exact sampling can use
rejection with expected `O(log K)` bits if `K` is not a power of two).

Consider a unitary-frame connection enforcer on a `K`-vertex connected graph:

```text
G = direct_sum_a U_a,
C_conn = (1/2) G (L_G tensor I) G*,
```

where `L_G=I-P_G` is the normalized graph Laplacian with kernel the uniform clock vector. Then `0<=C_conn<=I`, and a base graph gap `delta` gives invalid-space gap `delta/2`. For an edge `a~b`, its physical off-diagonal block is a nonzero scalar multiple of `U_a U_b*`. If the maximum edge-relative row support is `s_edge`, telescoping along any path `a_0,...,a_ell` gives

```text
sigma(U_{a_0} U_{a_ell}*) <= product_{i=0}^{ell-1} sigma(U_{a_i}U_{a_{i+1}}*)
                            <= s_edge^ell,
```

where `sigma(T)` is maximum row support. This uses only `sigma(AB)<=sigma(A)sigma(B)` and makes no tensor-factor, Clifford, locality, or copy-independence assumption about intermediate `U_a`.

For a term-anchored representation of the direct LCU frame, the two seed vertices have frames `R_phi,R_psi` (up to the same right logical gauge, which cancels in the relative matrix). The previous section gives `sigma(R_phi R_psi)>=N_R`. If the clock graph is an explicit bounded-degree regular expander with gap at least `delta>0`, its diameter obeys `ell<=c_delta log K` for a constant `c_delta`; this follows from the constant conductance/BFS growth bound. Hence

```text
s_edge >= N_R^(1/(c_delta log K))
       = exp(Omega(R/log K)).
```

The row degree of `C_conn` is at least `s_edge` and at most `1+Delta*s_edge` when the graph degree is `Delta`. With `K=poly(n)` and the BMVZ hard-family `R=n^Omega(1)`, `s_edge=exp(Omega(R/log n))`, which is superpolynomial. The result also applies to any chosen global intermediate unitary frames on the graph path. It is therefore a scoped no-go for constant-gap, bounded-degree expander clocks built from unitary branch connections anchored at the two actual LCU seed reflections.

Scope: this does not rule out an arbitrary positive sparse matrix with the same kernel, nor a new representation in which a global label rotation turns the unitary branch blocks into nonunitary linear combinations and the enforcer is not a unitary-frame connection Laplacian. It also does not rule out a larger encoding with active workspace. Those are the remaining global-frame escape routes.

## An exact nonunitary graph-incidence enforcer and its access failure

The actual LCU blocks also admit a useful exact graph-incidence construction outside the unitary-frame subclass. Since `K_0=Y>=I/4`, define the stacked operator

```text
T z = ( z_a - K_a Y^{-1} z_0 )_{a=1,...,m-1},
C_inc = (1/16) T* T.
```

Then `ker(T)=ran(V)`: `Tz=0` implies `z_a=K_aY^{-1}z_0`, so `z=V(Y^{-1}z_0)`. Since `sum_a K_a* K_a=I` and `K_0=Y`,

```text
sum_{a>0} (K_aY^{-1})* (K_aY^{-1}) = Y^{-2}-I <= 15 I.
```

Writing `T=[-K_1Y^{-1}; ...; -K_{m-1}Y^{-1} | I]` gives `TT*=I+K K*>=I`, while `||T||^2=||TT*||<=16`. Therefore

```text
0<=C_inc<=I,
ker(C_inc)=ran(V),
C_inc >= (1/16)(I - VV*).
```

This is an exact constant-gap positive enforcer for the complement-LCU image. It does **not** meet the row requirement: its cross blocks contain `K_aY^{-1}`, whose exact computational row support and exact classical row/entry oracle are not bounded polynomially. Replacing `Y^{-1}` by a finite-precision polynomial approximation does not preserve the exact kernel and is not a valid exact certificate. Thus this provides an algebraic alternative, not the requested sparse solution.

## Costs, status, and next falsifier

* BMVZ supplies `R=poly(n)` and `m=poly(n)`; the LCU reflection selector has polynomial circuit size. Each single specified transition entry uses `O(m^2R)` local algebraic operations and polynomial bit precision when given the exact rational weights and local seed descriptions.
* Canonical projector row listing requires at least `N_R/m^2` nonzeros in the worst row. A fast entry oracle cannot list these in polynomial time.
* A constant-degree expander clock has polynomially many vertices and `O(log K)`-bit vertex labels; its neighbor sampler is the ordinary explicit-expander sampler. Its physical matrix row degree has the superpolynomial lower bound above, even with arbitrary global intermediate frames.
* The nonunitary incidence enforcer has norm/gap exactly controlled by the `1/4` floor of `Y`, giving contraction scale `1/16`; its row listing/entry-computation cost remains UNKNOWN because of `Y^{-1}`. Any finite-precision implementation must separately repair exact annihilation of `V`.
* Strongest equally informed baseline: canonical LCU projector already has gap one and polynomial specified-entry evaluation, but only exponential row support; the term-frame graph has constant gap but the new reflection-transition lower bound forces a superpolynomial edge row. The incidence graph proves that algebraic gap is easy once `K_0` is invertible, isolating row support/access as the bottleneck.
* Falsifier for the scoped graph no-go: exhibit a term-anchored constant-gap graph whose seed endpoint relative matrix has a path with edge max row support below `N_R^(1/(c_delta log K))`; this contradicts the exact support-product inequality. A polynomial-row arbitrary enforcer, or a global label-mixing representation with controlled sparse relation rows, would not falsify this scoped statement but would resolve the open general case.

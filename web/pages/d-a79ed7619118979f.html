MAIN RESULT
For one critical EPR* gate per edge on an odd physical cycle of arbitrary length, the trace is exactly twice a weighted common-bases sum of two explicit matroids. This composes by direct sum on any odd-cycle cactus when all gates of each physical block occur consecutively. The final extension in section9 covers every cycle parity by a positive DAG-to-perfect-matching compiler, still with O(m) selectors. The binary odd-cycle construction has at most twice the number of gates as ground elements; the general-cactus path compiler has at most eight times the number of gates. All weights, independence oracles, initial sets, and coefficient range bounds are acquired explicitly. Chen-Liu 2610.06724v1 Corollary C.2 applies under its source-reported theorem. This is a restricted representation theorem, not a new hard-family approximation algorithm: the same cycle transfer calculation gives an exact polynomial-time algorithm on this family.

Two interleaved triangles provide an exact counterexample to scalar/direct-sum gluing. An independent closed triangle with trace zero can become part of a nonzero global trace when its boundary events interleave with another triangle. The unmodified transition matroid also cannot directly become the required common-bases representation: its transversal bases select Euler systems, whereas trace weights include dependent transversals with more loops.

2. EXACT ARBITRARY-CYCLE TRANSFER IDENTITY
Let G=C_n, n>=3, with one gate F_i on each edge, all physical vertices included in trace closure. Gate order can be arbitrary. At each physical vertex there are exactly two incident gate events. Trace closure identifies the output of the earlier event with the input of the later event and the input of the earlier event with the output of the later event. Consequently the two-coordinate index on that physical vertex is contracted using the swap matrix T on (input,output).

Reshuffle F so its row index is (input_u,output_u), its column index is (input_v,output_v). Write q=|00>+|11>, J=X tensor X, and T=SWAP on this four-state index. Reshuffling gives
  R_I=q q^T, R_C=J, R_D=JT.
Hence the transfer factor is
  B_i=R_{F_i} T = a_i q q^T + c_i JT + d_i J.
The qubit interchange and time reversal symmetries make this contraction insensitive to the orientation chosen for the physical cycle and to the chronological edge order. Explicitly,
  Tr_physical product_i F_i = Tr_4 product_i B_i.
All B_i share the following eigenvectors and eigenvalues (normalization immaterial):
  q+=|00>+|11>:    2a_i+c_i+d_i,
  q-=|00>-|11>:    -(c_i+d_i),
  r+=|01>+|10>:    c_i+d_i,
  r-=|01>-|10>:    c_i-d_i.
It follows exactly that
  Z_n = product_i(2a_i+c_i+d_i)
        + [1+(-1)^n] product_i(c_i+d_i)
        + product_i(c_i-d_i).                       (1)
This proof is purely algebraic; finite checks are diagnostics of the implementation.

Set u_i=a_i+c_i and v_i=a_i+d_i. Then
  E_n(u,v) := sum_{S subset [n], |S| even}
                 product_{i notin S} u_i product_{i in S} v_i
             = [product_i(u_i+v_i)+product_i(u_i-v_i)]/2.
Thus
  Z_n = 2 E_n(u,v)                                  if n odd;
  Z_n = 2 E_n(u,v) + 2 product_i(c_i+d_i)            if n even.   (2)
In particular the naive odd-parity transversal expression first fails on C_4, e.g. all C gives trace4 rather than2, and C,C,C,D gives trace2 rather than0. The positive correction in (2) completely repairs every even-cycle coefficient.

3. TWO EXPLICIT MATROIDS FOR E_n
The ground set is U_n={c_1,...,c_n,d_1,...,d_n}, with element weights w(c_i)=u_i, w(d_i)=v_i. Let P_n be the rank-n partition matroid allowing at most one element of each pair {c_i,d_i}. Let M_n be the binary vector matroid of the n x 2n matrix
  [ I_n | J_n-I_n ] over GF(2),
where J_n is the all-ones matrix. Both ranks equal n.

A P_n basis chooses d_i exactly on a set S, and c_i elsewhere. Eliminate the columns/rows fixed by the chosen identity columns. The remaining square matrix is I_k+J_k over GF(2), k=|S|. By the determinant lemma, det(I_k+J_k)=1+k in GF(2), so the transversal is an M_n basis if and only if k is even. Therefore
  sum_{B common basis of M_n,P_n} product_{e in B} w(e)=E_n(u,v).
For n=3 this is precisely the supplied graphic K4 representation: spoke columns are e_i and opposite-edge columns are 1-e_i. For larger n no claim that M_n is graphic is needed; its binary representation supplies a polynomial-time independence oracle.

There are exactly 2n elements, no exponential state list, and no uncharged kernel-color enumeration. GF(2) Gaussian elimination implements the M_n oracle; pair-counting implements the P_n oracle. For rational input weights of total bit length L, all derived weights and products have polynomial bit length and logarithmic positive coefficient range O(n(L+1)) using even the crude bound that every nonzero input weight lies between 2^-L and 2^L. Zero weights are handled by deletion, as in Chen-Liu Corollary C.2. Greedy bases initialize each nonzero weighted basis measure. A matroid intersection check can decide whether the common support is empty.

Chen-Liu Theorem1.6 / LemmaC.1 / CorollaryC.2 give a source-reported FPRAS for this acquired weighted common-bases instance. RemarkA.4 supplies polynomial bit complexity for rational polynomial-bit coefficient oracles. The broad arithmetic upper bound is O_tilde(N^11 (N+log R)^2 epsilon^-2) oracle/arithmetic calls with N=2n, multiplied by the implemented oracle cost. No implementation of that FPRAS is claimed. Here equation(1) already provides an exact rational algorithm using O(n) additions/multiplications, with O(nL)-scale intermediate bit lengths.

For even n, equation(2) is a positive sum of two explicitly countable pieces; the second is a product measure. Two relative approximations with failure probability at most1/8 each yield a relative approximation of their sum with success probability at least3/4. This is not asserted to be a single common-bases representation.

4. SCALABLE COMPOSITION ON BLOCK-ORDERED ODD CACTI
Let G be a simple cactus: each nontrivial block is a bridge or a cycle, and any two cycle blocks meet in at most one vertex. Require every cycle block to be odd. There is exactly one F_e per edge. Require additionally that the gates of each block form a consecutive segment in the circuit word. Blocks can occur in any order. This schedule condition is part of the theorem, not an assumption silently imposed on arbitrary circuits.

For a block B write O_B for the product of its local gates and Z_B=Tr O_B on its own vertex set. Each local F_e commutes with X tensor X and with Z tensor Z. Consequently O_B commutes with the collective Pauli products X_B and Z_B. If B is a leaf block attached at a vertex v, its partial trace over V(B) minus {v} commutes with both X_v and Z_v. The only complex2x2 matrices commuting with both are scalar multiples of identity, so
  Tr_{V(B) minus v} O_B = (Z_B/2) I_v.             (3)
Because O_B appears as a contiguous segment, this partial trace can be performed inside the global product even when O_B is between two other block products. Remove the leaf block and repeat. For a component this leaves one free qubit, of trace2. Thus
  Tr_G product_B O_B = 2^{components(G)} product_B (Z_B/2).      (4)
A bridge has Z_B/2=2a_e+c_e+d_e. An odd cycle has Z_B/2=E_|B|(a+c,a+d).

Use M_B,P_B from section3 for each cycle. For each bridge use a singleton rank1 free matroid in both factors, weighted by 2a+c+d. Take direct sums over all blocks in each factor. The common-bases weighted count is the product on the right of(4), so
  Z_G=2^{components(G)} WCB(M,P).
This is a single positive two-matroid instance, with equal rank m=|E(G)| and ground size 2m_cycle+m_bridge <=2m. Its independence oracles are explicit blockwise GF(2) rank and partition/singleton checks. The rational cost contract of section3 persists with n replaced by m. Isolated physical vertices contribute their own factor2.

This is an unbounded family and genuinely composes the triangle mechanism, but it does not include repeated-edge Trotter circuits or arbitrary interleavings. Physical cactus topology alone is insufficient, as the next section proves.

5. EXACT BOWTIE COUNTEREXAMPLE TO NATURAL GLUING
Take two physical triangles sharing vertex0:
  A=(01),(02),(12), B=(03),(04),(34).
Compare the grouped order A then B with the interleaved order
  (01),(03),(02),(04),(12),(34).                     (5)
Set all six gates equal to C, i.e. a=d=0,c=1. Each isolated triangle has trace2, so direct-sum/scalar gluing predicts2*2/2=2. The actual trace for(5) is4.

The exact computation can also be read as a short complete path certificate. Write each five-bit state in vertex order0,1,2,3,4. There are exactly four closed paths with unit weight through all six C gates:
  01010 ->01010 ->11000 ->11000 ->01001 ->01001 ->01010;
  10110 ->01110 ->01110 ->11010 ->11010 ->10110 ->10110;
  01001 ->10001 ->10001 ->00101 ->00101 ->01001 ->01001;
  10101 ->10101 ->00111 ->00111 ->10110 ->10110 ->10101.
C is allowed only when the acted pair is unequal, and either preserves or exchanges that unequal pair. The four displayed histories meet that rule; exhaustive exact propagation finds no others. Thus trace4.

Replace only the last gate(34) by D. Only the middle two paths survive, so global trace2. Yet the closed B triangle has gate patternCCD and trace0, so any construction that replaces B by its closed scalar and then glues predicts0. This mismatch is stronger than an overall normalization defect.

Every coefficient of the two orders was compared using exact integer arithmetic (729 monomials). Grouped order has zero failures against(4). Interleaved order has64 failures, precisely the monomials using only C,D on all six edges. Every one differs by+2. Consequently the full interleaved bowtie polynomial has the exact finite coefficient identity
  Z_interleaved = Z_A Z_B/2 + 2 product_{e in A union B}(c_e+d_e).  (6)
The second term is positive and makes a constant-sum representation possible for this six-gate example. No scalable count of correction branches for arbitrary cactus interleavings is proved. In particular(6) must not be extrapolated to arbitrary overlapping triangles.

A further independent order diagnostic exhausts all720 edge permutations at allC weights: 240 have trace4 instead of the scalar prediction2; 480 give2. Thus the schedule dependence is not a numerical roundoff or isolated gate convention.

6. WHY THE UNMODIFIED TRANSITION MATROID DOES NOT CLOSE THE GAP
Primary source: Lorenzo Traldi, The transition matroid of a4-regular graph: an introduction, arXiv1307.8097v7, Definition14/16, Theorem1, and discussion immediately after its proof. For a4-regular circuit graph H with m gate vertices, c(H) connected components, and a circuit partition P, the transition matroid has rankm and
  r(tau(P)) = m+c(H)-|P|.
It is represented over GF(2) by [I | A | I+A], A the adjacency matrix of an Euler system's interlace graph. Its bases that choose one transition per gate are exactly the Euler systems, |P|=c(H).

The signed trace expansion requires all balanced circuit partitions, with multiplicity2^|P|; partitions with any odd-flip loop have weight0. An ordinary common-base condition on the unchanged transition columns discards every dependent transversal with more than c(H) loops. Appending auxiliary elements and asking for a basis CONTAINING that unchanged chosen transversal cannot repair this: every subset of a matroid basis must be independent. Parallel copies of the same selected columns likewise do not repair its dependence.

An exact one-gate counterexample already appears before parity: a gate on two trace-closed wires gives a circuit graph with one vertex and two loops. Choose a joining transition as Euler system. Its transition matrix is [1 |0 |1]. The identity transition preserves the two individual wire loops, so its column is the matroid loop0 and its trace coefficient is4. A direct transition-matroid/partition common-base count assigns this state coefficient0. This is a no-go for the specified unchanged-column construction, not for all lifted matroids, complement/deletion encodings, sums, Rado constructions, or two-log-concave measures.

The source's parametrized Tutte/interlace polynomial records dependent transversals via a nullity exponent. That fact is not a conversion to a common-bases count or a polynomial-time evaluation of the required specialization. A successful general lift must acquire both nullity multiplicity and signed-loop consistency using polynomially many selectors and explicit oracles. Those obligations remain unresolved here.

9. FINAL EXTENSION: ONE COMMON-BASE REPRESENTATION FOR EVERY BLOCK-ORDERED CACTUS
The odd-cycle restriction is unnecessary if one uses a general positive path-sum compiler rather than insisting on the binary n x2n construction. This is an exact representation extension, still within the same one-gate-per-edge and consecutive-block schedule.

For each cycle define H_n=Z_n/2=E_n(u,v)+1[n even] product_i(c_i+d_i). Make an acyclic layered graph with parity states(i,p), p in{0,1}, i=0,...,n. The unique source is(0,0), unique target(n,0); retain both parity states only at interior layers. At edge i, an arc from parity p to p has weight u_i and one to1-p has weight v_i. Its weighted source-target path sum is E_n. If n is even, add a disjoint parallel source-target chain with its ith arc weighted c_i+d_i. The total positive weighted path sum is H_n. This graph has O(n) vertices/arcs and no cancellation.

Lemma (positive DAG paths to two partition matroids): Given an acyclic directed graph with source s and target t, take bipartite row vertices V minus{t}, column vertices V minus{s}. Include each directed arc as an edge of its weight and a unit edge from row v to column v for every v other than s,t. The weighted perfect-matching sum equals the weighted s-to-t path sum.
Proof: A perfect matching picks exactly one outgoing arc at every vertex other than t and one incoming arc at every vertex other than s, interpreting unit edges as selfloops. The component starting at s must terminate at t; it cannot enter a selfloop because that would give its entry vertex two incoming edges, and it cannot form a nontrivial cycle because the original graph is acyclic. Every off-path component must be a cycle, as no other vertex lacks indegree/outdegree. Acyclicity makes each off-path component its unit selfloop. Thus matchings and s-to-t paths are in weight-preserving bijection. Conversely a path plus all off-path selfloops is a unique perfect matching. QED.

Perfect matchings are the common bases of the row and column partition matroids on the bipartite edge set. Their ranks are |V|-1, and independence queries count at most one incident edge in each respective class. For an odd n-cycle the compiler has2n vertices,4n-4 DAG arcs and2n-2 unit edges, hence6n-6 ground elements and rank2n-1. For an even n-cycle the additional chain gives3n-1 vertices,5n-4 DAG arcs and3n-3 unit edges, hence8n-7 ground elements and rank3n-2. Thus every selector is explicitly charged. Zero arc weights can be deleted. No path count is precomputed and encoded into a weight; all edge weights are the acquired local u_i,v_i,c_i+d_i or unit weights.

Apply this compiler to H_n for every cycle, use singleton bridge matroids of weight2a+c+d, and take direct sums in the two factors. By the same partial-trace proof(3)-(4), EVERY block-ordered cactus, with arbitrary cycle parities, has
  Z_G=2^{components(G)} WCB(P_rows,P_columns),
with O(m) ground set/rank and explicit linear-time partition independence oracles. The same rational coefficient-range contract applies. This extends the final theorem's scope beyond the odd-cactus theorem in section4. It remains an already exactly tractable positive dynamic-programming family, and offers no claim for arbitrary interleaved cacti or arbitrary repeated-edge circuits.

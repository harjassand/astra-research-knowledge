# Audit: finite-range to arbitrary-range ambient (L_1) extension

**Verdict.** The finite-to-infinite bridge in `metric_representation/DERIVATION_CYCLE2.md` is valid for separable sources, conditional on the stated finite-range global-extension premise and its common σ-finite support property. I found no gap in the weighted disjoint-union/Komlós argument and no obstruction in the sources audited to this ambient-target conclusion. This is a conditional proof audit, not an independent verification of the pinned release's ℓ₁ metric-Markov-cotype theorem.

## The exact Mendel–Naor interface

Mendel–Naor, [*Spectral calculus and Lipschitz extension for barycentric metric spaces*](https://arxiv.org/html/1301.3963), Theorem 1.11 assumes a Markov-type-(p) source and a metric-Markov-cotype-(p), (W_p)-barycentric target. Its conclusion extends the data to each **finite subset of the source** with a uniform Lipschitz bound; by itself it does not supply a global map. Corollary 1.13 is the needed globalization: for a **dual Banach** target it gives (e(X,Y)\lesssim M_p(X)N_p(Y)). Thus applying only Theorem 1.11 would leave a real gap, but cycle 1 instead applies Corollary 1.13 to the coded target ℓ₁, which is (c_0^*). A Banach-space mean is (W_2)-barycentric with constant 1 since (W_1\le W_2).

The finite-range premise is an explicit factorization, not an assertion that arbitrary (L_1) is dual. For finitely many range vectors, the cut code is a finite weighted ℓ₁ metric; rescale it into the first (d\le 2^r-2) coordinates of ℓ₁, use Corollary 1.13 there, project back to those coordinates, and compose with the stated contractive affine cut-recovery map (T) into the original ambient (L_1). This gives the same finite-range factor (K=C_{MN}12\sqrt{21}M_2(X)), conditional on the release's Theorem 1.2 (N_2(\ell_1)\le12\sqrt{21}). The latter is the substantive unvalidated premise: it is stated in the pinned family-332 manuscript, but this audit does not certify that manuscript's proof. See [cycle-1 derivation](../metric_representation/DERIVATION.md) and [the extracted pinned manuscript](../metric_representation/sources/l1-markov-cotype-extracted.txt).

## Why the Komlós bridge works

If S is finite, apply the premise to A=S and finish directly. Otherwise let (S_0=\{s_i\}) be a countable dense subset of S, and choose a countable dense (D=\{x_j\}\) in (X), enumerated with (S_0) first. Apply the premise to (A_n=\{s_1,\ldots,s_n\}), choosing the finite-range cut extensions (F_n). For each fixed (x_j), all (F_n(x_j)) are uniformly bounded in (L_1(\mu)) by
\[
B_j=\|f(s_1)\|_1+KLd(x_j,s_1),
\]
because every extension agrees at (s_1). In the cut construction, each recovery map for (A_n) is built from the finitely many functions (f(s_i)), (i\le n). Hence all its outputs vanish off the one set
\[
\Omega_0=\bigcup_i\{f(s_i)\ne0\}.
\]
This set is σ-finite: for each integrable representative (h), “(h\ne0)” is the countable union of “(|h|\ge1/m)”, each of finite measure. This support condition is essential; it is supplied by the chosen cut recovery, not by an arbitrary global extension into (L_1).

On Ω₀ choose a finite measure ν equivalent to μ with (d\nu/d\mu\le1), using a countable finite-measure partition. Set (\alpha_j=2^{-j}/(1+B_j)>0) and put (\lambda(\{j\}\times E)=\alpha_j\nu(E)). Then λ is finite and the scalar functions (H_n(j,\omega)=F_n(x_j)(\omega)) satisfy
\[
\sup_n\|H_n\|_{L_1(\lambda)}\le\sum_j\alpha_jB_j\le\sum_j2^{-j}<\infty.
\]
Komlós, Theorem 1a in J. Komlós, [*A generalization of a problem of Steinhaus*](https://doi.org/10.1007/BF02020976) (1967, pp. 217–218; [open repository record and PDF](https://scholarship.libraries.rutgers.edu/esploro/outputs/journalArticle/A-generalization-of-a-problem-of/991031549979804646)), applies to a sequence of random variables with bounded first absolute moments. If its probability-space formulation is used, normalize finite nonzero λ; this preserves null sets and boundedness. The zero-measure case is trivial. Its conclusion gives a subsequence whose Cesàro averages converge almost everywhere to an integrable function.

Since every αⱼ is positive and there are only countably many (j), this yields simultaneous ν-a.e., hence μ-a.e. convergence at every (x_j). Outside Ω₀ all selected values are zero. Fatou with the original μ gives limits (g_j\in L_1(\mu)); applying Fatou again to each pair and using convexity of the norm shows
\[
\|g_j-g_\ell\|_1\le KLd(x_j,x_\ell).
\]
For (s_i\in S_0), all but finitely many extensions agree with (f(s_i)), so the Cesàro limit is (f(s_i)). Completeness extends (x_j\mapsto g_j) uniquely from (D) to a (KL)-Lipschitz map on (X). Continuity and density extend agreement from (S_0) to all of (S). The constant (K) is unchanged.

The proof is nonconstructive: it gives no runtime, finite precision guarantee, or effective way to select the Komlós subsequence. The finite code dimension at prefix (n) can be (2^n-2), but this does not affect the extension constant.

## Obstructions and status boundary

Mendel–Naor Theorem 1.14 gives a closed subspace of ℓ₁ failing every finite metric Markov cotype. That does not obstruct this argument: the code's recovery map lands in the **ambient** (L_1) and need not keep extension values in a prescribed subspace. Nor does the failure of weak compactness of (L_1[0,1])'s unit ball defeat this proof; Komlós/Cesàro convergence replaces weak compactness on the countable dense set. The argument does not establish the analogous result for nonseparable sources, where this single countable-set step is unavailable.

**Evidence status:** the conditional implication is proved by the written construction, provided the finite-range premise really supplies the common-support cut extensions. That provenance is visible in [cycle-1 derivation](../metric_representation/DERIVATION.md) and the pinned manuscript, but remains an internally reconstructed candidate. The 2013 paper itself notes that ℓ₁ metric Markov cotype 2 was open (Question 1.15); its Theorem 1.14 is only a subspace obstruction. No priority conclusion is drawn here.

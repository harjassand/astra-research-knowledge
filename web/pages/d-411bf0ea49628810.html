## Load-bearing construction

Reference state errors are bounded by exactly feasible H(div) flux fields q with div q=0 and q·n equal to the physical boundary load. A continuous P2 streamfunction gives q=(ψ_y,−ψ_x), an affine divergence-free field with exactly continuous normal traces. Its boundary values integrate the frozen P1 load. Auxiliary sensitivity states driven by the discrete reference states use zero-normal flux fields with target ∇w_h−φ_i∇u_h.

Galerkin orthogonality turns the reference derivative discrepancy into products of state and auxiliary errors, rather than an error times the full solution energy. Reference Pythagoras bounds continuum current and detector operator norms. The continuum affine resolvent estimate then controls every parameter in the box. Exact outward constants are

 Abstract. 
 
    
 It is a classical fact that every  n n -element set of positive reals has at least  ( n + 1 2 ) + 1 \binom{n+1}{2}+1  distinct subset sums, with equality exactly for homogeneous arithmetic progressions (when  n ≥ 4 n\geq 4 ). We establish stability versions of this inverse theorem in two regimes. First, for any parameter  M ≤ n − 4 M\leq n-4 , we precisely characterize the  n n -element sets of positive reals with at most  ( n + 1 2 ) + 1 + M \binom{n+1}{2}+1+M  subset sums. Second, for any constant  C C , we provide a characterization, sharp up to constants, of the  n n -element sets of positive reals with at most  C ​ n 2 Cn^{2}  distinct subset sums. Along the way, we constrain (for any fixed  d ≥ 2 d\geq 2 ) the structure of  n n -element subsets of  ℝ d \mathbb{R}^{d}  with  o ⁡ ( n d + 1 ) o(n^{d+1})  subset sums. 
 
  
 
 
 1.  Introduction 
 

 
 1.1.  Inverse and stability theorems 
 

 
 A central theme in additive combinatorics is that sets with small doubling have constrained structure. It is a basic fact that if  A ⊆ ℝ A\subseteq\mathbb{R}  is an  n n -element set, then the sumset  A + A A+A  has size at least  2 ​ n − 1 2n-1 . The “inverse theorem” for this inequality is the statement that equality holds if and only if  A A  is an arithmetic progression. Freiman’s  3 ​ k − 4 3k-4  Theorem provides a “stability” version of this inverse theorem, namely, a precise sense in which a set with doubling near the minimum must closely resemble an arithmetic progression. The Freiman–Ruzsa Theorem provides a rougher structural description of sets of bounded doubling, namely, that any  n n -element set  A ⊆ ℝ A\subseteq\mathbb{R}  with  | A + A | = O ⁡ ( n ) |A+A|=O(n)  is contained in a generalized arithmetic progression (GAP) of rank  O ⁡ ( 1 ) O(1)  and size  O ⁡ ( n ) O(n) ; this characterization is tight up to the dependence of the implicit constants. In the present paper we study analogous problems for sets with few distinct subset sums. 
 
 
 
 For a finite subset  A A  of an abelian group  G G , let 
 
 

 
 
 FS ⁡ ( A ) := { ∑ x ∈ B x : B ⊆ A } \mathrm{FS}(A):=\left\{\sum_{x\in B}x:B\subseteq A\right\} 
 
 
 denote the set of  subset sums  of  A A . (The notation “ FS \mathrm{FS} ”, standing for “finite sums”, originated in arithmetic Ramsey theory.) In the most natural setting  G = ℝ G=\mathbb{R} , an easy inductive argument (see  [ Nat95 , Theorem 3] ) gives that if  A ⊆ ℝ > 0 A\subseteq\mathbb{R}_{>0}  is an  n n -element set, then 
 
 

 
 
 | FS ⁡ ( A ) | ≥ ( n + 1 2 ) + 1 . |\mathrm{FS}(A)|\geq\binom{n+1}{2}+1. 
 
 
 One can further show (see  [ Nat95 , Theorem 5] ) that when  n ≥ 4 n\geq 4 , equality occurs if and only if  A A  is a  homogeneous arithmetic progression , namely, a set of the form 
 
 

 
 
 A = { a , 2 ​ a , … , n ​ a } A=\{a,2a,\ldots,na\} 
 
 
 for some  a > 0 a>0 . The goal of this paper is to establish stability versions of this inverse theorem. We study two regimes, one with a more “exact” flavor (like Freiman’s  3 ​ k − 4 3k-4  Theorem) and one with a more “asymptotic” flavor (like the Freiman–Ruzsa Theorem). 
 
 
 
 This line of inquiry is closely related to inverse Littlewood–Offord theory. Littlewood–Offord theory concerns the anticoncentration properties of the random variable  S := ∑ x ∈ B x S:=\sum_{x\in B}x , where  B B  is a uniformly random subset of a fixed  n n -element (multi)set  A ⊆ ℝ > 0 A\subseteq\mathbb{R}_{>0} . Inverse Littlewood–Offord theory, as introduced by Tao and Vu  [ TV09 ] , aims to describe the structure of the (multi)sets  A A  with  max y ∈ ℝ ℙ [ S = y ] \max_{y\in\mathbb{R}}\mathbb{P}[S=y]  large; a typical result (see  [ TV09 , Theorem 2.5 and Corollary 2.7] ) says that if  max y ∈ ℝ ℙ [ S = y ] ≥ n − O ⁡ ( 1 ) \max_{y\in\mathbb{R}}\mathbb{P}[S=y]\geq n^{-O(1)} , then almost all of  A A  is contained in a generalized arithmetic progression of rank  O ⁡ ( 1 ) O(1)  and size  n O ⁡ ( 1 ) n^{O(1)} . 
 
 
 
 Conceptually speaking, our main results describe the structure of the set  A A  when the random variable  S S  has  small support , while the work of Tao and Vu describes the structure of  A A  when the random variable  S S  has  some popular value . The former hypothesis is of a stronger form than the latter, and we obtain the accordingly stronger conclusion that  A A  must resemble a generalized arithmetic progression of rank  1 1 , rather than merely fairly small rank; this “rank-collapse” phenomenon (see  Proposition   4.4  below) is one of the main takeaways of the paper. 
 
 
 
 
 
 1.2.  Main results 
 

 
 We first study the regime where  | FS ⁡ ( A ) | |\mathrm{FS}(A)|  only slightly exceeds  ( n + 1 2 ) + 1 \binom{n+1}{2}+1 , as proposed by Nathanson in 1995  [ Nat95 ] . For  c ∈ ℝ × c\in\mathbb{R}^{\times} , let  c ⋅ A c\cdot A  denote the dilation of  A A  by  c c .

 The latter condition in  Theorem   1.1  implies that

See  [ Lev99 ]  for older results of a similar flavor; also see  [ Lev24 ,  GHHLLP20 ]  and the references therein for thematically related work on subsequence sums of zero-sum-free sequences in finite abelian groups.

 In this section we prove  Theorem   1.1 , our exact characterization of subsets of  ℝ > 0 \mathbb{R}_{>0}  with close to the minimum possible number of subset sums.

 We conclude by discussing some further (mostly open) questions raised by our work. 
 
 
 
 5.1.  Extensions of  Theorem   1.1 
 

 
 Freiman’s  3 ​ k − 4 3k-4  Theorem says that if  A ⊆ ℝ A\subseteq\mathbb{R}  is an  n n -element set with  | A + A | ≤ 3 ​ n − 4 |A+A|\leq 3n-4 , then  A A  is “close” to being an arithmetic progression, in the sense that it is contained in an arithmetic progression of length  | A + A | − n + 1 |A+A|-n+1 . The  3 ​ k − 3 3k-3  Theorem provides a looser structural constraint on  n n -element sets  A A  with  | A + A | ≤ 3 ​ n − 3 |A+A|\leq 3n-3  (roughly speaking, either  A A  is contained in a short arithmetic progression, or it is the union of two arithmetic progressions with the same common difference). From here, the situation becomes more complicated but is still somewhat understood as long as  | A + A | |A+A|  is at most around  4 ​ | A | 4|A| ; see  [ EGM14 ,  JM26 ]  and the references therein. 
 
 
 
 Our  Theorem   1.1  provides a precise characterization of the  n n -element sets  A ⊆ ℝ > 0 A\subseteq\mathbb{R}_{>0}  with  | FS ⁡ ( A ) | ≤ ( n + 1 2 ) + 1 + ( n − 4 ) |\mathrm{FS}(A)|\leq\binom{n+1}{2}+1+(n-4) , and we showed that our characterization fails if one replaces  n − 4 n-4  with  n − 3 n-3 . In contrast with the sumset setting described in the previous paragraph, however, here we are optimistic that for any fixed constant  C C , one should (with sufficient case analysis) be able to precisely characterize the  n n -element sets  A ⊆ ℝ > 0 A\subseteq\mathbb{R}_{>0}  with  | FS ⁡ ( A ) | ≤ ( n + 1 2 ) + 1 + ( n + C ) |\mathrm{FS}(A)|\leq\binom{n+1}{2}+1+(n+C) . We expect that such sets will still be “close” to homogeneous arithmetic progressions, but the allowed lengths of these arithmetic progressions will depend on the particular structure of the smallest  Θ C ​ ( 1 ) \Theta_{C}(1)  elements of  A A . The reason for our optimism is that the repeated addition of the subset sum operation introduces “smoothing” that tends to fill in gaps away from the very smallest and very largest subset sum values; the study of numerical semigroups may be relevant (see, e.g.,  [ Nat72 ,  GS23 ] ). 
 
 
 
 If one allows  C C  to grow sufficiently quickly with  n n , then of course one can no longer expect  A A  to resemble a homogeneous arithmetic progression. It would be interesting to determine, in some precise sense, the threshold at which this change of behavior occurs. 
 
 
 
 We also mention that one can pose the same questions for sets  A A  that are allowed to contain negative numbers as well as positive numbers (see  [ Nat95 , Theorems 4 and 6] ); the methods of  Theorem   1.1  should yield analogous results in this setting. 
 
 
 
 
 
 5.2.  Littlewood–Offord theory and extensions of  Theorem   1.2 
 

 
 Let us expand on our earlier discussion of Littlewood–Offord theory. Recall that this area concerns the anticoncentration properties of the random variable  S := ∑ x ∈ B x S:=\sum_{x\in B}x , where  B B  is a uniformly random subset of a fixed  n n -element multiset  A ⊆ ℝ > 0 A\subseteq\mathbb{R}_{>0} . Early results of Littlewood and Offord  [ LO43 ] , Erdős  [ Erd45 ] , Erdős and Moser  [ EM47 ] , and Sárközy and Szemerédi  [ SS65 ]  showed that  max y ∈ ℝ ℙ [ S = y ] ≪ n − 1 / 2 \max_{y\in\mathbb{R}}\mathbb{P}[S=y]\ll n^{-1/2}  for all  n n -element multisets  A A , and that  max y ∈ ℝ ℙ [ S = y ] ≪ n − 3 / 2 \max_{y\in\mathbb{R}}\mathbb{P}[S=y]\ll n^{-3/2}  for all  n n -element sets  A A . Tao and Vu  [ TV09 ]  later showed that if  max y ∈ ℝ ℙ [ S = y ] ≥ n − O ⁡ ( 1 ) \max_{y\in\mathbb{R}}\mathbb{P}[S=y]\geq n^{-O(1)} , then almost all of  A A  is contained in a GAP of rank  O ⁡ ( 1 ) O(1)  and size  n O ⁡ ( 1 ) n^{O(1)} . 
 
 
 
 In the setting of  Theorem   1.2 , the assumption  | FS ⁡ ( A ) | ≤ C ​ n 2 |\mathrm{FS}(A)|\leq Cn^{2}  implies that  max y ∈ ℝ ℙ [ S = y ] ≥ C − 1 n − 2 \max_{y\in\mathbb{R}}\mathbb{P}[S=y]\geq C^{-1}n^{-2} , and then the result of Tao and Vu tells us that most of  A A  is contained in a GAP of rank  O C ​ ( 1 ) O_{C}(1)  and size  n O C ​ ( 1 ) n^{O_{C}(1)} .  Consider the more general problem of studying the structure of  n n -element sets  A ⊆ ℝ > 0 A\subseteq\mathbb{R}_{>0}  with  | FS ⁡ ( A ) | ≤ C ​ n κ |\mathrm{FS}(A)|\leq Cn^{\kappa}  for fixed  κ > 2 \kappa>2  and  C > 0 C>0 . In this direction, the inverse Littlewood–Offord results of Tao and Vu identify a large subset of  A A  that is contained in a GAP of rank  O κ , C ​ ( 1 ) O_{\kappa,C}(1)  and size  n O κ , C ​ ( 1 ) n^{O_{\kappa,C}(1)} , but we do not see any way to guarantee that the rank is in fact at most  ⌊ κ ⌋ − 1 \lfloor\kappa\rfloor-1 .

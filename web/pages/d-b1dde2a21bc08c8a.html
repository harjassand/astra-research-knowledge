# Keep the global class when the lag uses an acquired scale

7 October 2026. Conditional successor to predictive_confidence_and_cost.md. Independent gate pending. This removes an otherwise illegal restriction of the confidence class to an empirically guessed bracket. It is not a standalone unknown-scale expected-cost theorem; scale acquisition and its tail must be separately supplied/proved.

## Coverage is global regardless of scale selection

Keep the original generator class with b in[0,1], unknown ordinary numerical rates in the fixed positive envelope, known baseline graph and parameter-independent initial state. At a stopping time determined by previous full observations choose any beta>0 and admissible small lag t=max(tau,kappa beta^(1/(L-1)))<=t0. Start exactly one future two-block predictor, all pilots before confirmations as in the primary note. The masked ratio is a martingale conditional on every preceding history, so the confidence set covers the true global-class Q with probability>=1-delta_c regardless of the accuracy of beta. All previous and future observations are physically charged. Never clip this class or a failed output to an uncertified guessed bracket.

For width only, suppose a separate acquired-scale event gives

    beta<=b<=c beta,

with fixed known c>=2 (c=4 fits the programme's geometric bracket). The next calculation is uniform conditional on every history satisfying this event. It does not reinterpret that event as part of the likelihood model.

## Observed small endpoint probability restricts accepted candidates

Let Kkappa=kappa^(-(L-1)) and Htrue=c Kkappa. Construct Cp_true from the explicit weighted support formula in cycle6/minimum_lag_joint_generator.md, with Htrue in place of its H. On the acquired-scale event,

    P_true(t)_uv<=Cp_true t^L.

The add-one split bound is uniform conditional on all pre-pilot history. With equal m pilot and confirmation counts, use a rational Bstar>=1+2n(n-1)/delta_w+log(1/delta_c) and the finite upper budget B as before. If B>Bstar, return[0,1]/UNKNOWN. Require the count schedule to imply k=B/m<=beta t. Since t>=kappa beta^(1/(L-1)),

    k<=Kkappa t^L.

On global true-coverage and the small-D event, binary indicator transport gives

    Phat_uv<=P_true,uv+sqrt(2 P_true,uv k)+k/3
             <=C1 t^L,
    C1=Cp_true+sqrt(2 Cp_true Kkappa)+Kkappa/3.

C1 is rounded upward. Make Phat_uv<=C1 t^L an observable precheck (with a slack-enclosed threshold if t is not rational). Failing it returns the full global range. It passes on the good scale/coverage/width events.

For every accepted global-class candidate, put p=P_Q(t)_uv and r=Phat_uv. Binary KL(r||p)<=k. Transport in the opposite direction and variance<=p yield

    p<=r+sqrt(2pk)+k/3
       <=r+p/2+4k/3,
    p<=2r+(8/3)k.

The inequality sqrt(2pk)<=p/2+k is elementary. Every admitted Q has escape rate<=lambda, so exactly one rare jump and no other jump gives p>=b_Q t exp(-lambda t). After the empirical precheck, therefore,

    b_Q<=Hglobal t^(L-1),
    Hglobal=exp(lambda t0)[2C1+(8/3)Kkappa].       (GLOBAL)

This is a consequence of acceptance and observable checks. It has not supplied an unknown ordinary rate or assumed that candidates respect the guessed bracket. In particular candidates with b_Q=0 remain in the original class unless their actual likelihood excludes them.

## Weighted log certificate and conditional width

Compute Cp_global,Cr_global,Vglobal,Mglobal by the previously proved weighted formulas, replacing H by Hglobal. These constants depend only on fixed graph/envelopes,kappa,c. Every accepted candidate obeys those bounds after(GLOBAL), even though the original class was b in[0,1]. Use the deterministic outer log certificate and count formula with these larger constants. Retain the norm check and finite arithmetic budget. Any failure or empty intersection returns[0,1]/UNKNOWN. Otherwise output the outer interval intersected with[0,1].

This is an unconditionally valid outer confidence set over the global class, for any selected beta. On the separate acquired-scale event and the split/coverage/cap good events, the observed checks pass and the radius is<=epsilon beta/2. The true rare rate then has a certified relative-width interval. If an interval is [a,z] with0<a<=z, midpoint relative error for every b in the interval is at most(z-a)/(2a); this observable condition can be used to stop without presuming the guessed bracket is valid.

The future two-block counts, conditional on the selected beta, have the same powers

    reads=O[beta^(-L/(L-1))+beta^-2 tau^(L-2)],
    time =O[beta^-1+beta^-2 tau^(L-1)]

with worse fixed constants. All2n hits and2nm cycles, plus earlier scale-acquisition data, must be added. To turn these conditional bounds into an unconditional expected-cost theorem requires a proved integrable tail for selected beta. High-probability bracket accuracy alone is insufficient: arbitrarily tiny beta on a rare bad event can make expected subsequent cost infinite. Root's separate geometric-stage tail argument is the relevant missing/composition interface; this note does not independently gate it. Multiple attempts at future confirmations similarly need error weights or a single common process; an unweighted repeated fresh-start search is not justified by the once-only conditional proof.

## Status and downstream use

This certificate resolves the mathematical confidence-class issue: legal global coverage can coexist with scale-adaptive lag selection and a topology-sensitive final interval. It does not solve practical constant size, general noisy sensors, unknown support, or arbitrary large sensor floors. The rare-row empirical precheck and the large Hglobal constants may be much weaker than a direct semigroup likelihood projection. No new-priority claim is made: this uses standard predictive universal inference and the programme's support-weighted matrix-log bound.

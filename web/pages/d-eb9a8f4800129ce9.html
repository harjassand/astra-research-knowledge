# Matrix-MW compiler audit for the equal-depth EB comparator

## Verdict

The separation proof can be made into a randomized polynomial-time **approximate** compiler, provided the supplied broadcaster has a finite, efficiently evaluable dense representation and the output may be a succinct program for a finite strategy mixture. Matrix multiplicative weights turns the all-positive-witness tree response into one finite mixture. The mixture has polynomially many tree components; its induced POVMs have exponentially many outcomes, but neither the compiler nor the operational specification needs to list them.

This does not give an explicit polynomial-size list of all POVM effects, nor an exact zero-slack comparator. The conclusion is a δ-slack comparator with high probability. Bit-complexity needs a finite input model (for example, rational/algebraic channel entries with certified arithmetic); an arbitrary exact-real oracle has no ordinary input-bit bound.

## Game and normalization

Work on the real Hilbert space \(\mathcal H_0\) of traceless Hermitian matrices, of dimension \(n=d^2-1\), with normalized Hilbert--Schmidt inner product. Let

\[
m=\lceil\log_2(d^2)\rceil,\qquad A=I-2mG,\qquad G=I-\Phi.
\]

The tree lemma says that for every density matrix \(Q\succeq0\) on \(\mathcal H_0\), a response tree produces a canonical EB map \(\Psi_Q\) with

\[
\operatorname{Tr} Q(\Psi_Q-A)\ge0.
\tag{1}
\]

Use loss matrices \(L_t=A-\Psi_t\). Given the current dual density \(Q_t\), (1) says \(\operatorname{Tr}(Q_tL_t)\le0\). Since \(0\preceq G\preceq2I\), \(\|A\|\le4m-1\); canonical measurement maps are positive HS contractions, hence \(\|\Psi_t\|\le1\). Thus \(\|L_t\|\le R:=4m+1\) is safe.

Run matrix MW with

\[
Q_t=\frac{\exp(\eta\sum_{s<t}\widehat L_s)}
{\operatorname{Tr}\exp(\eta\sum_{s<t}\widehat L_s)},
\qquad \widehat L_t=A-\widehat\Psi_t,
\]
where \(\widehat\Psi_t\) estimates \(\Psi_t\). If the support response has \(\operatorname{Tr}Q_t(\Psi_t-A)\ge-\epsilon_{\rm oracle}\) and \(\|\widehat\Psi_t-\Psi_t\|\le\epsilon\), then \(\operatorname{Tr}(Q_t\widehat L_t)\le\epsilon_{\rm oracle}+\epsilon\). Standard matrix regret gives

\[
\lambda_{\max}\!\left(\frac1T\sum_t L_t\right)
\le \epsilon_{\rm oracle}+2\epsilon+\frac{\log n}{\eta T}+O(\eta R^2).
\]

Taking \(T=O(R^2\log(n)/\delta^2)\), \(\eta\asymp\sqrt{\log(n)/(TR^2)}\), and \(\epsilon,\epsilon_{\rm oracle}=\Theta(\delta)\), with constants chosen so the right side is at most \(\delta\), yields

\[
\overline\Psi:=\frac1T\sum_{t=1}^T\Psi_t\succeq I-2mG-\delta I.
\tag{2}
\]

Each response may use a noisy support oracle with \(\operatorname{Tr}Q_t(\Psi_t-A)\ge-\epsilon_{\rm oracle}\); its error adds \(\epsilon_{\rm oracle}\) to the displayed average bound. Query/update and eigensolver roundoff can be charged in the same way: use a rational PSD trace-one approximation \(\widetilde Q_t\) with trace-norm error \(\alpha\), which changes the oracle payoff by at most \(R\alpha\). All required precision is polynomial in the input bit length, \(d\), and \(\log(1/\delta)\) under the stated finite arithmetic model.

## Sampling a response without enumerating its outcomes

For each eigendirection of \(Q_t\), choose a rank-one spectral PVM \(\{P_y\}_{y=1}^d\) of the associated traceless Hermitian observable. Use the full binary broadcast tree with \(K=2^m=O(d^2)\) leaves, assigning one direction to each needed leaf and arbitrary rank-one PVMs to unused leaves. To regularize outcome probabilities, replace every leaf PVM by

\[
F_y=(1-\gamma)P_y+\gamma I/d,\qquad y=1,\ldots,d.
\tag{3}
\]

These are a POVM, each \(F_y\succeq(\gamma/d)I\). For any frame observable \(H\in\mathcal H_0\), its noisy one-leaf marginal has outcome probabilities \(1/d\) and score exactly \((1-\gamma)^2\) times the projective score: the uniform part of (3) has zero pairing with traceless \(H\). The joint tree measurement refines each leaf marginal, so its canonical map has at least that score in every frame direction. Since each ideal score is nonnegative and is at least \(\|H\|_2^2-2m\langle H,GH\rangle\), the dual support inequality (1) loses at most \(2\gamma\) for trace-one \(Q_t\). Set \(\gamma=O(\delta)\).

Let \(E_z\) be the input effect for the full leaf outcome string \(z\), computed recursively by

\[
E_v=\mathcal B^*(E_{v_L}\otimes E_{v_R}).
\]

Because the full tree adjoint is unital and the leaf product effect is at least \((\gamma/d)^K I\),

\[
E_z\succeq(\gamma/d)^K I,\qquad p_z:=\tau(E_z)\ge(\gamma/d)^K.
\tag{4}
\]

For \(z\sim p\), define \(\rho_z=E_z/\operatorname{Tr}E_z\) and \(v_z=\rho_z-I/d\). The canonical channel restricted to \(\mathcal H_0\) is

\[
\Psi_0=d^2\,\mathbb E_{z\sim p}\bigl[|v_z\rangle\langle v_z|_\tau\bigr].
\tag{5}
\]

Thus one sample contributes a PSD matrix of norm \(d^2\|v_z\|_{2,\tau}^2\le d-1\). Matrix Hoeffding implies \(N=O(d^2\epsilon^{-2}\log(nT/\eta))\) samples estimate (5) to operator error \(\epsilon\), simultaneously for all \(T\) rounds with failure probability at most \(\eta\).

Sampling does not require a global \(d^K\)-outcome state or POVM list. For a partially fixed leaf string, put \(I\) at unassigned leaves and recursively compute one \(d\times d\) effect message per tree node. Its trace is the total probability of that partial string under input \(I/d\). To sample the next leaf, try its \(d\) candidate effects and divide their root traces by the current root trace. Cache sibling messages; each candidate changes only the path to the root. This costs \(O(Kd\log K)\) applications of the dense adjoint \(\mathcal B^*\) per sample, followed by one root contraction for \(E_z\). Bound (4) makes normalization and conditional probabilities polynomial-bit operations: \(\log(1/p_z)\le K\log(d/\gamma)\). The same lower bound holds for a partial assignment. The estimator never importance-weights by \(1/p_z\); rare outcomes therefore cause no variance blow-up.

For a Liouville dense broadcaster, one \(\mathcal B^*\) contraction has polynomial cost (at most a dense contraction of order \(d^6\)); the complete tree has \(K-1=O(d^2)\) broadcaster nodes. Overall sample, MW, matrix-exponential, and eigenspace costs are polynomial in \(d,1/\delta,\log(1/\eta)\), and the encoded channel size. Numerical sampler bias and eigenspace approximation must each be bounded in operator norm and added to \(\epsilon\); the full-support floor (4) gives polynomial precision for these steps.

## Finite mixture representation and operational cost

The exact output is the uniform mixture of the \(T\) response strategies. It is itself canonical EB: use the union POVM with effects \(E_{t,z}/T\), retaining the strategy index \(t\), and prepare \(\rho_{t,z}=E_{t,z}/\operatorname{Tr}E_{t,z}\). Store each component as its tree, local rank-one bases, and the supplied \(\mathcal B\), rather than listing all \(d^K\) outcomes. For a realized string \(z\), its effect and prepared state are recovered in \(O(K)\) cached dense contractions. One execution chooses one of the \(T\) strategies and uses \(K-1=O(d^2)\) broadcaster calls; storing the mixture takes polynomial space. A polynomial-size dense matrix estimate of \(\overline\Psi\) can also be formed from the same samples, but that empirical matrix is only an estimate and need not itself be EB. The exact EB guarantee belongs to the implicit mixture in (2).

The overall method is randomized: (2) holds with probability at least \(1-\eta\), after union-bounding the matrix concentration events and certified numerical errors. It gives a finite \(\delta\)-slack comparator, not a zero-slack exact optimizer. If a consumer insists on an explicit outcome-by-outcome POVM table, its exponential size is an unavoidable representation cost for this construction; the polynomial claim is for the succinct tree-mixture interface.

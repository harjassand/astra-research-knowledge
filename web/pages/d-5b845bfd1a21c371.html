ROUND 6 c04_l08 DEEPER ATTACK — BLACK-BOX COST OF ACQUIRING AN EB POVM
Saved 2026-10-07. Attribution: independent c04_l08 derivation after authorized cross-phase exposure.

CLAIM AND ACCESS MODEL

There is a constant c>0 and, for all sufficiently large d, a finite family of at least exp(c d^2) exact self-compatible channels on M_d, each of which is already entanglement breaking and has an exact rank-one d-outcome measure-and-prepare representation, such that any learner with black-box channel access that outputs a standalone classical channel/POVM description within diamond error 1/8 of the unknown member needs Omega(d^2/log d) channel calls in the worst case. The same query lower bound holds if its required accuracy is less than 1/(8d) in the normalized infinity-to-one norm induced by tau=Tr/d.

This is a representation-acquisition lower bound. Every channel in the family can itself be retained and invoked as an exact EB oracle, at zero identification cost. Thus the result does not lower-bound use of a retained physical device, does not refute existential EB reconstruction, and is not an unconditional acquisition lower bound when a circuit, matrix, or basis description is supplied for free. It isolates a missing input-model clause in any claim that a short POVM support bound is an efficient synthesizer.

CONSTRUCTION AND COMPATIBILITY

For U in U(d), write P_i^U=U|i><i|U* and define

  Delta_U(X)=sum_i Tr(P_i^U X) P_i^U.

This is a CPTP, unital, self-adjoint, entanglement-breaking dephasing channel. It has the exact d-outcome rank-one POVM {P_i^U} and prepares P_i^U after outcome i. It is self-compatible: the channel

  B_U(rho)=sum_i Tr(P_i^U rho) P_i^U tensor P_i^U

has both marginals Delta_U. The reference sigma=I/d and algebra M_d are fixed and known throughout the family. Only the basis U is hidden.

PAIRWISE SEPARATION AND LARGE CODE

Fix two bases U,V and let W=U*V. For input P_i^V, Delta_V(P_i^V)=P_i^V while

  Delta_U(P_i^V)=sum_j p_(ji) P_j^U,  p_(ji)=|W_(ji)|^2.

The binary test {P_i^V,I-P_i^V} shows that the output trace distance
  T(Delta_V(P_i^V),Delta_U(P_i^V)) >= 1-sum_j p_(ji)^2.
Thus if the diamond distance of the two channels is at most eta, then every column i satisfies sum_j p_(ji)^2>=1-eta/2, hence max_j p_(ji)>=1-eta/2. For eta<1, the selected high-mass row is unique in each column; unitarity makes these rows distinct. Therefore W must have a permutation pi with |W_(pi(i),i)|^2>=1-eta/2 for every i.

Now choose W Haar-random. Condition on the first i-1 columns. Column i is uniform on the unit sphere of a subspace of complex dimension n=d-i+1. For any specified coordinate row, the probability its squared overlap is at least 1-eta/2 is at most (eta/2)^(n-1): in the full subspace the squared overlap has Beta(1,n-1) tail (1-t)^(n-1), and projecting a coordinate into the subspace can only reduce the tail. For the first m=floor(d/2) columns, n-1>=m. A fixed permutation therefore has probability at most (eta/2)^(m^2) of meeting all high-overlap conditions. A union bound over at most d! permutations gives

  Pr[ every column has a row with p_(ji)>=1-eta/2 ] <= d! (eta/2)^(floor(d/2)^2).

At eta=1/4 this is exp(-Omega(d^2)). Since U*V is Haar when U,V are independently Haar, random coding and a union bound produce a code C_d subset U(d) of size exp(c d^2), for some constant c>0 and all sufficiently large d, such that for every distinct pair there is a column i with max_j p_(ji)<1-eta/2. For that i, sum_j p_(ji)^2<=max_j p_(ji)<1-eta/2, so the binary test above gives ordinary output trace distance greater than eta/2. Thus the channels are pairwise diamond-separated by more than 1/4 and also have the explicit normalized-norm witness used below.

INFORMATION LOWER BOUND FOR ADAPTIVE QUERIES

Let S be uniform on this code and let an adaptive learner use k calls to the unknown channel, with arbitrary entangled inputs, ancillae, and adaptive control. At call t, write A_t for the d-dimensional query input and R_t for all other prior memory; the returned register B_t also has dimension d. The query changes the mutual information about S by

  I(S:B_t R_t)_after - I(S:A_t R_t)_before
    = I(S:B_t | R_t)_after - I(S:A_t | R_t)_before
    <= I(S:B_t | R_t)_after <= 2 log_2(d),

because conditional mutual information with a d-dimensional system is at most 2 log_2(d). Any intervening adaptive control is independent of S and cannot increase mutual information. Induction over calls and final data processing imply that the learner transcript carries at most 2k log_2(d) bits about S. If the learner returns a hypothesis within diamond error strictly below 1/8 with probability at least 2/3, nearest-neighbour decoding identifies S because the code separation exceeds 1/4. Fano's inequality then requires I(S:transcript)=Omega(log |C_d|)=Omega(d^2), so

  k = Omega(d^2 / log d).

This applies to the number of black-box calls, not local computation time. The learner may perform arbitrarily expensive optimization after the calls.

CONVERSION TO THE CAMPAIGN'S NORMALIZED NORM; DESCRIPTION BITS

For each separated pair the proof supplies an i with ordinary trace distance greater than 1/8 on P_i^V. Therefore

  ||(Delta_U-Delta_V)(P_i^V)||_(1,tau) > 1/(4d),

since ||X||_(1,tau)=Tr|X|/d and P_i^V has operator norm one. Thus the same code is pairwise separated by more than 1/(4d) in ||.||_(infinity-to-1,tau); accuracy below 1/(8d) suffices to decode and gives the same query lower bound.

If a standalone hypothesis is encoded as a finite binary string and must work at either of these accuracies, one string cannot represent two code members. Any always-correct description therefore needs at least log_2|C_d|-O(1)=Omega(d^2) bits. This matches the order of the d^2 continuous degrees of freedom in a basis at constant channel accuracy, but says nothing about the additional log(1/epsilon) precision factor. It is compatible with d outcomes: support size and acquisition/description cost are different resources.

COST CONSEQUENCE AND LIMITS

The Caratheodory bound in INITIAL/CROSS_PHASE is an existential support compression after an exact channel/measure-prepare representation is already available. This lower bound shows that, under a black-box-only interface, even an exact d-outcome EB representation can hide Omega(d^2) channel parameters and costs Omega(d^2/log d) device calls to extract to constant diamond accuracy. A finite algebraic optimizer or a dimension-polynomial outcome bound does not pay this access cost. A physically retained channel oracle is a stronger representation than any synthesized POVM and must be charged/allowed explicitly in a fair comparator.

The proof does not address unknown central weights, non-EB compatible channels, a supplied channel matrix, promise of a known structured basis, or input access by direct tomography of sigma and likelihood states. It gives no efficient synthesis algorithm and is not a lower bound for the universal broadcasting-to-EB rounding theorem: the constructed channels are already EB. The decisive next gate for a useful constructive claim is therefore to state whether the compatible channel is supplied as a matrix/circuit, as query access, or as a retained physical oracle, and whether a standalone POVM description is required.

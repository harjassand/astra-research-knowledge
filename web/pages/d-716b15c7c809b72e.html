# Scientific report — first research cycle, 6 October 2026

The strongest supported advance is a **single-excitation identification and stability theorem for a specified nonlinear conductivity model class**. Let conductivities range over a fixed finite-dimensional vector space whose whole span is piecewise analytic, with uniform positivity on the compact parameter set of interest. One Gaussian boundary current, with injective trace-class covariance, almost surely identifies all model parameters from its full voltage response. Its compact inverse Lipschitz constant has **every finite moment**. Normalizing the current to unit L² power preserves that statement. Independent derivations checked the key rank, Gaussian-conditioning and compactness steps. This is internal mathematical validation; historical novelty and external review remain open.

The proof combines a finite-codimension localized-potential construction with rank-sensitive experiment geometry, then Gaussian small-ball probabilities and normalized-secant covering bounds. [PDE proof](../notes/rank_pde/proof.md), [rank theorem](root_rank/vector_input_theorem.md), [conditioning theorem](root_rank/conditioning_moments.md), [independent audit](../notes/team_a_inverse/vector_rank_audit.md). A radial two-layer model supplies explicit formulas, reconstruction and exact rational checks: [derivation](../notes/rank_pde/radial_derivation.md), [code](../work/rank_pde/radial_check.py).

The finite follow-up supplies explicit two-mode reconstruction and 2B-detector inverse moments of every order p<B. In a frozen six-detector, unit-current-power test, optimized deterministic excitation outperformed the random design; the radial model gives exact statistical equivalence between matched deterministic single- and multiple-current experiments. [Finite proof and costs](../notes/rank_pde/finite_construction.md), [executable experiment](../work/rank_pde/finite_radial_experiment.py). This is a scoped demonstration and a negative advantage comparison, not a practical general victory.

This matters because it changes the design question from how many scalar samples suffice to how much independent information one physical response contains. It offers a route to certified economical experiments. It is not yet a practical general method: the exact unresolved obstacle is an **effective uniform lower bound on whitened normalized-secant singular values**, with input bandwidth, detector count, precision, noise and computation charged. Finite input/detector spaces exist for any prescribed finite moment guarantee, but their general size remains nonconstructive. Arbitrarily poor constants across model classes remain possible.

Prior art is substantial. [Sontag2002 §6.9](https://www.sontaglab.org/FTPDIR/ident-experiments.pdf) already explains vector-output codimension; [Harrach2019](https://arxiv.org/abs/1808.04737) supplies localized potentials and finite-measurement conductivity stability. [Alberti et al., August2026](https://arxiv.org/abs/2608.14324) explicitly raises the one-input question. Earlier one-measurement inclusion results have different hypotheses. The potentially new contribution is the composed uniform fixed-span boundary theorem and conditioning moments, not those inherited ingredients. [Priority audit](../notes/a_prior/single_current_novelty.md) found no directly subsuming source, which is not proof of novelty.

A second substantive result is a **controlled-source exact-conversion theorem** for known finite full-support statistical experiments. One adaptive policy reproduces every finite terminal report of an integrable target stopping policy, with optimal statewise LP cost coefficients and a uniform square-root remainder. An exact example has adaptive first-order coefficient0.8281 in every state, versus worst-state coefficient at least1.2421 for every frozen IID mixture. [Proof](../notes/team_d_experiments/RESULT.md), [independent reconstruction](../notes/check_selection/technical_verdict.md), [exact rational converter](../work/check_selection/exact_finite_converter.py). This extends the interface of [Li–Liu2026](https://arxiv.org/html/2608.19897v2) using classical controlled-sensing ideas. Computationally efficient conversion, unknown-law acquisition and full prior-art coverage are still missing. The finite exact implementation costs about10.21 observations for its small example; it is not the asymptotic0.8281 claim implemented at that scale.

CYCLE 4 — BOUNDED SIGNIFICANCE COMPARISON
Checked 2026-10-08 against the two 2026 primary arXiv sources already in
LITERATURE.txt. Scope is the product-conjugate finite-Haar von Neumann
additivity witness and its channel interface; this is not a broad priority
search or an independent proof review.

Primary source 1: Zhen, Zhu, Chen, Wang, arXiv:2609.18747v1 (2026-09-16)
“Almost One Bit Violation of Minimum-Output Rényi Entropy Additivity
Simultaneously at All Orders.”
https://arxiv.org/abs/2609.18747
https://arxiv.org/html/2609.18747v1

Verified interface and theorem:
- Section 2.1, Eqs. (1)–(5): for Gamma=product_(j=1)^r F_d^(j), K=2rd
  inverse-closed branches, and a real orthogonal representation pi, the
  complementary channel Phi_pi has input M_(m)(C), output M_K(C). Its Haar
  model uses independent O(N) generators on separate tensor legs, with
  m=N^r. Realness makes Phi_pi equal to its channel conjugate, so the Bell
  input witnesses the same-channel tensor square.
- Theorem 2.1, Eq. (10): for every epsilon in (0,ln 2), suitable r,d give
  Haar-orthogonal realizations with probability tending to one as N grows,
  for which the same Bell input has gap at least ln 2-epsilon
  simultaneously for every Renyi order p in [0,infinity]. The output size
  can be K=O(epsilon^-3). The theorem is asymptotic in N; its displayed
  statement gives no explicit finite N threshold.
- Sections 4.2–4.3, Proposition 4.3, Lemma 4.4 and Corollary 4.5: for real
  orthogonal representations, branch-pair vectors collapse exactly on the
  relative-operation fibres. The fibre profile q is majorized by the Bell
  output spectrum, so H_p(Bell)<=H_p(q) at every order. The q profile is not
  in general the exact finite Bell spectrum.
- The paper's finite-output example at r=2,d=80,K=320 gives a displayed
  simultaneous all-order lower bound above 1.4e-3 nats, with Haar-O
  probability tending to one. It is a stronger gap/order result than this
  cycle's selected witness, though the example statement is not an explicit
  numeric N threshold.

Primary source 2: Zhen, Chen, Wang, arXiv:2610.06533v1 (2026-10-05)
“Closed-Form Arbitrary-Gap Rényi Nonadditivity Above Any Positive Order via
Direct Products of Free Groups and High-Girth Graphs.”
https://arxiv.org/abs/2610.06533
https://arxiv.org/html/2610.06533v1

Verified interface and theorem:
- Theorem 2.1 gives closed-form real-algebraic channels and one Bell input
  with any prescribed gap uniformly for p in [p0,infinity], p0>0; dimensions
  are explicit. The channel is a finite deterministic construction, not a
  Haar-existence statement.
- Corollary 2.2 (Eqs. (5), (105), (129)): a separate p=1 specialization is
  an explicit real-algebraic channel M_(2^N*)(C)->M_256(C), N*=37,608,898
  input qubits, whose standard Bell input has
  2 H_min,1(Phi*)-H_1(Phi*^tensor2(Omega))>1/1024 nats. The source states
  that the prescriptions specify the matrices. This is the closest direct
  same-channel p=1 baseline and is more explicit than the cycle's random
  Haar realization.

Cycle 4 interface and exact overlap:
- The selected finite model is complex Haar U(N), Gamma=F_65 x F_65,
  K=260, Phi_N:M_(N^2)(C)->M_260(C), with 130 independent generator
  matrices acting on the two tensor legs. The repaired Bell witness is
  Phi_N tensor bar(Phi_N), not the withdrawn Phi_N tensor Phi_N quotient.
- For the repaired pair, vectorization gives branch vectors
  vec(W_s W_t*)/sqrt(N^2), indexed by nu(s,t)=s t^(-1). Since S=S^(-1),
  this has the source's fibre multiplicities. Its finite Gram matrix is
  positive semidefinite with diagonal q; Schur–Horn therefore gives Bell
  entropy <=H(q) for every finite representation. The real-orthogonal
  source quotient is recovered as a special case, where the conjugate
  channel equals the channel. Thus the product-conjugate fibre mechanism
  is a complex-interface extension of the source's exact quotient, not a
  new free-product collision phenomenon.
- A standard flagged direct-sum channel Xi_N:M_(2N^2)(C)->M_260(C) turns
  the pair Phi_N,bar(Phi_N) into a same-channel tensor-square witness, at
  one extra input flag qubit per use. The flag conversion is standard.
- The finite-U score/net calculation in RESULT.txt selects
  N=16(130)^14 p^836, p=15,999,300,534, and gives a displayed p=1 gap
  lower bound 0.0010070146 nats with probability at least 2/3, conditional
  on the free-radius bound C^2<=50. The per-use Phi input has log2
  dimension 56,880.8948; Xi adds one qubit-equivalent input dimension.
  The dense Haar matrices are not materialized, and no explicit seed or
  efficient finite-precision sampler is supplied. The local claim status
  remains internally-proved-candidate/conditional, not externally
  validated.

Significance calibration:
- Do not claim the cycle discovers finite-dimensional von Neumann
  additivity violation, free-product Bell-fibre compression, or a
  same-channel Bell self-tensor mechanism. The 2026-09 source already proves
  the stronger near-one-bit all-order phenomenon in a real-orthogonal model;
  the 2026-10 source already gives a deterministic algebraic p=1 example.
- The defensible increment is narrower: an internally derived exact
  product-conjugate Bell quotient for complex U(N) tensor-leg branches, plus
  an explicit (astronomically large) finite Haar dimension/probability
  threshold for one p=1 witness under the stated free-radius and score
  estimates. This is a quantitative realization in a different ensemble
  and interface, not a stronger entropy phenomenon.
- Against arXiv:2610.06533, the cycle's displayed p=1 lower bound is only
  slightly above 1/1024 (0.001007 versus 0.0009766); both are lower bounds,
  so this is not an actual-gap ranking. Cycle 4 has a much smaller log input
  dimension than the explicit 37,608,898-qubit baseline, and a slightly
  larger output (260 versus 256), but gives up deterministic/algebraic
  specification and practical materialization. It cannot be described as
  an explicit construction or as an implementation improvement.
- Against arXiv:2609.18747, the cycle has a selected smaller output K=260
  than the cited K=320 finite-output example and a numeric Haar-U threshold,
  but it proves only a tiny p=1 gap and uses a different pair/flagged
  interface. The source has the stronger all-order, near-one-bit theorem.
- Historical priority beyond these two sources, correctness of the
  cycle's internal U(N) derivations, and external validation remain
  unresolved. No new novelty claim is made.

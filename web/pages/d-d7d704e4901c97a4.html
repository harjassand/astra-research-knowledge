# Cycle15 whole-proof Chu installer

The compact whole-proof installer is implemented and has an independent
data-only gate. It validates complete canonical LLW-Frege proofs, checks
standard fresh definitional extensions, unfolds them through explicit ordinary
source derivations, memoizes genuine Pair proofs, wires every actual template
input to an earlier endpoint, and checks the entire resulting ordinary ILLW
proof with no named initial sequents. This completes the mixed-proof execution
promised by cycle14. It does not acquire hard-family source proofs or supply
a new general classical Frege/EF lower bound.

`notes/handoff_sol_max_check/cycle15/WHOLE_PROOF_COMPOSITION_AND_COST.md`;

## General composition and exact acquisition cost

Source validation is complete for the specified closed canonical API. It
checks all lines, including unused lines, rather than trusting named rules
or axiom endpoints. Definitions must be globally distinct, fresh in all
earlier actual formulas/operands and their own bodies, depend only on earlier
definitions, conclude the exact equivalence, and be absent from the final
target. Preallocated unused syntax atoms do not count as prior theorems.

Unfolding preserves every original endpoint. Each definition is replaced by
seven explicit canonical source lines proving `(F->F) AND(F->F)`. If the
original input has L lines, d definitions and V supplied constructor nodes,
the resulting ordinary source has exactly `L_e=L+6d` lines and at most
`m_e=V+5d+1` common nodes. Installed inputs are actual earlier Pair or closed
theorem endpoints, classified by exact sequent and never treated as axioms.

The universal target occurrence bound is

    13m_e + 93L_e <= 13V + 93L + 623d + 13.

The mathematical proof is source induction plus uniform substitution in the
fixed26 templates. All resource multiplicities and exponential side conditions
are preserved. The finite full proof execution checks the actual installation
and its final goal; it is not a replacement for that universal derivation.

The input proof and prior template library are supplied. Shortest-proof search,
a general conservative repair installer, a sequent-to-Frege compiler and
controlled-contraction witnesses are not supplied here. Those remain separate
interfaces. No optimization oracle, floating arithmetic or rational denominator
is hidden in the implementation; references and exact tree-count integers have
their full polynomial bit costs charged.

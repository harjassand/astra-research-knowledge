STRONGEST CONCRETE RESULT
The two-measure exact-once theorem yields a conditional FPRAS for the full thermal trace of easy-plane XXZ interactions with arbitrary Z fields and nonnegative X fields, on arbitrary graphs. It also gives a FULL relative-error FPRAS for their largest eigenvalue, polynomial in binary coefficient length without requiring bounded numerical coupling scale (Section 4c). The gate/trace reduction below is explicit, rational, and has multiplicative error without inverse partition-function dependence. This extends the named source C.17 EPR application, but novelty is not established. Separately, an exact six-variable cubic disproves even homogeneous multiaffine log-concavity closure under full complement; this blocks a blanket equality-tensor transfer.

1. EXACT HAMILTONIAN INTERFACE
Let G=(V,E) be any finite loopless multigraph, with n qubits. Given binary rational coefficients,

 H = sum_{e=uv} [alpha_e (X_u X_v + Y_u Y_v) + gamma_e Z_u Z_v]
                  + sum_v [b_v X_v + c_v Z_v],

assume alpha_e >= |gamma_e|, b_v >= 0, and c_v arbitrary. Given rational beta>0 and 0<epsilon<=1, estimate

 Z_H(beta) = Tr exp(beta H)

with relative error epsilon and success probability at least 3/4, or amplify to 1-delta. The physical Hamiltonian is -H if using the conventional exp(-beta Hamiltonian) convention. No bipartition, planarity, degree, treewidth, or spectral-gap assumption is imposed.

Define r_v=|b_v|+|c_v|,
 C=3 sum_e alpha_e + sum_v r_v,
 D=2C,
 A_e=3 alpha_e I + alpha_e(XX+YY)+gamma_e ZZ,
 A_v=r_v I+b_v X+c_v Z.

Every A_i is real symmetric, positive semidefinite, and entrywise nonnegative. Indeed the edge eigenvalues are 3alpha+gamma (twice), 5alpha-gamma, alpha-gamma, so 0<=A_e and ||A_e||<=6alpha. The vertex eigenvalues are r +/- sqrt(b^2+c^2), so 0<=A_v and ||A_v||<=2r. Hence sum_i A_i=H+CI and sum_i ||A_i||<=D. C=0 is the trivial H=0 case, Z=2^n.

The algorithm has bit cost polynomial in the binary input length L, n, the NUMERICAL quantity beta D, epsilon^{-1}, and log(delta^{-1}), conditional on the every-execution rational-bit implementation asserted in Chen–Liu Remark A.4. It is not claimed polynomial in log(beta D). No exponentially long dense matrix is built.

2. RATIONAL LOCAL GATES AND LOG-CONCAVITY
For s>=0 use the rational matrix F_i=I+s A_i.

An edge gate in computational row/column order 00,01,10,11 is

 [ a 0 0 0 ]
 [ 0 b c 0 ]
 [ 0 c b 0 ]
 [ 0 0 0 a ],

where a=1+s(3alpha+gamma), b=1+s(3alpha-gamma), c=2salpha. Keep the row bits, complement the column bits, and label row ends 1,2 and column ends 4,3. The associated half-edge polynomial is

 q=a(x1 x2+x3 x4)+b(x1 x3+x2 x4)+c(x1 x4+x2 x3).

Its Hessian eigenvalues are a+b+c, a-b-c, -a+b-c, -a-b+c. The triangle inequalities hold:
 a-b-c=2s(gamma-alpha)<=0,
 -a+b-c=-2s(gamma+alpha)<=0,
 -a-b+c=-2-4salpha<0.
Thus q has at most one positive Hessian eigenvalue, which is exactly the homogeneous nonnegative quadratic log-concavity criterion. This includes |gamma|=alpha and zero off-diagonal weight c=0.

For a vertex field gate, in row/column order 0,1,

 F=[1+s(r+c), sb; sb, 1+s(r-c)].

With x the complemented column half-edge and y the row half-edge, the polynomial is

 q=sb(1+xy)+[1+s(r+c)]x+[1+s(r-c)]y.

This polynomial is generally NONHOMOGENEOUS. Theorem 1.6 supplies its direct interface; Section 3a supplies an explicit homogeneous lift permitting Theorem 5.1 alone. For a,b,c,d>=0, p=a+bx+cy+dxy is log-concave on the positive quadrant iff ad<=2bc (assuming b,c>0, as here). Proof: the diagonal entries of Hess log p are nonpositive, its off-diagonal numerator is ad-bc, and its determinant numerator is
 (b+dy)^2(c+dx)^2-(ad-bc)^2.
This is nonnegative for all positive x,y iff |ad-bc|<=bc, equivalent to 0<=ad<=2bc.

For the displayed field q this condition is

 s^2 b_v^2 <= 2[(1+s r_v)^2-s^2 c_v^2],

which follows from r_v^2-c_v^2>=b_v^2. If b_v=0 the polynomial is positive linear and also log-concave. This explicitly handles arbitrary Z field signs and nonnegative X fields. It does not cover arbitrary signed X fields unless an additional legal sign gauge is provided.

3. TENSOR REDUCTION: ARBITRARY WIRE GRAPHS
For a finite ordered circuit of these one- and two-qubit gates, expand its trace. Every active qubit column end connects to the row end at its next occurrence, cyclically around the trace. An isolated qubit contributes a separate factor 2. A wire originally carries the same bit at both ends. After complementing its column end only, exactly one endpoint carries bit 1.

Let U be the set of distinct half-edges and M=|U|/2 the number of wires. Write P(x)=product_t q_t(x_{legs(t)}). Its factors have disjoint variables, are multiaffine, have nonnegative rational coefficients, and are log-concave, so P is multiaffine and log-concave. Its coefficient oracle is product_t f_t(S intersect legs(t)); this takes one local table lookup per gate, with polynomial rational arithmetic. A positive support seed is obtained by selecting a diagonal entry at every local gate, independent of whether these choices already match along wires.

Set Q(x)=product_{wire {h,h'}}(x_h+x_h'). This is the basis polynomial of a rank-M partition matroid on U, which is its own dual because each block has size 2 and rank 1. Q is homogeneous, nonnegative, stable and log-concave; its coefficient range is 1 and a support seed is explicit.

Exactly once on each wire is enforced by

 Tr(circuit) = 2^{#isolated qubits} [x^U] P(x)Q(x).

Each contributing monomial of P selects one endpoint of every wire; Q selects its complement. The transformation is bijective with the original equality-wire assignments and preserves every local table entry. This needs no bipartition of the tensor graph because the row/column structure supplies a verified local flip pattern. Nonhomogeneous factors are allowed. If one instead invokes homogeneous Theorem 5.1, Lemma A.3 permits taking the degree-M part of P, but support initialization/layer extraction then must follow the source reductions.

Only the gate list, wiring, coefficient oracle, support seeds, and coefficient-range bound are built. A gate coefficient is rational with bit length O(L+log m+bitlength(beta)) (without treating log beta as possibly negative). If B0 bounds this length, each nonzero coefficient of P is between 2^{-O(T B0)} and 2^{O(T B0)} for T gates, so log R_P=O(T B0). This is a supplied/acquired bound, not an assumed unknown minimum. Theorem 1.6 costs at most soft-O(N^11(N+log R_P)^2 epsilon^{-2}) arithmetic operations and oracle calls, N=|U|, before bit/oracle costs and success amplification. It is a very high polynomial, not a practicality claim.

3a. DIRECT HOMOGENEOUS FIELD LIFT (independently found by soft_intersection_transfer)
The field polynomial actually satisfies the stronger stable inequality d^2<=uv, where d=sb_v, u=1+s(r_v+c_v), v=1+s(r_v-c_v). Introduce two new dummy variables z1,z2 and use

 F=d z1z2+(u/2)x(z1+z2)+(v/2)y(z1+z2)+dxy.

F is homogeneous quadratic and multiaffine, with F(x,y,1,1)=q(x,y). For d>0 its Hessian leading determinants, in order x,y,z1,z2, are -d^2, d u v/2, d^2(d^2-uv); hence it has at most one positive eigenvalue and is log-concave. Alternatively the geometric means of opposite pairs are d,sqrt(uv)/2,sqrt(uv)/2, whose triangle criterion is exactly d^2<=uv. For d=0, F=(z1+z2)(ux+vy)/2, a product of positive linear polynomials.

For a circuit with e two-qubit gates and f one-qubit gates (counting all repetitions), there are W=2e+f physical wires. Let Ptilde be the product of its unchanged pair polynomials and lifted field polynomials. It is homogeneous of degree 2e+2f. On the 2W physical half-edges plus the 2f dummy variables, let

 Qtilde = product_physical wires(x_h+x_h') * e_f(all 2f dummy variables),

where e_f is the elementary symmetric polynomial (e_0=1). Qtilde is a product of partition- and uniform-matroid basis polynomials, so homogeneous log-concave of degree W+f=2e+2f, and every positive coefficient is 1. The enlarged ground set has N=2W+2f=4e+4f variables, so the two degrees sum to N.

The coefficient [x^all]Ptilde Qtilde equals the original trace contraction. Qtilde enforces exactly one Ptilde half-edge per physical wire. These physical selections number W, so homogeneity forces exactly f selected dummy variables in Ptilde. For every such selection Qtilde has one complementary dummy monomial of coefficient 1. Summing dummy assignments sets every dummy variable to 1 and recovers the product of the original q factors. Crucially, dummy variables are not individually pinned; the global degree enforces their required total automatically.

Both coefficient oracles, support seeds, and range bounds are explicit with polynomial rational bit cost. Thus homogeneous Theorem 5.1 applies directly, at cost

 O(N^10 B^2 epsilon^{-2} log^2(2B/epsilon))

arithmetic operations/value-oracle calls ON EVERY EXECUTION, B=N+log R_Ptilde. This route avoids both the general homogeneous-component lemma and any unsupported claim that LC is closed under reciprocal.

4. MULTIPLICATIVE THERMAL APPROXIMATION — FULL EULER PROOF
Put tau=beta D, Q0=(H+CI)/D, and

 m=ceil max{1,4tau,20tau^2/epsilon},
 delta=tau/m<=1/4,
 s=beta/(2m)=delta/(2D),
 W=product_i (I+delta A_i/(2D)),
 B=WW^*= [product_i F_i][product_i reverse F_i].

The local matrices F_i are positive definite and satisfy F_i>=I. Thus W is invertible, its least singular value is at least 1, and B>=I. All noncommuting operators are handled by matrix norms; there is no scalar factorization of exp(sum A_i).

Let G_i=delta A_i/(2D), G=sum_i G_i=delta Q0/2, t=sum_i ||G_i||<=delta/2, and R=W-I-G. Expanding the ordered product and bounding each term by its norm gives

 ||R|| <= product_i(1+||G_i||)-1-sum_i||G_i||
       <= exp(t)-1-t <= (t^2/2)exp(t)
       <= (delta^2/8)exp(delta/2).

Also ||W-I||<=exp(t)-1. Therefore

 ||B-I-delta Q0||
 <=2||R||+||W-I||^2
 <=(delta^2/4)exp(delta/2)+(exp(delta/2)-1)^2.

Let E=B-I>=0. Since ||B||<=exp(2t)<=exp(delta), ||E||<=exp(delta)-1. For a scalar u>=0, 0<=u-log(1+u)<=u^2/2. Spectral calculus consequently yields

 ||log B-E|| <= ||E||^2/2 <= (exp(delta)-1)^2/2.

Combining,

 ||log B-delta Q0||
 <=(delta^2/4)exp(delta/2)+(exp(delta/2)-1)^2
                            +(exp(delta)-1)^2/2
 <=5delta^2 for 0<=delta<=1/4.

The final numerical inequality follows for example from exp(u)-1<=u exp(u): the coefficient is at most exp(1/8)/4+exp(1/4)/4+exp(1/2)/2<1.44<5. No imported product-formula black box is needed.

Hence ||m log B-beta(H+CI)||<=5tau^2/m<=epsilon/4. Both exponent matrices are Hermitian; the eigenvalue min-max principle pairs their ordered eigenvalues within epsilon/4. Exponentiating scalar eigenvalues and summing proves

 exp(-epsilon/4)Tr exp(beta(H+CI))
 <=Tr B^m<=exp(epsilon/4)Tr exp(beta(H+CI)).

Use the conditional coefficient FPRAS to approximate Tr B^m to relative epsilon/8, and compute exp(-beta C) to relative epsilon/8. Multiplying these rational approximations gives an upper ratio at most (1+epsilon/8)^2 exp(epsilon/4)<=exp(epsilon/2)<=1+epsilon and a lower ratio at least (1-epsilon/8)^2 exp(-epsilon/4)>=1-epsilon/2>=1-epsilon. This charges scalar exponential evaluation explicitly. Encoding the final value requires O(n+beta C+log epsilon^{-1}) bits at the asserted numerical-parameter cost.

The expanded trace uses 2m times the number of nonzero local terms as tensor nodes, with degree 2 or 4. Its size is polynomial in L,n,tau,epsilon^{-1}. There is no inverse Z, overlap, or rare-configuration probability in the imported count. The same trace bound with beta=O(n/eta) and fixed relative count accuracy gives an additive-eta approximation to lambda_max(H), hence the ground energy of -H, with polynomial numerical cost in C/eta. This is an energy/partition-function algorithm; no quantum Gibbs-state preparation is claimed.

4a. SCALE-INVARIANT GROUND-ENERGY CONSEQUENCE
Write Emax=lambda_max(H). For every beta>0,

 log Z_H(beta)/beta - n log 2/beta <= Emax <= log Z_H(beta)/beta.

Normalize by the exactly computable rational D=2C and choose beta D=8(n+1)/eta, for 0<eta<=1. Invoke the partition-function algorithm with constant relative accuracy (for example 1/4), and approximate its logarithm to constant additive accuracy. Both the n log 2/beta thermodynamic gap and the logarithm-estimation error are O(eta D); harmless constant-factor tightening gives error <=eta D. Runtime is polynomial in L,n,eta^{-1},log(delta^{-1}), even if the original coupling scale D is exponentially large in L: normalization makes the NUMERICAL beta D polynomial, while beta itself is a rational of polynomial bit length. Thus the normalized ground-energy approximation is scale invariant.

For polynomially bounded local coefficient norms, D is polynomially bounded in L,n. Set eta to the required inverse-polynomial physical energy tolerance divided by D. This gives a randomized polynomial-time algorithm for inverse-polynomial additive ground-energy estimation of -H, conditional on the imported counting theorem. Equivalently, the usual promise energy-decision problem for this exact bounded-norm cone is in BPP. This does not assert a ground-state preparation algorithm or a result for arbitrary stoquastic Hamiltonians.

4b. SIGNED GAUGE / BIPARTITE EXTENSION
The same result covers signed alpha_e and b_v whenever there are signs sigma_v in {+1,-1} satisfying

 sigma_u sigma_v alpha_e >=0 for every edge,
 sigma_v b_v >=0 for every vertex,
 |gamma_e|<=|alpha_e|.

Conjugate by product_{v:sigma_v=-1} Z_v. It changes X_v and Y_v by sigma_v while retaining Z_v. The resulting coefficients lie in the proved cone, and all spectra/thermal traces are unchanged. Such signs are acquired by signed-graph BFS: around each nonzero-edge cycle the product of alpha signs must be +1, and every nonzero b_v must be compatible with the propagated component sign. This test is polynomial and yields the actual gauge or rejects it. Merely having real signed coefficients is insufficient.

In particular, uniformly negative XY coefficients on a bipartite graph can be gauged positive by an alternating sigma; arbitrary longitudinal Z fields remain allowed. With no transverse X fields this covers bipartite easy-plane antiferromagnetic XXZ in the conventional -beta Hamiltonian convention. Transverse field signs must be compatible with the same alternating gauge; arbitrary independent signs cannot be silently added. A frustrated odd cycle of negative XY coefficients cannot be transformed by this diagonal sign gauge.

4c. RELATIVE LARGEST-EIGENVALUE FPRAS (independently found by xxz_thermal_audit)
Let A=sum_e alpha_e, B=sum_v b_v, T=sum_v|c_v|, so C=3A+B+T. The product state |+>^{tensor n} has energy A+B. A computational product state with Z_v=sign(c_v) has field energy T and edge energy at least -A, so Emax>=T-A. Therefore

 Emax>=max(A+B,T-A)
      >=(4/5)(A+B)+(1/5)(T-A)
      =(3A+4B+T)/5>=C/5.

The norm triangle bound gives Emax<=C. If C=0 return Emax=0; otherwise Emax is positive and within a fixed factor of the exact rational C. Choose rational beta=20(n+1)/(epsilon C), for which tau=beta D=40(n+1)/epsilon. Obtain a relative-1/4 partition-function estimate Zhat and compute log Zhat to, say, additive precision 1/4. The difference between log Zhat and log Z is less than 1 on the success event, so

 |(log Zhat)/beta-Emax| <= (n log 2+1)/beta
                             <=epsilon C/20<=epsilon Emax/4.

Further rational rounding of the energy estimate can spend the remaining margin. This is a full relative-epsilon FPRAS for Emax, with bit runtime polynomial in L,n,epsilon^{-1},log(delta^{-1}), with no numerical-coefficient restriction because beta was chosen inversely to C. It also estimates the magnitude of the negative ground energy of -H to relative error. The normalized additive/BPP consequence in Section 4a follows as well. Identity offsets are outside this relative objective unless explicitly tracked: an arbitrary added negative constant could destroy the lower bound, though additive energy estimation still applies.

5. GENERAL CONTRACTION AUDIT AND FATAL SCOPE LIMITS
The broader exact-once reduction is valid on any tensor graph: for local nonnegative rational f_v(A) whose multiaffine polynomials p_v are log-concave, product P=product_v p_v and partition-matroid Q above count Z_exact-once. Local support seeds and log coefficient ranges must be supplied or explicitly acquired. Nonzero local factors do not imply Z_exact-once>0. Loops are admissible at the tensor-interface level if their two endpoints are distinct half-edges, though translating them to graph-orientation conventions requires care.

Ordinary equality contraction is DIFFERENT. On a single edge with local polynomials 1+2x and 3+5y, equality contraction is 13 whereas exact-once contraction is 11. Its direct edge constraint polynomial is 1+xy, which is not log-concave. A bipartition permits complementing all legs on one side, but the transformed local polynomials must separately be log-concave. Partial leg flips on arbitrary graphs fail already for homogeneous stable p=x+y: flipping x gives 1+xy, and at x=y=1/2 the Hessian of its logarithm has positive curvature 24/25 along (1,1).

Even FULL complement of homogeneous multiaffine log-concave polynomials can fail. Let p be the cubic on x1,...,x6 with all 20 squarefree triples present. In lexicographic triple order
 123,124,125,126,134,135,136,145,146,156,
 234,235,236,245,246,256,345,346,356,456
assign coefficients
 1,2,1,3,3,4,4,2,2,3,2,1,2,2,3,3,3,4,4,3.

Every derivative partial_i p is quadratic on the remaining five variables. Its leading principal determinants of orders 2,3,4,5 are respectively
 i=1: -1,12,-15,42;
 i=2: -1,8,-12,70;
 i=3: -1,12,-32,224;
 i=4: -4,24,-80,364;
 i=5: -1,8,-15,40;
 i=6: -9,48,-176,816.
The first 2x2 pivot has one positive and one negative eigenvalue; subsequent Schur pivots are all negative by determinant ratios. Hence each derivative Hessian has inertia (1+,4-). The support is the full rank-3 uniform matroid, so the Branden–Huh Lorentzian criterion makes p Lorentzian and log-concave.

But p*(x)=x1...x6 p(1/x) has derivative partial_4 with Hessian, in remaining-variable order 1,2,3,5,6,
 [[0,4,3,2,1],[4,0,3,4,4],[3,3,0,3,1],
  [2,4,3,0,1],[1,4,1,1,0]].
Its leading determinants are -16,72,-252,-4, giving inertia (2+,3-). Thus partial_4 p* is not log-concave. Multiaffine log-concave polynomials retain log-concavity under partial differentiation, by the limit partial_i f=lim_{t->infinity} f(x_i=t)/t. Therefore p* itself is not log-concave. These are exact integer certificates, not merely numerical eigenvalues.
An explicit full-polynomial positive-point witness is x=(1,1,1,1000,1,1), direction v=(25,-23,41,0,25,-81): v^T Hess log(p*)(x) v=286483357/169338169>0. More generally the directional Hessian numerator at x4=t is 2700t^2-1552496t-1570572, while p*(x)=26t+26.

A universally nonnegative 2x2 gauge cannot automatically evade these obstructions: if a nonnegative invertible A has nonnegative inverse, A is positive diagonal or positive anti-diagonal (inspect the inverse formula). Thus universal positivity-preserving gauges are permutations and positive rescalings; class-specific holographic transforms require a separate positivity and log-concavity argument.

6. HARDNESS AND PRIOR-ART FILTERS
Six-vertex: source C.16 already proves the full symmetric triangle region on arbitrary loopless 4-regular multigraphs. Its quadratic Hessian criterion exactly rejects the ordered regions, where Cai–Liu–Lu prove approximation hardness unless NP=RP. Therefore a claim covering all positive six-vertex triples would be false without a complexity collapse. The present XXZ gates remain inside the admissible region. Generic positive nonsymmetric six-weight quadratics are LC precisely when the geometric means of opposite pairs form a triangle; diagonal variable scaling balances opposite coefficients to sqrt(w12*w34),sqrt(w13*w24),sqrt(w14*w23). This gives a routine conditional asymmetric extension, not certified novelty.

Permanent: equality contraction of degree-1 local vertex polynomials on bipartite graphs counts nonnegative weighted perfect matchings. Their full complements are elementary-symmetric stable polynomials, so the legal transfer recovers the known Jerrum–Sinclair–Vigoda FPRAS. Exact #P-hardness is no contradiction to an approximation theorem. Ordinary nonbipartite equality contractions cannot be included by the bipartition argument; any claimed general perfect-matching extension needs an independent legal gauge/reduction.

Independent sets: the incidence factor graph has edge factor 1+x+y (LC), but a degree-d site needs a COPY signature 1+lambda product_{i=1}^d x_i, which is not LC for d>=2. For d=2 the bivariate condition already fails (linear coefficients zero). Thus the transfer does not give an FPRAS above the Sly–Sun hard-core nonuniqueness threshold. Dropping local LC would cross this known hardness barrier.

Matchgates/BCS: a positive two-mode pair tensor has polynomial 1+a x1 x2, which fails LC. Two independent pair tensors give (1+a x1x2)(1+b x3x4), also failing LC; fixed-particle quadratic a x1x2+b x3x4 has two positive Hessian eigenvalues. Generic matchgate/fermionic Gaussian tensors are consequently outside this class. Bravyi's planar/Pfaffian and genus-dependent algorithms are different mechanisms, not a width-free all-graph counterexample to the LC criterion.

Prior named quantum algorithms: Bravyi–Gosset arXiv:1612.05602 covers ferromagnetic XY/Ising with transverse fields. Its Eq. 1 is written as sum_{ij}[-b_ij XX+c_ij YY]+sum_i d_i(I+Z_i), with |c_ij|<=b_ij, and has no ZZ interaction; alternate field-axis descriptions require an accompanying global axis rotation. A genuine gamma!=0 edge in the present cone has interaction matrix rank 3, so local product-unitary changes cannot map that edge into the BG rank-at-most-2 interaction class. Harrow–Mehraban–Soleimanifar arXiv:1910.09071 Theorem 50 has a quasipolynomial ferromagnetic XXZ regime Jzz>=|Jxy| with uniform constant longitudinal field and no independent transverse field. The present mixed-sign |gamma|<=alpha region and arbitrary longitudinal/nonnegative transverse fields extends those named interfaces, but broader priority is unresolved. The source C.17 EPR point gamma=-alpha is already in Chen–Liu and is not our novelty.

1. ACTUAL FINITE EB LIFT WITH AN EXPLICIT MODULUS AND ACQUISITION COST

For a finite tracial algebra and any bistochastic CP map T, suppose its
entire Hermitian input unit-ball image has an epsilon-accurate generator
description T(A)=aI+sum_(i=1)^k c_i B_i+remainder, with Hermitian contraction
generators, sum|c_i|<=K, and pair commutator L2 bounds <=delta. Then one
finite diagonal conditional expectation P_D gives the actual EB channel
E=P_D T satisfying

  ||E-T||_(infty->normalized L1, Hermitian) <=epsilon+K F_k(delta),

where F_1=0 and

  t=((k-1)delta)^(1/3),
  F_k(delta)=min{1,sqrt[t^2+F_(k-1)(min{2,delta+4t})^2]}.

For fixed k, this tends to zero independently of Hilbert dimension, trace
block weights, number of states or spectral gaps. Full derivation is in
INITIAL.txt sections1-3. The construction uses random shifted spectral bins,
one minimizing shift, compressed remaining generators, and recursively
refined pinching. It retains CP by composing with the supplied T rather
than modifying its matrix coefficients independently. The EB effects are
T_dagger(Q_z) and the prepared likelihoods are Q_z/tau(Q_z).

Corollaries: real range rank r gives an existential coefficient budget r;
an acquired rational-net maximum-volume frame has budget <=2r. A supplied
cover of N image points gives error epsilon+F_N(delta). Apply the baseline
power-range bound delta_m<=2/sqrt(m+1)+4/(m+1) to get vanishing EB error for
bounded-rank or suitably bounded-cover subclasses. This does not control
arbitrary growing rank/cover; F_5(10^-12)=1 in the direct recurrence.

Costed acquisition: an exact full matrix-output oracle takes a^2 public
Hermitian queries to acquire T:M_a->M_b. Choi/unital/trace equations are
checked. A computed nonzero minor mu selects rational zeta, and an input
zeta-net with M<=(1+8a/zeta)^(a^2) points is enumerated. Searching M^r tuples
acquires the frame. This is finite but exponential and NOT executed. Supplied
frame pinching has O(k^2 D^3) dense real-arithmetic work, not a claimed
polynomial bit algorithm. A finite algebraic polar-unitary net supplies
a gap-independent exhaustive precision fallback with search space
(1+16D/eta)^(2D^2), extra error <=8K eta. It too was not implemented as a
certified engine. Generic physical POVM/preparation costs and expanded

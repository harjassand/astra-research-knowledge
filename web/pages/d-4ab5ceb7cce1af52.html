# A limited novelty cone is not full theorem-library entailment

Code evidence: AutoGraphForge commit `510cf50083d2a2a481499e296383246d1587c029`, committer date 2026-09-13T12:59:31Z. Saved source `repo_pipeline__novelty.py`: `classify` selects only trusted relations with the same left-hand invariant as the candidate; `_convex_implies` uses a convex combination plus nonnegative coordinate lower bounds and class identities. `_transitive_theorems` closes only single-term coefficient-one zero-offset chains. The code explicitly intends conservative false-negative novelty behavior. This note concerns that mathematical limitation, not a newly discovered unsoundness bug.

Exact counterexample to completeness of that restricted certificate system: a library contains f<=g+h, g<=u, h<=v on nonnegative variables, with no equality identities. The candidate f<=u+v is an immediate consequence: sum the three affine inequalities with weights 1. Yet the candidate's same-target family contains only f<=g+h. Its convex weight is forced to 1, and the proposed residual u+v-g-h has negative g/h coefficients, so it cannot be a nonnegative combination of coordinate lower bounds plus nonnegative constant slack. Pure single-term transitive closure does not fix this multi-term example.

The general prior-art remedy is Farkas implication over the whole class-safe library. For nonempty P={x:Ax<=b, Ex=h}, c.x<=d holds for all x in P exactly when there exist lambda>=0 and unrestricted mu such that A^T lambda+E^T mu=c and b^T lambda+h^T mu<=d. A contradiction in the library makes P empty, so feasibility must be diagnosed first. Rational coefficients and exact rational verification can separate a solver's proposed certificate from its numerical status. `linear_certificate.py` verifies the displayed toy certificate exactly.

This is complete only relative to the encoded real polyhedron. A non-entailment witness x may be an unrealizable graph-invariant vector; therefore it certifies incomplete knowledge, not falsity of a graph theorem. Integer/parity constraints, floor/ceiling rules, nonlinear relationships, graph-realizability restrictions and unlisted literature remain outside a basic real LP. The fractional-annihilation continuation uses rounding and an extreme-point structural theorem, illustrating precisely such extra proof content.

Concrete research use: require every `known` flag to carry a reviewable trusted-library derivation, and report every unresolved candidate as library-unentailed, rather than globally novel. The scientific bottleneck is acquisition/validation of the trusted library, representation and structural lemmas. Completing an LP implementation alone is infrastructure, not a scientific discovery.

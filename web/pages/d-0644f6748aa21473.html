# Failure ledger and restart gates — cycle 9 deeper attack

## Failed, corrected, or bounded claims

1. **The released model uses the pulled Fisher minimum.** Rejected for the source seed. In the frozen A-homeostatic scalar reduction, `q₀/q*=0.0865`, so the simulator’s `aφ=4` initialization is on the shallow-tail branch. Classical KPP selection is prior art; this is only a source-parameter audit.

2. **The finite solver replay remained unverified.** Resolved for the published baseline. The independent centered-space/forward-Euler implementation reproduces the pinned `φ`, `ρ`, and `V` matrices to roundoff and the `φ=0.5` OLS front speed converges from `Nx=200` to `Nx=3200`. This is exact replay of one numerical model configuration, not external validation or proof about living skull tissue.

3. **An OLS front speed minus an unweighted mean `V` established negative material-frame propagation.** Withdrawn. The steep seed runs accelerate and OLS weights time differently from the mean flow. The corrected measure uses a front secant minus the time integral of local Eulerian `V` along the same moving level. On this matched estimand the speed remains positive through `aφ=80` and approaches zero only for much steeper seeds.

4. **The source scalar KPP comparator fails for steep seeds.** Mostly rejected after correcting estimands. With matched end-to-end front secants and matched integrated velocity/density drift, full-minus-scalar differences stay below about `1.2 μm/h` through `aφ=80` at `Nx=1600`; a refined `Nx=3200` `aφ=80` case differs by about `0.63 μm/h`. For `aφ=100–120`, discrepancies grow to about `1.3–1.9 μm/h`. This supports a conditional model comparator, not a universal propagation law.

5. **One source-model front speed uniquely identifies stiffness-sensitivity `α`.** Rejected across the source model family when initial profile steepness is not separately fixed. At `Nx=3200,Nt=25600`, `(aρ=aφ=4, α=3.5×10⁻⁶)` and `(aρ=aφ=8, α=1.934×10⁻⁶)` give `φ=0.5` secants differing by only `0.00079 μm/h`. Their Eulerian velocities and initial profiles differ, so other measurements can distinguish them. This does not refute the article’s joint fit with its fixed profile and additional data.

6. **The profile-steepness sign change is a biological switch.** Not supported. For the finite PDE discretization, matched front-relative rates bracket a 0–8 h zero around `aφ∈[115,116]`, but the 6–8 h sign is already negative near `aφ=110`; the inferred crossing depends on the time window. At `aφ≈115`, the initial exponential length is `6.5 μm`, below the density-derived characteristic cell spacing `11–12 μm` and unresolved by the published `15 μm` grid. No continuum-based tissue-control threshold is established.

7. **The Supplement parameter table and executed notebook specify identical viscosity.** Source mismatch. Supplement Table S1 prints `η=10⁴ Pa·s`; the pinned notebook sets `η=10³ Pa·s` before unit conversion. The released matrices match the notebook value. Using the tabulated value changes the baseline output only slightly, but author intent and other-regime effects are unresolved.

8. **The released notebook shift residual measures L1 shape error.** Rejected. The source takes an absolute value after a signed spatial sum. On this output the L1 minimizer happens to be the same shift, but its residual (`0.41495`) differs from the reported signed-mass residual (`0.03728`).

9. **The coupled skull model validates the 2026 Drosophila Fog relay.** Rejected. It is a different tissue and model class. The 2026 Fog source still does not jointly identify receptor mobility, contact-age response, adhesion state, and active force in a moving embryo.

## Restart gates

### Gate 1 — numerical model scope

The source baseline has passed exact discrete replay and base-profile grid/time refinement. Resume high-steepness claims only with refinement at the intervention scale, predeclared front estimands, and matched-time material-flow integration. Report OLS, secant, and window-specific estimates separately when profiles accelerate.

**Pass:** the same parameter-specific conclusion survives at least two further spatial/time refinements and the declared front estimand is stable over a stated window.  
**Fail/demote:** high-slope zero crossings or speed corrections move with mesh/time or fit window; retain only a finite-grid diagnostic.

### Gate 2 — identify `α` and transport in the living system

Acquire the initial front profile/tail, the same-condition front trajectory, local material/cell velocities, and matched stiffness/density profile. Fit `α` using one condition, then test a second condition with the same predeclared front and velocity observables. For the original Fog relay, also acquire cell-contact age, Fog-pool identity/mobility/clearance, active integrin, and cell-linked detachment/force measures.

**Pass:** the model predicts held-out profile and velocity data better than the equally informed contact-age/active-flux/mechanical-relay alternatives, with uncertainty at the embryo level.  
**Fail/demote:** profile steepness and `α` remain confounded, measured flow absorbs the apparent wave speed, or a local-response model predicts equally well; do not call a speed inversion a tissue parameter estimate.

### Gate 3 — respect the cell-scale boundary

Do not tune a continuum tail profile to lengths below the independently measured cell scale or below a numerically resolved scale. The current source uses a 15 μm grid and the pulled scalar length is about 16.2 μm; the finite solver stall bracket uses a 6.5 μm seed length.

**Pass:** direct tissue profiles and an appropriately cell-resolved model support a stable window-independent control boundary above the cell-scale limit.  
**Fail/stop:** the crossing remains subcellular or moves with time window/grid; stop the proposed profile-steepening design route.

## Cost and stop condition

The replay costs local Python/NumPy, with sub-second source-grid execution and tens of seconds for high-resolution discrete force solves. No new experiment, wet-lab work, or external review was performed. Biological continuation needs live profiles, matched material-frame motion, validated stiffness/density inputs, and held-out perturbations; source papers do not provide defensible animal count, imaging time, currency, or energetic costs for that acquisition.

Stop any biological threshold claim if profile steepness, matched flow, or a held-out speed is not acquired. The supported state is an exact source-model replay, conditional scalar comparison, speed-only parameter non-identifiability within the model family, and `UNKNOWN` for the biological control law.

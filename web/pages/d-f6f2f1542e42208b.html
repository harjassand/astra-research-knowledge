STATUS: internally derived exact representation and entropy estimate. The full

1. EXACT TARGET AND SIGN CONVENTIONS

Consider the quasi-static logarithmic aging-law rate-and-state model with fixed
positive spatial coefficients a,b,D=D_c,sigma, zero external stressing rate, and
nonlocal half-space stiffness K=-L. For a one-dimensional anti-plane fault,
K=kappa|partial_x|, kappa=mu/2, acting on displacement/slip-rate extended by zero
outside the physical fault Omega. Variable D is allowed in the representation.
The physical dynamical equations are

  V_t/V = -K[V]/(sigma a)+(b/a)(V/D-1/theta),
  theta_t=1-(V/D)theta.

This is the full aging-law memory, not a steady-sliding stiffness approximation.
No inertia, radiation damping, evolving normal stress, thermal weakening, or
pore-pressure law is included. The requested target is a continuum attracting
compact blow-up profile with initial data not conditioned on a guessed blow-up
time, including perturbations whose support differs from the limiting profile.

Write r=V/D, u=1/theta, c=sigma a D, B=sigma b D,
H=DKD-B and h[f]=<Df,KDf>-int B f^2. Then exactly

  r_t=-(r/c)(Hr+B u),   u_t=u(r-u).

2. PHYSICAL AMPLITUDE CLOCK AND MEMORY REPRESENTATION

Define rho=int c r>0, q=r/rho, y=u/rho and tau by d tau/dt=rho.
Thus int c q=1. The clock tau is determined by physical initial data; no future
time T occurs in these definitions. Set I=int B q y. A direct differentiation
gives

  lambda=-h[q]-I,
  q_tau=-(q/c)(Hq+c lambda+B y),
  y_tau=y(q-y-lambda),
  rho_tau=rho lambda,   t_tau=1/rho.                         (2.1)

The identity int c q_tau=0 follows from int c q=1 and the definition of lambda.
The memory variable y=qZ=1/(rho theta), with Z=D/(V theta), removes the
nonlocal elastic operator from the memory evolution. It is regular where the
limiting q profile vanishes. Both q and y preserve nonnegativity for strong
solutions because their equations are multiplicative. This preservation also
means exact support cannot expand at finite time from exactly zero q; compact
moving support is a limiting-profile/free-boundary question, not a literal
finite-time propagation assertion for positive physical slip rates.

3. A COMPACT OBSTACLE EQUILIBRIUM AND FULL-DOMAIN COERCIVITY

Let q_*>=0, int c q_*=1, lambda_*>0, and

  g=Hq_*+c lambda_*>=0,   g q_*=0.                           (3.1)

Then h[q_*]=-lambda_*. Equilibrium physical profile is W_*=q_*/lambda_*.
All-W<1 means delta_*=lambda_*-ess sup q_*>0. The obstacle relation imposes
the profile equation on its active set and the restoring invasion inequality
on its exterior. It does not prescribe the active set for the dynamics.

The substantive coercivity hypothesis for the entropy theorem below is

  h[v]>=eta ||v||_2^2 for every form-domain v with int c v=0, eta>0. (3.2)

This concerns the FULL physical domain, including perturbations positive in
the equilibrium exterior. It is stronger than a fixed-active-set index-one
count and will be constructed explicitly below. Heterogeneity pins position;
translation is not silently removed.

For v=q-q_*, define A=int g q>=0 and L=int B y>=0. Mass normalization gives

  <q_*,Hv>=int g q=A,
  h[q]=-lambda_*+2A+h[v],
  lambda=lambda_*-h[v]-2A-I.                               (3.3)

4. AN EXACT COUPLED ENTROPY IDENTITY

For nonnegative q with finite relative entropy and positive q wherever q_*>0,
put

  D_*(q)=int c {q_* log(q_*/q)+q-q_*},
  F(q,y)=D_*(q)+int B y.                                  (4.1)

The convention 0 log(0/q)=0 is used. The linear terms integrate to zero because
both profiles have mass one. This is reverse relative entropy of q against
q_*, not a KL functional with a zero reference state for memory.

Differentiating (4.1) using (2.1) gives

  D_*'=<q_*,Hq>+lambda+int B q_* y
       =-h[v]-A-int B v y,
  L'=int B v y-int B {(lambda-q_*)y+y^2},

and the coupling cancels exactly:

  F'=-h[v]-A-int B {(lambda-q_*)y+y^2}.                    (4.2)

This cancellation is the central new object. The original Z equation contains
the nonlocal elastic stress and no gap on the far exterior. y instead has a
uniform equilibrium memory gap delta_* across the entire bounded fault if
W_*<1. Importantly, we do NOT assume that gap remains valid along the solution.

Let Q=ess sup q_*, 0<B_min<=B<=B_max<infinity, and Y2=int B y^2.
Since I=int B qy=int B q_*y+int B v y,

  F'=-(1-L)h[v]-(1-2L)A-delta_* L
      +Q L^2+L int B v y-Y2,                              (4.3)

where replacing int B(lambda_*-q_*)y by delta_* L only weakens the equality
to <=. By Cauchy and Young,

  L |int B v y| <= (eta/4)||v||_2^2
                  +(B_max^2 L^2/(eta B_min))Y2.

Choose any ell_0>0 satisfying

  ell_0<=1/4,
  Q ell_0<=delta_*/2 (omit if Q=0),
  B_max^2 ell_0^2/(eta B_min)<=1/2.                        (4.4)

If F(0)<ell_0, then L<=F remains below ell_0 for as long as the strong solution
exists. Equations (3.2),(4.3),(4.4) prove

  F'<=-(1/2)h[v]-(1/2)A-(delta_*/2)L-(1/2)Y2.             (4.5)

Proof of the h coefficient: 1-L>=3/4, and the Young term eta||v||^2/4<=h[v]/4.
The A coefficient follows 1-2L>=1/2. The memory linear coefficient follows
Q L^2<=delta_* L/2. A first-exit argument proves invariance of F<ell_0.

Consequently, on any global tau solution obeying these identities,

  int_0^infinity {h[v]+A+L+Y2} d tau <= C F(0).            (4.6)

The constants are finite and explicit from eta,delta_*,B_min,B_max.
Moreover

  |I|<=Q L+(B_max/sqrt(B_min))||v||_2 sqrt(Y2),

so Cauchy in time and (3.2),(4.6) give

  int_0^infinity |lambda-lambda_*|d tau<infinity.          (4.7)

No pointwise bound lambda>=Q was assumed. High-frequency positive h[v] can
make lambda negative temporarily, but (4.3) absorbs that adverse memory term.

5. ACTUAL PHYSICAL BLOW-UP FROM THE CLOCK

Assuming a global tau solution, (4.7) gives

  rho(tau)=rho(0)exp(lambda_* tau+int_0^tau(lambda-lambda_*)d s),
  rho(tau)e^{-lambda_*tau}->rho_infinity in (0,infinity).

Thus T=t(0)+int_0^infinity d tau/rho(tau)<infinity, and

  (T-t(tau))rho(tau)->1/lambda_*.                         (5.1)

The latter follows dominated convergence after writing
rho(tau)int_tau^infinity rho(s)^{-1}ds and using the convergent integrated
lambda perturbation. If q(tau)->q_* in L2, then

  (T-t)V/D=(T-t)rho q ->q_*/lambda_*=W_* in L2.            (5.2)

Even without full-time convergence, (4.6) supplies subsequences and a vanishing
time-average L2 error. Those weaker statements are NOT an attracting-profile
theorem. The global-existence and actual-convergence gates are still open in
this v1 record.

The data condition F(q0,y0)<ell_0 is expressed entirely in physical initial
V0,theta0: rho0=int sigma a V0, q0=(V0/D)/rho0, y0=1/(rho0 theta0).
It requires positive finite theta0, finite entropy, and sufficiently old state
relative to the current amplitude. It does not specify or solve for T in advance.
It allows positive q0 throughout the equilibrium exterior; A controls this
support leakage. It cannot admit an exactly missing part of the positive
equilibrium support, because the reverse entropy would be infinite there.

6. EXPLICIT HETEROGENEOUS HALF-SPACE CANDIDATE

Take D=sigma=1, Omega=(-R,R), R>1, K=kappa|partial_x| with zero extension,
U(x)=(1-x^2)_+^(3/2), W_*=epsilon U, 0<epsilon<1,
H=K-beta kappa I, B=beta kappa. Direct Hilbert-transform integration gives

  KU=kappa(3/2-3x^2) for |x|<1,
  KU=kappa{3/2-3x^2+3|x|sqrt(x^2-1)} for |x|>1.           (6.1)

Set c=a=epsilon kappa {beta U+3x^2-3/2} on |x|<=1,
and c=epsilon kappa(3x^2-3/2) on 1<|x|<R. This is positive if beta>3/2:
on x^2<=1/2, the ratio (3/2-3x^2)/(1-x^2)^(3/2) decreases from 3/2;
on x^2>=1/2 positivity is immediate. It is continuous with a continuous first
derivative at |x|=1; its second derivative can have the allowed square-root
singularity. Then

  HW_*+c=0 inside |x|<1,
  G:=HW_*+c=3epsilon kappa |x|sqrt(x^2-1)>0 outside.       (6.2)

The support edge has W_*=O(distance^(3/2)), W_*'=0; it satisfies the published
nonsingular-tip condition. The exterior restoring residual is O(sqrt distance),
so the mobility-weighted half-space linearized problem need not have a gap.
The entropy proof deliberately avoids such a gap.

The profile normalization is C=int cW_*=-h[W_*]>0,
q_*=W_*/C and lambda_*=1/C. The gap is delta_*=(1-epsilon)/C>0.

Fourier bathtub inequality: for n orthonormal zero-extended eigenfunctions in
L2(-R,R), sum |hat phi_j(xi)|^2<=R/pi, int sum |hat phi_j|^2=n, and therefore
sum_{j<=n}lambda_j(K)>=kappa pi n^2/(4R). Hence
lambda_2(K)>=kappa pi/(2R). Direct integrals give

  int U KU=3pi kappa/8, int U^2=32/35,
  lambda_1(K)<=kappa(105pi/256)<(3/2)kappa.               (6.3)

If 3/2<beta<pi/(2R), H has exactly one negative eigenvalue. For R close enough
to one, G is small in L2 and c=-HW_*+G. Orthogonality <W_*,G>=0 gives

  <c,H^{-1}c>=h[W_*]+<G,H^{-1}G>.

Since h[W_*]=epsilon^2 kappa(3pi/8-beta 32/35)<0 and H^{-1} has a uniformly
bounded norm when beta stays separated from both lambda_1 and lambda_2,
the right-hand side is strictly negative for sufficiently small R-1. A
one-negative-direction quadratic form is then strictly positive on ker<c,.>.
An explicit eta bound and a detailed check of all form-domain statements are
requested from independent N25 support. This example fixes the material
domain Omega but does NOT fix the equilibrium active support (-1,1) in the
evolution; continuum perturbations throughout Omega are included in (3.2).

7. CONTINUUM GATES AND ALTERNATIVE EXISTENCE ROUTE

The constrained h form is convex on the affine mass hyperplane. This suggests
implicit mirror descent: minimize .5h[q]+int B q y_old+(1/dt)KL_c(q||q_old)
over q>=0,int cq=1. The Euler equation is log(q_new/q_old)/dt=-(Hq_new+B y_old)/c
-lambda_step. This is a concrete possible weak-solution construction, not
yet a proved existence theorem. The exact y ODE must be coupled and the
scheme's entropy bounds and compactness proved; a citation to ordinary
fractional porous-medium flow does not suffice, since q|D|q is a different
nonlinearity. Global classical regularity, possible concentration, strong
convergence, and support-edge regularity all require actual arguments.

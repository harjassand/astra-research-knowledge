1. Legal interface and exact model class
---------------------------------------
Fix q>=1. The learner is given q and ONE observed path x_1,...,x_n over
{0,1,...,q}, n>=1. Symbol 0 means no event; every nonzero symbol records an
event and its mark. Adjacent events and a repeated mark at successive events
are both allowed and both observed. There is no latent ambiguity about event
times or marks. In particular, this is not an assertion about a semi-Markov
state record in which a self-renewal has become invisible, nor about hidden
event marks or arbitrary HMM emissions.

After an event of mark i, the joint law of the positive integer distance g to
the next event and its mark d is p_i(g,d), with sum_{g>=1,d in[q]}p_i(g,d)=1.
Given the current event mark, this joint law is independent of the earlier
events. No factorization into a destination kernel times a gap law is assumed.
The q marked rows and q destinations are fixed; g is unbounded.

Use any stationary version of this Markov renewal law. More explicitly, let
P(i,d)=sum_g p_i(g,d), let pi be ANY stationary distribution of the finite
embedded chain, and assume only its weighted mean

  M=sum_i pi_i sum_{g,d} g p_i(g,d)<infinity.

No uniform bound on M is assumed. Irreducibility, mixing, aperiodicity, support
bounds, positive transition lower bounds and positive mass of every mark are
not required. States with pi_i=0 are irrelevant to the mean condition. Mixtures
of recurrent classes of ONE such kernel are included. Arbitrary mixtures of
different kernels are not inserted as an unstated enlargement of the class.

The stationary countdown/next-mark state Z_t=(r,d), r>=1,d in[q], emits mark d
at r=1 and then draws its next state (g,d') from p_d(g,d'); at r>1 it emits 0
and decrements r. Its stationary law is

  nu(r,d)=(1/M)sum_i pi_i sum_{g>=r}p_i(g,d).

This law is normalized, and nu(1,d)=pi_d/M by embedded stationarity. It gives
event intensity 1/M>0. Reducible embedded chains cause no change in the proof.
The identically zero law, or its mixture with a law of this ONE kernel, can
also be included by adding an absorbing countdown state infinity; this small
optional extension does not change any code or memory bound below.

Neither p, pi, M nor nu is supplied to the learner. The alphabet size q IS a
supplied fixed class parameter. The runtime exponent depends on q; there is
no claim of polynomial time jointly in n and an unbounded input q.

2. A proper code without endpoint or Euler-trail normalization
------------------------------------------------------------
Fix horizon N=n+1. A count pool is a vector of nonnegative integers
C_{i,d,g}, i,d in[q], 1<=g<=N-1, with total span and row totals

  S=sum_{i,d,g} g C_{i,d,g} <= N-1,
  R_i=sum_{d,g} C_{i,d,g}, R=sum_i R_i <= S.

Let p_{q^2}(s) be the q^2-colored integer partition count of s. There are
sum_{s=0}^{N-1}p_{q^2}(s) such pools, including the empty pool. Set

  K_N=1+sum_{s=0}^{N-1}p_{q^2}(s).

Choose uniformly among these pools and a separate allzero option. The latter
outputs 0^N. Conditional on a chosen pool C:

  (a) Choose an anchor a uniformly in {1,...,N-S} and a starting mark i
      uniformly in [q], independently. Record that event at position a.
  (b) If the current mark's remaining outgoing row is empty, STOP and emit
      zeros through position N. Unused pools in other rows are allowed.
  (c) Otherwise choose a remaining (destination d,gap g) in that row with
      probability equal to its multiplicity divided by the remaining row
      total. Remove one copy, record the next event g positions later with
      mark d, and repeat (b).

Each transition removes an item, so the process terminates after at most R
transitions. Its total used span is at most S; its final event is no later
than a+S<=N. Thus every choice outputs a legal length-N string and every row
choice is a probability distribution. This defines a proper Q_N, with no
rejection, no rare-success normalization and no Euler-trail count. Different
pools can generate the same string, which increases its mass and is allowed.

For every nonzero string x, take C(x) to be its ACTUAL complete gap/mark
transition counts, S(x) its first-to-last event span, and a(x) its first event.
Along that particular observed path every required draw is available. All of
C(x) is used at the last event, so its current row is empty and the urn stops.
Its path probability under that pool is exactly

  [q K_N(N-S)]^{-1} product_{i,d,g} C_{i,d,g}! / product_i R_i!.

The product follows by multiplying ordered draws in each row; visits to rows
can interleave, but their numerator multiplicities and denominator row totals
decrease in the same row-wise order. This is a LOWER BOUND on Q_N(x), since
other unused-pool histories may generate x too. When q=1 the sole row can
stop only when every item is used, recovering exactly the binary uniform
gap-type code and its type-class count.

3. Uniform pointwise domination and redundancy
---------------------------------------------
For a nonzero x with anchor a, first mark u, complete counts C and final zero
age b=N-last_event_position, the true stationary probability is

  P_N(x)=nu(a,u) product_{i,d,g}p_i(g,d)^{C_{i,d,g}}
           * sum_{g>b,d}p_lastmark(g,d).

The initial residual factor and final survival are each at most 1. For each
row i the multinomial probability

  [R_i!/product_{d,g}C_{i,d,g}!] product_{d,g}p_i(g,d)^{C_{i,d,g}}

is at most 1 (empty rows use the convention 0!=1). Combining all rows with
the exact-target-pool contribution above gives

  P_N(x)/Q_N(x) <= q K_N(N-S) <= q K_N N.

For 0^N the ratio is at most K_N. These bounds also survive the optional
allzero atom. Hence D(P_N||Q_N)<=log K_N+log q+log N, in natural logarithms.
No supplied mean or support enters the bound, and no truncation is imposed
on the true law; the code's finite pools are a computational device only.

The generating product for d=q^2 colors is
product_{g>=1}(1-exp(-beta g))^{-d}. For beta>0,

  log product=d sum_{k>=1}1/[k(exp(beta k)-1)] <= 2d/beta,
  sum_{s<N}p_d(s) <= exp(beta N+2d/beta).

Taking beta=sqrt(2d/N) yields log K_N<=log 2+2sqrt(2dN).
Thus the redundancy is O(q sqrt(N)+log(qN)). The ordinary colored-partition
integer DP computes K_N in polynomial time; its finite truncation is exact.

4. Exact prefix formula, including pools left unused
---------------------------------------------------
All marginals below belong to ONE FIXED horizon Q_N. The horizon family is
not presumed projective; shorter suffixes are interpreted as prefixes of Q_N.
For a prefix y of length t with events, define:

  a = first event position, ell = last observed mark, b = t-last position;
  c_{i,d,g} = counts of complete observed transitions;
  r_i = sum_{d,g}c_{i,d,g};
  W(C) = product_{i,d,g}(C_{i,d,g})_{c_{i,d,g}};
  D(C) = product_i(R_i)_{r_i};
  L(C) = sum_{d,g>b}(C_{ell,d,g}-c_{ell,d,g}).

Here (u)_v=u!/(u-v)! is a falling factorial. A pool contributes only if C>=c
coordinatewise and S<=N-a. Multiplying the observed ordered row draws gives
W(C)/D(C), regardless of how the rows' visits interleave. At the terminal
observed mark its residual row total is T=R_ell-r_ell.

  If T=0 the urn stops, so the tail of b zeros has probability 1.
  If T>0 the next event must be STRICTLY more than b positions away; its
  probability is L(C)/T.

Therefore the pool's prefix contribution is

  [q K_N(N-S)]^{-1} W(C)/D(C) * [1 if T=0, else L(C)/T].

Unused OTHER rows must NOT be required to be empty in the T=0 branch. An
observed path itself never requires Eulerian balance, connectivity or a fixed
endpoint for all of C: the code expressly allows resources it never visits.
Imposing such a test would change the code and invalidate this formula.

For the no-event prefix y=0^t, each pool allows (N-S-t)_+ anchors out of N-S;
the start mark and row draws have total mass 1 and occur after the prefix.
Thus

  q_N(0^t)=[1+sum_{S<N}p_{q^2}(S)(N-S-t)_+/(N-S)]/K_N.

The leading 1 is the allzero option. It gives q_N(empty)=1 and
q_N(0^N)=1/K_N. At t=N, a T>0 tail term is impossible: remaining total span
is at most b, so none of its items can have gap g>b. A T=0 term may still
have unused resources in other rows and must be retained.

5. Product-weight DP and a common integer denominator
----------------------------------------------------
For this prefix, sum product weights over pools with fixed (S,R_1,...,R_q):

  A(S,Rvec)=sum W(C), B(S,Rvec)=sum W(C)L(C).

Initialize A(0,0vec)=1 and B=0. Process each local coordinate (i,d,g), selecting
a multiplicity u>=c_{i,d,g}. Define w=(u)_{c_{i,d,g}} and
lambda=(u-c_{i,d,g}) if i=ell and g>b, otherwise lambda=0. Update

  A_new(S+gu,Rvec+u e_i)+=w A_old(S,Rvec),
  B_new(S+gu,Rvec+u e_i)+=w[B_old(S,Rvec)+lambda A_old(S,Rvec)].

Cap S at N-a. Each pool appears exactly once; local falling-factorial products
and the one additive tail statistic factor in this table. At the end, sum

  A/[(N-S) product_i(R_i)_{r_i}]                       if R_ell=r_ell,
  B/[(N-S) product_i(R_i)_{r_i}(R_ell-r_ell)]           otherwise,

and divide by q K_N. There is no path-history or item-order enumeration in the
compiler. The full observed path was already fixed by the input prefix.

Every denominator in the displayed final sum DIVIDES N!. In the T=0 branch
its row factors divide product_i R_i!. In the T>0 branch the last row factor
is (R_ell)_{r_ell+1}, which also divides R_ell!, and the other factors divide
their row factorials. Further product_i R_i! divides R! by multinomial
integrality. Since R<=S<N, (N-S)R! divides N!: N-S<=N-R and
N!/R!=binom(N,R)(N-R)!, so N-S divides N!/R!. By transitivity the claimed
denominator divides N!. For no-event prefixes N-S itself divides N!.

Consequently H_N(y)=q K_N N! q_N(y) is an integer for EVERY prefix y.
For event prefixes compute it using integer quotients N!/denominator; for
the no-event branch use the explicit formula times qN!. In particular
H_N(empty)=qK_NN!, and H_N(y)=sum_{v=0}^q H_N(yv). Q_N has full support: the
exact count pool supplies every nonzero string, and the allzero option handles
0^N. Therefore H_N(y)>0 for all y of length at most N.

The table has O(N^{q+1}) cells, O(q^2 N) local coordinates and at most N
multiplicity choices, so a conservative marginal cost is O(q^2 N^{q+3})
integer operations. W<=N^{sum r_i} and the number of partial pools is bounded
by the number of full pools. Thus table entries, with the marked statistic
bounded by N, have O(N log(N+1)+q sqrt(N)+log(q+1)) bits. H_N(y)<=qK_NN!
has the same bit order. For FIXED q this is O(N log(N+1)).

With schoolbook integer arithmetic the conservative per-marginal bit cost is
O_q(N^{q+5} log^2(N+1)); table memory is O_q(N^{q+2} log(N+1)) bits. These are
charged polynomial bounds, not a practical speed claim. The exponent depends
on the fixed mark count, and the dependence has not been optimized.

6. Terminal predictor and arbitrary-mean memory bound
----------------------------------------------------
For t=1,...,n let z_t be the LAST t observed symbols. In the same fixed Q_N,
compute the categorical vector

  Q_N(v|z_t)=H_N(z_t v)/H_N(z_t), v=0,...,q.

Output their arithmetic average. It is a proper rational prediction, computed
using O_q(n) prefix marginal calls. Exact addition can create O_q(n^2 log n)
output bits, even though each individual ratio has only O_q(n log n) bits.
The conservative total bit cost O_q(n^{q+6}log^2(n+2)) charges these calls and
the exact average. No approximate oracle or hidden rare-probability division
cost is omitted.

For any stationary source, convexity of KL in its second argument and adding
and subtracting the true suffix conditional give risk at most

  [D(P_N||Q_N)+sum_{t=1}^n
     I(X_N; X^{n-t} | X_{n-t+1}^n)]/n.

Stationarity identifies the code terms with Q_N's sequential KL contributions;
their sum omits only the nonnegative first-symbol term. This holds for the
finite categorical alphabet, with exactly the same argument as the binary
compression-to-prediction proposition. No projective family is required.

The stationary countdown Markov representation gives conditional DPI

  I(X^{n-t};X_N|X_{n-t+1}^n)
    <=I(Z_{n-t+1};X_N|X_{n-t+1}^n)
     =I(Z_1;X_{t+1}|X^t).

Summing and using the chain rule bounds the memory sum by I(Z_1;X^N).
Replace Z_1 by its exact (r,d) when 1<=r<=N and by one sentinel when r>N.
There are qN+1 values. In the sentinel case the whole block is zero; in every
other case its first event time/mark is retained and later events regenerate
through p. Hence X^N is independent of Z_1 conditional on the capped state,
and I(Z_1;X^N)<=log(qN+1). An optional infinity atom joins the same sentinel.
This proof never assumes finite entropy of the uncapped countdown state and
never subtracts infinite hidden-state entropies.

Combining all bounds, uniformly over every law in Section 1,

  E KL(P(X_{n+1}|X^n)||qhat_n(.|X^n))
    <= [log2+2q sqrt(2(n+1))+log q+log(n+1)+log(q(n+1)+1)]/n.

Thus for every fixed q the rate is O(n^{-1/2}) with polynomial bit time.
The class contains the binary stationary renewal subclass supported on
marks {0,1}, so the source-established HJW binary lower bound transfers by
categorical KL data processing. This gives the same minimax order for each
fixed q; no sharp q-dependence or leading-constant assertion follows.

7. Compiler principle and fixed allowed event graphs
---------------------------------------------------
The reusable algebraic mechanism is a finite collection of outgoing rows,
positive integer-cost items labelled by destination, a pool prior depending
on total cost, and stopping on an empty current row. An observed prefix fixes
the ordered item labels it used. Its weight is a product of local falling
factorials divided by falling factorials of aggregate row totals. A terminal
admissibility test on the next item contributes one additive moment. Tracking
total cost, one total per row and that marked moment compiles the prefix sum
exactly by the displayed DP. Endpoint/connectivity constraints on all items
are unnecessary because unused items are legal under the normalized code.

For a supplied fixed directed graph E of allowed marked transitions, restrict
pool coordinates to (i,d) in E. There are |E| colors in the partition bound,
giving logK<=log2+2sqrt(2|E|N), and the same q-row DP/denominator proof. The
predictor can then be defined on legal-support inputs, with any proper fallback
on impossible histories. For full support on all inputs, retain all q^2 colors
as in the main theorem; true zero transition probabilities cause no difficulty.
This graph compiler is conditional on observable item labels and fixed rows;
it does not supply a compiler for unobserved states, arbitrary automaton
emissions, arbitrary endpoint-conditioned target laws, or growing row count.

8. Independent finite diagnostics and decisive guards
----------------------------------------------------
check.py uses only standard-library Fraction and integers. Its reference
enumerates every pool and every row-urn path, recording paths that terminate
with unused pools; it then sums full block probabilities into prefix marginals.
The independent DP sums product weights over (S,Rvec), imports no root or other
worker checker, and multiplies exact integer N!/denominator quotients.

For q=1,N=1..8; q=2,N=1..6; q=3,N=1..4 it passed:
  * 3,099 exact prefix equalities;
  * 1,157 categorical parent/children normalization identities;
  * 6,578 stationary-law pointwise regret checks.

Fixtures include deterministic mark cycles, reducible mark kernels with a
stationary mixture, duration/destination dependence, rare transitions, and gaps
of length 200 beyond every checked horizon. True block distributions normalize
exactly. For q>1 many reference paths do stop with unused pools (e.g. 1,376
path branches at q=2,N=6), so this essential branch is explicitly exercised.
These finite tests support the formula; the all-N proof above carries the
theorem. Neither is external validation.

Decisive implementation falsifiers: require all pools to be consumed; require
Eulerian balance/connectivity of unused pools; count event marks as latent;
replace strict g>b by g>=b; omit S<=N-a; treat self-renewals as invisible;
use different Q_{t+1} codes for suffixes; ignore the no-event prefix; or charge
only O(n log n) bits for the exact averaged output. None is used in the code.

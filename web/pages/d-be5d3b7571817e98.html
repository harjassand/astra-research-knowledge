## Strongest claim

An explicit rational bimolecular population network admits a common exponential Foster certificate under arbitrary predictable, history-dependent rate control. That acquired certificate implies a uniform expected return-time bound to a finite recovery set and an a-priori finite-state cutoff for every bounded finite-horizon path property. For fixed species count, the cutoff has only logarithmically many count levels in horizon and target error, so the truncated state count is polylogarithmic in those quantities. This is a precise stochastic-control and biochemical/population-dynamics consequence. Its generic Lyapunov/truncation ingredients have substantial prior art; no novelty or field-breaking claim is made. The unresolved high-value gate is effective acquisition of such certificates for a materially broader coupled rational bimolecular endotactic class.

## Exact network and uniform certificate

For each species i=1,...,d use

  ∅ -> A_i       at predictable intensity λ_i(t) in [1,2],
  2 A_i -> A_i   at predictable intensity μ_i(t) binom(x_i,2), μ_i(t) in [1,4].

The rate choices may depend on the complete history and may be randomized. The state is x in N^d, n=||x||_1, and W(x)=2^n. The controlled generator gives

  (L^{λ,μ} W)(x)/W(x)
    = Σ_i [λ_i - (μ_i/2) binom(x_i,2)]
    <= 2d - (1/2) Σ_i binom(x_i,2)
    <= 2d - (1/4)(n^2/d - n),

where Σ_i binom(x_i,2)=(Σ_i x_i^2-n)/2 and Σ_i x_i^2>=n^2/d.

Let n_* be the least integer n for which

  2d - (1/4)(n^2/d - n) <= -1.

For n>=n_*, L W<=-2^n. With C={x:||x||_1<n_*}, stopped Dynkin localization gives, uniformly over every allowed predictable policy,

  E_x[τ_C] <= 2^{||x||_1-n_*}  (when x is outside C).

Inside C the state space is finite. Since the rates and jumps are locally bounded, the generator has a finite global upper bound B; the conservative explicit bound B=2d·2^(n_*-1) suffices. For N>||x_0||_1 define τ_N=inf{t:||X_t||_1>=N}. Stopped Dynkin gives

  sup_policy P_{x_0}(τ_N<=T) <= (2^{||x_0||_1}+B T)/2^N.

Let X^N be the finite chain that agrees with X until τ_N and then enters an absorbing boundary state. Any [0,1]-valued finite-horizon path payoff evaluated identically before exit changes in expectation by at most this exit probability. Coupling each full policy to its stopped version, and extending each stopped policy arbitrarily after exit, shows that both the supremum and infimum control values on X^N approximate the countable-state values within the same bound. Thus an acquired common recovery certificate gives a policy-uniform finite-state abstraction for finite-horizon reachability and bounded payoffs. The proof also establishes nonexplosion: finite sublevel sets have bounded rates, and the probability of reaching arbitrarily large W by any fixed T tends to zero.

For the displayed independent network, a simple geometric check of its complexes {0,e_i,2e_i} shows strong endotacticity: if w has a positive coordinate, a maximizing double complex has an inward 2A_i->A_i edge; if all coordinates are nonpositive, 0 is maximizing and 0->A_i has nonpositive w-increment, strictly negative for a negative coordinate. This property is only contextual; the stochastic proof is the explicit Foster calculation above.

## Concrete exact two-species instance

For d=2, n_*=8. Exhaustive exact rational evaluation on the finite set n<8 tightens the global upper drift to B=64 (the coarse formula gives 512). From x_0=(1,1), horizon T=100, and requested error 1/100, take N=20. Then

  P(τ_20<=100) <= (4+64·100)/2^20 = 1601/262144 < 1/100.

The retained states n<20 number binom(21,2)=210. This is an a-priori exact cutoff for any allowed policy, not an SSA estimate. `recovery_truncation_check.py` ran 8,081 finite exact checks for d=1..4 and confirms the displayed d=2 rational arithmetic. The analytic inequalities above, not these finite checks, prove the unbounded-state theorem.

## Literature and attribution boundary

Primary outward search found substantial neighboring results:

- Anderson–Kim, arXiv:1710.11263, gives fixed-rate positive recurrence and finite expected entry under structural reaction-network hypotheses. It does not state this arbitrary predictable-control quantifier.
- Munsky–Khammash, JCP 124 (2006), DOI 10.1063/1.2145882, gives finite-state projection with an accuracy certificate based on probability mass lost to an absorbing sink. The contribution here is an explicit a-priori cutoff for this particular all-control family, not the general idea of finite-state projection.
- Salamati–Soudjani–Majumdar, arXiv:1909.06112v2, already develops Lyapunov-based finite-horizon reachability approximation and CTMDP policy synthesis, including queueing examples. This overlap blocks a broad novelty claim; the countable-state chemical recovery-certificate interface needs an exact theorem-by-theorem comparison.
- Baumann–Sandmann, J. Appl. Prob. 52 (2015), DOI 10.1239/jap/1445543835, gives Foster-based truncation error bounds for long-run averages in infinite Markov chains, including queueing measures.
- Soloveichik, arXiv:0803.1030 / JCB 16 (2009), studies probability robustness and simulation cost in stochastic CRNs; its prior art means a generic “more reliable chemical computation” application is not new by itself.
- Anderson–Cappelletti–Kim–Nguyen, arXiv:1808.05328v2, includes the strongly-endotactic explosive counterexample. Deterministic permanence alone cannot supply the stochastic certificate.

Full metadata and links are in SOURCES.json. Current N35 material only establishes finite-horizon safety when an inward molecular certificate is supplied; N34/N50 global recognition claims have different scopes and do not supply the stochastic Foster object used here. The full permanence/certification source package was not independently proof-audited in this checkpoint.

## Costs, limitations, status, and next gate

For fixed d, n_* is explicitly computable from d and the rate envelope. The truncated count set has size binom(N+d-1,d)=O(N^d); here N=ceil(log_2((2^{n_0}+BT)/ε))=O(log(T/ε)+n_0+n_*), so fixed-d state count is polylogarithmic in T/ε. Within n<N, total jump intensity is at most 2d+4 binom(N-1,2)=O(d+N^2). Continuous rate intervals make the finite-state Hamiltonian linear in the rates, so endpoint actions suffice for extrema. A certified ODE/CTMDP solver, its numeric precision, and physical reaction work were not implemented or costed. Complexity is in numeric horizon T, not merely its bit length; n_* and B grow quickly with d and rate imbalance. The O(N^d) state count is not uniform-polynomial in species count.

The theorem controls high-count truncation and expected return to C. It does not by itself prevent extinction, prove a desired positive concentration band, ensure all-time safety, give mixing time or stationary-law error, or transfer to a coupled computation whose actions violate the common drift. The simple network is a tractable positive control class, not an effective general CRN certificate synthesizer. The general all-scale acquisition, boundary reachability, rate/stoichiometry bit bounds, and effective certificate-size bound remain open; prior explosive strongly-endotactic systems rule out dropping boundary hypotheses. Status: VERIFIED_INTERNAL elementary theorem for the stated subclass; broader application and novelty UNRESOLVED.

Next decisive gate: audit the three c10 Sol initial attacks after the root's cross-phase authorization, then try to extend the common exponential Foster/truncation interface to a genuinely coupled admitted network while preserving all predictable control quantifiers. The key falsifier is a boundary or action mode where the proposed common W loses negative drift or the process can enter an unrecoverable class.

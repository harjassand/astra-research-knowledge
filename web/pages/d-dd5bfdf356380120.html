THE PROFILE SYSTEM AND ITS LOGICAL ROLE

For an actual tensor character lambda, the primary source considers

    C(a,b) = sum_{i=0}^{a-1} sum_{j=0}^{b-1} x_i y_j z_{i+j},
    t = (p_X + p_Y + p_Z)/3,
    P(a,b) = (product_{pi in S_3} lambda_pi(C(a,b)))^(1/(6t)).

Here lambda_pi is lambda with its tensor legs permuted. The source establishes rank(C(a,b))=a+b-1 and shows that every such actual profile obeys the following numerical constraints, for positive integers a,b,h:

(A1) P(a,b)>0 and P(a,b)=P(b,a).
(A2) P(1,b)=b.
(A3) Separate discrete concavity: P(a,b+1)-P(a,b) is nonincreasing in b; equivalently 2P(a,b)>=P(a,b-1)+P(a,b+1) for b>=2, and the symmetric inequality in a.
(A4) Shifted tripling: P(a,3h+a-1)>=3P(a,h).
(A5) Rank envelope: P(a,b)<=(a+b-1)^(1/t).

The source also derives the coarse scalar range 1/3<=t<=1 from its oriented dot-product exponents. The obstruction value t=3/4 lies inside this range.

The primary proof combines (A1)–(A5) to obtain a^({4/3})<=P(a,a)<=(2a-1)^(1/t), hence t<=3/4. Its character-detection argument then gives omega<=9/4. The result below shows that (A1)–(A5), taken together, cannot yield a strict improvement t<3/4: they admit an extremal numerical profile at t=3/4. This is a statement about the reduced profile system only.

CONSTRUCTION

Set

    H_1=1,
    H_a = product_{j=1}^{a-1} (3j+1)/(3j)  (a>=2),
    P_*(a,b)=H_min(a,b) [max(a,b)+(min(a,b)-1)/2].

Thus H_(a+1)=((3a+1)/(3a)) H_a. Equivalently H_a=((3a-2)/(3a-3))H_(a-1) for a>=2.

A1–A2 hold directly. In particular H_1=1 gives P_*(1,b)=b. The following calculations verify the remaining constraints on every positive integer input.

CONCAVITY, INCLUDING THE SEAM

Fix a and write Delta_b=P_*(a,b+1)-P_*(a,b). When 1<=b<a, substitution and the recurrence for H give

    Delta_b = H_b (a+2b)/(3b).

For 2<=b<a, use H_(b-1)=3(b-1)H_b/(3b-2) to obtain

    Delta_(b-1)-Delta_b
      = H_b [(a+2b-2)/(3b-2) - (a+2b)/(3b)]
      = 2H_b(a-b)/(3b(3b-2)) >= 0.

At the seam, when a>=2,

    Delta_(a-1)=H_(a-1)(3a-2)/(3a-3)=H_a.

For b>=a, P_*(a,b)=H_a[b+(a-1)/2], so every tail increment Delta_b equals H_a. The increments therefore decrease up to the seam and are constant after it; equality holds across the seam. If a=1 all increments are 1. This proves concavity in the second variable for every a. Symmetry proves it in the first variable.

SHIFTED TRIPLING FOR ALL a,h

If h>=a, both arguments lie on the affine tail of the row, and

    P_*(a,3h+a-1)=H_a[3h+3(a-1)/2]=3P_*(a,h).

If h<a, then 3h+a-1>=a, and tripling is equivalent, after cancelling positive factors, to

    H_a/H_h >= (2a+h-1)/(a+2h-1).

For fixed h define F_h(a)=H_a(a+2h-1)/(2a+h-1). Then F_h(h)=H_h, and direct use of H_(a+1)/H_a gives

    F_h(a+1)/F_h(a)
      = (3a+1)(a+2h)(2a+h-1)
        / [3a(a+2h-1)(2a+h+1)].

The numerator minus the denominator is exactly 2(a-h)(a-h+1), which is nonnegative for a>=h. Hence F_h(a)>=F_h(h)=H_h, giving the required ratio inequality. This covers every positive a,h; no asymptotic step is involved.

RANK ENVELOPE AT t=3/4

For every j>=1, clearing positive denominators in

    (1+1/(3j))^3 <= (3j+2)/(3j-1)

gives the positive gap

    (3j)^3(3j+2) - (3j+1)^3(3j-1) = 6j+1 > 0.

Multiplication telescopes to H_a^3<=(3a-1)/2. (The earlier direct note gave the gap as 9j+1; that arithmetic is incorrect, though its intended inequality and conclusion remain valid with the corrected gap 6j+1.)

By symmetry take b>=a, put A=a-1 and c=a+b-1. Then P_*(a,b)=H_a(c-A/2). On c>=2A+1,

    d/dc log((c-A/2)^3/c^4) = (2A-c)/(c(c-A/2)) <= 0.

Thus P_*(a,b)^3/c^4 is largest at b=a. On the diagonal,

    P_*(a,a)^3
      = H_a^3 ((3a-1)/2)^3
      <= ((3a-1)/2)^4
      <= (2a-1)^4,

where (3a-1)/2<=2a-1 for a>=1. Therefore P_*(a,b)<=(a+b-1)^(4/3) for all positive a,b. Since a+b-1>=1, this also gives the rank envelope for every 0<t<=3/4.

ASYMPTOTIC SLOPE AND DIAGONAL RECURRENCE

The exact gamma expression and its standard ratio asymptotic are

    H_a = Gamma(a+1/3)/(Gamma(4/3) Gamma(a))
        ~ a^(1/3)/Gamma(4/3).

For fixed a, the row is affine once b>=a, with increment H_a. Hence its asymptotic slope is exactly

    lim_{b->infinity} [P_*(a,b+1)-P_*(a,b)] = H_a
      ~ a^(1/3)/Gamma(4/3).

Writing D_a=P_*(a,a)=((3a-1)/2)H_a gives the exact diagonal asymptotic

    D_a ~ 3 a^(4/3)/(2 Gamma(4/3)).

The exact recurrence also gives D_a-D_(a-1)=H_a+H_(a-1) for a>=2. This is equality in the diagonal increment inequality used below.

WHY THIS PROFILE IS POINTWISE EXTREMAL

The following slope argument proves that P_* is not merely one feasible profile: it is the pointwise minimum of the class defined by positivity, symmetry, P(1,b)=b, separate discrete concavity, and shifted tripling. The rank envelope is not needed for minimality.

Let Q be any profile in that class. Fix a and set delta_n=Q(a,n+1)-Q(a,n). Concavity makes delta_n nonincreasing. Positivity forces every delta_n>=0: a negative increment would force all later increments to be at most that negative number, eventually making Q(a,n) negative. Thus delta_n decreases to some finite L_a>=0. Cesaro averaging gives Q(a,n)/n -> L_a.

Let c_a=(a-1)/2. Starting at any h>=1 and iterating shifted tripling gives

    h_r = 3^r(h+c_a)-c_a,
    Q(a,h_r) >= 3^r Q(a,h).

Divide by h_r and take r to infinity. The row-slope limit implies

    L_a >= Q(a,h)/(h+c_a) for every h>=1.

Set D_a=Q(a,a) and K_a=2D_a/(3a-1)=D_a/(a+c_a). Then L_a>=K_a. By symmetry, for a>=2,

    D_a-D_(a-1)
      = delta_(a,a-1)+delta_(a-1,a-1)
      >= L_a+L_(a-1)
      >= K_a+K_(a-1).

Substitute D_a=(3a-1)K_a/2 and D_(a-1)=(3a-4)K_(a-1)/2. Rearranging yields

    K_a >= ((3a-2)/(3a-3)) K_(a-1).

Since K_1=Q(1,1)=1, iteration gives K_a>=H_a. For b>=a, all row increments from index a onward are at least their limit L_a, so

    Q(a,b) >= D_a+(b-a)L_a
            >= K_a[b+(a-1)/2]
            >= H_a[b+(a-1)/2]=P_*(a,b).

Symmetry covers b<a. Therefore Q(a,b)>=P_*(a,b) at every positive integer pair. For P_*, the tail slope is H_a and the diagonal increment recurrence is equality, so it meets the lower bounds at each step and is pointwise minimal.

EXACT CONCLUSION ABOUT THE AXIOMS

Together, (A1)–(A5) allow P=P_* and t=3/4. Its diagonal grows like a^(4/3), and its rank envelope holds at t=3/4. For t>3/4, the diagonal ratio

    P_*(a,a)/(2a-1)^(1/t)

is asymptotic to a positive constant times a^(4/3-1/t), which diverges; thus no such envelope holds globally. The maximum feasible t in this reduced system is exactly 3/4. The original direct note reversed this last comparison in one sentence: the correct statement is that no t>3/4 envelope holds; every 0<t<=3/4 envelope does hold.

Consequently none of the listed numerical axioms—individually or collectively as the reduced system (A1)–(A5)—forces a uniform strict cap t<=3/4-epsilon for any epsilon>0. This route alone therefore cannot improve the source's omega<=9/4 conclusion to omega<9/4: a pointwise strict inequality for each character, without a uniform gap, would not lower the supremum used by the detection argument. The pointwise-minimality proof also shows that optimizing every h in tripling or using the same concavity and boundary data more sharply cannot improve the diagonal lower exponent beyond 4/3.

LIMITS

P_* is a function on positive integer pairs, not a tensor character. The primary source's full character has global additivity, multiplicativity, normalization, and restriction monotonicity on all tensors. This leaf does not extend P_* to that semiring or prove it respects all tensor relations. Actual tensor characters may satisfy stronger relations that rule P_* out. Therefore this is not a tensor lower bound, does not prove omega>=9/4, and does not contradict the primary source's claimed upper bound. It only identifies the exact ceiling of the specified numerical reduction. Correctness and novelty of the primary manuscript remain outside this leaf's scope.

FALSIFIER

A concrete falsifier of the reconstruction would be an exact positive-integer pair where P_* fails one of (A1)–(A5), or a valid derivation from only (A1)–(A5) of t<3/4 despite the feasible witness above. The finite identities here make the first check explicit: concavity is governed by 2H_b(a-b)/(3b(3b-2)); tripling for h<a by 2(a-h)(a-h+1); and the telescoping envelope gap by 6j+1. A proposed new tensor inequality is a falsifier of the obstruction's relevance only if it is proved for every actual character and is violated by P_* at named integer parameters; if P_* satisfies it, that inequality alone does not escape this numerical obstruction.

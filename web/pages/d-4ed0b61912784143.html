T10 INFORMATION NETWORK — FROZEN PHASE-II RECORD v3
Date: 2026-10-09
Status: internally derived full-support non-group inner/outer bracket; exact capacity remains unresolved. No novelty or priority claim.

This is an append-only continuation of v1 and v2. It does not replace either record. The main Phase-II result is a concrete full-support non-group Latin-square source for which a structured syndrome/Slepian–Wolf hybrid beats the Slepian–Wolf sum by more than 0.52 bits/symbol, together with an exact one-sided envelope converse. The current code/converse gap is exactly 0.00048 bits/symbol. A finite search rules out better codes in a specified local group-sum/residual-label family, but does not rule out arbitrary operational codes.

1. Function and source
======================

Use the order-5 Latin square already displayed in v1, with rows indexed by x and columns by y:

        y=0  1  2  3  4
    x=0   2  0  3  1  4
      1   3  1  4  0  2
      2   4  2  0  3  1
      3   1  3  2  4  0
      4   0  4  1  2  3

The subtable with rows x={0,1} and columns y={1,3} is the XOR intercalate

        y=1  3
    x=0  0  1
      1  1  0.

Let P0 put masses 9/20, 1/20, 1/20, 9/20 on (0,1),(0,3),(1,1),(1,3), respectively. For epsilon=1/1000, define

    P_XY = (1-epsilon) P0 + epsilon U_25,

where U_25 is uniform on all 25 input pairs. Thus P_XY is full support. Its selected-cell masses are 44959/100000, 4999/100000, 4999/100000, 44959/100000; every other cell has mass 1/25000. The marginals are P_X(0)=P_X(1)=4997/10000 and P_X(x)=1/5000 for x=2,3,4. In particular, selected-row mass r=4997/5000=0.9994.

Define local bits A=1{X=1}, B=1{Y=3}, and D=A xor B. Define residual labels

    T_X = * if X in {0,1}, and T_X=X otherwise;
    T_Y = * if Y in {1,3}, and T_Y=Y otherwise.

For every input pair, Z=f(X,Y) is determined by (D,T_X,T_Y): if both labels are *, the intercalate gives Z=D; if exactly one side is exceptional, D gives the selected bit and the other label gives the exact exceptional symbol; if both are exceptional, both symbols are known. The full table is Latin, so the latter two rules are valid symbol by symbol.

The induced channels are not output-permutation equivalent. Rows x=0 and x=1 of W_Z are equal, whereas rows x=0 and x=1 of W_Y differ by swapping the y=1 and y=3 probabilities. Explicitly, for W_Y the two selected rows have entries (in y order)

    (2/24985, 44959/49970, 2/24985, 4999/49970, 2/24985),
    (2/24985, 4999/49970, 2/24985, 44959/49970, 2/24985).

For W_Z the two rows are both

    (44959/49970, 4999/49970, 2/24985, 2/24985, 2/24985).

A common output permutation preserves whether two input rows agree, which proves non-equivalence. For x=2,3,4 both channels have uniform rows because Y|X=x is uniform and each row of f is a permutation.

2. Operational structured code
===============================

The code has no feedback, no encoder cooperation, and no run-time common randomness. The source alphabets and the group alphabet are fixed. All entropies are in bits per source symbol.

First, the X encoder sends a Slepian–Wolf bin of T_X^n and the Y encoder sends a Slepian–Wolf bin of T_Y^n. The decoder recovers T^n=(T_X^n,T_Y^n) at total rate H(T_X,T_Y). This works because the two residual sequences are iid and each encoder sees its own sequence.

Second, both encoders use the same fixed binary matrix G_n. Encoder X sends G_n A^n and encoder Y sends G_n B^n. The decoder adds the messages to obtain G_n D^n. It decodes D^n using the already recovered T^n as decoder side information. For any delta>0, a random binary matrix with m/n>H(D|T_X,T_Y)+delta has vanishing expected error: for each incorrect conditionally typical d'^n with the same T^n, the collision probability is 2^{-m}, and there are at most 2^{n(H(D|T)+o(1))} such candidates. Fix one successful matrix for each blocklength. Its identity is part of the fixed code and costs no run-time seed bits. After recovering D^n, the decoder computes each Z_i from (D_i,T_Xi,T_Yi).

The resulting achievable sum rate is

    C_in = H(T_X,T_Y) + 2 H(D|T_X,T_Y)
         = 0.013003452707488 + 2(0.469284479640066)
         = 0.951572411987619.

By symmetry, one can split H(T_X,T_Y) equally between the two Slepian–Wolf messages, giving the symmetric point R_X=R_Y=0.475786205993810. This is a structured syndrome plus residual Slepian–Wolf hybrid. It is not the adjacent-parity Ahlswede–Han construction studied for binary XOR.

The complete Slepian–Wolf sum is

    H(X,Y)=1.481447932347554,

so this code saves 0.529875520359935 bits per symbol relative to reproducing both sources. The gain is an internally derived achievability result for the displayed full-support source; it is not a capacity claim.

3. Exact one-sided envelope converse
====================================

Use the Latin-square converse proved in v1. At lambda=1, every vanishing-error separate-encoder code satisfies

    R_X+R_Y >= H(X,Y) - cav(Delta)(P_X),
    Delta(p) = H(p W_Y) - H(p W_Z),

where cav is the upper concave envelope over posterior input distributions. For this source the envelope can be computed exactly.

For any posterior p on X, let s=p(0)+p(1), and set c=(1-epsilon)/r=4995/4997. For fixed s, pW_Z depends only on s because W_Z(.|0)=W_Z(.|1), and the entropy H(pW_Y) is maximized at p(0)=p(1) by the symmetry of the two selected rows and entropy concavity. Hence Delta(p) is at most psi(c s), with equality at a balanced selected posterior, where t=c s and

    u_Y(t)  = 1/5 + 3t/10,       v(t) = 1/5 - t/5,
    u_0(t)  = 1/5 + 7t/10,       u_1(t) = 1/5 - t/10,
    psi(t)  = H(u_Y,u_Y,v,v,v) - H(u_0,u_1,v,v,v).

The five entries in each entropy are the output probabilities, with v repeated three times. Direct differentiation gives

    ln(2) psi''(t) = -64/[5(t-2)(3t+2)(7t+2)] > 0,   0 <= t <= c.

Thus psi is convex and its upper concave envelope on [0,c] is the chord between (0,0) and (c,psi(c)). The mean t under any posterior decomposition of P_X is c r=1-epsilon. The chord therefore gives r psi(c). Equality is achieved by the auxiliary that reports “selected” with probability r and then has posterior (1/2,1/2,0,0,0), and otherwise reveals one of x=2,3,4. This proves

    cav(Delta)(P_X)=r psi(c),
    C_out = H(X,Y)-r psi(c)=0.951092411987619.

The scalar reduction and endpoint auxiliary give the exact envelope value for the one-sided v1 converse, not the operational sum capacity.

4. Exact residual gap and its encoder-information obstruction
=============================================================

Let T=(T_X,T_Y), and let p_ss=P(T_X=*,T_Y=*)=0.99916. Conditional on the both-selected event, D is Bernoulli with

    q=P(D=1 | T_X=T_Y=*) = 0.09998/0.99916.

There are 12 one-sided-exception cells and each has probability 1/25000, so their total probability is 0.00048. On each such T value D is uniform; on the nine both-exception cells D=0. Therefore

    H(D|T)=p_ss h_2(q)+0.00048.

On the both-selected event, (T,D) leaves one equiprobable orientation bit A; in all other T classes, T and D identify the input pair. Hence

    H(X,Y)=H(T,D)+p_ss=H(T)+H(D|T)+p_ss.

For the exact envelope auxiliary, the selected posterior's Y output consists of a selected two-symbol component and a three-symbol exceptional tail. The same tail distribution appears in Z, while the selected component has entropies 1 and h_2(q). The disjoint supports make the common mixing entropy and tail entropy cancel, giving

    r psi(c)=p_ss[1-h_2(q)].

Consequently the converse and code rates simplify to

    C_out = H(T)+2 p_ss h_2(q)+0.00048,
    C_in  = H(T)+2 p_ss h_2(q)+0.00096,
    C_in-C_out = 0.00048 exactly.

The missing half is one extra copy of the one-sided-exception D entropy in the current code. A tempting construction would use a Körner–Marton syndrome only on indices where both sides are selected, then send one-sided D bits from only the active encoder. That mask depends on both T_X and T_Y. Encoder X does not know T_Y and encoder Y does not know T_X, so neither can form that joint-mask syndrome without feedback or extra communication. This explains why the obvious masked refinement is invalid under the model. It does not prove that every possible code must pay the extra 0.00048.

5. Finite representation search
===============================

`latin_decomposition_search.py` exhaustively checks a restricted code family of the form

    Z = F(A(X)+B(Y), T_X(X), T_Y(Y))

for a finite abelian group label and local residual partitions. For each valid representation, the tested code sends the residual-label pair by Slepian–Wolf coding and sends one common linear syndrome from each encoder for the group sum, decoded with residual labels as side information.

For GF(2), the script checks every pair of local bit maps on five symbols and every pair of set partitions. It finds 19,968 valid representations; the minimum sum rate in this family is 0.951572411987619, attained by the construction above. For Z/4Z, it fixes the order-two difference required by the selected intercalate, checks all assignments to the remaining symbols, and all residual partitions that keep the selected pairs grouped. It finds 37,888 valid representations, with the same minimum. These finite searches only certify the minimum within their enumerated representation classes. They do not exclude a different nonlinear, multi-letter, or interactive-free code outside those classes, and do not close the 0.00048 gap.

6. Literature boundary and claim ledger
=======================================

Han and Kobayashi, “A dichotomy of functions F(X,Y) of correlated sources (X,Y),” IEEE Transactions on Information Theory 33(1), 69–76 (1987), DOI 10.1109/TIT.1987.1057272, give a universal source/function classification for when function computation has the Slepian–Wolf rate region for every full-support iid source. The displayed Latin square fails their cross-difference condition: f(0,1)=f(1,3)=0 although both input coordinates differ. Thus a full-support source with a strict gain over Slepian–Wolf is not a new existence result. The theorem does not identify this particular P_XY or the numerical inner/outer bracket above.

For the modulo-sum comparison, see v2 Section 2 and Section 5: Körner–Marton coding and the non-DSBS exact-sum family of Nair–Wang (ISIT 2020, DOI 10.1109/ISIT44484.2020.9174208) already cover the binary example recorded there. Tsujino–Watanabe, arXiv:2606.25570v2 (12 Aug 2026), Theorem 4, show that adjacent-parity multi-letter Ahlswede–Han coding eventually improves on Slepian–Wolf for the known strict condition in the binary XOR problem. Those results do not supply a matching converse for this non-group order-5 source.

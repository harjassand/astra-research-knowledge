Title:A New Sparse Algorithm for Polynomial GCD over Integers
    
Authors:Qiao-Long Huang, Michael Monagan            
View a PDF of the paper titled A New Sparse Algorithm for Polynomial GCD over Integers, by Qiao-Long Huang and Michael Monagan
    View PDF
    HTML (experimental)



    
            Abstract:We describe a new greatest common divisor (GCD) algorithm for polynomials with integer coefficients. The bit complexity of the new algorithm is polynomial in the input and output sizes and the individual degree this http URL algorithm follows the standard approach by reducing multivariate polynomial GCD to univariate polynomial GCD.
Our algorithm reduces a multivariate polynomial GCD to a single univariate polynomial GCD. The main idea of our algorithm is a new variable substitution which reduces a multivariate polynomial to a separated one, that is, the coefficients in a main variable are all monomials. The explicit bit complexity is analyzed and we have implemented our algorithm in Maple. It is shown that our algorithm is efficient for polynomials with high degree, large number of variables, but small number of terms in GCD.

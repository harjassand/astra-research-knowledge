# Space-simulation proof gate

## Result

A fixed Rossman/GKPS BGS term program, including `Card`, on unary/binary inputs of size at least two has a fixed binary-vocabulary two-dimensional FO+H interpretation simulator whose maximum universe is polynomial in input size plus peak native hereditary-closure size. The polynomial and simulator depend only on the fixed term. There is no factor in finite runtime or discarded history.

The construction supplies transitive current-state garbage collection, an actual-cardinality-bounded dynamic ordinal reserve, atom-safe extensional quotients, and a resettable tuple/incidence compiler. The standard-model exponential hereditary-space corollary follows conditionally from the already audited explicit-model lower bound.

Preserved route audit, 2026-10-09.

1. Finite-range iid image -> finite power Bernoulli.
   Rejected. Finite-gradient representations of Popa compact quotients over
   property-(T) groups are finite-range dependent algebraic block images with
   dense homoclinic points, but every finite power remains non-Bernoulli by the
   compact-extension cocycle obstruction. The missing complementedness premise
   is load-bearing. PROOF.txt section 7 contains the proof with the imported
   classical superrigidity statement made explicit.

2. Complemented finite-range idempotent image -> finite power Bernoulli.
   False without essential freeness. On Z x C3 the averaging idempotent gives
   an infinite mixing complemented block image with C3 in its action kernel.
   No finite power is a nontrivial full-group Bernoulli action. This does not
   refute the specific one-sided-inverse defect because the averaging example
   does not satisfy X ~= X x K.

3. Equal-entropy classification of (F2^d)^G -> d-th root theorem.
   Rejected. A statement about h_WP of a finite product of binary shifts does
   not automatically descend to an individual binary factor. Instead the CRT
   corner transfer embeds the actual finite field in a scalar F2 group algebra
   and adds the complementary identity. This supplies a genuine scalar binary
   one-sided witness over an explicit finite group extension.

4. Apply torsion-free N252 to the current comparator without checking scope.
   Rejected. The comparator asks for an arbitrary finite characteristic-two
   field and a finitely presented group with odd-prime torsion. Its current
   comparator statement is a target containing sorry, not a replayed proof.
   The correct conditional repair uses (G0 x C_(|F|-1))*Z, rather than
   silently asserting F=F2 or G0 torsion-free.

5. No finite normal action kernel -> residual Bernoullicity.
   Rejected inference. Kernel repair yields an essentially free defect system
   and permits the finite-color extraction. It gives no generating independent
   description of the residual and no unequal-entropy Bernoulli conjugacy.

6. Stable absorption / large direct Bernoulli factors -> cancellation of R.
   Not justified. The proved identity X ~= X^2 x R has no cancellation law.
   Countable powers of K absorb Bernoulli systems, but transferring this back
   through x -> (P A^j x)_j loses the nontrivial tail D. This canonical map is
   invariant under x -> x+1 and cannot be inverted modulo null sets.

7. Classical almost-freeness lemma presented as a discovery.
   Corrected before reporting. Tucker-Drob 2012 proves the broader theorem;
   the elementary coefficient proof is independent reconstruction only.
   Austin 2015/2016 Question 1.1 explicitly records the complemented Bernoulli
   factor problem. No novelty from source search absence is asserted.

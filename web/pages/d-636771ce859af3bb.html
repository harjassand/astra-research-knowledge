# Finite radial experiment: recorded results

Known interface R=.5; c2 in [1,2], t in [-.5,.5]. Every design uses one unit-power current and six scalar voltage coefficients. The deterministic two-mode control pays for all six detectors in this comparison. Six pure-harmonic currents with the same total power and one detector each have the identical Gaussian observation law as deterministic equal six-mode input.

| Noise SD | Random unit current RMSE | Deterministic six modes RMSE | Grid-selected two modes RMSE |
|---:|---:|---:|---:|
| 0.0001 | 0.0154263 | 0.00806819 | 0.00588688 |
| 0.001 | 0.183711 | 0.0783148 | 0.0694875 |
| 0.01 | 0.852984 | 0.506137 | 0.469135 |

These are finite synthetic outcomes, not confidence guarantees or a proof of optimal design. The deterministic selector checked 999 power splits on a fixed 41x41 parameter grid; first-mode power was .415. The exact two-mode inverse maximum error over the diagnostic grid was 4.6e-12.

The proved global lower stability constants for pairs (1,2), (3,4), (5,6) are approximately .00372113, .000142859, .00000585153. Their conservative unit-sphere inverse-second-moment bound is 7.68e11: mathematical finiteness does not make this a useful quantitative sensor guarantee.

All 1,152 trial records were retained and replay-checked for model/data consistency, unit current power, recovered parameter error, and the analytic reconstruction bound evaluated in ordinary floating arithmetic (no interval numerical certification). JSON summary records code and raw-data hashes. Local observed run time was 1.716s (including 0.487s grid design and 1.179s reconstruction/diagnostics).

SUPPLIED VERSUS ACQUIRED

The mathematical problem supplies an exact faithful physical sigma and
an exact finite pure decomposition, hence the exact canonical EB channel.
No ensemble acquisition, tomography, measurement black box, physical
state preparation, gate compilation or inverse oracle is free. The scalar
proof takes the N-atom decomposition as mathematical input and embeds
into an N-dimensional ensemble space. Inverse powers are used only for
the faithful physical sigma; the overcomplete embedded B can be singular
and is never inverted. A proof isometry is not an efficiently compiled
quantum circuit or an acquisition algorithm.

The existence of an equivalent pure finite representation with
d²(d²+1)/2 atoms preserves the SAME channel and sigma; it is a compactness/
Caratheodory fact, not an algorithmic extraction bound. The theorem's
constants do not depend on d,N,p_min,sigma_min or reference size. These
constant-free mathematical inequalities do not supply finite-bit runtime
or stable implementation costs for arbitrary input encodings.

The complete finite-reference proof has embedded dimension rN, uses
actual r-by-r positive blocks and a separate matrix lemma, and does not
assume global EB or purity. The normal-reference theorem is a limit of
finite-rank compressions, not an effective computation of an arbitrary
normal infinite-dimensional state; no reference energy constraint is
supplied or needed for the qualitative limit.

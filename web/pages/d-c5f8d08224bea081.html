## Verdict and scope

## Exact interface and contract

In readable Lean notation, the public signature is:

```lean
theorem N33Affine.exists_uniform_activity_cutoff
    {m : ℕ} {a b : ℝ} {E : (Fin m → ℝ) → ℝ}
    (F : BoxFamily m a b)
    (hFull : FullApproximation a b E F.family) :
    ∃ hAct : ℝ, 0 < hAct ∧ hAct < 1 ∧
      ∀ h, 0 < h → h < hAct → ∀ p, InCube a b p →
        ∀ j : F.family.Index, Active F.family.label j h p →
          ∀ i, |p i - (F.family.label j).slope i| <
            E (F.family.label j).slope
```

The `#check`/`#print` record at `project/UniformActivityAudit.log:1–23` confirms these binders and the theorem body; the last line records its axiom dependencies. The `#check` is emitted with `pp.all true`, so its elaborated form is verbose. A compact transcription and the exact logged axiom line are in `API_Audit.log`.

The imported contracts line up with the manuscript proof:

- `FiniteFamily` carries a `Fintype` and `Nonempty` index type; `BoxFamily` additionally requires every label slope to lie in `InCube a b` (`N33Affine/SliceFamily.lean:58–69`).
- `Active family j h p` means `∀ j', value (family j) h p ≤ value (family j') h p`; equality is allowed, so all tied minimizers are active (`N33Affine/AffineCore.lean:20–31`).
- `FullApproximation` quantifies over every fixed label, every `hSeq : ℕ → ℝ`, every `pSeq : ℕ → Fin m → ℝ`, and limit `p`. It assumes `hSeq → 𝓝[>] 0`, `pSeq → 𝓝 p`, `InCube a b p`, and **eventual** weak activity; it concludes the strict bound for every coordinate (`N33Affine/AffineInduction.lean:14–22`). There is no requirement that the approximating `pSeq n` lie in the cube.
- `E` is represented as a total real-valued function, with positivity required only on the cube by `exists_full_affine_family`. No continuity, measurability, or computability premise appears. In the contradiction limit, `E` is evaluated at the slope of one fixed label, so no continuity of `E` is used.

## Proof reconstruction against affine.tex

The proof follows the source's contradiction, finite-label extraction, and compactness argument, with a further finite coordinate extraction to formalize the infinity-norm violation as a coordinate witness.

1. Assuming no cutoff, for each `n` choose `δₙ = min (1/(n+1)) (1/2)` and a counterexample `hₙ < δₙ`, cube point `pₙ`, active label `jₙ`, and coordinate `iₙ` with `E(slope jₙ) ≤ |pₙ[iₙ] - slope jₙ[iₙ]|`. Thus `hₙ > 0` and `hₙ → 0+`.
2. The tag space `F.family.Index × Fin m` is finite. An infinite-fiber extraction, followed by a strictly increasing subsequence, fixes both the label and bad coordinate. This fixes the tolerance argument as well as the coordinate for the limiting violation.
3. The cube is identified with the order interval `Set.Icc (fun _ => a) (fun _ => b)` in `Fin m → ℝ`, hence compact. A further subsequence converges to `p₀` in the cube. Positivity of the scale sequence is retained, giving convergence to `𝓝[>] 0`.
4. The fixed label is active on this subsequence (in fact at every chosen counterexample index). `hFull` applies to the unrestricted approximant sequence and cube limit and gives the strict approximation bound at `p₀` for the fixed coordinate.
5. Coordinate evaluation and absolute value are continuous. The non-strict bad inequalities form a closed lower-bound condition, so they pass to the limit at the same fixed slope and coordinate. This contradicts the strict `hFull` conclusion.

This proves the source's quantifier order: one family is fixed first, then one `hAct ∈ (0,1)` works for all `h`, all cube points, and all labels weakly active at those points. It is not a uniform bound over labels from different families. The cutoff is existential and no effective numerical bound is supplied.

## Adversarial contract checks

- **Ties / activity domain:** no unique minimizer condition is present. `Active` compares the selected label weakly against every label, matching “each label active”; the target ranges over every active index.
- **Approximation sequences outside the cube:** allowed. Only the limit is constrained to `InCube`, matching the source affine lemma that the uniform corollary invokes.
- **Discontinuous tolerance:** no continuity is smuggled in. The extracted label fixes `E (slope j₀)` throughout the limit argument.
- **Coordinate / norm conversion:** a failed uniform conclusion supplies one coordinate with error at least `E`; the proof fixes that coordinate together with the label. For `m = 0`, there is no coordinate witness, so the target's `∀ i : Fin 0` is vacuous and the contradiction construction closes by impossibility. The upstream existential affine theorem also has an explicit `m = 0` branch.
- **Activity eventuality:** `FullApproximation` only gives eventual activity, which suffices. The counterexample sequence gives activity at each index, and subsequences preserve that fact.
- **External premise:** the cutoff declaration is conditional on `hFull`, but `exists_full_affine_family` supplies `F`, `FamilyLittleOAt F a`, and exactly this `hFull` for arbitrary `a ≤ b` and cube-positive `E`. Thus there is no residual `SliceOracle` or local-family premise in the composition. The conditional signature must still be described as conditional when citing this declaration alone.
- **Domain / scaling representation:** source labels are affine functions of `X_h(p)` with offsets defined for sufficiently small positive `h`; Lean's `Label.bump` is total on `ℝ`, and `value` uses `Real.rpow h (p i)`. The cutoff restricts to `0 < h < hAct < 1`, where this is the intended positive-scale evaluation. Totalization of source offsets is an encoding choice inherited from the affine development, not an extra regularity assumption in this corollary.

No executable counterexample, mutation test, or independent challenge proof was run; the checks above are inspection of the source and proof term/API contract. No failed Lean attacks are recorded.

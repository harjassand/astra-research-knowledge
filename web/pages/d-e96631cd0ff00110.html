DETERMINISTIC FINITE-QUOTIENT ROUTE: EXACT AXIAL-SECTOR OBSTRUCTION
2026-10-08

Question and verdict

Can a finite Cayley/quotient representation of the cycle-4 branch family, with
only its global trivial vector removed, realize the selected uniform score gate
Gamma_K <= sqrt(50)+s at r=2,d=65,K=260,s=33/200? No. For every nontrivial
finite quotient Q of F_65 x F_65, the left regular representation restricted
to ell^2_0(Q)=1^perp has Gamma_K >= sqrt(130*129)=sqrt(16770)>129.499.
This is an exact obstruction, independent of quotient order, girth, Ramanujan
scalar adjacency bounds, or low-word trace agreement. It does not rule out a
single carefully chosen mixed nontrivial irrep, a representation with all
factor-trivial sectors removed, or arbitrary algebraic-unitary circuits.

Exact interface

Let G=F_65^(1) x F_65^(2), with formal branch labels S_j={g_(j,i)^+/-:
1<=i<=65}; |S_1|=|S_2|=130 and K=260. For a finite quotient q:G->Q, put
H_j=q(F_65^(j)). The two H_j commute and generate Q. In pi=lambda_Q|ell^2_0(Q),
write

  P_A = sum_(s,t in S) a_st pi(q(s^-1 t)),
  Gamma_K(pi)=sup{||P_A||: A=A*, Tr(A)=0, ||A||_HS=1}.

The target from the selected Haar gate is sqrt(50)+33/200 =
7.236067811865... . The proof below exhibits one admissible A with norm at
least sqrt(16770), so it directly fails the all-coefficient-sphere gate.

Theorem and proof

Set m=130 and M=m(m-1)=16,770. If H_1 is proper in Q, define

  v = 1_(H_1) - (|H_1|/|Q|) 1_Q.

This is nonzero, mean-zero, and fixed by left translation by every h in H_1.
For s,t in S_1, q(s^-1 t) is in H_1, so pi(q(s^-1t))v=v. Take A supported
on the S_1 x S_1 block with a_st=1/sqrt(M) for s!=t and a_ss=0. It is
Hermitian, traceless, and has squared HS norm M*(1/M)=1. After normalizing v,

  P_A v = (M/sqrt(M))v = sqrt(M) v,

hence ||P_A||>=sqrt(M).

If H_1=Q, commutation forces H_2 subset Z(Q). For nontrivial Q choose any
nontrivial irreducible unitary representation rho of Q, which occurs inside
ell^2_0(Q). Every branch s in S_2 acts there as a phase z_s by Schur's lemma.
On the S_2 x S_2 block instead take a_st=z_s conjugate(z_t)/sqrt(M) for
s!=t and zero on the diagonal. Again A=A*, Tr A=0, ||A||_HS=1. On a unit
vector psi in rho,

  a_st rho(q(s^-1t)) psi
    = (z_s conjugate(z_t))(conjugate(z_s) z_t)/sqrt(M) psi
    = psi/sqrt(M),

so P_A psi=sqrt(M)psi and ||P_A||>=sqrt(M). If Q is trivial,
ell^2_0(Q) is zero-dimensional and is not a candidate channel space.
These cases exhaust all finite quotients.

The comparison is exact: (sqrt(50)+33/200)^2<53<56<16,770. Thus removing
the single global constant vector does not repair the finite-quotient regular
representation. The witness uses only one factor's branch block and formal
off-diagonal support of M=16,770 coefficients; quotient collisions can only
reduce the number of distinct group elements in the operator expansion, not
its action on the displayed vector.

Approximation robustness and resource accounting

Suppose each branch unitary U_s approximates the corresponding quotient
permutation pi(q(s)) in operator norm by at most delta. For the same witness A,
||U_s*U_t - pi(q(s^-1t))||<=2 delta, whence

  ||P_A(U)-P_A(pi)|| <= 2 sqrt(M) delta,
  ||P_A(U)|| >= sqrt(M)(1-2 delta).

Consequently the target still fails whenever

delta < (1 - (sqrt(50)+33/200)/sqrt(16,770))/2
       = 0.472061305993... .

This robustness claim only concerns circuits approximating a bad quotient
representation. It is not a no-go for independently designed unitaries.
The exact quotient acts on dimension |Q|, and the proposed constant-removed
space has dimension |Q|-1. The witness needs no numerical precision: the
quotient gates are permutation matrices and the lower bound is symbolic. No
successful quotient, group presentation, state-preparation routine, bounded-
local-control compilation, circuit depth, or matrix materialization is
provided; a generic Cayley permutation may be a global gate. Its reversible
gate cost cannot be charged without the presentation/encoding. Increasing
|Q| or girth cannot improve this exact score obstruction.

A possible but unproved repair is to use a split quotient Q_1 x Q_2 and retain
only ell^2_0(Q_1) tensor ell^2_0(Q_2), removing all sectors trivial on either
factor. The theorem's first invariant vector lies in a removed axial sector,
so it does not settle this repair. A necessary condition is that every four
positive generator images in each Q_j generate Q_j: if four images generate
a proper subgroup L<Q_j, their eight signed branch labels admit the same
constant-off-diagonal witness on those labels, with norm sqrt(8*7)=sqrt(56)
> sqrt(50)+33/200, using a nonzero L-invariant mean-zero vector in
ell^2_0(Q_j). This condition is not sufficient and no global operator-norm
certificate for the mixed augmentation follows from it. Scalar Ramanujan
adjacency and finite low-word trace tests do not control the required
all-coefficient-sphere supremum.

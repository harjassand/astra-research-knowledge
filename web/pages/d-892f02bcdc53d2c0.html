For R=-[v,f]=Kv+3alpha*x^2*v,

Hence C=R-[E,R]=Kv+P_support(v)*Kv and

2. FINITE POSITIVE HANKEL FLATNESS WITHOUT SUPPLIED N
Suppose actual p_j come from any finite physical model and a nonzero v.
Let H_s>0 and H_(s+1) be singular, using p_0,...,p_(2s). Solving the H_s
system yields monic P of degree s. Its Schur complement is exactly
 sum_i v_i^2*P(alpha_i*v_i^2)^2=0.
Every summand is nonnegative, so every positive-weight support point is a root.
This also holds for ANY competing positive measure with the same finite moments.
Since H_s is positive definite, there must be at least s support points; P
has at most s roots. Therefore all competing measures have exactly the same
s atoms and weights. Extra repeated physical atoms may split an aggregate
weight, but no new distinct positive atom can appear.

There is no missing n bound in this argument. For the actual finite model,
the scan must terminate. Directions with v_i=0 contribute weight zero and are
deliberately invisible to this one support test. The subsequent K/ternary Gram
closure tests are necessary; moment flatness alone would not certify W.

The certificate requires EXACT singularity. Arbitrarily tiny additional atoms
can approximate these moments, so finite error bars do not establish flatness.
An effective implementation on arbitrary real-number approximation oracles
would also need an exact equality/rank decision mechanism. The finite-jet
uniqueness statement is valid; a finite-noise dimension estimator is not proved.

same support-polynomial decisions even in a larger competing physical model.

At termination every K and ternary basis candidate lies in the current span
in BOTH models. Linearity/trilinearity therefore certify invariant closure in
both. Since the construction began at e1 and only uses K and T, that span is
precisely W in each model. Both have the same dimension r and the same paired
metric/operator data. The canonical quotient classification then applies.

The ternary-subspace classification in the addendum is valid: a generic vector

After reduction both models have full closure. The root-count argument for a

the measured-coordinate sign ambiguity. Thus the canonical quotient is unique
up to a hidden signed permutation even across different physical dimensions.

Equal germs imply equal complete IO here: the recovered canonical polynomial
ODE is identical up to gauge, and each physical zero-initial trajectory stays
in its exact invariant image. This does not rely on continuation of measured

4. PRECISE DEFINITION AND JUSTIFICATION OF MINIMALITY
Let the admissible class allow arbitrary finite N and positive heterogeneous
alpha_i. Define a minimal realization of a zero-initial IO map as an admissible
model of the smallest possible state dimension.
The canonical quotient is admissible, has dimension r, and has the same IO.
Every admissible equivalent model has closure dimension r by the argument above,
so its physical dimension is at least r. Hence the quotient is dimension-minimal.
Any minimal model has N=r and full closure; full-closure recovery proves that
all such minimal models are gauge-equivalent.

This is not merely smallest-invariant-linear-subspace terminology. In addition,
the generated constant fields span the reduced space and belong to the Lie
algebra generated by f,g, so the accessibility rank is full. The generated
linear observables z_v span the dual space, so the observation codistribution
is full. These give the usual local accessibility/observability interpretation.
No claim of minimum dimension among ALL possible nonlinear model families is
needed or proved; the theorem is model-class-relative.

5. EXHAUSTIVE DESCRIPTION OF EVERY EQUIVALENT PHYSICAL MODEL
Fix the canonical full-closure model (Kbar,alphabar) of dimension r. Apart from
the permitted hidden signed/permutation gauges, every equivalent admissible
physical model is obtained as follows:

* Choose N>=r, disjoint active blocks B_1,...,B_r, with B_1={1}, plus possibly
  inactive coordinates outside their union.
* Choose signs s_i, with s_1=1, and positive alpha_i obeying
      sum_(i in B_j) 1/alpha_i = 1/alphabar_j.
  Inactive coordinates have arbitrary positive alpha_i.
* Define V_ij=s_i*sqrt(alphabar_j/alpha_i) on B_j and zero elsewhere.
  Then V^T V=I and V e1=e1.
* Choose any symmetric operator R supported on W-perp, W=range(V), which is
  positive definite on that complement, and put
      K=V*Kbar*V^T+R,    R V=0.
  If the complement is zero, omit R.

SUFFICIENCY: K is SPD, the physical weighted cubic intertwines with the reduced
cubic under V, and input/output are anchored. The full-closure canonical model
forces physical closure exactly W. Thus the physical model has the same IO.
NECESSITY: apply the proved subspace classification to any equivalent physical
model. Its canonical quotient is the given one. Symmetry and K-invariance make
the cross blocks between W and W-perp zero, leaving exactly such an SPD R.

Consequently these generalized hidden refinements DO exhaust all equivalent
models within the stated class. They need not exhaust equivalences outside
that class. Inactive coordinates may mix through R with active-block difference
directions; the physical graph can therefore remain connected. An informal
description restricted to adding disconnected nodes would be incomplete.

6. WHY PHYSICAL N IS UNKNOWN, AND WHEN THAT CLAIM CHANGES
In the heterogeneous-positive class, a hidden canonical block can be expanded
to any m copies by taking alpha_i=m*alphabar_B on that block. The harmonic sum
is unchanged. Inactive coordinates can also be added. Physical N is therefore
not determined by IO in the unrestricted class.

If instead the common physical alpha is KNOWN and fixed, the quotient determines
every active block size m_B=alpha/alphabar_B exactly. It therefore determines
the total ACTIVE physical support size M=sum_B m_B. Extra inactive coordinates
remain possible in the unrestricted symmetric-SPD class, so N can still exceed M.
For a concrete connected homogeneous example, the following N=3 and N=4 systems
have identical IO for every input and the same alpha:
 K3=[[4,-1,-1],[-1,4,0],[-1,0,4]],
 K4=[[4,-1,-1,0],[-1,4,0,1],[-1,0,4,-1],[0,1,-1,4]].
Both are connected and SPD. K4 has eigenvalues 4+/-sqrt(2), each twice.
Starting zero, x2=x3=s and x4=0, leaving exactly the K3 equations. The fourth
coordinate is topologically connected through balanced signed couplings but
is inactive on every permitted trajectory.

If one additionally restricts to IRREDUCIBLE M-matrices and known common alpha,
inactive coordinates are impossible. For constant u>0 the unique equilibrium
satisfies (K+diag(alpha*x_*^2))*x_*=u*e1. The matrix is an irreducible nonsingular
M-matrix and its inverse is strictly positive, so every coordinate of x_* is
positive. Since x_* lies in W, every coordinate is active. Hence N=M is then
IO-identifiable, although the hidden topology/orthogonal dynamics can remain
undetermined. The addendum's blanket N statement must not be transferred to
that narrower subclass without this qualification.

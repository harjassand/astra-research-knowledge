A ROUTING BOUNDARY FOR FINITE-COPY DE FINETTI SHORTCUTS
Independent c05_s01 continuation, 7 October 2026.

STATUS / EXACT SCOPE

An exact family shows that arbitrarily many identical compatible marginals
and output quantum fibres of dimension 2 do NOT imply a dimension-free
DIAMOND or normalized-Choi trace approximation by EB. Its induced normalized
infinity-to-one distance nevertheless tends to zero, so it is explicitly
NOT a counterexample to the actual CP-power-range target. Input and output
algebras differ and it is not a positive selfadjoint endomorphism.
This earns a boundary for the shortcut, while preserving the correct norm.

For k>=1 let the input be k qubits, H_in=(C^2)^tensor k. Let the output be
A_out=direct_sum_(j=1)^k M_2, physically a classical flag j and one qubit.
Define the CPTP routing channel

 R_k(rho)=direct_sum_j [Tr_(all input qubits except j)(rho)/k].

It maps the input maximally mixed reference to
sigma_out=direct_sum_j I_2/(2k). In likelihood coordinates its j block is

 T_k(A)_j=Tr_(all input qubits except j)(A)/2^(k-1).

1. ACTUAL k-COMPATIBILITY

A k-output channel sends each input qubit to one distinct receiver and
records its input index in that receiver's classical flag. Average uniformly
over all k! permutations of the receivers. This is a mixture of unitary
routing isometries, hence CPTP. Every receiver has exactly the marginal
R_k. It is a joint redistribution of the supplied input qubits, not k
independent copies of the whole input. The marginal output has k classical
sectors, all quantum fibres dimension 2.

2. ITS DIAMOND DISTANCE TO EB IS EXACTLY 1

Feed the input halves of k Bell pairs, with all reference halves retained.
Conditionally on flag j, the routed qubit is maximally entangled with R_j;
the other reference qubits are maximally mixed. The normalized channel Choi
state is therefore

 J(R_k)=sum_j |j><j|/k tensor Bell_(R_j B) tensor I_(R_except_j)/2^(k-1).

Consider the effect

 W=sum_j |j><j| tensor Bell_(R_j B) tensor I_(R_except_j).

It has 0<=W<=I, and Tr[W J(R_k)]=1. On ANY state separable across the full
reference R and the flagged receiver, its expectation is <=1/2. Indeed,
condition on the flag and take a product term alpha_R tensor beta_B. The
Bell overlap of alpha_(R_j) tensor beta_B is at most 1/2: it equals
Tr(alpha_(R_j)^T beta_B)/2<=1/2. Convexity covers all separable states.
For an EB channel its normalized Choi state is separable, so the two-outcome
measurement {W,I-W} has probability difference at least 1/2. Consequently

 ||J(R_k)-J(E)||_1 >=1,    ||R_k-E||_diamond>=1

for every EB E, without assuming that E preserves any reference.

For the matching upper bound, measure every input qubit in its Z basis,
choose j uniformly, flag j and prepare its measured Z state. This is EB.
It equals R_k composed with full product Z dephasing. Equivalently each
flagged branch differs from R_k just by applying the single-qubit Z
dephasing D_Z to its retained qubit. For any input with an arbitrary
reference, the flagged trace-norm difference is at most

 average_j ||id_(reference) tensor (id-D_Z)(rho_(R,j))||_1 <=1,

because id-D_Z=(id-Ad_Z)/2 and the diamond distance of those two unitary
channels is at most 2. This proves distance exactly 1. The same witness and
upper bound give normalized Choi trace distance exactly 1 to the EB set.
The cost of the input is k qubits/dimension 2^k; ignoring that quantum input
size is precisely the invalid shortcut.

3. THE RELEVANT WEAK NORM VANISHES

Let E_k be the EB Z-measurement router just constructed. For a Hermitian
input contraction A, expand its one-qubit marginals using the orthonormal
normalized-trace Pauli coordinates

 a_(j,alpha)=2^(-k) Tr[A sigma_alpha^(j)], alpha=x,y,z.

The likelihood-map difference in output block j is

 (T_k-E_k)(A)_j=a_(j,x) sigma_x+a_(j,y) sigma_y.

Its normalized one-qubit trace norm is sqrt(a_(j,x)^2+a_(j,y)^2). The Pauli
operators over all j and alpha are orthonormal in input L2, so Bessel gives

 sum_j [a_(j,x)^2+a_(j,y)^2] <=||A||_2^2<=1.

Use Cauchy--Schwarz with the output reference weights 1/k:

 ||(T_k-E_k)(A)||_(1,tau_out)
  = (1/k)sum_j sqrt(a_(j,x)^2+a_(j,y)^2) <=1/sqrt(k).

Thus the normalized infinity-to-one EB distance tends to zero despite
constant Choi trace and diamond distance. There is no contradiction with
weighted quantum-fibre lifting, whose local dimensions concern INPUT
blocks, or with the true power-range gate. In particular this does not
refute an induced-norm finite-k modulus for positive selfadjoint maps.

CHECKS AND COSTS

The formal routing/entanglement/Bessel arguments cover all k. A bounded
script check_routing_boundary.py used k=1..6 (maximum input dimension 64),
16 random Hermitian contraction probes each, and checked the exact Pauli
Bessel bookkeeping and displayed weak upper bound. It did not solve an EB
optimization; the exact diamond value comes from the written witness.
The explicit extension's k! mixture is an existence expression; sampling a
uniform permutation and routing k qubits is polynomial in k, but sending
all retained reference/input-dependent registers is charged. No such
hardware experiment was performed. All source-relative novelty is UNKNOWN.

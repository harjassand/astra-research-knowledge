# Interface, costs, and unresolved gates

## Mathematical input/output contract

For the cotype transfer, the input is a finite family of actual elements \(x_i\in L_1(\Omega,\mu;\mathbb R)\), an integer \(t\), and a finite stationary stochastic chain \((A,\pi)\). The output is a finite family of actual elements \(y_i\in L_1\) satisfying the stated quadratic inequality. Reversibility is sufficient but not necessary; stationarity \(\pi A=\pi\) is the proved interface.

For the extension transfer, the input is a metric space \(X\) with a certified finite Markov type two constant \(M_2(X)\), a subset \(S\subseteq X\), and a Lipschitz map \(f:S\to L_1\) with exactly \(r<\infty\) distinct range values. The output is an extension to all of \(X\) with the universal factor shown in `DERIVATION.md`. The result is an existence theorem, not a proposed implementation.

## Representation size and metric access

The exact finite-cut representation has at most \(d=2^r-2\) oriented coordinates after zero-weight cuts are removed. It has distortion one on the range values, and its affine recovery map into the given ambient \(L_1\) target is 1-Lipschitz. The code dimension depends on range size, not on the cardinality of \(S\), ambient measure space, or dimension of \(X\).

The recovery map requires the actual L1 values: it uses their pointwise minima, maxima, positive gaps, and the integrals \(w_B=\int b_B\,d\mu\). Pairwise metric distances alone can describe some finite cut representation, but they do not supply this contractive recovery map into the original target. Thus a distance-only oracle does not instantiate the global extension construction with exact values in the supplied L1 space.

If each range value is an explicit rational vector in \(\ell_1^m\), direct cut enumeration takes \(O(mr2^r)\) arithmetic operations and \(O(m2^r)\) storage, before rational bit growth. A standard polyhedral cut-cone representation can use at most \(r(r-1)/2\) cuts for the induced metric, but this smaller representation is not shown to admit a contractive recovery map into the original target. It cannot replace the exponentially many ambient cuts without a new lemma.

## Precision and construction time

The inequalities are exact-real statements. For rational finite-coordinate inputs, cut weights and the recovery map can be built with exact rational arithmetic. For arbitrary measure spaces, exact integration and a finite description of the functions may be unavailable. No perturbation theorem is proved for approximate cuts, noisy distances, quadrature error, or finite-precision composition.

The cotype witness from the release can be written using the geometric resolvent
\[
G=(t+1)^{-1}\left(I-\frac{t}{t+1}A\right)^{-1}
\]
and the expected coordinatewise median of three independent endpoints from each row of \(G\). For rational finite matrices, this is a finite exact expression. However, bit complexity of its evaluation for arbitrary encoded inputs was not audited here. More importantly, the global extension step supplied by Mendel–Naor is nonconstructive in the sources read: its algorithm, output representation, numerical stability, and running time are `UNKNOWN`. The Markov type constant is also a supplied mathematical premise, not acquired by this construction.

## Scope limits

- The cotype conclusion is for the whole ambient \(L_1(\Omega,\mu)\), not arbitrary closed subspaces. The recovery map may leave a subspace containing the input values. The 2013 Kalton/Mendel–Naor counterexample shows why no subspace upgrade follows.
- The extension theorem covers finite-range maps. It makes no claim for arbitrary infinite-range maps into non-dual L1 targets.
- No optimality claim is made for the constant \(12\sqrt{21}\), the extension factor, or the cut dimension.
- The paper-specific cotype result is source-reported and internally reconstructed, not externally proof-checked. The transfer lemmas are internal derivations; historical priority is `UNKNOWN`.

# Exact failures of two endpoint transfers

These are internally derived counterexamples, found by the hidden-gate worker
and independently reconstructed here with rational arithmetic. Historical
priority and external mathematical review remain UNKNOWN. They retain every
assumption of the supplied finite grounded-network lifetime model; they do not
invalidate its one-edge, one-step theorem or independent-coordinate batch
theorem.

There are two transient vertices and a grounded target. Let a,b be their
respective grounded conductances and c the edge between them. For masses x,y,

    A = [[a+c,-c],[-c,b+c]],
    F = (b*x^2+a*y^2+c*(x+y)^2)/(a*b+a*c+b*c).

All conductances below are strictly positive, so every lower model is grounded
positive definite. The mean is F/(x+y); this constant cancels from every ratio.
The completion ratio for a box is F(lower)/F(upper), exactly as in the source.

## Adaptive two-query obstruction

Take x=y=1 and independent bounds

    a in [1/4,33/4], b in [8,72], c in [1/8,5/8].

After a first exact query a=t, let Q_b(t) and Q_c(t) be the worst completion
ratios after querying b or c once more. The supplied one-step theorem computes
each Q exactly by its two possible endpoint answers. Optimal continuation is
V(t)=min(Q_b(t),Q_c(t)). Exact values are:

| First answer t | Q_b(t) | Q_c(t) | V(t) |
|---|---|---|---|
| 1/4 | 588111/258635 | 86903/68471 | 86903/68471 |
| 5/4 | 1281775/961419 | 40843/30603 | 1281775/961419 |
| 33/4 | 130549/125449 | 1545975/806647 | 130549/125449 |

Thus V(5/4)=1.3332116382... exceeds both endpoint values, whose maximum is
1.2691942574.... This is possible because minimization over the next query
choice does not preserve the coordinate shape in the one-step proof.

The failure also affects the initial minimax value, rather than only an
arbitrarily selected first query. Endpoint-only two-step dynamic programming
gives worst values 86903/68471, 588111/258635, and 1545975/806647 for first
queries a,b,c respectively. It therefore selects a and reports 1.2691942574....
For the actual continuous-answer game, the interior answer above gives lower
bound 1281775/961419 for first query a. The endpoint values already give larger
lower bounds for first queries b and c. Consequently the true deterministic
two-query minimax ratio is at least 1.3332116382..., strictly above the
endpoint-only answer. The exact optimum, randomized policies, and average-case
performance are not asserted.

The source's restriction to one-step minimax is essential. A valid global
algorithm needs continuous-outcome analysis or a sound approximation with an
error bound; it cannot simply recurse on endpoint answers.

## A joint physical parameter is not a rank-one edge query

Take masses x=1/2,y=4. Measure a common parameter t in [0,1] setting

    a=1/8+128t, b=2+8t,

while c remains unresolved in [4,6]. The ratio F(a,b,4)/F(a,b,6) equals

    t=0:   2171/2170              = 1.0004608294...,
    t=1/4: 411538/347529          = 1.1841831904...,
    t=1:   1800674/1594629        = 1.1292118731....

The interior value exceeds both endpoints. The measured parameter makes a
positive rank-two update, despite having only one scalar outcome. Independent
coordinatewise batch reduction still holds; it does not reduce the diagonal
correlated parameter path to its two endpoints. Molecular perturbations
changing several rates require a separate theorem.

## Relative precision differs from fixed additive width

The hidden-gate audit proves an endpoint rule when every rate measurement
returns an interval of bounded additive width. That rule does not transfer
sharply to a multiplicative uncertainty interval. Take masses x=2,y=8,

    a in [1,2], b in [1/8,513/8], c in [8,10].

Query b with legal interval [s,4s], s in [1/8,513/32]. The completion ratio is

    R(s)=2(s+216)(12s+5)/((2s+141)(9s+8)).

It is 89908/41245 at the left interval, 1421100/408889 at the right interval,
and 5698/1581 at the interior interval [6,24]. The latter is strictly larger
than both endpoints. The independent checker directly evaluates each ratio
from the grounded matrix, then verifies the displayed rational formula.
The audit gives a corrected finite candidate rule using stationary points of
this degree-two rational function. A coarser additive-width reduction remains
valid if the relative sensor implies an absolute width bound, but it need not
be sharp. Actual confidence-interval coverage and acquisition cost remain
separate physical/statistical obligations.

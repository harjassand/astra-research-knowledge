- Model pp5-7: fixed finite state set, finite signal alphabet, positive probabilities, every state pair identified; iid samples from a known experiment; state-independent auxiliary randomness; finite terminal output; stopping time integrable in every state.
- Theorem 1 p8: for KL-generic F/G (all ordered pair rates unequal), strict dominance of every directed pairwise KL is equivalent to both small-cost dominance in every finite decision problem and large-budget exact stopping-output dominance. Decision cost cutoff may depend on the decision problem; budget threshold is uniform over all finite terminal experiments.
- Theorem 2 p9: each finite-output stopping G-policy has one exact F reproduction with E_i N <= rho_i E_i T + C_FG sqrt(E_i T), rho_i=max_{j!=i} I_ij(G)/I_ij(F). Constant independent of policy and output cardinality. This is an author theorem; its full proof is assigned elsewhere and is NOT independently validated by this prior-art worker.

Lemma 8 pp34-36 uses known classification matrix A_n and known target rows R to form A_n^{-1}R. - §1.1 pp4-5 expressly separates fixed source comparison from adaptive experiment selection. Conclusion pp15-16 leaves adaptive multiple sources as a further allocation problem. No theorem there settles controlled-source menus.

## Our independently derived controlled-menu obstruction

A tempting extension is to replace each source rate with max_u D(P_i^u||P_j^u). That is false, even for full-support Bernoulli observations and all six strict pairwise inequalities.

States i=0,1,2. Source actions have Bernoulli success vectors a=(0.5,0.01,0.49), b=(0.5,0.49,0.01). Target fixed source has G=(0.5,0.04,0.041). Every single action identifies every pair. Let d(p,q)=p log(p/q)+(1-p)log((1-p)/(1-q)). The saved script checks all six separately maximized source rates strictly exceed G's rates.

But source state0 row sum is constant across actions:

s=d(0.5,0.01)+d(0.5,0.49)=1.614663120371521.

Target state0 row sum is

g=d(0.5,0.04)+d(0.5,0.041)=1.8615782567626016.

For any randomized adaptive source policy with integrable stop N, let n_a=E_0 sum_{t<=N}1{U_t=a}, n_b similarly. Action-selection kernels and auxiliary randomness are state independent, so the stopped-transcript likelihood ratio is the product of observation likelihood ratios. Bounded increments justify the stopped KL chain rule:

D(L_0(transcript)||L_j(transcript)) = sum_u n_u D(P_0^u||P_j^u).

For exact reproduction of output G^{tensor m}, data processing gives m I_0j(G) <= sum_u n_u D(P_0^u||P_j^u), j=1,2. Summing both inequalities yields

m g <= s(n_a+n_b)=s E_0 N.

The crucial strict inequality g>s is exact: s=(1/2)log(6250000/247401), g=(1/2)log(156250000/3774624); it reduces to 25*247401=6185025>3774624. All six coordinate inequalities can also be certified without floating-point reliance: d(.5||q) strictly decreases on q<.5 and d(p||.5) strictly decreases on p<.5, proving four directions. For the remaining two directions, Pinsker gives d(.49||.01)>=2(.48)^2=.4608, whereas log(x)<=x-1 gives d(p||q)<= (p-q)^2/[q(1-q)]<.000027 for p,q in {.04,.041}.

Thus E_0 N >=1.152920527679029 m for EVERY integer m>=1. This is a universal obstruction proved by information accounting; numerical calculations only instantiate the strict inequalities. Adaptive actions, randomized stopping, and exact output garbling cannot evade it.

Correct necessary geometry: for each true state i the target rate vector must lie in the downward closure of the source convex hull, after the desired sample/cost rescaling. For fixed target G and desired factor r, necessary is existence of one q_i with r sum_u q_i(u)d_ij^u >= g_ij simultaneously in j. Equivalently r_i* = min_q max_j g_ij/(sum_u q(u)d_ij^u). This uses a single q for the row, not a separate maximizer per pair. For a controlled target the relevant target set has its own occupation-mixture region; pointwise pair maxima again discard necessary coupling. Necessity alone does not prove uniform exact conversion sufficiency.

## Independent lower bound for the proposed controlled-source factor

With positive action costs c_u, define c(q)=sum_u q(u)c_u. Exact reproduction of G^{tensor m} gives m g_ij <= sum_u E_i N_u d_ij^u simultaneously in j. With q_i(u)=E_i N_u/E_i N, expected cost/m is at least c(q_i) max_j g_ij/d_ij(q_i), hence at least inf_q c(q) max_j g_ij/d_ij(q). This derives the proposed optimized factor as a necessary universal conversion rate, including finite m. Source occupation counts automatically produce one mixture per row. It is first-order sharp only if the independent exact-conversion sufficiency construction under audit succeeds. For unequal source costs, using max_j g_ij/d_ij(q) without c(q) miscounts resources.

## Unknown-model obstruction

KL dominance alone does not make the known-law implementation learnable. Without labeled calibration or an orientation assumption, let worldA source rows be Bern(.2),Bern(.8), worldB swap these rows, while desired target rows remain Bern(.3),Bern(.7). In both worlds source KL dominates target in both directions. One law-independent procedure receives identical streams under (A,state0) and (B,state1), hence identical terminal-output laws. Exact reproduction would require distinct Bern(.3) and Bern(.7) laws. Impossible. This does not deny Bernoulli-factory constructions when the parameter relationship is supplied; it isolates unavailable semantic alignment.

## Novelty and consequence verdict

A strict adaptive-vs-fixed known-finite-menu gain theorem is classical. A general extension preserving EVERY finite terminal output exactly, uniformly over target stopping policies/output sizes, with optimized statewise source mixtures and a lower-order remainder could be new relative to sources inspected. It is not established merely by plugging the classical d_i* rate into Li-Liu. Exact repair, dependence on arbitrary H, error accumulation, and policy-uniform remainder remain load-bearing proof obligations. Greenshtein/Torgersen full text and broader experiment-simulation prior art remain to be checked before a novelty claim.

Credible narrow use: compare calibrated repeatable sensors/assays for all later finite decisions, avoiding optimizing separately for each task. Consequential scientific benefit requires a real supplied finite candidate family, repeatability, calibrated laws, adequate asymptotic budget, implementable policy, and full calibration/computation/sample cost. None is delivered by a known-table asymptotic gain example.

Next falsifiable step: prove or refute controlled-source exact finite-experiment reproduction using one state-conditioned row mixture, then establish uniform policy conversion. Test candidate theorem against the convex-hull witness above; a proposed criterion using pairwise source maxima fails immediately. For unknown models, explicitly add charged labeled calibration and an approximate/robust target-law contract before claiming application.

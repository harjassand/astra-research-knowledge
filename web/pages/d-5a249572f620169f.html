GAMES/HAMILTONIANS CYCLE 2 — DECODER-DERIVED HDX/qLTC ROUTE
Date: 2026-10-08
Status: INTERNALLY-PROVED-CANDIDATE for the architecture-specific statements below; BMVZ, BJSW, and qLTC theorem claims are SOURCE-REPORTED. This is not a no-go for arbitrary common encodings.

DECISION

For the actual BMVZ derandomized tensor-product generator, each path clause has a useful positive sparse lift in a layer-decoded basis. In fact the exact OR can be replaced by a positive Chebyshev approximate-OR with constant operator comparison and one nonzero per row. A common qLTC isometry can be inserted before the branch label and the same lift is available in the qLTC decoder coordinates, with the costs stated below.

The obstruction is the *common-image* constraint. A decoder penalty that checks only whether the qLTC syndrome is nonzero has kernel equal to the direct sum of the valid color branches, not the coherent image of the one common isometry. Any exact enforcer in the common decoder-coordinate representation must couple distinct color bases. The actual five-qubit BJSW seed pair is noncommuting, so the relative layer decoder is a non-monomial Clifford. Tensoring it over t BMVZ copies makes a row-level coherence certificate exponential in t. This rules out the proposed decoder-only/block-diagonal route and the direct coherent branch enforcer in decoder coordinates; it does not rule out a different encoding that makes both the logical lifts and the coherence checks sparse.

1. ACTUAL GENERATOR AND A TERMWISE POSITIVE LIFT

BMVZ’s input is layered:

    H = sum_chi w_chi H_chi,
    H_chi = average_{i in [m_chi]} Pi_i^chi,

where each layer consists of commuting projections. For a d-regular undirected graph G_chi on the terms, a path f=(f(1),...,f(t)) gives the amplified projection

    h_f^chi = I - tensor_{j=1}^t (I - Pi_{f(j)}^chi),
    H^(t) = sum_chi w_chi average_{f in F_chi} h_f^chi.

There are m_chi d^(t-1) walks under the usual start-vertex/edge convention (the paper states d^t m_chi up to its path-length convention). The total path list is polynomial in the base input when t=O(log n) and d,g are constants. Every Pi in the BJSW 5-LCH seed is a rank-one five-qubit Clifford stabilizer projector. Within each color chi the projectors commute, so their Pauli stabilizer generators extend to a common maximal commuting Pauli group. Symplectic Gaussian elimination produces a Clifford U_chi that makes all Pi_i^chi diagonal. Its circuit and description have polynomial size in the base instance.

On t copies, the path projectors commute. Let S_f=sum_j Pi_{f(j)}^chi. Its spectrum is {0,...,t}, and h_f^chi is the spectral projector 1[S_f>0]. Put d_t=ceil(sqrt(t-1)) for t>=2 and define the rational polynomial

    q_t(s) = 1 - ( T_{d_t}((t+1-2s)/(t-1)) / T_{d_t}((t+1)/(t-1)) )^2,

where T_d is the Chebyshev polynomial. Set q_1(0)=0, q_1(1)=1. The scalar bounds are

    q_t(0)=0,
    c0 <= q_t(s) <= 1       for integer 1<=s<=t,
    c0 = tanh(sqrt(2))^2 > 0.789.

Reason: for 1<=s<=t the Chebyshev argument is in [-1,1], hence |T_d|<=1; at s=0 it is (t+1)/(t-1)=cosh(2 asinh(1/sqrt(t-1))). The denominator is at least cosh(sqrt(2)) for d=ceil(sqrt(t-1)); thus the nonzero values are at least 1-sech(sqrt(2))^2=c0. It follows by functional calculus that

    c0 h_f^chi <= Q_f^chi := q_t(S_f) <= h_f^chi.

This is a positive contraction; it does not use a signed Hamiltonian decomposition. In the U_chi^tensor-t basis Q_f^chi is diagonal. Therefore the branch operator

    B_dec = direct_sum_chi average_{f in F_chi} Q_f^chi

is a positive contraction with at most one nonzero per row, and its compression through

    V0 |psi> = sum_chi sqrt(w_chi) |chi> tensor U_chi^tensor-t |psi>

satisfies the exact comparison

    c0 H^(t) <= V0* B_dec V0 <= H^(t).

These inequalities hold termwise before averaging. Thus the BMVZ path generator, including its actual five-qubit terms and O(log n)-length paths, has an explicit constant-factor positive logical lift in the *color-decoded branch basis*.

Access and precision: for a row label (chi,z), enumerate the BMVZ paths f and compute the t-bit violation count |{j: Pi^chi_{f(j)}(z)=1}|. Evaluate q_t at that integer by the three-term Chebyshev recurrence. This uses O(|F_chi| t + |F_chi| sqrt(t)) arithmetic operations in the direct exact implementation and O(log |F_chi| + sqrt(t) log t) bits for the common rational values and averaging denominator, after the path generator is fixed. With |F_chi|=m_chi d^(t-1), fixed d,g and t=O(log n), this is polynomial in n; a path can also be sampled in O(t) random choices, but exact row values use a full path average unless a separate averaging algorithm is supplied. Logical row sparsity is one. If the code has N physical qubits and K logical qubits, choose K>=nt (freeze unused logical bits to zero if needed), synthesize a CSS Clifford encoder/decoder from its check matrices by Gaussian elimination in O(N^3) elementary Clifford gates, and use B_dec in the decoder coordinates with syndrome register fixed at zero. These code and gate costs do not prove that conjugating B_dec back to the physical CSS basis is sparse.

2. EXACT FAILURE OF A SYNDROME-ONLY INVALID PENALTY

Let E be one common stabilizer-code isometry, with decoder coordinates H_syn tensor H_log in which E|psi>=|0^s>_syn tensor |psi>_log (and any frozen logical ancillas are also zero). In the color-branch space, the proposed coherent image is

    V|psi> = sum_chi sqrt(w_chi) |chi> tensor |0^s> tensor U_chi^tensor-t |psi>.

The natural global decoder penalty is

    C_syn = I_branch tensor (I - |0^s><0^s|) tensor I_log.

It is a positive contraction, has row support one in decoder coordinates, and has a unit gap against nonzero syndrome. But

    ker C_syn = direct_sum_chi (|chi> tensor |0^s> tensor H_log),

which contains every individual valid branch vector |chi>|0^s>U_chi^tensor-t|psi>. Those branch vectors are generally outside ran(V). Hence C_syn does not satisfy C_syn >= gamma(I-VV*) for any gamma>0. More generally, any penalty block diagonal in chi that vanishes on every valid code branch has this same failure: it annihilates the whole direct sum, so it cannot penalize incoherent branch combinations. This is exact and independent of the qLTC soundness, HDX expansion, decoder runtime, or code distance.

3. NECESSARY COHERENCE COST IN THE COMMON DECODER BASIS

For clarity, first consider two color bases U_0,U_1 with positive weights and the common decoder-coordinate isometry

    V|psi> = sqrt(w_0)|0>|0^s>U_0^tensor-t|psi>
             + sqrt(w_1)|1>|0^s>U_1^tensor-t|psi>.

Compress any proposed enforcer C to the coordinate code sector P0=I_branch tensor |0^s><0^s| tensor I_log: C0=P0 C P0. Since P0 is diagonal, row sparsity cannot increase. The target inequalities imply

    C0 V = 0,
    C0 >= gamma(P0 - VV*) on ran(P0).

Thus C0 is nonzero and has a nonzero row. In the logical computational basis, rows of V from a fixed branch are orthogonal. A normalized row from branch 0 and one from branch 1 have inner product bounded by

    mu_t = max_{a,b} |(U_0 U_1*)^tensor-t[a,b]|.

If a set of s normalized rows has pairwise cross-branch inner products at most mu_t and same-branch inner products zero, its Gram matrix has diagonal one and off-diagonal magnitudes at most mu_t. Gershgorin makes it positive definite when (s-1)mu_t<1. Therefore no such rows are linearly dependent below support 1+1/mu_t. A nonzero row of C0 annihilates V, so its coefficients give such a dependence. Every exact enforcer in these decoder coordinates consequently has

    row_support(C) >= ceil(1 + 1/mu_t).

This argument extends after merging color branches with monomial-equivalent decoders; because the number g of BMVZ layers is constant, the constant-size branch basis changes affect the row bound by at most a factor depending on g.

The actual five-qubit seed pair supplies the incompatibility. In the BJSW 5-LCH propagation terms, the two Clifford stabilizer states

    phi_3 = |-> tensor |00>,
    psi_3 = (|000>-|011>-|101>-|110>)/2

with the same two-qubit clock pattern |10> give five-qubit seed states with |<phi_5,psi_5>|=1/(2 sqrt(2)). Their rank-one projectors therefore neither commute nor coincide. They cannot lie in one commuting color layer, so BMVZ places them in different layers. A monomial relative Clifford would preserve the diagonal algebra, forcing the two layer projectors to commute; hence U_0 U_1* is non-monomial. For a Clifford matrix all nonzero entries have one magnitude 2^(-r/2), where r is its binary Fourier/symplectic support rank. Non-monomial implies r>=1, so mu_1<=1/sqrt(2) and

    mu_t <= 2^(-t/2),
    row_support(C) >= 1 + 2^(t/2)

for the direct common-decoder branch route. This remains exponential when a common CSS/qLTC isometry E is appended to every branch and then read in its decoder coordinates: E cancels from the logical row system. A branch-dependent code decoder can evade this statement only by changing the logical lifts; no such lift is provided by qLTC parameters.

For g>2, first quotient the constant number of branches by monomial-equivalent U_chi. If g' distinct classes remain, any two distinct class bases have non-monomial relative Clifford and hence cross-coherence <=2^(-t/2). Project C to the span of one branch combination per class. A constant-dimensional branch compression can inflate row support by at most O(g^2), so the same argument gives an exponential lower bound Omega(2^(t/2)/g^2), provided the BJSW incompatible pair occurs among the amplified color classes. The source guarantees the pair in the 5-LCH input, but I did not reconstruct BMVZ's full color assignment for a specific final iterated instance; the unconditional two-color lemma is the exact certificate, and membership in a selected output's two-class quotient remains a finite source-table check.

4. PHYSICAL-BASIS COST AND SCOPE

The one-nonzero row claims above are in the code-decoder basis. Returning to the physical CSS basis conjugates C_syn and B_dec by the code encoder. No cited HDX/qLTC theorem supplies polynomial-row access for those conjugated operators or the required two-sided comparison for the actual noncommuting color family. A generic N-qubit Clifford circuit with h Hadamard-type gates only gives the crude row bound 2^h; it is not a polynomial row bound. For the standard CSS projector, the exact stabilizer expansion is

    P_code = 2^(-s) sum_{g in S} g.

In the natural computational basis, each row has at most 2^(rank H_X) support points (and has that many on compatible Z-syndrome rows); the global Hadamard basis replaces rank H_X by rank H_Z. This is an access warning for those natural bases, not a lower bound for every Clifford basis or every code.

What is proved: (i) a constant-factor positive diagonal lift for every individual BMVZ path term in its commuting-layer decoder basis, with an explicit polynomial path-enumeration oracle when the output term list is polynomial; (ii) syndrome-only penalties cannot enforce the coherent color superposition; and (iii) the direct common-decoder coherence enforcer has exponential row support when the incompatible BJSW seed pair is represented on t repeated copies. What is not proved: impossibility of a different code, a history-state/HDX construction with off-diagonal branch relations, branch-dependent isometries, or a global sparse positive operator that uses cancellations outside the termwise decoder route. The qLTC decoder and HDX expansion statements alone do not provide such a construction.

PRINCIPAL-HEIGHT PBW CAPS: ALL-RANK UPPER PROFILE FOR REGULAR SU(m)
Date: 2026-10-08
Status: internally derived construction and finite algebra checks; no lower-profile or novelty claim.

1. Scope and target
-------------------

Fix m>=2 and a regular SU(m) highest weight with Dynkin labels

  lambda=(a_1,...,a_(m-1)),   N<=a_r<=2N,

where N is an integer satisfying N>=40 p h, with

  p=|Phi^+|=m(m-1)/2,   h=m-1.

Write d=dim V_lambda and use Hermitian generators normalized by
Tr_fund(T_A T_B)=delta_AB/2. Define

  E(X)=sum_A ||[T_A,X]||_HS^2.

This note constructs positive-semidefinite witnesses for both ends of the
rank range. It proves upper bounds only:

  inf_{X!=0, rank X<=Q} E(X)/||X||_HS^2
      <= C_m (d/Q)^(1/p),                         1<=Q<=floor(d/2),

and for m>=3,

  inf_{X>=0, X!=0, rank X<=d-k} E(X)/||X||_HS^2
      <= C'_m (k/d)^((p-1)/p),                    1<=k<=floor(d/2).

For m=2 (p=1), the near-full branch is logarithmic:

  inf_{X>=0, X!=0, rank X<=d-k} E(X)/||X||_HS^2
      <= C'_2 / log(e d/k),                       1<=k<=floor(d/2).

All constants are explicit below and depend only on m. These are
constructive variational upper bounds. No lower profile, optimizer claim,
or transfer to an operational score is inferred here.

2. Principal height and the stable PBW cap
------------------------------------------

Use the principal Cartan element

  H_0=diag((m+1-2i)/2 : 1<=i<=m).

For a positive root alpha_ij=e_i-e_j (i<j), its H_0-height is
ell=j-i. Put lambda_i=sum_(r=i)^(m-1) a_r and lambda_m=0, so
lambda_i-lambda_j=sum_(r=i)^(j-1) a_r. A weight mu in V_lambda has
principal depth

  q=<lambda-mu,H_0> in {0,1,2,...}.

Let W_q be the full H_0-weight shell at depth q and g_q=dim W_q. The
root-height generating function for the stable cap is

  F_m(z)=prod_(ell=1)^(m-1) (1-z^ell)^(-(m-ell))
        =sum_(q>=0) g_q^PBW z^q.                   (1)

There are m-ell positive roots of height ell. In particular

  g_q^PBW=[z^q]F_m(z),
  V_r^PBW=sum_(q=0)^r g_q^PBW.

These are exact carrier shell counts for every 0<=q<=N. Indeed, the
Kostant multiplicity formula for mu=lambda-beta is

  mult_lambda(lambda-beta)
   =sum_(w in W)(-1)^length(w) P(beta-(lambda+rho-w(lambda+rho))),

where P is the positive-root partition function. The identity Weyl term is
P(beta), whose generating function is (1). If w!=1, the shift
delta_w=lambda+rho-w(lambda+rho) is a nonzero positive-root combination.
For any positive root alpha_ij,

  <lambda+rho, alpha_ij^vee>
      =sum_(r=i)^(j-1)(a_r+1)>=(j-i)(N+1).

The inversion-set formula for delta_w therefore gives ht(delta_w)>=N+1.
When ht(beta)=q<=N all nonidentity terms vanish. This is the stable PBW
range; no symmetric-power occupation formula is used.

For volume estimates, let h=m-1. Since every positive-root height is in
[1,h], the number of p-tuples of root occupations with total height at
most r obeys

  (r/(p h))^p <= V_r^PBW <= binom(r+p,p).          (2)

The lower bound follows by taking every occupation between 0 and
floor(r/(p h)); the upper bound forgets the root heights and counts all
nonnegative p-tuples with unweighted sum at most r. In particular

  V_r^PBW <= (r+p)^p,
  V_r^PBW <= (p+1)^p r^p  (r>=1).

Weyl's dimension formula gives the useful carrier comparison

  d=prod_(i<j) (lambda_i-lambda_j+j-i)/(j-i),
  (N+1)^p <= d <= (2N+1)^p <= (3N)^p.              (3)

3. Exact all-root shell traces and crossing conductances
--------------------------------------------------------

For alpha_ij=e_i-e_j, set

  L_ij=lambda_i-lambda_j=sum_(r=i)^(j-1)a_r,
  A_(kl,ij)=<alpha_kl,alpha_ij^vee>
             =delta_(k,i)-delta_(k,j)-delta_(l,i)+delta_(l,j).

For a stable PBW monomial beta=sum_(k<l)n_kl alpha_kl, the H_ij=e_i-e_j
eigenvalue is

  <lambda-beta,alpha_ij^vee>
       =L_ij-sum_(k<l)n_kl A_(kl,ij).

Let s_ij(q)=Tr_(W_q)(E_ii-E_jj). The all-root trace identity, valid for
0<=q<=N, is the coefficient formula

  s_ij(q)=[z^q] F_m(z) [ L_ij
                 -sum_(k<l) A_(kl,ij) z^(l-k)/(1-z^(l-k)) ].       (4)

It follows by marking one root occupation in the product (1): for a root
alpha_kl, its total occupation generating function is
F_m(z) z^(l-k)/(1-z^(l-k)). Formula (4) is an exact finite coefficient
identity, not an asymptotic estimate.

Now define the source-shell crossing conductance

  c_ij(q)=Tr_(W_q)(E_ji E_ij),

so E_ij sends depth q to q-(j-i). Write ell=j-i. The commutator
[E_ij,E_ji]=E_ii-E_jj, unitarity E_ij^*=E_ji, and cyclicity of trace
between W_q and W_(q-ell) give the exact recurrence

  c_ij(q+ell)-c_ij(q)=s_ij(q),
  c_ij(q)=0 for 0<=q<ell,

and hence, throughout the full representation,

  c_ij(q)=sum_(t>=1, q-t ell>=0) s_ij(q-t ell).   (5)

This reconstructs every positive-root conductance separately. For q<=N/4,
each PBW state beta at depth q has at most q root factors and
|<beta,alpha_ij^vee>|<=2q, because A_(kl,ij) is in {-1,0,1,2} and
sum n_kl<=q. Since ell N<=L_ij<=2ell N, (4) gives

  (ell N/2) g_q <= s_ij(q) <= (5ell N/2) g_q.    (6)

Set c_1(q)=sum_(i=1)^(m-1)c_(i,i+1)(q), the combined conductance for
the simple roots, which all step one shell. Equations (5)-(6), for q in
the stable range, imply

  (N/2)V_(q-1) <= c_1(q)
      <= (5/2)(m-1)N V_(q-1),                    (7)

  c_ij(q) <= (5ell N/2)V_(q-ell)              (q>=ell).       (8)

With T_ij^(1)=(E_ij+E_ji)/2 and
T_ij^(2)=(E_ij-E_ji)/(2i), the pair of Hermitian root generators
contributes exactly

  sum_q c_ij(q) |f(q)-f(q-ell)|^2

to E(f(H_0)); the two directed matrix entries of one undirected root edge
are thereby counted once, with no extra factor of two.

The upper bound (8) remains valid for root edges whose source depth is up
to M+ell-1 whenever M+h<=N: its trace sum (5) only uses stable shells
through depth M-1.

For a uniform all-root taper comparison, define

  Gamma_m=max{ binom(2h+p,p), [2 p h (p+1)]^p }.

If q>=ell and q-ell+1<=j<=q, (2) gives
V_q<=Gamma_m V_(j-1): for q<2h use the first term in Gamma_m; for q>=2h,
j-1>=q-h>=q/2, and use the box lower bound in (2). Combining (7)-(8),

  c_ij(q) <= 5 ell Gamma_m c_1(j).                (9)

This is the only comparison needed for long roots; the simple-root taper
itself is exact.

4. Low-rank cap ramp and all-Q coverage
---------------------------------------

Put M0=floor(N/4). For any integer 1<=R<=M0, define

  F_R|_(W_q)=(1-q/R)_+.

It is positive semidefinite and has exact rank V_(R-1), since it is
strictly positive precisely on q<R. With

  W_m=sum_(ell=1)^h (m-ell)ell^3,

the exact root energy is bounded using (8). For a root of height ell,
only R source shells can cross the support boundary; each difference is
at most ell/R and each conductance is at most
(5ell N/2)V_(R-1). Therefore

  E(F_R) <= (5/2) W_m N V_(R-1)/R
          <= (5/2) W_m (p+1)^p N R^(p-1).        (10)

For the norm, F_R>=1/2 on 0<=q<=floor(R/2). The box lower bound (2),
with the q=0 state handling small R, gives the uniform explicit estimate

  ||F_R||_HS^2 >= R^p/[4(4ph)^p].                (11)

Thus, with

  L_m=10 [4ph(p+1)]^p W_m,

  E(F_R)/||F_R||_HS^2 <= L_m N/R.                 (12)

Integer rounding covers every low-rank budget. Let
q0=V_(M0-1). If 1<=Q<q0, choose the largest R<=M0 such that
V_(R-1)<=Q. Then V_R>Q and (2) implies

  R > Q^(1/p)/(p+1).

Equations (3),(12) give a ratio at most L_m(p+1)(d/Q)^(1/p). If
q0<=Q<=floor(d/2), use the single fixed ramp F_(M0), whose rank q0 is
at most Q. Since M0>=N/8, its ratio is at most 8L_m, and
(d/Q)^(1/p)>=1. Hence the first all-Q claim holds, for example with

  C_m=L_m max{p+1,8}.                              (13)

The whole-shell rank is deliberately allowed to be below Q; no exact
rank-Q assertion is made.

5. Near-full harmonic cap for p>=2
----------------------------------

Use M=M0=floor(N/4). Let r_*=floor(M/2) and

  k0=V_(r_*-1).

For 1<=k<=k0 choose the least R>=0 with V_R>=k and put B=R+1. Then
R<r_*, B<=M/2, and nullity rounding is exact in the required direction:
the filter below has nullity V_R>=k and rank d-V_R<=d-k. Define

  rho=sum_(j=B)^M 1/c_1(j),

  alpha_q=1                                  (q<=R),
          rho^(-1)sum_(j=q+1)^M 1/c_1(j)     (R<q<M),
          0                                  (q>=M),
  X=I-A,  A|_(W_q)=alpha_q.

This is positive semidefinite, with ||X||_HS^2>=d-V_(M-1)>=d/2. Indeed,
V_(M-1)<=binom(M-1+p,p)<=(M+p)^p<=(N/2)^p<=d/2 under N>=40ph.
Its simple-root energy is exactly

  E_1(X)=sum_(j=B)^M c_1(j)(alpha_(j-1)-alpha_j)^2=1/rho.       (14)

For a root of height ell, alpha_(q-ell)-alpha_q is a sum of ell
consecutive one-step increments. By Cauchy--Schwarz and (9), its energy
is at most 5 ell^3 Gamma_m E_1(X). Summing all nonsimple roots gives

  E(X) <= A_m/rho,
  A_m=1+5 Gamma_m sum_(ell=2)^h (m-ell)ell^3.     (15)

For a lower bound on rho, (7),(2) give

  c_1(j) <= C_s,m N j^p,
  C_s,m=(5/2)(m-1)p^p.

Since B<=M/2 and p>=2,

  rho >= [1-2^(1-p)]/[C_s,m(p-1)N B^(p-1)].     (16)

Also k>V_(R-1)>=( (R-1)/(ph) )^p, so
B=R+1<=(ph+2) k^(1/p). Combining (14)-(16), the norm bound, and
N/d^(1/p)<=1 yields

  E(X)/||X||_HS^2 <= C_small,m (k/d)^((p-1)/p),

  C_small,m=2 A_m C_s,m (p-1)(ph+2)^(p-1)/(1-2^(1-p)).     (17)

The stable cap covers a definite, explicit fraction of d. Since
N>=40ph, r_*-1>=N/20; by (2),(3),

  k0/d >= epsilon_m,   epsilon_m=(60ph)^(-p).    (18)

This same volume estimate gives V_(M-1)<=d/2 for the taper norm.

6. Moderate-nullity Cartan patch and endpoint coverage
------------------------------------------------------

For k>k0 up to floor(d/2), use the global positive-part filter

  X_H=(-T_(H0)/L)_+,
  L=<lambda,H0>=sum_(r=1)^(m-1) a_r r(m-r)/2.

The longest Weyl element sends H0 to -H0, so the spectrum is symmetric
and rank(X_H)<=d/2<=d-k. Let

  s0_m=||H0||_fund^2=m(m^2-1)/12.

With C2(lambda)=<lambda,lambda+2rho>/2 and roots of squared length 2,

  N^2 s0_m/2 <= C2(lambda) <=4N^2 s0_m,
  N s0_m <= L <=2N s0_m.

In the stated generator normalization,

  Tr(T_(H0)^2)=d C2(lambda) m/6.

Symmetry therefore gives

  ||X_H||_HS^2=Tr(T_(H0)^2)/(2L^2)
       >= d/[8(m^2-1)].                           (19)

For each positive root alpha_ij, the function x ->(-x/L)_+ is
1/L-Lipschitz and the root changes H0-weight by ell=j-i. The trace mass
of all positive-root pairs is at most d C2(lambda), since it is a
positive part of the quadratic Casimir trace. Hence

  E(X_H) <= h^2 d C2(lambda)/L^2,
  E(X_H)/||X_H||_HS^2 <= C_H,m,
  C_H,m=384(m-1)^2/m.                             (20)

By (18), (20) is at most

  C_H,m epsilon_m^(-(p-1)/p) (k/d)^((p-1)/p)

for every k>k0. Together with (17), this proves the near-full all-k upper
bound with the explicit constant

  C'_m=max{C_small,m, C_H,m epsilon_m^(-(p-1)/p)}. (21)

This patch is PSD and uses the same principal Cartan direction; it closes
the intermediate nullity interval not reached by the stable PBW cap.

7. The p=1 case: SU(2) and its logarithmic taper
-------------------------------------------------

For SU(2), write n=a_1 in [N,2N], d=n+1. The principal-depth shells
q=0,...,n are all one-dimensional, and the single exact conductance is

  g_q=1,  s(q)=n-2q,  c(q)=q(n-q+1).              (22)

The conductance follows by summing s(p) from p=0 to q-1. It is exact
through the bottom of the representation, unlike the PBW-only formulas
needed for m>=3.

The low-rank ramp F_R(q)=(1-q/R)_+ has rank R,

  ||F_R||_HS^2=(R+1)(2R+1)/(6R)>=R/3,
  E(F_R)=R^(-2)sum_(q=1)^R q(n-q+1)<=d.

Taking R=min(Q,floor(N/4)) and using the fixed ramp once Q>=floor(N/4)
gives the low-rank bound with C_2=72.

For the near-full branch put M=floor(n/2), k0=floor(M/4). For k<=k0,
the nullity cap is exact: R=k-1. Use the same harmonic profile from q=k
to q=M. Its exact resistance is

  rho=sum_(j=k)^M 1/[j(n-j+1)]
      =1/d sum_(j=k)^M (1/j+1/(d-j)).          (23)

Since k<=M/4, the first harmonic sum in (23) is at least
log((M+1)/k), and d<=2(M+1). Thus

  rho >= log(e d/k)/(3d),
  ||X||_HS^2 >= d-M >=d/2,
  E(X)/||X||_HS^2 <= 6/log(e d/k).                (24)

For k>k0, k/d>=1/48 (N>=40), so the global Cartan filter (20) patches
the remaining interval with constant C_H,2 log(48e). Therefore one may
take

  C'_2=max{6,192 log(48e)}.                       (25)

The logarithm arises from the exact one-dimensional resistance sum; it
does not come from a formal p->1 limit of the power-law estimate.

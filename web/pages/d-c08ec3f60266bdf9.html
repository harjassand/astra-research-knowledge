Model and phase gauge
--------------------
For F in Q(i)^(n by n), signs s_i in {+1,-1}, and unit phases gamma_i, set

  A_{s,gamma}(F) = diag(s_i gamma_i) F - F^T diag(s_i gamma_i),
  X_k(s;gamma) = sum_{|R|=2k} |Pf(A_{s,gamma}(F)[R])|^2,
  c_k(F) = sum_{|I|=|J|=k, I intersect J=empty} |det F[I,J]|^2.

The c03_l10/c03_s02 exterior-power identity writes each Pfaffian as
  Pf(A[R]) = sum_{S subset R, |S|=k} d_(R,S) chi_S(s),
where |d_(R,S)|^2=|det F[S,R\S]|^2. Under the twist, each term becomes
d_(R,S) gamma_S chi_S(s), gamma_S=product_(i in S) gamma_i. Since
|gamma_S|=1, character orthogonality gives

  E_s X_k(s;gamma)=c_k(F),
  0 <= X_k(s;gamma) <= C_k c_k(F),
  E X_k(s;gamma)^2 <= C_k c_k(F)^2,
  C_k=binom(2k,k).

The pointwise estimate is the same complex Cauchy--Schwarz argument as the
unphased estimator: for each R there are at most C_k terms, and their
coefficient-square sum is the corresponding part of c_k. Thus a site phase
twist preserves unbiasedness and the universal second-moment cap, but does not
by itself improve that cap. It can change the actual variance through
interference between Fourier coefficients.

More explicitly, let gamma_S=product_(i in S) gamma_i and define, for every
Boolean character Q,

  b_Q(gamma) = sum_(|R|=2k) sum_(S,T subset R, |S|=|T|=k, S triangle T=Q)
                  d_(R,S) conjugate(d_(R,T)) gamma_S conjugate(gamma_T).

Then X_k(s;gamma)=sum_Q b_Q(gamma) chi_Q(s), b_empty=c_k(F), and reality of
X makes these Fourier coefficients real. Parseval gives the exact general-k
variance classification

  Var_s X_k(s;gamma) = sum_(Q != empty) |b_Q(gamma)|^2.

Thus a phase choice changes only the grouped cross-character coefficients;
the diagonal coefficient and mean remain fixed. The k=1 graph condition
below is the simplification of this formula where each nonempty Q is one
two-site edge character.

There is also a target-preserving row/column gauge. For diagonal unitary
matrices D_rho,D_kappa, put F'=D_rho F D_kappa. Each physical minor obeys
  det F'[I,J]=(product_(i in I) rho_i)(product_(j in J) kappa_j) det F[I,J],
so c_k(F')=c_k(F). With gamma_i=rho_i/kappa_i,

  A_s(F')=D_kappa A_(s gamma)(F) D_kappa.

For each principal R, congruence multiplies its Pfaffian by
product_(i in R) kappa_i, a unit scalar; hence X_k(s;F')=X_k(s;gamma;F).
This identifies diagonal row/column gauge choice with phase preconditioning of
the Pfaffian estimator. Exact execution is immediate for encoded phases such
as Q(i) units; arbitrary real phases need not be available in the input field
or the exact finite-bit implementation.

Exact k=1 variance and phase-frustration criterion
--------------------------------------------------
Write g_ij=F_ij conjugate(F_ji), for i<j. Since the disjoint 1-minors are
exactly the off-diagonal entries, c_1=sum_(i<j)(|F_ij|^2+|F_ji|^2). Expanding
the size-two Pfaffians gives

  X_1(s;gamma) = c_1 - 2 sum_(i<j) Re(gamma_i conjugate(gamma_j) g_ij) s_i s_j,
  Var X_1 = 4 sum_(i<j) [Re(gamma_i conjugate(gamma_j) g_ij)]^2.

The products s_i s_j for distinct unordered edges are orthogonal under the
uniform sign measure, which proves the variance formula exactly. Form the
mutual-support graph with edge ij iff g_ij != 0. A continuous unit-phase
choice gamma makes the estimator zero-variance iff every edge satisfies
  arg(g_ij)+phi_i-phi_j = pi/2 (mod pi), gamma_i=exp(i phi_i).
Orient a cycle C=(i_0,...,i_(ell-1),i_0) and use
g_(i,j)=F_ij conjugate(F_ji) for each directed edge. Summing the edge
constraints proves the necessary cycle condition

  sum_(i,j in C) arg(g_(i,j)) = ell*pi/2 (mod pi).

Equivalently, product_(i,j in C) g_(i,j) is real for even ell and purely
imaginary for odd ell. The condition is sufficient as well: assign phases
recursively along a spanning forest; the cycle equations ensure every
non-tree edge is consistent (it suffices to check a fundamental-cycle basis).
Thus variance elimination is a phase-flux feasibility problem, not a generic
consequence of non-bipartiteness or diagonal gauge freedom.

Exact separating examples
-------------------------
1. Real matching blocks. Let
  F = direct_sum_(j=1)^q [[0,a_j],[b_j,0]], with real a_j,b_j.
Choose gamma_(2j)=1 and gamma_(2j+1)=i (zero-based indexing). Each only
nonzero skew edge is
  s_(2j) a_j - i s_(2j+1) b_j,
whose squared modulus is beta_j=a_j^2+b_j^2 for every sign word. Therefore
  X_k(s;gamma)=e_k(beta_1,...,beta_q)=c_k(F)
for every s and every k<=q: exact zero variance. For unit swap blocks
(a_j=b_j=1), the unphased central-sector estimator is 4^q with probability
2^-q and zero otherwise, so its relative second moment is 2^q. The same
instance under the alternating Q(i) phase has relative second moment one.
Consequently the unphased swap example is not a lower bound against the
phase-preconditioned estimator. The exact checker exhausts all sign words for
q<=4 and all sectors; it verifies the elementary-symmetric target and
zero-variance identity.

2. Frustrated triangle. Take F=J_3-I_3. Every mutual-support edge has g_ij=1.
The 3-cycle product is 1, whereas an odd cycle requires a purely imaginary
product, so no phase gauge can make Var X_1 zero. In fact
  Var X_1=4 sum_(i<j) cos^2(phi_i-phi_j).
Using sum cos(2(phi_i-phi_j))=(|sum_i exp(2i phi_i)|^2-3)/2 >= -3/2
shows sum cos^2 >= 3/4, attained at phases (0,pi/3,2pi/3), hence the
continuous minimum is exactly 3. Restricting to Q(i) unit phases, every edge
term cos^2 is 0 or 1; an odd cycle cannot have all three differences
orthogonal, so the minimum is 4, attained by (1,i,-1). The unphased value is
12. The exact checker exhausts all 64 Q(i)-unit triples and confirms these
values.

Relation to the acquired matching certificate
---------------------------------------------
c03_s01/revisions/phased_pfaffian.py uses the alternating Q(i) phases and an
acquired real matching G. Its certificate controls a dense input F by the
residual Frobenius-square condition relative to beta_min; its code states the
accepted sample range [3/4,4/3] times the baseline count. The exact block
calculation above is the zero-residual center of that design, while the
triangle explains why a diagonal phase rule alone cannot generically
annihilate variance. This phase-classification result supplies no way to
acquire a matching, does not extend the certificate to arbitrary F, and does
not implement the physical-prefix/Born sampler. The prefix sampler is a
separate estimator: its prefix support/bit/TV guarantees cannot be inferred
from the variance reduction on matching blocks.

The c03_s01 check JSON records phased relative second moment 1 for the raw
swap fixtures, but the corresponding source assigns that field as a literal
string rather than deriving it in the diagnostic. My standalone checker
computes the moments from exact Pfaffians for q=1..4; it verifies mean 2^q
and relative second moment 1 after alternating phases, and relative second
moment 2^q without them. c03_l04 independently reported this source/check
distinction and an exact swap-block verification. The separate
phase_variance_classification_checks.json stores computed ratios.

Verification and limitations
-----------------------------
Run:
  python3 work/cycle6/c03_l06/revisions/phase_variance_classification.py

It passes exact Q(i) checks for matching block counts q=1..4, every k, and
all 2^(2q) sign strings; checks the unphased central swap relative-second-
moment identity for q=1..4; exhausts 64 triangle Q(i)-phase triples; and checks
the row/column gauge congruence on all 8 triangle sign strings. Results are in
phase_variance_classification_checks.json. These finite checks support the
derivation but are not its proof. No optimization algorithm for arbitrary
gamma, sampler, runtime improvement for general F, literature priority
finding, or externally validated theorem is claimed. In particular, the
universal C_k cap remains the same under phase twisting; exploiting reduced
actual variance requires finding a useful phase choice, and the triangle
shows that zero variance may be impossible.

QUESTION AND RESULT
-------------------
Test the correction

  V = A + sum_i R_i^(b_i) [1 + epsilon_i h_i(a)/(1+b_i)^D] + K 1_{A=0},
  A=sum_j a_j,  h_i=1{sum_{j in N(i)}a_j=0},

against a finite list of reversible substrate-preserving channels

  A_j+z_B <-> A_l+z_B,      A_j+z_B <-> z_B,

with catalyst order one, unchanged substrate vector, |z_B|<=m, and positive
finite mass-action rates. Isolated-substrate counts are fixed class labels.

I find a sharp structural distinction for this template:

* The global denominator (1+sum_i b_i)^(-D) has a mixed-face positive-drift
  obstruction even with all rates positive; see Section 7 and the exact
  replay `outputs/research/reaction_dynamics/cycle5/verify_global_denominator_obstruction.py`.
* For the local denominator, an exact rational two-face sequence refutes a
  Foster bound when m>=D+2. At m=D+1 the same sequence refutes an unrestricted
  all-rate claim if the added switch rate is large enough.
* At the requested boundary D=m, the catalyst-switch ray cannot beat either
  the q-sink on the substrate whose support it deactivates or a largest
  substrate's inactive-face sink. The weighted-exponent split below covers
  unequal R_i, arbitrary finite sparse supports, multi-substrate cofactors,
  simultaneous support toggles, and a retained K 1_{A=0} term. Under the
  stated base-network hypotheses it yields a fixed-class inequality

       LV <= C - c_A A - c_B sum_i R_i^(b_i)/(1+b_i)^m.             (1)

  Thus this local candidate gives a physical-time Foster certificate for
  recurrence/nonexplosion, generally subgeometric rather than geometric.

1. EXACT INTERFACE AND CLASS QUALIFIERS
---------------------------------------
The base family has finite catalyst set J, finite substrate set I, support
E subset J x I, and reactions, for each j and (j,i) in E,

  0 <-> A_j,                                      rates alpha_j, delta_j a_j;
  A_j <-> A_j+B_i,                                rates p_ji a_j, q_ji a_j b_i;
  A_j+B_i <-> (k_ji+1)A_j+B_i,                    rates u_ji a_j b_i,
                                                  v_ji (a_j)_(k_ji+1)b_i,

where k_ji>=1 is fixed and every rate is strictly positive and finite.
The extra list is finite. A channel with substrate cofactor z has propensity
c a_j (b)_z in a catalyst-source direction and c'(b)_z in its reverse;
(b)_z=product_t (b_t)_(z_t). All source orders and total degrees are fixed,
and each rate is an ordinary finite constant. Assume each dynamic substrate
i has N(i) nonempty. Coordinates with N(i)=empty are invariant labels, even
when they occur in z; all statements are per fixed label vector, and
constants may depend on those labels. This is necessary: an unbounded frozen
cofactor can make jump rates arbitrarily large across different classes.

Fix R_i>1 and epsilon_i>0. For the base catalyst tail also require

  chi_j := delta_j - sum_{i in N(j)} p_ji (R_i-1) > 0  for every j.   (2)

This is feasible by choosing each R_i sufficiently close to one. Let D be
an integer with D>=m and K>=1 if the optional K term is retained. Rates,
R_i, epsilon_i, K and the finite channel list are fixed. No novelty or
external validation claim is made.

2. EXACT LOCAL GENERATOR AND WHY BASE SUBSTRATE JUMPS DO NOT MIX FACES
---------------------------------------------------------------------
Put W_i(n)=R_i^n/(1+n)^D, c_i=R_i-1, d_i=1-R_i^(-1),
alpha(N(i))=sum_{j in N(i)}alpha_j, and
J_ij(a)=1{a restricted to N(i) equals e_j}. With K omitted, the base
family contributes exactly

  H - sum_j delta_j a_j
  + sum_(j,i) in E [p_ji c_i a_j R_i^(b_i)
                    -q_ji d_i a_j b_i R_i^(b_i)
                    +k_ji u_ji a_j b_i
                    -k_ji v_ji (a_j)_(k_ji+1)b_i]
  + sum_i epsilon_i W_i(b_i)
       [-alpha(N(i)) h_i(a) + sum_(j in N(i)) delta_j J_ij(a)],       (3)

where H=sum_j alpha_j. If K is included, add

  -K H 1_{A=0} + K sum_j delta_j 1_{a=e_j}.                          (4)

The local correction has no denominator-change term under a base B_i jump.
Such a jump requires a_j>0 for some j in N(i), so h_i=0 before and
after; other h_l, b_l are unchanged. Base autocatalytic jumps preserve B
and leave their source A_j present, so they cannot turn a support correction
on. This is the exact point where a global denominator differs: a B_i jump
changes every corrected face there.

For an extra transfer A_j+z <-> A_l+z, total A and K 1_{A=0} are
unchanged. Its correction increment is exactly

  c a_j (b)_z sum_i epsilon_i W_i(b_i)
       [h_i(a-e_j+e_l)-h_i(a)].                                    (5)

For A_j+z -> z, the increment is

  c a_j (b)_z {-1 + sum_i epsilon_i W_i(b_i)
       [h_i(a-e_j)-h_i(a)]
       + K[1_{A=1}-1_{A=0}]},                                         (6)

where the K term is included only when K is retained. The reverse
z -> A_j+z has increment

  c'(b)_z {1 + sum_i epsilon_i W_i(b_i)
       [h_i(a+e_j)-h_i(a)]
       + K[1_{A+1=0}-1_{A=0}]}.                                      (7)

Every positive correction switch in (5) or (6), h_i:0->1, requires that
its source A_j be the unique molecule in N(i). In particular a_j=1 and
(j,i) is a base edge. The same state therefore enables the base q-removal
term -q_ji d_i b_i R_i^(b_i). Switches h_i:1->0 are nonpositive and can be
dropped in an upper bound. This source-order-one/last-neighbor implication
is the load-bearing structural hypothesis.

3. D=m MAX-FACE AUDIT, INCLUDING HETEROGENEOUS R_i AND COFACTORS
---------------------------------------------------------------
If I_* is empty, every substrate coordinate is a fixed label. On each
class all cofactor propensities are constants; transfers preserve A,
deactivations decrease it, reverse deactivations add only a finite
label-dependent rate, and the base immigration/death drift controls A.
The following max-face argument is only needed when I_* is nonempty.

Assume I_* is nonempty. Let r_i=log R_i>0, E_i=r_i b_i,
E_* = max_{i in I_*} E_i, P_z(b)=(b)_z, and
r_min=min_i r_i>0. Since the support and cofactor degrees are finite,

  b_t <= E_*/r_min,   P_z(b) <= C_z(1+E_*)^m,                       (8)

with C_z absorbing fixed isolated-label factorials. This works for an
arbitrary multi-substrate z, not only a pure power of one B_t.

Consider one positive correction switch in coordinate i. Its positive rate
term is at most C epsilon_i W_i(b_i)P_z(b). There are two cases.

(a) E_i >= E_*/2. For every coordinate t in z,

  b_t <= E_*/r_t <= (2r_i/r_t)b_i.

There are finitely many (i,t,z), hence P_z(b)<=C(1+b_i)^m. With D=m,

  W_i(b_i)P_z(b) <= C R_i^(b_i).                                   (9)

The positive switch itself implies a_j=1 for a source neighbor j of i.
The same source state has q rate q_ji b_i on that edge, whose negative
contribution is q_ji d_i b_i R_i^(b_i). It dominates (9) as b_i grows,
for any fixed finite added rate and epsilon_i. If b_i stays bounded in this
case then E_*<=2E_i is bounded, so all dynamic cofactor counts are bounded;
that contribution belongs to a finite-state constant.

(b) E_i < E_*/2. Choose t attaining E_*. Its local negative substrate block
has one of two forms for sufficiently large b_t. If h_t=1, all incident
base edges are disabled and catalyst immigration contributes
-alpha(N(t))epsilon_t W_t(b_t). If h_t=0, an incident catalyst is active;
the paired q term dominates the p and u positive terms at large b_t and
leaves a negative block of order b_t R_t^(b_t), after absorbing the local
last-neighbor death switch. In either case a fixed positive multiple of
W_t(b_t) is reserved. By (8), and b_t<=E_*/r_t,

  [epsilon_i W_i(b_i)P_z(b)]/W_t(b_t)
       <= C (1+E_*)^(m+D) exp(-E_*/2) -> 0.                         (10)

Thus the largest exponential face absorbs the term. Summing (9)-(10) over
the finite number of channels and simultaneously affected supports only
changes finite thresholds. The argument remains valid if the largest face
is not in z: every dynamic substrate has its own local negative block.

The positive A increment from a reverse deactivation z->A_j+z is at most
C P_z(b). The positive K-boundary increment from A_j+z->z is also at most
K C P_z(b), and occurs only from a=e_j. Both are bounded by a constant plus
a vanishing fraction of W_t(b_t) for a maximizer t of E_*, since (8) is
polynomial whereas W_t is exponential up to a polynomial divisor. If A=0,
the reverse birth changes A+K1_{A=0} by 1-K<=0 and decreases, or leaves,
every h_i, so it is already nonpositive for K>=1. For bounded E_*, every
active substrate count is bounded and P_z is bounded within the fixed class.
Annihilation's -1 A increment away from the zero boundary is favorable.

Base high-substrate blocks and large-catalyst tails are as in the exact
sparse paired-edge calculation: for each edge

  [p_ji c_i R_i^n-q_ji d_i n R_i^n+k_ji u_ji n]/R_i^n -> -infinity.

An active high face supplies the q sink; an inactive high face supplies the
negative immigration switch -alpha(N(i))epsilon_i W_i. For catalysts with
all adjacent b_i=0, (2) gives a strict negative linear coefficient. If an
adjacent b_i is positive and bounded, the reverse falling factorial
v_ji(a_j)_(k_ji+1)b_i dominates all linear catalyst gains for large a_j.
If an adjacent substrate is high and active, its q block controls the
incident catalyst count; if it is high and inactive, its local neighbors
are zero. Added transfers preserve A, forward deactivations decrease A,
and positive support-switch pieces have already been absorbed by (9)-(10).
This is the same mixed escape split: every unbounded substrate or catalyst
coordinate is covered; no remaining escaping ray has an uncharged positive
term.

Combining the finite low-coordinate region with those tails yields (1),
with constants depending on the fixed network and class. Since V is
comparable to 1+A+sum_i R_i^(b_i),

  A+sum_i W_i(b_i) >= c V/(1+log V)^m,

so LV<=C'-c'V/(1+log V)^m. This is enough to make LV<=-1 outside a finite
set. The usual stopped-Dynkin localization also gives nonexplosion in
physical time: V-sublevel sets and their one-jump target sets are finite,
exit rates on them are bounded, and LV<=C globally implies
P_x(tau_L<=T)<=(V(x)+CT)/L. Sending L to infinity rules out finite-time
escape. Once nonexplosion is established, the countable-state continuous-
time Foster criterion gives positive recurrence of each irreducible
fixed-label class (Anderson–Kim, Theorem 3.1, arXiv:1710.11263v3, 2018,
https://arxiv.org/html/1710.11263v3). The inequality is for physical time;
it is not an embedded-event-chain drift.

4. EXACT RATIONAL LOCAL COUNTEREXAMPLES BELOW D=m
------------------------------------------------
Use two catalysts A1,A2 and two dynamic substrates B1,B2 with sparse base
support E={(A1,B1),(A2,B2)}. Put every base rate equal to one, k=1, and
add the reversible conversion

  A1+4 B2 <-> A2+4 B2

with both rates one. This obeys the extension grammar and every directed
rate is strictly positive. Test

  V=A1+A2 + (6/5)^(b1)[1+(1/10)1_{a1=0}/(1+b1)^D]
               +(11/10)^(b2)[1+(1/10)1_{a2=0}/(1+b2)^D].

At x_n=(a1,a2,b1,b2)=(1,0,n,n), n>=4, the reverse conversion is disabled
because a2=0. The forward conversion fires at (n)_4, preserves A, and
changes h1:0->1 and h2:1->0. Exact rate-times-jump arithmetic gives

  LV(x_n)=1+n+(1/5)(6/5)^n - (n/6)(6/5)^n
          +(1+(n)_4)/[10(n+1)^D] * [(6/5)^n-(11/10)^n].            (11)

For D=2, the last term is asymptotic to (1/10)n^2 (6/5)^n, while the q
sink is only (1/6)n(6/5)^n; hence LV(x_n)/[n^2 (6/5)^n]->1/10 and
LV->+infinity. The base small-gain margins are strict:
1-(6/5-1)=4/5 and 1-(11/10-1)=9/10.
The exact checker verifies LV>0 for n=11,...,30. Thus this all-positive,
weakly reversible extension refutes an all-rate Foster claim for the local
candidate with D=2,m=4. It does not refute D=m, and it says nothing about
recurrence of this finite-rate CTMC. If K 1_{A=0} is added, only a fixed
K delta_1 boundary increment is added at x_n; the diverging leading term is
unchanged.

At the borderline D=m-1, the leading coefficient on the same ray is
controlled by the product epsilon times the added-channel rate. With
D=3,m=4, epsilon=1/10, base rates one, and both conversion rates 10, the
coefficient of n(6/5)^n is epsilon*10-1/6=5/6>0. The exact checker verifies
positivity for n=12,...,30; asymptotically LV/[n(6/5)^n]->5/6. So D=m is a
simple all-rate-safe sufficient exponent for this mechanism. D=m-1 can be
used only with additional channel-wise small-gain inequalities; this report
does not optimize that boundary.

5. K-BOUNDARY, CATALYST COUNTS, AND STATE-SPACE SCOPE
----------------------------------------------------
The K term does not spoil the D=m local split. Base death contributes only
the bounded term K sum_j delta_j 1_{a=e_j}; base immigration from A=0 has
increment 1-K<=0. A forward annihilation can activate K only if the entire
catalyst vector is e_j, adding at most K c P_z; (8)-(10) show the max
substrate sink dominates it whenever a dynamic cofactor grows. Reverse
creation from A=0 deactivates K and is nonpositive for K>=1. Transfers do
not change K. If z uses only isolated substrates, P_z is constant on each
class and the K increment is finite there.

The source catalyst order-one condition is essential to the q-pairing
argument. If source order were r>1, a support loss could occur from a_j=r;
its forward rate would carry an additional factor (a_j)_r, while the q sink
is only proportional to a_j. A separate catalyst-count factorization would
then be needed. Likewise q_ji>0 on every edge that can be the last local
neighbor is essential to this particular absorption; if q_ji=0, its local
sink disappears. Those are failures of this certificate mechanism, not
proofs of nonrecurrence.

Classwise versus uniform scope: if z includes an isolated substrate C, C is
a conserved label but can multiply a switch rate by (C)_r. Constants in
(1) then depend on C. There is no single all-lattice drift constant. An
exact family illustrating this boundary is E={(A1,B1)}, isolated C, and
A1+C <-> A2+C. With V's local B1 correction, K omitted, state
(a1,a2,b1,c)=(1,0,0,n) has a forward-switch increment epsilon_1 and rate n;
therefore LV grows like epsilon_1 n across distinct C-label classes. Every
fixed-C class still has a finite constant. Do not confuse this cross-class
uniformity failure with within-class transience.

The D=m inequality is generally subgeometric for D>0, not a geometric
inequality LV<=C-cV. The isolated-label, fixed-class ray from the parallel
physical-clock audit makes this exact: E={(A1,B)}, C is isolated and fixed
at 2, add A1+2C <-> 2C, take D=m=2, R=3/2, epsilon=K=1 and all rates one.
At x_n=(a1,a3,b,c)=(0,0,n,2), direct calculation gives

  LV(x_n)=-3(3/2)^n/(1+n)^2,
  V(x_n) >= (3/2)^n.

Thus LV/V->0; no constants C,c>0 give LV<=C-cV for this candidate on
this class. This is not a recurrence failure. An exact Fraction replay is
`outputs/research/reaction_dynamics/cycle5/leaves/physical_clock/evidence/check_local_ray.py`.

Here the q-removal A1+B1->A1 has rate 2N. It decreases total B in the

1. TEMPORARILY FREEZE VALUES ONLY FOR LONG PAIRS

Every movable sign site x has an oppositely prescribed site y at square
NN distance at most2. For a positive x,0<=h_x<=h_y+d1(x,y)<=2;
for a negative x,-2<=h_y-d1(x,y)<=h_x<=0. The same inequalities hold
when y is an original pin of the opposite weak sign. Thus all sign
values belong to[-2,2] throughout the conditional body, even when an
opposition edge is a NE diagonal. Original fixed values are<=1/2.

Disintegrate nu over ALL numerical values of the sign sites. All its
extra coordinate interval indicators are then decided; the remaining
conditional density is uniform on a Lipschitz body with that fixed set
and all pin values in[-2,2]. Positive-volume sections exist almost
everywhere by Fubini. A zero-width interval was already treated as a
true pin at0. This disintegration is not a new exact-value observation
in the near-edge argument.

Recall the bounded-data ONE-SAMPLE comparison on any finite square
graph with the SAME fixed set. Uniform laws with pin values -B,b,+B,
|b|<=B, can be coupled monotonically by single-site uniform heat baths.
The endpoints of the conditional height interval are increasing in
all neighboring heights. Couple the two extreme chains as exact
translates of one zero-pinned chain, and place the middle chain between
them. Compact stationary subsequential coupling, with the correct
uniform invariant marginals, gives
   |h_b(x)-h_0(x)|<=B at EVERY vertex simultaneously.
The upper/lower data have ALL pins at the same+B or-B; no infeasible
alternating extreme-pin assignment is made. Finite free components
are anchored to the common fixed set. This is the allowed frozen
bounded-data comparison; no quantitative mixing rate is used.

If needed, take a finite enclosing square graph including every tested
patch and every neighbor of a free coordinate. All other vertices are
fixed. This retains degree4 and the original law and includes the
canonical Manhattan paths below, even if a path passes through pins.
Apply the comparison at B=2 to each frozen section, to a zero-pinned field with
the ORIGINAL and temporarily frozen sites all pinned at0. Its NN
graph still has degree4. For every pair,
   |h_b(x)-h_b(y)|<=|h_0(x)-h_0(y)|+4.
Put delta=d0/2 and choose k0>=8/d0. For d>=k0,
   (1-delta)d-4 >= (1-d0)d.
Consequently a long failure for h_b implies a zero-field long failure
with deficit d0. This holds pointwise in ONE coupling for ALL tested
pairs/blocks together. It is not a separate-pair coupling assertion.

2. JOINT LONG-SLACK BOUND FROM ONLY ZERO-PIN CAP

For a zero field, if |h_0(x)-h_0(y)|>(1-d0)d along the prescribed
shortest Manhattan path of length d, at least ceil(d/2) of its DISTINCT
edges have |grad h_0|>1-a0. Otherwise the deficit is at least a0 d/2,
whereas the permitted deficit d0 d=a0 d/4 is smaller. Choose that
subset in at most2^d ways. The supplied zero-pin CAP gives
   P(long-pair failure)<=2^d(C4 a0)^(d/(2C4))=kappa^d.
Paths remain within their coordinate rectangle. Edges between two zero
pins can never be witnesses; the theorem is used on the original degree4
graph before any grounding, with extra pins at0.

For any k enlarged patches in one color class, their vertex sets and
canonical path edges are disjoint. Choose one failing pair in each,
at most N^2 possibilities per patch. CAP applies to the UNION of the
distinct selected near-edge witnesses, so
   P_0(all k patches have a long failure)
       <=(N^2 kappa^k0)^k.
This is a joint CAP argument, not independence of the fields in those
patches. It is uniform over the temporary fixed set and its geometry.
The one-sample coupling in Section1 transfers it on each frozen section;
integrating the sign values gives for nu
   P_nu(all z in A have L_z)<=eta^|A|                 (2.1)
for each one-color A. L_z is the ACTUAL long-failure event on P_z,
with deficit delta and distance threshold k0. Here L was chosen as
in the target and N^2 kappa^k0<=eta. Since L=O_m,d0(k0), this choice
exists. No general bounded-pin CAP is invoked.

3. THE GOOD SHELL IS MEASURABLE IN THE EXTERIOR

UNFREEZE all sign values before this step. For a patch let its truly
free interior coordinates be F_z=F intersect interior(P_z); condition
on every free coordinate outside F_z. In particular its whole geometric
shell is now given numerically. Original pins within P_z retain their
given values<=1/2, but interior sign sites remain VARIABLE in intervals
containing0. The resulting conditional law is uniform on the unchanged
convex body K_z of these coordinates, not on a long-good subset of it.

Let Xi_z be the following event of the exterior data ALONE:
there EXISTS a feasible filling h* in K_z for which every movable
endpoint x of every eligible tested central edge and every shell site s
satisfy
   |h*(x)-b_shell(s)|<=d1(x,s)-2.                     (3.1)
This is finite linear feasibility, with deterministic original pins and
sign intervals. It is a Borel event of the shell data: on a compact
shell-parameter set all feasible fillings are bounded by that shell
plus the fixed patch diameter, so the projection of the closed bounded
feasibility graph is closed. Conditional bodies of zero free volume
are outside a null set and need not be given a uniform density.

Every central endpoint is at distance at least mL-1>=k0 from the shell.
The prescribed L also ensures delta(mL-1)>=2. Therefore the ACTUAL
long-good event L_z^c provides exactly one such h*, the actual filling.
Pointwise, for every feasible global sample,
   Xi_z^c implies L_z.
In particular, for every specified one-color collection,
   P(all Xi_z^c)<=P(all L_z)<=eta^k.                  (3.2)
This is how the bad-SHELL joint estimate is inherited. The event Xi_z
does not condition on the inside sample being good; it asserts existence
of a useful centre somewhere in the FULL conditional body.

4. STRICT CENTRE FOR EACH PHYSICAL NN EDGE

Assume Xi_z. Fix an eligible tested edge(u,v) and choose a room filling
h*. All non-shell prescribed data are original fixed values<=1/2 or
movable coordinate intervals containing0. At a movable endpoint x,

The own-site sign interval also contains0.

If both endpoints are movable, put c=median(0,h*(u),h*(v)). It is
between0 and EACH old endpoint. It therefore respects every propagated
non-shell interval at both sites. Because(u,v) is an ORIGINAL NN edge,
each endpoint is moved by at most |h*(u)-h*(v)|<=1. Room(3.1) preserves
all endpoint-shell Lipschitz inequalities. Prescribe g(u)=g(v)=c.

If one endpoint is a true pin p, put the other endpoint at0. Its old
height has magnitude at most1+|b_p|<=3/2. Room2 again preserves all
shell inequalities. Its propagated non-shell intervals contain0 and
the tested edge now has gradient at most|b_p|<=1/2.

For completeness, interval data[alpha_x,beta_x] on a finite graph admit
a1-Lipschitz selection exactly when alpha_x<=beta_y+d1(x,y) for every
pair. Necessity follows from any selection. Sufficiency is the lower
cone g(y)=sup_x[alpha_x-d1(x,y)], omitting infinite endpoints. It is
1-Lipschitz and obeys every lower and upper bound. In the full square
patch graph its distance is Manhattan distance; true pin vertices remain
vertices in this extension, not deleted obstacles. The old data were
consistent and the new endpoint prescriptions satisfy every added pair
inequality by the preceding paragraph. Extend them to a feasible g_e.
Its tested gradient is<=1/2.

This argument constructs a centre for EACH edge; it does not need one
centre strict simultaneously on all tested edges. The centres may lie
on sign-wall boundaries. With0<s<1/2 the affine map
   h -> (1-2s)h+2s g_e
keeps the ENTIRE K_z in K_z and sends it into |grad_e|<=1-s. It has
Jacobian(1-2s)^m_z in the truly free-coordinate volume. Therefore
   P(|grad_e|>1-s | exterior, Xi_z)
        <=1-(1-2s)^m_z<=2m_z s.
The conditioning on Xi_z adds nothing to the fiber: Xi_z is already
exterior measurable. On open strict-sign fibers, contraction still

Zero widths were removed as fixed0 coordinates.

Union over at most Emax tested edges gives

5. PRODUCT NEAR BOUND AFTER CONDITIONING PATCH EXTERIORS

For one-color patches, condition on the COMMON exterior of the union

   P(all z in A have E_z and Xi_z | common exterior)<=eta^|A|.

   P(all z in A have E_z and Xi_z)<=eta^|A|.          (5.1)
This does NOT condition each body on an actual interior long-good event.
It uses the unchanged uniform body with a shell-only existence test.
Together(2.1),(5.1) handle static badness, since
   L_z union E_z is contained in L_z union(E_z intersect Xi_z).
If Xi_z fails then L_z already occurs for the actual sample.

6. SHORT STATIONARY STEP WITH THIN SIGN WALLS

Use the supplied finite Neumann/RBM construction on the full sign-interval
polytope, with covariance2I on its truly free coordinates. It is reversible
for nu. The stationary Lyons--Zheng coordinate identity over[0,T] is
   h_t(x)-h_0(x)=1/2 M_x(t)
      -1/2[hat M_x(T)-hat M_x(T-t)].
The full forward martingale vector has constant bracket2t I and hence
is a variance-two Brownian vector with independent free coordinates;
the reverse vector has the same property in its reverse filtration.
They are NOT assumed mutually independent. Pin coordinate differences
are0 and need no martingale. Narrow intervals change reflection but
not the free-coordinate bracket; no inverse width enters this estimate.

Let F_z be the event that some coordinate in P_z has forward sup|M|>
a_move; let R_z use the corresponding reversed Brownian increment.
For a one-color collection their possible coordinates are distinct.
The elementary reflection-principle bound
   p(T,a)<=4 exp(-a^2/(4T))
and independence WITHIN each vector give
   P(all F_z)<=[N p(T,a_move)]^k<=eta^k,
   P(all R_z)<=[N p(T,a_move)]^k<=eta^k.               (6.1)
This holds for each fixed sign kernel, independently of its probability,
dimension or interval widths. No product of forward and reverse events
is used. Their union is handled below by a type assignment.

Outside F_z union R_z, every vertex displacement is at most a_move.
If also L_z and E_z do not occur, then throughout[0,T],
   |grad_e h_t|<=1-s+2a_move<=1-s/2,
and for d>=k0,
   |h_t(x)-h_t(y)|<=(1-delta)d+2a_move
                  <=(1-delta/2)d.
Thus the target dynamic bad event is contained in FOUR types:
   L_z, E_z intersect Xi_z, F_z, R_z.                 (6.2)
Each type has the joint separated-set eta^k bound. Stationarity and
the exact sign-body reflected kernel are charged finite imports here;
the result is not inferred from the unconditioned original RBM path law.

7. FOUR TYPES AND FINITE COLORING

For k specified patches in one color, assign one of the four witnesses
in(6.2) to each bad patch. For every assignment some type occurs at
least k/4 times. Discard the other events and apply that type's joint
bound, giving at most eta^(k/4). Summing at most4^k assignments gives
   P(all k patches dynamically bad)
       <=[4 eta^(1/4)]^k=zeta^k.
No mixed-type probabilities were multiplied as if independent.

Color indices modulo q=2m+4 in each coordinate, J=q^2. Same-color closed
patches have an axial gap at least3L, so their vertex/witness sets and
interior nearest-neighbor interactions are disjoint as required above.
For ANY k boxes take a largest color subset of size>=k/J. The all-bad
event implies its all-bad event, hence is bounded by
   zeta^(k/J)=rho^k.
The empty set has probability1. All parameter choices precede the
domain/sign kernel/exploration; only the fixed degree4 CAP constant
and desired rho,m are charged. This proves(CS).

8. SCOPE CHECKS AND LOCAL PIN-DISTANCE CRITERION

The proof never applies controlled-gradient CAP to bounded nonzero pins
or sign-constrained fields. CAP is used ONLY after freezing bounded
sign values and coupling to a zero-pinned sample. The near bound is
proved by local convex volume with sign sites movable. Numerical reveals
are not silently retained as new fixed coordinates in that argument.

The actual reason original small pins suffice is local: every non-shell
fixed pin's propagated interval contains0 at EACH tested movable
endpoint, and every tested fixed endpoint has magnitude<=1/2. Given an
exact uniform conditional body these are the sufficient hypotheses.
For extra pin values bounded by2, NN distance at least2 from every
tested movable endpoint is sufficient for the first condition; edges
with an extra high pin as tested endpoint must still be excluded.
Requiring the enlarged patch to contain no extra revealed pins is a
stronger simple sufficient protection. This criterion is stated to make
pin distance explicit, NOT as a claim that arbitrary adaptive value
transcripts automatically satisfy it or have the needed kernel.
The supplied main theorem uses only original pins<=1/2 and true movable
sign intervals; its actual sign-prefix application is proved separately.

Auxiliary NE diagonals enter only the height bound2 and the exploration
definition. A diagonal is not a unit NN constraint; treating it as one
would alter both the law and the CAP degree. Similarly the absorber
along a sign prefix kills the independent walk but does not pin the
field in this conditional kernel. The uniform constants apply even
to boxes meeting that absorber, provided the declared physical NN
eligibility and shell-body hypotheses are retained.

The theorem is finite, static/short-step and uniform. It asserts no
normal-reflected comparison force probability under thin walls, no
infinite sign-wall bulk, no conditional covariance theorem, no trace
height gap, and no GFF/curve scaling conclusion. Its new reconstruction
requires fresh review before being promoted to an internally audited input.

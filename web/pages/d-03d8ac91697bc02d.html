choose Lambda=2R, C=A+Lambda I. Then
  R I <= C <= 3R I,  t0=2/N-2R/N^(3/2),

The equality is exact and t0>0 whenever R<sqrt N. No step in the exact
filter/rotation/Casimir derivation requires Lambda=M+1; that earlier choice

Now set r0=1/8, a0=2atanh(1/16), delta=1/2-logcosh1. Since
D=(I-mm^T)C(I-mm^T)-[m]_cross C[m]_cross^T, on |m|<=r0
  D >= R[(1-|m|^2)^2-3|m|^2]I >= (3R/4)I,
  D <=3R I.
Thus the positive stopping ball has FIXED radius, independent of M_N.
This avoids the artificial shrinkage r0~M_N^-1/2.

  N^-3/4 (7/3) exp[-Lambda/2-1/12]
whenever N>=Lambda^2. The unweighted outer tail is bounded by
  16exp[-N a0^4/768]+Cdelta exp[-delta N/4],

not exp(2hN). This refinement is also in the c07_s01/c04 audit discussion;
the looser exp(2hN) bound would give the same growing conclusion.

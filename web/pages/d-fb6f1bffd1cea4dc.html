# Cycle 2: conditional access can acquire a rare predictive feature

**Status.** Internally proved for one structured rank-two family: adaptive chosen-prefix conditional samples identify an unknown nonlinear predictive feature with polynomial cost, while passive independent trajectories require exponentially many samples for its final bit. The gain is exactly the oracle’s ability to draw from a rare selected history; it does not make rarity disappear. This is not a new general low-rank learning theorem. Liu and Moitra’s STOC 2025 result already resolves Kakade et al.’s arbitrary-rank conditional-sample distribution-learning problem in total variation. Exact/worst-history feature recovery is a distinct objective.

See [PROOFS_CYCLE2.md](PROOFS_CYCLE2.md) and [CLAIMS_CYCLE2.json](CLAIMS_CYCLE2.json).

## Source family and objective

For T≥2, let the observation alphabet be Ω={0,1}×{0,1}. An unknown word s∈{0,1}^T controls the source. Set A₀=1. At step i, draw Xᵢ independently and uniformly from {0,1}, update

Aᵢ=Aᵢ₋₁ 1{Xᵢ=sᵢ},

then draw Zᵢ|Aᵢ ~ Ber(1/4+Aᵢ/2), and emit Yᵢ=(Xᵢ,Zᵢ). Thus the marker Z is noisy: it is 1 with probability 3/4 while the prefix remains live, and 1/4 after the first mismatch.

The learner knows T, the pair alphabet, the clocked prefix-match template, and the marker noise, but receives neither s nor a feature dictionary. It must return s, which gives the exact predictive feature

φ_{s,t}(h)=1{x₁…x_t=s₁…s_t}.

At each cut t, the full future law depends on a history only through A_t∈{0,1}. There are at most two distinct conditional-future rows, so the finite-horizon Hankel rank is ≤2. An edge-output-to-state-output lift with a clock uses at most 8T+1 HMM states; its emitting transition weights are 1/8 or 3/8, plus a deterministic termination edge, and emissions can be deterministic. Thus this is a finite-state rank-two source. The acquired feature is a secret-prefix conjunction, not parity or a supplied linear direction. The class does supply this particular transducer template.

## Adaptive chosen-prefix theorem

On each call the oracle accepts a positive-probability exact history h and returns an independent sample of the entire future suffix conditioned on h. At level k, form

h_{k−1}=((ŝ₁,1),…,(ŝ_{k−1},1)),

using the bits already acquired. Query this same history m times. From the first returned pair (X_k,Z_k), calculate R=(-1)^{X_k}(Z_k−1/2). Conditional on prior bits being correct, A_{k−1}=1 despite the noisy marker history, and

E[R|h_{k−1}] = +(1−2η)/2 if s_k=0;  −(1−2η)/2 if s_k=1,

where η=1/4 here (more generally, marker rates 1−η when live and η when dead). Since R∈[−1/2,1/2], Hoeffding gives bit error at most exp(−m(1−2η)²/2). Taking

m=ceil(2(1−2η)⁻² log(2T/δ))

per bit and inducting on the first erroneous coordinate gives Pr[ŝ≠s]≤δ. At η=1/4, m=ceil(8 log(2T/δ)), so Q=Tm=O(T log(T/δ)) conditional-sample calls recover the exact feature map for every prefix, including rare ones.

### Complete access and resource accounting

A call at level k submits k−1 pair symbols and returns a full suffix of T−k+1 pair symbols. The algorithm uses only the first returned pair, but the rest are charged.

- Calls: Q=Tm.
- Query-prefix inputs: mT(T−1)/2 pair symbols = mT(T−1) raw bits.
- Full suffix responses: mT(T+1)/2 pair symbols = mT(T+1) raw bits.
- Total query-input and response communication: mT² pair symbols = 2mT² bits, plus O(Q log T) framing.
- Memory: T bits for ŝ and O(log m) bits for the running sum/counter; streaming and discarding each suffix keeps working memory O(T+log m), or O(T) extra pair symbols if one suffix is buffered.
- Local time/I/O: O(mT²) bit operations to encode histories and consume every returned suffix; O(mT) statistic updates.
- Precision: no numerical probabilities are returned. Source probabilities have denominator 4; R is exact half-integer arithmetic and ŝ is a T-bit exact output.
- Sampling contract: each query call yields an independent fresh suffix. One uninterrupted trajectory is not Q samples. Concatenated independent episodes with boundaries count as reset paths and all emitted symbols are charged.

The noise-robust form costs a factor (1−2η)⁻². The η=0 deterministic-marker limit uses one sample per level but directly reveals live/dead state.

## Exact passive lower bound and rare-context cost

For s,s′ differing only at coordinate T, their one-trajectory laws satisfy exactly

TV(P_s,P_{s′})=(1−2η)2^{−(T−1)}.

Indeed, the first T−1 X bits must match their shared prefix, an event of probability 2^{−(T−1)}. Until then the hidden states and marker laws agree. On that event the final live/dead marker laws are Ber(1−η) and Ber(η), at TV distance 1−2η.

For N independent passive trajectories,

TV(P_s^N,P_{s′}^N)≤N(1−2η)2^{−(T−1)}.

Le Cam’s two-point inequality gives average error for estimating the last bit at least

[1−N(1−2η)2^{−(T−1)}]/2.

Even if s₁…s_{T−1} are supplied, success ≥2/3 requires N≥2^{T−1}/[3(1−2η)]. At η=1/4 this is N≥2^T/3 complete paths, hence Ω(T2^T) pair-symbol observations. This is information-theoretic for exact worst-history feature recovery.

The successful adaptive query history has probability

P_s(h_{k−1})=((1−η)/2)^{k−1},

which is (3/8)^{k−1} at η=1/4. The chosen-prefix service returns its conditional sample in one call regardless of this mass. Passive rejection to realize the exact history costs the inverse probability in expected reset paths; summing over levels is exponential in T. Even if a service could condition only on X₁…X_{k−1}, omitting the marker coordinates, that event has mass 2^{−(k−1)}, still exponential. The oracle is a real reachability subsidy. Its call count does not translate into an equal-cost passive sample count. The conditional-query interface does not specify how the service computes a conditioned draw; our ledger charges each call, its submitted prefix, and every returned suffix symbol, while source-side computation beyond those interface costs remains unspecified. A passive-rejection implementation incurs the exponential expected reset cost above.

## Equal-output controls and validation

For m calls at each level, the training/validation query block returns mT(T+1)/2 pair symbols. Matching that response volume with passive data gives floor(m(T+1)/2) complete paths per split. Even a passive comparator granted Tm complete paths (matching active call count rather than output symbols) has last-bit success at most 1/2+Tm(1−2η)2^{−(T−1)}/2, which stays near 1/2 for polynomial m,T.

Freeze ŝ after training. For independent conditional validation, use m_val fresh calls at each prefix formed from the frozen candidate and evaluate R; no training suffix is reused. An oracle-known-s control receives the same validation response blocks plus s (T side-information bits) and computes the exact expected conditional statistic for each queried history. It is a same-path ceiling. The adaptive arm gets no s side information. A passive control gets an independent raw-path validation block at the same raw-symbol budget as its passive training block. Passive and conditional validation cannot literally use the same sample strings because they have different conditional laws; that interface difference is stated explicitly rather than represented as a paired test.

A GF(2) nullspace baseline is inapplicable: X₁…X_T are iid uniform under every s, so linear elimination on X contains no information; the predictive feature is a nonlinear conjunction. The appropriate generic basis-free comparator is low-rank conditional law learning.

## Prior art and the exact open-problem boundary

Kakade, Krishnamurthy, Mahajan and Zhang (COLT 2023) introduced the chosen-prefix conditional-sample model. Their Theorem 2 learns rank-r distributions under fidelity Δ*>0 with resources polynomial in r,T,|Ω|,1/Δ*,1/ε,log(1/δ). The robust basis need not be supplied: their procedure finds one under fidelity. They explicitly posed Open Problem 1—efficient conditional-sample learning of any low-rank distribution. Their Appendix F gives general-rank basis-finding machinery but leaves error propagation unresolved.

Liu and Moitra, Model Stealing for Any Low-Rank Language Model, STOC 2025, Theorem 1.3, resolve that distribution-learning problem. Their Definition 1.2 oracle accepts any chosen prefix and returns an independent full future suffix conditional on it. For any rank-S law they use poly(S,|Ω|,T,1/ε) queries and time to output an efficiently samplable law within TV ε, with success 1−ε. Our example has S≤2 and |Ω|=4 and uses that same interface. Thus no novelty claim about arbitrary-rank conditional-sample TV learning is available.

Their theorem does not itself imply exact recovery of this feature at polynomial T. Neighboring models differ in TV by only (1−2η)2^{−(T−1)}. A generic application requiring ε below half this gap has a theorem bound polynomial in 1/ε, hence exponential at that precision. This observation is not a lower bound against their algorithm or against another specialized method. Our explicit procedure exploits the local prefix structure to recover s exactly using O(T log T) samples. Also, an efficiently samplable approximation need not reveal a canonical latent feature map, since predictive realizations can be nonunique. Arbitrary-rank TV distribution learning is solved prior art; exact rare-history feature identification is the distinct target.

Angluin’s L* is the classic membership-query automata-learning precedent; Kakade et al. themselves frame their methods as robust generalizations of it. This construction is a noisy probabilistic prefix-trie instance, not a new automata-learning principle.

Primary sources: [Kakade et al., COLT 2023](https://proceedings.mlr.press/v195/mahajan23a/mahajan23a.pdf), Open Problem 1 and Theorem 2; [Liu and Moitra, STOC 2025](https://doi.org/10.1145/3717823.3718220), [full arXiv text](https://arxiv.org/html/2411.07536), Definition 1.2 and Theorem 1.3; [Angluin 1987](https://doi.org/10.1016/0890-5401(87)90052-6).

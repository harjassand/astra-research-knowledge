\section{Conclusion and Future work}
In this paper, we showed that none of the previous works on \DetMax\ for general matroid can yield estimation and approximation factors independent of $k$, the size of the output set. We showed an $\pr{O(d)}^d$-estimation algorithm by first showing the existence of an optimal solution to the convex program with at most $O(d^2)$ strictly fractional variables and rounding such a fractional solution. To improve this estimation factor, we may try answering the following question:

\begin{quest}
Let $\M=([n],\I)$ be a matroid with bases $\B$ and let $\bx^\star \in \P(\M)$ be a point in the matroid bases polytope with at most $O(d^2)$ strictly fractional variables, i.e. $|\{i\in [n] : 0 < x_i^\star < 1\}|  = O(d^2)$. For any $d$, does there always exist a distribution $\mu:\B \rightarrow \rR_+$ such that for any independent set $S$ of size $d$,
\[ \Pr_{T \sim \mu}[S \subseteq T] \geq e^{-O(d)} \Pi_{i \in S} x_i^\star ?\]
\end{quest}

A positive resolution to this question would improve the estimation factor for \DetMax{} problem from $\pr{O(d)}^d$ to $\pr{O(1)}^d$.

## Exact strongest checkpoint claim

For the critical spin-half family

  rho_(N,A,b) = exp(K_N)/Tr exp(K_N),
  K_N = 2 J^2/N + Q_A(J)/N^(3/2) + b.J/N^(3/4),

three separate interfaces must be kept distinct:

1. The known-parameter preparation is a randomized finite-bit classical
   algorithm with A,b supplied as rational inputs (or by a charged
   polynomial-time precision interface), fixed public rational bounds M,B,
   dyadic accuracy inputs, and admitted N with t0=2/N-M/N^(3/2)>0. Under the
   explicit native one-qubit precision interface, the audited construction
   has averaged whole-output trace error at most E_sep,N+2 eta+epsilon and
   polynomial classical bit cost for fixed M,B. Its O(N^(-3/2)) separable-cone
   proximity bound is parameter dependent. It is not a finite-gate-set or
   hardware result.
2. The unknown-parameter reverse map is a different operation: it receives
   one classical X whose law is p_(A,b)(x) proportional to
   exp(-4|x|^4/3+x^T A x+b.x), and outputs S_N(X). The internal theorem gives
   uniform whole-density trace error O_(M,B)(N^(-1/4)); it does not use A,b,
   but it does use X. Sampling/acquiring X and finite-bit/gate implementation
   costs are not thereby supplied. The faster known-parameter rate cannot be
   transferred to this unknown-input task.
3. The quartic experiment's memory law e_D=Theta(D^(-2/3)) is for one
   observation, a nondegenerate public field cube B>0, arbitrary unassisted
   quantum/hybrid archive dimension D, and all input-dependent persistent
   records charged. The finite-N transfer has an additive channel remainder
   R_N. A separate work report claims R_N=O(N^(-1/2)) for a coherent reverse
   channel, but says the memory converse was not independently reaudited.
   Thus a sharp joint N,D law is conditional and requires R_N=o(D^(-2/3));
   the root's fully product reverse decoder has only the O(N^(-1/4)) rate.

I derived two further interface consequences. First, a parameter-blind output
with no observation cannot uniformly approximate this family: the pair
b=+beta e_1 and b=-beta e_1 has asymptotically positive trace distance.
Second, the known-parameter finite-bit sampler's O(R) retained candidate array
can be replaced by an exact integer weighted reservoir using O(P) retained
weight bits, where P=O(N Q_*+log(R/epsilon)); this remains polynomial but may
increase precision and is not a practical-runtime claim. The derivation below
is independent of peer outputs.

## Known versus unknown parameters: exact obstruction

Take A=0 and b_+=beta e_1, b_-=-beta e_1 for any fixed 0<beta<=B. Let
f(x)=exp(-4|x|^4/3), H={x_1>0}, and let p_+,p_- be the corresponding quartic
laws. Their normalizers agree by reflection. Reflection also gives
P_-(H)=1-P_+(H), while

  P_+(H)-P_-(H)
    = Z_+^(-1) int_H f(x)[exp(beta x_1)-exp(-beta x_1)] dx > 0.

Hence d_beta:=TV(p_+,p_-) is strictly positive. The existing parameter-free
forward channel T_N obeys TV(T_N rho_(N,+),p_+)<=alpha_N and similarly for
minus, with alpha_N -> 0. Data processing and the triangle inequality give

  T(rho_(N,+),rho_(N,-)) >= d_beta - 2 alpha_N.

For any single fixed output state sigma independent of both b and any
observation, the triangle inequality forces

  max_{s in {+,-}} T(sigma,rho_(N,s)) >= (d_beta-2 alpha_N)/2.

Thus the known-parameter sampler cannot be advertised as a uniform unknown-
b sampler with vanishing error unless it also receives information. The
one-observation decoder avoids this obstruction because X is its input and
has different laws p_+,p_-; “parameter independent” does not mean “data free.”
This proof uses only the audited forward experiment approximation and the
strictly different tilted densities, not a point-estimation argument.

## Streaming weighted selection: derivation and resources

The finite-bit sampler proposes R branches. For branch i, write

  X_i = g_i tau_i g_i^*,  t_i=Tr X_i,  w_i=t_i^N.

On the retained normal event the path estimate in the existing compiler is
||g_i|| and ||g_i^(-1)|| <= exp(Q), so exp(-2Q)<=t_i<=exp(2Q) and
-2NQ<=log w_i<=2NQ. Choose a rational public enclosure Q_*>=Q, with slack
for the finite-precision path perturbation. Then

  v_i = exp(log w_i - 2N Q_*) satisfies exp(-4NQ_*) <= v_i <= 1.

Let r=epsilon/(1024 R), and choose integer

  P >= 8 N Q_* + log2(1024 R/epsilon).

Since 8 log(2)>4, this makes 2^(-P)<=r exp(-4NQ_*). Evaluate v_i by
certified interval arithmetic to absolute error at most 2^(-P-1), then round
to an integer a_i/2^P with total absolute error at most 2^(-P). It follows
that a_i>0 and

  |a_i/2^P - v_i|/v_i <= r.

All a_i share the same denominator and common scale; neither depends on a
future maximum weight. For S_i=sum_(j<=i) a_j, process candidates in order,
retaining the new branch with exact probability a_i/S_i. A uniform integer in
{0,...,S_i-1} implements this comparison by bounded-bit rejection in expected
fewer than two attempts. For any k, its final selection probability is

  (a_k/S_k) product_(i=k+1)^R (S_(i-1)/S_i) = a_k/S_R.

Thus this is exactly the normalized quantized-weight law. If p_i is the ideal
normalized w_i law and q_i the normalized a_i law, the relative error bound
implies q_i/p_i=(1+delta_i)/(1+sum_j p_j delta_j), |delta_i|<=r, and therefore
TV(p,q)<=r/(1-r)<=2r. This fits inside the original compiler's dyadic
selection budget by replacing its array-based selection step; it need not be
added on top of the declared epsilon.

Memory holds only S_i (at most R 2^P), one selected local Bloch vector, and the
current candidate's 2x2 filter/state data. Its weight counter is P+ceil(log2 R)
bits; working precision is O(P+ell+log N), where ell is the path precision.
No O(R) candidate-description array is needed. The selected product state can
then be emitted one qubit at a time. The N physical output cells/time remain
necessary.

For the compiler's Q=U L+B/(4 N^(3/4)), U=(3/2)sqrt(Mm)/N^(3/4),
L=O(sqrt(log(R(m+K)/epsilon))), m=O(eta^(-1)), R=O(eta^(-2)), this gives

  N Q_* = O_(M,B)(sqrt(m) N^(1/4) sqrt(log(R(m+K)/epsilon))
                   + N^(1/4)).

P and the O(R) sequential updates are polynomial in N, eta^(-1), epsilon^(-1)
and rational input length for fixed M,B. This trades retained records for a
larger common-scale precision; it does not improve the sampler's O(eta^(-3))
real-arithmetic work or establish practical speed. The script
streaming_selection_check.py exactly enumerates weighted-reservoir histories
with fractions for five integer weight lists; its saved JSON confirms the
selected law equals normalized weights. That finite check tests the recurrence;
the telescoping product above proves it for every positive integer list.

## Trace norm, weak limits, memory and hardware boundaries

The full-state trace bound T(rho,output)<=delta controls every POVM event on
the N-spin output by delta, not merely expectations of a selected fluctuation
observable. It does not control an arbitrary external purification. Weak
convergence of collective fluctuations alone is insufficient for full-state
recovery: for even N>=4 the spin-0 multiplicity is at least two. Two orthogonal
states |j=0,alpha=1><...| and |j=0,alpha=2><...| have identical values for
every polynomial in collective J (J_i=0 on both), yet trace distance one.
These are not members of the permutation-invariant Gibbs family. They show
why a weak collective limit needs the family-specific multiplicity reset or a
separate trace-norm proof. The candidate critical-spin channels do specify the
known maximally mixed multiplicity and claim whole-density trace bounds.

For the memory claim, all classical labels and quantum registers that persist
from encoder to decoder count in D. A finite-run sampler's workspace is a
different resource. The known-parameter finite-bit array stores R=O(eta^-2)
weights and local descriptions; the reservoir above reduces this working
record. Neither gives a memory lower bound for an algorithm run that is handed
A,b. The asymptotic archive lower bound requires B>0; if B=0 and the family is
one known state, the memory error is zero. At finite N, the transfer is only

  max(0,c D^(-2/3)-R_N) <= e^*_(N,D)
       <= min(1,C D^(-2/3)+R_N),  R_N -> 0.

It is not valid to discard R_N for arbitrary D=D(N). If one accepts the
separate asserted R_N=O(N^(-1/2)), a necessary scale for that remainder to be
smaller than D^(-2/3) is D=o(N^(3/4)); with only the product decoder's
O(N^(-1/4)) error, the corresponding scale is D=o(N^(3/8)). The O(N^(-1/2))
archive refinement is conditional on a coherent channel and on the unreviewed
memory proof, not a result established by this worker.

The finite-bit sampler assumes a native one-qubit interface that accepts finite
rotation descriptions and Bernoulli probabilities with charged output error.
It does not identify a discrete universal gate set, a compiling algorithm, a
hardware latency, or a physical implementation. Its output is an averaged
mixture of product states; each local trace error is budgeted at O(epsilon/N)
to control the full N-fold output. Exact trace-distance control is therefore
an operational full-output guarantee under that local-preparation interface,
not weak convergence or a hardware benchmark.

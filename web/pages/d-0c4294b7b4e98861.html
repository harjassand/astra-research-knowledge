# A22 — exact global coherent-fault mask bound and isometric polar repair

Date: 2026-10-09  
Status: internally proved finite-dimensional operator/combinatorial lemma under the stated global aggregate-cylinder hypothesis. This closes the algebraic extraction step in A04, conditional on that hypothesis for the complete multiround circuit and on the exact-fault-set expansion. It does not derive that hypothesis from a physical Hamiltonian or establish the full QTC memory theorem.

## 1. Exact statement and conventions

Let `T,N,k` be integers with `T>=1` and `1<=k<=N`. Let `L_1,...,L_T` be pairwise disjoint location sets, each of cardinality `N`; write `L=disjoint_union_j L_j`. For every exact fault set `F subseteq L`, let `W_F : H_in -> H_out` be a bounded linear operator. No positivity, orthogonality, commutativity, tensor-product structure, or individual bound on `||W_F||` is assumed. Put

`V = sum_{F subseteq L} W_F`, and for each cylinder mask `S subseteq L`,

`E(S) = sum_{F: F superseteq S} W_F`.

Assume the **global** cylinder bound

`||E(S)|| <= eta^{|S|}` for every `S subseteq L`, with `eta>=0` (and `eta^0=1`). The sum defining `E(S)` ranges over all faults at all unmasked locations, including every other round. Thus this is a common-bath multiround assumption, not a product of per-round channels.

A round `j` is bad on exact path `F` when `|F intersect L_j|>=k`; the global path is bad when at least one round is bad. Define

`B = sum_{F: exists j, |F intersect L_j|>=k} W_F`,

and let `G=V-B` be the sum over paths with fewer than `k` faults in every round. Then

`||B|| <= (1+beta)^{T}-1 <= (1+b)^{T}-1`,

where

`beta = sum_{s=k}^N binom(N,s) binom(s-1,k-1) eta^s`

is the exact absolute-coefficient bound furnished by the mask expansion, and

`b = binom(N,k) eta^k (1+eta)^{N-k}`

is the simpler bound proposed in the assignment. In particular, the proposed bound is true. The proof uses only the cylinder sums and finite linearity; it does not assume `||W_F||` bounds or independent faults.

## 2. Threshold-mask Möbius coefficients

For a fixed round with location set `L_j`, define the Boolean threshold function

`q(A)=1{|A|>=k}` for `A subseteq L_j`.

Its unique containment-basis expansion is

`q(A) = sum_{S subseteq A} c_|S|`,

where

`c_s = 0` if `s<k`, and `c_s=(-1)^{s-k} binom(s-1,k-1)` if `k<=s<=N`.

To derive this, binomial inversion for a symmetric set function gives

`c_s = sum_{r=0}^s (-1)^{s-r} binom(s,r) q(A_r)`

for any `A_r` of size `r`. If `s<k`, this is zero. If `s>=k`,

`c_s = sum_{r=k}^s (-1)^{s-r} binom(s,r)
     = (-1)^{s-k} binom(s-1,k-1)`,

using the alternating partial-binomial identity. Direct evaluation also verifies the expansion: for `|A|=f`,

`sum_{s=k}^f binom(f,s)(-1)^{s-k}binom(s-1,k-1) = 1` when `f>=k`,

and the sum is empty, hence zero, for `f<k`. One derivation of the displayed identity writes

`binom(f,s)binom(s-1,k-1) = binom(f,k) [k/s] binom(f-k,s-k)`

and evaluates the alternating sum using `k integral_0^1 x^{k-1}(1-x)^{f-k} dx = 1/binom(f,k)`.

The indicator of a location mask is therefore exactly

`1{|F intersect L_j|>=k} = sum_{S subseteq L_j, |S|>=k} c_|S| 1{S subseteq F}`.

For a nonempty set of rounds `J subseteq [T]`, the indicator that every round in `J` is bad is the product of these expansions. Because the `L_j` are disjoint, this gives

`1{all j in J bad on F}
 = sum_{(S_j subseteq L_j: |S_j|>=k, j in J)} (product_{j in J} c_|S_j|) 1{union_{j in J} S_j subseteq F}`.

Inclusion-exclusion over the bad rounds now gives the requested **product/union expansion**:

`1{F is globally bad}
 = sum_{emptyset != J subseteq [T]} (-1)^{|J|+1}
     sum_{(S_j subseteq L_j: |S_j|>=k, j in J)}
       (product_{j in J} c_|S_j|) 1{union_{j in J}S_j subseteq F}`.

Multiply this pointwise identity by `W_F` and sum over exact paths. Each containment sum is precisely the aggregate cylinder, so

`B = sum_{emptyset != J subseteq [T]} (-1)^{|J|+1}
     sum_{(S_j: |S_j|>=k, j in J)}
       (product_{j in J} c_|S_j|) E(union_{j in J} S_j)`.

This identity is exact even when the `W_F` are noncommuting operators: only scalar coefficients, operator addition, and the definition of `E` are used.

## 3. Norm bound, sharper finite constant, and round composition

For one selected round the sum of absolute cylinder bounds is

`beta = sum_{s=k}^N binom(N,s) |c_s| eta^s
      = sum_{s=k}^N binom(N,s) binom(s-1,k-1) eta^s`.

For any selected `J`, the disjointness of its round-location sets implies

`|union_j S_j| = sum_j |S_j|`.

The global cylinder assumption therefore bounds that `J` contribution by `beta^{|J|}`. Summing over the `binom(T,r)` choices of `J` with `r` rounds proves

`||B|| <= sum_{r=1}^T binom(T,r) beta^r = (1+beta)^T-1`.

The exact beta has the useful equivalent forms (let `R~Binomial(N-k, eta/(1+eta))`):

`beta = binom(N,k) eta^k sum_{r=0}^{N-k} [k/(k+r)] binom(N-k,r) eta^r`

`     = b E[k/(k+R)]`

`     = binom(N,k) eta^k k integral_0^1 x^{k-1}(1+eta x)^{N-k} dx`.

The first equality uses `binom(s-1,k-1)=(k/s)binom(s,k)`; the integral follows from `k/(k+r)=k integral_0^1 x^{k+r-1}dx`. For `eta>0`, `0<beta<=b`, since `k/s<=1`; for `eta=0`, both vanish because `k>=1`. Thus

`||B|| <= (1+b)^T-1 <= exp(T b)-1`.

The second inequality is often convenient, but it is only informative when `T b` is small. For a desired bad-sum tolerance `delta>0`, it suffices that `b <= (1+delta)^(1/T)-1`, equivalently `T <= log(1+delta)/log(1+b)` when `b>0`.

The coefficient `c_s` is exact, whereas `b` is a convenient upper bound, not the exact coefficient sum. In general `beta<b`; the ratio representation above quantifies the improvement. No norm bound on a selected sub-sum was inferred from a triangle inequality over exact paths: the inversion first expresses that selected sub-sum in terms of the controlled full cylinders `E(S)`.

## 4. Linear-size rounds and exponential constants

Take `N=N_0 n`, `k=ceil(tau n)`, where `0<tau<N_0` is fixed and `N_0 n` is integer. Let `rho_n=k/N` and `rho=tau/N_0`. With natural logarithms and binary entropy `H(x)=-x log x-(1-x)log(1-x)`, Stirling's formula gives

`log b = N [H(rho_n)+rho_n log eta+(1-rho_n)log(1+eta)]
         - (1/2)log(2 pi N rho_n(1-rho_n)) + o(1)`

for fixed `eta>0` and `rho in (0,1)`. Hence

`(1/n) log b -> N_0 [H(rho)+rho log eta+(1-rho)log(1+eta)]`.

The exact exponential decay condition for this displayed `b` is

`H(rho)+rho log eta+(1-rho)log(1+eta)<0`,

or equivalently `eta^rho (1+eta)^(1-rho) < rho^rho(1-rho)^(1-rho)`. The left side is strictly increasing in `eta>0`, so there is a unique positive critical value; all smaller `eta` satisfy the condition. The exact beta has the same exponential rate as `b`: from the binomial random-variable form,

`beta/b -> rho(1+eta)/(rho+eta)`

as `n->infinity` (the binomial law of large numbers gives `R/(N-k)->eta/(1+eta)`). This ratio is a positive constant for fixed `rho,eta>0`, so it does not change the exponential threshold.

A simpler, weaker sufficient condition follows from `binom(N,k)<=(eN/k)^k` and `(1+eta)^(N-k)<=exp(eta N)`:

`b <= exp(k log(e N eta/k)+eta N)`.

Thus for `N=N_0 n`, `k=ceil(tau n)`, the asymptotic exponent per `n` is at most

`tau log(e N_0 eta/tau)+N_0 eta`.

If this quantity is negative, `b` decays exponentially. It is negative for all sufficiently small positive `eta`. If `b_n<=exp(-c n)` and `T_n<=exp(a n)` for `a<c`, then `||B||<=exp(T_n b_n)-1=O(exp(-(c-a)n))`. In particular fixed `T` gives `O(T exp(-c n))` when `T b_n->0`.

## 5. Polar-isometry repair for a non-normalized good sum

Assume now that `H_in=L tensor B_in` and `H_out=L tensor B_out` for the same logical Hilbert space `L`, and that the complete, unpostselected decoded operation `V:H_in->H_out` is an isometry (`V^dagger V=I`). Suppose the good-path sum factors exactly as

`G=I_L tensor g`

for a bounded map `g:B_in->B_out`, and `||V-G||<=delta<1`. No assumption that `G` or `g` is normalized, isometric, trace preserving, or even a channel is made.

For every `y in B_in`, choose a unit vector `ell in L`. Then

`||g y|| = ||G(ell tensor y)|| >= ||V(ell tensor y)||-delta||y|| >= (1-delta)||y||`.

Similarly `||g y|| <= (1+delta)||y||`. Thus `g` is bounded below by `1-delta>0`; in finite dimensions this implies full column rank, and in general its range is closed. Its polar decomposition is

`g=h |g|`, where `|g|=(g^dagger g)^(1/2)` and `h^dagger h=I_{B_in}`.

So `h` is an isometry on every possible input-bath vector, including vectors entangled with a logical system or reference. The same singular-value bounds give `|| |g|-I ||<=delta`, hence `||g-h||=||h(|g|-I)||<=delta`. Since `||I_L tensor(g-h)||=||g-h||`,

`||V-I_L tensor h|| <= ||V-G||+||I_L tensor(g-h)|| <= 2delta`.

This isometry comparison is uniform on the entire joint logical-plus-bath input space. Let

`Phi_V(X)=Tr_{B_out}(V X V^dagger)` and
`Phi_h(X)=Tr_{B_out}((I_L tensor h)X(I_L tensor h)^dagger)`.

For isometries `A,C`, the standard two-term expansion

`A X A^dagger-C X C^dagger=(A-C)X A^dagger+C X(A^dagger-C^dagger)`

gives, also after adjoining an arbitrary reference, `||Ad_A-Ad_C||_diamond<=2||A-C||`; partial trace cannot increase diamond norm. Consequently

`||Phi_V-Phi_h||_diamond <= 2||V-I_L tensor h|| <= 4delta`.

Here `Phi_h` is the ideal logical identity with the bath discarded: `Phi_h(X)=Tr_{B_in}(X)` as a map `L tensor B_in -> L`, because `h` is an isometry. For any fixed bath state `sigma`, precomposing with `rho -> rho tensor sigma` yields the ordinary logical-channel bound `||Phi_{V,sigma}-Id_L||_diamond<=4delta`. The uniform joint-input inequality also covers arbitrary correlations with a reference. If “diamond distance” is defined as one half of the diamond norm, the corresponding bound is `2delta`.

There is no postselection or division by a success probability here. `V` and `I_L tensor h` are isometries, so their induced channels are trace preserving. `G` may be non-normalized; its closeness to the complete isometry forces its polar factor to be an isometry.

## 6. Scope, failure modes, and claim status

The mask inequality is false without the **global** cylinder assumption. Per-round marginals or per-round cylinder bounds that do not control joint masks across rounds do not justify the product `(1+beta)^T-1` under a common bath. The proof specifically uses `||E(S_1 union ... union S_r)|| <= eta^(sum |S_j|)` for masks in distinct rounds. This is the precise repair to the A04 gap: state and establish that global multiround condition for all circuit locations.

The polar conclusion would fail if `delta>=1`, since `g` can have a kernel; the strict condition supplies a uniform lower singular-value bound. It also requires the identity factorization and operator-norm closeness on the full input, not merely closeness on a postselected or fixed-bath subspace. Dimensions must permit an isometry `B_in -> B_out`; this follows from the lower bound and is automatic if the assumptions hold.

Claim ledger:

- **Internally proved:** exact threshold-mask Möbius coefficients; exact multiround union expansion into global aggregate cylinders; `||B||<=(1+beta)^T-1<=(1+b)^T-1`; asymptotic exponent and sufficient small-eta conditions.
- **Internally proved:** for a complete isometry `V` with `G=I_L tensor g` and `||V-G||<=delta<1`, the polar isometry `h` satisfies `||V-I_L tensor h||<=2delta` and the induced logical diamond norm is at most `4delta`.
- **Unresolved from this lemma:** whether the physical QTC extraction/readout/decoder locations satisfy the stated global aggregate-cylinder condition with a useful `eta`; whether every low-fault good path has the exact decoded factorization `G=I_L tensor g`; and whether a complete classical/readout model has been included. Thus this closes a mathematical sub-interface, not the full noisy-memory theorem or an originality/priority claim.

Its application to the local non-Markovian fault-path model depends on the source-level definition of aggregate cylinders and a separately proved global bound for the complete circuit.

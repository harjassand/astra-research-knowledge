# Complement-LCU projector: exact entries and an exponential row

**Result.** For the actual augmented BMVZ family, fix the complement-LCU
isometry and failure-flag test from Cycle 2, and fix an explicit legal unitary
completion of PREPARE as below. The canonical range projector
`C=U(I-|0><0|)U* = I-VV*` has a physical row with at least `5^R` nonzeros.
More precisely, one same-output-label block row has **exactly** `5^R`
nonzeros, which is also the exact maximum row support inside that block. Since
BMVZ's amplification parameter `R` grows as a positive power of the source
input size, this particular `C` has no polynomial row-list algorithm. This is
not a no-go for every PREPARE completion or for every positive enforcer of the
same image: the earlier specification gave only `A|0>=chi`, and row support is
basis-sensitive. The result is for the explicit completion fixed here.

## Actual augmented family and the fixed LCU `V,B`

Start with the BMVZ-admissible QMA-hard layered family. Add a fresh five-qubit
block and two rank-one seed projectors

```
phi = (|00010>-|10010>)/sqrt(2),
psi = (|00010>-|01110>-|10110>-|11010>)/2.
```
Put them in separate singleton commuting layers of weight `1/4` each, and
scale the old hard family to total weight `1/2`. The singleton rule in BMVZ
Definition 1.6 repeats the sole clause at every round. After `ell` rounds the
actual emitted seed clauses are

```
h_(v,R) = I - Q_(v,R),       Q_(v,R) = (I-|v><v|)^(tensor R),
R = (2t)^ell.
```

Here `v` is supported on the same fresh five-qubit block in each of the `R`
input copies. The exact generator extraction, QMA-hardness preservation, and
seed occurrence proof are in
[the Cycle-2 source audit](../../cycle2/bmvz_bjsw_source_audit.md). In
particular, the two seed layers remain separate positive-weight terms in the
full iterated generator; they are not inferred from the unmodified ABN-derived
starting family.

For the fine-spectrum augmentation, use

```
H = (1/2) H_B + sum_(k=1)^r delta_k P_k,
P_k=|10000><10000| on fresh disjoint 5-qubit registers,
sum_k delta_k=1/4,
r=n,
```
and add a zero projector of weight `1/4`. Thus `0<=H<=I` and the coefficients
form a probability distribution over projections. In this normalized target,
the two repeated seed clauses have weights

```
pi_phi = pi_psi = 1/8.
```
Split the silent zero weight among enough zero-projector terms that the total
number `L+1` of LCU labels (one identity label plus `L` projection labels) is
a power of two. All resulting branch weights stay positive, rational, and
polynomial-bit. Write `N` for the logical data-qubit count and `D=L+1=2^q`
for the exact label dimension.

For every projection term `h_j`, set `R_j=I-2h_j`. In particular,
`R_(v,R)=2Q_(v,R)-I`. With `chi_id=1/sqrt(2)` and
`chi_j=sqrt(pi_j/2)`, define `A|0>=chi`,

```
SELECT = |id><id| tensor I + sum_(j=1)^L |j><j| tensor R_j,
U = (A* tensor I) SELECT (A tensor I),
V|z> = U(|0> tensor |z>),
B = (I-|0><0|)_label tensor I_data.
```

Then `<0|U|0>=I-H`, and exactly

```
V* B V = I-(I-H)^2 = 2H-H^2,
H <= V*BV <= 2H.
```

`B` is a diagonal projection with row support one and locality `q=O(log n)`.
The circuit for `V` is polynomial: PREPARE uses a polynomial number of exact
algebraic rotations, and each controlled BMVZ reflection computes the OR of
its `R` local projector outcomes, applies a phase, and uncomputes. The local
projectors have constant-size descriptions; for the forced BJSW pair the
state-preparation Clifford circuits are explicitly checked by the existing
exact script. This statement is about the ideal algebraic circuit. Finite-gate
compilation is approximate and its error must be charged separately.

## Full physical-basis tensor-entry formula for `C`

The PREPARE unitary has rows indexed by the SELECT labels `j` and columns by
physical output labels `a`; put `chi_j=A_(j,0)`. The output-label blocks of V
are

```
K_a = sum_(j in {id,1,...,L}) conjugate(A_(j,a)) chi_j R_j.
```
Therefore, for computational-basis physical rows `(a,x)` and `(b,y)`,

```
C_(a,x),(b,y)
 = delta_(a,b) delta_(x,y) - <x|K_a K_b*|y>
 = delta_(a,b) delta_(x,y)
   - sum_(j,k) conjugate(A_(j,a)) chi_j A_(k,b) conjugate(chi_k)
          <x|R_j R_k*|y>.
```

This formula includes every BMVZ path term, both forced seeds, all dummy
projectors, and the silent zero branches. For a pair of amplified BMVZ clauses
write their copy factors as `Q_(j,s)=I-Pi_(j,s)`, `s=1,...,R`, so
`Q_j=tensor_s Q_(j,s)` and `R_j=2Q_j-I`. The relative-product entry factors
exactly per copy:

```
<x|R_j R_k*|y>
 = 4 product_s <x_s|Q_(j,s) Q_(k,s)|y_s>
   -2 product_s <x_s|Q_(j,s)|y_s>
   -2 product_s <x_s|Q_(k,s)|y_s>
   + delta_(x,y).
```

For complex local projectors the adjoints are retained in the local factors;
for the seed pair all matrices are real. Each requested C entry is thus a sum
of `O(L^2 R)` constant-size algebraic operations. With polynomial-bit local
matrices and weights it is computable exactly as a polynomial-size arithmetic
circuit, and to b-bit precision in time polynomial in `L,R,b` plus the input
coefficient bit lengths. This is entry access, not row enumeration.

The canonical C is also a polynomial-size quantum circuit (`U`, a label
projection, `U*`). Its expansion has at most `O(L^4)` label-pair/term-pair
summands, each supported on `q` label qubits and at most `10R` data qubits;
this is a locality bound `q+10R`, not constant locality. The general row upper
bound obtained from this expansion is exponential. The next section gives an
exact row count that makes the upper bound irrelevant for sparsity.

## Fixing the PREPARE completion and isolating the seed pair

A PREPARE state alone does not uniquely specify U or C: changing A on the
orthogonal complement of `|0>` leaves `A|0>=chi` unchanged but changes the
physical output-label basis of V and the row support of C. We now fix one
explicit completion without changing `chi`, `B`, the top-left block `I-H`, or
the complement-LCU construction.

Since `pi_phi=pi_psi=1/8`, `chi_phi=chi_psi=1/4`. Take output label `b=1`
and choose its column of A to be

```
A_(phi,b) = 1/sqrt(2),
A_(psi,b) = -1/sqrt(2),
A_(j,b) = 0 for every other SELECT label j.
```

This is a unit vector orthogonal to the first column `chi`. Complete these two
columns to a unitary by an exact Gram-Schmidt/Givens construction; the
completion has polynomial circuit size and polynomial-bit algebraic gate
parameters. The resulting selected output block is exactly

```
K_b = tau (R_(phi,R)-R_(psi,R)),       tau=1/(4 sqrt(2)).
```
No other BMVZ term enters `K_b`; they remain present in the complete `V`, `B`,
and `C`, but the chosen column zeros their coefficients in this one block.

Let `c=00010`, `f=10010`, and
`g1=01110,g2=10110,g3=11010`. Define the local rank-one complements

```
Q_phi = I-|phi><phi|,       Q_psi = I-|psi><psi|,
G = Q_phi Q_psi,             U0={c,f,g1,g2,g3}.
```
The exact row-c matrix entries, all rational, are:

| y | `G_(c,y)` | `G_(y,c)` | `(Q_phi)_(c,y)` | `(Q_psi)_(c,y)` |
|---|---:|---:|---:|---:|
| `c=00010` | `3/8` | `3/8` | `1/2` | `3/4` |
| `g1=01110` | `1/8` | `1/4` | `0` | `1/4` |
| `f=10010` | `1/2` | `3/8` | `1/2` | `0` |
| `g2=10110` | `1/8` | `1/4` | `0` | `1/4` |
| `g3=11010` | `1/8` | `1/4` | `0` | `1/4` |

All entries of these four local row vectors vanish outside `U0`. The values
follow directly from the displayed seed amplitudes; the same data are checked
exactly in
[`bmvz_bjsw_seed_pair_test.py`](../../cycle2/bmvz_bjsw_seed_pair_test.py).

For `x=c^R`, `y=(y_1,...,y_R)`, and `y!=x`, the seed relative-product
formula simplifies to

```
(R_(phi,R)R_(psi,R)+R_(psi,R)R_(phi,R))_(x,y)
 = 4 [ product_s G_(c,y_s) + product_s G_(y_s,c)
       - product_s (Q_phi)_(c,y_s) - product_s (Q_psi)_(c,y_s) ].
```
The same-label block of the full complement projector is

```
C_(b,x),(b,y)
 = delta_(x,y) - tau^2 [(R_(phi,R)-R_(psi,R))^2]_(x,y)
 = delta_(x,y) + 4 tau^2 [ product_s G_(c,y_s) + product_s G_(y_s,c)
       - product_s (Q_phi)_(c,y_s) - product_s (Q_psi)_(c,y_s) ].
```
This uses `Q_phi^2=Q_phi`, `Q_psi^2=Q_psi`, and the tensor-product
factorization across the R disjoint seed blocks. Since `4 tau^2=1/8`, every
term in the row is an exact rational. The entry is zero whenever `y` contains
a local symbol outside `U0`. For every `y in U0^R`, it is nonzero:

1. If y contains both `f` and at least one of `g1,g2,g3`, both Q-projector
   products vanish and both G products are positive.
2. If y is in `{c,f}^R` but `y!=c^R`, let k be the number of f symbols and
   m=R-k. After dividing the bracket by `(1/2)^R`, it equals
   `(3/4)^m+(3/4)^R-1` (with the all-f case giving `(3/8)^R` directly).
   For `m>0`, it cannot be zero: multiplying the proposed equality by `4^R`
   gives `3^m 4^(R-m)+3^R=4^R`, impossible modulo 3.
3. If y is in `{c,g1,g2,g3}^R` but `y!=c^R`, let k≥1 count the g symbols
   and m=R-k. The bracket equals
   `(1/4)^k(3/8)^m[(1/2)^k+1-2^m]`, which is positive when m=0 and strictly
   negative when m≥1.
4. At `y=x`, the C diagonal is positive because
   `||K_b||<=2 tau=1/(2 sqrt(2))<1`, so
   `C_(b,x),(b,x)=1-||K_b*|x>||^2 >=7/8`.

The three off-diagonal classes above partition `U0^R\{c^R}`. Consequently
this fixed physical row has exactly `5^R` nonzeros **inside the b-to-b block**:
all columns `(b,y)` with `y in U0^R`, and none outside. Moreover each row of
this b-to-b block has support at most `5^R`: outside the seed-support union,
the local factors reduce to the identity and force the matching symbol; inside
it, the only possible symbols lie in `U0`. Thus the exact maximum row support
of this diagonal label block is `5^R`.

The full physical row `(b,c^R)` can have additional nonzeros in other output
label blocks. They cannot cancel the `5^R` entries just counted, since those
are entries of the same block with fixed column label b. Therefore

```
max_row_support(C) >= 5^R.
```
This is a selected-row lower bound on the whole canonical projector and an
exact maximum for its selected diagonal block. The global maximum across all
label blocks may be larger; no exact global maximum is claimed. This is enough
to decide sparsity: outputting the selected physical row already requires
`Omega(5^R)` entries, so no polynomial row-list algorithm can exist for this
fixed V/B/C when R is the BMVZ hard-family amplification parameter.

## Costs, scope, and falsifiers

- **Alphabet/dimension:** `D=L+1=2^q=poly(n)` labels; `N=poly(n)` logical
  data qubits; physical dimension `D 2^N`.
- **V circuit:** polynomially many exact algebraic PREPARE rotations plus a
  controlled SELECT with polynomially many `O(R)` controlled clause circuits.
  The label dimension is polynomial, and `R` is polynomial in the BMVZ input.
- **B:** diagonal label-only projection, q-local, row support exactly 1,
  constant coefficient bit cost.
- **C circuit and entries:** exact circuit size polynomial; each entry has
  polynomial arithmetic-circuit size and polynomial-time b-bit evaluation.
  In the selected seed block, entries are rationals with `O(R)` bits.
- **C locality:** an explicit sum of `O(L^4)` terms, each touching at most q
  label bits plus `10R` data bits. This is not constant locality.
- **C rows:** exact maximum `5^R` within the selected diagonal label block;
  the full maximum is at least `5^R` and at most
  `min{(L+1)2^N,O(L^3 2^(10R))}`. Listing the selected full physical row costs
  at least `5^R` output operations.

BMVZ takes constant `t` and
`ell=ceil(6 log p_gap(n)/log t)`, where `p_gap` is the inverse-polynomial
soundness parameter, so `R=(2t)^ell=p_gap(n)^{O(1)}` is a positive power of n.
The BJSW unary-completeness exponent (chosen independently, e.g. n^3) only
ensures the yes energy stays negligible after BMVZ's polynomial completeness
loss. Hence `R` is polynomial in n and in the final output size, while `5^R`
is superpolynomial in either size.
The exact generator and hardness membership are audited in the Cycle-2 source
audit. Both local exact checks passed:

```
python3 outputs/research/games_hamiltonians/cycle2/bmvz_bjsw_seed_pair_test.py
python3 outputs/research/games_hamiltonians/cycle3/complement_lcu/check_seed_block_rows.py
```

The seed-pair check verifies the local preparations, the relative-basis entry magnitude
`1/(2 sqrt(2))`, all 32 local rows, and the amplified R=1,2 support formula.
The second script directly evaluates the exact rational tensor formula over all
32^R columns for R=1,2,3 and confirms counts 5,25,125, with no support outside
`U0^R`. The tensor formula and the `5^R` row count are proved symbolically;
these finite tests do not allocate the asymptotic exponential matrix.

**Boundary / exact falsifier.** The global maximum row support of C for this
fixed completion is not computed, and this result does not bound all other
unitary completions A or all positive C with the same kernel. The exact
falsifier for the row claim is a zero among the stated tensor entries for some
`y in U0^R`; the rational case split proves none exists. A uniform polynomial
row-list for the *same fixed C* is falsified by the explicit `5^R` output row.
To extend the result to every PREPARE completion or to every enforcer, one needs
a separate theorem controlling the output-label-basis dependence or arbitrary
sparse positive row relations of the LCU frame.

## Boundary against the inherited positive-PCP bridge

The N11 card says the general common encoding of an actual hard family and
positive sparse logical compression/enforcement were still missing. The
complement LCU supplies one common `V,B` with the exact positive compression
`H<=V*BV<=2H` for this family, but its canonical `C` fails polynomial row
access by the selected-row proof above. It therefore does not meet the bridge's
full `V,C,B` interface or close the sparse-QMA/PCP gate.

The N26 theorem in the bridge is a bounded-local-syndrome result with a fixed
auxiliary Hilbert space and a positive term-norm budget. Its conclusion is not
a no-go for arbitrary positive sparse matrices, sector-coupling encodings, or
all possible auxiliary identifications. The present result instead analyzes
one explicit LCU range projector and proves an exponential row in its physical
basis. Neither statement should be promoted to a theorem about every coherent
encoding. The bridge's conditional `(C+B)/2` conversion remains available only
when a polynomial-row, constant-gap `C` has actually been supplied.

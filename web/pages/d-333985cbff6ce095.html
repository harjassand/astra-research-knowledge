# Cycle 2: actual term generator, seed membership, and a sparse history encoding

Status: **bounded result; the constant-gap common positive encoding remains open.**
This note independently extracts the BMVZ term generator, gives an exact
hardness-preserving instance in which the Cycle 1 seed-pair witness really is
generated, and constructs a common history isometry for the *whole* explicit
constant-local algebraic-projector list. The history enforcer has constant
row support but gap Θ(K^-2), where K is its polynomial clock length.

## 1. What the BMVZ generator actually outputs

The primary source is Bergamaschi–Metger–Vidick–Zhang, arXiv:2510.01333v1,
Definitions 1.6, 1.7, and 1.9. Definition 1.6 (HTML lines 214–224) first
decomposes the normalized input as

    H = sum_chi w_chi H_chi,     H_chi = (1/m_chi) sum_i Pi_i^chi,

where the projections in a fixed color/layer commute. A d-regular expander
G_chi is placed on that layer's clause vertices. Definition 1.7 (lines
225–227) makes F_chi a one-to-one listing of every length-t path in G_chi;
it does not use all of [m_chi]^t. For each such path f, the output clause is

    h_(chi,f) = I - tensor_(a=1)^t (I - Pi^chi_(f(a))),

and Definition 1.9 (lines 234–240) averages these clauses within each layer
and then weights by w_chi. The paper says the small-layer case
m_chi <= m_0 is handled by trivially repeating clauses (line 224). It gives
no named adjacency table in these definitions. The sparse-PCP discussion
(lines 194–209) explicitly leaves use of the tensor structure for
sparsification open.

The important membership distinction is:

* A path clause belongs to one color only. Thus two noncommuting base
  projectors cannot be factors of the same clause if they are embedded on
  the same physical support and are noncommuting as full-system operators.
* A base vertex in a regular layer occurs in some path, so its seed appears
  as a factor of at least one output clause when t >= 1.
* A constant tuple (i,i,...,i) requires a self-loop at i (under the usual
  vertex-sequence convention). Definition 1.7 does not assert self-loops.
  Therefore the Cycle 1 bare witness cannot be inferred merely from the
  general path definition for an unmodified, unnamed input term table.

The BJSW source is *Zero-knowledge proof systems for QMA*, arXiv:1604.02804,
Section 2, proof of Theorem 2. Lines 175–189 specify the gate set
{Lambda(P), H tensor H} and the five-local propagation form (Eq. 4), with a
common two-clock-qubit pattern |10>. Lines 191–202 give the rank-one
three-qubit stabilizer vectors, including

    phi_3 = |-> |00>,
    psi_3 = (|000> - |011> - |101> - |110>)/2.

Tensoring each with the same |10> clock state gives the five-qubit seed pair
used in leaves/15_positive_encoding.txt. Their overlap is exactly
1/(2 sqrt(2)); hence their rank-one projectors do not commute when embedded
on the same five wires. This is a fact about the seed matrices. It does not
by itself say that the unmodified propagation terms at two different gate
times have identical five-wire supports.

### A generated-family membership witness that preserves QMA-hardness

There is a direct way to make the seed-pair test literal within BMVZ's
weighted layered interface. Start with the constant-layer, bounded-degree,
BJSW-derived 5-LCH QMA-hard family
`H_base=sum_chi v_chi H_chi`. On five fresh ancilla qubits, add the legal
5-LCH projectors `P_phi=|phi_5><phi_5|` and
`P_psi=|psi_5><psi_5|` as two separate singleton colors, each of weight
`1/4`, and scale the original color weights to `v_chi/2`. The augmented
Hamiltonian is

    H_aug = (1/2) H_base tensor I + (1/4) P_phi + (1/4) P_psi.

The two seed projectors have a common kernel of dimension at least 30 on
their fresh register. Hence

    lambda_min(H_aug) = lambda_min(H_base)/2.

The promise gap shrinks by exactly 1/2, preserving QMA-hardness. The number
of colors stays constant and all color weights remain bounded below. Each
new color has one commuting projector; the seed qubits have incidence two,
so the original bounded-incidence promise is retained. BMVZ Definition 1.6
permits positive layer weights, and its small-layer rule explicitly handles
a singleton by repeating its clause. Thus every path clause in each new color
is exactly

    h_phi^(t) = I - tensor_(a=1)^t (I - P_phi^(a)),
    h_psi^(t) = I - tensor_(a=1)^t (I - P_psi^(a)).

The two clauses occur in distinct layers of equal weight. This is a valid
BMVZ output from a hardness-preserving five-qubit input, not
an assertion that every unmodified BJSW propagation table contains a
same-support copy of the pair. If “the generated family” means one particular
unmodified reduction instance and its specific expander adjacency lists,
that instance-specific membership question still needs those lists; the
paper's abstract definition does not name them.

For the two-clause subinstance, the Cycle 1 lower bound now has an actual
generated-family witness. Let U_phi,U_psi be Clifford decoders and
W=U_psi U_phi*. Since W is Clifford and nonmonomial (it sends a computational
basis vector to a state with overlap 1/(2 sqrt(2)) with |0^5>),
max|W_yz| <= 1/sqrt(2). On t repeated dummy blocks,
max|(W tensor ... tensor W)_yz| <= 2^(-t/2). Therefore every nonzero row of
an exact enforcer for the *bare two-branch isometry* has support at least
1+2^(t/2), by the Gram/Gershgorin lemma in
work/programmes/games_hamiltonians/leaves/15_positive_encoding.txt.
This is not a lower bound for an arbitrary encoding of the full amplified
hard Hamiltonian: that Hamiltonian also has the original hard clauses and
other branches, and the maximum-coherence condition for the full list has
not been proved.

## 2. Full-list extra-workspace construction (polynomial row support, low gap)

This construction applies to the full BMVZ output list from any fixed-local
projector input whose terms have polynomial-bit exact algebraic matrix
descriptions (the term-matrix representation is part of the input interface).
For each base k-local projection P_i, choose an exact local
unitary U_i and a diagonal projection D_i with P_i=U_i*D_iU_i. Since k is
constant, exact algebraic row reduction and orthogonalization compute this
diagonalization in polynomial bit time. Clifford terms are a special case;
the augmented seed pair uses Clifford diagonalizers. Iterated OR amplification
preserves the factor form because complements and tensor products of diagonal
projections remain diagonal.

For one round, write the actual output as

    H = sum_(j=1)^M w_j h_j,
    h_j = I - tensor_(a=1)^t (I - Pi_(j,a)),  sum_j w_j = 1.

For each factor choose the corresponding constant-local diagonalizer U_(j,a)
and diagonal projection D_(j,a), and let

    U_j = tensor_(a=1)^t U_(j,a),
    D_j = I - tensor_(a=1)^t (I - D_(j,a)).

Here each designated k-wire set may depend on j and a. D_j is diagonal,
positive, and a projection, and h_j = U_j* D_j U_j. The use of a separate
D_j avoids an uncharged support-relocation circuit.

For further rounds, replace this displayed D_j by the recursively flattened
diagonal predicate generated from the previous-round clauses; the same
identity h_j=U_j*D_jU_j holds and the predicate has polynomial description
size for the explicit BMVZ term generator.

Flatten each iterated BMVZ clause to its R original local-projector factors.
For adjacent clauses j,j+1, the relative decoder factors over the R disjoint
data blocks as U_(i_(j+1),r) U_(i_j,r)*. Each factor acts on the union of two
k-wire supports, at most 2k qubits. Any such fixed-size algebraic unitary
has an exact decomposition into a constant number of one- and two-qubit
algebraic unitary gates. Thus ell_j<=c_k R for a constant c_k depending only
on k. Include one identity gate if two decoders coincide, so ell_j>=1. Put
L = sum_(j<M) ell_j.

Choose an integer Q such that q_j = Q w_j are positive integers, Q >= L,
Q >= 1/min_j w_j, and Q >= 2. This is polynomial for the BMVZ hard family: there
are a constant number of layers, each layer has uniform path weights, and
the layer weights/path counts have a common denominator Q_0 polynomially
bounded in value; M and t are polynomially bounded. More generally the
cost is polynomial exactly when a polynomially bounded common denominator
Q_0 for the w_j exists. Use Q=Q_0 times a sufficiently large integer to
meet the two lower bounds.

Make a line of clock positions as follows. Give clause j a tail T_j of q_j
consecutive positions, all with decoder U_j. Between T_j and T_(j+1), put
ell_j-1 intermediate positions carrying the successive partial products
of the ell_j transition gates. The initial number of positions is

    K_0 = sum_j q_j + sum_(j<M)(ell_j-1) = Q + L - M + 1.

Append idle positions with decoder U_M and no logical test until K is the
smallest power of two at least K_0. Since L >= M-1 and Q >= L,
Q <= K_0 <= 2Q and K < 2K_0 <= 4Q.

For s=0,...,K-1, let U_s be the decoder at position s, with
U_(s+1)=G_s U_s and G_s either a one-/two-qubit algebraic unitary gate or
identity.
With a K-dimensional clock and n' data qubits (n'=n_0t in one round), define

    V|psi> = (1/sqrt(K)) sum_(s=0)^(K-1) |s> tensor U_s|psi>.

The clock has log_2 K qubits. V is an isometry. It has a polynomial-size
description: prepare the uniform clock with Hadamards, apply U_0, and apply
each transition gate G_s controlled on the clock having passed position s.
The controlled local-gate sequence has O(L log K) fixed-size gates (or a
polynomial-size exact algebraic gate description). The gate list and local
matrix entries are computable in polynomial time; K is a power of two, so
the clock amplitude is exact.

Define the positive edge operator

    e_s = (1/4)[ |s><s| tensor I + |s+1><s+1| tensor I
                 - |s+1><s| tensor G_s - |s><s+1| tensor G_s* ],
    C = sum_(s=0)^(K-2) e_s.

Each bracket is positive (its two-clock block is
[[I,-G_s*],[-G_s,I]]), so e_s >= 0. Under the gauge unitary
W = sum_s |s><s| tensor U_s, C is the path-graph Laplacian divided by 4,
tensor I_data. Therefore

    ker C = ran V,
    C >= gamma_K (I - V V*),
    gamma_K = (1 - cos(pi/K))/2 = Theta(K^(-2)),
    ||C|| = (1 + cos(pi/K))/2 < 1.

Define

    B = sum_j sum_(s in T_j) |s><s| tensor D_j,

and set B=0 on all intermediate and filler positions. B is a positive
contraction. For every logical state, as an operator identity,

    V* B V = (1/K) sum_j q_j U_j* D_j U_j
            = (Q/K) H.

Because Q/K > 1/4, the compression holds with alpha=beta=Q/K >= 1/4.
All quantifiers are full-space: ker C is exactly the common isometry image,
the C gap applies to every output vector orthogonal to that image, and the
B identity holds on every logical vector. No promise about an auxiliary
input state is being substituted for an operator inequality.

### Exact costs and the remaining loss

* Output size: n' data qubits plus log_2 K clock qubits (n'=n_0t for a single
  t-fold amplification); M is the actual number of BMVZ clauses and K<4Q
  is polynomial in M, the gate-synthesis length, and the weight denominator.
* Positive terms: K-1 terms e_s for C, each with coefficient 1/4 and norm
  1/2; B is one diagonal projection specified by its clock blocks.
* Row support: each G_s acts on at most two data qubits, so a row of C has
  at most one diagonal entry and at most four entries at each of the two
  neighboring clock values: at most 9 nonzeros. A row of B has at most 1.
* Entry/precision cost: after splitting each transition into one-/two-qubit
  gates, a row of C has at most 9 entries. Its gate entries are exact
  algebraic numbers of polynomial bit height; the local algebraic degree is
  bounded by a constant depending on k and the input-term encoding. B entries
  are 0/1; its row algorithm evaluates the OR of R local diagonal predicates
  in O(R) time. The circuit description of V is polynomial; each gate's
  coefficient representation and the clock amplitude 1/sqrt(K) are charged
  explicitly. Addresses use O(n'+log K) bits.
  This exact statement assumes polynomial-bit exact local algebraic matrices;
  an approximate-entry-only input would need an operator-norm perturbation
  analysis before claiming the same kernel and gap.
* The gap is gamma_K=(1-cos(pi/K))/2, not a constant. Since K is polynomial,
  this is an inverse-polynomial gap. Rescaling C cannot repair it while
  keeping C a contraction: the top path eigenvalue is already bounded away
  from zero and one.

This is the extra-workspace escape in a transparent serial-history
architecture. It meets exact common-image, positivity, row support, entry,
and compression requirements for the full five-qubit rank-one family, but
misses the required constant image gap. It does not imply a sparse-PCP
result.

## 3. Exact next lemma and falsifiable test

The next theorem-sized step is to replace the line history by a **bounded
degree transported history graph** on the actual clause decoders U_j, while
preserving all three properties simultaneously:

1. every edge transition is implemented by a constant number of local
   gates (so the covariant edge terms keep constant row support);
2. the positive covariant graph Laplacian has an absolute spectral gap;
3. a constant fraction of its normalized history mass sits on clause-test
   vertices with masses proportional to w_j, so V*BV remains a constant
   multiple of H.

Subdividing a shortcut into the O(t) local gates used above gives a path
bottleneck and gap O(t^-2); the required lemma must avoid that loss or prove
it unavoidable in the stated architecture.

Falsifiable test: for the concrete BMVZ instance, emit the exact clause
table (layer, path, factor support, Clifford tableau, weight), build the
candidate transported graph and its exact-algebraic covariant Laplacian,
and compute a certified interval for its second eigenvalue along a family
with increasing t. A candidate claimed constant-gap construction is
refuted if a certified value falls below its claimed constant, or if any
output row exceeds its claimed support after local gate decomposition. For
the direct-branch route, compute

    mu_* = max_(j != k, x,y) |(U_j U_k*)_(x,y)|.

First merge identical branch encoders, as specified in the leaf note. The
Gershgorin lemma gives an exponential row lower bound only if
mu_* <= 2^(-rho t) for a fixed rho>0; the dummy pair certifies this for one
pair but not automatically for the maximum over the full list.

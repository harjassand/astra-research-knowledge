# Scale-free endpoint sampling for bounded-degree Boolean-polynomial XOR bursts

Construction and proof candidate, 2026-10-12. Novelty is not established.

Mechanism-selection update: the same approximate endpoint capability follows more simply by commuting the independent type endpoints, directly simulating low-intensity types, and replacing high-intensity types by their uniform coefficient-span laws using a uniform Fourier-decay bound. That method extends to every fixed prime characteristic and avoids continuous-time numerical issues. See commuting_polynomial_jump_sampler.md. The adaptive construction below remains a valid exact ideal-law representation with shared-rank event savings; it is not a broader tractability result.

## The acquired capability

Let X take values in F_2^D and start at x_0. Independently for each type j, at Poisson rate lambda_j perform

    X <- X + F_j(U),

where U is a fresh uniformly random n_j-bit string, and F_j is an explicitly supplied Boolean multilinear polynomial map from F_2^(n_j) to F_2^D. Suppose its degree is at most a supplied bound k. Rates and horizon T are binary rational. Different types may have arbitrary rate ratios.

There is an endpoint sampler within TV epsilon with work polynomial in the explicit polynomial input size, D, 2^k, all input bit lengths, and log(1/epsilon). In particular, its work is polynomial for fixed degree, or degree O(log N) where N is the explicit input size, and is independent of the numerical raw-event count T sum_j lambda_j. It does not need to count polynomial solutions, compute innovation probabilities, enumerate output states, or acquire conditional paths.

The ideal real-arithmetic sampler is exact and uses at most D rank increases. The expected number of proposed events before completion or the horizon is at most D 2^k (up to a final censored clock query).

## 1. Exact heat-bath replacement in characteristic two

For a fixed mark J, let T_J translate by J. Since J+J=0, a uniform choice between adding zero and adding J is uniform averaging on the two-point subgroup span(J). At the generator level,

    2 lambda [ E_J (I+T_J)/2 - I ]
       = lambda [ E_J T_J - I ].

Thus the original type-j jump process is exactly the same continuous-time semigroup as a rate-2 lambda_j process that draws J=F_j(U), then adds a J with a an independent fair bit. This equality is specific to characteristic two in this form.

Conditional on the proposed marks, all the a coefficients are independent uniform bits. The endpoint consequently has law

    x_0 + Uniform(W),

where W is the span of every proposed mark seen so far. The hidden span process updates W to span(W,J). Convolution of uniform subspaces gives an exact positive generator intertwining with the original XOR process.

## 2. Exactly recognize and delete clocks that are already absorbed

Express each polynomial in Boolean multilinear form:

    F_j(u)=sum_A c_(j,A) product_(i in A) u_i,

with vector coefficients c_(j,A) in F_2^D. Reduce powers using u_i^2=u_i and combine duplicate monomials by XOR before applying the test. For explicit polynomial input, this normalization is polynomial in its size.

A type's entire image lies inside W if and only if every coefficient vector c_(j,A) lies inside W.

The forward implication follows by reducing the polynomial modulo W: the Boolean square-free monomials form a basis of all functions on the Boolean cube, so a zero quotient-valued function has every coefficient zero. The reverse implication is immediate.

For such a type, every heat-bath mark lies in W and acts identically on Uniform(W). Its hidden generator is zero, so its clock can be deleted exactly. Because W only grows, an absorbed type never needs to be reactivated. This is a deletion of a provably null conditional operation, not a rate approximation.

All containment checks are Gaussian-elimination membership tests on explicitly supplied coefficient vectors.

## 3. Every remaining proposal has acquired success probability

Suppose type j is active, so at least one of its coefficient vectors is outside W. Choose a linear functional ell vanishing on W but not on that coefficient. Then

    f(u)=ell(F_j(u))

is a nonzero Boolean multilinear polynomial of degree at most k. Such a polynomial satisfies

    P(f(U)=1)>=2^(-k).

A short induction proves this. A nonzero constant has weight one. Otherwise choose a variable occurring in a highest-degree monomial and write f=x_i g+h, where g is nonzero and has degree at most k-1. Whenever g=1, the two values obtained from x_i=0,1 are opposite, so exactly one is 1. Hence P(f=1)>=P(g=1)/2>=2^(-k).

Since f(U)=1 implies F_j(U) is outside W,

    P(J outside W | active type j)>=2^(-k).

This bound is uniform in W and in all previous history. It is also valid for any rate-weighted mixture of active types. It is an acquired anti-concentration certificate, not an inference from low output rank.

## 4. The sampler

Set W={0} and elapsed=0. Repeat:

1. Mark active exactly those types with at least one coefficient vector outside W.
2. If no type is active, output x_0+Uniform(W).
3. Let R=2 sum_(active j) lambda_j. If R=0, output x_0+Uniform(W).
4. Draw a wait of rate R. If it exceeds the remaining horizon, output x_0+Uniform(W).
5. Advance time by the wait. Choose type j proportional to its lambda_j among active types.
6. Draw a fresh uniform n_j-bit input, evaluate J=F_j(U), and replace W by span(W,J). A contained J gives a null proposal. Return to step 1.

After every proposal, the hidden conditional distribution is x_0+Uniform(W). Deleting absorbed clocks is exact because their hidden transitions are identities. Simulating the remaining competing clocks therefore gives exactly the span-process endpoint. The final uniform-subspace draw gives exactly the original endpoint in ideal real arithmetic.

One can update the active list only after a rank increase; null proposals leave every membership test unchanged.

## 5. Why the runtime does not depend on event count

Every genuine innovation increases dim W by one, so there are at most D. Before termination, every active proposal independently conditional on its history has success probability at least rho=2^(-k). Couple its success indicator to an auxiliary Bernoulli(rho) indicator. The proposal count is stochastically dominated by the number of Bernoulli trials needed for D successes, stopped even earlier if the horizon or absorption is reached.

Thus its expectation is at most D/rho. For a bounded-work TV-epsilon implementation, cap proposals at

    M=ceil[4 rho^(-1) (D+log(4/epsilon))].

If the process is still running at this cap, fewer than D innovations have occurred. A binomial lower-tail bound makes this probability at most epsilon/4. On the cap event an arbitrary output can be charged to the TV budget.

Each proposal uses polynomial input evaluation and finite-field linear algebra. The rate-weighted categorical draw has polynomial-bit exact sampling routines. Very fast types disappear as soon as their whole coefficient image is absorbed, regardless of how many subsequent raw events their clocks would have generated.

## 6. Finite-bit time and sampling error

Only a finite endpoint is requested. A discretized real-time sample is singular in TV from its continuous law, so raw waiting-time TV is not the appropriate claim.

Let Lambda=2 sum_j lambda_j. Zero-rate and zero-horizon cases are immediate. With at most M proposals, couple ideal and rounded waits to absolute accuracy

    delta=epsilon/[256 (M+1)^2 Lambda].

Accumulated horizon error is at most M delta. Every next-wait density is bounded by its current rate R<=Lambda. Summing over possible horizon-crossing comparisons bounds the probability of a different stopping decision by O(M^2 Lambda delta), a fixed fraction of epsilon. Until that comparison differs, the two algorithms can use identical types, input bits and span updates.

Inverse-CDF sampling produces each exponential wait to this absolute precision with polynomially many bits, outside a small tail that is charged to the error budget. Its current nonzero rate is a sum of a subset of the input rates, so log(Lambda/R) is bounded polynomially in their binary input size. Excluding uniform random inputs below epsilon/poly(M), approximating logarithms, and allocating per-proposal failure probabilities gives the desired bound. This costs polynomial bit length rather than numerical rate magnitude or numerical horizon.

For an explicit precision choice, let R_min=2 min_{lambda_j>0} lambda_j and theta=epsilon/[64(M+1)]. Couple a continuous uniform U with its b-bit midpoint rounding U_b. Charge the event U<theta to the error budget. On the complement, if 2^(-b)<=theta R_min delta/8 and 2^(-b)<=theta/2, then

    |log U-log U_b|<=2*2^(-b)/theta.

Compute log U_b to absolute error at most R_min delta/4, and divide by the current R>=R_min. The resulting wait has error below delta. It suffices to use

    b=O(log(Lambda/R_min)+log(1/epsilon)+log(M+1)),

with loose constant multiples absorbing the two epsilon factors and powers of M. Logarithms at this precision are computable in polynomial bit work. Since every positive input rate is binary rational, log(Lambda/R_min) is polynomial in their encoded bit lengths. There is no inverse rare-probability rejection or numerical-rate factor hidden in this step. Comparisons and accumulated times require only the additional encoded bit length of T.

Exact rational categorical draws and uniform finite-field draws can be sampled with expected polynomial bits; cap their exceptional tails if bounded work is required. Gaussian elimination, polynomial evaluation and final subspace sampling are exact over F_2. Allocate the remaining epsilon budget among these rare truncations, the proposal cap, and time-rounding failures.

Therefore the finite-bit endpoint law is within TV epsilon and the total work is polynomial in the stated parameters.

## 7. Reproducible finite-generator check

The companion script boolean_polynomial_xor_checks.py enumerates all 67 subspaces of F_2^4 and compares their positive span generator to the 16-state XOR generator for five explicit polynomial mark types. These include correlated degree-two and degree-three vector maps, a degree-three single monomial attaining the 1/8 innovation lower bound, a constant nonzero map, and the zero map.

The script checks:

- Coefficient-containment iff entire-image containment, for every subspace/type pair.
- The 2^(-degree) innovation lower bound for every active pair.
- Exact generator intertwining G R=R Q, with R the uniform-subspace lift.

Executed output:

    D=4: 67 span states, 16 endpoint states
    checked 335 image-containment and innovation-weight instances
    generator intertwining residual=0; minimum weight/bound ratio=1

All numbers in that generator check are dyadic rationals represented exactly by the displayed floating-point operations. The general proof is Sections 1-4; the finite check tests the implementation and normalization conventions.

## 8. Scope and limitations

Acquired scope:

- Arbitrarily heterogeneous independent compound-Poisson XOR bursts.
- Fresh independent random input bits at each event.
- Correlated, wide-support output patterns, provided their explicit polynomial degree is bounded.
- Any fixed initial state, with a known affine initial uncertainty space handled by starting from that W instead of zero.

Not established:

- State-dependent or path-dependent mark maps.
- Shared control randomness across different event times, unless incorporated into a separately supplied valid model.
- Arbitrary noncommuting triangular circuits: their gates rotate prior response spans, whereas W in this additive construction grows monotonically.
- Polynomial complexity for arbitrary degree k: the acquired bound contains 2^k.
- A practical implementation or measured wall-clock performance at large dimension, or a novelty/priority claim.

The polynomial degree and explicit coefficient representation are substantive hypotheses. A succinct Boolean circuit or an oracle for F does not automatically give the required coefficient-containment operation.


## 9. Sharp boundary for a succinct, unrestricted Boolean-circuit interface

Do not replace the explicit bounded-degree polynomial input by an arbitrary succinct Boolean circuit while retaining the same claimed guarantee. Suppose D=1, the jump map F is a Boolean circuit on n uniformly random bits, lambda=1, and the binary-encoded horizon is T=2^n. The number of nonzero XOR flips is Poisson with mean #SAT(F). Its endpoint therefore satisfies

    P(X_T=1)=[1-exp(-2 #SAT(F))]/2.

For an unsatisfiable circuit this probability is zero. For a satisfiable circuit it is at least (1-exp(-2))/2, a fixed positive constant. A polynomial-time sampler with a sufficiently small constant TV error for this unrestricted interface would distinguish the cases by repeated endpoint samples, implying NP is contained in BPP.

This is a complexity-theoretic barrier to that broader interface, under the standard conjecture NP is not contained in BPP. It is not a hardness proof for explicit low-degree polynomials, nor for every growing-degree family. In the constructed sampler the degree-dependent factor is exactly 2^k up to polynomial overhead; degree O(log N) remains polynomial when the polynomial representation is explicit.

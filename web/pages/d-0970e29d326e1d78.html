# High-ceiling route: diagonal Naimark dilation versus a sparse image enforcer

Status: **exact positive-compression constructions; sparse common enforcer
still open.** A term-label Naimark dilation gives exact compression of the
complete augmented BMVZ Hamiltonian. More strongly, an LCU block encoding of
`I-H` gives a polynomial-circuit isometry and one ancilla-diagonal positive
contraction B with `H <= V*BV <= 2H`. Its canonical exact image enforcer has
gap one. For an explicit seed-adapted PREPARE completion, a same-label block
row has exactly `5^R` entries (Cycle 3); the global maximum may be larger.
Other PREPARE completions and other enforcers remain open. A constant-gap
weighted-star enforcer for the term-label image has an exponential row for
the actual repeated BJSW seed pair. A separate lower bound rules out only
bounded scalar-polynomial channel dilations with ancilla-only B on a
fine-spectrum augmentation. No general sparse C construction or all-V
impossibility is claimed.

## Interface and actual hard input

The target interface is one isometry `V : L -> K`, a common positive
contraction `B` diagonal in the physical computational basis, and a positive
contraction `C` satisfying, on the entire physical space,

    ker(C) = ran(V),
    C >= gamma (I - VV*),
    alpha H <= V* B V <= beta H,

for constants `alpha,beta,gamma>0` independent of input size and BMVZ
amplification depth. There is no auxiliary-state promise: the compression is
an operator inequality on every logical vector and the gap protects every
vector orthogonal to `ran(V)`.

Use the actual BMVZ generator on a hard 5-LCH input, augmented as in
`outputs/research/games_hamiltonians/cycle2/bmvz_bjsw_source_audit.md`: add the
two BJSW five-qubit rank-one Clifford seeds

    phi = (|00010> - |10010>)/sqrt(2),
    psi = (|00010> - |01110> - |10110> - |11010>)/2

on a fresh register as two separate singleton commuting layers of constant
weight. The old hard Hamiltonian is scaled by `1/2` and each seed layer has
weight `1/4`. The two seeds have a common kernel of dimension 30, so yes energy
and no energy are both changed only by constant factors. BMVZ's singleton
rule repeats its sole clause, producing both `I-(I-|v><v|)^{tensor R}` terms
in the amplified output. This is a deliberately augmented hard input, not a
claim that both seeds occur in every unmodified BJSW instance.

The generator/source audit is independently readable at
`outputs/research/games_hamiltonians/cycle2/bmvz_bjsw_source_audit.md`.
BMVZ Definitions 1.6--1.9 (HTML lines 214--240) define the weighted commuting
layers, list every length-t expander path, and emit the projective clauses
`I - tensor_s (I-Pi_s)`. The small-layer case is handled by repeating clauses
(line 224). For the iterated hard family, Theorem 7.3 gives polynomially many
terms/qubits and negligible yes energy (lines 1031--1075); Theorem 7.4 obtains
the hard starting family from equitable layers (lines 1078--1083), with the
bounded-degree/equitable construction at Claim 8.1 and Corollary 8.4 (lines
1102--1125). BJSW Theorem 2 permits any polynomial unary completeness exponent
(HTML lines 157--180) and supplies the two rank-one seed types in its
propagation decomposition (equations (4)--(7), lines 182--204).

Write the complete iterated BMVZ output as

    H_B = sum_{j in J} w_j h_j,       sum_j w_j = 1,
    h_j = U_j* D_j U_j,

where every `h_j` is the actual generated clause, each `D_j` is a diagonal
projection, and `U_j` is a product of constant-size local diagonalizers over
the clause's repeated factors. For the added BJSW seed terms these are the
explicit Clifford diagonalizers checked below; for other starting terms the
cost assumes their constant-size local matrix descriptions are supplied with
polynomial bit/access complexity. Let `R=(2t)^ell` be the number of
five-qubit seed blocks in a seed-layer output clause. BMVZ's choice has
`ell=ceil(6 log p(n)/log t)` with constant `t`, hence `R` is polynomial and
grows as a positive power of the inverse-gap polynomial. The precise term
table has `M=|J|=poly(n)` labels.

For the fine-spectrum test below, add `r=n` fresh, disjoint five-qubit
registers and let `P_k=|10000><10000|` on register k. Put

    delta = 1/4,
    delta_k = delta * 2^(-k)/(1-2^(-r)),       k=1,...,r,
    H_fine = (1/2) H_B tensor I + sum_k delta_k P_k.

This is still QMA-hard: a yes witness for `H_B`, tensored with
`|00000>^{tensor r}`, has energy at most half the old yes energy; positivity
gives no energy at least half the old no threshold. It has `M+r` nonzero
terms, `5r` extra qubits, and rational coefficient bit length `O(r)` beyond
the BMVZ weights. If a normalized convex-combination presentation is wanted,
add a zero projector with weight `1/4`; it changes no operator and is also a
useful silent branch below.

The dummy registers realize every binary level exactly. For a subset S,

    sum_(k in S) delta_k = Delta * a,
    Delta = delta/(2^r-1),
    a = sum_(k in S) 2^(r-k) in {0,...,2^r-1}.

Since the BMVZ and dummy registers are disjoint, if `epsilon_n` is the lowest
eigenvalue of `H_B`, the full `H_fine` has exact eigenvalues

    lambda_0 = epsilon_n/2,
    lambda_1 = epsilon_n/2 + Delta.

Choose the BJSW unary completeness exponent `p(n)=n^3`. BJSW gives yes energy
at most `2^(-n^3)` before normalization; the BMVZ iterated completeness bound
multiplies by a polynomial in n. Thus `epsilon_n <= 2^(-n^3) poly(n)` on yes
instances, while `Delta=1/(4(2^n-1))`; consequently `epsilon_n/Delta -> 0`.
The augmented target remains hard with constant soundness and negligible
completeness. The full target is a positive sum of polynomially many
projectors, including the BMVZ O(n)-fold terms and local dummy terms.

## Exact common diagonal test from a Naimark frame

For every branch j use the actual term diagonalizer `U_j` above. On the full
logical register (base data plus dummy blocks) add a silent label c with
`U_c=I` and `D_c=0`. Define branch weights

    pi_c = 1/4,
    pi_j = (1/2) w_j                 for j in J,
    pi_k = delta_k                   for k=1,...,r.

They are positive and sum to one. The common isometry and common physical
diagonal test are

    V|z> = sqrt(pi_c)|c> U_c|z>
           + sum_j sqrt(pi_j)|j> U_j|z>
           + sum_k sqrt(delta_k)|k> I|z>,
    B = |c><c| tensor 0
        + sum_j |j><j| tensor D_j
        + sum_k |k><k| tensor P_k.

The labels are understood disjointly. `V*V=I` because every branch unitary
preserves norm and the branch weights sum to one. `B` is an exact positive
contraction, diagonal in the physical basis, with row support exactly one;
entry access checks a branch and, for a BMVZ clause, scans its R seed blocks
to evaluate the diagonal OR predicate. As a single diagonal predicate, B
acts on the label and up to 5R data bits (the full clause support); it is not
constant-local. The compression is the exact operator identity

    V* B V = (1/2) sum_j w_j U_j*D_jU_j + sum_k delta_k P_k = H_fine.

This is a polynomial-size coherent circuit description of V: prepare the
amplitude state `|sqrt(pi)>`, then apply the branch-controlled Clifford
diagonalizers. There are `M+r+1=poly(n)` labels and each generated U_j has a
polynomial gate description. Exact algebraic rotations give the stated ideal
isometry; a fixed finite gate set gives an approximation, not an exact
operator inequality. Any approximation error must be charged against the
target's positive spectral floor (and an exact upper comparison on an exact
kernel requires an exact object). Clifford factors are exact. The binary
dummy weights and all branch weights have polynomial bit length; their square
roots have polynomial-size algebraic descriptions. Thus the ideal V and B meet
their circuit/access costs.

The Naimark formula is concrete here: for physical basis row `(j,y)`,

    v_(j,y) = V*|j,y> = sqrt(pi_j) U_j*|y>,
    sum_(j,y) |v_(j,y)><v_(j,y)| = I,
    V*BV = sum_(j,y) b_(j,y) |v_(j,y)><v_(j,y)|.

It solves the common-test half for the complete noncommuting Hamiltonian; it
does not by itself solve the image-enforcer half.

## LCU square-root dilation: exact constant-factor B, unresolved sparse C

The full target is a normalized sum of projections once the silent zero
projector of weight `1/4` is included. Split that silent weight among enough
zero-projector branches to make the number of LCU labels a power of two; this
preserves the operator, keeps every weight positive and rational with polynomial
bit length, and lets a q-qubit register represent the label space exactly. With
L denoting the number of non-identity branches after padding,

    H_fine = sum_(j=1)^L pi_j h_j,
    h_j^2=h_j,       pi_j>0,       sum_j pi_j=1.

The BMVZ clauses, dummy rank-one projectors, and zero projector are all
projections, and `0<=H_fine<=I`. Define the clause reflections

    R_j = I - 2 h_j.

They are unitary and satisfy

    Y := I-H_fine
       = sum_j pi_j (I-h_j)
       = (1/2) I + (1/2) sum_j pi_j R_j.

Prepare an LCU label state with amplitude `1/sqrt(2)` on an identity label
and amplitude `sqrt(pi_j/2)` on label j. Let A be any unitary preparation of
this state, and set

    SELECT = |id><id| tensor I + sum_j |j><j| tensor R_j,
    U = (A* tensor I) SELECT (A tensor I).

Then `<0|U|0>=Y` exactly. Let

    V|z> = U(|0> tensor |z>),
    B = (I-|0><0|)_label tensor I_data.

The first line means apply U to the fixed zero label and arbitrary logical
data; V is an isometry since U is unitary. B is a computational-basis
diagonal projection of row support one, with trivial entry access and norm
one. On every logical vector,

    V* B V = I - Y*Y = I-(I-H_fine)^2 = 2H_fine-H_fine^2.

Since `0<=H_fine<=I`,

    H_fine <= V*BV <= 2 H_fine.

This is an exact common positive compression with constants `alpha=1`,
`beta=2`, for the complete noncommuting BMVZ hard sum plus all dummy terms.
It is not the naive success-flag compression `H^2`: the selected diagonal
effect is the **failure** flag for a block encoding of `I-H`. The selected
failure component has squared norm `2H-H^2`, hence amplitude scale comparable
to `sqrt(H)` near zero. The output blocks are term-dependent and generally are
not scalar functions of H, so this is an escape from the restricted
all-polynomial-channel no-go below.

The LCU is polynomial size. By the padding above, the label alphabet has
`L+1=2^q=poly(n)` values with `q=log2(L+1)` qubits; the data register has
`N=N_B+5r=poly(n)` qubits. The diagonal B acts only on the label register, so
its locality is q=`O(log n)` and its computational-basis row support is one.
The isometry's circuit uses constant-local data gates after label controls
are decomposed; its total gate count is polynomial.
For a BMVZ clause, let

    Q_j = tensor_(s=1)^R (I-Pi_(j,s)),
    h_j = I-Q_j,
    R_j = 2Q_j-I.

Applying the constant-size local diagonalizers (Clifford for the forced BJSW
seed terms), computing the AND of the R zero-syndrome flags, applying a phase,
and uncomputing implements `R_j` with O(R) constant-local gates/ancillas,
assuming the supplied 5-local term descriptions support polynomial-cost
controlled local measurement. Reversible label lookup gives
a polynomial-size controlled SELECT for the L-term table; the dummy
reflections are five-local. PREPARE can be synthesized from a binary tree of
rotations whose probabilities are ratios of sums of rational branch weights.
It has a polynomial gate decomposition because the label dimension is
polynomial. Rational weights and their square roots have polynomial-size
algebraic descriptions. These are exact algebraic circuit objects; compilation
to a fixed finite gate set is approximate and must be charged against the
spectral floor if preserving negligible yes energy is required. Matrix-entry
formulas below use polynomial-size arithmetic circuits over these named
radicals; they can be approximated to b bits in time polynomial in `L,R,b`, but
this is not a claim about a canonical minimal-polynomial representation.

The canonical image enforcer

    C_LCU = U (I-|0><0|)_label tensor I_data U*

is a positive projection with `ker(C_LCU)=ran(V)` and
`C_LCU >= I-VV*` (gap one). This gives exact V/B/kernel/gap algebraically.
Its row support depends on the full PREPARE unitary A, not just its first
column. For the explicit seed-adapted completion in
`outputs/research/games_hamiltonians/cycle3/complement_lcu/01_canonical_C.md`,
one same-label block row has exactly `5^R` entries; this proves exponential
row support for that fixed C. For an unspecified completion no uniform row
lower bound is asserted. The entry/row ledger is explicit. Write `A` for the `(L+1)`-dimensional preparation unitary and
`chi_j` for the LCU amplitudes. The output blocks of V are

    K_a = sum_(j in {id,1,...,L}) conjugate(A_(j,a)) chi_j R_j,
    (VV*)_(a,b) = K_a K_b*.

For a pair of BMVZ terms,

    R_j R_k* = 4 Q_j Q_k - 2 Q_j - 2 Q_k + I.

Because the amplification copies are disjoint, each entry of `Q_j Q_k` is a
product of constant-size matrix entries on at most the union of two
five-qubit supports per copy. Thus one entry of `C_LCU=I-VV*` is computable
from O(L^2 R) constant-size algebraic operations, plus polynomial-size
arithmetic circuits for A and the weights. A requested b-bit approximation
takes time polynomial in `L,R,b` using interval arithmetic for the explicit
radicals. The physical matrix has `(L+1)2^N` rows. A rigorous row ledger
currently is only

    1 <= max_row_support(C_LCU)
      <= min{(L+1)2^N, O(L^3 2^(10R))}.

The power-of-two padding makes the label register dimension exactly `L+1`.
The second upper bound counts L+1 output labels, L^2 relative-reflection pairs,
and at most `2^(10R)` columns per pair because a pair acts on at most 10R data
qubits. These upper bounds need not be tight. The Cycle-3 file fixes a valid A
completion and proves `max_row_support(C_LCU)>=5^R`, with exact row support
`5^R` in one diagonal label block; thus that explicit C has no polynomial
row-list algorithm. For an unspecified PREPARE completion A, this construction
gives no lower bound beyond nonzeroness, and the exact global maximum remains
uncomputed. Circuit access and polynomial-time entry access alone do not
establish sparse-matrix access.

## A constant-gap common-label enforcer, and its exact row failure

It is useful to separate the branch-label gap from the data-register cost.
Let `i` range over every non-silent branch, so `sum_i pi_i=3/4`. Define a
reversible star Markov chain T with hub c by

    T_(i,c)=1/3,       T_(i,i)=2/3,
    T_(c,i)=pi_i/(3 pi_c),       T_(c,c)=0.

Every row sums to one, and detailed balance holds:
`pi_i T_(i,c)=pi_c T_(c,i)=pi_i/3`. The symmetric similarity
`S=diag(sqrt(pi)) T diag(1/sqrt(pi))` has eigenvalues `1`, `2/3` (leaf
differences), and `-1/3` (the remaining two-state mode). Let

    W = sum_j |j><j| tensor U_j,
    C_star = (3/4) W ((I-S) tensor I_data) W*.

Then `C_star>=0`, `||C_star||=1`,

    ker(C_star) = ran(V),
    C_star >= (1/4)(I - VV*).

The algebraic gap is exactly constant. In the physical computational basis,
however, the off-diagonal hub/leaf block is

    (C_star)_(c,i) = -(1/2) sqrt(pi_i) U_c U_i*.

Thus a branch-sparse graph is not necessarily a row-sparse physical matrix.
The diagonal blocks cost one entry per row, but a hub/leaf row also contains
the row support of the relative data unitary. A direct dense projector
`I-VV*` has the same issue, with blocks
`delta_(i,j) I - sqrt(pi_i pi_j) U_i U_j*`.

For the forced BJSW seed branches, the exact five-qubit relative Clifford
`W0=U_phi U_psi*` has 8 nonzeros in every row (the 32-by-32 matrix has 256
nonzeros); every nonzero magnitude is `1/(2 sqrt(2))`. The prior exact test
`python3 outputs/research/games_hamiltonians/cycle2/bmvz_bjsw_seed_pair_test.py`
passes and records this in `bmvz_bjsw_seed_pair_table.csv`. Over R disjoint
seed blocks,

    sigma(U_phi^(tensor R) U_psi*^(tensor R)) = 8^R,

where sigma is maximum row support. For any choice of hub unitary U_c,
multiplicativity of row support gives

    sigma(A B) <= sigma(A) sigma(B),
    8^R <= sigma(U_phi^(tensor R) U_c*)
             * sigma(U_c U_psi*^(tensor R)).

Therefore at least one of the two hub/seed relative unitaries has maximum row
support at least `sqrt(8^R)=2^(3R/2)`. Both seed branches have positive
branch weight, so the corresponding nonzero hub/leaf block occurs in
`C_star`; no choice of hub unitary avoids this bound. The full physical row support is at least `2^(3R/2)`, independent of the hub
unitary. For explicit hub choice `U_c=I`, it is at most
`1+(M+r)2^(5R)`: each leaf relative unitary acts on at most 5R data qubits.
If the hub is another generated branch, the generic union bound is
`1+(M+r)2^(10R)`. For an arbitrary hub unitary there is no such local-support
upper bound; the universal trivial bound is `2^N` data columns per edge, and
its entry/circuit cost depends on how that hub is supplied. As `R` is a
positive power of n in the BMVZ hard family, the universal lower bound is
superpolynomial. With `U_c=I`, each requested entry is computable from the
branch's Clifford tableau and `sqrt(pi_i)` in polynomial time, but listing a
row can take exponential time. The weights have polynomial-bit radical
descriptions. This is a sharp no-go for the weighted-star/gauge enforcer on the
term-sampling image, not for all enforcers of that image.

For the bare two-seed subfamily, the earlier, stronger statement in
`work/programmes/games_hamiltonians/leaves/15_positive_encoding.txt` proves
that every exact enforcer for the **two-branch** seed isometry has a row of
support at least `1+2^(3R/2)`. The star argument here is different: it allows
an arbitrary hub unitary and proves a large edge block in this particular
constant-gap graph enforcer. It does not silently promote the bare two-branch
lower bound to all branches or all positive C.

## A scoped obstruction: all-polynomial spectral channels

Here is a sharply specified subclass of redesigned coherent images. Let

    V|z> = sum_(a=1)^A |a> q_a(H_fine)|z>,

where each `q_a` is a (possibly complex-coefficient) scalar polynomial of
degree at most D and the vector polynomial is bounded and normalized on the
whole interval:

    sum_a |q_a(x)|^2 = 1       for every x in [0,1].

This is a bounded polynomial-channel subclass of block-encoding/QSVT
transformations of a normalized signal. It requires every output channel,
not just the selected block, to be a scalar polynomial in H. Let the common
positive diagonal be ancilla-only,

    B = sum_a b_a |a><a| tensor I_data,       0 <= b_a <= 1.

Then

    V*BV = F(H_fine),
    F(x) = sum_a b_a |q_a(x)|^2.

Suppose fixed constants `alpha,beta>0` give
`alpha H_fine <= F(H_fine) <= beta H_fine` on the full logical space.
Set `qtilde_a=sqrt(b_a) q_a`. The vector polynomial `qtilde` has degree at
most D and norm at most one throughout `[0,1]`, and
`||qtilde(x)||^2=F(x)`.

For all sufficiently large yes instances,
`lambda_0 <= alpha lambda_1/(4 beta)` because
`epsilon_n/Delta ->0`. Compression at eigenvectors for `lambda_0,lambda_1`
therefore gives

    ||qtilde(lambda_1)-qtilde(lambda_0)||
      >= sqrt(alpha lambda_1)-sqrt(beta lambda_0)
      >= (1/2) sqrt(alpha lambda_1)
      >= (1/2) sqrt(alpha Delta).

A degree-D vector polynomial bounded by one on `[0,1]` obeys
`||qtilde(x)-qtilde(y)|| <= 2 D^2 |x-y|`: take the real scalar component in
the direction of the vector difference and apply Markov's inequality after
rescaling `[0,1]` to `[-1,1]`. Setting `x=lambda_0`, `y=lambda_1`, whose
separation is exactly `Delta`, yields the necessary degree bound

    D >= alpha^(1/4) / (2 Delta^(1/4)) = Omega(2^(n/4)).

Thus no polynomial-degree isometry in this spectral-polynomial subclass can
simultaneously give a constant-factor positive ancilla-diagonal compression
of this augmented hard family. The plain LCU success-flag dilation with
success block `H_fine` compresses to `H_fine^2` and has ratio `lambda_0`
rather than a size-independent lower factor at the ground eigenvalue. The
complement-LCU construction above is an explicit escape from this subclass.
Its output blocks are term-dependent sums of the distinct reflections `R_j`,
not scalar polynomials `q_a(H_fine)` (the reflections need not commute). Its
failure-flag compression is `2H-H^2`, whose amplitude scale near zero is
proportional to `sqrt(H)`; the Markov argument does not apply to this V.

Cost accounting for this bounded obstruction: `H_fine` has polynomially many
efficiently describable terms, each an actual BMVZ product clause or a
five-local dummy projector. A normalized LCU/block encoding is therefore
available with polynomial work and O(n) coefficient precision for the dummy
weights. A QSVT circuit of degree D uses D block-encoding queries, polynomial
ancillas, and polynomial gate/entry costs if D is polynomial. The theorem
forces D exponential within the all-polynomial-channel subclass. The LCU
failure-channel square root and the term-dependent Naimark frames are outside
it. This is not a lower bound on arbitrary circuit isometries.

## Exact scope, falsifiers, and next lemma

This work establishes the following bounded facts for the complete augmented
hard family:

1. **Positive result:** an explicit polynomial-circuit term-label isometry
   and one computational-basis diagonal positive contraction B compress the
   entire H exactly; B has row support 1, `||B||=1`, and polynomial-time entry
   access.
2. **Positive result:** the complement LCU gives a polynomial-circuit
   isometry, one ancilla-only diagonal projection B, and exact compression
   `H <= V*BV <= 2H` for the complete target. Its canonical projection C has
   exact image kernel and gap 1. An individual C entry is computable in
   polynomial time to b-bit precision. For the explicit seed-adapted A
   completion, `5^R <= max_row_support(C) <=
   min{(L+1)2^N,O(L^3 2^(10R))}` and the selected diagonal label block has
   exact maximum row support `5^R`; for arbitrary A, the global exact maximum
   remains open.
3. **Failure of a natural C route:** an explicit common-label weighted-star
   enforcer has the correct kernel and gap 1/4, but an actual repeated BJSW
   seed pair forces a `2^(3R/2)`-support row for every hub choice.
4. **Scoped no-go:** any bounded scalar-polynomial channel isometry with
   ancilla-only diagonal B and fixed two-sided constants needs degree
   `Omega(2^(n/4))` on the fine-spectrum augmentation.

The exact falsifiers are concrete. For the polynomial subclass, exhibit a
family with degree `D=poly(n)`, `sum_a|q_a(x)|^2=1` on `[0,1]`, `0<=b_a<=1`,
and verify `alpha H_fine<=sum_a b_a|q_a(H_fine)|^2<=beta H_fine` with fixed
positive constants; the two explicit eigenvalues above immediately test it.
For the star route, an alleged hub avoiding the dense edge must make both
relative row supports less than `2^(3R/2)`, contradicting
`sigma(AB)<=sigma(A)sigma(B)` and the exact `8^R` seed product. For the LCU route, the Cycle-3 exact test and symbolic row proof establish
`5^R` support for one valid PREPARE completion. The next finite test is to
repeat the exact block analysis for a standard Householder completion; a
polynomial row-list there would demonstrate that completion dependence matters,
while another exponential row would strengthen the obstruction but still not
cover every A. The precise next lemma for arbitrary enforcers is whether
the LCU frame rows

    { K_a*|x> : a in the L+1 output labels, x in the N-bit data basis }

admit a polynomial-sparse positive matrix C whose rows are exact linear
dependencies of that frame, with kernel exactly `ran(V)` and a constant gap on
its orthogonal complement. A positive certificate must give C's row list and
full-space gap; a no-go must cover arbitrary positive couplings among those
relations, not only `I-VV*` or a weighted star. For the general term-label
route, the next precise lemma is: characterize whether
the frame rows

    { sqrt(pi_j) <y|U_j : j in J plus dummy and silent labels, y in basis }

admit a polynomial-row positive matrix C whose row dependencies span exactly
the orthogonal complement of the frame and whose smallest nonzero eigenvalue
is bounded below by a constant. A constructive certificate must give the
rows and a full-space gap proof; a no-go must cover dependencies beyond
weighted graph-Laplacian edges. A practical falsifiable first test is exact
row-relation enumeration on small R for the forced seed branches, followed by
symbolic tensor-rank bounds; a small-R pass is diagnostic only and is not a
proof at BMVZ's polynomial R.

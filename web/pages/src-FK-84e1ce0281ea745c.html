This is an addendum to the frozen packet in this directory. It does not edit or replace `REPORT.md`, `RESULTS.json`, `MANIFEST.json`, or the original witness script. The correction addresses two proof/exposition issues identified by an adversarial read: mismatched floating-point instances, and a generic nullspace argument that had not first removed redundant constraint rows. It also makes the finite-dimensional realization costs explicit.

## Precision correction and status

In the frozen script, `TAUS` and `OMEGAS` were created as `mp.mpf` values at module import under mpmath's default 15 decimal digits, before `main()` raised the working precision. The later 100-digit solve therefore used 53-bit-rounded inputs. Separately, the interval audit rebuilt exact rational times and decimal frequencies. Those two calculations certified nearby, but not literally the same finite-precision instance.

`corrected_equal_information_witness.py` now keeps only input strings and integers at module scope. It creates the intended beta, eta, rational tau values, and decimal omega values after setting `mp.mp.dps=110`. It independently reconstructs the exact decimal/rational instance in `mp.iv` at 80 digits and certifies the determinant, Cramer vector, positive weights, target values, common Euclidean means, first moment, and static response. Every corrected high-precision value lies inside the corresponding interval enclosure (`containment_all_pass=true`). The determinant interval is strictly negative and excludes zero; all 18 weight intervals are strictly positive; the response-gap interval is strictly negative.

The exact mathematical witness is defined by the exact inputs and Cramer's rule, not by rounded solver output: form the 8-by-9 matrix (A) from the six exact-time Euclidean rows and the rows (2\omega), (2/\omega); define (v_9=1), (v_{1:8}=-A_{1:8}^{-1}A_9), (b_i=1/(18\omega_i)), and (w_i^{\pm}=b_i\pm10^{-6}v_i). Interval exclusion certifies that this definition is valid and both measures are strictly positive. It then follows exactly that (Aw^+=Aw^-), including the six Euclidean observations, first moment, and static response. The interval target values certify a nonzero χ difference without relying on rounded arithmetic.

## Redundant constraint rows and the scope of the nullspace argument

The generic argument is now stated after row reduction. Given finitely many constraint functions φ\(_1\),…,φ\(_m\), first select a basis ψ\(_1\),…,ψ\(_r\) of their span as functions on the allowed frequency domain. If the target (g) is outside this span, then the (r+1) functions ψ\(_1\),…,ψ\(_r\), (g) are linearly independent. Their evaluation vectors therefore span ℝ\(^{r+1}\), so there are (r+1) frequencies whose augmented evaluation matrix has full rank. The (r\times(r+1)) constraint matrix has a nonzero null vector (v); full rank of the augmented matrix forces (g\cdot v\ne0). Around any strictly positive base weights on those support points, sufficiently small (\pm\delta v) perturbations preserve positivity, match every retained constraint, and separate the target. This explicitly handles redundant original rows.

For the present finite example, no abstract independence premise is needed: the interval-certified 8-by-8 determinant of the first eight columns is nonzero, and the ninth-column Cramer construction supplies the exact null direction.

The broader non-span statement is restricted to a finite list of Euclidean-time kernels, finitely many power/negative-power moment rows, and the static (2/\omega) row. At large ω, interior-time thermal kernels decay exponentially; the τ=0 row tends to a constant with exponential corrections; any finite collection of power and inverse-power rows spans only a finite Laurent polynomial. By contrast (g_\eta(\omega)=2\omega/(\omega^2+\eta^2)=2/\omega-2\eta^2/\omega^3+2\eta^4/\omega^5-\cdots) has an infinite nonzero Laurent tail for η>0. Thus it is not in that finite span. This does not cover an arbitrary calibrated intervention whose response function might include (g_\eta) itself or otherwise encode the target; such interventions must be analyzed from their actual measured row functions.

## Finite-dimensional realization and access costs

Each positive finite measure is realized by a 10-dimensional diagonal Hamiltonian (H=\mathrm{diag}(0,\omega_1,\ldots,\omega_9)) and a Hermitian star observable with (A_{0i}=A_{i0}=\sqrt{w_i Z/(1-e^{-\beta\omega_i})}) and all other entries zero. The Gibbs partition function is 2.9392215381684369392; ‖H‖=40. The observable operator norms are ‖A\(_+\)‖=6.4434207899234197175 and ‖A\(_-\)‖=6.4539131035328054714. These norms are above one. This witness therefore does not establish the same gap under a separate promise ‖A‖≤1.

The finite Gibbs probability vector and Shannon entropy (1.807413869805266759 bits) are included in the JSON as instance descriptors, not as a universal preparation lower bound. Under a classical diagonal-mixture model, a finite-precision categorical sampler can be specified with (O(d)) probability setup and (O(\log d+\log(1/\epsilon))) random bits per sample, followed by basis-label preparation. Here the smallest Gibbs probability is about 1.45×10⁻¹⁸, so a dyadic sampler that resolves even that level needs about 60 random bits before any extra total-variation margin. A coherent purification can be prepared with (O(d)) controlled rotations and angle precision (O(\log(1/\epsilon))) in an ideal gate model. These are representation-level costs for this explicit 10-level instance; actual gate synthesis, thermalization, readout, and physical runtime have not been acquired or measured. A Euclidean-data estimator is not granted the Gibbs probabilities, this state-preparation circuit, or an eigensystem oracle.

# Exact finite-dose activation boundary for step mechanical proofreading

## Claim and status

**Status: conditional theorem about the published coarse-grained model, internally reconstructed.** It is not evidence that B cells implement the controller. The result applies to the ideal step-force limit `beta = infinity`, to one cluster, before force turns on, with the paper's shared constant `kon`, force-independent prethreshold off-rates, and an absorbing `m=0` boundary. It omits the simulation's `t_min=1 s` restart and `t_max=1800 s` cutoff; those affect full-trajectory quantities and are kept explicit in the simulator audit.

Let `L` be the number of available ligands, `m` the number of three-body BCR–Ag–tether complexes, `n` the number of BCR-bound extracted antigens, and `m_c` the activation threshold. Starting immediately after the first association (`m=1,n=0`), before force onset the total upward rate of `m` is

`lambda_m = ((L-m-n)+n) kon = (L-m) kon`,

because both fresh binding and rebinding increment `m`. Its total downward rate is

`mu_m = m (ka0 + kb0)`,

where `ka0 = k0 exp(-Ea/kBT)` and `kb0 = k0 exp(-Eb/kBT)`. The marginal process `m(t)` is therefore a birth–death chain independent of `n` until the first time `m=0` or `m=m_c`.

For integer `L >= m_c`, the probability of hitting the force threshold before zero, starting at `m=1`, is

`h_1(L) = [1 + sum_{j=1}^{m_c-1} product_{r=1}^j { r(ka0+kb0) / ((L-r)kon) }]^(-1)`.

For `L < m_c`, `h_1(L)=0` because the state space constraint `m+n <= L` makes `m_c` unreachable. The formula is monotone nondecreasing in `L` and nonincreasing in the total preforce dissociation rate.

## Proof

Let `h_i` be the probability of hitting `m_c` before 0 from state `i`, `0 <= i <= m_c`. The first-step equation is

`h_i = p_i h_{i+1} + q_i h_{i-1}`,

with `p_i=lambda_i/(lambda_i+mu_i)`, `q_i=mu_i/(lambda_i+mu_i)`, and boundary values `h_0=0`, `h_mc=1`. Set `Delta_i=h_i-h_{i-1}`. Rearranging gives `p_i Delta_{i+1}=q_i Delta_i`, so

`Delta_{j+1}=Delta_1 product_{r=1}^j (mu_r/lambda_r)`.

Since `1=h_mc-h_0=sum_{i=1}^{m_c} Delta_i`, solve for `Delta_1=h_1`. Substitution of `mu_r/lambda_r` yields the expression above. If `L<m_c`, `m<=L`, so the upper boundary cannot be reached. Increasing `L` increases each `lambda_r` and decreases every product in the denominator, proving monotonicity.

## Numerical scope

Using the published code parameters `k0=1126.92 s^-1`, `Ea=12.6 kBT`, `Eb=13.3 kBT`, `kon=0.05 s^-1`, and `m_c=60`, direct evaluation gives:

| L | `h_1(L)` |
|---:|---:|
| 59 | 0 exactly |
| 60 | 0.998068 |
| 70 | 0.998349 |
| 100 | 0.998850 |
| 130 | 0.999118 |

This is a sharp *reachability* boundary in the ideal step model, not a dose-robustness theorem for the final extracted-antigen score. Reaching `m_c` does not alone imply dose-independent output: prethreshold extraction can accumulate, rebinding can occur after force onset, and finite-duration/contact cutoffs can censor trajectories. The full simulator audit measures these separately.

For finite `beta`, the force law in the paper is positive for every `m_max > 0`; the exact no-force/unreachable statement does not apply. A deterministic bound is only

`F <= F0 L^beta / (L^beta + m_c^beta)` when `m_max <= L`.

At `beta=5`, `L/m_c=1/2`, this upper bound is `F0/33`, about `24.2 pN` for `F0=800 pN`; the paper's simulated `beta=5` force is thus a soft ramp, not a hard gate.

## Falsifier and next gate

The ideal formula is falsified if an exact preforce CTMC with the stated rates gives a different hit probability. To transfer the result to the published finite-`beta`, finite-cutoff model, enumerate or simulate the joint `(m,n,t)` process and report threshold-hit probability, prethreshold extracted count, postthreshold rebinding count, `t_min` restart, and `t_max` censoring by dose. The next biological gate is direct measurement of force onset versus running maximum cluster size under independently controlled antigen density and mobility.

## Exact interface and primary lead

Let F={0,f_1,...,f_m} with f_j(i)=1_{i=j} on X={1,...,m}. A predictable query policy chooses z_t using only epsilon_1,...,epsilon_{t-1}; the epsilon_t are independent fair signs. Its unnormalized endpoint complexity is

    U(F,z)=E max_{f in F} sum_t epsilon_t f(z_t).

The usual fixed-n sequential Rademacher complexity is U/n. These signs are mathematical randomization/noise for a complexity functional. A generic actual scientific feedback stream is not thereby modeled as fair independent signs. The finite feature matrix and query cost law are supplied inputs; neither is acquired for free.

## Independently reconstructed fixed-policy obstruction

Use m=n. Begin at query1 with score0. Keep querying the current coordinate until its cumulative score reaches1, then permanently move to the next fresh coordinate. At every endpoint, all completed coordinate scores are1 and the only possibly nonzero unfinished score is nonpositive (a coordinate just completed on the final step can be treated as followed by a virtual zero coordinate). Write S_t=sum_{s<=t}epsilon_s and M_t=max(0,S_1,...,S_t). Exactly M_t coordinates have completed, and the unfinished score is S_t-M_t. Consequently,

    max_F endpoint = 1_{M_n>=1},
    max_{-F} endpoint = M_n-S_n.

Taking expectation gives U(F,z)=P(M_n>=1)<=1 and U(-F,z)=E M_n. Negation ell(u)=-u is globally1-Lipschitz and centered; no offset, high derivative or variable range explains this increase. The process needs two O(log n)-bit counters and one supplied query per sign; it does not need to materialize the 2^n-node query tree.

For a simple fair random walk, E S_n^2=n and E S_n^4=3n^2-2n. Holder yields E|S_n|>=n^(3/2)/(E S_n^4)^(1/2)>=sqrt(n/3). Since M_n>=(S_n)_+, E M_n>=sqrt(n)/(2sqrt3). Reflection gives E M_n<=E|S_n|<=sqrt(n). Thus

    U(-F,z)/U(F,z)>=sqrt(n)/(2sqrt3),

with the numerator and denominator divided by the same n if normalized. An exact finite recursion for the reflected state a_t=M_t-S_t avoids asymptotics: a -> max(a-1,0) after +, a -> a+1 after -. A completed-coordinate boolean suffices to retain the positive/symmetric terminal maxima as well.

## Symmetric closure has a charged price on the acquired policy

For Fpm=F union(-F), pointwise max_Fpm=max(max_F,max_-F). Therefore

    max(U(F,z),U(-F,z)) <= U(Fpm,z) <= U(F,z)+U(-F,z).

Here U(Fpm,z)=E M_n+P(M_n-S_n=0,M_n>=1), so it lies between E M_n and E M_n+1. Closing the one-hot class under signs raises this particular policy's complexity from O(1) to Theta(sqrt n). In contrast, on an exogenous fixed query sequence sign symmetry gives U(-F,x)=U(F,x), hence U(Fpm,x)<=2U(F,x). A doubled description or covering-number bound cannot be substituted for the fixed-policy complexity cost.

## Equally informed worst-case control

For every predictable z define zrev_t(epsilon_<t)=z_t(-epsilon_<t). Substituting delta=-epsilon in the path sum proves

    U(-F,z)=U(F,zrev).

The map z->zrev is an involution. Hence sup_z U(-F,z)=sup_z U(F,z) exactly, for the same finite class, query set and horizon. This does not imply equality for the same acquired z. The executable discriminator must retain actual query trees and compare both endpoints on the SAME tree; a separate Bellman optimum over all trees is a control, never silently an acquired-policy certificate.

## Independently derived compute-budget extension: predictable bounded costs

Use the same exhaustive policy, with a cost c_t determined before observing epsilon_t. Assume integer 1<=cmin<=c_t<=cmax, and sample until the next chosen query cannot fit the remaining integer budget B. Let tau be the number of accepted queries. Then

    floor(B/cmax)<=tau<=floor(B/cmin).

The stop decision after t signs is measurable with respect to those signs. Bounded stopping gives E S_tau=0 directly: E[S_tau]=sum_t E[epsilon_t 1_{tau>=t}]=0, because the indicator is predictable. Thus

    U_B(F,z)=P(M_tau>=1)<=1,
    U_B(-F,z)=E(M_tau-S_tau)=E M_tau
               >= E M_floor(B/cmax)
               >= sqrt(floor(B/cmax))/(2sqrt3).

An upper bound E M_tau<=sqrt(floor(B/cmin)) follows from monotonicity in stopping time and the fixed-horizon reflection bound. Normalize both functionals by B if a compute-indexed quantity is desired. This functional is not automatically a regression risk bound. It shows that a lawful bounded variable query cost cannot remove the obstruction. The actual predictable cost law is required for exact values; its mean alone is not the interface. Finite hypotheses can be m=floor(B/cmin), with a virtual next coordinate consulted only after the final possible observation.

If costs instead depend on the fresh sign, or the algorithm may quit voluntarily at an earlier favorable state, the predictability/exhaustion premises fail. Those are retained rejected interfaces, not cases silently covered by this theorem.

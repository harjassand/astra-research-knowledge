RESULT

The independent initial functional-digraph algorithm survives its algebraic
checks, but peer comparison changes its status: c03_s03's exact arbitrary-t
MPS class already contains every one-row-functional support. Such support is
a pseudoforest with pathwidth O(log n); ordering by first bag appearance gives
cut rank sum O(log n). The initial O(n^2) recurrence is consequently a
cost-specialized rediscovery, not a new tractability boundary.

The strongest new post-exposure result is an exact treewidth-FPT extension of
the hard-only Grassmann norm counters reported by c03_l08 and c03_s01. For an
explicit F over Q(i), rational t_i>=0, arbitrary site restrictions among
{0,u,d,ud}, and a supplied elimination order of support width w, the
determinant-pair polynomial

  C_k = sum_{|I|=|J|=k} |det F[I,J]|^2 product_{i in I intersect J} t_i

with disallowed local configurations omitted is computed exactly for all k.
The key new local value in site generator order x,y,u,v is
ell_i(x_i y_i u_i v_i)=z t_i, alongside ell_i(x_i u_i)=-z and
ell_i(y_i v_i)=1. The species-to-site shuffle contributes (-1)^(k-h),
h=|I intersect J|; the local row-only and overlap signs contribute the same
factor, so they cancel. This yields exactly z^k t^h |det F[I,J]|^2, including
diagonal matrix entries when t>0. The full proof, costs, sign accounting,
attribution, and boundaries are in
work/cycle6/c03_l09/revisions/treewidth_filtered_parity_derivation.txt.

With a supplied width-w elimination order, a conservative implementation
bound is O(n^3(w+1)2^(8(w+1))) rational operations and
O(n^2(w+1)2^(4(w+1))) rational storage. Input and intermediate rational bit
heights are polynomial in explicit input length. The order is charged: the
implementation's min-degree order is only a heuristic. The exact counter
also gives prefix completion masses; exact self-reduction samples one
canonical sector in expected polynomial time, with no rare-sector rejection.
This samples occupation labels, not a coherent quantum state.

## Interface

Input is an explicitly represented SIMPLE graph G=(V,E) and valid integers0<=f(v)<=deg_G(v). An f-factor is an EDGE SUBSET with these exact degrees. Binary edge multiplicities, general demands and weighted optimization are different problems. Output is either an explicit factor or NO. The transformation/decode is deterministic; solving its perfect-matching instance is the separate oracle/algorithm cost.

## Routing proof

For s a power of two, build a recursive directed acyclic network. At s1 there is one position serving as both input and output. At larger s, use s new inputs and s new outputs, two disjoint s/2 networks, arcs from each input pair to corresponding input in both copies, and arcs from each corresponding inner output to both positions of its output pair. Size recurrence is Q(s)=2Q(s/2)+O(s).

For a requested permutation, make a bipartite multigraph of input pairs versus output pairs, with an edge for each input-to-output assignment. Every vertex has degree2, so each component is an even cycle, including a two-parallel-edge cycle. Alternating two colors assigns exactly one edge of each color at each pair. Each color induces a permutation inside its chosen half network. Recursing then attaching outer arcs gives vertex-disjoint routes for ALL inputs. The routing algorithm can be constructive in the network-size bound.

## Transformation and both directions

Each host edge e={u,v} has two distinct port vertices x_(u,e),x_(v,e), joined by a cross edge carrying label e. At vertex v with degree d>0, take a separate network on the next power of two s>=d, assign its first d inputs to incidences, and choose b=d-f(v) outputs. Split each network position a into a_in,a_out, with an idle edge. Directed arc a->a' becomes transition edge a_out-a'_in. Attach a port to its network input endpoint. Each chosen output has a new mandatory degree-one sink attached to its output endpoint.

In ANY perfect matching of the new graph, each split pair is either idle or has both endpoints covered externally. Count non-idle input endpoints and output endpoints within this local network: the totals are equal. Each transition contributes once to each side and cancels. Every one of the b sinks is covered, so exactly b port attachments are used. The other d-b=f(v) ports use their cross edges. Thus the labels of selected cross edges give an f-factor. This converse does not assume that the matching literally follows our chosen permutation paths.

Conversely, given an f-factor, its b excluded incidences at v can be bijected to the selected outputs; extend this partial assignment to a permutation of all s positions. Keep the b disjoint routes. Use the factor's cross edges, the chosen ports/route transitions/sinks, and idle edges at every unused position. All endpoints are covered exactly once. Zero-degree vertices add nothing; b0 uses only idles, and s1's length-zero route is valid.

The graph is simple because the edge types have disjoint endpoint patterns and the routing network has distinct arcs. Since s<=2d, total positions/arcs/ports are O(sum_v d_v log(d_v+2))=O(m log(n+2)). Construction plus reading isolates takes O(n+m log(n+2)); labels decode a perfect matching within the same order. This proof is independent of any claimed new matching solver.

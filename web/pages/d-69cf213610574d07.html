EXACT HARD-BCS OBSTRUCTION FOR THE SYMMETRIC ALL-POSITIVE WITNESS
Worker c02_l09; 7 October 2026

The normalized generic stable equality polynomial

    h(x)=1+(1/3) sum_{1<=i<j<=4} x_i x_j + x_1x_2x_3x_4

cannot be a 4-site hard-BCS hole-coefficient polynomial. Its exchange is an
interior equality: for S=[4], T=empty, a=1, the three terms are each 1/3,
and both sides are 1.

For any complex 4-by-4 matrix F, write

    g_{ij}=|F_{ij}|^2+|F_{ji}|^2  (i<j).

The hard-BCS coefficient interface gives f(U)=g_{[4]\U} for a two-hole
set U, and f(empty)=sum_{|I|=2}|det F[I,[4]\I]|^2. For any 2-by-2
complementary minor, |ad-bc|^2<=2(|ad|^2+|bc|^2). Summing these six
inequalities groups the directed entry products by the three perfect
matchings of [4]. For each matching {e,e'}, all four orientations occur
once, with total g_e g_{e'}. Consequently

    f(empty) <= 2 sum_{perfect matchings {e,e'}} g_e g_{e'}
              = 2 sum_{perfect matchings {U,V}} f(U)f(V).

The last sum is complement-invariant. If all six pair-hole coefficients
equal 1/3, this gives f(empty)<=2*3*(1/9)=2/3, whereas the candidate
requires f(empty)=1. Contradiction. Diagonal entries of F do not affect
either side because complementary row and column sets are disjoint.

This is an exact algebraic obstruction for this symmetric coefficient
vector, not a classification of all-positive equality in hard-BCS. It does
not affect the general stable-polynomial equality example or the separate
one-sided-zero hard-BCS equality witness.

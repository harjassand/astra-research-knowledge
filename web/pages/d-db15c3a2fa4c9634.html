CYCLE08 PETZ-PI PRIOR CHECK
Date: 2026-10-09
Scope: exact operator-convexity threshold for f_kappa(t)=(t-1)log(t)-kappa(sqrt(t)-1)^2, and whether its Petz quasi-entropy yields a source-backed bridge to physical KMS entropy production versus the square-root KMS Dirichlet energy.

Finding
The exact static threshold is kappa <= pi (for real kappa; if the parameter is restricted to be nonnegative, 0 <= kappa <= pi). This follows by specializing the unique operator-convex integral representation in Franz--Hiai, Theorem 2.2, to alpha=1. It gives the faithful-state inequality

  Tr[(rho-sigma)(log rho-log sigma)] >= pi Tr[(sqrt(rho)-sqrt(sigma))^2].

This is a Jeffreys-versus-square-root-Hellinger inequality for a pair of states. It is not the dynamical KMS statement J(rho) >= pi E_KMS(rho). The reviewed primary results supply no conversion from this static quasi-entropy to that generator-weighted inequality.

Exact representation and threshold
Franz--Hiai Theorem 2.2 states that f is operator convex on (0,infinity) iff it has, for alpha>0, the representation

  f(t)=f(alpha)+f'(alpha)(t-alpha)+gamma(t-alpha)^2
       + integral (t-alpha)^2/[(t+lambda)(alpha+lambda)^2] dmu(lambda),

where gamma >= 0, mu is positive, integral (1+lambda)^(-3) dmu(lambda) is finite, and gamma and mu are unique (Theorem 2.2, pp. 159-160; the uniqueness discussion is lines 119-136 in the journal PDF).

At alpha=1, f_kappa(1)=f'_kappa(1)=0 and the direct scalar identities

  integral_0^infinity d lambda/[(1+lambda)(t+lambda)] = log(t)/(t-1),
  integral_0^infinity sqrt(lambda) d lambda/[(1+lambda)^2(t+lambda)]
      = pi/[2(1+sqrt(t))^2]

give

  f_kappa(t)=(t-1)^2 integral_0^infinity
       [1+lambda-(2 kappa/pi)sqrt(lambda)]/[(1+lambda)^2(t+lambda)] d lambda.

Thus the candidate representing measure is

  dmu_kappa(lambda)=[1+lambda-(2 kappa/pi)sqrt(lambda)] d lambda,
  gamma=0.

It meets the weighted integrability condition: its density is O(lambda) at infinity and bounded near zero. Its density is nonnegative for every lambda>0 exactly when kappa<=pi, since with x=sqrt(lambda), the numerator is x^2+1-(2kappa/pi)x. For kappa>pi it is already negative at lambda=1. To make the converse precise, divide the representation by (t-1)^2: the resulting Stieltjes transform has measure dnu=dmu/(1+lambda)^2 and no constant term (the integral tends to zero as t tends to infinity). Stieltjes-transform uniqueness in the weighted class from Theorem 2.2 forces any positive representing measure to agree with this density; a negative density near lambda=1 is impossible. For kappa<=pi, the displayed positive measure itself verifies operator convexity by Theorem 2.2. At the endpoint,

  1+lambda-2sqrt(lambda)=(sqrt(lambda)-1)^2.

The source proves the general representation and uniqueness, not this chosen one-parameter family as a separately named theorem; the threshold is an exact specialization plus the displayed integral calculation. The scalar nonnegativity threshold is different: inf_{t != 1} (t-1)log(t)/(sqrt(t)-1)^2=4, so pointwise f_kappa>=0 allows kappa<=4. That scalar fact does not establish operator convexity; pi is the operator-convex threshold.

Petz functional-calculus consequence
For faithful density matrices rho,sigma, put Delta=L_rho R_{sigma^{-1}} on Hilbert--Schmidt space and use the Petz K=I expression

  S_f(rho||sigma)=Tr[sqrt(sigma) f(Delta)(sqrt(sigma))].

Because Delta is positive definite and f_pi(t)>=0 for t>0, S_{f_pi}(rho||sigma)>=0. Linearity in f and functional calculus give

  S_{(t-1)log(t)}(rho||sigma)
      =D(rho||sigma)+D(sigma||rho)
      =Tr[(rho-sigma)(log(rho)-log(sigma))],
  S_{(sqrt(t)-1)^2}(rho||sigma)
      =Tr[(sqrt(rho)-sqrt(sigma))^2].

Consequently the static inequality above holds in every finite dimension for faithful states. The Hiai--Mosonyi--Petz--Beny source gives the quasi-entropy definition and the general data-processing framework, but its stated function domain is continuous functions on [0,infinity); f_kappa diverges at zero. The faithful-pair functional calculus is well-defined because Delta has spectrum in (0,infinity), but do not silently apply their [0,infinity)-continuous Theorem 4.3 to this f without proving a suitable extension. Data processing, even if separately extended, is a contraction statement for state pairs and does not itself compare a physical generator to a root Dirichlet form.

Decisive missing conversion to the target
For a differentiable trace-one path rho_t with dot(rho)=L_*(rho), fixed faithful sigma, and

  F_kappa(rho,sigma)=D(rho||sigma)+D(sigma||rho)
                         -kappa Tr[(sqrt(rho)-sqrt(sigma))^2],

direct differentiation gives

  dot(F_kappa) = -J(rho)
        -Tr[sigma Dlog_rho[L_*(rho)]]
        +2 kappa Tr[Dsqrt_rho[L_*(rho)] sqrt(sigma)],

where J(rho)=-Tr[L_*(rho)(log(rho)-log(sigma))] is physical entropy production. The two extra terms are not the square-root KMS Dirichlet form. In the target convention, that form is built by conjugating L_* with the square-root KMS embedding Gamma_sigma^(1/2)(X)=sigma^(1/4)X sigma^(1/4), then evaluating the resulting self-adjoint Dirichlet form at sqrt(rho). The derivative above instead uses Dlog_rho[L_*(rho)] and Dsqrt_rho[L_*(rho)].

At the stationary point, the static Hessian compares a BKM metric with the square-root Hellinger tangent metric. The target stationary Hessian places the KMS generator between tangent variables; positivity of the static metric difference alone does not imply positivity after this insertion. The exact tangent conversion is load-bearing: for s=sqrt(sigma), physical tangent Z=dot(rho)=sY+Ys, so Y=Lyap_s^{-1}(Z); if a source uses Z=sXs, then Y_ij=s_i s_j/(s_i+s_j) X_ij, not X. No checked primary theorem in this bounded source route bridges these forms for arbitrary KMS generators.

# A matrix-Krylov detector for hidden quartic coordinate planes

7 October 2026, cycle 10. **Internally proved conditional detector and coefficient-only implementation; independent worker gate PASS.** Gate: `notes/metric_acquisition/cycle10/ROOT_KRYLOV_DETECTOR_GATE.md`. Universal nonvanishing is OPEN. No historical novelty or general performance claim is made.

Given the expanded rational quartic f, reconstruct its symmetric polarization tensor T, normalized by f(x)=T[x,x,x,x]. Set

    H=Hess f, J=adj H,
    B_ij=Σ_kl T_ijkl J_kl,
    C=JB,
    K_f(x)=det[x,Cx,…,C^(n−1)x].

This uses only observed coefficients. It needs neither an input metric nor a hidden frame. Under g=f∘L,

    C_g(x)=det(L)^4 L⁻¹ C_f(Lx)L,
    K_g(x)=det(L)^[2n(n−1)−1] K_f(Lx).

The identities follow from the Hessian congruence and four-tensor transformation. In hidden even coordinates, C(sx)=sC(x)s for every coordinate sign flip s. On a sign-fixed coordinate plane C preserves that plane, so every Krylov column lies in it and its defining coordinate divides K. Covariance transfers the factors to the unknown rational input coordinates.

For diagonal Q>0, J is diagonal and C_ii=(det H)²/(144Q_ii x_i⁴). The determinant is the product of the x_i times a Vandermonde in these diagonal entries, which is not identically zero. Thus nonvanishing holds on a nonempty Zariski-open class of Q. This is not a proof for every coupled positive-definite Q. Neither implication between this K and the flow extactic E has been established.

The relation to the prior detector is exact:

    adj(H)∇det(H)=24Cx.

The flow detector differentiates this vector field repeatedly along itself; K instead freezes C(x) at the evaluation point and takes matrix powers. That removes the need for higher flow-time jets while retaining the same homogeneous degree

    deg K=n+2n(n−1)².

The coefficient-only line algorithm evaluates K and its ambient first derivatives in a dual univariate rational-polynomial ring. Newton trace identities and Cayley–Hamilton compute J with polynomially many matrix operations; multiplying C powers and a determinant is also polynomial. The degrees and rational heights are polynomial in the dimension and expanded input encoding. Conditional on K≠0, the established good-line/factor/multiplicity argument then recovers a reflection pool in expected polynomial bit time; the existing rational metric, axis and weighted-square verifiers complete acquisition. A failed/bad line returns UNKNOWN. Using this as a preliminary detector before the original flow route preserves the latter's already proved coverage. The universal polar-saturation fallback now supplies theoretical all-input completeness independently of both detectors.

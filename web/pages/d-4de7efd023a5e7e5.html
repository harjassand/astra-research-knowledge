PROTECTED ENTANGLING OPERATIONS AND ENCODED TRANSFER UNDER ONE COHERENT BATH
9 October 2026. Frozen v3. Extends the corrected memory theorem in v1+v2.

STATUS: internally derived operational extension, not external validation or a
new universal quantum computer. The physical CNOT and encoded-transfer circuits
below are actually executed with all their faults counted. No ideal final
decoder is executed inside these primitives. Ideal final decoding continues to
define their logical error metric, as is standard for encoded output. A bare
quantum output immune to its last allowed fault is impossible in this model.

1. EXACT NATIVE ENTANGLING GATE

Write a CSS code using binary subspaces A (X stabilizers) and B (Z stabilizers),
with A subset B^perp, and select a linear section of the quotient B^perp/A.
For u in that section, its logical computational basis is

 |[u]> = |A|^(-1/2) sum_{a in A} |u+a>.

Apply CNOT to every corresponding physical pair of two identical code blocks.
For u,v,

 CNOT^tensor n |[u]>|[v]>
 = |A|^(-1) sum_{a,b in A}|u+a>|u+v+a+b>
 = |[u]>|[u+v]>.

Thus the circuit implements all k corresponding logical CNOTs simultaneously.
Its entangling gates have depth1 and n two-qubit locations. This is a known CSS
transversal property, reconstructed here to specify exact logical addressing.
It does not implement a CNOT between arbitrary independently chosen indices
inside the blocks. A prescribed sequence of block-matching CNOTs is supported.

If a Pauli before the CNOT is X(a)Z(b) on source and X(c)Z(d) on target, propagation
gives X(a)Z(b+d) on source and X(a+c)Z(d) on target, up to phase. For reduced
weights r_A,r_B, choose minimal representatives first; each propagated block
has reduced weight at most r_A+r_B. Clifford covariance removes no information
from a shared bath and does not require stochastic paths.

2. COMPLETELY LOCAL ENCODED TRANSFER WITH NOISY READOUT/FEEDFORWARD

Input source block A contains arbitrary unknown encoded |psi> (possibly entangled
with other logical blocks or a reference). Input target block B is a SUPPLIED
or preexisting protected |[0]> state of the same CSS code. Run:

 (i) corresponding-qubit transversal CNOT A->B;
 (ii) X-measure every source physical qubit, obtaining the n-bit string x;
 (iii) apply physical Z(x)=product_i Z_i^(x_i) to target, using one local
       measurement-record/control connection per corresponding qubit;
 (iv) run one counted noisy single-shot QTC recovery on the target.

The true logical byproduct is represented by the full physical string x. No
dense logical-parity computation or single noisy global control bit is used.
All measurements, record bits, transfers, controlled Zs and subsequent decoder
operations are counted locations and can share the same bath.

Proof in the absence of faults. Transversal CNOT sends
sum_u c_u|[u]>|[0]> to sum_u c_u|[u]>|[u]>. For an X-basis outcome x,

 <x_X|[u]> = 2^(-n/2)|A|^(1/2)(-1)^(x.u) 1[x in A^perp].

For x in A^perp, Z(x)|[u]>=(-1)^(x.u)|[u]>. Therefore the target branch is
2^(-n/2)|A|^(1/2) Z(x)|psi>; step(iii) cancels it. Its branch scalar is
independent of |psi>, so the retained readout bath contains no logical
information. The circuit exactly transfers all k logical qubits to target,
while source is measured/discarded. The state resources consumed include the
target |0_L> block; no constant-depth preparation of that entangled code state
is asserted or charged as free.

Exact Pauli covariance, including imperfect target and readout. Put X(a)Z(b)
on source and X(c)Z(d) on target before CNOT. After Clifford propagation these
are X(a)Z(b+d) on measured source and X(a+c)Z(d) on target. If x0 is an underlying
ideal outcome, the true observed X outcome is x=x0+b+d. Source X(a) contributes
only a sign depending on x. If recorded x is further flipped by D, physical
feedforward applies Z(x+D). The target becomes, up to a branch-dependent phase,

  X(a+c) Z(b+D) |psi>.                                               (1)

The target Z error d cancels. To verify the ordering explicitly, use
<x_X|X(a)Z(b+d)=(-1)^(a.x)<(x+b+d)_X| and set x0=x+b+d; then combine target
Z(d), ideal branch Z(x0), and feedforward Z(x+D). Anticommutation phases are
independent of |psi> and are retained in the bath coefficient. Equation(1) is
linear in the input logical vector and valid for arbitrary binary a,b,c,d,D,
not only correctable errors. In particular a faulty local record bit causes
a LOCAL target Z error, rather than a full logical byproduct fault.

Every arbitrary local physical fault in the transfer primitive has a bounded
causal cone because its quantum/readout/control circuit has constant depth and
bounded arity/fanout. Expand its data part in Paulis and its controller part in
matrix units, retaining bath coefficients chronologically as in v2. Equation(1)
then gives each term a target residual Pauli with weight at most

   r_A+r_B+a_transfer f_transfer.

Faults during destructive X readout and local feedforward are covered by the
same statement; their Pauli/controller expansions alter only a bounded set of
outcome/control/data bits. No bath coefficients are norm-summed. A final noisy
single-shot recovery contracts this residual exactly as in the memory theorem.
Thus this is an actual protected encoded output/transfer interface, given the
explicit encoded target resource, within the all-location shared-bath model.

3. NATIVE CIRCUIT THEOREM, WITH DISJOINT TILES AND UNIFORM CONSTANTS

Consider q identical QTC blocks, initialized in an arbitrary encoded joint
logical state (or specified encoded resource states in the transfer variant).
At each round run a prescribed matching of transversal CNOTs on permitted
interblock edges, or identity on unmatched blocks, then the compiled noisy
single-shot recovery on each surviving block. Transfer may substitute for a
pair tile if its target is the specified protected |0_L> resource and the source
is discarded afterward. Previously stored resource errors are included in the
same residual invariant.

Choose source component decoder contraction alpha0<1/4, so the combined effective
alpha=2alpha0<1/2. Group circuit locations into one disjoint tile per matched
pair and one tile per unmatched block PER ROUND. All recovery locations of the
two participating blocks, transversal gates, measurements, controls, resets and
idles belong to that tile. Crucially a transversal gate is counted ONCE in its
pair tile; per-block location masks would overlap and would not justify the
product bound. Tiles in different rounds have disjoint spacetime locations.
Noise terms joining different tiles mark every touched physical location.

Let each tile contain <=N1 n elementary locations, for a fixed N1 independent
of n,q and the circuit length. A good tile has <=tau n marked faults. Input
residuals <=rho n on both blocks lead to per-output input errors <=2rho n+a tau n
before recovery, and a syndrome corruption <=b tau n. All primitive/recovery
fault support constants are collected in fixed a,b,c, so

 r_out <= 2 alpha rho n + K tau n,
 K=alpha a+beta b+c,
 rho=K tau/(1-2alpha).                                                (2)

Choose tau>0 satisfying

 A(2rho+a tau)+B b tau < h,  2rho<d0,                                 (3)

and, if needed, below the source exact-decoder input radius. Such a positive tau
exists since alpha<1/2 and all constants are fixed. Then every good tile
satisfies the original Pauli decoder premise and restores the invariant rho n.
For a one-block identity tile its spread is smaller, so the same inequalities
suffice. Begin with clean encoded blocks, and induct over prescribed rounds.

Let M be the total number of tiles. For q fixed live blocks and T matching
rounds, M<=qT. For transfer resource stocks, count every supplied block and
every storage/transfer tile; no uncounted just-in-time encoded preparation is
available. Let k_fault=floor(tau n)+1 and

 b_n=binom(N1 n,k_fault) eta^(k_fault)(1+eta)^(N1 n-k_fault),
 delta=(1+b_n)^M-1.                                                  (4)

The same exact global bad-mask expansion as v1 applies to all disjoint tiles.
Its aggregate cylinders include faults in arbitrary other tiles and rounds,
and the bound (4) requires no factorized bath or channels.

Let C be the ideal logical circuit of the prescribed corresponding-pair CNOTs
and wire transfers, identifying source/target logical spaces at a transfer.
Every fully expanded good global history is a final low-reduced-weight Pauli
times the ideal encoded C, with record/garbage/bath coefficients independent
of the input logical vector. This follows from Clifford covariance for CNOT
and Equation(1) for transfer, followed by (2)-(3). The common final ideal decoder
therefore gives G=C tensor g. Apply C^dagger in the proof metric and use the
same polar normalization as v1; if delta<1,

 || LogicalActual - Ad_C ||_diamond <= 4[(1+b_n)^M-1].                 (5)

Choose eta<=tau/(e^3 N1). Then b_n<=exp(-c1 n), with
c1=tau log[tau/(eN1 eta)]-N1 eta >= (2-e^(-3))tau >0. Hence any prescribed
circuit of M<=exp(c1 n) log(1+epsilon/4) tiles has logical diamond error <=epsilon.

Each tile has O(n) active quantum/controller registers, O(n) elementary gates,
readouts/resets/messages and constant GRAPH depth. q live blocks use O(qn) space
and O(qn) operations per matching round. Interblock matching links are explicit
additional hardware edges. If only edges of a fixed bounded-degree block graph
are permitted, physical data/control connectivity stays bounded degree. Arbitrary
long-range logical addressing would need routing and its extra time/locations.
Target encoded transfer consumes one protected |0_L> block per operation.

The AKP pair-Hamiltonian specialization uses the corrected v2 constant
exp(1+1/(2e)) and must cover the entire hardware dilation. All runtime syndrome
and bitwise transfer controls are noisy and have bounded fanout. The prescribed
ideal gate schedule/code description is supplied, as in any circuit specification;
arbitrarily unreliable shared global instruction bits are not free controls.

4. WHY BARE OUTPUT CANNOT REMOVE THE FINAL-DECODER BOUNDARY

Suppose an interface promises an actual unencoded output qubit and allows a
fault at its final local location, with a fixed eta>0. Append at that location
U_theta=exp(i theta X), theta in (0,pi/2) chosen so
||U_theta-I||=2sin(theta/2)<=eta. Set W_empty=V_ideal, W_{ell}=(U_theta-I)V_ideal,
and every other exact fault operator zero. This support-respecting expansion
has E({ell}) norm<=eta and every other nonempty cylinder zero, so it satisfies
the full aggregate local-noise condition for any block size.

Nevertheless its output channel differs from the bare ideal identity by diamond
norm 2sin(theta)=Omega(eta), independent of n. No earlier code can correct a
fault after its final unprotected output operation. The analogous final classical
output-bit flip also forces constant error if that bit's output location is
within the allowed fault model. Arbitrary-accuracy output therefore has to remain
protected/encoded, or the specification must explicitly exempt a final observer
or interface from those faults. This no-go does not obstruct encoded transfer
or the native CNOT theorem (5); it explains their precise logical-output metric.

 PASS: 43264 branch/operator covariances, common scalar across all 4 logical

6. PRIMARY COMPARISON AND REMAINING LIMITS

CSS transversal CNOT and one-bit teleportation are established primitives, not
new inventions. Primary one-bit source: Xinlan Zhou, Debbie W. Leung, Isaac L.
Chuang, Methodology for quantum logic gate constructions, arXiv:quant-ph/0002039,
https://arxiv.org/abs/quant-ph/0002039. The algebra above supplies the precise
blockwise byproduct/support statement needed here.

Christandl-Fawzi-Goswami arXiv:2512.02760v1 combines coherent single-shot QTC
recovery with logical primitives for its tensorized-channel/perfect-classical
model. Existing constant-overhead and non-Markovian threshold techniques are
the baseline. The extension proposed here is uniform aggregate-noise recovery
with a retained bath and faulty bounded-depth measured controls, including
explicit native gate/transfer circuits and costs. Exact novelty remains under
review; established primitives plus a theorem extension do not justify a major
breakthrough claim.

No full arbitrary logical gate set, addressed single-logical-qubit operation,
magic-state generation/distillation, protected encoded-state acquisition, or
bare quantum readout is supplied by this theorem. Those cannot be declared
complete by applying (5) to unspecified gadgets. The code resources, graph links,
initial encoding and transfer target state are explicit inputs. The operational
extension is stronger than passive memory but is a limited native circuit class.

# Cross-field frontier reset: exact recognizable-series acquisition

**Strongest supported consequence:** family116's finite-word faithfulness plus a newly reconstructed Volterra-kernel argument gives a much smaller exact cyclic detector. For a characteristic-zero proper m-state recognizable series over n letters, the explicit tuple T of dimension 2nm detects every nonzero series at some scalar multiple ell T, ell∈{1,...,m}, using the full matrix response. A nilpotent length marker of dimension 2nm(m+1) also works. This repairs an explicit proper cyclic series that vanishes as an entire unmarked Volterra operator, not merely one seed. Root's scalar-grid proof and the peer's kernel argument were independently reconstructed here; historical priority is unestablished.

The detector compiles an output-only exact residual learner. If the true residual rank is r≤m, batching 2n suffix seeds per query gives at most m+nm²r queries, each of matrix dimension≤2n(m+r)≤4nm, and returns a minimal r-state weighted realization. Every returned matrix entry is charged: the worst nominal response payload is O(n³m⁵), with straightforward coordinate processing O(n³m⁶) field operations and oracle execution charged separately. Larger seed batches trade fewer calls for larger matrices. Exact rational response processing is polynomial in encoded response length; m alone does not bound hidden heights. The precise proof and implementation are in the new addendum. The preceding first-column detector/learner and its eight-fixture independent audit are preserved as a separate packet.

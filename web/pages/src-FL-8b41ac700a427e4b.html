# Global modulation compatibility — research packet

Read `GLOBAL_COMPATIBILITY.md` for theorem statements, complete analytic proofs, limitations and source attribution.

Run `python verify_global_compatibility.py` with SymPy installed. It independently checks nine groups from explicit formulas and writes `global_verification.json`. No exploratory numerical state is an input.

`verification.log` is the executed exact-check log. `prior_replay.log` records 12 passed groups of the earlier tangent verifier; it is an audit record, not an input or a substitute for its analytic proof.

`search_carrier_envelopes.py` is an optional exploratory Torch/NumPy/SymPy search. It uses actual compatible piecewise-linear complex envelopes and multiple trigonometric carriers. `carrier_search.json` contains six completed 2000-update configurations. `carrier_search_200_steps.json` retains six preliminary configurations. No numerical minimum is a lower bound or proof. The final sixth 2000-update configuration was completed separately following tool timeouts; final saved data is complete for all six unique configurations.

`MANIFEST.json` records exact file sizes and SHA-256 hashes. No third-party manuscripts are included. The full planar quasiconvexity question is not resolved. Historical novelty, external proof validation and proof-assistant certification are not established.

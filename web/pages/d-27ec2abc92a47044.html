# Failure attempts, counterexamples, and scope limits

1. **Likelihood-ratio amplification is not an information gain theorem.** The all-pass output has success likelihood ratio raised to the Nth power. This can look like a dramatic improvement if only that conditional event is reported. The full N-mark path has KL `N*d`; the all-pass endpoint is a deterministic compression and has KL `D(Ber(p0^N)||Ber(p1^N)) <= N*d`, strictly less for N>=2 and p0 != p1. The full path Blackwell-dominates the endpoint. Thus the broad claim “N stages create more discrimination from the same event channel” fails.

2. **Using only the expected number of active stages can obscure the budget.** In the stopped chain the expected event count is `J_N(p_h)`, which varies with H. A baseline matched only under H0 is not uniformly cost-matched. The main comparison therefore uses a hard N-event cap and a fixed-N absorbing-stage construction; the stopped-chain identity is reported separately with its hypothesis-dependent costs.

3. **An endpoint cannot generally identify both depth and per-stage rate.** Success probability is `p^N`. Distinct pairs `(N,p)` can generate the same endpoint law; repeated terminal sampling does not repair this structural nonidentifiability. If N is known, p is identifiable from the endpoint distribution, so the result must not be overstated.

4. **Fixed-lag transition snapshots need not identify a CTMC generator.** The explicit three-state circulant pair in `proof.md` satisfies `exp(Q0)=exp(Q1)` at T=1 despite distinct positive transition rates. This is a known embedding/rate-identifiability issue, not a new general discovery. The witness does not prove that every acyclic staged architecture is nonidentifiable.

5. **The optimal threshold result is not a universal optimum over arbitrary CTMCs.** It assumes two simple hypotheses, known Bernoulli parameters, independent marks, a known fixed N, and equal hypothesis-independent event rate. If holding rates depend on H, event times themselves carry information. If rates are unknown, hypotheses are composite, marks are correlated, or the channel is adaptive, the Neyman–Pearson threshold proof no longer establishes optimality.

6. **No physical cost model is supplied.** State cardinality, number of jumps, elapsed time, and number of readouts are counted. Energetic, thermodynamic, implementation, and reliability costs are not derived. State-count comparison alone cannot establish a physically efficient memory device.

7. **Novelty boundary.** Data processing, Blackwell comparison, the Neyman–Pearson lemma, CTMC path relative entropy, and the Markov embedding problem are established prior art. The exact N-stage formulas and the matched finite-state construction are self-contained model calculations. They are not presented as a new general theorem, new application, or externally validated result.

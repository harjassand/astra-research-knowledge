# A04 Phase II: QTC decoder circuit locality and fault-support accounting

Date: 2026-10-09  
Status: internal derivation and compilation plan; not a complete coherent-memory theorem.  This file is a new version. `v1.txt` remains frozen.

## 1. Target interface

The target is one repeated quantum-Tanner-code (QTC) recovery cycle containing (i) extraction of all CSS checks, (ii) the fixed-iteration parallel mismatch-decomposition decoder, and (iii) correction or Pauli-frame update. Every preparation, reset, idle, gate, readout, classical logic operation, message transfer, and correction-control operation is a counted location. The decoder communication graph is the bounded-degree left-right Cayley-complex incidence graph. This is graph-local with constant degree; no Euclidean embedding or routing bound is asserted here.

This note establishes the decoder-side fact needed by a coherent fault-path proof: at fixed code parameters and a fixed number `k` of parallel decoder iterations, the exact QTC decoder can be compiled into an `O(1)`-depth, `O(n)`-location, bounded-fan-in/fan-out circuit on that graph. Thus each decoder fault can change only `O(1)` output correction bits, with a constant that may depend on the chosen `k` and local code parameters but not on `n`.

## 2. Exact source statement used

Gu et al., arXiv:2306.12470v2, 11 Apr 2024, https://arxiv.org/html/2306.12470, place qubits on faces of a left-right Cayley complex with `|Q|=n`; each face has four corner vertices, and each vertex view `Q(v)` has size `Delta^2` (Secs. 2.2–2.3, lines 110–139). `Delta`, local codes, local code degree, and expansion constants are fixed independently of `n`.

Algorithm 3 initializes each local correction from the syndrome restricted to `Q(v)`, forms the mismatch as the coordinatewise sum of the two `V_1` local corrections incident to each face, invokes `ParMismatch^(k)`, and returns the `V_01` correction plus the two local update arrays (lines 330–347 and 270–286). Algorithm 4 performs, for each of the four vertex classes `V_ij`, a local test of candidate codewords supported on `Q(v)`, chooses a maximal local candidate, decomposes it into a local row and column component, and updates only those bits (lines 349–380). The source explicitly describes the initial syndrome-to-local-correction operation as completely local (lines 271–280).

Theorem 4.20 states that if
\[
 A|e|_R+B|D|_V\leq \min(C_\delta n,d/\Delta),
\]
then after `k` parallel iterations the Pauli residual obeys
\[
 |e+\hat f^{(k)}|_R\leq \alpha_k|e|_R+\beta|D|_V,
\quad \alpha_k=\frac{24}{5\kappa}(1-\gamma)^k,
\quad \beta=\frac{6\Delta^2}{\kappa\delta},
\quad \gamma=\frac{1-18\delta}{16},
\]
for fixed `0<delta<1/18` and the theorem's QTC hypotheses (lines 930–942). Pick a fixed `k` large enough that `alpha=alpha_k<1`; this is a constant independent of `n`. The source's algorithm and theorem are Pauli/support statements, not a circuit-level coherent-noise theorem.

## 3. Decoder compilation lemma (internal proof)

Let the fixed component-code degree be `Delta`; a vertex view has `Delta^2` bits. Each local decision in Algorithms 3–4 is a function of a constant number of bits:

* the `argmin` over candidate corrections is over the fixed finite set of bit strings on `Q(v)`;
* the mismatch-decrease test depends on the current mismatch only on `Q(v)`;
* maximal-candidate choice and minimum row/column decomposition range over fixed finite local sets;
* each update writes bits only in `Q(v)`.

Fix deterministic tie-breaking once and for all. Each such operation is therefore a Boolean function on a constant-size input, and can be implemented by a finite circuit whose gate count, depth, scratch bits, and fan-in/fan-out are constants depending only on `Delta` and the component codes. No global reduction or search is present in the parallel algorithm.

For a fixed class `V_ij`, distinct views `Q(v)` are disjoint: every face has exactly one corner of type `ij`. The four classes are processed in a fixed sequence, so updates from different classes are serialized in four constant sublayers. The facewise sums in Algorithms 3 and 4 involve at most the four vertices incident to a face and can be implemented with bounded fan-in and fan-out. The number of local vertices and faces is `Theta(n)`. Therefore for fixed `k` there are constants `d_dec,g_dec,a_dec` such that the decoder has depth at most `d_dec`, uses at most `g_dec n` classical circuit locations and `a_dec n` scratch bits, and every location has bounded fan-in/fan-out. This establishes an implementability bound on the QTC graph, not on an arbitrary Euclidean layout.

Let `G_dec` be the overlap graph whose vertices are local views and where two views are adjacent if they share a face or a decoder wire. Its maximum degree `D_dec` is a constant determined by `Delta` and the fixed local circuit. In a depth-`d_dec` circuit, the output correction bits in the forward causal cone of one faulty classical location lie in at most
\[
c_{dec}:=g_{out}\sum_{j=0}^{d_{dec}}D_{dec}^{j}
\]
output bits, where `g_out` bounds the number of output bits per local processor. This deliberately loose constant is finite and independent of `n`. For `m_dec` faulty decoder locations, the set of output correction bits that can differ from the ideal decoder is contained in the union of these cones and has size at most `c_dec m_dec`.

This argument is insensitive to the Boolean values of the input syndrome and intermediate mismatch bits. It is a circuit-cone statement, not an assumption that the decoder returns the same output after faults.

## 4. Syndrome-extraction location and support bounds (internal construction)

Assume the QTC CSS checks have maximum weight `w` and each data qubit is incident to at most `q` checks, where `w,q=O(1)` follow from fixed local codes and bounded Cayley degree. Assign one measurement ancilla per check. The bipartite check–data incidence graph has maximum degree `max(w,q)`, so its edges can be edge-colored in at most `max(w,q)` colors; executing one color of CNOTs per layer gives constant-depth extraction. X- and Z-check extraction are put in separate constant-depth blocks. Preparation, basis changes, readout, reset, and idles add constant depth. The count is `O(n)` check ancillas, `O(n)` measurement bits, `O(n)` two-qubit gates, and `O(n)` reset/readout/idle locations.

Every fault in this fixed-depth extraction circuit touches a bounded number of system wires. Pushing a Pauli fault through the remaining ideal Clifford circuit can spread it only within its constant-depth bounded-degree causal cone. Thus there are constants `a_ext,b_ext` such that, for a Pauli fault path with `m_ext` faulty extraction/readout locations, its induced data Pauli before decoding has support at most `a_ext m_ext`, and its flipped syndrome/readout record has Hamming weight at most `b_ext m_ext`. The constants include both X- and Z-check rounds and all ancilla interactions. This is a pathwise statement; amplitudes and common-bath coefficients do not enter it.

To use this with a coherent fault-path expansion, expand each local system operator at a faulty location in the Pauli basis on its bounded set of system wires, keeping its bath coefficient as an operator. Each term is a Pauli fault path. For a fixed measurement branch, the extraction circuit is Clifford, so each term gives a definite data Pauli and a definite syndrome-bit flip pattern. Linearity then permits applying the support bounds term by term. This does not imply that amplitudes of different paths add stochastically.

## 5. Per-cycle Pauli recurrence and a positive fault fraction

Let `r_{j-1}` be the stabilizer-reduced support of the residual Pauli entering cycle `j`. Let `m_ext` and `m_dec` count extraction/readout and decoder locations faulty in its fault path. The ideal decoder on the same noisy syndrome has the Theorem 4.20 guarantee; an actual bounded-depth decoder with `m_dec` faults differs from that ideal output on at most `c_dec m_dec` correction bits. Combining the triangle inequality for reduced weight with the extraction bounds gives
\[
 r_j\leq \alpha r_{j-1}
       + (\alpha a_{ext}+\beta b_{ext})m_{ext}
       + c_{dec}m_{dec},
\tag{1}
\]
provided the single-shot theorem's input promise holds for that path. For `m_ext+m_dec<=tau n`, put
\[
K:=\alpha a_{ext}+\beta b_{ext}+c_{dec},\qquad
r_j\leq\alpha r_{j-1}+K\tau n.
\tag{2}
\]
Starting from `r_0=0`, this yields
\[
 r_j\leq K\tau n\frac{1-\alpha^j}{1-\alpha}
 \leq \frac{K\tau}{1-\alpha}n.
\tag{3}
\]
To make the use of Theorem 4.20 self-consistent, define `d_0:=\inf_n d_n/n>0` for the selected QTC family and choose `tau>0` so small that
\[
 A\left(\frac{K\tau}{1-\alpha}+a_{ext}\tau\right)
 +B b_{ext}\tau
 <h,\qquad h:=\min(C_\delta,d_0/\Delta),
\tag{4}
\]
and also `K tau/(1-alpha)<d_0/2`. These strict inequalities have a positive solution because all constants are finite and `h,d_0>0`. Then every cycle with at most `tau n` total extraction+readout+decoder faults satisfies the single-shot input promise and leaves a residual Pauli error of weight `<d_n/2`. This establishes a nonzero *pathwise* correctable fault fraction for the QTC round, conditional on the circuit-fault support model just stated.

The reduction in (1) treats a classical decoder fault as an additive output-correction error. Faults inside extraction are instead converted to `e,D` by the Pauli/Clifford path argument. All counts include reset, measurement, idle, and output correction/frame locations by assigning their bounded causal cones to `a_ext,b_ext,c_dec` (or adding one more constant term to `K`).

## 6. Precisely what remains unproved here

1. **Noise-condition match.** The compilation proof needs an aggregate fault-path hypothesis for every macro-location in the complete circuit, including reset, readout, decoder logic, message/control lines, and Pauli-frame storage. AKP's long-range Hamiltonian derivation gives a local fault-path bound for its stated quantum-location model; its discussion treats stable classical records as error-free. A physical implementation must either include the classical/readout locations in a corresponding system–bath dilation and prove the same bound, or state a separate certified bound for them. This note does not claim that calibration of one-qubit infidelity certifies such a bound.

2. **Good coherent-path map.** Equations (1)–(4) apply to every Pauli term in a fault path. To claim a coherent memory theorem, one still must show that the sum over all paths with at most `tau n` faults per cycle is a single correctable error map on the encoded subsystem, with the common bath retained throughout. The decoder's pathwise Pauli estimate alone does not prove this operator statement.

3. **Bad-path estimate / shared bath.** The proposed exact inversion in the director's message is a promising route. It requires the AKP aggregate `E(S)` to be exactly the sum over all exact fault sets containing `S`, for the complete multiround circuit and the chosen macro-location definition. Then, with `N` locations per cycle and `k=ceil(tau n)`,
\[
B_k=\sum_{|F|\ge k}W_F
 =\sum_{|S|\ge k}(-1)^{|S|-k}\binom{|S|-1}{k-1}E(S)
\]
and, if `||E(S)||<=eta^{|S|}`,
\[
\|B_k\|\leq\sum_{s=k}^N\binom Ns\binom{s-1}{k-1}\eta^s
\leq\binom Nk\eta^k(1+\eta)^{N-k}
\leq\left(\frac{eN\eta}{k}\right)^k e^{N\eta}.
\tag{5}
\]
For `N=N_0 n`, `k=tau n`, the exponent per `n` is at most
\[
\tau\log\left(\frac{eN_0\eta}{\tau}\right)+N_0\eta,
\]
which is negative for sufficiently small fixed `eta`. The combinatorial identity is checked by fixing an exact fault set `F` of size `f`: its coefficient is `sum_{s=k}^f (-1)^{s-k} binom(f,s)binom(s-1,k-1)=1`. The full noise-model identification and physical shared-bath parameter calculation remain with the sibling analysis; (5) is not yet combined with (1) into a theorem.

4. **Round composition and output.** A full proof must handle all rounds with one bath and one global fault expansion; it cannot multiply per-round probabilities. The same expansion must include final logical readout and the classical computation that turns records into output. No lifetime theorem is claimed in this note.

## 7. Claim ledger update

- **Source-reported:** QTC has fixed-degree face/vertex incidence, local mismatch decoder, and Theorem 4.20's Pauli single-shot inequality under its listed `A|e|_R+B|D|_V` premise.
- **Internally proved:** for fixed decoder iteration count and fixed local code parameters, each QTC decoder step is a finite-radius bounded-fan-in/fan-out circuit on the incidence graph; every decoder fault has an `n`-independent bounded output-correction cone.
- **Internally derived, conditional:** a Pauli fault path with at most `tau n` complete-cycle faults obeys the recurrence (1) and stays below the QTC single-shot premise for a sufficiently small positive `tau`, assuming the stated constant support-per-extraction-fault bounds.
- **Open:** end-to-end operator-norm theorem under one coherent shared bath, including complete classical/readout noise model, exact good-path map and logical output.
- **No discovery claim:** this is a circuit-geometry/support lemma that closes one implementation sub-interface only.

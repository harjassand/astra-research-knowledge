LARGE-CLIQUE BROADCASTING: A UNIFORM CHOI MONOGAMY OBSTRUCTION
7 October 2026. Worker /root/large_clique_broadcast.
Status: internally proved scoped theorem; checked algebra independently with
/root/quantum_classicality. Not externally reviewed. The underlying two-setting
monogamy mechanism is established prior art; historical novelty of the precise
flagged-ensemble statement is not claimed.

STRONGEST CONCRETE RESULT

For EVERY r >= 2, every number n of labels divisible by r, and every collection
of flagged r-clique partitions carrying anticommuting Hermitian involutions,
the maximally mixed perturbation experiment

    rho_(i,s) = (I + s a A_i)/D,  i=1,...,n, s in {+1,-1}, 0<a<=1,

has optimal two-receiver marginal broadcasting error

    b_2 >= (a/2)(1 - 1/sqrt(2)) = 0.1464466094... a.                 (1)

No balanced-design, affine-geometry, output-flag-preservation, output symmetry,
independent-copy, or unital-channel premise is needed. Arbitrary flag
reorganization and arbitrary correlated/entangled outputs are covered. Thus
the proposed large-r resolvable-Clifford family cannot give b_2 -> 0 at fixed a.
This rules out this frontier construction; it does NOT prove the unrestricted
bounded-Holevo-capacity broadcasting conjecture.

EXACT INTERFACE

H is finite-dimensional, D=dim(H), H=direct_sum_p H_p. A_1,...,A_n are
traceless Hermitian involutions on H preserving all H_p. For each input flag p,
the labels admit a partition P_p into r-element cliques. For i != j in a clique,
the restricted involutions G_i=A_i|H_p and G_j=A_j|H_p anticommute.

The intended model is a tensor product of independent Clifford systems within
each H_p, followed by a classically mixed direction flag. That is sufficient,
but tensor-product factorization within the input sector is unnecessary for
the proof. The cliques may even have unequal sizes, each at least two.

b_2 = inf_C max_(i,s,R in {B,C}) 1/2 ||C_R(rho_(i,s))-rho_(i,s)||_1,
where C is ONE member-independent CPTP map on the FULL input algebra B(H)
to B(H tensor H), and C_R are its marginals. Channels may read, replace,
reorganize, correlate or coherently manipulate flags. There are no restrictions
on ancillary systems that are discarded by the channel.

PROOF: AN EXACT TWO-OBSERVABLE SUM OF SQUARES

Lemma. Let G_1,G_2 be anticommuting Hermitian involutions on an input register.
Let B_1,B_2 and C_1,C_2 be Hermitian involutions on two distinct output registers.
In particular every B_i commutes with every C_j, while within-receiver
commutators are arbitrary. Define

    K = G_1(B_1+C_1) + G_2(B_2+C_2),
    F = i G_1 G_2,
    R = B_1-C_1, S = B_2-C_2,
    M = R + i F S.

All register tensor factors are implicit. F is a Hermitian involution and
commutes with R,S. Using G_1 G_2 = -i F and cross-receiver commutation,

    K^2 = 4I + 2(B_1 C_1 + B_2 C_2)
                - i F([B_1,B_2]+[C_1,C_2]),

    M^* M = R^2 + S^2 + i F[R,S]
          = 4I - 2(B_1 C_1 + B_2 C_2)
                + i F([B_1,B_2]+[C_1,C_2]).

Consequently

    8I - K^2 = M^* M >= 0,  hence ||K||_op <= 2 sqrt(2).           (2)

The same proof applies to transposed input involutions. No theorem import is
needed for this identity.

CLIQUE AVERAGING AND FLAGS

For an input clique L of size r, put h_i = G_i(B_i+C_i) and H_L=sum_(i in L)h_i.
Every pair within L obeys (2), so

    H_L = (1/(r-1)) sum_(i<j in L) (h_i+h_j),
    ||H_L|| <= (1/(r-1)) binom(r,2) 2 sqrt(2) = r sqrt(2).          (3)

This fractional averaging covers odd r without leaving an unpaired label.
Triangle inequality over all input cliques gives

    ||sum_i G_i(B_i+C_i)|| <= n sqrt(2).                           (4)

Now define the full Choi witness

    W = sum_i A_i^T tensor (A_i tensor I + I tensor A_i).

W is block diagonal in the INPUT flag p alone. On each input flag block, use
G_i=(A_i|H_p)^T and take B_i=A_i tensor I, C_i=I tensor A_i on the FULL output
registers. Applying (4) gives

    ||W|| <= n sqrt(2).                                          (5)

No decomposition into output flags is required. This explicitly includes
channels producing output-flag coherences or changing both flags arbitrarily.

CHOI NORMALIZATION AND TRACE ERROR

Let C be any feasible broadcaster with worst marginal error <= epsilon.
Its unnormalized Choi matrix is

    J = sum_(x,y) |x><y| tensor C(|x><y|).

Complete positivity gives J >= 0; trace preservation gives Tr J = D, so J/D
is a density operator. The convention is

    Tr[J(A_i^T tensor A_i^B)] = Tr[A_i C_B(A_i)],

and likewise for receiver C. Test each marginal error using the norm-one
observable A_i. Since Tr[A_i rho_(i,s)] = s a, the plus and minus error bounds
give, after subtraction,

    (1/D) Tr[A_i C_R(A_i)] >= 1 - 2 epsilon/a.                     (6)

The potentially nonzero term Tr[A_i C_R(I/D)] cancels between signs; no
unitality or symmetry assumption has entered. Summing (6) over n labels and
the two receivers, then using (5), yields

    2n(1-2 epsilon/a) <= Tr[(J/D)W] <= ||W|| <= n sqrt(2).

Rearranging proves (1). This argument gives a lower bound on the optimization
itself and requires no materialized Choi matrix of the growing model.

COMMUTING-REFERENCE EXTENSION

The same result holds for an arbitrary density operator tau commuting with
every A_i, with rho_(i,s)=tau(I+s a A_i). Anticommutation with a clique partner
and [tau,A_j]=0 imply Tr[tau A_i]=0, so these are normalized states and their
target A_i scores remain s a. Replace J/D by

    sigma = ((tau^T)^(1/2) tensor I) J ((tau^T)^(1/2) tensor I).

sigma is positive and has trace Tr C(tau)=1. As [tau,A_i]=0,

    Tr[sigma(A_i^T tensor A_i^R)] = Tr[A_i C_R(tau A_i)].

Sign subtraction bounds this score below by 1-2 epsilon/a; the identical W
operator bound then proves (1). Faithfulness of tau is unnecessary. Arbitrary
central reference spectra and arbitrary classical flag weights therefore do
not rescue this Clifford route. Noncommuting references or nonconstant signal
amplitudes require separate analysis.

AFFINE SPECIALIZATION AND CONSEQUENCE

For q a prime power, labels F_q^d, n=q^d, flags the t=(n-1)/(q-1) directions,
and each direction partitioning labels into affine q-lines, r=q and (1) is
uniform in q,d,t,D. As established by /root/quantum_classicality in this cycle,
the family has C(E)=c(a), e_EB=a(1-1/q)/2, delta=g(a)/t, where

    c(a)=((1+a)ln(1+a)+(1-a)ln(1-a))/2,
    g(a)=sqrt(1-a^2/2)-(1+sqrt(1-a^2))/2.

Capacity can also be checked directly here: each member has entropy
ln D-c(a), all ensemble means have entropy <= ln D, and averaging the two
signs of any label attains I/D. Thus sup_prior chi=c(a)<=ln 2.

The e_EB formula is cited from the other worker, not independently re-proved
in this file. The new broadcasting proof does not use it. In particular,
large t makes delta arbitrarily small at fixed capacity while the new b_2
lower bound stays positive. The small pair gap never licensed broadcasting.

NEXT DECISIVE QUESTION

The unrestricted bounded-capacity conjecture remains open. A counterexample
must evade the present commuting-reference, sectorwise anticommutation witness
(or make a -> 0, which already permits the constant EB replacement error
<=a/2 ->0). A promising next audit is whether candidate bounded-capacity
families with noncommuting reference spectra or several polarization scales
retain an analogous state-weighted monogamy witness. Copy ladders evade this
specific form because their local signal algebra/state reference is different;
the known restricted-pure-ladder capacity theorem already handles that route.

The exact affine b_2 for q>2 is not determined here. The universal floor may be
sharpened toward a/4 by proving the observed aligned Clifford-star spectrum
and controlling changed-output-flag blocks, but that sharpening is unnecessary
to reject the proposed vanishing-b_2 construction.

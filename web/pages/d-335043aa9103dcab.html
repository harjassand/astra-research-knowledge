## Question, interface, and answer

Can the already valid CTMC likelihood confidence set be projected onto a rare generator entry without the enormous absolute-resolvent constants or the persistent nuisance-envelope bias of the old single-endpoint path bound?

Yes: use a certified matrix logarithm over an empirical transition-matrix interval box. Every box is a necessary condition for membership in the ORIGINAL continuous generator confidence set. We also constructed a shared reverse-KL dual bound for a linearized logarithm. Both are rationally checkable, require no true-scale bracket, and use all observed state rows. The simple box repair changes the existing twelve frozen final-data outcomes from4 protected/8 UNKNOWN to8 protected/4 UNKNOWN, using zero new endpoint observations. The fancier shared-budget refinement further tightens some intervals but changes no additional status. This is a useful inference implementation repair, not a foundational discovery or reduced prospective stopping-cost theorem.

Supplied: n=3 baseline0↔1↔2 and2→0, ordinary rates in[7/10,13/10], unknown additional0→2 rate b∈[0,1]; exact calibrated passive lags and endpoint labels; carried chain, no resets/event observations. The five ordinary values, b, and a scale bracket remain unknown. Escape rate λ=13/5 bounds the full original class. Initial law is parameter independent. All computation operates on endpoint count arrays and an outward log-predictor enclosure; no audit truth enters a certificate.

## Confidence set remains the old global set

Let q_i be any positive, exactly normalized predictor chosen before endpoint Y_i. For each fixed global-class Q,

M_k/L_k(Q)=product_i q_i(Y_i)/[exp(t_iQ)]_(X_i,Y_i)

is a mean-one nonnegative martingale on the full endpoint/action filtration. Predictable adaptive lags, row visits and stopping do not alter this identity. The fixed parameter-independent action law cancels. Ville therefore gives simultaneous coverage of C_k={Q:L_k(Q)≥δ M_k} with probability≥1−δ, for EACH fixed true Q. There is no finite-grid true-model assumption and no conditional-on-report coverage claim.

Group retained endpoints by actual lag t and starting state x. Let counts C_txy, N_tx=sum_y C_txy and h_txy=C_txy/N_tx. For visited rows,

log L_sat−log L(Q)=sum_tx N_tx KL(h_tx || P_Q(t)_x).

An outward budget B≥log L_sat−log M−logδ therefore implies

sum_tx N_tx KL(h_tx || P_Q(t)_x)≤B                         (1)

for every accepted Q. Each row/coordinate is necessary separately. For unvisited rows that lag supplies no matrix certificate. Negative budget or inconsistent projection produces UNKNOWN/empty-set diagnostic, never a protected report.

The existing Dirichlet predictor and previous-block fitted predictor have independently audited predictability and exact log arithmetic. We import their scalar routines read-only, preserve source hashes, and do not modify their historical records. A fitted predictor is useful as an untrusted probability proposal; its correctness is not an assumption.

## Box projection theorem

Binary data processing gives N_tx kl(h_txy||P_Q(t)_xy)≤B. Exact scalar KL inversion supplies outward coordinate intervals [l_xy,u_xy]. Tighten them by stochasticity:

l_xy ← max(l_xy, 1−sum_(z≠y) u_xz),
u_xy ← min(u_xy, 1−sum_(z≠y) l_xz).

Sequential tightening is valid because every prior interval still contains the candidate. It does not assume that every point in the rectangular box is stochastic or embeddable.

Write A=P−I and define the rational box norm bound

r=max_x sum_y max(|l_xy−1_(x=y)|, |u_xy−1_(x=y)|).

Skip this lag if r≥1. Otherwise interval matrix multiplication encloses every entry of A^k for all P in the box. With any K≥1,

log P=sum_(k=1)^K (−1)^(k+1) A^k/k + R_K,
||R_K||∞ ≤ r^(K+1)/[(K+1)(1−r)].                         (2)

This follows from the absolutely convergent matrix power series and submultiplicativity, with 1/k≤1/(K+1) in the tail. Rectangular dependency inflation only widens the interval. We evaluate80 terms and add the explicit tail before dividing by t. Interval additions/products round outwards to70 dyadic bits; final b bounds round outwards to48 bits. Multiplication considers all four endpoint products, including signs.

We admit a lag only if 2λt<3. Every eigenvalue z of tQ has |Im z|≤|z|≤||tQ||∞≤2λt<3<π. Hence the analytic principal-log/exponential identity log(exp(tQ))=tQ holds, including non-diagonalizable Q by holomorphic functional calculus. The interval box's r<1 selects that same principal logarithm. At the more restrictive2λt<1 this identity can also be proved directly by differentiating the convergent series along exp(stQ),0≤s≤1. This guard prevents an unproved logarithm branch choice.

Thus every accepted b_Q lies in [(log P)_02/t] computed by (2). Intersect these intervals across usable lags and with the earlier graph/path projection and[0,1]. The inherited survival-exponential enclosure only handles λt≤8; our wrapper skips unsupported lags for that path bound while retaining ALL observations in the global likelihood budget B. Large calibrated lags may therefore yield UNKNOWN, and cannot cause an unsupported exponential call or a silently reduced confidence budget. All intersections contain the same original accepted set, so arbitrarily many times/lags/refinements require no additional confidence spend. A positive interval[L,U] supports the exact harmonic point h=2LU/(L+U) when (U−L)/(U+L)≤1/4. On the simultaneous confidence event this point has |h−b|≤b/4. A cap or failed check returns UNKNOWN with an outer interval, not a guessed estimate.

## Consistency improvement, distinct from novelty

For a fixed identifiable lag with ||P_true−I||∞<1, if every row count tends to infinity and B/min_x N_tx→0, the binary KL boxes collapse to P_true. Increasing K until the tail in(2) vanishes, or choosing K with a shrinking requested arithmetic tolerance, makes this projection converge to the exact b. This is a mathematical consequence of continuity and the established matrix-log identity. The executable uses fixed K80 and fixed rounding, so it has a tiny fixed numerical floor rather than literally satisfying the asymptotic premise.

The old path projection can retain positive width even with exact knowledge of P_02(t): before clipping, its width is

[(exp(λt)−1)P_02(t)/t]+(169/200−49/200)t ≥ (3/5)t.

This is an algebraic obstruction for THAT relaxation. It is not a statistical lower bound. Learning the other rows eliminates this particular nuisance-envelope floor. Matrix-log generator estimation is old prior; the contribution here is a global, effective protected projection of the existing confidence set.

## Optional shared-budget refinement

The box separately spends B on each coordinate. To use (1) jointly within a lag, let H be its empirical transition matrix and T_K(A)=sum_(k=1)^K(−1)^(k+1)A^k/k. At H compute the finite polynomial's exact differential coefficients

c_ij=(1/t) sum_(k=1)^K (−1)^(k+1)/k
      sum_(a=0)^(k−1) [(H−I)^a]_(0i)[(H−I)^(k−1−a)]_(j2).

All powers and coefficients are interval-enclosed. Use midpoint coefficients and charge coefficient error. Subtract c_ii from every row coefficient, since candidate E=P−H has zero row sums.

For ANY η>0 and numbers ν_x>max_y c_xy, direct unconstrained maximization of each coordinate gives

sum_xy c_xy(P_xy−H_xy)
≤ ηB + sum_x {ν_x−ηN_x−sum_y c_xyH_xy
       +ηN_x sum_y H_xy log[ηN_x/(ν_x−c_xy)]}.          (3)

Proof: subtract ηsum_x N_x KL(H_x||P_x) from the objective and impose each row's normalization with multiplierν_x. For a positive empirical mass the coordinate supremum occurs at P_xy=ηN_xH_xy/(ν_x−c_xy), yielding the displayed value. For H_xy=0 its supremum is0 because c_xy−ν_x<0, so zero empirical cells cause no gap. Re-add ηB by(1). We do not require the maximizing coordinates to normalize; dropping that constraint enlarges the supremum. Apply(3) to−c for the lower bound.

The floating golden-section/bisection search only proposes η,ν; it never excludes a model. Positivity is rechecked exactly; any failedν is moved above max c by a positive rational amount. All logarithms and the final upper bound are then recomputed with proved rational enclosures. Optimality or convergence of the floating search is not needed for validity. A failed search may fall back to the box interval.

Let e be the rectangular bound on||P−H||∞ and r the box bound on||P−I||∞. The entire segment H+s(P−H) is in that norm ball. For a finite log polynomial,

||D²T_K(A)[E,E]||∞ ≤ ||E||∞² sum_(k=2)^K(k−1)r^(k−2)
                                ≤ e²/(1−r)².

Thus the Taylor remainder, after dividing by t, is≤e²/[2t(1−r)²]. Add the candidate log-series tail r^(K+1)/[(K+1)(1−r)t], and n e times the largest midpoint-coefficient error. The center itself is outward enclosed. Formula(3) plus these terms gives another valid outer interval. The implementation uses K24. The generic nonlinear norm bound is often too large; this refinement did not produce any additional protected case in the current frozen data. We retain that negative result rather than promote the more elaborate method.

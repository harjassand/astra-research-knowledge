1. THE EXACT REPAIR CHANNEL

Let eta be any density on finite B, sigma>0 a faithful density there, and
delta=||eta-sigma||_1/2. All trace errors below use the HALF convention.
Define the positive part D=(sigma-eta)_+ and the common UPPER envelope

 A=eta+D.

Then A>=eta, A>=sigma>0, Tr D=delta and Tr(A-sigma)=delta. Define

 K=sigma^(1/2)A^(-1/2),
 C=K eta K^dagger,
 F=I-K^dagger K,
 S=sigma-C,
 t=Tr S=1-Tr C.

Since sigma<=A, K^dagger K=A^(-1/2)sigma A^(-1/2)<=I, hence F>=0.
Since eta<=A, C<=sigma, hence S>=0. The exact residual formula is

 S=sigma^(1/2)A^(-1/2)D A^(-1/2)sigma^(1/2),
 t=Tr[D A^(-1/2)sigma A^(-1/2)]<=Tr D=delta.             (1)

When delta>0, D!=0 and A^(-1/2)sigma A^(-1/2)>0, so t>0. Put zeta=S/t
and define on the ENTIRE input matrix algebra

 R(X)=K X K^dagger+Tr(F X)zeta.                        (2)

Both terms are CP. Their traces sum to Tr X, so R is CPTP, and
R(eta)=C+t zeta=sigma EXACTLY. The definition depends only on eta,sigma,
not an extension, input state of a family, prior, direction or observable.
If delta=0, eta=sigma, A=sigma and K=I; define R=id without division by t.
Singular eta is allowed: only the faithful A is inverted.

2. UNIFORM PURIFICATION DISTURBANCE

The common upper envelope also gives a quadratic control of the FILTER:

 r=Tr[(I-K)eta(I-K)^dagger]
   <=Tr[(I-K)A(I-K)^dagger]
   =||sqrt(A)-sqrt(sigma)||_2^2
   <=Tr(A-sigma)=delta.                               (3)

The equality uses K sqrt(A)=sqrt(sigma), not any commutation of eta,A
or sigma. For the last inequality, sqrt(A)>=sqrt(sigma), hence
Tr[sqrt(sigma)sqrt(A)]>=Tr sigma. Expanding the squared HS norm proves
(3). To reconstruct the root-order fact rather than import an unknown
lemma, for positive X use the scalar spectral-calculus identity

 sqrt(X)=(1/pi)integral_0^infinity x^(-1/2)X(X+xI)^(-1)dx.

Inverse order for A>=sigma gives (A+xI)^(-1)<=(sigma+xI)^(-1), and
X(X+xI)^(-1)=I-x(X+xI)^(-1). Integrating the resulting positive difference
proves sqrt(A)>=sqrt(sigma). All dimensions here are finite.

Let xi_QB be ANY finite extension with xi_B=eta. Purify it to a unit vector
alpha on QBE and put beta=(I_QE tensor K)alpha. Then

 ||alpha-beta||^2=r<=delta,
 ||beta||^2=Tr C=1-t<=1.

The rank-one factorization
 alpha alpha^dagger-beta beta^dagger
  =(alpha-beta)alpha^dagger+beta(alpha-beta)^dagger
and the trace norm of a rank-one operator give

 ||alpha alpha^dagger-beta beta^dagger||_1/2
   <=(||alpha||+||beta||)||alpha-beta||/2<=sqrt(delta).

Partial-trace contraction for Hermitian differences, even when their traces
are unequal, therefore gives

 ||xi-(id_Q tensor [K(.)K^dagger])(xi)||_1/2<=sqrt(delta). (4)

The failure branch Z=(id_Q tensor [Tr(F .)zeta])(xi) is positive with
Tr Z=Tr(F eta)=t. Adding it and using the triangle inequality proves

This is ONE R uniformly over ALL finite references Q and ALL extensions

4. EXACT FAILED LOWER-ENVELOPE SHORTCUT

The classical maximal-common-mass argument would seek one positive
Omega<=eta and Omega<=sigma with Tr Omega>=1-delta. That is false for
noncommuting states, even with faithful sigma. Take

 eta=diag(1,0),
 sigma=[[3/4,1/4],[1/4,1/4]],
 delta=sqrt(2)/4.

Omega<=eta forces Omega=q|0><0|. Positivity of sigma-Omega then forces
det(sigma-Omega)=1/8-q/4>=0, so q<=1/2. But 1-delta>1/2. Thus no such
lower common state exists. This is a counterexample to that attempted
proof lemma, NOT to the repair theorem. The construction above uses a
common UPPER matrix A and a non-Hermitian filter instead.

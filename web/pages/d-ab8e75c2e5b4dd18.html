# Exact fracture-budget threshold for parallel corridors

## Interface

Assume the supplied hydraulic graph consists of `m` pairwise edge-disjoint `s`-to-`t` corridors in parallel and no other path. Corridor `i` is a series path with exact conductance `g_i>0`. Deleting any one edge in corridor `i` disconnects that corridor. The cheapest admissible occlusion of that corridor has a conservative energy lower bound `c_i>0` (for edge-level costs, `c_i=min_{e in P_i} c_e`). Costs add across corridors. Initial conductance is `G_0=sum_i g_i`.

For a target `G_*` with `0<G_*<=G_0`, define `D=G_0-G_*` and

```text
B*(G_*) = min { sum_{i in I} c_i : I subseteq {1,...,m}, sum_{i in I} g_i > D }.
```

The strict inequality corresponds to failure defined as post-damage conductance **below** `G_*`.

## Theorem

`B*(G_*)` is the exact minimum lower-bounded occlusion energy that can reduce the network conductance below `G_*`. Every damage event with total energy `< B*` leaves effective conductance at least `G_*`; at budget `B*`, an attaining subset of whole corridors makes the conductance `< G_*`.

### Proof

Deleting an edge in a corridor sets that corridor's conductance to zero; leaving it intact retains `g_i`. The edge-disjoint parallel graph therefore has post-damage conductance `G_0 - sum_{i in I}g_i`, where `I` is the set of destroyed corridors. This is below `G_*` exactly when `sum_{i in I}g_i > D`. The cheapest damage causing that event is the stated minimum. A partial deletion inside a series corridor already destroys the whole route and costs at least `c_i`; additional deletion within the same corridor does not improve the objective. Thus the minimum is exact under the interface.

## Exact small-instance algorithm and cost

For rational conductances and rational costs, clear denominators separately: choose `L_g` so every `w_i=L_g g_i` and `D'=L_gD` is integer, and `L_c` so every `v_i=L_c c_i` is integer. The strict damage threshold is

```text
W = floor(D')+1.
```

Use the 0/1 dynamic program `dp[x] = least scaled cost to destroy total path conductance at least x`, with standard descending-weight updates for each corridor `i` by `(w_i,v_i)`. Return `dp[W] / L_c`. A brute force over subsets is a simpler exact algorithm in `O(2^m)` arithmetic operations. The DP runs in `O(m W)` time and `O(W)` memory, but `W` can be exponential in the bit length of the rational conductances. The problem contains minimum knapsack and is NP-hard in general; the pseudo-polynomial DP is not a polynomial-bit guarantee. For a small number of architected corridors, direct subset enumeration is transparent and inexpensive.

## Strict-threshold fixture

Take three parallel corridors with conductances `(3/5,3/5,3/5)`, destruction costs `(1,1,100)`, and target `G_*=7/10`. The intact total is `9/5`, so `D=11/10`. Destroying one cheap corridor loses `3/5` and leaves `6/5>=7/10`. Destroying both cheap corridors loses `6/5>11/10`, leaves `3/5<7/10`, and costs `2`. Therefore `B*=2` exactly. Each individual route has conductance below target, so the prior single-route certificate requiring `g_i>=G_*` cannot certify this network, while the exact parallel-path budget can.

This is a reduced-model theorem, not a real fracture prediction. It requires known corridor conductances and an additive occlusion-energy budget, no pressure-induced change of surviving conductances, no opening of new paths, and a fixed parallel decomposition. To apply it, conductance uncertainty must be rounded downward and failure-cost uncertainty must use lower confidence bounds; their acquisition dominates the combinatorial calculation.

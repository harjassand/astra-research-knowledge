# Selective pinned retrieval

Run from the workspace root. The helper reads complete frozen metadata, downloads only explicitly requested files, and executes no release code.

```sh
python3 work/handoff_sol_max_check/cycle19/retrieve_release.py list --family 240 --suffix .tex --suffix .bib --suffix .md
python3 work/handoff_sol_max_check/cycle19/retrieve_release.py list --prefix lean/OAI/ModelTheory/Categoricity
python3 work/handoff_sol_max_check/cycle19/retrieve_release.py fetch lean/docs/240.md lean/OAI/ModelTheory/Categoricity/Main.lean --out sources/YOUR_WORKER/cycle19/release
```

Repeat `--family` or `--suffix` to select multiple values. `list` returns manuscript PDFs, directories, existing paths, and the numbered scope document if present. TeX sources are often inside `build/sections` or `build/source`, rather than named `paper.tex` at the manuscript root. The unexpanded catalogue links use `main`; the helper always substitutes commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a` for retrieval.

`fetch` verifies the Git blob SHA1, computes SHA256, and checks known size before accepting or reusing a file. Unknown tree byte sizes are explicitly marked, with the same blob-hash verification. Paths must be canonical relative regular blobs. A corrupt existing file fails and is retained; the helper does not silently overwrite evidence. Each accepted file is checkpointed in `RETRIEVAL_MANIFEST.json`; use one writer per output directory. A failed subsequent selection leaves earlier checkpoints intact.

Choose only your assigned output directory. A successful retrieval is marked `retrieved-unread`; record actual reading depth in your own metadata or assessment. The helper does not grant a manuscript a full-reading or proof-verification status.

`sources/handoff_sol_max_check/cycle19/complete_inventory.json` contains complete repository metadata. The earlier `github_tree_adc7...json` and `github_tree_lean.json` responses are retained **truncated** evidence and must not be used for absence claims. GitHub API listing requests reached a shared unauthenticated rate limit; ordinary pinned raw-file retrieval remains available. The complete filtered-Git metadata fallback avoids duplicate listing requests.

# The protective thermostat cannot also be a rapid worst-case initializer

7 October2026. pde_gate10, root-verified Sol/max, no nested workers.
Status: exact analytic PASS; pde_gate9 independently reconstructed M1--M3
by direct message and preserved the same preparation-versus-mixing scope.
This is a
resource boundary of the current encoding investigation, not a new dynamics
branch or a complexity lower bound for arbitrary Gibbs preparation.

Let Phi_t=exp(tL) be any CPTP semigroup with stationary state rho. Suppose
the acquired CPTP Enc and Dec obey Dec Enc=id and the uniform decoded bound

    ||Dec Phi_t Enc(tau)-tau||_1<=t E                  (M1)

for every qubit state. A reference-safe bound is stronger than needed here.
Take orthogonal inputs tau_+,tau_- and physical sigma_±=Enc(tau_±). Complete
positivity, triangle inequality and contraction of Dec give

    ||Phi_t(sigma_+)-Phi_t(sigma_-)||_1
       >=||Dec Phi_t(sigma_+)-Dec Phi_t(sigma_-)||_1
       >=2-2t E.                                     (M2)

Define the WORST-CASE convergence time at trace-norm tolerance 0<eta<1 by

    t_mix(eta)=inf{t: sup_sigma ||Phi_t(sigma)-rho||_1<=eta}.

Whenever its condition holds, the left side of M2 is at most2eta. Thus

    t_mix(eta)>=(1-eta)/E.                             (M3)

If E=0 and eta<1, the convergence time is infinite. The analogous
definition using worst-case pairwise contraction has the corresponding
constant; choosing conventions never changes the scale. No construction
or efficient preparation of the hard pair sigma_± is required for this
mathematical worst-case lower bound: the definition includes every state.

Apply M3 to root_cycle16/STATIONARY_QUASILOCAL_MEMORY.md and the conditional
CKG Gaussian comparator. At its independently gated equilibrium, shifted
tail, actual LR/geometry and exact-stationarity premises,

    E<=poly(N) exp[-a Q^(1/3)], a>0,
    t_mix(eta)>=exp[Omega(Q^(1/3))]                    (M4)

for fixed eta after absorbing polynomial factors. The admitted conservative
Q bound gives exp[Omega(N^(1/1308))]. Enormous fixed source/temperature
constants remain. This is the SAME engineered protective thermostat, not
an inference about the unchanged physical Davies bath.

The primary CKG2311.09207v2 implementation theorem (main.tex398--425)
simulates its normalized generator for a supplied time t with controlled
Hamiltonian evolution tilde-O(beta t) and jump-oracle calls tilde-O(t).
It does not prove a small t_mix for arbitrary H. The ensuing Gibbs-sampling
discussion explicitly keeps t_mix as a resource. For S=sum_alpha||A_alpha||^2
unscaled channel strength, source time is S times physical time. Therefore
the current memory estimate rules out simply assigning a polynomial
worst-case mixing time to that same thermostat. Its elapsed mixing resource
is exponentially large; the stated implementation method retains a
runtime proportional to the supplied source time, up to logarithms.
An upper simulation-cost theorem is not a query lower bound for every
possible fast-forwarding or preparation algorithm, and none is claimed.

M3 does NOT prove that rho_A=Tr_L(D rho D*) is hard to prepare directly,
that all initial states require this mixing time, or that a different active
reset/annealing/auxiliary sampler cannot be fast. Indeed logical information
can be deliberately discarded during preparation; the storage theorem only
restricts the same protective semigroup. The missing acquired initialization
hypothesis is an explicit procedure supplying rho_A (or one NEW rho sample)
to target precision with paid time, gates, ancilla and physical-control
error. E1's small bad mass does not supply that procedure. BDL v1 independently
leaves efficient thermal initialization open in its Outlook.

Historical novelty is not claimed: slow global mixing of a reliable memory
is elementary. The concrete downstream value is to prevent a circular
application of the newly adopted stationary thermostat as its own free
initializer. A falsifier would be a violation of M1 for the hard pair, a
different mixing norm/convention, or a sampler that uses a different active
preparation mechanism; the last possibility is a genuine future avenue.

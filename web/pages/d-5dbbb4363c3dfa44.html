## Question, code and prior attribution

Given a dense integer quiver representation over Q or a caller-certified Fp and a signed integer weight sigma, acquire an actual optimizer and a justified support upper value. We permit loops and directed cycles. Active vertex dimensions are positive integers in the code; zero-dimensional vertices can be deleted with their zero incident maps. Rational weights require clearing their whole common denominator before this interface. Matrix rationalization must clear a whole arrow's denominator, preserving that arrow's linear map up to a nonzero scalar in the intended field.

It returns CERTIFIED_SUPPORT when an original subrepresentation attains an exact rank bound, UPPER_BOUND_ONLY when a sampled matrix gives only an upper bound, and BUDGET_UNKNOWN when explicit expansion or trials cannot be admitted. ## B1. Remove directed-cycle complications by identity-penalty doubling

Put T=sum_v max(sigma_v,0) alpha_v and

    M=T+max(0,max_v(-sigma_v))+1.

Replace each vertex v by out_v and in_v, both of dimension alpha_v. Add identity out_v -> in_v; replace each original arrow u -> v by out_u -> in_v with the same matrix. The new quiver is bipartite and acyclic. Give out_v weight p_v=sigma_v+M>0 and in_v weight -M.

Every new subrepresentation satisfies U_out,v subset U_in,v. Its score is

    sigma dot dim(U_out) - M sum_v(dim U_in,v-dim U_out,v).

The first term is at most T. If any gap is positive, the score is at most T-M<0, whereas the zero subrepresentation has score0. Therefore every optimizer has equality out=in vertexwise. Such an equal pair is exactly an original subrepresentation, and its score is unchanged. Conversely every original subrepresentation produces one. Thus supports and the lattice of optimizers, including the largest optimizer, are exactly preserved over every field.

If the original input already has strictly positive source weights, strictly negative target weights, and every arrow runs from positive to negative, the code uses it directly. This saves the penalty expansion; it does not change the theorem. For arbitrary original sigma apply the earlier canonical tilt sigma'=(A+1)sigma+ones if the unique largest original optimizer is needed rather than merely support.

This reduction adds A dimensions and one identity arrow per active vertex. Its NUMERIC penalty and weights are explicitly charged. M can be exponential in the bit length of an input weight.

## B2. Explicit weighted-copy matrix space

For a bipartite input let positive source i have weight p_i and negative target j have magnitude q_j. Define

    E_plus = direct_sum_i K^(p_i) tensor V_i,
    E_minus= direct_sum_j K^(q_j) tensor V_j,
    Nplus = sum_i p_i alpha_i,
    Nminus= sum_j q_j alpha_j.

For every arrow a:i->j include a generator with M_a in one target/source copy block and zeros elsewhere, for EVERY target-copy/source-copy pair. Call the resulting rectangular matrix space B. The generator count is sum_a p_tail(a) q_head(a), before omission of zero matrices. Sparse storage records only nonzero integer arrow entries with the explicit block offsets.

For any original bipartite subrepresentation W, its repeated-source subspace R has dim R=sum_i p_i dim W_i and B R is contained in repeated target W_j. Thus score(W)<=dim R-dim B R.

Conversely, every maximum-deficiency R is invariant under ALL source-copy matrix units, including vertex projections. For any such endomorphism Q, BQ subset B. Hence B(R+QR)=BR. If QR were not contained in R, the defect of R+QR would be larger, contradicting maximality. Matrix-unit invariance gives

    R=direct_sum_i K^(p_i) tensor U_i

with identical U_i across copies. Projections alone would not prove that identical-copy statement. Its image is direct_sum_j K^(q_j) tensor (sum_(a:i->j) M_a U_i). Taking precisely these minimal target images produces a bipartite subrepresentation with score=defect(R). Therefore

    support_bipartite(sigma)=max_R (dim R-dim B R).

Combining B1 and B2 yields exact original-quiver support. The argument is characteristic-free and does not enumerate subrepresentations or paths.

## B3. Any sampled blow-up rank supplies an upper bound

For any positive d and ANY A in Mat_d(K) tensor B, and any subspace R of E_plus,

    d(dim R-dim B R) <= d Nplus-rank A.

Indeed A acts on repeated R into repeated BR, so its nullity bounds that defect; equivalently dim A(repeated R)<=d dim BR and dim repeated R-dim A(repeated R)<=nullity A. B2 now gives the original support upper value

    U=Nplus-rank(A)/d.

This is valid without assuming A has maximum rank, without proving a particular blow-up size sufficient, and without a random success claim. A membership witness consists of the coefficient matrices multiplying the exported sparse generators; exact field row elimination checks its rank. An original subrepresentation of score U certifies exact support. In particular the rank upper is useful even if the Wong search fails.

The sampled matrix is rectangular d Nminus by d Nplus. Our rank/deficiency proof and implementation work directly with that rectangle. There is no hidden square-padding oracle. Published square-case algorithms require explicit zero padding if used instead.

## B4. A successful Wong sequence acquires a matching optimizer

Let C=Mat_d(K) tensor B and define W0=0, W_next=C(A^(-1)W). This increasing sequence stabilizes within the target dimension. At every step the code checks W_next subset im A; if containment fails, the trial supplies only its rank upper bound. At stabilization W=C U where U=A^(-1)W. Since W subset im A, A maps U onto W, so

    dim U-dim C U = dim ker A.

For every V, dim V-dim C V<=dim ker A. Thus U is a maximum-deficiency witness. It is also the unique smallest such witness: every maximum V contains ker A and has CV=AV; induction gives W_i subset AV, hence A^(-1)W_infinity subset V.

Maximum-deficiency input matrix-unit invariance, now for the d blow-up copies, forces U=K^d tensor R. Projection recovers R. B2 recovers each source U_i and its minimal target image; in the doubled case B1 forces out=in. The code checks this tensor form, every original arrow, and that the recovered original score equals the rank upper. These final checks make the success certificate independent of a probabilistic rank-attainment assumption. They also protect the interface against an implementation error in the proposed search.

Image computation exploits block structure: for any U, C U is a direct sum of d identical copies of B applied to the sum of the d input-block projections of U. Thus there is no materialized list of d^2 dense blow-up generators. The dense sampled A and all subspace bases remain charged.

## B5. Bounded arithmetic, bit sizes and sampling

The code receives an explicit finite blow-up list and number of trials. Default d in[1,2], two trials each, are practical attempts, not a complete noncommutative-rank algorithm. Seeded Random is used only for reproducible controls. Unseeded SystemRandom samples uniformly from the declared coefficient range; the output still carries no blanket success-probability bound. Fp is caller-certified, not sampled or certified by this module. Q coefficients are bounded integers; Fp coefficient draws range over all residues.

Before any copy loops, preflight charges Nplus+Nminus, ALL copy slots including zero arrows, sparse entries, and square dense basis/nullspace allocations. Before each d, it charges d(Nplus+Nminus) and d^2(Nplus+Nminus)^2. Sparse-entry or Nplus*Nminus bounds alone are insufficient: a zero arrow can have enormous empty-copy loops, and Nminus=0 still leaves an enormous explicit source identity. stat_exec15 found that initial bounded-interface defect; the two literal controls are now rejected BEFORE allocation. The original successful62-check run and the repair are retained separately.

Over Fp all normalized scalars have at most log2(p) bits. The code reports declared conversion/add/sub/mul/div calls, maximum scalar bits, dimensions, sparse/copy counts, coefficient draws, and elapsed times. These are not complete bit-operation counts: Python/Fraction internals, polynomial/input construction, entropy-rejection overhead and I/O are separate. Work is polynomial in EXPANDED dimensions, generator count, current scalar height and declared trials, not necessarily in binary weight length.

For successful/contained Q Wong prefixes one can also bound intrinsic coordinate height in these expanded parameters. Choose a nonsingular rank minor U of A with row/column sets I,J, and let G=embed_J U^(-1) select_I. On im A, AG is identity. Integerize G and a kernel basis using det U. With fixed seed C0=B ker A, the recurrence is

    W_next=C0+B G W whenever W subset im A.

Scaling G to an integer matrix preserves the spans. Every basis space is generated by products of at most the target dimension many fixed integer matrices B_i G applied to C0. Hadamard bounds on the rank minor give generator log-height O(N^2(log-height(A)+log N)+N log-height(B)), for expanded N. Canonical RREF entries are ratios of minors of these generators, hence have polynomial height in expanded N and input matrix/coefficient height. Intermediate Gaussian elimination adds a further polynomial factor. This explains a meaningful special-case height control rather than assuming that arbitrary lattice meet/join chains have bounded heights; the latter is false by the separate squaring control.

# Private check columns cannot calibrate a high-distance one-qubit code

7 October 2026. pde_spectrum9, verified reused GPT-6.1 Sol/max; no nested
workers. Own exact binary linear algebra. Independently reconstructed
PASS in transport's ODD_CALIBRATION_AND_PRIVATE_COLUMN_PEER_GATE.md.
Internal reconstruction is not external validation.

Consider a CSS code with one logical qubit and maximum original Z-check
incidence z per physical qubit. A proposed private-check calibration
would supply, for EVERY original Z-check row a, a physical qubit q_a
whose H_Z column is the unit vector e_a. Such fields can exactly rotate
one unit check at a time and thereby create independent effective check
weights. The promised columns impose a severe distance obstruction.

The unit columns imply that all m original Z rows are independent. Take
them as a column basis. For every other qubit q, its fundamental
dependence is

    c_q=e_q + sum_(a: H_Z[a,q]=1) e_(q_a).

It lies in ker H_Z and has weight at most z+1. The c_q are independent
and span ker H_Z: eliminate each nonbasis coordinate using its c_q.
Because dim(ker H_Z / row H_X)=1, at least one c_q lies outside row H_X.
It is a nontrivial pure-X logical of weight at most z+1. Thus

    d_X <= z+1.                                             (1)

At the actual bounded-incidence z<=7 interface, a full private-check
calibration would force d_X<=8. The independently reconstructed
high-level BDL distance lower bound exceeds eight, so such a complete
private-column supply cannot exist there. This uses the prior distance
certificate only for the final actual-family specialization; (1) itself
is a full proof from explicit CSS matrices.

Dependent original check rows do not evade the statement: identity
columns for ALL those rows would already prove their independence. A
private column for a chosen independent transformed row basis may touch
many ORIGINAL checks, and cannot silently be interpreted as a single
original unit penalty. Partial private supplies, columns of odd degree
greater than one, and matrix-valued calibration within degenerate shells
are not ruled out by (1).

The actual RX bulk note gives a separate obstruction even to fields on
all odd-incidence sites. The two statements are complementary, not a
claim that every positive-X calibration is impossible.

Constructing c_q and quotient testing costs polynomial GF(2) elimination
on supplied matrices. Minimum-distance search is unnecessary. There is
no quantum Gibbs preparation or frequency-acquisition cost hidden in
this binary theorem. The argument is a standard systematic-code basis
calculation; no historical novelty is asserted. Its concrete use is to
eliminate a proposed independent-weight acquisition step before expensive
spectral calculations. Next falsifier: identify a calibrated shell
construction using nonprivate sites with its actual effective operators,
or prove its required independent functions impossible by a stronger
source-specific argument.

# Precision and representation audit for a constructive comparator

## Verdict

The exponential outcome list is not itself an obstruction if the output interface is a succinct tree protocol. For a tree with K=O(d^2) leaves, each sampled outcome effect can be contracted from the exact dense broadcaster descriptor in O(K) operations on d-by-d matrices. There is also an exact recursive classical sampler for the tree outcome law under the maximally mixed input; it handles sibling correlations by keeping a conditional d-by-d state, rather than constructing the full tree output state.

Rare outcomes do not make the canonical-channel Monte Carlo estimator unbounded: its summand has operator norm at most d. A plausible fully polynomial compiler follows from the equal-depth support oracle plus stochastic matrix multiplicative weights, provided one uses a finite-bit input model (for example rational Choi entries) and asks for a succinct operational channel (tree, leaf measurements, and postprocessing), not an explicitly enumerated POVM or an exact dense superoperator. This report checks the interface and numerical costs; the MW convergence proof should still be stated as its own lemma before claiming a completed algorithm.

## Exact interface and recursive sampling

Assume the supplied broadcaster is given by an exact rational Choi matrix, or equivalent rational Kraus/superoperator data, with total bit length L; it is promised (or exactly verified) CPTP, symmetric, and to have both marginals equal to the supplied Phi. Let B* be its Heisenberg adjoint. At a leaf with outcome y, write its projective effect as P_y. If the left and right subtree effects are E_a,F_b in M_d^+, the parent outcome effect is

    E_(a,b) = B*(E_a tensor F_b).

Every effect remains d-by-d; calculating one outcome effect bottom-up costs one dense B* contraction per internal node, not a tensor of dimension d^K. The whole pulled-back POVM has exponentially many effects, but an individual effect has a polynomial-size address and polynomial-time evaluator.

There is a sampler for z with probability p_z=tau(E_z), tau=Tr/d, without enumerating outcomes or storing the full tree output state. For a subtree with input density matrix sigma, recursively:

1. At a leaf, sample y with probability Tr(sigma P_y), and return P_y.
2. At an internal node, calculate Omega=B(sigma) on its two root outputs. Sample the left subtree using the marginal input Phi(sigma); this returns outcome a and its effect E_a.
3. Form the unnormalized conditional right-root state

       chi_a = Tr_L[(E_a tensor I) Omega].

   If it has positive trace, sample the right subtree using chi_a/Tr(chi_a), obtaining outcome b and effect F_b. Return (a,b) and B*(E_a tensor F_b).

Indeed, Tr(chi_a)=Tr(E_a Phi(sigma)), and the conditional probability of b is Tr(F_b chi_a)/Tr(chi_a). Their product is Tr(B*(E_a tensor F_b) sigma), the exact joint Born probability. The recursion visits each tree node once and holds only d-by-d matrices, so it costs O(K) dense channel/effect contractions. This proof also covers a maximally mixed starting state, for which p_z=Tr(E_z)/d=tau(E_z). A zero-trace branch has zero probability and is never selected in exact arithmetic.

Be careful with normalization: the prepared state is

    rho_z = E_z/Tr(E_z) = E_z/(d tau(E_z)),

which has ordinary trace one. E_z/tau(E_z) has trace d, so it is not a density matrix. Under z sampled with probability tau(E_z), the canonical measure-and-prepare transfer operator on normalized-HS space is

    Psi = d^2 E_z[ |rho_z><rho_z|_tau ].

On the traceless space one can equivalently use bar-rho_z=rho_z-I/d. The sampled summand Y_z=d^2|bar-rho_z><bar-rho_z|_tau is PSD and has norm at most d, since Tr(rho_z^2)<=1. Thus rare outcomes have no 1/p_z blow-up in this estimator. In fact Y_z^2 <= d Y_z, so its variance proxy is at most d Psi <= d I.

## Succinct operational output

For any leaf PVMs, define the finite canonical map by

    Psi(X) = sum_z Tr(E_z X) rho_z,    rho_z=E_z/Tr(E_z),

with arbitrary fixed density output for zero effects. The operational protocol is:

* choose a strategy label if this is a mixture of tree strategies;
* run the broadcaster down the binary tree and measure each leaf PVM;
* compute the selected E_z bottom-up with B*;
* prepare E_z/Tr(E_z) and return it.

This is exactly an EB channel in the ideal descriptor model. It uses at most K-1=O(d^2) broadcaster calls and holds K output systems, or O(K log d) qubits when each d-level system is encoded in qubits. Its postprocessing is polynomial if the output format allows uniform classical feed-forward: from the measured label z, a polynomial-time routine contracts E_z and runs a polynomial-size state-preparation procedure for rho_z. A static lookup table of one preparation circuit per z would be exponential. Thus the compiler contract must accept a succinct uniform controller/tree protocol; the literal list of d^K effects is not polynomial-size. If the requested output must be a dense Choi matrix, an explicit POVM list, or a nonadaptive gate list with no classical controller, this argument does not give polynomial output construction.

The response strategy for a PSD dual Q need not diagonalize Q in the equal-depth proof. Any factorization Q=sum_i |A_i><A_i|, r<=n, suffices: put each A_i in H_0 at a distinct leaf, use its spectral PVM there, and pad with trivial leaves to K=2^ceil(log2 n)<2n. Summing the one-leaf score inequalities gives

    Tr(Q Psi_Q) >= Tr(Q)-2m Tr(QG),    m=ceil(log2 n).

This avoids the K^(-1/2) conditioning and tiny code probabilities in the weighted profile construction. The response strategy only depends on a rank-at-most-n factor and K local PVMs.

## Finite-precision costs and limitations

An “exact dense descriptor” alone is not an algorithmic input type unless its entries have a finite representation. Rational Choi/Kraus data with bit bound L is sufficient. Dense input size is polynomial in d (the broadcaster Choi matrix has d^6 entries), and applying B, B*, partial traces, and tree contractions costs polynomially many arithmetic operations. If entries are arbitrary exact reals with no effective precision oracle, a polynomial-time compiler claim is undefined.

The equal-depth proof avoids a near-zero eigenvalue or rare-codeword condition number. A numerical PSD factor Q_tilde=V V* can be projected/renormalized to trace distance eta from Q; the response for Q_tilde transfers to Q with score loss at most O(m eta), because norm(Psi_Q-(I-2mG))=O(m). Each Hermitian factor column A_i is measured in an approximately diagonalizing basis. Normalize every nonzero A_i before solving for that basis, since positive rescaling does not change its PVM; its contribution to Q is then weighted by norm(A_i)^2, and the sum of these weights is Tr(Q_tilde). Thus a common inverse-polynomial basis accuracy gives aggregate O(m zeta) score error, and tiny columns may be dropped at total squared-norm cost eta. No eigenvalue-gap promise is needed: rotations inside a nearly degenerate eigenspace change the observable only by its small eigenvalue spread. Set solver/gate precision to inverse-polynomial in d, 1/delta, and L.

For a literal gate-level implementation, approximate each use of B, each local PVM, and each conditional state preparation to operator/diamond error epsilon divided by a polynomial in K. Composition telescopes over O(K) nodes. State preparation of a normalized effect can use precision depending on log(1/Tr E_z). There are at most d^K outcomes, and log(d^K)=K log d=O(d^2 log d), so assigning an arbitrary fixed output state to any effect with trace below epsilon/d^K loses at most epsilon total probability and needs only polynomial precision. Under rational input and a fixed algebraic gate set, nonzero branch probabilities also have polynomial bit descriptions; adaptive-precision arithmetic with the cutoff avoids resolving smaller branches. The postprocessing is CPTP, so it cannot amplify measurement-channel error.

The maximum tree size remains K=O(d^2), each response strategy costs polynomial time to construct, and its support on Q can be estimated by the recursive sampler. A stochastic matrix-MW implementation would use one or a small polynomial number of sampled Y_z values per round. With reward L_t=(I-2mG)-Psi_t and dual Q_t PSD, Tr(Q_t)=1, the exact tree response has Tr(Q_t L_t)<=0. The sampled reward Lhat_t=(I-2mG)-Y_z is unbiased conditional on the chosen strategy, bounded by O(d), and has variance O(d). Standard matrix exponential-weights regret plus matrix martingale concentration therefore suggests T=poly(d,1/delta,log(1/alpha)) rounds suffice for a delta-slack common comparator with failure probability alpha. The final channel is the uniform mixture of the T stored succinct tree protocols; one run chooses one tree, so its broadcaster-call cost remains O(d^2), while the compiler stores T strategies. A full proof must spell out the stochastic MW update, sign convention, approximate best-response loss, and high-probability event; the existential separation argument by itself does not establish this algorithm.

## Remaining interface boundary

No outcome enumeration is required for (i) sampling the canonical-map score, (ii) evaluating one sampled outcome effect, or (iii) implementing the EB channel as a succinct tree protocol. Exponential work reappears only if one insists on an explicit effect/Kraus list or exact dense transfer matrix for the final canonical channel. The required source of broadcaster uses also matters: an exact dense descriptor supports classical contraction and circuit synthesis; a device-only black box does not support the same classical compiler guarantee without additional tomography/sampling assumptions.

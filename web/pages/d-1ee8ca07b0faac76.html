N24 SMALL HORN CLOCK — v1
Frozen: 2026-10-09
Status: internally derived finite construction; exact-rational interval certificate and explicit perturbation bound replayed locally. No external proof validation, empirical validation, novelty/priority assessment, or claim of a minimum-state realization.

1. Target and scope

Construct an irreducible, finite, all-even, locally detailed-balanced CTMC with positive finite entropy production such that its deterministic observed process is exactly time-reversal invariant at the full path-law level, while the stationary two-time output table at one lag is positive semidefinite but not completely positive in the classical matrix-cone sense. The table is a reflected two-frame table: by stationarity, the lag-one law of (Y_0,Y_1) is also the law of (Y_{-1/2},Y_{1/2}).

This is a 30-state replacement for the 1005-state numerical clock in work/root/horn_clock_check.py. It proves a finite PSD/non-CP separation at one lag. It does not characterize all reversible hidden Markov laws, prove the CP condition sufficient for equilibrium realizability, establish state minimality, or make a historical-priority claim.

2. Exact model

Let the hidden state set be Ω={+,-}×Z_15. Every hidden state is even under physical time reversal. Write A=15/8, b=δ=10^-8, and define the deterministic observation

  g(σ,n)=floor(n/3) in Z_5.

On the + sheet, n→n+1 has rate A and n→n−1 has rate b. On the − sheet, n→n+1 has rate b and n→n−1 has rate A. From (σ,n), switch sheets to (−σ,n) at rate δ. All other off-diagonal rates are zero; diagonals make row sums zero. Both directions around each ring and every sheet switch have positive rate, so the 30-state chain is irreducible.

The uniform distribution π(σ,n)=1/30 is stationary: at every state the total outgoing and incoming rates both equal A+b+δ. Let J(σ,n)=(−σ,n). Since π is uniform, the stationary adjoint is Q*_{x,y}=Q_{y,x}. Directly from the rates,

  Q*_{x,y}=Q_{Jx,Jy},       g(Jx)=g(x).

For any stationary CTMC, Q* generates the hidden path read backward in time. Applying J to that reversed chain gives Q again, and J leaves every observed value unchanged. Thus every finite-dimensional distribution of the deterministic output path agrees with its time reversal. For the finite-state càdlàg process this gives equality of the full observed path laws. The map J is a symmetry exchanging the two driven sheets; it is not a physical odd-parity map. Physical time reversal fixes all 30 states, and Q≠Q*.

Local detailed balance is explicit. Take equal state energies. On the + sheet assign each n→n+1 transition a chemical free-energy drop ln(A/b); on the − sheet assign the opposite drop. The reverse transitions carry the opposite stoichiometry. The sheet-switch edges are work-free and symmetric. Thus each ring edge has the prescribed rate ratio and each sheet has a nonzero chemical cycle affinity. The stationary entropy production rate is

  σ = (A−b) ln(A/b) = (15/8−10^-8) ln(187500000) > 0

in nats per unit time. To check the sum, each of the 30 oriented ring-edge pairs contributes ((A−b)/30)ln(A/b); the 30 sheet-switch edges contribute zero.

3. Base pair table and Horn witness

First set b=δ=0 only for a reference calculation, retaining the same uniform initial distribution. The two sheets are then the opposite directed 15-cycles. This reference chain is stationary but reducible; the physical model above is the irreducible positive-rate perturbation.

At lag t=1, condition on the initial output symbol and its phase r∈{0,1,2}. The phase is uniform. On the + sheet the jump count N is Poisson with mean A=15/8, and the output displacement is

  D=floor((r+N)/3) mod 5.

Set q_d=P(D=d). The − sheet contributes the transpose pair table, so the combined output displacement distribution is

  r_0=q_0,  r_1=r_4=(q_1+q_4)/2,  r_2=r_3=(q_2+q_3)/2,

and the joint table is the symmetric circulant matrix P^0_{ij}=r_{j−i}/5. Equivalently,

  q_d = (1/3) Σ_{r=0}^2 Σ_{n≥0} e^(−A) A^n/n! · 1{ floor((r+n)/3)=d mod 5 }.

For n=3m+s, the contribution to q_m and q_{m+1} is respectively (1,0), (2/3,1/3), or (1/3,2/3) times the Poisson mass for s=0,1,2. These exact rational weights are what the certificate script sums.

Use the 5×5 Horn matrix W with W_ij=−1 when j−i=±1 mod 5 and W_ij=+1 otherwise. It is copositive: W=11^T−2A_C5, so for x≥0,

  x^T W x = (Σ_i x_i)^2 − 4Σ_i x_i x_{i+1} ≥ 0.

For completeness, normalize Σ_i x_i=1 and maximize the edge sum. A maximizer with minimum support cannot contain two nonadjacent positive coordinates: moving their combined mass to the better of those two coordinates does not lower the objective and reduces support. Its support is therefore a clique of C5, hence has size at most two; on a single edge the product is at most 1/4. This proves the displayed inequality. For any completely positive P=BB^T with B entrywise nonnegative, <W,P>=Σ_k B_k^T W B_k≥0. Therefore a negative pairing certifies that P is not CP.

For the circulant P^0,

  <W,P^0> = F := q_0−q_1−q_4+q_2+q_3.

Its Fourier eigenvalues are 1/5, μ_1/5 twice, and μ_2/5 twice, where

  c_72=(√5−1)/4,       c_144=−(√5+1)/4,
  μ_1=q_0+c_72(q_1+q_4)+c_144(q_2+q_3),
  μ_2=q_0+c_144(q_1+q_4)+c_72(q_2+q_3).

The interval script gives the following outward-rounded enclosures from rational arithmetic:

  F ∈ [−0.013146973714577829, −0.013146973714577828],
  μ_1 ∈ [ 0.544100170411135147,  0.544100170411135289],
  μ_2 ∈ [ 0.043162678868956856,  0.043162678868956998].

So P^0 is strictly PSD, with least eigenvalue greater than 0.043162678868956856/5 > 0.00863253577, and its Horn pairing is strictly negative.

4. Certification for the irreducible positive-rate model

The base calculation is not the final CTMC because b and δ are positive. Couple the actual chain to the reference chain from the same stationary initial state. The actual process is the reference process plus independent reverse-jump events of rate b and sheet-switch events of rate δ; both added hazards are state-independent. Until the first added event the hidden paths agree. Hence, over lag one,

  TV(P_actual,P^0) ≤ 1−exp(−(b+δ)) ≤ b+δ,
  ||P_actual−P^0||_1 ≤ 2(b+δ)=4×10^-8,

where the second norm is entrywise matrix ℓ1. Thus

  λ_min(P_actual) ≥ λ_min(P^0)−||P_actual−P^0||_2
                   ≥ λ_min(P^0)−||P_actual−P^0||_1 > 0.008,

and, because |W_ij|=1,

  <W,P_actual> ≤ F+||P_actual−P^0||_1 < −0.012.

The actual pair table is symmetric because the entire output path law is reversible. Its positive semidefiniteness and negative copositive pairing therefore prove that it is PSD but not CP. In the midpoint reflected-word bound from work/root/hidden_dissipation_v2.txt, this one-lag table also yields the certified universal floor σ≥4(0.012)/1=0.048 nats/time for every compatible finite all-even CTMC, using the coarse strict pairing bound above. The construction's own σ is much larger; no sharpness claim is made.

Run from the campaign root:

  python3 work/natural/n24_small_horn/certify_small_horn.py

The script uses only the Python standard library. It checks the finite generator, exact uniform stationarity, the adjoint/J conjugacy, observation preservation, irreducibility, the exponential Taylor/remainder bounds, the Poisson tail bound, rational bounds for √5, and the strict Horn/PSD/perturbation inequalities using fractions.Fraction. Its captured output is work/natural/n24_small_horn/certificate_v1.json. All assertions pass.

The Taylor enclosure for e^A uses its positive series through degree 30; the remainder is bounded by a geometric series with ratio A/32. The omitted Poisson mass from n≥30 is at most (A^30/30!)/(1−A/31). The √5 bracket is [2236067977499789/10^15, 2236067977499790/10^15], verified by exact squaring. These estimates, rather than floating eigenvalue output, certify the base margins. The only approximation from the base process to the physical irreducible process is the explicit 4×10^-8 pair-table ℓ1 coupling bound.

No proof of minimality is offered.

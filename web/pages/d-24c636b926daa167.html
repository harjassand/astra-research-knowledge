INDEPENDENT AUDIT — CONSTRUCTIVE UNIFORM NEAR-FULL UPPER
Date: 2026-10-08
Audited source: outputs/research/spectral_geometry/cycle2/near_full/constructive_uniform_upper.txt
Scope: finite-N,k algebra and endpoint, rank, and constant checks requested. No source file was edited.

CONCLUSION

The stated upper bound and its constants check out for every admissible integer
pair (N,k). The radial edge conductance, resistance-linear profile, exact
nullity/rank count, and norm lower bound are correct. The p=1 logarithmic
constant 12 and the p>=2 constant U_p follow from the displayed estimates.
There is no counterexample in the finite range. Three small clarity additions
would make the endpoint bookkeeping completely explicit: define V_{-1}=0 (or
handle k=1 separately), spell out R+1<=N/4 in the p=1 paragraph, and state
that the theorem is vacuous when floor(32^{-p} n)=0. These are exposition
points, not changes to the result.

1. FINITE RANGE AND INTEGER ROUNDING

Write n=binom(N+p,p), V_s=binom(s+p,p), and M=floor(N/2). The allowed set of
positive integers k is nonempty exactly when n>=32^p. If n<32^p then
floor(32^{-p}n)=0 and there is no k to check. For example, with p=1 the first
nonempty case under N>=16 is N=31; with p=2 it is N=44 (n=1035; at N=43,
n=990).

For k=1, minimality gives R=0 directly. For k>=2, R>=1 and
V_{R-1}<k. The proof's estimate

  V_{R-1}=binom(R+p-1,p)=product_{i=0}^{p-1}(R+i)/p! >= R^p/p!

therefore gives R<(p!k)^(1/p). The same resulting bound on R is trivially true
for k=1. Thus one may avoid an undefined V_{-1} by separating k=1, or adopt
the usual extension V_{-1}=0.

For p=1, V_R=R+1, so R=k-1. Since k<=floor((N+1)/32),

  R+1=k<=(N+1)/32<=N/4,

where the last inequality holds for N>=16. Hence R<M. Also

  N/k >= 32N/(N+1) >= 512/17 > 30.

For p>=2, N>=4p implies p<=N. From n<= (N+p)^p/p! and
k<=32^{-p}n,

  R+1 < (p!k)^(1/p)+1 <= (N+p)/32+1 <= N/16+1 <= N/4.

The final inequality holds for N>=16. This also implies R<M. The resistance
sum from R through M-1 is therefore nonempty and all its weights are positive:
j<=M-1<N, so N-j>0. In particular the endpoint definition works for every
admissible finite pair, including R=M-1.

For p>=2 the sharper rounding estimate used in the constant is

  R+1 < (p!k)^(1/p)+1
       <= ((p!)^(1/p)+1) k^(1/p) = B_p k^(1/p),

using k>=1. The strict inequality can be weakened to the displayed <= bound
without changing the result. For k=1, R=0 and this bound holds directly.

2. EXACT ROOT-EDGE CONDUCTANCE

Represent a state by occupations (N-|beta|, beta_1,...,beta_p), with
|beta|=s. For a root pair joining the first occupation to coordinate i, the
edge from beta to beta+e_i has ladder coefficient squared

  c_beta,i=(N-s)(beta_i+1).

With the prescribed fundamental normalization, the two Hermitian root
generators are (E_{0i}+E_{i0})/2 and (E_{0i}-E_{i0})/(2i). For a diagonal
operator with entries differing by delta across this edge, each generator
contributes c_beta,i |delta|^2/2 to the commutator Hilbert-Schmidt norm; their
sum is c_beta,i |delta|^2. Thus an undirected occupation edge has exactly the
conductance c_beta,i, with no extra factor of two. Roots joining two of the
last p coordinates preserve s and contribute zero for a radial diagonal.

There are g_s=binom(s+p-1,p-1) vertices in layer s. Summing the crossing
conductances gives

  w_s = sum_{|beta|=s} sum_{i=1}^p (N-s)(beta_i+1)
      = (N-s)(s+p)g_s
      = p(N-s) binom(s+p,p).

Consequently E(A)=sum_{s=0}^{N-1} w_s |a_{s+1}-a_s|^2 exactly. This also
confirms that all within-layer root edges disappear from the radial energy.

3. RESISTANCE-LINEAR TAPER AND RANK

Set Q=sum_{j=R}^{M-1}1/w_j. The piecewise definition in the source is
equivalent on R<=s<=M to

  a_s = Q^{-1} sum_{j=s}^{M-1}1/w_j,

with the empty sum at s=M equal to zero. It gives a_R=1 and a_M=0. For each
j=R,...,M-1,

  a_j-a_{j+1}=1/(w_j Q),

so direct substitution yields E(A)=sum_j w_j(a_j-a_{j+1})^2=1/Q. This is the
unique minimizer of the weighted path energy with these two endpoint values,
by Cauchy-Schwarz (or the Euler-Lagrange constant-flux equation).

For X=I-A, entries vanish exactly on layers s<=R. If R<s<M, then the partial
resistance sum defining a_s is strictly between 0 and Q, so 0<a_s<1 and
X>0; for s>=M, X=1. Therefore

  nullity(X)=V_R,  rank(X)=n-V_R<=n-k.

This is the exact integer count; V_R may exceed k because a whole layer is
removed. Normalizing X by its Hilbert-Schmidt norm preserves this rank and
changes its energy quotient to E(X)/||X||_HS^2.

4. NORM LOWER BOUND

On every layer s>=M, X=1. There are n-V_{M-1} such basis states, so
||X||_HS^2>=n-V_{M-1}. The exact ratio is

  V_{M-1}/n = product_{i=0}^{p-1}(M+i)/(N+1+i).

Since M<=N/2 and p<=N/4, every numerator is at most
M+p-1<=3N/4-1, while every denominator is at least N+1. Each factor is
therefore <3/4; in particular V_{M-1}/n<=(3/4)^p. Hence

  ||X||_HS^2 >= eta_p n,  eta_p=1-(3/4)^p.

The argument is valid for odd and even N and includes the layer M itself.

5. CONSTANT AUDIT

For every 0<=s<M, using s+p<=p(s+1) gives

  w_s=p(N-s)binom(s+p,p)
      <= [p^p/(p-1)!] N(s+1)^p = C_p N(s+1)^p.

Thus Q>=(C_p N)^{-1} sum_{q=R+1}^{M}q^{-p}.

For p=1, C_1=1 and R=k-1. Since x^{-1} is decreasing,

  sum_{q=k}^{M}1/q >= integral_k^{M+1} dx/x
                    = log((M+1)/k)
                    >= log(N/(2k))
                    >= (1/2)log(N/k),

where M+1>=N/2 and N/k>=30 imply the last inequality. Therefore
Q>=log(N/k)/(2N), E(X)<=2N/log(N/k), and eta_1=1/4 gives

  E(X)/||X||_HS^2 <= 8N/[n log(N/k)].

To reach the stated form, put L=log(N/k). Then
log(e n/k)=L+1+log(1+1/N), and L>=log(30). Consequently
2[1+log(1+1/N)]<L, so 8/L<=12/log(e n/k); also N/n<=1. This proves the
constant 12. It remains valid in every nonempty p=1 case (the first is
N=31,k=1); for smaller allowed N the integer k-range is empty.

For p>=2, the endpoint bound R+1<=N/4 and M+1>=N/2 imply
(M+1)/(R+1)>=2. The decreasing-integral comparison gives

  sum_{q=R+1}^{M}q^{-p}
    >= integral_{R+1}^{M+1}x^{-p} dx
    >= 1/[2(p-1)(R+1)^(p-1)],

because 1-2^{1-p}>=1/2. Hence

  E(X)/||X||_HS^2
    <= 2(p-1)C_p N(R+1)^(p-1)/(eta_p n)
    <= 2(p-1)C_p B_p^(p-1) N k^((p-1)/p)/(eta_p n).

Finally n>=N^p/p! gives N n^{-1/p}<=(p!)^(1/p), and

  N k^((p-1)/p)/n
    = (N n^{-1/p}) (k/n)^((p-1)/p).

This is exactly the stated U_p, with no hidden dependence on N or k beyond
the displayed regime.

6. FINITE EXACT DIAGNOSTICS

I checked the layer sums, resistance energy identity, rank count, and norm
lower bound using exact rational arithmetic in three admissible examples:

  (p,N,k)=(1,31,1): n=32, R=0, M=15, nullity=1;
  (p,N,k)=(2,63,2): n=2080, R=1, M=31, nullity=3;
  (p,N,k)=(3,60,1): n=39711, R=0, M=30, nullity=1.

These checks illustrate, in particular, that the integer nullity can exceed
k. They are only finite diagnostics; the preceding inequalities establish
the full stated uniform range.

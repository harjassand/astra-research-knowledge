REACTION DYNAMICS CYCLE 3 — MULTIPLE BOUNDARY CORRECTORS
Leaf report | 2026-10-08

Question

For a finite gate graph indexing catalyst-activity strata, when does a bounded
corrector h(g) make the substrate return drift uniformly negative on every
gate state? What fails when a catalyst-free face is closed? Can the failure be
shown in weakly reversible mass action without confusing reducibility with
transience?

Result

There is an exact finite-state answer. Let Q be the row generator of the gate
graph and b(g) the substrate drift in the scale in which gate switching acts.
For a fixed epsilon>0, the inequalities

    b(g) + (Qh)(g) <= -epsilon       for every gate state g                 (1)

have a (necessarily bounded) solution h if and only if every invariant
probability measure mu of Q satisfies

    sum_g mu(g)b(g) <= -epsilon.                                            (2)

It is enough and necessary to check one stationary law on each closed
communicating class of Q. Thus strong connectivity is sufficient to leave one
averaging test, but is not itself the return-drift condition; for a reducible
graph, connectivity can be dropped exactly when every closed component has
negative averaged drift. A closed inactive face with zero/nonnegative drift
cannot be repaired by any h. A positive but asymptotically slower immigration
rate also cannot change the leading-order obstruction.

This condition is an exact theorem for the finite gate inequality, not by
itself a recurrence theorem for a chemical CTMC. Its CTMC use needs a proper
substrate Lyapunov function, a common asymptotic rate scale, bounded jumps,
uniform error control, and non-explosion. A weakly reversible three-species
example below has multiple inactive faces, active strata with an exact
negative substrate drift at large substrate count, and a closed all-inactive
face where every possible corrector has zero generator. All CTMC classes in
the example are recurrent; the obstruction is reducibility/no immigration,
not transience.

1. Exact finite-gate corrector theorem

Let G be a finite set, Q=(q_gh) a conservative generator (q_gh>=0 for g!=h,
sum_h q_gh=0), and b:G->R. Write

    (Qh)(g) = sum_{h!=g} q_gh (h(h)-h(g)).

Then, for a fixed epsilon>0, (1) is feasible iff (2) holds for every
invariant probability mu. In particular, a strictly negative corrector
b+Qh<0 exists iff every closed communicating class has strictly negative
stationary mean of b.

Proof. Rewrite (1) as Qh <= c, where c=-b-epsilon*1. Finite-dimensional
Farkas duality says this system is feasible iff y^T c>=0 for every y>=0 with
y^T Q=0. Every nonzero such y, after normalization by y^T 1, is an invariant
probability of Q; conversely every invariant probability supplies such a y.
Thus feasibility is equivalent to mu c>=0, i.e. mu b<=-epsilon, for every
invariant probability. The invariant probabilities of a finite CTMC are the
convex hull of the stationary laws on its closed communicating classes, so
checking the closed classes is exact. Since G is finite, every solution h is
bounded. This proof also includes transient gate states: their positive drift
can be offset by expected time spent before reaching a closed class.

If Q is irreducible with stationary law pi and pi b<0, the Poisson equation

    Qh = (pi b)*1 - b

has a solution (unique up to an additive constant), and then b+Qh=pi b at
every state. If Q is reducible, the closed-class tests above are the exact
criterion; irreducibility is not necessary.

Sharp failure test. If a closed class C has stationary law pi_C with
pi_C b>=0, then for every h,

    sum_{g in C} pi_C(g) [b(g)+(Qh)(g)] = pi_C b >= 0,

so at least one state of C has nonnegative corrected drift. No bounded or
unbounded h can make (1) hold with epsilon>0 there.

2. Multiple substrate directions and uniformity

If one proper substrate potential V0 supplies one common drift reward b(g),
the theorem applies directly. If distinct active substrate regimes/directions
give rewards b_j(g), one common corrector must solve all inequalities

    b_j(g)+(Qh)(g) <= -epsilon       for every g and every j.                (3)

The exact criterion is then feasibility of this finite linear system. If the
gate generator differs by regime, use Q_j in the corresponding constraints;
the stacked system is still a finite LP, with a stacked Farkas dual rather
than the single-invariant-measure test. Negative stationary averages of every
b_j separately are necessary, but not sufficient for a shared h. Small
abstract witness: G={0,1}, q_01=q_10=1, and

    b_1=(1,-3),       b_2=(-3,1).

Each reward has stationary mean -1. With d=h(1)-h(0), the b_1 inequalities
for epsilon=1/2 require -5/2<=d<=-3/2, while the b_2 inequalities require
3/2<=d<=5/2. There is no shared corrector. This is an abstract gate-LP
obstruction; no mass-action realization of this two-direction witness is
claimed here. If the active strata admit one common coercive V0, use its single
reward b instead of separately demanding (3).

For application to a CTMC with substrate a and gate g, a sufficient exact
asymptotic interface is a proper V0(a), a positive scale G(a), a finite
generator Q, and b(g) such that, uniformly in g,

    L V0(a,g) = G(a)b(g) + o(G(a)),
    L h(g)       = G(a)(Qh)(g) + o(G(a)).                                    (4)

The remainders must be uniform over the gate set for each fixed h. If (1)
holds with margin epsilon, (4) gives

    L(V0+h) <= -(epsilon/2)G(a)

outside a finite substrate set. If G is bounded below there, this is a strict
Foster drift. With V0 norm-like, bounded increments, a non-explosive CTMC,
and the usual finite-sublevel/irreducible-class hypotheses, it yields positive
recurrence of each relevant infinite irreducible class. It does not prove
irreducibility, uniform stationary tightness across classes, or recurrence
from a separate closed boundary class.

The factorization (4) is substantive. If substrate drift is order G(a) but
gate immigration is o(G(a)), then Lh/G(a) from that immigration vanishes for
bounded h; it cannot repair a nonnegative leading boundary drift. A strictly
positive edge with a lower asymptotic order is not equivalent to a uniformly
effective return edge.

Uniformity over a family of rate vectors also needs more than graph
connectivity. For each fixed finite Q, h is finite, but its oscillation can
diverge as gate rates degenerate. For example, let Q_epsilon have both
two-state transition rates epsilon and b=(1,-3). The stationary mean is -1
for every epsilon>0, but solving b+Q_epsilon h=-1 gives
|h(1)-h(0)|=2/epsilon. Thus a uniformly bounded corrector over a rate family
requires quantitative mixing/hitting control (or direct uniform feasibility
of (1)), not just a fixed graph and a negative mean. Similarly, if a finite
gate set arises only after fixing a conserved catalyst total M, a classwise
corrector h_M does not automatically give one uniformly bounded corrector
over all M; the margin, scale, remainder, and corrector norm must be uniform
in M.

3. Weakly reversible mass-action obstruction: two inactive catalyst faces

Use species A (substrate), B,C (catalyst gates) and the four directed
reactions

    A+B  -> 2A+B       rate 1
    2A+B -> A+B        rate 1
    A+C  -> 2A+C       rate 1
    2A+C -> A+C        rate 2.                                               (5)

Each pair is reversible, so the network is weakly reversible. It has three
species, four arrows, two linkage classes, rank one, deficiency one, and
maximum source-complex molecularity three. B and C are individually conserved
in (5); the two coordinate faces B=0 and C=0 disable different catalytic
channels, and their intersection B=C=0 disables all A reactions. This is the
smallest natural two-gate fixture: two distinct catalyst labels plus A require
three species, and each of the two weakly reversible channels uses one
reversible pair (four arrows total). This is not a global minimality claim over
all possible definitions of a gate network.

Under stochastic falling-factorial mass action, at state (a,b,c) the A-birth
rate is a(b+c), the A-death rate is a(a-1)(b+2c), and

    L A = a(b+c)-a(a-1)(b+2c).                                               (6)

Put M=b+c. Since b+2c>=M,

    L A <= M a - M a(a-1) = M a(2-a).                                       (7)

For every active gate state M>=1, this is <=-3M for a>=3. Thus the active
strata have an exact uniform-in-gate negative substrate drift outside the
finite set a<=2. In the two-gate state graph of (5), Q=0 because both catalyst
counts are conserved. At the inactive intersection M=0, all reaction rates
are zero, so LA=0 and Qh=0 for every h; in fact the full generator vanishes
there on every function of (a,b,c). At each fixed a the closed gate component
therefore has mean drift zero, and the finite-gate criterion fails exactly
there. No boundary corrector can manufacture a strictly negative return
drift.

The obstruction is reducibility, not transience. For fixed b,c with M>0,
A=0 is a singleton closed class. On a>=1 the A chain is an irreducible
birth-death chain with

    lambda_a = M a,
    mu_a     = (b+2c)a(a-1),
    rho      = M/(b+2c) <= 1.

Its stationary law is the Poisson(rho) law conditioned on a>=1:

    pi(a) = [rho^a/a!] / [exp(rho)-1],       a>=1.

Detailed balance follows from lambda_a/mu_(a+1)=rho/(a+1). When M=0, every
(a,0,0) is a singleton absorbing class. Hence every state lies in a recurrent
class; there is no transient path in this example. The stationary point masses
delta_(n,0,0) also escape in A within the deterministic stoichiometric class
B+C=0, which is an elementary reducibility warning, not a claim about a
single-class stationary tail.

For the M>0 positive-A class, non-explosion follows from LA<=M: stopping on
the first hit of A>=N gives P(tau_N<=t)<=(a+1+Mt)/(N+1), while every bounded-A
region has finitely many states and bounded total rates. Thus the normalized
detailed-balance law above does certify positive recurrence of that class.

The pair ratios required by complex balance are c_A=1 from A+B<->2A+B and
c_A=1/2 from A+C<->2A+C, so this weakly reversible example is not complex
balanced. That fact is not used in the class calculation.

4. Connectivity does not replace immigration: connected-gate extension

Add the reversible gate exchange

    B -> C       rate 1
    C -> B       rate 1.                                                      (8)

The enlarged network is still weakly reversible. It has one linkage class,
rank two, and the conserved gate total M=B+C. For fixed M>=1, the gate graph
is the finite irreducible path b=0,...,M, with b->b-1 rate b and b->b+1
rate M-b. At B=0 or C=0, the missing catalyst is restored at rate M. Thus
all single-inactive coordinate faces communicate with active gate states in
every positive-M slice. Formulae (6)-(7) are unchanged because (8) has no A
increment.

But the all-inactive state M=0 is still a closed one-node gate class: (8)
cannot create catalyst from zero, and all four A reactions remain disabled.
For M>=1 the leading A drift is already negative for large a in every gate
state, so the corrector condition holds there with no correction needed. At
M=0 its closed component has zero drift. No single corrector gives strict
negative return drift over all gate totals.

For completeness, each fixed-M>=1 slice is non-transient. The A=0 states form
a finite closed gate class. The a>=1 states form one irreducible class: gate
exchange connects every b, and the A birth/death transitions connect every
positive a. Gate transitions preserve A, and (7) gives LA<=-3M for a>=3.
Also LA<=M globally, so V=a+1 rules out finite-time escape by stopped Dynkin
localization; then Foster drift gives positive recurrence on the a>=1 class.
At M=0 the states are absorbing singletons. Again, failure of a uniform
corrector is exactly a closed zero-immigration face; it is not evidence of
transience.

The connected extension is also not complex balanced. At the A+C complex,
complex-balance would require 1+2c_A^2=2c_A, which has no real solution.
Its source order is at most three. This verifies the obstruction within
weakly reversible fixed-rate mass action; no arbitrary controlled rates or
fractional propensities are used.

5. Structural conditions and falsifiers

Exact sufficient conditions for one bounded gate corrector:

  (i) The relevant gate-state set is finite (or a finite set after fixing a
      conserved catalyst total).
  (ii) One common proper substrate potential V0 has a leading drift reward
       b(g) on that set, and gate transitions contribute Qh on the same
       asymptotic scale, as in (4).
  (iii) Every closed communicating class of Q has stationary mean b at most
        -epsilon for one common epsilon>0.
  (iv) The remainder in (4) is uniformly o(G), and G is bounded away from
       zero outside a finite substrate set.
  (v) For the CTMC recurrence conclusion, separately verify non-explosion,
     bounded increments/properness, and the hypotheses of the chosen
     Foster-Lyapunov criterion.

Under (i)-(iii), the exact finite theorem gives h; under (iv), it gives strict
large-substrate drift; under (v), the standard classwise recurrence
conclusion applies. Strong connectivity of Q is a convenient sufficient
way to remove multiple sink-class tests, but it is neither necessary nor
sufficient without the averaged-drift condition. Immigration is not required
if every closed inactive class already has negative drift; when an inactive
class has zero/nonnegative drift, a path out of that class must occur at the
leading scale to make correction possible.

For multiple distinct substrate directions, replace (iii) with feasibility
of the joint system (3); individual mean tests alone do not guarantee one
common h. For a parameter/rate family, require a common epsilon and common
bounded h (or uniform Poisson-resolvent bounds); pointwise finite-state
correctors do not imply uniformity.

Decisive falsifier for a proposed correction: exhibit a closed gate class C
and its invariant law pi_C with pi_C b>=0. This rules out every h by the
stationary averaging identity. For a proposed CTMC application, additionally
falsify any claimed leading-scale correction by showing all immigration
transitions out of C are o(G(a)); then Lh/G cannot change that boundary's
leading drift. To claim recurrence, the exact counterexample (5)-(8) warns
that a missing correction can reflect a family of closed absorbing classes,
not an explosive or transient path.

6. Status and scope

INTERNALLY-PROVED-CANDIDATE: the finite-gate feasibility equivalence (1)-(2),
proved directly by Farkas duality; the common-corrector LP warning for multiple
drift regimes; the exact reaction rates, drift identities, and class
separation in (5)-(8).

CONDITIONAL: positive recurrence from the asymptotic decomposition (4), under
the explicitly listed non-explosion/properness/Foster hypotheses.

NOT CLAIMED: a general weakly reversible recurrence theorem, a transient WR
counterexample, an unequal-diffusion PDE result, or a field-level novelty
result. The result resolves the finite graph corrector question and supplies
a WR no-immigration obstruction; it does not show that all WR networks need
such a correction or that the example has transient behavior.

STRONGEST CLAIM AT THIS CHECKPOINT

The sources checked do not close the generic hard-projected opposite-spin BCS norm problem

  c_k(F) = sum_{I,J disjoint, |I|=|J|=k} |det F[I,J]|^2,

for arbitrary rational-complex F. They give exact polynomial-time support/witness results, special constant-determinant counting formulas, Gaussian-branch simulation, and conditional/adjacent hardness results. None is a general count/FPRAS for this squared-Gram parity partition function. The central interface mismatch is precise: the target is a sum of nonnegative, input-dependent squared volumes over pair-selected subsets, whereas existing Pfaffian-parity counting sums signed determinants and becomes an unweighted count only when every feasible basis determinant is the same constant. The available log-concave-subset-convolution FPRAS also requires two log-concave source measures; the natural hard-site table (1,0,1) has a gap in its support and is outside that premise.

A useful prior-art refinement is that a 2026 monitored-FLO preprint uses coarse-grained, non-Gaussian single-occupancy monitoring plus feedforward and fixed-order Bell fusion to produce noncommutative branch amplitudes. It proves an exponential sequential-memory bound in a free-symbol model and states an average-case hardness conjecture; its sampling theorem is conditional on that conjecture and anti-concentration. This is adjacent to Gutzwiller projection, but is not a hardness or approximation theorem for c_k(F).

DERIVATIONS AND INTERFACE CHECKS

1. The hard norm is a weighted linear matroid parity partition function, not an ordinary parity-base count. Let f_i be the transpose of row i of F, set V=[I_n,F^T], and group its columns into pairs (e_i,f_i). For I subset [n], let V_I contain both columns from each selected pair. Cauchy–Binet gives

  det(V_I^* V_I) = sum_{J subset [n]\I, |J|=|I|} |det F[I,J]|^2,
  c_k(F) = sum_{|I|=k} det(V_I^* V_I).

The forced identity rows yield the displayed minor expansion; disjointness of I,J is exactly the remaining-row condition. Thus the summand is a positive Gram volume. It depends on the whole selected family, and for k<n it is itself a sum of squared minors. This exact identity is recorded in the baseline hard-BCS report and is the right interface for the literature comparisons below.

2. What Pfaffian parity actually counts. Matoya–Oki define a represented parity instance (A,L) and call it Pfaffian when det A[B]=c, the same nonzero field element, for every parity base B. Their Pfaffian minor-summation identity is

  pf(A Delta(z) A^T) = sum_{B parity base} det A[B] product_{ell in B} z_ell.

Only under the constant-determinant condition does specializing z=1 give c times the number of parity bases. Their weighted extension counts minimum-weight parity bases with additive line weights inside this Pfaffian class; it is not a partition function weighted by det(A[B])^2. The hard BCS volume weights above do not meet this interface for arbitrary F. Homogenizing c_k with dummy coordinates does not remove the old minors: it multiplies each old minor by a coordinate matching factor, so its magnitude still varies with F. No reduction from the generic target to the constant-determinant case was found.

3. Support is strictly weaker than counting. Hamada–Iwata Theorem 1.1 gives deterministic unweighted linear matroid parity optimization in O(N r^2 log r) field operations (or O(N r^2) with fast matrix multiplication) for an r-by-N representation under uniform field cost. Their theorem returns maximum independent-pair cardinality and a witness. The source notes that rational input can be reduced to polynomially many finite-field instances (citing Iwata–Kobayashi Theorem 11.3); the baseline audit supplies a Gaussian-integer norm/Hadamard finite-field argument for Q(i) input. This acquires exact support and zero decisions for the BCS partition, including forced/excluded prefixes. It does not sum positive weights, sample by them, or provide an energy/mixing bound. No weighted objective is needed for that support reduction.

4. Why Chen–Liu does not directly close this norm. Chen–Liu Theorem 1.6/Theorem 5.1 gives an FPRAS for a specified coefficient of g_mu g_nu when both nonnegative set-function generating polynomials are log-concave, with positive starting sets and supplied coefficient-range bounds. The homogeneous Theorem 5.1 arithmetic/value-oracle bound is O(n^10 B^2 epsilon^-2 log^2(2B/epsilon)), where B=n+ln(R_mu R_nu); the broader Theorem 1.6 subset-convolution bound is O(n^11 B^2 epsilon^-2 log(2n) log^2(2B/epsilon)). For rational value oracles returning polynomial-bit rationals, Remark A.4 gives an every-execution polynomial-bit implementation, charging rational-probability simulation/abort error. The hard parity table for choosing both-or-neither members of each pair is (1,0,1), so its support is {0,2}, not an interval. Its parity-restricted coefficient measure is not one of the admissible log-concave source measures. The BCS Gram factor is a determinant-weighted pair-selection measure, not an unweighted matroid-base indicator. The baseline establishes other useful Slater/Gutzwiller subclasses under this FPRAS, but the generic parity target remains outside it. This is a hypothesis/interface mismatch, not a refutation of Chen–Liu or a hardness result.

5. Gaussian postselection versus a Gutzwiller filter. Bravyi's FLO formalism includes Gaussian unitary operations and the single-mode projectors for occupation measurements; a postselected sequence resolving a mode-by-mode occupation pattern stays within the Gaussian simulation interface. A Gutzwiller factor on two spin modes is P_i=I-n_{i up}n_{i down}; selecting the accepted subspace {00,01,10} while preserving coherence is a coarse-grained sum of occupation branches, not one mode-resolved Gaussian outcome. The collective norm is a sum over many accepted occupation strings. Efficiently evaluating one Gaussian branch probability therefore does not evaluate this sum.

An exact two-site witness makes the closure failure concrete. Start with the Slater two-form

  (u_1+d_2) wedge (u_2+d_1)
    = u_1 wedge u_2 + u_1 wedge d_1 + d_2 wedge u_2 + d_2 wedge d_1.

Projecting out double occupancy at each site deletes the middle two terms and leaves, up to ordering sign, u_1 wedge u_2 + d_1 wedge d_2. Its wedge square is 2 u_1 wedge u_2 wedge d_1 wedge d_2, which is nonzero. A fixed-particle pure Gaussian state is a decomposable Slater form and has wedge square zero, so the filtered state is non-Gaussian. This is a precise reason Bravyi's Gaussian-branch simulator does not apply to the coherent local Gutzwiller projection. It is not a complexity lower bound.

6. Adjacent hardness sources have different supplied resources. Ivanov proves #P-hardness for a multiparticle amplitude given an initially pairwise-entangled fermion resource, by expressing a permanent as an exterior product of N^2 rank-two two-forms in dimension 2N^2. The input is not a single Slater/BCS Gaussian state and the output is an amplitude, not the sum of squared accepted amplitudes c_k(F). The 2022 fermion-sampling paper studies suitable magic-state inputs; its hardness assumptions do not imply generic projected-BCS norm hardness. The 2026 monitored-FLO source is closer at the measurement boundary: it postselects coarse-grained collision-free block records, with m=kappa n^2 and a constant lower bound on average record probability, then uses feedforward and Bell fusion to enforce an ordered contraction. Its Conjecture 1 posits average #P-hardness of conditional branch probabilities for a constant fraction of outcomes; Theorem 2 derives TV sampling hardness only assuming that conjecture and anti-concentration. The paper itself distinguishes its coarse-grained non-Gaussian monitoring from mode-resolved Gaussian FLO. It does not identify a Gutzwiller norm or prove its hardness.

JOINT QUADRATIC FIBERS OVER F_2
Status: internally proved algebraic construction; exact finite checks; no novelty or external validation claim.

Contract
--------
The complete coefficient lists of k Boolean quadratic functions
q_i:F_2^n -> F_2 are supplied, together with any requested target b in F_2^k.
Write Q_i(x)=q_i(x)+q_i(0), and define the alternating polar form

  B_i(x,y)=q_i(x+y)+q_i(x)+q_i(y)+q_i(0).

The common radical is

  R = intersection_i rad(B_i)
    = {v : B_i(v,x)=0 for every x and every i}.

The map L:R -> F_2^k, L(v)=(Q_1(v),...,Q_k(v)), is linear: for u,v in R,
Q_i(u+v)=Q_i(u)+Q_i(v), since B_i(u,v)=0.

Theorem: common-radical certificate and sampler
------------------------------------------------
Suppose rank(L)=k. Equivalently, there are d_1,...,d_k in R with
L(d_j)=e_j, the standard output basis. This condition itself is a compact,
checkable certificate.

For any target b, choose X uniformly from F_2^n and compute

  delta = b + F(X),       F=(q_1,...,q_k),
  Y = X + sum_j delta_j d_j.

Then F(Y)=b and Y is exactly uniform on F^{-1}(b). In particular every target
is attainable and every fiber has exactly 2^(n-k) points.

Proof. For any r in R, polarization gives F(x+r)=F(x)+L(r). Thus H=span(d_j)
has dimension k, and L restricted to H is an isomorphism onto F_2^k. On every
coset x+H, F is a bijection onto F_2^k. The correction above returns the unique
point of that coset in the requested fiber. A uniform seed chooses each
H-coset with equal probability, so the output is uniform. Equivalently, every
output point has exactly 2^k seed preimages.

The supplied promise that each q_i is balanced is not needed under this
certificate: surjectivity of L implies each coordinate has a radical direction
that flips it, which already proves individual balance.

Computation and certificate
---------------------------
From explicit algebraic-normal-form coefficients, each B_i is an alternating
matrix. Stack their matrices and row-reduce to obtain a basis of R. Evaluate
L on that basis and solve a k by dim(R) binary linear system for a right
inverse. With classical binary Gaussian elimination, certificate discovery
takes O(k n^3) bit operations for k>=1; stored forms use O(k n^2) coefficient
bits. A certificate consists only of the k vectors d_j (kn bits). A verifier
checks B_i(d_j,.)=0 and Q_i(d_j)=1[i=j] for all i,j, in O(k^2 n^2) direct
bit operations. One sample uses n fair random bits, k quadratic evaluations
(O(k n^2) coefficient operations), and an O(kn)-bit correction. It has fixed
runtime once the certificate is found.

The executable reference implementation is joint_quadratic.py. It constructs
and checks the certificate and applies the one-shot sampler. The input model is
supplied: this cost excludes learning or acquiring the q_i. In particular, it
does not pay for or solve the ordinal/comparison acquisition problem.

Exact scope beyond the common-radical certificate
------------------------------------------------
There is an exact characterization of when all joint fibers are equal. For
lambda in F_2^k, let q_lambda=sum_i lambda_i q_i. F(X) is uniform on F_2^k
(equivalently, all fibers have size 2^(n-k)) if and only if every nonzero
q_lambda is balanced. This follows by taking the nontrivial characters of the
output distribution. For each quadratic q_lambda, balance is equivalent to
Q_lambda being nonzero on rad(B_lambda): a radical vector with value 1 pairs
opposite outputs; if Q_lambda vanishes on the radical, q_lambda factors through
the nondegenerate quotient and its quadratic Gauss sum is nonzero. This exact
all-combinations test takes up to 2^k-1 single-quadratic checks, so it is an
exponential-in-k characterization, not a polynomial-time sampler theorem.
Uniform fibers do give a simple exact rejection sampler with expected 2^k
trials for any target.

Rank(L)=k is sufficient for equal, nonempty fibers and a fixed-time sampler,
but it is not necessary for equal fibers. For example, with variables x_0,x_1,z,

  q_1=x_0 x_1+z,       q_2=x_0 x_1+x_0+z.

Both are balanced, R=span(e_z), and L(e_z)=(1,1), of rank one. Yet
q_1+q_2=x_0, so all three nonzero output combinations are balanced; the four
joint fibers each have size two. This is an example where equal-fiber
existence does not provide the common-radical one-shot certificate.

Balanced coordinates alone do not imply a uniform joint map or even that all
targets exist. Two explicit failures follow.

1. Missing targets. For n=3 and variables x_0,x_1,z, take
   q_1=q_2=x_0 x_1+z. Each coordinate is balanced; the joint image is only
   {(0,0),(1,1)}, with fiber sizes 4,0,0,4.

2. Unequal nonempty fibers. For n=5 and variables x_0,x_1,x_2,x_3,z, take
   q_1=x_0 x_1+z and q_2=x_2 x_3+z. Both are balanced; the common radical is
   span(e_z), L(e_z)=(1,1). All four outputs occur, but diagonal fibers have
   size 10 and off-diagonal fibers size 6. Indeed, the product bit has counts
   N(0)=3,N(1)=1, and for output (a,b) the count is
   sum_{z in F_2} N(a+z)N(b+z).

In the non-surjective-L case, the common-radical translations only move the
output by W=im(L). The quotient pi(F(x)) in F_2^k/W is invariant under every
translation by R. Thus this mechanism cannot correct output discrepancies
outside W. Further samplers may exist by analyzing that quotient map; no
general efficient sampler follows from the common-radical test alone.

Individual balance check. For one quadratic q, q is balanced exactly when
Q=q+q(0) is nonzero on rad(B). If Q(r)=1 for some radical vector r, translation
by r pairs zeros and ones. Conversely, when Q vanishes on the radical, it
descends to a nondegenerate quadratic form on the quotient; its Gauss sum is
nonzero. This is the standard quadratic-form balance criterion.

Finite checks
-------------
exhaustive_check.py enumerates all 128 quadratic Boolean functions on F_2^3
(all constants, linear terms, and degree-two monomials) and all 4,900 ordered
pairs with balanced individual coordinates. It checked the common-radical
certificate on every pair, and compared the exact all-component radical test
with the enumerated equal-fiber condition on all 4,900 pairs. The two agreed.
It exhaustively enumerated all seeds for every target whenever the common
radical certificate existed: 168 pairs and 672 target/certificate cases. No
certificate-positive counterexample occurred. It also verified the
single-quadratic radical balance criterion on all 128 functions.

The explicit five-bit unequal example and both three-bit missing/uniform
examples are enumerated exactly. Receipts are in evidence/exhaustive_results.json.
These are finite diagnostics of the formulas, not evidence of novelty or a
physical capability.

Prior art and novelty
---------------------
The common-radical sampler is a direct finite-group action argument built from
standard quadratic-form polarization and an existing one-bit radical-toggle
construction in the inherited learning handoff. The vectorial criterion
"balanced iff every nonzero component is balanced" is standard Fourier/Walsh
theory. Carlet's Boolean-functions monograph gives this criterion (Section 3.2,
Proposition 35) and the quadratic radical balance criterion (Section 5.2,
Proposition 55, credited there to his 1990 thesis); exact source URLs and
retrieved ranges are in evidence/PRIOR_ART.txt.

The closest primary sampling-complexity paper found is Emanuele Viola,
"Quadratic maps are hard to sample," ECCC Report TR15-205 (2015). It proves
that some quadratic p have graph distributions (u,p(u)) that no polynomial-size
constant-depth AC^0 circuit samples. That concerns the circuit class and graph
distribution, not a polynomial-time sampler supplied with coefficients and
conditioned on a chosen fiber. It is therefore a useful boundary/control, not
a conflict or direct novelty claim. No direct prior for this precise
common-radical right-inverse sampler was identified in the bounded search.
Because the construction is an elementary action of a supplied subspace and
specializes the inherited one-bit result, it should be treated as classical
algebra unless a deeper search establishes otherwise.

No acquisition cost is credited, because the entire quadratic model is
supplied. No novelty, practical advantage over stronger general-purpose
quadratic-system methods, or civilization-enabling capability is claimed.

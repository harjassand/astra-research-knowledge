# Certified approximate designs suffice for the unit-charge inverse

7 October 2026. Root extension of the separately audited exact-design compiler. **Independent gate PASS:** `notes/equal_charge_audit/APPROXIMATE_DESIGN_REPAIR_GATE.md`. This removes an exact-design input oracle from the local inverse, provided explicit finite moment/Gram inequalities have been verified. It does not supply an efficient search for appropriate directions or useful high-count physical precision.

Use the notation of `EQUAL_CHARGE_JET_COMPILER.md`. Now omega_i are any N distinct unit directions. The normalized harmonic evaluation matrix E need not be an exact design. Let

    S=E E^T/N, b=E1/N,
    0<alpha<=1, S>=alpha I,
    K=16(D+1)^5/alpha^2, r=1/(4K).

Suppose ||b||_2<=r/4. These are sufficient observable matrix/moment certificates, not an assumption that a floating approximate design is exact.

For radial moments A(t), define

    B=-E^T S^(-1) Lambda^(-1).

Since J=DA(0)=-Lambda E/N, one has JB=I. Addition of spherical-harmonic squares is a pointwise identity, independent of quadrature. It gives

    ||B h||_infinity <=sqrt(M)/(2alpha)||h||_2
                      <=(D+1)/(2alpha)||h||_2.

Set F(h)=A(Bh)-b. Then F(0)=0 and DF(0)=I. The previous pointwise second-derivative bound, composed with this B, gives

    ||D^2F||<=4(D+1)^5/alpha^2<=K

whenever ||Bh||_infinity<=1/[2(D+1)]. The radius-r h-ball lies in that region because its site displacement is at most alpha/[128(D+1)^4].

For any desired moment vector z with ||z||<=r/4, solve F(h)=z-b. The right side has norm at most r/2, so the identical contraction proof applies: h maps to z-b+h-F(h), with Lipschitz constant<=1/4. Hence A(Bh)=z exactly. No exact-design identity has been used. In the rescaled polynomial construction choose epsilon<=r/[4 max(1,S_P)] so the desired z(rho) stays in this ball for every rho<=1. The site radii stay above 3/4; the uniform C^2 tail argument is unchanged.

The initially nonzero b is corrected by changing radii. Therefore reducing only the target amplitude or only rho need not make those changes arbitrarily small relative to the original approximate directions. A tighter initial moment certificate does reduce this correction. This distinction does not affect distinctness or the small-ball critical-point realization.

## Finite certificate and acquisition boundary

Choose directions by normalizing distinct rational nonzero vectors. The resulting coordinates and the harmonic basis values can be enclosed by finite interval arithmetic. Strict bounds such as S>(1/2)I and ||b||<r/4 can be certified by outward matrix norm/LDL estimates. Because exact designs exist and these conditions are open around them, sufficiently accurate rational approximations to a design satisfy them. The proposal does not assert that rounding an arbitrary approximate design suffices.

This supplies a checkable sufficient interface for numerical design generators: candidate directions can be treated as untrusted until their finite Gram and moment certificates pass. Once they pass, the quantitative radial inverse is justified. It does not provide a polynomial-time way to find such a candidate, nor does a high-precision Newton residual alone certify the final placement.

## Cardinality-optimal universal interface, not an equilibrium upper bound

There are M=D(D+2) independent nonconstant harmonic coefficients through degree D. Any analytic map from N freely positioned unit charges has at most 3N real input parameters. If its image contains an open set of exact jets, Sard's theorem requires 3N>=M. A fixed-ray radial map has only N parameters and therefore needs N>=M. Thus an O(D^2) source count is optimal in order for this universal open-jet interface.

This dimension count does not bound the equilibria of an arbitrary N-charge field, or the charge count needed for one special harmonic template. It leaves open whether a structured critical-point family can achieve a stronger lower exponent with a non-universal compiler.

The auditor also observed the stronger necessary count N>=M+1 for this particular small-mean certificate: S-bb^T is positive definite since ||b||^2<alpha, but equals E(I-11^T/N)E^T/N and therefore has rank at most N-1. This agrees with exact-design E1=0 and does not change the optimal asymptotic order. Four independent exact checks, including a perturbed tetrahedron and a noncommuting inverse-order fixture, supplement the universal gate.

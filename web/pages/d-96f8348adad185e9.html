# Cycle15 frozen whole-proof interface

Worker `handoff_sol_max_check`, verified GPT-6.1 Sol/max,7 October2026.
Only cycle15 owned paths are writable. No nested workers. The cycle14 theorem,
proofs, source versions and independent certificate gates remain sealed.

Input format `canonical-LLW-Frege-v1` has canonical topologically ordered
formula nodes, a list of closed source lines, and a rigid final target root.
A source line contains its rule, exact conclusion root, earlier-premise
indices, and the exact substitution annotations required by that axiom.
The rules are the primary canonical23 axioms plus MP, adj_u and theorem
necessitation. There are no hypothesis lines or arbitrary substitution rule.

Optional `def` lines contain a name and body and must conclude precisely
`(e->body) AND (body->e)`. Definition names are globally distinct, absent
from their own bodies and all earlier line/operand roots, absent from the
final target, and cannot occur in earlier definition bodies. Every source
line is validated before installing any target row. Serialized unused syntax
nodes alone are not earlier proof lines; reading their bytes is still charged.

Definitions expand chronologically by root redirection. A definition becomes
`I AND I` for I=`body_exp->body_exp`. Its explicit canonical replacement has
seven primitive source lines:

1. id gives I.
2. adj_u gives J=`I AND1`.
3. fusion introduction at A=B=J gives `J->(J->J*J)`.
4. MP with J gives `J->J*J`.
5. MP with J again gives `J*J`.
6. fusion-to-AND at A=B=I gives `J*J->I AND I`.
7. MP gives `I AND I`.

The same earlier theorem row is reused; no linear antecedent is contracted.
An original L-line proof with d definitions therefore yields L+6d ordinary
source lines, with an explicit original-to-expanded endpoint map. All other
inferences retain their premise wiring after the one global substitution.

The target installer retains both Chu components, memoized ordinary Pair
proof endpoints, and all fixed instantiated proof rows. Every template Pair
input maps to a previously proved compatibility sequent; MP/adj/Nec theorem
inputs map to the exact earlier installed endpoint. No named initial row is
allowed in the final target certificate. Every instantiated template goal
must equal a freshly computed true Chu translation of its source conclusion.
The full target sequence is then checked as an ordinary ILLW proof with cut.

The evidence will retain original and expanded source proofs, input-definition
redirects, per-source-step template ranges, premise/input maps, Pair endpoints,
the actual target syntax/rows and final goal. Counts distinguish original
source lines, expanded source lines, supplied syntax nodes, reachable common
syntax, target rows, formula occurrences, compact certificate bytes, exact
unfolded formula-node counts and exact UTF-8 tree-byte recurrences. Exponential
trees are not printed merely to establish their recurrence sizes.

The matched control uses exactly the expanded ordinary source skeleton and
goal from the EF run. It can distinguish extension-validation/expansion cost
from target compilation without pretending generic old DAG compression is
new. A whole-proof independent replay is requested from logic_gate14, with
no producer imports. His separate scientific branch remains his priority.

This is an implementation/composition investigation of the internally proved
cycle14 method. Generic proof-DAG sharing, finite-skeleton normalization and
fresh EF elimination remain named prior techniques. No new historical
priority, theorem-prover speed claim, full classical EF lower bound, or
hard-family source-proof acquisition is implied.

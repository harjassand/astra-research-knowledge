LEAD RESULT: COMMUTING THRESHOLD REPETITION

Let G=(X,Y,mu,V) be a finite two-player game with finite nonempty answer sets A,B, Boolean predicate V, and commuting-operator value v<1. Make the support graph on positive-mass question pairs, adjacent when two pairs share a coordinate. On each connected component j, condition mu to mu_j and set P_X,P_Y to conditional-expectation projections on L2(mu_j); let sigma_j be the gap of I-(P_X+P_Y)/2 on mean-zero functions. Let sigma=min_j sigma_j, taking sigma=1 if every component is a singleton, and let d=|A||B|. The reconstructed claim is: for every k>=1 and 0<delta<1-v, every commuting strategy, including arbitrary joint answer POVMs on the full question strings and arbitrary Hilbert-space dimension, obeys

  Pr[W_k >= ceil((v+delta)k)] <= exp(-sigma delta^3 k/[2048(1+ln d)]).

For connected support the denominator improves to 1024(1+ln d). The bound also holds for the supremum value; no optimizer is required. The source-level proof was reconstructed in full at work/programmes/games_hamiltonians/leaves/01_l02_proof.txt. Its load-bearing ingredients are separate scalar-ancilla POVM dilation; resolvent transport valid at zero spectrum by strong convergence; a resolvent proof of the operator Jensen/exposure inequality; mixed component reweighting controlled by relative entropy and Pinsker; Hilbert-valued Poincare; and a ceiling-preserving sampled-subset rounding argument. The independent reconstruction found no internal counterexample, but this remains INTERNALLY-PROVED-CANDIDATE: neither formalized nor externally refereed, and novelty/priority is UNKNOWN. Treat all numerical applications as conditional on this candidate until independent proof validation.

NAMED VERIFIER APPLICATION AND COST

For a game of commuting value v, erase only Alice's question with probability 1/4, accepting the erased branch exactly when she answers bottom. The wrapped value is exactly 1/4+3v/4; maximal correlation is at most sqrt(3/4), the pair support becomes connected, and the pair-resampling gap is at least (2-sqrt(3))/4>1/15. The wrapper adds two random bits and one Alice tag bit. Applied to Lin's source-reported coRE-complete verifier (yes value 1, no value <=1/2), it gives yes value 1, no value <=5/8 and, conditional on the connected L02 bound, repeated all-wins value at most

  exp(-27k/[7,864,320(1+ln d)]),   d=(|A|+1)|B|.

If both base answers have a bits, 1+ln d<=2a+2; for a requested polynomial exponent L it suffices to take k=ceil(7,864,320(2a+2)L/27). Randomness, wires and verifier time scale linearly in k; if the base sampler uses s bits and time T_Q and predicate time T_D, the repeated verifier uses k(s+2) random bits and time O(k[T_Q+T_D+x+a]), where x is the base question length. Padding the wrapper to Lin's equal fixed-length binary syntax changes the convenient alphabet bound to 1+ln d<=2a+3. This verifies a named amplification application, not a new coRE class: Lin already proves MIPco=coRE and has anchored parallel repetition. The wrapper arithmetic is checked independently in leaves/02_lin_wrapper.txt and /12_gap_certificate.txt; source status for Lin is SOURCE-REPORTED and L02 is still internally validated only.

The associated repeated acceptance is a positive contraction R_k in the universal commuting-measurement C*-algebra; K_k=I-R_k is positive and has K_k>=(1-exp(-L))I in a no instance. This is representation-independent, but supplies no finite dimension, basis, entry oracle, sparse rows, or local Hamiltonian decomposition. Conditional on Lin's coRE-completeness theorem, a total computable compiler from every game in this coRE-complete family to a finite effectively described Hermitian matrix with certified separated minimum-eigenvalue thresholds would decide a coRE-complete language. This rules out the generic repeated-game-to-finite-matrix route, even without a polynomial time bound. It does not rule out a compiler for a decidable QMA-only family or refute quantum PCP. Full quantifiers and proof are in leaves/07_game_hamiltonian.txt and /19_complexity.txt.

Prior art narrows any possible novelty claim. Lin's Theorem 9.3 gives anchored all-wins decay with power 17 for both finite-dimensional tensor and commuting strategies, but no threshold tail in that theorem. Bavarian–Vidick–Yuen already prove anchored finite-dimensional threshold repetition with explicit anchor, prover-count and answer-length costs. Song gives a cubic anchored all-wins tensor consequence. OpenAI release 277 states a universal finite-dimensional threshold exponent 5 and a fixed-law cubic threshold corollary at a component/minimum-atom parameter kappa_mu; that cost can be much worse than a spectral gap on thin support. Its Lean documentation formalizes a separate exponent-13 result, not the fixed-law cubic statement. Therefore the candidate-specific combination not found in these checked sources is arbitrary commuting strategies plus cubic threshold excess plus support spectral-gap dependence that can become constant under half-erasure. This is a scoped comparison, not a priority claim: historical priority remains UNKNOWN pending broader search and independent proof review. SECOND-CYCLE RESULT: qLTC / HDX DO NOT CLOSE THE POSITIVE-ENCODING GATE

The fresh Bafna–Nguyen–Zhang source (arXiv:2610.04952v1, 2026-10-04) studies combinatorial energy: a constraint counts as violated whenever Tr(Pi rho)>0. Theorem 9.3 gives 2-local Hamiltonians with amplified combinatorial soundness; its unconditional cap is 1/polylogloglog(n). A constant cap is conditional on all of Assumption 4.2, which includes both a polynomial-time robust noisy-syndrome single-shot decoder and an O(1)-depth error-suppressor, in addition to qLTC code parameters. The recent Gay–Granha Jeronimo and Chen–Huang–Liu–Tang preprints state strong static qLTC parameters but do not state those decoder/suppressor guarantees. This is a source-interface audit, not an independent proof review of these long preprints. BNZ also assumes constant-locality/degree input; the N26 amplified clauses can act on 5t_j qubits with growing t_j, outside that formal interface. Its two-locality in qudit count does not itself provide polynomial matrix row sparsity in the high-gap parameter regime.

There is an exact obstruction to converting combinatorial support soundness into ordinary energy, strengthened to a bounded-degree family. Let P_0=|1><1| and P_r=|v_r><v_r| with |v_r>=(r|0>+|1>)/sqrt(1+r^2), and set H_n=(1/(2n))Σ_{j=1}^n(P_0^(j)+P_{2^-n}^(j)). This is a normalized 1-local Hamiltonian with two terms per site. For every state, at least one term on each site has positive trace, so its combinatorial violation fraction is at least 1/2; |0>^⊗n attains 1/2. But λ_min(H_n)=(1-1/sqrt(1+4^-n))/2=Theta(4^-n), with polynomial-bit term descriptions. Thus support soundness alone does not yield even an inverse-polynomial QMA energy promise. The specific BNZ output Hamiltonians might have extra spectral structure, but their v1 theorem does not prove it. Similarly, for m=Theta(N) bounded-incidence qLTC checks, a weight-one Pauli error at a minimally incident site violates O(1) checks, so the normalized check-average has gap O(1/N); the qLTC soundness inequality gives the matching Omega(1/N) scale, not constant normalized gap.

One exact transfer is available if the HDX routing walk itself is made the verifier's pair sampler. For reversible R with stationary pi, mu(u,v)=pi(u)R(u,v) has maximal correlation ||R|| on mean-zero functions and question resampling gap at least (1-||R||)/2. A finite instance can certify ||R||<=beta via a rational matrix and an exact LDL^T witness on the mean-zero subspace. But the BNZ construction does not define a two-prover predicate using this endpoint-pair law, nor connect its game value to the output Hamiltonian; the displayed source bounds also leave a finite numeric beta to acquire. Therefore the HDX theorem does not currently instantiate L02. The precise certificate and acquisition costs are in leaf 24.

POSITIVE LOCALITY BOUNDARY AND ESCAPES

The supplied N26 theorem is a clean all-auxiliary-state barrier. For one fixed (possibly infinite-dimensional) auxiliary Hilbert space, let K_x=sum_a w_a E_{a,x|S_a}, where w_a>=0, sum_a w_a=1, 0<=E<=I, weights do not depend on x, and |S_a|<=r. If inf spec(K_0)<=eta and K_x>=cI for every nonzero x in {0,1}^t, then

  c <= eta + (r/t)(1-eta).

This follows by evaluating on a near-ground vector at zero and averaging singleton syndromes: a term cannot change on coordinates it does not inspect. The bound is sharp. Under total positive norm budget L, the sharp form is c<=eta+(r/t)(L-eta). The theorem allows noncommuting effects and dimension-free auxiliaries, but requires a common sector identification, fixed positive weights, and the positive term-budget decomposition. It does not apply to off-diagonal sector coupling, signed cancellation, x-dependent auxiliary embeddings, restricted legal syndromes, or a globally positive sparse matrix lacking this decomposition. It is an architectural obstruction, not a quantum-PCP no-go.

An exact signed-polynomial example proves the budget premise cannot be replaced by global positivity and low signed degree. On the Boolean cube of four bits, p(x)=(3/5)sum_i x_i-(3/10)sum_{i<j}x_ix_j is between 0 and 15/16 on the full real cube, is zero at 0, and is at least 3/5 on all nonzero Boolean inputs, despite degree 2. Its signed coefficient l1 norm is 21/5, and any positive degree-2 local realization with the same zero and gap needs total positive budget at least 6/5. More generally, the rational Chebyshev approximate-OR family in leaf 06 yields a globally positive contraction with constant Boolean gap and degree O(sqrt(t)); it is a diagonal 1-sparse matrix oracle on supplied bits, but signed coefficient l1 is Omega(t) and any N26 positive local realization needs positive budget Omega(sqrt(t)). This is an explicit escape from overgeneralized N26 statements, not an encoding for the actual overlapping five-qubit hard family.

The bare two-branch common encoding in leaf 15 has an additional route-specific lower bound: for the chosen pair of noncommuting five-qubit seed bases, every exact row of an image enforcer has support at least 1+2^(t/2). The bound applies only to that bare architecture; whether the repeated pair occurs in the exact BMVZ output list remains unverified, and auxiliary workspace or a different isometry may evade it. The actual target remains one common efficient isometry V plus positive sparse C,B with ker(C)=ran(V), a constant invalid-space penalty, and two-sided compressed comparison to the hard Hamiltonian, with row, coefficient, precision and normalization costs charged. No cited qLTC/HDX theorem supplies these objects.

OTHER CONTROLS AND UNRESOLVED CLAIMS

An O(r)-time connected symmetric two-level question sampler can have exact resampling gap 2^(-r-1), so sampler efficiency alone does not certify an inverse-polynomial gap; this does not establish that Lin's specific sampler has a small gap (leaf 04 and leaf 03). The exact signed even-cycle XOR family separates classical value, commuting value, CSP gap, game acceptance gap and question-chain gap; all are recorded separately in leaf 14. Tail-sharpness tests found a 2x2 game with gap sigma=eta whose fixed repeated strategy has a binomial tail with quadratic-deviation exponent independent of sigma, but this only proves looseness for that instance; the uniform cubic sigma*delta^3 commuting bound is not refuted and its optimality remains UNKNOWN (leaf 13). A direct Azuma shortcut fails on repeated CHSH because a legal full-string parity answer can make a one-coordinate question change alter all k wins (leaf 16). Detectability filters can be global even when built from local projectors, and coarse-graining trades locality for normalized gap (leaf 08).

# Source-reset branching assay for one kinetic decision

## Result

I derived a query-specific active readout for a finite killed Markov process. Prepare each parent from the requested source p; while it runs under the original kinetics, let it emit offspring at rate alpha times c(X_t), where c is the requested nonnegative occupation observable. Prepare each offspring from p again. For cumulative reward R equal to the integral of c(X_t) from 0 to absorption time T, we have

\[
\mathbb E_p[R]=p^T(-Q)^{-1}c=\mu,
\qquad \mathbb E[K]=\alpha\mu,
\qquad \alpha_c=1/\mu.
\]

The first identity is the Markov resolvent formula; the second follows because K conditional on R is Poisson with mean alpha times R; the last is the Galton–Watson threshold for the full family. Thus an ideal critical-rate measurement directly reads the requested zero-shift response without reconstructing hidden states or assuming a global low-degree mobility law.

For N798's equilibrium-source observable, take p(x) proportional to rho_0(x)w(x), normalized by Z equal to the rho_0 inner product of w with 1; take c(x)=w(x). Then mu equals the rho_0 inner product of w with A_theta inverse applied to w, divided by Z, which is tau. For an ordinary prepared-source lifetime, use that actual source p and c=1. This assay reads one source/reward pair; it does not return the operator, cross-loads, arbitrary boundary data, or a counterfactual model.

## Cost and limits

The mathematical identity is exact, but finite physical experiments are not free. A terminating first-generation protocol uses N independent parents and counts their offspring, quenching offspring immediately. Its unbiased estimator and variance are

\[
\widehat\mu=\frac{\sum_i K_i}{N\alpha},\qquad
\operatorname{Var}(\widehat\mu)=\frac{\mu/\alpha+\operatorname{Var}(R)}{N}.
\]

For relative error \(\varepsilon\) and failure probability \(\zeta\), a sufficient instance-wise bound is

\[
N\ge\frac{1/(\alpha\mu)+\mathrm{CV}(R)^2}{\zeta\varepsilon^2}.
\]

In the exact connected two-state reversible killed-chain fixture, critical tuning requires 3,999,801 parent runs for 10% relative error with 95% Chebyshev confidence. At that setting the expected daughter count is one per parent, giving 7,999,602 source preparations and about 1.99996e11 model-time units of parent exposure. This is a conservative bound from the authored fixture, not a laboratory estimate. A pilot to tune alpha, source preparation, resets, trigger/counter calibration, and any state dependence in c add cost.

The source-information lower bound is equally direct: if a hidden slow source component is selected with probability delta, any protocol using N independent unlabelled source starts has transcript total variation at most 1-(1-delta)^N. At delta=10^-3, at least 406 starts are needed to distinguish the component with equal-prior error below 1/3, even with complete path observation. No intervention that preserves the hidden kinetics can reveal an unselected source component.

The operation requires an actual source-reset channel and an offspring trigger that leaves the parent's original kinetics unchanged. For N798's weighted observable it also needs calibrated evaluation of w(x). If source and reward are arbitrary dense tables, their representation costs Omega(m) entries for m states; compact representations help only when independently justified. The cost formula for repeated sampling depends on CV(R)^2, which has no uniform bound in the unrestricted class. Finite-time survival of a full branching population does not certify which side of criticality it occupies without a tail or variance bound.

So the result is a source-complete physical readout for one scalar, with an exact finite-state law and explicit sampling cost. The Galton–Watson threshold itself is standard mathematics; no historical novelty is claimed for it. This is not a new solver, a general molecular acquisition theorem, an efficiency gain over direct lifetime sampling, or a demonstrated physical capability.

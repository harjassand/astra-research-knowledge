# Exact finite rational median constructor from family 332

## Statement and boundary

Input: a positive integer (t), a rational row-stochastic matrix (Ainmathbb Q^{n\times n}), and (n) rational vectors (x_1,\ldots,x_n\in\mathbb Q^m). A rational stationary probability vector π with πA=π is needed only to state/check the cotype guarantee; the constructor itself does not use π. The result below also applies to a finite weighted-atom (L_1) space: atom weights affect the norm, but not the output formula.

Define
\[
G=\frac1{t+1}\sum_{s\ge0}\left(\frac{t}{t+1}\right)^sA^s
 =\big((t+1)I-tA\big)^{-1}.
\]
For each state (i), take three independent samples (J_1,J_2,J_3\sim G_{i,\cdot}), and output
\[
y_i=\mathbb E\,\operatorname{med}(x_{J_1},x_{J_2},x_{J_3}),
\]
where the median is coordinatewise. This is exactly computable over the rationals. If π is stationary, the family-332 cotype inequality holds for this particular (y_1,\ldots,y_n), with candidate constant (3024), conditional on the released proof of Theorem 1.2.

The output is a witness for a finite rational vector instance. This is not an algorithm for arbitrary measurable (L_1)-valued inputs, a uniform algorithm for the global Lipschitz extension, or a proof of external validity/priority for the family-332 theorem.

## Fast cut formula

For a fixed feature (k\in[m]), list its distinct input values as (a_1<\cdots<a_q), with (q\le n). Define the upper-tail mass
\[
h_{i,k,r}=\sum_{j:x_j(k)\ge a_{r+1}}G_{ij},\qquad 1\le r<q,
\]
and φ(u)=3u^2-2u^3. Then
\[
y_i(k)=a_1+\sum_{r=1}^{q-1}(a_{r+1}-a_r)\,\phi(h_{i,k,r}).
\]
Indeed, the coordinatewise median is at least a threshold exactly when at least two of three independent samples exceed the threshold. If the one-sample tail probability is (h), this event has probability (3h^2(1-h)+h^3=\phi(h)). The sorted-level-set decomposition telescopes across adjacent values. This is also the family-332 cut formula (T(\Phi(h_i))): for every upper-level cut (B), (h_i(B)=\sum_{j\in B}G_{ij}), and only at most (n-1) cuts per coordinate have nonzero gaps. Thus the finite input need not enumerate all (2^n-2) subsets.

The identity (G=((t+1)I-tA)^{-1}) follows by summing the geometric series. It is well-defined because (tA/(t+1)) has spectral radius at most (t/(t+1)<1). It is stochastic because (A\mathbf1=\mathbf1), so (((t+1)I-tA)\mathbf1=\mathbf1), and the nonnegative geometric-series representation gives (G\ge0).

## Costs and representation

With exact rational arithmetic, construct (G) by inverting one (n\times n) matrix, then aggregate masses by sorted feature values. The operation counts are (O(n^3+mn^2+mn\log n)) rational arithmetic/comparison operations and (O(n^2+mn)) working storage; the (mn^2) term groups the (n) endpoint probabilities by each feature's value levels for every starting state. This replaces the direct triple-sample sum ((O(mn^4)) for all (i)) and exponential cut enumeration. It assumes the full explicit (A) and vector matrix (X) are supplied.

For bit costs, let (B_A) and (B_X) be the total binary input lengths of rational entries of (A) and (X), and let ℓt be the binary length of (t+1). Clearing all denominators of (A) gives an integer matrix for ((t+1)I-tA) with entry bit length (O(B_A+\ell_t)). Hadamard's determinant bound then gives a shared numerator/denominator representation for entries of (G) with bit length (O(n(B_A+\ell_t+\log n))). Per feature, all input values have a common denominator of at most (B_X) bits; each tail mass uses the shared denominator of (G), and φ cubes it. Consequently, each output rational has a representation with bit length polynomial in (n,B_A,B_X,\ell_t), for example (O(B_X+n(B_A+\ell_t+\log n))) for a denominator up to constant factors. Fraction-free exact linear algebra and rational comparisons therefore give polynomial bit complexity in the explicit input size. The script is a transparent Fraction-based reference implementation; no optimized arithmetic backend or benchmark is claimed.

If a transition sampler is supplied instead of the full matrix, one endpoint can be sampled by drawing a geometric number (S\) of transitions with mean (t) and running the chain from (i). Three such paths sample one median vector with expected (3t) transitions (plus the killing-trial convention). This is an unbiased randomized sample of (y_i), not an exact output; every transition-oracle call is charged. The exact rational constructor uses the full matrix and no sampling randomness.

## Proof interface and caveats

The pinned family-332 manuscript defines (N_2(\ell_1)\le12\sqrt{21}) (Theorem 1.2), and Remark 5.3 gives the expected-median identity above explicitly for its geometrically stopped Markov chain. Its proof establishes the cotype inequality with (108\times28=3024). For finite vector data the smoothing output is in the finite weighted-cut recovery image, hence in the span of the original feature coordinates; it never needs extra ambient ℓ₁ coordinates. With a rational stationary π and input data, both sides of the cotype inequality can also be computed exactly.

Do not infer cotype for a prescribed subspace of ℓ₁ or (L_1): the recovery map can leave that subspace, and Mendel–Naor's Kalton example gives a closed subspace of ℓ₁ with no finite metric Markov cotype. Also do not infer a computable global extension selector from this finite witness; the Mendel–Naor global extension theorem used in the extension corollary has no supplied algorithm or numerical universal factor in the source checked here.

## Novelty status

The expectation-median representation itself is already in family 332 Remark 5.3. The polynomial finite-data bit-complexity and locally sampleable interfaces are an implementation consequence of that formula; no historical priority search or comparison against any unpublished forthcoming implementation was possible. Treat the constructor as a reusable candidate capability, not a novel theorem. The family-332 premise remains source-reported/internal-proof-reconstructed and not independently proof-assistant or externally referee validated.

1. THE CORRECTED STATEMENT

In the frozen finite KMS channel/QMS classification, it suffices to test
FOUR against ANY ONE fixed faithful qubit PRODUCT REFERENCE tau_R tensor
sigma_B, including tau_R=I/2, provided ALL faithful joint density matrices
rho_RB are allowed. This is equivalent to testing all faithful tau_R.
The tuned ancilla eigenvalue ratio remains useful in the necessity proof
only as a chosen STATIONARY EXPANSION CENTER. It need not be the fixed
reference appearing in the property's original formulation.

Thus within the stated finite stationary KMS class, the following are
equivalent for either a channel Phi_B or a QMS generator G_B:
 (a) FOUR holds for all faithful rho_RB against one fixed faithful qubit
     reference tau_0 tensor sigma_B.
 (b) FOUR holds for all faithful rho_RB and every faithful qubit tau_R.
 (c) The system channel/generator is modular covariant, equivalently GNS
     self-adjoint within KMS symmetry.
 (d) FOUR holds for arbitrary finite untouched ancillas, faithful product
     references, and all faithful joint states.
The equivalence (b)<->(c)<->(d) was proved in the frozen classification.
The new algebra below proves (a)<->(b), not a new regularity assumption.

2. ROOT-ENERGY REFERENCE CANCELLATION

Write Gamma_eta(A)=eta^(1/2) A eta^(1/2). On R tensor B,
 Gamma_(tau tensor sigma)=Gamma_tau tensor Gamma_sigma.
For an untouched ancillary identity channel,
 T_(tau tensor sigma)
   =(Gamma_tau^(-1/2) tensor Gamma_sigma^(-1/2))
     (id_R tensor Phi_B)
     (Gamma_tau^(1/2) tensor Gamma_sigma^(1/2))
   =id_R tensor T_sigma.
Consequently D_total=I-T_total=id_R tensor(I-T_sigma), and
 E_Phi,tau tensor sigma(rho)
   =Tr[sqrt(rho)(id_R tensor D_sigma)(sqrt(rho))]
is EXACTLY independent of tau for each fixed physical joint rho. The same
calculation for the generator gives
 L_total=id_R tensor[-Gamma_sigma^(-1/2)G_B*Gamma_sigma^(1/2)],
so E_G is also independent of tau. No ancilla traciality, diagonality,
rho commutation, or product-state restriction is used in this identity.

3. ENTROPY-PRODUCTION REFERENCE CANCELLATION

For the channel set Delta(rho)=rho-(id_R tensor Phi_B)(rho). Trace
preservation of Phi_B gives Tr_B Delta(rho)=0 for EVERY joint matrix rho.
For example, testing against arbitrary ancillary A_R gives
 Tr[(A_R tensor I_B)Delta(rho)]
  =Tr[(A_R tensor(I_B-Phi_B*(I_B)))rho]=0.
Since the logarithm of a faithful product reference is
 log(tau tensor sigma)=log(tau) tensor I_B+I_R tensor log(sigma),
the ancillary reference term vanishes exactly:
 Tr[Delta(rho)(log(tau) tensor I_B)]
  =Tr[(Tr_B Delta(rho))log(tau)]=0.
Hence J_Phi,tau tensor sigma(rho)
 =Tr[Delta(rho)(log(rho)-I_R tensor log(sigma))],
independent of tau. For a QMS use Delta(rho)=-(id_R tensor G_B*)(rho).
The same dual calculation uses G_B(I_B)=0 and gives identical cancellation.
These two conservation identities do not themselves require KMS symmetry;
the stationary KMS hypotheses are needed for the classification they refine.

4. WHY THE TUNED CENTER IS STILL ADMISSIBLE

Assume (a), with reference tau_0 fixed once and for all. For any other
faithful tau, the POINTWISE equalities J_tau0(rho)=J_tau(rho) and
E_tau0(rho)=E_tau(rho) imply the same inequality at every faithful joint
state, so (b) follows immediately. In particular one may expand at the
stationary state tau tensor sigma with
tau=diag(s_j,s_i)/(s_i+s_j), exactly as in the frozen necessity proof.
The tested property still has reference tau_0, but its scalar functions
equal those computed with reference tau at that center. All such centers
are allowed because the state's ancillary marginal is unrestricted.
Thus the earlier frequency-cancellation argument applies unchanged.

5. THE ADDITIONALLY FIXED-MARGINAL CAVEAT

If the property fixes ONE tau_0 and allows ONLY joint states satisfying
rho_R=Tr_B rho=tau_0, the admissible domain is a proper slice of all joint
states. Reference cancellation still holds pointwise, but it does NOT
change the domain. The tuned center tau tensor sigma is excluded whenever
tau!=tau_0, and the allowed physical perturbations must satisfy Tr_B A=0,
not merely Tr A=0. The frozen necessity proof therefore does NOT establish
modular covariance from this single fixed-marginal slice property. Its
classification is left UNKNOWN here. Modular/GNS symmetry still suffices,
because the already proved full-domain inequality restricts to that slice.

If, instead, tau is allowed to follow rho_R for EACH arbitrary faithful
joint rho, there is no such restriction: a faithful rho has a faithful
partial trace, and the union of the slices rho_R=tau over all faithful
tau is the full faithful state domain. Such a formulation is equivalent
to (a)/(b) by the same reference cancellation. This logical observation
does not claim a theorem for one fixed-marginal slice or for a differently
embedded quantity in another literature convention.

STRONGEST CLAIM

The direct transfer of the N81 rare-herald PP-collapse construction from bosonic Gaussian optics to fermionic Gaussian linear optics fails at two exact, load-bearing gadgets: the KLM controlled-sign construction uses a two-boson-in-one-mode branch, and the N81 readout compression bunches R occupied bosonic rails into one output mode. Under fermionic second quantization, the first required doubly occupied single mode is outside the Fock space, and the R-to-one bunching amplitude is exactly zero by repeated-row antisymmetry. Reusing the supplied KLM nonlinear-sign contraction also fails on the allowed fermion sector: its postselected amplitudes for target occupations 0 and 1 are unequal. This is a route-specific formal obstruction, not a hardness result for determinant-weighted parity or a no-go for every fermionic postselection encoding.

EXACT DERIVATION

For a passive one-particle matrix U, bosonic Fock amplitudes are permanents of the repeated-row/repeated-column matrix, divided by the occupation factorials. Fermionic amplitudes are determinants on distinct occupied rows/columns. For the exact balanced splitter

  H = (1/sqrt(2)) [[1,1],[1,-1]],

bosonic input |1,1> has amplitudes

  |2,0>: 1/sqrt(2),  |1,1>: 0,  |0,2>: -1/sqrt(2).

The same matrix acting on two fermions gives only |1,1>, with amplitude det(H)=-1. The other two output configurations are forbidden (occupation 2 in one spinless mode). The V/N81 KLM controlled-sign gate first applies this bosonic transformation to two dual-rail modes; its |1,1> branch becomes (|2,0>-|0,2>)/sqrt(2), and the subsequent NS_1 phase flip is applied to those two-particle components. The transformation therefore cannot be copied into fermionic linear optics.

For a second independent failure, the V readout uses a balanced R-mode interferometer and postselects R photons in its first output mode. At R=4, a Walsh matrix has first row (1/2,1/2,1/2,1/2). With one boson in each input mode, the repeated-row permanent is 4!/2^4=3/2; after the bosonic normalization the amplitude is sqrt(24)/16=sqrt(6)/8, as in N81. For fermions the corresponding exterior-power matrix has four identical output rows, so its determinant is zero. Thus the specified readout-herald branch has zero success probability for R>1 in the literal fermionic replacement. A different readout over R modes might avoid this obstruction; it is not supplied by N81's two-detector compression.

The exact 2x2 contraction used in N81's bosonic NS primitive is

  A = [[1-sqrt(2), 2^(-1/4)], [2^(-1/4), 1/2]].

Bosonic permanent amplitudes for target occupations n=0,1,2, with the ancilla input/output fixed to one, are (1/2, 1/2, -1/2). Treating A instead as the one-particle block of a fermionic passive dilation, the allowed n=0 branch has amplitude A_aa=1/2, while the allowed n=1 branch has amplitude det(A)=(1-2sqrt(2))/2. These are not a common scalar. The target n=2 state used by NS_1 is forbidden for a single fermionic mode. So the NS truth table does not survive even on its allowed 0/1 restriction under this literal replacement.

The hard-projected BCS interface has its own signs and forbidden configurations. With canonical mode order (all up modes, then all down modes),

  |BCS_F> = exp(sum_ij F_ij a_i^* b_j^*) |0>

has k-pair coefficient on sorted row/column sets I,J

  (-1)^(k(k-1)/2) det F[I,J].

In the site-ordered physical spin basis, multiply by the additional sign from reordering the site creation sequence into up-then-down order. At half filling on an even n-site system, the hard one-particle-per-site projector retains only k=n/2, |I|=|J|=n/2 and J=V\I; it kills every hole or double-occupancy configuration. This is a different interface from generic charge-herald circuits whose successful patterns can include empty or doubly occupied local sectors.

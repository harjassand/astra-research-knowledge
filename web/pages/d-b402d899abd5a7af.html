# Next-type competitor asymptotic helper

## Result

The kernel-checked theorem
`N33Affine.NextTypeAsymptotic.finite_rpow_sum_add_littleO_tendsto_zero`
proves the requested finite-sum asymptotic. Let `ι` be any finite type,
`h : ℕ → ℝ` tend to zero through positive values, and let each exponent
sequence `p i` converge to `p₀ i > q`. For any fixed real coefficients
`c : ι → ℝ` and any `d : ℝ → ℝ` satisfying
`N33Affine.LittleO d q`,

```lean
Tendsto
  (fun n => (∑ i : ι,
    c i * (Real.rpow (h n) (p i n) / Real.rpow (h n) q)) +
    d (h n) / Real.rpow (h n) q)
  atTop (𝓝 0)
```

The coefficients need not be nonnegative; arbitrary fixed real coefficients
work. Each varying exponent sequence is unrestricted at finite indices and
only required to converge to its strict-gap limit. No bound placing its terms
inside the exponent cube is used.

The proof locally establishes the varying-exponent ratio lemma by fixing half
the limiting gap, bounding the ratio between zero and `h^gap` eventually, and
squeezing. It then takes fixed scalar multiples, sums over the finite type,
and composes the `LittleO` limit with `h`.

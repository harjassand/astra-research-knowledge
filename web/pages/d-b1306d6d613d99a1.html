Cost and evidence accounting

The stochastic proof object assumes the reaction/polytope/collar certificate,
graph and initial counts are supplied or acquired. Reading a listed mesh and
initial count state is O(N_h+|E_h|+N_h d); checking all initial facet gaps is
O(N_h m d). Count memory is O(d N_h log(1+V_h R)) bits; graph storage and
controller state are extra. The exit certificate itself does not execute the
O(V_h T h^(-p-2)) event envelope. The deterministic continuum limit uses no
stochastic event simulation, but does require uniform discrete-energy and
time-compactness bounds.

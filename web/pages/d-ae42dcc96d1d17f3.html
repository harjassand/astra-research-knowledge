C03_L02 INITIAL CHECKPOINT — fermionic transfer of V rare-herald PP collapse
Date: 2026-10-07. Independent initial-phase result; candidate source claims remain unreviewed.

STRONGEST CLAIM
The rare-herald loss filter has a direct fermionic analogue, and the V two-rail readout can be repaired by retaining all R fermion rails. But the literal V transfer into the hard fermionic-parity interface fails exactly at its central compressor: the bosonic bunching amplitude sqrt(R!)/R^(R/2) is replaced by a fermionic determinant with repeated rows, hence is zero for every R>1. The obvious no-bunching repair retains a constant PostBQP readout gap, but it does not supply the missing quantum-computation embedding. The direct source construction—independent heralded fermion pairs followed by passive one-particle transformations—stays in the known bipartite Slater/DPP subclass; passive fermionic linear optics plus particle measurements/postselection is classically simulable (Knill). Thus no PP-collapse transfer is established. This is a formal obstruction to the direct KLM/bunching route, not a no-go for all uses of non-Gaussian hard parity projection.

1. EXACT FAILURE OF THE V TWO-MODE BUNCHER
V's proof chooses R a power of four and feeds |1,...,1> through a balanced R-mode interferometer whose first row is constant 1/sqrt(R), then postselects every other output port to vacuum. For bosons the amplitude to end in |R,0,...,0> is alpha_R=sqrt(R!)/R^(R/2), so the probability is R!/R^R >= R^(-R). Applying this separately to the logical 0 and 1 rail groups produces the two retained states |R,0> and |0,R>, preserving the encoded PP acceptance weight.

For fermions, if the R input orbitals are distinct and U is the one-particle interferometer, the R-particle representation is the exterior power wedge^R U. The coefficient for any valid output set J of R distinct modes is det U[J,[R]]. The proposed output “all R fermions in the first port” is not a valid Fock occupation for R>1: (c_0^dagger)^R=0. In the determinant expression its putative minor repeats the first row R times, so its determinant is exactly zero. The V lower bound R!/R^R is therefore replaced by 0, not by a small perturbation. With two spin states, hard onsite parity t=0 still permits at most one fermion per site; two retained sites hold at most two, while V has R>=100. The proposed herald event itself has zero probability in that interface. This is a universal algebraic identity, not a finite numerical concern.

An exact diagnostic is in fermion_transfer_checks.py / fermion_transfer_checks.json. It evaluates repeated-row determinants for R=2,4,8 (all zero), beside the nonzero bosonic probabilities, using exact integer/Fraction arithmetic.

2. A LEGAL READOUT REPAIR, BUT NOT A PP REDUCTION
Bunching is avoidable for the measurement layer alone. Encode the logical branches as
 |0_L> = product_(j=1)^R c†_(0,j)|vac>,   |1_L> = product_(j=1)^R c†_(1,j)|vac>,
using two disjoint sets of R fermion modes. Keep all 2R output modes. Under independent loss eta=1/R, the occupied set has Binomial(R,1/R) surviving fermions. Decode the logical value from the rail set containing any survivor, and flip a fair coin if no fermion survives. For an ideal branch mixture with decision probability p_x this yields
 Pr[1] = 1/2 + a_R(p_x-1/2),   a_R=1-(1-1/R)^R >= 1-e^(-1).
Thus the PostBQP YES/NO gap is at least (1-e^(-1))/6 > 0.105, exactly as in V; the expected surviving count is R eta=1. The sampler output is an O(R)-bit occupation pattern, still polynomial in the instance size. The exact binomial calculation is included in the diagnostic.

This fixes only readout. The V KLM computation before readout still needs a valid gate embedding. It is not valid to replace photons by fermions and reuse the same controlled-sign/nonlinear-sign argument. Knill's primary analysis states that fermionic linear optics and particle measurements sit in the extended matchgate/FLO monoid and are efficiently simulable, in contrast with bosonic linear optics plus particle measurements. The inherited KLM universality theorem is specifically bosonic. The hard-parity model's t=0 projector is non-Gaussian and is an extra resource, so the FLO simulation result alone does not rule out a more elaborate construction that actively uses that projector; no such gate gadget or circuit-to-F map has been derived here.

3. FERMIONIC LOSS FILTER TRANSFERS (DERIVATION)
Let rho be a state on fermionic herald modes H and retained modes S. Let k in {0,1}^H be the detected binary pattern, h=|k|, and p0=Tr rho_(k,k)>0. Apply the number filter F_g=g^(N_H), normalize by Z_g=Tr(F_g rho F_g), then independent vacuum loss eta on H and condition on observing k. Fermionic occupation numbers are at most one. A pre-loss pattern compatible with the herald is exactly k+l, where l is a subset of the zero positions of k and records fermions lost from those modes. Different environment loss patterns are orthogonal and give positive conditional blocks. After factoring the ideal weight eta^h g^(2h)/Z_g, the unnormalized conditioned state is
  rho_(k,k) + sum_(nonempty l subset H\supp(k)) ((1-eta)g^2)^|l| sigma_l,
where each sigma_l is positive with trace Tr rho_(k+l,k+l) (any fermionic parity bookkeeping can be kept inside the normalized branch state). The sum of these block traces is at most one. If g^2<=1, the total bad trace b is at most g^2. Normalizing gives a convex mixture with bad weight b/(p0+b), so trace distance from the ideal no-loss herald block rho_(k,k)/p0 is at most b/(p0+b)<=g^2/p0, independent of eta. This is sharper than V's 2g^2/p0 binary bosonic estimate because fermion modes have no binomial loss multiplicities. Also p_success >= eta^h g^(2h) p0/Z_g >= eta^h g^(2h) p0 when g<=1. The known lower bound on p0 remains essential; the filter never supplies the rare branch for free.

The argument applies to finite fermionic mode systems and exact number-resolving loss/herald outcomes. It does not assert a source compilation or a conditional sampler. The accompanying exact two-branch diagnostic checks the posterior bound on 18 rational parameter choices; it is evidence for the formula, not its proof.

4. EXACT EASY-SUBCLASS BOUNDARY FOR THE OBVIOUS SOURCE
A fermionic analogue of V's squeezed-pair source is an opposite-spin pair source with independent idler set A and signal set B. Passive one-particle evolution within the signal modes transforms its rectangular pair matrix M but does not mix the A/B role classes. The resulting pair matrix has support only A-to-B (or, with a symmetric site convention, across the bipartition). Every fixed-k coefficient is
  sum_(I subset A, J subset B, |I|=|J|=k) |det M[I,J]|^2 = e_k(M M*),
by Cauchy--Binet followed by the principal-minor formula for e_k. Equivalently, after conditioning on a specified idler configuration, the signal state is a Slater determinant. This is in the already-closed bipartite Slater/positive subclass in work/cycle4/hard_bcs_counting_attack.txt, where t=0 and all rational onsite filters 0<=t_i<=2 are admitted conditionally on the imported Chen–Liu/N63 algorithms. The hard I∩J=empty condition is automatic because the labels lie in disjoint role classes. The direct replacement therefore does not reach the unresolved non-bipartite parity counting target where hard projection does actual work.

To reach that hard class, a construction must use non-bipartite site overlap so up/down supports can intersect and the t=0 projector is active. V's independent herald/signal source plus signal-only passive evolution supplies no such overlaps. Coupling the roles or using the hard projector as an interaction may be a new route, but it must preserve the desired logical computation, the known pre-filter herald lower bound, the bit precision, and the final loss-readout gap. These are open gates here.

# Failed claims and continuation gates

## Demoted or unresolved claims

1. **“The printed \(2\sqrt{Dr}\) is the simulated front speed.”** Refuted for the released run's finite output. Full model has \(\phi=.5\) level OLS speed 21.735 \(\mu m/h\), while the scalar linear minimum is 1.849 \(\mu m/h\). The difference is consistent with the deliberately shallow initial tail plus the mechanical tissue-frame drift. This does not itself classify the full front.
2. **“The full tissue is proven to have a pulled Fisher front.”** Unsupported. The full PDE's homogeneous leading-edge linearization gives a KPP dispersion relation, but nonlinear feedback and force-mediated advection may change nonlinear selection. Tail shape and roughness are not enough to decide pulled versus pushed for nature.
3. **“Eq. 32 is the correct parameter inversion.”** Refuted by direct algebra, sign, and units. The printed alpha can still be used as a code input; an independent parameter refit is required to repair its provenance.
4. **“The 0.03728 notebook residual is a profile shape error.”** Refuted by active code. It is an absolute signed-mass difference. The L1 recheck has a larger numerical value, although it picks the same shift here.
5. **“The table alpha is definitely misconverted.”** Unresolved. The table omits units, and code may use an internal-stress fitted parameter. Conditional physical-Pa interpretation changes the replay, but does not prove which convention authors intended.
6. **“The BAPN area increase validates the alpha/speed prediction.”** Unsupported. It is a qualitative endpoint response to a broad collagen-crosslinking intervention; no matched BAPN speed trajectory or BAPN-parameterized numerical prediction is reported.
7. **“Agreement of full solver output and measurements is held-out validation.”** Unsupported. The article describes fitting alpha from expansion velocities/reporter profiles, and SI Table S1 points to Eq. 32. No independent front-speed condition split is documented.

## Gates for a stronger mechanistic claim

1. **Resolve parameter provenance.** Get the intended units of \(\alpha\), the exact fit objective, and the front/cell velocity estimands. Recompute \(\alpha\) using the corrected KPP factor and a valid model-specific speed relation.
2. **Acquire initial and moving-frame states.** Measure the live \(\phi\)-tail exponent, local \(\rho\), the \(\phi=.5\) trajectory, and material-frame tissue velocity in the same region. Spatial resolution must resolve the threshold length (~16.2 \(\mu m\) under the notebook numeric convention); the published solver uses 15 \(\mu m\) grid spacing, too coarse to robustly resolve that transition.
3. **Separate fit from prediction.** Fix \(D,\Delta k,q\), and tissue drift from independent observations; fit alpha on one condition; predict a second measured stiffness-gradient condition, including both front speed and profile.
4. **Test pulled versus pushed.** Change initial tail steepness while independently measuring or constraining stiffness and tissue flow. After subtracting the measured frame drift, compare steep-tail speed to the directly measured linear spreading rate. Persistent excess speed supports nonlinear bulk/mechanical pushing; agreement under steep initial data supports a pulled scalar-like front.
5. **Make BAPN quantitative.** Measure BAPN's spatial Young's-modulus and collagen fields, front speed over time, reporter profile, and bone area. Map those fields into the PDE without refitting alpha and compare with an equally informed advection-only or fitted-growth control.

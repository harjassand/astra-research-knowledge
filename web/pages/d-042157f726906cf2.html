1. Exact target and why this is only a candidate

The exploratory target is the rational Extended Polynomial Calculus with square-root rule, Ext-PC^sqrt_Q, on an explicit family of integer polynomial systems. A refutation derives a nonzero constant from the input equations using linear combination, multiplication by variables, square root (from R^2 derive R), and acyclic extension definitions y_i-Q_i(x,y_<i)=0. Proof size counts coefficient bit lengths and line size. Alekseev’s current journal version says this system p-simulates Extended Frege, but also explicitly says the Binary Value Principle (BVP) input is not the translation of a CNF and its lower bound does not imply a lower bound for a logical proof system. The distinction is material here.

For n≥1, define H_n over Q with variables x_0,…,x_{n-1}, w_0,…,w_{n-1}, z and equations

  B_i := x_i^2-x_i = 0                                      (0≤i<n),
  W_0 := w_0-1 = 0,
  W_i := w_i-2w_{i-1} = 0                                  (1≤i<n),
  Z := z-1-Σ_{i=0}^{n-1} w_i x_i = 0,
  T := z = 0.

Every coefficient is in {−2,−1,0,1}, every equation has degree at most two, the number of variables is 2n+1, and the total number of monomial occurrences is O(n). Its encoding length is O(n) if variable tokens are unit-cost, and O(n log n) if indexed variable names are written in binary. The equations B and W force x_i∈{0,1} and w_i=2^i; then Z and T force both z=1+Σ2^i x_i≥1 and z=0. So H_n is unsatisfiable.

This is a recurrence-coded BVP: it replaces the binary-encoded coefficients 2^i in BVP_n by n constant-coefficient recurrence equations. It is not a propositional CNF tautology. It is a precise algebraic unsatisfiable system for the strong algebraic proof system above. It is a candidate succinct instance, not a claimed new proof-complexity breakthrough.

2. Prime-spectrum invariant and rule-by-rule proof

For an integer system Γ={F_1,…,F_m} and an integer target polynomial q, define its prime spectrum

  P(Γ,q) := {p prime : there exists a∈Z^r with F_j(a)=0 for every j
                         and p divides q(a)}.

For H_n take Γ_n={B_i,W_i,Z} and q=z. Then

  P(Γ_n,z) = {p prime : p≤2^n}.

Indeed, if p≤2^n, write k=p−1 in n-bit binary as k=Σ2^i b_i. The integer assignment x_i=b_i, w_i=2^i, z=p satisfies every equation in Γ_n and has q(a)=p. Conversely q(a) is an integer in {1,…,2^n} on every Γ_n-solution, so no prime larger than 2^n can divide it. For n≥2 the endpoint 2^n is composite; writing the spectrum with ≤ also handles n=1 correctly.

Lemma (prime-spectrum divisibility). Let π be an Ext-PC^sqrt_Z refutation from Γ∪{q=0}, with terminal nonzero constant M. Then every p∈P(Γ,q) divides M.

Proof. Fix p∈P(Γ,q) and a witnessing integer assignment a. For every extension definition y_i=Q_i(x,y_1,…,y_{i−1}), evaluate y_i recursively at a. Because Q_i has integer coefficients and all earlier values are integers, every extension value c_i is an integer, and each extension axiom y_i−Q_i evaluates to 0. Under this lifted assignment, every original F_j evaluates to 0 and q evaluates to a multiple of p. Hence every input line evaluates to a multiple of p.

Induct on proof lines. An integer linear combination αR+βS preserves divisibility by p. Multiplication by any original or extension variable multiplies by an integer, so it preserves divisibility by p. If a line R is obtained from R^2, the parent’s value is divisible by p; since p is prime, p|R(a)^2 implies p|R(a). This covers every inference rule, including the square-root rule. The terminal line is the constant M, so p|M. Since the argument applies independently to every p in the spectrum and distinct primes are coprime, their product divides M. ∎

Applying the lemma to H_n shows that every integral Ext-PC^sqrt refutation has terminal coefficient divisible by Π_{p≤2^n}p. By the prime number theorem, the bit length of this product is Θ(2^n). The proof therefore has size Ω(2^n).

For rational proofs, the denominator-clearing transfer in Alekseev’s Theorem 3.4 applies: the input equations are integer polynomials and the final line is a constant with no extension variables. The transfer gives an integer derivation whose final constant is the original rational constant multiplied by products of denominators from proof lines and rational inference coefficients. The logarithms of these multipliers are O(S) for a rational proof of bit size S. For n≥2, the integer terminal constant must contain every prime below 2^n, so S=Ω(2^n). This is an application of the published integerization theorem, not a new proof of that theorem.

Thus the candidate conclusion is: every Ext-PC^sqrt_Q refutation of H_n has bit size 2^{Ω(n)}, despite H_n having O(n) monomial occurrences (and O(n log n) bits with binary variable indices). This remains superpolynomial in either explicit encoding. It is an algebraic-system lower bound on a succinct recurrence presentation. It does not give a lower bound for Frege or Extended Frege because H_n is not a standard propositional input encoding and no proof-preserving reduction to a CNF tautology has been supplied.

3. Degree versus proof size; substitution and extension behavior

The same family has a short degree upper bound. Put q_n(x)=1+Σ2^i x_i. The recurrence equations derive w_i−2^i=0 by induction using only degree-one lines. Multiplying these equations by x_i and combining them with Z derives z−q_n(x)=0 at degree at most two. From T derive q_n(x)=0.

Define the Boolean-cube indicator

  δ_b(x)=Π_{i:b_i=1}x_i Π_{i:b_i=0}(1−x_i),
  h_n(x)=Σ_{b∈{0,1}^n} δ_b(x)/(1+Σ_i 2^i b_i).

For every Boolean assignment b, q_n(b)h_n(b)=1. Hence q_nh_n−1 vanishes on {0,1}^n. The vanishing ideal of the Boolean cube is generated by x_i^2−x_i, so q_nh_n−1=Σ_i g_i(x)(x_i^2−x_i), with deg(g_i)+2≤n+1. Expanding this identity gives a PC derivation of degree at most n+1; multiply q_n=0 by h_n and combine with q_nh_n=1 to obtain 1=0. Therefore H_n has Ext-PC^sqrt_Q degree O(n) while every proof has bit size 2^{Ω(n)}. This is an explicit degree/bit-size separation for this equation family; the interpolating polynomial h_n is generally exponentially large, consistent with the size lower bound.

Extension stability is exact for integer definitions. If a witness assignment a is extended by any finite acyclic integer-polynomial definitions, each new variable gets a unique integer value and q(a) is unchanged. Thus P(Γ,q) is preserved by adding legitimate definitional extension variables. In particular, naming z or the recurrence outputs cannot erase the prime spectrum. Rational extensions are handled only after charging the denominators through the integerization step.

Substitution stability requires a condition and is not unconditional. An integer-polynomial substitution pulls a witness assignment back to an integer witness whenever its image contains that witness. If the substitution is surjective on the witness assignments that realize the prime spectrum, those primes persist. Arbitrary substitutions can destroy the invariant: substituting x_i=0 in q_n=1+Σ2^i x_i leaves q=1, with empty prime spectrum. Therefore this is a functorial witness invariant under witness-preserving substitutions, not a scalar measure invariant under all substitutions.

4. Finite diagnostics requested by the task

The following code exhaustively computes the target spectrum for small n, the odd-charge triangle Tseitin residual spectrum after deleting one vertex equation, and a PHP relaxation spectrum. It is reproduced here so the finite check is transparent.

```python
from itertools import product

def primes_leq(N):
    return [p for p in range(2, N + 1)
            if all(p % d for d in range(2, int(p**0.5) + 1))]

def bvp_spectrum(n):
    values = [1 + k for k in range(2**n)]
    ps = [p for p in primes_leq(2**n)
          if any(v % p == 0 for v in values)]
    primorial = 1
    for p in ps:
        primorial *= p
    return ps, primorial.bit_length()

def tseitin_triangle_residuals():
    # Edges e01,e12,e20 are signs. Charges are (1,0,0), total charge odd.
    charges = (1, 0, 0)
    residuals = set()
    for e01, e12, e20 in product((-1, 1), repeat=3):
        vp = (e01*e20, e01*e12, e12*e20)
        if vp[1] == (-1)**charges[1] and vp[2] == (-1)**charges[2]:
            residuals.add(vp[0] - (-1)**charges[0])
    return sorted(residuals)

def php_relaxed_spectrum(n):
    # n pigeons, n-1 holes; every pigeon chooses one hole; all holes
    # except hole 0 have capacity one. Target q=occupancy(hole 0)-1.
    holes = n - 1
    qs = set()
    for assignment in product(range(holes), repeat=n):
        if any(assignment.count(h) > 1 for h in range(1, holes)):
            continue
        qs.add(assignment.count(0) - 1)
    ps = sorted({p for q in qs for p in primes_leq(abs(q))})
    primorial = 1
    for p in ps:
        primorial *= p
    return sorted(qs), ps, primorial.bit_length()

for n in range(1, 9):
    ps, bits = bvp_spectrum(n)
    print("BVP", n, len(ps), bits)
print("triangle residuals", tseitin_triangle_residuals())
for n in range(3, 7):
    print("PHP relaxation", n, php_relaxed_spectrum(n))
```

Tseitin diagnostic. Let G be a triangle with integer edge variables constrained by s_e²−1=0, and impose at each vertex v the equation Π_{e∋v}s_e−(−1)^{b_v}=0, for charges b=(1,0,0). Multiplying all three equations gives 1=−1, so the full system is unsatisfiable. If the v=0 equation is the target q=0 and the other two are the base equations, the residual q is exactly 2 on all satisfying integer assignments of the base equations. Thus P={2}; the invariant forces one factor of 2 and gives only a constant-bit lower bound. For an arbitrary connected graph with odd total charge the analogous deleted-vertex residual is ±2, so this scalar spectrum still sees only p=2. It does not reproduce known Tseitin degree or size lower bounds.

PHP diagnostic. For n pigeons and n−1 holes, take Boolean x_{ij} with explicit equations x_{ij}²−x_{ij}=0, exact-one row equations Σ_jx_{ij}−1=0, pairwise collision equations x_{ij}x_{kj}=0 for every non-special hole j≠0, and target q=Σ_i x_{i0}−1=0. The base equations admit assignments with q=r−1 for each r=2,…,n: put r pigeons in hole 0 and inject the remaining n−r pigeons into distinct non-special holes. Therefore P={p prime:p≤n−1}. Its primorial has Θ(n) bits, while the input has Θ(n^3) monomials, so the invariant yields no superpolynomial-in-input bound. This is a deliberately relaxed PHP algebraic system, not the standard CNF PHP tautology. In the standard encoding with all holes constrained, the base system has no integer witnesses and the prime spectrum is empty. The invariant does not capture the known PHP hardness.

No interpolation argument is used here; the algebraic target does not furnish the required propositional interpolation instance. The prime-spectrum property also is not a Razborov–Rudich natural property of Boolean functions, so the natural-proofs barrier is not the relevant obstruction. The real limitation is encoding: bit-blasting an integer output into Boolean output bits reduces a target output to 0/1 values, whose prime spectrum is at most {2}; no proof-preserving bridge back to the scalar q-spectrum was found.

Small global-composition lemma from the current Krajíček reduction. Fix p, n, d with 2≤d≤n/2. Let rho be uniform over partial injections of size n−2d from [n+1] to [n], so D^rho has 2d+1 unmatched pigeons and R^rho has 2d unmatched holes. Let each rho have a nonempty design family Des(n,d)^rho as in that paper. For a complete p-ary decision tree of height e, each leaf P carries a fixed output label (i_P,j_P), and a leaf is consistent for rho iff some design L in Des(n,d)^rho follows its queried answers. Then

  Pr_{rho,P}[P is consistent and (i_P,j_P)∉D^rho×R^rho]
     ≥ p^(−e) − ((2d+1)/(n+1))(2d/n).                 (★)

Here P is a uniformly random leaf, independent of rho. For every fixed rho, any design L follows one leaf, so at least one of p^e leaves is consistent; hence Pr[P consistent]≥p^(−e). For any fixed leaf label, the unmatched pigeon set and unmatched hole set are uniform subsets of their respective sizes, independently (each pair of subsets has the same number of bijections between complements). Thus that fixed pair is in D^rho×R^rho with probability q=((2d+1)/(n+1))(2d/n), and averaging over P preserves q. Subtracting gives (★). The condition “consistent” is exactly the paper’s 1∉Span(W(P)^rho) condition.

For e=0 this gives 1−q; for e=1 it gives 1/p−q. It is a valid rule-free lower bound on the requested error event for very shallow trees. It becomes vacuous once e≥log_p(1/q)≈2log_p(n/d). The target in Krajíček’s reduction has e=O(d log n) with d=(log k)^{O(ell)}, far beyond this threshold for the superpolynomial k of interest. This does not close the current open search-tree bound.

6. Failure modes and exact remaining gate

The prime-spectrum invariant is compositional through polynomial calculus rules and legitimate extensions, but it inherits its strength from a large integer image under a chosen integer lift. It is not stable under arbitrary substitutions; it gives only p=2 for standard odd-charge Tseitin residuals and only Θ(n) prime-product bits on the relaxed PHP diagnostic; over the standard Boolean CNF encoding its scalar range disappears. It is a known divisibility method in a new succinct presentation, not a demonstrated new mechanism beyond the frontier.

The exact unresolved inference toward the assigned objective is a lower bound on the global search-tree event in Krajíček’s Theorem 6.1 for e≈d log n and d≈(log k)^{O(ell)}, or another proof-system invariant that survives the full extension/simulation interface while retaining superpolynomial strength on a standard propositional tautology. The shallow estimate (★), local degree designs, and the H_n algebraic encoding do not prove that. No new Frege/EF lower bound, priority claim, or discovery claim is made.

1. RESERVOIR-REALIZATION CLAIM: SCOPE RESTRICTED

For a trace x_i(t), the inferred residual r_i(t)=ẋ_i+ℓ_i-b_i and stock

    R_i(t)=R_i(0)-∫_0^t r_i(s)ds,
    R_i(0)≥max(0,sup_{0≤t≤T}∫_0^t r_i(s)ds)

give an exact atom-label-preserving decomposition only in a phenomenological class allowing independently prescribed, time-dependent exchange fluxes r_i^+(t)=max(r_i,0) and r_i^-(t)=max(-r_i,0). The stock is finite for an integrable trace on a finite interval, but this construction provides no autonomous rate law, reaction mechanism, concentration dependence, or indefinite maintenance. It encodes the trace in an external schedule/controller. Any earlier implication that it constructs an abiotic autonomous chemical network for every absolutely continuous trace is withdrawn.

This limitation is structural: finite autonomous mass-action networks have polynomial vector fields and analytic solutions on intervals of existence. Arbitrary absolutely continuous traces need not be analytic. Thus the free-flux construction cannot prove an all-AC-traces autonomous-CRN theorem. A new result in that direction would need an explicit finite autonomous clock/reservoir, its reaction network, initial state, approximation error and resource bounds; none is supplied here.

2. REPLACEMENT PHYSICAL OVERLAP: FIXED-LAW, INPUT-DRIVEN, FINITE WINDOW

A narrower exact overlap avoids the trace-programming defect. Suppose stellar forcing has fixed spectral shape F_λ(t)=u(t)F^0_λ, with nonnegative scalar amplitude u(t). In a stated unsaturated linear-light biological regime, let photosynthetic O2 production be η_Bu(t). In a stated abiotic regime with fixed water activity/optical depth and adequate vertical replenishment, let water-photolysis O2 production be η_Au(t). Let both models have the same first-order O2 loss λx and same initial x. For η_A=η_B=η, both obey the same fixed-law equation

    ẋ=ηu(t)-λx,
    x(t)=e^{-λt}x(0)+η∫_0^t e^{-λ(t-s)}u(s)ds.

Over a finite interval T, the water route requires at least

    W=2η∫_0^T u(s)ds H2O molecules,
    H_esc=4η∫_0^T u(s)ds escaping H atoms,

to leave the produced O2 as net oxidizing product, and requires vertical water supply of at least 2ηu(t) at each time in the stipulated regime. Thus this is a finite-resource, externally forced kinetic overlap, not an arbitrary hidden flux schedule. It is conditional on the gray-scaled forcing, fixed source efficiencies and shared loss law. The atmospheric O2 trace (and ideal no-fractionation O2 isotopologue trace from equal-source water) is identical; unmeasured H escape and organic-carbon/redox products may distinguish the mechanisms. There is no claim of overlap for non-gray flares, all atmospheres, all isotope fractionation kernels, or the complete planetary state.

For water-source oxygen with heavy atom fraction ρ and the ideal random-pairing/no-fractionation model, the common fractions are ((1-ρ)^2,2ρ(1-ρ),ρ^2). Real fractionation can separate particular models only when the independently bounded output sets do not overlap. The identity is a constructive counterexample to source identity from the selected outputs, not an empirical biosignature measurement.

3. FEASIBILITY CLAIM: STOICHIOMETRIC SYSTEM IS ONLY AN OUTER TEST

The exact abiotic object is the reachable-output set for an explicit kinetic catalogue, bounded parameters and reservoirs:

    R_A^T(u;Θ_A)={Hq(0:T): q̇=S_Av_A(q,u;θ)+b(t), θ∈Θ_A,
                         q(0)∈Q_0, q(t)∈Q}.

The observation error tube must be tested for intersection with this set. A time-binned balance/extent model such as

    q_{k+1}=q_k+S_Aξ_k+b_k,
    AS_A=0, 0≤q_k≤Q_max, 0≤ξ_k≤K_maxΔt,
    Eξ≤W, |Hq_k-y_k|≤ε_k

is generally a necessary outer relaxation, not sufficient kinetic reachability. Feasibility of it is inconclusive. Infeasibility excludes the stated abiotic catalogue only when it is a sound outer enclosure and the bounds and error set are valid. For exact linear systems, use the exact state-transition relation; for nonlinear or uncertain kinetics, use sound reachable-set enclosures or a global infeasibility certificate. A local optimizer's failure is not proof.

For a polyhedral model Gz≤g, Mz=d, an infeasibility certificate is λ≥0 and free μ such that

    Gᵀλ+Mᵀμ=0,
    gᵀλ+dᵀμ<0.

It proves infeasibility only for the stated constraints, catalogue, discretization/enclosure, reservoir bounds, kinetics and measurement-error set. Even then, biological attribution requires enough catalogue completeness to rule out omitted abiotic pathways.

The two-route O2 identity is likewise catalog-specific. With ξ_w from 2H2O→O2+4H_esc and ξ_c from 2CO2→O2+2CO, and corrected O2 sinks/boundary fluxes plus complete CO-equivalent accounting,

    ΔO2=ξ_w+ξ_c=H_esc/4+ΔCO_total/2.

If only atmospheric CO is observed, unknown ocean/rock storage breaks the test. With caps W,H,C,S and absorbed dissociation-event count P, the stated two-channel source satisfies

    O2_A≤min(P/2, min(W/2,H/4)+min(C/2,S/2)).

This is not a bound on every abiotic pathway; quantum yields, wavelength-dependent absorption, recombination and all sinks must enter a real application.

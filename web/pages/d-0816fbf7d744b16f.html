## Independent result

For the closed conversion pair
\(mA\to(m-1)A+B\), \(mB\to A+(m-1)B\), with fixed volume \(V\) and
predictable rates in \([\kappa,K]\), I derived an exact finite-volume return
certificate to \(J=A=L\). If
\[
\mu_V=V^{1-m}\{\kappa(V-L)_m-K(L)_m\}>0,
\]
then from any \(j<L\), uniformly over history-dependent controls,
\(\mathbb E_j\tau_L\le(L-j)/\mu_V\). The exponential tail is
\[
\Pr_j(\tau_L>t)\le
\min\{1,\exp(\theta_V(L-j)-\alpha_Vt)\},\qquad
\theta_V={\mu_V\over2V S_L},\quad
\alpha_V={\mu_V^2\over4V S_L},\quad
S_L=\kappa+K(L/V)^m.
\]
The symmetric right-boundary statement follows by exchanging species.

For any rational \(q<p=[1+(K/\kappa)^{1/m}]^{-1}\), the exact rational buffer
\(\eta=f(q)/(2m(\kappa+K))\), \(f(x)=\kappa(1-x)^m-Kx^m\), yields an
effective even-volume threshold \(V_0\). Above it, \(\mu_V/V\ge\delta=f(q+\eta)>0\),
so the expected return is bounded by \(q/\delta\), independent of volume;
the return-tail exponent grows linearly in \(V\). The proof is based on a
stopped positive-drift estimate and a killed exponential supermartingale, so
it covers predictable controls. Exact rational fixtures at \(V=64,128,256\)
check the drift floors and the lower-extremal backward Poisson equations.

## Charged limitation

For \(M=2^b\), \(\kappa=1,K=M^2,q=M/(M+1)^2\), the rate and rational-threshold
inputs have \(O(b)\) bits while \(p-q=(M+1)^{-2}\). Here
\(f(q)=(2M^3+3M^2+2M+1)/(M+1)^4\), hence the certificate's sufficient
even-volume floor is \(V_0\sim2M^3=2^{3b+1}\). The exact sharp exit exponent
\(2D(q\Vert p)\sim M^{-3}\) also has no input-independent positive
coefficient per unit volume. This is margin dependence in the certificate and
the cited exact exit bound, not a necessary-volume bound or an algorithmic
hardness result. For fixed rate data, certificate computation uses exact
rational arithmetic on integers with bit length linear in \(\log V\) for
fixed \(m\); the closed-form sufficient threshold can nevertheless be
exponential in input bit length. The static exact-mean sum has no tight
common-denominator bit bound here, so it is diagnostic only.

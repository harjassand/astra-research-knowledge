## Combinatorial contracts: the single cost query is consequential

Xiaotie Deng, Hanyu Li and Chenghua Liu, *Approximating Combinatorial Contracts with Arbitrary Costs*, **2609.35803v1**, submitted **18 September2026**. Recoverable ABS/PDF/source are pinned. Read the main exact-real access/theorem statements, response monotonicity, complete welfare lemma proof, reward-anchor/grid argument (main sections3–4; source140–226,387–615). The theorem explicitly uses one exact **cost-value** query as well as best-response/supply and reward queries. No hidden omission is alleged. The proof's first-appearance epochs give (OPT\le W\le nOPT\) for normalized monotone subadditive rewards and arbitrary nonnegative normalized costs; reading this resolved the initially suspected welfare-scale obstruction.

A useful exact boundary follows independently. Even one action with known reward1 has arbitrary cost (1-\delta\), (0<\delta<1\). Its best response is empty below contract (\alpha=1-\delta\), and the action above that threshold; the optimal principal utility is delta. Any deterministic procedure making only finitely many exact best-response/supply-price queries, with no cost-value access, sees the same answers for all sufficiently small positive delta: prices below1 return empty, prices at or above1 return the action. On that common response path its final contract is fixed. If it is below1, choose delta smaller than its retained share; the action is not induced and utility is zero. If it is1, utility is again zero. This rejects a relative-approximation guarantee from response access alone, regardless of how finely the finite query points were chosen. It does **not** refute the source theorem, whose exact cost query reveals the missing scale.

The source counts exact-real oracle calls, not bit operations. Computing (W=f(T)-c(T)\) can demand arbitrarily fine answer precision when W is tiny. Its query guarantee is useful at its stated exact-access interface; it is not automatically a bit-polynomial acquired-oracle algorithm. This is a parked acquisition lesson, not a completed new research programme or novelty claim.

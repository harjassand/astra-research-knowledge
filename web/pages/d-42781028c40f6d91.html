COHERENT SINGLE-SHOT MEMORY — FROZEN CORRECTIONS AND AUDIT RECONCILIATION
9 October 2026. Append-only v2; v1 remains unchanged.

This version supersedes the CSS contraction and AKP conversion constants in v1.
It also states the coherent-controller argument in a representation that does
not assume nonlinear Boolean gates preserve Pauli errors. The theorem in v1
remains the candidate theorem with the corrected constants below. Independent
audits support its algebra and encoded-input good-path quantifier. They are
internal examinations, not external verification or novelty validation.

1. CSS FACTOR TWO (SUBSTANTIVE CORRECTION)

Let alpha0 be the contraction constant of each SOURCE X/Z decoder. Choose a
fixed number of QTC parallel iterations so alpha0<1/2, and put alpha=2 alpha0<1.
Keep r=the TOTAL stabilizer-reduced Pauli weight used by v1 (not the sum of
separately minimized component weights). If e has a representative X(x)Z(z) of
weight r, then |x|_red<=r and |z|_red<=r, so |x|_red+|z|_red<=2r. Consequently

 |e+f_X+f_Z|_red <= alpha0(|x|_red+|z|_red)+beta(|D_X|_V+|D_Z|_V)
                    <= alpha r+beta |D|_V,

where beta is the maximum component beta and |D|_V denotes the summed component
syndrome support. a_ext,b_ext include both extraction blocks and b_ext bounds
this sum. A,B,h can be safely chosen to satisfy both component premises whenever
A r+B |D|_V<=h n. Hence all v1 equations (3)-(21) hold with effective alpha=2alpha0.
The sentence in v1 Section1 asserting 'the same alpha' from component weights
<=r was incorrect. For the logical CNOT extension in v3, choose alpha0<1/4 so
this effective alpha is below 1/2.

2. AKP HAMILTONIAN CONSTANT (SUBSTANTIVE SOURCE CORRECTION)

The correct constant in AKP arXiv:quant-ph/0510231v1, Eq22 and Eq24, is

  C_A=exp(1+1/(2e)),  eta_noise=C_A sqrt(2 mu),

not exp(1-1/(2e)) as written in v1 and imported from A04's initial source audit.
The primary published PDF also prints the plus sign at Eq24, page4; live web
text lines364-367 of https://preskill.caltech.edu/pubs/preskill-2006-long-range.pdf
were checked. Thus v1 Section7's sufficient row-norm bound must use

  mu <= eta0^2/[2 exp(2+1/e)],  eta0=tau/(e^3 N0).

Positivity and all asymptotic memory conclusions survive. The numerical cutoff
is smaller. No empirical calibration claim is attached to this source result.

3. EXACT COHERENT CONTROLLER/BATH REPRESENTATION

Use a chronological fault history, retaining all readout/reset purifiers. For
each fixed local reversible truth-table block, pull faults in its fixed-size
implementation through the remaining ideal block to the block output. This
becomes an arbitrary operator on those fixed SYSTEM wires and the bath. If
faults interleave in distinct blocks sharing a bath, use a joint coefficient on
the union of their marked system supports. DO NOT factor or commute bath
operators. Support locality is the support-respecting fault clause, not bath
tensorization.

Expand controller operators in matrix units |a><b|, and data operators in Paulis.
On a basis controller input, a matrix unit either kills the term or produces a
definite new basis value times a bath operator. An ideal Boolean reversible
macro maps basis strings to basis strings; its induced action maps matrix units
to matrix units. Follow a basis transition through all macros, carrying all bath
coefficients in their original time order. Fixed-size fault blocks alter only a
constant number of controller bits, and their subsequent output changes remain
within the union of bounded fanout cones. A basis-controlled X/Z correction then
applies a definite data Pauli. Faults acting jointly on data and controller use
Pauli_data tensor matrix-unit_controller tensor bath-operator expansions.

Each fully expanded term therefore has: (i) a data Pauli Q, (ii) definite
syndrome/record/garbage strings, and (iii) an ordered bath coefficient. The
coefficient may be jointly correlated across many marked sites. These terms are
not assigned probabilities and their coefficient norms are never added.
The input logical vector enters only through Q Enc|psi>. v1's deterministic
recurrence bounds the stabilizer-reduced weight of THIS cumulative Q, relative
to the initially encoded state, by rho n<d/2. Thus Q Enc=phase R_s Enc, and its
good sum has the encoded-input form I_L tensor g after ideal final decoding.

4. LOGICAL-HOLONOMY QUANTIFIER

The asserted identity is on Enc(H_L) tensor H_B, as v1 Eq8 explicitly states.
It is not inferred from a decoder that only outputs a small syndrome or a small
chosen representative. For round induction, the previous residual is counted
as a stabilizer-reduced Pauli relative to the original encoded input; every
new decoder application includes that residual in the source theorem's promise.

A23 supplies an exact counterexample to a different unqualified extension:
the [[5,1,3]] code with radius1 syndrome reps, input IZIII, fault IIXII, and
output rep IIIZI gives IIIZI*IIXII*IZIII=IZXZI, a weight3 logical operator. A
small input/output syndrome representative alone does not rule out logical
holonomy. This example does not satisfy the required final cumulative
stabilizer-reduced error promise and does not refute v1 Eq8. It explains why
that promise and the encoded-input quantifier are essential.

If one wants a uniform full-syndrome-domain round theorem, apply the recurrence
to every chosen input R_s and every controller basis transition, including R_s
in the new input error. Then the final Pauli Q R_s must itself be stabilizer-
reduced below d/2. That stronger quantifier must be proved, not assumed. The
global encoded-input theorem needs no such unqualified extension.

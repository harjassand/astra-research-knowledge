## Exact universal interface and proof

Use the previously independently gated degree-T centroid acquisition: q=600(T+1), N=720000(T+1)^2, h=1/[50(T+1)], delta=2^-24(T+1)^-8, I=20+10ceil(log2(T+1)). Its normalized mean functional B_X has gradient-dual norm epsilon_G(X), and the admitted initializer satisfies epsilon_G<=E0=6Th². At iteration k define the computable rational envelope

    E_k = 4^-k E0+(8/3)delta.

The admission promise includes the actual certified centroid construction and the complete preceding legal motion history; a q field by itself is not a certificate. The sampling proof then provides full derivative rank and, along every admitted path, the gradient/Hessian bounds in the original box theorem. E_k<=1/(256T).

Given current exact rational unit points and rational harmonic basis, assemble the original averaged moment mu and tangent derivative J. Compute the unique minimum-Euclidean correction

    lambda=(JJ^t)^(-1)(-mu), v=J^t lambda.

Use exact rational arithmetic. Verify Jv=-mu and v=J^t lambda. Tangency follows from the tangent derivative columns and is checked directly. For every feasible alternative v+z, Jz=0, hence v dot z=0 and ||v+z||²=||v||²+||z||². This is an exact KKT/optimality certificate, not a numerical proposal acceptance.

Accept it precisely when

    max_i ||v_i||² <=16 E_k².                    (S1)

Otherwise call the established exact polynomial rational box oracle on the original problem

    minimize d, Jw=-mu, |w_(ia)|<=d, 0<=d<=1.

Require a feasible original primal and exact dual optimum certificate, then project each block tangentially. The original separation proof gives d<=2epsilon_G<=2E_k. Projection preserves Jw and max_i||v_i||<=sqrt(3)d<4E_k; the fallback therefore always satisfies (S1). No unknown universal maximum bound for the particular Euclidean pseudoinverse is assumed.

For either action put R=max_i||v_i||<=4E_k<1. The original neighborhood proof gives the Cayley remainder in gradient-dual norm at most R³/6+3TR². This is at most64T E_k²: the quadratic term is48T E_k² and the cubic term is(64/6)E_k³, smaller than the remaining16T E_k² under E_k<=1/(256T). The distinct rational reset adds2delta. Thus

    epsilon_G(next) <=64T E_k²+2delta
                     <=E_k/4+2delta=E_(k+1).     (S2)

The complete motion allocation from the true centroid is unchanged:

    delta+sum_(k<I)(4E_k+delta)<0.65h.

Every partial Cayley/reset path lies inside its allocated length, so the same neighborhood sampling and Gram>=13/19 remain valid. The source final mean proof and output height O(log(T+1)) are unchanged. This proves a universal adaptive theorem with the same source count and iteration bound, conditional on the same exact box primitive used by the original theorem.

The extra cost is explicitly charged: an O(NM²+M³) rational normal assembly/solve, O(NM) original-equation checks and O(N) block norm checks on every attempted Euclidean action, including rejected ones. Basis/input heights, differing-denominator sums and determinant/elimination bounds are polynomial in the original reset input. Exact actions can have much larger polynomial intermediate heights; the fixed next-state reset erases them. A failed Euclidean attempt cannot silently omit its arithmetic/certificate cost. The theorem remains polynomial; it does not improve its worst-case order, source count, iteration count or bit exponent.

## Finite globally certified admission outside the theorem regime

The actual existing T3,N32 input is outside the universal cardinality. We therefore use a different, directly checked local interface instead of attaching its q tag to (S1). It requires tangent exact cancellation, a supplied rational displacement cap r_cap<=1, a global Taylor/error certificate, and an exact resulting Gram>I/2 and unit/distinct reset.

Let e be the nonconstant orthonormal feature vector through T. The independently reconstructed addition-kernel constants are

    A²=T(T+1)²(T+2)/4,
    B²=T(T+1)²(T+2)[T(T+2)-1]/8.

Choose rational upper bounds Abar=(T+1)²/2 and Bbar=ceil(sqrt(B²)). In fixed-anchor tangent Cayley coordinates u the mixed Hessian is bounded by Bbar+(||u||/2)Abar. Exact first-order cancellation therefore gives

    ||mu_after_reset||
      <=U_action=[Bbar+(r_cap/2)Abar]
                         *(1/N)sum_i||v_i||²/2+Abar*delta. (S3)

The proof is vector Taylor along u=t v_i, followed by triangle inequality over the node average and the geodesic feature/reset bound. It uses average action energy as well as the maximum radius; no sampled Hessian is treated as a global bound. Test (S3) entirely rationally by requiring either

    U_action²<=||mu||²/16,  or U_action<=beta_T/8.

For rejected proposals with radius above r_cap we additionally report a valid Taylor bound using a dyadic upper bound on their actual radius, never a bound whose displacement premise failed. The independently reconstructed exact output mean must lie below U_action², and the exact output Gram is tested by integer principal minors. These output tests are acceptance conditions, not predictions from a numerical eigenvalue.

This finite mode may return no certified action on an arbitrary input. Its particular box fallback is not universally promised under a freely chosen r_cap. That is distinct from the universal mode's guaranteed4E_k cap. Our observed fallback has its own exact box optimum and (S3) certificates, so the adopted finite route is rigorous without a universal q=T+1 claim.

Acceptance has two stages. A pre-admitted Euclidean action is only a candidate until its reset output passes actual mean, Gram, unit and distinctness checks. A failure at either stage retains the candidate and tries the box action from the unchanged accepted input. A box action that also fails returns UNKNOWN. The current v3 implementation fixes a v2 control-flow gap in this post-certificate fallback; all frozen v2 outputs passed their post-certificates, so this correction does not alter their finite evidence or timing record. An optional transient-bit admission cap is a finite resource condition with no guaranteed universal fallback.

## Executable oracle and certificate contract

`work/handoff_sol_max_check/cycle12/adaptive_selector.py` contains both admission functions, a generic exact minimum-Euclidean routine, an exact primal/dual box acceptance routine, fixed-height distinct reset, and a complete matched finite runner. It imports only our independently built cycle11 sphere/verification helpers; no producer logic is imported or read.

The local box backend is deliberately separated from the theorem's polynomial exact oracle. HiGHS proposes a scaled numerical point. Its float.hex vector is converted to original exact binary rationals; original equality residuals and box margins are retained, and it is never accepted directly. An exact active system is reconstructed. If necessary, an exact full-rank block repair supplies a feasible starting point, a rational feasible edge walk reaches a vertex, and bounded exact primal-simplex pivots correct negative dual signs. Every attempted point and pivot is retained. Adoption requires original primal feasibility and nonnegative exact dual weights with stationarity, sum weights1 and objective equality. Any bounded numerical/vertex/pivot failure is returned as failure; it is not a worst-case algorithm theorem.

The backend's primal/dual certificates are sufficient for the correction independent of how the point was proposed. They do not establish polynomial runtime for the numerical proposer or primal simplex. A universal implementation must plug in the standard polynomial exact box primitive instead. The admission API and proof (S1)–(S2) already specify what that oracle must return, and the finite executed backend proves those obligations on the recorded actions.

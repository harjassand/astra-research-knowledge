## 1. Original continuous confidence law is preserved

Fix an arbitrary admitted true Q. Given the complete past and the chosen lag/current state, let p_Q(y) be its next endpoint law and let q(y)>0 be the exactly normalized, predictable numerator. The baseline graph is strongly connected, so p_Q(y)>0 at every positive lag even when b=0. Therefore

    E_Q[q(Y)/p_Q(Y) | past, chosen action] = Σ_y q(y) = 1.

The product M_k/L_k(Q) is a nonnegative mean-one martingale. Ville gives

    P_Q{there exists k with Q not in C_k} ≤ δ,
    C_k={Q:L_k(Q)≥δ M_k}.

This is a pointwise-in-true-Q probability statement for the full continuous class, simultaneous over time; there is no finite true-model grid and no union bound over candidate Q. Parameter-independent adaptive actions cancel conditionally. Arbitrary predictable lags and adaptive visits to rows are legal. Neither row counts nor selected lags are treated as independent binomial experiments.

Dirichlet(1,1,1) per lag/start-state cell has an ordered-sequence product determined by the final cell counts even when visits interleave. The historical all-endpoint counts, including final partial batches, therefore legitimately reconstruct that numerator. The retaining predictor uses weights derived from the PRECEDING block's fitted generator, held fixed during the next block, floored to positive integers and exactly normalized. Approximate fitting affects power, not validity. This gate does not justify choosing retrospectively between arbitrary competing numerators without accounting for selection; the retaining comparison uses its specified recursion and makes no new prospective coverage experiment claim.

For each visited row, with empirical H_xy=C_xy/N_x,

    log L_sat−log L(Q)=Σ_(lag,x) N_x KL(H_x || P_Q(t)_x).

All summands are nonnegative. The code's B=upper(log L_sat)−lower(log M)−lower(log δ) is an upper bound for the accepted set's available reverse-KL divergence. Retaining ALL rows/lags in B is essential even if one particular lag supplies no useful projection. Binary data processing gives each coordinate's necessary inequality N_x kl(H_xy||P_xy)≤B. The direction is empirical-to-candidate KL; reversing it would change the accepted set and invalidate this derivation.

Every later interval contains the projection of this same C_k. Intersecting across coordinates, rows, lags, old path bounds and either new matrix bound incurs no extra confidence spend. An empty interval is an empty-confidence-set diagnostic, not a physical impossibility claim or a protected point estimate.

## 2. Matrix-log identification is global on the supplied class

Since Q is a generator, ||Q||_∞=2 max_x(−Q_xx)≤2λ. The executable admits a lag to the logarithm stage only if 2λt<3. Thus every eigenvalue of tQ lies in the open strip |Im z|<3<π. On that strip the analytic identity Log(exp z)=z holds for the principal logarithm. Holomorphic functional calculus gives Log(exp(tQ))=tQ, including Jordan blocks; diagonalizability is unnecessary. This uses a GLOBAL class bound, not the fitted generator or an audit truth.

The independently acquired interval box gives r≥||P−I||_∞ for every admitted candidate. If r<1 then P is invertible, its spectrum lies in the disk centered at one of radius r, and the absolutely convergent logarithm series chooses the same principal branch. The matrix-log interval is therefore an interval for the original generator entry divided by t, rather than for some other embeddable generator. If r≥1 the lag is skipped, not forcibly inverted. If a row is unobserved, the full matrix bound is skipped; the old single-source path bound can still supply a legal interval.

The interval arithmetic is outward: every sum and product is rounded to 70 dyadic bits, multiplication considers all endpoint products, and signed scalar factors reverse endpoints where needed. Induction encloses every power (P−I)^k. The geometric majorant

    ||Σ_(k>K) (−1)^(k+1)(P−I)^k/k||_∞
       ≤ r^(K+1)/[(K+1)(1−r)]

is correct. Adding its rounded upper bound before dividing by positive t and rounding to 48 bits yields a valid outer interval. Dependency inflation widens an interval but cannot exclude a candidate. The fixed K=80 and fixed precision imply a tiny fixed numerical floor; the executable does not literally prove convergence to zero width as sample size tends to infinity without also increasing K/precision.

Sequential stochastic row-sum tightening is legal because each updated interval still contains every candidate stochastic row. The empirical H is itself contained in the initial and tightened boxes, so the whole line segment H+s(P−H) used by the next proof remains inside the same norm ball.

## 3. Shared reverse-KL dual and nonlinear remainder

For positive η and ν_x>max_y c_xy, maximize

    Σ_xy c_xy(P_xy−H_xy) − ηΣ_x N_x KL(H_x||P_x)
        + Σ_x ν_x(1−Σ_y P_xy)

over independent nonnegative coordinates. For H_xy>0, the stationary maximizer is ηN_x H_xy/(ν_x−c_xy); the scalar second derivative is negative. For H_xy=0 the supremum is zero at the boundary because c_xy−ν_x<0. Substitution and the row identity ΣH=1 produce exactly the author's upper bound

    ηB + Σ_x [ν_x−ηN_x−Σ_y c_xyH_xy
            +ηN_xΣ_y H_xy log(ηN_x/(ν_x−c_xy))].

Dropping row normalization during this separable maximization enlarges the feasible class. Any such dual parameters are valid, regardless of optimality or the floating search's accuracy. Applying the same calculation to −c gives the lower bound. All log terms have nonnegative multipliers ηN_xH_xy, so using outward upper logarithm endpoints is correct. The implementation rechecks ν_x>max c_xy exactly, replacing an invalid proposal with a rational strictly feasible one. A numerical search exception now safely skips the optional refinement.

For the finite polynomial T_K(A), differentiating A^k twice gives k(k−1) ordered terms before division by k. Hence

    ||D²T_K(A)[E,E]||_∞ ≤ ||E||_∞² Σ_(k=2)^K (k−1)r^(k−2)
                         ≤ ||E||_∞²/(1−r)².

Taylor's integral factor is 1/2, so the code's nonlinear radius e²/[2t(1−r)²] is valid. The interval-derived center is already enclosed. There is only one missing infinite-series tail, at the candidate P, because the center and differential both refer to the finite polynomial; the code charges that tail. If each differential coefficient has midpoint error at most d and each row of E has l1 norm at most e, the total linear rounding error is ≤n d e. Subtracting a constant from all coefficients of one row does not change their contraction with E because each row sums to zero. No factor is missing from the n d e charge.

The nonlinear bound is often too loose to help and makes no additional frozen case protected. Its failure to improve status is retained in the conclusion.

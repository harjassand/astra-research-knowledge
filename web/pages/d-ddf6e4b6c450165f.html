## Independently established countable-matrix lemma

Let B be countable and let `a,a' : N × B → F_2` be arbitrary. Choose an injective encoding `e:B→N` and put `d(n,b)=a(n,b)+a'(n,b)`. Define

`U_n={b:e(b)≤n and d(n,b)=1}`, and `V_b={n:n<e(b) and d(n,b)=1}`.

Injectivity makes `U_n` finite, with size at most n+1; `V_b` is a subset of a finite initial interval. Exactly one of `e(b)≤n` and `n<e(b)` holds. Therefore

`a'(n,b)+1[b∈U_n]+1[n∈V_b]=a(n,b)`.

This is a complete proof for arbitrary countable B, with no boundedness or regularity requirement on either matrix. It is the mechanism implemented by `Matrix.decompose` and `Matrix.normalize` in Arrays. Given equally sized index sorts and an order isomorphism between two countable dense base orders without endpoints, these row/column translations build the array isomorphism. `countable_isomorphic` in ArrayEmbeddings calls that normalization and the countable dense-order theorem; the tail argument first forces bases to be countable.

Twenty-eight finite matrix instances with nontrivial reversed encodings independently check the transcription. The deliberate replacement of `<` by `≤` in the column rule toggles the diagonal twice and fails. These finite checks supplement the universal proof just given; they do not certify the AEC or cardinal-partition arguments.

The countability interface is essential. For arbitrary B, row supports contribute only countably many exceptional columns (a countable union of finite sets), while every column translation changes only finitely many row entries. Hence outside that countable exception set, the eventual-equality class of each column is preserved. The uncountable-base construction can retain precisely these colors. This independently explains why a naive matrix-erasure shortcut would destroy the claimed endpoint mechanism.

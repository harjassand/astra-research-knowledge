# c09_l03 Final — conditional joint-posterior archive theorem

**Outcome:** constructed and audited a sufficient theorem for affine bounded-score families. It gives matching leading-order quantum lower and classical upper memory rates under an explicit joint-posterior regularity condition, and excludes the known equal-Fisher shared-scalar curve. The claim is conditional and internally derived; it is not a general Fisher-spectrum theorem, novelty clearance, or an end-to-end implementation result.

## Exact claim

Let `Z=(Z_1,...,Z_d):X→[-1,1]^d` be centered under a reference probability law `μ`. For known positive weights `s_i` with `||s||_2≤ρ<1`, define

`dP_v/dμ=1+sum_i s_i v_i Z_i`, for `||v||_2≤1`.

Assume every finite-coordinate score vector `Z_I` has a strictly positive `C^1` density on its cube and `max_i ||∂_i log g_I||_∞≤L`, uniformly in dimension and coordinate set. If `Eμ[Z_i Z_j]=σ_0² 1_{i=j}`, the Fisher matrix at zero is `σ_0² diag(s_i²)`.

For a one-observation archive whose parameter-blind encoder stores a classical/quantum hybrid state of total Hilbert dimension `D`, and whose single fixed decoder returns one `Y∈X` with `sup_v TV(Law_v(Y),P_v)≤ε`, the arbitrary-hybrid memory obeys, for every finite coordinate set `I`,

`ln D >= (1/2) sum_(i in I) ln(s_i/epsilon) - |I|(H+(1/2)ln(12 pi e))`,

where `H=max(0,2L-ln 2)`. In particular, with `K0=12 pi e exp(2H)` and `I={i:s_i≥K0 epsilon}`,

`ln D >= (1/2) sum_(i in I) ln(s_i/(K0 epsilon))`.

For `s_i=a exp(-bi)` and `||s||_2<1`, this gives `log_2 D >= ln²(a/epsilon)/(4b ln 2)-O_(a,b,L)(ln(1/epsilon))` when dimension reaches the active cutoff. Fixed smaller dimensions receive only the corresponding truncated partial-sum claim.

There is a positive finite-label classical codec with `log_2 D <= ln²(a/epsilon)/(4b ln 2)+O_(a,b,L)(ln(1/epsilon) ln ln(1/epsilon))` in the same large-d regime. It uses graded linear hats, independently randomized labels from the feature values, and a label-conditioned reference-law decoder `μ_j(dx)∝phi_j(Z(x)) μ(dx)`. The codec fixes `μ`; the uniform conditional-centroid bias is `O(J_i^-2)`, so retained score error is controlled in Euclidean norm and a geometric tail is dropped at norm at most `epsilon/4`.

The proof uses two separable joint-law properties: extensive lower bounds on `h(Z_I)`, and uniform `O(J^-2)` conditional hat-centroid error after all other feature labels. The coordinatewise joint log-gradient condition implies the entropy property and the centroid property; the audit derives the latter through covariance symmetrization, with valid constant `A=4+36e²L` for the codec. `INITIAL` retains the looser valid constant `4e+36e²L`.

## Converse and counterexample gate

For each coordinate, a uniform prior on `P_{+e_i},P_{-e_i}` has input mixture `μ` and posterior `E[T|X]=s_i Z_i(X)`. Uniform TV accuracy transfers first and second bounded moments, yielding reference-channel squared feature error `M_i=E[(Z_i(X)-Z_i(Y))²]≤6 epsilon/s_i`. The joint entropy lower bound and conditional Gaussian maximum-entropy inequality give a rate-distortion lower bound on `I(Z_I(X);Z_I(Y))`; data processing and Holevo bound it by `ln D`, even for hybrid memory. Shared independent randomness is handled by `I(Z_I;Q,R)=I(Z_I;Q|R)≤ln D`. No per-random-seed accuracy assumption is made.

Product-uniform scores `Z_i(x)=x_i` and the scalar curve `Z_i(t)=sqrt(2/3) cos(2 pi i t)` have the same covariance `(1/3)I`, hence identical Fisher matrices for the affine family. The curve’s every two-or-more-coordinate score law is supported on a `C^1` one-dimensional image, is singular with respect to cube Lebesgue measure, and fails the joint-density/entropy-thickness hypothesis. Thus the sufficient theorem excludes the equal-Fisher example for a structural reason: Fisher orthogonality does not constrain the joint posterior support. The condition allows dependence; a finite cyclic density proportional to `exp(lambda sum_i z_i² z_(i+1)²)` has uniformly bounded coordinate log-gradients, centered pairwise-uncorrelated coordinates, and a dimension-uniform positive coordinate variance for fixed `0<lambda<1`.

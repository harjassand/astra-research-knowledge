CORRECTION STATUS
=================

The earlier Cycle7 report incorrectly treated the simplex of marks as a
simplex of label coordinates. In the supplied construction, B is a set of
POINTS. The retained labels are their images under the perfect matching.
Consequently, the claimed retained origin labels [a,0,0,0,0] for all
1<=a<=s, the claim d_O=s, the derived origin block sizes, and every
"actual-origin" representation claim are withdrawn. The error is exposed
already at a=1. No conclusion about N65 nonsoficity follows from this repair.

1. EXACT SOURCE INTERFACE AND RETENTION CRITERION
================================================

The incidence equations are

  b-y=at,  c-z=bt,  d-w=ay,  e-v=az.

For a point mark m=(t,y,z,w,v), its matched line is the unique line with
first label coordinate a=t. Substitution gives the matching map

  lambda(m) = [t, y+t^2, z+t*y+t^3, w+t*y, v+t*z] in F_q^5.

The retained line set is lambda(B), where

  B = {m in Z_{>=0}^5 : |m|<=s},  s=(q-3)/2,

with the coordinates embedded in F_q. For each retained line, only its own
matched point is deleted. Thus, at any point z, an incident line is retained
exactly when its matched point belongs to B; the incidence is then deleted
only if z is that matched point.

At O=(0,0,0,0,0), the incident line of direction a is [a,0,0,0,0]. Its
matched point, obtained by setting the line parameter t=a, is

  m_a = (a, -a^2, 0, a^3, 0) in F_q^5.

For a=1 the canonical integer representatives are (1,q-1,0,1,0), with sum
q+1>s. Hence [1,0,0,0,0] is NOT a retained label. At a=0, O is the matched
point and that incidence is punctured. The actual origin degree is therefore
not s. An exact unevaluated expression is

  d_O = #{a in {0,...,s} : a + rep(-a^2) + rep(a^3) <= s} - 1,

where rep denotes the canonical representative in {0,...,q-1}. This cycle
does not evaluate that count or establish whether O is regular.

2. DIRECTION SETS VARY: THE ROOT'S GLOBAL SHORTCUT DOES NOT APPLY
================================================================

The direction-only shortcut proposed after Cycle7 assumed that every point
retains the same direction set. The exact matching geometry refutes that
premise. The mark m=(1,0,0,0,0) lies in B. Its matched line is

  lambda(m)=[1,1,1,0,0].

At P=(0,1,1,q-1,q-1), this line is incident: the four incidence equations
hold modulo q. Since P has parameter t=0 whereas the matched point has t=1,
this incidence is not the punctured matching edge and is retained. So
direction 1 occurs in the retained neighborhood of P.

At O, the line of direction 1 is instead [1,0,0,0,0], whose matched point
(1,q-1,0,1,0) is not in B. Thus direction 1 is absent at O and present at P.
The retained direction sets cannot be copied point-to-point, and the
proposed assignment using the same origin direction list and coordinates at
every point is not a legal construction. This does not rule out every global
assignment of coordinates or every possible finite representation.

For reference, at a general point z=(t,y,z_2,w,v), the matched point of its
incident line with direction a is

  (a, y+a*t-a^2,
      z_2+(y+a*t)*(t-a),
      w+a^2*(a-t),
      v+a*(y+a*t)*(a-t)) mod q.

The retained directions at z are those a in {0,...,s} for which the canonical
representatives of these five coordinates sum to at most s, with the
matching incidence removed when z itself is the matched point. This is the
correct interface for any new finite acquisition or degree calculation.

3a. Hypothetical block A of size r*n1
--------------------------------------

If an abstract triangle subsystem has a block bijection
i -> (alpha_i,beta_i) in Z/r x Z/n1 and the wiring

  L_(u,alpha_i+v) X_iuv R_(v,beta_i+u)^(-1)=1,

then the Cycle6 phase X_iuv=zeta^((epsilon(i)+u+v)^2) has rectangle
W_i=zeta^(2*Delta_u*Delta_v). For any cyclic character order M dividing the
selected coordinate length, legal shift differences kill that phase:

  4*4750 = 19,000 = r,
  17,938*12,903 = 231,454,014 = n1.

Each difference is between 1 and r-1, so these are nondegenerate legal
rectangles. This rules out the specified character-phase template on an
abstract block of those sizes, for either coordinate orientation and any
coordinate bijection. It is not a no-go for arbitrary tables or matrices.

For any such abstract block, the scalar assignment over F_q

  L_(u,j)=1,
  R_(v,k)=5^(v*k),
  X_iuv=5^(v*((beta_i+u) mod n1))

satisfies the triangles and separates every rectangle. If k_i(u) is the
canonical representative of beta_i+u mod n1, then the rectangle exponent is

  e=(v-v')*(k_i(u)-k_i(u')).

It is nonzero since n1>r-1, and

  |e| <= (r-1)*(n1-1) = 4,397,394,792,987 < q-1.

The supplied factorization q-1=2^2*3*13*71*227*3,498,493 and the checked
primitive-root residues establish that 5 has order q-1, hence 5^e!=1.
This is a valid conditional abstract-block model only; it is not assigned to
any actual retained N65 neighborhood.

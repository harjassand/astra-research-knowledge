CYCLE 3 HIGH-CEILING ROUTE — CUBICAL qLTC IMAGE, LOCAL GAP, AND ONE AGGREGATE DIAGONAL TEST
Date: 2026-10-08

STATUS

SOURCE-REPORTED: Chen–Huang–Liu–Tang (CHLT), arXiv:2609.28028v1, Theorem 1.2 constructs a polynomial-time explicit binary CSS qLTC family with constants alpha, delta, rho > 0 and Delta < infinity such that K >= alpha N, D >= delta N, all H_X,H_Z row and column weights <= Delta, and m_X,m_Z = Theta(N). The theorem does not numerically instantiate these constants.

INTERNALLY-PROVED-CANDIDATE: for this (indeed any) commuting bounded-incidence CSS stabilizer check family, the normalized average of its local check projectors has exact code-space spectral gap between 1/m and Delta/m, where m=m_X+m_Z=Theta(N). Thus its gap is Theta(1/N), despite constant qLTC Hamming soundness. A nonlocal orbit-expander operator on the same exact stabilizer image has constant gap and constant row support.

INTERNALLY-PROVED-CANDIDATE: for a fixed CSS/stabilizer logical frame, every physical computational-basis diagonal effect compresses to one diagonal logical algebra. This rules out simultaneously representing the two repeated BJSW seed clauses with positive lower comparison constants. For an explicitly augmented, legitimate BMVZ QMA-hard family, it also rules out exact aggregate equality V*BV=H in every fixed Clifford logical frame, by an anticommuting-Pauli partial-trace witness.

UNKNOWN / NOT RULED OUT: a single common diagonal B for the *aggregate* Hamiltonian with a constant-factor Loewner sandwich in a fixed Clifford frame. If the logical frame is unrestricted, there is an exact aggregate algebraic construction by diagonalizing H; no polynomial-cost diagonalizer, eigenvalue oracle, or corresponding efficient V is established. Hence this is not a complete efficient common-code verifier construction.

1. Concrete cubical CSS qLTC input and charged size

Use the r=4, k=2 binary member of CHLT, “Cubical Sheaf Complexes with Constant Expansion with Applications to Asymptotically Good qLTCs,” arXiv:2609.28028v1 (posted 2026-09-23), Theorem 1.2. It supplies explicit polynomial-time computable binary matrices H_X,H_Z with H_X H_Z^T=0 and a CSS code [[N,K,D,rho]] satisfying

    K >= alpha N,     D >= delta N,
    wt(row), wt(column) <= Delta,
    m_X,m_Z = Theta(N),

and, for every x,z in F_2^N,

    |H_X x|/m_X >= rho dist(x,ker H_X)/N,
    |H_Z z|/m_Z >= rho dist(z,ker H_Z)/N.

The theorem uses absolute positive constants alpha,delta,rho and an integer Delta, but gives no numerical values in its statement. It gives polynomial-time check-matrix construction, not a decoder theorem. The geometric construction is an arithmetic quotient of a product of four trees with compatible Reed–Solomon local codes and a local-to-global expansion argument; none of those combinatorial expansion parameters is itself an energy gap for the normalized stabilizer Hamiltonian.

For a selected family member, the native code encodes K logical qubits in N physical qubits, and N/K <= 1/alpha. A standard symplectic/GF(2) elimination on the supplied check matrices computes a stabilizer tableau, logical representatives, and a Clifford encoder in polynomial time; a conservative naive elimination/synthesis implementation is polynomial (at most O(N^3) elementary binary operations, with polynomial-size Clifford output). This is an implementation consequence of the supplied matrices, not an encoder complexity bound stated in CHLT. A target with fewer than K logical qubits can be embedded by fixing spare logical qubits, but those extra logical constraints need not retain bounded check weight. The theorem alone does not guarantee that every requested target logical dimension occurs exactly or that adjacent family lengths have bounded ratios; any size-matching padding must be charged. Syndrome evaluation for a supplied Pauli error costs O(N Delta)=O(N); no efficient decoder is claimed here.

2. Exact spectral gap and row costs of the normalized local check average

Let S_1,...,S_m be the nonidentity CSS stabilizer checks from H_X,H_Z, with m=m_X+m_Z, and set Q_j=(I-S_j)/2. These are commuting projections. Define

    C_av = (1/m) sum_(j=1)^m Q_j.

Then 0 <= C_av <= I and ker(C_av) is exactly the CSS code space. Because all checks commute, a joint syndrome eigenvector outside the code violates at least one check. Therefore

    gamma(C_av) >= 1/m.

For the upper bound, D >= delta N > 1 for all sufficiently large family members, so no weight-one Pauli is a logical operator. At a physical qubit i, at least one of X_i or Z_i anticommutes with a stabilizer check: otherwise both commute with every check and one is a weight-one logical operator. Choose the anticommuting Pauli E_i from {X_i,Z_i} and a code vector |psi>. Then E_i|psi> has a nonzero syndrome and is orthogonal to the code. Since this pure X or pure Z error anticommutes only with the opposite-type CSS checks containing i, and that column has weight <= Delta, it violates at most Delta checks. Thus

    gamma(C_av) <= <E_i psi|C_av|E_i psi> <= Delta/m.

Since m=Theta(N), this is the exact asymptotic conclusion

    1/m <= gamma(C_av) <= Delta/m,     hence gamma(C_av)=Theta(1/N).

The lower bound uses only commuting stabilizer checks; qLTC soundness is not needed for it. Constant qLTC soundness does not improve the upper bound. The classical qLTC inequalities applied to a weight-one error give a rejection fraction at least rho/N, while bounded column incidence gives at most Delta/m=O(1/N). This is Hamming-distance soundness, not constant normalized spectral gap.

Normalization is decisive. The unnormalized sum C_sum=sum_j Q_j has the same kernel and gap at least 1, with ||C_sum|| <= m=Theta(N). Dividing by m gives the normalized average and the inverse-linear gap above. If all listed checks are nonidentity, its normalized trace is m/2 and ||C_sum|| >= m/2 as well; this optional norm estimate is not needed for the exact average-gap bounds.

Per-row costs in the computational basis are also explicit. Each individual CSS check projector has at most two nonzero entries per row: identity plus one bit-flip for an X-type check, or a diagonal entry for a Z-type check. In the sum, all Z-type contributions merge into the diagonal position, and each of the m_X X-type checks contributes at most one flipped column. Therefore every row of C_av or C_sum has at most m_X+1=O(N) nonzeros (often fewer due to duplicate flips). Given a row string, scan the sparse check list, compute its O(N Delta) incidences, and accumulate entries in O(N Delta) time; rational entries have denominator at most 2m and O(log N) bits. This is polynomial-row sparse, but not constant-row sparse, and its normalized gap is only Theta(1/N).

3. Constant-gap sparse enforcer on this same code image (nonlocal)

There is a different operator on the exact stabilizer image. Let A be the affine set of computational strings satisfying all pure-Z stabilizers and let X_S <= F_2^N be the binary shift space generated by X parts of stabilizers, of rank r. Valid strings split into orbits O=A/X_S of size 2^r. For CSS checks, each logical computational-basis state is the uniform superposition on one orbit; different logical basis states have disjoint supports. (For a general stabilizer tableau the same orbit states carry computable phases.)

Choose a fixed-degree explicit expander on 2^r vertices with symmetric adjacency A_r and nontrivial eigenvalues bounded in absolute value by lambda_0<1. Set P_r=(I+A_r)/2, the lazy walk. On every valid orbit place I-P_r; on invalid computational strings place eigenvalue one. Call the resulting operator C_exp. It satisfies

    0 <= C_exp <= I,   ker(C_exp)=code space,
    C_exp >= delta_exp (I-P_code),
    delta_exp=(1-lambda_0)/2>0.

Each physical row has at most D+1 nonzeros, for constant graph degree D. A stabilizer-tableau reduction computes validity, orbit representative, and orbit coordinate in poly(N); a rotation-map query lists D neighbors in poly(r), so row/entry access is polynomial time with O(1)-bit graph coefficients (and exact CSS phases are absent). No decoder is needed. This is an actual constant all-state spectral gap, but expander edges can connect strings at Hamming distance Theta(N): C_exp is not a bounded-weight local-check Hamiltonian and does not follow from the qLTC soundness parameter. Its full derivation and arbitrary-stabilizer extension are in the sibling record `outputs/research/games_hamiltonians/cycle2/high_ceiling/route_code_image_enforcer.txt`.

Consequently, the cubical code does provide a concrete common image with an efficient code-membership enforcer if one accepts nonlocal sparse-matrix locality. What it does not automatically provide is the required Hamiltonian test B in that image.

4. Full-code compression algebra in the fixed CSS frame

Write C_X=rowspace(H_X), and let valid strings be ker(H_Z). For each coset O=x+C_X contained in ker(H_Z), the encoded computational logical basis vector is

    |ell_O> = |C_X|^(-1/2) sum_(u in C_X) |x+u>.

These vectors have pairwise disjoint computational supports and form a basis for the entire CSS code. If B= sum_z b_z |z><z| is any physical diagonal effect (0<=b_z<=1), then

    V_0* B V_0 = sum_O bbar_O |ell_O><ell_O|,
    bbar_O = |C_X|^(-1) sum_(z in O) b_z.

Conversely, every diagonal logical contraction in this basis is attainable by taking b_z constant on each valid orbit and zero on invalid strings. Thus the compression image of the full physical diagonal algebra is exactly one diagonal logical algebra; all such compressed effects commute. For V=V_0 W with an arbitrary logical unitary W onto the same code image, all compressions instead lie in W* (diagonal algebra) W, and still commute with one another.

This is a property of this CSS/stabilizer image and its fixed logical frame. It is not true for a general isometry: compressions of commuting diagonal physical effects need not commute if the image is not invariant under the physical diagonal algebra. The sibling `route_compression_cone.txt` contains an exact qutrit counterexample for arbitrary isometries.

5. Individual repeated seed tests: a rigorous fixed-frame obstruction

Let P_v=|v><v| for the two BJSW five-qubit seed states

    phi=(|00010>-|10010>)/sqrt(2),
    psi=(|00010>-|01110>-|10110>-|11010>)/2,
    |<phi|psi>|=1/(2 sqrt(2)) in (0,1).

For BMVZ repetition count T, the singleton-layer clauses are projections

    h_(v,T)=I-(I-P_v)^(tensor T),
    K_(v,T)=I-h_(v,T)=(I-P_v)^(tensor T).

The kernel projections K_(phi,T) and K_(psi,T) do not commute. To see this, put S=span{phi,psi} and L=S^perp, dim L=30. On the reducing subspace S tensor L^(tensor (T-1)), each K_(v,T) restricts to (I_S-P_v) tensor I. The two rank-one lines in S have overlap strictly between zero and one, so their orthogonal-complement projections do not commute.

Suppose two physical diagonal effects B_phi,B_psi on the same fixed CSS image had compressions A_v=V_0*B_vV_0 obeying

    alpha h_(v,T) <= A_v <= beta h_(v,T),    alpha>0, beta<infinity.

Each A_v is diagonal in {|ell_O>}, hence A_phi,A_psi commute. The two-sided inequality forces ker(A_v)=ker(h_(v,T)): on ker(h), positivity and the upper bound force A_v=0, while on ran(h), the lower bound makes A_v positive definite. Therefore the zero-eigenspace projections of A_phi,A_psi are exactly K_(phi,T),K_(psi,T), which would commute, contradiction. Hence no common fixed-frame diagonal algebra can carry both *individual* repeated seed tests with any positive lower comparison constant. This is termwise only; it does not prove anything about one B for the total sum.

6. Legitimate full BMVZ instance: exact aggregate equality no-go only for fixed Clifford frames

The noncommuting seed pair can be included in a legitimate BMVZ-admissible QMA-hard layered input, not merely considered as an isolated example. Start with the BMVZ equitable hard family H_0 (constant number of commuting colors, constant minimum color weight), append a fresh five-qubit seed register, and define

    H_plus = (1/2) H_0 tensor I
           + (1/4) I tensor P_phi
           + (1/4) I tensor P_psi.

Put the two seed projections in separate singleton colors. Their common kernel has dimension 30, so the minimum seed energy is zero. Since the base and seed registers are disjoint, lambda_min(H_plus)=lambda_min(H_0)/2; the low/high promise is preserved up to this constant scaling. The number of layers remains O(1), all weights remain bounded below by a positive constant, and each layer has commuting projections. This is an augmented BMVZ-admissible hard family. The canonical unmodified BMVZ/ABN starting family is not asserted to contain this particular seed pair; the augmentation is the construction that makes the instance legitimate.

BMVZ's small-layer rule repeats singleton clauses. After T-fold/iterated amplification, each seed color therefore contains exactly

    h_(phi,T)=I-(I-P_phi)^(tensor T),
    h_(psi,T)=I-(I-P_psi)^(tensor T),

with positive weights, while the base clauses act on disjoint base registers. For d=32,

    Tr_(2,...,T) h_(v,T)
      = [d^(T-1)-(d-1)^(T-1)] I + (d-1)^(T-1) P_v.

Now trace the full augmented output over all base qubits and all but one seed copy. The base contribution becomes a scalar multiple of identity on the remaining five seed qubits. The two seed contributions retain a positive multiple of P_phi+P_psi. In the stabilizer-projector Pauli expansions, Z_2 occurs with a nonzero coefficient in P_phi and -Z_1 X_2 X_3 occurs with a nonzero coefficient in P_psi; these Pauli operators anticommute. Their coefficients cannot cancel: opposite signs for a shared stabilizer would force phi and psi to be orthogonal, but their overlap is 1/(2 sqrt(2)). Thus the partial trace of the full aggregate has nonzero anticommuting Pauli terms.

An operator diagonal in any stabilizer basis has a Pauli expansion supported on a single abelian Pauli subgroup. Partial trace can only delete Pauli terms, so all surviving terms must still commute. The displayed partial trace violates that necessary condition. Therefore, for this legitimate full augmented BMVZ family, the aggregate H is not diagonal in any stabilizer basis. For every fixed Clifford/stabilizer logical frame V_0, no physical computational-basis diagonal B can satisfy exact equality V_0* B V_0=H.

This exact-equality result does not refute a constant-factor Loewner sandwich alpha H <= V_0* B V_0 <= beta H with alpha>0 and finite beta. BMVZ's promise has negligible (not necessarily zero) yes energy; the current full-instance argument does not provide an exact-kernel coordinate obstruction or a unique isolated ground state with the required overlap bound. The sandwich question in a fixed Clifford frame remains UNKNOWN.

7. The single-total-H loophole and a formal common-code construction

There is only one aggregate B when the task asks for the total Hamiltonian. The incompatibility of the two individual seed tests cannot be applied unless the interface separately requires a B_v for every clause. More strongly, if arbitrary logical basis changes are allowed, the same qLTC code image admits an exact algebraic aggregate compression:

1. Let V_0 encode the K-logical CSS space into its N physical qubits and let H be any positive contraction on those K logical qubits (including the full augmented BMVZ output when its norm is at most one).
2. Choose W with H=W* Lambda W, Lambda diagonal with eigenvalues in [0,1]. Set V=V_0 W.
3. On each valid X-stabilizer orbit O, set the physical diagonal B value to the eigenvalue Lambda_O; set B=0 on invalid strings.

The orbit formula gives V_0* B V_0=Lambda, hence V* B V=H exactly. B has one nonzero per physical row. The code image is unchanged, so the nonlocal C_exp from Section 3 still has row degree D+1 and gap delta_exp. Algebraically this is one common diagonal B, one constant-gap sparse C, and an exact common image for the entire aggregate H; it is not an efficient reduction theorem.

The missing costs are substantive. The logical unitary W is an eigenbasis of a QMA-hard amplified Hamiltonian. No polynomial-size circuit or uniform polynomial-time method for W is known here. A dense K-qubit unitary table has 2^K by 2^K entries (4^K complex values); generic matrix diagonalization is exponential in K. The orbit-to-eigenvalue map needed to answer a B row query may require storing 2^K eigenvalues (p-bit values cost 2^K p bits) or an efficient eigenvalue oracle; no such oracle is supplied. Exact algebraic eigenvalue description/precision is also not charged by the formal construction. Meanwhile, obtaining the cubical check matrices and C_exp is polynomial in N, and the base Clifford encoder is polynomial in N. Hence the high-ceiling route separates:

- local qLTC checks: explicit, bounded row/column weight, normalized gap Theta(1/N);
- nonlocal orbit expander: explicit polynomial row access, constant row degree and constant all-state gap on the code image;
- aggregate diagonal B: exact by unrestricted logical diagonalization, but with no polynomially efficient frame or eigenvalue access established;
- fixed Clifford frame: exact equality impossible for the named augmented full instance; constant-factor aggregate sandwich not ruled out.

No claim of an efficient verifier, QMA-hard sparse-C-plus-B encoding, qPCP, or constant-gap local Hamiltonian follows. An expander sampler gap is used only inside C_exp where its graph Laplacian is literally the matrix block; it is not transferred to the qLTC check-average Hamiltonian or to BMVZ energy without a separate theorem.

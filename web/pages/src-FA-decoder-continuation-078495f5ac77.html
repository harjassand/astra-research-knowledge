2026-10-13 — independent audit of compact winner-coordinate acquisition

Decision
  I found no counterexample to the compact representation under the complete
  hidden-affine triangular promise. The interpolation-only-in-the-prior-winner
  span argument and the omitted winner response are valid. The resulting
  expected comparison upper bound is D+6*binom(n,2), where
  D=Σ_(h=0)^d binom(n,h+1), exactly the coefficient-count lower bound for the
  known-coordinate subfamily. Thus the leading comparison ratio is 1 for
  fixed d>=2. The degree-1 expected ratio remains 7. The prior degree-3/4 v2
  audit and receipts are preserved; this is an additive v3 audit.

Contract
  The hidden order is generated by a bijection

      q_i(x)=u_i(x)+g_i(u_1(x),...,u_(i-1)(x)),  u(x)=Ax+b,

  over F_2, with A invertible and each q_i of total degree at most d>=1.
  The learner knows n,d and only an exact strict comparator for the
  most-significant-bit-first order of Q(x)=(q_1(x),...,q_n(x)). It does not
  receive A,b, the q_i, their coefficients, or the triangular directions.
  The guarantee is conditional on this complete triangular class; it does
  not extend to an arbitrary suffix after only a partial flag.

Direct-complement invariant
  Let

      H_k={s : Δ_s u_i=0 for every i<=k},
      W_k=span(v_1,...,v_k),

  where v_j is the winner selected at stage j. Inductively,
  F_2^n=W_k⊕H_k. Initially W_0={0}, H_0=F_2^n. At stage k, the current
  suffix basis spans H_k. The next hidden-coordinate difference
  Δ_s u_(k+1) is a nonzero linear functional on H_k, so some basis vector
  toggles it. A translation s in H_k whose earliest changed hidden
  coordinate is j has first changed output bit q_j, and therefore

      f_s(x)=1 xor C(x,x+s)=q_j(x) for every x.

  Compare two suffix-basis candidates v,w by drawing fresh uniform x and
  querying f_v(x),f_w(x) until their labels match at c. If their first
  changed coordinates a,b are distinct, (q_a(x),q_b(x)) is uniform on
  F_2^2 because Q is bijective, so a match occurs with probability 1/2.
  If a=b, the labels always match. On a match, query C(x+v,x+w). When
  a<b, the first differing translated bits are 1-c,c and this comparison
  returns c; when b<a, they are c,1-c and the comparison returns 1-c.
  Thus its answer equals c exactly when v has the earlier coordinate. When
  a=b, either witness has the same earliest changed coordinate and is valid.
  Pairwise tournament selection therefore returns a minimum-index candidate.

  The fresh-match tournament selects a suffix-basis vector v_(k+1) whose
  earliest changed coordinate is k+1. Consequently
  Δ_(v_(k+1))q_(k+1)=1 and v_(k+1) is not in the kernel
  H_(k+1)=ker(Δu_1,...,Δu_(k+1)). The old direct sum then refines to

      W_(k+1)=W_k⊕span(v_(k+1)),  F_2^n=W_(k+1)⊕H_(k+1).

  This proves the basis W_n=(v_1,...,v_n) is invertible, without knowing the
  hidden affine map. No common polar form is used.

Restricted interpolation and response row
  At stage k, let a∈F_2^k and w_k(a)=Σ_(i=1)^k a_i v_i∈W_k. Since the selected
  direction v_(k+1) has first changed output bit q_(k+1), the comparator
  label f_(v_(k+1))(w_k(a)) is exactly q_(k+1)(w_k(a)). Define

      h_k(a)=q_(k+1)(w_k(a)).

  This is a degree-at-most-d Boolean polynomial in k variables because
  w_k is linear. Querying it on the M_d(k)=Σ_(r=0)^d binom(k,r) low-weight
  coefficient points determines it exactly by ANF Möbius inversion. The
  constant value h_k(0)=q_(k+1)(0) is included.

  For s∈H_k, the lower hidden inputs u_1,...,u_k do not change, so

      Δ_s q_(k+1)(x)=Δ_s u_(k+1)

  for every x. Thus response on H_k is one linear functional. Probe each
  suffix-basis vector s other than the selected winner with the single
  comparison label f_v(s), then set
  ℓ(s)=f_v(s) xor h_k(0)=q_(k+1)(s) xor q_(k+1)(0). The winner's response
  is already known to be 1 from selection, so its value is skipped. This
  yields the entire row ℓ using dim(H_k)-1 comparisons, and its kernel is
  H_(k+1). Taking the winner as pivot gives a kernel basis by replacing each
  other s with s+ℓ(s)v. Summing these response queries over all stages gives
  P=binom(n,2).

Compact full map, inverse, and fibers
  For t=(t_1,...,t_n), write x=Σ_i t_i v_i. Every later winner v_j, j>i,
  lies in H_i and therefore leaves q_i unchanged; v_i flips q_i. The stored
  restricted polynomials hence give, for all t,

      q_(i+1)(x)=t_(i+1)+h_i(t_1,...,t_i),  i=0,...,n-1,

  where h_0 is a polynomial on zero variables and t is indexed from 1 in
  this displayed relation. Equivalently, with one-based coordinate j,
  q_j(Σ_i t_i v_i)=t_j+h_(j-1)(t_1,...,t_(j-1)).

  To invert a rank y, solve successively
  t_j=y_j xor h_(j-1)(t_1,...,t_(j-1)), then return x=Σ_j t_j v_j.
  To sample uniformly in the fiber of a requested first k output bits,
  first solve those k triangular equations for t_1,...,t_k, then choose
  only the n-k remaining t bits uniformly and return Σ_j t_j v_j. This is
  exact: W_n coordinates are bijective and the remaining bits enumerate the
  fiber without repetition. It uses n-k fresh random bits and no future
  radicals, rejection sampling, or full-coordinate ANFs.

Comparison and information costs
  Let P=binom(n,2), the number of pair contests across all suffix-basis
  tournaments, and D=Σ_(k=0)^(n-1) M_d(k). Hockey-stick summation gives

      D=Σ_(h=0)^d binom(n,h+1)=L,

  with terms h+1>n omitted. The algorithm uses D interpolation comparisons
  and exactly P response-row comparisons. Each distinct-coordinate
  tournament pair matches with probability 1/2 on a fresh uniform global
  point; a same-coordinate pair matches surely. A pair uses two comparisons
  per attempt and one priority comparison after a match, so its uncapped
  expected cost is at most 5. The uncapped Las Vegas learner therefore has

      E[Q] <= D+6P.

  It terminates almost surely and is exact whenever it returns. With
  0<beta<1, choose T=ceil(log_2(P/beta)) for P>0 and return UNKNOWN if a
  contest has no match in T attempts. Fresh points give
  Pr[UNKNOWN]<=P*2^-T<=beta. Every completed run is exact. The capped
  worst-case comparison bound is

      Q_max <= D+(2T+2)P.

  The learner transmits at most 2nQ input bits, receives Q comparison bits,
  and uses at most nPT fresh random bits under the cap (at most 2nP in
  expectation without a cap). Its compact output is D ANF coefficient bits
  plus n^2 bits for the winner vectors. Generating the low-weight
  interpolation points costs O(ndD) bit-XOR work; forming comparator
  endpoints costs O(nQ). Direct low-weight interpolation costs O(2^d D)
  subset-XOR operations. Compact rank evaluation, inversion, or prefix
  sampling uses O(dD+n^2) elementary bit operations after the winner-basis
  transform is available. Constructing that transform/inverse costs
  O(n^3) elementary bit operations by ordinary Gaussian elimination.

  The known-coordinate triangular subclass has 2^L distinct total orders:
  fix u=x and choose all coefficients of all g_i monomials of degree at most
  d. The number is
  L=Σ_iΣ_(r=0)^d binom(i-1,r)=Σ_(r=0)^d binom(n,r+1)=D. Distinct coefficient
  tables induce distinct bijections and thus distinct total orders. A
  deterministic exact comparison tree needs at least L comparisons. If a
  randomized algorithm has a worst-case Q-comparison cap, may return UNKNOWN,
  and succeeds on every order with probability at least 1-beta, the uniform
  subclass gives Q>=L+log_2(1-beta). For expected comparisons and average
  error at most beta<=1/2, Fano's inequality gives

      E[Q]>= (1-beta)L-h_2(beta).

  Hence the compact upper has asymptotic ratio 1 to this comparison lower
  bound for fixed d>=2, since D=L=Theta(n^(d+1)) and P=Theta(n^2). At d=1,
  D=L~n^2/2 while 6P~3n^2, so the expected ratio is 7; fixed-beta capped
  worst-case adds a logarithm through T.

  Source-side costs remain separate. For L=D triangular ANF coefficients,
  a dense Python n-bit-mask teacher costs conservatively O(n^2+nL)
  elementary bitwork per distinct rank input and O(n) per comparison to
  compare ranks. With U distinct endpoints, U<=min(2Q,2^n), memoized source
  work is O(U(n^2+nL)+Qn), with O(nU) logical bits for input/rank cache
  contents; without caching charge O(Q(n^2+nL)). The synthetic model also
  needs O(L+n^2) parameter bits. These are model-based bounds, not measured
  runtime or a physical comparator cost.

Independent exact finite test
  compact_tournament_audit.py is self-contained and does not import the v2
  learner. It uses only strict comparisons during acquisition. Across 18
  seeded cases (10 degree-3 cases with n=4..8; 8 degree-4 cases with n=5..8),
  it recovered all 2^n ranks and inverse targets exactly. For every case it
  exhausted every output-prefix target and every free suffix assignment,
  confirming exact prefix-fiber size and coverage. Each receipt confirms
  D=L, and reports row-probe, tournament, random-bit, query-argument,
  response, compact-output, and source-endpoint counts. The forced five-miss
  cutoff uses ten comparisons and returns UNKNOWN with no guess.

  This is seeded finite implementation evidence, not the proof of the
  general tournament or cap probability. The theorem assumes exact strict
  comparisons and fresh independent uniform global points. Novelty, external
  verification, practical comparison advantage, physical validation, and
  the broader mission remain unresolved.

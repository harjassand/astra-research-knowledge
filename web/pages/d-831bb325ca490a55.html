## C2. Source validation and actual strong EF elimination

The frontend independently writes the literal primary fifteen schema patterns,
not aliases for arbitrary canonical axioms. Used source terms have the primary
signature; exact substitution slots and MP endpoints are checked on the raw
canonical DAG. A definition concludes `(e->F) and (F->e)`, with e globally
unique, absent from all earlier actual formulas/operands, absent from F, and F
using only earlier extension names. The rigid final formula contains none of
these names. Future/self definitions and malformed endpoints fail before
unfolding. The global name set is known when validating earlier rows, so future
use cannot masquerade as an ordinary atom.

Let σ replace every fresh e by its recursively expanded body. All original
ordinary schema instances remain literal instances after σ. MP remains MP,
because σ preserves constructors and equality of actual formula roots. Each
definition becomes `(G->G) and (G->G)`. Its eleven-row named proof uses S3/S2
and the unit axiom to derive `G->G`; S3 lifts that closed theorem under 1; two
MP applications to S8(1,G->G,G->G) followed by MP with 1 produce the conjunction.
Reusing the same closed theorem row twice is legal MP reuse. There is no linear
antecedent contraction or substitution inference. The actual serialized eleven
rows, with the arbitrary body bound to G, are instantiated and checked.

Raw source and actual expanded source are both validated. Thus no nominal
fresh atom is evaluated as the body only after an invalid raw schema was
accepted. In particular, an input displaying S15(e,e) but containing the
different raw conclusion S15(p,p), with e:=p, is rejected even though global
substitution would equate them. A final extension name is rejected even when
its expansion is extension-free.

If the original proof has L rows, d definitions and V reachable common syntax
nodes (formula labels, slots and bodies included), the ordinary named source
has exactly L_e=L+10d rows. Expanding each original syntax node requires at
most one memoized node; substitution of an extension atom uses its previously
expanded body. The fixed identity template has 15 supplied nodes, including
its arbitrary body atom and unused initialization constants. Hence the safe
reachable bound m_e≤V+15d+1 holds without printing any unfolded tree. The
implementation asserts this bound on each complete input.

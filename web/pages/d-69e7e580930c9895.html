# Independent gate for the arbitrary two-shear class

Worker hessian_check12, 2026-10-07. Peer hessian_bridge12 proposed and
derived this class; I reconstructed its determinant and inverse without
running the peer script. Source of the binary singular-Hessian theorem:
de Bondt1203.6605v3 Theorem2.4(i), after subtracting affine terms.
Historical priority of this shear consequence is UNKNOWN.

Let F in C[x,eta], G in C[x,s], N!=0, and set

`s=rho+F(x,eta)`, `P2=eta+G(x,s)`,
`psi=N[y s+2x P2]`.

This covers arbitrary-degree consecutive triangular fibre shears with
coefficients in x. It does not cover a retained nonconstant base term,
y/t-dependent coefficients, three or more shears, or all fibre
automorphisms. Adding a constant to psi changes nothing here.

The source coordinates `(x,eta,s,v)`, `v=y+2xG_s(x,s)`, are a global
polynomial automorphism: `rho=s-F`, `y=v-2xG_s`. Their Jacobian in the
original order `(x,y,rho,eta)` is -1. The gradient outputs divided by N
are

`h=F_x v+2eta+2(G+xG_x)`, `s`, `v`,
`k=F_eta v+2x`.

At fixed s,v, put T=2G_x+xG_xx. The original Hessian determinant is
the negative of the determinant of D_(x,eta)(h,k), giving

`det Hess psi/N^4`
` =4+[4F_xeta-2F_etaeta T]v-det(Hess F)v²`.

Because x,eta,s,v are independent polynomial coordinates, constant
Hessian determinant is equivalent to

`det Hess F=0`, `2F_xeta=F_etaeta(2G_x+xG_xx)`.

The constant then has to be 4N^4. The source-dependent parameter v
has not been mistaken for a fixed quantity in this coefficient argument.

If F_etaeta=0, write F=f(x)+a(x)eta. The first identity gives
`-(a')²=0`, so a is constant and G is arbitrary. Recovery is

`x=(k-a v)/2`,
`eta=[h-f'(x)v-2(G(x,s)+xG_x(x,s))]/2`,
`rho=s-F(x,eta)`, `y=v-2xG_s(x,s)`.

If F_etaeta!=0, the named binary singular-Hessian theorem implies

`F=H(eta+c x)+ell x+a eta+d`, H''!=0,

after absorbing the nonzero eta coefficient into the univariate H.
Thus F_xeta=cH'', F_etaeta=H''. Cancellation in the polynomial domain
forces 2G_x+xG_xx=2c. Write G=sum_j g_j(s)x^j; coefficient comparison
uses j(j+1)!=0 in characteristic0 and gives

`G=c x+g(s)`.

There is no root-dependent division by H''. Set r=eta+c x and recover

`r=[h-c k-(ell-c a)v-2g(s)]/2`,
`x=[k-(H'(r)+a)v]/2`, `eta=r-c x`,
`rho=s-F(x,eta)`, `y=v-2x g'(s)`.

Here G_s=g'(s); the c occurs in G_x, not in the last recovery formula.
The initially sent inverse had that typo; the peer flagged it and the
saved checker uses the corrected formula. The formula recovers every
source variable for arbitrary targets and is polynomial. Its left
inverse identity implies the inverse is dominant; consequently the
right inverse also holds identically. Direct output substitution gives
the same two-sided result. Normalize h,s,v,k by the unit N only.

The consequence is a complete no-go for collision-preserving descent
in this coefficient class: every legal member with constant nonzero
Hessian determinant already has a polynomial gradient inverse. A new
shear route must change the retained base/parameter interface, and then
recheck polynomial coordinates, critical elimination, determinant and
collision. No published Meng--Yang collision is claimed to survive.

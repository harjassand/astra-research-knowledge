# Cycle 3: hidden controlled observability after exact Langevin-moment matching

**Status.** The earlier Cycle 2 three-cycle pair is retained only as a baseline-only one-lag embedding comparator: its two generators have different local drift/variance fields, so it does not answer the strengthened question. This cycle gives an explicit smallest scalar-state CTMC witness in which the two models have exactly the same chemical-Langevin drift and variance at every state under every allowed action, yet a short controlled hidden-observation word identifies their action-specific transition matrices and, under a short-lag branch condition, their generators up to one common hidden-state permutation. The HMM realization step is standard; no novelty or biological validation is claimed. A rank-one emission no-go and a finite-sample interface are included. The unknown-nuisance sample count is `UNKNOWN` until a compact nuisance region and a certified profile margin are supplied.

The executable finite witness is [cycle3_moment_matched_controls.py](cycle3_moment_matched_controls.py); saved numerical output is [CYCLE3_RUN.json](CYCLE3_RUN.json). The full-vector K=7 companion is [cycle3_full_vector_witness.py](cycle3_full_vector_witness.py), with its output in [CYCLE3_VECTOR_RUN.json](CYCLE3_VECTOR_RUN.json). ## Interface

Use four scalar states (x_i=i), (i=0,1,2,3). At source state (i), a reaction channel (i\to j), (j\ne i), has rate (q^a_{i\to j}>0) under intervention (a\in\{0,1\}), and stoichiometric jump Δx=(x_j-x_i). The generator is column-oriented, (Q^a_{ji}=q^a_{i\to j}), with diagonal (Q^a_{ii}=-\sum_{j\ne i}q^a_{i\to j}). The chemical-Langevin fields at each state are

\[
b_i^a=\sum_{j\ne i}q^a_{i\to j}(x_j-x_i),\qquad
A_i^a=\sum_{j\ne i}q^a_{i\to j}(x_j-x_i)^2.
\]

These are precisely (Sa) and (S\operatorname{diag}(a)S^\top) for the state-enabled reaction channels. Both actions are fixed, randomized, time-homogeneous interventions. Readouts (Y_t\in\{1,2,3,4\}) are emitted from the hidden current state with a shared but unknown column-stochastic matrix (E), and reads are conditionally independent given the latent path. The initial state distribution π is also unknown and has full support. Independent experimental units are separately randomized and tracked founders/lineages; descendants within one lineage are not independent replicates.

Supplied quantities are the four-state reaction topology, the allowed action labels, sampling lags, and compact bounds used for finite-sample guarantees. Acquired/estimated quantities are the unknown emission matrix (12 free parameters), initial distribution (3), two 4-state action generators (12 off-diagonal rates each), and their confidence region. If state coordinates are not calibrated, add 3 free coordinate values after fixing the origin (or 4 if absolute origin matters); if applied dose/potency is unknown for the two actions, add two nuisance parameters and charge for calibration. The labels remain identifiable only up to one shared permutation unless a state-coordinate or reporter calibration anchors them.

## Theorem: an exact actionwise moment alias, with a smallest scalar-state witness

For each source row, list destinations in increasing state order and use the following nonzero rate perturbations:

| source (i) | destination order | null vector δᵢ |
|---:|---|---|
| 0 | 1, 2, 3 | (3, −3, 1) |
| 1 | 0, 2, 3 | (−1, −3, 1) |
| 2 | 0, 1, 3 | (1, −3, −1) |
| 3 | 0, 1, 2 | (1, −3, 3) |

Each row satisfies both Σⱼ δⱼ Δxⱼ=0 and Σⱼ δⱼ Δxⱼ²=0. Take model A action rates (q^a_{i\to j}) and model B rates

\[
q^{a,B}_{i\to j}=q^{a,A}_{i\to j}+\varepsilon_a\delta_{ij},
\]

where δᵢⱼ is the row entry for that destination. If all resulting rates are positive, then for every state (i) and every allowed action (a),

\[
b_i^{a,A}=b_i^{a,B},\qquad A_i^{a,A}=A_i^{a,B},
\]

while (Q^{a,A}\ne Q^{a,B}). This follows row by row by applying the two null-vector identities. The third jump-moment rate generally changes; here Σ q Δx³ changes by (+6\varepsilon_a) at states 0 and 1 and by −6εₐ at states 2 and 3. Thus a second-order Langevin summary can be exactly identical while the higher jump law differs.

This is the smallest state count for this specific scalar, one-rate-per-directed-transition construction. With K≤3, each source has at most two outgoing destination rates. For K=3, the two constraints have coefficient matrix

\[
\begin{pmatrix}z_1&z_2\\z_1^2&z_2^2\end{pmatrix},
\]

whose determinant (z_1z_2(z_2-z_1)\ne0) for two distinct nonzero jump sizes; hence the rates at that source are determined by (b_i,A_i). K=2 has only one outgoing rate. K=4 is the first case with three rates and a nontrivial null direction. This minimality statement does not cover duplicated reaction channels with the same state jump, restricted topologies, or higher-dimensional state vectors.

The nullspace basis is not a numerical accident: the displayed vectors are exact integers and the moment identities hold exactly for (x=(0,1,2,3)). The printed residuals are only floating-point verification of those identities.

**Full-vector extension.** For a state (x_i\in\mathbb R^d), write (m=d+d(d+1)/2) and let column (j) of (B_i\in\mathbb R^{m\times(K-1)}) be

\[
\phi(x_j-x_i)=\left(x_j-x_i,\;\operatorname{vech}((x_j-x_i)(x_j-x_i)^\top)\right).
\]

Every δᵢ in \(\ker B_i\) preserves the full vector drift and covariance matrix (b_i=\sum_jq_{ij}(x_j-x_i)), (A_i=\sum_jq_{ij}(x_j-x_i)(x_j-x_i)^\top). If (K-1>\operatorname{rank}(B_i)), choose any nonzero null vector in each source row, start with strictly positive rates, and choose a sufficiently small nonzero action-specific ε to keep every perturbed rate positive. This gives exact actionwise matching of all (d+d(d+1)/2) Langevin fields at every state. Generically the feature matrix has rank (r=\min(m,K-1)), so the first generic state count with a null direction is (K=m+2). The scalar K=4 example is the (d=1) instance. For a high-dimensional one-hot population-state vector, (m) can exceed (K-1) and this particular rate-nullspace witness need not exist; exact matching must be assessed against the actual full state coordinates and reaction topology.

### Full two-dimensional state check

The full-vector extension is also instantiated, so the result does not rest on hiding extra components of the state. For (d=2), there are (m=2+3=5) moment features; the minimum generic (K=m+2=7) states give six outgoing rates per source. Take

\[
x_0=(0,0),\ x_1=(1,0),\ x_2=(0,1),\ x_3=(1,1),\ x_4=(2,0),\ x_5=(0,2),\ x_6=(2,2).
\]

The 5-by-6 moment feature matrix has rank 5 at all seven sources. Exact integer null vectors for every source are recorded in [cycle3_full_vector_witness.py](cycle3_full_vector_witness.py); action 0 uses ε=0.05 and action 1 uses ε=0.025, with base rates positive and minimum perturbed rate 0.60. Thus both components of drift and all three independent entries of the full 2-by-2 covariance matrix match actionwise at all seven states. The numeric residual is at most (3.6\times10^{-15}). With an illustrative unknown-to-the-estimator 7-by-7 full-rank reporter (σmin=0.8) and uniform initial mixture, the same three-read (action 0 then 1) law has L1 gap 0.04918, τ max\|Q\|₁=1.265<π, and no common state permutation aligns the two generator pairs (Frobenius gap 1.537). If these exact K=7 word laws were known, the total-variation test uses 9,911 independent lineages at δ=0.05 (29,733 reads and 19,822 action intervals); this is fixed-nuisance only. The exact moment statements follow from the integer null vectors; the recorded residual and observation gap are checks for this explicit instance.

## Three-read controlled word with unknown labels and emissions

Use one positive initial mixture and the action word

\[
Y_0\;\xrightarrow{a=0,\,\tau_1}\;Y_1\;\xrightarrow{a=1,\,\tau_2}\;Y_2.
\]

Let (P_a=e^{Q^a\tau_a}), π₁=(P_0\pi_0). Around hidden state (X_1=j), the conditional emission factors are

\[
L=E\operatorname{diag}(\pi_0)P_0^\top\operatorname{diag}(\pi_1)^{-1},
\quad M=E,
\quad R=EP_1,
\]

and the observed third-order probability tensor is

\[
\mathcal T=\sum_{j=1}^4\pi_1[j]\,L[:,j]\otimes E[:,j]\otimes R[:,j].
\]

If E is full rank and π₀ is positive, then P₀ and P₁ are nonsingular because matrix exponentials are invertible; π₁ is positive too. Each of L, E, and R therefore has column rank 4. Kruskal's uniqueness condition is satisfied (κₗ(L)+κₗ(E)+κₗ(R)=12 ≥ 2K+2=10), so the tensor determines these factors and weights up to one common permutation and scaling; column probability normalization fixes the scaling.

The one-time marginals give (E\pi_0) and (E\pi_1), so, after choosing the common permutation, invertible E gives π₀ and π₁. Then

\[
P_1=E^{-1}R,\qquad
P_0^\top=\operatorname{diag}(\pi_0)^{-1}E^{-1}L\operatorname{diag}(\pi_1).
\]

Thus both action transition matrices are identified from this one controlled word, despite unknown E, π, and hidden labels. If rates obey a supplied short-lag bound τₐ\|Qₐ\|₁<π, each generator is recovered as (Q_a=\tau_a^{-1}\operatorname{Log}(P_a)) by the principal matrix logarithm; otherwise a Markov-embedding ambiguity can remain. The concrete witness has τₐ max\|Qₐ\|₁=0.696<π. A common-permutation audit gives generator-pair Frobenius gap 1.61 and transition-pair gap 0.1095, so these are not merely relabelings.

For the transparent numeric law check, take a shared reporter matrix (E=0.7I+0.075\mathbf1\mathbf1^\top), which is column stochastic with σₘₙₙ(E)=0.7, and π₀=(1/4,1/4,1/4,1/4). These values are used only to report a finite numeric separation; the estimator is not given E or π. The three conditional-view factors have minimum singular values 0.469, 0.700, and 0.450. The two hidden models' observable triple laws have L1 gap 0.04096 (total-variation gap 0.02048). The two action generators do not commute (commutator Frobenius norms 2.08 and 2.24), so the selected word also uses genuine action order. Reversing the action order is a distinct experiment, not needed for this witness.

### Why three reads are the short generic word here

One read has no transition dependence. With K=m=4, two action-conditioned pair laws contain at most (2(m^2-1)=30) free observable probabilities. Yet E (12), π (3), and two independent CTMC generators (24) have 39 free parameters on an open positive-rate/full-rank region. Therefore those two-read summaries cannot generically identify all parameters. The 3-read tensor has 63 free entries and the full-rank CP argument recovers them. This makes three reads and two transitions the shortest generic realization word for this particular unknown-E, two-action design. It is not a universal minimum: known emissions, known initialization, special transition structure, or more action-specific two-read cohorts can change the count and conditions.

## Finite-noise rule, sample count, and full cost ledger

The experimental unit is one independently randomized founder lineage observed at all three scheduled timepoints. For K hidden states and a K-symbol reporter, the length-3 word has L=K³ possible categorical outcomes. The unknown emission, initial-law, and two-generator parameters per model total (K(K-1)+(K-1)+2K(K-1)=(K-1)(3K+1)): 39 for K=4, and 132 for the full-vector K=7 witness. If state coordinates are not supplied, add d(K−1) coordinate values after fixing the origin (3 for scalar K=4, 12 for d=2,K=7); unknown action potency adds two nuisance parameters. Let Ω₀,Ω₁ be compact sets of the two candidate word-law families after profiling over all unknown emissions, initial distributions, state-coordinate values, rates, dose parameters, and common hidden-state permutations. Define the **profiled** L1 separation

\[
\gamma=\inf_{p\in\Omega_0,\,q\in\Omega_1}\|p-q\|_1.
\]

When γ>0 is certified, classify the empirical L-cell word histogram by its nearer family. It is correct whenever ‖\hat p−p‖₁<γ/2. The finite-alphabet inequality

\[
\Pr(\|\widehat p-p\|_1\ge\epsilon)\le(2^{K^3}-2)e^{-n\epsilon^2/2}
\]

therefore gives the sufficient independent-lineage count

\[
n=\left\lceil\frac{8}{\gamma^2}\log\frac{2^{K^3}-2}{\delta}\right\rceil.
\]

This is deliberately conditional on a **certified profiled γ**, not the fixed-nuisance numeric gap. For K=4 the bound uses 64 cells; for K=7 it uses 343 cells and its own K=7 profiled margin. Without a compact nonsingular reporter region, positive initial-mass bound, bounded rate/dose region, and pairwise separation after hidden-state relabeling, the uniform finite-sample guarantee is `UNKNOWN`; γ can approach zero. For the numeric K=4 ((E,\pi)) alone, if the two simple word laws were supplied, the TV-optimal binary word event and Hoeffding threshold need 14,282 lineages at δ=0.05, corresponding to 42,846 reporter reads and 28,564 action intervals. For K=7, that fixed-nuisance illustrative count is 9,911 lineages, 29,733 reads, and 19,822 action intervals. These numbers do not cover estimating unknown nuisance parameters and must not be substituted for the profiled bound.

Total experimental cost is charged as

\[
n(c_{\rm lineage}+3c_{\rm read}+2c_{\rm action})+c_{\rm state\ calibration}+c_{\rm dose\ calibration},
\]

with actual local unit prices left explicit rather than invented. For the scalar K=4 witness, the 39 unknowns per model are E (12), π (3), and both action generators (24); state-coordinate calibration adds 3 independent coordinate values after origin-fixing, and unknown action potency adds two parameters. For the K=7,d=2 companion, the corresponding counts are 132 HMM/rate parameters and 12 uncalibrated coordinate values. No division descendants are counted as independent samples. The word-law calculation uses exact (e^{Q_a\tau_a}), so it has no finite-τ Taylor bias. If an analyst replaces it with the local estimate ((P_a-I)/\tau_a), the omitted finite-lag term must instead be charged using

\[
\|e^{Q_a\tau_a}-I-\tau_aQ_a\|_1\le e^{\tau_a\|Q_a\|_1}-1-\tau_a\|Q_a\|_1.
\]

Executable design algorithm for the K=4 implementation: declare compact parameter boxes for the two competing generator-pair neighborhoods, shared reporter, initial law, state coordinates, and dose map; calculate the 64-cell word-law sets using exact matrix exponentials; certify their permutation-quotiented minimum L1 gap γ by a global optimizer/interval bound; then pass that lower bound to `--profile-gamma` and pass actual unit prices through `--c-lineage`, `--c-read`, `--c-action`, `--c-state-calibration`, and `--c-dose-calibration`. For K=7, replace 64 by 343 and use its separate profile margin. The program returns the conservative sample count and total charged cost when given a certified γ; it does not pretend its finite witness numerically certifies that global γ. Without that certificate it reports `UNKNOWN`.

## Strongest equally informed controls and falsifiers

The moment-only comparator observes all states and both exactly calibrated (b_i^a,A_i^a) fields (vector-valued in the K=7 example). It cannot distinguish these constructed models, even at infinite precision, because those fields are identical at every state and action. Any model fit or feedback rule based only on those matched fields returns the same answer in both worlds. The controlled reporter-word design uses additional higher-order/time-ordered output information, charges three reads and two action intervals per lineage, and distinguishes the explicit full-rank witness. If full reporter trajectories are also supplied to a comparator, it should use the same three-view realization/likelihood machinery; no advantage over that equally informed full-data control is claimed.

These witnesses contain switching but no birth/death or net population growth state. They therefore do not identify the (r_i=b_i-d_i) terms in the Cycle 2 count model, nor separate birth from death. A growth-augmented model would need count-scale observations and an augmented transition/emission construction; no claim about those parameters is made here. With a target/unsafe set and a confidence region over action generators, a standard finite-action robust reach-avoid rule can maximize the worst-case success probability across that set, but no target or biological action costs were specified in this cycle, so no intervention is selected.

The decisive falsifiers are mechanical and statistical. First, exact symbolic substitution must fail if any displayed δ row does not annihilate both moment vectors, or if a perturbed rate is nonpositive. Second, recompute all action/state (b,A) fields and verify equality; a residual beyond arithmetic tolerance invalidates the witness. Third, compare both transition pairs over every common state permutation; zero would mean the hidden models are relabelings. Fourth, compute the actual triple laws; zero or a rank-deficient view factor invalidates the observation claim. Fifth, give an adversary identical emission columns: any claimed controlled word separation must then disappear. Finally, for an empirical design, the realized confidence set must have a certified positive profiled γ and contain the true-parameter assumptions; otherwise report `UNKNOWN` rather than a rate or control guarantee.

## Prior art and novelty boundary

The latent-state realization mechanism is routine HMM theory. Allman, Matias, and Rhodes prove generic identifiability results for HMMs using Kruskal's theorem and grouped observations; Gassiat, Cleynen, and Robin establish finite-state HMM identifiability up to labels under nonsingular transitions and linearly independent emissions; Hsu, Kakade, and Zhang give spectral learning under full-rank/separation assumptions. Liu and Bitmead study HMM observability and reconstructibility and discuss external control inputs, while Huang, Ge, Kakade, and Dahleh treat finite-string HMM realization. The C3 tensor argument is a direct controlled, nonstationary specialization of these ordinary realization ideas, not a new observability theorem.

The narrow load-bearing contribution of this lane is an explicit four-state scalar finite-jump pair under the stronger actionwise same-(b,A) quantifier, plus its exact shortest-generic-word interface and rank-one no-go. Whether the state topology, reporter assumptions, or control interventions describe any specific cell system is a biological modeling question; this report contains no cell-line data, literature-derived biological rates, or external validation.

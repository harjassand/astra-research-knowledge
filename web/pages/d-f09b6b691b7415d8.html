SHARED-CONSTITUENT BELL OBSTRUCTION FOR MIXED TENSOR REPRESENTATIONS
2026-10-08

Abstract route

Let H_1,H_2 carry the two factor branch representations on an input
H_1 tensor H_2, with inverse-closed branch labels S_1,S_2 of size k=130 each.
Suppose there are m distinct matched cross-factor branch pairs (s_j,t_j),
1<=j<=m, and invariant subspaces V_1<=H_1,V_2<=H_2 of common dimension D>0
such that, after a unitary identification V_2=overline{V_1},

  W_(1,s_j)|V_1 = sigma_j,
  W_(2,t_j)|V_2 = overline{sigma_j^{-1}}

for every j, where sigma_j is unitary. Then the score radius satisfies

  Gamma_K >= sqrt(2m).

For the selected gate, (sqrt(50)+0.165)^2<53, so any m>=27 such synchronized
pairs already refute the target. The inverse-twin quotient construction has
m=130 and gives Gamma_260>=sqrt(260).

Proof

Let Omega_D=D^(-1/2) sum_{a=1}^D e_a tensor overline{e_a} be the canonical
maximally entangled vector in V_1 tensor V_2. The identity

  (A tensor overline{A})Omega_D=Omega_D

holds for every unitary A. For each matched pair, the relative branch product
restricted to V_1 tensor V_2 is

  W_(1,s_j)^* tensor W_(2,t_j)
       = sigma_j^{-1} tensor overline{sigma_j^{-1}},

so it fixes Omega_D. Its reverse ordered relative product is
sigma_j tensor overline{sigma_j}, which also fixes Omega_D. Define a
coefficient matrix A supported on these 2m ordered off-diagonal entries, each
with value 1/sqrt(2m). Then A is Hermitian, trace zero, and HS norm one. Its
score polynomial fixes Omega_D with eigenvalue

  (2m)/sqrt(2m)=sqrt(2m).

Therefore the full score operator norm is at least sqrt(2m). If `m>=27`, its
square is at least 54, strictly above the selected target square, which is
less than 53.

Representation-theoretic consequence

This lemma does not require regularity. Any two factor carriers containing
matched conjugate-equivalent invariant constituents trigger the same lower
bound. In particular, for finite quotient regular-minus-constants carriers,
a common nontrivial quotient with the required inverse-label alignment
supplies shared constituents. The explicit inverse-twin pair in
mixed_augmentation_route.txt is a special case.

This is a necessary-avoidance condition, not a construction theorem. To pass
the selected gate, a mixed tensor representation must avoid at least 27
matched branch pairs on every common conjugate-equivalent constituent and
must still control the remaining full coefficient sphere. Avoiding common
constituents alone does not imply a score upper bound. The result does not
address Haar branches or contradict the free-group radius result.

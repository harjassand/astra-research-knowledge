## Formula graph and explicit compatibility templates

Write `T_X=X^t` and `S_X=X^s`. Memoize these two formulas and a proved
sequent `P_X: T_X,S_X => bottom` once per source node `X`.
Every antecedent below is a multiset. Repeated equal formulas retain their
multiplicity. The target has no unrestricted contraction.

For atoms and the four constants, `P_X` is a bottom axiom. For instance,
`T_1=1,S_1=bottom` and `T_0=bottom,S_0=1`.

* `X=A & B`: From `P_A`, replace `T_A` by `T_A & T_B` using `L&`.
  From `P_B`, replace `T_B` by the same conjunction using `L&`.
  Combine the two sequents by `L∨` on `S_A∨S_B`.
* `X=A∨B`: From `P_A`, replace `S_A` by `S_A&S_B` using `L&`;
  do the analogous replacement in `P_B`. Combine by `L∨` on `T_A∨T_B`.
* `X=A*B`: Use `T_A=>T_A` and `P_B` with `L→` to obtain
  `T_A,T_B,T_A→S_B=>bottom`. Replace that arrow by
  `(T_A→S_B)&(T_B→S_A)` using `L&`, then use `L*` on `T_A,T_B`.
* `X=A→B`: Use `T_A=>T_A` and `P_B` with `L→` to obtain
  `T_A,S_B,T_A→T_B=>bottom`. Replace that arrow by
  `(T_A→T_B)&(S_B→S_A)` using `L&`, then use `L*` on `T_A,S_B`.
* `X=!A`: Apply `L→` to the two identities for `!T_A` and `bottom`.
  This gives `!T_A,!T_A→bottom=>bottom` directly.

The most expensive case adds 13 total formula occurrences: one identity
with 2, an implication-left row with 4, an additive-left row with 4, and a
multiplicative-left row with 3. Thus all compatibility components together
use at most `13m` formula occurrences. Reusing `P_B` is reuse of a proved
sequent, expressly permitted by the proof-DAG definition. It does not
replace a context containing two resources by a context containing one.

For negation, the translation gives
`T_(neg X)=(T_X→bottom)&(1→S_X)` and `S_(neg X)=T_X*1`.
Prove its four equivalence directions as follows:

* The first conjunction entails `S_X` by projecting `1→S_X`, then
  applying that arrow to the axiom `=>1`.
* From cached `P_X`, implication introduction yields
  `S_X=>T_X→bottom`. Identity followed by `1w` and implication introduction
  yields `S_X=>1→S_X`. `R&` combines these with the identical context `S_X`.
* `T_X*1=>T_X` follows from identity, `1w`, and `L*`.
* `T_X=>T_X*1` follows from identity, `=>1`, and `R*` with an empty second
  context.

These four components add 30 formula occurrences per source node,
independently of its unfolded size. Any bounded extra negation closure
needed by an axiom template adds only `O(m+L)` source graph nodes.

## Explicit simultaneous conservative repair

For every conservative node `C`, memoize `F_C:T_C=>C` and `R_C:C=>T_C`.
For each fully conservative node `B`, also memoize `Z_B:S_B=>bottom`.
Membership is computed by the exact mutually recursive grammar of
Definition 16; in particular, an implication is admitted only when its
antecedent is conservative and its consequent fully conservative.

Atoms/constants use identity. For additive conjunction and disjunction,
use their left/right rules on the child endpoints. For multiplication,
combine the two child endpoints using `R*`, then combine the two principal
antecedent formulas using `L*`. For `!C`, first turn `T_C=>C` into
`!T_C=>C` by `L!`, then into `!T_C=>!C` by `R!`.
The reverse direction is analogous. Promotion is legal because its
antecedent consists entirely of an exponential formula.

The substantive case is `B=C→A`, with `A` fully conservative:

1. Apply `L→` to `R_C:C=>T_C` and `F_A:T_A=>A`.
   Introduce `C→A` on the right and project the first conjunction on
   the left. This proves `T_B=>B`.
2. Apply `L→` to `F_C:T_C=>C` and `R_A:A=>T_A`, then introduce the
   right implication. This proves `B=>T_C→T_A`.
3. Cut `Z_A:S_A=>bottom` with the bottom axiom
   `B,bottom=>S_C`, then introduce the right implication.
   This proves `B=>S_A→S_C`.
4. Apply `R&` to the last two sequents. Both antecedents are exactly
   the singleton `B`; that is the additive conjunction rule, not
   contraction. The result is `B=>T_B`.
5. For `Z_B`, cut `Z_A` with `T_C,bottom=>bottom`, then use `L*`.

The implication case adds 30 total formula occurrences across all three
new components, the maximum among the constructors. For a fully
conservative conjunction, `S_B` is a disjunction, so `L∨` combines child
collapse sequents. For a fully conservative disjunction, `S_B` is a
conjunction, so one child collapse and `L&` suffice. Accordingly all repair
components together cost at most `30m`. Together with compatibility and
four negation directions, the independent implementation's local upper
bound is `73m` formula occurrences, including all auxiliaries.

## Why raw fresh-atom translation is not the extension proof

Take the acyclic extension definition `e<->p*p`, with `e` fresh. If one
translates it while retaining `e` as an ordinary atom, then `S_e=bottom`
but `S_(p*p)=(p→bottom)&(p→bottom)`. The translation of `e→p*p` contains
the additional conjunct `S_(p*p)→bottom`. This conjunct cannot be silently
obtained from the positive extension definition.

Here is an exact countermodel. On `[0,1]`, interpret additive conjunction
and disjunction as min/max, multiplication as `max(0,x+y-1)`, and
implication as `min(1,1-x+y)`. Interpret `1=top=1` and `0=bottom=0`.
These operations are a commutative integral residuated lattice: the
residuation law reduces directly to `x+y-1<=z`. Associativity reduces
to `max(0,x+y+z-2)`. Negation is `1-x`, hence involutive. For full linear
logic, use `!x=1` if `x=1`, and `!x=0` otherwise: `!x<=x`,
`!x*!x=!x`, and the promotion rule follows by distinguishing whether
all exponential assumptions are 1. Thus this is also a valid affine
classical linear model.

Put `p=3/4` and `e=1/2`. The extension equation has value 1, because
`p*p=1/2`. But `S_(p*p)=1/4`, so the extra implication to bottom has
value `3/4`, and the translated definition has value `3/4`, not 1.
This is a minimal one-gate obstruction to the raw translation, not an
obstruction to the circuit proof construction.

The correct EF route is to substitute extension definitions first.
For fresh acyclic definitions whose variables are absent from the final
goal, each extension equation unfolds to `(F→F)&(F→F)` and has a
constant-line derivation using identity, implication introduction, and
additive conjunction. Redirecting extension names to prior formula nodes
keeps the common syntax graph within the original certificate size.
The Chu translation is then applied to these **ordinary unfolded formulas**.
No fresh atom is equated with a compound formula inside the target kernel.

## Finite-skeleton compression, independently reconstructed

For an ordinary `L`-line Frege proof of a fixed formula `A`, retain its
inference labels and premise indices. Introduce a fresh metavariable for
each line root and fresh schematic metavariables for every rule instance.
Write equations tying each cited premise/conclusion root to its schema
term; tie the last root to the given ordinary formula `A`. Because the
rule list is finite, this constraint graph has `O(L+|A|)` nodes.

Merge equivalent equation nodes. Two constructor-labelled classes must
have the same connective/constant/rigid atom and arity; merge their
corresponding children. A label conflict is impossible because the actual
proof supplies a finite term solution. A cycle in the constructor quotient
is also impossible: evaluating each class under that actual solution
would make the finite term size strictly decrease around the cycle.

Choose the common constructor of each labelled class. Ground each
unlabelled class to one fresh ordinary atom. The acyclic quotient graph
is now a common syntax DAG of `O(L+|A|)` nodes. Every original rule
equation remains true, and the final term is still exactly `A`.
This changes intermediate formulas honestly; it need not compress the
original labels without change.

For the present canonical schemas this has no hidden side condition:
there is no uniform-substitution inference, no requirement that a schema
metavariable be atomic, and no freshness restriction. Necessitation
acts on already derived closed theorems. The fresh-extension inference
is excluded from this step; it was handled by acyclic unfolding above.
The construction applies to any fixed finite schematic standard Frege
presentation; replacement by a fixed derivation preserves line counts
within a constant factor.

Combining this compression with the accepted whole-proof sharing lemma
yields an ordinary intuitionistic proof of every conservative
affine Frege theorem `A` with `O(L+|A|)` formula-occurrence lines.
Consequently the known intuitionistic lower bound on `Theta*_n` gives
exponential affine Frege **line** lower bounds and exponential
acyclic definitional-EF **size** lower bounds. This is the principal
candidate frontier closure. It does not assert an arbitrary
substitution-Frege lower bound or a classical Frege lower bound.
The corresponding sequent-system line statement needs its own explicit
line-preserving equivalence or direct sequent-skeleton normalization;

## Exact obstruction beyond exponential contraction

The unchanged Chu translation cannot add unrestricted contraction, even
when the contracted source formula is one atom. Consider

```
c = (A -> (A -> B)) -> (A -> B).
```

Use the same affine algebra above, with `D=N=bottom=0` and `A=p`, `p=1/2`.
The translation obeys

```
T_(X->Y) = min(T_X -> T_Y, S_Y -> S_X)
S_(X->Y) = max(0, T_X + S_Y - 1).
```

Both exact cases below give `T_c=1/2<1`:

| Choice of `B` | `(T_B,S_B)` | `(T_(A->B),S_(A->B))` | `(T_(A->(A->B)),S_(A->(A->B)))` | Fully conservative `c` |
| --- | --- | --- | --- | --- |
| linear `0` | `(0,1)` | `(0,1/2)` | `(1/2,0)` | no |
| atom `q`, with `q=0` | `(0,0)` | `(1/2,0)` | `(1,0)` | yes |

In each case the second conjunct in the outer translated implication
has value 1, and its first conjunct has value 1/2. The second example
is already in the fully conservative implication/atom fragment of
Definition 16. An atomic-contraction restriction therefore does not
repair this unchanged translation. This is an obstruction to this method,
with no full-classical proof lower-bound conclusion.

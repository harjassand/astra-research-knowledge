## 1. A certificate valid under adaptive stopping and design selection

Fix one reference Hamiltonian, conserved sector, inverse temperature beta>0,
and finite label projectors. Assume the acquired labels X1,X2,... are independent
draws from the SAME actual reference Gibbs histogram p. Supply a valid reference
coherence budget C>=1, so the source's latent weights satisfy

    0<=w_i<=p_i,       sum_i w_i>=1/C.

Obtaining equilibrium, independent preparations and C is charged. This theorem
does not infer them from a quiet time trace or a histogram. Changing a reference
gate, temperature or ensemble changes the distribution and requires a separately
justified statistical protocol. A finite-shot kinetic interval is not silently
converted into an anytime-valid interval.

For a binary label, let S_N be the number of ones. For a proposed reference
probability p in(0,1), define the uniform-Beta mixture likelihood ratio

    E_N(p)=S_N! (N-S_N)! /
                 [(N+1)! p^S_N (1-p)^(N-S_N)].                 (1)

This is the integral over q in[0,1] of
`q^S_N(1-q)^(N-S_N) / [p^S_N(1-p)^(N-S_N)]`.
For the true p, every integrand is a likelihood-ratio martingale. Integration
preserves nonnegativity, conditional expectation and initial value1, so E_N(p)
is a nonnegative unit-mean martingale. If T is its first crossing of1/alpha,
the stopped expectation at T wedge N is at most1; hence
`Pr(T<=N)<=alpha`. Letting N increase proves

    Pr[there exists N>=0: E_N(p)>=1/alpha] <= alpha.             (2)

The sets I_N={p:E_N(p)<=1/alpha}, with suitable endpoint limits, are intervals
because binomial log likelihood is concave. They are simultaneous confidence
sets for all observation times. Boundary probabilities also give a valid
supermartingale interpretation. In the finite-temperature source contract,
every nonempty projector has strictly positive Gibbs probability.

For k labels, either use a per-label Beta mixture with alpha_i>0 and
sum alpha_i<=alpha, intersecting its intervals with the probability simplex,
or use the direct uniform-Dirichlet likelihood mixture

    E_N(p)=(k-1)! product_i n_i! /
                    [(N+k-1)! product_i p_i^n_i].              (3)

The same proof works. The direct region is generally nonlinear. A box from the
per-label intervals retains the source's small linear-program formulation;
claiming the full Dirichlet region is a polytope would be incorrect.

At each time form a valid histogram confidence set P_N. For any supplied
candidate shifts v, u_i=exp(-beta v_i), calculate

    A_plus(N,v)=max_(p in P_N) p.u,
    L_minus(N,v)=min_(p in P_N,0<=w<=p,sum w>=1/C) w.u.

The source trace/partition proof then gives, on the ONE event that p belongs
to every P_N, simultaneously for every N and every v,

    -log(A_plus)/beta <= F(H+V(v))-F(H)
                       <= -log(L_minus)/beta.                 (4)

## 3. Adaptive expected sample lower bound

Consider any randomized algorithm reading independent p-coins, with arbitrary
adaptation and a stopping time N. Its other inputs beta,B,c and model promise
are identical in the two cases. Couple its internal randomness and use the
same uniform U_j for each requested reference draw: output1 if U_j<=p. The
oracles disagree only for theta<U_j<=2theta, of probability theta.

Along the p0 run, the event N>=j depends only on previous observations and
randomness. Therefore the expected number of disagreements by its stopping
time is theta*E_0 N. If there is no disagreement before that stop, both runs
have identical transcripts and outputs. Consequently

    TV(output0,output1)<=theta*E_0 N.                          (7)

The result is trivial if E_0 N is infinite. It allows variable and unbounded
runtime; it is not merely a deterministic-cap statement.

If each case has wrong-decision probability at most alpha and UNKNOWN probability
at most delta, the event "decide positive" has probability at least1-delta-alpha
in case0 and at most alpha in case1. Hence

    E_0 N >= max(0,1-delta-2alpha)/theta
           =max(0,1-delta-2alpha)*exp(beta*B).                 (8)

Unlimited abstention evades a lower bound, as it should. Physical cost is at
least this reference-shot count times its preparation/readout cost. The theorem
does not bound protocols that prepare other gate settings or use extra complete
Hamiltonian information, quantum coherent queries, importance ensembles or
target preparations. Those change the acquired-information contract and require
their own costs. It is a precise obstruction to treating arbitrary strong
counterfactual shifts as cheaply learnable from one reference histogram.

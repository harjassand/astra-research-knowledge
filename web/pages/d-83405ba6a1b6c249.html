## Parameter admission lemma

Let K>=64 be an integer, R=floor(sqrt K), and let alpha and h be rational numbers with 0<alpha<=32 and h>=13. Set

    H=h R²,
    w=alpha K r^(-4) exp(beta u),
    u=(sigma d-H)/r + R G/(2r²) +12R-e.

Admit these parameters if both inequalities hold:

    K/k > 13K/R² +6+768/(5 alpha),                 (reserve)
    (2 alpha K/R²) exp(25/4-h/2) <1.             (initialization)

Run the reconstructed algorithm only while N>=K. After a full cleanup, N<K forces every retained row to be empty. Finish by exact cost optimization on the current original face. The resulting favorable response has unsigned discrepancy strictly less than

    (h/2) R² +2K+1.                              (radius)

The cycle-9 exact-marginal extractor preserves this bound. Parameter encodings and all changed calculations are polynomial bits when alpha,h are chosen from a fixed rational table and K=O(k). Exact vertex access and face/cost reset remain the original GLS-derived interface.

## A universal closed-form fallback: 312k+625

Take

    alpha=32,    K=24(k+2),    h=22.

Then K>=72, R>=8, and K/R²<=5/4 because K<=(R+1)²-1=R²+2R. Initialization is certified by

    2 alpha K/R² exp(25/4-h/2) <=80 exp(-19/4)<1.

For a rational proof of the last inequality, e>8/3 and (8/3)^9>80²; hence exp(9/2)>80, and 19/4>9/2. No approximate logarithm is used.

For reserve, k=K/24-2, so the relevant gap is

    f(K,R)=24K/(K-48)-13K/R²-54/5.

For fixed R this is strictly decreasing in K. Its worst possible value is at K=R²+2R, where

    f >= 1/5-26/R+1152/(R²+2R-48).

Multiplying by the positive denominator 5R(R²+2R-48) gives exactly

    R[(R-64)²+1356]+6240 >0.

This proves reserve for every integer k>=1. The radius is

    B_new(k)=11 floor(sqrt(24(k+2)))²+48(k+2)+1 <=312k+625.

This beats the old linear upper bound 1161k for all k>=1; the exact floor-dependent old bound should be used in comparisons. It also improves that old exact bound for every k: at k=1 the new exact value is 849 versus 1161, while for k>=2 the old R²>=32k gives old radius>=648k+1>312k+625. It is a constant-factor theorem improvement, not an asymptotic improvement from O(k).

## A second fallback and the matroid specialization

The alternative alpha=12,K=32(k+1),h=20 is also universally admitted. Its reserve gap is

    32K/(K-32)-13K/R²-94/5.

Its worst fixed-R value is 1/5-26/R+1024/(R²+2R-32), whose positive numerator is R[(R-64)²+732]+4160. Initialization is at most 30 exp(-15/4)<1; a rational certificate is (8/3)^7>30². Its radius <=384k+385. It is sometimes smaller than the first fallback for small k.

For matroid bases, k=2, a better admitted choice is alpha=12,K=64,R=8,h=19. Reserve reads 32>13+94/5=159/5. Initialization is 24 exp(-13/4)<1; e>8/3 reduces its rational certificate to 2^27>3^17. The radius is

    B_matroid=19*64/2+128+1=737.

This improves the old 2209 bound under the same ordinary independence-oracle access. It still exceeds the transferred Li bound <198 on classes with an efficient all-subset complementary exchange interface, and it can be far worse than the general-P kT comparator on sparse features. Neither exact marginals nor parameter calibration is itself a novelty claim.

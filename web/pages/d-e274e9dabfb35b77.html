T12 MULTIPARTITE LOCAL-PROJECTION SAMPLER: EXACT SUBCASE AND GATES
Phase-II Luna/Max; frozen mathematical record v1; 2026-10-09

STATUS

This record proves an exact first-success sampler for finitely many
pairwise-commuting local projection families. It preserves every original
local algebra, produces a valid unconditional commuting-operator strategy,
and gives a quantitative bound for the probability that independently
chosen local first-success indices disagree. It also gives a state-vector
comparison when the local projections almost agree on the resource vector.

This is a strict projection-input subcase. It does not construct the
requested sampler for arbitrary local-description vectors or contractions.
The gap is not a scalar repetition wrapper: arbitrary positive moduli are
not projections, and multiplying or erasing their local filters changes
both the first-success law and the coherences of the target state. The
multipartite GHZ-label version of the bipartite graph filter has an explicit
failure below. No multipartite repetition theorem follows here.

1. EXACT LOCAL-PROJECTION THEOREM

Let m>=2, let H be a Hilbert space, let A_1,...,A_m be unital von Neumann
algebras in B(H) satisfying [A_i,A_j]=0 for i!=j, and let psi be a unit
vector. Fix projections P_i in A_i and finite local POVMs
{M_i^a : a in S_i} in A_i. Write

  q = <psi, P_1...P_m psi>,
  r = <psi, (1-P_1)...(1-P_m) psi>,
  Delta = 1-q-r,
  mu_ij = ||(P_i-P_j)psi||^2.

The projections commute, so q,r,Delta are respectively the probabilities
of all-success, all-failure, and nonunanimous flags in their joint classical
distribution. In particular

  Delta <= sum_{i<j} mu_ij,                                      (1)
  q >= <psi,P_1 psi> - sum_{j=2}^m mu_1j.                       (2)

For N independent copies of (H,psi), party i uses the local first-success
POVM

  E_i^a = sum_{j=1}^N (1-P_i)^{tensor(j-1)} tensor
                   (P_i M_i^a P_i) tensor 1^{tensor(N-j)}
           + 1_{a=a_i^0}(1-P_i)^{tensor N},                    (3)

where a_i^0 is a fixed timeout answer. These are complete POVMs: summing
(3) over a telescopes to the identity. E_i^a belongs to A_i^{tensor N};
therefore E_i^a and E_j^b commute for every i!=j and every pair of inputs.
No party is grouped with another, and all original local algebras are
preserved literally.

Let J_i be party i's first successful copy, or infinity on timeout. For
each copy t, the commuting projections give a classical flag vector
X^t in {0,1}^m. Let B be the event that X^t is neither 0^m nor 1^m; then
Pr(B)=Delta. The event U={X^t=1^m} has probability q. Across independent
copies, ignore all-zero trials and consider the first trial in U union B.
It is in B with probability

  Delta/(q+Delta),                                              (4)

when q+Delta>0. If it is in U, every party has had only all-zero flags
before it, hence J_1=...=J_m at that trial. The chance that no trial in
U union B occurs in N copies is (1-q-Delta)^N=r^N. Thus

  Pr(J_1,...,J_m are not the same finite index)
       <= Delta/(q+Delta),
  Pr(no unanimous success before timeout) <= r^N.              (5)

The first bound charges only the first disagreement race; later behavior
on the bad event is unrestricted. If q>0, r<=1-q and r^N<=exp(-qN).

On the event that all parties' first success is j, every earlier copy has
all flags zero and copy j has all flags one. Its outcome law is exactly
the local-POVM table on

  psi_sync = P_1...P_m psi / sqrt(q).                            (6)

Indeed, because different parties' algebras commute,

  product_i (P_i M_i^{a_i} P_i)
       = (product_i P_i)(product_i M_i^{a_i})(product_i P_i),    (7)

so the normalized joint outcome probability is
<psi_sync, product_i M_i^{a_i} psi_sync>.
The total mass of this good event, including any j<=N, is

  g_N = q (1-r^N)/(1-r)                                        (8)

when r<1. The remaining mass consists of mismatched first indices or
timeouts and is at most Delta/(q+Delta)+r^N by (5). For every fixed input
tuple, the actual unconditional outcome table is a convex combination
g_N p_sync +(1-g_N)p_bad; hence its half-total-variation distance from
p_sync is at most 1-g_N, with the sharper upper bound in (5) when bad
branches are charged separately.

2. VECTOR ALIGNMENT SUBCASE

Let p_1=<psi,P_1 psi> and S=sum_{j=2}^m mu_1j. Since the P_i commute,

  ||P_1...P_m psi - P_1 psi||^2
    = <psi, P_1(1-product_{j=2}^m P_j) psi>
    <= sum_{j=2}^m <psi,P_1(1-P_j)psi>
    <= S.                                                       (9)

The last inequality follows from
(P_1-P_j)^2=P_1(1-P_j)+(1-P_1)P_j. If S<p_1, then q>=p_1-S>0.
For u=P_1 psi/sqrt(p_1) and v=psi_sync, normalization and (9) give

  ||u-v|| <= 2 sqrt(S/q) <= 2 sqrt(S/(p_1-S)).                  (10)

For any joint POVM, half-TV of the outcome laws on u and v is at most
||u-v||. Thus, if the target is the original local-POVM table on
P_1 psi/sqrt(p_1), the first-success protocol has mean error at most

  Delta/(q+Delta) + r^N + 2 sqrt(S/(p_1-S)),                    (11)

provided p_1>S and q>0. This bound is uniform in dim(H) and uses only
local projections. It is not uniform in the relative success probability
p_1: without a lower bound on p_1, (11) can be vacuous. In particular,
(11) does not turn arbitrary unit vectors into projections.

For a finite input family (P_i(x_i),M_i(x_i)) and law nu on input tuples,
the same construction works with one N large enough for the finite family.
All estimates are then averaged under that same nu. If p_1(x) or q(x)
vanishes on positive nu mass, the corresponding normalized target is
undefined and must be removed only with an explicit mass payment.

3. WHAT THE PROJECTION ARGUMENT DOES NOT BRIDGE

The useful hypothesis for (9) is closeness of local *projection vectors*
P_i psi. A general local description has the form A_i psi with a local
operator A_i, and polar decomposition A_i=u_i c_i does not yield a
projection P_i satisfying P_i psi approximately c_i psi at a uniform
relative-success cost. The support projection s(c_i) can have arbitrarily
small probability even though ||c_i psi||=1. For example, on C^2 let

  psi_K = sqrt(1-K^{-2}) |0> + K^{-1}|1>,
  c_K = K |1><1|,

so ||c_K psi_K||=1 but <psi_K,s(c_K)psi_K>=K^{-2}. A lower spectral
cutoff below K has the same small success probability. The vector closeness
of the c_i psi does not supply a family-independent lower bound on p_1.

The elementary commuting-modulus estimate is not the missing sampler.
If A_i and A_j are in commuting local algebras, their self-adjoint
dilations Z_i=[[0,A_i],[A_i*,0]] and Z_j commute. On the lower block,
the joint spectral theorem and scalar 1-Lipschitzness of absolute value do
give

  ||(|A_i|-|A_j|)psi|| <= ||(A_i-A_j)psi||.                    (12)

But (12) only aligns the local positive moduli on psi. It does not imply
that separate local success events have matching first-success indices,
nor that a product of non-idempotent filters produces the desired single
local target vector. Replacing A_i by |A_i|^{1/m} makes a joint product
resemble |A_1| psi when all moduli are close, but each success effect is
then |A_i|^{2/m}; local Bernoulli success flags are not automatically
correlated. A shared classical threshold correlates flags but leaves a
threshold register correlated with the modulus, generally dephasing the
target table. No coherent local erasure resolving both defects is derived
here.

4. EXACT FAILURE OF A DIRECT GHZ-LABEL EXTENSION

Consider the natural proposed m-party analogue of the bipartite
soft-label resource,

  Omega = sum_k t_k |k>_1 ... |k>_m tensor psi,
  sum_k |t_k|^2=1,                                               (13)

and local rank-one success projections

  P_i = |g_i(c_i)><g_i(c_i)|

on party i's label register and H, where g_i(lambda) is a unit label
vector. For any two parties i!=j and m>=3, at least one label register
is untouched by P_i P_j. Its inner product forces the bra and ket GHZ
indices to agree. Consequently

  <Omega,P_i P_j Omega>
    = sum_k |t_k|^2 <psi, g_{i,k}(c_i)^2 g_{j,k}(c_j)^2 psi>, (14)

whereas

  <Omega,P_i Omega>
    = sum_k |t_k|^2 <psi, g_{i,k}(c_i)^2 psi>.                  (15)

For equal scalar descriptions c_i=c_j=lambda I and equal soft profiles
g_i=g_j=g, the ratio of (14) to (15) is

  [sum_k |t_k|^2 g_k(lambda)^4] / [sum_k |t_k|^2 g_k(lambda)^2].(16)

For the usual smooth logarithmic labels, g_k(lambda)^2 is spread over
Theta(1/h) adjacent labels while |t_k|^2 changes slowly across that
window; the ratio is Theta(h), not 1. Thus the local first-success
indices disagree with probability tending to 1 as h->0, even though the
descriptions are identical. The *all-party* successful Kraus branch still
has a coherent sum over k, but its individual marginal events are not
aligned, so independent first-success selection does not retain that
branch. This pinpoints why simply adding more GHZ label legs to the
bipartite graph proof fails.

5. GHZ/MERMIN AND CENTRAL-SECTOR CHECKS

For the three-qubit GHZ+ vector
  psi=(|000>+|111>)/sqrt(2),
with local Pauli measurements, the Mermin expectations are

  <XXX>=1,  <XYY>=<YXY>=<YYX>=-1.                                (17)

With P_i=I, the projection sampler has q=1, Delta=0 and preserves all
four values exactly. With P_i=|0><0| on each party, again Delta=0;
the common branch is |000>, and the four Mermin expectations become 0.
This is correct for the *conditioned target* in (6), but shows that local
projection sampling does not preserve the unconditioned GHZ target without
an explicit vector-alignment premise.

For P_i=|+><+| on each party, the X-outcomes of GHZ+ are uniform on the
four even-parity strings. Hence q=1/4, r=0, Delta=3/4, and every pair has
mu_ij=1/2. The first-nontrivial-trial race succeeds unanimously with
probability q/(q+Delta)=1/4; the bound correctly reports that this is a
poor sampler. This is a finite exact stress case, not evidence for or
against the missing general construction.

For the central direct sum M=C^2 with uniform trace, write the standard
L2 vector psi=(|0>+|1>)/sqrt(2) and take every local projection to be
P_i=|0><0|. Then q=r=1/2, Delta=0; all players select the same first
sector-0 copy and timeout probability is 2^{-N}. The selected vector is
|0>. This shows how sampling across copies evades the fixed-H
trace-preserving-channel obstruction. For any TP map with Kraus operators
K_s in M and any central projection z,

  sum_s K_s* z K_s = z sum_s K_s*K_s = z,                        (18)

so the central expectation cannot move from 1/2 to 1. Equation (18) is
not an obstruction to the enlarged first-success POVMs (3).

6. EXACT ARBITRARY-VECTOR REACHABILITY OBSTRUCTION

There is no universal local-algebra-preserving *state-preparation*
sampler for arbitrary Hilbert-space description vectors. Let H=C^2,
psi=|0>, and A_i=C I for every party. Any local Kraus operator is a
scalar multiple of I, so every joint local branch is proportional to
|0>. It has zero fidelity with the supplied target |1>. Thus a vector
interface must either require that descriptions be locally generated
(for example, A_i psi with A_i in the named local algebra), or weaken its
claim to a finite correlation table for supplied local POVMs. The scalar
example is not a counterexample to a correlation sampler: scalar local
POVMs cannot distinguish |0> from |1>.

The center example above is a separate exact obstruction. Even when a
target vector lies in L2(M), a fixed-H TP local channel with Kraus inside
M cannot change central weights. Any valid generalization must use an
enlarged-resource correlation interface or a genuinely non-TP selected
branch, and must state how the bad branches are charged.

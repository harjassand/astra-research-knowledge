1. Final supported mathematical capability

On GGJ's displayed actual-stalk local-filling, cubical-mixing, local-transpose
exactness and degree-2/3 parameter hypotheses, an explicitly constructed
deterministic two-sector decoder receives only the noisy binary syndrome.
For any fixed desired physical Pauli contraction alpha in (0,1), it returns
a correction satisfying

 |e+f(syn(e)+m)|_stab-red,physical
 <= alpha |e|_stab-red,physical + beta |m|_syndrome-bits,

under fixed positive linear adversarial data/syndrome promises. It has
O(N) gates, constant graph depth, bounded fanout, and bounded code-star
communication neighborhoods, after O(N) member-specific preprocessing.
The finite local constants can be enormous. An O(N) sequential version
also gives the alpha=0 residual beta|m| by potential descent to termination.

Application to a constant-rate, linear-distance, constant-degree good-qLTC
family remains dependent on GGJ's source-reported construction and universal
product-expansion theorems. This work did not rebuild those foundations.
It therefore establishes an internally derived, source-dependent decoder
theorem and consequence, not an independently validated new good-code family.

The old missing T1--T4 interface is concretely discharged by v1 §§4--7.
No operational step copies unknown data, chooses a global tensor basis,
requires naturality of a local inverse, or calls a nearest-cocycle oracle.

observed syndrome, calls the explicit K local decoder, and reverses by
fixed cube contractions. Proof-only arrays are labeled as such.

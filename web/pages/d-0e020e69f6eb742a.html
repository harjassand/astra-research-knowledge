\section{Paper overview}
Let $v_1,\dots,v_n \in \rR^d$ be $d$-dimensional vectors and $\M = ([n],\I)$ be a matroid with bases set $\B \subset \I$ Our goal is to find $T \in \B$ such that $det\pr{\sum_{i\in T} v_i v_i^\top}$ is maximized. This problem is NP-hard in the most restrictive setting such as when $\M$ is a uniform matroid. So, we focus on approximation algorithms for the problem. In this paper, we design approximation algorithms using concave relaxations. That is, we solve the following program:
\begin{equation}\label{eq:generic_rel}
 \sup_{\bx \in P(M)} f(\bx)
\end{equation}
where $P(M)$ is the matroid bases polytope and $f(\bx)$ is a function such that for any integral point $\bx \in P(M)$, $f(\bx) \geq det\pr{\sum_{i=1}^n x_i v_i v_i^\top}$. We then design a rounding scheme which given a fractional point $\bx^* \in P(M)$, find an integral point $\bx' \in P(M)$ such that $det\pr{\sum_{i=1}^n x_i' v_i v_i^\top} \geq \alpha f(\bx^*)$.  This yields an $\alpha$-approximation algorithm if the rounding scheme is efficient and we can solve \eqref{eq:generic_rel} efficiently. A natural choice for $f(\bx)$ is $det\pr{\sum_{i=1}^n x_i v_i v_i^\top}$. Unfortunately, this gives a relaxation with unbounded integrality gap. Consider a partition matroid with partitions $P_1 = \{1\}, P_2 = \{2,3\}$ and vectors $v_1 = \begin{bmatrix} 0 \\ 0 \end{bmatrix}, v_2 = \begin{bmatrix} 1\\0\end{bmatrix}, v_3 = \begin{bmatrix} 0 \\ 1\end{bmatrix}$. Any integral solution would pick $v_1$ and either $v_2$ or $v_3$. Value of both of these solutions is zero. However, a fractional solution $x_1 = 1, x_2 = x_3 = \frac{1}{2}$ is in the matroid bases polytope and has non-zero value. This suggests that we require a stronger relaxation. Nikolov and Singh~\cite{NikolovS16} proposed one such relaxation based on the following observations:
\begin{itemize}
\item Cauchy-Binet formula shows that $det\pr{\sum_{i=1}^n x_i v_i v_i^\top} = \sum_{S \in {[n] \choose d}} x^S det\pr{\sum_{i \in S} v_i v_i^\top}$ where $x^S = \Pi_{i \in S} x_i$.
\item For any basis $T$ of the matroid, all subsets $S \subseteq T$ are independent. Hence, for any integral solution $\bx$, $x^S$ is non-zero only if $S$ is an independent set.
\end{itemize}
Based on these observations Nikolov \etal~\cite{NikolovS16} wrote the following relaxation:
\begin{equation}\label{eq:nikolovs_rel}
 \sup_{\bx \in P(M)} \inf_{\by \in \rR_+^n: \forall S \in \I_d, y^S \geq 1} \sum_{S \in {[n] \choose d}} x^S y^S det\pr{\sum_{i \in S} v_i v_i^\top} = det\pr{\sum_{i=1}^n x_i y_i v_i v_i^\top}
\end{equation}

\[ \sup_{\bx \in P(M)} \inf_{\by: \forall S \in \I_d, y^S \geq 1} x^S y^S det\pr{\sum_{i \in S} v_i v_i^\top}\]
where $\I_d$ is the set of independent sets of size $d$. This was inspired by a similar relaxation for permanent by Gurvits~\cite{Gurvits08}. Next, to design a rounding scheme we need the notion of a positively correlated distribution.

\begin{definition}
For a matroid $\M$ and $x \in P(\M)$, we say that a distribution $\mu \in [0,1]^\B$ is $(\alpha,d)$-positively correlated if for any independent set $S \in \I_d$,
\[ P_{T \sim \mu} [S \subset T] \geq \alpha\cdot x^S.\]
\end{definition}
\vivek{@everyone: Suggest a better terminology.}

If there exists an $(\alpha,d)$ positively correlated distribution, we can round the fractional solution of \eqref{eq:nikolovs_rel} to get an integral solution with value
\begin{align*}
E_{T \sim \mu} \left[ det\pr{\sum_{i \in T} v_i v_i^\top}\right] &= E_{T \sim \mu} \left[ \sum_{S \in {T \choose d}} det\pr{\sum_{i \in S} v_i v_i^\top}\right]\\
& = \sum_{S \in \I_d} Pr_{T \sim \mu} [S \subseteq T] det\pr{\sum_{i \in S} v_i v_i^\top}\\
& \geq \alpha \sum_{S \in \I_d} x^S det\pr{\sum_{i \in S} v_i v_i^\top}
\end{align*}
Nikolov and Singh~\cite{NikolovS16} showed the existence of $(1,d)$-positively correlated distribution for partition matroid of rank $d$. Using the theory of real stability, they further showed that for any $\bx \in \rR_+^n$ and partition matroid of any rank,
\begin{equation}\label{eq:nikolovs_main_result}
\sum_{S \in \I_d} x^S det\pr{\sum_{i \in S} v_i v_i^\top} \geq e^{-d} \inf_{y \in \rR_+^n: \forall S \in \I_d, y^S \geq 1} det\pr{\sum_{i =1}^n x_i y_i v_i v_i^\top}
\end{equation}
Again, this was an extension of the work by Gurvits~\cite{Gurvits08} on real stable polynomials. This result combined with $(1,d)$-positively correlated distribution for partition matroid of rank $d$ gives an $e^{-d}$-approximation algorithm for \Ddesign with partition matroid of rank $d$. In this paper, we show the existence of $(e^{-d},d)$-positively correlated distributions for partition matroid of any rank. This yields the following result:
\begin{theorem}
There exists an $e^{-2d}$ approximation algorithm for partition matroid of arbitrary rank.
\end{theorem}

Generalizing this result for arbitrary matroids hasn't been easy. There are two main issues. First issue is that unlike partition matroid, the generating polynomial for arbitrary matroid is not real stable and hence \eqref{eq:nikolovs_main_result} is not valid for arbitrary matroid. This is not hard to resolve. There have been a series of work generalizing the result for real stable polynomials to log-concave polynomials~\cite{AnariGV18,AnariLGV19}. From this work, we can relate the output of the rounding scheme to a different relaxation considered in \cite{AnariGV18} for optimization using the theory of log-concave polynomials. Anari \etal~\cite{AnariGV18} proved that for any matroid $\M$ and $\bx \in P(\M)$,
\begin{equation}\label{eq:cost_anarig_rel}
 \sum_{S \in \I_d} x^S det\pr{\sum_{i \in S} v_i v_i^\top}  \geq e^{-2d} \sup_{\alpha \in P(\M)} \inf_{y,z \geq 0} \frac{det\pr{\sum_{i=1}^nx_i y_i v_i v_i^\top}\pr{\sum_{S \in \I_d} z^S} }{\pr{\frac{\by\bz}{\alpha}}^\alpha}
\end{equation}
In this paper, we show that \eqref{eq:nikolovs_rel} is stronger than this relaxation. That is, for any matroid $\M$ and $\bx \in P(\M)$,
\begin{equation}\label{eq:anari_nikolov_rel}
\sup_{\alpha \in P(\M)} \inf_{y,z \geq 0} \frac{det\pr{\sum_{i=1}^nx_i y_i v_i v_i^\top}\pr{\sum_{S \in \I_d} z^S} }{\pr{\frac{\by\bz}{\alpha}}^\alpha} \geq
\inf_{\by \in \rR_+^n: \forall S \in \I_d, y^S \geq 1}det\pr{\sum_{i=1}^n x_i y_i v_i v_i^\top}
\end{equation}
Second issue in generalizing the result from partition matroid to arbitrary matroid is the fact that there does not exists a $(\alpha,d)$ positively correlated distribution where $\alpha$ is a function of $d$. More formally,
\begin{theorem}
For any function $g: \nN \rightarrow \nN$, there exists a matroid $\M$ and $\bx \in P(\M)$ which does not admit a $(g(d),d)$-positively correlated distribution.
\end{theorem}
This turned out to be significantly harder issue to resolve. We resolve it in two steps. First is a new algorithm showing the exists of a $(g(d),d)$-positively correlated distribution if the solution $\bx$ is sparse. Second, we show the existence of a sparse optimal solution.

\vivek{We need some text to emphasize that showing sparsity for our program is not easy.}

\begin{definition}
A solution $\bx \in P(\M)$ is said to be $\beta$-sparse if the number of fractional values is at most $\beta$. That is,
\[ |\{i \in [n]\mid 0 < x_i < 1\}| \leq \beta\]
\end{definition}

\begin{theorem}\label{thm:sparse_distribution}
For any matroid $\M$ and $2(d^2+d)$-sparse solution $\bx \in P(\M)$, there exists a $\left(e^{-1.5} (2e^3 d)^{-d},d\right)$-positively correlated distribution.
\end{theorem}

Next, to show sparsity of optimal solution we start by proving the optimality condition for $\inf_{y \in \rR_+^n:\forall S \in \I_d, y^S \geq 1} det\pr{\sum_{i=1}^n x_i y_i v_i v_i^\top}$.

\begin{theorem}Let $Y = \{ y \in \rR_+^n \mid \forall S \in \I_d, y^S \geq 1\}$.  For $x^* \in P(\M)$ and $y^* \in Y$,  let $X = \sum_{i=1}^n x_i^* y_i^* v_i v_i^\top$ and $w_i = x_i^* y_i^* v_i^\top X^{-1} v_i$ for $i \in [n]$. Let $\B^* = \{S \in \I_d \mid (y^*)^S = 1\}$ and $\M^*$ be the matroid with basis set $\B^*$. Then,
\begin{center}
$\by^* \in \argmin_{y  \in Y}  det\pr{\sum_{i=1}^n x_i^* y_i v_i v_i^\top}$ iff $\bw \in P(\M^*)$.
\end{center}
\end{theorem}

Now, suppose $(\bx^*, \by^*)$ is an optimal solution to  the relaxation \eqref{eq:nikolovs_rel} and $\M^*$ be as defined in the theorem above. If we can find a solution $\bx' \in P(\M)$ such that $\bw' \in P(\M^*)$ where $w_j' = x_j' y_j^* v_j^\top \pr{\sum_{i=1}^n x_i' y_i^* v_i v_i^\top}^{-1}  v_j$, then $\by^* \in \argmin_{y  \in Y}  det\pr{\sum_{i=1}^n x_i' y_i v_i v_i^\top}$. Moreover, if $\sum_{i=1}^n x_i' y_i^* v_i v_i^\top = \sum_{i=1}^n x_i^* y_i^* v_i v_i^\top$, then $(x',y^*)$ is an optimal solution to the relaxation \eqref{eq:nikolovs_rel} as well.

\begin{theorem}
Let $(\bx^*,\by^*)$ be an optimal solution to \eqref{eq:nikolovs_rel}. Let $\M^*$ be the matroid with basis set $\{ S \in \I_d \mid (y^*)^S = 1\}$. Let $\bx'$ be a solution to LP~\ref{fig:sparsify_lp}. Then, $(\bx',\by^*)$ is an optimal solution to \eqref{eq:nikolovs_rel}.
\end{theorem}

\begin{theorem}
Any extreme point of the polytope defined by LP~\ref{fig:sparsify_lp} has at most $2(d^2+d)$ fractional values.
\end{theorem}

From these two theorems, we can conclude that there exists a sparse optimum solution to \eqref{eq:nikolovs_rel}.

\begin{corollary}
There exists an optimal solution $(\bx',\by^*)$ to \eqref{eq:nikolovs_rel} such that
\[|\{i \in [n]\mid 0<x_i' < 1\}| \leq 2(d^2 + d).\]
\end{corollary}

Combining this corollary with Theorem~\ref{thm:sparse_distribution}, \eqref{eq:cost_anarig_rel}, and \eqref{eq:anari_nikolov_rel}, we get the main result of this paper:

\begin{theorem}
There exists a $e^{-1.5}(2e^5d)^{-d}$-approximation algorithm for \Ddesign with arbitrary matroid.
\end{theorem}


\begin{remark}
Results mentioned above by Gurvits~\cite{Gurvits08}, Nikolov \etal~\cite{NikolovS14}, and Anari\etal~\cite{AnariGV18} are not restricted to the \Ddesign problem but apply more generally to the real stable and log-concave polynomials.
\end{remark}

# Independent KMS gate: approximate conservation does not control secular leakage

## 1. Same bath, complete old logical algebra

Use a logical qubit L and a gauge qubit G. Let

    B=Z_L tensor X_G, H_delta=delta B,
    A=I_L tensor Z_G,
    O_X=X_L tensor I_G, O_Y=Y_L tensor I_G, O_Z=Z_L tensor I_G.

The Hermitian raw bath A has fixed support and norm1 and commutes with ALL three old logicals for every delta. The bare safe projector can be P=I, with Gibbs bad mass0. The bath input is held fixed; no jump operators are arbitrarily specified.

For delta>0 the actual spectral projectors are P_s=(I+sB)/2. Since {A,B}=0, the only components are J_s=P_s A P_(-s)=P_s A=(A+sBA)/2. With convention [H,A_omega]=-omega A_omega, J_- has omega=2delta and J_+ has omega=-2delta.

Use the SAME smooth bounded rate function

    gamma(omega)=2/[1+exp(-beta omega)], 0<gamma<2.

It satisfies gamma(-omega)=exp(-beta omega)gamma(omega). Hence gamma(2delta)+gamma(-2delta)=2, independently of beta, and both rates tend to1 as delta tends to0. At delta=0 the only spectral component is A0=A and gamma(0)=1. Equal rates1 for nonzero delta would fail finite-beta KMS; the logistic normalization is the exact correction.

## 2. Exact full-frequency leakage and decay

For O=O_X or O_Y, {B,O}=0 and [A,O]=0. Directly

    [J_s,O]=s BAO.

BAO is unitary, so C_s^*C_s=I. In the actual Gibbs state rho_delta=(I-tanh(beta delta)B)/4,

    k_plus(delta)=sum_s gamma(-2sdelta)
                         Tr rho_delta C_s^*C_s=2, delta>0.

Yet [A,O_j]=0 for all j, p_bad=0, and

    ||[H_delta,O_X]||_(rho_delta,2)
       =||[H_delta,O_Y]||_(rho_delta,2)=2delta ->0,
    [H_delta,O_Z]=0.

At delta=0 every full-frequency logical commutator is zero. There is no vanishing universal bound on k_plus from the approximate Gibbs Hamiltonian commutators and bare-bath protection. The discontinuity comes from spectral resolution, not a nonsmooth or unbounded rate function.

For completeness J_s^*J_s=P_(-s), J_s^* O J_s=0, and {P_(-s),O}=O. Each normalized dissipator therefore has adjoint action -O/2. The KMS-weighted sum has EXACT action

    D_delta^*(O_X)=-O_X, D_delta^*(O_Y)=-O_Y,
    D_delta^*(O_Z)=0, delta>0.

At delta=0 D[A]^*(O_j)=0. If K=Y_L tensor X_G, the full Heisenberg equations are O_X'=-O_X-2delta K and K'=-K+2delta O_X. Thus O_X(t)=exp(-t)[cos(2delta t)O_X-sin(2delta t)K]. For a bare logical state tensor a maximally mixed gauge, the X expectation tends to exp(-t) times its initial value as delta tends to0+, whereas at delta=0 it is conserved. This is order-one decay of the specified old observable at fixed times.

## 3. Scope and what the obstruction does not prove

The two-qubit example is not the BDL code and proves no generic thermal-memory failure. Indeed X'_L=X_L tensor Z_G and Z'_L=Z_L tensor I_G form a DIFFERENT exact logical pair commuting with both H_delta and A. The example specifically refutes acquisition of SMALL full-frequency leakage for the approximately conserved OLD algebra from bare commutation and a Gibbs bad-mass estimate. A different exact factor may preserve memory, but it is not a perturbatively close acquisition here.

The earlier cycle14 source-based interior-edge example separately proves a Davies degeneracy-splitting discontinuity with actual BDL support. Neither substitutes arbitrary jumps. A proposed full-density transverse-field Gibbs witness tail still needs an exact/model-specific full-frequency bridge, or a clustered finite-resolution generator with paid resolution and time errors. An exponentially small logical splitting can trigger the same infinite-resolution mechanism; replacing delta by an arbitrarily small function of system size does not change k_plus.

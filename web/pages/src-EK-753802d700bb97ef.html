# C5 — Can global group constraints be reduced to computable holonomy?

**Status: strong operational theorem found; novelty rejected.** The best candidate is a useful exact local-to-global reduction, but its core is the classical fundamental-cycle criterion for gain graphs. A more ambitious universal claim is blocked by the undecidable word problem. This report does not claim a new theorem.

## 1. North Star

Find a representation of coupled local equations whose obstruction to global realizability is both (a) complete and (b) computable from a small, explicit witness. The hoped-for primitive would replace search over all vertex states with a finite set of gauge-invariant residuals, and expose exactly which representation assumptions make the computation possible.

## 2. Exact question

Let a finite oriented graph $G=(V,E)$ carry labels $g_e\in H$, where $H$ is a group and reversing an edge replaces its label by $g_e^{-1}$. Decide whether there are vertex potentials $x_v\in H$ satisfying

\[
  g_{u\to v}=x_u^{-1}x_v\qquad\text{for every oriented edge }u\to v.
\]

Can one transform this global feasibility problem into a complete, operational certificate whose time, memory, and output are charged in the input representation of $H$? The key boundary is whether equality-to-identity in $H$ is an effective operation.

## 3. Why it matters

This is the cleanest possible test case for the broader ambition: pairwise constraints are local, while a shared assignment must satisfy every cycle. If a residual invariant turns all-cycle consistency into $m-n+c$ checks, the number of group assignments — potentially $|H|^{n-c}$ — disappears. The same question arises in synchronization, discrete geometry, network reconstruction, and representations of graph fundamental groups. It also exposes a resource-accounting trap: “linear time” can silently assume a unit-cost identity oracle.

## 4. Obstruction and early examples

For a closed walk $C=e_1^{\epsilon_1}\cdots e_k^{\epsilon_k}$, define its ordered holonomy as the corresponding ordered product of labels. If vertex potentials exist, telescoping forces every closed-walk holonomy to be the identity. Conversely, on a connected graph, choose a spanning tree and propagate potentials from a root; every non-tree edge then supplies one fundamental-cycle residual. The noncommutative order matters.

A triangle already separates local satisfaction from global satisfaction. With $g_{1\to2}=1$, $g_{2\to3}=1$, and $g_{3\to1}=a\ne1$, each edge constraint can be satisfied separately, but the cycle product is $a$, so no common vertex potentials exist.

A length-$n$ cycle with all labels $1$ except one label $a\ne1$ has no obstruction on any proper edge subset: deleting one edge leaves a forest, and all forest equations can be integrated. Thus an edge-list certificate may require all $n$ edges. This is an exact lower bound on witness length, not a defect of the spanning-tree algorithm.

A binary cycle-space basis is not a sound replacement for ordered group holonomies. Rybnikov and Zaslavsky's explicit counterexample is one vertex with one loop $e$, gain group $C_k$ for odd $k\ge3$, and loop gain a generator $a$. The binary basis is $\{e\}$, but the closed-walk lift $e^k$ has gain $a^k=1$. The basis test passes even though the simple loop has nonidentity gain $a$. Mod-2 support has erased precisely the multiplicity that detects the obstruction.

The locality barrier is visible even in $C_2$. On an $n$-cycle, impose $x_{i-1}\oplus x_i=b_i$ at each vertex, with $\bigoplus_i b_i=1$. Multiplying all equations gives $0=1$, but every proper subset of the vertex equations is a forest and is satisfiable. Uniform distributions on the two satisfying pairs at each vertex agree on each shared one-variable overlap, yet no global distribution can satisfy all constraints. Any bounded local patching rule with range below $n$ misses this example.

Finally, for arbitrary finitely presented groups given by generators, relators, and edge-label words, even the one-vertex, one-loop instance asks whether one word is the identity. By Novikov–Boone, this word problem is undecidable for some finite presentations. A universal algorithm cannot be obtained merely by writing down cycle products; an effective equality representation must be supplied and charged.

## 5. Missing capability

The tempting primitive is **tree integration plus chord residuals**. For each component, choose a root and a spanning tree $T$; set $p_r=1$, then for a tree edge $u\to v$ set $p_v=p_u g_{u\to v}$. For every oriented edge $e:u\to v$, compute

\[
  r_e=p_u g_e p_v^{-1}.
\]

For tree edges, $r_e=1$ by construction. For a non-tree edge, $r_e$ is the holonomy around its fundamental cycle, up to the chosen orientation convention.

**Theorem (classical, reconstructed).** The potential system is solvable iff every non-tree residual is the identity. If solvable, $x_v=p_v$ is a solution. If some residual is nonidentity, its tree path plus chord is an explicit inconsistent-cycle witness. The solution, when it exists, is unique up to one common left multiplication per connected component.

*Proof.* A solution makes every cycle product telescope to identity, so each residual is identity. Conversely, if every residual is identity, then every edge, including each chord, satisfies $g_{u\to v}=p_u^{-1}p_v$; hence $p$ is a global solution. For uniqueness, if $x$ and $y$ both solve the system, $y_vx_v^{-1}$ is constant along each edge and therefore on each connected component.

This is a genuine operational reduction but not a missing capability: a spanning forest has $n-c$ edges, leaving $m-n+c$ residual checks, where $c$ is the number of components. Arbitrary non-fundamental cycle bases are not interchangeable with this construction in nonabelian groups.

## 6. Actual original investigation and result

I derived the tree-integration equivalence above, checked its noncommutative order convention, worked through the inconsistent triangle, and established the long-cycle lower bound on explicit witness length. I then tested two likely novelty routes:

1. **Replace fundamental cycles by a generic binary-cycle basis.** Rejected by the odd-order single-loop example; this exact failure has been studied and classified in the gain-graph literature.
2. **Use bounded local marginals as a universal gluing representation.** Rejected by the odd-parity cycle: every proper constraint patch and every overlap marginal is consistent while the whole system is not.

The decisive representation check is the word-problem reduction. With an arbitrary finitely presented group and a one-loop graph labelled by word $w$, “balanced?” is exactly “does $w=1$?” Hence no uniform computable holonomy operation exists over that input class. If $H$ is a finite group with an explicit multiplication table, or a represented group with decidable equality and computable multiplication, the tree algorithm works in the corresponding oracle/bit-cost model. The capability is then the supplied group arithmetic, not a discovered duality.

## 8. Bit, memory, and output costs

Let $m=|E|$, $n=|V|$, $c$ be the number of components, and $L=\sum_e |g_e|$ the encoded label length. In a group-oracle model, the algorithm uses $O(m)$ multiplication/inversion operations and $m-n+c$ identity checks. It stores $O(n)$ potentials in addition to the graph input. It can stream residual checks and stop at the first failure. A single explicit witness contains one chord and its tree path, at most $n$ edges, and its label data is bounded by the labels on that path.

These are operation counts, not universal bit bounds. With a finite group table, operations and equality are constant-time lookups only after charging for the table (up to $\Theta(|H|^2)$ entries). With word encodings, multiplication can concatenate words and simplification can dominate; equality may be undecidable. For matrix or algebraic-number encodings, multiplication and exact equality have representation-specific costs. If all residuals or all cycle witnesses must be output, output size can be $\Theta(m)$ elements and total encoded size must be charged. Any claimed linear-time global solver must name the group encoding and account for equality.

## 9. Decisive next step

**Stop this candidate as a novelty claim.** The exact positive theorem and its natural noisy and higher-order extensions already have primary literature, while the fully universal computational version is impossible without restricting the group representation. Continue only if a separately specified application supplies an effective group representation and asks a new question that the fundamental-cycle test does not answer—for example, a concrete noise/corruption model with a recovery guarantee that beats the best cycle-consistency baseline under the same measurements and cost accounting. Otherwise pivot to a different primitive-genesis question.

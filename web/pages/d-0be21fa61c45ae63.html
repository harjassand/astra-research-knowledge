# Finite acquisition interface, complete charges and competent controls

7 October2026. This ledger distinguishes the elementary universal derivations from executed finite probability calculations. No supplied representation, noise law, query oracle, regularity bound or experiment is called acquired for free.

## C1. Bellman input and actual output

Input: a finite query set of size r; p supplied hypotheses evaluated at those queries as a rational r-by-p matrix A; a fixed postprocessor and its rational evaluation table B; horizon n; rational objective multipliers target and factor. The joint scores s,t begin at0. A legal query is selected from the PAST sign prefix, then a fresh independent fair sign updates s by epsilon A[q] and t by epsilon B[q]. At the end the payoff is target max(t)-factor max(s).

The value recursion is

    V(0,s,t)=target max_j t_j-factor max_j s_j,
    V(h,s,t)=max_q {V(h-1,s-A[q],t-B[q])
                       +V(h-1,s+A[q],t+B[q])}/2.

Induction on h proves it is exactly the optimum over all predictable finite query trees. The two branches are averaged AFTER choosing q, so a source anticipating the fresh sign is not legal. Finite maximizers exist. Caching identical(h,s,t) states is valid because future signs are independent and the input tables/cost are fixed.

The output retains EVERY query alternative at every state, its two earlier child IDs and exact mean, the maximizing query, all rational scores, the full chosen-prefix tree and every leaf's actual query transcript. The released checker reconstructs the six DECLARED fixture inputs independently, checks all state equations and alternatives, enforces reachability/topological IDs, and re-evaluates every leaf from the same prefix policy. It checks a finite acquired policy AND optimality for that particular supplied finite table. The fixture whitelist is deliberate; it is not a generic trusted-library oracle or an arbitrary scientific-grammar verifier. The Bellman kernel itself accepts other rational tables, but their acquisition/operator validation is a separate obligation.

Two exact ordinary controls optimize the source and sign-negated classes separately on the identical table/horizon. Their optima agree, as the universal policy-sign-reflection identity predicts. Reusing the optimum while changing the tree would be an invalid acquired-policy comparison; the emitted transcripts prevent that mistake. A signed-class control and the frozen short-horizon clipped symmetric search both return factor1 violation0. The clipped NULL is retained and does not settle the recent logarithmic lower bound on other classes/horizons.

## C2. Total complexity and denominator bounds

Let b bound the input numerators/denominators' bit lengths. Use Q as a common denominator for both rational tables. Obtaining Q by LCM is paid, with log2 Q<=2rp b; it is not the largest individual denominator. Add the two objective denominators to obtain Q1. Every score lies on the1/Q grid, and each h-step value has denominator dividing Q1 times2^h. If C bounds table magnitudes and M bounds the objective multipliers, all scores are bounded by nC and values by2nCM. Thus an unreduced height bound

    B=O(log Q1+n+log(nCM+1))

controls every persistent rational value. Fraction reduction can only shorten this bound. The proof is an exact finite-bit statement about supplied rational evaluations; computing arbitrary transcendental operator values exactly is outside the input interface.

Write Vstates for the actual number of cached states. A coarse universal bound is sum_(t=0)^n(2r)^t, exponential in n. Exact source/transformed score updates and branch means cost O(Vstates*r*p) rational operations. Terminal maxima add O(Vstates*p) comparisons; query maxima add O(Vstates*r) comparisons; weighted terminal objectives add O(Vstates) operations. Hashing/storing scores, dictionary lookup, rational gcd/reduction, comparing fractions, allocation and serialization have additional polynomial bit work in p,B and log Vstates. A balanced exact map yields an explicit extra log Vstates factor if a worst-case map guarantee is desired. No unit-cost claim for big integers is made.

The recorded counter `charged_scalar_updates_and_mean_operations` covers precisely the score additions and branch mean addition/division; it is NOT a counter of every arithmetic instruction. The terminal/query comparisons, hash/cache bookkeeping, leaf replay and IO are included in observed wall time and charged by the displayed bound, not silently folded into that partial counter.

Storing the Bellman graph costs O(Vstates[pB+r(B+log Vstates)]) bits up to format overhead. This executable ALSO emits2^n-1 chosen query nodes and2^n leaves, paying O(2^n[n log(r+1)+pB+log Vstates]) bits, plus repeated prefix strings. Compact policy automata are possible for the special one-hot construction, but a compact automaton is not substituted for the actual emitted bytes of these fixtures. JSON byte counts are retained for each case.

## C3. Probability calculations versus physical/learning runs

The reflected-policy fixed-horizon and variable-cost artifacts are exact probability recursions. They integrate all virtual sign histories; they are not external experiments executing1024 physical queries. For n1024 the largest reflected recursion uses1537 active states and1,572,864 integer additions; its integer weights have at most n+1 bits. The independent checker uses a separate reflection/Ballot formula, not the producer's state recursion. Budget64 computations use three supplied predictable cost laws; exact stopping distributions, expected observations and spent costs are retained. The checker instead evolves spent/S/running-maximum states and checks bounded optional stopping.

The five constant-class offset cases integrate a Binomial(n,1/2) law through n+1 exact terms, including the n4096,eta1/32 small-eta case. Integer binomial coefficients have at most n+1 bits; weighted sums and reduced rational final results are charged at that height and the supplied rational eta/n denominators. Computing this expectation is certificate/audit work. A learner does not need the binomial table: proper discrete ERM and the competent sample-mean/star control each need one pass through n supplied labels. Both receive the same labels/library. The mean-zero population is used for evaluation, not given to either as an oracle. No new learning algorithm or performance superiority is claimed.

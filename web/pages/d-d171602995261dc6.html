REACTION DYNAMICS — CYCLE 3, LEAF 04
HIGH-BOUNDARY TIER AUDIT FOR THE GENERALIZED REVERSIBLE FAMILY
Date: 2026-10-08

STATUS AND RESULT

INTERNALLY-PROVED-CANDIDATE: for the finite complete family

  0 <-> A_j,
  A_j <-> A_j+B_i,
  A_j+B_i <-> (k_{ji}+1)A_j+B_i,

with m,n>=1, integer k_{ji}>=1, and strictly positive finite mass-action
rate constants on every directed reaction, the state space is one
irreducible communicating class, namely Z_{>=0}^{m+n}. In particular, every
boundary sequence with all A_j=0 and at least one B_i tending to infinity is
reachable from every nonabsorbing initial state. On the face with exactly one
B_i diverging and all other B_l bounded, the deterministic top tier consists
exactly of A_j+B_i and (k_{ji}+1)A_j+B_i for all j, while the stochastic top
tier is {0}. Thus ACK Theorem 6.1's tier-inclusion premise fails, for every
x_0, on a proper tier sequence in its reachable class.

This is a failure of a sufficient theorem premise, not a counterexample to
positive recurrence. The network has one stochastic class, so this finding is
not a cross-class stationary-escape construction. The exact general rule for
every boundary/tie stratum is: along a proper integer tier sequence, stochastic
tiers are the deterministic tiers restricted to eventually enabled source
complexes; therefore T^{S,1} is contained in T^{D,1} iff the deterministic
top tier contains at least one eventually enabled complex. The target
all-A-zero face has no enabled deterministic-top complex, regardless of k or
the relative growth/ties among the B coordinates.

MODEL, STOICHIOMETRY, AND REACHABILITY

Let j range over {1,...,m} and i over {1,...,n}; assume every displayed pair
is present. Write e_{A_j}, e_{B_i} for the coordinate vectors. The reaction
vectors include e_{A_j} from 0->A_j and e_{B_i} from A_j->A_j+B_i. Hence
the stoichiometric subspace is all R^{m+n}; there is no nontrivial linear
conservation law, and the nonnegative lattice is one stoichiometric class.
The complex graph is connected through 0<->A_j and A_j<->A_j+B_i; each
displayed edge is reversible, so the network has one weakly reversible
linkage class. Every state is nonabsorbing because each 0->A_j propensity is
positive.

Communication can be proved by an explicit finite path, without any
non-explosion assumption. Fix j_0. From any state, use 0->A_{j_0} if needed
to make A_{j_0}>=1. While holding A_{j_0} fixed, use
A_{j_0}<->A_{j_0}+B_i to adjust each B_i by unit steps to its target count;
the backward direction is enabled exactly when B_i>=1. Then use
0<->A_j to adjust each A_j to its target count. The prescribed finite path
has positive embedded-chain probability because every selected transition
has positive finite rate at each visited state. Thus every state communicates
with every other, including (0,...,0,B_i=N, B_{l!=i}=c_l), for every finite
N and every fixed c_l>=0. The same argument works from any x_0, so the
sequence used below belongs to every reachability set S_{x_0}.

ACK TIER DEFINITIONS AND THEOREM QUANTIFIER

For a source complex y and lattice state x, put

  lambda_y(x)= product_r (x_r)_{underline(y_r)},
  delta_y(x)= (x vee 1)^y.

The stochastic tier ordering is by lambda_y; the deterministic ordering is
by delta_y. A proper tier sequence for X started at x_0 has x_n in S_{x_0},
each coordinate converges in [0,infinity], at least one coordinate diverges,
and both tier partitions exist. ACK Theorem 6.1 states that for a weakly
reversible mass-action network with one linkage class, if

  T^{S,1}_{ {z_n} } subset T^{D,1}_{ {z_n} }

for every proper tier sequence {z_n} of that particular chain X started at
x_0, then X on S_{x_0} is positive recurrent. The premise is class/reachability
specific; it is not a uniform tightness or uniform return-time conclusion over
different classes or initial conditions. Here all x_0 have the same full
reachable class, and the failure below is in that one class.

EXACT CALCULATION ON THE ALL-A-ZERO FACE

Take x_n=(0,...,0,b_1(n),...,b_n(n)), with at least one B coordinate
diverging. Define beta_i(n)=max{b_i(n),1}. For every source complex,

  delta_0(x_n)=1,
  delta_{A_j}(x_n)=1,
  delta_{A_j+B_i}(x_n)=beta_i(n),
  delta_{(k_{ji}+1)A_j+B_i}(x_n)=beta_i(n).

The equality of the last two values is exact: the A_j factor is
(0 vee 1)^{k_{ji}+1}=1. Thus k_{ji} does not split their deterministic tier.

In contrast, the source factorial propensities are

  lambda_0(x_n)=1,
  lambda_{A_j}(x_n)=0,
  lambda_{A_j+B_i}(x_n)=0,
  lambda_{(k_{ji}+1)A_j+B_i}(x_n)=0.

Therefore T^{S,1}={0}, and every other source belongs to the all-zero
stochastic tier. This does not depend on how large any B_i is.

If exactly B_q diverges and b_l(n)=c_l is fixed for l!=q, then the deterministic
tiers are exactly

  T^{D,1} = { A_j+B_q, (k_{jq}+1)A_j+B_q : 1<=j<=m },

  T^{D,2} = {0, A_j : 1<=j<=m}
           union { A_j+B_l, (k_{jl}+1)A_j+B_l : 1<=j<=m, l!=q }.

All members of T^{D,1} tie exactly at monomial value b_q(n) (eventually
b_q(n)>=1); all members of T^{D,2} have monomial values bounded above and
below by positive constants. Hence 0 is strictly below D-top, and
T^{S,1} is not a subset of T^{D,1}.

This remains true for every tie pattern if several B_i diverge. Group diverging
indices into asymptotic growth blocks under i~h iff beta_i/beta_h tends to a
finite strictly positive limit; order the blocks by asymptotic dominance.
For each block, the corresponding A_j+B_i and high complexes form one D tier
for each j, with all j tied when the A coordinates are identically zero.
The maximal block is T^{D,1}; slower divergent blocks give lower D tiers, and
all bounded-B source complexes tie with 0 and the A_j in the bottom D tier.
The stochastic tier partition is still {0} followed by all unavailable
complexes, so every such proper sequence fails the inclusion. In particular,
whether two B coordinates are asymptotically tied, one dominates another, or
one is bounded does not rescue the premise. If every B coordinate is bounded,
the sequence is not proper and creates no ACK test case.

COMPLETE TIE/BOUNDARY CRITERION, INCLUDING NEARBY STRATA

The following exact lemma covers all proper tier sequences, not just the
requested face. Since coordinates are integer-valued and converge in
[0,infinity], each coordinate with finite limit is eventually equal to that
integer; a diverging coordinate is eventually above every fixed source
exponent. Let E be the set of source complexes eventually enabled, y<=x_n.
For y in E,

  lambda_y(x_n)/delta_y(x_n)
    = product_r (x_{n,r})_{underline(y_r)} /
                    (max{x_{n,r},1})^{y_r}
    -> c_y in (0,infinity).

For y not in E, lambda_y(x_n)=0 eventually. Therefore two enabled sources
are in the same S tier exactly when they are in the same D tier, and the S
tiers are obtained by deleting disabled sources from the ordered D tiers.
The S-top tier is the first D tier that contains an enabled source. In this
network it is nonempty because 0 is always enabled. Consequently

  T^{S,1} subset T^{D,1}
    iff T^{D,1} intersect E is nonempty.

This is an exact test of every tie stratum: compare the finitely many D-top
complexes, including all positive-finite-ratio ties, with their eventual
availability. A proper sequence fails precisely when every source in its
deterministic top tier is disabled.

For this network the deterministic weights at an arbitrary sequence
x_n=(a(n),b(n)) are explicitly

  delta_0=1,
  delta_{A_j}=alpha_j,
  delta_{A_j+B_i}=alpha_j beta_i,
  delta_{(k_{ji}+1)A_j+B_i}=alpha_j^(k_{ji}+1) beta_i,

where alpha_j=max{a_j,1} and beta_i=max{b_i,1}. The source availability
conditions are, respectively: always; a_j>=1; a_j>=1 and b_i>=1; and
a_j>=k_{ji}+1 and b_i>=1. These formulas plus the criterion above give the
pass/fail answer for every growth/tie/boundary stratum, without presuming all
A coordinates are bounded.

Useful explicit neighboring cases:

1. If each a_j(n) is bounded (hence eventually a fixed a_j) and at least one
   B coordinate diverges, let I_1 be the maximal B-growth tie block. If some
   a_j>=1, then A_j+B_i is enabled and D-top for every i in I_1; any enabled
   high source tied there is also in D-top. Thus T^{S,1} is a nonempty subset
   of T^{D,1}. If all a_j=0, this reduces to the failing face above.
   Inclusion does not require every D-top complex to be enabled.
2. If a_j(n)->infinity for some j and all B_i=0, then for that j the
   deterministic high complexes grow as a_j^(k_{ji}+1), while their
   stochastic propensities are zero. The largest k_{ji} values determine
   D-top ties for this j (and other diverging coordinates can add further
   ties); A_j itself is enabled with propensity a_j but has lower D order.
   The top-inclusion premise fails. This shows that failure is not confined
   to the all-A-zero face.
3. With diverging A coordinates and some positive B coordinates, the result
   can depend on the exact k_{ji} and on which B coordinates are enabled:
   compare alpha_j^(k_{ji}+1) beta_i across all j,i, then test whether the
   maximizing tied complexes satisfy their source availability conditions.
   The formula above is the complete answer; no blanket pass assertion is
   valid for this stratum.

CLASSWISE VERSUS CROSS-CLASS QUANTIFIERS

ACK 6.1 is a per-reachability-class sufficient implication: fix x_0, verify
the top-tier inclusion on every proper sequence reachable from x_0, and then
obtain positive recurrence on that class. It supplies neither a common compact
for stationary laws over classes nor a bound uniform in x_0. Here there is
only one communicating class; the counterexample to the premise is a
within-class boundary sequence. It says nothing by itself about recurrence.

This is distinct from N77's supplied summary: N77 reports infinitely many
positive-recurrent stochastic classes Gamma_n inside the same linear plane
B+C=2, with nonlinear invariant A-B(B+1)/2=n and stationary laws escaping
as n grows. That is a cross-stochastic-class failure of uniform tightness
inside one deterministic compatibility class. The full N77 proof packet was
not supplied in the card, so its status remains SOURCE-REPORTED here. The
cycle-2 two-species example is weaker in a different way: its classes have
different conserved totals A+B=N. Neither construction is being reused as a
proof of the present tier calculation.

N33's deterministic permanence statement is classwise, with a compact
absorber and bounds depending on the positive deterministic compatibility
class and an entry time depending on x_0; it does not provide cross-class
uniformity or stochastic stationary tightness. N35 is an acquired-certificate
finite-horizon exit bound, not infinite-time recurrence. N34 likewise
distinguishes a local certificate from recognition of global absorption on
an unbounded class. These scopes are compatible with the present result.

As a basic sufficient rescue for a family of stationary laws in unscaled
molecule counts, a common bounded envelope for all states in all classes
trivially gives uniform tightness (the lattice intersection is finite). A
uniform bound on conserved totals can provide such an envelope when the
stoichiometric geometry is bounded in the relevant coordinates. Finite
dimension, a fixed linear conservation plane, or polyhedrality alone do not:
the N77 plane is unbounded in A and contains the reported escaping family.
Any nontrivial rescue needs an actual common stochastic Lyapunov/compactness
bound or stronger control of the stochastic class index. The present network
has full stoichiometric rank, so no conservation polytope can control its
single full-lattice class.

INPUTS, COSTS, AND FALSIFIERS

Supplied: the finite complete reaction family and ACK's tier definition and
Theorem 6.1. Assumed explicitly: m,n>=1, integer k_{ji}>=1, positive finite
rates, and standard stochastic mass action with falling factorials. The
symbolic argument takes O(mn) source formulas and no search, precision,
oracle, or simulation cost. The LP diagnostic is exact rational arithmetic
on four complexes in dimension two and is not used as a theorem.

Direct falsifiers/interface changes: if a required A_j<->A_j+B_i pair is
missing, the reachability argument for that B_i must be revisited; if any
rate is zero, communicating classes can change; if the stochastic propensities
are not falling-factorial mass action or ACK's deterministic tier uses a
different regularization than (x vee 1)^y, the tier calculation must be
repeated. Under the stated interface, one can falsify the report by finding
an enabled nonzero source at all-A=0, or by showing 0 is D-top when some B_i
diverges; both contradict the displayed exact formulas.

The failure of the sufficient condition is not a claim of transient,
null-recurrent, or explosive behavior. At the all-unit rate choice, c=1 is
complex balanced edge by edge: both directions of each reversible pair have
complex flux 1. The standard product-form law is then

  pi(x)= product_{r=1}^{m+n} e^{-1}/x_r!.

The established complex-balanced non-explosion result makes this a genuine
stationary law for the irreducible CTMC and gives positive recurrence for
that rate choice. Thus the tier gate can fail while recurrence holds. No
arbitrary-rate recurrence claim is made here. The decisive next step for this
family is to use the finite criterion above to partition all proper strata
by top-tier enabledness, then seek an independent recurrence/nonrecurrence
argument for any parameter regime where the ACK gate fails.

CYCLE09 STATIONARY PETZ PRIOR-ART AUDIT
Status: bounded primary-source comparison; priority and candidate theorem status UNKNOWN.

Question audited
----------------
Let B be finite dimensional, let sigma_B be faithful, and let Phi:B->B be CPTP with Phi(sigma)=sigma. Write

  Phi^sharp(X)=sigma^(1/2) Phi^*(sigma^(-1/2) X sigma^(-1/2)) sigma^(1/2).

For a joint state rho_RB with rho_B=sigma, set

  D = D(rho_RB || rho_R tensor sigma_B) = I(R:B)_rho,
  b = (1/2)||rho_RB-(id_R tensor Phi)(rho_RB)||_1.

The target interface is a dimension-free (or specified polynomial) control of

  (1/2)||rho_RB-(id_R tensor Phi^sharp Phi)(rho_RB)||_1

from D<=C and b, using one fixed unrotated Petz map Phi^sharp determined by (Phi,sigma), uniformly over references R and all eligible rho. This audit found no identified primary theorem with that exact premise, map, and conclusion. This is a bounded search outcome, not a novelty or priority claim.

Closest exact imported theorem: universal rotated-Petz recovery
---------------------------------------------------------------
Junge, Renner, Sutter, Wilde, and Winter, “Universal recovery maps and approximate sufficiency of quantum relative entropy,” arXiv:1509.07127v3 (7 Aug 2018), Ann. Henri Poincare 19 (2018), 2955-2978, DOI 10.1007/s00023-018-0716-0. Primary source: https://arxiv.org/abs/1509.07127, v3 HTML https://arxiv.org/html/1509.07127v3.

Theorem 2.1 and Remark 2.2, Eqs. (17)-(21), state for states rho,sigma with the stated support condition and any CPTP N that

  D(rho||sigma)-D(Nrho||Nsigma)
    >= -2 log F(rho, (Rbar_{sigma,N} N)(rho)),

where Rbar is the beta_0-weighted average of rotated Petz maps, beta_0(t)=(pi/2)(cosh(pi t)+1)^(-1). Rbar depends on (sigma,N), not on rho. It is a single recovery channel but generally a rotated-map average, not the unrotated Petz map.

There is a useful exact specialization. Put N=id_R tensor Phi and omega=rho_R tensor sigma_B. Then N(omega)=omega and

  D(rho_RB||omega)-D(Nrho_RB||Nomega)
    = I(R:B)_rho-I(R:B)_{N(rho)}.

Because the reference and channel are product-local, direct substitution in the Petz formula makes each rotated map factor as id_R tensor a B-channel determined by (Phi,sigma); the rho_R modular factors cancel through id_R. The averaged map is therefore one fixed map on B across eligible rho_RB, despite the reference omega varying with rho_R. The theorem consequently gives a very close fixed-map recovery result if the mutual-information loss is small. It does not infer that loss from b, and it controls the rotated average composed with Phi, not Phi^sharp Phi. No modular-covariance assumption was supplied that would identify the average with the unrotated Phi^sharp.

This is the closest antecedent found: it matches the product-reference geometry and can supply one common recovery channel, but the controlling quantity and the recovery map differ at the precise gate.

Other exact interfaces and limits
---------------------------------
1. Sutter, Fawzi, and Renner, “Universal recovery map for approximate Markov chains,” arXiv:1504.07251v3 (23 Sep 2015), Proc. R. Soc. A 472 (2016), 20150623, DOI 10.1098/rspa.2015.0623. Primary source: https://arxiv.org/abs/1504.07251, v3 HTML https://arxiv.org/html/1504.07251v3. Theorem 2.1 gives, for each rho_ABC, a CPTP recovery R_{B->BC} with I(A:C|B)_rho >= -2 log_2 F(rho_ABC,R(rho_AB)); the map can be fixed for extensions sharing the specified marginal in the paper's universal formulation. Corollary 2.4 and Remark 2.5 describe a rotated/swiveled-Petz representation. The premise is conditional mutual information and the map reconstructs a tripartite extension from a marginal; this is not the stationary-channel trace residual b or the map Phi^sharp Phi. Appendix F's 2x2x2 example says the transpose map is not square-root optimal for a fidelity comparison. The authors explicitly note it does not establish failure of the main fidelity inequality for the Petz map. It is not a counterexample to the candidate here.

2. Brandao, Harrow, Oppenheim, and Strelchuk, “Quantum Conditional Mutual Information, Reconstructed States, and State Redistribution,” arXiv:1411.4921v4 (2 Jun 2016), PRL 115, 050501 (2015), DOI 10.1103/PhysRevLett.115.050501. Primary source: https://arxiv.org/abs/1411.4921, v4 HTML https://arxiv.org/html/1411.4921v4. Theorem 1, Eqs. (6a)-(6d), lower-bounds CMI by an asymptotic regularized ordinary relative-entropy reconstruction cost and by a one-shot minimum measured-relative-entropy reconstruction cost. The one-shot term optimizes over recovery channels Lambda; it is not a fixed transpose/Petz channel. The discussion after Eq. (9), including Eq. (19), reports 2x2x2 numerical pure-state examples in which reconstructed relative entropy for the transpose channel is strictly below CMI for about 73% of 10,000 samples. This refutes an equality/optimality comparison, not the stated lower bound for optimized maps, and it supplies neither the b-to-loss bridge nor the candidate trace-norm bound.

3. Salzmann, Bergh, and Datta, “Robustness of Fixed Points of Quantum Channels and Application to Approximate Quantum Markov Chains,” arXiv:2405.01532v1 (2 May 2024). Primary source: https://arxiv.org/abs/2405.01532, v1 HTML https://arxiv.org/html/2405.01532v1. Definition 3.1 measures approximate fixedness by half trace distance and channel perturbation by half diamond distance. Theorem 5.1 states that if a state rho and a channel N on a separable Hilbert space obey (1/2)||N(rho)-rho||_1<=epsilon, there exist a state sigma and channel M with (1/2)||sigma-rho||_1<=sqrt(epsilon) and (1/2)||M-N||_diamond<=sqrt(epsilon). This repairs the pair by changing both state and channel; it does not control a Petz reverse of the original channel. Proposition 4.2 gives closeness to a quantum Markov chain from small CMI with an unspecified dimension-dependent function. Theorem 7.2 shows lack of rapid simultaneous fixing for two approximate fixed points in the local-channel setting. These results explain why “approximate fixed point repair” is adjacent but not the same quantifier or object as exact sigma-stationarity plus one fixed Petz round trip. Since the present setup already assumes Phi(sigma)=sigma exactly, no repair or lower-eigenvalue estimate for sigma is needed to define Phi^sharp.

Why entropy-loss recoverability does not close the b gate
---------------------------------------------------------
For the product reference omega=rho_R tensor sigma and stationary Phi, the loss in the Junge et al. theorem is

  Delta I = I(R:B)_rho-I(R:B)_{(id tensor Phi)(rho)}.

It is not D itself. Nor does the trace residual b dimension-freely force Delta I to zero, even with bounded D and exact stationarity. The following elementary classical family demonstrates this specific obstruction, without refuting the candidate round-trip assertion.

For p in (0,1), choose N=N(p) with p log N -> c>0. Let B=R={0,...,N}, and let sigma(0)=1-p, sigma(i)=p/N for i>0. Define

  rho_RB=(1-p)|00><00|+(p/N) sum_{i=1}^N |ii><ii|.

Let Phi fix 0 and send each rare input i>0 to the uniform distribution on {1,...,N}. Then Phi is sigma-stationary, reversible for the sigma-weighted classical inner product, and idempotent; hence Phi^sharp=Phi and Phi^sharp Phi=Phi. The state has rho_B=sigma and

  D=I(R:B)=h(p)+p log N -> c,
  b=p(1-1/N) -> 0,
  Delta I=I(R:B)_rho-I(R:B)_{(id tensor Phi)(rho)}=p log N -> c.

Thus no general step “small b plus bounded I implies small relative-entropy loss” can feed the established recovery theorem. In this example the desired round-trip distance equals b, so it is not a counterexample to that desired conclusion.

Decisive missing interface
-------------------------
The simplest sufficient new lemma would be a dimension-free bound

  (1/2)||rho_RB-(id_R tensor Phi^sharp)(rho_RB)||_1 <= g(C,b),
  with g(C,b)->0 as b->0 for every fixed C,

uniform over dimensions, faithful stationary sigma, references R, and rho_B=sigma with I(R:B)<=C. Since Phi^sharp is CPTP under these hypotheses, trace-distance contractivity and the triangle inequality then give

  (1/2)||rho-(id tensor Phi^sharp Phi)(rho)||_1 <= b+g(C,b).

The audited recovery results instead require Delta I small and/or return a rotated average; the classical family above rules out deriving Delta I=o(1) from the stated data alone. The exact backwards-residual lemma remains the gate.

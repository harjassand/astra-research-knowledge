DIMENSION-FREE CLASSICAL RECONSTRUCTION FOR AFFINE CLIFFORD STATES
Independent verification, 2026-10-09.
Status: consequence of CLIFFORD_FACTOR_TWO.txt; external validation UNKNOWN.

Let Gamma_1,...,Gamma_q, q>=2, and Phi be as in the Clifford theorem.
Let X be any set of real q-vectors with ||x||_2<=theta<1. Define
  A_x=sum_i x_i Gamma_i,  rho_x=(I+A_x)/d.
These are density matrices because A_x^2=||x||_2^2 I, and the reference
state is I/d. Assume the SAME supplied compatible channel Phi obeys
  T(rho_x,Phi(rho_x))<=epsilon  for every x in X,
where T(rho,sigma)=||rho-sigma||_1/2.

Then the ONE canonical channel Psi constructed in CLIFFORD_FACTOR_TWO.txt
obeys
  T(rho_x,Psi(rho_x))<=sqrt(theta epsilon)  for every x in X.
It has at most 2q+1 POVM effects. It does not depend on the queried x.

PROOF
Write tau=Tr/d and delta_Phi(A)=tau[A(A-Phi(A))]. Since Phi is unital,
  tau|A_x-Phi(A_x)|=||rho_x-Phi(rho_x)||_1<=2epsilon.
Since ||A_x||_infinity=||x||_2<=theta, Holder's inequality gives
  0<=delta_Phi(A_x)<=2theta epsilon.
The constructed Psi is a convex combination of orthogonal HS projections
onto span{I,Gamma'_i} and span{I}. Thus it is HS-self-adjoint with
  0<=Psi<=I,
and spectral calculus gives (I-Psi)^2<=I-Psi. The Clifford theorem implies
  tau[((I-Psi)A_x)^2]
    <=tau[A_x(I-Psi)A_x]
    <=2delta_Phi(A_x)<=4theta epsilon.
Normalized Schatten Cauchy-Schwarz and unitality now give
  T(rho_x,Psi(rho_x))
    =tau|(I-Psi)A_x|/2
    <=sqrt(tau[((I-Psi)A_x)^2])/2
    <=sqrt(theta epsilon).

The theta<1 condition gives faithful affine states; the same trace bound
also holds at theta=1. For an error epsilon=0, the same channel exactly
reconstructs every state in the supplied family.

SCOPE AND COSTS
The observable matrices, Phi, and a compatibility witness B are supplied.
Constructing Psi requires q^2 dense HS correlations, a q-by-q real
diagonalization, and up to 2q+1 dense effects. No POVM acquisition, gate
implementation, precision robustness, or efficient circuit is supplied
by this proof. The result applies to affine Clifford likelihoods. It is
not the arbitrary bounded-Holevo broadcasting-to-EB theorem.

In particular q=3,d=2 with the Pauli matrices spans all real Hermitian
qubit matrices. The full-domain target has the sharp C=2 in dimension two.

# Cycle 10: original-face feature quotient and row screening

## Legal invariant and the stronger parameter

Fix the original minimum face F=F(y) and H=lin(F-F). For every b in F, b-y belongs to H. Any rational matrix X satisfying X|H=A|H therefore preserves the exact quantity of interest:

    X(b-y)=A(b-y).

Define the intrinsic column radius

    Gamma(F,A)=min_{X|H=A|H} max_j ||X_j||_2.

If original columns have norm <=1, Gamma<=1. If a rational certificate provides X and rho>0 with X|H=A|H and ||X_j||_2<=rho, apply the original theorem to X/rho on the same face. Its radius becomes B(k)rho for the original features, with no discrepancy from preprocessing, the queried cost, or exact marginal extraction. If AH=0, exact face optimization and direct exact decomposition already give zero feature error; a spectral trajectory is unnecessary.

The face and H are recovered with the same original strong optimization oracle, using the exact tangent-box/span/face-equation construction in the cycle-9 geometry gate. Matroid greedy optimization from independence still suffices. No optimization over good vertices, subspace oracle, conic optimizer, or complementary-exchange map is supplied.

## An explicit cheap certificate

Let B be a rational full-column-rank basis of H. The rational orthogonal projector is

    Pi=B(B^T B)^(-1)B^T.

X=A Pi is valid. Its maximum column norm can exceed the original maximum: for A=(-1,1,1) on the rank-one three-element base polytope, A Pi=(-4/3,2/3,2/3). Choose the original representation if that certificate is better.

With a common denominator Q_X, write max_j ||X_j||_2²=S/Q_X² for an integer S>=0. If S>0, an upper rational scale is

    rho=ceil(sqrt(S 2^(2p)))/(2^p Q_X),

computed by integer square root and an exact ceiling check. It satisfies rho>=max norm and rho<=(1+2^(-p))max norm. All bits are polynomial in the input, p, and the recovered basis. No exact irrational computation is used.

For a matroid original face, H is the direct sum of sum-zero spaces on the components of its face minor, with fixed coordinates zero. Pi subtracts the mean feature column within each component. Common covariates and information components are thereby removed. The minimum enclosing-ball center of the columns can improve on their mean, as the exact K4-face fixture shows.

## Polynomial-bit approximation of Gamma without a stronger oracle

This provides a complete algorithmic construction, not an executed general SOCP solver. Let Q_A be any common denominator of A. Choose a basis of H made of differences of Boolean vertices. If AH is nonzero, some such h has an entry of Ah of magnitude >=1/Q_A, while ||h||_1<=n. Every feasible representation X then gives

    Gamma>=1/(n Q_A).

If AH=0, handle it directly. If H=R^n, the representation is unique and column norms can be bounded as above. The other cases have q=n-dim H>0.

Select q independent columns C of I-Pi. They span H^perp. Every valid representation is uniquely of the form

    X=A Pi+T C^T,       T in R^(m by q).

C is rational, entries <=1 in magnitude, and operator norm <=1: it is an orthogonal projector followed by a coordinate inclusion. Let D_Pi be a common denominator of Pi. Some q-square row minor of C has determinant of magnitude >=D_Pi^(-q). Since an optimal X has column norms <=1, its entries are <=1; entries of A Pi have magnitude <=sqrt n<=n. Cramer's rule bounds every optimal coefficient by

    U=q!(n+2) D_Pi^q.

All encodings are polynomial. In particular a Boolean-difference basis gives Gram entries bounded by n and a polynomial-bit denominator determinant for Pi. Put D=mq, R_var=2D U, and r_var=1/(8n Q_A). The initial parameter ball of radius R_var contains an optimizer T*. For every t>=5 Gamma/4, a parameter ball of radius r_var about T* is feasible: a Frobenius perturbation of that size changes every feature column by at most r_var<=Gamma/8, leaving the required margin. The ball is also inside the initial ball.

At a rational parameter center T, test all explicit inequalities

    ||a0_j+T c_j||²<=t²,

where a0_j is column j of A Pi and c_j is row j of C. If a column z_j=a0_j+T c_j violates its inequality, a rational separating halfspace for every feasible parameter is

    z_j·(T' c_j) <= (t²+||z_j||²)/2-z_j·a0_j.

This follows from the convex quadratic inequality, and a central cut through the current parameter center is a valid weakening. If c_j=0 and the constant column violates, the system is exactly infeasible. The finite-precision outward ellipsoid construction already reconstructed in `EXACT_MARGINAL_GATE.md`, in dimension D, applies to these rational cuts. Choose the rational volume threshold (r_var/D)^D, below the volume of an inscribed coordinate cube. A polynomial number of outward updates either finds a rational feasible T or proves that no robust ball of this specified size survives. Failure is **not** asserted to mean infeasibility; it is impossible for t>=5 Gamma/4. For D=1, rational central interval bisection has the same guarantee.

Start at t=5/4 and repeatedly multiply t by 4/5 until the first failure. A first success is guaranteed because Gamma<=1. A failure must eventually occur because Gamma>=1/(nQ_A), so only O(log(nQ_A)) tests are needed. Its threshold t_fail is <5 Gamma/4. The preceding feasible threshold gives a rational representation and scale

    rho=t_prev=(5/4)t_fail<25 Gamma/16.

Choose the better of this representation and the original A. Thus the adopted hard-radius theorem implies a deterministic polynomial-bit exact-marginal law with radius <(25/16) B(k) Gamma(F,A), and <=B(k). A tighter geometric ratio or more accurate convex solver can reduce 25/16; no such implementation was run here.

All cut normals, ellipsoid state, thresholds, and explicit constraint evaluations have polynomial bits. The only original-polytope queries are those already used to recover the original face and its tangent. There is no hidden real-arithmetic or supplied-conic-oracle assumption.

## Mandatory restriction to the original starting face

Do not project onto the cost-slice tangent: the final favorable vertex need not lie on the exact cost hyperplane. On P=conv{(1,0),(0,1)}, y=(1/2,1/2), c=e1, A=(1,-1), that tangent is zero, yet every favorable vertex is (0,1) and has discrepancy -1. A zero-radius prediction would be false.

Do not recenter the global feature objective on a changing original face without carrying the accumulated feature displacement. The identity X(b-y)=A(b-y) is justified on F(y), which contains both y and every final atom. A newly entered face may not contain y.

## Certified screening and a nonvacuity gate

For a normalized feature matrix with unit columns, every Boolean outcome has row error at most

    R_i(y)=sum_j |a_ij| max(y_j,1-y_j).

Discard a row when this exact bound is strictly below the desired theorem radius B. A dangerous row has l1 mass >=B and therefore l2²>=B²/n. Since total squared column mass is <=n, at most n²/B² rows remain dangerous. Input reading is still charged O(mn), followed by computation on those rows. Exact min/max row values on F can improve this bound but cost two strong optimization calls per row. Li already uses harmless-row screening; this is an adaptation, not a novelty claim.

If every row is safe, one exact favorable face optimization plus the standard exact decomposition completes the task; the spectral algorithm should be skipped. In particular all unit-column inputs with n<B are automatically safe. The n134 peer fixture lies below even the improved matroid bound 737, so it demonstrates algorithm conformance only. Its observed radius must be compared with its product-structure DP and kT=14/5 comparator, not with B.

### Screened kT already meets the target below a dimension threshold

This is a consequence of the same energy calculation, not an additional discrepancy theorem. On the retained submatrix, every column has Euclidean norm at most one, so

    T'=max_j ||A'_j||_1 <=sqrt(m') <=n/B.

Apply the already gated favorable-cost/original-face kT comparator to the retained rows. Its hard radius there is at most kn/B. The discarded rows have a strict radius below B on every Boolean vertex independently of the algorithm. The comparator therefore meets the full strict target B whenever

    n<B²/k.

The standard exact-marginal extractor preserves both parts of this guarantee. Empty retained submatrices need only ordinary favorable face optimization. Equality at the threshold is not asserted without checking the precise strict inequalities.

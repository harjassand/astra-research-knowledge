# Cycle 2: a workspace extension of the two-branch row obstruction

Status: proved for a specified branch-dependent append-only workspace
class, instantiated on a valid BMVZ-generated five-qubit term family, and
explicitly not extended to data-dependent workspace encodings.

## Result in one sentence

Appending arbitrary branch-dependent *pure workspace states* after the two
Clifford branches cannot repair the exact sparse-enforcer failure: for the
repeated five-qubit BJSW seed pair, every positive all-state enforcer has at
least one computational-basis row of support

    ceil(1 + 2^(T/2)),

where `T` is the number of repeated five-qubit blocks. This holds for every
workspace dimension, every pair of normalized workspace vectors (with
arbitrary overlap), and an arbitrary positive enforcer formula. It does not
cover data-dependent workspace states or general workspace isometries that
mix data with work.

## Source terms and an actual BMVZ-generated instance

The five-qubit seed projectors are the BJSW 5-LCH projectors onto

    phi_5 = |-> |00> |10>,
    psi_5 = (|000> - |011> - |101> - |110>)/2  tensor |10>.

They are rank-one Clifford projectors. Their overlap has magnitude
`1/(2 sqrt(2))`. In BJSW, these three-qubit vectors occur in the propagation
decomposition (the `Lambda(P)` vector and the first `H tensor H` vector in
equations (4)--(7)); the shared `|10>` clock factor makes them five-qubit
terms. See Broadbent--Ji--Song--Watrous, arXiv:1604.02804, Section 2, proof of
Theorem 2, equations (4)--(7).

To make their membership in a BMVZ output exact rather than assume a
self-loop in an expander, use this allowed input modification. Start from the
equitable, QMA-hard five-local projective family `H_n = (1/m) sum_i Pi_i`
used as the BMVZ starting family. Append a five-qubit seed register disjoint
from the base register, and add `L=floor(m/g)` copies of `P_phi` as one new
color and `L` copies of `P_psi` as a second new color, where `g=O(1)` is the
number of original equitable layers. Define

    H'_n = [m (H_n tensor I_seed)
            + L (I_base tensor P_phi + I_base tensor P_psi)]/(m+2L).

The two new colors commute internally because all their terms are identical;
they commute with every other color on the disjoint seed register. The number
of colors remains constant. The minimum layer weight stays bounded below by a
positive constant, and the layer sizes remain balanced up to the original
rounding by one. The two rank-one seed projectors have a common kernel of
dimension at least 30 on the five-qubit seed register, so

    lambda_min(H'_n) = [m/(m+2L)] lambda_min(H_n).

Thus the negligible-versus-inverse-polynomial promise and QMA-hardness are
preserved, with a constant rescaling. This is a BMVZ-admissible augmented
family; it is not a claim that the paper's particular unmodified canonical
input already contains this pair.

In each new color every vertex of the expander carries the same projector.
Consequently every path clause in that color is exactly

    P_{phi,T} = I - (I - P_phi)^{tensor T},
    P_{psi,T} = I - (I - P_psi)^{tensor T}.

This remains true at every iteration: complementing an amplified clause
tensor-multiplies the complements, so repeated amplification flattens to the
same formula with the product repetition count `T`. BMVZ Definition 1.7 and
Definition 1.9 specify the path clauses; Theorem 7.3 iterates the construction
to polynomial repetition, yielding the O(n)-fold local-projector terms of
Theorem 1.4/7.4. Therefore both displayed clauses occur in a genuine BMVZ
output for the augmented QMA-hard starting family, with no graph-loop
assumption.

The result below concerns the normalized two-clause test
`H_pair,T = (P_{phi,T}+P_{psi,T})/2` formed from this actual output pair. It is
a stress test of the proposed two-branch encoding. It is **not** a lower bound
for a many-branch isometry encoding the full BMVZ output: other clauses could
participate in its row dependencies.

## Architecture covered

Let `L_T` be the BMVZ output data space for one of these clauses, including
the `T` copies of the seed register and all spectator qubits. Let `U_0` and
`U_1` be five-qubit Clifford decoders with

    U_0^* |0^5> = phi_5,       U_1^* |0^5> = psi_5.

Extend them by identity on spectator qubits and tensor them over the `T`
copies, obtaining `U_{0,T}` and `U_{1,T}` on `L_T`. For any finite workspace
`W` and any normalized vectors `a_0,a_1` in `W`, with arbitrary overlap,
consider the single isometry

    V_a |v> = ( |0> U_{0,T}|v> tensor |a_0>
               + |1> U_{1,T}|v> tensor |a_1> )/sqrt(2).

This class allows arbitrary workspace dimension and a distinct pure state
after each branch. The workspace states may be orthogonal or identical; the
proof does not depend on their overlap. Write `P_a=V_a V_a^*`.

For the logical test use the diagonal projection

    D_T = I - tensor_(i=1)^T (I - |0^5><0^5|_i),
    B = I_branch tensor D_T tensor I_spectators tensor I_W.

The branch tag gives `V_a^* V_a=I` for every normalized pair `a_0,a_1`;
also `0<=B<=I`, and exactly

    V_a^* B V_a = (P_{phi,T}+P_{psi,T})/2 = H_pair,T.

No approximation or term-dependent isometry is used. `B` is diagonal with
entries 0 or 1, so it is 1-sparse, has `||B||=1`, and has an exact row/entry
algorithm that scans the `T` five-bit seed blocks (O(T) bit operations; O(1)
nonzeros in a listed row). A uniform circuit for `V_a` uses the two fixed
five-qubit Clifford decoders on each of `T` blocks, a Hadamard on the branch,
and branch-controlled preparation of `a_0` or `a_1`; it is polynomial size
whenever both workspace states have uniform polynomial-size preparations.
The lower bound below does not require that preparation assumption.

## Workspace-robust lemma

Put

    mu_T = max_(u,v in basis(L_T)) |(U_{1,T} U_{0,T}^*)_(u,v)|.

The relative seed Clifford `W=U_1 U_0^*` is non-monomial: its `(0^5,0^5)`
matrix element has magnitude `|<phi_5,psi_5>|=1/(2 sqrt(2))`, whereas a
monomial unitary has every entry of magnitude 0 or 1. Clifford matrix entries
are either zero or have one common nonzero magnitude `2^(-r/2)` in each row;
non-monomiality forces `r>=1`. Hence

    mu_T = (max_(y,z) |W_(y,z)|)^T <= 2^(-T/2).

**Lemma.** Suppose `C=C^* >= 0`, `ker C=ran(V_a)`, and

    C >= gamma (I - P_a)

for some `gamma>0`. In the product computational basis
`|b,y,w>` (branch, data, workspace), at least one row of `C` has support at
least `ceil(1+1/mu_T)`, and therefore at least `ceil(1+2^(T/2))`.

**Proof.** Let `d=dim(L_T)` and `D=dim(W)`. A computational-basis row of
`V_a` at `(b,y,w)` is `a_b(w)/sqrt(2)` times the row vector `<y|U_{b,T}`.
For a row `r` of `C`, define its collapsed coefficients

    ctilde_(b,y) = sum_w r_(b,y,w) a_b(w).

The identity `r V_a=0` gives the row dependence

    sum_(b,y) ctilde_(b,y) <y|U_{b,T} = 0.

If `ctilde` is nonzero, its support contains distinct unit vectors from the
two row bases. Rows in either one basis are orthonormal, and cross-basis
inner products have magnitude at most `mu_T`. If the dependence uses `s`
vectors, its Gram matrix has diagonal 1 and off-diagonal magnitudes at most
`mu_T`; Gershgorin makes it positive definite whenever
`(s-1)mu_T<1`. Thus `s>=ceil(1+1/mu_T)`. Every nonzero collapsed coefficient
requires at least one nonzero original row entry, so `supp(r)>=s`.

It remains to show that some row has nonzero collapse. The collapse map from
all output row vectors to the `2d` coefficients `(b,y)` has rank `2d`: for
each branch, its `d` coordinate functionals use a nonzero coordinate of the
normalized vector `a_b`, and the two branch blocks are disjoint. Its kernel
has dimension `2dD-2d`. The gap and exact kernel conditions imply
`rank(C)=2dD-d`, which is strictly larger. Therefore
the row space of `C` cannot be contained in the collapse kernel; some row has
nonzero collapse and obeys the bound. ∎

The gap is an **all-state** statement: every vector orthogonal to the image
must have energy at least `gamma` times its squared norm. The proof is
independent of the value of `gamma>0`, of positivity decompositions, of
coefficient precision, and of how `C` is computed. In particular, an
efficient entry oracle cannot make this `C` polynomial-row-sparse. The dense
choice `C=I-P_a` has gap one and is an exact enforcer, illustrating that the
obstruction is row support, not existence or entry evaluation. Its projector
entries are

    (P_a)_(b,y,w),(b',y',w')
      = a_b(w) conjugate(a_(b')(w'))/2
        * (U_(b,T) U_(b',T)^*)_(y,y').

With efficiently computable `a_0,a_1`, these entries can be evaluated from
Clifford matrix entries and their amplitudes, but the row lower bound still
forces exponential support whenever `T` grows faster than the logarithm of
the output dimension. The BMVZ iterated gap-amplification regime has
polynomially growing repetition for inverse-polynomial starting gaps, so its
asymptotic instances pass this threshold; at smaller finite `T`, the exact
bound above remains valid without implying a superpolynomial row count.

## Exact falsifier and boundary

For any fixed `T` and any normalized pair of workspace states `a_0,a_1`, an
exact counterexample to the lemma would be a matrix `C` in the stated product
basis with all of the following properties:

    C=C^* >= 0,
    ker(C)=ran(V_a),
    C >= gamma (I-P_a) for an exact gamma>0,
    max_row_supp(C) < ceil(1+2^(T/2)).

All four conditions are finite-dimensional and algebraic for the Clifford
seeds and algebraic `a_0,a_1`; the row support counts exact nonzero entries.
Exhibiting such a `C` falsifies the theorem. For an asymptotic no-polynomial
row-support conclusion, a uniform family with polynomial row support and
these same exact conditions while `T(n)/log N(n) -> infinity` would falsify
the claimed growth consequence (`N(n)=2d(n)D(n)` is the output dimension).
When `T=O(log N)`, the finite lower bound can itself be polynomial, so it does
not alone rule out polynomial row support.

This closes the **branch-dependent pure appended-state workspace** escape,
including orthogonal workspace flags. A data-dependent workspace state or a
data-workspace isometry applied within either branch can change the collapsed
row vectors, so this proof says nothing about those encodings. Nor does the
two-clause obstruction imply a lower bound for an all-clauses BMVZ encoding.
The next decisive positive escape would be an explicit such broader `V,C,B`
with the exact compression, polynomial row
support, and the all-state gap; the next decisive negative result would need
to control those data-dependent workspace rows or prove a reduction from
the full multi-branch enforcer to this pair.

No contradiction with MIP*=RE, Tsirelson-type model separations, or QMA
complexity follows: this is a row-support lower bound for one explicit
finite-dimensional two-branch encoding architecture, not a restriction on
general finite-dimensional or tensor-product strategies.

# Explicit Strassen kernel for a structured selective-output interface

## Verdict and scope

The pinned 9/4 manuscript does not materialize its recursive kernel. Its page-9 proof chooses a fixed base size and an exact rank decomposition only after an existential exponent argument; it gives no effective base size, rank table, number-field degree, coefficient-height bound, or setup-time bound. The manuscript’s final remark says that a complex exact decomposition implies a rational one by Nullstellensatz. That implication is false in general (`x^2+1=0` has a complex point but no rational point). The equations do imply a point over an algebraic closure, hence some finite number field, but enumerating such witnesses is only a semidecision without a useful stopping-time bound.

There is, however, a fully explicit fixed kernel at base size 2: Strassen’s seven-product decomposition over `Q`. It gives a constructive, exact theorem for supplied rectangle-cover masks. This narrows the old 9/4-based class: the mask-cover volume exponent must be below about 1.79816 for this kernel to give a subquadratic bound at `D=N^(1/4)`. The concrete threshold below is `179/100`, certified by an exact rational inequality. This does not solve the arbitrary-mask target and is an elementary structured corollary of Strassen, not a priority claim.

## Exact interface theorem

Let `D` be a positive integer, `N=D^4`, and let

`X in Z^(N x D)`, `Y in Z^(D x N)`, with `|X_ik|, |Y_kj| < 2^b`.

The input mask representation consists of:

* a supplied list of rectangles `(R_t,C_t)`, `t=1,...,q`, with `R_t,C_t` explicit subsets of `[N]` and `|R_t|,|C_t| >= D`;
* a supplied explicit residual list `F subset [N]^2` outside the union of those rectangles.

Set `W = F union ⋃_t (R_t x C_t)` and `M = Σ_t |R_t||C_t|`, counting rectangle overlaps with multiplicity. Assume

`M <= N^(179/100)` and `|F| <= N^(7/4 - sigma)`

for a fixed `sigma>0`. The algorithm returns every distinct pair `(i,j) in W` once, together with the exact integer `(XY)_ij`.

There is a uniform exact integer-arithmetic algorithm with

`Q = O(ND + M D^(log_2(7)-2) + |F|D + M + |F|)`

scalar additions, subtractions, and multiplications, plus `O((M+|F|) log(M+|F|))` record-comparison work. If `b=O(log N)`, its total bit cost, including input-list reading and output materialization, is

`O(N^(2 - min{3/400,sigma}) polylog N)`.

For general `b`, the end-to-end bit cost is `O(Q(b+log N)^2 + (M+|F|)log(M+|F|)(b+log N))`. Here `Q` includes `ND`, `M+|F|`, and the arithmetic work; the formula therefore covers input/output reading, the `O((M/D+|F|)log N)`-bit mask description, and value-record sorting. If a fully unrolled gate listing is requested, its `O(Q log N)`-bit serialization is also dominated by this expression. Thus the `b=O(log N)` specialization is stated without suppressing a precision assumption.

The fixed kernel has coefficient field `Q` (field degree 1), coefficient alphabet `{−1,0,1}`, and logarithmic coefficient height 0. Its base data occupy 84 coefficient slots, 36 nonzero, and require no search. Exact verification of the base tensor identity uses at most 448 integer sign-products, 384 integer additions, and 64 equality checks. The online arithmetic is integer arithmetic, so there is no algebraic-number representation, finite-precision approximation, or rounding cost.

The explicit rectangle lists have `L=Σ_t(|R_t|+|C_t|)` indices. Since each side is at least `D`, `L <= 2M/D`; reading the lists costs `O((M/D+|F|)log N)` bits. Reading `X,Y` costs `O(NDb)` bits. The requested values have at most `2b+ceil(log_2 D)+O(1)` bits each. These costs are included in the displayed bit bound for `b=O(log N)`. Acquiring or discovering the rectangle representation is not included: if the only mask input is an `N x N` bitmap, reading it can already cost `N^2` bits.

## Materialized base kernel

Flatten each 2-by-2 input matrix in order `(11,12,21,22)`, and the output in the same order. Define seven products

```text
p1 = (a11+a22)(b11+b22)
p2 = (a21+a22)b11
p3 = a11(b12-b22)
p4 = a22(b21-b11)
p5 = (a11+a12)b22
p6 = (a21-a11)(b11+b12)
p7 = (a12-a22)(b21+b22)
```

and recover

```text
c11 = p1+p4-p5+p7
c12 = p3+p5
c21 = p2+p4
c22 = p1-p2+p3+p6.
```

This is an exact seven-term bilinear decomposition `T_2 = Σ_{ell=1}^7 u_ell ⊗ v_ell ⊗ w_ell` (so the tensor rank is at most 7). The executable coefficient arrays are recorded in `strassen_verify.py`. They have shapes `7x4`, `7x4`, and `7x4`; all entries are 0 or a sign, with 36 nonzeros total. For a base identity audit, the 64 structure-constant coordinates of the 2-by-2 multiplication tensor are checked against the seven rank-one terms. The recorded script performs that exhaustive check exactly over the integers.

The recursive compiler splits each `m x m` input into four half-size blocks and applies these same formulas with matrix addition/subtraction replacing scalar addition/subtraction. For `m=2^k`, it uses exactly `7^k=m^omega` scalar multiplications, where `omega=log_2 7`, and exactly `6(7^k-4^k)=6(m^omega-m^2)` additions/subtractions. This follows from `A_k=7A_(k-1)+18*4^(k-1)`, `A_0=0`. For arbitrary `D`, pad a tile to `m=2^ceil(log_2 D)<2D` with zero rows and columns, run the recursion, then discard padded outputs.

Kernel-table setup writes 84 fixed coefficients and performs no arithmetic search. If the setup routine also verifies the identity, its simple dense check uses at most 448 products of entries in `{−1,0,1}`, 384 additions, and 64 comparisons. The uniform recursive interpreter has constant-size source and recursion depth `O(log D)`; its control steps are `O(Q)` and are absorbed by the online count. If a caller requires an explicitly unrolled straight-line program, emit at most `O(Q)` arithmetic-gate records, with `O(Q log N)` bits for operand indices; this circuit-generation/output cost is charged separately from executing the circuit.

## Selective-mask compiler and proof

For each supplied rectangle `(R,C)`, partition each side into chunks of at most `D` indices. For each chunk pair `(R',C')`, place `X[R',:]` in the top rows of an `m x m` zero-padded matrix and `Y[:,C']` in the left columns of a second `m x m` zero-padded matrix, with `m=2^ceil(log_2 D)`. Run the recursive Strassen program and emit the top-left `|R'| x |C'|` block. Its inner dimension is the original `D`, so those entries are exactly the requested products.

If `a=|R|` and `c=|C|`, the rectangle uses at most

`ceil(a/D)ceil(c/D) <= 4ac/D^2`

tile products, because `a,c>=D`. Each padded product costs `O(D^omega)`, so all cover products cost `O(M D^(omega-2))`. Compute each residual pair in `F` by its direct `D`-term dot product, costing `O(|F|D)`. Reading the full inputs costs `O(ND)`. Copying tile data and materializing outputs costs `O(M+|F|)` records. Sort and deduplicate overlapping rectangle outputs; the residual is promised outside the cover.

For the exponent calculation, the exact integer comparison `7^100 < 2^281` proves `omega < 281/100 = 2.81`. Thus `omega-2 < 81/100`, and

`M D^(omega-2) <= N^(179/100) N^(81/400) = N^(797/400) = N^(2-3/400)`.

Also `|F|D <= N^(7/4-sigma+1/4)=N^(2-sigma)`, while `ND=N^(5/4)`. The index-list, record-sorting, and output-writing costs are lower-order polylogarithmic factors. This proves the claimed bound.

Every operand in the recursive integer algorithm is a sum or difference of at most `m` original entries on each input leg; any output accumulation contains at most `m^2` rank terms. Consequently all intermediates have `O(b+log m)` bits (a coarse explicit magnitude bound is `m^4 2^(2b)`). With schoolbook integer multiplication, the arithmetic count incurs at most `O((b+log N)^2)` bit operations per scalar operation. No numerical conditioning assumption is present.

## Explicit nonempty mask sequence

For integer `t>=2`, take `N=t^100`, `D=t^25`, `s=t^79`, and `q=t^21`. Partition `[N]` into `q` consecutive intervals of size `s`, and let the mask be the union of the `q` diagonal `s x s` interval blocks. Each side satisfies `s>=D`, and

`M=q s^2=t^179=N^(179/100)`, `F=empty`.

The explicit index-list encoding has `2N` indices up to constant factors, or `O(N log N)` bits. For this sequence the theorem computes `N^1.79` requested entries in `O(N^(2-3/400) polylog N)` bit operations. Direct independent dot products cost `Theta(MD)=Theta(N^2.04)` scalar multiplications. This example shows the theorem is nonvacuous; it is not a speedup claim against all other structured algorithms.

## Constructive boundary / non-transfer

The `9/4` exponent in the pinned source cannot be substituted into this theorem with a concrete setup bound based on the source alone. Its proof supplies an existential base size/rank pair; the exact enumeration suggested by its algebraic existence can eventually find a witness but has no source-derived stopping bound. The erroneous `C -> Q` sentence does not repair this gap. A `Qbar` point does give a finite extension for each witness, but neither the extension degree nor the witness height is bounded explicitly.

Strassen does not reach the old `M<=N^(15/8)` cover-volume endpoint: at `M=N^(15/8)`, its covered work has exponent `15/8+(omega-2)/4 > 2` (indeed the exact `omega` gives about `2.07684`). The theorem also says nothing when no rectangle cover plus small residual is supplied. It cannot be transferred to arbitrary masks by first reading an explicit bitmap, since that can cost `N^2` bits. These are interface barriers, not lower bounds against other selective-output circuits.

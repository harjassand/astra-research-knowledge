## Root's actual graph construction: independent derivation

Assume a commuting Pauli Hamiltonian H0 on N data qubits has bounded check weight w, incidence t, physical range R0 and density b0, with no idle sites. Assume every global stabilizer supported in B(x,r) has a representation by whole original checks in B(x,C max(r,1)), for r up to an explicitly stated r_fill. Assume the data lie in a rectangular grid box whose number of lattice sites M obeys log(N+M)=O(log N). The root's later connected-embedding argument can establish such a box for its particular family, but that argument is not proved by the present gate.

Add M independent |+> ancillary qubits and Hanc=sum_v (I-X_v)/2. Let F contain grid nearest-neighbor edges and one data-to-nearest-grid-site edge for every data qubit. At most b original qubits attach to one grid site, where b depends on density and fixed mesh. With maximum F-degree Delta, put s=Delta+1 and U=product_edges CZ. The gates commute and U is its own adjoint and inverse. Greedy edge coloring needs at most 2Delta-1 colors, hence gives a constant-depth implementation. Direct conjugation of Pauli generators yields X_u times Z on its F-neighbors, while Z_u is unchanged. Newly created Z factors do not spread again. Thus each Pauli has support multiplied by at most s and enlarged in ambient space by one fixed R_U.

The ancillary checks become

    K_v = X_v (product_grid_neighbors Z_w) (product_attached_data Z_q).

They have actual, nonidentity support on the grid edge endpoints and attached data. Adjacent K_v and K_w overlap. Each transformed original check retains its original nonidentity data sites, because there are no data-to-data CZ gates. It consequently overlaps K_{a(q)} for any original data site q in that check. Pure Z checks attach in exactly this way; they need not acquire an ancillary Pauli themselves.

Safe explicit bounds are

    w_c' <= max(s w, Delta+1),
    w_q' <= max(t+1, 2D+1+b t),
    N' = N+M,  N_c' = N_c+M = O(N').

The actual qubit graph contains F; all actual check/qubit graph degrees are bounded by constants. Therefore its balls admit a system-size-independent exponential growth bound. Identity original checks can be discarded as zero-energy terms; coverage of data is assumed and coverage of ancillas is supplied by K_v.

The augmented undressed code has the same logical dimension and distance as the original. Any Pauli in its centralizer has only I or X on each ancillary site; those X factors are ancillary stabilizers. A nontrivial logical restricts to a nontrivial data logical. If p is a transformed logical, U*pU is therefore an undressed logical and has weight at most s wt(p). This proves d' >= d/s. Exact preservation of distance is not assumed.

Take a transformed stabilizer p supported in B(x,r). Undress it. The result is uniquely a data stabilizer g times a product of ancillary X factors. Its actual support lies in B(x,r+R_U). Fill the data factor using the stated premise; its selected original checks have whole supports within C max(r+R_U,1). The ancillary factors are already original ancillary generators in the enlarged input ball. Redressing all selected generators enlarges whole supports by only R_U. This transfers ambient linear filling with a fixed constant and with the explicit radius condition r+R_U<=r_fill.

For a nonempty connected actual check set S, the fixed physical diameter of checks and overlapping-support path imply its actual union lies in a ball of radius A(|S|+1). Every filler check from the preceding paragraph lies in B(x,A'(|S|+1)). It attaches in at most one check-graph step to a K check. The two attachment sites can be joined by a Manhattan grid path of O(A'(|S|+1)) edges. Each grid path edge is an actual adjacency between K checks. The rectangular grid contains the entire path between endpoints even if the original occupied set is folded, sparse or has holes. Both filler endpoints are actual available sites; a filling ball extending past the rectangle introduces no unavailable checks.

For |S|>=1 absorb |S|+1<=2|S|. The result is precisely actual-union generation within ell|S| in the actual check graph. Its cutoff is proportional to r_fill after fixed range/spread losses. Thus the usable small-word cutoff is

    d_eff = c0 min(d, r_fill),

with a fixed positive c0. A finite filling window must be charged. A large code distance does not repair an O(1) filling window. ## Physical perturbation norm and auxiliary removal

Assume V=sum_X V_X is Hermitian with each physical support diameter <=R_V and

    J = sup_data_site q sum_{X containing q} ||V_X||.

The local strength assumption is essential: a list of O(N) bounded local terms all at one site is not intensive merely because it has O(N) entries. Bounded density and R_V give a fixed maximum q0 data sites per term. Hilbert–Schmidt orthogonality and Cauchy–Schwarz bound its Pauli coefficient sum by 2^q0 ||V_X||. Clifford conjugation is a signed permutation of Pauli strings, so preserves that coefficient sum.

For an original-only term, new ancillary sites are only the attached sites of original X/Y locations. Its transformed support lies in a bounded grid box around X. A connecting grid tree plus the attachments gives a cover of at most m0 sites in the actual qubit graph, independent of N. Each output data site q receives terms originally containing q. Each output ancilla v receives terms originally containing one of at most b attached data qubits. Combining equal output Paulis can only decrease the triangle bound. Hence

    |||U(V tensor I)U*|||_mu <= max(1,b) 2^q0 exp(mu m0) J.

This verifies exactly the prior intensive Pauli interface. The required mu and the exponential constants must be charged in the final threshold; no practical perturbation threshold is demonstrated.

The dressed total spectrum is exactly the spectrum of (H0+V) tensor I + I tensor Hanc. Its minimum is the original minimum; an ancillary excitation adds an integer at least one. Once the prior low-band width is <1, every eigenvector in that band has an ancillary ground factor. Its dimension is exactly the original 2^K, and any other original eigenvalue appears with ancillary ground state in the total spectrum. The total gap and band width therefore transfer to the original Hamiltonian. There is no subtraction of a putative perturbation to Hanc: the transformed perturbation was exactly U(V tensor I)U* from the start.

This proves a conditional reduction to the prior **ground-band** theorem. It does not transfer every dressed quasi-local unitary statement to the original code, and it proves no open-system thermal-memory lifetime.

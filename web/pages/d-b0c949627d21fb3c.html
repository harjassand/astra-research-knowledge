# C12 failures, limits, and closed routes

## No new scientific result established

The macrophage manuscript is a 2026 bioRxiv preprint and is explicitly marked not peer reviewed. Its findings are source-reported and are not independently validated here. The two-state model is a conditional branch-process abstraction. It does not explicitly represent spatial neighborhoods, paracrine transport, conditioned-medium dynamics, nutrient depletion, or an antigen/receptor signalling trajectory. Random clone-level `k_on,max` is a fitted extrinsic-heterogeneity term; it does not identify its biological cause.

The Methods estimate sister-pair transition rates from pairs selected by endpoint centroid proximity (within 30 pixels, separated from a third nucleus by at least 120 pixels), without reporting lineage tracking of those pairs. This does not show that the pairs are wrong; it leaves the true-sister fraction and matched neighbor-state association unmeasured. Under the explicit independent-neighbor contamination model, `proof/proximity_pair_rate_bias.md` shows the uncorrected method overestimates the sum of switching rates and underestimates relaxation time. Correlated local backgrounds can change that direction, so the matched-neighbor control is essential.

The mean-field lag derivation in `proof/density_size_clock_lag.md` is a routine consequence of the model. It is not a new immune law, does not prove the Hill-switching model is correct, and must not be presented as the requested breakthrough.

## Reproducibility gaps in public implementation

- The BioImage Archive manifest lists one `external_data.zip` of 2,496,119,118 bytes. Only the two small model workbooks were range-fetched and CRC-checked; the full archive, large sequencing inputs, and image data were not downloaded. No full bootstrap/optimization replay, source-model calibration, or image-level audit was performed.
- `R_scripts/Optimized_Parameter_Estimation.R` sets `GROWTH_RATE <- log(2)/18` while assigning `DOUBLING_TIME <- 14.4`; `DOUBLING_TIME` is not used in the simulator. Other public scripts use `log(2)/14.4`. This changes both endpoint size distribution and time available for switching in the optimization objective.
- The optimizer maps each experimental clone size to the single nearest simulated size with `which.min`, with replacement. It can duplicate a simulated trajectory and does not provide a conditional distribution of fractions at a fixed size. The bootstrap on this matched subset does not correct that design feature.
- Each objective call draws a fresh 5,000-clone Monte Carlo pool. The search objective is noisy as parameters change; reported search values need repeated/common-random-number validation. The script's initial `set.seed(42)` makes a fixed run replayable only when environment, inputs, and code match; it does not remove Monte Carlo noise from comparisons.
- Several R files use Windows-style paths with single backslashes inside quoted strings. R treats backslash sequences as escapes, so direct parsing/execution on a standard R interpreter may fail. This was not tested because no full run was attempted.
- Public GitHub includes small processed CV tables but not the model workbook or all raw data. Code presence alone is not an independent reproduction.

The selectively extracted workbook audit is in `proof/rate_input_marginal_mismatch.md`. It finds that the public rate-estimation Rmd combines a pair OR from the `CD36 Mock` proximity-pair table with an unweighted ON fraction from 1,108 separate clone-level observations. The paired-cell marginal from the same pair rows is 0.13428; the script's clamped clone mean is 0.21680. Holding the same pooled OR fixed changes the conditional inferred `k_on+k_off` by 24.4%. This is a source-code/workbook interface mismatch if the intended `f_ON` is the pair-population marginal; it is not proof the manuscript's final parameter estimates were generated by this script version or that the source biology is wrong.

These are implementation/reproducibility caveats, not proof that the preprint's experimental observations are false.

## Access and scope failures

- The 2026 T-cell ERK-pulsing paper's publisher page returned HTTP 403. Only the primary PubMed abstract was inspected; no methods, supplementary material, raw trajectories, or code were reconstructed. It is not advanced to a quantitative claim in this lane.
- The archive's full external zip is large. A complete image/clone reanalysis is outside this bounded pass; the API file manifest was inspected, but no large data were downloaded.
- No new machine-learning, inference, or controller advantage was established; no matched-control assay was run.

## Prior art / do not repeat

- Barcode-based identification of sister cells for cell-state/resistance analysis predates this audit (Dai et al. 2024, ReSisTrace; see `SOURCES.md`). The C12 contribution is not a new sister-tracking method.
- C7 adaptive mechanical proofreading is already published in the named 2026 paper and its claimed advantage depends on dose priors/controls; the B-cell lane is closed for this turn.
- A two-state immune-memory CTMC and exponential-mixture reconstruction are already catalogued as standard conditional mathematics in `work/agents/immunology/immune_memory/`.
- The nutrient T-cell combination has unresolved controls and was expressly excluded.
- Restricted RNA kinetic-barcode work was expressly excluded and not retried.

A. AN UNCONDITIONAL FINITE ALGORITHM: CERTIFY A ROUNDED c-COMPARATOR OR
REFUTE THE EXACT CANONICAL c-COMPARATOR ON A SUPPLIED RATIONAL CHANNEL

This refines the INITIAL semialgebraic reduction into a finite exhaustive
rational-grid algorithm with no implicit real-algebraic oracle. It is not
efficient and the unrestricted universal existence theorem is still open.
The error bound, unlike the search cost, has no dimension factor.

Input: an explicitly supplied rational-complex superoperator Phi on M_d,
rational c>=1, rational delta>0. For the broadcasting interpretation Phi is
promised/verified UCP, tracial preserving, positive selfadjoint and compatible;
the algorithm's mathematical completeness does not use compatibility.
Use canonical measurement maps, which are positive selfadjoint EB contractions.

Let n=d^2-1 and m=1+n+n(n+1)/2=d^2(d^2+1)/2. As proved in INITIAL, if ANY
canonical measurement map satisfies I-Psi<=c(I-Phi), rank-one refinement and
Caratheodory provide one with at most m effects. Pad with zero effects.
Set e=delta/(18d), u=e/m, q=e/(2md). Enumerate all m Hermitian matrices B_y
whose independent real/imaginary entries are integer multiples of q in the
bounded interval [-1-q,1+q]. There are finitely many choices. Preserve Hermitian
symmetry. Define N_y=B_y+uI, S=sum N_y. Reject a candidate unless each N_y>=0
and I-S/(1+2e)>=0. These PSD predicates are EXACT rational predicates (all
principal minors, for example). Set
  M'_y=N_y/(1+2e), M'_0=I-S/(1+2e).
These are an exact rational POVM. Drop zero effects. Form its canonical Psi'.
Test EXACTLY the rational Hermitian quadratic slack
  c(I-Phi)-(I-Psi')+delta I >=0.                         (A1)
If it passes, return the rational POVM, preparations M'_y/Tr(M'_y), and
an exact PSD certificate for (A1). If the ENTIRE finite grid is exhausted,
return REFUTED_EXACT_CANONICAL_c. A user-charged search cutoff must return
UNKNOWN, never refuted. No cutoff or approximate solver is substituted here.

Completeness: take any exact feasible POVM M with <=m outcomes. Each effect
obeys 0<=M_y<=I, so every real/imaginary matrix entry lies in [-1,1]. Nearest-grid
rounding is included in the enumeration. The INITIAL compiler then gives
||Psi'-Psi||_(infinity->1,tau)<=18e. For Hermitian X with ||X||_2,tau=1,
||X||_infinity<=sqrt(d), whence
 |<X,(Psi'-Psi)X>_tau|
 <=||X||_infinity ||(Psi'-Psi)X||_1,tau
 <=18 e ||X||_infinity^2 <=18 e d=delta.
Thus (A1) holds for this enumerated candidate. Consequently exhaustive failure
is a sound refutation of the EXACT canonical c comparison for this input.
It is not necessarily a refutation of every additive-delta comparison, because
the grid algorithm only supplies this one-sided feasibility/refutation guarantee.

On return, one actual positive canonical EB map satisfies for every Hermitian
||H||<=theta
 ||(I-Psi')H||_1,tau^2
 <=<H,(I-Psi')H>_tau
 <=c<H,(I-Phi)H>_tau+delta||H||_2,tau^2
 <=c theta ||(I-Phi)H||_1,tau+delta theta^2.             (A2)
For all bounded likelihood states simultaneously the half-trace reconstruction
error is <=(1/2)sqrt(c theta r+delta theta^2). There is no label-count factor.
In particular, an actual universal c theorem would yield a concrete (very
expensive) bare-rational-Choi reconstruction algorithm without a supplied POVM.
This does not prove the theorem, nor an efficient implementation.

Cost accounting: there are m d^2=O(d^6) independent real coordinates. Each has
O(1/q)=O(md^2/delta) possibilities. Exhaustive enumeration is bounded by
 (O(md^2/delta))^(m d^2)
up to the additional final effect and Hermitian conventions. PSD verification
by all principal minors of the d^2-dimensional quadratic slack costs an
additional O(2^(d^2) poly(d,B)) rational arithmetic operations per candidate;
intermediate rational bit growth must be retained. The grid has
O(log(md^2/delta)) new bits per entry. These bounds are intentionally enormous.
Using more sophisticated exact PSD tests can improve verification, but cannot
turn this enumeration into an asserted practical algorithm. The search has
NOT been executed on a generic d>1 channel. The independently executed code
implements the compiler and checks supplied admitted witnesses, not this full
finite enumeration. No full QE, FPRAS or quantum hardware run is claimed.

B. A BOUNDED-HOLEVO CLASSICAL FAMILY FORCES A GROWING EB ALPHABET

The intended dimension-uniform analytic rounding bound does not entail an
outcome alphabet bounded by the Holevo capacity or residual alone. This is
true even when the channel is exactly EB and broadcasts with ZERO error.
The obstruction is representation/memory, not failure of the EB conclusion.

Fix even d>=2 and 0<theta<1. Let sigma=I/d, and consider the FINITE classical
experiment
 E_(d,theta)={rho_h=(I+theta diag(h))/d:
                h in {-1,+1}^d, sum_i h_i=0}.
It has binomial(d,d/2) states. They all obey (1-theta)sigma<=rho_h<=
(1+theta)sigma. Their common relative entropy is
 c(theta)=[(1+theta)log(1+theta)+(1-theta)log(1-theta)]/2.
For any ensemble prior, Donald's identity gives
 chi=sum_h p_h D(rho_h||sigma)-D(mean_rho||sigma)<=c(theta).
Thus the experiment's Holevo capacity is bounded independently of d, even
though its labels and dimension grow. This is an exact classical calculation,
not a use of continuity or a statement about accessible information only.

The dephasing channel D(X)=sum_i <i|X|i>|i><i| is UCP, tracial preserving,
positive selfadjoint, EB, and exactly fixes every rho_h. Its actual full-domain
broadcast is B(X)=sum_i <i|X|i>|ii><ii|. Thus residual r=b2=0.
An explicit d-outcome EB realization achieves error zero.

Claim: EVERY EB channel Lambda with an m-outcome measure-and-prepare
factorization satisfying sup_E T(Lambda rho,rho)<=epsilon must obey
  m >= d(1-2 epsilon/theta).                            (B1)
Equivalently epsilon>=theta(d-m)_+/(2d). Prepared states may be arbitrary
quantum states, and Lambda need not fix sigma. This bound concerns the actual
classical outcome alphabet of the factorization, not the number of Kraus
operators of an arbitrary different representation or a largest branch size.

Proof. Restrict Lambda to diagonal matrices. Its range lies in the real span
of its m preparation states, so its rank is at most m. Let
 K={h in R^d: Lambda(diag(h))=0}.
Then dim K=k>=d-m. Trace preservation forces sum_i h_i=0 for every h in K.
The compact polytope K intersection [-1,1]^d has a vertex with at least k
saturated coordinates |h_i|=1. Indeed if a putative vertex has fewer than k
active coordinate constraints, a nonzero tangent vector in K vanishing on
those coordinates gives two nearby cube points with the vertex as midpoint.
This is impossible at a vertex. Consequently sum_i |h_i|>=k.

For even d the vertices of the trace-zero cube {h in [-1,1]^d:sum h_i=0} are
exactly the balanced +/-1 vectors. At a vertex at least d-1 coordinates are
saturated; their odd sum forces the remaining coordinate, if any, to be +/-1.
Therefore every h in K intersection cube, and also -h, is a convex combination
of vectors indexing E_(d,theta). By convexity of trace-distance error, the
same epsilon bound holds for rho_+=(I+theta diag h)/d and rho_- with -h.
Because h is in K, Lambda(rho_+)=Lambda(rho_-). Triangle inequality gives
  theta sum_i |h_i|/d =T(rho_+,rho_-)<=2 epsilon.
Using sum |h_i|>=d-m proves (B1). No approximation, prior, physical oracle or
minimum effect weight is used. The d-outcome exact realization shows the
zero-error m>=d consequence is attained.

At epsilon<=theta/4, every such reconstruction uses m>=d/2 outcomes, hence
at least log2(d)-1 classical record bits when fixed-length outcome storage is
required. A factorized tensor measurement can have a succinct description
and still have d distinct records; the lower bound does not force an explicit
dense list when a circuit interface is supplied. It also does not lower-bound
expected bits under a named prior, adaptive apparatus work or energy. No
energy-per-bit premise is imported. Dense explicitly supplied joint Choi
matrices independently cost Omega(d^6 B) to read; that is a representation
cost under a different explicit input interface, not a universal input bound.

C. EXECUTED COMPILER EVIDENCE / SCOPE
povm_compiler_check.py is an exact rational REAL-SYMMETRIC POVM compiler plus
a small complex-free d=2 diagnostic. It uses a mixture of Z and the rational
rotated (3/5,4/5) basis, splitting one effect at weight 2^-200. Original minimum
tracial outcome probability is 2^-202. At e=2^-16 the compiled specification
uses six outcomes, exact PSD/normalization checks and maximum entry bit length
21; minimum compiled probability is 1/327690. The analytic guaranteed
infinity-to-L1 error is 9/32768; 101 real traceless unit-contraction floating
fixtures gave max ~2.784e-5. The floating fixtures are transcription diagnostics.
Exact positivity and rational arithmetic are distinct from the all-dimension
continuity proof. The implementation does not support arbitrary complex input
or calculate algebraic roots; those are included only in the proved compiler
specification, not claimed as executed features. Observed runtime ~0.0057 s.

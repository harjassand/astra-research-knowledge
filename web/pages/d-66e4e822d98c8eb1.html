# Actual recursive pair-check circuits and their unit-field blocks

7 October 2026. pde_transport9, verified Sol/max; no nested workers.
Own construction from the literal RX/RZ cellular maps, **independent
analytical PASS** at notes/pde_spectrum9/cycle18/ACTUAL_PAIR_CIRCUIT_PEER_GATE.md,
including the explicit arm paths, counts and signed-orbit representation.
This is an internal reconstruction, not external validation.
It acquires an actual circuit subclass and
an exact block reduction; it does not acquire a Davies leakage bound.

## 1. Exact circuit interface

Let S be a nontrivial pure-X logical support in a finite actual CSS code.
Suppose every original Z-check row restricts to either zero or exactly
two sites of S. Associate a multigraph G_S: vertices are sites of S and
each nonzero restricted Z check is an edge between its two sites.
Assume G_S connected. Its binary incidence matrix has kernel
span{1_S}; hence S has no nonempty proper zero-syndrome subset. It is
an actual binary column circuit, and its nontrivial logical class is
separately retained below.

The literal five-qubit source seed has

    H_X = [11100; 00111],   H_Z = [10110; 01101],
    order (NW,NE,C,SW,SE).

S={NW,SW} is nontrivial and its pair graph is one edge (the left Z check).
The construction below carries this property through both replacement
operations, so it is available at the actual final even levels. It does
not assert the circuit is a minimum-weight logical, a path, or a tree.

## 2. RX: an all-one CQ representative

The source RX complex has physical qubits CX^1 plus CQ^1; CQ^1 is the
vertex space of the doubled connected star graph Y_q. Put one on EVERY
CQ^1 vertex of Y_q for each old q in S, zero on all other qubits,
including CX^1. Call the new support S_RX.

Its local CQ coboundary is zero because graph-edge incidence annihilates
the all-one vertex vector. The gluing map into each of the two CZ^2
points is restriction to the terminal vertex of each adjacent Y_q. Thus
each such check sees exactly the number of old selected q neighbors,
which is zero or two by hypothesis. CX^2 checks see none. Consequently
every new Z-check restriction is zero or two:

* each CQ^2 graph edge has its two selected endpoints;
* each touched CZ^2 point joins the terminal vertices in two selected
  old Y_q blocks, one link in each layer;
* the other new Z checks vanish on S_RX.

Every selected Y_q is connected. Contracting them produces two parallel
copies of each edge of the old connected graph. The new pair graph is
therefore connected. Its binary kernel is again exactly the all-one
vector on S_RX.

Nontriviality can be proved without invoking an unspecified HPL
representative. If this CQ-only closed vector were a new X boundary,
its CX^1 component would be delta_X f_X=0. Since each Y_x is connected,
f_X is constant on each Y_x. RX has no CQ^0 or CZ^0. Restriction of each
such constant to the adjacent Y_q is all-one, so the CQ component of
the boundary is the all-one lift of an OLD X boundary. This would make
S an old boundary, contradiction. This also pays the possibility of
arbitrary CY_x 0-cochain potentials in the new boundary.

RX introduces belts and branching. Even the lifted seed support need
not remain a path: treating its spectrum as the open free-fermion chain
without a separate graph argument would be invalid.

## 3. RZ: paths in the actual doubled CZ blocks

In RZ the physical spaces are CZ^1 (1-skeleton edges in doubled Y_z)
and CQ^1 (vertices in doubled Y_q). Choose the layer-zero old-q apex
vertex a_q in every selected CQ^1 block. Its image under g_QZ^1 is a
single vertex in each adjacent Y_z. Images of distinct old q apices in
one Y_z are distinct. For each old Z check z meeting S={q,q'} in
exactly two sites, choose the layer-zero path q -> z -> q' through
the original z apex along its two distinct subdivided parent arms.
With Nsub=(ell-1)/2, this path has exactly 2Nsub CZ^1 edges. This is
a simple path in the actual doubled Y_z 1-skeleton. Add its CZ^1
edges to the selected CQ^1 vertices; other blocks have zero support.

The CZ coboundary is the graph boundary map. A simple path has precisely
the two required endpoints, so delta_Z(path)+g_QZ^1(a_q+a_q')=0 over
F2. There are no CQ^2 rows in RZ. This is therefore a closed actual X
support S_RZ. Restricted new Z-check rows are:

* at a path endpoint, one selected CQ vertex and one CZ path edge;
* at an internal path vertex, two distinct selected CZ edges;
* elsewhere, zero.

Paths in different old z blocks have disjoint CZ qubit spaces, even
when their geometric images overlap. A selected CQ vertex is shared
by all old incident blocks precisely as in the gluing map. The pair
graph is thus a graph subdivision of the old connected G_S. It remains
connected and is again a circuit. No Tanner gluing is substituted for
the source's cellular restriction maps.

To check nontriviality, sum CQ^1 coefficients separately in each Y_q.
The sum of the boundary of every CQ^0 graph edge is zero. Each old-x
layer point in CX^0 restricts to one endpoint in every adjacent Y_q,
giving the corresponding OLD X-check row under this parity map.
CZ^0 boundaries contribute no CQ^1 term. Thus the CQ parity image of
every new X boundary is an old X boundary. The constructed support
has CQ parity exactly 1_S, which is not such a boundary.

This proof uses connectedness of the actual Y_z 1-skeleton and the
literal transpose/restriction incidence. It does not require disks to
be disjoint in ambient space or require an interior path to avoid
other unselected CQ images; those images contribute zero coefficients.

## 4. Exact positive-X circuit Hamiltonian

Acquire S and G at any actual level as above. Initially set fields
outside S to zero. The original unit-check Hamiltonian restricted to
one orbit of the active X_i, i in S, has an exact representation by
d=|S| auxiliary spins, restricted to global-X parity eta:

    H_(eta,orbit) = E_const
       + sum_(edges e={i,j}) (1-sigma_e Z_i Z_j)/2
       - sum_(i in S) epsilon_i X_i,
    product_(i in S) X_i = eta.                                (1)

Here sigma_e=+/-1 is the ORIGINAL check sign in a chosen old reference
state. Original X-check labels and untouched Z-check labels determine
the orbit, E_const and possible constraints on the signs. The same
physical bath X_q for q in S is exactly the auxiliary X_q. Repeated
original checks give distinct unit edges; no edge weight is adjusted.

For a direct construction, choose one old reference syndrome state in
each conserved original-X-check and L sector. Apply all subsets of the
active X_i. The connected pair incidence has exactly the one full-S
relation, so it yields 2^(d-1) distinct syndromes. The relation acts as
a nontrivial pure-X logical, differing from the originally fixed L by
an X stabilizer; its sector sign is absorbed into eta. This agrees
with the parity states (|z>+eta|-z>)/sqrt(2) of the auxiliary spins.
Every edge check measures sigma_e z_i z_j, and every field flips z_i.
This proves (1) as an exact subspace representation of the original
Hamiltonian, not a comparison model.

The ORIGINAL decoder O becomes its actual syndrome-dependent
off-diagonal map between the two parity spaces. It must not be replaced
by a raw Z_i or a free-fermion zero mode without proving equality or a
controlled current-Gibbs comparison. Likewise, typical orbits need not
have sigma_e=+1: cycle products can be frustrated. The full Gibbs trace
weights all legal signed orbits and their multiplicities. An
unfrustrated ground orbit alone can have exponentially small mass in N.

## 5. What this acquires, what remains, and costs

The construction acquires connected graph-like circuits for every
actual RX/RZ level from the literal seed. The RZ paths are selected
by the two source-local parent arms, without shortest-path search;
all-one RX supports and binary nontriviality tests are direct. Given
the explicit actual complexes, support and graph acquisition is
polynomial in their size. Their
matrices themselves have N-site size; this is not a compact numerical
simulation of the huge admitted family.

There is also an exact graph-size ledger. If d and e are the old
pair-graph vertex/edge counts (including repeated original check rows),
then, with the same ell in both replacements,

    d_RX=2d+2(ell-1)e,       e_RX=2(ell+1)e,
    d_RZ=d+(ell-1)e,         e_RZ=ell e.                         (2)

For RX, every selected Y_q has 2(1+Nsub degree(q)) vertices,
2Nsub degree(q)+degree(q) graph edges, and the CZ rows add two links
per old edge. RZ subdivides every old graph edge to length ell. Thus
the RZ first Betti number e-d+1 is unchanged; RX gives 4e-2d+1.
Already the seed one-edge RX lift has d=e=2ell+2 and one cycle,
with four terminal tails. These counts explicitly reject a persistent
path/tree simplification of the acquired actual family.

Only active-circuit fields are present in (1). Ultimately making every
outside field strictly positive requires a separately chosen positive
total norm w and a stability argument for the specific conclusion.
Exact Davies frequency matching is not continuous in w; no bound from
small w alone permits that restoration. A proposed spectral inequality
must provide a finite algebraic frequency margin and field-description
cost before this step can be claimed.

The useful next target is the shell-frame defect (6) in
UNIT_ENERGY_SHELL_LOGICAL_REDUCTION.md for these actual signed Ising
graph blocks, weighted over their legal current Gibbs orbits. The
graphs generally have loops and branching; a conditional path
free-fermion computation does not classify them. If a structural
intertwiner cancels this defect, its dependence on syndrome frustration
and the original decoder must be retained.

This supplies a concrete actual geometry for the unresolved unit-check
problem. It is **not** a lower bound on leakage, an old-channel error
theorem, an all-encoding rejection, or a microscopic storage claim.
The nearest older circuit/Ising reductions are standard methods;
historical priority of this literal recursive lift is UNKNOWN.

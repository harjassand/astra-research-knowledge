# ASTRA Meta-Genesis quartic research packet

Read `ASTRA_META_GENESIS_Morrey_quartics.md` first.

## Status

A constructive reflection-invariant classification and related exact algebra are developed in the note. General planar Morrey, the full SO(2)-invariant quartic problem, and quasiconvexity of the retained interior example are NOT solved here. Historical novelty and external verification are unresolved.

## Replay the exact checks

With Python 3.10+ and SymPy available:

```sh
python verify_morrey_quartics.py
```

This executes 23 exact symbolic/rational checks and rewrites `verification_results.json`. It does not formally verify the whole analytic proof.

The exact moment calculator uses only the Python standard library:

```sh
python exact_fourier_moments.py
```

It checks four exact identities and exports `Wave` and `moment_vector` for other rational Fourier potentials.

## Exploratory material

The `exploratory` folder records numerical discovery tools, not proof certificates. They additionally use NumPy, SciPy, SymPy and/or PyTorch. Some optimization scripts retain the original `/mnt/data/astra_meta_genesis` output directory; change that path before replaying outside the original environment. The production exact verifier and moment calculator have no such path requirement.

The first sampled LP candidate failed rank-one validation. No counterexample from that search is claimed. The later retained quartic is globally rank-one convex by the exact certificate in the note, but its 24 finite Fourier searches establish no quasiconvexity theorem. The Fourier log records the last evaluated iterate before the final optimizer update; the saved state is the subsequent update.

# Finite-precision task certificates, and a transfer that fails

## 1. The exact input contract

Let H be a complex Hilbert space, a>0, P>=0 bounded, and let
Phi(X)=sum_i V_i X V_i* be a bounded positive subunital map: Phi(I)<=I.
Write g_a(Z)=Z(I+aZ)^-1 and F_P(X)=g_a(Phi(X)+P).
The source-spectrum note, sections 2 and 6, proves that F_P has a unique bounded
positive fixed point X_P and the modulus

    ||F_P(X)-F_P(Y)|| <= g_a(||X-Y||),   X,Y>=0.                  (1)

For clarity, if ||X-Y||<=d, positivity gives Phi(X)<=Phi(Y)+dI.
Operator monotonicity and functional calculus give
g_a(Z+dI)-g_a(Z)<=d/(1+ad) I; interchange X,Y. This proves (1),
including noncommuting X,Y. The fixed point is an identified target in this
section. An arbitrary positive subsolution A<=F_P(A) is a different contract.

For a single channel this covariance update is a classical discrete Riccati /
Kalman covariance operation, with observation H_obs=I and noise a^-1 I.
This note does not invent the operation or general goal-oriented approximation.
Its purpose is an exact error and transfer contract for this capital.

## 2. A sharp a-posteriori norm certificate

Suppose Y>=0 is bounded and an ACQUIRED whole-operator bound satisfies

    ||Y-F_P(Y)|| <= eta,   eta>=0.

Then

    ||Y-X_P|| <= R_a(eta)
               = (eta+sqrt(eta^2+4eta/a))/2.                    (2)

Proof. Put d=||Y-X_P||. The triangle inequality and (1) imply
d<=eta+d/(1+ad). Thus a d^2-a eta d-eta<=0, whose nonnegative
root is (2). No spectral gap or compactness is used. Conversely, for any e>=0,

    eta <= a e^2/(1+ae)  implies  ||Y-X_P||<=e.                 (3)

The dependence is sharp: Phi=Id, P=0 has X_P=0, and Y=eI has
eta=e-g_a(e)=a e^2/(1+ae) and error exactly e. It works in finite
and infinite dimension. For small e the required norm residual is quadratic,
eta~a e^2, rather than a linear accuracy promise. This is a sufficient worst-case
precision requirement; problem-specific structure can improve it.

This is the same scalar stability mechanism as the source's outside-g_a
essential-norm floor, now applied to a fixed-point approximation. It does not
make a nonzero residual certify compactness. On an infinite-dimensional H the
sharp example Y=eI is noncompact for every e>0.

If the supplied source is approximate instead, Q>=0 and ||P-Q||<=zeta, the source's
inside-g_a perturbation proof gives

    ||X_P-X_Q|| <= S_a(zeta)
                 = (sqrt(zeta^2+4zeta/a)-zeta)/2.               (4)

Therefore an approximate solve for F_Q has error at most
R_a(eta)+S_a(zeta) relative to X_P. Outside and inside errors have
different signs in their root formulas and must not be interchanged.

## 3. What a task can use without certifying a spectral class

Let a finite action family have losses

    ell_u(X)=c_u+Tr(Q_u X),

where Q_u is a supplied selfadjoint trace-class operator, c_u a supplied scalar,
and L=max_u ||Q_u||_1<infinity. All acquisition, representation and trace
evaluation costs are charged. Equations (2) and trace duality give

    |ell_u(Y)-ell_u(X_P)| <= ||Q_u||_1 R_a(eta).                (5)

Thus if the computed loss margin of a selected action over every competitor is
greater than 2 L R_a(eta), that action minimizes the true losses. The sharper
pointwise certificate, identified by the independent critic, subtracts first:

    |[ell_v(Y)-ell_u(Y)]-[ell_v(X_P)-ell_u(X_P)]|
       <= ||Q_v-Q_u||_1 R_a(eta).                              (6)

Only this smaller pairwise margin is needed. If D=max_(u,v)||Q_u-Q_v||_1,
minimizing approximate losses incurs true regret at most D R_a(eta)<=2L R_a(eta).
Proof: apply trace duality to Q_v-Q_u, and compare the selected action with
a true optimum. Common task components cancel exactly; they need not be
estimated to the absolute accuracy their separate norms would suggest.

For a family indexed by unknown theta, the same statement holds uniformly if
the approximation and trace-norm bounds hold for every theta. With exactly the
same acquisition output laws and policy class, changing only those loss tables
changes minimax risk by at most L R_a(eta), and a
policy optimal for the approximate table has excess minimax risk at most twice
that quantity. Pairwise pointwise cancellation alone does not replace this
minimax-risk bound: a theta-dependent common loss offset can change which theta
is worst. This does not optimize or acquire the experiment; it only bounds
loss-table perturbation for an unchanged acquisition class.

Consequently a strict scientific decision can remain certified when a nonzero
residual cannot establish compactness or a Schatten class. The conclusion needs
an identified fixed-point target and task margin. It does not require the full
singular-value list, but it does require the actual uniform residual guarantee.

For an exact source-word iterate X_k, the source supplies instead
||X_P-X_k||<=1/[a(k+1)]. Regret<=2L/[a(k+1)] follows. The dimension
D_k, Gram construction, source/operator acquisition, conditioning and arithmetic
precision remain paid. Free-word branching can make D_k exponential in k even
with rank-one P. A small list of formulas does not provide a cheap loss compiler.
If only an inexact solve and small gap Delta are available, (3) shows that the
universal norm-residual requirement scales as a Delta^2/(4L^2) near zero.

## 4. Executed obstruction: a subsolution is not an acquired response

Take H=C, a=1, Phi=Id and P=1/2. The unique fixed point is X_P=1/2.
Both A_0=0 and A_1=1/2 satisfy A<=g_1(A+P), with exactly the same
source and propagation data. They are also actual scalar operator comparisons:
T_i=sqrt(A_i) and B=sqrt(1/2) satisfy T_i*T_i<=g_1(T_i T_i*+BB*).

Consider actions u in {0,1} and loss (u-2A)^2. At A_0 the unique optimum
is u=0; at A_1 it is u=1. A decision procedure given only the comparison
data cannot distinguish them. If it randomizes with probability p of choosing
u=1, its two regrets are p and 1-p, hence worst-case regret at least 1/2.
This is an exact information-interface counterexample, not a runtime lower bound
for algorithms given T or additional observations.

Thus the source's A<=X_P theorem cannot by itself provide two-sided losses for
an unspecified A. If Q>=0, a one-sided statement survives:

    Tr(QA) <= Tr(QY)+||Q||_1 R_a(eta).

For the scalar comparison, an exact rank or Schatten certificate is still a
valuable upper bound on an already specified T. It supplies no acquisition
oracle for the target, its polar factor, task losses or a physical observable.
In particular this fixed-point result does not close the N764/N768 interacting
inverse/rank or loss-acquisition obligations.

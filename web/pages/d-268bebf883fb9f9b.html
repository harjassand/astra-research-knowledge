PHASED COUNTER EXTENSION: ARBITRARY COMPLEX MATCHING ENTRIES
c03_s01, authorized phase two. Read together with PHASED_DENSE_SECTOR.txt.
This extension retains the same supplied rational-complex F, hard c_k target,
exact formal-square-root sample and capped FPRAS. It requires no irrational
phase field, numerical singular values, hidden norm or optimal matching.

STRONGER ACQUIRED CLASS

Let n=2q, 1<=k<=q. From F acquire G by retaining its diagonal and both FULL
complex off-diagonal entries in the fixed pairs (0,1),(2,3),...; set every
other off-diagonal entry to zero. For pair j write a_j=G_(2j,2j+1) and
b_j=G_(2j+1,2j). Define the exact rational quantities

 beta_j=|a_j|^2+|b_j|^2, beta_min=min_j beta_j,
 Delta^2=||F-G||_F^2.

If beta_min>0 and

 Delta^2<=beta_min/(1024 k^2),                                  (C')

then an explicitly acquired rational-unit-phase site-sign estimator satisfies

 E X_k=c_k(F),
 3c_k(G)/4<=X_k<=4c_k(G)/3 on EVERY draw,
 E X_k^2/c_k(F)^2<=256/81<4.

Here c_k(G)=e_k(beta_1,...,beta_q) is acquired exactly in O(nk) rational
operations. Consequently a capped polynomial-bit FPRAS uses
O(epsilon^-2 log(1/failure)) draws, including k=Theta(n). The real-reference
certificate Delta^2<=beta_min/(256k^2) from the earlier report retains its
larger radius for real matching entries; (C') admits arbitrary phases in
the strong matching entries, and can discard less residual by retaining
their full complex values.

EXACT RATIONAL PHASE ACQUISITION

For each pair set w=a_j conj(b_j), m=16k. Construct the O(k) exact phases

 alpha = +/- (m^2-l^2+2 i m l)/(m^2+l^2), l=-m,...,m.           (P)

Each has modulus exactly one and Q(i) entries of O(log(k+1)) bits. Set
alpha_(2j)=1, and choose alpha_(2j+1) among (P) minimizing the exact rational
|Re(w conj(alpha))|. No continuous optimization or square root is queried.

Coverage proof: the rational unit-circle map alpha(t)=(1-t^2+2it)/(1+t^2)
has derivative magnitude 2/(1+t^2)<=2. Its t in [-1,1] half-circle has
nonnegative real part; adding its negative covers the whole circle. Given
the ideal quadrature point i w/|w| when w!=0, choose its sign so its real
part is nonnegative. It has t=Im(alpha)/(1+Re(alpha)) in [-1,1]. A nearest
grid l/m is within 1/(2m), so its rational unit phase is within 1/m of the
ideal point or its negative. The ideal Re(w conj(alpha)) is zero. Therefore
the minimizing candidate satisfies

 |Re(w conj(alpha))|<=|w|/m<=beta_j/(2m).

The final inequality is 2|a_j||b_j|<=|a_j|^2+|b_j|^2. If w=0 the cross
term is identically zero for every phase. Thus the acquired, exact quantity

 h_j=2|Re(w conj(alpha_(2j+1)))|/beta_j <=1/(16k).                (1)

SMALL PHASE ERROR PLUS SMALL RESIDUAL

For independent real signs s and t_i=alpha_i s_i, each baseline skew block
has entry a_j s_(2j)-alpha_(2j+1)b_j s_(2j+1). Its squared singular value is

 beta_j-2s_(2j)s_(2j+1)Re(w conj(alpha_(2j+1))),

which lies in beta_j(1+-h), with h=max_j h_j<=1/(16k). Each value occurs
twice. These inequalities survive sorting: if each scalar lies between
the same two positive multiples of its corresponding beta_j, its ordered
values lie between those multiples of the ordered beta values as well.

For every sign word, ||A_t(F)-A_t(G)||_2<=2Delta. Put
rho=2Delta/sqrt(beta_min)<=1/(16k) by (C'). Using the ordered singular-value
Lipschitz inequality from the earlier report, and sqrt(1-h)>=1-h,
sqrt(1+h)<=1+h, the corresponding ordered singular values of A_t(F) lie
between

 (1-h-rho)sqrt(beta_j) and (1+h+rho)sqrt(beta_j).

Since h+rho<=1/(8k), every k-fold product of squared singular values and
their positive elementary-symmetric sum lies between

 (1-1/(8k))^(2k)e_k(beta) and (1+1/(8k))^(2k)e_k(beta).

The earlier Bernoulli/geometric argument bounds these factors by 3/4 and
4/3. This proves the asserted pointwise bound. Fixed phases of exact modulus
one preserve the Pfaffian/Fourier unbiasedness for arbitrary F, so taking
expectation proves the same norm comparison and the second-moment bound.
No phase approximation error is left uncharged: it is explicitly in (1).

For a simultaneous all-coefficient counter, choose k=q in (C') and m=16q.
The same phase error/residual inequalities are sufficient for every j<=q.
Compute the full coefficient vector on each sign word, use median means
and confidence failure/(q+1), and sum coefficients for the grandcanonical
norm. This is a proved algorithmic consequence; its separate all-vector
wrapper is not implemented. Arbitrary physical-prefix/Born sampling is
still outside this result.

COST AND IMPLEMENTATION

The phase search has O(nk) candidate evaluations with polynomial-bit Q(i)
arithmetic. Delta^2,beta_min and the certificate use O(n^2) exact operations.
No adverse conditioning or tiny beta incurs more than its encoded bit cost.
All acquired phases have one common denominator of O(n log(k+1)) bits; combine
it with F's common denominator. Every sign sample has a common denominator
dividing that product to power 2k, so the previous uniform bit/averaging proof
applies. Each draw uses n fair bits. Exact sample evaluation is the same
O(k n^3+k^2) rational Newton/trace/formal-square-root program. Median batching
is fixed and capped. The counter returns NOT_CERTIFIED if (C') fails.

approximate_count(...,complex_matching=True), in addition to the earlier
real-matching functions. The admitted complex baseline is not asserted
sample-flat; its samples are uniformly close to e_k(beta). Its MEAN is exact.

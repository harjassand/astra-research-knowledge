# Fixed rate and parameter conventions for the sealed obstruction

## One unchanged finite-channel interface

Every result concerns ONE specified original system coupling A=X_q, selected from the actual code before applying the perturbation, and the SAME rate function evaluated at the old/current Bohr frequencies. The site q may depend on the finite code level. The theorem does not assert constant-time error for an extensive inventory of all one-site channels by treating its total norm as constant. No nonzero Lamb shift is implicitly included.

The general proofs use a fixed upper envelope Gamma and a positive lower gamma_* on |omega|<=W=7hmax+1. They therefore allow several explicit choices, but displayed numerical values must use one choice consistently:

* Spectrum/root logistic example: gamma_L=1/(1+exp(-beta omega)), Gamma=1, gamma_*=1/(1+exp(beta W)).
* Transport logistic example: 2gamma_L, Gamma=2, gamma_*=2/(1+exp(beta W)).
* Fixed Gaussian-cut example: gamma_G=exp(-omega^2)/(1+exp(-beta omega)). It is <=1, and one may retain the conservative Gamma=2 used by the selector.

For every example gamma(-omega)=exp(-beta omega)gamma(omega). The Gaussian-cut spectrum is integrable and smooth with rapidly decaying tails. It is chosen once, unchanged before/after adding fields. No physical coupling synthesis, microscopic approximation or uniform reservoir theorem is acquired by specifying this formal Davies rate.

## Cost and limit order

Its field precision scales exponentially with circuit size; near-unit total norm adds the supplied positive tolerance's denominator height.

# Cycle 10 implementation repair record

The independent hostile audit is preserved unchanged at
`work/agents/c10_reversible_module_hostile/REPORT.md`. Its two executable
findings are repaired below.

1. **Merged-edge coefficient bound.** The previous global upper bound took
   `max_r M_r`, although a simple directed reaction can aggregate same-source,
   same-direction tuple contributions from multiple modules. Two identical
   unit `0 <-> X` modules have merged coefficient 2 while the old bound was 1.
   The public convention is now explicit: coincident directed tuple edges are
   summed into a simple graph and the compiler reports
   `kappa=min_r m_r`, `K=sum_r M_r`. The exact collision fixture and replay
   verify both merged directions have coefficient 2 and the reported K is 2.

2. **Python decimal digit cap.** Python 3.11+'s default 4,300-digit conversion
   cap rejected valid exact inputs/outputs. The standalone compiler now calls
   `sys.set_int_max_str_digits(0)` when available. Exact integer,
   integer-ratio, and finite-decimal strings (no exponent syntax), tuple
   counts, and rational output remain exact. JSON floats and exponent-form
   strings are rejected so explicit digits charge the rational bit size; no
   rounding or truncation is used.
   This changes a process-wide Python setting, appropriate to this standalone
   local CLI. Do not embed it in a service without a separate resource policy.
   A 5,001-digit positive rational fixture and a generated valid schema input
   with 15,000 explicit two-term factors exercise input and output conversions,
   including the exact `2^15000` tuple count. `json_float_rejected.json` and
   `scientific_rational_rejected.json` check that inexact/compact encodings are refused.

3. **Rank-zero/self-loop contract.** The schema requires at least one module
   and rejects equal endpoints. Therefore each accepted jump is nonzero and
   total stoichiometric rank is at least one; rank zero is outside the input
   domain. The sufficient strong gate is exactly rank one versus higher-rank
   `UNKNOWN`. The self-loop fixture is rejected as `INVALID_INPUT`; JSON float coefficients
   are also rejected so no inexact decimal rounding enters the rational schema.
   No standard-strong argument relies on accepting neutral self-loop sources.

4. **QSSA evidence boundary.** The Schnell–Mendoza compiler now emits the
   initial-state Eq. 38 enzyme-scale ratios. In the synthetic fixture these
   are `1/3`, `1/6`, and `2/9`, maximum `1/3`. This does not demonstrate the
   required much-less-than-one QSSA regime. Extinction remains proved exactly
   for the reduced ODE only; no error bound for the unreduced mechanism is
   asserted.

The weak-endotactic paired-edge theorem is unchanged. The rank-one strong
result is a standard weak-reversibility/same-linkage-subspace consequence,
not a new geometric principle. Higher-rank permanence remains conditional on
the N33 candidate; no novelty or priority claim is made.

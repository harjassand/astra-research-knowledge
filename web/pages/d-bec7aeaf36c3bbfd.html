UNIFORM ALL-T CUMULATIVE CASIMIR COUNT FOR A FIXED SIMPLE ROOT SYSTEM
Date: 2026-10-08
Status: internally proved for every fixed compact connected simple G; explicit
root-system-dependent constants are given. The estimate is uniform in the
carrier. No sharpness or novelty claim is made.

1. STATEMENT, SCOPE, AND NORMALIZATION

Fix a compact connected simple group G, with root system Phi, rank r, positive
root set Phi+, p=|Phi+|, Weyl group W, and q=p-r. Work in the Euclidean root
space E with the invariant inner product normalized so every long root has
squared length 2. Short-root lengths are left at their type-dependent values;
no simply-laced assumption is used. Put

  alpha^vee = 2 alpha/(alpha,alpha),
  rho = (1/2) sum_(alpha in Phi+) alpha,
  rho^vee = (1/2) sum_(alpha in Phi+) alpha^vee.

For a dominant highest weight nu, use the basic half-Casimir convention

  c2(nu) = (nu,nu+2 rho)/2
         = ||nu||^2/2 + (nu,rho).                              (1)

This fixes the scale for every simple type, including B, C, D, F4 and G2.
For SU(m), it agrees with Hermitian fundamental generators normalized by
Tr_fund(T_A T_B)=delta_AB/2. There is no common fundamental-trace convention
for all simple groups, so (1) is the scale definition here. Some references
call (nu,nu+2rho), without the factor 1/2, the basic Casimir; that is the
rescaling c2 -> 2c2 and only changes the constants below.

Let V_lambda be any irreducible representation allowed by the global form
of G. For the conjugation action on End(V_lambda)=V_lambda tensor V_lambda*,
write m_lambda(nu) for the multiplicity of V_nu, and define the full
cumulative isotypic dimension

  D_lambda(T) = sum_(nu dominant, c2(nu)<=T)
                    m_lambda(nu) dim(V_nu),   T>=0.            (2)

Then there is an explicit finite C_G, depending only on the normalized root
system, such that for every carrier lambda and every real T>=0,

  D_lambda(T) <= C_G (1+T)^p.                                 (3)

The constant and the exponent are independent of lambda. For a non-simply
connected form of G the allowed highest weights are a subset of those for
the simply connected cover, so the same upper bound applies.

2. CONSTANTS

All norms and pairings below are those in the long-root-length-2 metric.
Define

  u_G = ||rho^vee||,
  v_G = ||rho||,
  s_G = max_(alpha in Phi+) ||alpha^vee||/(rho,alpha^vee),
  t_G = max_(simple alpha_i) ||alpha_i^vee||,
  A_G = sqrt(2) u_G,
  B_G = 1 + 2 u_G v_G.

The denominator (rho,alpha^vee) is a positive integer (the coroot height),
so s_G is finite. One valid constant is

  C_G = |W| (A_G^2+B_G^2)^(q/2)
             (1+2 s_G^2)^(p/2) (1+2 t_G^2)^(r/2).             (4)

This deliberately loose expression uses only the finite normalized root
system, including its actual short-root lengths. The root counts used in the
exponent are:

  type       r       p=|Phi+|      q=p-r
  A_r        r       r(r+1)/2      r(r-1)/2
  B_r,C_r    r       r^2            r(r-1)
  D_r        r       r(r-1)         r(r-2)
  G2         2       6              4
  F4         4       24             20
  E6         6       36             30
  E7         7       63             56
  E8         8       120            112

For a rescaled Laplacian with eigenvalue c_(2,kappa)(nu)=kappa*c2(nu),
kappa>0, the same proof gives (3) with the constant

  C_(G,kappa) = |W| (B_G^2+2u_G^2/kappa)^(q/2)
       (1+2s_G^2/kappa)^(p/2) (1+2t_G^2/kappa)^(r/2).          (5)

In particular, the no-half convention has kappa=2. The stated normalization
is therefore explicit rather than an implicit choice of Killing-form scale.

3. MULTIPLICITY IS BOUNDED BY ZERO-WEIGHT MULTIPLICITY

Let z_nu=dim V_nu[0], the dimension of the zero-weight space. For every
carrier lambda and dominant output nu,

  m_lambda(nu) <= z_nu.                                        (6)

Here is a direct proof valid for every compact simple root system. By
semisimplicity, quotient-oriented Hom and tensor-Hom currying give

  m_lambda(nu)
   = dim Hom_G(V_lambda tensor V_lambda*, V_nu)
   = dim Hom_G(V_lambda*, V_lambda* tensor V_nu).                (7)

Put mu=lambda*, and let v_mu be a nonzero highest vector in V_mu. For an
intertwiner phi in the last Hom space, w=phi(v_mu) is a highest vector of
total weight mu. Since the weights of V_mu lie in mu-Q_+, write

  w = sum_(beta in Q_+) w_beta,
  w_beta in V_mu[mu-beta] tensor V_nu[beta],                     (8)

where Q_+ is the nonnegative integer span of the simple roots. Its beta=0
term is v_mu tensor p_phi for a unique p_phi in V_nu[0]. This defines a
linear map phi -> p_phi.

Suppose p_phi=0 but w!=0, and choose beta of least root height among indices
with w_beta!=0. Then beta>0. For each simple raising operator e_i, highestness
of w gives (e_i tensor 1 + 1 tensor e_i)w=0. Project to the tensor weight
space V_mu[mu-beta+alpha_i] tensor V_nu[beta]. The first term is
(e_i tensor 1)w_beta. The only possible second term comes from
w_(beta-alpha_i); this is absent if beta-alpha_i is not in Q_+, and otherwise
vanishes by minimality. Thus (e_i tensor 1)w_beta=0 for every i. The common
kernel of the simple raising operators in the irreducible first factor is
its highest line, which has first weight mu, whereas w_beta has first weight
mu-beta!=mu. This contradiction proves w=0. Since v_mu generates V_mu,
phi=0. Hence phi -> p_phi is injective into V_nu[0], proving (6).

The dual convention in (7) matters: it is the quotient-oriented Hom
Hom(V_lambda tensor V_lambda*,V_nu) that curries to
Hom(V_lambda*,V_lambda* tensor V_nu), with nu (not nu*) in the second
factor. The argument requires no regularity of lambda and no PRV inference.

The center of the simply connected cover acts trivially on End(V_lambda),
so every occurring nu lies in the root lattice Q. Also, if nu is outside Q,
all weights of V_nu lie in nu+Q and z_nu=0. We drop this root-lattice
restriction in the upper count, which only enlarges it.

4. KOSTANT ZERO-WEIGHT COUNT AND THE EXPONENT p-r

For eta in Q, let P(eta) be the number of expressions

  eta = sum_(alpha in Phi+) n_alpha alpha,  n_alpha in Z_>=0,

and set P(eta)=0 if there is no such expression. Kostant's multiplicity
formula gives

  z_nu = sum_(w in W) (-1)^ell(w) P(w(nu+rho)-rho).             (9)

For eta=sum_i c_i alpha_i in Q_+, define ht(eta)=sum_i c_i. In the chosen
Euclidean realization, (rho^vee,alpha_i)=1 for each simple root, so

  ht(eta)=(rho^vee,eta).                                       (10)

This is the point where nonsimply-laced systems require care: (10) uses the
dual Weyl vector rho^vee, not rho. Likewise Weyl's dimension denominator
below is the coroot height (rho,alpha^vee). Confusing these two heights is
not valid for B/C/F/G types.

There are p positive roots and r simple roots, hence q=p-r nonsimple
positive roots. In any positive-root partition of eta, each coefficient
n_alpha is at most ht(eta), because every positive root has positive integer
height. Choose the q coefficients corresponding to nonsimple roots first;
once they are fixed, the simple-root coefficients are uniquely determined
since the simple roots form a basis. They may fail to be nonnegative, but
there is at most one admissible choice. Therefore

  P(eta) <= (1+ht(eta))^q.                                      (11)

This proves the p-r exponent directly from the root partition problem; it
does not assume a zero-weight growth estimate.

For eta_w=w(nu+rho)-rho, orthogonality of W and the triangle inequality give

  ||eta_w|| <= ||nu||+2||rho||.

If P(eta_w)>0, eta_w is in Q_+, so (10) and Cauchy-Schwarz imply

  ht(eta_w) <= u_G (||nu||+2v_G).

For dominant nu, (nu,rho)>=0 and hence c2(nu)>=||nu||^2/2. Thus c2(nu)<=T
implies ||nu||<=sqrt(2T). Taking absolute values in (9) and applying (11),

  z_nu <= |W| (B_G+A_G sqrt(T))^q
       <= |W| (A_G^2+B_G^2)^(q/2) (1+T)^(q/2).                (12)

The last step is Cauchy-Schwarz applied to (B_G,A_G) and (1,sqrt(T)). It
also covers q=0, in which case every Kostant partition count is at most 1.

5. WEYL DIMENSION AND NUMBER OF DOMINANT LABELS

Write nu=sum_(i=1)^r a_i omega_i, with Dynkin labels
a_i=(nu,alpha_i^vee) in Z_>=0. If c2(nu)<=T then

  a_i <= ||nu|| ||alpha_i^vee|| <= t_G sqrt(2T).

The number of possible dominant label tuples is therefore at most

  (1+t_G sqrt(2T))^r
      <= (1+2t_G^2)^(r/2) (1+T)^(r/2).                         (13)

Weyl's dimension formula, written with coroots, is

  dim(V_nu) = product_(alpha in Phi+)
                   (nu+rho,alpha^vee)/(rho,alpha^vee)
             = product_(alpha in Phi+)
                   (1+(nu,alpha^vee)/(rho,alpha^vee)).          (14)

Each denominator is a positive integer and each factor is at most
1+s_G||nu||. Thus

  dim(V_nu) <= (1+s_G sqrt(2T))^p
             <= (1+2s_G^2)^(p/2) (1+T)^(p/2).                 (15)

Combining (6), (12), (13), and (15), and summing over all dominant labels
in the Casimir ball, gives

  D_lambda(T)
   <= |W|(A_G^2+B_G^2)^(q/2)
        (1+2s_G^2)^(p/2) (1+2t_G^2)^(r/2)
        (1+T)^((q+p+r)/2)
   = C_G(1+T)^p,

because q=p-r. This proves (3). The exponent arithmetic is: zero-weight
multiplicity contributes q powers of sqrt(T), Weyl dimension p powers of
sqrt(T), and label count r powers of sqrt(T), totalling 2p powers of
sqrt(T), i.e. T^p. No stable-range restriction is used.

6. CARRIER SUPPORT AND THE LARGE-T PLATEAU

The all-label estimate above already applies to every T, whether below or
above the carrier's support. For an explicit saturation check, put

  sigma=lambda+lambda*,  lambda*=-w_0 lambda.

The top constituent of V_lambda tensor V_lambda* has highest weight sigma;
every constituent nu is dominated by sigma. If sigma-nu=sum_i b_i alpha_i
with b_i>=0, then

  c2(sigma)-c2(nu) = (sigma-nu,sigma+nu+2rho)/2 >= 0,

since sigma and nu are dominant. Hence the maximum supported Casimir is
c2(sigma), and D_lambda(T)=dim(V_lambda)^2 for T>=c2(sigma).

This plateau also obeys a root-system-only polynomial bound. The map
i -> i* induced by -w_0 permutes the fundamental weights, so if lambda has
Dynkin labels a_i, sigma has labels a_i+a_(i*)>=a_i. Consequently

  ||lambda|| <= sum_i a_i||omega_i||
       <= K_G^* ||sigma||,
  K_G^* = sum_i ||omega_i|| ||alpha_i^vee||.

By (14), dim(V_lambda)<=(1+s_G||lambda||)^p. Since
c2(sigma)>=||sigma||^2/2 and T>=c2(sigma),

  dim(V_lambda)^2
     <= (1+2s_G^2(K_G^*)^2)^p (1+||sigma||^2)^p
     <= [2(1+2s_G^2(K_G^*)^2)]^p (1+T)^p.                    (16)

Thus both the unsaturated range and the full plateau are covered; the direct
proof of (3) does not need a carrier-dependent cutoff.

7. FINITE TYPE / EXPONENT AUDIT

The count premise has no counterexample among the finite irreducible root
systems: (11) is a coefficient injection for every positive-root partition,
and (6) is an explicit highest-vector coefficient injection for every
compact simple G. The argument is independent of root lengths except in the
finite constants and the correctly distinguished rho/rho^vee pairings.

Small checks:

* A1 has r=p=1 and q=0. For highest weight n omega, zero weight occurs iff n
  is even and then z_(n omega)=1. This matches P(eta)<=1 and confirms the
  q=0 edge case; the label count and Weyl dimension each contribute one
  square-root power, giving D(T)=O(T).
* B2 has simple roots alpha1=e1-e2 (long), alpha2=e2 (short), with long-root
  length squared 2. Its positive roots are alpha1, alpha2, alpha1+alpha2,
  alpha1+2alpha2, so p=4, r=2, q=2. A partition of x alpha1+y alpha2 is
  counted by nonnegative a,b,c,d satisfying a+c+d=x and b+c+2d=y; fixing
  c,d (the two nonsimple-root coefficients) fixes a,b uniquely. Direct
  Kostant-sum checks for highest labels (n,n), n=1,...,6, give zero-weight
  multiplicities 2,5,8,13,18,25. These finite values are only a diagnostic,
  not an asymptotic claim; the theorem relies on (11), not extrapolation.

The central-character restriction can reduce the actual label count, but it
was not needed. Replacing the type-specific metric by an unspecified
"Casimir" scale, using rho instead of rho^vee for ordinary root height, or
using (rho^vee,alpha^vee) instead of (rho,alpha^vee) in Weyl's formula would
leave a normalization gap in nonsimply-laced types; (1), (10), and (14)
avoid those pitfalls.

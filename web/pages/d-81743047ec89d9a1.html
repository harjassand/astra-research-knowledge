# No-expansion exact recognition of positive-rational endotactic structure

**Result.** Positive rational rate channels admit an exact structural test that never forms the common-denominator product. In arbitrary dimension, a failure has a polynomial-bit rational direction certificate, so non-endotacticity is in NP and recognition is in coNP. For every fixed species dimension `d`, a deterministic polynomial-time algorithm follows from enumerating faces of one central hyperplane arrangement and solving rational linear programs. The direct all-dimensional finite procedure in the existing rational-lift report is still an exact exponential algorithm; the fixed-`d` bound below is a separate complexity refinement, not a claim of a polynomial-time algorithm when `d` varies.

## Interface and exact rule

For each labeled channel `e`, the input consists of a jump `nu_e in Q^d` and finite, nonempty rational supports `A_e,B_e subset Q^d` for

```text
rho_e(x) = P_e(x)/Q_e(x),
P_e(x) = sum_(alpha in A_e) p[e,alpha] x^alpha,
Q_e(x) = sum_(beta in B_e) q[e,beta] x^beta,
```

with every displayed coefficient strictly positive. Terms with the same exponent are first collected. Coefficient values do not enter the structural test: positivity keeps every support term present, and makes every denominator positive on the positive orthant. Negative and rational exponents are allowed there.

For a direction `r in R^d`, put

```text
mP_e(r) = min_(alpha in A_e) r·alpha
mQ_e(r) = min_(beta in B_e) r·beta
tau_e(r) = mP_e(r) - mQ_e(r)
E_r = {e : r·nu_e != 0}.
```

The exact condition is vacuous for `E_r` empty; otherwise every label minimizing `tau_e(r)` over `E_r` must satisfy `r·nu_e > 0`. Ties are universal: one minimum-tied label with negative projected jump is a failure. Neutral labels are removed *before* taking the minimum; their `tau` may be strictly lower than all active labels without affecting the condition. This is the `r=-w` form of the standard essential-source rule.

The positive-lift identity explains why this is the correct rule without constructing any lifted sources. If

```text
Gamma_e = A_e + sum_(f != e) B_f,
C(r) = sum_f mQ_f(r),
```

then independent minimization over a finite Minkowski sum gives

```text
min_(gamma in Gamma_e) r·gamma
  = mP_e(r) + sum_(f != e) mQ_f(r)
  = tau_e(r) + C(r).
```

This identity holds on all support tie faces, and collisions in the Minkowski sum cannot delete a source because all collected products of coefficients are positive. `C(r)` is common to every channel, so it disappears from comparisons among active labels. The explicit lift may contain `sum_e |A_e| product_(f != e)|B_f|` source tuples; this test only reads the sparse supports.

## Rational counterdirection certificates

Failure is equivalent to the existence of a label `e` and direction `r` such that

```text
r·nu_e < 0,
r·nu_f != 0 => tau_e(r) <= tau_f(r)  for every f.
```

Suppose a real witness exists. Record its active set `J=E_r`, its sign for each `r·nu_f` with `f in J`, and one minimizing exponent from every `A_f` and `B_f`. On that branch:

- the chosen numerator and denominator exponents are minima, enforced by rational homogeneous linear inequalities;
- each active sign is fixed, and every neutral edge is constrained by `r·nu_f=0`;
- all required `tau_e<=tau_f` comparisons are homogeneous rational linear inequalities.

Scale the witness by a positive scalar until `r·nu_e<=-1` and every active `|r·nu_f|>=1`. This is possible because there are finitely many nonzero active projections and all comparisons are homogeneous. The selected branch is now a nonempty rational polyhedron. A nonempty rational linear system has a rational feasible point of bit size polynomial in its coefficient bit size (for example, minimize `t` subject to `-t<=r_i<=t`; an optimal rational basic solution has the standard determinant bit bound). Thus a violating rational `r` of polynomial encoding length always exists.

The executable checker `verify_direction_witness.py` verifies a claimed rational `r` using only `Fraction`: it computes the active labels, every support minimum, all tied minimizers, and the offending labels. This certificate is polynomially checkable in the explicit sparse input size. The theorem is an upper bound only: no hardness lower bound is established here.

## Fixed-dimension deterministic algorithm

Let

```text
H <= m + sum_e [binom(|A_e|,2) + binom(|B_e|,2)]
```

be the number of input hyperplanes before removing zero/repeated normals. Form the central arrangement through the origin of the reaction hyperplanes `nu_e·r=0` and all within-support comparison hyperplanes `(alpha-alpha')·r=0` for pairs in each `A_e` and `B_e`.

Each relatively open face of this arrangement fixes (i) whether each channel is active, positive, negative, or neutral, and (ii) the set of minimizers in every support. On a face, choose any one of the minimizing exponents in each support; ties persist identically throughout that face, so `tau_e` is a fixed linear form there. For each face and each active label `e` with negative sign, ask whether the following rational linear system is feasible:

```text
face equalities:        r·h = 0,
face strict signs:      sigma_h (r·h) >= 1,
minimum comparisons:    tau_e(r) - tau_f(r) <= 0 for all active f.
```

Here `h` ranges over arrangement normals; zero signs use equalities, and `sigma_h in {+1,-1}` is the face's sign for nonzero forms. Replacing every strict sign by margin `1` is exact because the face and all `tau` comparisons are homogeneous: any point in the relative interior can be scaled until all its finitely many nonzero arrangement forms have magnitude at least one. The edge `e` itself is a negative active sign, so the all-zero face cannot produce a witness. A feasible LP is a refutation; infeasibility for every such face and edge certifies the all-directions property.

A central arrangement of `H` hyperplanes in `Q^d` has `H^{O(d)}` faces, including its lower-dimensional faces. Incremental exact arrangement construction enumerates just the realizable faces, after which each LP has `d` variables and `O(H+m)` constraints. Therefore the total is polynomial in support count and rational bit length for every fixed `d`, with a conservative `H^{O(d)}` face bound. As a parameterized statement this is XP in `d`, not FPT: the exponent depends on `d`. This route handles neutral faces directly and does not need hyperplanes comparing every possible pair of `tau` pieces.

## Relationship to prior procedures and limits

The existing `RATIONAL_RATE_TROPICAL_LIFT.md` already gives the Minkowski identity and an exact all-dimensional branch-enumeration recognizer, with at most `m * 3^m * product_e(|A_e||B_e|)` rational LP calls. It also states correctly that materialized denominator expansion can be exponential and that no general runtime advantage over lifted-graph MILP is known. The 2026-10-08 positive-rational audit independently checks the lift/tropical equivalence, including within-support ties, cross-edge ties, neutral exclusion, and sign reversal `w=-r`; its dimension-independent algebraic result is compatible with the recognition argument here.

The refinement here is the arrangement compression: for fixed `d`, it merges the exponentially many sign/minimizer branches into `H^{O(d)}` realizable faces. It does not improve the worst case when dimension is part of the input, prove FPT in `d`, or establish coNP-hardness. A loss of strict coefficient positivity invalidates the support-only argument: cancellations can remove a Newton-support source or change a denominator's leading order.

OPTIONAL UNIFORM FINITE-DEPTH CERTIFICATE AND SHALLOW WARM START
9 October 2026. Companion improvement, no edit to frozen main proof.

The safe main depth r(8/9)^m<=delta/8 is deliberately loose. This document
gives a spectrum-independent exact scalar certificate for a smaller depth.
It does NOT replace the full final channel certificate or promise shallow
success for arbitrary channels.

Let gamma=delta/8, r=2d-1, and 0<delta<=1. Put

  l=(3+gamma)/4,
  a(lambda)=2lambda^2-1,
  g(lambda)=4lambda-3-gamma.

On omitted modes lambda<=l, the desired 4lambda-3-gamma is nonpositive.
For selected modes lambda>l, the earlier full-block Schur argument gives

  Psi_m >= J diag[D_m(lambda)^(-1)] J^T,
  D_m(lambda)^(-1)=a/[1+(2lambda^2)^(-m)(ra-1)].

The denominator is strictly positive on [l,1]. Consequently the scalar
inequality D_m(lambda)^(-1)>=g(lambda) is equivalent to

  P_m(lambda)>=0, lambda in [l,1], where

  P_m(lambda)=[2(1-lambda)^2+gamma](2lambda^2)^m
              -(4lambda-3-gamma)[r(2lambda^2-1)-1].       (S4)

This is a rational polynomial of degree at most max(3,2m+2), coefficient height
O(m+ell+log r). If both endpoint values are positive and an exact Sturm
sequence counts ZERO real roots on [l,1], then P_m is strictly positive
throughout the interval by continuity. Therefore the same full Schur order
proves Psi_m>=4Phi-3I-gamma I on ALL Hermitian modes. This certificate does
not test only the actual eigenvalues of Phi: it covers the entire interval.
It uses only d and delta, with no spectral diagonalization/acquisition.

Search m=0,1,...,m_safe and accept the first such certified polynomial,
where m_safe is the frozen safe depth. This deterministic search succeeds:
for lambda<1 the frozen bound has strict positive curvature slack
2(1-lambda)^2. At lambda=1, m_safe>=1 and 2^(-m_safe)<(8/9)^m_safe, so
the loss bound is strictly less than gamma there as well. Hence P_(m_safe)
is strictly positive, has positive endpoints and has no real roots on the
interval. Fraction-free Sturm/subresultant arithmetic has polynomial bit
cost in m_safe, ell and log r; coefficient bounds can be obtained from
Sylvester minors just as in the LDL height lemma. The safe depth already
has m_safe=O(log r+log(1/delta)).

The executable replay computes the following EXACT certificates at

EXACT ANTISYMMETRIC CONTROL: LOCAL CHANNEL VS STATE EXTENSION
2026-10-09. foundational_transfer_sol. No other Cycle05 ladder read.

For every integer d>=2 let A=B=C^d, let F be swap, and put
 P_-=(I-F)/2, r_-=d(d-1)/2, rho_-=P_-/r_-=(I-F)/[d(d-1)].
Then rho_A=rho_B=I/d and
 I(A:B)_{rho_-}=ln[2d/(d-1)]<=ln4.                     (1)
The information tends to ln2 as d grows. Logs are NATS.

CLAIMS

(a) rho_- admits an exact permutation-symmetric k-extension on B for
every 1<=k<=d-1. This is not a Bose-symmetric extension.
(b) The optimal reference-preserving local EB HALF-trace reconstruction
error is EXACTLY e_EB(rho_-)=1/2.
(c) The optimal ACTUAL local two-output broadcasting HALF-trace error is
EXACTLY b_loc(rho_-)=1/4.

Consequently k-extension together with bounded mutual information DOES
NOT imply small joint trace distance to local EB reconstruction. This
is not a counterexample to the assigned actual-channel theorem: the
actual local broadcasting error never tends to zero. No novelty is
claimed for these standard antisymmetric/universal-cloning calculations.

1. ENTROPY AND EXACT EXTENSIONS

The normalized antisymmetric projector has rank r_- and constant
nonzero eigenvalues 1/r_-, so S(AB)=ln r_-. The two marginals are I/d
by U(d) invariance, giving (1). For k+1<=d take
 omega_{AB_1...B_k}=P_{wedge^(k+1)(C^d)}/binom(d,k+1).
It is a density because the antisymmetric subspace is nonzero. Its
density is invariant under permuting the B systems (antisymmetric vectors
change sign, but their projector does not). Every AB_j marginal is
U(d)-invariant, supported on the two-particle antisymmetric subspace,
and trace one; hence it is rho_-. This proves the extension claim.
The global support is antisymmetric, so it is not the fully symmetric
support required by a Bose extension theorem. No input-local channel
producing these extensions from rho_- has been supplied or inferred.

2. EXACT EB ERROR

For every normalized product vector u tensor v,
 <u tensor v,P_-(u tensor v)>=(1-|<u,v>|^2)/2<=1/2.
Convexity gives the same bound for every separable state. Every local
EB output on rho_- is separable, while Tr(P_- rho_-)=1. Since P_- is
a POVM effect, variational HALF trace distance is at least 1/2.

For the matching upper bound use the EB channel
 Psi(X)=(X+Tr(X)I)/(d+1).
It is measure-and-prepare: d integral pi Tr(pi X)dmu(pi), where pi
ranges over Haar-distributed pure projectors. The second-moment identity
 integral pi tensor pi dmu=2P_sym/[d(d+1)]
follows by unitary invariance, symmetric support, and trace one, and
gives the displayed channel. Its integral admits a finite physical EB
representation by finite-dimensional convex compactness/Caratheodory.
Writing any depolarizing map as D_lambda(X)=lambda X+(1-lambda)TrX I/d,
one has
 (id_A tensor D_lambda)rho_-=lambda rho_-+(1-lambda)I/d^2,
 T(rho_-,I/d^2)=(d+1)/(2d).                            (2)
For lambda=1/(d+1), equation (2) gives error 1/2. Thus e_EB=1/2.

3. LOWER BOUND ON AN ACTUAL LOCAL BROADCASTER

Start with ANY full-domain CPTP C:B->B_1B_2. Symmetrize outputs and
twirl by the same input/output U(d) conjugation. Because rho_- is
invariant under U tensor U and HALF trace norm is convex and unitarily
invariant, neither step increases its larger joint marginal error.
The twirled marginal is a depolarizing channel D_lambda by the identity/
traceless decomposition of conjugation-covariant linear maps.

Feed the maximally entangled pure state |Omega_d> on a NEW reference
R and input B into this actual local broadcaster. This is legal because
C is a channel on every input, not just a state extension. Each RB_j
marginal has singlet fraction
 f=lambda+(1-lambda)/d^2.
Put Q_j=P_{Omega_d,RB_j} tensor I on the other B register. Their range
isometries have overlap exactly I/d (up to the fixed B_1/B_2 basis
identification), so
 ||Q_1+Q_2||_infinity=1+1/d.
For completeness, the nonzero spectrum equals that of the range Gram
block [[I,I/d],[I/d,I]], whose eigenvalues are 1+1/d and 1-1/d.
Thus for the output density, 2f<=1+1/d, giving
 lambda<=(d+2)/[2(d+1)].                              (3)
By (2), its original rho_- joint marginal error is at least
 [1-(d+2)/(2(d+1))](d+1)/(2d)=1/4.
Since the twirling operations could only lower the original error,
EVERY actual local broadcaster has b>=1/4.

4. MATCHING ACTUAL BROADCASTER

Let P_sym=(I+F)/2 and define the actual local universal cloner
 C_clone(X)=2/(d+1) P_sym(X tensor I)P_sym.
It is CP. Since Tr[P_sym(X tensor I)]=(d+1)TrX/2 it is TP. Both
marginals are
 [(d+2)X+Tr(X)I]/[2(d+1)],
obtained by expanding the two swap factors and taking partial trace.
This is D_lambda with lambda=(d+2)/[2(d+1)], so (2) gives EXACT error
1/4. This proves b_loc=1/4. The universal cloner is standard prior art;
primary background: Werner, Optimal Cloning of Pure States,
https://arxiv.org/abs/quant-ph/9804001 . The algebra above is reproduced
directly so the interface control does not depend on a remembered bound.

WHAT THIS FALSIFIES

The tempting claim 'large k-extension plus bounded I implies small joint
local EB reconstruction' fails by (a),(b). Replacing actual broadcasting
by a state extension or an LOCC distinguishability guarantee invalidates
the main theorem's contract. Conversely this family verifies that bounded
I does not force classicality by itself: the actual b=1/4 is essential.
The full robust theorem's logarithmic bound is very loose at b=1/4 and
does not conflict with either exact optimal value. No claim about the
coordinator's separate growing-I antisymmetric ladder is made here.

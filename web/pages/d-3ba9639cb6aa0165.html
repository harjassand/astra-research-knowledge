    dim sum_i T_i U>(w-1) dim U,  1<=dim U<=B.

The folded Casoratian bound used to prove this is

    sum_(i,j) d_(i,j)<=h(M-1)+w h(h-1).

Its direct proof works over F(q), for EVERY coefficient field F, because q has infinite order and the anchors (1+q)^i have disjoint q-orbits. No derivative factorial or finite-field multiplicity assumption remains.

Composing this with the source's shrunk-subspace rank argument, a prime-to-characteristic symbol division lift, and an explicitly counted separable finite-field grid yields the following internally audited theorem candidate:

Over every extension/coefficient field F of characteristic p, EVERY family of <=B feasible affine pencils of order <=B has a common invertible hit. The generator is independent of coefficients and witnesses. All matrix entries, dense output, finite-field construction, and elimination costs are charged.

    lambda adj(U_0) U_i

## Rational formulas and exact noncommutative rank

Hrubes–Wigderson2015 Theorem2.1 and Proposition7.3 apply over arbitrary fields. A nonzero admissible formula represents a nonzero free-field element; its original inverse-node domain pencils and root augmented pencil are feasible. The released Section4 recursions use only field operations and +/-1 and preserve all inverse occurrences, including in characteristic two. For formula size s there are <=s+1 pencils of order <=2s+1. With B=2s+1 the integer list gives a DEFINED, INVERTIBLE value for the original formula over every field. No inverse-nesting or constant-height bound is needed by the generator. Evaluation over an unspecified coefficient field still requires its own exact arithmetic interface and bit charges.

The same list also computes exact noncommutative rank through an exact full matrix-output or rank-output evaluation service. If an order-r affine pencil has free-field rank t, division-ring pivot induction selects ORIGINAL rows and columns giving a t-by-t invertible affine subpencil. The list with B=r hits that subpencil, so some evaluation has rank >=t d. Cohn inner rank equals free-field rank, hence L=P Q with polynomial matrices of width t; this evaluates everywhere and proves rank <=t d at every tuple. Therefore

    nc-rank(L)=max_over_list rank(L(X))/dim(X).

The upper bound is valid over arbitrary fields and requires no acquired factorization. Primary exact source Fortin–Reutenauer Section2 pp3–4, https://www.mat.univie.ac.at/~slc/wpapers/s52reut.pdf; its later infinite-field assumptions are not used. Audit: cyclic_shift_audit/difference_kernel_attack/q_green_adversary/NC_RANK_COROLLARY_AUDIT.md. Exact rank replies allow ordinary integer processing. Full matrix replies require represented-field exact linear algebra with all bit costs charged. This does not acquire an ordinary-language oracle, unknown model weights, or a physical service.

These consequences extend the actual release116 Q-only strong rational list and its division-free positive-characteristic companion. They do not establish scalar commutative PIT, general arithmetic-circuit PIT, or first white-box noncommutative rank: NC2026 already supplies a white-box algorithm with coefficients input.

## Smaller all-characteristic nonvanishing detector

The compact cyclic q-Green transfer proof yields an integral jointly nilpotent tuple with

    N=max(1,2n(m-1)),
    E=1+binom(N,2)+n(N-1),
    d=m N E=O(n^3m^4).

The marker degree is strictly below m. For finite polynomials or acyclic ABPs the marker can be omitted, giving d=N E=O(n^3m^3); formulas give O(n^3s^3), versus release116 positive-characteristic O(n^3s^6). One integer tuple reduces correctly over EVERY field without characteristic input. Full-matrix output is essential. Infinite unmarked faithfulness is false; only the bounded-state graded guarantee survives.

This compact detector depends on the actual release116 finite-word independence lemma, whose mechanism was read and composed. Its downstream proof is independently audited, but neither the full source nor this result has external certification. ## Matrix multiplication: an exact barrier and corrected bit consequence

MM_PROFILE_BARRIER.md directly attacks stronger use of release107's profile inequalities. Define H_1=1, H_a=product_(j<a)(3j+1)/(3j), and

    P*(a,b)=H_min(a,b) [max(a,b)+(min(a,b)-1)/2].

At t=3/4 this numerical profile satisfies EVERY used Section4–5 axiom: symmetry, boundary, separate concavity, shifted tripling for every h, and rank envelope P(a,b)<=(a+b-1)^(4/3). Its diagonal growth is Theta(a^(4/3)). The proof is exact and shows that optimizing those same axioms, all shifts, or their constants cannot prove an exponent below 9/4. Larger proportional odd-sector counts also fail to exclude it. It is not an actual tensor character or a lower bound on the true matrix multiplication exponent. Additional structural identities can escape it.

The same-copy auxiliary dot-product format cannot improve sector entropy power: source and target Y-flattenings force Q<=L. A new format is needed to obtain Q=M^(1+epsilon) with L=O(M).

CONSTRUCTIVE_BIT_TRANSFER.md corrects an overly absolute reading of L03. Conditional on omega<=9/4, standard dovetailed algebraic-number rank-decomposition search gives a UNIFORM exact integer algorithm for every fixed epsilon>0:

    C_epsilon+O_epsilon(N^(9/4+epsilon)(b+log(N+2))^2)

elementary bit operations for b-bit inputs. The constant C_epsilon is uncontrolled and potentially enormous. Thus no practical/supplied decomposition is acquired, but it is false to say no uniform bit algorithm follows at all. This standard consequence receives no novelty claim, and does not acquire N-dependent selective circuits.

1. The unchanged ten-term output-support-pruning recursion needs Omega(N^2) retained syntactic products for some legal mask, even with free encoders and all fitting block/inner assignments.

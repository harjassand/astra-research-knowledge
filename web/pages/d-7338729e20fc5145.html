ROOT DERIVATION — SYMMETRY-COMPRESSED WHITE-BALL CORRECTION
2026-10-07. Internal mathematical derivation; independent audit pending.

This is a separate reduction from the fixed-variable iid-cone optimizer.
It assumes that optimizer supplies an accurate rational mixture. It does
not infer that an efficient optimizer exists merely from separability.

Fix d. Use a rational orthogonal Hermitian local basis T_0=I and:
 X_ab=E_ab+E_ba, Y_ab=i(E_ab-E_ba) for a<b;
 H_l=(E_11+...+E_ll-l E_(l+1,l+1))/l, 1<=l<d.
Every nonidentity T has trace zero, operator norm <=1, and squared HS norm
h_a in [1,2]; h_0=d. There are q=d^2 basis elements. All entries are in Q(i).

For a count vector m of length q with sum N, let S_m be the sum over
distinct tensor words with these counts. Its orbit size is
 s_m=N!/prod_a m_a!, and HS squared norm is s_m prod_a h_a^m_a.
The S_m are an orthogonal rational Hermitian basis of the permutation
commutant. There are D=binom(N+d^2-1,d^2-1) of them.

Rational change of basis from the matrix-unit orbit algebra is acquired
by the degree-N symmetric power of the fixed local basis transformation.
Expanding products of fixed-q linear polynomials needs polynomially many
degree-N monomials for fixed q; equivalently solve the D-dimensional
rational linear system after constructing its columns. Each coefficient
is a sum of at most q^N products of N fixed rational entries, hence has
O_d(N log N) bits. Rational elimination therefore has polynomial bit cost.
This is not enumeration of the d^(2N) ordered words.

Let R be a rational permutation-invariant Hermitian trace-one target and
S=sum_j p_j sigma_j^tensorN a rational iid mixture, with p_j>=0, sum p_j=1,
and every sigma_j>=zeta I for a rational 0<zeta<1/d. Set w=(d zeta)^N.
Expand E=R-S=sum_{m != (N,0,...,0)} c_m S_m. Define
 a_m=d^N c_m, A_m=s_m |a_m|, and A=sum_m A_m.
All coefficients, signs, multiplicities and A are exactly rational,
with polynomial bit length if the input representation has polynomial bits.

For each nonidentity ordered tensor word v, let P_v be its tensor product.
The state (I+sign(c_m)P_v)/d^N is fully separable: on each active site
use (I+s_i T_(v_i))/d, with uniform signs conditioned on their product
being sign(c_m); inactive sites use I/d. This is exact even for one active
site. Averaging v uniformly within its count orbit gives a separable state
Omega_m = I/d^N + sign(c_m) S_m/(s_m d^N).

If A<=w, the following identity is an explicit positive decomposition:
 R = [S-w I/d^N] + (w-A) I/d^N + sum_m A_m Omega_m.
All terms have nonnegative weights, their traces sum to one, and their
sum is exactly R. No assertion of identical factors follows.

For completeness, coefficient Cauchy-Schwarz gives
 sum_v |c_v| <= ||E||_2 [sum_v prod_i h_(v_i)^(-1)]^(1/2)
             <= ||E||_1 d^N,
because sum_a h_a^-1 <= d^2. Thus A<=d^(2N)||E||_1, so
 ||E||_1 <= (zeta/d)^N suffices, with the same deliberately loose ball.
Testing actual A rather than this sufficient norm bound can only help.

SAMPLING WITHOUT EXPONENTIALLY MANY LISTED PRODUCT STATES
The top-level choices have weights 1-w, w-A, and A_m (at most D+1).
For the first branch choose j with probability p_j. Write
 sigma_j = p I/d + (1-p) tau_j, p=d zeta,
 tau_j=(sigma_j-zeta I)/(1-p), an exactly rational positive state.
Generate N independent white/nonwhite choices with white probability p,
conditioned not all white. Their conditioning probability 1-p^N is known;
sequential conditional probabilities use powers p^r and require polynomial
bits and O(N) arithmetic. Return the corresponding I/d or tau_j factors.
This samples (S-w I/d^N)/(1-w) exactly as an abstract rational law.

For branch m, sample a uniform random permutation of its multiset of local
labels (sequential remaining-count probabilities), then independent signs
on all but the last active site and set the last sign to enforce parity.
Return the N rational one-site states. A branch with no active sites was
excluded by Tr E=0. This uses O(N) discrete choices and O(N) output length.

Exact rational sampling need not have bounded fair-bit length. For a
bounded finite-bit compiler, round every top-level and sequential rational
transition to dyadic probabilities with total TV budget epsilon; there
are polynomially many top-level categories and O(N) adaptive transitions.
Standard coupling bounds the full output-law TV by the sum of conditional
rounding errors. O(log(DN/epsilon)) bits per transition suffice. All local
density matrices are already rational PSD. Physical implementation requires
N one-qudit state preparations with total trace-error budget separately
charged; this is not a hardware execution.

APPLICATION TO THE ALL-N STOPPED-DIFFUSION THEOREM
The exact source is c04_s01/revisions/EXACT_FULL_SEPARABILITY.txt, not the
earlier weaker e^(-2N) summary. It supplies a mixture with local floor eta
and UNHALVED trace error <=(eta/d)^N e^(-2N). Choose a certified rational

strict fraction of the parity-ball radius for target approximation and
optimization. Acquiring R and S at additional error c*(zeta/d)^N costs
O(N log(d/zeta)+log(1/c)) accuracy bits, not exponentially many bits.

If c01_s01's fixed-variable optimizer is proved with polynomial dependence

fixed tiny-radius constants may be impractical; they must not be omitted.

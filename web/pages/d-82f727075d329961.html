# Uniform continuum secant certificate from reference flux and sensitivities

This is an independently reconstructed conditional theorem for the SAME square, coefficient partition, theta box[-.05,.05]^2, frozen raw dyadic boundary P1 currents/tests and their exact L2 normalizations used by rank_pde/cycle2. Parameter metric Euclidean; output stack has four scalar readings. No H2 regularity or continuum computation is assumed. Actual equilibrated flux residuals must be acquired before any numerical continuum claim.

## Hilbert-space contract

Work H=H1(square)/constants with a0(u,z)=integral grad u dot grad z and norm ||u||0. Zero-mean boundary L2 traces define continuous loads. Let a_theta=a0+sum theta_i b_i, b_i(u,z)=integral_region_i grad u dot grad z. Regions disjoint: their positive forms sum<=a0; hence ||H_theta||<=rho=.05, ||C_v||<=||v||2, and a_theta coercivity a=1-rho=.95. The conforming frozen P1 space is Vh and its reference orthogonal projection P. The physical trace load is exactly the same in continuum and Galerkin weak formulations. Grounding a finite node is only a finite gauge implementation; continuum proof uses the quotient and does not require point evaluation of H1 functions.

For every normalized load z (each current g_j or detector q_jl), let u_z be the continuum reference solution and u_h,z its Galerkin solution, e_z=u_z-u_h,z. An equilibrated H(div) flux p_z with div p_z=0 and boundary normal z gives

||e_z||0 <= eta_z = ||p_z-grad u_h,z||L2.

This follows by integrating p_z against grad w to recover the boundary load, subtracting the finite state, and applying Cauchy-Schwarz to w=e_z. No H2 estimate is involved. The flux is actual weakly equilibrated, not merely nodally divergence-free. Boundary P1 trace must match its normal trace exactly. Approximate equilibrations need extra certified dual-residual terms.

## Quadratic reference derivative transfer

For each region i and frozen state u_h,z define the true auxiliary sensitivity w_z,i by a0(w_z,i,t)=b_i(u_h,z,t), and its Galerkin approximation w_h,z,i. A flux p_z,i with div p_z,i=0 and zero boundary normal, approximating grad w_h,z,i-1_region_i grad u_h,z, certifies

||w_z,i-w_h,z,i||0 <= xi_z,i = ||p_z,i-grad w_h,z,i+1_region_i grad u_h,z||L2.

Galekin orthogonality a0(e_z,vh)=0 is decisive. For one current/test row,

D_i y(0)-D_i y_h(0) = -b_i(e_g,u_h,q)-b_i(u_h,g,e_q)-b_i(e_g,e_q).

The first term equals -a0(e_g,w_q,i-w_h,q,i), and the second similarly. Consequently its absolute value is <=d_row,i=eta_g xi_q,i+eta_q xi_g,i+eta_g eta_q. Assemble

D0 = [sum_(rows,i) d_row,i²]^(1/2).

The matrix operator error ||J0_cont-J0_h||<=D0, so sigma_min(J0_cont)>=alpha_h-D0. Counting all entries in Frobenius norm is conservative but valid. Correlated flux-error Gram certificates can tighten this; unverified correlation cancellation cannot.

## Uniform theta without a theta net

Pythagoras gives ||u_g||0²=||u_h,g||0²+||e_g||0²<=U_j²+eta_g². For the block detector-state map Q0:c->sum_l c_l u_q,l, its finite and error images are orthogonal. Therefore ||Q0||²<=V_j²+d_j² with d_j²<=sum_l eta_q,jl² (or a certified joint operator error Gram upper bound). U_j² and V_j² are the exact finite energy constants already certified in cycle2.

The resolvent R_theta=(I+H_theta)^-1 satisfies ||R_theta C_v R_theta-C_v||<=f(rho)||v||2, f(rho)=rho(2-rho)/(1-rho)². Hence the CONTINUUM derivative differs from its OWN reference derivative by at most

beta_cont = f(rho) [sum_j (U_j²+eta_g,j²)(V_j²+d_j²)]^(1/2).

Combining and integrating over the straight parameter segment yields, for all theta,eta in the box,

||y_cont(theta)-y_cont(eta)||2 >= kappa_cont ||theta-eta||2,
kappa_cont=alpha_h-D0-beta_cont.

A positive kappa is an effective uniform continuum certificate. A nonpositive bound is UNKNOWN, not failed identifiability. This reference-anchor route requires no perturbed continuum states, no theta cover, no H2, and no continuum derivative agreement inferred from coarse forward agreement. It also does not by itself transfer the strict ordering of two designs' TRUE global minima; the single-design secant upper witness needs its own continuum error certificate if that ordering is claimed.

## Charged thresholds for the frozen designs

work/a_quant/cycle3/threshold.py reads the actual frozen currents, exact finite reference inverse and exact finite output norm uppers. It acquires no new continuum data. If ALL relevant normalized state errors eta and auxiliary errors xi are <=t, each d_row,i<=3t², giving D0<=3sqrt(8)t². Single has one detector block of size4; multi has two blocks of size2. Thus beta_cont uses (U²+t²)(V²+4t²) in single and sum_j(U_j²+t²)(V_j²+2t²) in multi.

The common-t positive thresholds are approximately .130530(single) and .152337(multi). These decimal roots are diagnostics. Rational checks using 8.486>3sqrt8, exact finite constants and squared remainder inequalities confirm positive conditional margins at t=.1 for both, and at t=.15 for multi only. See results/a_quant/cycle3/reference_thresholds.json. Conditional thresholds can beat the .148/.202 finite margins if actual flux residuals fall below them; they do NOT say the actual frozen mesh residuals do. The actual errors/flux residual upper bounds must determine the outcome.

Without sensitivity flux, linear state/full-energy transfer is valid but more conservative. Without ANY certified state residual, same-trace cross-mesh agreement cannot resolve this obligation: an unchecked fine mesh is another finite surrogate.

## Optional uniform perturbed derivative net

If a reference anchor is too coarse, certify actual state and auxiliary residuals at a theta net. Use baseline energy norm to keep coefficients explicit. The state-error map e_z(theta)=u_z(theta)-u_h,z(theta) obeys

||e_z(theta)-e_z(eta)||0 <= L_e,z ||theta-eta||2,
L_e,z=[sqrt(U_h,z²+eta_z(0)²)+U_h,z]/a².

This follows by differentiating each full/finite resolvent and bounding C_v by||v||. Define auxiliary w_z,i(theta) with a_theta(w,t)=b_i(u_h,z(theta),t), FE w_h analog, and zeta=w-w_h. Each auxiliary derivative has baseline norm<=2 U_h,z/a³; their difference therefore has Lipschitz constant L_zeta<=4 U_h,z/a³. No H2 is used. Certified a_theta-energy residual bounds at a center convert to baseline bounds by division bysqrt(a). At covering radius hnet, add L_e hnet and L_zeta hnet respectively. The same Galerkin orthogonality derivation then bounds each perturbed derivative error using baseline products eta_g xi_q+eta_q xi_g+eta_g eta_q. Integrating a verified uniform derivative difference against the known finite global secant bound supplies a continuum lower certificate.

A square grid with m intervals per coordinate has (m+1)² centers and radius .1 sqrt2/(2m). Upper cost ignoring duplicate traces: single has5 normalized loads, multi6; per center one shared FE factorization with5/6 state RHS and10/12 sensitivity RHS, plus15/18 corresponding equilibrated-flux reconstruction RHS. Flux matrices/factorizations and exact quadrature/interval verification costs are separate. This net rapidly becomes expensive as hnet shrinks and its universal Lipschitz bound can be too coarse. It is optional, not silently free.

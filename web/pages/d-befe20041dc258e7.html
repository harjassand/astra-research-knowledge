## I1. Input and resulting interface

one logical qubit, code distance d, and

    H0=sum_a e_a(I-C_a)/2, e_a>0,

The physical beta multiplies this displayed Hamiltonian. Decoder-dressed

Pauli. The inherited primary input is

    p1=Tr[(I-P1)rho0]<=C_base exp(-b Q),
    rho0=exp(-beta H0)/Z0.                             (I1)

For the actual admitted BDL2605.10943v1 family, b=log2, Q=2^(k-1), and
the cycle14 finite-lookup/witness repair, exceptional-level charge and

is explicitly inherited primary prior. One safe actual calibration has
Q>=c N^(1/436), independently of its stronger distance bound. The support
condition below must be checked separately from decoder/energy conditions.

Let X be a supplied set of s<d qubits. V is ANY Hermitian operator on X;
it may fail to commute with the checks and its terms may fail to commute
with one another. H=H0+V and rho=exp(-beta H)/Z. Physical implementations
can declare V=sum_j V_j, each support contained in X, bounded range/body,
and intensity J=max_i sum_{j:i in supp V_j}||V_j||. Then ||V||<=s J, but
the main equilibrium/lifetime bound below does not need this amplitude bound.

Original Hermitian bath couplings A_alpha, their actual frequency components

Let the supplied physical density bound give at most G_b qubits in each

N balls; this contains all Paulis and prefixes on each actual Y_alpha.
The number of distinct admitted E's is at most

    M_b=1+N sum_{j=1}^{q_b}3^j binom(G_b,j)

For single-site Pauli baths one may instead use M_b=1+3N. Duplicate tiny

## I2. Saturate the disturbed subsystem and clean the bare logical pair

Let F range over all4^s Pauli strings on X, phases ignored. Define

    R=intersection_F F*P1F,
    P=intersection_{F,E} (E F)*P1(E F).                 (I3)

All projectors in these intersections are syndrome-diagonal and commute.
Pauli conjugation on X permutes the intersection factors, so R and P
commute with the FULL matrix algebra on X. Thus R=I_X tensor R_out and
P=I_X tensor P_out; both commute with V and every original check. P<=R.
For every admitted bath Pauli E, E ran(P) subset ran(R): for every F,
F E agrees with E F up to phase and F E ran(P) subset ran(P1).

All pre-factor prefixes of a Pauli F_X or a Pauli E_Y lie in the admitted
family. Telescoping the single-site commutator proves

    [F_X,Q_j]R=0,    [E_Y,Q_j]P=0.                    (I4)

There is no Pauli coefficient l1 loss in linear extensions of exact zeros.

Choose bare logical Paulis L_X,L_Z in the same logical classes as the
decoder pair and clean both off X. A constructive symplectic proof is as
follows. If the restriction of a logical label l to X did not lie in the
restriction of S, a linear functional separating it from that subspace is
represented by a Pauli u on X with symplectic pairing <u,S>=0 and <u,l>=1.
Since s<d, this centralizer u is a stabilizer, contradicting <u,l>=1.
Therefore a binary stabilizer combination cancels the restriction of each
logical. Solve the two GF(2) systems; the cleaned labels L_j^c are outside
X. Stabilizer multiplication preserves the logical anticommutation. Cleaned
Paulis commute with H0, V and every syndrome-diagonal projector. Cleaning
requires s<d, not a source-decoder low-error threshold.

## I3. Patch the full logical algebra, eliminating a square-root-tail loss

Define on the entire Hilbert space

    O_j=R Q_j+(I-R)L_j^c, j=X,Z.                      (I5)

R commutes with both pairs. Orthogonal blocks give O_j*=O_j, O_j^2=I
and O_X O_Z=-O_Z O_X. Both O_j commute with every original check. On R,
I4 makes Q_j commute with every Pauli on X; on I-R the cleaned logical
has disjoint support. Since R itself is X-invariant, O_j commute with the
FULL matrix algebra on X globally. In particular

    [H,O_j]=0, [H,P]=0, [P,O_j]=0.                    (I6)

For a bare bath Pauli E, both input P and output E P lie in R. Hence
[O_j,E]P=[Q_j,E]P=0. Arbitrary non-Pauli A_alpha is covered by exact
Pauli linearity. Unlike an approximate-conservation argument, (I6) supplies
the global Chesi algebra and the exact p_bad rather than sqrt(p_bad) bound.

The ordinary decoder choices are zero on zero input and f2(0)=0. Thus
Q_j equal the original bare logical on the original code projector P_code.
Stabilizer cleaning preserves that action. Whether R contains the code
or not, (I5) therefore agrees with the original logical pair on P_code.
This is logical-label compatibility, not a theorem that ground-state
initialization has the thermal-encoder lifetime.

## I4. Full-frequency protection for the ACTUAL Hamiltonian

    [A_alpha(t),O_j]P=exp(iHt)[A_alpha,O_j]P exp(-iHt)=0,

Frequencies are those of H0+V. No spacing bound, infinite-time generator

For later Lamb-shift products an exact algebra description is useful.
Let D(C) mean any function of the commuting original checks. The linear
span A_X={sum_F F_X D_F(C)} is a finite-dimensional star algebra: moving a

If A_alpha is on Y_alpha, then

    A_alpha,omega lies in span{F_X E_Y D(C)},
    A_alpha,omega* A_alpha,omega lies in SAME span.    (I8)

## I5. Gibbs comparison using reducing blocks, not exponential operator order

For any syndrome-diagonal projector T reducing H0 and V, eigenvalue minmax
inside its invariant block gives

    Tr T exp[-beta(H0+V)]<=exp(beta||V||) Tr T exp(-beta H0),
    Z>=exp(-beta||V||)Z0.

Consequently p_T(H)<=exp(2beta||V||)p_T(H0). No false operator inequality
between noncommuting exponentials is asserted. The actual P reduces both.

There is a stronger amplitude-independent bound. Split

    H0=H_out+H_touch,
    H_touch=sum_{a:supp C_a meets X} e_a(I-C_a)/2,
    0<=H_touch<=M I, M=sum_touch e_a<=g0 s.             (I9)

H_out acts entirely outside X. In rho_out=exp(-beta H_out)/Z_out every
F_X translation costs ZERO. An E of weight<=q_b changes H_out energy
by at most g0 q_b, giving the union bound

    p_P(H_out)<=4^s M_b exp(beta g0 q_b) p1(H_out).

Positive common-block minmax gives p1(H_out)<=exp(beta M)p1(H0).
For K=H_out+V the Gibbs state factorizes on X/X^c, and P=I_X tensor P_out,
so p_P(K)=p_P(H_out) independently of amplitude or noncommutativity of V.
Adding 0<=H_touch<=M gives p_P(H)<=exp(beta M)p_P(K). Combining,

    p_P(H)<=4^s M_b exp[beta(2M+g0 q_b)] p1(H0).        (I10)

This sharper ordering avoids an extra beta g0 s translation charge. Both
trace comparisons use invariant blocks. Arbitrary amplitude can still
increase the bath frequency/rate envelope, which is retained below.

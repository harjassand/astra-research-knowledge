EXACT QUANTIFIERS
Fix a bistochastic CPTP T_B and an actual CPTP joint broadcaster for it.
Set S_B=T_B* T_B. Choose ONE canonical pure EB Psi_B from supplied C4
for S_B and fix it ONCE. Then for EVERY finite reference dimension d_A
and EVERY state rho_AB, with tau_B=I_B/d_B,

  F = D(rho_AB||rho_A tensor tau_B)
    = I(A:B)_rho + D(rho_B||tau_B),
  b = (1/2)||rho_AB-(id_A tensor T_B)(rho_AB)||_1,
  e = (1/2)||rho_AB-(id_A tensor Psi_B)(rho_AB)||_1,

the SAME local Psi_B obeys

  e^3<=54 F b,
  e<=min{1,(54 F b)^(1/3)},
  e^2<=3*2^(4/3)(F+1)b^(2/3)<=8(F+1)b^(2/3).             (L1)

If rho_B=tau_B, the budget is EXACTLY F=I(A:B)_rho. Without that marginal
condition, the additional divergence D(rho_B||tau_B) must be retained.
No assumption of classicality of A, a cq state, or an independently
broadcastable reference is made. The map id_A tensor Psi_B is LOCAL EB
on B; it is not claimed to be an EB channel on the whole input AB.
It outputs a separable state across A:B, as follows from Psi_B being EB.

1. GLOBAL FORM ORDER AMPLIFIES WITHOUT GLOBAL BROADCASTING

Write ordinary-trace local form order as
  Tr_B[H_B(H_B-Psi_B(H_B))]
   <=4 Tr_B[H_B(H_B-S_B(H_B))]
for every Hermitian H_B. Choose any ordinary-HS orthonormal real
Hermitian basis {F_alpha} of M_A. Every Hermitian H_AB has an expansion
  H_AB=sum_alpha F_alpha tensor H_alpha,
with Hermitian coefficient matrices H_alpha on B. Expand the full
quadratic form and use Tr_A F_alpha F_beta=delta_alpha,beta to get

  E_(id_A tensor Psi_B)(H_AB)
     =sum_alpha E_Psi_B(H_alpha)
     <=4 sum_alpha E_S_B(H_alpha)
     =4 E_(id_A tensor S_B)(H_AB).                         (L2)

Let Tbar=id_A tensor T_B, Sbar=id_A tensor S_B=Tbar* Tbar, and
Psibar=id_A tensor Psi_B. They are actual bistochastic CP maps. The
analytic transfer and discrete entropy lemma thus apply to Tbar, Sbar
and Psibar. We do NOT invoke C4 on the full reference channel Tbar:
the identity channel on A need not be self-compatible. C4 was invoked
only on B, and (L2) is the complete algebraic amplification step.

2. SUPPORT AND FAITHFUL REGULARIZATION

Every rho_AB is supported in supp(rho_A) tensor H_B. To see this, if
R is the kernel projector of rho_A, then
  Tr[(R tensor I)rho_AB]=Tr[R rho_A]=0;
positivity implies both diagonal and cross blocks on that subspace vanish.
Restrict A to supp(rho_A), where rho_A is faithful. All the local maps
above preserve this restriction and still have the same B factors.

Set sigma=rho_A tensor tau_B and
  rho_delta=(1-delta)rho_AB+delta sigma, 0<delta<1.
On the restricted space, rho_delta is faithful. Its A marginal remains
EXACTLY rho_A. Since Tbar and Psibar fix sigma, the residuals scale
  b_delta=(1-delta)b, e_delta=(1-delta)e.
Its F_delta tends to F: Tr rho_delta log rho_delta is continuous, and
log sigma is bounded on the restricted support. If rho_B=tau_B, this
regularization also preserves that exact B marginal.

3. THE CONSERVED REFERENCE TERM REMOVES THE REFERENCE ENTROPY PENALTY

For faithful rho_AB on the restricted space, use the raw local Poisson
flow Qbar_t=id_A tensor exp[t(T_B-I)] and write rho_t=Qbar_t rho_AB.
Trace preservation on B keeps its A marginal equal to rho_A. Therefore

  F_t=D(rho_t||sigma)
     =Tr[rho_t log rho_t]-Tr[rho_A log rho_A]+log d_B.

The expectation of log sigma is constant along this flow. Thus

  -F'_t
    =Delta_Tbar(rho_t)+D(Tbar rho_t||rho_t)
    >=Delta_Tbar(rho_t).                                 (L3)

This is the same exact identity as in the raw tracial proof; the
nontracial A term disappears because it is conserved. F_t>=0 by
nonnegativity of relative entropy, whose separate-eigenbasis classical

  integral_0^H Delta_Tbar(rho_t) dt<=F_0=F.                (L4)

The complete form comparison (L2) and CP-Schwarz/purification give
e(rho_t)^2<=8 Delta_Tbar(rho_t). The raw local flow stays within distance

The choice H=(2F/b^2)^(1/3) for F,b>0 gives e^3<=54Fb. The squared
coefficient and cap follow exactly as in the main proof.

4. ENDPOINTS AND SAME LOCAL COMPARATOR

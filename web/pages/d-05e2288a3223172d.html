CLAIM AND STATUS
I give an exact phase-retaining transfer representation and sampler for determinant-weighted linear-matroid parity when F is block diagonal with blocks of size at most b. Its coefficient-extraction tensor has bond dimension at most k+1 for the k-pair coefficient, and local phase-aware preprocessing costs O(m 3^b poly(b,L)) rational bit operations for m blocks and input bit length L (with explicit polynomial bit growth). Thus b=O(log n) is an admitted polynomial-time subclass strictly broader than monomial blocks. This does not handle arbitrary dense F.

For the unrestricted interface, I prove a separate tensor-width obstruction: on q independent two-site swap blocks, the exact two-replica orientation tensor has Schmidt rank 4^q across the cut separating the first and second sites of every block. A common-orientation seam keeps squared norm only 2^-q of the independent tensor. This exactly quantifies the cost of the common-cut sewing shortcut and shows why a generic global MPS truncation of this phase-retaining object is not polynomial-size. It does not rule out a block-aware tensor network, local transition flow, or a different auxiliary representation.

CONSTRUCTION: BLOCK-LOCAL PHASE TENSOR
Use c_k(F)=sum_{I,J disjoint, |I|=|J|=k}|det F[I,J]|^2. Suppose F=diag(F_1,...,F_m), with coordinate blocks B_t and sizes b_t<=b. Define
  a_{t,l}=sum_{I,J subset B_t, I intersect J=empty, |I|=|J|=l} |det F_t[I,J]|^2,
  p_t(z)=sum_l a_{t,l} z^l.
The determinant inside each local factor is evaluated with its actual complex phases; only after the determinant is formed is its modulus squared taken. This is an auxiliary positive tensor for a block, not entrywise replacement of F by |F|.

For any global I,J, write I_t=I intersect B_t and J_t=J intersect B_t. The selected matrix F[I,J] has nonzero entries only between row and column indices in the same block. Its rank is at most sum_t min(|I_t|,|J_t|). If some |I_t| differs from |J_t|, this is strictly below k, so its determinant is zero. If all block counts agree, row/column permutations make F[I,J] block diagonal and its determinant is, up to a sign, product_t det F_t[I_t,J_t]. Hence
  sum_k c_k(F) z^k = product_t p_t(z).
The k coefficient is computed by the charge-transfer recurrence
  D_0(0)=1; D_t(s)=sum_l D_(t-1)(s-l) a_(t,l),
with s=0,...,k. The chain tensor has bond/charge index s in {0,...,k}, so bond dimension k+1. Local enumeration has at most 3^(b_t) disjoint row/column assignments. Computing each determinant directly costs poly(b_t,L); the total local cost is O(m 3^b poly(b,L)), and charge convolution is O(m k b). For b=O(log n), both are polynomial in n and the rational input length; determinant, modulus-square, sum, and product bit lengths remain polynomial. This yields exact coefficients. If c_k>0, suffix versions of D sample block charges with probabilities proportional to a_(t,l)D_(t-1)(remaining-l), then sample each local disjoint (I_t,J_t) proportionally to |det F_t[I_t,J_t]|^2. Clearing rational denominators and rejection from a power-of-two range gives an exact sampler with expected polynomial random-bit cost. If c_k=0 the sector is empty and the DP certifies it.

This is the tractable auxiliary graph/tensor result: phase interference is resolved inside each small determinant; the remaining network is a one-dimensional nonnegative coefficient convolution. It is not an extension of the product identity to matrices with interblock entries. For larger blocks, the 3^b local table can itself be exponential.

UNRESTRICTED BOND-DIMENSION / SEWING OBSTRUCTION
Let F_q be block diagonal with q blocks [[0,1],[1,0]], and retain all 2q sites. For one orientation register define
  v_q = sum_(x in {0,1}^q) |x>_L |1-x>_R,
where L contains the first coordinate of each block and R the second. Each nonzero complementary minor is 1, so this is exactly the orientation vector. Its coefficient matrix is a 2^q by 2^q permutation matrix and has Schmidt rank 2^q, with all singular values 1.

Two independent replica registers give Gamma_q=v_q tensor v_q. Group both replicas' L registers on the left and both R registers on the right. The coefficient matrix is again a permutation matrix, now of order 4^q; its exact Schmidt rank is 4^q and all singular values are 1. Therefore every exact MPS across this cut needs bond dimension at least 4^q. By Eckart–Young, a rank-D truncation retains at most D/4^q of squared norm; relative squared error is at least 1-D/4^q.

The common-orientation sewing projector keeps only equal labels x=y between the replicas. It leaves 2^q terms of unit amplitude, so its squared norm is 2^q, while ||Gamma_q||^2=4^q. Its retained fraction is exactly 2^-q. Thus the tensor dimension needed to retain independent orientations and the positivity/norm loss caused by identifying them are exponential in q on this family. An ordering that keeps each two-site block together still has a small bond dimension; the lower bound applies to the specified global seam, not every graph decomposition.

PHASE AND POSITIVITY BOUNDARIES
Taking absolute values of matrix entries before determinant evaluation cannot be the general local tensor. Put either A=[[1,1],[1,1]] or A'=[[1,1],[1,-1]] in the upper-right 2x2 block of a 4x4 matrix and set all other entries to zero. The two 4x4 matrices have identical entrywise magnitudes, but their only possible nonzero legal disjoint k=2 minor, on rows {1,2} and columns {3,4}, is respectively 0 and -2. Thus c_2 is respectively 0 and 4. The phase must remain until after the determinant is formed.

The prior F4 obstruction from the baseline is sharper against a positive matching-circuit lift of the full hole signature. Its nonzero values are f(empty)=4, f(all)=1, and f(13)=f(14)=f(23)=f(24)=1, while f(12)=f(34)=0. The 12|34 pairing orbit has zero capacity; each other pairing orbit has capacity at most 1, but the endpoint product is 4. For q direct-sum copies, any single global positive pairing-orbit comparison needs factor at least 2^q; coefficientwise K-approximation by such an even-windable signature needs K>=2^(q/4). This follows from McQuillan's nonnegative decomposition definition and the exact signature calculation already in the supplied cycle-5 checkpoint. It blocks that positive representation class, not all nonnegative algorithms or local flows.

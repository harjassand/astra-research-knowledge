## 1. A sufficient exact segment certificate

Hold a cleaned state's retained coefficients and scales fixed during a legal
cube segment `x+t h`, `0<=t<=s`. The rational direction is nonzero, lies in
the current original-face tangent and exact cost kernel, annihilates every
large row and every protected medium-barrier gradient, and is normalized
to `1/2<=||h||<=1`. For this acceleration require `x.h=0` exactly.

For each medium row/sign, compute entirely in rational arithmetic

```
u_sigma(t) = u_sigma(0) + a_sigma t - b t^2,
a_sigma   = sigma (b_row.h)/r - (R/r^2) sum p_j x_j h_j,
b         = (R/(2r^2)) sum p_j h_j^2 >= 0.
```

The maximum `U_sigma` is the largest value at `0`, `s`, and the stationary
point `a_sigma/(2b)` if the latter lies inside the interval. Require
`U_sigma<=0`. With `beta=1/(2R)`, let

```
J_sigma=floor(-beta U_sigma),
E_sigma=2^(-min(J_sigma,J_cap)),
```

where `J_cap` is preselected, nonnegative, and polynomially bounded in the
original input length.
Since Euler's number exceeds two, `exp(beta u_sigma(t))<=E_sigma` for the
entire segment. The exponent cap only loosens the upper bound; computing
`2^(-J_sigma)` without this cap is unnecessary and can generate a huge
denominator when a numerical row scale is tiny.

Weighted Cauchy--Schwarz gives the genuine PSD inequality

`p p^T <= q diag(p)`, with `q=sum p_j`.

Consequently, writing the large-row background separately,

```
C_j = sum_medium,sigma (32K q/r^4) E_sigma p_j
      + sum_large p_j,
L(t) <= max_j C_j + eta N.
```

Require the last rational upper bound to be at most eight. Then the cubic
term in `Phi` vanishes throughout the whole segment, and

`Phi(x+s h)-Phi(x)=-eta s^2||h||^2 <= 0`.

No source restriction `s<=tau` or inverse-polynomial facet width is used.
This certificate can be conservative; rejection says nothing about whether
the actual top eigenvalue stays below eight. The large-row equation keeps
its stored displacement zero. The explicit maxima certify medium barriers
even for long segments, for which the source's quarter-length argument
alone would not suffice.

Choose `s` to be an **exact original-face endpoint**. Its minimal original
face is a proper subface, so face nesting charges the step to one of at
most `n` face drops. The reset must use that NEW minimal original face.
Keeping only the same face dimension or the old anchor is insufficient.

A universal hybrid can try this certificate and otherwise regenerate the
original spectral direction and take the original step. In the low-potential
branch an exact `x.h=0` equation replaces its approximate-gradient equation;
the source reserve already charges one such equation. Nothing here asserts
that the attempted certificate succeeds on every input. In particular, a
high-potential fallback can still inherit the original poor constants.

## 2. Two fixed reset grids preserve the global proof

Keep the source parameters

```
tau = min(1/4, eta/(8B3)),
D   = eta tau^2/64,
S   = ceil(2eta n/D)+2n+4,
delta_o = min(D/(2^12 eta n^2), 1/[2^12 S(n+R+1)]).
```

Use the following fixed choices, selected before the trajectory:

```
delta_full = delta_o/2,
0 < delta_event <= 1/[2^14 n(n+R+1)].
```

A reset after any actual proper original-face drop uses `delta_event`.
Every other step is an original full step and uses `delta_full`.
Both resets use the already proved normalized-basis construction in the
current new face/cost slice, grid medium `d` at `r delta`, set large `d=0`,
and increase `e` by `4delta`. They have displacement `<delta`, preserve
the exact new original face and cost, decrease medium barriers by at least
`delta`, and increase potential by at most `3eta sqrt(n)delta`.
For a wholly rational bound we use the weaker `3eta n delta` below.

Let `f` count steps without a face drop. Let `a<=n` count all face drops,
including original short endpoint steps and certified long events.

* An original full motion decreases potential by at least `25D/6`.
  Its full-grid reset loss is at most `3D/(2^13 n)`, so its net decrease
  is greater than `D`.
* A source short endpoint motion increases potential by at most `D/(2n)`;
  their total motion increase is at most `D/2`.
* A certified event motion is nonincreasing by section 1. An original full
  motion that happens to reach a face endpoint is also nonincreasing.
* All event-grid reset losses sum to at most
  `3eta n^2 delta_event <= 3eta n/[2^14(n+R+1)] < eta n/4096`.
* Cleanup never increases the top eigenvalue, hence never increases
  potential at fixed ambient `x`. Coordinate deletion uses entrywise
  Perron monotonicity; its justification does not require a false general
  Loewner deletion claim.

Initially `Phi<=0`. For every reached clean state, therefore,

`Phi <= -fD + D/2 + eta n/4096`.

The universal lower bound `Phi>=-eta n` implies

`f <= (1+1/4096)eta n/D + 1/2`.

Thus `f+a<S`; the original enlarged hard cap remains sufficient. This is
a bootstrap: impose the cap provisionally, prove the invariants for every
prefix up to the cap, and use the strict count bound to show the cap cannot
be exhausted. It does not assume termination in order to bound reset loss.

Before the provisional cap, cumulative row-tracking error is bounded by

```
(n+R+1)(S delta_full+n delta_event)
 <= 1/8192+1/16384 = 3/16384 < 1/4096.
```

Similarly,

`e <= 4(S delta_full+n delta_event) <= 3/[4096(n+R+1)] < 1/1024`.

The source cleaned-state bootstrap still closes:

```
(L-8)_+^3 = Phi+eta||x||^2
 <= eta n(1+1/4096)+D/2 < 1,
```

since `eta n=1/K<=1/64` and `tau<=1/4`. Hence `L<9`. Original fallback
steps retain their local Taylor assumptions. Certified segments have the
stronger bound `L<=8` directly. The unchanged tracking and barrier ceilings
give the **same original** discrepancy bound

`B(k)=16R^2+2K+8k+1`.

This proves an algorithmic variant, not a retroactive claim that the source
used the larger grid. It also does not change the strong oracle interface.

have polynomial encoding in the original call parameters. The reset anchor

original-input denominator bound; its normalized basis has original-input

minor of this basis, independently of old coefficient denominators.

delta. Thus each reset regenerates the state from polynomial encodings.

Medium `d` has `|d|<H` and lies on one of the fixed rational grids `r delta`;

## 4. Adversarial boundary and next decisive observation

The most consequential surviving operational gap is executable high-`L`
direction/precision/oracle composition on an instance where the Gram
potential actually activates. Neither this trace nor the two-atom runtime
obstruction demonstrates that branch. A guard failure must fall back to
the already proved source routine; it cannot be called evidence that a
larger step is safe or that the implementation is practical.

The next falsifiable gate is an independently checked trace with `L>8`,
nonvacuous discrepancy target, exact new-face resets, and a competent
same-information comparator. Arbitrary strong-oracle implementations must
also charge every GLS reduction, exact face reconstruction, and numerical
spectral query; a product fixture is not a substitute for that interface.
Mathematically, no new universal counterexample was found in dimensions,
exact cost slices, original-input reset bits, or arbitrary optimizing-vertex
tie choices: spanning LPs force a point outside the acquired span when one
exists, and normalized resets preserve the current original face. That is
the scope of this adversarial audit, not external validation.

Concrete downstream use remains quota/matroid design with arbitrary signed
Euclidean-normalized feature columns: the same oracle, exact cost control,
and exact-mean extractor can support randomized panels with hard feature
deviation. A practical implementation must justify acquisition/runtime,
and should use the simple product/DP comparator whenever that structure is
available.

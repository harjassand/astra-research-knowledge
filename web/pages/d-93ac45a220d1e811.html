# Global posterior axis certificates from an acquired candidate

**Worker/date:** metric_use10, cycle12, 7 October 2026; verified GPT-6.1 Sol/max; no nested workers. **Status: internally proved and independently root-gated PASS**, [root reconstruction](../../root_cycle12/GLOBAL_AXIS_CERTIFICATE_GATE.md). Historical priority is unassessed. This changes the cycle11 branch interface only when an aligned metric, or a certified uncertainty set for it, is available. It does not acquire a metric from noisy quartic coefficients alone.

## Input and output

For n>=2, given expanded observed real/rational homogeneous quartic coefficients \(\widehat f\), a supplied SPD metric G, and a certified error \(\delta\), promise that a true quartic is

\[
 f_t(x)=h_{Q_t}(L_tx),\qquad h_Q(z)=(z^2)^TQ(z^2),\qquad L_t^TL_t=G.
\]

The original QPD promise \(Q_t\succ0\) suffices. The broader theorem only needs the **pair gaps**

\[
 q_{t,kk}+q_{t,ll}-2q_{t,kl}\ge0\quad(k<l).
\]

No hidden frame, matching permutation, branch, latent Q, or lower true gap is supplied. The equality to G is a real additional datum: in the standardized dependent-component source interface it is the population covariance of the observed random vector, in the quartic's argument coordinates. Sampling/estimating it and bounding its error are charged separately.

At n1 the sole axis is already determined; no minimum over pairs or gap division is needed.

For a G-orthonormal matrix V, \(V^TGV=I\), define the metric Bombieri norm by

\[
 \|p\|_{B,G}=\|p(V\,\cdot)\|_B,
 \qquad \|p\|_B^2=\sum_{|\alpha|=4}c_\alpha^2/\binom4\alpha.
\]

It is independent of the choice of V. If T is the symmetric coefficient tensor, its squared norm is its full contraction against \((G^{-1})^{\otimes4}\), computable without choosing an irrational whitening factor. The error premise is \(\|\widehat f-f_t\|_{B,G}\le\delta\). Converting an ordinary coefficient bound to this norm incurs \(\|G^{-1}\|_{op}^2\) and coefficient-norm conversion factors.

An algorithm acquires a candidate Vc satisfying \(V_c^TGV_c=I\). It projects \(\widehat f(V_cz)\) onto its even monomials to obtain \(h_{Q_c}(z)\), and computes

\[
 f_c(x)=h_{Q_c}(V_c^{-1}x),\quad
 \rho=\|\widehat f-f_c\|_{B,G},\quad
 q_c=\tfrac12\min_{k<l}(q_{c,kk}+q_{c,ll}-2q_{c,kl}).
\]

All three quantities come from the observed input and acquired candidate. When \(q_c>0\), the theorem returns a **global ambiguity cap** around the unordered candidate axes. The candidate need not be a global optimizer for the certificate to be sound. Qc can also be checked SPD if an actual QPD candidate is required for the downstream energy certificate. Positive pair gaps alone are weaker than QPD; for example Q=I−J has positive pair gaps but is indefinite when n>1.

## Exact quartic contrast and its SOS gap

In whitened coordinates, define \(C_f(V)=\sum_i f(v_i)\) for an orthogonal frame V. For any symmetric Q and R in O(n), put \(W_{ki}=R_{ki}^2\). W is doubly stochastic. Row and column sums give the exact identity

\[
 \boxed{\operatorname{tr}Q-C_{h_Q}(R)
  =\sum_i\sum_{k<l}(q_{kk}+q_{ll}-2q_{kl})(R_{ki}R_{li})^2.}
\]

For example, expand \(\sum_kq_{kk}W_{ki}-(W_{\cdot i})^TQW_{\cdot i}\) using \(\sum_kW_{ki}=1\), then sum i and use \(\sum_iW_{ki}=1\). Equivalently the gap is \(\operatorname{tr}(Q(I-WW^T))\). Nonnegative pair gaps make coordinate axes global contrast maximizers. Strict pair gaps force every column to have at most one nonzero coordinate, hence give precisely signed permutations. QPD implies each pair gap is at least \(2\lambda_{\min}(Q)\).

Set

\[
 d(R)=n-\sum_{ki}R_{ki}^4
     =2\sum_i\sum_{k<l}(R_{ki}R_{li})^2.
\]

The candidate contrast gap is at least \(q_cd(R)\). This is an explicit degree-four weighted SOS on the orthogonality variety. The quartic contrast is classical MaxKurt/ICA machinery; this identity and its use on the stated dependent positive-gap class are our reconstruction, not a priority claim.

## Global linear inverse bound; no local branch

Write Vt for any compatible true axis frame and \(R=V_c^{-1}V_t\in O(n)\). Let the symmetric fourth axis tensors be

\[
 S_c=\sum_i e_i^{\otimes4},\quad
 S_t=\sum_i(Re_i)^{\otimes4}
\]

in candidate coordinates. Orthogonality gives

\[
 \|S_c-S_t\|_F^2=2n-2\sum_{ki}R_{ki}^4=2d(R).
\]

Each true axis frame globally maximizes the true contrast by its own nonnegative pair gaps. Thus

\[
 q_cd(R)\le C_{f_c}(V_c)-C_{f_c}(V_t)
 \le\langle f_c-f_t,S_c-S_t\rangle
 \le\|f_c-f_t\|_{B,G}\sqrt{2d(R)}.
\]

If d>0, divide by its square root; d=0 needs no division. With \(e=\delta+\rho\),

\[
 \boxed{\sqrt{d(R)}\le\frac{\sqrt2 e}{q_c},\qquad
        \|S_c-S_t\|_F\le\frac{2e}{q_c}.}
\]

There is no dimension factor. The sum-tensor subtraction, rather than bounding two contrasts separately by \(\sqrt n e\), is essential. If a certified true half-pair-gap lower bound qt is additionally available, add both contrast deficits to get the sharper bound

\[
 \sqrt{d(R)}\le\frac{\sqrt2 e}{q_c+q_t}.
\]

This latter constant is attained by the SPD binary example \(f_c=a(x^4+y^4)\), \(f_t=a[(cx+sy)^4+(-sx+cy)^4]\): qc=qt=a, d=(2cs)^2, and \(\|f_c-f_t\|_B^2=2a^2d\). The rational rotation c=3/5,s=4/5 is retained as an exact check. With only qc known, the stated weaker bound remains sound.

The returned cap is the explicit semialgebraic set

\[
 \mathcal A_e=\{V:V^TGV=I,\quad
       n-\sum_{ki}(V_c^{-1}V)_{ki}^4\le2e^2/q_c^2\}.
\]

Every compatible true frame belongs to it. It may contain additional incompatible frames; this is an outer ambiguity set, not a complete description of the feasible models. If qc≤0, return the entire G-orthonormal frame set or continue fitting, without asserting informative recovery.

## Matching acquired from the cap

If \(D=2e^2/q_c^2<1/2\), each row of W has maximum greater than1/2, since its squared sum is at least1−D and is at most its maximum. Two such row maxima cannot occupy one column because column sums are1. Therefore the maxima give a unique permutation. For that matching,

\[
 \max_i\|P_{v_{c,i}}-P_{v_{t,\pi(i)}}\|_{op,G}
 \le\sqrt D\le\sqrt2e/q_c.
\]

Here the projectors and operator norm use G; equivalently normalize vectors in whitened Euclidean coordinates. The maximum projector difference is the sine angle. Converting to ordinary Euclidean axis distances costs at most \(\kappa(G^{-1/2})\) (normalize the transformed line; use its minimum singular value). Thus the discrete matching is a consequence of a computed cap, not a supplied branch. Large caps must remain ambiguity sets. A near-isotropic midpoint input can have two verified separated compatible models even with exact G; the cycle11 obstruction still applies.

## Acquiring a candidate; complete cost

RGD on the reflectional residual, a classical eigenmatrix method, or MaxKurt can propose Vc. Exact postchecking of orthogonality, residual and pair gaps gives the same certificate for every proposer. No convergence guarantee for a heuristic is assumed. The equally informed methods receive the same covariance, tensor error and positive-gap promise.

A complete deterministic proposer exists by a finite rational Givens net, although its cost is prohibitive. Choose a G-orthonormal whitener W0 by algebraic LDL square roots. An orthogonal frame is a product of m=n(n−1)/2 fixed-order Givens rotations and column signs. Column signs do not change the residual/candidate quartic. For each rotation use

\[
 C(u)=\frac1{1+u^2}\begin{pmatrix}1-u^2&-2u\\2u&1-u^2\end{pmatrix},
 \qquad u=j/H,\quad -H\le j\le H,
\]

and also −C(u). These two charts cover the unit circle. Since \(\|C'(u)\|_{op}\le2\), nearest rounding moves one rotation by at most1/H. Telescoping products gives operator error at most m/H. The net has at most \((4H+2)^m\) frames. Every frame and quartic substitution is exact over the whitener's algebraic field; algebraic whitening/number heights and expanded-tensor costs are charged too. This is not a polynomial-time arbitrary-n algorithm.

Let \(M\ge\|\widehat f\|_{B,G}+\delta\) be a computed rational upper bound. A closest net frame to the true one has

\[
 \rho\le\delta+4Mm/H.
\]

The proof is four-slot telescoping between orthogonal actions and contraction of the even projection. Its candidate half-pair gaps differ from the true ones by at most \(\sqrt2(\delta+4Mm/H)\), since the coefficient functional \((c_{4e_k}+c_{4e_l}-c_{2e_k+2e_l})/2\) has Bombieri dual norm \(\sqrt2\). In particular at zero noise, refining H eventually gives any requested cap width for every strictly positive-gap model. Under nonzero noise an arbitrarily narrow cap is not promised; the limiting residual/error and actual gap must permit it. Searching the net, choosing among positive-gap candidates, or accepting an exact heuristic candidate acquires the frame. The theorem does not charge a global-search oracle as free.

## Certified metric uncertainty

Use a supplied candidate metric Gc and the explicit Loewner promise

\[
 (1-\zeta)I\preceq A=G_c^{-1/2}G_tG_c^{-1/2}\preceq(1+\zeta)I,
 \qquad0\le\zeta<1,
\]

where \(G_t=L_t^TL_t\). Whiten Gc and put B=A^{-1/2}. The ideal quartic \(h_*=f_t\circ B\) has hidden orthogonal frame \(L_tB\), so the previous theorem applies. All eigenvalues of B lie between \((1+\zeta)^{-1/2}\) and \((1-\zeta)^{-1/2}\). The tensor action is self-adjoint; its largest departure from identity is at most

\[
 c_\zeta=(1-\zeta)^{-2}-1,
 \quad\|h_*-f_t\|_B\le c_\zeta\|f_t\|_B.
\]

Indeed the tensor eigenvalues are products of four B eigenvalues. Their distance from1 is bounded by cζ; restricting to symmetric tensors cannot increase it. If \(\|\widehat f-f_t\|_{B,G_c}\le\delta\) and \(M\ge\|\widehat f\|_{B,G_c}+\delta\), substitute

\[
 \delta_{eff}=\delta+c_\zeta M
\]

in the exact-metric certificate. This uses observed coefficient norms, not a supplied hidden-Q norm. Ideal axes map to actual axes by B. Their additional sine distance in candidate-whitened coordinates is at most

\[
 \sqrt{1+\zeta}\big((1-\zeta)^{-1/2}-1\big)
 \le\frac{\zeta(1+\zeta)}{1-\zeta}.
\]

Add this term to the ideal cap's axis bound and then charge \(\kappa(G_c^{-1/2})\) for ordinary Euclidean interpretation. These are conservative finite constants. The relative Loewner uncertainty itself must be acquired/certified; small empirical covariance residual alone is not that certificate. The cycle11 bounded-support moment bounds can supply joint covariance/cumulant confidence bounds when their sample, support and known-mean assumptions hold.

Under the exact equality \(G_t=L_t^TL_t\), coordinate right-action by B leaves Q itself unchanged, so it preserves the pair-gap criterion. An interface that supplies an aligned metric only after unknown row rescaling is different: QPD survives that rescaling, whereas arbitrary pair-gap positivity need not. Do not conflate those interfaces or claim general noisy metric acquisition.

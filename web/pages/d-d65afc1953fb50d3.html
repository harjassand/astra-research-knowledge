# Proper 2-potency changes the same unit-family tree cost

Status: universal primitive derivation, independently gated by logic_prior14;
bounded exact-kernel evidence PASS. No new global tree/DAG simulation or
same-logic Frege/EF separation is claimed.

The baseline is the exact unit family Un from TREE_RESOURCE_BOUNDARY.md. Base
FL_e, and FL_e plus the literal structural wc/mix rules, require exactly
2^(n+1)−1 formula-occurrence lines in every actual occurrence-tree proof of ⇒Un.
The DAG minimum is n+1. This includes arbitrary cuts and compound identities.

Now add the finite **uniform 2-potency structural rule**

    Γ,A,A,A⇒D / Γ,A,A⇒D.                  (potency23)

This is the knot^2_3 presentation in the recent paper's Example3. The selected
rule presentation is explicit; it is not unrestricted contraction and no
formula-dependent domain guard is used. A fixed power-axiom presentation
A²→A³ can implement the particular width≤1 instances below with fixed source
adapters, but the numerical counts here are for this primitive sequent rule.

For arbitrary A put Q=A*A and D=Q*Q. The following is an ordinary proof tree:

| Row | Sequent | Primitive rule/premises |
|---|---|---|
|0|A⇒A|identity|
|1|A⇒A|new identity occurrence|
|2|A⇒A|new identity occurrence|
|3|A⇒A|new identity occurrence|
|4|A,A⇒Q|R*,0 and1|
|5|A,A⇒Q|R*,2 and3|
|6|A,A,A,A⇒D|R*,4 and5|
|7|A,A,A⇒D|potency23, Γ=A, from6|
|8|A,A⇒D|potency23, Γ=empty, from7|
|9|Q⇒D|L*,from8|

All endpoints and resource multiplicities are literal. The target D is
(A*A)*(A*A), so no associativity or equivalence shortcut is needed. There are
10 rows and 4*2+2*3+5+4+3+2=28 formula occurrences. Every premise slot has a
distinct subtree; there are **zero** primitive ⇒1 leaves. Compound identity is
allowed by the ordinary rule even when A contains many unit symbols.

Start with the 3-row,3-occurrence occurrence-tree proof ⇒U1 using two distinct
⇒1 leaves and R*. For each j=1,...,n−1, instantiate a fresh copy of the macro
with A=U(j−1), so Q=Uj,D=U(j+1), and cut its Q⇒D endpoint against the preceding
closed ⇒Uj tree. The earlier endpoint is used once. This gives, for n≥1,

    rows = 3+11(n−1) = 11n−8,
    formula occurrences = 3+29(n−1) = 29n−26,
    primitive unit leaves = 2.

The final unfolded formula is still exactly Un. The proof is a genuine tree;
formula storage may use a common constructor DAG without changing its inference
tree. Ordinary symbol-size can still be exponential in n because Un is large.
The claim is only a linear **formula-occurrence line** upper bound for this family.

The weight is a **proof-cost potential**, not an algebraic truth valuation:
w(1)=1 counts the resource-generating unit axiom, whereas a monoidal algebraic
unit would have neutral additive weight0. Potency breaks this proof-cost measure
and supplies an actual zero-unit square-duplication proof. The wc averaging
rule preserves it. No identification of literal wc with the earlier CWC axiom
is made.

This is a meaningful controlled-contraction boundary: a proper uniform source
principle changes tree serialization cost for the same goal family, without
solving or assuming general lower bounds. Future work can ask which square/
k-potent logics admit broader polynomial tree serialization; this cycle proves
neither a positive nor a negative answer to that global question.

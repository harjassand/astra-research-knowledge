## Question, source and exact interface

Can the ground-band stability proof of De Roeck, Khemani, Li, O'Dea and Rakovszky, *LDPC stabilizer codes as gapped quantum phases: stability under graph-local perturbations*, be used with bounded declared supports that include sites on which a check acts as identity?

The primary version is arXiv2411.02384v3, dated 12 August 2026; the arXiv author index states that this revision updates funding and identifies the journal article as PRX Quantum 6, 030330 (2025). The theorem and proof are prior work. This note audits Sections2–8 and AppendixB of the saved48-page v3 PDF, rather than inferring an extension from the abstract. We have not audited the examples in AppendixA or the classical/symmetry-breaking extensions in Sections9–12. Source snapshots and exact read scope are in the owned metadata file.

Let Lambda be N qubits and C_alpha, alpha in E, be commuting Hermitian Pauli checks with a nonzero common +1 eigenspace P. Write

    H0 = sum_alpha E_alpha,  E_alpha = (I-C_alpha)/2,
    G_alpha = (I+C_alpha)/2,  Nc = |E|,
    G = group generated by the checks.

Actual Pauli support always means nonidentity sites. Phases of Pauli representatives are absorbed in coefficients. The actual code distance d implies: a Pauli of actual weight <d commuting with every check belongs to the stabilizer algebra. This is the TQO-I input; its definition is not enlarged.

For each check choose a nonempty **declared** set D_alpha containing its actual support. Assume every qubit belongs to at least one declared set. Set

    inc_D(x) = {alpha : x in D_alpha},
    sigma_D(S) = union_{alpha in S} D_alpha,
    Wq = max_x |inc_D(x)|,  Wc = max_alpha |D_alpha|.

Both Wq and Wc are fixed constants for the family. The declared qubit graph joins two sites in a common D_alpha. The declared check graph joins two checks whose declared sets intersect. These graphs have degree at most Wc Wq. Fix kappa with both ball cardinalities at radius r bounded by exp(kappa r); kappa >= log(Wc Wq+1) suffices.

The additional, stronger hypothesis is

    For connected check S with |S| < d_tilde,
    {g in G : actual supp(g) subset sigma_D(S)}
       subset < C_alpha : dist_D(alpha,S) <= ell |S| >.       (D-TQO-II)

Here ell is independent of N. We do not obtain this condition merely by shortening distances. The larger sigma_D(S) changes the set of stabilizers that must be generated. In the intended memory composition d_tilde must be comparable with d, or the actual smaller effective cutoff must be retained.

Define d_dagger = min(d/Wc, d_tilde). Suppose d_dagger >= c log N for a fixed c>0. Define the intensive Pauli norm exactly as in the primary theorem, except that the minimum connected qubit cover M_D(p) uses the declared qubit graph:

    |||O|||_nu = sup_x sum_{p: x in actual supp(p)} |c_p| exp(nu |M_D(p)|).

The identity component is a scalar energy shift and is removed before forming nonempty words. Disconnected Pauli supports with no connected cover have infinite norm, so the perturbation hypothesis excludes them.

## Word algebra and connected support

Use the primary word quadruple S=(S_+,S_-,S_e,S_g), with disjoint sets of checks. Its underlying set is their union. Define its operator class by the same projector sandwich L_S X_tilde R_S, but require

    inc_D(actual supp(X_tilde)) subset S.                    (1)

All assertions below follow from actual operators and declared containment; they do not require a check to act nontrivially at every declared site.

1. **Operator support.** The projectors in the sandwich are actually supported in sigma_D(S). By coverage and (1), every actual site of X_tilde belongs to sigma_D(S). Thus actual supp(X_S) subset sigma_D(S), and every Pauli component has actual weight <= Wc|S|. The check incidence of a Pauli component need not be contained in S.
2. **Commutation outside S.** If beta notin S, its actual support is disjoint from actual supp(X_tilde), because actual supp(C_beta) subset D_beta. Consequently X_tilde commutes with C_beta and its projectors. No identity site contributes an anticommutation.
3. **Product table.** Checks outside each word can be moved through its underlying operator using item2. Shared projectors then obey precisely the same G/E multiplication table as in primary Table1. A nonzero product is in the class for S union S'; its underlying operator satisfies (1) for the union. No new labels are needed.
4. **Disjoint words commute.** For S intersection S' empty, actual supports of X_tilde and X_tilde' are disjoint: a common site would have some declared incident check, forced into both words. Also X_tilde commutes with every check projector from S', and conversely. All projector checks commute mutually. Therefore [X_S,X_S']=0. This establishes the anchoring property needed for every nested commutator.
5. **Two connectivity implications.** A connected nonempty qubit set M has connected ext_D(M)=union_{x in M} inc_D(x): each adjacent pair of qubits has a common declared check, and all checks incident at a fixed qubit form a check clique. Its size is <=Wq|M|. Conversely, connected check S has connected sigma_D(S), with size <=Wc|S|, because every declared check set is a qubit clique and adjacent checks share a site. These are statements about the specified incidence graphs.

Initially choose a minimum connected M_D(p), extend it to ext_D(p), and sandwich p by all projector choices. Each check either commutes or anticommutes with p; only two of its four label choices can survive. Hence at most 2^{|ext_D(p)|} nonzero terms, each of operator norm <=1. Extra checks introduced through identity sites have commuting choices e or g; they enlarge the book-keeping, not the actual action of p. Initial words are connected. Every nonzero nested commutator is a union of intersecting connected words and remains connected.

The word norm is

    ||O||_mu = sup_alpha sum_{S: alpha in S} ||O_S|| exp(mu |S|),

and ||sum_S O_S|| <= Nc ||O||_0. Empty words are removed as scalar shifts.

## Norm conversions and two necessary bookkeeping repairs

For the initial Pauli-to-word construction the safe bound is

    ||O||_mu <= |||O|||_{Wq mu + Wq log2 + kappa + log(2Wc)}.   (2)

Proof: for alpha in ext_D(p), some actual site x of p lies at declared qubit distance <=|M_D(p)| from D_alpha. At most Wc exp(kappa r) candidate sites lie within distance r of D_alpha. Group by **r=|M_D(p)|**, use |ext_D(p)|<=Wq r and the at-most-2^{|ext|} choices, and insert exp(-(kappa+log(2Wc))r). The geometric series has total Wc/(2Wc-1)<=1. This is the same final estimate as primary Proposition3.1. In AppendixB.1 the displayed grouping index is |ext(p)| while the compensating exponent uses |M(p)|; those displayed equalities are not identities in general. Regrouping by |M(p)| repairs the argument without changing its final constant. We do not need a claim that |ext| and |M| are equal.

For an arbitrary connected-word collection a conservative reverse estimate is

    |||O|||_mu <= Wq ||O||_{Wc(mu+log4)}
               <= ||O||_{Wc(mu+log4)+log Wq}.                (3)

Indeed each O_S has at most 4^{Wc|S|} Pauli coefficients, each bounded by ||O_S||, and any component has a connected cover of size <=Wc|S|. If actual x occurs then some alpha in inc_D(x) belongs to S, giving the factor Wq. The counting argument displayed in AppendixB.2 drops Wc from the log4 term in its next norm. We use (3), rather than the printed weaker exponent. A visual check of PDFpage48 confirms the displayed exponent. This repair is immaterial to the ground-band flow, which needs (2) but does not convert its word collections back to Pauli norms. It makes any optional later Pauli-norm statement conservative.

## Small-word TQO and the ghost correction

If |S|<d_dagger, every Pauli component has actual weight <d. A word commuting with every check therefore belongs to the stabilizer algebra by actual-distance TQO-I. If S is connected, D-TQO-II then puts this operator in the algebra generated by checks within B^D_{ell|S|}(S).

A pure-g ghost M_S commutes with every check: for alpha in S this follows from its G_alpha sandwich, and outside S from (1). It is supported in sigma_D(S). Therefore it is a sum of stabilizer Paulis represented by checks in the stated buffer. For a word S' containing only + and g,

    [M_S,X_S'] P = q(S',S) X_S' P,
    |q(S',S)| <= 2 * 4^{Wc|S|} ||M_S||,                     (4)

and q can be chosen zero unless B^D_{ell|S|}(S) meets S'_+. This follows because a stabilizer product acts on a raised syndrome by the parity of its intersection with S'_+. Summing (4), anchored at a member of S'_+, yields

    sum_S |q(S',S)| <= 2 |S'_+| ||M||_mu
       sum_{r>=1} exp((kappa ell + Wc log4 - mu) r)
       <= |S'_+| ||M||_mu,                                 (5)

when mu>kappa ell+(Wc+1)log4. The last geometric sum is <1/3, so the indicated factor2 is safe.

**Primary Eq.(5.6) needs a support repair even on the actual graph.** It requires Pauli components to have supp_c(p) subset S. This does not follow from (3.7), because the surrounding projectors add check Paulis. For example M_S=G_alpha, S_g={alpha}, X_tilde=I is a valid ghost; its Pauli component C_alpha can overlap a neighbouring check beta. The property actually used and proved above is actual supp(p) subset sigma_D(S). It supplies both TQO hypotheses and the identical 4^{Wc|S|} count. Replace the summation condition in primary Eqs.(5.6),(5.9) by this support containment. Thus the incorrect intermediate claim is not a counterexample to the ghost bound or the theorem.

For completeness, the most geometric late step is relative boundedness. Decompose by all exact check syndromes P(X). D_S changes only labels in S, and is nonzero only if X intersects S. The primary calculation gives

    ||D psi||^2 <= ||D||_0 ||D||_1 <psi,H0^2 psi>.

Extra declared identity sites cannot change a syndrome and do not alter that calculation. For a small ghost subtract its scalar on P: Mbar_S=M_S-<M_S>. By D-TQO-II,

    Mbar_S G_buffer = G_buffer Mbar_S = 0,
    ||Mbar_S|| <= 2||M_S||,
    G_buffer = product_{alpha in B^D_{ell|S|}(S)} G_alpha.

Since these ghosts commute with all checks, their sum is relatively bounded by sum_S ||Mbar_S||(I-G_buffer), then by sum_alpha E_alpha sum_{S:alpha in buffer}||Mbar_S||. The last coefficient is bounded using

    sum_{r>=1} exp(-(mu-kappa ell)r) ||Mbar||_mu.

This is precisely where a **linear** generation radius suffices. No fixed physical collar, support-volume substitution or uncharged iteration of a physical dilation is used. The finite-size terms |S|>=d_dagger are charged as Nc exp(-mu_infinity d_dagger), not discarded.

The optional local-unitary statement also survives. In encoding a local operator on connected Y, include the factor <=4^{|Y|} from its Pauli coefficients and 2^{Wq|Y|} projector choices. The smaller finite factor displayed near primary Eq.(4.48) is unnecessary: the conclusion permits an arbitrary finite C(mu0,Y). A connected word reaching declared qubit distance r from Y has |S|>=r-O(1); its word-norm tail is exponentially small. The final globally small error rotation gives the same background term. We do not use this optional conclusion to infer memory lifetime.

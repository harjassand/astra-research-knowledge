## Proof correspondence

The module uses Mathlib's `AbsolutelyContinuousOnInterval` definition for both the vector path and the scalar branch/envelope functions. It derives coordinate AC by composing the vector path with each 1-Lipschitz coordinate projection. A fixed affine branch is then AC by finite sums, scalar multiplication, and addition. The absolute value of a scalar AC function is proved AC by the endpoint inequality `dist (|u|) (|v|) ≤ dist u v`; the identity `min f g = (f + g - |f-g|)/2` gives binary-minimum AC. Induction over `Finset.Nonempty.cons_induction` extends this to the exact `Finset.inf'` used by the parent `finiteMinimum` definition.

For a.e. regularity, the proof applies the actual Mathlib theorem `AbsolutelyContinuousOnInterval.ae_differentiableAt` to each scalar branch and to the scalar envelope. It applies it to every path coordinate and takes the countable/finite AE intersection. Mathlib's `differentiableAt_pi` then yields differentiability of the vector-valued path itself. Thus differentiability of the minimum is derived from AC; it is not an input assumption to the a.e. result.

At a common differentiability time, the affine branch derivative is proved by the finite-sum derivative rule and the coordinate chain rule. The parent `finite_minimum_active_derivative_eq` is then applied to every index satisfying equality with the minimum. The weak active condition is equality to the lower envelope, and the theorem universally quantifies over all such indices, so ties are retained. The drift corollary uses finite attainment only to select one active index after the hypothesis has already bounded every active branch.

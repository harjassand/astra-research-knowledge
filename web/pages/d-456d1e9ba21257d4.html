INVARIANT POSITIVE-VOLUME CODE POWER LEMMA
Follow-up refinement; INITIAL.txt remains immutable.

Interface. Let (M^3,g) be closed, let X be smooth and divergence-free (zeros are allowed), let T=φ_1, μ=dVol_g/V, S=Def_g X, ν>0, and let U={X≠0}. On U define r=|X|, e=X/r, P=I−e⊗e. On e⊥ put B=PSP and q=<Se,e>. Since tr B=−q, write B=B_0−(q/2)I with trace-free symmetric B_0 having eigenvalues ±s, s≥0. Orthogonal block decomposition gives |S|²=2s²+(3/2)q²+2|PSe|²≥2s². Define s_1(x)=∫_0^1 s(φ_t x)dt on U.

Claim A (invariant measures supported on U). For every T-invariant probability η with η(U)=1,

  h_η(T) ≤ ∫ s_1 dη.

The normal cocycle Q_t=P_{φ_t x}Dφ_t|_{e(x)⊥} obeys the moving-frame estimate

  log||Q_t(x)|| ≤ ∫_0^t s(φ_u x)du − (1/2)log(r(φ_t x)/r(x)).

This is the audited cycle-1 identity. If X has zeros outside the η-full set U, the endpoint term need not be uniformly bounded. Instead the X-line exponent exists by Oseledets and is zero: along a Poincaré recurrent subsequence T^{n_j}x→x in U, log r(T^{n_j}x)−log r(x)→0; because the exponent limit exists, it must equal zero. The normal determinant is r(x)/r(φ_n x), so its exponent sum is also zero. The projected cocycle and inverse have integrable logarithms because their norms are bounded by the full derivative and inverse derivative on compact M, as in the cycle-3 zero-set audit. Thus the full spectrum is χ,0,−χ, χ≥0. For integer n, apply the estimate at n and write the integral as Σ_{j<n}s_1(T^j x). Oseledets for η, Birkhoff for s_1 and the recurrent sublinear endpoint give ∫χdη≤∫s_1dη. Ruelle's inequality for the C¹ map T gives h_η(T)≤∫χdη. No absolute-continuity, ergodicity or full-flow-invariance assumption on η is needed; T-invariance and η(U)=1 suffice.

Claim B (code-set work floor). Let C be a measurable T-invariant set modulo μ, with β=μ(C)>0 and μ(C\U)=0, and η=μ|_C/β. If h_η(T)≥κ nats per time-one unit, then the global sustaining power satisfies

  W = 2ν∫_M|S|²dVol_g ≥ 4ν V β κ².                       (★)

Proof. Claim A yields ∫s_1dη≥κ. For each t, φ_t preserves μ and μ(φ_t C)=β. Thus

  ∫_M s²dμ ≥ ∫_0^1∫_{φ_t C}s²dμdt
             = β∫_0^1∫_C s²(φ_t x)dη(x)dt
             ≥ β(∫_0^1∫_C s(φ_t x)dη(x)dt)²
             = β(∫s_1dη)² ≥ βκ²,

where the penultimate inequality is Jensen on η×Lebesgue[0,1]. Since |S|²≥2s² and the stationary closed-manifold strain-viscosity identity is W=2νV∫|S|²dμ, (★) follows. This does not require C to be invariant for every real time; T-invariance suffices because the estimate uses the time-one averaged observable s_1 and each φ_t C has the same volume.

A fixed finite readout partition P with h_η(T,P)≥κ is sufficient; this is more concrete than merely naming a code set. If β and κ are certified lower bounds, use W≥4νVβκ². In bits/time unit, κ_nat=(ln 2)κ_bits. This is stronger than applying only the global entropy affinity H_μ(T)≥βκ and the original theorem, which yields W≥4νVβ²κ². The improvement uses the all-invariant-measures version of the normal-cocycle/Ruelle estimate and localizes its strain integral to the orbit sweep of C.

Scope. This is a conditional mathematical consequence, not a universal-computation theorem. It requires a stationary invariant code population of positive volume that is supported almost everywhere on U, a fixed finite readout and a positive asymptotic entropy rate under the conditioned population. Zeros elsewhere are allowed. Finite-duration simulation, a candidate set with β→0 as horizon grows, an exceptional null set, or worst-case/topological complexity does not meet the premise. The theorem still supplies no effective procedure to certify β, κ or the asymptotic partition entropy from finite data, nor actuator/readout costs.

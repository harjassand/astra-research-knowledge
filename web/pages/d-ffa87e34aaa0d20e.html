# Three-point dictionaries: a sharp cubic obstruction to collinearity

Date: 2026-10-06. Worker: r06_combinatorics.
Status: first statement has a complete elementary proof. Four finite minima were exhaustively computed by an exact set-cover solver; these do not imply an all-dimension theorem. Novelty unverified.

## Exact analytic example

Let S={s1,s2,s3} be a basis of R^3 and let repetitions be allowed in 3S. The minimum |B| for arbitrary |A|=3 with 3S subset A+B is exactly 4.

There are 10 distinct targets, so |A||B|>=10 implies |B|>=4. For the upper bound choose

`A={2s1,2s2,2s3}`,

`B={s1,s2,s3,-s1+s2+s3}`.

Every target with a repeated index has form 2si+sj, covered by the first three B elements. The only target without a repeated index is s1+s2+s3, covered by 2s1+(-s1+s2+s3). This proves the exact value.

In contrast the progression theorem in `two_dictionary_theorem.md` gives minimum 5 for every three-term progression A. Thus noncollinear A is strictly more efficient. This is a precise obstruction to inferring universal r-point results from line-covering calculations. It does not refute Xu's two-fold theorem.

## Why the finite candidate space covers arbitrary real dictionaries

This reduction is specific to three points. Choose one representation for each target using A and B. Form a graph on the three A labels: put an edge between ai,aj whenever one chosen B value is used to represent one target with ai and another target with aj.

If this graph is connected, choose a spanning path on its three vertices and translate its middle A point to zero. Both remaining A differences are then differences of two targets, hence lie in `D=(T-T) minus {0}`. This is exactly the candidate space enumerated.

If the graph is disconnected, every chosen B value serves targets from one component. A singleton component serves at most one target per B value. Replace its A point by an existing A point a0 and replace each of its assigned B values b with `target-a0`. This preserves all selected representations and cannot increase |B|, since coincidences may only decrease the set size. Thus a disconnected solution converts into a two-point cover (or one-point cover) with no larger B. The two-point bound therefore applies to every disconnected solution.

For the four rows above, the two-point minima are respectively 4,6,7,13, larger than the reported three-point minima. Consequently an optimal dictionary can be chosen connected; every arbitrary-real optimum is included in the finite normalized search. For fixed A, any useful B value must be `target-a` for some target and a in A, so the set-cover candidate list is also exhaustive.

This is a universal reduction for each fixed finite instance, followed by exact finite computation with separate solver agreement. It does not prove a closed formula for arbitrary n,k, nor establish novelty. A stronger delivery would include a human-readable lower-bound certificate for the 9 claim.

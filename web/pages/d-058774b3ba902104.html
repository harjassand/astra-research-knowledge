# Cycle 2: output-specific source allocation and controlled target menus

2026-10-06. Status: independently reconstructed proof candidate; checker and d_math audits requested. This extends the mathematical sample-cost theorem, not its computational implementation. Previous cycle artifacts are preserved.

## Interface and candidate result

Source actions a have supplied known finite full-support channels F_i^a and positive costs c_a; the source menu jointly identifies each finite state pair. Target actions b have supplied known finite full-support channels G_i^b and positive costs β_b. The hidden state is fixed. A target action is chosen from observed history by the same state-independent kernel in every state; samples are fresh given state/action. Target policy stops with finite output Z and integrable total target cost C_G. Source reproduction preserves exactly the statewise output law, not the target clock or online action trace.

Write d_ij^a=KL(F_i^a||F_j^a), g_ij^b=KL(G_i^b||G_j^b). For each true-state row i define the gauge on nonnegative vectors

    φ_i(v)=min { Σ_a c_aw_a : w≥0, Σ_aw_ad_ij^a≥v_j for all j≠i }.

It is finite, convex, coordinatewise monotone and positively homogeneous; it is subadditive, and bounded by L_i||v||_1 because a fixed positive mixture identifies every pair. LP duality gives φ_i(v)=max_{λ≥0:D_i^Tλ≤c} λ·v. Positive costs and identification make a maximizing dual solution bounded. Define

    γ_i=max_b φ_i(g_i^b)/β_b.

Candidate theorem: a single adaptive source converter exactly reproduces every integrable finite-output controlled-target policy and satisfies

    E_i C_F ≤ γ_i E_i C_G + C sqrt(E_i C_G), simultaneously in every i,

with C independent of policy and terminal output cardinality. Each γ_i is first-order sharp: target action b repeated n times and full transcript output forces E_i C_F≥nφ_i(g_i^b). Taking b attaining the maximum rules out any smaller uniform coefficient. A source mixture fixed for candidate i generally gives min_q max_b rather than max_b min_q; output-specific source allocations are essential.

## Load-bearing finite-H construction

Let H_i(y)>0 be a finite common-support report law. Set λ_ij(y)=log(H_i(y)/H_j(y)), Δ=max|λ|, η small, g=log(1/η). Choose globally identifying baseline mixture q0. First take O(g) baseline observations and classify candidate K with error≤η. Propose y~H_K.

For the observed proposal (k,y), set b_j=[λ_kj(y)]_+ +g and solve the source row LP for w at φ_k(b). Take n_a=ceil(w_a) samples of each action in a predetermined order, with planned duration N=Σn_a and planned cost A=Σc_an_a. These depend only on k,y, never on the true state. They satisfy

    E_k S_kj(N)=Σn_ad_kj^a≥b_j,
    A≤φ_k([λ_k(y)]_+) +gφ_k(1)+Σc_a,
    N≤A/c_min≤C(1+Δ+g).

During this batch reject as soon as any reverse likelihood S_jk≥g. On surviving to its end, accept if every S_kj≥b_j. Otherwise continue on fresh baseline q0 observations until either every total S_kj≥b_j, or any reverse S_jk≥g; reject wins ties. The continuation has bounded positive forward drifts under k and positive i/k reverse drift under every wrong true i. All stop times are integrable. Sampling kernels change at observed stopping times only.

### Correct-candidate expected cost: random deficits remove the log factor

Analyze the hypothetical full batch even on paths that would reject early. Its samples are independent and bounded under state k. For every j,

    E_k[(b_j-S_kj(N))_+] ≤ E_k|S_kj(N)-E_kS_kj(N)|≤σ_max sqrt(N).

The first inequality uses E_kS_kj(N)≥b_j. On a surviving path the actual batch equals this hypothetical batch; multiplying the deficits by its survivor indicator only reduces their unconditional expected value. Therefore conditioning on survival does not invalidate the bound.

Given the observed batch, the baseline continuation's simultaneous-passage benchmark is t=max_j(b_j-S_kj(N))_+/d_ij(q0). Its expected sampling duration, ignoring rejection, is ≤t+C√(1+t)+C by the bounded positive-drift Hoeffding tail argument. Hence its unconditional cost is O(√N)+O(N^{1/4})+O(1). Fresh IID baseline action costs satisfy Wald conditional on the observed batch.

Total correct-candidate expected cost is at most

    φ_k([λ_k(y)]_+) +C[ sqrt(1+φ_k([λ_k(y)]_+))+g ].

This requires no uniform positive drift from an output-specific fixed mixture. It samples a finite rounded optimal allocation, then repairs the actual stochastic deficits using the one fixed baseline.

### Wrong-candidate expected cost

The batch cost is deterministically O(1+Δ+g). If it survives under wrong true state i, the baseline reverse i/k process must cross from its batch score S_ik(N) to g. Its remaining threshold is at most g+L_FN, because every source log likelihood increment is bounded by L_F. The same scalar passage bound gives additional cost O(1+g+N). Consequently

    sup_{i≠k,y} E_i[verifier cost | k,y] ≤ C(1+Δ+g).

Wrong candidates have total probability at most η, so they contribute only O(η[1+Δ+g]). The batch itself need not have a wrong-state rejection drift; baseline continuation supplies it.

### Exactness and residual repair

Under candidate's true state k, exp(S_jk) is a nonnegative mean-one martingale despite the heterogeneous batch and observed-history baseline switch: the selected action's likelihood increment has conditional mean one. Ville plus union bound gives rejection probability≤dη, d=|Θ|-1. On success S_ki≥[λ_ki]_++g≥λ_ki+g, so stopped change of measure gives

    p_i(k,y)≤η H_i(y)/H_k(y) p_k(k,y),  i≠k.

These are exactly the two error bounds needed by the original mass construction. Independently thin accepted proposals by (1-η)/(1+dη), obtaining accepted mass Q_i(y)≤(1-η)H_i(y), missing probability η≤δ_i≤2(d+1)η, and residual R_i=(H_i-Q_i)/δ_i with Δ(R)≤Δ(H)+log(2(d+1)/η). Reproduce R exactly on fresh baseline observations using classifier-confusion inversion; cost O(1+Δ(R)), paid only with probability δ_i. Final law is Q_i+δ_iR_i=H_i exactly.

The result is the uniform finite-H bound

    E_i C_F≤B_i(H)+C[√(1+B_i(H))+g+η(1+Δ(H))],
    B_i(H)=E_{Y~H_i} φ_i([λ_i(Y)]_+).

Every classifier, wrong batch, deficit correction and residual observation is included. C is independent of H, its output cardinality and η. Real arithmetic, exact probability calculation and LP compilation are not charged.

## Controlled-target transfer and arbitrary stopping

For T≤m target observations, action-selection likelihood factors cancel and

    S_ij^G(T)=Σ_{t≤T}g_ij^{B_t}+M_ij(T),
    E_i M_ij(T)^2≤V E_iT.

Terminal likelihood identity plus Jensen gives λ_ij(Z)≤E_i[S_ij^G(T)|Z]. The function v↦φ_i(v_+) is convex and coordinatewise monotone. Therefore

    B_i(H)≤E_i φ_i((S_i^G(T))_+)
           ≤E_i φ_i(Σ_{t≤T}g_i^{B_t})+L_iΣ_jE_i|M_ij(T)|
           ≤E_i Σ_{t≤T}φ_i(g_i^{B_t})+C√E_iT
           ≤γ_i E_i C_G+C√E_iT.

This is a pathwise gauge/subadditivity bound, not an interchange of max and expected action counts. It remains valid when the target branches into different designs based on earlier outcomes.

Full support and bounded increments give Δ(H)≤mL_G. Set η=η0/m and obtain E_iC_F≤γ_i E_iC_G+C√m. Apply this converter to dyadic target continuation blocks with durations2^k. Exact reproduction of each live history ensures correct reach probabilities and final law. Leading costs sum to γ_iE_iC_G. The remainder is bounded pathwise by C√T, hence in expectation by C√E_iT≤C/√β_min √E_iC_G. Every bounded converter consumes at least one classifier observation; infinite stages cannot accumulate at finite source time. Integrability and target termination prove finite source duration and exact output law.

## Converse and boundaries

For arbitrary adaptive source reproduction of n outputs from a fixed target action b, stopped-record KL is Σ_aE_iN_ad_ij^a and output data processing gives ≥ng_ij^b. Thus w_a=E_iN_a/n is gauge feasible and source cost≥nφ_i(g_i^b). If a proposed coefficient is smaller than γ_i, choose a maximizing b and let n→∞; any uniform lower-order remainder fails. All coefficients above are simultaneously achieved by one state-independent source policy.

Necessary menu large-budget stopping dominance condition is γ_i≤1 for every i. Strict γ_i<1 for every i is sufficient. Equality is unresolved. This does not automatically characterize preference in all decision problems, finite hard-horizon simulation, online preservation of target time/action traces, or unknown/calibrated channels. Target actions that change the physical state lie outside this interface.

# Root gate: a dimension threshold for the screened prior comparator

7 October 2026, cycle10. **PASS**, independently reconstructed after `rounding_prior` supplied the consequence. This is an elementary comparison of the new theorem's guarantee with the already gated kT rounding interface, not a new general discrepancy theorem.

Let A have n columns with Euclidean norms at most one, y∈[0,1]^n, and target hard radius B>0. For each row, compute exactly the maximum and minimum of A_i(z−y) over the whole Boolean cube. Discard a row if its absolute box range is strictly below B. Its bound then holds on every vertex of the actual polytope, independently of the rounding method.

Every retained dangerous row has l1 norm at least B, hence squared l2 norm at least B²/n by Cauchy–Schwarz. Summing over rows and using the n column-energy bounds shows that their count m′ satisfies

    m′ ≤ n²/B².

On the retained-row submatrix, the largest column l1 norm obeys T′≤√m′≤n/B. Apply the prior favorable-cost/original-face kT procedure, then its exact-mean extraction if a law is required. It uses the same polytope and input information, and has radius at most kT′≤kn/B on the retained rows. Together with the discarded-row range certificates this meets strict target B whenever

    n < B²/k.

Equality at the threshold requires preserving the exact strict/non-strict conventions and is not adopted here. Empty retained submatrices are trivial.

For B=737 and k=2 the threshold is n<271584.5. Both inspected treatment-allocation cohort sizes and the n134 trace lie below it. At those sizes the new dimension-free theorem therefore does not improve the guaranteed hard radius over this equally informed screened control. The n4422 fixed-step runtime witness is also below it, consistent with its much stronger explicit two-atom law.

This does not refute the asymptotic O(k) theorem on arbitrary Boolean short-edge polytopes: n and the number of dangerous rows may grow past this threshold. It sharply changes experiment selection. A demonstration of guaranteed-radius advantage at the current constants must escape this screening bound and all stronger available structural controls. No new large experiment was run to manufacture such an example.

PRECISION AND ACQUISITION LOWER BOUNDS FOR A HIDDEN RATIONAL PATH
Date: 2026-10-08
Status: self-contained scoped derivations; classical two-point/Fano mechanisms; no novelty or priority claim.

Question and interface

How costly is it to identify a small rational predictive process when observations expose only noisy or rounded evaluations? The answer depends on the legal observation interface. The theorem below is for passive uniform word observations or a fixed, nonadaptive point-query schedule. It does not claim a lower bound for adaptive matrix-output access, arbitrary dense linear functionals, or exact full-matrix output.

Let n>=2, d>=1, N=n^d, and let the hidden word U=(U_1,...,U_d) be uniform on [n]^d. For each u define the finite-horizon weighted automaton

    f_u(a_1...a_l) = Delta * 1{l=d and (a_1,...,a_d)=u},

where Delta=2^(-H), H is a nonnegative integer. This has a deterministic acyclic realization with d+1 states: at layer r, symbol u_(r+1) alone carries a unit transition to layer r+1; all other transitions are zero; the final output weight is Delta. Thus all entries lie in {0,1,2^(-H)}, the transition graph is acyclic, and the hidden state count is d+1. The description length of the unknown path is d log2(n) bits; the nonzero rational output coefficient has denominator height H+1 bits. Distinct functions are Delta apart in uniform norm. Exact identification is therefore necessary for uniform prediction error strictly below Delta/2.

Observation model A (passive words or fixed point queries)

At each of q rounds the learner sees a word x_t in [n]^d and

    Y_t = f_U(x_t) + Z_t,       Z_t iid N(0,sigma^2).

The input words may be iid uniform, or they may follow a fixed or randomized schedule chosen in advance, independently of U and the Y values. Each query returns one scalar. Query count q, input description bits q*d*log2(n), and arithmetic are separate costs.

Theorem. If an estimator identifies U with probability at least 1-delta for every u, where 0<delta<1/2, then for N>=2

    q >= max { (1-delta)N - 1,
               (2 sigma^2 N / Delta^2) * ((1-delta) ln(N) - ln(2)),
               (sigma^2 N / Delta^2) * kl(1-delta || delta) }.

A negative second term is vacuous for small N and should be dropped. Here kl(p||q)=p ln(p/q)+(1-p)ln((1-p)/(1-q)). The same lower bounds hold for iid uniform passive words. Quantizing the Gaussian outputs cannot weaken these lower bounds, by data processing.

Proof. Write r_u for the number of scheduled queries equal to u. Under U=u, the complete Gaussian response vector has mean Delta times the indicator vector of those r_u rounds. Against the all-zero-mean reference law P_0,

    D(P_u || P_0) = r_u Delta^2/(2 sigma^2).

For a fixed schedule, I(U;Y | schedule) <= (1/N) sum_u D(P_u||P_0) = q Delta^2/(2 sigma^2 N). Fano's inequality and average error at most delta imply I(U;Y | schedule) >= (1-delta)ln(N)-ln(2), giving the second bound. Averaging over a schedule independent of U and Y gives the same result for passive uniform inputs.

For the third bound, any pair u!=v induces two response laws whose KL divergence is Delta^2(r_u+r_v)/(2 sigma^2). Applying data processing to the binary decision {U-hat=u}, the assumed per-hypothesis error bound forces this divergence to be at least kl(1-delta||delta). Average over all unordered pairs and use average(r_u+r_v)=2q/N. This yields q >= sigma^2 N Delta^(-2) kl(1-delta||delta).

For the first bound, let S be the set of distinct queried words, |S|<=q. The chance U lies in S is |S|/N. If U is outside S, all responses have the same law for every unqueried word, so the learner can succeed on that event with probability at most 1/(N-|S|). Averaged over U, the total success probability is at most (|S|+1)/N <= (q+1)/N. This proves q >= (1-delta)N-1. The bound does not require Gaussian noise; it only uses that an unqueried word leaves no trace in point observations.

Strong point-query baseline. Query every word r times and select the largest empirical mean. For each wrong word, the difference between its empirical mean and the true word's empirical mean is Gaussian with variance 2 sigma^2/r. A union bound gives error at most (N-1) exp(-r Delta^2/(4 sigma^2)). Hence

    q = N r,   r = max(1, ceil((4 sigma^2/Delta^2) ln((N-1)/delta)))

suffices. This maximum-likelihood scan has the same N*(sigma^2/Delta^2)*log(N/delta) order as the lower bound for fixed point schedules, up to constants; when noise is tiny, the N-query search term dominates. This is the strongest explicit baseline used here under the stated point-query interface: it knows the full family and prior, but not U. If the environment supplies U or permits richer queries, this baseline and theorem no longer describe the same interface.

Precision, rational height, conditioning, and noise

1. Two-point statistical bound. Suppose a fixed observation has Gaussian variance sigma^2 and two candidate models differ in its mean by gamma. With q independent repetitions,

    D(P_1^q || P_0^q) = q gamma^2/(2 sigma^2).

If both testing errors are at most delta, data processing gives

    q >= (2 sigma^2/gamma^2) kl(1-delta || delta).

If the relevant evaluation/query map attenuates a coefficient contrast Delta_c to gamma=Delta_c/kappa, then q >= 2 sigma^2 kappa^2 Delta_c^(-2) kl(1-delta||delta). Here kappa is defined by that actual contrast attenuation. A condition number of a freely changed realization basis alone does not imply this attenuation: the observable process can be invariant under similarity transformations.

2. Coefficient height. For the displayed family Delta_c=2^(-H), so the pairwise noisy lower bound scales as sigma^2 kappa^2 2^(2H) kl. In the N-way hidden-path theorem, substitute Delta=2^(-H): its noise term is 2 sigma^2 N 2^(2H) ((1-delta)ln(N)-ln(2)). Thus bit-length H of a small rational coefficient can induce exponential-in-H sample cost even though the automaton has only d+1 states and polynomial description length.

If rational coefficients are represented in reduced form p/q with |p|,q<=2^H, any two distinct such rationals differ by at least 1/(q1 q2)>=2^(-2H). This separation can be attained to constant factors, e.g. 1/2^H and 1/(2^H-1) differ by 1/[2^H(2^H-1)]. A worst-case height-H pair can therefore force a two-point noisy cost of order sigma^2 kappa^2 2^(4H) kl. This is a worst-case possibility, not a claim that every height-H model family has such a small gap.

3. Deterministic quantization. Let Q_b(y)=floor(2^b y) on nonnegative outputs, with bin width 2^(-b). For the noiseless family above, if b<=H-1 then both 0 and Delta lie in [0,2^(-b)) and quantize to zero. Every transcript is then exactly independent of U, even with unlimited point queries. With a general quantizer, an exact collision is possible whenever the two values fall in the same bin. This is an alignment-sensitive statement, not a universal lower bound for every quantizer grid.

If Gaussian noise is added before quantization, the exact collision argument no longer applies: shifted noise distributions may remain distinguishable below one output bin. The analog Gaussian KL bound still applies to quantized observations because quantization is post-processing. To guarantee that any two length-m noiseless output vectors with Euclidean separation at least gamma cannot round to the same uniform-grid vector for every grid offset, it is sufficient to make the per-coordinate bin width less than gamma/sqrt(m). For a contrast Delta_c attenuated to Delta_c/kappa this sufficient precision is b > log2(kappa*sqrt(m)/Delta_c). If the smallest rational contrast can be 2^(-2H), the corresponding uniform guarantee requires about 2H+log2(kappa)+0.5log2(m) bits after the binary point. This is a worst-case no-alias precision requirement; noise-driven statistical estimation is governed separately by the KL bounds above.

Concrete interface counterexample to an overbroad lower bound

A claim that every learner needs Omega(N) oracle calls is false if the oracle accepts dense linear functionals of the whole coefficient table. Let theta_U=Delta*e_U in R^N. Choose m public sign vectors a_t in {+1,-1}^N whose N code columns have pairwise Hamming distance at least m/4; random signs provide such a code for m=C log(N/delta). Query

    Y_t = <a_t, theta_U> + Z_t = Delta*a_t[U] + Z_t.

Maximum likelihood over the public code has pairwise error at most exp(-m Delta^2/(8 sigma^2)); taking m >= 8 sigma^2 Delta^(-2) ln((N-1)/delta), plus C ln N for code existence, suffices. This is O((1+sigma^2 Delta^(-2)) log(N/delta)) scalar calls, rather than N point calls. The interface and its bill changed: each dense query has squared excitation ||a_t||_2^2=N, total excitation is N*m, and explicitly materializing/evaluating the query touches N entries each time (O(Nm) entry work). If each query must have norm at most one, scale a_t by 1/sqrt(N); the same construction then needs O(N(1+sigma^2 Delta^(-2)) log(N/delta)) calls. Thus call count alone does not measure acquisition, and the point-query lower bound does not transfer to dense linear sensing. A one-call full-vector response has the same caveat: it returns N outputs and costs N entries.

This is relevant prior art for the adaptive interface boundary, not a theorem imported into the present derivation: https://arxiv.org/abs/1206.0648

Status and limits

The automaton construction, KL calculation, Fano step, pairwise test step, quantizer collision, and codebook counterexample are written derivations. The result is a standard finite-hypothesis lower-bound specialization to a compact rational predictive-process family; no novelty, priority, broad autonomous learning, or full-matrix-oracle claim is made. The fixed-schedule theorem does not cover adaptive point selection based on Y. Exact matrix-output and adaptive dense-query interfaces require their own charged resource ledger. Primary-source browsing establishes that sparse-support and adaptive-sensing lower bounds are established neighboring literature; it does not establish novelty clearance or external validation of this note.

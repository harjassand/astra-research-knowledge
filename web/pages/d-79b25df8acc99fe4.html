# Cycle2: finite energy and noise comparator

Exact interface: F(a) is finite discretized ND map of nonradial scalar EIT on known partition. Pick currents f_l and detector matrix D; observe y_l=DF(a)f_l+η_l, independent η_l~N(0,s²I). Budget must charge total input energy Σ||f_l||²≤E, total scalar readings Lq, boundary bandwidth, electrode restrictions, and computation. One excitation by itself is not lower total observation cost.

## Independent global comparator derivation
Let normalized secant T_ab=(F(a)−F(b))/||a−b||. For fixed detectors, set A_T=T*D*DT≥0. Stack L experiments. Then
 Σ_l||DT f_l||²=tr(A_T Q),  Q=Σ_l f_l f_l*≥0, trQ≤E.
For equal Gaussian detector noise, KL(P_a||P_b)=||a−b||² tr(A_T Q)/(2s²). Thus the global worst-pair energy-normalized design is
 max_{Q≥0,trQ≤E} min_{T∈T_K}tr(A_T Q).
Finite secant discretization is an SDP with scalar linear inequalities. Continuous version is semi-infinite SDP; discretizing without a verified net gives only fixture performance. At one parameter, minimizing over tangent v yields E-optimal Fisher information; A/D optimality optimize different summaries and priors. Global secants protect distant pairs that a local Fisher design can miss.

Every PSD Q has a spectral decomposition Q=Σ λ_j u_j u_j*. The deterministic multi-current design f_j=√λ_j u_j exactly realizes it. With fixed detector/noise interface this obtains the covariance objective with no random concentration loss. One deterministic current imposes rankQ=1. One normalized random current drawn from Q only matches the covariance in expectation, not worst-pair performance per draw. Energy normalization alters its covariance; Gaussian trace energy is expected energy, not a hard fixed-energy budget.

Consequently a sufficiently flexible optimized multi-current comparator weakly dominates the feasible one-current class at this objective. No universal scientific advantage for one current can be claimed without an explicit cost for excitation setup, temporal frame cost, hardware limits, or different detector allocation. If total readings B=Lq is fixed, multi-current must reduce q or choose per-current detector subsets; Q alone no longer captures the budget because D_l may vary. General budget representation is a sum of current-detector rank-one channels, and Gaussian noise whitening must be applied before comparing them.

For an estimator with global residual within the true residual, secant conditioning κ implies parameter error≤2||stacked η||/κ. This is a basic bound, not minimax optimality; a competent comparator should also report KL testing lower bounds and estimation risk, not only min singular value.

## What could remain structurally new
PDE-specific effective certificate that a finite set of nonradial normalized secants/tangents controls the entire admissible conductivity parameter compactum; an explicit geometry/contrast/noise-dependent lower bound; certified rank1 current rounding under hard energy and detector constraints compared with optimal feasible multicurrent; an exact overhead-dependent tradeoff theorem. Generic SDP design, Fisher information, optimized current selection, or random patterns do not qualify.

Next falsifiable step: specify E,B,s,input bandwidth and setup overhead; compute a finite secant SDP upper bound, optimize rank1 with multiple initializations, and certify the covering error from operator derivative bounds. A provable positive rank1 value establishes identifiability for that fixture; finite samples do not establish continuum EIT advantage. Report global rank1 gap and estimation/testing error against the same-budget SDP-realizable multi-current design.

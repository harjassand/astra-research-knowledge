INITIAL CHECKPOINT — c01_l08
7 October 2026; acquisition, precision, and total-cost audit

STRONGEST CLAIM

For a proposed finite-support microscopic Metropolis kernel on full-basis
line configurations, every pointwise acceptance ratio is exactly computable
from rational-complex input in polynomial bit length, without a partition
function or hole coefficient. A T-step implementation with fixed worst-case
random-bit use can approximate the ideal rational-acceptance trajectory to
total variation at most T*2^(-k), using k-bit downward-rounded coins. The
coordinate-dominated refresh also has a fixed polynomial-bit description:
its deliberately tiny activity is 2^(-K), where K is polynomial in the
instance bit length and dimension. A uniformly sampled coordinate matching
can be generated to explicit TV error in fixed worst-case bit cost.

This closes an arithmetic/acquisition accounting gate conditional on a
specified proposal kernel and a polynomial step bound. It does not construct
the required microscopic two-replica energy inequality or prove mixing. In
fact, exact bounded-time Bernoulli sampling for arbitrary non-dyadic rational
acceptance is impossible from fair bits, and some natural determinant
reassignments have acceptance 2^(-4L) for L-bit inputs. So polynomial bit
length does not imply polynomial mixing or worst-case exact random-bit cost.

MICROSCOPIC INTERFACE AND ACCEPTANCE DERIVATION

Let r be even and let the finite line system have M paired-vector lines
v_l=(v_l^(1),v_l^(2)) in Q(i)^r, with positive rational activities theta_l.
A valid microscopic state A is a set of r/2 lines for which the concatenated
r-by-r matrix W_A has nonzero determinant. Its unnormalized weight is

  w_theta(A) = (product_{l in A} theta_l) |det W_A|^2.

For rational-complex entries, |det W_A|^2 is rational: if det W_A=a+ib with
a,b in Q, then it is a^2+b^2. Zero determinants are recognized exactly by
rank/determinant computation, and the deterministic support reduction in
the previous audit can certify global zero/support separately. A partition
Z_theta=sum_A w_theta(A) is not used below.

Let q(A,B)>0 be the rational proposal probability for a proposed legal state
B. Metropolis-Hastings uses

  alpha(A,B)=min(1, w_theta(B) q(B,A) / (w_theta(A) q(A,B))).

The common normalizer Z_theta cancels exactly. If q is symmetric, only the
point-weight ratio remains. A proposal requiring a conditional distribution
over all completions would introduce an unknown completion sum; it is not
covered by this cancellation and is precisely a forbidden hidden partition
oracle. Proposals from an explicit polynomial-size list can instead be
enumerated and assigned rational probabilities, including their reverse
proposal-count ratio.

BIT BOUND. Let ell be the full binary encoding length of the rational-complex
matrix and activities. A common denominator for all matrix entries has
O(ell) bits. After clearing it, every Gaussian-integer entry has O(ell) bits.
Hadamard bounds each r-by-r minor numerator by 2^(O(r(ell+log r))); the
cleared denominator to power r has O(r*ell) bits. Thus each determinant norm,
each product of at most r/2 rational activities, and each nonzero point
weight have polynomial bit length. A ratio of two nonzero point weights and
polynomial-size rational proposal probabilities also has polynomial bit
length. Fraction-free elimination or exact rational Gaussian elimination
takes polynomial bit time on these bounded-size minors. The ratio may be
numerically tiny; no floating-point precision proportional to its reciprocal
is needed to compare exact integers.

BOUNDED-TIME ACCEPTANCE. Write alpha=a/b in reduced integers, 0<=a<=b.
For k fair bits draw U uniformly from {0,...,2^k-1}, compute
T_k=floor(2^k a/b), and accept iff U<T_k. The implemented acceptance is
T_k/2^k, so

  0 <= alpha - T_k/2^k < 2^(-k).

This takes exactly k random bits and polynomial bit arithmetic in the input
ratio plus k. Coupling each such decision to the ideal acceptance coin gives
disagreement below 2^(-k). For a T-step run, a union/coupling bound gives
trajectory TV error at most T*2^(-k); choosing
k=ceil(log2(T/eta)) makes this at most eta. Include proposal-selection bias
in the same budget. The exact ideal MH chain retains detailed balance with
pi_theta(A)=w_theta(A)/Z_theta; the bounded implementation need only be
coupled to its finite trajectory. A TV/mixing theorem for the ideal chain
therefore transfers to a T-step output with the extra T*2^(-k) additive
error.

There is a strict worst-case caveat: any event decided after at most K fair
bits has dyadic probability. Therefore an exact Bernoulli(a/b) coin with
non-dyadic a/b cannot have a finite worst-case bound on fair-bit use.
Rejection-based randbelow(b) gives an exact coin with constant expected
trials but an unbounded tail. One must either state expected runtime or use
the explicit bounded-precision coupling above and charge its output error.
The latter approximates a finite trajectory; it does not make the rounded
kernel exactly stationary.

COORDINATE-DOMINATED REFRESH WITH CHARGED BITS

Use all M0=binom(r,2) coordinate lines (e_i,e_j), each with activity 1, and
N original lines, each with activity epsilon<=1. Let M=M0+N. The
coordinate-only configurations are perfect matchings on r coordinates;
each determinant has magnitude 1, so their exact partition is
Z0=(r-1)!! and their conditional law is uniform. Let R>=1 be a rational or
integer upper bound on the absolute value of every vector coordinate. In a
full-basis W_A, each column has Euclidean norm at most sqrt(r)R. Hadamard
therefore gives |det W_A|^2<=r^r R^(2r). Every configuration containing an
original line has activity product at most epsilon, and there are at most
2^M line subsets. Its total weight C obeys

  C <= epsilon * 2^M * r^r * R^(2r).

The target base law is a mixture of the uniform coordinate matching law and
the contaminant law on configurations containing original lines. Its TV
distance from the uniform coordinate matching law is the contaminant mass,
at most C/Z0 <= epsilon*2^M*r^r*R^(2r). Thus the sufficient choice

  epsilon=2^(-K),
  K=ceil(log2(2^M*r^r*R^(2r)/eta)),

makes refresh error at most eta. If M=O(r^2+N) and input bit length is ell,
we can choose R=2^b with b=O(ell), giving

  K=O(M + r log r + r*ell + log(1/eta)).

Although epsilon itself can be exponentially small in the input size,
its binary description and every acceptance ratio involving it use only
polynomially many bits. Any algorithm whose number of operations scales as
1/epsilon would still be exponential; the refresh bound alone does not
exclude such a dependence.

To sample a matching without an unbounded rejection loop, recursively choose
one partner among q=r-1,r-3,...,1 remaining coordinates. For a choice among
q values, use k_q=ceil(log2 q)+h fair bits, reduce modulo q, and continue.
For 2^(k_q) equally likely bit strings, this modulo law has TV at most
q/2^(k_q)<=2^(-h) from uniform. There are r/2 choices, so h=ceil(log2(r/(2 eta)))
keeps the full matching TV at most eta by sequential coupling. The total
random-bit cost is O(r log(r/eta)) and is fixed on every execution. Splitting
the error budget between this approximate matching sampler and the
coordinate-dominance bound gives a total refresh TV budget eta. Exact
uniform partner selection by rejection is expected-polynomial but not
worst-case bounded.

For nonuniform final original activities lambda_l, let Lambda=max_l lambda_l,
set their base activities to epsilon*lambda_l, and choose
epsilon<=eta/(Lambda*2^M*r^r*R^(2r)). If epsilon*Lambda<=1, the preceding
contaminant proof is unchanged after the single extra Lambda factor. Since
log Lambda is bounded by the binary input length, this adds only polynomial
bits. For a simple activity ramp theta_l(t)=t*lambda_l on original lines,
with coordinate activities fixed, a state using s original lines changes
weight by (t'/t)^s between adjacent stages. Since 0<=s<=r/2,
Z(t')/Z(t) lies between the minimum and maximum pointwise factors; the
unknown partition ratio cancels from the density ratio and
  (t/t')^(r/2) <= d pi_(t')/d pi_t <= (t'/t)^(r/2).
Taking t'/t<=1+O(1/r) yields a constant adjacent-law ratio in O(r log(1/epsilon))
stages. The partition ratio need not be queried. This observation is only
for the stated uniform scaling path; a target path that changes coordinate
activities needs its own pointwise ratio bound.

EXPONENTIALLY SMALL ACCEPTANCE COUNTEREXAMPLE

The inherited four-site rational matrix is

  F=[[0,delta,1,0],[delta,0,0,1],[1,0,0,1],[0,1,1,0]], delta=2^(-L),

with all line activities 1. For row/column sets I={1,2}, J={3,4},
det F[I,J]=1; its complementary determinant F[{3,4},{1,2}] is also 1.
For I'={1,3}, J'={2,4}, det F[I',J']=delta; the complementary determinant
F[{2,4},{1,3}] is delta. The two-replica squared-weight ratio is exactly

  (delta*delta)^2 / (1*1)^2 = delta^4 = 2^(-4L).

For a symmetric proposal that moves between these pairings, MH acceptance is
2^(-4L); its expected waiting time for this move is 2^(4L). The exact ratio
still has only O(L) bits and the bounded-precision coin needs O(L+log T)
bits. This is not a mixing lower bound for every proposal/kernel. It does
disprove any argument that infers a polynomial lower bound on microscopic
acceptance from bounded line activities, bounded-size moves, or polynomial
input precision alone.

STATUS AND NEXT DECISIVE GATE

The acceptance, fixed-precision coupling, and coordinate-base refresh costs
are derived with polynomial bit bounds and no hidden normalization oracle.
Two genuine barriers remain: (1) obtain a polynomial two-replica energy /
mixing inequality for a specific reversible local kernel uniformly along the
annealing path; and (2) ensure the implemented bounded-precision trajectory
is allowed by that theorem's error model. The delta^4 example means this
kernel must not rely on a transition whose only route has such an
exponentially small acceptance. An energy proof must give an alternative
route or charge that bottleneck explicitly. No general FPRAS, sampler, or
field-breaking result is claimed.

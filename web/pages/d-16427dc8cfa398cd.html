CYCLE10 SCREENED-ANCHOR TRANSPORT TRACE ADDENDUM
2026-10-09

Status: conditional P1 trace and test-commutator lemma. This addresses the
screened-fill distinction that original boundary pins swallowed by initial
holes need not be zero for the filled field. It assumes an explicit map from
the original hitting measure to retained zero P1 vertices at distance at
most R_h. It does NOT prove that the screened geometry supplies such a map.
The addendum is separate from and does not change the frozen direct-zero-atom
packet.

1. EXACT CONDITIONAL INTERFACE

Let h_n downarrow 0, let u_n be continuous P1 functions on shape-regular,
quasiuniform planar meshes in a fixed neighborhood of a compact set X, and
fix 1<p<2. Assume

    sup_n ||u_n||_{W^{1,p}} <= E_p.

For each n let nu_n be a positive finite measure supported on the original
pin/hit set K_n in X and satisfying, for fixed A,r_0,alpha>0,

    nu_n(B(x,r)) <= A (r+h_n)^alpha,
       x in R^2, 0<=r<=r_0,       sup_n nu_n(X) <= M.       (1)

Assume there is a Borel map tau_n:K_n -> Z_n, where Z_n consists only of
retained mesh vertices at which u_n(z)=0, and

    |tau_n(x)-x| <= R_n,
    h_n <= R_n -> 0.                                      (2)

All points and connecting balls are required to lie in the common mesh
neighborhood where u_n and its P1 extension are defined with the stated
energy bound. Write bar-nu_n=(tau_n)#nu_n and pi_n=(id,tau_n)#nu_n. Multiple
original atoms or points may map to one retained pin. No atom-scale
(r+h_n)^alpha bound is assumed for bar-nu_n; its available bound is only

    bar-nu_n(B(x,r)) <= A (r+R_n+h_n)^alpha.               (3)

The uniform finite mass M is not assumed to be one. If nu_n are supported
in a fixed compact set, it follows from (1) and a fixed-radius finite cover;
we retain it explicitly for all integral/commutator statements.

2. PUSHED-MEASURE TRACE ESTIMATE

Take p satisfying p+alpha>2 and set theta=(p+alpha-2)/p>0. Let M_s be
convolution with a fixed smooth unit-mass mollifier at scale s. For
h_n<=R_n<=s<=r_0/c, the zero values on Z_n and (3) imply

 ||u_n-M_s u_n||_{L^p(bar-nu_n)}
   <= C A^(1/p) [h_n^((p-2)/p) R_n^(alpha/p) + s^theta] E_p. (4)

In particular, because u_n=0 bar-nu_n-a.e.,

 ||M_s u_n||_{L^p(bar-nu_n)}
   <= C A^(1/p) [h_n^(p-2) R_n^alpha]^(1/p) E_p
      + C A^(1/p) s^theta E_p.                            (5)

Proof, including the non-Frostman atom scale. At any mesh vertex z, the
shape-regular P1 inverse estimate and local Poincare give

 |u_n(z)-M_{h_n}u_n(z)|^p
   <= C h_n^(p-2) integral_{B(z,C h_n)} |grad u_n|^p.

After integration against bar-nu_n, centers z whose ball contains y have
total mass at most bar-nu_n(B(y,C'h_n)) <= C A R_n^alpha, by (3) and
h_n<=R_n. Hence the base cost is

 ||u_n-M_{h_n}u_n||_{L^p(bar-nu_n)}^p
   <= C A h_n^(p-2) R_n^alpha E_p^p.                      (6)

At a dyadic scale h_n<=t<=R_n, local Poincare and (3) yield

 ||M_tu_n-M_{2t}u_n||_{L^p(bar-nu_n)}
   <= C A^(1/p) R_n^(alpha/p) t^((p-2)/p) E_p.            (7)

Since p<2, the exponent (p-2)/p is negative, so the dyadic sum from h_n
through R_n is dominated by its smallest scale. Its total is bounded by
C A^(1/p) R_n^(alpha/p) h_n^((p-2)/p) E_p, exactly the root of (6).
At t>=R_n, (3) improves to bar-nu_n(B(y,Ct))<=C A t^alpha. The outer
dyadic increments are therefore at most C A^(1/p)t^theta E_p, and sum to
C A^(1/p)s^theta E_p because theta>0. Together these prove (4)-(5).

The crucial scale distinction is explicit: the pushed measure's atom-scale
mass can be order R_n^alpha, not h_n^alpha. It is not valid to reuse the
prior direct-zero-atom bound h_n^(p+alpha-2) for bar-nu_n. The correct base
cost is h_n^(p-2)R_n^alpha.

3. WEAK-LIMIT ZERO TRACE

Assume, after a subsequence, nu_n converges weakly to nu and u_n converges
weakly in W1p and strongly in Lp on the common localization to u. The
coupling displacement and mass bound imply bar-nu_n has the same weak limit
nu: for every continuous phi,

 |integral phi dbar-nu_n - integral phi dnu_n|
   <= M sup_{|x-y|<=R_n}|phi(x)-phi(y)| -> 0.               (8)

The weak limit nu has the usual alpha-growth bound nu(B(x,r))<=C A r^alpha,
obtained by continuous cutoffs and then shrinking their support. In
particular the mollifier trace T_nu u exists in Lp(nu) when p+alpha>2.

Assume the additional mesh-rate condition

    h_n^(p-2) R_n^alpha -> 0.                              (9)

For fixed s>0, (5), strong Lp convergence (hence uniform convergence of
fixed-scale mollifications), and bar-nu_n=>nu imply

 ||M_su||_{L^p(nu)} <= C A^(1/p) s^theta sup_n E_p.         (10)

Here (9) removes the atom-scale term before the limit is taken. Sending
s down to zero in (10), using the continuous-measure dyadic trace estimate,
gives

    T_nu u = 0  nu-a.e.                                    (11)

Thus the limit trace conclusion remains valid even though the pushed
measures lack mesh-scale h_n-growth. Finite mass only enters through the
weak transport comparison; no probability normalization is used. As in the
prior packet, (11) is a trace on supp(nu), not a claim on all of a Hausdorff
limit K unless supp(nu)=K is separately proved.

4. ORIGINAL-TO-RETAINED TEST COMMUTATOR

The same hypotheses give a quantitative bound on the original field values,
not just the pushed trace. For pi_n=(id,tau_n)#nu_n,

 ||u_n(x)-u_n(tau_n(x))||_{L^p(pi_n)}
    <= C A^(1/p) E_p [R_n^theta
                       + (h_n^(p-2)R_n^alpha)^(1/p)].       (12)

To prove (12), compare each value to M_{R_n}u_n. On the original marginal,
the standard dyadic argument using (1) costs C A^(1/p)R_n^theta E_p. On
the pushed marginal, use (6)-(7) up to scale R_n; because p<2 the total
cost is C A^(1/p)(h_n^(p-2)R_n^alpha)^(1/p)E_p. For the middle term,
|x-tau_n(x)|<=R_n and local Poincare give

 |M_{R_n}u_n(x)-M_{R_n}u_n(tau_n(x))|^p
    <= C R_n^(p-2) integral_{B(x,C R_n)} |grad u_n|^p.

Integrating uses the original marginal's mass bound
nu_n(B(y,C R_n))<=C A R_n^alpha, yielding the first R_n^theta cost.
This proves (12).

Since u_n(tau_n(x))=0, for every bounded test phi,

 |integral phi(x)u_n(x) dnu_n(x)|
   <= ||phi||_infinity M^(1-1/p) C A^(1/p) E_p
      [R_n^theta+(h_n^(p-2)R_n^alpha)^(1/p)].              (13)

The measure-only test commutator is

 |integral phi dnu_n - integral phi dbar-nu_n|
    <= M Lip(phi) R_n                                    (14)

for Lipschitz phi. Thus smooth test pairings pass through the transport.
If (9) holds and R_n->0, both (13) and (14) vanish. This makes precise the
commutator needed when original pins are swallowed but a nearby retained
zero vertex is available.

5. RATE REGIMES

The exact analytic requirement is (9), together with R_n>=h_n, R_n->0,
and p+alpha>2 for the outer dyadic and original-marginal terms.

If R_n=h_n(log(1/h_n))^C for a fixed C>=0, then

    h_n^(p-2)R_n^alpha
       = h_n^(p+alpha-2)(log(1/h_n))^(C alpha) -> 0

exactly when p+alpha>2. The logarithmic loss is absorbed by any strict
power margin.

If R_n=(h_n log(1/h_n))^(1/2), then

    h_n^(p-2)R_n^alpha
       = h_n^(p-2+alpha/2)(log(1/h_n))^(alpha/2) -> 0

exactly when p>2-alpha/2. Equality fails for this positive logarithmic
factor. This condition already implies p+alpha>2. Given uniform W1p bounds
for every fixed p<2, such a p exists for every fixed alpha>0 (also requiring
p>1); for small alpha it lies close to 2. A p chosen depending on n is not
allowed: choose one fixed p first, then take n to infinity.

For a general R_n=h_n^gamma L_n with 0<gamma<1 and positive slowly varying
L_n, the exact test is h_n^(p-2+gamma alpha)L_n^alpha ->0. At the critical
power p=2-gamma alpha, convergence depends on L_n and must not be inferred
from the power alone.

6. SCREENED-FILL SCOPE AND NONCLAIMS

This addendum applies if every point in the original measure support can be
mapped to a retained zero vertex within R_n, the transport remains in the
buffer where the physical P1 fill is defined, the hit measures satisfy
(1), and the chosen fixed p has the required uniform energy bound. It does
not establish any of these geometric, probabilistic, or energetic facts
from the screened fill itself. In particular it does not infer a nearby
retained pin merely from the original pin being swallowed by an initial
hole; the screened proof explicitly distinguishes swallowed pins from
retained controlled pins.

If no such bounded-displacement map exists, or if the pushed pin measure
does not obey the bound inherited in (3), this argument gives no trace
conclusion. If the fill is not zero at the selected retained vertices,
(5), (11), and (13) do not follow. If (9) fails, the atom-scale cost may
stay bounded away from zero or diverge even though the push distance tends
to zero. No full Brownian boundary identification or Poisson representation
is concluded; those remain separate moving-domain/harmonic-measure gates.

# A raw non-Clifford gate resource, rather than an assumed encoded magic factory
30 October 2026. Root conditional construction to test against actual code families. Not a new accepted capability. The missing code interface is substantive.

## Required code, not granted by the word LDPC
The SAME code family must supply both (i) the actual local autonomous-memory correction/confinement/decoder contract, with fixed check and correction footprints and an admissible growing correctable radius, and (ii) an explicit bounded-depth bounded-spread physical circuit U with code-preserving non-Clifford logical action U_L. A concrete candidate is a transversal product of physical CCZ gates on columns of three code blocks. Constant rate/distance alone, or an efficient global decoder, does not imply (i). A gate on a different dense-check code does not satisfy this interface.

## Source and storage
Start with three copies of the actual raw physical Bell resource used by the reviewed AB buffer. Apply U to the B factors at the physical source. For a transversal CCZ, this source uses three raw Bell pairs and one three-qubit CCZ per column; no encoded |+> or encoded CCZ Choi state is supplied for free.

Conjugate the whole AB nominal apparatus by I_A tensor U_B. For fixed-depth bounded-spread U, every actual interaction/complete reset footprint grows only by a fixed factor; for a columnwise product, group the three corresponding B sites as one larger finite site. This is paid hardware, not a claim of elementary-qubit locality. Noise transforms within a correspondingly enlarged fixed-body incident-norm class. The raw source is exactly the conjugate of the admitted old source, so the fixed Bell-target/gauge module becomes its U-twisted version. Clean apparatus, resets/control, independent source-quality and normal-propagator requirements remain.

Existing lifetime and positive-source comparison transfer by exact unitary conjugation. This is a new application of the earlier theorem, not a new proof of general autonomous non-Clifford computation. Its historical novelty is unverified.

## Actual finite gate consumption
For full physical Bell-measurement outcome m, ordinary teleportation produces P_m rho P_m† at Bob. A U-twisted resource instead produces U P_m rho P_m† U†. The actual correction is

 C_m = U P_m† U†,

giving U rho U†. For U a product of columnwise CCZ gates, each C_m is a fixed-size column operation (Paulis and CZs, with irrelevant global phase). The physical correction can be compiled as an actual finite circuit with measured bits and real local couplers. The classical bits are not magically reliable; use the existing finite endpoint's paid bit paths, pointer/noise budget and support expansion, with new constants for this circuit.

All retained source, syndrome/gauge, clock and bath coefficients must pass through the SAME generalized Bell identity. Conjugation is linear and applies coefficientwise; no independence of error histories is introduced. However the actual endpoint whole proof must be rechecked before acceptance, especially physical drain, new-controller initialization and finite expansion rates. The earlier recipient receipt is not automatically a gate-consumption receipt.

## Fixed decoder cannot supply the gate
For the common zero-code encoder Enc,

 U Enc = Enc U_L.

For any retained input Pauli coefficient E, U E Enc=(U E U†) Enc U_L. A bounded-spread U maps a weight-w physical error to an arbitrary operator supported on at most c_U w physical sites. Expand that operator into the common correctable Pauli span and pay the factor c_U, both CSS sector weights, native prefix footprints and endpoint insertions. The SAME ordinary DATA decoder then returns U_L rho U_L†. It is independent of m and does not insert U_L itself. New B ordinary memory can preserve this output because it is still in its code, provided the actual endpoint earns the usual warm radius/energy bounds.

## Scientific decision
If a real existing code meets both interfaces, this could turn the reviewed raw resource buffer plus finite port into an actual non-Clifford operation, without solving full asynchronous command control first. If no such code is available, merely writing both premises is not progress toward a device. Candidate code sources are being checked directly, including their local correction geometry, not accepted on headline rate/distance claims. Preset finite Clifford-frame extensions are not an adequate substitute for this missing interface.

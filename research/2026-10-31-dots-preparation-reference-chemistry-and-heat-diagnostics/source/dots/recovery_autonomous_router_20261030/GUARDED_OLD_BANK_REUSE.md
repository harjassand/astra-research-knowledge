# A stronger simple alternative when the consumer can obey a physical DONE guard
30 October 2026. Root exact algebra, independent review pending. This is a changed consumer interface, not removal of the bounded-rate theorem's assumptions.

The reviewed bounded-rate old-bank theorem permits UNGUARDED old-Q operations by paying a faster router. If the old-bank consumer can instead be redesigned to obey the actual receiving-bank routing phase, an exact auxiliary action is available and the speed hierarchy is unnecessary for protection of the original input.

For an intended old-Q Hamiltonian H_S on a fixed set S of columns, use the actual physical guarded Hamiltonian

 H_guard = (product_(i in S) P_1,i) H_S.

For an actual old-Q jump A_S, use J_guard=(product P_1,i) A_S, with its complete loss. These are physical joint controls on the TRUE routing phase, not a cached classical ACK or an externally inferred completion time. S has fixed bounded size; a cross-column all-DONE guard has that actual enlarged support and must be physically built, not treated as a free broadcast.

The fixed G frame maps each guarded operation to the corresponding operation solely on canonical spare, with the same routing guard. Every original-memory witness, cut and logical factor therefore commutes with it or is annihilated by its full adjoint. The router witness V_r is identity on the guarded all-DONE sector and has no DONE/active off-diagonal entries, so its adjoint is also annihilated exactly. Thus arbitrary rates of these declared guarded operations do not change either nominal Lyapunov argument, provided the total propagators exist. Residual deviations from the actual guard remain in the original weak local noise budget; unbounded control errors are not allowed.

This remains true on arbitrary physical states, including false-DONE states produced by earlier faults. In such a state, the physical interpretation of the protected canonical factor is already B, and a guarded old-Q operation acts only on its ancillary factor. The earlier clock fault may have caused a correctable error; the guarded consumer does not add uncontrolled propagation. No classical claim that DONE was historically truthful is used for this SAFETY statement.

For a fixed bank-wide reset, apply the one-column version in parallel. Each completed column can be reset or used without waiting for all routers to settle. This can recycle old-Q physical cells while preserving the original logical input in the paired code. It does not certify that a new multi-column algorithm on old Q has executed correctly: unavailable columns can stall or omit consumer operations, and a noisy guard can affect their semantics. Fresh-input encoding, computational causal order and receiver detachment remain separate problems.

The comparison is important. Prefer this exact interface when guardable source operations suffice; retain the faster-router theorem for genuinely ungated bounded source operations. Neither mechanism alone supplies reliable autonomous commands. The algebra is an application of the established covariant subsystem mechanism, not a historical novelty claim.

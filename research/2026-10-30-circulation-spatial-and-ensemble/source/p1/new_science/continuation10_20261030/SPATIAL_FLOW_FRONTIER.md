# Unfinished next attack: spatial circulation fields without changing density histories

30 October 2026. A concrete possible continuation, not an accepted theorem.
It serves the broader consequence of programming an emergent spatial flow
law; increasing a finite ring fixture is not the target.

The completed theorem changes finitely many circulation histories. In a
two-dimensional periodic exclusion material, total horizontal displacement
within each row is also a pointwise martingale at zero force when horizontal
exchange has one homogeneous reciprocal prefactor on that row. Vertical
exchanges change occupancies but do not enter that count, and horizontal
instantaneous drift still telescopes within the row. A weak horizontal field
adds bounded drift per row. Thus the actual native source interface can be
supplied without reconstructing the full two-dimensional generator.

An isolated auxiliary horizontal lane on every row, with R_N carriers per
row and 1<<R_N<<N, has total added mass N R_N/N^2=R_N/N->0. The same conservation
argument preserves the full two-dimensional density history at the
macroscopic scale. Real row winding can supply a horizontal current profile
depending on the vertical coordinate: a divergence-free shear field. This
is a concrete physical route beyond finitely many harmonic coordinates,
using local row controllers rather than a dense instantaneous transformer.

One cannot simply apply the completed proof N times and claim a full
two-dimensional path LDP. The native volume speed is N^2. The one-row queue
tail has exponent of order K_N N, and K_N=R_N a_N=o(N). A union of those
individual estimates is insufficient at speed N^2.

The useful missing connection is a joint spatial error estimate. A fixed
weak-field error requires a sum of row errors of order N^3, not one row error
of order N^2. Native jumps affect one row count at a time, giving a diagonal
conditional bracket bound of order N per row even though row states are
coupled by vertical motion. A candidate proof can exploit simultaneous
exponential martingales over selected signed row excursions. The expected
large-error exponent would be of order K_N N^2; choosing row entrance times
costs only exp(O(N log N)). Delayed-window errors likewise need a joint bound,
not a union of insufficient one-row events. This is an outline only; the
stopping-time selection and actual spatial weak topology must be proved.

Sensing and physical resources grow with the number of controlled lanes.
The native event stream is O(N^4) on the diffusive horizon. Separate tracks,
shared-lane readout, control power and logical reliability must be compared at
that volume scale. A rare-arming rule can preserve ordinary laws only under
its actual joint trigger and initial-law contract. The existing single-lane
noise bounds and a renamed spatial current are not a supplier for these costs.

A successful construction would program a nontrivial spatial circulating
flow while retaining all interacting density histories. Failure of the joint
estimate or an ordinary passive/active architecture achieving the same task
at lower actual resources should redirect this attack. No completed spatial
law, practical improvement or device is claimed here.

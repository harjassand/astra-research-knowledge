2026-10-30. Governing candidate. The earlier accepted one-shot gate and memory sources remain unchanged. This is a scheduled, finite-resource frame-tracking construction, not an autonomous instruction distributor or universal computer.

## 0. Useful conclusion and its limit
A single PERMANENT onsite gauge can protect the same continuously running native controllers while a finite local program register is repeatedly driven toward different absolute transversal frames. Native controllers need not become idle, be reset, or have their forest frame physically inverted between commands. Neither local dimension nor interaction support grows with command depth. After a fixed settling time, one ordinary product DATA decoder reads the actual cumulative logical frame, up to an exponentially small channel error depending on total elapsed physical time, not a sum of separate per-command restart errors.

The scope is a FIXED number b of colocated identical CSS blocks and a fixed finite group Gamma of onsite gates whose uniform transversal actions preserve their product code. For an explicit noncommuting example, b=2 and Gamma=GL(2,F_2), the six two-bit permutation matrices generated by forward and reverse CNOT. These are exact unitary representatives, with no projective-phase convention. This does NOT supply arbitrary partner changes across an unbounded number of blocks. Uniform finite-group instruction streams are classically compressible to a final group element; this construction does not give a computational speedup over an equally informed scheduled route.

## 2. A finite register which can retire every stale intermediate
Let m=|Gamma|. At each column introduce m^2 orthonormal labels

    r_g (g in Gamma),
    e_(a,b) (a,b in Gamma, a!=b).

Here the symbol b in e_(a,b) is a group label, not the block count. Define the label-to-frame map w(r_g)=g and w(e_(a,b))=b, and the PERMANENT onsite unitary

    G_i=sum_q u_(w(q)),i tensor |q><q|,

For a commanded ABSOLUTE target v in Gamma, the program-frame Hamiltonian and always-on resets are

    H_v=Omega sum_(g!=v) (|e_(g,v)><r_g|+|r_g><e_(g,v)|),
    J_(a,b)=sqrt(kappa)|r_b><e_(a,b)|,  a!=b.

Omega,kappa>0 are fixed. The Hamiltonian is a direct sum of disjoint 2x2 edges, not a star with dark ready superpositions. ALL intermediate resets remain on under every command. In particular an old e_(a,b), b!=v, first decays to r_b, then follows the current b->v pair. No new labels recursively indexed by old intermediate labels are needed.

    L_phys,nom(t)=Ad_G [L_mem + sum_i L_prog,i(t)] Ad_Gdagger.

## 8. What support growth is avoided, and what is not
For fixed b and Gamma, G is permanently onsite. Native two-site support, local dimension m^2, forest cones, and Pauli spread constants are independent of K. That is the exact bounded-depth handoff mechanism, not a reset-and-recompile argument.

For an unbounded set of blocks with changing CNOT partners, this does not suffice. A nearest-neighbor CNOT chain can conjugate one X into X on K+1 successive blocks. A memory term sensitive to that operator then acquires growing support if one simply tracks the cumulative frame by conjugation. Grouping all such blocks into one column loses fixed dimension/constant overhead; storing an unbounded clock/history loses the finite-register requirement. This is a precise obstruction to the naive cumulative-conjugation compiler, NOT a no-go theorem against all fault-tolerant moving-frame handoffs. Such a wider scheme would need an actual local consolidation, measurement/feedback, code deformation, resource injection or another proved interface.

## 9. Equally informed scheduled comparator and scope
An equally informed classical controller can multiply a uniform finite-group instruction stream to its final v before any DATA operation. If only a final output is required, it can protect the DATA in ordinary storage and perform ONE scheduled implementation of U_v at the end (or adapt compatible measurement bases). Therefore absence of K separate gate-error terms is not a computational advantage: the nominal computation itself is compressible. If actual intermediate physical targets are demanded, both schemes must update them, and both need reliable finite-rate control and the same local calibration/noise accounting. The present construction supplies asynchronous physical frame convergence with no native-controller interruption, not a speedup or a demonstration that an ordinary scheduled implementation cannot match it.

## 1. Concrete commuting false-value projectors

Work in the exact product forest frame. For a DATA-valued classical slot s belonging to read hub h, let O_s be its occupied-DATA projector (ACK/empty contributes zero), let |a><a|_s resolve its finite classical value, and let Pi_h^A(a) be the joint projector for the CURRENT commuting Alice stabilizers in h's declared read. Define

    F_s = sum_a |DATA(a)><DATA(a)|_s tensor [I-Pi_h^A(a)].

For Bob's active immutable P, use the same formula with occupation determined by A/C/B or their computation/acquisition-origin abort phases. Occupation must not be an untrusted optional validity bit that can be zero in a nominally good executing C phase. Q/I have no active program. A cache slot is occupied only in the exact physical WANT(a) state; LOAD consumes it while creating the active P.

These are actual bounded-support orthogonal projectors. All Alice stabilizer projectors commute, all classical slot projectors commute, and the forest-frame mechanical good projectors are DATA-independent. Hence these F_s commute with each other and the mechanical history flags. In physical coordinates conjugate the entire family by the same F; support expands only by a fixed radius and commutation remains exact. No crossparty measurement of F_s is proposed: they are analysis observables, not a coherent communication bus.

## 2. Actual nominal operations and defect transport

- Forest-frame payload Hamiltonians are controller-only. They preserve Alice DATA and all immutable carried values, so they preserve the corresponding comparison tests.
- Clean Alice terminal read has Kraus Pi_a and writes DATA(a). Its newly created value is true on the actual output, even on a coherent syndrome/gauge input.
- FIFO hop, worker enqueue, response dequeue/cache and LOAD are basis-resolved **move-and-consume** operations. A false value may move to a different physical slot, but is not nominally cloned. ACK/empty messages carry no such flag.
- Bob's nominal operations never change Alice DATA. A mechanically clean terminal with F_P=0 is exactly an ordinary current-relative-syndrome GPT move. A mechanically clean false-P rollback is DATA identity.
- A mechanically dirty Alice retirement can change finitely many Alice stabilizers and write a wrong held reply. It can therefore create finitely many lower-tier F_s in neighboring private message/cache/program patches. Bounded degree, finite channel capacities and fixed read weight give an explicit finite fanout bound.
- A Bob dirty retirement acts only on actually owned Bob resources, so it cannot change Alice comparison projectors. Its program/reset can only remove its local carried value. The full-read-lock argument separately prevents a dirty Bob action from invalidating a different clean Bob snapshot.

These are concrete reasons an acyclic mechanical-Alice -> semantic-Bob defect hierarchy is plausible for the operator energy. They are not merely a reinterpretation of hidden stochastic marks.

## 3. Why one cannot just substitute these into the accepted continuous proof

Individual per-slot flags are transported: a nominal hop can clear F_s and create F_t. Thus they do NOT individually satisfy the mechanical no-creation invariant. A sum with equal weights is nonincreasing under move-and-consume, or one may use a single OR projector over every fixed private request/reply/worker/cache/P patch for h. These patches have bounded size in the declared hardware scope, but their overlap and their gain/loss algebra must be recomputed.

A Bob T_h clears its active program/cache and starts a purge; it does NOT immediately erase false DATA in all in-flight FIFO slots. Therefore an OR-of-private-patch semantic flag is NOT regenerated by every Bob T_h. Its actual healing path is full purge/draining, not the old terminal/abort reset. One must build the corresponding killed generator/resolvent or phase-aware CP service credit for that real process. A bound on the lifetime of a hidden analytical semantic mark is not a substitute for this operator statement.

Also, raw continuous noise can create coherences between mechanical/semantic flag sectors. The future theorem must control those cross blocks with the actual spectral envelopes and the concrete CP credit maps. The stochastic root/count MGF proved separately supplies none of that by itself.

# Factorial reference plus bounded perturbations and short return cycles is insufficient

Internally derived exact generic-CTMC counterexample. NOT a finite mass-action network; NOT a counterexample to chemical recurrence. It challenges only a proposed abstract comparison based on these weaker data.

## A local lattice path with large graph distance

Enumerate all x_n=(a_n,b_n) in N^2, n≥0, by alternating square-shell snakes. Start x_0=(0,0). On shell k=max(a,b), if k is odd enumerate

    (k,0),(k,1),...,(k,k),(k−1,k),...,(0,k);

if k is even enumerate the reverse list. Consecutive points are nearest neighbors, including between shells. Shell k has 2k+1 vertices, and indices k^2,...,(k+1)^2−1. In particular max(a_n,b_n)=floor(sqrt n).

Keep only edges between consecutive path vertices, in both directions. Each edge has an immediate two-edge return cycle. Let

    m_n=1/(a_n! b_n!),
    lambda_n=min(1,m_(n+1)/m_n),
    delta_(n+1)=min(1,m_n/m_(n+1)), delta_0=0.

The rates are at most one. Detailed balance holds because

    m_n lambda_n=m_(n+1) delta_(n+1)=min(m_n,m_(n+1)).

The total reference measure is exactly sum_(a,b)1/(a!b!)=e^2. Hence this bounded-rate irreducible reference chain is positive recurrent with normalized product-factorial stationary law. Its return-cycle reference conductances agree exactly.

## Arbitrarily small fixed relative changes can make it transient

Fix ANY R>1. Change only lambda'_n=R lambda_n, keeping delta'_(n+1)=delta_(n+1). Every nonzero directed rate changes by a factor in [1,R]; total jump rates remain at most R+1, so no explosion is possible.

The reversible sigma-finite measure for the new birth-death chain is

    m'_n=R^n m_n.

Since both coordinates are at most sqrt n,

    m_n ≥ 1/(floor(sqrt n)!)^2 = exp[−O(sqrt n log(n+2))].

Thus m'_n grows without bound and is nonsummable. More strongly, the edge conductances are

    c'_n=m'_n lambda'_n=R^(n+1) min(m_n,m_(n+1)).

Therefore sum_n 1/c'_n < infinity: exponential R^n dominates the subexponential reciprocal factorial factor along this enumeration. The standard birth-death hitting calculation, or direct solution of the finite-interval harmonic recurrence c'_n(h_(n+1)−h_n)=constant followed by the limit, gives a positive probability of escaping to infinity without hitting zero. The perturbed chain is transient.

## Exactly what is and is not ruled out

This example simultaneously has a summable product-factorial reference law, bounded nearest-neighbor jumps, bounded total rates, uniformly bounded relative perturbations, and length-two return cycles with equal reference conductance. These data do NOT imply robust recurrence or exp(C|x|) stationary-density comparison.

The mechanism is graph-distance accumulation: n=Theta(|x_n|^2), so a factor R per path step becomes exp[Theta(|x|^2)], beating factorial confinement. The edge support and rates depend on the snake location and are NOT generated by finitely many translated mass-action reactions. Nor are its conductances asserted to have the full chemical residual form constant/(x−y)! with a fixed finite source set. Those extra chemical restrictions could still exclude the construction; exploiting them is precisely the missing theorem, not something provided by generic perturbation theory.

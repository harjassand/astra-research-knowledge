# Hidden-slot streaming integrity: an established purity-testing application

28 October 2026. **Resource comparison and negative novelty finding, not a new authentication theorem or acquired-channel result.** No source calls, hardware result or publication. The received local-algebra sources are unchanged.

## Decision

Secretly placing one payload among random test blocks does not close a new integrity gap in Astra: `learned_recovery_fresh_key_authentication_composition.md` already imports arbitrary-attack, fresh-key authentication without recycling, and `frozen_bell_bank_memory_safe_recovery.md` already gives hidden-kept-slot sampling with a full-reference boundary. The possible streaming variant below is a weak purity-testing code with a restricted coherent-width interface. It trades wide cross-use coherent coding for many calls, private randomness, trusted payload storage and acceptance loss. An equally informed conventional trap/permutation authentication implementation receives precisely this interface; no quantum-learning advantage or historical novelty is asserted.

Portmann's no-recycling composition, Appendix D Lemma D.1, is the applicable primary theorem, not the distinct square-root key-recycling bound. It already permits retained adversarial side information and arbitrary coherent attacks. [Portmann, Quantum authentication with key recycling](https://arxiv.org/abs/1610.03422). Trap codes likewise combine encoded data, traps, secret permutation and encryption; their original versus stronger purity-testing distinctions concern ciphertext security/key recycling, neither of which is newly claimed here. [Dulek and Speelman, Quantum ciphertext authentication and key recycling with the trap code](https://arxiv.org/abs/1804.02237).

## Explicit fixed-width member of that conventional family

Freeze the entire learned q-qubit inner interface after its calibration history. Let d=2^q and L=N+1. Secretly choose one uniform payload slot; prepare a fresh independently uniform q-qubit stabilizer trap in each of the other N slots. Independently Pauli-encrypt every slot. After the fixed inner interface, undo each pad; test each trap by its inverse known Clifford and the all-zero projector. Keep the payload in trusted storage and accept only if every trap passes. Perform all L calls regardless of earlier test outcomes, with no public label, timing or abort-feedback leakage. Discard all keys/test records except the accept/erase flag. There is no entangling gate between source uses.

The entire L-use source plus frozen inner controls must define one channel independent of the fresh keys. Its memory may be correlated with the payload/reference; that side information is an explicit channel input, not silently assumed independent. A source choosing a new operation from leaked current keys or private timing is outside this interface. Outer preparation, storage, pad undo, trap tests and erasure handling are trusted and separately charged.

For completeness, the elementary purity-testing count is transparent. After slotwise Pauli averaging, a joint attack on slots and side information has a diagonal expansion sum_alpha Ad_(P_alpha) tensor Phi_alpha, with Phi_alpha completely positive and sum_alpha Phi_alpha trace preserving. This is an equality of maps and therefore retains arbitrary initial payload/reference/side-information correlations. For a nonidentity q-qubit Pauli, the uniformly random stabilizer trap accepts with probability a=1/(d+1). A Pauli pattern nontrivial on k slots has probability

    b_alpha=(k/L) a^(k−1)<=1/L

of a damaged payload with every trap accepted. Thus the secret-slot/trap family has weak purity-testing error1/L. This is the familiar encode-then-encrypt premise, not evidence that an untrusted source belongs to the learned reset family.

One can also see the accepted-subchannel statement directly. Define the ideal accepted operation as identity on the payload tensored with the same sum of accepted side-information CP branches, replacing each accepted payload Pauli by identity. The bad branch map is CP-bounded by(1/L)sum_alpha Phi_alpha. Therefore the unhalved accepted-map distance, with arbitrary reference retained, is at most2/L. The real and ideal accepted branches have identical trace for every input; the erased branch has the same side-information map because tracing out the payload removes its Pauli. This supplies an averaged identity-or-erasure channel, not merely a classical wrong-answer probability. Conditional accepted distance can still be as large as min(2,2/(L p_acc)); acceptance conditioning does not disappear. Keys are fresh each block and are not recycled.

## Honest comparison and costs

* **Same-width conventional baseline:** the construction itself is available to a conventional trap/permutation authenticator. It can be viewed as appending qN traps, selecting a secret block permutation that places the payload, applying independent local trap Cliffords, then encrypting. It has no error-correcting distance against benign noise. Stronger conventional trap codes may add such distance but require their actual encoded-block controls/storage; comparing them requires an explicit common hardware interface, not declaring them unavailable.
* **Calls/traffic:** L actual q-logical-block source calls, qL input-qubit uses and nL physical output exposures for an n-qubit inner output. Achieving unconditional integrity tolerance epsilon by this count needs L>=1/epsilon (up to the norm convention). There are N trusted trap preparations/readouts and L pad operations, with their finite samplers and compiler errors paid.
* **Private information/storage:** log2 L slot entropy,2qL pad bits and N independent q-qubit Clifford indices; finite rejection-sampler caps add their discrepancy. Sender and receiver retain the payload for up to L call times, with qL-order trusted payload qubit-time in the worst schedule, plus the current inner block/workspace. No Nq coherent register is required, but storage fidelity and no timing leakage are real extra capabilities, not provided by count calibration.
* **Availability:** none is guaranteed for arbitrary correlated noise. Under the separate iid benign Pauli-channel premise with Bell loss r, all traps pass with probability[1−d r/(d+1)]^N. Keeping this bounded away from zero requires r=O(1/N). Conversely an attack nontrivial on every slot can make acceptance tiny while every accepted payload is damaged; the conditional denominator is essential. Retained authentication availability notes already draw this integrity/throughput distinction.
* **Other retained alternatives:** whole-compiled-operation qualification certifies a frozen stationary/reset execution, not future no-reset utility. Frozen Bell-bank sampling permits choosing a retained slot after noise but pays trusted retained entanglement/storage. Neither interface is silently granted here.

Conclusion: preserve this as an implementation/resource comparison. The scientifically consequential next construction is robust approximate local acquisition/composition, not another purported authentication cutoff.

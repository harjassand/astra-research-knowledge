# Annealed source bounds: exact removal of the fixed-syndrome exponential cost

2026-11-02. Exact coefficient lemmas; connected normalization remains unproved.

## 1. Full reference trace Hölder

For any finite-dimensional Hermitian reference H_ref (in particular the full native clock/data/bath Hamiltonian), t_i>=0 with sum t_i=beta, and arbitrary bounded operators A_i,

  |Tr(e^{-t_0 H_ref} A_1 e^{-t_1 H_ref} ... A_k e^{-t_k H_ref})|
       <= Z_ref product_i ||A_i||.

Apply generalized Schatten Hölder with exponent beta/t_i to each heat kernel and infinity to each A_i. Each heat-kernel norm is Z_ref^(t_i/beta), so their product is exactly Z_ref. Zero intervals are handled by the infinity norm convention.

For a fixed distinct label set A, summing all chronological repetitions and orders in the Dyson expansion gives the absolute upper bound

  product_{lambda in A}(exp(beta ||V_lambda||)-1)

for the normalized coefficient family. This includes all clock excited states, signs, dimensions and the actual bath. It has beta v, not beta v exp(C beta J), as its elementary small parameter.

It does NOT justify summing all label sets: doing so yields an extensive exp(beta sum ||V_lambda||) bound. The connected denominator cancellation is essential.

## 2. Conditional local-orbit version

Let P be an orthogonal projector commuting with H_ref and every V_lambda in A. Then the same bound holds on ran(P), normalized by Z_P=Tr(P e^{-beta H_ref}).

A useful exact choice is a data syndrome orbit under the translations generated by the Pauli dictionary of A, possibly fixing all syndrome coordinates outside the affected set. H_ref preserves all syndrome projectors, and each insertion preserves the chosen orbit. This conditional bound is uniform in the outside syndrome, while summing over the allowed internal orbit. The prior fixed-syndrome activity bound did not enjoy this property because individual insertions did not preserve its sector.

For disjoint affected-check sets, the translation groups act independently and commute. Global syndrome validity does not break invariance: adding any actual Pauli syndrome preserves the valid syndrome space. This supplies an exact algebraic starting point for a multi-source orbit-fiber resummation. It does not, by itself, establish product factorization of the conditional clock traces or stabilizer-character expectations.

## 3. Root's uncovered-witness coefficient lemma, checked

For valid witness tau and a source label set A, let C_A be all checks that any insertion in A can flip, and U=tau minus C_A. Let P_U impose occupation of every check in U. Then [P_U,H_ref]=[P_U,V_lambda]=0, and P_tau<=P_U.

Insert P_tau as one further norm-one operator in the restricted P_U trace and apply Hölder. Thus each normalized witness-marked coefficient obeys

  |Tr(P_tau e^{-t0 H_ref} V_1 ... V_k e^{-tk H_ref})|/Z_ref
       <= Pr_ref(P_U) product_i ||V_i||.

This remains exact with the native prefix dictionary, provided C_A uses the actual dressed data Pauli syndrome and includes every affected check.

To bound Pr_ref(P_U), translate a valid syndrome by the WHOLE valid tau. Even when checks of tau intersecting C_A are not occupied, this creates at most |tau intersect C_A| new defects while removing at least |tau|-|tau intersect C_A| defects. For a commuting reference the energy drop is therefore at least 2J(|tau|-2|tau intersect C_A|). For the native static free energy, use the already-earned general syndrome-translation bound on its remainder, not a fictitious native energy ladder. Low coverage retains thermal suppression; high coverage requires many bounded-footprint source labels and can be paid by powers of beta v.

This is precisely the desired thermal-versus-virtual split at coefficient level. It is not yet a bound on the normalized full perturbed Gibbs probability.

## 4. Candidate exact canonical trace polymer gas

The actual decoder join uses a fixed bounded-degree dependency graph, all-branch potential stencils, all collision preimages, component-local deterministic decisions, and no recursive zero activation. Under the explicit convention that the active graph includes every fixed dependency edge between its activated stencils, it appears to give the following exact representation:

- A polymer is a labeled connected full trace W=T(tau) with one component and its valid base syndrome tau.
- Two polymers are incompatible when their complete stencils overlap or have a connecting activated dependency edge.
- A compatible collection reconstructs T(sum tau_i)=disjoint union_i W_i by layerwise component independence.
- Every valid syndrome decomposes uniquely into these polymers by its canonical full trace.
- Terminal-reaching polymers all meet the same finite terminal bag and hence are incompatible.

For the commuting reference, weights factor as exp(-2 beta J sum |tau_i|), and the prior exponential-in-mass shape count gives an ordinary low-activity polymer gas with full Ursell/cumulant control, not merely two-point clustering.

This requires checking the active-edge/halo convention. Deletion stability ALONE is not enough in a generic decoder: a higher-order activation rule could merge three components even though every pair remains separate. The actual union-of-input-seeded all-branch construction appears designed to rule that out. The native free-energy remainder further induces interactions among these polymers and needs its own convergent interaction treatment.

# A3 — Causal experiment design under physical measurement limits

**Status:** internal mathematical derivation of a known realization-theory obstruction; research direction is a candidate, with novelty and practical value unverified. No external experiment was run.

## 1. North Star

An AI scientist should be able to say which available control and measurement would distinguish two proposed laws, what physical calibration that requires, and which predictions remain valid if the internal state variables cannot be identified. It should make causal claims about named physical variables only when the experiment actually anchors those variables.

## 2. Exact task / theorem

Start with a discrete-time linear system

\[
x_{t+1}=Ax_t+Bu_t,\qquad y_t=Cx_t,\qquad x_0=0,
\]

where the controls \(u_t\) and readouts \(y_t\) are available but the coordinates and calibration of the internal state \(x_t\) are not. A candidate exact task is: for a stated family of calibrated actuator/readout channels and their costs, characterize which queries of \(A\) are constant over all minimal realizations compatible with every feasible input-output experiment; find the least-cost added calibration that makes a specified query identifiable.

The base obstruction is exact. For every invertible state-coordinate map \(S\), define

\[
A'=SAS^{-1},\qquad B'=SB,\qquad C'=CS^{-1}.
\]

Then \(x'_t=Sx_t\) gives the same output for every input sequence, so no adaptive experiment policy using only these input/output channels can distinguish the two realizations. The zero pattern of \(A\), and hence its coordinate-specific edge graph, need not be preserved.

For a concrete minimal two-state example, take

\[
A=\begin{pmatrix}1/2&0\\0&1/3\end{pmatrix},\quad
B=\begin{pmatrix}1\\1\end{pmatrix},\quad C=\begin{pmatrix}1&1\end{pmatrix},\quad
S=\begin{pmatrix}1&1\\0&1\end{pmatrix}.
\]

This gives

\[
A'=\begin{pmatrix}1/2&-1/6\\0&1/3\end{pmatrix},\quad
B'=\begin{pmatrix}2\\1\end{pmatrix},\quad C'=\begin{pmatrix}1&0\end{pmatrix}.
\]

The original controllability and observability matrices both have determinant \(-1/6\), so both realizations are minimal. The first \(A\) has no cross-state edge; the second has an edge \(x'_2\to x'_1\). Yet their complete input-output maps agree, including with noiseless, unlimited-precision readout and arbitrary excitation.

A useful positive control is also immediate: if the actuator matrix is physically calibrated and has full row rank \(n\), then any similarity between two minimal realizations with the same calibrated \(B\) obeys \(SB=B\), hence \(S=I\); similarly, a calibrated full-column-rank \(C\) forces \(S=I\). This sufficient condition is not claimed minimal. The research question is the query-specific version: with only some calibrated channels, determine the residual stabilizer \(\{S:SB_{\rm cal}=B_{\rm cal},\ C_{\rm cal}S^{-1}=C_{\rm cal}\}\), and test whether a desired causal query is invariant over it.

## 3. Importance

The obstruction separates mechanism claims from observable scientific behavior. Input-output predictions and many control properties can be properties of the transfer map even when the latent edge graph changes under a state-coordinate transformation. A system that reports an internal edge graph as if it were physically identified can therefore overstate what the experiment established. A query-specific anchor result could tell an experimenter whether to buy a new calibrated sensor or actuator, or to report only behavior-level conclusions.

This has high foundational relevance and plausible practical value in latent dynamical systems. The exact counterexample itself is classical, so this exploration does not establish a breakthrough.

## 4. Obstruction

The missing information is not merely more samples or finer readout. Similarity-equivalent systems agree for every possible control history, so arbitrary increases in sample count and output precision cannot recover coordinate-dependent edges. The gap is an interface one: a physical actuator or sensor must be tied to a named state coordinate, or the target must be reformulated as an invariant of the measured input-output behavior.

This is distinct from ordinary DAG Markov equivalence: each realization can be controllable and observable, yet its chosen internal causal coordinates still are not identified by input-output behavior. Conversely, if the scientific state variables are already physically named and calibrated, this particular ambiguity may be irrelevant.

## 5. Missing capability

The candidate missing operation is a **query-specific identifiability and anchor planner** for physically accessed dynamical systems. Given a model family, accessible control/readout maps, calibration status, precision, and costs, it would:

1. compute the observational/interventional equivalence class allowed by that interface;
2. label each requested causal or control claim as invariant, identifiable after a stated anchor, or unresolved;
3. find the cheapest feasible calibration that separates the models for the requested claim, with an indistinguishability lower bound when none exists.

This is a task specification, not an implemented capability. A generic appeal to “maximize information gain” would not suffice: the exact equivalence relation must include the unknown state-coordinate gauge and the physical meaning of calibrated channels.

A second direction considered was choosing interventions, sample counts, and readout resolution to maximize separation per unit cost. This matters for finite-data science, but by itself sits close to established active and optimal experiment design; it becomes more distinctive only when candidate laws include unknown physical actuator/readout calibration and the design explicitly tests query identifiability over the resulting equivalence class. I prioritized the exact gauge obstruction.

## 6. Actual first derivation / test

The induction is direct: if \(x'_0=Sx_0\), then \(x'_{t+1}=A'x'_t+B'u_t=S(Ax_t+Bu_t)=Sx_{t+1}\), while \(y'_t=C'x'_t=Cx_t=y_t\). This holds for all finite or infinite input histories, including histories selected adaptively from past outputs. In the displayed two-dimensional example, \(A'_{12}= -1/6\ne0\) while \(A_{12}=0\), and both controllability/observability ranks are full. The alternate edge is therefore not recoverable from the available interface, even in the ideal-data limit.

The full-rank calibrated-actuator sufficient condition follows from minimal-realization uniqueness up to similarity: a residual similarity must fix every column of \(B\); if those columns span the state space, it is the identity. The sensor argument is dual. These calculations are internally checked algebra, not a new realization theorem or a finite-data study.

## 7. Prior work, baselines, and acquisition / precision / output costs

**Closest established foundations.** Kalman’s realization theory extracts the controllable/observable state from input-output behavior, and Ho–Kalman give a construction from Markov parameters; the equivalence of realizations under constant coordinate transformations is classical ([Kalman, 1963](https://doi.org/10.1137/0301010), [Ho–Kalman, 1966](https://doi.org/10.1524/auto.1966.14.112.545), [Anderson et al., 1966](https://doi.org/10.1016/0016-0032(66)90298-5), [NASA record](https://ntrs.nasa.gov/citations/19670049337)). That is the source of the obstruction, so the similarity argument is not novel.

For named variables in a DAG, Hauser and Bühlmann characterize interventional Markov-equivalence classes and give active strategies for choosing intervention targets ([2012 JMLR](https://www.jmlr.org/papers/v13/hauser12a.html), [Hauser–Bühlmann, 2014](https://doi.org/10.1016/j.ijar.2013.11.007)). These are strong baselines for selecting interventions once the variables and intervention targets are defined. Akbari, Etesami, and Kiyavash optimize intervention cost for a target causal effect and allow a non-intervenable variable to have infinite cost, but assume the causal graph is supplied and assign zero cost to observation ([JMLR 2025](https://www.jmlr.org/papers/volume26/22-1516/22-1516.pdf), problem setup pp. 3–4). Their problem is more specific and more mature than this candidate in intervention-cost optimization; it does not remove the latent state-coordinate ambiguity above.

The closest representation-learning baseline is von Kügelgen et al., *Nonparametric Identifiability of Causal Representations from Unknown Interventions* (NeurIPS 2023). It handles unknown nonlinear mixing and unknown intervention targets: in the bivariate case, an observational domain plus one perfect intervention per node suffices subject to a genericity condition; for arbitrary dimension, the paper gives a sufficient condition of two distinct perfect interventional domains per node ([paper](https://www.cs.columbia.edu/~blei/papers/K%C3%BCgelgenBesserveLiangGreseleKeki%C4%87BareinboimBleiSch%C3%B6lkopf2023.pdf)). This sharply limits any novelty claim around “unknown sensors plus causal discovery.” Yang et al. study linear SEMs with measurement error and latent variables, under a separability assumption that identifies the mixing matrix up to permutation/scaling, and characterize remaining edge ambiguity under faithfulness ([paper](https://arxiv.org/abs/2211.03984)). The open question worth isolating is dynamic, query-specific calibration design under explicit physical actuator/readout access and costs, not generic representation identifiability.

**Accounting.** No physical data, instrument calibration, or finite-precision sample was acquired here. The no-go is exact and survives infinite sample size and precision. The proposed positive anchor requires external physical calibration; the sufficient full-rank condition may be expensive and is not asserted optimal. Any next study must separately charge control excitation, sensor/actuator calibration, sample count, measurement precision, computation, and the final claim/output representation. Nothing in this derivation establishes a practical cost advantage.

## 8. Decisive next step

Choose one explicit small physical access model (for example, an \(n\)-state linear dynamical system with a fixed list of controllable input directions, a fixed list of readout channels, and stated calibration/noise costs). For a target query such as one named edge of \(A\), characterize the residual similarity group exactly; either give a pair of minimal systems in the same access class with opposite query answers, or prove the query invariant. Then find the minimum-cost additional calibrated channel that breaks that equivalence and compare its cost with a behavior-level target such as a held-out input-output prediction or closed-loop stability. The rank-\(n\) anchor above is the positive control; the two-state construction is the negative control. The decision gate is a query-specific theorem plus a matched finite-precision design calculation. If the result reduces to standard realization theory or existing causal representation identifiability after checking the literature, record a clean negative novelty result and stop this branch.

# Hard-frontier context and representation experiment

Frozen before experimental constructors start, 30 October 2026. This studies practical research policies, not how to manufacture a named new theory or a reliable 90+ rating. Two independent source analysts challenged task admission before launch. Production Pro, Ultra and Dots are not experimental subjects and receive none of these experimental prompts. No additional Pro run, production worker, formal goal or automation is created.

The mechanism hypothesis is that some failures belong to a representation rather than the scientific target. Separating the two, retaining what the old attempt lost and constructing a different object may enable a stronger result. Alternatives are that ordinary expert search already does this, that missing information/opportunity matters more, or that explicit method instructions consume useful effort. A useful result can use established theory; creating a new theory is not an outcome criterion.

Two hard tasks are fixed in `packet/MATH_TASK.md` and `packet/CONTROL_TASK.md`. The first concerns the genuinely exceptional rotational quartic with four nontranslation cubic modes, not the already classified rigid family. Factorisation, the kernel jump, the general ROC Schur criterion and compatible moment reduction are supplied, so repeating them is not new progress. The second concerns approximate PRIVATELY RANDOMIZED robust entanglement with P2's original bounded signed handles, arbitrary spectator and a dimension-independent LOCAL commutator-motion promise. Bath history is independent of private signs; no uniform full-bath norm or derivative bound is given. Known gains/axes, a five-pulse drift-free identity, the limited deterministic exact no-go and an explicitly UNPROVED sign-cycle foothold are supplied. The design was strengthened during preflight, before any experimental constructor started: simple qubit norm-bounded drift and exact deterministic impossibility were insufficient frontiers. Assuming a positive parity meter, defeating one echo, proving only the supplied exact no-go or averaging Hamiltonians instead of channels does not solve the frozen task. These are unresolved selected frontiers, not representative samples of all science.

First phase: two fresh ordinary expert constructors per task, four total, all with empty inherited conversation and the same frozen local sources for their task. Each gets one substantive research tranche. Both successful and failed returns remain in the study. No sibling information is shared.

Before any second-phase return, the coordinator freezes a factual capsule for each first-phase state: actual constructions, corrected false claims, remaining obligation and original proof/code pointers. It adds no new scientific suggestion. Every continuation receives the same capsule, artifacts and frozen library.

Each initial state gets three continuations: W, its warm ordinary expert; F, a fresh ordinary expert using the capsule; R, a fresh expert using the same capsule plus a short target/representation audit and constructive replacement procedure. There are four matched blocks, twelve second-phase outcomes and twelve researcher contexts in total. W versus F tests resetting WITH compression and lost conversational state, not pure freshness. F versus R tests the procedure package within equally fresh contexts. Both may freely change representations and use existing mathematics. One substantial construction is requested from every arm; R is not given an extra helper or scientific witness.

Common allowance: one substantive tranche aiming at 15–25 minutes per phase, up to 25 minutes of scientific work requested, ordinary concise final assembly and proof/code files. No hard inference/output limit or exact equal-compute control is available; actual elapsed work and interruptions are retained. If an initial state already resolves the target, all three continuations receive the same request to establish its strongest unproved scope/consequence; if there is no meaningful unsolved consequence, record a ceiling rather than invent a favorable follow-up. No extra time is selectively granted to a favored arm. A transient access failure may be retried in the same agent after measured backoff, without duplicates or model substitution.

All constructors inherit the same local coordinator model/effort with no override. This is not native Pro, whose performance cannot be inferred directly. Tool rights are frozen local-only scientific reading/computation from launch; no network, browser, connectors, provider feedback, production/dispatcher contact, nested agents or other repository/history/memory browsing. Each writes only its own directory and reads only its packet and explicitly supplied checkpoint artifacts. These are instructions on a shared filesystem, not an enforced sandbox. Observed violations remain separate from scientific outcomes.

Assess actual proof and executable consequences, separating correctness from reach. Categories: inherited-only/restatement; new local fact with central barrier intact; central advance; target resolved; unresolved/incorrect. A broad negative theorem is useful allocation information but does not become an enabled technology. New words, number of proposals, claims of creativity, elapsed thinking and restrictions removed are not success metrics. A promising incomplete framework deserves credit for a proved new consequence, without calling it a breakthrough. Root is source-exposed; an arm-masked scientific assessment will be sought before revealing treatment labels, with possible stylistic inference acknowledged. Important new claims receive targeted proof/code scrutiny; no outside-validation gate or majority vote is used.

The effective evidence is four initial states across two task families, not twelve independent discoveries. If all outcomes repeat predecessors or fail to move a checkable consequence, the study is uninformative about the relative policies at those frontiers. Mixed results favor conditional use. A clear procedure benefit warrants a different-task replication, not immediate portfolio-wide rollout. No outcome here establishes an optimal policy or consistent civilisation-changing discovery.

Original experimental prompts, ordinary artifacts, factual handoffs and a compact results table are sufficient records. No researcher forms, extensive ledgers, credit tracking or memory edits. Retain negative outcomes and actual source omissions. Any later selective cross-agent construction or further development is labelled a separate adaptation, not folded into the initial comparison.

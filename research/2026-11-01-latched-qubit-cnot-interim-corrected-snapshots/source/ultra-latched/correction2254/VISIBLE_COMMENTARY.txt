I’ll start from a full memory construction that already admits imperfect controllers and couplers, then test where it can gain a stronger capability. The key target is an allowance for reference-breaking faults that stays fixed as the code grows, without relying on exact Gibbs balance.

The earlier Tanner construction already has the requested fixed allowance for reference-breaking faults, so I’ll treat it as a serious comparator. A new route needs to improve something concrete, such as controller complexity or geometry.

I’m testing finite-duration unitary jobs as a way to realize fault-tolerant autonomous updates. Overlapping jobs are the critical issue: their partial operations must have a valid quantum history, rather than being assumed to act like instantaneous updates.

A simpler route is emerging: an autonomous encoded CNOT driven by one relaxing flag per data pair. The correction interactions depend on those local flags, so they follow the changing code frame.

In the proposed proof, each flag relaxation becomes a local disturbance that the memory can correct. The promising point is that readout may only need the remaining flag density to be small, rather than every flag finished. I’m checking that claim against the full quantum decoder, including flag faults and correlations.

I’m working on a concrete extension: a one-shot encoded gate driven by local flags that relax while the memory corrects errors. The key test is whether the gate remains reliable with a fixed allowance for faults on the flags and couplers, including faults that break reference balance.

The gate construction has a useful feature: it need not wait for every flag to finish. A small density of unfinished flags acts as a correctable error at readout, which could give a constant latency as the code grows. I also found accepted Astra results on generic-noise memory and prescribed Clifford computation; I’m checking those before claiming that this adds anything.

Astra already contains the asynchronous CNOT argument with a fixed ordinary data decoder. I’ll treat that as an existing result. I’m testing a narrower extension: combining it with the finite-controller construction to obtain explicit qubit interactions, one-qubit losses, and the same data-only recovery, with flag faults counted in the noise budget.

The finite quantum checks pass for the flag mechanism: controller loss errors, coherent flag–controller faults, upward flag jumps, and a shared bath all fit the moment bound. The decoder checks also pass with coherent flag–bath correlations. Two unfinished columns fail on the small test code, confirming that the proof needs a bound on their density.

The compiler appears to preserve the property the gate proof needs: every Hamiltonian term contains only \(I\) or \(Z\) on each flag. The flag-count bound therefore survives reduction to three-qubit interactions and degree three. The explicit construction check passes. In the small-code dynamics test, the scheduled comparator performs better, so there is no numerical advantage to claim.

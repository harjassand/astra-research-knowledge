# A monitored, constant-excitation entangler with an explicit actuator–measurement tradeoff

Independent capability-originating research note, 31 October 2026.

## 0. Result and status

Desired capability: execute a useful logical entangler while the noisy monitoring apparatus cannot acquire information within a logical sector, and correct physical loss without knowing or preserving the state of that apparatus. Preparation, monitoring, control, recovery and reset are part of the operation, not free background assumptions.

This note develops one concrete route:

* Store each qubit in the known two-mode, four-photon Chuang–Leung–Yamamoto (CLY) code.
* Execute an ordinary cross-Kerr interaction between one rail of each encoded qubit.
* Continuously monitor each block's TOTAL photon number with a symmetrically coupled readout. The total number is exactly constant inside every correctable logical sector, so arbitrary noise confined to this ideal monitor does not distinguish logical states.
* Estimate the time of a loss from the total-number record; identify its rail at the end; cancel its propagated phase with an ordinary oscillator phase rotation; then restore the missing photon coherently.

The resulting ideal instrument implements a CZ exactly through zero losses, one loss in either block, or one loss in EACH block. No-jump evolution is included. The result assumes a Markovian linear-loss model, accurate time/rail information, a quadratic number Hamiltonian, and ideal recovery. It does not protect against arbitrary faults of the nonlinear gate coupler, differential monitor coupling, or faulty recovery.

A sharp complementary result is available. For this code, a static number-diagonal Hamiltonian that is continuously transparent to a single loss anywhere requires occupation degree at least 5. Requiring transparency to one loss in each block raises the minimum to 6. Explicit Hamiltonians attain both bounds. Thus the monitored construction exchanges a high-degree static interaction for measurement bandwidth, symmetry matching, classical processing and recovery.

Known ingredients are explicitly identified below. The narrow candidate contribution is the complete monitored, rate-balanced instrument and the sharp occupation-degree comparison, not the code, cross-Kerr gate, detected-jump principle, or symmetric readout themselves. A targeted literature search did not establish novelty of the combined construction. It certainly did not establish experimental superiority or a fault-tolerant threshold.

## 1. The code and the full loss process

For modes a,b define

    |0_L> = (|4,0> + |0,4>)/sqrt(2),
    |1_L> = |2,2>,
    N_A = n_a + n_b.

Both codewords have exactly N_A=4. This is an established bosonic amplitude-damping code [1], not a new encoding. Its single-loss images are

    a|0_L> = sqrt(2)|3,0>,    a|1_L> = sqrt(2)|1,2>,
    b|0_L> = sqrt(2)|0,3>,    b|1_L> = sqrt(2)|2,1>.

Writing P_A for the code projector,

    P_A a†a P_A = P_A b†b P_A = 2P_A,
    P_A a†b P_A = P_A b†a P_A = 0.

The two loss images are orthogonal two-dimensional spaces. Every single loss is an isometry on the logical state; it does not merely flag that the state has been destroyed. The even/odd parity pattern distinguishes the two error spaces without distinguishing their logical basis states.

For equal per-photon loss rates kappa in the rails, the no-jump propagator is

    K_0(t) = exp[-kappa t N_A/2].

It equals exp(-2 kappa t) on the initial code and exp(-3 kappa t/2) on either single-loss sector. These are EXACT scalars, not a first-order replacement of n by its expectation. This matters: merely equal average photon number does not make finite-time no-jump evolution scalar. The distinction is discussed explicitly for binomial and multimode codes in [2].

The construction uses two blocks, A=(a,b) and B=(c,d), initially containing eight photons in four storage modes.

## 2. A quadratic actuator gives an exact endpoint CZ

Set hbar=1 and use

    H_g = chi n_a n_c,      T = pi/(4 chi).

On |0_L>, the occupation of the active rail is 0 or 4; on |1_L>, it is 2. Consequently:

* |00_L> components accumulate phases 0 or 16 chi T, all equal modulo 2pi.
* |01_L> and |10_L> components accumulate phases 0 or 8 chi T, all equal modulo 2pi.
* |11_L> accumulates 4 chi T=pi.

Thus

    exp(-i H_g T) P = CZ_L P,
    CZ_L = diag(1,1,1,-1).

At intermediate times the state generally leaves the original product code. Its total number in each block remains fixed. Cross-Kerr controlled rotations as logical entanglers for rotation-symmetric codes are established machinery [3]. Leaving the original code during a gate is not itself a fault-tolerance failure; error closure and dynamic encodings are established approaches [4,5].

Suppose mode a loses a photon at time t. Ignoring the scalar damping and sqrt(kappa) factors for a moment,

    exp[-i H_g(T-t)] a exp[-i H_g t] P
       = exp[+i chi(T-t)n_c] a CZ_L P.

The loss is the usual correctable a error followed by an extra phase rotation of the OTHER block. Apply

    F_a(t) = exp[-i chi(T-t)n_c].

Then ordinary local loss recovery produces exactly CZ_L. A loss in c similarly requires exp[-i chi(T-t)n_a]. Losses in b or d commute with this bare gate and require no propagated-phase correction.

The correction depends on the remaining gate area, not elapsed wall-clock time if chi(t) is shaped. Replace chi(T-t) by the calibrated integral from t to T.

One loss in each block is also correctable. Multiple phase factors commute; moving a phase through a later loss changes only a known scalar phase. Two losses in the SAME block are not generally correctable. For example, ab annihilates |0_L> but maps |1_L> to 2|1,1>, so that record directly reveals a logical basis value.

The complete matched-rate density for a single loss in a specified mode at t is

    K_a(t)† K_a(t) =
       2 kappa exp[-8 kappa t - 7 kappa(T-t)] P.

It is input independent. This equation includes the no-loss interval both before and after the loss; checking only a†a at t=0 would not suffice.

## 3. General quadratic-control trajectory statement

This is the algebra behind the construction and its extension to calibrated self-Kerr terms.

Assume a time-dependent, number-diagonal Hamiltonian

    h(t,n) = (1/2) n^T J(t)n + v(t)^T n + c(t),

linear Markov loss operators sqrt(kappa_j(t)) a_j, and possibly instantaneous rail permutations tracked in a toggling frame. Define

    F(n) = integral h(t,n) dt,
    G(n) = integral sum_j kappa_j(t)n_j dt.

All diagonal evolutions commute. For a trajectory r consisting of known losses at known times, their commutation through the remaining evolution gives

    K_r P = C_r exp[i ell_r(n)] E_r exp[-i F(n)] exp[-G(n)/2] P,

where E_r is the product of end-of-gate annihilation operators, C_r is a scalar, and ell_r is LINEAR in occupations. Quadratic energy differences after a single number decrement are linear. Cross terms between two decrements contribute only scalar phases.

Suppose:

1. exp[-iF(n)] preserves the endpoint code and implements U_L;
2. G(n) is scalar on the initial code;
3. P E_r† E_r P = c_r P for every admitted trajectory;
4. its error syndrome can be resolved and an isometric recovery performed.

Then a one-body phase correction followed by recovery gives

    R_r exp[-i ell_r(n)] K_r P = alpha_r U_L P,

and

    P K_r† K_r P = |alpha_r|^2 P

after the conventional normalization of R_r. Every accepted trajectory has the same logical unitary and input-independent probability. By retaining a reference entangled with the logical input, this also proves preservation of arbitrary quantum information, not merely agreement on basis populations.

For multiple unresolved bath channels, the endpoint syndrome can supply the missing channel label. If timing remains unresolved, this statement becomes a mixture over different ell_r and is no longer exact; Section 7 quantifies that residual.

The result is a specialized, useful realization of monitored-error correction and error closure. It is not offered as a replacement for the general Knill–Laflamme or path-independence frameworks [4,6,7].

## 4. A monitor whose own noise does not see logical information

Directly collecting every intrinsic cavity-loss photon is generally an unrealistic resource assumption. Dielectric and conductor losses are not conveniently monitored output ports. Adding a monitored port increases total damping and does not eliminate the original unmonitored loss.

Instead, monitor N_A and N_B nondestructively. A suitable ideal interaction is

    H_M,A = N_A tensor B_M,A,

where B_M,A can be a transmon operator, a readout-mode occupation, or another apparatus observable. A familiar dispersive realization is

    H_M,A = lambda (n_a+n_b) m_A†m_A,

with a driven, damped readout mode m_A. Its output distinguishes N_A=4 from N_A=3, but not logical states inside either sector.

The protection is stronger than a perturbative ancilla-error calculation. During any fixed N_A interval, the FULL apparatus-plus-environment Hamiltonian is

    H_apparatus + N_A B_M,A.

It is independent of the unknown logical state. Arbitrary preparation error, relaxation, dephasing, readout loss or reset dynamics confined to this apparatus can change the quality of the number record but cannot directly acquire logical information. Conditioned on an exact total-number trajectory, the apparatus state depends only on the integer-valued N_A(t). The gate commutes with N_A, so entangling evolution does not spoil this factorization.

The common-mode monitor need only identify when a block loses a photon. A final error-syndrome operation identifies which rail lost it. The time estimate and rail label then determine the propagated-phase correction. One parity measurement on a chosen rail suffices once N=3 and the loss count are known; a coherent recovery can instead store the rail syndrome in a resettable ancilla.

Joint-number measurements in coupled cavities and symmetrically coupled readout are existing techniques [8,9]. In particular, Hung et al. (2026) report time-continuous erasure detection in parallel with single-qubit gates for transmon dual rail [9]. The missing operation here is its use to make a correctable MULTIPHOTON entangler, with a full timing/recovery error budget. A single-excitation demonstration does not establish the necessary symmetry across occupations up to four.

The microscopic lost-photon bath need not be observed directly. A time-resolved N record selects a narrow range of loss times, and therefore a narrow range of propagated phases in the quantum-trajectory expansion. The independent bath is still traced out; finite timing resolution leaves a random phase, rather than magically erasing all bath information. The exact result is an ideal time-resolution limit, and the practical result is explicitly approximate.

## 5. Unequal loss rates: an exact ideal echo

If kappa_a != kappa_b, fixed TOTAL number alone does not make the weighted no-jump operator scalar. A simple ideal echo balances the integrated rates.

Evolve for T/2 with chi n_a n_c, swap a<->b and c<->d, evolve for T/2 with the same laboratory interaction, and restore the rail frame or absorb its final permutation into recovery. In the toggling frame,

    h(t) = chi n_a n_c,       0<t<T/2,
           chi n_b n_d,       T/2<t<T.

The integrated no-jump exponent becomes

    G = (T/2)[(kappa_a+kappa_b)N_A
              +(kappa_c+kappa_d)N_B],

which is scalar on the code. This balancing also works for the full single-loss trajectory: commuting its annihilator through G adds only a scalar depending on the time and rail. It does not leave a logical filter after the gate.

At N_A=N_B=4, the integrated Hamiltonian is

    F = (chi T/2)(n_a n_c+n_b n_d)
      = chi T[n_a n_c-2(n_a+n_c)+8].

At chi T=pi/4, it implements Z_A Z_B CZ. The two known logical Z factors are removed or tracked. The timestamp correction is found by integrating the interaction matrix after each loss; it remains linear in occupations.

The echo is exact under instantaneous, ideal swaps. A physical beam-splitter swap takes time, exposes the photons to loss and control noise, and, with unequal damping, does not commute with the differential damping generator during the pulse. Those errors must be included in the hardware simulation. The construction does not assert that a single finite-duration swap perfectly eliminates arbitrary rate drift. Rate balancing can instead be engineered directly, at the cost of any added loss.

## 6. Sharp static-interaction lower bounds

Here the allowed alternative is a STATIC number-diagonal Hamiltonian h(n_a,n_b,n_c,n_d), with continuous error transparency: it generates the same logical entangling Hamiltonian in the code and in each correctable loss sector, up to an arbitrary sector-dependent scalar. This is a restriction on the instantaneous generator, not a no-go theorem for all gates, encodings, holonomies or monitored controls.

Define two linear functionals on a polynomial f in the occupations of one block:

    D_4 f = [f(4,0)+f(0,4)]/2 - f(2,2),

    D_3 f = [f(3,0)+f(0,3)-f(1,2)-f(2,1)]/2.

D_4 is the logical 0-versus-1 energy contrast in the initial code. D_3 averages that contrast over the two normalized single-loss sectors.

Both functionals annihilate every affine polynomial. On EVERY quadratic polynomial,

    D_3 = (1/2) D_4.

For example, D_4(n_a^2)=4 and D_3(n_a^2)=2. For the mixed monomial, D_4(n_a n_b)=-4 and D_3(n_a n_b)=-2. The same relation holds for n_b^2; these monomials, the affine terms and linearity prove the identity.

For a two-qubit diagonal logical Hamiltonian with nonzero entangling contrast Delta, applying D on both blocks gives Delta. Local logical terms and all syndrome-dependent scalar offsets cancel.

If total degree(h)<=4, the only monomials that survive D_A D_B have degree exactly two in each block. Therefore

    D_3^A D_4^B h = (1/2) D_4^A D_4^B h.

Error transparency demands that both sides before the factor equal Delta. For Delta !=0 this is impossible. Thus one-loss transparency requires occupation degree AT LEAST 5, even allowing arbitrary scalar energies in the four error sectors.

The bound is attained by

    H_5 = (Omega/16)(9-N_A-N_B)n_a n_b n_c n_d.

In the code, n_a n_b is 0 on |0_L> and 4 on |1_L>. After one loss in that block, it is 0 or 2. The factor 9-N_A-N_B is 1 without a loss and 2 after one loss anywhere. Thus H_5 is Omega |11_L><11_L| in the code and every globally single-loss sector. Omega T=pi yields a CZ.

If one loss IN EACH block must also be tolerated, let

    Q = D_4 - 2D_3.

Q annihilates every polynomial of degree <=2. Hence Q_A Q_B annihilates every polynomial of total degree <=5. But if the same nonzero entangling contrast is present in all four combinations of unlost/lost blocks,

    Q_A Q_B h = Delta -2Delta -2Delta +4Delta = Delta !=0.

Degree at least 6 is necessary. It is attained by

    H_6 = (Omega/16)(5-N_A)(5-N_B)n_a n_b n_c n_d.

Each factor (5-N)n_a n_b equals 4 on logical 1, whether N=4 or N=3, and zero on logical 0. The construction is therefore exactly transparent to one loss per block.

These polynomial Hamiltonians are specified only on the relevant finite Fock sectors. Their unbounded extrapolation at high occupation is not a proposed physical potential. Engineering a bounded or truncated equivalent would still require the high-degree occupation dependence on these sectors. Degree 5 or 6 in n corresponds to terms as high as degree 10 or 12 in creation/annihilation operators; this does not prove a general many-body locality theorem.

A simpler general observation is also useful: for any product of codes correcting single linear loss, P n_i P is scalar on each code. Every cross-block quadratic number term n_i n_j consequently projects to a scalar. A fixed-code, continuously preserving quadratic-number Hamiltonian cannot generate a nontrivial entangler. The monitored Kerr construction evades this premise through code deformation and measured error timing.

## 7. Timing, efficiency and symmetry errors

### 7.1 Finite timestamp precision

For an active-rail loss, an error delta t in the time estimate leaves the partner rotation

    exp[i theta n],    theta = chi delta t.

Within the partner CLY code, after removal of a global phase,

    P exp[i theta n_a] P = diag(cos(2theta),1).

The omitted amplitude leaks into (|4,0>-|0,4>)/sqrt(2). Thus it is incorrect to treat the residual solely as a small logical Z rotation. Its entanglement infidelity relative to the encoded identity is

    1 - [(1+cos(2theta))/2]^2 = 2theta^2 + O(theta^4).

For zero-mean timing uncertainty with variance sigma_t^2, the conditional error per active-rail loss is approximately 2 chi^2 sigma_t^2. The bare gate has active-rail loss probability 4 kappa T to first order, giving an unconditional contribution

    epsilon_time approximately 8 kappa T chi^2 sigma_t^2.

For a uniform uncertainty interval of width Delta, sigma_t^2=Delta^2/12, so

    epsilon_time approximately (2/3) kappa T chi^2 Delta^2.

The coefficient changes for shaped/echoed gates; the general quantity is the variance of the remaining interaction area under the posterior loss-time distribution.

### 7.2 Monitor efficiency

Let eta_m be the quantum efficiency of the common-number readout. Lost readout photons carry only N in the ideal symmetric model, so eta_m<1 does not by itself reveal logical information. It worsens the loss-time posterior and can create missed or ambiguous steps.

A distinct quantity eta_c denotes the fraction of losses with an accepted, sufficiently precise timestamp. If all other losses are caught by a final number/syndrome check, they can be flagged. A formula using eta_c is a yield model; it is not a claim that quantum efficiency enters only as a classical click probability.

For direct loss-photon collection, with intrinsic loss kappa_int, engineered output loss kappa_out and detector efficiency eta_det,

    eta_total = eta_det kappa_out/(kappa_int+kappa_out).

Adding a monitored output increases total losses. The missed-loss rate is kappa_int+(1-eta_det)kappa_out, never smaller than the original intrinsic rate. This is why the common-number QND monitor is the serious route.

### 7.3 Differential monitor coupling

Write an effective continuous monitor as

    L_M = sqrt(gamma)[N + epsilon J_z],
    J_z = (n_a-n_b)/2.

Within fixed N, the unwanted unconditional channel is gamma epsilon^2 D[J_z]. For the CLY code,

    P J_z P=0,      P J_z^2 P=diag(4,0).

It is not a correctable scalar noise. Its leading entanglement-infidelity rate is 2 gamma epsilon^2 per block, or 4 gamma epsilon^2 for both blocks.

If a particular estimator has sigma_t approximately a/(eta_m gamma), with a calibrated dimensionless constant a, then a schematic error budget contains

    epsilon_M approximately
       8 a^2 kappa T chi^2/(eta_m^2 gamma^2)
       + 4 gamma epsilon^2 T.

Optimizing only these two terms gives

    gamma_opt^3 = 4a^2 kappa chi^2/(eta_m^2 epsilon^2),

and a residual scaling proportional to

    T kappa^(1/3) chi^(2/3) epsilon^(4/3) eta_m^(-2/3).

This is a design tradeoff, not a universal metrology bound. Readout response time, change-point estimator tails, dark counts, measurement-induced transitions and nonlinear dispersive terms can dominate it.

In particular, matching only the linear dispersive shifts is insufficient at four photons. A residual readout coupling proportional to n_a^2+n_b^2 distinguishes the codewords (values 16 and 8). A quadratic response must be proportional to N^2, with the appropriate 2 n_a n_b cross term, to remain common mode. Higher-order matching across the whole N=4 and N=3 support is a serious hardware requirement absent in a single-excitation test.

### 7.4 Recovery errors and blind intervals

A local recovery for an a loss requires the coherent isometry

    |3,0> -> (|4,0>+|0,4>)/sqrt(2),
    |1,2> -> |2,2>.

A concrete control route is number-selective photon addition using an ancilla prepared with one excitation, followed by a controlled redistribution between |4,0> and |0,4> and phase compensation. For example, selective sidebands can add one photon to the occupied error states; an eSWAP/SNAP-style sequence can restore the NOON component. The b recovery is analogous. Such selective addition and eSWAP recovery machinery is already proposed for CLY [10].

These operations are non-Gaussian and are not provided for free by the quadratic gate. They can be synthesized with conventional nonlinear ancillas and controls, but those ancillas can introduce new errors. A rail-syndrome Ramsey measurement also is not automatically protected merely because its ENDPOINT observable is parity. Ancilla decay during it can impose number-dependent phases. It requires its own error-detectable or error-transparent implementation [4,6], or its failure must be included in the logical budget.

If a block recovery has error probability epsilon_R, its contribution is approximately the expected number of recoveries times epsilon_R. If recovery lasts t_R, the three-photon error state can lose another photon during it. At small rates this contributes order kappa^2 T t_R per gate with a photon-count-dependent coefficient. Monitoring dead time and apparatus reset must be included in sigma_t and acceptance, not excluded from the cycle.

## 8. Physical circuit route and unprotected actuator errors

A concrete superconducting implementation contains four long-lived storage modes, one tunable nonlinear coupling between a and c, two total-number readout channels, and nonlinear ancillas for preparation and recovery. A weakly hybridized Duffing element q provides a familiar route to the gate:

    H = sum_i omega_i n_i + omega_q n_q
        +(alpha/2)q†²q² + sum_i g_i(a_i†q+q†a_i).

If the dressed nonlinear coordinate contains q approximately q_tilde+u_a a+u_c c, its quartic term supplies, to leading order,

    chi approximately 2 alpha |u_a|² |u_c|².

The same hybridization gives inherited loss of order kappa_q |u_i|² and self-Kerr terms of order alpha |u_i|^4. Thus chi and storage noise cannot be varied independently in a hardware resource comparison. A tunable or parametrically controlled coupler can improve the on/off ratio, but its pumps and modes introduce additional channels to model.

Known, matched self-Kerr terms are not fatal to the algebra: they are quadratic in occupations, preserve the endpoint code up to known local phases when rail matched, and their jump propagation remains a one-body phase. Unequal self-Kerr can be balanced or separately compensated, with additional control cost.

Coupler dephasing, thermal occupation, pump-amplitude fluctuations and state-dependent Purcell channels are NOT protected by the total-number monitor. For example, a jump a f(n_c) has

    P f(n_c)† n_a f(n_c) P

generically non-scalar, so its amplitude can reveal logical information at the instant of a loss. A Hamiltonian-level derivation is insufficient: one must derive the dressed Lindblad operators and test the projected Gram matrices on the full code/error spaces.

The Markov approximation also needs a bath sufficiently flat over the photon-number-dependent transition shifts. Frequency-dependent loss amplitudes can violate the assumed sqrt(kappa)a model. Finite measurement resolution leaves the explicitly computed phase uncertainty even with a flat bath.

## 9. Resource comparison without optimizing away costs

At fixed native cross-Kerr chi:

| Resource | Ordinary dual rail | This CLY construction |
|---|---:|---:|
| Storage modes for two logical qubits | 4 | 4 |
| Stored photons | 2 | 8 |
| Bare cross-Kerr CZ duration | pi/chi | pi/(4chi) |
| Integrated photon exposure | 2pi/chi | 2pi/chi |
| Consequence of one storage loss | erasure | locally correctable with timing/syndrome |
| Continuous total-number channels | optional/architecture-dependent | 2 for this route |
| Non-Gaussian local recovery | not needed to restore unknown erased state | required after a correctable loss |
| Memory loss exposure between gates | 2 photons | 8 photons |

The fourfold shorter Kerr gate exactly compensates the fourfold photon count in bare gate-time exposure. It does not erase the extra preparation energy, idle loss, photon-number-dependent hardware nonlinearity, or recovery cost. The possible advantage is converting an otherwise erased logical qubit into a recoverable local event, not reducing the first-loss probability at a fixed Kerr strength.

Let x=kappa T. For either CLY block, the probabilities of zero and exactly one photon loss are

    p0 = exp(-4x),
    p1 = 4 exp(-3x)[1-exp(-x)].

With exact correction through one loss per block,

    p_good = (p0+p1)^2,
    p_bad = 1-p_good = 12x²+O(x³).

If only a fraction eta_c of individual losses yields an accepted timestamp and all other events are flagged,

    p_accept = (p0+eta_c p1)^2.

The expected number of block recoveries per accepted gate is

    2 eta_c p1/(p0+eta_c p1).

If independent block recoveries each fail with probability epsilon_R, their exact contribution under this simple model is

    1 - [(p0+eta_c p1(1-epsilon_R))/(p0+eta_c p1)]².

Illustrative values, NOT experimentally optimized predictions:

| Assumptions | chi/2pi=10 kHz | chi/2pi=100 kHz |
|---|---:|---:|
| Single-photon lifetime | 1 ms | 1 ms |
| Bare CLY gate time | 12.5 microseconds | 1.25 microseconds |
| Probability of any loss | 9.516% | 0.9950% |
| >=2 losses in the same block | 0.1820% | 0.001870% |
| Acceptance with eta_c=0.9 | 98.864% | 99.899% |
| Accepted gates requiring >=1 recovery | 8.476% | 0.8945% |
| Error from 1%-failure block recoveries alone | 0.08662% | 0.008965% |

The table omits neither recovery nor monitoring conceptually: it separates one computable contribution from the additional contributions that require hardware parameters. It is NOT a complete predicted fidelity. In particular, it holds lifetime fixed while varying chi; a microscopic coupler generally changes both.

The physical ledger also includes:

* Preparation of four photons per code block and coherent four-photon NOON amplitudes; in-code preparation errors can evade a total-number check.
* One excitation supplied per corrected loss, selective recovery pulses, and their duration.
* Two readout modes or equivalent collective ancillas; drive power, amplification, digitization, estimator latency and continuous measurement duty cycle.
* A rail-syndrome bit for each loss and a timestamp accurate relative to the interaction area.
* Ancilla/readout reset and the associated blind windows and entropy disposal.
* Optional rail-swap echo pulses and their additional photon exposure.
* Cross-Kerr actuator noise, always-on interactions, and imperfect turn-off.

Other strong baselines must also be included in a serious decision: error-detectable bosonic gates using a programmable beam splitter and noisy ancilla [4]; path-independent ancilla control [6]; conventional error-transparent operations [11]; demonstrated erasure-biased dual-rail entanglers [12]; and engineered photon-number-dependent error-transparent controlled rotations [13]. Their native coupling rates and ancilla costs differ. The table compares only a common ideal cross-Kerr primitive and does not rank those full architectures.

## 10. Verification and the next decisive experiment

The companion Python script checks trajectory matrices on the entire four-dimensional logical input, not just chosen pure states. It includes random loss times, zero/one loss in each block, and unequal rail losses with the ideal echo. The maximum corrected trajectory residual was 3.79e-16 and the maximum non-scalar trajectory Gram residual was 9.63e-16. Without the rate-balancing echo, the tested unequal-rate no-jump instrument had a nonzero Gram residual about 1.84e-3.

Exact rational linear algebra independently checks the polynomial lower bounds while allowing arbitrary scalar offsets in every error sector:

* Globally one-loss, degree <=4: coefficient rank 29, augmented rank 30; impossible.
* Globally one-loss, degree <=5: both ranks 33; possible.
* One loss per block, degree <=5: coefficient rank 46, augmented rank 47; impossible.
* One loss per block, degree <=6: both ranks 49; possible.

Both explicit polynomial constructions have zero residual on every specified Fock support. A uniform timing-angle variance of 4e-6 gave entanglement infidelity 8.0001e-6, agreeing with the 2 variance prediction. These are mathematical consistency tests, not hardware simulations.

The most decisive next work is not a bigger ideal Lindblad simulation. It is a microscopic model or experiment of the following limited operation:

1. Prepare one CLY block entangled with a reference and a second block in several logical states.
2. Execute the Kerr gate while continuously reading total number.
3. Introduce a calibrated loss at a chosen time, then repeat with naturally occurring loss.
4. Condition only on a time posterior and error syndrome, and compare the corrected channel across all logical inputs.
5. Independently measure information leaked by the total-number apparatus in the N=4 and N=3 sectors, including nonlinear dispersive corrections.
6. Measure the FULL corrected cycle including recovery, monitor reset, extra storage dwell and coupler-induced noise.

A useful success criterion is that the measured residual conditional channel scales with timing variance and calibrated symmetry mismatch as predicted, while total corrected-cycle error and wall-clock resource use beat a specified error-detectable baseline at equal storage/coherence resources. Failure to beat that baseline would not refute the algebra; it would reject this particular route as an engineering advantage.

[5] S. Roy, O. C. Wetherbee, V. Fatemi, “Error semitransparent universal control of a bosonic logical qubit,” Nature Communications (published 8 October 2026), DOI: https://doi.org/10.1038/s41467-026-78317-y . Dynamic encoding subspaces and simple-drive single-qubit universal control are recent prior art; this is not an unexplored conceptual loophole.

[6] W.-L. Ma et al., “Path-Independent Quantum Gates with Noisy Ancilla,” Physical Review Letters 125, 110503 (2020). DOI: https://doi.org/10.1103/PhysRevLett.125.110503 . General ancilla-path independence predates this note.

[7] G. Alber et al., “Detected-jump-error correcting quantum codes, quantum error designs and quantum computation,” Physical Review A 68, 012316 (2003). DOI: https://doi.org/10.1103/PhysRevA.68.012316 . Detected-jump correction, constant-excitation protection and monitored recovery are known machinery.

[8] “A mid-circuit erasure check on a dual-rail cavity qubit using the joint-photon number-splitting regime of circuit QED,” npj Quantum Information (2025). DOI: https://doi.org/10.1038/s41534-024-00944-4 . Joint total-photon-number-sensitive control is experimentally grounded.

[9] J. S.-C. Hung et al., “Fast, High-Fidelity Erasure Detection of Dual-Rail Qubits with Symmetrically Coupled Readout,” arXiv:2604.16292 (17 April 2026). https://arxiv.org/abs/2604.16292 ; full text https://arxiv.org/html/2604.16292v1 . Symmetric continuous readout parallel with single-qubit gates has been demonstrated for transmon dual rail. Its measured performance must not be transferred directly to this N=4 bosonic construction.

[10] “Gate Set and Error Correction Protocol for the CLY Bosonic Code in Circuit QED,” APS Global Physics Summit 2026 abstract. https://meetings-archive.aps.org/smt/2026/mar-b09/2/ . This is a conference abstract, not a fully inspected peer-reviewed implementation; it explicitly describes CLY single-qubit error-closed gates and parity/selective-addition/eSWAP recovery.

[11] “Error-transparent operations on a logical qubit protected by quantum error correction,” Nature Physics (2020), DOI: https://doi.org/10.1038/s41567-020-0893-x . Experimental bosonic error-transparent phase gates are established.

[12] “An entangling gate for dual-rail erasure qubits,” Nature (2026), DOI: https://doi.org/10.1038/s41586-026-10822-y . A fast experimentally demonstrated erasure-biased entangler is a stronger practical comparator than an unprotected abstract gate.

[13] C.-H. Wang, K. Noh, J. Lebreuilly, S. M. Girvin, L. Jiang, “Photon-Number-Dependent Hamiltonian Engineering for Cavities,” Physical Review Applied 15, 044026 (2021). DOI: https://doi.org/10.1103/PhysRevApplied.15.044026 ; preprint https://arxiv.org/abs/2009.07855 . The work engineers arbitrary number-dependent Hamiltonians and specifically includes error-transparent controlled rotations between cavities. High-degree logical entangling Hamiltonians are therefore an established baseline; the code-specific minimal degree proved here is the limited additional statement.

The only novelty position justified at present is a candidate explicit combination and a proved code-specific polynomial-degree tradeoff. A complete priority search, a microscopic device optimization, and a full fault-tolerant resource comparison remain open.

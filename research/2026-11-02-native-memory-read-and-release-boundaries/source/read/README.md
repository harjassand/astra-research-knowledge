# Terminal READ and remaining capability gates

Read construction/NOISY_TERMINAL_READ_THEOREM.md and FRESH_NOISY_READ_AUDIT.md.

This is a conditional terminal quantum READ theorem under a specified local-stochastic access-fault model and independently admitted FT resource/output interfaces. It is not a construction of the actual access Hamiltonian or a noisy WRITE/complete usable memory. The split-tail proof avoids an artificial exponentially temperature-dependent read-fault threshold. Resource correlations, classical errors, and decoded FT-output error are explicitly charged.

construction/RESOURCE_CONSEQUENCE_AUDIT.md distinguishes extreme sufficient certificates from physical lower bounds and explains why ideal Gibbs preparation plus FT compilation does not automatically solve native-output release. The quotient and stationary-envelope observations are admission criteria, not built loaders. static_loading_test/ gives a restricted thermal cursor obstruction; no static native counterexample or universal warm-start no-go is claimed.

The complete previously delivered robust-native package is included as a prerequisite. Its actual-equilibrium ideal endpoints remain assumptions.

Finite check: Python3/numpy, construction/root_bell_read_check.py. It exhausts 1024 Pauli Bell outcomes on the actual five-qubit seed with coherent syndromes/reference, verifying normalized full-space decoder extraction. It is not a noisy full-family simulation.

The explicit small-scale alternative family is being investigated separately and is not certified by this package.

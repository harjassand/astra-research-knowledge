Theorem scope is the full trace over every clock. It covers free/deleted-edge finite volumes and periodic finite volumes with the stated bounded degree. Arbitrarily pinned excited boundary clocks are not covered: a static excited prefix can reverse a neighboring check's loop sign. Such boundary constraints need their own explicitly charged boundary interaction, not the same uniform leading J0 assertion.

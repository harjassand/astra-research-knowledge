## Exact discarded-program task
For U=I,Z and white reset, the actual labelled-and-discarded program is a Phi_U+bI with a=p/4,b=(1-a)/9. The two Choi vectors are orthogonal and the states commute. Their affinity is r=7b+2sqrt[b(a+b)]=1-(sqrt(a+b)-sqrt b)^2. The tensor-product affinity is r^n; independent omega programs and known ancillas do not change it. TV<=sqrt(1-r^(2n)) gives Bayes error >=r^(2n)/4. A complete diamond error zeta for the sharp projector or deterministic inverse yields a perfect-target discrimination experiment with error <=zeta/2. Thus n>=log(1/(2zeta))/(-2 log r). Exact expansion gives -2log r=(9/32)p^2+O(p^3), and r(1)=11/12. This bounds the specified mixed-program tasks, not all ways to retain labels or query channels.

The result q^n rho_R<=rho_U<=(9p+q)^n rho_R is valid also for subnormalized heralded branches; it must not be applied after an uncharged normalization. The all-reset-history common component separately gives error >=q^n for deterministic perfect-distinguishing retrieval.

The two-sided order is stronger: accepted retrieval Choi operators have the same support. Distinct exact inverse-unitary or accepted projector Choi lines cannot both contain a nonzero common support. If one accepted map vanished, the same upper/lower order forces the others to vanish too. Hence no finite q>0 program can implement these tasks exactly with positive heralded success, even with adaptive finite training and abort. This argument is for storage completed before an independent data input; new data-dependent channel queries and source-known operations are excluded.

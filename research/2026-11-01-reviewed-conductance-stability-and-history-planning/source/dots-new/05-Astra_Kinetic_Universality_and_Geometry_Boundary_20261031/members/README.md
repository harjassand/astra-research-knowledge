# Accepted unknown-transverse-mobility conductance family

This local package preserves the source-bound exact open attainable-range theorem and separately scoped family receiver, plus all accepted homogeneous/parallel/finite dependencies. The model family is every fixed finite SPD transverse matrix, with unit longitudinal mobility, zero cross mobility and matching reversible drift/noise. A particular physical model's membership is NOT authenticated from its potential.

The exact attainable range is open(k_parallel,k_free); both endpoints are limiting values, not attained by finite SPD matrices. The receiver numerically produces a closed OUTER enclosure, not the exact lower endpoint or an inverse mobility. The raw513D example receives every member in [2.369045057852262e-37,2.384988210037886e-37], ratio1.0067297800574877<1.01, without matrix entries. All raw/finite scalar work and actual verification replay are paid.

Run python -B check_family.py in homogeneous_entropic_capacity_20261031/transverse_mobility_family. This includes a costly513D replay and can take minutes. Python standard library only.

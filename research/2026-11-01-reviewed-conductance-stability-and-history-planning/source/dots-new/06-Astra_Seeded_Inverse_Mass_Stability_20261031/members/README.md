## What is established

For all positive rates in

```
0 <-> A
2A+B <-> A+B+C
2A+C <-> A+2B
A+B+C <-> A+2C
```

every closed communicating class is positive recurrent and every stationary
distribution has all finite exponential total-count moments. Positive rational
rate input admits exact certificate acquisition. The main non-complex-balanced
fixture sets every rate to one except `A+B+C -> A+2C`, whose rate is two.

The proof genuinely crosses an extinction face missed by the previous leading-support
cone: all cubic source complexes require A. For A>=1, strip the common A to obtain
the exact shifted internal generator `A Q(A-1,B,C)`. An acquired inverse mass
`1+c/(A+eta B)` retains the hidden mediator. A separately paid A=0 patch handles
last-copy death at rate mu and seed immigration at lambda; neither is suppressed.

No positive normlike function of only `(A,N)` can satisfy a one-step geometric Foster
inequality on one closed positive-satellite class. Standard linear and chemical
entropy templates also have explicit failure controls. These are template/representation
results, not claims that all conventional tier or sampled-time methods fail.

The qualitative receiver spends the retained theorem that halving terminates for
all positive rates; it performs only finite raw recognition. A capped numerical run
can return `UNKNOWN` while its separate qualitative conclusion remains certified.

The generic finder is broader but only sufficient. At one requested t, a successful
generic profile proves that t^N moment, **not automatically every exponential moment**.
All-t termination is proved for the displayed hard skeleton and the valid zero-weight
profile branch. Every rational generic profile is eventually enumerated without a
budget; failure within a budget means UNKNOWN. The lifted opposing-pure-ray fixture
has no inverse-linear profile at all, by contradictory weight-order inequalities;
its stability is not decided here.
The `(A,N)` no-go even holds at the hard family's all-unit-rate parameter point,
where unit concentrations are complex balanced and classical Poisson product form
already proves stability. Thus the no-go measures lost representation information;
it is not, by itself, evidence of a difficult or new recurrence theorem. The executed
alpha3=2 fixture is deliberately outside that classical complex-balanced case.

## Costs that were not hidden

The main fixture at t=2 uses nine eta trials; eleven are a proved sufficient bound.
It returns eta=1/2048 and a safe exception box containing **3,462,766,534,656** states.
That box was **not enumerated**. Its Foster constant has a power of two with exponent
**3,692,711**, stored exactly in factored form, **not expanded**. The bounds are
conservative; no claim of efficient numerical tails is made.

Main tests executed 6,366 ordinary states and 518 targeted boundary/huge states,
including counts 10^50, seven parameter/architecture cases, six coordinate
permutations, fifteen semantic corruptions and fifteen invalid-input controls.
These finite tests supplement the ordinary all-state proof, not replace it.
Independent test counts are recorded separately and must not be silently merged
with the author's counts as if they were disjoint states.

Profile budgets do not cap input validation, graph work, rational bit arithmetic,
termination-bound preprocessing, memory, or output bit length. Search records retain
actual trial/source evaluation counts and a peak size of retained rational records,
not a bound on every transient arithmetic operand.
In a capped generic search, the legacy metadata name `last_denominator` records the
current **cap-check cursor**, not necessarily the last denominator actually tested.
For example, after all four denominator-one profiles in two dimensions, a cap of
four stops at cursor two. Actual profile/source evaluation counts remain exact.

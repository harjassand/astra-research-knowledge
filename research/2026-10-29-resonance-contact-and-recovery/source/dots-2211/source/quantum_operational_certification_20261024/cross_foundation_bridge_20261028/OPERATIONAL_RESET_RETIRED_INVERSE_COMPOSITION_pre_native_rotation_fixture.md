# Retired-record inverse learning with operational rather than microscopic restarts

28 October 2026. Candidate composition. Depends separately on the corrected operational-reset theorem and the received ordinary retired-record phase-inverse and finite-reuse theorems. It does not claim that a certified mixing word creates the required phase-calibration family.

## 1. Configuration first, fresh fit afterward

An initial paid pilot yields a valid quotient core and an interval certificate for a selected physical reset word R, with c<1 and K. Freeze its configuration omega. All statements below are conditional on that accepted configuration; its operational-limit law L_omega may differ from another configuration's limit. No unconditional erasure of omega is asserted. A finite initial reset/core acquisition bank remains a substantive resource unless an actual separate bootstrap supplies it.

Require the following ADDITIONAL interface: under L_omega, each specified fresh one-qubit calibration experiment has the stationary reduced phase family Ad_Vtheta after Z-dephasing with contrast a_omega>0. The service slots have the SAME fixed Vtheta after arbitrary complete native joint maps, as required by the retired-record theorem. Native maps may retain coherent memory and react to earlier service outputs, but cannot inspect the private final-fit program except through the declared receiver gates. The structural phase-family promise and fixed Vtheta are not inferred from a quotient contraction certificate.

The final calibration bank is FRESH after omega is frozen. Its N and finite root-grid size K_grid are chosen from supplied or separately valid pilot lower bounds on a_omega. Do not reuse data that selected omega as though it were a fresh symmetry-covariant fit. If a further contrast pilot determines N, the final fit is fresh conditional on both pilots. Both pilot records may remain private control configuration, but the final-fit record and learned angle must be genuinely retired from source and external-controller access as in the governing retired-record theorem.

## 2. Replace the actual independent-start interfaces

Before each of the N final-fit probes, execute t repetitions of the frozen reset word. Before the whole J-slot service, execute another t repetitions. This pays N+1 operational resets, NOT a fresh reset between the J service slots: their arbitrary continuing memory is already covered by the finite-reuse theorem. Set

    kappa = min(1,2K c^t).

The reset theorem includes arbitrary retained record/reference correlations and every finite subsequent controller, so the complete joint distribution/process differs by at most (N+1)kappa from the reference protocol with independent operational-limit starts. The reference source law may be defined by limits of actual long fixed-word resets; no stationary hidden density or finite hidden CP realization is assumed. For rigor, use the EXACT limit-law calibration distribution to define the independent classical program distribution, and combine it with a sequence of independently prepared finite physical reference service states obtained by longer reset words. The retired-record proof permits ANY independent joint service source with the same Vtheta, so its derivative/cancellation bound applies to each such service state. Then pass to the operational service limit. Do not claim that a finite reference reset already produces the exact phase-calibration distribution. The bound is independent of hidden dimension and finite reference-service reset depth.

For fixed configuration and theta, the reference FINAL-fit records are independent of service memory by construction. Their phase-error symmetry is exactly the governing reference learner's symmetry. Averaging over those records is legitimate only after their actual retirement. It is NOT justified merely because the microscopic memory is unobserved.

## 3. Quantitative bound with all reset uses paid

Let v=4/a_omega^2-1. The finite-reuse source gives the reference error

    r_N,J <= min(1, (pi^2/4) J^2 v/N
                         + pi(sqrt(N)+J)/(2K_grid)).

The compiled real process therefore has final record-retired half-distance at most

    min(1, r_N,J +(N+1)kappa + beta_pilot + nu_all),

where beta_pilot includes invalid core/reset/contrast pilot events and nu_all is the WHOLE calibration, reset, control, program and service implementation discrepancy. If analyzing conditional acceptance rather than a protocol sharing the same abort branch, retain the acceptance denominator. A conditional pilot guarantee does not become an unconditional high-throughput promise.

Choose power-of-two K_grid as in the received source and t so kappa<=epsilon/[4(N+1)]. Then the physical source bill is

    initial valid pilot/core work
    + N calibration calls
    + (N+1)t L_R reset-word native calls
    + J service calls,

in addition to actual preparations/readouts, finite random bits, program isolation, rotations, routing and storage. At fixed acquired K,c<1 and a_omega>0, sufficient N is O(J^2/(a_omega^2 epsilon)) and t=O(log((N+1)/epsilon)/(-log c)). This is a theoretical bound, not a practical resource claim. Weak mixing, small contrast, control noise or large J can make it unusable.

For one service use, substitute the sharper one-use reference bound v/N+pi(sqrt(N)+1)/(2K_grid). The coarse J^2 expression is not needed at J=1 but gives the same order.

## 4. Configuration averaging and failure modes

If every accepted configuration has a valid conditional reference theorem and a declared conditional risk bound r(omega), then averaging gives E[r(omega)] plus the corresponding failure/implementation allowances. This is a mixture of configuration-specific comparators. If the desired comparator must itself be independent of the pilot selection, prove that the limits/targets agree or choose the configuration independently; conditioning alone does not establish that.

One post-fit reset is insufficient when the final-fit records were drawn from a correlated nonstationary source: it may decorrelate the service memory but does not restore the estimator's reference distribution or conjugation symmetry. Every start used by the reference statistical proof is replaced and paid.

Choosing between two exact c=0 pointer replacers using a retained pilot bit also does not erase that bit: their limits differ. The corrected reset source preserves this counterexample. The present composition conditions on the frozen configuration and uses a genuinely fresh fit rather than hiding this selection information.

This result does not solve generic no-reset core acquisition, discover the phase-family promise, provide arbitrary noncommuting retired-record recovery, or prove a new quantum-computing threshold. Standard burn-in combined with a valid reference learner is the equally informed competitor. Its potential contribution is a complete operational certificate when the actual environment never resets or even possesses a stationary normal state.

# Derived native recovery certificate for the learned decoder

28 October 2026. Separate derived endpoint; independent audit pending. These files were added AFTER the initial localization demonstration, and are not covered by its original author manifest/receipt unless a later receipt names them.

The fixed decoder quaternion comes only from main_8192. Its site was selected by that bank's accepted localization guard. The independently generated larger_65536 bank supplies all validation contrasts. Neither source rotation, lambda/epsilon, true logical site nor true oracle score enters derive_holdout_schur.py.

For a qubit, C_j=(m_j.sigma)/2. The predeclared simultaneous coefficient radius eta therefore implies the exact valid operator allowance a<=sqrt(3)eta/2. This improves only the dimension conversion; it does not invent a new confidence event. The script uses an upward rational square-root bound.

The candidate is exactly physical by its integer-quaternion construction. Its Bell projection P has rank1. Consequently the empirical stationarity block Z has rank<=1, so ||Z||op^2=Tr Zdagger Z exactly; the script computes this rational quantity. A lower transverse gap is checked by all15 exact principal minors of W-kappahat(I-P). No floating eigenvalue alone is accepted as a certificate.

The local regret comparison is against ALL CPTP decoders on the selected site. The global recovery-oracle comparison additionally uses successful localization and the same stationary source across banks. A conservative failure union is .01 for main-bank localization plus .01 for the holdout coefficient event. This is not a posterior probability conditioned on the displayed scores.

This is a post-demonstration derived mathematical certificate, not a separately preregistered experiment. The candidate used for this calculation is a function only of the earlier independent training bank, and the validation confidence radius was fixed before its data were generated. No terminal unknown-payload recovery experiment, decoder gate synthesis or hardware execution was performed. The output is an explicitly specified physical decoder and a finite-data native fidelity-regret certificate under the declared interfaces.

# Actual flagged five-qubit storage EC: exact one-fault construction

28 October 2026. Status: construction and exact executable enumeration; independent review pending. This instantiates **known** Chao–Reichardt fault-tolerant EC, not a new code or new flag method. Primary: Rui Chao and Ben W. Reichardt, *Quantum error correction with only two extra qubits*, arXiv:1705.02329v1, §II and Fig. 2, https://arxiv.org/html/1705.02329v1#S2 . The original unflagged `IIZXI` hook and its logical failure are already in that source. This note closes an implementation obligation in the Astra storage bridge; it does not claim historical novelty for the gadget.

## Actual circuit and adaptive rule

Data stabilizers are `XZZXI, IXZZX, XIXZZ, ZXIXZ`. For each stabilizer, visit its four nonidentity data positions in increasing physical index. Prepare syndrome s in |0> and flag f in |+>. Measure data Z parity with CX(data,s); measure data X parity with H(data), CX(data,s), H(data). Insert CX(f,s) after the first and before the fourth data parity coupling. Measure s in Z and f in X. The X measurement/preparation are native single-qubit operations; the X-parity couplings are explicitly decomposed into H/CX/H.

Run the four flagged checks in listed order. Stop at the first flag or nontrivial syndrome. On stopping, take **one fresh full unflagged syndrome pass** and physically apply the corresponding correction as conditional native single-qubit Pauli gates. If flag=1, use that check's flag-error lookup table; otherwise use the unique weight≤1 correction. Flag takes precedence if both outcomes are nontrivial. If all four checks are trivial, do nothing. There is no two-consecutive-identical-syndromes rule.

The executable generates each flag table from all single local Pauli faults in that check and verifies syndrome uniqueness modulo the stabilizer. Its first two tables are explicitly verified equivalent modulo the stabilizer to the primary paper's two written correction lists. For checks 3 and 4, the ascending-support choice supplies the paper's “similarly” prescription and is separately exhaustively checked. A representative in the generated table need not equal the printed representative: for example `IIXZX` differs from `IXXII` by stabilizer `IXZZX`.

## Exact verified claims

Program: `flagged_five_qubit_storage_check_20261028.py`; full machine-readable cases: same stem `.json`.

1. All 16 identity/weight-one input Pauli errors are corrected modulo stabilizer by the fault-free complete adaptive gadget.
2. Starting from a clean arbitrary encoded state, each of **1,528 nonidentity single-Pauli fault cases at 424 reached locations** leaves a stabilizer-equivalent weight≤1 data error after the physical correction. Zero failures.
3. The fault set includes all 15 post-CX two-qubit Paulis; all three post-H and post-preparation single-qubit Paulis; measurement outcome and subsequent classical readout flips as separate locations; and all three Pauli faults on every unused qubit at each serial step. Conservatively, inactive or already measured ancilla idles are also counted, though many cannot affect output. Initial preparations reset reused ancillas. Classical correction lookup and adaptive controller logic are trusted; only readout-bit flips are charged as classical faults.
4. Every flag table has no syndrome collision between inequivalent code actions. The stabilizer group size and commutation are checked. The 16 weight≤1 representatives have 16 distinct syndromes.

Why fresh-pass fault locations are absent from the clean-input single-fault list: the ideal clean trajectory reaches only the four flagged checks. Reaching a fresh pass requires a flag/nontrivial syndrome, which on a clean input already requires the unique fault to have happened. Thus a sole fault cannot first occur inside the fresh pass. The same reasoning applies to the conditional correction-gate and correction-idle locations, which are implemented and fault-injectable but are inactive on the ideal clean path. This is a reachability fact, not an omission of a vulnerable second fault. In contrast a nonzero input error plus a fault in that pass is a two-event case and is not asserted correctable.

## Linear-span extension, not just stochastic Pauli sampling

Let C encode one qubit and let S be the stabilizer. All enumerated residual operators acting on C are, up to scalar, in the same space span{E C : wt(E)≤1}. This is stronger than merely giving every fault an individually convenient decoder. That space has a **single common ideal recovery**: distinct weight-one errors have distinct stabilizer syndromes, and same-syndrome residual representatives differ by stabilizers. Consequently their Knill–Laflamme products are scalar on the code. Expanding an arbitrary single local faulty Kraus operator in the local Pauli basis, propagating through ideal Clifford gates, and conditioning on each classical record therefore leaves a linear combination in this common correctable span. Discarding or keeping records does not change the logical identity after common ideal recovery. No twirling assumption is used. A faulty preparation means arbitrary local preparation after reset; a faulty terminal measurement/readout means arbitrary local outcome corruption. Clean-trajectory measured ancillas are otherwise disentangled from the encoded state. Arbitrary corruption of lookup/controller logic, leakage, nonlocal crosstalk, and a shared uncontrolled bath are outside this model.

The physical gadget's output need not lie in the exact code space. A late one-qubit fault can remain. The claim is *correctable output*, not perfect physical reset, and the final ideal decoder used in a logical assessment is not supplied as a free hardware component.

## Resource bill and interfaces

Two reused ancillas, five data qubits. A flagged check has 6 CX, 4 H, two preparations, two measurements, two readout slots (16 serial primitive/readout slots), plus 90 conservative unused-qubit idle locations. An unflagged check has 4 CX, 4 H, one preparation, one measurement, one readout (11 slots), plus 62 idle locations. The longest branch has four flagged checks followed by four unflagged checks: **40 CX, 32 H, 12 preparations, 12 measurements, 12 readout slots**, 108 serial slots and 608 conservative idle locations, 716 locations before physical correction. A flag correction has weight at most three and adds at most three native single-qubit Pauli gates and 18 conservative idle locations, giving **111 slots and 737 total locations** for this implementation. These are upper bounds, not an optimized hardware schedule. The clean trivial branch has 24 CX and 424 counted locations. The |+> preparation and X measurement require calibrated local axes; if physically compiled into extra H gates, their additional locations must be charged, not assumed free.

Corrections are physically applied, not merely recorded in a Pauli frame: an initially unknown non-Pauli next source need not respect a tracked frame. Their calibrated single-qubit operations, conditional control, and idles are explicit. The controller and lookup logic remain trusted, not supplied as fault-tolerant classical hardware. Initial unknown-input encoding/injection and eventual physical decoded readout remain separate one-off interfaces. This construction does not make an unencoded unknown input fault-tolerant before redundancy exists.

## One storage-cycle first-order cancellation

Consider a specified composed circuit with: an initially ideal encoded input; a native-noise / acquired-frame local receiver stage; this actual EC gadget; and an **ideal final decoder only for the logical-channel definition**. Suppose the receiver's existing interleaving contract guarantees that an isolated native or frame fault enters the EC as an operator on at most one physical data qubit of this code block. Each isolated receiver fault is corrected by claim 1. Each isolated EC fault on clean input is correctable by claim 2, and is removed by the ideal final decoder. Thus every single local replacement fault yields the identity logical channel. A gate that spreads one fault across two data qubits is not covered by this premise merely because its norm is small.

More explicitly, unroll the bounded classical adaptive circuit with controlled/padded slots. Require an actual ordered local-CPTP gate/instrument model with trusted classical control, not merely reduced local noise marginals. For each slot i let epsilon_i bound the diamond norm of actual minus ideal operation on its full allowed local interface. Expanding each slot as ideal plus difference, the empty term is identity and every singleton term vanishes after logical decoding. The exact bound is

    || Logical_actual - id ||_diamond
       ≤ product_i(1 + epsilon_i) - 1 - sum_i epsilon_i
       ≤ exp(sum_i epsilon_i) - 1 - sum_i epsilon_i.

It is quadratic when the total error budget is small. If epsilon denotes half-diamond distance instead, substitute 2 epsilon in this expression. Syndrome-gate and idle errors are included in the same budget as receiver/native errors, so the idealized one-cycle logical metric has no uncharged first-order syndrome term. No useful threshold constant is inferred from the conservative 737-location union bound.

This is **not** a repeated-storage theorem. A single fault can leave a syndrome-bearing physical output; another nearby fault in the next round can interact with it. Multiplying independent decoded-round bounds would silently insert an ideal reset/decoder between rounds. Repeated storage needs a separately proved extended-rectangle / paired-fault analysis, with time-correlations and the actual initial/final interfaces retained. This note does not alter earlier received ideal-QEC bridge sources and does not certify those missing interfaces.

# Why the corrected-code calibration rates do not contradict the earlier fixed-workload lower bound

28 October 2026. Scope note; no earlier governing source changed.

The received retired-inverse reuse lower bound in ordinary_retired_inverse_finite_reuse_20261028.md fixes a GHZ encoding and simultaneous J phase exposures. It permits arbitrary collective final recovery but explicitly excludes changing that encoding/workload. Its Omega(J²/epsilon) ordinary-calibration conclusion concerns that fixed logical phase-sensitive task.

The interleaved five-qubit architecture changes the encoding so that every single-local-channel error is exactly correctable. In its separate private/independent-program one-cycle specialization, local averaged inverse error is O(1/N), and product-code cancellation makes the logical error O(1/N²) when native noise is negligible. This is not an inference that the same GHZ workload beats its lower bound. It is a different protected operation with five physical carriers per logical qubit, actual known encoding/syndrome resources, independently acquired programs across sites, and a restricted one-cycle record-retired interface.

Likewise the record-retaining Omega(epsilon^-2) inverse-calibration lower bound concerns complete joint inverse approximation before such a code changes the task. A code can protect logical information without making the uncoded physical inverse globally accurate. No lower bound for the unchanged metric/task is refuted.

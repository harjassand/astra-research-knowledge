## 2. Constructing recovery that cannot execute a logical error

The cooling failures identified the right obstruction: reaching the code space does not determine which logical state arrives there. I therefore constructed the recovery operators in a coordinate system that tracks logical action everywhere.

Use the established perfect five-qubit code, with stabilizers

\[
S_1=XZZXI,\quad
S_2=IXZZX,\quad
S_3=XIXZZ,\quad
S_4=ZXIXZ.
\]

The five-qubit code corrects an arbitrary one-qubit error; that foundation is established prior work. :chatgpt-content-reference{index="0"}

Let \(P\) be its code projector. Every nonzero syndrome \(s\) has a unique one-qubit Pauli representative \(E_s\), and \(E_0=I\). Define

\[
U|\ell,s\rangle=E_s|\ell_L\rangle.
\]

There are sixteen two-dimensional syndrome sectors. They fill the entire 32-dimensional data Hilbert space, so \(U\) is a full unitary identification

\[
\mathcal H_D\simeq\mathcal H_L\otimes\mathcal H_S.
\]

This matters: the recovery proof applies to all data states, including states reached after overlapping faults.

### Operators that change the error label

For physical site \(i\) and Pauli \(\alpha\), construct

\[
B_{i\alpha}
=
\frac14
\sum_{\substack{S\in\mathcal S\\S_i=\alpha}}
S E_{i\alpha},
\]

where \(\mathcal S\) is the stabilizer group.

Each \(B_{i\alpha}\) is a sum of **four weight-three data Pauli terms**. Its exact action is

\[
B_{i\alpha}E_{i\beta}P
=
E_{i\beta}E_{i\alpha}P,
\qquad
\beta\in\{I,X,Y,Z\},
\]

and it vanishes on single-error sectors belonging to other sites. Consequently,

\[
\boxed{
U^\dagger B_{i\alpha}U=I_L\otimes b_{i\alpha}.
}
\]

The operator changes the error label while preserving the logical factor.

For example, for the representative \(E_s=IXIII\),

\[
B_s=\frac14
\left(
IIZZX+XIYIY+YIXYI+ZIIXZ
\right).
\]

The Pauli phases in this construction matter. They give the recovery the correct action on superpositions and on error-to-error transitions.

### Making the clean code exactly dark

The Hermitian \(B_s\) operators alone also drive the clean code outward. To obtain a recovery with an exactly dark clean state, add

\[
C_s=-i[P,E_s],
\qquad
A_s=\frac12(B_s+iC_s).
\]

Each \(C_s\) expands into eight weight-four data Pauli terms. In corrected coordinates,

\[
U^\dagger C_sU
=
I_L\otimes
\left(
-i|0\rangle\langle s|
+i|s\rangle\langle0|
\right).
\]

The resulting \(A_s\) has a directed error-to-clean component, together with retained error-to-error components, and obeys

\[
A_sP=0,
\qquad
U^\dagger A_sU=I_L\otimes a_s.
\]

These identities construct the recovery service. They imply that every intended recovery path, including coherent excursions through other error sectors, preserves the logical factor. Products of recovery operators cannot accumulate a hidden logical Pauli.

## 3. The literal six-qubit model

Add one controller qubit \(a\), with \(n_a=|1\rangle\langle1|\). The Hamiltonian is

\[
H_D=
g\sum_{j=0}^{3}2^j\frac{I-S_{j+1}}2,
\]

\[
\boxed{
H=
H_D+8g\,n_a+
\frac g2\sum_{s=1}^{15}
\left(B_sX_a+C_sY_a\right).
}
\]

The controller has one engineered reset,

\[
L_{\rm reset}=\sqrt{8g}\,\sigma_a^-.
\]

Writing

\[
\mathcal D[L](\rho)
=
L\rho L^\dagger-\tfrac12\{L^\dagger L,\rho\},
\]

the Pauli-noise model is

\[
\boxed{
\mathcal L(\rho)
=
-i[H,\rho]
+8g\,\mathcal D[\sigma_a^-](\rho)
+\gamma\sum_{i=1}^{6}\sum_{\alpha=X,Y,Z}
\mathcal D[\sigma_i^\alpha](\rho).
}
\]

All terms act continuously and simultaneously. The calculation keeps the full Hamiltonian, controller, reset, and ambient noise. It uses no rotating-wave approximation, adiabatic elimination, or intervening correction operation.

The physical resources are:

| Resource | Count or value |
|---|---:|
| Data qubits | 5 |
| Controller qubits | 1 |
| Engineered dissipators | One one-qubit reset |
| Weight-four coupling terms from \(B_sX_a\) | 60 |
| Weight-five coupling terms from \(C_sY_a\) | 120 |
| Data stabilizer terms | 4, each weight four |
| Controller field | 1, weight one |
| **Total nonidentity Hamiltonian terms** | **185** |
| Largest/smallest nonzero coherent coefficient magnitude | 64 |

All constituents have dimension two. The actual coefficient magnitudes range from \(g/16\) to \(4g\).

The model therefore has a small Hilbert space and moderate coefficient ratios, but a demanding interaction requirement. The 120 weight-five terms are genuine primitives of this result. A microscopic synthesis of those terms from simpler interactions has not been supplied.

## 4. The certificate measures logical exposure

Your proposed opening—replacing a whole-channel approximation estimate by a logically relevant, noise-weighted certificate—works for this construction.

For each data site \(i\), define the four-syndrome subspace

\[
\mathcal U_i=
\operatorname{span}
\{I,X_i,Y_i,Z_i\}\mathcal C,
\]

and let \(Q_i\) project onto its complement.

Every operator on physical site \(i\) preserves \(\mathcal U_i\) and acts there as logical identity in the chosen frame. Therefore a further fault on that site can change the decoded logical state only through the part of the actual state outside \(\mathcal U_i\).

For the perfect code,

\[
\sum_{i=1}^{5}Q_i=4Q_D,
\]

where \(Q_D\) projects onto nonzero data syndrome, irrespective of controller state.

Suppose site \(i\) has noise

\[
\mathcal N_i
=
-i[h_i,\cdot]+\sum_\alpha\mathcal D[L_{i\alpha}],
\qquad
r_i=\|h_i\|+\sum_\alpha\|L_{i\alpha}\|^2.
\]

For any norm-one Hermitian observable on the logical qubit and an arbitrary reference, the adjoint noise derivative is supported on \(Q_i\) on **both sides**. Its norm is at most \(2r_i\). Trace-norm duality then gives

\[
\boxed{
\epsilon(T)
\le
\sup_{\rho_{LR}}
\int_0^T
\sum_i r_i\,\operatorname{Tr}[Q_i\rho(t)]\,dt.
}
\]

This statement retains syndrome coherences and logical-reference correlations. It does not replace the physical noise by syndrome-conditioned jumps.

For equal Pauli rates, \(r_i=3\gamma\), giving

\[
\epsilon(T)\le
12\gamma\int_0^T q_D(t)\,dt.
\]

For one amplitude-damping jump of rate \(\gamma\) per data site, the coefficient is \(4\gamma\).

### Certifying the occupation under continuing noise

For the actual noise-free engineering generator \(\mathcal G_0\), I constructed an internal Hermitian witness \(V\) satisfying

\[
0\le V\le\frac7g Q_0,
\qquad
VP_0=0,
\qquad
-\mathcal G_0^\dagger(V)\ge Q_D.
\]

Here \(P_0\) is clean syndrome with controller vacuum, and \(Q_0=I-P_0\).

The summed unit-rate physical Pauli-noise drift satisfies

\[
\mathcal N_P^\dagger(V)
\le
\frac{c_P}{g}I,
\qquad
c_P=\frac{72847817}{1048576}.
\]

This inequality is checked on the **full 64-dimensional physical Hilbert space**. It does not assume that the syndrome marginal evolves independently of the logical state.

Under the actual noisy evolution,

\[
\frac{d}{dt}\langle V\rangle
\le
-q_D(t)+\frac{c_P\gamma}{g}.
\]

For encoded input and controller vacuum, integration gives

\[
\int_0^Tq_D(t)\,dt
\le
\frac{c_P\gamma T}{g}.
\]

Combining the two inequalities proves the stated \(\gamma^2T/g\) channel bound.

Every subsequent fault remains in this evolution. There is no cutoff on the number of faults and no assumption that recovery finishes before another one occurs.

### What makes the proof exact

Floating-point calculations proposed the witness. The admitted witness has Gaussian-integer entries divided by \(2^{44}\). The replay verifies positivity and generator inequalities using exact integer arithmetic, with exact checks binding the certified Hamiltonian to the physical Pauli recipe.

The 44-bit denominator is **proof precision**. It is not a requirement to manufacture interaction coefficients to 44-bit accuracy.

The full-channel numerical error and the exact upper bound differ by only about four percent at the main operating point. That close agreement is useful evidence that the occupation certificate captures the relevant failure mechanism without paying for harmless internal dynamics.

## 5. Finite recovery, controller faults, and the output interface

A second exact witness \(W\) certifies finite response:

\[
\frac{Q_0}{4g}\le W\le\frac8gQ_0,
\qquad
\mathcal G_0^\dagger(W)\le-Q_0.
\]

For the actual intended recovery dynamics without further ambient noise, this implies

\[
\int_0^\infty
\Pr(Q_0,t)\,dt
\le\frac8g,
\]

and

\[
\Pr(Q_0,t)
\le
\min\{1,32e^{-gt/8}\}.
\]

These are unconditional population and integrated-occupation bounds. A reset event is not assumed to announce completed recovery; a reset can leave residual syndrome occupation or coherence.

The continuing-noise theorem above uses the complete noisy evolution throughout. It does not splice together isolated recovery episodes.

### What controller noise can do

In corrected coordinates, the intended Hamiltonian and reset act as logical identity on the entire internal space. Every controller-only operator does too.

Consequently, controller faults alone cannot change the decoded logical information, even during arbitrarily overlapping controller excursions. They can heat or stall the syndrome dynamics, increasing the exposure to subsequent data faults. That effect is included in the occupation drift.

Perfect controller initialization is also unnecessary for a useful bound. An initial excitation probability adds a calculable transient term. At the main operating point, a certainly excited controller adds approximately \(0.00137\) to the Pauli bound.

### Input and output

The theorem has two declared boundary services: encoded input and one final decoder.

At readout, one can measure the four stabilizers, apply the corresponding \(E_s\), and decode the five-qubit code. Equivalently, the mathematical decoder applies \(U^\dagger\) and discards syndrome and controller.

Readout can occur at the requested time, including during an unfinished recovery excursion. There is no need to wait for a reset flag.

No ideal correction is supplied during storage. If the encoder and final decoder are themselves imperfect, their channel errors contribute additional boundary terms. The bulk memory theorem does not silently provide fault-free physical I/O.

## 6. Protection beyond Pauli noise

The same physical mechanism earns a broader theorem.

At each of the six sites, allow arbitrary time-dependent one-site Hamiltonian and Lindblad noise with

\[
\|h_i(t)\|
+
\sum_\alpha\|L_{i\alpha}(t)\|^2
\le r.
\]

Then

\[
\boxed{
\epsilon(T)\le
\min\!\left\{1,\frac{336r^2T}{g}\right\}.
}
\]

The proof is short once the physical algebra is established. The six sites contribute at most \(84r/g\) to the witness drift because \(\|V\|\le7/g\). The five data sites contribute logical hazard at most \(4r\,q_D(t)\). Multiplying the resulting occupation bound by that hazard gives \(336r^2T/g\).

The strength convention matters: three Pauli channels of rate \(\gamma\) correspond to \(r=3\gamma\). The specialized Pauli certificate has a much sharper constant.

### Amplitude damping

For five actual data jumps \(\sqrt\gamma\,\sigma_i^-\), with controller \(X,Y,Z\) noise retained, the exact bound is

\[
\epsilon_{\rm AD}(T)
\le
4\frac{20099433}{1048576}
\frac{\gamma^2T}{g}.
\]

At the same operating point:

- full-channel entanglement fidelity is approximately \(0.999787140289\);
- numerical half-diamond upper bound is approximately \(0.000213556410\);
- exact half-diamond upper bound is \(0.000584970491\);
- the bare channel already incurs error \(1-e^{-1/8}\approx0.1175031\) on an excited input.

This uses amplitude damping directly in the physical generator.

One failed shortcut is preserved because it clarifies the broader-noise issue. A finite-rate Poisson representation would require

\[
\gamma\mathcal D[\sigma^-]=r(\mathcal C-\mathrm{id})

with \(\mathcal C\) completely positive. Writing \(a=\gamma/r>0\), this candidate map has population survival \(1-a\) and coherence factor \(1-a/2\). Complete positivity would require

which fails for every \(a>0\). The occupation proof avoids that representation.

### A bounded shared bath

The general theorem also extends to a finite shared bath when each perturbation term acts on **one device qubit plus that bath**, under the same operator-norm budget. The reduced device dynamics can then have temporal and spatial correlations.

For a channel and diamond-norm statement, the initial bath state must be fixed independently of the logical/reference input. Direct uncontrolled terms acting on several device qubits, and arbitrary unbounded bath interactions, require further analysis.

## 7. Independent calibration errors are admitted

The nominal construction uses matched sums of Pauli terms, so robustness to their independent coefficient errors is essential.

I proved a uniform bound allowing every one of the **185 Hamiltonian coefficients**, and the reset rate, to have an independent real relative error bounded by \(\delta\). The errors may vary in time within that bound.

This is an operator bound over the entire allowed coefficient range. It is not an inference from sampled sign patterns.

At the main operating point:

| Allowed relative error in every Hamiltonian coefficient and reset rate | Proved half-diamond upper bound |
|---:|---:|
| 100 ppm | \(0.019998\) |
| **500 ppm, or \(0.05\%\)** | **\(0.142519\)** |
| Bare-qubit comparison | \(0.295102\) |

Thus the model retains a certified advantage even with independent 500 ppm errors in all listed coefficients and the reset.

The calibration argument uses another useful structural fact: each individual coupling term is a stabilizer times a one-site Pauli, tensored with a controller Pauli. Although an independently perturbed sum can leave the exact logical commutant, its terms still have reducing subspaces that constrain their logical damage.

The bound does not say that every device in the tolerance range retains the nominal \(0.00636\) performance. Fixed calibration errors introduce an additional error contribution, and arbitrary unlisted many-qubit perturbations are outside this tolerance theorem.

## 8. The informative failures and the locality boundary

Two failures directly shaped the successful construction.

**Equal syndrome energies leave a dark obstruction.** With one shared controller and degenerate error energies, define

\[
|u_i\rangle=
\frac{|X_i\rangle+|Y_i\rangle+|Z_i\rangle}{\sqrt3}.
\]

Combinations \(\sum_i c_i|u_i\rangle\) with \(\sum_i c_i=0\) form a four-dimensional trapped subspace. Every individual one-qubit Pauli error has squared projection \(4/15\) onto it. The binary-weighted stabilizer energies remove this degeneracy; the finite-response certificate verifies the resulting dynamics.

**The four-body Hermitian variant heats the code.** Coupling only through \(B_sX_a\) preserves logical identity, but it excites error syndromes even without ambient faults. That variant remains useful as a diagnostic and is preserved in the archive. The additional \(C_sY_a\) quadrature creates exact darkness and permits the nominal quadratic-noise theorem at fixed engineering parameters.

I also obtained a precise, restricted locality result. For this code and this global corrected-logical commutant:

- data operators of weight at most two contain only the scalar identity;
- at weight at most three, the commutant is spanned by the identity and the fifteen \(B_s\).

Within the chosen product-code/controller-vacuum design, a nonzero operator in that three-body span cannot both supply recovery and annihilate the clean code. The construction therefore reaches exact darkness by adding weight-four data operators, producing weight-five data-controller interactions.

This is a boundary of the present design class. It is not an impossibility theorem for two-body autonomous quantum memories.

The same algebra also supplies an optional protected logical Hamiltonian: corrected logical \(X,Y,Z\) each expand into sixteen terms of weight at most five. Adding a fixed logical rotation preserves the occupation certificates relative to that intended rotation. That is a further capability of the model, while a fault-tolerant universal gate architecture remains unconstructed.

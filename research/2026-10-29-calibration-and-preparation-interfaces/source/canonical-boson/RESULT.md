# Canonical boson operation and a failed trace completion

Two substantive results are complete.

**Positive operation.** Conjugate boson histories have exact nonnegative K,K canonical weights |h_K(B)|^2, with no artificial local occupation cap. The native U1(n_b-n_c)^2 class is nontrivial, frustrated, and has an extensive lower bound. More generally a physical finite number filter is universally compatible precisely when its entrywise-nonnegative charge-label matrix is PSD; that necessity has an explicit arbitrary-history/reachability scope. Fixed TOTAL number does not automatically inherit positivity.

**Decisive trace-completion failure.** A stable two-mode Hamiltonian H=N²/2+2N has an exact continuous Kramers-HS representation for which all algebraic determinant weights are positive, yet their integral is <280/361 while the true partition is >1. This refutes the general post-continuum finite-part recovery asserted under stable-H/finite-Z assumptions. It does not refute configuration-level Kramers positivity, valid trace-convergent models, or the canonical operation. Finite Gaussian-slice expectation convergence remains unpaid.

All current proofs and executed scopes passed root's full analytic review; both canonical runs were independently replayed read-only. The core sources are pinned arXiv2610.31541v1 and2010.09813.

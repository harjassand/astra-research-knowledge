# Constant-sensitivity matching probes and a positive-rate guarded interface
2026-10-29. Conditional new synthesis; matching theorem and this bridge pending review.

Assume the random-matching survival theorem under review: on the full n-qubit singlet space P of dimension d=binom(n,n/2)/(n/2+1), all-pair survival failure q bounds projected entanglement loss by C_full q with C_full=(n+2)/(n-1). Choose a fixed K=2^floor(log2 d) dimensional subspace, an actual isometric encoder, and reset-completed decoder. Then C=(d/K)(n+2)/(n-1)<2(n+2)/(n-1) <=4 for even n>=4. Logical Pauli pads and all test-setting metadata stay private, and the same conditional source map acts at the declared source boundary.

Using the existing adaptive hazard guard with service probability s=1/(1+C), zero allowed test failures, J services and correction of t service-block Pauli faults, the accepted bad-fault probability is at most 2^(-t-1). This is an accepted subnormalized diamond statement after actual outer correction, not conditional-on-accept error. It needs no common-noise algebra or correct frame model for soundness. Tests and service can have unequal average input density matrices; the theorem must hold for every joint source memory state and lift to the operator hazard bound.

For a good source with q_h=0 at every visited history (not conditioning a noisy run on observed zero failures), uncapped expected native source calls for J services are (C+1)J<5J. For a finite cap L>=J/s, the good-source noncompletion probability is exactly P[Bin(L,s)<J]; a Chernoff lower-tail bound gives an explicit exponentially small overhead penalty when L=(1+zeta)J/s. This cap does not weaken soundness when cap exhaustion aborts. Capped accepted throughput additionally pays the cap success probability; the uncapped expected-call expression is not its exact denominator.

If a supplied physical implementation and a fixed-rate outer quantum code correct t=alpha J service-block faults and retain R_out J k logical qubits (k=log2 K), the good-source expected source-exposure rate is R_out k/[n(C+1)]. This stays positive as n grows because k=n-(3/2)log2 n+O(1). This last statement is CONDITIONAL on an actual outer-code family and compatible block/alphabet grouping, not an additional code-construction theorem. Use the previously constructed CSS/GRS grouping mechanism with its finite-size conditions, rather than assuming an arbitrary scalar code is automatically valid.

The old one-edge witness with C growing linearly in n would force O(n) test calls per service under the same R=1 rule. Matching probes remove that particular test-exposure obstruction. They do not discover a good encoder, establish arbitrary-noise positive capacity, or protect against adversarial permanent rejection. Direct logical two-design tests already have C=(K+1)/K~1, so constant statistical overhead is not new as a general capability. The potential improvement is a lower-complexity test preparation/readout interface, to be assessed against full logical preparation and its noisy implementation.

Counting only source exposures hides important costs. On a nearest-neighbour line, exact random-matching singlet preparation has expected gate lower bound n(n+1)/12 from the entropy-across-cuts argument in the accompanying routing note. Payload encoders, outer correction, trusted storage, control calibration and secret routing remain paid operations. No total-runtime, hardware-fidelity, or unassisted-capacity advantage is asserted.

## Exact unitary saturation of the full-space witness (new root derivation)
Let S swap physical sites1,2 and U_t=exp(i t S). Since S commutes with collective SU(2), U_t preserves P. Put a=Tr(P S)/d. The random-matching resolution P/d gives a=(-1)/(n-1)+(n-2)/(2(n-1))=(n-4)/(2(n-1)). When sites1,2 are paired the probe is a swap eigenstate and never fails. Otherwise its two-site marginal is I/4, so its swap expectation is1/2, and survival is cos²t+(1/4)sin²t. Therefore q=3(n-2)sin²t/[4(n-1)], while full-space Bell loss is 1-|Tr(P U_t)/d|²=(1-a²)sin²t=3(n²-4)sin²t/[4(n-1)²]. Their ratio is EXACTLY (n+2)/(n-1) for any sin t nonzero. Thus the full-space matching coefficient cannot improve for arbitrary channels, even restricting to an elementary unitary partial swap preserving the code. This does not prove sharpness of the d/K subcode transfer coefficient.

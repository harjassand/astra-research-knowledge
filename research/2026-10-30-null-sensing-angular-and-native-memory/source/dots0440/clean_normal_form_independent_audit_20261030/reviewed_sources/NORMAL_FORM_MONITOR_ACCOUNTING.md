# Accounting clarification for CLEAN_EFFECTIVE_NORMAL_FORM Sections 2–3
2026-10-30. Supplements the frozen source without changing its reviewed hash.

For EACH fixed commutator [L*,Q_h], include every actual resource-monitor term on R_h in the isolated core calculation for h. On h's ready-neighbor guard those terms are exactly its isolated monitored controller dynamics; off that guard Q_h is identity. They are NOT classified as neighboring fast terms that commute Q_h, and their raw action on DATA-only V is zero.

This grouping is repeated separately when evaluating each h commutator. It is NOT a proposed global decomposition L=sum_h L_iso,h, which would double-count monitors shared by different resource footprints. For any fixed h, each actual physical generator term is counted once.

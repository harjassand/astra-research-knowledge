# Direct swapping of signed-sector encoded Bell resources
2026-10-30. Exact ordinary teleportation instrument, with finite-latency noisy-interface accounting. This closes the signed-output mismatch of the bilateral buffer algebra; it does not supply its missing autonomous LOCC controller.

## Useful result first
Two encoded Bell links need not be converted to the zero-syndrome code before they can be switched. Bell-measure all matched physical qubits at the middle node, send the FULL raw physical Pauli mask to one recipient, and apply that mask in parallel. The measurement itself forces the extensive syndrome difference to be exactly the syndrome of the mask. After its application the output is a shared-syndrome encoded Bell state with the known logical Bell correlations.

No global syndrome decoder, logical-frame inference, or protected long-lived baseline is required for this operation. The classical mask has 2N bits, is held only for a declared bounded transmission/control time, and is applied physically. This is standard physical teleportation specialized to signed code sectors, not a newly invented entanglement-swapping mechanism.

## 1. Exact instrument, including its normalization
Let C be a real CSS [[N,k,d_code]] code. Set D=2^N, K=2^k, and let Pi_s be its syndrome-sector projectors. Define row-first vectorization by

    |M>> = sum_(i,j) M_(i,j) |i>|j>,
    |Omega_s> = |Pi_s>>/sqrt(K).

There are r=N-k independent syndrome bits. The input consists of Omega_s on R,A and Omega_t on B,S. A and B are at the same middle node. For a unitary Pauli mask P, define its physical Bell outcome ket on A,B by

    |beta_P> = (I tensor P)|Phi_D>.

Contracting the middle pair gives the exact unnormalized recipient vector

    <beta_P|_(A,B) (|Omega_s>_(R,A)|Omega_t>_(B,S))
       = |Pi_s P† Pi_t>>_(R,S) / (K sqrt(D)).       (1)

Now apply P^T on S. The vectorization identity (I tensor B)|M>>=|M B^T>> yields

    (I tensor P^T)|Pi_s P† Pi_t>>
       = |Pi_s P† Pi_t P>>
       = 1[s+t=sigma(P)] |Pi_s>>.                  (2)

Thus the corrected branch is

    1[s+t=sigma(P)] |Omega_s>/sqrt(KD).             (3)

A Pauli transpose differs from the usual physical mask only by its global phase. The operational Pauli application therefore uses the ordinary raw Bell outcome bits. For fixed s,t, exactly KD of the D² physical Pauli outcomes are compatible, each with probability 1/(KD). The instrument never postselects a rare desired syndrome.

## 2. Coherent common syndromes and retained bath
Let W|s>=Omega_s denote the Bell-target/gauge isometry. On the two input gauge registers, each corrected Bell outcome P acts as

    G_P = (KD)^(-1/2) sum_s |s><s,s+sigma(P)|.      (4)

Consequently the entire instrument maps the fixed logical Bell factors to one fixed output logical Bell factor, while applying G_P only to the gauge registers. Equation (4) holds for coherent superpositions sum_(s,t) alpha_(s,t)|s,t> and arbitrary gauge-reference/bath entanglement. Since there are KD masks of each syndrome, sum_P G_P†G_P=I.

There is no unjustified sampling of the common syndromes, no inference that common errors protect arbitrary joint logical inputs, and no need to choose Pauli preimages of those syndromes. The factorization is for the known encoded Bell resource.

## 3. Small residual errors and a genuinely noisy endpoint
Suppose both input links lie in the common correctable span generated by relative Pauli errors with stabilizer-reduced physical representatives of weight at most r_1 and r_2. Choose the relative representatives on the middle halves A and B, absorbing common Pauli changes into the respective gauge registers. Multiplying by stabilizers only changes gauge-dependent phases and does not change the target factor.

A local Pauli on a middle Bell-measurement input flips only the corresponding physical Bell outcome bits. The resulting discrepancy in the applied full mask has support contained in the union of those input supports. Equivalently the standard transversal Bell circuit has bounded column spread. Therefore the output has a relative Pauli representative of weight at most

    r_out <= r_1+r_2+c K_terminal,                  (5)

for each compatible coefficient history, where K_terminal counts actual bounded-support faults during the entire fixed-duration endpoint: local Bell gates/measurement, recipient waits, raw-mask transmission, local record/control, and physical mask application. The constant c includes their finite-depth/bounded-fanout light cones. Arbitrary CPTP faults may be expanded coefficientwise while retaining a common actual-record support envelope. No Pauli-twirling assumption is needed.

The two input radius budgets must be chosen so their sum plus endpoint faults is within the output relative buffer's decoder/basin radius; merely knowing that each is individually correctable is insufficient. One may run additional fixed recovery rounds to reduce the contraction part before switching, but the ongoing-noise floor and all those rounds remain charged.

## 4. The physical-time and controller seam is not free
Before P is applied, the new R,S resource generally has an EXTENSIVE relative Pauli byproduct. It must not be handed to an unchanged small-relative-error controller at that moment. The declared terminal operation must include the entire Bell measurement, classical mask delivery and physical recipient correction, and only then restart/continue the relative buffer in its output regime.

For the scheduled comparator this is explicit: finish a round, pause incompatible correction actions, execute the bounded-duration switch/control sequence, then start the next relative-syndrome round. Data noise during the pause counts in K_terminal. This requires 2N classical bits of bandwidth per switch and fixed physical latency tau_switch; if latency grows, the fault budget grows accordingly. No promise of arbitrary-delay mask transmission is made.

For an autonomous realization, the analogous seam must handle all live controller prefixes, records, locks and nominal motion. The old full-forest controlled terminal-stage construction may be reused only after its frames and allowed mode operations are instantiated for the ACTUAL bilateral LOCC controller. The current native coherent hub cannot be assumed to do this across separate laboratories without introducing a quantum communication resource. Hence this manuscript closes the exact resource algebra and the scheduled endpoint, not that compiler obligation.

## 5. Consequence and strong ordinary comparison
Together with the bilateral-buffer construction, this gives an end-to-end ordinary resource path:

    noisy physical Bell pairs
       -> relative-syndrome protected signed-sector Bell links
       -> unpredictable protected waiting
       -> direct physical-mask Bell swap
       -> signed-sector Bell output to encoded recipients.

Initial sources must obey the stated local support/moment noise hypothesis; N physical pairs are a real entanglement input, not generated by LOCC. Both endpoints continually participate in protection and communicate fresh syndrome bits. Quantum memories/source synchronization during acquisition of those N pairs remains a separate resource.

This path avoids the O(N²) encoded Bell factory route and its high-energy global preparation-frame inference for this PARTICULAR known-Bell task. It does not replace that factory for arbitrary known logical states, unknown-state loading, or universal computation. Nor does it beat an ordinary scheduled implementation given the same source, local connectivity, classical channels and noisy gates: that ordinary implementation realizes exactly the above process. The remaining autonomous challenge is genuinely autonomous noisy LOCC service, rather than Bell initialization algebra.

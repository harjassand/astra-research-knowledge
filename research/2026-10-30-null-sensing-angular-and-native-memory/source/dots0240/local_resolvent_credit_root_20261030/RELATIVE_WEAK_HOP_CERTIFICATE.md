# Relative weak-hop certificate with an actual resolved monitor
2026-10-30. Root derivation candidate. This avoids applying an absolute instrument-error bound to an event whose probability is O(epsilon^2).

## Finite no-jump amplitude lemma
Let P0,P1 be orthogonal source/target clock projections. On a fixed finite isolated-controller patch, no-jump evolution is generated by G_epsilon=G0+epsilon V, with ||G0||<=B and ||V||<=v. Assume G0 preserves the source P0, so P1 exp(tG0)P0=0. Assume A=P1 V P0 obeys A^dagger A>=a0^2 P0 with a0>0. For the first native acquisition edge, A is a nonzero constant times an isometry on the idle DATA/workspace/monitor subspace.

Duhamel expansion gives

    P1 exp(tG_epsilon)P0
      =epsilon integral_0^t P1 exp((t-s)G0)V exp(sG0)P0 ds+R2,
    ||R2||<=epsilon^2 v^2 t^2 exp[(B+|epsilon|v)t]/2.

The first-order coefficient differs from tA by at most C Bv t^2 exp(Bt), for an absolute C. Choose a fixed small delta>0 so this error is <=a0 t/4 for EVERY t in [delta,2delta]. Then choose epsilon0>0 so ||R2||<=|epsilon|a0 t/4 on the same interval. These choices are independent of total memory size.

For 0<epsilon<=epsilon0 and t in [delta,2delta], every source vector satisfies

    ||P1 exp(tG_epsilon)P0 psi||>=epsilon a0 t ||psi||/2,

hence the exact selected-clock effect is

    P0 exp(tG_epsilon)^dagger P1 exp(tG_epsilon)P0
       >=epsilon^2 a0^2 delta^2 P0/4.

This is a relative amplitude estimate. The leading epsilon is retained in every error term; no O(delta) absolute instrument error is subtracted from an O(epsilon^2) probability.

## Actual finite-rate monitor record
The native resolved monitor has H_mon=Omega X and distinct decay channels M_c=sqrt(kappa_m)P_c tensor |0><1|. After a real monitor flush, its no-emission dynamics factorizes and a label-c emission applies the EXACT clock projector P_c, at a finite random time. These are physical instrument identities, not a limiting dephasing model.

Select no main jumps before the target emission, no competing monitor emissions, and one target-label P1 emission in the fixed interval [delta,2delta]. Starting from a reset monitor, the timing density is clock-independent and has a strictly positive integral on this interval; isolated zeros of its damped-Rabi amplitude do not remove that integral. Multiplying and integrating the preceding effect gives a lower bound c_weak epsilon^2 P0 with fixed c_weak>0. A prior finite flush/clock-source projection only adds its explicitly positive constant factor.

For the clean isolated native idle state, zero-initiation dynamics cannot leave A0. The weak edge is the only exit. After selection of A1, consistency fixes the first owned resource and the workspace remains clean; a fixed fast monitored acquisition/commit/computation path can then reach a useful terminal with an additional positive conditional probability. Its windows need not shrink with epsilon. Applying the old absolute-error path lemma only to this FAST part is legitimate because its success probability has a fixed positive lower bound.

## Scope and checks still required
For the native application, apply the amplitude lemma to the main clock/workspace evolution after EXACTLY factoring the flushed monitor dynamics. The bound B includes every main no-jump loss; the monitor probabilities and silence factors are accounted for separately as above. No monitor contribution is dropped from the actual instrument. P0 must be a genuinely invariant source at epsilon=0, and the first edge must have no kernel on it. Full malformed masks or an unisolated busy neighbor need not satisfy those conditions. The local path from any non-idle isolated state to either success or idle, plus uniqueness of the actual idle monitor steady state, remains part of the regenerative resolvent proof. No global native threshold is inferred from this weak-hop lemma alone.

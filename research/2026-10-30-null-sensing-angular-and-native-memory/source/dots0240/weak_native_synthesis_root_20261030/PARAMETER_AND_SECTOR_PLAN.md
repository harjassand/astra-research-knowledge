## Potential full-Hilbert surgery scale window
Let b denote the strength of the useful DATA CP credit, so useful drift is of order b epsilon^2 W. Let delta denote an activity-congruence strength. A possible compatible strict hierarchy is

    b << delta << sqrt(b) epsilon,
    delta epsilon^4 << b epsilon^2.

For example b=epsilon^4 and delta=epsilon^(7/2) satisfy these as epsilon tends to zero. Constants must be fixed before selecting epsilon, and the real derived error bounds must fit these powers. This is not a claim they already do.

The intention is to pay O(delta) dirty diagonal corrections with uniform bad-flag loss, O(delta) clean/dirty cross blocks by Young at cost O(delta^2) on the clean side, and activity-startup source O(delta epsilon^4) below useful service. A purported proof must display the source support and constants of each term; assigning it a desired order is not a derivation.

## Parity qualification
On the all-good legal sector, first-initiation sign reversal may be conjugation by activity parity if fast Hamiltonians preserve activity and each actual resolved jump has a definite activity change. This can force idle/single blocks to be odd powers of epsilon, making exact isolated first-order cancellation useful.

It is NOT automatic on the entire malformed Hilbert space. One actual ready Kraus may clear busy activity for no-own-tag sectors but leave busy activity for stray-own-tag sectors. Splitting that Kraus by unobserved ownership masks changes coherent dynamics. Thus no global parity symmetry is imported from no-creation alone. Either prove the actual symmetry, redesign a permissible physical reset explicitly, or pay those sectors through a correct dirty-history surgery.

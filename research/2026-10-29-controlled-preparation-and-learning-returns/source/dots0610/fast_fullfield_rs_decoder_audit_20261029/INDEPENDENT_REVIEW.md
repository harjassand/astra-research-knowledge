# Independent full-field fast decoder review
2026-10-29. Mathematical and executable receiving review.

## Decision
The finite-field algorithm and its actual measured CSS readout interface are correct on the stated domain (valid field labels, t>=1, 4t<q for the CSS wrapper). This closes the previously unexecuted large classical bounded-distance decoder obligation for the supplied B2048 instances. It is established syndrome-decoding machinery, not a new decoding principle, a hardware benchmark or evidence of quantum practical superiority. The known correctable-radius guarantee does not detect all physical errors above that radius.

## Exact algorithm argument
Write S_j=sum_a e_a a^j, j=0,...,2t-1, with 0^0=1. For r distinct nonzero nodes a_i and nonzero weights w_i, the moments form a linear recurrence with C(z)=product_i(1+a_i z). Its length is exactly r: the r-by-r moment Hankel matrix is V diag(w_i) V^T and is nonsingular. Consequently 2r moments determine the recurrence uniquely; the standard Berlekamp–Massey discrepancy update recovers it. The implementation stores normalized C[0]=1 and updates the saved discrepancy and connection polynomial when 2L<=n, matching this convention.

If e_0=0, at most t nonzero nodes occur and 2t input moments suffice. If e_0 is nonzero, S_1,...,S_(2t-1) instead have r<=t-1 nonzero nodes and weights w_i=e_i a_i. Their 2t-1 samples are more than enough. After recovering those weights, divide by nonzero a_i and set e_0=S_0 XOR sum_i e_i. Thus the explicit shifted branch handles the evaluation point zero; no assumption excluding that physical location is made. The t=1 zero-only case reduces to the zero-length shifted recurrence.

For amplitude reconstruction let A(z)=sum_{j>=0}s_j z^j=sum_i w_i/(1+a_i z). Then Omega(z)=C(z)A(z)=sum_i w_i product_{k!=i}(1+a_k z), of degree below r. Its first r coefficients are obtained from the first r sequence entries, exactly as the program's truncated convolution. At z_i=1/a_i, C'(z_i)=a_i product_{k!=i}(1+a_k z_i), giving w_i=a_i Omega(z_i)/C'(z_i) in characteristic two. The implementation's node factor, formal derivative and shifted division therefore have the correct convention. Chien search covers every nonzero field node. Root count and derivative checks reject degenerate candidates.

Both candidate branches verify every one of the original 2t syndromes and the final total support before acceptance. If a weight-at-most-t representative exists it is unique: the difference of two such representatives would have at most 2t nonzero entries and lie in a full-field RS code of distance 2t+1. Therefore a verified candidate is correct under the radius promise, regardless of which branch found it. If neither verifies, the classical function returns a fixed zero vector and a failure flag. A physical above-radius error can share a syndrome with a correctable one: successful bounded-distance decoding is not an uncorrectable-error detector.

For paired CSS streams the code additionally checks the UNION support count count_nonzero(ex|fz)<=t, rather than accepting separate X/Z bounds as a joint guarantee. On any failure the surrounding controller may choose any declared total correction rule; correctness is only claimed on the correctable branch.

## Actual quantum readout interface
The accepted FFT compiler uses row matrix T with encoded labels cT. An inverse elementary addition dst+=c*src sends phase labels by its transpose, namely src+=c*dst, in reverse gate order. The code's transpose_fft therefore computes field-vector T multiplication in the required convention; no unproved self-dual basis assumption enters. Binary phase bits are mapped to field labels by the explicit trace pairing table.

Let H comprise the first 2t rows of T and R its final 2t rows. The measured last-register X labels x_last are lifted to a coefficient vector with all other entries zero, forward-transformed to x_last R, then transpose-transformed and truncated: this gives H R^T x_last^T, the correct syndrome. Omitted earlier coefficient components lie in C and are annihilated by H. The first phase readout already gives the novel-basis syndrome after trace-dual conversion.

The lower-triangular matrix L contains monomial coefficients of the degree-filtered basis. Its diagonal is nonzero. Solving L*S=Y converts novel syndromes to the power moments used by the decoder. Recovery returns physical error labels from those measured syndromes alone; the logical correction bits follow inverse X transform and trace-dual transpose Z transform on the middle registers. Actual hidden errors enter only the test harness that generates the readout and verifies correction, not decode_readout.

The earlier accepted CSS Knill–Laflamme argument then gives arbitrary coherent errors on at most t outer symbols, with reference/system-memory correlations. This classical benchmark does not itself simulate the complete quantum experiment or close noisy endpoint operations.

## Independent executed checks
1. Exhaustive GF8,t=2 test constructs an independent polynomial-arithmetic dictionary of all weight<=2 errors, then tries ALL 4,096 possible length-four syndromes. Exactly 1,429 unique representatives are accepted; all 2,667 others return failure. The explicit zero-coordinate branch is used for 350 syndromes. This directly tests malformed/nonrepresentable syndrome vectors as well as correctable data, without relying on a sampled all-zero-leading-moment assumption.
2. Independently propagating binary Pauli labels through the actual inverse CNOT circuit yields 180 readout/correction checks across h3,t1; h4,t3; h5,t5. They verify measured X-basis bit labels, final trace-dual correction bits and the full X readout conversion. A separate disjoint-X/Z-support case confirms the joint-radius rejection.
3. The complete author large benchmark was rerun in a separate directory. All saved deterministic error and measured-readout arrays match. Timings and process memory are newly measured host observations, not expected to match identically. The author's 60 small BW comparisons are reproduced.
4. Additional B2048 checks at both t99 and t147 propagate actual binary labels through all 651,264 compiled inverse CNOTs for all-zero, boundary random-with-zero, and boundary random-without-zero cases, then feed only those measured bits to the fast decoder. Final logical bit corrections are checked against actual propagated binary errors. This closes the large-interface bridge independently of the fast field-transpose implementation.

## Costs and limits
No q-by-q field multiplication table is used. Field lookup arrays have O(q) entries; verified primitive-element enumeration establishes the supplied multiplicative table. The novel-basis coefficient matrix has O(t^2) entries. Per-decode work includes O(q log q) classical FFT additions, O(t^2) triangular conversion/BM and O(qt+t^2) Chien/Forney/full verification. The field-addition list itself occupies O(q log q) classical records. Setup and compilation are separate finite costs, not free operations.

Measured host runtimes do not establish deterministic latency, device execution, buffer lifetime, or physical correction performance. The t99 and t147 tests are at B2048, not silently transplanted B2047 results. The exhaustive syndrome test is GF8, not exhaustive B2048 validation. Valid finite-field inputs and declared lengths are preconditions; the implementation is not certified as a defensive parser for arbitrary corrupt Python objects. Generic t=0 support is outside this CSS wrapper's domain.

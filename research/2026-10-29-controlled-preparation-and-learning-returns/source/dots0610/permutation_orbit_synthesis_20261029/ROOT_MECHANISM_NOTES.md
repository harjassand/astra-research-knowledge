# Randomized code orbit: central synthesis and next obligations
2026-10-29 04:17 UTC. Working derivation, NOT accepted yet.

The recovered programme has an accepted arbitrary-channel matching witness on P, but fixed proper-subcode transfer loses d/K and private logical Pauli twirling needs difficult code operations. A physical permutation twirl can address both obligations at once.

Let V:C^d->H be the full singlet embedding. The S_n representation on its domain is irreducible and occurs with multiplicity one in the full n-qubit H. For each joint source Kraus K_a:L M->H M', decompose K_a=V tensor B_a+R_a with B_a=(1/d)Tr_L[(V† tensor I)K_a]. Group averaging kills R_a as an intertwiner. After physical pre-permutation and inverse output permutation, cross terms vanish and the averaged source is ideal embedding tensor a CP memory map plus a CP residual. Trace preservation and Schur imply residual trace effect I_L tensor H_bad. This is stronger than merely bounding a reduced channel.

Encode a fixed qubit subcode W:C^K->C^d BEFORE sampling/applying permutation; after source undo the permutation and use a TP reset-completed decoder for VW. Restricting the good branch gives id_K tensor B_good. The bad effect stays I_K tensor H_bad, independently of K. Matching probes test the fullP source map and bound H_bad with coefficient C_full=(n+2)/(n-1). Thus the new mechanism randomly MOVES the code withinP during the source call. It is not an improvement to the old fixed-code inequality and does not imply a proper subcode is permutation-invariant.

Service and test average source input are now both P/d: averaging a fixed Q/K over an irreducible group givesP/d. For a payload entangled with memory, averaging the pre-permutation depolarizes L while preserving its reference/memory marginal. This helps conceal role at the quantum interface, but cannot hide classical timing, routing, control fields or later key disclosure. Current matching/permutation keys and seed purification must remain inaccessible to source and retired at the declared interface.

Required closure: (i) exact full-joint CP proof, including leakage; (ii) correlated-payload, retained-memory sequential hazard and outercorrector proof without assuming Pauli labels; (iii) a finite n6 d5 K4 instance exercising a genuinely proper subcode; (iv) counts and calibration of physical permutations in learned local frames, and service decoder/storage cost. A composite-d outercode construction was started as a fallback but should not be mandatory if the proper-subcode orbit theorem survives review.

Known general covariance/Schur machinery likely covers the reduced-channel norm equality. Historical novelty of the architecture is unresolved. A simpler control interface is not automatically a physical advantage: source exposure during routing and errors in known rotations/permutations can invalidate the ideal split unless budgeted. No generic noise-capacity or hardware threshold claim.

## Material resource correction, 04:23 UTC
The earlier motivation describing logical Pauli twirling as necessarily difficult code control is too strong. In the existing service pipeline E -> source -> D, the random logical Paulis can be applied to bare logical qubits BEFORE E and AFTER D. This costs O(k) one-qubit gates and 2k fresh key bits, not extra full encoded-Pauli compilation. The physical permutation orbit adds O(n) SWAPs (or quadratic line routing) and O(n log n) exact-sampling expected bits. It therefore does NOT establish a cheaper universal control interface than the existing endpoint-Pauli route. The defensible improvement is removing subcode localization cost by randomizing the code orbit, with a strict channel fixture, plus an alternative operation when physical permutation access is independently valuable. Any encoded-data-only control advantage needs that restricted interface stated and compared explicitly. Preserve this correction rather than silently inheriting the earlier motivation.

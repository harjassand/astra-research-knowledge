# Independent review: finite first-success resource compiler
2026-10-29. Reviewer: derive_matching_survival_bound.

## Main determination
The finite first-success compiler is mathematically sound at the stated uniform, full accepted-operation diamond interface when its accepted memory comparator has exactly the actual accepted trace effect. In particular the actual accepted coarse memory map required by the main construction satisfies this condition. A simulator defined by inserting a fixed dummy logical input also satisfies it when acceptance is input-independent at the governing interface.

An unrestricted alternative simulator need not: actual acceptance effect 0.3 I, simulator effect 0.2 I, and unchanged actual rejection effect 0.7 I produce a purported ideal factory of trace 0.9. The norm comparison can remain true, but that comparator is not a complete physical instrument. Requested correction: require matched accepted effects for the optional simulator formulation. This does not alter the main actual-memory construction.

## Proof obligations checked
1. At each attempt and classical history, the complete actual rejected-prefix map acts on source memory and its reference, with no memory reset inserted. It is CP and trace-nonincreasing. Histories are disjoint classical branches. Uniform per-history accepted diamond error bounds each branch contribution by epsilon_i times its reaching mass. Summation over histories bounds the attempt contribution by epsilon_i; summation over finite attempts gives sum epsilon_i.
2. No hybrid changes rejected prefixes, so there is no assumption that later learned candidates or bath trajectories remain unchanged after an idealized rejection. Candidate selection is a classical-history-controlled instrument and may vary arbitrarily under the declared caps.
3. Exact matching of accepted effects ensures the ideal success replacements together with the unchanged all-rejected branch are a trace-preserving flagged instrument. This is a full instrument guarantee, not a claim of normalized success-conditional error epsilon.
4. A pre-buffered unknown payload may initially be entangled with source memory. It is an external reference during generation. Memory instruments can steer it on conditioning, correctly represented by id_D tensor B, and may not be described as conditional statistical independence. The submitted manuscript makes this distinction.
5. Bell measurement, public two-bit-per-qubit outcome retention and corrected teleportation are CPTP postprocessing. The ideal Bell resource implements identity on arbitrary correlated D:M states with each classical outcome exactly uniform. Full joint resource norm control is sufficient even with public records; mere Bell-label statistics would not suffice.
6. Trusted reference isolation/storage, actual Bell measurement/corrections, output typing, retired private keys and decoder records remain material assumptions. The proof does not remove shared-bath control noncomposability, establish yield, or bootstrap trusted quantum storage.
7. The four-attempt numbers are consistent: (2/5)^7=128/78125, total512/78125<1/128, service probabilities4/13 and1/4, respective caps1840 and2264. Finite caps only add abort to an already certified accepted subinstrument.
8. Fixed nonsummable error under unlimited retries does fail: repeated rare exclusively bad acceptance converges to wrong first-success probability1. This does not contradict finite sum bounds.

## Why grouping is a valid new composition
Prepare the outer31 symbols (each five qubits) using the actual GRS encoder. Process their155 physical logical-qubit coordinates through the independently private-padded inner service in a fixed public order. The exact retired-key instrument produces a joint Pauli pattern on all155 coordinates even with arbitrary retained memory and entangled payloads. If at most6 inner-service coordinates have nonidentity labels, at most6 of the31 grouped symbols have a nonidentity q-ary Pauli. The GRS code therefore corrects every such pattern. No independence between coordinates, between grouped symbols, or across tests is introduced.

Polynomial-basis field X labels are the bitwise XOR coordinates. For Z labels, the simulator explicitly computes the dual basis for the trace pairing; simply treating binary Z positions as polynomial-basis field coefficients would be wrong. The actual syndrome decoder and total fallback are called, not replaced by a count-only ideal QEC oracle. The NB fault-count bound remains on155 inner SERVICE calls; J in the scalar stopping rule is155, whereas the outer code length is31. This grouping extension replaces v1's one-inner-symbol/one-outer-symbol specialization for this instance.

## What was simulated and what was not
The simulator knows the source generator and computes its memory CP maps, then propagates two-by-two unnormalized bath states and latent Pauli/count branches. Those maps and fault labels are NOT provided to the physical protocol. Physical execution uses only private coins, actual prepared probes, observed sign failures and the final outer syndrome. This is a valid source-generator compression for checking the mathematics, not a new bath-tomography/access oracle. The full32^31-dimensional outer state is not amplitude-simulated; exact Clifford/finite-field error propagation and actual total decoding implement its correction check.

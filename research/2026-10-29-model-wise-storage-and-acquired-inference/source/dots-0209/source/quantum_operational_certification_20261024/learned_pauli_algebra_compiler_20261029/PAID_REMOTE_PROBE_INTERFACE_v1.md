# Paid remote Bell-probe realization with a preshared entanglement seed
2026-10-29. Candidate physical-interface addendum, independent review pending. This is **not** an unassisted channel-capacity claim.

Suppose Alice holds each trusted reference R, Bob receives the output B of the unknown n-qubit source channel, and both have trusted local operations plus two-way classical communication. The joint Bell probe used in the service theorem is not LOCC by itself. An explicit realization uses n preshared trusted ebits per probe: after the source call, Alice teleports all n reference qubits R to Bob (2n classical teleportation bits), and Bob performs the n local Bell measurements. Bob returns the sampled physical-frame label to Alice for the next compiled encoder. Conjugate reference control can be done before teleportation, or Bob can apply the prescribed control after reconstruction. Each probe's cost must be counted as n consumed ebits; no entanglement-assisted measurement is free.

On a service, Alice keeps the logical reference halves while Bob decodes and retains his logical halves, creating the resource assessed by the theorem. Current role can remain private until the source interaction is over. Revealing previous role/label afterwards does not invalidate the actual-prefix proof; source dynamics already allow dependence on past accessible history. All seed resources, local controls and key records must obey the original isolation assumptions.

## Finite seed budget with a rare-probe schedule
Let r=1-q<=1/4. Request J services and impose a hard cap P on the number of probes, stopping when eitherJ services orP probes have occurred. Provide exactlynP trusted seed ebits. On reaching the probe cap beforeJ services, abort/fill outputs and charge that event. At mostJ+P source calls occur.

Choose P>=max(4rJ,6 ln(1/delta_seed)), rounding upward. Couple the roles to J+P independent coins. The mean number of probes in that many coins is r(J+P)<=P/2. The event thatP probes are reached beforeJ services is contained in the event that at leastP probes occur among thoseJ+P coins. The standard binomial upper-tail bound then gives probability at most exp(-P/6)<=delta_seed. Thus seed usage is deterministically capped while the additional failure charge isdelta_seed. This bound is conservative; exact negative-binomial tails may reduce the budget.

The trusted seed scales as n*O(rJ+log(1/delta_seed)) ebits. In an outer-code construction where r tends to zero while J*r grows sufficiently to pay the finite-innovation correction overhead, this is sublinear in J for fixed n. The final output ebits must have the seed consumption subtracted when reporting **net** entanglement gain. For example r proportional to sqrt(m/(epsilon*J)) gives seed ordern sqrt(mJ/epsilon), whereas service output can be orderJ*k0. This is a seeded, feedback-assisted architecture with paid nonlocal acquisition, not a free remote Bell oracle.

No bootstrap from uncertified earlier service resources is justified: imperfect seed teleportation could corrupt probe labels and destroy the learned-subspace inclusion invariant. Supplying or fault-tolerantly creating high-quality seed ebits is a separate obligation. Nor does sublinear seed consumption automatically prove equality with an unassisted quantum capacity in this adversarial retained-memory setting.

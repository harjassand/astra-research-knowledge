# Additional operational boundary: joint Bell-probe access is not free remote LOCC
2026-10-29. Clarifies the accepted theorem's trusted-control interface; does not invalidate its mathematical bound.

The probe branch requires a complete Bell measurement jointly on the retained reference R and the returned source output B, after the reference Clifford. This is physically available in a local returned-output/memory-test setting with trusted joint controls. It is not implementable for spatially separated Alice and Bob using only local gates and forward classical communication: complete discrimination of the four two-qubit Bell states is already a nonlocal measurement requirement. Local X and Z parity measurements cannot simply be executed sequentially to obtain the same Bell instrument; individual local measurements disturb the other parity.

Consequently, a remote communication or channel-capacity reading requires an additional explicitly paid interface: a quantum return path, nonlocal quantum control, pre-shared entanglement to implement the probe measurement, or a genuinely different locally implementable acquisition mechanism. Role-dependent return routing could occur after the noisy source call without breaking role hiding, but its quantum communication resource cost must be included. Forward source-block rate alone is not the net communication rate of such a protocol.

The existing service theorem is accepted for its explicit trusted Bell-preparation/readout and isolated-storage model. An outer code can improve that model's normalized source-use rate; it does not remove this acquisition locality requirement. The strong conventional alternative is also interface-dependent: if all systems share a laboratory and trusted quantum storage is freely available, direct use of that storage may already protect payloads without passing them through the unknown source. A practical architectural advantage therefore needs a connectivity, timing or storage restriction that makes the learned source operation genuinely useful rather than assuming away the task.

No new impossibility result is asserted here. This is an interface accounting obligation before a remote-capacity or useful-memory-device claim.

Self-contained check of the nonlocality assertion: Alice locally prepares an EPR pair A:R and Bob locally prepares B:D. Their joint state is separable across the laboratories AR|BD. An exact complete Bell measurement on R:B would, conditional on each recorded outcome, project the untouched A:D pair onto a known Bell state (entanglement swapping). Local Pauli correction would then deterministically leave an EPR pair across Alice/Bob. LOCC cannot create such entanglement from a state separable across those laboratories. Thus exact full Bell measurement requires a nonlocal quantum resource. This argument concerns the actual measurement/instrument, not merely reproducing some marginal probabilities for a restricted source family.

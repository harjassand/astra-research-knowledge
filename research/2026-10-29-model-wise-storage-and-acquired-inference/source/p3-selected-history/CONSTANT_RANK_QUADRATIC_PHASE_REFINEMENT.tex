\section{An explicit triangular source whose phase is an arbitrary CNF truth value}

Let $F(x)$ be any CNF formula on $n$ actual state bits, and let $z$ be an
additional actual state bit.  Use the explicit directed acyclic path-sum
construction in the preceding proof to obtain a strictly upper triangular
matrix $N(x,z)$ with affine state entries and
\[
 \big((I+N)^{-1}\big)_{s,t}=zF(x).
\]
Write $A=I+N$, of size $m$, and $h=zF(x)$.  All diagonal entries of $A$ are
literally one.  Its rank is $m$ at every state and its triangular solves need
no data-dependent pivot branch.

Take $2m$ actual fresh uniform noise bits $u,v$ and define the scalar channel
\[
 G(x,z,u,v)=u^TA(x,z)v+u_t+v_s.\tag{1}
\]
This is a sparse cubic Boolean function with state degree at most one and noise
degree at most two.  Let
\[
 a=A^{-1}e_t,\qquad r=A^Tu+e_s,\qquad w=v+a.
\]
The change $(u,v)\mapsto(r,w)$ is affine and invertible at every actual state,
and direct expansion gives
\[
 r^Tw=u^TAv+u_t+v_s+e_s^TA^{-1}e_t=G+h.
\]
Thus
\[
 \boxed{\qquad G=r^Tw+h(x,z).\qquad}\tag{2}
\]
The polar matrix of (1) is
$\left(\begin{smallmatrix}0&A\\A^T&0\end{smallmatrix}\right)$,
of constant full rank $2m$.  The map $v\mapsto Av$ already gives a global
polar congruence to the fixed standard bilinear form, independently of the
linear terms.  All normalization coordinates, including the triangular solve
for $a$, have polynomial-size ordinary gate circuits.  The phase $a_s=h$ may
nevertheless lack a small representation in the original common order.

\begin{theorem}[Global independence remains coNP-complete at constant rank]
For the raw channels (1), deciding whether $G(x,z,U,V)$ has the same law at
every actual state is coNP-complete.  This holds with constant full polar rank,
fixed unit pivots, a known structural polar congruence, sparse cubic source
ANF, and polynomial same-order width for every raw gate wire.
\end{theorem}
\begin{proof}
For $r,w$ independent uniform $m$-bit words,
$\sum_{r,w}(-1)^{r^Tw}=2^m$.  Equation (2) therefore gives
\[
 C_0(x,z)=2^{2m-1}+(-1)^{h(x,z)}2^{m-1}.\tag{3}
\]
At $z=0$ the phase is zero.  A state with the opposite nonzero bias exists
exactly when $F$ is satisfiable.  Nonindependence is witnessed by actual state
assignments and verified by polynomial-time quadratic counting, proving
coNP membership in the stated syntactically quadratic class.

An ordinary transition preserves $x,z$ and replaces an additional carrier $s_0$
by (1); its requested observation is $s_0$.  These are actual original state
and noise bits.  The raw source computes each displayed monomial and then XORs
partial sums.  Every monomial has common-order width one, so every wire has
width bounded by the polynomial number of source monomials.  No independent
gate wires, external rank promise or hidden decoder are introduced into the
reduction.  The constant-rank and congruence claims were established directly
above, rather than assumed from a failed certificate.
\end{proof}

For a full original initial cube including the unused carrier, (3) also gives
\[
 \#\{(x,z,s_0,u,v):G=0\}
 =2^{n+2}(2^{2m-1}+2^{m-1})-2^{m+1}\#F.\tag{4}
\]
This preserves the distinction between easy local quadratic counting and
counting over an unrestricted initial population.

\section{The phase alone loses exponential common-order compression}

Use $F(x,y)=\prod_{i=1}^k(1+x_i y_i)$, for which the matrix and raw source have
size $O(k)$.  The completion phase is
\[
 h=z\prod_{i=1}^k(1+x_i y_i)=\sum_{S\subseteq[k]}x_S y_Sz.
\]
Its coefficient matrix across the order cut $x\mid y,z$ has rank $2^k$.
Hence its exact Boolean ROABP width is $2^k$, whereas every raw source wire
has width $O(k)$.  This is the same proved invariant as in the preceding
construction, now appearing as a \emph{phase with no rank variation}.
The normalized constant bit or an exact count bit must retain it if emitted
in that fixed representation.  This is not a lower bound for unrestricted
gate circuits or for every possible proof certificate.

In particular, eliminating all varying-pivot branches or acquiring a compact
polar congruence does not guarantee an efficiently checkable state-independent
law.  A complete general method still has to verify the signed quadratic
population, including the phase created by its acquired coordinate changes.

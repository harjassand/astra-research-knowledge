The implementation test has changed the mechanism: the new candidate lets independent syndrome probes overlap and produce occasional wrong reports, then explicitly accounts for that damage. It no longer relies on a perfectly reliable collision controller.

The remaining test is whether the same protection survives faults in the physical clocks themselves. The comparison is against active error correction using the same hardware; the intended gain is removing trusted timing and control, not merely producing another expensive simulator. A useful operating regime is still unproved.


The formal construction now includes faulty physical clocks, probes and correction circuitry, using specified operations on at most six qubits at a time. The complete proof passed a separate internal review; the ZIP preserves the proofs, checks, failures and comparisons.

This removes an essential implementation assumption, but useful performance is still unproved. The next test is microscopic hardware: simpler interactions and real reservoirs, with their noise and cost included, against scheduled correction using the same resources.

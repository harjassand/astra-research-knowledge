# Adaptive stopping and abort normalization clarification
2026-10-29. Mandatory companion to ADAPTIVE_GAP_ADDENDUM.md following independent receiving review.

The averaged returned-channel bounds epsilon+delta (and K epsilon+delta) refer to the unlimited-stage protocol under the fixed IID promise g>0. Almost-sure termination follows, beyond merely high-probability termination: stage confidence failures have summable probabilities delta_l, so the first Borel–Cantelli lemma gives only finitely many failures almost surely, without requiring interstage independence. Since E_l tends to zero, eventually g_lower_l>=g-4E_l and the stopping condition holds. Thus a returned channel exists almost surely. This does not by itself assert finite expected stopping cost; the addendum's finite sample-cost comparison is on the simultaneous-confidence event.

For a finite public cap with explicit abort, the guaranteed bad-return probability is at most delta jointly. The normalized accepted channel need not have error epsilon+delta; if its success probability is A>0, the direct conditional bound is epsilon+min(1,delta/A), capped at one. If a fixed default gate is applied upon abort so the overall protocol is trace preserving, the direct averaged error bound is at most min(1,epsilon+delta+P(abort)). Analogous K-use bounds replace epsilon by K epsilon and count the common calibration bad event only once. Keeping an explicit abort flag is preferable when the operation cannot safely substitute a default. All finite source-call waiting caps add their own abort event.

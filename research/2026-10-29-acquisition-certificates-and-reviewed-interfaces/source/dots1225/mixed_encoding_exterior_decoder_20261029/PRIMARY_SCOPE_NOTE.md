# Primary-source scope check
2026-10-29. Selective check, not an exhaustive novelty review.

- Yoshida, Soeda and Murao, arXiv:2110.00258v4, Lemma4 Eq23 and Eq22/Fig4: the universal compression is a CPTP-map identity for arbitrary input operators, with reference extension implicit in complete positivity. It can therefore be applied to logical-plus-junk inputs without granting control of the junk. The paper's stated decoder task is an unknown pure isometry, not the present access model N(rho)=V(rho tensor sigma)V†. https://arxiv.org/html/2110.00258v4
- Their later arXiv:2401.10137v3, Sec5.1 Eqs134–139, discusses Petz implementation using access to a Stinespring isometry and state block encodings. Its proposed adjointation replacement still uses forward calls to the Stinespring isometry, which are not available from an opaque mixed channel alone. https://arxiv.org/html/2401.10137v3
- Zhu et al., arXiv:2602.05828v1, distinguishes physical channel transformations from virtual adjoint/Petz expectation estimation. That virtual protocol is not a decoder producing the recovered quantum state. https://arxiv.org/html/2602.05828v1

No exact match to the restricted mixed-encoding exterior protocol was identified in these checked passages. This is NOT evidence of historical priority, an exhaustive literature result, or an assertion that all related work has been excluded. Standard unitary/isometry inversion, exterior identities and Schur compression remain credited dependencies.

# CrSBr calibration from charged before and after counts

**A distinct inference operation was constructed and tested. Physical retained depth readout remains NOT_ACHIEVED.** A native reference can remove shared image-background uncertainty without supplying the thermal nuisance label. With a supplied family of changed-state contrasts, the tested operation identifies native/layer 15/layer 16 under a held-out scattering setting, and rejects two deliberate failures. The useful endpoint costs **10⁶ e/Å² total**, including the native acquisition. Real contrast-family coverage, state preparation, calibration disturbance, all-species damage, and retention remain unacquired.

The completed first report/results remain frozen. This continuation changes only its own directory. It uses the same 200 keV, 32 mrad, 16-repeat CrSBr geometry and unrelaxed displacement construction from the [authors' pinned repository](https://github.com/KleinAtomLab/Mesoscale-atomic-engineering/tree/6844cc568271d448704a0eb6ee55ddfd5246d242). This inherits the finite periodic-cell and relaxation limitations; it does not establish an isolated, relaxed defect model.

**Native calibration alone does not acquire the response to a defect.** First I tested exact paired-Poisson conditional scoring. Given a detector/probe feature's before+after count, its after count is binomial with probability r/(z+r), where z is the before/after dose ratio and r the candidate defect/native response ratio. Arbitrary shared native intensity cancels. Nevertheless, rigid response ratios applied to the earlier σ=0.1 Å phonon truths asymptotically report native for all four tested defects (layers 10, 11, 15, 16), including with an infinitely precise native reference. This is an actual-template failure, not a Fisher-information toy. Calibrating the unchanged image does not calibrate the changed-state transfer function.

An ordinary joint likelihood is stronger than a rigid classifier. With the rigid and thermal endpoint families both available, it infers the nuisance from the recorded diffraction data. For the five-class endpoint family, the sufficient worst-class Poisson bound remains about 3,834 e/Å² with no separate native acquisition. Adding a separate native read only increases total dose in that particular model: host scattering already identifies its nuisance. Thus native references are not a universal necessity, and the frozen rigid-model failure was not an information-theoretic prohibition.

**The different acquisition interface learns the background empirically.** Acquire the same 45-point raster before the proposed write and afterward. Use the native/background means b_k as arbitrary nuisance parameters, rather than forcing them to match a rigid or thermal image. For each candidate class h, model

`E B_k = a D_before b_k`,

`E A_k = a D_after [b_k + delta_hk(w)]`,

with `b_k>=0`, `b_k+delta_hk(w)>=0`, and latent `0<=w<=1`. The contrast is an intensity-change mixture between rigid and σ=0.1 Å training endpoints. Neither w nor the true layer is passed to the estimator. The class list is native and layers 10, 11, 15, 16. Power is tested for native/15/16; this is not the full 17-state operation.

Software groups the full detector/probe records into 32 categories using only the ten training endpoint patterns. This retains 22.98% or more of their pairwise Bhattacharyya information. It is a charged acquisition followed by an ordinary software coarsening, not additional free observations. The before state being native is a preparation assumption: arbitrary-background estimation cannot verify pristine structure or absolute atom count. Without that assumption, class 0 means no calibrated change relative to the reference.

The likelihood profiles every b_k analytically through a quadratic root and profiles w globally through concavity. Counts are thinned offline into two independent Poisson halves. Each half trains a proper predictive distribution; the other half tests it against each class's profiled likelihood. Averaging swapped split ratios gives a confidence set. The operation reports a layer only for a singleton set, ambiguity for multiple classes, and model rejection for an empty set. This is ordinary [split/profile likelihood universal inference](https://pmc.ncbi.nlm.nih.gov/articles/PMC7382245/), not a new statistical principle.

For exact null suprema or conservative upper bounds, the mathematical construction bounds the probability of excluding a covered true class by α=0.005, uniformly over its arbitrary shared background and latent w. A wrong singleton therefore has probability at most 0.005. This is neither a bound conditional on acceptance nor a success/yield guarantee. The implementation uses floating-point supporting-tangent upper bounds. Thirty random profiles were checked against a 1,001-point grid and independent bounded optimization: minimum upper slack about 9.8×10⁻⁸ log units, maximum score disagreement about 1.9×10⁻⁹. These are not outward-rounded certificates. **Numerical coverage remains conditional on the profile bounds being conservative.** The derivation and qualifications are in `INFERENCE_CONTRACT.md`.

**A held-out nuisance setting tests the transfer.** New multislice templates use σ=0.065 Å and four independently seeded Gaussian displacement configurations. Training used σ=0.1 Å and different seeds. No σ=0.065 template is supplied to the estimator or partition builder. These Gaussian parameters are sensitivity settings, not measured CrSBr temperatures or a converged thermal ensemble. A covered w=0.5 mixture supplies a statistical control. Final count tests use a fresh random seed after the pilot, with 2,000 trials per row.

Each all-success 2,000-trial row has a separate 95% Clopper–Pearson lower limit about 0.99816; the layer 15 row has one rejection. These intervals describe count Monte Carlo under the stated forward models, not physical acquisition. The full-data ordinary profile MLE on the same grouped paired counts made no point errors in the tested in-class rows at these doses. The lower-dose deficit is largely the cost of qualified reporting rather than missing point-decision information. A competent ordinary controller gets the same rejection option; no advantage over it is claimed.

The two-Cr control is one additional unrelaxed multislice state under the held-out setting. Its rejection does not establish rejection of every second edit, different hidden depth, S/Br loss, contamination or relaxation. The drift control changes the native scattering setting between acquisitions, violating the shared-background law; rejection catches that particular failure. Native counts do not establish general contrast transfer. Indeed, the best additive fits to held-out layers 15/16 still have minimum joint KL residuals about 2.72×10⁻⁵ and 2.32×10⁻⁵ per unit total dose. Correct labels at the selected doses do not prove model coverage or validate the exact confidence theorem for that held-out physics.

**Costs and unresolved return.** The 10⁶-dose pair uses 5×10⁵ e/Å² before and afterward:90 recorded diffraction patterns, about 7.875 million incident electrons, and approximately 63.1 ms beam-on time at 20 pA. Its nominal union raster footprint is 7.875 Å² plus the probe/channeling halo, since the same positions are revisited. Focus, drift registration, detector/count normalization, a genuinely native preparation, and acquisition of the changed-state contrast family are additional costs. A reference on another column adds footprint and a transfer assumption; repeated reference reuse may amortize exposure but requires its own stability and dependence analysis.

The native acquisition can itself change the target before writing, and either image can contain state changes. No such probability or all-species transition law was measured. If this particular static pair demanded≥0.995 no-change probability and one introduced an unmeasured aggregate exponential dose coefficient, its 10⁶ total dose would require a ceiling about 0.501 barn. This is a protocol gate, not a fitted CrSBr coefficient or a universal requirement for microscopy. No SI population-rate conversion is used. A transition-aware ordinary read may track changes instead; its observation/transition kernel must be acquired.

Untimed integrated counts also have a precise boundary. With the actual native/layer 15 detector templates, opposite temporal orders with equal occupation fractions during each retained dwell give identical count means and opposite endpoints. Under a path class permitting both, equal-prior endpoint error is at least 1/2 regardless of count precision. This does not say measured CrSBr dynamics realize those paths. Sub-dwell timestamps, subframes, or an acquired restrictive transition law can escape it. The fixed-pair inference does not hide this temporal assumption or establish optional stopping for repeated pulse/read cycles.

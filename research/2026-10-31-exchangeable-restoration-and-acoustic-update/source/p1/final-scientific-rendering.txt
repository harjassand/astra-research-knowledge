The strongest construction is restoration through exchangeable probes

I have a new operation that moves the structural obstruction beyond the exponential decomposition LP.

After a complete adaptive sequence of binary linear observations of an unknown product-distributed cache, the cache can be restored exactly using a number of fresh source calls controlled by the rank of the disclosed constraints. The operation discovers its restoration set through fresh probes and elementary linear algebra. It does not estimate the source probabilities or search for a global certificate decomposition.

The qualification is essential: the released probe record contains unordered pairs, while their old/new orientations remain private. Revealing those orientations can invalidate restoration. I have proved the result for the complete declared record, tested that identity exactly, and constructed explicit failures when the record is mishandled.

There is also an important comparison limit. A fresh factory can generate linear observations alone at comparable source cost. The distinctive operation here is repair after an observation has already been made and must be preserved, while retaining the rest of a cached world and its computations. I have not established an end-to-end advantage for a scientific learner merely from the inexpensive sketch-generation case.

    probed = []
    unordered_pairs = []
    span = BinarySpan()

    while True:
        i = find_unprobed_column_outside_span(columns, probed, span)

        pair_count = cache[i] + partner

        probed.append(i)
        unordered_pairs.append((i, pair_count))

        if pair_count == 1:
            span.add(columns[i])

    for i in probed:

If each restoration is completed before the next interrogation, the next cache has the correct product law conditional on the entire preceding released record.

Therefore:

a fixed query produces independent output answers across rounds;
an adaptively chosen query has the correct fresh-world conditional law;
the full cache versions remain correlated.

The third point is unchanged. The construction creates valid future query opportunities; it does not turn every retained cache version into an independent dataset.

8. The strongest comparisons, and the failures that matter
Fresh generation of a sketch is a different, already competitive task

For a fresh linear sketch, an ordinary factory can draw two fresh values from each probed coordinate. It records their unordered pair and applies the same span test.

At stopping, the desired sketch is uniform on a known affine coset, so it can be generated using private randomness. Its source cost is also two draws per probed coordinate.

Thus the new restoration operation does not establish a source-cost advantage for generating linear sketches from scratch. If the scientific task permits designing the computation afresh, that factory is a strong competitor and can avoid changing the cached world at all.

The post-selection contract is different. The old observation already exists, and its dependence on the old cache must be repaired without replacing the historical observation. Freshly generating another sketch does not remove that dependence.

This is where the new theorem contributes an operation.

10. What is established, and what remains open

The main completed result is restoration after an adaptive affine disclosure, using exchangeable probes and a rank certificate. It supplies:

an exact conditional-law theorem covering the complete adaptive query history;
an explicit algorithm requiring no numerical source probabilities;
conditional source-cost bounds that count probes and replacements;
polynomial structural preprocessing and incremental matrix maintenance;
a valid model-update wrapper;
a joint approximate guarantee suitable for finite adaptive inference;
exact finite-state checks and an executed adaptive implementation.

The familiar ingredients remain familiar. Exchangeable-pair extraction, conditional resampling, and randomness recycling are established. Resampling-oracle work already treats removal of conditioning and structural composition; the broad idea of recycling a conditionally correct random state is not a new claim. 
epubs.siam.org
+1

A controller can also learn which valid restoration implementation is cheaper from the costs of calls that already produced legitimate answers. For a fixed source law and task, every completed restoration resets the conditional cache law, so ordinary bounded-cost bandit guarantees apply to a finite catalogue. Exploration costs remain charged, and the comparison is only with that catalogue. UCB’s logarithmic regret guarantee is established machinery, not a new learning theorem. 
people.eecs.berkeley.edu

The earlier results remain intact with their original scopes:

the one-pass adaptive restoration characterization and LP;
the information balance;
the optimal recursive witness;
the model-update wrapper;
the failed minimal-certificate rule;
the absence of an established efficiency advantage for the earlier posterior proposal.

The new operation leaves that one-pass class through fresh probing and exchangeability. It does not invalidate its converse.

The research frontier is now more precise: identify a consequential computation in which an already disclosed, low-rank or otherwise symmetry-controlled decision must be preserved, and in which retaining the remaining cached computation beats the strongest fresh factory after all maintenance and preprocessing costs are included. Arbitrary adaptive learning still needs more structure, and the current experiments do not establish that application-level advantage.

These proofs and checks are internal results from this turn; priority and independent review remain open. The public Astra sources were used under the pinned governing repository state.

## Assumptions and exclusions
Common positive damping, compatible number-preserving self-adjoint H_f, initially vacuum private reservoir, bounded system coupling operators with acquired controlled encodings, and prescribed system intervention times are binding. Zero direct coupling to a particular mode does not permit deleting it if H_f can populate it.

Unequal damping mixed by H_f, excitation-creating H_f, arbitrary nonlinear thermal preparations, public bath colors/timestamps, adaptive intervention times and normalized rare-postselection guarantees are excluded. The previous harmonic thermal-doubling result is included as separate capital; it does NOT turn this nonlinear interacting theorem into a thermal-bath theorem.

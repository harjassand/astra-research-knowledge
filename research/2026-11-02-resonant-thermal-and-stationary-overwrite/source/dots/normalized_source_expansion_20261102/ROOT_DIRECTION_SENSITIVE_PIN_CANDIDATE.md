# Parked next refinement: own off-diagonal columns, not every diagonal control

2026-11-02. Candidate, not yet part of the admitted source dictionary.

The current rigorous full-column dictionary owns every clock appearing in a dressed perturbation. This can overcharge diagonal clock controls generated by Pauli-prefix conjugation. A native clock matrix unit becomes one off-diagonal clock factor, a data Pauli prefix segment, and diagonal commutation-phase functions on other clocks. Those diagonal factors are instantaneous insertions, not a requirement to replace their entire clock trajectories.

Proposed refined marks:
- Full columns for clocks actually changed off-diagonally and for stabilizer fluxes flipped by the data Pauli word (the latter carry time-dependent syndrome seams).
- Time-point pins for remaining diagonal clock functions. Expand a general diagonal function into clock Fourier unitaries, normalized to value1 at clock0, so each factor is a product over the rod containing that insertion time. Coefficients remain signed/complex and charged. Projectors with vacuum value0 must NOT be treated as multiplicative pins without this expansion.
- Data/bath overlap and point/full clock contact must still merge used-label components with matching hard-core compatibility.

For an exterior winding rod, an instantaneous pin samples its duration-biased measure, not all beta starts:

 integral |winding activity| 1_{rod contains fixed time}
 =2g^2(A^-2)_(1,K-1)
 =J0 (K^2-1)/(6t).

For g=eta t/K this is O(eta^2/K), rather than beta J0. Positive nonwinding singleton factors remain bounded by1 in modulus. Thus point pins might be charged per actual V insertion, while only off-diagonal/flux-changing cores pay full-column pressure. This separates data support, syndrome-flip width, owned clock count and diagonal pin count.

A clock prefix's syndrome width can depend on the ordering of physical Pauli factors, potentially much less than its total weight. Optimizing that width is a finite graph-ordering/cutwidth problem; it is not automatically small for every stabilizer. Nor does a small syndrome width alone remove all diagonal clock controls.

Needed before use: exact mixed-history factorization with point pins, per-event coefficient norm accounting, enlarged contact grouping, and second-level event KP/influence. No time-dependent control or noisy WRITE admission follows from this static projected-Gibbs idea.

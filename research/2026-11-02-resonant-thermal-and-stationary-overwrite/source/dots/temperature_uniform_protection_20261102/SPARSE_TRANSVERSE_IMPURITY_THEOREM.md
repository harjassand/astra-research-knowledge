# Uniform-low-temperature theorem for sparse arbitrary quantum impurities

2026-11-02. **Proved restricted-trace mechanism; decoder saturation extension stated with its explicit geometric premise.** This is a consequential subclass on the same native physical Hamiltonian, not a generic extensive perturbation phase.

## 1. Setup

Work in the exact bounded-depth native dressed frame, unitarily equivalent to the same physical two-body clock reference Hamiltonian. The full reference H_ref is block diagonal in actual valid data syndrome s and identity on the logical qubit. All clock excited states are retained. An independent arbitrary bath Hamiltonian H_B may be included; it commutes with data syndromes and cancels from reference syndrome probabilities.

Let V be any Hermitian operator (or sum of local operators) whose data Pauli expansion changes syndrome only inside a fixed set F. This includes arbitrary clock and bath operators in its coefficients. Let G_F be the finite subgroup of actual syndrome translations generated by those data Pauli supports. No small-beta assumption is made. Set M=||V||; for k bounded-strength local impurities, M<=k v times the local dictionary-free norm convention.

Let B be a decoder bad-event projector, diagonal in data syndrome and identity on clocks, logical qubit and bath. Define its orbit saturation

  E_F(s)=max_{g in G_F} B(s+g),  P_F=sum_s E_F(s)P_s.

The maximum is taken only on actual valid syndrome translates. Then B<=P_F, [P_F,H_ref]=0, and [P_F,V]=0 exactly.

## 2. Exact restricted Gibbs comparison

For every beta>=0,

  Tr[B e^{-beta(H_ref+V)}]/Z_V
    <= exp(2 beta M) Tr[P_F e^{-beta H_ref}]/Z_ref.      (S)

Proof: P_F reduces both Hamiltonians. On its range, -M I <=V<=M I. Eigenvalue monotonicity/min-max implies

  Tr_{P_F} e^{-beta(H_ref+V)} <= e^{beta M} Tr_{P_F}e^{-beta H_ref}.

On the full space, the opposite bound gives Z_V>=e^{-beta M}Z_ref. Combine and use B<=P_F. This uses monotonicity of **traces of exponentials on invariant subspaces**, not false operator monotonicity of the exponential. It is valid for arbitrary signs, coherent couplings and logical-sector selection, with all bath/clock states included.

This exactly normalizes the memory vacuum in the sparse subclass: no Dyson expansion, logical perturbative remainder, or beta-small parameter occurs.

## 3. Decoder saturation witness condition and consequence

Suppose the reference decoder admits a finite-root version of its removable-witness theorem: saturation by syndrome translations supported on F, |F|=f, has

  Tr(P_F rho_ref) <= C exp(c f) sum_{m>=m_*(n)-C_F f} A^m exp(-beta epsilon m),    (W)

where epsilon>0 is the reference per-leaf free-energy penalty, uniform over beta>=beta0. The native rod result gives such a uniform epsilon once its cold/strict-margin conditions hold. For fixed f, this is the same exponent as the original theorem.

Under A exp(-beta0 epsilon)<1, (S)-(W) yield

  p_V <= C' exp(c f) exp{-beta[epsilon(m_*(n)-C_F f)-2M]
                                  +log(A)(m_*(n)-C_F f)}.

Thus if f and M are fixed while n grows, the actual full-Gibbs bad probability is stretched-exponentially small uniformly over all beta>=beta0, at any fixed finite impurity strength. More generally, f and M may grow provided their charged losses remain a sufficiently small fraction of m_*(n). For M<=v k and f<=c0 k, this admits k=O(m_*(n)) with a sufficiently small coefficient, including genuinely growing collections of arbitrary transverse impurities.

This is not a fixed-density open ball: the allowed impurity count is tied to the decoder witness scale rather than volume.

## 4. Why the existing full-trace geometry should give (W), and what to check

For a fixed orbit element g, the bad decoder comparison uses syndromes s+g and s+g+delta(e). Add the original full trace T(s). Join matching stencil vertices across these three copies and root at the fixed set F plus the bounded fault neighborhood. In each run, the selected set is a union of whole trace components. In the original run, its base syndrome tau is therefore valid/removable by the existing local-row telescoping proof. The other runs differ from s only on F union supp(delta(e)), so their selected base masses differ by at most O(f+1). Three-run instead of two-run accounting changes constants only.

If the union is disconnected, every relevant component meets one of the prescribed roots; one must count rooted forests rather than assert a single bounded-degree rooted animal. The number of forests with total size q and a fixed set of O(f) roots is at most C^(q+f): assign each component a canonical first root, sum compositions of q among roots, and use bounded-degree animal counting per component. No n^f placement factor occurs because the impurity locations are fixed, not chosen in the Gibbs event.

The correction-support/distance argument applies to the total selected mass and loses O(f) from the artificial shifts. Whole-component removal leaves an injection on the original valid syndrome space. These observations supply (W) provided the original causal-attachment and complete-stencil trace hypotheses extend to the union of the finitely many supplied fault roots. For fixed support F this is the direct finite-root version of the earned proof; for growing f, the explicit forest counting and support bookkeeping should be independently checked before quoting the strongest mesoscopic claim.

There is no need to enumerate all 2^f orbit elements individually: the witness labels can include the values of g on F at cost exp(O(f)), already paid in (W).

## 5. Relation to essential target

This is genuinely transverse and uses the full native Gibbs state. It is not merely a commuting diagonal perturbation result or a ground-gap statement. It also automatically handles exponentially small logical splitting at beta -> infinity. Its limitation is spatial sparsity: orbit saturation of a fixed-density generic perturbation would erase too much syndrome information and can become the whole space. Therefore this exact mechanism cannot establish the desired extensive fixed-v phase without a genuinely dilute quantum-excursion estimate.

Root's stationary-state ideal-SWAP consumer applies with a commutator scale bounded by the actual impurity norm (rather than an unnecessary vn bound). The resulting lifetime remains exponentially/stretched-exponentially large in the witness scale within the stated sparse subclass, subject to the same ideal WRITE/READ scope.

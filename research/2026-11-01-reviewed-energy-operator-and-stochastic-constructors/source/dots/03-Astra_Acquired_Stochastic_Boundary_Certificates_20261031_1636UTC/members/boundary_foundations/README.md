# Constructive stochastic stability: a boundary obstruction and an acquired repair

## What was earned

This package develops one mathematical obstruction rather than claiming the general weak-reversibility conjecture: **a fast conservative linkage can monopolize every finite marked-target episode while the stabilizing action occurs in a slower linkage.** An exact complex-balanced negative control proves that merely extending the episode length cannot solve that obstruction.

Two complementary raw-list constructions now have ordinary proofs and executable exact certificates:

1. **Terminal-gap acquisition.** A finite family of rational cone problems over boundary coordinate subsets and actual linkage classes acquires the missing rare-terminal condition. Success proves classwise nonexplosion/positive recurrence and finite stationary mean genuine jump intensity, at arbitrary finite molecularity. The finite selector is implemented with rigorous rational logarithm intervals. It does not assume a decomposition, Lyapunov function, stationary law, or exceptional radius.
2. **Infinite-fiber pivot-star repair.** When same-linkage terminal gaps fail, a distinct acquired rational-ratio correction handles arbitrary-dimensional catalytic star lifts of any one-species weakly reversible core, with arbitrary high-degree reactions preserving the pivot and total count. Its extinction face is proved separately. For this restricted class the compiler constructs a global geometric Foster inequality and earns every exponential total-count invariant moment. The executed cubic three-species witness is not complex balanced.

`compile_recurrence.py` accepts an actual raw list, tries the acquired pivot route, then the terminal-gap route, and otherwise returns **UNKNOWN**. These are sufficient routes, not a complete classification. No historical novelty, physical implementation, or civilisation-scale capability is asserted. The main gain is an acquired boundary-corrector operation and an exact account of why the simpler operation fails.

Python 3 and SymPy are used for the pivot rational-function algebra. The terminal-gap finder and selector use the Python standard library only.

```text
python pivot_lift.py
python compile_recurrence.py
python terminal_gap/exact_terminal_gap.py
python terminal_gap/select_episode.py
```

The pivot prototype operates on the theorem's trusted exact rational input contract (integer/Fraction arithmetic) and its own unmodified recognition records. It is not a hardened validator for externally supplied certificates or floating-point inputs. The terminal-gap module separately includes a no-LP certificate verifier; that property is not silently transferred to the pivot prototype.

The program output's finite grids are consistency challenges, not infinite-state proofs. The cone certificate verifier checks every relevant coordinate subset and linkage; its consequences come from the written recurrence proof.

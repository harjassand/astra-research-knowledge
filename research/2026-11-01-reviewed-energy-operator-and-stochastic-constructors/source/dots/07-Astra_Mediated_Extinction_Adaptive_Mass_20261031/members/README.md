# Acquired regenerative mass across mediated extinction

**Result:** a raw-list exact rational search acquires a normalized weighted mass proving classwise positive recurrence and every finite exponential total-count moment for its accepted cone. It always succeeds, without a finite search budget, for every positive rational rate choice of

    0 <-> A;  A+B <-> B+C;  A+C <-> 2B;  B+C <-> 2C.

This three-species weakly reversible family has accelerated last-copy A loss and mediator-dependent recovery. For a non-complex-balanced executed member, the acquired function is

    W=t^N [1-epsilon (A+B/3)/(N+1)].

The complementary no-go proves that **no positive normlike function F(A,N)** can satisfy one-step geometric Foster drift on the positive-satellite class. Correctly acquired composition information matters; merely enriching the same aggregate memory cannot fix that obstruction.

## Replay and status

The source-bound independent audit accepted this restricted mathematical boundary. Its nine challenge cases passed 12,597 ordinary and 230 huge-state exact quotient checks plus 574 direct expanded-value checks; nine tampered certificate fields were rejected. It independently reconstructed the cone and its exact basis search. These finite checks supplement the ordinary all-state proof.

The main constructor uses Python standard-library `Fraction` arithmetic:

    python adaptive_mass.py > replay_results.json
    python independent_audit/verify_adaptive.py > replay_challenges.json
    python independent_audit/extra_controls.py > replay_extra_controls.json

The constructor is a **trusted int/Fraction research API**, not a hardened externally supplied certificate verifier. It accepts its own recognition record as trusted mutable data. The independent audit recomputes raw generator quantities separately; read its precise scope rather than inferring hostile-input security from successful tests.

The main demo pays 62 exact candidate bases (41 nonsingular), 3 LP variables, 9 inequalities; its largest solved basis fraction has 4 bits. It checks 5,456 small states and 25 targeted states exactly. Counts up to 10^50 are checked using drift quotients, not impossible expansion of t^N. The analytic finite-exception radius is R=431, corresponding to 13,436,856 possible states; they are **not** enumerated. Finite constants have explicit rational-power form and declared expansion bit budgets.

Default basis cap is 200,000. Set the programmatic `max_bases=None` for unbudgeted finite cone enumeration. A budget stop is UNKNOWN. Exhausting all bases rules out only this cone, not stability. For every requested rational t>1 the same weight yields a new explicit certificate; constants and computational cost are not uniform across t.

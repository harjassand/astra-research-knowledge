# Forward memory drift with no total-bath-energy bound

Date: 2026-10-30. New root working derivation, not independently reviewed.
This extends the source class of the uniform-control construction in THEORY.md.
It does not promote any earlier finite check into an unrestricted all-Fock
claim. Sources failing the local regularity conditions below remain excluded.

## 1. Precise replacement for a bounded memory Hamiltonian

Let H_M be self-adjoint, possibly unbounded. Its unitary group exists, and the
three bounded native couplings have norm-smooth memory orbits

\[
\alpha_t(A_j)=e^{iH_Mt}A_je^{-iH_Mt}.
\]

For each finite order r needed by a selected compiler word, assume known
uniform bounds \(\|\delta^r(A_j)\|\le h_r\), where delta is the generator
of this norm-differentiable orbit. The usual domain compatibility of these
bounded commutators is included. For example, finite spin baths with the
local bounds in Section 5 satisfy these assumptions uniformly in size.

For arbitrary requested accuracy, the source class must supply the bounds
at every finite order reached by polynomial compensation. A fixed finite
differentiability order alone does not grant arbitrary accuracy. The
native couplings retain the same specified data and mediator Pauli form;
the scalar chirality is in a known positive interval. They are static and
the waveform is classically prescribed. Native sign symmetry and control
timing are physical resources, not generated by this theorem.

No bound on \(\|H_M\|\) appears below. Remote memory energies that do not
affect the local orbit derivatives are irrelevant to this error estimate.
There is no bath initialization, inverse, or replacement between calls.

## 2. Interaction-picture jets preserve the native extraction identity

Normalize an extracted native word to total duration T. Its piecewise-constant
controlled Hamiltonian K(s), for 0 <= s <= 1, specifies the actual relative
durations, signs, and temporary amplitude scalings. The exact interaction-
picture generator and propagator are

\[
G(T,s)=-iT\alpha_{Ts}(K(s)),\qquad
U_I(T)=\mathcal T\exp\left(\int_0^1G(T,s)ds\right).
\]

This is a bounded-operator, norm-differentiable family in T. Its finite Taylor
coefficients follow from the Dyson expansion and are polynomials in bounded
operators \(\delta^r(K(s))\). No power of the unbounded H_M is applied
to an input state.

The native extraction lemma in THEORY.md says that the formal full-word
logarithm has only memory terms below odd degree k, a clean degree-k term
\(i\eta T^kP\), and no nonmemory term at degree k+1. This cancellation
identity also holds for the interaction-picture jets. To translate the
formal identity, commute each formal D symbol to the left with
\(DA=AD+[D,A]\), before cancelling the free-memory factor. The remaining
coefficients contain controls and their nested memory commutators. Terms
whose data factor is I remain memory-only. The desired P commutes with
every memory operator, so removing free-memory evolution does not introduce
a data term at degree k+1.

The norm-smooth memory orbit represents this same derivation algebra: delta
obeys the product rule, preserves data factors, and acts on all products
occurring in the finite jet. Consequently the resulting formal identities
are bounded-operator identities on this class. This argument uses the
finite interaction-picture jet, not a norm Taylor expansion of the full
Schrodinger-picture unitary for unbounded H_M.

Define the mathematical target-removed family

\[
F(T)=e^{-i\eta T^kP}U_I(T).
\]

Every nonmemory Taylor coefficient of F through degree k+1 vanishes. The
first factor is only a comparison operation; no physical perfect logical
gate is inserted into the native word.

## 3. Explicit remainder bound from local derivatives

Fix T0 > 0. Differentiating G gives, for q >= 1,

\[
\partial_T^q G(T,s)=-i\left[
q s^{q-1}\alpha_{Ts}(\delta^{q-1}K(s))+
T s^q\alpha_{Ts}(\delta^qK(s))\right].
\]

Thus \(\|\partial_T^qG(T,s)\|\le qh_{q-1}+T_0h_q\), uniformly
for real 0 <= T <= T0 and 0 <= s <= 1. Choose a known bound eta0 >= |eta|
using the compiler coefficient and c_+. For q from 1 through k+2 put

\[
g_q=qh_{q-1}+T_0h_q+
1_{q\le k}\,\eta_0\frac{k!}{(k-q)!}T_0^{k-q},
\]

and define nonnegative numbers a_n by

\[
\exp\left(\sum_{q=1}^{k+2}g_q\frac{z^q}{q!}\right)
=\sum_{n\ge0}a_nz^n.
\tag{1}
\]

Successive parameter Duhamel expansions give
\(\|F^{(n)}(T)\|\le n!a_n\). Here is a direct coefficient argument.
For a real reference T, express the variation propagator at T+z relative
to T. Its formal perturbation generator has coefficients
\(\partial_T^qG(T,s)/q!\), conjugated by unitaries. Taking their norms
does not change those bounds. In the time-ordered variation series, sum
over all derivative orders at each insertion. The scalar ordered integrals
are bounded coefficient by coefficient by the exponential of the integrated
scalar series. This gives (1). The target-removal factor is included as a
second mathematical unit-duration evolution with generator
\(-i\eta T^kP\); its derivative bounds are the last terms in g_q.
This reasoning needs only the stated finite differentiability order.

Let \(E_D\) be normalized data partial trace followed by tensoring I_D,
and \(Q=I-E_D\), with \(\|Q\|\le2\). Taylor's theorem and the
vanishing nonmemory jets yield

\[
r(T)=\|QF(T)\|\le2a_{k+2}T^{k+2}.
\tag{2}
\]

For r(T) < 1, the conditional-expectation polar argument supplies a
memory unitary V_I with

\[
\|U_I(T)-e^{i\eta T^kP}\otimes V_I\|
\le r(T)+1-\sqrt{1-r(T)^2}.
\tag{3}
\]

The actual Schrodinger-picture reference is
\(e^{i\eta T^kP}\otimes e^{-iH_MT}V_I\), on the same complete
memory. For fixed useful coefficient, repetitions accumulate O(T squared)
error as in the original construction. The per-cycle bound is an operator
bound on all input states, so repeated use does not assume an independently
initialized bath.

This is a local-regularity estimate rather than a total-energy estimate.
It preserves the fixed-program limitation: different pulse choices may
have different memory references, and coherent control of those choices
requires a separate qualified operation.

## 4. Signed-only amplitude compilation without a total-energy bound

The original Strang estimate used \(\|H_M\|\). A first-order splitting
is enough here. For a desired amplitude 0 <= lambda <= 1, let
\(p=(1+\lambda)/2\) and \(q=(1-\lambda)/2\). Use cells

\[
e^{-ip\Delta(H_M+A_j)}e^{-iq\Delta(H_M-A_j)}.
\]

The two scaled anti-Hermitian generators have commutator norm at most
\(2pq h_1\). The unitary Duhamel commutator bound gives cell error at
most \(pq h_1\Delta^2\) relative to
\(e^{-i\Delta(H_M+\lambda A_j)}\). Repeating r cells over a duration
t gives

\[
\epsilon_{\rm PWM}\le\frac{pq h_1t^2}{r}
\le\frac{h_1t^2}{4r}.
\tag{4}
\]

The smooth bounded-commutator premise supplies the requisite domain
conditions for this Duhamel estimate. All actual physical durations are
positive and sum to t. The splitting is chosen to meet a finite total
accuracy budget; it is not claimed to preserve exact formal coefficients
at fixed r. More switching and finer timing remain real costs.

## 5. A source class independent of retained bath size

Place the mediator at endpoint site 0 of a spin chain. Let the unknown
memory Hamiltonian be a sum of arbitrary on-site and nearest-neighbor
bond terms, each with operator norm at most J. The controlled B_j act
only on site 0, with norm at most B0.

In an r-fold nested commutator, support can grow at most r sites from
the endpoint. At the q-th commutator, at most 2q on-site/bond terms
touch the preceding support. Each commutator multiplies a norm bound
by at most 2J. Hence

\[
h_r\le B_0(4J)^r r!
\tag{5}
\]

uniformly in finite chain length. With only bond terms the sharper
\(B_0(2J)^r r!\) suffices. The chain's total Hamiltonian norm can
grow with the number of spins; it does not enter (1)-(4).

The same prescribed program therefore serves every finite chain length
with these local promises, arbitrary unknown interaction coefficients,
arbitrary initial chain states, and arbitrary external reference
correlations. The local commutator bounds do not imply a short pulse word.
They show that increasing memory size does not by itself require more
microscopic identification or history storage for this operator-level task.

Combining this extension with the odd-chirality polynomial construction
gives a uniform entangler for a positive-orientation source class coupled
to an arbitrarily large retained local bath. Coupling geometry and local
interaction bounds replace full bath tomography or initialization in the
information contract. The unknown-gain action lower bound still applies:
in an interaction picture, bounded controls give the same entire gain
dependence even when total H_M is unbounded.

The remaining physical gap is explicit. Unknown data holding, sign errors,
waveform delivery, finite timing resolution, source qualification, and
calibration/probe operations have not become free. The current literal
compiler can impose a very severe control and holding budget. This is a
foundational source-class result, not a practical device advantage or a
new fault-tolerance threshold.

## 6. Finite timing precision without a total-energy norm

Rounding segment times in the bounded-H_M theorem was charged with the
total generator norm. That argument must be replaced here. Let one complete
nominal word have durations t_j, total T, and start times S_j. Let the actual
durations be t'_j = t_j + Delta t_j >= 0, and set
\(D_t=\sum_j|\Delta t_j|\). Its start-time error satisfies
\(|S'_j-S_j|\le D_t\).

In a common normalized segment coordinate u in [0,1], the two interaction-
picture generators are
\(-it_j\alpha_{S_j+t_ju}(K_j)\) and
\(-it'_j\alpha_{S'_j+t'_ju}(K_j)\). The local bounds give their integrated
norm difference at most

\[
B_0|\Delta t_j|+
t_jh_1\bigl(|S'_j-S_j|+\tfrac12|\Delta t_j|\bigr).
\]

Since \(|S'_j-S_j|\) is bounded by the sum of the preceding absolute
duration errors, the parenthesis is no larger than D_t. Segmentwise Duhamel
comparison and telescoping therefore yield

\[
\|U'_I-U_I\|\le(B_0+h_1T)D_t.
\tag{6}
\]

The different final free-memory duration is absorbed into the actual
same-memory reference \(e^{-iH_MT'}V_I\). No norm estimate of
\(e^{-iH_MT'}-e^{-iH_MT}\) is required. Consequently a finite rational
timing grid can approximate every finite nominal word to any chosen
additional logical/product error using only the local constants. This
removes the need for exact irrational durations in the existence theorem.
It does not supply a clock of that quality: both the word length in D_t and
its total duration T can make the required resolution extremely stringent.
Always-on data holding and sign/amplitude errors remain separate bounded
Hamiltonian perturbations to be charged over the actual duration.

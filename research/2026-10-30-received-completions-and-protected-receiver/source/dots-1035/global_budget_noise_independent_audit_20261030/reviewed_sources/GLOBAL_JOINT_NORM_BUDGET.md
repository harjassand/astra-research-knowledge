# Global joint-norm budget: unknown strong hot spots as a constructive target
2026-10-30. Root candidate, not reviewed. Question: can the accepted GLOBAL-radius native architecture tolerate a small unknown population of strongly defective components without locating them, rather than assuming every site is weakly perturbed? This is a possible hardware-yield consequence, not a claimed advantage or a mere change of constants.

## 1. Precisely different assumption
Retain bounded system body size q, actual full joint CPTP propagators and the nominal bounded-degree/local-dimension/rate architecture. Replace the pointwise per-site noise budget by

  Σ_Z ||N_Z*(t)||_cb ≤ η N

at every time, with each Z containing at most q system sites. The shared external bath remains inside the JOINT norm. Terms can concentrate on unknown sites and change locations over time; no fixed noise-partner graph is required.

This is a worst-case generator-norm budget, NOT a time average, state-average power, marginal decoherence rate, calibration score, or a bound on Σ||Tr_bath N_Z||. The earlier rare common-bath pulse counterexample is not removed: a pulse violating this instantaneous total bound remains excluded. Center identity actions if needed at the already proved factor2 cost. Never allow cancellation of uncontrolled/unbounded bath terms to masquerade as a small declared decomposition norm.

A fraction f of permanently defective fixed-degree components with individual joint generator-difference bounds R would contribute at most C f R N. They may be strongly perturbed relative to the original per-site threshold, but the TOTAL can still be below ηN. This does not cover infinite-strength faults or a single failed high-fanout global controller hidden inside the nominal bounded-degree model.

## 2. Why the global memory proof appears to use only this sum
For the accepted F=T_B T_t(VG), a q-site HP perturbation is conjugated through only a fixed finite cone of the known proof circuit. The local relative/dilation estimate is

  N_Z*F ≤ C(q) ||N_Z*||_cb F.

Its constant depends on support size and actual fixed controller maps, not on the number of other noisy terms incident at those sites. Summing immediately gives C(q)ηNF under the GLOBAL budget. The canonical local-edge identity requires bounded support, not small individual amplitude. The full-versus-killed Duhamel prefactor uses the sum of local generator norms, now still O(N). Thus the global energy moment, boundary mass and fixed correctable-radius conclusion appear unchanged.

This is an audit target: any hidden use of per-site noise strength elsewhere in the accepted complete proof must be found before acceptance. The NOMINAL architecture remains bounded degree with fixed rates; only the additive actual-noise allocation is broadened. Earlier animal/spacetime-service theorems are not silently generalized.

## 3. Live BUSY tail also appears global
For the accepted full-catalog singleton activity weight G_busy, each q-site noise term has a bounded finite-cone congruence estimate. The refined centered form is

  +/- N_Z*G_busy ≤ Cδ ||N_Z*||_cb G_busy.

Again summation needs only the total budget. The exact nominal drift and maskwise log bounds then give

  L_actual*G_busy ≤ −λ G_busy logG_busy + Cδ(ε²+η)N G_busy,

and the uniform pointwise macroscopic BUSY tail. No subset-wise noise law is needed for this GLOBAL tail. This is sufficient for the live bare-DATA common span, while the old per-subset readiness assertions may fail at a hot spot and should NOT be claimed.

## 4. Replace subset tails by a global completion moment where needed
Readout/boot/carrier proofs previously used per-site subset hierarchies. For a product of independent nominal finite modules, each with 0≤A_i≤I, a B_i≤A_i≤B_i and L_i*A_i≤−r A_i, define

  H=∏_i(I+θ A_i),  θ>0 fixed.

Disjoint module factors commute. The nominal product rule gives

  L_nom*H ≤ −r H Σ_i [θ A_i/(I+θ A_i)]
           ≤ −[r/(1+θ)] H logH.

The scalar inequality x/(1+x)≥log(1+x)/(1+θ) holds on0≤x≤θ. Each centered bounded-body noise map touches only O(q) factors and has H-relative norm at most Cθ||N_Z||, by subtracting its identity action and using bounded factor inverses. Thus

  L_actual*H ≤ −λ HlogH+CθηN H.

Scalar Jensen contracts log Tr(Hρ) from any initial state toward O(θηN). Since H≥exp[log(1+θa)Σ_i B_i], this yields an exponentially small tail for too many unfinished modules after a fixed sufficient dwell, under a global budget. It does not promise correctness at a particular defective module.

Complete pointer/controller resets are one-site modules; the already constructed finite Bell-pointer/carrier chain is a fixed column module. Native retirement witnesses are not independent modules, so their old subset proof should not be imported here. The live BUSY route avoids needing that retirement step.

## 5. Finite-window support and physical consequence
The readout/boot forward Dyson tail already uses only the integrated TOTAL norm CηNT and bounded support per insertion. Concentrated noise does not change that estimate. Each insertion still adds a fixed number of DATA/owner/carrier footprints. The positive common-span and signed-normalization steps are therefore plausible unchanged once global completion moments replace the former subset bounds.

If all these interfaces pass, the resulting operation would store and destructively read encoded quantum information while tolerating an unknown sparse population of bounded-strength permanently bad local components, without first mapping their locations. It would NOT establish useful numerical yield, unrestricted hardware failures, an efficient diagnostic, arbitrary faulty global classical control, or a separation from equally informed scheduled QEC with adversarial-error tolerance.

The strongest ordinary comparator must be allowed the same global error budget, code distance and hardware resources. Published adversarial-error/single-shot decoder guarantees may already provide much of the corresponding code-level capability. The potentially nontrivial part here is the actual continuously operating native controller and physical finite-output composition, not the observation that a distance-d code corrects fewer than d/2 bad qubits.

## 6. Explicit excluded transfers
The old stochastic LOCC theorem and its native compiler use spatial service/ancestor arguments, so their noise scope is NOT broadened by this note. The rate-separated recipient theorem still inherits its old source's Poisson/local assumptions during source waiting. Likewise an arbitrary public calibration dataset does not certify the worst-case global joint-norm hypothesis. This candidate concerns a rigorously declared physical-error class, not automatic acquisition of that class from finite observations.

## Initialization / physical-failure interpretation
The stored logical input must still satisfy an earned encoded or warm-input contract. A global noise budget does not construct an encoder through unknown missing hardware. A permanently faulty component is covered only when its effect is representable within the fixed physical Hilbert space by bounded-body joint generator differences with the declared finite norm budget (for example cancelling a bounded number of its nominal terms and adding bounded local dissipation). Infinite-rate destruction, undeclared loss levels, unbounded fanout, or an unverified source state are not covered. Controller finite reset can be reanalyzed with a global completion moment, but bare unknown-input encoding remains a separate operation.

## Load-bearing facts, not a decoder convention
A signed resource is Omega_s=vec(Pi_s)/sqrt(K), with unknown possibly coherent common syndrome s. Full physical Bell outcome P produces transfer Pi_s P^dagger/sqrt(KD). Applying the ACTUAL physical P returns a sector-zero input to the same sector-zero code. Before that correction, the receiver remains in C_s, not the standard zero-syndrome code.

Therefore a standard zero-syndrome receiver engine cannot simply run unchanged during resource waiting or extensive-mask latency. The fact that the resource has a correctable RELATIVE error says nothing about its absolute syndrome density. Treating the missing raw mask as a logical Pauli frame is wrong: it can have extensive nonzero syndrome. The old logical-Bell-switch result assumed zero-syndrome encoded Bell links and cannot silently replace this resource.

## Common-bath scope that must be earned
A first atomic-resource composition must retain the Poisson-CPTP fault-location class. The native receiver can work in that subclass of its larger continuous joint-noise model, but the atomic Bell theorem cannot be promoted to generic coherent noise by composition.

All protected DATA blocks remain PHYSICAL sites in ONE bounded-support/incidence decomposition. One may retain a common EXTERNAL bath, but may not reclassify another protected block as an unconstrained bath and then claim its faults are local. Resource-only known-Bell accuracy and source-memory logical accuracy must be combined through one positive common-record/coefficient span, not a product of reduced states or an independent-bath assumption.

## Strict-live candidate
The uncorrected teleported state remains in the SAME signed sector C_s as the resource half. A receiver engine correcting relative to a physically frozen shared Alice syndrome baseline can therefore remain live during finite raw-mask latency. Required actual steps would include:
1. acquire one shared baseline record per local view/check using finite noisy local instruments, with all readers using the same underlying value;
2. redirect the old Alice worker from quantum checks to these classical records after Alice is consumed, with FIFO/cache purge semantics retained;
3. materialize the full raw Pauli mask by fixed finite onsite program registers;
4. reconcile the baseline/controller engine to ordinary zero-syndrome protection without an ideal inverse frame or uncharged stale cache.

There is a useful sparse-difference relation: on the common good event, baseline a differs from sigma(P) only by input/resource/measurement defects. Replacing a by sigma(P) is therefore a sparse program change even though both strings can be extensive. With the full mask applied, conjugating relative correction with baseline sigma(P) gives ordinary zero-baseline correction at the CHANNEL level. Actual asynchronous program labels, stale classical caches and native prefix frames still need a proof. The channel-level identity is not yet a live-controller handoff.

## Simpler bounded-pause fallback
A finite, explicitly charged pause can avoid the baseline seam: disable atomic resource DATA operations, perform full physical Bell measurement, transmit/apply the raw mask with finite noisy controls, and initialize/enable a fresh ordinary receiver using the already accepted finite controller boot plus an EARNED global-moment warm input. No ideal encoded Bell factory or decoder/re-encoder would be needed. Correctable encoded quantum information could be protected through the bounded stage and afterward, with all waits charged. But this is NOT an engine remaining actively correct­ing throughout the unknown-mask latency. It must not be advertised as the stronger strict-live result.

## Ordinary comparator
An equally informed scheduled teleportation implementation gets the same raw Bell source, matched local couplers, measured channels, finite control stages and classical reliability resources. It can use the same signed-sector identity, pending-frame technique or bounded protected pause. No teleportation/Pauli-frame novelty or practical advantage is claimed. A real new bridge must supply the common-channel receiver-state and actual-control contract, not merely repeat the exact Bell identity.

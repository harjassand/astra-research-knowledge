# Failed shortcut: a global DATA-free controller-type algebra
2026-10-30. Preserved negative result, before use in any service proof.

A target observable may ignore every W/P and DATA value yet contain an off-diagonal owner-mask term |m><n|. For an actual complete dirty reset with controlled forest unitaries V_m,V_n, summing all erased workspace labels gives the source pullback

    |m><n| tensor V_m^* V_n.

The product can act nontrivially on DATA. Acquisition and cleanup Hamiltonians can generate owner-tag coherences, so excluding them merely by calling the observable classical would change the proof model. Complete erasure removes workspace information; it does not erase retained tag coherences.

`check_controller_type_algebra_failure.py/json` verifies the exact reset algebra with V_m=I and V_n=controlled-X on workspace/DATA: the pulled observable has a nonzero DATA-Z commutator. Thus no global controller-type invariant algebra has been earned on malformed owner states.

A buffered CLEAN restriction may still be controller-only: a good C terminal has full ownership and the same full circuit on both sides, good B0 has identity frame, and other clean exits have identity frame. A finite local witness could then be extended by explicit B-pinching and conditional expectation on DATA, retaining its clean restriction and charging all dirty extension errors to the now-reviewed weighted debt service. Such an extension requires its own support/guard calculation; it is not assumed by this note.

This failure does not invalidate the exact raw exponential lemma, whose terminal weighted target is very special, nor the own-corner moment/congruence proofs. Neither used an arbitrary controller-type adjoint algebra.

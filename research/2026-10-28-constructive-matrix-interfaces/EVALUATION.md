curation. The owner had read the proofs and earlier exposed retrieval context.
This is neither held-out evaluation nor an unassisted-agent trial. Queries
and available/unavailable assumptions were unchanged across the comparison;
no query-specific alias, ranker, model or search-code change was made.

The pre-intake baseline is merged main ca9174c, input version d611210e.
Its 2047 scientific content versions remain unchanged. The new corpus has
2064 records: three new cards and fourteen selective reusable units. The
source index admits 204 selected files, including two owner finite-control
files. This is a computational-algebra slice, not coverage of every result
in the 1639-payload checkpoint or every Astra research field. Static inherited
code dependencies receive no automatic scientific acceptance.

structured operation search and the existing local CPU agent reranker. Before

## Realistic scientific use

For P01, the old menu leads to a different local-algebra counter and cannot
supply this missing conditional sampler. The new first packet supplies a
correct usable premise: for the actually acquired rectangular matrix-product
slice, the three-stratum row-prefix evaluator retains only the original
`2^c` characters. The returned proof shows nonnegative completion-count
branching followed by a uniform affine left-fiber solve. This enables a
researcher to construct exact original-input samples without the exponentially
rare full-fiber rejection route, after checking the explicit character budget,
coordinate bijection and unbiased-draw contract. It does not make arbitrary
original-bit conditioning or unrestricted codimension polynomial.

For P03, the result plus its returned companion-construction alternative gives
the fixed invertible affine representative and the original-input section.
The actual proof states the partial-trace constraints, companion matrix and
all-target identity. This supplies witness synthesis without a count oracle
when every natural multiplicity is at least two. It does not sample the full
fiber uniformly. P07 follows the unequal-size multiplicity-one obstruction
and correctly leaves general preimage-search hardness unsupported.

P06 is deliberately outside the two-factor theorem: three arbitrary factors
and a uniform sampler are not supplied. P04 reaches the actual M8 multiplier
calculation and its nonzero square-zero radical, preventing a false automatic
count-to-sampling transfer. P05 reaches both corrected original translations,
including `u0` and `c+L(u0)`, rather than a merely adjacent matrix theorem.

P08 remains a neural-ranking failure. Full-content search finds the correct
family and structured search returns the exact comparison unit fourth; the
agent top five omit it. The proof-use check reads the actual crossing-fixture
metadata, unique-extension CNF contract, two count timeouts and the separate
empty compilation artifact. It supports no ordinary sampling ratio, broad
solver advantage, SAT witness timing or independent large-count validation.
The distinct-target E6 fixture is not substituted as a matched comparator.

## Checks and limits

Five regression tests protect reviewed artifact versions, the section's one-line
guard delta, actual original-origin and two-flag proof branches, typed positive
count binding, radical incompatibility and evidence-level separation. Independent
finite binary controls enumerate the rejection formulas for p=1 through4,
verify all188 rational sampling leaves, and identify exactly128 left
multipliers among512 conditioned-dual candidates with a nonzero square-zero
two-sided radical. They are not producer execution or a native benchmark.

All seventeen default packets fit the32768-byte route; the largest is27722
bytes. Normalization build/check, unchanged prior content versions, exact
source/index checks and repeated deterministic intake are required separately
from this usefulness result. Raw/portable sources and immutable histories are
preserved. Source-produced execution tables remain attributed; no producer
research script was imported or executed here.

The installed connector independently serves older a1681a9f/8d51d607 rather
than current published P1 d611210e/ca9174c. CLI and Pages source-use success
does not close that deployment failure. It requires actual installed search
and fetch verification after a validated published refresh. The next ranking
improvement should protect useful independent full-content/structured candidates
from reranker omission, evaluated across fresh scientific tasks rather than
adding an alias for P08. No corpus-completeness, Google-superiority or
civilisation-level capability claim follows from this infrastructure.

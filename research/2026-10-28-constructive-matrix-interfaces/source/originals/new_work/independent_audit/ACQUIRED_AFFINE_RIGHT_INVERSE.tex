\paragraph{New operation and exact scope.}
The existing regular matrix-dual counters acquire an evaluation problem but
restrict target geometry and, in some versions, affine phases. This note
constructs an affine right inverse for every consistent output target and
every acquired affine phase, provided that each regular matrix factor has
natural multiplicity at least two. This is simultaneous constructive
inversion on an affine input subspace, not a count or uniform full-fiber
sampler. The elementary matrix completion below is not asserted to be
historically new. The result proved here is its complete acquired-coordinate
construction and original-input interface, including a manufactured
invertible dual map.

\section{Checked input contract}

The raw frontend receives an ordinary indexed Boolean gate DAG with exactly
$n$ declared independent input bits and one final Boolean output. It exposes
actual degree-at-most-two marked registers, reverses a recognized literal
reversible suffix, and obtains a complete-register equality target. Its
shared-DAG traversal visits each wire once; unknown high-degree polynomials
are not truncated. Its algebraic certificates manufacture a source-free
polar split and a simple left nucleus $S\simeq M_p(F)$, $F=\F_{2^a}$.
Internal circuit wires never become independent inputs.

The affine-Hom frontend checks the complete marked identity and supplies
actual binary modules $U,O$, an injective map $\iota:V\to H=\Hom_S(U,O)$,
and $h_0\in H$. Require $\dim_2U=\dim_2O=apd$.
Writing $W=\iota(V)$, the reduced equation is
\begin{equation}\label{eq:eval}
 (h_0+\iota(v))(u)=y,\qquad u\in U,\quad v\in V.
\end{equation}
The full marked target is $b=c_0+P_Oy$ for an acquired injective binary map
$P_O$ into the marked-register space. Target consistency is therefore an
explicit binary linear condition.

The original input map $x=x_{\rm aff}+J(u,v)$ is a known affine bijection.
The offsets after affine-Hom acquisition, not the earlier polar offset,
must be used. If the initial split gave $B(u,v)+L(u)+R(v)+c$ with
$R(v)=B(u_0,v)$, then
\[
 x_{\rm aff}=x_{\rm split}+J(u_0,0),\qquad
 c_0=c+L(u_0),\qquad h_0=L.
\]
The exact certificate keys are \path|original_affine_input_offset| and
\path|original_input_coordinate_columns|.

The acquired reverse-Hom pairing is
\[
 \langle D,T\rangle=\tau(DT),\quad
 D\in\Hom_S(O,U),\quad T\in H,
\]
where $\tau$ is a nonzero binary functional annihilating all commutators
in $\End_S(U)$. Abstractly
$\tau(Z)=\operatorname{Tr}_{F/\F_2}(\gamma\tr Z)$ for $\gamma\ne0$.
This is the reduced trace functional, not the trace of a large represented
binary action matrix, which can vanish at even multiplicity.

Let $\mathcal D=W^\perp$ be the actual reverse-Hom dual. The preceding
regular matrix-dual acquisition checks the full multiplier algebra
\[
 A=\{T\in\End_S(U):T\mathcal D\subseteq\mathcal D\}
      \simeq\prod_{i=1}^b M_{s_i}(F).
\]
Its actual scalar fields agree with the actual field of $S$; equality of

The new additional condition is $h_i\ge2$ for every factor.

\begin{theorem}[All-output affine section]\label{thm:section}

polynomial bit complexity manufactures an invertible $h_*\in h_0+W$.
It constructs $v_*$ with $\iota(v_*)=h_*-h_0$ and the affine map
\[

satisfying the original marked-gate identity
\[

\]
The map $\sigma$ is injective. Its image is an affine input subspace of
dimension $\dim_2O$ containing one representative of every consistent

A native complete-register equality therefore has a witness exactly when

\section{Manufacturing the invertible dual map}

The prior counting proof establishes existence of an isomorphism $D_0:O\to U$
with $\mathcal D=AD_0$. Here it is constructed without searching random
dual combinations for invertibility.

For each $A_i\simeq M_{s_i}(F)$, manufacture primitive orthogonal idempotents
and connecting matrix units using its actual table. The inherited sampler's
primitive-corner algorithm draws a uniform element of a corner, spans the
commutative algebra it generates with the center, and solves $z^2=z$ by
binary linear equations. In a corner of size $r\ge2$, a trial succeeds
with probability at least $1/(8r)$, uniformly in field size. Rank-one corners
need no random search. Connecting units follow from linear equations in
one-dimensional field corners and are checked by multiplication. Thus the
randomness has expected polynomial cost and is not rare invertibility
rejection.

Write $e_i=E^{(i)}_{11}$ and $a_{ij}=E^{(i)}_{j1}$, $1\le j\le s_i$.
The actual space $e_i\mathcal D_i$ has dimension $s_i$ over $F$. Choose an
$F$-basis $D_{i1},\ldots,D_{is_i}$ greedily by testing binary span membership
of all acquired center multiples. No field generator or field-element
enumeration is needed. Set
\begin{equation}\label{eq:D0}
 D_0=\sum_{i=1}^b\sum_{j=1}^{s_i}a_{ij}D_{ij}.
\end{equation}

\begin{lemma}
The map $D_0$ in \eqref{eq:D0} is an $S$-linear isomorphism and
$\mathcal D=AD_0$.
\end{lemma}
\begin{proof}
Its summands have values in pairwise disjoint primitive images
$E^{(i)}_{jj}U$. If $D_0z=0$, applying these projectors gives
$a_{ij}D_{ij}z=0$. Each $a_{ij}$ is an isomorphism on $e_iU$, so all
$D_{ij}z$ vanish. Their $A_i$ translates span $\mathcal D_i$; hence every
element of $\mathcal D$ kills $z$. The common-kernel test implies $z=0$.
Equal dimensions make $D_0$ invertible. Membership in $\mathcal D$ and
binary invertibility are also checked explicitly.
Since $\mathcal D$ is $A$-stable, $AD_0\subseteq\mathcal D$.
Multiplication by $D_0$ is injective and both spaces have dimension
$\sum_i as_i^2$, proving equality.
\end{proof}

\section{Invertible completion of every affine partial trace}

Set $T_0=D_0h_0$. A candidate $h=D_0^{-1}T$ lies in $h_0+W$ exactly when
\[
 \tau(B(T-T_0))=0\qquad\text{for all }B\in A.
\]
Partition component $i$ into $h_i\times h_i$ blocks of size $s_i$.
Nondegeneracy of the matrix trace and field trace pairings makes the
conditions precisely
\begin{equation}\label{eq:partial}
 \sum_{\alpha=1}^{h_i}T_{i,\alpha\alpha}
 =H_i:=\sum_{\alpha=1}^{h_i}(T_0)_{i,\alpha\alpha}\quad(1\le i\le b).
\end{equation}
All off-component blocks are unrestricted. The unknown nonzero trace
factor $\gamma$ cannot change these equivalences because the whole
$F$-linear factor $M_{s_i}(F)$ is tested.

For component $i$, put $H_i$ in block $(1,1)$, identities in blocks
$(\alpha,\alpha+1)$ for $1\le\alpha<h_i$ and $(h_i,1)$, and zero elsewhere.
For $h_i=2$ this gives
\[
 T_i=\begin{pmatrix}H_i&I\\I&0\end{pmatrix}.
\]
Its diagonal-block sum is $H_i$. It is invertible for every $H_i$: the
last equation in $T_i z=0$ forces $z_1=0$, the middle equations force
$z_3,\ldots,z_{h_i}=0$, and the first forces $z_2=0$.
Thus $T=\bigoplus_iT_i$ is invertible and satisfies \eqref{eq:partial}.
The map $h_*=D_0^{-1}T$ is invertible and lies in the exact affine slice.
The code independently verifies actual Hom-space membership, every

\section{Bit costs and limits}

Put $J=2+n+m+\dim_2S+\dim_2A+\dim_2H+\dim_2U+\dim_2O+\dim_2V$.
Actual matrices have at most $J^2$ binary entries and algebra tables at most
$J^3$ bits. The sum of expected primitive-corner trials is
$O(p^2+\sum_i s_i^2)=O(J^2)$. Each corner, Frobenius, connecting-unit,
center-basis, and coordinate-inversion calculation has polynomial binary
size. Schoolbook arithmetic and elimination fit within the deliberately
conservative $O(J^{14})$ expected preprocessing bound and polynomial space.
There is no count oracle, field enumeration, or rare invertibility search.
After preprocessing, checking dependencies and applying the exported map
fit within $O(J^4)$ bit operations per target, including the $n$-bit output.

For explicit indexed DAG length $L$, the acquired dimensions give
$J=O(L^2)$. The inherited $O(L^{14})$ deterministic frontend and this
construction therefore fit within a safe expected $O(L^{28})$ bit bound.
Literal target-suffix reversal is charged to $L$. These upper bounds are
not practical speed claims. A random bit sequence can take arbitrarily long;
the stated bound is an expectation, not a worst-case bound over randomness.

The condition $h_i\ge2$ is sufficient, not necessary. It cannot simply be
discarded: for two multiplicity-one factors of unequal sizes, the homogeneous
primal space can be the block off-diagonal matrices
$\left(\begin{smallmatrix}0&B\\C&0\end{smallmatrix}\right)$, all singular
when the block sizes differ. Such a space has no invertible transversal
element. Some multiplicity-one cases admit other constructions.

The section selects one member of each fiber, not a uniform full-fiber
sample. Signed character coefficients are not sampling probabilities, and
arbitrary original-input pins need not preserve the counting certificates.
Those counting and sampling tasks remain separate. This theorem does not
establish unrestricted polynomial Boolean counting or the civilisation-level
research objective.

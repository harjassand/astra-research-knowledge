1. D0 is constructed, not assumed

The code restricts each regular dual component to a primitive left idempotent,
uses the actual common scalar action to choose an F-basis of e_i D_i, and
transports its s_i basis maps to the pairwise orthogonal primitive images by
connecting units. Their sum belongs to the actual dual.

If that sum kills a vector, each orthogonal output projection shows that each
chosen primitive map kills it. The connecting unit is injective on the first
primitive image. Their full algebra translates span the regular component,
so the common-kernel certificate forces the vector to vanish. Equal U and O
dimensions imply invertibility. The dimension comparison then gives
A D0 = D. There is no hidden cyclic-vector or invertible-combination search.

The independent replay recomputed D0 with a new random seed, checked its
inverse on every output basis vector, and checked equality of the actual
binary spans A D0 and D. These checks passed.

2. Matrix-unit and joint-coordinate ordering

SimpleMatrixUnits uses the inherited primitive-corner splitter with its
natural-rank multiplier adjusted to the represented factor action. Each
connecting pair a_j,b_j satisfies b_j a_j=e and a_j b_j=e_j. Orthogonality
then gives the full matrix-unit multiplication identities.

The center basis is the actual center of the acquired nucleus. Field-basis
selection includes all center multiples, so it does not assume that the
binary word 1 is the field identity. The code correctly uses F.one when
probing field coordinate vectors and inserting companion identities.

The joint coordinate order is nucleus row, factor, multiplicity copy,
matrix-factor index, scalar-basis bit. It is consistent between the seed
construction, first-row T0 extraction, companion matrix, and reconstruction.
On the fresh native replay, every actual multiplier-basis action was
independently conjugated into the new coordinates and checked to be exactly
the required repeated diagonal block. All eight checks passed.

3. Trace orientation and common-field assumptions

The stored matrices act on binary column-coordinate vectors. In natural
row-matrix coordinates, an S-linear map is right multiplication, so the
natural matrix convention reverses operator composition. The proof uses
operator composition D0 h0, and the implementation computes exactly that
binary composition. Cyclic invariance of the reduced matrix trace makes the
partial-diagonal trace test consistent with this right-multiplication
convention. No unaccounted transpose remains.

The actual annihilator is formed with a nonzero commutator-annihilating
functional on End_S(U), not the possibly vanishing trace of the large binary
representation. Since every complete F-linear matrix factor is tested, the
unknown nonzero scalar gamma in Tr(gamma tr(-)) cannot change the condition
that each sum of diagonal blocks equal its prescribed matrix.

The inherited multiplier acquisition checks inclusion of every actual
nucleus-center operator in the restricted factor center; both have dimension
a, making this equality of scalar actions, not merely equality of degrees.
That common-field check is essential to both the joint coordinates and the
partial trace argument and is present in the actual code path.

The fresh replay independently formed D(h*-h0) for every actual dual-basis
matrix, reduced it in the actual endomorphism basis, and applied the stored
reduced trace functional. All eight values were zero.

4. Invertible completion for every multiplicity h>=2

The component matrix has H in block (1,1), identity blocks on the forward
cycle, and no other blocks. Its diagonal-block sum is exactly H for every
h>=2. The last row of a kernel equation kills z1, intermediate rows kill
z3 through zh, and the first row then kills z2. This proves invertibility for
all H and all h>=2, including singular H and odd h. There is no determinant
division or search for a lucky affine offset.

The h=2 case does not overwrite the H block: the two inserted identities are
off diagonal. The general loop has the same property for every h>=2. The
theorem correctly refuses to infer the result for multiplicity one.

5. Original affine reconstruction

The section consumes original_affine_input_offset and
original_input_coordinate_columns from the affine-Hom certificate. These
include the acquired left translation u0 and the corrected marked constant
c+L(u0). The older polar offset is used only when no affine reconstruction
keys are present in a lower-level homogeneous certificate. The native entry
always runs the complete affine acquisition.

The exported map fixes the right coordinate v*, varies u=h*^{-1}y, and embeds
that pair through the exact original coordinate bijection. Thus the section
is affine and injective, and its marked-output map is the actual constant
plus the acquired output embedding. No gate variable is counted or sampled
independently.

6. All-target certificate, independently checked on literal gates

The production native entry checks every coefficient after composing the
exported affine map with each acquired original quadratic. This is a finite
all-target identity, not evidence from a few sampled targets.

For an independent test, review_affine_section.py used a separate literal
interpreter for the actual 72-input/24,635-gate E6 fixture. It read the actual
initial-wire indices returned by reversible peeling. It evaluated the
exported section at y=0, every basis vector, and every pair of basis vectors:
137 evaluations for 16 output coordinates. Because the exposed map has
degree at most two, these evaluations determine every Boolean coefficient.
All 16 marked outputs agreed with the exported affine output map at every
probe. This independently certifies the identity for all 65,536 outputs of
this fixture. A witness for the native equality target also passed the
original Boolean output gate.

The exact replay is in affine_section_independent_review_results.json. It
reused previously acquired raw certificates but reconstructed the section,
matrix units and D0 afresh with seed 2026102828. It did not rerun the whole
8973-check author audit; the reviewer read that saved evidence separately.

7. Costs and residual limits

The primitive splitter's inherited success lower bound 1/(8r) is uniform in
the field size. The expected polynomial qualification is therefore supported;
there is no deterministic worst-case guarantee for every random bit stream.
All later map construction and coefficient verification are polynomial-size
binary operations. The displayed conservative preprocessing bounds are
consistent with those operations and include the explicit output size.

This section proves search/surjectivity beyond the earlier target-counting
admissions, including targets occupying multiple joint simple copies. It
does not determine their counts and does not uniformly sample their full
fibers. The original restricted-circuit admission remains necessary.

Minor operational recommendation

The reviewed production module does not itself set sys.dont_write_bytecode.
The review ran with PYTHONDONTWRITEBYTECODE=1 and set that flag before imports,
so it did not add caches to recovered_source. Adding
sys.dont_write_bytecode = True before the recovered imports would make the
standalone CLI preserve that same source-snapshot discipline automatically.
This is an operational preservation improvement, not a theorem correction.

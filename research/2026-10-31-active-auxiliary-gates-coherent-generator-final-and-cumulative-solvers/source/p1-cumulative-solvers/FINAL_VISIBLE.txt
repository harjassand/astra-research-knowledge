### 1. The consequential question I chose

I chose:

> **Can difficult computations teach a learner reusable machinery, so that the cumulative acquisition burden follows shared structure across problems, while later answers can reach finer accuracy without relearning the representation?**

The downstream task is solving changing positive linear systems. This gives a precise computational capability to construct and measure.

The learner acquires a **preconditioner**: an operation that makes an iterative solver converge quickly. It then corrects each proposed answer using the residual of the actual current equation.

This change matters because the learned approximation only needs to cross a useful accuracy threshold. Final answer accuracy comes from the subsequent correction process.

Preconditioning and residual correction are established numerical methods. The potentially distinctive result here is the cumulative accounting theorem connecting **actual rejected tests, acquired directions and changing operators**. Adaptive Nyström preconditioning already provides a strong foundation, including rank adaptation and residual estimation. :chatgpt-content-reference{index="0"}

### 2. The source operation is explicit

The equations are

\[
A_t x=b,
\qquad
A_t=\lambda_t I+K_t,
\qquad
K_t\succeq0,\quad \lambda_t\ge\mu>0.
\]

The learner may choose a numerical vector \(v\) and obtain the actual product \(K_t v\), paying for that operation and its returned coordinates.

It starts without a useful basis, rank, eigenspace, preconditioner or common spectral envelope.

**This matrix-vector service is a different research model from P1’s scalar endpoint-return experiments.** The previous theorem does not supply it. The positive-semidefinite source class, known coordinates and regularization floor are also premises.

Within that interface, the learner constructs the useful representation itself. It receives neither inverse answers nor a teacher that solves the equations.

### 3. The central theorem: rejected tests have a cumulative budget

Let \(Q\) span the input directions already acquired. Form the ordinary Nyström approximation

\[
N_Q(K)
=
KQ(Q^\top KQ)^\dagger Q^\top K
\]

and its residual

\[
E_Q(K)=K-N_Q(K).
\]

For positive-semidefinite \(K\),

\[
E_Q(K)\succeq0,
\qquad
E_Q(K)Q=0.
\]

The construction performs a finite test using random sign vectors and repeated applications of this residual.

It has two outcomes:

- **Accept:** certify \(\|E_Q(K)\|\le \mu/2\), with a charged confidence allowance.
- **Reject:** obtain an actual new unit direction \(q\) satisfying
  \[
  q\perp\operatorname{range}(Q),
  \qquad
  q^\top E_Q(K)q>\mu/4.
  \]

The second implication is deterministic. Every rejection contributes a quantitatively useful, independent direction. There is no unresolved refinement loop whose cost disappears from the accounting.

Now let \(C\succeq0\) be **any matrix dominating the operators in the sequence**:

\[
K_t\preceq C.
\]

The learner does not need to know or query \(C\). It is a retrospective measure of the sequence’s shared structure.

The total number \(J\) of acquired directions satisfies

\[
\boxed{
J\le
\min\left\{
n,\;
\operatorname{rank}(C),\;
\log_2\det\!\left(I+\frac{4C}{\mu}\right)
\right\}.
}
\]

**This bound holds on every random path.** The confidence statement is separate: with probability at least \(1-\delta\), every issued certificate is sound across the adaptive history.

The proof uses the variational identity

\[
z^\top E_Q(K)z
=
\min_c (z-Qc)^\top K(z-Qc).
\]

It implies

\[
K\preceq C
\quad\Longrightarrow\quad
E_Q(K)\preceq E_Q(C).
\]

Each rejected test then increases

\[
\log\det\!\left(I+\frac{4Q^\top C Q}{\mu}\right)
\]

by more than \(\log 2\). The full determinant provides a finite budget for those increases.

This also gives a useful result beyond exact low rank. If

\[
\lambda_i(C)\le c\,i^{-p},\qquad p>1,
\]

then

\[
J\le
\frac{\pi}{\log 2\,\sin(\pi/p)}
\left(\frac{4c}{\mu}\right)^{1/p}.
\]

That direction bound is independent of the finite ambient dimension. Reading and storing \(n\)-coordinate vectors, and performing the tests, still cost work.

### 4. What the acquired knowledge actually enables

After acceptance, define

\[
P_t=\lambda_t I+N_Q(K_t).
\]

On the joint confidence event,

\[
P_t\preceq A_t\preceq \frac32P_t.
\]

The explicit correction operation

\[
x_{k+1}
=
x_k+P_t^{-1}(b-A_t x_k)
\]

therefore satisfies

\[
\boxed{
\|x_k-A_t^{-1}b\|_{A_t}
\le
2^{-k}\|A_t^{-1}b\|_{A_t}
}
\]

when started at zero.

Thus \(O(\log(1/\varepsilon))\) correction steps suffice for relative energy error \(\varepsilon\), **for every later right-hand side**, including one selected after seeing the acquired model.

The retained object is an executable numerical operation. Its inverse application is constructed through small-matrix elimination and the Woodbury identity. No inverse oracle is assumed.

The exact implementation also uses an actual-residual stopping certificate and a finite iteration cap. A failure to meet the requested tolerance is charged and reported.

### 5. Reuse across whole parameter families

For the important specialization

\[
K(\theta)=\sum_{j=1}^{m}\theta_jB_j,
\qquad B_j\succeq0,\quad \theta_j\ge0,
\]

the learner caches every \(B_jq\) when it acquires a direction \(q\). That costs \(mJ\) primitive applications.

Future task-specific approximations can then be assembled from those retained responses.

If a parameter box \(0\le\theta_j\le u_j\) is supplied, the accessible operator

\[
C=\sum_j u_jB_j
\]

dominates the entire family. **One acquired certificate for \(C\) covers every later parameter and right-hand side in that box.**

Certificates remain valid as the retained space grows. The executable consequently remembers certified parameter regions and reuses them.

The affine composition law is supplied structure. Constant sketches and affine caching are already present in strong existing research, so they are not being counted as new discoveries here. :chatgpt-content-reference{index="1"}

### 7. Useful failures preserved

Three failures materially shaped the construction.

**Primitive certificates do not automatically certify mixtures.** With

\[
B_1=\operatorname{diag}(1,0),\quad
B_2=\operatorname{diag}(0,1),\quad
Q=\operatorname{span}(1,1),
\]

both primitive Nyström residuals vanish. The residual for \(B_1+B_2\) nevertheless has norm \(1\). A genuine envelope argument or combined-operator test is necessary.

**Systematic observation error can block arbitrarily accurate inversion even in a rank-one example.** Repeating the same biased service does not eliminate that ambiguity. The exact matrix-vector premise cannot be transferred silently to noisy physical measurements.

**Perfect prediction does not acquire a planner.** The preserved reduction uses commuting PSD projections whose endpoint value measures uncovered elements of a set system. Selecting an optimal action sequence then contains Set Cover. An ordinary greedy planner gives a useful restricted approximation, but spectral prediction alone does not solve the optimization problem.

The inherited endpoint theorem and its limitations remain preserved separately.

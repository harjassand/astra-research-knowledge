RETAIN CERTIFICATES, COMPLETE THE LEDGER, AND USE STRONG COMPARATORS
31 October 2026

1. DOMAIN CERTIFICATES ARE REUSABLE KNOWLEDGE TOO

For fixed PSD primitives B_j, define A(theta)=sum_j theta_j B_j, theta>=0.
Suppose a space S was certified at parameter u and threshold mu_old:

 R_S(A(u)) <= (mu_old/2) I.

Let S' contain S. If theta<=u componentwise and mu_new>=mu_old, then

 R_(S')(A(theta)) <= R_S(A(theta)) <= R_S(A(u))
                    <= (mu_new/2) I.

The first inequality is monotonicity under subspace enlargement; the second
is monotonicity under PSD operator order. Thus an accepted test covers a
whole parameter box and remains valid after more knowledge is acquired.
No further random confidence allowance is spent by reusing that same event.
Later right-hand sides and parameters may be selected from the prior history.

The software stores an antichain of certified upper parameter vectors with
their thresholds. A new request first checks this finite list. An old box
can be removed only when a new accepted box dominates its parameters and has
at least as strict a threshold. The comparison and list update are explicit
O(m times number-of-retained-boxes) arithmetic; this index is not a free oracle.
An unbounded family can require many boxes. The main J bound controls useful
directions, not the number of incomparable parameter domains.

If R genuinely new operator/domain certificates are required and J additions
occur, there are R+J randomized tests, rather than necessarily T+J for T
requests. Every accepted terminal test is paid. A supplied parameter envelope
can reduce R to one. Success on finitely many tasks alone does not establish
a domination promise outside their certified domains.

2. THE FULL COST

At each certificate stage s, q power steps are run on ell_s actual sign
vectors. The planned r_s is chosen from the summable confidence allocation.
One threshold crossing causes immediate rejection; all r_s vectors must pass
before acceptance. The actual combined-operator cost is q sum_s ell_s.
The source exposes m component operations, so each combined application pays
one call per nonzero coefficient. One call returns an entire n-vector.

The affine cache costs mJ component calls and stores every B_j v. Building
the current task's Nystrom inverse also pays vector assembly, a small Gram,
and its factorization. The theorem's efficient exact pivoted-LDL construction
can select the positive Gram block in O(J^3) rational operations. The simple
exact fixture recomputes principal inverses and can cost O(J^4); it is not
silently charged at the optimized bound.

All current factor construction, preconditioner application, new b reading,
actual residual correction, confidence bookkeeping and unsuccessful attempts
remain necessary costs. Source calls are not unit bit operations. The exact
fixture records selected arithmetic counts and bit maxima, not a complete
hardware, energy or peak-memory bill. Its source-output maxima are distinct
from the larger fractions created by elimination and final certificates.

3. EXACT RUN

results/exact_solver.json is the authoritative final ledger. The observed
stage widths were 0,1,2. Two failed tests acquired actual directions; the
third accepted. There were 184 power-probe component calls, four additional
Rayleigh-audit calls, four cache calls, and nine later solve calls.

All three requested solves meet their exact rational relative energy bound.
They use 2,2,1 Richardson updates, respectively. A posteriori actual solutions
are computed by exact full-matrix elimination only in the separate evaluator,
not as learner input. The two determinant-potential ratios were approximately
276.393 and 45.638; the saved exact fractions verify each is greater than two.

The final arithmetic counters, including selected validation work, record
14,036 Fraction additions, 13,345 multiplications and 379 divisions. The
largest recorded numerator has 9,911 bits and denominator 9,973 bits. The
source input/output entry maximum is 3,749 bits. These numbers demonstrate
why a direction-count theorem is not a cheap finite-precision theorem.

4. NUMERICAL COMPARISON

The fixed simulated family has n=192, three noncommuting PSD components with
an eight-dimensional dominant subspace and a small full-dimensional positive
tail. The hidden subspace is not given to any learner. The source internally
uses those factors to implement its vector service; the comparison gives
every algorithm the same service. All parameters lie in [0,1]^3 and shifts
are at least one. Acquisition certifies the actual accessible envelope sum B_j.
The later 512 right-hand sides and parameters are new. This is a synthetic
controlled fixture, not an application benchmark or an assumed exact rank.

All retaining compact methods use the SAME confidence rule, same affine cache,
same parameter envelope, same final target and ordinary preconditioned CG.
The raw Gaussian method doubles input columns. The stronger Gaussian range
method first applies the envelope to the proposed Gaussian columns, paying
these calls, then caches component actions on their orthogonalized outputs.
This is ordinary randomized range finding, not a new learned architecture.

Final totals (primitive component calls):

                             Cache   Test   Proposal   Solve   Total
 Witness                        24    630          0    4608    5262
 Retained Gaussian input        96    504          0    6129    6729
 Retained Gaussian range        24    414         24    4608    5070
 Ordinary CG                     0      0          0   15822   15822
 Full matrix acquisition         0      0        576*      0     576

*The last row's calls are recorded as tomography, not proposal. It learns
every primitive by its n coordinate columns, retains the resulting dense
matrices, and pays dense task assembly and Cholesky. This is allowed by the
same vector interface; an incumbent must be allowed to exploit it.

The witness and Gaussian range methods both retain 6,144 floating numbers
in their persistent basis and component caches. Gaussian input retains 24,576;
dense matrix retention uses 110,592. Those are not total memory peaks. Cached
small factors, current temporary arrays, source simulator state, runtime and
raw ledgers have separate costs. Per-task compact assembly is of order
m n J+n J^2+J^3; dense assembly/factorization is of order m n^2+n^3.

The strongest compact comparator wins source calls in this run, with equal
retained width. Full matrix retention wins the source-call metric by a much
larger margin, at larger storage and dense numerical work. The small elapsed
times are recorded, but are too small and include common evaluator work;
they do not demonstrate an application-speed advantage. PCG, CG and dense
roundoff are validated numerically against the fixture, not by rigorous
interval arithmetic.

The ordinary CG comparator uses a sharper a posteriori lower bound than the
initial attempt. For any iterate x and exact r=b-Kx,

 L(x)=2 b^T x-x^T Kx=b^T x+x^T r <= b^T K^(-1)b.

Because K>=lambda I, ||r||^2<=epsilon^2 lambda L(x), with L(x)>0,
certifies the required relative energy error. Candidate stops are checked
with a paid actual residual. The initial duplicated Kb call was removed.
Both corrections improve the comparator; the earlier costs remain in the
archived ledgers, not as the headline result.

5. ONLINE RUN

The 75-task online fixture first uses one direction, introduces a second at
task26 and a third at task51. Current operators must be fixed before their
fresh probes; the theorem also allows choices depending on previous results.
This fixture uses a fixed schedule, so it checks implementation and accounting,
not every possible adaptive strategy.

Final result: J=3, six tests (three rejected, three accepted), and 72 reuses
of previously earned domain certificates. Paid calls are 9 cache,576 test,
300 solve,885 total. Global stage numbering persists. The live PRNG is reused
across calls rather than restarted. New directions can still be acquired after
more accepted requests than ambient dimension; the cap applies per acquisition
attempt and to independent dimensions, not the lifetime number of accepted tasks.

The earlier 75-task implementation reran already valid certificates and paid
21,240 test calls. It is preserved in before_certificate_reuse_online.json.
That unnecessary cost is repaired, not presented as a fundamental lower bound.

6. WHAT THE RESEARCH DID NOT REMOVE

Known coordinates, symmetry, PSD structure, the affine law where used and a
regularization floor remain supplied. Physical scalar endpoint experiments
do not automatically provide this interface. An adversarial systematic error
can prevent finer inverse accuracy even at rank one. A small Euclidean basis
angle can be disastrous near a small eigenvalue. Those counterexamples are
preserved separately.

The cumulative determinant bound controls actual new directions, including
all rejected tests. It does not control arbitrary Gram conditioning, rational
bit growth, unstructured full-rank family changes, every domain-box index,
or all costs of obtaining a real scientific matrix-vector service. Existing
methods already possess much of the mechanism. No independent historical
novelty determination or practical superiority result has been obtained.

The next substantive burden is a stable finite-precision acquisition theorem
with comparable lifetime accounting, followed by a demanding scientific family
where full matrix retention, multigrid, sparse direct methods and retaining
randomized solvers receive their best applicable source structures.

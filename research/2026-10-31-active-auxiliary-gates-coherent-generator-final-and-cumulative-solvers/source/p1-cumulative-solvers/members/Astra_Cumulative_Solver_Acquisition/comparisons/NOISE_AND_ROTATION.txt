SOLVER-SOURCE LIMITS AND ROBUST GEOMETRY
31 October 2026. Complement to root's reusable-solver construction.
All statements below have elementary proofs; no historical priority claimed.

1. CONSISTENT NOISY MATVECS: A RANK-ONE LOWER BOUND

Interface: learner may query any vector v adaptively and observe Av+z(v),
where ||z(v)||_2<=sigma ||v||_2. Errors may be adversarial and consistent
across all calls. This is bounded-error, not independent zero-mean noise.

For any unit u, alpha>0 and sigma>=0 let
 A0=I+(alpha-1)uu^T,
 A1=I+(alpha+2sigma-1)uu^T,
 B =I+(alpha+sigma-1)uu^T.
Both A0 and A1 are SPD and fit I+U C U^T with the SAME rank-one U=u.
The oracle returning Bv is admissible for both: its errors are respectively
+sigma uu^T v and -sigma uu^T v, bounded as required. Thus every adaptive
transcript and output law is identical, even with infinitely many queries.
This remains true if u is given to the learner in advance.

For b=u the exact solutions are u/alpha and u/(alpha+2sigma). For any output
x, discarding x's component orthogonal to u can only improve either relative
Euclidean error. Write x=t u. Then the two relative errors are
 |alpha t-1| and |(alpha+2sigma)t-1|.
Their minimax over t is attained at t=1/(alpha+sigma), with value

              sigma/(alpha+sigma).                         (N1)

Proof: if both errors <e then their allowed t intervals intersect only if
(1-e)/alpha < (1+e)/(alpha+2sigma), which requires
e>sigma/(alpha+sigma). Equality follows by the displayed t.
For randomized algorithms the same disjoint intervals imply that no method
can have success probability >1/2 in BOTH worlds for error below (N1).
So a high-confidence arbitrary-accuracy claim needs additional source
conditions. Knowing low rank, exact U, or retaining unlimited old data does
not repair adversarial uncertainty in a small eigenvalue.

Independent mean-zero noise is different: repetition can reduce sigma_eff,
with all repetitions paid. Bias/systematic noise cannot be averaged away.
If alpha is an a priori coercivity lower bound, relative target epsilon
requires approximately sigma <= epsilon*alpha/(1-epsilon) in this example.

2. SMALL EUCLIDEAN ROTATION CAN RUIN A RETAINED PRECONDITIONER

Take 0<alpha<=1, orthonormal u,w and v=c u+s w, c=cos theta,s=sin theta.
Define A_u=I-(1-alpha)uu^T and A_v=I-(1-alpha)vv^T.
Use the EXACT learned inverse of A_u to precondition A_v. The symmetric
preconditioned operator K=A_u^(-1/2) A_v A_u^(-1/2) is identity off span(u,w).
On this plane its matrix is

 [ (1-(1-alpha)c^2)/alpha, -(1-alpha)c*s/sqrt(alpha) ]
 [ -(1-alpha)c*s/sqrt(alpha), 1-(1-alpha)s^2        ].

Its determinant is det(A_v)/det(A_u)=1. Its trace is

 2+gamma,     gamma=((1-alpha)^2/alpha) sin^2(theta).

Therefore its nontrivial eigenvalues and condition number are exactly

 lambda_+- = [2+gamma +- sqrt(gamma(gamma+4))]/2,
 kappa(K) = lambda_+^2.                                    (R1)

Constant conditioning is equivalent to bounded gamma. For alpha small this
requires sin(theta)=O(sqrt(alpha)); a small dimension-independent angle is
not sufficient. For sin^2(theta)>>alpha, kappa is asymptotically
sin^4(theta)/alpha^2. The geometric accuracy must track the small eigenvalue.
The rank of each modification is one, but an adversarial sequence of rotated
u_t can span arbitrarily many directions: rank per task is NOT shared rank.
Conversely if all u_t belong to one fixed r-dimensional U, exact new direction
acquisitions are still bounded by r; this calculation concerns approximate
retention and cost, not a counterexample to exact shared-subspace counting.

For the explicit later right-hand side b=w, the stale inverse predicts x=w.
Then the true residual and solution error are

 ||b-A_v x|| = (1-alpha)|sin(theta)|,
 ||A_v^(-1)b-x|| = [(1-alpha)/alpha]|sin(theta)|.             (R2)

A tiny measured residual can coexist with a large absolute solution error.
Its true error in A_v energy has square
 (1-alpha)^2 sin^2(theta)/alpha.
Again the natural control is sin^2(theta)/alpha, not just angle or rank.

3. AN HONEST NOISY RESIDUAL CERTIFICATE

Suppose the ACTUAL operator is known to obey A>=mu I, mu>0. This is a source
premise or separately established structural fact, not a finite noisy-Ritz
estimate. Given proposed x and noisy matvec y=Ax+z with ||z||<=sigma||x||,
let

 r_plus=||b-y||+sigma||x||.

Then with x*=A^-1 b,

 ||x-x*||_2 <= r_plus/mu,
 ||x-x*||_A <= r_plus/sqrt(mu).                            (C1)

Proof: true residual r=b-Ax=(b-y)+z satisfies ||r||<=r_plus; x*-x=A^-1r.
The Euclidean inverse norm is <=1/mu and r^T A^-1r<=||r||^2/mu.
If r_plus<mu||x||, a relative Euclidean certificate avoiding a supplied upper
spectral bound is

 ||x-x*||/||x*|| <= r_plus/(mu||x||-r_plus).                (C2)

This follows from ||x*||>=||x||-r_plus/mu. It can be conservative.
An upper bound A<=L I instead gives the usual relative A-energy certificate
sqrt(L/mu)*r_plus/||b||.

Exact task-subspace closure can replace a GLOBAL lower bound in an exact
matvec model: if a finitely acquired space W contains b and is invariant
under A, the SPD restricted matrix determines the exact solution in W, and
unseen modes are irrelevant. With noisy data, apparent closure is not exact
closure; arbitrarily small omitted components can meet arbitrarily small
omitted eigenvalues. A robust theorem needs an outside coercivity bound,
a quantitative cross-block/energy certificate, or additional source
information. Declaring a tiny residual vector to be zero is not sound.

4. COMPARISON AND INTERPRETATION

These are limitations on what the source reports permit, not limits on
learning or intelligence. Ordinary recycled Krylov, deflation and augmentation
methods encounter and sometimes handle the same geometry. A new method must
beat or adopt those methods under the same access and task sequence.
The positive design requirement is clear: retain not only approximate vectors
but an energy-scaled residual/angle certificate and the noise floor governing
later precision. Exact rank counting is useful separate capital, but it is not
a noisy acquisition cost theorem.

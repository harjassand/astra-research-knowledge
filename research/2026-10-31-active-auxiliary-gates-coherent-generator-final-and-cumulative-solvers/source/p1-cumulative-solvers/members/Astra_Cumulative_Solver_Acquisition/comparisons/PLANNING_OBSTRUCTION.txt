PERFECT PREDICTION DOES NOT AUTOMATICALLY ACQUIRE A PLANNER
31 October 2026. Elementary reduction; no historical priority claimed.

Let U be a finite universe of n elements and let S_1,...,S_m be subsets.
For each action a define the diagonal matrix

 T_a = diag(1_{i not in S_a}),       f = (1,...,1)/sqrt(n).

Every T_a is a commuting positive-semidefinite orthogonal projection, hence
a self-adjoint contraction. The exact endpoint predictor for a word w is

 <f,T_w f> = |U minus union_{a in w} S_a| / n.

Computing this quantity for a specified word is elementary. Finding a word
of length at most k with endpoint value zero is exactly Set Cover. The model
is supplied perfectly and can even be stored as binary diagonals. Thus no
spectral fitting improvement alone removes the separate combinatorial planning
burden. Values are integer multiples of 1/n, so an additive prediction error
strictly less than 1/(2n) does not remove that decision obstruction.

This is not a limit on learning/intelligence in general, nor a claim that all
useful planning requires exact optimum. The ordinary coverage function

 F(A)=|union_{a in A} S_a|/n

is monotone submodular. At each step select an action with largest additional
covered fraction. If OPT is the best coverage with k actions, the uncovered
gap contracts by at least 1/k at each greedy step, giving

 F(A_k) >= [1-(1-1/k)^k] OPT >= (1-1/e) OPT.

To verify the recurrence, the remaining actions of an optimal set have total
marginal gain at least OPT-F(A_i) by monotonicity and submodularity. One of
at most k actions has marginal at least (OPT-F(A_i))/k.

If every evaluated set value has absolute error at most gamma, each estimated
marginal differs from its true value by at most2gamma. Selecting the largest
estimated marginal loses at most4gamma versus the best true marginal. The
recurrence becomes

 OPT-F(A_(i+1)) <= (1-1/k)[OPT-F(A_i)]+4gamma,

and yields the valid conservative bound

 F(A_k) >= [1-(1-1/k)^k]OPT-4k gamma.

This explicitly constructs a restricted useful planner with at most mk
marginal evaluations. Direct measured greedy is an equally informed ordinary
competitor; a learned model is not automatically the cheapest way to obtain
those values. This distinction helped select actual inverse computation as
the main downstream task of the current investigation.

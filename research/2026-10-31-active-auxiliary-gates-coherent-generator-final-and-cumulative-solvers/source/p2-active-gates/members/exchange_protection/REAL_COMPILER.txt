REAL DARK-SPACE CONTROLS SUFFICE FOR CIRCUIT COMPUTATION
31 October 2026. Complement to HOLONOMY_CONSTRUCTION.txt and the root theorem.

Purpose and scope

The physical common-gain gate proof can use entirely real moving bright
vectors. This avoids requiring a full complex phase loop. The construction
below compiles any supplied Clifford+T circuit on computational-basis input
into a finite set of such real dark loops, using one additional rebit and a
linear number of primitive gates. Its final computational-basis output
distribution is the same in the ideal limit. This is the established
real-amplitude simulation principle, with an explicit compiler into the
current primitives; it is not a new universality theorem.

This consequence must be distinguished from performing an arbitrary complex
unitary on an unknown incoming quantum state. A real-only device with only
real initial auxiliary states cannot do the latter. A prepared complex phase
reference or complex control supplies the missing resource.

1. Primitive real reflections

For any fixed real logical ray u_beta=(cos beta,sin beta), the half-turn
dark-space loop theta=pi(3s^2-2s^3), bright b=sin theta*u_beta+cos theta*a,
implements
  F_beta = I - 2 |u_beta><u_beta|
         = [[-cos 2beta,-sin 2beta],[-sin 2beta,cos 2beta]].
Its path lives in a fixed real plane. The dark vector d=cos theta*u_beta-
sin theta*a starts at u_beta and ends at -u_beta, while its orthogonal logical
companion is a spectator. The gate is a reflection; no scalar dynamical phase
is used. The finite-time source robustness comes from the root theorem.

For real matrices we use the standard convention
  R_y(alpha) = exp(-i alpha Y/2)
             = [[cos(alpha/2),-sin(alpha/2)],
                [sin(alpha/2), cos(alpha/2)]].
Then direct multiplication gives
  R_y(alpha) = F_{alpha/4} F_0,
where the rightmost operation is performed first. Also
  H = F_{5pi/8},
  X = F_{-pi/4}, Z=F_{pi/2}.

The pair half-turn loop from HOLONOMY_CONSTRUCTION.txt gives
  CZ = diag(1,1,1,-1).
Thus
  CNOT_{c,t} = (I_c x H_t) CZ_{c,t} (I_c x H_t).
It uses two local reflection loops and one pair loop.

2. Realification with one additional rebit

For a vector psi=a+i b with real coefficient vectors a,b, define its numerical
encoding as
  E(psi)=a x |0>_r + b x |1>_r.
For U=A+iB, with real A,B, define
  R(U)=A x I_r + B x J_r,
  J = [[0,-1],[1,0]] = -iY.
The phase rebit is written last. Equivalently, with it written first,
  R(U) = [[A,-B],[B,A]].
R(U) is real orthogonal if U is unitary, and
  R(U) E(psi)=E(U psi), R(UV)=R(U)R(V).
Computational-basis outcomes on the original register have probabilities
  a_x^2+b_x^2 = |psi_x|^2
after the phase rebit is ignored.

If the original input is computational-basis |0...0>, the encoded input is
just |0...0>|0>_r. No imaginary phase state is needed. Adaptation to classical
input bit strings costs their ordinary preparation. The source E may be
arbitrarily complex and correlated: only the ideal logical gates and their
prepared logical input are real. Actual joint source-carrier dynamics is not
asserted to have real amplitudes.

If the inherited sector-readout instrument is qualified for carrier Z, a
loaded code carrier can be initialized without an additional pure logical
source: measure Z, then apply X=F_{-pi/4} on outcome 1. Each carrier and the
phase rebit requires at most one readout and one conditional reflection. In
the ideal instrument the resulting pure logical |0> factors from the retained
source despite initial correlations. Finite readout and correction errors
are charged. This procedure does not load the carrier into span{0,1}, and
cannot by itself repair population in a,e,f. The preparation library adds
the fixed real ray beta=-pi/4 to the computational rays listed below.

3. Explicit Clifford+T compiler

Take H, T=diag(1,exp(i pi/4)), and CNOT as the supplied universal circuit set.
H and CNOT are real and act on their original carriers with r untouched.
T on a carrier q is represented by controlled R_y(pi/2) on r:
  R(T_q)=|0><0|_q x I_r + |1><1|_q x R_y(pi/2)_r.

For any angle alpha,
  CR_y(alpha) = CNOT (I x R_y(-alpha/2))
                       CNOT (I x R_y(alpha/2)).
Chronological order is: R_y(alpha/2), CNOT, R_y(-alpha/2), CNOT.
On control zero, the rotations cancel; on control one, use X R_y(-x) X=R_y(x)
to obtain R_y(alpha). This is an exact identity, not an asymptotic synthesis.

Consequently:
  Original H:    1 local reflection loop.
  Original CNOT: 2 local reflection loops + 1 pair CZ loop = 3 loops.
  Original T:   4 local reflection loops for the two rotations, plus
                4 local reflection loops + 2 pair CZ loops for two CNOTs
                = 10 loops.
T-dagger has the same cost with rotation signs reversed.

If the supplied circuit has h H gates, c CNOT gates and t T/T-dagger gates,
an explicit upper bound on dark-space gate count is
  N = h + 3c + 10t.
The local reflection rays needed are only
  beta in {0, +pi/16, -pi/16, 5pi/8},
plus the pair CZ primitive. Thus no continuous family of new ray directions
has to be acquired to simulate circuits over this gate set. Their relative
control amplitudes and signs must nevertheless be physically calibrated.

Each loop also has its finite idle-code coupler reset from c_a=-1 to +1, unless
the actual implementation directly alternates compatible endpoint conventions.
If the moving segment takes T_j and the reset tau_j, then actual sequential
duration is sum_j(T_j+tau_j), plus loading, routing and readout. If the root
theorem yields gate error <=C_j/T_j, assigning equal per-gate error epsilon/N
with a uniform C gives moving-segment duration at most C N^2/epsilon for this
simple sequential schedule. That is a sufficient upper bound, not an optimal
gate complexity or a practical advantage. Native calibrated conventional gates
remain a serious comparator.

Every T/T-dagger interacts the original gate's target with the one extra phase
rebit. Nonlocal access to that rebit is therefore a connectivity resource. On
a restricted graph, route it by physical SWAP operations (three CNOTs, hence
at most nine dark loops per standard synthesized SWAP) or provide an earned
transport mechanism. Total overhead must include the chosen routes. The
compiler is linear in supplied circuit size only with the corresponding pair
access; for arbitrary routing, a polynomial bound is all that follows without
a specified layout. Parallel T gates also contend for the one shared rebit.

4. Arbitrary complex inputs and a catalytic phase reference

The mapping psi -> E(psi) is real-linear, not complex-linear. It cannot be
implemented as a physical isometry on an unknown quantum state. The input
rays |0> and i|0> are physically identical, whereas their encoded vectors
|0>|0>_r and |0>|1>_r are orthogonal. This alone rules out the desired general
input conversion. The computational simulation starts from a known real
preparation and tracks a specified circuit; it does not convert an arbitrary
unknown state.

A prepared complex phase reference gives a different, legitimate route.
With the convention above, |y_->=(|0>-i|1>)/sqrt(2) is an eigenvector of
J=-iY with eigenvalue +i. Therefore for every input psi,
  R(U) [psi x |y_->] = U psi x |y_->.
The phase rebit is unchanged exactly in the ideal algebra and so is catalytic.
Using |y_+>=(|0>+i|1>)/sqrt(2) instead gives U* with the same R(U); replacing
R(U) by A x I-B x J uses |y_+> to implement U. This sign convention matters.

One cannot prepare |y_+> or |y_-> from real states using only real matrices
and real-invariant measurement primitives. Complex conjugation leaves all
such initial density matrices and operations invariant, but swaps the two
phase states. Phase-reference preparation is a genuine additional control
resource. Imperfect gates can also degrade the reference; the ideal catalytic
identity is not a claim of perpetual perfect reuse in a noisy device.

5. Geometric and numerical precision

For a fixed ray-angle error delta,
  ||F_{beta+delta}-F_beta|| = 2|sin delta| <=2|delta|.
Thus finite relative-amplitude calibration contributes an explicit ordinary
unitary error. The real pair lambda has a useful topological feature: as long
as its nonzero two-component real coupling vector follows the same half-winding,
with the same endpoint code, its sign holonomy remains -1. Path speed and
radial changes do not affect that ideal sign. Crossing zero, incorrect endpoint
alignment, unintended spectator couplings, complex phase errors, and changes
of the coupled logical plane are outside this sign protection.

6. Checks and established source

rebit_compiler.py verifies the reflection identities, two-CNOT controlled
rotation, T realification, the phase-reference catalytic identity, and a
120-gate three-qubit random Clifford+T circuit compiled into primitive loops.
It compares the real encoded state at every step and the final probabilities,
and writes rebit_compiler_results.json. Ordinary matrix errors are at roundoff.
These checks verify the compiler, not the finite-time gate-following theorem
or physical coupling acquisition.

Primary source: Terry Rudolph and Lov Grover, 'A 2 rebit gate universal for
quantum computing', arXiv:quant-ph/0210187 (2002),
https://arxiv.org/pdf/quant-ph/0210187 . It gives real-amplitude circuit
simulation with one real/imaginary ancilla and explicitly distinguishes
computational universality from arbitrary-unitary universality. The compiler
above independently derives the finite gate identities used here.

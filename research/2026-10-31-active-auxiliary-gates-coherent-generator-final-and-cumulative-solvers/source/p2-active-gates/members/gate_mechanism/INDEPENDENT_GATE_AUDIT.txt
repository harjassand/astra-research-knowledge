1. A POSITIVE QUANTUM BRIGHT ENERGY IS NOT AN ADIABATIC GAP

Let the retained qutrit have basis |s>, |d>, |b>. Its logical code is
span{|s>,|d>}; |b> is a bright spare level. Let the source be a qubit with

    H_E = Omega Z,
    G = g I + b X,       0 < b < g,
    Omega = (g^2-b^2)/(2g).

Let R(theta) rotate |d>,|b> and leave |s> fixed:
R(theta)=exp(-i theta Y_db), Q(theta)=R(theta)|b><b|R(theta)^dagger.
The complete Hamiltonian is

    H(t)=I_D tensor H_E + Q(pi t/T) tensor G.

The instantaneous logical projector P=I-Q has rank two and returns to itself
at t=T. G has eigenvalues g-b,g+b, so its smallest eigenvalue is strictly
positive. Nevertheless the joint dark/bright Hamiltonians are

    H_dark = Omega Z,
    H_bright = Omega Z + g I + b X.

The bright energies are g +/- sqrt(Omega^2+b^2). Since
sqrt(Omega^2+b^2)=(g^2+b^2)/(2g), the lower bright energy equals Omega,
the upper dark-source energy. The source eigenvector overlap is

    c = |<up|v_bright,minus>| = b/sqrt(g^2+b^2).

In the rotating qutrit frame the complete Hamiltonian is constant:

    H_rot=H(0) - (pi/T) Y_db tensor I_E.

The perturbation acts resonantly in the exactly degenerate pair
{|d,up>, |b,v_bright,minus>}. As T tends to infinity its integrated mixing
angle tends to pi c. Hence input |d,up> has final bright probability

    lim_(T->infty) p_bright(T) = sin^2(pi b/sqrt(g^2+b^2)).

For g=2,b=1,Omega=3/4, the gain spectrum is {1,3}, but the limiting loss is
sin^2(pi/sqrt(5))=0.972750463671889. The other code state |s> is untouched;
the example therefore damages genuine encoded quantum information, rather
than only an unobservable phase on a one-dimensional code.

The exact finite-matrix diagnostic positive_gap_counterexample.py gives:
T=100: p_bright=0.9717137573376315;
T=1000: p_bright=0.972739979410175;
T=10000: p_bright=0.9727503591746227.

This is a counterexample to a uniform warm adiabatic theorem inferred merely
from G>0 and arbitrary H_E. It is not a no-go theorem for all holonomies,
all dissipative control, or carefully qualified physical source spectra.

The same projector path under N perfect repeated sector projections has
all-code-branch operator

    K_N=|s><s| - cos(pi/N)^N |d><d|,

so its worst all-code probability is cos(pi/N)^(2N), which tends to one.
This illustrates why actual irreversible observation can remove the resonance.
It does not construct a tunable projector coupling by itself.

2. AUDIT OF THE ROOT'S DAMPED BRIGHT/EXCITED CONSTRUCTION

In a frame removing the common source Hamiltonian, let b,e be source-valued
bright and excited amplitudes. More generally than a Hermitian positive gain,
allow an accretive transition amplitude A(t):

    bdot = -i A(t)^dagger e,
    edot = -i A(t) b - (kappa/2+i D(t)) e,

where

    g I <= Re A(t) <= h I,    0<g<=h,
    D(t)=D(t)^dagger,         ||D(t)||<=d,
    kappa>0.

Bounded/measurable coefficients or standard common-domain propagation
conditions suffice. No derivative of A or D enters the estimate. The common
source Hamiltonian may be arbitrarily fast and noncommuting; removing it
unitarily preserves the numerical-range bounds on A and the norm bound on D.

Define

    N=||b||^2+||e||^2,
    r=Im <b,e>,
    V=N+alpha r,
    c0=kappa/2+d,
    0<alpha<=min{1, kappa/[2h+c0^2/g]}.

Direct differentiation gives

    Ndot=-kappa ||e||^2,
    rdot=-Re<b,A b>+Re<e,A e>-(kappa/2)r-Re<b,D e>.

Therefore

    Vdot <= -alpha g ||b||^2 -(kappa-alpha h)||e||^2
             +alpha c0 ||b||||e||
         <= -(alpha g/2)||b||^2 -(kappa/2)||e||^2.

The second line uses
c0 xy <= (g/2)x^2+[c0^2/(2g)]y^2 and the declared alpha bound.
Also |r|<=N/2, so

    (1-alpha/2)N <= V <= (1+alpha/2)N.

The alpha bound implies alpha g<=kappa/2. Thus

    Vdot <= -[alpha g/(2+alpha)]V,
    ||U_BE(t,s)|| <= C exp[-lambda(t-s)],
    C=sqrt[(2+alpha)/(2-alpha)],
    lambda=alpha g/[2(2+alpha)].

For D=0, A=G=G^dagger this is the root's proposed lemma with exactly its
alpha bound. The signs and factors are correct.

The accretive extension is useful physically: A need not be a positive
classical amplitude or even Hermitian. A common traveling-wave amplitude
A=g0 exp(ikx) obeys Re A>=g0 cos(a) on a dynamically invariant domain
|kx|<=a<pi/2. The source can move noncommutatively inside that domain.
For a generic source, a globally fixed phase can first be used to put its
numerical range inside a right half-plane. A changing unknown phase is not
automatically allowed if it leaves that half-plane.

An arbitrary unbounded differential detuning D is not covered. It can
off-resonantly suppress excitation and make bright absorption arbitrarily slow.
The bounded-D version charges this explicitly: at large d the conservative
decay rate scales as kappa g^2/d^2, up to constants. A common large source
Hamiltonian costs nothing in this estimate, whereas a large differential
Hamiltonian is a real obstruction and resource cost.

Source-only Lindblad operators I_BE tensor L_j commute with the Lyapunov
observable and contribute zero to its adjoint generator. This provides an
extension of the same energy inequality to common Markov source noise.
For an exact full instrument theorem it is simpler to include arbitrary
common source surroundings in a joint unitary dilation, subject to the same
bounded transition-amplitude qualification.

3. MOVING DARK SPACE AND FULL GATE ERROR

Use the Kato parallel frame for a rank-r dark ground-space projector P(t)
and its one-dimensional bright complement. In that frame the geometric
connection is off-diagonal between dark and bright. Let its norm be at most
L/T. It sources the bright/excited system by a vector f(t) satisfying
||f(t)||<=L/T because the full no-emission propagator is a contraction.
The damped propagator estimate gives

    ||(b(t),e(t))|| <= C L/(lambda T)

for dark initial data, uniformly over source states and reference systems.
Integrating the back-action on the dark amplitudes gives

    ||d(T)-d(0)|| <= C L^2/(lambda T).

For complex control paths there is a gauge detail. The Kato-transported bright
vector can be b_K(s)=exp(i phi(s)) b_lab(s). Transforming only the ground basis
would replace A by exp(i phi)A, which need not remain accretive. Co-rotating the
excited basis by the same phase restores A and adds the known differential
term D_geom=(d phi/dt) I. Its norm is bounded by a path-dependent constant/T
and belongs in the bounded-D lemma. Alternatively, the actual common optical
pulse phase can be chosen so the laboratory bright vector is parallel. A
closed code-projector loop need not close that global bright-vector phase.

These are deliberately conservative sup-norm bounds. End-point smoothing can
reduce the final leakage separately; it is not required for the basic result.
The ideal target is the Kato holonomy on data tensor the actual free common
source evolution. Initial data-source-reference correlations are allowed.

Let K_0 be the physical no-emission operator and V_id the ideal dark isometry.
If ||K_0 P - V_id P||<=delta, all nonzero-emission histories together obey

    q_max=||P(I-K_0^dagger K_0)P|| <= 2delta+delta^2.

For the reduced full channel, photons or physical decay events distinguish
the zero-emission sector from other sectors; after tracing that field, the
nonzero-emission contribution is a completely positive map of trace at most q.
Consequently the half diamond distance on the admitted code is bounded by
delta+q_max/2 <= 2delta+delta^2/2.

This is O(1/T), not an unjustified O(1/sqrt(T)) dilation estimate and not a
postselected gate claim. All emission histories are charged, whether observed
or not. A detector is optional for this error estimate; a cold output channel
with the asserted decay law remains a physical resource. Thermal absorption,
a return channel that repopulates excited states, and non-common couplings
must be included in the actual generator/error budget.

For sources with different ground/excited trapping potentials, use the bounded
D extension. For rank-one optical transitions with slightly different spatial
mode functions, separate their common A(t) factor and bound the remaining
dark-space-breaking interaction on the admitted physical domain. Calling a
mean-energy bound an invariant domain is not valid; domain escape must be
proved or included as a separate probability/error cost.

4. PHYSICAL/ARCHITECTURAL LIMITS THAT SHOULD REMAIN VISIBLE

* A logical qubit's rank-two tripod dark space supports a gate set but does not
  itself provide scalable entangling gates between independently encoded qubits.
  An N-pod with 2^n ground levels has exponential physical/control size and cannot
  be counted as a scalable processor merely because it supports U(2^n).
* A conditional projector on |11> needs an actual interaction. Rydberg blockade,
  exchange, cavity mediation or another coupling must be qualified on the same
  source domain; the single-tripod lemma does not obtain it automatically.
* A common optical spatial factor is a microscopic condition. Different optical
  tones have slightly different wavevectors, and multiple polarizations may
  obey transversality/selection rules. A concrete atom must have enough resonant
  controls; one cannot assume three independent copropagating polarization
  components at a fixed frequency.
* For a traveling wave the localized accretivity domain can be maintained by
  confinement or treated through a tail/escape estimate. Initial localization
  alone is insufficient for arbitrary-duration warm evolution.
* Fresh emitted radiation, external control fields, stable relative phases,
  switching/ramp intervals and maintenance of the mode-factor bounds are real
  resources. The source need not be purified, but those resources are not free.
* A full optical microscopic approximation cannot hold uniformly for literally
  unbounded motional energies or arbitrarily fast transitions; the theorem's
  lack of ||H_E|| is an effective-model statement whose common-mode microscopic
  domain must still be earned.

7. SAME-TRIPOD COHERENT FAILURE AND DISSIPATIVE RECOVERY

The first counterexample used an effective Q tensor G bright energy. A stronger
comparison retains the same physical bright/excited tripod Hamiltonian used by
the dissipative construction. Let atom basis be |s>,|d>,|b>,|e>, where |s>,|d>
span the code, and take

    H_0 = I_atom tensor Omega Z
          + (|e><b|+|b><e|) tensor (g I+beta X),
    Omega=(g^2-beta^2)/(2g),    g=2, beta=1, Omega=3/4.

Rotate |b> with |d> by R(theta)=exp(-i theta Y_db), theta=pi t/T.
In the bright/excited basis |+>=(|b>+|e>)/sqrt(2),
|->=(|b>-|e>)/sqrt(2), the source Hamiltonians are H_E+G and H_E-G.
At source energy +Omega, exactly two participating levels are degenerate:

    |d,up>,    |+> tensor |v_minus(H_E+G)>.

The geometric connection between them has magnitude

    c=beta/sqrt[2(g^2+beta^2)]=1/sqrt(10).

The spectator |s,up> is also at that energy but has zero connection to the
rotating |d>,|b> plane. The H_E-G branch instead resonates with |d,down>
at energy -Omega; it adds no resonant partner to the up sector. Standard
finite-dimensional degenerate perturbation of the constant rotating-frame
Hamiltonian therefore yields

    lim_(T->infty) p_(bright or excited)
      =sin^2(pi/sqrt(10))=0.7021079103735884.

Both source eigenstates have the same limiting leakage, so even an initially
maximally mixed source exhibits this failure. This is not only a special pure
source effect. The exact co-moving matrix is

    H_rot=H_0-(pi/T)Y_db tensor I - i(kappa/2)|e><e| tensor I.

For kappa=0 it is Hermitian and produces the coherent counterexample.
For kappa>0 its no-emission propagator is the dissipative model, with all
emission histories charged through the lost norm. There is no numerical
time-stepping error: the check uses the exact finite matrix exponential.

tripod_resonance_comparison.py computes both limits and operator errors on
the entire initial code tensor source space. For kappa=0 and T=10000 the
bright/excited probability is 0.7021078882165744. For kappa=2 at the same
duration, the maximum code emission probability is 0.0007892575836087293,
the no-emission operator error is 0.0007079627378732996, and the resulting
full half-diamond sufficient bound delta+q/2 is 0.0011025915296776641.
At T=1000 this bound is 0.010993741796967084, consistent with the proven
inverse-duration scaling. Increasing kappa to 8 makes the T=10000 bound
0.0018763738698050535: arbitrarily increasing loss is not optimal because
overdamping slows bright-to-excited transfer.

The numerical code-space operator norm and lost-norm quantities are complete
over source inputs and so support reference-system extension analytically.
They are still floating-point diagnostics without certified rounding. They
are not measured device errors, experimentally certified operation times, or
claims that dissipation beats optimized coherent gates with calibrated sources.

8. AUDIT OF A TIME-ERROR LOWER BOUND FOR FLAGGED STAR-ONLY REFLECTIONS

This bound uses a fixed physical ground manifold P_g, one excited manifold,
and an absorbing flag space. After removing the common source Hamiltonian,
assume the only ground-changing Hamiltonian is

    H_ge(t)=|e><b(t)| tensor A(t)+h.c.,    ||A(t)||<=a.

The excited no-emission decay term is -i(kappa/2)P_e. All physical excited
decay channels lead to flags orthogonal to the ground space, and flags cannot
return. There is no direct ground-manifold Hamiltonian. Let u,v be normalized
orthogonal logical vectors. The spectator v is untouched by the operation,
so the no-emission operator K satisfies Kv=v. The target reflection F sends
u to -u and v to v. A pure source state can be included in u,v, or the scalar
source instance alone can establish a worst-case lower bound.

Suppose the actual full reduced output channel has half diamond distance at
most epsilon<1 from F on this code. Put n=<u|K u> and input
|+>=(|u>+|v>)/sqrt(2). No jump carries coherence from the spectator, and jumps
have only flag support. Therefore the norm-one observable

    X_uv=|u><v|+|v><u|

has target expectation -1 and physical expectation Re n. Trace distance gives

    1+Re n <= 2 epsilon.

An optimized linear combination of X_uv and Y_uv also proves
|1+n|<=2 epsilon, but the real-part inequality already suffices. Hence

    ||P_g K u-u|| >= |n-1| >= 1-Re n >= 2(1-epsilon).

In the fixed physical ground block the no-emission trajectory satisfies
||d psi_g/dt||<=a ||psi_e||. Integrating and applying Cauchy-Schwarz gives

    ||P_g K u-u||^2 <= a^2 T integral_0^T ||psi_e(t)||^2 dt
                   = a^2 T p_u/kappa.

The last equality uses the absorbing flag probability
p_u=kappa integral ||psi_e||^2 dt. The target has no flag outcome, so a final
measurement of the flag projector gives p_u<=epsilon. Combining the bounds,

    T >= 4 kappa (1-epsilon)^2 / (a^2 epsilon).

The constants and direction of the inequalities are correct. For fixed
kappa>0 and a this proves an unavoidable inverse-error duration within this
architecture. It does not establish a universal quantum speed limit. In
particular, a direct ground-manifold gate, a phase operation on the spectator,
nonabsorbing decay that repairs rather than flags, a different coupling graph,
or an epsilon-dependent choice of kappa changes the premise.

For non-Hermitian accretive A the norm a is a separate required upper bound;
an upper bound on Re A alone does not bound the full transition speed. The
proof must use the fixed physical ground projector P_g, not the moving dark
projector, whose derivative would introduce a geometric term. Removing a
common source Hamiltonian is valid and preserves ||A||. If only the logical
output is retained, the spectator still makes the relative phase observable;
source freedom cannot erase this lower bound without destroying that coherence.

The potential distinct contribution is the explicit uniformly stable
bright/excited dynamics for a fast noncommuting quantum amplitude, with a
source-independent dark holonomy, full non-postselected error and common
physical-domain qualification. Priority and practical superiority remain
unestablished.

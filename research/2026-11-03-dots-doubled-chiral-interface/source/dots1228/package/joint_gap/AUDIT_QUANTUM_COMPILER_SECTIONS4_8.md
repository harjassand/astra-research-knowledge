# Independent audit of quantum compiler sections4–8

2026-11-03. Read POLYNOMIAL_QUANTUM_TERM_COMPILER.md. Section3's coordinate-variation bound is separately audited and needs its reported additional sqrt(d) factor. This note assumes that polynomial repair.

## Findings
No exponential Fock-space or tensor-grid enumeration is necessary in the proposed representation. The polynomial gate claim is supportable after the following explicit bookkeeping repairs. This does not certify the preceding interface construction or turn the constants into practical ones.

1. **Shear and reset representation pass.** Write the actual D as a multiplication-unitary M followed by the single fixed integer shear S. Then D† A P0 A† D=S†(M†A) P0(A†M)S. There is still exactly one active reset coordinate. This also covers an original theta-ancilla reset. The Fourier action of S is an integer inverse-transpose map; using the larger box L'=c_D L and grid S_grid>2L' ensures the INPUT and OUTPUT cutoff vectors embed without aliasing. Intermediate grid states can have arbitrary Fourier labels; no no-alias claim for those states is needed, because the compressed matrix element is tested between the correctly embedded input and output vectors.

2. **Physical cutoff needs an explicit valid-code sandwich.** With d=2L+1 not a power of two, logical rotor registers have unused binary states. Define the physical code projector explicitly and a reversible embedding J taking valid signed momentum labels into the S_grid Fourier register. Prepare the padded auxiliary bits, map signed labels to their modular Fourier positions, and apply the grid QFT. Compress the grid block with J† and J. Accept validity at both ends, or equivalently block-encode P_valid A P_valid and give invalid states a decoupled prescribed block. Charge pinching alone does not prevent physical-to-invalid leakage. This is a polynomial exact-comparison/isometry addition, but must be stated.

3. **Grouped polynomial arithmetic passes.** Compression h_patch has norm<=R even when its gap closes. For B=1−h_patch²/R², ||B||<=1. Differentiating the grouped series gives polynomial k² growth, avoiding exponentially large monomial coefficients. Intermediate fixed-precision error grows polynomially in k,f and precision if each matrix multiply is rounded with a paid spectral/Frobenius error budget. No diagonalization or eigenvector conditioning is needed. The chosen polynomial is bounded by1 on [−1,1] after scaling, so even if the retained spatial entry mask increases a matrix norm by a polynomial patch factor, the quadratic coefficient sum remains polynomial.

4. **Gaussian Trotter synthesis passes conservatively.** There are O(f²) bounded bilinear coefficients, so summed norm is O(f²) and the first-order error is O(f^4/n_steps). O(f^6/eta) pair rotations, plus polynomial routing, is sufficient. Reversible computation of their coefficients from fixed grid angles is polynomial. Evaluate coefficients once, use them as unchanged controls, and uncompute only after the quadratic circuit. No superposition over classical matrix entries is required. Pair rotations use the declared integer-projector scalar convention where relevant; dropping scalar phases can change controlled-rotor Hamiltonians.

5. **Hermiticity must be enforced by construction.** For resets, synthesize an actual unitary A_circ and use its exact circuit inverse in A_circ R0 A_circ†. Use a synthesized QFT and its exact inverse in the embedding. Real approximants for Hermitian Pauli coefficients and scalar terms maintain Hermiticity. If a generic block-encoding approximation is used instead, replace its block by (A+A†)/2 using a standard two-branch controlled-U/U† construction. Its norm error does not increase. Exact charge pinching then preserves Hermiticity. Merely saying the target was Hermitian is insufficient for an arbitrary approximate block.

6. **Finite axial averaging needs the integer LOCAL convention.** On the closed rotor manifold, the global scalar S can be represented by the sum of integer m cup dm densities; its difference from (m−dphi)cup dm is a total coboundary. Using canonical compact-angle representatives makes these bounded measurable local functions. Together with K=Σ n_pair, every retained local generator has integer spectrum. The commuting controlled matching structure means only the causal support's finitely many generators act on a local term. A cyclic phase sample count exceeding its charge-difference range then exactly equals the Haar average. Do not apply the finite-cyclic claim to arbitrary fractional local densities without this rewrite. Proper counterterms are needed if the rotor manifold itself has a boundary.

7. **Charge-copy pinching passes.** Compute input integer charge into a clean register, apply the block-encoding circuit, subtract output charge and postselect zero. The accepted block is exactly Σ_q P_q A P_q. A modulus larger than the charge-difference range avoids aliasing. Use exact reversible integer gates and ensure the code-validity acceptance from item2. Subsequent coefficient approximations can be arbitrary before this sandwich, while its accepted Hamiltonian block has exact charge conservation. If only the SUM of target terms is symmetric, termwise pinching still preserves that sum by linearity; one need not assert symmetry of every decomposition term.

8. **Simulation scope.** After Hermiticity/code repairs, normalization alpha and all prescribed cutoffs remain polynomial in the displayed variables at fixed microscopic constants. Standard block-encoding Hamiltonian simulation applies. The exact symmetry is a property of the encoded finite Hamiltonian, not a promise that every finite-precision physical implementation of its evolution has zero symmetry leakage. Likewise the positive gap of the numerical Hamiltonian requires the global norm error to be budgeted below the previously established gap/fidelity margin, not just below epsilon/time. Ground preparation, the open chiral surface and gauge dynamics remain separate.

These checks are algebraic/operator bounds, not a full executable gate compiler. A reproducible small-code test of valid-code sandwich and Hermitian pinching would further verify the implementation bookkeeping, but is not required to remove an asymptotic exponential factor.

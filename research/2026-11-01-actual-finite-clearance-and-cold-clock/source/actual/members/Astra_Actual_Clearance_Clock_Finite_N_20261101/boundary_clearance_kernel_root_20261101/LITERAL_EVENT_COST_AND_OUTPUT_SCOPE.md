# What the output computes and what cost comparison it supports

Root conditional consequence; requires the current admission and clock receiver to be independently accepted before reporting the numerical output as certified.

Input is the specified twelve-channel count generator, raw state (0,N,1,1,0), encoded integer N, and a requested confidence. The output is an interval for the actual first hitting time of S<=15(N+2)/16. It is neither a microscopic trajectory nor a physical preparation or experimental observation. The count state can be supplied symbolically in O(log N) bits; claiming a real prepared population of N particles would require a separate physical construction.

Every actual jump changes L=A+(C+D)/2 by at most1 and E by at most1. From raw L=1,E=0, reaching the macro target E>=ceil(N/100) OR L>=N/5000 requires at least N/5000-1 actual reaction marks. Thus, on the same high-probability event that the received window proves macro arrival, a literal one-event-at-a-time exact trajectory simulator must enumerate at least that many marks. At N=10^25 this is 2*10^21-1. This lower bound is on that specific computational interface, not on all exact or approximate prediction algorithms.

The new interval computation need not enumerate either the reactions, H_N(E)'s product factors, or the population states. Local-ratio identities and closed log bounds acquire the carrier barrier. The numerical consumer uses a fixed number of rational operations, outward square roots, and the already acquired scalar-clock enclosure, plus explicit finite gate sums if accepting a broader input family. Reusing the scalar certificate is legitimate retained computation, but a cold comparison must also charge its construction and verification. Source retrieval, unsuccessful research, initial theorem construction, and independent checks must be reported separately rather than silently treated as zero measured work.

Strong ordinary competitors already include deterministic stiff integration, linear noise, multiscale averaging, approximate tau-leaping, and exact finite-state truncation. The first group can already generate inexpensive estimates of the clock; the last supplies certificates at potentially enormous state cost. The current specific advance, if accepted, is an error-budgeted actual stochastic timing interval at large encoded populations without simulating their firing history. No universal optimality, speedup over all conventional retained methods, historical novelty, experimental validation, or civilisation-changing significance is established by this comparison alone.

The exact weak CLT and random-phase readout remain separate accepted consequences, with no finite-N Gaussian CDF rate. A confidence interval does not become a sampling kernel or a Gaussian approximation merely because its center is the asymptotic blowup clock.

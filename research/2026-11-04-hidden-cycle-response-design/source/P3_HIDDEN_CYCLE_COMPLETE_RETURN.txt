## 1. The scientific object: which interaction signs can occur together?

Start with the operation we can actually execute: choose a binary configuration \(x\in\mathbb F_2^n\) and observe a scalar response. Write its canonical Walsh expansion as

\[
f(x)=c+\sum_{i=1}^{m}\theta_i(-1)^{a_i\cdot x},
\]

where the nonconstant frequency masks \(a_i\) are distinct and nonzero. Addition and dot products in the exponent are modulo two. An interaction may involve every visible control.

The key object is the matrix \(A\) having these masks as rows. Its image

\[
C_f=\{Ax:x\in\mathbb F_2^n\}
\]

records **all simultaneously attainable interaction-sign patterns**.

This matters even in a two-control example. Consider

\[
f(x_1,x_2)
=-(-1)^{x_1}-(-1)^{x_2}-(-1)^{x_1+x_2}.
\]

Each term individually prefers its parity to be one. Those three preferences cannot hold together, because

\[
x_1+x_2+(x_1+x_2)=0.
\]

Treating the terms independently predicts value \(3\); the actual maximum is \(1\). Learning the coefficients alone does not resolve this incompatibility.

The selected class consists of responses for which there exists an edge-labeled undirected multigraph \(G\) satisfying

\[
\boxed{\operatorname{im}A=\ker B_G,}
\]

where \(B_G\) is its binary vertex-edge incidence matrix. Thus attainable patterns are exactly the edge sets having even degree at every vertex.

Equivalently, the column matroid of \(A^{\mathsf T}\) is **cographic**. The graph may have loops, parallel edges, disconnected components, and unbounded treewidth. It is an existential promise, not an input.

The algorithm needs to recover any graph satisfying that equality. Recovering the original physical wiring or hidden coordinate transformation is unnecessary.

### The promise also supplies the description-length bound

Initially, the learner used a supplied sparsity bound. That input can be removed.

At each vertex of a realizing graph, \(B_GA=0\) says that the XOR of the masks on incident nonloop edges is zero. Therefore:

- Nonloop degree one would force an interaction mask to be zero.
- Nonloop degree two would force two interaction masks to be equal.

Both contradict canonical support. Every component with at least two vertices consequently has minimum nonloop degree at least three.

For such a component, let \(v\) count vertices, \(m_0\) nonloop edges, and \(\ell\) loops. Then

\[
2m_0\ge 3v,
\qquad
r_c=m_0+\ell-v+1,
\]

where \(r_c\) is its cycle-space dimension. It follows that

\[
m_0+\ell\le 3r_c-3.
\]

A one-vertex component contains only loops and has one independent cycle per edge. Summing over components gives

\[
\boxed{m\le 3\operatorname{rank}A\le 3n.}
\]

The learner can therefore set

\[
\boxed{S=3n+1}
\]

before making any observations, allowing for a constant term. This counting argument uses the promised graph’s existence without requiring its prior acquisition. Three-edge-connected cubic graphs make the factor three asymptotically sharp.

The resulting input boundary is particularly clean: **the cographic-support promise already forces a polynomially learnable description length.**

## 2. The starting mechanism: coordinated contrasts that reveal hidden interactions

Choose binary vectors \(v_1,\ldots,v_b\), write \(Vt=\sum_jt_jv_j\), and query the configurations \(Vt+z\) for every \(t\in\mathbb F_2^b\). Transform this small table:

\[
C_{V,z}(h)
=
2^{-b}\sum_t f(Vt+z)(-1)^{h\cdot t}.
\]

Character orthogonality gives the exact identity

\[
\boxed{
C_{V,z}(h)
=
\sum_{a:V^{\mathsf T}a=h}
\widehat f(a)(-1)^{a\cdot z}.
}
\]

The experiment groups Fourier interactions into buckets. It does so using actual chosen configurations, without enumerating the \(2^n\) frequencies.

If a bucket contains just one frequency \(a\), its unshifted value is \(\theta\). Shifting the same experiment by the unit vector \(e_j\) changes that value to

\[
\theta(-1)^{a_j}.
\]

Comparing signs therefore reveals bit \(a_j\). The unshifted experiment and its \(n\) unit shifts recover the entire interaction mask, regardless of how many controls participate in it.

The serious issue is collision. Several terms can cancel or imitate a different interaction. The construction must reject those imitations globally.

### A completely explicit deterministic acquisition

Let \(q=2^k\) be the smallest power of two at least \(4Sn\), for \(n\ge1\). Construct \(\mathbb F_q\) explicitly by finding an irreducible binary polynomial of degree \(k\). Even simple exhaustive trial division takes polynomial time in \(q\); here \(q=O(Sn)\).

Associate each frequency \(w\) with

\[
P_w(z)=\sum_{i=0}^{n-1}w_i z^i.
\]

For every \(b\in\mathbb F_q\), hash \(w\) to the binary coordinate vector of \(P_w(b)\). Two distinct frequencies collide for at most \(n-1\) values of \(b\), by the polynomial root bound.

These hashes are executable through the preceding experiment. For \(t\in\mathbb F_2^k\), choose

\[
x_i(t,b)=t\cdot\operatorname{coord}(b^i).
\]

Then

\[
(-1)^{w\cdot x(t,b)}
=
(-1)^{t\cdot\operatorname{coord}(P_w(b))}.
\]

For each hash, the algorithm decodes candidate masks from shifted bucket signs and requires each candidate to hash back to its purported bucket. It then accepts a candidate only if it appears in **strictly more than half** of all hashes.

- Every true frequency is isolated in more than \(3q/4\) hashes, so it is repeatedly decoded correctly.
- A false frequency can pass the hash-back check only when it collides with a true frequency. This happens in fewer than \(q/4\) hashes.
- Taking the median of the accepted frequency’s recorded bucket values returns its exact coefficient.

The schedule uses

(n+1)q^2=O(n^3S^2)

## 3. Noise: uncertainty must preserve the class that makes optimization possible

The acquired surrogate \(g\) instead satisfies two simultaneous guarantees:

\[
\boxed{
\operatorname{supp}\widehat g
\subseteq
\operatorname{supp}\widehat f,
\qquad
\|f-g\|_\infty\le\varepsilon.
}
\]

The first is essential: uncertainty may remove weak genuine terms, but it does not invent new ones on the success event.

Set

\[
\eta=\frac{\varepsilon}{3S}.
\]

In the more economical randomized implementation, use \(B=\Theta(S)\) buckets and several independent discovery hashes. A true frequency is isolated with probability at least \(7/8\) per hash. Unit shifts generate a polynomial candidate list.

Then acquire a separate collection of **independent validation hashes**. For each candidate, take the median of its validation-bucket values and retain it only if the median’s magnitude exceeds \(2\eta\).

Conditioning on the entire discovery transcript makes the reason for independence clear. A false candidate was selected using the discovery hashes and their noise. Those same observations cannot serve as an independent check of that candidate.

With appropriate confidence budgets:

- Every coefficient of magnitude greater than \(3\eta\) is retained.
- Every retained mask is genuine.
- Every retained coefficient has error at most \(\eta\).
- The total contribution of omitted coefficients is small enough that

  \|f-g\|_\infty
  \le \|\widehat f-\widehat g\|_1
  \le 3S\eta=\varepsilon.

There is **no minimum nonzero coefficient assumption**.

All other work is polynomial in these resource parameters and the total encoding length of the observations and numerical inputs.

Then \(\sigma=1\) suffices, every repetition supplies one outcome bit, and all means, transforms, thresholds, and medians can be computed exactly. Infinite-precision measurement is not an input.

### Computing the optimum and returning actual controls

For each retained coefficient, let

\[
w_i=|\theta_i|,
\qquad
b_i=\mathbf 1[\theta_i<0].
\]

The vector \(b\) is the collection of preferred parity bits. For an attainable vector \(y=Ax\), define \(z=b+y\). Then

\[
g(x)=c+\sum_iw_i-2\sum_iw_i z_i,
\qquad
B_Gz=B_Gb.
\]

Thus optimization asks for a minimum-weight edge set having a specified set \(T\) of odd-degree vertices: a **minimum-weight \(T\)-join**.

The algorithm computes shortest-path distances between terminals, finds a minimum-weight perfect matching, expands its matched pairs into paths, and combines those paths by **symmetric difference**.

This is globally optimal because any \(T\)-join decomposes into terminal-pairing paths and cycles. Removing nonnegative-cost cycles cannot increase cost, so a minimum metric matching costs no more than any \(T\)-join. Conversely, the symmetric difference of matching paths is feasible and costs no more than the matching. The two inequalities establish equality of the optima. This signed cycle-code decoding method is established mathematics. :chatgpt-content-reference{index="4"}

Finally, set \(y=b+z\) and solve

\[
Ax=y
\]

by binary elimination. The verified code equality guarantees that an actual control setting exists. The implementation checks every returned parity equation and the exact objective identity. Rational costs are scaled to integers of polynomial bit length before blossom matching; the matcher therefore does not depend on unbudgeted floating-point precision. :chatgpt-content-reference{index="5"}

For noisy acquisition, if \(\widehat x\) maximizes \(g\), then

\[
f(\widehat x)
\ge g(\widehat x)-\varepsilon
\ge g(x^*)-\varepsilon
\ge f(x^*)-2\varepsilon.
\]

That completes the observation-to-intervention guarantee.

Astra P3: acquired exact field counters

Environment executed: Python 3.12.14, NumPy 2.3.5. Other dependencies are Python standard-library modules. The independent matrix and stabilizer compilers use the standard library; the Frobenius audit imports the field modules and therefore also loads NumPy.

Read the accompanying mathematical proof for the structural promises, exact arithmetic, acquired representations, prior art and failures. This is a restricted exact counter, not a generic circuit or SAT solver. It makes no practical speed claim.

From the archive root, run:

python work_field_root/run_field_counter.py work_field_root/example_21_bit_input.json --output exact_count.json

Expected signed_count: 128; zero_count: 1048640.

python work_field_root/circuit_field_counter.py work_field_root/example_36_bit_circuit.json --output circuit_count.json

Expected original_variables: 36; gate_compilation.internal_gates: 3205; acquired_defect_rank: 4; signed_count: -176128; zero_count: 34359650304.

For the general acquired representation, including automatic bandwidth selection:

python work_field_root/run_field_counter.py work_field_root/example_21_bit_input.json --method acquire --bandwidth auto --output representation.json

The acquire method does not run a general field point counter. The complete count method implements the three-field-coordinate product-cubic family and bandwidth-one rank correction. Its field evaluator is an actual finite Dwork trace, not exhaustive field enumeration. General exact point counting in the theorem is a composition with the published Lauder--Wan algorithm.

ANF inputs are JSON objects with integer n and a polynomial array. A mask encodes the variables in one monomial: mask 0 is constant one, mask 5 is x_0*x_2. Repeated masks cancel modulo two. Program inputs have n, gates and output. Input wires have indices 0 through n-1; each subsequent gate appends one wire. Gates are ["CONST",bit], ["XOR",left,right], ["AND",left,right], or ["NOT",input]. Every reference must be causal. The program front end computes exact ANFs, allows sparse high-degree intermediate states, and checks a term budget after cancellation. Its default budget is the number of cubic ANF monomials. A final noncubic output or a failed field certificate rejects this route.

The count method streams Walsh leaves by default. --retain-leaves is only a finite diagnostic option and uses exponential storage in the defect rank. The saved small-fixture data retain diagnostic leaves. Large input cubes are not silently enumerated as a fallback.

The annihilator and stabilizer acquisition identities are unconditional. Their asymptotic local-phase counting consequences depend on the separately preserved phase theorem and the user-pinned OpenAI manuscript. Their finite test programs use exhaustive local leaves or exact constraint elimination; they do not implement that manuscript's asymptotic engine. The field-counting theorem is unconditional and has an actual narrower backend implementation.

The prior phase proof and quadratic diagonal-repair source are included under prior_dependencies only to make those conditional statements readable. Previous network and response-learning artifacts remain unchanged.

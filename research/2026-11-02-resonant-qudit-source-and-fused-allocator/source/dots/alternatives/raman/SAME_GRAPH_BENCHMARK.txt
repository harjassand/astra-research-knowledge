STRICT SAME-GRAPH ACTIVE/AUTONOMOUS BENCHMARK
2026-11-01. This supersedes the conditional O(w/g) statement for this particular apparatus graph.

Available native resources: same d=16 w=4 apparatus, data-dependent chain edges of strength g, identity endpoint reference |r|=J, detuning Delta, prefix-undo edges h=sqrt(Jg)/2, endpoint reset kappa=J, dump decay g. NO new fast identity reference or reset is added.

Explicit active control interface (additional control capabilities, not free native autonomous resources): individually gate existing coherent edges; tune onsite energies with amplitude at most Delta; gate existing reservoirs. These are standard external schedule resources but were not established as independently present in the original autonomous primitive. Conditional on them, we simulate the following exact finite-dimensional sequence on BOTH cache branches:
1. Resonantly activate first Pauli edge for pi/(4g), splitting the ground amplitude.
2. Sequentially activate remaining w-1 Pauli edges for pi/(2g) each. Now endpoint amplitude carries full S, while ground provides reference arm.
3. Apply endpoint onsite energy -Delta for pi/(2Delta), producing phase +i (w=4).
4. Activate EXISTING signed reference r_c=(-1)^c J for pi/(4J), recombining paths. Correct initial cached parity maps to g_c; mismatch maps to e_c.
5. Enable SAME endpoint and dump reset ports for R/J, R=2,4,6. e_c decays to g_(1-c). No external detector is required; the existing ground-state branch stores the answer.
Ideal gate latency = pi/(4g)+(w-1)pi/(2g)+pi/(2Delta)+pi/(4J). Thus strict same graph still pays 1/J. The earlier O(w/g+1/kappa) conventional comparator requires an additional fast coherent identity/probe control or a separate hardware compilation; it cannot be asserted for this strict graph. The dump's fast incoherent decay is not that coherent control.

Noise/imperfection model explicitly simulated in benchmark_same_graph_imperfect_controls.py:
- gamma/g=1e-6, one-site apparatus depolarization gamma[Tr(rho)I/d-rho] throughout both protocols;
- common uncalibrated +0.5% drift on coherent native couplings, including reference and reverse edges;
- reverse/upward copy of EVERY enabled reservoir jump with rate ratio 1e-5 (finite reset purity);
- active residual off coherent H=1e-5 H_native, and off reservoir rates 1e-5 of native rates;
- active pulse-duration systematic clock error +0.2%.
No noise-free clock, perfect off switch, or pure reset is assumed in this tested model. Waveforms remain piecewise constant; finite switching bandwidth is NOT simulated. Noise choices are illustrative declared fixed ratios, not experimental data or a universal fault model.

A common independent report-bit flip p adds e_report=p+(1-2p)e to either reported error; no perfect operational report is needed by the autonomous latch.

Interpretation: even without a fast reference edge, the matched scheduled comparator substantially improves finite-latency acquisition when given explicitly charged external gating/tuning. It is therefore not justified to claim an autonomous accuracy/speed win. The surviving autonomous capability is removing those real-time controls while retaining a finite microscopic generator and exact ideal dressed-logical algebra.

Scope limit: data syndrome is fixed, represented by its scalar sector. This is a genuine noisy 2x2 cache confusion channel (all starting cache values and both parity signs), not a full noisy quantum logical channel. It does not simulate data-error-driven syndrome histories, overlap scheduling, arbitrary apparatus initialization, or physical controller implementation. These remain distinct missing interfaces and must not be described as benchmarked. The complete arrays are benchmark_imperfect_controls_results.jsonl. The first benchmark_same_graph.py/results file records the simpler pre-control-leakage model, kept for provenance rather than overwritten.

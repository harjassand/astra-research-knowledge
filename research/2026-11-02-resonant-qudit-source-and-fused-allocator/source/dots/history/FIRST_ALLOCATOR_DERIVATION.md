## Primary mechanism: dark parking + physical token/locks
Two probes: add dark PARK and absorbing DONE states. Native Hamiltonian acts only on the active-cycle subspace, so launching from PARK uses a two-apparatus Lindblad jump, not a forbidden token–probe–data gate. Redirect native completion/report jump to DONE. A physical token t=A/B launches only its owner and hands off only on owner completion. A non-owner completion resets without handoff. A fault-free system alternates exact native cycles with O(1/g) launch/handoff overhead. A token fault can produce two simultaneous active cycles, but absent further faults first completion leaves at most one active probe and no other probe can restart until that remaining owner completes. This is noisy physical scheduling, not ideal mutual exclusion.

Baseline native rates fit mean cycle time T≈5.5/g. At launch and handoff rates g, per-check alternation rate is approximately g/(2(5.5+2))=.0667g; compare sparse-start r=.1 gives .06415g and cache error .06790. Token controller fault error scales O(eta*g*T), but constants/report noise need joint simulation. This is not an established numerical fidelity claim.

## Extension to bounded conflict degree D
Use one exclusive physical qutrit lock (free,u,v) on each conflict edge and one finite-state local acquisition/release controller per check. Check attempts: sweep/release stale own locks, acquire locks sequentially via two-apparatus jumps, abort/release immediately if a lock is busy, launch parked native probe only after collecting all locks, hold during native cycle, then release/reset. No waiting on busy locks, hence no acquisition deadlock, no global token, no need for globally shared clock or ordered global locks. All native Hamiltonian terms remain unchanged.

Key fault/repair details still being resolved: controller skips release and leaves orphan lock; controller enters RUN while probe PARK and waits forever; controller leaves RUN while probe active; malformed probe state. Proposed repairs: every attempt begins with owner-release sweep; pairwise RUN+PARK transition enters cleanup; DONE from any controller state enters cleanup; launch while active rejected. Native finite-state active sector must absorb into DONE with uniformly finite first/second moments from every reachable state. If this property fails, actual dissipative reset needs analysis (cannot assume it).

All fault-free trajectories starting clean have mutually exclusive neighboring active cycles. Controller/lock faults can violate it; their influence must be bounded through clearing sweeps and finite native completion, not by idealized perfect token assumption. Need finite expected repair window and local probability bound independent of graph size. Exponential-in-D lower bound for a local clean service window is easy but numerically weak; practical rate remains unestablished for general graph.

Physical pairwise try-lock protocol above compiles that guard with O(D) states/time. ## Explicit pairwise jump protocol
For vertex v of degree d, controller states CLEAN_j, COLLECT_j (j=0,...,d), WAIT, RUN. Edge lock e=(u,v) has states 0,u,v. Probe has PARK, native active states, DONE. All listed rates are g, apart from the native fixed g,gamma generator and a chosen constant attempt rate nu*g.

1. CLEAN_j + lock owner v -> CLEAN_{j+1} + lock 0. CLEAN_j + lock 0/u -> CLEAN_{j+1} with unchanged lock. After d edges, WAIT.
2. WAIT -> COLLECT_0 at nu*g.
3. COLLECT_j + next lock 0/v -> COLLECT_{j+1} + lock v. If next lock u, transition immediately to CLEAN_0, leaving lock u untouched. Never wait for a busy lock.
4. COLLECT_d + probe PARK -> RUN + native entry. COLLECT_d + any other probe state -> CLEAN_0 with probe unchanged.
5. Native completion enters DONE and writes cache using the baseline completion channel. DONE + ANY controller state -> PARK + CLEAN_0.
6. RUN + PARK -> CLEAN_0 + PARK. RUN + active probe has no ordinary outgoing controller transition; awaits completion.

Each transition touches at most two apparatus subsystems. Every data coupling remains native two-body probe–data coupling, enabled by occupancy of native states rather than a third-body conditional gate. Finite-state controller may be physically one O(d)-dimensional component or a charged equivalent register; its noise is NOT neglected. A cache write may require more than one physical transition depending on native representation and must be counted.

Fault-free proof: acquire owns all conflict-edge locks before launch; no edge can be acquired by another check until native completion; therefore neighboring native cycles cannot overlap. No acquisition deadlock because failure enters cleanup rather than waiting. All idle owners release stale locks before another attempt. Controller faults that jump into RUN without a running probe are repaired by rule 6. Controller faults during activity may release locks, but do not prevent eventual cleanup when DONE occurs.

Remaining proof obligation: native active sector drains to DONE uniformly even after a fault starts in an arbitrary active state and despite a bounded cluster of simultaneous neighbors. Correctness of isolated completed cycles alone DOES NOT establish this obligation. If native active sector is an open path with unitary edge labels and damping at an endpoint, no-dark-subspace proof is available: an invariant subspace with zero endpoint amplitude must also have zero adjacent amplitude because the endpoint has one invertible edge; recurse along path. Other probes preserve this cursor's site and do not affect this induction. This argument can fail for branched/interfering probes. The actual generator must be checked.

Conditional performance: a local clean service event involving v and its bounded conflict neighborhood has nonzero probability c(D,w,nu)>0 in a constant-length window, giving service lower bound c*g independent of system size. This bound can be exponentially poor in D and is NOT a practical numerical rate certificate. A fault has bounded-size affected neighborhood, and if the drain/cleanup process has finite exponential moments independent of system size, the space-time bad fraction is O(C(D,w)*eta); retained report errors additionally include cache noise and data-fault tracking at rate noise/(c*g). Proving a positive admission threshold requires constants and a local-stochastic fault bound, not just this scaling statement.

The strongest same-hardware alternative is this same noisy physical scheduler driving timed extraction (with its gate-clock/register/reset noise included). No claim of autonomous superiority is established. The concrete win over dilute random starts is structural: service density remains constant as controller noise is reduced, while overlap errors vanish with physical controller noise rather than with start rate.

## Parent-supplied completion premise and consequent self-stabilization
At 17:59 UTC parent supplied: native probes complete under arbitrary neighbor quantum states, from an incident-commutator bound. No parent general-graph architecture supplied. Under this premise, the protocol above has a clean repair argument and never pauses/resets a partial active probe.

An arbitrary controller state reaches a full cleanup in at most O(D) ordinary g-rate transitions plus at most one naturally completed active job (and an exponential WAIT attempt, if necessary). Every step except RUN has a local outgoing transition regardless of neighboring lock states; contention aborts immediately. RUN with PARK repairs directly; RUN with active probe completes by the supplied premise; DONE forces cleanup from every controller state. Launch while not PARK is rejected. Thus every controller repairs in a random time with an n-independent tail (exponential if native completion has such a tail). Any orphan lock is released during the named owner's next full cleanup. A corrupt controller may launch one unvalidated job before that first cleanup; after full cleanup all subsequent acquisitions obey the clean protocol. Never infer controller corruption merely from a bad cached report.

Uniform useful-service event from arbitrary state: suppress WAIT->COLLECT transitions of v and N(v) for a constant drain window L/g. With constant positive probability all their initially active jobs finish and all their controllers reach clean WAIT by the end; these cleanup sweeps cannot be blocked by outside locks. Then permit v's attempt while suppressing neighbors' attempts for another constant window: all incident locks are free, v acquires them in d g-rate transitions and runs an isolated correct cycle. The event probability c(D,T,L,nu)>0 and time Δ/g are independent of graph size. Iterating gives a geometric clean-service waiting bound and rate at least c*g/Δ. This proof is deliberately conservative; c can be very small and needs numerical optimization before practical claims.

An isolated physical fault causes a bounded set of controller/probe/edge defects. Their repair windows have n-independent tails. Old unvalidated active jobs can corrupt neighboring reports until they finish, but cannot replicate malformed controller states through a report. Controller logic never branches on the syndrome value. Under independent local physical faults, local bad-time/report probability therefore scales O(eta) with constants set by defect neighborhood, repair-tail moments, service rate, cache storage noise, and physical data tracking. This supplies a route to a positive admission threshold, not its numerical value. Physical jumps into DONE/active malformed states are charged probe faults; they are not hidden free resets.

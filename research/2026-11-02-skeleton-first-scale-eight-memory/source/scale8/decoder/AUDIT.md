# Proof audit and scope

## Why arbitrary component-size decisions are not fatal

Changing one check may merge or split components of unbounded diameter. The affected union of old and new components is nevertheless connected to that changed check, and its size is charged to all the occupied checks in those components. The space–scale animal pays for this whole union. No assertion of bounded influence radius is made.

## Why an isolated coarse-syndrome Peierls estimate is insufficient

Even if both decoders' syndromes vanish at an intermediate scale, their lower-level corrections can differ by a nontrivial logical. This proof separately bounds the physical support of that correction difference using distance. The resulting d/S_h term is indispensable.

## Necessary exact interpretation of the geometric assumptions

A fixed, uniformly bounded-degree ambient space–scale graph must contain every possible component shape, correction enlargement, and selected dependency connector. A statement that each realized component happens to have bounded degree is not enough: its edges could otherwise vary nonlocally with the syndrome and create uncounted entropy. Fixed bounded-local maps on a geometrically nested hierarchy give the ambient graph when their reverse multiplicities are bounded too.

Component consistency means a component's decision is fixed by its own labeled local data. Merely saying "choose a minimum" without fixing tie-breaking does not establish this property. Likewise a hidden state surviving after syndrome discrepancies disappear invalidates the stopping argument unless it is included and charged.

## Output overlap is harmless if all relevant parents are included

The theorem states the convenient unique-owner form. More generally select every input component contributing to each selected nonzero output check. The input components are disjoint. Then

  sum |input_C| >= 2 sum |output_C| >= 2 |selected outputs|.

Cancellation does not hurt this inequality. Each selected nonzero output still needs at least one contributing parent for connectivity. One must include all the relevant component supports when reconstructing a changed decision, but this does not require bounded-arity selection. Thus unique ownership is sufficient, not fundamentally necessary.

## Depth matters

The theorem does not claim arbitrary terminal decoders are stable with shallow hierarchies. It counts any changed terminal syndrome as failure. A depth-limited hierarchy has only the general exp[-c min(2^h,d/S_h)] bound. To improve that requires a separate, proved reference-decoder stability property. The terminal code's distance by itself is not a deterministic promise about an arbitrary decoder.

## Exact statistical input

Only P(T subset supp(s))<=q^{|T|} is used, for each fixed witness leaf set T. No witness is removed from a valid syndrome, no Gibbs energy-lowering map is constructed, and no assumption of independence of check bits is made. Both comparison runs are charged to the same s; s' differs at only k base checks. The two-run witness therefore pays for distinct original occupied checks, not a fictitious independent product of two Gibbs laws.

## Common-lift requirement

Identical higher-level syndrome implies identical higher-level correction before lifting. For cancellation on the physical code, both runs must also use the same lift. Branch-dependent lifts are not automatically harmless: their difference can act on a large common higher correction. Either use fixed common lifts, or explicitly charge bounded alignment-homotopy differences in the influence trace. The mere existence of some exact logical identities does not supply this support estimate.

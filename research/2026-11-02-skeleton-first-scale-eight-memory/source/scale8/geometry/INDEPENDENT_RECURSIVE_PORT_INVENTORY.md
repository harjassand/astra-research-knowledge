## Resource amendment: recursive common refinement is NOT automatically harmless

Root correctly flagged a gap in the generic common-refinement wording above. A uniform bound for one substitution does not itself prove a uniform minimum physical cell scale after infinitely many substitutions. Therefore the verdict above earns topology/degree inventory closure for the defined labeled substitution, but physical density closure requires a fixed master-port realization or no additional physical subdivision.

For the displayed T exterior paths, the lengths are left(4,4,4), right(3,5,7). Uniform normalized arc parameters admit a common master denominator420; the union of their knots has17 vertices. Including denominator8 rib markers and denominator6 virtual warp subdivision gives a safe finite arithmetic denominator840. These numbers bound THIS set of port/warp conventions, not all unlisted geometric interpolation operations.

The crucial distinction is that the warp's common subdivision can be entirely VIRTUAL: compute the cochain/prism maps on it, then compose with subdivision contractions back to the original physical cellulations. Such virtual denominators never change the hardware or accumulate geometrically. This is the preferred option if the physical source-template boundary words already match through their inherited integer-grid edge IDs.

If physical boundary refinements are needed, the construction must record a fixed finite output-port word and geometric grid for every input-port type, and show that all output types return to that same inventory. Repeatedly taking normalized fractions along each newly created short physical edge is NOT permitted: the minimum edge scale could shrink each generation and invalidate bounded density. A fixed enlarged scale such as 8D may repair this, but D=840 alone is NOT a proof: the enlarged rib locations, source perturbation boxes, translation, and all emitted cell types must still be checked. No full enlarged-scale geometric compiler was supplied in this audit.

Thus the exact remaining physical-resource gate is a finite recurrence table (input boundary type -> emitted ordered integer/rational vertex word, outgoing type, embedding route), or proof that all further subdivisions are virtual and the unchanged source physical words already glue. There is no identified nontrivial port cycle; the unresolved issue is uniform metric realization, not abstract seam topology. Do not quote the source's numerical density constant or literal ell=8 admission solely from this independent audit.

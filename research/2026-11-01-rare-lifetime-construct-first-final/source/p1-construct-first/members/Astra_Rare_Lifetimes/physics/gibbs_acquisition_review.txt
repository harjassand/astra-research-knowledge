GIBBS ACQUISITION EXTENSION: ORDINARY COMPARATOR AND PHYSICAL CONTRACT
Independent review, 2026-10-31. This note supplies caveats and an ordinary
construction, not a claim of a new feasibility class.

1. STRONG EQUALLY INFORMED ORDINARY CONSTRUCTION

For a binary path Gibbs model
  W(x)=exp(sum_i h_i x_i + sum_i J_i x_i x_{i+1}),  x_i in {-1,+1},
local heat-bath conditional probabilities satisfy
  (1/2)logit p_i(+|a,b)=h_i+J_{i-1}a+J_i b.
Holding the two neighbors in each of four contexts and observing marked
heat-bath update outcomes yields independent Bernoulli samples by the specified
heat-bath rule. The initial central spin and global mixing time are irrelevant.
Estimate conditional logits and use their four-point Walsh coefficients to
recover h_i and its incident J values. Average the two estimates of each shared
edge coupling. This ensures a compatible global Gibbs family; arbitrary
independently fitted conditional tables need not be compatible.

If all local conditional probabilities lie in [a,1-a], a>0, estimating each
probability to a*delta/2 is sufficient for parameter error at most delta (using
clipped estimates and a conservative logit derivative bound). Hoeffding gives
O(a^-2 delta^-2 log(n/alpha)) update attempts per local context. There are O(n)
contexts. To achieve uniform unnormalized log-weight error u it suffices to take
delta=u/(2n-1), giving O(n^3 a^-2 u^-2 log(n/alpha)) attempts by this simple,
non-optimal construction. Known positive attempt-rate lower bounds convert
event counts to elapsed calibration time. If local widths grow with n, a may
be exponentially small; bounded local width and accessible update attempts
must be part of the claimed polynomial regime.

For |log What(x)-log W(x)|<=u uniformly,
  exp(-2u)<=pihat(x)/pi(x)<=exp(2u),
and the same bound holds for pihat(A)/pi(A) and for conditional density ratios
pihat(x|A)/pi(x|A), whenever A is nonempty. The factor two includes normalization.
Thus relative accuracy for exponentially small cylinder mass requires local
parameter accuracy O(epsilon/n), not exponentially small accuracy.

Ordinary transfer matrices / forward-backward dynamic programming compute the
partition function and the constrained partition function for a cylinder A in
O(n) arithmetic operations, and supply conditional draws. Bit precision and
randomness must still be charged; rational local weights or certified interval
evaluation can avoid hidden real-arithmetic oracles.

Feed the resulting model into standard nonreversible potential theory,
cycle-sector comparison, screened/soft capacities, and exponential hitting-time
theory. The current project's explicit finite-constant confidence composition
can be useful, but adding inverse-Ising acquisition and path dynamic programming
does not establish a new computational feasibility class.

Relevant primary comparators:
  Dutt et al. (ICML 2021), active/short-trajectory learning of Ising dynamics:
  https://proceedings.mlr.press/v139/dutt21a.html
  Gaitonde and Mossel (STOC 2024), node-wise logistic learning from several
  local dynamics: https://arxiv.org/abs/2311.09197
  Gaitonde, Moitra and Mossel (COLT 2026), learning from actual state changes
  alone, for broad reversible single-site dynamics:
  https://proceedings.mlr.press/v336/gaitonde26a.html
The last comparator is stronger in observation access than marked-attempt
learning, but does not automatically cover a generator with driven 2-bit cycles.

2. WHY CLAMPING IS A REAL ASSUMPTION

The valid engineered model specifies that a native local update kernel and its
clock law remain the same when neighbors are held by the calibration controller.
The controller can select contexts and observe the designated channel's event
counter, including unsuccessful/null attempts. A Gibbs invariant distribution
or detailed balance alone implies neither this intervention invariance nor
absolute transition speeds. Hidden channels, changed transition-state barriers,
changed clock rates, or unobserved null events invalidate simple calibration.

Concrete nonidentifiability if intervention invariance is dropped: let C mark
whether calibration clamps are present, and take
  q_{i,C}(x,x^i)=a_i(C) q_i^HB(x,x^i).
Two devices can have a_i(C)=1 in every measured clamped experiment, but all
a_i(0)=1 versus all a_i(0)=c in free operation. Both obey detailed balance with
the same Gibbs measure in every regime. Every measured clamped conditional and
event-count distribution agrees. Free mean hitting times differ by factor 1/c.
This counterexample shows exactly why an architecture promise is needed.

A local Gibbs-preserving directed cycle is mathematically straightforward.
For fixed exterior z write W(x,z)=Wout(z) w_z(x), and cycle three of the four
2-bit states. Set q(x,Px)=kappa_z/w_z(x) on that cycle. Then pi(x,z)q(x,Px)=
Wout(z) kappa_z/Z is constant around the cycle, so the cycle preserves pi.
Its length is three. This is a designed stochastic component. It is not implied
by thermal dynamics or detailed balance; Gibbs invariance does not imply
equilibrium reversibility. Pure one-way transitions should not be advertised
as a finite-dissipation thermal implementation without reverse channels or a
specified controller. Adding a reverse cycle is a possible separate design,
not a fact established by the abstract generator.

Physical reference illustrating kinetic freedom: Sigg, Voelz and Carnevale,
J. Chem. Phys. 152, 084104 (2020), explicitly distinguish rate choices satisfying
the same detailed-balance ratio:
  https://pmc.ncbi.nlm.nih.gov/articles/PMC7042020/
Primary Gibbs-preserving irreversible Ising example: Godreche (2011):
  https://arxiv.org/abs/1102.0141

3. TARGET ACCESS CANNOT BE SMUGGLED INTO THE CLAIM

Even a known uniform product Gibbs law does not make arbitrary target
conditioning cheap. Let A={z} for an unknown n-bit z, accessible only through
membership queries. Its mass 2^-n may even be supplied. Averaging over uniform z,
an algorithm using k membership queries and then returning a candidate has
success probability at most (k+1)/2^n. Hence constant-success conditional
sampling requires Omega(2^n) membership queries in this oracle model. This is an
unconditional lower bound, not a complexity-separation assumption.

For an explicitly described Boolean formula F, exact target mass under uniform
bits equals #SAT(F)/2^n, so a general efficient exact-mass service would compute
#SAT. This is an exact reduction, not a proof that no such algorithm exists.
Similarly, a sampler with guaranteed polynomial runtime and a correct empty-set
flag would decide satisfiability; a sampler promised only nonempty inputs does
not automatically decide unsatisfiable instances. Keep these distinctions.

Cylinders on a known path are a clean earned interface: constrained transfer
matrices supply both mass and conditional samples. More general target classes
require an explicit additional algorithm and its cost.

4. COMPARISON CHECKS

The previous common-pi robustness theorem cannot simply be reused when Gibbs
weights change: the Hilbert space, stationary averaging, and target conditional
law all change. Use the separate weighted-flow comparison with normalization
factors explicitly retained. Gap lower bounds likewise must be earned for the
fitted/true path model, not inherited from the uniform independent-flip example.

Recommended scope: a finite-confidence acquisition and rare-event prediction
theorem for a specified engineered family with local, intervention-invariant
rules, bounded local widths, a certified gap, and transfer-matrix target access.
This removes a given-stationary-law input from that family and quantifies its
replacement cost. It does not solve arbitrary unknown Gibbs models, arbitrary
rare-set sampling, or generic physical reliability prediction.

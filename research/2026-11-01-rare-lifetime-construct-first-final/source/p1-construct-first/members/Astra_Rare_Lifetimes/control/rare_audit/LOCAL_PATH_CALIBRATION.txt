CONSTRUCTIVE LOCAL CALIBRATION FOR A RATIONAL BINARY PATH
1 November 2026

RESULT

For a known binary path architecture, nonrare local clamping and marked unit
heatbath attempts acquire rational fitted factors and a simultaneous pointwise
stationary-weight confidence band. The true and fitted generators both have
an earned constant additive-symmetric gap. Directed local three-cycles can be
added with their stationary circulation explicitly constructed. No complete
rare target configuration is needed during calibration.

This is a model-qualified statistical construction, not a claim that arbitrary
physical clamping preserves native rates. The modular proposal/mark interface
below is essential. Standard logistic identification, transfer matrices and
Dobrushin coupling are credited as conventional machinery.

1. TRUE ARCHITECTURE AND ACTUALLY OBSERVED LOCAL INTERFACE

The state is x in {0,1}^n, n>=2. Unknown positive factors satisfy

   9/10 <= a_i,b_i <= 11/10,
   w(x)=product_(i=1)^n a_i^(x_i)
                   product_(i=1)^(n-1) b_i^(x_i x_(i+1)),
   pi(x)=w(x)/Z.

Each site has a visible independent unit-rate Poisson attempt clock. At an
attempt it proposes a heatbath redraw of x_i. Given its neighboring bits l,r,
the odds of a proposed1 versus0 are

   R_i(l,r)=a_i b_(i-1)^l b_i^r,

with missing boundary factors omitted. If the proposal equals the current bit,
the event is a marked null. The proposal probability does not depend on the
old bit. Proposal rates are a known local function of the displayed factors.

The calibration intervention may set/hold the current bit and its at most two
neighbors, and observe proposed redraw marks without committing them. Other
sites need not be prepared or frozen. Holding these local bits does not change
the proposal probabilities, attempt-clock rates or their readout convention.
This causal modularity follows from the declared proposal mechanism; it cannot
be inferred from finite unrestricted observations alone. If only state changes
are visible or a clamp changes the local proposal law, this protocol does not
apply without another paid observation/control construction.

Every true local odds value belongs to [(.9)^3,(1.1)^3]. Therefore both positive
transition/proposal rates

   q_+(l,r)=R_i(l,r)/(1+R_i(l,r)),
   q_-(l,r)=1/(1+R_i(l,r))

are greater than1/3. This holds at all nonrare calibration settings. It includes
the boundary sites, whose odds ranges are narrower.

2. TWO NEIGHBOR SETTINGS PER SITE SUFFICE

For each site i, use the setting in which every existing neighbor is0. Measure
both current-bit directions and form the rate ratio Rhat_i(0,0).

For each i<n, also use right neighbor1 and left neighbor0 (when present).
Measure both directions and form Rhat_i(0,1). Then define

   atilde_i=Rhat_i(0,0),
   btilde_i=Rhat_i(0,1)/Rhat_i(0,0),   i<n.

There are2n-1 neighbor settings and4n-2 positive-rate counts. No fourth-setting
consistency test is needed for identification UNDER the known path architecture.
Additional settings can test that architecture, but finite testing cannot prove
the entire parametric assumption. Each shared b_i is estimated only once, so
the fitted model is globally consistent by construction.

For each positive rate run, hold the required current bit and neighbors for a
fixed duration T. The observed positive-proposal count N_j is Poisson(q_j T),
and qhat_j=N_j/T. Counts are rational when T is an integer; all fitted factor
ratios below are then rational. Fresh disjoint runs make the usual Poisson
model literal; the union bound itself does not need independence between runs.

3. SIMULTANEOUS CONCENTRATION AND EXACT COSTS

Choose0<eta<1 and failure allowance delta_cal. The standard Poisson Chernoff
bound gives

   Pr(|qhat_j/q_j-1|>eta)
      <=2 exp(-q_j T eta^2/3)
      <=2 exp(-T eta^2/9).

Thus the deterministic integer duration

   T=ceil[9 eta^(-2) log((8n-4)/delta_cal)]

gives, with probability at least1-delta_cal,

   1-eta <= qhat_j/q_j <=1+eta for EVERY measured rate.

Every required count is positive on this event. If any required count is zero,
the fixed-budget protocol reports a failed calibration instead of dividing by
zero or inventing a fitted ratio. This failure is included in delta_cal.

Sequential elapsed observation time is (4n-2)T, plus the separately charged
clamp-setting/reset/readout time. Each setting holds at most three local bits.
The expected number of heatbath attempt marks is (4n-2)T. With a further event
budget delta_evt, the total is at most

   2(4n-2)T +2 log(1/delta_evt)

with probability at least1-delta_evt (a conservative Poisson mgf bound).
Counts can be accumulated in O(n) counters; reading every mark costs the actual
mark count. There is no factor1/pi(A) for a later rare target in these costs.

If one uses the EXACT known unit heatbath normalization, one held-current run
per neighbor setting is enough: the two Poisson-thinned outcome counts (or a
fixed number of Bernoulli redraws) determine both proposal probabilities. The
4n-2-run construction above is deliberately conservative and also makes the
forward/reverse ratio interpretation explicit.

4. RATIONAL FIT AND WHOLE-WEIGHT CONFIDENCE EVENT

Let

   ell_eta=log[(1+eta)/(1-eta)], alpha_eta=-log(1-eta).

On the simultaneous event,

   |log(atilde_i/a_i)|<=ell_eta<=2alpha_eta,
   |log(btilde_i/b_i)|<=2ell_eta<=4alpha_eta.

Clip every fitted factor to the rational interval [4/5,5/4], giving ahat,bhat.
Because all true factors are inside this interval, clipping cannot increase
any displayed log error. No logarithm is evaluated to perform the fit: ratios,
products, comparisons and clipping are rational operations.

Let what be the product weight constructed from ahat,bhat. Uniformly over all
2^n configurations on the SAME event,

   |log[what(x)/w(x)]|
      <=u=(3n-2)ell_eta<=(6n-4)alpha_eta.

Consequently

   exp(-u)Z<=Zhat<=exp(u)Z,
   exp(-2u)<=pihat(x)/pi(x)<=exp(2u).

Every target mass p=pi(A) then lies in

   [exp(-2u)phat,exp(2u)phat] intersect[0,1].

The fitted law is explicitly acquired; the true law is bounded, not identified
exactly from finite data. Exact sampling from the fitted law must not be
described as exact sampling from the unknown true law.

To ensure a chosen global weight budget u0, it suffices to take

   eta<=1-exp[-u0/(6n-4)].

For fixed small u0, the conservative sequential calibration time is therefore
O(n^3 u0^(-2) log(n/delta_cal)). This polynomial bill is retained rather than
hidden behind constant local accuracy.

5. EARNED TRUE AND FITTED GAP

Changing one neighboring bit changes a heatbath log odds by log b. The maximal
change of the redraw probability is

   sup_t |logistic(t+log b)-logistic(t)|
      =tanh(|log b|/4).

For true factors, every such influence is at most

   c_true=tanh(log(10/9)/4)=19-6sqrt(10).

For fitted factors it is at most

   c_fit=tanh(log(5/4)/4)=9-4sqrt(5).

Each site has at most two neighbors. Couple two heatbath paths using the same
site clocks and common redraw uniforms. The expected Hamming distance obeys

   d/dt E d_H(X_t,Y_t) <= -(1-2c_fit) E d_H(X_t,Y_t).

This follows by bounding each new discrepancy by the sum of neighbor
influences; the path's symmetric influence bound controls both row and column
sums. Coupling first neighboring configurations and then using path coupling
extends the inequality to all pairs. Thus the semigroup contracts Lipschitz
differences at rate kappa=1-2c_fit.

The heatbath generator is reversible for its own Gibbs law. If a nonconstant
eigenfunction had eigenvalue lambda<kappa, its difference under the semigroup
would decay as exp(-lambda t), contradicting the coupling estimate for a pair
on which it differs. Therefore its L2 spectral gap is at least kappa. This is
a finite-state proof, with no unearned mixing oracle or asymptotic limit.

In particular,

   g_true>=12sqrt(10)-37>0.9473,
   g_fit >=8sqrt(5)-17>0.8885.

The common rational lower bound g>=1/2 is safely earned. Known site-attempt
rates bounded below by c would multiply these lower bounds by c. If the rates
are unknown, their visible clocks need their own simultaneous calibration.

6. AN ACTUAL LOCAL THREE-CYCLE WITH THE SAME STATIONARY LAW

For adjacent sites i,i+1, fix the outside neighbors l=x_(i-1), r=x_(i+2), with
boundary factors omitted. Define the LOCAL weight of the two-bit state(u,v):

   wloc(u,v;l,r)=a_i^u a_(i+1)^v
                 b_(i-1)^(l u) b_i^(u v) b_(i+1)^(v r).

The global weight is C(outside)*wloc, where C(outside) does not depend on u,v.
Use a visible independent clock of rate kappa_i and the directed cycle

   00 -> 01 -> 11 -> 00,

leaving10 fixed. At a clock ring in one of the three active states, execute
the next cycle step with probability m0/wloc and otherwise return a marked
null, where

   m0=(4/5)^5=1024/3125.

At most five local factors appear and every fitted factor lies in[4/5,5/4],
so0<m0/wloc<=1 for BOTH the true and fitted models. All fitted probabilities
are rational. For fixed outside configuration, the unnormalized stationary
flow along every directed edge is EXACTLY

   w(x) q_cycle(x,next)=kappa_i m0 C(outside).

It is constant around the cycle; its divergence is zero. Summing all such
cycles preserves pi without assuming detailed balance. The kernel includes
nulls and a two-bit transition11->00; those are part of the declared primitive,
not generated freely by independent single-bit flips.

Every invariant Markov generator has a positive semidefinite additive
symmetric part in its own stationary inner product. Adding these directed
cycles therefore cannot decrease the heatbath gap proven above. True and fitted
full generators inherit their respective displayed bounds.

The original permutation form must be generalized carefully: this accepted
cycle kernel has state-dependent acceptance and is not a permutation. Its
STATIONARY-FLOW form is a constant-circulation three-cycle. The csc(pi/3)
sector proof applies to that flow form, because the weighted inner product
reduces each orbit to its common circulation times the ordinary three-cycle
quadratic form. A theorem insisting on literal uniform-measure permutations
cannot simply be quoted without this explicit flow-level reformulation.

7. CLOCK CALIBRATION AND FLOW COMPARISON

Visible clock marks, including inactive-state and rejected null firings, give
N_i~Poisson(kappa_i T_k) without requiring rare enabling states. If every
kappa_i>=kappa_min>0, simultaneous relative error eta_k follows from

   T_k>=3/[kappa_min eta_k^2] log[2(n-1)/delta_k]

when all clocks are observed concurrently. Sequential separate observations
multiply elapsed time by the number of clocks. If no lower clock-rate promise
is supplied, adaptive confidence intervals can be used but their actual
waiting times remain; null visibility does not remove slow physical clocks.

All fitted kappa_i=N_i/T_k are rational. Source and fitted generators now have
fully specified local rational transition rules; total fitted marked rate is

   Lambda_hat=n+sum_i kappahat_i.

For a heatbath edge with unnormalized endpoint weights w0,w1, its reversible
conductance is

   f=w0 w1/(w0+w1).

This is homogeneous and coordinatewise increasing. Therefore the global
weight event exp(-u)w<=what<=exp(u)w implies

   exp(-u)<=fhat/f<=exp(u).

There is no extra local-rate error factor in this conductance comparison.
For a directed cycle the flow is kappa_i m0 C(outside), so

   |log(fhat_cycle/f_cycle)|<=u+alpha_(eta_k).

The outside product uses only a subset of the global factors and obeys the
same conservative u. These are UNNORMALIZED flow comparisons. If normalized
pi flows are used instead, normalization contributes its own bounded factor.

8. EXACT FITTED TARGET COMPUTATION AND RANDOMNESS COST

For the path, partition functions and marginals of the acquired rational model
are computed by ordinary two-state transfer messages in O(n) rational
arithmetic operations. A target fixing any specified subset of bits is handled
by zero/one masks at those sites. Its fitted probability phat is then exact and
an exact fitted conditional sample is obtained by backward messages and
sequential conditional Bernoulli draws. No rejection factor1/phat is needed.

This does not cover arbitrary membership-defined targets. Their counting and
conditional sampling can remain hard; the target grammar must be stated.

If factor numerators/denominators have at most L bits, straightforward exact
messages have O(nL+n) bits and all arithmetic has polynomial bit cost. A rational
Bernoulli probability A/B is sampled exactly by drawing a uniform integer in
{0,...,B-1} with ceil(log2 B) fair bits and rejection; the expected number of
trials is less than two. There are no irrational thresholds or unit-cost real
random coins. The naive full conditional sampler uses O(n^2(L+1)) expected
random bits; sharper arithmetic is optional, not assumed.

These samples initialize a CLASSICAL simulation of the fitted chain. Preparing
the corresponding physical many-bit state requires a separately charged
control service. Local calibration itself never needs that global rare target
preparation. Likewise, the known local transition maps are part of the source
architecture; estimating factors does not learn an otherwise unknown simulator.

UNRESTRICTED SAT: DECISION-ONLY FINITE-FIELD CONTINUATION

STATUS

This continuation does not establish a uniform polynomial-bit SAT algorithm
and does not prove that one is impossible. Its completed results concern one
decision-and-witness construction attempt. They are not extra requirements
imposed on alternative SAT algorithms. In particular, exact counting, all

1. THE CANDIDATE: INJECTIVE EXPONENTS AND A NONZERO VALUE

Let F be a CNF whose n occurring variables have been uniformly renumbered
x_0,...,x_(n-1). Preserve this original universe when subsequently adding
unit clauses. Write

  c(x) = sum_(i=0)^(n-1) 2^i x_i,
  P_F(T) = sum_(x satisfies F) T^c(x) in F_2[T].

Each exponent identifies exactly one assignment. Therefore no coefficients
cancel in the definition of P_F, and

  F is satisfiable if and only if P_F is not the zero polynomial.

The exponent weights have polynomial binary descriptions: storing all
weights takes O(n^2) bits. The polynomial degree can nevertheless be
2^n-1. This distinction does not itself rule out a compressed algorithm.
It rules out charging dense coefficient storage only by log(degree).

The proposed decision route evaluates P_F at selected elements of finite
fields of characteristic two. A nonzero value certifies existence. A zero
value alone does not certify unsatisfiability. This is a weighted parity
operation, not an exact integer count. At the point 1 it is ordinary parity
of the number of satisfying assignments.

CONDITIONAL WITNESS THEOREM.
Suppose a uniform algorithm constructs, from F, a polynomial-size list of
explicit finite fields and points with the property

  P_F != 0 => some selected value P_F(a_j) != 0.

Suppose also that a uniform deterministic algorithm evaluates the selected
weighted sums for F and its unit-clause restrictions in polynomial bit time.
Then this candidate yields a uniform deterministic polynomial-bit SAT
decision-and-witness algorithm. The two suppositions have not been
constructed here.

Proof of the witness component. First evaluate the q selected tests. If all
are zero, the stated hitting property certifies UNSAT. Otherwise fix a
point a at which the value v is nonzero. At the current partial assignment,
split on the next original variable. With the original exponents retained,

  P_current(a) = P_(current AND x_i=0)(a)
              + P_(current AND x_i=1)(a).

Query the zero branch. If its value is nonzero, choose it. If it is zero,
choose the one branch, whose value is the nonzero parent value. The invariant
is maintained through all n variables. At a leaf, an unsatisfying assignment
would have value zero, so the obtained assignment satisfies F. Verify it
directly against the original clauses.

This uses q+n evaluation calls, not every conditional marginal. A point a=0
causes no problem: keeping the full original exponent prevents an invalid
division by a power of a. No division by the number of witnesses occurs.

Cost accounting. Let N be the complete binary input length, q the number
of tests, d the largest field degree, G(N) the actual cost of constructing
and validating the list, and T(M,d) the actual bit cost of one exact
restricted evaluation. Uniform renumbering and each restriction can be
written in at most M=8(N+1)^2 bits, a deliberately loose bound for a fixed
ordinary explicit CNF encoding. Standard polynomial-basis field arithmetic
and direct formula handling give the conservative conditional bound

  G(N) + (q+n) T(M,d) + O((q+n+1)(M+d+1)^3).

Any required irreducibility checking and field construction must be charged
in G or T. This expression is polynomial only if its unsupplied components
are polynomial. The verifier in this archive computes values by exhaustive
assignment enumeration; it is not such an evaluator.

Empty-variable formulas and an empty clause are handled directly. Variable
names supplied as large binary integers are renumbered by their occurrences;
their full encoding is charged in N, with no unit-cost large integers.

2. EXACT CRITERION FOR A FIXED LIST OF FINITE-FIELD JETS

This section fixes the probes in advance. A probe consists of

  K_j = F_2[u]/g_j(u),  degree(g_j)=d_j,
  a_j in K_j,
  J_j >= 1,

where g_j is explicitly supplied, monic, and irreducible. Its observation is
the entire Hasse jet

  (D^[r] P(a_j))_(0 <= r < J_j).

Hasse derivatives are defined by

  P(a+Z) = sum_r D^[r]P(a) Z^r.

They remain informative in positive characteristic, unlike repeated ordinary
derivatives. This is the stronger observation model used in the result.

Let mu_j be the minimal polynomial of a_j over F_2 and define

  Lambda(T) = lcm_j mu_j(T)^J_j,
  D = degree(Lambda).

THEOREM (EXACT ZERO-OBSERVATION CRITERION).
For every P in F_2[T], all the supplied jets are zero if and only if
Lambda divides P. Consequently, on polynomials of degree less than M,
the joint observation map has F_2-rank min(M,D). In particular, for M=2^n,
the probes distinguish every nonempty Boolean assignment set from the empty
set if and only if D >= 2^n.

Proof. The minimal polynomial mu_j is irreducible and separable over F_2.
For completeness, an irreducible nonconstant polynomial with zero derivative
would be a square over F_2 and hence reducible, so separability holds. Write
P=mu_j^s R with mu_j not dividing R. Then R(a_j) is nonzero, and the simple
root a_j of mu_j has multiplicity exactly s in P. Thus the first J_j Hasse
coefficients vanish exactly when mu_j^J_j divides P. Taking all probes gives
the least common multiple condition.

Among polynomials of degree less than M, the kernel consists of multiples
Lambda Q with degree(Q)<M-D when D<M. Its dimension is M-D in that case,
and zero otherwise. Rank-nullity gives min(M,D).

Every coefficient vector in F_2^M is the characteristic vector of an
assignment set when M=2^n. If the kernel is nonzero, it contains the support
polynomial of a nonempty set with exactly the same all-zero observations as
the empty set. Therefore allowing a nonlinear final decision function does
not repair a zero-transcript collision. This statement concerns this fixed
observation interface; it does not constrain unrestricted access to F.

Repeated or Frobenius-conjugate points need not provide independent
constraints. For example, the two roots a and a^2 of T^2+T+1 both have the
same minimal polynomial; their value observations impose total rank two,
not four. The least common multiple, rather than a sum of field degrees,
captures this redundancy exactly.

3. COMPACT CNF COUNTEREXAMPLES FOR ANY SUPPLIED PROBE LIST

When D<2^n, choose P=Lambda. This is a nonzero polynomial with binary
coefficients and a known leading term T^D. It has an explicit CNF realization
of size polynomial in n+D, which is stronger than merely producing an
arbitrary exponential truth table for this particular counterexample.

Let ell=ceil(log_2(D+1)), with ell>=1 in the nonempty probe setting. Force
x_ell,...,x_(n-1) to zero. For each code a in [0,2^ell) whose coefficient
in Lambda is zero, include the clause

  C_a = OR_(i=0)^(ell-1) L_(a,i),
  L_(a,i) = x_i if bit_i(a)=0, and NOT x_i if bit_i(a)=1.

C_a excludes exactly the low-bit assignment a. Include a tautological
clause for any otherwise absent named variable so the universe is explicit.
The satisfying assignments are exactly the exponent support of Lambda.
The binary representation of D, padded with zeros, is a known witness.
There are no auxiliary variables or hidden multiplicities.

The number of clauses is O(n+D+1). A safe encoding bound is

  O((n+(D+1)log(D+2)) log(n+2)) bits.

Minimal polynomials can be acquired by finding the first F_2-linear
dependence among 1,a_j,...,a_j^d_j in the explicit polynomial basis. Gaussian
elimination and ordinary polynomial arithmetic suffice. Constructing Lambda
and the displayed CNF costs polynomially many bit operations in

  n + sum_j d_j J_j + sum_j d_j,

with an O((1+n+sum_j d_j(J_j+1))^6) conservative bound for simple dense
implementations. If jet lengths are encoded in binary and are huge, their
numeric lengths and the output size are charged; no polynomial-in-log-J
claim is made. For polynomially bounded probe degrees, counts, and explicit
jet lengths, this is a polynomial-size known-witness counterexample family.

Concrete three-variable example. Use values at

  0 and 1 in F_2,
  a root alpha of T^2+T+1 in F_4,
  a root beta of T^3+T+1 in F_8.

Their least common multiple is

  Lambda(T) = T(T+1)(T^2+T+1)(T^3+T+1)
            = T + T^2 + T^5 + T^7.

With code x_0+2x_1+4x_2, the satisfying codes are {1,2,5,7}. One CNF is

  (x_0 OR x_1 OR x_2)
  AND (NOT x_0 OR NOT x_1 OR x_2)
  AND (x_0 OR x_1 OR NOT x_2)
  AND (x_0 OR NOT x_1 OR NOT x_2).

It has four witnesses but zero at every listed test point. The DIMACS file
fixtures/four_point_failure.cnf stores this example.

The precise failed claim is that injective assignment exponents make these
fixed field observations a universal existence detector. The claim fails
even without exponent collisions and with an easily verifiable witness.
This does not refute a formula-dependent point-selection algorithm. It also
does not prove that every polynomial list fails for every fixed CNF encoding
length bound; the constructed counterexample's own full length must fit
such a bound before that inference would be legitimate.

4. TWO-WITNESS FAMILIES THAT DEFEAT EVERY POINT OF AN ENTIRE FIELD

For integers d>=1 and h>=0, use n=d+h+1 variables. Force every variable
except x_h and x_(d+h) to zero, and impose

  (x_h OR x_(d+h)) AND (NOT x_h OR NOT x_(d+h)).

Call this CNF F_(d,h). Its two satisfying codes are 2^h and 2^(d+h), so

  P_(F_(d,h))(T) = T^(2^h) + T^(2^(d+h))
                 = (T+T^(2^d))^(2^h).

For every a in F_(2^d), a^(2^d)=a. Hence every field point is a root, and
the first 2^h Hasse coefficients at every point are zero. At order 2^h the
coefficient is exactly 1, so the stated jet cutoff is sharp for this family.

The complete CNF has O((d+h)log(d+h+2)) bits and only unit and binary
clauses. The family is easy to solve directly. Its purpose is an explicit
failure of the specified field-observation summary, not a hard SAT family.
An unsatisfiable formula has the same all-zero summary. The d=4,h=3 member
is stored in fixtures/all_F16_eight_jets_failure.cnf; its witnesses have
codes 8 and 128, on eight variables.

For one value probe to detect every support polynomial of degree below
2^n, its point must have minimal-polynomial degree at least 2^n. Thus the
ordinary explicit polynomial-basis field-word representation is already
exponential in n. This does not prohibit a different compressed algebra
representation whose operations and zero test are separately established.

5. WHY THIS IS NOT A GENERAL DERANDOMIZATION LOWER BOUND

There is an important difference between all assignment sets and all short
CNFs. Fix a binary encoding length bound N. There are fewer than 2^(N+1)
formula descriptions of length at most N, and each uses at most N occurring
variables after renumbering. Every corresponding nonzero P_F has degree
less than 2^N.

Take a field K of size 2^(N+1). A uniformly chosen point is a root of any
one such nonzero polynomial with probability less than 1/2. A list of N+2
independent points misses a particular polynomial with probability less
than 2^(-N-2). A union bound over the encodings leaves total failure
probability below 1/2. Therefore there exists a list of N+2 points hitting
every satisfiable formula of length at most N. The list and a defining
polynomial for K have O(N^2) bits.

This is an existence proof for nonuniform advice. It does not construct
the list in uniform deterministic polynomial time, and it supplies no
polynomial weighted evaluator. It is consistent with the counterexamples
above: their constructed formula size need not be at most the particular
N for which a hitting list was chosen. A uniform polynomial evaluator plus
this advice would give a nonuniform polynomial SAT search algorithm, which
is outside the user's contract. Randomly choosing points would instead
give a randomized construction, also outside the contract.

The primary isolation literature likewise distinguishes a list containing
an isolating restriction from a procedure returning a single isolated
instance. Neither the probabilistic existence of a useful restriction nor
nonuniform advice is being treated as a uniform algorithm here. The cited
isolation theorems are context; none is an uncharged subroutine of this
construction.

6. TESTING THE EXISTING WEAK-WIRE ENGINE ON THIS SMALLER OUTPUT

The previous exact gadget is retained:

  K = [[1,-1],[0,2]],  H = [[5,1],[1,1]],
  K H K^T = 4 I.

The identity is integral, so it remains true after adjoining a finite-field
lift. Given an irreducible g over F_2 of degree d, use the literal monic
0/1 lift g_tilde and the explicit free rank-d ring

  R_p = (Z/2^p Z)[u]/g_tilde(u).

Represent a lifted point a_tilde in this basis. Unary weights for x_i are
1 and a_tilde^(2^i); repeated squaring manufactures all these weights with
polynomial bit work in n,d,p. Compiling them into a bounded-degree tensor
network does not require a count or SAT oracle. If the original weighted
network has m wires and all wires receive the old gadget, there are E=2m
weak wires and the exact relation is

  Z_weak = 4^m W_F = 2^E W_F,
  W_F = sum_(x satisfies F) a_tilde^c(x) in R_p.

The desired field value is just W_F mod 2. Nevertheless, if p<=E, the
weak-network residue is identically zero for every input. At p=E+1,
coefficientwise division of the represented residue by 2^E recovers
W_F mod 2. A unique satisfying assignment and nonzero field point already
show that p=E can erase a nonzero desired result.

Thus the target has only one characteristic-two coefficient per basis
coordinate, but this particular embedding still needs E+1 binary precision
bits per coordinate before division. The requirement comes from the known
embedding scale, not from asking for the full integer witness count.

For these weak wires delta_i=1. The previous global contractor enumerates
subsets S with |S|<p. At p=E+1 every one of the 2^E subsets survives its
valuation cutoff. Over the extension ring each operation can be performed
in O(d^2(p+1)^2) elementary bit operations by schoolbook arithmetic, but
this does not turn its exponential subset enumeration into polynomial work.
Some individual inputs have additional zero factors or admit simplification;
this argument is the failure of the claimed cutoff bound, not a lower
bound for every way to compute the desired field value.

Analytically cancelling the gadget scale by K H K^T=4I returns the original
weighted network. That equality is exact and useful, but it is not a new
algorithm for contracting all such networks. No impossibility theorem for
a different scalar evaluator follows from this observation.

The accepted Astra N1118 fixed-locality, fixed-root-order phase machinery
and its input/precision accounting remain available at their recorded
scope. No implication from its subexponential bounds to a polynomial
unrestricted weighted evaluator is made. The current source inspection
did not supply that missing evaluator or a uniform hitting-list construction.

7. EXACT CHECKS AND THEIR LIMITS

verify.py uses only standard-library integer and polynomial-basis arithmetic.
All SAT-value calculations in the verifier use exhaustive enumeration on
small instances, explicitly paying an exponential reference cost.

The checks cover:

  * 126 acquired minimal polynomials, including separability checks;
  * 51 CNF annihilator constructions, with complete truth-set comparison;
  * 81 joint-jet rank checks, including conjugate-node redundancy;
  * 30 two-witness families, every field point and all stated jets, plus
    the first nonzero jet immediately beyond the cutoff;
  * 150 witness-extraction trials: 65 nonzero values yielded verified
    witnesses in n+1 reference calls; 85 zero values made no UNSAT claim;
  * 20 coefficientwise weak-wire precision-recovery checks over lifted
    finite fields, including nonzero unique-witness monomials.

All passed. The universal assertions above rest on their algebraic proofs,
not on the finite tests. The lifted-ring tests check the new recovery issue;
the predecessor's general network-gadget theorem is retained without
claiming it was reproved by these smaller tests.

8. REMAINING CONTRACT

There is no complete construction or unrestricted negative proof in this
archive. The chosen candidate needs an actual uniform test-selection method
and an actual polynomial-bit evaluation method, or a different SAT method
must avoid them. Their existence is not assumed. The obstructions do not
exclude such alternatives. Neither P=NP nor P!=NP is asserted.

The preserved files contain explicit failures for later coordinator use.
They have not been sent to any counterpart or used to initiate an exchange.

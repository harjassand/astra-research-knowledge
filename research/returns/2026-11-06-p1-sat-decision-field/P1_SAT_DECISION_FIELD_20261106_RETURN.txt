## 1. A construction aimed only at existence and witness recovery

Renumber the occurring variables of \(F\) as \(x_0,\ldots,x_{n-1}\), charging their original binary encodings to the input length. Define

\[
c(x)=\sum_{i=0}^{n-1}2^i x_i
\]

and the polynomial

\[
P_F(T)=\sum_{x\models F}T^{c(x)}
\quad\text{in }\mathbb F_2[T].
\]

Every assignment has a distinct exponent. Consequently, no coefficients cancel in the definition, and

\[
F\text{ is satisfiable}\iff P_F\ne 0.
\]

The weights \(2^i\) have short binary descriptions. The polynomial can nevertheless have degree \(2^n-1\). An algorithm must account separately for those two facts.

The candidate was to evaluate \(P_F\) at selected points in finite fields of characteristic two. A nonzero value certifies satisfiability. It also suffices for witness recovery.

### A nonzero value supports a complete search

Suppose an exact evaluator has returned

\[
P_F(a)\ne0.
\]

Keep the original variable indices and exponents throughout the search. For any current restriction \(G\),

\[
P_G(a)
=
P_{G\land(x_i=0)}(a)
+
P_{G\land(x_i=1)}(a).
\]

Evaluate the zero branch.

- If its value is nonzero, retain that branch.
- If its value is zero, retain the one branch, whose value equals the nonzero parent value.

After \(n\) steps, the retained assignment satisfies \(F\): an unsatisfying leaf would have value zero. The assignment can then be checked directly against the original input.

Thus, **once one nonzero value is available, witness recovery needs at most one further evaluation per variable**. It needs neither an exact integer count nor conditional probabilities. Keeping the original exponents also avoids dividing by \(a\), so the argument remains valid when the selected point is zero.

For this candidate, a complete algorithm would therefore require two supplied components:

1. A uniform deterministic procedure selecting polynomially many tests such that every satisfiable input has a nonzero result on at least one test.

## 2. An exact criterion for when fixed field tests lose existence information

I examined a stronger interface than point values alone: a fixed list of field values together with Hasse derivatives.

A probe specifies a finite field \(K_j\), a point \(a_j\in K_j\), and a positive integer \(J_j\). It returns

\[
D^{[r]}P(a_j),\qquad 0\le r<J_j,
\]

where the Hasse derivatives are defined by

\[
P(a+Z)=\sum_{r\ge0}D^{[r]}P(a)Z^r.
\]

These derivatives preserve the appropriate coefficient information in characteristic two.

Let \(\mu_j(T)\) be the minimal polynomial of \(a_j\) over \(\mathbb F_2\), and put

\[
\Lambda(T)=\operatorname{lcm}_j\mu_j(T)^{J_j},
\qquad
D=\deg\Lambda.
\]

### Exact fixed-test theorem

For every \(P\in\mathbb F_2[T]\),

\[
\boxed{
\text{Every specified observation is zero}
\iff
\Lambda(T)\mid P(T).
}
\]

Therefore, on polynomials of degree below \(M\), the joint observation map has \(\mathbb F_2\)-rank

\[
\min(M,D).
\]

Taking \(M=2^n\), the fixed probes distinguish **every nonempty assignment set** from the empty set exactly when

\[
\boxed{D\ge 2^n.}
\]

**Proof.** The minimal polynomial \(\mu_j\) is separable. If

\[
P=\mu_j^s R,\qquad \mu_j\nmid R,
\]

then \(R(a_j)\ne0\), and \(a_j\) has multiplicity exactly \(s\) as a root of \(P\). The first \(J_j\) Hasse coefficients vanish precisely when \(\mu_j^{J_j}\mid P\). Combining the probes gives the least common multiple condition.

Among polynomials of degree below \(M\), the kernel consists of multiples \(\Lambda Q\). Its dimension is \(M-D\) when \(D<M\), and zero otherwise. This proves the rank formula.

Every binary coefficient vector of length \(2^n\) represents an assignment set. Hence a nonzero kernel element represents a nonempty set with the same observations as the empty set. Even a nonlinear final decision rule cannot distinguish those two identical observation records.

The least common multiple matters. Distinct field points can impose redundant constraints. For example, the two roots of \(T^2+T+1\) have the same minimal polynomial; their value observations impose total binary rank two, not four.

This theorem concerns the specified fixed observations. It does not restrict an algorithm’s other access to the formula.

## 3. The failed tests have explicit satisfiable CNF counterexamples

The kernel argument can be made into a concrete CNF family.

Assume \(D<2^n\), and choose

\[
P(T)=\Lambda(T).
\]

Let

\[
\ell=\left\lceil\log_2(D+1)\right\rceil.
\]

Force the variables with indices at least \(\ell\) to zero. For every \(\ell\)-bit code \(a\) whose coefficient in \(\Lambda\) is zero, add the clause excluding exactly that assignment:

\[
C_a=\bigvee_{i=0}^{\ell-1}
\begin{cases}
x_i,&a_i=0,\\
\neg x_i,&a_i=1.
\end{cases}
\]

The resulting CNF has exactly the exponent support of \(\Lambda\) as its satisfying assignments. Because \(\Lambda\) is monic, the binary encoding of \(D\) is a known satisfying assignment.

There are no auxiliary variables or multiplicities. The complete CNF encoding has size

\[
O\!\left(
\bigl(n+(D+1)\log(D+2)\bigr)\log(n+2)
\right).
\]

Acquiring the minimal polynomials and constructing this CNF takes polynomial bit work in the explicit field descriptions and the total supplied jet lengths. Large jet lengths are charged by their numeric output size; they are not treated as inexpensive merely because their bounds have short binary encodings.

## 4. Why these failures do not exclude short test lists for short formulas

The distinction between arbitrary assignment sets and short CNF descriptions is essential.

Fix an input-length bound \(N\). There are fewer than \(2^{N+1}\) binary formula descriptions of length at most \(N\). Each corresponding nonzero \(P_F\) has degree below \(2^N\).

Choose a field of size \(2^{N+1}\). For any one such nonzero polynomial, a uniformly random point is a root with probability below \(1/2\). A list of \(N+2\) independent points misses that polynomial with probability below

\[
2^{-N-2}.
\]

A union bound over all the formula descriptions gives total failure probability below \(1/2\). Consequently:

> There exists a list of \(N+2\) field points that detects every satisfiable CNF of encoding length at most \(N\).

The list and a field definition have \(O(N^2)\) bits.

This is **nonuniform existence**, with no uniform polynomial-time construction supplied. It also supplies no polynomial evaluator. Using the list as advice would violate the original contract unless its production were accounted for.

This observation prevents an overstatement of the counterexample theorem. A CNF constructed to defeat a supplied list need not fit the particular length bound for which that list was selected. Its own complete encoding length must be included before drawing a conclusion about bounded-length inputs.

The primary isolation literature likewise distinguishes producing a list containing an isolating restriction from returning a single isolated instance, and it treats nonuniform advice separately.

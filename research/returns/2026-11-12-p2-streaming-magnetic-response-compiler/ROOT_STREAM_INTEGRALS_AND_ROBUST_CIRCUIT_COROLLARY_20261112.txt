Streaming integral capture and a robust circuit consequence of magnetic registers

Scope. The complete initial-field-data return supplies simultaneous
Fourier routing, prescribed-time two-frequency memory, actual ternary
assignments and the final writer at their uniform actual-input contracts.
It does not supply these services under order-one persistent magnetic
input. The following derives a new unforced sampling/refresh interface,
isolates that missing upgrade, and records a separate circuit consequence.

1. An actual short unforced sampling and memory step

Let g1,...,gq be known, pairwise L2-orthogonal real solenoidal single-mode
Fourier fields of mean zero, frequencies<=N and squared L2 norms in[1/2,2].
Let the magnetic equation receive G(t,x)=sum theta_j(t)g_j(x), with
arbitrary unknown measurable |theta_j|<=1. These signals are not chosen
controls, not observed coefficient values and not small disturbances.
Their fixed-order spatial norms are bounded by C_m sqrt(q)N^m.

Start a short unforced interval with u=0 and
 B=H+e3 sum a_j[sin(2pi n_j y)+sin(4pi n_j y)],
where all n_j>N and the two code banks are disjoint. Take a fixed large
Sobolev order m and a polynomial envelope P for this state, the signal
spatial norms, N, the code band, mu^-1 and coefficient bounds. Local
strong estimates give a lifespan at least an inverse fixed polynomial
and uniform bounds on u,B and their time integrals on that interval.
Time derivatives of theta are NOT used.

Let Y_j(d)=<B(d),g_j>/||g_j||_2^2. Initially this coefficient is zero.
The weak induction identity and the integral equations give
 Y_j(d)=integral_0^d theta_j(t)dt+O(P*d^2).
Indeed, the initial velocity vanishes, all initial magnetic nonconstant
modes lie outside the input band, diffusion has zero initial projection
onto g_j, and input forcing has its exactly known spatial projection.
The remaining diffusion projection involves the O(t) newly generated
low coefficient; induction involves u(t)=O(P*t). Integration gives the
stated d^2 remainder, without differentiating the input history.

For a code frequency n let lambda_n=(2pi n)^2 and R_d=integral_hold rho.
The high projection has no direct input forcing. The same integral
expansion gives
 b_n(d)=a_n-lambda_n R_d*a_n+O(P*d^2),
 b_(2n)(d)=a_n-4lambda_n R_d*a_n+O(P*d^2).
Consequently (4b_n-b_(2n))/3=a_n+O(P*d^2), simultaneously with input
capture. The nonlinear terms generated by the input are included in the
second-order remainder; the state is not assumed to remain in the exact
parallel sector after G begins.

The variational equation with respect to the finite initial code vector
has the same first-order cancellation. On a fixed code ball the combined
ideal hold/read map has derivative I+O(P*d^2), apart from any intentionally
appended input coordinates. This is a local finite-dimensional statement
with a fixed-degree Sobolev envelope, not an arbitrary full-space operator
bound or a completed controlled routing theorem.

2. Integrals should be accumulated without dividing by the hold time

For known temporal weights w_l that are constant on the hold, use the
logical update
 a_l_new=(4b_(n_l)-b_(2n_l))/3 +w_l*Y_(j(l))(d).
It adds the desired actual input integral directly. No d^-1 normalization
or unknown coefficient division is needed. The code state and input
integral have total defect O(P*d^2). Derivative loss on historical code
errors is1+O(P*d^2), not the absolute coefficient sum5/3 of recombination.

Over J holds with d<=1/J and bounded accumulated data, the total defect
is O(P/J) with a bounded product of derivative losses. Fresh physical
errors may be assigned O(epsilon/J). All intended integral registers stay
bounded if integral |w_l|<=1. Step-weight breakpoints can be included in
the known schedule. If the total absolute weight-list envelope is Kt,
discarding intervals of total duration sigma costs at most Kt*sigma in
the data vector, hence CKD Kt*sigma in a coefficient-K degree-D target.
Very short binary-described weight pieces can therefore be omitted using
a numerical error threshold; no inverse of their smallest length is a
free physical charge. This remains an approximation to the ORIGINAL full
integral, not a redefinition of the data interval.

3. The remaining controlled input interface is real

The live signal does not pause while the physical router, eraser,
arithmetic or final writer runs. The earned services tolerate a small
L-infinity L2 disturbance eta. They cannot automatically be invoked with
an order-one persistent G by calling it noise. Shortening an active gate
is insufficient unless its input-to-endpoint gain is controlled: a bound
G_gate(h^-1)*h may grow as h decreases. This is a genuine potential
parameter circularity.

A full streaming compiler must either obtain appropriate forcing-to-
endpoint estimates for the actual finite-band signal space, retain its
contribution in a causal encoding through active gates, or use a different
mechanism. Small total active duration pays missed INTEGRALS only after
the effect of the live forcing on stored data and output is also paid.
No magnetic input shutter, signal sample, oracle or extra actuator has
been constructed here.

The initial-field router can capture B0 during a short first interval
with additional drift O(q N^m*s); the uniform input bound pays the missed
temporal integral near zero. A short final-write interval has the analogous
bounded missing-tail budget. These observations do not solve3. Rough
unmodelled disturbances remain a SEPARATE small eta budget.

4. A complete robust Boolean-circuit consequence at the earned scope

There is already a consequence beyond expansion into sparse monomials.
Fix a known mean carrier H1=1 and input visibility gamma>0. Promise each
raw Fourier input divided by gamma lies within a fixed small r0 of+1 or
-1. Include gamma^-1 in the numerical resources. This scaling is needed:
q near-unit Fourier features normalized by the joint H1 bound would give
an empty promise for large q. For example gamma~1/(qF) permits q distinct
bounded-frequency encoded bits with a paid H1 envelope.

Route odd bit registers b=(H1+r)/2, near0 or1, with a carrier c copied
fresh from the actual mean H1. Odd cubic operations implement
 AND(b1,b2)=c*b1*b2, NOT(b)=c-b,
and the restoring polynomial
 R(b)=3c*b^2-2b^3.
On c=1, R(0)=0,R(1)=1 and its derivative vanishes at both bit values.
On their r0-neighborhoods, |R(b)-bit|<=C|b-bit|^2 and |R'(b)|<=C r0.
Choose r0 so that applying R after a fixed Boolean gate contracts the
local error by at least1/2. Fresh carrier and gate errors have polynomial
absolute budgets. Refresh all live bits once per gate layer, if needed;
this costs at most O(G^2) physical ternary/router services for a G-gate
circuit, rather than an exponential-depth error budget.

All code states remain in a fixed bounded coefficient cube and the
canonical band has polynomial size. The earned router's actual-input
absolute guarantee, two-frequency memory and prescribed-duration services
then compile the circuit with costs polynomial in G,q,M,gamma^-1,mu^-1,
tau^-1,epsilon^-1 and the supplied coefficient bounds. The final writer
can use a known carrier times an odd bit for an even velocity readout,
or retain odd magnetic bit codes. Input acquisition, storage, all weak
realizations and rough disturbance budgets remain those of the earned
physical services. No dense expansion of a degree2^G polynomial is used.

This is a conditional corollary of the accepted uniform physical gate
contracts plus the displayed robust arithmetic. It is an externally
programmed finite circuit in the dissipative fluid, not a fixed autonomous
Euler universal machine, a complexity-class separation or an advantage
over ordinary digital computation. Persistent unknown input is still3.

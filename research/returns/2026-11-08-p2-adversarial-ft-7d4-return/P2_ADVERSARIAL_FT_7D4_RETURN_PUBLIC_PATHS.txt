2. The central algorithm: repairing a noisy, initially arbitrary syndrome

The preparation problem differs from ordinary recovery. When preparing a code state by measuring checks on a product state, the true syndrome can be an arbitrary valid syndrome. It need not be the syndrome of a small data error.

The operation needed is therefore the following.

Let

$$H:\mathbb F_2^n\longrightarrow\mathbb F_2^r$$

be one CSS syndrome map. Given

$$y=s+f,\qquad s\in\operatorname{im}H,$$

where only the measurement error $f$ is small, construct a valid syndrome $\widehat s$ such that

$$\widehat s+s=Hg$$

for some small data error $g$. The algorithm must produce $\widehat s$; it need not identify the unknown $f$ or the particular small lift $g$.

The achieved contract is

$$|f|\le\chi n
\quad\Longrightarrow\quad
\widehat s\in\operatorname{im}H,\qquad
\widehat s+s=Hg,\qquad
|g|\le K|f|,
\tag{1}$$

with fixed computable $\chi>0$ and $K<\infty$.

This is a promised nearby-valid-syndrome problem. It does not claim to solve unrestricted nearest-syndrome optimization.

4.1 Fixed preprocessing

All local code parameters, fields, and arithmetic choices are fixed before the requested logical size is known.

For example, real-root and irreducibility tests decide the field conditions; local algebra tests decide the quaternion conditions. -

-

The important algorithmic point in step 3 is that orbit testing terminates on both answers. The candidates therefore lie in a finite, effectively bounded lattice region, which can be enumerated exactly.

Cocompactness guarantees that quotient traversal eventually closes. A fixed initial congruence level ensures freeness; finite local-ball tests then find a level with the required cubical incidences and complete upward stars.

5. Encoded Bell preparation and a repeatable recovery cycle

5.1 Bell preparation

There are two implementations once complete logical zero/plus preparation is available. One prepares those two blocks and applies transversal CNOT. A direct implementation makes the syndrome-lift issue especially clear.

Prepare $n$ physical Bell pairs. Measure all code checks on the first half. An ideal syndrome branch is

$$|\Phi_s\rangle=(R_s\otimes\overline{R_s})|\Phi_Q\rangle,$$

where $R_s$ is any Pauli with syndrome $s$, and

$$|\Phi_Q\rangle
=
2^{-k/2}\sum_x |x_L\rangle|\overline{x_L}\rangle .$$

Clean the observed syndrome to $\widehat s$. Compute any canonical Pauli lift $R_{\widehat s}$ by linear algebra, and apply its inverse to the first half and its conjugate inverse to the second.

The cleaner guarantees a small Pauli $Q_f$ with syndrome $s+\widehat s$. Thus

$$R_{\widehat s}^{\dagger}R_s=Q_fL$$

for a code normalizer $L$. But

$$(L\otimes\overline L)|\Phi_Q\rangle=|\Phi_Q\rangle.$$

Therefore the corrected resource is

$$(Q_f\otimes\overline{Q_f})|\Phi_Q\rangle,
\tag{11}$$

apart from the additional bounded-weight physical faults.

Arbitrary logical ambiguity in the chosen syndrome lift cancels between the two halves. No branch is rejected, and the controller never solves a minimum-weight problem.

5.2 Whole-block teleportation removes incoming errors

Let $A$ hold the unknown encoded input and prepare the Bell resource on $B,C$. Apply transversal CNOT from $A$ to $B$, measure all physical qubits of $A$ in $X$, and measure all physical qubits of $B$ in $Z$.

The classical records can be decoded using the actual clean-syndrome decoder. For example, an ideal destructive $Z$-measurement record $y_0$ satisfies

$$H_Zy_0=0.$$

For a corrupted record $y=y_0+b$, its syndrome is computed exactly by noiseless classical arithmetic:

$$H_Zy=H_Zb.$$

Executing the clean decoder produces $\widehat b$ with

$$b+\widehat b\in\operatorname{rowspan}H_X.$$

That ambiguity does not change logical $Z$-outcomes. The dual calculation recovers logical $X$-outcomes. Their logical Pauli correction is applied to $C$.

This uses exact syndromes of already classical strings. It does not assume exact physical syndrome measurements.

Errors on the incoming block and the measured Bell half are removed through decoding the measurement records. The remaining physical errors are those on the surviving Bell half and those introduced while it idles or receives the final correction. Thus the output error bound is independent of the previous residual, provided the decoder’s input promise holds.

Blocks can be returned to a fixed designated output location by a paid transversal swap. No computation is hidden in a final relabeling or decoder.

For

$$|\Phi_U\rangle=(I\otimes U)|\Phi_Q\rangle,$$

a paired unknown normalizer acts as

$$(L\otimes\overline L)|\Phi_U\rangle
=
(I\otimes\overline L\,U\,L^{\mathsf T})|\Phi_Q\rangle.
\tag{14}$$

$$U=T=\operatorname{diag}(1,e^{i\pi/4}),\qquad L=X.$$

$$XTX=e^{i\pi/4}T^\dagger.$$

The normalized Choi states of $T$ and $T^\dagger$ have overlap magnitude $1/\sqrt2$, hence unhalved trace distance $\sqrt2$. Ignoring this logical ambiguity would therefore produce a constant error, not an error that disappears with increasing code size.

This refutes the proposed automatic extension of the identity-Bell argument. It is not an impossibility theorem for protected gate-resource preparation by another method.

1. Generic preparation and recovery lemma

Consider one CSS sector with syndrome map

$$H:\mathbb F_2^n\longrightarrow\mathbb F_2^r.$$

Assume a deterministic algorithm receives $s=s_0+f$, where $s_0\in\operatorname{im}H$, and, whenever $|f|\le\zeta n$, computes a vector $\widehat f$ such that

$$t=s+\widehat f\in\operatorname{im}H,$$

and guarantees the existence of $g$ satisfying

$$Hg=f+\widehat f,\qquad |g|\le K|f|.$$

The algorithm need not find $g$.

Known-state preparation

For preparation of the all-logical-zero state, start from physical $|0\rangle^{\otimes n}$ and measure the $X$-checks. An ideal measurement outcome $s_0$ yields

$$Z^{z_0}|0_L\rangle,\qquad Hz_0=s_0.$$

Clean the observed syndrome $s=s_0+f$, solve the ordinary linear system

$$Ha=t,$$

and apply $Z^a$. No minimum-weight requirement is imposed on $a$. Since

$$H(a+z_0+g)=0,$$

the Pauli $Z^{a+z_0+g}$ is a product of $Z$-stabilizers and logical $Z$'s. All of these fix $|0_L\rangle$. Consequently,

$$Z^a Z^{z_0}|0_L\rangle=Z^g|0_L\rangle$$

up to an irrelevant phase.

The dual statement prepares $|+_L\rangle$.

Noisy-syndrome recovery

Suppose the actual data error is $e$. The observed syndrome is

$$s=He+f.$$

The same cleaner produces

$$t=H(e+g),\qquad |g|\le K|f|.$$

If the clean-syndrome decoder corrects every error of weight at most $\tau n$, and

$$|e|+K|f|\le\tau n,$$

run that decoder on $t$. Its correction $a$ satisfies

$$e+g+a\in\mathsf S,$$

where $\mathsf S$ denotes the relevant stabilizer subgroup. Thus the actual residual is equivalent to $g$, with weight at most $K|f|$.

This is a useful distinction: recovery never needs to identify the hypothetical small lift $g$.

2. Encoded Bell preparation without an exact noisy-syndrome oracle

Define the code Bell state by

$$|\Phi_Q\rangle
=
2^{-k/2}\sum_{x\in\{0,1\}^k}
|x_L\rangle_A|\overline{x_L}\rangle_B.$$

For a real CSS encoding the conjugate code is the same code.

Physical procedure

- Initialize $n$ physical Bell pairs between $A$ and $B$.

- Measure every $X$- and $Z$-check on only the $A$ half, using bounded-weight extraction circuits.

- Clean both observed syndrome records.

- Compute any canonical Pauli $R_{\widehat s}$ with the cleaned joint syndrome $\widehat s$.

- Apply $R_{\widehat s}^{\dagger}$ to $A$ and its complex conjugate to $B$.

Step 5 consists of parallel single-qubit Pauli operations. Computing a possibly dense canonical lift is harmless: it is a polynomial classical linear-algebra operation followed by one quantum layer.

No measurement branch is rejected or postselected.

Why arbitrary logical lifts cancel

Let $P_s$ be the joint code-syndrome projector. In the ideal extraction circuit, a valid syndrome $s$ produces

$$|\Phi_s\rangle
=
\frac{(P_s\otimes I)|\Phi_{\rm phys}\rangle}
{\|(P_s\otimes I)|\Phi_{\rm phys}\rangle\|}
=
(R_s\otimes\overline{R_s})|\Phi_Q\rangle$$

for any Pauli $R_s$ with syndrome $s$.

Suppose the cleaner receives $s+f$, returns $\widehat s$, and its guarantee supplies a small Pauli $Q$ with syndrome $s+\widehat s$. Then

$$R_{\widehat s}^{\dagger}R_s=QL$$

for some code normalizer $L$. Since $L$ preserves the codespace,

$$(L\otimes\overline L)|\Phi_Q\rangle=|\Phi_Q\rangle.$$

Consequently the corrected state is exactly

$$(Q\otimes\overline Q)|\Phi_Q\rangle$$

up to an irrelevant phase.

It is unnecessary to know which logical normalizer occurs. The two matching halves cancel it. This is the essential difference from correcting an arbitrary unknown single-block state using an arbitrary syndrome lift.

3. Physical-fault accounting for preparation

Let the extraction/preparation prefix before the final Pauli correction have fixed quantum depth $D_p$. It uses only bounded-arity Clifford gates, preparations, measurements, and idles.

Use the conservative propagation constant

$$K_p=D_p2^{D_p}$$

for two-qubit gates. Let

$$f=\lfloor \rho N_{\rm total}\rfloor$$

be the adversary’s permitted support after each physical quantum layer.

For a Pauli fault path, push the faults through the fixed-depth Clifford prefix. At its end there are:

- Pauli errors $E_A,E_B$ on the two blocks;

- flips $f_X,f_Z$ in the two classical syndrome records;

with the conservative bound

$$|E_A|+|E_B|+|f_X|+|f_Z|\le K_pf.$$

The cleaners therefore apply whenever

$$K_pf\le \chi n.$$

After the matching Pauli corrections, the output errors have total weight at most

$$|E_A|+|E_B|
+
2L\bigl(|f_X|+|f_Z|\bigr).$$

Include the attack after the correction layer. The prepared state lies in the coherent error span of the ideal encoded Bell state with total error weight at most

$$\boxed{
w_B\le K_B f,\qquad
K_B=(1+2L)K_p+1.
}$$

This is a noisy encoded Bell resource with a bounded physical error span, not an assertion that the final physical state is exactly the pure Bell state despite a last-layer attack. A valid terminal recovery decodes it to the exact logical Bell state.

Arbitrary CPTP faults and the persistent environment

The argument is not a stochastic Pauli substitution.

Expand each supported fault operator in Paulis while retaining its environment operators as coefficients. Analyze the ket and bra Pauli paths separately. For a fixed observed classical record, the cleaner chooses the same $\widehat s$ on both sides. Each side reduces to a bounded-weight Pauli deviation of the same ideal code Bell state.

Linearity therefore gives the coherent error-span conclusion for general CPTP faults. The environment may persist and adapt. It may also be entangled with another data block or an external reference. Corruption of that separate data block is charged separately; no independence between resource faults and data faults is assumed.

4. Whole-block teleportation performs genuine recovery

Let $A$ hold an encoded unknown state, possibly entangled with an arbitrary reference, with incoming physical error weight at most $w_0$. Internally prepare a Bell resource on $B,C$ as above.

Then:

- Apply transversal CNOT from $A$ to $B$.

- Measure every qubit of $A$ in the $X$ basis.

- Measure every qubit of $B$ in the $Z$ basis.

- Decode the two measured classical strings using the actual clean-syndrome decoder.

- Extract the $k$ logical Bell outcomes.

- Apply their logical Pauli correction to $C$.

All quantum operations have constant depth. The Pauli representatives can have weight $\Theta(n)$; they are products of simultaneous single-qubit Paulis.

Why classical outcome recovery is justified

An ideal destructive $Z$-measurement string $y_Z^0$ satisfies

$$H_Zy_Z^0=0.$$

For observed $y_Z=y_Z^0+b_Z$, compute its syndrome exactly and noiselessly:

$$H_Zy_Z=H_Zb_Z.$$

Run the clean $X$-error decoder on that syndrome. If $|b_Z|\le\alpha n$, it returns $\widehat b_Z$ such that

$$b_Z+\widehat b_Z\in\operatorname{rowspan}H_X.$$

Thus the corrected record has the correct logical $Z$-outcomes:

$$z_i=\bar z_i\cdot(y_Z+\widehat b_Z).$$

The ambiguity is an $X$-stabilizer word, which commutes with every logical $\bar Z_i$.

Similarly, for the $X$-measurement record,

$$H_Xy_X=H_Xb_X,$$

and the clean $Z$-error decoder returns a correction whose remaining ambiguity is a $Z$-stabilizer. Hence

$$x_i=\bar x_i\cdot(y_X+\widehat b_X)$$

are the correct logical $X$-outcomes.

These are exact classical syndromes of already measured strings. There is no clean physical-syndrome oracle here.

Transversal CNOT on two identical CSS blocks acts as pairwise logical CNOT in the chosen paired logical basis. Therefore these two destructive measurements perform all $k$ logical Bell measurements. Applying the corresponding logical Pauli to $C$ gives the original logical unknown input.

Incoming errors are removed

All errors on $A$ and on the measured resource half $B$ become flips or phases of the Bell-measurement records. The clean classical decoding removes their effect on the logical outcomes. They do not propagate as new physical data errors to $C$.

Only:

- resource errors already on $C$;

- faults on $C$ while it idles during teleportation;

- the final correction-layer fault;

remain as physical output errors.

Let the teleportation use $q$ quantum layers, including the final correction. For a direct implementation one may take $q=4$. Then

$$\boxed{
w_{\rm out}\le (K_B+q)f=:K_Rf,
}$$

independently of the incoming error $w_0$, provided the measured-record error bounds remain inside the clean decoder’s promise.

This is a genuine mending/recovery operation.

5. An explicit sufficient constant threshold

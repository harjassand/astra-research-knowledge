5. A prescribed endpoint time creates a NEW memory operation

For mean-only responses the previous compiler fills the initial unused
time with an eraser; H is conserved. Nonconstant input probes cannot be
stored by that argument. Nor may an unknown attenuated coefficient be
read and externally corrected. A passive code held for timeT has a
factor exp(-rho lambda_n T), not a constant-time identity.

There is a concrete counter-diffusion opening while velocity is still
disposable. Put a finite code bank in the exact parallel sector
 u=e2 v(z), B=H+e2 b(z),
and start each hold with velocity small. For a code frequency n, the exact
coupled2-by2 propagator gives, with lambda_n=(2pi n)^2,
 b_n(d)=r_n-lambda_n R_d r_n+O(Pd^2)|r_n|,
 R_d=int_0^d rho(t_start+s)ds.
P is a computable fixed polynomial in the code band,M and the supplied
coefficient bounds. Mean coupling and viscosity enter the second-order
remainder, not an unobserved first-order velocity assumption.

The earned internal resistivity operation, on physically prepared coded
copies, supplies rho_probe b_n(d), with |rho_probe-R_d/d| bounded by
Lambda times the elapsed local preparation/probe/hold lengths, plus its
assigned approximation error. Apply the KNOWN code-diagonal linear map

Its ideal composition with the hold has endpoint error<=P(d^2+ds)|r_n|
for a probe/preparation delay<=s, with corresponding logical derivative
norm<=1+P(d^2+ds). No coefficient value or register is numerically evaluated.
Both factors live in the same actual magnetic field.

For J holds filling timeT, taking d,s<=delta/[P(1+T)] bounds the product
of these endpoint factors by exp(Cdelta). Fresh physical errors are
assigned O(delta/J). The actual-state smoothing/identity-restore method
retains historical errors as real code coefficients; it does not delete
them by a proof projection. All physical resetting, probing, copying,
routing and off-code residuals must be paid by their earned services.
The above ideal composition is not by itself a completed memory compiler.

A noncircular clock design compiles uniform overhead caps first, chooses
J from their known envelopes and the prescribed storage interval, then
sets the exact rational holds from the remaining clock. Template call
times can be fixed from coefficient upper bounds and padded by zero force;
they must not secretly depend on the actual data or rho. Code envelopes

polynomial iterated as an exponent J times.

This is encoded endpoint memory with potentially large intermediate
carriers/fields and disposable velocity. It is NOT simultaneous uniform-

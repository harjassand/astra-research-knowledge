Retained development failure, 5 November 2026.

The first correlated scalar audit used P[-1,i] to address the target row
of an mpmath matrix. Unlike a NumPy array, this did not select the last
row: it returned zero entries, yielding a zero scalar and a division by
zero. The product-family run and all its preceding identity checks had
completed. The matrix row was changed to the explicit nonnegative index
P[size-1,i]. The new correlated check was rerun alone and appended to the
existing deterministic family record; the final main script reproduces
both parts. This was an execution indexing error, not a failed spectral
identity or a changed mathematical premise.

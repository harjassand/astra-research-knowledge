# Independent fixed-law route: completed boundary

The completed result and its exact scope are in `FOUNDATIONAL_CONTRACTION_BOUNDARY.md`. It gives a finite rational compiler from two-counter programs to globally certified 1/2-contractions of R^4, proving undecidability of finite arrival at the known unique equilibrium and crossing a fixed homogeneous halfspace. It also gives a polynomial-bit finite-prefix algorithm for positive absolute margins, a rapidly computable Lipschitz event value whose exact zero test is undecidable, and a scoped finite ReLU corollary.

The compiler and exact arithmetic diagnostic were executed successfully. `execution_record.json` preserves the complete record. No original package was modified. No external publication was made.

## Selection and priority judgment

This is a foundational companion, not the selected main practical mission endpoint. General continuous piecewise-affine reachability undecidability is established prior machinery, and homogeneous scaling may already imply the contraction consequence. The package makes no historical originality claim. Its useful incremental role is an explicit mathematical boundary for the accumulated fixed-law certificate, with a complete global extension, finite compiler, and real precision bill.

## Alternatives and failed inferences retained

- A finite adaptive-experiment game over a Lipschitz-consistent version space was considered. Without additional structure it largely re-expresses established set-membership identification/dual control, and it does not avoid physical dimension, global prior, or horizon costs. It was not selected as a new scientific operation.
- Generic piecewise-affine undecidability was insufficient: its maps can be discontinuous, and local or radial decay alone does not establish pairwise global contraction. The construction explicitly uses continuous triangulation, a convex cone, and nonexpansive projection.
- Scaling an arbitrary affine simulator does not preserve its iterates. Positive homogeneity is the indispensable interface: `(cF)^n=c^n F^n` only under that property.
- An oracle division by a shrinking scale would hide a physical precision demand. The implementation instead uses homogeneous inequalities and scaled barycentric interpolation. Exact comparisons and shrinking signal amplitude still carry unbounded precision costs.
- Exact zero arrival is not the same problem as entering a fixed positive-radius target away from the equilibrium. The latter has an explicit finite horizon.
- A finite numerical trace cannot prove generic nonhalting or undecidability. The nonhalting example has its own closed-form orbit, and the general result is a reduction from counter-machine halting.
- Fixed-noise physical universality, a fixed-width four-neuron implementation, smooth/analytic-law extensions, and undecidability for the special finite-state Bellman operators are not claimed.
- A complete geometric convergence modulus for an event value does not decide whether that value is exactly zero. The constructed value makes this failure explicit while preserving efficient additive approximation.

VERDICT AND SCOPE

The latest strengthening is received and appears correct. Bounded ordinary
odds distortion is unnecessary. Known full-support rational factor weights,
uniform efficient sampling under arbitrary coordinate pinnings, and a fixed
constant c with q_e^- >= (q_e^+)^c suffice for the static construction. The
heavy-prefix partition-function estimator really removes inverse local
rarity: every estimated transition in its self-reduction has probability
bounded below by an absolute constant. This is standard sampling/counting
self-reduction, not a new primitive. The substantial composite endpoint is
static relative disconnection estimation and conditional failure sampling
for a correlated distribution, with no inverse failure probability.

I found no fatal obstruction in the stipulated model. The proof below
supplies finite arithmetic, explicit count/tail bounds, approximate-union
stability, and a concrete strong-interaction family. Two composition details
must be stated explicitly: replace independent refresh by Gibbs heat bath
when constructing reversible dynamics; and replace the old product-law
bit floor by the rational-factor bit floor. Cached sampler setup failure
must also be charged correctly when claiming an unconditional TV bound.

My independent opening, preserved separately in INDEPENDENT_OPENING.txt,
was fixed-parameter long-time certification through auxiliary functions.
It did not earn a new capability beyond known auxiliary-function duality
and robust polynomial analysis, and should not displace this endpoint.

1. EXACT PREMISES AND STATIC CONSEQUENCE

Let G=(V,E) be a connected undirected graph, v=|V|>=2, m=|E|. A state
x in {0,1}^m marks failed edges by ones. Let B be graph disconnection.
Let W(x)>0 be an explicitly supplied product of positive rational factors,
pi(x)=W(x)/Z. Evaluation of W and of a local conditional must have counted
polynomial bit cost. For the completely explicit heat-bath realization,
bounded factor arity and incidence permit enumeration of all conditional
extrema and all influence coefficients. More generally these certified
bounds may be inputs, but an unpriced certification oracle must not appear.

For each e suppose certified rational 0<q_e^-<=q_e^+<1 satisfy
  q_e^- <= pi(x_e=1 | x_-e=z) <= q_e^+ for every z,
  q_e^- >= (q_e^+)^c,
where c>=1 is a fixed constant. If c is not an integer, this last inequality
is a mathematical input promise unless a finite verification method is
also given. One can use a fixed integer upper bound on c throughout.

Suppose for every coordinate pinning A and every tau>0 an actual algorithm
S(A,tau) produces a sample within tau TV of pi(.|A), uniformly in A, at
polynomial cost in input length, tau^-1 and any declared mixing parameter.
Fresh calls use fresh random bits. For Dobrushin heat bath the cost depends
on log(1/tau), and a construction is supplied in section 8 below.

Then, at fixed c, there is a finite-work FPRAS for p=pi(B) and an approximate
sampler for pi(.|B). Estimation at relative tolerance epsilon and failure
delta has polynomial work in input length, epsilon^-1, log(1/delta), and
the numerical mixing parameter. Sampling at TV tolerance rho has polynomial
work in input length and rho^-1 (in particular logarithmic accuracies inside
the pinned heat-bath sampler). No p^-1, q_min^-1, Z, or pi_min^-1 factor is
required. Fixed c matters: graph-size exponents are O(c), so this is not a
fully polynomial statement in an unbounded c supplied as input.

2. RATIONAL LOG WEIGHTS: ROOT'S SHARPER FORMULA IS VALID

Given q=q_e^+, compute s=floor(log2(1/q)) by integer comparisons of q's
numerator and denominator. Put y=2^s q, so 1/2<y<=1, and
  z=(1-y)/(1+y),
  w_e=(2/3)s+2z.
All these quantities are rational with polynomial bit length. w_e>0
because q<1. This remains true arbitrarily close to q=1.

For 0<=z<=1/3,
  2z <= 2 atanh(z) <= 2z/(1-z^2) <= (9/8)2z.
Since 2/3<=ln2<=3/4=(9/8)(2/3),
  w_e <= -ln q_e^+ <= (9/8) w_e <= 2w_e.
Thus root's proposed stronger formula is correct, including its near-one
regime. A simpler but weaker alternative is w_e=(2/3)s+1-y, also within a
factor two. Either avoids numerical logarithms entirely.

Use C=ceil(2c) to preserve root's existing constants. C=ceil(9c/8) is valid
with the sharper formula, but this numerical improvement is inessential.
For every subset D of edge variables, reveal its failures sequentially.
A partially conditioned marginal is an average of full conditionals, so
it stays in [q_e^-,q_e^+]. Hence
  product_D q_e^- <= pi(x_e=1 for e in D) <= product_D q_e^+,
and consequently
  exp(-C w(D)) <= pi(D failed) <= exp(-w(D)).                 (1)
This argument uses no conditional independence and no association property.
In particular, if lambda is the minimum nontrivial weighted graph cut,
  p >= exp(-C lambda).                                      (2)
The weighted minimum cut is computed with exact rational capacities by a
polynomial algorithm. Scaling all capacities to integers only increases
bit length polynomially; no numerical lower bound on lambda is needed.

3. HEAVY-PREFIX NORMALIZATION: FULL ADAPTIVE PROOF

For a coordinate pinning A define the absolute restricted partition sum
  Z_A = sum_{x consistent with A} W(x).
W must be the original absolute weight, including factors touching pinned
coordinates. Arbitrarily dropping constants while simplifying a pinned
model would invalidate a ratio of independently normalized partition sums.

Here is an explicit routine producing relative error at most zeta<=1/4
with failure at most beta. Let n<=m be the number of free coordinates. If
n=0, return W(x) exactly. Otherwise put a=zeta/(32n). At each successive
prefix A_i:
  - request fresh samples from S(A_i,a/2);
  - use N=ceil(2 a^-2 ln(2n/beta)) samples to estimate the next bit's
    probability of one, giving empirical value t_i;
  - set the bit to one if t_i>=1/2, otherwise zero;
  - record h_i=max(t_i,1-t_i), always at least 1/2.
After all n choices, let x* be the completed state and return
  Zhat_A = W(x*) / product_i h_i.                           (3)

Conditioned on every preceding random choice, S's marginal bias is at
most a/2. Hoeffding gives sampling deviation at most a/2 with failure at
most beta/n. Therefore, with probability >=1-beta, every selected true
conditional probability h_i^true obeys
  |h_i-h_i^true|<=a,
  h_i^true >=1/2-a.
Adaptivity is harmless: this probability bound is conditional on every
history and the sampler guarantee is uniform over all pinnings.

For our range a<=1/128,
  |h_i/h_i^true-1| <=3a,
  |ln(h_i/h_i^true)| <=6a.
The probability of the adaptively chosen final state under pi(.|A) is
still exactly the product of its true successive conditional probabilities.
Once a concrete path is selected, the ordinary chain rule applies to it.
Thus
  |ln(Zhat_A/Z_A)| <=6na=3zeta/16,
which is safely within relative error zeta. No empirical rare branch is
estimated to relative precision. All branch estimates are at least 1/2;
small W(x*) is evaluated exactly as a rational input expression.

The routine uses O(n^3 zeta^-2 log(n/beta)) pinned draws, each at TV
accuracy zeta/(64n), plus polynomial exact rational work. It is deliberately
conservative; no optimal sampling-counting complexity is claimed.

Estimate Z once and each retained cut partition sum Z_D independently with
relative error zeta=eta/4 and suitable confidence. Then
  phat_D=Zhat_D/Zhat
lies in [(1-eta)p_D,(1+eta)p_D] on the joint event, for eta<=1/4. The same
estimated Z may be shared by all cuts; their estimates need not be mutually
independent. Union bounds and later conditional-on-cache arguments suffice.

This is a weighted sampling/counting self-reduction in the tradition of
Jerrum-Valiant-Vazirani, supplied here with the precise adaptive heavy-branch
implementation. It should not be presented as a new rare-probability lemma
in isolation. Its role is to fill the cut-event mass operation with real
finite computations, under the actual pinned sampler premise.

4. STOP-AT-2A CONTRACTION AND EXPLICIT CUT COUNT

A is a positive integer; put r=2A. For a designated cut D of weight<=A lambda,
contract random edges with probability proportional to their positive
weights until r vertices remain, discarding loops and retaining parallel
edges. While there are k>r vertices, every remaining singleton cut is an
original nontrivial cut, so total nonloop weight is at least k lambda/2.
Conditional on preserving D so far, its weight is unchanged and at most
A lambda=r lambda/2. The next contraction avoids D with probability at
least 1-r/k. Therefore
  Pr(D survives to r vertices)
     >= product_{k=r+1}^v (1-r/k)
      = 1 / binom(v,r).                                    (4)

At r vertices choose a uniformly random bipartition by fixing the first
supervertex on side zero and assigning independent fair bits to the other
r-1. Allow the trivial all-zero assignment and discard it. Conditional on
survival, the designated unordered cut is output with probability
2^{-(r-1)}. Since r!>=2^{r-1} for r>=2,
  Pr(one run outputs D)
     >= [binom(v,r)2^{r-1}]^-1 >= v^-r=v^-2A.               (5)
If r>=v, simply make that random bipartition at the original vertices;
its target probability 2^{-(v-1)} is also at least v^-2A. This resolves
the large-A branch without an unbounded enumeration step.

Different designated cuts are disjoint output events of one run. Equation
(5) therefore itself proves N_A<=v^{2A}, where N_A is the number of cuts
of weight<=A lambda. This proof is not circular and requires only integer A.
Integer A is enough everywhere else, including tail bins.

Let Jbar=v^{2A}. Run the procedure
  R=ceil(Jbar [2A ln v + ln(1/delta_enum)])
times, retain only cuts of weight<=A lambda, and deduplicate canonical sides.
For any cut its miss probability is at most exp(-R/Jbar). A union bound
over at most Jbar cuts shows the entire list is complete with probability
>=1-delta_enum. Root's replacement of natural logs by larger integer binary
logarithms is safe. R has a deterministic polynomial bound below, even if
an adverse random outcome yields an incomplete list. If the list is empty,
return FAIL rather than looping.

Finite categorical approximation can couple the entire enumeration to the
exact procedure: if there are at most Rv edge selections, make each weighted
categorical draw TV error<=delta_arith/(Rv). Then the probability of any
difference in all runs is <=delta_arith. One can implement a rational inverse
CDF with b uniform bits; for at most m categories its TV error is <=m2^-b.
Thus b>=ceil(log2(mRv/delta_arith)) suffices. This provides deterministic
finite work and avoids an infinite rational-rejection loop.

5. TAIL AND POLYNOMIAL LIST SIZE: CONSTANTS CHECKED

Let L_v=ceil(log2(2v)). Consider lambda>=4L_v. Put
  h=ceil(log2(32/epsilon)),
  A=ceil(2C+2+2h/lambda),       0<epsilon<=1/4.
In bins k lambda < w(D) <= (k+1)lambda, k>=A, the cut count is at most
v^{2(k+1)} and each cut event has probability at most e^{-k lambda}.
Summing the geometric series, with L=ln(2v), gives
  pi(any cut with w(D)>A lambda fails)
      <=2 exp(2L-(lambda-2L)A).                            (6)
The denominator is safely bounded by two since lambda>=4L_v>=4L.
From (2), lambda-2L>=lambda/2, and A's definition,
  log(tail/p) <=ln2+2L-lambda-h <=ln2-h.
Here h>=ln(32/epsilon), so tail<=epsilon p/16. There is surplus slack.

Furthermore A<=2C+3+2h/lambda, and
  2A ln v <=(4C+6)ln v +4h ln v/lambda
           <=(4C+6)ln v+h ln2.
Therefore
  Jbar=v^{2A} <=64 v^{4C+6}/epsilon.                       (7)
Consequently enumeration, even the very conservative repetition count in
section 4, is polynomial in v and epsilon^-1 at fixed C. A large inverse
lambda does not appear in this branch. All choices use rational lambda
and integer h,L_v; transcendental values are only proof notation.

6. APPROXIMATE UNION: EXACT FORMULAS AND TV ACCOUNTING

Let retained cut events be E_1,...,E_J and U their union. Write p_j=pi(E_j),
Zcut=sum_j p_j, and c(x)=sum_j 1_{E_j}(x). Let phat_j=a_j p_j with
1-eta<=a_j<=1+eta, and Zhatcut=sum_j phat_j. With exact pinned sampling,
select j with probability phat_j/Zhatcut and draw from pi(.|E_j). The
proposal qhat has density
  qhat(x)=pi(x)/Zhatcut * sum_j a_j 1_{E_j}(x).
On U define d(x)=c(x)^-1 sum_j a_j 1_{E_j}(x), so d is in [1-eta,1+eta].
Accept a proposal with probability 1/c(x). The unnormalized accepted law is
  pi(x) 1_U(x) d(x)/Zhatcut.                              (8)
Its acceptance s satisfies
  Zhatcut*s=p_U E_{pi(.|U)} d,
  (1-eta)p_U <=Zhatcut*s<=(1+eta)p_U,
  s>=(1-eta)/(1+eta) * 1/J.                              (9)
Thus the estimator's mass error is eta, not an artificially accumulated
series of normalized-mixture errors. The exact accepted conditional law
has density d/E[d] relative to pi(.|U), hence TV<=eta/(1-eta).

Suppose the actual proposal qtilde is within tau TV of qhat, including
pinned-sampler error and categorical-index error. Set the acceptance to
zero outside U in case an abstract sampler can violate its intended pin.
The joint accepted measure differs by at most tau; |stilde-s|<=tau.
The accepted conditional law differs from the exact one by at most
2tau/s, a safe bound. For eta<=1/4 this is at most 4Jtau. This is the
crucial amplification: the list length J appears; p^-1 does not.

ONE CONSISTENT FINITE BUDGET. In the rare branch use
  eta=epsilon/64,
  tau=epsilon/(256J),
  a_stat=epsilon/(256J).
Use a sample mean of h(x)=1/c(x) on U and zero outside U. N bounded trials
with N>=ceil([2a_stat^2]^-1 ln(2/beta_stat)) give sample-mean error<=a_stat
around the actual proposal mean. On success,
  |Zhatcut*mean-p_U|/p_U
       <=eta+(1+eta)J(tau+a_stat) <epsilon/32.
Together with the omitted tail epsilon/16 this is safely within relative
epsilon of p. Allocate total confidence among enumeration, arithmetic,
all partition estimates, and this mean estimate. Subsequent bounded trials
are independent conditional on the frozen cache of list and estimates.

For conditional sampling use the same construction with epsilon=rho.
The actual acceptance is >=1/(2J). Cap independent proposals at
  L=ceil(2J ln(8/rho)).
The chance of no acceptance is <=rho/8; return a fixed valid fallback or
FAIL with that budget, rather than an unbounded loop. Conditional on a
valid fixed cache, the successful output has TV at most
  eta/(1-eta) +4Jtau +pi(B\U)/p
      <=rho/32+rho/64+rho/16=7rho/64
from pi(.|B). A fallback adds at most rho/8. The sum is <rho/4.

CACHE QUALIFICATION. A cache whose list or masses failed their setup
conditions is not itself covered by these deterministic bounds. If the
setup succeeds with probability 1-beta_setup, the unconditional output TV
is at most the conditional bound plus beta_setup. For a standalone TV-rho
sampler take beta_setup<=rho/4, leaving ample finite-arithmetic slack.
For the whole-CDF certificate, alternatively make cache correctness part
of its global confidence event and use the uniform conditional-on-cache
TV guarantees for every later draw. Do not silently claim TV rho while
leaving a larger setup failure probability uncharged.

7. NONRARE BRANCH, STILL UNIFORM IN RARE FIELDS

If lambda<4L_v, (2) gives the known rational bound
  p>=p0=2^{-8CL_v}.
Indeed e^{-4CL_v}>=2^{-8CL_v}. Since 2^{L_v}<=4v,
  p0^-1 <=(4v)^{8C}.
Direct approximate Gibbs draws with TV O(epsilon p0) and bounded Bernoulli
means estimate p relatively. Even conservative Hoeffding work
O(p0^-2 epsilon^-2 log(1/delta)) is polynomial. A multiplicative bound
improves p0^-2 to p0^-1 but is unnecessary for validity.

Rejection on graph disconnection has acceptance at least p0/2 when the
ordinary sampler's TV error is <=p0/2. For TV-rho conditional output,
choose ordinary-sampling error O(rho p0), since conditioning costs at most
2tau/p0, and cap attempts at O(p0^-1 log(1/rho)). This uses a known
polynomial bound, never the unknown p^-1 or an inverse rare-field input.

8. DOBRUSHIN REALIZATION, RATIONAL BITS, AND THE DYNAMIC GAP

Let c_ij be the maximum change in site i's conditional failure probability
when only site j is changed. Suppose max_i sum_j c_ij<=chi<1. Row sums,
not column sums, suffice for this argument. Pinning can only remove
influences; every restricted system has the same upper bound chi.

Couple two random-scan heat-bath chains on the n<=m free sites by choosing
the same site and the maximal Bernoulli coupling. If p_i(t) is the chance
of a discrepancy at site i, then
  p_i(t+1)<=(1-1/n)p_i(t)+(1/n)sum_j c_ij p_j(t).
Consequently max_i p_i contracts by 1-(1-chi)/n. Union bound gives
  TV(P^t(x,.),pi_A)<=m exp(-(1-chi)t/m).
Mixing to tau/2 therefore takes
  t=ceil(m/(1-chi) ln(2m/tau))
updates from any consistent state. No warm-start, tiny-state-probability,
or rare-field factor is present. Completely pinned systems are deterministic.

Every rational conditional Bernoulli draw can be implemented using b
uniform bits and a rational comparison, with TV error at most 2^-b. Choose
b>=ceil(log2(2t/tau)) for all t updates; the trajectory coupling budget is
tau/2. This makes sampler running time deterministically finite. Analogous
dyadic inverse-CDF draws implement all other rational categorical choices.

Let B_in bound the total binary length of the supplied positive rational
factor values. Coarsely 2^{-B_in}<=W(x)<=2^{B_in}, hence
  pi(x)>=2^{-(m+2B_in)}.                                  (10)
Every positive event mass and every conditional event mass under pinning
has this same coarse floor. This replaces the product-specific p_floor
in the old CDF proof. It is needed for output rounding only, not for an
inverse-floor simulation cost. Partition estimate (3) is rational of
polynomial bit length, because empirical branch probabilities are >=1/2
and W is a rational product. Exponentially small masses are never forced
through fixed-precision floating point.

DYNAMIC COMPOSITION. An operating independent-refresh generator does not
in general preserve a correlated Gibbs law. The explicit replacement is
  Q0=gamma sum_e (E_e-I),
where E_e is the Gibbs single-site conditional resampling projection.
Each E_e is self-adjoint and positive semidefinite in L2(pi). Random-scan
P_H=m^-1 sum E_e is reversible and positive semidefinite. The exact
coupling rate above implies every nonconstant eigenvalue is at most
1-(1-chi)/m: apply the TV contraction to an eigenfunction and take t-th
roots. Therefore
  gap(-Q0)>=gamma(1-chi).
Adding any explicitly supplied pi-reversible local generators adds
nonnegative Dirichlet forms, so this gap lower bound persists. For a
rational exit-rate bound Lambda and uniformization P=I+Q/(2Lambda),
  g>=gamma(1-chi)/(2Lambda).
The known-CDF theorem's alternative general-reversible interface can now
be invoked with actual ordinary sampling, update, gap, p-estimation and
conditional-failure costs. For its equilibrium-conditioned-safe start,
retain p<=1/2 so ordinary pi rejection is efficient. The new static theorem
itself has no p<=1/2 restriction.

The previous CDF proof specifically deriving failure samples by product
prefix counting should be replaced by section 6 here; it should not be
reapplied as though a pinned correlated graph had become a product law.
Its later argument only needs the explicitly bounded TV failure sampler.

9. CONCRETE UNBOUNDED-INTERACTION FAMILY

The c condition is strictly weaker than bounded odds distortion, even in
an explicit rapidly mixing positive rational model. Let the dependence
graph on edge variables have degree at most d>=1. For H a positive integer
multiple of 2d, take
  W(x)=2^{-H sum_e x_e} product_{(e,f) in F} 2^{(H/(2d)) x_e x_f}.
Its conditional odds range between 2^{-H} and 2^{-H/2}, so valid bounds are
  q^-=1/(1+2^H),   q^+=1/(1+2^{H/2}).
Since (1+2^{H/2})^2>=1+2^H, q^->=(q^+)^2: fixed c=2 works for all H.
On a degree-d site the odds distortion is exactly 2^{H/2}, unbounded and
exponential in H. Interaction log-strength (H/(2d))ln2 is unbounded too.
Yet each influence is at most q^+ and the row sum is at most d q^+.
Choose H with d/(1+2^{H/2})<=1/2; then chi<=1/2 uniformly in H and every
pinning. All factor entries are explicit rationals with O(H) bits.

Thus the strengthened theorem includes strong positive interactions with
strong rare-failure fields, where both fixed logarithmic contrast and
uniform mixing are verified directly. It does not assert tractability of
all strongly coupled spin models; these particular rare fields suppress
the relevant absolute influences.

10. BOUNDED-ODDS RAO-BLACKWELL SPECIAL CASE

If max O_e/min O_e<=K, then q_e^-/q_e^+>=1/K and
q_e^->=(q_e^+)^K. Under pin A not containing e,
  pi(x_e=1|A)=E_{pi_A}[r_e(x_-e)],
where r_e is the full local Gibbs conditional. Normalizing by the known
q_e^+ gives an observable in [1/K,1]. Sequential pinning of a cut and
relative estimation of those means yields its probability with no inverse
q_e^+. Per-factor relative tolerance O(eta/m) uses
O(K^2 m^2 eta^-2 log(mJ/beta)) draws at each of at most m cut factors,
with pinned TV error O(eta/(Km)). This is valid and can exploit locality
or a small cut, but has no advantage that justifies restricting the main
theorem to bounded K after section 3 is available. Keep it as a useful
special implementation. The tower-property identity requires e remain
unpinned when the expectation is taken.

11. COSTS, LIMITS, COMPARATORS, AND UNFINISHED WORK

A conservative rare-branch cost is polynomially bounded by:
  - Jbar=64 v^{4C+6}/epsilon;
  - R<=O(Jbar log(Jbar/delta)) contractions, each with O(v) choices;
  - O((J+1)m^3 epsilon^-2 log(m(J+1)/delta)) pinned draws for all
    normalization estimates;
  - O(J^2 epsilon^-2 log(1/delta)) additional pinned union proposals;
  - per conditional output O(J log(1/rho)) proposals, after setup at rho.
Each proposal tests at most J cuts, each of size at most m. Heat-bath draw
cost is O(m/(1-chi) log(m/tau)) local updates, with explicitly allocated
finite bits. Polynomial graph and exact rational arithmetic overheads are
additional. These are existence bounds, not competitive numerical costs.

The completed hard operation is static relative rare-event access for an
interacting law, not estimating a rare rate from ordinary physical samples.
Known factor weights, the contrast promise, and a verified uniformly fast
pinned sampler remain premises. Full-support is essential to this version.
The cut enumeration/tail argument is specific to undirected all-terminal
disconnection and does not yield an FPRAS for arbitrary failure predicates.
No nonreversible full-CDF theorem or broad no-mixing-gap result follows.
Any CDF consequence retains the old numerical inverse-gap dependence.

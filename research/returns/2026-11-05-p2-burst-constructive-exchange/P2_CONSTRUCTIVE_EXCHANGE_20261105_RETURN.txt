\[

\mathrm{COPY}(x,y)&=(x,x),\\
\mathrm{SWAP}(x,y)&=(y,x),\\
\mathrm{SORT}(x,y)&=(x\wedge y,\;x\vee y),
\end{aligned}

Choose a fixed fault budget and repetition parameters

\[
D=11,\qquad t=2D,\qquad n=8D+1.

A level-\(k\) logical cell contains \(B\) level-\((k-1)\) cells. Among them are \(n\) designated data cells, a disjoint bank of fresh output cells, and workspace.

Define validity recursively:

\[
V_0^b=\{\text{physical bit }b\},

\[
V_k^b=
\left\{
\text{at least }n-t\text{ designated children belong to }V_{k-1}^b
\right\}.

Every other child and every workspace register may be arbitrary.

### The contract we actually need

Suppose some input cells to a gate are valid for specified bits, while the remaining input cells are arbitrary. If those specified bits force a particular output of the Boolean gate, a good encoded implementation must make that output valid for the forced bit.

Examples include:

- A valid COPY source forces both outputs, even with an arbitrary destination.
- SWAP transports each valid input independently of the other input.
- A valid zero input forces SORT’s first output to zero.
- A valid one input forces SORT’s second output to one.
- RESET forces its constant output regardless of the old state.

There is no requirement that an entirely arbitrary input first be converted to a consistent logical bit. That normalization operation is unnecessary for this construction.

### The finite gadget

For **each output replica separately**, the gadget executes the following fixed schedule:

1. Clear that row’s reusable workspace using the reset gates.
2. Copy the designated replicas of each input into workspace.
3. Compute each input majority with a monotone sorting circuit.
4. Compute the required output component.
5. Store it in its own fresh output cell.

After every output replica has been computed, swap the fresh outputs into the designated data positions and retire the old records.

Both outputs of COPY and SWAP are freshly reconstructed. Merely leaving the source bank untouched would allow its old errors and new errors to accumulate.

The construction also enforces four separation rules:

- A child cell holds at most one live parent-level source, workspace or output value.
- Original source values participate only as COPY sources or SWAP passengers until final commitment.
- A computed majority or intermediate result from one output row is never reused by another output row.
- Stored sources and completed outputs receive the included protected identity operations while other work proceeds.

All routing is a predetermined permutation implemented by adjacent swaps. Row names and source-lineage labels belong to the compiler and proof; they are not protected mutable records inside the device.

### Why malformed inputs cause no semantic gap

Represent a valid zero by \([0,0]\), a valid one by \([1,1]\), and an arbitrary block by \([0,1]\). AND, OR, COPY and SWAP propagate the corresponding lower and upper bounds.

If more than half the inputs to a monotone majority circuit are valid for \(b\), both endpoint evaluations of the majority equal \(b\). Therefore the result is forced even if every other input block behaves inconsistently between uses.

This argument applies recursively: it uses only the forced-output contracts of the lower-level gates.

Now suppose a level-\(k\) gadget contains at most \(D\) bad child operations. Each child operation occupies at most two child cells. It can therefore newly contaminate at most two original source lineages and at most two output-row identities.

For each valid input, a fixed set of at least

\[
n-t-2D
=
4D+1
=
\frac{n+1}{2}
\]

source replicas remains valid throughout the gadget. Every output row untouched by bad child operations consequently obtains the forced result. At most \(2D=t\) output replicas can be contaminated, so every forced output belongs to \(V_k^b\).

\[
\boxed{
\text{At most }D\text{ bad child operations}

\text{the encoded gate obeys its forced-output contract}.

The proof covers arbitrary corrupted decoder records because those records are the same recursively protected workspace cells used in the row computations.

For fixed \(n\), each row contains finitely many copying, sorting and storage operations. An operation between prescribed positions in a block of width \(B\) can be routed by \(O(B)\) adjacent swaps.

## 4. The actual “large burst or two independent failures” implication

- A level-zero operation is bad if a burst reaches its participating registers during its clock interval.
- A level-\(k\) operation is bad if it contains more than \(D\) bad child operations.

Every active operation and every idle location is counted.

This definition is independent of incoming register values. Persistent corrupted values are handled by the validity invariant; they do not create an unrecorded dependence of the bad-location event on earlier clock intervals.

\[

S=2BA

For the remaining process, a child operation anchored at position \(pL_{k-1}\) has possible Poisson centers within

\[
[(p-1)L_{k-1},\;(p+3)L_{k-1}]
\]

during its single child-clock interval.

Two such source regions are disjoint if their time intervals differ, or if their spatial anchors differ by at least five child lengths.

More than \(D=11\) child locations cannot all lie in one such close neighborhood. Hence a bad parent, in the absence of a large burst, has two bad child locations with disjoint truncated Poisson source regions.

Those two events are independent. Each truncated bad event is contained in the corresponding full-process bad event, since the recursively defined hit-count badness is monotone in the fault set.

This proves the quadratic term; it is not an assumption about independent repair cones.

A radius-\(\rho\) interval can intersect a parent footprint of length at most \(2L_k\) from a set of centers of length at most \(2L_k+2\rho\). Therefore

&\le

\int_{L_{k-1}}^\infty
(2L_k+2\rho)\,a\rho^{-a-1}\,d\rho\\

where

\theta=AB^{1-a}

C_{\rm tail}

Centers outside the device are included in this integral.

Combining the two cases gives

\[
\boxed{
p_k\le S^2p_{k-1}^2+

}

At the base level,

\[
p_0\le c_a\lambda_1,
\qquad
c_a=2+\frac{2a}{a-1}.

Set

C_p\ge\max\{c_a,2C_{\rm tail}\}.

If

\[
\lambda_1\le\frac{\theta}{2S^2C_p},

induction gives

\[
\boxed{

Indeed, the quadratic term consumes at most half this bound, and the large-burst term consumes the other half. All constants are fixed before the requested horizon is chosen.

## 5. Completing the operation from one seed to one physical output

The construction must still earn encoding and readout. They are explicit circuits.

### Noisy ascent from the finite seed

Initially, only physical cell \(0\) contains the unknown bit. The remaining prebuilt hardware has input-independent state and may be arbitrary.

To lift a valid level-\((k-1)\) cell into a level-\(k\) representation:

1. Reset unused child cells.
2. Use protected COPY and SWAP operations to populate the \(n\) designated children.
3. Maintain all live values with the included protected idles.

If every child operation in this finite lifting circuit is good, the new parent is valid.

The lift itself does **not** claim tolerance of \(D\) bad child operations. Its failure is bounded by a union bound

\[
M p_{k-1},
\]

where \(M\) is a fixed upper bound on its child calls, including idles. Thus the total ascent failure is at most

\[
M\sum_{k\ge0}p_k
\le
\frac{M C_p\lambda_1}{1-\theta}.
\]

The horizon-dependent encoding is therefore performed under noise and paid for. It is not placed into the initial seed.

### Protected storage

At top level \(m\), repeat the protected identity operation for

\[
\left\lceil\frac{T}{A^m}\right\rceil
\]

cycles. The probability that one of these cycles is bad is at most

\[
\left(\frac{T}{A^m}+1\right)p_m.
\]

### Noisy local descent

To descend one level, copy the \(n\) designated children into protected workspace, execute their monotone majority circuit, and transfer the result into child \(0\).

A valid parent has a strict majority of valid children. If the lower-level operations used in this descent are good, the forced-output property makes child \(0\) valid for the original bit.

Again, use the union bound \(M p_{k-1}\), rather than claiming that this decoding stage independently corrects bad child operations.

Repeat until the result reaches physical cell \(0\). Include one final physical clock interval for the terminal read window.

Consequently, for a constant \(c\) covering that endpoint,

\[
P_{\rm error}
\le
\frac{2M C_p\lambda_1}{1-\theta}
+
\left(\frac{T}{A^m}+1\right)C_p\lambda_1\theta^m
+
c\lambda_1.
\]

Choose \(m\) minimally so that

\[
B^m\ge T^{1/(a-1)}.
\]

Then the holding contribution obeys

\[
\begin{aligned}
\left(\frac{T}{A^m}+1\right)p_m
&\le
C_p\lambda_1
\left[
T B^{m(1-a)}+\theta^m
\right]\\
&\le 2C_p\lambda_1.
\end{aligned}
\]

Thus

\[
\boxed{
P_{\rm error}
\le
\lambda_1
\left[
\frac{2M C_p}{1-\theta}+2C_p+c
\right].
}
\]

Taking the fixed positive intensity small enough makes this at most \(1/4\), uniformly in \(T\).

This is one requested output per execution. It does not demand arbitrarily accurate readout at a fixed noisy cell or simultaneous success of an infinite stream of answers.

Since \(m\) is minimal,

\[
B^m=O\!\left(T^{1/(a-1)}\right),
\qquad
A^m=O\!\left(T^{\kappa/(a-1)}\right),
\]

with \(\kappa<a-1\). Translating back to ambient dimension gives:

| Resource | Bound |
|---|---|
| Initial input-dependent seed | One physical bit |
| Mutable data and work cells | \(O(T^{1/(\alpha-d)})\) |
| Noisy encoding and local decoding duration | \(O(T^{\kappa/(\alpha-d)})\) |
| Operating time from seed arrival through delivery | \(T+O(T^{\kappa/(\alpha-d)})\) |
| Physical local operations, including idles | \(O(T^{1+1/(\alpha-d)})\) |
| Explicit schedule generation/materialization | \(O(G\,\mathrm{polylog}\,T)\) work/description bound, where \(G\) is the physical operation count |

The operation bound follows from bounded update rate on the installed wire. It includes idle updates on the full installed hardware during encoding and decoding.

The pre-input apparatus is also charged: it has the stated number of data/work cells and adjacent connections, together with the finite schedule. The linear-plus-sublinear time bound is the **post-input operating time**, not a claim that manufacture and schedule generation take no time.

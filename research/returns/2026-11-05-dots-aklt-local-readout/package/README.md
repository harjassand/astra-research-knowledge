# Exact local square-AKLT loop sampling and physical readout

Start with RESULT.md for the executed result, then square_aklt_local_sampler_20261105/README.md and LOCAL_SAMPLING_THEOREM.md.
The runtime paths in these directories are relative, so run commands from this release root.
Core sampling uses Python and NumPy. Primitive audits also use mpmath; Fourier recertification uses SciPy.

The operation is exact local classical loop sampling and a specified thermodynamic spin-pair expectation.
It is not quantum preparation, a spectral-gap theorem, or a demonstrated speedup over the published worm.
See the final independent audit and production result for implementation status and confidence scope.
The retained early statistical anomaly, fixed follow-up protocol and all reported runs remain included.

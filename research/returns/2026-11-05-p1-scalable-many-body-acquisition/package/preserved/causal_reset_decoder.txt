SUMMARY

A known finite local quantum circuit with coherently collected local depolarizing environments admits an explicit efficient output-only decoder whenever a classical forward active set becomes empty. The environment is first processed into an input-independent no-reset/reset-export instrument. On reset, the old unknown source state, including reference correlations, is exported to a receiver qudit; the source is replaced by I/q. The decoder inverts only the active subcircuit. It remains valid when its ancillary boundary is mixed and entangled with inaccessible systems. At sufficiently large local reset probability, capture takes O(log(n/delta)) rounds with success >=1-delta, total interface work O(n log(n/delta)), and expected retained memory/inverse work O(n). No dense matrix on q^n dimensions is synthesized.

This is a structured scalable compilation theorem. Percolation forgetting and Kraus-representation freedom are established machinery, not claimed new discoveries.

1. ACQUIRED LOCAL RESET-EXPORT INSTRUMENT

Let q be fixed. The physical local noise channel is
  D_p(rho) = (1-p) rho + p Tr(rho) I/q,
with its actual calibrated pure Stinespring environment delivered coherently and losslessly. The reduced generator/channel alone is insufficient.

An isometry acting only on the actual environment changes its Kraus representation to
  E_empty = sqrt(1-p) I,
  E_ab = sqrt(p/q) |a><b|,  0<=a,b<q.
This finite isometry is constructed from the calibrated Kraus operators by standard Kraus-isometry equivalence. An actual dilation larger than the minimal one can be padded; the map only needs to agree on the physical output support.

The isometry becomes
  V|psi> = sqrt(1-p)|psi>_S|empty> + sqrt(p)|Phi_q>_SA |psi>_B.
Measuring only empty versus the AB subspace, then discarding A, yields for every entangled rho_SR:
  I_0(rho_SR) = (1-p) rho_SR,
  I_1(rho_SR) = p (I/q)_S tensor rho_BR.
The flag distribution is independent of the payload. The old state is exported, not measured.

For q=2, the usual Pauli dilation has K0=aI,Kx=bX,Ky=bY,Kz=bZ, with a=sqrt(1-3p/4), b=sqrt(p)/2, c=sqrt(1-p). In output order empty,00,01,10,11 the 5x4 environmental isometry is
  [c/a,             0,        0,         0]
  [b/(sqrt(2)a),    0,        0,  1/sqrt(2)]
  [0,      1/sqrt(2), i/sqrt(2),         0]
  [0,      1/sqrt(2),-i/sqrt(2),         0]
  [b/(sqrt(2)a),    0,        0, -1/sqrt(2)].
Its columns are orthonormal, and its Kraus combinations give the stated instrument.

2. EXACT CAUSAL-CUT DECODER THEOREM

Model: n q-dimensional source sites initially contain an arbitrary state rho_XR, entangled across sites and with arbitrary external reference R. The known finite source circuit consists of arbitrary known unitary gates of arity <=k and local reset-export events as above. The receiver has all relevant exported qudits and flags but never touches the surviving source.

Track wire segments (not merely physical site names):
  (i) Every initial payload wire is active.
  (ii) A gate with at least one active input is recorded; all its output wires are active.
  (iii) A gate with no active input is not recorded.
  (iv) Reset on an active site stores the old wire and starts a fresh inactive source wire.
  (v) Reset on an inactive site leaves it inactive; the old output can be discarded.
Stop when no source wire is active. This is a classical certificate from the gate schedule and payload-independent flags.

Theorem: For every trajectory with an empty active set, the receiver exactly recovers rho_XR by applying the G recorded gate inverses in reverse chronological order and discarding restored boundary-ancilla wires. The required stored qudits M satisfy
  M <= n+(k-1)G.

Proof: Replace every reset by a wire break: the old source wire terminates in a receiver register; a fresh independent source wire begins in I/q. Keep purifications of fresh mixed wires in an inaccessible reference if desired. An active gate is precisely a gate in the directed future of the original payload, treating a gate as connecting every input to every output and reset as breaking the old-to-fresh source connection. There is no directed edge from an active gate to an inactive gate, since that would make the latter active. Thus disjoint-gate commutations reorder all inactive operations before the active subcircuit. Inactive operations prepare a joint state omega_AF independent of rho_XR. Here A comprises all boundary wires entering the active subcircuit, and F may include inaccessible source registers and their purifying partners. omega_AF may be arbitrarily mixed and entangled. At active extinction every output wire of the active unitary U_A terminates in captured receiver memory. The relevant global state is
  (U_A tensor I_RF) [rho_XR tensor omega_AF] (U_A^dagger tensor I_RF).
The receiver applies U_A^dagger and discards A, exactly restoring rho_XR. Each recorded k-site gate introduces at most k-1 fresh boundary wires, giving the memory bound.

This proof handles inactive pre-entanglement: if an inactive-only gate creates Bell pair a,b and an active gate later couples payload x to a, capturing the active x,a outputs and undoing that gate restores x without touching b. It does not assume pure or independent boundary ancillas.

Counterexample to an insufficient certificate: Reset a, then couple fresh a to still-active b, then reset b. Both physical sites have reset once, but a can again depend on the payload. The active-wire rule correctly reactivates a.

3. DISCRETE CAPTURE TIME AND COSTS

Suppose each round is a layer of disjoint unitary gates of arity <=k followed by independent local D_p noise, with the actual environments processed by Section 1. Let alpha=k(1-p), and a_t be the active count after round t. Then
  E[a_(t+1) | A_t] <= alpha a_t,
  E a_t <= n alpha^t,
  P(A_t nonempty) <= n alpha^t.

If p>1-1/k, so alpha<1, then
  T = ceil(log(n/delta)/[-log alpha])
gives a recovery certificate with probability >=1-delta. This is a uniform sufficient branching bound, not a sharp quantum threshold.

For a capped T-round protocol:
  total source noise-port uses: nT;
  full flag processing/classical bookkeeping: O(nT), bounded k;
  worst-case retained memory and inverse gates: O(nT);
  expected inverse gates: E G <= n/(1-alpha);
  expected retained qudits: E M <= n+(k-1)n/(1-alpha) = kp n/(1-alpha).
At fixed distance from the sufficient threshold, retained memory/inverse work are linear in expectation, while total spacetime interface work remains O(n log(n/delta)).

The success probability is payload independent, and the ideal successful map is exactly s id_(q^n), s>=1-delta. If failure is replaced by an arbitrary output state, unconditional diamond error is <=2delta. Alternatively, continue collecting the same input until extinction; this is legitimate only because all relevant information stays coherently available, not a restart of a destroyed unknown state.

If L actually used receiver operations each have diamond error <=nu, the full instrument error is <=L nu by telescoping. For unconditional target epsilon, choose 2delta<=epsilon/2 and nu<=epsilon/(2L). Fixed-dimensional local unitaries can be synthesized with ordinary precision-dependent gate costs. Memory waiting error, classical latency, and error correction must be included; they are not free.

4. IDEAL CONTINUOUS-TIME MARKOV SUBCLASS

There is an ideal Markov corollary for local depolarizing generators r(R_I/q-id), plus known k-local unitary jumps U_X with rates gamma_X, and arbitrary one-site Hamiltonians. All modeled ports are actual calibrated coherent outputs.

For depolarization use Weyl ports L_mu=sqrt(r)/q W_mu, mu!=0. Append the source-independent identity coherent port L_0=sqrt(r)/q I (D[I]=0) and mix all q^2 ports unitarily into
  L_ab=sqrt(r/q)|a><b|.
Then sum_ab L_ab^dagger L_ab=rI. The coarse replacement clock is Poisson rate r independent of the state; each event has the same |Phi_q>_SA |psi>_B factorization. Detecting the separate unitary-jump channel labels/times gives known unitaries at state-independent rates.

Let g=max_i sum_(X containing i) gamma_X, b=(k-1)g, kappa=r-b. If kappa>0,
  E|A_t| <= n exp(-kappa t),
  P(tau>t) <= n exp(-kappa t),
  E tau <= (log n+1)/kappa,
  E G <= gn/kappa,
  E M <= rn/kappa.

This corollary is an ideal input-output model, not a finite-bandwidth photon receiver. Finite-bandwidth coarse-event detection and quantum internal-mark capture need a separate physical interface construction. The digital theorem is the fully finite operational statement here.

UNPROVED EXTENSION: Arbitrary interacting continuous Hamiltonians are not covered. Naive Trotterization fails because every infinitesimal entangling gate Boolean-reactivates all its output sites, causing the branching bound to diverge as the time step vanishes. A norm-sensitive construction/cluster expansion would be needed. Do not claim the contact-process theorem closes this case.

5. COMPARISONS AND SCOPE

Direct parallel source SWAP is simpler if that source access is granted. With the same reset-export ports and no interactions, collecting all original wires already takes O(log(n/delta))/r. This theorem handles repeated interaction-driven spread and constructs an output-only decoder with polynomial overhead. No device advantage over direct source access is shown.

Astra N1732 is more general: any known finite-dimensional pure-port Markov source, full canonical Stinespring channel preserved approximately, finite receiver controls. Its dense compilation scales in d=q^n. The present result requires local reset-export structure and an efficient gate/jump history, recovers the payload with polynomial n-cost, and does not claim canonical compression of every residual-source/environment correlation.

No contradiction with the predecessor acquisition law: accessible depolarizing ports include actual noncommuting source operations. Inaccessible Z-dephasing is not relabeled as an accessible port. Additional hidden source noise can invalidate exact recovery and remains constrained by the acquisition converse.

# Final attack: from observed cell gaps to finite-N prediction certificates

7 November 2026. This is a constructive follow-up, not a completed finite-N certificate theorem. It separates an additional operation that closes from the exact remaining entropy/replacement burden.

## 1. Result of the attack

**Closed:** one can construct a succinct, deterministic, admissible density-free local corrector and directly certify its uniform constitutive residual R(rho,F)=c(rho;F)-c(rho), using polynomial sampling and the observed primal/dual lower coefficient bracket. Neither the corrector nor its residual needs to be supplied as an unevaluated functional. The source's empirical-density gluing operation can be implemented with polynomial query/storage costs using fixed shared random seeds, rather than listing all microscopic inputs.

**Not closed:** a complete operational finite-N weak-prediction error bound with every coefficient numeric and checked. In the source's entropy proof, small R and a corrector norm are not the entire error: the canonical CLT variance in the gradient replacement, source/profile terms and the large-deviation entropy term also enter. The uniform finite-block canonical variance and a positive spectral lift can be made explicit as below, but I have not completed their full inhomogeneous entropy integration with all constants. It would be false to promote the acquired coefficient interval alone into a finite-N prediction certificate.

## 2. Why the closed dual optimizer is not automatically the needed corrector

The dual optimizer in `DUAL_ADAPTIVE_BRACKET.md` is a function u_(k,zeta) on the whole closed domain Gamma=Lambda^+, pasted across counts and outside environments. The source's translation/Jensen argument for a local corrector uses a function supported in Lambda^-, followed by F=phi/|Lambda|. These are different spaces. For SSEP on a path, the normalized closed dual optimizer is

u(eta)=sum_(i=0)^L(i-L/2)eta_i.

It already depends on both boundary occupations; subtracting ell leaves a count-dependent gauge supported on the whole path. A special cancellation repairs SSEP, but the claim that an arbitrary closed optimizer is a member of F_0(Lambda^-) is literally false. With nontrivial outside dependence there is an additional mismatch. A primal-dual scalar gap plus an infinity norm does not by itself supply the missing admissible-function conversion.

The safe route uses the source's actual construction, (6.34), not this shortcut. Write the large cell as a union of smaller cells. At each interior small cell use its **open primal** Poisson corrector at a clamped empirical density of the large cell; sum over small cells away from the large boundary. Normalize the resulting compactly supported function by the large volume. This is a density-free local function, because the density argument is computed from the input configuration itself. Proposition 6.7 and Lemma 6.8/Proposition 6.9 are the governing established construction and translation estimate. The density cutoff and boundary truncation are indispensable. In one dimension the source chooses small side about large_side^(1/12) and density cutoff about large_side^(-1/6).

## 3. Succinct construction of an actual finite function

Let f_p be the mean-zero open-cell Poisson solution at density p. For a queried microscopic input x it has the representation

f_p(x)=integral_0^infinity E_x j_p(X_t)dt,

with polynomial gap, bounded j_p and a fully explicit mixing-tail truncation as proved in `FOLLOWUP.md`. In the empirical-density gluing there are only polynomially many p values, namely clamped integer count/large-volume fractions. A finite computation can therefore represent all needed f_p as follows.

For each p store M independent random-seed blocks, each of sufficient finite length to specify a capped local trajectory from ANY input x. For a fixed x, the blocks generate independent trajectories of the specified open generator. Their averaged time-integrated drift is a bounded estimate fhat_p(x). Use the SAME stored seeds whenever the finite function is evaluated again. Thus fhat_p is an actual deterministic function once the seeds are fixed; it is not an oracle returning unrelated noise on repeated calls.

A union bound over all p and all 2^m microscopic inputs costs only log(number of inputs)=O(m+log(number of p)) in M. It does not require evaluating or storing all those inputs. Common randomness creates correlations between different x values, which do not invalidate this union bound. The expected value/concentration for each fixed x still uses independent seed blocks. Uniformization, a common hard proposal cap and a finite-bit probability approximation have uniform-in-x bias/failure bounds; charge their bits and allocate them before the union bound.

Consequently a polynomial seed array and a polynomial-time evaluation program give, with one high-probability event,

sup_(p,x)|fhat_p(x)-f_p(x)|<=e_f.

The minimum permitted p is inverse-polynomial in the large cell side, so every gap, logarithmic minimum-probability bound, trajectory duration and sample count remains polynomial. The function can be clipped at its explicit Poisson/mixing bound. The source's gluing then gives a finite, density-free Fhat supported in the large interior. Its radius and supremum norm are explicit program bounds. Its repeated evaluation is deterministic and local. The source's exact admissible glued function is uniformly approximated; no density differentiability of the sampled program is assumed.

It is evaluated by finitely many local calls to the retained program. Ordinary product Bernoulli sampling estimates its expectation, with bounded-score confidence intervals. No many-body equilibration is needed for this expectation.

For any bounded function Z of q Bernoulli bits, differentiation by one coordinate at a time gives the exact endpoint-safe bound

|d E_rho Z/d rho|<=2q||Z||infty,  0<=rho<=1.

Thus a uniform density mesh is effective even at rho=0,1. In particular the energy score is exactly zero at both constant configurations, because an exchange changes nothing. On the remaining interval use the certified primal/dual lower coefficient bound from `DUAL_ADAPTIVE_BRACKET.md`, with that explicitly chosen inverse-polynomial cutoff. Subtract this lower c(rho) from the upper sampled energy. The resulting nonnegative envelope bounds R uniformly over ALL rho in [0,1].

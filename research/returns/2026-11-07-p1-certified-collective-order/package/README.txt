CERTIFIED COLLECTIVE ORDER FROM ACQUIRED PORT MODELS
7 November 2026, Australia/Brisbane

Question resolved in this treatment:
Can finitely acquired, uncertain, possibly infinite-dimensional passive
components be assembled into reciprocal nonlinear networks whose global
ordered states, ordering transition, and prescribed amplitude patterns are
computable and certifiable without internal identification?

Answer: yes for the explicitly stated attractive/balanced cubic class.
The complete result includes a finite-bit convex algorithm, a direct inverse
design construction, source and calibration uncertainty, a full-state
equilibrium/inertia reduction, and a convergence theorem. It does not assert
that physical relaxation finds the global minimum from every initial state.
An explicit attractive metastability family and a frustrated NP-hardness
reduction delimit that stronger assertion.

This is a model-level mathematical construction and checked software
execution, not a new hardware experiment, a novelty determination, a
general nonconvex optimizer, or a resolution of P versus NP.

Run from this directory: python run.py
Replay the saved certificates only: python verify.py

no native hidden source, new experiment, network request or source call is
available to the new solver. Full acquisition costs remain in the preserved

No peer or additional worker was used. All source/transfer holds remain.

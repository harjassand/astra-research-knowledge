THE CROSSED-PETZ TWO-QUBIT STATISTIC IS NOT A CAUSAL SUFFICIENT STATISTIC
Scope: known homogeneous tracial partial-SWAP qubit stream.

This is a construction-specific obstruction, not a lower bound for all causal
receivers. Pure workspace, measurements, classical records, alternative quantum
statistics, and growing memory remain unrestricted by this result.

1. The tempting virtual statistic

The actual source S meets independent E_j=I/2 through
  U_SE = c I + i s SWAP_SE, c=cos(theta), s=sin(theta).
Initialize receiver R,A in Phi_RA, the normalized maximally entangled projector.
Define the nonphysical update
  X_SRA -> Tr_E[V_AE U_SE (X_SRA tensor I_E/2) U_SE^* V_AE^*],
  V_AE = c I - 2 i s Phi_AE.
Call this CP, generally non-TP map T (R is a spectator). On the particular
initial family rho_S tensor Phi_RA, each full prefix has unit trace. Folding
the A wire proves this: V_n ... V_1 acting on Bell-initialized RA is an isometry
on the entire E_1...E_n input space, equal after Bell transposition to the
reverse-order dummy unitary. Consequently the R marginal equals the accepted
reverse-dummy/Petz decoder applied to that entire prefix.

That global isometry statement does NOT make T a physical local update on
the mixed SRA state obtained after discarding earlier E's. The distinction is
decisive below.

2. Closed form for the four-dimensional input family

Write Atilde=(X_A,-Y_A,Z_A), and let S_i,R_i denote ordinary Pauli operators.
Set Q_SA=sum_i S_i Atilde_i=4 Phi_SA-I. For the input basis I/2,Z/2, define
  sigma_n = T^n[(I_S/2) tensor Phi_RA],
  delta_n = T^n[(Z_S/2) tensor Phi_RA].
Thus the two physical input states |0>,|1> produce sigma_n +/- delta_n.
All equations below are exact, for arbitrary integer n>=0. Put
  u=c^(2n), v=(1-s^4)^n,
  w=[c^2(c^2-s^2)]^n, h=n c^(2n-1) s^3,
with h=0 at n=0 and the continuous endpoint convention if c=0.
Then
  sigma_n = (I_S/2) tensor [u Phi_RA+(1-u)I_RA/4],
and
  8 delta_n = u S_z + (1-v)R_z + (v/3) R_z Q_SA
      + (u/2) sum_a R_a (S_z Atilde_a - S_a Atilde_z)
      + w sum_a R_a [(S_z Atilde_a+S_a Atilde_z)/2
                     - delta_za Q_SA/3]
      + h sum_{a,k} epsilon_zak R_a(S_k-Atilde_k).

Derivation: decompose the operator space of SA under U tensor conjugate(U).
The scalar sector has I -> I and Q -> (1-s^4)Q+3s^4 I.
Both single-vector operators S_i,Atilde_i have eigenvalue c^2. The
antisymmetric vector K_ij=S_i Atilde_j-S_j Atilde_i obeys
  K_ij -> c^2 K_ij+2cs^3 sum_k epsilon_ijk(S_k-Atilde_k).
The symmetric traceless rank-two sector has eigenvalue c^2(c^2-s^2).
Exponentiating these scalar/Jordan blocks and expanding the initial Bell
projector gives the displayed formula. It can also be verified by a single
three-qubit matrix multiplication on each sector; no large output state is
represented or assumed compressed in this derivation.

3. Physical data-processing obstruction

For any physical causal receiver, include the ACTUAL source S in the tracked
state, even though the receiver cannot access S. Between successive receiver
memory states, the operation consists of adjoining fresh tau_E, applying the
source unitary U_SE, then applying a CPTP receiver map to its memory and E.
Therefore the trace distance between the joint S+receiver states for inputs
|0>,|1> cannot increase. The unitary/adjoining stage preserves it; the receiver
stage contracts it. This remains true with pure initialized workspace,
unlimited later memory, feedback and retained classical registers.

The virtual statistic violates this necessary condition. Its distinguishability
is D_n=||delta_n||_1. Define
  D(v) = [1+3 |1-4v/3|]/4.
The first three nondecaying terms in delta_n are
  delta_v=(R_z/8)[(1-v)I_SA+(v/3)Q_SA],
which has trace norm D(v), since Q_SA has eigenvalues 3,-1,-1,-1. The remaining
terms have the rigorous triangle bound
  |D_n-D(v)| <= 3u+(10/3)|w|+4|h|.                         (1)

In the weak-action scaling n theta^4 -> a>0, u,w,h ->0 while v->exp(-a).
Thus D_n tends to D(exp(-a)), which reaches 1/4 at a=log(4/3) and then rises
to 1 as a increases. This is an order-one, trace-norm-stable failure of the
causal data-processing condition. It is not a normalization coefficient or
a vanishing small-angle artifact.

More operationally, suppose any physical receiver compresses a prefix into
exactly the joint SRA virtual state at n. Every later decoder has input-Z
distinguishability at most D_n. If its final payload channel has half-diamond
error epsilon from identity, its output-Z distinguishability is at least
1-2epsilon. Therefore
  epsilon >= (1-D_n)/2.
If the joint state at that cut differs from each of the two virtual states by
at most eta in HALF trace norm, the bound becomes
  epsilon >= (1-D_n)/2 - eta.                              (2)
Equation (1) supplies an explicit finite collision bound in (2).

At theta=0.1, choose n=2896:
  v=0.7499945013409817,
  D(v)=0.25000549865901833,
  3u+(10/3)|w|+4|h|=3.6786862666822246e-12.
Hence any continuation after that exact virtual compression has
  epsilon >= 0.37499725066865147.
This is incompatible with the one-percent task despite allowing arbitrarily
many later collisions. If physical states approximate the virtual statistic
uniformly at two cuts, with per-input half-trace error eta, their target
distinguishability can increase by at most 4eta. In the weak limit the rise
from 1/4 to 1 therefore requires eta>=3/16.

No conclusion follows for a different two-qubit sufficient statistic. In
particular, this does not prove a memory lower bound for the fixed emitter.
It establishes that Bell-folding the reverse decoder, tracing spent carriers,
and treating its virtual bond as an online quantum memory is not a valid
physical construction, even when only the actual four-dimensional input
family is to be matched.

4. Independent weighted-chi-square diagnostic

For n>=1 and 0<theta<pi/2, sigma_n is full rank. The monotone quantity
  chi_n=Tr(delta_n^2 sigma_n^{-1})
has exact value
 [36h^2u+24h^2+9u^3-12u^2v-30u^2w+12u^2
  +16uv^2-24uv+5uw^2+12u+8v^2-12v+10w^2+6]
 /[6(1-u)(3u+1)].
In the same quartic limit this approaches 1-2v+(4/3)v^2, which drops to1/4
at v=3/4 and then rises to1. This is consistent with the simpler trace-norm
proof and is not needed for it.

5. Finite SDP diagnostic (not part of the proof)

crossed_extension_sdp.py asks for an arbitrary CPTP channel RAE->RA matching
every source-Pauli coefficient of every input-family basis state before and
after one virtual update. It does not restrict Kraus rank, ancillary purity,
or instruments (discarded/retained internal outcomes can be absorbed in the
channel; external retained classical records would change the target statistic).
At theta=.3 the first-step extension is feasible, matching constraints at
2.4e-15. The first-step Bell-initialized subspace admits an isometric extension,
so this is also analytically expected. SCS reports the second-step extension
infeasible (receiver input operator span rank13). CLARABEL encountered numerical
failure there. We do not use numerical infeasibility as a theorem or substitute
for a dual certificate. The analytic obstruction in Section3 suffices.

Numerical resources: fixed 8x8 virtual state recursions; one 32x32 Hermitian
Choi SDP for a channel 8->4, with CP and TP constraints. cvxpy1.9.3/CLARABEL
0.11.1/SCS3.3.1 were installed only in /tmp/weak_stream_deps for the diagnostic.
The verification of the closed form itself uses NumPy alone.

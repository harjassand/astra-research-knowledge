PURIFIED-DUMMY BLOCK COMPRESSION: EXACT GRAM AND SCALING OBSTRUCTION

This concerns the physical block reader that retains BOTH its dummy R and
accessible Bell purifier A. Each block of b chronological source outputs is
stored, a fresh Bell RA is prepared, the block is reverse-decoded using R,
the original b outputs are discarded, and RA is retained. Later blocks use
fresh Bell pairs. Any final joint decoder of every RA pair is allowed.

Notation: c=cos(theta),s=sin(theta), and
  u=c^(2b), v=(1-s^4)^b, w=[c^2(c^2-s^2)]^b,
  h=b c^(2b-1)s^3, a=1-v, d=sqrt[(1-u)(1+3u)].
The baseline joint source/output state is
  sigma=tau_S tensor omega_RA, omega=u Phi+(1-u)I/4.
The exact Pauli family delta_b for input Z/2 is in the companion proof.

1. The required metric is the SYMMETRIC PETZ GRAM

Define <X,Y>_sigma=Tr[X sigma^(-1/2)Y sigma^(-1/2)]. This is not the RLD
quantity Tr[X Y sigma^(-1)], which cannot substitute in Petz visibility.
Let P(X)=tau_S tensor Tr_S(X), Q=I-P. They are orthogonal in this metric.
Set p_b=<P delta_b,P delta_b> and q_b=<Q delta_b,Q delta_b>. The input norm
is one; p_b,q_b>=0 and p_b+q_b<=1 by data processing. The exact formulas are

  p_b = a^2/[2(1-u)] + (a^2+4h^2)/(2d),                    (1)
  q_b = (6u+v+5w)^2/[36(1+3u)]
       +[36h^2+27u^2-24uv-30uw+7v^2+10vw+10w^2]/[36(1-u)]
       +[36h^2+9u^2+12uv-30uw+4v^2-20vw+25w^2]/(36d).    (2)

Derivation: set P0=I_S tensor Phi_RA, P1=I-P0. For X=Pdelta, the traces
T00=Tr(P0 X P0 X), T11=Tr(P1 X P1 X), T01=Tr(P0 X P1 X) are respectively
  0, a^2/16, (a^2+4h^2)/32.
For X=Qdelta they are respectively
  (6u+v+5w)^2/288,
  [36h^2+27u^2-24uv-30uw+7v^2+10vw+10w^2]/288,
  [36h^2+9u^2+12uv-30uw+4v^2-20vw+25w^2]/576.
The Gram is 8[T00/(1+3u)+T11/(1-u)+2T01/d], proving (1)-(2).

2. Exact repeated-block law and arbitrary final-decoder converse

Baseline outputs are independent omega_RA's. Covariance makes the three
source-Pauli Gram matrices scalar, and product weights factor. Thus K equal
blocks give
  q_K=q_b^K, p_K=p_b(1-q_b^K)/(1-q_b).                    (3)
Old source-identity information is orthogonal to new export because the new
export has trace zero. Actual correlated output states need not factor.

The Petz recovery has qubit depolarizing visibility p_K and half-diamond
error 3(1-p_K)/4. EVERY decoder has the converse
  epsilon >= (3/4)(1-sqrt(p_K)).                          (4)
Indeed, F_j=C_K(sigma_j/2) has Gram p_K. For a decoder, Y_j=D^*(sigma_j)
obeys ||Y_j||<=1. Weighted Cauchy-Schwarz gives
  |Tr(F_j Y_j)|^2 <= p_K Tr(omega^(1/2)Y_j omega^(1/2)Y_j)
                 <= p_K Tr(omega Y_j^2) <= p_K.
Hence entanglement fidelity <=(1+3sqrt(p_K))/4, proving (4).

For unequal predetermined block lengths,
  p_K=sum_j p_{b_j}prod_{i<j}q_{b_i}
     <=max_j p_{b_j}/(1-q_{b_j}).
Combining many lossy blocks cannot exceed the best individual efficiency.

3. Weak-action scaling

For theta->0 and any positive integer b(theta)=o(theta^(-4)),
  p_b/(1-q_b) ->0.                                        (5)
Proof by the three possible subsequential regimes x=b theta^2:

(i) x->0: expansion gives p_b~b^(3/2)theta^5 and 1-q_b~2b theta^2,
so p_b/(1-q_b)~sqrt(b)theta^3/2 ->0.

(ii) x->x0 in (0,infinity): set U=exp(-x0). Then
  p_b=theta^2[2x0^2 exp(-2x0)/sqrt((1-U)(1+3U))]+o(theta^2),
  q_b->q0(U)<1,
where q0 is (2) with u=U,v=1,w=U^3,h=0. Strictness is algebraic. Put
  A=(5U^3+6U+1)^2,
  B=(U-1)^2(10U^4+20U^3-10U+7),
  C=(U-1)^2(5U^2+5U+2)^2.
Then q0=A/[36(1+3U)]+B/[36(1-U)]+C/[36sqrt((1-U)(1+3U))].
For T=36-A/(1+3U)-B/(1-U), T>0, and
  T^2(1-U)(1+3U)-C^2=4(1-U)^3 P(U)/(1+3U)>0,
  P(U)=475U^10+1675U^9+2500U^8-650U^7-2825U^6-545U^5
       +5590U^4+7600U^3+5092U^2+1632U+192.
The negative terms are bounded below by -4020U^4, so P>0 on (0,1).
This proves q0<1.

(iii) x->infinity while b theta^4->0: u,w,h->0,v->1, so p_b->0,q_b->1/3.
These cases also make (5) uniform for all b below any o(theta^(-4)) cutoff.

At quartic block size b theta^4->alpha>0,
  p_b->(1-exp(-alpha))^2, q_b->exp(-2alpha)/3,
  p_infinity->(1-exp(-alpha))^2/[1-exp(-2alpha)/3].         (6)
At fixed 0<theta<pi/2 and b->infinity the same expansion holds with
v=(1-s^4)^b: p_b=(1-v)^2+o(v^2), q_b=v^2/3+o(v^2).
Consequently the converse error is (3/4)v+O(v^2), while the Petz error is
(3/2)v+O(v^2). High accuracy still needs blocks on the original quartic
log(1/epsilon) scale. The accessible purifier does not supply the proposed
square-root-storage construction.

4. Operating point and scope

At theta=.1, p_b/(1-q_b) for b=1,100,1000,3000,10000,40000 is respectively
  .0005837458115202695, .0043146376416744675, .012305301900397279,
  .08135921424497877, .4154965705869547, .9628563212214019.
For b=100, p=.0024588950371461165, q=.4301039296102177,
loss=1-p-q=.5674371753526362, loss/export approximately230.76.

The proposed memory b+2N/b and O(N) block-processing bill therefore fail on
information retention at subquartic b, independently of compilation quality.
This result covers reverse-dummy block compression retaining R AND A, with
arbitrary final collective decoding. It does not cover other block
instruments, retained block modes, or general causal receiver representations.

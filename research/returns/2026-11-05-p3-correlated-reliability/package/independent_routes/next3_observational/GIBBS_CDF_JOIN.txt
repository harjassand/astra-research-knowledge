VERDICT
The old spectral/Palm/head-middle-tail construction is distribution-generic.
Its product-law uses are confined to static counting/conditional-failure
sampling, safe-equilibrium preparation, a bit-length mass floor, and the
original refresh-gap construction. The Gibbs replacements below suffice.
The hardest distinction is computational approximate initialization versus
changing the target physical initial law: only the former is repaired here.
The static Gibbs FPRAS and sampler remain subject to root's cut-enumeration
and finite-mixture proof; this note proves the join, not their whole theorem.

1. PRECISE GIBBS AND DYNAMICS PREMISES

Let pi(x)=w(x)/Z on {0,1}^m, w(x)=product_a phi_a(x_{S_a}), where all entries
of explicit factor tables are strictly positive rationals. Fix bounds on
factor arity and incidence for polynomial-time local extrema. Write
 q_i^- = min_{x_-i} pi_i(1|x_-i),
 q_i^+ = max_{x_-i} pi_i(1|x_-i),
and assume a fixed certified c>=1 with q_i^- >= (q_i^+)^c for every i.
This is a LOG-CONTRAST bound; no fixed q_i^+/q_i^- is assumed. Full support
ensures 0<q_i^-<=q_i^+<1. Root uses rational cut weights
 w_i <= -ln(q_i^+) <= 2w_i and C=ceil(2c).
B is undirected all-terminal disconnection;
A=B^c. Retain the exact target nu=pi(.|A), and the promise 0<p=pi(B)<=1/2.
Connected G and full support imply p>0 and a>0; p<=1/2 is a separate promise.

For i != j define the row-oriented Dobrushin influence
 C_ij = sup_{x,y differing only at j} TV(pi_i(.|x_-i),pi_i(.|y_-i)).
C_ii=0, and supply an exactly computed or certified rational upper bound
 max_i sum_j C_ij <= chi < 1.
This is a ROW sum with i the receiving/update coordinate. Standard Hamming
one-step path coupling often uses column sums; it is not the proof used here.

Let H_i f = E_pi[f | x_-i]. The physical or fitted operating generator is
 Q = sum_i kappa_i (H_i-I) + Q_extra,
where kappa_i>=kappa_min>0 and Q_extra is a sum of rational succinct local
moves each reversible with respect to this same Gibbs pi. Each added move
must preserve the declared pi, not a product proxy. A supplied independent
unconditional bit-refresh generator cannot simply be retained for correlated
pi; it generally violates detailed balance. The heat-bath backbone is an
actual part of Q. Adding it solely to aid proof changes the failure CDF.

There is no need to require the observed dynamics themselves be the sampler
used for static pinnings. The static sampler is a computational operation on
the explicit Gibbs model. Physical equilibrium preparation is separate.

2. EXPLICIT HEAT-BATH MIXING AND GAP, INCLUDING ARBITRARY PINNINGS

For random-scan H=(1/m)sum_i H_i, synchronously choose the update coordinate
and maximally couple its Bernoulli conditionals. Let d_i(n) be the probability
that coordinate i disagrees in two coupled copies after n steps. Telescoping
single-coordinate changes in a full conditional gives
 d_i(n+1) <= (1-1/m)d_i(n) + (1/m)sum_j C_ij d_j(n).
Consequently max_i d_i(n) <= [1-(1-chi)/m]^n when d_i(0)<=1.
A union bound, with one chain initially stationary, yields
 sup_x TV(H^n(x,.),pi) <= m [1-(1-chi)/m]^n
                         <= m exp[-n(1-chi)/m].                (J1)
This justifies the row-sum claim without exchanging row and column norms.

Every H_i is an orthogonal projection in L2(pi); hence H is self-adjoint and
positive semidefinite. If Hf=theta f and pi f=0, choose x with |f(x)|=||f||inf.
The total-variation estimate gives
 |theta|^n <= 2m[1-(1-chi)/m]^n.
Take n-th roots and n->infinity. Therefore
 gap(H) >= (1-chi)/m,
 gap(sum_i(H_i-I)) >= 1-chi.                                  (J2)
No pi_min factor is paid in this gap deduction.

For the operating generator, its Dirichlet form obeys
 E_Q(f,f) = sum_i kappa_i E_pi Var(f|x_-i) + E_extra(f,f)
          >= kappa_min sum_i E_pi Var(f|x_-i).
Every reversible extra move has nonnegative Dirichlet form, so
 gamma(Q) >= kappa_min(1-chi).                                (J3)
If a total update-rate r is spread uniformly over coordinates, kappa_i=r/m,
so gamma>=r(1-chi)/m. Omitting this factor m would overstate the gap.
Extra reversible moves can improve gamma, but can increase uniformization R;
the certified dimensionless g=gamma/R need not increase.

Pinning any subset of coordinates removes influence entries and restricts
the remaining supremum. Every pinned model has row sum at most chi. With k
free coordinates, (J1) holds with k in place of m if scanning only free sites;
the bound with m is a safe common bound. If k=0, output the pinned state.
Pinnings may have exponentially small prior probability: none appears in the
mixing bill because the sampler runs directly on the normalized conditional.

3. RATIONAL EXIT BOUND, UNIFORMIZATION, AND PSD

The heat-bath exit rate is at most sum_i kappa_i. If S_extra bounds the total
exit rates of the extra local tables, set
 R = 2(sum_i kappa_i + S_extra),
 g = kappa_min(1-chi)/R,
reducing g if necessary so g<=1. All are rational and succinct. The exact
P=I+Q/R is reversible and PSD; the Poisson construction in the old proof is
genuine uniformization of Q. Upper-bounding exit rates by local table maxima
avoids enumerating all 2^m states. Ordinary P transitions require only the
supplied local-factor evaluation and local-table access.

No modification of the old killed-spectrum argument is needed. Its
 j>=gpa, gp<=lambda_1<=j/a, lambda_2>=g, r/lambda_1<=1/(ag),
relative exponential tail, Palm identity, and reverse no-return identity use
only full-chain reversibility, PSD, the spectral gap, and the exact nu.

4. A GIBBS MASS FLOOR WITH POLYNOMIAL BIT LENGTH

Let l_a=min_s phi_a(s), u_a=max_s phi_a(s), computable from the explicit
positive tables. Define the rational
 zeta = 2^(-m) product_a(l_a/u_a).                            (J4)
Since w(x)>=product l_a and Z<=2^m product u_a, every pi(x)>=zeta.
If L is the total binary input length of the explicit table numerators and
denominators, both numerator and denominator of zeta have O(m+L) bits,
using ordinary rational multiplication. Hence log2(1/zeta)=O(m+L), regardless
of how small a rare field is. Constants in pinned factors must be retained
when computing their unnormalized partition functions.

A common denominator D can be formed by multiplying all input entry
denominators. Every full-state weight has denominator dividing D, so even
an exact pinned partition sum Z_C has O(m+L) numerator/denominator bits.
This is a representation bound, not a claim that exact counting is easy.
For a relative rounding tolerance d, a dyadic mesh of width <=d*zeta/4
uses O(m+L+log(1/d)) fractional bits and changes any positive event mass
by at most d/4 relatively. The necessary bit count follows by integer
comparisons with the exact rational zeta; no floating-point logarithm oracle
is required.

Any nonempty event has probability at least zeta. Under any feasible pinning
C, pi(x|C)=pi(x)/pi(C)>=pi(x)>=zeta for x consistent with C. Thus every
positive conditional event mass also exceeds zeta. This replaces exactly the
old product_i min(q_i,1-q_i) floor, including dyadic relative rounding. It
does not give a polynomial lower bound in VALUE, nor a direct rare-event
Monte Carlo algorithm. Arithmetic uses log(1/zeta), never a loop of length
1/zeta.

The all-failed state is a known member of B, and all-working is a known
member of A. They are valid finite-error fallbacks, not claims of stationarity.

It is sufficient to deliver these two finite subroutines on the ORIGINAL

 CountG(alpha,beta): with probability >=1-beta returns relative alpha
   approximation to p. Worst-case work polynomial in succinct input,
   alpha^{-1}, log(1/beta), (1-chi)^{-1}, at fixed log contrast c.
 SampleB(tau): ALWAYS returns a state in B, with unconditional output law
   within tau TV of pi(.|B). It has deterministic finite work and uses fresh
   randomness independently on repeated calls.

Then replace old PROOF.md Section 4.1 entirely by SampleB(tau_B). Do NOT
retain its product-bit self-reduction normalization. The direct Gibbs union
sampler makes the old contracted/deleted-prefix counting interface unnecessary

HEAVY-PREFIX PARTITION COUNTING REPLACES RARE-MARGINAL ESTIMATION.
The old normalization r_i/q_i^+ in [1/K,1] is unavailable in this stronger
class and must be removed. It is not needed. Here is a complete partition-
counting interface from the uniformly pinned Gibbs sampler alone.

For any feasible pinning C, let
 Z_C = sum_{x consistent with C} W(x), W(x)=product_a phi_a(x_{S_a}).
Given alpha in (0,1] and beta in (0,1), let d=alpha/(128m), for m>=1.
At each of at most m free-coordinate stages, draw
 M >= ceil[2*d^(-2)*ln(2m/beta)]
fresh samples from the current pinned model, each within d/2 TV, and use
the empirical next-bit frequency qhat. The implementation may upper-bound
the natural logarithm by ceil(log2(2m/beta)), keeping the schedule finite.
The sample-mean bias is <=d/2; Hoeffding makes its remaining deviation >d/2
have probability <=beta/m. These assertions hold conditionally on every
previous realized prefix. A conditional union bound therefore gives a
joint good event of probability >=1-beta despite adaptive prefix choices.

Choose the empirical heavier bit, with estimated mass
 hhat=max(qhat,1-qhat)>=1/2,
and pin that bit. On the good event its true conditional mass satisfies
 h>=1/2-d>=63/128>0.49, |hhat-h|<=d.
After the last stage a complete x* is known. For this realized path,
 pi_C(x*)=product_j h_j,
 Zhat_C=W(x*)/product_j hhat_j.
Because min(h_j,hhat_j)>=1/2-d,
 |ln(Zhat_C/Z_C)| <= m*d/(1/2-d) <= 3m*d = 3alpha/128.
Thus |Zhat_C/Z_C-1|<=alpha/16, with ample slack for a requested relative-alpha
output. Every estimated heavy mass is >=1/2 even off the good event, so this
subroutine always produces a positive rational after deterministic work.
For no free coordinates simply return W(x*). For m=0 use the same trivial
case. No inverse rare marginal, event mass, or state mass enters the cost.

A coarse update bill is
 O(m^4 * alpha^(-2) * (1-chi)^(-1)
   * log(m/beta) * log(m^2/alpha))
local conditional evaluations, obtained by inserting Section 6's sampler.
Store only a prefix, an m-bit state, running sample counts, and products.
Rational product lengths are O(L+m*log M); rounding can use the previous
zeta rule when a normalized event mass is formed. Do not discard constant
factors introduced by pinning: the identity requires the original W(x*).

For a cut event D (all crossing coordinates pinned to failure),
 pi(D)=Z_D/Z_empty.
Estimate numerator and denominator at relative tolerance e/8, with joint
failure allocation across all retained cuts and the common denominator.
Their ratio has relative error <=e/2 for e<=1, leaving another e/2 for
rounding. In mixture probabilities the common denominator cancels, but it
is needed for normalized union probability estimates. Sharing it WITHIN a
single SampleB call does not cause a problem; sharing random preprocessing
ACROSS the old CDF trials requires the conditioning treatment below.

A HIGH-PROBABILITY SAMPLER DESCRIPTION IS NOT YET THIS INTERFACE.
There are two valid conversion choices:
(a) Rebuild randomized cut enumeration and weights with fresh randomness for
    every SampleB call. Charge their internal failure probability as output
    TV, using the known failed state on detected failures. Unobserved bad
    preprocessing also contributes at most its probability to TV. Calls are
    then independent and the old bounded-mean proof applies unchanged.
(b) Reuse one randomized table. Allocate its bad-event probability explicitly
    to the outer delta budget, and establish uniform TV bounds conditional
    on every successful table. Subsequent trials are iid conditional on that
    table and can use conditional concentration. Unconditional iid claims
    are generally false after sharing the table. Root may use either option;
    (a) is the most direct finite-polynomial join.

For clarity, the large-cut union method can realize (a) as follows, assuming
root's enumeration theorem and its truncation bound. For target tau, retain
cuts whose omitted union probability is <=tau*p/8. Let J>=1 be the retained
count. On a good construction event, estimate every cut mass relatively to
 e=tau/(256J), use pinned draws within eta=tau/(128J) TV, and implement
categorical cut choice within eta_cat=tau/(128J) TV. Their mixture proposal
differs from the exact mass-weighted proposal by at most
 2e+eta+eta_cat =3tau/(128J)<tau/(32J).
The proposal remains supported on the retained union: each pinned draw
satisfies its cut. The acceptance probability 1/c(x), c<=J, is pointwise at
least 1/J. Conditioning amplifies TV by at most 2J, giving output error at
most tau/16 relative to the retained-union conditional law. Cap its trials
at ceil[J*ceil(log2(16/tau))]; the cap probability is <=tau/16. Return the
known failed state on cap exhaustion. Allocate total cut-enumeration/weight
failure probability <=tau/8. Finally TV(pi(.|retained union),pi(.|B)) equals
the omitted conditional mass, at most tau/8.

For the acceptance draw 1/c(x), use b-bit Bernoulli rounding with
 2^(-b)<=tau/(16L_cap), L_cap=ceil[J*ceil(log2(16/tau))].
Coupling every rounded accept/reject decision to the ideal rational decision
adds at most tau/16 TV. This avoids an unbounded exact-randomness primitive.
Categorical cut choice can use dyadic interval bins, costing at most
J*2^(-b_cat) TV; choose b_cat for the eta_cat allowance above. Every output
still belongs to B, including fallback. Total error remains <tau, with slack.
Mass rounding uses zeta; all random-bit, cut-membership, and list storage
costs are finite polynomial and belong in T_B.

In root's small-mincut branch, p>=p0 with p0^{-1} polynomial in v at fixed c.
A Gibbs draw error O(tau*p0) is enough before rejection on B; its mixing cost
is logarithmic in (tau*p0)^{-1}. Rejection and probability-estimation costs
may include p0^{-1}, which is polynomial in that branch. An unqualified TV
error O(tau) before rare-event conditioning would be insufficient.

6. FINITE PINNED GIBBS DRAWS WITH NO HIDDEN EXACT-RANDOMNESS ORACLE

A concrete implementation for unconditional or pinned stationary draws with
TV tolerance eta is:
 n = ceil[(m/(1-chi))*ceil(log2(2m/eta))].
Start free bits deterministically and run n random-scan heat-bath steps. The
ideal mixing error is <=eta/2 by (J1). Evaluate each full conditional exactly
as a rational from the local factors. Round its Bernoulli probability to a
dyadic b-bit number. Also approximate a uniform free-coordinate choice by
mapping a uniform b-bit integer into k coordinate bins. Per-update TV error
is at most (m+1)2^(-b), a conservative bound. Choose
 b >= ceil(log2(2n(m+1)/eta)).
Telescoping kernel coupling bounds accumulated implementation error by eta/2.
The output is within eta TV of the pinned Gibbs target with a deterministically
bounded number of updates and random bits, and cannot violate a pinning.
This introduces no failure event. Cost is O(n) local conditional evaluations
and O(n b) random bits, plus polynomial rational-bit operations.

Using exact rational categorical draws with capped binary rejection is an
alternative. If so, its caps must be charged explicitly. The bounded dyadic
version above is simpler for internal Gibbs mixing.

7. APPROXIMATE SAFE PREPARATION: THE HARDEST CDF INTERFACE

Keep the old

Reject until it is safe. Since a>=1/2 and eta_eq<=1/4,
 mu(A)>=1/2-eta_eq>=1/4.

 TV(mu(.|A),pi(.|A)) <= 2 eta_eq/a <=4 eta_eq
                                      =xi*q0/32.             (J5)
For E subset A, write the conditional-probability difference with denominator
a and use |mu(E)-pi(E)|<=eta_eq, |mu(A)-a|<=eta_eq. This proves the factor 2/a.
Independent attempts produce the same accepted law; no p^{-1} is involved.

Charge this only to the direct-simulation bounded indicator's mean. Its ideal
mean F(u) is >=1/3 whenever the hybrid chooses direct simulation. The new
bias is at most
 4eta_eq+tau_P <=3xi*q0/64 < xi*q0/8.                         (J6)
The other old bias bounds remain:
 Palm: 4tau_B/g+tau_P+h_W <=xi*q0/16;

The common q0 mean floor and the old biased-mean lemma therefore apply without

At arbitrarily small u, the algorithm uses the boundary-derived slope j/a,
not approximate safe-start simulation. Thus (J5) does not generate a fixed
additive error floor in the announced CDF at u->0. This is why an absolute-TV
computational sampler suffices even though the final certificate is relative
at every positive deadline.

THIS DOES NOT CERTIFY A DIFFERENT PHYSICAL INITIAL LAW.
If the real device starts from a distribution only known within eta TV of nu,
the true first-failure CDF can differ additively by eta. A fixed such error
need not be relatively small as t->0. Retain the old physical initialization
limitation. The target theorem is about exact nu; approximate computational
samples estimate bounded identities for that target.

9. WORK, MEMORY, AND UNIFORM-DEADLINE CONSEQUENCE

Let T_B(tau_B) be the fully finite Gibbs conditional-failure sampler work,
and T_eq(eta_eq) the Section 6 unpinned Gibbs work. Replace the old prefix-
Count and product-initialization costs by
 O(N(2+G*C_B))*T_B(tau_B)
 +O(N*G*C_A)*T_eq(eta_eq),
plus the original ordinary P-update, failure-predicate, Poisson-table, grid,
rounding, and query arithmetic costs. The initial count cost is
 T_CountG(xi/8,delta/8).
These are polynomial at fixed c, fixed factor arity/incidence, inverse
Dobrushin margin, g^{-1}, epsilon^{-1}, log(1/delta), and input bit length.
The claim is NOT polynomial in the value of variable c: v^{O(c)} is a
parameter dependence in root's static construction. Likewise an exponentially
small physical gap still costs exponentially much through g^{-1}.

Safe preparation uses only log(1/eta_eq) extra bits and mixing time; no
inverse-p factor appears. Static rare quantities may have exponentially many
zero bits after the binary point, but their description/rounding bill is
polynomial via log(1/zeta). Rejection caps, cut lists, and proposal-count scans
must remain included inside T_B. Memory is finite polynomial in those explicit
cut lists and the prior certificate/Poisson tables; no 2^m state table is
silently allocated.

The prior proof's finite set of successful confidence inequalities then
covers every positive rational deadline at once. All head, interpolation,
and rare/nonrare tail ratio calculations are unchanged. The outward evaluator
for 1-exp(-lambda*R*t) remains polynomial in the binary deadline length and
certificate size, with no new trajectories at query time. An approximate
Gibbs sampler does not add a separate per-query failure probability.

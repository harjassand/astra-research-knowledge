The product-state Berry–Esseen theorem of Cramer, Brandão, Guţă, Alhambra, and Scandi gives a rigorous \(O(n^{-1/2})\) approximation to the energy distribution under the required extensive-variance condition. Here that variance is exactly \(3(n-1)/4\). :chatgpt-content-reference{index="1"}

Applying that theorem yields

\[
\frac{\operatorname{rank}A_x}{2^n}
\le
\min\left\{
1,\,
\frac{4w}{\sqrt{6\pi(n-1)}}+\frac{2K_{\mathrm{BE}}}{\sqrt n}
\right\}.
\]

For fixed \(w\), this saves

\[
\frac12\log_2 n-O(1)
\]

qubits per block. The theorem’s constant is not assigned an invented numerical value. The elementary construction above avoids it entirely.

## 4. The memory consequence that is actually earned

A memory saving at a fixed collision count would be insufficient if compression required so many extra collisions that the total storage increased. The following comparison includes that acquisition cost.

Fix \(0<\epsilon<3/4\), and define

\[
e=\frac{4\epsilon}{3},
\qquad
L=\log\frac1e,
\qquad
p_n=\frac{16\pi^2}{n(n-1)}.
\]

Choose a fixed integer \(n\) satisfying

\[
p_n<\frac e2,
\qquad
n>\frac{4224\pi^2}{eL}.
\]

This \(n\) depends on the target error and is fixed before taking \(\theta\to0\).

For sufficiently small angle, choose \(N\), rounded upward to a multiple of \(33n\), so that

\[
r^N\le\frac{e-p_n}{1-p_n}.
\]

The receiver then achieves the target error, and

\[
\boxed{
\limsup_{\theta\to0}
\sin^4\theta\,M_{\mathrm{core}}
\le
\left(1-\frac1{33n}\right)
\log\frac{1-p_n}{e-p_n}
\le
L-\frac{L}{66n}
<L.
}
\]

The store-all inverse reader has leading memory coefficient \(L\). Thus this is a strict improvement against that explicit benchmark.

For finite control, use ideal target \(\epsilon-\nu(\theta)\), where \(\nu(\theta)\to0\). The strict limiting inequality survives. At fixed block size, fixed primitive gate times, and fixed arrival spacing, the precision overhead produces only polylogarithmic additional circuit-service storage, which is \(o(N)\).

**The scope of the improvement is narrow but definite:**

- It works at arbitrarily small fixed target error.
- It pays for the extra acquisition used to offset compression loss.
- It preserves quartic weak-angle memory scaling.
- It compares with the explicit store-all inverse reader, not with the unknown optimal receiver.
- Its explicit constants are conservative and can certify only a very small saving.

It also establishes a concrete distinction between two operations emphasized in your question. The receiver can reduce stored dimension by a fixed positive fraction at fixed error as \(\theta\to0\) **after coherent block processing**. The preserved law for independent erasure **before receiver access** still requires loss probability of order \(\epsilon\theta^2\) in the weak-angle, high-accuracy regime. The compressor does not violate or replace that law.

## 5. The processing and protection costs

The construction is a complete logical circuit operation, but its present resource guarantee is expensive.

| Resource | Guaranteed accounting |
|---|---|
| Retained compressed data | At most \(N-N/(33n)\) qubits for complete groups |
| Collection and unpacking | \(O(n)\) coherent cells per active processor, including flags and dummy |
| Encoder and support decoder | Generic \(2^{O(n)}\) addressed gates per 33-block group |
| Reverse recovery sweep | Exactly \(N\) inverse collision gates; the dummy creates a sequential dependency |
| Classical record | One binary outcome per block, plus the finite compiled control description |
| Finite gate set | Polylogarithmic precision overhead for a specified total synthesis-error budget |
| Service backlog | All additional processors or coherent queues are counted |
| Preparation and protection | Required for every live data, routing, flag, and work cell throughout its actual lifetime |

The general gate-existence and compilation machinery is standard: arbitrary finite-dimensional unitaries can be synthesized from elementary gates, and a finite universal gate set permits polylogarithmic precision overhead. This establishes finite implementability; it does not establish an efficient exchange-energy basis transform. :chatgpt-content-reference{index="2"}

More explicitly, if carriers arrive every \(\Delta\) and one packed encoder takes time \(\tau_{\mathrm{enc}}\), provision

\[
P=
\max\left\{
1,\left\lceil
\frac{\tau_{\mathrm{enc}}}{33n\Delta}
\right\rceil
\right\}
\]

processors, or an equivalent coherent queue. That adds \(O(Pn)\) coherent cells, with routing charged separately.

A channel hybrid bound allows preparation, gate, and storage errors to be allocated a combined budget \(\nu\). For example, \(G\) elementary operations each having half-diamond error at most \(\nu/G\) contribute at most \(\nu\) in total, before allocating any separate storage-error budget.

**No hardware-independent protection cost has been proved.** A noisy-device implementation must add the physical cells, gates, and time needed to meet these logical error budgets. The memory advantage above is a logical core-and-service statement under its stated circuit assumptions. It is not yet a physical-cell advantage for an unspecified noisy architecture.

## 6. The strongest unrestricted result: an exact acquisition-loss identity

Alongside the construction, the most useful general result is an exact identity that holds for **every permitted causal receiver**, including nontracial initialized workspace, arbitrary instruments, and unlimited classical feedback.

At tracial logical input, the actual source–receiver reference state always factors as

\[
\mathcal N_j(I/2)=I_S/2\otimes\sigma_j.
\]

This remains true within each classical-history branch. It does not assert independence for other inputs or for an entangled logical input.

Balance the three logical Pauli images against this changing reference state. Let \(a_j\) be their average squared norm in the source-identity sector and \(q_j\) the corresponding norm in the source-traceless sector. These are information quantities; \(q_j\) is not a qubit count.

Initially,

\[
a_0=0,\qquad q_0=1.
\]

There are nonnegative physical processing losses \(\ell_j^P,\ell_j^Q\) such that

\[
a_j=a_{j-1}+s^4q_{j-1}-\ell_j^P,
\qquad
q_j=rq_{j-1}-\ell_j^Q.
\]

Therefore

\[
\boxed{
a_N=1-r^N-L_N,
}
\]

where

\[
\boxed{
L_N=
\sum_{j=1}^{N}
\left[
\ell_j^P+
(1-r^{N-j})\ell_j^Q
\right]\ge0.
}
\]

The weights have an operational interpretation. Destroying information already acquired by the receiver costs its full amount. Destroying a component that remains associated with the source costs the fraction that could otherwise have been acquired during the remaining collisions.

The positivity follows from contraction of the changing-reference Hilbert norm under CPTP maps. This uses established monotone quantum \(\chi^2\) machinery, including the contraction theorem of Temme and collaborators. The source-specific sector decomposition and weighted identity are the deductions here. :chatgpt-content-reference{index="3"}

### Its recovery meaning is quantitative

Every final decoder obeys

\[
\boxed{
\epsilon_{\mathrm{opt}}
\ge
\frac34(1-\sqrt{a_N}).
}
\]

A physical global Clifford-twirled implementation of the receiver, finished with its Petz decoder, achieves

\[
\boxed{
\epsilon_{\mathrm{Petz,twirl}}
=
\frac34(1-a_N)
=
\frac34(r^N+L_N).
}
\]

The two bounds differ by a factor of at most two. General comparisons between optimal and pretty-good entanglement recovery are established in Renes’s work; the report also supplies a direct proof of the constants in this normalization. :chatgpt-content-reference{index="4"}

Thus, for target error \(\epsilon\), a necessary condition is

\[
L_N
\le
1-r^N-\left(1-\frac{4\epsilon}{3}\right)^2,
\]

while a sufficient condition, with the physical Petz-twirled finish, is

\[
r^N+L_N\le\frac{4\epsilon}{3}.
\]

This converts the full endpoint into a precise control problem: **how little weighted loss can a causal receiver attain at a given coherent width and processing budget?** The identity answers how to evaluate a receiver. It does not yet solve that optimization.

### A general memory-duration consequence

The same framework proves a quantum-retention bound. Define

\[
C_\epsilon=4\epsilon-\frac83\epsilon^2,
\]

and let \(\pi_j\) be the probability that a receiver branch retains at least one coherent qubit at cut \(j\). Then

\[
\pi_j\ge
\left[
1-C_\epsilon r^{-(N-j)}
\right]_+.
\]

For equal collision spacing \(\Delta\), this yields a necessary expected qubit-time of at least

\[
\Delta
\sum_j
\left[
1-C_\epsilon r^{-(N-j)}
\right]_+.
\]

For sufficiently long horizons and small error, its order is

\[
\Omega\!\left(
\Delta\,\theta^{-4}\log(1/\epsilon)
\right).
\]

This constrains how long quantum information must remain protected. It does not determine the peak number of qubits.

## 7. What remains unresolved

The two central scaling gaps remain open.

**At fixed nonzero angle**, the preserved general converse gives

\[
q_{\mathrm{peak}}
=
\Omega_\theta\!\left(
\frac{\log(1/\epsilon)}
{\log\log(1/\epsilon)}
\right).
\]

At the natural acquisition horizon, this is \(\Omega_\theta(N/\log N)\), versus the \(O(N)\) storage upper bound. The logarithmic gap is still present.

**At weak angle and fixed error**, the new compressor improves one explicit leading coefficient, but does not determine whether an unrestricted causal receiver can achieve substantially smaller-order memory.

## Logical memory is not a free physical-cell advantage

The [energy compressor](README.md) retains at most `N-N/(33n)` data qubits for complete groups, plus O(n) core collection/unpacking cells. Generic encoder/support-decoder circuitry requires **`2^O(n)` addressed gates per 33-block group**. Reverse recovery uses exactly N inverse collisions with a sequential dummy dependency. Classical outcomes, finite gate descriptions, routing, preparation and every storage lifetime are paid.

At arrival spacing Delta and encoding service time tau_enc, the sufficient processor count is `P=max(1,ceil(tau_enc/(33n Delta)))`, or an equivalent coherent queue. This adds O(Pn) cells, with routing separate. Finite universal-gate precision overhead is priced by a total channel budget, with storage/protection additional. For fixed target block size, the stated weak-angle limiting service overhead can be lower order than N; that is not an economical circuit or a hardware-independent noisy-cell guarantee.

No efficient exchange-energy basis transform or universally cheap memory protection is proved. The arbitrary-accuracy all-angle construction can be less economical than storage at fixed angle. The unrestricted optimum still requires an attainable bound on minimal weighted loss at specified coherent width **and** processing budget, uniform in angle/error/count.

EXACT RETAINED-CARRIER LAW FOR THE HOMOGENEOUS TRACIAL STREAM
Research derivation, 5 November 2026. This is a boundary calculation inside
the selected causal-recovery question, not its resolution.

1. Contract
An arbitrary source qubit, including any reference, interacts with N fresh
independent I/2 carriers by U=c I+i s SWAP, c=cos(theta), s=sin(theta).
The final source is discarded. A subset A of carriers is retained intact;
the others are erased before receiver processing. The pattern is supplied
as a classical flag. No inaccessible purifiers or input keys are supplied.
Subsequent decoding on every retained carrier is unrestricted.

Errors are half diamond distances. Let b=s^4 and d=c^4.

2. Exact recurrence and a physical receiver
Set q_0=1, a_0=0. In chronological order,
  retained j: a_j=a_(j-1)+b q_(j-1), q_j=(1-b)q_(j-1);
  erased j:   a_j=a_(j-1),          q_j=d q_(j-1).

The retained-output channel C_A has a physical transpose/Petz decoder D_A
such that D_A C_A=a_N id+(1-a_N)R_(I/2), exactly. Therefore
  delta(D_A C_A,id)=3(1-a_N)/4.
For every decoder R,
  delta(R C_A,id)>=3(1-sqrt(a_N))/4.
The explicit receiver is within a factor two of this all-decoder bound.

D_A starts a mixed dummy qubit, traverses the actual schedule backwards,
applies U^dagger to each retained output at its original position, and at
each erased position applies the dummy depolarizing channel with visibility
c^2 (implemented using a fresh mixed qubit, inverse partial SWAP, discard).
It then returns the dummy. This is output-only and uses no actual source.

Proof of the recurrence. In normalized Hilbert-Schmidt inner products,
propagate a source Pauli under the source circuit and immediately trace each
erased carrier; this is equivalent to the final erasure since it never
returns. Split the operator into a source-identity P part and orthogonal Q
part. Old P is unchanged. For a retained fresh carrier, projection of each
traceless source coefficient X is s^2 I_source tensor X_carrier, orthogonal
to old P. Its squared norm is b times the old Q norm; the remaining Q norm
is multiplied by 1-b. For an erased fresh carrier the partial trace leaves
c^2 X, multiplying Q squared norm by d, and no new P. The recurrence holds
for every Pauli and all their linear combinations, including spectator
coefficients. Polarization gives the retained Gram scalar a_N. Because the
maximally mixed input produces a maximally mixed retained output, its Petz
decoder is its dimension-normalized adjoint. The reverse schedule above is
exactly this adjoint. Composition is the stated depolarizing channel.

For the converse, normalized retained operators B_k have squared tracial
norm a_N. Thus ||C_A(sigma_k)||_1<=2 sqrt(a_N). Any decoder is trace-norm
contractive, so its entanglement fidelity is <=(1+3 sqrt(a_N))/4. Testing the
normalized Choi state against the Bell projector gives the half-diamond
bound. Equivalently one can apply Renes's sharper transpose-recovery bound
to the computed Gram value. This recovery inequality is established prior
machinery, not a new general inequality here.

3. Independent flagged loss
Let each carrier be retained with probability p independently of the input
and of other erasures. Define f=p(1-b)+(1-p)d. Independence gives
  a_bar_N=p b (1-f^N)/(1-f).
The flagged branchwise Petz receiver has depolarizing visibility a_bar_N
and error 3(1-a_bar_N)/4. Every decoder of the entire flagged output obeys
  error>=3(1-sqrt(a_bar_N))/4.
Indeed the average of sqrt(a_N) is <=sqrt(a_bar_N). These are unconditional
channel statements, including the classical loss pattern.

Writing ell=1-p and g=1-c^4, the limiting visibility is
  a_bar_inf=(1-ell)b / ((1-ell)b+ell g).
For weak theta, g~2theta^2 and b~theta^4. If ell=k theta^2 with fixed k,
  a_bar_inf -> 1/(1+2k).
If ell/theta^2 diverges, both error bounds approach 3/4. Arbitrarily many
collisions do not recover the unknown state at any fixed nonzero loss
probability in the weak-angle limit.

For epsilon<3/4, set A_e=(1-4epsilon/3)^2. A necessary asymptotic condition
is ell <= (1-A_e)b / (A_e g+(1-A_e)b). A sufficient condition to have a
strictly smaller asymptotic Petz error than epsilon uses t=4epsilon/3:
  ell < t b / ((1-t)g+t b).
Strict inequality leaves a positive finite-N margin. Both conditions scale
as ell=Theta(epsilon theta^2) for small epsilon and theta. For a finite
margin, N is obtained exactly from
  (3/4)[1-a_bar_inf+a_bar_inf f^N] <= epsilon.

4. Optimal subset under an intact-carrier budget
For any fixed budget of m retained unprocessed carriers among N>=m rounds,
the recurrence a_N is maximized by retaining the first m. Exchange an
adjacent (erase,retain) pair for (retain,erase): a increases by b(1-d)q,
and the subsequent q is unchanged because d(1-b)=(1-b)d. Repetition moves
all retained positions first. Hence
  a_N <= 1-(1-b)^m.
Every arbitrary final decoder therefore has error at least
  (3/4)[1-sqrt(1-(1-b)^m)].
For epsilon<3/4 it necessarily needs
  m >= log[1/(1-(1-4epsilon/3)^2)] / [-log(1-b)].
The first-m reverse receiver achieves epsilon when
  m >= log[3/(4epsilon)] / [-log(1-b)].
The collision/retained-carrier scale is consequently Theta(theta^-4
log(1/epsilon)). Independent randomization over patterns with at most m
retentions cannot improve this bound. This statement does not cover
state-dependent instruments or coherent compression before discarding.

5. Implementability and limits
The retained-only recovery still stores every selected carrier. Mixed
replacement preparations at erased reverse positions, inverse gates,
routing, calibration and memory protection must all be paid. A local FIFO
layout may incur quadratic routing; a LIFO stack or direct-address memory
can implement the abstract inverse circuit in linear addressed operations.
Any actual preparation, gate, route and memory error is charged through a
whole-channel half-diamond hybrid sum. These costs are not a scalable
fault-tolerant hardware construction. Loss here is flagged before receiver
access. It is not mathematically interchangeable with a general receiver
measuring, coherently processing, then discarding a carrier.

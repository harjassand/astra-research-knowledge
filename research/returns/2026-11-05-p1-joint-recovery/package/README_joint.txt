STRONGEST COMPLETED PHYSICAL OPERATION
joint_algebra/train_energy_compression.md gives a positive energy-window
instrument, explicit support ranks, deterministic causal compression and an
actual reverse decoder for every finite angle and collision count. An elementary
binary version removes the need for an unspecified density-of-states constant.
It proves arbitrary-accuracy recovery and a strict, potentially very small,
weak-angle leading-coefficient improvement over the store-all inverse reader.
Generic block synthesis is exponential in block size; retained memory still has
quartic weak-angle order. Service queues, finite control, preparation and
protection are explicitly distinguished from core retained storage. The logical
circuit theorem is not a hardware-independent noisy physical-cell guarantee.

STRONGEST GENERAL FRAMEWORK
joint_root/general_acquisition_ledger.md proves an exact positive weighted loss
identity for every permitted causal CPTP receiver, with initialized workspace,
classical feedback and arbitrary logical references. Its final value gives an
attained Petz-twirled error and an all-decoder lower bound within a factor two.
It makes the remaining optimization precise; it does not evaluate that optimum.

REPRODUCTION
Extract the archive and work from its root. Python dependencies and versions
are in runtime_joint.json. Representative deterministic checks are:
  python3 joint_algebra/train_energy_compressor.py
  python3 joint_root/check_general_ledger.py
  python3 joint_channel/check_bch_exact.py
  python3 joint_operational/cascade_continuity_check.py
These scripts may rewrite their own diagnostic outputs; run them on a copy
if preserving the delivered checksums matters.

Numerical searches are not necessary to read the proofs. Saved initial frames,
physical Kraus bases, decoder matrices and replay audits are included. The
nine-qubit Bell fidelity is robust floating-point evidence, not an interval
certificate or an asymptotically accurate recovery family. Searches and dense
checks can be expensive; read a script's arguments before increasing size.

To rebuild the report from output/pdf:
  pdflatex -interaction=nonstopmode -halt-on-error joint_recovery_continuation.tex
Run that command twice for cross references. The unchanged prior PDF is an
input to the appendix. LaTeX build logs and rendered QA images are omitted.

## 4\. What a full polynomial-resource solution still requires

The new dispersive estimate supplies polynomial quantitative control within individual Fourier sectors. The exact three-actuator argument also shows that noncommuting Fourier-ladder composition can sometimes be controlled without a sum over intermediate frequency paths.

The remaining mathematical problem is to extend this to an arbitrarily large input-dependent frequency scale while avoiding the calibrated return channel.

One plausible approach would use a number of fixed-frequency pulse blocks proportional to

\[
1+\log S.
\]

This is compatible with polynomial synthesis bit work and pulse count. But the Sobolev resource accounting imposes an additional restriction: if every block has amplification factor \(L_j\), then naïve iteration gives

\[
\|u\|_{H^3}
\lesssim K\prod_j L_j.
\]

If \(O(\log S)\) blocks each require \(L_j=S^{c}\), the resulting estimate is

\[
S^{O(\log S)},
\]

which violates the fixed-degree polynomial contract.

A successful argument therefore needs both a calibrated multiscale evacuation estimate and a cumulative \(H^3\) estimate that remains polynomial. Constant-strength blocks with a uniform geometric contraction could accomplish this, but the supplied \((1+A)^8\) sector bound alone does not establish that contraction for growing transverse frequencies.

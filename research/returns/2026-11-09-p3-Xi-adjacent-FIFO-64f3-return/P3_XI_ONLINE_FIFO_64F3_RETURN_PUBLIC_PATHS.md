## Result: the full online FIFO record-fabric theorem is not yet established

The stated requirements do not yield an immediate impossibility. In particular, independent unit-rate Poisson arrivals, finite buffers, and exponentially long operating horizons are compatible with the requested scaling.

I can establish the following queue-capacity result, which separates ordinary traffic overload from the harder noisy-control problem.

### 1\. Finite reusable buffering can handle the live arrival streams

Consider a reference FIFO with arrival rate \(1\), service rate \(\mu>1\), and capacity \(B_L\)\. Start it empty and declare overflow if an arrival would exceed capacity.

For an infinite-capacity reference queue, each busy excursion starting at occupancy one reaches level \(B_L\) before returning to zero with probability

\[
p_{\mathrm{hit}}
=\frac{\mu-1}{\mu^{B_L}-1}
\leq \mu^{1-B_L}.
\]

There are at most \(N_T\) busy-excursion starts by time \(T\), where \(N_T\) is the unit-rate Poisson arrival count. Consequently,

\[
\Pr(\text{overflow before }T)
\leq T\mu^{1-B_L}.
\]

For \(L^2\) independent arrival streams, a union bound gives

\[
\boxed{
\Pr(\text{any overflow before }T)
\leq L^2T\mu^{1-B_L}.
}
\]

Choose, for example,

\[
B_L=\left\lceil L^2+4\log_\mu(L+1)\right\rceil.
\]

Then, for computable constants \(C_1,c_1>0\),

\[
\Pr(\text{any overflow before }T)
\leq C_1T e^{-c_1L^2}.
\]

The total buffer capacity is \(O(L^4)\), polynomial in system size, and buffers are recycled indefinitely.

This establishes a reference-queue probability bound, **not** a physically fault-tolerant implementation. It shows that Poisson traffic alone does not force infinite storage or a shrinking input rate.

### 2\. A physical fault can have a geometrically bounded damage cone without counters

There is a simpler containment mechanism than maintaining protected record indices.

Consider an autonomous capacity-one transducer. Its state is an empty slot or one stored bit. A local Poisson service proposal of rate \(\mu\) emits the stored bit, if present, and resets the slot. Fault proposals can arbitrarily corrupt its finite local state; the next nominal service proposal still clears that state.

For a fault at time \(s\), let \(S\) be the waiting time to the next service proposal. Then

\[
S\sim\operatorname{Exp}(\mu).
\]

Let \(N\) be the number of source arrivals during that waiting time. Since arrivals have rate one,

\[
\boxed{\Pr(N\ge r)=(1+\mu)^{-r}.}
\]

An isolated state fault can therefore affect at most the previously held record, the \(N\) intervening arrivals, and one subsequent emitted record. Its damage ends at the next service proposal, without consulting an index, counter, acknowledgement, or global phase.

This gives an actual clock-to-record witness: **one state fault has a geometrically tailed number of potentially damaged records**\. Other faults can occur during the same interval, but none can prevent the scheduled nominal clearing transition in this transducer.

The important distinction is that this is a short-range autonomous transducer, not yet a proof for a growing-distance communication channel.

## 3\. A complete construction for the literal geometric specification

There is an important distinction in the statement: **it does not impose a growing physical distance between the input and output faces**\.

That permits an \(L\times L\times2\) slab. Its input and output ports occupy opposite faces, but corresponding ports are nearest neighbours.

For this geometry, a capacity-one architecture gives a positive construction. It does not require the previously supplied stabilizing-link machinery.

I will distinguish this literal result from the substantially stronger growing-distance problem at the end.

### Device and local rules

At each \((x,y)\in\{1,\ldots,L\}^2\), place two neighbouring sites\:

\[
(x,y,0)\longleftrightarrow(x,y,1).
\]

The first is the input site; the second is the output site.

Each module has physical state

\[
(B,M)\in\{\varnothing,0,1\}\times\{0,1\}.
\]

Here \(B\) is a capacity-one record buffer and \(M\) is a faultable output-mask bit. Neither field stores a record index.

The nominal operations are\:

**Arrival.** At every external unit-rate Poisson arrival, if \(B=\varnothing\), capture the presented bit with independent probability \(1-\delta\), or its complement with probability \(\delta\)\. If the slot is occupied, discard the new record. The arrival event itself is never delayed.

**Service.** An independent local Poisson proposal clock of rate \(\mu\) operates continuously. If \(B\) contains a bit, emit

\[
B\oplus M\oplus Z,
\qquad Z\sim\operatorname{Bernoulli}(\delta),
\]

at the corresponding output port. Whether occupied or empty, the service transition then sets

\[
(B,M)\gets(\varnothing,0).
\]

Fault proposals may arbitrarily change either physical state field, and may affect neighbouring modules when their templates span them. They cannot change the fixed nominal generator itself: that is the distinction between a local state fault and a generator perturbation in the specified model.

The input and output rules are noisy. Every stored state field is faultable. There is no separate phase counter, clock register, router, acknowledgement channel, or persistent logical label.

### Explicit parameters

Let \(R\) denote the fixed microscopic fault-template radius. Since it is independent of \(L\), the surface modules can be partitioned into an absolute number \(D\) of colours such that no fault template meets two modules of the same colour. For example, a sufficiently generous choice is

\[
D=(2R+3)^2.
\]

Define the positive rational number

\[
\zeta=\frac{q^{16D}}{10^6},

and choose

\[
\boxed{
\begin{aligned}
\epsilon_0&=\zeta/10,\\
\delta&=\zeta,\\
\mu&=\zeta^{-2},\\
\ell_L&=\zeta,\\
t_0&=0.
\end{aligned}}
\]

All these values are finite and computable from \(q\), with \(D\) an absolute constant of the fixed local fault model.

The initial state is the product state \((\varnothing,0)\), subject to the stipulated independent local reset errors. No encoded initialization is required.

The device has exactly \(2L^2\) sites and constant local alphabet. Its compiler writes \(L^2\) copies of the same finite rule table, with \(O(L^2)\) layout complexity for fixed \(q\)\.

### The matching

For the proof only, associate a semantic origin with a captured input. This origin is never stored in the device.

Call a record *certifiably clean* if it was captured after a nominal clearing transition with no intervening fault, its capture bit was correct, it experienced no local fault before emission, its emitted bit was correct, and its service delay was at most \(\zeta\)\.

Match exactly these clean emissions to their originating inputs. Leave every other output unmatched and designate it bad. Designate as bad any defective or deleted input whose failure is determined by the horizon, and every input arriving by \(T-\zeta\) that lacks its required timely match.

Because a module holds at most one record and clears it at emission, this matching is causal, injective and order-preserving. No good output has a cross-port or incorrect predecessor.

The problem is now to prove the requested probability bound for this actual matching.

### 4\. Joint bound for arbitrary input indices

Let \(A_j\) be the \(j\)\-th input time at one port, with \(A_0=0\)\.

For each interarrival interval

\[
I_j=(A_j,A_{j+1}),
\]

declare \(H_j\) if the following all happen\:

- The interval lasts at least \(h=\zeta\)\.
- A nominal service proposal occurs during its first \(h\) units.
- No fault proposal touching either site of the module occurs anywhere in the interval.

The total fault-proposal intensity touching one module is at most

\[
\kappa\leq2\epsilon_0=\zeta/5.
\]

By the exponential interarrival law and independent Poisson increments,

\[
\begin{aligned}
\Pr(H_j^c)
&\leq (1-e^{-h})+e^{-\mu h}+\kappa\\
&\leq h+e^{-1/\zeta}+\zeta/5\\
&\leq3\zeta.
\end{aligned}
\]

The interval events \(H_j\) are independent for different \(j\) at a given port. They are also independent across modules of the same fault-template colour.

If \(H_{j-1}\) and \(H_j\) occur, the slot is clean and empty when input \(j\) arrives, and that record is serviced within \(h\), with no intervening fault. Only its independent capture and read coins can still spoil it.

Consequently, writing \(B_j^{\mathrm{in}}\) for the event that input label \(j\) is bad,

\[
B_j^{\mathrm{in}}
\subseteq
H_{j-1}^{c}\cup H_j^{c}
\cup C_j\cup R_j,
\]

where \(C_j,R_j\) are the respective capture/read-noise witnesses, each with probability \(\delta=\zeta\)\. For \(R_j\), use the read mark of the first service proposal in interval \(I_j\), padding missing proposals with unused independent marks.

For any \(r\) distinct selected input indices within one colour, choose one of these four witnesses for each selected index. Every interval witness can cover at most two selected input indices, while a capture/read witness covers only its own index.

Thus every assignment of witnesses contains at least \(\lceil r/2\rceil\) distinct independent primitive witnesses. A union bound gives

\[
\boxed{
\Pr(\text{all }r\text{ selected inputs bad})
\leq(4\sqrt{3\zeta})^r.
}
\]

For selections distributed across all \(D\) colours, Hölder's inequality yields, with \(u\) selected input labels,

\[
\Pr(\text{all selected inputs bad})
\leq(4\sqrt{3\zeta})^{u/D}.
\]

Our explicit choice of \(\zeta\) ensures

\[
4\sqrt{3\zeta}\leq q^{2D},
\]

so

\[
\boxed{\Pr(\text{all }u\text{ selected input labels bad})\leq q^{2u}.}
\]

This is uniform in the chosen payload strategy. The argument examines arrival gaps and physical proposal clocks, not assumed reliable record indices.

### 5\. Joint bound for arbitrary output indices

There is a separate regenerative argument for output labels.

Immediately after every nominal output event, the physical module is exactly in state \((\varnothing,0)\)\.

Starting at that event, consider the following clean-output certificate: the next source arrival precedes the next local fault proposal; its capture coin is correct; its next nominal service proposal precedes any subsequent local fault and occurs within \(h\); and its output read coin is correct.

On this event, the next actual output is a correct, timely record with a real input predecessor. Additional arrivals while its slot is occupied cannot alter that emitted record.

The two exponential races give

\[
\Pr(\text{certificate fails}\mid\text{past})
\leq
\frac{\kappa}{1+\kappa}
+\frac{\kappa}{\mu+\kappa}
+e^{-\mu h}
+2\delta.
\]

For the first output, include the at-most-\(2\epsilon_0\) probability that either initially reset site is erroneous.

With the specified parameters, each bound is less than \(4\zeta\)\.

These certificates are decided before the corresponding output event. At a fixed port their inspection intervals do not overlap, because every output resets the module. Within one colour the relevant Poisson drivers have disjoint fault-template sets. The strong Markov property permits fresh independent race tickets at successive, possibly adaptively chosen, certificate starts. History-adapted fault maps can choose what a fault does, but cannot predict or alter those fresh proposal races.

Hence for \(v\) selected output labels, combining the per-colour bound with Hölder,

\[
\Pr(\text{all selected outputs bad})
\leq(4\zeta)^{v/D}.
\]

Since \(4\zeta\leq q^{2D}\),

\[
\boxed{\Pr(\text{all }v\text{ selected output labels bad})\leq q^{2v}.}
\]

An output label that has not occurred by \(T\) is excluded, as required. Its absence only reduces the event being bounded.

### 6\. The full labelled-index law

Take any deterministic finite label set \(F\), containing \(u\) input labels and \(v\) output labels.

No independence between input-bad and output-bad events is assumed. Cauchy–Schwarz gives

\[
\begin{aligned}
\Pr(F\subseteq\mathrm{Bad})
&\leq
\sqrt{
\Pr(F_{\mathrm{in}}\subseteq\mathrm{Bad})
\Pr(F_{\mathrm{out}}\subseteq\mathrm{Bad})
}\\
&\leq
\sqrt{q^{2u}q^{2v}}\\
&=q^{u+v}.
\end{aligned}
\]

Therefore

\[
\boxed{
\Pr(F\subseteq\mathrm{Bad})\leq q^{|F|}
}
\]

for every finite \(F\), every horizon and every causal payload strategy.

For this slab design we can take

\[
\boxed{G=\Omega.}
\]

Then

\[
\Pr(G^c)=0\leq CT e^{-cL^a}
\]

for any positive computable \(c,a,C\)\. In particular, \(a=c=1\) works, and the result is not limited to the requested exponential horizon.

This is stronger than relying on a rare global-failure exclusion event: damage is recurrently contained at each port.

## 8\. The essential limitation of this resolution

The construction above resolves the **literal short-distance interpretation** of the specification. It is not a theorem about transporting a live FIFO stream over a distance that increases with \(L\)\.

That distinction is substantive. If the intended condition is

\[
\operatorname{dist}(\text{input port},\text{output port})
\geq \gamma L
\]

for some fixed \(\gamma>0\), the two-site transducer no longer qualifies.

Transporting each physical bit across \(\Omega(L)\) noisy local steps introduces cumulative corruption. The reset argument cannot simply be repeated across those steps: independently restarting intermediate transducers risks losing and misaligning records, and a majority decoder must align the physical copies without a reliable external phase or growing record labels. The supplied link and asynchronous-repair results do not establish that combined property.

**Final status\:** There is a complete positive construction, with a joint labelled-index proof, for the geometric specification as literally written using adjacent opposite-face ports. There is **no established full resolution here** for a growing-distance, finite-reuse, autonomous noisy FIFO fabric. If growing input-output separation is part of the intended definition, that additional condition is decisive and the stronger research problem remains unresolved.

EXECUTED CONSTRUCTION

Requirements: Python 3, NumPy, and a C++17 compiler named g++. The default
acquisition algorithm uses sorted parity collisions and independent held-out
verification; the default decoder is polynomial weighted blossom. Its source
and full upstream BSD license are included, so NetworkX installation is not
required. The program generates actual stabilizer-measurement samples, learns
the checks, reconstructs graphs and distances, and exercises noisy logical
Bell readout and hidden-Pauli learning. It regenerates the calibration binary.

The existing latent_code_calibration.bin is also included to permit direct
inspection or reuse of the exact finite measurement records. The C++ scanners
are finite-audit implementations for at most 64 wires and 256 rows per basis;
the mathematical algorithms use arbitrary-length bit strings. The larger
logical-data test explicitly reuses the acquired 50-wire code block. It is not
a full calibration experiment on 800 wires.

The default recorded seed is 4112606. Current results are in
latent_code_bell_result.json. The earlier exhaustive and dynamic-programming
audits are retained under their separately named JSON files; they are not the
default complexity claim. See latent_code_bell_README.md for the exact modes.

ANALYTIC FINITE CERTIFICATES

  python3 latent_code_collision_certificate.py
  python3 latent_code_parameter_certificate.py

All asserted numerical inequalities in these files use exact rational
arithmetic. Positive Taylor polynomials bound exponentials. The collision
certificate covers the selected sparse acquisition algorithm and a larger
analytic capability point. The parameter certificate covers the older,
sample-minimizing exhaustive learner. They have different copy and computation
costs. Neither certificate silently includes a specimen-factory approximation
budget: that budget is supplied explicitly by the theorem's factory formula.

The finite simulations, exact tail certificates and mathematical channel proof
serve different purposes. Zero observed simulation failures do not establish a
hardware threshold or replace the uniform analytic error bound.

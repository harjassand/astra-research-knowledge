SOURCE CONTRACT AND ACQUISITION
Each component has 256 distinct visible native modes and 3 normalized ports.
Component A has uniformly spaced rational rates in [1,2); component B
uses squared rational spacings. Source bounds a=1, A0=2, c0=1/4 are
checked by exact native arithmetic and supplied to the learner. The learner
is not supplied the source order, entries, rates, private states or Hq access.
All source arithmetic and this validation are counted below.

Both acquisitions use 128 rational frequencies, 768 real trials and 2304
scalar readouts per component. There is one continuously evolving source
state per component and ZERO between-trial resets. An initial norm prior
1 gives a uniform trial-start bound 2. Every trial waits 53 model-time
units under zero forcing and then uses a 52-unit finite harmonic history.
The post-wait norm bound is 2^-52, retained rather than set to zero.
Per component: 768 zero-input preparation commands plus 768 active
harmonic commands; 40,704 waiting and 39,936 active model-time units.
Across both: 1,536 trials, 4,608 scalar reports and 161,280 total sequential
model-time units. This is distinct from computer wall time.

Maximum frequency: 32512/255 = about 127.498 model radians/time.
Reported fractional precision: 48 bits. Native target: 80 fractional bits.
A bounded input gain mismatch and nonzero bounded sensor bias are each
2^-48; output quantization bound is 2^-49; timing bound is 2^-52.
The continuously propagated initial state, finite startup transients,
calibration, timing and certified arithmetic errors all enter the radius.

RESULT

A complete conditional construction acquires a finite rational causal
model from finite, paid input/output histories at fixed accessible ports.
No whole-state readout, Hq action, source dimension, eigenmodes or exact
transfer-function oracle enters the learner. It then supports all
qualified later monotone nonlinear attachments, finite added damped
states, modular networks and the retained qualified inference/design
operations. Source uncertainty, imperfect initialization and numerical
residuals remain together in the actual prediction certificate.

The class is globally stationary self-adjoint dissipative linear bulk,
with known normalized collocated ports, a positive decay margin and
supplied first/coupling-moment bounds. Internal dimension and global
frequency range need not be bounded. A diffusion-operator corollary
covers infinitely many unknown spatial coefficient fields with smooth
fixed distributed ports and explicit coefficient/derivative bounds.

This is a mathematical and software result under that contract. It is
not a finite-data proof of the physical source class, an unqualified
all-science identification theorem, an exact internal reconstruction,
a claim of historical priority or a demonstrated practical speedup.

EXECUTION

From this directory, run:
    python run_all.py

Already installed environment used: Python 3.12.14, NumPy 2.3.5,
SciPy 1.17.0. No package installation or new service is required by the
saved execution. The optional numerical proposer uses scipy.optimize
linprog(method='highs'); rational verification alone establishes the
reported data/model certificates. Results and timings are overwritten
on replay; file hashes in MANIFEST.json describe the saved run.

native.py is the paid software SOURCE: two known-to-native 256-state
diagonal media, fixed three-dimensional Hadamard ports, finite harmonic
commands and finite relaxation waits. It has one unknown-to-learner
initial state and no between-trial resets. It computes finite-duration
responses with rational elementary-function enclosures, bounded gain
mismatch and bounded nonzero sensor bias, then quantizes them. Its
private state propagation, source validation and full work are charged.

acquisition.py is the source-independent LEARNER: it receives only the
declared contract and returned port records. It proposes a finite
positive-residue impedance model and checks its global certificate
using exact rational arithmetic. The generally terminating SDP fallback
is proved/costed in THEOREM.txt; it is not implemented by this smaller
optional LP example.

flow.py uses only retained component models and later attachment/input
descriptions. A floating RK4 path proposal is converted into a rational
piecewise Hermite path. Exact polynomial residual bounds give the final
source-plus-numerical trajectory enclosure. Its common checker is
adapted with credit from the retained acquired-memory predecessor.

run_controls.py checks the fast weak-mode family algebraically, rejects
three deliberately invalid certificates, and performs separately billed
known-source transfer validation. The latter validation is not an input
to the learner or its certificate. It does not replace finite acquisition.

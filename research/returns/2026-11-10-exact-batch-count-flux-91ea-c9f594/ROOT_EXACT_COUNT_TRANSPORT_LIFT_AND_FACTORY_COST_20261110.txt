MODEL. P,Q are arbitrary fixed laws on[d], including zeros. The actual ordered row X~P^m is supplied; only new independent P/Q samples and fair bits may be queried. The whole output law must be EXACT Q^m and the expected mismatch on this actual row at most TV(P,Q)+eta. Define A_i=#j:X_j=i.

EQUIVALENT COUNT PROBLEM. Supply only A~Mult(m,P). A sample-only algorithm must output B with its entire exact law Mult(m,Q) and E||A-B||1/(2m)<=TV(P,Q)+eta. Charge the same fresh oracle calls and require an explicit uniform finite expected-bit-work bound. The original and count problems have exactly the same fresh-query minimax infimum, not merely a matching-order equivalence.

CONSTRUCTIVE LIFT. Given actual ordered X and a count B produced using A and new randomness/oracle calls only, put K_i=min(A_i,B_i). For each i independently choose a uniform K_i-subset of the positions whose actual X-label is i and keep those entries. Fill all remaining positions uniformly with the multiset containing B_i-K_i copies of each label i. Use exact fair-bit integer sampling/Fisher-Yates; no P_i,Q_i or conditional oracle is used.
Pathwise the output count is B. Every unkept old position has a label with A_i>B_i, while every newly filled label has B_i>A_i; hence no unkept position is accidentally equal. The EXACT number of changes is
 m-sum_i min(A_i,B_i)=||A-B||1/2.

WHOLE-PRODUCT PROOF, INCLUDING CONDITIONAL DEPENDENCE. Conditional on A=a, the actual X is uniform on its finite type class, even when P has zeros (ignore zero-probability a). The count algorithm sees only A; thus B conditional on A does not depend on the old row's ordering. The lift is equivariant under EVERY position permutation. Consequently, conditional on A=a,B=b, Y is invariant under the transitive action on the type-b class and therefore is UNIFORM on that type class. Averaging over A changes nothing: conditional on B=b, Y is uniform type-b. Since B has exactly Mult(m,Q), the unconditional ENTIRE ordered law of Y is Q^m. This does not claim Y|X or Y|A has law Q^m, which is neither required nor generally true. Input-row identity is preserved by the actual-position lift, not silently replaced by another P row.

REVERSE REDUCTION. Given any admissible ordered-row algorithm, a count policy internally samples a uniform type-A row Xstar and supplies it to that algorithm, using independent new P/Q samples/bits. Xstar marginally has law P^m, so its output Ystar has exact Q^m and B=count(Ystar) has exact Mult(m,Q). Deterministically ||A-B||1/2<=#j{Xstar_j!=Ystar_j}. Expected budget and query costs are preserved. Applying the lift to the actual X afterwards yields a valid original-row algorithm with no greater mismatch. This internal Xstar simulation is not substituted for the stored row in the final mismatch contract. Both inequalities for the two minimax infima follow, including arbitrary adaptive stopping and infima not attained.

BIT COST. Build count and position lists in O(m*log(d+1)+d*log(m+1)) bits of storage up to standard indexing factors. A uniform integer below n is sampled by ceil(log2 n) fair bits with rejection, expected at most2 trials. Uniform subsets/multiset permutations/type rows can all be generated by at most O(m) such draws and O((m+d)*poly(log(m+d+2))) bit operations with ordinary arrays and integer counters. These are finite explicit uniform overhead bounds. No deterministic cap/exponential tail for the scientific oracle algorithm is inferred; its admitted expected work bound composes with this fixed overhead. Additional output-list overhead is paid, and no extra oracle queries are hidden.

WHAT THIS CHANGES. The remaining central operation can be represented as a sample-only exact MULTINOMIAL COUNT coupling with an L1 budget. Merely sampling a perfect matching with the right edge marginals, or estimating a transport matrix, does not produce this law. The count-flux lower bounds already exploit count geometry; this construction makes its exact converse interface explicit. It does not close the present minimax gap.

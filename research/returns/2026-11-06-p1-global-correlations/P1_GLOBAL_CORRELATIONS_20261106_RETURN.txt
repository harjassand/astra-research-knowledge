## 1. An exact algorithm for the global sum

I examined a representation whose individual wire interactions become rank one modulo two. The relevant question was whether their remaining correlations could be summed efficiently at the precision needed to recover SAT.

For an integer \(t\), define
\[
K_t=
\begin{pmatrix}
1&1-t\\
0&t
\end{pmatrix}.
\]
Its row is indexed by a bit \(y\), and its column by a bit \(x\). Equivalently,
\[
K_t(y,x)=l_y(tx),\qquad l_0(z)=1-z,\quad l_1(z)=z.
\]

Consider a network with \(E\) wires, local tensors \(A_v\) on one side and \(B_w\) on the other. Each wire supplies one port to each side. The contraction is
\[
Z=
\sum_{x,y\in\{0,1\}^E}
\left(\prod_v A_v(y_v)\right)
\left(\prod_w B_w(x_w)\right)
\prod_{i=1}^E K_{t_i}(y_i,x_i).
\tag{1}
\]
The local tensors are explicitly tabulated; their description and arithmetic costs are included.

Work modulo \(2^p\), and let
\[
\delta_i=v_2(t_i).
\]

### The local computation

The kernel vanishes unless \(y_i\le x_i\). Where it is nonzero,
\[
\prod_iK_{t_i}(y_i,x_i)
=
\left(\prod_{i:y_i=1}t_i\right)
\left(\prod_{i:y_i=0,\ x_i=1}(1-t_i)\right).
\]

For each \(B\)-side vertex, form
\[
\widetilde B_w(y_w)=
\sum_{x_w\supseteq y_w}
B_w(x_w)
\prod_{i\in x_w\setminus y_w}(1-t_i).
\tag{2}
\]

This is an explicit local table computation. Starting with the table of \(B_w\), process each port \(i\), updating every mask \(y\) whose \(i\)-th bit is zero by
\[
B[y]\leftarrow B[y]+(1-t_i)B[y\cup\{i\}]
\pmod{2^p}.
\]
A table on \(d\) ports takes \(d2^{d-1}\) modular updates. This is polynomial in the explicit table length. It does not assume free access to an exponentially large table represented by a short evaluator.

### The global identity

After the local transformations, the exact contraction is
\[
\boxed{
Z=
\sum_{\substack{y\in\{0,1\}^E\\
\sum_i\delta_i y_i<p}}
\left(\prod_{i:y_i=1}t_i\right)
\left(\prod_v A_v(y_v)\right)
\left(\prod_w\widetilde B_w(y_w)\right)
\pmod{2^p}.
}
\tag{3}
\]

Every omitted term is individually divisible by \(2^p\). No approximation or cancellation assumption is needed to omit it.

The number of retained states is
\[
r(p;\delta)=
\#\left\{S\subseteq[E]:
\sum_{i\in S}\delta_i<p\right\}.
\tag{4}
\]
These states can be enumerated with polynomial delay and space. An include-or-exclude search prunes a branch when its accumulated weight reaches \(p\); every surviving prefix has its all-zero continuation.

For full explicit input length \(I\), a conservative bit bound is
\[
\boxed{
O\!\left(
(I+1)^3(p+1)^2+
r(p;\delta)(E+1)^2(p+1)^2
\right).
}
\tag{5}
\]
Space is polynomial in \(I+E+p\). The \(p\) precision bits are charged as \(p\) bits of work, not as the length of a binary encoding of \(p\).

This gives an exact global operation with no hidden conditional-counting oracle. **It does not supply polynomial time when \(r(p;\delta)\) is superpolynomial.**

## 2. Arbitrary SAT survives this representation

I then checked whether the representation itself forces the retained-state count to become small on the inputs that matter. A constant-size identity shows that it does not.

Set
\[
K=
\begin{pmatrix}
1&-1\\
0&2
\end{pmatrix},
\qquad
J=
\begin{pmatrix}
2&1\\
0&1
\end{pmatrix},
\qquad
H=JJ^{\mathsf T}=
\begin{pmatrix}
5&1\\
1&1
\end{pmatrix}.
\]
Direct multiplication gives
\[
KJ=2I,
\qquad
\boxed{KHK^{\mathsf T}=4I.}
\tag{6}
\]

Both \(K\) and \(H\) have rank one modulo two. Their composition nevertheless carries an exact equality constraint, multiplied by four.

### A uniform construction covering every CNF

Given a CNF \(F\):

1. Represent each clause of width at most three by its Boolean satisfaction table.
2. Replace a longer clause by a chain of deterministic two-input OR gates and require its output to be true.
3. Connect repeated occurrences of each logical signal using a tree of equality tensors of degree at most three.

Every original assignment determines all OR-gate and equality-tree auxiliaries uniquely. Hence the resulting bounded-degree network has contraction
\[
S(F)=\#\{\text{satisfying assignments of }F\}.
\]

Empty clauses and the empty conjunction are handled as scalar zero and the empty product, respectively. Variable names are normalized with a retained map to the original encoding.

Now replace each ordinary wire by the gadget in (6). If the original network has \(m\) wires, the new network has \(E=2m\) couplings of type \(K\), and
\[
\boxed{Z_{\mathrm{weak}}=4^mS(F)=2^E S(F).}
\tag{7}
\]

The construction uses constant-size integer entries and bounded-arity tensors. It adds no satisfiability promise.

### Complete size and precision costs

Let \(N\) be the original binary input length and \(n\) the number of occurring variables.

The construction gives:

| Quantity | Bound |
|---|---:|
| Couplings of type \(K\) | \(E\le 12N\) |
| Encoded network size | \(O(N\log(N+1))\) bits |
| Construction time, conservatively | \(O((N+1)^3)\) bit operations |
| Required precision | \(p=E+n+1\le13N+1\) bits |
| Local tensor arity | At most three |

Since \(0\le S(F)\le2^n\), the residue
\[
Z_{\mathrm{weak}}\bmod 2^{E+n+1}
\]
recovers \(S(F)\) exactly by shifting right by \(E\) bits.

Thus a uniform polynomial-bit exact contraction algorithm for this family would solve unrestricted SAT. Such a contraction algorithm has not been constructed here; (7) is a fully charged reduction demonstrating the generality that remains.

## 3. The exact separation cost at finite precision

The retained-state count has an additional interpretation: it is the exact minimum number of separated terms needed to represent the full boundary kernel over \(\mathbb Z/2^p\mathbb Z\).

For \(b\) wires, define
\[
\mathcal K(y,x)=\prod_{i=1}^bK_{t_i}(y_i,x_i).
\]

**Theorem.** The smallest \(r\) for which arbitrary functions \(f_j,g_j\) with values in \(\mathbb Z/2^p\mathbb Z\) can satisfy
\[
\mathcal K(y,x)=\sum_{j=1}^{r}f_j(y)g_j(x)
\quad\text{for every }x,y
\tag{9}
\]
is
\[
\boxed{
r=
\#\left\{S\subseteq[b]:
\sum_{i\in S}v_2(t_i)<p\right\}.
}
\tag{10}
\]

For a common positive valuation \(\delta\),
\[
r=
\sum_{j=0}^{\min(b,\lceil p/\delta\rceil-1)}
\binom bj.
\tag{11}
\]

In particular, \(t_i=2\) and \(p=b+1\) require exactly \(2^b\) terms.

### Why ordinary rank modulo two would miss this

The invertible matrix
\[
Q_t=
\begin{pmatrix}
1&t-1\\
0&1
\end{pmatrix}
\]
satisfies
\[
K_tQ_t=\operatorname{diag}(1,t).
\]
Taking tensor products transforms the boundary kernel into a diagonal matrix whose entry for \(S\) is
\[
\prod_{i\in S}t_i.
\]
Its nonzero entries modulo \(2^p\) are precisely those counted in (10).

The lower bound needs an argument over the finite ring, rather than treating it as a field. For a diagonal matrix with nonzero entries
\[
2^{a_1},\ldots,2^{a_r},\qquad a_i<p,
\]
its image module satisfies
\[
\dim_{\mathbb F_2}
\bigl(\operatorname{im}D/2\operatorname{im}D\bigr)=r.
\]
Therefore that image requires at least \(r\) generators.

Every submodule of \((\mathbb Z/2^p\mathbb Z)^k\) can be generated by at most \(k\) elements. This follows by induction on \(k\), using the fact that every ideal in \(\mathbb Z/2^p\mathbb Z\) is generated by one power of two. A factorization through \(k\) separated coordinates would therefore force the image to have at most \(k\) generators. Hence \(k\ge r\). Writing each nonzero diagonal entry separately attains the bound.

This handles the nonunit entries that disappear modulo two but survive at higher precision.

### An explicit ordinary CNF family

The same separation cost occurs in conditional counts of unweighted binary-clause formulas.

For each boundary pair \(x_i,y_i\), introduce a selector \(s_i\) and \(\delta_i\) auxiliary bits \(a_{i,j}\), with clauses
\[
(\neg s_i\vee x_i),\qquad
(\neg s_i\vee y_i),\qquad
(s_i\vee\neg a_{i,j})
\quad(1\le j\le\delta_i).
\tag{12}
\]

If \((x_i,y_i)\ne(1,1)\), there is one auxiliary extension. If \((x_i,y_i)=(1,1)\), there are \(1+2^{\delta_i}\) extensions. Its conditional-count matrix is therefore
\[
G_{2^{\delta_i}}=
\begin{pmatrix}
1&1\\
1&1+2^{\delta_i}
\end{pmatrix}.
\]
This matrix is equivalent to \(\operatorname{diag}(1,2^{\delta_i})\) by invertible integer row and column operations, so its tensor products have the same bound (10).

For \(\delta_i=1\), the formula has \(4b\) variables and \(3b\) binary clauses, with indexed binary length \(O(b\log(b+1))\). At precision \(b+1\), its conditional-count matrix needs exactly \(2^b\) separated terms.

**The scope is representation-specific.** These disjoint formulas are easy to satisfy and count. Likewise, contracting the kernel against product boundary functions is easy even when its separated dimension is large. The theorem excludes a universal small separated representation, not a polynomial SAT algorithm.

## 4. The determinant route: a valid case and an explicit failure

The Cauchy structure in the source suggested using Borchardt’s identity to eliminate coefficient enumeration.

For an ordinary Cauchy matrix
\[
C_{ij}=\frac1{a_i-b_j},
\]
the identity is
\[
\operatorname{per}(C)=
\frac{\det(C^{\circ2})}{\det C},
\tag{13}
\]
under the relevant nonvanishing conditions. The primary literature gives this identity for that matrix form. :chatgpt-content-reference{index="0"}

### A usable repeated-column formula

Coalescing repeated simple Cauchy columns gives a valid coefficient computation.

Suppose \(\sum_j\beta_j=L\), with distinct row nodes \(a_i\), distinct active column nodes \(b_j\), and \(a_i\ne b_j\). Index columns by \((j,r)\), \(0\le r<\beta_j\), and define
\[
D_{i,(j,r)}=(a_i-b_j)^{-r-1},
\]
\[
N_{i,(j,r)}=(r+1)(a_i-b_j)^{-r-2}.
\]
Then
\[
\boxed{
[Z^\beta]\prod_{i=1}^{L}\left(\sum_j\frac{Z_j}{a_i-b_j}\right)
=
\frac{\det N}
{\det D\,\prod_j\beta_j!}.
}
\tag{14}
\]

This follows by coalescing columns in (13), cancelling their common Vandermonde factors, and accounting for the permutations among repeated columns. For explicitly specified rational nodes, it gives polynomial bit complexity in the matrix dimension and node-description length through exact determinant arithmetic.

The distinction is consequential: (14) computes coefficients built from repeated **simple** Cauchy columns. It does not assert that the permanent of the resulting higher-power matrix \(D\) itself equals \(\det(D^{\circ2})/\det D\).

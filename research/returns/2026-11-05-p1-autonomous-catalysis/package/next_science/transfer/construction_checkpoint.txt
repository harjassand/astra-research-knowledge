6. CORRECTION: CUT LOCUS AND A BETTER FORCE-BALANCE INTERFACE
The radial-control sensor inequality in section1 is NOT globally valid for
shortest torus lifts: lifts can jump by L across the cut. Root identified this.
Section1's exact-sensor result survives; the sensor extension needs repair.
The following finite-sample unwrapping repair supplies it, with different costs.

At each target-window start choose the periodic copy z+Lm nearest the current
OBSERVED continuous lift. Fix this copy for the entire window. Follow the
continuous lift Y by unwrapping successive position measurements. On an event
that every actual step displacement is <=r/4 and each position-vector sensing
error <=s<=r/16, with r<=L/4, the winding integer is unambiguous. Inductively
observed lift minus true lift has magnitude<=s; it does not accumulate.
Initial true radius R0<=sqrt(d)L/2+s. This is reference selection, not reset.
Control at each sample is u=-U(Yobs-z)/|Yobs-z|, held over Delta. On correctly
unwrapped paths, loss in (Ytrue-z).u relative to exact radial control <=2Us.
One can define an ideal auxiliary controller with access to the correct lift
and the same bounded sensor errors; actual/auxiliary controllers agree until
unwrap failure. Probability of failure is bounded below independently.

Write v=U-M, B=M+U, take Delta<=dD/B^2. For the auxiliary lifted process,
 E[|Ynext-z|^2-|Y-z|^2|past]
 <=-2v|Y-z|Delta+4UsDelta+6dDDelta.
Unbounded squared distance causes no optional-stopping problem on fixed finite
T: bounded drift and Gaussian noise give finite moments. Summing for N=T/Delta

For per-window localization failure budget alpha_loc choose

Then expected grid radius <alpha_loc r/16; Markov gives
 P[mean grid true radius>r/4]<alpha_loc/4.
The observed mean-radius gate <=r/2 therefore passes except this event, since
s<=r/16. Gate failure returns NO CERTIFICATE, not a fabricated rate.

Fix T before sampling; choose Delta=T/N after setting N large enough. On every
step, drift displacement<=BDelta. Require BDelta<=r/8. By the reflection
principle and a union bound over d components and n windows,
 P[any step Brownian maximum norm>r/8]
 <=4dnT/Delta exp[-r^2/(256dDDelta)].
Choose Delta so this is <=alpha_step. This is a finite condition; e.g. let
 a0=r^2/(256dD), C=4dnT/a0, S=max(e,4C/alpha_step),

7. FINITE CONSTANT-D ACQUISITION (NEW ADDITION, SUPERSEDES 'NOT COMPOSED' ABOVE)
An initial known bracket 0<D_min<=D<=D_max is needed to budget controller and
no-wrap events, but D can then be refined from finite controlled increments.
For one coordinate and K consecutive increments on the no-wrap event, let
 R_i=Delta Yobs_i-u_i Delta=sqrt(2DDelta) Z_i+e_i,
 |e_i|<=MDelta+2s+a_uDelta, Z_i iid N(0,1).
The b-integral may depend on Z_i, but only its bound is used; adaptive feedback
and bounded adversarial measurement errors do not invalidate the inequality.
Set S=sum R_i^2/(2KDelta), r_D=(MDelta+2s+a_uDelta)/sqrt(2Delta).
The Euclidean triangle inequality gives
 |sqrt(S)-sqrt(DQ)|<=r_D, Q=K^-1 sum Z_i^2.
For t=log(2/alpha_D), Laurent-Massart bounds give with probability>=1-alpha_D
 q_minus=1-2sqrt(t/K)<=Q<=q_plus=1+2sqrt(t/K)+2t/K.
Take K>4t so q_minus>0. Therefore
 D in [(max(sqrt(S)-r_D,0))^2/q_plus,
       (sqrt(S)+r_D)^2/q_minus].
Intersect this with the initial bracket; empty intersection is a model/error
specification failure, not permission to discard the data. Refine K and Delta
if the resulting rate-sensitivity budget is not met. No equilibrium sampling
or inaccessible rare event is used.

To obtain relative D accuracy epsilon_D, sufficient orders are
 K=O(log(1/alpha_D)/epsilon_D^2),
 M sqrt(Delta)+s/sqrt(Delta)=O(epsilon_D sqrt(D_min)),
with actuator error added to M. Thus fixed bounded sensing error cannot be
removed just by more samples: this sufficient design has an error floor of
order sqrt(Ms/D). It is not claimed an optimal lower bound. Sensor resolution,
number of observations and sampling bandwidth are all paid.

For potential V normalized at a base point, |V|<=M*diameter along chosen paths.
A D interval changes log conductivity log[D exp(-V/D)] by at most
 |log(Dhi/Dlo)| + V_span*(1/Dlo-1/Dhi), plus potential-acquisition error/Dlo.
Normalization has its corresponding exponent budget. Thus epsilon_D must
usually be O(epsilon/(1+dimensionless barrier span)); this is not a free
thermometer or mobility calibration. Work in drift units avoids separately
assuming beta or mechanical mobility. To claim force/energy units, acquire
that conversion and its uncertainty independently.

The full theorem can be run with D_max in controller/noise upper bounds and
D_min wherever a lower diffusion scale is required; after calibration use
its acquired interval in the conductivity bracket. The fixed-D formulas in
sections1/6 are the clean special case, not an assertion that D is noiseless.

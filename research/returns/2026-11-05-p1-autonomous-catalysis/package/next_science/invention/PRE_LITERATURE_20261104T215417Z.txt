Question owned by this constructor
=================================
Can a finite-memory machine generate a stationary structured stochastic output
at its full thermodynamic entropy-rate limit, while preserving all output
correlations? Which memory representation, access and execution resources are
necessary, and when is there an unavoidable gap? The ambition is a general
theory of the thermodynamic cost of structured computation, not a better
periodic-load scheduler or quantum-state acquisition device.

Proposed mechanism
==================
Ordinary predictive memory summarizes the past to predict the future. For
generation, that direction can be the wrong one: a memory state may instead
be a retained boundary condition on the not-yet-produced future. The machine
stochastically refines that condition into one output symbol and a new future
condition. If the old condition can be recovered from these two outputs, the
local step need not erase its past correlation. This is not an external future
oracle: initialize an internal state from its stationary law, then generate
the next state and symbol by an ordinary causal stochastic kernel.

Pre-literature deduction 1: exact local thermodynamic comparison
=============================================================
Assume a stationary finite-alphabet process, ideal degenerate logical states,
an isothermal bath at temperature Theta, and a local operation that can access
only its current memory and a fresh standard-state output cell. Earlier output
cells are outside that operation. Work sign is positive for work supplied.
Use natural-log entropies throughout. Reversible realization of the local map
is a provisional ideal capability; finite-time controlled physical realization
is a separate operation to earn, not an assumption of a usable device.

Let S_t be a finite predictive sufficient state, and suppose it updates
unifilarly: S_{t+1}=f(S_t,Y_t). The output entropy rate is
h=H(Y_t | S_t). For a stationary local step
(S_t,blank)->(S_{t+1},Y_t), the minimum free-energy change is

 W_local >= -k_B Theta h + k_B Theta H(S_t | S_{t+1},Y_t).

Proof: H(S_{t+1},Y_t)=H(S_t,Y_t)-H(S_t|S_{t+1},Y_t)
=H(S_t)+h-H(S_t|S_{t+1},Y_t), and subtract input entropy.
Thus local use of an otherwise predictive sufficient state can lose usable
correlation information when the preceding state is not retrodictable.
This is an interface-dependent cost, not a claim that predictive models force
dissipation if an implementation can revisit the earlier output tape.

Now seek a stationary alternative memory X_t such that
(i) X_t=f_reverse(Y_t,X_{t+1}) deterministically;
(ii) H(Y_t|X_{t+1})=h;
(iii) an ordinary forward kernel P(Y_t,X_{t+1}|X_t) reproduces the process.
Then stationarity gives H(Y_t,X_{t+1})-H(X_t)=h, so the local free-energy
limit is exactly W=-k_B Theta h. The map is reverse-unifilar and can avoid
erasing local correlation. A reverse-time predictive-state machine, if finite,
appears to provide such X_t by time reversal and Bayes' rule. This must be
challenged against existing work and physical implementation requirements.

Concrete example: binary stationary Markov output, switch probability p.
Past-oriented memory S_t=Y_{t-1} updated to S_{t+1}=Y_t has
H(S_t|S_{t+1},Y_t)=h_2(p), so W_local>=0. Instead retain the next symbol
X_t=Y_t, emit it first, and sample X_{t+1} conditional on X_t. The output
law is identical, and the local entropy increase is h_2(p), giving an ideal
work-extraction limit -k_B Theta h_2(p). The ordered access to the output
cell, rather than a predictive-accuracy improvement, changes the work bill.

Pre-literature deduction 2: universal blocking bound
===================================================
For an m-state unifilar predictive generator, let B=Y_t...Y_{t+L-1} and
S'=S_{t+L}. Exactly as above,

 W_block >= -k_B Theta Lh + k_B Theta H(S_t | S',B).

The excess local entropy cost is bounded by H(S_t)<=ln m, independent of L.
Thus an ideal controllable block operation permits an excess cost per output
of at most k_B Theta ln(m)/L, even if a finite exact reverse-state generator
does not exist. Exact output sampling is ordinary sequential generation from
S_t; a physical implementation must preserve the initial-state information
until the final block has been produced, then account for its erasure.
This is a constructive target, not a license to assume an exponential-arity
stochastic operation, a free clock or zero-cost memory.

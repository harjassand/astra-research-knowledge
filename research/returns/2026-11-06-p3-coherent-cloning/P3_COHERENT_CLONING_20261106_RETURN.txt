## 3. The central construction

The main difficulty is normalizing a successful symmetry projection **without consuming the only input and asking for replacement copies**. The construction resolves that difficulty because its success operator has exactly the same singular value on every allowed input.

### A. Symmetrization needs only \(k+1\) branches

Suppose the current \(k\) systems occupy \(S_k\), and append a new system \(B\). Define
\[
T_k=\frac{1}{k+1}
\left(I+\sum_{i=1}^{k}\operatorname{SWAP}_{i,B}\right).
\]

On \(S_k\otimes\mathbb C^d\),
\[
T_k=P_{k+1}.
\]

The reason is a permutation-group decomposition: after averaging over permutations of the first \(k\) systems, only the \(k+1\) possible placements of the new system remain. The input is already invariant under the first average.

The domain restriction matters. \(T_k\) is not a projector on the entire unrestricted \((k+1)\)-system Hilbert space.

Prepare a known normalized Bell pair
\[
|\Phi_d\rangle_{BE}=\frac{|\Gamma_d\rangle}{\sqrt d}.
\]
The unnormalized successful operation is
\[
A_k|v\rangle
=
(T_k\otimes I_E)
\left(|v\rangle\otimes|\Phi_d\rangle_{BE}\right).
\]

### B. Its success probability is exactly independent of the unknown input

On \(S_k\),
\[
\boxed{
A_k^\dagger A_k=p_k I,
\qquad
p_k=\frac{d+k}{d(k+1)}
\ge \frac1{k+1}.
}
\]

This identity is the crucial calculation.

Because the successful clone register is fully symmetric, \(T_k^2\) can be replaced by \(T_k\) on the relevant input vectors. Sandwiching the identity term between Bell vectors gives \(I\); sandwiching each swap term gives \(I/d\). Hence
\[
p_k=\frac{1+k/d}{k+1}.
\]

The statement is an operator identity, so it preserves inner products between different inputs. It covers superpositions and external-reference entanglement, not merely a list of pure states with matching success probabilities.

Dividing by \(\sqrt{p_k}\) yields
\[
W_k|v\rangle
=
\sqrt{\frac{k+1}{d+k}}\,
(P_{k+1}\otimes I_E)
\left(|v\rangle\otimes|\Gamma_d\rangle\right),
\]
which is the required one-step cloning/transposition isometry.

### C. All reflections act on known ancilla conditions

The circuit implements \(T_k\) through a uniform superposition of \(k+1\) branches. One branch performs the identity; each other branch performs one controlled swap. Unpreparing the branch register exposes \(T_k\) in its all-zero block.

Each swap between two encoded \(d\)-level systems costs \(q\) controlled bit swaps. The explicit implementation expands these into one- and two-qubit gates.

To make the successful block deterministic, choose
\[
j_k=\left\lceil\sqrt{k+1}\right\rceil,\qquad
\theta_k=\frac{\pi}{4j_k+2}.
\]
A known attenuation flag changes the success probability from \(p_k\) to
\[
\sin^2\theta_k.
\]
The required attenuation factor,
\[
a_k=\frac{\sin^2\theta_k}{p_k},
\]
lies strictly between zero and one.

Let \(U_k\) be the known circuit comprising Bell preparation, controlled swaps, branch unpreparation and attenuation. Two projectors suffice:

- \(\Pi_{\mathrm{in}}\) tests whether the fresh ancillas are initialized.
- \(\Pi_{\mathrm{good}}\) tests whether the branch and attenuation flags indicate success.

Neither projector tests the unknown quantum state.

The flat-success identity implies that amplification rotates every allowed input through the same angle. After \(j_k\) iterations,
\[
\sin\!\bigl((2j_k+1)\theta_k\bigr)=1,
\]
so the ideal circuit implements \(W_k\) deterministically.

This is an application of established oblivious amplitude amplification, which permits amplification when reflection about the unknown input is unavailable. Here the required operator condition and the available reflections are explicitly supplied. [arxiv.org](https://arxiv.org/abs/1312.1414?utm_source=chatgpt.com)

The inverse used by the algorithm is \(U_k^\dagger\), the inverse of a circuit we have constructed. No inverse of the unknown state’s preparation appears.

### D. Sequential composition gives the full joint operation

Apply
\[
W_n,W_{n+1},\ldots,W_{m-1},
\]
retaining each environment register.

Every stage leaves the clone register in the symmetric subspace required by the next stage. The normalization factors telescope:
\[
\prod_{k=n}^{m-1}\sqrt{\frac{h_k}{h_{k+1}}}
=
\sqrt{\frac{h_n}{h_m}}.
\]

The projectors also collapse:
\[
P_m(P_k\otimes I)=P_m.
\]

Consequently the composition is exactly \(V_{n,m}\), up to an irrelevant input-independent global phase tracked by the code.

This proves equality of the **whole isometry**. It establishes the transposition output directly, without leaving an unspecified environment transformation to be compiled later.

It also avoids a potentially expensive global postselection. A single projection after appending all pairs has success probability
\[
\frac{h_m}{h_n d^{m-n}}.
\]
The sequential circuit instead pays \(O(\sqrt{k+1})\) amplification uses at each stage, while preserving the input coherently throughout.

## 5. The quality limits remain decisive

The channel is optimal, but its outputs are approximate and correlated.

For an unknown pure input and squared fidelity,
\[
F_{\mathrm{all}}=\frac{h_n}{h_m},
\]
where the target is the entire ideal product \(|\psi\rangle^{\otimes m}\), while
\[
F_{\mathrm{one}}
=
\frac{n(m+d)+m-n}{m(n+d)}
\]
judges one clone. These are distinct operational guarantees, even though the same optimal channel attains them. [arxiv.org](https://arxiv.org/abs/quant-ph/9804001?utm_source=chatgpt.com)

Writing \(m=n+\ell\),
\[
1-F_{\mathrm{one}}
=
\frac{\ell(d-1)}{(n+\ell)(n+d)},
\]
but
\[
F_{\mathrm{all}}
=
\prod_{j=1}^{\ell}
\frac{n+j}{n+d-1+j}.
\]

### A concrete difference between marginal and joint quality

For
\[
d=1024,\qquad n=100,\qquad m=101,
\]
the calculated fidelities are
\[
F_{\mathrm{one}}\approx0.990989,
\qquad
F_{\mathrm{all}}\approx0.089858.
\]

Each individual clone looks quite good by its marginal criterion. The complete output is a poor approximation to 101 independent ideal preparations.

There is a useful comparison: randomly place the 100 original systems in 100 of the output positions and fill the remaining position with the maximally mixed state. That elementary procedure already achieves one-site fidelity
\[
F_{\mathrm{retain}}
=
\frac{n}{m}+\frac{\ell}{md}
\approx0.990109.
\]

Thus a favorable one-site benchmark can substantially reward retention of the original quantum information. A claim about additional usable independent preparations requires the joint-output guarantee.

For this same \(d=1024\) example, the literal compiler costs **497,339 native logical gates before finite-angle synthesis and 1,243 logical qubits** when retaining the transposition output. Those are calculated circuit counts, not hardware prices.

### Efficient dimension dependence does not remove the copy requirement

For just one additional clone,
\[
F_{\mathrm{all}}=\frac{n+1}{n+d},
\qquad
1-F_{\mathrm{all}}=\frac{d-1}{n+d}.
\]

Consequently, achieving worst-case global infidelity at most \(\varepsilon\) requires
\[
n\ge \frac{d-1}{\varepsilon}-d.
\]

This is an immediate consequence of the established optimal fidelity. At fixed nontrivial \(\varepsilon\), the required input count grows linearly with \(d\), which is exponential in the number of qubits per system.

The compiler resolves the implementation dependence on \(d\). It preserves the underlying statistical limitation.

More generally, any such processing obeys
\[
D\!\left(\mathcal C(\rho_0),\mathcal C(\rho_1)\right)
\le D(\rho_0,\rho_1),
\]
for trace distance \(D\). The output cannot contain more distinguishability than the supplied joint input. Treating the clones as fresh independent observations would therefore produce an invalid statistical accounting.

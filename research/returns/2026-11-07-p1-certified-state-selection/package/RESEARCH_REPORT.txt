These promises are retained physical/model assumptions. No finite fitting

The actual actuator is tau v'=-v+c+e_a, ||e_a||<=zeta. The controller sends
held finite-bit commands c. It receives noisy quantized port readings with
total Euclidean error <=nu, including source-evaluation error in the native
software channel. Clock spacing, jitter, computation and communication
latency have explicit bounds. The source and actuator initially satisfy only
||x(0)||<=R0 and ||v(0)||<=V0. An exact hidden-state reset is unnecessary.

During writing the programmable total port law is temporarily replaced by a
constant command c_w approximately equal to S_hat p. During retention it is

capability is substantive. A permanently present nonlinear interaction which

For the selected class, the source may have infinitely many hidden modes and

2. WHY THE HANDOVER IS CERTIFIED

The full equilibrium associated with port q is LIFT q, with
||LIFT||<=ell=sqrt(1+c0/a^2). A certified local port-potential Hessian lower
bound m supplies a full-state contraction rate alpha whenever

    (m-alpha)(a-alpha)>=alpha c0/a,  0<alpha<a.

This follows by a Schur complement of the full source-plus-interaction
Hessian. It is stronger information than an equilibrium point alone.

Let r be a full-state ball which stays inside the certified local port region.
Suppose writing gives state error <=w0 and actuator mismatch
||v-F(y)||<=D0 at release. Let L bound the local feedback derivative, M_y bound
the actual output time derivative, h bound reading age and epsilon_c bound
the finite-bit command error. Define

    d_inf=L nu+epsilon_c+zeta+L M_y(h+tau),
    A=w0+2tau D0,                 b=d_inf/alpha.

The finite handover condition is

    alpha tau<=1/2,              A+b<r.

It gives the continuous-time guarantee

    ||x(t)-x_*|| <= A exp(-alpha t)+b.

This inequality includes the actual lagged actuator state at the switch.
There is no zero-cost actuator reset. A first-exit argument makes the local
bound invariant. Any desired delta>b is reached after a computed finite time,
and the state remains within delta for any charged finite retention horizon.

The constant write has a true equilibrium x_w=H^{-1}Bc_w. Its convergence
from every declared preparation is bounded by

 ||x(T)-x_w|| <= [R0+||c_w||/a+2tau(V0+||c_w||)] exp(-aT)+zeta/a.

The acquired static error bounds the distance between x_w and the intended
full equilibrium. In the executed design F(p)=S_hat p exactly before command
rounding, so this static mismatch is small. A separately proved sampled
linear feedback writer can shrink the mismatch when stronger clamping is
needed. Failure of these sufficient inequalities for a fixed device is not
presented as a general impossibility of control.

coordinates differ from their signs by less than 0.024.

To address one pattern, a supplied n-bit sign vector names its box. A rounded
projected-gradient iteration on the known nominal potential contracts by

It never enumerates the other patterns. The true source-induced target error

6. WHY STATIC ORDER DOES NOT DETERMINE PREPARATION TIME

For 0<d<=1, take H_d=diag(d,2-d) and normalized port
B_d=(sqrt(d/2),sqrt(1-d/2)). Every source has exactly S=1. Also A<=2 and the
coupling moment is at most 1/4. Nevertheless a slow hidden mode approaches
zero decay as d decreases.

Start from zero, use any bounded write force |v|<=V, V>=1, and then release
into the retention law v=2y-y^3. Requiring y to remain in [0.9,1.1] after
release entails

    T_write >= 0.529/(dV)-1.071 log(5V)/V.

The bound diverges as d tends to zero despite identical static impedance and
ordered states. The proof explicitly separates fast and slow port responses.
Its scope is bounded-force preparation followed by the specified retention
law. It does not exclude indefinitely continuing auxiliary clamping. It
identifies the precise dynamical information used by the positive operation:
a known decay prior must pay for erasing unknown hidden preparation.

### Obtain a successful short path from a rare stationary state

Consider a stationary block of normalized duration \(L\). Rate-one Poisson uniformization gives a random number of potential updates and a state sequence

\[
X_0,\ldots,X_n.
\]

Let

\[
N_B=\sum_{j=0}^{n}\mathbf 1_{\{X_j\in B\}}
\]

count all visits to \(B\), including visits at null updates.

The proposal inserts a marked rare state sampled from \(\pi(\cdot\mid B)\). It grows the path backward using \(P^*\) and forward using \(P\), with an explicit mixture accounting for a mark at time zero. Its density relative to an ordinary stationary block is exactly

\[
\frac{N_B}{p(1+L)}.
\]

Define the desired block event

\[
G=\{\text{the block’s first hit of }B\text{ lies in }(H,L]\}.
\]

Accept the proposed path with probability

\[
\frac{\mathbf 1_G}{N_B}.
\]

The multiplicity cancels. The accepted path is exactly a stationary block conditioned on \(G\).

This correction matters. A typical stationary failed state is biased toward long or frequently revisited failure episodes. Reversing from it without correcting the visit multiplicity does not automatically produce a first-entry history.

Let \(q_G=\Pr_\pi(G)\). The bounded acceptance observable has mean

\[
\mu_G
=
\mathbb E_{\rm proposal}\frac{\mathbf 1_G}{N_B}
=
\frac{q_G}{p(1+L)}.
\]

The mixing inequality gives a usable lower bound on that mean. Writing \(q(t)=\Pr_\pi(\tau_B\le t)\), I derive

\[
q(t)\le p(1+t),
\qquad
q(t)\ge \frac{gpt}{2+gpt}.
\]

The lower bound follows from the first two moments of stationary occupation time in \(B\). Consequently, if

\[
L\ge \frac{16(H+1)}{g},
\qquad Lp\le1,
\]

then

\[
q_G\ge \frac{gLp}{4},
\qquad
\mu_G\ge \frac g8.
\]

Thus the rejection cost is controlled by the mixing margin. It does not contain an inverse global-rarity factor. Estimating the bounded mean \(\mu_G\), together with the relative static estimate of \(p\), also acquires the block success probability.

### Make the approximation error proportional to success probability

Place mixing buffers between these blocks. After a sufficiently long buffer, every possible starting distribution has density between \(1-\eta\) and \(1+\eta\) relative to \(\pi\).

Comparing two complete block laws gives an error of order \(\eta\). Accumulating that over approximately \(1/q_G\) unsuccessful blocks would destroy the result.

The useful representation retains:

- one symbol for an unsuccessful block;
- the **entire path** for a successful block.

For this outcome, the TV error per block is at most

\[
\eta q_G.
\]

The expected number of reached blocks is at most \(1/[(1-\eta)q_G]\). Therefore the entire replacement error is bounded by

\[
\eta q_G
\sum_{k\ge0}[1-(1-\eta)q_G]^k
=
\frac{\eta}{1-\eta}.
\]

This cancellation is the central principle. It preserves the successful path and its index while allowing the enormous unsuccessful sequence to be represented by one geometric random integer.

### Pay for events hidden in the buffers

The buffers and the first \(H\) units of each block can contain a genuine earlier failure. Those events must be charged.

The resulting bound is

\[
\frac{1+\eta}{1-\eta}
\frac{q(H)+q(b)}{q_G},
\]

where \(b\) is the buffer length.

A crucial detail is that a buffer hit is bounded as a **joint event before exposing the current block**. Conditioning on a fully observed unsuccessful block is unsafe: such a block can end inside \(B\). The proof instead uses

\[
\Pr(G^c\ \text{and following buffer hits }B)
\le (1+\eta)q(b).
\]

This avoids an unjustified conditional-survival denominator.

The restriction that a successful block’s first hit occurs after \(H\) ensures that the complete requested precursor window lies inside that block. No missing history must be invented across a discarded interval.

\le (1+\eta)\pi.

\frac{\eta}{1-\eta}

\frac{1+\eta}{1-\eta}

The huge geometric clock has a finite-bit guarantee under independent fair bits.

EXACT MICROSCOPIC MODEL
Set t_0=t_n=0. For each site i,
 a_i=t_{i-1}(1-t_i^2)/(1-t_{i-1}^2 t_i^2),
 b_i=t_i(1-t_{i-1}^2)/(1-t_{i-1}^2 t_i^2).
Flip rate c_i(sigma)=lambda_i[1-sigma_i(a_i sigma_{i-1}+b_i sigma_{i+1})]/2.
All rational; proposal clock per site lambda_i. Stationary law
 pi(sigma)=2^-n product_{i=1}^{n-1}(1+t_i sigma_i sigma_{i+1}).
Pimin=2^-n product(1-t_i)>0, computable rational with polynomial bits.
g=min_i lambda_i(1-a_i-b_i)>0, Lambda=sum lambda_i, G=2Lambda.
Monotone coupling bounds gap >=g (site disagreement sup <=e^-gt).
For killed chain outside target A, gap >=d=g*pi(A), from Poincare and f|A=0.
Thus survival <=C exp(-dt), C=1/pimin safe rational; mean>=1/Lambda if x not A.

CORRELATION CLOSURE / CONFIGURATION PROBABILITY
Let K be n-by-n tridiagonal: K_ii=lambda_i, K_i,i-1=-lambda_i a_i,
K_i,i+1=-lambda_i b_i. U(z)=exp(-zK), Re z>=0.
Exact symmetrizing weights, including zero bonds:
 w_i=(1-t_{i-1}^2 t_i^2)/[lambda_i(1-t_{i-1}^2)(1-t_i^2)].
w_i lambda_i b_i=t_i/(1-t_i^2)=w_{i+1}lambda_{i+1}a_{i+1}.
K is positive self-adjoint in weighted norm; eigenvalues >=g.
Use C_U=n*max(w)/min(w) as a safe infinity norm bound for U(z), any Re z>=0.
For initial deterministic x, m(z)=U(z)x. Antisymmetric matrices C0_ij=x_i x_j
and Ceq_ij=product_{r=i}^{j-1} t_r for i<j. Then

This avoids an n(n-1)/2 exponential: pair generator is exterior square of K.

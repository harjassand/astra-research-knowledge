1. Actual compatible data and the inherited exact division.

Fix ANY real A and periodic phi in W1,4(T2;R2), G=Dphi, F=A+G. Write u=|F_col1|^2,v=|F_col2|^2,j=det F and Delta H=integral H(F)-H(A). Use

The new P1 exact division, inherited from its complete native return, is
 8Q_k=(k-1)u^2+4uj+(u+v-2j)^2/(k+1).               (1)

Set the FOUR real statistics
 X=Delta u^2, D=Delta(u+v-2j)^2,
 V=Delta j^2=integral(j-det A)^2, a=-Delta Q_0.
All are finite. Compatibility gives the stated variance formula, and X,D,V are nonnegative by convex Jensen inequalities. For nonzero G, D>0. If X=0, strict convexity makes the total first column constant, Delta(uj)=0 and a=-3D/32. That case has
 Delta J_k=V+(3k-1)D/[8(k+1)]>=0 for EVERY k>1/3.     (2)
If G=0 all gaps are zero. These handle degeneracies without dividing by X.

For X>0 put h=k-1/3>0. The exact P1 endpoint identity is
 Delta J_(1/3+h)=V-3ha+(3h^2/8)[X-D/((4/3)(4/3+h))]. (3)
There is no Taylor remainder and no small-h restriction. The source's sufficient negative certificate a>0,VX<=6a^2 follows by taking h=4a/X. The operation below eliminates the entire parameter continuum, without assuming a>0 or replacing the full question by that sufficient certificate.

2. A cubic whose sign is EXACTLY the original gap sign.

Multiply(3) by h+4/3. Define
 r3=3X/8>0,
 r2=X/2-3a-9D/32,
 r1=V-4a,
 r0=4V/3>=0,
 P(h)=r3 h^3+r2 h^2+r1 h+r0.
Then EXACTLY
 Delta J_(1/3+h)=P(h)/(h+4/3), for EVERY h>0.         (4)

Thus a fixed ACTUAL compatible field has a negative original gap at some admitted parameter if and only if P is negative somewhere on the positive half-line. This converts parameter selection into an elementary finite moment operation. It does not construct a compatible field or assert that arbitrary nonnegative X,D,V with a real a are realizable.

3. Complete parameter-free sign test.

Put
 Delta_c=r2^2-3r3 r1,
 T_c=2r2^3-9r3 r2 r1+27r3^2 r0.
There is a negative original gap for this field at SOME k>1/3 if and ONLY if all three conditions hold:

 (i) Delta_c>0;
 (ii) r2<0 OR r1<0;
 (iii) T_c<0 OR T_c^2<4 Delta_c^3.                   (5)

This is a necessary AND sufficient test for parameter existence, not just another sufficient endpoint criterion.

Proof. Since r3>0 and r0>=0, P(0)>=0 and P(h) tends to positive infinity. If Delta_c<=0 its derivative is nonnegative everywhere. If Delta_c>0, the only possible interior local MINIMUM is
 h_plus=(-r2+sqrt(Delta_c))/(3r3).
It is positive exactly under(ii). The other critical point is a local maximum. Thus P is negative somewhere on h>0 exactly when h_plus>0 and P(h_plus)<0. Direct substitution gives
 P(h_plus)=[T_c-2 Delta_c^(3/2)]/(27r3^2).
For T_c<0 this is strictly negative. For T_c>=0, squaring the two nonnegative sides shows strict negativity precisely when T_c^2<4Delta_c^3. This proves(5), including equality/zero-minimum cases. No optimization or root oracle is involved.

In particular, the FULL original all-k/all-A/all-compatible-gradient quasiconvexity question is equivalent to the assertion that EVERY actual compatible tuple with X>0 avoids the open semialgebraic region(5). The earlier k=1 lift is a different possible representation of the same full problem; neither representation is mandatory.

4. A rational parameter with paid bit complexity.

When(5) holds, an explicit rational h with P(h)<0 can also be computed with polynomial bit work. Here is a quantitative bound avoiding an uncharged exact square root.

Choose an integer H>=2 that bounds the absolute reduced numerators and positive reduced denominators of r0,r1,r2,r3,Delta_c,T_c. This H is computed from the rational data; log H is polynomial in their input length. Then
 1/H<=r3<=H, 1/H<=Delta_c<=H,

Moreover,

For T_c<0 the lower bound on Delta_c directly gives(6). For T_c>=0, the positive rational 4Delta_c^3-T_c^2 is at least H^-5. Dividing it by 2Delta_c^(3/2)+T_c<=3H^(3/2) shows

which implies(6). The root bounds follow from its displayed formula; if r2>0, rationalizing the numerator gives h_plus=-r1/(sqrt(Delta_c)+r2).

On [0,H^2+1] one has |P'|<=20H^5. Bisect the rational interval[0,H] to approximate sqrt(Delta_c) by a rational s with

This takes O(log H) bisections, each decided by the exact rational comparison s^2 versus Delta_c. Set

Then h>0, |h-h_plus|<=1/(10000H^15), and(6) with the derivative bound gives P(h)<0. Finally evaluate P(h) and the original gap P(h)/(h+4/3) exactly to output the negative rational margin. All numbers have O(log H) bits up to fixed constant factors, so ordinary integer arithmetic has polynomial bit cost. The parameter's NUMERICAL size can be large; no polynomial numerical search/field-construction bound is asserted.

For arbitrary real L4 fields, (4)--(5) are exact mathematical statements about finite moments, not an algorithm supplied with an oracle for those moments.

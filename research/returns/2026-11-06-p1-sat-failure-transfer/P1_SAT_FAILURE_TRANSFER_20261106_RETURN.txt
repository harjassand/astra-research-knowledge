## 1. The construction: polynomial precision is sufficient

Let:

- \(N\) be the complete binary input length;
- \(n\) be the number of distinct variables occurring in the formula;
- \(m\) be the number of clauses;
- \(E_F(x)\) be the number of clauses that assignment \(x\) violates.

Variable names can first be renamed densely, retaining a map back to their original names. The numerical value of the largest variable label is never treated as the number of variables. In an explicit encoding, \(n,m=O(N)\), and elementary string comparisons suffice for polynomial-time preprocessing.

Set
\[
b=2n+2,\qquad q=2^{-b},
\]
and define
\[
Z_F(q)=\sum_{x\in\{0,1\}^n}q^{E_F(x)}.
\]

This assigns weight \(1\) to every satisfying assignment and at most \(q\) to every nonsatisfying assignment.

If \(S(F)\) denotes the number of satisfying assignments, then
\[
S(F)\le Z_F(q)\le S(F)+2^nq
=S(F)+2^{-n-2}.
\]

Consequently,
\[
F\text{ satisfiable}\implies Z_F(q)\ge1,
\]
whereas
\[
F\text{ unsatisfiable}\implies Z_F(q)\le\frac14.
\]

There is therefore an exact gap between the two cases.

### The small weight does not hide exponential precision

Using the common denominator \(D=2^{bm}\),
\[
Z_F(q)=\frac{A}{D},
\qquad
A=\sum_x2^{b(m-E_F(x))}.
\]

The numerator has at most
\[
bm+n+1=O(N^2)
\]
binary digits. The denominator also has \(O(N^2)\) digits. The same bounds apply to restricted sums after fixing any prefix of the assignment, and hence to the numerators and denominators of conditional probabilities.

Thus this representation does **not** require an exponentially long integer or an exact-real primitive.

But the displayed sum still ranges over \(2^n\) assignments. Establishing that the answer fits in polynomially many bits does not establish that it can be computed in polynomial time.

That distinction is the first boundary of the construction.

## 2. A constant-error marginal estimate would suffice for deterministic search

Normalize the positive weights:
\[
\mu_F(x)=\frac{q^{E_F(x)}}{Z_F(q)}.
\]

Every assignment has positive probability, so every prefix has a well-defined conditional distribution—including prefixes that cannot extend to a satisfying assignment.

The following implication has a complete proof.

### Conditional rounding statement

Suppose a single total deterministic procedure could, for every \(F\), every prefix \(\alpha\), and the next variable \(x_i\), compute an estimate
\[
\widetilde p_i
\]
satisfying
\[
\left|
\widetilde p_i-
\Pr_{\mu_F}(x_i=1\mid\alpha)
\right|
\le\frac18
\]
in time polynomial in the complete query length.

Then deterministic polynomial-time SAT search and decision would follow:

1. Start with the empty prefix.
2. Set \(x_i=1\) when \(\widetilde p_i\ge\frac12\), and set \(x_i=0\) otherwise.
3. After all variables are set, evaluate the original formula.
4. Return the assignment if it satisfies the formula; otherwise return UNSAT.

**The estimator in this statement has not been constructed.** The statement identifies a sufficient operation; it does not supply that operation as an oracle.

### Proof of the rounding step

At each step, the selected branch has true conditional probability at least
\[
\frac12-\frac18=\frac38.
\]

By the probability chain rule, the final assignment \(x^\star\) therefore satisfies
\[
\mu_F(x^\star)\ge\left(\frac38\right)^n.
\]

If \(F\) is satisfiable, then \(Z_F(q)\ge1\). Every nonsatisfying assignment \(y\) has
\[
\mu_F(y)\le q=2^{-2n-2}
<\left(\frac38\right)^n.
\]

So \(x^\star\) must satisfy \(F\).

If \(F\) is unsatisfiable, direct evaluation rejects the final assignment and the procedure correctly returns UNSAT.

This establishes both sides of correctness **conditional on the estimator’s guarantee**.

### Complete conditional cost

There are \(n\) marginal queries. Each query includes the formula, its prefix, and the explicitly represented rational \(q\), all with polynomial encoding length.

If the missing estimator took at most \(CM^c\) bit operations on a query of length \(M\), the complete construction could be implemented in
\[
O\!\left(N^{c+1}+N^3\right)
\]
bit operations, including elementary renaming, prefix processing and final verification.

This is not the polynomial bound requested in the question: the procedure to which \(C\) and \(c\) would apply is missing.

The useful distinction is that this route does not demand exponentially accurate marginals. **Fixed additive accuracy would suffice—but obtaining it uniformly remains a hard computational task.**

## 3. The marginal task remains SAT-hard even with an explicit satisfying assignment

I checked whether positivity or a known feasible assignment might make the required estimation substantially easier. There is a direct reduction showing that neither condition removes the unrestricted SAT problem.

Let \(H(y_1,\ldots,y_h)\) be an arbitrary CNF. Put
\[
k=h+4.
\]

Introduce a selector \(s\) and fresh variables \(x_1,\ldots,x_k\), and construct
\[
G_H=
\left(\bigwedge_{C\in H}(s\lor C)\right)
\land
\left(\bigwedge_{i=1}^{k}(\neg s\lor\neg x_i)\right).
\]

This formula is always satisfiable. An explicit satisfying assignment is
\[
s=1,\qquad x_1=\cdots=x_k=0,\qquad y_1=\cdots=y_h=0.
\]

Its construction has polynomial cost. No information about whether \(H\) is satisfiable is needed to build it or its witness.

Now consider the two selector values.

When \(s=0\), the original formula \(H\) is active and all \(x_i\) are free. Its unnormalized mass is
\[
Z_0=2^kZ_H(q).
\]

When \(s=1\), all guarded clauses from \(H\) are satisfied. The energy is the number of \(x_i\) set to one, giving
\[
Z_1=2^h(1+q)^k.
\]

The total number of variables is
\[
r=h+k+1=2h+5.
\]
Choose
\[
q=2^{-2r-2}=2^{-4h-12}.
\]

If \(H\) is unsatisfiable, then \(Z_H(q)\le2^hq\), so
\[
\Pr_{\mu_{G_H}}(s=0)
\le2^kq
=2^{-3h-8}
\le\frac1{256}.
\]

If \(H\) is satisfiable, then \(Z_H(q)\ge1\). Since \((1+q)^k\le2\),
\[
\Pr_{\mu_{G_H}}(s=0)
\ge
\frac{16}{16+(1+q)^k}
\ge\frac89.
\]

Therefore:

| Original input \(H\) | Selector probability in the always-satisfiable \(G_H\) |
|---|---:|
| Unsatisfiable | At most \(1/256\) |
| Satisfiable | At least \(8/9\) |

An additive-\(1/8\) estimate of **one unconditional marginal**, followed by thresholding at \(1/2\), decides the arbitrary original formula \(H\).

This remains a polynomial reduction when a width-three encoding is required. Binary AND/OR gates can be encoded with functional CNF definitions, giving each original input assignment exactly one gate-consistent extension. With \(M\) total variables and weight \(q'=2^{-2M-2}\), all nonzero-energy extensions together contribute at most \(2^{-M-2}\). That contribution is too small to erase the selector gap.

The complete gate encoding, its costs and the resulting concrete formulas are retained in the package.

\[
\bigoplus_{\text{edges incident to }u}x_e=b_u.

Each vertex has degree three. Encode its parity equation using the four 3-clauses excluding the four local assignments of the wrong parity.

Compare two charge assignments:

- **Even instance:** every \(b_u=0\).
- **Odd instance:** one \(b_u=1\), with every other charge zero.

The resulting formulas have:

- \(3k\) variables;
- \(8k\) clauses;
- exactly three literals per clause;
- eight occurrences per variable;
- binary encoding length \(\Theta(k\log k)\).

The even instance is satisfiable. The odd instance is unsatisfiable.

\[
2^{e-v+1}
\]
preimages.

\[
Z_{\mathrm{even}}(q)
=
2^{e-v}\bigl((1+q)^v+(1-q)^v\bigr),

\[
Z_{\mathrm{odd}}(q)

2^{e-v}\bigl((1+q)^v-(1-q)^v\bigr).

\[
Z_{\mathrm{even}}(q)-Z_{\mathrm{odd}}(q)

## 5. Second explicit failure: exponentially slow local Gibbs updates

(s\lor a)
\land(s\lor\neg a)
\land
\bigwedge_{i=1}^{k}(\neg s\lor\neg x_i).
\]

It has \(k+2\) variables and \(k+2\) binary clauses, with no unit clauses. It has exactly two satisfying assignments:
\[
s=1,\qquad x=0,\qquad a\text{ arbitrary}.
\]

Its energy is
\[
E(s,a,x)=
\begin{cases}
1,&s=0,\\
|x|,&s=1.
\end{cases}
\]

Use the same weighting rule:
\[
q=2^{-2(k+2)-2}=2^{-2k-6}.
\]

Consider the exact single-site heat-bath chain:

1. Choose one variable uniformly.
2. Redraw it from its exact conditional Gibbs distribution.

The obstruction below already applies with exact transition probabilities.

### A large initial region has very small equilibrium mass

Let
\[
A=\{s=0\}.
\]

Its stationary probability is
\[
\pi(A)=
\frac{2^kq}{(1+q)^k+2^kq}
\le2^{-k-6}.
\]

But a uniform initial assignment lies in \(A\) with probability \(1/2\).

While \(s=0\), the energy is independent of \(a\) and all \(x_i\), so local updates leave those bits uniformly distributed unless the selector escapes.

At Hamming weight \(j=|x|\), an update of \(s\) changes it to one with probability
\[
\frac{q^j}{q+q^j}.
\]

Thus the mean escape probability per step of the reflected chain within \(A\) is
\[
\phi_k=
\frac{1}{(k+2)2^k}
\sum_{j=0}^{k}
\binom{k}{j}\frac{q^j}{q+q^j}.
\]

The \(j=0\) contribution is at most \(1\); the \(j=1\) contribution is \(k/2\); and the remaining terms sum to at most \(2^kq\). Therefore
\[
\phi_k\le2^{-k}.
\]

A coupling to that reflected chain and a union bound give
\[
\Pr(X_t\in A)\ge\frac12(1-t\phi_k)
\]
when the original chain starts uniformly.

For every integer
\[
t\le2^{k-2},
\]
we obtain
\[
\Pr(X_t\in A)-\pi(A)
\ge
\frac38-2^{-k-6}
>\frac14.
\]

This is an error bound for the **selector marginal itself**, not merely for some inaccessible feature of the full distribution.

So polynomially many updates cannot uniformly supply the additive-\(1/8\) marginal needed by the rounding construction. The lower bound is exponential in \(k\), and therefore superpolynomial in the complete \(\Theta(k\log k)\)-bit formula description.

Exactly-three-literal instances can also be obtained by replacing every binary clause \(C\) with
\[
(C\lor z_C)\land(C\lor\neg z_C).
\]
For every assignment of the fresh padding bits, this preserves the number of violated clauses. The package includes such an instance.

### Exact failed claim and scope

The falsified claim is:

> Uniform-start, random-scan, single-site heat-bath updates at this weighting always provide sufficiently accurate marginals in polynomial time.

This result does not exclude preprocessing, nonlocal moves, other representations or arbitrary SAT algorithms. The unpadded family is 2-CNF and is efficiently solvable.

The example refutes the proposed evaluator’s universal runtime guarantee. It supplies no unrestricted SAT lower bound.

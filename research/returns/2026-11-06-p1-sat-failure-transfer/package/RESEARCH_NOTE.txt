1. INPUT AND COST MODEL

Let N be the complete binary description length of a CNF F. Let n be the number
of distinct variables actually occurring, m the number of clauses, and L the
number of literal occurrences. Names can be arbitrary binary strings. Densely
rename occurring variables and retain a reversible map. Pairwise string
comparison and repeated scans suffice in O(N^3) bit operations; more efficient
implementations are unnecessary for this argument. In a standard explicit
encoding n,m,L=O(N). The numerical value of the largest variable name is not n.

Assignments are returned for the variables of F, with the original names.
Unused variables in a syntactic header may be assigned zero implicitly; a
binary-encoded declaration of exponentially many unused variables is not an
obligation to print exponentially many redundant output bits.

Repeated clauses and literal occurrences are allowed. A tautological clause
contributes zero energy; an empty clause contributes one. The analysis need not
silently discard either. The case n=0 is decided by direct evaluation.

All arithmetic below is exact integer/rational arithmetic. None of the bounds
count a growing integer, an exact real, or a simultaneous evaluation of all
assignments as one operation.

2. A POLYNOMIAL-PRECISION WEIGHTING

For x in {0,1}^n define E_F(x) as the number of violated clauses. Set

    b = 2n+2,        q = 2^(-b),
    Z_F(q) = sum_x q^(E_F(x)),
    mu_F(x) = q^(E_F(x))/Z_F(q).

Every assignment has strictly positive weight. If S(F) is the number of
satisfying assignments, then

    S(F) <= Z_F(q) <= S(F) + 2^n q
                        = S(F) + 2^(-n-2).

In particular UNSAT implies Z_F(q)<=1/4, whereas SAT implies Z_F(q)>=1.
The exact count is floor(Z_F(q)). This is an identity, not an efficient
evaluation algorithm.

Precision is fully finite. With D=2^(bm),

    Z_F(q) = A/D,
    A = sum_x 2^(b(m-E_F(x))),
    0 < A <= 2^(bm+n).

A and D have at most bm+n+1 and bm+1 binary digits respectively. Both are
O(N^2). The same common denominator works under every prefix restriction.
Conditional marginal probabilities are ratios of such integer sums, and their
numerators and denominators also require O(N^2) bits. A small numerical value
of q therefore does not create an exponential representation cost.

Computing A by its displayed sum examines 2^n assignments. The exact reference
implementation does precisely that. A compact answer is not a fast evaluator.

3. CONSTANT-ERROR CONDITIONAL MARGINALS WOULD SUFFICE

Conditional theorem. Suppose one has a single total deterministic procedure
A which, given (F,q,alpha,i), returns an estimate p_tilde satisfying

    |p_tilde - mu_F[x_i=1 | x extends alpha]| <= 1/8

for every CNF, every prefix alpha, and every next variable i, with a polynomial
bound in the complete query bit length. Then a uniform deterministic
polynomial-bit-time SAT search-and-decision algorithm follows.

Construction:

    alpha := empty
    for i = 1,...,n:
        obtain the stipulated estimate p_tilde
        append 1 if p_tilde >= 1/2, otherwise append 0
    evaluate F(alpha)
    return alpha if it satisfies F, otherwise return UNSAT

The estimate is NOT implemented here; A is the missing mathematical operation.

Proof. At every step the true conditional probability of the selected branch
is at least 3/8. The probability chain rule therefore gives

    mu_F(alpha_final) >= (3/8)^n.

If F is satisfiable, then Z_F(q)>=1. Every nonsatisfying assignment y has

    mu_F(y) <= q < (3/8)^n.

The produced assignment must therefore satisfy F. If F is unsatisfiable,
direct verification cannot accept any assignment and correctly returns UNSAT.
No prefix has undefined conditional probability because q>0.

Cost. There are n queries, each of O(N) bits after dense renaming, including
the O(n)-bit denominator of q and the prefix. If the missing procedure takes
at most C M^c bit operations on a query of length M, the full computation has
cost O(N^(c+1)+N^3), with constants depending only on that procedure and the
fixed encoding. There is no instance-dependent advice. This is a conditional
cost statement, not the requested complete polynomial-time construction.

The reference program obtains each p exactly by exhaustive enumeration and
perturbs it toward the less likely branch by at most 1/8. Those tests check the
rounding implication. They do not implement A efficiently.

4. EVEN A SINGLE MARGINAL WITH A KNOWN WITNESS RETAINS SAT HARDNESS

Here is a polynomial construction showing why the missing marginal operation
cannot be justified merely by positivity or by supplying one feasible point.

Given any CNF H(y_1,...,y_n), set k=n+4 and introduce a selector s and fresh
x_1,...,x_k. Construct

    G_H = [AND over C in H of (s OR C)]
          AND [AND over i=1,...,k of (NOT s OR NOT x_i)].

It has n_G=n+k+1=2n+5 variables and m_H+k clauses. Its bit encoding and the
time to write it are polynomial in the complete input length of H. The
assignment s=1, x=0, y=0 is supplied explicitly and always satisfies G_H.

For any positive q, its two unnormalized selector masses are exactly

    Z_0 = 2^k Z_H(q),
    Z_1 = 2^n (1+q)^k.

Use q=2^(-2n_G-2)=2^(-4n-12). If H is unsatisfiable, Z_H(q)<=2^n q,
so

    mu_G[s=0] <= 2^k q = 2^(-3n-8) <= 1/256.

If H is satisfiable, Z_H(q)>=1. Also (1+q)^k<=2: for example
kq<=4/4096<1/2 and (1+q)^k<=exp(kq)<2. Therefore

    mu_G[s=0] >= 16/(16+(1+q)^k) >= 8/9.

An additive-1/8 approximation to this one unconditional marginal, even when
accompanied by the explicit satisfying assignment, decides the arbitrary
original H by thresholding at 1/2. This is a reduction, not a proof that such
an estimator cannot exist.

The statement can be retained at width at most three. Build a Boolean circuit
for G_H using binary OR and AND gates, add the standard definitional clauses
for each gate, and assert the output. For z=(a OR b), use

    (NOT a OR z), (NOT b OR z), (a OR b OR NOT z).

For z=(a AND b), use

    (NOT z OR a), (NOT z OR b), (z OR NOT a OR NOT b).

Signed input literals are permitted as wires. Every assignment of the original
variables has exactly one gate-consistent extension. This follows inductively
along the circuit, and every gate has a complete local truth-table check.
The encoding is parsimonious, including separately for s=0 and s=1.

If M is the number of all variables after this encoding, choose
q'=2^(-2M-2). Total nonzero-energy weight is at most 2^M q'=2^(-M-2).
The two zero-energy masses are

    a_0 = 2^k S(H),          a_1 = 2^n.

Thus UNSAT gives mu[s=0]<=1/8, and SAT gives mu[s=0]>=8/9 (the actual
bounds are stronger). The additive-1/8 threshold still works. Gate count,
variable count, binary encoding, q' precision, and witness extension are all
polynomial in H's complete input length. No counting oracle was used in
constructing the reduction. This does not strengthen the unresolved target
into a proved lower bound.

5. FIRST RETAINED FAILURE: LOW-ORDER VIOLATION STATISTICS

Explicit family. For k>=3 take the prism graph C_k x K_2. It has v=2k vertices,
e=3k edges, and degree three. Put one Boolean variable x_e on each edge. For
each vertex u impose XOR of its three incident edge variables = b_u.
Encode that equation by the four 3-clauses excluding its four wrong-parity
assignments. An assignment violating the equation violates exactly one of
those four clauses. Let F_b be the resulting CNF.

The input has 3k variables, 8k clauses, maximum clause width three, and eight
occurrences per variable. Its ordinary binary encoding has Theta(k log k)
bits. There are no unit clauses, tautological clauses, or repeated clauses.

Compare b_even=0 at every vertex with b_odd=1 at the first vertex and zero
elsewhere. The first formula is satisfiable; the second is unsatisfiable.

Exact distribution. The incidence map of a connected graph over F_2 has image
the even-parity vertex vectors and kernel dimension e-v+1. One way to see
surjectivity onto that image is to route paired odd vertices along a spanning
tree; the one necessary parity constraint is the sum of all rows. Every
attainable syndrome therefore has exactly 2^(e-v+1) preimages. Consequently
the violation-count histogram is

    H_even(j) = 2^(e-v+1) binom(v,j), j even, and 0 otherwise;
    H_odd(j)  = 2^(e-v+1) binom(v,j), j odd,  and 0 otherwise.

Equivalently, their partition polynomials are

    Z_even(q) = 2^(e-v)[(1+q)^v + (1-q)^v],
    Z_odd(q)  = 2^(e-v)[(1+q)^v - (1-q)^v].

Their difference has a zero of order v at q=1. The derivatives of orders
0 through v-1 there coincide. Since those derivatives give factorial moments
of E under the uniform assignment law, their ordinary moments of all orders
0 through v-1 also coincide. Yet

    Z_even(0)=2^(e-v+1),       Z_odd(0)=0.

For the triangular prism k=3 the exact histograms are:

    energy j       0    1    2    3    4    5    6
    even          16    0  240    0  240    0   16
    odd            0   96    0  320    0   96    0

The first five moments agree. The formula files contain the actual 24
3-clauses on nine variables for both sides.

Failed claim, precisely: the truncated violation-moment data through some
order r<v always determines satisfiability, or always determines the
zero-energy contribution by high-temperature Taylor truncation.

Scope: this falsifies that summary/readout rule. It does not exclude access
to the original clauses, other statistics, structural algorithms, or computing
more moments. The family is affine and has a polynomial algorithm by linear
algebra. A polynomial number of all higher moments is not ruled out; acquiring
them efficiently is a separate task. This is not a lower bound on SAT.

6. THE SAME FAILURE CAN AFFECT A REQUIRED ONE-BIT MARGINAL

Add a selector s to the parity equation at the first vertex, and make the
charge there b in {0,1}; all other charges remain zero. The first equation
now has four variables and is encoded with eight 4-clauses. Other vertices
keep their four 3-clauses. Call the result F_b^sel.

For fixed s the global charge is b+s modulo two, so

    Z_(b,s)(q) = 2^(e-v)[(1+q)^v + (-1)^(b+s)(1-q)^v].

For s=0 and for s=1 separately, the uniform restricted moments of E through
order v-1 are identical for b=0 and b=1. Thus the summary consisting of all
those joint moments of E and s is the same. Nevertheless, with

    r=(1-q)/(1+q),
    mu_b[s=1] = [1 + (-1)^(b+1) r^v]/2.

Their separation is r^v, which exceeds 1/4 at the stipulated
q=2^(-2(e+1)-2). For instance r^v >= 1-2vq by Bernoulli's inequality, and
the latter is already much larger than 1/4 at k=3 and increases thereafter.
No readout using only that common summary can be within 1/8 of both answers.
The full raw inputs do differ. This is not an indistinguishability argument
against algorithms allowed to inspect and process the clauses.

7. SECOND RETAINED FAILURE: LOCAL GIBBS UPDATES

Explicit family. For k>=1 use variables s,a,x_1,...,x_k and

    T_k = (s OR a) AND (s OR NOT a)
          AND [AND_i (NOT s OR NOT x_i)].

There are k+2 variables and k+2 binary clauses. It is satisfiable, with exactly
two satisfying assignments: s=1, x=0, a arbitrary. It has no unit clauses.
Its energy is particularly simple:

    E(s,a,x) = 1 when s=0;
    E(s,a,x) = |x| when s=1.

Use q=2^(-2(k+2)-2)=2^(-2k-6). Define the single-site heat-bath chain: at each
step choose one of the k+2 coordinates uniformly, then redraw that bit from
its exact conditional Gibbs distribution. This is the exact chain, without
sampling or rounding error in its transition probabilities.

Let A={s=0}. Its stationary probability is

    pi(A) = 2^k q / [(1+q)^k + 2^k q] <= 2^(-k-6).

Conditional on A, a and all the x bits are uniform. A reflected version of
the chain, which never permits a selector flip out of A, preserves that
uniform law. At Hamming weight j, a selector update exits A with probability

    q^j/(q+q^j).

Therefore the average escape probability per reflected step is exactly

    phi_k = [1/((k+2)2^k)]
            sum_(j=0)^k binom(k,j) q^j/(q+q^j).

The j=0 term is at most 1, the j=1 contribution is k/2, and for j>=2 the
probability is at most q^(j-1)<=q. Hence

    phi_k <= [1+k/2+2^k q]/[(k+2)2^k] <= 2^(-k).

Start the actual chain from the uniform law on all assignments. Half of this
law starts uniformly in A. Couple its A-started trajectories to the reflected
chain until the first escape. A union bound on escape attempts, each having
unconditional reflected probability phi_k, gives

    Pr[X_t in A] >= (1/2)(1-t phi_k).

For k>=2 and t<=floor(2^(k-2)),

    Pr[X_t in A] - pi(A) >= 3/8 - 2^(-k-6) > 1/4.

This lower bounds both total-variation error and the error in the selector
marginal itself. Thus polynomially many such updates do not uniformly provide
the additive-1/8 marginal required in Section 3, even with exact transition
probabilities and an easily sampled uniform starting law. The failure is
asymptotic, not a finite timing extrapolation.

If exactly-three-literal clauses are desired, replace every binary C by
(C OR z_C) AND (C OR NOT z_C), with a fresh z_C. For every original assignment
and every padding assignment, violated-clause count is unchanged. Original
Gibbs marginals are unchanged at each fixed q. Extra coordinates only slow the
corresponding random-scan chain. Choosing q for the larger full variable count
also preserves the preceding upper bounds on escape. The supplied exact-3
fixture is such an energy-preserving padding.

Scope: this excludes the specified chain's universal polynomial mixing or
marginal-estimation assertion at the specified weighting. It does not exclude
nonlocal moves, other representations, preprocessing, or arbitrary SAT
algorithms. The unpadded family is 2-CNF and can be solved efficiently. The
counterexample is about the proposed evaluator, not about SAT hardness.

8. USE OF ACCEPTED CAPITAL AND PRIMARY SOURCES

Accepted earlier q-Horn/linear-autarky reductions, structural algorithms,
explicit-residual and representation obstructions were not promoted into
unrestricted results. Their prior scopes remain unchanged. They were not
reproved here as a substitute for new construction.

The Astra N1118 packet and its governing 636-line TeX source were acquired at
the source revision listed below. Its theorem is conditional on the pinned
replacement-form source. Its exact phase-counting guarantee has fixed locality
and root order and log(2+m/n)=o(log n); it is subexponential, not polynomial.
Its guards, expansion costs, denominator bounds, and retained failures remain
part of its contract.

The pinned OpenAI source's product/replacement interface and common counting
routine were read as well. That routine explicitly retains

    C_d = sum_(j<=d) 2^j binom(n,j),

where d is the retained Taylor correction order (not the Gibbs weight q).
It also enumerates group assignments and measurement tuples. Merely
reapplying the algorithm to smaller groups does not remove already incurred
outer enumeration. The supplied design controls replacements at the selected
points, not all their derivatives. Its group factors after fixing measurements
are not automatically fresh bounded-locality Boolean phase instances. No
closure or reconstruction theorem establishing a polynomial recursion was
constructed here. This is a missing bridge, not a general impossibility proof.

The weighting in Section 2 uses a dyadic weight whose exponent grows with n;
it is not a fixed-order root of unity. N1118 therefore does not automatically
supply its evaluator. Encoding a new sum or circuit must charge every added
variable and every reconstruction step.

The original Cook/Clay formulation concerns uniform deterministic polynomial
time in the complete input length. The current Clay page labels the general
problem unsolved. Neither finite tests nor these restricted failures alter
that status. The mathematical reductions above stand as direct arguments;
the cited sources are not claimed to have proved this particular package.

9. EXACT CHECKS AND REPRODUCTION

Run, using standard Python 3 and no external packages:

    python3 verify.py --out results.json --fixtures fixtures

The checker enumerates assignments and uses integer arithmetic and Fraction.
It checks the derived formulas against the literal CNFs, verifies moment
agreement and selector separation, checks exact escape-flow inequalities,
checks energy-preserving width-three padding, and exercises conditional
rounding with adversarial bounded errors.

The first executed suite checked three prism SAT/UNSAT pairs, three selector
pairs, ten trapping formulas, four width-three padded formulas, every CNF of
at most three distinct non-tautological clauses on zero through three declared
variables (3,444 formulas), and four additional duplicate/tautology/empty cases.
The subsequent integrated suite additionally checked the one-marginal
amplification identities and the parsimonious gate interface; exact counts are
recorded in results.json. Both suites passed. No floating-point fit, solver
oracle, or asymptotic runtime benchmark was used.

The general claims rely on the proofs in Sections 2-7. The finite checks
support implementation fidelity and exhibit concrete refutations. They do
not prove an unrestricted complexity bound.

10. RETAINED FRONTIER

The candidate positive route has a complete finite-precision rounding argument
but an unconstructed uniform conditional-marginal evaluator. A single such
coarse marginal already encodes arbitrary SAT, even on the always-satisfiable
known-witness construction. Low-order moment readout and single-site Gibbs
evaluation fail on the explicit families retained here. The inspected
replacement-form machinery does not supply a polynomial recursive evaluator
at its presently established interface.

None of this excludes a different polynomial-time SAT algorithm. No theorem
excluding all such algorithms was obtained. No work or computation is claimed
to continue after this returned checkpoint without a further active turn.

The object-only transfer packet contains explicit instances/families, the
failed claims, and their scopes, omitting preferred fixes and proof narratives.
It has not been sent to another role. The current research note and verifier
are separate from that proposed initial scientific transfer.

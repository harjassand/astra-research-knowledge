ACTUAL EXPECTED MEMORY UNDER IMPERFECT EMISSION
5 November 2026

Conventions: all channel distances are half diamond; classical distances are
total variation. The theorem assumes 0<=nu<=1 and epsilon+nu<=1/2.

INTERFACE

Compare the declared ideal emission to an actual emission with flagged
whole-output half-diamond distance at most nu, including the late source
control record and every receiver-accessible side output. The two experiments
have the same fixed arrival and record-disclosure schedule. The same receiver
instrument acts at the same physical cut and assigns the same quantum
dimension to each classical branch in both experiments. The source has no
receiver-dependent future operations; no additional side channel is supplied.

A final-output channel comparison WITHOUT this common timing contract is
insufficient: identical final states can arrive in different orders, and an
early selector changes the memory cost even at zero final-channel distance.
Unbounded timing shifts likewise need a temporal/process comparison.

CAPACITY

If the actual reader has recovery error epsilon, compose that same receiver
with the ideal emission. Contractivity and the triangle inequality bound
the ideal recovery error by epsilon+nu. Therefore, with

  r_e=1-8e(1-e)/kappa,

the per-branch uniform capacity at an ell-qubit prefix satisfies

  m_ell/2^ell >= max{0,r_(epsilon+nu)}.

This statement does not require closeness of mean resource usage.

ACTUAL EXPECTED OCCUPANCY

Let branch y retain quantum dimension m_y=2^(q_y). Set z_y=min(q_y,ell),
so 0<=z_y<=ell. Under the maximally mixed payload/Bell marginal, the ideal
branchwise rank proof gives

  E_ideal 2^(z_y-ell) >= r_(epsilon+nu).

The convex chord bound on [0,ell] gives

  E_ideal z_y >= f_ell(r_(epsilon+nu)),
  f_ell(r)=max{0,ell(r-2^(-ell))/(1-2^(-ell))}.

Data processing of the flagged whole-emission comparison through the deferred
prefix instrument bounds the total variation of the ideal and actual
classical branch laws by nu. Since z_y has range at most ell,

  E_actual z_y >= E_ideal z_y-ell*nu.

Using q_y>=z_y and nonnegativity proves

  E_actual q_y >= max{0,f_ell(r_(epsilon+nu))-ell*nu}.

There is no extra factor of two with the stated half-diamond/total-variation
conventions. The truncation removes any need for an upper bound on actual
branch memory: extra ancillas only increase q_y.

Apply the same bound pointwise between common fixed arrival slots before any
selector information appears. Integrating gives the corresponding actual
expected qubit-time. In particular, with spacing at least tau,

  E_actual exposure >=
    tau sum_(ell=1)^(s-1) max{0,f_ell(r_(epsilon+nu))-ell*nu}.

The ideal n=1000 numbers in the figure use nu=0. At fixed total comparison
error epsilon+nu=.01 and kappa=.8, a conservative actual pre-flag bound is
450950.228340645*tau - nu*500500*tau, clipped at zero; the sum of the
individually clipped bounds can be stronger.

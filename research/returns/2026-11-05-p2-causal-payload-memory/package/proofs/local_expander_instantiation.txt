1. EXACT PRIMARY INPUT

For n=3s, s>=1, let C_ab be CNOT with control a and target b. Indices are
periodic modulo n, represented in {1,...,n}. The 16 indexed generators are

 U1=X1; U2=Z1;
 U3=C12; U4=C21; U5=C23; U6=C32;
 U7,...,U12 = product_(i=0)^(s-1) C_(3i+a,3i+b),
             one for each a,b in {1,2,3}, a!=b;
 U13=product_i C_(3i+4,3i+2);
 U14=product_i C_(3i+5,3i+1);
 U15=product_i C_(3i+5,3i+3);
 U16=product_i C_(3i+6,3i+2).

Choose any fixed enumeration of the six ordered pairs for labels 7,...,12.
At small n, some indexed matrices coincide; retain their sampling multiplicity.
With uniform sampling, Phi(A)=(1/16)sum Uj A Uj* satisfies

 ||Phi(A)||_2 <= (1-gamma)||A||_2 whenever Tr A=0,
 gamma >= gamma0 := 1/(2*10^8).

This is an absolute contraction: both spectral ends are controlled. Each
generator is a disjoint-pair CNOT layer or a single Pauli, is Hermitian, squares
to identity, and has ring interaction range at most four. Each layer's control
residue and target residue modulo three are distinct, proving disjointness.

2. BALANCED LIFT, UNIFORM 17 LABELS

Let carriers have dimension D=2^n and add a flag F, giving N=2D. Set

 H0=Z_F tensor I_D;
 Hj=X_F tensor Uj, j=1,...,16;
 pj=1/17, j=0,...,16.

These are balanced Hermitian involutions. For an arbitrary complex operator
K=I tensor A+X tensor B+Y tensor C+Z tensor E,

 ||[K,H0]||_2^2=8(||B||_2^2+||C||_2^2),

 average_(j=1..16)||[K,Hj]||_2^2
  =2 average_j (||[A,Uj]||_2^2+||[B,Uj]||_2^2
                     +||{C,Uj}||_2^2+||{E,Uj}||_2^2).

The absolute expander gap gives

 average_j ||[A,Uj]||_2^2 >=2gamma||A-(Tr A/D)I||_2^2,
 average_j ||{A,Uj}||_2^2 >=2gamma||A||_2^2.

The anticommutator inequality holds on scalar operators as well, where its
left side equals 4||A||_2^2. Combining the Pauli blocks proves

 sum_j pj ||[K,Hj]||_2^2
   >= kappa ||K-(Tr K/N)I||_2^2,
 kappa=min(32gamma/17,4/17).

Using only the published certified gap,

 kappa0=16/(17*10^8) = 9.41176470588235e-9.

This is a very small certified numerical robustness constant. It is independent
of n; it is not a practical one-percent error threshold. Gap amplification
changes selector and execution costs and is not silently available.

Choose V0=I and Vj=controlled-Uj (H_F tensor I_D). Then
Vj(Z_F tensor I_D)Vj*=Hj. Prepare the actual carrier state I_D/D and encode

 E_j(rho_FR)= (Vj tensor I_R)(rho_FR tensor I_D/D)(Vj* tensor I_R).

The source preparation is known. This is a new constructed family, not the
natural partial-SWAP collision channel and not its low-memory decoder.

A calibrated 17-way classical randomizer supplies the uniform selector. Five
fair bits with rejection also suffice, with 32/17 attempts in expectation. For
a finite fixed initialization deadline, B attempts leave failure probability
(15/32)^B, which must be charged to the implementation error or reported as an
independent heralded preparation failure. Selection occurs before the common
stream clock starts; no selector-dependent timing is exported.

3. FIXED PHYSICAL EMISSION ORDER AND CLOCK

Use one common output order for every selector:

 carrier 5,6,...,n, then carriers 1,2,3,4, then flag F, then selector j.

For n<4 interpret the first block as empty and the second as 1,...,n. These
finite small cases can simply retain all their at most six carriers. The
permutation is fixed, known, independent of j, and preserves the commutator gap.
There is no selector-dependent arrival pattern, missing output, or timing flag.

For n>=9, retain sites 1,...,4 in four boundary registers. Generate the remaining
independent tracial carriers in natural order. Keep a four-site look-ahead
window. When fresh site t arrives, its matched partner is either already in the
boundary/window registers or has yet to arrive. Apply the corresponding
flag-controlled gate when both partners are present. A nonwrapping gate joins
sites at separation <=4, so both are available before the earlier site is
released. A wrapping partner is among retained sites 1,...,4. After loading
t>=9, release site t-4. At the end, flush the window and then the four boundary
registers in the common order. For n=3,6, a fixed finite buffer handles the
whole block, with the same announced order convention.

Peak source workspace is at most four boundary carriers, four window carriers,
one newly loaded carrier, and the coherent flag: ten qubits. This is a safe
bound rather than an optimization. The original unknown source may be swapped
into the flag at initialization and then discarded; that transfer is an explicit
gate/resource if F is not itself the input register.

Each source CNOT becomes a Toffoli controlled by F. Pauli cases require a
controlled Pauli. A fixed ten-register local gate cell can route and compile
these into a constant number of bounded-strength one- and two-qubit gates.
The source can pad every clock slot to the worst-case local compilation time.
There is a common fixed initial fill, one carrier per declared emission slot,
and a common fixed final flush. If a hardware port requires a load on every
clock, use and discard a fixed number of additional tracial padding carriers
during fill/flush; at most a constant number is needed and it is counted.
Padding and release do not depend observably on j.

Thus the source uses n+O(1) carrier preparations, O(n) local gates and routing
operations, O(n) time at fixed hardware rates, and O(1) retained source qubits.
The flag and four boundary carriers require protection for O(n) slots, while
window storage is O(1) slots. This protection is a real supplied or compiled
resource. No carrier preparation labels or purifiers are delivered to the
receiver. The independent tracial preparation factory itself is part of the
physical premise and bill.

4. EARLY-SELECTOR POSITIVE OPERATION

CNOT has a product eigenbasis:

 CNOT (|c>_Z tensor |b>_X) = (-1)^(c*b)|c>_Z tensor |b>_X,
 |b>_X=(|0>+(-1)^b|1>)/sqrt(2).

If j is supplied before the carriers, measure each control site in Z and each
target in X. Measure or discard unmatched sites arbitrarily. Compute the parity
b_total = XOR_over_pairs (control_bit AND target_X_bit). For U1 or U2 measure
the first site in X or Z, respectively. For j=0 no carrier data are needed.

Refining the Uj eigenspaces into this full product basis is harmless. A product
basis outcome with eigenvalue (-1)^b_total leaves the late flag/reference in

 (Z_F^b_total H_F tensor I_R) rho_FR (H_F Z_F^b_total tensor I_R).

Its probability is independent of rho_FR. On arrival of F, apply H_F Z_F^b_total
(rightmost gate first). This restores arbitrary rho_FR exactly. For j=0 the
flag is already rho_FR. The claim is reference-uniform and instrument-level.

Receiver quantum cost is one arriving flag qubit plus the currently measured
carrier, with no intersite coherent delay, two-qubit measurement or coherent
return link. Product-basis measurement is local even for wrapping CNOT pairs.
Only outcomes need be buffered. At most four matched pairs cross any cut in
the common rotated output order: each of the two arc boundaries crosses at
most two length-four matching edges. Thus four pending classical bits and one
running parity bit suffice. A controller with an explicit site counter costs
O(log n) classical bits; a physically supplied periodic clock/end marker permits
a fixed finite controller. The selector itself uses five classical bits.

Work is O(n) one-qubit measurements, Boolean updates and bounded local flag
correction. The four pending classical bits can last O(n) slots. Readout and
classical timing/routing are paid, even though they need no quantum protection.

5. LATE SELECTOR AND ERRORS

Across the cut after all carriers and F but before j, root's theorem gives

 m/N >= 1 - 8epsilon(1-epsilon)/kappa

for any receiver whose selector-averaged recovered qubit channel is within
epsilon in half diamond of the identity. The quantum dimension m is counted
in each classical branch. Arbitrary classical records and arbitrary pre-selector
processing are allowed; every retained coherent register and delay line counts.

Keeping all n+1 output qubits is an exact upper bound. When j arrives, perform
the same product measurements and flag correction. This matching upper bound
does not require a large reverse quantum circuit, only large retained memory.

Every source, receiver, routing, readout and memory-storage error contributes to
the implemented channel. If G=O(n) operations have worst-case half-diamond
errors e_g, telescoping gives total error <=sum_g e_g. Fixed total error can
therefore require per-operation accuracy O(1/n) absent a sharper structured
noise argument or a fault-tolerant implementation. The proof does not turn fixed
local unprotected noise into fixed reference-uniform channel error.

## Selected question: efficient access to a three-dimensional passive quantum memory

**Can we write an arbitrary unknown qubit into a three-dimensional local quantum memory, hold it passively for stretched-exponential time at a fixed positive temperature, and recover it—with polynomial write/read costs and an explicit account of preparation, control, uncertainty and reuse?**

The guarantee must preserve entanglement with an external reference. Writing and reading may use active control. During storage, the memory receives no scheduled syndrome measurements, correction cycles or refresh gates.

I selected this question because its successful resolution would turn a protected thermal encoding into an accessible quantum-information operation. I also obtained a substantial opening: **an exact reduction from thermal syndrome sampling to quantum loading, a proved sampler for contracting decoder histories, and a source-conditional construction for the recently proposed three-dimensional memory family.**

The principal unresolved comparison is consequential: existing Code Swendsen–Wang or regular-matroid algorithms might already supply the required sampler. I have not ruled that out. The construction is therefore ready for a question-level challenge, but I am not presenting it as an established new discovery over the strongest existing methods.

## 1. The consequence the question earns

Consider a known commuting stabilizer Hamiltonian on \(N\) qubits,

\[
H_N=\sum_{a=1}^{m}J_a\frac{I-S_a}{2},
\qquad
m=O(N),
\qquad
0<J_{\min}\le J_a\le J_{\max},
\]

with bounded interaction support and bounded geometric range in three dimensions. A violated check \(S_a\) costs energy \(J_a\).

The target is the **random-embedding family** in Balasubramanian–Davydova–Lin’s May 2026 preprint. I use its decoder-defined thermal encoding and stated lifetime theorem. The paper’s separate explicit-embedding proposal is not substituted for the family whose lifetime is proved. :chatgpt-content-reference{index="0"}

The desired operational theorem has the form

\[
\boxed{
\frac12
\left\|
\widetilde{\mathcal D}_N
\Phi_{N,t}
\widetilde{\mathcal E}_N
-\operatorname{id}
\right\|_\diamond
\le
\varepsilon_{\rm sample}
+\varepsilon_{\rm calibration}
+\varepsilon_{\rm control}
+\varepsilon_{\rm read}
+C\Gamma Nt\,e^{-cN^\eta}.
}
\]

Here:

- \(\widetilde{\mathcal E}_N\) writes the unknown input using product/reset ancillas.
- \(\Phi_{N,t}\) is the specified passive thermal evolution.
- \(\widetilde{\mathcal D}_N\) reads the qubit.
- \(\Gamma\) bounds the local bath rates.
- \(c,\eta>0\) are fixed family constants.

The diamond norm makes this a reference-preserving quantum guarantee.

At fixed overall error, this would allow

\[
t=\exp(c'N^\eta),\qquad c'<c,
\]

while writing and reading remain polynomial in \(N\) and the desired inverse accuracy. Conversely, the asymptotic qubit requirement for a prescribed holding time would grow as a power of \(\log t\), subject to the family’s constants and the polynomial prefactor.

That is the concrete consequence: **efficient preparation and recovery surrounding a long passive storage interval**. The full expenditure still includes occupying and cooling the memory for that interval.

The general protected-observable stability criterion supplies the connection between a small unstable Gibbs weight and a storage bound. A concrete sufficient holding model is a Davies generator with bounded local system–bath couplings, energy-resolved transitions and bounded rates. This treats the Markovian semigroup as the dynamics; deriving its accuracy from a finite-coupling physical bath uniformly over exponential times would require an additional theorem. :chatgpt-content-reference{index="1"}

I have deliberately allowed active initialization. Requiring preparation itself to be passive would impose a restriction the useful operation does not need. An efficient ground-state encoder together with a comparable ground-start lifetime theorem would also answer the selected question.

## 2. The exact operation connecting a classical sampler to an unknown qubit

Let \(\mathcal S\) be the valid stabilizer syndromes. Choose a ground-space encoding isometry \(V_0\), and let \(F_s\) be the Pauli correction for syndrome \(s\) in the **same decoder frame that defines the protected logical observables**.

Set

\[
V_s=F_s^\dagger V_0.
\]

The ranges of different \(V_s\) occupy orthogonal syndrome sectors. For a probability distribution \(p\) on \(\mathcal S\), define

\[
\mathcal E_p(\rho)
=
\sum_{s\in\mathcal S}
p(s)V_s\rho V_s^\dagger.
\]

This is an executable loading procedure:

1. Sample \(s\) classically.
2. Encode the unknown input with \(V_0\).
3. Apply \(F_s^\dagger\).

The classical sample can be prepared before the unknown input arrives.

The exact identity is

\[
\boxed{
\frac12\|\mathcal E_p-\mathcal E_q\|_\diamond
=
\operatorname{TV}(p,q).
}
\]

**Proof.** For any input entangled with a reference, the output difference is block diagonal across syndrome sectors. Its \(s\)-block is a normalized positive state multiplied by \(p(s)-q(s)\). The trace norms therefore add to

\[
\sum_s|p(s)-q(s)|,
\]

independently of the input or reference.

The thermal distribution is

\[
p_{\beta,J}(s)
=
\frac{1}{Z}
\exp\!\left[-\beta\sum_aJ_as_a\right],
\qquad s\in\mathcal S.
\]

All valid syndrome sectors have the same logical dimension, so no additional syndrome-dependent quantum degeneracy enters this distribution.

This reduction also fixes the comparison standard. **An efficient full Gibbs-state preparation algorithm is a valid competitor.** Measure its commuting stabilizers, retain the classical syndrome, and use the procedure above to load a fresh unknown input. Randomization of the sampler’s logical sector does not disqualify it.

### Preparation error is paid once

If

\[
\frac12\|\widetilde{\mathcal E}-\mathcal E_{\beta,J}\|_\diamond
\le\varepsilon,
\]

then channel contractivity gives, for every holding time,

\[
\frac12
\left\|
\mathcal D\Phi_t\widetilde{\mathcal E}
-
\mathcal D\Phi_t\mathcal E_{\beta,J}
\right\|_\diamond
\le\varepsilon.
\]

There is no factor of \(t\).

Thus fixed or inverse-polynomial initialization accuracy can support exponentially long storage in the stated model. Exponentially accurate initialization is an unnecessary requirement. Errors continuously introduced by unwanted dynamics require a separate analysis.

## 3. The central constructive opening: retain the decoder history

The difficult operation is sampling the thermal syndrome law. Physical syndrome bits can obey large parity constraints. A bound showing that dangerous syndromes are rare does not, by itself, provide a sampler.

The representation I constructed retains the intermediate syndromes of the multiscale decoder:

\[
h=(s_\ell,s_{\ell-1},\ldots,s_0).
\]

The top level is the physical syndrome. The bottom level is a syndrome of a fixed finite base code.

At each scale, impose the local correction and coarse-output equations

\[
s_i
=
\delta_i f_i(s_i)+F_i^{(2)}s_{i-1},
\qquad
s_{i-1}=R_i(s_i),
\]

together with the **complete** base-validity constraint

\[
s_0\in\operatorname{im}\delta_0.
\]

The corrections use fixed deterministic tie-breaking. Correction variables need not be sampled; their local functions can be evaluated inside the constraints.

For the target family, the source inputs are its local correction/coarsening maps, residual identities, alternating syndrome-weight contraction and constant-size base. These appear in Definition 4.3, Theorems 4.6–4.7 and the base construction. The compiler and sparse-incidence deductions are our use of those inputs, rather than statements quoted from the paper. :chatgpt-content-reference{index="2"}

Three facts make this representation useful.

### A. Local equations certify global physical validity

Suppose the base syndrome is physical:

\[
s_0=\delta_0e_0.
\]

The cochain property gives

\[
F_i^{(2)}\delta_{i-1}
=
\delta_iF_i^{(1)}.
\]

Inductively,

\[
s_i
=
\delta_i\!\left(
f_i(s_i)+F_i^{(1)}e_{i-1}
\right).
\]

Every accepted level is therefore a valid physical syndrome.

This matters when local decoder tables are defined only on globally valid inputs. One can compile their entries using binary linear extension problems, assign arbitrary defaults to impossible local views, and enforce the residual equations. The induction ensures that impossible views never occur in an accepted history.

Determinism then gives **one accepted history per physical syndrome**. There is no hidden multiplicity changing the Gibbs measure.

### B. Connected components remain valid histories

Construct a graph whose vertices are history variables. Join variables whenever they appear in the same constraint.

Take a valid history and isolate one connected component of its nonzero variables. Any constraint sees either:

- the same assignment it saw in the original valid history; or
- the all-zero assignment.

Both are valid. Each isolated component is therefore a valid history on its own. Compatible components can also be recombined.

This produces an exact positive-polymer representation. A “polymer” here is simply a connected nonzero history component.

Keeping the **entire finite base-validity relation** is important. The construction samples the full syndrome law. It does not impose base syndrome zero and inherit an excluded-probability preparation floor.

### C. Physical energy pays for the whole history

The alternating contraction bounds yield

\[
\sum_i|s_i|\le4|s_\ell|.
\]

Because an isolated component is itself a valid decoder history, the same inequality applies to it:

\[
|\gamma|
\le4|s_\ell^\gamma|.
\]

Consequently,

\[
\boxed{
E(\gamma)\ge\frac{J_{\min}}4|\gamma|.
}
\]

This is the central estimate. The history makes the constraints local, while contraction prevents that added history from creating arbitrarily large, almost-energy-free components.

Locality alone would not suffice.

## 4. A proved sampler, with an explicit polynomial bound

The general theorem proved in the brief applies to a history model with:

- \(M=\operatorname{poly}(N)\) variables;
- a fixed alphabet of size \(q\);
- a constraint graph of fixed maximum degree \(\Delta\);
- a unique valid history for each physical syndrome;
- locally checkable constraints accepting the zero assignment;
- additive physical energy satisfying \(E(\gamma)\ge a|\gamma|\).

Define

\[
\kappa=(q-1)\max(2,\Delta)^2,
\qquad
x=\kappa e^{-\beta a}.
\]

A sufficient low-temperature condition is

\[
x\le\frac{1}{8(\Delta+1)}.
\]

Under these assumptions, the Gibbs syndrome law can be sampled to total-variation error \(\varepsilon\) in

\[
\operatorname{poly}(N,1/\varepsilon)
\]

time.

### The constructive proof

There are at most \(\kappa^r\) labeled connected supports of size \(r\) containing a specified root. A polymer’s inclusion probability is at most its activity,

\[
w(\gamma)=e^{-\beta E(\gamma)}.
\]

Therefore,

\[
\Pr[\text{some polymer has size}>L]
\le
\frac{Mx^{L+1}}{1-x}.
\]

Choose

\[
L=O(\log(M/\varepsilon)).
\]

All admissible polymers of size at most \(L\) can then be enumerated in polynomial time. Let their number be \(K\).

Run a finite heat-bath chain on compatible collections of these polymers. Select a polymer uniformly; if it is compatible with the other present polymers, include it with probability \(w/(1+w)\).

For weighted Hamming distance, where disagreement on \(\gamma\) costs \(|\gamma|\), the influence estimate is

\[
\sum_{\gamma'\not\sim\gamma}
|\gamma'|w(\gamma')
\le
(\Delta+1)|\gamma|
\frac{x}{(1-x)^2}
\le\frac14|\gamma|.
\]

A coupling contracts by at least

\[
1-\frac{3}{4K}
\]

per step. Thus

\[
T\ge
\frac{4K}{3}
\log\frac{4M}{\varepsilon}
\]

steps suffice for the required mixing accuracy, after dividing the error budget between truncation, mixing and finite-precision arithmetic.

Positive-polymer sampling is established machinery. The potentially useful contribution here is the **faithful decoder-history compiler that makes this machinery applicable**, including validity, uniqueness, bounded incidence and energy control. :chatgpt-content-reference{index="3"}

### A concrete example and a failure case

The package checks a four-child parity hierarchy with rule

\[
a\oplus b=c\oplus d=s,
\]

where \(s\) is the parent bit and only leaves cost energy. A nonzero parent forces at least two nonzero children, giving the required control of history size by physical defects.

For its partition functions,

\[
Z_{h+1}(0)=\bigl(Z_h(0)^2+Z_h(1)^2\bigr)^2,
\qquad
Z_{h+1}(1)=4Z_h(0)^2Z_h(1)^2.
\]

Hence, with \(r_h=Z_h(1)/Z_h(0)\),

\[
r_{h+1}\le4r_h^2.
\]

The exact depth-two check enumerated all \(65{,}536\) leaf strings, found \(1{,}024\) valid histories and \(300\) distinct polymers, and verified component deletion, recombination, energy additivity and sampling probabilities using rational arithmetic.

The counterexample replaces that rule by ordinary binary XOR. Two defective leaves in opposite branches of a depth-\(h\) tree produce \(2h\) nonzero history variables while costing only \(2J\). The history remains local and unique, but its energy per variable tends to zero.

That example identifies the substantive obstacle: **the representation must preserve a size-independent energy cost per connected history variable.**

## 5. A further deduction: bounded positive coupling variation is covered

The construction gives more than nominal equal-coupling initialization.

Choose the same admissible decoder for the history certificate and protected logical frame. A nonzero syndrome at the fixed base level belongs to a polymer containing a base variable. Alternating contraction forces that polymer to contain at least

\[
2^{k-1}
\]

nonzero history variables when the physical level is \(2k\).

If \(B\) is the fixed number of base syndrome variables, rooted counting gives

\[
\Pr[s_2\ne0]
\le
\frac{B\,x^{2^{k-1}}}{1-x},
\qquad
x=\kappa e^{-\beta J_{\min}/4}.
\]

Since \(N=e^{\Theta(k)}\), this yields

\[
b_N\le C e^{-cN^\eta}.
\]

The argument uses the actual positive couplings in the activities and only \(J_{\min}\) in the bound. It is therefore uniform over fixed coefficients in \([J_{\min},J_{\max}]\).

The protected logical operators and the relevant syndrome projector commute with every stabilizer. Their protection property is combinatorial. Applying the Gibbs-stationary protected-observable criterion to the actual weighted Hamiltonian gives the same form of storage bound. :chatgpt-content-reference{index="4"}

Calibration can also be quantified. Let

\[
\lambda_a=\beta J_a
\]

and let \(\widehat\lambda_a\) be the values used by the sampler. Interpolating the two Gibbs distributions gives

\[
\boxed{
\operatorname{TV}(p_\lambda,p_{\widehat\lambda})
\le
\min\!\left\{
1,\frac14\sum_a|\lambda_a-\widehat\lambda_a|
\right\}.
}
\]

Thus average coefficient precision \(O(\varepsilon/N)\) suffices for an \(O(\varepsilon)\) loading contribution. Contractivity carries that initial discrepancy through the actual weighted dynamics without multiplying it by the holding time.

This covers fixed positive coefficients on the same known commuting checks. Changes to the check operators, extra logical terms, temporal drift and general noncommuting perturbations remain outside the argument.

### The precise Code Swendsen–Wang challenge

For a physical check matrix \(h\), one relevant criterion asks for a graph incidence matrix \(g\) on the same check coordinates such that

\[
\ker(h^T)\subseteq\ker(g^T),
\]

with defect

\[
\Delta
=
\dim\ker(g^T)-\dim\ker(h^T).

There is a dual alternative. The mixing dependence is \(2^{O(\Delta)}\operatorname{poly}(N)\), so \(\Delta=O(\log N)\) can suffice. The comparison graph need not respect the physical geometry. :chatgpt-content-reference{index="6"}

Neither one encoded logical qubit nor large metachecks determines this defect. The package includes an exact synthetic counterexample to that shortcut. It does **not** classify the target memory.

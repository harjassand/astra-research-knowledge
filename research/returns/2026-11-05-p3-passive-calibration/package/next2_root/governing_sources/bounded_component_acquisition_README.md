## Finite response, noncircular prescription and actual costs

Both capture and local readout can use fixed three-pole responses. An infinite actuator tail is compared with a physically truncated future Hamiltonian using its integrated norm; photon counting is only over the resulting finite window. A finite rail count is not incorrectly applied to photons over an infinite tail. A separate bound pays the missing ideal readout pulse area.

An explicit prescription resolves guard/hardware dependencies. With dimensionless total window `z=1+BA`, the supplied majorants have photon cap `Q<=q0 z`, mode count at most `M0 z^4`, rail count at most `P0 z^2`, and total capture nodes at most `D0 z^6`. Finite readout/capture guards reduce to `z>=c+d log z`; the explicit choice `z=2c+2d^2` closes the construction. The chosen mode count is the least integer satisfying its lower requirement, which is needed for the stated upper majorant. The independent [closure note](package/construction/fixed_response_parameter_closure_and_finite_qubit_bounds_2026-11-04.txt) and [composition audit](package/construction/final_receiver_composition_audit.txt) give the constants, finite generator-error bounds and both readout variants.

Logical splitter depth is not physical delay. At fixed planar density and component spacing `a`, a safe root-to-leaf path is `O(aP)` and in-module delay is `O(a(P+N)/v)` for `P` rails and `N` cascade cells, plus fixed component delays and external delivery. Wire length, delay, source collection, mode processing, decoder runtime and all stationary waiting are paid. Arrival uncertainty `delta_t` is handled by delaying commanded starts, then charging the resulting bounded waveform deviation; arbitrary pre-zero output is not assumed vacuum at an active absorber.

Input-independent local initialization, coefficient precision, stable phase/timing calibration, readout, ancillary reset, classical arithmetic, local gates, routing and protected memory remain resources. An optional offline fitting claim needs **both** inverse-identifiability and forward-Lipschitz bounds, plus actual probes/reset/readout, SPAM/drift assumptions and confidence: efficient pointwise prediction alone does not prove polynomial fitting. Raw first capture is uncoded; later fault tolerance cannot reconstruct arbitrary information already lost at ingress.

The sufficient polynomial bounds are enormous. One supplied scalar `n=1`, `epsilon=0.1` recipe already requires more than `10^112` capture cells. This is an evaluated sufficient proof bound, not a lower bound, simulated array, practical design or competitive-device claim. No wall-time, memory or hardware optimality is established.

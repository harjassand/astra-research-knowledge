FINITE PHYSICAL INTERFACE AND PAID RESOURCE BILL
Companion to the tracial collision acquisition theorem

Status: finite qubit-register construction and proved sufficient error bounds. No hardware experiment or hardware advantage is claimed. All errors below use HALF diamond distance Delta(Phi,Psi)=||Phi-Psi||_diamond/2; state errors use trace distance ||rho-sigma||_1/2.

1. Hardware and exact operation

Use N+2 qubit cells: source S, N memory cells, and distinct dummy D. The source contains an arbitrary input/reference state. Initialize every other logical qubit to independent I/2. Load the unknown payload after offline calibration and initialization; otherwise charge its extra waiting time.

The switched nearest-neighbor primitive is U(phi)=exp(-i phi SWAP), generated by H(t)=hbar g(t)SWAP, phi=integral g(t)dt, |g|<=J. For spins SWAP=(I+XX+YY+ZZ)/2: this is isotropic exchange up to a scalar Hamiltonian. XY/flip-flop exchange alone is not the stipulated primitive. If a physical norm budget includes the scalar, retain its constant in the action bound. Free evolution must be known/tracked; unknown phase drift is an error.

Source collisions use only U(theta), 0<theta<pi/2. Receiver full SWAPs use angle pi/2. Inverse pulses need signed exchange for duration theta/J_M. Positive-only exchange can instead use angle pi-theta, since U(pi-theta)=-U(theta)^dagger, at the longer duration (pi-theta)/J_M.

Nearest-neighbor junction geometry: S at (-1,0), memory cell1 at (0,0), other memory cells at (1,0),...,(N-1,0), dummy D at (0,1). There are N+2 cells, N+1 edges, maximum degree three. After collection the S--cell1 coupling is closed permanently; the decoder never accesses S.

2. Exact routing schedule and counts

In capture round j, fresh logical E_j is at cell1. Apply U(theta) on S/cell1, then bubble the emitted token right through the remaining fresh tokens with N-j adjacent full SWAPs, stopping before earlier outputs. After j rounds the cells hold remaining fresh tokens followed by E_j,...,E_1. Full SWAPs only permute factors, so future logical inputs remain independent I/2. At the end the order is E_N,...,E_1.

Capture routing: R_c=N(N-1)/2.

Close the source port. Inverse-collide the independent MAXMIX dummy from the side branch with E_N at cell1. Full-SWAP the dummy token into cell1; spent E_N enters the branch. Inverse-collide the dummy with E_{N-1} in cell2, SWAP it right, and continue. Omit the final movement after inverse-colliding with E_1. This is the reverse chronological decoder on logical tokens. All output correlations are retained until their coherent use; no measurements or postselection are used.

Decoder routing: R_d=N-1.
Total routing R=(N-1)(N+2)/2.
Total two-qubit gates G=2N+R=(N^2+5N-2)/2.
Peak operation qubits N+2; unknown payloads consumed one.

Strict 1D alternative: line S,E_1,...,E_N,D. After the same capture, move D left through all N output cells by N full SWAPs, then execute the moving-dummy decoder. This adds N routing SWAPs, giving R_d=2N-1. The junction counts above are the main construction.

3. Finite time and coherent storage

Let tau_c=theta/J_S, tau_d=theta/J_M for signed receiver exchange (or (pi-theta)/J_M for positive-only), tau_w=pi/(2J_M), and tau_ctl bound switching/addressing/settling time per operation. A serial schedule has

T_c=N tau_c+R_c tau_w+(N+R_c)tau_ctl,
T_d=N tau_d+R_d tau_w+(N+R_d)tau_ctl,
T_op=T_c+T_d.

Source exposure is T_c, after which S is isolated/discarded. Memory space-time is at most V_M=(N+1)T_op qubit-time units, plus any extra preparation/waiting interval. This conservative bound includes even initially uncorrelated cells. Initialization and calibration are paid separately before input arrival.

At fixed strength and latency this layout costs O(N^2) wall time and O(N^3) memory space-time. N=Theta(theta^-4 log(1/epsilon)) can therefore give theta^-8 wall-time and theta^-12 memory-space-time powers. The result is collision-count optimal in the weak source-port model, not wall-time optimal for this routing layout. If a strong source SWAP is available, one source pulse exports the payload; receiver-only full SWAPs do not supply that source resource.

4. Joint bath-defect bound and finite factory

For independent actual initial states tau_j, let x_j=chi^2(tau_j||I/2)=2Tr(tau_j^2)-1. For L cells,

D_tr(tensor_j tau_j,(I/2)^tensor L) <= (1/2)sqrt[product_j(1+x_j)-1].   (A)

Proof: with Q=2^L, Cauchy-Schwarz gives ||rho-I/Q||_1^2<=Q Tr(rho-I/Q)^2=Q Tr(rho^2)-1, and product purity factors. Replacing a fixed input-independent environment in any circuit changes the induced channel by at most its initial trace distance, uniformly over arbitrary input/reference. Thus (A) is ONE whole-process bound, not a bound reapplied to emitted outputs; their later correlations are fully retained.

For the decoder include the independent dummy, L=N+1. For the source-output converse use L=N. Writing tau_j=(I+b_j dot sigma)/2 and |b_j|<=beta gives

epsilon_init <= (1/2)sqrt[(1+beta^2)^L-1] <= (1/2)sqrt[exp(L beta^2)-1].

A sufficient tolerance for epsilon_init<=epsilon_p is beta^2<=log(1+4epsilon_p^2)/L, or beta=O(epsilon_p/sqrt(N)). This is a sufficient certificate, not a claimed optimal tolerance. Independence is essential: every marginal can be exactly I/2 while the global state is correlated and far from the product. Local tomography does not certify independence or inaccessible purification records. Use an actual global trace-distance bound if available; arbitrary composable per-preparation channel errors can always be summed instead.

Exact tracial preparation does not require infinite-temperature thermalization. Independently uniform Pauli randomization followed by inaccessible key disposal realizes

(1/4)sum_P (P tensor I)rho(P tensor I)=(I/2)tensor Tr_qubit rho.

Independent application to all N+1 cells removes even initial correlations in the ideal gate model. It requires two uniform classical bits per cell and at most two bounded single-qubit Pauli pulses (X^a Z^b). If one pulse takes tau_1, serial pulse time is at most 2(N+1)tau_1, plus key generation, switching and disposal time. Work/reset costs of these factories and classical memories are additional actual resources.

EVERY copy of the operating randomization key must be unavailable to receiver and future source controller. Retaining a label in an accessible classical log gives a nontracial conditional bath and invalidates the universal converse. Merely choosing not to use an available key is insufficient. Calibration logs can be retained only without revealing actual operating keys.

Approximate Pauli gates on arbitrarily correlated raw cells do not automatically yield independent tau_j. Their safe error estimate is a composable channel-error sum. The sharper product formula requires a justified independent memoryless factory or another establishment of the actual product-state premise.

5. End-to-end physical error budget

Let eta_g be each gate's composable HALF diamond error, uniformly with arbitrary entangled spectators in the operating configuration. Let kappa_S bound half the diamond norm of the unwanted source noise generator during collection. Let kappa_M be a per-qubit memory storage bound such that the global unwanted generator norm is bounded by the sum. Direct composable interval-error bounds can replace the generator model. Correlated noise/cross-talk needs a global bound; independent scalar coherence times alone do not control it.

Duhamel/telescoping and CPTP contraction give

Delta(actual recovered channel,id)
 <= (3/4)(1-sin^4 theta)^N + epsilon_init + sum_g eta_g
    + kappa_S T_c + kappa_M V_M + epsilon_other.           (B)

The 3/4 is the exact HALF diamond distance of the qubit depolarizing replacement from identity. epsilon_other includes any uncounted drift, leakage, key leakage, delay or cross-talk. Avoid double counting terms already included in gate/storage bounds. The estimate is reference-uniform and makes no independence assumption about emitted outputs.

One explicit budget for total epsilon is intrinsic algorithm error epsilon/2 and epsilon/8 each for initialization, gates, source storage and memory storage, with no uncounted epsilon_other:

N >= log[(3/4)/(epsilon/2)]/[-log(1-sin^4 theta)],
eta_g <= epsilon/(8G),
beta^2 <= log(1+epsilon^2/16)/(N+1),
kappa_S <= epsilon/(8T_c),
kappa_M <= epsilon/[8(N+1)T_op].

These conditions are conservative, not necessary. A protected logical implementation can replace the cells only with its extra encoding, ancillas, factories, gates, time and certified composable errors included. No fault-tolerance overhead theorem or free protected memory is supplied here.

The same initial bath replacement bound changes the source-output channel by epsilon_bath at most; an ideal recovery lower bound transfers with additive subtraction epsilon_bath and other relevant channel errors. A fixed unqualified preparation bias is not harmless as N grows.

6. Finite independent-factory qualification

Assume stationary reproducible independent factories and trusted Pauli readout. For each of L=N+1 cell types, measure X,Y,Z on repeated disposable calibration preparations. If each mean has error at most h, the Bloch-vector estimate has Euclidean error at most sqrt(3)h. An empirical Bloch norm <=beta/2 and h<=beta/(2sqrt(3)) therefore certify norm <=beta.

For +/-1 observations, Hoeffding plus a union bound gives

M_p >= 24 beta^-2 log(6L/alpha_p)

samples PER axis and cell, sufficient at failure probability alpha_p. Total qualification is 3L M_p preparations/readouts. With beta=Theta(epsilon_p/sqrt(N)), this is O(N^2 epsilon_p^-2 log(N/alpha_p)). If the bias fails, improve the factory or reduce N. Known SPAM systematic errors add to h and must be below the required beta. This qualification does not certify independence, hidden-side-channel absence, or future stability. Calibration is before loading the unknown payload and uses no copies of that payload.

7. Finite pulse and model qualification

If exact exchange FORM is promised, prepare |01>, apply the pulse and measure either Z on the first qubit or the X tensor Y correlation. Their means are cos(2phi) and sin(2phi). These determine phi modulo pi, the physically irrelevant global-phase ambiguity of exp(-i phi SWAP). Local angle precision h_phi costs O(h_phi^-2 log(K/alpha_g)) pulse trials, also near phi=0 because X tensor Y has linear response. No entangled reference is needed for this scalar calibration. A pulse angle error Delta phi gives HALF diamond gate error <=|Delta phi|. Signed inverse control must be qualified too.

Scalar tests do NOT certify a generic unknown gate's exchange form, excluded leakage, absence of cross-talk or stationarity. Full finite-channel qualification is available under a closed two-qubit, stationary, context-independent CPTP gate model and trusted SPAM. For each distinct pulse configuration, prepare its normalized Choi state using two input/reference Bell pairs, apply the tested gate to the two inputs and measure all L_P=4^4-1=255 nonidentity four-qubit Pauli observables on separate specimens. Each trial uses four qubits, two trusted Bell pairs, one tested gate and four trusted Pauli readouts. These references are paid calibration resources, not accessible bath purifiers during operation.

Put q=4 (gate input dimension), r_P=Tr(JP) for normalized Choi state J, and let hat r_P have statistical width h plus known systematic width s_P. A direct upper certificate is

Delta(E,U) <= (q/2)sqrt[sum_P (|hat r_P-r_P(ideal)|+h+s_P)^2].  (C)

Proof: Pauli orthogonality and trace/HS norm comparison give ||J_E-J_U||_1<=sqrt[sum_P coefficient_error_P^2], and ||E-U||_diamond<=q||J_E-J_U||_1. No possibly nonphysical reconstructed channel is needed.

Taking h=Theta(eta/(q sqrt(L_P))) and sufficiently small SPAM systematics yields an eta certificate with

M_g >= 2 h^-2 log(2L_P K/alpha_g)

trials PER Pauli observable. Total K L_P M_g=O(K eta^-2 log(K/alpha_g)) at fixed dimension. There are K<=2N+1 two-qubit pulse/edge configurations: one source weak pulse, N receiver inverse-pulse locations and N receiver full-SWAP locations. With eta=Theta(epsilon/G), the conservative qualification cost is O(N^5 epsilon^-2 log(N/alpha_g)). It is not optimized; smaller costs need independently justified shared-parameter structure.

Each gate trial has actual duration tau_Bell-prep+tau_test+tau_readout+tau_reset+tau_control, multiplied by the displayed trial count. Factory qualification costs 3L M_p(tau_factory+tau_Pauli-readout+tau_reset). These times and trusted SPAM resources are additional to operation time. Trusted references/readouts cannot be bootstrapped for free from the same unqualified gates. Their systematic floor must be sufficiently low. Source-edge calibration must precede unknown input loading, or use an independently justified equivalent replica.

Finite data certify approximation under the declared finite-dimensional stationary gate/factory model, not exact Hamiltonian form, zero error, absence of hidden side channels, or arbitrary future drift. On the joint calibration-confidence event, probability at least 1-alpha_p-alpha_g, the composable physical budget (B) is reference-uniform.

8. Paid-resource summary and scope

One unknown payload; N+2 operation qubits; O(1) extra calibration references can be reused.
N weak one-pass source pulses and N inverse receiver pulses, with actual bounded-strength durations.
N(N-1)/2+N-1 nearest-neighbor routing SWAPs (junction), or N extra for strict 1D.
N+1 initialized tracial inputs; optional ideal Pauli factory uses 2(N+1) random bits, at most 2(N+1) Pauli pulses and inaccessible key disposal.
Explicit T_c+T_d operation time, coherent memory space-time <=(N+1)T_op, and additional finite factory/calibration durations.
Sufficient general qualification bills: O(N^5 epsilon^-2 log(N/alpha)) fixed-dimensional gate trials and O(N^2 epsilon^-2 log(N/alpha)) independent-factory trials.
Actual source isolation during routing/decoding and correlated-output preservation are substantive resources. This construction assumes that its stated error/noise/control budgets can be met; it does not establish a present platform that meets them, or a wall-time/hardware advantage over equally informed strong-coupling or purified-environment alternatives.

Isolation refinement. A residual coherent coupling from S to retained receiver cells is not ordinary source-only storage noise: it supplies forbidden feedback access unless bounded. If the Hamiltonian on nominally closed source/receiver edges is H_off(t), a sufficient composable error term is epsilon_off <= integral ||H_off(t)|| dt/hbar over every closed interval, including decoding while S remains physically nearby. Include this in epsilon_other or an allocated isolation budget. Actual physical removal/shielding with a certified bound is an alternative. Long routing time makes the required off-state isolation substantive; a quoted single-qubit coherence time does not establish it.

Weak-port access clarification. A switchable exchange Hamiltonian by itself does NOT impose a weak source port: freely extending its pulse implements a full SWAP. The physical interface premise is a maximum encounter window tau_enc for each fresh logical ancilla, with |g(t)|<=J_S, so its action satisfies a<=J_S tau_enc. The receiver cannot pause/extend that encounter, reuse its token at the source, or concatenate nominal weak encounters on the same token. The register schedule realizes this supplied timing-and-reach contract; it does not establish that generic exchange hardware intrinsically cannot extend the pulse. If source interaction can last pi/(2J_S) at full strength, one source SWAP exports the payload and is the stronger equally informed alternative.

9. Independent register modules with a global error target

For m independent identical emission/decoder modules, the construction uses
m(N+2) operation cells, L=m(N+1) initialized bath/dummy cells, and
G_total=m(N^2+5N-2)/2 two-qubit gates. There are at most
K_total=m(2N+1) distinct two-qubit pulse/edge configurations. A global gate
budget epsilon_g permits eta=epsilon_g/G_total. The same sufficient Choi
qualification then costs O(m^3 N^5 epsilon_g^-2 log(mN/alpha_g)) trials.
The product-preparation bound applied across all L cells gives the conservative
factory qualification O(m^2 N^2 epsilon_p^-2 log(mN/alpha_p)). These bounds
allow arbitrary entanglement between source modules and the reference.

If all modules operate in parallel, wall time is T_op and memory space-time
is at most m(N+1)T_op; source exposure summed over modules is m T_c. The
composable noise budgets use these summed exposures. With sequential arrivals,
fully serial operation takes m T_op. If all payloads are already present during
serial execution, their additional waiting/storage exposure must also be paid.
These are sufficient polynomial bills for this specified local layout, not
optimized calibration complexity or a demonstrated platform with those costs.

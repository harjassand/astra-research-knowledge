QUESTION RESOLVED
How much information can fresh maximally mixed physical outputs acquire about
an arbitrary unknown quantum source, and when can those outputs alone recover
the input after the source is discarded? The result connects a universal
acquisition obstruction to a family with an explicit matching receiver.

INTERFACE
Source S has finite dimension d. Each encounter introduces a fresh finite
ancilla E_j in I/e_j, independent of input/reference and all receiver memory,
conditional on genuinely classical history. Initial purifiers and operating
preparation keys are inaccessible. All emitted outputs/correlations may be
retained, measured or processed coherently; classical feedback may choose later
source unitaries and S/E_j interactions. No emitted register returns to S, no
retained quantum memory coherently couples back, and there is no additional
source measurement/reset port. A finite stopping bound is paid. The final
source is discarded. These are physical access premises, not consequences of
short source observations. Error is HALF diamond distance throughout.

UNIVERSAL ACQUISITION LAW
Set hbar=1 and charge each entire fresh encounter by
a_j >= integral ||H_j^h(t)||dt for every history h, after source/fresh-ancilla
local interaction pictures. Subdividing one encounter does not create freshness.
Let q_j=min(1,4a_j^4), b=product_j(1-q_j), alpha=1-b, c=1-d^-2.
For the full acquired channel C and sigma=C(I/d),
  (1/2)||C-Tr(.)sigma||_diamond <= min(1,sqrt[(d^2-1)alpha]/2),
  inf_R (1/2)||R C-id||_diamond >= c(1-sqrt(alpha)) >= c b/2.
Every CPTP final receiver decoder is included, without a computational bound.

For every-history charge sum -log(1-q(a_{j,h}))<=C_*, the same law holds with
b=exp(-C_*), including branch-dependent actions and bounded stopping. This is
a worst-case path budget, not an expected-action theorem or free postselection.
If all 4a^4<=q_*<1, target error epsilon<c/2 requires fourth-action budget
  sum_j a_j^4 >= (1-q_*) log[c/(2epsilon)]/4.

PROOF MECHANISM
The baseline source remains I/d and product with receiver memory, in every
classical block. The weighted norm Tr(X^dagger X omega^-1) contracts under
receiver channels. Projection onto source identity captures accessible output.
For fresh I/e, the source partial trace of the first interaction commutator
vanishes. Exact Volterra expansion bounds export amplitude by 2a^2, hence
squared-norm transfer by 4a^4. Old and new exported pieces are orthogonal.
This yields the finite recursion, arbitrary-reference bound, and centered
decoder converse. The observable amplitude itself need not be fourth order.

EXACTLY CHARACTERIZED MATCHING RECEIVER
For partial SWAP U_j=exp(i theta_j SWAP), possibly interspersed with arbitrary
known source rotations, retain all N d-level outputs. Prepare one independent
maximally mixed dummy source, apply the known full inverse circuit in reverse
order to dummy/outputs, and return the dummy. The original source and bath
purifiers are absent. This is the Petz map for the maximally mixed reference,
an instance of established physical inverse recovery, with exact channel
  D C=(1-r)id+r Tr(.)I/d,
  r=product_j(1-sin^4(theta_j)).
Its HALF diamond error is c r. Every decoder obeys
  c(1-sqrt(1-r)) <= epsilon_opt <= c r.
The receiver's error is therefore within a factor two of optimal.

INDEPENDENT SOURCE MODULES
For m product emission channels with arbitrary entangled input/reference and

For fixed d and weak constant theta, N=Theta(theta^-4 log(m/epsilon)) per

TWO CLOCKS AND IDENTICAL REDUCED DYNAMICS
The source retains visibility beta=product_j cos^2(theta_j). Thus it forgets
in Theta(theta^-2 log(1/epsilon)) collisions, whereas high-fidelity output-only
recovery takes Theta(theta^-4 log(1/epsilon)).

Choosing cos^2(theta)=exp(-gamma Delta) gives EXACT source depolarization
exp(-gamma T) at every grid time T=N Delta. Yet
  r=[1-(1-exp(-gamma Delta))^2]^(T/Delta),
  alpha=gamma^2 T Delta+O(Delta^2) for fixed gamma,T.
The whole physical bath approaches a replacer as Delta->0. A coarse strong
collision and arbitrarily many fresh weak collisions can give the same exact
source channel at every coarse time and different output acquisition clocks.
T is the native collision clock; delivery/routing/decoder time is additional.
Fixed gamma requires peak coupling Theta(sqrt(gamma/Delta)). At bounded J and
theta=J Delta, source forgetting takes order (J^2 Delta)^-1 and output
collection (J^4 Delta^3)^-1, times accuracy logarithms. No free continuum clock
or arbitrary finite-temperature/infinite-dimensional bath theorem is supplied.

FINITE EXECUTION AND ERRORS
One qubit module has an N+2-cell nearest-neighbor junction. Collection uses
N(N-1)/2 full routing SWAPs; moving-dummy decoding uses N-1 more. Total two-qubit
gates G=(N^2+5N-2)/2. Finite exchange pulses, positive-only inverse alternative,
control latency and exact schedule times are given. At fixed hardware speeds
this layout has O(N^2) operation time and O(N^3) memory space-time. It is not
a proof of optimal wall time or optimal storage.

Weak source access requires a maximum encounter window tau_enc and bounded
coupling J_S, deriving a<=J_S tau_enc. If the source pulse may last
pi/(2J_S), one full SWAP is a simpler export. The finite register realizes
the stated contract; it does not establish an intrinsic inability to extend
the pulse on generic exchange hardware.

For independent actual bath/dummy inputs tau_j and x_j=d Tr(tau_j^2)-1,
  epsilon_init <= sqrt[product_j(1+x_j)-1]/2.
This replaces the whole initial environment once and retains all later output
correlations. For L qubits with Bloch norms <=beta, beta=O(epsilon_init/sqrt L)
suffices. Independent ideal Pauli twirls make exact mixed product cells using
two random bits each, provided every operating key is inaccessible. Approximate
twirls on correlated raw cells require composable channel bounds instead.

The finite sufficient physical error is intrinsic c r plus initialization,
sum of gate half-diamond errors, source and correlated-memory noise exposures,
and source-off coupling integral ||H_off||dt/hbar. Protected memory, trusted
calibration states/readouts, independence, stationarity and coupling isolation
are actual resources. Conservative qualification is O(N^5 epsilon^-2 log(N/alpha))
gate trials and O(N^2 epsilon^-2 log(N/alpha)) independent-factory trials; global
m-module bills are O(m^3 N^5 epsilon^-2 log(mN/alpha)) and O(m^2 N^2 epsilon^-2
log(mN/alpha)). Calibration does not prove absence of arbitrary hidden access.

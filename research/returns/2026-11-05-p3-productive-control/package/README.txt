COMPLETED ENDPOINT

A conditional theorem and finite certificate select the complete optimal
productive feedback rule in a controlled nearest-neighbor damage process.
Interventions change the failure/recovery law. Strict local inequalities can
certify every finite failure depth without accurately forecasting the rare
absolute value. A separate finite-mission theorem, a same-access relative-value
lower bound, matched rare-hazard operations, and an explicit omitted-catastrophe
obstruction state what this does and does not buy. The independent continuous-
time repair construction gives a productive capacity boundary and exact repair,
energy and shared-support costs. A resource-priced objective is proved in the
main report; a hard total fuel constraint remains a different control problem.

This is not a validated physical apparatus or an established historical-priority
claim. Forward skip-free recursion, machine-repair theory and statistical change
of measure are established primary machinery. The strongest equally informed
direct policy-identification method can exploit the same certificate.

REPRODUCING THE EXECUTION

Run from this package directory, with Python 3 and NumPy, SymPy, SciPy, Matplotlib:

  python3 code/acquire_and_certify.py
  python3 code/verify_certificate.py
  python3 code/plot_results.py
  python3 independent/intervention_constructor/independent_check.py
  python3 independent/physical_repair_companion.py

The first three commands regenerate the corresponding current results/figures.
The two independent checkers print their results without changing their preserved
notes. The acquisition source generates multinomial counts representing 371,368
one-cycle trials per mode; no laboratory experiment or ordered physical trace is
claimed. The compiler consumes counts, reward values and declared uncertainty
budgets, not the simulator's probabilities. Its implementation specializes the
general theorem to one prefix state followed by a constant tail, and abstains if
the exact inequalities do not certify that form. The independent verifier reads
saved counts and certificates without consulting the synthetic source.

The saved execution uses Python 3.12.14, NumPy 2.3.5, SymPy 1.14.0, SciPy 1.17.0
and Matplotlib 3.10.8. Exact certificate comparisons use fractions. Matrix solves
in the root checker use exact SymPy rationals; the two independent checkers and
survival/source diagnostics use floating point. Random seeds are in saved counts.
Regeneration under different numerical-library versions need not reproduce every
floating diagnostic or random sample bit for bit.

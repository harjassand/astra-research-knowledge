### Proof

When \(S=\{0\}\), the population classes are singletons. Suppose \(\dim S=1\), and choose a primitive integer direction \(v\) generating the rational stoichiometric line.

If \(v\) has both positive and negative coordinates, the intersection

\[
(x_0+\mathbb Rv)\cap\mathbb N_0^d

\[
g=\gcd\{|a_r|:a_r\ne0\text{ among the remaining reactions}\}.

Using the stationary-adjoint channels, each step \(a_rv\) is available as an undirected Dirichlet-form edge in both orientations. \[
a+kgv\longleftrightarrow a+(k+1)gv,\qquad k\geq0.

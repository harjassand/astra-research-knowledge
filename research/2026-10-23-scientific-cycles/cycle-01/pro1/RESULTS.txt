MODEL AND CONVENTIONS
The bath is ell2 of vertices of the rooted 3-regular tree. Root child ports
are 0,1,2; nonroot parent port is 0 and child ports 1,2. U reverses each
labeled directed edge, U*=U and U^2=I. All forward qutrit calls are counted.
The entire persistent internal state is E. The same normal initializer is
used across message sizes and horizons, independent of the message/reference.
No bath access, reset, replenishment, hidden discarded internal ancilla,
preshared entanglement, backward quantum wire or free forward side channel.
Local laboratories, retained outcomes and all error branches are included.

eta=diag(3/4,1/8,1/8), pi(root)=1/3,
pi(child)=pi(parent)*eta_a/(3/4). tau_pi is normal and faithful; the product
eta tensor tau_pi is fixed by U. The main process uses this same stationary
bath. The stated capacity/cost extensions allow any one fixed normal tau.
Classical instruments are normal, controls measurable (e.g. standard Borel);
CP densities need not individually be trace-nonincreasing.

c=log2(2 sqrt(2))=3/2; M_n=floor((2 sqrt(2))^n), M_0=1.
F_e is unconditioned entanglement fidelity for maximally entangled Phi_K.
Half-diamond epsilon=(1/2)||Lambda-id||_diamond; full diamond is 2 epsilon.
State half-trace distance is (1/2)||rho-sigma||_1.

F1 — SUPPLIED FIXED-HORIZON FEEDBACK PROOF INCORPORATED
Freeze each complete transcript t without normalizing:
    Lambda_t = D_t o N_n o E_t.
E_t depends on t. Every logical Kraus matrix D_(t,b) C_z E_(t,a) preserves
the individual device rank bound. All physical branches sum to TP. Hence:
    F_e <= min(1,M_n/K);  Q_backward_classical=3/2.
The invariant is the finite block Choi Schmidt number, not Kraus count or
one-use rank. The evaluator trial owns the new transcript lemma. This is
not a theorem that classical feedback never helps other channels.

F2 — COHERENT NORMAL INITIALIZERS
For a finite VERTEX COORDINATE projection P_F, r=|F|, q=Tr(P_F tau)>0:

S1 — NEW STOPPED-SUBCHANNEL CONVERSE
N is a receiver-controlled integer stopping time, finite almost surely for
every actual logical input; its decoded channel is CPTP. No free Alice-
controlled silence or timing channel. All calls on all branches are counted.
N may have unbounded support. Let n_circ=E_(tau,I/K)N,
n_bar=sup_rho E_(tau,rho)N. For diagonal tau, alpha_L=min(1,M_L/K):
    F_e <= alpha_L Pr(N<=L)+Pr(N>L).
For any fixed normal tau:
    F_e <= r M_L/K + sqrt(1-q) + Pr_(tau,I/K)(N>L),
    n_circ >= (L+1)[F_e-sqrt(1-q)-r M_L/K]_+.
The same lower bound applies to n_bar. Compare only the bounded event
"stop by L and pass the Phi_K test"; do not compare unbounded means under
nearby bath states. Termination under the truncated initializer is not needed.

S2 — SHARP LEADING EXPECTED COST AND COMPLETE ERROR
For every fixed normal tau and fixed 0<f<=1, the infimal costs under either
mean convention obey:
    C(K,f)/log2 K -> f/c = 2f/3.
For fixed half-diamond allowance 0<=epsilon<1:
    C_diamond(K,epsilon)/log2 K -> (1-epsilon)/c.
For full diamond allowance e in [0,2), the coefficient is (1-e/2)/c.
These are leading asymptotic optima, not exact finite-K optimum formulae.

Matching construction: Bob sends a local Bernoulli(p) bit backward. Run the
exact Dyck code of length n_K with probability p; otherwise make zero calls
and prepare I_K/K. Both branches count toward error.
    n_K=(log2 K)/c+O(log log K),
    Lambda=p id+(1-p) depolarizing,
    F_e=p+(1-p)/K^2,
    epsilon_diamond=(1-p)(1-1/K^2)=1-F_e,
    n_circ=n_bar=p n_K.
The entire bath and its inert purification return exactly at the terminal
boundary on BOTH branches. Terminal block return is not all-use return.

S3 — CONSEQUENCES
Reliable expected-use capacity remains 3/2. At expected rate R>3/2, optimal
limiting F_e is c/R and optimal limiting half-diamond error is 1-c/R.
The expectation-only strong converse therefore fails, already for a two-point
duration distribution. Duration concentration restores a strong-converse
limit via S1. The classical transmit-or-stop C/(1-error) phenomenon is known;
it is not claimed as a new principle.

P2 — LOWER STABILITY WITHOUT RESET, UNIFORM OVER BATH STATES
Fix a Dyck block L=2m and ell=floor(log2(C_m 2^m)). For ANY fixed unitary V

block is identity on its logical packet AND all of E, with a fixed external
syndrome. The actual block differs by norm <=epsilon.
A history with j bad blocks acts only on those j packets, despite arbitrary
bath correlations. An outer code corrects the coherent Pauli span of errors

    rate >=(ell/L)A(delta),
    A(delta)=1-4[h2(delta)+delta log2 3].

h2(delta)+delta log2 epsilon<0, the omitted coherent-history tail satisfies:

The error is uniform over bath states and purifications. All LN forward calls

The code is an existence construction, not an efficient synthesis result.
The perturbed code DOES NOT certify terminal or all-use bath return.

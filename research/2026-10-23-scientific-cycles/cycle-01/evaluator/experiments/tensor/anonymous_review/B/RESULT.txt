2. EXACT POSITIVE-MATRIX REDUCTION
Theorem. Given any normalized X and any finite nonnegative weights w_j on
completely positive maps E_j, one of Y=|X| or Y=|X*| satisfies
 sum_j w_j ||E_j Y||_2^2 >= sum_j w_j ||E_j X||_2^2.
Both candidates have the same singular values as X, the same normalized
Hilbert-Schmidt norm, and the same entropy Ent_tau(Y^2)=Ent_tau(X*X).
In particular sup_X F(X)=sup_(Y>=0) F(Y). This holds for all N,r.

Proof. Choose a unitary polar factor U (extending the partial isometry if
needed), X=U|X|. Then |X*|=U|X|U*, and the block matrix
 [ |X*|   X  ] = [ U ] |X| [ U*  I ]
 [  X*   |X| ]   [ I ]
is positive semidefinite. Complete positivity, in fact two-positivity, implies
 [ A  B ] >=0, A=E_j(|X*|), B=E_j(X), C=E_j(|X|).
 [ B* C ]
For every positive block matrix of this form,
 ||B||_2^2 <= ||A||_2 ||C||_2.
For completeness, block positivity gives B=A^(1/2) K C^(1/2) for a contraction
K, including singular A,C by a limiting argument. Schatten Holder gives
 ||B||_2 <= ||A^(1/2)||_4 ||K||_infinity ||C^(1/2)||_4
          <= ||A||_2^(1/2) ||C||_2^(1/2).
The same inequality holds for normalized Schatten norms since all blocks have
the same dimension. Therefore
 ||E_j X||_2^2 <= (||E_j|X*|||_2^2+||E_j|X|||_2^2)/2.
Sum with weights w_j. At least one of the two common polar moduli has total
weighted score at least that of X. The entropy is unchanged by the replacement,
so the desired assertion follows. No separate Y is chosen for different j.

Scope and limitation. This removes a real representation issue: it is enough
to solve the ORDINARY positive-matrix tensor inequality. It neither makes its
failed completely bounded strengthening true nor proves tensorization. It
also does not assert pointwise dominance for each individual prefix by the
same Y; only the weighted total is guaranteed. That is exactly what F needs.
The operator principle is standard; the direct entropy-preserving application
here is explicitly proved rather than attributed as a new norm theorem.
Primary bibliographic checks: S. J. Szarek, arXiv:quant-ph/0603110, abstract,
and K. M. R. Audenaert, arXiv:math-ph/0505085, abstract, both identify the known

3. WHAT EVERY JOINT-PREFIX SCHMIDT ENVELOPE ACTUALLY SAYS
Set P_0^(a)=I. For a multi-index i=(i_1,...,i_r), 0<=i_a<=N, the commuting
joint prefix projector is P_i=product_a P_(i_a)^(a). Its range consists of a
Bell state of total Schmidt dimension D^s tensor an arbitrary residual vector,
where s=sum_a i_a. Permuting local tensor factors does not change Schmidt
coefficients. The source's singular-value overlap proof therefore gives
 <P_i> <= B_s(lambda),
 B_s(lambda)=D^(-s) sum_blocks (sum_(j in block) sqrt(lambda_j))^2,       (J)
using one sorted global Schmidt spectrum lambda and consecutive blocks of
D^s entries. Set B_0=1. This is valid for every multi-index simultaneously.

Since each task's P_i are nested and tasks commute, their joint spectral
measurement defines an actual probability law for K_1,...,K_r in {0,...,N},
where K_a is the last successful prefix. Thus (J) reads
 Pr(K_a>=i_a for all a)<=B_(sum i_a)(lambda),                          (R)
and the desired positive term is m E[sum_a K_a]. All rectangular tails,
including marginals (some i_a=0), are included. The question is whether (R),
ordinary probability consistency, and the spectrum lambda already imply
 m E[sum K_a]<=H(lambda)+r K_D. They do not.

4. EXACT COUNTERFAMILY TO THAT SCALAR RELAXATION
Fix D>=2 and integer k>=1. Set
 T=D^k-1, N=T, r=2, L=T-k>=0.
Take lambda uniform on M=D^L entries and zero on the remaining entries in
ambient dimension D^(2N). Its entropy is H(lambda)=L m. Since M and each
block length are powers of D, direct evaluation gives
 B_s(lambda)=min{1,D^(L-s)}, 0<=s<=2N.                                (U)
This is the exact sorted-Schmidt envelope, not just a rank upper bound.

Define an abstract probability law by J uniform on {0,...,T} and
 K_1=J, K_2=T-J.
It has no discarded branches. Every outcome has K_1+K_2=T. For all
0<=i,j<=N, put s=i+j. Then
 Pr(K_1>=i,K_2>=j)=(T-s+1)/(T+1) when s<=T, and 0 otherwise.           (V)
For s<=L this is <=1=B_s. For L<s<=T write u=T-s, so 0<=u<k.
Because T+1=D^k, the required inequality (V)<=B_s is exactly
 (u+1)/D^k <= D^(u-k), i.e. u+1<=D^u.
The latter holds for every integer u>=0 and D>=2 (induction using 2^u>=u+1).
For s>T the probability is zero. Hence EVERY constraint (R) is satisfied,
with exact equality at s=T, and in the qubit case also s=T-1.
Nevertheless
 m E[K_1+K_2]-H(lambda)=m T-m L=k ln D ->infinity.                    (GAP)
Thus no finite defect 2 K_D can follow from this complete scalar constraint
set. All nonnegative combinations of those valid inequalities also hold for
the constructed data and cannot repair the missing implication.

This is a limitation of the relaxation, not of quantum mechanics. We have
NOT constructed a pure physical psi with this spectrum and this law. In fact,
if the desired tensor theorem is true, those data must violate some additional
simultaneous quantum compatibility condition that (R) forgets. Any proof based
on the joint-prefix scalar envelopes must supply such a condition. Ordinary
joint-probability consistency alone cannot supply it: (V) is an explicit law.
The required extra information is therefore sharper than separately applying
the exact Schmidt comparison to every intersection and then solving a scalar
probability problem. This identifies the missing step precisely.

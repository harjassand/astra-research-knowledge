ROBUST FULL-TASK QUANTUM COMPATIBILITY: EXACT WEIGHTED EXTREMUM
Owner subtask: cycle_robust_compatibility; 21 October 2026.
All logarithms, if used, are natural. This is a finite mathematical result.
No generic entanglement-of-formation additivity is invoked.

1. SETUP AND RESULT

There are two tasks. Each task has local dimension q at Alice and q at Bob.
For a normalized pure vector psi on A1 A2 : B1 B2, let p_a be its probability
under the full-task Bell projector Phi_q on Aa Ba (identity on the other task).
Let lambda be the global Schmidt spectrum across Alice:Bob and put
  R(lambda) = (sum_j sqrt(lambda_j))^2.

THEOREM. For every alpha,beta >= 0,
  q(alpha p_1 + beta p_2)
    <= max(alpha,beta) R(lambda) + min(alpha,beta).                 (1)
If rank(lambda) <= q, this upper bound is the EXACT maximum at that fixed
Schmidt spectrum. In particular, every pure state of Schmidt rank <= M <= q
satisfies
  p_1 + p_2 <= (M+1)/q.                                          (2)
By linearity the latter inequality also holds for mixed states of Schmidt
number <= M. The inequality (1) itself holds without rank(lambda)<=q; that
rank condition is used for the stated sharpness construction.

Thus the earlier exact incompatibility of two simultaneously saturated full-
task probabilities has a quantitative, sharp supporting inequality. It does
not require flat Schmidt coefficients. It is a full-task compatibility result,
not the all-prefix tensor entropy witness sought by the principal owner.

2. COMPLETE PROOF

Use the standard coefficient matrix X:
  psi = sum_{a1,a2,b1,b2} X_{a1 a2,b1 b2}
        |a1,a2>_A |b1,b2>_B,
with ||X||_HS=1. Singular values of X are sqrt(lambda_j). Direct contraction
with the normalized Bell vector gives exactly
  q p_1 = ||Tr_1 X||_HS^2,
  q p_2 = ||Tr_2 X||_HS^2.                                      (3)
Here Tr_a is the ordinary partial trace of the square coefficient matrix on
task a's matrix factor. It is not a trace of the physical density operator.

We recall and prove the precise positive reduction needed in this proof.
Let X=U|X| with U unitary (extend the polar partial isometry in finite square
dimension), and write L=|X*|=U|X|U*, R=|X|. Then
  [ L  X ; X*  R ] = [U;I] R [U*,I] >= 0.
For a completely positive map Phi, its two-by-two amplification gives a
positive block [A B;B* C], with A=Phi(L), B=Phi(X), C=Phi(R).
Block positivity gives B=A^(1/2) K C^(1/2) for a contraction K. For singular
A,C use A+epsilon I,C+epsilon I and pass to a convergent subsequence of the
finite-dimensional compact contraction ball. Schatten Holder then yields
  ||B||_HS <= ||A^(1/2)||_4 ||K C^(1/2)||_4
           <= ||A||_HS^(1/2) ||C||_HS^(1/2).
For Phi=Tr_a, this says
  ||Tr_a X||_HS^2
    <= ||Tr_a L||_HS ||Tr_a R||_HS.
Weighted scalar Cauchy-Schwarz, valid for alpha,beta>=0, therefore implies
  F(X) <= sqrt(F(L) F(R)) <= max(F(L),F(R)),
where F(Z)=alpha||Tr_1 Z||_HS^2+beta||Tr_2 Z||_HS^2.
Both positive matrices L,R have the same singular spectrum and norm as X.
It consequently suffices to bound F(Y) for positive Y at the fixed spectrum.
This is one common choice of modulus for the total weighted score, not an
assertion that one modulus improves both probabilities separately.

Let t=Tr Y=sum_j sqrt(lambda_j)>0 and sigma=Y/t. This sigma is an auxiliary
density matrix on the two task matrix factors. It is not the original physical
output density matrix. Write sigma_1=Tr_2 sigma and sigma_2=Tr_1 sigma.
For any bipartite density matrix sigma,
  Tr sigma_1^2 + Tr sigma_2^2 <= 1 + Tr sigma^2.                   (4)
For completeness, on two copies let F_a swap task a between the copies. The
operators I-F_1 and I-F_2 commute and are positive. Hence
  0 <= Tr[(sigma tensor sigma)(I-F_1)(I-F_2)]
     = 1 - Tr sigma_1^2 - Tr sigma_2^2 + Tr sigma^2.
The nonnegative trace follows from positivity of both factors, without any
commutation assumption involving sigma tensor sigma. Each marginal purity is
also at most one. If alpha>=beta, these facts give
  alpha Tr sigma_2^2 + beta Tr sigma_1^2
   = (alpha-beta)Tr sigma_2^2
      + beta(Tr sigma_1^2+Tr sigma_2^2)
   <= alpha + beta Tr sigma^2.
The other ordering is symmetric. Multiplying by t^2, and using
t^2=R(lambda), t^2 Tr sigma^2=Tr Y^2=1, proves (1) using (3).

If rank(lambda)<=q, place a state sum_j sqrt(lambda_j)|j,j> into the task
with higher weight, and put the other task into |0>_A|0>_B. These are honest
task states with the specified global Schmidt spectrum. Their probabilities
are p_high=R(lambda)/q and p_low=1/q, attaining (1). This includes zero
weights and ties. Finally R(lambda)<=rank(lambda)<=M by Cauchy-Schwarz,
which proves (2). Averaging pure-state decompositions proves its mixed
Schmidt-number version; in finite dimension the relevant convex hull is closed.

3. EXPLICIT ROBUST SEPARATION OF THE SCALAR FAMILY

Let M<=q and consider the proposed abstract full-task event law with
  p_1=p_2=a=M/q,  p_12=0.
(Its existence as an abstract distribution requires 2a<=1, as holds in the
counterfamily.) Every quantum state with Schmidt number <=M obeys (2).
The union of its full-task events has probability at most p_1+p_2 <=(M+1)/q.
The abstract law gives that union probability 2M/q. Therefore the total-
variation distance of their joint two-event distributions is at least
  (M-1)/q.                                                       (5)
This uses the union event, so no unnecessary factor of two is lost. If only
the two separate marginal errors are each bounded by e, then (2) instead
forces
  e >= (M-1)/(2q).                                              (6)
If a physical state or hypothetical initial vector is within half trace
distance e of one with the specified Schmidt-number bound, measurement
contractivity and (5) give the corresponding triangular error bound. No
Schmidt-number robustness under arbitrary approximate preparation is assumed.

Equivalently, with flat rank M and f_a=q p_a/M, the exact supporting inequality
is f_1+f_2<=1+1/M. Both relative errors 1-f_a cannot be small: their sum is
at least 1-1/M. This strengthens the elementary near-saturation argument
which only yields f_1^2+f_2^2<=1+1/M.

For the accepted scalar family q=D^T, T=D^k-1, M=D^(T-k), one has
  a=1/(T+1),  (M-1)/q=1/(T+1)-D^(-T).
Thus (5) is a quantitative incompatibility bound but tends to zero. It rules
out approximation at error o(1/T), not approximation at a general vanishing
error. In particular it does not by itself control an extensive prefix score.

The sole M=1 member of this scalar family has D=2,k=T=1,q=2, where (5) alone
is zero. A separate joint-event argument supplies a sharp robust bound there.
For any state of Schmidt number one, and any q,
  q(p_1+p_2) - q^2 p_12 <= 1.                                  (7)
For a pure product across Alice:Bob, write X=|u><v| for unit local vectors
u,v on the two task factors. A direct index contraction gives
  ||Tr_a X||_HS^2 = Tr(rho_(u,a) rho_(v,a)),
where rho_(u,a) and rho_(v,a) are the reductions of |u><u| and |v><v| on
factor a. (The factor traced in X is the factor retained in this formula.)
The expectation of the positive operator (I-F_1)(I-F_2) in u tensor v gives
  Tr(rho_(u,1)rho_(v,1))+Tr(rho_(u,2)rho_(v,2))
     <=1+|<u|v>|^2.
Since q p_a=||Tr_a X||_HS^2 and q^2 p_12=|Tr X|^2=|<u|v>|^2, this is (7).
Averaging proves it for every separable state. At q=2 its left side is twice
the probability of EXACTLY one full-task Bell event. That probability is at
most 1/2; the exceptional abstract family assigns it probability one. Thus
the joint-event total-variation distance is at least 1/2, and this is sharp:
put aligned local product states in both tasks, giving independent Bell
success probabilities 1/2 and a uniform four-outcome distribution. This
supplement does not assert any analogous higher-Schmidt-rank negative-weight
polar reduction, which has not been proved here.

4. FAILURE RETAINED: THIS NEW CONSTRAINT DOES NOT SOLVE THE TENSOR PROBLEM

There is an explicit way to evade precisely this additional constraint within
the abstract scalar relaxation, with a vanishing change of probabilities.
Keep the original flat spectrum and original uniform atoms (J,T-J), each of
mass 1/(T+1). Move the two endpoint atoms
  (T,0) -> (T-1,0),   (0,T) -> (0,T-1).
For T=1 the two new atoms coincide at (0,0), which is harmless. Each move only
decreases a coordinate. Every rectangular upper-tail probability is therefore
at most its original value, so every old Schmidt-envelope constraint still
holds. Both full-task Bell events now have probability zero, satisfying (1)
for all weights and the original flat spectrum. The total-variation change
is exactly 2/(T+1); the mean K_1+K_2 is T-2/(T+1). The relaxed witness gap is
  [k-2/(T+1)] ln D,
which still diverges. This is only abstract relaxation data. It is not asserted
to be physically realizable. In fact further near-full-prefix compatibility
constraints may exclude it. This example establishes the exact limit of the
new result: the entire family of nonnegative weighted FULL-TASK supporting
inequalities alone, even with the previous rectangle constraints, is not enough.

This failure must not be summarized as failure of the actual tensor witness.
It identifies the necessary next operation: compatibility across nested or
overlapping prefixes, with the tail matrix factors retained, rather than only
two complete-task contractions. Ordinary linear entropy subadditivity is valid
for disjoint complete factors. Replacing it by an unproved strong-subadditive
purity inequality for overlapping complements would introduce a real gap.

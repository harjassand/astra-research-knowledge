OBSERVED LOCAL COSTS AND LIMITS

Two bounded executions of check_full_task.py were performed with a single
OpenBLAS/OMP thread using the existing PostB3 Python environment. Each used
225 random pure states, four weights per state, explicit sharpness examples,
and exact rational checks of 702 rectangular tails. The second execution
added 75 rank-one joint-event checks; no new random state generation scale.

Run 1, core result only: script body wall 0.1396120421 s; CPU 0.075596 s;
maximum resident set 35,307,520 bytes. Shell tool command wall 0.16888675 s.
Run 2, core plus rank-one joint supplement: script body wall 0.0750822920 s;
CPU 0.059805 s; maximum resident set 35,258,368 bytes. Tool command wall
0.03853325 s (tool/script wall metrics have different measurement boundaries,
so do not derive any speed comparison from their apparent mismatch).

Total reasoning, tool orchestration and source reading cost: not instrumented.
Fresh bounded analytic audit by one subagent: separate intellectual work,
unmetered. No web searches, paid computations, physical runs, repository
mutations or private uploads were performed by this subtask.

Retained failed routes/limits:
1. Direct near-saturation factorization gives only the weaker curved bound
   f1^2+f2^2<=1+1/M. The stronger sharp linear supporting inequality was then
   proved through positive reduction and two-copy purity subadditivity.
2. The sharp full-task result gives absolute separation O(1/T) from the large
   abstract scalar family, while a generic vanishing-error approximation can
   be this inaccurate. It does not exclude that approximation regime.
3. Adding every nonnegative weighted full-task inequality to the old rectangle
   relaxation remains insufficient: the endpoint-decrement family in RESULT
   has the original divergent gap, up to O(1/T), and passes those constraints.
   This is not a physical state and is not a counterexample to the theorem.
4. The positive reduction applies to nonnegative weights. Applying it to a
   score with a negative joint-Bell coefficient would be unjustified. Only
   the separately proved rank-one joint result is asserted for such a score.
5. Ordinary two-factor purity subadditivity does not authorize insertion of
   a stronger conditional purity or entropic premise for overlapping prefixes.

The check script writes FINITE_CHECKS.json beside itself. Replaying it changes
only timing/RSS fields (and hence its hash), with the scientific outputs fixed
by the recorded seed. Replay on a copy when preserving a frozen package.

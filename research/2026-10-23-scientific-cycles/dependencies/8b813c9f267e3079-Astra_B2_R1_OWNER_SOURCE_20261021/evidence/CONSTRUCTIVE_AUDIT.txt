R1 EXPLICIT RESERVOIRS — independent constructive branch, 21 October 2026
Notation: B=|Phi_2><Phi_2|; Z=|01><01|. All distances in this note are half trace norm T=||rho-sigma||_1/2. Logarithms are natural. J denotes the number of single-qubit-pair output calls, m=J ln 2. No construction here by itself is claimed historically new.

1. FIXED NORMAL LOCC DEVICE AND COMPLETE JOINT RESPONSE
Let H_K=direct_sum_{k=0}^K (C^2)^{tensor k}, with its standard basis denoted |k,x>. Its local dimension is D_K=2^{K+1}-1. Let |e_k> be the maximally entangled vector of Schmidt rank 2^k inside the k-th matched sector and omega_k=|e_k><e_k|. The k=0 sector is one dimensional and omega_0 is product.
For each party define T: H_K -> C^2_out tensor H_K by
 T|k,bx>=|b>_out tensor |k-1,x>, k>=1; T|0>=0.
Define V_A|0>=|0>_out tensor |0>, V_B|0>=|1>_out tensor |0>, and V_A,V_B vanish on k>=1. T^*T+V_X^*V_X=I, so L_X(.)=T(.)T^*+V_X(.)V_X^* is a normal local CPTP map with two Kraus outcomes. The bipartite device Lambda discards its finite external inputs and applies L_A tensor L_B. It is fixed, has finite outcomes and requires no communication. All branches are included in the average. Retained shared registers consist exactly of H_K tensor H_K; no outcome record is retained. Every faithful product input eta induces this same memory channel.

For any probability vector p_0,...,p_K, tau_p=sum_k p_k omega_k. At every integer j>=0 the entire output-memory density operator is exactly
 rho_{O_1...O_j C} = sum_{k=0}^K p_k B^{tensor min(k,j)} tensor Z^{tensor (j-k)_+} tensor omega_{(k-j)_+}.
The ordering is chronological: Bell outputs occur first, followed by Z after exhaustion. This includes correlations among outputs and with memory. It specifies the complete causal process because inputs are discarded. In particular any adaptive or reference-entangled tester sees this replacement process.
If p is supported on k>=J, then for every j<=J,
 rho_{O^j C}=B^{tensor j} tensor tau_{S^j p},  S^j p(r)=sum_{k:(k-j)_+=r}p_k.
Thus all first J Bell outputs are exact, independent across slots and exactly independent of memory. Their process/strategy error is zero. Moreover
 T(rho_{O^j C},B^{tensor j} tensor tau_p)=T(tau_{S^j p},tau_p)=TV(S^j p,p),
because the omega_k occupy mutually orthogonal locally readable sectors.

The exact resource ledger is
 E_R(tau_p)=(sum_k k p_k) ln 2.
Upper bound: compare each Bell sector with its separable Schmidt-diagonal state, and mix with the same p_k. Lower bound: locally measure the sector flag and use strong monotonicity of E_R; every conditional omega_k has E_R=k ln 2. No branch is postselected away. The same equality holds for entanglement cost and distillable entanglement for these flagged Bell states, with the standard asymptotic definitions.

2. ALL INTERMEDIATE RETURNS: SIMPLE EXACT-OUTPUT FAMILY
Choose k uniformly on {J,...,J+L-1}, L>=J, and K=J+L-1. Then for every 0<=j<=J,
 T(Phi^j(tau),tau)=j/L,
 rho_{O^j C}=B^{tensor j} tensor Phi^j(tau),
 E_R(tau)=[J+(L-1)/2] ln 2,
 log D_K = (J+L)ln2 + log(1-2^{-(J+L)}).
At terminal delta=J/L, delta E_R = (J ln2)/2 + delta (J-1/2)ln2.
This yields exact Bell operation throughout the whole horizon, not just good one-slot marginals, and it makes all intermediate returns small. It improves the seed fixture's exhausted branches but is standard consumable/approximate-catalytic reservoir machinery.

3. EXACT LADDER-CLASS OPTIMUM FOR TERMINAL RETURN ONLY
Fix 0<delta<=1. Put n=ceil(1/delta), p_{qJ}=delta for q=1,...,n-1, and p_{nJ}=1-(n-1)delta. Every other p_k=0. Then the first J outputs are exact Bell pairs, the terminal return T(Phi^J(tau),tau)=delta, and
 E_R(tau)=m [n-delta n(n-1)/2].
The bracket lies in [1/(2delta)+1/2, 1/(2delta)+1/2+delta/8].
This is exactly minimal over all classical Bell-ladder distributions p supported on k>=J with terminal return at most delta.
Proof of optimality: TV(S^Jp,p)<=delta implies every contiguous J-level block has probability <=delta (apply the difference of cumulative distribution functions). For every integer r>=1, Pr[K>=rJ]>=max{1-(r-1)delta,0}. Hence
 E[K]>=J E[floor(K/J)]=J sum_{r>=1}Pr[K>=rJ]>=J[n-delta n(n-1)/2].
The displayed distribution has nonincreasing block masses, terminal TV exactly delta, is concentrated at the left end of each block, and attains equality.
CAUTION: this terminal optimizer has T(Phi^j(tau),tau)=1 for j=1,...,J-1 when J>1. It does not satisfy small intermediate returns. Use section 2 if those are required. Both have the same sharp leading coefficient as delta->0 at fixed J.

4. ASYMMETRIC OUTPUT/RETURN ERRORS AND CORRELATIONS
Let 0<=alpha<1, s=1-alpha, and choose a good distribution p supported on k>=J+1, disjoint from the absorbing vacuum even after J calls. Initialize tau=alpha omega_0+s tau_p. Then
 rho_{O^J C}=alpha Z^{tensor J} tensor omega_0 + s B^{tensor J} tensor tau_{S^Jp}.
Since B and Z are orthogonal, the COMPLETE J-output state has half trace error exactly alpha from B^{tensor J}. The memory return is exactly
 delta=s TV(p,S^Jp).
The joint output-memory error to B^{tensor J} tensor tau is exactly alpha+delta.
Thus output error alpha and return delta are separate quantities; one must not call delta alone the joint catalytic error. The bad branch is fully counted and stays correlated with every output and with the memory flag.
For the all-intermediate-return version choose p uniform on {J+1,...,J+L}. Then for all j<=J:
 output half trace error =alpha,
 memory half-return =s j/L,
 joint error to B^{tensor j} tensor tau =alpha+s j/L,
 E_R(tau)=s[J+(L+1)/2]ln2.
At delta=sJ/L, delta E_R -> s^2 m/2 as L->infinity.
For the terminal-only exact class optimizer choose d=delta/s in (0,1], n=ceil(1/d), p_{qJ+1}=d for q<n and p_{nJ+1}=1-(n-1)d. Its resource is
 E_R(tau)=s ln2 [1+J(n-d n(n-1)/2)]
 =s^2 m/(2delta) + s(J/2+1)ln2 + O(delta m).
This is an achievable asymmetric error/resource curve only. Section 10 gives a stronger noisy-output incumbent and disproves its interpretation as a universal lower frontier.

5. COHERENT PURE-STATE INCUMBENT (DO NOT COMPARE ONLY WITH HARMONIC STATES)
The same channel applied to a pure coherent ladder supported above the first J levels preserves that coherence until J calls. Let theta=pi/(L+1),
 |psi>=sum_{r=0}^{L-1} a_r |e_{J+r}>,  a_r=sqrt(2/(L+1)) sin((r+1)theta).
Then for j<=J,
 rho_{O^j C}=B^{tensor j} tensor |psi_j><psi_j|,
 |psi_j>=sum_{r=0}^{L-1}a_r |e_{J+r-j}>,
 C_j=<psi|psi_j>=[(L-j)cos(j theta)+sin((j+1)theta)/sin(theta)]/(L+1),
 T(|psi><psi|,|psi_j><psi_j|)=sqrt(1-C_j^2).
For j fixed relative to L, T~pi j/L (full trace norm ~2pi j/L). The initial entanglement is exactly
 E_R(psi)=H({a_r^2})+[J+(L-1)/2]ln2.
Consequently pure smooth ladders also achieve E_R=Theta(J/delta), with this sine profile having delta E_R -> (pi/2)m. This is a stronger scaling comparator than the usual unoptimized harmonic embezzler's familiar square-root global error bound. The mixed uniform ladder uses a smaller leading coefficient, m/2. No claim of optimal pure-state coefficient is made.
For a local rank/dimension cap D this coherent or mixed family requires log D=Theta(J/delta). A continuity-bound substitution gives the same scaling but is not the novel universal resource theorem.

6. INFINITE-RANK, FINITE-ENTROPY EXACT SUCCESS-BRANCH EMBEZZLER
For completeness, normal infinite rank permits a different exact probabilistic catalytic branch that no finite Schmidt rank can have. Let alpha_exp=1+u>1 and
 |gamma_u>=sum_{n>=1}sqrt(p_n)|n,n>, p_n=n^{-(1+u)}/zeta(1+u).
Set q=2^{-u}. Alice performs the two-outcome diagonal filter
 f_n^2=q p_{ceil(n/2)}/(2p_n)<=1.
On success both parties relabel n=2(m-1)+b+1 as (m,b). The unnormalized vector is exactly sqrt(q)|gamma_u> tensor |Phi_2>. A single success bit is communicated to Bob, so this is a normal finite-round finite-outcome LOCC operation. The failure Schmidt weights are proportional to p_{2m-1}-p_{2m}. Nothing is postselected out in an average use.
H(p)=ln zeta(1+u)-(1+u) zeta'(1+u)/zeta(1+u)=1/u+O(log(1/u)); 1-q=u ln2+O(u^2).
A separate reserve of J exact Bells ensures the first J emissions even if a filter attempt fails. On each success the emitted Bell is replaced in the reserve and gamma returns exactly. After any failure the reserve is consumed normally, with a retained local failure flag counted in memory. The probability of any failure by call j is 1-q^j and the memory half-return is <=1-q^j. The ER cost is Jln2+H(p); at delta~uJln2 it has delta E_R~m. This is a valid but factor-two-worse leading resource constant than the mixed uniform ladder. It also demonstrates why a statement that finite ER or normality forbids every exact catalytic success branch would be false. Finite rank forbids that exact branch by Schmidt rank multiplication; all branches averaged obey the universal obstruction.

7. ENERGY/SPREAD AND NONRECURRENCE BOUNDARIES
An optional explicitly declared Hamiltonian is H_A=nu sum_k k I_k, H_B likewise, nu>0. Then each party's mean energy is nu E[K] and its maximum energy is nu K. The degeneracy at energy nu k is 2^k, so Z(beta)=sum_k 2^k exp(-beta nu k); an infinite ladder has finite Gibbs partition function only for beta nu>ln2. This is a mathematical energy convention, not a proof of a physically obtainable memory or an experimentally measurable resource cap.
The mixed uniform state's entanglement-number spread is L-1, and the maximum stored entanglement is Kln2=Theta(J/delta). The expected entanglement, not the maximum, enters the resource ledger.
For every fixed normal distribution p on nonnegative k, including infinite-mean p, the absorbing shift has Phi^t(tau_p)->omega_0 in trace norm because Pr[K>=t]->0. Thus none of these reservoirs is recurrent; they offer finite fuel with small fixed-error return. Sending L->infinity changes the initializer and does not create one normal infinite reusable reservoir.

8. COMPARISON AND SCOPE
Ordinary exact J-Bell consumption costs exactly m and generally has terminal return 1; it is cheaper than small-return storage when actual entanglement use is honestly counted. The mixed ladder's apparent preservation comes from uncertain initial fuel balance, with fuel still depleted by exactly one Bell per good call. Standard approximate catalysts and smooth embezzlers also require counted memory resources. The principal branch's exact-output stopping argument handles arbitrary output-output and output-memory correlations. The section 4 bad/good mixture supplies an achievable noisy-task curve, but section 10 proves that curve is not the globally optimal noisy frontier. Correlations in the explicit bad/good mixture are not discarded.

9. UNFLAGGED MIXED RESERVOIR: VERIFIED ALL-PREFIX SECOND-ORDER IMPROVEMENT
This construction was proposed independently by the principal/bound-audit branch and audited here. It is stronger than the classical flagged ladder at fixed E_R because it erases the locally readable fuel flag. This is a mathematical E_R accounting improvement, not a proved preparation-cost improvement.

Let N=J+L-1, L>=J, and chi=(|00><00|+|11><11|)/2. On exactly N local qubits per party put
 theta_k=B^{tensor k} tensor chi^{tensor(N-k)}, k=0,...,N,
 rho_{J,L}=(1/L) sum_{k=J}^N theta_k.
The fixed device emits the first local qubit, shifts the other N-1 left, and appends one copy of chi. Alice generates one fair classical bit, communicates it, and both parties append that bit locally; all outcomes are averaged. Thus no fresh shared entanglement is supplied. The memory has local dimension 2^N, finite external qubit outputs, and a normal finite-round two-outcome LOCC device. The input ports are discarded, so every faithful product reference works.
For every j<=J,
 rho_{O^j C}=B^{tensor j} tensor rho_j,
 rho_j=(1/L) sum_{k=J-j}^{N-j} theta_k.
There are no correlations at all among the first J outputs or between those outputs and memory.

EXACT HALF-TRACE RETURN:
 delta_j=T(rho_{J,L},rho_j)=[j-(2^j-1)2^{-L}]/L, 0<=j<=J.
In particular all intermediate returns are at most j/L. Proof: use the common tensor-product Bell-plus/Bell-minus eigenbasis, with chi=(B_plus+B_minus)/2. Let r be the length of the initial all-plus run in the eigenstring; all strings with the same r have the same likelihood ratio. Initially
 P(r)=(1-2^{-(r-J+1)})/L, J<=r<N,
 P(N)=2(1-2^{-L})/L,
 and zero otherwise.
For the post-j state, replace the mixture range [J,N] by [J-j,N-j]. Direct subtraction shows Q(r)>=P(r) for r<=N-j and P(r)>=Q(r) for r>=N-j+1. The inequality at r=N-j is Q-P=(2^j-1)2^{-L}/L>0; for all larger r the geometric tail of Q makes P-Q positive (L>=j). Therefore the positive eigenspace is exactly the event that the first N-j+1 Bell signs are plus. In the difference of the mixtures, this event has probability j/L for the j added high-k terms, less
 (1/L)sum_{k=J-j}^{J-1}2^{-(N-j+1-k)}=(2^j-1)2^{-L}/L
 for the j removed low-k terms. This proves the formula. It is the full memory distance and, because the first j outputs are pure Bell and factor, also the full joint output-memory distance to B^{tensor j} tensor rho_{J,L}.

EXACT E_R:
 E_R(rho_{J,L})=N ln2-S(rho_{J,L})
 =[J+(L-1)/2]ln2-lnL+h_L,
 where h_L=H(K|X) and 0<=h_L<=2ln2.
Here K is uniform on {J,...,N}, and conditional on K=k the Bell-sign string X has its first k signs plus and its last N-k signs uniform. To prove E_R=Nln2-S, the separable comparison chi^{tensor N} gives the upper bound. For every separable sigma one has sigma<=sigma_A tensor I_B (each product term obeys rho_B<=I). Operator monotonicity of log then gives
 D(rho||sigma)>=D(rho||sigma_A tensor I_B)
 =-S(rho)-Tr rho_A ln sigma_A>=S(rho_A)-S(rho).
The marginal rho_A=I/2^N, proving equality without assuming a closest separable state.
The entropy identity follows from H(X|K)=E[N-K]ln2 and H(K)=lnL. Given X with initial plus run r, the posterior K is proportional to 2^k over k=J,...,min(r,N). Reversing the index gives the truncated geometric distribution
 p_u=2^{-(u+1)}/(1-2^{-t}), u=0,...,t-1,
 with t=min(r-J+1,L). Its entropy is
 h_t=[2-t/(2^t-1)]ln2+ln(1-2^{-t})<=2ln2.
Averaging proves the bound. Moreover h_L->2ln2 as L->infinity by bounded convergence over the mixture (the probability of any fixed small t is O(1/L)); no divergent constant is hidden.

For fixed J and L->infinity, terminal delta_J=J/L+O(2^{-L}/L), and hence
 E_R(rho_{J,L})=m/(2delta_J)-ln(1/delta_J)+O_J(1).
This simultaneously attains the leading inverse-error term and the negative logarithmic correction of the principal branch's universal stopping obstruction (assuming that obstruction is certified). The exact constant term is
 (J-1/2)ln2-lnJ+2ln2+o(1).
There is no implication of recurrence because L changes the initializer and the memory has a finite supply of Bell factors. The entanglement decreases by exactly j ln2 through the first J calls: the pure Bell factorization plus the appended separable chi gives E_R(rho_j)=E_R(rho_{J,L})-jln2.

ASYMMETRIC VERSION:
Add only a persistent locally readable binary good/bad flag. The bad sector, weight alpha, is product and absorbing, emitting Z every call; the good sector, weight s=1-alpha, contains rho_{J,L} and follows the device above. The flag is retained and counted, but K is never retained. Then at every j<=J,
 rho_{O^j C}=alpha Z^{tensor j} tensor omega_bad + s B^{tensor j} tensor rho_j (in the good sector),
 output error T(rho_{O^j},B^{tensor j})=alpha,
 memory return delta_j=s[j-(2^j-1)2^{-L}]/L,
 joint error T(rho_{O^j C},B^{tensor j} tensor tau)=alpha+delta_j,
 E_R(tau)=s E_R(rho_{J,L}).
For fixed J and s>0, delta=delta_J->0 gives
 E_R(tau)=s^2 m/(2delta)-s ln(1/delta)+O_{J,s}(1).
All branches and all output-memory correlations are explicit. If only the combined joint error beta is specified, alpha and delta must satisfy alpha+delta=beta; do not silently identify beta with delta.

ENERGY/PREPARATION LEDGER:
The local dimension is exactly 2^N. The local marginal is maximally mixed on N qubits. For H_X=nu sum_{i=1}^N |1><1|_i, each party's mean energy is nu N/2, maximum nu N. There is no observable orthogonal fuel number K: different theta_k overlap. A Hamiltonian whose energy is nu k on theta_k cannot exist because nonorthogonal states cannot belong to distinct eigenspaces. A direct preparation that samples K and then discards its record consumes E[K] Bells on average and at most N; E_R is smaller by lnL-h_L. No claim that entanglement cost E_C equals E_R is made. Efficient laboratory preparation and access to the whole memory are separate unknowns.

10. NOISY ENTANGLED INCUMBENT DEFEATS A NAIVE ASYMMETRIC FRONTIER
The earlier sections' achievable coefficient (1-alpha)^2 m/(2delta) is NOT a proved universal lower bound for nonzero output error alpha. In fact it is false already for a single Bell-pair output (J=1). An approximate task must compare genuinely noisy entangled output states, not only rare orthogonal bad branches.

For 0<=alpha<=1/2 let
 rho_alpha=(1-alpha) B + (alpha/3)(I-B)
 be the two-qubit isotropic state. Then T(rho_alpha,B)=alpha and exactly
 e_alpha=E_R(rho_alpha)=ln2-h_2(alpha),
 h_2(alpha)=-alpha ln alpha-(1-alpha)ln(1-alpha).
Proof of lower bound: any separable gamma has q=Tr B gamma<=1/2. Binary Bell-test data processing gives
 D(rho_alpha||gamma)>=d(1-alpha||q)>=d(1-alpha||1/2)=ln2-h_2(alpha).
For the upper bound take the separable isotropic state
 gamma_*=(1/2)B+(1/6)(I-B).
An explicit separable decomposition is the uniform mixture of |psi><psi| tensor |psi*><psi*| over psi in {0,1,+,-,+i,-i}; the six Pauli-axis states form the required second moment. Since rho_alpha and gamma_* have uniform weights on their three-dimensional orthogonal complements, their relative entropy is exactly the same binary expression.

Use a classical flagged reservoir with k copies rho_alpha and local padding, k uniform on {1,...,L}. The fixed controlled shift device emits one rho_alpha and decrements k. The first output is exactly rho_alpha and factors from all retained memory. The memory half-return is delta=1/L. Every branch is counted. Additivity of relative entropy for the comparison gamma_*^{tensor k} gives
 E_R(tau_L)=(1/L)sum_{k=1}^L E_R(rho_alpha^{tensor k})
 <=[(L+1)/2] e_alpha.
Consequently limsup_{delta->0} delta E_R(tau_L)<=e_alpha/2.
At alpha=0.1, e_alpha=0.3680642072 nats, e_alpha/2=0.1840321036, whereas the proposed rare-bad-branch lower coefficient (1-alpha)^2 ln2/2 would be 0.2807246081. This is an explicit strict counterexample.
The complete one-call joint state is rho_alpha tensor tau_shift. Relative to B tensor tau_initial its half trace error is exactly
 beta=delta+(1-delta)alpha,
 because common flag sectors have output trace error alpha and the two boundary flag sectors have disjoint support. Thus no output-memory correlations or failure damage are hidden.

AN EXACT-ADDITIVE ALTERNATIVE:
Replace rho_alpha by the maximally correlated phase-noise state
 rho_alpha^phase=(1-alpha)B_plus+alpha B_minus.
It has the same trace error alpha and the same exact e_alpha. Moreover
 E_R((rho_alpha^phase)^{tensor k})=k e_alpha
 follows directly from the maximally correlated entropy formula proved in section 9: local marginal I/2^k, total entropy k h_2(alpha), and separable comparison chi^{tensor k}. Thus this flagged noisy reservoir has E_R(tau_L)=[(L+1)/2]e_alpha exactly, with no reliance on unknown isotropic-state additivity.
For a whole J-call Bell target with error alpha, let a=1-(1-alpha)^{1/J} and use copies of rho_a^phase. Every first J output is rho_a^{phase tensor J}, whose half trace error from B^{tensor J} is exactly alpha. The all-prefix flagged ladder k uniform {J,...,J+L-1} has terminal delta=J/L and
 E_R=[J+(L-1)/2][ln2-h_2(a)],
 so delta E_R -> (J/2)[ln2-h_2(a)].
This is another admissible ordinary consumable-entanglement comparator. The globally sharp noisy-output frontier, allowing arbitrary correlations and memory states under the same E_R and error definitions, remains unresolved here. The principal exact-output alpha=0 second-order result is unaffected.

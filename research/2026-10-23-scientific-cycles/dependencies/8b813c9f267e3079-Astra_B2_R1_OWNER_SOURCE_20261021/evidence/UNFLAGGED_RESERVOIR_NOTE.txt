# Unflagged nested Bell reservoir: exact return and relative entropy resource

All logarithms are base 2. The error below is the full trace norm, not half trace distance. This note proves a finite construction and its resource exactly. It makes no historical novelty claim.

## 1. Registers and fixed finite LOCC device

Fix integers `d >= 2`, `t >= 1`, `N >= 1`. Each external use is intended to emit one `d`-dimensional Bell pair. Write

\[
 \phi_d=|\Phi_d\rangle\langle\Phi_d|,
 \quad |\Phi_d\rangle=d^{-1/2}\sum_{a=0}^{d-1}|aa\rangle,
 \quad \chi_d=d^{-1}\sum_{a=0}^{d-1}|aa\rangle\langle aa|.
\]

The memory comprises `Nt` such pairs, so each local memory has dimension `d^(Nt)`. All of it is counted. The device transfers the first memory pair to the external output, shifts the other pairs left by one place, and fills the final place with `chi_d`. The fill is finite-round, finite-outcome LOCC: Alice samples a uniform `a`, sends it to Bob, and they prepare `|aa>`. The branch average is included. No branch is postselected. Retaining additional copies of that classical outcome is unnecessary; the retained pair itself already records it.

After `t` uses, this same fixed device shifts out the first `t` pairs and appends `chi_d^tensor t`. Set

\[
 D=d^t,\quad m=\log D=t\log d,\qquad
 \rho_k=\phi_d^{\otimes kt}\otimes\chi_d^{\otimes(N-k)t}
 \quad(0\leq k\leq N).
\]

Define the initial and returned memory states

\[
 \tau_N=\frac1N\sum_{k=1}^N\rho_k,
 \qquad \tau'_N=\frac1N\sum_{k=0}^{N-1}\rho_k.
\]

The initial state has no explicit classical `k` flag. In each term, the first `t` memory pairs are Bell pairs. Consequently, the complete first `t` outputs are exactly

\[
 \phi_d^{\otimes t}\otimes\tau'_N
 =\phi_D\otimes\tau'_N
\]

after the canonical local regrouping. In particular these outputs are mutually independent and independent of the returned memory. Later outputs need not be independent, and the construction makes no such assertion.

For `t=1`, this is a one-use reservoir. Grouping `t` successive uses only simplifies its analysis and does not change the device.

## 2. Exact return error

Telescoping gives

\[
 \tau_N-\tau'_N=\frac1N(\rho_N-\rho_0)
 =\frac1N(\phi_D^{\otimes N}-\chi_D^{\otimes N}),
\]

where `chi_d^tensor t = chi_D` under local regrouping. The pure state `phi_D^tensor N` is a rank-one projector inside the support of `chi_D^tensor N`; the latter is the normalized identity on the correlated subspace of dimension `D^N`. The difference has one positive eigenvalue `1-D^(-N)` and `D^N-1` negative eigenvalues `-D^(-N)`. Hence

\[
 \boxed{\delta_N:=\|\tau_N-\tau'_N\|_1
 =\frac{2(1-D^{-N})}{N}.}
\]

This is the marginal state error of the complete retained quantum memory. It is not a statement that this hidden-memory error can be measured from external ports.

## 3. Exact relative entropy of entanglement

The states are maximally correlated in the common local computational basis. Their local marginals equal the maximally mixed state on dimension `D^N`, and their common computational diagonal is `chi_D^tensor N`.

For every separable state `sigma_AB`,

\[
 \sigma_{AB}\leq I_A\otimes\sigma_B.
\]

This follows first termwise from a separable convex decomposition, because a density matrix on `A` is bounded above by `I_A`, and then by closure. Operator monotonicity of the logarithm gives, with the usual support convention or positive regularization,

\[
\begin{aligned}
 D(\tau_N\|\sigma)
 &\geq -S(\tau_N)-\operatorname{Tr}(\tau_{N,B}\log\sigma_B)\\
 &=S(\tau_{N,B})-S(\tau_N)
   +D(\tau_{N,B}\|\sigma_B)\\
 &\geq N\log D-S(\tau_N).
\end{aligned}
\]

Choosing the separable comparator `chi_D^tensor N` attains the last bound. Thus, without any regularization or asymptotic distillation argument,

\[
 \boxed{R_N:=E_R(\tau_N)=N m-S(\tau_N).}
\]

This identity also proves that all the entropy saving stated below concerns the actual relative entropy resource, not merely an upper bound on it.

## 4. Complete finite spectrum

Let `omega = exp(2 pi i/D)` and define Bell phase vectors

\[
 |\varphi_z\rangle=D^{-1/2}\sum_{a=0}^{D-1}\omega^{za}|aa\rangle,
 \qquad z=0,\ldots,D-1.
\]

These form an orthonormal basis of the correlated subspace, with `phi_D = |varphi_0><varphi_0|` and `chi_D = I_corr/D`. All the `rho_k` commute in their tensor-product phase basis. For a phase string `z=(z_1,...,z_N)`, let `L(z)` be its initial number of zeros, capped at `N`.

The eigenvalue depends only on `l=L(z)`. The zero class `l=0` has eigenvalue zero and multiplicity `(D-1)D^(N-1)`. For `1 <= l < N`,

\[
 \boxed{
 \lambda_l=\frac1N\sum_{k=1}^{l}D^{-(N-k)}
 =\frac{D^{-(N-l)}}{N}\frac{1-D^{-l}}{1-D^{-1}},
 \quad a_l=(D-1)D^{N-l-1}.}
\]

The all-zero phase string has multiplicity one and eigenvalue

\[
 \boxed{\lambda_N=\frac1N\sum_{k=1}^{N}D^{-(N-k)}
 =\frac{1-D^{-N}}{N(1-D^{-1})}.}
\]

Outside the correlated subspace all eigenvalues are zero. These eigenvalues obey `sum_(l=1)^N a_l lambda_l = 1`, with `a_N=1`. Therefore an explicit closed finite sum for the resource is

\[
 \boxed{R_N=Nm+\sum_{l=1}^{N}a_l\lambda_l\log\lambda_l.}
\]

This formula needs only `N` scalar terms, even though the memory dimension is exponential in `Nt`.

## 5. Conditional-entropy formula and uniform finite constant

Equivalently, sample a uniform `K` from `{1,...,N}`. Given `K=k`, set `Z_1,...,Z_k=0` and sample `Z_(k+1),...,Z_N` independently and uniformly from `{0,...,D-1}`. The classical distribution of `Z` is the spectrum just computed. Consequently

\[
 S(\tau_N)=H(Z)
 =\log N+\frac{N-1}{2}m-H(K\mid Z),
\]

and

\[
 \boxed{R_N=\frac{N+1}{2}m-\log N+H(K\mid Z).}
\]

The posterior depends on `Z` only through `L=L(Z)`. Put `r=1/D`. For `1 <= l < N` and for `l=N`, respectively,

\[
 p_l:=\Pr(L=l)=\frac{1-r^l}{N},
 \qquad p_N=\frac{1-r^N}{N(1-r)}.
\]

Conditioned on `L=l`, the gap `G=l-K` has the truncated geometric law

\[
 \boxed{\Pr(G=g\mid L=l)=\frac{(1-r)r^g}{1-r^l},
 \qquad g=0,\ldots,l-1.}
\]

Its entropy is the explicit scalar

\[
\begin{aligned}
 h_l
 &=-\log(1-r)+\log(1-r^l)
   -\left[\frac{r}{1-r}-\frac{l r^l}{1-r^l}\right]\log r\\
 &=c_D+\log(1-r^l)+\frac{l r^l}{1-r^l}\log r,
\end{aligned}
\]

where

\[
 \boxed{c_D=-\log(1-D^{-1})+\frac{\log D}{D-1}
 =\log\frac{D}{D-1}+\frac{m}{D-1}\leq 2.}
\]

Both corrections to `c_D` in the expression for `h_l` are nonpositive, so `0 <= h_l <= c_D`. The bound `c_D <= 2` follows because `r <= 1/2` and the entropy of a geometric distribution is increasing in `r` (or directly from the displayed formula). Therefore

\[
 \boxed{0\leq H(K\mid Z)=\sum_{l=1}^N p_lh_l\leq c_D\leq2,}
\]

and the exact finite resource satisfies

\[
 \boxed{
 \frac{N+1}{2}m-\log N
 \ \leq\ R_N\ \leq\
 \frac{N+1}{2}m-\log N+c_D.}
\]

The lower estimate can be negative for very small `m,N`; the exact resource remains nonnegative.

## 6. Asymptotics and inversion of the error

For fixed `D`, the nonnegative series `sum_(l>=1) [c_D-h_l]` converges, because its terms are `O_D(l D^(-l))`. Since `p_l <= 1/N` for `l<N`, while the capped `p_N = O_D(1/N)`, this gives

\[
 H(K\mid Z)=c_D-O_D(N^{-1}).
\]

Hence

\[
 R_N=\frac{N+1}{2}m-\log N+c_D-O_D(N^{-1}).
\]

The exact return error obeys

\[
 \frac1{\delta_N}=\frac{N}{2(1-D^{-N})}
 =\frac N2+O_D(ND^{-N}),
 \quad \log\frac2{\delta_N}=\log N+O_D(D^{-N}).
\]

Consequently the sharp-order error/resource relation on this explicit sequence is

\[
 \boxed{
 R_N=\frac{m}{\delta_N}-\log\frac2{\delta_N}
      +\frac m2+c_D+O_D(N^{-1})+O_D(mND^{-N}).}
\]

The signed `O_D(N^-1)` term above may be negative. In particular,

\[
 \delta_N R_N
 =m-\delta_N\log\frac2{\delta_N}+O_D(\delta_N).
\]

For fixed output block dimension `D`, the possible logarithmic correction to the leading `m/delta` resource requirement is real. A universal inequality of the form `R >= m/delta - C_D` with a constant independent of `delta` is false, and so is `m <= delta R` for all sufficiently large `N`. This does not contradict coarser inequalities with a larger constant multiplying `delta R`.

## 7. Comparison with the prefix-test universal lower bound

Suppose any LOCC channel takes a memory `tau` with finite `R=E_R(tau)` to the exact product `phi_D tensor tau'`, and `||tau-tau'||_1=delta>0`. Repeating the same channel `j` times makes the prefix `j` Bell test pass with probability at least `1-(j-1)delta/2`. For a separable initial memory the pass probability is at most `D^(-j)`.

Cap the number of initial consecutive Bell-test successes at `M=ceil(2/delta)`. Its actual distribution has no zero outcome, its expectation is at least

\[
 A_M=M-\frac{\delta M(M-1)}4,
\]

and its entropy is at most `log M`. The separable comparison distribution has probability at most `D^(-k)` at outcome `k`. Relative-entropy data processing therefore proves

\[
 \boxed{R\geq m A_M-\log M
 \geq \frac m\delta+\frac m2-\log\left\lceil\frac2\delta\right\rceil.}
\]

The second inequality follows by writing `M=2/delta+s`, `0<=s<1`, which gives `A_M=1/delta+1/2+delta*s*(1-s)/4`.

At the constructed errors `delta_N`, this universal bound and the explicit resource `R_N` differ by at most `c_D + o_D(1)` bits as `N` tends to infinity. Since `c_D <= 2`, the universal asymptotic lower envelope is determined to a bounded additive error, including the coefficient of the logarithmic correction. This statement concerns internal correctness; the historical novelty of this exact formulation must be checked separately.

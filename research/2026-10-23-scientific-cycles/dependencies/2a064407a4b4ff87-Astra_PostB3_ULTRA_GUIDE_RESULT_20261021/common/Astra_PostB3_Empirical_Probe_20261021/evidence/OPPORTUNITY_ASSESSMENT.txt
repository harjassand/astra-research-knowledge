BOUNDed EMPIRICAL OPPORTUNITY ASSESSMENT — GENETIC DOUBLE PERTURBATIONS
2026-10-21. This is source admission and strategic assessment, not predictor work.

DECISION
Do not make Norman-only perturbation prediction Astra's new flagship. Do not
infer a new scientific opening from the 2025 finding that additive/linear
baselines beat several deep models. The current October 2026 primary comparator
substantially changes that premise. Wessels23 is a more defensible source for a
bounded evidence-acquisition experiment, but no new prediction mechanism or
performance headroom beyond the strongest applicable methods is established.

WHAT CHANGED THE INITIAL ATTRACTION
The 2025 Ahlmann-Eltze/Huber/Anders paper benchmarked 100 single activations and
124 pairs in Norman K562 data, with all singles and half the pairs available for
training. Its additive baseline predicts mean_a + mean_b - mean_control on the
specified log-normalized scale. It outperformed the tested complex methods in
that benchmark. Code was inspected, not merely its abstract.

The October 2026 Miller et al. Nature Biotechnology paper now reports improved
models under calibrated metrics, discusses limited remaining Norman headroom,
and includes Wessels23 double perturbations. The strongest comparator therefore
cannot be limited to additive, mean, GEARS or the 2025 paper's model selection;
PRESAGE and the current calibrated evaluation belong in any advancement claim.
The availability of current counterevidence is sufficient to reject the easy
story that simple linear models universally define the current frontier.

An independent 2026 GenBio preprint also claims model improvements, but its actual
Norman preprocessing explicitly filters to nperts<=1. Its convenient 4.81 MB
norman_pseudobulk_deltas.h5ad is NOT a double-perturbation seed. This was verified
in the actual code at pinned commit e5b4caf734fd81b24bee004eb2d55d2f675cd4a2.

POSSIBLE FIRST EXPERIMENT, ONLY IF ALLOCATED
Question: Is there a reproducible, perturbation-specific interaction signal beyond
the additive expectation under the available experimental grouping, large enough
to justify a new predictive construction under Astra's free CPU resources?

Use available raw sample/batch/guide metadata before assigning splits. Keep all
cells from an experimental unit together. Preserve single-pair relationships and
identify pair labels whose two singles and matched controls actually exist.
Do not silently treat every cell as an independent biological experiment.

Construct groupwise mean log-normalized expression and the residual
  r_ab,g = mean_ab,g - mean_a,g - mean_b,g + mean_control,g.
The log-normalized endpoint must be fixed in advance, because additivity changes
under a nonlinear response transformation. Choose evaluated genes using training
controls/training data only; retain a declared whole-gene sensitivity analysis.
Do not select DE genes from held-out pair outcomes and then claim blind prediction.

With independent experimental groups, examine cross-group agreement of r_ab.
With only technical cell halves, independently partition pair, each single and
control cells; shared estimated single/control means across halves would create
spurious residual agreement. The cross-half dot product r_ab,1 dot r_ab,2 is a
simple noise-aware signal diagnostic when the sampling errors are independent.
It estimates squared interaction magnitude under those sampling assumptions, not
generalizable causal mechanism. Shared singles couple pair errors, so uncertainty
must retain this dependence; ordinary cell bootstrap confidence is insufficient.

Compare no-change, additive and a validation-tuned linear/shrunken additive model
on the same transformation and grouping, and reproduce the relevant published
positive-control calibration. A positive control reveals measurable headroom but
is not an achievable predictor. Report condition/pair-level errors and effect
specificity as well as whole-transcriptome averages. Use the current PRESAGE
results only as contextual evidence unless the same inputs/splits/predictions are
reproduced; incompatible published numbers cannot be used as a matched win.

Stopping condition: if the actual metadata cannot separate experimental groups,
state that only within-experiment precision was learned. If residuals fail even
technical reproducibility, stop this target. If residuals survive, a predictor
programme still requires an identified relation/features unavailable to the
strongest current method; measurable residual is not itself a method opportunity.
This first experiment admits or rejects a source/modeling premise. It is not a
claim of a new metric framework, biological discovery, or research amplification.

RESOURCE ADMISSION
No GPU training, model sweep, paid API, wet laboratory or outreach is needed for
data inspection and pseudobulk arithmetic. Sparse input aggregation can be done
in row blocks; the dense output has only conditions x selected genes entries.
The current public full benchmark recommends substantial GPU/RAM resources and
is not a suitable default execution plan. Rebuilding all model environments or
all fourteen datasets would violate this bounded admission scope. Actual running
time for a later aggregation is not measured by this source inspection.

WHY NOT CHOOSE METABOLIC KNOCKOUT MODELING INSTEAD?
The perturbation input has direct experimental response observations and a
specified current baseline dispute; the B3 metabolic artifact has exact model
semantics but no acquired phenotype validation set or demonstrated downstream
scientific failure. This gives perturbation evidence acquisition a clearer next
measurement, not a demonstrated superior long-term opportunity. Neither target
currently justifies displacing productive protected mathematics or becoming a
many-branch programme. A bounded empirical admission owner is the maximum justified
allocation from this investigation.

3. Precise interaction-versus-implementation observational equivalence
======================================================================
Fix the actual observed arm set and any declared ordinary nuisance means b_fc
(including singleton, technical, potency and target-incidence terms). Let Z be
the arm-by-family incidence matrix that is1 on BOTH pair constructions for family
f and0 on every singleton/control arm. Consider a gene-wise outcome model
  mu = b + Z*theta + Z*kappa,
where theta_f is a gene-pair biological interaction and kappa_f is a shared
family-specific dual-target-array implementation effect. The latter may represent
unmeasured partner-dependent guide processing/delivery/efficacy beyond the tested
scalar nuisance model. For every response-vector collection d_f,
  theta_f' = theta_f+d_f,  kappa_f' = kappa_f-d_f
leaves ALL observed arm means unchanged. With the same noise/dispersion law it
leaves the entire observed-data likelihood unchanged. In the augmented design,
  rank([M,Z_implementation,Z_interaction])
     -rank([M,Z_implementation]) =0
because the two Z blocks are identical. Even arbitrarily many cells at the same
arms cannot separate these two components.

Two concrete observationally identical models are (theta=h,kappa=0) and
(theta=0,kappa=h), for the same measured family residual h. The narrower potency
example in STATISTICAL_LEMMA is constructive without arbitrary per-gene nuisance:
if both guides' singleton signatures for A equal u and for B equal v, and both
pair responses equal(u+v)/2, then a shared interaction -(u+v)/2 and zero-interaction
half efficacy in dual-target arrays produce identical observations. The frozen
ordinary two-scalar model can remove this narrower explanation; Q removes any
linear combination of all four measured signatures.

This is a remaining mechanistic nonidentifiability proof, not a claim that the
restricted ordinary calibration can explain every observed outcome. That
restricted null is falsifiable and the admitted descriptive test remains useful.
A positive completed conditional result would constrain that specified ordinary
model, while still requiring an implementation exclusion to label the remaining
component intrinsic biological interaction. A nonpositive or incomplete result
cannot establish zero interaction, especially because Q deliberately removes
interactions aligned with the singleton span.

4. Shared reference, causal generalization and absolute RNA are separate axes
============================================================================
The raw unadjusted LOG cell-mean crossproduct has exact shared-control bias
tr(Cov(Cbar)) under iid disjoint-arm sampling; subtracting the sample covariance
trace/7 is its unbiased U-statistic correction. Code uses raw arm means for this
extra diagnostic. The count-rate trace is an influence/delta estimate, and learned
Q or technical-adjusted quantities have no such exactness claim. The contract's
pre-outcome precision note correctly distinguishes these cases.

Seven shared controls remain seven controls across105 families. They do not
become105 independent reference measurements. Lane and HTO labels support
conditional technical adjustment; they are not demonstrated independent culture
starts or randomized delivery batches. Bootstrap cell uncertainty does not
estimate culture/transduction variance or causal transport to other experiments.

Both representations retain a distinct absolute-RNA ambiguity. Conditional on
library size L_i, counts identify relative composition p_ag=R_ag/sum_h R_ah.
For arbitrary positive arm scales s_a, R_ag'=s_a*R_ag leaves p and every normalized
mean unchanged. Even an unconditioned capture model can keep the EXACT observed
count distribution by simultaneously setting capture efficiency q_i'=q_i/s_a,
so q_i'R_ag'=q_iR_ag. The library-size offset contains no independent total-RNA
measurement to break this invariance. Spike-ins or a separately established
absolute-RNA interface would be needed for that distinction.

For example absolute log interaction changes by
  log(s_pair)-log(s_A)-log(s_B)+log(s_control)
under this transformation, while the observed relative-RNA data remain identical.
A count-rate sensitivity therefore checks representation behavior within measured
RNA composition. It cannot establish absolute transcriptional interaction or
resolve capture/global-RNA scaling. This ambiguity is separate from the Z/Z
biological-versus-implementation alias and from unknown culture independence.

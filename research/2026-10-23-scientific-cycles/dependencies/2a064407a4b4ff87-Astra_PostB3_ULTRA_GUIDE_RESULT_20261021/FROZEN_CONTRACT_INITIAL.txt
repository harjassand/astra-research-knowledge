ESTIMANDS / TWO DIRECTIONS
C1=A_g1:B_g2; C2=B_g1:A_g2 with A<B lexical. Every family is tested C1->C2 and
C2->C1. Both sides may use ALL singles and controls. Source direction pair responses
may fit the declared ordinary calibration; ALL counterpart direction pair responses
are withheld from that direction's calibration/hyperparameters. No target response
chooses a coefficient, seed, model or tuning rule. Reverse analysis is prespecified,
not an independent replication or a later favorable split.

Primary representation: per-cell log1p(10000*raw_count/library_count), arithmetic
arm means. Count sensitivity: saturated arm Poisson model with library-size offsets;
arm rate MLE =10000*sum raw counts /sum library counts (no log). This remains relative
RNA composition, not absolute transcription. No spike-ins/total-RNA port is supplied.
The sensitivity is identical arms/genes/calibration, not a second dataset search.

REFERENCE-ONLY TECHNICAL ADJUSTMENT
Estimate additive lane+HTO effects using reference cells (all delivered single/NT
cells) with array fixed effects removed, by FWL weighted least squares. Primary
log uses equal cell weights; count-rate uses library weights. No pair response
estimates these effects. Center technical profile at reference cell composition.
Do not infer biological replicates or nonparametric batch common support. Report
rank/conditioning and missing exact-control support (control is L3/L4 only).
Conditional means bootstrap must propagate this shared technical adjustment.

ONE STRONG ORDINARY CALIBRATOR, SOURCE RESPONSES ONLY
For each source family, fit two NONNEGATIVE scalar main-effect weights to source
pair delta using its matched two single effects. Ridge toward (1,1), diagonal
penalty equal to the two singleton+control mean trace-noise estimates, with
1e-8 relative numerical floor. This is guide/slot efficacy calibration, not target
pair response fitting. Flag large/boundary weights and collinearity; never select
pairs by those outcomes.
On remaining source residuals, fit a weighted target-incidence vector ridge with
unpenalized intercept, leave-one-family-out prediction. This conventional nuisance
term can explain common/reference errors and target-associated corrections, rather
than rewarding them as pair specificity. Source-only analytic LOOCV chooses among
lambda [.01,.1,1,10,100]; predictors are column standardized; weights use source
pair counts normalized to mean1. Counterpart responses cannot choose lambda.
The same source weights and leave-one-out nuisance correction predict counterpart
using its allowed matched singles. Count-scale ordinary predicted rates are clipped
to nonnegative values; primary log predictions to [0,log(10001)]. Report clipping.

PAIR-SPECIFIC CONTRAST
From the four matched singleton delta vectors, form their joint span, pseudoinverse
Gram relative eigenvalue threshold1e-10. This projector Q is target-pair-blind and
removes arbitrary linear combinations of ALL FOUR measured main-effect signatures,
a broader potency span than the two-weight fit. It is noisy and must be refitted
in resampling; freezing a projector estimated from the same singles/control does
not make it independent. Interactions aligned with the span are deliberately lost.
Source-specific residual u=Q(source_pair_mean - ordinary_source_prediction).
Declare fixed half-strength transfer: counterpart prediction = ordinary_prediction
+0.5u, then the same representation range guardrail. Score directional gain as
MSE(ordinary,counterpart)-MSE(transfer,counterpart), all genes, equal family weights.
This is a technical contrast/evidence test, not a proposed predictor or a claim
that half transfer is optimal. No positive gain -> zero-interaction inference.
Report ordinary raw-additive and calibrated errors, all directional family scores,
counts of failures/positive signs, and projected dimensions. No individual family
significance claims or favorable family selection.

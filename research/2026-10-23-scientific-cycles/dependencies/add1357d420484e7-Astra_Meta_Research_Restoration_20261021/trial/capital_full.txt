3. Complete implemented operation

Write X_ig for raw counts,L_i=sum_g X_ig,G=21052. For the primary operation use
Y_ig=log(1+10000 X_ig/L_i); raw arm means average cells equally. For the sensitivity
use the saturated arm Poisson-offset MLE m_ag=10000 sum_i X_ig/sum_i L_i.
This is a relative rate; Poisson fitting here defines the arm estimate, NOT a
claimed complete count-interaction likelihood test or a Poisson noise assumption
for bootstrap calibration. Both representations remain library/composition based.
The implementation uses float32 stored sparse counts/log values and float64
aggregates/linear algebra. This is ordinary numerical arithmetic, not a rigorous
interval-arithmetic certificate of a population effect.

A common additive lane+HTO effect is fitted using only all2,612 single/NT reference
cells, with array fixed effects removed. For each representation let w_i=1 orL_i,
z_i be the12 lane/HTO indicator coordinates and a(i) the arm. Define n_a^w=sum_i w_i,
z_a=sum_i w_i z_i and raw weighted outcome mean M_a. With reference-arm set R,
K=sum_ref w_i z_i z_i' -sum_{a inR} z_a z_a'/n_a^w,
B=sum_ref w_i z_i Y_i' -sum_{a inR} z_a M_a'.
Gamma=K^+ B. Adjust every arm M_a by subtracting
(z_a/n_a^w-z0)'Gamma, with fixed reference-only target composition z0.
For rate calculations w_iY_i=10000X_i. K has numerical rank10 on both scales;
nonzero condition numbers are2.864 and2.692. No pair outcome estimates Gamma.
The additive common-effect assumption is not proved by a well-conditioned K.

For familyf/source constructions let s_A=M_singleA-C,s_B=M_singleB-C,

4. Information-boundary proof

Fix a direction. Technical coefficients and Q are functions of reference cells
only. Two-scalar coefficients and source residuals use source pair means only.
The ridge design/weights come from metadata/counts; its CV uses source residuals
only. Its target prediction replaces source signatures by permitted counterpart
single signatures while preserving target identityA/B. Thus the fitted target
prediction is measurable with respect to(source pairs,all references,design).
The counterpart pair means enter only scoring. Changing all counterpart pair
means arbitrarily cannot change beta,CV,source ordinary prediction or null mean.
The synthetic mutation check exercises precisely this property on the actual
105-family indexing and a synthetic expression array. The bounded source audit
independently checked indexing and this dependency structure, not RNA values.

In the source-only ORDINARY-NULL bootstrap, both pair null means are replaced by
that direction's ordinary source/target predictions, references unchanged. The
same jointly resampled arm-mean error (bootstrap minus observed) is added and
all fits refitted. Centered counterpart cell variability DOES enter this plug-in
noise estimate. 'Source-only' qualifies fitted null means/tuning, not all noise
inputs; it is not an externally specified exact null distribution. The procedure
was stopped after7draws and supplies no completed inferential result.

5. Why shared references must remain shared — complete covariance proof

Assume disjoint cell arms sampled independently, IID within each arm, finite
covariance, fixed arm membership. Let M_a be arm means,V_a=Cov(M_a), and fixed
linear contrasts R_j=sum_a l_ja M_a. Independence and bilinearity give
Cov(R_j,R_k)=sum_a l_ja l_ka V_a. Taking traces after writing each random vector
as its mean plus centered error gives
E[R_j'R_k]=r_j'r_k+sum_a l_ja l_ka tr(V_a).
This is the entire proof; it does not require gene-wise independence.

For two distinct pair and four distinct single arms sharing exactlyC,
rhat_1=P1-S_A1-S_B2+C and rhat_2=P2-S_A2-S_B1+C. OnlyC contributes a shared-arm
term, tr(V_C). Let Cbar be the seven-cell mean, S_C its unbiased sample covariance.
Then rhat_1'rhat_2-tr(S_C)/7 is unbiased for r1'r2 for UNADJUSTED LOG CELL MEANS
under those IID assumptions. Replacing Cbar'Cbar by sum_{i!=j}Y_i'Y_j/(7*6)
gives the same expression: expand(sum_iY_i)'(sum_iY_i), remove diagonal terms,
and use tr(S_C)=sum_i||Y_i-Cbar||^2/6. The42 ordered terms are dependent terms,
not42controls. The synthetic algebra check verifies the identity to2.22e-16.

The rate ratio is nonlinear in random library totals; its trace correction is
an influence plug-in, not this exact unbiasedness result. Fitted Gamma,Q,beta and
CV are data dependent; no fixed-coefficient trace correction makes their score
exact. In particular Q estimated from the same singles/control is not independent
merely because it is pair-response blind. Hence the frozen bootstrap resamples
each UNIQUE arm once per draw, reuses it across all families, and refits Gamma,
beta,CV,Q. No genes, duplicated references or families become independent cultures.
The intended399-draw one-sided null check, Bonferroni.0125 threshold, basic98.75%
intervals and Monte Carlo bound are preserved in the contract, but NOT reported
as executed. Seven controls would make even a completed check approximate and
conditional; arbitrary unobserved tails/culture variance are not certified.

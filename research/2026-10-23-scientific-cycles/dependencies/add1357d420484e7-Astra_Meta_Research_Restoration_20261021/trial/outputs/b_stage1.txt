TASK 1

Theta is uniquely identified for every attainable observation if and only if

    rank(C T) = q.

Equivalently, ker(C) intersects im(T) only at zero. These equivalences use T's full column rank.

Proof and reconstruction. Since A has full column rank, its left inverse H = (A^T A)^(-1) A^T recovers the mixture w = H y = B + T theta. Therefore

    d = C w - z = C T theta.

If M = C T has full column rank, then

    theta = (M^T M)^(-1) M^T (C H y - z).

Thus theta is uniquely determined. Conversely, if rank(M) < q, take a nonzero v in ker(M). For any compatible pair (B, theta), the distinct parameter pair

    B' = B - T v,    theta' = theta + v

produces exactly the same y and z: its mixture is unchanged and C B' = C B. Consequently every attainable observation has nonunique theta. This proves necessity and sufficiency.

Full reconstruction of B is not required first. One recovers the mixed vector w, or just C w, and solves for theta from d. If desired, B is then recovered as B = w - T theta. Indeed, under these assumptions identifying theta also makes B identifiable, but that does not require estimating B separately beforehand.

For the specified designs, write y = (y1, y2, y3).

* C_bad T = [0, 0], of rank zero. Its response z = B1 - B2 = y1 - y2 is already determined by y. Neither theta coordinate is identified; every theta in R^2 is compatible with the same attainable observations after adjusting B.

* C_good T = I_2, of rank two. Writing its response as (z1, z2),

      theta1 = y1 - z1,    theta2 = y3 - z2.

  The optional baseline reconstruction is B = (z1, y2 - y1 + z1, z2).

Minimum additional calibration rows. Let r = rank(C T). The exact minimum is q - r. Appending s calibration rows can increase the rank of C T by at most s, proving the lower bound. For achievability, choose q - r row vectors d_i that extend a basis of the row space of C T to a basis of R^q. With the left inverse J = (T^T T)^(-1) T^T, define the new calibration rows c_i = d_i J. Then c_i T = d_i, so appending these rows gives rank q. This uses the permission to choose arbitrary calibration rows. Thus the bad design needs two additional rows and the good design needs none.

Put s = x^T y and n = ||x||^2. Expanding the squared loss gives

    L(alpha) = ||y||^2 - 2 alpha s + alpha^2 n,
    G(alpha) = L(0) - L(alpha) = 2 alpha s - alpha^2 n.

The fixed prediction b cancels from the residual. At the frozen alpha = 1/2,

    G(1/2) = s - n/4.

Hence negative frozen gain implies only s < n/4, not s <= 0. Strict negativity is impossible when x = 0. For x != 0, a positive alpha improves the loss exactly when

    s > 0 and 0 < alpha < 2s/n.

Thus some positive alpha improves the loss if and only if x^T y > 0. When s > 0, the optimum is alpha* = s/n, giving gain s^2/n. When s <= 0, no positive alpha improves the loss.

Counterexample: take scalar x = 1 and y = 0.1. Then x^T y = 0.1 > 0, L(0) = 0.01, and L(1/2) = 0.16, so the frozen gain is -0.15. Nevertheless alpha = 0.1 gives zero loss and gain 0.01. The frozen step overshoots despite the favorable direction.

TASK 1 — EXACT IDENTIFICATION

Let A^+ = (A^T A)^{-1} A^T. Because A has full column rank, the observed y determines
w = A^+ y = B + T theta.
Consequently
d = Cw - z = CT theta.

Thus theta is uniquely identified for every attainable observation if and only if
rank(CT) = q.
Equivalently, ker(CT) = {0}, or col(T) intersects ker(C) only at zero. The equivalence of the last condition uses the full column rank of T.

Necessity: Suppose CT v = 0 for a nonzero v in R^q. Given any compatible pair (B, theta), define
theta' = theta + v,    B' = B - Tv.
Then B' + T theta' = B + T theta and CB' = CB - CTv = CB. Both observations agree, although theta' differs from theta. This ambiguity occurs for every attainable observation, not merely for one exceptional value.

Sufficiency and reconstruction: If M = CT has rank q, its left inverse M^+ = (M^T M)^{-1} M^T gives
theta = M^+(CA^+ y - z).
Every compatible parameter pair must obey this equation, proving uniqueness. If desired, recover
B = A^+ y - T theta.
Full reconstruction of B is not required first: recover the composite w, then use the calibrated contrasts to identify theta directly. Indeed, under the stated assumptions, unique identification of theta also implies unique identification of B. Conversely, a nonzero theta ambiguity changes B because T is injective.

For the specified designs, write theta = (theta_1, theta_2). Since A = I_3,
y = (B_1 + theta_1, B_2 + theta_1, B_3 + theta_2).

For C_bad = [1, -1, 0],
C_bad T = [0, 0].
The calibration merely reports z = B_1 - B_2 = y_1 - y_2. It identifies neither component of theta; every theta remains possible after adjusting B.

For C_good with rows [1, 0, 0] and [0, 0, 1],
C_good T = I_2.
Writing its observation as z = (z_1, z_2), reconstruction is
theta_1 = y_1 - z_1,    theta_2 = y_3 - z_2,
and
B = (z_1, y_2 - y_1 + z_1, z_2).

Minimum additional calibration rows: Let r = rank(CT). The exact minimum is q - r. Appending s rows to C appends only s rows to CT, increasing its rank by at most s; therefore s >= q - r is necessary.

For attainability, choose q - r row vectors u_j that extend a basis of the row space of CT to a basis of R^q. For each such row, set
c_j = u_j (T^T T)^{-1} T^T.
Then c_j T = u_j. Appending these c_j to C makes the product with T have rank q. This uses precisely q - r rows and proves sufficiency. In particular, C_bad needs two additional rows and C_good needs none. The relevant deficit is q - rank(CT), rather than the rank deficit of C in the whole nuisance space.

TASK 2 — FIXED TRANSFER SIZE AND POINT LOSS

Set p = <x, y> and s = ||x||^2. Expanding the squared norm yields the exact gain
G(alpha) = L(0) - L(alpha) = 2 alpha p - alpha^2 s.
Hence
G(1/2) = p - s/4.
A negative half-transfer gain says precisely p < s/4. It does not require p <= 0.

If x is nonzero, then s > 0, and for positive alpha,
G(alpha) > 0 if and only if p > 0 and 0 < alpha < 2p/s.
Thus some positive transfer improves the point loss exactly when the inner product is positive. The unconstrained minimizer is alpha_* = p/s; over alpha >= 0 the minimizer is max(0, p/s). If x = 0, all gains vanish, so a strictly negative half-transfer gain is impossible.

Numerical counterexample: Take scalar b = 0, x = 1, y = 1/8. Then p = 1/8 > 0, but
L(0) = 1/64,    L(1/2) = 9/64,
so G(1/2) = -1/8 < 0.
Nevertheless alpha = 1/8 gives L(alpha) = 0 and strictly improves the point loss.

Observing y permits a descriptive, target-dependent optimization of this particular loss. It does not turn the failed frozen alpha = 1/2 comparison into a successful frozen test, nor establish performance on an unseen target. A coefficient selected using the scored target is fitted to that target; an honest predictive evaluation must account for this selection or evaluate it on independent held-out data. The negative fixed-size result alone does not show that a beneficial positive coefficient exists either, because p could be nonpositive.

These equations rely on the stipulated absence of clipping and on fixed b. They do not directly describe a clipped prediction rule.

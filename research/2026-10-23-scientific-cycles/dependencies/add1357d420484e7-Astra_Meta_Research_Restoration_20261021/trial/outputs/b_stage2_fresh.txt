Let A have p rows and C have m rows. Define

N = [A; C],    D = [AT; 0],    M = [N D] = [[A, AT], [C, 0]].

The necessary and sufficient condition for unique identification of theta is

rank(M) - rank(N) = q.

Here identification means that any two parameter pairs with identical observations must have identical theta; B itself need not be identifiable.

Proof. Differences of observationally equivalent pairs satisfy

N delta_B + D delta_theta = 0.

Thus theta is identifiable exactly when D delta_theta belongs to the column space of N only for delta_theta = 0. Equivalently, the q columns of D are linearly independent modulo that column space. Their contribution to the rank of [N D] must therefore be q, which proves the criterion. This uses no full-column-rank assumption on A.

An equivalent block-rank condition is

rank([[A, 0], [C, CT]]) = rank([A; C]) + q.

Indeed, the invertible parameter change X = B + T theta gives observations (AX, CX - CT theta); reversing the sign of the final block of columns does not change rank.

     [1, 0, 0, 0, 0],

rank(M) = 4.

For fixed Q, write S = (Qr_1)^T(Qr_2). Because Q is an orthogonal projector, Q^T Q = Q. Expanding r_1^T Qr_2, all error terms except the shared-error quadratic term have zero expectation by independence and zero means. Consequently,

E[S] = theta_1^T Q theta_2 + E[c^T Qc]
     = (Qtheta_1)^T(Qtheta_2) + tr(Q Sigma).

Thus S - tr(Q Sigma) is unbiased for the stated target when Q is fixed.

When Q = Q(c), conditioning on c instead gives

E[S | c] = (theta_1 + c)^T Q(c)(theta_2 + c).

The e errors still average to zero because they are independent of c. The terms involving c do not generally average as though Q were fixed independently of c.

More explicitly, let mu_Q = E[c | Q] and K_Q = E[cc^T | Q]. Then

E[S | Q] = theta_1^T Q theta_2
           + theta_1^T Q mu_Q + mu_Q^T Q theta_2
           + tr(Q K_Q).

Subtracting tr(Q Sigma) need not remove the conditional bias: mu_Q need not vanish and K_Q need not equal Sigma. Unconditionally, one must average this entire expression over Q. Because the target itself is random, conditional unbiasedness means E[corrected S | Q] equals theta_1^T Q theta_2; the weaker unconditional equality compares E[corrected S] with E[theta_1^T Q theta_2]. Neither is guaranteed.

For the requested counterexample, c is standard normal in R^2, all theta and e vectors vanish, and

Q = I_2 - cc^T / ||c||^2.

This is an orthogonal projector of rank one with Qc = 0 almost surely. Define Q arbitrarily on the null event c = 0. Since r_1 = r_2 = c,

S = 0,    (Qtheta_1)^T(Qtheta_2) = 0,
tr(Q Sigma) = tr(Q) = 1

almost surely. The proposed corrected estimator is therefore identically -1. Its expectation is -1 both unconditionally and conditionally on Q (or on c), whereas the target is zero.

For additional conditional detail, normal radial symmetry gives mu_Q = 0 and K_Q = 2(I_2 - Q): Q determines the unoriented line of c, and the independent squared radius has mean 2. Hence tr(Q K_Q) = 0, consistently with E[S | Q] = 0. The marginal covariance Sigma = I_2 cannot replace this conditional second moment. Independence from the data used to learn Q, or an appropriate conditional calculation, is needed to justify such a correction.

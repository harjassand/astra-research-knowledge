Changed assumption: A may be rank deficient, so y need not determine the mixture B + T theta. The previous rank(C T) condition alone is therefore insufficient.

Define the nuisance and signal observation matrices

    K = [A; C],    D = [A T; 0],    F = [K D] = [[A, A T], [C, 0]].

Here semicolons denote vertical stacking. The necessary and sufficient condition is

    rank(F) - rank(K) = q.

Proof. The stacked observation o = [y; z] satisfies o = K B + D theta. Two parameter pairs yield identical observations exactly when

    K DeltaB + D Deltatheta = 0.

Theta is uniquely identified precisely when this equation forces Deltatheta = 0. Equivalently, the map v -> D v modulo the column space of K must be injective. Its rank is rank([K D]) - rank(K), so injectivity is exactly the displayed condition. If the condition fails, some v != 0 has D v = K u; the perturbation DeltaB = -u, Deltatheta = v leaves all observations unchanged. Thus failure gives nonuniqueness for every attainable observation.

For an explicit reconstruction, let P be the orthogonal projector onto the orthogonal complement of the column space of K. Then P o = P D theta and rank(P D) = rank(F) - rank(K). When the condition holds,

    theta = (D^T P D)^(-1) D^T P o.

This uses no full-column-rank assumption on A and does not require identifying B first.

In the specified example,

    A T = [[2, 0], [0, 1]],    C T = I_2.

The actual observations are

    y1 = B1 + B2 + 2 theta1,    y2 = B3 + theta2,
    z1 = B1,                  z2 = B3.

Here rank(K) = 3 and rank(F) = 4, so the rank difference is 1 < q = 2. Theta2 = y2 - z2 is identified, while theta1 remains confounded with B2. Thus full column rank of C T does not suffice.

For a concrete collision, take

    B = (0, 0, 0),      theta = (0, 0),
    B' = (0, -2, 0),    theta' = (1, 0).

The first mixture is zero and the second is (1, -1, 0), which lies in ker(A). Both baseline vectors have C B = 0. Hence both pairs yield y = 0 and z = 0 despite distinct theta.

TASK 4

For a fixed orthogonal projector, Q^T Q = Q. Independence and zero error means eliminate every cross term except the shared-c term:

    E[(Q r1)^T(Q r2)]
      = theta1^T Q theta2 + E[c^T Q c]
      = (Q theta1)^T(Q theta2) + tr(Q Sigma).

Thus subtracting tr(Q Sigma) is unbiased for the stated target when Q is fixed.

Changed assumption: when Q is learned from c, Q and c are generally dependent. The identity E[c^T Q c] = tr(Q Sigma) cannot be applied as though Q were fixed independently of c. Moreover, mean-zero c need not have mean zero conditional on Q.

To be precise, let Q be a measurable function of c, put

    mu_Q = E[c | Q],    M_Q = E[c c^T | Q],
    S(Q) = theta1^T Q theta2.

The e_i remain independent of Q and c, with zero conditional means. Consequently,

    E[(Q r1)^T(Q r2) | Q]
      = S(Q) + theta1^T Q mu_Q + mu_Q^T Q theta2 + tr(Q M_Q).

Here M_Q = Cov(c | Q) + mu_Q mu_Q^T. Subtracting tr(Q Sigma) is conditionally unbiased for S(Q) only if the remaining conditional bias vanishes. Unconditional unbiasedness instead asks whether the expectation of that bias is zero, equivalently whether the corrected statistic has expectation E[S(Q)]. It need not hold even if c has unconditional mean zero and covariance Sigma.

In the requested example, c ~ N(0, I_2), all theta_i and e_i are zero, and almost surely

    Q = I_2 - c c^T / ||c||^2.

This is a rank-one orthogonal projector satisfying Q c = 0. Therefore the observed product and the target are both identically zero, whereas

    tr(Q Sigma) = tr(Q) = 1.

The proposed corrected statistic is identically -1. Its conditional expectation given Q and its unconditional expectation are both -1, while the corresponding target is zero. The correction therefore fails in both senses.

The conditional structure explains why: rotational symmetry and independence of Gaussian radius and direction give

    E[c | Q] = 0,    E[c c^T | Q] = 2(I_2 - Q).

Thus the actual conditional shared-error contribution is tr(2 Q(I_2 - Q)) = 0, not tr(Q I_2) = 1. Averaging conditional expectations also gives the unconditional product expectation zero. Learning Q from the same error changes the relevant conditional second moment.

## Reproduce the selected evidence

From this directory, with assertions enabled:

```sh
python3 -B verify.py
python3 -B verify.py --replay exact --receipt /tmp/astra-math-exact.json
python3 -B verify.py --replay all --receipt /tmp/astra-math-all.json
```

The first command checks the selected file manifest, byte-copy provenance and local Markdown links. `exact` runs six standard-library-only checks: independent kinetic algebra/rank and Jacobian bounds, independent scalar interval arithmetic, and the two original scalar certificates plus the original Decimal scalar check. `all` additionally runs the selected SymPy/mpmath algebra and NumPy diagnostics, including the original kinetic programs. **Every execution happens in a temporary copy**, so retained source/receipt bytes are not overwritten. Receipts use new, exclusive output paths.

Python 3.12 or newer is the target; the publication replay environment and exact installed versions are recorded in [REPLAY.json](REPLAY.json). `exact` uses only the Python standard library. `all` also needs existing SymPy, mpmath and NumPy; no dependency is silently installed. Do not use Python `-O`, which disables the source assertions. Missing optional dependencies are reported as a failure of that reproduction environment, not a scientific refutation. The optional original SciPy matrix branch is not run. The unchanged original `sources/pro/entropy_bound/verify.py` also requires SciPy; its archived `verification.json` is source-reported, and no new execution of that optional diagnostic is claimed. Numerical matrix residuals, random tests and Decimal diagnostics remain explicitly uncertified.

The original audit initially hid an existing user-site SymPy installation with `-I`; the corrected source replay used `-E -B`, with no installation. The archive's separate 70-digit Decimal diagnostic has no identified dedicated reproducer; it is retained as an explicitly noncertifying diagnostic. The current exact certificates and 80-digit scalar replay are reproducible.

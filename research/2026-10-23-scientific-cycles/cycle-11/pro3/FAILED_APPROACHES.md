# Failures and scope changes that affected Cycle11

## A deterministic progress coordinate was an unnecessary premise

The old missing reduction asked for a scalar remaining-progress state
coordinate for arbitrary reciprocal native geometry. Proposal cycles may
have nonzero circulation in log(q_x Q_xy/(q_y Q_yx)), so such increments
need not telescope to a state function. Treating them as a deterministic
geometric coordinate is unjustified.

The new proof retains cumulative PATH progress and reverses labelled
proposal products. The new exact diagnostic has cycle product 8 and
reverse product 1/8, so it explicitly exercises this distinction.
No claim that every reciprocal graph is a forward tree is needed.

## Mixtures of separate trees did not establish a general obstruction

A convex mixture of disjoint old tree families cannot improve their
best source-weighted phase value. Fixed positive source fractions shift
eta log(source mass) only by o(1). This observation was too narrow:
it did not cover shared terminal unions, very small source strata,
merging or cycles. It was not accepted as the arbitrary-geometry proof.

The native tagged-path theorem supplies the missing shared q-mass
accounting. A heterogeneous counterexample filling a trough was not found;
the complete finite bound now excludes it at the stated asymptotic scale.

## A fixed accepted-jump bound did not justify SUM becoming MAX

The separate contribution NATIVE_COMPOSITION.md proves an exact killed-local
race norm and a fixed-J landing bound on arbitrary reciprocal graphs.
Its successful operation integrates real local holds before conjugation.
It is retained as a valid bounded result.

Applying that bound with the full source mass at every crossing count gives
a SUM of bounds. First-hit events are disjoint in the forward law, but the
reverse path measures are not automatically disjoint across J. Replacing
SUM by MAX would reuse the source/boundary budget without proof.
Within-A global moves also cannot simply be deleted from that embedded
local race. These premises prevented it from closing the full phase law.

The successful path partition handles all crossing counts together and
keeps global state changes as history-dependent zero-progress transitions.
The fixed-J result is not an unacknowledged premise of the final theorem.

## The reverse reference is not a Markov kernel

Removing off-diagonal acceptance factors while retaining the real diagonal
can produce row sums above one. Renormalizing these rows would change the
path weights and invalidate the claimed exact relation. The new proof pays
the bound (3/2)^N explicitly. It chooses the threshold only after this entire
growth is included. The diagnostic has actual reference row sums above one.

## Direct global hits and local returns cannot be omitted

A global jump has zero proposal likelihood progress. A high-progress path
ending globally must have completed its threshold earlier; other global
hits belong to the paid low-progress term. The new frozen diagnostic
includes 640 high-progress paths ending globally and checks this event
containment exactly.

The first-hit estimate is inserted into the original full-return
decomposition. No absorbed kernel is used after a hit, and no return,
global attempt or actual rejection is removed from the original law.

## Domain convention clarified during review

The first principal draft wrote proposal ratios under "for x!=y" without
explicitly restating their restriction to Q_xy>0. The reviewer requested
the present-edge convention and L_xy=0 on absent edges. That sentence
was added before final binding. No inequality, theorem or construction
required mathematical repair.

M(U) is 1-Lipschitz only on U>0. Its immediate-completion extension jumps
at zero; the principal explicitly states this and uses thresholds tending
to infinity. A global Lipschitz assertion across zero was not made.

## Historical failures remain unchanged

The original 32-state example is admitted. Frozen coalescence_native5462
fails its K=1 admission and remains an algebraic fixture only. It was not
retuned or rerun. The evaluator's altered subset query was not replayed.
The old two-state precision result changes the oracle contract and was not
made into a new arithmetic campaign. The B3 pISO correction, failed full
halo inference and closed R3/anMC consumer remain preserved in the source
chain. No retired or separately owned programme was reopened.

## Remaining boundary

The finite critical phase question is closed internally. The selected
next problem concerns general state spaces and intrinsic reciprocal flow,
with real access requirements and an atomless sharpness obligation.
Finite matrix sums do not alone prove measurable disintegration or
provide an atomless sampler. This is an explicit continuation, not a
claim already established by Cycle11.

\begin{abstract}
For the actual root-retaining qutrit interaction with one evolving infinite
bath, every finite input density satisfies the whole-bath operator inequality
\[
D_b(\rho)\ge
2\{S_2(\rho)-k\log_2[2\sqrt2(1-b)+3b]\}I,\qquad b=\beta^2.
\]
The result allows arbitrary correlations among all input calls and requires
neither charge preservation nor a finite initial bath entropy or mean depth.
Initial input--bath independence is essential. A tilted completely positive
map, logarithmic compression and the Golden--Thompson inequality retain the
physical root and every coherent history.

The bound settles the small-angle entropy-gain order in the full
inward-drift input class, uniformly over all block lengths. More strongly,
it gives a finite-error depth-expenditure inequality for arbitrary
unassisted fixed-call quantum codes. The completed quadratic-rate code
is shown to have logarithmic final mean depth at the actual initializer.
Consequently communication with sublinear mean-depth cost has excess
capacity of order \(\Theta(\beta^2)\).

This is a resource-constrained capacity law and an unrestricted
rate--depth tradeoff, not an unrestricted capacity or feedback converse.
A pure-input example has linear depth growth but only logarithmic bath
entropy, preventing that invalid extension. The stronger
\(O((bk)^2)\) prefix-pressure target remains open; the new all-length
operational conclusion does not require it.
\end{abstract}

\section{A reusable entropy--displacement interface}

We first isolate the operation that makes the all-length statement
possible. This is a finite-port, possibly infinite-memory result.

\begin{theorem}[Tilted transfer bound]\label{thm:general}
Let a finite-dimensional port with Hermitian observable \(q\) interact
unitarily with one memory \(E\) by \(V\), repeated \(k\) times.
Let \(Q_k=\sum_iq_i\) and \(G_k=Q_k-W_k^*Q_kW_k\).
Fix \(\lambda>0\) and define the normal completely positive map
\[
 \Psi_\lambda(X)=
 \Tr_A[(e^{-\lambda q}\otimes I)V^*(e^{\lambda q}\otimes X)V].
\]
If \(\Psi_\lambda(I)\le f_\lambda I\), then for every input density
\(\rho\) and every normal memory density \(\tau\), initially independent,
\begin{equation}\label{eq:generalentropy}
 S_2(\rho)\le k\log_2 f_\lambda+
 \frac{\lambda}{\ell}\Tr[(\rho\otimes\tau)G_k].
\end{equation}
Equivalently, the full memory operator obeys
\begin{equation}\label{eq:generaloperator}
 D(\rho)\ge\frac{\ell}{\lambda}
       [S_2(\rho)-k\log_2 f_\lambda]I_E.
\end{equation}
Correlations across the input calls and within the memory are unrestricted.
No finite entropy or moment of \(\tau\) is assumed.
\end{theorem}

The tilted map is an analytic comparison, not a physical intervention.
It need not be trace preserving or unital. Independence is only between
the entire initial input and the initial memory, not between input calls.

\begin{proof}
Purify \(\tau\) into a vector \(\ket{\Omega_\tau}\) on \(E\otimes E'\).
The untouched factor \(E'\) is only a mathematical dilation. Define an
isometry from the finite input space by
\[
 Bv=(W_k\otimes I_{E'})(v\otimes\ket{\Omega_\tau}),\quad
 M=B^*Q_{\rm out}B,\quad D_\tau=Q_{\rm in}-M.
\]
For coherent memory states, \(M\) and \(Q_{\rm in}\) need not commute.
All three compressed operators are finite-dimensional and bounded.

For the strictly positive bounded operator
\(T=e^{\lambda Q_{\rm out}}\otimes I_{EE'}\), logarithmic compression gives
\begin{equation}\label{eq:logcompression}
 \lambda M=B^*(\log T)B\le\log(B^*TB).
\end{equation}
For completeness, the compression inverse inequality
\[
 (B^*TB+sI)^{-1}\le B^*(T+sI)^{-1}B,\qquad s>0,
\]
follows from the Schur complement, or from minimizing the positive
quadratic form after decomposing into \(\operatorname{ran}B\) and its
orthogonal complement. Integrating it against the identity
\[
 \log T=\int_0^\infty
 [(1+s)^{-1}I-(T+sI)^{-1}]\,ds
\]
proves \eqref{eq:logcompression}. Bounded positive lower and upper spectral
bounds justify the integral in operator norm. This is the logarithmic
case of operator Jensen \cite{HP}. Exponential is not being treated as
an operator-convex or operator-monotone function.

Trace exponential is monotone on finite-dimensional Hermitian matrices:
Loewner order implies eigenvalue order and hence order of the sums of
their scalar exponentials. With \(C=B^*TB>0\), the finite-dimensional
Golden--Thompson inequality \cite{Golden,Thompson} therefore gives
\begin{align}
 \Tr e^{-\lambda D_\tau}
 &\le\Tr e^{-\lambda Q_{\rm in}+\log C}\notag\\
 &\le\Tr(e^{-\lambda Q_{\rm in}}C)\notag\\
 &=\Tr\tau\,\Psi_\lambda^k(I)
 \le f_\lambda^k. \label{eq:partition}
\end{align}
Only the port trace in this display is finite-dimensional; no trace of
the bath identity is taken.

To verify the sequential identity, diagonalize \(q\), and put
\(K_{oi}=\bra oV\ket i\). Then
\[
 \Psi_\lambda(X)=
 \sum_{i,o}e^{\lambda(q_o-q_i)}K_{oi}^*XK_{oi}.
\]
The ordered \(k\)-call matrix element is
\(K_{o_ki_k}\cdots K_{o_1i_1}\). Summing the weighted squared products
is exactly \(\Psi_\lambda^k(I)\), so no fresh-memory factorization has
been made. Positivity and \(\Psi_\lambda(I)\le f_\lambda I\) prove its
envelope by induction.

Relative entropy against the faithful finite input density
\(e^{-\lambda D_\tau}/\Tr e^{-\lambda D_\tau}\) is nonnegative. Hence
\[
 \ell S_2(\rho)\le
 \lambda\Tr(\rho D_\tau)+\ln\Tr e^{-\lambda D_\tau}.
\]
Equation \eqref{eq:partition} proves \eqref{eq:generalentropy}.
Finally every normal vector state is an allowed \(\tau\).
The scalar inequalities for all such states are precisely the bounded
operator inequality \eqref{eq:generaloperator}.
\end{proof}

Theorem~\ref{thm:general} is a reusable interface: a receiving device must
provide its actual tilted-map envelope, the initial product contract,
and the meaning of its conserved observable before interpreting \(G_k\)
as a physical resource. Section~\ref{sec:counterexamples} gives an actual
device counterexample when initial independence is omitted.

\section{Exact whole-bath evaluation and the all-length entropy law}

\begin{lemma}[Root-retaining tilted map]\label{lem:tilt}
For the actual qutrit device and every real \(\lambda\),
\begin{align}
 \Psi_\lambda(I)
 &=f_\lambda(b)I-a(e^\lambda-1)P_0,\label{eq:roottilt}\\
 f_\lambda(b)&=3b+a(e^\lambda+2e^{-\lambda}).\notag
\end{align}
Thus \(\Psi_\lambda(I)\le f_\lambda I\) for \(\lambda\ge0\).
\end{lemma}
\begin{proof}
For input zero the bath Kraus operators are
\(\sqrt a R+i\sqrt b I,\sqrt a S_1^*,\sqrt a S_2^*\).
Their output-charge weighted squared sum is
\[
 bI+aP_0+ae^\lambda(I-P_0).
\]
The cross terms in the first square cancel because \(R=R^*\).
For each colored input the two nonzero bath Kraus operators are
\(\sqrt a S_j\) and \(i\sqrt b I\), giving the weighted input--output
contribution \(ae^{-\lambda}I+bI\).
Adding the three input columns proves \eqref{eq:roottilt}.
\end{proof}

\begin{theorem}[Entropy forces uniform outward displacement]
\label{thm:entropyoperator}
For every \(0\le b\le1\), every \(k\ge1\), and every density \(\rho\)
on the \(k\) qutrit inputs,
\begin{equation}\label{eq:mainoperator}
 \boxed{D_b(\rho)\ge2[S_2(\rho)-k c(b)]I_E,\qquad
 c(b)=\log_2[2\sqrt2(1-b)+3b].}
\end{equation}
The actual root is included. There is no charge-preservation hypothesis.
In particular a single nonpositive expectation
\(\Tr[\tau D_b(\rho)]\le0\) in any normal independent initializer implies
\(S_2(\rho)/k\le c(b)\).
\end{theorem}
\begin{proof}
Apply Theorem~\ref{thm:general} and Lemma~\ref{lem:tilt} at
\(\lambda_*=\ell/2\). This minimizes the scalar envelope
\(f_\lambda\) for \(\lambda\ge0\) when \(a>0\), because
\(e^{\lambda_*}=\sqrt2\). At \(a=0\), the envelope is constantly \(3\).
The displayed consequence follows by taking a normal expectation.
\end{proof}

Let \(d_*:=3/(2\sqrt2)-1>0\). The exact ceiling is
\begin{equation}\label{eq:csmall}
 c(b)=\frac32+\log_2(1+d_*b)
 =\frac32+\frac{d_*}{\ell}b+O(b^2).
\end{equation}
This statement is uniform over all \(k\), including lengths far beyond
every previous controlled temporal window. It is not a statement only
about product, pair, or charge-preserving inputs.

\section{Finite-error quantum communication and charged bath depth}

Consider an arbitrary deterministic fixed-\(N\) unassisted code, with a
CPTP encoder from a \(K\)-dimensional logical system to \(N\) qutrit
inputs, and a CPTP decoder on the emitted outputs. The encoder may use
local retained systems, but supplies no system correlated initially
with the bath and has no receiver-to-sender feedback. Such a protocol
can be represented by one correlated input state on all \(N\) slots.
Receiver processing may be deferred to the decoder.

Let \(\rho_N\) denote the physical input when the logical system is
maximally mixed. Let the full-diamond error from the logical identity
be at most \(\epsilon_N\le1\). Its half-diamond value is
\(\epsilon_N/2\).

\begin{lemma}[Reliable transmission requires input entropy]
\label{lem:codeentropy}
For the above code,
\[
 S_2(\rho_N)\ge
 (1-\epsilon_N)\log_2K-h_2(\epsilon_N/2).
\]
\end{lemma}
\begin{proof}
Use half of a maximally entangled logical state, with untouched reference
\(R\), as input. The decoded state \(\omega_{R\widehat R}\) has half
trace distance at most \(\delta_e=\epsilon_N/2\) from that pure state.
Its overlap is at least \(1-\delta_e\). Pinching into the target ray
and its orthogonal complement increases entropy, whence, for
\(\delta_e\le1/2\),
\[
 S_2(R\widehat R)\le
 h_2(\delta_e)+\delta_e\log_2(K^2-1)
 \le h_2(\delta_e)+2\delta_e\log_2K.
\]
The case \(K=1\) is trivial. The reference marginal is exactly uniform.
Araki--Lieb gives
\[
 I(R:\widehat R)\ge2\log_2K-2S_2(R\widehat R).
\]
Because the bath is initially independent and there is no feedback,
data processing and \(I(R:A^N)\le2S_2(A^N)\) give
\(I(R:\widehat R)\le2S_2(\rho_N)\).
Combining these statements proves the lemma. It allows a general CPTP
encoder; no isometric-encoder assumption is hidden in the upper bound.
\end{proof}

\begin{theorem}[Rate--depth expenditure]\label{thm:codecost}
Every such code obeys the whole-bath inequality
\begin{equation}\label{eq:codeoperator}
 D_b(\rho_N)\ge
 2[(1-\epsilon_N)\log_2K-h_2(\epsilon_N/2)-Nc(b)]I_E.
\end{equation}
For a bath initializer with finite mean depth, and in particular
\(\tau_\pi\), this implies
\begin{align}
 (1-\epsilon_N)\frac{\log_2K}{N}
 &\le c(b)+\frac{\E L_{\rm final}-\E L_{\rm initial}}{2N}
      +\frac{h_2(\epsilon_N/2)}N. \label{eq:finiteratecost}
\end{align}
For reliable rate \(R\), a rate exceeding \(c(b)\) requires asymptotic
mean-depth expenditure at least \(2(R-c(b))\) per forward call.
\end{theorem}
\begin{proof}
Combine Lemma~\ref{lem:codeentropy} and
Theorem~\ref{thm:entropyoperator} with \(k=N\).
Conservation gives the quadratic-form inequalities
\[
 L-NI\le W_N^*LW_N\le L+NI.
\]
They follow first on the finite-coordinate core and then by positive
form approximation. Thus finite initial mean gives finite final mean
and the bounded displacement expectation equals their difference.
For an infinite-mean normal initializer, \eqref{eq:codeoperator}
remains valid; \eqref{eq:finiteratecost} is not written as an undefined
infinity minus infinity.
\end{proof}

The full-error and half-error conventions are not interchangeable:
if the error is reported as half diamond \(\delta_e\), the first factor
in \eqref{eq:finiteratecost} is \(1-2\delta_e\), and the entropy term is
\(h_2(\delta_e)\).

The general tilt gives the stronger envelope, whenever a reliable code
has \(\limsup_{N\to\infty}(\E L_{\rm final}-\E L_{\rm initial})/N
\le v\) for \(v\ge0\),
\begin{equation}\label{eq:costcurve}
 R\le C_b(v):=\inf_{\lambda\ge0}
 \left\{\log_2[3b+a(e^\lambda+2e^{-\lambda})]
             +\frac{\lambda v}{\ell}\right\}.
\end{equation}
This is an upper envelope, not an asserted achievable tradeoff.
At \(v=0\) it is exactly \(c(b)\).
For \(0\le v<a/3\) and \(a>0\), its minimizing \(z=e^\lambda\) is
\[
 z=\frac{\sqrt{9b^2v^2+8a^2(1-v^2)}-3bv}{2a(1+v)}.
\]
For \(v\ge a/3\), the minimum is the port-dimension bound \(\log_2 3\)
at \(\lambda=0\). Differentiation of the strictly convex
log-sum-exponential verifies these statements. At \(b=0\),
\(C_0(v)=h_2((1+v)/2)+(1+v)/2\) for \(0\le v\le1/3\),
recovering the ordinary diagonal charge-entropy comparator.

\begin{definition}[Sublinear-depth communication]
Let \(\Qcap_{\rm sub}(\beta,\tau_\pi)\) be the supremum of reliable
unassisted rates for the unchanged fixed device and actual initializer,
in full diamond norm, with final mean bath depth \(o(N)\) on the encoded
maximally mixed logical input. All \(N\) forward slots count.
The code sequence is chosen independently of the initializer, with
pointwise reliability for every fixed normal initializer; the additional
depth budget is evaluated at \(\tau_\pi\). The upper bound below even
allows a code chosen solely for \(\tau_\pi\).
This is an explicitly additional resource constraint on the original
operation, not a redefinition of its unrestricted capacity.
It constrains final mean depth only. It is neither a bound on the largest
intermediate depth nor a promise to return the bath state to \(\tau_\pi\).
\end{definition}

\begin{theorem}[Sharp small-angle order for this resource-constrained capacity]
\label{thm:sublinear}

\begin{equation}\label{eq:sublinearcapacity}

 \ \le\ \Qcap_{\rm sub}(\beta,\tau_\pi)

\section{The original prefix-pressure question and failed comparisons}

For this paragraph, let \(\mathcal G_k(b)\) be the bulk restriction of
\(G_k\), pinched by total input charge. It acts on the finite first
\(k\) bath colors; a prefix density \(\zeta\) is analytically realized
at a fixed depth at least \(k\), with any fixed seed. No such prefix
is physically supplied by the communication protocol.
The initial question concerned
\[
 K_\zeta=\Tr_F[(I\otimes\zeta)
       (\mathcal G_k(b)-a(2Q_k-kI)\otimes I)]
\]
and a bound on
\(\ln\Tr\sigma e^{-\ell K_\zeta/(2a)}\) of order \((bk)^2\).
Only one usable analytic prefix would have sufficed for its proposed
inward-drift entropy upper. We did not impose all-prefix uniformity as
an additional premise.

There is now a genuine full exponential-moment estimate, albeit of a
different sufficient scale:
\begin{equation}\label{eq:bulkmoment}
 \Tr\sigma e^{-tK_\zeta}
 \le[a\cosh(tb)+b\cosh(ta)]^k,\qquad t\in\mathbb R.
\end{equation}
It holds for every prefix density, including coherent and entangled ones.
This stronger prefix quantifier is a consequence of the proof, not an
assumed requirement or a physically prepared state.

Here is a direct derivation. Realize the prefix at a fixed initial depth
\(h\ge k\), purify it, and use the isometry \(B\) above.
Then \(M=B^*Q_{\rm out}B\) commutes with \(Q_k\) by total-charge
conservation. In each total-charge sector, scalar Jensen applied to
eigenvectors of the compressed \(M\) bounds
\(\Tr e^{tM}\) by \(\Tr B^*e^{tQ_{\rm out}}B\).
For a computational input charge word \(x\), distinct stay masks have
distinct output charge words. Their diagonal expectation of
\(e^{tQ_{\rm out}}\), after the coherent word is retained, is exactly
\[
 (b+ae^t)^{k-|x|}(a+be^t)^{|x|}.
\]
The word's reference weight is \(2^{-k-|x|}\); its color fiber has
dimension \(2^{|x|}\). Summing over all binary words, including the
factor \(e^{-t[(2b-1)|x|+ak]}\), gives
\[
 2^{-k}e^{-tak}
 [b+ae^t+e^{t(1-2b)}(a+be^t)]^k
 =[a\cosh(tb)+b\cosh(ta)]^k.
\]
This does not replace coherent dynamics by a classical noise model.
It is a trace estimate after actual charge selection.

For fixed \(t\), the logarithm of the envelope is
\[
 bk(\cosh t-1)+O(kb^2).
\]
It is not a proof of \(O((bk)^2)\) uniformly as \(bk\downarrow0\).
That stronger pressure question remains open. The new all-\(k\)
entropy and operational resource laws already settle the attainable
small-angle order under sublinear depth cost, so improving this pressure
bound is no longer the chosen next bottleneck.

Two failed routes changed that choice:
\begin{itemize}
\item The exact absolute block-moment comparison is valid, but its
positive Johnson-matrix majorant has a distance-four Perron eigenvalue
of order \(r^2k^2\), for \(b=r/k\). Its pressure diverges.
The pair-only comparator does have a finite all-length pressure bound;
discarding the actual higher-endpoint terms would be invalid.
\item Even adding the correct conditional second moment, the physical

repair a block-data-only argument. The explicit abstract rare-sector
example in the contribution below passes those conditions but has

\end{itemize}
The new tilted-map proof uses an exact physical property absent from
these fake responses: the whole coherent ordered word and its one-call
positive transfer envelope. No actual-device counterexample to the
stronger pressure target has been claimed.

\section{Counterexamples fixing the scientific boundary}
\label{sec:counterexamples}

\subsection{Initial input--bath independence is necessary}

Take \(k=1\), \(0<\beta\le1/32\), \(\alpha=\sqrt{1-\beta^2}\),
\(\delta=\beta/(8\alpha)\), and \(g=1/8\).
For each \(j=1,2\), on the orthogonal edge pair
\(\ket0\ket j_E,\ket j\ket{\mathrm{vac}}_E\), put the joint density block
\[
 \begin{pmatrix}1/4-\delta/2&ig\\-ig&1/4+\delta/2\end{pmatrix}.
\]
The two blocks have total trace one and are strictly positive:
their eigenvalues are \(1/4\pm\sqrt{g^2+\delta^2/4}\).
The input marginal has charge \(p=1/2+\delta\) and entropy
\(h_2(p)+p\).
For this range \(\delta<1/128\),
\(1-h_2(1/2+\delta)\le4\delta^2\le\delta/2\).
For example the first inequality follows by bounding the magnitude of
the binary-entropy second derivative on \([3/8,5/8]\).
Hence
\[
 S_2(\rho_A)-3/2\ge\delta/2\ge\beta/16.
\]
On each edge \(U\) is the swap. Direct calculation gives joint drift
\[
 \Tr(\rho_{AE}G_1)=2a\delta-4g\alpha\beta
 =-\alpha\beta/4<0.
\]
But \(c(b)-3/2\le d_*b/\ell<b/8<\beta/16\).
Thus applying Theorem~\ref{thm:entropyoperator} to this initially
correlated state would be false. Such correlations are not available
in the admitted communication operation.

\subsection{Negative tilt cannot discard the root term}

At \(b=0,k=1\), from vacuum the compressed displacement is \(D=q\).
For \(\lambda<0\),
\[
 \Tr e^{-\lambda D}=1+2e^{-\lambda}
 >e^\lambda+2e^{-\lambda}=f_\lambda(0).
\]
Equation \eqref{eq:roottilt} remains exact, but its scalar upper envelope
requires \(\lambda\ge0\). The bulk all-real-\(t\) statement
\eqref{eq:bulkmoment} has a different scope and is not a root identity.

\subsection{Linear depth does not imply extensive bath entropy}
\label{sec:purepush}

At any fixed \(0\le b<1\), use the pure input \(\ket1^{\otimes N}\)
and the actual initializer \(\tau_\pi\). Every call has bath Kraus
operators \(\sqrt a S_1\) and \(i\sqrt b I\), with orthogonal emitted
output symbols. Consequently the exact bath state is
\begin{equation}\label{eq:purepush}
 \tau_{E,N}=\sum_{j=0}^N\binom Nj a^j b^{N-j}
                   S_1^j\tau_\pi S_1^{*j}.
\end{equation}
No path reaches a problematic boundary; \(S_1\) is an actual isometry
on the root-retaining bath. It raises depth by one, so
\[
 \E L_N=\tfrac12+aN.
\]
Each branch has entropy \(S_2(\tau_\pi)\). The standard entropy bound
for a finite mixture therefore gives
\[
 S_2(\tau_{E,N})
 \le S_2(\tau_\pi)+H(\operatorname{Bin}(N,a))
 \le S_2(\tau_\pi)+\log_2(N+1).
\]
At \(b=0\) the entropy is exactly constant. If the initial bath is
purified, the joint final bath/purifier entropy is at most
\(H(\operatorname{Bin}(N,a))\).
There is no logical reference information in this pure fixed input.

This is an actual same-device failure of the implication that
linear outward depth forces linear complementary entropy.
It does not exhibit high-rate reliable transmission. A converse for
unrestricted capacity needs a reference-aware argument that also uses
the entropy or dimension of the transmitted code.

\section{Comparison, costs, and the next owned scientific question}

The new theorem uses established finite-matrix tools: logarithmic
operator Jensen \cite{HP}, Golden--Thompson \cite{Golden,Thompson},
relative-entropy positivity and data processing.
The device-specific content is the exact tilted map with its signed
vacuum term, its iteration on one unchanged infinite bath, the uniform
operator entropy threshold, and the resulting quantum rate--depth
operation. No priority is claimed for those general inequalities.

Fluctuation-relation approaches already connect completely positive maps,
exponential moments and information bounds. Goold--Paternostro--Modi
\cite{GPM} give a heat bound for an erasure operation starting from a
product system and a thermal bath; Kafri--Deffner \cite{KD} derive a
measurement-dependent Holevo bound using a quantum fluctuation relation.
Reeb--Wolf \cite{RW}, Theorem 3, relate entropy reduction, reservoir heat,
correlations and relative entropy under their precise Landauer assumptions.
These are meaningful primary comparators. They do not assert the present
same-bath quantum coding law or its root-retaining scalar envelope.
Here depth is a mathematical conserved charge resource, not calibrated
laboratory heat, and no initial thermal-state assumption is required by
the upper theorem.

The inherited coding comparison remains
Giovannetti--Burgarth--Mancini \cite{GBM}, Definition 1 and Theorem 2:
subexponential effective environment size can support reliable quantum
communication. The actual infinite-bath compression proof, coherent
initializer quantifiers, positive-block factor, auxiliary normalization
and polar repair are retained in the predecessor. This turn adds the
resource bound to that actual code; it does not replace it with a
fresh-channel theorem.

The strongest earlier pair, nonscalar four-call, cubic and clipped
certificates remain valid. Cycle10's new order was not strongest at
every fixed angle. At \(\beta=1/512\), for example, its lower certificate
is \(1.98184515852\,10^{-11}\), while Cycle9 retains
\(2.35512760108\,10^{-11}\). Those are excess-rate certificates, not
capacities. This cycle does not improve those lower constants.

For the guaranteed lower construction, \(k=\Theta(\beta^{-2})\),
input dimension is \(3^k\), and rank is
\(\rank(I-(\ell/8)bH_k)\le3^k\). The inherited bath cutoff has coefficient
\((\rank\rho+16)/t\), with \(t\) the fixed Lyapunov parameter.
Its being finite proves the asymptotic logarithmic depth assertion,
not a useful finite blocklength. No efficient state preparation,
encoder, decoder, spectral computation or synthesis-precision bound
has been obtained. At \(\beta=1/512\), the Cycle10 input dimension is
\(3^{1024}\); these resource costs cannot be hidden by the simple new
upper formula.

The new diagnostic scripts retain actual coherent histories and the
vacuum exchange, and check precisely the new compression/pressure and
counterexample formulas. Small matrices and short script times do not
prove all-length statements or measure the cost of discovery.
Inference, design, and total review costs remain unknown.
Independent internal challenges are recorded separately from historical
novelty, external acceptance, implementation and private delivery.

\subsection{Continuation decision}

The completed boundary is now substantive: no construction based on
nonpositive complete operator drift, at any temporal length, can improve
the \(\beta^2\) order. The same order is sharp for all unassisted codes
whose mean bath-depth cost is sublinear. Merely sharpening the old
prefix-pressure constant would not change that operational boundary.

The next owned question is whether reliable communication can exploit
the escaping bath while keeping its \emph{logical-reference leakage}
small enough to exceed this quadratic order.
For an input purification \(R\) and an initial bath purifier \(F_0\),
\[
 \Ic(\rho_N,\mathcal N_N^{\tau_\pi})
 =S_2(\rho_N)-I(R:E_NF_0).
\]
This identity retains the purifier of the actual mixed initializer.
Here \(R\) purifies the physical input \(\rho_N\). For a general CPTP
encoder it need not equal the original logical reference. A complete
coding converse would therefore also need an encoder reduction or a
reference-sensitive version for the actual encoded logical state.
A concrete candidate converse obligation is
\[
 I(R:E_NF_0)\ \ge\
 [S_2(\rho_N)-Nc(b)]_+-o(N),
\]
with hypotheses and uniformity sufficient for arbitrary reliable
unassisted codes. It is \emph{not proved here}. An explicit correlated
code family violating the useful form of that inequality would instead
identify an escape-compatible mechanism to pursue. The pure-push
example rules out replacing reference leakage by depth alone.

The unrestricted capacity and feedback questions remain open under
their original resource contract. The mission continues at this
reference-aware boundary; the resource-constrained theorem is not
silently substituted for the original problem.

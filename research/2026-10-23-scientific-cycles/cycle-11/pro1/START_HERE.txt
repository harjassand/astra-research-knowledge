MAIN RESULT
For the actual root-retaining device, every k-call input density rho satisfies
  D_b(rho) >= 2 [ S(rho) - k c(b) ] I,
  c(b) = log2[2 sqrt(2)(1-b)+3b], b=beta^2.
S is von Neumann entropy in bits. This is a whole-bath operator bound,
with no input charge-preservation restriction. Every normal independent
initializer is allowed; initial bath entropy and mean depth may be infinite.

It yields an all-length ceiling for inward-drift input constructions and
a finite-error rate versus mean-depth expenditure theorem for arbitrary
unassisted fixed-call codes. The actual Cycle10 code is newly proved to
have O_beta(log N) final mean depth at tau_pi, uniformly over logical inputs.
Thus the capacity EXCESS under the additional sublinear mean-depth condition
has sharp small-angle order Theta(beta^2). This is not unrestricted capacity.

THE ORIGINAL OPERATION IS PRESERVED
One evolving infinite bath, actual root exchange, all calls and retained
registers counted. No bath control, reset, fresh channel, shared entanglement,
postselection, backward quantum wire, free timing, or terminal bath-return
promise. Code choice remains independent of the initializer; full-diamond
error vanishes pointwise for every fixed normal initializer. Inner beta,
block length and density are fixed before the outer horizon.
The new mean-depth budget is explicitly additional and evaluated at tau_pi.
The upper theorem even allows codes chosen only for tau_pi.

WHAT IS OPEN
The original O((bk)^2) prefix-pressure bound is not proved or physically
disproved. Its stronger form is no longer needed for the completed inward
and sublinear-depth order results. Unrestricted capacity, its small-angle
order, and feedback equality remain open. Linear outward depth alone
cannot prove reference leakage: a new exact pure-push example disproves
that shortcut.

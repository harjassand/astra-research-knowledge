# Failed routes and scope corrections

## Absolute block comparison is too coarse

The exact trace-moment comparison with a positive Johnson/Hamming matrix is valid. It respects color-fiber dimensions and the critical reference weight. However, distance-four entries alone create a Perron eigenvalue of order r^2 k^2 when b=r/k. The normalized exponential moment diverges. Its norm eventually exceeds the physical response range, so this first matrix is not a physical counterexample.

The pair-only comparator has an all-length log-MGF bound of order r^2. It does not license deleting higher-endpoint coherences of the actual response. The exact all-color-1 bulk cancellation illustrates what absolute entries erase.

## Adding norm and second moment still does not identify physical response

The refined rare-sector construction in contributions/moment_comparison has zero charge-pattern diagonal, the physical Hamming block bounds, the appropriate conditional second moment, linear spectral norm and compressed output-charge interval. Its normalized exponential moment still diverges. It is deliberately an abstract response, not a realized K_zeta.

Consequence: these limited data cannot establish the original physical log-MGF. They do not disprove the existence of a usable analytic prefix with the stronger pressure bound. The exact ordered-unitary tilted-map envelope supplies information absent from both fake responses.

## Original pressure objective remains unproved

The genuine all-prefix estimate is
Tr sigma exp(-tK_zeta) <= [(1-b)cosh(tb)+b cosh(t(1-b))]^k.
Its envelope is O(bk), not uniformly O((bk)^2) as bk tends to zero.
The new Gibbs/tilted-map argument already proves the desired O(beta^2)

## Invalid operator Jensen for exponential

Exponential is not operator convex or operator monotone on the whole real line. Coherent initializers can make the compressed output charge fail to commute with input charge. The valid extension uses compression concavity of logarithm, finite trace-exponential monotonicity, then Golden–Thompson. This correction is load bearing for the all-normal global theorem.

## Initial correlation is a forbidden resource

An explicit density on two actual root edges has entropy gain of order beta and strictly inward joint drift. It violates the entropy–drift conclusion if input–bath independence is dropped. The example is outside the permitted communication resources and establishes necessity of the premise.

## Root sign cannot be discarded at negative tilt

For one unperturbed call from vacuum, D=q and Tr exp(-lambda D)=1+2exp(-lambda). At negative lambda this exceeds the proposed bulk envelope exp(lambda)+2exp(-lambda). The global root envelope requires lambda>=0. The bulk all-real parameter statement is a different operation.

## Depth is not complementary information

At any fixed b<1, repeated pure input |1> gives mean depth 1/2+(1-b)N and at most logarithmic bath/purifier entropy. This actual example retires an unqualified “linear depth implies linear entropy/leakage” route. It does not transmit a high-dimensional unknown state and is not a capacity counterexample. The next investigation must use the reference and high input entropy.

## Reliability and moment quantifiers differ

Normal initializers may have infinite mean depth; the explicit h^-2 depth mixture remains infinite-mean after every finite number of calls. The inherited code can still be reliable pointwise for each such state. The new O(log N) mean-depth guarantee is specifically at tau_pi, whose geometric tail is charged.

A small overflow probability alone does not bound a first moment with an unbounded bath. The new lower-code resource proof also uses finite propagation and the actual tail. It uses the joint uniform logical/bath overflow bound, not average-state domination.

## Reference in a possible future converse

The coherent-information identity uses a purification of the physical input. A general CPTP encoder need not make that the original logical reference. The proposed leakage inequality remains unproved and requires an encoder reduction or a direct encoded-reference formulation before any unrestricted coding converse.

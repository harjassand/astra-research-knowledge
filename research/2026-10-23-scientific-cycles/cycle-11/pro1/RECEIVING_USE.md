## What changed because of the inherited source

## Exported proof interface

Input to Theorem 2.1:

1. A finite port observable q and an actual unitary interaction with one memory.
2. An initially product input–memory state; correlations across all input calls are allowed.
3. A proved bound Psi_lambda(I)<=f_lambda I for the exact tilted CP map, at lambda>0.
4. The actual ordered repeated interaction, with all port factors counted.

Output: an all-input entropy upper in terms of a bounded charge displacement, equivalently a full memory operator lower. No memory entropy or moment assumption is required.

To convert it into a physical resource inequality, additionally supply an exact conservation law and finite initial moments where means are subtracted. To convert it into a code inequality, the initial bath must be independent, with no feedback or uncharged wire, and code error must preserve arbitrary reference entanglement.

An omitted-premise counterexample is included: initial input–bath correlations at actual root edges violate the proposed extension. Negative tilt also loses the global root envelope. These delimit reuse.

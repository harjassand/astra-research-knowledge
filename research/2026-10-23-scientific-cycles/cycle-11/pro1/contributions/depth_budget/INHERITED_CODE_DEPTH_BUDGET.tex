\section{The actual reliable code has logarithmic final mean depth}
\label{sec:code-depth-budget}

Fix the inner device parameter, block length $k$, and actual input density
$\rho$ from the completed inward-drift construction. Write $n$ for the
number of inner blocks and $N=nk$ for the counted forward calls. All
inner parameters are fixed before $n\to\infty$.

The exact inherited operator-coding proof chooses
\begin{align*}
 A_n&=\lfloor\log_2(n+1)\rfloor,\qquad
 \epsilon_n=(n+1)^{-16},\\
 H_n&=A_n+\left\lceil
 \frac{(d+16)\ln(n+1)+\ln(1+C_{\rm Lyap})}{t}
 \right\rceil,
 \qquad d=\operatorname{rank}\rho.
\end{align*}
Here $t>0$ and $C_{\rm Lyap}<\infty$ are the fixed constants in that
proof. They may be enormous; no practical finite-horizon assertion is
made. For the two-seed binary Fock bath,
\[
 r_{A_n}=\operatorname{rank}P_{\le A_n}
 =2\sum_{h=0}^{A_n}2^h=2^{A_n+2}-2<4(n+1).
\]

\begin{lemma}[Uniform depth consequence of joint compression]
\label{lem:code-depth}
Let $C_n$ be the actual isometric encoder supplied by the inherited
joint-compression lemma. Start the physical device in its actual
$\tau_\pi$, with depth mass $(2/3)3^{-h}$. For every logical density,
including one entangled with an arbitrary retained reference, the final
bath satisfies
\begin{align}
 \operatorname{Tr}(L\tau_{E,N}^{\rm out})
 \le{}&H_n+(A_n+nk)\,2r_{A_n}^{2}(n+1)^{-16}\notag\\
 &+(A_n+nk+3/2)\,3^{-(A_n+1)}.\label{eq:depth-budget-exact}
\end{align}
In particular the bound is uniform over all logical inputs and references,
and
\[
 \sup_{\text{logical inputs}}\operatorname{Tr}(L\tau_{E,N}^{\rm out})
 \le H_n+o(1)=O_{\beta,k,\rho}(\log(n+1)).
\]
The same code and its inherited full-diamond arbitrary-reference error
guarantee are unchanged.
\end{lemma}
\begin{proof}
The inherited compression proof forms an input expurgation projection
$Q_{{\rm exp},n}$ inside the spectral-type subspace. Its actual encoder
has range in $Q_{{\rm exp},n}$, and the proof's positive-block estimate is
\[
 F_{Q_{{\rm exp},n}}\le2r_{A_n}^{2}\epsilon_n I.
\]
Consequently, for the actual ordered physical isometry $W_N$,
\begin{align}
 &(C_n^*\otimes P_{\le A_n})W_N^*
   (I\otimes P_{>H_n})W_N(C_n\otimes P_{\le A_n})\notag\\
 &\hspace{35mm}\le\delta_n I_{\rm logical}\otimes P_{\le A_n},
 \qquad \delta_n=2r_{A_n}^{2}\epsilon_n.
 \label{eq:actual-uniform-overflow}
\end{align}
This is the uniform joint operator bound, not a trace domination of the
code state by the average spectral type. The polynomial type-probability
factor has already been paid when choosing $H_n$; it is not paid again.
The auxiliary normalization in the inherited proof is not the actual
encoder. In particular the range statement applies to $C_n$, not to a
physically implemented inverse normalization.

Depth plus total port charge is conserved by the actual device, including
its vacuum exchange. Since each of the $N$ ports has charge in $[0,1]$,
the exact quadratic-form inequality and support implication are
\[
 W_N^*(I\otimes L)W_N\le I\otimes L+NI,\qquad
 W_N(\mathcal H_{\rm input}\otimes P_{\le A_n}E)
 \subseteq\mathcal H_{\rm output}\otimes P_{\le A_n+N}E.
\]
The form inequality follows by subtracting the nonnegative final port
charge from the conserved total. It extends from finite-coordinate
vectors by monotone approximation to finite-mean input densities.

Because $\tau_\pi$ is depth diagonal, it has the positive decomposition
\[
 \tau_\pi=\tau_{\le A_n}+\tau_{>A_n},\qquad
 \tau_{\le A_n}=P_{\le A_n}\tau_\pi P_{\le A_n},
 \quad\tau_{>A_n}=P_{>A_n}\tau_\pi P_{>A_n},
\]
with no offdiagonal cross terms. This decomposition is an analysis of
the original input, not a bath measurement, truncation, reset or
postselection.

For the low-depth subnormalized component, finite propagation and
\eqref{eq:actual-uniform-overflow} give a final mean bounded by
\[
 \operatorname{Tr}(\tau_{\le A_n})
 \bigl[H_n+(A_n+N)\delta_n\bigr]
 \le H_n+(A_n+N)\delta_n.
\]
For the high-depth component, conservation gives the bound
$\operatorname{Tr}[(L+N)\tau_{>A_n}]$, independent of the logical input.
The actual geometric depth law gives exactly
\[
 \operatorname{Tr}\tau_{>A}=3^{-(A+1)},\qquad
 \operatorname{Tr}(L\tau_{>A})=(A+3/2)3^{-(A+1)}.
\]
Adding the two positive components proves
\eqref{eq:depth-budget-exact}. Every estimate remains valid after
tensoring an arbitrary logical reference; the bath marginal depends
only on its encoded input marginal. Deterministic decoding on emitted
outputs does not change the unconditioned bath marginal.

Finally, putting $\nu=\log_2 3>1$, one has
\[
 \delta_n<32(n+1)^{-14},\qquad
 3^{-(A_n+1)}\le(n+1)^{-\nu}.
\]
The two extra terms in \eqref{eq:depth-budget-exact} are therefore
$O_k(n^{-13})$ and $O_k(n^{1-\nu})$, respectively, and tend to zero.
The fixed-parameter cutoff $H_n$ is $O(\log(n+1))$.
\end{proof}

\subsection{Quantifiers, resource consequence, and omitted-premise warning}

The code choice remains independent of the bath initializer, and its
inherited reliable-transmission guarantee is still pointwise in every
fixed normal initializer, in full diamond norm. The displayed
logarithmic mean-depth guarantee is for the actual $\tau_\pi$; it is
not a uniform moment statement over all normal initializers. For an
explicit omitted-premise counterexample, the normal density
\[
 \tau_\infty=\sum_{h\ge0}\frac{6}{\pi^2(h+1)^2}
             \frac{P_{=h}}{2^{h+1}}
\]
has infinite mean depth. Conservation also gives
$W_N^*(I\otimes L)W_N\ge I\otimes L-NI$, so every finite-call output
from this initializer still has infinite mean depth, for every input.
The pointwise reliability theorem remains applicable to this normal
initializer; the finite-depth-cost assertion does not.

For total call counts not divisible by $k$, at most $k-1$ counted,
data-independent calls can be appended. They increase the final mean
depth by at most $k-1$ and do not change already emitted output marginals.
Thus the logarithmic resource conclusion extends to the usual complete
capacity sequence. No terminal bath-return condition is introduced.

This proves that the actual completed quadratic-rate code belongs to
the class with sublinear final bath-depth cost, even when that class
requires a uniform bound over logical inputs. It can therefore be paired
with an independently proved all-input entropy--drift upper theorem for
that resource-constrained class. The present lemma by itself is not a
capacity converse and does not extend a restricted upper to unrestricted
channel capacity.

The uniform overflow premise matters. A small probability above a finite
cutoff alone does not bound a first moment when the possible output depth
is unbounded. Here it is combined with exact finite propagation for the
truncated initial component and an explicitly charged initial tail.
Similarly, replacing \eqref{eq:actual-uniform-overflow} by overflow only
for an average code state would not give the logical-input supremum.

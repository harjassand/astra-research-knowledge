1. PRECISE ACTUAL STATE AND OUTPUT CONTRACT

Let Omega_XAB be any finite-dimensional complete source, with inaccessible
X including the actual current clocks and all old memory. Apparatus initially
tensor-factors from Omega. Let V be a fixed finite-round finite-outcome LOCC
preprocessor, acting only on AB and independent apparatus, with accessible
local outputs A',B' and any other outputs W. Retain all actual outcome copies,
work registers and residual quantum systems in R=XW. Write

   Theta_(A'B'R)=(id_X tensor V)(Omega tensor apparatus),
   theta_(A'B')=Tr_R Theta.

For r independent complete queues, apply the same V independently, including
independent initial apparatus copies. The ACTUAL accessible marginal is then
theta^tensor r. Its extension to R need not factor from theta and usually does
not. More generally a b-queue block preprocessor gives a rate per original
queue divided by b; the independent coding units must be whole b-queue blocks.

A final coding instrument has one fixed output register Q=A_o B_o of Bell
dimension M_r. Its complete implemented state is rho_(Q R_r), where R_r includes
all actual clocks, old memory, preprocessing records, every copy of the public
coding transcript, residual local work, unused quantum data and every other
retained register. One may also include physical disposal environments; the
proof is independent of their dimension and availability. The comparison is

   Phi_(M_r) tensor (rho_(R_r)),                                  (1)

with the EXACT ACTUAL JOINT residual marginal, not merely its individual
register marginals, not an invented independent transcript law and not an
environment chosen by an Uhlmann optimization. No inaccessible X is measured.
The total resource convention charges all input queues and apparatus used by
V and the code, classical messages, randomness if actually sampled, local
work/disposal, and code construction/compilation. No initial entangled aid is
required by the coding theorem. No source clock access is supplied for free.

2. SHARP PURE-OUTPUT LIFT (SELF-CONTAINED)

Lemma. For every state rho_QR and every rank-one P=|phi><phi|_Q, set
t=1-Tr(P rho_Q). Then

  T(rho_QR, P tensor rho_R) <= g(t)
  g(t)=[t+sqrt(4t-3t^2)]/2 <= sqrt(t)+t/2 <= 2sqrt(t).             (2)

The function g is increasing and concave on [0,1], and the first bound is
sharp as a universal function of t. This lemma was independently audited by
/root/cycle10_block_code/decoupling_audit; its complete proof follows.

For a pure state write
 |psi>=sqrt(1-t)|a>+sqrt(t)|b>, |a>=|phi>|u>,
 (P tensor I)|b>=0, and Tr_Q|b><b|=tau.
Thus rho_R=(1-t)|u><u|+t tau. The operator
 X=|psi><psi|-(1-t)|a><a|
has matrix [[0,sqrt(t(1-t))],[sqrt(t(1-t)),t]] on span{a,b}.
Its trace norm is sqrt(4t-3t^2). Consequently
 ||rho-P tensor rho_R||_1=||X-t P tensor tau||_1
 <=sqrt(4t-3t^2)+t.
The endpoint t=0 or1 is obtained directly or by continuity.

For mixed rho choose a pure-state decomposition. The map
rho -> rho-P tensor Tr_Q rho is linear; use trace-norm convexity and Jensen.
Indeed g''(t)=-2/(4t-3t^2)^(3/2)<0 in (0,1), while g'(1)=0, so g is concave
and increasing. This proves (2), also for any t<=delta with g(t)<=g(delta).
The easier estimates follow from sqrt(4t-3t^2)<=2sqrt(t).

Sharpness: choose |chi> orthogonal to |phi> and
 |psi>=sqrt(1-t)|phi>|0>+sqrt(t)|chi>|1>.
Then t P tensor |1><1| has support orthogonal to X above, so the triangle
inequality is equality. Thus in general an O(t) joint bound is false even
though the pure-target marginal overlap error is t; the sqrt dependence is
necessary. For desired global error epsilon in [0,1], (2) guarantees it iff

 delta <= d(epsilon)
 d(epsilon)=[1+epsilon-sqrt(1+2epsilon-3epsilon^2)]/2
           =2epsilon^2/[1+epsilon+sqrt(1+2epsilon-3epsilon^2)].       (3)

The simple sufficient rule delta<=epsilon^2/4 avoids cancellation in (3).
All records must be in R BEFORE the lift. Tracing out a coding transcript,
proving a bound, and restoring that transcript afterward is invalid. If a
protocol yields transcript-dependent Bell encodings, perform the actual
locally controlled correction to one fixed P before applying the lemma.

3. THE KNOWN CODING INPUT, AND WHAT IT ACTUALLY SUPPLIES

Primary source read: I. Devetak and A. Winter, arXiv quant-ph/0306078v1,
Section III, Theorem10 and Remark11; exact downloaded PDF and identity are in
DEVETAK_WINTER_quant-ph_0306078v1.pdf and SOURCE_READ_RECEIPT.json.
Canonical links:
 https://arxiv.org/abs/quant-ph/0306078
 https://arxiv.org/pdf/quant-ph/0306078
 https://doi.org/10.1098/rspa.2004.1372

Known theorem used: for every fixed finite-dimensional bipartite theta,
every rate R<I(A'>B')_theta=S(B')-S(A'B') with R>=0 is attainable by one-way
LOCC on theta^tensor r. These are finite instruments at finite r, with fixed
Bell output dimensions M_r satisfying liminf log(M_r)/r>=R and Bell overlap
at least 1-delta_r, delta_r->0. Their construction has forward classical
communication rate I(A':E) for a purification, plus vanishing overhead.
This is an asymptotic existence theorem, not an efficient circuit theorem.
No explicit usable blocklength, decoder runtime or numerical circuit cost
is imported here. Its fidelity convention is squared fidelity, agreeing
with pure-target overlap. The source's Section III defines all-outcome CPTP
distillers, so abort outcomes belong to the fidelity average.

Apply each selected distiller to the ACTUAL theta^tensor r marginal, while
implementing it on the complete Theta^tensor r extension. Since a local map
commutes with the partial trace, its actual Q marginal has the same Bell
overlap. Apply (2) to its COMPLETE implemented final state. This proves

  T(rho_(Q R_r),Phi_(M_r) tensor rho_(R_r)) <= g(delta_r)->0.        (4)

This is one global bound and needs no sum of r one-queue errors. In particular,
a source-specific finite-error preprocessor may be fixed once for each L;
one must lower-bound I of its ACTUAL theta, then code that actual state. One
cannot tensor a nearby ideal state and silently replace theta^tensor r:
the naive replacement error can grow to r times the one-queue error.

If a code provides a marginal trace-distance error e_r instead of infidelity,
the Bell positive test gives delta_r<=e_r, and (2) applies with g(e_r).
If all one knows is a root fidelity F_root>=1-u_r, then overlap is at least
(1-u_r)^2 and delta_r<=2u_r-u_r^2; do not confuse fidelity conventions.

4. SHARED FINITE FLAGS AND PADDED VARIABLE OUTPUT SUPPORT

Suppose the actual accessible state has a classical flag C copied at both
parties,
 theta= sum_c p_c |c><c|_(C_A) tensor |c><c|_(C_B)
                        tensor theta^c_(A'B').
The theta^c may have c-dependent support, including c-dependent Bell lengths,
but embed all into declared finite local registers A',B' with fixed padding.
Direct-sum entropy gives

 I(A'C_A > B'C_B)_theta
 = [H(p)+sum_c p_c S(theta^c_B')]
   -[H(p)+sum_c p_c S(theta^c_A'B')]
 = sum_c p_c I(A'>B')_(theta^c).                                  (5)

No H(C) penalty remains, and no hidden flag is made accessible. Any other
record C' correlated with C stays in R and is covered by (4). If theta^c is
the exact padded Bell state of accessible known length c, its contribution
is c logD. For an approximate state that identity is only for the ideal
comparison state; the ACTUAL coherent information still needs a valid
entropy bound. A bad flag can be locally reset at both parties using the
already accessible flag, making its coherent information zero, if this
operation is actually included in V.

This covers source outputs of variable length without asking a distiller
for a random Bell output size: its final Q still has the same fixed M_r on
every branch, and every insufficient/abort branch contributes to delta_r.

5. BELL DIMENSION CONVENTION AND FULL RESOURCE BOUNDARY

Rates may be stated as ebits, log2(M_r), or D-dimensional Bell pairs,
log_D(M_r). If exactly m_r D-dimensional pairs are demanded, take
m_r=floor(log_D M_r) and N_r=D^m_r<=M_r. Exact deterministic LOCC converts
Phi_M to Phi_N for all integers M>=N, including composite D. For a concrete
finite instrument: Alice measures all cardinal-N subsets S of {1,...,M},
with Kraus A_S=binom(M-1,N-1)^(-1/2) P_S. Completeness follows since each
basis vector lies in binom(M-1,N-1) subsets. Both parties apply the announced
subset's basis relabelling, then identify its support with N. Each ideal
branch is exactly Phi_N. The outcome count binom(M,N) and corresponding
communication are charged if this deliberately inefficient conversion is
used. To keep the same infidelity bound under this actual map Lambda, use
E=Lambda^dagger(Phi_N). Since 0<=E<=I and Tr(E Phi_M)=1, E has Phi_M in its
unit eigenspace and E>=Phi_M. Thus actual Bell infidelity does not increase.
Reapply (2) with its original delta to the COMPLETE new state, including the
subset announcement, obtaining the exact-actual-residual target. Contractivity
alone would preserve the earlier reference residual, not automatically replace
it by the new actual residual.
Alternatively choose permissible DW fixed Bell dimensions directly; no
zero-cost efficient arbitrary-dimension converter is asserted.

For the known code, per-copy forward messages can be bounded crudely by
2log(dim(A'C_A)) plus vanishing overhead, using I(A'E)<=2S(A') with the full
local system understood. If dim(A'C_A)<=|C|D^L, the crude upper bound is
2log|C|+2LlogD bits per queue. This is in addition to actual preprocessing
messages. Codebooks can be fixed deterministically after the existence
argument, so no extra source-correlated label, shared entanglement or online
public seed is needed. The offline choice is computational work, not free.

Each finite-dimensional instrument has finite Kraus/Stinespring realizations
and finitely many outcomes. Arbitrary local block unitaries may require
exponentially many gates; neither fast decoding nor a useful finite-r budget
has been established. If numerically compiled, an actual diamond-norm error
budget for the implemented channel must be charged. In a common full output
space let e=||Lambda_implemented-Lambda_ideal||_diamond/2. Triangle inequality
and contraction give actual-residual error <=g(delta)+2e; alternatively its
Bell marginal test and (2) give <=g(min{1,delta+e}). A bare +e to an existing
actual-residual bound is not automatically justified, since the target's
actual residual also changes. Bounds only on an AB marginal cannot charge
implementation errors on an arbitrary correlated extension. No physical
memory/resource accessibility is proved by this mathematical coding reduction.

6. ORDER OF LIMITS / NONCLAIMS / DECISIVE FAILED BRIDGES

Hold finite L,D and the actual V fixed, choose R below its proved actual
coherent information, and let r->infinity with delta_r->0. Only afterward
compare L->infinity rates. A single simultaneous L(r) assertion requires
uniform finite-blocklength estimates and is NOT supplied by DW alone.

Failed or excluded bridges:
 (a) Output Bell overlap alone does not give O(delta) complete-joint error:
     sharp example in Section2 forces square-root scaling.
 (b) A near-ideal preprocessing state is not an iid state substitution at
     fixed global error; code the actual state rather than charge r eta.
 (c) Variable output inventory known only to inaccessible clocks cannot be
     treated as an accessible flag. Formula(5) requires actual duplicate C.
 (d) Postselecting successful blocks or deleting abort records does not give
     the declared deterministic fixed-output receiver.
 (e) Asymptotic achievable rate is not an efficient finite-size construction,
     an advantage over equally informed ordinary stock, or historical novelty.
 (f) This changes the pooled-output task. It does not reopen or evade the
     closed Cycle9 pointwise per-queue loss converse on its own interface.

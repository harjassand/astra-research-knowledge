1. ACTUAL STATE AND ASSUMPTIONS

Let D>=2, 1<=K<=L, p_K>=0, sum_K p_K=1, N>=1, and t_K=min(K,N).
Write Phi=Phi_D, nu=(I_D/D)_A tensor (I_D/D)_B, and

 r_K = Phi^tensor t_K tensor nu^tensor(N-t_K).

The actual joint state is

 Omega_N = sum_K p_K |f_N(K),f_N(K)><f_N(K),f_N(K)|_C
                    tensor rho_M^K tensor r_K.                 (1)

C_A,C_B are retained locally accessible CLASSICAL clock registers.
Their actual labels agree. Each party knows the deterministic map f_N,
and the relevant threshold t_K is locally recoverable from its label.
Injectivity of f_N on {1,...,L} is sufficient; full K recovery is stronger
than necessary. M denotes EVERY other retained memory register.

The fixed finite-horizon processor is defined on every input, including
mismatched clock sectors, by each party using its own local label. Its
behavior on those unused sectors is immaterial to (1), but the map is
still linear CPTP. There is no branch selection or inference of K from
a decomposition of an unflagged mixed state.

No additional initial shared entangled ancilla or communication is used.
The shared entanglement and shared classical clock correlations already
present in (1) remain part of the charged complete initialized resource.
Fresh LOCAL pure work/blank registers and their entropy disposal must be
allowed and charged separately from shared entanglement.

2. CONTROLLED LOCAL CHANNEL AND COMPLETE MEMORY RETURN

At party X=A,B, for output position i, apply identity if i<=t_K and the
local replacement channel

 R_X(T)=Tr(T)|0><0|

if i>t_K, controlled by that party's clock. Do not change the clock value
or any register in M. Both parties run the same known threshold rule.
For each actual K sector, the resulting output is

 s_K = Phi^tensor t_K tensor |00><00|^tensor(N-t_K).

Therefore the EXACT repaired joint state is

 Omega'_N = sum_K p_K |f_N(K),f_N(K)><f_N(K),f_N(K)|_C
                     tensor rho_M^K tensor s_K.                (2)

Every inventory branch K is included with the original probability.
Taking the output partial trace in (1) and (2) gives the identical full
C+M marginal, not merely the same pair-content or clock marginal.
Consequently the half-trace return error against ANY specified original
complete-memory target is unchanged by this terminal repair.

This is preservation branchwise in K and after averaging all branches.
It is not a claim that conditioning on an additional measured environment
transcript leaves the same memory distribution; such a transcript would
be a new retained register and must itself be counted.

The return contract used here is the complete MEMORY MARGINAL contract.
A stronger requirement to preserve the full output-memory joint state,
or to return every environmental degree of freedom, is different and
is not proved. The output-memory correlations are changed exactly as
displayed in (2), rather than silently discarded in the argument.

3. ALL PREFIX SCORES IMPROVE POINTWISE

For the Bell-prefix test P_i=Phi^tensor i tensor I, 1<=i<=N, put
 h=(i-t_K)_+ (equivalently h=(i-K)_+).
The original conditional score is D^(-2h), and the repaired conditional
score is D^(-h), since Tr(Phi|00><00|)=1/D.
Thus every prefix score is nondecreasing in EVERY K branch. Averaging
with p_K preserves this conclusion; no cancellation or postselection is
needed. Any weighting of K induced by an allowed memory readout gives
the same comparison.

In the score-loss convention Delta=old_score-new_score, Delta<=0.
For N=1 and K>=1, the exact first Bell output is unchanged.

4. OUTPUT READOUT UNCERTAINTY IS EXACTLY ZERO

Every s_K is supported on the same maximally correlated subspace

 span{|x>_A|x>_B : x in {0,...,D-1}^N}.

So is the repaired output marginal sum_K p_K s_K. Measuring Alice's
outputs in the common computational product basis produces, for every
positive-probability outcome x, Bob's exact pure output |x><x|.
Consequently

 inf_Alice-readout sum_y p_y S(B_outputs|y) = 0.

For r independent repaired tasks, measuring the whole Alice complement
in this basis gives every complementary Q_a=0 and hence Qbar_*=0.
The same is true with the global Alice/Bob orientation swapped.
This is an explicit product readout; no E_F optimizer, additivity
assumption, hidden-state label readout, or postselected ensemble is used.

The scored Bob system in this statement is OUTPUT ONLY. Arbitrary
retained Bob memory, reset garbage, or an inaccessible Bob-side clock
must not be silently appended to it. If clocks are included, Alice must
also be allowed to read her available clock; arbitrary additional
quantum memory still requires separate analysis.

5. EXPLICIT DILATION, WORK UNCOMPUTATION, AND ENTROPY EXPORT

On each side append N local D-dimensional blank registers in |0>.
For i>t_K perform a local controlled SWAP between output i and blank i.
For i<=t_K leave blank i untouched. This gives a one-outcome local-unitary
dilation followed by the declared local environment discard. Conditioned
on K, the complete state after the swaps is

 rho_M^K tensor s_K tensor e_K,
 e_K=|00><00|^tensor t_K tensor nu^tensor(N-t_K),               (3)

with the same classical clock sector as (1). Thus the environment
explicitly receives the private mixedness removed from the outputs.

Its conditional entropy is

 S(E_A E_B | C M) = 2 sum_K p_K (N-t_K) ln D,                 (4)

for the classical-clock state (3); each party contributes half. This is
the exact conditional entropy export, not a claim that unconditional
S(E_AE_B) equals (4). The environment can also be correlated with K.
If total entropy differences are used, all registers and clock
correlations must be included; no heat, work, or hardware price is
calculated here.

All decoder/comparator work bits are deterministic functions of the
unchanged clock and fixed schedule. They can be computed reversibly,
used as controls, and uncomputed with the clock unchanged. The old output
noise is not in those work bits: it is in the explicit E registers.
One must not claim that uncomputing classical control erases that noise.

At most N D-register swaps/resets are required PER PARTY: at most 2N
individual local register resets overall, or N paired resets. For
qubit-level implementation at variable D, resetting all physical output
degrees of freedom carries the corresponding O(N log D) local register
cost. The mean number of actual paired resets is sum_K p_K(N-t_K).

For the actual cyclic clock
 f_N(K)=1+[(K-N-1) mod L],
 inverse decoding is a reversible modular addition on O(log L) bits.
Comparison with each i and uncomputation therefore have
O(N log(L+1)) ordinary reversible-classical gate cost, in addition to
the local D-register reset/swap cost, with O(log(L+1)) reusable work.
If f_N is merely an arbitrary known injective labeling, efficient
inversion does NOT follow from injectivity: its actual decoder cost
must be added. This is the precise computational qualification.

The map here is the finite-horizon terminal processor Gamma_N with known
N. An online version may use the known deterministic call schedule.
If an autonomous implementation retains a new elapsed-time counter,
that counter is additional counted memory and its return must be checked.

6. RETAINING GARBAGE CHANGES THE CONTRACT

If E is genuinely discarded as a paid local entropy export, it is not
a retained memory register and (2) is the correct complete retained
state. This is allowed by the local-CPTP model.

If E is retained, it must be included as new memory. It starts pure and
ends in (3), generally correlated with the old clock. Its return is
NOT automatic, so the original complete-memory error cannot simply be
reused on the enlarged register list. If Bob's garbage is part of the
scored system, its private (N-t_K)lnD conditional entropy persists and
the output-only Q=0 statement does not erase it.

If the intended free operations require a closed cyclic reset of every
ancilla/environment, or prohibit local purity consumption/entropy export,
this construction is NOT yet admitted: (3) is exactly the missing paid
resource. It uses zero ADDITIONAL shared entanglement and zero
communication, rather than zero total physical cost.

7. CORRECT SUPPLY/WITNESS INTERFACE

The Cycle5 retained-register/all-branches contract permits an LOCC
operation on the complete state before the final local memory trace.
The repair is such an operation, with the clock counted throughout.
For the complete initialized supplied resource R and its actual joint
state Omega_N, the valid monotonicity chain is

 C_sup >= E_F(Omega_N) >= E_F(repaired output),

with the same deterministic versus genuinely preselected-expected
supply distinction as in the parent contract. For a preparation with
GLOBAL complete-memory half-trace error epsilon, applying this fixed
CPTP processor and tracing memory contracts that error, so the usual
bounded-output score error budget remains available.

Specifically the finite-error witness must retain

 C_sup/r >= m A_N(delta)-C_D-Qbar(actual repaired output)-mN epsilon.

The ideal repaired source has Qbar=0. Arbitrary epsilon-close
initialization need not have that exact support or Qbar=0, so this term
cannot be dropped by transferring ideal entropy to actual output.
An explicit support-preserving initialization, an actual-output
prediction-cost upper bound, or a paid continuity argument is needed
to remove it. The score transfer itself uses a bounded positive
operator of norm at most rNm, hence costs at most mN epsilon after
division by r. This does not require an entropy-continuity assertion.
If an approximate initialization has coherent clock errors, the exact
unchanged-memory assertion of Section 2 also cannot be promoted to it
without a further error argument; Section 2 is for the stated cq state.

This chain does NOT require E_F(unflagged original output) to upper
bound E_F(repaired output). The latter inference would be unjustified:
Gamma_N uses accessible side information correlated with that output,
which was already discarded in the unflagged marginal. Likewise, the
output-only normalization interface cannot be cited unchanged.

The previous pairwise actual-queue rigidity result remains correct.
Its maps are fixed input-independent channels on the reduced outputs,
or input-independent shared-random mixtures thereof. Here the retained
clock makes the choice correlated with the actual K branch: the same
position receives identity when Bell and reset when noise. It is
outside those output-only hypotheses and supplies no contradiction.

8. SCOPE OF THE PASS

This is an explicit efficient clock-assisted repair of this flagged
finite queue, including its actual output-memory correlations and
paid local entropy disposal. It does not establish a universal repair
for arbitrary finite-return memories, or one for the unflagged queue
after all correlated side information has been discarded. It does not
show a supply saving over the ordinary flagged stock whose inventory
and clock were already counted. Its role is to retire the claim that
the large raw output-only Q of this flagged queue remains an
irreducible obstruction when the accessible clock may be used first.

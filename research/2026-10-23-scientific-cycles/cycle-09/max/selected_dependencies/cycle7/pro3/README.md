## Bounded reproducibility

Python 3.10 or later with only the standard library is sufficient. From any
extracted copy run:

```sh
python replay.py --output /absolute/path/to/replay-receipt.json
```

The script verifies MANIFEST.json, executes only the two new exact-rational
diagnostics in a temporary directory and compares the four deterministic
input/result files byte for byte. It records separate replay timing and
process receipts. It does not overwrite frozen evidence, materialize any
asymptotic graph, use network access or rerun predecessor campaigns. Assertions
must remain enabled; the runner explicitly rejects optimized Python mode.

EXPERIMENT_CONTRACT.md and FANOUT_CHECK_CONTRACT.md were frozen before their
respective first executions. NUMERICS.md records actual results and limits.
RESOURCE_RECEIPTS.json separates recorded computation from unknown discovery,
inference, token, monetary and historical costs.

The archive freezes before private delivery. An external immutable delivery
receipt records its final bytes, hash, private identities, actual roundtrip,
fresh-extraction replay and Page insertion. This avoids a self-referential
archive hash. Delivery, recipient reading, scientific acceptance and programme
integration are different events. Max owns integration; PRO3 owns science
and this handoff. No user file relay is needed.

PRE-EXECUTION DEVELOPMENT RECORD

The three-arm design was strengthened before any experimental search: a common
minimal-mask antichain removed the original quadratic-reducer difference, and
an occupancy/flags-only intermediate arm separated forgetting per-color
multiplicity from the stronger support order.

Source review found active_ports.expanded remained unbounded in the archived
file. The experimental adapter explicitly rebinds both its defining module and
monotone_ports importing alias to the same 512-entry cache used in the other
arms. Original source files are preserved byte for byte.

Independent pre-execution review identified redundant result serialization:
the draft computed a large unused JSON string before writing another copy.
The final driver streams exactly one JSON output; wait4 measures total process
CPU and peak RSS including that serialization. No experimental search outcome
was observed before making this correction. Python syntax compilation passed.

This is development work, with total design, source-reading, inference and
integration cost unmeasured. It is not included in the runtime advantage of
any arm. Focused adapter semantic checks are separately preserved; they do not
constitute a fresh literal-witness certificate for the whole closure.

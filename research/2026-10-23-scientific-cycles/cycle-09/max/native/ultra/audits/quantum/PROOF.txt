1. ACTUAL INPUT AND COMPLETE REFERENCE SYSTEM

Condition on the actual classical inventory K=k. The L emitted pairs are
 Phi_2^tensor k tensor nu^tensor(L-k), nu=I_4/4.
At horizon L, the complete OLD memory is the matching current clock |kk><kk|
and nu^tensor L. Its pair contents are independent of the emitted system;
the clock is correlated with the inventory. The receiver never reads it.
All assertions below retain K in a cq extension; this is mathematical
conditioning on a counted register, not an added control interface.

A useful exact decomposition writes each noise pair as a uniform computational-
basis mixture. For fixed tail strings u_A,u_B, the emitted pure component is
 2^(-k/2) sum_(x in F2^k) |x,u_A>_A |x,u_B>_B.
All coherent amplitudes are positive and equal. Equivalently, the Z-bit
difference e has e_i=0 for i<=k and independent uniform bits for i>k. This is
an unchanged latent classical variable for all subsequent local Z-parity
measurements, since those measurements are diagonal in this basis. If J is
first nonzero e coordinate minus one, with J=L when e=0, then J>=K.

2. ADAPTIVE LOCAL COMMUTING PARITY INSTRUMENT

Every query specifies the SAME row h to both parties, with h_1=0 and support
in coordinates2..j. Each party projectively measures its local Z parity h,
and BOTH outcome bits are exchanged and retained in a common public transcript.
The row is selected using public independent coins and prior classical
transcript. A fixed complete path therefore fixes a finite list of rows H and
outcomes s_A,s_B. Even with adaptivity, its net data Kraus operator is precisely
 P_A(H,s_A) tensor P_B(H,s_B),
because all those diagonal projectors commute. Adaptivity changes which path
is selected and its probability; it does not insert any unrecorded phase or
noncommuting back-action.

The actual parity difference is h dot e. With fresh uniform h over coordinates
2..j, it is always zero if j<=J, and is an unbiased bit if j>J, conditional on
any prior history and a fixed latent e. Hence any classical noisy-search proof
that uses this precise one-sided fresh-row oracle is a valid description of
the measurement outcome differences. Individual local parity outcomes need
not be fresh independent bits; such independence must not be assumed. The
classical controller may use them, but fresh h still has the stated law.

3. TAIL MEASUREMENT AND EXACT AFFINE-CODE DECODE

Let the public transcript choose a cut c>=1. Measure every output coordinate
>c locally in the computational basis, temporarily recording Y_A,Y_B. Let
H_c be the measured parity matrix restricted to coordinates1..c. Each party
subtracts the measured tail contribution from its own parity outcomes:
 s_A'=s_A-H_tail Y_A, s_B'=s_B-H_tail Y_B over F2.
Use a common deterministic Gaussian-elimination convention on the public H_c.

On EVERY positive-probability branch c<=K, the first c pairs were exact Bell
pairs before the parity instruments. The initial computational decomposition
and the diagonal projectors show that the conditional retained prefix is
 EXACTLY 2^(-(c-r)/2) sum_(x:H_c x=s_A') |x>_A |x>_B,
where r=rank H_c and s_A'=s_B'. Inconsistency has zero branch probability.
Conditioning on all tail digits fixes all omitted computational variables;
there is no remaining random phase or unobserved mixture on this prefix.
Even if c<K, measuring the other original Bell pairs merely fixes their
matching tail digits and leaves the displayed equal-amplitude state.

A local invertible binary affine transform, identical at both parties on these
good branches, maps this affine solution space to r fixed coordinates and
c-r free coordinates. It is implemented by ordinary CNOT/permutation gates
and computational-bit flips. Reset the constrained coordinates and route the
free coordinates first. The exact port output is then
 Phi_2^tensor(c-r) tensor |00><00|^tensor(L-c+r).
All rows omit coordinate1, so H_c has zero first column, r<=c-1, and the
Gaussian circuit can act only on coordinates2..c while protecting coordinate1.
Thus the actual first Bell pair remains exact on ALL branches, including
c>K branches on which the rest of the decoding is not promised ideal.

The safe deterministic bound is r<=q when at most q parities are measured.
One must not call c-r an actual Bell inventory on bad branches c>K. It is a
classical decoder dimension there; only the first Bell is guaranteed.

4. ALL-BRANCH CQ COUPLING AND FINAL DISCARD

Retain the mathematical cq extension (K,R,T,Y_A,Y_B), where R are public coins
and T contains all measured rows, query choices, both parity outcomes and any
stopping decisions. The conditional quantum output includes the deterministic
decoding/reset channel. On good branches c<=K it is the exact state above,
independent of the compatible tail digits Y after correction.

Define n_star=max{1,min{K,c-r}} and a reference state having the SAME ACTUAL
joint law of (K,R,T,Y_A,Y_B), the same terminal old memory clock and nu^L, but
port state Phi_2^tensor n_star tensor |00><00|^tensor(L-n_star).
This is a comparison state. It is not claimed that the receiver learns K or
physically prepares the reference by access to the clock. On good branches
n_star=c-r, and the actual/reference conditional quantum states coincide.
On every bad branch their half trace distance is at most1. Block diagonality
therefore gives
 T(actual extended state,reference extended state)<=Pr[c>K].

The implemented receiver may now discard the PRIVATE tail digits and local
Gaussian work after correction/reset. Trace them in BOTH states. Contractivity
preserves the same bound for the declared joint final state on ports, old
complete memory and retained (R,T). No hidden retained tail record or its
return is assumed. Since the good decoded state is the same pure Bell/zero
state for every compatible Y, this discard introduces no good-branch dephasing.
Both parity outcomes were exchanged, so the retained public transcript is
identical at A and B. Private unmatched Y digits would not be a standard shared
MC record if retained; their discard is a real reset/entropy-export obligation.

6. RESOURCE, RECORD AND IMPLEMENTATION BOUNDARY

No additional entanglement or clock access is needed. Shared classical random
rows are created by allowed LOCC and are independent of the initial inventory;
their later correlation with K is obtained by measured emitted systems.
All public coins, row descriptions, both outcomes and adaptive choices remain
in the declared retained transcript/reference. Their information is not free
hidden access. The decoding pays at most q Bell pairs via its rank loss, and
may discard genuine Bell pairs after its selected cut.

An h-parity can be implemented with a fresh pure local ancilla, at most its
support-size CNOTs and a Z measurement. At most qL such CNOTs per party suffice
for all queries. Local binary elimination and its affine decoder are finite
ordinary classical/CNOT operations. Tail reset/discard, fresh ancilla purity,
measurement and transcript control have physical/entropy costs, not measured
here and not asserted zero. Retaining their garbage enlarges the complete
memory. The OLD memory marginal is unchanged by TP processing of its emitted
system; its correlations with output and transcript change and are retained
in the reference.

This is a separate receiving operation after the fixed reusable queue's calls.
Appending new transcripts or consumed work to that device's memory does not
establish a complete return of the enlarged memory. No such new return claim
follows from this coupling. Source formation cost remains ordinary flagged
stock; the operation itself does not establish a supply advantage or close
an asymptotic formation gap without a separate resource argument.

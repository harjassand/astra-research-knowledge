1. CONDITIONALLY FRESH ORACLE WITHOUT A SHARED SEED

Fix actual source inventory K. Every position is an independent tensor factor:
a Bell pair before K, a maximally mixed product pair after K. The deterministic
color classes partition positions2..L. Before raw call a, its color has never
been touched by earlier calls, even when the thresholds were adaptive and both
individual local parity results were retained. Previous instruments act on
OTHER tensor factors. Conditional on K and the entire previous transcript,
the unused color's subsystem remains its original state and is independent of
the previous colors. The threshold j must be selected from prior history before
measuring that unused color, as the algorithm specifies.

If j<=K, its local mod-D sums agree exactly. If j>K+Q, the interval (K,j]
contains a representative of every cyclic color. In particular the current
unused color includes a product-noise position with independent uniform
computational difference in Z_D. Its coefficient is ONE, so its contribution
makes the sum exactly uniform in Z_D, including composite D. No field,
random coefficient or public-coin lemma is needed. In the width-Q band nothing
is promised, as the abstract search allows. Synthetic calls may reserve/skip
their color; distinct physical calls must never reuse a color, and at most Q
raw calls are made. Empty colors are harmless when Q>=L; then the useful cut
bound can become vacuous, not incorrect.

2. EXACT SAFE-BRANCH QUANTUM DECODE FOR COMPOSITE D

Use the Lueders sum-parity instrument: coherently add the data digits into a
pure local D-ancilla, then measure only that ancilla. Measuring individual data
digits instead would invalidate the coherence claim. On any fixed adaptive
path all local data Kraus projectors commute and have computational entries
zero or one. Measure the tail i>c only after the cut is selected. Subtract EACH
party's own measured tail contributions from its own parity sums.

When c<=K the retained prefix is exactly the equal-phase uniform maximally
entangled vector on Hx=u, with equal adjusted syndromes at both parties.
Restricted nonempty rows have disjoint supports and all coefficients are1.
Choosing one pivot in each row and replacing that pivot by the row sum is an
invertible coordinate map over Z_D: its inverse subtracts the other unchanged
coordinates. After subtracting the local syndrome at pivots, r coordinates are
zero and c-r coordinates are free. The affine solution set has EXACT size
D^(c-r), so the decoded state is Phi_D^(c-r), with reset zero tail. This does
not rely on Gaussian elimination over a field or an ambiguous module rank.
Position1 belongs to no row and stays an exact first Bell on every branch.

3. ALL-BRANCH JOINT REFERENCE AND RECORD COST

The earlier quantum coupling proof applies verbatim. In the temporary cq
extension retain K, common query history and BOTH local tail strings. Use their
ACTUAL joint law. The old current-clock memory and terminal nu^L are retained;
there is no receiver clock access. On c<=K, the decoded port is exactly the
claimed pure prefix state, independent of compatible tail digits. Replace
unsafe port outputs in the comparison state only, using n_star=min(K,c-r).
Every branch is included, so joint half-trace error is at most Pr(c>K).
Actually discard private tail/work records in both states, preserving the bound.
The complete old memory marginal is unchanged, but correlations with output
and transcript change and are retained in the reference. No enlarged returned
memory apparatus is claimed.

The simplest communication convention sends a D-symbol EACH WAY per query,
so both raw parity values and their equality answer are a matching public
transcript. An alternative Alice-symbol/Bob-equality convention is valid for
control and local syndrome decode, but Bob's untransmitted raw symbol remains
private until it is discarded after use. If such private symbols are retained,
they must be included in the joint state; they cannot be silently called a
matching shared MC record. The principal version should use two exchanged
symbols or explicitly discard private records. Only the external quantum
ports are promised MC in a reference; old nu memory is never claimed MC.

4. IMPLEMENTATION COST SCOPE

Each position is touched by at most one parity sum, hence at most L-1
controlled-addition data touches per party before final decode. Disjoint-row
pivot decode uses O(L+Q) further local additions/reset work. Zero shared random
seed and zero auxiliary entanglement are correct. Control computation, local
ancilla purity, outcome storage, tail measurement and entropy disposal remain
real resources. Initial source supply is still ordinary stock; the receiver is
a separate output-processing stage, not an enlarged complete-return protocol.
The r-copy global error still requires an explicit sum/allocation, and a
large w>=L branch bound is vacuous rather than an iid asymptotic improvement.

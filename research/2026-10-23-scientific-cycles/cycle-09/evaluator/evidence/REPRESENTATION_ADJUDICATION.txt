A/B/C SEMANTICS
A retains exact terminal neighbor-count vectors, actual terminal colors and the
SAT4 projection. It orders only flag masks within an identical color/count
base. That is the strong completed exact-count control, not an earlier raw
state method or a saturation-only failed attempt.

B retains actual total degree, colors and neighbor support masks, applying
flag dominance only within a fixed support base. The occupancy theorem makes
per-color multiplicities irrelevant to any admitted future merge: children
are already valid, and only cross-child collisions can create a new violation.
Keeping the supports fixed is a weaker sound simulation order than C. Given
smaller actual flags at the same supports/degrees, a successful extension or
merge stays successful and resulting flags can only decrease. This gives the
needed compositional monotonicity.

C uses the same occupancy transition implementation as B and additionally
orders support masks as well as flags. At fixed actual degrees, shrinking
supports/flags can only remove merge hazards. Extension output flags depend
monotonically on whether the added color occupied the old support. This is the
source's proved stronger guarantee order, not an assumption that arbitrary
lower-degree or unrelated graph states are interchangeable.

In all arms, saturated degree-four ports retain their actual degree but forget
colors/count details only after the creating merge has been checked. No later
admitted operation can touch such a port. Positive degree, degree cap, true
child disjointness, nonadjacent terminals and common color permutation remain.
No free vertex split, artificial graph edge, recoloring of only one shared
interface, or hidden resource is introduced.

COMMON REDUCER
For each equality base, mask subset is the intended order. Sorting by popcount
puts every proper subset before its strict superset. Keeping a mask only if no
retained submask exists computes exactly the minimal antichain: if an earlier
candidate was itself discarded, it has a retained subset by transitivity.
All bits partition into disjoint four-bit blocks. Recanonicalizing retained
states is valid because one common permutation acts equivariantly on both
ports, all subset relations, and all operations.
This analytically justifies the common reducer. It does not rely solely on
finite passing fixtures.

WHAT THIS ESTABLISHES
After equal cache repair and the common efficient antichain algorithm, the
scientifically justified representation/order still has a substantial measured
computational effect on this actual constructive proof search.
- A to B: about 2.8 times less CPU, 1.55 times less peak RSS. This is the occupancy
  representation PACKAGE: lower state redundancy plus its actual primitive
  implementation and induced schedule, not a pure theorem in isolation.
- B to C: about 6.9 times less CPU, 2.15 times less peak RSS, on the SAME occupancy
  backend. The additional support-dominance theorem is therefore a major part of
  the gain; merely saying 'forgetting counts caused the improvement' is incomplete.
- A to C: about 19.3 times less CPU and 3.3 times less peak RSS in this run.
  The final obligation count drops by more than a factor of six. This discrete
  structural reduction is not explained by operating-system timing fluctuations.

The strong conventional A control also succeeds. Therefore neither this frozen
experiment nor the historical sequence supports saying that occupancy abstraction
was necessary to prove the theorem or necessary to fit the declared budget.
This is computational leverage in obtaining the same proved finite closure. It
is not an additional mathematical result, an independently verified new witness
certificate, or proof of new generally learned scientific creativity.

No percentage of the speedup is assigned to a 'mathematical' versus 'coding'
factor beyond the declared A/B/C interventions. Additional cache hits, changed
canonicalization work and worklist order are consequences of the representation;
this experiment does not artificially hold those downstream mechanisms fixed.
The old 2.185-GB incomplete run is NOT the comparator, and its historical memory
ratio must not replace the controlled 97.54-to-29.26-MiB observation.

CAUSAL AND STRATEGIC LIMITS
There is one scientific problem and one measured execution per arm in fixed
order. All arms use known source mathematics, and the abstraction was supplied,
not invented by a tested learning algorithm. Strong deterministic differences
in family/obligation counts and large CPU differences support the local mechanism;
no statistical distribution or confidence interval for timing was estimated.
No independent receiving investigation was accelerated by this experiment.
It establishes a reason to retain the proved representation as scientific
capital and to investigate when comparable abstractions can be discovered.
It does not establish how to invent them more reliably, net lifetime gain after
invention costs, transferable scientific intelligence, or recursive amplification.

The three timed processes consumed 210.162818 aggregate CPU seconds. The focused
adapter checks consumed about 12.71 additional CPU seconds; analytical design,
proof review, original discovery, inference, source adaptation, integration and
packaging remain unmeasured. This cannot be presented as a net total-research
cost ratio or a historical counterfactual in which the original investigator
received a free abstraction.

VERDICT
Accept the scoped positive computational result. The representation/order has
real scientific-computation value after a stronger conventional implementation
control; the additional order relaxation is particularly consequential. Reject
necessity-for-feasibility, automatic invention, total-discovery-cost and recursive
improvement claims. Preserve owner autonomy: this is evidence for conditional
use of proof-backed semantic abstraction where an actual bottleneck admits it,
not grounds to prescribe the same reasoning routine to every research branch.

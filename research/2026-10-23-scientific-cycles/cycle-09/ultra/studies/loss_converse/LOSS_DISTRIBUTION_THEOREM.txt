ACTUAL-QUEUE SEPARABLE RECEIVING LAW: COMPLETE LOSS DISTRIBUTION
22 October 2026. Developed in cycle9_loss_converse; root was informed as each
step was proved. The underlying score argument has an independent helper
check; the sharpened sum/distribution/access corollaries require final root
audit. This file supersedes the looser count-times-maximum estimate in
SEP_LOG_LOSS_CANDIDATE.txt without making that earlier valid inequality false.

1. SOURCE, RESOURCE AND ERROR DEFINITIONS

D>=2,L>=2 integers. Phi_D is a D-level Bell pair, nu=I_D/D tensor I_D/D.
K is uniform on {1,...,L}, carried by complete retained inaccessible current
clock registers. Conditional on K=k the accessible external quantum input is
  sigma_k=Phi_D^k tensor nu^(L-k).
The unchanged old memory nu^L and all retained records remain in the original
joint comparison. No physical operation reads the inaccessible K clock.

The baseline receiver is an arbitrary finite-dimensional trace-preserving
separable operation on the external pairs, including finite-round LOCC.
Independent local apparatus, independent shared classical randomness and
discarded local entropy can be absorbed into this operation. Such apparatus
is not declared returned. Receiving apparatus and disposal still carry their
usual implementation cost; the converse does not set those costs to zero.

Optionally a receiving auxiliary A'B' is supplied. Conditional on K=k it is
tau_k and is a PRODUCT with sigma_k. Require an explicitly given separable
normalized zeta on A'B', independent of K, and a number kappa>=1 such that
  tau_k <= kappa zeta for EVERY k.                             (R)
The actual receiver on external input plus A'B' is separable across AA':BB'.
This one-shot domination constraint prices both inventory access and extra
entanglement. Baseline tau_k absent means kappa=1. No assertion is made that
(R) is experimentally measurable or follows from a mere entropy/energy bound.

The actual final joint state rho is at GLOBAL half-trace distance <=epsilon
from a reference Theta, with the exact uniform K marginal and arbitrary
retained transcript T, whose external conditionals are
  v_N=Phi_D^N tensor |00>^(L-N), 0<=N=N(k,T)<=k.
The complete old memory and output-memory/transcript correlations are retained
in that premise. N need not be available to either receiver. Define the
REFERENCE LOSS W=K-N, a nonnegative integer random variable. It is a precise
mathematical resource/error quantity, not a claim of experimental inventory
access or an actual finite-error branchwise Bell certificate.

2. THE FINITE DISTRIBUTION LAW

For every pair of integers b,a>=0,
  Pr_Theta(W<=b)
   <= epsilon + D^(-(a+1))
      + kappa D (D^(b+a+1)-1)/[(D-1)L].                       (1)
The right side can of course be capped at 1. There are NO restrictions on the
amount or number of messages in this theorem. It is not a communication bound.

In particular a pointwise W<=w target obeys
  1-epsilon-D^(-(a+1))
   <= kappa D (D^(w+a+1)-1)/[(D-1)L].                         (2)
For kappa=1, fixed D and any fixed epsilon<1, choose a constant a such that
D^(-(a+1))<1-epsilon. Then
  w >= log_D L - O_(D,epsilon)(1).
Thus logarithmic loss in L is NECESSARY under actual-queue separable receiving
operations even at fixed error. Cycle8's actual admissible receiver gives the
matching O(log L) order at fixed D,error and kappa=1. No sharp coefficient
for that particular receiver or an optimal implementation is established.

3. PROOF OF THE SCORE INEQUALITY

Append an actual local coarse measurement on Alice's final output:
  J=max({0} union {i:x_i!=0}).
For j>=1 its projector is I^(j-1) tensor (I-|0><0|)_j tensor |0><0|^(L-j);
for j=0 it is the all-zero projector. Alice broadcasts J. Each party retains
the first n_j=max(0,j-1) pairs and resets the rest to zero. This is an LOCC
map C. It does NOT measure the individual prefix digits.

On a reference v_N, J<=N, its conditional remaining output is precisely v_nj,
and Pr(N-J>a | N)<=D^(-(a+1)). The statement includes N=0 and J=0. Hence the
mathematical joint test which checks both K in [J,J+b+a] and the output v_nj
has reference success at least Pr(W<=b)-D^(-(a+1)). Trace contraction transfers
this to actual success with an additional loss <=epsilon. The test can use
inaccessible K for its analysis; C itself never reads K. Bad branches are
included, not postselected away.

For the kappa=1 baseline, refine C Gamma into product Kraus A_lambda tensor
B_lambda, each with fixed j, on local input dimension d=D^L. Trace away other
records and refine local discards; completeness remains
  sum_lambda A_lambda^*A_lambda tensor B_lambda^*B_lambda=I_(d^2).
For one source computational tail |u>_A|v>_B, contract local output tail-zero
vectors and write the resulting maps A',B' with D^n_j rows. The v_nj amplitude
on Phi_D^k tensor |u,v> is
  D^(-(k+n_j)/2) sum_(x in [D]^k,y in [D]^n_j) A'_(y,xu)B'_(y,xv).
Cauchy-Schwarz, summing the PRODUCT noise-tail probability D^(-2(L-k)), gives
the complete contribution including the uniform source prior
  f_(lambda,k) <= D^(-2L+k-n_j)/L
          Tr(A_lambda^*A_lambda)Tr(B_lambda^*B_lambda).          (3)
The actual nu tail is essential to the factorized u,v sum. No chi-tail
resource witness or retained-coordinate certificate is used.

For fixed j>=1, eligible k in [1,L] intersect [j,j+b+a] satisfy
  sum_eligible_k D^(k-n_j)
    <= sum_(h=0)^(b+a) D^(h+1)
     = D(D^(b+a+1)-1)/(D-1).                                  (4)
For j=0, n_j=0 and eligible k=1,...,min(L,b+a), whose sum is smaller. Trace
the Kraus completeness identity to obtain
  sum_lambda Tr(A_lambda^*A_lambda)Tr(B_lambda^*B_lambda)=d^2.
Therefore the baseline actual joint-test success is at most
  D(D^(b+a+1)-1)/[(D-1)L].                                    (5)
Together with the reference lower bound this proves (1) at kappa=1.

For the optional resource (R), the entire actual initial state with clocks is
operator-dominated by kappa times the same queue supplied with independent
separable zeta. Applying C Gamma and its positive joint test preserves this
order. With zeta supplied, the effective operation on the external queue is
separable (expand zeta into product states and absorb each local state into
local Kraus). Thus (5) is multiplied by at most kappa. This proves (1).

4. MEAN LOSS WITHOUT AN EPSILON*L CONTINUITY PENALTY

Put C_D=1+D^2/(D-1). Whenever x=kappa D^b/L<=1, choose
  a=floor((1/2) log_D(1/x)).
Then D^a<=x^(-1/2)<D^(a+1). In (1), the tail term is <=sqrt(x), while
  kappa D(D^(b+a+1)-1)/[(D-1)L]
    <= [D^2/(D-1)] sqrt(x).
Consequently
  Pr(W<=b) <= epsilon+C_D sqrt(kappa D^b/L).                    (6)
Let h=max(0,floor(log_D(L/kappa))). Sum Pr(W>b) for b=0,...,h-1.
The geometric sum of the square-root terms is <=1/(sqrt(D)-1). Hence
  E_Theta W >= (1-epsilon)h - C_D/(sqrt(D)-1).                  (7)
This mean-deficit theorem differs from the pointwise one. It is obtained
directly from a full loss-CDF bound; no pointwise guarantee is assumed and no
dimension-dependent entanglement-entropy continuity error is inserted.

For fixed kappa,D and fixed epsilon<1, (7) gives
  E W >= (1-epsilon)log_D L - O_(D,epsilon,kappa)(1).
If log kappa is a charged budget and kappa<=L, it equivalently gives a loss/
resource tradeoff on the scale log(L/kappa). This does not imply a bound in
terms of E_F or an expected preselected log Schmidt rank.

5. EXACT RESOURCE SPECIALIZATIONS

Independent fixed Bell aid Phi_M: kappa=M is both achievable and minimal.
Indeed zeta=chi_M=(1/M)sum_i|ii><ii| has M zeta>=Phi_M. Conversely the overlap
of any separable zeta with Phi_M is <=1/M, so Phi_M<=kappa zeta forces
kappa>=M. Thus log kappa=log M is its total initial Bell supply. No returned
catalyst is free: (R) prices its total initial state, irrespective of what
Gamma does to it or any extra return requirement.

Independent arbitrary entangled tau: inf log kappa over separable zeta in
tau<=kappa zeta is the familiar max-relative entropy of entanglement / log
robustness. That measure and the domination machinery are KNOWN. This proof
does not need any unproved property of the measure or solve its optimization.

Perfect initial inventory access at both parties: tau_k=|kk><kk| on supplied
classical registers has kappa=L, attained by uniform zeta=(1/L)sum_k|kk><kk|;
diagonal overlaps force kappa>=L. The loss obstruction becomes vacuous, as it
must: known K permits keep-K/reset-tail exactly. A source decomposition is not
such an accessible record.

Classical access channel z with p(z|k), recorded identically at both parties:
its exact least domination factor is kappa=sum_z max_k p(z|k), by choosing
q(z)=max_k p(z|k)/kappa for the separable zeta=sum_z q(z)|zz><zz|. This is an
actual max-likelihood access constraint, not Shannon mutual information.
Erasure-style access revealing K with probability p and a common blank with
probability 1-p has kappa=1+p(L-1), whereas I(K;Z)=p log L.

For a preselected random independent Bell rank M with an accessible matching
label at both parties, a direct blockwise domination yields kappa=E M (when
finite), NOT exp(E log M). Replacing one by the other is unsupported and can
be arbitrarily false on heavy-tailed choices. These distinctions are part of
the resource definition, not a claim that these constraints are easy to
certify experimentally.

6. PRIMARY-REFERENCE / NOVELTY BOUNDARY

The proof uses product-Kraus Cauchy-Schwarz score machinery. A closely related
known theorem is Lim, Hhan, Kwon, 'Trade-off between Information Gain and
Disturbance in Local Discrimination of Entangled Quantum States', Quantum
Sci. Technol.10,025048(2025), arXiv2308.16032v3, Theorem1 and AppendixA:
  https://arxiv.org/html/2308.16032v3
Their score concerns guessing a pure-state label while retaining fidelity to
that same input state. Here the actual input is a mixed nu-tail queue, its
ideal output length is initially unknown, and the receiving step is a local
coarse last-nonzero measurement that exposes a classical length while keeping
a pure Bell prefix. The mixed-tail sum, geometric eligible-band sum and joint
loss-distribution transfer are proved explicitly above. Historical novelty of
this combination is UNKNOWN; this is not a claim to invent general local
information/disturbance tradeoffs.

The optional resource name is established in Datta, 'Max-Relative Entropy of
Entanglement, alias Log Robustness', Int.J.QuantumInf.7,475-491(2009),
arXiv0807.2536v4, read directly:
  https://arxiv.org/pdf/0807.2536
We use only the explicit separable-domination definition, proved special
cases, and positivity; it is known machinery, not a new entanglement measure.

Ghosh et al., 'Locally Accessible Information and Distillation of Entanglement',
arXivquant-ph/0403134, was checked as an alternative complementarity route:
  https://arxiv.org/pdf/quant-ph/0403134
Its displayed proof is for one-way LOCC and an entropy argument here would
lose epsilon*L. It is not used to assert the two-way fixed-error result.

7. REMAINING GAPS

The universal fixed-error logarithmic-loss boundary is resolved internally
for the specified separable receiver / separable-domination resource model,
subject to final audit. Leading constants and optimal receiver construction
are open. Expected preselected entanglement (E log M), energy-bounded aid,
source-correlated auxiliaries not product conditional on K, catalytic joint
return, and arbitrary approximate formation consequences require additional
arguments. Ordinary consumable stock has precisely the same source and law;
there is no formation advantage. The global-CPTP nonlocal control below shows
that this log L obstruction uses separability substantively, not only nested
input support or memory correlations.

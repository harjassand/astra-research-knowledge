# Attempts that changed the Cycle8 decision

## 1. Full count profiles were exact but costly

The first interface correctly retained per-color neighbor counts and far-end
flags. Its first bounded family search stopped at 150 discovered records;
the longer run stopped at 45 seconds with 1174 discovered records and 939 active
families. Neither produced an empty state family. These were resource stops,
not coloring counterexamples or evidence of an all-real recovery obstruction.
Their full results and original unprojected sources remain archived.

Projecting only degree-four saturated ports retained an exact contextual
interface, but the next 60 second run still stopped with 345 active families.
This justified changing the representation, not increasing graph fixtures.

## 2. A sound flag order was useful but memory was not free

With exact count vectors and flag-dominance pruning, a 120 second worklist run
reached 220 active families but did not finish its obligations. Unbounded
transient caches reached 2,185,433,088 bytes peak RSS. The process was stopped,
cache bounds were introduced, and its SAVED state resumed. The resumed run
closed in 67.433970355 seconds at 220 families. The first run and resume are
both charged. The resumed state is not a new independent rediscovery.

This first positive closure was retained as evidence. It was superseded for
delivery by a stronger proved quotient, not silently erased as failed work.

## 3. Actual degree and occupancy replace unnecessary exact counts

The load-bearing correction was to prove that, for already-star-valid child
colorings, new merge hazards depend only on cross-child color occupancy and
far-end flags. Exact actual total degree remains; multiplicities remain in
the graph. Support/flag dominance then yields 73 sufficient guarantee families.
The final closure took 7.922470543 seconds and has a much smaller explicit
certificate. This is not a claim that a finite palette or a solver success
proves universal existence: all literal obligations have independent witnesses
and a separate checker, with an all-depth induction.

Never apply occupancy compression to invalid syntactic child records. A
concentrated repeated color with a flag can already violate the star property.
The proof substitutes REAL valid colorings, not arbitrary count assignments.

## 4. Omitting real extensions would lose received scope

An unstubbed S/P grammar with path>=2 leaves alone has every edge incident
to a degree-two path-interior vertex. It would not contain all the existing
Cycle7 supports with adjacent branching vertices and real exterior stubs.
One-sided terminal extensions were therefore included explicitly, with exact
flags and actual degree checks. No original stub was removed.

## 5. A_L alone is not a four-query advance

The boundary witness family A_L is outside the old grammar, but an explicit
star-three control works for EVERY L>=2. Its coefficient dimension excludes
all arbitrary-real q2 designs. Thus four queries on A_L alone would lose the
query comparison. The new result derives its consequence from complete
higher-load closure and the intrinsic theorem for all two-connected
chordless width-two degree-four atoms. A5 was actually run with the stronger
three-query control, not a deliberately weaker conventional baseline.

## 6. Local validity does not imply arbitrary graph coverage

The H8 grammar still does not cover C4 with leaves at adjacent cycle vertices:
the only possible terminals are those leaves, and a terminal path has a chord.
The intrinsic atom theorem explicitly assumes two-connectivity. Independent
colorings of atoms can create a bichromatic P4 through a shared vertex. The
next rooted-interface question remains open; the present table does not grant
arbitrary attachment colors or force any marked vertex to be a legal terminal.

SAT4 is not a fifth color. Its color is existentially unspecified because its
degree budget is exhausted, not because later contexts can demand a new one.
Adjacent-terminal formulas and overlapping-child formulas are not supported.

## 7. Retained prior failures and closed methods

The Cycle6 naive even-series coloring rule still has the exact Q_h growth
witness. Cycle7 fixes its grammar; it does not provide an all-real q3 lower
on Q8. Earlier arbitrary-boundary reset/reinsertion invariants remain false.
Bounded diameter and locally stable pieces alone remain insufficient.
Degree-preserving maximal2tree completion is unavailable, and the unequal-
gain Cheeger shortcut remains retired. None is retried in this checkpoint.

Cycle5's 99 vertex squaredconstant 20 is unchanged. The closed molecular family,
NIST speed comparison, thermal/TPV/half-cell and GUIDE campaigns remain closed.
The broader mathematical mission is active. This positive atom result closes
one construction, not the unrestricted arbitrary-real four-query question.

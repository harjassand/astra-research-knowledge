# Independent finite-gate costs

One scientific gate was executed, on the final literal certificate, and passed
on its first run. The discovery search and intermediate 220-family closure
were not rerun.

* Body wall: 0.2002076990029309 seconds.
* Body CPU: 0.19994599100000002 seconds.
* Peak process RSS: 37,216,256 bytes.
* Included: actual certificate bytes read and JSON parse, syntactic family
  validation, actual path-two enumeration, independent admitted-case set,
  all 11,142 literal transition witnesses, and SHA256 input authentication.
* Excluded: process startup and final receipt serialization.
* Unknown: source reading, proof assessment, inference, checker/review
  authoring and integration totals.

All scientific checks use Python standard-library exact integers and sets.
No floating solver, package installation, paid resource, source-author
outreach, prior benchmark replay or user administration was used. The gate
does not claim that a short replay equals the cost of discovery.

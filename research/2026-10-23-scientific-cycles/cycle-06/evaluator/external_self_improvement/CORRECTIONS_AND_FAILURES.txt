CORRECTIONS, UNSUCCESSFUL APPROACHES AND SCOPE

1. Source retrieval first considered reading only GitHub metadata; evolved runs
   are in a large public archive. Exact ZIP ranges recovered the needed members
   without downloading the full archive. One initial-member HTTP503 was repaired;
   original and retry receipts are preserved. No whole-archive digest is claimed.

2. The conceptual fixed-producer control was initially described too strongly as
   operating on the same evolving code workspace. Root source inspection raised
   the discrepancy; one actual trace confirmed it. Corrected interpretation:
   producer and edited target change together locally. No aggregate blame follows.

3. The primary common10 comparison is arithmetically valid but insufficient for
   broad capability. The published task list labels it a basic functionality gate.
   A post-primary common60 sensitivity preserves missing outcomes and shows useful
   pipeline progress. The selected final edge reverses direction across these
   views. Do not select only the metric that favors a desired narrative.

4. Root's per-row new-pass field was relabelled to
   observed_child_passes_absent_from_reported_parent_passes_10 after independent
   review: an absent parent label need not be a known failure. Aggregate complete-
   pair gain calculations were already correct. No scientific count changed.

5. The legacy aggregate label unknown_child_outcome_pairs_10 denotes incomplete
   parent-child pairs. An incomplete pair can still force a direction. The fixed
   producer has7 complete-pair gains plus2 bounded incomplete gains, not9 complete
   gains. The report and independent reviews explicitly preserve the distinction.

6. Raw aggregate accuracy mixes evaluation tiers and submitted denominators.
   Comparing those values as identical-task measurements was rejected. Absent
   outcome IDs are not assigned successes or failures. Missing per-attempt cost
   receipts prevent resource-normalized rates; timeout caps are not cost data.

7. A rising retained best and a negative average mutation change can coexist.
   Neither, by itself, identifies a change in the ability to invent useful
   successors. Adaptive selection, proposal choice, targets and resources all
   vary. No causal regression, iid significance test or exponential fit was used.

8. Prospective crossed-producer experiments were not run. No paid agent execution,
   owner scientific continuation or new research platform was initiated. The new
   bounded outcome is evidence reconstruction and a substantive causal boundary,
   not a validated scientific-amplification mechanism.

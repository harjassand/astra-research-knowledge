PORTABLE DGM RECORD-ANALYSIS REPLAY

Python3 standard library only. No DGM installation, downloaded code execution,
network connection, credentials, model calls, training or agent run is needed.

Extract the common package into a fresh directory. From any working directory:
  python3 /absolute/package/external_self_improvement/analyze_lineages.py
  python3 /absolute/package/external_self_improvement/analyze_sensitivity.py
  python3 /absolute/package/external_self_improvement/verify_baseline_workspace.py
  python3 /absolute/package/external_self_improvement/independent_review/check_common10.py

The first script binds the original downloaded source members, reconstructs every
scheduled attempt, checks parent/child membership and native archive admissions,
and computes common-task quantities with missing labels unknown. The sensitivity
uses the common60 outcomes and declares its post-primary status. The trace verifier
parses the observed editor and parent patch without executing either. The final
script independently reconstructs primary counts using a different JSON lexer.

Scripts write regenerated JSON/CSV receipts beside themselves. Use a fresh copy
to preserve supplied receipts. Timing fields will vary; deterministic scientific
counts and source identities must match. The field unknown_child_outcome_pairs_10
means incomplete parent-child pairs, not necessarily unidentifiable directions.
Two incomplete fixed-producer pairs force a gain, two force a loss.

These checks reproduce calculations on historical public observations. They do
not rerun agent tasks, validate every historical execution, attribute causal
effects, establish improvement-generation growth or verify every v2 experiment.
The common10 cases were an admission set; the common60 sensitivity materially
changes interpretation. Both are retained with their limits.

Original records remain under released_metadata/. The code subset is pinned in
SOURCE_AUDIT.txt and covered by its included Apache2.0 LICENSE. Public source
attribution and selected-member retrieval receipts are supplied. The complete
1GB archive and uninspected Polyglot data are not included or claimed as replayed.

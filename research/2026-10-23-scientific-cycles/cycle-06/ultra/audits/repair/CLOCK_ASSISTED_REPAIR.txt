1. EXACT RECEIVING INTERFACE

Suppose the complete actual joint state after N queue uses is
 Omega_N=sum_{K=1}^L p_K |f_N(K),f_N(K)><f_N(K),f_N(K)|_(C_A C_B)
       tensor rho_M^K tensor Phi_D^{tensor min(K,N)}
                         tensor nu_D^{tensor(N-min(K,N))}.
Here M is ALL remaining retained memory (including any further registers), the
specified clocks C_A,C_B are physically available local registers with a known
orthogonal basis, and f_N is known and injective on the inventory support.
The actual finite queue has f_N(K)=1+((K-N-1) mod L), a cyclic decrement clock on labels 1,...,L;
N is a public description parameter of this finite receiving operation.
The equation keeps the complete K-output-memory correlations. It is stronger
than a claim about the output marginal or an unknown memory dimension.

A locally copied classical clock identifies K nondestructively, since its actual
state is diagonal in the stated basis. No tomography or inaccessible dimension
inference is used. The specification, basis access and compiled local control
are extra hypotheses; they are not certified by the ordinary output witness.

2. SIMPLE PRODUCT-TAIL REPAIR

For each K let R_K be the local product channel which leaves output slots i<=K
unchanged and replaces every local output slot i>K by |0><0|. This is a CPTP
channel, with no postselection, communication, fresh shared entanglement, or
additional shared randomness. Apply it controlled by each party's clock value
f_N(K). Both parties have the same value, so the resulting complete state is
 Omega'_N=sum_K p_K |f_N(K),f_N(K)><f_N(K),f_N(K)|
       tensor rho_M^K tensor Phi_D^{tensor min(K,N)}
                         tensor |00><00|^{tensor(N-min(K,N))}.             (1)

All branches remain in this density, and every initial or retained shared
register is still counted. The complete retained-memory marginal, including
both clocks and M, is EXACTLY unchanged. More generally this marginal identity
holds for any state diagonal in the specified control basis, because every
conditional output channel is trace preserving:
 Tr_out R_control(Omega_N)=Tr_out Omega_N.
No unchanged-memory claim is made for a hypothetical coherently superposed
clock. No output-memory product or decorrelation is asserted.

For a fixed K and prefix i, the Bell-prefix probabilities before and after are
 p_i^K=1 (i<=K), D^{-2(i-K)} (i>K),
 p_i'^K=1 (i<=K), D^{-(i-K)} (i>K).
Thus EVERY prefix score weakly improves, conditionally and unconditionally.
For every K, its total per-task score increase is at most
 m sum_{h>=1}(D^{-h}-D^{-2h})=m D/(D^2-1),
so the receiver changes the original multiscale task score by only O_D(1);
it cannot manufacture an extensive favorable score from the reset tail.
The first emitted exact Bell pair stays exactly Bell. This is not a noisy-output
relaxation, although its optional local receiving operation is dissipative.

Every branch in the output marginal of (1) is supported on
 W_MC=span{|x>_A tensor|x>_B:x in {0,...,D-1}^N}.
So is every mixture and every iid tensor power of these outputs. A complementary
Alice computational-basis measurement fixes Bob's complementary string exactly:
projecting Alice's complementary indices to y restricts Bob to that SAME y.
Therefore Q_a=0 for every task of the r-output witness, with no support-distance
or compatibility-gap argument and without optimizing an E_F convex roof.
Every mixed ensemble is covered by the existing universal Cycle5 theorem.

3. OPTIONAL MARGINAL-PRESERVING CHI TAIL

One may instead replace each exhausted pair by
 chi_D=(1/D)sum_t |tt><tt|.
It has the same local I/D marginals as nu_D, remains maximally correlated,
and gives the same Bell overlap 1/D as |00>. Alice measures the exhausted
A slot in the computational basis, sends its D-valued outcome t to Bob, and
Bob locally overwrites his slot by |t>. Both retain or erase their local work
copies by an explicitly specified operation; every t branch is included.
There is at most one log_2 D-bit classical message per exhausted pair, no
initial shared entangled resource, and no need for supplied shared randomness.
Outcome records may be exposed as finite classical output ports. If copies are
retained in memory, they must be counted there; their added-memory return does
not follow from the original clock argument. The simpler |00> version avoids
these message/record issues entirely.

4. CONCRETE FINITE CIRCUIT AND HONEST ENTROPY EXPORT

For the cyclic clock use b=ceil(log_2(max(2,L))) local clock bits. A local work
register initialized to zero copies the clock basis value. Use the zero-based clock value c-1 and reversibly add the known constant
N modulo L to obtain K-1 in that work register; add one if a one-based
comparator is used. For each public
index i, compute [i>K] into a one-bit control, conditionally SWAP the output
D-site with a fresh local |0> D-site, then uncompute the comparison bit.
After all slots, undo the modular addition/label conversion and clock copy. All computational
work is returned EXACTLY to zero using the unchanged clock. This construction
is a finite local CPTP circuit when the noise-bearing swap environments are
traced out. A nondestructive local clock readout plus classical comparisons
implements the same channel on the admitted cq state.

For fixed D the Boolean work costs O((N+1)b) reversible elementary gates per
party, plus at most N controlled D-site swaps, O(b) reusable work bits, and
at most N fresh pure D-sites and N discarded D-sites per party. For nonbinary
D specify an exact D-level swap or its chosen encoding; no precision cost is
silently suppressed. For an arbitrary f_N, inverse-table synthesis is an extra
cost, so the cyclic O(Nb) bound is not asserted for an unspecified inverse.

The entropy export is real. Conditional on K, the |00> version transfers
2m (N-K)_+ of pre-existing product entropy into the two local discarded
noise environments. Its expected conditional export is 2m E[(N-K)_+].
For K uniform and N<=L, this is m N(N-1)/L. The chi-tail version can export
only Bob's old private m (N-K)_+ entropy while converting Alice's existing
noise into shared classical labels, but uses the communication specified above.
These are entropic/export counts, not a thermodynamic work estimate.

If the noise-bearing environment registers are RETAINED as part of the new
memory, their dimensions, correlations, entropy and return error MUST be added.
The unchanged original memory marginal does not certify return of that enlarged
memory. Hence this operation is not advertised as a closed all-unitary repair
or a physically free eraser. In the ordinary LOCC resource model local pure
ancillas and local discard are permitted, and their shared-entanglement cost is
zero. Physical usefulness requires pricing the stated control, pure ancillas,
entropy export, and access interface. No experimental validation is supplied.

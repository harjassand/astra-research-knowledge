1. UNFLAGGED QUEUE: PASS UNDER THE INHERITED FACTORY CONTRACT

The fixed reuse channel emits the first local pair-slot, relabels the
remaining L-1 slots to the left, and appends a fresh product nu. It is a
finite-dimensional one-outcome product CPTP channel; no communication or
postselection is used. Local replacement by I_D/D is free local state
preparation, with all of that channel's Kraus outcomes averaged. No
entangled or shared resource arrives during reuse.

Every omega_k, k>=1, has first pair Phi, so the first complete output is
EXACT Phi and factors from all retained memory. The memory channel sends
omega_k to omega_(k-1), including omega_0 to omega_0. Therefore

 tau'_L-tau_L=(omega_0-omega_L)/L,
 T(tau'_L,tau_L)=(1-D^(-2L))/L=:delta_L.

Here T=half trace norm. The last equality is exact: omega_L is a pure
state and omega_0=I_(D^(2L))/D^(2L), hence their commuting difference has
one eigenvalue 1-D^(-2L) and D^(2L)-1 eigenvalues -D^(-2L).
This computes the COMPLETE retained memory return, not a marginal return.

The inherited exact preselected-supply factory definition explicitly
samples its input-resource branch before supply and permits discarding
the label only when genuinely unavailable later; every retained shared
register belongs to tau and its return test. See unchanged
work/Restore/principal/PROOF.txt, section 1, paragraph beginning
"An exact variable-resource factory FIRST samples ...".

Thus a factory may choose K uniform in {1,...,L}, receive K Bell pairs,
place them in the first K slots, and prepare product nu in the remainder.
It must erase every reusable record of K before claiming the unflagged
state tau_L. Every branch is included with probability 1/L. Its exact
preselected expected supplied cost is

 C_sup <= L^(-1) sum_(k=1)^L k m=(L+1)m/2.

This is an upper bound, not an optimality claim. It is not a deterministic
fixed-rank supply of that cost, not an iid formation theorem, and not a
postselected successful branch. A deterministic supply of L Bell pairs
also prepares tau_L by discarding surplus entanglement, with charge Lm.

2. IF AN IMMUTABLE PREPARATION FLAG IS RETAINED, THE CLAIM NEEDS A CHANGE

Suppose the complete memory instead contains a flag |k,k> and the device
leaves it unchanged. The old and new memory are block diagonal in k,
and in branch k the only change is Phi becoming nu in slot k. Consequently

 T(tauhat'_L,tauhat_L)=1-D^(-2),

independent of L. The small 1/L return would then be false. An additional
immutable preparation transcript anywhere in retained shared memory has
this same obstruction. Erasing a flag from the notation is insufficient.

There is an explicit FLAG-COUNTING CORRECTION that avoids relying on an
unflagged runtime memory. Retain matching local copies of the current
flag J in {1,...,L}, with initial state

 tauhat_L=L^(-1) sum_(k=1)^L |k,k><k,k| tensor omega_k.

In addition to the shift/replacement channel, update BOTH current flags
cyclically, j -> j-1 for j>=2 and 1 -> L. This update is a local
permutation, so it need not retain an old flag or measurement outcome.
For new label j<L the resulting memory is exactly omega_j. Only new
label L differs, carrying omega_0 in place of omega_L. Thus

 tauhat'_L-tauhat_L=
 L^(-1)|L,L><L,L| tensor(omega_0-omega_L),
 T(tauhat'_L,tauhat_L)=delta_L.

This version includes the actual current shared flag in both initial
state and complete return test, has the same exact first Bell output,
and has the same preselected expected upper cost. It does not promise
small return conditioned on an immutable historical label. If such a
history is retained as an extra register, it must also be counted and
the small-return conclusion fails. The cyclic update supplies no new
entanglement: once the physical stock is exhausted, changing its label
does not refill it.

3. FULL OUTPUT LAW AND CORRELATIONS: PASS

At any N>=L, the complete N-pair external state is

 rho_N=L^(-1) sum_(k=1)^L Phi^tensor k tensor nu^tensor(N-k).

For a general N, replace k by min(k,N) in that expression. This is a
joint mixture, not a product of pair marginals. Before exhaustion, its
prefix and the remaining memory are correlated through the same K;
those correlations must remain in any joint resource argument. After
N>=L calls the physical memory is exactly omega_0 and factors from the
outputs. The optional cyclic flags remain correlated with the history
and outputs and must be counted when discussing complete retained
memory; tracing them for the external output state is legitimate.

At N=L+1 in particular,
 rho_(L+1)=rho_L tensor nu.
Thus the terminal Bob output is I_D/D, independent of every other
output, of Alice, and of the optional current flags. This last claim
does not assume independence among the preceding L outputs.

For r independently prepared queue outputs sigma=rho_(L+1)^tensor r,
fix any task a and any joint Alice-complement POVM with classical label
Y_a. The r-1 terminal Bob slots outside task a remain an independent
maximally mixed tensor factor after every outcome. Since cq conditional
entropy of the remaining Bob system is nonnegative,

 Q_a(sigma)=S(B_complement a|Y_a)>=(r-1)m,
 Qbar(sigma)>=(r-1)m,

even after optimizing over EVERY Alice-complement POVM. This is an
admitted ordinary queue counterexample to a universal bound on that
particular optimized complementary penalty independent of r. Its supply
cost is ordinary (L+1)m/2 per queue; it demonstrates no resource saving.
Any repaired resource argument must avoid charging these irrelevant
locally mixed terminal factors, or establish another structural premise.

SPECIFIED OPERATION, INPUTS, RETURN, ERROR AND COST INTERFACES
22 October 2026. The actual complete proof is PROOF.txt, not this summary.

1. ORIGINAL REUSE DEVICE (COUNTEREXAMPLE)
Parameters D>=2,L>=1; memory dimension L D^L per party, current clock included.
Known faithful free product external input nu=I/D tensor I/D each call.
Each party unitarily rotates input and L memory slots, emits slot1, decrements
its L-valued cyclic clock. One outcome, zero communication, no reuse discards.
All joint branches are Omega_t in PROOF(1.3). First ideal output exact Phi_D.
Return is COMPLETE marginal half-trace error delta=(1-D^-2L)/L, not a return
conditioned on an uncounted immutable original inventory. This is finite
approximate reuse and eventual stock exhaustion, not recurrence.

2. SUPPLY AND INITIALIZATION
Normal LOCC from Phi_M costs lnM. A random rank may be genuinely selected BEFORE
receipt and costs its complete expectation ElnM; every branch is averaged.
Every shared catalyst/retained register counts. Error epsilon is GLOBAL on all
r complete initialized memories; it is distinct from ideal one-use return delta.
Exact supply frontiers(3.2),(3.3) allow approximate flags to be biased optimally.
The finite Bell success tests used in their converses are mathematical effects,
not experimentally local hidden-memory certification interfaces.
Known resource parameters are premises of this specified model. External output
statistics alone do not verify complete memory return, absence of retained
records, incoming entanglement, or an untrusted factory's supply rank.

3. ADDITIONAL SPECIFIED CONTROLLER INTERFACE
After public horizon N, an explicitly addressable local current-clock register
and its known basis are supplied by this architecture. Zero-based inverse adds
N modulo L. On output slots i>K, each party swaps with a fresh pure D-ancilla
and discards the old noise; earlier slots remain untouched. Copy/control work
is reversibly cleared. The map is a CPTP LOCAL joint memory-output operation,
not an output-only transformation or an unpriced black-box readout operation.
Complete memory marginal is unchanged for the stated diagonal clock state.
If reset garbage is retained instead of discarded, it joins complete memory;
return for that enlarged memory has NOT been established. The repair is not
all-unitary and is not silently folded into the original fixed-port device.

At most N pure D-ancillas/swaps/discards per party, no communication or shared
entangled ancillas for the |00> repair. Modular arithmetic/comparison and gate
synthesis cost depends on representation; an explicit finite control circuit
is in audits/repair/CLOCK_ASSISTED_REPAIR.txt. Naive branch-table control uses
O(NL) tests; for fixed D standard reversible modular control is O((N+1)log L)
Boolean work with clock encoding conventions. N may be reduced modulo L first.
Conditional exported product entropy is 2lnD E(N-K)_+. Physical work of resets,
calibration, pure-state preparation and entropy disposal is UNKNOWN, not zero.

4. ACTUAL INITIALIZATION AND PENALTY
For arbitrary global initialization error epsilon, the specified receiver gives
 Csup/r>=m A_N(delta)-C_D-Qbar(actual repaired output)-mN epsilon.
A proximity statement alone does not transfer ideal Q=0. Our explicit typical
factory samples Kvec, prepares exact Bells if S<=t, otherwise |00> on ALL nominal
active pairs; remaining memory pairs are nu. Global error <=Pr[S>t], supply t m.
After the receiver every branch is globally maximally correlated, even though
fallback correlates all tasks. Thus actual Q=0 without any free continuity bound.
The ideal device's first output remains exact; the global initializer error
boundary is paid by mN epsilon. No new noisy-output task is introduced.

5. COMPUTATION AND REPLAY
The exact stock inventory distribution uses integer polynomial convolution.
The deterministic rank error uses increasing-inventory greedy allocation.
The expected-supply LP has 2[r(L-1)+1] rational variables. coefficients D^s have
O(rL log D) bits; inventory numerator size O(r log L). Physical isotropic twirls
in the achieving factories can have large finite synthesis cost. Small LP size
is not evidence that a physical preparation is cheap.

THREE CAPPED QUERIES FAIL UNIFORMLY ON TREEWIDTH TWO
Investigator: independent arm A of the bounded known-sparsity trial.

Finish UTC: 2026-10-21 15:24:01 UTC.

PRIMARY ENDPOINT: NO.

An explicit obstruction is the square of a path, already of maximum degree four.
The proof below quantifies over every real dense three-column query block. It
uses an adjoint dimension argument to construct a small NONZERO singular value,
then pays the full sqrt(n) loss needed to pass to operator norm. No coloring
restriction, unit-row restriction, or exact-identification surrogate is imposed.

1. PRECISE THEOREM

For m >= 1 put n = 8m and let G_m have vertex set {1,...,n}, with an edge
{i,j} exactly when 1 <= |i-j| <= 2. Let S_m be the real vector space of
symmetric n-by-n matrices supported on these edges and on all diagonal entries.
For any X in R^(n x 3) with row norms at most one define

  K_2(X) = sup_{0 != D in S_m} ||D||_2 / ||DX||_F,

with K_2(X) = infinity if a nonzero supported D has DX = 0. Then

  K_2(X) >= max{1, n^(1/4) / sqrt(24 sqrt(5))}.

Consequently

  inf_{X in R^(8m x 3), max_i ||x_i|| <= 1} K_2(X)
       >= max{1, (8m)^(1/4) / sqrt(24 sqrt(5))} -> infinity.

The bags {i,i+1,i+2}, i=1,...,n-2, in their natural path order constitute a
width-two tree decomposition: every edge is covered and the bags containing
any vertex are consecutive. Also Delta(G_m) <= 4. This is therefore a
negative answer even with uniformly bounded maximum degree.

A supplementary sharper statement with a row lower bound is

  K_2(X) >= max{1/r, r sqrt(n)/(24 sqrt(5))},
  r = min_i ||x_i|| > 0.

In particular unit-row designs have K_2(X) >= sqrt(n)/(24 sqrt(5)).
No sharpness of the constants or exponents is asserted.

2. HILBERT-SPACE ACTION MAP AND THE DIMENSION COUNT

Equip S_m with the Frobenius inner product and equip R^(n x 3) with the same
inner product. Define L_X(D) = DX. The graph has (n-1)+(n-2)=2n-3 edges, so

  dim(S_m) = n+(2n-3) = 3n-3.

If X has a zero row, its corresponding diagonal matrix unit is invisible and
the theorem holds. More generally, if L_X is not injective, the theorem holds.
Hence it suffices to consider r > 0 and injective L_X. In this case its adjoint
has a kernel of dimension exactly three, because its domain has dimension 3n
and its rank is 3n-3.

Write each query row as x_i^T with x_i in R^3. If Y has rows y_i^T, then

  L_X^*(Y) = P_G sym(Y X^T),

where sym(B)=(B+B^T)/2 and P_G retains the allowed diagonal and edge entries.
Indeed <Y,DX>_F = <sym(YX^T),D>_F for symmetric D. Explicitly,

  [L_X^*(Y)]_ii = y_i dot x_i,
  [L_X^*(Y)]_ij = (y_i dot x_j + y_j dot x_i)/2   on edges.

This projection, these Hilbert metrics, and the factor 1/2 are essential.

3. LOCALIZED SKEW-ROTATION FIELDS

Use the following three skew-symmetric matrices:

  A_12 = [[0,-1,0],[1,0,0],[0,0,0]],
  A_13 = [[0,0,-1],[0,0,0],[1,0,0]],
  A_23 = [[0,0,0],[0,0,-1],[0,1,0]].

Each has operator norm one, and for every x in R^3,

  ||A_12 x||^2 + ||A_13 x||^2 + ||A_23 x||^2 = 2 ||x||^2.

Let f be any real scalar function on the vertex indices and choose one such A.
Define Y(f,A) by y_i = f_i A x_i. Skew symmetry makes all diagonal entries of
L_X^*(Y) zero. On an edge {i,j} its entry is

  (f_j-f_i) (x_i^T A x_j)/2.

Therefore, with one copy of each unordered edge,

  ||L_X^* Y(f,A)||_F^2
    = (1/2) sum_{edges {i,j}} (f_j-f_i)^2 (x_i^T A x_j)^2
    <= (1/2) sum_{edges {i,j}} (f_j-f_i)^2.                 (1)

The inequality uses only ||x_i|| <= 1 and ||A||_2 = 1.

For k=1,2,3,4 set c_k=(2k-1)m and define, on all integer indices,

  f^(k)_i = max{0, m-|i-c_k|}.

On vertices 1,...,8m these four functions have disjoint nonzero supports.
Their squared sums are all

  sum_i (f^(k)_i)^2 = m^2 + 2 sum_{j=1}^{m-1} j^2
                         = (2m^3+m)/3 >= 2m^3/3.          (2)

For each k, summing the squared norm of Y(f^(k),A) over the three choices of A
and using r <= ||x_i|| yields

  sum_A ||Y(f^(k),A)||_F^2
     = 2 sum_i (f^(k)_i)^2 ||x_i||^2
     >= 2 r^2 sum_i (f^(k)_i)^2.

Choose A_k attaining at least one third of this sum and put
Y_k = Y(f^(k),A_k). By (2),

  ||Y_k||_F^2 >= (4/9) r^2 m^3,
  ||Y_k||_F   >= (2/3) r m^(3/2).                         (3)

Every Y_k is nonzero, and the four Y_k are mutually orthogonal because their
row supports are disjoint. The matrices A_k may depend on X; the argument is
valid for every X, which is exactly the required lower-bound quantifier.

4. BOUNDING THE ADJOINT RESIDUALS

For an integer tent f as above, extend it by zero to the whole integer line.
Its successive differences are +/-1 on 2m steps and zero elsewhere, giving

  sum_{i in Z} (f_{i+1}-f_i)^2 = 2m.

By (a+b)^2 <= 2a^2+2b^2,

  sum_{i in Z} (f_{i+2}-f_i)^2
       <= 4 sum_{i in Z} (f_{i+1}-f_i)^2 = 8m.

The graph edges comprise a subset of these distance-one and distance-two
pairs. Hence (1) gives

  ||L_X^* Y_k||_F^2 <= (1/2)(2m+8m) = 5m.

Combined with (3),

  ||L_X^* Y_k||_F <= [3 sqrt(5)/(2 r m)] ||Y_k||_F.       (4)

Let W = span{Y_1,Y_2,Y_3,Y_4}, a four-dimensional space. For any
Y=sum_k alpha_k Y_k, the triangle inequality, (4), Cauchy-Schwarz on four
terms, and orthogonality give

  ||L_X^* Y||_F
    <= [3 sqrt(5)/(2 r m)] sum_k |alpha_k| ||Y_k||_F
    <= [3 sqrt(5)/(r m)]
           (sum_k alpha_k^2 ||Y_k||_F^2)^(1/2)
     = [3 sqrt(5)/(r m)] ||Y||_F.                         (5)

No orthogonality of the residuals is presumed; the factor two pays for their
possible overlap at neighboring block boundaries.

5. A SMALL NONZERO SINGULAR VALUE

Because dim W=4 but dim ker(L_X^*)=3, there is a nonzero vector

  Y in W intersect (ker L_X^*)^perp.

For clarity, imposing orthogonality to a three-dimensional kernel imposes at
most three homogeneous linear constraints on the four-dimensional W. Thus
this intersection contains a nonzero vector. By (5) that vector has adjoint
Rayleigh quotient at most 3 sqrt(5)/(r m).

For an injective finite-dimensional linear map, the smallest singular value
of L_X equals the smallest singular value of L_X^* restricted to
(ker L_X^*)^perp. Therefore

  sigma_min(L_X) <= 3 sqrt(5)/(r m).

Equivalently there is a nonzero supported symmetric D with

  ||D||_F / ||DX||_F >= r m/(3 sqrt(5))
                           = r n/(24 sqrt(5)).           (6)

This is an existence proof over all query blocks, not a numerical singular
value observation. It explicitly excludes the three automatic zero adjoint
singular directions before drawing the conclusion.

6. OPERATOR NORM AND ALL CAPPED ROW NORMS

For every real symmetric n-by-n matrix D,

  ||D||_F <= sqrt(n) ||D||_2.

Apply this inequality to the D supplied by (6). The operator inverse constant
therefore obeys

  K_2(X) >= r sqrt(n)/(24 sqrt(5)).                       (7)

Independently, choose i with ||x_i||=r and D=e_i e_i^T. Its operator norm is
one and its action Frobenius norm is r, so

  K_2(X) >= 1/r.                                        (8)

For positive numbers, max{a,b} >= sqrt(ab). Combining (7) and (8) eliminates
r WITHOUT any monotonicity assumption about row scaling:

  K_2(X) >= sqrt[(1/r)(r sqrt(n)/(24 sqrt(5)))]
          = n^(1/4)/sqrt(24 sqrt(5)).

Also r <= 1 implies K_2(X) >= 1. The cases of zero rows and noninjectivity
were already handled. This proves the displayed infimum-over-all-X theorem.

7. RECOVERY CONSEQUENCE, COST, AND EXACT SCOPE

Any exact decoder with a uniform operator-error guarantee from absolute
Frobenius action noise would imply the same inverse inequality: compare zero
input and D with noise -DX, using that exact recovery fixes the decoder's
output at zero data. Thus no three-query design and decoder can have the
requested dimension-independent error factor over all treewidth-two supports.
This conclusion covers arbitrary real dense designs, all row lengths in
[0,1], all supported real symmetric perturbations, and the specified operator
recovery target. The obstruction uses graphs of degree at most four.

The proof does not claim a sharp growth exponent, an optimal constant, or an
impossibility for four or five queries. The supplied six-query upper bound
remains compatible. Generic three-query exact identification also remains
compatible: the result concerns conditioning as n grows.

For a particular finite X, a witness D can be obtained from an orthonormal
supported-symmetric matrix representation of L_X: diagonal basis matrices
E_ii and edge basis matrices (E_ij+E_ji)/sqrt(2). If the map is singular,
choose a nonzero kernel vector; otherwise choose a right singular vector for
its smallest singular value. A conventional dense SVD uses polynomial work
(O(n^3)) and O(n^2) storage. This is an existence/witness procedure, not a
claimed efficient stable decoder or a calculation used to establish the
asymptotic theorem.

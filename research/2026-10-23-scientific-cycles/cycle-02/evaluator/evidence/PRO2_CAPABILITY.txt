D. Universal path obstruction and constructive forest recovery.

For symmetric tridiagonal matrices including diagonals, two-column X with EVERY row norm exactly one, and absolute Frobenius action error, the owner proves

  inf_X sup_{D != 0} ||D||_F / ||DX||_F
      = 1/[sqrt(2) sin(pi/(2n))].

The important representation is a flow: edge coefficients b_i=c_i/det(x_i,x_{i+1}), with diagonals cancelling parallel components. Then (DX)_i=(c_i-c_{i-1})Jx_i. A sine flow proves the sharp universal Frobenius lower bound for arbitrary dense query rows; a tent flow gives a growing operator-norm lower bound. Alternating coordinate rows attain the Frobenius optimum, while three periodic colors give an isometry. [O/PROOF.md:397–479; O/research/checks/check_path_stability.py:20–34]

The exact sharp formula fails when row norms are only capped by one. An independent challenge supplied an exact n=4 endpoint-shrink counterexample; the owner retained the sharp theorem only for unit rows and proved weaker growing bounds under the cap. In particular the operator inverse factor grows at least max(1,(floor(n/2)/2)^(1/4)). This distinction matters because the current continuation uses the cap, not equality. [O/PROOF.md:486–519; O/research/notes/path_stability_extensions_challenge.md:52–149]

6. ONE NON-SATURATED OBLIGATION FOR A CONTROLLED META-RESEARCH EXPERIMENT

Use the owner's already chosen unresolved boundary, without centrally choosing a replacement programme:

  For each known graph G of treewidth <=2, diagonals allowed, choose
  X_G in R^(n by 3), with ||(X_G)_i||_2 <=1. Does a universal finite C exist
  such that ||D||_2 <= C ||D X_G||_F for every symmetric D supported on G?

The positive obligation is a genuine construction and a global bound independent of n and degree, preferably with an explicit decoder from DX+E. The negative obligation is an explicit growing treewidth-two counterfamily G_n and a proof that

  inf_{X: row cap 1} sup_{0 != D supported on G_n}

Either would change the actual q3-versus-known-q6 research decision. One favorable fixed X, one finite bad example, a coloring obstruction, an exact-rank proof, or a rediscovery of q6 does not meet it. A useful candidate representation, derived algebraically by this investigator and NOT a new accepted owner theorem: for nonzero row vectors x_i and symmetric edge coefficients b_ij, choose

  a_i = -sum_j b_ij <x_i,x_j>/||x_i||^2.

Then the i-th action row is the sum of b_ij times the projection of x_j perpendicular to x_i. The path flow is the one-dimensional transverse special case. In three coordinates the transverse space is two-dimensional; constructing a global small-residual supported stress while retaining a large operator norm is the hard missing step. Zero rows separately yield an unobserved diagonal. This identity is a possible transfer interface, not evidence that the universal q3 lower bound follows. Do not score the identity itself as resolving the obligation.

Sharper intervention aligned with the meta-research hypothesis: bypass a uniformly stable Frobenius/all-coefficient inverse while preserving the owner's weaker, actual OPERATOR-error endpoint. The archive's positive forest and six-color constructions prove the stronger Frobenius bound; that stronger bound need not be a necessary prerequisite for a q3 operator bound. The existing actual X9 example already warns that qualitative coefficient identifiability is not the endpoint.

An exact candidate dual-certificate interface is as follows. Let P_G be orthogonal projection onto symmetric matrices supported on G, with the diagonal retained. Given G, a three-column row-capped X and a vector v, construct Z with three columns such that

  P_G sym(Z X^T) = P_G(v v^T),
  ||Z||_F <= C ||v||_2^2.

For every supported symmetric D, exact trace algebra gives

  v^T D v = <Z, D X>_F.

Therefore a construction valid for ALL v, with the same universal C, certifies ||D||_2 <= C||DX||_F directly. It does not require ||D||_F <= C||DX||_F. This is an algebraic candidate interface proposed by this investigator, not a capability already implemented in the owner archive or a solution to the q3 frontier. For rational finite inputs the checker can verify the projected adjoint equation and squared-norm allowance exactly. A finite set of v witnesses cannot certify the all-v requirement; the synthesis layer needs a parameterized construction and a proved uniform bound.

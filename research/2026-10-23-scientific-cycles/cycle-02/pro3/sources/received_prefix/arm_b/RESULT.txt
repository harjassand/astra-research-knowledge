FULL IMPOSSIBILITY FOR UNIFORM NULL-FAMILY FRACTIONAL SAVINGS
Live prefix-stopping trial, arm B

STATUS
A complete analytic impossibility proof under the frozen contract. In fact,
on an explicit sequence of public null instances, every uniformly safe
stopping family must use at least n_safe(epsilon)-O(1) candidates in
expectation. This rules out every fixed fractional saving rho<1. The proof
also supplies a finite stopped-history/capture tradeoff. No numerical
experiment or external theorem about adaptive prefixes is used.

1. EXACT STATEMENT AND CONTRACT

Fix K>0 and 0<alpha<1, and write
  beta=1-alpha,
  b_K=1-exp(-K), lambda_K=-log b_K,
  gamma=beta/(1-alpha*b_K),
  n=n_safe(epsilon)
   =max(1,ceil(log(gamma/epsilon)/lambda_K)+1).
In particular the requested K=1, alpha=1/2 are covered.

Consider any family of stopping rules satisfying the specified candidate-
only target oracle, public labelled q and public symmetric proposal Q,
ordinary IMH prefix, actual output X_T, scale invariance, and
  1 <= T_epsilon <= 2 n_safe(epsilon)
almost surely. Candidate identities, exact q values, repeated identities,
all acceptance uniforms and private randomization are retained. The prefix
has no local transition/acceptance oracle and no target queries at unseen
states. After stopping, each instance uses its fixed ordinary-MH local
kernel L_pi and C_pi=(I+alpha G+beta L_pi)/2.

THEOREM. Suppose that for all sufficiently small epsilon the rule has the
uniform safety guarantee at the single prescribed time
  t_epsilon=ceil(exp((K+1)/epsilon)):
  sup_(q,w_tilde,Q) TV(Law(X_T) C_pi^t_epsilon,pi) <= epsilon.
Then there is an explicit sequence of finite public pairs (q_epsilon,
Q_epsilon), independent of the stopping rule, such that under the null
pi=q_epsilon, with the supplied certificate still K and raw weights 1,
  E_0[T_epsilon] >= n_safe(epsilon)-C_(K,alpha)
for all sufficiently small epsilon, where one possible constant is
  C_(K,alpha)=3+log(9/beta)/lambda_K.
Consequently
  liminf_(epsilon->0) sup_(public q,Q)
       E_(pi=q)[T_epsilon]/n_safe(epsilon) >= 1.

The requested safety property holds for every zeta>0 and hence includes
zeta=1 used here. Its conjunction with the requested null-family condition
limsup sup E_0[T]/n_safe <= rho<1 is therefore impossible. This proves the
full primary impossibility, not merely a restricted range of rho.

This is a necessary prefix-cost result. It makes no new claim about a
matching subsequent-time coefficient for arbitrary random prefixes. The
inherited deterministic T=n_safe supplies the admissible upper comparator.
The theorem does not assert that a fixed finite q, every easy instance, or
an oracle permitting off-proposal target queries needs this many draws.

2. A FINITE TRADEOFF FOR THE ACTUAL STOPPED HISTORY

The following construction and bound are the proof mechanism. Let M be a
deterministic candidate cap. Take integers 1<=k<m with k>=M^2, set b=k/m,
and choose p,kappa>0. Define
  r=p exp(-kappa/p),
  s=p exp(-2 kappa/p),
  c=1-p-s.
Assume the parameters are sufficiently small that c>0, 0<r<1,
  s <= b(1-r),       s <= bp,
  kappa-log(1-b)-log(1-r) <= K.
All these conditions will be verified for the theorem's explicit choices.

2.1 Public inputs, null target, and hidden target family

The known labelled space consists of pairs
  a_1,...,a_m, z_1,...,z_m.
The public normalized proposal is
  q(a_j)=(1-r)/m,    q(z_j)=r/m.
The public symmetric local proposal is the involution
  Q(a_j,z_j)=Q(z_j,a_j)=1
for each j, with all other entries zero. Thus the pairing, both label
groups, their exact masses, and the complete table of q and Q are public.
Reducibility of this Q is permitted by the contract. The full C includes
the global component.

The null oracle has w_tilde_0(x)=1 at every label, so pi_0=q. The same
positive certificate K is supplied under this null.

For each subset S of {1,...,m} of size k, define the positive target pi_S by
  pi_S(a_j)=s/k             if j is in S,
  pi_S(a_j)=c/(m-k)         if j is outside S,
  pi_S(z_j)=p/m             for all j.
Let W_S=pi_S/q. Set the raw oracle function to
  w_tilde_S(x)=W_S(x) / [s/(b(1-r))].
Its finite positive normalizer is Z_S=b(1-r)/s; normalizing indeed gives
pi_S. The rule is not supplied this normalizer. Crucially,
  w_tilde_S(a_j)=1 for j in S,
exactly the raw null value, rather than just a value equal up to an
undisclosed comparison convention.

All S share the same public space, q, Q, K, alpha, epsilon and oracle
interface. S is only encoded in target values that the rule must acquire
through counted iid candidates. The derived L_pi tables can differ,
precisely as allowed by the frozen prefix-access contract.

The forward KL is exactly
  D(pi_S||q)
   = kappa
     +s log(s/[b(1-r)])
     +c log(c/[(1-b)(1-r)]).
This expression is independent of S. Since s/[b(1-r)]<=1 and 0<c<1,
  D(pi_S||q)
   <= kappa-log(1-b)-log(1-r) <= K.
Here c log c<=0 and -c log((1-b)(1-r))
<=-log((1-b)(1-r)). Every finite member is admitted and strictly positive.

2.2 Matching the full stopped transcript

Fix any candidate-only rule with 1<=T<=M for these public inputs. Write
  tau=T under the null,     d_0=E_0[tau].
Generate the null and every hard instance with the same iid q candidate
stream, the same IMH uniforms, and the same private randomization. Define
F_S to be the event that all null candidates Y_1,...,Y_tau are ordinary
labels a_j with j in S.

On F_S, all observed raw weights equal 1 in both instances. Every prefix
IMH proposal is accepted in both instances, so all states, raw weights,
q values, uniforms, acceptance outcomes and rule decisions coincide at
every time through tau. The stopping-time property then gives
  T under pi_S = tau on F_S,
  X_T under pi_S = Y_tau in {a_j:j in S} on F_S.
In particular, if mu_S is the actual unconditioned stopped output law,
  mu_S({a_j:j in S}) >= P_0(F_S).                    (2.1)
This includes all branches and all private randomization; it does not
condition away a false-stop event.

To lower-bound this probability for some fixed S, average S uniformly over
all k-subsets, independently of the entire null experiment. Conditional
on a realized full null stopped transcript with only ordinary labels, let
D be its number of distinct ordinary indices. Its inclusion probability is
  P_S(F_S | transcript)=(k)_D/(m)_D,
where (u)_D=u(u-1)...(u-D+1). Because D<=tau<=M and k>=M^2,
  (k)_D/(m)_D
   = b^D product_(j=0)^(D-1) [(1-j/k)/(1-j/m)]
   >= b^D product_(j=0)^(D-1) (1-j/k)
   >= b^D [1-D(D-1)/(2k)]
   >= (1/2) b^D
   >= (1/2) b^tau.                                  (2.2)
The product inequality follows by induction from
(1-u)(1-v)>=1-u-v for u,v in [0,1]. If a rare label was observed before
tau, the conditional inclusion probability is zero.

Let A denote no rare label among Y_1,...,Y_tau. Since tau<=M,
  P_0(A^c)<=P_0(some rare label among the first M candidates)<=Mr.
As 0<b^tau<=1 and x -> b^x is convex, averaging (2.2) gives
  average_S P_0(F_S)
    >= (1/2) E_0[1_A b^tau]
    >= (1/2) [E_0[b^tau]-Mr]
    >= (1/2) [b^d_0-Mr].                             (2.3)
There is therefore at least one deterministic S with the last lower
bound. Arbitrary label-dependent stopping, known proposal masses,
duplicates, computations on Q, and private randomization are all allowed
inside the conditional transcript in this argument.

Jensen is applied to the exact stopped-history expression E_0[b^tau].
No deterministic prefix law is evaluated at E_0[tau].

2.3 One local capture and subsequent retention

Use the S obtained above. Let R={z_1,...,z_m}; pi_S(R)=p. From any low
ordinary a_j, j in S, its paired rare label has
  pi_S(z_j)/pi_S(a_j)=bp/s >=1.
The first subsequent C transition therefore moves from a_j to z_j with
probability at least beta/2, by selecting the local MH component.

At z_j with j in S, its normalized importance weight is W_S(z_j)=p/r.
For the global IMH step, the probability of departure from this individual
label is at most
  sum_y q(y) min(1,W_S(y)/W_S(z_j))
   <= sum_y q(y) W_S(y)/W_S(z_j)=r/p.
The local step can depart only to a_j, with probability s/(bp).
Consequently the probability of leaving z_j during one C transition is
at most
  v=(alpha/2)(r/p)+(beta/2)(s/(bp))
   =(alpha/2) exp(-kappa/p)
      +(beta/(2b)) exp(-2 kappa/p).                    (2.4)
For 0<=v<=1, remaining at that same label for the next t-1 steps has
probability at least h_t=(1-v)^(t-1). In particular
  h_t >= 1-(t-1)v.
The Markov property and (2.1)--(2.3) now imply, for every integer t>=1,
  max_(|S|=k) TV(mu_S C_pi_S^t,pi_S)
   >= (beta/4) h_t [b^d_0-Mr]-p.                      (2.5)
Indeed test TV on R, count the paths that start in the matched low set,
select the local component on the first subsequent step, and then remain
at the captured rare label. All other contributions to the mass of R
are nonnegative. Finally subtract pi_S(R)=p.

Equation (2.5) is the promised finite tradeoff for an arbitrary admissible
stopping rule. The post-prefix kernel is fixed throughout. Neither the
stopping decision nor the local proposal is changed after target
observations from the subsequent phase.

If every target in this finite family has TV<=epsilon at time t, and
h_t>=1/2, rearranging (2.5) gives the useful necessary condition
  b^d_0 <= Mr + 8(epsilon+p)/beta.                     (2.6)

3. EXPLICIT PARAMETER FAMILY AT THE FROZEN EXPONENT

Let epsilon decrease to zero. For n=n_safe(epsilon), put
  M=2n,       m=n^3,
  k=floor(b_K m)-1,       b=k/m,
  eta=b_K-b,
  kappa=(K+log(1-b))/2,
  p=epsilon^2,
  r=p exp(-kappa/p),      s=p exp(-2 kappa/p).
Use the public q and Q of Section 2. These are specified without knowing
the stopping rule. The chosen hard subset S may depend on the rule,
which is legitimate for the supremum over target instances.

For all sufficiently small epsilon, n tends to infinity, 1<=k<m,
and k>=M^2. The latter follows from k/m -> b_K>0 and
M^2/m=4/n -> 0. The integer construction also gives the exact bounds
  1/m <= eta < 2/m.
Thus
  kappa=(1/2)log(1+exp(K) eta)>0,
  kappa=Theta_K(1/m).
The small entropy slack is positive at every finite epsilon.

The prescribed common time is
  t=ceil(exp((K+1)/epsilon)).
Since n=Theta_(K,alpha)(log(1/epsilon)),
  m=Theta_(K,alpha)((log(1/epsilon))^3),
  epsilon*m -> 0,
  (kappa/p)/(1/epsilon)=kappa/epsilon -> infinity.
It follows directly from (2.4), with b -> b_K>0, that
  t v -> 0,
  h_t >= 1-(t-1)v >= 1/2
for all sufficiently small epsilon. Also
  Mr=o(epsilon),   p=o(epsilon),   r=o(kappa),
  s/(bp)=exp(-2 kappa/p)/b -> 0.
In particular all positivity and low-to-trap acceptance conditions in
Section 2 hold eventually.

For completeness, the KL constraint is verified with a strict margin,
not by admitting a singular limiting target. Because
  -log(1-b)=K-2 kappa,
the exact KL formula and its elementary upper bound give
  D(pi_S||q)
   <= kappa-log(1-b)-log(1-r)
    = K-kappa-log(1-r) < K
for all sufficiently small epsilon, since -log(1-r)=o(kappa).
The inequality holds for every S. All q and pi masses and all raw oracle
weights are finite and strictly positive at each such epsilon.

4. SAFETY FORCES THE NULL EXPECTED COST

Assume the safety hypothesis in the theorem. Its common threshold is
independent of q,w_tilde,Q. Therefore it applies, for small epsilon, to
every hard target pi_S just constructed, at this same t. Write d_epsilon
for the expected null stopping time on the constructed public q,Q.
Apply (2.6):
  b^d_epsilon
   <= Mr+8(epsilon+epsilon^2)/beta
    = (8/beta+o(1)) epsilon
   <= (9/beta) epsilon                               (4.1)
for all sufficiently small epsilon. Hence, writing L=log(1/epsilon) and
lambda_b=-log b,
  d_epsilon >= [L-log(9/beta)]/lambda_b.              (4.2)

Because b_K-b is between 1/m and 2/m,
  lambda_b=lambda_K+O_K(1/m),      lambda_b>=lambda_K.
Moreover L/m -> 0. In particular, for sufficiently small epsilon,
  L(1/lambda_K-1/lambda_b) <=1.
Equation (4.2) therefore yields
  d_epsilon
   >= L/lambda_K-log(9/beta)/lambda_K-1.              (4.3)
Now 0<gamma<1, and the defining ceiling gives, for small epsilon,
  n_safe(epsilon)
   <= (L+log gamma)/lambda_K+2
   <= L/lambda_K+2.
Combining with (4.3),
  d_epsilon >= n_safe(epsilon)
                -3-log(9/beta)/lambda_K.             (4.4)
This proves the stated additive-constant bound on an explicit null
sequence. Taking the supremum over public q,Q and then the liminf proves
  liminf sup E_0[T_epsilon]/n_safe(epsilon) >=1.
It contradicts every proposed limsup bound rho<1, as claimed.

For the frozen primary constants the allowable displayed constant is
  3+log(18)/[-log(1-exp(-1))].
The constant is not optimized; the necessary leading candidate fraction
is exactly the point relevant to the question.

5. WHY THE INFORMATION AND OPTIONAL-STOPPING CONTRACT IS PRESERVED

- Public q is a complete labelled finite probability table, with two
  known mass levels. Public Q discloses every ordinary/rare pairing.
  Nothing in the proof suppresses those observations. The randomized
  hidden-subset average is performed after conditioning on the complete
  label-sensitive null stopped transcript.
- The support size 2n_safe^3 grows with epsilon. Complete observed-support
  certification on a fixed small space is therefore no obstruction to
  this uniform lower bound. The full class explicitly permits supports
  depending on epsilon.
- The raw target functions match exactly at every observed point on F_S.
  They differ only at unobserved points of that matched transcript. Their
  normalizers differ and are unavailable, as specified in the question.
- The proof couples the entire candidate stream, acceptance uniforms and
  private randomness. It uses the actual output X_T, not a resampled
  candidate or a deterministic-time proxy for its distribution.
- All iid draws count. Duplicates only reduce the number of distinct
  constraints on the hidden set and are explicitly allowed in (2.2).
- The public local proposal is target-independent and symmetric. Its
  ordinary-MH implementation is fixed for each target. It is used only
  after stopping, through the prescribed mixture C and exactly t steps.
- The local trap is entered through one ordinary subsequent transition,
  then retained with an explicit finite-time probability. The proof
  does not rely on a target-dependent choice of Q or a singular chain.
- The same known positive K is used for the null and hard targets. No
  empirical inference of KL or hidden normalization is made.

The conclusion is restricted to the given candidate-only target access
and uniform null-family objective. Access to full numerical L_pi tables,
pre-prefix local probes that reveal new target values, arbitrary unseen
weight queries, target-code inspection, a fixed known small support, or
other changed scientific contracts would require a separate analysis.
The result does not exclude instance-specific savings on a smaller easy
subclass. It also does not establish a wall-clock or practical sampling
comparison.

1. AUDITED MATHEMATICAL STATEMENT

D>=2,L>=2,r>=1,w>=0 are integers. The inaccessible complete clock vector
K is iid uniform on {1,...,L}^r. Conditional receiver input is exactly
  sigma_K = tensor_a [Phi_D^K_a tensor nu_D^(L-K_a)],
  nu_D=I_(D^2)/D^2.
The receiver Gamma is any trace-preserving separable channel on all rL Alice
and Bob external pairs, with no receiving entanglement or source-correlated
apparatus. Independent local/separable apparatus can be absorbed into Gamma.
Its actual output can have arbitrary collective correlations and transcripts.

The complete target, conditional on K and a classical profile/transcript,
has pure external output tensor_a v_(N_a), where
  v_n=Phi_D^(tensor n) tensor |00>^(tensor(L-n)),
  max(1,K_a-w)<=N_a<=K_a.
Every reference branch satisfies these constraints; N need not be supplied
or measurable by the receiver. The complete global half-trace error, including
all retained inaccessible clocks, memory and transcript, is at most epsilon.

Put t=w+9 and beta=(3/2)(3/4)^8=19683/131072<0.151. Then

  1-epsilon-beta^r
    <= L^-r sum_(s=r)^(rt) binom(s-1,r-1) D^s
    <= L^-r D^(rt) binom(rt,r)
    <= [e t D^t/L]^r.                                      (V)

When the left side is positive this gives
  ln L <= t ln D+ln t+1-(1/r)ln(1-epsilon-beta^r).
For epsilon<=1/2, the last term is bounded uniformly over r>=1, giving
  w >= log_D L-log_D(w+9)-O_D(1).
This is a uniform-r logarithmic L loss obstruction for this output contract.
It is independent of the earlier CPTP log(r/epsilon) obstruction.

2. THE PHYSICAL POSTPROCESSOR IS VALID AND DOES NOT READ K

After Gamma, Alice performs separately on each L-digit output block the
COARSE projective measurement J=last nonzero computational position:
  Q_j=I^(j-1) tensor (I-|0><0|)_j tensor |0><0|^(L-j), j>=1,
  Q_0=|0><0|^L.
These projectors are orthogonal and sum to I. The digits before j are not
measured individually. Alice broadcasts J to Bob; both retain the first
n_J=(J-1)_+ pairs and reset all remaining pairs to |00>. J is kept public.
This is a trace-preserving LOCC map and preserves effective separability.
The extra communication and disposal are proof overhead, not a claimed
receiver upper bound or catalyst return.

For a target v_N, Q_j has nonzero probability only for j<=N. For j>=1 its
postmeasurement state factors an EXACT Phi_D^(j-1) prefix, a nonzero-digit
state on j, and zero-digit projections after j. Resetting sites >=j leaves
exact v_(n_J). For j=0 the output is v_0. Thus, after postprocessing, the
kept target output is exactly tensor_a Phi_D^(n_(J_a)), regardless of hidden
N, K, preceding transcript or the source of that transcript.

For proof only put G=N-J. It is a truncated geometric variable:
  Pr(G=g|N)=(1-1/D)D^-g, 0<=g<N;
  Pr(G=N|N)=D^-N.
Consequently for z=4/3,
  E[z^G|N] <= (1-1/D)/(1-z/D) <=3/2.
All D>=2 are covered, with no prime-field premise.

Conditional on the complete reference profile vector, the external state is
a product, so the G_a are independent there. Profile and transcript averaging
therefore preserve
  E z^(sum_a G_a) <= (3/2)^r.
Markov's bound gives
  Pr(sum G_a>8r) <= beta^r.
For every target outcome J_a<=N_a<=K_a and
  delta_a=K_a-n_(J_a)>=1,
  delta_a<=w+1+G_a.
The latter includes J_a=0, where the sharper delta_a<=w+G_a holds.
Hence with target probability at least 1-beta^r,
  J_a<=K_a for all a, and sum_a delta_a<=r(w+9).

3. ONE COMPLETE JOINT ACCEPTANCE TEST

On the postprocessed state, mathematically read K and the ACTUAL broadcast J.
Accept only if J_a<=K_a and sum delta_a<=rt, and then test the retained
external prefix against tensor_a Phi_D^(n_(J_a)). This is one effect W with
0<=W<=I, tensored with identity on any other retained registers. It is a test
of the DECLARED GLOBAL comparison; it does not give K to the receiver and
does not prove that this hidden-memory test is experimentally obtainable.

The target's kept output passes the Bell test exactly on every branch. Thus
  Tr W post(target)>=1-beta^r.
Complete trace contraction and the variational half-trace bound imply
  Tr W post(actual)>=1-epsilon-beta^r.                       (1)
No actual outcome or bad branch has been postselected away.

4. THE EXACT SOURCE-DEPENDENT PRODUCT-KRAUS BOUND

Trace out retained apparatus and transcript not used by W, leaving only
finite external outputs and J. The effective post-Gamma channel is still
separable and TP. Refine local discarded environments in a mathematical
product-Kraus representation. Write each fine branch as A_lambda tensor
B_lambda, with fixed public J=J_lambda. Refinement is an analytic sum; its
hidden labels need not be retained or physically accessible.

One can either (i) use output dimension M_lambda=D^(sum_a n_(J_a)) on that
branch, or (ii) embed into the fixed L-pair ports and refine/reset their tails.
Both give the same TP identity on the fixed input dimension d=D^(rL):
  sum_lambda A_lambda^dagger A_lambda tensor
                  B_lambda^dagger B_lambda=I_(d^2).
Taking traces defines normalized nonnegative weights
  q_lambda=Tr(A_lambda^dagger A_lambda)
             Tr(B_lambda^dagger B_lambda)/d^2,
  sum_lambda q_lambda=1.                                   (2)
Branch-dependent output dimensions do not change this input identity.

Fix K. Reorder source coordinates locally into its Bell part and nuisance
tail. Let H=D^(sum_a K_a), T=d/H, M=D^(sum_a n_(J_a)). In those coordinates,
  sigma_K=Phi_H tensor I_(T^2)/T^2.
For tail basis indices u,v and output i=1,...,M, the Bell amplitude is
  (HM)^(-1/2) sum_(x=1)^H sum_(i=1)^M
                   A_(i,xu) B_(i,xv).
The transpose-free expression A B is correct for a maximally entangled ket;
absolute-value Cauchy-Schwarz applies equally to complex entries.
Including the uniform prior L^-r and the product-tail factor T^-2 gives

  f_(lambda,K)
   = [L^r H M T^2]^-1 sum_(u,v)
             |sum_(i,x) A_(i,xu)B_(i,xv)|^2
   <= [L^r H M T^2]^-1
          [sum_(u,i,x)|A_(i,xu)|^2]
          [sum_(v,i,x)|B_(i,xv)|^2]
   = (q_lambda/L^r) D^(sum K_a-sum n_(J_a)).                 (3)

Any local environments left after keeping the Bell outputs can equivalently
be included as additional fine Kraus indices. A fidelity test against zero
reset tails only reduces the Hilbert-Schmidt norms if explicitly contracted.
The K-dependent coordinate reordering leaves those norms unchanged.

The factor T^-2 is the actual FULL PRODUCT nu tail. Replacing that input by
a chi tail or source-correlated apparatus invalidates this contraction and
is not an allowed shortcut.

5. COUNTING ELIGIBLE CLOCKS, INCLUDING J=0

For a fixed lambda, J is fixed. Eligible K obey J_a<=K_a and
delta_a=K_a-(J_a-1)_+ positive, with sum delta_a<=rt. This also holds for
J_a=0 because K_a>=1. The map K->delta is injective for fixed J.
Dropping bounds K_a<=L can only increase the positive weighted sum. Thus

  sum_(eligible K) D^(sum delta_a)
   <= sum_(s=r)^(rt) binom(s-1,r-1)D^s
   <= D^(rt) binom(rt,r)
   <= [e t D^t]^r.                                        (4)

The middle identity uses the count of positive compositions and the
hockey-stick sum. All upper endpoints are integers because w is an integer.
For a noninteger deficit use its integer floor or replace rt by floor(rt);
do not apply a binomial coefficient to an unspecified noninteger count.

Summing (3) over eligible K and then all lambda, (2) and (4) give
  Tr W post(actual)<=L^-r D^(rt)binom(rt,r).
Combining with (1) proves (V).

7. PRECISE OPTIONAL AID/ACCESS MULTIPLIERS

One valid aid extension is: there is a fixed independent separable eta such
that the actual independent aid zeta obeys zeta<=A eta. Positivity gives
actual acceptance<=A times the eta-input acceptance, so (V)'s right side is
multiplied by A. This is an explicit operator-domination/E_max-type resource;
it is not the aid's entropy or mutual information. If the resource is only
approximately dominated, its separate global error must be included.

For classical supplied label Z with conditional product source
sigma_K tensor |z><z| and probability p(z|K), each conditional receiving map
Gamma_z is SEP. Applying (3) for that map and bounding p(z|K) by its maximum
over K gives the valid multiplier
  A_access=sum_z max_K p(z|K).
In particular A_access<=|Z| for a finite alphabet. Full deterministic
inventory access has A_access=L^r, making the bound appropriately vacuous.
Generic I(K:Z), mean record length, or a marginal I(K:Z)=0 is NOT a substitute
for these domination hypotheses. Source-Z entanglement is outside this
conditional-product extension.

8. OPTIONAL SUPPORT-ONLY EXTENSION, NO CLASSICAL PROFILE REQUIRED

The same SEP volume law in fact holds if, conditional on K, the reference
external state (possibly coherent, entangled across slots and entangled with
records) is supported in tensor_a U_(K_a), where
  U_k=span{v_n:h_k<=n<=k}, h_k=max(1,k-w).
This is a mathematical output-support theorem; it is not automatically a
classical Bell-allocation or mean-resource statement.

First, Q_J acting on any v_n with n<J is zero. For n>=J its first (J-1)_+
pairs factor as exact Bells. Thus for every vector in the profile-band span,
the post-Luders retained prefix factors as those same Bells. Superpositions
and entanglement with other registers cannot change this common factor.

Second, for U=span{v_h,...,v_k} and j<h, let Q_(J<=j) be Alice's projection
onto zero digits after j. Direct tensor contraction gives, for n,m>=h,
  <v_n|Q_(J<=j)|v_m>
     =D^(-(n+m-2j)/2)
     =D^(-(h-j)) <v_n|v_h><v_h|v_m>.
Hence its compression to U is the rank-one operator
  D^(-(h-j)) |v_h><v_h|,
with operator norm D^(-(h-j)). For G=(h-J)_+ this implies the operator tail
bound Pr(G>=g)<=D^-g for every supported state, and therefore at z=4/3
the compressed moment operator is <=(3/2) I_U.
Tensoring these local moment operators bounds the joint moment by (3/2)^r
even for entangled target states. Finally
  K-(J-1)_+ <= K-h+1+(h-J)_+ <= w+1+G.
This recovers the same high-probability delta event and completes the same
proof without assuming a profile mixture or independent target output flags.

CYCLE9 SHARPNESS OF THE r/epsilon EXPONENT IN THE BROADER CPTP CLASS
Internal mathematical observation; NOT a zero-aid LOCC receiver.

Fix D,L,r and integer 0<=w<=L-2. Use the actual nu-tail source with
inaccessible iid uniform clocks K, and retain complete old memory unchanged.
Measure the complete product generalized Bell basis of the rL source pairs.
This is one collective CPTP operation; it is not generally LOCC without aid.
Let Y be the actual complete outcome, and j_a the number of leading
distinguished Phi labels in slot a, taking j_a=L if all labels are Phi.
The actual source implies j_a>=K_a with certainty.

Output freshly prepared v_(n_a), where n_a=max(1,j_a-w), and retain Y.
No clock value is consulted by this operation. Define the reference with
the SAME actual K,Y law, unchanged old memory and output v_(n_a^*), where
  n_a^*=min(K_a,n_a).
Then, on EVERY reference branch,
  max(1,K_a-w)<=n_a^*<=K_a.
Indeed j_a>=K_a gives n_a>=max(1,K_a-w), and min with K preserves this.

On j_a<=K_a+w the actual and reference outputs agree. The complementary
event requires w+1 independent nuisance Bell indices all equal Phi, and is
possible iff K_a<=L-w-1. Its exact probability is
  p=((L-w-1)/L) D^(-2(w+1)).
The r slots are independent in this construction. On every globally safe
branch actual and reference states agree; unsafe branches have half trace
distance at most one. Consequently
  T(actual,reference) <= 1-(1-p)^r <= r p.

For d=w+1, the root lower bound is
  epsilon >= [r D^(-2d)/(1+r D^(-2d))]
              (1-D^-1)(1-d/L).
Thus in the small-error regime its dependence on r,epsilon,w has the same
exponent 1/(2 ln D) as this general-CPTP construction. This is not a proof
of exact best constants, nor of the logarithmic L cost of the admissible
zero-aid LOCC receiver. It shows that a lower bound applying to ALL CPTP
receivers with uncharged entanglement cannot improve that r/epsilon exponent.

EXPLICITLY PRICED ENTANGLEMENT-ASSISTED LOCC IMPLEMENTATION

The same CPTP operation can be realized by LOCC with deterministic independent
auxiliary Bell stock at most 2rL lnD nats: teleport all rL Bob source halves
to Alice (rL Bell pairs), perform the Bell-basis measurements and prepare
both halves of each v_n locally at Alice, then teleport rL designated output
halves back to Bob (rL additional Bell pairs, even though some could be sent
classically or prepared locally). Each teleportation uses two D-ary symbols,
so this conservative implementation sends 2rL D-symbols in EACH direction.
All source destruction, teleportation records, Y, local preparation and
ancilla disposal are charged; it is not a returned catalyst. Generalized
Weyl teleportation works for every integer D. The stock is independent of K
and does not grant inventory access.

This construction has deliberately enormous paid resource and communication
compared with the actual Cycle8 receiver. It is a sharpness comparator for
the broader theorem class only, not evidence of a cheap new receiver,
ordinary-stock advantage, or physical usefulness.

1. PRECISE AUDITED STATEMENT

Let D>=2,L>=2,r>=1 be integers, and let K=(K_1,...,K_r) be uniform on
{1,...,L}^r, retained as inaccessible orthogonal clock registers. The receiver
is a single K-independent CPTP map on

  sigma_K = tensor_a [Phi_D^K_a tensor nu_D^(L-K_a)],
  nu_D = I_(D^2)/D^2,

and any initially K-independent auxiliary state. This permits arbitrary
collective quantum operations and independent auxiliary entanglement; LOCC
is not needed. All desired output, transcript and work registers are outputs
of that same map. The map cannot use K-correlated access.

For n=0,...,L define
  v_n = Phi_D^(tensor n) tensor |00>^(tensor(L-n)).
The complete comparison reference, conditional on K and any classical profile
label/transcript, has output tensor_a |v_(n_a)><v_(n_a)|, with
  0 <= K_a-n_a <= w on every reference branch.
Its additional retained records and inaccessible memory are unrestricted by
the proof apart from the stated joint interface; projectors below act as
identity on them. In particular, n_a can depend on all K and the entire joint
transcript. This is a profile-mixture condition. It is not a claim about an
arbitrary allocation of entanglement across newly encoded output registers.

Let e_K be the conditional half-trace distance between complete actual and
reference states. The same clock marginal gives e_bar=L^-r sum_K e_K<=epsilon.
If the target is specified only after discarding a record, apply the theorem
to that declared interface; do not assume a stronger joint guarantee.

For every integer d with w<d<L, set
  c=D^(-2d), q=1-D^(-(d-w)).
Then

  epsilon >= [r c/(1+r c)] q (1-d/L).                         (A)

In particular, for integer w>=0, d=w+1<=L/2, and 0<epsilon<=1/8,

  r D^(-2(w+1)) <= 8 epsilon,
  w+1 >= ln[r/(8 epsilon)]/(2 ln D).                         (B)

Thus the logarithmic r/epsilon dependence is a genuine obstruction for this
pointwise pure-profile reference. It does not prove the logarithmic L loss
optimal for a single queue, nor a formation-resource advantage/disadvantage.

2. FULL CHECK OF THE LINEAR-ALGEBRA LEMMA

Put a=D^(-1/2). Direct tensor contraction gives
  <v_i|v_j> = a^|i-j|.
For S_k=span{v_0,...,v_k} and every ell>k,

  <v_j| v_ell-a^(ell-k) v_k>
   =a^(ell-j)-a^(ell-k)a^(k-j)=0 for all j<=k.

Hence P_(S_k)v_ell=a^(ell-k)v_k exactly, and
  ||P_(S_k)v_ell||^2=D^(-(ell-k)).
This proof uses no field structure, so every integer D>=2 is covered.
The Gram matrix is positive definite (or the displayed orthogonal innovations
v_0,(v_j-a v_(j-1))/sqrt(1-a^2) give an explicit basis).

The same result holds using span{v_1,...,v_k}; inclusion of v_0 is harmless.
If the target insists on at least one Bell pair, the larger S_k still yields
the stated valid bound. k=0 is never used as a source clock.

3. FULL CHECK OF THE SOURCE ORDER

For 1<=k<=L-d,
  sigma_k = Phi^k tensor I_(D^(2d))/D^(2d) tensor nu^(L-k-d)
           >= D^(-2d) sigma_(k+d),
because I>=|Phi>^d<Phi|^d. Tensoring the other r-1 inputs and the same
K-independent auxiliary state preserves positivity. Applying the same CPTP
map preserves the order:
  rho_K >= c rho_(K+d e_a).
Here rho includes all output registers generated by the receiver. The old
memory in the actual queue is the same independent nu state on every clock
branch, so it can be included directly. More generally, if old retained memory
had K-dependent conditionals, only the receiver-output reduced order is
automatic; the proof remains valid because its test is identity on old memory.

The order would NOT be justified for K-correlated receiver auxiliaries or
K-dependent channels. Actual supplied access therefore needs a separate law.
Independent auxiliary entanglement, including a large consumed catalyst, does
not invalidate the order. The proof does not infer that such an auxiliary
returns or is experimentally measurable.

A concrete warning against replacing product independence with I(K:Z)=0:
take D=L=2 and suppress the common first Bell pair. For K=1, let the second
pair and a four-dimensional Z be a maximally entangled pure state, so the
second pair marginal is nu=I_4/4. For K=2, let their joint state be
Phi_2 tensor I_Z/4. In both cases Z has the SAME I_Z/4 marginal and hence
I(K:Z)=0. Nevertheless the K=1 joint state has rank one while the K=2 state
has rank four; no positive constant multiple of the latter is below the
former. This does not by itself refute the loss inequality under that larger
class; it proves that its essential source-order premise cannot be inferred
from marginal zero information. The product-factor hypothesis excludes it.

4. ORTHOGONAL-DEFECT TEST AND AVERAGING

For each K let A(K)={a:K_a<=L-d}, and define
  Pi_(K,a) = (I-P_(K_a))_a tensor_(b!=a) P_(K_b),
with identity on every other retained register. These are pairwise orthogonal
projectors because for a!=b the factors on slot a include I-P and P.
Thus E_K=sum_(a in A(K))Pi_(K,a) satisfies 0<=E_K<=I.
The K-reference is supported in tensor_a S_(K_a), so Tr E_K theta_K=0 and
  e_K >= Tr E_K rho_K.

For the neighbor K'=K+d e_a, all other profile vectors remain in S_(K_b).
The a-th profile has n_a>=K_a+d-w>K_a, so the projection lemma gives
  Tr Pi_(K,a) theta_K' >= 1-D^(-(d-w))=q.
The variational half-trace bound for the ONE effect Pi_(K,a) yields
  Tr Pi_(K,a) rho_K' >= q-e_K'.
Combining with source order and summing orthogonal effects gives
  e_K >= c sum_(a in A(K)) [q-e_(K+d e_a)].
Negative terms are harmless lower bounds; no positive-part operation or
independence of output slots has been assumed in the actual state.

Average over uniform K. The total eligible-neighbor count is
  L^-r sum_K |A(K)| = r(1-d/L).
Every fixed neighbor label K' appears at most once per coordinate a and hence
at most r times in the error sum. Thus
  e_bar >= c q r(1-d/L)-c r e_bar.
Rearranging and using e_bar<=epsilon proves (A). No union bound over r actual
output errors has been substituted for the global error.

5. CONSTANT CHECK AND EDGE CASES

For d=w+1<=L/2, q>=1/2 and 1-d/L>=1/2. If x=rc, (A) implies
  epsilon >= x/[4(1+x)].
Therefore x<=4epsilon/(1-4epsilon)<=8epsilon when epsilon<=1/8.
This proves (B). The small-error hypothesis is used in its final numerical
simplification. For epsilon=0, (A) itself rules out any admissible d; do not
write ln(1/epsilon) at zero. If w is nonintegral, use any integer d>w or
replace w with floor(w) in the pointwise integer allocation premise; do not
silently use noninteger d=w+1. If w>=L-1 no such d exists, consistently with
retaining only the guaranteed first Bell pair.

6. ADVERSARIAL SCOPE CHECKS

- Complete transcript correlation is allowed: the tests act as identity on
  transcript and all additional retained registers. No conditionally
  independent transcript, locally measurable clock, or actual K selector is
  used by the receiver.
- Target pure-profile support is used only in a mathematical reference test.
  The argument does not put the finite-epsilon ACTUAL state into MC support,
  evaluate its formation witness at zero defect, or substitute a chi tail.
- The actual state can contain arbitrary correlations across its r slots and
  across outputs and retained records; all originate from one CPTP map.
- The actual comparator's source must be the same nu-tail queue, not an
  arbitrary source with the same mean Bell supply. A representation change
  that changes source support does not inherit this order bound.
- The uniform clock prior matters in the simple coefficient 1-d/L. For
  nonuniform or correlated priors the neighbor counting must be redone.
- Arbitrary independent resources cannot remove this obstruction. Paid
  correlated access CAN remove the common-map order and is a separate resource.
- This law proves no efficient implementation, physical usefulness, or
  historical novelty. It closes the fixed-loss uniform-r possibility only in
  the stated small-global-error/profile interface. It does not bound different
  collective Bell encodings or ordinary distillation to a global register.

7. CHECKPOINT VERDICT

No defect was found in (A) or (B). The proof genuinely applies beyond LOCC
and arbitrary independent auxiliary dimensions, while preserving the complete
joint clock/output comparison. It establishes a finite-r loss/error law.
Its limit epsilon lower bound alone saturates below one; a separate posterior
test can establish error tending to one at fixed L and useful pointwise loss.
That separate theorem should be stated with its own finite-r dependence and
not inferred merely from (A).

8. OPTIONAL STRONGER SUPPORT INTERFACE (INDEPENDENT LEMMA)

The finite-r proof does not actually require a classical pure-profile mixture.
It remains true if, conditional on K, the reference output is any state
(possibly entangled across slots and with retained records) supported in

  tensor_a U_(K_a),
  U_k=span{v_n:max(0,ceil(k-w))<=n<=k}.

To verify the nontrivial neighbor step, take h>k and
U=span{v_h,...,v_ell}. For every z in U, the same Gram identity implies

  P_(S_k) z = a^(h-k) v_k <v_h|z>.

Indeed this holds on each spanning v_n because
<v_h|v_n>=a^(n-h). Therefore ||P_(S_k)|_U||=a^(h-k), attained at v_h, and
the compression of I-P_(S_k) to U is at least
  [1-D^(-(h-k))] I_U.
In the neighbor K+d e_a, h>=K_a+d-w, so this compression is at least qI.
All other factors of the reference support remain within S_(K_b), and hence
the compression of Pi_(K,a) is also at least qI on its entire joint support.
No productness of the conditional target state is needed for this argument.

This is a stronger mathematical support-interface theorem. For coherent
profile-band states it should not be presented as a classical allocation of
exact Bell pairs or assigned the mean inventory of a profile mixture without
an additional operational argument. Different collective Bell encodings are
still outside this declared output support.

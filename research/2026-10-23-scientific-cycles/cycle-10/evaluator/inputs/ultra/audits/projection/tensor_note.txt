CYCLE9 BOUNDED TENSOR STRENGTHENING NOTE
Role: independent bounded lemma for /root/cycle9_projection_audit
Scope: comparison with the already completed collective posterior theorem;
not a second audit or a historical novelty claim.

1. FINITE-r THRESHOLD IMPROVEMENT

Assume the actual source conditional on iid uniform K_1,...,K_r is
tensor_a rho_(K_a), where rho_k=Phi_D^k tensor nu_D^(L-k), and all receiver
apparatus is initially a tensor factor independent of the source. Allow
an arbitrary collective quantum channel. The complete comparison reference
has the same classical K marginal and a classical pure-product profile
ensemble tensor_a |v_(N_a)><v_(N_a)|, with
 v_n=Phi_D^n tensor |00>^(L-n),
 max(1,K_a-w)<=N_a<=K_a on every reference branch.
Retained clocks/transcripts/old memory can be kept in the joint distance.
Take integer 0<=w<=L-2, s=L-w-1, alpha=1-1/D, and
 c_s=(D^(2s)-1)/(D^(2L)-1), gamma_s=-ln(1-c_s).
For m=floor(alpha*r/(2L))>=1, global half-trace error satisfies

 epsilon >= 1-exp(-alpha*r/(8L))-exp(-gamma_s*m).             (A)

Thus the fixed-L pointwise-deficit error tends to one, and the finite-r
scale in this bound is L D^(2(w+1)), rather than L D^(2(L-1)). It proves
a logarithmically growing collective deficit is necessary in the range
where ln(r/L) grows and remains below the finite-L saturation boundary.
It is not a one-copy Omega(log L) Bell-loss theorem.

2. PROOF

Let V_s=span{v_1,...,v_s} and P_s=I-Proj(V_s), measured separately on each
output slot. Because <v_j,v_n>=D^(-|j-n|/2), for n>s the projection of v_n
onto V_s is exactly D^(-(n-s)/2)*v_s. Consequently
 Pr(flag|n)=0 for n<=s,
 Pr(flag|n)=1-D^(-(n-s))>=alpha for n>s.

Under the reference, every flag has K_a>s. Every coordinate with K_a=L
has N_a>=L-w=s+1, so it flags with probability at least alpha. Conditional
on the entire K,N, profile outputs are product and these flags independent.
Couple them using independent uniform coins U_a: flag count dominates
sum_a 1{K_a=L,U_a<=alpha}, an iid Binomial(r,alpha/L) count. Therefore,
writing S for the set of flagged slots, the reference test event
 E={|S|>=m AND K_a>s for every a in S}
has probability at least 1-exp(-alpha*r/(8L)). This Chernoff bound follows
from the usual lower-half-mean inequality, since m=floor(alpha*r/(2L)).

For the actual source, introduce the mathematical latent full product
Bell-basis index Y. This uses the commuting source decomposition and does
not grant the receiver a Bell measurement or label access. If j is the
number of leading distinguished zero Bell indices in a slot's Y, then
 Pr(K=k|Y)=D^(2k)/sum_(h=1)^j D^(2h), k=1,...,j.
Hence Pr(K<=s|Y)>=c_s, including j<=s where that probability is one.
Across slots the posteriors remain independent conditional on full Y.
The receiver channel, arbitrary independent apparatus and final flag
measurement satisfy K -> Y -> S. Thus
 Pr_actual(E|Y,S)<=1{|S|>=m}(1-c_s)^|S|,
and Pr_actual(E)<=exp(-gamma_s*m). Testing K in this inequality is allowed
by the global state distance; it does not make K accessible to the device.
Trace-distance data processing proves (A).

3. CONNECTION TO THE ROOT SUPPORT/ORDER BOUND

The stated order comparison gives a useful finite-r rational lower bound
of the form epsilon >= [r c/(1+r c)]q(1-d/L). The posterior/flag test
handles simultaneous selected label violations and gives an exponentially
small actual probability when a positive number of useful profiles is
required. This removes the saturation below one for fixed finite L and
pointwise w<L-1. The threshold P_s is an operational distinguishability
test only; its nonlocal implementation is permitted for mathematical
trace-distance lower bounds and is not a proposed receiver operation.

4. PRECISE CAVEATS

- All source and auxiliary branches remain averaged. No postselection or
  accessible K estimator occurs. No chi-tail replacement occurs.
- The reference pure-product profile mixture is essential to the simple
  independent-flag coupling used above. A target in differently allocated
  collective Bell registers is outside this theorem.
- The initial apparatus/source tensor-factor condition matters. Merely
  saying an apparatus marginal has I(K:Z)=0 does not establish the Markov
  condition if it is correlated or entangled with the source conditional
  on K. The old independently prepared apparatus contract does establish it.
- Correlated access Z whose conditional state factors from the source can
  instead be charged by I(K:Z), using the already stated relative-entropy
  comparison in the collective theorem; this note does not duplicate it.
- The argument does not use LOCC, so no communication protocol, unbounded
  independent entanglement or computation can evade this specific output
  profile obstruction. It does not contradict ordinary collective
  entanglement distillation to a changed output interface.
- The bound is vacuous when r is too small for m>=1 or w>=L-1; these are
  stated regime limits, not an inference that receivers exist there.

5. OPTIONAL STRONGER SUPPORT INTERFACE: COHERENT PROFILE SUPERPOSITIONS

The pure-product-mixture premise can in fact be replaced by a support
premise, keeping the same inequality (A). This section is a strengthening
of the theorem proved in sections 1-2 and supersedes the mixture-only
limitation there IF this stronger support premise is established.

For each observed K, suppose the reference output is supported on
 T_K=tensor_a U_(K_a),
 U_k=span{v_n:max(1,k-w)<=n<=k}.
It may be an arbitrary mixed, coherent or entangled state on T_K, including
correlations with retained records. Bell inventory moved to different
collective output registers is still outside this stipulated interface.

Let V=span{v1,...,vs}, U=span{v_(s+1),...,v_L}. On U one has
 Proj(V)|_U=D^(-1/2)|v_s><v_(s+1)|_U,
because both sides agree on every spanning v_n, n>s. Consequently, for
P_s=I-Proj(V),
 Proj(U) P_s Proj(U) >= alpha Proj(U), alpha=1-1/D.
For k<=s, U_k is contained in V, hence flag probability is zero. For k=L,
U_k=U, so the displayed compression lower bound holds.

Let F be total flag count and t>0. The local flag measurements commute;
e^(-tF)=tensor_a [I+(e^(-t)-1)P_s]. Compress this operator to T_K. On a
coordinate with K_a=L its norm is at most
 1-alpha(1-e^(-t));
on every other coordinate it is at most one. All factors are positive, so
for EVERY state supported on T_K,
 E[e^(-tF)|K] <= [1-alpha(1-e^(-t))]^(#{a:K_a=L}).
Averaging the specified iid uniform K gives
 E[e^(-tF)] <= [1-(alpha/L)(1-e^(-t))]^r.
The same Binomial(r,alpha/L) Chernoff lower-tail estimate therefore holds.
Under the reference all flagged coordinates still have K_a>s. The actual
posterior test and trace-distance step are unchanged, proving (A) under
this larger support interface without conditional output independence.

This extension excludes a superficially plausible loophole (coherent
superpositions within the original profile-band spans) while preserving
the substantive gap of changed collective Bell-register allocation.

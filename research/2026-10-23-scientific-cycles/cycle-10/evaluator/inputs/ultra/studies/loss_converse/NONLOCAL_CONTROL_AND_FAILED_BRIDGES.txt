1. UNRESTRICTED GLOBAL CPTP CONTROL HAS CONSTANT LOSS AT FIXED ERROR

This is NOT an admissible LOCC receiving operation. It is an explicit control
showing that the separable structure in the new log-L law is essential.

On the actual conditional input Phi_D^K nu^(L-K), an unrestricted nonlocal
receiver tests sites2,...,L in order using the joint projective measurement
{Phi_D,I-Phi_D}, stopping at the first failure. Let H be the length of the
passed prefix, with H=L when all tests pass. The known first Bell is untouched.
Every actual Bell passes without disturbance, so H>=K. Each independent nu
tail slot passes with probability q=D^-2. Therefore, conditional on K=k,
  Pr(H=h|k)=(1-q)q^(h-k), k<=h<L,
  Pr(H=L|k)=q^(L-k).

Fix an integer w>=0. Keep n=max(1,H-w) passed Bell slots and reset all other
slots to pure zero; retain the actual H transcript. The output conditional
on (K,H) is exactly Phi_D^n followed by zeros. A reference with SAME actual
(K,H) law and SAME complete old memory takes nstar=min(K,n). Its deficit is
  max(1,K-w)<=nstar<=K.
Actual and reference agree whenever n<=K. If n>K, their half-trace distance
is at most1, so the complete joint error is at most
  Pr(n>K)<=q^(w+1)=D^(-2(w+1)).
More precisely each unsafe pure-state distance is
sqrt(1-D^(-(n-K))), but the rational bad-mass bound is enough.

At fixed epsilon this needs w=O(log(1/epsilon)) independent of L. On unsafe
branches the NONLOCAL Bell test has created entanglement from product noise;
that is permitted only in this deliberately unrestricted comparator. It is
why no universal CPTP-only fixed-error log-L lower bound can be true.
The new SEP proof forbids this operation through its product-Kraus premise.

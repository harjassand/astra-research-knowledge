EXACT RECEIVING INTERFACE

Input: terminal Omega in PROOF(1); full current clocks F and old memory M are
retained but inaccessible. Receiver acts only on the finite L external pairs
and declared local work. No K-dependent selector, shared seed or entangled
receiving aid is supplied. K appears only in proof/fixture generation.

Retained output: L external D-pairs plus two matching public transcripts of
BOTH mod-D sums from each physical parity query. Synthetic calls and query
indices can be reconstructed from common history. If retaining additional
deterministic control state, include it as a function of the transcript.
Private tail outcomes, pivot syndrome work, controller weights and measurement
ancillas are actually reset/discarded after use; export is charged.

Unchanged complete old memory: clocks retain K correlated with the output and
transcript, all terminal old pairs remain nu^L. No decoupling is assumed.
No receiving apparatus is asserted to return or to be a reusable catalyst.

Target: SAME actual p(K,T), SAME complete old-memory conditionals, and external
Phi^max(1,min(K,n(T))) followed by pure |00> tails. It is a comparison state,
not a free hidden-clock implementation. All branches are averaged and bad
branches remain in the actual output. Bound: one GLOBAL half trace epsilon.
The actual first Bell pair is exact even on unsafe branches. Ideal Bell
allocation nstar>=max(1,K-3Q); actual unsafe allocation is not Bell inventory.

If an exact source is initialized at global distance alpha, the same reference
is reached at distance <=alpha+epsilon by contraction. This is not a new
source distribution or a transfer of source-dependent expected-cost charges.
For r tasks allocate epsilon/r per receiver or prove a direct collective
construction. A fixed epsilon per copy is not fixed global epsilon.

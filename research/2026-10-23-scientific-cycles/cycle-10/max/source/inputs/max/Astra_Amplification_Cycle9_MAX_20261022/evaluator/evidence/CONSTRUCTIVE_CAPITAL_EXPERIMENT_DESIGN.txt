RECOMMENDED FACTORIZATION
A. Strong conventional exact-count control: SAT4 projection + exact counts + flag dominance, current final algorithm.
B. Occupancy quotient with ONLY flag dominance at fixed colors, actual degrees and neighbor-color supports.
C. Occupancy quotient with current support-and-flag dominance.
Use a single generic subset-antichain reducer/coverage test, with:
 A base=(a,b,nL,nR), mask=(FL,FR);
 B base=(a,b,dL,NL,dR,NR), mask=(FL,FR);
 C base=(a,b,dL,dR), mask=(NL,FL,NR,FR).
Pack mask coordinates in disjoint four-bit fields, order by bit count then mask, retain a mask only if no earlier retained mask is a subset. Group bases first. Apply the same routine to all three. This preserves each arm's intended order while removing quadratic-versus-bitmask implementation differences. A and B then differ in forgetting multiplicities; B and C isolate support-order relaxation. SAT4 is held fixed in every arm.
If resource costs permit only two arms, A versus C is an acceptable comparison of the whole proved abstraction package. Do not label that result an occupancy-only causal effect.

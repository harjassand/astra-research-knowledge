2. SHARP ERROR FUNCTION, INCLUDING THE INVERSE

For a pure rho=|psi><psi|, let t=1-Tr(P rho_Q), a=|phi>|u>, and write
psi=sqrt(1-t)a+sqrt(t)b, where b lies wholly in Q orthogonal to phi. This
does not require b to be a product or to have a fixed residual Schmidt rank.
The cross terms vanish under Tr_Q, giving
rho_R=(1-t)|u><u|+t tau, tau=Tr_Q|b><b|.

X=|psi><psi|-(1-t)|a><a| has eigenvalues
  [t +/- sqrt(t^2+4t(1-t))]/2.
Thus ||X||_1=sqrt(4t-3t^2), and
  ||rho-P tensor rho_R||_1
  =||X-t P tensor tau||_1 <= sqrt(4t-3t^2)+t.
Endpoints t=0,1 follow directly. Trace-norm convexity and linearity of
rho -> rho-P tensor Tr_Q(rho) reduce a mixed state to pure states. Jensen
applies because g(t)=(t+sqrt(4t-3t^2))/2 has
  g''(t)=-2/(4t-3t^2)^(3/2)<0, 0<t<1.
Since g'(1)=0 and the derivative decreases, g is increasing on [0,1].
The saved proof correctly uses t<=delta to conclude T<=g(delta).

For psi=sqrt(1-t)|phi>|0>+sqrt(t)|chi>|1>, chi orthogonal to phi,
the operator -t P tensor |1><1| is supported orthogonally to X. The bound
is an equality. Therefore g is the optimal universal function, not merely
a sufficient estimate, when Q and the residual admit this two-dimensional
example. A bound linear in t is impossible uniformly.

Solving g(delta)<=epsilon for 0<=epsilon<=1 gives precisely
  delta <= [1+epsilon-sqrt(1+2epsilon-3epsilon^2)]/2
        = 2epsilon^2/[1+epsilon+sqrt(1+2epsilon-3epsilon^2)].
The squared inequality selects the smaller quadratic root; monotonicity of
g validates the whole interval and the endpoints. The proof's 'iff' should
be read as the exact universal guarantee from the infidelity bound, not as
a necessary condition for each individual state's actual distance.
The simpler delta<=epsilon^2/4 is safely sufficient via g(delta)<=2sqrt(delta).

4. ACCESSIBLE DUPLICATE FLAGS

For the exact cq state written in Section 4, both the B marginal and the
joint AB state have the same H(p) direct-sum entropy term. These terms cancel
in S(B'C_B)-S(A'B'C_AC_B), leaving the probability-weighted conditional
coherent informations. This requires the actual classical flag to be
available at both parties in the declared orthogonal register copies.
It does not follow for a flag present only in an inaccessible source clock.

Other flag copies in R can be arbitrarily correlated with the accessible
copies. They remain in the final actual residual, and the global lift covers
them. A c-dependent conditional Bell state contributes c log D only if that
conditional accessible state is actually the exact padded Bell state.
The proof explicitly retains the need to bound the actual coherent
information for approximate outputs. Resetting a bad accessible flag's
quantum output to a fixed product state gives conditional coherent
information zero only when that reset is actually performed. These are the
correct distinctions.

The final coding register has a fixed dimension on every branch. Hence
insufficient/abort branches cannot be removed by postselection; they enter
the Bell-overlap error. The existing text handles this correctly.

5. SECTION 5 CONVERSION AND IMPLEMENTATION PRECISION OBSERVATIONS

The announced cardinal-N-subset instrument is an exact deterministic LOCC
conversion from Phi_M to Phi_N. Its completeness factor is correct because
each basis vector occurs in binom(M-1,N-1) subsets. Every ideal outcome has
probability 1/binom(M,N) and becomes exactly Phi_N after local relabelling.
Its potentially enormous outcome count, messages, and compilation costs are
explicitly charged. It establishes mathematical existence, not efficiency.

Precision observation A: Contractivity alone preserves error to the image
of the OLD comparison state, whose new residual marginal need not be the
actual one. The new target with the exact actual residual should be obtained
by a fresh pure-output lift, as the text proposes. One can state the sharp
error preservation without any intermediate loss: if C is the converter's
Q-output marginal and E=C^*(Phi_N), then 0<=E<=I and
Tr(E Phi_M)=1 imply E>=Phi_M. (Positivity of I-E makes its action and cross
terms on the Phi_M vector vanish.) Therefore an input Bell infidelity <=delta
gives output Bell infidelity <=delta. Applying Section 2 to the COMPLETE new
output, including the subset record, gives g(delta) with its actual residual.
No assumption about the old residual or branch distribution is needed.

Precision observation B: An implementation error must include its effect
on an arbitrary correlated extension, as the text correctly requires.
To make 'added to the global error' quantitative, define
  e=||C_implemented-C_ideal||_diamond/2.
Then a safe actual-residual bound is g(delta)+2e, capped by 1: one e changes
the full state and the other changes its residual marginal. Alternatively,
the marginal Bell test gives implemented infidelity <=delta+e, so a fresh
lift yields g(min{1,delta+e}). Merely appending +e to an old bound with an
EXACT ACTUAL residual target is not justified by contractivity alone.
The present proof gives no numerical compilation claim, so this is a
clarification of the future implementation boundary, not a counterexample
to its exact-channel theorem.

6. LIMITS AND NONCLAIMS

Holding finite L,D and V fixed before taking r to infinity is sufficient
for the known iid theorem. A subsequent L limit is a different statement
from a simultaneous L(r) claim, which would require a uniform finite-size
coding analysis. Section 6 distinguishes these correctly.

The six excluded bridges are substantive and correct: marginal overlap
does not imply O(delta) decoupling; a fixed one-queue ideal replacement can
accumulate global error; inaccessible inventory is not an accessible flag;
postselection is not deterministic output; asymptotic rate does not establish
efficient finite-size advantage; and pooling changes the task rather than
contradicting Cycle9's pointwise per-queue converse.

No historical novelty, physical implementation, hidden-memory experimental
accessibility, or ordinary-stock advantage is asserted by this audit.

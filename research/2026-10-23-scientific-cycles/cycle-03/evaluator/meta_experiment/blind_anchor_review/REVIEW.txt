1. INDEPENDENT CHECK OF THE SHARED CORE

Write n = r + 1 and a_i = k_i^2 > 0. Full rank of N gives im(N^T) = k-perp, so the original inequality is equivalent to

    sum_i theta_i x_i^2 <= sum_{x_i < 0} x_i^2

for every x with sum_i k_i x_i = 0. This is an exact equivalence: the argument is not checking only a subset of attainable x. A nonzero such x has both positive and negative coordinates because every k_i is strictly positive.

The common characterization is:

  (i) A vertex theta = e_m is feasible exactly when
      a_m >= sum_{i != m} a_i.

  (ii) Every feasible nonvertex probability vector has all entries strictly
       between zero and one and satisfies

           a_i = T theta_i (1 - theta_i) for every i

       for one T > 0. Conversely, this identity and the probability-vector
       conditions imply feasibility.

There is no unaddressed intermediate case with some zero entries and at least two positive entries.

The necessity in (ii) is particularly restrictive and is correctly proved in both texts. For a nonvertex, every 1 - theta_i is positive. The single-positive-coordinate cone for index j yields

    theta_j B_j <= a_j,
    B_j = sum_{i != j} a_i/(1 - theta_i).

The minimizing negative coordinates used in A, or the explicitly scaled witness used in B, have the required signs and satisfy the hyperplane constraint. Thus no unconstrained minimization has been substituted for a sign-constrained one.

Set b_j = a_j/(1 - theta_j) and T = sum_j b_j. The displayed inequalities are equivalent to T theta_j <= b_j. Since their sums agree, every nonnegative slack must vanish. Hence a_j = T theta_j(1 - theta_j). Because a_j > 0, this also rules out theta_j = 0. This equality argument is finite, exact, and noncircular.

The converse genuinely controls every sign pattern. A proves it directly from the identity using q_i = k_i x_i, the common positive/negative mass s, and b = sum_{q_i < 0} theta_i > 0. The negative part is bounded below by s^2/b, while every positive-coordinate denominator satisfies 1 - theta_j >= b and the positive sum of squares is at most s^2. B proves the more general finite criterion directly: maximize theta_i/a_i on the positive set and combine the resulting bound on the positive energy with weighted Cauchy–Schwarz on the negative set. In each proof the signs required for the inequalities are explicitly available. Neither proof extrapolates singleton-cone necessity to general sufficiency without justification.

2. EXISTENCE AND BRANCH ANALYSIS

Both submissions correctly split the coefficient vectors at the dominance condition.

If a_m >= sum_{i != m} a_i, theta = e_m works. When x_m <= 0, its square is already in the negative sum. When x_m > 0, the balance condition and Cauchy–Schwarz show

    a_m x_m^2 <= (sum_{i != m} a_i) sum_{x_i < 0} x_i^2.

This proves sufficiency including equality in dominance. The explicit single-positive witness gives negative energy a_m/sum_{i != m} a_i when x_m = 1, proving necessity as well. The denominator is positive because n >= 2 and all a_i > 0.

Otherwise choose a_m maximal and set b = 1/(4a_m). On [0,b] the smaller roots

    h_i(t) = (1 - sqrt(1 - 4t a_i))/2

are real, continuous, strictly increasing, and satisfy h_i(1 - h_i) = t a_i. There are two exhaustive cases:

  • If sum_i h_i(b) >= 1, continuity and strict monotonicity give a unique
    positive root of sum_i h_i(t) = 1. All weights are positive, including
    when the root is the endpoint b.

  • If sum_i h_i(b) < 1, put g(t) = sum_{i != m} h_i(t) - h_m(t).
    Strict nondominance gives g(t)/t -> sum_{i != m} a_i - a_m > 0
    as t decreases to zero. Since h_m(b) = 1/2, g(b) < 0. Thus a root
    exists strictly inside (0,b). Replacing h_m by 1 - h_m makes the
    weights sum to one and preserves all quadratic products.

This is a valid existence proof for every strictly nondominant coefficient vector. It does not accidentally select the root g(0) = 0. It also does not need monotonicity of g or uniqueness of the second root. The square-root endpoint, ties among maximal coefficients, and an endpoint value sum_i h_i(b) = 1 introduce no gap. In particular, two tied maxima already contribute 1 at b, so the second branch cannot require an arbitrary choice between tied maxima.

A specifies a terminating dyadic search for a positive-sign lower endpoint before bisection. B states the sufficiently small endpoint and proves it exists; a dyadic search immediately implements that statement. This difference is additional algorithmic explicitness in A, not an incompleteness in B.

3. DEGENERATE AND BOUNDARY CASES

Zero weights: Neither submission divides by theta_i before it is established to be positive. Nonvertices may initially have zeros; the necessity argument then excludes them. Vertices are handled separately before any denominator 1 - theta_m could vanish.

Singular S: Both proofs work entirely with the scalar inequality and never invert S. A vertex gives S = v_m v_m^T, which has rank one since v_m is nonzero and is singular exactly when r > 1. Strictly positive weights give positive definite S because the v_i span R^r. Thus singularity is explicitly covered, not dismissed by an implicit positive-definiteness assumption.

Dimension one: Here n = 2 and a maximal entry is always dominant. If a_1 > a_2, only e_1 is feasible; if a_2 > a_1, only e_2 is feasible. If a_1 = a_2, every probability vector is feasible: vertices pass the dominance test, and every interior probability vector satisfies the quadratic identity with a suitable positive T. Both characterizations are consistent with this special case.

Dominance equality for n >= 3: The vertex construction remains valid. An interior certificate cannot occur at equality, since the quadratic identity gives positive complete-graph edge weights T theta_i theta_j and

    sum_{j != i} a_j - a_i
      = 2T sum_{j < l, j != i, l != i} theta_j theta_l > 0.

Thus there is no hidden interior solution required at the boundary. A states this graph interpretation explicitly; it also follows from B's identity.

Zero coordinates of x and x = 0: Omitting zero coordinates from the positive and negative sets is legitimate, and both texts address the zero vector. All Cauchy–Schwarz denominators used in the nonzero case are positive.

Unequal coefficients and the common quadratic: The reduction uses the actual supplied v_i and their positive kernel vector, with no equality of norms or coefficients assumed. The final common-Q identity follows exactly from sum_i theta_i = 1 and the established scalar bound. There is no additional assumption on Q needed for that conclusion.

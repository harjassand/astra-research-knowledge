\section{Coherent balanced words: an exact filter and its limits}\label{sec:filter}

Let $\mathcal D_m$ be the $C_m2^m$-dimensional colored-Dyck input space of length $2m$. A colored symbol is a push, $0$ is a pop, and each prefix has nonnegative height. The inherited map $F$ sends a push to output $0$ and a pop to the color of its matched push. Let $J_m,J'_m$ be the inclusions of this abstract basis into the input and ideal-output spaces. The original whole-bath identity is
\[
 W_{2m,0}(J_m\otimes I_E)=J'_m\otimes I_E.
\]

\begin{theorem}[A coherent return filter]\label{thm:filter}
There is an explicit finite matrix $T_m(s)$ such that
\begin{equation}
 (J_m'^*\otimes I_E)W_{2m,s}(J_m\otimes I_E)=T_m(s)\otimes I_E.
 \label{eq:filter}
\end{equation}
For every $m\ge1$, $\norm{T_m(s)}=\alpha^2$. An explicit $(m+1)$-dimensional subspace has $T_m(s)=\alpha^2 I$. The accepted projection returns the entire bath on that subspace with probability $\alpha^4$. This is an outcome-conditioned filter with all other outcomes still counted, not a deterministic noiseless code.
\end{theorem}
\begin{proof}
For input Dyck word $w$ and ideal output $F(z)$, compare their two Dyck heights $H_w,H_z$. A push in both $w,z$ forces $\alpha S_a$. A pop in both forces $\alpha S_b^\dagger$. An input push and a $z$-pop force $i\beta I$, provided their colors agree. An input pop and a $z$-push nominally allow $\alpha R+i\beta I$.

The relative bath height of the forced move history is $(H_w+H_z)/2$. It is an integer, never negative, and ends at zero. Just before a possible $R$ term, $w$ is about to pop, so $H_w\ge1$; the two heights have the same parity, hence their sum is at least two. The internal stack is nonempty and $R$ annihilates that term. Every forced pop closes an internal push and never reads the initializer. If one color match fails the amplitude vanishes; otherwise all bath operators cancel to $I_E$. If $2r$ forced moves occur, the matrix entry is
\begin{equation}
 T_m[z,w]=(-1)^{m-r}\alpha^{2r}\beta^{2m-2r}.
 \label{eq:filterentry}
\end{equation}
This proves \eqref{eq:filter} on the entire bath, including both seed vacua.

For a unit color vector $c=c_1\ket1+c_2\ket2$, let
\[
 S_c=c_1S_1+c_2S_2,\qquad
 \chi_c=\frac{\ket{0,c}-\ket{c,0}}{\sqrt2}.
\]
The relations $RS_c=0$ and $S_a^\dagger S_c=c_a I$ give directly
\[
 (U_1+U_2)(\chi_c\otimes S_c\psi)=0,\qquad
 U_2U_1(\chi_c\otimes S_c\psi)=-\chi_c\otimes S_c\psi.
\]
Expansion of $V_{s,2}V_{s,1}$ and $\alpha^2+\beta^2=1$ yield the exact interference identity
\begin{equation}
 W_{2,s}(\chi_c\otimes S_c\psi)=-\chi_c\otimes S_c\psi.
 \label{eq:darkpair}
\end{equation}
Now use the length-$2m$ vector
\[
 \ket c\otimes\chi_c^{\otimes(m-1)}\otimes\ket0.
\]
All basis words in this vector are Dyck words. On the accepted balanced-output event the first and last calls must move, each supplying $\alpha$. After the first push the stack is $S_c\psi$; every internal pair obeys \eqref{eq:darkpair}. Its signs are exactly those of the ideal map $F$. Hence $T_m$ acts as $\alpha^2 I$ on the span of these vectors. The linear isometry that sends the first color qubit to the first port and every remaining one to $\chi_c$, then appends $0$, maps $\operatorname{Sym}^m(\mathbb C^2)$ onto this span. Its dimension is $m+1$, because the powers $c^{\otimes m}$ span that symmetric space.

For the upper norm bound, every allowed input begins with a colored symbol and every allowed output begins with $0$, so the first projected interaction has norm $|\alpha|$. Every input ends with $0$ and every allowed output ends with a color, so the last projected interaction also has norm $|\alpha|$. Other interactions are unitary and the remaining projections are contractions. Therefore $\norm{T_m}\le\alpha^2$, and the constructed subspace attains equality. Squaring gives its accepted probability $\alpha^4$.
\end{proof}

At $m=2$, order words as separate pairs $(a,0,b,0)$ and nested pairs $(a,b,0,0)$. With the matching ideal-output ordering,
\[
 T_2=\alpha^4I_8-\alpha^2\beta^2
 \begin{pmatrix}0&\mathrm{SWAP}\\I_4&0\end{pmatrix}.
\]
The last matrix is unitary and its fourth power is identity. The maximal singular value is $\alpha^2$, with multiplicity three for $\alpha\beta\ne0$. Thus the gain over the all-move amplitude $\alpha^4$ is real constructive interference. The known protected subspace has only dimension $m+1$ at general $m$; no claim that it exhausts the maximal singular subspace is made.

\subsection{A dimension obstruction to this route exceeding the floor}

Even a perfect code using \emph{all} colored Dyck inputs has dimension only $C_m2^m=2^{3m-O(\log m)}$. The larger critical type space of Section~\ref{sec:depth} has dimension $2^{3n/2-O(\log n)}$. No isometric code confined to either family can exceed rate $3/2$ asymptotically. Exact bath-return filtering within them can improve a finite operation or establish the floor, but cannot settle the live target of a rate strictly above it. The explicit interference-protected subspace is smaller still, with $\log_2(m+1)/(2m)\to0$.

This closes the proposed strategy of finding the desired gain \emph{solely inside the balanced input space}. It does not rule out coherent superpositions across larger composition sectors, a different decoder using all branches and output syndromes, or a capacity gain in the original device.

\section{A finite exact-code obstruction, without an asymptotic inference}\label{sec:exactobstruction}

\begin{proposition}[Two calls have no nontrivial exact subspace code]\label{prop:twonocode}
For $\alpha\beta\ne0$ and any fixed faithful vertex-diagonal initializer, including $\tau_\pi$, there is no exact two-forward-call subspace quantum code of dimension $K\ge2$. An arbitrary deterministic decoder and logical-independent bath evolution are allowed; bath return is not required.
\end{proposition}
\begin{proof}
The Kraus family contains $\sqrt{\pi(v)}A_{w,v}$ for every initial and final vertex, with
$A_{w,v}=\bra w W_{2,s}\ket v$. Faithfulness makes every initial weight nonzero. An exact $K\ge2$ code must lie in the kernel of any rank-one Kraus error: its compressed positive square has rank at most one but the Knill--Laflamme condition makes it a scalar times $I_K$, forcing that scalar to be zero.

For a final vertex at graph distance two from the start, both interactions must move. The unique geodesic fixes the input word, and the endpoint error is a nonzero rank-one map $\alpha^2\ket y\bra x$. The input $00$ can follow two ancestor edges from a sufficiently deep vertex. Each $0a$, $a=1,2$, can pop then push a different child color to a sibling. Every $ab$ with $a,b=1,2$ follows two child edges. Thus the seven words $00,01,02,11,12,21,22$ must all be orthogonal to the code, leaving only $\operatorname{span}\{10,20\}$.

Fix an ordinary deep vertex $v$ and its child of color $a$. A one-edge endpoint in two slots requires exactly one move by parity. On the remaining space its error is
\[
 A_{va,v}\ket{b,0}=i\alpha\beta\delta_{ab}\ket{0,0}.
\]
These two rank-one errors have kernels with zero intersection in the remaining space. No $K\ge2$ code exists. All paths use actual vertices; no finite-tree boundary is introduced.
\end{proof}

The endpoint assumptions are essential: the original two-word Dyck code is exact at $\beta=0$, while $\alpha=0$ is the identity device. The proposition concerns exact subspace codes at two calls. It is compatible with the long approximate codes of Theorem~\ref{thm:floor}. It does not prove an all-block exact obstruction or an asymptotic capacity converse. The recorded three-call modular operator-system and rank-one-kernel probes were inconclusive and remain explicit non-results.

There is also a one-use gauge obstruction. The five independent bath coefficients of $U$ are $R,S_1,S_2,S_1^\dagger,S_2^\dagger$, with five independent port coefficients. For $\alpha\beta\ne0$, $V_s$ adds an independent bath identity with port coefficient $I_3$. Its operator Schmidt rank is six, while that of $U$ is five. Invertible local unitary pre/postprocessing preserves this rank, so it cannot gauge $V_s$ back to $U$ in one use. This says nothing about block equivalences or capacity equality.

\section{Why diagonal bias fails, and the next coherent operation}\label{sec:continuation}

\begin{proposition}[A limited compression obstruction]\label{prop:biased}
For fixed diagonal data input $\eta_q$, $q<1/2$, and $\alpha\ne0$, put $\mu=\alpha^2(1-2q)>0$. For every normal initializer and $h<\mu n$,
\begin{equation}
 \Tr[P_{\lfloor h\rfloor}\Phi_{s,q}^n(\tau)]
 \le\exp[-(\mu n-h)^2/(2n)].\label{eq:biased}
\end{equation}
Thus any sublinear-depth coordinate cutoff contains asymptotically vanishing mass under this product data input.
\end{proposition}
\begin{proof}
In Lemma~\ref{lem:depth}, the unreflected sum $S_n$ has mean $\mu n$ and increments in $[-1,1]$. Reflection only raises its position: $Y_n\ge Y_0+S_n\ge S_n$. The centered Chernoff bound gives $\Prob(S_n\le h)\le e^{-(\mu n-h)^2/(2n)}$. The exact observable identity transfers it to every initial depth marginal, with no moment assumption.
\end{proof}

Moving $q$ just below $1/2$ raises the diagonal input entropy above $3/2$, but it also makes the bath climb linearly. Consequently the critical proof cannot be extended merely by changing the input proportions and keeping its sublinear-depth compression. This is a failure of that sufficient method, not evidence that the quantum information necessarily leaks at the same rate as the geometric depth.

The same failure holds for the uniform fixed-composition type with $nq$ zeros when $nq$ is an integer: its state is bounded by $\eta_q^{\otimes n}$ divided by its binomial type probability, which is only polynomially small. Applying this domination to the \emph{low-depth} event in \eqref{eq:biased} leaves exponentially vanishing mass. This still does not exclude exceptional coherent subspaces chosen by a different method.

\subsection{An exact drift identity retaining input coherence}

For a general port density $\rho$, let
\[
 q=\rho_{00},\quad \gamma_a=\rho_{a0},\quad
 p=\Tr(\tau P_0),\quad z_a=\Tr(\tau S_a).
\]
The bounded increment of depth for the product input $\rho\otimes\tau$ is
\begin{equation}
 d_s(\rho,\tau)=\alpha^2(1-2q+qp)
 +2\alpha\beta\operatorname{Im}\sum_{a=1}^2\gamma_a z_a.
 \label{eq:coherentdrift}
\end{equation}
To see this, on the domain of $I\otimes L$ the difference extends to the bounded operator
\begin{align*}
 V_s^*(I\otimes L)V_s-I\otimes L
 ={}&\alpha^2\big[(I_3-2\ket0\bra0)\otimes I_E+\ket0\bra0\otimes P_0\big]\\
 &+i\alpha\beta\sum_{a=1}^2
 \big[-\ket0\bra a\otimes S_a+\ket a\bra0\otimes S_a^\dagger\big].
\end{align*}
Taking its expectation gives \eqref{eq:coherentdrift}, including its sign. When $\Tr\tau L<\infty$ it is the ordinary difference of mean depths. For infinite mean it is the limit of capped-depth differences, not subtraction of two infinities. The capped increments are uniformly bounded and converge strongly, so normality permits this limit.

For every normal density,
\[
 \sum_a|z_a|^2\le1-p,\qquad
 \sum_a|\gamma_a|^2\le q(1-q).
\]
For the first inequality, any unit linear combination $S_c$ is an isometry whose range is contained in the nonvacuum space, and Cauchy--Schwarz in the state gives $|\Tr\tau S_c|^2\le\Tr\tau S_cS_c^\dagger\le1-p$; optimize $c$. The second follows from positivity of the block matrix $\rho$. Thus a necessary one-step condition for zero drift is
\begin{equation}
 \alpha^2(1-2q+qp)\le2|\alpha\beta|\,\norm\gamma\sqrt{1-p}.
 \label{eq:necessarydrift}
\end{equation}
This condition allows coherent cancellation missed by the diagonal drift calculation. It is only necessary and does not prove a stationary normal bath, tight tails, low complementary information, or a code.

\begin{proposition}[Stronger product stationarity cannot supply high input entropy]\label{prop:product}
If $\alpha\ne0$ and $V_s(\rho\otimes\tau)V_s^*=\rho\otimes\tau$ for a normal bath density, then $q>1/2$ and $S(\rho)<3/2$ bits.
\end{proposition}
\begin{proof}
Unitary invariance is equivalent to commutation, and $[V_s,X]=\alpha[U,X]$. Hence the product also commutes with $U$. The color--color block of $U(\rho\otimes\tau)U=\rho\otimes\tau$ gives
\[
 qS_a^\dagger\tau S_b=\rho_{ab}\tau.
\]
$q=0$ is impossible after summing diagonal color traces. If $m_\ell=\Tr[1_{\{\ell\}}(L)\tau]$, summing those blocks gives
\[
 q m_{\ell+1}=(1-q)m_\ell\qquad(\ell\ge0).
\]
Normality requires $\sum_\ell m_\ell=1$. A zero $m_0$ would force all masses zero, and a ratio $(1-q)/q\ge1$ would make their sum infinite. Thus $q>1/2$. Pinching $\rho$ into its zero/color blocks and maximizing the color entropy show
\[
 S(\rho)\le h_2(q)+(1-q)<3/2.
\]
The strict inequality follows because the last expression is decreasing for $q\ge1/2$.
\end{proof}

\subsection{Chosen next question and concrete starting family}

The continuation will test whether coherent input can stabilize the \emph{reduced} bath, or otherwise keep its relevant information subextensive, at input entropy above $3/2$. The stronger product-stationarity route is ruled out by Proposition~\ref{prop:product}. The diagonal-bias route is ruled out for sublinear-depth compression by Proposition~\ref{prop:biased}. Neither obstruction settles reduced quantum dynamics with persistent port--bath correlations.

Fix once and for all $\beta=1/512$, $\alpha=\sqrt{1-\beta^2}$, and keep the actual initializer $\tau_\pi$. A concrete finite-parameter seed is
\begin{equation}
 \rho_{q,g}=\begin{pmatrix}q&ig&0\\-ig&(1-q)/2&0\\0&0&(1-q)/2\end{pmatrix},
 \qquad q=\frac12-\frac{3\beta^2}{32},\qquad g=\frac\beta8.
 \label{eq:seed}
\end{equation}
Its positivity and entropy are elementary finite-matrix checks; they are not the scientific bottleneck. Writing $a=(1-q)/2$, its eigenvalues are
\[
 a,\qquad \frac{q+a\pm\sqrt{(q-a)^2+4g^2}}2.
\]
The executable source supplies a certified entropy interval strictly above $3/2$ for this one rationally specified density. The small-$\beta$ expansion is
\[
 S(\rho_{q,g})=\frac32+\frac{\beta^2}{32}+O(\beta^4).
\]
For a bath with real positive $z_1$, its drift cross term is $-2\alpha\beta g z_1$, which can oppose the positive diagonal drift. This makes it a concrete candidate to test, not a construction of a stable bath.

The next load-bearing obligation is to construct a normal invariant state with controlled tails, or prove a corresponding uniform compression/entropy estimate along $\Phi_{s,\rho_{q,g}}^n(\tau_\pi)$, where
\[
 \Phi_{s,\rho}(\tau)=\Tr_{\rm port}V_s(\rho\otimes\tau)V_s^*.
\]
If an invariant state is found with a different initializer, reachability from $\tau_\pi$ with counted, sublinear preparation cost is an additional obligation; it may not be presumed. A finite reflecting-bath simulation necessarily has a stationary state and is not evidence of normal tightness on the infinite tree. A zero one-step drift is also insufficient. If the candidate produces extensive bath information or the required uniform compression fails, retire that candidate and use the failure to refine the capacity question.

An eventual rate claim must still pass from a controlled whole-block complementary process to a deterministic arbitrary-reference code; marginal entropy or a finite block rank alone will not suffice. The present checkpoint deliberately leaves this hard step open. It does not change $s$ with the horizon, replace coherent amplitudes by probabilities, or borrow another owner's programme.

\section{Exact final-bath overlap calculus}\label{app:overlap}

This finite symbolic calculus is supplied to make the next operator investigation replayable without a reflecting cutoff. Let $L_u$ denote creation of a finite color word $u$, with the empty word giving identity. Put
\[
 F_{uv}=I_2\otimes L_uL_v^\dagger,\qquad
 K_{uv}=X\otimes\ket u\bra v.
\]
Finite products of the entries of \eqref{eq:matrix} lie in their finite linear span. For words $u,v,x,y$, the products are determined by prefix matching:
\begin{align*}
 F_{uv}F_{xy}&=F_{uw,y}&&\text{if }x=vw,\\
 F_{uv}F_{xy}&=F_{u,yw}&&\text{if }v=xw,\\
 F_{uv}K_{xy}&=K_{uw,y}&&\text{if }x=vw,\\
 K_{uv}F_{xy}&=K_{u,yw}&&\text{if }v=xw,\\
 K_{uv}K_{xy}&=\delta_{v,x}\left(F_{uy}-\sum_{a=1}^2F_{ua,ya}\right).
\end{align*}
If the stated prefix condition fails, the corresponding product is zero. The coincident case in the first two rules is counted only once. Adjoints exchange the two word indices. These rules follow by cancellation of $L_a^\dagger L_b$ and the vacuum identity $P_{\rm vac}=I-\sum_aL_aL_a^\dagger$.

For the original stationary bath, with $\vartheta=1/6$,
\[
 \Tr(\tau_\pi F_{uv})=\delta_{u,v}\vartheta^{|u|},\qquad
 \Tr(\tau_\pi K_{uv})=0.
\]
The first formula sums the mass of the prefix cylinder, and the second uses the equal diagonal seed mixture. For input/output words $x,y$ define
\[
 A_{yx}=B_{y_nx_n}\cdots B_{y_1x_1},\qquad B_{ba}=\bra b V_s\ket a.
\]
Then the exact reduced block matrix element is
\begin{equation}
 \bra y\mathcal N_{n,s}^\tau(\ket x\bra{x'})\ket{y'}
 =\Tr[\tau A_{y'x'}^\dagger A_{yx}].\label{eq:kernel}
\end{equation}
The multiplication and trace rules compute \eqref{eq:kernel} with finitely many symbolic terms for each finite block. Nonorthogonal $F$ terms retain the coherent final-bath overlaps. Replacing them by independent history weights discards exactly this information. For arbitrary coherent $\tau$, the algebra remains valid but its trace functional must be evaluated for that actual state; the odd/even seed orthogonality is specific to $\tau_\pi$.

\section{Receiving use and preserved assumptions}

Keep the auxiliary normalizer separate from the physical encoder. To reuse the exact two-call operation, retain the full decoder syndrome or dephasing flag in the dilation and use only its designated reduced logical interface when invoking memoryless erasure coding. To reuse the balanced filter, keep the failure outcomes in any unconditional communication cost and error. The counterexamples in Section~\ref{sec:compression} and Section~\ref{sec:erasure} show that weaker average or marginal assumptions are insufficient.

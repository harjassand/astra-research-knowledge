PRIMARY ENDPOINT: NEGATIVE. A family of fan graphs defeats ALL real dense
three-column designs with row norms at most one. The proof below is an
analytic all-design lower bound for the OPERATOR/Frobenius-action ratio.
Numerical checks are supplementary and are not premises of the proof.

1. Statement and explicit graph family

For m >= 4, let F_m have vertices 0,1,...,m, with edges

  {0,i}, 1 <= i <= m, and {i,i+1}, 1 <= i < m.

All diagonal entries are also permitted. The bags {0,i,i+1}, 1 <= i < m,
in their natural path order give a tree decomposition of width two: every
edge belongs to a bag, vertex 0 belongs to all bags, and every other vertex
belongs to one or two consecutive bags. Thus this is an explicit family of
graphs of treewidth at most two (in fact exactly two).

For X in R^((m+1) x 3), define

  C_2(F_m,X) = sup_{0 != D = D^T supported on F_m} ||D||_2 / ||DX||_F,

with value infinity if the action map is noninjective. Every query row is
assumed to have Euclidean norm at most one. Then

  C_2(F_m,X) >= max {1,
    [2 sqrt(m-1) sin(3 pi/(2m))]^(-1/2)}
             >= max {1, m^(1/4)/sqrt(3 pi)}.                 (1)

Consequently the infimum of C_2(F_m,X) over ALL such X tends to infinity.
In particular there is no constant C independent of graph size and maximum
degree with the property requested in the experiment.

The rate in (1) is a lower bound only, and is not claimed sharp. The family
has maximum degree m; no impossibility for a bounded-degree subfamily is
claimed here. The question allowed unbounded degree, so this family answers
the stated endpoint.

2. Degenerate designs and a local row-cap obstruction

Write x_i for the column transpose of row i of X. If x_0=0, a nonzero
diagonal supported at vertex 0 has zero action, so C_2=infinity.

Otherwise set r_0=||x_0||>0 and u=x_0/r_0. Decompose each leaf query row as

  x_i = z_i + t_i u,   z_i perpendicular to u,   t_i=<x_i,u>.

Choose any orthonormal coordinates identifying u-perpendicular with R^2.
Write r_i=||z_i||. Since ||x_i||<=1, we have r_i<=1.

If det(z_i,z_(i+1))=0 for any i, the three rows x_0,x_i,x_(i+1) are linearly
dependent. Let a nonzero vector w, supported on those three vertices,
satisfy w^T X=0. The matrix ww^T is supported on their triangle in F_m,
is nonzero and symmetric, and annihilates X. Again C_2=infinity. This also
handles any z_i=0, since every leaf belongs to at least one such triangle.

We may therefore assume all adjacent projected determinants are nonzero,
and in particular

  delta := min_{1<=i<=m} r_i > 0.

For each i, let w have w_i=1, w_0=-t_i/r_0, and all other entries zero.
Then w^T X=z_i^T, and ww^T is supported on the edge {0,i} and its diagonals.
For this rank-one symmetric matrix,

  ||ww^T||_2 / ||ww^T X||_F
      = ||w||/||z_i|| >= 1/r_i.

Choosing the smallest r_i gives the first uniform-in-X bound

  C_2(F_m,X) >= 1/delta.                                    (2)

This step explicitly uses the allowed diagonal entries. It does not assume
unit query-row norms, and it does not apply a monotone rescaling argument.

3. Path flow in the two-dimensional quotient

Let J = [[0,-1],[1,0]], and let c_0=c_m=0, with c_1,...,c_(m-1) to be
chosen. Put

  Delta_i = det(z_i,z_(i+1)),
  b_i = c_i/Delta_i,  1<=i<m,

and define a real symmetric tridiagonal m-by-m matrix B by

  B_(i,i+1)=B_(i+1,i)=b_i,
  B_ii = -[b_(i-1)<z_i,z_(i-1)> + b_i<z_i,z_(i+1)>]/r_i^2,

where terms outside the path are omitted. Let Z be the m-by-2 matrix with
rows z_i^T. Resolving each neighboring row into its components parallel and
perpendicular to z_i gives the exact identity

  (BZ)_(i,:) ^T = (c_i-c_(i-1)) J z_i / r_i^2.               (3)

For completeness, the right-neighbor perpendicular component is
det(z_i,z_(i+1)) Jz_i/r_i^2, and the left-neighbor one is
-det(z_(i-1),z_i) Jz_i/r_i^2. The chosen diagonal cancels the parallel
components. Thus (3) has no uncontrolled propagation or approximation.

It follows that

  ||BZ||_F^2 = sum_{i=1}^m (c_i-c_(i-1))^2/r_i^2
             <= delta^(-2) sum_{i=1}^m (c_i-c_(i-1))^2.      (4)

Also |Delta_i| <= r_i r_(i+1) <= 1, so

  ||B||_2 >= max_i |b_i| >= max_i |c_i|
          >= ||c||_2/sqrt(m-1).                             (5)

The first inequality is the elementary operator-norm bound on each matrix
entry. It does not replace the recovery target by the Frobenius norm.

4. Two global constraints can be absorbed by three slow flow modes

Let S be the three-dimensional subspace of R^(m-1) spanned by

  s_k(i)=sin(k pi i/m),  i=1,...,m-1,  k=1,2,3.

These modes are linearly independent for m>=4. The Dirichlet path
difference-energy matrix has diagonal 2 and adjacent entries -1. Its
eigenvectors s_k have eigenvalues

  lambda_k = 4 sin^2(k pi/(2m)).

The identity follows directly by substituting s_k into
2c_i-c_(i-1)-c_(i+1). Orthogonality of the three sine modes, or symmetry
and their distinct eigenvalues, therefore gives, for every c in S,

  sum_{i=1}^m(c_i-c_(i-1))^2
       <= 4 sin^2(3 pi/(2m)) ||c||_2^2.                     (6)

Write t=(t_1,...,t_m)^T. The map

  c in S  ->  t^T B(c) Z in R^(1 x 2)

is linear by (3). It has at most two independent scalar constraints.
Since dim S=3, there is a NONZERO c in S such that

  t^T B(c) Z = 0.                                          (7)

This is an existence argument over an explicit three-dimensional space,
not a selection of finitely many test vectors for the desired operator
inequality. All the constructed constraints are imposed exactly.

5. Lift the path witness to the fan, with zero apex action

For the nonzero c above, set

  L = [ -t^T/r_0 ]       (an (m+1)-by-m matrix),
      [    I_m   ]

and D = L B L^T. In blocks this is

  D = [ t^T B t/r_0^2     -t^T B/r_0 ],
      [ -B t/r_0                B   ].

It is symmetric. Its leaf block is tridiagonal, and its only remaining
off-diagonal entries are apex-to-leaf entries, all permitted by F_m.
Thus D has exactly the required support. Its principal leaf block is B,
so ||D||_2 >= ||B||_2 and D is nonzero.

After a common orthogonal rotation of the three query coordinates, the
rows of X can be written as

  X = [ 0  0  r_0 ],
      [    Z    t ].

Therefore L^T X=[Z,0] and

  DX = [ -t^T BZ/r_0   0 ] = [ 0  0  0 ],
       [      BZ       0 ]   [    BZ   0 ],                (8)

where the top row vanishes by (7). Orthogonal rotation does not change
Frobenius action norm. Combining (4)-(8) yields

  ||D||_2/||DX||_F
    >= delta/[2 sqrt(m-1) sin(3 pi/(2m))].                  (9)

The denominator ||DX||_F is nonzero: if it were zero, (3) would force all
differences c_i-c_(i-1) to vanish, and the boundary value c_0=0 would force
c=0, a contradiction. All divisions in this nondegenerate case are valid.

6. Optimize the two valid witnesses and conclude the all-design result

Let Q_m = [2 sqrt(m-1) sin(3 pi/(2m))]^(-1). Equations (2) and (9) say

  C_2(F_m,X) >= max{1/delta, delta Q_m}
             >= sqrt(Q_m).

The last inequality follows because the maximum of two positive numbers
is at least the square root of their product. Since delta<=1, (2) also
gives C_2>=1. Finally sin y<=y yields

  Q_m >= m/[3 pi sqrt(m-1)] >= sqrt(m)/(3 pi),

which proves (1). Each step holds for an arbitrary fixed capped X, with
the singular cases handled separately. Taking the infimum over all dense
real X therefore preserves this divergent lower bound.

7. Decoder implication and computational scope

No exact-recovery decoder can have a dimension-independent adversarial
Frobenius-noise-to-operator-error constant for three capped queries on
these supports. Indeed, if a decoder R_X obeys

  ||R_X(A X+E)-A||_2 <= C ||E||_F

for all supported symmetric A and all E, taking E=0 requires exact
recovery. Set A=0 and E=DX. Exact recovery on the noiseless datum DX also
requires R_X(DX)=D, and consequently ||D||_2<=C||DX||_F. Inequality (1)
rules out a universal C. This argument permits nonlinear decoders.

The counterexample graph has O(m) vertices and edges. Given a
nondegenerate X, a sparse witness can be constructed with O(m) real
arithmetic operations and O(m) storage after evaluating a constant number
of trigonometric constants: project rows, form three sine modes by
recurrence and their
2-by-3 constraint matrix, take a nonzero null vector, and form B and the
apex row. This is an exact-real-arithmetic construction, not a claim of
bit complexity or uniform floating-point conditioning. Rank-one witnesses handle the
degenerate cases and the local lower bound. The supplementary Python
checks use dense small matrices only for independent numerical evaluation.

9. A matching query-count upper bound on this particular family

Four queries suffice uniformly on the fan family itself. Take the apex
row to be e_4 in R^4, and let the leaf rows cycle e_1,e_2,e_3 along the
path. Every row has norm one. Each diagonal is read from the corresponding
vertex's own color. Each apex-leaf coefficient is read from the leaf's
fourth action coordinate. Each path coefficient is isolated at either
endpoint in the coordinate of the other endpoint's color, because a leaf
and its two path neighbors have three distinct colors.

Choose one of the two isolated cells for each path edge. All chosen cells
for diagonals and edges are distinct. The direct-read symmetric decoder
therefore obeys ||Dhat-D||_F <= sqrt(2)||E||_F, and hence the same operator
bound, with O(m) work and storage after four actions. Equivalently, one can
read both ends to see directly that the action energy contains every
diagonal square, twice every path-edge square, and once every apex-edge
square, plus nonnegative squares of apex aggregates.

Together with (1), this establishes that FOUR is the minimum fixed query
count for uniform stability on the fan family. The construction is an
elementary instance of the supplied classical star-coloring mechanism;
no novelty is claimed for that mechanism. This does not establish a
four-query upper bound for all graphs of treewidth at most two.

## Limits that remain active

The upper is not a converse for unrestricted capacity or feedback. It does
not cover correlations between input blocks or charge-changing coherences.
The all-normal upper is uniform; the same-code lower convergence is pointwise.
The explicit k=4 upper threshold is far below beta=1/512. Fixed k and k
growing with beta are different limits. No useful finite blocklength,
efficient code compiler, terminal bath return or material implementation is
established. The primary comparison is bounded, not an exhaustive novelty
audit. External scientific acceptance and repository integration are not
reported by this checkpoint.

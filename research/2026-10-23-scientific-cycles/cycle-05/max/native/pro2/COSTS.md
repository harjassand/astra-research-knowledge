## Operation-level costs under the scientific contract

The coordinate operation takes a known support and an admitted coloring or
supplied structural representation. Verifying properness, building pairwise
components, checking acyclicity and evaluating component/cut certificates cost
O(nq+m) arithmetic/work and storage. For fixed q and bounded degree this is
O(n). Each new observation is decoded in the same arithmetic order using
component means and subtree sums. It needs exactly q actions; q=4 for the
new banded/prism operations, q=5 for the ordinary banded isometry comparator.

These counts include representation validation/construction from the supplied
bandwidth order or forest-parent representation. Finding such a representation
for an arbitrary graph is not supplied or counted free. The general five-query
17-color square/full-spark operation remains the full-class upper comparator.
No implementation timing of that entire general comparator was claimed here.

Exact arithmetic bit cost depends on input bit lengths and component size;
the O(n) statement counts arithmetic operations. The banded and degree-bounded
prism blocks have constant size, but this does not turn arbitrary input
conversion or physical acquisition into a constant cost. Source formation,
reading all action entries, and downstream spectral inference remain chargeable.

## Error accounting

All seeds have total row energy at most one. Coordinate seeds have exactly
representable0/1 rows of norm one. The signed helper seed is Z/sqrt2, not Z;
its saved tests explicitly use noise squared ||E0||F^2/2. The rational local
completion seed has squared row norm1/2.

All error theorems use the absolute Frobenius norm of the entire action block,
permit correlated/adversarial noise, and produce a supported symmetric output.
The main generic bound is directly in operator norm; banded/prism bounds are
stronger Frobenius bounds. Their conversion to operator norm costs no missing
dimension factor. The lower witness only uses ||D||2>=|D_e|, an exact bound.

For the generic coordinate decoder, numerical error can be charged through
R=Dhat X-PY, where P is the exact componentwise least-squares action projection:

    ||Dhat-D||2 <= C (||E||F+||R||F).

The residual must itself be rigorously bounded. Query implementation error
deltaX contributes D deltaX and requires its own operator/input bound. No
floating solver success status, separately rounded graph or uncharged query
matrix is used in the exact saved evidence. The tests and independent check
use Fraction arithmetic; numerical certification of a faster floating
implementation is not claimed completed.

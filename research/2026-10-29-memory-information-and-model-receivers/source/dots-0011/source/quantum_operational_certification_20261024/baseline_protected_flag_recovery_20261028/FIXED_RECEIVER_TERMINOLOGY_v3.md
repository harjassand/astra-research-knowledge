# Fixed-X receiver score is not an acquired oracle equality
2026-10-29. Governs interpretation of diagnostic field names and README statements.

The program fields containing `informed_Helstrom_score` evaluate the SAME fixed X-basis flag receiver at every history. That is the Helstrom receiver for the uncoupled equal-prior flag pair. With unequal branch priors and the actual flag-memory coupling it is not proved to be the history-dependent Helstrom optimum. Thus .9897999722 is the observed common fixed-X receiver fidelity and a LOWER bound on the full-CPTP oracle, not an equality with that oracle.

The governing HIGH_ORACLE_SOURCE_v1.md already uses the safe statement that the informed fixed receiver supplies a lower bound; its conservative bound above .97989 remains valid. The independent review gives the stronger exact fixed-X formula [1+sqrt(1-c^2)cos(2kappa)]/2. No records, controller parameters or earlier files are changed by this terminology correction.

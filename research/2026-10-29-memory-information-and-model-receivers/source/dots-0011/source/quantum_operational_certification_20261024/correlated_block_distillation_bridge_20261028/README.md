# Correlated block distillation comparator

28 October2026. Scientific alternative/comparator construction, author derivation pending independent review.

New material: exact finite sampling bound for the accepted bad mass of a fixed executable distillation code under arbitrary correlated Bell errors; standard bilateral twirling turns an arbitrary isolated output block into that interface. Concrete125-pair/25-retained instance has exact bad-acceptance bound97106/217474455. A twice-concatenated five-qubit code is specified with a finite minimum-weight decoder, not merely capacity existence. A retained arbitrary source environment is allowed; no channel reconstruction is used.

What this enables: a current block can be checked and distilled before a fresh unknown payload is teleported. Candidate pair generation may use imperfect learned frames without extrapolating them into future stationary noise. It pays for bipartite stored qubits, late random test selection, classical communication and trusted distillation/teleportation controls.

Scope: existing entanglement distillation/QKD machinery is the strongest conventional alternative, not a claimed Astra invention. No laboratory data, physical sampling, historical priority, useful yield under arbitrary sources or complete noisy25-qubit implementation is established. Acceptance is heralded; bound is success-weighted, not automatically conditional. Gates/storage faults after isolation need an actual whole-protocol error budget.

Programs: `python exact_block_test_v1.py` recomputes all rational tail values and stabilizer checks; `python operation_checks_v1.py` checks the base-code bilateral maps and pair/environment twirl numerically. Outputs are `.json`; no external packages except NumPy for the second program. Original Astra sources are unchanged. No result is superseded.

Dependencies: ordinary stabilizer-code/distillation constructions, credited primary sources in governing proof.

# Empty selected image and immutable candidate scope

28 October2026. Clarification to GOVERNING_ORBIT_FRAME_v1.md. Original v1 preserved unchanged.

The existence of H-invariant seeds(s>0) does not imply that a particular selected set S has nonzero image. For example, lambda differs from mu and S contains only the trivial irrep. Therefore the reference-channel and beta formulas in Section7 apply only when N=rank(Pi_S)>0. If N=0, W_A=0, the selected physical good mass is zero, and the total decoder outputs its fixed fallback. No negative beta formula is used. The algorithm need not solve a hidden-rank problem to detect this case: its zero contraction already implements fallback. The s=0 early branch remains directly detectable from enumerated paths.

The source-weight guarantee is on the physically selected error space, never arbitrary redundant M-dimensional weights. Random-code mean statements require the physical weights to be independent of the code. The bound in Section8 assumes0<=c/k<=1 (otherwise use the trivial probability bound1), and a maximal eigenvalue at least1−c/k; it is not a finite-data certificate for that promise.

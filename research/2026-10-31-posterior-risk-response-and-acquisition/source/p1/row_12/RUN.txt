This regenerates the seeded synthetic source for verification and checks every

To regenerate the large execution in a NEW local output directory:

  python p1_risk_compiler_20261031/run_workload.py --depth 8 --rounds 1000 --seed 20261031 --outdir producer-workspace/p1_risk_compiler_reproduction

The outdir option avoids overwriting the original complete_history.jsonl and
its measured workload report. Timing fields will vary. The recorded execution
has 65,536 initial source calls, 2,000 subsequent source calls, 19 target edits,
and 1,000 fixed two-call batches. All these costs, not only updates, are paid.

To reconstruct the final original learner state and query the globally optimal
ADAPTIVE two-observation policy with a numerical regret bound:

  python p1_risk_compiler_20261031/run_adaptive_query.py

It uses the preserved input history, pays reconstruction and an O(nh) query,
acquires no new source data, and writes adaptive_query.json. This is not an
O(h) maintenance algorithm for the best adaptive first action. The ordinary
exact reversible hypothetical-update comparator is in adaptive_planner.py;
the independent adaptive audit tests it against exhaustive policies.

FILES AND SEMANTICS

risk_compiler.py
  Fraction and interval fixed-batch compiler. RiskTree stores full local
  posterior parameters, gate tables, moments, derivatives, gain budget tables
  and attaining allocations. observe() and edit_gate() update ancestors.
  edit_gate() changes a target table, not a primitive observation likelihood.

adaptive_planner.py
  Exact/interval adaptive_two_step(), plus an exact ordinary reversible
  hypothetical-update comparator. The returned Policy fixes the first source
  and the second source for each first outcome. Do not silently substitute
  a different numerical branch policy while claiming this policy's bound.

exact_checks.json
  Main independent count-outcome and prior-variance checks, myopic trap,
  fixed-horizon failure, and the fixed-versus-adaptive AND separator.

complete_history.jsonl
  Complete learner inputs and predictable decisions; every real maintenance
  path and work count; initial/final enclosures; plus clearly marked harness-
  only truth for source replication. Bayesian claims condition on the learner
  record, not the auditor's additional knowledge of that truth.

workload.json / replay.json / adaptive_query.json
  Fully paid large execution, complete replay, and later adaptive query.
  L is a lower bound achieved by the returned plan; U bounds the exact
  optimum. U-L (rounded up) bounds optimization regret. U need not be the
  gain of the returned plan. Mean midpoint error is reported separately.

review_resolution.json
  Targeted checks of the three fixed implementation/reporting findings.

manifest.json
  SHA-256 of main and complementary scientific files; cross-reference to the
  untouched previous P1 record. The manifest excludes itself and reproducible
  __pycache__ files. It is a preservation aid, not an external transfer.

I’ve put the quantum-memory construction through a stricter resource check. The proof’s current sufficient temperature scale is extraordinarily small, and I cannot yet show how to load a qubit into the required thermal state efficiently. The very small bound is a conservative proof guarantee, not a demonstrated physical lower limit. So my assessment is: potentially meaningful mathematics about which interactions can retain a thermal memory, but not yet a credible practical memory breakthrough. The next attack is the actual write/loading operation and whether the resource bounds can be improved.

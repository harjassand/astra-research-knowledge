CODE TARGET: WHICH ORDINARY SHORTCUTS FAIL, AND WHICH SURVIVE

Target: C=ker H, H=[I_64 | P], on 80 bits, with P from
research_work/passive/code_target/code_target_exact.json (seed 2026110202).
Thus C={(Py,y):y in F_2^16}, |C|=2^16, and uniform mass is 2^-64.
The source file gives all 80 nonzero, distinct columns of H. All claims below
concern this explicit input, not an unknown code or a missing target sampler.

1. NO BIT COMPLEMENT MAKES THE TARGET MONOTONE

Every nonempty affine subspace that is a down-set in the coordinate order is a
coordinate face. Indeed it contains zero, hence is linear; whenever it contains
x it contains each unit vector e_i below x, so it is spanned by coordinate unit
vectors. For an up-set, complement all bits and use the down-set argument.
Translation by a fixed bit mask preserves the underlying linear direction
space. Therefore an affine subspace can be made an up-set or down-set by any
bit complementation only if its direction is a coordinate subspace.

The graph code {(Py,y)} is a coordinate subspace iff P=0: its projection onto
the final 16 coordinates is full, so a coordinate subspace of dimension 16
would have precisely those 16 free coordinates and all first 64 fixed at zero.
Here P is nonzero. Thus no bit complement or coordinate permutation makes C
monotone. A concrete down-set failure is e_i<= (P e_j,e_j) for any nonzero
P_ij, while e_i is not in C. Since C contains zero but is proper, it is also
not an up-set in the original coordinates.

Consequently a coordinatewise biased-bit sandwich does not order the event
of hitting C. This is a failure of that particular comparison, not a claim
that every coupling or every exact method fails. An invertible linear change
of variables can express C as zero syndromes, but it changes single-bit moves
into column-mask moves and does not preserve the independent monotone-bit setup.

2. EVEN THE REFERENCE DOES NOT LUMP BY DISTANCE TO THE CODE

Exact enumeration of the 65536 codewords gives minimum nonzero weight 22 and
a unique minimum word
  c = 0xc84425e22c2984a0000.
This was independently checked from P by Gray-code enumeration. Set
  x = 0x22c2984a0000,
  y = 0x22c298480001,
with leading zeros to make 80-bit strings. Both have weight 11. The support
of x is an 11-element subset of the support of c. The vector y replaces one
of these coordinates by bit 0, which is outside the support of c.

Both states have distance 11 from C. For x the nearest codewords are exactly
{0,c}; for y the unique nearest codeword is 0. To see this, every other nonzero
codeword has weight at least 23 and hence is at distance at least 12 from a
weight-11 vector. Also d(x,c)=11 and d(y,c)=13.

Every neighbor at distance 10 must move toward a nearest codeword. For x,
there are 11 such flips toward zero and 11 distinct flips toward c, for 22
in total. For y there are exactly 11. Under uniform single-bit flip rate c0,
the rates from distance 11 to distance 10 are therefore 22c0 and 11c0.
Distance to the code is not an exact Markov lump, even for the reference.

3. SYNDROME LUMPING WORKS FOR THE REFERENCE, NOT GENERIC NATIVE RATES

Write h_i=H e_i. With state-independent rates c_i, the syndrome s=Hx jumps
to s+h_i at rate c_i, combining rates if columns coincide. Thus the uniform
reference has an exact syndrome quotient. Its binary-character eigenvalues
are 2c0 |H^T a|. The ordinary character/Green-function and MacWilliams route
already computes its mean, approximately 2.3358101076456726e17 for c0=1.
This exact reference solution is credited to ordinary machinery.

For state-dependent single-bit rates q_i(x), strong syndrome lumpability
requires, for each s and nonzero syndrome increment h,
  sum_{i:h_i=h} q_i(x)
to be identical for every x with Hx=s. Here all columns are distinct, so
each q_i must itself be constant on every code coset. A known small kinetic
dependence range does not imply this translation invariance.

An explicit nearest-neighbor example uses 1-based indices:
  q_64(x)=c0[1+eta*(-1)^(x_65)],   q_i(x)=c0 for i!=64.
Let g=(P e_1,e_1) in C, z=e_1 and z'=z+g. Both have nonzero syndrome e_1,
and both are outside C. Their rates to syndrome e_1+e_64 differ by 2c0 eta.
This disproves lumpability inside the killed domain, not merely on the target.
The example even preserves uniform measure and is reversible, because q_64
does not depend on its own bit. It is used only to disprove the quotient;
ordinary Dirichlet comparison solves its relative-mean question below.

The recorded dual minimum weight is 3. Thus C projects surjectively onto every
set of at most two coordinates: otherwise a nonzero dual word supported there
would have weight <=2. Consequently any nonconstant rate depending on at most
two bits fails coset constancy. No specially hidden global gate is needed to
destroy the syndrome quotient.

4. THE STRONG ORDINARY COMPARISON MUST REMAIN IN THE ACCOUNT

If actual Q and reference Q0 are BOTH reversible for the SAME pi0, and
  (1-eta)q0<=q<=(1+eta)q0,
then their symmetric Dirichlet forms obey the same ordering. Restricting to
the killed subspace and inverting gives, for EVERY target, including this code,
  1/(1+eta) <= M/M0 <= 1/(1-eta).
No monotonicity, quotient, code-distance reduction or new transfer theorem is
needed for that statement.

Even unknown actual pi is not by itself enough to defeat elementary comparison
when actual Q is reversible. Detailed balance gives along each cube edge
  [(1-eta)/(1+eta)] <= (pi(y)/pi0(y))/(pi(x)/pi0(x))
                         <= [(1+eta)/(1-eta)].
A path of at most n bit flips, followed by normalization, yields
  exp(-u_rev)<=pi/pi0<=exp(u_rev),
  u_rev=n log[(1+eta)/(1-eta)].
Ordinary symmetric conductance comparison and the changed initial-weight
formula then give an arbitrary-target relative mean bound. This needs no
unknown target sampler and should not be credited as new capability here.

For common invariant measure but nonreversible Q, ordinary sector/capacity
comparison is also an available stronger comparator. The root's unknown-law
and skew-transfer theorem is relevant to the larger acquired class where the
native stationary law is not supplied and nonreversible currents are allowed.
Basic same-measure Dirichlet comparison does not directly cover that class:
its energy weights and conditioned initial law are unknown. The root mechanism
earns those weights and the circulation control from native rate information.
This does not exclude equally informed standard perturbation constructions;
it is not a historical-priority or new-feasibility claim.

The usual agreement-until-first-mismatch coupling gives only a path-error bound
of order eta*n*c0*T. It is not useful by itself at T comparable to this rare
mean. Ordered biased-bit coupling additionally lacks a monotone target event.
These are limitations of those specific constructions, not impossibility
results for all couplings or numerical methods.

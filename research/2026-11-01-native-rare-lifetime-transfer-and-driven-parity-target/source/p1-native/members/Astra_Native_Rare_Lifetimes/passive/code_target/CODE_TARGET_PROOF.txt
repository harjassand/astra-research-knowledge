1. Fixed target and operations

Work over F2. Set n=80,m=64,k=n-m=16. The target is the linear code

    C=ker H,   H=[I_64 | P],   P in F2^(64 by 16).

The 16 columns of P are generated once by Python random.Random(2026110202),
using getrandbits(64) for each. They are then stored explicitly as unsigned
64-bit integers in code_target_exact.json. The same file stores all 80 columns
of H, so subsequent use does not depend on regenerating a random matrix.
The identity block proves rank H=64 without a probabilistic rank assertion.

Every codeword has the unique form

    x=(Pz,z),   z in F2^16.

Therefore |C|=65536. Under the uniform reference law on F2^80,

    p=pi0(C)=2^(-64),    b=1-p.

The target mass is an exact structural consequence, not a fitted empirical
frequency. An exact conditional sample is obtained from 16 independent uniform
bits z followed by at most16 column XORs to form Pz. Membership is Hx=0.
After a known single-bit update, maintain Hx using one 64-bit XOR.

The saved P columns have weights

    27,34,29,31,32,30,36,40,28,31,37,28,33,32,31,24.

All 80 H columns are nonzero and distinct. Exhaustive enumeration of the 65536
codewords gives minimum nonzero weight22, attained by exactly one word,

    0xc84425e22c2984a0000.

These are exact integer results from this fixed instance. They are useful for
the separate monotonicity and scalar-lumping obstruction, not an assumption
that every randomly generated code has the same properties.

2. Reference chain and exact quotient

The reference generator flips each coordinate at rate 1:

    Q0 f(x)=sum_(i=0)^(79) [f(x+e_i)-f(x)].

It is reversible with uniform stationary law. Its full-state gap is2, by the
ordinary binary Fourier basis. The total exit rate is80. Let h_i be column i
of H. The syndrome process Y_t=H X_t is exactly Markov, with

    Qsyn f(y)=sum_i [f(y+h_i)-f(y)].

This is a translation-invariant walk on F2^64. Its stationary law is uniform,
and it is irreducible because the first64 h_i form a basis. The event X_t in C
is precisely Y_t=0. Every syndrome fiber has2^16 elements, so the pushforward
of pi0 conditioned outside C is the uniform law on nonzero syndromes. Thus
the reference mean sought here is exactly the stationary-outside hitting mean
of the single state 0 in this quotient. No approximation or unjustified scalar
distance lumping enters this reduction.

For u in F2^64 the character chi_u(y)=(-1)^(u dot y) is an eigenfunction:

    -Qsyn chi_u = 2 wt(H^T u) chi_u.

The map u -> H^T u is a bijection onto C-perp. If B_j counts dual codewords
of weight j, the positive eigenvalue2j has multiplicity B_j. In this fixed
instance the minimum positive dual weight is3, so the quotient gap is6.
The full 80-bit reference gap remains2; the quotient improvement is target-
specific and is only used for the optional tighter reference-only interval.

3. Exact stationary-outside mean from the return Green function

Write N=2^64 and let P_t be the quotient transition kernel. Define

    G(x,y)=integral_0^infinity [P_t(x,y)-1/N] dt.

This is finite by irreducibility. It satisfies

    (-Qsyn)G=I-Pi,

where Pi has every row equal to the uniform law. The function

    h(x)=N[G(0,0)-G(x,0)]

is zero at 0, and for x!=0 it satisfies -Qsyn h(x)=1. Uniqueness of the finite
killed Poisson problem therefore gives h(x)=E_x tau_0.

Each column of G has uniform average zero. Hence

    E_uniform tau_0 = N G(0,0).

The normalized characters have constant squared magnitude1, so Fourier
diagonalization gives

    G(0,0)=(1/N) sum_(j>=1) B_j/(2j).

Conditioning out the atom at 0 yields the exact identity

    M0 = E_(uniform outside0) tau_0
       = [sum_(j>=1) B_j/(2j)] / (1-2^(-64)).

This establishes the requested formula, including its normalization. Confusing
the stationary mean with the stationary-outside mean would omit the factor b.

4. MacWilliams/Krawtchouk transformation, proved directly

Let A_w be the number of codewords c in C with Hamming weight w. It is cheap
enough here to enumerate C, because its dimension is16, even though its dual
has dimension 64. For every v in F2^n, character cancellation gives

    1_(v in C-perp)=(1/|C|) sum_(c in C) (-1)^(v dot c).

If v is orthogonal to C, every term is1. Otherwise choose c0 in C with
v dot c0=1; pairing c with c+c0 cancels the sum. Multiply by z^wt(v), sum over
v, and factor the n binary coordinate sums. The result is

    sum_j B_j z^j
      =(1/|C|) sum_(c in C) (1-z)^wt(c)(1+z)^(n-wt(c))
      =2^(-16) sum_w A_w (1-z)^w(1+z)^(80-w).

Taking coefficients proves

    B_j=2^(-16) sum_w A_w K_j(w),
    K_j(w)=sum_r (-1)^r binom(w,r)binom(80-w,j-r).

This is the binary MacWilliams identity. The implementation uses the exact
integer recurrence

    K_0=1,  K_1=n-2w,
    (j+1)K_(j+1)=(n-2w)K_j-(n-j+1)K_(j-1).

It follows by differentiating (1-z)^w(1+z)^(n-w) and equating coefficients.
Every recurrence division and final division by 65536 is checked exact. The
computed B_j are nonnegative integers, B_0=1, and sum_j B_j=2^64. Those checks
are preserved in the output. No floating polynomial cancellation is used.

Kernel enumeration uses Gray-code order: one z bit changes at each step, so
the corresponding64-bit parity word changes by one P-column XOR. It performs
65536 codeword weight evaluations and 65535 parity XOR updates. The transform
needs O(n^2) integer arithmetic operations on the 81 weight classes. The final
sum is computed as a Python Fraction and preserved exactly in JSON. This
enumeration cost is charged; it would not be small for an arbitrary large-
dimension kernel. This instance deliberately permits an exact conventional
baseline against which the short receiver can be checked.

5. Exact screened quantities from the same ordinary spectrum

For s>0 let

    G_s(x,0)=integral_0^infinity exp(-st) P_t(x,0) dt,
    u_s(x)=E_x exp(-s tau_0).

The strong Markov property at tau_0 gives G_s(x,0)=u_s(x)G_s(0,0). The
resolvent equation at 0 therefore gives

    r_s=s+sum_i [1-u_s(h_i)] =1/G_s(0,0).

Fourier diagonalization gives

    G_s(0,0)=p[1/s + sum_(j>=1) B_j/(s+2j)].

Consequently

    R_s=1/(p r_s)-1/s = sum_(j>=1) B_j/(s+2j).

These exact rational expressions provide an independent target for every
receiver quantity. They are already conventional exact reference computation,
not an inference from the Monte Carlo observations.

For the fixed code and s=1/10:

    M0  = 2.3358101076456726e17,
    r_s = 79.07499767230635,
    mu  = (r_s-s)/80 = .9871874709038294.

The exact fractions, rather than these rounded displays, are in the result.

6. Actual rational short-excursion receiver

code_receiver.cpp explicitly prepares each initial target state as(Pz,z).
It inspects all 80 coordinates to recompute and check its zero syndrome. It
then chooses one of the 80 initial flips uniformly, obtaining syndrome h_i.
This pays target preparation and the initial boundary move; total boundary
rate 80 appears in the estimator.

For the following path, each coordinate flip gets10 integer slots and an
independent killing event gets1 slot. Draw uniformly from 801 categories:

    categories0,...,799: flip coordinate floor(category/10),
    category800: kill and count success.

After a flip, update the syndrome by XOR and stop on syndrome0, counting a
return. This exactly simulates the embedded jump chain of the reference walk
with an independent rate 1/10 kill. No exponential waiting times are needed,
because only which event happens first is used. Each trial's Bernoulli success
has expectation

    mu=(1/80)sum_i [1-u_s(h_i)].

The initial codeword sampler is more work than this homogeneous reference
strictly needs: translations by C leave its future syndrome law unchanged,
so canonical0 would suffice after proving that invariance. The executed run
nevertheless pays for every conditional preparation explicitly.

All random choices use integer rejection from 64-bit words. For bound d, reject
words below 2^64 mod d, then take the remainder modulo d. Accepted categories
are uniform. The seeded mt19937_64 execution is a reproducible diagnostic;
the probabilistic coverage statement assumes independent ideal random bits.
There are no floating acceptance thresholds or time discretizations.

With K successes among T independent trials, set

    muhat=K/T,  rhat=s+80 muhat,  Rhat=1/(p rhat)-1/s.

A fixed rational halfwidth h=1/120 has Hoeffding failure at most

    2 exp(-2 T h^2).

Clip the interval for mu to[0,1], map it to[rlo,rhi], and use monotonicity:

    Rlo=1/(p rhi)-1/s,  Rhi=1/(p rlo)-1/s.

The screened-time theorem then gives the reference-mean interval

    [Rlo/(b(1+s/g)), Rhi(1+s/g)/b].

Use g=2 for the full reference; alternatively g=6 for this exact quotient.
The full reference mean and R_s are known exactly here, so the execution can
check that the resulting intervals contain them. This validates receiver
conventions; it does not establish the theorem through simulation alone.

8. Small independent exact check

The n=8,m=5 instance uses seed2026110203 and P columns[7,15,6]. Enumerating
its 8 kernel words and transforming their weights gives the dual enumerator.
Directly enumerating all 32 dual characters gives exactly the same integers.

A rational Gaussian elimination solves the 31-state killed quotient system.
Its stationary-outside mean is exactly

    2092/465,

equal as a Fraction to the weight-enumerator formula. A separate full 256-state
coordinate-flip matrix, killed on the 8 target codewords, gives the same value
to floating precision, with maximum killed-equation residual below 5e-14.
This checks the quotient normalization and return identity, not merely the
same formula evaluated twice. All values are saved in code_target_exact.json.

FINITE FIXED RECEIVER UNDER POLE UNCERTAINTY, WITH DIGITAL REALIZATION
Phase8 physical-mechanisms collaborator. 1 November2026.

RESULT
======
The root finite direct-port longitudinal readout is made robust to unknown
constant readout-rate gain and frequency offset by a fixed derivative-null
homodyne filter. No actual pole is fitted and no exact filter at the unknown
pole is used. The result has two distinct admitted contributions:

 (i) an actual-parameter reference CP parity-bit error e_ref;
 (ii) a completely bounded dilation remainder on a photon-number INPUT sector.

The latter is an amplitude, not an assumed independent probability. Root's
whole-history input-sector replacement lemma is required to use it. This note
never inserts physical number projection or assumes every normalized rare
history has low energy.

The final finite implementation uses512 homodyne integration bins, actual
40-bit integer weights, a16-bit ADC of normalized range[-16,16], and an exact
integer accumulator of at least72 signed bits. All switching/force ramps remain
in the physical model. Tread=4.472 includes both .1 ramps. Classical finalization,
protected refresh and any extra settling guard are charged separately.

1. PHYSICAL MODEL, UNKNOWN PARAMETERS, AND FIXED FILTER
=====================================================

The storage mode has intrinsic loss k0=1e-4 and opened direct readout loss
kr(t)=kr w(t), with kr=4 and the root's .1-duration sin^2 rise/fall w.
The ancilla-Z force is u(t)=F w(t), F=3/(1+1e-6), so a constant force-gain error
of magnitude at most1e-6 still respects the physical force cap3.
All fresh ports have the same white thermal occupation nb=.1; eta=.5.
This is a direct-port effective model, not elimination of the old finite buffer.

Let W(t)=integral_0^t w(s)ds. The nominal initial-mode output column is

 H0(t)=sqrt(kr w(t)) exp[-k0 t/2-kr W(t)/2].                    (1)

An actual constant fractional readout gain epsilon and frequency offset Delta
give

 H_actual(t)=sqrt(1+epsilon) H0(t)
              exp[-epsilon kr W(t)/2-i Delta t].             (2)

The same FIXED real normalized filter f(t) is used for every actual parameter.
For derivative order p it is orthogonal to

 H0(t) [t/T]^q [W(t)/T]^r, q+r<=p.                            (3)

For p=1 there are3 columns; for p=2 there are6. Ordinary least-squares
projection of the nominal signal onto their orthogonal complement maximizes
nominal signal under these declared null constraints. No global optimum is
claimed. Both the t and W columns are needed because finite ramps make W an
affine function of t only in the interior of the observation window.

2. AN ANALYTIC UNIFORM RESIDUAL BOUND
===================================

The selected mode is b_f=c a_old+b_fresh+z mu, with

 c=integral f H_actual dt.

Let epsilon_max and Delta_max be the declared parameter bounds, n=p+1,
A0=sqrt[(epsilon_max kr/2)^2+Delta_max^2], and r=.1.
W(t)<=t and W(t)>=t-r. Taylor's remainder, the null conditions and Cauchy-Schwarz
give, whenever kr+k0>2A0,

 |c| <= sqrt(1+epsilon_max)/n!
     * sqrt{ kr exp(kr r) A0^(2n) (2n)! /
             [kr+k0-2A0]^(2n+1) }.                           (4)

The upper integration limit was enlarged to infinity. This is conservative but
uniform over the full parameter rectangle; a grid of sampled parameters is
only a diagnostic. Numerical lower-order residuals of an implemented filter
must be added, not silently called zero.

3. FULL INSTRUMENT COMPARISON ON AN INPUT PHOTON SECTOR
======================================================

The actual selected output annihilator is c a_old+sqrt(1-|c|^2)b, plus z mu,
where b is a fresh thermal mode. All other passive output modes are retained
or traced exactly as specified by the actual receiver.

Define a REFERENCE passive scattering transformation by rotating a_old and b
at the input so the selected output has zero old-mode coefficient. The required
beam-splitter angle is theta=asin|c|. This reference uses the same actual
controlled displacement z mu and all actual-parameter radiation displacements.
It is used in the proof, not implemented as calibration or reset.

For G=i(a_old^dag b-a_old b^dag), fresh thermal input and arbitrary old
apparatus-data-reference correlations,

 <G^2>=(2nb+1)<n_old>+nb.

Therefore, on the input sector n_old<=N,

 ||(U_actual-U_ref) P_N|| <= asin|c| sqrt[(2nb+1)N+nb].        (5)

Here the norm is the Stinespring vector/operator norm with a fixed thermal
purification; it also bounds half the restricted-input diamond distance.
The bound follows from |exp(-i theta G)-I|<=|theta G| by spectral calculus.
There is no driven-photon term: the SAME controlled displacement is applied
after the passive transformations and cancels from the comparison.

This is a cap on the input of the comparison. It neither truncates the physical
Hamiltonian nor bounds the oscillator number continuously during the operation.
It is compatible with root's whole-history sector replacement if that lemma
has earned a small total excluded weight at every actual prefix.

4. COMPLEX POINTER AND EXACT REFERENCE CP ERROR
==============================================

An actual pole can make mu complex even though f and the nominal pointer are
real. Let v=2nb+1 and wdet=1+2eta nb. For homodyne sign r, the diagonal wrong
probability and offdiagonal coefficient of the reference instrument are

 q=Phi[-2 sqrt(eta) Re(mu)/sqrt(wdet)],
 gamma_r=exp[-2v|mu|^2]
          Phi[i r 2 sqrt(eta) v Im(mu)/sqrt(wdet)].            (6)

The second Phi is its entire complex extension. One must not substitute
.5exp[-2v|mu|^2] when the pointer is misaligned. Gamma_-=gamma_+^*.
The2x2 Schur complement gives the exact reference decomposition with

 e_ref=q+|gamma_r|^2/q.                                      (7)

The good component is the rank-one ancilla-Z projection, with weight1-e_ref.
The bad map has effect e_ref I on every correlated old input. Thus actual
measurement+conditional-X preparation remains justified; no ideal bit is used.

Signal bounds used in the code are also uniform. Writing z0=k0/2+iDelta and
D_dot=1-[k0+kr(1+epsilon)w]/2 D-iDelta D, one obtains

 B(t)=(2F/[kr(1+epsilon)]) [1-r_actual(t)-z0 D(t)].

Consequently mu is a known positive multiple of integral f sqrt(w) minus c
and a bounded D term. During the first ramp |D|<=r; in the flat region
|D|<=max(r,2/[kr(1-epsilon_max)+k0]); the last ramp adds at most r.
Using |D|<=2/[kr(1-epsilon_max)+k0]+r throughout gives the conservative
uniform lower/upper Re(mu) and upper |Im(mu)| reported in the JSON.
The tiny constant force-gain uncertainty multiplies these bounds explicitly.

6. FINITE BIN FILTER, ACTUAL COEFFICIENTS, AND EXACT ARITHMETIC
===========================================================

Let B=512 and Delta_t=T/B. The physical detector integrates the homodyne record
in consecutive bins and reports each normalized bin quadrature. The filter is
PIECEWISE CONSTANT, defined in this finite bin-mode space from the start.
Each derivative column is the exact integral of(3) over that bin divided by
sqrt(Delta_t); the signal vector is constructed the same way. This avoids
assuming a continuously programmable exact analog weighting function.

The optimized512-vector is rounded to40-bit signed integer coefficients on
range[-2,2), step4/2^40. The ACTUAL integers are saved in
finite_bin_receiver_weights.json. Its normalized vector differs from the
unrounded vector by2.435e-11. A simple rounding bound is8.232e-11.

More strongly, certify_bin_receiver_moments.py checks the actual integer filter
with85-digit standard-library Decimal arithmetic. It uses16-point Gauss-Legendre
quadrature on smooth pieces split at the ramp boundaries. On complex disks of
radius.025 each normalized moment integrand has magnitude below10. The rule is
exact through degree31; the Taylor tail bounds the entire quadrature error by
4.947e-23. A1e-20 outward margin is retained in each reported moment. This is
an analytic quadrature error estimate plus high-precision evaluation, not a
machine-checked interval-arithmetic proof.

The actual zero-order residual is1.9039317046e-12. Including all actual lower
moments in the Taylor polynomial gives, at epsilon_max=.001,Delta_max=1e-6,

 |c|<=6.87368620181e-10,
 restricted-input dilation error at N320 <=1.34713728197e-8.   (8)

No ideal coefficient-precision oracle remains in these numbers. The protected
controller stores the displayed integers and computes their integer dot product.
With40-bit weights and16-bit signed samples, products require56 bits and summing
512 terms requires65 signed bits. A72-bit protected accumulator supplies margin.
Coefficient memory, sample latches, addressing, timing and arithmetic hardware
still belong to the actual classical fault domains and refresh construction.

7. ADC QUANTIZATION AS A CP SUBINSTRUMENT, NOT AN ERROR COIN
=========================================================

Use a16-bit ADC on normalized range[-16,16]. On the nonclipping event its step
is32/2^16 and each sample error has absolute value at most half that step.
For a unit2-norm512-vector the scalar-score error is at most

 d=(32/2^16) sqrt(512)/2 =.005524271729.

This is a deterministic bound for all sample records, including correlated
records. No independent quantization-noise model is used.

The actual decision agrees with the ideal homodyne sign on the two outer
regions Y_f>d and Y_f<-d. Extract these actual outer-region CP maps. Put the
entire uncertain middle strip into the bad map, regardless of which report the
finite electronics emits there. A Schur complement now gives

 e_ADC = Phi[(d-2sqrt(eta)Re(mu))/sqrt(wdet)]
       + |gamma_outer|^2 /
         Phi[(-d-2sqrt(eta)Re(mu))/sqrt(wdet)].                (9)

A valid bound is
 |gamma_outer| <= .5 exp[-2v mlo^2+2eta v^2 Immax^2/wdet],
with the proved signal bounds mlo and Immax. This is a CP admission; it does
not incur an unnecessary square-root penalty for a tiny boundary strip.
No new perfect flag or erasure outcome is assumed.

At Tread=4.472 with the actual512-bin40-bit filter and16-bit ADC,

 e_ADC<=9.7013521e-7.

The conservative coefficient-rounding version of(5) is1.5047329e-8; the direct
actual-moment bound(8) is sharper. T4.466 can instead use a24-bit ADC and an
80-bit protected accumulator, but the selected16-bit construction avoids
requiring that extra converter resolution. ADC analog gain, offset and noise
are separate hardware parameters: positive common gain does not change sign,
but offset/nonwhite noise must be calibrated, bounded or added to the model.
An offset bounded per bin can simply enlarge d in(9); it is not silently zeroed.

8. FINITE DYNAMIC RANGE AND ALL READOUT HISTORIES
===============================================

A photon-number cap does NOT bound a quadrature's support. Its tails must be
proved. For any input state supported on n<=N,

 <exp[s(c a+c^*a^dag)]>
   <= exp[s^2|c|^2/2+2|s c|sqrt(N)].                         (10)

This follows from BCH and ||exp(s a)P_N||<=exp(|s|sqrt(N)); no classical
coherent-state decomposition of the old input is assumed. Convolving with
fresh thermal/detector Gaussian noise gives a Gaussian Chernoff bound with a
finite shift allowance. For each normalized time bin, use

 |c_bin|<=sqrt(kr_max Delta_t),
 |h_bin|<=2F_max sqrt(kr_max Delta_t)/kr_min,
 shift=2sqrt(eta)[|c_bin|sqrt(N)+|h_bin|].

The probability that its value exceeds ADC rangeR in either direction is at
most2exp[-(R-shift)_+^2/(2wdet)]. At R16,T4.472,B512,N320 this is at most
9.289e-24 per bin. A union bound for one million full readouts is below
4.756e-15. This bound needs no independence across bins or operations: root's
input-sector replacement handles excluded inputs, and(10) is uniform on each
accepted input sector. Clipping is a real rare event, not an assumed fault count.

The intended instrument delivers the coarse reported bit. Raw homodyne/ADC
samples and accumulators are internal receiver state with a declared no-future-
use contract and protected overwrite/refresh. If a later observer/controller
receives and uses the refined record, the coarse-bit projective CP decomposition
is NOT automatically the complete instrument. Such an enlarged consumer needs
its own proof. The same issue applies to the inherited homodyne construction.

Finite bin integration timing, detector bandwidth/linearity, noise covariance,
DC offset, port control and protected finalization are actual physical conditions.
The files implement the arithmetic/filter and exhibit a finite specification;
they do not certify an existing amplifier/ADC against all of those conditions.

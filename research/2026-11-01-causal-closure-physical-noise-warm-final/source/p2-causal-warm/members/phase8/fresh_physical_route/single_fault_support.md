# Single-fault support for a two-data diagonal mediator parity operation

This lemma applies equally to a harmonic force bus and to the six-interaction finite dirty-qubit comparator. It is independent of a trajectory's occupation, temperature, memory, and fault strength. It establishes support/correctability modulo an actual code gauge, not a rare-event rate.

## Hypotheses

Let data qubits be 1,2; put every ancillary, mediator, bath, and reference degree of freedom in R. Define P=Z1 Z2 and the data diagonal algebra A=alg(Z1,Z2). Suppose that between the distinguished fault and any final readout, each evolution operator and each readout Kraus operator is in A tensor B(R). This permits arbitrary conditional mediator dynamics; it only requires that the nominal data coupling conserve each data Z.

The distinguished fault is one of:

- An arbitrary operation on R alone.
- An arbitrary operation on one data site j and R.
- An arbitrary control excursion that remains diagonal in both data Z operators.

The noise map may be decomposed into Kraus operators; each case is proved operator by operator. One can also use a Stinespring dilation. None of the coefficients below must be scalar or commute with each other.

## Algebraic reduction

Every D in A tensor B(R) can be expressed as

\[
 D=I\otimes d_0+Z_1\otimes d_1+Z_2\otimes d_2+P\otimes d_{12}.
\]

For j=1, use Z2=Z1 P to rewrite

\[
 D=A(P)+Z_1B(P),
 \quad
 A(P)=d_0+P d_{12},\quad B(P)=d_1+P d_2.
\]

The same identity holds with j=2. Therefore A is generated by a one-site Z and P.

Let the arbitrary local-data fault be

\[
 F_j=\sum_{\alpha=0,x,y,z}\sigma_j^\alpha\otimes f_\alpha.
\]

Surround it by arbitrary diagonal conditional evolutions D_left and D_right. Expanding the data factors, and commuting P past a one-site Pauli when necessary, gives

\[
 D_{\rm left}F_jD_{\rm right}
 \in \mathcal B(\mathbb C_j^2)\,\operatorname{alg}(P)
       \otimes\mathcal B(R). \tag{S1}
\]

No time-discretization or small-fault approximation enters. A continuous local fault Hamiltonian at site j can also be handled by its full time-ordered propagator: the generated algebra still contains arbitrary operators at j but only diagonal Z dependence at the other data site. Ancilla/mediator-only faults give

\[
 D_{\rm left}F_RD_{\rm right}
 \in\operatorname{span}\{I,Z_j\}\,\operatorname{alg}(P)
       \otimes\mathcal B(R). \tag{S2}
\]

Taking a final partial matrix element on a readout ancilla, selecting an observed outcome, or tracing a bath preserves these algebraic inclusions. An arbitrary initial state entangled with R does not affect the operator proof.

## When this proves correctability

Suppose the physical code is a subsystem code, its correctable error set contains all one-site errors E_j, and P belongs to its gauge group. On the code subsystem, gauge operators act trivially on the logical subsystem. Equation (S1) is then in the linear span of correctable one-site errors followed by gauge operators. The operator quantum-error-correction condition is preserved under multiplication on the code side by gauge operators. Hence the logical subsystem remains correctable, even if the error is coherently correlated with R.

This is not a license to quotient by any parity that happens to be measured. If P is a nontrivial logical parity used to perform a consumed CNOT, arbitrary functions of P can change the intended measurement instrument. That case needs the outer encoded gadget's correction and instrument-correctness proof.

## Important exclusions

1. An arbitrary fault simultaneously acting non-diagonally on **both** data sites need not belong to (S1). A shared controller fault must be charged at its actual support. A small Hamiltonian sum of two local terms can be expanded and charged locally; a rare large common event cannot be declared two independent local events.
2. If a pulse drives X or Y on the other data site during the interval, the conserved-diagonal-algebra hypothesis can fail. Frame rotations at certified boundaries can be handled by changing Pauli labels; an overlapping noncommuting drive needs a new proof.
3. Leakage from a physical qubit is not included unless its propagation is separately shown to be correctable or replaced by an admitted leakage-reduction gadget.
4. The statement says nothing about the probability of the distinguished fault. Unbounded photon-loss/dephasing/control generators can make a formally correctable error occur at order-one strength or arbitrarily often. Joint norm or CP-instrument bounds are a separate obligation.
5. A correctable data error surviving the previous cycle remains present. Combining it with the error in (S1) can require two-site correction. Extended rectangles, including the shared recovery and all idles, must budget the old and fresh errors together.

## Application to the force-loop proposal

For

\[
 H(t)=(Z_1+Z_2)(f_xa^\dagger+f_x^*a)
      +Z_A(f_ya^\dagger+f_y^*a),
\]

the conserved-diagonal-algebra hypothesis holds. Arbitrary faults on the oscillator or ancilla preserve data diagonality; a local data fault has the form (S1). Thus the one-representative-modulo-gauge support assertion is sound under the stated physical-code condition. Exact incoming/outgoing damped closure and the proposed dephasing effect bound are needed separately to obtain a useful rate. They cannot be inferred from this support lemma.

## Application to the finite dirty mediator

In the chronological six-gate sequence

\[
 \mathrm{CX}_{1\to M},\ \mathrm{CX}_{2\to M},\ \mathrm{CZ}_{AM},\
 \mathrm{CX}_{2\to M},\ \mathrm{CX}_{1\to M},\ \mathrm{CZ}_{AM},
\]

every gate conserves Z1,Z2. The same support lemma therefore applies, with the additional advantage that bounded physical generators give state-uniform norm bounds directly. The sequence equals CZ_A1 CZ_A2 tensor I_M, as checked in `verify_dirty_bus.py`.

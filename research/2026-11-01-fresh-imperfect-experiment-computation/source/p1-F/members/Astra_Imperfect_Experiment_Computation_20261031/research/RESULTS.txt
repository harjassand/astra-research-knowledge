ASTRA — WHAT IMPERFECT EXPERIMENTS CAN ACQUIRE FOR RELIABLE LATER COMPUTATION
Scientific conclusion and executed results, 31 October 2026

MAIN CONCLUSION

The strongest completed construction is a continuing, task-triggered solver.
It learns a reusable subspace of actual operator actions, constructs a small
Galerkin solver, and returns each answer with an explicit residual bound that
includes the retained experimental error. When the learned object is inadequate,
the failed solve produces a quantitatively separated new direction to retain.

At a fixed accuracy/coercivity scale, a numerical-width hypothesis bounds the
TOTAL number of such learning events over an arbitrarily long adaptive task
stream. Exact algebra closure, a useful basis, exact solution snapshots, and a
global worst-task search are not supplied. Generic full-rank perturbations are
allowed. The source remains available; novel task directions can still require
an action measurement. This continuing-access contract is essential.

This is a constructive robust computation result assembled from established
numerical machinery. It is not yet a civilisation-changing advance. The
strongest ordinary comparator tested ties it on source-action count, and
historical novelty/practical superiority have not been established.

THE COMPLETED MATHEMATICAL SERVICE

Unknown fixed Hermitian primitives B_j are accessed through imperfect full-vector
actions with norm error at most d||v|| at the actually requested tolerance d.
The later tasks solve

    [alpha I + sum theta_j B_j] x=b,
    sum |theta_j|<=1,
    alpha I+sum theta_j B_j >= mu I,

to relative Euclidean solution error epsilon. The source bound mu>0 is warranted;
it is not inferred from the reduced model. For a positive quadratic combination
of the original Hermitian sources, B_j=A_j^2 can be constructed using two
imperfect source actions, and a chosen alpha>0 supplies mu=alpha.

Put tau=mu epsilon/(1+epsilon) and sigma=tau/16. The cache is calibrated so its
whole action-matrix error is at most sigma. The actual acceptance test is

    ||b-alpha x-Yz|| + sigma||x|| <= tau||x||,
    x=Vz.

Coercivity then proves the requested relative error. A rejection supplies a raw
action image at distance greater than g=tau-2sigma from the retained space.
It is never normalized merely because a machine reports it nonzero.

If the actual encountered action images all lie within eta of SOME unknown
r-dimensional subspace, with eta+sigma<=g/2, the total number R of additions is

    R <= min(n, r max{4, 2+4 log_2[(L+sigma)/g]}).

The learner receives neither the subspace nor r. A stronger sufficient condition
is a common r-dimensional approximation to all primitive ranges in operator norm.
The safe input-preparation variant has g=3tau/4 and explicitly budgets omitted
small input components. See PROOF.txt for ordinary proofs and exact quantifiers.

The lifetime source count is at most k(T+4R) for T tasks under the stated refresh
schedule. Retained full-vector storage is O(knR), and dense execution includes
O((T+R)[kn(R+1)+k(R+1)^2+(R+1)^3]) arithmetic. Under the declared per-action price
d^(-p), precision work is

    O_p(k sigma^(-p)[(R+1)^(1+p/2)+T(R+1)^(p/2)]).

For p=2 the important terms are R^2+TR, not merely R+T. The whole-vector noise
model, input/output work, confidence costs and future source access are explicit.
No physical interpretation of d^(-2) is asserted without an instrument model.

A SHARPER REASON UNIVERSAL OFFLINE LEARNING CAN BE EXPENSIVE

The supporting lower bound uses A=I+a uu*, with 0<a<=1. These matrices have
condition number at most two and exact algebra dimension at most two. An
admissible, fixed, query-dependent bounded-error oracle can return the identity
transcript until a probe overlaps u strongly enough to rise above its tolerance.

A source-free artifact that must solve EVERY later b to relative error
epsilon<a/(a+2), with failure probability delta<1/2, necessarily satisfies

    2 E sum_t exp[-n sigma_t^2/(2a^2)] >= 1-2delta.

This gives an exponential fixed-tolerance query lower bound and, for declared
price sigma^(-p), an expected precision lower bound of order n^(p/2)/a^p.
Allowing a to be of order epsilon gives order n^(p/2)epsilon^(-p). The source is
fixed before the learner's random coins. Independent isotropic stochastic noise
and a single globally small linear perturbation are different models.

When a task b is already supplied and a is known, one actual action suffices:

    A^(-1)b=[(2+a)b-Ab]/(1+a).

This elementary class-specific comparison is supporting capital, not the main
new solver. It proves that downstream conditioning, algebraic simplicity, and
experimental observability are distinct resources. The lower bound does not
apply to the inherited all-positive-cone TRACE task, which has a different output.

Every method met the same requested relative error. The strongest tested
ordinary comparator is the Gaussian/SVD proposal with the SAME live residual
checks: it ties the proposed method at 92 calls and rank four. Its precision
proxy is higher under the tested calibration schedule, but no optimality of
that schedule or physical speed/energy advantage is established. This test is
not an exhaustive comparison with globally certified Nystrom preconditioners.

Late information: task index 55 excites a previously absent fourth dominant
direction. The cache changes from rank three to four and pays six actions on
that task, including the capacity refresh. This is useful task-driven learning,
not a prior declaration that no other direction exists.

Stricter accuracy: after tightening epsilon from 0.02 to 0.00025, twelve tasks
in the tail grow the retained rank from 4 to 16 and require 62 additional actions,
including the four-column initial precision refresh. The additional precision
proxy is 1.180237897728e14. Maximum true relative error is 2.9600011e-6. This
preserves the hidden-tail failure instead of calling the tail exactly absent.

NONCOMMUTING, ADAPTIVE AFFINE TASKS

A separate n=128,k=2 experiment uses independent generic dense PSD tails on the
whole ambient space. The primitive commutator norm is 1.49533211. Forty simplex
mixtures choose coefficients from previous computed answers. The learner receives
no useful basis. It uses 104 primitive actions (52 per primitive), retains rank
four, and returns maximum relative error 0.00916023 under the 0.02 target.
All individual and mixture action-error matrix checks and enrichment-margin
checks passed. This tests the actual changing noncommuting-family implementation.

AN ACTUAL PLANNING CONSUMER

For unknown PSD B_j, optimize the continuous simplex design

    F(theta)=c*theta+b*[alpha I+sum theta_j B_j]^(-1)b.

The noisy solver and cached actions give explicit intervals for every gradient
component. Their Frank-Wolfe gap gives a global suboptimality certificate. The
planner is constructed by scanning those k values and moving to the minimizing
simplex vertex; it is not supplied as an oracle. An explicit finite iteration
bound and all precision requirements are proved in the planning appendix.

The separate consumer prototype uses a fully charged noisy Richardson solver,
not the main cache: n=24,k=6, sixteen design iterates, 1026 primitive actions,
computed gap upper bound 0.0091553075 against target 0.01. An exact-reference
calculation used only for checking gives gap 0.0090647179. This verifies the
consumer interface and algorithm in floating point; it does not establish an
executed reuse advantage for the optimization application.

USEFUL ROUTES RETAINED WITHOUT OVERPROMOTION

1. Variable-precision noisy power iteration acquires a reusable resolvent for a
   promised dominant mode plus generic small tail, with precision cost scaling
   as discovery plus refinement. Strong ordinary noisy-power methods already
   attain the same polynomial dependence; the tempting polynomial advantage
   over a weak fixed-precision comparison was corrected. Certifying an unknown
   tail restores the harder ambient-times-accuracy cost.

2. Relative energy approximation supports arbitrarily long switched dissipative
   computations without accumulating model error in proportion to time. This
   is powerful existing machinery: Veselic already proves the autonomous core,
   and mixed-defect operator geometry supplies the discrete counterpart. A full
   noisy-action learner is supplied but costs dense identification. Unknown zero
   modes remain impossible to certify from a fixed absolute-noise floor.

3. Passive component assembly and port reduction have strong established
   reduced-basis precedents. They were not recast as new inventions.

4. Exact-algebra trace capital remains separate and preserved. Numerical action
   width is not a universal replacement for algebra dimension.

EVIDENCE AND LIMITS

The primary proof and supporting arguments were checked by complementary
collaborators with shared construction context. The primary main and affine
programs were also re-executed by the lead. Numerical results are reproducible
finite tests, not formal verification or physical experiments.

The main theorem models exact internal arithmetic with bounded external action
errors. A finite-arithmetic specification provides safe normalization cutoffs,
Gram conditioning, explicit rounding debits and threshold slack. The prototype
uses ordinary double precision and does not implement outward interval arithmetic.
No completed formal finite-bit complexity theorem is asserted for this extension.
The earlier exact compiler's separate rational finite-bit result remains intact.

The decisive remaining research goal is a total-cost advantage over equally
informed strong retaining methods on an important family, or a broader acquired
geometry theorem that enables an operation those methods do not already supply.
The present result is a reliable constructive step and a sharper boundary on
universal compilation, not evidence that this goal has already been achieved.

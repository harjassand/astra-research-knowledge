# Precision and observability before reusable computation

Date: 2026-10-31. Working mathematical result for the Astra construction task.
This note derives an information lower bound and a constructive task-directed
escape. It does not claim literature novelty. The main proof is elementary
indistinguishability plus a spherical small-cap bound. The comparison section
identifies existing machinery relevant to stronger positive constructions.

## 1. Exact contract

Let n >= 2 and 0 < a <= 1 be known. Work initially over R^n. The unknown,
fixed positive-definite matrix belongs to

    C = {I} union {A_u = I + a u u^T : ||u||_2 = 1}.

Every matrix in C has condition number at most 2. A_u generates an exact
unital algebra of dimension 2 (the identity matrix generates dimension 1).
Thus neither a large exact algebra nor an ill-conditioned downstream problem
causes the lower bound below.

An experiment requests a vector v and an accuracy sigma > 0, and receives

    y = A v + e,        ||e||_2 <= sigma ||v||_2.

Errors may be deterministic, query-dependent, correlated across experiments,
and chosen adversarially subject to this bound. The matrix A is fixed before
the algorithm's random coins. This is a contract on each action, not a promise
that all errors are generated by a single small-norm linear perturbation.

The learner chooses v and sigma adaptively and eventually produces a
source-free compiled map F. For a requested relative solve accuracy epsilon,
its required event is

    for every later b: ||F(b) - A^{-1} b||_2 <= epsilon ||A^{-1}b||_2.

The map can use ordinary arithmetic and retained data, but cannot consult the
source after b is provided. We require the event to have probability at least
1-delta for every A in C and every admissible source-error rule. Assume

    0 < delta < 1/2,        0 < epsilon < a/(a+2).

For example a=1, epsilon=1/4 is allowed, while all matrices remain between I
and 2I in Loewner order. Acquisition failure, unsuccessful probes and precision
charges count. No representation of u is supplied.

## 2. A single fixed source-error rule

For each u define the following oracle, for every v and requested sigma:

    O_{u,sigma}(v)
      = A_u v - clip(a u^T v, -sigma||v||, sigma||v||) u.

Here clip truncates a scalar to the indicated interval. This is a fixed,
deterministic rule determined by u, v and sigma. It has admissible error norm
at most sigma||v||. In particular,

    O_{u,sigma}(v) = v whenever |u^T v| <= (sigma/a)||v||.

The identity matrix's reference oracle returns v exactly. Until a query has
enough overlap with u to exceed its tolerance, the entire transcript is exactly
the identity transcript. The rule does not need advance knowledge of the
algorithm's random coins or future queries.

## 3. Spherical small-cap lemma

If U is uniform on the real unit sphere and x is a fixed unit vector, then

    P(|U^T x| > t) <= 2 exp(-n t^2/2)  for all t >= 0.

For t>=1 the actual probability is zero. One elementary proof uses the moments

    E[(U^T x)^(2k)] = (2k-1)!! / [n(n+2)...(n+2k-2)]
                    <= (2k-1)!! / n^k.

Odd moments vanish, so E exp(s U^T x) <= exp(s^2/(2n)). Apply Chernoff to the
two tails. No asymptotic approximation is used.

## 4. Adaptive randomized coupling theorem

Run the acquisition algorithm against the identity reference oracle. Conditional
on all its random coins omega, this defines a full reference sequence

    (v_t(omega), sigma_t(omega)),       t=1,...,M(omega).

Sample U uniformly and independently before running the algorithm. Let H be
the event that all these reference queries obey

    |U^T v_t| <= (sigma_t/a)||v_t||.

On H, induction on the query index shows that the A_U oracle generates exactly
the same answers, query vectors, requested precisions, stopping time and stored
artifact as the identity reference oracle. Adaptivity therefore does not make
the reference query directions depend on U. The union bound and the lemma give

    P(H^c) <= 2 E_omega sum_{t=1}^{M(omega)}
                         exp[-n sigma_t(omega)^2/(2a^2)].                  (1)

For a fixed direction u, the ideal identity and spike solves on b=u are u and
u/(1+a). Their relative-epsilon balls are disjoint because

    ||u-u/(1+a)|| = a/(1+a)
       > epsilon [1+1/(1+a)]

is exactly epsilon < a/(a+2).

Let G_0 be the event that the identity artifact works for every b. By the
required guarantee P(G_0)>=1-delta. On G_0 intersect H, the same compiled map
must fail for A_U at b=U. Thus averaged over U, its failure probability for A_U
is at least

    1 - delta - P(H^c).

If it succeeds with probability at least 1-delta for every fixed u, averaging
forces P(H^c)>=1-2delta. Combining with (1) gives the necessary condition

    2 E_omega sum_t exp[-n sigma_t^2/(2a^2)] >= 1-2delta.                 (2)

This argument samples the matrix before the algorithm's coins. Averaging then
shows that some fixed matrix A_u violates any proposed stronger guarantee.
There is no choice of A after seeing the learner's randomness.

The reference run may have a random finite stopping time. If its expected
precision price is infinite, the cost lower bound below is automatic; otherwise
the same union bound is justified by monotone convergence. Zero vectors are
uninformative and can be deleted.

## 5. Fixed-precision and variable-precision consequences

### Fixed precision

If at most m experiments are made and every requested tolerance is at least
sigma, (2) implies

    m >= [(1-2delta)/2] exp[n sigma^2/(2a^2)].                            (3)

For fixed nonzero sigma and a, the worst-case number of experiments is
exponential in ambient dimension, although the exact algebra has dimension at
most two and the matrix condition number is at most two. Even querying every
coordinate can leave the spike hidden: each column error can have norm at most
sigma while the jointly hidden rank-one matrix has operator norm a.

### Precision price

Suppose an experiment at tolerance sigma has declared price sigma^{-p}, p>0.
This may represent an explicit worst-case accuracy-cost contract. It is not
automatically a statement about the sample complexity of unbiased stochastic
experiments. Let

    C_p = E_identity sum_t sigma_t^{-p}.

The elementary maximization

    sup_{sigma>0} sigma^p exp[-n sigma^2/(2a^2)]
       = [p a^2/(e n)]^(p/2)

and (2) imply

    C_p >= [(1-2delta)/2] [e n/(p a^2)]^(p/2).                           (4)

In particular,

    C_2 >= e n(1-2delta)/(4a^2).                                        (5)

Thus the most useful discovery tolerance lies on the scale a/sqrt(n), and
paying for many coarse experiments cannot evade the total precision charge.
For a=1 and delta=1/3, C_2 >= e n/12.

The same calculation gives a more general weighted observability condition
(2) even when the precision price is not a power law.

## 6. Complex field

For U uniform on the unit sphere in C^n, n>=2,

    P(|U^*x|>t) = (1-t^2)^(n-1) <= exp[-(n-1)t^2], 0<=t<=1.

Use radial complex clipping of a U^*v. The same proof gives

    E sum_t exp[-(n-1) sigma_t^2/a^2] >= 1-2delta,

    m >= (1-2delta) exp[(n-1)sigma^2/a^2],

    C_p >= (1-2delta) [2e(n-1)/(p a^2)]^(p/2).

These constants differ because a complex spherical coordinate has two real
components. The underlying conclusion is unchanged.

## 7. A constructive escape: do the requested computation first

Every matrix in the promised class obeys

    (A-I)^2 = a(A-I),
    A^{-1} = [(2+a)I-A]/(1+a).

Once b is supplied, make one experiment y=Ab+e and return

    x = [(2+a)b-y]/(1+a).

Then

    ||x-A^{-1}b|| <= sigma||b||/(1+a)
                   <= sigma||A^{-1}b||.

The second inequality uses A<= (1+a)I. Therefore a single experiment at
tolerance sigma=epsilon solves every future instance to the desired relative
accuracy, for every admissible deterministic error. Its precision price is
epsilon^{-p}, independently of n. Arithmetic and reading/writing the vector
still cost O(n).

This is an exact, fully charged comparison, not a claim of a new solver:
the polynomial relation is supplied by the class promise, and the one-action
formula is elementary. Its purpose is to show that asking for a source-free,
task-independent representation can be drastically more expensive than making
the consequential computation feasible with one task-directed experiment. If
there are T future tasks, this baseline has T experiments. An offline compiler
must beat that total, including its precision expenditure, before it has earned
an amortized benefit.

More general conclusions must not smuggle this identity, the unknown direction
u, a stable basis, or a useful solver into the learner's input. Here a is known;
an unknown a would require a separate acquisition argument.

## 8. Uniform future tasks versus average prediction

For a fixed u and an independent uniform unit right-hand side B, let
beta=a/(1+a). Using the identity as an approximate inverse gives

    E ||B-A_u^{-1}B||^2 = beta^2/n,
    E ||A_u^{-1}B||^2 = 1-(2beta-beta^2)/n.

Average prediction is therefore excellent, with RMS relative scale O(n^{-1/2}),
while the particular later task b=u suffers order-one error. This is an
information distinction, independent of any hard combinatorial planning
problem.

The lower bound is for uniform source-free future guarantees. If all later
tasks are drawn independently from a prescribed benign distribution, the
guarantee is weaker and may be cheap. If the learner gets new source actions
after seeing a task, the one-action construction applies. If source and future
task may be correlated, the task b=u is a valid stress test. These contracts
must be kept distinct.

## 9. What the theorem does not say

1. It does not apply without modification to a fixed linear perturbation E with
   ||E||<=sigma for all v simultaneously. Our admissible clipping error is
   nonlinear in the query. The actionwise error model permits this; the fixed
   perturbation model excludes it.
2. It does not apply directly to independent, zero-mean, isotropic errors.
   Such errors have much smaller projections onto a fixed signal direction;
   noisy power iteration can exploit that structure. Repeated averaging can
   reduce random error but cannot remove arbitrary deterministic bias.
3. The price sigma^{-2} is an explicit hypothetical accuracy-cost law. To obtain
   it from physical measurements one must construct the estimator and charge
   confidence, bias control, ambient output dimension and any correlations.
4. No bound on ordinary arithmetic, memory, total experimental energy, or
   acquisition of the model-class promise is proved by (3)-(5). They are source
   information/precision lower bounds. The full-vector interface already has
   O(n) input/output cost.
5. The lower bound does not imply that all useful reusable computation is hard.
   It identifies a missing resource: overlap of admissible experiments with
   task-relevant modes at available precision. Local interfaces, restricted
   future tasks, a source noise covariance promise, or online correction can
   change that resource.

## 10. Organizing lesson for the positive construction

There are two different conditioning problems:

- downstream conditioning: how a learned operator error changes the requested
  computation;
- acquisition observability: whether the available experiments expose the
  directions whose errors matter, at the precision the source can afford.

The example keeps downstream condition number <=2 and exact algebra dimension
<=2 while making acquisition observability poor. A robust compiler theorem
must earn both. A useful route is to learn local passive/energy certificates
on small interfaces, which can preserve relative errors under assembly, rather
than demanding that broad probes discover every global direction. That route
still owes the actual local experiment protocol, energy norm and solver costs.

## 12. Accuracy-sharp version for unknown spike amplitude

Consider the larger class A=I+a uu^T with unknown a in [0,1]. Let the demanded
relative solve error be epsilon in (0,1/4]. Taking the admissible subfamily
with a=4epsilon gives epsilon<a/(a+2), so (4) yields

    C_p >= [(1-2delta)/2] [e n/(16p epsilon^2)]^(p/2).                   (6)

The n and epsilon exponents are attainable, up to a logarithmic confidence
factor, by a direct construction that does not know a or u:

1. Draw q independent uniform unit vectors v_i. Request y_i=Av_i+e_i with
   ||e_i||<=eta, eta=epsilon/(100sqrt(n)). Form z_i=y_i-v_i.
2. If max_i||z_i||<=2eta, output the identity inverse.
3. Otherwise set uhat=z_i/||z_i|| for an index attaining the maximum. Request
   y=A uhat+e with ||e||<=zeta=epsilon/100. Set
   ahat=clip(Re(uhat^*y)-1,0,1), and retain (ahat,uhat).
4. Answer every later task explicitly by
   F(b)=b-[ahat/(1+ahat)]uhat(uhat^*b).

For a fixed true u, the real spherical second/fourth moments and
Paley-Zygmund give

    P(|u^Tv_i|>=1/(2sqrt(n))) >= 3/16.

Thus, with probability at least 1-(13/16)^q, at least one probe has that overlap.
Condition on this one simultaneous event. If step 2 occurs, then
a/(2sqrt(n))-eta<=2eta, hence a<=6eta sqrt(n)=0.06epsilon; the identity inverse
has relative error at most a for every b.

Otherwise put P=uu^T and Q=uhat uhat^T. The measured largest residual satisfies
||(I-P)z_i||<=eta. If a>=4eta sqrt(n), then ||z_i||>=a/(4sqrt(n)), so
a||P-Q||<=4eta sqrt(n)=0.04epsilon. If a<4eta sqrt(n), the same bound follows
from ||P-Q||<=1. The amplitude estimate obeys

    |ahat-a| <= a sin^2(angle(u,uhat))+zeta <=0.05epsilon.

Therefore Ahat=I+ahat Q has ||Ahat-A||<=0.09epsilon and Ahat>=I. The resolvent
identity gives, for every b,

    ||Ahat^{-1}b-A^{-1}b||
      <=||Ahat^{-1}|| ||A-Ahat|| ||A^{-1}b||
      <=0.09epsilon ||A^{-1}b||.

The failure probability is at most delta for q>=log(1/delta)/log(16/13).
Acquisition makes q+1 full-vector actions and has precision price
O(n^(p/2)epsilon^{-p}log(1/delta)); it stores O(n) numbers and answers a full
vector task in O(n) arithmetic. Arithmetic precision is separately chargeable;
this argument is in exact arithmetic with bounded experimental errors.

This matching special model calibrates the missing acquisition resource.
It is not offered as the main scientific destination or as a new general
low-rank recovery algorithm.

## 13. Why a live task audit can remain necessary

For any retained experimental history, let C_history contain all sources and
admissible error histories consistent with the observed answers. If there are
A_0,A_1 in C_history for which the acceptable output balls on a newly supplied b
are disjoint, no source-free deterministic answer can be certified for that
task. More source information is needed, or the required accuracy must change.

A simple exact-history example takes the span Q of all queried vectors,
u in Q-perp, A_0=I, A_1=I+a uu^T, and the new task b=u. Both sources give exactly
the same prior answers, while their correct solutions are incompatible at
epsilon<a/(a+2). This deterministic completion example alone is not a randomized
lower bound; sections 2-6 provide the appropriate randomized, fixed-source,
bounded-noise version.

The conclusion is not that every task always needs one fresh action. Once a
sufficient global model is earned, source-free execution can be valid. Instead,
until the task-relevant uncertainty is removed, a live residual audit is a
constructive economical alternative to paying the worst-case universal
precision cost. Actual task-image width can remain small even when universal
offline certification is expensive. Any claimed elimination of all future
audits must separately earn that stronger uncertainty guarantee.

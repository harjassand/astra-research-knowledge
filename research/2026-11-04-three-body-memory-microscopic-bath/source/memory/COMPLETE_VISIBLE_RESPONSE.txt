The memory work has made progress on the noise question: we now have an internally checked extension for a specified class of microscopic interacting baths, rather than relying only on an idealized noise equation. It still assumes a particular correlated thermal starting state and an ideal write/read interface. That makes the storage argument stronger, but it does not solve the practical task of preparing that state or writing into it reliably. The result is also not a guarantee against arbitrary hardware noise. I’m focusing on those missing operations.

AN EXACTLY RETURNING EXCHANGE ENTANGLER AND AN EXPLICIT CZ COMPILER
31 October 2026. Units hbar=1 and s=sigma/2 throughout.

PURPOSE AND STATUS

This supplies a complete entangling operation on the same four-spin singlet
encoding used by the exact exchange verifier. It is an exact finite eight-spin
Hamiltonian result. No small interblock coupling, infinite gap, adiabatic limit,
or additional four-body interaction is used. Physical exchange calibration,
the dense coupling graph, orbital admission, switching and noise remain costs.
It does not establish a quantum-dot device window or protected control angles.

The four-spin singlet code, exchange universality, and traversal of the larger
global singlet manifold are established prior art. The candidate increment is
this explicit, finite-ratio, exactly returning graph and its actual pulse time.
A targeted literature search did not establish historical novelty.

1. ENCODING AND PHYSICAL GRAPH

For each block of four spins, use

 |0_L> = |s_12>|s_34>,
 |1_L> = (|t+_12 t-_34> - |t0_12 t0_34> + |t-_12 t+_34>)/sqrt(3).

Label two blocks A=(1,2,3,4), B=(5,6,7,8). Define

 J_A=s1+s2+s3+s4,       J_B=s5+s6+s7+s8,
 A=s1+s2, C=s3+s4,      B=s5+s6, D=s7+s8.

Turn on the following positive exchanges, all with the same strength Delta:

 H_G = (Delta/2)(J_A^2+J_B^2) + Delta A dot B.             (1)

The first term is six ordinary pair exchanges within each block plus a known
constant. The second is FOUR crosslinks 1-5,1-6,2-5,2-6. Thus (1) means sixteen
simultaneous pair exchanges, not a free four-body or all-to-all black box.
Dropping the known constant changes only a global phase.

The individual pair spins A^2,B^2,C^2,D^2 are conserved. If either logical input
is 0, then A=0 or B=0 and the cross term annihilates that input. Both blocks
start in J_A=J_B=0. Therefore |00>,|01>,|10> are exactly stationary under (1).

Only |11> moves. Its four constituent pairs all have spin one, and their total
spin remains zero. The global singlet sector of four spin-one objects is
three-dimensional. A convenient basis couples A+C to j and B+D to j, then
couples those two spins to zero, with j=0,1,2. The first basis state is |11>.

2. THREE-DIMENSIONAL EXACT REVIVAL

In this basis, choosing harmless real phases,

 H_G/Delta = [[0,        2/sqrt(3),       0],
              [2/sqrt(3), 3/2,           sqrt(5/12)],
              [0,        sqrt(5/12),     9/2]].            (2)

One can obtain (2) by Clebsch-Gordan recoupling, or directly by restricting the
eight-spin Hamiltonian. The diagonal penalty is (0,2,6); the cross term is

 A dot B = [[0, 2/sqrt(3), 0],
             [2/sqrt(3), -1/2, sqrt(5/12)],
             [0, sqrt(5/12), -3/2]].                      (3)

The characteristic identity is

 (H_G/Delta - 2I)^3 = 7(H_G/Delta - 2I).

Consequently its eigenvalues are 2-sqrt(7), 2, 2+sqrt(7). At

 T_G = 2pi/(sqrt(7) Delta),                              (4)

all three eigenphases coincide. The initially local singlet state returns
exactly, with phase

 phi_G = 2pi(1-2/sqrt(7)) = 1.533543660284683... .         (5)

On the entire two-qubit code the gate is therefore

 U_G = diag(1,1,1,exp(i phi_G)).                          (6)

This is entangling. Its duration is 2.374820823447452/Delta. Local J=1 and J=2
states are REALLY occupied during the gate; their presence was not discarded
as a perturbative virtual population. The endpoint return is the exact spectral
recurrence. The global total spin remains zero throughout.

3. EXPLICIT EXACT CZ FROM THREE NATIVE CONTACTS

Let R_z(theta)=exp(-i theta Z/2), and similarly R_y. A conditional phase is

 CP(phi) = |0><0| tensor I + |1><1| tensor exp(i phi/2) R_z(phi).

Set phi=phi_G and choose

 n_z = cot(phi) cot(phi/2) = 0.038684830603923664...,
 beta = acos(n_z) = 1.532101840941977... .                 (7)

The target-unitary product

 R = R_z(2phi) R_y(beta) R_z(phi) R_y(-beta)               (8)

has zero trace because

 tr(R)/2 = cos(phi)cos(phi/2) - n_z sin(phi)sin(phi/2)=0.

It is a determinant-one pi rotation, so M=iR is a Hermitian involution with
eigenvalues +1,-1. Choose a calibrated local V with V^dagger M V=Z. Then

 Q = (I tensor V^dagger) CP(phi)^2 (I tensor R_y(beta))
                       CP(phi) (I tensor R_y(-beta)) (I tensor V)

is identity for control 0 and exp(i3phi/2)(-iZ) for control 1. Multiplying the
control by diag(1,exp(i(pi/2-3phi/2))) gives CZ EXACTLY.

Thus arbitrary local exchange gates plus three copies of (6) give an explicit
standard universal gate set. The sum of entangling intervals is

 3T_G = 6pi/(sqrt(7) Delta) = 7.124462470342355/Delta.

The local rotations, their calibration, switching and any inserted verifier
are additional elapsed operations. They must not be silently counted as zero.
The program supplies one explicit V and verifies the complete 4x4 circuit.

4. LOCAL CONTROLS AND COMPATIBILITY WITH THE VERIFIER

Within the stated code basis,

 h12 = s1 dot s2 = -I/4 - Z/2,
 h23 = s2 dot s3 = -I/4 + Z/4 + sqrt(3)X/4.              (9)

Positive h12 and h23 pulses provide nonparallel axes. For example h23+h12/2
is -3I/8+sqrt(3)X/4, so simultaneous positive exchanges give an exact X axis;
Z and X generate all local rotations. The uniform penalty is scalar in the
code and is optional for these local gates.

For the verifier with singled-out data spin i=4, both controls act on its three
other data spins. They commute with every ideal verifier generator. Hence the
local compiler can run during verification in the spin Hamiltonian model.
The finite Hubbard calculation separately tests how simultaneous hopping
corrections modify this exact projected-spin statement.

The two-block Hamiltonian (1) does NOT generally commute with a local verifier.
The construction schedules its complete entangling interval first and then
verifies the two blocks, in parallel if two helper pairs and readouts exist.
It is not legitimate to insert local projective checks into the middle of
the three-dimensional excursion without recalculating the gate.

5. WHAT ERRORS THIS DETECTS, AND WHAT IT DOES NOT

Let P be the product of block singlet projectors and W(t2,t1) any SU(2)-scalar
exchange evolution. A single local vector S_i^a maps GLOBAL spin zero to one.
Thus at every time t,

 P W(T,t) S_i^a W(t,0) P = 0.                           (10)

This is a familiar singlet-code selection rule, not a new general QEC theorem.
It applies to the fast gate because its entire trajectory is globally singlet.
The exact physical verifier supplies the endpoint P test, including all local
J=2 leakage. Ordinary global Pauli stabilizers can also reject global J=1;
full-J admission is a stronger task but is not exclusively responsible for (10).

If a two-block gate is flagged, conservative recovery marks BOTH participants
as erased. An error during entangling evolution may affect both blocks, even
if only one helper reports triplet. Repair requires an outer code capable of
correcting that located two-block event, together with actual data replacement.

There are three essential counterexamples to a broader claim:

 (a) Two vector insertions can return to the code. For example
     P (sigma1z sigma2z) P = diag(-1,1/3) on one block.
 (b) A scalar exchange error h12 is a logical Z term and passes the verifier.
 (c) A wrong crosslink amplitude in (1) produces a first-order accepted logical
     phase error even though leakage probability starts quadratically.

The last statement is verified directly. For a common fractional crosslink
error epsilon=0.001, the accepted nonscalar error is about0.00142947 while
worst gate leakage is only2.09048e-6. A successful singlet check is therefore
not a gate-angle calibration certificate.

Magnetic faults occurring DURING the physical verifier have a further boundary:
late faults can remain as unflagged J=1 output. The exact counterexample and
required full-duration exposure are in GAP_FREE_STAR_PROJECTOR.txt. An ideal
endpoint projector cannot be substituted for its noisy physical implementation
when evaluating a full code cycle.

6. COMPARATORS AND COUPLING COST

Bacon et al. (PRL85,1758,2000) already established universal exchange control
of four-spin singlets by using the global eight-spin singlet manifold. Their
construction explicitly supplies a controlled phase through exchange-generated
commutators. Singlet-only SAGE control (Foulk et al., arXiv:2501.18589v2) already
has a single interblock interaction interval; its sparse one-crosslink regime
uses an effective coupling of order J_c^2/J_0. It pays a weak-coupling time scale
and leakage, while requiring much less connectivity than (1).

The present graph trades coupling density and matching for a finite-ratio exact
return and O(1/Delta) coherent duration. No maximum-degree, planar-nearest-
neighbor, control-noise, shuttling or elapsed-readout advantage is established.
It can be replaced by a strong established sparse exchange compiler whenever
that is the better physical implementation; the exact verifier does not rely
on this particular entangler.

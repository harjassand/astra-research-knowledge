ENDPOINT PARITY CONVERTS LOST FLUORESCENCE INTO LOCATED ERASURES
2026-10-31. Complementary construction; not the selected device architecture.

Decision
========

The inherited split-manifold optical instrument contains a useful syndrome
which was not used in its perfect-collection recovery: the final emitter
sector records the parity of the actual number of informative photons.
Comparing it with the received-photon count detects every odd number of
missed photons, without knowing how many photons were emitted or predicting
their times. One photon lost from an exposed unknown qubit remains an
irreversible local error; it becomes a located error rather than an
unannounced error. An outer distance-d code then corrects every history with
fewer than d missing photons. This improves the loss exponent, in the exact
interaction model, from the ordinary unknown-error counting to order d.

This is a substantive extension of the recovery capital, but not a winning
proposal for a new quantum network. A prepared communication emitter can be
kept disconnected from stored data until a photon is accepted; established
double-heralding and emit-then-add methods exploit that freedom. They are
the stronger choice for preparing network or computation resources with
poor collection. The construction below is useful when unknown information
has already been exposed to the alternating fluorescence process. It has
not supplied a reason why a useful processor must expose that information.

1. The retained optical model
=============================

Use the complete split-manifold construction in
next_recycling_optics/ and phase3_photon_closure/. Its invariant sectors are

 C = C^2_logical x span{g_j, e_zj, e_jz}, j=x,y,
 B = span{g_z, e_zz, (e_xx+e_yy)/sqrt(2)}.

The block Hamiltonians and every z-polarized recycling history are identical
on the two logical vectors inside C. Informative x/y emissions alternate
C -> B -> C. The source may be noncommuting and shared with previous
operations; no source reset, classical hidden-source assumption, or
independent emission-time model is introduced here. The physical source,
orbital and optical Markov admission of the inherited model is unchanged.

After the drive is off and optical excitation has drained, the emitter is
in span{|g_x>,|g_y>} for an even total number N of x/y photons and |g_z> for
odd N. Define b=0 on the former subspace and b=1 on the latter. Then

                     b = N mod 2.                           (1)

The z photons are not included in N and do not change b. This is a block
identity for every fine trajectory, not an equality of averaged rates.

The streaming receiver prepares one memory in |+>, applies the same
controlled-Z between this memory and every collected informative photon,
and measures that photon in X. Let M be their number and s the XOR of
their outcome bits. With no loss, the inherited correction recovers the
logical qubit in the memory if N is odd and in the emitter if N is even.
For N=0 the emitter already contains the qubit. Endpoint-dependent routing
or code recovery must address the correct physical register; that is a
real control cost, not a relabeling that supplies a physical SWAP.

2. A syndrome for an unknown photon count
========================================

Let L=N-M be the number of missed informative photons, including failures
to produce a receiver outcome after emission. Read b at the endpoint and
set

                     f = b XOR (M mod 2).                    (2)

Equations (1)-(2) give f=L mod 2 on every emission history. Every single
miss is detected, even if the miss occurred before the receiver could
interact with the photon. Two misses in one stream can be invisible.

The sector measurement must distinguish {x,y} from z without resolving x
against y. It is not enough to measure the three Cartesian states and
discard the extra classical label: that would destroy a surviving even-N
logical qubit. Equivalently the desired observable on the spin-one ground
manifold is F_z^2 (in units with hbar=1), whose eigenspaces are the two
logical states and the single auxiliary state.

A selection-rule construction for this endpoint operation is available:
add a calibrated pi-polarized transition from an F=1 ground manifold to an
F'=0 auxiliary excited level. Its dipole matrix has only the m=0 ground
column. A selective shelving pulse has the interaction

 H_s(t)=Omega(t)|a><g_z|+h.c.,

and is exactly zero on span{g_x,g_y}. A pulse area pi/2 transfers z to a
shelved marker a. A subsequent detector which acts only on the marker can
be destructive: the logical information is outside the emitter on that
branch. Recoil and detector fine outcomes cannot distinguish x/y because
the no-marker branch has not coupled at all. Spontaneous decay during
shelving, other excited manifolds, imperfect polarization, detuning,
source shifts and marker discrimination remain errors to bound. Raman
shelving can reduce intermediate excited occupation when a suitable
metastable target exists, but no atomic species with this complete window
is claimed here. This is an explicit compatible selection-rule operation
in the interaction model, not a fitted optical device.

The addition deliberately permits calibration and a prepared marker
detector. It does not claim that the original arbitrary-source theorem
automatically guarantees the new shelving pulse.

3. Correcting all histories with fewer than d missing photons
============================================================

Encode k logical qubits in an [[n,k,d]] code across n separate streams.
During this exposure there are no logical entangling gates between code
positions; any shared source acts through the inherited logically scalar
couplings. The sources can be jointly correlated and dynamically active.

For each stream with f_i=1 discard its accessible output and mark that
code position as erased. For f_i=0 apply the inherited endpoint decoder.
Every stream with no lost photon has a fine operation I_logical tensor
B_history, including all source backaction. A stream with lost photons
may undergo an arbitrary local error. The true-parity endpoint read tells
the decoder which physical endpoint is present even on a faulty stream.

Let e be the number of flagged positions and u the number of unflagged
positions that contain one or more lost photons. Each flagged position
has at least one miss. Each such unflagged position has at least two.
Therefore

                  2u+e <= L_total.                          (3)

A distance-d code corrects arbitrary errors on u unknown positions and
arbitrary errors at e known positions when 2u+e<d. To see this directly,
condition on the set F of flags. Expand every fine operator in Pauli
operators on F and on at most floor((d-1-|F|)/2) other positions, tensored
with source and output-field operators. A product of two such Pauli
operators has support at most |F|+2 floor((d-1-|F|)/2)<d. Its compression
to the code is scalar. The Knill-Laflamme conditions therefore hold for
the entire conditional error set. The coefficient operators on a common
source or a previously emitted field do not change that conclusion.

Combining this with (3), a single syndrome-and-recovery operation corrects
every trajectory with L_total<d. The assertion includes coherent sums
over unknown emission times and polarization histories. Tracing the lost
field is permitted only after constructing the local error algebra.

This is not a fault-tolerant circuit threshold. In particular, a logical
entangling gate during exposure can spread an error and invalidate the
support count. Encoding, recovery, memory noise and endpoint controls must
be separately fault tolerant if this mechanism is used in a processor.

Examples:

 * The four-qubit code
   |0_L>=(|0000>+|1111>)/sqrt(2),
   |1_L>=(|0011>+|1100>)/sqrt(2)
   corrects every one-miss history. It suppresses collection errors to
   second order. This erasure code is established prior art, not a new code.

 * The standard five-qubit [[5,1,3]] code corrects every two-miss history.
   Two misses on different streams produce two erasures. Two on one
   stream produce at most one unknown local error. Both are correctable.
   The resulting collection contribution starts at third order.

4. Full instrument error and complete-duration count bound
=========================================================

Let epsilon bound the probability of loss for every admitted one-photon
mode. A polarization-independent passive collection map has transmitted
and lost mode operators T,L with L^dagger L<=epsilon I and with no
polarization dependence. For a general N-photon state, including arbitrary
temporal entanglement, the falling factorial moments of the number of
lost photons obey

   E[(L_total)_d | N_total=N] <= epsilon^d (N)_d.

This follows by applying (L^dagger L)^{tensor d} to the d-particle density
operator; independence or a binomial classical hidden state is not
required. Hence

  Pr{L_total>=d} <= epsilon^d E[binom(N_total,d)].             (4)

A polarization-blind no-loss filter commutes with the global polarization
parities used by the receiver. It therefore preserves the no-loss logical
identity. Polarization-dependent collection, unresolved dark counts, or
an output CZ whose phase depends on polarization frequency must instead
enter an additional instrument error; (4) alone does not remove them.

In the admitted optical Markov model, the total photon rate from each
emitter is at most Gamma. During a drive of duration T the count process
is stochastically dominated by a Poisson process of mean mu=n Gamma T.
After the drive is exactly zero there can be at most one further photon
per emitter. Thus N_total is dominated by Poisson(mu)+n, and

 E[binom(N_total,d)] <=
       sum_{j=0}^{min(n,d)} binom(n,j) mu^{d-j}/(d-j)!.       (5)

Informative counts are no greater than all-photon counts, so counting z
recycling photons in this bound is conservative. Combining (4)-(5), the
half-diamond error of the corrected logical instrument has the bound

 epsilon_L <= min(1, epsilon^d
       sum_{j=0}^{min(n,d)} binom(n,j) mu^{d-j}/(d-j)!)
       + delta_encoding + delta_recovery + delta_endpoint
       + delta_receiver + delta_memory + delta_model.       (6)

The ideal comparison retains the actual source, all classical records,
and accessible quantum outputs on all correctable histories. The lost
field is explicitly traced, as it is inaccessible in the stated task.
After exact recovery each correctable fine operator factors as I_logical
tensor B_history. The remaining CP map has effect at most p_bad I, where
p_bad is (4). Complete it with an ideal logical identity and the same
total auxiliary effect. The difference of the two bad CP maps has diamond
norm at most 2p_bad, giving the stated half-diamond probability cost. This
uses the trace over lost photons to remove cross terms between different
lost-field number sectors. If a comparison instead retains that entire
lost field coherently, orthogonality alone does not remove cross terms;
the general continuity allowance is of order sqrt(p_bad), not p_bad.
The complete emission history is used in the proof, but an inaccessible
environment is not silently made into an accessible classical record.

For [[4,1,2]], x=Gamma T, the coefficient in (6) is
  epsilon^2 (8x^2+16x+6).
For [[5,1,3]], it is
  epsilon^3 (125x^3/6+125x^2/2+50x+10).
These are upper bounds, not thresholds or required apparatus overheads.
At x=1 and epsilon=0.01 they are 0.003 and 0.000143333 respectively,
before any encoding, measurement, memory or receiver error.

Complete elapsed time includes loading, encoding, T, the off ramp,
optical drain, propagation/storage and receiver latency, endpoint shelving
and readout, endpoint routing, recovery and any reload. The ideal exact
drain can be replaced by a time T_d. With the drive off, excited occupation
is bounded by exp(-Gamma T_d) per emitter in this model; a conservative
coherent truncation allowance is 2 sqrt(n exp(-Gamma T_d)). Thus
T_d >= (2/Gamma) log(2 sqrt(n)/delta_d) suffices for allowance delta_d.
Photons remain collected and decoded throughout the drain. A finite
propagation-delay or filter-tail allowance is also required. There is no
unmonitored waiting interval whose coherence cost is omitted.

5. What the syndrome changes, and what it does not
=================================================

The previous loss no-go is preserved. If the first informative photon is
lost before any receiver interaction, the accessible channel of that
single exposed qubit is independent of its input. Its conditional
entanglement fidelity cannot exceed 1/4. Endpoint parity does not recover
the missing qubit. It supplies the location needed for a larger code to
recover information stored nonlocally across its physical qubits.

For poor collection, epsilon is large and (6) is generally useless. It
would be a mistake to demand high-order correction of a deliberately
exposed input when the same prepared memories could isolate that input
until a communication resource has been heralded. Gold et al.'s
emit-then-add architecture uses one extra memory spin, an extra local
entangling gate and measurement/reset per accepted photon. For the MBQC
tasks it supports, destructive photon detection may precede connection
to the stored graph; no photon QND measurement or storage is then needed.
Its rate is linear in inverse collection efficiency, at the cost of
longer memory exposure and local gate infidelity. Barrett-Kok double
heralding is an older strong comparator for remote entanglement.

Our receiver already requires a quantum memory, a uniform coherent
photon-memory interaction, stopping/drain control, and new endpoint
readout. Four or five encoded streams then add nontrivial local gates.
No advantage over the above calibrated resource-generation schemes has
been demonstrated at equal resources. In particular, alternating output
locations do not themselves implement deterministic transfer to a remote
receiver: returning the even endpoint to that receiver needs a physical
transfer, and distributed code recovery can require network gates.

The new organising point is narrower and useful: a quantum system can
record emission parity even when the photon counter misses emissions.
Matching a local endpoint syndrome against the received record converts
the leading irreversible quantum loss into a located fault. It can be
combined with ordinary codes without predicting a disordered source's
emission history. The scientific priority should nevertheless go to a
mechanism with a useful operation that is not already better achieved by
isolating data and heralding prepared communication resources.

6. Validation and sources
=========================

check_endpoint_erasure.py and endpoint_erasure_results.json include:
 * all 127 loss-position patterns through six informative photons;
 * 9,829 complete fine streaming maps, retaining lost polarizations;
 * no-loss identity, endpoint parity, and constant-channel first-loss check;
 * 2,720 corrected four-qubit fine histories;
 * 17,920 corrected two-loss hidden histories for the five-qubit code;
 * all two-erasure Knill-Laflamme conditions, including correlated errors;
 * 24 finite-duration count-tail comparisons and the shelving matrix.
Maximum completeness residual: 3.77e-15. Maximum recovered fine-map
residual in the five-qubit tests: 1.99e-17. These are finite algebra checks,
not a proof of experimental pulse, field bandwidth, or saturation control.

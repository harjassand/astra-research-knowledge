ESSENTIAL COHERENT-HELPER RESOURCE: A DECISIVE FAILURE TEST
31 October 2026

Scope: the exact star verifier in GAP_FREE_STAR_PROJECTOR.txt. This note tests
the same six-spin interaction with helper singlet/triplet dephasing between the
three queries, without reset. It also gives the helper-phase calibration law.
These are exact full-instrument calculations, not an additional device model.

1. MODEL AND COMPLETE FINE HISTORIES

Let P=I_data tensor |s><s| and Q=I-P. The ideal chronological sequence is

    U, R(-phi), U^dagger, R(phi), U,
    phi=arccos(1/3), R(theta)=I+(exp(i theta)-1)P.

The helper remains the same two-spin system throughout. A complete singlet/triplet
pinching is D(rho)=P rho P+Q rho Q. Insert it immediately after the first and/or
second query. The pinching commutes with the neighboring R phase, so the precise
placement before versus after that adjacent phase makes no difference.

For pinching at both positions, the complete fine Kraus operators, including the
final helper outcome h, are

    K_{h,b,a}=<h| U R(phi) b U^dagger R(-phi) a U |s>,
    a,b in {P,Q}, h in {|s>,|t_-1>,|t_0>,|t_+1>}.

The final accept effect sums K_{s,b,a}^dagger K_{s,b,a}; all four final helper
outcomes sum to a trace-preserving instrument. No intermediate outcome is used
for corrective feedback. The environment causing the dephasing is not assumed
accessible. If its complete record were accessible and used to undo its phase,
that would be a different, enlarged resource contract.

The single-query accepted operator is

    K=-i P0-(D_i+P2)/2.

The J=1 bright sector B_i already has singular value zero, and the code has
singular value one. The dephasing failure occurs in the eight-dimensional
D_i+P2 sector with K=-1/2. Write k=-1/2 and x^2=1/4 in that sector.

For the four pinching histories, the accepted scalar amplitudes are

    a=P, b=P: k x^2                       = -1/8;
    a=P, b=Q: k(1-x^2) exp(-i phi)        = -(3/8)exp(-i phi);
    a=Q, b=P: k(1-x^2) exp(+i phi)        = -(3/8)exp(+i phi);
    a=Q, b=Q: -k(1-x^2)                  = +3/8.

Without pinching these four amplitudes sum coherently to zero. Pinching makes
the corresponding probabilities add, or prevents one of the two required
interference cancellations.

2. EXACT FAILURE PROBABILITIES

Let E_pass be the final helper-singlet effect on the data. In every case below,

    E_pass = P0+p(D_i+P2).

The worst probability of falsely accepting any leaked input is exactly p:

    no inter-query pinching:                  p=0;
    pinching only after the first query:      p=3/8;
    pinching only after the second query:     p=3/8;
    pinching after both queries:              p=7/16.

For example, with both pinchings the four squared history amplitudes sum to
(1+9+9+9)/64=7/16. With only the first pinching, the b histories still interfere
within each a outcome. Each of the two a outcomes contributes 3/16.

The code still passes with probability ONE in every case. Thus testing the
verifier only on uncorrupted code states would completely miss this resource
failure. Helper coherence is needed for rejection, not for good-input survival.

3. PARTIAL DEPHASING

Let D_eta leave both diagonal P/Q blocks unchanged and multiply P rho Q and
Q rho P by eta in [0,1]. This equals eta times the identity channel plus
(1-eta) times complete pinching. Applying D_eta1 after the first query and
D_eta2 after the second yields

    p(eta1,eta2)=(7-eta1-eta2-5 eta1 eta2)/16.             (1)

This follows by linearity from the four complete-pinching corner cases. The
formula is verified on all sixteen data dimensions by the full Kraus instrument.

Writing eta_j=1-d_j,

    p=(3/8)(d_1+d_2)-(5/16)d_1 d_2.

The false-accept probability therefore grows LINEARLY with a small loss of
inter-query helper coherence. If eta1=eta2=0.99, p=0.00746875. This is a direct
coherence requirement over the actual coherent-query interval, distinct from
the second-order sensitivity to small phase-area calibration errors below.

4. HELPER PHASE-AREA ERRORS

Replace the two intended singlet phases by

    alpha=phi+delta_plus,
    beta=-phi+delta_minus.

These deltas refer to the resulting singlet phases; the physical positive-area
implementation of beta uses 2 pi-phi+delta_minus. Keep the query unitaries ideal.
Expanding the two phase operators gives

    K_C=K[exp(i alpha)+exp(i beta)-1
               +(exp(i alpha)-1)(exp(i beta)-1)K^dagger K].

On code input it is -i exp[i(alpha+beta)] times identity, hence the code is still
accepted with probability one and incurs only an overall phase. B_i is still
rejected exactly. On D_i+P2, the false-accept probability is

    p_phase = |3 exp(i alpha)+3 exp(i beta)
                    +exp(i(alpha+beta))-3|^2/64.          (2)

For small phase errors,

    p_phase=(delta_plus+delta_minus)^2/16
               +(delta_plus-delta_minus)^2/8+O(delta^3).  (3)

In particular:
  * one phase has error delta: leading p=3 delta^2/16;
  * both phases have the same signed error delta: leading p=delta^2/4;
  * opposite phase errors delta,-delta: leading p=delta^2/2.

For the last case the exact formula is

    p=[3 cos(phi+delta)-1]^2/16.

This result is a sensitivity statement for these two phase areas only. It does
not imply immunity to arbitrary helper noise or simultaneous exchange errors.

5. LIMITED POLYNOMIAL DEGREE OBSERVATION

Within the standard parity-constrained singular-value-polynomial class, a
projector for this query must satisfy

    f(0)=0, f(1/2)=0, f(1)=1.

An odd degree-one polynomial cannot satisfy these values. The smallest possible
odd degree is three, and its uniquely normalized polynomial is

    f(x)=(4x^3-x)/3.

This is the polynomial actually implemented by the three-query construction.
An even polynomial of degree zero or two also cannot satisfy all three values;
degree four is the first even possibility, for example x^2(4x^2-1)/3.

This is a degree observation within that specified polynomial class. It is NOT
a lower bound on every exchange detector, every alternate Hamiltonian, adaptive
measurements, extra ancillas, or a different query construction. No overall
physical optimality claim follows.

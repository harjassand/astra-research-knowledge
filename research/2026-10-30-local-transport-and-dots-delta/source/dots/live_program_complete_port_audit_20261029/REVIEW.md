## Why extra causal calls do not break the algebra
Fix the allowed pre-role history and the candidate controller. A finite causal network of trusted operations, source interactions, adaptive classical measurements, capped branches and total output defaults is a CPTP map from L⊗M to L⊗M'. Its initial M contains the full source memory and controller/program state; its final M' contains every allowed record, residual program, source register and clock record. Time-dependent causal source interactions are allowed. There is no requirement that this finite network factor as one memoryless source call or that the auxiliary source outputs be independent quantum programs.

Under the explicit common-port condition the SAME network is used on fresh test states and padded service inputs. For each initial memory state, the averaged two-design failure effect equals k/(k+1) times the logical Bell-loss effect of this complete network. On SERVICE, the private logical pad is placed before the entire network and undone only after its logical output; every internal live-source interaction is between those endpoints. Retiring the pad then diagonalizes the complete Kraus expansion in the Pauli basis, including each retained internal measurement/time-out record. This is an equality of superoperators on arbitrary correlated logical-memory-reference inputs. The old aggregate-effect/NB/outer-code argument therefore imports directly per COMPLETE trial.

The logical payload need not be absent from all internal query registers: ordinary causal quantum information derived from the padded logical input is part of the common network and is allowed. What is forbidden is an extra current role, classical test label, pad key, or unpadded-payload access outside this network. The source may attempt to infer a test state through its legitimate quantum input; the two-design identity already handles arbitrary actions on that input. It must not be supplied the classical state description before the output is fixed.

## Clock and privacy boundary is substantive
An identical abstract algorithm is insufficient if role-controlled routing, pulses, program availability, timing or idle source exposure implements different physical maps. These must be equalized or included in a genuinely common network. Adaptive schedules depending on internal measurements of the common network are allowed and their records can be retained. Schedules depending directly on the private role, test label or pad are not. Pre-role work may depend on permitted past records; all fresh role/settings must retain their stipulated privacy. Previously retired keys and protected outer buffers must remain inaccessible to the continuing source. Noise acting on other outer buffers is not covered merely by calling those buffers source memory; the old protected-buffer requirement remains.

An elementary counterexample demonstrates necessity: if the source receives the current role, it applies identity on TEST and X on SERVICE. Test failures are zero while every service has a nonidentity Pauli fault, so the positive-effect/hazard comparison fails. A source receiving the classical test label could similarly discard and reprepare that state. These violate the stated interface rather than refute the theorem.

## Total fallbacks, aborts and causality
Every post-loading failure must produce a fixed-dimensional logical output via its declared CPTP fallback. It is part of the tested port, not a discarded calibration attempt. A flag may subsequently abort the guard. Formally one may complete the port, define the terminal test outcome and virtual service Pauli on every branch, and then apply the flag's stopping rule; aborting earlier is only an implementation optimization of that fully defined instrument. An accepted-history event remains a subset of the old NB crossing event. One must not replace the full-effect identity by an unsupported identity conditioned on a success flag or renormalized timeout-free subset.

The source must be causal: later revelation of a terminal test label cannot retroactively alter the completed output. Subsequent memory updates remain allowed by the old fine-history guard. No accepted conditional error without its acceptance denominator follows. The comparator is the actual accepted memory/transcript CP filter, not a scalar identity operation on initially correlated memory.

## Resources and limits
Per complete trial at most Q_pre preparation calls, one encoded test/service call and Q_post live-program calls are charged. Thus a cap of L trials costs at most L(Q_pre+1+Q_post), plus separately declared calibration. A shorter adaptive branch can use fewer; failed and timed-out calls still count. All gates, known-state preparations, readout, idle evolution, buffers, storage, random bits and total simulation durations remain charged. A source-use cap is not by itself a laboratory-time or storage guarantee.

The extension permits a decoder that obtains fresh source outputs after target arrival. It does not prove those outputs are IID or meet the conditional-product contract of sample-based Hamiltonian simulation under arbitrary memory. It supplies model-free accepted-instrument soundness only. IID/structured source hypotheses may separately establish that the candidate has low loss and useful availability. A prebank-only access model cannot claim this live-query interface or its possible memory savings without possessing continued source access.

COMPUTATIONAL OPENING: A RANK-TWO PREDICTOR DOES NOT ACQUIRE CONTROL
29 October 2026. Private scratch research. No publication. No novelty claim.

Outcome first
The attempted capability was autonomous intervention design from a compact,
accurate learned scientific predictor, without assuming a full matrix oracle.
It fails in an explicit binary process whose probability rank is only TWO at
every time cut. Exponentially accurate observational prediction can coexist
with exponential acquisition cost for a constant-value intervention. The
failure survives strictly positive reward laws. It is a conventional
combination-lock mechanism, not a new impossibility theorem. This branch
does NOT produce the requested civilisation-level enabling capability.

Strong same-information comparator, before any claimed gain
With terminal-only controlled experiments, the competent conventional method
tests candidate action strings (noiseless) or performs best-arm identification
over strings (noisy). Learned representation does not improve the information
budget below. With a progress sensor, direct sequential coordinate tests solve
the same problem cheaply; this is not a feature-learning advantage.
For Astra L01's exact full-matrix interface, N25 already supplies a smaller
randomized output-only learner: max query dimension <=2m versus L01's larger
deterministic universal construction. Distinguish determinism from efficiency.

Construction
Fix horizon d and a hidden binary word w in {0,1}^d. An experiment resets,
chooses d binary actions A, receives only constant dummy observations until
the terminal step, then sees reward R. Let
  Pr_w(R=1 | A)=3/4 if A=w, and 1/4 otherwise.
All reward probabilities are strictly positive. One time-inhomogeneous
two-state model tracks 'prefix still correct' versus 'failed'; the correct
state transitions to failed on an incorrect action. A time-homogeneous
implementation uses d+2 states including stage and failure. Thus no enormous
hidden table is supplied. Reset, adaptive action choice, and randomized
policies are allowed, but no clone/condition-on-unobserved-state service.

Under fair independent logging actions, define trajectory law P_w(A,R).
Let P_0 have the same actions and reward Ber(1/4) for every A. At each cut
1<=t<=d, the prefix/future probability matrix has exactly two row types:
the unique correct prefix and all incorrect prefixes. Its rank is exactly
2 (including at t=d, where the suffix consists of R alone). Normalizing rows
does not change this. Therefore low probability-rank query-model results
apply to learning the LOGGING LAW, with their stated accuracy costs.

Exact distances and control objective
Only action A=w differs, of logging probability 2^(-d). Hence
  TV(P_w,P_0)=2^(-d-1),
  KL(P_0||P_w)=KL(P_w||P_0)=2^(-d) (log 3)/2.
Nevertheless optimum expected intervention reward is 3/4, while a policy
placing mass p on w has value 1/4+p/2. Achieving regret <1/4 forces p>1/2;
then the policy's modal action string identifies w. For an algorithm that
outputs a string, constant-value control is exactly word identification.
There is no contradiction with polynomial(1/epsilon) distribution learning:
epsilon must become exponential before its guarantee distinguishes the
relevant interventional event. Conditional completion sampling alone still
samples a rare successful suffix unless the full string is guessed.

Acquisition proof A: noiseless terminal feedback
Replace terminal reward by 1[A=w]. Before the first success, every response
is zero. Fix the learner's random seed. Its null transcript determines all
q tested strings; at most q hidden words yield a success. On the all-zero
branch its final output can identify at most one additional hidden word.
For uniform w, success <=(q+1)/2^d. Averaging seeds preserves the bound.
It is sharp: query q distinct strings, then guess one untested string.
Adaptive stopping with expected null budget C gives (C+1)/2^d by the same
null-path counting argument, provided the null procedure terminates.

Acquisition proof B: strictly positive noisy terminal feedback
Let N=2^d, k0=KL(Ber(1/4)||Ber(3/4))=(log 3)/2. Suppose an algorithm has
fixed budget q (or finite expected null budget C), and identifies each w
with probability >=1-delta. Under P_0 let p_w be its output probability for
w and T_w the number of episodes using action string w. Adaptive KL chain
rule gives KL(Law_0(transcript)||Law_w(transcript))=k0 E_0 T_w. Data processing
to the event 'output w' gives >=kl(p_w,1-delta), provided p_w<=1-delta.
For arbitrary p_w the exact lower bound is zero if p_w>1-delta; define
g(p)=kl(p,1-delta) for p<=1-delta, and g(p)=0 otherwise. This g is convex
(derivative meets zero at 1-delta). Jensen and sum p_w=1 yield
  k0 C >= sum_w g(p_w) >= N kl(1/N,1-delta),
for N>=2 and delta<1/2. Thus C=Omega(2^d log(1/delta)) for fixed confidence
away from 1/2. Count d*C physical action steps, not merely episodes.
The truncation g matters: binary KL monotonicity cannot be used on the wrong
side of its minimum. This proof does not assume a special learner.

Constructive repair and why it is not a breakthrough
Add a genuine physical progress sensor: after any action, independently with
probability eta it reveals whether the prefix is still correct, otherwise
returns a flagged erasure. Starting from the recovered prefix, append 0 and
repeat until revelation. A correct report fixes the next bit to 0; failure
fixes it to 1. Expected episodes d/eta; expected action steps
d(d+1)/(2eta). Truncating each test after ceil(log(d/delta)/[-log(1-eta)])
episodes bounds failure by delta (eta=1 needs one). This directly acquires
the needed information. It is also exactly the competent conventional
algorithm with that sensor. No assumed predictive basis is smuggled in.

Consequence for selecting the next foundational attack
Rank, a succinct model, excellent actual-path likelihood, and even a theorem
for conditional-sample distillation are not enough to justify autonomous
experimental optimization. The missing resource is an experimentally
available revealing/coverage mechanism, with its physical price. The actual
object-level task would be to construct such a mechanism for a useful class
that conventional adaptive experiments cannot already exploit as cheaply.
Merely proving another certificate or restating revealing assumptions does
not meet the user's goal. Do not extend this easy lock family as the main
campaign; the decisive transfer has failed and the failure is understood.

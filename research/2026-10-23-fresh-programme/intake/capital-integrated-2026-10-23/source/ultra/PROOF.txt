1. Exact contract and source boundary

The target is every entry of a real n by n drift A, with a supplied valid spectral
norm bound ||A||_2 <= B. At a calibrated damping gamma > B the system is
 dX=(A-gamma I)X dt + background noise + sqrt(2 gamma D_s) dW_s.
The background is additive, constant in state, and identical between a baseline
and its associated probes. W_s is independent of it. Full-state stationary
covariances are acquired, not given free. Independent additive readout noise may
have unknown covariance if unchanged between that baseline and those probes.
Its covariance, and the background contribution, cancel in C_s=Omega_s-Omega_0:
 (gamma I-A) C_s + C_s (gamma I-A)^T = 2 gamma D_s.                 (1)
This is a linear OU model, not a general nonlinear/hidden-state result.

2. A conditional expansion-to-identification theorem

Let H_1,...,H_d be real symmetric orthogonal involutions: H_s^T=H_s and H_s^2=I.
Let Phi(K)=d^{-1} sum_s H_s K H_s, restricted to real skew-symmetric K. Assume
 lambda_max(Phi|skew) <= 7/8.                                    (2)
A sufficient, slightly stronger certificate is spectral radius <=7/8. No full
quantum-channel gap on symmetric matrices is needed. Use 2d PSD designs
 D_{s,+}=I+H_s, D_{s,-}=I-H_s.
Their norms are <=2. Normalize stacked matrix outputs by (2d)^(-1/2), and define
 L_D(E)=(E D_t+D_t E^T)_t/sqrt(2d).

Write E=S+K with S symmetric and K skew. For a complementary pair the outputs are
 2S +/- ({S,H_s}+[K,H_s]).
Both terms in parentheses are symmetric. H_s^2=I gives the exact cancellation
 <{S,H_s},[K,H_s]>_F=0 by cyclicity of trace. Averaging the two signs then s gives
 ||L_D(E)||^2 = 4||S||^2 + avg_s ||{S,H_s}||^2
                           + avg_s ||[K,H_s]||^2.
The last average equals 2||K||^2-2<K,Phi(K)>, hence is >= ||K||^2/4 by (2).
Since S and K are Frobenius orthogonal, sigma_min(L_D)>=1/2.       (3)
This argument controls all real E, not just skew targets.

Set r=B/gamma<1. Equation (1), or its convergent integral solution, implies
 ||C_t||_2 <= 2/(1-r),  ||C_t-D_t||_2 <= 2r/(1-r).
Therefore ||L_C-L_D||_{F->stacked F} <=4r/(1-r), and
 sigma_min(L_C) >= 1/2-4r/(1-r).
In particular gamma>=17B gives sigma_min(L_C)>=1/4.               (4)
The exact covariance differences uniquely determine A by
 L_C(A)=2 gamma (C_t-D_t)_t/sqrt(2d).
For B=0 the target is already zero; the construction still requires gamma>0.

3. Finite, exact expansion certificates; no all-n theorem

Saved designs have d=8 and n=4,8,16,32. Each H_s is a signed perfect-matching
matrix, with exactly one nonzero +/-1 per row, zero diagonal, H_s^2=I.
On skew basis e_i e_j^T-e_j e_i^T, conjugation by H_s is a signed permutation.
Thus Phi=T/8 for a symmetric integer matrix T, a sum of eight signed permutation
matrices. The saved certificates verify
 ||T^k||_infinity <= 7^k.
Every eigenvalue mu of Phi then obeys |mu|^k<=||Phi^k||_infinity<=(7/8)^k.
This proves (2) using exact integer arithmetic, independently of numerical SVD.
The respective (n,k,max absolute row sum) are
 (4,1,4), (8,3,266), (16,4,2186), (32,5,16168).
The respective RHS 7^k are 7,343,2401,16807.
The generator's one fixed seed produced these four designs; no asymptotic random
matching theorem, uniform success probability or scalable family is claimed.
The checker uses int64 only while 8^k<2^63, and Python integers for the final
inequality. At every intermediate step entry/row absolute sums are <=8^k, so its
integer calculations cannot overflow. All H entries and involution properties
are checked. A fresh independent scientific proof review has NOT occurred.

4. Physical implementation and deterministic error contract

For a matched pair (i,j) carrying sign h, the block I+/-H equals v v^T with
v=e_i+/-h e_j. One shared independent scalar driver per pair realizes that block.
Thus each setting uses n/2 scalar drivers, n signed couplings and n/2 matched
edges. Total added coordinate variance is n at A=0; it is not an energy in joules.
These are classical covariance controls; no quantum hardware is implied.

Suppose max_t ||Chat_t-C_t||_2<=epsilon, RMS Frobenius design calibration error
<=xi, fitted residual is r_fit, and shat is a certified lower bound for
sigma_min(L_Chat). If shat>2epsilon, the source-interface perturbation argument gives
 ||Ahat-A||_F <= [r_fit+2epsilon||Ahat-gamma I||_F+2gamma xi]
                 /(shat-2epsilon).                             (5)
Proof: substitute Ahat into the true equations, bound the covariance-error terms
by 2epsilon||Ahat-gamma I||_F and design errors by 2gamma xi, and use
sigma_min(L_C)>=shat-2epsilon. A floating SVD alone is not a rigorous shat, and a
sample covariance is not accompanied by a confidence radius in these scripts.
Consequently (5) is a deterministic conditional bound, not a finite-shot guarantee.

5. Exact failure with common injection-gain uncertainty

If the actual injection is 2gamma c D_t for unknown common c>0, all covariance
differences solve F C_t+C_t F^T=2gamma c D_t, F=gamma I-A.
An estimator assuming gain one fits F'=F/c, namely
 A_alias=gamma I-(gamma I-A)/c.                                  (6)
It can have exactly zero residual. Unknown background diffusion can simultaneously
be divided by c to preserve baseline covariance; readout covariance can stay fixed.
For c=1.01, gamma=17, n=8, the saved exact-covariance test has both real drifts
inside ||A||_2<=1, but their Frobenius separation is 0.476135. The alias is algebraic;
near-zero floating residual is only a diagnostic. Increasing gamma amplifies this
calibration requirement approximately as gamma|c-1|sqrt(n).

6. Constructive repair: 19 total settings with one known damping increment

At gamma1 acquire baseline plus the 16 matched-noise settings, all with actual
injection 2gamma1 c D_t. Injectivity of L_C identifies Z=F1/c from
 Z C_t+C_t Z^T=2gamma1 D_t.
At gamma2!=gamma1 acquire one additional baseline and one nonzero reference probe
D_ref (an existing matched pattern suffices). Keep its noise amplitude identical:
2gamma1 c D_ref. Let its baseline-subtracted covariance be C2. Background/readout
covariances may differ across damping values, provided each local subtraction is
valid. Drift must change by precisely -(gamma2-gamma1)I, with known increment.
Then F2=cZ+(gamma2-gamma1)I and
 c [2gamma1 D_ref-Z C2-C2 Z^T]=2(gamma2-gamma1) C2.
Since c>0, D_ref!=0 and the stable covariance integral is nonzero, C2!=0. Hence
 c=2(gamma2-gamma1)||C2||_F^2
        /<2gamma1 D_ref-Z C2-C2 Z^T,C2>,                         (7)
 A=gamma1 I-cZ.
The denominator is nonzero by the preceding identity. This proves uniqueness,
not favorable statistical conditioning. An alternative joint linear system in
(n^2+1) unknowns A,c is
 A C_t+C_t A^T+2gamma1 c D_t=2gamma_j C_t,
where j is the damping level of that setting. This joint system is injective by
(7). It replaces an unknown common amplitude with a calibrated damping increment;
it does not eliminate all calibration obligations or identify arbitrary gains c_t.
The exact fresh dense-real test recovered c=1.03 and A with error <6e-14.

7. Statistical follow-through and retained failures

N=170000 independent synthetic snapshots per protocol, six repetitions, n=8:
16 noise settings+baseline gave RMS drift error 1.527330; recorded Gaussian mean
forcing gave 0.381155 using lower added stationary trace (7.07744 versus 8).
The full input-output costs differ: mean labels are reprogrammed every sample,
whereas noise uses 17 fixed batch regimes. Neither switching cost nor a hardware
platform has been acquired, so no end-to-end advantage follows in either direction.
N532 already contains a sharp local Fisher comparison favoring recorded means;
our new geometry does not evade it.

A competent diagonal bit-mask comparator uses 2ceil(log2 n) noise settings, with
ideal s0>=min(2,2/sqrt(ceil(log2 n))). At n=4,8,16,32 it needs 4,6,8,10 settings,
all fewer than our 16. Thus these finite cases establish no setting-count win.
At n=512, 8 diagonal binary masks necessarily repeat a coordinate word, giving an
exact invisible skew pair at A=0; this narrow diagonal obstruction says nothing
about continuous diagonal amplitudes, arbitrary interventions or mean controls.

The 19-setting repair at 190000 synthetic snapshots had RMS drift error 2.59783
and RMS gain error 0.05085, over six repeats. Its exact identifiability is not a
low-shot acquisition result. Noisily estimating a design matrix and then doing
ordinary least squares introduces errors-in-variables bias.
A subsequent matched-data diagnostic split each covariance regime into independent
halves. For corresponding linear systems M1 theta=b1 and M2 theta=b2, it used
 G=(M1^T M2+M2^T M1)/2, h=(M1^T b2+M2^T b1)/2, theta_hat=G^{-1}h.
Independence makes E[G theta_true-h]=0; it does NOT make the inverse estimator
unbiased or guarantee G positive. At a separately seeded real-drift fixture,
190000 snapshots, eight repeats, RMS drift errors were 3.79113 (ordinary fit) and
1.45110 (cross-fit), mean gain estimates 0.95503 and 1.02105 (truth 1.03).
This finite diagnostic motivates statistical work; it is not general superiority.

10. Additional finite-sample confidence construction (conservative)

For K acquired regimes, assume N independent Gaussian full-state snapshots per
regime, with sample covariance S_l (sample mean removed) and nu=N-1. For each regime
use vectors e_i and e_i+e_j, e_i-e_j (i<j): n^2 vectors total. For confidence alpha,
set delta=sqrt(8 log(2 K n^2/alpha)/nu), requiring delta<1.
For any fixed vector v, nu v^T S_l v/(v^T Sigma_l v) is chi-square(nu).
The elementary moment-generating-function Chernoff calculation gives
 P(|chi-square(nu)/nu-1|>delta) <=2 exp(-nu delta^2/8), 0<delta<1:
upper exponent nu[delta-log(1+delta)]/2 >=nu delta^2/8, lower exponent
nu[-delta-log(1-delta)]/2 >=nu delta^2/4.
A union bound over K n^2 vectors therefore provides simultaneous confidence >=1-alpha.
No independence between different quadratic forms is required.

On that event, diagonal errors are <=delta S_ii/(1-delta). Polarization of the
plus/minus vectors bounds every off-diagonal error by
 delta(S_ii+S_jj)/(2(1-delta)).
Consequently a fully data-observable conservative spectral radius is
 e_l = delta/(1-delta) sqrt([n sum_i S_ii^2+(tr S_l)^2]/2),
with ||S_l-Sigma_l||_2<=e_l. A baseline-subtracted covariance has error bound
 epsilon_t=e_probe+e_baseline. Shared-baseline correlations require no further
independence assumption because the confidence event is simultaneous. For unequal
N use the corresponding regime-specific delta with the same union allocation.

For the 19-setting gain repair, use h=gamma1 c so all unknown parameters (A,h)
have inverse-time units. Normalize the joint linear system by sqrt(J), J=17 probe
differences (16 at gamma1 and one at gamma2). Its last column is (2D_t)_t/sqrt(J),
its right-hand side (2gamma_j Chat_t)_t/sqrt(J). Set
 eta=2 sqrt(avg_t epsilon_t^2).
If shat is a CERTIFIED lower bound on the measured augmented operator's smallest
singular value and shat>eta, then simultaneous confidence >=1-alpha gives
 ||(Ahat-A,hhat-h)|| <=
 [r_fit+2 sqrt(avg_t epsilon_t^2 ||Ahat-gamma_j I||_F^2)]/(shat-eta).  (8)
Proof: the true augmented operator differs only in its A columns, by norm <=eta;
substitute the fitted parameters into the true equations as in (5). This theorem
is deliberately conservative. Gaussian iid acquisition, exact relative noise
shapes and exact damping increments remain assumptions; covariance model bias is
not covered. An ordinary floating SVD does not certify shat. If the inequality
fails, ABSTAIN. No interval proof or hardware acquisition is manufactured.

Executed confidence_check.py uses fresh raw Gaussian snapshots and this explicit
union radius. At 190000 total observations it abstains: the covariance uncertainty
exceeds the smallest measured joint singular value by a large margin. This closes
a narrow confidence construction, not the statistically efficient confidence-set
problem. Efficient covariance-aware bounds and actual physical acquisition remain
the most valuable continuation.

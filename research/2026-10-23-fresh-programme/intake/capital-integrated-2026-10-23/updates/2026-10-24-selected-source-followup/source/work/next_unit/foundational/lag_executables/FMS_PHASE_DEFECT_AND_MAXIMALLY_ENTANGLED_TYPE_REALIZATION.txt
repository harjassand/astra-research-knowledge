FMS common-phase defect and exact maximally-entangled type realization
=======================================================================

Scope
-----
This is an exact algebra check for the phase-modified FMS strategy and an
exact resource realization of its common-phase average. It is not a new
game theorem or an assertion that phase averaging preserves a pure-state
fine table. The source is Mančinska, [arXiv:2610.06512v1](https://arxiv.org/abs/2610.06512),
Section 3.2, Proposition 1, especially equations (12)--(15): the 5-dimensional state,
bridge bases, and FMS question-cell rules used below. The paper's displayed
perfect strategy is theta=0; the phase family and average are checked here.

1. Single-copy phase defect
--------------------------
Use the local basis consisting of the flag |0> and four core basis vectors
|j>, j=1,...,4, and define

    |psi_theta> = (|00> + exp(i theta) sqrt(2) sum_(j=1)^4 |jj>)/3.

This is normalized since (1+4*2)/9=1. In the FMS strategy, Alice's bridge
sign vector is

    |t_x^a> = (|0> + a |c_x>)/sqrt(2),

and Bob uses the conjugate of

    |u_y^b> = (|0> + b |r_y>)/sqrt(2),

where <c_x|r_y>=(-1)^(xy)/sqrt(2). With the same maximally-correlated
basis convention as Proposition 1, the joint amplitude is

    <t_x^a| D_theta |u_y^b>
       = (1 + exp(i theta) sqrt(2) ab <c_x|r_y>)/6
       = (1 + exp(i theta) ab (-1)^(xy))/6.

For a losing sign pair ab=-(-1)^(xy), this becomes

    (1-exp(i theta))/6,
    probability = |1-exp(i theta)|^2/36 = (1-cos(theta))/18.

There are exactly two losing sign pairs in each of the four frustrated
bridge cells T_x x U_y. Each of the 25 question pairs is uniform. The other
answer pairs in those cells win automatically. In every other cell, no
losing event gains nonzero amplitude from changing theta: the flag/core
sectors remain orthogonal; the uniform phase on the entire core multiplies
core-only amplitudes by a common phase; and the zero amplitudes enforcing
the MS and calibration support rules remain zero. The remaining cells are
the nine MS cells, two Alice-calibration cells, two Bob-calibration cells,
and eight free cells. Thus the total loss and win probabilities are exactly

    1-f_theta = (4/25) * 2 * (1-cos(theta))/18
              = 4(1-cos(theta))/225,
    f_theta = 1 - 4(1-cos(theta))/225.

This agrees with f_0=1. No expansion or numerical approximation is used.

2. Common-phase average over n copies
-------------------------------------
Take one common theta, uniform on [0,2 pi), across all n copies, and average
the density operator (not the state vector):

    rho_n = (1/(2 pi)) integral_0^(2 pi)
            |psi_theta>^{tensor n}<psi_theta|^{tensor n} d theta.

For a word alpha in {0,1,2,3,4}^n let its type a be the number of nonzero
core symbols. There are

    D_a = binom(n,a) 4^a

words of type a. Define the normalized maximally entangled vector on that
type support by

    |Phi_a> = D_a^(-1/2) sum_(alpha:type(alpha)=a) |alpha,alpha>.

Each word of type a has amplitude 3^(-n) 2^(a/2) exp(i a theta). Hence

    |psi_theta>^{tensor n}
       = sum_(a=0)^n exp(i a theta) sqrt(p_a) |Phi_a>,
    p_a = D_a 2^a / 9^n.

Since sum_a D_a 2^a = sum_a binom(n,a) 8^a = 9^n, the p_a sum to one.
Uniform phase averaging kills exactly the cross terms between distinct a,
so

    rho_n = sum_(a=0)^n p_a |Phi_a><Phi_a|.          (1)

For any fixed local fine POVMs M_o,N_v, the phase-averaged table is
Qbar_n(o,v)=Tr[(M_o tensor N_v) rho_n]; this is why matching rho_n's table
is the relevant implementation target.

This is a dephased mixed resource, not generally a pure maximally entangled
state and not the same thing as drawing an independent phase per copy.

3. Exact simulation of the averaged fine table by one maximally entangled
   state
--------------------------------------------------------------------------
Let S_a be the D_a-dimensional local span of the words of type a, with
projector Pi_a. Let {M_o} and {N_v} be the original local product PVMs for
the n-copy input questions and their complete fine outcomes. Compress them
to the type support:

    M_o^(a) = Pi_a M_o Pi_a restricted to S_a,
    N_v^(a) = Pi_a N_v Pi_a restricted to S_a.

These are valid POVMs: they are positive and sum to identity on S_a. Their
outcome labels are exactly the original fine answer labels. They need not
remain projective, since S_a need not reduce every original measurement.

Now use the single maximally entangled state of local rank 9^n on

    H_A = H_B = direct_sum_(a=0)^n (C^(D_a) tensor C^(2^a)),
    dim(H_A)=sum_a D_a 2^a=9^n,

namely

    |Phi_(9^n)> = 9^(-n/2) sum_a sum_(u=1)^D_a sum_(v=1)^(2^a)
                    |a,u,v>_A |a,u,v>_B.

Its local sector-a readouts agree with certainty and have probability
D_a 2^a/9^n=p_a. In sector a, run M_o^(a) tensor I_(2^a) and
N_v^(a) tensor I_(2^a). The sector state is
|Phi_(D_a)> tensor |Phi_(2^a)>, so the identity multiplicity factor
contributes no outcome dependence. The sector-a fine table is exactly

    <Phi_a| M_o tensor N_v |Phi_a>,

the same term appearing in (1). The direct-sum measurement is complete,
and the resulting untagged fine-outcome table is exactly the table obtained
from rho_n and the original product PVMs. This remains true even when the
original PVMs mix different type subspaces: compression keeps precisely
their diagonal type-block matrix elements, which are the only terms present
in rho_n.

The parties may first read the common sector a locally, map u to its type-a
word, and apply the compressed POVM; no communication is used. If they
retain a as an extra answer tag, forgetting that tag recovers the original
fine table exactly. Retaining the tag refines the table; it does not claim
the tagged output alphabet is identical to the original one.

This is an exact realization of the averaged table using one maximally
entangled state, not a claim that each fixed-theta pure strategy or the
coherent n-copy state is maximally entangled. The construction uses local
sector measurements and no outside nonmaximally entangled resource.

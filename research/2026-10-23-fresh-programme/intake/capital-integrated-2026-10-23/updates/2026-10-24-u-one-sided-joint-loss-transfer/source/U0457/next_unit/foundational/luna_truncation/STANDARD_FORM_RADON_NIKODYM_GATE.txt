STANDARD-FORM RADON-NIKODYM GATE FOR A COMMUTING MODEL
2026-10-24. Bounded independent operator check.

Scope
-----
This verifies the one-sided assemblage reconstruction in an arbitrary
standard-form von Neumann algebra, including the support completion and
the side on which the Radon-Nikodym effect acts. It does not establish a
source-specific entropy allocation or a resource bound. The final
payoff estimate uses the standard Araki-relative-entropy/fidelity
inequality, stated separately below.

Exact RN construction
---------------------
Let N act in standard form on H, with inner product linear in its second
argument. For a normal state rho, let xi_rho be its natural-cone vector,
so rho(n)=<xi_rho,n xi_rho>. Set K_rho=closure(N xi_rho). If tau is a
normal positive functional with 0<=tau<=rho, define on N xi_rho

  b(a xi_rho, c xi_rho) = tau(a* c).

This is well-defined: Cauchy-Schwarz for tau gives
|tau(a* c)|^2 <= tau(a* a) tau(c* c) <= rho(a* a)rho(c* c),
so a xi_rho=0 or c xi_rho=0 makes the form vanish. Also
0<=b(a xi,a xi)<=||a xi||^2. It therefore extends to a bounded
positive sesquilinear form on K_rho and yields a positive contraction
T_K on K_rho with b(u,v)=<u,T_K v>.

For n in N,
  b(a xi,n c xi)=tau(a* n c)=b(n* a xi,c xi).
The adjoint identity for the chosen inner-product convention implies
<u,T_K n v>=<u,n T_K v> on the dense N xi vectors, hence
T_K n=n T_K. K_rho is reducing for N, so its projection p_K lies in
N'. Extending T_K by zero on K_rho^perp gives T in N', 0<=T<=p_K<=I,
and
  tau(n)=b(xi_rho,n xi_rho)=<xi_rho,T n xi_rho>.

Thus the effect belongs to the commutant, the Alice side. This orientation
is important: putting the derivative in N generally fails to encode an
arbitrary subfunctional of rho by an Alice-local measurement.

If finitely many normal tau_a sum to rho, their derivatives T_a sum to
p_K on K_rho, by equality of the forms. Add I-p_K to a chosen default
outcome. The completed effects are a POVM in N' and still represent each
tau_a on xi_rho: the added term has zero expectation because
(I-p_K)xi_rho=0. The same support argument handles non-faithful rho;
no inverse or full-support assumption is needed.

Common-standard-form HJW lift
-----------------------------
For a finite input alphabet x, let tau_(a|x) be normal positive
functionals with sum_a tau_(a|x)=rho_x. Choose the standard form once for
N and use its natural-cone vector xi_(rho_x) for each rho_x. Applying
the construction separately to each x gives a complete Alice POVM
{T_(a|x)} in N'. For every Bob POVM {B_(b|y)} in N,

  <xi_(rho_x), T_(a|x) B_(b|y) xi_(rho_x)>
       = tau_(a|x)(B_(b|y)).

This is exact for all supported x. For a finite reference law nu, put
rhobar=sum_x nu(x)rho_x and use xi_rhobar as the actual shared resource,
chosen before fresh x,y. Use the same T_(a|x) and B_(b|y). Inputs
outside supp(nu) receive arbitrary complete Alice POVMs; this makes the
strategy defined on the whole alphabet. The flag/prefix version uses a
classical direct-sum standard form, with each branch resource selected
before its fresh inputs.

For any loss predicate, the operator
  L_xy=sum_{(a,b) losing at (x,y)} T_(a|x) B_(b|y)
obeys 0<=L_xy<=I: commuting positive factors make each summand positive,
and the sum over all (a,b) is
(sum_a T_(a|x))(sum_b B_(b|y))=I. Write d_x=||xi_(rho_x)-xi_rhobar||.
For each x,y, the square-root triangle inequality gives
sqrt(<xi_rhobar,L_xy xi_rhobar>) <=
sqrt(<xi_(rho_x),L_xy xi_(rho_x)>)+d_x,
since ||sqrt(L_xy)||<=1. Squaring, averaging over x,y, and applying
Cauchy-Schwarz yields

  loss_new <= alpha + 2 sqrt(alpha chi) + chi,
  chi = sum_x nu(x) D_A(rho_x || rhobar),

provided one uses the standard-form inequality
  ||xi_rho-xi_sigma||^2 = 2(1-F(rho,sigma))
       <= -2 log F(rho,sigma) <= D_A(rho||sigma).
Here F is the standard-form (root) fidelity and D_A is Araki relative
entropy, with natural logs. The exact RN/POVM reconstruction above is
independent of this entropy inequality; if the source proof does not
already establish the displayed Araki bound in its conventions, retain
the vector-distance version instead of invoking the chi bound.

What this closes / what it does not
-----------------------------------
It removes a finite-dimensional density-matrix restriction from the
one-sided HJW/RN gate for normal commuting models. It does not by itself
show that a particular event has small chi, that a fresh-input
factorization exists for a Bob-dependent selection, or that a
finite-dimensional approximation transfers a scalar criterion. Those
remain separate hypotheses/proofs.

Sequential quantum-memory source: CP domination audit
===================================================

Question audited
----------------
For a sequential Alice source with a D-dimensional carried memory C, complete
local instruments, and no use of emitted outputs except through C, does
resetting C before each checked interval T give

  tau_(alpha_T|X) <= D^(2 b(T)) tau0_(alpha_T|x_T)

as an order of full Bob functionals, with the reference independent of
X_outsideT? Here b(T) is the number of maximal contiguous checked intervals,
equivalently the number of incoming-memory reset sites. The answer is yes
under the stated assumptions, with a few interface conditions made explicit
below. This is an algebraic audit, not a repetition claim.

Source model and notation
-------------------------
Initial state rho_(C_0 A_1...A_n B) is arbitrary and independent of the
question strings. Each round i applies a complete instrument
  {Phi_(i,a_i)^(x_i): C_(i-1) A_i -> C_i}_a_i,
whose sum over a_i is CPTP and whose output memory C_i has dimension D.
Any retained classical control that can affect a later map is part of C_i.
The records a_i outside T are summed, not selected. Let T be decomposed into
maximal consecutive intervals I_1,...,I_b. Keep the full tuple alpha_T as
orthogonal classical output blocks. Define rho0's comparison process by
inserting at the incoming memory of every I_j the channel
  R_C(Z_CR) = (I_C/D) tensor Tr_C Z_CR,
where R denotes *all* other systems: previous checked output records,
unprocessed A ports, Bob, and any analysis reference. Run the same checked
maps and sum the same outside-T complete instruments. This defines tau0;
it is a full conditional Bob-state functional, not just a scalar success
probability.

The single-cut CP inequality
----------------------------
With unnormalized Choi matrices,
  J(id_C)=|Omega><Omega|,  |Omega>=sum_j |jj>,
  J(R_C)=I_C tensor I_C / D.
The rank-one operator |Omega><Omega| has top eigenvalue D, so
  J(id_C) <= D^2 J(R_C),
and therefore id_C <= D^2 R_C in completely positive map order.
The order is complete: it remains valid after tensoring the identity on
an arbitrary reference, including all unprocessed A ports, Bob, old output
registers, and an entangled purification. Thus at one reset site, for every
positive input Z and every downstream CP map F,
  F o id_C (Z) <= D^2 F o R_C (Z).
This is Loewner order on the entire downstream output, not only an equality
or inequality of traces.

Apply this to the sequential process
------------------------------------
Fix X and one alpha_T block. The map from the incoming memory at a checked
interval to the full final output is CP: checked outcomes are fixed to that
block, outside-T outcomes are summed, and every instrument component is CP.
Insert id_C <= D^2 R_C at the incoming memory of I_1, retain the positive
operator difference through every later CP map, then repeat at I_2,...,I_b.
This gives, block by block,
  sigma_(alpha_T|X) <= D^(2b) sigma0_(alpha_T|X),
where sigma denotes the subnormalized joint output on the full Bob system
(and may retain further comparison registers). Evaluating against I_A tensor
any positive Bob operator B gives
  tau_(alpha_T|X)(B) <= D^(2b) tau0_(alpha_T|X)(B).
Summing or coarse-graining alpha_T preserves the order, but the proof gives
the stronger full fine-block order. Bob may hold/process the entire Y string:
his fixed Y-dependent CP map is simply a downstream positive map, so the
order is preserved for every Y and for the direct-sum full Bob functional.

Why the reset reference loses X outside T
----------------------------------------
Before the first checked interval, all Alice maps are complete and their
outputs are summed. They act only on C and already visited A systems. A
trace-preserving local map cannot change the reduced state of untouched
A_ports tensor B. Applying R_C then discards all correlations with the
incoming C and leaves I_C/D tensor that unchanged untouched-port/B marginal.
So the first reference interval depends on x in I_1, not on earlier X.

Between checked intervals, condition on the already retained checked labels
alpha_(T before the gap). The gap maps still form a local CPTP map when their
own emitted outputs are summed. After tracing the gap systems and the old C,
the reduced state on future untouched A ports tensor B is unchanged by that
map, even in this subnormalized checked-label block. The next R_C traces the
possibly input-dependent gap memory and replaces it by I_C/D. Thus the
reference state entering the next checked interval depends on previous
checked inputs/labels and the untouched-port/B marginal, but not on the gap
questions. Iterating proves tau0_(alpha_T|X)=tau0_(alpha_T|x_T).
After the last interval, the remaining complete Alice maps cannot change
Bob's reduced functional in a fixed alpha_T block when their outputs are
summed. This removes dependence on later X as well.

The claim needs the stated memory boundary
------------------------------------------
The dimension D must include every retained Alice-side register that can
influence a later instrument, including classical control. If an emitted
answer is also available to future rounds through an uncounted external
history, resetting C does not cut that path. For example, with D=1, Alice
could store x_1 in an external classical register and output alpha_2=x_1;
then T={2} has dependence on X_outsideT after the C reset. This is excluded
by the supplied “no reuse except via C” condition; if reuse is allowed, its
storage must be included in the dimension bound.

Likewise, outside-T maps must be complete when their outcomes are omitted.
If one postselects on an outside outcome, the resulting subchannel can steer
Bob/future ports and can carry outside-question dependence through a reset
of C alone. Finally, the comparison tau0 must be the actual reset-inserted
output functional on the same Bob algebra and with the same alpha_T block
labels. A scalar/coarse table match by itself does not imply full Bob
functional order; CP composition gives the required order only because the
full reference systems and fine blocks are retained through the cut proof.

Verdict
-------
No counterexample arises from arbitrary entanglement with future ports or
from later complete untested maps: trace preservation and the reference-safe
CP order handle both. With b(T) explicitly defined as the number of memory
reset sites, the D^(2b(T)) factor and full-Bob-functional order are valid.
The meaningful failure modes are an uncounted retained history path,
postselection among outside-T outcomes, or defining tau0 only after a coarse
probability match rather than as the full reset-inserted functional.

ASTRA — INDEPENDENT REVIEW OF THE ADAPTIVE TERMINAL OPERATION
25 October 2026

Reviewed operation
==================
The previously acquired 256 positive task weights are frozen. After each
complete round of six actual local weak probes, the observer either requests
another round, stops because remaining perfect-syndrome value is <=1/200, or
stops at the35-round cap. No unperformed marks are sampled in the executed
generator. The physical quantum memory continues from the preceding L15 run.

Governing code:
  ../bootstrap/adaptive_terminal_observer.py
  ../bootstrap/run_adaptive_terminal_transmission.py
  ../bootstrap/verify_adaptive_terminal.py

1. Positive update and actual acquisition boundary
==================================================
The generator obtains the latent syndrome only on its plant side. The sole
argument passed to receive_round is the requested round's six actual signs.
The observer's stop test occurs before the next signs are drawn. Resetting
the observer clears its local counters/posterior to the same acquired model;
it does not reset the physical channel memory.

For a sign mask m and latent syndrome u, one complete round contributes
4^(6-Hamming(m,u))/5^6. The code multiplies by the integer numerator, leaving
the common denominator implicit. This is the correct eta=3/5 likelihood.
The four logical-error weights for fixed u receive the same factor, so the
per-u best logical repair can be computed once from the acquired model.

The stopping gap is exactly
  G(w)=[sum_u max_s Wpost(u,s)-max_s sum_u Wpost(u,s)]/sum Wpost.
It measures modeled value of perfect information about the terminal syndrome,
not total error and not a calibrated physical-memory posterior error.

A targeted independent check reconstructed all posterior entries from raw
word counts with the unshifted integer likelihood on seven actual calls,
including the unique capped call. It checked77 actual prefixes. Integer
posteriors, normalizers, gaps, stopping times and final actions agreed. This
was not a rerun of the whole native model.

2. Capping: expectation is essential
====================================
For any fixed positive weight model, couple the terminal QND experiment to
a full35-round observation table for proof purposes. Unperformed signs need
not be drawn by the apparatus or accessed by the observer. On an early-stop
leaf G<=epsilon. On a capped leaf G=G35>=0. Therefore

  E[G_stop] <= epsilon + E[G35].

The full-record MAP decision is no worse on average than estimating each
latent syndrome bit by35-round majority and then using the perfect-syndrome
repair. The latter can disagree with the perfect-syndrome repair only if at
least one bit estimate is wrong. Consequently

  E[G_stop] <= epsilon + 6*t35
            = 0.005205369524250406... .

This is excess Bayes risk relative to perfect syndrome for that fixed acquired
model. It is not a uniform per-leaf gap claim or a guarantee about future
physical memory outside the model. The executed unique capped leaf has
G=0.3334776059009501. Preserving that value is necessary and does not contradict
the expectation theorem. All noncap leaves pass the exact rational gap test.

The proof does not certify optimal probe scheduling. Its fair whole rounds
avoid the demonstrated parity trap in which every individual first probe has
zero one-step value while joint information has positive task value.

3. Physical schedule
=====================
A round means six actual local probes with the already supplied meter and
routing resources. With one meter these are six serial uses; concurrent lanes
require previously supplied concurrent meters. Calling the group one round
does not acquire a new parallel interface. The original full schedule is
reserved, including routing and feedback latency, and unused measurement
intervals are isolated padding. No shortened elapsed-time claim follows.

All adaptive actions are terminal local measurement and final local Pauli
feedback. There is no subsequent ancillary interaction with the native memory
before discard, and the controller cannot use the current outer frame key,
axis, or secret role. Thus the outer wrapper still treats the whole operation
as one raw macro with received internal flags, including the stopping time.

An equally informed conventional active Bayesian controller can implement the
same update and stopping rule.

5. Source correction identified
================================
The initial saved adaptive protocol inherited changed_operation describing
exactly15 probes from its predecessor. This stale metadata was reported to
its owning author for correction in both generation code and the saved JSON.
The actual sampling and replay code already implements adaptive rounds.

No substantive implementation error was found. The remaining obligations are
the explicit terminal-isolation and timing premises, the acquired-model scope
of the expectation bound, and the separate accepted-output integrity statement.

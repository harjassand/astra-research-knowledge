ASTRA — INDEPENDENT REVIEW OF THE ACTUAL SOFT-READOUT OPERATION
25 October 2026

Scope
=====
This is a targeted review of the changed physical observation kernel and
received-only controller in communication/run_soft_transmission.py and
communication/soft_record_observer.py. It does not rerun the complete native
model or promote model diagnostics to experimental evidence. The earlier
compiled-encoder, positive-composition, and quantum-transfer reviews remain
governing for those unchanged parts.

1. The kernel change is legitimate for this stated operation
==========================================================
After inverse decoding, the six measured auxiliaries have a simultaneous
product eigenbasis |u>, u in {0,1}^6, with the specified X or Z basis at each
site. For any joint state with output and continuing quantum memory, write
its auxiliary blocks rho_uv. A local weak word w multiplies block rho_uv by
a diagonal amplitude k_u(w) k_v(w)*. The actual auxiliary trace removes every
u!=v block. The remaining joint instrument is therefore

  J_w(rho)=sum_u L_u(w) rho_uu,
  L_u(w)=|k_u(w)|^2.

This identity is valid without a supplied classical state of the memory.
Changing only the terminal word length changes L_u, while the pre-readout
CP effects rho -> rho_uu remain the same. No auxiliary reinteraction or
record-controlled memory interaction may occur before discard. Padding the
shorter measurement by isolated idle time preserves the declared schedule;
the executed model evolves its memory only at forward-carrier interactions.
The operation saves probes, not elapsed storage time.

The code first inverts the old L35 majority BSC in all six coordinates, then
clips, normalizes, and quantizes 256 latent (u,s) task weights. It does not
reuse old noisy-majority weights as though they were latent weights. Those
positive weights are calibration-history quantities, not a learned quantum
memory state or a promised future stationary distribution.

2. Exact likelihood sign and quantization
========================================
For eta=3/5 and a length-L word containing k negative marks,

  Pr(w|u=0)=4^(L-k)/5^L,
  Pr(w|u=1)=4^k/5^L.

For all six words, the unnormalized integer score for output repair s is

  Score_s=sum_u W_(u,s) 4^[sum_i ((1-u_i)(L-k_i)+u_i k_i)].

The implementation uses d_i=2k_i-L and the equivalent common rescaling

  Score'_s=sum_u W_(u,s) 2^[ -2 sum_(d_i<0) d_i
                                      +2 sum_i u_i d_i ].

Every exponent is nonnegative. The rescaling is independent of u and s,
so comparisons and ties are exact Python-integer operations. Binomial count
multiplicities are common to the candidate latent states for a fixed count
tuple and do not affect the repair argmax. Context bits and the four Pauli
labels use the same little-endian convention as the previous controller.

Eleven targeted count tuples, including extremal, mixed, and actually received
rows, were independently evaluated with the unshifted 4-power expression and
all choices matched. The acquired numerators sum to 2^24 and each observed
numerator fits within 24 bits. This checks the actual representation; a
generic all-mass-on-one-coordinate representation would need a separate
encoding convention for the endpoint numerator 2^24.

3. Actual operation, history, and information boundary
=====================================================
The new run calls sample_macro(..., read_length=15). Preparations remain L35
and all actual outer audits remain L35. The new stored memory_before array
equals the previous memory_after_validation array exactly. No reset of the
physical quantum memory was inserted. All recorded inner words fit in 15 bits.

The fitting and repair modules import no native noise model and read no
hidden logical errors, branch labels, or memory state. The only fitting input
is the previous received training record and declared weak-instrument
constants. The new received record contains only axis, pre/post words, six
syndrome words, applied repair, secret-slot positions after use, and acceptance.
Hidden model variables are kept in separate validation files. Reordering
generation of outer roles/axes after the Pauli-error path is valid only for
the already framed input-independent model, as the code explicitly states.

The compared coarse policy is the exact majority-kernel MAP rule using the
same acquired weights and the same L15 instrument. This is the appropriate
strong conventional competitor. In this plant the final output Pauli does
not feed back into the continuing memory, so the stored same-history action
comparisons are valid; they are not general changed-history simulations.

5. Independent check of the received-only comparison
====================================================
The bootstrap paired-policy theorem and certify_fresh_soft_gain.py use the
actual applied fine repair to undo its known character in the outer score.
Their statistic Y=(chi_fine-chi_coarse) z_raw/2 therefore has conditional mean
2*gamma/3 times the coarse-minus-fine one-use risk. The code excludes every
payload slot and includes all audit slots regardless of packet acceptance.
It does not select only favorable accepted records.

For |lambda|<=1/2, exp(lambda*y-lambda^2*y^2)<=1+lambda*y on |y|<=1,
giving the stated nonnegative-supermartingale bound. A union over the eight
fixed lambda values permits the reported selection. The actual received
statistics N=32,256, S=273 and Q=387 give the displayed one-sided 99% lower
mean-gain bound 0.00795998609507325. The unrounded formula and exact gamma
govern; this floating display is not an interval-arithmetic certificate.

The claim concerns the mean predictable one-use risk difference along the
actual audited histories. It is not a gain guarantee for each delivered
payload, the postselected payload population, or arbitrary future memory.
No iid or native-model premise enters this comparison. The separate outer
accepted-output theorem remains responsible for delivered-output integrity.

Conclusion
==========
No substantive implementation error was found in the changed kernel,
likelihood, acquisition boundary, continued-memory state, or operation counts.
The useful new consequence is an actually executed reduction of local weak
probes with a received-record certificate of a positive task-risk gain over
the equally informed coarse controller. Its stated time and conditional
accuracy limitations are essential parts of that consequence.

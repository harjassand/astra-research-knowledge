SHARED-LABEL DILATION AND BRANCH RESOURCE CHECK
2026-10-24. Scope: SHARED_LABEL_PRIVATE_RELATION_DRAFT.txt, Sections 2-4.

The displayed Naimark unitary is valid. With V:H->H^m an isometry and
P=VV*, the block matrix U=[[V,I-P],[0,V*]] maps H direct-sum H^m to
H^m direct-sum H. Since V*V=I, V*(I-P)=0, and P is a projection,
U*U=UU*=I. Its entries lie in the finite matrix amplification of the
original local von Neumann algebra when the POVM effects do. Embedding H
as the first input summand and assigning the final output summand to a
default outcome gives a PVM whose compression to H is exactly E_a.
Question-dependent U_x are allowed: each input selects one PVM, and no
commutation between Alice's different settings is required. In the
commuting model, separate private ancillas for the two parties preserve
cross-party commutation.

The stated finite-state branch Schmidt-rank bound also holds. Local
Naimark ancillas start in product states. Applying the local projector
P_l^{x0} to a pure bipartite vector cannot increase its Schmidt rank;
adjoining |l>_A|l>_B to the normalized branch does not change it. The
dephased shared-label resource is explicitly a mixture of these branches,
so its Schmidt number is at most the input Schmidt rank. For a mixed
bounded-Schmidt-number strategy, choose a high-value pure component from
a Schmidt-number-bounded decomposition before applying the argument.

One wording caveat: “copy the mathematical label isometrically into two
local registers” must not be read as a deterministic product-channel
operation on the original resource. Starting with no correlated flag,
Alice cannot locally copy her measurement outcome into Bob's register
without communication. This does not invalidate the value conversion:
the proof may choose zeta_0 as a new, valid pre-input shared resource
(or use shared randomness over the valid branch states eta_l). It should
describe that as resource replacement/selection, not as local generation
of the shared flag from eta. The resource is unrestricted except for the
explicit Schmidt-number claim, which the dephased branch ensemble meets.

The losing-vector estimate has the claimed linear dependence after
squaring. For each (x,y), sqrt(M_xy) is a contraction, and the same
controlled local default rule defines M_xy on both comparison vectors.
Minkowski on the direct sum over product-uniform (x,y) gives
  sqrt(delta_candidate) <= sqrt(E_xy <zeta_x,M_xy zeta_x>)
                           + sqrt(E_xy ||zeta_0-zeta_x||^2)
                         <= sqrt(delta)+sqrt(8e).
With e<=delta this is (1+sqrt(8))^2 delta=(9+4sqrt(2))delta.
No extra factor comes from the Naimark extension or the default outcomes.

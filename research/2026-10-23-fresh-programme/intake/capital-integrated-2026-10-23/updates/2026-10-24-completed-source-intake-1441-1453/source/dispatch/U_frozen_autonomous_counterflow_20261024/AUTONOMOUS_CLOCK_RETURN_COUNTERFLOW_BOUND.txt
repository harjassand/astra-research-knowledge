1. Actual operation and resource question
----------------------------------------
On an N-cell periodic spin chain, each cell contains equal-dimensional data
rails A and B (dimension d>=2), and a clock rail C (dimension q). The target
coherent data unitary is
  beta = S_A tensor S_B^{-1},
where S moves one fine cell right. The two chiral indices cancel. Two
externally scheduled SWAP layers implement beta exactly: first swap A_i
with B_i at every cell, then swap B_i with A_(i+1). This is the strong
scheduled local-control comparator, not a hard target merely because its
combined index is one.

The missing resource question is whether one STATIC local Hamiltonian can
perform this coherent data operation while returning a full-rank distributed
clock's complete classical label records. This differs from returning only
the clock marginal. A diagonal phase on the clock may return all labels;
arbitrary changes inside a degenerate thermal eigenspace need not do so.

We give a finite quantitative obstruction, with an explicit global coherent
data metric and a local clock-record metric on the SAME input preparation.
It is not a clock construction or a data-channel certificate obtained from
classical tags alone. Pure/coherent rank-deficient clocks, centralized
nonlocal clocks, externally scheduled controls, and small wrapping rings
are not excluded by this result.

2. Literal finite model and metrics
-----------------------------------
Let
  H = sum_i h_i + sum_i h_(i,i+1),
  ||h_i||op <= J,  ||h_(i,i+1)||op <= J,
  U = exp(-iHT/hbar),  u=JT/hbar.
Each h term acts on the WHOLE cell(s), including their clock degrees of
freedom. There is one aggregate term per site and one per bond; a hidden
multiplicity of individually J-bounded terms is not allowed. All clock
onsite energies and data-clock couplings are included. Thus ||H||op<=2NJ.
There is no bath, postselection, label-dependent feedback, or outside pulse
schedule during T. The same fixed H acts in all metric experiments.

Prepare a known product clock state tau_C= tensor_i tau_i, diagonal in the
declared local label bases. These may be chosen as the local eigenbases.
Every tau_i is strictly positive. Write K=q^N and
  kappa = K lambda_min(tau_C)
        = product_i [q lambda_min(tau_i)] > 0.                 (1)
If tau_i>=p_* I, then kappa>=(q p_*)^N. For the product trace, kappa=1.
Copying all clock labels to uncoupled reference registers leaves this clock
marginal unchanged. A coherent tau in a different tag basis would be
dephased by copying and is not silently identified with this preparation.

Let D=d^(2N) be the total data dimension. With tau_C as the environment,
let E_U be U's reduced data channel. The data error is the GLOBAL Choi
entanglement infidelity
  epsilon_D = 1 - <Phi_beta|(E_U tensor id)(Phi)|Phi_beta>,     (2)
where Phi is a normalized maximally entangled data/reference state and
|Phi_beta>=(beta tensor I)|Phi>. It is not a per-site classical error.

For the clock tests, prepare product-tracial data, the SAME tau_C, and
copies of its input labels. Let e_i be the TOTAL joint probability that
the output C_i label differs from its copied input label. Sum over the
input labels with their actual tau_i probabilities. Conditional errors or
per-label joint masses must be converted to this total before using e_i.
References do not couple to H. The full-string mismatch E_C is a
mathematical joint event obeying E_C<=sum_i e_i.

All Hilbert--Schmidt norms below are normalized: ||X||2^2=Tr(X^dagger X)/(DK)
on data+clock, and ||B||2,C^2=Tr_C(B^dagger B)/K on the clock alone.

Define
  ell=ceil[100(1+u)],
  c_(d^2)=[sqrt(3-2/d^2)-1]^2 > 1/4.
Require N>=32ell+1, so the imported local-time witness fits in a proper
nonwrapping arc. This also ensures N>16 for the three-step projection below.

CLAIM under these assumptions:
  epsilon_D + sum_i e_i
    >= kappa c_(d^2) / [224 ell (1+12Nu)^2]
    >= kappa c_(d^2) / [22624 (1+u)(1+12Nu)^2].               (3)

3. From data coherence and label return to a diagonal product target
--------------------------------------------------------------------
Set W=(beta^dagger tensor I)U and B=Tr_data(W)/D. Normalized partial trace
is unital completely positive, so B is a contraction. The Kraus formula
for (2), in the same diagonal clock preparation, gives exactly
  1-epsilon_D = Tr_C(tau_C B^dagger B).
Since tau_C>=kappa I/K and I-B^dagger B>=0,
  1-||B||2,C^2 <= epsilon_D/kappa.
The normalized conditional expectation is an orthogonal HS projection, so
  ||W-I tensor B||2^2=1-||B||2,C^2.
Complete the polar partial isometry of B to a clock unitary V. Singular
values in [0,1] imply ||B-V||2,C^2<=1-||B||2,C^2. The two preceding error
terms are orthogonal, giving
  delta^2 := ||U-beta tensor V||2^2 <= 2 epsilon_D/kappa.      (4)

Let P_C denote pinching onto the COMPLETE clock product-label algebra,
acting on an operator as sum_c (I tensor |c><c|)X(I tensor |c><c|).
Under tracial data and tracial clock labels,
  ||U-P_C(U)||2^2
is exactly the full-string clock mismatch. The input floor and union bound
therefore give
  r^2 := ||U-P_C(U)||2^2 <= (sum_i e_i)/kappa.                (5)
Because I-P_C is an HS contraction,
  s := ||V-P_C(V)||2,C <= delta+r.
Polarize each diagonal entry of P_C(V) to a unit phase (arbitrary if zero),
obtaining a possibly GLOBAL diagonal unitary D_C. Orthogonality and
|V_cc|<=1 imply ||V-D_C||2,C^2<=2s^2. Thus, for
  Z=beta tensor D_C,  zeta=||U-Z||2,
  zeta <= (2+sqrt2)sqrt(epsilon_D/kappa)
                         +sqrt2 sqrt((sum_i e_i)/kappa),
  zeta^2 <= 14 (epsilon_D+sum_i e_i)/kappa.                  (6)
No locality of D_C is asserted or needed.

4. Autonomy converts approximate return into small mixed-rail coupling
-----------------------------------------------------------------------
Choose tensor-product operator bases that separate identity from traceless
operators on each A/B cell and use offdiagonal matrix units plus a diagonal
traceless basis on C. Let Pi_mix be the normalized-HS orthogonal projection
onto canonical strings of ring diameter at most one that touch at least
two of the rails A,B,C. Then H_mix=Pi_mix(H) is exactly H's mixed-rail part.

The anchored-core observation gives
  Pi_mix[Z^3 H Z^{-3}]=0.                                   (7)
Indeed, a canonical A core moves right three cells and a B core moves left
three. An originally range-one A--B string then has core separation at
least five. A diagonal C factor is fixed by D_C. For an offdiagonal C
matrix unit with changed labels on S, diagonal conjugation has the form
  D_C^3 E_(ab,S) D_C^{-3}=E_(ab,S) F(C_diagonal).
The dressing F may be global, but every changed-label core remains
nontrivial at its original physical C site. Thus a mixed data--clock
string has a shifted data core and an anchored clock core at distance at
least two. Diagonal dressing cannot erase an offdiagonal core. Pure-rail
terms stay on their rail. None of these terms can project onto a short
mixed-rail string. Orthogonality prevents cancellation from changing this
zero projection. N>16 excludes wraparound of all separations used here.

Static autonomy is load-bearing: U^3 H U^{-3}=H. Telescoping and unitary
invariance give ||U^3-Z^3||2<=3zeta. Hence
  ||H_mix||2
    <= ||H-Z^3 H Z^{-3}||2
    <= 6||H||op zeta <=12NJ zeta.                           (8)
This uses no logarithm branch, total infinite Hamiltonian, or strict QCA
claim for the actual Hamiltonian evolution.

Let H_sep=H-H_mix. It is the sum of three rail-only NN Hamiltonians and a
scalar. Each rail Hamiltonian can be formed by normalized partial trace
of the original site/bond terms over the other rails. These maps are
operator-norm contractions, so each induced A or B site/bond is bounded
by J. The triple-counted scalar is removed as one global scalar and has
no dynamics or local-strength consequence. In particular the A-rail
Hamiltonian H_A obeys the SAME aggregate NN-bond bound J.

Duhamel in normalized HS, with unitary factors on each side, gives
  ||U-exp(-iH_sep T/hbar)||2 <= (T/hbar)||H_mix||2.
Write U_sep, up to a scalar phase, as U_A tensor U_B tensor U_C. Equations
(6),(8) imply
  zeta_sep := ||U_sep-Z||2 <= (1+12Nu)zeta.                 (9)

5. A separated rail must pay the frozen finite-time translation error
-----------------------------------------------------------------------
Normalized trace factorizes. Put
  z_A=tr_A(U_A^dagger S_A),
  z_B=tr_B(U_B^dagger S_B^{-1}),
  z_C=tr_C(U_C^dagger D_C).
Absorb the harmless scalar phase into U_C. Since
  Re(z_A z_B z_C)=1-zeta_sep^2/2
and each factor has modulus <=1, some phase omega satisfies
  ||U_A-omega S_A||2,A^2 <= zeta_sep^2.                    (10)
If zeta_sep^2>=2 the assertion is trivial; otherwise use
|z_A|>=1-zeta_sep^2/2 and the phase minimizing the HS distance.

For a tracial A input basis string s and any output site i, let Q_(i,s)
be the projector onto labels different from the target shifted label.
It annihilates S_A|s>, so
  ||Q_(i,s)U_A|s>||^2
    <= ||(U_A-omega S_A)|s>||^2.
Averaging s yields every local shift-tag mismatch

with no Hilbert-dimension or label-count factor.

6. Consequence and what it does not establish
----------------------------------------------
For N chosen proportional to 1+u with a sufficiently large fixed coefficient
to fit the witness, (3) gives
  epsilon_D+sum_i e_i = Omega[kappa/(1+u)^5].
Since epsilon_D+sum_i e_i <= (N+1)max{epsilon_D,max_i e_i},
  max{epsilon_D,max_i e_i} = Omega[kappa/(1+u)^6].           (13)
For maximally mixed product clocks kappa=1, this is a polynomial joint
accuracy/disturbance obstruction to a STATIC NN implementation. For biased
full-rank clocks the explicit global floor kappa may decay exponentially
with N. It is not a dimension-free bound from a merely local p_*>0 promise.
For a rank-deficient prepared clock, kappa=0 and this proof says nothing.
No optimal exponent, matching autonomous upper, clock-energy lower bound,
or practical acquisition cost follows from (13).

The distinction from scheduled SWAPs is substantive: the scheduled drive
need not commute with the final beta tensor D_C, so (8) fails. The bound
therefore prices a specific autonomous return contract rather than the
ordinary combined QCA index, which is already trivial. Complete clock
records are essential. Same marginal thermal state alone is insufficient,
and the local clock tests do not certify the global coherent metric (2).

energy range, and abstract shared-clock/system interaction do not impose
the distributed NN, full-rank same-basis record contract used here. Their
autonomous upper is a serious incumbent, not evidence that arbitrary
autonomous gates require appreciable disturbance in every model.

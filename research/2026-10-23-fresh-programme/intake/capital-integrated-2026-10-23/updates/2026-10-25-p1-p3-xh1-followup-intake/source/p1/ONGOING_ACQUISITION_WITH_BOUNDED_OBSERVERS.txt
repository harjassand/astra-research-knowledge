MAIN RETURN
===========
The continuation now supplies an explicit regime in which an observer can
continue receiving informative, phase-sensitive marks and applying interacting
controls while keeping both its state coordinates and their bit precision
bounded in elapsed time. The regime is a deliberately specified physical
protocol, not a solution for an unrestricted unknown nonlinear environment.

Two operations do different jobs. Actual local measure-and-prepare readouts
bound the size of acquired correlation blocks. Private full-rank noise makes
positive numerical approximation errors decay even under continuing marked
observation. Their combination has a same-record, all-history, positive
finite-output theorem. Ordinary independently acting onsite noise suffices;
there is no need for a single simultaneous reset of the whole many-body state.

At fixed maximum block size B and local dimension d, the observer stores
O(N d^(2B) log(N/epsilon)) state bits, with explicit constants, for global
current-state trace tolerance epsilon on N sites. Partition labels, the
controller, supplied model, arithmetic work and physical interventions are
charged separately. The theorem is exponential in B. It changes the physical
protocol when a joining interaction would exceed B, so it must not be called
an accurate simulator of the original uncut experiment.

This is a substantive extension of the conditional-lifetime principle:
retirement can occur while rich acquisition remains active. It is also a
use of established filtering, cone-contraction, measure-and-prepare and
cluster-simulation mathematics. No priority claim or exclusive advantage
over conventional observers is established.

3. A GEOMETRY IN WHICH ACQUISITION DOES NOT AMPLIFY OLD ERROR
============================================================
For comparable nonzero positive operators define the Hilbert projective
distance
  h(X,Y)=log(M/m),  mY <= X <= MY,
with M the smallest upper multiplier and m the largest lower multiplier.
It is invariant under positive scalar normalization. Every positive linear
map, including a selected CP measurement branch, is nonexpansive in h:
apply the same map to both order inequalities. Comparable inputs have
compatible nonzero output supports on every supported branch.

For normalized density matrices,
  D_tr(X,Y) <= tanh[h(X,Y)/4] <= h(X,Y)/4.

These are established results, not a newly discovered metric. In particular,
projective filtering is prior work in Le Gland--Oudjane (2004), and quantum
observer applications appear in Bonnabel--Astolfi--Sepulchre (2011).
Reeb--Kastoryano--Wolf (2011) provide the quantum cone and trace bounds.

Consider any acquired marked instrument, any same-record CPTP control, then
the actual PRIVATE physical refresh
  E(X)=(1-r)G(X)+r tau Tr X,    tau>0, 0<r<1.
The refresh indicator and discarded environment are not available later.
Put a=r lambda_min(tau), c=1+(1-r)/a, and
  q=(c-1)/(c+1)=(1-r)/(1-r+2a)<1.
The refresh has projective diameter at most2log c, so Birkhoff contraction
gives q. The entire acquired update therefore obeys
  h_next <= q h_old
for EVERY supported received mark, without a lower bound on that particular
mark's probability. Full-rank refresh is the substantive physical premise.

An invertible single-Kraus weak measurement can be informative and an
isometry of this metric. It keeps changing the posterior; it does not
increase relative approximation error. Private noise supplies strict decay.
For maximally mixed reset on dimension D, q=D(1-r)/(D(1-r)+2r).

The same mechanism has a continuous-time version for finite dimension:
private depolarizing generator gamma(Tr(rho) I/D-rho) gives at least the
projective decay rate2gamma/D under arbitrary interleaved acquired branches
and common Hamiltonian controls. A bounded-model positive product limit
covers concurrent evolution. This is a sufficient noise rate, not a claim
about the original unbounded bosonic generator.

4. ACTUAL POSITIVE FINITE-BIT STATE, NOT A FORMAL POSTERIOR
========================================================
Store the state immediately after refresh, where C>=aI. Round the real
Hermitian coordinates of C to mesh delta=2^-b, enforcing Hermiticity, to R.
The operator rounding error is at most D delta. Write
  W=R+D delta I,       Q_delta(C)=W/Tr W.
This is an explicitly encoded positive state, and
  C <= W <= (1+2D delta/a)C.
The local projective charge is
  eta <= log(1+2D delta/a).

Perform the actual same-record update from the previously encoded state,
refresh, then quantize. The accumulated error satisfies
  H_(n+1) <= q H_n + eta.
If preparation is identical, H_0=0, and for every elapsed time and record,
  D_tr(rho_n,rhohat_n) <= tanh[eta/(4(1-q))].

With fixed rational instrument/control matrices, the intermediate update,
normalization and rounding are exact integer operations with a record-age
independent bit bound. The encoded output is a rational density matrix.
If model evaluation is approximate, its certified operator error must also
be included in the padding; a floating calculation alone is not this proof.

The finite-system operation can also ACQUIRE a usable initial prediction
without knowing the actual starting density matrix. Start the computer at a
strictly positive reference and process the actual marks. One private refresh
bounds the projective diameter of the two states. For D4,r1/4,b28, an exact
rational/Taylor check gives the all-initial-state, all-record bound
  D_tr <= (13/10)(6/7)^(n-1)+224*2^-28.
After104 continuing marked cycles this is9.998225735650567e-7 <1e-6.
No original conditional-state oracle is received. The noise/model contract
is still supplied, and this does not acquire a general bosonic posterior.

This single-system result still has D^2 coordinates. For many-body D=d^N,
it does not solve the description problem. Treating independent local noise
as one global replacement also incurs a replacement weight r0^N. This was
the next consequential limitation, and motivated the acquired block attack.

5. OBSERVATION THAT BOTH ACQUIRES A MARK AND CUTS DEPENDENCE
=========================================================
An actual local measure-and-prepare branch is
  C_y(X)=sigma_y Tr(E_y X),       sum_y E_y=I.
For an arbitrary correlated state on site A and remainder R,
  (C_y tensor id)(rho_AR)
    = sigma_y tensor Tr_A[(E_y tensor I)rho_AR].
The observed site becomes the known sigma_y. The outcome generally changes
the state of the rest, which must still be retained. This operation can be
phase-sensitive and useful for feedback. It is physical backaction, not
software deletion of a correlation.

Maintain a product of acquired correlation-block density matrices. Local
instruments update a block; joining interactions merge blocks; a received
cut separates the measured site from its conditionally updated old block.
Blocks need not be spatially contiguous. Measuring an intermediate site can
leave or create entanglement between distant surviving sites, so the rest
must not be split merely by looking at current spatial adjacency.

There is also an explicit initialization interface. Apply a known local cut
instrument to every site and receive the marks. The output is the known
product of their sigma_y even for an unknown, correlated input. This obtains
a future predictive state without initial tomography. It does not predict
the initialization record law, identify unknown dynamics, or calibrate the
instrument. Fresh Markov environment and absence of an inaccessible memory
that later reconnects are part of the model.

Fix a maximum block size B>=2. Before a two-site gate joining blocks of
sizes a and b:
  - If a+b<=B, apply it directly.
  - Otherwise cut the participant in the larger block if min(a,b)+1<=B.
  - If a=b=B, cut both participants, then interact their fresh singletons.
At most TWO local informative readouts are needed per overflowing two-site
interaction. The old block remainders are retained with their conditional
states. For an r-site operation, at most r participating-site cuts suffice
when B>=r. Adaptive topology is permitted for this active budget rule.

The coordinate bound follows, but exact bit lengths could still grow under
arbitrarily many weak marks in a surviving block. The next section closes
that gap with ordinary private onsite noise and positive quantization.

6. COMBINED MANY-BODY THEOREM: COORDINATES AND BITS
================================================
Suppose the acquired block partition has |C|<=B at all times by the preceding
physical rule. All observations are retained. At the end of each declared
sweep, each site independently undergoes the physical channel
  e(X)=(1-r0)X+r0 I_d/d Tr X,       0<r0<1.
Its replacement labels remain private. A finite number/description size of
operations between sweeps is required to bound working arithmetic.

Within a block of s sites, the channel has a positive decomposition
  e^tensor_s = r0^s R_(I/d^s)+(1-r0^s)G_s,
where G_s is CPTP. This is used to prove a bound; the observer does not
sample or receive these hidden reset choices. It propagates the local
channel directly on its represented block.

The block's eigenvalue floor and contraction are
  a_s=(r0/d)^s,
  q_s=(1-r0^s)/[1-r0^s+2(r0/d)^s] <= q_B <1.

The important product identity is
  h(tensor_C rho_C,tensor_C sigma_C)=sum_C h(rho_C,sigma_C).
Every same-record operation between sweeps is globally nonexpansive, even
when the common partition changes. At the sweep, each block contracts by
at most q_B. Quantizing each refreshed block at mesh delta gives

  H_(n+1) <= q_B H_n + 2delta (N/B)(d^2/r0)^B.

Here sum_C d^(2|C|) <= (N/B)d^(2B), because d^(2s)/s increases with integer
s. No divisibility of N by B is needed. With legitimate H_0=0,

  D_tr(rho_n,rhohat_n)
    <= N (d^2/r0)^B delta / [2B(1-q_B)]              (MAIN)

for every supported complete received history, uniformly in n. The same
allowance bounds the current state during intervening branches, and every
common future physical experiment started from the encoded state.

The state uses at most (N/B)d^(2B) independent real integer coordinates,
each with b+2 bits, plus derived or cached trace normalizers. A sufficient
precision is
  b >= ceil log2[N (d^2/r0)^B / (2B(1-q_B)epsilon)].
Also satisfy delta<=1/(4d^B). Partition labels use, for example,O(Nlog N)
bits; controller and model memory remain separate. Rational work between
sweeps is finite with an explicit dependence on B, local model precision,
the number of primitive operations and b, rather than elapsed record age.

Thus for fixed d,B,r0 and tolerance, state coordinate count is linear in N,
and precision grows logarithmically with N/epsilon. The theorem is still
exponential in the permitted correlation size B. Its physical intervention
cost must be judged against the scientific or control task.

Illustrative scaling calculation, NOT an executed10,000-spin simulation:
N=10000, d=2, B=4, r0=1/4 gives q_B=2040/2041. Choosing b=58 gives
  bound =1275625/2199023255552 = approximately5.800870895e-7.
The bound permits640,000 independent real coordinates. At60 bits per raw
coordinate this is4.8 MB of coordinate payload (decimal MB), before partition,
model, controller, normalizer caches, working arrays or language overhead.
This is a constructive upper bound for the changed protocol, not an observed
runtime or a claim that these interventions preserve an unrestricted device.

8. INFORMATION CREATION, ACQUISITION AND SURVIVAL
===============================================
An explanatory balance accompanies the constructive theorem but does not
replace it. Let U carry old preparation information, R the received past,
and a same-record instrument produce Y and residual C from physical B.
Define P=I(U:B|R), A=I(U:Y|R), P_res=I(U:C|R,Y). Standard data processing
and the chain rule give
  A+P_res <= P.
After actual private replacement with fraction r,
  P' <=(1-r)P_res <=(1-r)(P-A).
Immediate acquisition A is unchanged by a reset applied AFTER that mark.
Later observations/control generally change. Acquired information remains
in the record; its influence on the continuing physical system can retire.

For fresh independent injected classical labels S_t,
  P_t <=(1-r_t)[P_(t-1)+H(S_t)-A_t].
For constant r>0 and H(S_t)<=b_in this gives a finite steady upper allowance
(1-r)b_in/r for residual information about those labels, plus a transient.
It does not bound matrix dimension, tensor rank, numerical bits or work.
The separate positive/block construction is what pays those costs.

The exactly solvable qubit control has weak-readout strength3/5 and
post-readout private fraction1/4. It acquires approximately0.278072 bits
about the supplied binary preparation label. Its retained state is one
received sign and exact Bloch magnitude9/20. A sign-controlled unitary
achieves target population29/40=.725, versus1/2 without the mark for the
same averaged input. This gives an explicit useful-acquisition/retirement
tradeoff, without a net-work or hardware-efficiency claim.

Unknown permanent model parameters are different: if they affect each new
preparation or evolution, they re-enter the physical system every round.
Their posterior is learning memory, not a dying old-state component. An
unbounded historical controller can likewise reinsert old information.
The present theorem either includes their finite state in the supplied
interface or charges those memories separately.

  a=4/[27q(1-q)^2]>1,       G=3(1-q)^2/(4q).
For component vertex count S,
  Pr(S>=s)<=G a^-s,       E S<=1+4q/(1-3q).
At most S+1 present sites belong to that component. The union bound for

10. DECISIVE LIMITS AND THE NEXT CONSTRUCTION
===========================================
First, observed random-unitary noise can preserve old information in a
small retained frame. Unconditional mixing is not conditional contraction.
Second, rank-deficient replacement can be excluded by a survivor-subspace
record: the saved qutrit example remains orthogonal on arbitrarily long
supported survivor words. Full-rank interior bounds are substantive.

Third, a coherent single-Kraus marked branch K X K^dagger with rank(K)>1
contains NO nonzero CP measure-and-prepare submap. Its Choi matrix is rank1,
so every positive dominated Choi matrix is proportional to it, while that
Choi vector is entangled. Consequently the original a1+/-a2 coherent jump
cannot simply be renamed 'a positive cut plus survivor'. This argument does
not rule out the complete finite first-latch map with its hidden bath/time
integration, nor an entirely different representation.

Fourth, a fixed tolerance for the current conditional state does not imply
a fixed total error for the whole infinite record. For per-sweep projective
allowances H_n, one has conditional KL<=H_n^2/4 and record
  TV<=sqrt(sum H_n^2/8).
Square-summable local quantization allowances suffice for one global
infinite-record bound, with precision growing roughly alpha log2(n) for
alpha>1/2. Constant bits instead support the declared uniform current-state
and future-from-current guarantee. A payoff in[0,1] has value error<=epsilon;
optimal choice under the encoded state has regret<=2epsilon plus planning
error. Planning complexity and the physical effect of added cuts remain
separate.

Finally, arbitrary bosonic space has no positive minimum eigenvalue for a
thermal density. The finite-dimensional cone floor cannot be transferred
using a mean-energy bound alone. Continuous rich bosonic marks still create
the unresolved weighted moment hierarchy in the retained representation.

The next valuable attack is to replace destructive exact cuts with an
acquired, quantitatively controlled smaller predictive interface: partial
quantum/classical boundary messages or a proved summable influence carrying
nonlinear correlations. The present Choi obstruction rules out a naive
positive cut decomposition of coherent jumps. A useful successor must pay
for the actual retained boundary information and its conditioning, while
preserving more of the scientific target dynamics than the hard block cap.

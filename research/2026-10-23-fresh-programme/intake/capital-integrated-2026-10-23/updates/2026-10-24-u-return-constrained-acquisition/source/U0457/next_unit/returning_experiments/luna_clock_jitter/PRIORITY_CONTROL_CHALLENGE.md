# Returning discrimination: primary-priority and control challenge

**Frozen assessment — 24 October 2026.** This is a bounded audit of the opening in `../LEAD_OPENING_FROZEN.txt`; it is not a fixture, implementation, or priority claim. The relevant inherited research context is broad, so this note is not a blind survey.

## Finding

For the stated finite, known class of deterministic machines, a returning discriminator is directly expressible as a strong contingent plan in a finite partially observable transition system. Its hidden state is the candidate world `(machine, anchor, current state)`; actions update `current`; observations split the belief; and the terminal condition says that, in every surviving world, `current` has the same future trace behavior as `anchor`. The extra requirement that some pair of worlds with different anchor futures be separated by the experiment is a finite plan-monitor condition. It can be included in the planning state or checked on the induced partition of initial worlds.

This is an exact established formulation, not a planner that has been handed the lead’s policy. The strongest conventional control is an independently specified strong-belief planner over the same declared class, initial belief, terminal return predicate, and finite transcript monitor. On finite instances it can search for, certify, or rule out such a policy. The proposed operation therefore appears to be a particular goal and information postcondition for known belief-space synthesis. Its potential application value could still come from a useful domain encoding or a favorable cost bound; the opening does not yet give either. No novelty or practical-advantage claim follows from this bounded comparison.

## Exact conventional control

Let `W` be the finite set of currently compatible triples `w=(M,a,q)`, where `a` is that world’s anchor state and `q` its current state. For action `x`, the world deterministically moves to `(M,a,δ_M(q,x))` and reports its model’s output. A belief node is a nonempty subset `B ⊆ W`; after choosing `x`, each possible output `o` leads to the nonempty successor belief

`B[x,o] = { (M,a,δ_M(q,x)) : (M,a,q) ∈ B and output_M(q,x)=o }`.

Define a return goal by requiring behavioral equivalence of current and anchor in every world in `B`: for each `(M,a,q) ∈ B`, every future input word has the same output trace from `q` as from `a`. This relation is computable for each finite machine by ordinary state-equivalence/partition refinement. A finite strong plan is found by backward reachability on beliefs: start with goal beliefs, then add any belief for which some action has every possible nonempty output-successor already in the winning set. The least fixed point decides existence; a decreasing-cost or shortest-depth version yields an optimal finite plan for its specified action cost. Belief count is at most `2^|W|`, so exactness does not imply cheap synthesis.

To enforce the lead’s information condition, mark a pair of initial worlds as relevant when their anchor futures differ. For the finite action tree, record which initial worlds reach the same leaf; accept only if at least one relevant pair is split across leaves. This is a finite monitor/postcondition over a candidate plan. Thus the comparison is not merely “find a safe way back”: it includes the information gain required by returning discrimination. Search, model simulation, monitor/certificate size, action execution, and retained policy storage must all be charged equally to both methods.

This control is independently implementable from the shared machine class; it does not receive a synthesized tree or recipe. A planner given the lead’s final policy would only demonstrate replication, which is not the comparison here.

## What the closest primary sources establish

Rivest and Schapire’s no-reset automata-learning work is directly relevant but does not itself identify the proposed return objective. Their primary extended abstract says the general inference procedures experiment without reset and periodically require a teacher to provide counterexamples to wrong structural conjectures; it separately gives teacher-free probabilistic procedures for permutation automata. It defines a homing sequence by its output transcript determining the terminal machine state (“orientation”), which does not mean returning to the initial state or preserving its future behavior. See [Rivest and Schapire, “Inference of Finite Automata Using Homing Sequences,” extended abstract](https://people.csail.mit.edu/rivest/pubs/RS89.pdf), and the [1993 journal record](https://www.sciencedirect.com/science/article/pii/S0890540183710217). The author-hosted 1993 PDF timed out during this audit; the directly inspected extended abstract states the teacher/permutation distinction explicitly.

The permutation special case has a particularly sharp return wrapper. In a finite class where every action transition is a permutation, choose `L` divisible by every order of every action map in every candidate machine. For an executed word `x₁…xₖ`, append `xₖ^(L−1)…x₁^(L−1)`. Each suffix block implements the inverse of its corresponding permutation, so the complete word returns every candidate state to its own start state. Any distinguishability that occurred in the forward prefix is retained in the transcript, while the suffix restores the anchor exactly. This follows from the permutation assumption and finite class; it is not a general-machine result and `L` and the wrapper can be extremely costly. It reinforces that return can be an ordinary experiment plus a known inverse wrapper in this subclass, while the complete search problem remains belief planning.

Kushik and Yevtushenko’s primary paper on adaptive homing gives another nearby but narrower operation. It studies complete observable nondeterministic FSMs with an unknown initial state; an adaptive input tree is homing when each terminal output trace leaves a singleton terminal-state set. If such an experiment exists, their algorithm constructs one in polynomial time under the paper’s alphabet-size condition. Homing identifies the final state; it does not restore the initial anchor or identify which candidate machine generated the trace. See [Kushik and Yevtushenko, “Adaptive Homing is in P”](https://arxiv.org/html/1504.02444), especially §§1–3. It is valid prior art for adaptive state-estimation trees, not an exact substitute for the lead’s return postcondition.

The most direct planning incumbent is Bertoli, Cimatti, Roveri, and Traverso’s primary paper on strong planning under partial observability. It formalizes a conditional plan that succeeds for every possible initial state and nondeterministic outcome, and gives an AND-OR algorithm over belief states that terminates and is correct and complete. A finite candidate-machine identity can be included as a hidden state component that remains fixed; the return relation is then the goal condition, with the discriminator requirement added as the finite monitor above. See [“Strong planning under partial observability,” Artificial Intelligence 170 (2006)](https://www.sciencedirect.com/science/article/pii/S0004370206000075), DOI [10.1016/j.artint.2006.01.004](https://doi.org/10.1016/j.artint.2006.01.004). This is the decisive exact-method comparison for the opening’s own explicit finite belief-space synthesis.

The cited physical incumbent is narrower in a different direction. Sieber et al. experimentally continued branches of periodic orbits through a fold, using control-based setup and Newton iterations to track an unstable periodic orbit of a vertically forced pendulum. The APS primary abstract does not describe hidden finite-machine identification, return-to-anchor guarantees, or information-gain certification; it supports the physical idea of continuing an operating regime while probing it, not the exact formal operation. See [Sieber et al., “Experimental Continuation of Periodic Orbits through a Fold,” Physical Review Letters 100, 244101 (2008)](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.100.244101).

## Structural claim repairs and boundary

- **Concatenation (A):** Under exact finite deterministic models and behavioral equivalence as stated, the return condition is stable under every future action. A later adaptive returning tree therefore behaves as it would from the anchor in each surviving world. Previously available return trees remain executable after an earlier returning experiment, so their partitions can be composed/refined. This is a valid consequence of the definition, not a new learning theorem.
- **Stage count (B):** The natural bound is `|W₀|−1`, where `W₀` counts initial `(machine, anchor, current)` worlds, not necessarily `|H|−1` if a machine in `H` has multiple possible anchor/current states. Each truly discriminating tree separates at least one relevant pair, so every observed leaf removes at least one candidate world. Reaching a **maximal** safely learnable quotient additionally requires exhaustive synthesis over all finite returning policies. A finite depth cap can only say “inconclusive.”
- **Existence/complexity (C):** Finite strong belief planning already supplies an exact decision formulation for whether a return-and-information tree exists. This makes a DFA-intersection reduction unnecessary as the first decisive challenge. A reduction could still establish a sharper lower bound for a carefully delimited problem, but it would not make the underlying operation novel by itself.
- **No reset does not imply no return:** For non-permutation transitions a return tree may not exist. Homing, synchronizing, or a behavior-preserving return are different terminal requirements; none can be substituted without checking the exact anchor-future predicate.
- **Costs remain decisive:** The wrapper and belief planner may be exponentially large or costly. A useful claim would need a proved reduction in total acquisition plus synthesis plus execution cost against the independent planner, not only a bound on successful information stages.

## Bounded conclusion

The exact formulation of “preserve the anchor while learning” is already available as strong contingent planning with a custom terminal set and finite information monitor. Rivest–Schapire establish no-reset learning under their stated teacher assumptions, with a separate teacher-free permutation result; homing establishes terminal orientation, not return. The opening’s own belief-tree search is therefore best treated as a transparent specification of a standard planner, unless it next demonstrates a distinct resource bound or a costed instance where an independently run strong planner is materially worse. Stop here before fixture expansion.

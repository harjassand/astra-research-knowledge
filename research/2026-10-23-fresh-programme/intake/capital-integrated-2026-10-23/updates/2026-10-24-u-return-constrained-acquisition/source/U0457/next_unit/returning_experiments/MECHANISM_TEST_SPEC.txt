MINIMAL ACQUIRED-ACCESS TEST, FIXED BEFORE IMPLEMENTATION
24 October 2026. Lead-owned finite symbolic specification.

Purpose: falsify the claimed mechanism, not establish an algorithmic advance,
physical explanation, practical superiority, or benefit over a strong planner.
All prior candidate programs and the allowed initial-anchor set are shared.
The only acquired information will be ordinary executed action/output events.

Two candidate deterministic Mealy machines M_theta, theta in {0,1}, share seven
states H0,H1,S0,S1,T0,T1,D, actions a,b, and binary outputs. The unknown anchor is
H_phi, phi in {0,1}; thus there are four pointed worlds. The learner receives
none of theta, phi, or the actual current-state label.

                      action a                     action b
 H_phi           output 1, next S_phi        output phi, next T_phi
 S_phi           output theta, next H_phi    output 1, next D
 T_phi           output 0, next H_phi        output 0, next D
                    if theta=0                 if theta=0
 T_phi           output 0, next D            output 0, next H_phi
                    if theta=1                 if theta=1
 D               output 0, next D            output 0, next D

Before implementation, S_phi's b-output was changed from0 to1; its next state
stays D. This avoids a single output value uniquely naming a state and changes
none of the mechanism arguments. The original proposal is preserved in the
lead-to-worker challenge message. No run had occurred at this correction.

The primitive a is not a reset: at H it leaves H, at S it returns, and at T it
can destroy return. The primitive b is not a reset either. No output is a
globally unique state label. In particular, a's output 1 at both possible
anchors does not distinguish their phi. No separate calibration sensor,
simulator truth, model selection hint, or supplied macro library is exposed.
The engineered transition table does supply a class-specific safe source path;
this is an ordinary model-class promise, not discovered structure outside it.

Predictions to decide exactly using generic model simulation/strong planning:

1. The word aa is returning for all four worlds and has transcript (1,theta).
   It learns theta, leaves phi unknown, and costs two primitive actions/events.

2. Before that source experience, no finite sure-returning policy can begin
   with b. Its output reveals phi, but both theta alternatives remain at T_phi.
   Stopping fails return (T's a-output0 differs from H's a-output1). Choosing a
   traps theta1 in D; choosing b traps theta0 in D. D cannot be equivalent to
   any anchor because its a-output is0 and the anchor's is1. Later observations
   cannot undo true-world absorption. Hence adaptation at this point cannot help.

3. After aa, b followed by a if theta0, or b if theta1, is returning and gives
   transcript (phi,0). It is newly valid for immediate execution on the remaining
   version set. Together the source and target require four primitive actions
   and identify the four possible anchor futures without any reset.

4. The whole depth-four adaptive source+target is already one feasible standard
   contingent plan from the initial class. Therefore the experiment has become
   newly warranted WITHOUT replaying calibration, not newly physically possible
   or impossible to plan initially. A strong planner should find the same policy.

5. A generic pair-separation fixed point must find all four singleton terminal
   classes and certify return by the actual candidate equivalence relation,
   rather than by a hardcoded H-state equality test. It must reject b-first
   return from the initial belief, and accept it from either post-source belief.
   All possible true worlds must be tested, with separate planning/search,
   controller storage, and executed-action counts.

No parameter sweep, random benchmark, asymptotic performance ranking, or later
favorable class will be added to this minimal test. Failure of any item above
withdraws the corresponding mechanism claim. Passing only demonstrates exact
acquired-access dependence in this stipulated finite class. The substantive
general result remains the return-closure theorem, with classical planning
as its exact implementation and PSPACE-hard synthesis as a cost obstruction.

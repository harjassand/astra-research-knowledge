RETURN-CONSTRAINED ACQUISITION: EXACT FINITE-CLASS CLOSURE
24 October 2026. Lead derivation; not a novelty or practical-advantage claim.

Correction to the preserved LEAD_OPENING_FROZEN.txt

The opening's |H|-1 stage bound is wrong when H counts unpointed machines and
their initial states are unknown. Count pointed worlds instead. The correction
was independently found by luna_batched_mean and luna_hidden_state. Their
one-machine/two-anchor example is decisive: an output-distinguishing self-loop
can require one stage although |H|-1=0. The frozen opening is not overwritten.

1. Trusted interface, acquired information, and return

A finite set W of m pointed worlds is prior knowledge. A world w specifies a
deterministic, total, finite Mealy machine M_w=(Q_w,A,O,delta_w,lambda_w) and a
candidate anchor a_w. Different worlds can be the same machine with different
anchors. The actual w is unknown. Candidate-model state labels are internal
simulation coordinates; the real interface exposes only chosen a in A and its
output o in O. There is one immutable continuous stream, no reset operation,
state-label sensor, equivalence teacher, or supplied experiment library.

Membership of the actual system in W and the allowed anchor set are assumptions,
not conclusions certified by a finite realized trace. All simulated tables and
the synthesis algorithm are prior programs; executed outputs narrow W. The
model-class description, search, certificate, controller storage, and executed
actions are distinct paid resources.

Within a candidate machine let q ~_w q' mean that every finite input word has
identical output traces from q and q'. This is a transition congruence:
equivalent states have equal one-action outputs and equivalent successors.
It can be computed from the explicit finite candidate machine.

An epistemic node X consists of a nonempty B subset W and one current q_w for
each w in B. Updating by action a and observed o gives

 X[a,o]={(w,delta_w(q_w,a)): w in B, lambda_w(q_w,a)=o}.

An empty successor is not an outcome. A returned boundary satisfies q_w~_w a_w
for every w in B. A finite adaptive test is returning if all of its realizable
terminal nodes satisfy that condition. Its complete action/output transcript
partitions B. It is informative exactly when that partition has >=2 blocks.
Such a pair necessarily has different unrestricted anchor futures.

The return guarantee is task-uniform over future tasks whose reward depends
only on actions and their output traces, with the same interface. A common
randomized adaptive policy can be coupled on the same random tape; congruence
then gives identical traces pathwise from q_w and a_w. This preserves all
bounded trace rewards and all later finite experiments. It does not preserve
unobserved material inventory, damage, fuel, hidden-state rewards, or new
sensors. Such costs must be included in the certified model/interface.

2. Closure under composition

Lemma 1 (restriction). A returning test valid on B stays returning on each
nonempty B' subset B, if begun at states equivalent to their anchors. Restrict
its realizable branches to B'; congruence gives the same worldwise traces and
return states. Removing alternatives cannot introduce a bad true-world path.

Lemma 2 (composition). Run a returning test T on B. On each of its terminal
transcript blocks C, run any returning test S_C valid on C. The resulting finite
tree is returning on B. At the join, congruence transports S_C from each
world's anchor to its actual equivalent current state. Each terminal returns.

In particular, two tests T,S returning on B can be run in sequence, and their
paired transcript is the common refinement of their transcript partitions.
Old certified tests remain physically executable at a returned boundary;
additional tests may become valid because the version set has shrunk.

3. The unique safely obtainable information partition

Fix the initial anchor belief B0 subset W. Let R(B0) be ALL finite returning
adaptive trees valid on B0, including trees containing long excursions and
information-dependent return paths. Define

 w ==_R w'  iff  T has the same transcript under w and w' for every T in R(B0).

This is an equivalence relation. It can be coarser than ordinary equality of
unrestricted anchor futures: some differences require irreversible access loss.

Theorem. Start from B0 at a returned boundary. Whenever an informative finite
returning tree exists on the current version set, execute any such tree and
retain the actual transcript block. If synthesis is complete, this process:

 (i) has at most |B0|-1 successful stages on every actual-world branch;
 (ii) preserves all earlier returning tests;
 (iii) terminates at exactly the ==_R equivalence class of the actual world.

Thus the final safely learnable information is independent of greedy test
choices. This is information confluence, not cost optimality. A depth-limited
or incomplete search can return only INCONCLUSIVE when it finds no test.

Proof. An informative deterministic tree has >=2 nonempty transcript blocks;
each is proper, so every realized stage removes at least one world. Lemmas 1-2
give preservation and make the finite composition of all executed stages a
single member of R(B0). Therefore a world equivalent to the truth under ==_R
cannot have been removed: it follows the same transcript of this composition.

Conversely, suppose a terminal version set C contains the truth w and a world
w' not ==_R-equivalent to w. Some test T in R(B0) separates them. By Lemma 1,
T is also returning on C and remains separating there, contradicting termination
with no informative returning test. Hence C is exactly the stated class. QED.

Equivalent alternative proof: a terminal cell of any greedy strategy cannot
be split by any competing returning strategy. Restrict each competitor test
to that cell and induct over the competitor's branches. Interchanging the two
strategies yields identical terminal cells. This does not assert that all
nonreturning safe-control objectives have such a confluence property.

The entire adaptive source protocol can already be compiled as ONE ordinary
contingent plan. Calling a later test 'newly licensed' means that it is now
valid immediately without replaying earlier calibration, not that no composite
plan for it existed initially. Stage boundaries are a useful execution/cache
interface, not an invariant count of independent discoveries.

4. Complete finite synthesis, including an explicit certificate

For a selected pair u,v in the current B, enumerate reachable epistemic nodes.
The terminal goal is

 G_uv={X: X is returned and {u,v} is not a subset of B(X)}.

Every world follows one deterministic branch. Reaching G_uv on every branch
means the two selected worlds can never share a terminal transcript, while
every true-world trajectory returns. Empty tests are allowed at goal nodes.

Set Win_0=G_uv and iterate

 Win_(j+1)=Win_j union {X: some a has every nonempty X[a,o] in Win_j}.

At the finite fixed point, a node is winning iff a finite sure returning tree
separating u,v exists. A controller chooses the witnessing action and moves to
strictly smaller iteration rank on every outcome; rank is a finite termination
certificate. Induction proves soundness. Conversely, induction on the depth of
any finite successful tree puts its root in the corresponding Win_j, proving
completeness. Test all pairs to decide whether an informative returning test
exists. A single pair goal suffices for each successful greedy stage.

If n_w=|Q_w|, there is at most one current state per surviving pointed world,
so the number of nonempty epistemic nodes is at most

       N <= product_(w in W) (1+n_w) - 1.

This can be much smaller than 2^(sum n_w), but is still exponential in a compact
class description. Explicit graph generation and fixed-point sweeps incur
candidate transition/observation computations, memory, pair searches, and policy
storage. A winning rank is <=N, giving a crude bound N on a synthesized macro's
worst-case primitive length, and (m-1)N across greedy stages. These are upper
bounds, not a practical efficiency claim. A fully expanded tree has <=m nonempty
leaves but can still have long shared trunks and many unary internal nodes.

Existence is not made easy by the small stage count. The separately audited
DFA-intersection reduction in luna_ctmc/COMPLEXITY_CONTRACT_CHALLENGE.md proves
PSPACE-hardness for explicit candidate classes. The general exact complexity
class or a cost-competitive greedy rule is not established here.

5. What is acquired and what remains an incumbent

Paid source observations reduce the robust return obligation. A retained
controller that is invalid for a larger version set can become valid on the
actual smaller set. A minimal mechanism test must show precisely that change,
using the same transition/output kernel before and after, while charging the
source and synthesizing the controllers from candidate programs.

Strong partial-observation/contingent planning is the exact established solver
for this contract; the procedure above is its direct fixed-point implementation.
It is a stronger comparator than prediction-only fitting or model identification
allowed to abandon the anchor. A planner independently reconstructing the policy
is conventional evidence; a control given the policy demonstrates reproducibility
and does not refute usefulness. No speed or novelty over planning is claimed.

Rivest-Schapire homing identifies terminal
orientation, not anchor return. Their 1989 primary extended abstract explicitly
uses counterexample teachers for general machines and gives a separate teacher-
free permutation case; it also accepts learning a terminal component when a
non-strongly-connected environment loses access to the rest. This is a different
target, not a deficiency in that theorem. Primary:
 https://people.csail.mit.edu/rivest/pubs/RS89.pdf (pp.1-5).
Nearby homing definition and polynomial result:
 https://arxiv.org/html/1504.02444 (Kushik and Yevtushenko, 2015).
Exact planning incumbent:
 https://doi.org/10.1016/j.artint.2006.01.004
 Bertoli et al., Strong planning under partial observability (2006).

No claim here covers noisy/stochastic observations, approximate return, model
misspecification, discovery of the true finite class from the same finite trace,
or a physical device. Such extensions need a separate error and resource theory.

ACQUIRING EXPERIMENTS THAT PRESERVE THE ABILITY TO LEARN AGAIN
24 October 2026. Lead-owned opening before worker assignments or fixture work.
The completed inverse/PCA/QEC units remain frozen. This is independent of the
opportunity group's matrix/rational procedures and first-failure-stage example.

Scientific/intelligence obstruction

An agent can improve prediction by driving a system into an absorbing condition
where every future output is trivial. It has then identified the current future
while destroying the experiments needed for new questions. Thus a learned model's
prediction accuracy is not sufficient evidence of cumulative experimental ability.
The question here is whether experience can acquire return instructions that
make new tests safely executable, without receiving a reset, current state ID,
equivalence-query teacher, or a supplied safe experiment library.

Concrete source/target interface

Use a finite known class H of deterministic finite input/output machines, with a
finite action and observation alphabet and a declared state bound. Ordinary model
classes and code are legitimate prior knowledge shared with all controls. The
actual machine and initial state are unknown. Only one action/observation stream
is available; its immutable kernel is used for source and target tasks. Internal
states of candidate models are bookkeeping hypotheses, not observed state IDs.
There is no reset oracle and no teacher-generated counterexample.

The initial condition is an anchor. A finite adaptive experiment is returning if
every possible observation branch ends at a state behaviorally equivalent to
that anchor in every still-compatible world. Equivalence means identical output
traces under every future action sequence, not equality of a reported label.
This requirement preserves every bounded reward on future output traces; no
future task is singled out to make the source look useful. Repeated target
requests can be selected after earlier answers. Experiments/control steps,
discovery/search, memory and certificates are paid.

Owned central operation: returning discrimination

Maintain a version set of (candidate machine, anchor state, current state) triples
consistent with the actual stream. Search for a finite action/observation tree T
whose leaves all satisfy the return obligation and which gives different output
transcripts for at least one pair of candidate worlds with different anchor
futures. Execute it once. Its actual output branch updates the version set and
provides a certified return recipe for this now-smaller set. Retain the recipe,
not only its output label. New tests that lacked a common return policy over the
old version set may now have one. The learner can therefore acquire a new
experimental interface, rather than just a better estimate on a fixed interface.

The search is explicit finite belief-space synthesis, not a free policy oracle:
at a node, an action updates each candidate's current state; observed outputs
partition candidates; each output branch must terminate with return. Source
queries occur only when executing a synthesized tree, not when simulating the
declared candidate machines. Those simulations/planning costs are separately
charged and may dominate. A finite search-depth cap may return inconclusive.

Structural target to prove or falsify before fixture investment

(A) Returning tests can be concatenated without losing experimental access.
    Their information partitions admit common refinements. Greedy execution of
    any returning discriminator removes a candidate on every observation branch
    while leaving every future returning test physically available at the anchor.
(B) With finite H, at most |H|-1 successful discrimination stages reach a version
    set on which no further returning test distinguishes anchor futures. This
    must be a maximal safely learnable quotient, rather than merely a local
    dead end caused by a bad earlier experiment. The finite synthesis cost and
    controller size cannot be hidden in this stage count.
(C) Discovering whether any informative returning test exists can itself be a
    consequential computational obstruction. Try a precise reduction from DFA
    intersection, while allowing adaptive output branches. If that reduction is
    just an established partial-observation planning result, say so explicitly.

The mechanism test is not a broad benchmark: first determine whether (A)--(C)
are correct and whether returning discrimination supplies anything beyond known
homing/active automata/safe belief-space planning. Then, only if warranted, require
an explicit immutable-machine family where information from one returning
experiment enables a new safe test, while a predictor trained by destroying
access fails later arbitrary trace objectives. The source compiler must find
the experiment from the shared class/actual history; no action called 'reset'
or specially supplied latent calibration feature is allowed to do the work.

Strong conventional comparisons and stop rules

Rivest--Schapire homing-sequence learning already acquires orientation without a
reset, but its general theorem uses counterexample-teacher access; its special
permutation-machine results need separate treatment. These are prior art, not
new mechanisms. Noninvasive control/experimental continuation is a physical
incumbent for preserving an operating regime while observing unstable behavior.
Safe active automata learning, contingent planning, knowledge-based control and
ordinary finite-belief game synthesis are the decisive conventional comparators.
A control implementing this new policy after receiving it is replication;
an established planner independently solving the same problem is a substantive
comparison. Do not weaken it to cold prediction or full-model identification.

No claim that the robustly certified action set creates new physical actions.
It changes which experiments can be executed with the required warranty under
the acquired uncertainty. Actual source experience must change that set in the
decisive test. If this entire construction is merely a known belief-game wrapper,
retain the prediction-versus-access distinction and stop before fixture volume.

## The closed finite-class result

The [governing theorem](source/U0457/next_unit/returning_experiments/RETURN_CLOSURE_THEOREM.txt) assumes a finite supplied set `W` of pointed deterministic total Mealy-machine worlds. Each world specifies its machine and candidate anchor; the actual world is unknown. Candidate labels are internal simulations, and the learner sees only chosen actions and outputs on one immutable stream. There is no reset, state-label sensor, equivalence teacher, or supplied experiment library. Membership of the real system in `W` and the allowed anchor set are assumptions, not conclusions learned from a finite trace.

Within each candidate machine, `q ~_w q′` means every finite future action word has the same output trace from both states. This is a transition congruence. A test returns when every realizable terminal branch ends in a state equivalent to that world's anchor. Finite returning tests compose and refine their transcript partitions; shrinking the version set preserves tests already safe at the returned boundary.

Let `R(B₀)` be all finite returning adaptive tests valid at the initial returned version set `B₀`. Define `w ≡_R w′` when every test in `R(B₀)` gives the same transcript in both worlds. Under complete synthesis, executing any informative returning test at each stage reaches exactly the `≡_R` class of the actual world, independently of greedy test choices, in at most `|B₀|−1` successful stages. This is the maximal safely obtainable information cell for the declared action/output interface; it can be coarser than equality of unrestricted anchor futures. A depth-limited or incomplete search may report only `INCONCLUSIVE`.

The original [0437 opening](source/U0437/next_unit/returning_experiments/LEAD_OPENING_FROZEN.txt) is retained byte-for-byte with its earlier `|H|−1` claim. That count is wrong when `H` counts unpointed machines while anchors are unknown. The corrected theorem counts initial pointed worlds, and the [adversarial audit](source/U0457/next_unit/returning_experiments/luna_hidden_state/FIRST_ADVERSARIAL_AUDIT_FROZEN.md) gives the one-machine/two-anchor counterexample.

For a pair `u,v` in the current belief, the [complete synthesis](source/U0457/next_unit/returning_experiments/RETURN_CLOSURE_THEOREM.txt) searches reachable epistemic nodes and uses the goal “returned and `u,v` separated.” Its least fixed point adds a node when some action sends every nonempty observation successor to the prior winning set. A fixed-point rank certifies finite termination; solving all pairs decides whether an informative returning test exists. With `n_w` states in world `w`, the explicit node bound is `N ≤ ∏_(w∈W)(1+n_w)−1`; a synthesized macro has crude worst-case length at most `N`, and the at-most-`|B₀|−1` stages have crude total at most `( |B₀|−1 )N`. These can be exponential costs, not practical efficiency guarantees. The separate DFA-intersection reduction establishes PSPACE-hardness for its explicit encoding; no new exact complexity classification is claimed.

The return guarantee preserves bounded future rewards that depend on action/output traces. It does not preserve unobserved inventory, damage, fuel, hidden-state rewards or new sensors unless those are included in the certified model and interface.

## Bounded mechanism and conventional control

The fixed [mechanism specification](source/U0457/next_unit/returning_experiments/MECHANISM_TEST_SPEC.txt) uses four pointed worlds from two deterministic machines over seven states, actions `a,b`, and binary outputs. In each world, the source `aa` returns to the anchor, emits `(1, θ)`, and costs two primitive actions. Before that observation, no sure-returning test can start with `b`. After `aa` reveals `θ`, `b` followed by `a` if `θ=0` or `b` if `θ=1` returns and reveals `φ`. The source-plus-target uses four primitive actions in every world and ends in one of four singleton truth cells.

The [producer result](source/U0457/next_unit/returning_experiments/RETURNING_ACCESS_CHECK.json) reports an exact finite check: 34 reachable epistemic nodes, 116 candidate transition evaluations, 8 fixed-point solves, 29 sweeps, 1,188 fixed-point action tests, and 24 minimum-witness greedy paths checked. All four executions use four primitive actions and end in singleton cells. The reported unbenchmarked elapsed time is not a performance comparison. The [strong-planning audit](source/U0457/next_unit/returning_experiments/luna_clock_jitter/PRIORITY_CONTROL_CHALLENGE.md) says a conventional strong contingent planner independently finds the same full depth-four policy from the original belief. Thus experience makes `b` immediately safe as a standalone test after `aa`; it is not newly physically possible or unavailable to a planner from the outset. No planner advantage or new physical action is established.

The [development correction](source/U0457/next_unit/returning_experiments/CHECKER_DEVELOPMENT_CORRECTION.txt) preserves the initial checker failure: it compared a pair-separation policy with a full-singleton terminal goal. The pair policy could correctly stop on a different nonsingleton branch. The corrected checker performs a separate return-and-singleton solve while retaining the pair-separation solves; it did not retune the machine or report a full-identification result from the failed run. The checker source is retained as data and was not executed here.

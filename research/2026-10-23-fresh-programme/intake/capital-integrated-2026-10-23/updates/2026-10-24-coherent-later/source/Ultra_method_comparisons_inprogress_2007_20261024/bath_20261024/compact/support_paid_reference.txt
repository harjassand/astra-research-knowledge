# Paid dark-reference tap: covariance and interface audit

This checks the proposed two-port, one-mode Gaussian tap and separates a generic signal-estimation calculation from the parent's actual spin-only gate identity. It does not assume an ideal thermal-state purifier and does not read the warm-arm output.

Let the native incoming lines be independent thermal modes with quadrature variances \(v_j=N_j+\tfrac12\), and let \(L_j=\sqrt{\gamma_j}a\), \(\Gamma=\gamma_1+\gamma_2\). The passive input rotation

\[
B=(\sqrt{\gamma_1}b_1+\sqrt{\gamma_2}b_2)/\sqrt{\Gamma},\qquad
D=(\sqrt{\gamma_2}b_1-\sqrt{\gamma_1}b_2)/\sqrt{\Gamma}
\]

puts the coupling entirely in \(B\). The \(D\) mode is decoupled from \(a\). For either quadrature \(P\),

\[
v_B=(\gamma_1v_1+\gamma_2v_2)/\Gamma,\quad
v_D=(\gamma_2v_1+\gamma_1v_2)/\Gamma,\quad
c_{BD}=\operatorname{Cov}(P_B,P_D)=\sqrt{\gamma_1\gamma_2}(v_1-v_2)/\Gamma.
\]

Thus \(D\) is not generally independent of \(B\): unequal native temperatures produce a bright-dark input correlation. If \(v_1=v_2\), the dark reference is uncorrelated with the bright thermal input and cannot estimate it.

Now mix \(D\) with an independent cold vacuum mode \(V\), whose quadrature variance is \(v_0=\tfrac12\):

\[
P_{D_t}=\sqrt{1-r}P_D+\sqrt r P_V,\qquad
P_R=\sqrt r P_D-\sqrt{1-r}P_V.
\]

The same-quadrature observables commute, \([P_{D_t},P_R]=0\), so ideal homodyne detection of \(P_R\) can condition \(P_{D_t}\) without disturbing that quadrature. For \(v=v_D\),

\[
v_R=rv+(1-r)v_0,\quad
\operatorname{Cov}(P_{D_t},P_R)=\sqrt{r(1-r)}(v-v_0),
\]

\[
\operatorname{Var}(P_{D_t}\mid P_R)
=v_{D_t}-\frac{\operatorname{Cov}(P_{D_t},P_R)^2}{v_R}
=\frac{v\,v_0}{rv+(1-r)v_0}
=\frac{v}{2(rv+(1-r)/2)}.
\]

So the stated formula is correct for the **dark quadrature alone**. It falls monotonically from \(v\) at \(r=0\) to the vacuum floor \(1/2\) at \(r=1\); for \(v\gg1\) and fixed \(r>0\), it tends to \(1/(2r)\).

For a generic transmitted-signal estimator, if \(P_{B,\mathrm{out}}=s+P_B\), with signal displacement \(s\) independent of bath inputs and thermal input \(P_B\) as the only noise in this simplified model, then \(Y=\sqrt f P_{B,\mathrm{out}}+\sqrt{1-f}P_{D_t}\). The **optimal linear correction from \(P_R\)** is conditional regression of the whole bath contribution to \(Y\), not only subtraction of the dark conditional mean. Set \(c=c_{BD}\). The conditional covariance entries are

\[
\operatorname{Var}(P_B\mid P_R)=v_B-\frac{r c^2}{v_R},\qquad
\operatorname{Var}(P_{D_t}\mid P_R)=\frac{v_Dv_0}{v_R},\qquad
\operatorname{Cov}(P_B,P_{D_t}\mid P_R)=\frac{\sqrt{1-r}\,c\,v_0}{v_R}.
\]

Consequently, after referring the output back to unit signal gain, the residual bath variance is

\[
v_B-\frac{r c^2}{v_R}
+\frac{1-f}{f}\frac{v_Dv_0}{v_R}
+2\sqrt{\frac{1-f}{f}}\frac{\sqrt{1-r}\,c\,v_0}{v_R}.
\]

This is before detector inefficiency and before any additional oscillator/system noise. If the detector has efficiency \(\eta_d\), the simple output model \(Y_d=\sqrt{\eta_d}Y+\sqrt{1-\eta_d}P_{V_d}\), followed by division by \(\sqrt{\eta_df}\), adds the separate input-referred vacuum term \((1-\eta_d)v_0/(\eta_df)\). It must not be folded into \(N_1,N_2\).

If a separate, independently established step cancels the bright thermal component and the correction has an overall scalar gain \(q\), the remaining dark-tap term is exactly \(q^2(1-f) v_Dv_0/(f v_R)\), plus the separately propagated detector vacuum. The tap calculation supports that term; it does not establish the assumed bright cancellation.

For that generic estimator only, the tap does not by itself cancel the bright thermal input: for equal bath temperatures \(c=0\) and the record contains no bright-noise information; for unequal temperatures it removes only the component predictable from \(P_R\), with a generally positive conditional bright variance. This estimator calculation must not be used to refute a separate spin-gate correction.

## Spin-gate distinction supplied by parent

The live spin instrument has an independent exact Weyl/BCH correction: multiplication by the stated spin feedback \(\exp(+i a qY/\sqrt f)\) cancels the bright output displacement in \(D_B(qa+cb,pb)\) for arbitrary bright-output state. Under that separate identity, one need not estimate or cancel the bright thermal input by regression; the reference tap is only tasked with estimating the dark-mode contribution introduced by the feedback. In that spin-gate interface, the dark-only residual above is the relevant tap term (scaled by the gate's feedback coefficient), with detector vacuum propagated separately. The candidate selects equal input temperatures, so \(c_{BD}=0\), consistent with the dark reference carrying no bright-input information. This is a formal gate identity as supplied by the parent, not independently rederived in this source check.

The identity does not remove the separately retained hot cross vector \(w_B=O(K^2)\) in the prior instrument/gate. The tap is therefore only an add-on for the dark admixture and is not a general cure for the existing hot-residual gate.

For a continuous damped system, the bath output has frequency-dependent transfer and memory; neither the one-mode regression formula nor the supplied Weyl/BCH gate identity alone proves a full dynamical implementation.

## Physical and baseline costs

- The scheme needs simultaneous coherent access to both native input lines so they can be mixed in the coupling-matched bright/dark basis. That is straightforward only for accessible, phase/mode-matched traveling fields with known \(\gamma_j\); it is unavailable for an internal or inaccessible material reservoir. Different-frequency or broadband lines require a frequency-dependent, low-loss mode transformation.
- \(V\) is an actual cold input resource. A tap beam splitter changes the dark-port state, and \(D_t\) must be returned to the line. The \(R\) port is destructively homodyned; the record is then used for classical correction of the later captured record. This is an engineered bath-boundary operation, not passive observation of an unchanged thermal reservoir.
- One homodyne measures only \(P_R\). The conjugate quadrature has measurement back-action; the operation does not remove the other quadrature phase term (including the stated \(qp/2\) term). Simultaneous two-quadrature monitoring needs an additional vacuum split and incurs heterodyne noise.
- If the same input access/control permits \(r=1\), direct replacement of the decoupled \(D\) input by cold vacuum reaches the best possible dark-quadrature variance \(1/2\), without needing the hot-input reference measurement. It is strictly at least as good for this dark-noise term as every \(r<1\). If both output lines are also accessible, direct inverse rotation and measurement of \(B_{\mathrm{out}}\) is the stronger mode-separation baseline.

Decision gate: compare the proposed finite-\(r\) tap with (i) direct cold-vacuum replacement of \(D\) (\(r=1\)), (ii) bright-output mode sorting where both lines are accessible, and (iii) ordinary detector vacuum loss, using the full conditional covariance above, system transfer functions, real splitter/detection loss, bandwidth, and the same signal gain. The tap is only distinct when full cold replacement or bright-output access is genuinely unavailable but partial coherent access to the dark input is available.

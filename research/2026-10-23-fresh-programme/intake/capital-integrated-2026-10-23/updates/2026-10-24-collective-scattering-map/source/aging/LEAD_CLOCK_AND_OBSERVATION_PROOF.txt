1. Keep three hypotheses distinct

A. One clock: a shared increasing xi_H(t) can parameterize fixed kernels for
specified observables under histories H. TN additionally retains a convolution
of the full temperature history in that clock. This need not be one state or
one relaxation mode.
B. One smooth state: all future tested control/response laws factor through
one current scalar. This is stronger than merely sharing a clock; a broad TN
kernel can have arbitrarily large memory rank while using one clock.
C. Clock-only intervention: a probe changes only the phase/speed of a fixed
measured trajectory, with its other constitutive inputs and fast effects fixed.
This is narrower than general TN and is the target of the transverse-response
test below. Nonzero transverse response must not be used to reject all TN.

Existing primary priors matter. Narayanaswamy/TN, KAHR, Cugliandolo-Kurchan
triangle relations and dynamic Prigogine-Defay tests are not new constructs.
Prados-Brey2010 Eq43 already supplies the Kovacs superposition numerator used
in LEAD_KOVACS_KERNEL_CANDIDATE.txt. Ellegaard etal2007 already tests one
generally non-exponential thermo-viscoelastic order parameter, not a scalar
Markov state. The present distinctions sharpen observation/claim boundaries.

2. A frozen time change cannot repair a physical FDT ratio

Fix a deterministic increasing clock xi(t) for a prepared aging protocol,
with gamma=dxi/dt>0. For a physical conjugate field h(s), define response per
unit LABORATORY source time by
  delta m_i(t)=integral R_i(t,s) delta h(s) ds.
Express the SAME physical field as h_xi(xi(s))=h(s), keeping the clock fixed.
Then response per unit material source time is R_i/gamma(s), and
  partial_(xi(s)) C(t,s)=partial_s C(t,s)/gamma(s).
Therefore R_i/[beta partial_s C] is invariant wherever the denominator is
nonzero. A different clock cannot restore equilibrium FDT by a source-time
Jacobian alone. Conjugate variables, equilibrium-reference beta, parity and
observable normalization are separate required physical inputs. This is the
known FDR/framework boundary, not a newly invented fluctuation theorem.

The clock must be fixed before the probe. If it is estimated anew from each
perturbed trajectory, the following extra gauge freedom appears.

3. Response removed by a perturbation-dependent clock

Suppose an instantaneous slow measured mean vector is m_i(t)=q_i(xi(t)).
Let a probe induce delta xi(t)=integral K_clock(t,s)delta h(s)ds. Comparing
means at a FIXED PERTURBED material-time coordinate moves the physical
readout time by delta t=-delta xi/gamma(t). Chain rule gives the effective
laboratory-source response
  R_i^co(t,s)=R_i(t,s)-v_i(t)K_clock(t,s),
  v_i(t)=dm_i/dxi=dot m_i/gamma(t).                         (1)
After changing the source integration variable, divide the whole expression
by gamma(s). This describes a different readout convention, not loss of the
actual laboratory response. Retain K_clock as a causal output if using it.

At a drifting single observable with v_i!=0, an unconstrained fitted clock
can absorb ANY one response component by selecting K_clock=R_i/v_i. Thus a
one-observable collapse following clock refitting has weak causal content.
For multiple observables, the exterior response
  W_ij(t,s)=v_i(t)R_j(t,s)-v_j(t)R_i(t,s)                  (2)
is unchanged by the subtraction in(1). Ordinary frozen retiming rescales it;
whether it vanishes is invariant. If v!=0, all W_ij vanish iff R is parallel
to v. If v=0, any nonzero R is already outside a clock-phase change.
Nonsingular fixed unit changes preserve zero/nonzero; a numerical residual
norm requires a predeclared measurement/noise metric, not arbitrary units.

For several probes R is a matrix and the observable quotient is its image
modulo span(v). Rank in this quotient counts observed transverse response
directions, NOT microscopic state coordinates. A reproducible nonzero quotient
rejects clock-only action under the calibrated measurement interface. It
does not prove an elastic/plastic mechanism, equilibrium failure, or failure
of a broad history-kernel material-time model.

For two-time correlation channels C_i=F_i(xi(t)-xi(s)), pure clock changes
produce delta C_i=F_i'(Delta xi)[delta xi(t)-delta xi(s)]. Replace v_i by the
known slope F_i'(Delta xi) in(2). Each measured channel must genuinely use
the same two endpoints and fixed measurement operator. A fixed-laboratory-lag
DLS observable has two endpoint shifts; treating it as an instantaneous mean
without these terms is invalid. Fast thermo-optic/elastic terms also require
calibration or must be retained as additional response directions.

Falsifiable operation: freeze the clock and masters on unperturbed calibration
histories, return compared samples to common readout T/stress, apply the same
weak pulses and measure at common endpoints. Test W and the full frozen TN
history-kernel prediction separately. A response difference predicted by the
old TN convolution is memory with a useful common clock, not a clock failure.

4. A simple recurrence can reject a monotone clock without identifying z

Suppose the tested null is C(t0,t)=F(xi(t)-xi(t0)) with xi increasing and an
independently verified strictly decreasing master F over the relevant window.
For t0<t1<t2 it implies C(t0,t2)<=C(t0,t1). A registered recurrence exceeding
the two measurement-error bounds rejects this null directly. There is no need
to infer a hidden displacement coordinate, factor a self ISF, or reconstruct
xi. Oscillatory equilibrium masters, readout/contrast changes and unregistered
reciprocal-space/beam motion are outside that null and must be tested.
This is conventional echo logic as a clean negative clock test. It does NOT
identify an elastic mechanism or certify a universal clock's failure for
other observables. Positive physical explanation has stricter requirements.

6. When can a measured mean certify displacement-field return?

On a finite linearized REACHABLE strain-mode space e, let y=B e be all
calibrated mean proxies, and A e the displacement/density-mode change needed
for a chosen echo claim. A finite constant kappa satisfying
  ||A e||<=kappa||B e|| for every reachable e              (5)
exists iff ker(B) is contained in ker(A) on that space. Equivalently A=L B.
Necessity follows by taking Be=0. For sufficiency define L(Be)=Ae; the kernel
condition makes it well-defined and finite dimension makes it bounded. The
optimal Euclidean constant is ||A B^+|| on the measured range. This is standard
linear observability/factorization algebra, not a new general state theory.

If a zero-mean heterogeneous/shear mode has Be=0 but Ae!=0, no improvement
in scalar mean precision certifies field return. For example B=(1,1) misses
e=(1,-1), which is visible to A=(1,-1). Volume/FSDP mean matching therefore
requires an independently established lifting bound; the source experiments
do not supply one. Full temporal/probe observability can enlarge B, but that
information must actually be measured and calibrated. In an infinite-dimensional
space, kernel inclusion alone is insufficient: a bounded lifting/closed-range
condition must additionally be established.

With measurement error epsilon_y, a justified finite bound gives
  ||Ae||<=kappa(||delta y_measured||+epsilon_y),
plus any independently bounded mode-model error. Turning this into a coherent
intensity interval requires the actual forward map(3)-(4) or a controlled
density-sensitivity bound. It is not supplied by a self-ISF formula.

Save SUPPORT_NONLINEAR.txt; no new agents.”

Verdict

The finite-amplitude max/min assertion is valid under the stated positive-current premise, provided L is a graph Laplacian with nonnegative edge weights and the same increasing eta is used at all nodes. The proposed Robin comparison works at the actual common drive V. It does not require eta to be convex and does not require entrywise reasoning about Z. The constrained gradient identity is also exact, but its mobility has an overall factor nu*j0 unless time/current has been normalized to absorb it. Exponential decay follows with an additional finite upper bound on the state-dependent metric; R′≥alpha supplies strong convexity, not by itself a uniform lower bound on mobility. With physical smooth kinetics and a finite initial state range, this metric bound is available. Under the literal assumption “eta increasing” alone, a cusp at j0 gives a valid subexponential counterexample.

1. Finite-amplitude maximum principle

Write R_i=R(h_i) and Φ_i(j)=R_i j+eta(j) for j≥0. Since R_i>0 and eta is nondecreasing, Φ_i is strictly increasing; let F_i=Φ_i⁻¹ on nonnegative potentials. From u=V1−Zj and Y=gI+L, Y1=g1 and YZ=I imply

  j + g u + L u = g V 1,
  F_i(u_i)+g u_i+(Lu)_i=gV.

The second line is the semilinear discrete Robin equation. For a uniform resistance R*, define u*=Φ_* (j*) and the uniform solution at the same V by

  j*=g(V−u*), equivalently F_*(u*)+g u*=gV.

It is unique because j↦R*j+eta(j)+j/g is strictly increasing. Positivity of the actual j gives u_i=Φ_i(j_i)>0 and V>0, so the comparison root has j*>0 as well.

Let Rmax=max_i R_i. Since R_i≤Rmax, F_i(u)≥Fmax(u) for u≥0. Suppose u−u* has a positive maximum at node i. The graph Laplacian obeys (L(u−u*))_i≥0 at that node, while F_i(u_i)>Fmax(u*) and g u_i>g u*. Their sum would exceed gV, contradicting the Robin equation. Therefore u_i≤u* for every node. At any maximum-height node i, R_i=Rmax, so j_i=Fmax(u_i)≤j*.

Summing the Robin equation and using 1ᵀL=0 gives

  j0 = (1/N)Σ_i j_i = g(V−ū).

Since ū≤u*, j0≥g(V−u*)=j*. Thus every maximum-height node has j_i≤j0 and hdot_i≤0.

For the minimum, set Rmin=min_i R_i. Now R_i≥Rmin implies F_i(u)≤Fmin(u). If u−u* had a negative minimum, then (L(u−u*))_i≤0 there, F_i(u_i)<Fmin(u*), and g u_i<g u*, contradicting the equation. Thus u_i≥u* everywhere. At a minimum-height node j_i=Fmin(u_i)≥j*. Also ū≥u*, so j0≤j*. Hence hdot_i≥0 at every minimum-height node.

For differentiable h(t), the upper right Dini derivative of M(t)=max_i h_i(t) is the largest hdot_i among active maximizers, so D⁺M≤0. The corresponding lower Dini derivative of min_i h_i is nonnegative. Ties are covered by the same pointwise comparisons. The mean-zero constraint is preserved because Σ_i hdot_i=nu(Σ_i j_i−Nj0)=0. This proves the claimed global finite-amplitude extrema monotonicity for as long as the positive-current solution exists.

The essential structure is the monotone semilinear operator F_i(u_i)+g u_i+(Lu)_i with L satisfying the discrete maximum principle. The claim can fail if the shared bulk operator is not an M-matrix/graph Laplacian, if columns have differing kinetic laws, or if some j_i cross zero so the stated positive branch/inverses are unavailable. The fixed-V comparison also relies on comparing with the uniform-Rmax/min system at the same V; comparing at the same imposed mean current is not the maximum-principle step.

2. Exact constrained gradient identity

Let P=I−11ᵀ/N and δj=j−j0 1, so δj∈1⊥. Define the secant

  eta_sec,i = [eta(j_i)−eta(j0)]/(j_i−j0)

when j_i≠j0, and use any nonnegative finite value at equality (eta′(j0), if it exists). Let

  M = Z + diag(R(h_i)) + diag(eta_sec,i),
  E(h) = Σ_i ∫₀^{h_i}[R(v)−R(0)]dv.

Subtracting the uniform constants in V1=Zj+R(h)⊙j+eta(j) and projecting gives the exact identity

  (PMP)|_{1⊥} δj = −j0 P[R(h)−R(0)1].

Here Z is symmetric positive definite, R_i>0 and eta_sec,i≥0, so PMP is positive definite when restricted to 1⊥. Since hdot=nu δj,

  hdot = −nu*j0 [(PMP)|_{1⊥}]⁻¹ P∇E,
  dE/dt = −nu*j0 (P∇E)ᵀ[(PMP)|_{1⊥}]⁻¹(P∇E) ≤ 0.

Thus it is an exact constrained gradient flow. The mobility as written in the assignment omits the common scalar nu*j0; it is correct after rescaling time by nu*j0 (or absorbing that scalar into the mobility). The secant representation is algebraic and does not need eta to be linear.

3. Exponential rate and its required bound

If R′(h)≥alpha>0 throughout the feasible height interval, E is alpha-strongly convex on 1⊥, with minimizer h=0. The strong-convexity inequality gives ||P∇E||²≥2alpha E. If the restricted metric has a finite upper eigenvalue M_P≤Lambda I along the trajectory, then

  dE/dt ≤ −(nu*j0/Lambda)||P∇E||²
         ≤ −(2*nu*j0*alpha/Lambda)E.

Hence E(t)≤E(0)exp[−2*nu*j0*alpha*t/Lambda]. The extrema result keeps all h_i between their initial minimum and maximum. Positive currents and fixed total give 0<j_i<Nj0. Therefore Lambda is finite for smooth R and eta with bounded secant slopes on these compact reachable ranges; for example one can take

  Lambda = ||Z||₂ + sup_{h∈[m(0),M(0)]}R(h)
                    + sup_{j∈[0,Nj0]}|eta_sec(j,j0)|.

This rate is initial-range/kinetics dependent. The statement R′≥alpha alone does not bound eta_sec. If eta is only increasing, no exponential-in-time guarantee follows.

Explicit cusp counterexample to exponential decay under only monotonic eta: take N=2, L=0, g=1, j0=nu=1, and for |h|<1 set R(h)=2+h, so R′=1 and R>0. For j≥0 set

  eta(j)=j + sgn(j−1)√|j−1| + 1,

with the value at j=1 defined continuously. This eta has eta(0)=0 and is strictly increasing, but has unbounded secant slope at j0=1. Start h=(a,−a) with small a>0. The fixed-current constraint gives j1=1−x, j2=1+x. Equality of the two common-V branch equations V=(R(h_i)+1)j_i+eta(j_i) reduces exactly to

  sqrt(x)+4x=a.

Thus x/a²→1 as a↓0 and adot=−x∼−a². The energy is E=a², so E(t) decays asymptotically as t⁻², not exponentially. This does not apply to smooth Butler–Volmer kinetics; it identifies the missing regularity/finite-metric condition in the literal monotonicity-only claim.

4. Provided pore-resistance law

For the supplied straight-pore cell, with fixed solid volume/area s, remaining thickness d=d0−h and porosity epsilon=1−s/d, the stated resistance is

  R(h)=d²/[k_l(d−s)].

Differentiating with respect to h gives

  dR/dd = d(d−2s)/[k_l(d−s)²],
  R′(h)=−dR/dd = d(2s−d)/[k_l(d−s)²].

Consequently R′>0 for s<d<2s, R′=0 at d=2s, and R′<0 for d>2s; R diverges as d↓s. This checks the monotonicity window in the assignment. In the physical pore interpretation, the resistance blow-up is a finite-connectivity limit, and the continuum derivation does not resolve discrete pore closure or interface mechanics.

Scope: the maximum/minimum theorem and gradient identity are exact for the finite graph-column model written here. They do not establish a pore-scale mechanism, a material response law, a stability result outside the positive-current regime, or physical compatibility of the column approximation.

5. Follow-up audit: common Euclidean variance under switching

The stronger contraction in CONSTRUCTION.txt §3 is correct for the stated reciprocal network. With positive secants D_i, let K=Z+diag(D), M=K^{-1}, v=M1, and A=M-vv^T/(1^Tv). Put B=Y+diag(D^{-1})=gI+L+diag(D^{-1}). This is a symmetric positive definite nonsingular M-matrix, so B^{-1} is entrywise nonnegative with positive diagonal. Woodbury gives

  M=D^{-1}-D^{-1}B^{-1}D^{-1},
  v=D^{-1}[1-B^{-1}D^{-1}1]
   =D^{-1}B^{-1}(B1-D^{-1}1)
   =g D^{-1}B^{-1}1 > 0.

Thus M_ij<=0 for i!=j, and A_ij=M_ij-v_i v_j/(1^Tv)<0. Also A is symmetric and A1=0, so it is a (complete, possibly weighted) graph Laplacian. From f(j_i,h_i)=D_i(j_i-j0)+Q(h_i), the fixed-total-current constraint gives delta j=-A Q(h); no sign assumption on j0 enters this algebra beyond D_i>0. Consequently

  h^T A Q(h)=sum_{i<j}(-A_ij)(h_i-h_j)(Q(h_i)-Q(h_j)).

If Q is increasing, the Euclidean variance is nonincreasing. If Q is uniformly strongly increasing with slope at least alpha_Q, then h^T A Q>=alpha_Q h^T A h. On 1-perp, A is the inverse of P K P: P K A x=x for x in 1-perp. Since lambda_max(PKP)<=lambda_max(K)<=Dmax+||Z||_2, lambda_min(A|1-perp)>=1/(Dmax+||Z||_2). Therefore

  d(||h||^2/2)/dt <= -nu*alpha_Q/(Dmax+||Z||_2) ||h||^2,

which yields exactly the factor 2 in the exponent for ||h||^2 stated in equation (7). Units are consistent: nu*alpha_Q/(resistance) has inverse-time units when Q is a voltage and D,Z are differential resistances.

There is no Lyapunov-metric switch penalty when the global phase parameters jump: h and ||h||^2 remain continuous, and the differential inequality holds almost everywhere in each phase. To integrate it, alpha_Q and Dmax must be bounded phasewise (or have a finite integrated rate bound); this is explicit in (7). A phase jump that mechanically moves the interface would violate the model's continuous-h assumption and is not covered. The script's graph_identity() numerically checks one positive-current instance; the algebra above is the sign-independent check.

Crucially, negative j0 is not by itself stabilizing. For the particular branch f(j,h)=eta(j)+jR(h), Q'(h)=j0 R'(h). The criterion Q'>0 holds on both signs only if the operating geometry makes R' have the same sign as j0 (as in the separately selected compression/expansion windows in §6). At fixed R'>0, reversing j0 makes Q decreasing; the pairwise argument then points the other way and provides no contraction. This common-variance theorem is a conditional network result, not a physical validation of hydraulic phase switching.

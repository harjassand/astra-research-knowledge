Outcome
Derived and checked a deterministic quantum recovery operation for known cubic
phase kernels with commuting local dephasing, together with a robust generic
lower bound on all-trusted implementation. The result is a CONDITIONAL trusted-
control tradeoff. It uses established coherent-check machinery; equally informed
CPC/quantum-filter methods tie the protocol. No new hardware, total-runtime,
energy or incumbent-superiority claim is established. Priority is unestablished.

Closed operation
For U_f|x>=(-1)^f(x)|x>, f cubic overF2, use r=ceil(log2(n+1)) protected syndrome
qubits. H's nonzero binary columns label each single-Z error. Output checks are
X(H_row); prechecks are U_f†X(H_row)U_f. Controlled pre/post checks around ONE
ordinary native invocation write the syndrome independently of an arbitrary
logical input/reference; feedforward Z correction retains every outcome. Any
coherent Kraus span{I,Z_i} is corrected exactly. This is ordinary syndrome
recovery expressed as a known CPC/PCS superchannel, not a new Hamming code.

Native error class is DERIVED, not replaced by one output fault
Specified native Hamiltonian H_f=(pi hbar/tau)sum c_ijk N_i N_j N_k, with local
Markovian Lindblad terms gamma_i(t)(Z_i rho Z_i-rho), commutes throughout. It
therefore implements U_f followed by independent Z flips
p_i=(1-exp(-2 int gamma_i))/2. Full residual normalized diamond error is exactly
the probability of>=2 net flips, bounded by sum_(i<j)p_i p_j. Internal X/Y or
leakage noise is not covered: an X fault generally grows a suffix quadratic phase.

Load-bearing representation and costs
The discrete derivative f(x+q)+f(x) is quadratic. Its polar form has rank2s;
a binary basis change gives s<=n/2 quadratic pairs. Each CONTROLLED precheck
uses at most n/2 CCZs, O(n²) Clifford gates, plus controlled-X and postcheck.
Total trusted control: O(n log n) CCZ-equivalents, O(n²log n) Clifford primitives,
O(log n) protected qubits, with readout/reset/feedforward and idle errors paid.
Known f's Theta(n³)-bit description and O(n³log n) classical compilation remain
counted. Dense monomial count is NOT an optimal T-count: clean synthesis can
use O(n²) CCZs with Clifford volume separate.

For a fixed finite bounded-arity all-trusted gate alphabet, fixed simple ancillas
and polynomial workspace, MOST cubic U_f require Omega(n³/log n) expected quantum
primitives at any fixed normalized diamond tolerance epsilon<1/16, including
adaptive measurements/classical branching. Proof: distinct cubic targets have
Choi overlap<=3/4 (nonzero degree3 Boolean polynomial weight is between1/8 and7/8).
An epsilon-accurate channel has average Kraus-branch Choi infidelity<=epsilon.
Markov on infidelity and runtime leaves a branch of length<=4G and fidelity
>=1-2epsilon; one branch cannot approximate two such targets. There are only
2^(O(G log n)) bounded-arity paths. Final discarded-ancilla refinement adds only
O(G) bits because only O(G) ancillas were touched. This excludes free arbitrary
resource states, analog angles and coherent classical lookup. It compares resource
classes, not two algorithms supplied the same native device.

Actual useful accuracy and native hardware boundary
Full error bound is sum_(i<j)p_i p_j+sum eta_trusted/idle+mu_native_model.
For p_i<=.1/n and total remaining error<=.01, it is<=.015<1/16, so the trust
tradeoff concerns the same nonvacuous approximate quantum-output task.
Quality inputs are supplied physical specifications, not acquired gate calibrations.

Native hardware is substantial: m_f nonzero cubic couplers, action pi hbar m_f,
operator norm pi hbar m_f/tau and maximum site incidence D_f. A local sum-strength
bound J forces tau>=pi D_f/J. Generic dense f has m_f~n³ and D_f~n²; at fixed
dephasing rate this destroys the small-error regime as n grows. Maintaining
p~1/n requires gamma=O(J/n³) at fastest bounded-strength operation. Protected
memory coherence, geometric routing, native calibration/temperature and reset
energy are additional costs. Worst-case per-coupler phase tolerance is
O(mu_native/m_f). No scalable fixed-quality physical platform is supplied.

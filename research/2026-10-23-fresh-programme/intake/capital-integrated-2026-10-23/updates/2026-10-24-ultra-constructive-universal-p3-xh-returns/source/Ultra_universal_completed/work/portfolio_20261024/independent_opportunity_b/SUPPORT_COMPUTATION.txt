AUTONOMOUS FLAGGED UNITARY: BOUNDED OPPORTUNITY CHECK
24 October 2026

Status
------
A concrete exact operation exists in the supplied local clock model: any
compiled unitary U can be applied on a known direction sector while a finite
clock returns exactly, if the output includes a flipped direction bit. Its
inverse acts on the opposite direction sector. This is a real extension of
the useful input/output interface, not a speedup over the ordinary circuit
model. The only surviving opportunity is conditional on a platform where
fixed local couplings are materially easier than gate-by-gate control. No
physical platform, calibrated couplings, or advantage has been acquired.

Substrate read and comparator
-----------------------------
I used the older Astra source
`work/portfolio_20261024/autonomous_depth/sol_involution_clock/REUSABLE_INVOLUTION_CLOCK.txt`
as the construction substrate. It proves an exact time-independent nearest-
neighbor cycle whose clock returns at T=pi/(2 alpha) and applies any
Hermitian involution W to arbitrary data. Its local example compiles a
multi-controlled phase with clean work. It already includes finite clock
length, local dimension, operator norm, and linear-time scaling; I do not
claim those results as new here.

The governing incumbent is strong. Feynman's clock construction is a
reversible Hamiltonian computation with a moving program counter
([Feynman 1986](https://doi.org/10.1007/BF01886518)). Engineered spin-chain
couplings already give fixed-Hamiltonian perfect transfer over arbitrary
linear-chain distance ([Christandl et al. 2004](https://doi.org/10.1103/PhysRevLett.92.187902)). The ordinary gate model computes U directly, cleanly, and can repeat it. Qubitization/QSP gives an efficient standard circuit interface for unitary-derived transformations ([Low and Chuang 2019](https://doi.org/10.22331/q-2019-07-12-163)). The question here is narrower: can the returned-clock theorem expose a useful general unitary interface without time-dependent gate switching?

Exact flagged operation
-----------------------
Let U be any unitary on data, and let d be one direction qubit. Define

  V_U = |0><0|_d tensor U + |1><1|_d tensor U^dagger,
  W_U = (X_d tensor I) V_U
      = |1><0|_d tensor U + |0><1|_d tensor U^dagger.

Then W_U^dagger=W_U and W_U^2=I. The identities follow directly from
X V_U X=V_U^dagger. Thus W_U is in the exact domain of the returned-clock
theorem. For any input |0>_d tensor |psi>, one clock period gives

  |0>_clock |0>_d |psi>
    -> (-i)^L |0>_clock |1>_d U|psi>.

For an input with d=1, it returns d=0 and applies U^dagger. The clock is
returned exactly and may be reused. The flag is part of the declared output;
it is not erased for free. Repeating this same period toggles the flag and
applies U^dagger on the second call, so the second call undoes the first. This
is not a clean, repeat-forward U oracle.

A local circuit U=G_s...G_1 of s gates yields a circuit for V_U as the
product C_1(U^dagger) C_0(U), where C_0(U)=|0><0| tensor U + |1><1| tensor I
and C_1(U^dagger)=|0><0| tensor I + |1><1| tensor U^dagger. Each controlled
block uses s gate locations; the inverse block runs the inverse gates in
reverse order. Append X_d to obtain W_U. Count routing of d and controlled-gate
decomposition in S, the actual local gate count. The resulting Hermitian
involution has a reversible local factorization and can be assigned to the
cycle edges. If the flag cannot be routed locally with finite cost, this
compilation is not an acquired interface.

Finite clock and precision costs
--------------------------------
For L>=3 edges, use the source's coefficients

  w_0=w_(L-1)=alpha sqrt(L/2),
  w_j=alpha sqrt((j+1)(L-j))  for 1<=j<=L-2.

The maximum is w_max=alpha sqrt(floor((L+1)^2/4)). Set w_max=J, where J is
the available local angular-frequency scale. Then

  T=pi/(2 alpha)=pi sqrt(floor((L+1)^2/4))/(2J)
    = pi L/(4J)+O(1/J).

The cycle uses L clock states and L weighted local edge terms. In a one-head
local encoding, this is O(L) constant-size cells; it is not a free clock
register or free initialization. The source's clock-sector norm obeys
||H||/hbar <= alpha L, so ||H||T/hbar <= pi L/2. The elapsed time and
integrated action are linear in circuit length, like a sequential gate
implementation.

There is a useful explicit finite-precision bound. Let each edge weight have
absolute error at most delta, and each programmed edge unitary have operator
error at most eta_g. On the cycle, each vertex has two incident edges, so a
block row-sum bound gives

  ||H_hat-H||/hbar <= 2 max_j(delta + w_j eta_g)
                    <= 2(delta+J eta_g).

Duhamel's bound at the intended time gives

  ||exp(-i H_hat T/hbar)-exp(-i H T/hbar)||
       <= 2 T (delta + J eta_g).

To guarantee operator error at most epsilon, it suffices that
`delta + J*eta_g <= epsilon/(2T)`, i.e. absolute coupling precision
`delta/J = O(epsilon/L)` and edge-gate accuracy `eta_g=O(epsilon/L)`.
This costs O(log(L/epsilon)) bits per coupling/edge accuracy, plus O(L) such
settings and the finite circuit description. This assumes approximate edge operators remain unitary so the Hamiltonian
remains Hermitian. The bound is conservative and is only on the invariant
one-head sector. Timing error is also finite:
`||H||*|Delta T|/hbar <= alpha L |Delta T|`; the start and read time still
need a supplied clock/timer. No robustness against drift or leakage outside
the one-head sector is established.

Incumbent comparison and decision
---------------------------------
The ordinary reversible circuit implements U with no output flag, no extra
clock cells, and approximately s gate locations; its gate-model capability
strictly dominates the flagged output contract. Feynman-style static
computation already supplies an autonomous clock but normally advances the
clock to a different endpoint; perfect-transfer chains provide the transport
part but not this exact returned-clock computational action. The Hermitian
dilation plus the Astra involution clock composes those known ingredients to
obtain the flagged interface, at O(s) elapsed time, cells, and local terms.
It gives no query, gate-count, or asymptotic time advantage and adds a
precision-calibrated coupling array. Repeated forward U calls require
additional direction-control/reset work.

Therefore this is not a general quantum-computation opportunity. It is a
conditional static-control operation: worth pursuing only if an actual
platform provides the required local gate-labeled edges and direction routing
more easily than externally scheduled gates, while meeting the O(epsilon/s)
precision and return/leakage requirements. Without that platform condition,
the incumbent wins and this candidate should be parked rather than promoted.

STOPPED-PROGRAM QUOTIENT-NORM BOUND — INDEPENDENT CHECK
2026-10-24

Verdict
The O(e/delta) terminal-instrument perturbation bound is valid under the
instrument-summed error and quotient-invariance conditions stated below. The
resolvent subtraction using the TRUE post-completion instrument O is the key:
it avoids paying a second 1/delta factor. No CP realization or learned CP gauge
is needed for this linear stability statement. The learned maps are formal
linear predictors and need not themselves define probabilities.

1. Operational quotient and norm comparison

Let R be the real Hermitian reachable space of the true hidden instrument
model. Let N consist of elements annihilated by every future action/outcome
test, including the empty test. This is a linear subspace invariant under each
true outcome map T_(a,o): if n is invisible to every future test, then T_(a,o)n
is too, since prepending (a,o) to any future test is again a future test.
Thus the maps descend to R/N. Define

  ||[X]||_Q = inf_{n in N} ||X+n||_1,
  ||x||_infinity = sup_f |f(X)|,

where f ranges over the same future tests and f(X)=Tr(F_f X). Each F_f is an
effect (0 <= F_f <= I), so for every representative X+n,
|Tr(F_f(X+n))| <= ||X+n||_1. Taking the supremum and then the infimum gives
||x||_infinity <= ||x||_Q.

For the upper bound, assume the r core history states [rho_j] are a basis of
the entire quotient R/N, not merely that a selected r-by-r submatrix happens
to be nonsingular. Let p_j=Tr(rho_j)<=1, let f_i be the core tests, and
H_ij=f_i(rho_j), with sigma_min(H)>0. Write [X]=sum_j c_j[rho_j]. Then
Hc=(f_i(X))_i, hence

  ||[X]||_Q <= sum_j |c_j| ||[rho_j]||_Q
             <= ||c||_1
             <= sqrt(r)||c||_2
             <= sqrt(r)||Hc||_2/sigma_min(H)
             <= r ||x||_infinity/sigma_min(H).

The second inequality uses ||[rho_j]||_Q<=||rho_j||_1=p_j<=1; the last uses
that each core prediction is included in the infinity norm. This proves the
claimed kappa<=r/sigma_min(H), with the specified normalization. If core
states have only a known mass bound p_max rather than p_j<=1, multiply kappa
by p_max. If the core does not span R/N, the upper comparison does not follow.

2. True instrument contraction

For a fixed action a, the outcome maps form a CP instrument:
sum_o T_(a,o) is trace preserving. For Hermitian Y,
sum_o ||T_(a,o)Y||_1 <= ||Y||_1 (trace-norm contraction of the direct-sum
instrument). For any n in N, each T_(a,o)n lies in N. Therefore

  sum_o ||[T_(a,o)X]||_Q
   <= sum_o ||T_(a,o)(X+n)||_1
   <= ||X+n||_1.

Infimize over n. Thus the full action/outcome map contracts the direct-sum
quotient norm (l1 over classical branches, Q on each branch). The result
extends to a finite classical controller by lifting its classical register
into the direct sum; random action choices are convex mixtures. Invariance of
N is essential for maps on the quotient to be defined.

3. Stopping and perturbation

Use column-state convention. Let M be the one-step continuation/terminal
instrument before the stop coin; it is a contraction in the full
instrument-summed norm. Before each step, abort with probability delta and
retain the current memory/register as a labelled terminal outcome. The abort
branch is exact and identical in both models. Write K=(1-delta)M for the
continuation map and E for the combined terminal map (abort plus all terminal
outcomes at this step). The complete true terminal instrument O obeys

  O = E + O K,

where maps compose right-to-left: K acts first, then O. Since the terminal
outcomes of the actual process form a complete CP instrument, ||O||<=1 in the
direct-sum quotient norm. Also ||K||<=1-delta.

Assume the learned primitive has error e in the *instrument-summed* operator
norm on this same quotient: summing the induced Q norms over all its mutually
exclusive action/outcome/controller branches is <=e. The abort coin and its
label are exact. Then ||Khat||<1 provided

  (1-delta)(1+e)<1, equivalently e<delta/(1-delta),

and the learned linear terminal map exists uniquely as the convergent
resolvent Ohat=Ehat(I-Khat)^(-1). This uses only operator norms; Ehat,Khat and
Ohat need not be CP or positive.

Subtract O=E+OK and Ohat=Ehat+Ohat Khat. With Delta denoting learned minus
true,

  Delta O = Delta E + O Delta K + Delta O Khat,
  Delta O = (Delta E + O Delta K)(I-Khat)^(-1).

The combined branch error is at most (1-delta)e: the abort component has zero
error, and the nonabort terminal-plus-continuation components are a subset of
the instrument-summed one-step error after multiplication by the nonabort
probability. Using ||O||<=1 gives
||Delta E+O Delta K|| <= ||Delta E||+||Delta K|| <= (1-delta)e. Also

  1-||Khat|| >= 1-(1-delta)(1+e) = delta-(1-delta)e.

Consequently

  ||Ohat-O|| <= (1-delta)e/[delta-(1-delta)e].

For e<<delta this is (1-delta)e/delta + O(e^2/delta^2), hence O(e/delta).
The improvement over a crude O(e/delta^2) estimate comes from multiplying
the local continuation error by the contractive true O before taking the
single learned-resolvent factor.

4. Scope conditions / failure modes

* “Error e” must mean the l1-summed direct-sum instrument error, not the
  maximum error of an individual outcome branch. A per-branch maximum e0 over
  m branches only yields a summed bound up to m e0 (or a sharper declared
  aggregate), which must replace e throughout.
* The exact abort branch is required for the discounted numerator. If it is
  itself learned with error, that error is not automatically multiplied by
  1-delta and must be added separately.
* The learned maps must be operators on the same quotient (or on a common
  coordinate space with the stated operator-norm guarantee). If raw learned
  maps are applied to representatives but fail to preserve N, their quotient
  operator and this bound are undefined. This is an interface condition, not
  a CP-gauge condition.
* O must include every terminal branch, including abort, and retain whatever
  memory/controller state the promised predictive continuation observes. A
  scalar success probability alone is not the full terminal instrument.
* A finite controller with a fresh independent abort coin per attempted
  primitive has the stated K=(1-delta)M. Correlated stopping rules or a coin
  only at controller cycles need a separate bound on the continuation norm.
* The result bounds finite linear predictions in Q norm. It does not show
  learned predictions are nonnegative, that a CP quantum realization exists,
  or that physical memory has been reset.

Conclusion: PASS with the stated operational-quotient, complete-instrument,
exact-stop, and aggregate-error hypotheses. The advertised O(e/delta) bound is
correct; the essential caveat is to state “instrument-summed” quantitatively
and keep the true and learned maps on the same invariant quotient.

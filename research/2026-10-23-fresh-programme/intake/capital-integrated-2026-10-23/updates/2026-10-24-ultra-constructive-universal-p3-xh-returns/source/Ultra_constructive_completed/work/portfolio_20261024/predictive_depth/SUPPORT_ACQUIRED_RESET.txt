OPERATIONAL RESET WORD: REPEATED-HISTORY SAMPLING
Bounded derivation; 24 October 2026

Result
======
A data-certified contraction of a legal nonselective word R gives a useful operational reset without resetting the hidden bath. If each trial begins by applying R^k and the contraction is uniform over every reachable conditional predictive state, then each bounded event's conditional probability lies within epsilon_reset of its stationary post-R value. The empirical event frequency obeys a martingale-Hoeffding bound with this one additive bias, independent of the number N of trials. This avoids an N epsilon_reset term for estimating a single event probability. It does not make the full N-trial law close in total variation to an iid law; that distance can grow with N.

Exact predictive-coordinate calculation
========================================
Use normalized predictive coordinates x=(m,u), m=1. The legal nonselective word has block form

    R = [[1, 0], [b, D]],       ||D||_infinity <= q < 1.

Thus u maps to b+Du. Since q<1, I-D is invertible and the unique fixed predictive coordinate is

    u_* = (I-D)^(-1)b.

After k applications,

    u_k - u_* = D^k (u_0-u_*),
    ||u_k-u_*||_infinity <= q^k ||u_0-u_*||_infinity.

Let Rch be the full reachable class of predictive states that may occur immediately before a trial's reset word, including states conditioned on every recorded prior event/outcome. Require a finite uniform bound B = sup_{x in Rch} ||u(x)-u_*||_infinity. If the quotient norm comparison gives operational distance d_Q(x,y) <= kappa ||u(x)-u(y)||_infinity, then after the word

    d_Q(R^k x, x_*) <= epsilon_reset := kappa B q^k,

where x_*=(1,u_*). Cap epsilon_reset at 1 if desired. Here d_Q must control every allowed bounded event probability: |p_G(x)-p_G(y)| <= d_Q(x,y). If the quoted Q-distance is instead a trace norm, include the usual measurement-to-probability factor in kappa.

The fixed point is the stationary state of the stroboscopic nonselective word on the finite operational quotient. For an actual CPTP word on a finite-dimensional physical state space, an invariant state exists; contraction makes its predictive image unique. This says nothing about convergence of the microscopic bath state. Hidden distinctions that no allowed future experiment can read may remain. If the experiment is periodically driven, apply R at the same clock phase each trial and define x_* for that stroboscopic map.

Sequential sampling guarantee
=============================
After each prior trial, apply the same nonselective R^k, then perform one fixed event test G with indicator Y_i in {0,1}. Let F_(i-1) contain all recorded history before this reset word. Assume: (1) the conditional predictive state given F_(i-1) belongs to Rch; (2) R's internal branch labels are not recorded or conditioned on, or the contraction is separately certified for each recorded branch; (3) the event test and timing are identical each trial. The conditional event probability is

    mu_i = E[Y_i | F_(i-1)],       |mu_i - p_*| <= epsilon_reset,
    p_* = p_G(x_*).

The variables Z_i=Y_i-mu_i are martingale differences. Conditional on F_(i-1), Z_i lies in an interval of length 1. Hoeffding's martingale inequality therefore yields, for every t>0,

    Pr( |(1/N) sum_i Y_i - p_*| >= epsilon_reset + t )
       <= 2 exp(-2 N t^2).

Equivalently, with probability at least 1-alpha,

    |Ybar-p_*| <= epsilon_reset + sqrt(log(2/alpha)/(2N)).

This remains valid when the trial outcomes are correlated through the hidden memory: the conditional-mean error contributes at most epsilon_reset to the average pathwise, and only the centered martingale term needs concentration. There is no union bound over the N trials. For M event types, a simultaneous guarantee can use alpha/M in the tail term (or another suitable vector concentration bound); the reset bias remains additive per event.

Why this is not an iid or trajectory-TV claim
=============================================
A bound on every one-step conditional probability gives concentration of an average around p_*. It does not bound the total variation distance between the whole N-outcome sequence and N iid draws by epsilon_reset. For example, if all conditional probabilities equal p_*+epsilon_reset, the mean is biased by epsilon_reset for every N, while the sequence laws can become nearly perfectly distinguishable as N grows. Do not use this theorem to replace the actual adaptive process by an iid simulator for arbitrary downstream decisions.

Reset failures and observation of the reset
===========================================
If each attempted reset word is certified to fail with conditional probability at most rho from every state in Rch, and on failure the event probability is unconstrained, then for trials that are still included in the data the safe conditional bias is

    epsilon_total <= min(1, epsilon_reset + rho).

The same martingale inequality holds with epsilon_total. This assumes the failure probability bound is conditional on the recorded past; a marginal average failure rate is insufficient. A failure branch that is detected and excluded requires a separate guarantee for the successful-reset map and its state-dependent acceptance rule, plus an accounting of the rejected attempts. If the reset's outcome labels are visible, contraction of the nonselective average alone does not control the state conditioned on those labels; certify branchwise contraction or hide/ignore those outcomes as required by the protocol. A reset error already included in the measured full nonselective map should not be charged again as rho.

Acquisition contract and limits
===============================
The premise ||D||_infinity<=q must be a valid upper certificate for the true map on the entire reachable quotient, in a fixed coordinate basis; a fitted point estimate is not a certificate. The reachable-class radius B and norm-comparison constant kappa must also be known bounds. If q or these bounds are estimated with confidence 1-alpha_cert, combine that failure probability with sampling alpha, for example by a union bound. A finite list of tested directions does not establish a uniform operator bound unless the quotient has been fully spanned or a justified confidence/structural argument covers the remainder. The fixed point and p_* likewise refer to the true map; using fitted values adds model-estimation error separately.

This is operational mixing in a finite predictive representation, not a physical bath reset, not an assertion that microscopic correlations vanish, and not by itself a low-cost acquisition result. The reset cost is k word executions per trial, so the direct experiment uses Nk executions plus the event tests, with any reset failures/retries counted. If q is close to one, achieving epsilon_reset <= epsilon requires k >= log(kappa B/epsilon)/log(1/q), for kappa B>epsilon. No reset word, contraction certificate, or data were physically acquired in this derivation.

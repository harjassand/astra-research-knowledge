ADAPTIVE TERMINAL-LAW PERTURBATION BOUND
Bounded audit of SUPPORT_ALTERNATIVE.txt; 24 October 2026

Verdict
=======
The proposed bound is valid under an instrument-level error contract and a norm compatible with composition. It is uniform over every finite classical controller because the direct-sum norm does not depend on the number of controller states. Row normalization alone is insufficient: the primitive approximation error must control the *joint branch instrument*, not only its nonselective channel or each branch separately. The fitted model need not be CP; small complete-map error and the forced-abort margin make its linear completion a convergent resolvent.

Assumptions and notation
========================
Let V be the finite operational memory quotient with a submultiplicative induced trace norm. Include the finite classical controller register by direct sum. Terminal outputs retain the actual hidden quantum memory and include success/abort/controller labels. For a true physical completed terminal instrument O, assume ||O||<=1 in this quotient norm. This follows from complete positivity and trace preservation on the memory-plus-record output; more generally it is an explicit hypothesis of the claim.

Before each primitive, an externally fixed, model-independent coin aborts with probability delta in (0,1); write gamma=1-delta. The abort output is exact and retains memory. Conditional on not aborting, a true primitive instrument has terminal branches E_a and continuation branches M_b, where continuation b also selects the next finite controller state. M denotes the direct-sum continuation instrument and E the terminal part, including the exact forced-abort branch. The full true controller obeys

    O = E + O K,             K = gamma M.

The learned linear instrument has Ehat, Mhat, Khat=gamma Mhat and completion Ohat=Ehat+Ohat Khat. It is causal-row normalized but need not be CP. Assume its primitive error is at most e in the *joint instrument norm*: for every allowed input, including a reference if the contract is complete,

    sum_a ||(Ehat_a-E_a)(x)||_1 + sum_b ||(Mhat_b-M_b)(x)||_1
       <= e ||x||_1.

The same bound holds uniformly over controller states and their selected primitives. This is the needed meaning of “instrument error.” The forced-abort branch has zero approximation error. The operator and instrument norms must be the same compatible quotient/trace-norm family; a pointwise error on a few states is not enough.

Proof
=====
Let DeltaO=Ohat-O, DeltaK=Khat-K and DeltaE=Ehat-E. Subtract the two completion equations and add/subtract O Khat:

    DeltaO = DeltaE + O DeltaK + DeltaO Khat.

First, the exact abort branch contributes nothing to DeltaE. Every discrepancy in a primitive branch is incurred only after the coin permits execution, so it receives the factor gamma. On terminal branches the difference is just the instrument error; on continuation branches it is followed by the true O for the branch's next controller state. Each such O is contractive. Summing the branch norms is exactly why the joint instrument error is required. Therefore

    ||DeltaE + O DeltaK|| <= gamma e.

Second, the true continuation instrument is trace-nonincreasing, so ||M||<=1. The joint instrument error implies ||Mhat-M||<=e, hence

    ||Khat|| = gamma ||Mhat|| <= gamma(1+e).

If gamma(1+e)<1, equivalently e<delta/gamma, the learned completion has a convergent Neumann series and is unique. Taking norms in the difference identity gives

    ||DeltaO|| <= gamma e + gamma(1+e)||DeltaO||,

and thus

    ||Ohat-O|| <= gamma e / (1-gamma(1+e))
                 = gamma e / (delta-gamma e).

No contractivity of Ohat and no CP property of its primitive maps was used. The only role of row normalization is to keep the learned instrument's declared terminal/continuation accounting complete; the norm error and abort margin control its resolvent. The bound is independent of the number of finite controller states, the number of possible histories, and the hidden-memory dimension once the quotient norms and uniform instrument error are fixed.

As e tends to zero at fixed delta, this is gamma e/delta + O(e^2/delta^2). It improves the generic subtraction bound that charges an independent ||Ohat|| factor to the primitive error. It does not make the approximation uniformly useful as delta tends to zero: the learned continuation resolvent still has a gap delta-gamma e.

Exact failure if “instrument error” is weakened
================================================
Causality row normalization plus a maximum error per branch does not imply the bound uniformly over controllers. Here is an exact classical (hence also a diagonal quantum) counterexample.

Take a one-state memory, delta=gamma=1/2, and one primitive with N even mutually exclusive terminal outcomes. The true primitive distribution is uniform: p_i=1/N. The learned distribution is p_hat_i=2/N for i<=N/2 and 0 for i>N/2. Both rows sum to one, all learned branch probabilities are nonnegative, and every branch has absolute error at most e=1/N. There is no continuation after the primitive. With the exact forced-abort branch included, the total terminal total-variation distance is gamma times the primitive TV distance, namely gamma/2=1/4. The claimed expression using e=1/N is

    gamma e/(delta-gamma e) = 1/(N-1),

which is below 1/4 for N>5. Thus no bound uniform in outcome count follows from per-branch sup error, even for a finite controller and a causal, positive learned model. The example does not refute the result under joint instrument error. For classical branches the joint sum-of-trace-norm discrepancy used in the theorem is the L1 discrepancy, which equals 1 here (equivalently, primitive TV is 1/2), not 1/N; with the theorem's norm convention the required small-error premise fails. If one instead defines e using TV, the theorem's constants must be rescaled consistently. Similarly, error only on the nonselective channel is inadequate; branchwise differences can cancel in that channel and be separated by a controller that records the branch.

The forced coin and terminal output must also be in scope. If delta is miscalibrated or the learned model is allowed to perturb the abort branch, the numerator need not be gamma e. If the “abort” operation secretly resets/discards M while the intended device retains it, the model describes a different process. A finite-controller theorem cannot compensate for either interface mismatch.

Conditioning and costs
======================
The theorem controls the unconditioned complete terminal instrument. It does not remove rare-event costs. If a success subinstrument has true probability p>=p_min and the unnormalized success branch is within trace norm epsilon, its normalized conditional output is stable only at scale O(epsilon/p_min); for epsilon<p_min the direct algebraic bound is at most 2 epsilon/p_min. A non-CP fitted instrument may not define a physical conditional state at all, even though its unconditioned linear terminal map obeys the bound. Any empirical estimate of a probability-p success branch still needs order 1/p successful-prefix attempts, on top of the data required to reach the primitive error e.

Likewise, this is a terminal-law sensitivity theorem, not a runtime theorem. A single unit-cost geometric run stopped by the forced coin has expected primitive count gamma/delta. Total acquisition cost can be larger: for example, if attaining e requires O(delta^-1) independent trajectories, multiplying by O(delta^-1) steps per trajectory gives O(delta^-2) expected primitive exposure. Any such first-moment budget must be proved for the chosen data-collection rule separately; the terminal-law bound does not supply it.

Scope
=====
This proves the stated adaptive bound for a finite controller composed of primitives whose joint branch instruments satisfy a uniform error e in the complete, compatible quotient norm, with an exact forced-abort coin and retained memory. It does not certify that learned signed maps are physical, that the causal span/basis is identifiable from finite noisy data, that the full instrument error is acquired, or that conditional rare-history prediction is affordable. The exact branchwise counterexample marks the main contract ambiguity.

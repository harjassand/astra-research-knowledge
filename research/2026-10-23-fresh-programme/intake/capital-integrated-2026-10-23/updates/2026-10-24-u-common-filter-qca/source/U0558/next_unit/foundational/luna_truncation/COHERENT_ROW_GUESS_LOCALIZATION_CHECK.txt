COHERENT ROW-GUESS LOCALIZATION: OPERATOR CHECK
2026-10-24. Bounded constructive compatibility check.

Disposition
-----------
The proposed Bob-only localization is valid under its stated
factorization/source-null and PRESELECTION-error hypotheses. The key
inequality is an exact coherent-measurement comparison:
||U_D state - ideal true-row copy||^2 <= 2 e. A common Bob instrument
and accepted-output filter are contractions on both vectors, so the
same absolute error controls accepted mass and losing mass. No actual
access to Alice's row is used; the true-row copy exists only in the
comparison vector. If the acceptance predicates agree only source-null,
nullity must be certified under the COMPLETE preselection output law.

Source and actual local operation
---------------------------------
Condition on the offline shared tested label c and Bob's local fresh
input Y_J. The original complete Alice instrument has an orthogonal
classical coarse outcome alpha (and retained fine output a_J). Write its
post-instrument pure dilation, including any purifying reference, as

  |Psi> = sum_(alpha,a) |alpha,a>_A |omega_(alpha,a)>_(R B).

The vectors omega may be subnormalized. Their squared norms sum to one
when averaging over source inputs and all complete instrument outcomes.
This representation also covers a mixed source by purifying it and a
general CP instrument by retaining its Stinespring environment. The row
alpha must be an actual orthogonal instrument record, or a deterministic
function of retained Alice fine records; a hidden nonclassical
decomposition is not an available row label.

Here c is drawn with its original one-round prior and shared before the
fresh J block; under iid question-pair sampling, c is independent of J.
Within any one pair, Alice's and Bob's questions may still be correlated:
all direct-sum averages below use the original joint prior on each pair.

For k=f_c(alpha), let {D_(k|c,Y_J)} be Bob's POVM on B before his
original instrument. If it is initially a sub-POVM, append a default
guess outcome so it is complete. The physical premeasurement isometry

  U_D = sum_k |k>_K tensor sqrt(D_(k|c,Y_J)),

since U_D*U_D=sum_k D_k=I. Bob then runs his ORIGINAL complete
instrument, retaining coarse gamma and all fine b_J/Kraus records. He
locally accepts using theta_hat_c(k,gamma). The extra K register can be
measured/dephased only after that instrument; the specified sequence is
physical and uses only c,Y_J and Bob's own system. Alice's instrument is
unchanged and complete. Failure branches are completed with the original
or any fixed default answer, so E' is one Bob-local success event.

If the guess must be stored as a classical record before the original
instrument, dephase K after U_D. This dephasing commutes with Bob's
subsequent operation I_K tensor W and with the diagonal acceptance
projection. Equivalently, purify the dephasing by copying k to a private
environment: the actual vector becomes sum_k |k>_K|k>_E sqrt(D_k)|omega>,
and the ideal vector becomes |k0>_K|k0>_E|omega>. Their overlap and
the same 2e bound are unchanged. Thus no coherence between guessed rows
is being used to create an unphysical acceptance event.

Exact coherent error estimate
-----------------------------
The comparison isometry copies the true class into K using Alice's
orthogonal alpha record:

  |Psi_id> = sum_(alpha,a) |alpha,a>_A |f_c(alpha)>_K
                                      |omega_(alpha,a)>_(R B).

This is a mathematical reference and is not an allowed physical
operation. For k0=f_c(alpha), the actual-versus-ideal squared norm in
this row is

  ||sum_k |k> sqrt(D_k)|omega> - |k0>|omega>||^2
      = 2||omega||^2 - 2<omega|sqrt(D_(k0))|omega>
      <= 2[||omega||^2-<omega|D_(k0)|omega>],

because 0<=D_k<=I implies sqrt(D_k)>=D_k. Summing over the orthogonal
Alice records and averaging the original input/source law gives

  ||Psi_act-Psi_id||^2 <= 2e,
  e = E_original,preselection[1-D_(f_c(alpha)|c,Y_J)].

The expectation includes every complete Alice outcome and is taken
BEFORE either the original joint event E or the new event E'. A
posterior error after E is not a substitute: conditioning can amplify
errors, whereas the proof needs the unconditioned vector norm above.
Input and c labels can be kept as orthogonal direct-sum blocks with their
original prior weights; this is not a sampled online shared copy of
fresh J.

One common accepted contraction
-------------------------------
Let W_(Y_J) be a Stinespring isometry for Bob's original complete fine
instrument, including every gamma,b_J output and environment. Let
Pi_hat be the projection onto the locally accepted output labels
theta_hat_c(k,gamma)=1. The map
  C = Pi_hat (I_K tensor W_(Y_J))
is a contraction and is IDENTICAL on the actual and ideal vectors. If

  theta_c(alpha,gamma)=theta_hat_c(f_c(alpha),gamma)

for all labels, then C|Psi_id> is exactly the original accepted
instrument vector, with all original fine outputs preserved (and an
ideal K=f_c(alpha) record that can be discarded). Thus, with p and p'
the original and localized event masses,

  |sqrt(p')-sqrt(p)| <= ||C(Psi_act-Psi_id)|| <= sqrt(2e).

For any [0,1]-valued loss effect L on the accepted input/output blocks,
the same argument gives

  sqrt(p' alpha') = ||sqrt(L) C Psi_act||
      <= ||sqrt(L) C Psi_id|| + sqrt(2e)
      = sqrt(p alpha)+sqrt(2e).

The statement is about unnormalized event and losing masses. It does
not give a p-independent bound on conditional table distance when p is
tiny. For the full original fine table, retain the original alpha/a_J
and gamma/b_J records through W and apply the same readout to both
vectors. Contractivity gives total-variation distance at most
sqrt(2e) for the corresponding SUBNORMALIZED output measures (with the
usual half-L1 convention); conditional normalized tables additionally
require a positive lower bound on p and p'. The auxiliary guess K may be
kept as an extra fine label or marginalized; either is a common
post-map, but a target that includes K=the true row has no physical
meaning unless e is small.

Exact and source-null predicate conditions
------------------------------------------
Exact factorization theta_c(alpha,gamma)=theta_hat_c(f_c(alpha),gamma)
is sufficient and requires no approximation. It is also enough if any
violating pair (alpha,gamma) has exactly zero probability under the
ORIGINAL COMPLETE source instruments at that c,Y_J and input law. Then
the ideal-copy accepted vector still equals the original one. "Null"
must mean zero mass in the complete preselection table, not merely zero
mass in the already accepted table or a tiny empirical count.

If the predicate mismatch has preselection mass eta rather than zero,
the true-row ideal accepted vector differs from the original by at most
sqrt(eta) in norm because the two diagonal accepted projectors differ
only on that event. The mass/loss amplitudes then have additive
error sqrt(2e)+sqrt(eta). This extension is optional; the exact theorem
needs a source-null certificate.

Zero rows, zero POVM effects, and support
----------------------------------------
* If a row alpha has zero probability under the complete Alice source,
  its ideal vector block is zero. Its predicate value is immaterial to
  the original table. Actual guesses of another row on positive source
  blocks are still charged by e.
* If D_(k0)=0 on a positive true-row block, that block's guess error is
  one and the squared vector cost is 2||omega||^2. There is no divide by
  zero or omitted branch.
* If D is a sub-POVM, the missing effect is a default guess/failure
  outcome. It must be included in U_D and counted as error whenever
  k0 is a required class. Renormalizing the sub-POVM rowwise would not
  be the claimed physical operation.
* Bob states may be rank deficient or have overlapping supports. No
  inverse, support projection, or rowwise polar extension is used by
  this localization. The operator square root is bounded on the entire
  Bob space, and U_D remains an isometry.
* The class k may be an arbitrary deterministic function f_c(alpha).
  If two rows in the same class have different predicate rows, the
  proposed factorization is false; no POVM accuracy assumption repairs
  that algebraic mismatch.

Optional shared record xi
-------------------------
If xi is an input-independent shared seed which is also independent of
the private row class, and the conditional program pair remains
rho_0,rho_1 in every xi branch, include it as an orthogonal direct-sum
block. Use D^(xi) and apply the same bound in each block; averaging
gives ||Psi_act-Psi_id||^2<=2 E_xi e_xi. A fixed independent ancilla
is likewise absorbed into Bob's POVM and cannot improve Helstrom
distinguishability.

If xi is correlated with alpha or the conditional program states vary
with xi, the bound must instead use the augmented states actually
available to Bob,
  Omega_alpha = sum_xi p(xi|alpha)|xi><xi| tensor rho_(alpha,xi).
For equal row priors the best possible error is
  e_min = (1/2)(1-(1/2)||Omega_0-Omega_1||_1).
An accessible record xi=alpha makes these states orthogonal and removes
the obstruction, but it is explicit row leakage. In the present pure
program fixture, if Bob's conditional state remains exactly the pure
rho_alpha and xi is independent of alpha, every extension factors on
Bob's program and gives no improvement. A record produced by measuring
Bob before the original instrument is already part of a POVM on the
program and remains subject to Helstrom. If xi is only the
post-instrument record of gamma or the checked event, it is already
part of the source output and cannot be treated as a pre-instrument
guess resource.

Compatibility boundary
----------------------
This is a genuine constructive route from a joint checked event to a
Bob-only event when the predicate factors through an inferable row class
and the preselection guessing error is small. For e=0, the accepted
mass and full original fine table are exactly preserved. Nonorthogonal
program rows such as |0> and |+> have Helstrom e>= (2-sqrt(2))/4 for
their binary class, so the mechanism cannot glue the corresponding
rowwise-perfect labels at zero cost. The bound does not infer small e
from rowwise scalar acceptance effects, postselection success p, or
conditional state entropy. It is an operator mechanism to be checked on
the actual preselection source.

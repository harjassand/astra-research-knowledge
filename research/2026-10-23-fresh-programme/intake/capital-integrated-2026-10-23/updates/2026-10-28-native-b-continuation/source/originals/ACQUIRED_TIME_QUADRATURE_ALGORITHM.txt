The full-law and Gaussian-chaos proofs are in
../source_replica/DETERMINISTIC_COVARIANCE_QUADRATURE_AUDIT.txt.
This file closes the finite coefficient-acquisition operation used there.
The executable source is acquire_time_quadrature.py; checks and numerical

1. COEFFICIENT CONTRACT

Given integers J,m>=1 and a rational 0<zeta<1, acquire rational nodes and
positive rational weights on the J dyadic intervals
I_j=[1-2delta_j,1-delta_j], delta_j=2^(-j).
Each interval's weights sum EXACTLY to delta_j. The nodes approximate the
true m-point Gauss-Legendre nodes within delta_j zeta, and the weights have
total absolute error at most delta_j zeta on that interval.

For every original L-Lipschitz conservative source, the resulting matrix
Ctilde_Q=sum_i w_i F(t_i), F(t)=E H_(sqrt(1-t))(sqrt(t)W)^2, satisfies

 ||C-Ctilde_Q||op <= L^2 xi,
 xi=2^(-J)+(2m+1)16^(-m)+2zeta.                         (1)

All nodes and weights are independent of the source. The true Legendre
rule is used only for analysis. Runtime uses the acquired rational rule.
Approximation can destroy the exact rule's Loewner underestimate; (1)
is the claimed norm bound. No algebraic root, derivative, or mean oracle
is used. The actual squared-weight sum S2=sum_i w_i^2 is computed exactly.

2. EXACT RANKED ROOT ISOLATION

The recurrence
P_0(x)=1, P_1(x)=x,
(k+1)P_(k+1)(x)=(2k+1)xP_k(x)-kP_(k-1)(x)
computes rational values at rational x. Orthogonality gives m simple roots
in (-1,1), and the recurrence is a Sturm chain: at a root of an intermediate
P_k, its two neighbors have opposite signs. The number of roots of P_m
in (-1,x] is m minus the sign variations of (P_0(x),...,P_m(x)), with zero
terms removed. At a root of P_m this convention counts that root.

For each rank 1,...,m, bisect [-1,1] with that exact count. If a midpoint is
exactly the desired root, record a degenerate bracket; otherwise keep the
appropriate half. After b steps, every bracket has width <=h=2^(1-b).
This method does not require discovering root separation before starting.
Even if two approximate brackets were to overlap, each is still certified
for its own ranked true root. The resulting approximation argument does
not require distinct approximate nodes.

3. WEIGHT CERTIFICATION AND AN EXPLICIT PRECISION CAP

Build the coefficients of P_m by the same rational recurrence. Evaluate its
derivative polynomial on each root bracket by rational interval Horner
arithmetic. Enclose

 D_i=(1-r_i^2)P_m'(r_i)^2,  lambda_i=2/D_i,

where r_i is the true root. All true Gauss weights are positive and sum to
two, hence D_i>=1. If an interval denominator is not positive, increase b.
For every positive denominator enclosure record a certified true-weight
interval [l_i,u_i]. Put raw_i=(l_i+u_i)/2 and

 eta=sum_i (u_i-l_i)/2.

When eta<=zeta and the largest root midpoint error is <=2zeta, normalize
w_i=2 raw_i/sum raw. These weights are rational, positive, and sum to two.
Their total absolute error from the true weights is at most 2eta<=2zeta:
the raw error is <=eta, and normalization moves them by exactly
|sum raw-2|<=eta. Affine scaling to length delta proves Section 1's contract.

There is a uniform deterministic precision cap, substantially smaller than
the conservative discriminant cap in the independent audit. The sum of
absolute coefficients of P_m is at most 3^m by the recurrence; for P_m' it
is at most m 3^m. An interval X in [-1,1] of width h therefore gives

 width(P_m'(X)) <= h m^2 3^m,
 width((1-X^2)P_m'(X)^2) <= 2h m^2(m+1)9^m.            (2)

The first inequality follows termwise through Horner's recurrence; the
second uses width(X^2)<=2h and the absolute derivative bound m3^m.
If the denominator width is <=1/2, its lower endpoint is >=1/2 because it
contains D_i>=1. The reciprocal weight interval then has width at most
eight times the denominator width. Consequently

 eta <= 8h m^3(m+1)9^m
      =16m^3(m+1)9^m 2^(-b).                         (3)

The actual implementation sets

 b_cap=max(4, 1+ceil_log2(16m^3(m+1)9^m/zeta),
                2+ceil_log2(1/zeta)).               (4)

At this cap (2) is certainly <=1/2, (3) is <=zeta, and the node error
condition holds. The adaptive coefficient loop doubles b and stops at the
cap if necessary; failure there is an implementation error, not an
unbounded stopping condition. The executed checks never hit such a failure.
ceil_log2 is itself implemented with integer bit lengths and comparisons.

4. COMPLETE ARITHMETIC, SOURCE QUERY, AND NOISE COSTS

Root ranking uses O(m) rational operations per bisection and m roots.
Across precision doublings the precomputation costs

 O(m^2 [m+log(m/zeta)]) rational operations,

plus O(Jm) rational operations to scale nodes/weights to the dyadic grid.
All integer bit lengths are polynomial in m,J,log(1/zeta); this follows
from polynomial degrees and dyadic denominators in the recurrence and
interval evaluations. Fraction reduction and normalization therefore also
have polynomial bit cost. No exponential precision assumption is hidden.
The code retains certificates, using polynomial storage. A streamlined
implementation may discard root/weight brackets after verification.

At each acquired time t_i, draw its own standard d-Gaussian W_i and run
two original S4 two-value heat actions at center sqrt(t_i)W_i, scale
sqrt(1-t_i), with fresh internal seeds and common input v. Sum the resulting
four-value covariance actions with the rational positive weights.
For common Gaussian input Z and independent node seeds,

 E[A_Q(Z)|Z]=Ctilde_Q Z,
 E||A_Q(Z)-Ctilde_Q Z||^2 <= L^4 d S2.

The actual correction from the main theorem returns

 O_Q=U+tau Z-kappa A_Q(Z)/(2tau)+nu W,
 tau=nu=sigma/sqrt(2).

U is the main theorem's mean-preserving rational replica sum. Its n+1
source queries are still paid. The total is at most n+1+4Jm original
values on EVERY execution. Surrounding sample arithmetic is O(d(n+Jm));
storage is O(d+Jm) besides the coefficient certificates. All smoothing is
performed by the sampled source points. The two Gaussian reserves each
consume half of sigma^2; neither is free additional target noise.

If kappa L^2<=sigma^2/2, the full-law bound is

 TV(O_Q,N(mu,sigma^2I))
 <=kappa^2(L/sigma)^4[(sqrt(6)+1/(2sqrt(2)))sqrt(d)+phi(1)d S2]
   +kappa(L/sigma)^2 xi sqrt(d)/sqrt(2pi).            (5)

For an explicit integer R>=1, r_i=ceil(R w_i) independent actions at each
node give at most R+Jm actions and variance receipt
sum_i w_i^2/r_i <=1/R. The code acquires these counts with exact rational
ceilings. Replace S2 by this receipt and pay n+1+4 sum_i r_i queries.

Exact-real Gaussian and source primitives are the declared model. The
supplied NumPy execution is a numerical prototype of that program; a
finite-bit Gaussian/source/normalization error theorem remains a separate
obligation. Coefficient acquisition, unlike those primitives, is already
implemented with exact rational certificates.

5. SCOPE AND CHECKS

The all-chaos derivative and quadrature error proofs apply to every legal
source, not merely polynomials or tested moments. The exact monomial checks
through degree 256 validate arithmetic and indexing; they are not a TV
certificate. The nonlinear source checks use fixture parameters ONLY in
the verifier, while the sampler receives only a counted value callable.
Every tested execution observes the complete original-query cap.

This algorithm removes random-time variation and acquires accurate
expected-time bias with logarithmically many dyadic intervals and nodes
per interval. It does not remove within-time Brownian/secant variation,
and it does not reduce source-replica cost. Independent random-time
averaging remains an equally informed alternative and can have a better
worst-case variance per query. No universal speedup over that alternative
or recursive closure of the corrected source class is asserted.

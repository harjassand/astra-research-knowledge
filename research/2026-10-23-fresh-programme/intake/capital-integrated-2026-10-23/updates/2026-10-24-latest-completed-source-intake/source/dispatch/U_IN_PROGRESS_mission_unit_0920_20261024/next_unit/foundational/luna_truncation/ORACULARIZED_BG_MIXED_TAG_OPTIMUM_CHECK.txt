ORACULARIZED BG SOURCE: MIXED-TAG OPTIMUM CHECK
2026-10-24. Bounded algebra check; full unconditioned source only.

Conventions and necessary source condition
------------------------------------------
Let N=k^r, and sample X,Y independently and uniformly from [k]^r before
the test. Γ is a fixed subset of [k]^r×[k]^r, with density
qhat=|Γ|/N^2. The literal full-string validity checks require a winning
Alice response to encode the actual X,Y strings; Bob's consistency
answers at every queried coordinate must reproduce the corresponding
full BG string. A random tag pattern σ∈{A,B}^r chooses, independently in
each coordinate, whether Bob sees X_i or Y_i. The original predicate
checks (X,Y)∈Γ on the unconditioned source. There is no prior
postselection on Γ and no Bob access to unshown symbols.

Exact classical optimum for a fixed Γ
------------------------------------
For a mixed pattern σ (at least one A and one B), the visible context
c fixes X_i on A coordinates and Y_i on B coordinates. It is uniform
over N contexts. Its fiber F_{σ,c} consists of all completions of the
other symbol in every coordinate; there are exactly N distinct ordered
pairs (X,Y), each conditionally uniform with probability 1/N. A winning
Bob answer must specify the actual hidden completion: Alice's full
validity forces her strings to equal the sampled X,Y, and consistency
forces Bob to match them on both tag types. Thus a deterministic Bob
completion wins with conditional mass 1/N if it is an edge in Γ, and
zero otherwise. The optimized mass at c is exactly
  N^(-1) 1{F_{σ,c}∩Γ ≠ ∅}.
Choosing one edge completion per nonempty fiber attains the bound.
Consequently the fixed-pattern contribution is
  opt_σ(Γ)=N^(-2) |{c:F_{σ,c}∩Γ ≠ ∅}|.

For a homogeneous pattern A^r, Bob sees all of X and only needs to
answer that visible full string; the B^r case is symmetric. The
acceptance predicate still checks the actual sampled pair (X,Y)∈Γ.
Hence each homogeneous pattern has optimum qhat, not a completion-
fiber value. Averaging the 2^r equally likely patterns gives the exact
deterministic optimum
  p_opt(Γ)=2^(-r) [2 qhat + Σ_{σ mixed} opt_σ(Γ)].

No-signalling upper bound
-------------------------
The mixed-pattern bound also holds for arbitrary entangled strategies.
Fix (σ,c), and let h range over its N missing-symbol completions. The
shared state is independent of source inputs, and Bob's question is
only (σ,c). By no signalling, his output distribution q_{σ,c}(h') is
independent of the hidden completion h, even if Alice performs an
h-dependent quantum instrument. Winning implies both (X,Y)=h∈Γ and
that Bob outputs h. Therefore
  Pr[win | σ,c]
    <= (1/N) Σ_{h∈F_{σ,c}∩Γ} q_{σ,c}(h)
    <= 1/N.
If the fiber has no Γ edge, the probability is zero. The deterministic
completion strategy attains this quantum upper bound. For homogeneous
patterns, the source edge event has fixed probability qhat, and Bob can
always report the visible side; no entanglement raises it. Thus the
formula above is the exact entangled optimum as well, under this source
interface (and the same upper bound follows for nonsignalling boxes).

Random Γ and the all-fibers event
--------------------------------
Suppose each of the N^2 ordered pairs is independently placed in Γ with
probability q. For each fixed mixed σ and context c, its fiber contains
N distinct potential edges, so
  Pr[F_{σ,c}∩Γ=∅]=(1-q)^N <= exp(-qN).
There are (2^r-2)N mixed contexts. Hence
  Pr[any mixed fiber empty]
    <= (2^r-2)N exp(-qN)
    <= 2^r k^r exp(-q k^r).
Whenever this is <1, in particular with high probability when qk^r
dominates r ln 2+r ln k, every mixed pattern has all fibers nonempty.
Then opt_σ=N^(-1) for all mixed σ and
  p_opt(Γ)=2^(1-r) qhat + (1-2^(1-r)) k^(-r).
The formula uses the realized density qhat; no concentration replacement
of qhat by q is needed for this identity.

Row-default and quotient boundary
---------------------------------
The 1/N result depends on the literal complete source: a win forces
Alice's full strings to be the actual sampled X,Y, the event Γ is
evaluated on that actual pair, and a mixed-tag Bob answer must match the
full strings across all queried coordinates. If one weakens validity so
Alice may choose an arbitrary edge completion matching only the visible
coordinates, then Alice and Bob can choose the same edge completion for
each nonempty fiber, giving conditional success 1 rather than 1/N.
Likewise, conditioning the source on (X,Y)∈Γ before play changes the
hidden-completion law and invalidates the calculation. Thus row defaults,
quotienting, or Alice-side filtering are not available under the stated
complete unconditioned source, but they would matter for a weaker game.

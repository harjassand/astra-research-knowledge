Ordinary BG-oracularization: exact mixed-fiber count
====================================================

Scope and interface
-------------------
This is the finite counting calculation for the interface in the task:
X,Y are independent uniform elements of [k]^r; the tag vector sigma is
independent uniform in {A,B}^r; at coordinate i Bob sees X_i for tag A
and Y_i for tag B. On a homogeneous tag, consistency checks only the fully
visible side, so it can be passed for every input pair; the source predicate
Gamma(X,Y) remains to be checked. On a mixed tag, Bob's whole response
determines at most one of the k^r completions of the missing symbols, and
consistency passes only when the actual completion equals that response.
The calculation below assumes Alice can answer with the actual pair and
that each Bob context may choose a response independently. It does not
derive this interface from an arbitrary variant of oracularization.

Exact count
-----------
Write W=[k]^r, M=|Gamma|, and delta=M/k^(2r). For a mixed tag sigma and a
visible context v in [k]^r, define the completion fiber

    F_(sigma,v) = {(X,Y) in W x W :
                    X_i=v_i if sigma_i=A, and
                    Y_i=v_i if sigma_i=B}.

There is exactly one hidden symbol per coordinate, so each such fiber has
k^r elements. Conditional on (sigma,v), the hidden completion is uniform.
If F_(sigma,v) intersects Gamma, Bob can fix one point of that intersection
as his response and obtain consistency plus Gamma on exactly one of the k^r
possible completions. If the fiber misses Gamma, no response can win. Thus
the optimum conditional success is 1/k^r or 0 according as the fiber is
nonempty or empty after intersection with Gamma.

Let N_Gamma be the number of pairs (sigma,v) with sigma mixed and
F_(sigma,v) intersecting Gamma. Each (sigma,v) has prior probability
1/(2^r k^r), and the selected completion has conditional probability
1/k^r. The two homogeneous tags instead contribute their full Gamma mass.
Therefore the exact optimum in this completion-guess model is

    p_opt = 2^(1-r) delta + N_Gamma / (2^r k^(2r)).

This is a count of tag/context fibers, not of Gamma edges with multiplicity.
It uses no runtime access to hidden inputs; Bob's maximizing choice is a
preprogrammed representative of Gamma in each nonempty public fiber. If
classical computation or response-table size is constrained, this choice
has not been charged or optimized for complexity.

Checks
------
The standard-library script `check_bg_oracularization.py` explicitly
maximizes Bob's response separately in every visible context.

* For k=2,r=2 it checked all 2^16 predicates Gamma by exhaustive exact
  integer arithmetic; for every predicate the context optimization agrees
  with the formula above.
* For complete Gamma, N_Gamma=(2^r-2)k^r, giving
  p_opt=2^(1-r)+(1-2^(1-r))k^(-r). In particular k=2,r=2 gives 5/8;
  k=2,r=3 gives 11/32.
* For k=2,r=2 and Gamma={(X,Y): X_1=Y_1}, M=8 and N_Gamma=8, so
  p_opt=3/8.
* For k=2,r=3 and Gamma={(X,Y): parity(X)=parity(Y)}, M=32. Every mixed
  fiber has at least one parity-matching completion, hence N_Gamma=48 and
  p_opt=7/32.

The script reports 65,536 predicates checked, and the r=3 replay reports
(M,N_Gamma)=(32,48). These are finite implementation checks of the stated
model. They do not imply a quantum or commuting-operator optimum, nor a
general theorem for a different consistency predicate.

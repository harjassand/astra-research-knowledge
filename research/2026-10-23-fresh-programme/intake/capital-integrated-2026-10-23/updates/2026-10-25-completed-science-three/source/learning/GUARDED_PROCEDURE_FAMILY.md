# Accepted-task acquisition with a fallible procedure language

This strengthens the expired-source construction by removing a semantic
contract: the chosen finite native feature space H need NOT contain the real
sources. H is an actually compiled proposal language, with paid construction,
selection and evaluation, not a supplied true representation. Accuracy is
target-distribution accuracy certified by new observations. Exact global
reuse still requires the previous envelope/disagreement contract and is not
inferred here.

## 1. Inputs and actual operations

Let X be a native input domain with a paid implementable sampling law nu.
For example X=F_p^n with uniform native sampling; this is an input sampler,
not a latent-model, task, feature, or useful-context sampler. Actual sources
f_t:X->F_p are fixed during their acquisition/use contract and can be chosen
adaptively from the past. They may be outside every proposed feature model.

Compile a finite linearly independent family of native programs spanning H,
dimension M, and a checked native unisolvent set Z. The language may be
computed from retained old procedures by a declared uniform composition
rule, or chosen as a generic bounded language. This theorem does not invent
a useful rule for free. Failure of construction/rank/computation caps returns
UNKNOWN; all work remains paid. Nothing infers that future sources use H.

Choose r<M anchors P in Z and compute the cardinal splitting psi,k of the
expired-source note. Actual old incomplete records impose

    k(y_t)^T R a_t = f_t(y_t)-psi(y_t)^T a_t,
    a_t=(f_t(x_1),...,f_t(x_r)),

on an unknown m-by-r graph R, m=M-r. Retain the exact affine solution family
R_0+K_0. If it is empty, this proposal family returns UNKNOWN. Old sources
may expire; all later programs use only the compiled known native features
and retained observations, not those old oracles. The old values need not
have been generated by any true common graph. Their cost and any model
search/failed alternatives remain explicit.

For a new target, query its actual r anchors, obtaining a. Compute

    V_a = {Delta R a: Delta R in K},  s=dim V_a.

This defines the known affine candidate family

    F(a)=psi^T a + k^T R_0 a + k^T V_a.

Select s native points with an injective evaluation matrix on k^T V_a,
using actual feature evaluations on Z. Query those s values and fit the
unique candidate G in F(a). Cached same-target constraints are credited;
inconsistent extra cached values force UNKNOWN. Every candidate is a closed
native program, whose execution cost is paid. The selection used no real
task coefficients, useful source label, true common-rank certificate or
future task sampler.

## 2. Distributional soundness without realizability

Before seeing new guard samples, fix G using the fitting history. Define its
actual disagreement risk

    e_t=Pr_(x~nu)[G(x)!=f_t(x)].

For desired epsilon_t,delta_t>0, draw q_t fresh independent native samples
with

    q_t >= ln(1/delta_t)/epsilon_t.

Query the ACTUAL target at those points and compare with the actually
evaluated compiled G. Accept only if every comparison agrees; otherwise
return UNKNOWN for this proposal. If e_t>epsilon_t, its conditional
wrong-acceptance probability is at most

    (1-e_t)^q_t <= exp(-epsilon_t q_t) <= delta_t.

This proof has no degree, rank, H-realizability, source-code or derivative
assumption. It uses fixed target semantics and fresh guard randomness after
selection. Summable conditional budgets imply, with probability at least
1-sum_t delta_t, every accepted program has its stated risk bound, even for
adaptive target sequences. Reusing old guard points/tapes after adaptive
selection does not instantiate this theorem. The law nu, its actual random
bits, repeated inputs, sampling rejection/caps, source calls, known-program
evaluations and finite arithmetic all remain paid.

This is ordinary held-out testing of a fixed candidate. It does not certify
the old common-rank hypothesis or say the source is globally in H. A narrow
or accidental proposal may safely return UNKNOWN on almost every target.
No lower bound on acceptance probability is supplied by this theorem.

## 3. Deterministic fit-debt bound, separate from validation

After acceptance, write G=psi^T a+k^T b and retain R a=b. Since G was
constructed from F(a), at least one current R realizes it. The new family is
nonempty and

    K_next = {Delta R in K: Delta R a=0},
    dim K_next = dim K - s.

This dimension decrease holds for EVERY accepted candidate as an algorithmic
identity; it does not require pretending approximate agreement means exact
source equality. The update asserts a policy's chosen compatible program,
not a newly observed universal law. Approximate accepted programs can bias
the family and reduce later coverage; each later candidate still needs its
own independent guard against its actual source.

Thus for A accepted targets,

    total accepted-target fitting answers <= r A + dim K_0.

Add sum of their actual q_t guards. If there are J rejected trials, their
actual r+s_t+q_t answers, or earlier rejection cost, must be added separately.
There is no arbitrary-stream total-cost or lifetime advantage without a
coverage condition. Algebraic fit debt is bounded; unproductive trial cost
is not.

Given the measured a and its current F(a), the s extra-fitting values are
sharp for exact selection within that family by the p^s-versus-p^q decision
tree bound. The whole r+s policy need not be globally optimal: a competent
joint/interleaved learner can beat coefficient-first plans, as the preserved
33-tax result demonstrated. This theorem does not impose its staging on a
comparator or ignore a pre-existing same-target cache.

## 4. What guarantees later use, and its cost

Risk under nu is not deterministic transcript equality. For a subsequent
interactive use, suppose that at every common history its actual next native
input law for the selected accepted source/program is dominated by
kappa_l nu. Stop the comparison at the first erroneous calibration or output
mismatch. At a common past with no bad calibration yet, the current program
has the stated risk, so the next mismatch probability is at most
kappa_l epsilon_(selected task). Couple histories while outputs agree and
sum these probabilities, adding the union bound for bad calibrations. Do
not condition fresh input laws on an event about future calibration outcomes.
For a finite declared horizon choose deterministic caps
beta_l >= sup_common_history[kappa_l(history)*epsilon_selected(history)].
Full transcript TV is then at most

    sum_t delta_t + sum_l beta_l.

Equivalently a suitable expected stopped predictable sum can be used. A
realized random selected-task sum is not by itself an unconditional
deterministic TV certificate.
Fresh execution inputs are not assumed independent; the domination contract
is what permits the coupling. If the policy may choose arbitrary concentrated
points, kappa can be as large as |X| under uniform nu, and the bound may be
vacuous. Exact global reuse is not recovered by wording alone.

To make this bound small over a longer/more concentrated deployment, one
must lower epsilon_t and pay the corresponding q_t, or obtain a stronger
actual source contract. This retains the earlier rare-exception lifetime
obstruction. No validation claim is made about an unbounded future horizon.

## 5. Computation and remaining scientific decision

For d=mr graph coefficients, dense affine-family maintenance costs polynomial
field work/storage in d; explicitly retaining K can require O(d^2) entries.
Computing K a, native row selection, solving candidate coefficients and
constructing/evaluating closed H-programs are additional. Exact inversion is
not a unit-cost bit operation outside a declared field model. All previously
paid feature acquisition, language construction, discarded candidates and
sampling failures remain in total cost. No runtime/evaluation advantage
follows from the accepted-source query inequality alone.

The result changes one interface honestly: incomplete expired observations
can compile a reusable family, and later accepted-task acquisition has a
finite algebraic debt WITHOUT asserting that the proposed representation is
true. Realizability reappears only if one asks for nontrivial coverage rather
than selective accuracy. A conventional constraint/subspace learner with
the same feature programs and observations can run these same operations;
no exclusive algorithmic advantage or priority is claimed.

The consequential unresolved bottleneck is now specific: acquire/choose a
language and experimental policy with demonstrably useful coverage and
manageable total computation, rather than promote a finite fit/low-rank
completion to a true world model. No new favorable data is introduced to
hide that remaining requirement.

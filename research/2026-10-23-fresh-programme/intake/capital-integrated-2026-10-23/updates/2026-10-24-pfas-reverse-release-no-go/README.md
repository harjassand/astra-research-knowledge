# PFAS reverse release is a transport control, not a fate test — 24 October 2026

This selected bounded no-go concerns release-only inference from a spent PFAS-loaded porous sorbent. A target-start washout can measure desorbability when the starting target inventory is independently known, but a finite parent-only release trace cannot uniformly distinguish retained parent from parent converted to unmonitored products. No experiment was run. The complete source note is retained byte-exact in [source](source/pfas_reverse_release_no_go.md), with hashes in the [manifest](source_manifest.json).

For retained mass `M` with first-order release rate `k`, a finite chase of duration `T` yields `M(1-exp(-kT))`. At any finite resolution `epsilon`, choosing `0 < k <= epsilon/(M T)` makes retained parent observationally indistinguishable from the converted case with zero parent signal. A fresh label injected after treatment measures current transport; for unchanged pore structure it has the same trace whether historical PFAS was retained or converted. Loading a known target inventory through the ordinary inlet also costs inversely with the same rare forward-arrival probability. In a closed reversible transport model, a true target-start reverse response is a weighted forward cross-kernel and adds no ideal identifiability beyond that kernel.

For the fate decision, the stronger equally informed incumbent is a closed endpoint inventory: targeted parent/product assays plus total, organic and inorganic fluorine accounting over the bed, eluate, filters, vessel, off-gas and scrubber, with recovery blanks and matrix controls. An unclosed fluorine term remains unresolved. This release-only result is separate from the [PFAS bound-resin electron-beam hypothesis](../2026-10-24-pfas-bound-resin-eb/README.md); it does not revise that process note or establish destruction performance.

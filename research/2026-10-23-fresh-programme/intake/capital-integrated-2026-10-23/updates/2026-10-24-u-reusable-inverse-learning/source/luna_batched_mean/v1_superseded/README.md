# Preserved v1 run

This directory is an unchanged snapshot of the first fixed run and its first public replay. It was retained before the ordinary-cost/reporting repairs required by the subsequent audit. V1 did not evict obsolete proposal CDFs, failed to reuse 64 OS* point evaluations when those points later became singleton nodes, and reported only final-tree normalizer intervals rather than task-start intervals. Its public replay opened the full-grid transcript before replaying the lead. The v1 run is superseded; use the parent directory's current benchmark, transcripts, and verification.

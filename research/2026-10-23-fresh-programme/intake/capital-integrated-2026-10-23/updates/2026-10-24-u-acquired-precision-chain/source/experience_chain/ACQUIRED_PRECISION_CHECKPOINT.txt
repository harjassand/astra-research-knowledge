Outcome

Paid source measurements can acquire an unknown shared task space AND an
observed coverage/precision certificate. That certificate then determines the
measurement exposure needed to solve a growing sequence of genuinely new
operators at successively tighter requested tolerances. Finite source precision
creates a quantified bias floor; more target averaging cannot remove that floor
for the projected estimator. Paying for more source experience lowers it.

This is an explicit conditional capability mechanism, not a new PCA algorithm,
a physical-material model, an architecture advantage, or an established novelty
claim. Shared-subspace representation learning and its dimension benefit are
strong prior art. A same-history implementation given the whole new policy is
a replication, which does not by itself refute usefulness or procedural novelty.

The concrete interface and what experience actually supplies

Known b=e1, delta>0, Gaussian per-output-coordinate noise sigma, rank ceiling r.
Unknown fixed T within b-perp with dim(T)<=r. Source and future unit v lie in T.
Each defines a NEW operator
 A_v=I+(delta/2)(b+v)(b+v)^T,
 x_v=A_v^{-1}b=(1-beta/2)b-(beta/2)v,
 beta=delta/(1+delta).
An exposure-m action at b returns A_v b+N(0,sigma²I/m), costs m unit-input
probe energy/time, and reads n coordinates. Other adaptive inputs are permitted
for strong solver comparisons. No exact A, hidden state ID, T or v is supplied.
The mathematical model class is supplied; T's orientation is learned from paid
responses. The logical simulator/learner input separation is not a security
sandbox claim.

The learner projects/scales paid outputs to z_i=v_i+N(0,tau²I_d), d=n-1.
Its source covariance targets EMPIRICAL S_K=VV^T/K, not population P_T/r.
There is no silently missing random-design covariance term. Sources must be
noise-independent as a whole under the present Gaussian-matrix proof; no
adaptive-source martingale extension is claimed. Repeated/poor source directions
can leave the gate inconclusive. The main execution uses independent spherical
directions, not a balanced or supplied source basis.

Proved acquisition and continuation guarantee

PAID_COVERAGE_PRECISION_TRANSFER.txt gives the full derivation. Its Gaussian
event bounds ||C_hat-S_K||, first with a fixed radius and then with a sharper
observable quadratic-root radius. The sharpened radius uses the same event and
no extra confidence penalty. If lambda_hat_r exceeds that radius, the supplied
rank<=r promise plus Weyl certifies rank(S_K)=r and hence span(V)=T. A direct
eigenvector residual gives ||P_hat-P_T||<=s=radius/lambda_hat_r.

For a new v, fresh independent exposure m and xhat constructed from P_hat z,
the exact error is an orthogonal bias-plus-noise sum, giving
 ||xhat-x_v||² <= beta²s²/4
                +sigma² Q_r(alpha_t)/[(1+delta)²m],
 Q_r(alpha)=r+2sqrt(r log(1/alpha))+2log(1/alpha).
This determines the sufficient integer m for each requested tolerance. Source
checkpoints and target confidence levels receive summable predeclared alpha

target directions may depend on earlier history, before their own fresh noise.
Membership of every future v in the same T remains a supplied class promise;
finite source data do not establish it outside the class.

The new-task benefit is not just a weak estimator comparison

Exact arithmetic CG solves this two-eigenvalue family in two exact actions.
It would invalidate a noiseless story that geometry acquisition enables the
solve. NEW_TASK_PRECISION_LOWER_BOUND.txt instead covers the actual noisy
solution target, arbitrary adaptive inputs, all retained state and free unlimited
postprocessing. For a known q-dimensional allowed v-space, q>=2, it proves

 B >= sigma²(q-1)(1-2alpha)^3 /
       [27(1-alpha)(1+delta)²epsilon²]

in the stated local tolerance range, and independently
 B >= sigma² kl(1-alpha||alpha)/[4(1+delta)²epsilon²]
for epsilon<beta/2. The source-history law must be the same across alternatives
for the NEW v. These are standard Assouad/Gaussian-testing specializations with
explicit constants. Before source acquisition q may be n-1; after a certified
rank-r acquisition it is r. Projected averaging has the corresponding r-plus-log
precision order plus its paid representation bias. No source-cost optimality
or sharp finite-n constant is claimed. For q=1, unit v has only two signs and
the continuous 1/epsilon² conclusion is false; sign classification is explicit.

Resource/precision principle

Every acquired source checkpoint produces an observed pair (E,bias²), which
quantifies the tolerances and further-task exposures that it can certify. The
main note gives an exact ex-post break-even formula for a paid reduction in
this bias. It does not predict the result of an unacquired source experiment.

PRECISION_INVESTMENT_THEOREM.txt additionally proves a conditional exposure
allocation result: IF a retained refinement contract supplies bias²<=A/E with
incremental source cost, the fixed-horizon optimum is
 (sqrt(A)+sqrt(T B))²/epsilon².
For arbitrary announced precision/noise-budget requests, a current-prefix
optimizer buys monotonically increasing source precision and costs <=2 times
the best offline exposure allocation for every prefix (<=3 with doubling source
levels). This is the known be-the-leader/monotone-investment argument, with
additive multislope ski-rental priority stated. The arbitrary uncurated source
class does NOT automatically supply this 1/E contract; the actual run uses
observed certificates instead. The rule s<=epsilon/beta used in that run is a
simple sufficient allocation rule, not a globally optimized investment policy.

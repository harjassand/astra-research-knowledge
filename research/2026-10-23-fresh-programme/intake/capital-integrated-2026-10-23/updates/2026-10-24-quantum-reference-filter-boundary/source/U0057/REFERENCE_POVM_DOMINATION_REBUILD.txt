WHOLE-COARSE RECONSTRUCTION FROM A COMMON REFERENCE POVM
2026-10-24. passive_lag. Actual finite local operation; novelty UNKNOWN.

Disposition

This is a constructive alternative to an entrywise ancillary mask lift.
It changes the coarse resource itself. For ANY acceptance predicate, a
common reference POVM dominating all fresh-question coarse POVMs gives
one all-input event/live-law-preserving filter. Its one-sided masses
depend on that domination radius, rather than the answer predicate's
rectangle or coherent-mask cost. It can therefore evade the established
conjunctive mask obstruction.

There is no universal small-radius theorem. A fresh-input-copy example
below forces an exponentially large radius while the required live law
can still be trivial. The meaningful remaining target is a payoff-aware
choice or redesign of the coarse reference, not a generic max-entropy
estimate that ignores fine-instrument compatibility.

1. Setup and explicit additional invariant

Work with one finite bipartite original strategy, in the standard matrix
notation chi(F,H)=Tr(sigma F sigma H), sigma>=0, Tr(sigma^2)=1.
The trace in this display is ordinary matrix Tr; a normalized matrix
trace requires the usual square-root-dimension rescaling of sigma.
Physical Bob effects are transposed in the fixed Schmidt basis before
using right/opposite matrix multiplication.

Fix tested questions c. The full unchecked own question strings are u
and v. Let the original coarse/fine effects obey
  sum_alpha F_u^alpha=sum_gamma H_v^gamma=I,
  sum_(a_J)G_u^(alpha,a_J)=F_u^alpha,
  sum_(b_J)K_v^(gamma,b_J)=H_v^gamma,
with all effects positive. Define the original accepted subtable
  T_c(u,v,a_J,b_J)=sum_(alpha,gamma)theta_c(alpha,gamma)
                         chi(G_u^(alpha,a_J),K_v^(gamma,b_J)).   (R1)

Suppose there exist question-INDEPENDENT reference POVMs F0^alpha,
H0^gamma and finite numbers d_A,d_B>=1 such that

  F_u^alpha <=d_A F0^alpha for every u,alpha,
  H_v^gamma <=d_B H0^gamma for every v,gamma.                  (R2)

This is a Loewner operator inequality, not merely a scalar probability
bound or a constant total acceptance effect. It concerns the full joint
tested answer strings. One-coordinate marginal bounds do NOT suffice to
assert a tensor bound on (R2).

2. Prepare the accepted reference BEFORE receiving u,v

Put
  w0_(alpha,gamma)=chi(F0^alpha,H0^gamma),
  p0=sum_(alpha,gamma)theta_c(alpha,gamma)w0_(alpha,gamma).
For w0>0 let xi_(alpha,gamma) be the normalized bipartite vector whose
standard-form matrix is
  sqrt(F0^alpha) sigma sqrt(H0^gamma)/sqrt(w0_(alpha,gamma)).
Prepare the fixed finite pure state

  zeta_c=(1/sqrt(p0)) sum_(accepted alpha,gamma)
            sqrt(w0_(alpha,gamma)) |alpha,gamma>_A
                          |alpha,gamma>_B tensor xi_(alpha,gamma). (R3)

Zero-w0 branches are omitted. Both players can read the entire old pair
of coarse labels in this NEW resource because it was sampled/prepared
offline. It is not the actual coarse pair from a question-dependent
measurement performed after u,v. No communication is used to reveal it.
If p0=0, (R2) implies that the original accepted table is identically zero
for this c. Use an arbitrary fixed resource, always-fail POVMs, and
lambda_c=1 on that c. This gives an everywhere-defined replacement
without division by zero; that c has zero posterior accepted weight.

3. Fresh local fine filters, completed to genuine POVMs

For each fixed reference branch, define bounded support effects

  C_(u,alpha)^(a_J)
       =(1/d_A)(F0^alpha)^(-1/2) G_u^(alpha,a_J)(F0^alpha)^(-1/2),
  D_(v,gamma)^(b_J)
       =(1/d_B)(H0^gamma)^(-1/2) K_v^(gamma,b_J)(H0^gamma)^(-1/2). (R4)

Inverse notation is support shorthand. Because sum G=F_u<=d_A F0,
bounded Douglas factorization gives positive operators with
  sum_(a_J) C_(u,alpha)^(a_J)<=I.
The same holds for D. Add one local failure effect I-sum C (respectively
I-sum D). These are actual COMPLETE local success/fine/failure POVMs.
The displayed branch selectors in (R3) make each player's POVM depend
only on own u or v and the shared offline branch. Arbitrary local
noncommutativity of the original effects is allowed.

For every u,v,a_J,b_J the simultaneous-success fine probability is

  P_zeta_c(1,a_J;1,b_J|u,v)
         =T_c(u,v,a_J,b_J)/(d_A d_B p0).                      (R5)

Proof: in branch alpha,gamma, the unnormalized fine expectation is
chi(G_u/d_A,K_v/d_B)/w0. Multiply by its preparation weight
theta_c w0/p0 and sum. This calculation preserves every accepted
fine entry, not just the probability of the tested event.

Thus the generic all-input replacement identity holds with
  lambda_c=d_A d_B p0 for p0>0.                             (R6)
Here lambda_c can be below one; the earlier lambda>=1 observation was
specific to a binary MASK kernel taking the value 1/lambda on each
accepted entry. It is not a restriction on a whole-table replacement.

4. The one-sided cost is NOT the product d_A d_B

On the new resource, Alice's conclusive marginal satisfies exactly

  lambda_c P(s_A=1|u,c)
      =d_B sum_(alpha,gamma)theta_c(alpha,gamma)
                                  chi(F_u^alpha,H0^gamma)
      <=d_B.                                                 (R7)

The final inequality follows from theta<=1, positivity of every joint
term, and completeness of BOTH original/reference coarse POVMs. Likewise

  lambda_c P(s_B=1|v,c)
      =d_A sum_(alpha,gamma)theta_c(alpha,gamma)
                                  chi(F0^alpha,H_v^gamma)
      <=d_A.                                                 (R8)

Thus the construction pays at most the OPPOSITE player's domination
factor in its one-sided mass. No bound on answer alphabet size enters
these formulas. Retaining the exact cross masses can be much sharper.

For finitely many c, prepare an offline tensor pool of all zeta_c.
Selecting only one's hypothesized c is then a local operation on ONE
fixed resource, including when guessed histories mismatch. As in the
frozen mask theorem, assign scalar branch weight lambda_c and normalize
with Lambda=E_(c~mu^C)lambda_c if a probability prior is needed. The
event mass is p/Lambda and the two masses are G_A/Lambda,G_B/Lambda;
conditional normalization cancels Lambda exactly.

5. Same-source event inequality and the precise quantitative criterion

Let c range under the ORIGINAL unconditioned mu^C. Bounds (R7),(R8) give
  G_A<=E_c d_B(c), G_B<=E_c d_A(c).                           (R9)
These bounds also hold at every exposure stage. The reference resource
and its d_A,d_B are fixed for c; taking conditional expectations of
original fine/coarse effects is linear in (R4), so it creates the same
R/H half-exposure family on that fixed resource. The exact full-table
identity (R5) ensures the original joint referee law is preserved.

Therefore the already-frozen R/H/S_actual event composition yields its
same scalar bound with

  tau_ref=log(max{1,E_c d_A(c),E_c d_B(c)}/p)/m, m=n-|C|,      (R10)
  loss<=alpha+2^16[sqrt(alpha)tau_ref^(1/4)+sqrt(tau_ref)]
                    +arbitrarily small final accuracy.

Alternatively, NEW directly dilated binary instruments (R4) satisfy the
conditional-QRE parent identities from
BINARY_FILTER_CHARGE_AND_WHOLE_REBUILD.txt. This gives the same actual
log(G_A/p),log(G_B/p) charges in the finite copied-input setting.

Equation (R10) is an event/strategy statement, not a new unconditional
repetition theorem. A game-level rate requires (R2) with controlled radii
at the greedy selected C for EVERY repeated strategy being bounded.
For example, a uniform bound E_c d_A,E_c d_B<=exp(s|C|) recovers the
same exp[-2^-75 epsilon^3 n/(epsilon+s)] argument, while radii at most
p^(-O(1)) at the selected histories would give quadratic gap order.
Neither general bound has been proved.

The proof is finite-tensor, with finite actual reference states/effects.
Its resource can have one classical branch per accepted old coarse pair,
and the offline c pool can be enormous. It does not provide an efficient
preparation or numerical-conditioning bound. The new operator premise
(R2) is NOT known to transfer merely from a finite-TABLE approximation.
No unqualified commuting-model extension of this radius criterion is
being asserted. Finite-tracial direct realizations require their own
representation and domination assumptions.

6. Genuine escape and a decisive limitation of this operation

If F_u^alpha=F0^alpha and H_v^gamma=H0^gamma, choose d_A=d_B=1.
All branches of (R3) then succeed locally with certainty. Equations
(R7),(R8) give G_A=G_B=p (after the original c average), not merely <=1.
The original accepted fresh-question law is exactly mu^m, so its referee
charge is zero as well. This gives an exact accepted live realization
for ANY theta, including L. It escapes the conjunctive ancillary-mask
lower bound by changing the reference coarse realization.

For a direct single-coordinate strategy, sample the other fresh question
pairs offline, independently of the selected fresh pair, and use the
fine POVMs of (R4). The accepted resource is independent of that fresh
pair. This reproduces the original conditional coordinate law exactly;
no sampler approximation is required in this special case.

Conversely, let Alice's checked coarse answer be her full unchecked
question string u, with N possible u, and take scalar effects
  F_u^alpha=1{alpha=u}I.
For any reference POVM F0 and any factor d_A satisfying (R2), each u
requires I<=d_A F0^u. Summing yields N I<=d_A I, so d_A>=N.
The uniform reference F0^u=I/N attains that lower bound. For m binary
unchecked inputs this radius is 2^m. The predicate can always accept and
all live answers can be constant, so this is NOT an obstruction to the
desired weak interface: discarding that irrelevant coarse tag solves
the live problem exactly. It is a sharp obstruction to this particular
reference-POVM domination task while those tags are retained.

This separates the useful new operation from an unjustified universal
claim. A payoff-preserving redesign before choosing the reference may
remove a large radius, but the construction here does not prove that
such a redesign exists for arbitrary games.

7. An explicit family with noncommuting fresh-input dependence

For arbitrary finite positive weights w_alpha summing to one, take
  F_u^alpha=w_alpha[I+eta K_alpha(u)], 0<eta<1,
  K_alpha(u)=K_alpha(u)*, ||K_alpha(u)||<=1,
  sum_alpha w_alpha K_alpha(u)=0.                            (R11)
Then this is a POVM, F0^alpha=w_alpha I is a common reference, and
  F_u^alpha<=(1+eta)F0^alpha.
No restriction on the answer alphabet or the number of fresh inputs is
needed. K_alpha(u) can vary noncommutatively with u. Given ANY local
POVM P_(u,alpha)^(a_J), the joint fine family
  G_u^(alpha,a_J)=sqrt(F_u^alpha) P_(u,alpha)^(a_J) sqrt(F_u^alpha)
is positive and has the required coarse sums. It may be noncommuting
even for one u. Bob can use the analogous construction. Thus (R11) is
an actual input-indexed fine instrument family, not only a collection of
scalar marginal distributions.

Here is a quantitative separation from EVERY conjunctive mask lift.
Take sigma=I_2/sqrt(2), t>=5, r=t^(-1/2), and the tested mask L^(tensor t).
Let the coarse string weights be
  w=(1-r,r)^(tensor t), z=(r,1-r)^(tensor t).
Put m_t=(1-2r)^t, and define centered parities
  k_alpha=[(-1)^(number of ones in alpha)-m_t]/(1+m_t),
  l_gamma=[(-1)^(number of zeros in gamma)-m_t]/(1+m_t).
Both weighted means are zero and both absolute values are at most one.
Choose fresh-input-dependent Pauli directions S_u,T_v, including at
least X and Z, and set
  K_alpha(u)=k_alpha S_u,
  H_v^gamma=z_gamma[I+eta l_gamma T_v].                      (R12)
The original coarse one-party marginals remain EXACTLY w,z, since Pauli
matrices are traceless. Across inputs the coarse effects do not commute.
Choose fine P,Q along other Pauli directions to make the original fine
effects noncommuting as well.

The original coarse joint table is
  chi(F_u^alpha,H_v^gamma)
    =w_alpha z_gamma[1+eta^2 k_alpha l_gamma c(u,v)],
  c(u,v)=Tr(S_u T_v)/2 in [-1,1].
The reference tested mass is p0=(1-r^2)^t=(1-1/t)^t. Therefore every
fresh pair, and hence every averaged actual event mass p, satisfies
  (1-eta^2)p0<=P(E|u,v)<=(1+eta^2)p0.                       (R13)
For fixed eta, p is bounded away from zero uniformly in t.

The whole-coarse construction has d_A=d_B=1+eta and G_A,G_B<=1+eta.
Its source budget obeys
  tau_ref <=[log(1+eta)-log((1-eta^2)(1-1/t)^t)]/m=O(1/m).   (R14)
By contrast, the weighted nuclear-norm obstruction for every exact
conjunctive ancillary MASK lift, with these SAME original marginals,
gives
  max(G_A,G_B)>=[sqrt(1+2r-3r^2)]^t=exp(Theta(sqrt(t))).
Its sufficient one-sided MASS-budget overhead is therefore Omega(sqrt(t)),
even though p=Theta(1). The new construction changes that mass certificate
to O(1). This is NOT a lower bound on the actual Jensen gap, conditional
QRE charge, or physical reconstruction error. At eta=0, for example,
those Jensen gaps can vanish despite exactly the same mask mass bound.
The unbounded separation is between the stated mass interfaces on a
genuinely input-dependent, noncommuting operator family, not a general
reconstruction impossibility. The nuclear bound applies also to arbitrary
collective conjunctive quantum lifts, so the classical tensor-cap
correction does not remove this particular mass comparison.

For eta=1/3, the new reference resource is simply the original two-qubit
state together with shared alpha,gamma drawn from the product weights
conditioned on L^(tensor t). That rejection sampler has success p0>=1/4,
uses 2t stored label bits, and requires an expected constant number of
length-t draws. No exponentially large dense quantum matrix is needed
to describe this PARTICULAR resource. The original coarse instrument
can also be implemented as a binary weak Pauli POVM on the parity class,
followed by sampling the string conditional on that parity; its Kraus
operator for alpha is exactly sqrt(F_u^alpha). Conditional parity has
probability bounded away from zero for the displayed r. Exact real
probabilities remain mathematical data; no uniform gate/precision bound
or overall S_actual resource estimate follows.

The local filter pair itself has simultaneous success probability at
least (1-eta)/(1+eta). It is nevertheless a COMPLETE POVM including
failure. Conditioning on joint success is not free implementation of
the final one-round strategy: that step remains the source's actual
all-input event reconstruction, including its timeout/failure charges.

This is a SOURCE/EVENT family, not a proof of a positive-gap game rate.
The L predicate alone has value one. It can be decorated with a hard
independent game factor, but doing so would not establish a new game-level
advantage. The proper substantive claim here is the strict improvement
of the SAME event-preserving reconstruction interface under (R2).

8. What rate is justified under an explicit selected-history hypothesis

For clarity, a strategy-restricted quantitative consequence does follow.
Let epsilon=1-omega_star(G)>0 use the unrestricted OWN finite-tensor
base gap. Suppose that every repeated strategy under consideration has,
at its OFFLINE greedy-selected C, references satisfying (R2) and
  max{1,E_c d_A(c),E_c d_B(c)}<=D,
with fixed D>=1. The references must control ALL full unchecked inputs
and remain fixed across the half-exposure stages, as above. Then the
same scalar contradiction gives
  P(all wins)<=min{1,D exp[-2^-75 epsilon^2 n]}.               (R15)
Indeed, a larger probability would give L+log D<2^-75 epsilon^2 n,
t<=2L/epsilon<n/2, and tau_ref<2^-74 epsilon^2, below the frozen
contradiction threshold. The case with exp(s|C|) instead of D has the
gap-cubic/(epsilon+s) rate stated after (R10).

This is NOT an upper bound on unrestricted omega_star(G^n) without
proving that the selected-history hypothesis holds for all its strategies.
An arbitrary fixed-C example such as (R11) does not automatically define
one global n-round strategy with compatible references for every C.
Moreover, a globally dominated product-answer model can have a stronger
elementary linear-gap bound, so it should not be advertised as a rate
advantage merely because it satisfies (R15). The new unresolved task is
to identify natural nontrivial source families with the required selected
history control, or a payoff-preserving redesign that creates it.

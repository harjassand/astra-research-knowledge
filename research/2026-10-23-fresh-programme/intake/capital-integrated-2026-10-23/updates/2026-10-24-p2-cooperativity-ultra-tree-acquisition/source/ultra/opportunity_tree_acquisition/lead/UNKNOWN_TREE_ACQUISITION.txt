ACQUIRING AN UNKNOWN DEPENDENCY TREE FROM PAID PASSIVE SNAPSHOTS
Lead representation-acquisition construction, 2026-10-24.
No novel learning-algorithm or physical-validation claim.

Different gate from the supplied-frontier theorem
The graph/blueprint and independently prepared conditional rows are no
longer supplied. Instead observe ALL n binary variables X_i in each
independent snapshot, at a charged cost C_snap including readout and any
preparation/reset needed to obtain that independent draw. A time series
with unacquired mixing is not automatically such an oracle.

The scientific MODEL CLASS is supplied: a zero-field binary Markov tree,
with unknown labelled tree T and unknown real edge correlations rho_e,

 P_T,rho(x)=2^-n product_{e=(i,j) in T}(1+rho_e x_i x_j),
 x_i in {-1,+1}, 0<rho_min<=|rho_e|<=rho_max<1.          (1)

The known quantitative bounds are supplied as finite rational bounds
certified to contain the true parameters; epsilon and delta below are
finite rational inputs too. Integer observation counts use certified
upward bounds on the displayed logarithms. All vertices are observed;
unmodelled latent nodes are excluded. This includes strong
interactions and exponentially small configuration probabilities, not a
weak total-modulation hypothesis. Exact membership in this class is NOT
established by the reconstruction procedure below.

1. Central representation invariant and finite identification margin
Choose a root, sample it fairly, and independently sample edge signs
Y_e with mean rho_e; propagate child X as parent X times Y_e. This gives
(1), and for any two vertices

 c_uv=E[X_u X_v]=product_{e on the T path u->v}rho_e.    (2)

For any true edge e, remove it to form a cut. Every crossing nonedge f
has a path containing e and at least one other edge. Hence

 |c_e|-|c_f| >= |rho_e|(1-rho_max)
               >=gamma:=rho_min(1-rho_max)>0.          (3)

Here c and hat c are UNCENTERED pair means E[X_u X_v] and the sample
mean of X_u X_v; they are not centered sample Pearson correlations.
If every empirical correlation hat c differs from its true c by at
most alpha<=gamma/4, the true edge e is the unique maximum empirical
absolute-correlation edge crossing its cut. Therefore the maximum
spanning tree of weights |hat c_uv| is EXACTLY T. This is an explicit
representation-learning invariant; no unobserved graph or hidden state
is supplied to the algorithm.

2. Paid observation count and parameter intervals
For n>=2 let D=binom(n,2), 0<epsilon,delta<1 and choose

 alpha=min{gamma/4, epsilon(1-rho_max)/(4n)},
 N >= (2/alpha^2) log(2D/delta).                         (4)

Each X_u X_v is in [-1,1]. Hoeffding and a union bound give one event
of probability >=1-delta on which ALL pair correlations have error at
most alpha, despite dependent pairs within a snapshot. On that event,
the MST is T and for each recovered edge the rational interval

 I_e=[hat c_e-alpha,hat c_e+alpha] intersect [-rho_max,rho_max]

contains rho_e. It has length <=2alpha and all its factors 1+r*s are
positive for s=+/-1. Known sign/lower-magnitude constraints may tighten
I_e but are unnecessary for the following probability envelope. Empty
intervals cause an explicit inconclusive result; they do not occur on
the simultaneous confidence event.

Acquire N FULL snapshots, not N pair-specific preparations. The source
cost is N*C_snap and nN recorded binary values. Directly computing all
pairs costs O(N n^2) integer operations, followed by a polynomial MST.
Correlations are rational counts/N, so tree comparisons and intervals
use finite exact arithmetic, with the rational input bit lengths charged.
The complexity is polynomial in n,
gamma^-1,(1-rho_max)^-1,epsilon^-1,log(delta^-1) and the paid snapshot
cost. No polynomial physical acquisition time is asserted if C_snap is
large/unacquired, or if nominal independent draws are actually correlated.

3. Uniform probability certificates, not just an average fit
For s in {-1,+1}, let

 l_e(s)=min_{r in I_e}(1+r*s),
 u_e(s)=max_{r in I_e}(1+r*s).

Compute the two finite rational functions

 L(x)=2^-n product_e l_e(x_i x_j),
 U(x)=2^-n product_e u_e(x_i x_j).                       (5)

On the SAME confidence event, for EVERY configuration x simultaneously,

 L(x)<=P(x)<=U(x),
 U(x)/L(x)<=[1+2alpha/(1-rho_max)]^(n-1)
           <=exp(epsilon/2)<=1+epsilon.                (6)

No exponentially many confidence tests or observations of the rare
configuration are needed. Summing nonnegative L/U preserves the bound
for any event, but evaluating an arbitrary event sum is NOT claimed
polynomial. A single specified failure configuration is O(n) work;
its event encoding does not smuggle an arbitrary global SAT predicate.
For the aligned configuration all +1, the true probability satisfies

 p_+ <= (1/2)[(1+rho_max)/2]^(n-1),

so it is exponentially small at fixed rho_max<1. Equation (5) still
produces a relative interval in polynomial data/work under the model.
Standard tree message passing can supply other tractable declared
queries; its query complexity must be charged separately.

The recovered tree also defines an ancestral generative representation
with n steps. Local interval factors then give high-confidence upper/
lower future-event messages just as in the earlier frontier theorem.
This does not supply exact true conditional probabilities or a physical
conditional sampler from finite snapshots. The direct probability
interval is already the strongest needed output here.

What was acquired and what remains assumed
The graph and its parameters are acquired with the declared statistical
confidence; no caller-chosen rare context is prepared. Exact tree
factorization, zero field, absence of latent variables, parameter gap,
unchanged source law and iid snapshot access are model/access premises.
Their validity cannot be inferred merely because the algorithm returns
a tree. The companion common-shock construction quantifies this limit.

KNOWN TREE AND HEAT-BATH FORM DO NOT ENSURE FAST PARAMETER ACQUISITION
Direct in-class source-cost obstruction, 2026-10-24.
No new metastability, testing, or algorithm-priority claim. No simulation.

This extends neither the frozen positive star theorem nor its scope. It
tests the remaining physical source gate on a different, fully supplied
tree. The obstruction is a slow RELATIVE phase, which survives quotienting
by global spin flip and directly carries a required edge correlation.

1. Two models with the same known graph and access interface

There are n=2m+2 spins, m>=1. Two hubs A,B are joined by one bridge; each
has m distinct degree-one leaves. All 2m leaf edges have correlation
rho_l=1/2, equivalently Ising coupling J_l=atanh(1/2)=(log 3)/2.
The only unknown parameter is the bridge correlation

 rho_b^(0)=1/4,       rho_b^(1)=3/4.

Each model is an exact positive zero-field binary Markov tree. All edge
magnitudes lie in [1/4,3/4], uniformly in m. Even the labelled graph and
leaf parameters are given, so structure learning is not a hidden cost.

The actual source is continuous-time single-site heat-bath Glauber, with
independent rate-one clocks at all n spins. It starts in the all-plus
configuration under both hypotheses. The observer is given the COMPLETE
continuous spin path and all labelled clock-attempt times, with arbitrary
adaptive computation. It is not given a conditional-probability, energy,
coupling, or latent-randomness oracle. It cannot reset, prepare another
configuration, or intervene on the autonomous dynamics. Supplying the
single all-plus start at no cost only strengthens the lower bound.

The two models therefore satisfy the SAME structural and calibrated
kinetic class. This is not an out-of-class common-shock alternative.

2. An unconditional frozen-hub hazard bound

Construct a reference process in which both hubs are fixed at +1 and all
leaves run their common heat-bath clocks. Starting all-plus, every leaf
at time t is independent of the other leaves and has mean

 mu(t)=rho_l+(1-rho_l) exp(-t) >= rho_l.

This independence is asserted for the UNCONDITIONED reference process,
not for the actual process conditioned on no hub flip. Let S be the sum
of the m leaves adjacent to a given hub. Hoeffding gives, uniformly in t,

 Pr_ref(S<=m rho_l/2) <= exp(-m rho_l^2/8).

While both hubs are still +1, a clock at that hub flips it with probability

 r_b(S)=1/[1+exp(2(J_l S+J_b))],  J_b=atanh(rho_b)>0.

On S>m rho_l/2 this is at most exp(-J_l rho_l m), for either bridge.
Consequently define

 H_m=exp(-m/32)+3^(-m/4),

and obtain E_ref[r_b(S(t))]<=H_m for every t and each hypothesis.

Use the same independent hub clock/acceptance construction on the frozen
reference paths. The first accepted hub flip in an actual model occurs
at exactly the first reference acceptance; until that event, its leaves
and hubs coincide with the reference. Ignoring all later reference
acceptances can only decrease the count. There are two rate-one hubs,
so Campbell's identity / the integrated counting-process expectation gives

 Pr_b(first hub flip by T) <= 2 T H_m.                    (1)

There is no assertion that the two no-flip-CONDITIONED leaf path laws are
equal: survival conditioning can reweight those paths. Bound (1) instead
uses the integrated unconditional reference hazard.

3. Full observed-path indistinguishability

Couple both hypotheses with the same leaf clocks and refresh randomness,
and the same labelled hub clocks. Their complete observable trajectories
coincide until at least one model has a hub flip. A union bound using (1)
therefore gives the conservative bound

 TV(Law_0(path through T), Law_1(path through T))
      <= 4 T H_m.                                       (2)

The labelled clock-attempt records can be included in the coupling; no
information is hidden by observing only sparsely. Arbitrary adaptive
readout/computation from this full transcript cannot increase its TV.

Any test with error <=1/3 under each hypothesis requires transcript
TV>=1/3. A deterministic maximum source duration must therefore satisfy

 T >= 1/(12 H_m) >= exp(m/32)/24.                        (3)

These are conservative constants, not a sharp metastable-time asymptotic.

4. The required rare-event forecast really separates the models

The equilibrium all-plus probabilities are exactly

 p_0=(5/16)(9/16)^m,       p_1=(7/16)(9/16)^m,
 p_1/p_0=7/5.

Their relative-error-1/8 intervals are disjoint: in common units
(9/16)^m, the null upper endpoint is 45/128 and the alternative lower
endpoint is 49/128. An estimate with that relative accuracy and success
probability >=2/3 under BOTH models yields a distinguishing test, e.g.
by thresholding at (47/128)(9/16)^m. Thus it obeys (3), even though
the parameters have constant tree-identification margins and all spins
and clocks are observed. Abstention or nontermination counts as failure
in this success requirement. Estimating the bridge correlation to disjoint
constant-width intervals gives the same obstruction.

The target is the specified equilibrium forecast, not a near-future
event under the nonstationary all-plus initial source law.

5. Adaptive stopping does not remove the physical-time obstruction

Let tau be any stopping time at which the estimator outputs. Use the
same algorithm randomness in the two coupled runs. For any fixed T>0,
if no coupled path discrepancy occurs through T and tau_0<=T, both runs
stop with the same transcript and answer. Therefore

 TV(terminal transcript_0, terminal transcript_1)
      <=4 T H_m+Pr_0(tau>T)
      <=4 T H_m+E_0[tau]/T.                             (4)

If E_0[tau] is infinite the desired lower bound already holds. Otherwise
take T=6 E_0[tau] (the zero-expectation case cannot distinguish). Correctness
under both hypotheses requires TV>=1/3, hence

 E_0[tau]>=1/(144 H_m)>=exp(m/32)/288.                  (5)

The bound concerns one continuously running source with no interventions.
Clocks continue during any observation/computation overhead; that elapsed
time is included in tau. At rate one per site, the expected number of
attempted local updates up to an integrable stopping time is n E_0[tau],
by the Poisson compensator. Readout and computation costs can only add.

6. Operational boundary

The positive STAR construction removes a slow GLOBAL orientation because
its sufficient pair statistics lie in a fast quotient. Here the bridge
product X_A X_B is itself global-flip invariant, but is stuck at +1 until
a hub flips. The independent leaf-refresh Dirichlet form does not refresh
this bridge coordinate, so the star's gap-one proof does not apply.

Thus a tree factorization, all-spin readout, known graph and known local
heat-bath rule do not by themselves provide fast passive acquisition of
the parameters needed for rare equilibrium forecasts. The positive star
result remains valid; extending it to arbitrary trees needs an additional
observable mixing/access certificate. Repeated caller-chosen preparation,
forced hub updates, balanced-neighbour row probes, or supplied parameter
values change the access model and can evade this particular lower bound.

This is a finite reversible metastability/trajectory-coupling obstruction
inside the exact tree class, with conventional ancestry. It is not a
general impossibility for tree learning, independent Gibbs sampling,
physical interventions, or richer paid model-query access. Its hubs have
degree m+1; it makes no bounded-degree-tree exponential lower-bound claim.

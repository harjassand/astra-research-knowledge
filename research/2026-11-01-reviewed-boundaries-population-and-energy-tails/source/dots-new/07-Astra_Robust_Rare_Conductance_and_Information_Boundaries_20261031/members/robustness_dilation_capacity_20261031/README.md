## Running

Keep sibling `dilation_partition_free_20261031/receive_dilation.py` at its
source-relative path. Its SHA256 is checked before import; only Python standard
library is needed. Execute `python -B check.py` from this directory in a COPY to
preserve frozen reports. This actually recomputes both costly513D cases. Use
`--skip-saved` for only unit/adversarial checks; that is not a full receiving replay.

```python
from fractions import Fraction
from receive_robustness import fixture, certify, verify
raw = fixture(2, axis=2)
task = dict(delta=Fraction(1, 500), shape='critical_flat')
certificate = certify(raw, **task)
receipt = verify(raw, certificate, **task)
```

The supplied delta is a hypothesis the program must prove globally, not a trusted
measurement or minimal-error oracle. Pass the ORIGINAL external task to verify.
Unsupported grammar/positivity/precision/tail/grid/serialization/total-width cases
raise `Unknown`, never an unsupported success. Timing, work counts and floating
displays are diagnostic and explicitly not proof-bearing. Historical versions
need to be copied to the original source-relative location before execution.

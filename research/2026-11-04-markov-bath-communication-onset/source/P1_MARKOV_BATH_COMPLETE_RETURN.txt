Choose \(m=\Theta(B^{-1})\). Then \(q_m\) stays bounded below by a positive constant. Since

\[
s=\Theta(t),\qquad B=\Theta(t^2),
\]

we have

\[
m=\Theta(t^{-2}).
\]

The exact-ebit yield per original source use is

\[
\boxed{
R_m=\frac{q_Y}{2}A^{m-1}\log_2m
}
\]

and hence

\[
R_m=\Theta\!\left(t^3\log(1/t)\right).
\]

A fixed two-rail version produces an exact Bell pair but yields only \(\Theta(t^3)\). The growing coherent position space earns the logarithm.

The matching converse is

\[
Q_{\leftrightarrow}(\mathcal B_t)\le h_2(\beta),
\]

where \(h_2\) is binary entropy. Since \(\beta=\Theta(t^3)\), this has exactly the same asymptotic order.

The lower and upper constants are not claimed equal.

## 4. The strongest direct implementation uses logarithmic memory

The weight-one operation does **not** require storing all \(m\) primitive pairs.

Each party maintains a register with basis

\[
|{\rm vac}\rangle,\ |1\rangle,\ldots,|m\rangle.
\]

At position \(j\):

1. Test whether an excitation has already been recorded and the incoming qubit is also one. Reject that overflow.
2. Otherwise coherently transfer a first excitation into memory label \(j\).
3. Reset the incoming qubit.

At the end, reject vacuum and coherently relabel \(j\mapsto j-1\).

The successful local Kraus operator is exactly

\[
W_m=\sum_{j=1}^{m}|j-1\rangle\langle e_j|,
\]

where \(|e_j\rangle\) is the one-excitation string at position \(j\).

This is an operator identity, so it holds for arbitrary coherent inputs entangled with external references. Every accepted history has identical overflow flags and identical reset incoming qubits; no position information leaks into discarded registers.

There is a direct reversible implementation. Let \(C_j\) XOR the binary string \(j\) into memory, controlled by the incoming qubit. Let \(X_j\) flip the incoming qubit exactly when memory equals \(j\). Then

\[
C_jX_jC_j
\]

swaps only

\[
|{\rm vac},1\rangle
\longleftrightarrow
|j,0\rangle.
\]

Equality tests and overflow detection use \(O(\log m)\) Toffoli/CNOT gates with reusable clean work qubits.

The resulting accounting is:

\[
\boxed{
\begin{aligned}
\text{working quantum memory per party}
&=O(\log m),\\
\text{local gates per candidate block}
&=O(m\log m),\\
\text{local overflow measurements}
&=O(m).
\end{aligned}}
\]

For the cubic branch, working memory before coding is therefore

\[
O(\log(1/t)),
\]

rather than \(O(t^{-2})\).

This is an ordinary coherent streaming implementation of the required measurement. Using it avoids attributing an artificial storage burden to the communication law.

**The coherent waiting time remains.** The register must survive the sequence needed to obtain \(m\) successful primitive inputs. Primitive heralds synchronize the two streams, and their latency counts. Local overflow flags can be exchanged at block end, so the decoder does not require an additional round trip for every position.

qubits per original bath use; the adaptive upper bound is approximately

## 5. Why the cubic law holds in every finite dimension

The qubit example exposes the operation. The general proof establishes that the same useful structure always appears in the commuting-noise, noncommuting-Hamiltonian branch.

Choose a common pointer basis for the normal commuting noise operators. If some \([H,L_a]\neq0\), there are levels \(i,j\) and a jump \(L\) such that

\[
\Delta=\ell_j-\ell_i\neq0,
\qquad
H_{ji}\neq0.
\]

Let

\[
G=-iH-\frac12\sum_aL_a^\dagger L_a.
\]

The one-jump operator density is

\[
K(u)=e^{G(t-u)}Le^{Gu}.
\]

Select its constant and centered-linear temporal components:

\[
f_c(u)=t^{-1/2},
\qquad
f_\ell(u)=\sqrt{12}\,t^{-3/2}(u-t/2).
\]

The centered component exposes

\[
[L,G]=-i[L,H].
\]

A known midpoint input preparation and an explicit receiver filter then produce a two-qubit state with:

\[
p_t=\frac{|\Delta|^2}{2}t+O(t^2),
\]

\[
(\rho_t)_{10,10}=O(t^4),
\qquad
(\rho_t)_{00,11}=ct+O(t^2),
\qquad
|c|=\frac{|H_{ji}|}{\sqrt{12}}.
\]

Thus the useful coherence appears at order \(t\) in the conditional state, while the troublesome forbidden population is pushed to order \(t^4\).

The conditional coherent information satisfies

\[
I(R\rangle B)_{\rho_t}
=
\frac{|H_{ji}|^2}{6}t^2\log_2(1/t)+O(t^2).
\]

Multiplying by the primitive success probability gives the explicit information-theoretic lower bound

\[
Q_{\leftrightarrow}(\mathcal B_t)
\ge
\frac{|\Delta|^2|H_{ji}|^2}{12}
t^3\log_2(1/t)+O(t^3).
\]

The construction goes beyond invoking an unspecified asymptotic decoder.

After streaming weight-one concentration on \(m=\Theta(t^{-2})\) successful primitives, the retained state is \(O(t)\)-close to

\[
f_t\Phi_m+(1-f_t)\frac1m\sum_j|j,j\rangle\langle j,j|,
\qquad
f_t\longrightarrow f_0>0.
\]

One physical phase-comparison operation on two such blocks succeeds with constant probability and produces \(\log_2m\) Bell pairs with total batch error \(O(t)\). Pairwise twirling converts the errors into Pauli errors. Different positions within a batch may remain correlated, but each fixed position is iid across independent batches.

An established efficient quantum code can therefore be applied row by row. The construction explicitly acquires the code using random permutations, charges the probability of a bad graph, and assumes no unperformed expansion certification. The decoding theorem used here is the quantum-expander result of Fawzi, Grospellier and Leverrier. :chatgpt-content-reference{index="1"}

For \(n\) coding batches, the resulting resources are

\[
\boxed{
\begin{aligned}
\text{source uses}&=\Theta_{\mathcal L}(nt^{-3}),\\
\text{output ebits}&=\Theta\!\left(n\log(1/t)\right),\\
\text{quantum memory}&=O_{\mathcal L}\!\left(n\log(1/t)\right).
\end{aligned}}
\]

Local block-processing work is \(O(nt^{-2}\log(1/t))\), with additional polynomial coding work. The general coded output approaches perfect ebits; finite exact pure output is the stronger property earned by the explicit qubit specialization.

### The converse that prevents a better order

For each pointer projector \(P_i\), define

\[
\sigma_i(t)=\mathcal N_t^\dagger(P_i).
\]

The proof obtains

\[
1-\operatorname{Tr}\sigma_i(t)^2
=
\frac{t^3}{3}
\sum_a
\|[L_a,[H,P_i]]\|_2^2
+O(t^4).
\]

The pointer state remains pure to first and second order. Its first possible mixed spectral tail is cubic.

Measuring the discarded system in this pointer basis defines a single mathematical squashing map. For every reference–input state, including inputs chosen as a function of \(t\), the associated average conditional entropy is

\[
O_{\mathcal L}\!\left(t^3\log(1/t)\right).

The same map works uniformly over inputs; no interchange of a maximum and an infimum is needed. The channel squashed-entanglement bound then covers arbitrary adaptive two-way communication. That discarded-system measurement is an upper-bound device. The communicating parties do not receive access to the discarded system.

## 6. Finite positive synthesis closes the mode-acquisition problem

The temporal-mode description would be incomplete if it simply assumed access to an arbitrary continuous-field projector.

The construction earns the required filter on a finite supplied environment.

Let \(J\) be the source channel’s Choi matrix. Let \(V\) contain the vectorized desired selected Kraus operators, and choose a finite factor

\[
J=WW^\dagger.
\]

Bessel’s inequality for the chosen temporal modes, together with positivity of the remaining trajectory sectors, gives

\[
VV^\dagger\le J.
\]

Consequently, the exact factorization

\[
B=W^+V
\]

satisfies

\[
WB=V,\qquad BB^\dagger\le I.
\]

The physical receiver success operator is \(B^T\). Choi domination supplies its contractivity.

There is also a quantitative version that avoids an exact support inverse:

\[
B_\lambda=W^\dagger(J+\lambda I)^{-1}V.
\]

It remains contractive, and its coherent synthesis error obeys

\[
\boxed{
\|V-WB_\lambda\|_F^2\le\frac{d^2\lambda}{4}.
}
\]

Thus a prescribed tolerance determines \(\lambda\) directly. The construction does not need the smallest positive Choi eigenvalue. Since \(\operatorname{Tr}J=d\),

\[
\kappa_2(J+\lambda I)\le1+\frac d\lambda.
\]

For a fixed algebraic generator in the canonical finite basis, the manuscript supplies polynomial bit acquisition in the time-description length and \(\log(1/\varepsilon)\). A supplied physical Kraus basis needs coefficient access of corresponding precision.

The selected operators themselves come from fixed-size block matrix exponentials. For known finite collision models, the emitted stream can also be compressed sequentially into a register of dimension at most \(d^2\), with work linear in the number of collision units at fixed local dimensions. Known tensor-network compression is a relevant precedent; it is not claimed as a new compression principle. :chatgpt-content-reference{index="3"}

This removes a support-conditioning obstacle in implementing the operation. It does not calibrate an unknown physical bath or make exact generator classification robust to finite-data uncertainty.

## 7. The linear and zero branches also close constructively

When the noise family is not commuting and normal, a nonnormal direction is found in the finite list

\[
L_a,\qquad
\frac{L_a+L_b}{\sqrt2},\qquad
\frac{L_a+iL_b}{\sqrt2}.
\]

For a selected nonnormal \(L\),

\[
L^\dagger L-LL^\dagger
\]

is nonzero, Hermitian and traceless. A negative eigenvector supplies an explicit two-dimensional extraction space.

Coherent vacuum attenuation and jump selection succeed with probability \(\Theta(t)\), producing a two-qubit state with a fixed strict entanglement margin. Explicit local filtering, finitely many recurrence rounds and an acquired efficient code yield a positive constant conditional rate. Hence the total rate is \(\Omega(t)\).

A separate adaptive converse proves

\[
\|T\circ\mathcal B_t\|_\diamond\le1+O(t),
\]

and therefore

\[
Q_{\leftrightarrow}(\mathcal B_t)=O(t).

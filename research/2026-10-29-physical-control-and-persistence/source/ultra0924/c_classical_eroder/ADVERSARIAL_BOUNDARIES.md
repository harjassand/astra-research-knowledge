# Adversarial checks retained at the construction boundary

1. The register is a classical repetition encoding, not a quantum
   repetition code protecting arbitrary phases. A terminal majority
   observable is a mathematical decoder, not an error-free hardware bus.

2. The initial source's sparse error pattern is fixed, or mixed independently
   of future primitives. This is not a simultaneous union over every
   adversarially future-selected initial error pattern. The later fault
   labels DO have the stronger future-dependent quantifier.

3. All-wrong replacement is a pathwise bound only because every fixed
   nominal draw is monotone, and bit complement maps the retained1 case
   to the retained0 case. A generic multi-symbol decoder or a Boolean rule
   with NOT applied to arbitrary inputs does not inherit that order.

4. Source count is not asserted Markov. Its legitimate birth/death
   domination is established only after the worst-label coupling, and
   only before first exit from the small-density region.

5. The clock-rate factors are included in a=17/128,d=105/128. Omitting
   them would invalidate the heterogeneity claim. The copying excursion
   threshold isceil(9n/1024), not the earlier exact-rate-only ceil(n/128).
   RUN1_EXACT_RATE_CONTRACT.json is historical; REGISTER_CONTRACT.json
   is the governing heterogeneity-qualified output.

6. The first-crossing event is bounded by a compensator and a uniform
   exponential moment. The expectation of the error count and an average
   correction speed are not being used as a failure probability.

7. Buffered copy has NO feedback to its source. Coalescence of two
   destination initializations at the first reset/update of each site
   would fail for a generic controller which reads its old state.

8. The read-q bound uses independent primitive Poisson streams and private
   nominal coins. One support stream can touch at most q separate pairs.
   Dynamic inter-pair feedback, shared global randomness, or a single
   correlated unlabelled fault source can violate that read-q admission.

9. Unknown error maps can be arbitrary on their specified support; unknown
   state-dependent or future-selected EVENT TIMES are not granted. A bath
   strategy-norm expansion with signed fault terms is not a positive
   Poisson support process.

10. Explicit graph locality is not Euclidean locality. The four-bit
    channel may read graph-distant endpoints with graph radius16/17.
    Executing those paths via faulty messages adds resources not covered
    by simply running the host address arithmetic.

11. Exact Fractions in the receiver are finite arithmetic consequences of
    the proof. The graph's spectral theorem and the Finner/read-q import
    remain named analytical premises. File hashes, a large stated horizon
    and a successful compiler do not verify an autonomous physical memory.

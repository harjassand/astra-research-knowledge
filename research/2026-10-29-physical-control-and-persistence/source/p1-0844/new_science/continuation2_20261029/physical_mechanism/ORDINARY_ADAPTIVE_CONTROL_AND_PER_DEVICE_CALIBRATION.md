# Ordinary adaptive control and per-device calibration of frozen disorder

29 October 2026. Complementary Astra P1 investigation. These are strong
conventional comparators for the inherited acquired mixture construction.
Nothing here claims to invent hitting-time control, system identification,
Bernoulli factories, exact sampling or relative-entropy propagation.

## 1. What the ordinary alternative actually achieves

The inherited source B has fixed hidden h in [-1,1] and binary visible Y.
Conditional on h, one raw operation j flips Y with probability

    p0(h)=1/10+h/20,
    p1(h)=3/10+3h/20,
    p2(h)=1/4+h/10,
    p3(h)=7/20+h/10.

Each call has the same physical duration t0, and its fresh flip increment is
independent of the entire previous history conditional on h. There is no
additional unmodelled returning memory. Endpoint readout is exact and
noninvasive in the theorem. Switching, readout and randomization have actual
costs. The continuum h need not be drawn from a known prior or from equilibrium.

The declared read/choose/call interface must be an actual interface. Any
unavoidable evolution during sensing, randomization or controller latency
must be included in the native kernel or prevented by an actual holding
control. A bounded controller time alone does not imply state preservation.
Independent selector draws can be prepared before the declared input epoch;
their acquisition costs remain. The continuous generator interface in
Section 6 is an additional model promise, not inferred from endpoint data.

Three ordinary routes are constructive:

1. Observation feedback implements any desired endpoint binary transition
   EXACTLY without estimating h, at a random duration. Complete exposed
   stopping transcripts remain h-dependent.
2. Repeated mode-3 waiting approximates visible reset geometrically, with no
   calibration. With an actual identity branch, it also approximates both useful
   target transitions while exposing the chosen word and its duration. Native
   interiors are excluded from this marked service record.
3. Calibration on the SAME device yields two useful target transitions within
   a finite-horizon guarantee. A positive marked reference predicts all raw
   action keys, intermediate endpoint reads and durations; they may remain
   exposed. There is no unconditional-density or retained-record-cardinality
   premise. Calibration/deployment sameness is a substantive static-h promise.

Thus source B's open-loop exact no-go is not a no-go for useful ordinary
control. The exact one-call mixture from source A remains a stronger special
interface, but should be compared with these actual alternatives.

## 2. Exact feedback by stopping on the desired visible state

To implement logical NOT, repeatedly execute mode 3, observing each endpoint,
until Y differs from its starting value. Conditional on ANY fixed h and old
record, the number N of calls is geometric with success p3(h). Therefore

    P(N>L |h,old record)=(1-p3(h))^L <=(3/4)^L,
    E[N |h,old record]=1/p3(h)<=4.

At termination the actual physical bit is the desired one, with probability
one. The hidden h is unchanged. No microscopic reset, stationarity, guessed
parameter, or asymptotic estimator is used.

For a desired flip probability c, independently draw R~Bernoulli(c). If R=0,
return immediately with the same bit. If R=1, run the hitting procedure. The
actual endpoint flip is exactly R. Consequently, any finite or countable
sequence of these completed endpoint operations, with outer feedback using
ONLY admitted old records and completed logical endpoints, realizes the
chosen positive controlled binary chain exactly. This applies to the inherited
useful targets cA=3/20 and cB=3/10. Expected native calls are c/p3(h)<=4c.

An exact external Bernoulli(3/20) or Bernoulli(6/20) can be generated by drawing
five fair bits, rejecting integers 20 through 31, and accepting an integer
below 3 or 6 respectively. This uses eight fair bits on average; it is not a
fixed worst-case bit count. The logical choice R is the eventual output flip,
so retaining R itself adds no hidden-h information. Actual randomizer time,
endpoint reads, switching and computation are still charged.

The scope depends decisively on the record. For the NOT operation, the full
endpoint path up to completion is determined by N and the starting bit. At
h=-1, N~Geom(1/4); at h=+1, N~Geom(9/20). Their TV distance is exactly

    TV(Geom(1/4),Geom(9/20))=13/50.

The difference is attained by the event N<=2. For the c-randomized operation,
the corresponding complete stopping-record discrepancy is 13c/50. Therefore
this is NOT an h-independent complete instrument if stopping times, internal
reads, controller logs or elapsed times are retained. An outer policy using
those timings can also change future logical action choices. One must either
exclude them from the declared service record or use the marked calibrated
model below; they cannot simply be called one observation.

A hard cap L gives an explicit failure flag and failure probability at most
c(3/4)^L. Discarding timing, a sequence of n capped operations has endpoint/
failure-record TV at most n c_max(3/4)^L from the desired always-successful
logical model. Exposing the successful stopping times still reveals h, even
when the deadline failure is tiny. Padding to a common deadline needs an
ACTUAL state-preserving hold after success; an empty identity word does not
supply that physical hold.

The same idea extends beyond this source: if an actual feedback policy has
conditional probability at least p_* of hitting a chosen observable target
per block, uniformly over all relevant hidden states and prior histories,
then repeated blocks hit the target almost surely with E[blocks]<=1/p_* and
geometric tails. This is a strong pointwise reachability premise. An equilibrium
L2 defect does not supply it.

## 2A. Cheap ordinary waiting, with the actual record and identity premise

Mode 3 has centered multiplier

    lambda3(h)=1-2p3(h)=3/10-h/5 in [1/10,1/2].

Consequently L successive mode-3 calls, with their intermediate native
outcomes excluded from the service record, have endpoint kernel

    P3(h)^L = Pi + lambda3(h)^L (I-Pi),

where Pi is the uniform binary reset. Its row TV from Pi is
lambda3(h)^L/2 <= 2^(-L-1), uniformly in the frozen specimen and input bit.
This is already a useful preparation operation without an identity control,
without per-device calibration, and without any ensemble baseline.

If the interface also supplies an ACTUAL identity branch, choose P3^L with
probability 2c and identity otherwise, for c in {3/20,3/10}. The positive
reference chooses exactly the same branch and runs Pi or I. Its unmarked
endpoint flip probability is c. The branch key and durations 0 or L t0 may
remain exposed in both laws: the joint marked row TV is at most

    2c * (lambda3(h)^L/2) <= c 2^(-L).                 (W1)

The word "identity" here means an executable unchanged-state return at this
declared variable-duration interface. It supplies no positive-time protected
hold. Common-deadline service requires an actual state-preserving padding
control and its costs. If even the identity return is not available, only the
reset conclusion above is claimed.

For n adaptive macros the complete marked record, jointly with arbitrary old
record Z and its arbitrarily correlated h, differs from this positive marked
reference by at most

    min(1, n c_max 2^(-L)).                             (W2)

The ordinary hybrid proof conditions on h and the shared prior prefix; its
uniform row premise survives posterior changes and record-selected actions.
No raw interior observations or continuous native path are included. They
have h-dependent laws and require their own comparator.

There is also a sharper conventional likelihood estimate. Put

    d(x)=[(1+x)log(1+x)+(1-x)log(1-x)]/2.

The conditional KL of a reset branch to its uniform endpoint is d(lambda3^L).
The identity branch is identical. Chain rule and Pinsker therefore give

    TV <= min(1, n c_max 2^(-L),
                 sqrt[n c_max d(2^(-L))]).             (W3)

This bound includes keys and durations, since their shared conditional laws
contribute zero KL. Their record may select future targets. It requires only
the stated native endpoint process, not a fitted microscopic path model.

For n=100 and tolerance 0.01, the simple hybrid uses L=12 and gives
30/4096=0.00732421875. The entropy bound already uses L=9 and gives about
0.007565. Expected native calls per macro are 2cL, hence at most 5.4 for L=9,
with maximum nine. For 100 such macros this is at most 540 expected native
calls, versus the conservative million-call calibration bound below. This
ordinary alternative must be included in any resource comparison.

The branch probabilities 2c=3/10 or 6/10 have an exact fair-bit sampler: draw
four bits, reject integers 10 through 15, then compare the accepted integer
with 3 or 6. It uses 6.4 fair bits on average and unbounded but almost surely
finite randomizer time. Word execution, switching, endpoint sensing and the
randomizer's time and precision retain their real costs.

For preparation alone, L mode-3 calls give joint (h,Z,Y) TV at most 2^(-L-1)
from a reference carrying the SAME (h,Z) and an independent uniform Y. The
bound is pointwise in the initial bit and hidden specimen. Any subsequent
COMMON actual physical channel preserves this error, at every horizon,
including adaptive controls and later timing records. This statement is a
physical-reference coupling, not an h-independent predictive model. Retained
reset paths are not included: conditioning on a retained latest reset label
would reveal the state being prepared. Previously retained Z, including the
pre-reset input label, is allowed. Deterministic reset duration L t0 is allowed.

## 3. One-device calibration, including the complete calibration history

Execute N calls of mode 0 and N of mode 3 on the actual deployment device.
For each raw call record the flip increment F=Y_before XOR Y_after. Conditional
on h and the whole pre-calibration record Z, these increments are independent
Bernoulli variables of the appropriate p_j(h). Initial Y is unrestricted.

Let the FULL retained calibration record D include all labels, increments,
raw mode choices, times and known calibration randomization. Estimation uses
its two counts but D need not be erased or replaced by those counts. Clip the
empirical means to the known intervals

    p0_hat in [1/20,3/20],     p3_hat in [1/4,9/20].

For any beta in (0,1), put

    eta=sqrt(log(4/beta)/(2N)).

Conditional on every h and every admissible old Z, Hoeffding and a union bound
give probability at least 1-beta to the event

    G={|p0_hat-p0(h)|<=eta and |p3_hat-p3(h)|<=eta}.        (1)

Clipping cannot increase either error. This conditional-on-the-actual-device
statement survives any initial law of (h,Z), including point masses and
perfectly informative Z. No baseline ensemble is needed. Native fresh
randomness and preservation of h throughout calibration and deployment are
needed. Ordinary unconditioned independence of the observed sequence is not
claimed.

This is not the assertion that a pre-calibration density bound survives data
selection. It is a different receiving route: (1) is a uniform pointwise
parameter-confidence event. Given D, h may be arbitrarily correlated with D.
The probability of failure is accounted for under the actual joint law.

## 4. The same two useful targets with one or two raw calls

Use the two available physical words

    W_low = T0,
    W_high = T3 T3.

The high word has endpoint flip probability r3(h)=2p3(h)(1-p3(h)), lying in
[3/8,99/200]. Its estimate r3_hat=2p3_hat(1-p3_hat) lies in the same interval.
On G, |r3_hat-r3(h)|<=eta, since the derivative 2-4p on [1/4,9/20] lies
between 1/5 and 1.

For either target c in {3/20,3/10}, select the low word with probability

    w_c(D)=(r3_hat-c)/(r3_hat-p0_hat),                    (2)

and the high word otherwise. The known intervals guarantee 0<=w_c<=1 and a
denominator at least 9/40. Fresh physical calls follow the chosen word. Both
conditional endpoint rows are symmetric. Under the fitted model,

    w_c p0_hat+(1-w_c)r3_hat=c.

Under the actual fixed h, their endpoint flip error is

    |w_c p0(h)+(1-w_c)r3(h)-c|<=eta                     (3)

on G. The proof is just the weighted sum of the two estimation errors; it does
not pay an inverse denominator in the final output error. Neither h nor its
affine representation is estimated. A known bracketing interval is sufficient.

This realizes the SAME targets as the root's exact source-A example, with at
most two raw calls per macro. The low/high branch can be retained, along with
the intermediate high-word endpoint and elapsed time t0 or 2t0. No padding is
needed for the marked reference below. If one instead insists on an unmarked
fixed-duration instrument, actual padding or an appropriate restricted record
must be supplied.

The probabilities in (2) are rational when based on integer counts and rational
clipping endpoints, so exact sampling from fresh fair bits is possible by
integer rejection. Their numerator and denominator have O(log N) bits: the
unreduced denominator is bounded by a fixed constant times N squared. Exact
integer rejection uses O(log N) fair bits in expectation, with an unbounded
but almost surely finite number of attempts. Its bit and runtime costs are
real. If implemented mixture
probabilities differ by total variation zeta per macro, add n zeta to the
record bound. Finite arithmetic can instead use certified intervals.

## 5. Complete exposed records have a positive fitted instrument

Freeze the fitted raw probabilities after calibration. Define a genuine
positive two-state marked reference that chooses exactly the same word using
(2), then runs its one or two raw transitions with probabilities p0_hat and
p3_hat. It records the chosen word, every raw endpoint, and its corresponding
deterministic elapsed time. Its outer policy sees the same full record format.
Its unmarked logical transition for action c is exactly flip-c.

For a single Bernoulli step,

    KL(Bern(p)||Bern(q)) <= (p-q)^2/[q(1-q)].

All fitted raw probabilities lie in [1/20,9/20], so

    d_raw=min q(1-q)=19/400.

Conditional on fixed (h,D,Z) satisfying G, any causal raw-control policy using
modes 0 and 3 for at most L raw calls satisfies the KL bound L eta^2/d_raw
against the fitted model, by the chain rule. This includes policies using all
old records and all previous exposed keys, endpoints and timing. Policies
must choose an action before its fresh native randomness. Any random choice
law shared by the actual and reference policy adds zero conditional KL.

Give actual and reference laws the SAME initial (h,D,Z,Y_service_start), then
marginalize h at the end. Split the shared initial measure into G and G^c.
The latter has total probability at most beta; apply Pinsker on G. Therefore

    TV(complete actual record, complete fitted record)
       <= min(1, beta + eta sqrt[L/(2 d_raw)]).           (4)

For n compiled macros, L<=2n, giving beta+eta sqrt(n/d_raw). This compares
jointly with the entire D and Z; it is not conditional coverage claimed for
every rare observed D. No retained-bit count stands in for acquisition.

If service hides the word branch and all internal endpoints, and the outer
policy only uses the unmarked macro record, the reference is simply the two
fixed target matrices. Equation (3), and

    d_target=min{(3/20)(17/20),(3/10)(7/10)}=51/400,

give the sharper bound beta+eta sqrt[n/(2 d_target)]. This sharper constant
must not be used for exposed primitive marks without their separate model.

A data-conditioned positive reference is an operationally meaningful fitted
model. It is NOT the original device independently prepared at a global
hidden equilibrium. An infinitely long future can eventually distinguish any
nonzero per-device estimation error. The theorem makes no exact all-horizon
claim from finite calibration.

## 6. Full continuous-time records at the warranted generator interface

The inherited explicit source has a compatible symmetric bit-flip generator

    q_j(h)=-log(1-2p_j(h))/(2t0).

Only when this generator realization is actually warranted may endpoint
calibration be used to model within-call continuous records. An arbitrary
kernel with the same endpoints need not have this intervening path law.
Set qj_hat using the same formula on pj_hat. On G,

    |q0-q0_hat| <= (10/7) eta/t0,
    |q3-q3_hat| <= 10 eta/t0,
    q0_hat >= -log(9/10)/(2t0),
    q3_hat >= log(2)/(2t0).

For a full observed jump process under predictable selection of modes 0 and
3, compare the actual and fitted hazards along the SAME recorded history.
The usual likelihood ratio has a sum of log(q/q_hat) at jump times and the
compensator integral. Taking expectation yields

    KL = E int_0^T [q log(q/q_hat)-q+q_hat] dt
       <= E int_0^T (q-q_hat)^2/q_hat dt
       <= [200/log(2)] (T/t0) eta^2.                     (5)

The first inequality is log x<=x-1. The last constant also dominates mode 0's
200/[49(-log(9/10))]. This allows arbitrary nonexplosive predictable mode
selection with a declared deterministic total physical-time ceiling T. The
fitted controls and physical record clocks are shared. Complete readout,
switching and precision costs remain; a continuous sensor is not supplied by
an endpoint assay.

After the same good-event split,

    TV(full controlled continuous record, fitted record)
       <= min(1,beta+eta sqrt[(100/log(2))(T/t0)]).        (6)

This is a conventional path-likelihood bound. Its coarser constants reflect
the much richer record. It neither hides clock information nor infers a
microscopic semigroup from finite endpoint data without the stated model.

## 7. Preparation and resource accounting

Conditional on any h,D on G, repeating the actual compiled action cB=3/10
has centered contraction at most r=2/5+2eta, provided eta<3/10. Thus m reset
macros prepare Y within r^m/2 of uniform independently of (h,D,Z). Reset
internal outcomes must be excluded from the later service record for this
particular contraction statement; conditioning on a retained latest reset
label would of course reveal Y. A different instrument proof is needed if
reset paths remain retained.

Following with n macros gives the target logical reference bound

    beta + r^m/2 + eta sqrt[n/(2 d_target)],              (7)

with the appropriate marked bound substituted if service marks are exposed.
The physical reference carrying the SAME h,D,Z but an independent uniform Y
has preparation error beta+r^m/2 for every subsequent actual service channel,
regardless of horizon. That reference retains the hidden specimen and its
information; it is not the original global mu independently of D or Z.

For target total finite-record tolerance epsilon>beta and n macros, the marked
bound is ensured by

    N >= n log(4/beta)/[2 d_raw (epsilon-beta)^2]          (8)

samples PER calibrated raw mode. Calibration uses 2N t0 native time and
2N+1 endpoint reads. Deployment uses at most 2n t0 native time, n exact
word-selection draws, and up to 2n endpoint reads. The sharper unmarked bound
uses N>=n log(4/beta)/[4 d_target(epsilon-beta)^2]. Numeric resource tables in
the executable are theorem arithmetic, not acquired trials.

Known uniform rate drift or actuation/sensor errors can be added at their
actual interfaces. Without such a contract, static-h calibration does not
survive specimen replacement, drifting kinetics or hidden state evolution.
If each raw transition/read instrument has uniform TV implementation error
xi, a complete-protocol hybrid across calibration plus deployment charges
at most (2N+2n)xi. Large trial count can make this physical-error budget severe.

## 8. Interpretation

The cross-Gram method and this per-device learner answer different access
questions. The cross Gram identifies relative hidden responses across an
ensemble without assuming every specimen behaves as a stationary observable
binary Markov chain. The present same-specimen calibration exploits precisely
that additional conditional structure. It preserves registration by staying
on one frozen h; isolated assays on fresh unrelated specimens do not provide
it.

A competent ordinary controller therefore has exact variable-time endpoint
control, cheap uniformly robust waiting, and a data-conditioned positive model
with finite-record guarantees including exposed native marks. Calibration is
useful when a short native-word latency or the full intermediate/continuous
record is required; it is not needed for bare approximate preparation or the
waiting macro's declared endpoint-and-word record. The explicit source-B exact
no-go must be stated at its bounded-duration or exposed-clock interface. It is
not a no-go for useful approximate physical control.

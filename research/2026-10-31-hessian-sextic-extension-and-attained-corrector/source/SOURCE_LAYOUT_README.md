# Receiver dependency layout

The latest final snapshot alone is not standalone. SOURCE_LAYOUT.json links current final files and previously retained originals under the expected outputs tree, including graded_stabilization, square_completion, degenerate_completion and hopf_structure helpers/certificates. The copy-only helper takes explicit --repository, --layout and --output arguments,verifies hashes/lengths and refuses conflicting overwrite. It imports/runs no producer code. Original mathematical source bytes stay unchanged;this layout does not certify identity with reported executions or imply independent scientific review. Broader numerical work/ scripts are not packaged as standalone. The epoch/topology receipt SHA values identify original captured bytes;SOURCE_LAYOUT gives the actual byte-identical public files for this receiver tree.

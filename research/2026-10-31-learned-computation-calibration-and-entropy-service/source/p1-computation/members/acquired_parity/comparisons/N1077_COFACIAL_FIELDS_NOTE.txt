EARNED MACHINERY

The source obtains a two-term CP decomposition of each generic tensor by a
2x2 matrix pencil, with invertible leg-factor matrices A_(v,e). For e=vw,
W_e=A_(v,e)^T A_(w,e). Choose local endpoint scalars satisfying

  r_(v,e)^2 = W_10 W_11 / (W_00 W_01),
  r_(w,e) = W_11 / (W_00 r_(v,e)).

Then diag(r_(v,e),1) W_e diag(r_(w,e),1) is [[a,b],[b,a]]. Compensation at v
changes its COPY weights to [1/g_v,1], where g_v=product_e r_(v,e).
The intrinsic obstruction is beta_v=g_v^2. Its equality to one is independent
of CP rescalings and swaps, though swaps can invert beta_v. The N1077 parity
admission criterion is beta_v=1 at every vertex.

Opening: edge symmetrization itself does NOT require beta_v=1. Arbitrary
generic inputs therefore acquire a zero-field Ising edge representation with
nontrivial vertex fields only on the learned set

  D = {v : beta_v != 1}.

At the other vertices g_v=+/-1. In a connected component containing a defect,
choose a spanning tree rooted at one defect, process vertices toward the root,
and flip both endpoint square-root signs on a parent edge whenever necessary
to make a balanced vertex g_v=1. Defect vertices absorb sign residue. If a
component contains no defect, use the source's global even/odd sign test;
the odd case has zero partition. No hidden field support is supplied.

PHYSICAL PARITY READOUTS THROUGH SIGNED ACQUIRED GRAPH KERNELS
2026-10-31. Addendum to GRAPHIC_PROOF.txt.

RESULT

An acquired planar cut-space kernel supports every single original-coordinate
parity readout, not only the acquired features. A conjunction of original
parity evidence has a finite, explicitly charged Fourier projection. Its cost
can be compressed from 2^k to 2^t, where k is the evidence rank and

  t = rank(A) + k - rank([A;C])
    = dim(row(A) intersect row(C)).

The proof uses signed partition sums, exact polynomial interpolation when a
Fisher denominator vanishes, and ordinary binary linear algebra. These are
classical algebraic operations, not a new inference engine. Parent integration
implements this extension; signed_parity_audit.py independently checks its
mathematics against complete physical-state enumeration on a small model.

1. SIGNED FISHER EVALUATION IS VALID

Let the acquired feature image be the cut space of a connected cubic planar
graph, with the previously acquired embedding and Kasteleyn orientation. The
weights w_e(0),w_e(1) may now be arbitrary exact rationals, including negative
values and zeros. Define

  a_e=(w_e(0)+w_e(1))/2, b_e=(w_e(0)-w_e(1))/2.

Whenever every a_e is nonzero, the existing construction is an algebraic
identity:

  Q(w) = 2^(V-1) product_e a_e * signed_Pfaffian(K(w)).

Its external dimer weights are b_e/a_e. Neither negative a_e nor a negative
prefactor invalidates the identity. The local K_4 matching identity is a
polynomial identity; the Kasteleyn orientation makes the formal Pfaffian
coefficient of every perfect-matching monomial have the same sign, independent
of the numeric signs of its edge weights. That common orientation sign is
still calibrated by the all-internal matching. Numeric edge-weight signs stay
inside the monomial and must NOT be absorbed into the calibration. In
particular, taking an absolute value or a positive square root of a determinant
would be incorrect for signed readouts.

Zero weights do not invalidate a precomputed orientation: the orientation is
for the fixed decorated graph, before any coefficient is specialized to zero.
If a pair is identically (0,0), the full partition is exactly zero and should
return immediately.

2. ZERO-DENOMINATOR REPAIR WITH PAID INTERPOLATION

Suppose q remaining nonzero edge pairs have a_e=0, equivalently w_e(1)=-w_e(0).
For precisely those q edges replace BOTH entries by

  w_e(b;t) = w_e(b)+t.

Other edges remain unchanged. The complete code partition Q(t) is a polynomial
of degree at most q: in its defining sum, each selected edge factor is affine
in t. On every modified edge, a_e(t)=t and b_e(t)=b_e. Thus at t=1,...,q+1,
all Fisher denominators are nonzero; the signed kernel can evaluate Q(t).

The (q+1)-st finite difference of a degree-q polynomial vanishes, giving

  Q(0) = sum_{j=1}^{q+1} (-1)^(j-1) binom(q+1,j) Q(j).

Interpolate the FULL partition Q(j), including its signed product-of-a
prefactor. The bare Pfaffian is generally rational in t and is not the object
to which this finite-difference formula applies. For q=0, use one direct
signed kernel evaluation.

Cost. At most q+1<=s+1 Pfaffian evaluations are charged. Each takes O(s^3)
rational operations in the present backend; the worst-case readout therefore
takes O(s^4) rational operations. The interpolation coefficients have O(q)
bits, and j has O(log s) bits. Adding j to an input rational increases its bit
length only polynomially. Products, sums, and Pfaffian minors retain polynomial
bit length in s and the explicit rational-weight encoding. Exact arithmetic
is essential to this claim: cancellation can be severe, and no floating-point
relative-error guarantee is asserted for a signed sum near zero.

3. A SINGLE PHYSICAL PARITY

The current base weight must depend only on y=Ax:

  W(x) = product_e w_e(a_e x).

Nonnegative reweighting and any acquired-feature clamps satisfy this contract.
Define the unnormalized physical-parity moment

  T_c = sum_{x in F_2^n} (-1)^(c x) W(x).

If c is not in row(A), choose v in ker(A) with cv=1. Translation x->x+v
preserves W and reverses the character, so T_c=0 exactly. Gaussian elimination
decides membership; no partition evaluation is needed for this outcome.

If c is in row(A), solve A^T lambda=c. Then

  (-1)^(cx) = (-1)^(lambda dot Ax).

Consequently flip the sign of w_e(1) on exactly the support of lambda and
evaluate the signed cut-code partition. Multiply by the original fiber factor
2^(n-rank A) (and any separately retained constant energy factor) to obtain
T_c. Different solutions lambda differ by ker(A^T) and therefore give exactly
the same function on im(A), so the result does not depend on a hidden basis
choice. The physical expectation is T_c/T_0 when T_0>0.

IMPORTANT BASE-EVIDENCE SCOPE. If the base already includes physical evidence
C_0 x=z_0, the balance test is not simply c outside row(A). One must test
c outside row([A;C_0]). When c=lambda A+mu C_0, the restricted character is
(-1)^(mu z_0) times the corresponding feature twist. The simplest safe API is
to retain the unconditioned/feature-clamped T_c primitive and implement all
physical evidence by the projection below.

4. PHYSICAL EVIDENCE: FINITE PROJECTION AND OVERLAP COMPRESSION

Reduce Cx=z by exact binary Gaussian elimination, checking its consistency and
retaining an equivalent independent-row system of rank k. Inconsistent
evidence has mass zero. For consistent evidence,

  1[Cx=z] = 2^(-k) sum_{u in F_2^k} (-1)^(u dot z) (-1)^((C^T u)x),

so its unnormalized mass is

  Z_C(z) = 2^(-k) sum_u (-1)^(u dot z) T_(C^T u).

This is valid for every evidence system. It is not a claim that 2^k is cheap
when k grows. However the fiber-balance lemma kills every term outside

  U_0 = {u : C^T u belongs to row(A)}.

Because C has independent rows, u->C^T u is injective. Hence

  dim U_0 = dim(row(C) intersect row(A))
          = rank(A)+k-rank([A;C]) = t.

Compute U_0 by solving A^T lambda+C^T u=0, projecting a nullspace basis to
its u-coordinates, and row-reducing that projection. This is paid polynomial
binary linear algebra. Enumerate the 2^t combinations of the resulting basis.
The prefactor remains 2^(-k), NOT 2^(-t).

In the parent's rank notation, d_0=s-rank(A) and
d_C=s+k-rank([A;C]), so t=d_C-d_0. The previously acquired graph kernel
handles the baseline dependencies d_0; the projection pays only the added
evidence overlap t. This is a computational improvement over discarding the
acquired graph and running a total-syndrome DP with 2^d_C states.

Special case t=0: all nonconstant projection terms vanish, giving
Z_C(z)=2^(-k) T_0. Such evidence may have exponentially small probability even
though its mass is computed without a rare-event rejection factor. It only
constrains the uniform fibers and leaves the feature distribution unchanged.
If rank(A)=n, then t=k; the free-fiber simplification disappears.

5. PHYSICAL PARITY MARGINALS AFTER PHYSICAL EVIDENCE

The conditional numerator for another physical parity c is

  N_(c,C,z) = 2^(-k) sum_u (-1)^(u dot z) T_(c+C^T u).

Nonzero terms lie in

  U_c = {u : c+C^T u belongs to row(A)}.

This is either empty or an affine coset u_0+U_0. Determine which and obtain
u_0 by solving A^T lambda+C^T u=c. Thus at most 2^t signed moments are needed
for the numerator as well. When Z_C(z)>0, the expectation equals
N_(c,C,z)/Z_C(z). For a genuinely nonnegative base distribution, exact checks
0<=Z_C<=T_0 and |N|<=Z_C are useful diagnostics. At zero evidence mass the
conditional distribution is undefined.

Total upper bound for one joint-event mass or one conditional parity readout:
paid polynomial preprocessing plus O(2^t (s+1) s^3) rational operations in the
current simple signed Pfaffian implementation. The common case with no zero-a
edge in any used twist removes the extra (s+1) interpolation factor. Actual
kernel calls, cancellations, and cache hits should be recorded, not replaced by
this worst-case expression in experimental reports.

6. WHAT THIS DOES AND DOES NOT EXTEND

This extension earns original physical parity readouts without observing a new
operation or acquiring more energy samples. It does not make arbitrary complex
observables sparse in the Walsh basis, and it does not remove the 2^t cost of
large evidence overlap. It also does not provide a MAP theorem by replacing
addition with minimization: the Fourier projection has signed cancellations.
The previously preserved graphic/cographic/trellis optimization distinctions
remain relevant.

An optional sampling corollary follows: sequentially clamp acquired features,
evaluate the evidence mass of each branch with the same U_0, and after selecting
the full y solve [A;C]x=[y;z] and draw uniformly from its affine solution space.
Feature clamps leave row(A), U_0, and t unchanged, so this needs O(s 2^t)
signed-readout calls up to interpolation and polynomial overhead, without
rejection from the rare unconditional event. This addendum does not claim
that the parent has executed that broader sampling extension; the present
implementation task is the signed readout and finite projection.

7. INDEPENDENT EXECUTABLE AUDIT

signed_parity_audit.py uses a dense hidden rank-7 cube code in nine physical
bits and twelve features. It acquires the graph and embedding using the same
matrix-only interface, then independently inserts signed external weights
into the fixed Fisher topology. Direct enumeration covers all 512 physical
states. Its successful run checked:

  * 14 distinct physical twists, including an outside-rowspace zero;
  * 43 exact Pfaffian calls, including 16 negative prefactors;
  * 12 interpolation cases, with q as large as 12;
  * an identically-zero edge-factor shortcut;
  * rank-3 physical evidence with t=2, using four possible nonzero terms;
  * conditional parity numerators with both a nonempty affine coset and an
    empty affine coset of admissible twists.

All equalities used exact rational arithmetic. The production graphic kernel
was left unchanged by this audit; the parent owns the signed API integration.
SIGNED_PARITY_AUDIT.json records the compact successful output.

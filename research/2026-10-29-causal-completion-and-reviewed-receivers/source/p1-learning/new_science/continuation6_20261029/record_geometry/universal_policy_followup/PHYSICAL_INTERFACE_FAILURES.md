# Exact boundaries of a universal policy experiment bank

Date: 2026-10-29. Existing Astra P1 / record_geometry role.

These examples delimit the receiving claim. They do not challenge the correctly scoped physical-path likelihood identity or the conventional theorem in `ORDINARY_UNIFORM_POLICY_LEARNING.md`.

## 1. Literal private random keys

There is one action decision and no plant dynamics. Draw a fair bit `U`. Behavior selects `A=U`. The target selects `A=1` while still drawing a dummy fair bit `U`.

Behavior assigns probability `1/2` to each of `(U,A)=(0,0),(1,1)`. The target assigns `1/2` to `(0,1),(1,1)`. The target is not absolutely continuous with respect to behavior on this augmented record. An action-only likelihood ratio cannot compare the complete literal key record.

After marginalizing `U`, the valid ratio is `2 1{A=1}`. An arbitrary hidden plant can be attached after the action without changing this obstruction. A theorem may include latent plant states, observations, actions and common old records while excluding private selection keys. If a downstream service needs the keys too, their joint law must be treated separately.

A logged behavior propensity is also an analysis annotation, not automatically an identically generated target-controller output. It may be carried along under a common explicitly specified annotation map.

## 2. Selection latency

Let a physical clock evolve as `X(t)=t`, with final output the elapsed time when the only available action occurs. Behavior acts immediately; the target spends one time unit selecting the same action. Both action likelihood factors are one; the physical output laws differ.

The common conditional plant kernel must include relevant action timing. Protected isolation, a common external action clock, or a logged/reweighted timing kernel can supply the missing interface. Assigning the same action name does not.

KT selects rational probabilities. Exact fair-bit rejection can have random unbounded duration. A fixed decision deadline therefore does not follow from the probability formula; bounded-time approximate selection has an actual error to charge.

## 3. A frozen bit defeats unjustified independent trials

There is one action. At fabrication, draw `Z ~ Bernoulli(1/2)`. Every nominal trial on that specimen reports `R_i=Z`; nominal restarts do not refresh it.

All weights are one, but the empirical mean is `Z` for every bank size. Its deviation from the population value `1/2` is exactly `1/2` with probability one. Calls on one unrefreshed specimen do not supply independent population preparations.

Conditional on this device's fixed `Z`, its value is `Z`, and the data correctly learn that different quantity. A valid conditional deployment claim must name that device law. Martingale concentration may sometimes estimate an average of conditional values over the actual evolving starts; that average is not automatically a future deployment value or a fixed-baseline value.

## 4. Post-data invention of arbitrary tasks

With one action, let independent episodes report `X_i ~ Uniform[0,1]`. After seeing the bank `D`, define

\[
R_D(x)=\mathbf1\{x\in\{X_1,\ldots,X_N\}\}.
\]

Its empirical value is one and its deployment expectation is zero almost surely. The policy coverage factor is one. Thus uniformity in policies does not supply uniformity over arbitrary newly invented task functions. A declared finite task list, a controlled task class, or an independent test bank is different.

Similarly, uniform confidence for probabilities on one supplied context map is not uniform confidence over arbitrary data-selected partitions of histories.

## 5. Domination cost is not the difficulty of every task

For one context with `A` actions, KT domination has order `H^((A-1)/2)`. A constant reward requires no experiment to select a useful policy. Deterministic fixed-context targets admit domination `A^S` independent of horizon. Unreachable contexts do not contribute their full nominal parameter count to a particular plant's difficulty.

A lower bound using separated response regions must state worst-case plant/task quantifiers. It must permit every experimental strategy promised by the upper theorem, including adaptation within and across episodes, and must concern final selected value rather than only an importance-sampling estimator. Root's reviewed lower construction satisfies these distinctions at its stated interface. Its family is chosen after the requested accuracy, or embedded in a single class containing all reward gaps.

For a random episode stopping time, the null-to-alternative KL counting proof naturally gives expected cost under the null. It does not automatically imply the same expected cost on every alternative. The accepted root theorem explicitly uses a fixed or hard budget.

## 6. Adaptive contexts and exact normalized maximum likelihood

With predetermined visit counts for each context, separate normalized maximum-likelihood action-string codes give a product optimum. If the plant chooses future contexts in response to earlier actions, normalizing by the future context path can define an unavailable noncausal experiment.

The causal per-context KT rule and its individual-sequence guarantee survive. An exact finite-horizon minimax constant needs a separately specified context-generation game. A horizon-exponent lower bound under a fixed schedule, as used by root, avoids claiming an unjustified exact optimum for arbitrary adaptive contexts.

## 7. Surviving claim

With actual action semantics and timing, a fixed supplied context architecture, recorded task values, a warranted independent-start or conditional-dependence contract, and a controlled task class, a universal controller can provide reusable experiments for a data-selected untested policy without reconstructing microscopic state. This is a strong conventional method.

Episode preparation, native calls, sensing, randomization, latency, storage and optimization remain costs. Robustness to within-episode hidden memory does not supply those resources.

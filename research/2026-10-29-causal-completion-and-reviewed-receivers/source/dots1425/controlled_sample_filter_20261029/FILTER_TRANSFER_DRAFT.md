# Spectral acceptance preserves the logical subsystem without a junk eigengap
2026-10-29. Pending composition, not an accepted robust recovery theorem.

Consider N_eta(rho)=(1-eta)V(rho tensor sigma)V†+eta I_D/D, with code support dimension d=kr and fixed memoryless parameters. Then tau=N_eta(I/k) has eigenvalues (1-eta)lambda_a/k+eta/D on each k-dimensional logical block, and eta/D outside the code support.

An ideal finite phase-estimation acceptance instrument built from controlled exp(i pi tau) acts identically on every logical vector in each such block. Its actual scalar acceptance profile f(lambda) need not be a sharp projector. After discarding phase records, the signal part is exactly V(rho tensor sigma_f)V†, with sigma_f diagonal entries lambda_a f((1-eta)lambda_a/k+eta/D). Near a chosen threshold, arbitrary reweighting of junk is harmless: there is no need for a gap between junk eigenvalues, nor for maintaining coherence between distinct junk eigenvalues, since the input encoding is already block diagonal in that basis.

Choose gamma>0 with eta/D<=gamma/4. Ordinary finite phase estimation of phase lambda/2, unwrapped to[-1/4,3/4), with M>=64/gamma grid points has a constant-error test distinguishing lambda<=gamma/4 from lambda>=gamma. Repeated independent phase-estimation flags conditioned on each eigenvalue, followed by a majority test, reduce misclassification to zeta with O(log(1/zeta)) repetitions. This is an ideal controlled-evolution statement; controlled DME must supply the joint instrument accuracy separately. Phase-estimation estimates near phase zero must be unwrapped; treating negative wraparound as a large positive eigenvalue would be incorrect.

If f<=zeta at the ambient noise eigenvalue and f>=1-zeta for eigenvalues>=gamma, the accepted signal weight is at least1-eta-d gamma-zeta. Accepted depolarizing noise is at most eta(d/D+zeta). The success probability is independent of logical input in the ideal spectral instrument. Inside-code noise can be treated as an approximately correctable small-output channel by the compressed learned-Petz method; it need not incur a training-count hybrid factor. Outside-code accepted noise and simulation errors do need an appropriate joint-copy budget.

Still unresolved in this draft: fully frozen finite-QPE tail constants and acceptance circuit; normalization and finite-attempt sampling of approximate filtered programs; all source-call budgets for training and payload; the small-D alternative; composition into a flagged or completed physical recovery guarantee. Arbitrary source memory and non-isotropic channel perturbations are not covered. This is a mechanism proposal with derived structural bounds, not a claim that broad noisy recovery has already been proved.

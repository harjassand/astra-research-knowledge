# Optional reference-free whole-block validation
2026-10-29. Additive author theorem, independent receiving required. The received Bell-test selector remains unchanged. This uses the standard Horodecki average-fidelity identity, Eq(3) in Nielsen quant-ph/0205035v2 (https://arxiv.org/pdf/quant-ph/0205035v2), not a new fidelity estimator.

For each fixed candidate M on k=2^ell logical dimensions, choose a uniform logical Clifford C, prepare |psi>=C|0>, run the COMPLETE fresh candidate, apply C†, and measure whether every logical output bit is zero. No retained Bell reference is used. The uniform Clifford orbit is an exact state2-design, so the failure mean is
 q=1-F_avg(M)=k[1-F_e(M)]/(k+1).
A direct check is E(|psi><psi|^tensor2)=(I+SWAP)/(k(k+1)); applying the linear channel functional gives F_avg=(k F_e+1)/(k+1). This holds for any CPTP M, with its entire fresh training/randomness averaged. Each trial's logical test state is independent of that training and the fixed source.

In the parent schedule retain delta_(j,a),b_(j,a),L_j, but set h=k epsilon/(k+1), m=ceil(32b/h), and accept when failure fraction<=3h/4. A candidate with entanglement infidelity>epsilon has q>h, so false acceptance<=delta_(j,a). A good candidate with infidelity<=epsilon/4 has q<=h/4, so ideal-test rejection<=delta_(j,a)^8. This increases the nominal sample count by at most factor(k+1)/k<=3/2, apart from ceiling. Private pre-encoding Pauli padding and key retirement still supply the parent's linear reduced half-diamond conclusion; they are not replaced by a classical state test.

## Finite uniform test seeds, no biased fallback
Use the received uniform-integer Clifford indexing/synthesis algorithm on ell qubits. For each test seed draw at most B bitstrings of length ceil(log2 |Cliff_ell|), rejecting indices outside the group range. Choose B LEAST integer such that 2^(-B)<=1/(256m). If ANY of the m test-seed samplers fails, reject the WHOLE candidate trial; never substitute an identity test state and never treat this event as a pass. It is permissible to prefetch all m seeds before invoking any source block.

An accepted uniform-integer index is independent of its rejection count; the range and B do not depend on the index. Conditional on no sampler abort, the test seeds are independent exact-uniform Clifford elements. The resulting false-accept probability is no larger than the ideal test bound. A union bound gives sampler-abort probability<=1/256. Thus for a good candidate the total rejection probability is <=delta_(j,a)^8+1/256<=1/128. With at least3/4 good candidate codes at adequate rank, each trial still fails with probability at most1/4+(3/4)/128<1/2. All parent stage-tail and polynomial expected-cost results survive.

Finite sampling uses O(m B ell^2) random bits; standard Clifford synthesis uses polynomial(ell) classical work and O(ell^2) known Clifford gates per test. Preparation and return measurement have trusted exact finite-alphabet Clifford/Pauli gates in this mathematical interface. Arbitrary noisy test controls are NOT covered silently: their bias must be measured/bounded and thresholds adjusted, just as for the parent trusted Bell test. This removes a retained external logical test reference, not the quantum output records needed inside the learned decoder. Reference-free training is a separate interface theorem.

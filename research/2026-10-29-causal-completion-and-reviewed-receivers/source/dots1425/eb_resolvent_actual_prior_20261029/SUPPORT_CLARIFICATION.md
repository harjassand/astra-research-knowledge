# Mandatory support clarification
2026-10-29. Additive clarification; original governing file unchanged.

For the generic EB-mixture theorem, if ν=Φσ is rank deficient, let P=suppν. The primary recovery is TP on P. Extend it to the entire output algebra by R_ext(Y)=R(PYP)+Tr[(I−P)Y]σ. This is CPTP, agrees with recovery on all relevant outputs, and fixes the prior through R_extΦσ=σ. Use this extended recovery before calling R_extB and R_extC channels. For faithfulσ, every Φρ is supported in P. In particular every actual ensemble letter is covered. In the unital-qubit case, faithfulσ implies faithfulΦσ directly.

The general governing proof is stated for faithfulσ. To justify the unital-qubit conclusion for EVERY prior: a singular qubit prior is rank one, so every positive-weight ensemble letter equals that pure state. Constant re-preparation has zero error. In the product-reference version with meanσ_A⊗ω_R and rank-oneσ_A, positivity forces every letter to factor as σ_A⊗ρ_R,x; replacement on A again has zero disturbance. No singular Petz inverse is needed for this case.

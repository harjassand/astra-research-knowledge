The separate `episode_protocol` harness actually executes ordinary forward
calls on the existing four-state rational counterexample, with exact rational

38,501 stopping coin draws, 123,398 random-bit requests totaling 613,934 bits,

The algebraic class condition is not inferred as an exact equality from samples.

All 4,096 actually observed microscopic paths/source rows/actions are retained
in `episode_micro_paths.json.gz`, with 42,722 microscopic labels. The array's
canonical JSON digest is bound by the saved result. These are real tagged data,
not reconstructed missing historical tags. Retaining learners get the same
paths and can extract stronger statistics. They pay the same simulation and
metadata storage. Source probabilities are private to this test's sampler;
`acquire` and the count receiver use only forward outcomes.

Author protocol execution before this note: one first run plus one same-seed
replay to preserve the path archive, 77,252 total source calls. This is a
reproduction cost, not new independent evidence. Future author/reviewer replays
add their actual 38,626 calls per run and must not be confused with the single
batch's prospective acquisition bill. The theorem assumes ideal iid random
choices; the executable uses a reproducible Python PRNG, not authenticated
physical randomness. The counts cannot certify that premise.

`control.py` deliberately separates a received SMALL certificate from its full
n-state map/count evidence. The core holds hashes of the source design/map,
not the n-entry map itself, so per-goal hash checks do not quietly scan n labels.
The full receiver costs O(nmr) counter reading and exact arithmetic and must run
at acquisition/independent re-audit. The n-label map is separately retained for
actual sensor-to-policy execution. No cheap full provenance re-verification is
claimed per goal.

`max_lp_entry_numerator_or_denominator_bits` measures LP inputs, primal and dual
outputs, not every internal simplex pivot. Actual internal bit operations and
peak memory have not been instrumented. Exact primal/dual inequalities are
independently checked by the author backend. SymPy rational simplex is ordinary
and not claimed polynomial worst case; the theorem's polynomial consumer uses
standard rational LP theory. Numerical backend failure returns UNKNOWN.

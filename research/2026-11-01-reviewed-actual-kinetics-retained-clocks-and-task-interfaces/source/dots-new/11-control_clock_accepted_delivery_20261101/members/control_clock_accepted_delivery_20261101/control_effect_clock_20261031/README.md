From the workspace root:

```bash
python control_effect_clock_20261031/replay.py --saved-only
python control_effect_clock_20261031/replay.py
```

The first verifies hashes, replays saved path receiving, the accepted canonical witness, and the matched ordinary baseline with **zero new source calls**. ## Honest boundaries

The interface needs microscopic labels and named-state preparation. Its cost is reported, not assumed free or physically available. Source independence, source identity, correct execution and nonanticipating validation/coin designs are external provenance premises, not authenticated by JSON hashes. Changed partitions require fresh prefix validation or a separately paid uniform event.

Pair meeting can be much slower than useful observable cancellation: identical uniform kernels mix in one step but independent pairs take expected n-1 steps to meet. A good global or task-specific coupling is not assumed. The current partition is native task semantics; the refinement implementation does not claim an executed successful multiround discovery. Future goals, source discount, action alphabet, sensor/map and confidence remain explicitly bound.

All common denominators, rounding, call counts, labels, preparation requests, failed attempts, finite-bit arithmetic and small LP work are charged in the proof/ledger. Ordinary correct polynomial-time LP is a paper consumer; installed simplex is a checked proposal backend, not a guaranteed polynomial runtime. The finite executable search has a grid budget, not a hard per-LP wall-clock timeout.

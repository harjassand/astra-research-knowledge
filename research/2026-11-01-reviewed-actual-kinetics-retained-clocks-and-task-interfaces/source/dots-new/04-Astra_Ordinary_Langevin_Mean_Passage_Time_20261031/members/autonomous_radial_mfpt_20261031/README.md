# Autonomous radial-gain MFPT: author construction boundary

The new observable is the actual autonomous mean B-hitting time from exact
Gibbs|A initialization for the declared homogeneous radial-gain/tangent diffusion.
It is NOT the earlier clamped CDF and is NOT a capacity certificate relabeled
as latency. No physical realization or empirical model membership is established.

- `POISSON_CURRENT_MFPT_CANDIDATE.md`: full zero-resolvent/current/source/tail proof.
- `receive_mfpt.py`: acquired raw model, two scalar interval integrals, finite
  Poisson correction formula, strict external-task receiving.
- `check.py`: symbolic identities, exact source-to-mean finite-chain analogues,
  independently integrated polynomial resistances, interval/resource attacks,
  five actual saved replays. Floating mass checks are diagnostics only.
- `ARITHMETIC_COSTS_AND_SCOPE.md`: all numerical/model costs, prior comparisons,
  real refusals and exact-initial-law qualification for unbounded means.
- `small_raw_fixture.json`, `small_certificate.json`: standalone original-task case.
- `DEPENDENCIES.json`: exact accepted inherited kinetic parser/lift bindings.

Run `python -B check.py` here. Production is standard-library Python; tests use
SymPy and mpmath. The imported kinetic source is checked by SHA before use, but
its accepted clamped-CDF receipt does not automatically accept this new MFPT join.

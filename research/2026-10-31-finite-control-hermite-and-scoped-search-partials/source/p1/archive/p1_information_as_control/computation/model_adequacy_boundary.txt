MODEL-ADEQUACY BOUNDARY: L2 STABILITY AND A PAID HOLDOUT CERTIFICATE
P1 frontier companion, 2026-10-30. Ordinary robustness machinery, not a new
headline result. No additional experiment or large certification run executed.

1. WHAT IS ROBUST

Let F0 be the constructed reference target on the specified Gaussian inputs,
and let the actual target be F=F0+e on the SAME input law and sensing interface.
Suppose ||e||_L2<=delta. Measurement noise, legal actions, information available
to each party, and budgets are unchanged; the perturbation changes the target,
not the observation law.

If the constructed strategy and its implemented reference predictor Fhat0
have reference MSE at most R0, the SAME strategy and predictor satisfy

  E[(F-Fhat0)^2] <= (sqrt(R0)+delta)^2.                       (1)

Proof: apply the L2 triangle inequality to
F-Fhat0=(F0-Fhat0)+e. This is an achievable bound using the reference predictor;
it does not require computing the unknown actual-target conditional mean.

For a legal fixed experiment E, let G_E be its complete observable sigma-field,
including declared independent design randomness and noisy readouts. Its
optimal MSE is the squared L2 distance from F to the closed subspace
L2(G_E). Distance to any set is 1-Lipschitz. Equivalently, conditional
expectation is an orthogonal projection, so

  sqrt(risk_E(F))
    = ||F-E[F|G_E]||_2
    >= ||F0-E[F0|G_E]||_2-||e-E[e|G_E]||_2
    >= sqrt(risk_E(F0))-delta.

Thus, if EVERY legal fixed experiment has reference risk at least L0, then
every such experiment, even with its best predictor for the actual F, obeys

  risk_E(F) >= (sqrt(L0)-delta)_+^2.                        (2)

The reference separation remains strict whenever

  R0<L0 and delta < (sqrt(L0)-sqrt(R0))/2.                   (3)

These statements concern an L2 neighborhood under the declared input law.
They provide neither uniform pointwise approximation nor protection against
a changed input/measurement distribution. They do not acquire delta or prove
that the actual target belongs to the reference model class.

2. A FULLY COUNTED HOLDOUT ROUTE, GIVEN A MOMENT PROMISE

Freeze F0 and the proposed strategy before validation. Fresh iid full-input
samples X_i are available under the declared law, with target evaluations
F(X_i) and computable reference evaluations F0(X_i). This is an additional
access resource beyond a few restricted deployment measurements. Training
and model selection costs are separate and retained.

Assume an independently justified constant K>=1 satisfying, for this frozen
residual and fresh input law,

  E[e(X)^4] <= K (E[e(X)^2])^2.                             (4)

If F0 was produced randomly, the promise must hold conditional on that frozen
candidate; an unconditional average over training runs is not the same
guarantee. The moment bound is supplied, not estimated for free by validation.

For failure probability beta in (0,1), set

  b=ceil(16K),
  t=the smallest positive odd integer >=8 log(1/beta),
  N=b t.

Acquire exactly N independent full-input samples and form Y_i=e(X_i)^2. Split
them into t disjoint blocks of b samples. Let A_j be each block mean and let
M be the median of these t means. Write mu=E[e^2]. If mu>0, Chebyshev gives

  Pr{|A_j-mu|>mu/2}
    <=4 Var(e^2)/(b mu^2)<=4K/b<=1/4.

Independent blocks imply a median failure probability at most exp(-t/8).
For completeness, the Chernoff bound with exponential parameter log 3 gives
(sqrt(3)/2)^t<=exp(-t/8) for at least half the blocks being bad. Therefore,
with probability at least 1-beta,

  mu/2 <= M <= 3mu/2,
  (2/3)M <= mu <=2M.                                      (5)

If mu=0, e=0 almost surely and all exact residual values vanish, so the same
claim holds directly. The reported upper certificate is

  delta_cert=sqrt(2M).                                    (6)

It can be inserted into (1)--(3). To certify a predeclared tolerance delta0,
accept only if M<=delta0^2/2. On the good event this certifies ||e||_2<=delta0;
it is guaranteed to pass on that event if mu<=delta0^2/3. Failure to pass does
not itself show that the model is inadequate.

Paid resources: N target evaluations, N reference evaluations, N complete
input draws, and their full input traffic. For a d-dimensional dense input,
that is dN sampled/transmitted coordinates. Evaluation work is the actual
sum of the N target and N reference evaluation costs, not N unit-time calls.
Computing block sums costs O(N); a deterministic median selection costs O(t)
operations. Streaming needs one input and t block means, in addition to the
stored model. Exactly N samples suffice for the displayed confidence level;
no asymptotic or unspecified successful-learning oracle is invoked.

The validation data must remain independent of model fitting/selection. If a
model is revised after inspecting this holdout, use fresh validation, a valid
predeclared simultaneous confidence allocation, or another explicitly proved
adaptive-validation procedure. Reusing the same certificate after arbitrary
model selection is not covered.

3. FINITE EVALUATION PRECISION AND THE LIMIT OF THE CERTIFICATE

Suppose numerical target/reference evaluations instead provide residuals
etilde_i with |etilde_i-e(X_i)|<=tau deterministically. Evaluating each target
and reference to absolute error tau/2 is a sufficient way to obtain this;
their required precision and cancellation cost are charged. Let Mtilde be
the median of the block means of etilde_i^2.

Within each block, the finite-dimensional L2 triangle inequality gives

  |sqrt(mean etilde_i^2)-sqrt(mean e_i^2)|<=tau.

Taking medians preserves this bound, because square root is monotone. On the
SAME probability-1-beta event as (5), the honest widened certificate is

  (2/3)(sqrt(Mtilde)-tau)_+^2
    <=mu<=2(sqrt(Mtilde)+tau)^2,
  delta_cert=sqrt(2)(sqrt(Mtilde)+tau).                     (7)

No moment bound for the rounded residual is needed: (4) remains a promise
about the true residual. A fixed evaluation floor prevents arbitrarily fine
relative certification near mu=0. Likewise, digitally approximated Gaussian
inputs require their distribution error to be separately bounded using an
appropriate regularity argument; the iid full-input access assumption is not
automatically established by drawing rounded numbers.

Finally, K is substantive. For a residual with e^2=A on an event of probability
p and zero elsewhere, E[e^4]/(E[e^2])^2=1/p. An unseen rare residual can carry
substantial mean-square error. A finite holdout by itself does not certify a
uniform K, an unknown polynomial degree, or exact model-class membership.
No Gaussian-polynomial hypercontractive example is needed for the bounds
above, and none is assumed here.

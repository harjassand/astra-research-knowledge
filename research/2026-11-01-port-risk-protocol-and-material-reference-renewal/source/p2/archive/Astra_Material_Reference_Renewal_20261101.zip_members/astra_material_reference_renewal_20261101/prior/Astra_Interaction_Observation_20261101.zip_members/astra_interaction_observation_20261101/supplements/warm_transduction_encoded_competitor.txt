# A different mechanism: finite-angle encoded gates evade the continuous-projection obstruction

Date: 1 November 2026 (Australia/Brisbane).

## Why this matters

The KL/HNLS argument P S^2 P=cP forbids a nontrivial *projected continuous S^2 Hamiltonian* inside a code correcting {I,S}. It does not forbid an isolated finite-angle gate exp(i Phi S^2). At special phases, different charge supports can acquire uniform but distinct logical phases despite having identical low-order charge moments.

This provides a strong conventional competitor to monitored-bath erasure. It changes the encoding and allows recovery after the complete gate. It must not be dismissed by importing a metrological continuous-parameter no-go theorem beyond its scope.

## Minimal explicit code

Take four charge levels n=0,1,2,3 and define

    |0_L> = (|0>+sqrt(3)|2>)/2,
    |1_L> = (sqrt(3)|1>+|3>)/2.

With encoding isometry V,

    V^dagger n V = (3/2) I,
    V^dagger n^2 V = 3 I.

Thus the error set {I,n} is exactly correctable. Let E=(2/sqrt(3))(n-3I/2). The four columns of [V,EV] form an orthonormal basis. A complete recovery to the logical qubit has Kraus operators

    R_0=V^dagger,    R_1=V^dagger E.

This construction is the finite-charge form of a dephasing binomial code. It can also be represented in the symmetric spin-3/2 subspace of three physical spins.

## Exact entangling force-loop gate

For all even integers n, exp(i pi n^2/2)=1; for all odd integers it equals i. Therefore

    exp(i pi n^2/2) V = V diag(1,i).

For two independent code blocks A,B, couple the common bus to n_A+n_B and execute a physically closed force loop with Phi=pi/2. Its target operation is

    U=exp[i pi(n_A+n_B)^2/2].

On the product code,

    U_L=(S_L tensor S_L) CZ_L=diag(1,i,i,1),

because exp(i pi n_A n_B)=(-1)^(logical_A logical_B). This is an exact entangling logical operation on arbitrary encoded states and their references.

The bus-induced collective phase exp[-i phi(n_A+n_B)] commutes with the complete gate. Recovery can therefore be applied after the force loop. There is no requirement to continuously project the Hamiltonian onto the code.

## Exact one-block Gaussian dephasing performance

For a common phase kick exp(-i phi n), the decoded one-block coherence factor is

    c(phi)=(9 cos(phi)-cos(3phi))/8
             + i(3 sin(phi)-sin(3phi))/8.

If phi is mean-zero Gaussian with variance v, its average is real and the decoded channel is a logical Pauli-Z channel with probability

    p_L(v)=1/2-(9/16)exp(-v/2)+(1/16)exp(-9v/2)
          =(9/16)v^2+O(v^3).

Thus ordinary encoded recovery removes the first-order Gaussian dephasing term while the finite-angle entangling gate remains exact.

For two blocks experiencing the same phi, recovered logical errors are correlated. One must use the joint recovered channel; treating it as the tensor product of its one-block averages would discard a real correlation. The executable check constructs this joint Schur channel directly.

## What is and is not earned

* The encoding, exact finite-angle gate, and ideal recovery are explicit.
* A physical realization needs four charge levels or a three-spin collective encoding per logical qubit, plus syndrome extraction and recovery operations.
* Imperfect recovery is a separately paid channel. An ideal recovery expression is not a noiseless-helper hardware construction.
* Charge-dephasing faults commute with the gate and are covered by the model. General charge-changing/bit-flip faults during the gate can propagate differently and require a fault-tolerant analysis.
* Equal charge coupling, force-loop closure, and the special gate phase are calibration requirements.
* Increasing code size cannot automatically remove arbitrary large shared phase uncertainty: a physical phase rotation of pi is already a nontrivial logical operation, creating aliasing limits.

## Primary predecessors

This is not a novelty claim for Kerr-encoded gates. It is a concrete instantiation of established machinery needed for a fair comparator.

Any claimed advantage of a monitored warm-bus gate should compare against this encoded finite-angle route at the same available charge coupling, target noise, recovery fidelity, and physical resource budget.

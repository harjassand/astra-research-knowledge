PREFIX BALANCE, CONTAINED LEAKAGE, AND THE COST OF STRONGER NOISE PROTECTION
Ordinary derivations, 31 October 2026. Units hbar=1.

1. A criterion that follows the actual operation
------------------------------------------------
Let U(t) be the ideal physical unitary, V an initial code isometry and P=VV*.
For a no-jump contraction K generated by -iH(t)-Gamma(t)/2, move to the ideal
interaction frame. Suppose

 V* U(t)* Gamma(t) U(t) V = gamma(t) I                    (1)

for almost every t. Set D(t)=U*Gamma U-gamma(t)I on the admitted finite
physical space and eta=(1/2) integral ||D(t)|| dt. Then

 V* U(T)* K(T) V = exp[-integral gamma/2] (I+E),
 ||E|| <= exp(eta)-1-eta.                               (2)

The escaped amplitude satisfies

 ||(I-P) U(T)*K(T)V|| <= exp[-integral gamma/2](exp(eta)-1).

Proof: factor the scalar exponential, expand the time-ordered Dyson series,
and observe that its first compressed term is zero by (1). Bound each
higher ordered integral by eta^k/k!. Time dependence and noncommutativity
of the D(t)'s are allowed. Equation(2) is a compression statement, NOT a
full accepted-output guarantee when an actual last check leaves leakage.

The same proof applies to coherent control defects: if each interaction-frame
error E_a(t) satisfies V*E_a(t)V=c_a(t)I, the first-order in-code effect is
scalar. Subtract that scalar before defining eta. Bounded quantum bath
coefficients can be retained in this argument; the scalar part then acts on
the bath, and interaction-frame norm bounds must include that evolution.
No arbitrary unbounded bath or initially unadmitted charge state is acquired
by invoking this observation.

For independent unknown nonnegative modal loss rates, Gamma=sum kappa_j n_j.
Uniform validity of (1) for all such rates is equivalent to scalar
compression of EACH n_j at EACH time. Equality only after an unweighted
time integral is insufficient for arbitrary changing rates.

2. A minimal balanced excitation construction
--------------------------------------------
In the N=2 two-mode space ordered (20,11,02), use

 |0>=|11>, |1>=(|20>+|02>)/sqrt2, |q>=(|20>-|02>)/sqrt2.

Then P n_a P=P n_b P=P. With Jx=(a*b+b*a)/2,

 P Jx P=X,  Jx|q>=0,
 n_a n_b=|0><0|,
 exp(-i pi n_a n_c)|P tensor P = diag(-1,1,1,1).        (3)

Thus ordinary beam splitting supplies continuous X control, intra-block
Kerr supplies Z control, and an interblock pi Kerr contact supplies an
entangler. These ideal gate endpoints preserve both P and q. If either
N=2 block is q, the interblock pi Kerr contact is identity on the partner.
That last identity is a useful containment property, not a statement about
photon-number-loss sectors.

Beam splitting preserves P throughout. Any number-diagonal contact preserves
the moment equalities (1) in its moving code because it commutes with n_j.
This includes the intermediate excursion of the pi Kerr entangler. At every
instant P_initial U* n_j U P_initial is scalar, even when the code has not
returned to its endpoint subspace.

For a Kerr strength defect delta_chi(t)n_a n_c, the first-order compression
also equals a scalar: P_joint n_a n_c P_joint=I. It remains so at every time
of that diagonal gate. A general local X or Z angle error does NOT have this
property; those controls still need ordinary calibration, or noisy resource
preparation/teleportation. The completed construction is not universal
fault transparency.

3. Exact idle and entangler error channels with a declared code projection
-------------------------------------------------------------------------
Let A=int kappa_a, B=int kappa_b, S=A+B, d=(A-B)/2. The no-loss operator,
compressed onto P, is

 K_P=exp(-S/2) diag(1,cosh d),
 Q K P= -exp(-S/2) sinh(d) |q><1|.                    (4)

The second term is first-order leakage amplitude. Claiming that the WHOLE
state has only a second-order error would be false.

If a code projection is actually completed and rejected states are erased,
physical logical-X randomization turns the accepted channel into I/Z noise.
Its unnormalized nonidentity probability is

 q_Z=exp(-S)(cosh d-1)^2/4
     =exp(-S)(A-B)^4/256+O((A-B)^6).                   (5)

For ordinary one-photon dual rail the corresponding probability is
exp(-S/2)sinh((A-B)/4)^2, of second rather than fourth order.
These are benchmark channel identities. They do not supply a free projector,
free physical randomization, or a new randomized-compiling theorem.

For an overrotated pi Kerr gate, remove its ideal unitary and a common phase.
The compressed relative diagonal is exactly

 (1,cos delta,cos delta,exp(i delta)(3+exp(-4i delta))/4).

Pauli-twirl this complete accepted channel and erase the actual rejected
space. Its nonidentity accepted Pauli probability is

 q_P=19 delta^4/64+O(delta^6),
 e=5 delta^2/4+O(delta^4).                              (6)

An ordinary dual-rail pi Kerr overrotation instead gives
q_P=3 sin(delta/2)^2/4=3 delta^2/16+O(delta^4).

Known Pauli randomization is doing real work in (5)-(6). Keeping each random
key as a coherent output, or conditioning an adversarial noise source on that
key, does not give the averaged Pauli channel. Physical frame operations and
their noise must be charged; changing a software label alone does not twirl
the physical bath. Detector misses and other unheralded noise add to these
rates. The code also doubles stored excitation and therefore roughly doubles
the photon-loss exposure at equal mode lifetime and elapsed time.

4. An imperfect check can contain leakage over a long computation
----------------------------------------------------------------
This elementary block-matrix lemma explains what a final-time leakage
amplitude does and does not imply. It is not a replacement for a noisy
fault-tolerance architecture.

In code/leakage coordinates, remove a known scalar attenuation alpha_j from
an accepted operator and write M_j=[[A_j,B_j],[C_j,D_j]]. Assume uniformly

 ||A_j-U_j||<=a, ||B_j||<=b, ||C_j||<=c, ||D_j||<=r<1,

where U_j is the desired code unitary. Scalars and actual acceptance
probabilities must be restored when constructing the full instrument.
Let d=a+bc/(1-r). Starting in the code, after L accepted operations,

 ||X_L-U_L...U_1|| <= (1+d)^L-1,
 ||Y_L|| <= c(1+d)^(L-1)/(1-r).                         (7)

Proof: X_j=A_j X_(j-1)+B_jY_(j-1),
Y_j=C_jX_(j-1)+D_jY_(j-1). The second recurrence gives
||Y_j||<=c max_(k<j)||X_k||/(1-r). Substitute in the first and induct on
the running maximum of ||X_j||. Subtract the ideal product and telescope.

If a=O(eta^2) and b,c=O(eta), the in-code error accumulates as
O(L eta^2/(1-r)) in its useful perturbative regime, although surviving
leakage remains O(eta/(1-r)). A last-instant fault is therefore compatible
with contained computation. It is NOT compatible with advertising a
second-order standalone quantum-output diamond error.

If the final, actually implemented consumed-output measurement is block
diagonal in P/Q, cross-sector coherence cannot enter its output. Leakage
then contributes by its population. Imperfect terminal measurement is a
separate operation. Retaining a fine record that is not block diagonal may
restore amplitude-order sensitivity, so the output interface must be stated.

General multi-Kraus apparatus memory, stochastic bad-check events, losses
that spread to later partners, and outer recovery require their own full
instrument/circuit accounting. The physical C-X-C checker is being examined
for these conditions; equation(7) must not be applied merely because its
ideal limit is a projector.

5. Correlated outlets change the allowed control algebra
--------------------------------------------------------
The N=2 code obeys P a*b P=X. Consequently the positive correlated hazard

 Gamma=kappa(n_a+n_b)+xi(a*b+b*a), |xi|<=kappa,

acts IN the code as 2kappa I+2xi X. Its no-jump filter exp(-xi T X) is
first order and cannot be found by the symmetry test. Independent modal
outlets are a physical admission requirement, not a cosmetic assumption.

The familiar N=4 code {(40+04)/sqrt2,22} instead satisfies
P a_i*a_j P=2 delta_ij P and corrects a single unknown-mode loss. It pays
four stored photons but has its own efficient nonlinear gates: pair hopping
provides logical X and a pi/4 cross-Kerr supplies an entangler. It must not
be dismissed as automatically slower.

More generally, for ANY code satisfying P a_i*a_j P=c_ijP, every passive
bilinear Hamiltonian has scalar compression. A continuous passive gate that
keeps a fixed such code invariant is logically trivial. Nonlinear control,
code excursions, measured operations or teleportation are required to escape.
This is the familiar control/noise-span obstruction in this concrete setting,
not a claim that passive transformations can never implement discrete gates
or that loss-correcting bosonic computation is impossible.

6. Scope of the advance
----------------------
The construction can change the TYPE of a dominant entangling calibration
error: most leading distortion becomes detected leakage, while an accepted
randomized residual is fourth order in angle. The stream bound makes clear
why checks need not magically remove the last fault. Whether that gain beats
twice the loss exposure and extra measurements depends on the actual native
control and readout cycle. No complete cheaper universal architecture is
claimed from the compressed formulas.

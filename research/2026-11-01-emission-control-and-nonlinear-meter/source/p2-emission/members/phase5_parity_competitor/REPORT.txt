# Independent constructive competitor: a matched qutrit parity meter

## Result and claim boundary

The strongest practical competitor I found is the established **error-transparent, dispersively coupled qutrit ancilla**, used with dissipative cat data qubits. It has a precise whole-instrument protection property against a specified, physically important class of meter imperfections. It also has an experimental foothold in repeated correction. A simultaneous mapping window is a useful hardware-dependent optimization, not a new architecture or an experimentally established advantage of this report.

The elementary construction measures products of **photon parity**, which are products of **cat X operators** in the coherent-sign computational basis. It therefore directly supplies the XX checks needed by a repetition code correcting the dominant cat Z errors. It does not directly supply coherent-sign ZZ measurements. With an additionally provisioned weight-three interaction, the same multi-X primitive can perform a teleported, bias-preserving CNOT, with an explicit four-cat resource and explicit readout costs. That prevents the comparison from stopping at a memory-only capability without silently promoting a demonstrated nearest-neighbor device into a three-mode factory.

The exact result is conditional on a physical noise model: meter jumps must preserve a matched dispersive block and have data-independent amplitudes. Actual device imperfections outside that class give an error floor, not an exactly harmless measurement. No finite noisy apparatus preserves every coherence under arbitrary faults. The useful contract is an exact protected leading mechanism, an explicit budget for mechanisms that violate it, and a full elapsed-time comparison.

### Primary experimental and theoretical anchors

The following factual summaries are deliberately compact. The subsequent algebra, instrument checks, resource construction, and arithmetic are worked out here.

* **Rosenblum et al., Science 361, 266–270 (2018)** demonstrated error-transparent parity detection by matching the dispersive shifts of the ancilla e and f levels. The experiment reported a fivefold suppression of ancilla-error propagation. [DOI](https://doi.org/10.1126/science.aat3996); [author-hosted manuscript](https://jianggroup.yale.edu/sites/default/files/2018_yale_univ_srosenblum_fault-tolerant_266.full_.pdf).
* **Putterman et al., Nature 638, 927–934 (2025)** implemented a distance-five dissipative-cat repetition memory using tunable cat–transmon interactions, native approximate matching, three-state readout, and erasure-aware decoding. The reported cycle was 2.8 microseconds; effective storage lifetimes were 57–68 microseconds. Its checks used two CX gates per ancilla, not the simultaneous pulse suggested below. The reported average minimum logical error per cycle was 1.65(3)% for distance five. This establishes useful repeated operation, not universal computation or an arbitrarily low logical error. [DOI](https://doi.org/10.1038/s41586-025-08642-7); [full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC11864976/).
* **Hann et al., PRX Quantum 6, 030305 (2025)** studied an extension correcting residual cat X errors using an additional cat-controlled transmon gate and a rectangular surface code. Their performance and overhead figures are projections. They explicitly identify transmon faults as limiting the achievable bias. [DOI](https://doi.org/10.1103/75x7-5ysv); [paper](https://journals.aps.org/prxquantum/pdf/10.1103/75x7-5ysv).
* **Cohen et al., PRL 119, 060503 (2017)** proposed a nonlinear Josephson interaction projected by cat stabilization into a direct parity coupling. It is an attractive alternative in principle; its controlled-regime sensing-rate frontier is evaluated in Section 7. [DOI](https://doi.org/10.1103/PhysRevLett.119.060503); [manuscript and supplement](https://arxiv.org/pdf/1611.01219).
* Gate teleportation is established, not a new computational architecture here: **Gottesman and Chuang, Nature 402, 390–393 (1999)**. The particular multi-X-only resource preparation and all measurement branches used below are derived and checked explicitly. [DOI](https://doi.org/10.1038/46503); [preprint](https://arxiv.org/abs/quant-ph/9908010).

## 1. Encoding, axes, and the useful measurement

For oscillator j, let the stabilized code be spanned by the normalized even and odd cats

    |C+> ∝ |α> + |-α>,       |C-> ∝ |α> - |-α>.

An exactly orthonormal computational basis is

    |0_Z> = (|C+> + |C->)/sqrt(2),
    |1_Z> = (|C+> - |C->)/sqrt(2).

These approach |α> and |-α> at increasing n = |α|². On this code,

    X_cat = (-1)^(a†a),      a ≈ α Z_cat.

The finite-cat correction to the second relation must be retained in a device error model. The first relation is exact. Two-photon stabilization has dark-space jump operator a² - α². Single-photon loss is predominantly a Z error in this convention.

For a set S of w cats, the proposed measurement is

    P_S = product_j∈S X_j = exp(iπ sum_j∈S n_j).

It preserves all coherences inside either eigenspace of this operator in the protected meter model. In particular, a two-cat measurement is a useful phase-repetition syndrome; it is not a measurement of the two coherent-state signs.

## 2. Concrete hardware and full cycle

Use one transmon ancilla with levels g, e, f, a readout resonator capable of resolving all three levels, and independently tunable dispersive couplings to the selected cat modes. During the sensing window, turn off their two-photon pumps and turn off the ancilla readout drive. Set

    Q_A = |e><e| + |f><f|,
    H_int(t)/ℏ = Q_A ⊗ sum_j χ_j(t) n_j,
    integral_0^T χ_j(t) dt = π mod 2π for each selected j.

The matching is pointwise: the e and f dispersive shifts must agree over each pulse. Merely matching their final integrated phases does not make arbitrary intermediate decay times harmless. The χ_j need not be identical functions, provided every area is π and the same function applies to e and f on each link.

The sequence is:

1. Initialize the ancilla to g with the data decoupled. Prepare (g + f)/sqrt(2), keeping control drives that mix g with the excited block outside the sensing window.
2. Disable stabilization, apply the calibrated dispersive mapping, then decouple the data. Simultaneous coupling gives one window if the device supports it; sequential coupling also satisfies the algebra but takes longer.
3. Apply a g–f Ramsey analysis pulse. Resolve g, e, f in the readout. Treat e as an erasure of the parity result, not as either parity.
4. Reset the ancilla with the data decoupled. Restore two-photon stabilization and allow it to finish. Stabilization can overlap ancilla readout and reset.
5. Continue with the updated syndrome and Pauli frame. If a useful parity result was erased, the decoder can use neighboring rounds; an offline resource can be remeasured.

A full-cycle clock is

    T_cycle = T_prepare + T_switch + T_map
              + max(T_readout + T_reset, T_restabilize) + T_control.

This formula assumes the indicated overlap is physically available and that no extra cooling or guard window is needed. Otherwise those intervals must be added. Data photon loss is accumulated over T_cycle, not only T_map. Meter faults occurring during reset are harmless only insofar as residual data coupling and direct measurement crosstalk are negligible.

There are w dispersive links. Parallel operation changes depth, not the number of links. Matching and characterizing their joint operation is a resource. A three-level readout and cat stabilization hardware are also resources. This should not be compared with an abstract CNOT circuit while omitting those costs.

The experimentally demonstrated chain supplies an ancilla adjacent to two data modes and sequential interactions. A weight-three check requires an ancilla coupled to three selected modes, with the matched-block conditions verified across those links; it is not earned by citing that chain. Sequential access to three modes would suffice for the protection theorem, but loses the one-window speedup. Simultaneous access further requires characterization of the joint activated circuit, including coupler–coupler and spectator effects. This report does not present an extra-helper compilation of the weight-three check into only the demonstrated adjacent XX operations.

## 3. Exact whole-instrument theorem, including no-click evolution

Assume during the mapping interval that:

* all data number operators commute with one another;
* every meter Hamiltonian and every meter–environment coupling preserves Q_A;
* those couplings are independent of the data number configuration;
* each integrated χ_j is π modulo 2π.

The last two assumptions concern the microscopic jump operators, not just a fitted readout histogram.

Let V_AE denote the complete meter-plus-environment evolution, including arbitrarily many unresolved emissions, meter dephasing events, and their no-jump evolution. Because it preserves Q_A, it commutes with the conditional phase accumulation. At the end of the map, the joint unitary/dilation factors as

    U_total(T) = [ (I_A - Q_A) ⊗ I_D + Q_A ⊗ P_S ] V_AE(T).

Any subsequent meter readout, reset, inefficiency, classical coarse-graining, or ignored output therefore gives data Kraus operators of the form

    K_(r,λ) = a_(r,λ) Π_+ + b_(r,λ) Π_-,
    Π_± = (I ± P_S)/2.

Here λ includes every unobserved environmental record. For any input supported in one sector, every fine-grained branch acts as a scalar. No bath learns which vector inside that sector was present. This proves coherence preservation even when the bath is uncollected. It does not infer preservation from two-valued final outcomes.

The relevant physical jump is J_fe = sqrt(γ_f)|e><f|. Both this jump and J_fe†J_fe preserve Q_A, and [H_int, J_fe] = 0 when matched. Ancilla dephasing also preserves the block. The emitted f→e photon has no data-dependent transition frequency in this ideal model. A photon counter with unit efficiency is not required.

### Explicit no-jump and erasure instrument

Take only f→e decay, with rate γ_f, and let r = exp(-γ_f T/2). After the final Ramsey pulse, the two non-erasure branches are

    K_g = (I + r P_S)/2,
    K_f = (I - r P_S)/2.

An f→e jump at any time t produces the Kraus density

    K_e(t) = sqrt(γ_f/2) exp(-γ_f t/2) P_S.

These satisfy completeness after integrating t. They are all sector-scalar. The no-click branch is not assumed unitary: its unequal g/f amplitudes are explicitly retained, but they depend only on P_S. The erasure probability is (1 - r²)/2, independent of the data. The conditional non-erasure error attributable just to amplitude damping is

    q_ad = (1-r)² / [2(1+r²)] = (γ_f T)²/16 + higher orders.

An erasure branch applies P_S to a state spanning both sectors. That byproduct can be tracked; within either sector it is just a sign. Pure meter dephasing makes the parity result noisier while preserving this same intra-sector property.

The theorem tolerates intermediate data–meter entanglement. What matters is that the accessible and inaccessible meter faults commute through that entanglement to an endpoint interaction depending only on parity.

## 4. Real faults and a quantitative frontier

### 4.1 Double decay and heating

The jump e→g changes Q_A and violates the theorem. After f→e at t₁ and e→g at t₂, the data have accumulated only the phase up to t₂. For constant equal χ this is exp(-iχ t₂ sum n_j), rather than total parity. Tracing over t₂ gives within-sector decoherence.

Starting in (g+f)/sqrt(2), the probability of two decays during T is

    p_double = 1/2 { 1 - [γ_f exp(-γ_e T) - γ_e exp(-γ_f T)]/(γ_f-γ_e) }
             = γ_f γ_e T²/4 + O(T³).

The equal-rate limit is obtained continuously. A g→e heating event changes the block at first order. Preparation residue in e followed by e→g is another first-order contribution in that residue. Leakage to higher levels, drive leakage, and coupler excitations need their own rates.

These probabilities are fault-exposure terms, not automatically the logical failure probability. A fault can create correlated rotations across the w coupled cats; a code-level analysis must retain that correlation and the stabilizer geometry.

### 4.2 Imperfect χ matching

If χ_e,j = χ_f,j + Δχ_j, a single f→e jump at t produces, after a correctly calibrated f mapping,

    P_S exp[-i sum_j Δχ_j (T-t) n_j].

For two number configurations s,s′ with the same parity, put Δ = sum_j Δχ_j (n_j,s - n_j,s′). Conditioned on one jump and neglecting second decay, the coherence factor is

    C(Δ) = [γ_f exp(-iΔT)/(1-exp(-γ_f T))]
           × [1-exp(-(γ_f-iΔ)T)]/(γ_f-iΔ).

For γ_f T much smaller than one, this approaches exp(-iΔT/2) sinc(ΔT/2). Correcting the known mean phase does not remove its magnitude loss, approximately (ΔT)²/24. Collecting and time-resolving every emitted photon could remove this specific uncertainty, but the chosen construction does not assume that resource. Hardware matching is the primary protection.

Errors in the f pulse areas are different: they corrupt the no-click map itself. If the area is π+δ_j, K_g and K_f contain P_S exp(-i sum δ_j n_j). A final parity histogram alone cannot establish that this error is small.

### 4.3 Data-dependent jump amplitudes

Equal dispersive energies do not by themselves imply data-independent dressed decay matrix elements. For example, replace γ_f by γ_s. Even when the frequencies match, the no-click amplitude exp(-γ_s T/2) reveals s. Tracing the complete one-emission output gives, for a same-parity pair,

    C_ss′ = 1/2 {1 + exp[-(γ_s+γ_s′)T/2]
             + [2 sqrt(γ_s γ_s′)/(γ_s+γ_s′)]
               × (1-exp[-(γ_s+γ_s′)T/2]) }.

This is below one unless the two rates agree. Rate spectroscopy and a process test of the complete cycle are necessary; a single fitted χ is insufficient.

### 4.4 Remaining channels and useful budget

Count intrinsic data photon loss during preparation, readout, reset, controller latency, and reconfinement. For approximately constant n and a Poisson loss rate λ = κ₁ n, the odd-loss probability of one cat is

    p_Z,loss(T_cycle) = [1 - exp(-2 κ₁ n T_cycle)]/2.

At small n, the exact mean photon numbers of even and odd cats differ; heating and other channels also modify this simplified rate model. The formula is used below only for transparent arithmetic.

Separately bound measurement-induced bias-breaking probability by terms such as

    p_X,meter ≲ p_double + p_heat + p_prep,e γ_e T_map
                 + p_leak + p_residual-coupling + p_bad-reconfinement,

and bound intra-sector instrument error from mismatch, area error, and data-dependent rates. Reconfinement can protect the bias without restoring an exactly coherent sector. Its bath must be included in the final process characterization.

For a phase-repetition code, increasing distance does not eliminate the residual X floor. Reliable unbounded computation requires correcting that floor or using a larger code; the extra gate and code resources in the hybrid surface-code work are material.

## 5. Continuing entangling computation under the same axes

The multi-X meter can implement a CNOT without physically rotating the coherent-sign axes through Hadamards. This is ordinary gate teleportation specialized to the available measurements.

### 5.1 Resource preparation

Prepare four cats a,b,c,d in |0_Z> and measure

    S₁ = X_a X_c X_d,       S₂ = X_b X_d.

For +1 outcomes the normalized state is

    |R_CNOT> = (|0000> + |0101> + |1011> + |1110>)/2
             = 1/2 sum_(x,y) |x,y,x,y⊕x>.

For outcomes (-1)^r₁ and (-1)^r₂, track Z_a^r₁ Z_b^r₂. The commuting X checks preserve the initial Z constraints Z_a Z_c and Z_b Z_c Z_d. Therefore the state is exactly the CNOT Choi resource.

### 5.2 Consume two inputs

For input control u and target v, measure X_u X_a and X_v X_b, with outcome bits x₁,x₂. Then destructively measure Z on u,v,a,b. Let

    z₁ = z_u ⊕ z_a,       z₂ = z_v ⊕ z_b.

An XX measurement followed by individual Z measurements is a destructive Bell measurement: its branch bra is proportional to <z_u,z_a| + (-1)^x₁ <1-z_u,1-z_a|. The individual Z results do not measure extra information about the surviving outputs; they refine the implementation of a Bell bra.

The output c,d is CNOT applied to the original two inputs, with byproduct

    X_c^z₁ X_d^(z₁⊕z₂) Z_c^(x₁⊕x₂) Z_d^x₂,

up to a global phase and the previously tracked resource signs. This Pauli frame can be updated in software. All 256 resource/check/readout branches are verified in the accompanying program; no favorable branch is postselected.

### 5.3 Bias and actual costs

Physical Z faults and false X-parity outcomes propagate to Z-type output faults. The CNOT itself preserves the Z-error subgroup. Single-photon data loss during a dispersive mapping gives a data loss operator and an ancilla phase change, rather than an X error in the ideal large-cat model. The usual finite-cat, heating, and reconfinement qualifications still apply.

The difficult measurement is the destructive coherent-sign **Z readout**. An incorrect Z result causes an X-type output frame error. Four such results are used, so a conservative target requires 4 p_Z-readout to fit the allowed bias-breaking budget. If one merely releases a coherent state into a homodyne receiver of efficiency η, its assignment error is

    p_release = erfc(sqrt(2 η n))/2.

At η=0.5, this is 2.28% for n=2 and 0.234% for n=4. Four reads at those qualities are unsuitable for an extreme-noise-bias claim. A better calibrated readout protocol, longer protected signal integration, or encoded measurement is required, with its corresponding time and hardware cost. One cannot borrow an exponentially small idle bit-flip rate and assume the destructive readout has the same quality.

The minimum resource ledger per physical CNOT is:

| Resource | Count before verification and erasure retries |
|---|---:|
| Fresh resource cats | 4 |
| Offline parity checks | 2, with weights 3 and 2 |
| Online parity checks | 2, both weight 2 |
| Destructive Z results | 4 |
| Output cats replacing the inputs | 2 of the four resource cats |
| Required meter connectivity | At least a weight-3 check for this preparation |

The offline checks must be treated as noisy, and multiple factories can hide latency at a space cost. A finite erasure probability increases the mean number of attempts. Quantum data waiting for the resource or classical frame still accumulate loss. At the encoded level, code preparation, verification, and reliable logical readout are additional costs.

This is a concrete entangling computational continuation with the same axes. It is not a claim that it is cheaper than a calibrated native bias-preserving CNOT. It supplies no direct coherent-sign ZZ primitive, and it does not by itself supply an entire fault-tolerant universal gate set. Non-Clifford resources and correction of residual X faults remain separate obligations.

### 5.4 A noisy resource factory, and the final-fault limit

A concrete factory repeats S₁ and S₂ for R rounds, retains erasure flags, and estimates the *last* resource syndrome from the full time history. In the dominant Z-error model this is a small hidden-Markov decoding problem with four syndrome states. Decode to a Z_a/Z_b frame; if the posterior error exceeds the selected budget, continue measuring or discard the offline resource. Both actions consume elapsed time. With two independently provisioned meters the checks commute and may overlap; with one meter they are sequential. Neither schedule is free connectivity.

For a completely static resource and independent classical measurement error q, an odd-R majority vote has error sum_(k>(R/2)) binomial(R,k) q^k(1-q)^(R-k). That formula is not valid for a resource suffering photon losses during verification. A last-syndrome decoder must include those changes. Even ideal decoding cannot remove a Z fault after the last informative interaction: if the total relevant Z-fault rate is Λ_Z and the unobserved tail/storage/consumption gap is τ_tail, there is an O(Λ_Z τ_tail) boundary contribution. More rounds suppress some readout mistakes but lengthen data exposure. An erasure retry is a new interval, not a costless missing sample.

There is a separate limitation: repeated S₁,S₂ cannot detect X faults that violate the resource's Z stabilizers T₁=Z_aZ_c and T₂=Z_bZ_cZ_d. Such faults can arise from initialization, double ancilla decay, heating, or a last faulty interaction. Under the noise-bias contract they must be bounded explicitly by preparation errors, the factory and queueing X-hazard integrals, and the bias-breaking faults of every check. Full verification of T₁,T₂ requires an additionally earned coherent-sign Z-check primitive; it does not come from the XX meter. There is no claim here of perfectly verified Choi resources or an arbitrarily small output error using X checks alone.

At minimum the resource error budget has the form

    ε_resource,Z ≤ ε_decoder,last + Λ_Z τ_tail + other modeled Z channels,
    ε_resource,X ≤ ε_prep,X + integral_factory+wait Λ_X(t)dt
                     + sum_checks p_X,meter + unmodeled-channel allowance.

These are budgets whose terms must be characterized, not proved numerical bounds for a device. The online Bell checks add their own full-cycle faults, and the four destructive Z readouts add the X-frame-error budget identified above. This is the honest frontier between the useful ideal entangling construction and reliable repeated noisy computation.

The program also computes exact Bayesian average error in a deliberately limited classical factory model: projected resource syndrome sectors, independent per-cat Z jumps, projective checks with classical assignment error, and erasures. It does not replace a full quantum instrument model. With illustrative per-cat Z rate 0.002 per microsecond, a 2.45-microsecond round containing both checks, 2% assignment error, 1% erasures, and a 0.5-microsecond final unobserved gap, one round gives 5.27% final-syndrome error; three rounds give 2.27%; five give 2.12%, while verification plus gap lasts 2.95, 7.85, and 12.75 microseconds respectively. Even perfect measurement records retain a 0.399% final-gap error for every number of rounds. These figures illustrate diminishing returns and the final-fault limit, not a claimed viable factory operating point.

## 6. Full-cycle comparison with sequential syndrome extraction

For comparable per-link interaction duration T_π and nonmapping overhead T₀,

    T_seq = T₀ + w T_π,
    T_sim = T₀ + T_π.

The maximum saving is (w-1)T_π. If readout/reset/reconfinement dominate T₀, a factor-w mapping-depth reduction is not a factor-w cycle reduction. If joint activation degrades χ matching, adds spectator shifts, or needs extra guard time, the comparison must use those measured penalties.

Here is a reproducible **arithmetic example, not a measured timing decomposition or device prediction**. Set T_π=0.35 microseconds; preparation 0.2, switches outside mapping 0.2, readout 0.8, reset 0.7, restabilization 0.9, controller 0.2 microseconds. Overlap stabilization with readout/reset, giving T₀=2.1 microseconds. Use n=2, storage T₁=63 microseconds, ancilla T₁,f=25 and T₁,e=50 microseconds.

| Weight and schedule | Mapping (μs) | Entire cycle (μs) | Per-cat odd-loss probability | Double-decay exposure |
|---|---:|---:|---:|---:|
| 2, sequential | 0.70 | 2.80 | 8.14% | 9.66×10⁻⁵ |
| 2, simultaneous | 0.35 | 2.45 | 7.20% | 2.43×10⁻⁵ |
| 4, sequential | 1.40 | 3.50 | 9.96% | 3.81×10⁻⁴ |
| 4, simultaneous | 0.35 | 2.45 | 7.20% | 2.43×10⁻⁵ |

For weight two, cycle time falls by only 12.5% despite halving the mapping time. The change in double-decay exposure is larger because it is quadratic in the interval during which a block-changing ancilla decay can affect data. The ordinary photon-loss probabilities remain substantial. A logical claim requires an actual repeated-measurement decoder model, not these individual probabilities added together.

The comparison with a generic CNOT-based syndrome circuit is favorable when the native matched interaction replaces w sequential mapping intervals without adding a larger off-interval cost, and when bias allows a smaller outer code. It is not favorable merely because the pulse is called a direct parity measurement: algebraically the same ideal unitary factors into w controlled-parity gates. For a competing platform with faster CNOTs, cheaper preparation/reset, or superior readout, the above inequality can reverse.

## 7. Why I do not choose the direct nonlinear cat meter as the practical winner

There is an attractive stricter solution: engineer an actual P_S-dependent readout interaction throughout the experiment. In that case any meter emission sees parity alone. The projected Josephson construction provides a concrete example, but its measurement strength can become the limiting resource.

The following is an optimistic calculation for the controlled rotating-wave, Zeno, and weak-readout operating regime. It is not a no-go theorem for other nonlinear meters or for operation outside that regime.

For one cat define the number-diagonal physical operator

    F_φ = exp(-φ²/2) sum_m L_m(φ²)|m><m|.

Its exact projection onto the even/odd cat subspace has form c I + d X_cat. With α real and s=exp(-2n),

    f = exp(-φ²/2) J₀(2αφ),
    h = exp[-(φ-2α)²/2] I₀e(2αφ),
    c = 1/2[(f+h)/(1+s) + (f-h)/(1-s)],
    d = 1/2[(f+h)/(1+s) - (f-h)/(1-s)].

Here I₀e(x)=exp(-x)I₀(x). At φ≈2α, d≈1/sqrt(8πn). Products of w such factors produce the desired parity term, but finite c also produces lower-weight terms. Parameter tuning or extra nonlinear elements can address that projected error; finite-Zeno output channels and higher-order circuit terms remain separate checks.

Let j=E_J/ℏ, q=n_read φ_read², and ε=j/κ₂. With q much smaller than one and ε small enough for the stated controlled treatment, the favorable measurement rate scales as

    Γ_m ≈ 2 j q d^w,
    Γ_m/κ₂ ≲ 2 ε q d^w.

This includes the strong penalty for higher-weight checks. At the favorable cavity linewidth, steady-state homodyne discrimination has

    q_meas = erfc(sqrt(η Γ_m T_sense))/2.

This already assumes the steady state; buildup, ringdown, reset, and reconfinement can only add exposure. To demand q_meas≤q_* while one cat accumulates at most p_* odd-loss probability, a necessary optimistic inequality is

    κ₂/κ₁ ≥ [erfcinv(2q_*)² n]
             / [η (-ln(1-2p_*)/2) 2 ε q d^w].

For η=0.5, q_*=1%, p_*=5%, ε=0.1, q=0.1, the exact projected d above gives:

| Cat size n | Check weight | Minimum κ₂/κ₁ in this operating point |
|---:|---:|---:|
| 2 | 2 | 5.0×10⁵ |
| 2 | 4 | 2.4×10⁷ |
| 4 | 2 | 2.0×10⁶ |
| 4 | 4 | 2.0×10⁸ |

These are resource targets for a specific deliberately controlled regime, not claimed device capabilities. Increasing ε or q changes the numbers but eventually invalidates the approximations used to derive them. A new operating point has to demonstrate its full instrument and noise exposure afresh. This calculation explains why a meter that is structurally purer in the projected model need not be the best practical competitor to the matched dispersive route.

## 8. Verification and what remains to be demonstrated

Run:

    python phase5_parity_competitor/verify_competitor.py

The program uses NumPy and SciPy. It evolves each data cross-block under the exact three-level ancilla Lindbladian, including no-click attenuation and all unresolved jump histories, then extracts each readout-conditioned data instrument. It checks every within-sector matrix element for four data qubits. The data occupations are 0/1 in this finite test; the analytic theorem covers arbitrary integer oscillator occupations. This is a model certificate, not a simulation of a full pumped superconducting circuit.

For substantial dimensionless decay γ_f T=0.23 and dephasing coefficient γ_φ T=0.17, the matched model's maximum sector-scalar defect is 2.43×10⁻¹⁶ and its no-click defect is 2.01×10⁻¹⁶. The negative controls are informative:

| Perturbation in the numerical model | Worst unconditional intra-sector coherence loss | Final outcome probabilities can remain equal within sector? |
|---|---:|---|
| f/e frequency mismatch | 1.64×10⁻³ | Yes |
| Mapping-area mismatch | 3.08×10⁻³ | No |
| e→g decay added | 5.75×10⁻³ | Yes |
| Data-dependent f→e rate | 5.15×10⁻⁴ | No |

Thus equal parity-label statistics are demonstrably insufficient. The same code verifies the 256 CNOT-teleportation branches, their completeness, the Z-type propagation of representative physical Z faults and false XX records, and the X-type consequence of a false Z readout. In binary-exact arithmetic for these projectors, the CNOT branch residual is zero.

The next decisive hardware test is complete-cycle instrument characterization within each parity sector, including recovery and reset, for all g/f/erasure outcomes. For bounded check weight, reference-assisted process tomography or a suitable worst-case instrument bound is practical. A collection of QND parity histograms or a single recovered cat Wigner function is insufficient. Simultaneous and sequential operation should then be compared at the same total elapsed cycle, readout error, erasure policy, and calibrated bias-breaking error budget. The teleported CNOT additionally requires verification of its coherent-sign readout and resource-factory budgets.

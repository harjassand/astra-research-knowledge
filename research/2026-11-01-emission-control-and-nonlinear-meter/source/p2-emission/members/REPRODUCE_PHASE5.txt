REPRODUCING THE COMPLETED CHECKPOINT
Python3.12.14, NumPy2.3.5 and SciPy1.17.0 were used.
Run from the extracted archive root. Set OPENBLAS_NUM_THREADS=1 for stable
runtime and to avoid oversubscribing parallel numerical jobs.

Useful short entry points:

The corresponding JSON outputs are included. The complete nonlinear Fock
and Gaussian-instrument programs have their invocation options in the source
and phase5_autonomous/FINAL_REPORT.txt. Full nonlinear runs are materially
more expensive. The cutoff4convergence checkpoint completed10of16cycles;
PARTIAL_CONVERGENCE_c4.json records that partial status rather than claiming
a full run or a saved full-density restart state.

The root package check parses every new Python file and JSON, tests ZIP
integrity, and verifies that all143previous archive entries are unchanged.
It does not pretend to have re-executed all earlier research programs.

Read PHASE5_START_HERE.txt before interpreting a numerical result. Metrics
include code-projected amplitudes, instrument quantities, entanglement
infidelities, lost visibility and photon exposure; they are not interchangeable.

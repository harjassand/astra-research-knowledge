STREAMED OPERATION CONTRACT AND COMPARISON WITH CLY/BINOMIAL CODES
31 October 2026

This is a conditional organising theorem for the specified finite bosonic
model. It is not a threshold theorem, a complete fault-tolerant recovery
circuit, or a stand-alone accepted-instrument diamond guarantee.

DECISIVE LIMITATION: a bounded number of DIRECT partners of a tagged wire
does not by itself bound the correlated error support. A partner can carry
an undetected in-code Pauli fault onward through further gates. The mask
must cover the TRANSITIVE forward interaction cone, or the schedule must
cut that cone by recovery, consumption, or a proven transversal rule. An
inner check alone therefore does not complete a scalable computation.

I. THE MODEL AND THE TAGS

For each data block define the total-number-two sectors

    P = span{|11>, (|20>+|02>)/sqrt(2)},
    Q = span{(|20>-|02>)/sqrt(2)}.

Use N<2 as an absorbing loss tag until explicit replacement. Distinguish
this physical tag from a classical erasure label: a finite sensor may not
have reported it yet. A coherent Q amplitude is another pending tag.

Allowed ideal computational primitives are

    exp(-i alpha Jx),       Jx=(a^dag b+ab^dag)/2,
    exp(-i beta n_a n_b),
    C_AB=exp(-i pi n_a n_c).

They provide continuous local X and Z plus an entangling Clifford. Their
endpoints preserve P and Q for each block individually. In particular,
C_AB is identity if either block is Q: Q has even occupation in the
interacting mode, whereas only |11> has odd occupation. Losing the desired
interaction can still damage the partner relative to the intended circuit.
This is why the tag's entire bounded interaction cone is marked.

At intermediate times of a Kerr pulse, P need not remain the original
tensor-product code, but each n_j commutes with the Kerr Hamiltonian. Thus
for the moving ideal code W(t),

    W(t)^dag n_j W(t) = I

on its appropriate logical factor. During local BS/Kerr pulses the code
is invariant and the same compression holds.

Data noise in the protected contract is independent modal loss:

    L_j(t)=sqrt(kappa_j(t)) a_j,
    Gamma(t)=sum_j kappa_j(t) n_j.

The rates may vary arbitrarily in time. No bath cross-correlation is
included in this expression. Logical Hamiltonian noise, dephasing,
heating, and correlated loss outlets have separate residual parameters.

II. FIRST-ORDER STRUCTURE OVER ONE BOUNDED WINDOW

Consider a window containing a bounded number of gates and checks, with
complete integrated hazard eta=O(p). In the no-jump Dyson expansion the
accepted logical term is

    K_PP = c U_ideal P + O(eta^2),

because every first-order hazard insertion compresses to a scalar along
the ideal trajectory. Its non-scalar first-order contribution instead
has at least one Q tag:

    K_QP = O(eta).

This is an amplitude statement. The Q population is O(eta^2), but the
coherence between P and Q makes the full unmeasured output state O(eta)
away in trace norm. The distinction must be retained.

A single loss trajectory has probability O(p) and lowers the number of
at least one block. A loss during a two-block Kerr pulse can rotate the
partner by an unknown phase and can create its Q component. The entire
error is supported on those operands at that time. Marking both operands
is sufficient locally; downstream interactions enlarge that known support.

All ideal gate endpoints preserve every tag. In particular, a Q amplitude
cannot become a P amplitude merely by another ideal allowed gate, and a
lost photon cannot be restored by the number-preserving controls. Returning
an unflagged Q contribution to code requires another noise/control event,
unless the protocol performs an operation outside this tag-preserving set.

III. A FINITE MEASUREMENT DOES NOT RESET THE TAG MODEL TO PERFECT CODE

An ideal symmetry instrument on an incoming N=2 block has

    K_good = i X_L P,     K_flag = Q.

Its concrete C_h X C_h implementation includes a middle beam-splitter
pulse and two controlled parities. A noisy finite realization can accept
new Q amplitude created AFTER the part of the query that would have
distinguished it. The saved calculation exhibits exactly that term.

Nevertheless, a Q amplitude that was already present at the entrance of
a subsequent FAULT-FREE symmetry query is removed from its good branch.
Therefore, with periodic bounded-depth checks, the first-order pending
amplitude at an accepted boundary comes from the current finite window,
not coherently from arbitrarily old clean windows. Its return to P in a
subsequent accepted window is a two-event term. This is the useful local
streaming statement; it is weaker than asserting perfect quantum outputs.

An analogous rule holds for a loss after the last number sample: it may
remain unreported at the output, but a later clean number/parity check
detects it. A first-order loss must not be allowed to interact with an
unbounded number of partners before that later check.

With at most k interactions of any tagged wire between reliable samples,
the decoder receives a conservative erasure mask containing the wire and
all k partners. If one common event can blind the current check, enlarge
the mask to cover the next bounded window as well. A noise model with
unbounded sensor outage or unbounded leakage fanout does not satisfy this
contract. Classical records retain the earlier window boundaries.

IV. WHAT A TERMINAL COMPUTATION CAN CLAIM

For a finite computation ending in a measurement whose effects are block
diagonal in P and Q, the cross term between a clean code amplitude and a
pending Q amplitude does not contribute to outcome probabilities. After
the last bounded window, that particular contribution is therefore
O(eta^2), not O(eta). A logical Z readout may assign |11> to one value and
the whole {|20>,|02>} subspace to the other, while separately detecting
wrong total number. It is block diagonal in P/Q; changing basis by the
allowed local gates preserves that property. This does not locate every
Q event, but it does prevent its coherent cross term from causing a
linear classical-output error.

A retained QUANTUM output is different. Until a physical sector measurement
or dephasing has resolved its P/Q coherence, its trace/diamond distance can
remain linear. Do not promote a classical-output or code-projected claim
to a general quantum-output guarantee. A terminal physical instrument,
including its own tail, is needed for that stronger interface.

For long computation, the bounded-window property is essential. Without
checks, an O(p) amplitude can accumulate coherently over many locations
and give O((number_of_locations*p)^2), not a per-location local stochastic
rate. A complete outer-code proof must establish locality of the window
expansion and count malignant pairs; this report does not supply that proof.

IV-A. FINITE REJECTION CONTRAST, NOT AN IDEAL PROJECTOR

The same containment argument has a useful finite-contrast version. Let
a be a lower bound on the intended code acceptance amplitude and b an
upper bound on the acceptance amplitude of an incoming Q state. A
conservative coherent-readout bound is

    a >= sqrt(1-f_FP),   b <= sqrt(q_FN),   rho=b/a<1.

The detector calibration must justify these worst-case/conditional bounds;
an average clean-input test does not. If each bounded window creates at
most c p new Q amplitude and all unflagged P<->Q mixing is O(p), then in
an accepted-history expansion

    q_{m+1} <= rho q_m + c p + higher-order terms.

Thus the pending amplitude is bounded by c p/(1-rho), instead of
accumulating indefinitely. Re-entry into P carries another O(p) factor,
so its local contribution is O(p^2)/(1-rho). A terminal block-diagonal
measurement sees Q probability O(p^2)/(1-rho)^2. This does not eliminate
the linear P-Q coherence of a retained quantum output.

A finite-contrast detector can be unsafe if rho approaches one as the
device scales or if a persistent sensor outage violates the conditional
bound. Such an outage is not repaired by writing q^L.

For N=1 loss, an incoming-loss false-negative probability q implies a
delay tail at most q^L ONLY when the same bound holds conditionally for
successive checks. Retrospectively mask L windows; the remaining beyond-
mask contribution is at most O(p q^L). For fixed q<1, selecting
L>=ceil(log(p)/log(q)) makes this term O(p^2). Its history and cone size
are costs. With depth d of two-block gates per window, a completely
general forward cone can grow as 2^(d L). A surface-code orientation or
transversal schedule can give a much tighter bound, but must prove it.

There is a simple constructive counterexample to a direct-partner mask.
A differential-loss no-jump insertion can produce the tagged map
|Q_A><1_A|. A subsequent logical X on A converts its ideal-domain bra to
<0_A|, while Q_A itself stays Q. Conjugation by C_AB then gives a partner
phase (minus Z_B, with our controlled-phase convention), because C skips
when A is Q but should act when its ideal-domain state is |0_A>.
Apply H_B and then C_BC. The phase on B becomes X_B and spreads to Z_C.
The original tagged A never interacted with C. Checks of B's inner
membership see an in-code Pauli and do not flag it. The same propagation
mechanism is available for N=1 loss-induced partner errors.

For nearest-neighbour gates of finite range on a D-dimensional bounded-
density lattice, a delay of L windows of depth d confines the cone to
radius O(d L) and O((d L)^D) live sites. The spacetime history volume can
be O((d L)^(D+1)). This is better than the general circuit's exponential
branching bound but remains a real erasure/recovery cost. For arbitrary
connectivity or a tree-like schedule, exponential branching is attainable.
Measurement/consumption can end branches; it cannot be assumed in a
continuing coherent circuit.

At fixed detector miss q, choosing L=O(log(1/p)) to make p q^L<=p^2
therefore costs a polylogarithmic spatial mask on a fixed-dimensional
local geometry, but potentially a power of 1/p on unrestricted geometry.
For depth d, the crude unrestricted bound is

    2^(d L) approximately p^(-d log(2)/|log(q)|).

This calculation is not a decoder threshold. A real delayed-erasure
decoder may use probabilistic locations more efficiently than erasing the
whole conservative cone; that is established architectural work. At fixed
nonzero q, a single loss plus a long string of misses also gives a logical
failure contribution p q^L that is first order in p at fixed code size.
One must not infer a doubled power-law distance in p while holding sensor
errors fixed. In a joint q=O(p) fault scaling, the same event costs L+1
faults instead.

The root's native always-on-dispersion synthesis does not have scalar
code compression at every prefix. Its accepted first-order in-code term
requires the separate fresh-sign randomization/phase-covariant-noise
contract established by the native-control agent. Once that in-code
channel is reduced to O(p^2), the finite-contrast tag recurrence above
still applies to its P/Q blocks. One must not cite the ideal switched
primitive's prefix balance as proof for that different native schedule.

V. IMPERFECT HELPERS, READOUT, AND RECOVERY

For the intended C_h X C_h primitive, helper number-diagonal noise commutes
with the whole query and factors to the final pointer on valid data.
Arbitrary faulty preparation within the intended helper control manifold
has the same property at the nominal BS angle: valid data receive the
known X, while the syndrome reliability can be wrong. In a g/f/e helper,
f->e decay gives a terminal e flag if the drive does not return e to g/f.
Its arbitrary propagated data action is discarded on that flag.

Finite readout false-negative probability q and false-positive probability
f remain real. A single loss plus a distinct independent miss contributes
O(p q). At fixed nonzero q this is first order in p; it is quadratic in a
joint physical-fault scaling only if q=O(p). Helper loss plus a readout miss
has the same issue. A common fault with both effects costs its own c term.
The tentative window budget is therefore of the form

    located clusters: O(p)+O(f),
    unlocated/incorrect-record terms:
        r_control + r_dephase + r_heat + c + O(p q) + O(p^2),

with constants and coherent/stochastic metrics declared separately.
This expression does not assert a threshold or a recovered logical rate.

Noisy replacement keeps the erased location marked. The outer decoder
must operate with noisy repeated syndromes and a Pauli frame, including
reset errors, delayed flags, correlated partner damage, and false flags.
An inner flag is not a perfect recovery operation. The unprotected local
analog X/Z gates and a complete noisy recovery/factory schedule remain
outside the completed subroutine. Standard teleportation or verified
ancilla constructions can be adopted only with their actual costs.

One concrete continuation is an established distance-three CSS outer code
such as the seven-qubit Steane code, with transversal Clifford operations
and noisy verified ancilla/teleportation recovery. Seven inner blocks cost
fourteen data modes and fourteen data photons per outer logical qubit,
before syndrome helpers, spare modes, factories, readout and couplers.
A transversal inner C gate couples only coordinate i of each outer block.
A single tagged inner failure then affects at most that coordinate in
each touched outer block; keeping all later interactions coordinate-wise
prevents an unbounded same-block hook. Two located erasures are correctable
by the abstract distance-three code, whereas arbitrary unknown errors
have the ordinary one-error limit.

An encoded Bell-state teleportation recovery can replace a damaged outer
block without trying to reconstruct its lost inner states in place. Its
Bell measurement is transversal, its measurement erasures and Pauli
outcome errors are decoded, and its output Pauli frame is tracked. But
the Bell-state factory must have a verified single-fault property under
the SAME inner model, not an ideal-state assumption. Denote its remaining
malignant-fault probability r_factory, recovery probability r_recovery,
duration T_recovery, and live-spare count N_spare. They remain explicit
terms and resources until a selected known circuit has been audited.
Magic-state injection/distillation is an additional universal-computation
cost. This supplies a concrete integration route, not completed resource
numbers or a new threshold proof.

VI. THE FULL-LOSS-ALGEBRA OBSTRUCTION

Independent outlets are consequential, not cosmetic. If the bath has a
positive correlation matrix G, its hazard is

    Gamma=sum_jk G_jk a_j^dag a_k.

For the N=2 code,

    P a^dag b P = X_L.

For example, positive G=[[kappa,xi],[xi,kappa]], |xi|<=kappa, gives

    P Gamma P = 2 kappa I + 2 xi X_L.

Its no-jump branch contains exp(-xi T X_L), an undetected first-order
logical filter. All actual losses can still reduce number and be flagged.
Thus flagging every jump does not repair the correlated no-jump channel.
Either the physical outlets must be independent to the stated accuracy,
or the off-diagonal G terms must be included in the residual budget or
addressed by a stronger code/randomization strategy.

VII. FAIR COMPARISON OF THREE ESTABLISHED ENCODING LEVELS

A. One-photon dual rail |10>,|01>
   Two data modes, one photon. Independent unequal rates create a linear
   deterministic no-jump filter. Matching, echo, or physical randomized
   compiling address it under their respective contracts. Ordinary BS
   performs logical X; dispersive/Kerr or SWS gates provide interactions.
   Experimentally mature imperfect-check comparators already exist.

B. Balanced N=2 code |11>, (|20>+|02>)/sqrt(2)
   Two data modes, two photons. Independent modal hazards compress to a
   scalar at first order. Full correlated loss algebra does not. Ordinary
   BS still supplies a nontrivial logical X, because off-diagonal modal
   exchange was not included in the protected hazard span. Loss is an
   outer erasure; a same-number symmetry check is an additional cost.
   This is a contract/control tradeoff, not a newly discovered code.

C. CLY/two-mode binomial N=4 code
       |0>=(|40>+|04>)/sqrt(2), |1>=|22>.
   Two data modes, four photons. Here
       P n_a P=P n_b P=2 I,   P a^dag b P=0.
   It satisfies the one-loss Knill-Laflamme algebra, including unknown
   mixtures/correlations of the two loss outlets. The two loss spaces can
   be distinguished and corrected in an ideal recovery, though that
   recovery must itself be qualified for a physical comparison.

For ANY code satisfying P a_i^dag a_j P=c_ij P, every passive bilinear
Hamiltonian H=sum h_ij a_i^dag a_j has scalar PHP. If H preserves the code
at all times, it cannot perform a nontrivial continuous logical gate.
This is the resource law connecting the protected loss algebra to control:
more protection removes passive control generators from the logical
algebra. Nonlinear interactions, excursions, or measured/teleported gates
must pay the difference.

Do not infer that four photons are always slower. The N=4 example has
logical X from a^dag^2 b^2+a^2 b^dag^2, with projected matrix sqrt(48) X;
this is higher-order pair hopping. It also has a controlled phase from

    exp[-i (pi/4) n_a n_c],

which is diag(1,1,1,-1) on two N=4 code blocks. At the same hypothetical
Kerr strength its required Kerr phase is four times smaller than the N=2
gate's pi. Its greater excitation count therefore does not automatically
imply greater entangling-gate loss. Conversely, pair hopping, higher Fock
calibration, code checks, and recovery may be harder. Only a complete
device-level operation comparison can determine an advantage.

The CLY code and its interpretation are established work: Chuang, Leung,
Yamamoto, Phys. Rev. A 56, 1114 (1997), doi:10.1103/PhysRevA.56.1114;
Michael et al., Phys. Rev. X 6, 031006 (2016). The small matrix identities
and comparator gate formulas above are directly checked specializations,
not historical novelty claims.

PREPARATION-ROBUST REALISED-PATH INFERENCE WITH A KNOWN DENSITY BOUND
Solo derivation, 31 October 2026. Read after PREPARATION.txt.

1. AN EXTERNAL PREMISE THAT CAN REPLACE EXACT STATIONARY PREPARATION

Let P be the same time-homogeneous all-even Markov dynamics, with a
stationary reference probability pi, but start at rho_0 instead. Assume an
EXTERNALLY CERTIFIED finite constant C>=1 satisfies

                 rho_0 << pi,       d rho_0/d pi<=C.        (W1)

The algorithm receives C, not hidden states, pi, P, a mixer or fitted
source parameters. This is a quantified preparation assumption; it is not
learned from the observed record. Merely assuming that some unspecified
finite C exists is insufficient for this finite-confidence procedure.
The exact preparation countermodel requires C growing exponentially with
the horizon, so it does not supply a free counterexample to the bound here.

For discrete time write r_t=d rho_t/d pi. Markov propagation and stationarity
give r_t=P^{*t}r_0<=C. This also holds for every physical time of a CTMC.
Define Sigma_st(t) using the stationary reference pi and the ordinary
reverse dynamics. The ACTUAL nonstationary total path entropy, defined
with initial ensemble rho_0 and final ensemble rho_t, is exactly

 Sigma_act(t)=Sigma_st(t)+log r_0(X_0)-log r_t(X_t).        (W2)

This identity also holds for the full CTMC path, including the correct
nonstationary system-entropy term. It must not be replaced by stationary
entropy alone. One-way/infinite cases use the extended likelihood-ratio
conventions; the inequality below is immediate when total entropy is infinite.

2. A UNIFORM BOUND WITH ALL PREPARATION CHARGES

Under the ACTUAL rho-start path law, the probability of an event E on the
entire infinite path is at most C times its probability under the pi-start
law: their Radon-Nikodym derivative is r_0(X_0). Also

 Pr_rho{log r_0(X_0)<log delta}
       =int_{0<r_0<delta}r_0 d pi<=delta,                 (W3)

for0<delta<1. This is one initial event, so it is simultaneous over time.

Take any stationary-reference time-uniform observation-only band B^gamma
from CHECKPOINT_PROOF.txt, with stationary error risk gamma. For a desired
total risk alpha set

     gamma=alpha/(2C),       delta=alpha/2,
     A_t=B^gamma_t+log delta-log C.                       (W4)

The stationary-reference band fails under rho with probability at most
C gamma=alpha/2. On its coverage event and the complement of (W3), (W2)
gives Sigma_act(t)>=A_t at EVERY time. The total risk is therefore<=alpha.
No conditional martingale for exp(-Sigma_act(t)) is asserted; that process
need not be a martingale away from stationarity. The proof uses change of
initial path measure and the explicit boundary term. Stopping is valid at
the same scope, while the dynamics and preparation contract remain fixed.

If C=1, probability normalization implies rho_0=pi; warm_preparation.py
uses the original stationary band at alpha with zero preparation penalty.
Otherwise it implements (W4), including conservative logarithms, the
increased inference-confidence cost and the negative boundary allowance.
It retains negative endpoints. A sharper user-supplied lower bound on r_0
could improve (W3), but is not silently assumed.

This extension changes the preparation premise, not the target. It bounds
ACTUAL nonstationary total trajectory entropy. It is not a stationary
ensemble mean-rate estimator, a bound on drive dissipation with preparation
removed, or inference under arbitrary unknown preparation.

3. CONSEQUENCE AND LIMITS

An exact stationary draw is no longer necessary if a finite bound (W1) is
genuinely available. For example a known uniform16-state stationary
reference permits any fixed known initial state with C=16. This fact is
supplied by the validation model, not inferred from binary measurements.
Obtaining a uniform state-space density bound for a real device may still
be expensive or impossible; preparation work, reference-model validation
and physical reversal are external resources.

For fixed C the extra boundary allowance/N vanishes and its confidence
charge adds log C to calibration logarithms. Almost-sure properties proved
under the reference stationary path law also transfer to the rho-start law
by absolute continuity. Thus a complete growing-library band has the same
observed-component minimum limit, for the visited ergodic component of the
REFERENCE stationary law. This is not a rate statement for a nonexistent
stationary ensemble of the transient preparation. No uniform convergence
onset or computational budget follows.

The control work/warm_preparation_control.py verifies exact nonstationary
boundary identities and path-law domination on small hidden chains. It
then draws fresh fixed-state CTMC records for driven and reversible dynamics,
with preparation density ratio bound16, and withholds all latent data from
the wrapper. Reversible DYNAMICS with a fixed-state preparation need not
have zero actual total entropy; that control is labelled accordingly.
This is synthetic validation, not acquired physical preparation calibration.

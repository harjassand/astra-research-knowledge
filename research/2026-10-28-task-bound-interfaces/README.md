# Source-supported interface navigation

This slice makes separately qualified results discoverable through an actual
shared operation. It does not infer a transfer from similar words or convert
one provider's scientific inputs into another's.

The new consumer takes a warranted scalar enclosure for a named task and a
threshold in the same units. Its complete elementary proof is in
`source/QUALIFIED_TASK_BOUND_INTERFACE.md`. It retains the source model family,
validity event, units and costs. It also proves the witness-persistence test for
an observation that leaves a sharp task interval unchanged, and gives the
counterexample separating that statement from Bayesian value.

Six reviewed adapters in `source/ADAPTER_PROOFS.md` connect control regret,
signed moments, a three-correlation heat certificate, simplex regret, canonical
displacement and conditional modeled readout benefit. Two previously buried
premises have their own units: the observation-fibre gradient regret lemma and
the finite imaginary-time heat bound. The shared consumer is useful navigation
between these operations. It supplies no physical, confidence or unit conversion
between them. `bridge` continues to report no supported provider-to-provider
connection unless a separate actual transfer is recorded.

The storage is linear in the number of declared bindings. Each exact-version
binding is stored once on its consumer; provider and parent routes point to it.
CLI, source packets and the read-only agent adapter consume this same canonical
representation. Source programs are not executed.

```sh
python3 knowledge/retrieve.py search "describe the scientific problem"
python3 knowledge/retrieve.py peers N768
python3 knowledge/retrieve.py packet U768-fibre-gradient-regret
```

`peers` supports `--offset` and `--limit`. Agent search menus expose bounded
previews and fetch routes; the consumer capsule contains all bindings with
ordinary complete-payload pagination. Read each candidate's actual proof,
conditions and corrections before reuse.

This is a curated physics/control/learning slice. Its elementary interface is
not a novelty, measurement, device or practical-advantage claim. The existing
producer sources remain byte-identical at their old public routes. Newly
authored proofs and adapter reviews are explicitly separate from originals.
Further source-supported ports use the existing unit/transfer formats and the
ordinary build/check path; no scientist reporting form is added.

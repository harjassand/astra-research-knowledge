# Qualified scalar bounds as a decision interface

Astra retrieval-owner construction, 28 October 2026 (Brisbane).
This is an elementary interface derived for reusable research navigation,
not a novelty, measurement, device or advantage claim. Original producer
sources remain separate. Review covers only the explicitly stated mathematics.

## 1. The operation and its qualification

Fix a named real task T on a nonempty admissible model family C. Keep the
source's units, quantifiers and validity condition E. Receive warranted
bounds L <= T(m) <= U for every m in C conditional on E. One side may be
infinite; no missing finite bound is invented. Let c be a supplied threshold
in the same units. The requested decision is the predicate T <= c.

If U <= c, the predicate holds throughout C. If L > c, it fails throughout C.
Proof: substitute each warranted inequality. No reconstruction of the model
is needed. Source costs and the obligation to establish E remain unchanged.
If the source bounds hold on an event of probability at least 1-alpha, this
conclusion inherits that event; it does not become unconditional certainty.

If L <= c < U, this interval alone does not certify the decision. It proves
actual decision ambiguity only when admissible witnesses occur on both sides
of c. A loose interval [0,2] for the singleton family T=1 and threshold c=1/2
is unresolved by that interval even though the true decision is fixed.

## 2. Additional observations and task value

For an observation o with reported value y, replace C by the justified fibre
C_y = {m in C : o(m)=y}; use the actual thickened fibre under bounded error.
If both old task extremizers remain admissible and attain L and U in C_y,
then the sharp task interval remains [L,U]. Every threshold predicate has
the same robust feasibility status as before. This is a setwise statement
about the named task, not zero Bayesian, average-loss or physical value.

## 3. A forbidden quantifier conversion

Let S be a fair bit and let Y equal S with probability9/10. Both conditional
laws S|Y retain support {0,1}; the sharp setwise interval for T=S stays[0,1].
Bayes classification error nevertheless falls from1/2 to1/10. Thus unchanged
support-based bounds do not mean unchanged Bayes risk. Conversely a small
model-average error does not certify every model or outcome. A prior with
Pr(S=1)=1/100 permits a constant-zero predictor with mean error1/100 and
conditional error1 on the rare model. These are exact mathematical controls,
not experimental data or an acquired quantum-readout implementation.

## 4. What a common consumer means

Control regret, a signed moment task, a heat deficit, a canonical displacement
and remaining model-average readout benefit can each supply their OWN valid
scalar bound to Section1. They retain different target definitions, units,
model families, validity conditions and acquisition costs. Sharing this
consumer makes them scientifically useful navigation peers. It does not
convert one provider's theorem, physical interface, confidence or unknown
inputs into another provider's hypotheses.

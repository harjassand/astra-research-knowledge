ALL-ORDER CRITICAL ISING RESPONSE: CONVENTIONAL COMPARISON
1 November 2026

The task here is chi=<M,K^-1 M> for the actual nonlinear spin dynamics, not
exclusion transport. Use the root's normalized rates

 w_i=(1-b sigma_(i-1)sigma_(i+1))/2
        *[1-gamma sigma_i(sigma_(i-1)+sigma_(i+1))/2],
 b=1/3, gamma=(n^2-1)/(n^2+1), t=(n-1)/(n+1).

Set kappa=(1-b)(1-gamma), theta=kappa chi/Var(M). This kappa is the dual
killing coefficient, not the Rayleigh coefficient denoted kappa in the older
critical_ring_proof.txt. The response is to this physical generator; changing
an equilibrium sampling algorithm would not preserve it.

1. Strongest completed deterministic comparator
-----------------------------------------------
The exact two-moment Gauss--Radau construction in critical_radau.py uses the
same microscopic rates and the acquired cubic reference inverse. At n=128,
after adjusting its old overall rate normalization, it gives

 theta in [0.5096202313320317, 0.5098649261668976],
 chi   in [78145285.89608003, 78182807.4594958],

relative width 4.8015134e-4 in 0.918 seconds. These are deterministic rational
certificates, not statistical intervals. The root's completed 500000-sample
all-order calculation gives, at95% confidence,

 theta in [0.5097029693966784,0.5097486541071838],
 chi   in [78157972.97033411,78164978.27456665],

relative width8.9630e-5 and midpoint relative-error certificate4.4813e-5, in
320.3seconds including certification. It is5.36times narrower and substantially
more expensive. The earlier50000-sample run had width3.9084166e-4 in32.6seconds.
There is no measured speed advantage near the Radau accuracy. The deeper run
demonstrates refinement beyond the fixed two-moment information width.

The fixed two-moment bound has a strictly positive information width at fixed
n. Reducing the numerical residual of its cubic solve cannot remove that
width. Increasing the moment order is a valid conventional route, but requires
additional target/reference actions and growing odd-degree spaces; neither
the existing two-moment certificate nor an assumed low-rank tensor acquires
an arbitrary-accuracy backend. This is the actual service difference of the
all-order sampling result. The elementary potential/current comparison also
already gives O(1/n) relative accuracy; fixed-accuracy large-n asymptotics
alone would not distinguish the new operation.

2. Physical waiting time versus ordinary event cost
--------------------------------------------------
The exact equilibrium total accepted flip rate is

 A_n = n/2 [1-b C2-gamma(1-b) C1],
 Cj=(t^j+t^(n-j))/(1+t^n).

It tends to (1+b)tanh(1)=4tanh(1)/3, a constant. Equilibrium has only
n(1-C1)/2 ->tanh(1) domain walls on average. Thus a conventional rejection-free
n-fold/domain-wall simulation takes Theta(n^2) accepted flips per magnetization
correlation time chi/Var(M), not Theta(n^3). A uniform site-attempt implementation
would waste the additional factor n, but is not the strongest elementary-event
comparator.

At n=128, A_n=1.0051143197685624. The deeper root confidence interval implies
response time [6263.6123652,6264.1737732], and the stationary expected number of
accepted physical flips over that duration is [6295.6464817,6296.2107609]. This
differs from the transformed dual's roughly234 accepted events per sample. These
counts do not by themselves compare estimator variance or wall-clock speed.

The n^2 event count is not a lower bound for every conventional method.
First-passage KMC already skips internal diffusion hops by protective-domain
propagators. Oppelstrup etal explicitly include discrete lattice jump walks;
Donev etal include insertion, death, and competing reactions. A fully costed
implementation for this periodic pair-creation/annihilation process and its
integrated magnetization response has not been acquired here. It must remain
an unresolved acceleration competitor, rather than be declared impossible.

3. Established general machinery versus the acquired model-specific bridge
-------------------------------------------------------------------------
Awad--Glynn--Rubinstein (2013) treat positive linear-system expectations,
Markovian importance sampling, regenerative ratios, jump-chain embeddings,
and Lyapunov variance bounds. Their exact zero-variance transition kernel uses
the unknown answer. The root's positive h and explicit Wcost therefore supply
the hard model-specific operation instead of inventing importance sampling.

Douc--Jacob--Lee--Vats (AOS2026) construct unbiased Poisson/asymptotic-variance
estimators using coupled chains. Their governing assumptions require moments
of an actual coupling meeting time; these do not supply a uniform-in-n cost
bound for this nonlinear kinetic Ising model without another construction.

The positive branching-annihilating dual and the Herman-protocol F3/F5
polynomials are also prior machinery, as the interacting collaborator's proof
now records. The newly acquired interface in this investigation is the target
branch drift, the U drift, and the pointwise positive combination

 H Wcost >= N h.

Together with Hh>=epsilon N, this gives both bounded transformed scores and
proved expected work. No universal theory or literature priority is established.

4. Compatible conventional implementation using the same new potential
-----------------------------------------------------------------------
There is a useful reconciliation: Wcost can also certify ordinary raw killed-
dual regenerative sampling, without the Doob transform.

Let P be the embedded substochastic jump matrix on nonsingleton odd subsets,
N the diagonal particle-count matrix, and H=N(I-P). Let T be the number of
embedded steps until killing or singleton return, starting at the packed3.
Then u=E T=H^-1 N <=h/epsilon. The standard second-moment recursion gives

 E T^2 =2[(I-P)^-1 u]-u
       <=2[H^-1(Nh)]/epsilon
       <=2 Wcost0/epsilon =O(n).

Meanwhile E T<=h0/epsilon=O(1). Thus the variance has the factor n while each
raw excursion has constant expected event count. Median-of-means gives
O(n delta^-2 log(1/failure)) excursions. The transformed version instead uses
O(delta^-2 log(1/failure)) excursions, each with O(n) expected events. Both can
have the same asymptotic total arithmetic cost. This does not independently
displace the new result: the improved raw variance bound explicitly USES its
newly acquired Wcost. Without that bridge, the simple geometric killing plus
first-moment bounds only yield an O(n^2) second-moment bound.

For a raw path, acquire
 U_sample=T,
 R_sample=sum_over_visited_states alpha(S)/N(S).
Then theta=(1+b E R_sample)/(1+b E U_sample); 0<=R_sample<=T/3. No exponential
holding times need be sampled: conditional means Rao--Blackwellize them.

The static-score backend need not enumerate every site at every step. The
root's positive gap formula has a small transfer representation. For a gap g
traversed with slope +, set q=t^g and r=t^(1-g)(1-q), and use

        [q    0    0]
 M+(g)= [0   1/q   0],   M-(g) swaps the first two coordinates.
        [1-q  r    1]

These act on (t^e,t^(n-e), accumulated numerator). Initial e is the sum of
odd-index gaps; the final numerator is divided by (1+t)(1-t^n) to obtain alpha.
Maintain both starting parities of the ordered matrix product,
plus alternating gap sums, in an augmented balanced tree. Toggling two sites
changes only a constant number of adjacent gaps. Precomputing outward dyadic
t^g and t^-g for0<=g<=n takes O(n) operations; subsequent updates cost O(log n).
At this critical scaling t^-n is uniformly bounded, so the positive transfer
matrices do not introduce an exponential condition number. This earns an
ordinary complete-score implementation with the same O(n log n delta^-2
log(1/failure)) expected arithmetic order once Wcost is available. The transfer
formula is derived here and checked with exact rationals on all1016odd subsets
of rings4through10against the independently enclosed positive gap sum. A
separate fast raw-sampler implementation has not been run, so no numerical
performance claim is attached to it. The executable transfer audit is preserved
in raw_dual_transfer.py and raw_dual_transfer_audit.json.

5. Audit points and limitations
-------------------------------
The root C++ sampler's proposal law normalizes correctly. With D=3(n^2+1),
the proposal envelope is D+4(D-4), and acceptance probability is exactly
D/[D+4(D-4)]=1/(5-4kappa), independent of state. Branch/hop weights match the
intended h-transformed generator, including killing. I found no transition
normalization error in this inspection.

The W-score clipping needs an explicit mathematical justification, not a
numerical convention. Nonnegativity is equivalent to

 1-alpha(S)<=kappa N h(S)/c0, c0=gamma(1-b)/2+b.

It follows from reference annihilating duality:
1-alpha(S)<=2(1-gamma)h(S)/gamma. At b=1/3,N>=3,gamma>=1/2, the latter is at most
kappa N h/c0. The upper W bound follows from alpha<=1 and N theta0>=1.
This supplies a proof route for the clipping used in the implementation.

The four-tail exact empirical-Bernstein certificate uses a fixed sample count,
which is appropriate. It is statistical confidence under independent random
bits; the executable uses a seeded standard PRNG. Expected work does not bound
individual excursions. The C++ integer implementation is explicitly restricted
to n<=65536; arbitrary n requires the straightforward multiple-precision integer
version, with logarithmic-size integer operands accounted for. The root has
also implemented streaming score accumulation and matched its exact moments
against the n16histogram output, so sample-memory growth is avoidable by an
actually constructed path. The older Python sampler still has the obsolete
n^2work-bound text; the newer certificate uses Wcost correctly.

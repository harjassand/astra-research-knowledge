## Result and practical boundary

The retained result is a **mathematically valid, access-dependent energy-sensitive
compiler and expected adaptive-call corollary**, together with acquired clock,
two-state bridge, and source-only Gaussian-kernel components. Exact review scopes
and source versions matter: this is not a blanket independent review of every
file, an executed quantum simulator, or a new integrability claim.

The static audit is still expensive. On the same n=4, epsilon=0.01,
lambda=10^24 fixture, the reviewed last-refresh ledger reports
**6,848,103,948 source-clock controlled-rotation invocations** and
**1,905,309,000 Gaussian-filter controlled-rotation invocations**. These are
separate padded invocation proxies, **not elementary gates or T counts**.
Reflection/zero-test gates, comparisons, reversible arithmetic, routing,
phase/rotation synthesis, Gaussian basis changes, source acquisition, physical
couplings/jump stacks, H0, and controls remain additional costs. No practical
advantage or error-certified runtime crossover has been established. The strong
ordinary dense/effective-model comparators are retained, not replaced by a
weaker baseline.

Both alternative proposed advantages failed their stronger comparisons:

* **Acquired GF(2) multiplication identity.** Exact rank-seven recovery and
  shared-XOR compilation work, but the 15-addition result matches retained
  Strassen–Winograd and does not establish a new capability. In the recorded
  n=512 Python-packed fixture, direct Four Russians took about 6.16 ms versus
  10.37 ms for the best acquired recursive cutoff and 10.61 ms for Winograd.
  These are local timings, not a native/SOTA benchmark. AlphaTensor, flip-graph
  search, AlphaEvolve, and alternative-basis algorithms remain explicit prior
  art/comparators in that investigation's README.
* **Hidden parity-family acquisition.** Variation can recover a shared spatially
  varying parity chart, but one generic member, using the actual prior N1077
  recognition mechanism, already determines the same maximal local family.
  The recorded four-task acquisition took 0.200–0.244 s versus 0.047–0.051 s
  for the stronger one-member route, including a rejected trial. Retained
  elimination on the small cube took 0.72–1.02 ms per query versus 24.8–29.3 ms
  for membership checking plus Pfaffian contraction. The exact singular-query
  extension and 2,600-byte persisted chart remain useful capital, not a new
  tractability class or demonstrated practical advantage. No cheap full-rank
  sampling promise is inferred from a varying task distribution.

## Integrity and reproduction

All 125 copied scientific source files are byte-for-byte unchanged. `ALLOWLIST.json`
identifies those files and separates inherited dependencies. `FILE_LIST.txt`
lists every archive member. `MANIFEST.json` gives SHA-256 and byte counts for
every payload except itself and `SHA256SUMS.txt`; the latter additionally hashes
the manifest and excludes only itself. `verify_checkpoint.py` checks exact
membership, safe paths, hashes, byte counts and checksum-list consistency. SHA
hashes provide integrity, not independent review or a cryptographic signature.

From an extracted archive root:

    python3 -B verify_checkpoint.py
    python3 -B check_checkpoint.py

The second command is a focused, read-only reproduction check: source syntax,
JSON parsing, exact reviewed-ledger regeneration in memory, bridge diagnostics,
10 parity tests, and the 347 exact multiplication cases/84 corruption
rejections. `CHECKPOINT_VALIDATION.json` and `CHECKPOINT_TESTS.log` record the
local packaging run; they are not a new independent scientific review or a
rerun of every historical performance benchmark. The archived first-run
timings are preserved unchanged.

Environment used: Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, mpmath 1.3.0,
SymPy 1.14.0. No software was installed for this package. The integrity verifier
uses only the Python standard library. Other original scripts may rewrite their
JSON outputs: run them only in a disposable extracted copy if preserving the
checkpoint bytes matters. Float diagnostics and timings can vary by platform.

Caches, administrative/private material, the mixed N1077 contribution/source
note, the administrative N1077 packet, old subset manifests, delivery metadata,
and `effective_logical_channel_20261031` are excluded. See `EXCLUSIONS.json`.
No source file or older archive was edited or overwritten during packaging.

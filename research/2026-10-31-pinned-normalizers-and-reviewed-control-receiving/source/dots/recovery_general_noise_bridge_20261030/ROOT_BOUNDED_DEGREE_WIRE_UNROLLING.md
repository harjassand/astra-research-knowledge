# Optional static bounded-degree wiring for the scheduled ordinary factory
30 October 2026. Root construction candidate; not independently reviewed. No geometrically local or autonomous implementation is claimed.

The ordinary protected circuit may use changing gate partners. Bounded instantaneous fan-in does not by itself bound the number of physical neighbors a reused qubit needs over the entire run. A conservative explicit space-time wiring construction pays for this distinction.

Take the complete finite padded elementary schedule, including idle locations. For each logical wire segment at each clock period allocate a new physical carrier. For a gate on at most g wires, its coarse physical location contains the g current carriers and g next-period carriers. Reset the latter with the actual finite onsite replacement primitive, execute the intended g-wire gate on the current carriers, then swap each current state into its next carrier. Old carriers become unused garbage. For idle gates do the same with g=1, or count their explicit holding periods.

The ideal target channel of this coarse location is the desired wire gate followed by state transfer to the new carriers. It resets/discards the old carriers only as already specified by the target replacement/transfer channel. Its actual finite reset has residual delta as in the accepted approximate-target cavity proof. All operations inside this fixed-size location have bounded strength and fixed total duration; their support has at most2g carriers. The CP-cavity theorem can therefore be applied DIRECTLY to these coarse locations with the enlarged fixed g and duration. Do not append uncontrolled swaps after a fault-tolerance proof while continuing to use its old location count or noise constant.

At a time layer these coarse blocks are disjoint. The same future carrier becomes a current carrier only in the next layer. Ordinary fault-class correctness treats the coarse faulty location as an arbitrary error on its participating wire symbols and bath, precisely its existing interface. Old garbage may retain correlations; include it in the arbitrary shared bath once its ideal wire use has ended. If all old sites remain in the formal system, their later idle faults outside every live output cone do not give a new ideal communication path to the data; any actual coupling to a live wire is already a bounded incident perturbation at that live location.

The static physical graph contains edges for each fixed gate implementation and each wire transfer. Each carrier belongs to at most a preceding transfer, one current gate and a following transfer (and its onsite reset); its number of distinct neighbors is bounded by a constant depending on the actual gate body. No global crossbar, dynamically selected physical neighbor, perfect routing computation or unbounded-degree port is required. Gate times and all reset/transfer activations remain an externally specified schedule.

If L_phys denotes the COMPLETE padded location count of the protected factory before this constant-size replacement, carrier count and static edges are O(L_phys); depth and location count increase only by a fixed factor. This is larger than active-width space and must be included. For the present exp(-cN) preparation target the protected schedule already has polynomial(N) size, so this remains a potentially very large polynomial cost, not a near-linear or practical factory.

Choose the last new carriers to be the actual native DATA/ready-apparatus handoff sites. Their native Tanner/controller edges add only their existing bounded degree. Future native operation does not require preserving the abandoned unrolled wires. The fixed graph can be reset and reused for another known-state preparation, but a repeated-factory guarantee must count its actual reset and retained correlations rather than infer renewal from this one-run wiring argument.

This construction proves only an abstract static bounded-degree gate graph under supplied local gate/reset primitives. Euclidean embedding length, finite signal speed over long edges, hardware switch realization, heat removal, and a noisy autonomous clock are separate physical costs. It does not improve asymptotic time or work, and is not presented as a new routing algorithm.

# Screened alternative: common-syndrome Bell resources
30 October 2026. Root algebraic opportunity screen, not an accepted preparation theorem.

For a CSS code, start with N physical Bell pairs and measure the code stabilizers on both halves. In the ideal case the outcomes coincide, s_A=s_B=s, and the conditioned state is the maximally entangled state between the two syndrome-s code sectors:

 Phi_s=(P_s tensor P_s^*)Phi_code.

The choice of Pauli P_s carrying code sector0 to sector s does not change this state: changing P_s by a logical Pauli applies that Pauli and its conjugate to the two logical Bell halves. Thus all logical Bell correlation operators have the same ideal signs despite the unknown common syndrome. For Pauli errors moved to the first half using the physical Bell transpose identity, the measured syndrome difference is the error syndrome. A decoder for that difference can align the halves up to a residual local error.

This suggests using the already-earned imperfect-baseline native receiver to protect a common-sector relational resource instead of forcing every physical syndrome to zero. However it is NOT yet a usable stand-alone replacement for the ATG source:

1. A fixed algebraic logical decoder on arbitrary syndrome sectors need not correct a small physical error. The ordinary code decoder expects a qualified reference sector.
2. Destructive logical Bell measurement between an independent data block and this resource has an unknown dense syndrome offset unless their gauges are actually matched. A noisy record of that offset does not automatically give arbitrarily reliable final logical parities. Single-shot correction's residual-error promise is not a noiseless final classical answer.
3. While both halves remain jointly coupled, direct physical Bell-pair pumping is an equally informed simpler competitor. Joint product-check correction does not by itself create an advantage over this ordinary source.
4. Many resources with the same syndrome are an additional acquisition/preparation task, not free broadcasting of an unknown reference. A reusable matched-sector computational consumer would need actual operations and a full history guarantee.

This screen changes neither the accepted source nor the main ordinary protected-encoder route. The possible useful target is a task that consumes only relational logical information with an actually maintained common gauge, but no such complete new task/operation is established here. Do not label the ideal conditional identity as constant-depth fault-tolerant encoded state preparation or universal computation.

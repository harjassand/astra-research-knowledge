# Exact-rate bounded-remainder reduction: independent local review

30 October 2026. Review of the proposed next direction before code/integrated transfer. This is a local algebraic and forcing-interface receipt, not a new whole-network recurrence receipt.

## Verdict

**The proposed reduction is sound under the retained structural hypotheses.** Source-pool-bounded remainders can be included in uniformly bounded per-label residual clocks without any rank restriction. In the accepted conservative binary architecture, every genuinely cross-source-pool term that survives the actual boundary guards is an a+D->2a term and points toward a. Consequently baseline reachability supplies the needed forcing interface after enlarging the suppressed residual-clock rate; arbitrary non-a rank restrictions are unnecessary for these actual bounded remainders.

The structural proof must retain the premise that zero PHYSICAL mass in the protected pool forces a true-F output, or its equivalent certificate consequence. This is automatic in the accepted one-hold and catalytic phase-type branches. In the general bounded-face-potential setting it follows by evaluating the same hidden state at a=0, where no seed/clear kill is present. Binary unit changes and an active-output guard alone, without the retained face restrictions/exit certificate, should not be advertised as that premise.

## 1. Uniform per-label suppression

Use v_D=D-1 and v_h=x_h otherwise. For a source pool i, Y_i=sum_{h in i}v_h. After maximal affine baseline subtraction, write the nonnegative remainder as

    R=c+sum_h r_h v_h,   c,r_h>=0,
    B=c+sum_{h in i}r_h v_h,   U=sum_{h outside i}r_h v_h.

When Y_i>=1,

    B/Y_i <= c+max_{h in i} r_h.

Assign B uniformly among the actual abstract labels in pool i. Their total rate is exactly B and each label's rate is bounded by that fixed constant. Summing over the finitely many outgoing groups gives a fixed per-label row bound. This part may move uphill in any proposed rank and may leave a: it is simply added to an independent residual potential clock and suppressed on the forcing event. Destination choices/thinning can depend on the current state without compromising independence of the POTENTIAL clocks.

The grouped physical channel is selected in its actual available proportions and within-pool identities can be reassigned, as in the already checked baseline realization. Uniform assignment of abstract source labels therefore does not assert independent physical molecules or change the count generator.

No division is made at Y_i=0. Ordinary empty pools have no physical outgoing unit transition. An empty protected coordinate may allow an actual terminal event consuming its last physical D-pool particle; that output is checked/stopped before assigning a nonexistent label. Its existing terminal hazard/reward bound remains required.

## 2. Binary cross-term classification

Consider one positive-D residual reaction with unit pooled increment -e_i+e_j. A source2D has divided propensity k(D-1)=k v_D and is supported in its source protected pool. It cannot supply a cross-pool coefficient.

Every other binary source containing D is D+h and has divided propensity k x_h. If h belongs to the negative/source pool i, this term is source-pool-bounded. Suppose h lies outside i. Since some source particle must belong to the negative pool and the only other source particle is D, necessarily i is the protected D pool.

Test the enabled state with D=1,h=1 and every other residual count zero. The physical protected pool has exactly one particle. The unit negative change removes it, so the actual output has D=0 and zero physical protected-pool mass. Under the retained face premise, this is true F. The raw guard must therefore give a_out>=2 at THIS actual enabled state.

If h is not a, initial a=0. A is a singleton pool, so a unit pooled transfer can produce at most one a; the output guard fails. If h=a, initial a=1. A non-a destination preserves its pool count at one, again failing the guard. The only surviving case has destination a, whose count rises to two. Since the product is binary and a is singleton, the product is exactly2a. Thus the reaction is a+D->2a.

The test classifies reaction channels, not every later output of the a-born channel. With additional unprotected pool particles, that same a-born channel may enter a mixed face or true F; all such actual outputs still retain their existing trace/terminal checks.

Grouping and subtracting a baseline supported only on i cannot manufacture a new outside-pool coefficient. Hence the same classification applies to the cross part U of every affine remainder. In fact the shifted constant is zero for these basic binary divided sources and their protected baseline subtraction, but the more general bounded-B argument safely allows any certified c>=0.

## 3. Forcing consequence and exact limit of the conclusion

If every baseline type reaches a, choose shortest-distance ranks and a positive strict-lower baseline edge at each non-a type. Split off a common progress clock exactly as in the accepted rank lemma. The residual potential clock now contains BOTH the remaining fixed baseline rates and the uniformly bounded source-pool remainder rates.

The only unbounded cross part points directly to a and cannot undo progress. Therefore at least L progress rings and no enlarged residual rings guarantees arrival at a, uniformly over all actual state histories, with probability at least a fixed c t^L. Initial-a retention and last-unit forcing likewise hold. The enlarged residual clock also bounds downward reference-cohort crossing intensity. All constants depend on the fixed raw rate coefficients, not population.

This is an exact-rate statement. A support-only adversary allowed to scale these formerly bounded non-a terms without a common cap could still defeat forcing; the accepted rank converse remains correct for that DIFFERENT control class. There is no contradiction. The reduction does not establish necessity of baseline reachability or optimality of its exponent for a fixed network; other rate information may yield further certificates.

## 4. Independent finite structural check

`check_binary_cross_pool.py` enumerates all15 partitions of five residual species with a singleton a, all binary D-containing sources and binary products, retaining600 unit pooled channels. It finds192 channels whose divided coefficient lies outside the negative/source pool. Testing the extremal boundary state's active true-F output leaves15 survivors, one per partition, all exactly a+D->2a. This checks the classification implementation idea; the proof above, rather than this finite enumeration, covers arbitrary species count.

## Required before any global upgrade

A separate implementation must preserve the full actual ingress/terminal guards, zero-physical-protected-pool condition, face-potential and pool-neutrality checks, seed law, activity and weak reversibility. It must output the bounded per-label clock constants and restrict resets to positive-D starts. The completed carried/phase transfer must then be checked against this modified forcing interface. This receipt approves the local reduction and explains why old rank rejection need not survive it; it does not silently approve code or a broader whole-network theorem that has not yet been presented.

## Steane concatenation as punctured Type-II CSS code
Let S_r be the X=Z stabilizer binary row space of r-fold concatenated Steane, n_r=7^r. A recursive generating set consists of the S_(r-1) generators in each of seven disjoint blocks, plus the three outer Steane stabilizer rows, replacing each outer 1 by the inner all-ones logical representative.

The inner generators are doubly even and selforthogonal inductively. Each new generator has weight 4 n_(r-1), divisible by four. It is orthogonal to every inner generator because the latter has even weight; two outer rows overlap on an even number of complete blocks. Selforthogonality plus doubly-even generators implies all their linear combinations are doubly even. The three outer rows are independent modulo the inner spaces because inner all-ones is a nontrivial logical representative. Therefore

    dim S_r=7 dim S_(r-1)+3=(7^r-1)/2.

Set C_r=S_r+span{1^n}. Then S_r=C_r^perp. Extend to D_r=span{(S_r,0),(1^n,1)}. This is selforthogonal of half the extended length, hence selfdual. For odd r, n+1=0 mod8, so the added generator is also doubly even. D_r is Type II, and its puncture is C_r. Thus odd r supplies exactly the required algebraic form.

The concatenated quantum distance is 3^r: a nontrivial outer logical requires at least three nontrivial inner logical blocks, each with weight at least 3^(r-1), and a product of minimum-weight representatives attains this bound. Hence r=5 has length16807, distance243, and corrects121 arbitrary Pauli errors.

IMPORTANT: for r>=2 the CLASSICAL minimum distance of C_r is only4, since S_r contains an inner weight4 stabilizer. It must not be called a classical distance243 code. Nevertheless a minimum-weight syndrome representative corrects every quantum error of weight<=121: its difference with the true error has zero syndrome and weight<=242<243, hence is a stabilizer. This is the necessary degeneracy-aware correctness argument for using the syndrome machinery. The correction/replacement test can use this quantum radius, because every syndrome generated by such an error has a representative of weight<=121. Arbitrary syndromes can be mapped to a code state by correction or whole-block replacement. This argument does not itself audit every circuit fault-spread constant.

Primary check: Aharonov–Ben-Or, https://arxiv.org/html/quant-ph/9906129, sections4.3,4.6,4.8 and Theorem4. These supply the punctured Type-II restriction, minimum-weight syndrome machinery, arbitrary-word correction modification, and stated procedure spread4. Section4.9 is a classical readout procedure and is NOT a coherent quantum decoder. Definition16 concerns combined correction-plus-gate spread. Composition of individual spread4 bounds gives conservative16, provided the totalizing correction is included in the imported procedure contract. The radius121 leaves room for k=1 under that conservative bound. Numerical threshold/gadget size is not inferred.

## Sufficient common quantum receiving argument
At level ell>1, first perform totalizing correction on every child level ell-1 block. Count these as actual padded child identity rectangles, or separately establish an equally strong totalization statement. All accepted-good children preserve their logical state and produce only child-sparse syndrome garbage. Arbitrarily damaged exceptional children are brought into some child code module with child-sparse residuals; their logical contents and garbage may be arbitrary.

Use the SAME child recovery/decoder isometry on the entire admitted sparse operator family. The leading correction therefore reduces the upper-level input to the intended base-code state with arbitrary operators on at most the upper sparse budget of child symbols, plus arbitrary retained garbage/bath. This is not a support-by-support choice of decoder. The fixed finite coherent base recovery corrects that entire family by cross-term Knill–Laflamme, and the inverse Clifford encoder then maps its code space to one retained symbol plus garbage. Execute that fixed circuit fault-tolerantly at child level, including preparation, correction, routing, and idle locations. If every constituent child rectangle is good, the retained child is in the correct lower-level sparse module.

At ell=1 the same finite base recovery/inverse-encoder circuit is executed physically. The entire stage is declared good only if all its physical locations are fault-free. Thus a fully good top-down history ends in the actual intended physical output qubit, not an analysis-decoded output.

Kraus completion of each local contraction and rank-one marginal purity, as in the accepted scheduled-FT receipt, promote deterministic physical-path correctness to the same quantum intertwiner for unrestricted bath-valued operator histories and their cross terms. Every stage must use the same completed coherent decoder on the union of supports. Merely showing classical basis output correctness would not suffice.

## Counting and scope
Stage rectangles at different levels occupy disjoint physical time intervals. Selecting constituent rectangles from these stages therefore gives a prefix-free set in the recursive partition, not an ancestor/descendant overlap. Recursive sieving on their disjoint child sets yields the mixed-level inclusive product bound. Exact union sieving then bounds decoder bad-map norm by product_j(1+x_j)^B-1, where B counts ALL constant-size stage constituents. Since x_j falls doubly exponentially, sum_j x_j=O(x_0), uniformly in the number of levels. No marginal-probability union is used.

This gives a physical-output error contribution O(x_0), not an arbitrarily accurate physical output at fixed noise as levels increase. The last physical stage sets the floor. Complete logical-channel error uses the good-part trace-defect argument and its factor two; a bad-map norm alone is not already that channel distance. Scheduled resources, actual finite reset errors, noise during idles and routing, encoded ingress, and final observation time must all remain explicit.

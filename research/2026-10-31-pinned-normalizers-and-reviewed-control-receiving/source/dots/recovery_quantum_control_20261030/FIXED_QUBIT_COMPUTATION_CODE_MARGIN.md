# Optional explicit qubit code with large fixed quantum residue margin
30 October2026. Algebraic realization; read its degeneracy qualification. The main top-down decoder may instead receive the already accepted computation-code family.

Start from the Steane [[7,1,3]] CSS code with identical X/Z stabilizer rowspace generated by 1111000,1100110,1010101. Concatenate this code an odd fixed number r times, but regard the resulting [[7^r,1,3^r]] code as ONE base code when invoking the fixed-size computation-code gadgets.

Let n=7^r and C2 be its X=Z stabilizer space. Its generators are inherited inner stabilizers (weights divisible by4) and encoded upper stabilizers, each involving four equal odd-sized logical-X representatives. They are pairwise orthogonal, so all linear combinations also have weight divisible by4. Standard concatenation gives dim(C2)=(n-1)/2 and quantum distance3^r. Since all C2 vectors are even, allones lies in C2-perp and, having odd weight, outside C2. Therefore

 C1=C2-perp=C2+span{allones}.

Extend C2 by a zero last coordinate, and adjoin (allones,1). For odd r, n+1 is divisible by8. The extended code is self-orthogonal, has half the ambient dimension, and every word has weight divisible by4. It is therefore doubly-even selfdual, and its puncture is C1. This is the CSS family condition in ABO §4.3 / Theorem4.

Taking r=5 gives block size16807 and quantum distance243, so it corrects121 arbitrary qubit errors. These are huge fixed constants, not a proposed practical code.

## Degeneracy must NOT be ignored
For r>=2 the classical C1 contains weight4 inner stabilizers. Its classical minimum distance is NOT243. The relevant correctability is the minimum weight in C1 minus C2, i.e. quantum logical distance.

The syndrome correction still works with a degeneracy-aware interpretation. Given an actual bit error e of weight<=121, choose a minimum-weight e' with the same classical syndrome. Then |e'|<=|e| and e+e' lies in C1 with weight<=242. It cannot be a nontrivial logical coset, so it belongs to C2 and is a harmless X stabilizer. The phase sector is identical. This proves the required quantum correction, not recovery of a unique classical word. A logical-bit decoding lookup must likewise output the C1/C2 coset, not a fictitiously unique nearest classical codeword.

ABO Theorem4 gives fixed-size measurement-free gadgets with per-procedure spread<=4 for this puncturedTypeII CSS family. A conservative composition of a correction and gate bounds spread by16, provided both procedures' input-location spread is included (pad explicit input idles if necessary). Then k=1 has k*ell<=16<121/2. All preparation, syndrome classical lookup and gate circuits are still finite, but their constants can be enormous.

This margin is optional: the top-down decoder declares ANY bad child rectangle a failed output stage, and charges its decreasing x_j. Its deterministic receiving nevertheless requires the actual arbitrary-input sparse correction/common-logical-factor contract. Neither a large distance nor this algebra alone replaces that contract.

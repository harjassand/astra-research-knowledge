# Pay only uphill token exchanges

30 October 2026. Local extension of the two token-exchange notes; no global claim.

Let r be a certified baseline progress rank on ordinary label types, with target a the unique rank-zero type. In a token excursion, an ordinary-i restoration reassigns that label to the old token type p. Split its exact per-particle restoring intensity into

    h_i^up(p,y)=h_i(p,y) 1{r(p)>r(i)},
    h_i^down(p,y)=h_i(p,y) 1{r(p)<=r(i)}.

Only the uphill reward needs a stopped potential: -Q_y psi_i>=h_i^up and summed entry lambda psi_i<=b_i. The same terminal compensator proves that the entire uphill part of the traced exchange kernel has source-i intensity <=b_i y_i. It belongs in the bounded residual clock. The remainder, possibly arbitrarily fast, is rank-nonincreasing and belongs in the permitted adapted excess. At target a every genuine departure is uphill and therefore bounded; self exchanges are irrelevant.

On the independent event of at least L progress rings and zero residual rings per label, no uphill exchange occurs and every other exchange cannot undo progress. Hence the same deterministic-time forcing event succeeds, without any small-return or small-exchange assumption. This applies equally when terminal phase metadata controls the destination, provided the actual terminal output has been used in the rank comparison. If a terminal reaction also changes the old token, use its actual post-jump type in this indicator instead of the pre-jump phase.

For the phase-scaled rule Q_y=sQ0-diag(k), it is enough that h_i^up<=hbar_i^up independent of y; unbounded downhill restoring intensities may remain in k and only improve the potential inequality. Solve -Q0 t_i=hbar_i^up. This combines the accepted abstract rank asset with ordinary killed-chain reward acquisition; it does not assert that every raw physical module supplies the needed factorization or frozen-ordinary structure.

The all-exchange bound in the preceding notes is the special case where every nontrivial exchange is charged as uphill. This refinement identifies the exact dangerous terminal reward rather than controlling harmless restoration rates unnecessarily.

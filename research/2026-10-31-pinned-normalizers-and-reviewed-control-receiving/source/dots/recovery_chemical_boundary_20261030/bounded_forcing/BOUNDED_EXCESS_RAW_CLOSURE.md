# Bounded per-label uniformization closes the current raw excess interface

30 October 2026. New candidate for whole integration; earlier accepted rank and face sources are unchanged. This uses actual affine rate information rather than pretending every nonzero remainder is an arbitrarily fast adversarial channel.

## 1. Separate bounded noise from genuinely unbounded excess

After the protected substitution D=1+u_D, write the nonnegative remainder of a grouped unit transfer i->j as

    R_ij=c_ij+sum_h r_ij,h v_h,     c_ij,r_ij,h>=0,
    v_D=u_D, v_h=x_h otherwise,    Y_i=sum_{h in pool i}v_h.

The maximal baseline q_ij Y_i was already subtracted and checked exactly. Split

    B_ij=c_ij+sum_{h in pool i}r_ij,h v_h,
    U_ij=sum_{h outside pool i}r_ij,h v_h.

Whenever Y_i>=1,

    B_ij/Y_i <= b_ij:=c_ij+max_{h in pool i}r_ij,h.

Assign B transfers uniformly among current source-pool labels. Their per-label rate is bounded by b_ij, even though the realized rate and destination choices depend on the full actual state. Add these channels to the residual potential clock, with

    Qmax=max_i sum_j(q_ij+b_ij).

Only U needs a nonincreasing rank. On no residual rings, all bounded transfers are absent, regardless of direction; the root progress-clock event then succeeds exactly as before. Initial-a retention suppresses bounded a departures as well. This is ordinary Poisson thinning/uniformization, not a new independence assumption about actual histories.

At an empty ordinary pool, the raw outgoing rate is zero. At an empty protected coordinate, any enabled outgoing event must be sent through the actual true-F terminal rule before label assignment. The inequality B/Y is NEVER used at Y=0. Existing boundary compensators pay those stopping events separately.

The abstract robust rank/converse/sharp-exponent theorems extend to this contract by adding bounded noise to Qmax for the lower bound and turning it off in the upper-bound controls. That observation does not identify the actual raw rate law with the worst adversary.

## 2. Under the RETAINED raw guards, unbounded non-a excess cannot occur

Use all of the following premises: binary residual source/product counts, unit pooled transfers, a as a singleton pool, and zero PHYSICAL mass in the D-containing pool implies true F. The last premise is supplied by pooled-neutral one-hold restoration, or by the acquired phase-type face; in the more general potential principle it follows from bounded exit at a=0/1. It must NOT be omitted if unrelated dead internal face moves are allowed.

Every D-containing binary source is either2D or D+h.

* A 2D source contributes k(D-1) in D-clock. For a unit pooled transfer its negative/source pool is the D pool, so this is a source-pool variable and is bounded per label.
* For D+h, the divided rate is k x_h. If h lies in the negative/source pool, it is again bounded per label.
* Otherwise the negative/source pool must be the D pool. Its net loss is the D particle; the h pool's source particle is retained or increased in the binary product. Set D=1, h=1, all other hidden counts0, and a=0 unless h=a, in which case a=1. The actual output has zero physical mass in the D pool and therefore lies in true F.

If h!=a, the binary product with a retained h-pool particle has a_out<=1. If h=a but the target pool j!=a, the output has exactly a_out=1. Both violate the independently checked true-F active-output requirement a_out>=2. The only possibility left is h=a,j=a, with product2a: the required a+D->2a reaction (or parallel copies).

Thus every genuinely cross-pool remainder in an ACCEPTED raw unit-transfer module points directly to a. Non-a remainders are source-pool-bounded noise. After D=1 substitution no extra constant arises from binary2D rates, but the implementation conservatively supports a nonnegative constant in the bounded part.

This is a structural consequence of the current architecture, not an extra claim about arbitrary networks. It means the general non-a unbounded-rank theorem is broader as an ABSTRACT result than the currently accepted raw class actually needs. We do not manufacture a chemical advantage for that unnecessary layer.

This is a bounded prior comparison, not a novelty search certificate. The
generic mechanisms below were found before any physical-success claim. All
external actions were read-only.

It models particle-image diameter and velocity-gradient broadening, with two experimental demonstrations. This is much stronger than an ordinary comparator that must first track every particle. It already allows non-Gaussian PSF shapes in principle; the present operation removes a radial-profile nuisance for a particular integrated query, not all calibration costs. |

The Laurent pole-neighborhood condition remains necessary for the particular analytic query here. |
| [Cerbino and Trappe2008, DDM](https://doi.org/10.1103/PhysRevLett.100.188102); [primary manuscript](https://arxiv.org/pdf/1507.01344), equations1--3 | Uses differences of microscopy images, spatial variance/Fourier analysis and ensemble averaging to obtain dynamics without resolving particles. Static-pattern rejection by differencing is established. The receiver here is an explicit harmonic mechanical-query specialization and a covariance control identity; it is not a new tracking-free principle. |

| [Sasikumar and Varma2019](https://arxiv.org/pdf/1904.04594), theory section | Uses local pixel-intensity variance to infer motility without correlations or Fourier transforms, beginning with a sparse one-pixel particle model. | [Berghout et al2021, JFM919A45](https://doi.org/10.1017/jfm.2021.413), sections2 and8 | Actual Taylor--Couette PIV plus a separate middle-cylinder torque sensor; the PIV-derived/model torque relation agrees with torque measurements at about5%. The sensor avoids endplate contamination by measuring only the middle section. Thus generic nonintrusive/indirect torque characterization is already a demonstrated strong route; the proposed exact full-volume query must pay its different support and sampling contract. |

The equally informed query-specific ordinary method may itself combine
Campbell's Poisson covariance identity, radial harmonic moments and a weak
mechanical balance, and implement the same eight moment sums. We have not
established separation from that competitor. Comparing against an explicit
P-by-P covariance matrix, a full dense displacement reconstruction, or a
deliberately uncalibrated PIV pipeline would be unfair.

## Native public input actually acquired

[PIV-UQ experimental database](http://piv.de/uncertainty/) and its
[six-page primary database description](http://piv.de/uncertainty/Background/Database%20description.pdf)
describe simultaneous measurement/HDR systems in a rectangular jet. The MS
camera measures512-sized crops here, with nominal10-bit intensity captured
in16-bit TIFF files. The source states2D-2C acquisition and finite laser-sheet
thickness; it does not certify the radial PSF tail, full particle retention,
independent records, or annular mechanical data needed by the new receiver.

The author data page supplies
[all H015 images](http://piv.de/uncertainty/Data/H015/MS_Images_H015.zip), nominal
particle-image diameter2.5pixels. The ZIP contains500 TIFF frames and was
fully acquired and consumed. The HDR reference is a higher-accuracy PIV
measurement, not mathematical ground truth. The H015 data-page links do not
supply an acquired whole-domain mechanical/torque reference for this query.

The Figshare/4TU large-file route failed before the author-host ZIP was found.
A Cambridge fallback supplied a README and a ZIP directory tail, but its
images concern plate-position tracking, so that source was not promoted to
the flow/torque input. No Cambridge TIFF record was consumed. The attempted
Neal2015 PDF acquisition is partial and was NOT used as a complete primary
text; the full database description supplies the actual native qualification.

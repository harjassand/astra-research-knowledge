LEARNING THE PART OF A SCIENTIFIC LAW THAT A DESIGN OPERATION USES
Main construction: contrasts within resource classes, 31 October 2026 UTC

SCIENTIFIC DESTINATION

Acquire a reusable global inverse-design service across exponentially many
resource contexts without learning their arbitrary common baseline energy.
The learned object is an executable reduction modulo task-invariant functions.
The unknown law need not be quadratic: an arbitrary, even computationally
complicated function of conserved resources is permitted. Only its variation
within resource classes has a quadratic representation plus a quantified dense
quadratic remainder. Neither the useful interaction forest nor an optimizer
is provided. Both are constructed.

This is the acquired known-resource construction beyond the conventional
near-forest route in PROOF.txt. The later selected latent-variable construction
is in LATENT_OPERATION_THEOREM.txt; it uses a different observation contract.
Differencing nuisance effects, compressed sensing, maximum-weight
forests, and tree optimization remain established components. The claim here
is an explicit acquisition-and-execution construction and its guarantees, not
historical priority for any component or an unproved speedup over every strong
task-aware conventional method. The exact stochastic compiler is not needed.

1. A CONCRETE RESOURCE-CONSTRAINED SCIENTIFIC TASK

There are k modules, each containing two binary occupation controls x_a1,x_a2
in {-1,+1}. A later scientific design request specifies the number B_a of +1
occupations in each module, B_a in {0,1,2}, and arbitrary known unary costs h.
These can represent fixed local inventories with a remaining placement choice.
The operation chooses the placements jointly, accounting for interactions.
If B_a=1, two placements are possible; B_a=0 or 2 fixes that module completely.

The module identities are part of the resource constraint being requested,
not a supplied interaction graph, hidden coordinate system, or downstream
solver. Their between-module interaction graph is unknown and may be complete.
Write n=2k for the number of physical binary controls.

The source permits chosen full configurations and gives an energy report with
conditional mean

 E(x)=g(B(x)) + Q(x),                                           (1)

where g is an arbitrary unknown function on {0,1,2}^k and Q is an unknown
degree-at-most-two polynomial in the original binary controls. No regularity,
smallness, sparsity, representation, or computational ease is assumed for g.
In particular its values may differ enormously among the 3^k resource contexts.
Fresh observation errors are conditionally sigma-subgaussian in absolute energy
units. Reporting precision, full configuration preparation and every source
shot are charged. A two-reading difference uses two source calls. This is an
experimental access contract, not a claim that an uncontrolled physical system
can be freely reset or prepared this way.

More precisely, each preparation has its actual cost C_prepare(x), including
any reset, relaxation, verification and rejected attempts, and total physical
cost includes their sum. The O(k) figure used for the executable is the number
of directly settable binary-control writes, not a universal bound on physical
preparation time. Resource preservation is exact in the interface: known
count-conserving swaps or correctly observed final counts can implement it.
Generic unobserved actuation errors are not covered. If a supposedly matched
pair changes B with probability eta, an arbitrary nuisance jump H can cause
bias eta H; no g-independent bound can survive this as H grows. Detecting and
discarding mismatched preparations is allowed only with the detection and all
retries charged and a valid distributional/noise analysis for accepted pairs.

The requested result for every later (B,h) is a feasible xhat such that

 E(xhat)+h.xhat <= min_{x:B(x)=B}[E(x)+h.x] + epsilon*n.           (2)

Only placement design is promised. The unknown absolute optimum value g(B)
and comparisons between different resource vectors are not returned. Those
operations actually depend on g and require different evidence.

The controlled-input interface is literal for a stochastic computational
experiment: its full binary input can be written explicitly, and its complete
simulation cost is paid per call. The synthetic executable is such a source.
Extending this to a laboratory needs an instrument meeting the preparation
and noise contract; the theorem does not supply arbitrary physical access.

2. THE OPERATION QUOTIENT AND ITS EXPLICIT FEATURES

Define, for each module,

 q_a=(x_a1-x_a2)/sqrt(2),  s_a=(x_a1+x_a2)/sqrt(2).

The resource vector determines every s_a. Under a uniform independent binary
configuration, q_a and s_a each have mean zero and variance one, and are
orthogonal. The non-invariant degree-two features are exactly

 q_a;  q_a q_b, q_a s_b, s_a q_b for a<b.                        (3)

Their number is D=k+3k(k-1)/2. They are orthonormal under uniform configurations
and bounded by 2 in absolute value. Every other degree-two term is a function
of B: constants, s_a, within-module x_a1*x_a2, and s_a*s_b.
Thus (1) has a unique non-invariant coefficient vector theta in (3), after
absorbing all invariant polynomial terms into the arbitrary g.

For a fixed B, g is an additive constant. It has no effect on any minimizer
in (2), even after arbitrary h is added. The physically useful representation
is therefore an equivalence class E~E' if E-E' depends only on B. This quotient
is dictated by the operation, rather than by a wish to fit the whole source.

3. EXPERIMENTS THAT MEASURE THE QUOTIENT DIRECTLY

Choose X uniformly from {-1,+1}^{2k}. Independently swap the two controls in each
module with probability 1/2, producing Y. This is a simple chosen-configuration
preparation, not an inaccessible conditional-sampling oracle. Given B(X), X and
Y are independent uniform members of that resource class. Inactive modules
have only one placement; active modules get independent fair orientations.

Take two independent energy readings and subtract them. Their common unknown
g(B) cancels in the mean. With

 a=(phi(X)-phi(Y))/sqrt(2),  Z=(Ehat(X)-Ehat(Y))/sqrt(2),

we have E[Z|X,Y]=a.theta and conditional noise parameter sigma. Each feature
in (3) has conditional mean zero given B, so

 E[a a^T]=I_D.                                                  (4)

This identity is exact. No estimates of the 3^k nuisance values are involved.
The entries of a have absolute value at most 2sqrt(2). Known normalization
square roots can be avoided by the equivalent rational unnormalised features
and explicit diagonal Gram scaling; finite arithmetic is addressed below.

An alternative conventional procedure could first learn within-class response
differences and then fit them. That is precisely the new experimental question
which this construction makes explicit. An absolute-energy predictor is an
unnecessary and potentially exponentially larger task.

4. ACQUIRING THE EXECUTABLE INTERACTION STRUCTURE

A module forest model retains all q_a terms and the three features attached
to each edge of a forest on k modules. It has at most s=4k-3 coefficients.
Projection of a coefficient vector z onto this model class is exact and cheap:
assign each module pair weight

 w_ab=z_qq,ab^2+z_qs,ab^2+z_sq,ab^2,

run Kruskal to choose a maximum-weight forest, and keep those edge triples and
all unary coefficients. This is an explicit polynomial-time projection.

Take M independent paired experiments as in section 3. Let A have rows
a_l/sqrt(M), and y=Z/sqrt(M). Starting with theta_0=0, run the existing model-IHT
iteration

 theta_{t+1}=P_forest(theta_t+A^T(y-A theta_t)).                  (5)

Straightforward arithmetic per iteration is O(MD+k^2 log k). The graph is
discovered by (5); a true forest, its edges, and the nuisance function are never
given to the learner. A bounded iteration count follows from an ordinary
coefficient-norm/range upper bound B0. Final least-squares refitting on the
selected support is optional and is an actual linear solve.
Alternatively, section 7 applied to the zero candidate acquires a confidence
upper bound on ||theta||_2, at its stated validation cost, which can supply B0.

5. AN ELEMENTARY MODEL-RIP ACQUISITION BOUND

For clarity, this sharper analysis avoids asking an RIP-checking oracle to
certify the randomly chosen experimental matrix. Let a coefficient vector be
supported on the union of q module forests, together with all unary terms.
Express each edge triple of (3) in the four original-spin products using the
orthogonal 2-by-2 Hadamard coordinate transformation. The squared coefficient
norm is preserved. A module forest, expanded to its four spin pairs, splits
into two ordinary spin forests: same-index edges and crossed-index edges.
Each is a double cover of a tree and therefore has no cycle. A union of q
module forests consequently splits into at most 2q ordinary forests.

On an ordinary forest under independent fair spins, its edge products are
independent Rademacher variables: select one free root spin per component and
one independent edge product per edge, then reconstruct all vertex spins.
Therefore each forest edge sum is subgaussian with variance proxy equal to
its squared coefficient norm. The unary sum is likewise subgaussian. Holder's
inequality for the 2q+1 groups proves that f_theta(X)=theta.phi(X) has proxy
(2q+1)||theta||_2^2. Cauchy-Schwarz applied to the possibly dependent X,Y gives

 E exp[t a.theta] <= exp[(2(2q+1)||theta||_2^2)t^2/2].           (6)

Together with exact isotropy (4), the usual fixed-vector squared-subgaussian
concentration and a 1/4-net give uniform covariance approximation on a fixed
union of forest supports. There are at most (2k)^{qk} such supports: every
forest is a subgraph of a spanning tree, and Cayley's bound plus edge subsets
suffices. Each support has dimension at most (1+3q)k. A union bound over these
supports and their nets proves, for a universal constant C,

 M >= C(2q+1)^2 delta_RIP^{-2}
                   [qk log(2k)+log(1/zeta)]                    (7)

suffices for delta_RIP approximation, with probability at least 1-zeta, on
all vectors in the union of q forest models. The standard net implication
uses ||G||op <=2 max_{v in net}|v^T G v| on each support. This is an ordinary
probabilistic proof for the actual allowed experiments. Set q=3 and
delta_RIP=1/8 for the IHT argument.

The older bounded-orthonormal-system theorem also applies immediately to (4)
and yields a slightly larger logarithmic sufficient budget. Both routes are
conventional random-design machinery; their use does not supply the forest.

5A. THE STRONGER OPERATION MODEL: ONLY PLACEMENT INTERACTIONS NEED A FOREST

The grouped forest above is unnecessarily restrictive. At fixed B, EVERY
q_a*s_b coefficient is unary in placement, even when its cross-context graph
is dense or cyclic. The stronger class retains all k unaries, a forest only
on qq coefficients, and t arbitrary directed cross coefficients. It has
s0=2k-1+t parameters and is projected onto exactly by two independent steps:
Kruskal on |qq coefficients| and top-t selection on |cross coefficients|.
Both maximize the retained squared norm (the forest greedy ordering is the
same for absolute and squared weights). This remains a real polynomial
projection; t is a proposed budget, not a supplied true support.

For acquisition, use the conventional bounded orthonormal system theorem on
the actual paired features psi=(phi(X)-phi(Y))/sqrt(2). They are orthonormal
on the finite (X,swap-mask) probability space and bounded by 2sqrt(2).
Brugiapaglia--Dirksen--Jung--Rauhut, arXiv:2005.06994, Theorem 2.3, gives RIP
of order sR=min(D,3s0) with probability at least 1-zeta when

 M >= C*8*delta_RIP^(-2)*sR *
       [log^2(8sR delta_RIP^(-2))*log(eD)+log(2/zeta)].

Apply the same exact-projection IHT recurrence, fixed-law dense-tail Markov
bound, and fresh certificate below. The sharper forest-union subgaussian
argument above is NOT asserted for arbitrary cross supports. Arithmetic remains
O(MD+k^2 log k) per iteration; retention and each later execution are O(k+t).
For fully dense cross terms t=k(k-1), quadratic retention is honestly charged.

To see the real scope increase, take disjoint directed triangles with terms
q1*s2+q2*s3+q3*s1 and no qq edges. Every future operation is purely unary, yet
a grouped forest must discard an order-one term in every triangle. The stronger
class retains them all. The executed 24-module comparison gives both methods
the same full contrast OLS data; the grouped model fails a requested design,
whereas the conditional model passes a uniform certificate and executes it.

The finite consumer quantizes orientation coefficients into rationals before
fresh validation. It adds cross terms to the actual future unary costs, then
uses exact integer tree DP. This is implemented in
../consequence_mechanism/conditional_forest.py and the undersampled acquisition
pipeline in conditional_design.py. The full OLS confidence ball remains a
strong conventional alternative when that acquisition has already been paid.

6. STABILITY TO AN UNKNOWN DENSE NON-INVARIANT REMAINDER

Assume, only for a sufficient completion guarantee, that some forest vector
theta_F obeys ||theta-theta_F||_2<=rho. There is no exact sparsity, edge gap,
sign, treewidth, or graph-recovery promise for the true theta. Its nonzero
interaction graph may be complete. Let r=theta-theta_F.
The physical law and this approximating vector are fixed before the random
acquisition design is drawn. Completion is not uniform over arbitrary dense
laws chosen adversarially after observing that underdetermined design.

Average L fresh energy readings on each side of a training pair. The paired
normalized noise then has parameter sigma/sqrt(L). Since E||Ar||_2^2=rho^2,
Markov gives ||Ar||_2<=sqrt(8)rho with probability at least 7/8. Likewise the
averaged observation error vector e has ||e||_2<=sqrt(8)sigma/sqrt(L) with
probability at least 7/8. With the RIP event of probability at least 7/8,
all three hold with probability at least 5/8; independence among these events
is not required. Write w=Ar+e.

Exact Euclidean model projection, restricted to the union of the new support
and theta_F's support, gives the usual model-IHT estimate

 ||theta_{t+1}-theta_F||_2
 <=2 delta_RIP ||theta_t-theta_F||_2
                  +2sqrt(1+delta_RIP)||w||_2.                   (8)

Here the error term uses the upper singular-value bound on the restricted
measurement matrix; no coordinatewise estimate of a dense remainder is made.
At delta_RIP=1/8, iteration yields

 ||theta_t-theta||_2
 <=4^{-t}B0 + rho + (8/3)sqrt(9/8)||w||_2
 <=4^{-t}B0 + 9rho + 8sigma/sqrt(L).                            (9)

The last constants are rounded upward (the exact products are eight for
each contribution before adding the leading rho). Thus rho=O(epsilon),
L=O(max(1,sigma^2/epsilon^2)), and O(log(B0/epsilon)) iterations supply a
candidate with O(epsilon) coefficient error with constant probability.
Independent trials, each separately validated, amplify completion probability.
They do not weaken soundness. A cap of O(log(1/delta)) trials suffices under
the stated small-rho condition; expected trials to a successful validation are
constant when the acceptance threshold has constant slack.

The displayed constants in (9) apply to raw IHT. If an actual least-squares
refit on its support does not increase measurement residual, writing e0 for
the raw error relative to theta_F and e1 for the refitted error gives

 ||e1|| <= sqrt((1+delta_RIP)/(1-delta_RIP)) ||e0||
                         +2||w||/sqrt(1-delta_RIP).

Indeed lower RIP bounds ||A e1||, while residual improvement and the triangle
inequality bound it by ||A e0||+2||w||. This preserves the order of the
completion bound with larger constants. Regardless of any RIP or convergence
event, the independent certificate below validates the actual returned model.

The sufficient source count, up to universal constants, logarithms and the
chosen success margin, is

 O(k log k * max(1,sigma^2/epsilon^2))                            (10)

per constant-success training attempt, with two physical readings per pair
and all L repetitions included. Arithmetic is O(M k^2 log(B0/epsilon)) plus
projection work; commanded binary writes are O(k M L). There is no 3^k factor. Numerical
constants are not represented as physically optimal or as executed when only
the smaller empirical budget was tested.

In (10) the preparation count is at most 2ML configurations; O(kML) is only
commanded binary-write work in the directly settable implementation. Actual
preparation time is the sum of C_prepare, as specified in section 1. Shot count
is independent of g's amplitude, but report bit lengths and physical energy
measurement costs need not be. No amplitude-independent total bit-cost claim
is made.

7. A POSTERIORI CERTIFICATE FOR THE ACTUAL OPERATION

For a data-dependent forest candidate G, write R_perp for the non-invariant
part of E-G. It is a degree-two polynomial in the original spins, regardless
of the arbitrary g. Its variance under uniform spins is v=||r_perp||_2^2.
Fresh paired within-module swaps give D_R=(E-G)(X)-(E-G)(Y). Conditional iid
on B and E[R_perp|B]=0 imply

 E D_R^2=2v,
 E D_R^4 <=8 E R_perp^4 <=120v^2.                              (11)

The last inequality uses the degree-two fourth-moment bound
E R_perp^4<=15v^2. Thus Var(D_R^2)<=116v^2. A block of 464 pairs has its mean
squared difference in [v,3v] with probability at least 3/4 by Chebyshev.
A median of O(log(1/delta)) independent block root-mean-squares gives S such
that, when each paired report has absolute error at most nu,

 sqrt(v)<=S+nu<=sqrt(3v)+2nu                                  (12)

with the advertised confidence. Independent noisy readings may be averaged to
earn nu by an explicit subgaussian tail bound and a union bound over all shots.
The validator implementation charges every repetition and control preparation.
Data-dependent candidate search uses fresh holdouts and a summable delta_j.

For completeness the fourth-moment constant has a short proof. Replacing one
Rademacher coordinate by a standard Gaussian cannot decrease the fourth moment
of a multilinear polynomial: condition on the others and write A+xB, whose
fourth moment is A^4+6A^2B^2+B^4 in the Rademacher case, with the last coefficient
3 in the Gaussian case. After replacing all coordinates, write the centered
Gaussian polynomial as b.G+G^T H G, tr(H)=0, with variance
v=||b||^2+2 tr(H^2). Its fourth moment is

 3v^2+48 tr(H^4)+48 b^T H^2 b <=15v^2.

To check the last inequality put u=tr(H^2), w=||b||^2. The extra terms are at
most 48u^2+48uw <=12(w+2u)^2. This proves the asserted bound.

STRONGER FINITE-VARIANCE VALIDATION. The preceding pointwise-noise construction
is sufficient but can be needlessly expensive. For each fresh orbit pair make
TWO independent replicate residual contrasts U=D_R+eta1 and V=D_R+eta2, using
ell fresh readings for each of their four energy reports. Assume only that
each raw error has conditional mean zero and variance at most sigma^2, with
independent replicate and report errors. Set t=sigma^2/ell. Then

 E[UV]=2v,
 Var(UV)<=116v^2+8tv+4t^2 <=116(v+t)^2.                         (12a)

The variance formula follows by conditioning on the pair: each contrast noise
has variance at most 2t; the additional conditional variance of the product is
at most 4t D_R^2+4t^2. No fourth noise moment is needed. With 464 pairs per
block, Chebyshev puts each block mean in [v-t,3v+t] with probability at least
3/4. For an odd number J>=8 log(1/delta) of independent blocks, Hoeffding on
the bad-block indicators gives, for their median m,

 v <= m+t <=3v+2t.                                            (12b)

Therefore S_new=sqrt(max(0,m+t)) is an upper bound on the residual norm. This
uses 4*ell*464*J actual scalar shots and at most 2*464*J distinct requested
configurations. Choosing ell=max(1,ceil(8sigma^2/target^2)) controls completion
noise with no per-shot union bound. The certificate is sound even if IHT or
the fitted model was a poor proposal. It does not guarantee acceptance.

If every computed contrast differs from its ideal noisy contrast by at most
rho_num, replace each product by

 U_obs V_obs + rho_num(|U_obs|+|V_obs|)+rho_num^2.

This dominates the ideal product deterministically, so the median upper bound
remains sound. The upper bound on S_new^2 deteriorates by at most twice the
largest block average of this added correction. Precision can be increased to make it small;
its bit cost includes the absolute report range. The older pointwise validator
remains an alternative: at very low noise it can use fewer shots. When full
OLS was already acquired, a same-data coefficient confidence ball can be
cheaper still; all three routes are retained in executable comparisons.

For a resource vector with a active (B_a=1) modules, direct evaluation of (3)
gives

 ||phi(x)||_2^2=2a(2k-a),   whenever B(x)=B.                     (13)

Let C_res denote the certified norm radius, either S+nu from the pointwise
construction or S_new from the independent-replicate construction. Then the
residual's oscillation within this resource class is bounded by

 max_{B(x)=B} R_perp(x)-min_{B(y)=B}R_perp(y)
 <=2sqrt(2a(2k-a)) C_res <=2sqrt(2)k C_res.                     (14)

No unknown nuisance amplitude occurs. If a=0, the bound is zero as it should
be: there is only one feasible placement. An acquired S gives either a single
uniform epsilon*n service bound for every context or more informative bounds
for each future number of active modules. A failed test is an informative
failure of this proposed reduction, not proof that the true design is hard.

8. ACTUAL EXECUTION AFTER A NEW RESOURCE QUERY

Given B, s_a is fixed. For active modules set q_a=sqrt(2) z_a with z_a in
{-1,+1}; for inactive modules q_a=0. Every retained q_a s_b or s_a q_b term
becomes a known unary coefficient of an active z. A q_a q_b term becomes a
pairwise coefficient only when both modules are active. Hence the active graph
is a subgraph of the acquired module forest. Known arbitrary physical unary
fields also become unary z costs or constants. Two-state tree dynamic
programming returns the exact global optimum of G+h on that resource class
in O(k) arithmetic. It includes a backtrace producing the actual 2k controls.
No numerical optimization oracle, inaccessible conditional sampler, or search
over 2^a configurations is supplied.

If xG is this computed surrogate optimum and x* is the physical optimum,

 [E+h](xG)-[E+h](x*) <= R_perp(xG)-R_perp(x*) <= bound (14).      (15)

The one acquired event in (12) covers every resource vector and field, including
unlimited adaptive future choices. This is a simultaneous design-regret claim,
not a claim about the total variation of an infinite output transcript.

9. WHAT IS DIFFERENT, AND WHAT STRONG ORDINARY METHODS ALREADY DO

The absolute predictor E may have arbitrary complexity and exponential context
dimension; the useful quotient can have a small executable approximation.
Learning E uniformly would be an unnecessary stronger task. For example, an
arbitrary hidden g on 3^k contexts cannot be uniformly learned from observations
in only a vanishing fraction of those contexts: alter g at an unvisited context.
This elementary information separation is from absolute prediction, NOT from
the strongest task-aware algorithm allowed the same paired experiments.

A strong conventional route should adopt the paired contrasts, then use
structured sparse recovery and tree optimization. We do precisely that.
Uniform-regression bounds for quadratic absolute responses do not apply to an
arbitrary g, but conditional/fixed-effect modelling already motivates nuisance
elimination. The contribution to retain is the complete operation quotient:
actual contrasts, exact feature covariance, acquired structured solver, dense
remainder validation, and a single all-context operational guarantee. Claiming
that differencing itself, Kruskal, IHT or tree DP was invented here would be
wrong. Historical priority for the whole construction remains unestablished.

There is also a clean impossibility boundary: these contrast observations have
identical laws for every g with the same non-invariant source. They cannot
determine the best resource vector, absolute free energies, or cross-context
comparisons. That missing information is not a numerical defect to be repaired
by more within-context samples. New experimental questions are necessary.

10. PRECISION, FAILURE AND EXECUTION RECORD

The real experiment must support the specified preparations and a warranted
absolute error model. Large g is canceled mathematically, but two finite-bit
absolute readings must carry enough precision to recover their difference.
The reading bit length and any digitization floor are charged. If the device
only returns a noisy normalized energy, sigma must be scaled back to energy
units. Shared uncontrolled drift between the two readings is not automatically
canceled unless it is actually common and specified in the observation law.

The residual outside the arbitrary invariant g must remain quadratic. A hidden
high-order orientation spike can change one design while escaping all sampled
contrasts. That counterexample is preserved; empirical success cannot establish
the constitutive class. Dense quadratic perturbations, which generically destroy
exact graph sparsity, ARE covered by (11)-(15).

Floating NumPy demonstrations are not interval-verified hardware calibration.
Exact algebraic normalizations can be represented in Q(sqrt(2)); alternatively
unnormalised q,s in {-1,0,1} give a rational diagonal preconditioner. Rational
IHT has finite polynomial bit cost for finite rational inputs and an explicit
iteration cap. Tree DP uses exact rational comparisons if its coefficients and
query fields are rational. A deployed floating certificate must include actual
evaluation and rounding bounds in nu and the optimizer slack.

The companion executable module_quotient.py creates the noisy source separately
from the learner, acquires a forest from paired measurements, validates with
fresh experiments, and executes later resource/field queries. Synthetic truth
is used only by the independent evaluation code. Every reported source sample
and control setting is counted. See the generated numerical record for what
was actually run, including failed candidates and limitations.

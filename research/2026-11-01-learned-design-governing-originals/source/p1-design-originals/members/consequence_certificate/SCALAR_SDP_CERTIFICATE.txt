SCALAR EXPERIMENTS CAN ACQUIRE A CANDIDATE'S SPECTRAL OPTIMALITY CERTIFICATE
Version 1, 2026-10-31 UTC. Constructed independently within the current Astra turn.

Status and purpose
------------------
This is a complementary construction, not a claim of historical priority. SDP
dual optimality certificates, PSD property testing, noisy power iteration, and
finite-difference recovery of a quadratic action are established components.
The construction below pays for their interface when the only physical source
is a noisy scalar energy experiment on a BINARY configuration. It does not
assume a matrix-vector, gradient, eigenvalue, or optimization oracle.

It addresses a limitation of the uniform Frobenius residual certificate: a
large, dense, high-rank discrepancy can preserve the optimum. Learning or
uniformly suppressing that discrepancy is unnecessary if a cheap proposed
design admits a spectral lower certificate. The result is query-specific and
uses fresh source measurements. It is not a finite-calibration, source-free
uniform service for every later field.

0. The stronger consumer: preserve the operation, not the model
-------------------------------------------------------------
Let an actually constructed tractable model E_hat and its actually executed
optimizer return z, with a proved bound

  E_hat(z)+h^Tz <= min_{x in F} [E_hat(x)+h^Tx] + beta.

Define the EXPERIMENTAL RESIDUAL R=E-E_hat. Every residual source call is an
actual noisy E(x) measurement minus a deterministic evaluation of E_hat(x).
No residual coefficient, gradient, or solver is supplied. Apply Sections 1-6
to this residual source, with zero additional field (the query field is
already consumed by the tractable optimizer). A cardinality multiplier may
still be used on a fixed-cardinality feasible set. If the residual test earns

  R(x)-R(z) >= -4 rho n  for every x in F,

then the true design regret is at most beta+4 rho n. This follows by ADDING the
two inequalities. The known tractable model need not itself possess an SDP
certificate. Its real forest dynamic program supplies its own optimality
proof. The unknown residual may be very large, dense, high rank, and far from
zero in every uniform prediction metric: it suffices that it does not make a
different feasible design much better than z.

This distinction is material. Plain Shor/diagonal PSD certificates need not
certify even an exactly correct tree optimum in nonzero fields. Subtracting
the already solved tractable core preserves the strength of that solver and
uses the spectral certificate only for the unknown remainder. This is a
sufficient operation-preservation test, not a generic minimization algorithm.

1. Actual source and output contract
-----------------------------------
There are n binary controls x in {-1,+1}^n. One shot at a chosen complete x
returns E(x)+xi, where

  E(x)=c+b^T x+x^T H x,  H=H^T, H_ii=0.

Conditional on the entire past and the chosen x, xi has mean zero and satisfies
E exp(t xi) <= exp(sigma^2 t^2/2). Fresh shots used in different coordinate
estimates are conditionally independent. A known finite entry cap |H_ij|<=B_e
is used only to control binary-expansion truncation; M_H=n B_e suffices as an
operator-norm cap. All n control settings per shot are charged. If the sensor
normalizes an extensive energy into a Bernoulli range, sigma must include that
normalization. No constant-noise physical assumption is inferred from n.

A candidate z in {-1,+1}^n, a later known field h, optional exact cardinality
sum_i x_i=sum_i z_i, and target additive regret epsilon*n are supplied to the
CERTIFIER. The candidate is obtained by an actual separately charged procedure
(e.g. the acquired forest dynamic program), not by this certifier. An optional
Lagrange multiplier lambda is any explicitly selected real number. Use lambda=0
without a cardinality constraint. The certifier returns ACCEPT or INCONCLUSIVE.
With probability >=1-delta, every ACCEPT is a valid epsilon*n regret guarantee
for the true source. It need not accept every optimal candidate.

The theorem is sound for arbitrary dense quadratic H and arbitrary b. Its
favorable running time depends on the spectral size of a certificate that
actually exists, not on sparsity of H. The exact quadratic source class is a
structural premise. Unrestricted hidden high-degree spikes invalidate it.

2. The ordinary SDP dual identity, including an active resource constraint
-------------------------------------------------------------------------
Put g=b+h+lambda*1 and

  d_i = z_i ( (H z)_i + g_i/2 ),       Q = H - Diag(d).

For every binary x,

  x^T H x + g^T x - (z^T H z + g^T z)
       = (x-z)^T Q (x-z).                              (1)

Proof: expand the right side and use
(x_i-z_i)^2=-2 z_i(x_i-z_i). The cross term becomes
2 (Hz+g/2)^T(x-z), as required. On the cardinality slice the lambda term
cancels. Thus Q >= -rho I proves regret <=4 rho n. In particular Q>=0 is a
standard sufficient SDP certificate of global optimality, even when H is dense
and the energy graph has full treewidth. This is a sufficient certificate, not
a characterization of all global optima.

3. Acquire the diagonal without knowing b or H
---------------------------------------------
Let z^(i) flip coordinate i. Then

  ( E(z)-E(z^(i)) )/4 = z_i ( (Hz)_i+b_i/2 ).           (2)

For each i use fresh independent batches of m_d shots at z and z^(i). Add the
known z_i(h_i+lambda)/2. The resulting d_hat_i has sub-Gaussian variance proxy
sigma^2/(8 m_d). For zeta>0, taking

  m_d = max(1, ceil[ sigma^2/(4 zeta^2) log(2n/delta_d) ])

gives max_i |d_hat_i-d_i|<=zeta with probability >=1-delta_d. This event is
uniform over all lambda values subsequently added exactly to the same base
diagonal estimates. Reusing a SINGLE noisy E(z) across all coordinates would
create correlated errors; this proof explicitly uses separate fresh batches.

Define S=H-Diag(d_hat)+zeta I. On the diagonal event:

  Q>=0 implies S>=0;
  S>=-tau I implies Q>=-(tau+2zeta) I.                 (3)

Choose zeta=epsilon/16 and tau=epsilon/8. Then ACCEPT of a sound lower PSD test
for S certifies regret <=epsilon*n by (1)-(3).

4. Realize H times a sign vector using only binary scalar experiments
-------------------------------------------------------------------
For any s in {-1,+1}^n and coordinate i, use four configurations with x_i set to
plus/minus and all other coordinates set to s_-i or -s_-i. The combination

 [ E(+1,s_-i)-E(-1,s_-i)-E(+1,-s_-i)+E(-1,-s_-i) ]/8
       = sum_{j!=i} H_ij s_j = (Hs)_i.                (4)

The offset and all linear terms cancel. With m independent shots per term,
the coordinate error is conditionally sub-Gaussian with proxy sigma^2/(16m).
Use fresh independent source batches for different i and different actions.
One sign action costs 4 n m scalar shots and at most 4 n^2 m control writes.

For an arbitrary represented real vector v with alpha=||v||_infinity>0, the
greedy signed binary expansion gives sign vectors s_l such that

  v = alpha sum_{l=1}^B 2^(-l) s_l + r,
  ||r||_infinity <= alpha*2^(-B).

The action alpha sum_l 2^(-l) Hs_l differs from Hv by norm at most
M_H sqrt(n) alpha 2^(-B). This is an actual list of binary source experiments,
not a promise that continuous control settings are available. When alpha=0,
the action is identically zero.

For M=I-S/a, a>0, evaluating its known diagonal part digitally and using these
actions gives

  v_next = Mv + beta + eta,

where ||beta||_2 <= eta_det if B is sufficiently large, and conditional on the
past eta has independent coordinates with sub-Gaussian proxies at most s2.
For alpha<=A it suffices to choose

  B >= ceil log2[ 2 M_H sqrt(n) A / (a eta_det) ],
  m(v) = max(1, ceil[ sigma^2 alpha^2/(16 a^2 s2) ]).

Indeed sum_l 4^(-l)<1/3, so this m is conservative. Reserve half eta_det for
finite-bit arithmetic in the known diagonal and the summation. Bit precision
grows logarithmically in the displayed finite quantities. The executable uses
floating-point arithmetic and is an experimental implementation, not an
interval-verified version of this finite-bit assertion.

5. A simple noise-tolerant gap-PSD tester (no eigensolver)
-------------------------------------------------------
The following intentionally conservative tester is easier to audit than a fast
Lanczos implementation. Fix a>=tau and kappa=tau/a in (0,1]. To test S with
failure allowance delta_p, set

  R = ceil[ log(1/delta_p)/log(4/3) ],
  L = log[64 n R/(delta_p kappa)],
  T = ceil(32 L/kappa),
  eta_det = kappa/32,
  s2 = kappa/(256 log 64),
  A = sqrt(2(1+T s2) log[4 n(T+1)R/delta_p]) + T eta_det + 1.

Perform R independent trials. Each starts with n independent fair signs v_0.
For t=0,...,T-1, reject the entire test as INCONCLUSIVE if ||v_t||_infinity>A;
otherwise construct the action above and set v_{t+1}=Mv_t+beta_t+eta_t.
Also reject if the final vector exceeds A. ACCEPT only if every trial stays
within A. Early rejection saves work and is not an incorrect-design output.

Soundness: if lambda_min(S)<-tau, M has an eigenvalue lambda>1+kappa and a
unit eigenvector u. Write s_t=u^T v_t. The discounted recurrence is

  lambda^(-t) s_t = u^T v_0
      + sum_{j<t} lambda^(-j-1) u^T beta_j
      + sum_{j<t} lambda^(-j-1) u^T eta_j.

The deterministic sum is <=eta_det/(lambda-1)<=1/32. The stochastic sum is
a sub-Gaussian martingale with total variance proxy <=s2/(2kappa). A two-sided
maximal exponential bound gives

  Pr(max_t |noise sum|>1/16) <= 2 exp[-kappa/(256s2)] = 1/32.

For a Rademacher starting vector, E(u^T v_0)^2=1 and E(u^T v_0)^4<=3.
Paley-Zygmund therefore yields

  Pr(|u^T v_0|>=1/4) >= (1-1/16)^2/3 = 75/256.

On the intersection, |s_t|>=(1/8)(1+kappa)^t. This has probability at least
75/256-1/32=67/256>1/4. If no threshold had been crossed by T, |s_T|<=sqrt(n)A,
contradicting this growth. To check the generous constants, T<=33L/kappa,
log[4n(T+1)R/delta_p]<=3L, and A<=6L, whereas
(1/8)(1+kappa)^T >= exp(16L)/8 >6 sqrt(n)L.
Thus a false matrix passes one trial with probability <=3/4, and all R
independent trials with probability <=delta_p. Stopping preserves the argument:
one can set unused future noises to zero, and stopping itself already rejects.

Completeness: if 0<=S<=2a I, then ||M||op<=1. Ignoring the bounded deterministic
errors, each coordinate of M^t v_0+sum_{j<t}M^(t-1-j)eta_j is sub-Gaussian with
proxy <=1+t s2. This follows from the conditional coordinate noise bound and
||M^j e_i||<=1; no independent trajectory states are assumed. Deterministic
bias has norm <=t eta_det. A union bound over n(T+1)R coordinates gives that
all trials remain below A with probability >=1-delta_p/2. This proves a
certifiable gap test, not an exact PSD decision at an unknown zero margin.

6. Cost and automatic choice of spectral scale
----------------------------------------------
The test makes at most

  4 n B R T max(1, ceil[sigma^2 A^2/(16a^2 s2)])      (5)

raw scalar source calls; each is at a complete binary configuration. Its
control-setting work is at most n times (5), plus diagonal acquisition. All
digital work to construct the actual queries and perform the recursions is
polynomial in those counts and bit precision. It need not store H: the
retained numerical state is the candidate, n diagonal estimates and O(n)
recursion vectors, plus any candidate-generating model.

Suppressing only logarithmic factors, (5) is

  O_tilde( n [ a/tau + sigma^2/tau^2 ] ).              (6)

The B,R,L,A factors are explicitly shown above; constants are conservative.
For fixed spectral scale and physical noise, this is near-linear source count,
but quadratic control-writing work. Do not claim near-linear total execution.

The scale a need not be supplied. Try a=tau,2tau,4tau,... with summable failure
allowances, fresh tester randomness, and the SAME diagonal estimates. An
ACCEPT remains sound at every scale. If Q>=0, then S>=0 on the diagonal event,
and a>=||S||op/2 makes the completeness result apply. A work-capped sequence
can report INCONCLUSIVE if no scale accepts. If unlimited retries are used,
fresh independent trials at a valid scale give finite expected completion.
No claim is made that a bad candidate will ever be accepted.

If no scale is accepted, the output remains INCONCLUSIVE. A rejecting PSD
test does not prove the design is suboptimal. For example, the unconstrained
antiferromagnetic triangle has an exactly optimal binary configuration whose
diagonal dual Q has minimum eigenvalue -1. Such examples prevent interpreting
certificate search failure as an optimization lower bound.

For later adaptive design queries, assign failure delta_t proportional to
1/t^2, and use fresh diagonal/source/test randomness conditional on the full
past. A union bound gives one lifetime correctness event for every ACCEPT.
The source cost grows with the number of queries. A fixed residual certificate
and this query-specific spectral certificate are complementary tools.

7. A strict separation from the Frobenius residual CERTIFICATE, not from all
   conventional algorithms
-------------------------------------------------------------------------
Let z be any binary design, P=I-zz^T/n, and let L=P W^T W P/n plus a bounded-
norm signed tree Laplacian with kernel z. Then L>=0 and Lz=0. Set
H=L-Diag(diag L), and take b=-lambda*1. On the cardinality slice of z, choose
the same lambda in the certificate. The true Q is exactly L. It can have rank
n-1, bounded operator norm, dense positive and negative off-diagonal entries,
and Frobenius norm of order sqrt(n). A forest or unary candidate can propose z;
the proposed experiment then certifies the true dense objective directly.
The uniform Frobenius residual bound can be order n^(3/2), hence useless for
epsilon*n accuracy. The spectral certificate certifies zero ideal regret and
epsilon*n with noisy assays. This does not say the unknown dense objective is
hard once its full coefficients are supplied: its SDP dual is the reason it
is certifiable, and an ordinary full-data SDP route is a strong comparator.

8. Strong conventional sources and actual remaining novelty question
--------------------------------------------------------------------
Needell, Swartworth, Woodruff (2022; revised 2023), 'Testing Positive
Semidefiniteness Using Linear Measurements', arXiv:2204.03782, treats both
matrix-vector and vector-matrix-vector query models, gives sharp testing
bounds, and contains faster methods than the conservative power test above.
https://arxiv.org/abs/2204.03782

Hardt and Price (2014), 'The Noisy Power Method: A Meta Algorithm with
Applications', analyzes noisy products including coherence-dependent effects.
https://proceedings.neurips.cc/paper_files/paper/2014/hash/3c8a075d9a17aa1ec1146f92e1eede8f-Abstract.html

Van Doornmalen, Molina, Verdugo, Verschae (2026), 'Tight L_infty Sample
Complexity for Low-Degree and Sparse Boolean Polynomials', arXiv:2606.17319,
directly studies optimization-safe surrogates. Its comparison must use the
actual extensive tolerance epsilon*n and actual source normalization.

The contribution here is the explicitly charged binary-scalar noisy access
bridge and the complementary operation-specific certificate. Historical
novelty of this bridge has not been established. A strong ordinary method can
adopt it. The theorem does NOT solve generic quadratic optimization, replace
the candidate generator, certify arbitrary misspecification, or provide a
zero-cost universal planner.

9. Resource-quotient extension: arbitrary nuisance on occupancy contexts
-----------------------------------------------------------------------
Suppose there are k physical two-site modules and physical binary spins. A
later experiment/design task fixes the number B_a in {0,1,2} of +1 spins in
each module. Let I={a:B_a=1}, m=|I|. The actual encoding from orientation
z in {-1,+1}^m is

  B_a=0: (x_a1,x_a2)=(-1,-1),
  B_a=2: (x_a1,x_a2)=(+1,+1),
  B_a=1: (x_a1,x_a2)=(z_a,-z_a).

Assume the physical law is an arbitrary unknown function g(B) plus a fixed
quadratic function of physical spins. On this context the induced source is

  E_B(z)=g(B)+c_B+b_B^Tz+z^T H_B z.

The arbitrary 3^k-entry nuisance is CONSTANT on every one of the physical
configurations used by (2), (4), and the signed-binary action construction.
It cancels identically. There is no estimate of g(B), no traversal of its
context table, and no assumption that g is quadratic across contexts.

The effective off-diagonal coefficient satisfies

 (H_B)_ab = H_a1,b1-H_a1,b2-H_a2,b1+H_a2,b2,

so a physical entry cap B_e gives effective cap 4B_e. Effective diagonal
terms are constants since z_a^2=1 and are moved into c_B. Known physical
unary fields become the orientation fields h_a1-h_a2. The same construction
applies to a learned forest surrogate restricted to B: subtract its known
value on the physical configuration before using the residual source.

Use n=m in the spectral proof and scalar-call count, but each physical shot
prepares 2k controls. Consequently source work is

  O_tilde( m[a/tau+sigma^2/tau^2] ),

while full control-writing work can be 2k times this quantity. No invisible
reset or preparation saving is claimed. If m=0, the context has a unique
configuration and no optimization/certification work is needed.

All observations for one spectral certificate stay in its chosen B. A
certificate is conditioned on its actual proposed orientation z. It cannot
be transferred freely to a different context or a different proposed design.
Later adaptive contexts/candidates use fresh experiments and summable failure
allowances, unless an explicit prior certificate already covers them.

The nuisance costs no IDENTIFICATION, but a source reporting absolute energy
must still supply the warranted absolute accuracy and represent its offset.
If its noise scales with the total output range, that scale belongs in sigma.
A genuinely differential matched-assay instrument can avoid reading a huge
offset; such an instrument is an additional physical capability, not a
consequence of algebraic cancellation. The same warning applies to finite-bit
arithmetic subtracting large nearly equal absolute energy readings.

10. Reuse under reinforcing controls
-----------------------------------
For a fixed accepted candidate z and fixed feasible set, replacing the field
by h+Delta h changes the corresponding dual to

  Q_new=Q-(1/2)Diag(z_i Delta h_i).

Therefore z_i Delta h_i<=0 for every i preserves the spectral lower bound and
the same regret certificate. An arbitrary added uniform field is also
irrelevant on a fixed-cardinality slice and can be absorbed in lambda. More
generally, if max_i z_i Delta h_i<=2s, the new regret bound increases by at most
4sn. These are explicit reusable sets of controls, with no new experiments.

For the residual/core composition of Section 0 the residual certificate does
not change with the query field as long as the actual core optimizer returns
the SAME z. Thus the certified set can additionally include any field region
on which the known core optimizer is proved to retain that candidate. It is
not a guarantee for a different optimizer output. Reuse may also restrict
the feasible set further if z remains feasible and the core's proved bound
continues to hold; feasibility itself must be explicitly checked.

ACQUIRED NONLINEAR FAST-FORWARDING: A COMPLETE BASELINE AND A REMAINING FRONTIER
Research constructor: capability_reframe. 2026-10-31.

STATUS

This file proves a restricted end-to-end mathematical construction and records a
synthetic implementation. It does not establish historical novelty, a measured
physical capability, or the parent's full mission of a genuinely new scientific
power. Its main algebra is standard class-two collection. The useful result of
the investigation is a completely paid baseline: observations -> checked finite
identities -> constructed nonlinear program summaries -> actual binary-horizon
execution. Neither a hidden conjugacy nor a downstream solver is supplied.

The proposed organising principle is: when the observed local operation lies in
a finitely checkable algebraic variety with compact free objects, construct the
free object on the FUTURE INPUT VARIABLES, instead of reconstructing latent
coordinates of the observed alphabet. This can expose a reusable computational
operation that a one-step model by itself does not expose. Here the variety is
groups with central commutators. This principle is not asserted novel.

1. POWER SOUGHT AND STRONG BASELINES

Power: after a finite campaign of noisy experiments on a previously unknown
local rule, compute a full n-site nonlinear system at a binary-encoded horizon
T, for arbitrary future initial states, in work polynomial in n and log T.
The learned object must also support composing future nonlinear local programs.

Retain-and-simulate: learn the q^2 local table and evaluate nT local updates.
Retain all global transitions: q^n states; table squaring is exponential in n.
Cycle detection: up to q^n global states; can be excellent on short cycles and
must be included in a practical benchmark. It is not uniformly polynomial.
Generic learned one-step approximation: local prediction error alone does not
guarantee long-horizon accuracy. A rare wrong table entry can be queried next.
Generic dense quadratic lifting: once appropriate coordinates/closure are
known, a dimension O(n^2) linear system gives binary powering; naive dense
storage O(n^4) and arithmetic O(n^6 log T). Structured lifting is substantially
stronger and may reproduce the present O(n^3 log T) algorithm.
Nilpotent collection: already gives exactly the short algebra exploited below.
Thus it is the strongest tailored baseline, not a discovery to be renamed.

Moore--Pnin (1998), "Predicting Non-linear Cellular Automata Quickly by
Decomposing Them into Linear Ones", already studies these nonlinear local
algebras, including central commutators. Its bound is polylogarithmic parallel
DEPTH, with circuit size polynomial in the light-cone horizon T and O(T) input
sites. It does not, merely by its stated depth bound, give poly(n,log T) work on
a fixed n-site ring. But its commutator construction strongly anticipates the
algebra here. In particular, Section 5 writes the predicted word as products of
generator powers and bounded-length commutators. The present modular summary
and substitution formula are a restricted uniform implementation of that idea.

Compressed-word algorithms for nilpotent groups are another close baseline.
An ordinary SLP for n-site T-step evolution has O(nT) gates; binary-encoded T
does not automatically make it a small SLP. Our missing executable step is
closed SUBSTITUTION of an entire equivariant word map, with O(n^2) coefficients.
There is no claim that this substitution consequence is historically new.

2. EXACT INPUT AND OBSERVATION CONTRACT

Alphabet A={0,...,q-1}; q>=2; an unknown deterministic table f:A^2 -> A.
The same time-independent spatially homogeneous table governs the future ring:

    F(x)_i = f(x_i, x_(i+1 mod n)).

An experiment prepares the exact ordered pair (a,b) and returns a label Y.
Conditioned on all previous observations and this query, the correct label
f(a,b) is returned with probability at least 1/2+gamma, gamma>0 supplied.
Preparation and output labels are included in the observation interface.
This is measurement noise, not stochastic evolution or model drift.

No group law, identity label, inverse table, exponent, factorisation, basis,
conjugacy, or long-time dynamics are supplied. The known local arity, stationarity,
spatial homogeneity and noise bias remain physical/interface premises. If they
fail, the theorem does not certify the actual system. Calibrating the bias in a
real experimental system would require a separately justified measurement model.

For every pair use

    r = an odd integer >= log(q^2/delta)/(2 gamma^2)

repeated measurements and take a strict-majority label, abstaining if absent.
The conditional bounded-noise Hoeffding argument gives failure <=exp(-2r gamma^2)
per pair. Union bound gives an event E with probability >=1-delta on which the
entire recovered table is EXACT. No future-query union bound is needed.

Queries: Q=q^2 r. Label communication O(Q log q) bits. Learned table O(q^2 log q)
bits. Counting repeated outcomes costs O(Q) plus count-bit arithmetic.

3. STRUCTURE IS CHECKED ON THE ACQUIRED TABLE

Find a two-sided identity, every two-sided inverse, and verify associativity for
all q^3 ordered triples. Then form [a,b]=a^-1 b^-1 a b and check that every
commutator commutes with every c, another q^3 tests. If these checks fail, return
NOT THIS CLASS; the learner is not promised a class-two group and does not
pretend to support arbitrary tables.

If they pass, the recovered table is a finite group of nilpotence class <=2.
On E this is a certificate for the actual deterministic local table. Off E a
wrong table could pass, which is charged to the same delta event.

Compute each element order by multiplying until the identity, at most q steps.
Let E0 be the lcm of these orders. Lagrange implies E0 divides q. The name E0
below denotes this exponent, not the event E. Store powers through 2E0-1.
All these tasks use O(q^3) table operations and O(q^2 log q) storage.

4. CONSTRUCTED EXECUTABLE REPRESENTATION

For any n introduce formal input generators X_0,...,X_(n-1). Store

    W(a,b) = X_0^a0 ... X_(n-1)^a(n-1)
             product_(i<j) [X_i,X_j]^b_ij,

with a_i modulo M=2E0 and b_ij modulo E0. There are n+n(n-1)/2 scalar slots.
The commutator convention is [u,v]=u^-1 v^-1 u v, so uv=vu[u,v].

For two collected words the multiplication law is

    (a,b) * (c,d) = (a+c, b+d-a_j c_i for each i<j).

This is a finite central extension. Its commutator coordinates are bilinear,
its commutators have order dividing E0, and every element has order dividing
2E0, since binom(2E0,2)=E0(2E0-1). Thus arbitrary assignments to its generators
define endomorphisms. Evaluating formal generators at any elements of the
acquired group is a homomorphism. No coordinates for the acquired group are
needed. The factor two is deliberate: naively storing a_i only modulo an even
E0 makes binom(a_i,2) ill-defined modulo E0.

Useful identities, all by collection:

    W(a,b)^k: linear k*a;
              central k*b_ij - binom(k,2) a_i a_j.

    [W(a,b),W(c,d)]: linear zero;
                     central a_i c_j-a_j c_i.

Spatially equivariant maps are specified by one base word W. Site s applies
that same word to (x_s,...,x_(s+n-1)). Relabeling variables under a cyclic shift
must also collect the wrapped generator blocks. For an original i<j mapping
to u=i+s mod n and v=j+s mod n:

    u<v: b'_uv += b_ij;
    u>v: b'_vu += -b_ij-a_i a_j.

This gives each shifted word in O(n^2) arithmetic.

5. CLOSED SUBSTITUTION IN O(n^3), NOT AN ORACLE

Let outer base word be W(u,c); inner base word V. Its shifted words V_i have
linear rows A_i and central coefficients B_i. Let K be the n*n matrix

    K_ii = -binom(u_i,2),
    K_ij = c_ij                         (i<j),
    K_ji = -c_ij-u_i*u_j                (i<j).

All K and central matrix arithmetic is modulo E0. The composed base word
W(V_0,...,V_(n-1)) has

    a' = u A                               modulo 2E0,
    b'_jk = (A^T K A)_jk + sum_i u_i B_i,jk modulo E0, j<k.

Proof: expand each V_i^u_i with the power identity, then collect their ordered
product. Its power self-interactions contribute diagonal K; crossings of V_i
and V_l contribute -u_i u_l A_l,j A_i,k. Substitution into the outer central
commutators adds c_il (A_i,j A_l,k-A_i,k A_l,j). These are exactly the two
off-diagonal entries of K. Inner central terms sum independently.

Computing A^T K A costs O(n^3). Generate B_i one at a time and accumulate its
weighted contribution in another O(n^3). Space is O(n^2). All coefficients have
O(log q) bits, with at most O(log n+log q) bits in unreduced accumulators.

The acquired one-step map has base word X_0 X_1 (X_0^2 if n=1). Repeated
squaring using the above composition performs at most 2 floor(log2 T)+1
compositions. Each full future ring state is evaluated by n short collected
words using the acquired table, inverse table, commutators and power table.
This costs O(n^3) table operations after O(n^2 log T) coefficient storage is
avoided by a rolling two-summary algorithm: actual live space is O(n^2).

The total arithmetic bound per future query is

    O(n^3 log(1+T))

plus acquisition O(q^2 gamma^-2 log(q/delta)), structure processing O(q^3),
O(n) input/output labels, and the stated modular bit costs. Total live storage
is O(q^2+n^2) scalars. A summary can itself be retained for repeated initial
states at the same n,T. The same composition routine executes arbitrary
grammar-compressed schedules of acquired group-word maps, with cost O(G n^3)
for a G-node binary concatenation grammar; leaves must be explicitly described
words. This is not an oracle for arbitrary adaptive state-dependent branching.

On the single event E, all these future outputs are exact simultaneously for
all n, T and initial states. The confidence concerns acquisition, not a
per-query approximation that accumulates over time.

6. SYNTHETIC REPLAY

Run: python3 consequence_reframe/class2_fastforward.py
Recorded output: consequence_reframe/diagnostic.json.

The source is an independently randomly relabelled Heisenberg group over F3,
q=27. Its hidden coordinates are used only to generate the synthetic oracle.
The learner receives only noisy queried labels. At actual corruption 18%,
supplied bound 20%, delta=1e-6, r=115 gives 83,835 queries. It recovers the whole
table in this run, performs 19,683 associativity and 19,683 centrality tests,
and discovers exponent 3. Acquisition plus checks took about 0.021 seconds on
this executor; this timing does not model real experimental latency.

54 finite trajectories were compared with direct simulation, 80 arbitrary
nonlinear word compositions were compared with direct execution, and 30 Q8
trajectories tested even-exponent arithmetic. All passed. S3 is rejected because
some commutators are noncentral.

A 43-site query at T=1,000,000,000,000,012,345 used 946 scalar summary slots,
89 compositions and approximately 1.33 seconds including execution. This
huge horizon was NOT independently replayed; a split-horizon composition check
passed, and the proof supplies the extrapolation.

The starting state has two noncommuting labels followed by identities. For the
Heisenberg source these have independent abelian quotient vectors. The linear
factor acts by 1+X in F3[X]/(X^43-1). Exact modular powering and prime-factor
descent give operator order 34,599,629,822. The two independent quotient vectors
make this also the starting state's quotient orbit period. Thus ordinary
cycle-detection cannot explain this example by a short hidden cycle. This does
not beat a tailored algebraic baseline, which is precisely what the compiler
implements.

7. WHY THIS IS STILL A BASELINE, AND THE CONCRETE MISSING OPERATION

Standard commutator collection already supplies the mathematical closure. The
construction pays acquisition and actual execution but does not warrant a
foundational novelty claim. A paper claiming merely "learn hidden group
dynamics and fast-forward" would overstate what was found here.

An acquired S3 multiplication table is the first small obstruction to this
closure. Its quotient C2 evolves linearly, but its C3 coordinate is propagated
by state-dependent signs. A finite-state one-step description exists; a bounded
quadratic summary does not. Moore--Pnin's polynomial-in-T parallel construction
does not settle poly(n,log T) sequential work. This is a sharper next operation
than generic "find a nonlinear representation": determine whether binary-time
prediction for the fixed S3 neighboring-product rule on an n-ring admits
poly(n,log T) work, or prove a suitable hardness/representation obstruction.
One must not silently replace that problem by polynomial-time-in-T NC depth.

A second meaningful frontier is stability to actual model mismatch: a local
table that is almost a class-two law, or a noisy/stochastic evolving system.
The present method only denoises observations of an exactly class-two table.
No claim that small one-step error permits huge-time prediction is justified.
Neither extension has been solved in this construction.

8. ACQUISITION BOUNDARY

Without a structural promise, any q^2 table entries can hide an alteration at
one ordered pair. The future-query family includes n=2, T=1 and the initial
state (a,b), whose first output is exactly that table entry. Therefore uniform
exact reuse includes recovery of the entire local table. On a baseline table,
couple a learner's transcripts with a family of one-entry alterations. If it
does not query the altered pair, the transcripts are identical and its answer
for that future input cannot be correct in both cases. Summing the resulting
query probabilities gives an Omega(q^2) worst-case observation requirement.
More precisely, require the learner to produce a correct reusable predictor on
the baseline table with probability >=1-alpha, and on each one-entry
alternative either produce a correct predictor or honestly reject with total
failure <=alpha. If p_ab is the probability that the baseline run ever queries
(a,b), the coupled event "baseline success and no query to (a,b)" has probability
at least 1-alpha-p_ab and is a failure on that alternative. Hence
p_ab>=1-2alpha, and the expected number of distinct baseline queries is at least
(1-2alpha)q^2. The requirement to succeed on the baseline prevents a vacuous
algorithm that always abstains.
So O(q^2) pair coverage is not free inefficiency that a more elegant latent
coordinate learner may simply wish away under the same unrestricted promise.

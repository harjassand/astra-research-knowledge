A SIX-SYMBOL BOUNDARY FOR REUSABLE NONLINEAR FAST-FORWARDING
2026-10-31. Locally derived reduction; historical priority not assessed.

This is the concrete next obstruction after CONSTRUCTION.txt. It is not a new
algorithm for discrete logarithms and not a lower bound for the homogeneous
S3 neighboring-product cellular automaton. It concerns polynomial-size explicit
group-operation circuit networks. A conditional computational barrier and an
unconditional linear-representation lower bound are proved below.

1. OPERATION AT ISSUE

Fix the group S3, with six explicitly named symbols. A state has m+1 group
registers. The one-step update is given by a polynomial-size circuit using
group multiplication, inverses, constants and shared subexpressions. Given an
initial state and T in binary, predict one distinguished register after T steps.

The local law is extremely easy to acquire: it has only 36 table entries. Even
granting its exact table for free does not settle the downstream operation.
Unknown representation acquisition is therefore not the bottleneck of this
example. Experimental trajectories still cost their actual number of steps.

Claim A. A classical algorithm for this operation with time polynomial in
m, circuit size and log(1+T) gives a classical polynomial-time algorithm for
discrete logarithms in F_(2^m), for instances supplying an irreducible defining
polynomial and a primitive generator. The reduction uses only O(m) endpoint
queries, and only a yes/no readout of the distinguished register.

Constant pointwise prediction error does not remove the reduction. If a query
returns the correct binary readout with probability at least 2/3, independent
repetitions and majority reduce each error to O(1/m), then a union bound makes
the binary search reliable with polynomial overhead. A numerical scalar
estimate of the deterministic readout with absolute error <1/2 likewise
reveals the bit. No exact full-state output is required.

This is a reduction, not a proof that such an algorithm cannot exist. It does
not assert an exponential classical discrete-log lower bound. Quantum
algorithms and changes to the computation model are outside this classical
comparison.

2. GROUP GADGET: CONJUNCTION WITHOUT A LARGE TRUTH TABLE

Choose an involution a and a three-cycle c in S3. Then a c a = c^-1. With
[u,v]=u^-1 v^-1 u v, for z,b in {0,1},

    [c^z,a^b] = c^(z*b).

Indeed b=0 or z=0 gives the identity. If z=b=1 the expression equals c^-2=c.
Starting w_0=c and setting w_(j+1)=[w_j,a^b_j] therefore gives

    w_m = c^(product_j b_j).

There are O(m) gates when w_j is a shared subexpression. Expanding this as a
literal unshared word would have exponential length; the circuit input model
is essential and explicitly charged. Inverses are constant-cost group
operations or a constant number of multiplications because all element orders
divide six. The same construction is a small explicit one-step circuit, not
a hidden predicate or oracle.

3. THE DYNAMICS

Take an instance g,h in F_(2^m)^*, with g primitive. Represent a field element
x in a fixed binary basis by bits x_0,...,x_(m-1), and encode them in registers
u_j=a^x_j. Multiplication x -> g*x is a known F2-linear transformation A and
has a circuit of O(m^2) group multiplications: XOR is multiplication inside
the subgroup {1,a}. The matrix is constructed by multiplying each basis vector
by g using the given field polynomial, in polynomial bit complexity.

At a current x, the bit indicating equality of x_j to h_j is

    b_j = 1 + x_j + h_j mod 2.

Its group encoding is a*u_j*a^h_j. Apply the nested-commutator gadget to these
m encodings. This produces exactly

    w(x) = c^(1{x=h}).

Add an accumulator r in <c> and update simultaneously

    x' = g*x,
    r' = r*w(x).

The total state has m+1 group registers; the one-step circuit has O(m^2)
gates, or fewer for a sparse field multiplier. Start x=1 and r=1.

4. REDUCTION TO DISCRETE LOGARITHM

Let N=2^m-1. There is one k in {0,...,N-1} with g^k=h. On the range 0<=T<=N,
the orbit visits h at most once, so

    r_T = 1 if T<=k,
    r_T = c if T>k.

Thus a binary search on T in [0,N] finds k using at most m queries to the
hypothetical fast-forward operation. All those horizons have O(m) bits, all
circuits and initial states are polynomial in m, and field/circuit setup is
polynomial. This proves Claim A.

The same circuit is reused for every binary-search query. A purported
learn-once algorithm with a single simultaneous confidence event therefore
does not evade the reduction. If an accelerator needs exponentially long
experimental trajectories to compile this circuit, its evidence cost is
already the missing computational cost; it has not supplied the desired power.

5. UNCONDITIONAL OBSTRUCTION TO EXACT LINEAR FEATURE CLOSURE

Let X=F_(2^m)^* and K be any field. Define f(x)=1{x=h}. The functions

    f_t(x)=f(g^t*x)=1{x=g^-t*h},  t=0,...,N-1,

are the N distinct delta functions on X. They are linearly independent over K.

Claim B. Every vector space of exact observable features on X that contains
f and is invariant under pullback by x -> g*x has dimension at least N=2^m-1.

Proof: closure contains every f_t; independence follows by evaluating any
linear relation at the N distinct supported points. This proof is basis-free.
It is not just an objection to a poorly selected monomial or Fourier basis.

The same lower bound applies if one starts with all accumulated observables
R_T(x)=sum_(t<T) f(g^t*x), because f_T=R_(T+1)-R_T. In particular, an exact
finite-dimensional linear state model with linear readouts for all these
accumulator queries cannot have polynomial dimension. A nonlinear decoder may
avoid the dimension claim, but its cost is not free; Claim A still applies to
the complete endpoint algorithm.

Approximate average-error feature models are not refuted by Claim B. Individual
delta functions have small average mass. The demanded operational readout is
pointwise at the specified initial state and binary horizon; replacing that
by average error over states changes the problem and may erase the event that
the query needs to decide.

6. FINITE DIAGNOSTIC AND PRECISE NONCLAIMS

Run: python3 consequence_reframe/discrete_log_boundary.py
Output: consequence_reframe/boundary_diagnostic.json.

The script builds the actual six-symbol permutation multiplication table, the
linear field-update circuit and the nested-commutator equality circuit. It
tests every target in fields of size 16 and 32, plus eight targets in the field
of size 256. All prefix answers use ordinary charged simulation. Binary search
recovers the exact exponent in every test. No unknown group coordinate map is
fed to the circuit; group constants and inverses are explicitly identified.

This is not evidence that discrete logarithms have been solved quickly. It
only tests the reduction on finite cases. Nor does it prove hardness for
S3 rings with the single fixed rule F(x)_i=x_i*x_(i+1), for which the ability to
embed the above known linear update and shared circuit has not been shown.

7. WHAT THIS CONTRIBUTES TO THE ORIGINAL MISSION

The class-two construction is an honest fully paid learning-to-operation
baseline, already supported by ordinary algebra. Enlarging the same claim to
all tiny solvable local algebras silently grants substantial computational
power. The S3 circuit above pinpoints that missing power with a classical
discrete-log reduction and an exponential exact-linear-closure obstruction.

A plausible genuine next capability must either solve a restricted portion of
this nonlinear accumulation problem, exploit a scientifically justified
approximate observable that avoids the target event, or find a useful algebra
between central commutators and this S3 construction. Merely fitting the
one-step model, invoking a latent representation, or citing polylogarithmic
parallel depth with polynomially many gates in T does not complete it.

The homogeneous S3 ring remains a narrower unresolved operation here. It is
worth attacking directly, but no theorem in this package claims it solved.

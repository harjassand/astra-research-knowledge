# Development correction retained before freeze

The first extreme-box scalar test reached Python's default 4,300-decimal-digit
integer-to-string limit while serializing a valid acquired rational. It terminated
with ValueError in Fraction.__str__, before any result file or acceptance claim.
This was a real wire/cost limitation, not a mathematical drift failure.

The new canonical wire uses tagged numerator/denominator hexadecimal strings for
all Fractions and tagged hexadecimal for integers above4,096bits. It does not
globally disable Python's digit safety limit. Wire bytes remain charged explicitly;
receive_wire has a byte budget and roundtrips canonical normalization. The entire
fresh preflight is rerun after this source change. No old output hash or accepted
source identity is assigned to regenerated bytes. The same-author receiver is
not an independent implementation, audit or adversarial security boundary.

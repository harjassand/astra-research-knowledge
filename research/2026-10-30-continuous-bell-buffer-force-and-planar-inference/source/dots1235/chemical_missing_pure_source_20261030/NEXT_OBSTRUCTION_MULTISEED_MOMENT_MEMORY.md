# Next obstruction: scalar reset envelopes lose incoming A memory
Status: exploratory obstruction calculation, NOT a new recurrence claim. Does not modify the four frozen A-catalytic proof files.

Consider trying to replace the active minimum A=1 by a0>=2: all fast complexes contain at least a0 A, sources a0 A+(m-a0)X_i produce more A, and mA is included. The first activation seed still supplies m A, and inactive A<a0 requires actual immigrations. The old proof does not automatically extend.

Heuristically (and subject to a new local proof) the slow-start time scale becomes N^{-(m-a0)}log N, so a uniform reset moment envelope would be p0~N^{-(m-a0)}log N. The crude section opportunity lower bound remains u0~N^{-(m-1)}. Substituting these into the refined scalar reset formula produces, for its ell=1 cross term, a relative power exponent

    [gamma + m(2-a0)-1]/m.

Already a0=2 requires gamma>1, which the mesoscopic proof cannot deliver. Thus scalar worst-case reset moments cannot certify the needed strict gap by the same inequalities.

This is not evidence of transience. A concrete explanation of the loss is available. Start a section with A proportional to N. Its first clearing leaves A still proportional to N, so an immigration/activation excursion initially retains a large A reserve. Replacing the NEXT clearing's reset kernel by the global p0 envelope permits an artificial instant jump to the slow-start A=a0 regime. The actual conservative fast process and bounded connector jumps do not perform that adversarial replacement for free.

A future extension therefore needs a composition-sensitive family of reset costs, such as propagation of several inverse-A moments or a joint incoming/outgoing A potential, rather than another scalar uniform clearing bound. The multi-seed inactive waiting alone is not the decisive obstruction: it is bounded. The loss is in conditional low-walk memory between successive reset kernels.

For comparison, the two-composition minimal graph 2A+C<->3A with q>3 and the connector is deficiency-zero (four complexes, one linkage, rank3), so it has conventional complex-balanced positive-recurrence machinery. It is an adversarial test of the scalar proof method, not a new hard scientific target by itself.

# A nominal rooted-burst norm kernel, and the unresolved inclusive expansion
2026-10-30. New partial derivation; no whole threshold acceptance.

## Useful result

A local operator insertion into the explicit rollback compiler causes at most a bounded number of mechanically nonideal terminal instruments before actual nominal retirement heals the affected histories. The duration, and the number of nearby nominal update events before healing, have exponential tails in completely bounded trace norm, uniformly over the bath/reference. This is enough to define an integrable one-root fault/delay kernel. It is NOT yet the inclusive multi-root local-noise bound required by the QCA theorem.

## 1. Deterministic coefficientwise emission count

Conjugation by the bounded-depth full-Hilbert forest enlarges a primitive insertion support to a fixed patch S+. For a local completely bounded superoperator N_(S,E), expand only its finite SYSTEM matrix indices. This expresses it as finitely many left/right system-matrix actions with bath superoperator coefficients, with total coefficient norm at most C_(dim S+) ||N||_cb. No bath basis or bath dimension enters that constant. Equivalently one may keep N intact and use the affected-owner support set below.

Mark every owner whose good-history projector or live frame meets S+. There are at most b fixed owners. Unmarked good ranges are preserved coefficientwise because all their predicates and supports commute with the insertion. Every subsequent nominal term preserves those ranges; a marked owner's first following complete retirement has its whole output in that owner's good range. Live ownership cannot be released and reacquired before such retirement. Consequently, absent another insertion, each marked owner can emit at most ONE possibly nonideal bounded-footprint DATA instrument. Clean terminal events after it are exact Phi attempts, and clean rollback is Id.

A root can also alter the QCA's own structure/program/clock fields on S+. Their later ALGORITHMIC propagation is not counted as fresh physical faults: it must be handled by the asynchronous QCA damage theorem. The bounded-emission claim concerns additional mechanical prefix/rollback errors only. It does not assert that the effect of a physical fault remains spatially localized under arbitrary computation.

## 2. Exponential return norm on nominal record branches

Let J_h be the sum of the actual nominal complete-retirement gains and K_h=L0-J_h. This is a genuine CP/TNI no-retirement generator for the NOMINAL physical apparatus. The verified full-Hilbert finite-path proof, after substitution of the new finite unitary payload, gives

    ||exp(t K_h)||_diamond <= C exp(-r t).                 (2.1)

The bound is reference-stable and holds on arbitrary signed input operators as a norm bound, not only on states. A fixed finite union of b marked owners gives the no-complete-healing event bound

    ||H_(>t)||_diamond <= b C exp(-r t).                  (2.2)

This follows by a union bound on positive event effects in the actual NOMINAL record instrument. It is valid after an arbitrary local root superoperator: composition multiplies the right side by ||N||_cb. The event is analytical and no physical flag/counter is added.

For sufficiently separated owner sets, the finite-support killed-witness product argument can give joint exponential miss bounds with fixed packing loss. This requires verifying the new witness supports and generator; it is not a claim of independent quantum clocks.

## 3. Exponential tail in nearby attempted-update count

Let D be the bounded set of update hubs whose full footprints meet the root's mechanical patch. Let n_D(t) count their actual NOMINAL SUCCESS events. Their total intensity effect obeys sum_(a in D) J_a^*(I) <= Lambda_D I, where Lambda_D is fixed, even on malformed states. The tilted CP instrument therefore satisfies

    ||E[exp(theta n_D(t)); ·]||_diamond
        <= exp[(exp(theta)-1) Lambda_D t].               (3.1)

Let tau be the first time all marked histories have retired, and n_D(tau) the nearby event count up to it. For any t and integer m,

    ||{n_D(tau)>=m}||_diamond
      <= b C exp(-r t)
         + exp[-theta m+(exp(theta)-1)Lambda_D t].        (3.2)

Indeed if tau<=t, the event is contained in n_D(t)>=m. These are genuine nominal CP record events, so effect union/Chernoff bounds apply uniformly to every initial state and reference. For theta=1 and t=m/[2(e-1)Lambda_D],

    ||{n_D(tau)>=m}||_diamond <= (b C+1) exp(-c m),
    c=min{r/[2(e-1)Lambda_D],1/2}>0.                     (3.3)

The Lambda_D=0 case is trivial. Thus a fixed root has finite exponential moment in both physical lifetime and nearby completed-update count. A bounded support multiplier and this integrable kernel are compatible with a small-activity polymer argument, but do not themselves constitute it.

## 4. The exact missing step under broad continuous noise

The target discrete condition is an INCLUSIVE fault-path norm bound: for every prescribed set F of virtual spacetime locations, the sum of all paths faulty at every location in F, with unrestricted extra faults elsewhere, must have norm <= eta_eff^|F| (or a fixed bounded-reuse exponent sufficient for renormalization). A bound on exactly k Dyson insertions, or on one isolated root followed by NOMINAL evolution, is insufficient.

Under arbitrary bounded joint HP generator perturbations, nominal SUCCESS/retirement gains need not remain physical sub-instruments. Example: the actual generator (1-epsilon) D[L] is CPTP and arbitrarily close to D[L], but deleting the OLD nominal gain L rho L^dagger gives a nonpositive no-jump map. For L=|0><1| and input |1><1| it is exactly

    exp[t((1-epsilon)D[L]-J_L)](|1><1|)
       = exp[-(1-epsilon)t]|1><1|
         - epsilon/(1-epsilon)*(1-exp[-(1-epsilon)t])|0><0|.

Thus the virtual nominal-record lift is not an actual CP lift under this allowed calibration error. A fortiori no conditional-probability argument on that lift is valid. This is not a physical instability; it is a proof obstruction.

Global absolute Dyson summation gives exp(O(eta N T)), which is unusable for a local threshold. Short-time Stinespring continuity O(sqrt(eta dt)) cannot be summed over dt->0. The remaining task is a localized spacetime hybrid/cluster expansion that contracts unmarked ACTUAL CPTP intervals without conditioning a fictitious SUCCESS record, while using (2)-(3) only on exposed nominal pieces. Shared bath support and non-CP individual perturbation pieces must remain explicit.

An alternative is an actual-state operator certificate for damaged regions and delayed updates. It would need to reproduce the recursive QCA fault-tolerance/damage argument; the specialized energy-monotone memory observable is not such a certificate.

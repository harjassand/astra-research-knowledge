Some collaborator scripts read files relative to their own script or expect the
workspace working directory; read their short main block if moving them individually.
The archive retains the directory structure. Numerical wall times vary by hardware.
Result JSON files are retained from the executed run. Running a script may replace
its corresponding output JSON with a new run. Seeds are in the scripts.

The general all-order Gaussian word engine and end-to-end interval arithmetic are
constructively specified in PROOFS.txt but are NOT implemented as a finished package.
Large computations implement the reference and first interaction insertion. Higher
orders are checked against dense small-state matrices. The ordinary double-precision
code is limited to resolved probabilities, rates, spectral gaps and Gaussian charts;
the arbitrary-precision circuit algorithm in the proof is not silently delegated
to NumPy. The separate Decimal script handles the specified six-site stiff stress.

This is a coordinator derivation from the stated model, not part of Dots' frozen acceptance, a new correction principle, or an acquired hardware result.

Consider only the identity/idle service. Suppose the SAME isolated output memory and source-blind SWAP are available from the beginning, and the memory's noise is bounded over the entire requested storage/consumer interval. Set receiver dispersion to zero from the start, or omit the unnecessary receiver. Keep the unwanted source on. Its initial state is the supplied cold state, independent of the unknown data/reference input.

Apply the source-blind SWAP immediately for duration tau, isolate the memory using the same stated switch-off service, and store the input there. Later trace-preserving dynamics of the old source/data cannot change its reduced state. Any additional SWAP, initialization, isolation and full-duration memory noise belongs in epsilon_extra. Full-duration memory performance is an EXTRA comparison condition: the original post-release holding budget alone does not establish it.

In R2 let r=lambda/2 and c=sqrt(lambda)b. The cold initial source gives Y0=Tr_source(X_s rho0)=0, uniformly over data/reference inputs. The full trace-norm bound is therefore

    epsilon_early <= 4c^2 tau/r + epsilon_extra
                  = 8b^2 tau + epsilon_extra.

The output-memory map is thus bounded in the same full-diamond convention (maximum 2). No earlier correlated-source endpoint debit 16b^2/lambda is needed for this cold-start comparison. No photon detector, coherent receiver, cavity ramp, energy-selective eraser or source reset is required.

At the declared b=1/5 and tau=1/1000,

    8b^2 tau = 1/3125 = 0.00032.

To certify total error <=0.01 requires epsilon_extra<=0.00968. If epsilon_extra<=0.001 were earned for this longer memory interval and the baseline's actual operations, its sufficient upper bound would be 0.00132. The original assumed 0.001 residual allowance cannot simply be transferred to a longer holding task without earning that condition.

This is a stronger possible sufficient guarantee, not an ordering of actual errors: comparing two upper bounds does not prove that one actual device outperforms another. It explains why the isolated memory must be offered to strong alternatives before claiming an architectural storage advantage.

Scope limit: this does NOT implement a graph-phase operation whose required interactions are accessible only on the original data hardware. Moving a qubit to memory can remove access to those gates. Memory holding over the longer interval, SWAP performance, isolation and access timing all need the same fair physical bill. The comparison does not refute the accepted coherent receiver theorem. A task in which the noisy mediator supplies an essential entangling interaction is materially different and is already among Dots' stated next questions.

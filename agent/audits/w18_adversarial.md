# W18 adversarial audit: cross-result scientific transfer

Scope: attempt plausible cross-result compositions in ASTRA_KNOWLEDGE and identify interface conditions that prevent them. This is an adversarial transfer audit, not a certification of theorem correctness. Card statements below retain their recorded status (often source-derived/unreviewed).

## Five invalid compositions

1. **Phase robustness transferred to a phase-free or arbitrary-phase sampler.**

   Tempting composition: combine the positive-kernel sampler in N42/N43 with the “no inverse herald probability” phase bound in N44 and claim sampling remains efficient for any complex phases, or that phase input can be omitted. The N44 statement is conditional on a *supplied local phase gauge*, a pure undisplaced reference with nonnegative (A), same entry magnitudes, and every individual phase bounded by \(\theta\); its bound is \(\theta^2[(3h+1)+(4h+3)E]^2/4<1\). It explicitly does not cover arbitrary phases, mixed/displaced inputs, or uniform growing (h/E). N42’s positive-kernel result is for a rational nonnegative Bargmann kernel and specified herald, with numerical (E,h); N44 adds a perturbation guarantee, not an arbitrary-phase positive representation. N83 also records that unconditional TV can hide conditional TV 1, and that phase complexity/conditional weights need to be charged. **Missing assumptions:** a supplied recoverable gauge, pointwise phase bound with scale-control relative to (h,E), and the N44 pure/undisplaced/same-magnitude premise; alternatively a separate arbitrary-phase algorithm and its complexity/error guarantee. **Automatic exposure:** typed fields `phase_model={nonnegative,gauged_bounded,arbitrary,unknown}`, `gauge_supplied`, `max_phase`, `same_magnitudes`, `state_class`, `herald_condition`, `h,E`, and `uniformity_regime`; reject a phase-free/arbitrary request when the source requires gauged-bounded.

2. **Expected input cost transferred to a hard support ceiling.**

   Tempting composition: use N18/N19’s sharp expected-cost exponent and coherent-window construction to claim a hard energy-budget result, or use N32’s two-use hard-budget advantage to infer an expected-cost exponent. N18 permits arbitrary block states under \(\mathrm{Tr}(\rho H_{[r]})=Q\); its Jensen/typical-window proof and exponent \(\alpha\) are expectation-contract results. N19’s coherent window preserves adjacent-type coherence and counts model-input cost separately from preparation. N32 instead requires the *entire support* of the probe to lie in \(H_{[r]}\le Q\), and establishes a specific two-use qutrit witness and repeated-block lower bound; it does not give an optimal general hard-budget exponent. An expectation constraint admits rare high-energy tails that violate a hard ceiling, while projecting/truncating a state can alter both miss probability and coherence. **Missing assumptions:** a proved transformation preserving the error objective, false-alarm promise, and cost while mapping expectation to support (or vice versa), plus apparatus/preparation/control costs if the claim is total work. **Automatic exposure:** `budget_kind={expected,total_expected,hard_support}`, per-probe support certificate, cost observable, error metric, false-alarm contract, and `charged_costs`; block a result join across unequal `budget_kind` absent an explicit conversion lemma.

3. **Asymptotic archive rate transferred to a finite-bit physical implementation.**

   Tempting composition: turn N30’s dimension/order memory law or N37’s continuous Gaussian archive bound into a practical finite-bit archive by citing N73’s finite-bit spectral sampler, or infer finite-bit realization from a finite-dimensional rate theorem. N30 explicitly leaves finite-bit observation/compiler costs unresolved and its linked proof package is unavailable in this snapshot. N37 separates ideal archive bits from a rounded implementation whose one-instance 13 retained bits coexist with a 242,597-bit public table and 320 fresh random bits; deterministic finite-alphabet output has TV 1 under its continuous-output contract. N73 is a different rational-input buffered count-sampler interface, with a promised ideal path, explicit model and precision parameters; its complete theorem schedule was not emitted or executed, and only exact arithmetic building blocks were implemented/reported tested. These are different objects and guarantees. **Missing assumptions:** a common input/output experiment, explicit precision and representation map, certified total variation error for discretization and finite randomness, bit/runtime accounting (including public tables, fresh randomness, calibration and tails), and a proof that the finite implementation meets the target epsilon. **Automatic exposure:** `result_kind={asymptotic_order,finite_alphabet,finite_bit_algorithm}`, input encoding, output topology, `epsilon_scope`, `precision`, `public_description_bits`, `retained_bits`, `random_bits`, `runtime_model`, and proof status; do not promote asymptotic rates to implementation claims without all cost fields and a certified bridge.

4. **Measurement-specific archive transferred to a reusable classical channel.**

   Tempting composition: use N66’s archive guarantee for a query selected after storage to claim the archive simulates all future measurements jointly or implements a classicalizing/entanglement-breaking channel; alternatively use N92’s channel reconstruction for an archive-query guarantee. N66 allows a later choice of *one coordinate* and its own POVM; it expressly needs neither simultaneous joint output nor compatible/reusable POVMs. Its archive preserves the specified experiment’s output law. N92 concerns explicitly supplied compatible instrument channels and a dimension-free EB reconstruction inequality, with supplied Kraus/POVM/reference blocks/native precision/preparation data; the listed theorem classes do not represent all compatible channels, and there is no efficient general decoder/compiler or POVM search. A one-query archive need not preserve correlations across a sequence of measurements or an external reference. **Missing assumptions:** whether queries are single/adaptive/batched, whether joint outcome law and reference systems are preserved, compatibility/instrument structure, a supplied channel decomposition, and an explicit channel-distance criterion. **Automatic exposure:** `observation_interface={selected_single_query,joint_batch,adaptive_sequence,channel}`, `measurement_quantifier`, `joint_law_preserved`, `reference_system`, `instrument_supplied`, `compatibility_class`, and output distance; forbid “archive implies channel” unless a bridge theorem matches these fields.

5. **Selected pure/projector mixture transferred to arbitrary mixtures or global EB classicality.**

   Tempting composition: take a theorem proved for selected pure directions/projectors (for example the restricted pure uniform ladder in N69) and average over or replace them by mixed/projector mixtures, then claim global classicalization; or infer a pure-input ladder result from a mixed-family bounded-capacity claim. N69 states a restricted *pure uniform ladder* with bounded Holevo capacity and concludes an EB error bound for that ladder; the global target over arbitrary priors, \(C(E)=\sup_{\rm prior}\chi\), is recorded OPEN. It also flags weighted pure ladders as needing small flag-shift variation. Convexly mixing selected inputs changes the family, its capacity quantifier, and possibly flags/reference correlations; a selected projector list is not a uniform bound over all pure states, let alone arbitrary mixed states or channels. N18’s pure-null and zero-false-alarm assumptions likewise cannot be removed by mixing without a new argument. **Missing assumptions:** exact family/quantifier (selected set vs all directions vs all priors), mixture closure, uniform capacity bound under the enlarged family, flag-shift control, and the target EB metric/reference convention. **Automatic exposure:** `input_family`, `selection_rule`, `state_purity`, `projector_set_complete`, `mixture_closure`, `capacity_quantifier`, `reference_scope`, `error_metric`; reject widening the state family or quantifier unless a cited closure/extension result is present.

## Repository-level prevention

The recurring failure is that prose search returns nearby results while the join keys are mostly topic and terminology. The design already describes a result as having a *typed information interface, dependencies, costs and failure domain* (`DESIGN.md`), and the cards often state these boundaries in prose. To make that contract machine-facing, attach a compact normalized `interface` object and `transfer_limits` list to every result record, then expose them in result cards, search packets, exports, and the query API. At minimum encode:

| Field group | Required discriminants |
|---|---|
| State / quantifier | pure, mixed, selected family, all states, prior-uniform, iid/independent/correlated; reference and side information |
| Observation | one selected measurement, joint outcomes, adaptive sequence, channel/instrument; output and distance |
| Cost | expected, hard support, per-use, total; what is charged (input, preparation, apparatus, calibration, bits, runtime, randomness) |
| Regime | finite/asymptotic; fixed/growing dimension; epsilon range; phase/gauge; energy/herald assumptions |
| Evidence | source-reported, internally reconstructed, finite-tested, externally reviewed; supplied artifacts and missing bridge/proof |

Add a transfer gate that compares source and target contracts before composing claims. It should emit a machine-readable list of mismatches (for example `budget_kind: expected != hard_support`) and classify the proposed join as `compatible`, `conditional_on:[...]`, or `invalid_for_requested_scope`; never silently infer an omitted field. Unknown must remain unknown. Require an explicit bridge edge with a stated lemma and matched assumptions to resolve a mismatch. Search ranking may still retrieve related cards, but summaries should surface these mismatches before presenting a synthesized claim. Preserve citation-level provenance so each inherited premise can be traced to its card and evidence status.

This audit found strong prose-level boundary information in the cards, but that is not itself an automatic transfer check. No theorem correctness certification is attempted here.

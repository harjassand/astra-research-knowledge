## Actual cold tool use: a reusable thermal premise

A fresh server was launched by the package's **actual stdio manifest** (`uv`,
the pinned MCP SDK, and a committed public-corpus checkout), without installing
the neural runtime. The client performed tools/list, search and fetch calls.
The tool list was exactly `search` and `fetch`; structured and compatibility
JSON text matched. The thermal problem found N1012, content version
`ee6b59ae717fe0b5653f6c78280df28c43eb7efa536f29cbccba5a8bcdecccef`.

The client fetched its current capsule and the returned
[CANONICAL_SECTOR_RESPONSE.md, lines 1–80](https://github.com/harjassand/astra-research-knowledge/blob/2fb5350ce4b105534419fc846db840756331b6cc/research/2026-10-23-fresh-programme/intake/capital-integrated-2026-10-23/updates/2026-10-26-ultra-final-closeout/source/thermal/CANONICAL_SECTOR_RESPONSE.md#L1-L80),
SHA256 `60f2c21c90bcf128839f438cff363065abd6063286378f1402237ece76f3d874`.
Reading the passage gives the full half-line representation
`D = -sigma_x tensor d`, `Q = I tensor T + sigma_z tensor P_0`, with
`d_j = j + 1/2`. This enables a detuning-response construction that retains
the normal ladder and the actual unbounded transverse vertex, rather than
assuming an acquired bounded two-level interaction. The same passage identifies
the reduced sector Hamiltonian as generally non-Gaussian and retains finite
canonical-regulator/prepared-sector moment premises. It does not supply the
missing cold-heat or KMS/NESS preparation theorem, an acquired infinite-bath
parity measurement, or a working device.

The first attempt selected a packet reference covering the operator discussion
and incorrectly expected the introductory cold-heat sentence inside that
narrower range. Its assertion failed. The second attempt fetched the distinct
returned evidence window containing both the representation and the limitation;
it passed. This range error is retained: matching filenames/hashes alone was
insufficient. Neither a scope sentence nor a theorem was invented to make the
first range pass. The full-content baseline also finds N1012 within its five
candidates; the demonstrated gain is a compact executable source route, not
exclusive discovery or an established time saving.

## Implementation checks and deployment boundary

Eight adapter regression checks cover every current record's capsule/public
routes, exact proof reading, all notices/reviews, source-alias deduplication,
bounded lossless continuation, old versions with current correction context,
stale/invalid handles and explicit optional-runtime fallback. Three further
checks validate the official portable schemas and use real SDK stdio and HTTP
clients. HTTP also exercises the legacy initialize handshake. Full publication
integrity and these transport checks must pass at the reviewed PR head.

Initial local failures were corrected before publication: related units live
in generated packets and are objects, not strings; an obsolete `httpx` test
import was removed because the current SDK uses its own HTTP dependency.
Large capsules are deliberately multipart, with byte coordinates and a full
payload hash. Tests concatenate all pages; no current correction is omitted
to meet a budget. Invalid IDs produce explicit tool errors. Tests do not run
the archived scientific programs or confer a new scientific acceptance.

The current external gap is an approved reachable HTTPS MCP host or Secure MCP
Tunnel and the corresponding account connection. Local HTTP/stdio tests do not
establish ChatGPT web usability. No such endpoint, directory installation or
native P1/P2/P3 behavior is claimed. The dispatcher/coordinator must release
the exact prospective native Pro test at a natural boundary; no warm Pro was
reset or prompted by this implementation. Static public search/source routes
remain available.
